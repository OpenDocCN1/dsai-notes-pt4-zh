### 本地部署 GLM-4.5

GLM-4.5 和 GLM-4.5-Air 的基础和聊天变体的模型权重在 Hugging Face 和 ModelScope[本地部署](https://zhipu-ai.feishu.cn/wiki/HMQWwX3ztii7zhktzNOcxA5nn0f?from=from_copylink)上公开可用。对于本地部署，GLM-4.5 支持包括 vLLM 和 SGLang 在内的推理框架。全面的部署说明，请参考 。

### 在 BigModel.cn 上调用 GLM-4.5 API

BigModel API 平台 为 GLM-4.5 和 GLM-4.5-Air 模型提供 OpenAI 兼容的接口。有关全面的 API 文档和集成指南，请参考 https://docs.bigmodel.cn/cn/guide/models/text/glm-4.5。

### 在 Z.ai、智谱清言上与 GLM-4.5 聊天

### 将 GLM-4.5 与编码代理一起使用
