## Step 5：创建各 Agent 的 MEMORY.md

### 5.3 创建各 Agent 的 MEMORY.md

```shell
# 为每个子 agent 创建初始 MEMORY.md

for agent in ops dev xhs wechat x yt admin intel law finance; do

  cat > ~/.openclaw/workspace-$agent/MEMORY.md << EOF

# MEMORY.md - $(case $agent in ops) echo "运营虾";; dev) echo "开发助理";; xhs) echo "📕部";; wechat) echo "🛰️部";; x) echo "X平台部";; yt) echo "YT部";; admin) echo "私人助理";; intel) echo "情报部";; law) echo "法务助理";; finance) echo "财务助理";; esac)的长期记忆

## 身份

我是 $(case $agent in ops) echo "运营虾 🦐";; dev) echo "开发助理 💻";; xhs) echo "📕部 📕";; wechat) echo "🛰️部 📢";; x) echo "X平台部 ✖️";; yt) echo "YT部 📺";; admin) echo "私人助理 🎩";; intel) echo "情报部 🕵️";; law) echo "法务助理 ⚖️";; finance) echo "财务助理 💰";; esac)，负责 $(case $agent in ops) echo "用户增长、数据分析";; dev) echo "代码开发、运维、研发";; xhs) echo "📕笔记、封面";; wechat) echo "👸号长文、排版";; x) echo "X帖文、热点";; yt) echo "视频脚本、SEO";; admin) echo "日程、备忘";; intel) echo "竞品、趋势";; law) echo "合同审查、合规";; finance) echo "成本、预算";; esac)。

## 工作记录

### 2026-03-08

- 完成启动测试，团队协作架构就绪

---

_此文件用于存储重要的事件、经验教训和项目背景。_

EOF

done
```

## Step 6：配置 Cron 定时任务

### 6.1 Cron 任务类型

| 任务类型 | 数量 | 时间 | 作用 |
| --- | --- | --- | --- |
| 周反思 | 6 个 | 周日 10:00 | 整理本周经验，更新 `MEMORY.md` |

### 6.2 创建周反思任务

#### main 的周反思（main session，可读 `MEMORY.md`）

```shell
openclaw cron add \
  --name "main-weekly-reflect" \
  --agent "main" \
  --cron "0 10 * * 0" \
  --tz "Asia/Shanghai" \
  --session "main" \
  --wake "now" \
  --system-event "执行周反思：1. 读 memory/ 最近 7 天所有日志 2. 提炼有价值的模式、决策、教训到 `MEMORY.md` 3. 清理 `MEMORY.md` 中过时的条目 4. 若本周无日志，在 `MEMORY.md` 记录「本周无活跃任务」5. 完成后在频道简报本周摘要"
```

#### 子 Agent 的周反思（isolated session，隔离执行）

```shell
for agent in ops dev xhs wechat x yt admin intel law finance; do

  openclaw cron add \
    --name "${agent}-weekly-reflect" \
    --agent "$agent" \
    --cron "0 10 * * 0" \
    --tz "Asia/Shanghai" \
    --session "isolated" \
    --wake "now" \
    --message "执行周反思：1. 读 memory/ 最近 7 天所有日志 2. 提炼有价值的模式到 `MEMORY.md` 3. 清理过时条目 4. 完成后简报本周摘要" \
    --thinking "low" \
    --timeout-seconds 300 \
    --announce \
    --channel "last"

done
```

### 6.3 验证 Cron 任务

```shell
openclaw cron list
```

## Step 7：配置 Heartbeat

### 7.1 Heartbeat 作用

- 定时巡检系统状态

- 整理记忆，提炼经验

- 发现问题主动汇报

### 7.2 配置 main 的 Heartbeat

```shell
openclaw config set agents.list[0].heartbeat '{"every": "6h", "session": "main", "target": "none", "prompt": "Read HEARTBEAT.md if it exists (workspace context). Follow it strictly. Do not infer or repeat old tasks from prior chats. If nothing needs attention, reply exactly: HEARTBEAT_OK"}' --strict-json
```

### 7.3 验证配置

```shell
openclaw config get agents.list[0].heartbeat
```

## 常见问题

### Q1：子 Agent 无法被 spawn？

**检查**：

```shell
openclaw config get agents.list[0].subagents.allowAgents
```

**解决**：

```shell
openclaw config set 'agents.list[0]' '{"id": "main", "subagents": {"allowAgents": ["ops", "dev", "xhs", "wechat", "x", "yt", "admin", "intel", "law", "finance"]}}' --strict-json

openclaw gateway restart
```

### Q2：修改配置后不生效？

| 修改内容 | 生效方式 |
| --- | --- |
| Workspace 文件 | 清 session |
| `openclaw.json`（大部分） | 热重载 |
| heartbeat 配置 | 重启 Gateway |

```shell
# 万能操作
find ~/.openclaw/agents/*/sessions/ -type f -delete && openclaw gateway restart
```

### Q3：write 工具有路径限制？（云服务会遇到这个）

**原因**：`write` 工具只能写入 workspace 内

**解决**：用 `exec` + `cat` 写入 workspace 外的文件

```shell
cat > /path/to/file << 'EOF'

内容

EOF
```

### Q4：Gateway 启动失败？

**检查端口占用**：

```shell
lsof -i :18789

# 如果有进程占用，杀掉
kill <PID>
```

**检查配置语法**：

```shell
python3 -c "import json; json.load(open('$HOME/.openclaw/openclaw.json')); print('valid')"
```
