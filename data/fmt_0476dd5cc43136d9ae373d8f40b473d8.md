
## 触发条件类型

1. 时间触发：按照时间间隔触发
1. 事件触发：按照特定事件触发
1. 数据触发：按照数据变化触发
1. 手动触发：手动触发执行

## 触发条件配置

时间触发配置

+ 每天触发：每天固定时间
+ 每周触发：每周固定时间
+ 每月触发：每月固定时间

事件触发配置

+ 文件上传：上传文件后触发
+ 邮件接收：接收邮件后触发
+ 任务完成：任务完成后触发

数据触发配置

+ 数据更新：数据更新后触发
+ 数据达到阈值：数据达到阈值后触发
+ 数据异常：数据异常时触发

## 配置示例

配置 1：每天生成日报

+ 触发条件：每天 18:00
+ 执行流程：收集今日数据、生成日报、发送日报

配置 2：每周生成周报

+ 触发条件：每周五 17:00
+ 执行流程：收集本周数据、生成周报、发送周报

配置 3：收到邮件自动回复

+ 触发条件：收到特定邮件
+ 执行流程：分析邮件内容、生成回复、发送回复

## 案例示例

### 案例：自动化会议纪要流程

任务：自动化生成会议纪要

流程设计：

步骤 1：会议录音

+ 使用录音设备录制会议
+ 自动保存录音文件

步骤 2：语音转文字

+ 使用语音识别工具
+ 将录音转换为文字

步骤 3：生成会议纪要

+ 使用 Claude Code 生成会议纪要
+ 提取会议要点
+ 整理决议事项
+ 列出待办事项

步骤 4：人工审核

+ 人工审核会议纪要
+ 调整不准确的内容
+ 补充遗漏的信息

步骤 5：发送会议纪要

+ 自动发送给参会人员
+ 保存会议纪要存档

触发条件：

+ 会议结束后自动触发

测试结果：

+ 准确性：95%
+ 完整性：90%
+ 效率性：节省 80% 时间
+ 稳定性：稳定可靠

效果：

+ 原耗时：2-3 小时
+ 现耗时：30-45 分钟
+ 节省时间：70-80%

## 小技巧

1. 从小流程开始：先从简单的流程开始，逐步复杂化
1. 持续优化：根据使用情况，持续优化流程
1. 记录配置：记录流程的配置，方便后续使用
1. 测试验证：配置完成后，测试验证流程的效果
1. 备份配置：备份流程配置，防止丢失
