# 引言

《流浪地球》是深受大家喜爱的系列科幻作品，其中提及了许多引人深思的科技概念，“人在回路”便是之一。影片中，人类的智慧和决策过程（数字生命图丫丧的介入）融入到机器学习的循环中，让人工智能（MOSS）在执行任务时不仅依赖数据，更考虑道德和伦理因素（人道主义），从而避免了人类的毁灭性危机。在自动化和智能化系统中，人类智能的不可替代性，以及在关键决策过程中引入人类判断的过程是至关重要的。智慧和算法的有机融合，不仅在电影中试图帮助人类构建一个充满希望的未来世界，在现实世界的科学研究和技术发展中也具有深远影响。

![](img/3baeeb4eac5612cbb0856925308286ce.png)

基于人类反馈的强化学习（Reinforcement Learning with Human Feedback, `RLHF`）是大语言模型（Large Language Models, `LLMs`）的典型训练方法，在对大量数据进行训练时，人类的直接反馈被用来优化模型的性能。这样看，`RLHF`其实也是一种实现“人在回路”的技术手段，并且已在`LLMs`训练中得到广泛应用。回顾计算机视觉领域相关研究，尤其是文本到图像（Text-to-Image, `T2I`）的生成任务，虽然技术上取得了显著进步，但生成的图像仍然存在诸多问题，如伪影、与文本描述不一致以及审美质量低下。这些问题凸显了现有自动评估指标的局限性，同时也表明了在图像生成过程中引入人类反馈的必要性。

本次将要介绍的这篇CVPR 2024最佳论文候选《Rich Human Feedback for Text-to-lmage Generation》，其核心贡献在于提出一种新颖的方法，通过收集和利用丰富的人类反馈来指导和改进`T2I`生成模型，这不仅为图像生成领域带来了新的思路，也为“人在回路”概念在计算机视觉中的实践有效性提供了有力证明。

# 论文十问

## Q1：论文试图解决什么问题？

论文试图解决`T2I`生成模型在生成高分辨率图像时仍然存在一些问题，例如现实规则不一致（图像中的伪影与不合理性）、图文语义不一致（与所提供的提示词描述不一致）、美学期望不一致（生成的图像具有低审美质量）。为了改善这些问题，论文提出了一种通过丰富人类反馈来改进`T2I`生成的方法。

## Q2：这是否是一个新的问题？

这个问题并不是一个全新的问题，因为在深度学习时代，`T2I`生成模型已经经历了多次迭代和进化，包括生成对抗网络（`GANs`）、变分自编码器（`VAEs`）和扩散模型（`DMs`）。`T2I`生成模型的改进一直是计算机视觉和机器学习领域的研究热点，这些模型在生成图像的质量和多样性方面取得了显著进展，但上述问题仍然是该领域研究者们面临的挑战。不过，本文提出的解决方案是新颖的，因为它引入了丰富的人类反馈来改善评估和生成过程，这是对现有方法的扩展。

## Q3：这篇文章要验证一个什么科学假设？

文章希望验证：通过收集和利用丰富的人类反馈（包括图像中不合理或与文本不一致区域的标记、文本提示中未被正确表示或缺失的词汇的注释，以及对图像的多方面细致评分），可以训练一个多模态`Tansformer`模型（`Rich Automatic Human Feedback`, `RAHF`）来自动预测这些反馈，并且使用这些预测的反馈来改善`T2I`生成模型的输出质量。具体来说，这个工作期望使用预测的反馈来指导模型微调、选择训练数据，以及进行区域修复，从而提高生成图像的质量。

## Q4：涉及哪些相关研究领域？

+ 文生图模型：`GANs`、`VAEs`、`DMs`这些模型通过不同的方法生成图像，但都面临质量和准确性的挑战。

+ 图像评估和奖励：研究者们开发了多种评估生成图像质量的方法，例如基于人类偏好的数据集和评估模型，如`Pick-a-Pic`，`PickScore`，`T2I-CompBench`，`HPS`等。

+ 图像修复和编辑：一些研究专注于通过识别图像中的伪影或不合理区域，并提出修复方法，如使用分割模型预测伪影区域并进行修复。

+ 图文多模态学习：结合图像和文本信息以提高生成质量和评估准确性的研究，例如使用`CLIP`模型来评估图像和文本的对齐度。

## Q5：论文中提到的解决方案之关键是什么？

+ 丰富的人类反馈：通过标记图像中的不合理或与文本不一致的区域，并注释文本提示中未正确表示或缺失的词汇，收集更细致和可解释的反馈。

+ 多模态`Transformer`：设计了一个名为`RAHF`的模型，用于自动预测丰富的人类注释。

+ 预测的反馈的下游应用：使用预测的反馈来改善图像生成过程，包括选择高质量的训练数据进行微调，以及创建掩码来修复问题区域。

## Q6：论文中的实验是如何设计的？

### 数据收集

论文收集了18,000张生成图像的丰富人类反馈，包括点注释、文本标记和细粒度评分。注释数据的要点详见图一，注释者在图像上标记点以指示与文本提示相关的不合理区域（图中红点，如熊猫的鼻子和轮毂部分）或图文不一致区域（图中蓝点，如右侧熊猫）。然后，标注者点击单词以标记不匹配的关键词（右侧下划线和着色文字，例如这里有两只熊猫），并为可信度、图文对齐程度、美观度和整体质量选择分数（右侧下划线文字）。

### 模型训练

如图三所示，论文使用收集的数据训练`RAHF`模型，该模型结合了视觉变换器`Vision Transformer`（`ViT`）和文本编码器（`T5X`），主要包括如下几个部分：

1. 双流计算：模型包含两个主要的流，一个是视觉流，处理输入的图像；另一个是文本流，处理与图像相关的文本提示。使用`ViT`作为编码器，将输入图像转换成一系列的图像token，这些token是图像的高级表示。文本提示被嵌入成密集向量，然后通过`T5X`模型进行编码。

2. 自注意力模块：图像token和文本token通过自注意力模块进行融合，以实现图像和文本信息的双向传播。

3. 图像特征映射：图像token被重塑成特征映射，特征映射通过一系列层，最终通过`Sigmoid`激活函数输出不合理性和不一致性的热图，以及四项细致评分的标量值。

4. 文本预测：使用`T5X`解码器生成文本序列，预测文本中与图像不一致的关键词序列。

5. 损失函数：模型使用像素级均方误差（`MSE`）损失函数来训练热图预测，使用均值损失来训练分数预测，以及使用教师强制交叉熵损失来训练文本序列预测。

![](img/4b5af5aed73addc47c4f508ff4516c7d.png)

## Q9：这篇论文到底有什么贡献？

1. **数据集创建**：首次创建了一个包含18,000张图像的丰富人类反馈数据集（`RichHF-18K`），它包括对图像中不合理或与文本描述不一致区域的标注、文本中缺失或错误表示的关键词的标注，以及对图像的合理性、文本-图像对齐、审美和整体质量的细粒度评分。

2. **模型设计**：提出了一个多模态变换器模型`RAHF`，该模型能够自动预测人类对生成图像的丰富反馈。这包括对不合理区域和文本-图像不一致区域的热图预测，以及对图像质量的细粒度评分预测。

3. **提高生成质量**：展示了如何利用`RAHF`模型预测的丰富人类反馈来改善图像生成过程。具体方法包括使用预测的热图作为掩码进行问题区域的修复，以及使用预测的评分来指导生成模型的微调，从而提高生成图像的质量。

4. **泛化能力证明**：证明了通过`RAHF`模型获得的改进不仅可以应用于生成训练数据集中的模型（如`Stable Diffusion`变体），还可以推广到其他模型（如`Muse`），显示了`RAHF`模型良好的泛化能力。

## Q10：下一步呢？有什么工作可以继续深入？

1. **提高标注质量**：论文提到了在标注过程中存在的一些问题，如对人类面部和手部的过度标注。未来的工作可以探索改进标注指南和流程，以减少此类问题。

2. **探索新的应用场景**：`RAHF`模型目前主要应用于图像生成的评估和改进。未来的研究可以探索将该模型应用于其他领域，如图像编辑、视频生成或虚拟现实内容创建。

3. **集成到生成模型中**：将`RAHF`模型集成到`T2I`生成模型的训练过程中，可能通过直接使用预测的反馈作为训练信号来提高生成质量。

4. **奖励信号的进一步研究**：使用预测的反馈作为强化学习的奖励信号，以微调或训练生成模型，这可能是一个值得探索的方向。

5. **伦理和社会影响研究**：随着`T2I`技术的发展，研究其对社会、文化和伦理的潜在影响，确保技术的健康发展和使用。

# 扩展阅读

+ `IC9600`（南开大学计算机视觉实验室杨巨峰团队）

+ 图像复杂度通常与人类感知有密切关系，因为更复杂的图像往往包含更多的视觉元素和信息，这可能会影响人类的注意力分配、记忆负荷和审美评价，进而影响对图像的理解。`IC9600`旨在评估图像的复杂度，其包含了多种类型的图像，每张图像都经过了人工标注，以评估其复杂度等级。数据集由17个标注人员标注其复杂度分数（1-5 分制）。这个数据集可以用于训练和测试计算机视觉模型，以提高它们对图像复杂度和图像语义理解的能力（数据集链接：`https://github.com/tinglyfeng/IC9600`）

![](img/7692cb97d18bcf500e91b2c5b27d46d1.png)

+ `EmoSet`、`EmoGen`、`EmoEdit`（深圳大学可视计算研究中心杨景媛团队）

+ 视觉情感计算是计算机视觉和情感计算的交叉领域，它涉及到分析和理解图像或视频中的情感内容。`EmoSet`是一个图像情感数据集，它包含了大量带有情感标签的图像。`EmoSet` 总共包含 330 万张图像，其中 118,102 张图像由人类注释者仔细标记。（数据集链接：`https://vcc.tech/EmoSet`）

![](img/6b2a2bb6583c55008d327e6b833c6e77.png)

+ 人类直觉反馈机制也可用于进一步深入探究视觉情感计算模型，目前有如下一些场景得到初步探索：`EmoGen`是一个生成模型，它可以根据给定的情感标签生成具有相应情感特征的图像。这种模型在艺术创作、广告设计等领域有广泛的应用潜力。`EmoEdit`是一个编辑模型，它允许用户对图像中的情感内容进行编辑和调整。例如，用户可以增强或减弱图像中的某种情感表达，或者改变图像的整体情感氛围。

# 结语

展望未来，我们可以预见`RLHF`将不局限于自然语言处理领域，在计算机视觉领域等多个领域也将不断得到应用和进一步的发展。随着模型的不断优化和数据集的扩充，我们期待看到更加精准、更具创造性的图像生成模型。同时，这也将激发我们对于人工智能与人类协作的更多思考，如何平衡技术的发展与人类的价值，确保技术进步能够服务于人类的福祉。总之，这篇论文不仅为我们提供了解决现有问题的新思路，也为我们打开了探索人工智能与人类协同工作新领域的大门。随着技术的不断进步，我们有理由相信，人工智能将成为人类创造性工作的有力伙伴，共同开创更加丰富多彩的视觉世界。
