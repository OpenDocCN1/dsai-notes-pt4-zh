
# “傻瓜式”中科院学术版ChatGPT 本地部署

> 来源：[https://diwfpqo78m.feishu.cn/docx/G5OxdJJ61o7wI6xRi4Dcvhf9nlL](https://diwfpqo78m.feishu.cn/docx/G5OxdJJ61o7wI6xRi4Dcvhf9nlL)

中科院学术专业版 ChatGPT 仅用了短短一两天，该项目 Star 数便增长到了 1800+，成为 GitHub 上又一个基于 ChatGPT 构建的热门开源项目。项目针对中科院日常科研工作，基于 ChatGPT 专属定制了一整套实用性功能，用于优化学术研究以及开发日常工作流程。

安装使用有一定门槛，尤其对于一些没有 Python 基础的小伙伴很不友好；但安装好后，你无需🪜即可直接使用 GPT，不用再去用各种镜像网站了。因此，这里简单总结一下教程。

## 前提条件

1. 官方安装包：[https://github.com/binary-husky/chatgpt_academic](https://github.com/binary-husky/chatgpt_academic)
2. 安装 Anaconda（Windows 为例）：[Anaconda 超详细安装教程（Windows 环境下）\_windows安装anaconda\_菜鸟1号！！的博客-CSDN博客](https://blog.csdn.net/fan18317517352/article/details/123035625)
3. 获取 GPT 的 API：自备上网环境 + GPT 账号 + 到官网获取 API。

    关于[如何获取 API](https://zhuanlan.zhihu.com/p/615392081)：有几种方法，一种是直接购买 GPT 账号，有些注册商直接提供账密和 API 给你直接使用，鉴于广告嫌疑，请自行解决；另一种方法是使用自己注册的账号到官网获取，官方获取教程参考：如何获取 ChatGPT 的 API KEY – 知乎 (zhihu.com)。

    关于[如何获取 Access Token](https://chat.openai.com/api/auth/session)：获取 Token 同样很简单，登录 ChatGPT 之后，输入以下地址即可：`https://chat.openai.com/api/auth/session`，有效期一个月，过期后需要重新获取。
