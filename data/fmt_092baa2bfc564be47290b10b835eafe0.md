
# 特殊的 IP 地址 `127.0.0.1`

> 来源：[https://leonzhang.feishu.cn/docx/UeRUdJD95o2zKsxBiXjcU5Ranbh](https://leonzhang.feishu.cn/docx/UeRUdJD95o2zKsxBiXjcU5Ranbh)

在网络配置中，`127.0.0.1` 是一个特殊的 IP 地址，它通常被称为 "本地回环地址" 或 "本地主机地址"。这个地址用于指向计算机自身，也就是说，当你尝试连接到 `127.0.0.1` 时，你的计算机会将请求指向它自己，而不是网络上的任何其他设备。

`127.0.0.1` 被称为 "别名" 是因为它是 `localhost` 的一个常用 IP 地址。`localhost` 是一个域名，它在 DNS 解析中被特别处理，总是指向 `127.0.0.1`。使用 `localhost` 而不是 `127.0.0.1` 的好处是，它提供了一种更可读和更易于记忆的方式来引用本地主机，同时它也允许系统管理员在不更改 IP 地址的情况下更改主机名。

简而言之，`127.0.0.1` 是 `localhost` 的 IP 地址，它们都用于指向运行它们的设备的本地地址，常用于开发和测试目的，以确保网络请求不会离开本地机器。
