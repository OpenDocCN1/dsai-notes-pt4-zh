# 五 wxauto 对接阿里云百炼智能体（搭桥梁，通血脉）

## 5.1 什么是 wxauto？

`wxauto` 是一个基于 Windows 桌面 UI 自动化的微信控制库，利用 `Win32 UI Automation` 技术实现：

- 自动读取 🛰️ 窗口内容
- 自动发送文本、图片、文件
- 自动选择聊天对象
- 自动提取聊天消息框文本
- 解析群聊消息（有限能力）

它本质上是一个 “模拟人类操作 🛰️ 电脑客户端” 的自动化库，而不是 🛰️ 协议层面的机器人框架。

不是 Hook，不外挂，不逆向 🛰️ 协议 → 封号风险最低。

**github 地址：** https://github.com/cluic/wxauto

## 5.8 实施过程常见问题与解决方案

### 5.8.1 技术类问题

#### 问题 1：wxauto 安装后无法识别 🛰️ 窗口

**现象**：

```
from wxauto4 import WeChat
wx = WeChat()  # 报错：找不到微信窗口
```

**原因**：

- 微信版本不兼容（`wxauto4` 支持 4.0.5）
- 微信未启动或窗口被最小化
- 微信进程名称异常

**解决方案**：

1. 确认微信版本：打开微信 → 设置 → 关于微信 → 查看版本号，必须是 4.0.5 版本
2. 确保微信窗口可见：不要最小化，不要被其他窗口遮挡
3. 检查进程：打开任务管理器 → 查找 `WeChat.exe`，如果有多个微信进程，关闭重启
4. 重启电脑（终极方案）：有时候系统 UI 缓存会导致识别失败

#### 问题 2：阿里云百炼 API 调用失败

**现象**：

```
dashscope.common.error.AuthenticationError: Invalid API-key
```

**排查步骤**：

1. 检查 API-KEY 是否正确：`print(os.getenv("DASHSCOPE_API_KEY"))`，应该输出 `sk-` 开头的长字符串
2. 检查 `.env` 文件位置：必须和 `heart-driven.py` 在同一目录
3. 检查 `.env` 文件格式：

   正确格式：
   ```
   DASHSCOPE_API_KEY=sk-xxxxx
   ```
   注意：等号两边没有空格，没有引号

4. 重新加载环境变量：`from dotenv import load_dotenv`，`load_dotenv(override=True)`（强制重新加载）
5. 检查百炼平台配额：登录阿里云百炼平台 → 密钥管理 → 查看剩余额度

### 5.8.2 运营类问题

#### 问题 3：机器人回答不准确

**表现**：

```
回答内容与知识库不符
编造不存在的信息
答非所问
```

**诊断方法**：

1. 在百炼平台测试同样的问题
   - 如果平台也回答错误 → 知识库或提示词问题
   - 如果平台回答正确 → API 调用问题
2. 查看知识库匹配情况：百炼平台 → 智能体 → 测试 → 查看“引用来源”
3. 分析提示词是否过于宽松：是否允许机器人“推测”或“延伸”？

**优化方案**：

在提示词中强化限制

你必须严格基于知识库回答，禁止任何推测、编造或延伸。

如果知识库中没有相关信息，你必须明确告知：
“抱歉，这个问题超出了我的知识范围，已转给教练团队，稍后会回复您~”

**绝对禁止**：
- ❌ 根据常识推测答案
- ❌ 综合网络信息回答
- ❌ 给出不确定的建议

#### 问题 4：个性化问题过多，机器人无法处理

**表现**：

```
机器人频繁回复“已转教练”
实际有效回答率 < 50%
学员体验不佳
```

**原因分析**：

- 学员问题确实个性化程度高
- 或知识库内容覆盖不足
- 或提示词判断标准过严

**优化方案**：

**扩充知识库**

增加“案例库”：
- 收集典型学员困境案例
