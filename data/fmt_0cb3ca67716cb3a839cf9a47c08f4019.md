### 一、题材和文风

#### 主流题材

+ 题材热度：言情 > 脑洞 > 世情 > 黑手党 > 悬疑/惊悚。

+ 言情是基本盘，体量最大。

+ 脑洞是增长点，容易出爆款。

+ 世情和黑手党是稳定的垂直品类，拥有固定受众。

+ 流派标签热度：

+ 重生/逆袭：出现频率极高，是当前最核心的流量题材。常与“复仇”、“虐渣”、“打脸”、“全家火葬场”等强情节绑定。

+ 火葬场文学：“追妻”和“追夫”是绝对的顶流。核心看点是“前期你对我爱答不理，后期我让你高攀不起”的极致反转与情感宣泄。

+ 狗血虐恋：包含“出轨”、“小三”、“白月光”、“替身”、“虐恋”等元素的婚恋故事，情感冲突强烈，读者粘性高。

+ 大女主/女强：强调女主“清醒独立”、“复仇”、“逆袭”、“事业心”，迎合现代女性读者的精神需求。

+ 脑洞/系统/超能力：如“读心术”、“系统”、“金手指”、“超能力”等，为传统言情和世情题材提供新鲜感，降低阅读疲劳。

#### 最热门题材组合

> 基于标签频率分析，当前最成功的题材组合为：重生 + 追妻火葬场 + 虐恋 + 爽文 + 反转

+ "追妻火葬场"：出现频率最高（约65%的作品包含此标签）

+ "重生"：第二高频标签（约60%作品包含）

+ "虐恋"：第三高频标签（约50%作品包含）

+ "爽文"：第四高频标签（约45%作品包含）

+ "反转"：第五高频标签（约40%作品包含）

#### 爆款作品特征（划重点，要考的！）

+ 【女频顶配】：重生 + 追妻火葬场 + 虐渣 + 爽文 + 反转 + 大女主/清醒独立

+ 【男频利器】：男视角/男频 + 追夫火葬场 + 豪门霸总 + 复仇 + 反转

+ 【黑手党专供】：Mafia/黑手党 + 出轨狗血 + 虐恋追妻 + 反转 + 大女主

+ 【脑洞新奇】：重生/系统 + 超能力/金手指 + 反转 + 爽文 + (猎奇/奇葩元素)

+ 【世情爆款】：家庭情感/全家火葬场 + 重生/死人文学 + 反转 + 打脸 + 爽文

### 二、欧美读者的偏好

#### 女性读者（主要受众）偏好

+ 情感需求：虐恋中寻求情感宣泄，追妻火葬场中获得情感补偿

+ 核心爽点：打脸渣男、逆袭、复仇、觉醒

+ 角色偏好：清醒独立女主 vs 偏心/自私男主

+ 热门冲突：小三、白月光、偏心父母、财产纠纷

#### 男性读者偏好（少数但稳定）

+ 热门题材：死人文学、亲情向、追夫火葬场

+ 核心爽点：复仇、逆袭、打脸

+ 角色偏好：家庭破坏者、男视角

### 三、想出海的同学要仔细看了！划重点

#### 题材选择策略

+ 优先考虑组合：选择"重生+追妻火葬场+虐恋+爽文+反转"的组合，这是当前最稳妥的爆款公式

+ 避免单一元素：不要只写"重生"或只写"虐恋"，需要多个热门元素组合

+ 考虑细分题材：

+ 黑手党题材：有稳定受众，如《The Birth That Broke the Boss》

+ 末世题材：如《Blocked by Love in the Zombie Apocalypse》

+ 亲情死人文学：男性向的热门题材

#### 情节设计建议

+ 开头3章关键：需要在前3章内快速建立核心冲突（如"男主背叛"、"重生时刻"）

+ 节奏把控：

+ 第1章：冲突爆发（如发现小三、重生时刻）

+ 第3-5章：初步打脸/复仇

+ 第10章左右：重大反转

+ 第20章：第一次大高潮（如"火葬场"开始）

+ 爽点设计：

+ "打脸"场景要具体且有层次感

+ "反转"要合理但出人意料

+ "虐恋"要真实引发读者共情

#### 角色塑造指南

+ 女主设定：

+ "清醒独立"（高频标签）

+ 可考虑"重生后觉醒"的成长弧线

+ 避免过度圣母，要展现"无情"和"复仇"特质

+ 男主设定：

+ 初期"偏心/自私"（让读者产生愤怒）

+ 中期"后悔"（情感转折点）

+ 后期"追妻火葬场"（核心爽点）

+ 反派设定：

+ "小三"要塑造得有特点（不只是工具人）

+ "渣男"要有真实动机（不只是无理取闹）

+ 可考虑"虚伪"、"人渣"等特质

#### 标题与标签策略

+ 标题设计：

+ 参考热门模式："XX, I XXX"（如Grandma Called It, I Dumped Him）

+ 包含核心冲突或反转（如The Birth That Broke the Boss）

+ 长度控制在4-8个单词

+ 标签选择：

+ 必选3-5个核心标签：如"重生,追妻火葬场,虐恋,爽文,反转"

+ 避免过多标签（平台显示最多6-7个）

+ 优先选择高频热门标签，不要过度创新

#### 内容更新与推广

+ 更新频率：保持每天至少1-2章更新，平台明显偏好稳定更新的作品

+ 关键章节：在第10、20、30章等节点设置强情节转折

+ 利用平台机制：研究"起量新书"→"爆量"的转化路径，针对性优化内容

+ 关注榜单：每天关注平台榜单，及时调整创作方向
