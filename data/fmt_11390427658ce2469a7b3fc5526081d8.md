## 二、思路（来自大神~@犄角啊犄角）

### 一、什么是系统文

> 系统文，就是以系统或者类系统元素为主要金手指推进剧情的一类小说题材。

> 主角可以利用系统发布的任务去升级成长或者获得某些奖励。

> “系统”这一设定是自游戏中脱胎而来的，它天然携带游戏的各种属性，如：发布任务、提升等级、积累经验值、升级装备、获得技能点、任务奖励、商店…...

### 二、系统文的优势

> 系统文是众多小说流派中，热度持续比较长久的类型。

> 对于网文萌新来说，系统文是最容易上手的类型，没有之一。

> 这背后的原因很简单：

> ①系统发布任务便于作者把控剧情主线

+ 系统可以推动剧情发展，控制剧情节奏。动机是系统给的，目标也是系统给的。

+ 有目标自然就有冲突，谁阻碍任务完成，谁就是主角解决的矛盾。

+ 当剧情停滞时，可以利用系统任务推动主角行动。只要给主角发布新任务就行了。

> ②系统的设定便于作者补足逻辑漏洞

+ 当出现圆不回来的剧情时，直接搬出系统，通过发布任务与奖励来解决漏洞。

> ③系统可以随时给主角开金手指，便于作者把控爽点

+ 通过给主角开金手指升级打脸虐渣，符合读者对快节奏，多爽点的需求

+ 系统文在和其他元素的融合上，适配度也相当之高。

+ 比如：重生+系统、穿越+系统、穿书+系统、读心术+系统、宫斗宅斗+系统……

+ 但凡你想要通过一个简单可控的、能够引导剧情，给主角开金手指的元素设定，那就一定是系统。

### 三、想写好系统文该从哪入手?

> 在系统文中，通常主角开局会陷入某个致命危机，然后接受系统绑定，系统以奖励利诱主角接受绑定。

> 利诱方式：生命、钱财、权力... (满足主角的欲望，欲望越迫切越好)

> 比如：主角绝症，系统借续命利诱主角执行任务

> 由此可见，系统与主角之间要建立“互相需要”的关系。

> 系统需要借助主角完成`KPl`或达成某种目的，如获取气运，维护世界运行…...

> 主角需要借助系统任务奖励，满足欲望，如维持生命，获得巨额财富，复活，拯救某人 ….

那么在创作时，我们就可以从“主角”“系统”“主角与系统之间的关系”入手构建剧情。

#### 一、从主角的欲望入手构建剧情

> 主角当前面临什么危机?

> 他亟待满足的欲望是什么?(或者说主角最缺什么?)

> 根据主角的欲望，思考主角需要一个什么样的系统(金手指)?

> 关于系统属性常见的有九类，在后文关于系统设定的部分有详细说明。

#### 二、从“主统关系”入手构建剧情

主角与系统之间的关系受三个因素影响。

**【因素一：系统的立场】**

> 系统立场主要分为三种，即“神助攻”、“猪队友”和“无情AI”。

+ ①正面：同盟关系，互利互惠，辅助主角实现愿望

+ ②中立：合作关系，没有感情的任务机器

+ ③反面：敌对关系，压榨奴役主角，获取某样东西(如：气运)

> 根据系统立场，我们可以为系统与主角的相处模式找到多个方向，比如：

+ ①死对头：双方相看两厌，互相算计套路对方

+ ②相爱相杀：表面嫌弃，实则提供各种福利

+ ③相亲相爱：互利互惠的好基友

+ ④保持距离：系统对待宿主完全公事公办

+ ⑤抱大腿：系统为大佬宿主的吉祥物，撒娇卖萌讨好宿主

**【因素二：主角对于系统的接受度】**

根据主角对于系统的接受度，我们在构建剧情时，可以围绕以下问题进行创作。

A.主角接受系统(主角和系统联手可以成为爽点)

> 相处模式：相亲相爱、相爱相杀、抱大腿、保持距离

> 构建此类剧情，你需要思考下面几个问题：

+ ①获得系统前，主角正陷入什么危机?(期待感)

+ ②绑定系统后，主角将获得哪些金手指?(期待感)

+ ③系统发布了什么任务?主角将遇到哪些阻碍?(期待感)

+ ④主角是否接受系统规则与任务要求?(期待感)

+ ⑤主角如何利用金手指完成任务，升级打脸虐渣?(爽点)

+ ⑥任务结束后，主角是否收获了任务奖励?(爽点或反转)

+ (此处如没有收获任务奖励，那么必须有意外所得，意外所得的价值要大于任务奖励的价值)

+ ⑦任务奖励会解决后续剧情中的什么阻碍?(期待感)

+ ⑧未得到的任务奖励是什么?主角为什么一定要获得?(期待感)

B.主角不接受系统(主角与系统拉扯对抗可以成为爽点)

> 相处模式：死对头

> 构建此类剧情，你需要思考下面几个问题：

+ ①获得系统前，主角正陷入什么危机?(期待感)

+ ②绑定系统后，主角将如何忽悠系统，坑骗金手指?(期待感、爽点)

+ ③系统发布了什么任务?主角将遇到哪些阻碍?(期待感)

+ ④主角为脱离系统规则与任务要求做出了哪些计划与行动?(期待感)

+ ⑤主角如何反套路完成任务，升级打脸虐渣?(爽点)

+ ⑥任务结束后，主角是否收获了任务奖励?(爽点或反转)

+ (此处如没有收获任务奖励，那么必须有意外所得，意外所得的价值要大于任务奖励的价值)

+ ⑦任务奖励会解决后续剧情中的什么阻碍?(期待感)

+ ⑧未得到的任务奖励是什么?主角为什么一定要获得?(期待感)

**【因素三：主角和系统各自的性格特质】**

> 在创作时，将系统“拟人化”或“宠物化”处理，通过系统与主角之间的对话，可以增加故事中的萌点、笑点、反差感、CP 感。

> 为系统设置性格标签的方式，与为人物设置性格标签的方式是一样的。系统更集中通过与主角之间的对话体现性格标签。

> 下面列举一些比较常见的“统设”关键词标签，如高冷、话痨、人工智障、阴险、傲娇、弱小呆萌…..

> 注意，在为系统设置标签时，既要考虑系统的立场，又要考虑系统与主角之间的关系。如想要系统与主角之间产生微妙的化学反应 (CP 感),选用“反差强烈”的标签更为合适。

> 比如：弱小没经验的话痨系统×满级大佬的腹黑宿主

> 传统的系统文设定中，我们以一个系统为主，在创新设定中，一个主角可以拥有两个甚至两个以上的系统。两个系统的任务可以是对立的。

> 比如：

> 主角同时绑定大善人系统与大恶人系统，为了完成系统任务，主角可以对任务对象先折磨，后救赎。同时收获两份任务奖励。

#### 三、从系统设定入手构建剧情

完善的系统设定是“系统文”是否好看的关键点。系统设置主要分为属性、规则、奖惩机制、成长升级四个部分。

##### Part1. 为系统设置“金手指”属性

> 系统是作为主角金手指来存在的，创作时你要将“金手指”属性与剧情紧密结合。【下面是九类常用的系统属性】

+ ① 演绎类：扮演剧中角色以维持世界正常运行

+ ② 经营类：神豪系统、基建狂魔系统、神农系统、祖师系统(开山立派，传道授业)、创业系统、

+ ③ 任务类：打卡系统、科举系统、巨星系统、争霸系统、学习强国系统、文娱系统、日行一善系统、

+ ④ 攻略类：攻略反派、攻略高岭之花、攻略主角….

+ ⑤ 技能类：兵王系统、神探系统、考古系统、鉴宝系统、特工系统、美食系统.....

+ ⑥ 求生类：末世求生系统、野外求生系统、远古求生系统、炮灰求生系统…...

+ ⑦ 养成类：养娃系统、巨星养成系统、

+ ⑧ 奖励类：直播系统(弹幕水字数)、卡牌系统、抽奖系统

+ ⑨ 救赎类：反派救赎系统、虐文女主救赎系统、娇妻救赎系统、炮灰救赎系统、女配救赎系统、对照组救赎系统

##### Part2. 为系统建立一套规则

+ ① 正反馈规则(胜利→ 奖励)

+ 地图打卡收获奖励(机缘、秘籍、武器、传承...) 提升好感度收获奖励(金钱)

+ ② 反套路规则(失败→奖励，奖励对主角有绝对吸引力)

+ 战败才能获得奖励

+ (主角拥有绝对武力值，打遍天下无敌手，为获得奖励，被迫开山立宗培养对手) 亏本才能赚钱

+ (主角干啥啥赚钱，始终完不成系统任务，每天都在因得不到奖励哭唧唧，最后哭成首富) 躺平才能提升修为

+ (主角被门派排挤，被迫天天躺平，一步一步躺成了飞升第一人)

+ 在系统规则的限制下，主角会走向下面几个方向：

+ A.主角接受系统要求，完成系统任务，获得奖励，靠奖励封神；

+ B.主角接受系统要求，没能完成系统任务，靠绝对实力封神；

+ C.主角接受系统要求，没能完成系统任务，但阴差阳错封神；

+ D.主角脱离系统要求，反套路完成任务，靠绝对实力封神；

+ E.主角脱离系统要求，被迫完成任务(受对手影响),阴差阳错封神；

##### Part3.为系统设定明确的奖励惩罚机制

> 系统包含奖励机制与惩罚机制。任务成功获得奖励，任务失败获得惩罚。

+ **惩罚机制：**

+ ① 任务失败惩罚，主角任务失败，系统给予惩罚

+ ②违抗规则惩罚，主角不按照系统规则行事，系统给予惩罚

+ ③隐形惩罚，任务完成度与主角生命值息息相关，任务失败就意味着生命值下降

+ **奖励机制：**

+ ① 任务奖励，主角完成任务，系统发放奖励

+ ②意外奖励，主角意外解锁隐藏任务，主角发放奖励

+ ③透支奖励，系统提前透支奖励给主角，主角完成任务后归还

+ **奖励兑换机制：**

> 系统能够提供给主角的好处，这个好处一定能和主线相结合，最好能够还解决未出现或将要出现的困境。

+ ①积分商城(确定性)，设置稀有奖励来调动主角做任务的积极性，激发读者的期待感

+ ②积分抽奖(随机性)

+ 非酋：脸比较黑，手气极差，抽奖必出看起来鸡肋又无用的废品 欧皇：运气好到爆炸，抽奖必出价值极高的稀有物品

+ 用于增加主角本身的反差感，以及主角和系统之间的戏剧性。

+ 比如：

+ 主角能力超强，但非酋(系统瑟瑟发抖，不敢说话)

+ 主角极度不配合系统工作，但欧皇(系统气到自闭，不想说话)

+ ③技能点(提升自身的技能)，比如生命值、体能、敏捷度、运气 ….

##### Part4. 系统要能成长，可升级

> 在主角技能升级的同时，系统也可以升级。

> 系统升级可以开放更多的功能与任务奖励，或者拥有更高的智能。

> 这一设定可以自然拉长主线剧情，能够有效避免主角金手指开得过大，前期无脑爽后期剧情崩盘的情况。

> 以此衍生出的另一种设定就是“主角培养系统”。

> 传统设定是系统辅助主角，培养主角。反套路设定便是主角通过努力做任务，“养大系统”。

> 举例子：

+ 我靠攻略反派养系统、

+ 我靠偷气运养系统、

+ 为了养大系统我成了玄学大师、

+ 我靠当反派救活系统...

### 最后，我们来强调一下系统文的写作注意事项：

> ①开篇不要用主角和系统的对话水字数，容易劝退读者

> **②主角太过容易变强，没有对抗感，读者会感到无趣。不要将系统任务设置的过于简单，不要让对手太弱。**

> ③系统存在感过强，会喧宾夺主。系统只是辅助，主角人物塑造才是重点。

> **④剧情后期，主角要学会脱离系统克服困境，让系统成为点缀，而不是成为主角全部的光环。**

> ⑤系统要有升级变化，一成不变的系统会让读者没有期待感。

> ⑥最终任务奖励一定要诱惑力十足，这样才能让主角行动起来。
