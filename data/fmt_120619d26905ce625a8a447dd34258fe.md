## 免费开源教材与实战手册

1. [AutoGen 官方 GitHub 示例集](https://github.com/microsoft/autogen)：这是最核心的免费实操资料，地址为 `https://github.com/microsoft/autogen`。仓库中包含大量入门级 Python 代码示例，涵盖单智能体创建、多智能体协作、工具调用、AutoGen Studio 配置等基础功能。比如简单的智能体对话案例、代码执行代理案例等，每个示例都有完整注释，可直接复制运行，适合快速上手体验框架用法。

1. 《AutoGen 101 入门手册（社区版）》：CSDN 社区开发者整理的开源入门讲义，内容从框架简介、环境搭建，到 `AssistantAgent` 和 `UserProxyAgent` 的基础使用，再到多智能体团队协作，循序渐进引导入门。手册中包含多个避坑指南，比如 API 密钥配置、模型适配问题等，还附带代码片段和运行结果，可通过 CSDN 博客搜索标题免费获取。

1. 阿里云 AutoGen 架构学习指南：阿里云开发者社区发布的免费开源学习指南，不仅有基础入门内容，还划分了初学者、资深开发者、贡献者三个学习路径。入门部分聚焦 `AssistantAgent` 和 `Team` 的基础用法，搭配架构解析帮助理解核心原理，适合零基础者建立完整的知识框架，可在阿里云开发者社区直接搜索阅读。

## 权威官方文档

1. AutoGen 官方英文教程：官网教程是入门首选，地址为 `https://microsoft.github.io/autogen/docs/tutorial/introduction/`。内容涵盖智能体定义、消息传递机制、组件组合等基础概念，还有简单的代码示例演示单智能体调用。教程语言通俗易懂，适合搭配翻译工具学习，是理解框架设计理念的核心资料。

1. AgentChat 用户指南：作为 AutoGen 的核心模块，其专属指南 `https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/` 详细讲解了高层 API 的使用方法。重点涵盖代理创建、团队协作、流式消息等基础功能，步骤清晰且配有完整代码，是初学者快速实现多智能体应用的关键参考。

1. AutoGen Studio 中文使用指南：地址为 `https://autogen-python.doczh.com/user-guide/autogenstudio-user-guide/usage.html`。该中文文档详细介绍了零代码搭建智能体应用的流程，包括团队构建、组件配置、测试运行等操作，适合不想编写代码的初学者快速体验智能体开发。

## 优质社区实战教程

1. 《AutoGen 快速入门》：CSDN 的免费博客教程，系统梳理了 AutoGen 的核心组件，包括 `AgentChat`、AutoGen Studio 等模块的安装与使用。文中提供了 AutoGen Studio 的启动命令、简单智能体对话的完整代码，还对比了 AutoGen 与 LangChain 等框架的差异，帮助理解框架优势，适合零基础者建立认知。

1. AutoGen GraphFlow 实战教程：掘金和 AI 超元域社区发布的免费教程，聚焦 AutoGen 新增的 `GraphFlow` 技术。教程通过顺序执行翻译系统、并行文章创作系统、旅行规划系统三个案例，演示复杂工作流的搭建，附带详细的代码配置和步骤说明，可帮助初学者掌握多智能体协作的进阶用法。

1. AutoGen Studio 环境安装与操作教程：稀土掘金上的保姆级教程，从 Python 环境准备到 `autogenstudio` 包安装，再到 UI 界面启动和智能体团队创建，每一步都有命令和截图。能解决初学者环境搭建的常见问题，按教程操作可快速跑通第一个零代码智能体应用。
