
# 适合普通人的AI提问框架

> 来源：[https://now.feishu.cn/docx/FLuGdNCaXo19xNxeQq6cCtcxnbd](https://now.feishu.cn/docx/FLuGdNCaXo19xNxeQq6cCtcxnbd)

## 一、最简单实用的框架

### 1. CHAT框架（最好记）

CHAT是Character(角色)、History(背景)、Ambition(目标)和Task(任务)的缩写。一个有效的任务指令可以定义为:定义角色+提供背景信息+描述任务目标+设置输出要求

记忆口诀:四字真言

+ Character - 告诉AI扮演什么角色

+ History - 说明背景情况

+ Ambition - 明确你的目标

+ Task - 描述具体任务

举例:

```
角色:你是一位资深健身教练
背景:我是30岁上班族,久坐办公室,没有运动基础
目标:想要改善体态,缓解腰酸背痛
任务:为我设计一套每天15分钟的办公室拉伸方案
```

### 2. 万能模板:立角色+述问题+定目标+补要求

把一个Prompt拆分成了"立角色+述问题+定目标+补要求"这四个部分,无论面对什么任务,利用这个模版都可以得到一个"及格"的Prompt

## 二、常用经典框架

### 3. BROKE框架（结构化场景）

Background(背景)、Role(角色)、Objectives(目标)、Key Results(关键结果)、Evolve(改进)

适用场景: 需要系统解决问题时

举例:

```
背景:我要准备年度述职报告
角色:你是经验丰富的PPT设计师
目标:制作一份专业的述职PPT
关键结果:需要包含工作成果、数据展示、未来规划三部分
改进:请给我3个不同风格的方案供选择
```

### 4. CRISPE框架（需要专业输出）

Capacity and Role(角色)、Insight(洞察/背景)、Statement(声明/诉求)、Personality(个性/风格)、Experiment(实验/多方案)

适用场景: 需要专业建议或创意内容

举例:

```
角色:你是儿童心理学专家
背景:我5岁的孩子最近不愿意上幼儿园
诉求:帮我分析可能的原因并给出解决方案
风格:用通俗易懂的语言,带点温暖的语气
方案:请提供3种不同的应对策略
```

### 5. TRACE框架（日常沟通）

Task(任务)、Request(请求)、Action(行动)、Context(上下文)、Example(示例)

适用场景: 日常简单任务

举例:

```
任务:写一封请假邮件
请求:语气要礼貌正式
行动:说明请假原因和时间安排
背景:我要参加亲戚婚礼,需要请假2天
示例:参考常规商务邮件格式
```

## 三、进阶技巧

### 6. 添加思维链（复杂问题）

对于Zero-Shot只需要简单的一句"Let's think step by step"就可以让模型一步步思考

使用方法:

+ 简单加一句:"请一步步分析"

+ 或者:"让我们逐步思考这个问题"

举例:

```
我的电脑开机很慢,请帮我分析原因并给出解决方案。
请一步步分析可能的原因,然后针对每个原因给出对应的解决办法。
```

### 7. 提供示例（格式规范）

在Prompt中提供您期望的输出示例,可以让LLM"模仿"我们所要求的规范、格式、概念、文法、语气进行输出

举例:

```
帮我生成产品卖点文案,参考以下格式:
【示例】
核心卖点:轻薄便携
具体描述:仅重800克,厚度1.5cm,单手可握
用户价值:随时随地办公,不受空间限制

请按照这个格式为我的新款耳机生成卖点
```

## 四、普通人快速上手指南

第一步:选择最简单的CHAT框架

+ 初学者建议从CHAT框架开始

+ 记住:角色-背景-目标-任务

第二步:记住三个关键原则

1. 具体明确 - 避免模糊的描述

+ ❌ "写点东西"

+ ✅ "写一篇800字的产品介绍"

1. 提供背景 - 让AI理解上下文

+ ❌ "怎么减肥?"

+ ✅ "我是25岁女生,身高160cm体重65kg,想在3个月内健康减重10斤"

1. 说明输出要求 - 明确期望的格式

+ ❌ "介绍一下Python"

+ ✅ "用3个要点,每个要点100字左右,介绍Python的主要优势"

第三步:遇到复杂问题加一句"请一步步思考"

第四步:不满意就追问优化

+ "请更简洁一些"

+ "能否举个具体例子"

+ "请用更通俗的语言"

## 五、实战模板（直接套用）

```
通用模板:
你是[具体角色],我的情况是[背景描述]。
我想要[明确目标],请帮我[具体任务]。
要求:[格式/风格/长度等]

示例1-学习场景:
你是编程老师,我是零基础学员。
我想学会Python基础,请为我制定一个30天的学习计划。
要求:每天学习时间1小时,包含理论和实践,循序渐进。

示例2-工作场景:
你是会议记录专家,我参加了一场产品讨论会。
我想整理会议纪要,请帮我把以下内容[粘贴内容]整理成规范的会议记录。
要求:包含时间、参会人员、讨论要点、待办事项四部分。

示例3-生活场景:
你是旅行规划师,我想带父母去成都玩3天。
我想体验当地美食和文化,请帮我规划行程。
要求:考虑老人体力,节奏不要太赶,包含交通和餐饮建议。
```

总结: 普通人只需要记住CHAT框架(角色-背景-目标-任务)就能应对80%的场景。遇到复杂问题,加上"请一步步思考",再不满意就追问优化。最重要的是:越具体越好,别怕麻烦!
