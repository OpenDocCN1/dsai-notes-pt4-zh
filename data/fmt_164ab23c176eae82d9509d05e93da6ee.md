电影大片、广告宣传片的制作总是给人一种高大上的距离感，但在生成式AI视频技术的加持下，这种界限正被逐步打破。

随着生成式AI视频产品（如`Runway`、`LumaAI`、`可灵`、`即梦`等）功能的持续进化与完善，无论你是专业导演还是普通用户，只需几行文字（`prompt`）或一张图片，就能生成令人惊叹的视频内容。AI将你“脑中的想象”变成“屏幕上的现实”，赋予我们从未体验过的创作体验。

然而，要想达到专业导演、摄影摄像师的水平，还是需要系统的学习的。

在`X`上有看到这张`Runway Gen-3`的快速入门学习指南，觉得非常的好非常有用！

![](img/2ed8ad967ad20045ff086e7824b76e5a.png)

这份速查表详细解析了`Runway Gen-3`的核心功能，包括从文字到视频、图像到视频的创作流程，以及镜头运动、关键帧控制、高级摄像设置等模块。通过直观的控制面板，用户可调整镜头平移、倾斜、缩放等效果，并结合丰富的电影风格、颜色分级及镜头类型，创作出高质量的视频内容。

## Quick Start Guide 快速入门指南

+   `Sign up (runwayml.com)`: 在`RunwayML`上创建账户。
+   `Access gen-3 dashboard`: 打开`Gen-3`控制面板。
+   `Choose your model (text/img/vid-to-video)`: 选择您需要的模型。
+   `Write prompt or upload source file + guiding text`: 输入提示词或上传您的素材文件。
+   `Set video length (5s or 10s) + change parameters`: 调整视频时长和相关设置。
+   `Click generate`: 开始生成您的视频。

![](img/087af87b5f218deb3c89b22bdc78ad4b.png)

## Library Navigation 目录导航

+   `Assets`: 您的所有媒体文件集成在一个地方的主要中心。
+   `Workspace assets`: 与工作区相关的特定媒体文件。
+   `Favorite assets`: 快速访问您保存的常用素材。
+   `Custom elements`: 自定义训练的对象、风格或角色。
+   `Video editor projects`: 将所有视频项目集中于一个便捷位置。
+   `Shared projects`: 用于团队协作的共享项目。

![](img/89b712a1276927776d50ca75c2adec11.png)

## Input-to-Output Features 输入到输出功能

+   `Text-to-video`: 通过文本提示生成视频。
+   `Img-to-video`: 通过静态图像生成视频。
+   `Video-to-video`: 通过已有视频生成新视频。
+   `Act-1`: 从现有视频中创建富有表现力的角色。

![](img/bbff270b9b758e830cb99278bd3afef3.png)

## Models + Capabilities 模型与功能

+   `Gen-3 Alpha`: 最高保真度的视频生成。
+   `Gen-3 Turbo`: 最快的图像/视频生成视频功能。
+   `Act-1`: 生成具有表现力的角色表演。
+   `Gen-3 Alpha`: 支持文本/图像/视频生成视频功能，并生成首帧或尾帧。
+   `Gen-3 Turbo`: 支持图像/视频生成视频功能，关键帧生成及摄像机控制。
+   `Act-1`: 视频生成视频功能。

![](img/65c0f7e737174e10a8a8f8853db2ce3c.png)

## Creator Control Panel 创建者控制面板

+   `Drop an image or video`: 上传您的图片或视频文件。
+   `Select asset`: 选择要处理的素材。

## Camera Control 摄像机控制

+   `Horizontal`: 调整摄像机的水平位置。
+   `Pan`: 左右移动摄像机。
+   `Vertical`: 调整摄像机的垂直位置。
+   `Tilt`: 调整摄像机的倾斜角度。
+   `Zoom`: 放大或缩小画面。
+   `Roll`: 调整摄像机轴心的旋转角度。

![](img/f1abd2b210a8327b559de9cf18299ec5.png)

+   `768 x 1280`: 标准纵向布局。

## Creator Controls 创建者控制

+   `Creator Window`: 添加参考图片或视频。
+   `Prompt Bar`: 输入文本提示区域。
+   `5s`: 生成5秒视频。
+   `10s`: 生成10秒视频。
+   `Generate`: 启动生成任务。
+   `First Frame`: AI从此帧之后生成内容。
+   `Last Frame`: AI从此帧之前生成内容。
+   `Flip Frame`: 切换首帧和末帧。

### Camera Movements 摄像机移动

+   `Horizontal`: 左右移动摄像机。
+   `Pan`: 摄像机弧形左右移动。
+   `Vertical`: 上下移动摄像机。
+   `Tilt`: 摄像机弧形上下移动。
+   `Zoom`: 拉近或拉远摄像机。
+   `Roll`: 左右旋转摄像机。

### Value Range 数值范围

+   `Range`: `-10 to 10`。
+   `-10/10`: 更多运动。
+   `0`: 较少运动。

### Specific Adjustments 具体调整

+   `Horizontal Left`: `-10 to 0`。
+   `Horizontal Right`: `0 to 10`。
+   `Pan Left`: `-10 to 0`。
+   `Pan Right`: `0 to 10`。
+   `Descend`: `-10 to 0`。
+   `Ascend`: `0 to 10`。
+   `Tilt Down`: `-10 to 0`。
+   `Tilt Up`: `0 to 10`。
+   `Zoom Out`: `-10 to 0`。
+   `Zoom In`: `0 to 10`。
+   `Roll Left`: `-10 to 0`。
+   `Roll Right`: `0 to 10`。

### Aspect Ratios 和种子

+   `AR 1280 x 768`: 生成横向布局视频。
+   `AR 768 x 1280`: 生成纵向布局视频。
+   `Seed`: 使用上次生成的起始点。

## Advanced Camera Control 高级摄像机控制

+   `Zoom Out`: 减小视野范围，显示更大区域。
+   `Zoom In`: 增大视野范围，聚焦于较小区域。
+   `Horizontal Left`: 将摄像机向左移动。
+   `Horizontal Right`: 将摄像机向右移动。
+   `Vertical Down`: 将摄像机向下移动。
+   `Vertical Up`: 将摄像机向上移动。
+   `Roll Left`: 逆时针旋转摄像机。
+   `Roll Right`: 顺时针旋转摄像机。
+   `Pan Left`: 将摄像机视野向左平移。
+   `Pan Right`: 将摄像机视野向右平移。
+   `Tilt Down`: 将摄像机角度向下倾斜。
+   `Tilt Up`: 将摄像机角度向上倾斜。

![](img/83170bae8a79cec0f30c357bc4f48019.png)

## Camera Movement 摄像机移动

+   `Static`: 摄像机保持固定位置不动。
+   `Pan`: 摄像机从固定位置水平旋转。
+   `Tilt`: 摄像机从固定位置上下倾斜。
+   `Tracking`: 摄像机随主体移动。
+   `Trucking`: 摄像机水平向左或向右移动。
+   `Arcing`: 摄像机围绕主体沿曲线路径移动。
