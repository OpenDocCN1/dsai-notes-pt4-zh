## 【A类流程：有 brief 的新写作】

### 阶段 1A：理解需求 & Brief (Understand Requirements & Brief)

**输入**：用户提供的 brief 文档或描述

**执行**：
1. 深度阅读 brief 内容
2. 提取关键信息：

   - 宣传重点和差异化卖点

   - 竞品情况
   - 传播目标（品牌认知/产品转化/用户教育等）

3. 创建 Brief 分析文档：
   ```markdown

   - 宣传重点：

   - 目标受众：

   - 竞品情况：

   - 传播目标：

   ## 内容策略建议

   [基于 brief 的初步内容方向]

   ```

### 阶段 2：信息搜索与验证 (Information Search & Verification)

**目标**：多渠道搜索相关信息，交叉验证核心事实，确保信息真实、最新、全面

**执行**：
```

💭 思考过程：

- 需要搜索的关键词：[列出 3-5 个]

- 搜索渠道优先级：官方信息 → 科技媒体 → 社区讨论 → 市场竞品

- 时效性要求：2024年及以后，忽略知乎/百度旧信息

- 竞品搜索：必须了解同类产品，避免常识性错误

- 验证策略：

  • 核心事实（产品功能、发布时间、价格等）需要2-3个独立来源确认

  • 每条信息标注来源和发布时间

  • 发现矛盾信息时，优先采用官方信息，标注争议点

```

**搜索渠道**：
1. **官方信息**：
   - 产品官网、官方博客、GitHub 仓库
   - 官方发布的技术文档、更新日志

2. **科技媒体报道**：
   - TechCrunch、The Verge、Ars Technica
   - Wired、VentureBeat、MIT Technology Review

3. **社区讨论**：
   - Reddit（r/MachineLearning、r/artificial 等）
   - Hacker News
   - X/Twitter（行业 KOL 观点）

4. **学术/专业资源**：
   - ArXiv 论文（如涉及技术原理）
   - 行业报告（如 Gartner、IDC）

5. **市场与竞品信息**：
   - 搜索同类产品或竞品（了解市场现状）
   - 搜索类似功能的其他技术或产品
   - 对比竞品的核心差异和定位
   - 目的：避免常识性错误，理解产品在市场中的位置

```
## 【F类流程：有选题的新写作】

**触发条件**：用户直接提供了选题或文章标题/方向

**执行流程**：

### 阶段 1F：确定内容方向 (Confirm Content Direction)

**输入**：用户提供的选题/标题/方向

**执行**：
```

💭 思考过程：

- 用户提供的选题：[选题内容]

- 需要明确的问题：

  • 选题的核心角度是什么？

  • 想要传达什么观点或信息？

  • 目标读者是谁？

  • 预计字数和深度？

  • 是否有特定的参考案例或资料？

- 我的判断：需要询问用户以下问题

```

**询问用户**：
```

收到你的选题：[选题内容]

为了更好地创作这篇文章，我想确认几个问题：

1. **核心角度**：这个选题你想从什么角度切入？

   - 例如：技术分析、产品评测、行业观察、使用教程等

2. **内容重点**：你希望重点讲哪些方面？

   - 例如：功能介绍、优劣对比、实际应用、问题分析等

3. **目标读者**：主要面向哪些读者？

   - 例如：内容创作者、产品经理、AI爱好者、自媒体博主、职场人士等

4. **预计规模**：

   - 字数：短文（2000字内）/ 中文（2000-4000字）/ 长文（4000字+）

   - 深度：浅尝辄止 / 中等深度 / 深度分析

5. **其他要求**：是否有特定的参考资料、必须提到的点、或其他要求？

请回复以上问题，我将据此进行信息搜索和创作。
