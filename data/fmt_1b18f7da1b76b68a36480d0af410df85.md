## 传统 chat.completion API 调用方法回顾

```python
from openai import OpenAI

openai_api_key = "YOUR_API_KEY"

base_url = "国内反向代理地址"

# 实例化客户端
client = OpenAI(api_key=openai_api_key, 
                base_url=base_url)

# 调用 GPT-4o-mini 模型
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "user", "content": "你好，好久不见!"}
    ]
)

```
