## 6. SwiGLU (Swish-Gated Linear Unit)

`SwiGLU` 最早是在论文 "GLU Variants Improve Transformer" 中提出的。这项工作探讨了不同的 `GLU` 变体在 `Transformer` 模型中的应用，并展示了 `SwiGLU` 的有效性。`Gated Linear Units` (`GLU`) 是一种由两个线性投影的逐元素乘积组成的组件，其中一个投影首先通过一个 `sigmoid` 函数。测试了 `GLU` 的不同变体在 `Transformer` 序列到序列模型的前馈子层中的表现，发现某些变体在质量上优于通常使用的 `ReLU` 或 `GELU` 激活函数。(实验结论)

`Transformer` 模型交替使用多头注意力和“逐位置前馈网络”（`FFN`）。`FFN` 将一个向量（序列中特定位置的隐藏表示）通过两个学习的线性变换传递，其中激活函数为 `ReLU`。

# https://github.com/meta-llama/llama3/blob/11817d47e1ba7a4959b025eb1ca308572e0e3963/llama/model.py#L193
class FeedForward(nn.Module):
    def __init__(
        self,
        dim: int,
        hidden_dim: int,
        multiple_of: int,
        ffn_dim_multiplier: Optional[float],
    ):
        super().__init__()
        hidden_dim = int(2 * hidden_dim / 3)
        # custom dim factor multiplier
        if ffn_dim_multiplier is not None:
            hidden_dim = int(ffn_dim_multiplier * hidden_dim)
        hidden_dim = multiple_of * ((hidden_dim + multiple_of - 1) // multiple_of)

        self.w1 = ColumnParallelLinear(
            dim, hidden_dim, bias=False, gather_output=False, init_method=lambda x: x
        )
        self.w2 = RowParallelLinear(
            hidden_dim, dim, bias=False, input_is_parallel=True, init_method=lambda x: x
        )
        self.w3 = ColumnParallelLinear(
            dim, hidden_dim, bias=False, gather_output=False, init_method=lambda x: x
        )

    def forward(self, x):
        # in SwiGLU, the Swish function is used to gate the linear function of GLU
        # swish(x) = x * sigmoid(beta * x)
        # when beta = 1, swish function becomes same as the sigmoid linear unit function (SiLU)
        return self.w2(F.silu(self.w1(x)) * self.w3(x))
