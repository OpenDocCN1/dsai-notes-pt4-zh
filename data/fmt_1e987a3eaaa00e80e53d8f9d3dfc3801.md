
# 复刻形象需要做哪些准备工作？

> 来源：[https://aiyanxishe.feishu.cn/docx/Q3podooSrolnRvxU7OsczjUrnHd](https://aiyanxishe.feishu.cn/docx/Q3podooSrolnRvxU7OsczjUrnHd)

如果需要复刻数字人形象，在选定了数字人平台以后，我们就可以做复刻形象的准备工作了。

各个数字人平台对复刻形象的要求大同小异，这里统一对注意事项做一下介绍

## 一、提交原型视频

复刻数字人形象，需要提交一段人物原型视频，包括声音。原型视频的质量对生成的数字人形象的质量影响很大，因此大家一定要让录制的视频尽可能高。尽量找专业的照相馆租用场地进行拍摄，确保原型视频的质量

![](img/e8a6a82b532ce86744c82959a5d3e396.png)

情绪贯穿视频：焦虑，紧张，黑幕，内幕，权威取景：高级餐厅、酒吧、茶室、书房。高级感，职业感、人物状态：煞有介事，爆料感，喝到位了才偷偷告诉你的诉说感，催促用户认真听，句句都是重点。

画面构图：人物头顶在画面3/4的位置，单侧光，目视前方或者侧15度角，塑造出采访感。背景虚化、前景虚化，突出人物。音乐：焦虑，紧张，可怕的内幕消息。

### 原型视频大致有几个要求：

+ 拍摄背景需要绿幕，因为制作数字人时要对人物做抠像处理
+ 不要穿绿色的衣服或戴绿色的饰品，避免抠像时错抠
+ 注意身上不要有反射绿幕的光，避免抠像时错抠
+ 不要戴耳环等边缘锐利的物体，发型也尽量圆润，尽量避免刘海或者毛刺
+ 光线调整好，面部不要有阴影
+ 站姿或坐姿都可以，这个姿势会决定生成的数字人形象的姿势。如果站姿和坐姿都想要，那就要复刻两个形象
+ 录制时不要左顾右盼，可以提前准备一段话，自然的说出来
+ 表情和手势尽量自然，动作幅度不要过大
+ 视频时长大约1分钟-3分钟
+ 提交原型视频到生成数字人形象，大概需要1-10小时。
  + heygen -- 1小时
  + 微软小冰 -- 10小时
  + 其它的不太清楚

## 二、提交原型声音

自己录制一段音频，提前准备好 3-5 分钟左右的文案来说。

确保录制时环境安静，没有杂音。

## 三、获取复刻好的数字人形象和声音

+ 提前注册数字人平台的账号。生成的数字人形象和声音，会在账号中展示和使用。
+ 目前数字人形象和声音，不能跨数字人平台迁移。
+ 后续只需要输入文案内容，就可以让数字人进行口播内容了。
