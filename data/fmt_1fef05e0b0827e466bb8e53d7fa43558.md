
# 🏞️ 图像 Token 化：视觉数据转换的关键技术

> 来源：[https://v11enp9ok1h.feishu.cn/docx/Woj3dVn95o7Toyxm9Ytcx89XnVc](https://v11enp9ok1h.feishu.cn/docx/Woj3dVn95o7Toyxm9Ytcx89XnVc)

+ 随着 `GPT-4o` 的发布，多模态模型真正惠及普罗大众。多模态模型在单一模型中同时处理不同类型的数据，做到不同模态之间的端到端。而多模型模型中的第一步（也是非常重要的一步）往往就是利用不同类型的 `Tokenizer` 把数据各自表达为离散的 `token` 序列。

+ 很多场景下使用离散表示更方便，比如文本中的 `tokens` 都是离散的，`Transformer` 模型也是针对离散数据发明的。

+ 本文介绍图像或视频数据中常用的 token 化模型。这些模型都符合以下结构，主要包含 3 个部分：

![](img/c6178511259b284916d96358263639fd.png)

1. `Encoder`：把原始图片压缩成维度更低的序列向量。常用的模型包括：`CNN`、`Transformer`、`MLP` 等，逻辑上只要模型可以降维、压缩都 ok。

1. `Vector Quantizer (VQ)`：把上面得到的向量对应到 `Codebook` 中的向量，获得在 `Codebook` 中的索引值，这样就可以用离散的序列索引值表示原始的图片。

1. `Decoder`：把序列索引值映射回像素空间，还原出 `RGB` 图像。`Decoder` 一般都使用和 `Encoder` 对称的模型结构。

## 下面具体介绍各种模型

### VQ-VAE

+ [Understanding VQ-VAE (DALLE Explained Pt. 1)](https://mlberkeley.substack.com/p/vq-vae)
+ Code: [https://github.com/apple/ml-4m/blob/main/fourm/vq/vqvae.py](https://github.com/apple/ml-4m/blob/main/fourm/vq/vqvae.py)

`VAE` 使用连续向量表示隐状态，而 `VQ-VAE` (VQ: vector quantization) 使用离散方式表示隐状态。

> 思路其实也挺简单的，`encoder` 的输出还是连续向量，但会维护一个大小为 的 `codebook` （连续向量集合），然后把 `K` 这个连续向量对应到 `codebook` 中离它距离最近的向量 ，对应的序号就变成了离散的隐状态了。传给 `decoder` 的输入就是向量 。

![](img/3d4ee1effd0178cd8528e9d8ecd36541.png)

+ 除了模型参数外，`codebook` 中的向量集合也是通过训练获得的。

![](img/99b6cd9e0588cd6ad2000198aec63094.png)

> 如果一个输入的图片只用 `codebook` 中的一个向量表示的话，表达能力一般是不够的（`decoder` 只能看到 个向量）。但可以让一个输入输出一个向量序列，表达能力就够了。比如把一张图片按横竖线划分为 `32 x 32` 个网格，然后每个网格对应 `codebook` 中的一个向量，这个表达能力就足够了 。

#### 先验分布

### discrete VAE (dVAE)

+ [How is it so good ? (DALLE Explained Pt. 2)](https://mlberkeley.substack.com/p/dalle2)
+ Code: [DALLE-pytorch/dalle_pytorch/dalle_pytorch.py at main · lucidrains/DALLE-pytorch](https://github.com/lucidrains/DALLE-pytorch/blob/main/dalle_pytorch/dalle_pytorch.py#L101)

> `VQ-VAE` 每次只对应到 `Codebook` 中的一个元素，而 `dVAE` 则每次计算与 `Codebook` 各元素的对应分布，然后从此分布中抽取一个 `Codebook` 元素作为 `Decoder` 的输入。

#### 训练 Loss

`dVAE` 的训练 `loss` 和 `VQ-VAE` 类似，只是使用了 KL 距离来让分布尽量分散：

![](img/6ee369acc611888ddfc056747ad5c2a7.png)

其中  利用 `Gumbel-Softmax` 从  中抽样得到，  是个等概率的多项式分布。

+ 上面第一项 `loss` 为 L1，L2 或者 Smooth L1（靠近 0 为 L2，否则为 L1）。

+ 第二项 `loss` 是 `Encoder` 输出的 logits 和 uniform 分布的 KL 距离，示例代码如下。

```
logits = self.encoder(img)
logits = rearrange(logits, 'b k h w -> b (h w) k')
log_qy = F.log_softmax(logits, dim = -1)
log_uniform = torch.log(torch.tensor([1. / num_tokens], device = device))
kl_div = F.kl_div(log_uniform, log_qy, None, None, 'batchmean', log_target = True)
```

#### 感知损失（Perceptual Loss）

+ Perceptual Loss（感知损失）论文笔记 - stardsd
+ `VQGAN` 中实现，参考：[lpips.py](https://github.com/CompVis/taming-transformers/blob/master/taming/modules/losses/lpips.py)

+ 感知损失（Perceptual Loss）是一种用于衡量生成图像质量的损失函数。它与传统的像素级损失（如均方误差，MSE）不同，更关注图像的高层次特征和感知质量。感知损失通常基于预训练的卷积神经网络（CNN），如 `VGG` 网络，用来捕捉图像的内容和样式特征。

**感知损失的工作原理：**

1. **预训练模型的使用**：感知损失利用了在大规模数据集上预训练的卷积神经网络（例如 `VGG-16`）。这些网络在分类任务上已经学到了丰富的图像特征表示。

>

1. **特征提取：**将原始图像和生成图像分别通过预训练模型，提取出不同层次的特征图。这些特征图包含了图像的高层次语义信息。

>

1. **计算损失**：在特征空间中计算原始图像和生成图像之间的差异。感知损失通常由内容损失和样式损失组成：

**感知损失在许多计算机视觉任务中都有广泛应用，包括但不限于：**

+   图像超分辨率：通过感知损失，生成的高分辨率图像可以更好地保持原始图像的细节和感知质量。

+   图像风格迁移：在图像风格迁移（`style transfer`）中，通常会同时使用内容损失和样式损失。内容损失确保生成图像与原始内容图像在内容上相似，而样式损失则确保生成图像与目标样式图像在样式上相似。通过在不同层次上衡量内容和样式的相似度，可以生成具有特定艺术风格的图像。
