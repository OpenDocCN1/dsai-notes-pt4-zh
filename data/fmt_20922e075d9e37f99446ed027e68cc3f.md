
# TensorFlow 入门

> 来源：[https://gotoaiworld.feishu.cn/docx/VxdRdJa63oEpMnxaSXMcOddInYe](https://gotoaiworld.feishu.cn/docx/VxdRdJa63oEpMnxaSXMcOddInYe)

## 免费开源教材

1. 《TensorFlow 2 入门指导手册》：由 xi han li 等人编写的开源手册，专为具备基础机器学习和 Python 知识的开发者设计。基于 TensorFlow 2.0/2.1 版本，聚焦 Keras 和即时执行模式，内容简洁易懂，所有示例代码均可获取，能帮助学习者快速上手 TensorFlow 2 的核心用法，适合快速建立框架使用认知。旧版中文版 PDF 可通过官网链接下载。

1. **《TensorFlow 入门》**：开源免费的入门教材，以 Python 为编程语言载体，内容循序渐进且贴合新手。从 TensorFlow 基本概念、数学运算讲起，逐步延伸到机器学习模型、神经网络，还涵盖 CNN、RNN 等深度学习架构，以及 GPU 编程相关内容。每章都配有对应编程示例，能帮助学习者衔接理论与实操，快速掌握框架核心功能。

1. 《动手学深度学习》（TensorFlow 版）：李沐团队出品的经典开源教材，在线免费阅读地址为 `https://zh-v2.d2l.ai/`。书中专门适配了 TensorFlow 实现代码，内容涵盖深度学习基础、经典模型及实战案例。从张量操作到复杂神经网络搭建，每节都有可直接运行的代码，搭配详细的原理讲解，既适合夯实理论，又能锻炼 TensorFlow 实操能力，是入门深度学习与框架的优质资料。

## 官方核心文档

1. TensorFlow 官方入门文档：官网 `https://www.tensorflow.org/tutorials` 的入门板块，是最权威的入门资料。提供从环境搭建到基础模型实现的完整教程，支持选择 Python 等常用语言，包含张量操作、计算图、模型训练等基础内容，还有图像分类、文本处理等场景化案例。文档会随框架版本更新，能确保学习者获取适配最新版本的用法。

1. TensorFlow Hub 官方文档：地址为 `https://tfhub.dev/`。TensorFlow Hub 是预训练模型仓库，文档中不仅有模型调用教程，还包含如何基于预训练模型进行迁移学习的实操案例。新手可借助现成模型快速完成图像识别、文本分类等任务，降低从零搭建模型的难度，快速感受框架的实用价值。

## 优质免费视频课程

1. CSDN TensorFlow 零基础入门实战教程：由资深 IT 研发专家张子良主讲的免费视频课，总时长 374 分钟，课程分 7 大模块，涵盖 TensorFlow 体系结构、环境部署、计算图、张量等基础内容，还包含手写数字识别、卷积神经网络两个核心实战案例。课程用 Python 编写案例，配套讲解模型可视化和异常处理，适合零基础者系统入门。

1. B 站 “TensorFlow2.0 入门到实战”：站内多位 UP 主（如 “跟李沐学 AI”“黑马程序员”）均有免费课程。以李沐团队的课程为例，内容同步其开源教材，每节视频搭配 TensorFlow 代码实操，从基础语法到项目实战逐步推进，讲解细致，适合偏好视频学习、需要跟着敲代码巩固的学习者。

1. Coursera《TensorFlow for Everyone》：谷歌官方开设的免费旁听课程。课程节奏平缓，从框架基础概念讲起，逐步延伸到简单模型开发，案例贴近实际应用场景。适合利用碎片化时间学习，能帮助学习者在权威指导下建立 TensorFlow 的系统认知。

## 入门实战项目与仓库

1. TensorFlow 官方示例仓库：GitHub 地址 `https://github.com/tensorflow/examples`。包含大量入门级项目，如 MNIST 手写数字识别、简单图像分类器等，代码结构清晰，注释详细。新手可通过模仿代码，掌握从数据预处理、模型搭建到训练评估的完整流程，熟悉 TensorFlow 的核心 API 使用。

1. **MNIST 手写数字识别实战**：这是 TensorFlow 入门经典项目，多个开源仓库（如 GitHub 上 `tensorflow/tutorials` 下的对应案例）都有完整实现。通过该项目可学习数据加载、神经网络构建、模型训练与保存等核心流程，适配 TensorFlow 的基础语法与操作，是新手入门的 “敲门砖”。

1. **中文文本分类小项目**：GitHub 上多个开源入门仓库（如基于 TensorFlow+`jieba` 实现的文本分类项目），适配中文场景。项目涵盖文本分词、词向量转换、模型搭建等 NLP 基础流程，能帮助学习者掌握 TensorFlow 在文本任务中的应用，同时熟悉框架与第三方文本处理库的结合使用。
