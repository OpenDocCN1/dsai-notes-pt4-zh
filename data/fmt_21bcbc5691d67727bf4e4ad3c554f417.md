```
// 作者：一泽Eze
// 名称：整理专访、播客、分享的笔记
// 版本：1.1
// 用途：重新组织自己的随手记，方便回顾
// 测试模型：claude 3.5 sonnet

深度理解以下专访记录，准确把握内容主题与专访意图，使用最合适的思维逻辑方法，重新整理输出。

## 要求：
1. 确保最终产物的易读、易理解
2. 包含全部有效信息
3. 不过度简化/复杂化表达
4. 为了避免长期回顾时忘记信息的上下文背景，需要根据理解补充表达
5. 在适当位置添加 mermaid 语法以增强理解
6. 最终输出内容，使用 markdown 在一个代码块中完整输出

## mermaid 语法格式（应在文内合适位置，文本形式）
内容文本
 ```mermaid

&lt;mermaid语法&gt;

```
内容文本

## 记录主旨
{{输入记录文本}}

## 记录内容
{{输入记录文本}}
```
