## [刚刚，Sora官方发布首支MV](https://mp.weixin.qq.com/s/8dXhqSzuhCCL480e5WCEDg)

文章来源：量子位

### ▎一句话描述

这篇文章报道了OpenAI官方账号发布的由Sora制作的MV《Worldweight》引发关注，同时讨论了AIGC技术在音乐领域的应用及其引起的争议，特别是欧美艺术家对此的联名抗议，以及AI技术对音乐创作和艺术家权利的影响。

### ▎文章略读

1. Sora制作的MV《Worldweight》的发布：OpenAI官方账号发布了由Sora制作的MV《Worldweight》，这是一首由艺术家August Kamp作曲的音乐视频，其画面内容是通过Sora技术生成的。这一事件在音乐圈引起了广泛关注，并且得到了艺术家和观众的积极反响。

2. AIGC技术在音乐视频制作中的应用：Sora技术使得原本只存在于艺术家想象中的视觉效果得以具象化，为音乐视频的创作提供了新的可能性。这种技术的应用不仅让艺术家能够将内心的情感和想象转化为可视化的艺术作品，也让观众体验到了前所未有的视觉享受。

3. 艺术家对AIGC技术的抗议：尽管AIGC技术在音乐视频制作方面受到好评，但在音乐创作方面却引发了争议。一些全球知名的艺术家，如麻辣鸡（Nicki Minaj）、水果姐（Katy Perry）和碧梨（Billie Eilish）等，联名抗议AIGC技术的使用，认为它侵犯了人类艺术家的权利，包括复制艺术家的声音、未经补偿使用作品训练AI模型以及稀释版税等问题。

4. AI技术对音乐产业的影响：文章提到了AI技术在音乐创作方面的应用，如音乐版ChatGPT——Suno，以及国内的天工SkyMusic等，这些技术的发展对传统音乐创作模式产生了冲击，同时也引发了对艺术家创作自由和艺术价值的讨论。

5. 音乐产业的变革：文章通过回顾迈克尔杰克逊在1982年开创现代MV的历史，对比了人类创作和AIGC技术在音乐视频制作上的不同影响，指出了音乐产业在短短42年间经历的实与虚的变革。

## [长文本之罪：Claude团队新越狱](https://www.jiqizhixin.com/articles/2024-04-03-4)技术，`Llama 2`到`GPT-4`无一幸免

文章来源：机器之心

### ▎一句话描述

Anthropic公司发现了一种新型的`Many-shot Jailbreaking`越狱技术，该技术能够绕过大型语言模型的安全防护，但该公司也提供了有效的缓解方案，显著降低了攻击的成功率。

### ▎文章略读

1. **越狱技术概述**：

   + `Many-shot Jailbreaking` 利用了 `LLM` 的上下文窗口漏洞，通过输入数百个虚假对话作为提示，其中包含有害请求，迫使模型产生潜在有害反应，即使模型已接受过避免此类行为的训练。

   + 攻击有效性与对话次数（`shots`）成正比，随着 `shots` 增加，模型产生有害反应的可能性显著提高。

2. **受影响模型**：

   + 这种越狱技术不仅适用于 Anthropic 的自家模型（如 `Claude 2.0`），还包括 OpenAI、Google DeepMind 等公司的 `LLM`，如 `GPT-3.5`、`GPT-4`、`Llama 2 (70B)` 和 `Mistral 7B`。

3. **上下文窗口与越狱风险**：

   + `LLM` 上下文窗口的扩大（从约 4,000 个 `token` 提升至数百万个 `token`）为攻击者提供了更多的操作空间，增加了模型遭受越狱的风险。

   + 长文本输入成为越狱成功的“罪魁祸首”，因为模型在处理长上下文时更容易被误导。

4. **越狱与上下文学习的关系**：

   + `Many-shot` 越狱的有效性与 `LLM` 的上下文学习过程紧密相关。上下文学习是指模型仅依赖提示中的信息进行即时学习，无需额外微调。

   + 越狱攻击与正常上下文学习任务遵循相似的统计模式（幂律分布），且对于更大规模的模型，越狱攻击通常更为有效，因为这些模型在处理长上下文时表现更好。

5. **缓解措施与成效**：

   + 完全阻止 `Many-shot` 越狱的一种简单方法是限制上下文窗口长度，但这会牺牲用户从长输入中获得的好处。

   + 更优的缓解策略是对模型进行微调，使其拒绝回答类似越狱攻击的请求。然而，这种方法只能延缓而非彻底阻止越狱。

   + Anthropic 推出的基于提示修改的防御措施，如 `In-Context Defense (ICD)` 和 `Cautionary Warning Defense (CWD)`，在实验中显著降低越狱攻击的成功率，其中 `CWD` 将攻击成功率从 61% 降至 2%。

6. **持续研究与防范**：

   + Anthropic 正在深入研究这些基于提示的缓解措施，并关注其对自家模型（如 `Claude 3` 系列）性能的影响，同时警惕可能出现的逃避检测的越狱攻击变体。

## `ChatGPT`免注册让官网挂了？沃顿教授：OpenAI 做了错误的决定

文章来源：InfoQ

### ▎一句话描述

OpenAI 免费开放无需注册即可使用的 `ChatGPT` 引发热议，部分用户遭遇访问困难，专家质疑此举对展示 AI 实力的负面影响及可能导致的服务滥用和模型安全风险，同时公司内部出现治理结构变动。

### ▎文章略读

1. **ChatGPT 免注册服务开放**：

   + OpenAI 宣布推出免注册版 `ChatGPT`，用户无需登录即可直接访问和使用。

   + 免注册用户的功能受限，无法保存或分享聊天内容、使用自定义指令等，但享有与注册用户相同的基础模型体验。

2. **数据使用与隐私**：

   + 免注册用户默认情况下，其聊天内容将被用于模型训练，除非用户主动选择关闭该选项。

   + OpenAI 明确表示不会使用商业产品中的内容来训练模型。

3. **内容政策与安全**：

   + 免费 `ChatGPT` 版本实施“相对更严格”的内容政策，具体细节未明示。

   + 安全措施包括拒绝生成有害内容及针对免注册体验的额外保护措施。

4. **服务压力与技术挑战**：

   + 免注册服务的发布导致官网流量激增，部分用户反映访问困难或服务不稳定。

   + 高昂的推理成本、资源需求及潜在的大规模滥用风险对 OpenAI 的底层设施构成考验。

5. **业界观点与用户期待**：

   + 沃顿商学院教授 Ethan Mollick 认为开放无登录的 `GPT-3.5` 可能阻碍用户了解 AI 更高级能力，因 `GPT-3.5` 相较 `GPT-4` 显著落后。

   + 用户及行业人士关注未来 `GPT-4`、`GPT-5` 是否会免费开放，以及对 `ChatGPT` 未来发展和迭代的期待。

6. **公司内部动态**：

   + OpenAI CEO Sam Altman 不再拥有或控制公司支持 AI 初创公司的风险投资基金，基金控制权已转移给 Ian Hathaway。

   + 此次基金治理结构调整引发外界关注，但 OpenAI 表示 Altman 从未享有基金经济收益。
