## 课程大纲

面向非技术背景人员、无算法背景的技术人员和任何对大模型感兴趣的初学者，使用大模型能力的初级认证，主要考核考生对大模型领域知识的整体掌控情况。

通过该技术认证可以有效证明该认证人员具备以下能力：

+ 了解大模型的基本概念和工作原理，具备和大模型相关技术人员沟通协作的能力。
+ 了解改进大模型应用效果的手段，包括但不限于提示词工程、RAG、微调等。
+ 了解大模型应用的安全合规风险来源与治理防控方法。
+ 能够思考如何使用大模型解决实际业务问题，包括但不限于批量文本分析、信息提取、内容生成、翻译、图表分析等。
+ 能够使用大模型构建面向私有领域知识的问答机器人。

### 课程内容

第一章：大模型概念 (占比 18%)

+ **1.1 人工智能与大模型基础** 基本概念技术发展历程

+ **1.2 大模型的工作方式** 基础架构与工作原理

+ **1.3 大模型的常见应用场景** 批量文本分析、信息提取、内容生成、翻译、图表分析等

第二章：提示词工程 (占比 20%)

+ **2.1 提示词基础与技巧** 学习并掌握有效的提示词编写方法

+ **2.2 提示词框架** 了解结构化的提示词框架，提升输出质量

+ **2.3 业务应用** 学习如何使用提示词协助完成具体业务工作

第三章：增强大模型应用的能力 (占比 20%)

+ **3.1 大模型API技术** 借助 API 让大模型自动化地处理任务

+ **3.2 大模型插件** 插件的工作原理了解百炼大模型服务平台支持的插件

+ **3.3 RAG（检索增强生成）** RAG 的工作原理

+ 3.4 如何通过 RAG 增强大模型在垂直领域的表现

+ 3.5 改进 RAG 应用效果的方法

第四章：大模型 Agent (占比 14%)

+ **4.1 Agent 原理与结构** 了解大模型 Agent 的基本构成

+ 4.2 ModelScope-AgentModelScope-Agent 的原理与结构介绍

+ 4.3 Multi-Agent 系统了解 Multi-Agent 系统的概念与项目案例

+ **4.4 Agent 系统优化** 学习如何不断完善大模型 Agent 系统

第五章：大模型微调 (占比 12%)

+ **5.1 微调的概念与作用** 了解什么是微调及其在优化模型中的角色

+ **5.2 微调的关键与适用场景** 判断何时需要使用微调技术

+ **5.3 微调的流程和原理** 掌握微调的基本步骤和技术原理

第六章：大模型应用的安全合规 (占比 10%)

+ **6.1 大模型的风险识别** 了解大模型应用中存在的潜在风险及相关案例

+ **6.2 风险治理** 学习大模型风险的治理建议与防控方法

+ **6.3 应用备案** 了解大模型应用的备案要求与流程

第七章：拓展与总结 (占比 6%)

+ **7.1 多模态大模型** 多模态大模型的概念、应用与体验
