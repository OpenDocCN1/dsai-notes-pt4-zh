## Nano Banana 分镜制作核心方法

创作优秀的分镜，需要一套系统性的**方法论**，这套方法论的核心在于对提示词进行结构化。通过将画面拆解成不同的层次，我们可以更精准地控制AI生成的每一帧画面，实现从宏观构图到微观细节的全方位把控。

### 结构化提示词方法论

这套方法论的核心是“**三层设计**”，即：前景、中景、背景。

+   **前景（Foreground）：** 画面最前方的元素，通常是主体人物的局部特写或能增强景深感的道具。前景能有效引导观众的视线，为画面增添层次感。

+   **中景（Midground）：** 这是画面的“故事核心”。主体人物及其主要动作都发生在这个区域，是叙事的主体。

+   **背景（Background）：** 提供环境氛围和空间感，让画面更具纵深。背景应与前景、中景相互呼应，共同构建完整的故事世界。

#### 完整提示词模板

为了确保每次创作都有据可依，我们推荐使用以下完整的提示词模板。这个模板不仅包含三层结构，还加入了光影、风格等关键要素，让生成的图像更具电影感。

```
[镜头类型][焦段]mm镜头，[机位描述]。
前景：[前景元素描述]
中景：[主体人物/动作描述]  
背景：[环境/氛围描述]
[质感风格]，[光影效果]，[色彩基调]。
保持[需要保持一致的元素]与参考图完全一致。
```

#### 实用模板示例

以下是一些经过实战验证的模板，你可以直接拿来使用，也可以在此基础上进行修改。

**基础分镜模板：** 适用于建立一个场景的基础镜头。

```
中景，85mm镜头，平视角度。
前景：虚化的金属栏杆
中景：宇航员站在平台上，望向远方
背景：深邃的太空和远处的星云
电影质感，戏剧性侧光，冷色调。
保持人物面部、服装细节与参考图完全一致。
```

**环境切换模板：** 当需要将同一人物放到新环境中时，这个模板能帮助你快速转换。

```
广角24mm镜头，低角度仰拍。
保持宇航员角色不变，场景更换为火星峡谷。
宇航员正在攀爬岩壁，表情专注。
环境：黄昏时分，红色沙尘飞扬，双月悬空。
保持角色面部特征、宇航服所有细节完全一致。
```

**视角变换模板：** 改变观察角度，为故事增添更多视角。

```
过肩镜头，50mm焦段。
前景：宇航员肩膀和头盔背面（虚化）
中景：前方的探测设备和地形
背景：与参考图相同的银河背景
保持原始光线方向和环境特征不变。
```

## 五大核心技巧

除了结构化的提示词，掌握以下五个核心技巧，将大大提升你的分镜制作效率和质量。

### 技巧1：建立"锚点"系统

分镜制作最容易遇到的问题是角色的一致性。为了避免人**物在**不同镜头中“变脸”，你需要建立一个“锚点”系统。

+   **创建一张高质量基础图**，作为你所有分镜的**参照标准**。这张图应该包含你角色的核心特征，如面部、服装、配饰等。

+   在每个提示词中，都包含一个特定的“身份锚点词”，比如“宇航员”、“女特工”、“机器人”。这个词就像一个标签，能帮助AI始终识别并锁定你的角色。

+   **建立一份“项目圣经”**，将角色的所有硬性特征以条款化的形式记录下来，例如：“面部：左眼角有一道疤痕”，“服装：蓝色宇航服，胸口有红色徽章”。

**关键操作：** 永远从你的**锚点图**出发去生成新镜头，而不是从已生成的图继续迭代。这能有效避免因多次迭代而导致的特征偏离。

---

### 技巧2：人物不变，环境切换

这个技巧的核心在于**明确区分“不变量”和“变量”**。

+   **不变量（角色特征）：** 身份锚点词必须保留，确保人物身份的延续性。

+   **变量（场景、动作）：** 针对新环境和新动作进行细致描述。动作描述要具体、可量化，例如，“缓缓抬头”、“紧握拳头”，而不是笼统的“动作”。

+   在提示词的结尾，加上“**一致性约束语句**”，明确告诉AI哪些元素必须与原始锚点图保持一致。

**提示词结构**： `[身份锚点] + [新环境描述] + [具体动作] + [一致性约束]`

---

### 技巧3：环境不变，视角变换

当你需要在一个固定场景中展现不同视角时，这个技巧尤其重要。

+   **锁定关键背景元素**，如“银河”、“月球表面”等，确保背景的统一性。

+   **使用专业的摄影术语**来描述视角和机位，如“过肩镜头”、“俯拍”、“仰拍”，这能让AI更准确地理解你的意图。

+   **明确焦段参数**（如24mm、50mm、85mm），不同的焦段会产生不同的视觉效果。

+   **24mm：** 广角镜头，适合宏大场景，能带来强烈的视觉冲击。

+   **35mm：** 接近人眼视角，适合环境人像，能很好地展现人物与环境的关系。

+   **50mm：** 标准镜头，透视自然，是常用的人像焦段。

+   **85mm：** 长焦镜头，适合人物特写，能很好地虚化背景，突出主体。

---

### 技巧4：精准编辑（逐步修改）

“**小步迭代**”是这个技巧的核心思想。不要试图一次性修改多个元素，这很容易导致画面崩坏。

+   采用"小步迭代法"：每次只改一个元素

+   使用明确动词："移除"、"替换"、"添加"

+   3-4轮编辑后必须返回锚点图，避免累积误差

+   分层编辑：背景层→动作层→光影层

**防止退化策略**：

始终回到你的**锚点图**，进行新的编辑。而不是从“编辑1”的基础上继续“编辑2”。在连续进行3-4轮编辑后，务必返回锚点图重新开始，避免累积误差。

```
锚点图 → 编辑1
锚点图 → 编辑2  ✅
而非：编辑1 → 编辑2 → 编辑3 ❌
```

---

### 技巧5：多图融合

这个技巧能让你充分利用已有素材，创作出意想不到的新画面。

+   **明确每个元素的来源。** 比如，“将图1的人物”融合到“图2的环境”中。

+   **详细描述融合方式。** 告诉AI如何将两个元素自然地融合在一起，比如“匹配透视”、“统一光源”、“在接触面生成自然阴影”。

+   **关注融合细节。** 确保新生成的图像在景深、色彩、光线方向等方面都保持一致，让融合看起来毫无PS痕迹。

**融合提示词模板**：

```
将图1中的[主体]融合到图2的[环境]中。
融合要求：
- 匹配环境的透视和光线方向
- 在接触面生成自然阴影
- 保持各元素的材质特征
- [主体]的所有细节保持不变
```

## 核心原则总结

掌握以上技巧，并遵循以下三个核心原则，你的分镜制作之旅将会更加顺畅。

+   **锚点原则：** 永远从原始锚点图生成新镜头，避免串行生成。

+   **身份锁定：** 每个提示词都要包含你的“身份锚点词”，确保角色一致性。

+   **分层控制：** 明确哪些是“不变量”，哪些是“变量”，并分层进行控制。

+   **具体描述：** 避免抽象词语，使用具体的动词和细节描述。

+   **质量控制：** 每生成一个镜头，都生成2-3个版本进行对比选择，并适时返回锚点图进行重置。
