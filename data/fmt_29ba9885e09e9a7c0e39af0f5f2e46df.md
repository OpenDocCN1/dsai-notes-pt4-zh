
# 当AI有了记忆力，变化正在悄悄发生，效率高的人会越来越快

> 来源：[https://my.feishu.cn/docx/GLGjdg6exoPWIcxJUFzc56TGnFe](https://my.feishu.cn/docx/GLGjdg6exoPWIcxJUFzc56TGnFe)

老金我最近复盘自己的工作时间。

发现每天被各种邮件、会议纪要、查资料这些破事儿占了至少一半的时间。

感觉自己不像个搞科技的，倒像个不知疲倦的信息搬运工。

最可怕的是，我居然已经习惯了。甚至觉得忙就等于充实。

转折点发生在我上次直播前，我突然发现我跟Chatgpt说话时候，它居然能想起来我很早之前说过的事儿。

这文档写的立马就变味儿了，关联前提和不关联前提，会导致两种不同的发展方向。

比如，我什么上下文也没有，就问Chatgpt，我适合怎么挣钱？

它的答复是这样的，完全基于我以往输入的信息进行有效推理。

![](img/5108255b542683a36baa6af0f1cb03d2.png)

从那天起，老金我换了个活法。

开始研究怎么让一个“有记性”的AI，真正成为我的第二大脑。

今天，我就把这套能彻底改变工作流的指令分享给家人们。

不过，老金我得先跟家人们交个底。

这些玩法要想效果拉满，最好是用带记忆功能的AI，否则和之前没区别，你需要把提示词+上下文一起输入进去，效率只能说一般般。

这玩意儿能记住你的习惯和偏好，用起来才叫一个丝滑！

目前我稳定用到的主要是ChatGPT的记忆功能。

听说谷歌的Gemini也将在今年9月全面开放。

以下是常规工作时所用到的一些通用类的提示词。

## 1、邮件分类与摘要

面对每日涌入的繁杂邮件，快速抓住重点至关重要。你可以让AI成为你的邮件预处理器。

此项若是ChatGPT或Gemini，可以直接链接Gmail使用，连发送都不需要手动操作了。

```
请扮演我的私人助理。扫描我收件箱里所有未读邮件，根据发件人、主题和内容，将它们分为紧急处理、需要回复、普通阅览和推广信息四类。然后，为紧急处理和需要回复的邮件各生成一份内容摘要和回复要点草稿。
```

## 2、会议信息精炼

冗长的会议过后，从大量对话中提取有效信息往往耗时耗力。AI可以快速完成这项工作。

这里可以使用【通义，豆包】等可以免费进行录音（但涉及数据保密的情况，请自行查找其他语音转文字工具）。

```
这是我们团队会议的录音转录文本。请从中提取出所有的关键决策、分配给每个人的具体行动项（Action Items），以及明确的截止日期（Deadline）。最后，用不超过300字的篇幅总结整个会议的核心内容，风格要求简洁、专业。
```

## 3、个性化学习路径规划

当你想进入一个新领域时，海量的信息常让人无从下手。AI可以为你绘制一张清晰的学习地图。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
我想学习[输入你想学的主题，例如：量化交易]。假设我是一个完全没有基础的初学者，请为我制定一个为期30天的学习计划，每天投入1小时。计划需要包括每天要学习的核心概念、推荐的免费学习资源（如权威文章或视频链接），以及一个简单的实践任务来巩固所学。
```

## 4、多维度文案创想

好的产品需要好的表达，但灵感并非时刻在线。AI可以从多个角度出发，提供丰富的创意起点。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
我的产品是[简单描述你的产品，例如：一款帮助用户记录每日心情的App]，目标用户是[描述你的用户，例如：20-30岁的年轻职场人]。请为我生成5个不同风格的社交媒体推广文案草稿，风格分别侧重于：1. 情感共鸣；2. 实用价值；3. 幽默趣味；4. 故事叙述；5. 挑战悬念。
```

## 5、辅助复杂决策

在关键选择面前，人容易受到情绪和偏见的影响。AI可以提供一个相对客观、基于逻辑的分析框架。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
我正在进行一项决策，有两个备选方案。方案A是[描述方案A]，其优缺点分别是[A的优缺点]。方案B是[描述方案B]，其优缺点分别是[B的优缺点]。请你扮演一位资深战略顾问，从成本、风险、长期收益和实施难度四个维度，为我分析这两个方案，并给出一个基于分析的建议和理由。
```

## 6、快速解读长篇报告

在有限的时间内吸收一份几十页的行业报告是一项挑战。AI可以成为你的信息压缩机。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
这是一份关于[报告主题]的文档。请为我提炼出这份报告的核心观点、关键数据、市场趋势预测以及它对我们行业可能产生的影响。最后，请生成一个可以在5分钟内完成口头汇报的要点大纲。
```

## 7、代码审查与调试

程序员在解决代码错误时，有时会陷入思维盲区。AI可以提供一个全新的视角来发现问题。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

也可以替换下关键词，让它来审核文字内容或报告内容，甚至是合同内容（合同需要慎重，得人工二审）。

```
我写了下面这段[语言，例如：Python]代码，它的预期功能是[代码目的]。但现在遇到了[错误信息]这个错误。请帮我检查代码，找出潜在的问题根源，并提供修改后的代码方案，同时附上关于错误原因和修改逻辑的简要解释。
```

## 8、结构化头脑风暴

自由发散的讨论有时会效率低下。AI可以引入创新框架，引导团队进行更具结构性的思考。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
我们是一个[你的团队类型，例如：在线教育平台]，计划为[你的目标，例如：新学期]策划一个线上活动来吸引用户。请你使用逆向思维、跨界结合和极端用户场景这三种创新思维方法，为我们提供10个具备可行性的活动创意。
```

## 9、定制化行程规划

规划一次旅行涉及大量琐碎信息的整合。AI可以根据你的个性化需求，生成一份井井有条的方案。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
我计划在[日期]与家人（2位成人，1位5岁儿童）前往[地点]旅行，为期[天数]天。我们的预算是[金额]。我们的偏好是自然风光和亲子互动，希望避开过度商业化的景点。请为我设计一份详细的行程表，包括每日的行程安排、特色餐厅推荐、交通建议和住宿区域分析。
```

## 10、引导每日复盘

成长源于有效的反思，但我们常常不知道该如何开始。AI可以扮演一个客观的教练，引导你进行深度复盘。

基于以往的记忆，若有关联项，会给你和你涉及更紧密的答案。

```
我今天的日程安排是[你的日程]，我完成的主要工作任务有[你完成的工作]。请扮演一位个人成长教练，根据我的输入，向我提出5个引导性问题，帮助我复盘今天的工作，发现亮点、不足以及明天可以改进之处。
```

## 老金有话说

家人们，这些指令的背后，其实是一种工作方式的转变。

它要求我们从一个模糊的想法，到一个清晰的问题。这个转变，本身就是一种宝贵的思维训练。

老金我最大的感受是，当咱们熟练地将重复性的脑力劳动外包给AI时，我们并没有变得懒惰。

反而为自己赢得了最稀缺的资源：**专注力与深度思考的时间。**

人类发明工具，是为了解放双手。

而我们今天驯服AI，是为了解放我们的大脑。

真正的进化，不在于我们创造的工具本身有多强大。

而在于，当我们被工具解放之后，我们选择去思考什么样的新问题。

AI负责搞定怎么干。

而咱们，就能腾出空来想想，到底为啥要干。
