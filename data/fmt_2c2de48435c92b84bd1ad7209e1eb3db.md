
Op[enClaw 是](https://github.com/openclaw/openclaw)一个开源的个人 AI 助手平台，支持多种操作系统和部署方式。本章将详细介绍如何在不同环境下安装和部署 OpenClaw，帮助你快速搭建自己的 AI 助手系统。citation

## 4.1 环境准备

在开始安装 OpenClaw 之前，需要确保系统满足基本要求并安装必要的依赖软件。OpenClaw 的架构包括网关服务器（Gateway）、技能系统（Skills）和多个通信渠道，因此环境准备至关重要。

### 4.1.1 系统要求

OpenClaw 对硬件和操作系统有一定的要求，以确保系统能够稳定运行：

**硬件要求**

+   CPU: 双核及以上处理器
+   内存： 最低 2GB RAM（推荐 4GB 及以上）
+   存储空间： 至少 5GB 可用磁盘空间
+   网络： 稳定的互联网连接

**操作系统支持**

+   **Linux**: Ubuntu 20.04+, Debian 11+, CentOS 8+, Fedora 35+ 等主流发行版
+   **macOS**: macOS 11 (Big Sur) 及更高版本，支持 Intel 和 Apple Silicon (M1/M2/M3/M4) 芯片
+   **Windows**: Windows 10/11，强烈建议使用 WSL2 (Win[dows Sub](https://docs.openclaw.ai/install)system for Linux 2) 运行 OpenClaw citation

**特别说明**： 如果你使用的是 VPS 或云服务器，且实例内存小于 2GB，建议分配 4G[B 交换文件（s](https://blog.promptlayer.com/how-to-install-openclaw-step-by-step-guide-formerly-clawdbot-moltbot/)wap file）以避免在 `npm` 安装阶段出现内存不足的问题。citation

### 4.1.2 依赖软件安装

OpenClaw 依赖于 Node.js 生态系统，因此需要安装以下核心软件：

**Node.js 22+**

Node.js 是 OpenClaw 运行的基础环境。安装脚本会自动检测并安装缺失的 Node.js 版本，但你也可以手动安装：

```
# macOS (使用 Homebrew)
brew install node@22

# Linux (使用 NodeSource)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node --version
npm --version
```

**`pnpm` 包管理器**

OpenClaw 使用 `pnpm` 作为包管理器，它比 `npm` 更快且更节省磁盘空间：

```
# 全局安装 pnpm
npm install -g pnpm

# 验证安装
pnpm --version
```

**Git 版本控制**

如果你计划从 GitHub 克隆源代码或参与开发，需要安装 Git:

```
# macOS
brew install git

# Linux (Debian/Ubuntu)
sudo apt update &amp;&amp; sudo apt install git -y

# Windows
# 从 https://git-scm.com 下载安装包
```

**构建工具（可选但推荐）**

某些依赖包（如 `sharp`、`node-llama-cpp`）需要本地编译，因此建议安装构建工具：

```
# macOS
xcode-select --install
npm install -g node-gyp

# Linux (Debian/Ubuntu)
sudo apt install build-essential python3 -y

# Windows (在管理员权限的 PowerShell 中)
npm install -g windows-build-tools
```

如果[遇到 “shar](https://docs.openclaw.ai/install)p: Please add `node-gyp` to your dependencies” 错误，安装 Xcode 命令行工具和 `node-gyp` 即可解决。citation

### 4.1.3 API Key 获取

OpenClaw 需要连接大语言模型（LLM）才能正常工作。你需要至少获取一个 AI 服务提供商的 API Key:

**支持的 AI 服务提供商**

+   **OpenAI**: 支持 GPT-4、GPT-4 Turbo、GPT-3.5 等模型
+   **Anthropic**: 支持 Claude 3.5 Sonnet、Claude 3 Opus 等模型
+   **Google AI**: 支持 Gemini Pro、Gemini Ultra 等模型
+   **本地模型**： 通过 Ollama 运行本地 LLM（无需 API Key）

获取 OpenAI API Key

1.  访问 `https://platform.openai.com`
1.  注册或登录账户
1.  进入 API Keys 页面
1.  点击 “Create new secret key”
1.  复制并妥善保存生成的 API Key（格式： sk-……）

获取 Anthropic API Key

1.  访问 `https://console.anthropic.com`
1.  注册或登录账户
1.  进入 API Keys 设置
1.  创建新的 API Key
1.  复制并保存（格式： sk-ant-……）

**使用本地模型（Ollama）**

如果你想避免 API 费用或需要完全离线运行，可以使用 Ollama 运行本地模型：

```
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 下载模型(例如 llama3)
ollama pull llama3

# 验证模型运行
ollama run llama3
```

Ollama 甚至可以自动安装和配置 OpenCl[aw，只需一条命](https://ollama.com/blog/openclaw-tutorial)令即可完成整个设置流程。citation

**安全提示**： API Key 具有[高度敏感性，请勿](https://blog.promptlayer.com/how-to-install-openclaw-step-by-step-guide-formerly-clawdbot-moltbot/)将其提交到代码仓库或公开分享。OpenClaw 会将配置存储在 `~/.openclaw` 目录中，请像对待密码一样保护这个目录。citation

## 4.2 本地安装部署

OpenClaw 提供了三种主要的安装方式：安装脚本（推荐）、`npm` 全局安装、从源代码构建。安装脚本是最简单快捷的方式，适合大多数用户。

### 4.2.1 Windows 系统安装

在 [Windows ](https://docs.openclaw.ai/install)上运行 OpenClaw，强烈建议使用 WSL2(Windows Subsystem for Linux 2)，因为 OpenClaw 的许多功能在 Linux 环境下表现更好，且安全性更高。citation

**步骤 1: 安装 WSL2**

打开 PowerShell（管理员权限）并执行：

```
# 启用 WSL 功能
wsl --install

# 重启计算机
```

重启后，WSL2 会自动安装 Ubuntu 作为默认 Linux 发行版。首次启动时需要创建用户名和密码。

步骤 2: 在 WSL2 中安装 OpenClaw

打开 Ubuntu 终端，执行安装脚本：

```
# 使用官方安装脚本(推荐)
curl -fsSL https://openclaw.ai/install.sh | bash

# 或者使用 npm 全局安装
npm install -g openclaw
pnpm approve-builds -g  # 批准 openclaw、node-llama-cpp、sharp 等包
```

**步骤 3: 运行配置向导**

安装完成后，运行配置向导进行初始设置：

```
openclaw onboard
```

配置向导会引导你完成以下设置：

+   选择 AI 模型提供商并输入 API Key
+   配置工作空间目录（默认： `~/openclaw/workspace`）
+   选择通信渠道（Telegram、WhatsApp、Web UI 等）
+   安装初始技能包

**步骤 4: 启动网关服务**

配置完成后，启动 OpenClaw 网关：

```
# 启动网关(默认端口 18789)
openclaw gateway start

# 检查网关状态
openclaw gateway status

# 查看实时日志
openclaw logs --follow
```

**WSL2 特别优化**

为了提高安全性，建议创建专用的 Ubuntu WSL 发行版来隔离 OpenClaw:

```
# 导出默认 Ubuntu
wsl --export Ubuntu ubuntu-base.tar

# 导入为新的发行版
wsl --import OpenClawUbuntu C:\WSL\OpenClawUbuntu ubuntu-base.tar

# 在新发行版中安装 OpenClaw
wsl -d OpenClawUbuntu
```

这样可以减少 Windows 与 [WSL 之间的交](https://www.youtube.com/watch?v=uqc_54fbsPU)互风险，提高系统安全性。citation

### 4.2.2 macOS 系统安装

macOS 是 OpenClaw 支持最完善的平台之一，安装过程简单直接。支持 Intel 芯片和 Apple Silicon(M1/M2/M3/M4)。

步骤 1: 安装 Homebrew（如果尚未安装）

Homebrew 是 macOS 上最流行的包管理器：

```
/bin/bash -c &quot;$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)&quot;
```

**步骤 2: 安装依赖**

```
# 安装 Node.js 22+
brew install node@22

# 安装 pnpm
npm install -g pnpm

# 安装构建工具
xcode-select --install
```

步骤 3: 安装 OpenClaw

使用官方安装脚本（推荐）:

```
curl -fsSL https://openclaw.ai/install.sh | bash
```

或者使用 npm:

```
npm install -g openclaw
pnpm approve-builds -g
```

**步骤 4: 运行配置向导**

```
openclaw onboard
```

按照提示完成配置：

+   输入 API Key
+   选择 `npm` 作为技能安装的包管理器
+   配置通信渠道
+   选择是否安装推荐技能（OpenClaw 自带 50+ 个技能）

**步骤 5: 启动服务**

```
# 启动网关
openclaw gateway start

# 访问 Web 控制面板
open http://localhost:18789
```

**macOS 特有功能**

OpenClaw 在 macOS 上提供了菜单栏伴侣应用，可以快速访问常用功能：

+   系统通知集成
+   快速命令执行
+   Canvas 画布功能
+   摄像头和屏幕录制

[详细配置请参考官](https://github.com/openclaw/openclaw)方文档中的 macOS 菜单栏伴侣指南。citation

### 4.2.3 Linux 系统安装

Linux 是 OpenClaw 的原生平台，性能和稳定性最佳。以下以 Ubuntu/Debian 为例，其他发行版的步骤类似。

**步骤 1: 更新系统并安装依赖**

```
# 更新软件包列表
sudo apt update &amp;&amp; sudo apt upgrade -y

# 安装基础依赖
sudo apt install -y curl wget git build-essential python3 python3-pip
```

步骤 2: 安装 Node.js 22+

```
# 添加 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -

# 安装 Node.js
sudo apt install -y nodejs

# 验证安装
node --version
npm --version
```

**步骤 3: 安装 `pnpm`**

```
npm install -g pnpm
```

步骤 4: 安装 OpenClaw

方法 A: 使用安装脚本（推荐）

```
curl -fsSL https://openclaw.ai/install.sh | bash
```

方法 B: 从 GitHub 克隆源代码

如果你需要自定义或参与开发：

```
# 克隆仓库
git clone https://github.com/openclaw/openclaw.git
cd openclaw

# 安装依赖
pnpm install

# 构建 UI 和项目
pnpm ui:build
pnpm build
```

构建完成后，可以直接通过 `pnpm openclaw` 运行命令，而不需要全局安装。[citation](https://docs.openclaw.ai/install)

**步骤 5: 配置向导**

```
openclaw onboard
```

步骤 6: 设置系统服务（可选但推荐）

为了让 OpenClaw 在系统启动时自动运行，可以创建 systemd 服务：

```
# 创建服务文件
sudo nano /etc/systemd/system/openclaw.service
```

添加以下内容（替换 YOUR_USERNAME 为你的用户名）:

```
[Unit]
Description=OpenClaw AI Assistant Gateway
After=network.target

[Service]
Type=simple
User=YOUR_USERNAME
WorkingDirectory=/home/YOUR_USERNAME
ExecStart=/usr/bin/openclaw gateway start
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用并启动服务：

```
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启用开机自启
sudo systemctl enable openclaw

# 启动服务
sudo systemctl start openclaw

# 查看状态
systemctl status openclaw
```

## 4.3 云端部署方案

将 [OpenClaw](https://medium.com/@guljabeen222/how-to-install-openclaw-2026-the-complete-step-by-step-guide-516b74c163b9) 部署到云端服务器可以实现 7×24 小时不间断运行，且不占用本地计算机资源。由于 OpenClaw 具有高权限和潜在的安全风险，云端部署时必须特别注意安全配置。citation

### 4.3.1 Docker 容器化部署

Docker 是最推荐的云端部署方式，它提供了隔离性和可移植性，降低了安全风险。

**步骤 1: 安装 Docker**

```
# Linux (Ubuntu/Debian)
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
newgrp docker

# 验证安装
docker --version
```

步骤 2: 使用 Docker 运行 OpenClaw

OpenClaw 官方提供了 Docker 镜像：

```
# 拉取镜像
docker pull openclaw/openclaw:latest

# 创建配置和工作空间目录
mkdir -p ~/.openclaw
mkdir -p ~/openclaw/workspace

# 运行容器
docker run -d \
  --name openclaw \
  --restart unless-stopped \
  -v ~/.openclaw:/root/.openclaw \
  -v ~/openclaw/workspace:/root/openclaw/workspace \
  -p 18789:18789 \
  openclaw/openclaw:latest
```

Docker 会挂载两个卷：

+   `~/.openclaw`: 存储配置文件和 API 凭证
