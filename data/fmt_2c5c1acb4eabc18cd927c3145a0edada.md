## FedNE：基于代理辅助的 Neighbor Embedding 嵌入用于降维

贡献人：

链接：https://arxiv.org/abs/2409.11509

联邦学习（Federated Learning, FL）迅速发展成为一种有前景的范式，能够在不交换本地数据的情况下，促进分布式参与者之间的协作模型训练。尽管FL在计算机视觉、图学习和自然语言处理等领域有广泛的应用，但在FL背景下有效用于数据可视化的数据投影模型的开发至关重要，然而这一领域仍然未得到充分探索。邻居嵌入（Neighbor Embedding, NE）是可视化复杂高维数据的基本技术，但协作学习一个联合的NE模型存在困难。关键挑战在于目标函数，因为有效的可视化算法如NE需要在数据对之间计算损失函数。本文介绍了FedNE，一种将FedAvg框架与对比NE技术集成的新方法，无需共享数据。为了解决缺乏跨客户端排斥（inter-client repulsion）的问题，这对于全局嵌入空间中的对齐至关重要，我们开发了一种代理损失函数，每个客户端学习并相互共享。此外，我们提出了一种数据混合策略，以增强本地数据，旨在缓解由本地kNN图构建的不可见邻居和错误邻居的问题。我们在合成和真实世界数据集上进行了全面的实验。结果表明，与几种基线方法相比，我们的FedNE能够有效地保留邻居数据结构并增强全局嵌入空间中的对齐。

## 自对比前向前向算法

贡献人：

链接：https://arxiv.org/abs/2409.11593

前向前向（Forward-Forward, FF）算法是一种新近提出的纯前向模式学习方法，能够局部且逐层地更新权重，并支持监督和无监督学习。这些特性使其非常适用于脑启发学习、低功耗硬件神经网络以及大型模型中的分布式学习等应用。然而，尽管FF在手写数字识别任务上表现出色，其在自然图像和时间序列上的性能仍然存在挑战。一个关键的限制是需要为对比学习生成高质量的负样本，尤其是在无监督任务中，目前缺乏多样化的解决方案。为了解决这一问题，我们引入了自对比前向前向（Self-Contrastive Forward-Forward, SCFF）方法，灵感来源于自监督对比学习。SCFF生成适用于不同数据集的正负样本，超越了现有的本地前向算法，在MNIST（多层感知机：98.7%）、CIFAR-10（卷积神经网络：80.75%）和STL-10（卷积神经网络：77.3%）上的无监督分类准确率。此外，SCFF首次实现了前向前向训练循环神经网络，开启了更复杂任务以及连续时间视频和文本处理的大门。

## 少样本类增量学习与非独立同分布分散数据

贡献人：

链接：https://arxiv.org/abs/2409.11657

少样本类增量学习对于开发可扩展和自适应的智能系统至关重要，因为它使模型能够在最小化标注数据的情况下获取新类别，同时保护先前积累的知识。然而，现有方法以集中式方式处理连续的数据流，限制了其在优先考虑数据隐私和安全的场景中的适用性。为此，本文引入了联邦少样本类增量学习，这是一种分散式机器学习范式，旨在从分布在多个客户端的稀缺数据中逐步学习新类别。在这种学习范式中，客户端在本地更新其模型以学习新类别，同时保护数据隐私，然后将模型更新传输到中央服务器，在那里进行全局聚合。然而，这一范式面临诸多问题，如少样本学习的困难、灾难性遗忘和数据异质性。为了解决这些挑战，我们提出了一个基于合成数据的框架，利用重放缓冲区数据来维护现有知识并促进新知识的获取。在该框架内，我们开发了一个噪声感知生成重放模块，通过平衡新数据和重放数据来微调本地模型，同时生成新类别的合成数据，以进一步扩展未来任务的重放缓冲区。此外，我们设计了一种类特定加权聚合策略，通过根据本地模型在合成数据上的表现自适应地聚合类特定参数，以应对数据异质性。这使得在不直接访问客户端数据的情况下，实现有效的全局模型优化。我们在三个广泛使用的数据集上进行了全面的实验，结果证明了所提出框架的有效性和优越性。

## 基于多文档的多轮合成对话生成

贡献人：

链接：https://arxiv.org/abs/2409.11500

我们介绍了一种基于多文档的多轮合成对话生成技术，该技术融合了三个主要理念。首先，我们通过使用链式思维（Chain-of-Thought, CoT）提示生成的分类驱动用户查询来控制整体对话流程。其次，我们通过模拟实际使用检索器在每个用户轮次后更新基础文档，支持多文档基础的对话生成。第三，我们应用“大型语言模型作为评判者”（LLM-as-a-Judge）来过滤掉回答错误的查询。对合成对话数据的人类评估表明，该数据具有多样性、连贯性，并且大多数回答都是正确的。对可回答查询的人类和自动评估均表明，基于合成对话微调的模型在四个公开的多轮文档基础基准测试集上，始终优于基于现有人工生成训练数据微调的模型。

## 平等的语言表示在语言模型中：一切始于Tokenizers

贡献人：

链接：https://arxiv.org/abs/2409.11501

分词器作为人类语言与语言模型潜在空间之间的桥梁，影响着语言在这些模型中的表示方式。由于以英语为中心的大型语言模型（Large Language Models, LLMs）的极大普及，正在努力将其适应于其他语言。然而，我们证明，从分词的角度来看，并非所有分词器都能公平地表示复杂书写系统的语言，如泰米尔语、僧伽罗语和印地语，主要原因在于预分词方法的选择。我们进一步表明，预分词在实现这些复杂书写系统语言的平等表示方面，比分词算法本身起着更为关键的作用。为了解决这一问题，我们通过引入音素（graphemes）改进了字节对编码（Byte Pair Encoding, BPE）算法，称之为音素对编码（Grapheme Pair Encoding, GPE）。我们的实验表明，基于音素的字符提取在处理复杂书写系统时，优于字节级分词器。我们通过在泰米尔语、僧伽罗语和印地语上的实验验证了这一方法的有效性。

## 小型语言模型在短篇创意写作中超越人类：比较SLMs、人类与LLMs的研究

贡献人：

链接：https://arxiv.org/abs/2409.11547

本文评估了微调后的小型语言模型（Small Language Model, SLM）BART Large在创意小说写作能力上的表现，并将其与人类以及两种大型语言模型（Large Language Models, LLMs）：GPT-3.5和GPT-4o进行了比较。我们的评估包括两个实验：（i）人类评估，读者对SLM生成的故事与人类编写的故事进行评分；（ii）定性语言分析，比较不同模型生成的故事在文本特征上的差异。在第一个实验中，我们邀请了68名参与者根据语法正确性、相关性、创意性和吸引力等维度对模型和人类生成的短篇故事进行评分。结果显示，BART Large在大多数方面超过了人类作家，整体得分为2.11，而人类编写的文本得分为1.85，提升了14%。在第二个实验中，定性分析揭示，尽管GPT-4o表现出近乎完美的内部和外部连贯性，但其生成的叙事更为可预测，仅有3%的故事被视为新颖。相比之下，BART生成的15%的故事被认为是新颖的，显示出尽管模型规模较小，但其创意程度更高。本研究提供了定量和定性见解，探讨了模型规模和微调如何影响创意写作任务中创意性、流畅性和连贯性之间的平衡。

## Moshi: a speech-text foundation model for real-time dialogue

贡献人：

https://zhuanlan.zhihu.com/p/720818708?utm_psn=1820060061046800385

Moshi 是一款两个月前刷屏的语音对话模型，最近发布了其权重和论文。这款开源模型具有7.6B参数，专注于实时语音对话，并提供了详细的技术报告，非常适合跨领域的研究者入门。

Moshi 基于经典变换器架构，引入了一种离散编码（RVQ），可以接收多种输入并输出多种结果。其主要目标是处理语音中的双工工况（模型能够边说边听），并通过文字提升输出语音的逻辑性。在浅层上拉一个输出头用于生成文字，增强语音对话的逻辑表现。

"Inner Monologue" 是 Moshi 采用的关键技巧之一，即在生成语音 token 时同步生成文字 token，从而提升语音生成的效果。这一方法也曾在其他工作中出现，如 Mini-Omni、Llama-Omni，以及更早的 SpeechGPT-Gen。在 Moshi 中，“先生成”文字指的是文字相对于声学 token 更早产生，虽然与语义 token 是同步生成的。通过这种方式，模型在生成声学 token 时已经提前获取了语义信息。
