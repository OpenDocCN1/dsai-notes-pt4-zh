
# 对每个chunk进行embedding，并存储结果

```
results = []
for i, chunk in enumerate(chunks):
    embedding = get_embeddings(chunk)  # 获取嵌入向量
    result = {
        'chunks': i + 1,         # Chunk编号
        'page_content': chunk,   # 原始文本内容
        'embedding': embedding,  # 嵌入向量
    }
    results.append(result)
```
