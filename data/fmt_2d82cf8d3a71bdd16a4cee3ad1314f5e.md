
# Multi Diffusion 插件使用指南

由于显存大小的限制，通常我们即使采用高分辨率修复，也只能将分辨率提高到 2048*2048。若我们强行将分辨率调整至 2048 以上，要么显存直接耗尽无法生成图像，要么生成的图像会出现各种异常问题。

为了解决这一难题，我们还可以使用“Multi diffusion”这个插件进行图像放大。这被视为目前最佳的图像放大解决方案，能够在放大图像的同时增加细节。

## 1. 插件安装

在我提供的网盘文件中已经自带了这个插件。如果在 SD 界面中没有，点击“扩展 → 从网址安装”，输入以下网址后重启 UI 即可：

安装网址：`https://github.com/pkuliyi2015/multidiffusion-upscaler-for-automatic1111`

## 2. 插件使用

1. 建议在正向提示词中的，去除与主体提示词相关有实际意义的部分，只留下例如 "masterpiece, best quality" 等画质描述的词汇。由于该插件的工作原理是将大图分成小块进行绘制，因此在正向提示词中添加了具体对象后，该对象将出现在图像的各个区域。

2. 可以将提示词引导系数调大，例如调到 15 左右，这样出图的效果和细节是要好于 7 的，但是肉眼差别不大，嫌麻烦可以不用调整。

## 3. 插件参数设置

首先，在图生图页面发送要生成的图，重绘幅度建议调整为 0.3，然后向下滚动页面，找到 Tiled Diffusion 和 Tiled VAE 两个选项，并点击右侧的箭头展开设置项。分别在展开设置中点击 Enable Tile Diffusion 和 Enable Tile VAE 前面的小勾确定，这样就启用了。

![](img/86dd4e1cf45974fc9329e83f62bd5f1b.png)

## 4. Tile Diffusion 参数设置

对于 Tile Diffusion，常规情况下，我们只需要调整以下几个参数，其他参数保持默认即可，不需要更改。

放大算法（Upscaler）：我建议只采用 R-ESRGAN 4x+ 系列，其中真实图像类使用 4x+，二次元动漫图像类使用 4x+anime。

放大算法（Scale Factor）：先点选 Keep input image size，保留原始图片尺寸，然后在放大算法的选项中选择最终图像相对于原图的放大倍率（例如选择 2 就是 2 倍，可以将 1500*1500 的图像放大为 3000*3000）。

![](img/8b9fe1d5f0d5fa9c5d9d6871ac033d87.png)

## 5. Tiled VAE 参数设置

如果是第一次使用，可以点击 Reset 进行重置，系统会自动计算出最适合当前电脑配置的编码器区块大小和解码器区块大小。其他参数不需要调整。然后点击生成即可。
