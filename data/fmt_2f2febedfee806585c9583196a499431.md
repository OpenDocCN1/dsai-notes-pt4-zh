
## 链表归并排序

```
// 对链表进行排序的主函数
function sortList(head: ListNode | null): ListNode | null {
    if (head === null || head.next === null) {
        return head;
    }
    const mid = getMiddle(head);
    const rightHead = mid.next;
    mid.next = null;

    const left = sortList(head);
    const right = sortList(rightHead);

    return merge(left, right);
}

function getMiddle(head: ListNode): ListNode {
    let slow = head;
    let fast = head;
    let prev = null;
    while (fast !== null && fast.next !== null) {
        prev = slow;
        slow = slow.next!;
        fast = fast.next.next;
    }
    return prev!;
}

function merge(l1: ListNode | null, l2: ListNode | null): ListNode | null {
    const dummy = new ListNode();
    let current = dummy;

    while (l1 !== null && l2 !== null) {
        if (l1.val < l2.val) {
            current.next = l1;
            l1 = l1.next;
        } else {
            current.next = l2;
            l2 = l2.next;
        }
        current = current.next;
    }

    if (l1 !== null) {
        current.next = l1;
    } else {
        current.next = l2;
    }

    return dummy.next;
}
```

### 复杂度分析

+   时间复杂度：O（n log n）。归并排序的时间复杂度由分割和合并两部分组成。每次分割将链表长度减半，需要进行 log n 次分割操作；每次合并操作需要遍历所有节点，时间复杂度为 O（n）。因此，总的时间复杂度为 O（n log n）。

+   空间复杂度：O（log n）。递归调用栈的深度为 log n，因为每次递归将链表长度减半，所以递归的最大深度为 log n。因此，递归调用栈的空间复杂度为 O（log n）。

## 146.LRU 缓存

`https://leetcode.cn/problems/lru-cache/description/?envType=study-plan-v2&envId=top-100-liked`

### 思路分析

[什么是 LRU](https://juejin.cn/post/6844903982779875335?searchId=20250317094943EEF112BCA56C97C38F36)，我们可以看一下这篇文章缓存淘汰算法，这里我们可以可以利用 `Map` 对象的特性来实现。`Map` 对象能够记住键的插入顺序，并且它的 `keys()` 方法返回的迭代器按照插入顺序排列，这就使得我们可以较为方便地实现 LRU 缓存机制。

### 代码实现

```
class LRUCache {
    private capacity: number;
    private cache: Map<number, number>;

    constructor(capacity: number) {
        this.capacity = capacity;
        this.cache = new Map();
    }

    get(key: number): number {
        if (this.cache.has(key)) {
            const value = this.cache.get(key)!;
            this.cache.delete(key);
            this.cache.set(key, value);
            return value;
        }
        return -1;
    }

    put(key: number, value: number): void {
        if (this.cache.has(key)) {
            this.cache.delete(key);
        } else if (this.cache.size >= this.capacity) {
            const firstKey = this.cache.keys().next().value;
            this.cache.delete(firstKey);
        }
        this.cache.set(key, value);
    }    
}
```

### 复杂度分析

+   时间复杂度：`get` 和 `put` 操作的平均时间复杂度都是 O（1）。因为 `Map` 对象的 `has`、`get`、`set` 和 `delete` 操作的时间复杂度均为 O（1）。

+   空间复杂度：O（`capacity`），主要用于存储 `Map` 中的键值对。

## 常见的一些链表类问题方法选择

### 操作类型

+   节点遍历：如计算链表长度、寻找中间节点 → 单指针或快慢指针。

+   节点修改：如反转链表、删除节点 → 三指针迭代或双指针。

+   结构重组：如合并链表、交换相邻节点 → 递归或虚拟头节点辅助。

### 边界条件

+   是否需要处理头节点变化？ → 使用虚拟头节点（如删除倒数第 `n` 个节点、交换相邻节点）。

+   链表是否可能为空或仅有一个节点？ → 在代码中提前判断。

## 做链表类题的一些通用办法

### 定义辅助节点

+   虚拟头节点：在处理涉及头节点操作（如删除头节点、交换头节点等）的问题时，创建一个虚拟头节点 `dummy` 是非常有效的方法。它可以避免对头节点进行特殊处理，简化代码逻辑。例如，在删除链表倒数第 `n` 个节点和两两交换链表相邻节点的问题中，都可以使用虚拟头节点来简化边界条件的处理。

```
const dummy = new ListNode(0);
dummy.next = head;
```

### 指针操作

+   单指针：在一些简单的链表遍历问题中，使用一个指针就可以完成任务。例如，计算链表的长度，只需要一个指针从头节点开始，依次遍历每个节点并计数。

```
let current = head;
let length = 0;
while (current) {
    length++;
    current = current.next;
}
```

+   双指针：双指针是解决链表问题的常用技巧，常见的有快慢指针和前后指针。

+   快慢指针：通常快指针每次移动两步，慢指针每次移动一步。可以用于寻找链表的中间节点、判断链表是否有环等问题。例如，在寻找链表中间节点时，快指针到达链表末尾时，慢指针正好指向中间节点。

```
let slow = head;
let fast = head;
while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
}
```

+   前后指针：两个指针保持一定的距离，用于解决删除倒数第 `n` 个节点等问题。先将一个指针向前移动 `n` 步，然后两个指针同时移动，当前面的指针到达链表末尾时，后面的指针就指向要删除的节点的前一个节点。

```
let prev = dummy, curr = dummy;
for (let i = 0; i <= n; i++) curr = curr.next;
while (curr) {
    prev = prev.next;
    curr = curr.next;
}
prev.next = prev.next.next; // 删除节点
```

+   三指针：在反转链表等问题中，可能需要使用三个指针，分别记录当前节点、前一个节点和下一个节点，以便在反转过程中正确修改指针的指向。

```
let prev: ListNode | null = null;
let curr: ListNode | null = head;
while (curr) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
}
```

### 递归方法

+   对于一些具有递归结构的链表问题，使用递归方法可以使代码更加简洁。递归的关键在于找到递归的终止条件和递归关系。例如，在两两交换链表相邻节点的问题中，递归的终止条件是链表为空或只有一个节点，递归关系是先交换当前两个节点，然后递归处理后续节点。

```
function swapPairs(head: ListNode | null): ListNode | null {
    if (!head || !head.next) {
        return head;
    }
    const first = head;
    const second = head.next;
    first.next = swapPairs(second.next);
    second.next = first;
    return second;
}
```

### 边界条件处理

+   在编写链表代码时，一定要考虑边界条件，如链表为空、链表只有一个节点等情况。这些边界条件可能会导致代码出现错误，因此需要在代码中进行特殊处理。例如，在删除链表节点时，如果链表为空或者要删除的节点不存在，需要进行相应的判断和处理。
