## 1️⃣ 🤖 智能电子粘附皮肤：机器人与环境交互的新进展！

+ 新加坡南京理工大学和清华大学等联合研发的智能电子粘附皮肤，集成了感知与可控粘附功能，突破了传统粘附设计的限制。
+ 该技术利用形状记忆聚合物（SMP）的特性，实现了从弱粘附到强粘附的调控，适应多种操作场景。
+ 电子皮肤集成了柔性压力传感器和加热器，提升了机器人与环境的复杂交互能力。
+ 应用场景包括表面检测、轻巧物体抓取、重型和多样化物体操控，展现了在工业和医疗等领域的潜力。
+ 这项研究不仅推动了机器人交互技术的发展，也为智能机器人领域的产业化提供了新动力。

### 关键词
智能电子皮肤，形状记忆聚合物，机器人交互，多场景应用，产业化潜力

## 2️⃣ 🌏 百度决定背叛闭源大模型，李彦宏重新拥抱开源

+ 百度宣布下一代文心模型将开源，计划推出文心大模型4.5系列，并从6月30日起正式开源。
+ 文心一言自2023年3月启动邀测以来，已迭代至4.0版本，成为推动中国大模型发展的关键。
+ 核心技术之一是知识增强，结合百度知识图谱，提升问答任务的精准度。

+ 百度的开源决定展示了其在AI领域的开放态度和技术自信，计划发布多款模型，5.0版本将显著提升多模态能力。

## 3️⃣ 🧠 [DeepSeek R1遇难题142次"I give](https://mp.weixin.qq.com/s/sbSUI0ECeqsSDaWoI3cPMw) up"，研究还称需增加推理时机控制机制

+ DeepSeek R1在最新大语言模型推理测试中表现不佳，遇到难题时142次放弃，研究建议增加推理时机控制机制。
+ 研究基于NPR周日谜题挑战构建了包含近600个问题的基准测试，发现最新一代推理模型解决此类谜题具有挑战性。
+ 测试结果显示OpenAI o1表现最优，准确率为59%；DeepSeek R1准确率为35%，明显低于具备推理功能的其他模型。
+ 研究揭示了模型新的"故障"模式，如在推理过程中直接放弃，给出明知错误的答案，或陷入"无限思考"状态。
+ 网友热议研究结果，有人认为这类挑战更侧重"记忆回忆"而非传统意义上的"推理"，对模型表现不一提出疑问。

### 关键词
DeepSeek R1，推理测试，NPR谜题，模型故障，网友讨论

## 4️⃣ 🤖 Claude 4被曝发布在即！DeepSeek把大招都给逼出来了

+ Claude 4即将发布，它是一个混合型大模型，结合了推理能力和传统大模型的处理能力。
+ 用户可以控制推理成本，通过游标刻度尺调整每个问题所需的token数，从而控制算力和推理时间。
+ Anthropic和OpenAI都在推动通用模型和推理模型的融合，这可能是大模型发展的下一个趋势。
+ Claude系列以其编程能力著称，擅长处理复杂的编程任务，如理解大型代码库并生成完整代码。
+ 关于Claude 4的定价尚未明确，市场期待其在实用能力上有显著优势。

### 关键词

## 5️⃣ 🌏 [达摩院开源VideoLLaMA3：仅7B](https://mp.weixin.qq.com/s/RgMLx5w9ozECXPGS7SgVbA)大小，视频理解拿下SOTA | 在线可玩

+ 达摩院发布新一代7B大小的视频理解模型VideoLLaMA3，取得视频理解领域的SOTA成绩。
+ VideoLLaMA3以图像为中心，使用3M视频文本数据实现超越同参数量模型的视频理解能力。
+ 模型在HuggingFace上提供图像、视频理解demo，用户可上传图片或视频进行互动。
+ VideoLLaMA3采用以图像为中心的训练范式，包含视觉编码器适配、视觉语言对齐、多任务微调和视频微调四个关键内容。
+ 模型性能得益于高质量图像重新标注数据集VL3Syn7M的构建和各训练阶段的数据混合策略。

### 关键词
视频理解，SOTA，多模态学习，图像中心，HuggingFace

## 6️⃣ 🌏 一图一3D世界，视频还可交互，昆仑万维「空间智能」开年首秀来了

+ 昆仑万维发布Matrix-Zero世界模型，探索空间智能领域，包括3D场景生成和可交互视频大模型。
+ Matrix-Zero能将图片转化为3D场景，并生成可交互视频，增强AI的物理推理和空间认知能力。
+ 该技术方案在3D世界生成领域展现出独有优势，支持大范围自由探索和动态物理效果。
+ Matrix-Zero的可交互视频子模型强化了视频内容的可操作性，提升了用户参与度。
+ 昆仑万维在空间智能领域的进展，有望为构建通用世界模型和AGI提供强大助力。

### 关键词
