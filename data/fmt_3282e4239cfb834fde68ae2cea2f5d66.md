## 论文总结: 《IS IMAGENET WORTH 1 VIDEO? LEARNING STRONG IMAGE ENCODERS FROM 1 LONG UNLABELLED VIDEO》

## 摘要

自监督学习（`SSL`）通过避免昂贵的标注，成功地在数十亿张图像上进行预训练。然而，我们是否充分利用了数据？我们可以更经济地利用数据吗？本文通过两个贡献尝试回答这些问题。首先，我们调查了第一人称视频，并引入了`Walking Tours`数据集。这些视频是高分辨率的，时长数小时，单次拍摄未剪辑，描绘了大量对象和动作，具有自然的场景过渡。其次，我们引入了一种新的自监督图像预训练方法`DORA`，旨在从连续视频中学习。与现有方法不同，我们提出了一种“追踪以学习识别”的方法，通过跨时间的对象追踪，使用`transformer`的交叉注意力来生成关注图，并在经典的自监督蒸馏损失中使用这些追踪视图。使用我们的方法，一个单一的`Walking Tours`视频在多个图像和视频下游任务中成为了`ImageNet`的强大竞争者。

## 引言

### 背景

+ **数据使用效率**：尽管大规模的图像预训练展示了强大的性能，但人类视觉系统在自然环境中更有效地发展。

+ **视频的优势**：人类通过连续的视频流来学习，而传统方法多采用对象中心的视频，从而可能导致性能差距。

### 研究动机

+ **经济高效的预训练**：探索更经济高效的预训练方法，避免过度依赖大量标注数据。

+ **第一人称视频的优势**：第一人称视频提供了丰富的语义信息和自然的场景过渡，有助于更好地学习视觉表示。

## 主要贡献

1. `Walking Tours`数据集：引入了一个新的开放源代码的第一人称视频数据集，包含不同城市的长视频，未标注且未策划，适用于自监督学习。

2. 自监督预训练方法`DORA`：提出了一种新的预训练方法，通过对象的发现和追踪来学习视觉表示，显著提高了预训练效率。

## 数据集与方法

### Walking Tours数据集

+ **视频特点**：视频时长从1小时到3小时不等，4K分辨率，包含大量对象和动作，具有自然的光照和场景过渡。

+ **高分辨率**：视频的高分辨率保证了图像的清晰度，提供了丰富的视觉细节。

+ **长时连续性**：长视频的连续性提供了丰富的上下文信息，有助于捕捉动态变化和场景过渡。

+ **数据透明性**：数据集透明且易于获取，适用于自监督学习。

+ **开放源代码**：数据集开放源代码，研究人员可以自由获取和使用。

+ **未标注且未策划**：视频未经标注和策划，模拟了自然环境中的视觉数据，提供了真实世界的学习场景。

### DORA方法

+ **高层次想法**：利用多头注意力机制在视频帧之间追踪对象，通过对象的跨帧一致性学习视觉表示。

+ **对象一致性**：通过追踪对象的一致性，`DORA`方法能够捕捉对象在不同时间点的变化，提高学习的鲁棒性。

+ **预处理过程**：

+ **对象发现**：使用教师模型的多头注意力在初始帧中发现对象。

+ **教师模型**：预训练好的教师模型通过注意力机制在初始帧中检测出感兴趣的对象。

+ **多头注意力**：利用多头注意力机制，保证对象检测的多样性和准确性。

+ **对象追踪**：在后续帧中追踪对象，通过跨帧的交叉注意力生成关注图。

+ **交叉注意力**：通过交叉注意力机制，生成每一帧中对象的关注图，确保对象在不同帧之间的关联性。

+ **关注图生成**：基于追踪结果生成每一帧的关注图，用于后续的自监督学习。

+ **多视图蒸馏**：使用多视图蒸馏损失，将追踪到的对象作为学习信号。

+ **蒸馏损失**：将不同视图下的对象表示进行蒸馏，使模型在不同视图下的表示更加一致。

+ **自监督学习**：利用生成的关注图和蒸馏损失，实现自监督的视觉表示学习。

## 实验

### 数据集比较与分析

+ **与现有数据集的比较**：`Walking Tours`数据集在对象数量、场景多样性和视频连续性方面优于其他数据集。

+ **对象数量**：视频中包含大量不同类型的对象，提供了丰富的学习样本。

+ **场景多样性**：视频覆盖了多种不同场景，包括城市街道、建筑物、自然景观等。

+ **视频连续性**：长视频的连续性使得模型能够学习到更多的动态变化和场景过渡信息。

+ **实验设置**：在多个任务（如图像分类、对象检测和语义分割）中，使用`DORA`预训练的模型表现优于传统的`ImageNet`预训练方法。

+ **图像分类**：在标准图像分类任务中，`DORA`预训练的模型在准确率上显著优于`ImageNet`预训练的模型。

+ **对象检测**：在对象检测任务中，`DORA`预训练的模型在检测精度上有显著提升。

+ **语义分割**：在语义分割任务中，`DORA`预训练的模型在分割质量上表现更好。

### 性能评估

+ **下游任务性能**：在`ADE20k`语义分割和`MS COCO`对象检测任务中，`DORA`方法显著优于使用`ImageNet`预训练的方法。

+ **ADE20k语义分割**：在`ADE20k`数据集上，`DORA`方法预训练的模型在语义分割任务中表现优异，取得了更高的`mIoU`（平均交并比）。

+ **MS COCO对象检测**：在`MS COCO`数据集上，`DORA`方法预训练的模型在对象检测任务中表现突出，取得了更高的`mAP`（平均精度）。

+ **视频理解任务**：在`DAVIS-2017`视频对象分割和`GOT-10k`对象追踪任务中，`DORA`方法展示了优越的性能。

+ `DAVIS-2017`视频对象分割：在`DAVIS-2017`数据集上，`DORA`方法预训练的模型在视频对象分割任务中表现出色，取得了更高的`J&F`指标。

+ `GOT-10k`对象追踪：在`GOT-10k`数据集上，`DORA`方法预训练的模型在对象追踪任务中表现卓越，取得了更高的成功率和精度。

### 参数分析

+ **跟踪对象数量**：研究了不同跟踪对象数量对性能的影响，发现跟踪3个对象时效果最佳。

+ **参数选择**：通过实验分析了不同跟踪对象数量对模型性能的影响，最终确定跟踪3个对象是最佳选择。

+ **性能平衡**：在跟踪对象数量和模型性能之间找到了最佳平衡点，确保模型在性能和计算资源之间达到最优。

+ **遮罩选择与`Sinkhorn-Knopp`算法**：分析了不同遮罩策略和`Sinkhorn-Knopp`算法对模型性能的影响，证明多对象遮罩与`Sinkhorn-Knopp`算法的结合最为有效。

+ **遮罩策略**：研究了多对象遮罩策略对模型性能的影响，发现多对象遮罩策略能够显著提高模型的表示能力。

+ **`Sinkhorn-Knopp`算法**：通过结合`Sinkhorn-Knopp`算法，进一步优化了对象追踪和蒸馏过程，提高了模型的整体性能。

## 结论

本文展示了通过一个长视频进行自监督预训练的方法，证明了在多个下游任务中取得了显著的性能提升。我们的研究表明，合理利用视频数据可以在不依赖大规模标注数据的情况下实现强大的视觉表示学习。

+ **自监督学习的潜力**：`DORA`方法展示了自监督学习在视觉表示学习中的巨大潜力，通过合理利用视频数据，显著提升了模型的性能。

+ **视频数据的优势**：通过分析和实验验证，证明了使用第一人称视频数据进行自监督预训练的优势，为未来的研究提供了新的方向。
