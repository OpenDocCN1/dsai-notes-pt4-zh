
# 其他有效的差异（Diff）格式

如果你想尝试使用不同的差异格式，我们在测试中发现，Aider 的 polyglot 基准测试中使用的 `SEARCH/REPLACE` 差异格式，以及一种无内部转义的伪 `XML` 格式，都具有很高的成功率。

这些差异格式有两个共同的关键特点：(1) 它们不使用行号；(2) 它们提供了要被替换的确切代码和用于替换的新代码，并且两者之间有清晰的分隔符。

```
SEARCH_REPLACE_DIFF_EXAMPLE = """path/to/file.py>>>>>>> SEARCHdef search():    pass=======def search():   raise NotImplementedError()<<<<<<< REPLACE"""PSEUDO_XML_DIFF_EXAMPLE = """<edit><file>path/to/file.py</file><old_code>def search():    pass</old_code><new_code>def search():   raise NotImplementedError()</new_code></edit>"""
```
