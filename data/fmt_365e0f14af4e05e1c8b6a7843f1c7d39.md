## 什么是PTCF框架？

PTCF框架是谷歌官方总结的四要素提示词模版，将提示工程从"凭感觉提问"的艺术，转变为"有章可循"的科学方法。

**PTCF分别对应：**

+ **P (Persona)** - 角色设定

+ **T (Task)** - 任务描述

+ **C (Context)** - 上下文背景

+ **F (Format)** - 输出格式

---

## PTCF框架详细解读

### P (Persona) - 角色设定：让AI成为专家

**作用：** 为AI指定一个专业角色，让它以特定专家的身份和知识水平来回答问题。

**核心要点：**

+ 选择与任务最匹配的专业角色

+ 越具体越好，避免泛泛的"专家"描述

+ 可以组合多个角色特征

**示例对比：**

❌ **普通版：** 请帮我分析这个营销策略

✅ **PTCF版：** 作为一名拥有10年经验的数字营销专家和数据分析师，请帮我分析这个营销策略

---

### T (Task) - 任务描述：明确你要什么

**作用：** 清晰、具体地描述你希望AI完成的任务，避免模糊不清的指令。

**核心要点：**

+ 使用行动导向的动词（分析、总结、创建、优化等）

+ 明确任务的具体目标和预期结果

+ 必要时可以分解复杂任务

**示例对比：**

❌ **普通版：** 帮我处理这份报告

✅ **PTCF版：** 请分析这份销售报告中的关键趋势，识别前三个增长机会，并为每个机会提出具体的执行建议

---

### C (Context) - 上下文背景：提供足够信息

**作用：** 这是PTCF框架的核心，提供AI理解任务所需的所有背景信息。

**核心要点：**

+ 说明任务的背景和目的

+ 提供相关的约束条件和限制

+ 包含目标受众信息

+ 利用`@文件名`功能调用具体文档

**示例要素：**

```
• 业务背景：我们是一家B2B SaaS公司
• 时间背景：正在准备Q4季度总结  
• 受众背景：报告将提交给董事会
• 约束条件：篇幅控制在5页以内
```

---

### F (Format) - 输出格式：规范呈现方式

**作用：** 明确指定输出的结构和格式，确保结果符合使用需求。

**核心要点：**

+ 指定文档类型（报告、邮件、清单等）

+ 明确结构要求（段落数、标题层级等）

+ 设定长度限制

+ 说明语言风格要求

**常用格式示例：**

```
• 邮件格式：包含主题行、问候语、正文、行动要求
• 报告格式：执行摘要+正文+结论建议
• 清单格式：编号列表，每项不超过20字
```

## 应用场景举例

### 场景1：工作邮件撰写

❌ **传统提示：** 帮我写一封邮件给客户

✅ **PTCF优化版：**

```
【P】作为一名专业的客户成功经理
【T】撰写一封跟进邮件，确认客户对上周演示的反馈并推进下一步合作
【C】客户是一家200人规模的电商公司，上周我们演示了数据分析解决方案，
     客户表现出浓厚兴趣但提出了关于数据安全的担忧
【F】正式商务邮件格式，包含主题行，正文控制在150字以内，
     结尾包含明确的下一步行动建议
```

### 场景2：数据分析报告

❌ **传统提示：** 分析一下这个数据表

✅ **PTCF优化版：**

```
【P】作为一名资深的业务数据分析师
【T】分析Q3销售数据，识别业绩下滑的根本原因并提出改进建议
【C】@Q3销售数据.xlsx 公司主营B2B软件销售，Q3业绩比预期下降15%，
     需要为管理层会议准备分析报告
【F】结构化报告格式：1)执行摘要 2)关键发现 3)根本原因分析 4)改进建议，
     总长度800-1000字
```

## 复杂场景实战：企业数字化转型咨询方案

让我们用PTCF框架来构建一个能解决复杂商业问题的提示词：

```
【P - 角色设定】
作为一名拥有15年经验的企业数字化转型顾问，专精于制造业的数字化升级，
曾成功帮助50+传统制造企业完成数字化转型。

【T - 任务描述】
为一家传统制造企业制定完整的数字化转型战略方案，包括现状诊断、
转型路径设计、技术选型建议、实施时间表和ROI预测。

【C - 上下文背景】
目标企业：年营收5亿元的传统机械制造企业，员工1000人
- 当前痛点：生产效率低、库存管理混乱、客户响应速度慢、数据孤岛严重
- 技术现状：仍在使用10年前的ERP系统，缺乏现代化数字化工具
- 管理层期望：3年内实现生产效率提升30%，运营成本降低20%
- 行业背景：面临激烈竞争，急需通过数字化获得竞争优势
- 参考文档：@企业现状调研报告.pdf @行业数字化趋势分析.pdf

【F - 输出格式】
生成一份专业的数字化转型战略方案，包含以下结构：
1. 执行摘要
2. 现状诊断与问题分析
3. 数字化转型目标与愿景
4. 技术架构设计
5. 分阶段实施路径（包含详细时间表）
6. 投资预算分配（含ROI分析）
7. 风险评估与缓解措施
8. 成功指标与考核体系
```

## 实用技巧补充

### 1. 迭代优化法

如果第一次结果不满意，不要放弃，而是继续对话：

+ "很好，但请在第3部分增加更多的技术细节"

+ "基于以上分析，请具体说明第一阶段的实施步骤"

### 2. AI辅助优化

谷歌还提供了一个"元技巧"：

```
Make this a power prompt: [你的原始提示]
```

让Gemini帮你优化提示词本身。
