## 一、Embedding 概述

因为计算机本身不能识别单词、词语、字符等标识符（`token`），所以需要把这些标识符数字化。嵌入（`Embedding`）是将高维稀疏数据（如单词、句子或图像）转换成低维密集向量的一种技术。

有一句话叫做“万物皆可`Embedding`”，意思是任何类型的数据（文本、图像、音频、视频、用户行为、物理现象等）都可以通过某种数学方法转化为低维稠密的向量（`Embedding`），从而让计算机能够更高效地处理和理解这些数据。通过`Embedding`，所有类型的数据都能被统一表示为向量，方便计算机进行相似性计算、分类、聚类等任务。例如：通过词向量（`Word2Vec`），计算机可以理解“猫”和“狗”的语义相似性；通过图像`Embedding`，可以判断两张图片是否属于同一类别。因此`Embedding`有着广泛的应用场景。

可以说：`Embedding`是AI理解世界的一种通用语言。

本次微学习仅介绍文本嵌入模型（`Text Embedding`）。

## 三、典型 `Text Embedding` 模型简介

### （一）`Text2Vec`：`text2vec-base-chinese`/`text2vec-base-multilingual`/`text2vec-large-chinese`

#### （1）模型概述

`text2vec`发布于2022年3月，是一种基于词袋模型的文本嵌入方法。它通过构建词汇的共现矩阵，然后应用奇异值分解（`SVD`）等矩阵分解技术来生成文本的向量表示。`text2vec`模型简单易用，适用于处理大规模的文本数据。然而，由于它忽略了词序信息，因此在某些复杂的NLP任务中可能表现不佳。

+ `text2vec-base-chinese`模型（V1.1.4）：是用`CoSENT`方法训练，基于`hfl/chinese-macbert-base`在中文`STS-B`数据训练得到，并在中文`STS-B`测试集评估达到较好效果。

+ `text2vec-base-chinese-nli`模型（V1.2.0）：基于`nghuyong/ernie-3.0-base-zh`模型，使用了中文`NLI`数据集`shibing624/nli_zh`全部语料训练的`CoSENT`文本匹配模型，在各评估集表现提升明显。

+ `text2vec-base-chinese-nli`模型（V1.2.1）：针对`CoSENT`的loss计算对排序敏感特点，人工挑选并整理出高质量的有相关性排序的`STS`数据集`shibing624/nli-zh-all/text2vec-base-chinese-sentence-dataset`，在各评估集表现相对于之前有提升

+ `text2vec-base-multilingual`模型（V1.2.2）：用`CoSENT`方法训练，基于`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`用人工挑选后的多语言`STS`数据集`shibing624/nli-zh-all/text2vec-base-multilingual-dataset`训练得到，并在中英文测试集评估相对于原模型效果有提升。

+ `text2vec-large-chinese`模型（V1.2.4）：用`CoSENT`方法监督训练，基于`BAAI/bge-large-zh-noinstruct`用中文匹配数据集训练得到，并在中文测试集评估相对于原模型效果有提升，短文本区分度上提升明显

### （二）`M3E`：`m3e-small`/`m3e-base`/`m3e-large`

#### （1）模型概述

`M3E`（Moka Massive Mixed Embedding）是`MokaAI` 2023年发布的开源中文`Embedding`模型。该模型采用了大规模混合嵌入技术，旨在提高词向量的表达能力和泛化能力。`M3E`在训练过程中充分考虑了词语之间的语义关系、上下文信息以及领域知识等因素，从而生成了更加丰富、准确的词向量。

+ Moka——由`MokaAI`训练，开源和评测。

+ Massive——经过千万级（2200w+）的中文句对训练。

+ Mixed——旨在提供一个 ALL IN ONE 的文本嵌入模型，只需要一个模型就可以覆盖全部的应用场景，支持中英双语的同质文本相似度计算、异质文本检索等功能。

`m3e-small`是较小尺寸的`M3E`模型，`m3e-base`是标准尺寸的`M3E`模型，`m3e-large`是较大尺寸的`M3E`模型。`M3E`模型的特点如下：

+ 大规模混合嵌入：`M3E`采用了大规模混合嵌入技术，将不同类型的词向量进行融合，从而生成更加全面、准确的词向量表示。这种技术能够充分利用各种词向量的优点，提高词向量的表达能力和泛化能力。

+ 丰富的语义信息：`M3E`在训练过程中充分考虑了词语之间的语义关系、上下文信息以及领域知识等因素。这些因素的有效融合使得`M3E`生成的词向量更加具有丰富的语义信息，能够更好地表达词语的真实含义。

+ 高性能表现：在多个数据集上的评测结果表明，`M3E`在检索任务和文本分类任务上均表现出了卓越的性能。例如，在`T2Ranking 1W`中文数据集上，`M3E`在`ndcg@10`上达到了0.8004，超过了`openai-ada-002`的0.7786；在6种文本分类数据集上，`M3E`在`accuracy`上达到了0.6157，超过了`openai-ada-002`的0.5956。这些成绩充分证明了`M3E`在实际应用中的优势。

`M3E`团队建议：

+ 如果使用场景主要是中文，少量英文的情况，建议使用 `m3e` 系列的模型

+ 多语言使用场景，并且不介意数据隐私的话，建议使用 `openai text-embedding-ada-002` 模型

+ 代码检索场景，推荐使用 `openai text-embedding-ada-002`

+ 文本检索场景，使用具备文本检索能力的模型

### （三）`BGE`：`bge-small`/`bge-base`/`bge-large`

#### （1）模型概述

`BGE`（Bilingual General Embedding）模型是北京智源人工智能研究院（`BAAI`）2023年8月推出的中英文语义向量模型。它首先使用`RetroMAE`预训练算法在大规模语料库上进行预训练，然后利用难负样本挖掘方法进行微调。`bge`模型能够有效地捕获跨语言的语义信息，因此在处理跨语言NLP任务时表现出色。`RetroMAE`预训练算法论文地址：https://arxiv.org/abs/2205.12035

`bge-small-en`和`bge-small-zh`是较小尺寸的`BGE`模型，`bge-base-en`和`bge-base-zh`是标准尺寸的`BGE`模型，`bge-large-en`和`bge-large-zh`是较大尺寸的`BGE`模型。

`BGE`的技术特点如下：

+ 高效预训练和大规模文本微调；

+ 在两个大规模语料集上采用了`RetroMAE`预训练算法，进一步增强了模型的语义表征能力；

+ 通过负采样和难负样例挖掘，增强了语义向量的判别力；

+ 借鉴`Instruction Tuning`的策略，增强了在多任务场景下的通用能力
