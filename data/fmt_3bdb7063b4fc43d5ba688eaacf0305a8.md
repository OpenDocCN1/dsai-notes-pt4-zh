
# 如何保存`Cursor`的历史对话记录

> 来源：[https://now.feishu.cn/docx/ZT5idFIbno384ExVHrxci232nAg](https://now.feishu.cn/docx/ZT5idFIbno384ExVHrxci232nAg)

1. 下载`SpecStory`并重启
2. 点击顶部搜索框，选择第二项
3. 输入：`SpecStory: Save Composer and Chat History`
4. 选择需要保存的历史记录并确定
5. 打开`md`

![](img/0e787f04fcd39f47fd8e1952e6ac59c9.png)

6. 保存`md`

![](img/163a6f12c23b381a948e72061f106e91.png)

左侧目录结构也能看到之前的对话历史

![](img/29e36e1b531a64d3646d51226ac02b5e.png)
