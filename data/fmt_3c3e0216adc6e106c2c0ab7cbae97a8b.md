## 7.1 知识图谱的表示:三元组模型

知识图谱(Knowledge Graph)这个概念最早谷歌公司于2012年提出的，是为了准确阐述各种人、事、物之间的相互关系而创建，最早是服务于搜索引擎。这种把各种人、事、物用概念的方法来描述称为`Entity`，又叫作`Ontology`。而知识图谱是为了准确阐述文本的语义，而建立起来的自然界中实体关系的知识数据库。一般来说用关系图来表示知识图谱，如图7-1所示。实体通常用图(`Graph`)中的节点(`Vertex`)表示，而实体间的关系(`Relation`)则用图中的边(`Edge`)表示。

知识图谱的组成三要素:知识图谱的组成三要素分别是实体，属性和关系的三元组。

实体:各种人、事、物用概念的方法来描述，独立且区别于其他存在的事物称为`Entity`，又叫作`Ontology`。实体是知识图谱中最基本的元素。

关系:在知识图谱中，关系表示知识图谱中的边，用来表示不同实体间的某种联系。

> 如图7-2所示，人物实体张三和人物实体李四的关系是夫妻。

属性:知识图谱中的实体和关系都可以有各自的属性。

> 比如图7-2中，人物实体的属性有年龄和职业(张三，年龄:23，职业:演员;李四，年龄:22，职业:歌手)。关系的属性有(夫妻关系，登记时间:2018年8月，有无子女:无)。

语义类和内容也是知识图谱中可选择的要素。

语义类:具有同种特性的实体构成的集合，如人类、动物、国家、植物等。

内容:通常是实体和语义类的名字、描述、解释等，变现形式一般有文本、图像、音视频等。

知识图谱:把实体间的关系表示成一种多关系图谱，形成一种知识型的语义网络。

图谱中的节点用来表示实体，而实体间的关系用图谱中的边来表示。

实体知识图谱:以人和物为实体中心的关系图谱，反应人和物之间的关系的关系网络。

> 如图7-2中两个人物之间通过夫妻关系联系起来的网络，

事件知识图谱:事件区别以人和物为实体的关系图谱，每个不同的事件都用节点表示，事件和事件之间通过逻辑关系相连。

> 比如因果关系、并列关系、时序关系，等。

## 7.2 知识抽取

### 7.2.1 知识抽取-命名实体识别

命名实体识别(`NamedEntityRecognition`，`NER`)是自然语言处理中的一项基本任务，其方法是给出一段输入文本，利用序列标注等方法，抽取出文本中的实体。

命名实体一般指的是文本中代表具体指向意义的实体，一般人名、机构组织名、地址名时间日期、金额等都属于可以用来识别的实体。

`NER`一般被看作分词中的一部分，属于未登录词识别的一种，文本中有很多各式各样的`NER`词汇，一些词还是在特定场景下出现的词汇，比如电影名称、歌曲名、餐馆名称等。

把`NER`词汇都全部准确识别是件难度很大的事情，而且也影响到分词最后的效果。

![](img/8568a8e005d8fec1b28dd3ad19b42003.png)

### 7.2.2 利用 `CRF` 模型识别 `NER`

`NER`在自然语言处理中的做法和中文分词，词性标注的类似，都是把问题转换成相应的序列标注问题，并通过大规模语料的训练，得到句子中每个位置和标注的对应关系。

条件随机场(`Conditional Random Field`，`CRF`)是一种判别式模型。我们最常用到的是`CRF++`工具，用其进行序列标注型训练。

算法流程:

```
1)训练文本预处理
    a.文本清理:清理文本中的乱字符，统一文本格式。
    b.文本分词，对待训练文本进行中文分词。
    c.确定序列标注集合，对训练文本进行标注。
2)训练CRF模型
    a.制作 CRF 特征模版。
    b.输入标注好的预处理训练文本。
    c.使用 CRF ++工具进行训练，生成CRF model。
```

`CRF`模型适用于序列标注模型的训练是因为，`CRF`训练的序列标注的目标函数除了包含输人的转态特征函数外，还包含了各个标签之间的转移特征函数。

`CRF`模型通过语料来训练模型，利用随机梯度下降优化未知参数的值。

在`NER`的预测阶段，实际上是求序列标注的概率最大问题。既用训练模型为输入序列做标注，得到输出序列标注，然后利用维特比算法解码，使用动态规划求出概率最大的也就是最优的标签序列。

> 假设给出一段文本，开头为:谁是北京中赫国安足球俱乐部的主教练。

> 1)预处理阶段(包括分词):谁是北京中赫国安足球俱乐部的主

> 2)使用`BMESO`作为序列标注的标准:

> `B`表示实体的开头，`M`表示实体的中间，`E`表示实体的结尾，`S`表示单一实体，`O`表示非实体部分

> 那么预处理的文本经过标注表示为:

> 谁/O 是/O 北京/B 中赫/M 国安/M 足球/M 俱乐部/E 的/O 主教练/O

> 3)模版一般分`Unigram`标注和`Bigram`标注

### 7.2.3 利用 `BiLSTM+CRF` 模型进行命名实体识别

自从深度学习诞生后，学者们就开始考虑如何利用深度学习的自动提取特征的功能，来更加有效的提取特征，以此提高`NER`模型识别的准确率和召回率。但是深度学习预测出来的标签有可能是无效的，因为深度学习是对每个`Token`进行单独的标签预测，没有更多的上下文规律，模型需要`CRF`提供更多的标签之间的转移概率，即是我们需要得到更多的上下文信息。

所以在一段时间内`DL-CRF`变成了序列标注的标配，这里我们用`BLSTM-CRF`模型作举例说明。

## 7.3 知识抽取-实体关系抽取:`RelationExtraction`

信息抽取是从大规模的语料或是半结构化的自然文本中提取出来结构化信息。一般来说信息抽取分为以下几个步骤如图7-5表示出来。

![](img/4132d29fd02fcf3d9d2893c9c4d45bde.png)

关系抽取就是识别出实体并抽取实体之间的语义关系。

+   如果关系类型是已知的，那这种抽取的方法就被称为封闭式关系抽取。

+   而如果关系类型是未知的，只是确定了实体间发生了关系，关系内容还需要发现，那么这种抽取称为开放式关系抽取。

一般我们面对的是2个不同的实体间的关系，称为二元关系抽取。

但是还是有3个，或3个以上实体关系的句子描述，我们称这种为多元实体关系抽取。

实体关系抽取的方法有很多种，首先介绍的是基于规则的关系抽取，这部分的关系抽取一般是靠人工总结的模式进行的。

### 基于规则的模式匹配和关系抽取

实体关系抽取(`Relation Extraction`，`RE`)和实体识别(`Name Entity Recognition` `NER`)都是从语料中将非结构化的数据解析成为结构化的数据加以存储和利用的一种方法。在学术界，单纯的关系抽取任务和基于远程监督的关系抽取任务是采取比较多的两种方法。

### 基于监督学习的方法(Supervised Method)

在这里，把实体关系转化成高维空间的特征向量，把实体配对的语义关系转换成多分类问题，其中每一种关系都被看成是一个类别。然后通过对已标注数据进行训练得到分类器的方式来解决这个问题，关系如图7-6所示。

![](img/67b5f89b9733fbc7160ad83c11ae7cd9.png)

基于监督学习关系抽取步骤

```
1)实体特征构建
  a.命名实体识别构建的特征:定义涉及的所有命名实体，把识别的命名实体做特征。
  b.特征词构成的特征:一个命名实体前面的特征词，后面的特征词，组成命名实体的特征词。
2)实体关系特征构建
  a.定义需要抽取的实体关系。
  b.标注训练中的实体关系
  c.通过依存句法分析器获得句子的句法解析结果。
3)在标注好的训练集合上训练得到分类器
4)对待标识文本进行关系预测
  a.对待标识文本，识别是否有涉及的命名实体。
  b.判断两个命名实体是否相关。
  c.对相关的命名实体进行文本分类，得到关系类别。
```

`Multi-Way Classification of Semantic Relations Between Pairs of Nominals`

任务描述:给出一句话并且标注出句子中的两个实体，并从提供的9组关系中选择一个最恰当的关系来描述句子中两个实体的关系。

```
Relation1(Cause-Effect:因果关系)
Relation2(Instrument-Agency:表现状态和媒介的关系)
Relation 3(Product-Producer:生产与被生产的关系)。
Relation 4(Content-Container:物体与容器的关系)。
Relation5(Entity-Origin:实体-起源)。
Relation6(Entity-Destination:实体与终点的关系)。
Relation7(Component-Whole:部分与整体的关系)。
Relation 8(Member-Collection:元素与集合的关系)。
Relation 9(Message-Topic:条款与主题的关系)。
```

### 基于种子的启发式算法(Seed-Based or Bootstrapping Approach)

在关系提取中常会遇到没有足量的标注语料的问题。鉴于这种常见的情况，出现了基于种子的启发式算法，这种方法为各种不同的关系标注少量的`Seed`种子实体关系，把这些实体关系的语料作为训练集合，抽取出可以表达这些关系的规则模版或者模式(`Pattern`)，发现更多的实体关系。然后反复迭代，得到最后的结果。这种迭代的过程又叫作“滚雪球”(`Snow Ball`)。

### 远程监督学习(Distant Supervision)

远程监督学习的思想是，如果一句话中的两个实体构成了一种实体关系，那么其他大多数句子里面包含这两个实体的大都体现这种实体关系。假设一个句子包含某对实体，那么这个句子应该蕴含了两个实体间的关系(`Freebase`中罗列的关系之一)，可以将这个句子作为该实体对所对应关系的训练正例。具体步骤为:

```
对每个关系中的每一对元组，在语料库中找到同时包含这两个实体的句子
  1) 抽取高频的特征(语法分析、单词等)。
  2) 用模式训练有监督的分类模型，
```

这种方法的最大缺陷是假设过于完美，实际例子中会引起很多噪音数据，遇到包含两个`Entity`的句子，不一定就在是描述对应的`Relation`。

实体属性抽取: 知识属性的抽取是我们利用规则或是算法，自动的抽取结构化的数据从而得到实体的属性信息。

比如实体是一个人物，我们则根据网络公开信息到他的国籍，生日，出生地，经历等等信息。

一般有以下几种方法来抽取实体属性。

```
1)将实体的属性视作实体与属性值之间的一种名词性关系，将属性抽取任务转化为关系抽取任务。
2)基于规则和启发式算法，抽取结构化数据。
3)基于百科类网站的半结构化数据，通过自动抽取生成训练语料，用于训练实体属性标注模型，然后将其应用于对非结构化数据的实体属性抽取。
4)采用数据挖掘的方法直接从文本中挖掘实体属性和属性值之间的关系模式，据此实现对属性名和属性值在文本中的定位。
```

## 7.4 知识图谱的构建

对于知识图谱的应用来说，知识图谱的构建是一切相关应用的基础，我们需要找到包含需要实体的数据源，并把这些实体和实体关系及属性从数据源中抽取出来。爬虫是一个很好的抓取数据的工具，因为这些在网络上公开的非结构化的数据大多数是以网页的形式存在于互联网的各式各样的文本信息当中，其中维基百科数据、百度百科数据、各个新闻网站的分类新闻数据，都是可以采集的范畴。

也就是说除了开源的结构化的知识图谱的数据，我们最常采用的是利用爬虫爬取半结构化和非结构化的文本数据，利用命名实体识别、关系抽取、实体统一、指代消解等自然语言处理的技术来进行实体提取、关系提取和属性提取。在前面的内容里面我们已经详细的举例解释了命名实体识别，关系抽取，所以这里来说一下实体统一。

### 实体统一

实体统一从字面上理解是将不同的形式表现的是同一种实体，所以我们要把它们进行合并。

> 比如“北大”和“北京大学”从字面上看是不一样的，但是它们在表达上确是指向了同一个实体北京大学，一个大学的校名。

为了减少实体的种类和降低图谱的稀疏程度，需要做合并来实体统一。

另外，代词在文章中指的也是一个实体，而为了明确地表明这些实体，我们需要用实体本身替换指向他们的代词，这个过程称之为指代消解。

### 存储方式

一般知识图谱有两种存储的形式。

一个是基于`Resource Description Framework`(`RDF`)的存储，另外一个是基于图数据库的存储。`RDF`使用`XML`语法和`RDF Schema`(`RDFS`)来将元数据描述成为数据模型。一个`RDF`文件包含多个资源描述，而一个资源描述是由多个语句构成一个语句是由资源、属性类型、属性值构成的三元组，表示资源所具有的属性。资源描述中的语句可以对应于自然语言的语句，其中资源对应于自然语言中的主语，属性类型对应于谓语，属性值对应于宾语，在`RDF`术语中称其分别为主语、谓语、宾语。在之前的认识中，我们习惯用关系型的数据库，而不是图数据库。那么知识图谱为何会选择使用图数据库呢?

图数据库相比关系性数据库更加有利的是:如果知识图谱关系变得很复杂，特别是有很多的2度，3度关联查询时，图数据库会比关系型数据库关联查询的效率上高出几万倍。

### 知识图谱的逻辑架构:数据层与模式层

数据层，模式层把知识图谱分为不同的两个层次。

**模式层**:在数据层之上，是知识图谱的核心，存储经过提炼的知识，通常通过本体库来管理这一层这一层(本体库可以理解为面向对象里的“类”这样一个概念，本体库就储存着知识图谱的类)。

**数据层**:存储真实的数据。

> 例如:

> 模式层:实体-关系-实体，实体-属性-性值

> 数据层:比尔盖茨-妻子-梅琳达·盖茨，比尔盖茨-总裁-微软

### 知识图谱的技术架构

![](img/4723f9c840ee648a063a848768a44387.png)

如图7-7所示，构建知识图谱是不断完善和迭代的过程，而每一个迭代又分成3部分:信息的抽取、知识融合和知识的加工。

信息抽取:可以解释为，把已经成型的公开的结构资源纳入到我们的知识图谱或者通过爬虫爬取非结构和半结构的资源。在爬取到资源后，我们利用命名实体识别关系提取来进行实体提取、属性提取和关系提取。

知识融合:在获得或者更新知识后，需要利用实体统一和指代消解来消除矛盾和歧异。

知识加工:在融合新的知识后，需要经过人工参与的质量评估，才能把有质量的新的部分加入到知识库中。

### 本体构建

本体(`Ontology`)是指工人的概念集合、概念框架，如“人”“事”“物”等。

本体可以采用人工编辑的方式手动构建(借助本体编辑软件)，也可以以数据驱动的自动化方式构建本体。因为人工方式工作量巨大，且很难找到符合要求的专家，因此当前主流的全局本体库产品，都是从一些面向特定领域的现有本体库出发，采用自动构建技术逐步扩展得到的。

```
自动化本体构建过程包含3个阶段:
  1)实体并列关系相似度计算。
  2)实体上下位关系抽取。
  3)本体的生成。
```
