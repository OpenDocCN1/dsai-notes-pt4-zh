## 创建 `Modelfile`

创建文件：`Modelfile`

```
FROM D:\damoxing\llama3-chinese-novel.gguf
```

```
ollama create llama3-chinese-novel -f Modelfile
ollama create Llama-3.1-8B-Lexi-Uncensored_V2_F16 -f Llama-3.1-8B-Lexi-Uncensored_V2_F16.modelfile
```

## 运行新创建的模型

运行新创建的model

```
   ollama run llama3-chinese-novel
   ollama run Lexi-Llama-3-8B-Uncensored_F16
```

## 删除模型

删除模型:

```
ollama list
ollama rm Lexi-Llama-3-8B-Uncensored_F16:latest
```

## 从 `bin` 文件构建

```
FROM ./ollama-model.bin
```

该 `bin` 文件位置应指定为绝对路径或相对于该 `Modelfile` 位置的路径。

```
ollama cp llama3-chinese-novel yunying/llama3-chinese-novel
ollama push yunying/llama3-chinese-novel
```

《星网囚徒》是我用大模型写作的小说，感兴趣可以看看，感受一下大模型的小说的，当然这过程中也有笔者的参与。

首先是签约首次就通过了，在写小说的过程中，我对比了GPT-4等一些开源的LLM。对比下来有些痛点没有解决的很好。

我这里列一些需求,这还依赖一些产品上的解决方案：

1. 给定题材，出一个主旨和脉络，给出章节标题，并叙述每章/每10章故事脉络；
2. 对于给定章节，写/续写内容会a.指定字数，b.生成的内容不符合预期（大改或小改），大改就是重新生成，小改能够在生成结果上改，并影响到接下来的生成结果；甚至不满意自己的提示词，修改提示词后重新生成结果；
3. 给定下一章标题，按照字数要求，过渡衔接
4. 由于网文字数较长，一些前文伏笔、道具、收获等在后文是想用到的，所以最好有张鱼骨和关系图，能够提取关键信息，并生成图，并且图是可以编辑和修改的；
5. 一些细节描写不到位，或者更类似故事梗概而缺少细节描述；
6. 按卷发展的思路不够，比如上界篇、中洲篇等
7. 有时内容和章节标题都希望自动生成
8. 场景构建
9. 小修生成结果
10. 字数扩写
11. 区分正文和提示词：识别正文，识别用户提示词
12、过渡、伏笔、悬念、引出、正文、总结
13、帮助梳理故事脉络，对上前后文
14、错别字，比如公式—写成公司，上下文能否给出公式？

总的来说，现有大模型在写作方面支持的很不到位，最最迫切的是长上下文，Qwen支持了32K，Google Gemini1.5采用了MoE架构，支持1Million上下文，虽然gemma（没MoE）和Gemini1.5使用了相同的结构，但是上下文只有8192，算是遗憾之一。

## 小说 `Prompt` 提示词

小说prompt提示词（总共4745个字符，实际Token会因词汇表大小而差异）：

我想写一本小说，故事概览是：

由于早在几千年前，人类因技术的急速发展和扩张性的本性，威胁到了宇宙的均衡与安全。为了控制人类，同时保护宇宙的和谐，高度文明的外星文明联盟将地球转变为一个隐蔽的监狱，限制人类的科技发展，监视他们的一举一动，外星人通过科技封锁了光的本质，在亚世界时代，林浩在一次观测超新星爆发数据时，发现了T-7暗中利用这次超新星爆发释放的消息，T-7想借助银河系技术突破实现回归银河系外的母星，最后林浩采用光谱逆转装置瘫痪外星监控系统，最终人类科技在解锁了外星人束缚下，“超态”促进科技大发展，最后男主一众乘坐飞船去T-7指示的银河系内定位坐标去了。

主要人物角色和定位是：

林浩

角色定位：数学家、物理学家兼业余天文学家，热爱追寻未解之迷。对政府持有怀疑态度。

性格特点：智力超群、好奇心旺盛、具备精湛的逻辑思维和解决问题的能力，个性中带有独立和轻微的叛逆。

构成作用：他的天文研究无意中涉及到了可能受外星文明控制的复杂科学理论。由于他对数据、物理学和天文的专业知识，成为揭开星际监控系统之谜的关键人物，并成为一系列事件的推动者。

周杰

角色定位：神秘的信息黑客，后来成为林浩的盟友。

性格特点：非常聪明，擅长解密和编程，多疑且有些阴谋论倾向。

构成作用：帮助林浩解码外星监管者留下的数字密码和网络踪迹，但他的阴谋论思维有时会令团队陷入误解和紧张。

赵雨欣

角色定位：记者，追求真相的狂热者。

性格特点：无畏、执着、具有挑战精神，对揭露政府和权威机构的秘密抱有强烈意志。

构成作用：她在追求报道的过程中无意间卷入林浩的冒险中。使用她的社会影响力和资源帮助揭露真相。

韩磊

角色定位：前军人，林浩的老邻居，后来成为林浩的保护者。

性格特点：忠诚、勇敢，有时过度保护。

构成作用：作为团队的保护者，韩磊不太懂科学技术，但能在物理上保护队员，常提供现实生活中的解决方案。

T-7（代号天启）

角色定位：脱离外星监管者的叛逆者，决定帮助林浩。

性格特点：神秘、沉思而深沉，有时表现出机械般的性格。

构成作用：天启作为外星文明的叛逆者，提供了关于外星监管系统的关键内部信息，成为连接人类斗争与外星监管者的纽带。它的参与增加了故事的宇宙性和伦理冲突。

T-7存在于一种人眼不可见的特殊光谱里，它通过影响光的波长与人类沟通，而只有利用特定的接收器才能看到它的“身影”和接收它的信息。这种形态的神秘之处在于，T-7能够嵌入到任何光源之中，成为了科学家手中强有力的实验工具。

辅助人物

陈嘉诚

角色定位：政府高官，外星监管者在地球上的联络人。

构成作用：陈嘉诚在剧情中扮演反派角色，竭力阻止林浩及其朋友揭露真相，同时试图维护自身权力和外星秘密。

王伟

角色定位：联邦安全局局长

构成作用：陈嘉诚导师，知道旧帝国外星文明这一秘密，在组织林浩等人。

苏菲（假名）

角色定位：联邦安全局的情报官。

构成作用：苏菲是一个神秘人物，她父亲早年遭受政府莫须有的妄想症迫害，被关入精神病院，出院后郁郁而终，留给的吊坠秘密被林浩破解，真心实地支持林浩，并与林浩产生出爱情的火花

致命一击方案：光谱逆转

在小说中，致命一击可以被设计为一种科技漏洞的利用，这个漏洞存在于外星人认为完美无瑕的监控系统之中。基于对光的精湛li理解与操控，团队发现了一种方法来逆转外星人所设下的监控机制。

技术原理：

外星监控系统依赖于对光的特殊态——“超态”——进行操控来实施限制。团队发现，尽管外星人封锁了地球文明对此的研究，但光的本质在某些极端条件下会自然展现其另外一种状态：纳秒极瞬态（Nanosecond Ephemeral State，简称NES）。

实施方案：

光谱逆转装置：

利用特殊设计的量子设备产生高强度的脉冲激光，这些脉冲激光能够在极短时间内激发出NES。

当NES与外星监控系统的“超态”光相遇时，会触发一个逆转效应，破坏外星人所依赖的光态控制。

分布式全球网络：

在全球各地建立量子信标，这些量子信标协调发射控制脉冲，形成覆盖全球的NES网络。

这一全球协调操作确保了各地的“超态”操控点同时被逆转，从而使整个监控系统无法执行其功能。

紧急启动密钥：

林浩团队揭露了外星监控系统具备紧急停止协议，该协议能够在探测到系统受重大威胁时激活。

团队将全球网络的NES逆转行动设置为启动紧急停止协议的条件，通过诱导外星系统自我关闭。

执行步骤：

技术验证：

通过小规模实验验证光谱逆转机制的可行性，并保证对“超态”操控的干扰最小化。

全球协同：

密切合作并联合各国的科学机构，在全球部署量子信标设备，并进行实施前的最终协调。

同步启动：

在确保所有量子信标准备就绪后，林浩团队发出全球同步激活NES的指令，影响外星监控系统的全部。

触发紧急协议：

预期中的全面逆转效应促使外星监控系统自动启动了紧急停止协议，导致其在全球范围内瘫痪。

这一致命一击既巧妙又大胆，利用了外星人未曾预料到的自然现象和对光的新理解。团队的创新和合作能力成为了战略行动成功的关键，同时也展示了人类自古以来对光的持续探索和对新知识的不懈追求。

当前故事发展到天才科学家林浩、记者赵雨欣、黑客周杰及其妹妹、退休军人韩磊、苏菲六人在索尔领地领袖库尔马博士提供实验帮助下，通过光子超态林浩等人和外星文明T-7取得联系，T-7告知林浩等人一些秘密，林浩等人和联邦政府谈判取得了胜利，林浩等人试图突破‘以太锁’，计划采取在太阳系做实验，当时当前的观测活动受到了不愿暴露自己，使用了技术直接干预了林浩领导的全球观测数据，林浩等人也发现了数据中的微小异常。
