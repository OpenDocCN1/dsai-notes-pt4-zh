
# 《跃上高阶职场》：探索职场的高度与深度

> 来源：[https://docs.feishu.cn/docx/TJ70dnnFKoWjj1xKWaKcMSfNnxg](https://docs.feishu.cn/docx/TJ70dnnFKoWjj1xKWaKcMSfNnxg)

## 背景

某一天早上听《组织进化论》的播客，刚好听到了 E57｜《跃上高阶职场》马吐兰：先管好自己 这一期，当下才知道有这部近两年很火的综艺。

在接下来的两周，开启了熬夜追剧的日子。

下面沉淀些在看完这部综艺后，一些对个人很有启发的想法与见解~

## 持续学习，保持谦逊

### 保持谦逊

+ 第3集下的时候，Sam对Leong说：你不尊重我，所以你还没有赢得我的尊重。

+ Leong在被Sam说了之后，说：我也在学习，你要有时间允许我学习。随后还询问了Sam说是否能提供一些改进的建议。

+ Leong老师的回复让我颇为受到触动，不管在哪个年龄段，永远都保持谦逊的态度、高情商的回应、以及永远保持学习的心态。

## 明确目标，挖掘潜能

### 放下包袱爱自己

+ 天真老师：爱自己在先，你才会拥有能量，等你拥有能量之后你再去想，这个能量你要用在哪里。

+ 创意大乱斗包子惜败后，Leong对包子说：在职场上，有一个东西，你必须要做的是，就是你必须把负担和包袱放下，身上背着这么多包袱和负担，你是往上爬不了的，放下负担，放下包袱，找一个让自己最舒服的方式，对自己、对他人，都有用。

### 保持自己的节奏

+ 伊琍老师：他强任他强，清风拂山岗，你当温柔又有力量。

### 挖掘潜能

+ 切换赛道，也有可能是另一种前进。

+ 每个人在每个阶段都要有突破，同时，不要被年龄给禁锢住，一直保持着好奇心，保持探索的能力，一定会越来越好。

+ 剧中中间有一部分，安安在努力地写出一个完整的创意文案，不局限于自己。并不能因为我是一个account，就不能写文案。（非常好的例子）

+ 小龙走了之后，还被beck发了offer邀请。天真老师当时的点评是，只要你能力强，此处不留爷，自有留爷处。所以说，在职场，能力是非常重要的。当你非常出色的时候，自然会有被看到的一天。所以在日常中，要不断地去提升我们个人的能力上限。

> 第4集下的时候，八月当组长，挑了凡凡和刘权两名组员。然后在任务开始前，八月是选择了激励的方式，先去挖掘组员们的潜力。当时八月先是提问了一个问题：在一家公司，怎么样能做的让你开心？接着回答了以下两点：

+ 首先你是能被看到你的特长，另外一个就是不足的地方，它有机会让你增长。

+ 所以一定要两点都达成，你才能很开心的在一家公司工作。

> 之后组员们的热情，一下子就被调动起来了。

+ 最后组建S-Team之前，妙妙找了beck聊天。beck对妙妙说：你能力不止设计师，小龙的话可以直接说让他去做设计师。

+ 一些感悟：有些人专精，他就适合纯技术。而有些人的能力边界不止这些，就可以适当的往外扩展，去突破，拿到更大的机会。所以在职业发展的时候，可以多去探索自己的职业边界，明白自己想要什么。

## 稳定情绪，寻找快乐

### 情绪管理

+ Leong老师：能解决问题的同时，又能化解情绪。

+ 自己的内心永远平静，比任何东西都重要。

### 找到快乐

+ 专注自己所爱的事情，也是一种幸福。马伊琍老师说别人问她为什么不去做导演、制片，她说：我觉得那个对我来说是负担，我要让我自己开心。（让自己开心，并且做自己最爱的事情，这才是最好的）

## 积极主动，协作共赢

### 关于天赋

+ 伊利老师说：一个十年的人比不过一个两年的人，这个东西就是天赋。你做哪个行业是天赋，就是老天爷赏你饭吃。

+ 天赋是很容易花光的，在被照耀之后，要去寻找自己的第二个突破口。也就是还需要不断去学习新的知识，让自己的专业能力越来越厉害。

+ 天赋决定你的亮度，但是努力决定你的时长。

### 关于努力

+ 所有人他最重要的东西是他最怕的东西，当你知道这个东西是你最怕的东西的时候，你的努力就会有动力了。

+ 你想要过什么样的生活你自己来赚，你自己来努力。

### 能力+主动=王炸

+ 职场小透明很容易被忽略，所以我们要多去主动去争取自己的权益。默默做事其实不容易被看到，要有能力+主动=王炸。

+ 在职业生涯过程中，要不断去思考，我要解决什么问题，然后抵达什么样的目标。

+ 苏醒当嘉宾的那一期说到：跳槽需要考虑代价。

+ 这让我想起自己的职业规划，会先考虑当下职业对自己发展的前景，能否让自己进步、以及非必要少搬家，或者不搬家。尽量让所有精力都放在最重要的事情上。

### 团队协作

+ 在团队协作上，配合才是关键，信息不同步是团队的大忌。

+ 一把锋利的匕首如果不能找准方向，迟早会刺向自己。

+ 你真正能够跟同事建立信任的是，在关键时刻站出来了。

+ 有时候你的合作伙伴是你的考官，他关系到你在工作过程中的人际关系等等。因为你们都在同一个行业，日后大家说起你都会跟身边的人一起去问，去评价。

+ 当你是一个团队的时候，要不然就是能力上互补，要不就是性格上互补。

### 学会倾听

+ 枕头案子合作的时候，思凡直接拒掉了其他所有文案，沉浸在自己的世界，想要再次证明自己的实力。

+ 伊琍老师点评了一句话：6个人是6个不一样的人生，各个人能提供的观点都很不一样，不要太局限在自己的世界里。

+ 想起之前厂内零度突破小组协作的时候，创意海报的文案部分，分配给不同的组员来做。每个人的想法都很不一样，每个人都有他们不同的想法。最终再根据这些不同的想法，拼接整合，就是一个非常完美且新颖的文案。

## 提升领导力，学会向上社交

### 领导能力

+ 作为领导，或者team leader，要做好主动分工。

+ 平级管理和向上管理是成熟职场必备技能。

+ 在成长过程中，如果遇到好的领导，应该去学他们解决问题的方式，而不是会依赖他们。

+ 不同的人，激励的方式不一样。

## 拥抱变革，培养商业嗅觉

### 创新能力

+ offer4项目的时候，马伊琍老师说了一句话很对，不能被数据裹挟。八月组就是完全用现有数据去分析，而非凡组是在现有数据的基础上，做进一步的分析，分析出甲方最终想要的东西。

+ 间接地也思考到，八月组这个也是小编目前在日常编程和创作过程中会存在的问题，后续应该要勤于突破，不断去精进个人的创新能力。

### ROI最大化

+ 非凡刚来的时候，接了抱枕那个项目，并且承担着团队owner的角色。

+ 非凡在选队伍的时候，会看中很多。因为是项目，短期的，要出结果的。

+ 所以应该是每个人都尽量自己的能力价值最大化，所以她会去选择八月。

+ 一些感悟：在职场上也尽量要这样去让投入产出比ROI最大化，如果做一个事情，长期高投入低回报，那说明肯定某个环节出了问题。

### 商业能力

+ 蛋总：投在广告里的钱，有一半是浪费的，但你永远不知道是哪一半。

+ 很多时候我们需要不断地去弥补信息差，不断地去培养我们敏锐的商业嗅觉，知道自己的产品能为客户和甲方带来什么，不拘泥于当下所做的工作，要不断地去向上思考。
