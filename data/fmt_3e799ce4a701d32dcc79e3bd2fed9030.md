### GitHub Copilot 局限性

GitHub Copilot 尽管是一个功能强大的工具，但开发人员在使用时必须注意其固有的限制和约束。这些限制主要集中在代码质量、对训练数据的依赖性、处理复杂问题的能力以及对不同技术支持的差异方面。

![](img/71fed8f29bd5cbb1d66ccaa6e867c786.png)

以下是 GitHub Copilot 的主要局限性：

#### 一、代码质量和正确性方面的局限性

+ 可能出现错误或不符合要求：GitHub Copilot 有时可能会建议包含 bug 的代码。或者，生成的代码可能未完全满足要求。

+ 安全和最佳实践问题：生成的代码可能并不总是遵循最佳做法。因此，它需要开发人员进行仔细审查，以确保没有引入安全问题。

+ 上下文误解：GitHub Copilot 可能会误解更广泛的上下文，从而可能导致其提供的建议不适当或不准确。

#### 二、依赖于训练数据

+ 建议中的偏差和过时做法：GitHub Copilot 的建议反映了其训练数据中的模式。这意味着其建议可能包括偏差或过时的做法。

+ 版权问题：关于从已培训模型生成的代码的版权影响，目前持续存在争论。

#### 三、解决复杂问题和高级设计方面的限制

+ 高级体系结构设计的限制：GitHub Copilot 擅长处理代码级任务。但是，它可能无法掌握复杂的体系结构决策。

+ 创造力约束：尽管 GitHub Copilot 提供了有力的帮助，但它不能取代人类解决新问题的创造力。

#### 四、特定于语言和框架的差异性

+ 性能不同：GitHub Copilot 的有效性可能因不同的编程语言和框架而异。

+ 利基技术的相关性：对于不太常见或较新的技术（利基技术），GitHub Copilot 提供的建议可能不太准确或相关。

## 使用 GitHub Copilot 工具开发单元测试

GitHub Copilot 通过在单元测试工作流的各个阶段提供自动化和智能建议，极大地支持并增强了其效率。

以下是 GitHub Copilot 如何支持单元测试工作流并提高效率的详细介绍：

### 核心支持与效率提升

GitHub Copilot 通过减少重复过程和确保代码经过全面测试来提高效率。

+ 测试代码生成：Copilot 能够生成覆盖应用程序代码的单元测试、集成测试和端到端测试。

+ 推荐测试用例：如果指定方法签名和正文，GitHub Copilot Chat 可以推荐涵盖输入参数和预期输出值的测试用例。

+ 深度测试覆盖：Copilot 利用代码的上下文和语义来推荐确保函数正常运行的断言。例如，它可以生成断言以确保函数输入参数有效。

+ 处理边缘情况：Copilot 尤其能帮助为难以手动识别的边缘情况和边界条件编写测试用例。它可以建议针对错误处理、空值（`null` 值）或意外输入类型等情况的测试用例。

+ 减少重复：使用代码行补全功能生成单元测试可以减少重复过程，并有助于确保代码经过全面测试。

**重要提示：** 尽管 Copilot 提供了强大的支持，但生成的测试用例可能未涵盖所有可能的方案。为确保代码质量，必须进行手动测试和代码评审。

### 通过多种工具生成测试代码

GitHub Copilot 提供了多种工具和模式来帮助开发人员根据具体需求生成单元测试：

#### 聊天视图模式支持

- 询问模式（Ask Mode）：经过优化用于查询代码项目和技术概念。此模式可用于分析工作区，并为文件中的多个函数或整个文件创建单元测试。

- 编辑模式（Edit Mode）：经过优化用于在代码库中的多个文件中进行编辑。可用于创建或更新测试文件，为文件中的特定函数或整个文件创建测试。

- 智能体模式（Agent Mode）：经过优化用于启动智能体编码工作流，可用于在单元测试过程中自动执行任务。它最适合需要对项目有更深入了解的单元测试创建工作。例如，智能体模式可以搭建测试项目、创建测试文件、运行测试或生成测试报告。

### 支持测试工作流的特定阶段

除了代码生成，Copilot 还支持测试生命周期中的其他关键任务：

#### 设置测试框架

Copilot 可以帮助项目和语言配置正确的测试框架和 VS Code 扩展，从而加速测试工作流。用户可以在“聊天”视图中输入 `/setupTests` 命令，然后遵循 GitHub Copilot 的指导来配置项目。

#### 修复失败的测试

Copilot 与 Visual Studio Code 中的测试资源管理器集成，有助于修复失败的测试：

1. 通过测试资源管理器：将鼠标悬停在失败的测试上，选择 “修复测试失败” 按钮（闪光图标），然后查看并应用 Copilot 的建议修复。

1. 通过聊天视图：输入 `/fixTestFailure` 斜杠命令。

1. 通过智能体模式：智能体模式可以在运行测试时监视测试输出，并自动尝试修复并重新运行失败的测试。

#### 保持一致性

如果组织有特定的测试要求，用户可以自定义 Copilot 生成测试的方式，以确保其符合标准。通过提供自定义说明，可以定制 Copilot 的行为，例如：

+ 指定首选测试框架。

+ 定义测试的命名约定。

+ 设置代码结构偏好。

+ 请求特定的测试模式或方法。

总之，GitHub Copilot 通过自动化测试生成、提供深入的边缘案例建议、协助框架设置以及智能化地修复失败的测试，从而全面增强了单元测试工作流的效率和质量。

GitHub Copilot 商业版（或称 GitHub Copilot Business）是一个强大的生成式 AI 工具，旨在提高组织内部开发人员的工作效率、安全性和实现性。

### GitHub Copilot 商业版关键功能

GitHub Copilot 商业版将生成式 AI 的强大功能集成到编辑器扩展中，提供实时代码建议。

### 技术与性能功能

+ 功能更强大的 AI 模型：采用了新的建模算法，提高了所提供代码建议的质量。

+ 实时建议：根据代码和自然语言提示（例如注释）提供可快速接受或拒绝的多个代码建议。

+ 适应性学习：GitHub Copilot 会与开发人员一起学习，并适应各个编码样式和约定。

+ 编辑器支持：开发人员可以使用自己选择的编辑器，包括 Visual Studio、VS Code、Neovim 或 JetBrains 集成开发环境 （IDE）。

+ 网络兼容性：支持 VPN 代理（包括自签名证书），使开发人员可以在任何工作环境中使用该工具。

### 安全与管理功能（对比个人版）

Copilot 商业版提供了更高级的组织管理和安全控制，这使其区别于 Copilot Pro 或 Free 版本：

+ 基于 AI 的安全漏洞筛选：它能够自动阻止常见的不安全代码建议，方法是定位硬编码凭据、SQL 注入和路径注入等问题。

+ 组织范围的策略管理。

+ 审核日志 （Audit logs）。

+ 排除特定文件：可以从 GitHub Copilot 中排除特定文件。

+ 提高 GitHub 模型速率限制。

### GitHub Copilot 商业版的优势与价值

GitHub Copilot 商业版通过优化工作流程、减少中断，帮助开发人员更快地完成任务，并将精力集中在更具挑战性的工作上。

### GitHub Copilot Enterprise 功能概述

GitHub Copilot Enterprise 提供了多项增强开发体验和提高协作效率的功能，其中许多功能区别于 GitHub Copilot Business 和 Individual 版本。

#### 核心功能和独特优势

#### 知识库和自定义模型（Knowledge Base and Custom Models）

+ 组织所有者可以创建自定义知识库，汇集一个或多个存储库中的 Markdown 文档、代码片段和其他 Markdown 文件。

+ 这些知识库用于帮助培训 GitHub Copilot Enterprise 的知识，以满足组织的特定需求。这是区别于其他 GitHub 产品的独特功能。

+ GCE 允许微调基于公司特定知识库和专用代码生成的专用自定义模型。

+ 利用自定义模型，组织可以获得更准确、更符合上下文的建议和响应，从而增强开发人员的经验和生产力。

#### 根据代码库定制的聊天（Customized Chat based on Codebases）

+ 开发人员可以使用 GitHub Copilot Chat 创建根据代码库定制的提示。

+ 此功能可直接应用于议题、拉取请求、Codespaces 中的代码文件，甚至直接应用于存储库。

+ 团队成员可以在聊天界面中无缝生成、讨论和优化特定于其项目上下文的代码建议，并直接评论、编辑或接受这些建议。

#### 拉取请求摘要（Pull Request Summaries）

+ GCE 允许开发人员根据代码更改生成拉取请求摘要。

+ 其目的是减少创建信息性拉取请求说明所需的时间和精力。

+ 它可以增进了解并加快评审流程，使评审者能够快速了解涉及的更改和需要注意的领域。

#### 使用文档集的文档搜索和摘要（Document Search and Summarization using Document Sets）

+ 文档集是专为组织的特定需求和工作流定制的内部代码和文档的专用自定义集合。

+ GCE 文档集管理可以帮助用户找到所需的答案，并简洁地展示。

+ 例如，它可以回答有关使用特定库或框架的具体问题。

+ 它还会引用与问题相关的现有文档，以便用户可以找到更多上下文信息。

#### 代码评审（Code Review）

+ Copilot 代码评审通过在代码库内提供深入的帮助，将协作提升到更高的级别。

+ Copilot 可以在整个代码库中解释选定的代码片段，帮助开发人员了解其团队成员的意图，并明确代码的复杂部分。

#### 其他企业级功能比较

与 Copilot Business 和 Individual 版本相比，GitHub Copilot Enterprise 提供的功能还包括：

+ 拉取请求中的协作聊天。

+ Copilot 文档集管理。

+ Copilot 代码评审。

+ 代码片段和使用情况遥测的零数据保留。

+ 组织范围的策略管理。

+ 与安全工具集成（GCE 是完全集成，其他版本可能受限或无）。

+ 审核日志和报告（GCE 是全面提供，其他版本可能受限或无）。

+ 通过自签名证书的 VPN 代理支持。
