## 背景

### 什么是 Agent Fine-Tuning

随着大语言模型的发展，研究人员们发现利用大语言模型的指令跟随、推理、检索与理解等多方面能力，来让大语言模型实现对于外部工具的调用，就可以进一步增强大语言模型的能力。这便是智能体。

我们以 `ReAct`（`Reasoning & Acting`，思考+行动+观察）逻辑为例：智能体在 System Prompt 的指引下，根据用户的输入按照规定的格式输出思考结果，然后由相关逻辑解析模型输出、得到工具输出结果并返回给智能体，最后智能体根据工具输出再决定下一步动作，从而最终完成整个任务。

为了让大语言模型强化这些能力，便有了智能体微调，也就是 Agent Fine-Tuning。

### 核心现象

Agent-Flan 论文中提到了现在智能体微调相关工作存在的三个核心现象：

#### 智能体微调数据偏离预训练的数据域

因为大语言模型往往是在对话数据域进行预训练，而最近的智能体微调相关工作在数据方面都采用了固定格式（如 `ReAct`），动作参数相关均为 JSON 格式。这样格式的数据显然与预训练时的对话数据分布不一致，也就导致了智能体任务成为了域外任务。这样一来，智能体微调成为分布外学习，导致学习难度变大。我们这里给出一组例子：

```
对话数据

User：
请你简单介绍一下大语言模型
Assistant：
好的，大语言模型（Large Language Models, LLMs）是一种人工智能技术，它基于深度学习算法，能够理解和生成自然语言。这些模型通常非常庞大，由数十亿甚至数万亿个参数构成，并使用海量的文本数据进行训练。大语言模型的目标是理解和模仿人类的语言使用方式，以便能够执行各种基于语言的任务，如文本翻译、摘要生成、情感分析、问题回答、内容创作等。
```

```
ReAct 数据

System：
你是一个可以调用外部工具的助手，可以使用的工具包括：
[{&quot;name&quot;: &quot;ArxivSearch&quot;, ...}]
如果使用工具请遵循以下格式回复：
Thought:思考你当前步骤需要解决什么问题，是否需要使用工具
Action:工具名称，你的工具必须从 [&quot;ArxivSearch&quot;] 选择
Action Input:工具输入参数
...
开始!
User：
帮我搜索一下 InternLM2 技术报告
Assistant：
Thought: 我应该调用 ArxivSearch 工具去搜索 InternLM2 技术报告
Action: ArxivSearch
Action Input: {&quot;query&quot;: &quot;InternLM2 技术报告&quot;}
...
```

#### 不同智能体相关任务的学习速度不同

智能体能力涉及到了指令跟随、推理、检索与理解等多方面能力，分别对应输出特定格式、思维质量、选择适当的工具、传递工具参数。但是每一方面能力的学习速度有着比较大的区别。Agent-Flan 将训练损失拆分并可视化，观察到了：检索和指令跟随任务的损失下降最快，且稳定时最低；其次是理解任务；稳定时损失最高的是推理任务。这将用于指导训练数据的分解与均衡。

![](img/0bd861bfbdddd9765ef94a1fe70ab527.png)

#### 现有方法忽视了幻觉的普遍与重要性

智能体微调过程中存在着两种幻觉：格式幻觉与工具幻觉。格式幻觉指的是模型没有按照要求的格式进行输出，导致工具调用失败；工具幻觉指的是模型在面对引导性任务的时候，可能会去调用一些根本不存在的工具，导致失败。

## Agent-Flan

### 智能体微调数据与预训练域对齐

为了将智能体微调数据与人类对话数据进行对齐，Agent-Flan 将格式化的数据转为多轮的自然语言对话，通过多轮对话的方式拆解“思考+行动+观察”的模式。这里以上文中的 `ReAct` 数据为例：

```
Agent-Flan 数据

System：
...
User：
帮我搜索一下 InternLM2 技术报告
你现在的想法是什么？
Assistant：
我应该调用 ArxivSearch 工具去搜索 InternLM2 技术报告
User：
你要用什么工具？
Assistant：
ArxivSearch
User：
工具需要什么参数？
Assistant：
query
User：
query的值是什么？
Assistant：
InternLM2 技术报告
User：
接下来按照 ReAct 格式输出，ReAct 格式是：...
Assistant：
...
```

### 智能体相关能力分解与数据均衡

由于之前的工作证明，适当混合训练数据可以让训练效果变得更好。基于上面对于学习速度的分析，Agent-Flan 将智能体微调数据按能力进行分解，并寻找混合权重。

从图中可以看到，当减少推理和理解数据时，最终表现有较为显著的下降。然而减少一半指令跟随和检索数据时，性能收到的影响较小。这也是因为推理和理解任务学习难度较大，具体表现为稳定时损失较高。

![](img/d3d52f99fedaf9b85d625b675534c89e.png)

### 负样本学习以缓解智能体的幻觉

为了衡量模型在智能体任务上的幻觉情况，Agent-Flan 建立了 Agent-H 基准，分别从格式和行动两个层面衡量模型。其中，格式层面指的是模型能不能遵循指令，行动层面包括四种情况：

+ 没工具，正常对话

+ **有工具，正常对话**

+ **没工具，需要调用工具**

+ 有工具，需要调用工具

![](img/4b5b3722fd7872da573206b17560ff7b.png)

通过 Agent-H 基准，可以发现现在的智能体微调方法存在缺陷。因此，Agent-Flan 根据上面提到的行动层面的四种情况加入了适当数量的负样本，即“有工具，正常对话”和“没工具，需要调用工具”
