
## 部署检查与故障排查

### 控制台与源代码检查

+ 点击 "Console"（控制台）标签

+ 看看有没有红色错误信息

1. 查看页面源代码

+ 在页面上右键，选择 "查看页面源代码"

+ 确认代码已经正确加载

### 问题 3：样式或图片没有显示

如果 HTML 结构正常但样式或图片缺失：

#### 检查文件路径

+ CSS 文件路径是否正确

+ 图片路径是否正确

+ 使用相对路径，如：`./style.css` 或 `./images/logo.png`

#### 检查文件是否已上传

+ 回到仓库首页

+ 确认 CSS 文件、图片文件都已上传

#### 检查文件名大小写

+ 确保 HTML 里写的文件名和实际文件名大小写一致

+ Linux 系统区分大小写

### 4.3 成功访问

如果一切正常，你应该能看到：

+ 你的网页正确显示

+ 标题、内容、样式都正常

+ 可以正常交互（如果有 `JavaScript`）

恭喜你！你的网站已经成功上线了！🎉

## 《GitHub Pages 部署指南（精简版）》

**只需要 4 步：**

1. 创建 `Public` 仓库

1. 创建 `index.html` 文件（粘贴你的 HTML 代码）

1. 等 2 分钟，访问 `https://用户名.github.io/仓库名/`

**完成！**

## 第五步：更新网站内容

### 5.1 编辑已有文件

假设你要修改 `index.html`：

1. **进入仓库首页**

+ 访问：`https://github.com/你的用户名/仓库名`

1. **点击要编辑的文件**

+ 点击 `index.html` 文件名

+ 页面会显示文件内容

1. **进入编辑模式**

+ 看到文件内容后，找到右上角的工具栏

+ 点击 `铅笔图标 ✏️`（`Edit this file`）

+ 或者点击文字 `Edit this file`

1. **修改代码**

+ 页面变成编辑模式，可以直接修改代码

+ 按 `Ctrl+F`（`Command+F`）可以查找内容

+ 直接输入或删除即可

1. **预览（可选）**

+ 编辑框上方有 `Edit` 和 `Preview` 两个标签

+ 点击 `Preview` 可以预览（但 HTML 预览效果有限）

1. **提交修改**

+ 滚动到页面底部

+ 在 `Commit changes` 第一个输入框输入修改说明

+ 例如：更新标题 或 修改联系方式

+ 第二个输入框可以写详细说明（可选）

+ 点击绿色按钮 `Commit changes`

1. **等待重新部署**

+ 提交后 GitHub 会自动重新部署

+ 等待 30秒 - 2分钟

1. **刷新网站查看更新**

+ 打开你的网站

+ 按 `Ctrl+F5`（Windows）或 `Command+Shift+R`（Mac）强制刷新

+ 查看更新是否生效

### 5.2 上传新文件

如果要添加图片、`CSS`、`JS` 等新文件：

#### 方法 A：创建文本文件（`.html`、`.css`、`.js`）

1. 点击 `Add file` → `Create new file`

1. **输入文件名**（如 `style.css` 或 `about.html`）

1. **粘贴代码**

1. **提交**

#### 方法 B：上传文件（图片、字体等）

1. **准备文件**

+ 在你的电脑上准备好要上传的文件

+ 例如：`logo.png`、`favicon.ico` 等

1. **进入上传界面**

+ 在仓库首页点击 `Add file`

+ 选择 `Upload files`

1. **上传文件**

+ **拖拽方式：**

+ 直接把文件从电脑文件夹拖到浏览器页面

+ 松开鼠标，文件开始上传

+ **选择方式：**

+ 点击 `choose your files` 链接

+ 在弹出的文件选择窗口选择文件

+ 点击"打开"

1. **可以一次上传多个文件**

+ 同时选中多个文件上传

+ 或者分批上传

1. **提交**

+ 等待上传完成（显示文件名和大小）

+ 滚动到底部

+ 输入提交说明：上传图片 或 添加资源文件

+ 点击 `Commit changes`

#### 方法 C：创建文件夹并上传文件

如果要创建 `images` 文件夹并上传图片：

1. 点击 `Add file` → `Upload files`

1. **创建文件夹：**

+ 在文件名前面加文件夹名和斜杠

+ 例如上传文件时命名为：`images/logo.png`

+ GitHub 会自动创建 `images` 文件夹

1. **上传文件**

1. **提交**

**注意**：在 `Upload files` 界面无法手动创建文件夹，只能通过 `Create new file` 时在文件名前加路径来创建

### 5.3 删除文件

如果要删除某个文件：

1. **点击要删除的文件**

+ 在仓库首页点击文件名

1. **进入删除界面**

+ 点击右上角的 `垃圾桶图标 🗑️`

+ 或者点击三个点 `...` 选择 `Delete file`

1. **确认删除**

+ 滚动到底部

+ 输入删除原因：删除旧文件 或 移除不需要的图片

+ 点击 `Commit changes`

1. **等待重新部署**

+ 删除文件后网站也会自动重新部署

### 5.4 重命名文件

1. **点击要重命名的文件**

1. **点击 `铅笔图标 ✏️`** 进入编辑模式

1. **修改文件名**

+ 在页面顶部的文件名输入框

+ 直接修改文件名

1. **提交**

+ 滚动到底部提交

### 5.5 查看部署状态

想知道修改后的网站是否部署完成：

1. **进入 `Actions` 页面**

+ 在仓库顶部点击 `Actions` 标签

1. **查看部署任务**

+ 会看到 `pages build and deployment` 列表

+ 最上面的是最新的部署

1. **查看状态**

+ `黄色圆圈`：正在部署中

+ `绿色对勾`：部署成功

+ `红色叉号`：部署失败

1. **等待完成**

+ 黄色圆圈通常会在 30秒 - 1分钟后变成绿色对勾

+ 看到绿色对勾后，刷新网站就能看到更新了

## 第六步：完整文件结构示例

### 6.1 简单网站结构

```
my-website/                    (仓库名)
├── index.html                 (首页，必须有)
├── about.html                 (关于页面)
├── style.css                  (样式文件)
├── script.js                  (JS 文件)
└── README.md                  (项目说明)
```

**访问方式：**

+ 首页：`https://用户名.github.io/my-website/`

+ 关于页：`https://用户名.github.io/my-website/about.html`

### 6.2 带子文件夹的结构

```
my-website/
├── index.html
├── about.html
├── css/
│   ├── style.css
│   └── reset.css
├── js/
│   ├── main.js
│   └── utils.js
├── images/
│   ├── logo.png
│   ├── banner.jpg
│   └── favicon.ico
└── README.md
```

**在 HTML 中引用文件：**

```
<!-- 引用 CSS -->
<link rel="stylesheet" href="css/style.css">

<!-- 引用 JavaScript -->
<script src="js/main.js"></script>

<!-- 引用图片 -->
<img src="images/logo.png" alt="Logo">
```

## 第七步：高级技巧

### 7.1 使用 GitHub Desktop（图形界面）

如果你觉得网页操作麻烦，可以用 `GitHub Desktop`：

#### 下载安装

1. 访问：`https://desktop.github.com`

1. 下载并安装 `GitHub Desktop`

1. 登录你的 `GitHub` 账号

#### 克隆仓库到本地

1. 打开 `GitHub Desktop`

1. 点击 `Clone a repository`

1. 选择你的仓库（如 `my-website`）

1. 选择本地保存位置

1. 点击 "Clone"

#### 编辑文件

1. 在电脑上用编辑器（记事本、`VS Code`等）打开文件

1. 修改并保存

#### 提交和推送

1. 回到 `GitHub Desktop`

1. 左侧会显示所有修改的文件

1. 在左下角输入提交信息（如"更新首页"）

1. 点击 `Commit to main`

1. 点击右上角的 `Push origin`

1. 修改会自动上传到 `GitHub`

### 7.2 使用命令行（Git）

#### 安装 Git

+ **Windows：** `https://git-scm.com/download/win`

+ **Mac：** 打开终端输入 `git --version`（会提示安装）

+ **Linux：** `sudo apt install git`（Ubuntu/Debian）

#### 克隆仓库

```
git clone https://github.com/你的用户名/仓库名.git
cd 仓库名
```

#### 修改文件后提交

```
# 查看修改
git status

# 添加所有修改
git add .

# 或添加单个文件
git add index.html

# 提交
git commit -m "更新首页内容"

# 推送到 GitHub
git push
```

#### 拉取最新代码

```
git pull
```

### 7.3 自定义域名

如果你有自己的域名（如 `www.mysite.com`）：

#### 在 GitHub 设置

1. 进入 `Settings` → `Pages`

1. 在 `Custom domain` 输入框输入你的域名

1. 点击 `Save`

1. 勾选 `Enforce HTTPS`

#### 在域名服务商设置 DNS

添加以下记录（以阿里云为例）：

**方式一：使用 A 记录**

```
类型：A
主机记录：@（或 www）
记录值：185.199.108.153
       185.199.109.153
       185.199.110.153
       185.199.111.153
```

**方式二：使用 CNAME 记录**

```
类型：CNAME
主机记录：www
记录值：你的用户名.github.io
```

#### 等待生效

+ `DNS` 生效时间：几分钟到 48 小时

+ 可以用 `https://dnschecker.org` 查询是否生效

### 7.4 添加网站统计

#### 使用 `Google Analytics`

1. 注册 `Google Analytics`

+ 访问：`https://analytics.google.com`

+ 创建账号和属性

+ 获取跟踪代码

1. **添加到网站**

+ 编辑 `index.html`

+ 在 `<head>` 标签内添加跟踪代码：

```
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

1. **提交更新**

1. **查看统计**

+ 24小时后在 `Google Analytics` 查看访问数据

### 7.5 添加 favicon（网站图标）

#### 准备图标

1. 制作一个 `16x16` 或 `32x32` 像素的 `.ico` 文件

1. 或使用在线工具转换：`https://www.favicon-generator.org`

#### 上传到仓库

1. 在仓库根目录上传 `favicon.ico` 文件

1. 或上传 `PNG` 格式：`favicon.png`

#### 在 HTML 中引用

编辑 `index.html`，在 `<head>` 标签内添加：

```
<!-- ICO 格式 -->
<link rel="icon" href="favicon.ico" type="image/x-icon">

<!-- PNG 格式 -->
<link rel="icon" href="favicon.png" type="image/png">

<!-- 多种尺寸 -->
<link rel="icon" sizes="16x16" href="favicon-16x16.png">
<link rel="icon" sizes="32x32" href="favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="apple-touch-icon.png">
```

### 7.6 添加 SEO 优化

在 `index.html` 的 `<head>` 标签内添加：

```
<meta property="og:image" content="https://用户名.github.io/仓库名/images/share.jpg">

<meta name="twitter:image" content="https://用户名.github.io/仓库名/images/share.jpg">
```
