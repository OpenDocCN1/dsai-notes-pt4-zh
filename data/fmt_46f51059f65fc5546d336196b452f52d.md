## 一、🧩 结构化思维：让混乱想法变清晰框架

![](img/11b596e3be829cc2457a2ab10a2c545f.png)

### 1、这个技能解决什么问题？

你有没有过这种体验：脑子里明明有很多想法，但就是说不清楚？或者开完会记了一堆笔记，回头看完全不知道重点在哪儿？

结构化思维这个技能，核心用的是麦肯锡的 MECE 原则，全称是 Mutually Exclusive， Collectively，即⌈相互独立，完全穷尽⌋，把你脑子里乱糟糟的想法，转化成逻辑严密的思维导图。

#### （1）项目启动阶段：从零星点子到完整方案

```

- 做裂变活动
- 发优惠券
- 找 KOL 合作
- 建用户社群
- 优化落地页
- 设计推荐奖励
```

| --- | --- |

### 3、为什么这个技能这么好用？

细心的小伙伴已经发现，这个技能的核心并不在于⌈帮你想点子⌋，而在于⌈帮你整理点子⌋。它就像一个超级助理，把你脑子里的碎片化信息，自动归类、排序、补充，最后输出一个可执行的方案。结构化后的方案在团队沟通时，理解成本也会大幅降低。

## 二、📚 费曼学习教练：让知识真正变成能力

![](img/379b88fb318c583bca047866a5698447.png)

### 1、这个技能解决什么问题？

相信大家都有过这种体验：

看完一篇文章觉得⌈懂了⌋，合上书却说不出个所以然？或者学了一堆理论知识，到实际工作中完全不知道怎么用？

而费曼学习教练这个技能，核心理念来自诺贝尔物理学奖得主理查德·费曼的学习方法：如果你不能用简单的语言向外行人解释清楚一个概念，那说明你还没真正理解它。

这个技能会像一个学习陪练伙伴一样，通过对话式提问，引导你主动输出知识。它不会直接给你答案，而是通过四个步骤帮你把知识⌈讲出来、想明白、用起来⌋:

1. 深挖理解：通过类比和原理解释，检验你是否真懂

2. 落地应用：设计具体场景和行动步骤，让知识变得可用

3. 反思边界：识别误区和局限，避免盲目套用

4. 总结确认：整理完整的知识框架，明确哪里懂、哪里还需要补

### 2、一个典型使用场景

场景还原：

你刚看完一篇关于⌈增长黑客⌋的文章，觉得自己理解了，但让你给同事讲讲，却不知道从哪儿说起。

让我们打开YouMind，直接启动费曼学习教练技能，AI 会像朋友聊天一样，通过一系列问题引导你主动输出知识。

![](img/a958d86b23d539e9db31aa91fefea1d1.png)

来对比下，有无 Skill 的情况下，前后的差异：

| 使用前 | 使用后 |

| --- | --- |

| 觉得自己懂了，但说不清楚 | 能用大白话向外行人解释清楚核心逻辑 |

| 概念停留在理论层面 | 通过对话的方式，梳理出具体的应用场景和步骤 |

| 不知道哪里没理解透 | AI 通过追问帮你发现理解盲区 |

| 学完就忘，无法内化 | 在主动输出的过程中，知识真正变成自己的 |

### 3、为什么这个技能这么好用？

这个技能特别适合学习那些⌈看起来懂，用起来废⌋的知识。

关键在于，它不会直接给你答案，而是通过提问和启发，让你在⌈努力回忆+被启发⌋的过程中，把知识真正变成自己的。

## 四、🌉 智能桥接：跨界连接创造新价值

![](img/e96312f82c1dd244233c81dd4eb66121.png)

### 1、什么是⌈隐性连接⌋？

你有没有想过，⌈咖啡⌋和⌈编程⌋能有什么关系？但星巴克就把这两个看似无关的东西连接起来，创造了⌈第三空间⌋的概念，成为程序员的办公室。

智能桥接这个技能，核心就是帮你找到两个看似无关节点之间的⌈隐性连接⌋，然后利用美第奇效应（跨界创新）创造新洞察。

美第奇效应来自文艺复兴时期，美第奇家族资助了来自不同领域的艺术家、科学家、哲学家，他们的交流碰撞出了无数创新。现代商业中，很多突破性创新都来自跨界连接：

+ iPhone = 触摸屏 + 互联网

+ Airbnb = 住宿 + 社交 + 共享经济

+ 📕 = 电商 + 社区 + 内容

### 2、实际应用场景

场景还原：

比如说，你在做一个健身 APP，但却找不到一个全新的增长点。

这时候你需要是⌈换个角度想⌋——如果把健身和其他领域连接起来，会产生什么化学反应？

测试 Prompt 参考👇🏻：

```
请帮我找到「健身」和「社交」之间的隐性连接，并给出 3 个可执行的产品创新方向。
```

### 3、技能独特价值

市面上大部分 AI 工具都是⌈在同一个领域内优化⌋，但智能桥接是⌈跨领域创新⌋。它能帮你看到别人看不到的机会，这在竞争激烈的市场中尤其重要。

一旦你有任何想要做「跨领域创新」的点子，都可以快速使用智能桥接功能，来帮助你快速做决策。

## 五、😈 魔鬼代言人：让你的方案经得起推敲

![](img/95ee8b624124d9761ef35f26ea156a21.png)

### 1、什么是⌈红队测试⌋？

在网络安全领域，⌈红队⌋专门负责攻击自己公司的系统，找出漏洞。魔鬼代言人就是把这个思维应用到日常工作中，专门挑你方案的毛病。

### 2、为什么需要这个技能？

很多时候，我们做方案时会陷入⌈自我感觉良好⌋的陷阱，觉得自己的想法天衣无缝。但真正拿出去执行时，才发现到处是坑。

魔鬼代言人会模拟最挑剔的甲方、最毒舌的同事、最理性的投资人，从逻辑、数据、可行性等多个维度来攻击你的方案。

### 3、具体怎么用？

场景还原：

比如说，你准备了一个融资 BP，想在路演前检查一遍。

测试 Prompt 参考👇🏻：

```
这是我的融资 BP 核心内容：
- 市场规模：100 亿
- 目标用户：18-35 岁白领
- 商业模式：订阅制 + 广告
- 竞争优势：AI 算法更精准

请扮演一个挑剔的投资人，找出这个方案的所有漏洞和逻辑谬误。
```

最终生成效果如下：

![](img/511e9b245e3d131d3f146baed4322aad.png)

### 4、使用建议

可以发现，魔鬼代言人技能，会快速地帮你找到逻辑漏洞，并给你合适的补救建议。

这个技能有点⌈反人性⌋，因为没人喜欢被批评。但从经验来看是：越早被⌈魔鬼⌋批评，越晚被现实打脸。

非常建议在每个重要方案定稿前，都用这个技能过一遍😉

## 六、🎬 瞬间演示：从混乱信息到精美幻灯片

![](img/ce2735fbd94584b825a9a01a8b8c0a6c.png)

### 1、这个技能解决什么问题？

很多时候，我们会遇到这种情况：

手里有一堆资料，但不知道怎么组织成一个有说服力的演示？或者做 PPT 时，不知道该用什么结构？

瞬间演示会从你的混乱信息中提取⌈叙事弧线⌋，自动选择最合适的演示结构，然后重组为有说服力的幻灯片大纲。

### 2、四种动态结构适配

这个技能一个厉害的地方在于，它会根据你的内容类型，自动选择最合适的演示结构：

| 内容类型 | 推荐结构 | 适用场景 |

| --- | --- | --- |

| 过程/历史 | 时间轴结构 | 产品发展历程、项目进度汇报 |

| 复杂概念 | 金字塔原理 | 战略规划、商业模式讲解 |

| 多方案对比 | 横向对比结构 | 竞品分析、方案选择 |

| 散点灵感 | 聚类归纳结构 | 头脑风暴总结、创意提案 |

### 3、实际操作流程

#### Step 1 - 输入原始信息

```
我要做一个关于【AI 在教育领域的应用】的演示，目标听众是【教育行业投资人】，
我手里有这些素材：
- AI 可以个性化推荐学习内容
- 市场规模数据
- 3 个成功案例
- 技术实现难点
- 商业模式设想
```

#### Step 2 - AI 分析并选择结构

YouMind会判断这是⌈商业提案⌋类型，适合用⌈痛点-解决方案-效果展示-商业价值⌋结构。

接着，YouMind会帮你输出 PPT 的结构和配图👇🏻：

![](img/9610fcd7d83d47b5c4a3051beabfbc35.png)
