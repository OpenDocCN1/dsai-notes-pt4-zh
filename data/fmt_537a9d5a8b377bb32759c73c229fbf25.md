
# TransformerBlock 与 RMSNorm

## TransformerBlock 代码实现

```python
class TransformerBlock(nn.Module):
    """ Transformer block: communication followed by computation
    """
    def __init__(self, layer_id: int, args: ModelArgs):
        super().__init__()
        self.n_heads = args.n_heads
        self.dim = args.dim # 4096
        self.head_dim = args.dim // args.n_heads # 4096 // 32

        # ATTN
        self.attention = Attention(args)
        
        # FFN
        self.feed_forward = FeedForward(
            dim=args.dim,
            hidden_dim=4 * args.dim, # 16384
            multiple_of=args.multiple_of, # 1024
            ffn_dim_multiplier=args.ffn_dim_multiplier, # 1.3
        )
        self.layer_id = layer_id
        self.attention_norm = RMSNorm(args.dim, eps=args.norm_eps)
        self.ffn_norm = RMSNorm(args.dim, eps=args.norm_eps)

    def forward(
        self,
        x: torch.Tensor,
        freqs_cos: torch.Tensor,
        freqs_sin: torch.Tensor,
    ):
        # (B, seq_len, dim) + (B, seq_len, dim) --> (B, seq_len, dim)  (torch.Size([1, 17, 4096]), torch.Size([17, 64]), torch.Size([17, 64]))
        h = x + self.attention(self.attention_norm(x), freqs_cos, freqs_sin)
        out = h + self.feed_forward(self.ffn_norm(h))
        return out
```

## RMSNorm 介绍

### 目的

- 目的：一种替代Layer Normalization的方法，RMS Norm 通过计算特征的均方根来标准化输入。它减少了对均值的依赖，适用于不同的输入分布。

### 特点

- 特点：计算效率高，适用于大规模模型。

1.   ：表示神经元的输入总和，通常是经过加权的模型参数的输出。

2.  ：均方根值，作为输入的标准化因子，提供输入幅度的度量。它帮助在不同的输入和权重缩放情况下保持输出的稳定性。

3.  ：归一化后的输出，经过RMS标准化的神经元激活值。

4.  ：增益参数，允许模型对归一化后的输出进行重新缩放。通常初始化为1，但在训练过程中可以更新。

5.  ：默认 1e-6，是一个很小的数字，加在分母用于数值稳定性。

### 设计目标

RMSNorm的设计目的是提高计算效率，同时保持归一化的优点，如稳定训练过程和增强模型收敛性。与传统的`LayerNorm`不同，`RMSNorm`不执行均值归一化，从而简化了计算，减少了开销，特别适用于大型模型或需要快速迭代的任务。

## RMSNorm 代码实现

```python
class RMSNorm(torch.nn.Module):
    """ Root Mean Square Layer Normalization
    """
    def __init__(self, dim: int, eps: float = 1e-6):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(dim))

    def _norm(self, x):
        # (B, seq_len, dim)
        return x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

    def forward(self, x):
        output = self._norm(x.float()).type_as(x)
        # (dim) * (B, seq_len, dim) --> (B, seq_len, dim)
        return output * self.weight
```
