## 🎓 专业评价

### [Andrej Karpathy](https://twitter.com/karpathy)

founding team @ OpenAI

#### 模型性能与规模

+   发布了8B和70B参数的模型，包括基础和微调版本，性能在其类别中表现出色。

+   400B参数的模型仍在训练中，已接近GPT-4的性能水平。

#### 分词器改进

+   分词器的`Token`从`Llama 2`的32K增加到128K，提高了压缩序列的能力，减少了令牌使用，并提升了下游性能。

#### 架构优化

+   架构上没有大的变化，但所有模型包括最小的`8B`模型都采用了分组查询注意力（`GQA`），这是一种参数共享方案，优化了推理过程中的`KV`缓存大小。

#### 序列长度增加

+   模型的上下文窗口最大`Tokens`从`Llama 2`的4096增加到8192，尽管增加幅度不大，但对现代标准而言仍有提升。

#### 训练数据集扩展

+   `Llama 3`的训练数据集从`Llama 2`的2万亿个`tokens`增加到了15万亿个`tokens`，注重质量，增加了代码`tokens`和多语言支持。

#### 规模定律与训练

+   15T的训练数据集对于8B参数的模型来说是非常大的，通常不会这样做，但这种训练规模的增加是非常受欢迎的。

#### 系统与训练效率

+   `Llama 3`使用16K `GPU`进行训练，达到了400 `TFLOPS`的吞吐量，显示出良好的`GPU`利用率。

### [Ahmad Al-Dahle](https://twitter.com/Ahmad_Al_Dahle)

Leading GenAI @ Meta

#### 主要亮点

• 公开可用的预训练和微调模型，参数量分别为`8B`（80亿）和`70B`（700亿）。

• 在超过15万亿个令牌上进行训练，数据集大小是`Llama 2`的7倍多！

• 改进的分词器，128K `Tokens`，以提高性能。

• 在行业基准测试中表现领先。

• 新增能力，包括增强的推理和编码能力。

• 比`Llama 2`的培训效率高出3倍。

• 引入新的信赖和安全工具，包括`Llama Guard 2`、`Code Shield`和`CyberSec Eval 2`。

• 已集成到`Meta AI`中，并在更多国家中可用。

## 🤝 使用体验 & 最佳实践（持续补充中）

### langchain中使用llama3

#### 安装ollama

安装`ollama`:`curl -fsSL https://ollama.com/install.sh | sh`

![](img/036245bfd32e252570c6efb888774f88.png)

使用`ollama`运行`llama3`:`ollama run llama3`

建议先指定运行在那张`GPU`上:`export CUDA_VISIBLE_DEVICES=0`（当设置其他编号`GPU`时,发现次命令无效,还是非常顽固得在0号`GPU`上运行）

![](img/6925334b6e5b097a0946fad699c39c2b.png)

首次运行会下载4bit量化版本的模型.

![](img/421db76cdb0c4113365626ecd7f4e7cd.png)

退出命令行对话:`/bye`

#### 在langchain中通过ollama使用llama3

```
from langchain_community.llms import Ollama
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain.prompts import ChatPromptTemplate

llm = Ollama(model="llama3")

prompt_template = "system:{system}\nuser:{user}"
prompt = ChatPromptTemplate.from_template(prompt_template)
ra_chain = (
    prompt
    | llm
    | StrOutputParser()
)

response = ra_chain.invoke({"system": "请用中文回答问题", "user": "请介绍东北大学?"}) 
```

#### ollama在指定GPU上运行

**问题描述**

使用`ollama`运行LLM,不在指定的`GPU`上运行.

**解决方法**

```
ps aux | grep "ollama serve"
sudo service ollama stop
CUDA_VISIBLE_DEVICES=1 ollama serve
```
