看到网上很多人都说`prompt`很难写，写不好，但对新手来说，其实是有"捷径"的，而这个捷径就是`prompt`框架。

框架可以帮助我们更好地组织思维，确保信息的一致性和完整性。

框架为思考提供了一种结构化的途径，使得处理复杂问题时可以更加系统和全面。它们在分析、决策或执行计划时提供了方法论支持，特别是在需要处理复杂或多变环境的商业决策中尤为重要。

以下是最全的13个`prompt`框架

## BARD

1. 阐述背景Background: 提供清晰的背景信息，说明任务的上下文环境

2. 定义目标Aim: 在提示词中要清晰地陈述你的具体问题或具体任务

3. 设定角色Role: 明确地指出在对话中用户和ChatGPT的角色

4. 设置要求Demand: 你对输出的具体要求，风格、语气、格式等任何限制

## APE

1. Action 行动:定义要完成的工作或活动。

2. Purpose 目的:讨论意图或目标。

3. Expectation 期望:说明期望的结果。

## BRTR

1. 背景(B)：在什么平台做什么主题的账号，受众是谁，目标策略、人设、风格等

2. 角色(R)：设定对的专家身份+特定经验技能

3. 派任务(T)：简要介绍写作任务的方向、效果预期

4. 提要求R）：语谱言风格、内容结构、写作技巧、模仿示例、创作流程

## RACE

1. 背景:设置讨论的舞台或背景。

2. 行动:描述您想要做什么。

3. 结果:描述期望的结果。

4. 示例:举一个例子来说明你的观点.

## BROKE

1. 阐述背景B(Background):说明背景，为chatGPT提供充足信息

2. 定义角色R(Role):“我们希望chatGPT扮演的角色”

3. 定义目标O(Objectives):“我们希望实现什么”

4. 定义关键结果K(Key Result):“我要什么具体效果”

5. 试验并调整，改进E(Evolve):三种改进方法自由组合

   a.改进输入:从答案的不足之处着手改进背景B，角色R，目标O与关键结果K

   b.改进答案:在后续对话中指正chatGPT答案缺点

   c.重新生成:尝试在`prompt`不变的情况下多次生成结果，优中选优

## ICIO

1. Instruction （指令）：你希望模型执行的具体任务

2. Context （背景信息）：或者说是上下文信息，这可以引导模型做出更好的反应

3. Input Data （输入数据）：告知模型需要处理的数据

4. Output Indicator （输出引导）：告知模型我们要输出的类型或格式。

## RTF

1. 角色:指定 ChatGPT 的角色，即chatgpt扮演的角色。

2. 任务:定义具体任务。

3. 格式:定义您想要的答案的方式。

## CRISPE

1. Capacity and Role（能力与角色）：希望大模型扮演的角色。

2. Insight（洞察）：背景信息和上下文。

3. Statement（陈述）：希望大模型做什么。

4. Personality（个性）：希望大模型以什么风格或方式回答。

5. Experiment（实验）：要求大模型提供多个答案。

## TRACE

1. Task (任务）：需要大模型完成什么任务

2. Request （请求）：需要大模型提供什么样的帮助或资源以完成任务

3. Action（行动）：完成任务，需要执行的具体步骤

4. Context（背景信息）：任务的重要性或任务的补充信息

5. Example（示例）：提供一个或多个相关的具体示例

## ROSSS

1. Role 角色:指定 ChatGPT 的角色。

2. Objective 目标:说明目的或目标.

3. Scenario 场景:描述情况。

4. Solution 解决方案:定义期望的结果,

5. Steps 步骤:询问达成解决方案所需的行动。

## CREATE

1. Clarity 清晰度:明确界定提示的任务或意图。

2. Relevant info 相关信息:提供相关细节，包括具体的关键词和事实语气、受众、格式和结构。

3. Examples 实例:使用提示中的示例为输出提供背景和方向。

4. Avoid ambiguity 避免含糊不清:重点关注关键信息，删除提示中不必要的细节。

5. Tinker 迭代、修补:通过多次迭代测试和完善提示。

## TAG

1. Task 任务:定义具体任务， 需要chatgpt完成什么任务 。

2. Action 行动: 描述需要做什么，越详细越好。

3. Goal 目标:解释最终目标。

## COSTAR

1. 背景（C）：提供任务的关键背景信息或情境。这有助于模型理解其所处的特定场景或领域，从而生成更贴切的回答。

2. 目的（O）：明确表达提示的目标。具体说明你希望模型达成的目标，确保其专注于实现这一目标。

3. 风格（S）：设定期望的回答风格。这可以是模仿特定职业的写作风格，如科学家或记者，或是模仿特定类型文本的叙述语气。

4. 语气（T）：确定回答的情感或态度。无论是正式、随意、热情还是富有同理心，设定合适的语气以确保模型的回答与预期情感相符。

5. 受众（A）：明确回答的目标读者。根据读者群体，如专家、初学者或普通读者，调整内容和复杂度，以提高理解和参与度。

6. 格式（R）：指定期望的回答格式。这可以是列表、报告、JSON对象或叙述等。明确格式有助于生成适合后续分析、展示或处理的回答。
