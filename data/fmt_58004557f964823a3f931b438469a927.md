## 1️⃣ [精准提取数据太折磨人，试下 `pip install -U contextgem`，自动生成提示 | 痛快](https://mp.weixin.qq.com/s/V4xyCkUG88z4GJPXZp__uw)

> 🎯

- `ContextGem` 是专注“结构化提取”的免费开源 LLM 框架，解决文档数据提取难题，可作 RAG 前置处理器等。
- 安装简单，通过声明式 API 定义提取概念，结合 LLM 实现结构化数据提取，实战效果佳。
- 引入 `SAT` 神经网络模型，基于 Transformer 架构，提升提取质量，优于传统分段方法。
- 以 `Document` 为核心，通过 `Aspect` 与 `Concept` 组织信息，提供多种概念类型。
- 具备自动提示生成等优势，适用于法律合同分析等多领域。

关键词：`ContextGem`，LLM 框架，结构化提取，`SAT` 模型，文档处理

## 3️⃣ 谷歌开源基于物理模拟的气象模型，能预测暴雨、台风、大干旱

> 🤖

- 谷歌开源基于物理模拟的神经通用环流气象模型 `NeuralGCM`，以克服传统气象模型在处理小尺度物理过程的局限。
- `NeuralGCM` 结合物理模拟与深度学习，其动态核心解决大气方程，物理模拟模块对小尺度过程参数化。
- 独特神经网络架构及编码器、解码器设计，采用端到端训练方法提升性能。
- 经多方面测试，`NeuralGCM` 在预测恶劣天气上表现出色，分辨率提高时谱更准确。
- 该模型在水预算、地理风平衡方面也有良好表现。

关键词：`NeuralGCM`，气象模型，物理模拟，深度学习，开源

## 5️⃣ [大模型入门指南 - Prompt Engineering：小白也能看懂的“提示词工程”全解析](https://mp.weixin.qq.com/s/PSzkKStJkBAUO8EQNHHSjw)

> 🎯

- 提示词工程通过设计优化输入提示词，引导大模型生成更精准答案，普通用户无需懂代码就能“编程”大模型。
- 完整提示词包含指示、上下文、例子、输入及输出格式描述等要素。
- 技术实现由角色定义、任务拆解、场景限定、示例教学四大要素构成。
- 角色定义可框定 AI 思考边界，任务拆解能防止 AI 跑偏，场景限定避免不相关推荐，示例教学可把控输出风格。
- 提示词工程有助于解锁大模型生产力，提升输出质量。

关键词：大模型，提示词工程，技术实现，输出优化

## 6️⃣ [Long CoT 前沿研究速览](https://mp.weixin.qq.com/s/m04no0szcOouiv_dk8l91g)

> 🤖

- 探索解锁大语言模型通用长链思考推理能力，提出 `GLoRE` 方法。
- 研究强化学习对大语言模型数学推理能力提升的影响。
- 关注模型在推理任务中的过度思考、推理长度与任务难度不匹配等问题，提出多种优化策略。
- 探讨如何高效训练推理模型，如 `FASTCURL` 方法及不同训练方式的影响。
- 分析长链推理训练成本、推理效率及模型性能间的关系，提出相应框架与策略。

关键词：大语言模型，长链思考推理，强化学习，推理优化，训练效率
