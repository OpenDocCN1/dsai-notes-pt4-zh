## 四、GPT4o调用测试

接下来打开Jupyter输入如下代码测试调用方法：

安装`openai`库：

```
!pip install openai
```

导入`openai`库，创建`client`对象

```
from openai import OpenAI
```

若是国内网络，则需要额外加入反向代理地址：

```
client = OpenAI(api_key="YOUR_API_KEY", base_url='proxy_url')
```

此处`"YOUR_API_KEY"`需要填入自己的`API-KEY`，或根据置顶评论领取`API-KEY`。此处`'proxy_url'`需要输入国内反向代理地址，可根据视频置顶评论领取。
