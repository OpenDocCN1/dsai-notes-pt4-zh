## 02.

**再看看它为 Agent 准备了什么。**

这才是我觉得最震惊最喜欢的地方。

**LibTV从产品设计的第一天起，就**同时面向两类用户：人类创作者和Agent。

对于Agent来说，LibTV是一组可以直接调用的创作能力，通过Skill接口，Agent可以理解任务、调用模型、编排工作流，自动完成创作。

简单说，你可以让小龙虾（OpenClaw）帮你做视频。

这个Skill的GitHub链接：[https://github.com/libtv-labs/libtv-skills](https://github.com/libtv-labs/libtv-skills)

首先是Skill的安装，简单2步：

1. 通过 `npx skills` 一键安装技能到你的项目中：

```
# 交互式选择要安装的技能
npx skills add libtv-labs/libtv-skills

# 直接安装指定技能
npx skills add libtv-labs/libtv-skills --skill libtv-skill
```

2. 安装完成后，设置环境变量即可使用：

```
export LIBTV_ACCESS_KEY="your-access-key"
```

**补充：**`your-access-key`，在界面右上角的个人中心里：

![](img/d70f104986c9f9388fc5bf2c35f5a48c.png)

很快就配置好了！

![](img/296aba83d30ce36542b4d9adb77c4d5f.png)

**接着**，你只需要输入一句话描述你的需求，Agent就会自动完成剧本生成、分镜设计、视频生成和剪辑，直接产出完整的视频作品。

而且LibTV已经开放了多种核心Skill：

1. **短漫剧生成Skill：**一句话生成5分钟短剧，Agent自动完成剧本、角色设计、分镜、视频、音效、剪辑。
2. **爆款视频复刻Skill：**输入一个视频URL，Agent解析原片的镜头语言和风格，重新演绎为一部全新作品。
3. **音乐MV生成Skill：**输入一段音乐，Agent分析节奏与情绪走向，生成匹配的视觉叙事，剪辑成片。

直接对话就可以调用，你的AI自己就能给你拍广告、做短剧了。

## 04.

**这两天深度使用下来**，我能感受得到LibTV的产品理念，我觉得这个是最值得聊的。

**LibTV**的宣传语是：你可以做电影，你的Agent也可以。

这句话看着简单，细品很有味道。

以前我们觉得AI工具要么太简单，只能聊天，要么太复杂，需要写代码。创作者要么被工具绑架，要么被工具抛弃。

但**LibTV**想构建的是一种新的创作结构：人负责选择与审美，Agent负责执行与扩展。

![](img/ca8959161b8ae565f1096e15b715cda9.png)

你可以在画布上落下第一笔，Agent已经在理解你的意图；Agent生成10个方案的时候，社区里无数创作者的审美偏好已经在替它筛选；当一个人调出一套绝妙的节奏时，它会变成一个Skill，流进千万个Agent的工具箱。

这是人和AI共同创作的交响。

我始终相信，真正决定作品高度的是人的判断与审美。

AI可以帮你执行、帮你扩展，但最后的选择权在你手里。

**LibTV**让这件事变得更简单了：

你可以做电影，你的Agent也可以。
