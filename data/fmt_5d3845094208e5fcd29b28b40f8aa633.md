## 一、全国IT教育培训机构全景图

1. 传智教育：教育行业 A 股 IPO 第一股，涵盖 JavaEE、Python + 大数据开发等十余门学科，在全国有多所分校，是工信部软促中心战略合作伙伴和国家信息技术紧缺人才培养工程人才培养标准制定者。
2. 达内教育：美股上市企业，专注 IT 职业教育，在中国 70 个大中城市建立 373 家学习中心，合作院校 1200 家，累计培训学员 100 万人次以上。
3. 千锋教育：教育部教育管理信息中心指定移动互联网实训基地，开设 HTML5 大前端培训、JavaEE + 分布式开发培训等多种课程，在全国多地设有分公司。
4. 黑马程序员：传智教育旗下高端 IT 教育品牌，以高品质教学质量赢得好口碑，开设 python + 数据分析、java 培训等十多个精品学科，19 所直营分校遍布全国。
5. 国信安职业培训学校：隶属于电科集团旗下的高技能 IT 教育培训机构，成立于 2002 年，业务涵盖研发、测试、教育、人才培训和就业服务。
6. 优就业：中公教育 IT 培训品牌，提供多种 IT 培训课程，具有一定的品牌影响力和教学资源。
7. 动力节点：成立于 2009 年，专注 Java 单科教育，因高就业率被业界誉为 “口口相传的 Java 黄埔军校”。
8. 北大青鸟：专注于职业教育的教育科技公司，推出 BCSP 软件开发专业、BCNT 网络运维专业等多种课程。
9. 尚硅谷：知名的专业 IT 教育培训机构，拥有北京、深圳、上海三处基地，开设大数据运维 + Python 自动化、Java 等多门学科。
10. 老男孩教育：专注互联网 IT 技术人才培训和企业内训的知名教育机构，是 python 编程培训、Linux 云计算运维的行业领军者。
11. 东方瑞通：致力于成为提供全品类、线上和线下综合教育服务的集团公司，解决职业教育的效率问题。
12. 誉天教育：引入大厂技术人才，成立研究院和培训院，致力于使课程研发和师资培训精细化、品质化、专业化。
13. 云和数据：拥有全国一体化就业保障服务，成为学员信赖的IT职业教育品牌。
14. 万和教育：知名的专业IT教育培训机构，拥有北京、深圳、上海三处基地，已开设大数据运维+Python自动化、Java、HTML5前端+全栈、大数据、人工智能、Android+HTML5混合开发等多门学科。
15. 思博教育：是专注互联网IT技术人才培训和企业内训的知名教育机构，是python编程培训、Linux云计算运维的行业领军者。
16. 泰克教育：以体系化、深度讲解、注重原理和实战为特点，目标是帮助学员掌握扎实的IT技能并实现就业或职业提升。
17. 腾科教育：采用小班教学和一对一辅导的方式，确保每个学员都能掌握所学知识。
18. 思科教育：和众多企业建立了合作关系，为学员提供了丰富的就业机会。
