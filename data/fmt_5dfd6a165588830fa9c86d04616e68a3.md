
# 一文搞懂-从 RAG 到 Agent Memory 的演进

> 来源：[https://qqs7y1hozd1.feishu.cn/docx/RqoVdt9xUoa58AxNdVpcuJb3n5i](https://qqs7y1hozd1.feishu.cn/docx/RqoVdt9xUoa58AxNdVpcuJb3n5i)

## 一、RAG：Retrieval-Augmented-Generation

检索增强生成的概念最初是在2020年提出的，2023年流行起来的基础技术。RAG技术通过外部向量数据库注入知识，解决LLM出现的幻觉问题。实现该技术总共分为两步：

![](img/3ee596722fb20f9b9cd00f80d8b3f9bf.png)

> （1）离线阶段将文档嵌入并进行存储；
> （2）在线阶段根据检索，召回与`query`相关的上下文，并与提示词进行拼接作为整体的大模型输入信息。

RAG技术的优势在于高效的减少大模型幻觉，但是也存在一定的缺陷，它是“一次性”解决方案，无法评估检索的必要性或相关度；知识源比较单一，并且无学习机制，无法从交互中迭代。这使得它比较适合简单回答，但是不适用于复杂、连续的对话场景。

![](img/949866ecc27e36c89398c15dcffa7d60.png)

## 二、Agentic RAG

为了处理RAG技术存在的缺点，后来又出现了Agentic RAG技术，这种技术是将检索视为智能体可调用的工具。智能体不再被动检索，而是住动判断是否需要调用工具（比如数据库搜索或网络查询），并评估检索结果与用户`query`的相关性。

这种方式提升了灵活性，智能体能够选择合适的工具，避免了无关信息的注入，但是它仍然停留在“只读”层面，信息仅在离线阶段存储，无法实时修改或个性化，无法从用户交互中“学习”。

![](img/70bb106a731efbb47404a8c390ddd2b9.png)

## 三、Agent Memory

智能体记忆的核心是将Agentic RAG扩展为读写系统。通过新增“写工具”，智能体不仅能够检索，还能存储、更新或删除信息。这种方式就实现了从交互中学习的闭环。例如，记录用户的偏好或事件，并在后续对话中检索。

在交互中若有写操作，则将信息存入数据库，反馈确认。这直接解决了前两者的痛点，动态存储支持实时适应，个性化检索提升用户体验。智能体可存储对话摘要或原始会话历史，实现“记住”功能，而非仅“回忆”。

这种引入记忆存储模块，读写能力虽然强大，但是会引入新风险，比如记忆腐败（过时信息干扰）或管理负担，实际在实现过程中需要结合事件检测、摘要生成等技术，确保可扩展性。
