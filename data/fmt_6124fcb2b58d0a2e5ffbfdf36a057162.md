#### 2.2 Second response

这里我们只需要借助`` `**` ``方法，直接将`function_args`对象传入`fuction_to_call`中，即可一次性传输全部参数，`` `**` ``方法的功能可以参考如下示例：

```python
def function_to_call_test(a, b, c):
    return a + b + c

function_args_test = {'a': 1, 'b': 2, 'c': 3}

result = function_to_call_test(**function_args_test)

print(result)
```

6
