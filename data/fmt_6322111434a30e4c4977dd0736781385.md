#### 如果没装怎么办？

莫慌！我已经给 AI 下了命令，它会像个尽职的管家一样，自动帮你去下载 Docker。

**为啥非得要 Docker？**

1. **安全！** 它就像个沙盒，所有操作都在里面进行，不会动你电脑一根毫毛。

2. **省心！** 你不用自己配环境，不用装 Python 什么的，它自带全套装备。

3. **牛X！** Claude Code 可以直接指挥 Docker 干活，简直是天作之合！

4. **免费！** 这么好的东西，它不要钱！

如果万一、万一 AI 自动安装失败了（毕竟AI也有打盹的时候嘛），也别怕！

咱们自己去官网下载一个：`https://www.docker.com/`

![](img/7e4b20a8652e1396e4a9cc3cd0ae1194.png)

```
给我把项目部署到 Docker 上！
```

### 第三步：部署两大核心“情报员”

#### 情报员A：`wechat2RSS`（推荐，付费）

这家伙是专门帮你追踪👸号更新的，稳准狠！

**💰 费用：**15块钱一个月，也就一杯奶茶钱，换来的是稳定和速度！

**💡 不想花钱？** 没问题！后面有免费的替代方案 `wewerss`，就是可能偶尔会有点小脾气。

下面先说说 `wechat2RSS` 的配置方法：

![](img/7214fda3a62ffd922022251e94f744f4.png)

购买地址：`https://wechat2rss.xlab.app/deploy/`

我也心领神会地把支付二维码给你扒下来了，直接扫就行，省得你再登录了，我贴不贴心！🤣

![](img/f4c77018f9047e9d185feceeee7b92c9.png)

##### 拿到激活码

邮箱里的邮件大概长这样：

![](img/16af6a62b8f25f541d141a3ef1b09594.png)

##### 配置个人信息

部署成功后，AI 会自动打开一个网页 `http://localhost:4001`。

到这步，我们需要让 AI 给我们一个 `RSS_TOKEN`，就像一个通行证。

![](img/8dfd1b7dfb203b1a2e183b75fad8613d.png)

你就直接问它：

```
给我 rsstoken
```

AI 就会乖乖地把 token 给你！（我知道这步有点傻，我回头就让 AI 自动填好，懒是第一生产力嘛！）

![](img/67b252a27f6d50d1da65af2ee1747efd.png)

把 token 填进去，下面就会显示配置信息了。

![](img/f76f0fcaf0ce310df963b695efeea8f0.png)

最后，扫码登录一下🛰️，因为这个工具是通过登录🛰️读书来获取文章的，很安全！

![](img/2da20c2c5cb566bac6d98ce63454f1db.png)
