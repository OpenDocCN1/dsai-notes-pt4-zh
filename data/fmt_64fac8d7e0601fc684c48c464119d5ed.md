
# 扣子Skill两步生成PRD+产品Demo

> 来源：[https://qqs7y1hozd1.feishu.cn/docx/XY7Zd2gnZoaZWMxaSfXcCvmwnYg](https://qqs7y1hozd1.feishu.cn/docx/XY7Zd2gnZoaZWMxaSfXcCvmwnYg)

本文先通过扣子 Skill 生成 PRD、再让其他模型根据 PRD 来写代码的产品，直接产出基本能直接交付的文档。

## Step 1：进入扣子平台，创建 PRD 生成技能

进入 `code.coze.cn` 这个链接，点击对话框上方的“技能”。

## Step 2：用 PRD 样本训练，生成高质量 PRD 技能

掏出两篇压箱底 PRD 产品文档，丢给扣子。让它分析学习后生成一个能把产品构想改写成高质量的 PRD 的技能。

![](img/1bddea11ad34ca14e9f144c567f29a84.png)

在这个干活页面上的左边栏，能看到扣子制作 Skill 的细节👇

![](img/e4981b16d3ec9dc6c735eeb316f0363b.png)

不到10分钟，这个一键制作 PRD 的 Skill 被搞定了。点开一看，这细节扑来一股产品味儿，我安心了。

![](img/d22200557b9beadaca94008a5ea2eb2a.png)

*总结得挺到位，不到10分钟成为资深产品经理*

PRD 到位，我开始继续制作一个能让 PRD 快速变成产品 Demo 的技能。没错，咱们就是要把效率拉满🔥💯

还是一样，通过扣子技能的对话框描述功能：

> 帮我生成一个「技能」。用户只需要上传一份详细的PRD文档，就能一键生成一个高保真的、可交互的产品demo出来。在生成demo时，你需要注意，必须覆盖到产品的主流程，用户的主交互链路，并尽可能覆盖异常情况。如果产品需要数据，需要尽量模拟真实场景，编造一些数据，用于在demo上展示。

点击开始执行！扣子先拆解任务，把创建 Demo 分成读取 PRD、分析产品结构、设计交互、生成代码、创建预览文件五大步骤。

![](img/bb840cbe5a2a10cb7686f6c0f2afe8d7.png)

在生成 Demo 代码后、创建 Demo 前，它还写了两个“指导”文档，把“怎么分析 PRD”和“生成 Demo 代码的规范”做了个总结。这样下次再用到这个 Skill，它就能参考文档的分析思路。

![](img/3599b2945447f00170a2aa470dd5d1ec.png)

![](img/46870ce867f3109b798259be4b225595.png)

大概等了不到5分钟，Demo 生成的技能也创建好了。

总共花了半小时，我就用扣子完成了 PRD 生成+ Demo 生成的 AI 提速链路🔜

![](img/c418442c22d49667259419ad626ee6fd.png)

## 进阶的Vibe Coder

搞定两个 Skill 的制作，技能配齐，我立马跑了个实测。

马年春节快到了，我决定做一个让用户一键生成马年春联的小网页，不仅能生成春联内容，还把春联直观展示出来。

给 Skill 里输入一些不成熟的提示词：

使用「PRD撰写技能」，帮我撰写如下产品的PRD：一个可以帮用户生成马年春节祝福春联内容的网页。网页不仅能生成春联的文案内容，也能直接以漂亮美观的3D样式直接展示出春联。如果用户对春联内容不满意，也可以反复重新生成对联的内容。同时，用户也可以自行输入春联的文案。

过了四分钟，扣子写出了一篇详细的 PRD。

读完内容，我发现它不仅写了所有我说的功能点，还补充了很多细节。

![](img/98226bb52543e00ec8ee8be259ab77f3.png)

*文档中规范了所有可能遇到的异常情况展示逻辑；明确标注了哪些功能点必须要有；还直接以线框图的形式画出了界面样式、指定了配色色号*

接着，我开始连环尝试 Demo 生成 Skill。

我把刚刚生成好的 PRD 丢给了扣子，让它调用“产品 Demo 生成技能”，直出效果。

结果，PRD 中提到的功能都没落下，页面上每个按钮也都能正常点击。

![](img/09619f37bd7316efe6650a8945b43bb2.png)

想想之前，我还用 Claude 等其他模型直接对话做出过春联生成器。结果页面上只有俩按钮🔘，还有一个没反应。生成新的对联时，上下联的前4个字还不会变。

![](img/88196be49604ed9a119671807c303d63.png)

不出所料，得到 Skill 加持的模型，生成的产品功能多了，效果也靠谱了不少。有了这个产品，妈妈估计不怕我不会拜年了。

![](img/30dd19a916e198205cdfbf1291452e4c.png)

在更正经的需求里，我还用这两个技能跑了制作数据看板的需求。

![](img/84ef1317dd7ada6c3106c064054762c7.png)

总之，这次扣子新上的 Skill 还是让我这个初级 Vibe Coder 浅尝了一把 AI 拯救 AI 的滋味，似乎又能继续做独立开发的致富梦了。

这两个我做的 Skill 也已经上架到了扣子的技能商店()里，朋友们有需求可以自取。
