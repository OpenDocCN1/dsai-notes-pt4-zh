
# 产品文案生成指南

## 关键词
产品文案、文案生成、文案模板、文案要求、产品描述、广告文案

## 文案类型
1. 产品描述
2. 广告文案
3. 社交媒体内容
4. 邮件内容

## 文案要素
1. 产品名称
2. 主要特点
3. 目标用户
4. 文案风格
5. 字数要求

## 文案要求
1. 突出产品核心卖点
2. 语言生动有趣
3. 符合目标用户需求
4. 包含行动号召

## 操作步骤
### 步骤 1：准备产品信息
- 产品名称
- 主要特点（至少3个）
- 目标用户
- 文案风格
- 字数要求

### 步骤 2：使用提示词模板
```
请帮我生成产品文案：

产品信息：

+ 产品名称：[产品名称]
+ 主要特点：[特点1]、[特点2]、[特点3]
+ 目标用户：[目标用户]

文案要求：

1. 突出产品的核心卖点
1. 语言生动有趣，吸引目标用户
1. 字数在[字数]左右
1. 风格要求：[风格]
1. 包含行动号召
```

### 步骤 3：生成文案
- 上传产品信息
- 使用提示词模板
- 生成文案

### 步骤 4：人工审核
- 审核文案内容
- 调整不准确的内容
- 优化表达方式

## 定期清理过时内容
### 清理的原则
1. 及时性：及时清理过时内容
1. 准确性：确保内容准确
1. 相关性：确保内容相关
1. 实用性：确保内容实用

### 清理的方法
方法 1：删除过时内容
+ 删除过时的案例
+ 删除过时的方法
+ 删除过时的说明

方法 2：更新过时内容
+ 更新过时的信息
+ 更新过时的方法
+ 更新过时的案例

方法 3：标记过时内容
+ 标记过时的内容
+ 说明过时的原因
+ 提供替代方案

### 清理示例
清理前：

```
## 案例示例

### 案例 2：无线耳机文案

```

清理后：

```
## 案例示例

### 案例 2：无线耳机文案
```

## 建立文档更新机制
### 更新机制的设计
1. 定期更新：定期检查和更新文档
1. 触发更新：根据特定事件触发更新
1. 版本管理：对文档进行版本管理
1. 更新记录：记录更新的历史

### 更新机制的示例
机制 1：定期更新
+ 每月检查一次文档
+ 检查是否有新案例
+ 检查是否有新方法
+ 检查是否有用户反馈

机制 2：触发更新
+ 收到用户反馈时更新
+ 发现新方法时更新
+ 出现新案例时更新
+ 发现错误时更新

机制 3：版本管理
+ 使用版本号管理文档
+ 记录每次更新的内容
+ 保留历史版本
+ 支持版本回退

机制 4：更新记录
+ 记录更新的时间
+ 记录更新的内容
+ 记录更新的原因
+ 记录更新的效果
