## 创作过程

卡尼曼先生已经离开我们半年多了，但他的《思考，快与慢》和《噪声》依旧影响着无数人~

很多人都是通过这两本总结了他毕生研究成果的书，了解了什么是“行为经济学”，了解了怎样能“让自己做出更好的决策”，进而了解了这位叫丹尼尔·卡尼曼的“行为经济学”之父。

诺贝尔获奖词里的：

**“他将心理学的前沿研究成果引入经济学研究中，特别侧重于研究人**在不确定的情况下进行判断和决策的过程。”

道尽了他一生中倾力投入的事业..

卡尼曼教授的书里有一句公式，很短

凝练为一个关键公式：

**决策错误=偏差+噪声**

( error = bias + noise )

> “所有的专业性决策中都会存在错误，我们认为它们都有一个共同点，我们把这些决策错误视为偏差和噪音的组合。”

### 方法论

那么有没有可能我们封装一个prompt，

用卡尼曼教授的思路和方法论来指引我们辅助做决策，来帮助我们避坑？

主要思路：

+   分析用户输入的决策情境,识别潜在的偏差和噪声。

+   基于背景识别可能的认知偏差、基于背景识别可能的噪声。

+   基于识别出的偏差和噪声生成建议，输出SVG卡片。

#### 基础概念

1.  五种认知偏差：

+   锚定效应：人们在做决策时，会受到最初获得的信息的影响。

+   代表性偏差：人们会根据事物的表面特征做出判断。

+   可得性偏差：人们会依赖最容易获得的信息做决策。

+   损失厌恶：人们对损失的厌恶大于对同等收益的喜好。

+   框架效应：信息的呈现方式会影响人们的决策。

1.  噪声的三种类型：

+   水平噪声：不同人对同一情境的判断可能有差异。

+   模式噪声：同一个人对相似案件在不同时间可能做出不同判决。

+   情境噪声：偶然的外界因素会影响判断。

最终测试下来其实最有用的点都是AI直接文字输出的，卡片里面毕竟空间有限~

## 实际场景

### 1、商品打折场景

用户输入：「今天我和一个朋友走进一家奶茶店，突然，他看了看海报上写着的一行字：“原价30元，今日特价15元”，接下来我想直接进行购买，因为我觉得便宜了很多。」

![](img/e3929cf5d822a6f10c5949b15bbe5a6c.png)

解读：

```
基于您描述的情境，我为您创建了一个决策分析卡片。这个卡片展示了您在奶茶店特价购买决策中可能面临的认知偏差和噪声。让我为您解释一下卡片中的关键点：
1. 潜在偏差：
  - 锚定效应：原价30元作为一个锚点，可能影响您对15元特价的判断。
  - 框架效应：特价促销的表述方式可能影响您的决策。
  - 损失厌恶：担心错过优惠可能导致急于做出购买决定。
2. 可能的噪声：
  - 情境噪声：促销环境可能影响您的判断。
  - 模式噪声：习惯性地认为促销就意味着便宜。
3. 决策思考路径：
卡片中的图表展示了从看到原价和特价，到比较、感知价值，最后做出购买决策的思考过程。
4. 建议：
退一步思考实际需求和价值，不要被表面的折扣迷惑，考虑是否真的需要这个产品。
这个分析旨在帮助您意识到可能影响决策的因素。在做出购买决定之前，建议您客观评估奶茶的实际价值，考虑是否符合您的需求和预算，而不仅仅被折扣吸引。
```

### 2、人工智能投资

用户输入：「今天我有一位投资人朋友，在找他的下一个机会。今天，他看到一家叫“TechFuture”的科技公司，发现它在人工智能领域很有创新能力，他接下来觉得这是人工智能诶，赶紧投！」

![](img/258533ac53b8e39116e4d628ce5e48f1.png)

解读：

```
感谢您提供的决策情境。让我为您分析这个投资决策中可能存在的偏差和噪声。
基于您描述的情况，我已经创建了一个决策分析卡片，详细分析了您朋友在考虑投资&quot;TechFuture&quot;公司时可能面临的认知偏差和决策噪声。以下是对卡片内容的简要解释：
1. 潜在偏差：
  - 可得性偏差：您的朋友可能过度关注了人工智能这个热门话题，忽视了其他重要因素。
  - 代表性偏差：他可能认为创新能力必然带来投资回报，这种假设可能过于简化。
  - 锚定效应：决策似乎过于锚定在&quot;人工智能&quot;这个概念上，可能忽视了其他重要的商业和财务指标。

  - 模式噪声：您的朋友可能过度依赖于过去成功的投资模式，而忽视了每个机会的独特性。
3. 决策思考路径：
图示展示了您朋友可能跳过了深入分析和理性决策的步骤，直接从初始兴趣跳到了执行投资。这种快速决策可能增加了犯错的风险。
4. 建议：
建议您的朋友放慢决策速度，全面评估公司的价值和市场前景，而不要仅仅因为&quot;人工智能&quot;这个概念就仓促投资。
这个分析旨在帮助您的朋友认识到可能存在的决策陷阱，鼓励他采取更加审慎和全面的投资决策过程。如果您需要更详细的解释或有任何问题，请随时告诉我。
```

### 3、出行工具选择

用户输入「我朋友打算买张机票，飞到其它地方去旅游。可是，刚要点付款时，屏幕上方突然弹出一条新闻：“xx航空飞机失事，机上乘客无一生还”。他打算取消订单，换高铁出行。」

![](img/bc271a3887edc3d92150059e91578c68.png)

解读：

```
潜在偏差：
a) 可得性偏差：最近发生的、容易回想起的事件会被认为更有可能再次发生。您朋友刚看到空难新闻，因此高估了飞机失事的概率。
b) 代表性偏差：您的朋友可能将这一特定事件视为所有航空旅行的代表，忽视了航空旅行总体上的安全记录。
c) 损失厌恶：对可能的生命损失的恐惧可能远远超过了对航空旅行便利性的重视。
可能的噪声：
a) 情境噪声：新闻弹出的时机（正要付款时）可能加剧了其对决策的影响。
b) 模式噪声：如果您的朋友之前就对飞行有恐惧，这条新闻可能会强化这种模式化的恐惧反应。
建议：
为了做出更理性的决策，建议您的朋友：

冷静下来，不要让单一事件过度影响决策。给自己一些时间来平复情绪。
查看长期的航空安全统计数据。实际上，航空是最安全的交通方式之一。
理性比较不同交通方式的安全性、效率和成本。高铁虽然感觉上更安全，但长途旅行可能更耗时且疲劳。
考虑改变航空公司而不是完全放弃飞行。不同航空公司的安全记录可能有所不同。
如果决定改变计划，确保这是基于全面考虑后的决定，而不仅仅是出于一时的恐慌反应。
```

![](img/867d554daf490d505169d77816a6a1fb.png)

```
谢谢您提供的决策情境。让我为您分析这个选择中可能存在的认知偏差和决策噪声。

1. 潜在偏差：
  - 现时偏差：您可能高估了未来30天内使用优惠券的可能性。我们往往对未来的行为过于乐观。
  - 框架效应：第二个选项中的&quot;获得&quot;一词可能让这个选项看起来更有吸引力，尽管实际价值可能相同或更低。

  - 评估两种方案的即时价值
  - 考虑30天内再次购物的实际可能性
  - 计算优惠券过期的风险
  - 权衡即时满足与潜在收益
  - 考虑个人消费习惯和预算
4. 建议：
客观评估未来30天内使用优惠券的实际概率，计算实际可能获得的收益。考虑选择即时折扣，以避免因过度乐观估计而可能带来的损失。
请记住，最佳决策应该基于您的具体情况和偏好。这个分析旨在帮助您认识到可能的偏见和噪声，从而做出更加理性和客观的决策。

### 6、法官断案

用户输入「现在有两个法官。一个，是身为妈妈的女法官，一个，是还没结婚的男法官。面对一个因为孩子被霸凌而过失伤人的被告，他们的判决结果不一样。」

![](img/9a1605d4478c47c1cc70905c1d03a310.png)

解读：

```
感谢您提供这个有趣的决策情境。我将为您分析其中可能存在的认知偏差和噪声，并通过一个SVG卡片呈现结果。
基于您描述的情境，我已经创建了一个决策分析卡片。以下是对这种情况的简要分析：
1. 潜在偏差：
  - 情感偏差：法官的个人经历（如是否为父母）可能影响他们对案件的看法。
  - 框架效应：案件的描述方式可能影响法官的判断。
  - 确认偏差：法官可能倾向于寻找支持自己初步判断的信息。
2. 可能的噪声：
  - 水平噪声：两位法官之间的判决差异反映了司法系统中的不一致性。
  - 情境噪声：法官的个人状态（如心情、工作压力等）可能影响判决。
3. 建议：
建立标准化的判决流程，减少个人因素对判决的影响。这可能包括：
  - 制定明确的判决指南
  - 进行定期的判决校准训练
