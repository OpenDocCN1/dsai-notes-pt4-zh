# 补充知识

## 1）什么是`json`格式

一种通用的数据格式，用来存数据、传数据

1.  最基础的结构（对象）

用 {} 包裹，里面是多个键值对，键和值之间用 : 连接，键值对之间用 , 分隔。

例：描述一个人

```
{
  &quot;name&quot;: &quot;张三&quot;,    // 键是&quot;name&quot;，值是&quot;张三&quot;（字符串，用双引号）
  &quot;age&quot;: 20,         // 键是&quot;age&quot;，值是20（数字，不用引号）
  &quot;isStudent&quot;: true  // 键是&quot;isStudent&quot;，值是true（布尔值：true/false，不用引号）
}
```

1.  包含多个同类数据（数组）

如果要描述 “一群人”，可以用 [] 包裹多个对象，这就是数组。

例：描述两个人

```
[
  {
    &quot;name&quot;: &quot;张三&quot;,
    &quot;age&quot;: 20
  },
  {
    &quot;name&quot;: &quot;李四&quot;,
    &quot;age&quot;: 22
  }
]
```

1.  嵌套结构（复杂数据）

键的值还可以是另一个对象或数组，实现 “数据嵌套”。

例：描述一个人及他的宠物

```
{
  &quot;name&quot;: &quot;张三&quot;,
  &quot;pets&quot;: [  // 键&quot;pets&quot;的值是一个数组
    {
      &quot;type&quot;: &quot;猫&quot;,
      &quot;name&quot;: &quot;花花&quot;
    },
    {
      &quot;type&quot;: &quot;狗&quot;,
      &quot;name&quot;: &quot;旺财&quot;
    }
  ]
}
```
