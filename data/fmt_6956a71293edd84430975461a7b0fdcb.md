
# 一周涨了 3W 粉，📕爆款的“多巴胺穿搭”AI 绘画风格教程！

> 来源：[https://my.feishu.cn/docx/M3wFdHBv5oPQHPxr9eZczGRBnKd](https://my.feishu.cn/docx/M3wFdHBv5oPQHPxr9eZczGRBnKd)

今天给大家汇总一下近期非常火的 4 种风格 ai 绘画作品咒语及思路，大部分直接复制就可以，以下所有风格必须使用 `niji` 的默认模式。

1. 多巴胺穿搭风格
2. 混合涂鸦贴纸风格（彩虹色涂鸦贴纸风格）
3. 手帐拼贴风格
4. 复古港风风格

## 1、多巴胺穿搭

多巴胺穿搭是近期的热点，这套词最经典的有两个版本。

一个是蓝色多巴胺、一个是粉红色多巴胺，并且已经衍生出了几种变体的关键词。

我们看完所有的词可以发现，多巴胺系列的核心关键词是 `mixed patterns`（混合模式）和 `text and emoji device`（文字和表情装置）。

这两个词的作用就是帮助你在画面上运用两种或者多种不同的图案、花纹、形状、文字、表情，呈现出混合的视觉效果。

## 2、混合涂鸦贴纸

混合涂鸦贴纸，又叫做彩虹色涂鸦贴纸，可以自由替换咒语中的颜色，红橙黄绿青蓝紫都可以。

它和多巴胺其实差不多，核心的关键词都是 `mixed patterns` 和 `text and emoji installations`。

## 3、手帐贴纸风格

手帐贴纸风格的有多个核心关键词可以达到效果。

- `pocket sticker` 拆解式贴纸
- `decomposed stickers` 拆解式贴纸
- `knolling layout` 平铺布局
- `disassembly design` 拆解设计
- `pocket book` 袖珍本

基本上在咒语的演变上，还是遵循着从物品、到人物、再到风格化人物的路径。

### （1）水果手帐风格

咒语：

```
pocket stickers， watermelons， cute girls， desserts， high details， knolling layout， highly detailed， depth， mang parts ar 3:4
```

![](img/70f4850b8a37b63f0b685a727ca83887.png)

### （2）人物手帐风格

咒语：

```
knolling layout， cake and dessert， girl wearing maid costumes style expressive
```

![](img/d443f0e8e3fd956b91a92b0c346670c9.png)

### （3）复古昭和风手帐

这套词在原先的手帐风格基础上，融入了昭和女孩和复古时尚的关键词。

相对之前的普通版的手帐，更加具备风格和表现力。

最早版本的咒语比较简单：

```
old fashion, showa comic girl, planner book collage --niji 5 --s 400
```

## 4、复古港风风格

复古港风风格表面上是港风，其实它的核心关键词是依旧是 90 年代的日本老式漫画。

这里单独拿出来是因为相比于复古港风手帐风格，它的画面中心在于人物，更加具备爆款的潜力。

咒语：

```
old fash， 90s japanese anime poster， headshot， a young student， curly hair， wearing bad ears， eyes clear forward on a nostalgic background， the photo presents the old manga style of the girl image， planner book， collage
```
