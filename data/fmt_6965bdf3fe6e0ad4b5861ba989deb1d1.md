
# 财务预测模型

## 财务预测的基本假设

+ 有关费用和资产的预测通常都是假定，他们与销售成比例，称为销售百分比法
+ 销售成本、毛利、管理费用和销售费用通常与销售成比例。
+ 注意：不是所有的利润表项目都与销售收入成正比。

![](img/cc461ec043847e895d5831266c0a1d4e.png)

### 毛利率的假设

+ 是否变动?
+ 变动原因:
+ 价格变动?
+ 成本变动?
+ 销售费用率假设
+ 企业是否调整营销策略?
+ 销售费用率是否变动?
+ 管理费用率假设

### 资产负债表预测的假设

+ 大部分资产项目假设是与销售成正比的。
+ 现金周转率
+ 应收账款周转率
+ 存货周转率
+ 应付账款周转率
+ 固定资产周转率
+ 正常情况下资产周转率保持稳定是合理的;
+ 历史周转率是否稳定?
+ 如果不稳定,如何估计未来的周转率?
+ 是否应考虑长期资产的不均衡增长?
+ 调整会计报表
+ 区分经营资产与非经营资产；
+ 区分经营净利润与净利润
+ 区分经营债务与投入资本；

## 财务预测模型(案例二)

案例: NEWCOM公司是一定新成立的公司，公司开发和生产医疗仪器。根据公司的产品开发和生产销售规划，得出如下基本的预测假设。

1. 产品开发期预计为18个月，第19个月开始生产销售产品。
2. 第19个月的销售估计为10000元，三年内实际销售额按每月8%的增长率增长，以后按通货膨胀率增长。
3. 通货膨胀率估计每年9%（每月0。75%）。
4. 开发期间每月运营费用为15000元，考虑通货膨胀。
5. 在第18个月开末，企业租赁一条价值20万元的生产线，足够满足前五年生产所需，每月租金为3000元。
6. 销售毛利率为60%（不包括租金）。
7. 销售费用为销售额的15%。从第19个月起，每月的管理费用为10000元，且以通货膨胀率上涨，加销售额的15%。
8. 企业所得税率为25%，损失不能递延。
9. 所有销售都是信用销售，平均收账期为45天。
10. 存货每年周转五次，用期初存货衡量。
11. 最低现金余额为30天销售额或10000元较大者。
12. 应付账款每年周转八次，用期初应账款衡量。
13. 创业者初始投资为40万元，假设以后融采用借款，借款利率为每月1%。
