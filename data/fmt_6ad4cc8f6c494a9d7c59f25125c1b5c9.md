
# 2 供应商评估

> 来源：[https://rxq0zfnkm77.feishu.cn/docx/VN5kdRxKOotZvqxtxhKcJaZMneb](https://rxq0zfnkm77.feishu.cn/docx/VN5kdRxKOotZvqxtxhKcJaZMneb)

## 一、定义 / 概念

供应商评估，是指采购部门根据供应商在质量、交付、价格、服务、合规等方面的实际表现，对供应商进行系统评价的管理动作。

它的目的，不是“打分好看”，而是为了判断这家供应商：

+ 是否值得长期合作，
+ 是否需要重点改善，
+ 是否存在淘汰风险。

一句话总结：

评估不是走流程，而是用数据判断供应商到底靠不靠谱。

---

## 二、为什么要做供应商评估

很多企业在供应商管理上，常见的问题不是“没有供应商”，而是“用了很多供应商，却不知道谁真正稳定”。

如果不做评估，容易出现三种情况：

1. 质量问题频发，但没有数据沉淀；
2. 交付经常延误，却一直没有预警；
3. 关系看起来不错，实际合作表现并不稳定。

供应商评估的意义主要有三点：

### 1. 识别优劣

把真正稳定、值得深度合作的供应商筛出来，也把问题频发的供应商识别出来。

### 2. 作为管理依据

后续的分层管理、订单分配、谈判、淘汰，都需要以评估结果为依据。

### 3. 推动持续改善

评估不是为了“扣分”，而是为了让供应商知道问题在哪里、怎么改。

---

## 三、常见的供应商评估维度

### 1. 质量表现

重点看：

+ 来料合格率
+ 不良率
+ 客诉次数
+ 返工返修情况
+ 质量问题关闭速度

**实务提醒：**

质量不是只看“有没有出问题”，而要看“问题出现后处理得快不快、改不改得动”。

---

### 2. 交付表现

重点看：

+ 准时交货率
+ 延误次数
+ 紧急订单配合度
+ 发货准确率
+ 交付异常响应速度

**前辈经验：**

交付管理不能只看“这次到了没”，而要看“稳定性”。偶尔一次准时，不代表长期可靠。

---

### 3. 价格与成本表现

重点看：

+ 报价是否合理
+ 是否具备持续降本配合能力
+ 调价频率是否异常
+ 成本透明度是否足够
+ 是否支持年度议价或成本优化

**注意：**

价格低不等于表现好。

如果低价换来的是质量波动、交付不稳，最后企业付出的成本往往更高。

---

### 4. 服务与响应表现

重点看：

+ 沟通效率
+ 异常处理速度
+ 配合度
+ 技术支持能力
+ 售后问题闭环能力

很多供应商平时看不出差距，真正拉开差距的，往往是在出问题的时候。

---

### 5. 合规与风险表现

重点看：

+ 资质是否齐全
+ 合同履约情况
+ 财务状况是否稳定
+ 是否存在环保、劳动、税务等风险
+ 是否过度依赖单一客户或单一区域

**一句话：**

供应商能不能供货，不只看产能，还要看它会不会突然出事。

---

### 6. 改善与协同能力

重点看：

+ 是否愿意配合改进
+ 是否能落实整改计划
+ 是否具备一定创新能力
+ 是否愿意参与联合降本、工艺优化、交付改善

真正值得长期合作的供应商，不只是“能交货”，而是“能一起进步”。

---

## 四、常见评估方式

### 1. 日常绩效评估

按月或按季度统计质量、交付、服务等数据，形成评分结果。

### 2. 年度综合评估

结合全年表现，给出等级分类，如 A/B/C/D 级。

### 3. 现场审核评估

对关键供应商进行实地考察，了解产能、设备、现场管理、质量体系等真实情况。

### 4. 事件型评估

出现重大质量异常、延误、投诉时，单独启动专项评估。

---

## 五、案例 / 场景代入

某企业过去只凭“合作感觉”管理供应商，结果发现几家长期合作的供应商，其实交付波动很大，只是没有被系统记录。

后来企业建立了季度评估机制，重点考核：

+ 来料合格率
+ 准时交付率
+ 异常响应速度
+ 配合改善情况

连续两个季度下来：

+ 2 家供应商被调出核心名单；
+ 3 家表现稳定的供应商获得更多订单份额；
+ 采购在议价和分配订单时，也第一次真正有了数据依据。

差别就在于：

以前靠印象，现在靠事实。

---

## 六、常见误区 / 避坑提醒

### 1. 只评价格，不评综合能力

低价不是唯一标准，采购要看总成本，而不是只看单价。

### 2. 评分维度太多，最后没人维护

评估体系不要一开始就做得过于复杂。先抓住质量、交付、价格、服务四个核心项。

### 3. 评分后没有动作

评估结果如果不用于订单分配、改善计划或淘汰机制，那评估就只是形式。

### 4. 只在出问题时评估

真正有效的评估，应该是日常持续记录，而不是出事后临时翻账。

### 5. 没有统一标准

不同采购员各打各的分，结果没有可比性。评估口径一定要统一。

---

## 七、总结

供应商评估的核心，不是“给别人打分”，而是“帮企业做判断”。

评估做得越扎实：

+ 谁该重点合作，越清楚；
+ 谁该整改预警，越明确；
+ 谁该退出名单，也越有依据。

一句话总结：

供应商评估，是把“凭感觉合作”变成“按表现管理”。
