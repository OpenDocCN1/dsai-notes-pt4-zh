# 二、搭建📕账号

## 2.1 定位

定位和选品就是回答 3 个问题：

+   面向什么人群
+   通过提供什么样的服务，解决什么样的问题
+   卖给目标用户什么产品（解决什么样的问题？）

总的来说，定位决定了你：通过什么方式赚钱？（变现形式），凭什么赚钱？（核心价值），赚谁的钱？（精准用户），赚多少钱？（定价）等等因素。

### 2.1.1 归纳九宫格

你是谁？

+   职业（社会角色、行业角色）
+   外表（形象特征、穿搭风格、妆容风格）
+   性格（性格特点、人物个性）

你需要谁？

+   粉丝画像（性别、年龄段、人群共性）
+   需求场景（具体、细节、生活化、感性）
+   记忆点（一个词一句话、一个招牌动作、标签、标志道具）

你有什么不一样？

+   优势（差异化、厉害之处、专业角度）

你能做什么？

+   价值（提供什么、解决什么、分享什么）

中心点

+   核心价值观

| 职业 | 外表 | 性格 |
| --- | --- | --- |
| 优势 | 核心价值观 | 价值 |
| 粉丝画像 | 需求场景 | 记忆点 |

## 2.2 包装

### 2.2.1 头像

跟你的人设形象吻合即可，长得不错的建议用真人头像，容易建立信任感。

如果不想用真人头像，用虚拟 IP 形象也可以。

制作方式：可以使用图怪兽等网站来进行图片的制作，将满意的图片作为头像。又或者找些无版权的图片：

+   `https://818ps.com/`
+   `https://www.canva.cn/`
+   `https://www.chuangkit.com/`
+   `https://qiye.gaoding.com/`

注意事项：注意避免使用容易侵权的商标类图片

### 2.2.2 昵称

有辨析度、好记、有趣的名字，专业属性标签最好能加，更有辨析度和真是可信。不要用复杂的符号或特殊语言。

有以下 4 种公式可作参考：

+   昵称 + 个性：大鹅的七七八八
+   昵称 + 地区：姚老板在北京
+   昵称 + 专业：跟着拆哥看房
+   昵称 + 价值观：阿鱼爱学习

### 2.2.3 简介

一个写简介的公式：

+   你是谁
+   你做过什么牛逼的事
+   关注你有什么好处，或者分享哪些领域的内容

有的账号出了上万点赞的爆款，但是粉丝只有 100 个，主要原因是账号的内容没有明确的垂直定位，并且个人简介没有写好，没有能够让粉丝找到关注的理由。

所以，写简介的时候千万不要谦虚，如果你不能展现出可以给粉丝提供的价值，那他们凭什么关注你呢？

### 2.2.4 背景图／瞬间

跟产品、人设、工作场景有关的都可以设置为背景图。

瞬间可以发一些类似朋友圈的工作和生活打卡，尽量发和你 IP 领域有关的，用来拉近和用户的距离。

### 2.2.5 主页排版

封面要体现你的风格和特色。风格尽量统一，色彩统一和谐不要太杂乱。可调整封面设计但不要一天一个样。

## 3.4 📕内容制作

### 3.4.1 标题

#### 3.4.1.1 二极管标题法

基本原理：

+   本能喜欢：最省力法则和及时享受
+   动物基本驱动力：追求快乐和逃避痛苦，由此衍生出 2 个刺激：正刺激和负刺激

标题公式

正面刺激：产品或方法＋只需１秒（短期）＋便可开挂（逆天效果）

+   减重 90 斤，分享 4 条干净饮食习惯

负面刺激：你不 xxx + 绝对会后悔 （天大损失）+（紧迫感）

+   你不看这个文章就会错过一个亿 限时删除！！！
+   简单来说就是制造焦虑，有点损，但是用户吃这一套。

其实就是利用人们厌恶损失和负面偏误的心理（毕竟在原始社会得到一个机会可能只是多吃几口肉，但是一个失误可能葬身虎口，自然进化让我们在面对负面消息时，更加敏感。）

#### 3.4.1.2 杂交法

如下图：搜纪录片-最热，翻看排名前十笔记，会发现关键字就这么几个：唯唯诺诺、央视推荐、格局炸裂

最热前 8 个中有 6 个的标题几乎是一样的（爆款都是重复的）

直接抄，关键词不断排列组合，这样杂交出的标题自带爆款基因。

![](img/bf8ccb19a05afb16a42b7fb5d1841529.png)

#### 3.4.1.3 做比较

把不同事物或同一事物的不同阶段进行对比，形成反差，引发用户好奇和点击。

举例：

+   坚持带孩子做这四件事，比补课强 100 倍！
+   低学历逆袭，高中毕业如何年入百万
+   上映时被骂烂片，如今成无数人心中的白月光

#### 3.4.1.4 戳痛点

击中用户痛点，可以引发他们的共鸣，从而激起用户解决问题的需求，让他们忍不住点开笔记一探究竟。

举例：

+   没时间锻炼，推荐这个动作
+   总怀疑自己不够好！完成这两点终于摆脱自卑
+   平胸有救啦！提 cup，消副乳，防止胸部下垂

#### 3.4.1.5 立权威

通过引发权威，来提升用户的信任度。这里的权威，可以指名人明星，也可以是领域内的专家，还可以是经验丰富的普通人。

举例：

+   十年黑长直护发经验，总结了 12 个日常小习惯
+   从理发店小哥那学到的去头油的方法
+   央视推荐的 6 本书 | 值得一读再读

#### 3.4.1.6 提问题

问句是一种十分常见的标题技巧，常见的有设问句、反问句等等。相比于陈述句，问句可以很好地调动用户的积极性，引发用户思考，增加他们的参与感。

举例：

+   怎样爱自己？当妈后我开窍了
+   被夸奖后如何回复？
+   父母不强调自己的付出，就会养出白眼狼吗？

#### 3.4.1.7 设危机

人们对威胁到自己的东西普遍比较敏感，所以，警告、威胁性的标题，可以很好地吸引大家的目光。例如“千万不要”、“一定要”之类，或者是直接体现严重后果的警示性标题。

举例：

+   女生这样做男友会离你越来越远！
+   2022 已过 1/3！想要逆风翻盘必须停止这 3 件事
+   8 种珠宝佩戴禁忌，90%的人都踩坑了！

#### 3.4.1.8 留悬念

都说“好奇心害死猫”，但好奇是每个人的天性。当你说一半留一半，犹抱琵琶半遮面，就能勾起用户的好奇心和探索欲。

举例：

+   死亡会有感觉吗？3 次成功抢救，3 个真实故事
+   避开这些雷区，教你装修省钱的秘诀
+   灭杀蟑螂的公司，不会告诉你的秘密。

#### 3.4.1.9 反常规

除了“欲说还休”，大家也可以通过一些有违常理的点，或提供新鲜的认知来制造悬念，目的也是激发用户的好奇心。

举例：

+   睡姿也能控梦
+   每天都吃肉，结果我瘦了 15 斤
+   你的记忆可能欺骗了你！最后一个我不相信！

#### 3.4.1.10 走捷径

做一件事，谁都希望能省时省力省钱省心，最后还能获得满意的结果。所以“速成类”、“低成本类”的关键词往往也很能打动人心。

举例：

+   新手学 ipad 绘画必备！白嫖五大 procreate 课
+   新手在家不花一分钱，也能 get 新技能
+   10 秒钟就能做好的懒人早餐，不揉面不擀面

#### 3.4.1.11 晒成果

人都有慕强心理，如果你的成果比较牛，不妨把它晒出来。

举例：

+   我曾经靠这套学习方法，单科平均提升 30 分
+   自媒体涨粉难？一天涨粉 1000+的我，教你 3 个秘诀
+   纯新手 30 天涨万粉，全靠📕 5 个隐藏功能

#### 3.4.1.12 蹭热点

热点本身自带流量，关注的人会比较多，比如今年年初的谷爱凌，6 月份的梦华录，以及最近的董宇辉等等。借助热点赋能，可以让你的笔记获得更多的曝光量。

举例：

+   刘亦菲《梦华录》，别让“善良”成为诅咒
+   谷爱凌的 7 个特质，值得所有女孩子学习
+   房琪 | 会说话的女生，真的会发光

但是也要注意，热点不要瞎蹭，结合自己的领域，去挖掘适合自己的热点。

#### 3.4.1.13 贴标签

我们可以从年龄、地域、身份、职业等方面给用户贴标签，制造用户的身份认同感，以及角色代入感，其实也是在定位精准人群。

举例：

+   小镇女孩如何克服自卑感？
+   学生党随身迷你好物，出门必备
+   150 小个子 | 八条显高法则

#### 3.4.1.14 列数字

数字法是应用最为广泛的一种标题技巧，因为比起文字，数字更加直观，也更有冲击力。

而且，它还可以和以上任何一种技巧组合起来，增加标题的吸引力。但是，如果没有其他技巧的结合，数字本身就要足够吸睛，让人感觉干货满满。

举例：

+   115 部优质电影汇总，马住慢慢看
+   80 件新生开学必备用品
+   值得花一生阅读的 300 本书

### 3.4.4 评论区

让用户多多评论的直接好处就是

+   通过羊群效应激发更多有需求的用户主动私聊，就像 “ 排队买肉香，人多饭好吃 ” 一样
+   流量更上一层楼

那重点策略就要放在多多让用户评论和关注上

> 跟很多公域平台一样，📕也有算法推荐机制，系统会根据你笔记的初始点赞、收藏、评论、转发、分享、转粉数据来打分，评论、转发和转粉这三个的分数占比较高。
>
> `CES` 评分：点赞数 x 1 分 + 收藏数 x 1 分 + 评论数 x 4 分 + 转发数 x 4 分 + 关注数 x 8 分
>
> PS：`CES` 为📕的内部评分体系。

当你的笔记分数越来越高，就会一级一级的被系统推荐到更大的流量池，成为爆文（小爆款互动量 1000+，大爆款 10000+，不同类目有所不同）而这篇爆文还会带动其它笔记的整体数据增长，当然要先满足这些前提。

原理：

+   羊群效应：大部分人都是跟风，盲目跟从，所以我们需要的是带动羊群的头羊。
+   给指令：用户很懒，不想动脑，当用户看到喜欢的内容时，要马上告诉他如何领取，否则那些需求不是特别高的用户就会流逝。

具体操作

1.  引导关注+扣随机数字 （给出简单指令，同时这个指令有利于我们做数据）
2.  拿 3 个小号自己先评论（激发羊群效应，三人成虎，3 个就够了。）

没有小号的话，可以加几个任务群，互助群（📕直接搜关键字，就会找到很多。）

#### 3.4.4.1 评论区可以发图片了（2023 年 04 月 22 日最新版本内侧 `7.85.0`）

评论区也可以发图片了，如果侧重营销属性的话，可以把用户好评之类的放在评论区来消除用户的戒心，也是在推动用户来做决策。

因为平台的规则一直在变，很可能昨天能用的方式，今天就不行了，所以，引流方式务必需要不断地迭代更。

### 3.5.6 玩法六：设置📕号

每个新用户都有一次设置📕号的权限，📕号是账号 ID，用户可以通过搜索📕号找到你的账号。
