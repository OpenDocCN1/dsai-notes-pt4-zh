## 3.3 与 Claude API 的关系

OpenClaw 与 Anthropic 的 Claude API 有着特殊而微妙的关系。

### 3.3.1 命名渊源

**Clawd → Clawdbot → Moltbot → OpenClaw**

OpenClaw 的原名 **"Clawdbot"** 直接来源于 **"Claude Bot"**:

+ **Clawd** 是 Peter 最初开发的个人 AI 助手，名字就是 Claude 的变体
+ **Clawdbot** = Clawd + Bot，强调其机器人属性
+ 项目开源后迅速走红，但 Anthropic 认为名字太接近 “Claude”，构成商标侵权

#### 商标纠纷

2026 年 1 月 27 日，Anthropic 向 Peter Steinberger 发出商标投诉，要求更名。Peter 迅速响应：

+ 当天就将项目改名为 **Moltbot**（Molt = 龙虾蜕皮，呼应龙虾主题）
+ 但 Peter 后来承认 “Moltbot” 这个名字 “never quite rolled off the tongue”（念起来不顺口）
+ **3 天后（1 月 30 日）**再次更名为 OpenClaw（Open = 开源，Claw = 龙虾钳）

这段改名风波反而给项目带来了巨大的曝光度，GitHub stars 在一周内从 2,000 飙升到 100,000+。

### 3.3.2 技术依赖关系

OpenClaw 不是 Claude 的官方产品

需要明确的是：

+ ❌ OpenClaw **不是** Anthropic 开发的
+ ❌ OpenClaw **不是** Claude 的官方客户端
+ ✅ OpenClaw 是一个 **独立的开源项目**，可以使用 Claude API
+ ✅ OpenClaw 也支持 GPT、Gemini、DeepSeek 等其他模型

#### 为什么 OpenClaw 偏爱 Claude?

虽然 OpenClaw 是模型无关的，但 Claude 确实是最推荐的选择：

1. **工具调用能力强** - Claude 3.5 Sonnet 的 Function Calling 准确率高
2. **上下文窗口大** - 200K tokens，适合长对话和大文件处理
3. **指令遵循好** - 能够准确理解复杂的 System Prompt
4. **安全性高** - 拒绝执行危险操作的能力强
5. **创始人偏好** - Peter 本人是 Claude 的重度用户

#### API 调用方式

```
// OpenClaw 调用 Claude API 的简化示例
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

  }
```

### 3.3.3 MCP (Model Context Protocol) 集成

#### 什么是 MCP?

MCP (Model Context Protocol) 是 Anthropic 推出的一个开放协议，用于：

+ 让 AI 应用能够连接到各种数据源和工具
+ 标准化 AI Agent 与外部系统的交互方式
+ 使得为 Claude Desktop 开发的插件可以在其他平台复用

OpenClaw 对 MCP 的支持：

OpenClaw 是最早全面支持 MCP 的开源项目之一：

```
// MCP Server 配置
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/allowed/files"]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "your-token"
      }
    },
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://..."
      }
    }
  }
}
```

#### MCP 的价值

1. **生态互通** - 为 Claude Desktop 开发的 MCP Server 可以直接用于 OpenClaw
2. **标准化** - 不需要为每个工具单独开发集成
3. **安全隔离** - MCP Server 作为独立进程运行，提供沙箱隔离
4. **社区共享** - 社区开发的 MCP Server 可以被所有人使用

#### OpenClaw + Claude Code 联动

一个强大的组合是将 OpenClaw 与 Claude Code 联动：

```
用户 → OpenClaw (任务分配)
         ↓
    Claude Code (代码开发)
         ↓
    执行结果 → OpenClaw
         ↓
    反馈给用户
```

这种组合让 OpenClaw 可以：

+ 委托复杂的编程任务给 Claude Code
+ Claude Code 完成后将结果返回
+ 实现“AI 管理 AI”的多层协作
