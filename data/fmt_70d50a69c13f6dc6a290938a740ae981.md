**相关报道：**ChatGPT 王炸更新，能联网获取新知识，可与 5000+个应用交互

**观点：**OpenAI 开放插件的目的是绑定开发者生态，把自己打造成互联网新的操作系统和流量入口

相比于过去半年仅提供 API 帮助建设不同产品，所有的产品都相当于在为 ChatGPT 提供功能和现实世界接口。一越从幕后转到台前。

联网数据，运行代码，开放交互是这次 OpenAI 生态策略的三大主题，每一条都比你想象得要更有长远影响。

1. 过去的 ChatGPT 在遇到一些问题时会提醒你它的训练数据并不包括这一内容，但是在添加 Browsing 插件后就可以自主判断什么时间去互联网获得更多信息以及如何获取筛选和解读这些数据。将 ChatGPT 联网意味着或许会更进一步改变我们获取信息的习惯进一步提高效率，但是也意味着多重风险 - 模型被有意投喂大量恶意数据，通过 AI 作恶也会更加容易。

2. 旧版 ChatGPT 其实是可以通过指令使其“模拟”成一个命令行界面运行代码，但是结果其实是内在逻辑分析后再伪装成代码结果。使用 Code Interpreter 插件后就可以在对话中直接进行 Python 代码运作。这不是仅仅允许使用者运行 python 代码那么简单，而是意味着一些复杂问题 ChatGPT 会自己撰写代码，运行后辅助分析。AI 真正会使用代码就像当初动物学会使用工具一样。

3. 能够通过 ChatGPT 对话直接通过 Instacart 上面买菜、通过 Kayak 预定旅行交通和住宿，通过 Klarna 买到各个平台比价最便宜的商品只是冰山一角。通过链接 Zapier 意味着我们可以更容易通过 ChatGPT 定制我们的工作流，自动回复邮件、撰写新闻稿、进行代码 Review 都不需要人工介入。几乎你在互联网上能做的一切事情 ChatGPT 都可以去替你做。

这一点其实刚好契合了我昨天所分享的 AI 公司护城河的思考，Retrieval 这一个案例插件直接干掉大多数 summarization 企业。希望每一位 builder 共勉。大势不可挡，但是漩涡里也能涌现更多弄潮儿。
