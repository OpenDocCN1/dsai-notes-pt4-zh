## 接入 Telegram

### 流程总览

> 3 个步骤完成接入：

1. 在 Telegram 创建 Bot（获取 Token）
1. 将 `Token` 写入 `OpenClaw` 配置
1. 完成配对（`Pairing`）授权

---

### 1. 在 Telegram 创建 Bot（获取 Token）

1. 在 Telegram 搜索 `@BotFather`

1. 发送：

`/newbot`

1. 设置 `Bot Name` 与 `Bot Username`（必须以 `bot` 结尾）

4. 保存 `BotFather` 返回的 `Bot Token` （下文称为 `YOUR_BOT_TOKEN`）

![](img/5e95ebbaadb54b9d08d4183d217c2358.png)

> `Token` 泄露等同于 `Bot` 被完全控制，请妥善保管。

---

### 2. 将 Telegram Bot 接入 OpenClaw

#### 方式 A：交互式配置

将上文获取到的 `YOUR_BOT_TOKEN` 添加到后台配置中。

选择路径：`Settings - Config - Channels - Telegram - Telegram Bot Token`

![](img/18c25182191269db3886c7dec1d15dea.png)

---

#### 方式 B：一行命令快速配置

```
pnpm openclaw channels add telegram --bot-token "YOUR_BOT_TOKEN"
pnpm openclaw gateway restart
```

---

### 3. 完成配对（关键步骤）

#### 在 Telegram 获取配对码

1. 打开你的 `Bot`

2. 点击 `START` 或发送 `/start`

1. 机器人返回配对码，例如：

`Pairing code: Z9KH7RFG`

#### 在本地批准配对

```
pnpm openclaw pairing approve telegram Z9KH7RFG
```

---

配对成功后，Telegram 消息将直达 `OpenClaw` 主 `Agent`，支持对话。

### 六、常见问题

+ 检查 `~/.openclaw/openclaw.json` 配置是否正确

#### 设置浏览器配置文件（1，2 选根据需求选一个即可）

1. 让 `OpenClaw` 使用独立配置文件打开浏览器，在终端中输入

```
openclaw config set browser.defaultProfile "openclaw"
```

1. 让 `OpenClaw` 复用用户浏览器登录状态，在终端中输入

```
openclaw config set browser.defaultProfile "user"
```

1. 上面代码运行完成以后重启网关，告诉 `OpenClaw` 可以操作浏览器了

```
openclaw gateway restart
```
