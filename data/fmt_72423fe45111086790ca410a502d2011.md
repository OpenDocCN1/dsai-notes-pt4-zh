
# Day 1

`nvidia-smi` 是一个用于监控和管理 NVIDIA GPU 设备的实用程序。你在 Docker 容器内部运行了 `nvidia-smi` 命令，下面是对输出的一些解释：

+ `NVIDIA-SMI 535.86.01`：NVIDIA System Management Interface 的版本号。
+ `Driver Version: 536.67`：NVIDIA 驱动程序的版本号。
+ `CUDA Version: 12.2`：CUDA（Compute Unified Device Architecture，统一计算设备架构）的版本号。

在 GPU 部分：

+ `0 NVIDIA GeForce RTX 4090`：你的系统中的 GPU 设备，编号为 `0`，型号为 NVIDIA GeForce RTX 4090。
+ `38C`：GPU 的当前温度为 38 摄氏度。
+ `P8`：GPU 的当前性能状态。`P8` 表示低功耗状态。
+ `26W / 450W`：GPU 当前的功耗和最大功耗。
+ `15192MiB / 24564MiB`：GPU 的当前内存使用情况和总内存。目前使用了约 15.2GB，总内存约为 24.6GB。
+ `6%`：GPU 的使用率。

在进程部分：

+ `0 N/A N/A 1 C /python3.10 N/A`：在 GPU `0` 上运行的进程。PID 为 `1`，类型为 `C`（Compute），进程名为 `/python3.10`。这可能是你在 Docker 容器中运行的 Python 应用，它正在使用 GPU 进行计算。具体的 GPU 内存使用量没有显示出来（`N/A`）。

注意，由于你在 Docker 容器中运行这个命令，所以这里显示的信息是关于容器内部环境的，可能与宿主机的环境有所不同。

## 持续运行容器

我们看一下此前运行容器的命令

```
docker run --gpus all --ipc=host --ulimit memlock=-1 --ulimit stack=67108864 --rm -it -v `pwd`/meta-llama:/app/meta-llama -p 7860:7860 soulteary/llama2:7b
```

这个命令中已经包含了 `-it` 选项，这个选项会让 Docker 以交互模式运行容器，并且会把控制台附加到容器的标准输入。这也就意味着，当你关闭控制台时，容器会停止运行。

如果你想让容器在后台持续运行，你需要使用 `-d` 选项（代表 "detach"）来替换 `-it`。`-d` 选项会让 Docker 在后台运行容器，并且会返回容器的 ID。

你的命令修改后应该是这样的：

```
docker run --gpus all --ipc=host --ulimit memlock=-1 --ulimit stack=67108864 --rm -d -v `pwd`/meta-llama:/app/meta-llama -p 7860:7860 soulteary/llama2:7b
```

这个命令会在后台启动容器，你可以通过 `docker ps` 命令来查看正在运行的容器，或者通过 `docker logs <container_id>` 命令来查看容器的日志。

注意，`--rm` 选项会在容器停止后自动删除容器。如果你想保留容器的状态以便于调试，你可能需要移除这个选项。

如果你希望在宿主机重启后容器能自动启动，你需要在运行命令中添加 `--restart` 选项。这个选项可以设置容器的重启策略。

例如，如果你希望在任何情况下容器都能自动重启，你可以使用 `--restart=always`：

```
docker run --gpus all --ipc=host --ulimit memlock=-1 --ulimit stack=67108864 --restart=always -d -v `pwd`/meta-llama:/app/meta-llama -p 7860:7860 soulteary/llama2:7b
```

这样，无论容器是正常退出还是因为错误退出，或者是宿主机重启，Docker 都会尝试重新启动这个容器。

### 使用 `nvidia-smi` 查询宿主机上的信息

`nvidia-smi` 是 NVIDIA System Management Interface 的缩写，它是一个用于监控和管理 NVIDIA GPU 设备的命令行实用程序。这个工具提供了对 GPU 的实时监控，以及对一些参数的配置控制。

以下是 `nvidia-smi` 的一些主要功能：

1. **GPU 状态监控**：`nvidia-smi` 可以显示关于 GPU 的各种信息，包括但不限于其型号、内存使用情况、温度、风扇速度、功耗以及当前正在运行的进程。

1. **GPU 性能管理**：`nvidia-smi` 允许用户对 GPU 进行一些配置，如设置功耗限制，调整内存和 GPU 时钟频率等。

1. **GPU 计算模式管理**：`nvidia-smi` 可以改变 GPU 的计算模式，这对于优化特定应用的性能可能是必要的。

1. **GPU 进程管理**：`nvidia-smi` 可以列出正在使用 GPU 的进程，并显示它们的 GPU 和内存使用情况。它也可以用于终止这些进程。

在大多数情况下，你只需要运行 `nvidia-smi` 命令，它就会显示出你的 GPU 的当前状态。例如，它可能会显示出你的 GPU 型号、总内存、已使用的内存、GPU 利用率、内存利用率、温度等信息。

`nvidia-smi` 是一个非常强大的工具，尤其是对于需要密集计算的应用，如深度学习、科学计算等。它允许你监控并管理你的 GPU，以确保它们能够以最佳性能运行。
