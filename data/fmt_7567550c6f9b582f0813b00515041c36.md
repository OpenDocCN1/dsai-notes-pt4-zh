to_all_seer_turn → 预言家阶段 (查人)

## ChinesePrompts 类详解

`ChinesePrompts` 是 `EnglishPrompts` 的逐句翻译版本，同时保留了占位变量。它们的用途、调用顺序、逻辑结构与英文版完全一致，只是语义更符合中文表达。比如：

| 英文版 | 中文版 |
| --- | --- |
| "Night has fallen, everyone close your eyes..." | "天黑了，请所有人闭眼。狼人请睁眼..." |
| "The game is over and werewolves win🐺🎉!" | "游戏结束，狼人获胜🐺🎉！" |
| "Now each player can reflect on their performance..." | "现在每位玩家可以对自己的表现进行反思..." |

这保证了整个系统可以通过简单修改 `Prompts` 变量实现语言切换，不需要改动游戏逻辑。

## Prompts 与结构化输出（Structured Output）的关系

在 `game.py` 里，所有 `Prompts.to_xxx` 的内容并不只是自然语言提示，它们会成为 模型输入的一部分（prompt template），指导 LLM 生成结构化结果。例如：

```
msg = await agent(
    await moderator(Prompts.to_witch_resurrect.format(
        witch_name=agent.name,
        dead_name=killed_player,
    )),
    structured_model=WitchResurrectModel,
)
```

模型会收到以下内容：

```
[仅女巫可见] Alice，你是女巫，今晚Bob被淘汰。
你可以用解药救他/她... 你要救Bob吗？请给出理由和决定。
```

而 `WitchResurrectModel` 会定义结构化 schema：

```
class WitchResurrectModel(BaseModel):
    reason: str
    resurrect: bool
```

LLM 输出：

```
{"reason": "I think Bob is a villager, so I will save him.", "resurrect": true}
```

于是 `msg.metadata['resurrect'] == True`，控制逻辑继续执行。这就是语言模板与结构化输出模型的配合机制。

## structured_model.py 代码解释

### 代码功能介绍

本段 `structured_model.py` 是“结构化输出协议层”：它把狼人杀中每个决策点（讨论是否达成一致、投票给谁、女巫是否救/毒、预言家查谁、猎人是否开枪/射谁）定义成 Pydantic 模型。当 `ReActAgent` 被调用时，会把这些模型作为 `structured_model=...` 传入，要求大模型按照给定 schema 输出（一般是 JSON），框架再把解析后的字段放进 `msg.metadata`，供 `game.py` 的流程控制使用（比如 `metadata['vote']`、`metadata['shoot']` 等）。好处：强约束、可校验、可国际化，并且随着“当前存活玩家列表”动态生成可选项，避免模型输出无效名字。

### 原始代码

```
# -*- coding: utf-8 -*-
"""The structured output models used in the werewolf game."""
from typing import Literal

from pydantic import BaseModel, Field
from agentscope.agent import AgentBase


class DiscussionModel(BaseModel):
    """The output format for discussion."""

    reach_agreement: bool = Field(
        description="Whether you have reached an agreement or not",
    )


def get_vote_model(agents: list[AgentBase]) -> type[BaseModel]:
    """Get the vote model by player names."""

    class VoteModel(BaseModel):
        """The vote output format."""

        vote: Literal[tuple(_.name for _ in agents)] = Field(  # type: ignore
            description="The name of the player you want to vote for",
        )

    return VoteModel


class WitchResurrectModel(BaseModel):
    """The output format for witch resurrect action."""

    resurrect: bool = Field(
        description="Whether you want to resurrect the player",
    )


def get_poison_model(agents: list[AgentBase]) -> type[BaseModel]:
    """Get the poison model by player names."""

    class WitchPoisonModel(BaseModel):
        """The output format for witch poison action."""

        poison: bool = Field(
            description="Do you want to use the poison potion",
        )
        name: Literal[  # type: ignore
            tuple(_.name for _ in agents)
        ] | None = Field(
            description="The name of the player you want to poison, if you "
            "don't want to poison anyone, just leave it empty",
            default=None,
        )

    return WitchPoisonModel


def get_seer_model(agents: list[AgentBase]) -> type[BaseModel]:
    """Get the seer model by player names."""

    class SeerModel(BaseModel):
        """The output format for seer action."""

        name: Literal[tuple(_.name for _ in agents)] = Field(  # type: ignore
            description="The name of the player you want to check",
        )

    return SeerModel


def get_hunter_model(agents: list[AgentBase]) -> type[BaseModel]:
    """Get the hunter model by player agents."""

    class HunterModel(BaseModel):
        """The output format for hunter action."""

        shoot: bool = Field(
            description="Whether you want to use the shooting ability or not",
        )
        name: Literal[  # type: ignore
            tuple(_.name for _ in agents)
        ] | None = Field(
            description="The name of the player you want to shoot, if you "
            "don't want the ability, just leave it empty",
            default=None,
        )

    return HunterModel
```

### 代码解释如下：

1. 讨论是否达成一致

```
class DiscussionModel(BaseModel):
    """The output format for discussion."""
    reach_agreement: bool = Field(
        description="Whether you have reached an agreement or not",
    )
```

+ **用途**：狼人小群“讨论阶段”每轮发言的结构化结果。
+ **字段**：
+ `reach_agreement: bool`：是否达成一致（在 `game.py` 中每轮讨论结束会检查这个布尔值；若为 `True`，则提前结束讨论）。
+ **在 `game.py` 的位置**：狼人讨论 `DiscussionModel` → 若一轮结束（轮数整除狼人数量）并且 `reach_agreement=True` 则 `break`。

2. 动态投票模型（全部投票点通用）

```
def get_vote_model(agents: list[AgentBase]) -> type[BaseModel]:
    class VoteModel(BaseModel):
        """The vote output format."""
        vote: Literal[tuple(_.name for _ in agents)] = Field(  # type: ignore
            description="The name of the player you want to vote for",
        )
    return VoteModel
```

+ **用途**：要求模型输出“投给谁”的单选结果。
+ **关键点**：`Literal[tuple(_.name for _ in agents)]`
+ 用传入的 `agents`（通常是当前存活玩家）构造一个字面量枚举，从而把 `vote` 限制在名字列表之内。
+ 这样无论是夜里的狼人投票，还是白天全员投票，都能保证只会投给“当下有效的人”。
