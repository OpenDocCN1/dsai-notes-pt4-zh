
# Translation Agent：基于反思工作流的智能翻译

> 来源：[https://agijuejin.feishu.cn/docx/I3uKdhKANopjojxdejKcWT2Zndg](https://agijuejin.feishu.cn/docx/I3uKdhKANopjojxdejKcWT2Zndg)
> 作者：lucas大叔
> 原文：[https://zhuanlan.zhihu.com/p/704413258](https://zhuanlan.zhihu.com/p/704413258)

Translation Agent是吴恩达大佬推荐的基于反思工作流的智能翻译，实现思想比较直接，主要步骤是：

1. 提示LLM将文本从`source_language`翻译成`target_language`；
2. 让LLM对翻译进行反思，提出建设性的改进建议；
3. 使用建议来改进翻译。

该系统以LLM作为翻译引擎的核心，具有高度的灵活性。相比传统的机器翻译，定制化更容易。通过修改提示词，可以：

+ 调整输出风格，正式/非正式
+ 指定如何处理俚语和特殊术语，例如名称、技术名词、缩略语等
+ 指定使用语言的特定区域或特定方言，同样的语言在不同国家表达方式略有不同，例如我们熟知的美式英语和英式英语

Translation Agent还不是成熟的软件，但作为基于智能体的翻译，它提供了一个继续探索的起点。

## 安装使用

按照 [github](https://github.com/andrewyng/translation-agent)上的指示，首先安装`Poetry`包管理器，

```
pip install poetry
```

克隆安装，如果LLM使用ChatGPT，需要在`.env`文件中指定`OPENAI_API_KEY`。

```
git clone https://github.com/andrewyng/translation-agent.git
cd translation-agent
poetry install
poetry shell # activates virtual environment
```

安装成功后，就可以在代码中导入`translate_agent`使用

```
import translation_agent as ta
source_lang, target_lang, country = "English", "Spanish", "Mexico"
translation = ta.translate(source_lang, target_lang, source_text, country)
```

另外，`examples/example_script.py`是个样例程序，可以直接执行体验。

## 本地模型调用

原始代码默认使用的LLM是`gpt-4-turbo`，使用成本有点高。。。

这里参考 `src/translation_agent/utils.py`进行改造，使其可以调用本地的`glm-4-9b-chat`模型，调用其他模型按照这个思路改改应该也都可以。

主要改造内容如下，利用`transformers`库加载`tokenizer`和`model`

```
device = "cuda"
# Load the Hugging Face model and tokenizer
model_name = "/path/to/glm-4-9b-chat"  # You can replace this with the Hugging Face model you want to use
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.bfloat16,
    low_cpu_mem_usage=True,
    trust_remote_code=True
).to(device).eval()
```

改写`get_completion`函数模型调用部分

```
inputs = tokenizer.apply_chat_template([{"role": "user", "content": prompt}],
                                           add_generation_prompt=True,
                                           tokenize=True,
                                           return_tensors="pt",
                                           return_dict=True,
                                           )
    inputs = inputs.to(device)
    gen_kwargs = {"max_length": max_length, "do_sample": True, "top_k": 1, "temperature": temperature}
    with torch.no_grad():
        outputs = model.generate(**inputs, **gen_kwargs)
        outputs = outputs[:, inputs['input_ids'].shape[1]:]
        generated_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
```

注释掉 `src/translation_agent/__init__.py`文件中的导入语句，改为 `from .custom_utils import translate`

### 英译中测试（学术领域）

源文本：

> In order to thrive in hostile and ever-changing natural environments, mammalian brains evolved to store large amounts of knowledge about the world and continually integrate new information while avoiding catastrophic forgetting. Despite the impressive accomplishments, large language models (LLMs), even with retrieval-augmented generation (RAG), still struggle to efficiently and effectively integrate a large amount of new experiences after pre-training. In this work, we introduce HippoRAG, a novel retrieval framework inspired by the hippocampal indexing theory of human long-term memory to enable deeper and more efficient knowledge integration over new experiences. HippoRAG synergistically orchestrates LLMs, knowledge graphs, and the Personalized PageRank algorithm to mimic the different roles of neocortex and hippocampus in human memory. We compare HippoRAG with existing RAG methods on multi-hop question answering and show that our method outperforms the state-of-the-art methods remarkably, by up to 20%. Single-step retrieval with HippoRAG achieves comparable or better performance than iterative retrieval like IRCoT while being 10-30 times cheaper and 6-13 times faster, and integrating HippoRAG into IRCoT brings further substantial gains. Finally, we show that our method can tackle new types of scenarios that are out of reach of existing methods.

翻译后的文本：

> 为了在敌对且不断变化的自然环境中生存，哺乳动物的大脑进化出储存了大量的世界知识，并在避免出现记忆灾难的同时不断吸收新信息。尽管取得了令人印象深刻的成就，但大型语言模型（简称LLMs），即使在检索增强生成（简称RAG）的情况下，仍然难以在预训练后有效地整合大量新经验。在这项工作中，我们引入了HippoRAG，这是一种受人类长期记忆的海马体索引理论启发的创新检索框架，以实现对新经验更深层次和更有效的知识整合。HippoRAG协同调度LLMs、知识图谱和个性化PageRank算法，模拟人类记忆中新皮层和海马体的不同作用。我们在多跳问答任务人类新皮层和海马体在人类记忆中的作用。我们将HippoRAG与现有的RAG方法在多跳问答上进行比较，并显示我们的方法显著优于现有最先进的方法，最高提升可达20%。使用HippoRAG的单步检索在性能上与IRCoT等迭代检索相当甚至更优，同时成本降低10-30倍，速度提升6-13倍，将HippoRAG集成到IRCoT中还能带来进一步的显著提升。最后，我们展示了我们的方法可以应对现有方法无法触及的新类型场景。

### 测试总结

翻译质量大体上还可以，不知道是不是模型自身能力的原因，按照翻译“信、达、雅”的标准衡量，翻译质量还有很大的提升空间。

在英译中时，有些会出现词不达意的表达，例如“我们在多跳问答任务人类新皮层和海马体在人类记忆中的作用。”。句子的顺畅表达方面还可以提升，例如“根据我与立法者的对话，我对美国联邦政府在了解人工智能风险方面取得的进展感到鼓舞。”改成“根据与立法者的对话，我对美国联邦政府在了解人工智能风险方面取得的进展感到鼓舞。”更好一些。
