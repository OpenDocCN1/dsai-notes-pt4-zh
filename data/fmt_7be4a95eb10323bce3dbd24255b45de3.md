
# 酒店评论数据预处理与数据集划分

## 导入依赖库与定义清洗函数

```python
import numpy as np
import pandas as pd
import re
from pathlib import Path
import os
import shutil


def cleanquestion(x: str) -> str:
    "去除文本中的符号 仅保留中文、英文、数字等"
    str_text = re.sub(
        u"([^\u4e00-\u9fa5\u0030-\u0039\u0041-\u005a\u0061-\u007a])", "", x)
    return str_text
```

`cleanquestion(x: str) -> str` 用于去除文本中的符号，仅保留中文、英文、数字等字符。

## 加载原始数据

使用 `pd.read_csv()` 读取 `data_all/ChnSentiCorp_htl_all.csv`，并通过 `pipe()` 调用 `dropna()` 删除缺失值：

```python
rawdata = pd.read_csv("data_all/ChnSentiCorp_htl_all.csv").pipe(
    lambda x: x.dropna()

rawdata
```

输出显示原始数据包含 7765 行 × 2 列。

## 查看标签分布

对 `rawdata` 按 `label` 分组，并使用 `agg()` 统计 `review` 列的频数 `freq`：

```python
rawdata.groupby(['label']).agg(
    freq = ('review', 'count')
)
```

输出结果显示标签 `0` 的频数为 2443，标签 `1` 的频数为 5322。

## 创建目标数据目录

定义 `target_data_dir = Path("data_all/data")`。如果目录已存在，则调用 `shutil.rmtree()` 将其删除，随后通过 `os.makedirs(name=target_data_dir, exist_ok=True)` 重新创建：

```python
target_data_dir = Path("data_all/data")

if target_data_dir.exists():
    shutil.rmtree(target_data_dir)

os.makedirs(name=target_data_dir, exist_ok=True)
```

## 划分数据集并保存

将 `review` 列重命名为 `text`，并按指定比例采样后分别保存为训练集、测试集和验证集。

### 训练集

采样 90% 的数据并保存至 `data_all/data/train_data.csv`：

```python
rawdata.sample(frac=0.9).pipe(
    lambda x: x.rename(columns={
        'review':'text'
    })
).to_csv("data_all/data/train_data.csv", index=False)
```

### 测试集

采样 10% 的数据并保存至 `data_all/data/test_data.csv`：

```python
rawdata.sample(frac=0.1).pipe(
    lambda x: x.rename(columns={
        'review':'text'
    })
).to_csv("data_all/data/test_data.csv", index=False)
```

### 验证集

采样 20% 的数据并保存至 `data_all/data/valid_data.csv`：

```python
rawdata.sample(frac=0.2).pipe(
    lambda x: x.rename(columns={
        'review':'text'
    })
).to_csv("data_all/data/valid_data.csv", index=False)
```

> 补充：另一个单元格对 `rawdata` 执行了 `sample(frac=0.9)` 并将 `review` 列重命名为 `text`，仅展示结果，未写入文件。输出显示采样后数据包含 6988 行 × 2 列。
