
# 案例：迭代优化文案

展示如何通过迭代优化提高文案质量：

第一次尝试：

```
你：请帮我写个智能耳机的文案。

Claude：这款智能耳机采用先进的降噪技术，音质出色，续航时间长，佩戴舒适。
```

第二次优化：

```
你：文案太简单了，请详细一些，突出产品的核心卖点。

Claude：这款智能耳机采用先进的主动降噪技术，有效隔绝外界噪音，让你沉浸在纯净的音乐世界中。40mm 大动圈单元，呈现丰富细腻的音质。超长续航，单次充电可连续播放 30 小时。人体工学设计，搭配柔软的耳罩，即使长时间佩戴也依然舒适。
```

第三次优化：

```
你：不错，但希望能更生动一些，加入一些场景描述，字数控制在 200 字左右。

Claude：在喧嚣的地铁上，一键开启降噪，世界瞬间安静。在安静的图书馆里，享受纯净的音乐，不打扰他人。40mm 大动圈单元，每一个音符都清晰可辨。30 小时超长续航，从周一到周五，无需充电。柔软耳罩，全天佩戴依然舒适。

这款智能耳机，让音乐成为你生活中最美好的陪伴。
```

第四次优化：

```
你：很好！现在请帮我写三个不同风格的版本：专业版、幽默版、温馨版。

Claude：
**专业版**：
SoundPro 智能降噪耳机，采用先进的主动降噪技术，降噪深度达 35dB。40mm 大动圈单元，频响范围 20Hz-20kHz，呈现专业级音质。30 小时超长续航，支持快充，充电 10 分钟，可使用 3 小时。人体工学设计，重量仅 250g，佩戴舒适无负担。

**幽默版**：
还在为找不到安静的地方发愁？这款智能耳机，一键开启"静音模式"，世界瞬间清静。音质好到让你怀疑人生，续航长到让你忘记充电。戴着它，你就是街上最靓的仔！

**温馨版**：
有时候，你需要一个安静的空间，让自己放松下来。这款智能耳机，为你创造一个专属的音乐世界。降噪技术隔绝外界干扰，让你专注于音乐本身。柔软的耳罩，像朋友的拥抱，温暖舒适。30 小时的陪伴，从清晨到深夜，音乐一直都在。
```

# 案例：调整输出格式

展示如何调整输出格式：

原始输出：

```
你：请帮我整理这些销售数据。

Claude：产品A销售额500000元，产品B销售额350000元，产品C销售额250000元，产品D销售额134567元。
```

调整为表格格式：

```
你：请帮我整理这些销售数据，输出格式为表格。

Claude：
| 产品 | 销售额（元） |
|------|-------------|
| 产品A | 500,000 |
| 产品B | 350,000 |
| 产品C | 250,000 |
| 产品D | 134,567 |
```

调整为带占比的表格：

```
你：请在表格中增加一列，显示各产品的销售额占比。

Claude：
| 产品 | 销售额（元） | 占比 |
|------|-------------|------|
| 产品A | 500,000 | 40.5% |
| 产品B | 350,000 | 28.4% |
| 产品C | 250,000 | 20.3% |
| 产品D | 134,567 | 10.8% |
```

## 小技巧

1. 逐步优化：不要期望一次就得到完美结果，逐步优化效果更好

2. 提供具体反馈：反馈越具体，AI 的改进越准确

3. 明确约束条件：字数、风格、格式等约束条件要明确

4. 多版本对比：要求生成多个版本，从中选择最好的

5. 保存优秀结果：将优秀的结果保存下来，作为参考

6. 记录有效提示词：记录效果好的提示词，方便下次使用

现在，试着用这些技巧提高 Claude Code 的输出质量吧！
