
+ 这条链接能不能带来咨询
+ 这条链接吸来的用户准不准
+ 这个类目和表达能不能接住需求

## 微付费阶段最常见的 3 种情况

### 情况 1：空烧

表现：

+ 钱在花
+ 曝光在涨
+ 咨询很少甚至没有

说明：

这条链接被看到了，但没把人点进来。

优先改：

+ 主图
+ 标题

不要先乱改投放设置。先把“用户为什么不点”解决掉。

### 情况 2：能烧动，但出价偏高

表现：

+ 有咨询
+ 预算能消耗
+ 单个咨询价格明显偏高

说明：

人群还没完全跑准，或者当前类目、词、主图的匹配度还不够好。

优先动作：

+ 先观察 2-3 天
+ 同时复盘类目、人群、关键词
+ 如果这条链接本身咨询质量不错，不要一上来就砍掉

### 情况 3：曝光低、浏览低、咨询低

表现：

+ 各项数据都弱

说明：

这条链接整体就不强，不值得继续烧。

优先动作：

+ 直接放弃
+ 重新换词、换主图、换表达、换链接测试

### 完成标准

> 当你出现下面的状态时，说明这一步已经跑顺了：

+ 至少有 1 条链接能稳定带来咨询
+ 你开始知道什么样的主图和标题能把用户吸进来
+ 店铺开始有成交和评价数据

## 七、数据优化：怎么看曝光、浏览、想要

通过数据判断问题出在哪一层，而不是凭感觉乱调。

### 三个核心数据先看懂

+ 曝光：你的链接被平台推到别人眼前了没有
+ 浏览：别人看到了之后，愿不愿意点进来
+ 想要/咨询：点进来之后，愿不愿意继续往下走

### 数据判断速查表

### 你每天复盘时就盯这几件事

+ 哪条链接的浏览最高
+ 哪条链接的想要最多
+ 哪条链接开始出现稳定咨询
+ 哪条链接反复优化还是没起色

你后面要做的不是“所有链接都救”，而是把有机会成为爆款的链接维护好，把弱链接及时换掉。

### 完成标准

> 你已经能根据数据判断：

+ 该改主图还是改标题
+ 该改描述还是改类目
+ 该继续烧还是直接放弃

## 八、导流与承接：咨询来了以后怎么接

### 先记住导流原则

优先走 拍下后导流。

不要一有私信就急着硬拉。很多号不是死在没流量，而是死在太急。

### 标准顺序

1. 用户拍下链接
1. 你先完成发货动作
1. 发导流承接内容
1. 用户按备注、二维码或🛰️号来加你
1. 你在🛰️里继续承接和转化

### 承接内容怎么放

常见做法是用一个网盘页，把几样东西一次性放好：

+ 备注说明
+ 🛰️号
+ 二维码
+ 简单引导语

这样用户点开后，不用反复问你，也更清楚下一步该干嘛。

小技巧：优先用夸克，毕竟他也属于阿里体系下面的

百度网盘还需要复制到浏览器才可以看

### 两种最常见情况怎么处理

#### 已读未加

说明用户看到了你的导流信息，但没行动。

这时候要补一句提醒，不是催命，而是让他知道：

+ 你要给他安排什么
+ 为什么现在就该来加
+ 晚了会损失什么

重点是补“行动理由”，不是单纯再发一遍二维码。

#### 未读未加

说明用户买了，但还没真正看信息。

这时候要做的是提醒触达，让他回来看消息，而不是立刻追加一堆新话术。

### 哪些动作最容易把前面白做

+ 没拍下就急着硬导流
+ 导流话术太直白
+ 咨询一多就乱发违规内容
+ 链接刚起来就把号搞废

### 完成标准

> 你至少已经有一套固定承接顺序：

+ 拍下后怎么发
+ 网盘里放什么
+ 已读未加怎么补
+ 未读未加怎么提醒

## 九、自然流阶段：号起来后每天怎么维护

### 进入自然流阶段的标志

+ 微付费阶段已经有稳定咨询
+ 店铺有基础成交和评价
+ 不只一条链接有反应
+ 停掉付费后，依然有自然咨询进来

### 每天固定动作

#### 每天上新 1-2 条链接

就算已有链接在跑，也要保持上新。

原因有两个：

+ 新链接会带来额外曝光
+ 你永远不知道下一条会不会成为新的爆款链接

#### 每天复盘数据

重点看：

+ 哪条链接还在持续进咨询
+ 哪条链接开始掉量
+ 哪条链接浏览高但咨询低

#### 继续做日常任务

**签到、任务中心、闲鱼**币这些动作，不是起号阶段才做，而是只要你在跑闲鱼，就要持续做。

#### 用闲鱼币去放大强链接

闲鱼币更适合投给已经跑出浏览和咨询的链接，快速把人群标签拉正，而不是瞎投给弱链接。

#### 把回复效率拉上来

自然流阶段，回复慢会直接影响店铺状态。

如果你号多，可以用工具统一收消息、做自动回复，但前提是你的基础流程已经跑顺。

### 日常维护清单

+ 每天上新 1-2 条
+ 每天做签到和免费任务
+ 每天看链接数据
+ 每天优先回复有效咨询
+ 每天观察爆款链接有没有掉量
+ 每天把弱链接和强链接分开处理

### 爆款链接的 3 个不要

1. 不要乱改爆款标题
1. 不要频繁上下架爆款链接
1. 不要大改爆款主图

爆款链接可以微调，但不要大动。很多人不是没爆款，而是把有机会的链接自己折腾死了。

### 可以加上的放大动作

+ 闲鱼币折扣
+ 两人小刀
+ 闲鱼联盟返佣

这些动作的本质都是增加链接的点击和分发概率。

### 完成标准

> 你已经进入“每天维护店铺”的状态，而不是“今天有空就看看，没空就放着”。
