## 3、AI英语口语陪练（教育行业）

在全球化的今天，英语口语能力已成为职场和学习的重要技能。然而，传统的英语学习方式往往重读写轻口语，很多学习者面临「哑巴英语」的困扰。找外教成本高昂，时间安排困难；和朋友练习又担心发音不准、语法错误。

那随着AI技术的不断发展，各大AI工具产品为这一痛点提供了新的可能性。

我们可以来尝试下制作一个AI英语口语陪练的应用，让用户可以快速地且随时随地进行口语练习，获得即时反馈和个性化指导，让英语口语学习变得更加便捷高效。

打开你的秒哒输入框，开始写提示词：

```
请为我设计一个专业的CET-6英语口语训练AI教练页面，具体要求如下：
1.模拟口语对话场景模块：
创建贴近大学生活的口语对话情境，包括但不限于：
- 校园兼职（如兼职家教、校园店铺服务生等）
- 图书馆借阅（如询问书籍位置、办理借阅手续等）
- 学生社团活动（如社团招新、活动策划与执行等）
- 宿舍生活（如室友交流、宿舍规定讨论等）
每个情境应包含对话双方的角色设定、对话背景及具体对话内容，对话内容需符合CET-6口语考试难度。
提供符合CET-6水平的话题讨论引导和应对策略，帮助学生熟悉考试题型和答题技巧。

2.实时纠错与建议模块：
- 在学生模拟对话过程中，实时指出语法、词汇和句式方面的错误。
- 提供语音语调、重音和停顿的具体建议，帮助学生提升口语表达的准确性和自然度。
- 给出更地道的表达方式替代选项，丰富学生的口语词汇库和表达方式。

3.能力评估报告模块：
- 分析学生口语的流利度，包括语速、连贯性和停顿情况。
- 评估词汇多样性和使用情况，指出学生常用词汇和高级词汇的使用比例。
- 指出发音准确性问题，包括音标发音、单词重音和句子语调等。
- 提供针对性的提升建议，针对学生的薄弱环节给出具体的改进方法和练习建议。

请确保页面设计简洁明了，操作便捷，能够为学生提供良好的口语训练体验。同时，页面应包含清晰的指导说明和反馈机制，以便学生随时了解自己的训练进度和效果。
```

## 4、翻转棋（小游戏行业）

在以前的文章中，已经尝试着生成了2048和贪吃蛇等游戏，这一次想试试新游戏的能力边界：翻转棋。

```
请帮我创建一个智能化的黑白格H5小游戏，包含以下功能：

**游戏模式：**
- 人机对战：多种难度的AI对手（新手、进阶、专家、大师）
- 在线对战：与全球玩家实时对弈
- 本地双人：同一设备上的面对面对战
- 残局练习：经典残局题目训练

**AI智能系统：**
- 智能提示：显示最佳落子位置和原因分析
- 悔棋功能：允许撤销上一步操作
- 走棋预测：显示AI的思考过程和可能走法
- 难度自适应：根据玩家水平自动调整AI强度

**学习辅助：**
- 规则教学：动画演示游戏规则和基本策略
- 战术指导：角落控制、边线策略、中盘技巧
- 复盘分析：回顾对局，分析关键节点的得失
- 进步追踪：记录胜率变化和技能提升

**视觉设计：**
- 3D棋盘：立体感强的游戏界面
- 翻转动画：棋子翻转的流畅动画效果
- 主题皮肤：木质、大理石、科技风等多种风格
- 粒子效果：落子时的光影特效

**竞技功能：**
- 段位系统：从青铜到王者的晋级体系
- 锦标赛：定期举办的线上比赛
- 积分排行：全球排行榜和地区排行
- 观战模式：观看高手对局，学习技巧

**社交互动：**
- 好友系统：添加好友，私人对战

- 聊天系统：对局中的礼貌用语和表情

传统的团建游戏往往缺乏新意，参与度不高。那这个时候，我们可以通过使用一些应用生成软件，让AI帮我们打造一个即兴词语卡片墙系统，以便于可以随机生成各种有趣的词语组合，用于破冰游戏、创意联想、团队协作等环节，让团建活动更加生动有趣，同时也能减轻行政人员的准备工作和负担。

测试Prompt如下👇🏻：

```
请帮我创建一个团建即兴词语卡片墙应用，具备以下功能：

**词语卡片系统：**
- 多类别词语库：情感词汇、动作词汇、物品名词、抽象概念、职场术语

- 自定义词语：支持添加企业文化、部门特色词汇

**团建游戏模式：**
- 破冰游戏：自我介绍词语提示
