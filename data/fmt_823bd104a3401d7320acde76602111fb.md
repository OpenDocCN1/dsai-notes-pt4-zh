## 1. Windows环境启动`Cursor`调用本地`QWQ`

### 1.1 `Ollama`的下载&安装

`Ollama`支持在`Windows`环境下进行部署下载，使用此方法下载意味着你可以无需调整任何硬件设备直接在你的电脑上实现`QWQ`模型的安装部署和推理使用。

首先要下载`Windows`版的`Ollama`文件，进入官网选择下图的内容进行下载：

`https://ollama.com/download`

![](img/8b23c0a9701fbe367975ff0e4c862d74.png)

当然，你也可以直接在浏览器中搜索关键词`ollama`,按照图中的实例点击进入官网亦可。

进入官网后点击正下方的Download按钮，进入下载页面。

![](img/39ddd62cf2aecc074747b649a93fcad9.png)

确保是在`Windows`环境的下载方式，即可点击Download for Windows开始下载。

![](img/a2f8b745afd7cab883c10920c1262e6e.png)

开始下载后便会在右上角下载/安装栏出现下图图标，安装完成后可以在下载栏或下载文件夹（你的默认下载路径）找到该文件。

![](img/4b4591bebda8104e98b7cc1bf9f2472a.png)

![](img/18fe2fa9bce0121539bc46324a8cf29a.png)

### 1.3 使用`Ollama`实现推理大模型`QWQ`安装启动全流程

启动`Ollama`可以直接在`Windows`的命令行中实现，通过`win+R`键启动`cmd`命令，打开命令行终端。

![](img/804faf53e420b449e8911593f97a8a3b.png)

![](img/025c9f968d314c9d7806fdba11fe1e46.png)

可以通过输入指令`ollama -v`来检查是否成功部署，如果通过返回版本号信息则成功。`Ollama`支持以下的命令操作，关于这些指令的具体含义可以查看第一节`Ollama`快速入门的内容。

![](img/602106457c4f5cbe9d807281f31360b0.png)

+   `QWQ`推理大模型的部署和使用

首先还是回到`Ollama`的官网，搜索关键词`QWQ`可以找到对应模型。

![](img/d65e1920c459441050866b0a66cf98d0.png)

在终端中执行命令`ollama run qwq`，即可下载该模型。模型下载完成后，会自动启动大模型，进入命令行交互模式，直接输入指令，就可以和模型进行对话了对应参数的模型的下载方式可以通过在`Ollama`官网查看到下载指令。

模型挂载网址：`https://ollama.com/library/qwq`

![](img/58eb5897660d2734e26d0e88dc491cf6.png)

完成下载后会直接进入模型启动状态，如果退出或刷新界面，再次输入指令`ollama run qwq`即可启动对应模型。

![](img/2d574f49b59f2261bfdc356e348211a9.png)

当命令行中返回`>>>`即可进行对话,实测通过`Ollama`启动这种方式，`Ollama`默认搭载的是`int4`量化的模型版本，使用该版本运行推理的时候需要21G左右的显存，单张24G显卡（如`RTX-XX90`）即可满足使用要求。

### 1.5 `Cursor`接入`Ollama`启动本地大模型`QWQ`

在左边栏如图位置点击插件栏，搜索`cline`.点击`install`进行下载。

![](img/4622d407c52b218bf68c46a745d132ed.png)

下载完成后会出现下图图标（可以实现卸载意味着已经安装好了哈哈）

![](img/5165868486fdf8437ad474e32a6534b8.png)

接下来我们继续在插件栏中找到已经下载好的`cline`，点击进入。

![](img/7affcea4407ba35420abd105361c1c63.png)

点开`Cline`插件，会看到以下的界面，我们需要先选择`API Provider`中的信息。

![](img/3d865bd673d950421634c83c634fabf4.png)

下拉界面选择`Ollama`

![](img/9d5e82def01ef8dc6c5129e4c9d7e16b.png)

如果是本机调用`Ollama`直接使用默认的`Base URL`即可，同时下面会展示所有可以通过`Ollama`驱动的模型列表，点击选择确认在`Model ID`中展示后，点击`Let's go`实现激活。

![](img/047088ab4e3bee41f0e0d4e0f5d743f4.png)

激活使用：此时在工具栏最右边会出现`cline`的机器人图标头像，如下图点击右数第二个图标`Open in Editor`实现工具调用。

![](img/b1e53fb98ffbd95a8c2df596466c7bdc.png)

![](img/94376b8605f5a52d74e285bf7a75d6da.png)

激活后在页面最右边出现页面可以进行对话，可以通过`@`+文件名的方式将对应代码文件交给大模型进行分析处理。

![](img/e5832c9d4778adf23645315aed27351e.png)

如下图所示，可以通过这种方式进行代码文件的查看。

![](img/dd6147b9b20d1a18c0ebc6c6262201b9.png)

通过在右下角进行交互可以实现本地`Ollama`驱动`QWQ`推理了。

![](img/2eeb3730820b87e1178fbd4cb1aca717.png)

不过使用这个插件并不能很好的适应`Cursor`的全部功能，这是由于`Cursor`本身其实不支持调用本地模型，而主营业务是调用各种线上模型`API`的方式实现辅助编程，因而使用这种方式一定程度上限制了模型交互。

## 2. Windows环境启动`Cursor`调用线上`QWQ`

### 2.1 注册`siliconFlow`

本次课推荐给大家一个线上`API`调用大模型的方式--`siliconFlow`，推荐大家使用这个平台来实现大模型借入的理由是这个平台它的模型全、价格实惠、并且模型速度很快，更重要的是，`siliconflow` 注册即可白嫖2000万不限时`token`额度，足以让你度过新手开荒期。

`siliconFlow`注册官网：`https://cloud.siliconflow.cn/account/ak`

![](img/e1e670189280c1f3bf4d4513f270dd7c.png)

该平台支持诸多主流模型的线上`API`调用，在模型广场可以搜索对应模型名称复制对应的模型`ID`，这里选择`Qwen/QwQ-32B-Preview`来进行测试。

![](img/c1b27282dd9ed9582b07f59cd5fc73d8.png)

在`siliconFlow`完成注册后在账户管理->`APi`密钥 中创建密钥，点击复制保存好为接下来的流程备用。

### 2.2 配置模型

返回`Cursor`应用里，如图点击打开`setting`设置。

![](img/837c84ea7e68ddc355e688fdbdb698f3.png)

在`Cursor Setting`中点击`Models`栏，接下来要完成几个参数的设置，首先将所有已经激活的模型关闭，点击下面`add model`,输入`Qwen/QwQ-32B-Preview`, 添加完成后记得打开模型后面的开关并将`Url`从默认的修改为`base Url : https://api.siliconflow.cn/v1`

并且点击`Verify`，即可完成添加

![](img/c149438636c887efbae9ce4018672c0a.png)

激活成功后效果如下图：

![](img/95bf68571f4440be75932d1bddf767f1.png)
