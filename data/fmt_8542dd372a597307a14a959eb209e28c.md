
## 一、基础训练配置

### 1. `--stage sft`

**含义**：训练阶段类型

+   `sft`：Supervised Fine-Tuning（监督微调）

+   其他选项：`pt`（预训练）、`rm`（奖励模型）、`ppo`（强化学习）

**效果**：

+   `sft`：用标注数据微调模型

+   `pt`：从头训练或继续预训练

+   `rm/ppo`：RLHF 训练

### 2. `--do_train True`

**含义**：是否执行训练

+   True：训练模式

+   False：只评估/推理

### 3. `--num_train_epochs 3.0`

**含义**：训练轮数（遍历数据集的次数）

| 值 | 效果 | 适用场景 |

| --- | --- | --- |

| **1-2** | 欠拟合风险 | 数据量很大（>10K） |

| **3-5** | ✅ 平衡 | 中小数据集（100-1K） |

| **10+** | 过拟合风险 | 极小数据集（<50），需监控 |

**您的配置**：3.0 ✅ 合适

## 二、模型和数据配置

### 4. `--model_name_or_path /home/ubuntu/Qwen3-VL-4B`

**含义**：基础模型路径

+   本地路径或 HuggingFace 模型 ID

### 5. `--preprocessing_num_workers 16`

**含义**：数据预处理的并行进程数

| 值 | 效果 |

| --- | --- |

| **1-4** | 慢，CPU 利用率低 |

| **8-16** | ✅ 快，充分利用多核 |

| **32+** | 边际收益递减 |

**配置**：16 ✅ 适合多核 CPU

### 6. `--dataset_dir data` + `--dataset llamafactory_train`

**含义**：数据集目录和名称

+   完整路径：`data/llamafactory_train.jsonl`

### 7. `--cutoff_len 2048`

**含义**：最大序列长度（token 数）

| 值 | 效果 | 显存占用 | 适用场景 |

| --- | --- | --- | --- |

| **512** | 截断长文本 | 低 | 短文本任务 |
