
# 信息管理

> 来源：[https://my.feishu.cn/docx/NKy8dHuM7orggSxo2PjcnHk2nbe](https://my.feishu.cn/docx/NKy8dHuM7orggSxo2PjcnHk2nbe)

> 层级管理、双链管理、标签管理、模型管理.....

> 知识管理有两大核心：⼀是梳理清楚知识之间的关系，这个就是知识体系的功能；⼀是收敛知识从而回归本质,这个就是第一原理的功能。

> 知识就是知识，当你得到了它，你就得到了一小片自己世界观的拼图，你拼得越多,世界观就越完善,在这个过程中,会有一种东西渐渐浮现,那就是你关于信息的直觉。——河森堡

> 我们不追求读书的速度，不追求读书的数量,我们甚至都不太追求记忆。我们只把掌握事物背后的法则,当做唯一的学习目标。——兰陵王《模型树》

> 世界分为「物质世界」和「法则世界」。法则世界支配着物质世界，它是永恒不变的；物质世界在法则世界的支配下,一直在运动、变化。而我们的感官又只能直接感受到物质世界,无法直接感受到法则世界。所以,单纯只靠记忆,我们是无法应对这个不断变化的世界的。——兰陵王《模型树》

> 「道虽然无法被直接感知,但是它主宰着万物」,所以我们可以通过万物的变化规律,来反推出背后的道。——兰陵王《模型树》

> 我们唯一能直接感知到的是规律"即某个现象一直在重复"。——兰陵王《模型树》

> 知识体系是一堆关系紧密"并严格按照其关系联结的知识的集合"——兰陵王《模型树》

> 我们在学习的时候,不仅仅要掌握每个知识的内容,还要掌握知识之间的关系。只有同时掌握了这两者,我们才能更加系统地看待事物,从而具备更加深刻的洞察力。——兰陵王《模型树》

> 学习可以说就是掌握事物关联性的过程,学习的本质就是把之前各自独立的信息在脑中关联起来。——《考试脑科学》

> 如果我们「没有」或者「不能」将知识都按照其关系联结在一起,那么即使我们学了再多知识,也只是盲人摸象而已。——兰陵王《模型树》

> 长久以来,我坚信存在某个系统——几乎所有聪明人都能掌握的系统,它比绝大多数人用的系统管用.你需要的是在你的头脑里形成一种思维模型的复式框架.有了那个系统之后,你就能逐渐提高对事物的认知。——查理·芒格

## 一、核心原则

### 1. 知识管理的两大核心

⭐ **核心1：梳理知识之间的关系**

+ 知识不是孤立的点，而是相互关联的网络

+ 建立知识体系，让知识有结构

⭐ **核心2：收敛知识回归本质**

+ 从现象到本质

+ 从碎片到模型

+ 从信息到洞察

### 2. 三个层次的管理

**层级管理：** 文件夹 → 子文件夹 → 文件

+ 清晰的分类

+ 便于查找

+ 结构清晰

**双链管理:** 知识之间的关联

+ 知识A和知识B有联系

+ 用链接把知识串起来

+ 形成知识网络

**标签管理:** 知识的特征

+ 给知识打标签

+ 便于检索

+ 灵活分类

**模型管理:** 提炼通用模式

+ 从案例中提炼模型

+ 从碎片中提炼本质

+ 从信息中提炼洞察

### 3. 学习的本质

⭐ 学习 = 掌握事物关联性的过程

+ 把独立的信息关联起来

+ 形成知识网络

+ 看到事物的本质

⭐ 学习目标 = 掌握事物背后的法则

+ 不是记忆知识点

+ 而是理解法则

+ 法则永恒不变，知识点不断变化

## 二、我的信息管理方法

### 1. 三个工具组合

**收集工具：** flomo / 🛰️收藏

+ 快速记录灵感

+ 碎片化收集

+ 不追求完美

**整理工具：** 飞书文档 / Obsidian

+ 结构化整理

+ 建立知识体系

+ 深度加工

**检索工具：** 飞书搜索 / Obsidian搜索

+ 快速找到信息

+ 关联知识

+ 回顾复习

### 2. 信息流动

**输入：** 阅读、听课、交流、灵感

+ 每天都有新信息进来

+ 不要追求完美，先收集

+ 碎片化收集，不要整理

**加工：** 提炼、整理、建模

+ 定期整理碎片

+ 提炼核心观点

+ 建立知识模型

**输出：** 写作、分享、应用

+ 知识要流通才有价值

+ 分享是最好的学习

+ 应用是最好的记忆

### 3. 知识体系

**我的知识体系：**

```
知识库
├── 关于信息（信息源、阅读笔记）
├── 关于效率（工具、方法、技巧）
├── 关于智慧（认知、原则、心法）
├── 关于项目（副业、实战、案例）
└── 关于生活（日志、回忆、成长）
```

**关键：** 知识要有结构，不是平铺。

## 三、实用技巧

### 1. 每周信息整理

**周日晚上30分钟：**

+ 回顾本周收藏的内容

+ 提炼核心观点

+ 整理到知识库

+ 删除无价值的信息

### 2. 每月知识复盘

**月末1小时：**

+ 回顾本月学到的知识

+ 提炼通用模型

+ 建立知识关联

+ 删除过时信息

### 3. 笔记三问

**记笔记时问自己：**

1. 这个知识可以用在哪里？

1. 这个知识和什么知识有关联？

1. 这个知识的本质是什么？

### 4. 信息减法

**定期删除信息：**

+ 这条信息还有价值吗？

+ 这条信息我能找到吗？

+ 这条信息我还在用吗？

+ 如果三个都是"否"，就删除

## 四、常见问题

### Q1: 收藏太多，看不过来怎么办？

+ 收藏≠学习

+ 定期清理收藏

+ 只保留真正有价值的

+ 建立信息减法机制

### Q2: 知识太碎片化怎么办？

+ 定期整理碎片

+ 提炼通用模型

+ 建立知识关联

+ 形成知识体系

### Q3: 学了就忘怎么办？

+ 知识要应用，不是记忆

+ 知识要关联，不是孤立

+ 知识要输出，不是收藏

+ 分享是最好的记忆

### Q4: 如何建立知识体系？

+ 先有主干（核心分类）

+ 再添枝叶（子分类）

+ 定期修剪（删除过时信息）

+ 持续生长（添加新知识）
