
# Translation Agent 翻译质量分析

在中译英时，会出现中式英语，例如“Tasks like document layout analysis, document information extraction, document visual question answering, and document image classification have all seen big jumps in performance. ”，翻译为“Document intelligent tasks represented by document layout analysis, document information extraction, document visual Q&A, and document image classification all have significant performance improvements.”更妥当一些。

总的来说，`Translation Agent` 是基于 LLM 翻译的一次不错的尝试，大家可以根据自己的场景优化提升。
