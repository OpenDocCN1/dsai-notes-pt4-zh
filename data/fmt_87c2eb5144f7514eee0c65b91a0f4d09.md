
# Cursor 新建文件

> 来源：[https://v11enp9ok1h.feishu.cn/docx/T3jZd6YTXohKkoxnO0OcMjPJnCb](https://v11enp9ok1h.feishu.cn/docx/T3jZd6YTXohKkoxnO0OcMjPJnCb)

Cursor 新建文件很简单，可以点击菜单栏的"文件"或左侧的"资源管理器"来创建：

![](img/889cb3ae1b8c812f6d337e04b97600e3.png)

通过"资源管理器"打开一个项目，项目上就有创建文件和创建目录的按钮：

![](img/039a5dfc7245543b23cc943cb2017ff3.png)

点击菜单栏的新建文件，会出现一个空文本，我们可以输入代码，并按下 `Ctrl + s` 来保存代码，输入文件名，并设置保存目录：

![](img/ed78cc5756126855736889c48f07a7f8.png)

通过"资源管理器"项目上按钮来创建文件，会先出现一个输入文件名的输入框，输入文件名后即可完成创建：

![](img/753be904795c33572fe9c3cb2017ff3.png)

## 智能补全与代码生成

Cursor 内置 IntelliSense 功能，根据上下文提供智能补全建议。

我们在编写代码，如 Python 或 JavaScript 时，Cursor 会预测我们要输入的内容:

![](img/d93f30ae2d3831f756df4406272aff29.png)

如果写上注释如 `# 计算平均数`，Cursor 就会自动帮我们实现功能，按下 `Tab` 键就可以才能 Cursor 提供的代码：

![](img/bdb8b3f70ca100783740a8a3e5ba70ca.png)

如果对代码不熟悉，需要 AI 来解析，可以通过快捷键 `Cmd/Ctrl + L` 来调出 AI 对话窗口：

![](img/db3305d97cffcd3e5ed2b5295d9fe641.png)
