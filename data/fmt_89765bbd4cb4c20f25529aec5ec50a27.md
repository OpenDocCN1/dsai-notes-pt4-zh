
# `@Definitions`

> 来源：[https://kcn9ut4m7icc.feishu.cn/docx/LPHxdhe4UopuCmx1g0jcJyPSnse](https://kcn9ut4m7icc.feishu.cn/docx/LPHxdhe4UopuCmx1g0jcJyPSnse)

Add nearby code definitions to `Cmd K` context using the `@Definitions` symbol

添加附近代码定义到 `Cmd K` 上下文，使用`@Definitions`符号

> This feature is currently only for `Cmd K`.

> 此功能目前仅适用于 `Cmd K`。

The `@Definitions` symbol adds all nearby definitions to `Cmd K` as context.

`@Definitions` 符号将附近的所有定义添加到 `Cmd K` 作为上下文。
