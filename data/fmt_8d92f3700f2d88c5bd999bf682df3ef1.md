## 二、上干货

### 核心逻辑总纲（贯穿全文的底层规则）

1. 时空跃迁：明确 “起点世界→目标世界” 的跳转关系（如现代→古代 / 玄幻 / 末日）

1. 金手指定位：作为主角核心倚仗，需绑定剧情（避免脱离主线的 “无敌挂”）

1. 创意延伸：通过 “脑洞 + 细节” 填补设定漏洞（如现代物品在异世界的合理用途）

### 穿越基础设定（决定开篇代入感）

#### 穿越类型（3 大核心模式）

| 类型 | 关键设定 | 冲突点 / 优势 / 劣势 | 适用题材 |

| --- | --- | --- | --- |

| 魂穿 | 附身身份（丫鬟 / 皇子 / 废柴少爷） | 易获得身份，快速融入剧情；需处理原身社会关系 | 宫斗、权谋、宅斗 |

| 身穿 | 落地处境（乞丐 / 战场 / 荒洞） | 优势：保留现代物品/身体优势；劣势：身份黑户，易被排斥 | 末世、原始、异世界 |

| 胎穿 | 重生状态（婴儿重活） | 优势：有时间布局积累优势3 岁懂事 / 10 岁顿悟，缺点：前期成长过程漫长 | 权谋、商业、修仙 |

#### 穿越触发与携带物（埋伏笔关键）

1. **新手建议：**从魂穿开始，最容易上手和展开剧情。

1. 触发方式（3 类场景 + 优化建议）

+ 职场型：加班猝死边缘→电脑血红色弹窗 “是否穿越”（带倒计时）

+ 意外型：车祸 / 雷击→附加神秘元素（闪电中显古代城门、雷击见家族祠堂虚影）

+ 主动型：生日许愿→蜡烛熄灭显选项框 “穿越到 XX 世界？是 / 否”

+ 优化原则：避免 “摔一跤穿越”，用 “祖传玉佩发光”“生日愿望伏笔” 替代

1. 携带物品（功能 + 伏笔双重作用）

+ 玉佩：刻上古符文→前期装饰，中期传送阵钥匙，后期关联原身家族

+ 手机：电量有限→短期当光源 / 指南针，中期映射异世界地图（迷雾区 = 隐副本）

+ 打火机：取火 / 造武器→引发古人敬畏，后期可作为 “异宝” 触发剧情

### 金手指与系统设定（主角成长核心）

#### 系统类型（3 大主流方向）

| 系统类型 | 核心规则 | 创意设计 |

| --- | --- | --- |

| 签到系统 | 每日签到地点随机 + 限制条件 | 皇宫签到得玉玺碎片，乱葬岗签到得阴魂仆从；限制：需踩特定地砖 |

| 任务系统 | 主线 + 支线绑定 + 失败惩罚 | 主线 “称帝 = 回家”，支线 “救郡主”；失败扣寿命；奖励：权谋术技能书 / 淬毒匕首 |

| 兑换系统 | 积分获取（打倒敌人）+ 冷却机制 | 神器需攒 30 天积分，普通道具即时兑换 |

#### 金手指设计原则

+ 有用性：必须能解决实际困境

+ 稀缺性：只有主角或极少数人拥有

+ 限制性：有冷却时间、消耗或代价（避免无敌文）

+ 成长性：随剧情发展可升级/进化

#### 金手指能力（3 类常见能力 + 限制）

1. 基础能力（带代价避免 “无敌”）

+ 读心术：3 米范围 + 用后头痛→读反派心发现宝藏，却被反派察觉异能

+ 时间回溯：每日 1 次 + 回溯后疲劳→救队友改战局，反派研究回溯规律反制

+ 元素控制：单元素（如火）+ 耗体力→后期解锁双元素，却遭元素反噬

1. 优化原则（绑定剧情 + 解决 BUG）

+ 剧情绑定：医学金手指 “需先找青霉菌”（增加探索线）；系统任务 “称帝 = 回家”（结合权力博弈）

+ BUG 修复：“召唤战斗机”→优化为 “召唤古代战机图纸”（需解决材料 / 工匠问题）

1. 常见金手指类型：

+ 知识型（现代医学、历史、科技）

+ 系统型（签到、任务、兑换）

+ 异能型（读心、元素控制、时间回溯）

+ 宝物型（玉佩、手机、未来武器）

### 世界构建体系（决定故事张力）

#### 主流世界类型（细节避免 BUG）

1. 古代历史世界（按朝代定核心线）

| 朝代 | 核心剧情线 | 关键细节（官职 / 货币 / 习俗） | 参考资料 |

| --- | --- | --- | --- |

| 唐朝 | 商业 / 文化线 | 官职：刺史 / 知府；货币：铜钱 + 绢帛；习俗：叉手礼（左手抱右手） | 《全唐诗》 |

| 宋朝 | 科举 / 商战线 | 货币：交子（仅四川用）；习俗：市井文化 | 《东京梦华录》 |

| 明朝 | 航海 / 经营线（资本主义萌芽） | 官职：按察使；货币：白银 + 铜钱 | 明史资料 |

| 清朝 | 宫斗 / 民族矛盾线 | 官职：总督≠巡抚；习俗：打千礼 | 清史稿 |

| 冷门（五代十国） | 乱世崛起线 | 混乱政权设定；参考《旧五代史》补细节 | 《旧五代史》 |

1. 玄幻世界（修炼 + 势力双维度）

+ 修炼体系：筑基（灵气入体需灵草）→金丹（御剑需丹药）→元婴（分身需过杀劫）；瓶颈：心境考验

+ 势力分布：正道 XX 宗（守正）、邪派 XX 教（修魔）、中立商会（卖情报 / 资源）

+ 特殊设定：灵气潮汐（定期爆发→生天材地宝 / 引兽潮）、神兽守护（麒麟守遗迹，认主放行）

1. 未来末日世界（危机 + 人类派系）

+ 丧尸围城：等级（普通→速度型→智慧型）；感染规则（咬伤 / 空气传播）；人类进化（异能者 / 机械改造）

+ 虫族入侵：种类（工蜂→战虫→母皇）；地球防线（城墙 + 能量罩）；人类派系（主战 / 求和）

+ 环境细节：辐射区（变异生物 + 稀有资源）、安全区（贵族统治，等级臂章区分）

#### 世界设定表模板（快速套用）

> 朝代/修炼等级/货币体系/核心势力/特殊规则

> 示例：

> 1. 唐朝 + 无修炼 + 铜钱 + 正邪门派 + 灵气潮汐；

> 2. 末日 + 异能者 + 物资兑换券 + 主战派 / 求和派 + 辐射区规则

### 剧情架构与节奏控制（避免烂尾）

#### 开场场景（10类选择 + 避坑）

1. **高冲突场景（开局3章内必须完成【穿越】+【困境】+【金手指初显】三个步骤）**

+ 刑场刀下：刽子手挥刀瞬间穿越，刀锋已触及脖颈

+ 战场中央：身穿重甲置身混战，不懂用剑差点被劈

+ 祭坛献祭：魔法阵发光，被当祭品即将献给邪神

+ 闺房毒杀：醒来发现原身被毒杀，凶手仍在房中

+ 龙床惊魂：穿越到皇帝床上，听见门外臣子密谋

+ 荒野逃生：身穿荒野被狼群包围，只有打火机防身

+ 考场作弊：科举考场刚穿越，衙役正走来搜身

+ 花轿错嫁：替嫁花轿中醒来，听说新郎是瘫痪暴君

+ 海底沉船：身穿古代沉船，氧气将尽黑暗窒息

+ 宗门测试：测出废灵根全场嘲笑，系统突然激活

1. **避坑：**

1. 拒绝 “一觉醒来在古代闺房”（平淡无冲突）；

1. 升级版开场：辞职摔信→天花板裂→龙爪捞走（加鳞片反光 / 黑雾黏腻触感）

#### 冲突设计（内外结合）

1. **外部冲突：**

+ 反派追杀（从刺客→精锐部队升级）；

+ 家族陷害（庶子被嫡兄栽赃通敌）；

+ 国仇家恨（宋穿辽→身份暴露被追杀）

1. **内部冲突：**

+ 道德困境（救仇人 vs 救爱人）；

+ 身份认同（现代灵魂 vs 古代责任，如皇子想当诗人却被逼争权）

#### 剧情推进方法

1. 冲突公式：解决 A（治好公主）→触发 B（被诬陷下毒，实则公主自导自演）

1. 钩子法：每章结尾留悬念（新娘玉佩 = 反派同款→暴露黑手；金手指失灵→陷绝境）

1. 伏笔回收：1 章玉佩发光穿越→10 章指引传送阵→结局启动传送（闭环）

#### 节奏控制（按章节划分）

| 阶段 | 章节范围 | 核心任务 |

| --- | --- | --- |

| 前期 | 1-3 章 | 1 章穿越，2 章觉醒金手指，3 章遇小贼→用金手指反制 |

| 中期 | 4-20 章 | 学技能→打小喽啰→突破金手指限制→战反派骨干；插入知识应用（制青霉素被当妖人 / 造蒸汽机封能工巧匠） |

| 后期 | 21 章 + | 与 BOSS 三战（山谷试探→皇宫绝境→异空间逆袭，场地 / 手段差异化）；主角蜕变 + 伏笔回收 |

### 角色塑造体系（避免工具人）

#### 主角弧光

+ 初期：废柴少爷（被排挤，金手指弱→召唤小傀儡）

+ 中期：学权谋 / 武功（救小乞丐→培养成心腹；解锁金手指隐藏能力）

+ 后期：蜕变（从逃避→主动担责，放弃回家守护世界）

#### 反派塑造（3 类 + 悲情底色）

| 反派类型 | 核心动机 | 塑造技巧 |

| --- | --- | --- |

| 圣母婊 | 伪善 “宽恕” | 优化：表面放敌人，暗留后手（避免降智） |

| 野心家 | 皇叔篡位（先帝害家族→童年阴影） | 用道具（破碎玉佩）+ 回忆杀（眼神突变）暗示过去 |

| 疯狂科学家 | 人体实验（爱人修炼惨死→走极端） | 回忆杀：实验室里的破碎画像 |

#### 配角与情感线

1. 配角设定（带成长 / 功能）

+ 小乞丐→情报头目：教识字→建情报网（性格：机灵贪财重情义，用现代梗吐槽）

+ 死党（搞笑担当）：说 “这任务太内卷”→解释 “竞争激烈”（反差萌）

+ 女将军：战场互救（性格飒爽有谋，互动：斗嘴 + 并肩作战）

1. 情感线：家族使命 vs 主角目标→产生误会→和解（避免无脑甜）

### 其他碎碎念

1. 场景描写：每个关键场景至少包含 2 种感官（视觉 + 触觉 / 嗅觉）

+ 市集（臭豆腐臭 + 胭脂香 + 铜锣声 + 糖葫芦甜 + 喧闹声）；

+ 修炼室（灵气清凉 + 丹药苦 + 突破时经脉胀痛）；

+ 末日废墟（腐臭味 + 钢筋锈味 + 丧尸嘶吼 + 风声呜咽）

1. 不要让主角轻易改变世界，先适应再局部影响

1. **不要忽略古代社会规则的约束力**

1. 不要让金手指太强而无限制，必须设门槛

1. 不要写双线叙事（穿越前后来回切换）

1. 不要让现代用语频出（偶尔玩梗可以）

### 章节细化大纲模板（直接套用）

#### 10章速成模板（以玄幻穿越为例）

1. 第1章：加班猝死→系统弹窗选择→魂穿废柴弟子

1. 第2章：记忆融合→了解被欺辱现状→恶奴上门挑衅

1. 第3章：系统首任务完成→获得新手奖励→初步打脸

1. 第4章：外门小比→用现代格斗术取胜→引起关注

1. 第5章：秘境探索→利用化学知识破阵→得第一桶金

1. 第6章：炼丹考核→提纯技术碾压→长老抢徒

1. 第7章：宗门大比→连胜天才→遭嫡系弟子嫉妒

1. 第8章：被陷害逐出师门→反杀追兵→得奇遇

1. 第9章：三月后→实力大涨→王者归来

1. 第10章：当众揭穿阴谋→洗刷冤屈→打脸全场

## 三、提示词（结合雪花写作法）

```
# 穿越文创作指南：雪花写作法实战手册

## 🎯 核心目标
本指南将引导你从零开始，逐步构建一个结构完整、爽点清晰的穿越故事大纲。请依次完成以下六个步骤。

### 第一步：一句话概括（核心概念）
用一句话说清你的故事内核：【现代身份】的主角穿越到【世界背景】，凭借【核心金手指】，必须完成【核心目标】，否则将面临【最坏后果】。

*   现代身份: (例: 社畜程序员、外科医生、历史系学生)
*   世界背景: (例: 修仙世界、唐朝贞观年间、末日废土)
*   核心金手指: (例: 内卷系统、医学知识库、预知历史的记忆)
*   核心目标: (例: 百日筑基、废除奴隶制、拯救即将灭亡的宗门)
*   最坏后果: (例: 系统抹杀、被处死、与世界一同毁灭)


### 第二步：一段话扩展（故事主线）
将你的“一句话”扩展成一段话（约5句），勾勒出故事的主线进程。
1.  开端（触发与困境）： 主角因______（穿越方式）穿越，刚醒来就面临______（致命初始困境）。
2.  破局（金手指）： 在绝境中，他觉醒了______（金手指），通过______（方式）初步解决了危机。
3.  发展（目标与成长）： 为了达成最终目标，他必须先后完成______、______、______（三个中期目标），在此过程中不断成长和积累势力。
4.  高潮（终极冲突）： 最终，他需要与______（主要反派）在______（地点）进行决战，决战的关键在于______（核心矛盾或智斗）
5.  结局（落幕）： 故事以主角______（结局状态）告终，他最终选择了______（回家/留下）

### 第三步：角色档案（人物弧光）
为你故事中的关键角色建立档案，思考他们如何推动剧情。
#### 1. 主角
*   姓名：
*   现代身份/技能： (与金手指相关的技能，如：编程、医学、历史知识)
*   穿越后身份： (如：废柴庶子、冷宫妃子、战场小兵)
*   核心动机： (求生、回家、复仇、守护)
*   人物弧光： 开始时他是______（性格/状态），结束时他将变为______（性格/状态）。

#### 2. 主要反派
*   姓名：
*   目标： (他想要什么？为何与主角冲突？)
*   信念： (他为何认为自己才是对的？) *（可选：悲情往事）*

#### 3. 重要配角 (至少1位)
*   姓名 &amp; 身份：
*   功能： (如：引导者、盟友、爱人、喜剧担当)
*   与主角的关系变化： (从______到______)


### 第四步：场景序列（故事卡串联）
将你的主线分解为4-8个关键阶段，并为每个阶段填入1-N个“故事卡”。这是你情节的骨架。

| 阶段一：开局 | 生存下来，熟悉世界  | 【身穿/魂穿】-&gt;【陷入困境】-&gt;【金手指觉醒】-&gt;【临危受命】-&gt;【装逼打脸】(初级)                                                                                             | 危-&gt;爽                 |
| 阶段二：发展 | 提升实力，积累资本   | 【贵人相助】-&gt;【寻宝之旅/秘境探索】-&gt;【得到神器】-&gt;【比试】(以弱胜强) -&gt;【好感变化】                                                                                        | 爽-&gt;燃-&gt;甜             |
| 阶段三：转折 | 遭遇挫折，揭示阴谋    | 【势力相争】-&gt;【遭遇背叛】-&gt;【绝境求生】-&gt;【因祸得福】                                                                                                                   | 危-&gt;燃                 |
```
