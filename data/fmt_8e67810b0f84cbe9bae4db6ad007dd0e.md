## ✅ 1. 小球在旋转多边形中弹跳（动画 + 物理模拟）

### 提示词：

```
请生成一个独立的HTML文件，其中包含一个在六边形边界内弹跳小球的模拟器。

所有代码应包含在 `&lt;html&gt;` 文件内，不要引用外部库或文件。

该模拟器应具备以下功能：

## 视觉与布局
* 深色主题界面，中心有一个发光的蓝色六边形边界。
* 一个小型的彩色小球在该六边形内弹跳。小球移动时应留下微妙的、逐渐消失的轨迹。
* 屏幕右侧应有一个控制面板，包含用于调整模拟参数的滑块。

## 模拟参数（初始值和范围）
1. **小球大小 (Ball Size)**：一个用于控制小球半径的滑块。
  * 初始值：15像素 (px)
  * 范围：大约 5px 到 30px
2. **重力 (Gravity)**：一个用于控制施加到小球垂直加速度的滑块。
  * 初始值：0.5
  * 范围：大约 0 到 1
3. **弹性 (Elasticity)**：一个用于控制小球弹性的滑块（碰撞后保留的速度量）。
  * 初始值：0.9
  * 范围：大约 0 到 1
4. **旋转速度 (Rotation Speed)**：一个用于控制六边形边界旋转速度的滑块。
  * 初始值：1°/帧 (1°/frame)
  * 范围：大约 0°/帧 到 5°/帧

## 小球行为
* 小球应持续在六边形的内部边缘弹跳。
* 碰撞应显得逼真，小球的轨迹应根据撞击角度和“弹性”设置而改变。
* “重力”设置应影响小球的向下加速度。

## 交互
* 用户应该能够拖动滑块以实时更改模拟参数。
* 每个滑块的显示值应随滑块的移动而更新。
* 小球的颜色在碰撞时应动态变化，例如在红色、绿色和粉色之间切换。

## 技术考量
* 使用HTML作为基本结构。
* 使用CSS进行样式设置（颜色、布局、发光效果）。
* 使用JavaScript进行物理模拟、在`&lt;canvas&gt;`元素上绘制小球和六边形，以及处理滑块交互。
* JavaScript应实现一个游戏循环（例如，`requestAnimationFrame`）来更新模拟。
* 确保动画流畅。
```

## ✅ 2. 烟囱爆破效果模拟

### 提示词：

```
请生成一个独立的HTML文件，其中包含一个可交互的砖块烟囱爆破模拟器。

所有代码应包含在 `&lt;html&gt;` 文件内，不要引用外部库或文件。

该模拟器应具备以下功能：

## 视觉与场景
* 深色或简洁的背景，主要呈现一个平坦的基底（地面）。
* 在基底上构建一个由多个砖块堆砌而成的烟囱状结构。
* 烟囱和地面应有基本的3D渲染效果，使其看起来有体积感。
* 整个场景应支持3D视角旋转，允许用户从不同角度观察。

## 模拟功能
1. **初始状态**：加载时，显示一个完整、稳固的砖块烟囱。
2. **爆破触发**：用户应能通过点击或特定的交互（例如，视频中类似“引爆模拟”的按钮）来触发烟囱的爆破。
3. **物理模拟**：
  * 爆破发生时，烟囱应碎裂成大量的独立砖块。
  * 碎裂后的砖块应受重力影响下落，并相互之间发生碰撞，最终散落在地面上。
  * 碰撞和下落过程应尽可能模拟真实的物理效果。
4. **重置功能**：提供一个“重置场景”或类似功能的按钮，点击后能将烟囱恢复到初始的完整状态，以便再次进行爆破模拟。

## 交互与控制面板
* **控制面板**：在屏幕左上角显示一个控制面板，包含以下交互选项：
  * **“引爆模拟”按钮**：用于触发烟囱的爆破。
  * **“重置场景”按钮**：用于将模拟重置到初始状态。
  * **“切换视角”或“3D视角控制”**：一个提示或模式，指示用户如何通过鼠标（例如，鼠标左键拖拽旋转视角，鼠标右键拖拽移动视角，滚轮缩放）来控制场景的3D视角。面板上应有相应的文字说明，例如：“鼠标左键：旋转视角；鼠标右键：移动位置；滚轮：缩放”。
* **底部信息显示**：在屏幕左下角显示实时信息，例如：
  * **“物理对象数量”**：显示当前场景中参与物理模拟的对象数量（例如，初始烟囱由多少砖块组成，爆破后碎裂成多少小块）。
  * **“模拟状态”**：显示当前模拟的状态（例如，“等待引爆”、“模拟中”、“模拟完成”）。

## 技术考量
* 使用HTML作为基本结构。
* 使用CSS进行基本布局和样式设置。
* 核心模拟功能必须使用JavaScript实现。
* 3D渲染部分可以考虑使用基本的3D图形库或直接通过`Canvas` API实现（如果大模型能独立生成复杂3D渲染代码）。
* 物理模拟部分应包含对碰撞检测、重力、力和动量的处理。
* 确保动画流畅，即使在大量物理对象参与模拟时也能保持良好的性能。
```

## ✅ 3. 太阳系运行模拟器

### 提示词：

```
请生成一个独立的HTML文件，其中包含一个可交互的太阳系模拟器。

所有代码应包含在 `&lt;html&gt;` 文件内，不要引用外部库或文件。

该模拟器应具备以下功能：

## 视觉与场景
* **背景**：深色背景，模拟宇宙空间。
* **恒星**：中心应有一个发光的大型黄色球体代表太阳。
* **行星**：围绕太阳绘制八颗主要的行星（水星、金星、地球、火星、木星、土星、天王星、海王星），每颗行星的颜色和相对大小应有视觉区分度。土星应有环。
* **轨道**：为每颗行星绘制椭圆（或圆形）轨道，以同心圆或接近同心圆的形式环绕太阳，清晰地显示它们的运动路径。
* **标题**：页面顶部中央显示“Solar System Simulation”标题。

## 模拟功能
* **行星运动**：
  * 所有行星应以各自的速度沿其轨道围绕太阳公转。
  * 行星的公转速度应与其实际太阳系中的相对速度成比例，越靠近太阳的行星移动越快。
* **初始状态**：加载时，行星应处于其预设的初始位置，并可能处于暂停状态或以默认速度开始运行。

## 交互与控制面板
* **控制面板**：在模拟区域下方有一个水平布局的控制面板，包含以下交互元素：
  * **“`Start`”按钮**：点击后开始或恢复模拟。
  * **“`Pause`”按钮**：点击后暂停模拟。
  * **“`Reset`”按钮**：点击后将所有行星重置到其初始位置和默认速度。
  * **“`Speed`”滑块**：一个滑块控件，允许用户调整模拟的速度，范围从慢速到快速（例如，从1倍速到5倍速，并显示当前的倍数）。

## 技术考量
* 使用HTML作为基本结构。
* 使用CSS进行基本布局、背景、按钮和行星的样式设置。
* 核心模拟功能必须使用JavaScript实现，包括：
  * 绘制太阳、行星和轨道（推荐使用 `&lt;canvas&gt;` 元素进行绘制）。
  * 计算行星的实时位置以模拟公转。
  * 处理“`Start`”、“`Pause`”、“`Reset`”按钮的点击事件。
  * 根据“`Speed`”滑块的值调整模拟的帧率或步长。
* 确保动画流畅，行星运动轨迹平滑。
```

## ✅ 4. 粒子漩涡模拟器

### 提示词：

```
请生成一个独立的HTML文件，其中包含一个可交互的粒子漩涡模拟器。

所有代码应包含在 `&lt;html&gt;` 文件内，不要引用外部库或文件。

该模拟器应具备以下功能：

## 视觉与动画
* **背景**：深色（接近黑色）的背景。
* **粒子**：
  * 屏幕上应充满大量随机分布的粒子。
  * 粒子应具有不同的颜色（例如，视频中主要显示白色、青色/浅蓝色、洋红色/粉色等），并带有发光效果。
  * 粒子应持续地、缓慢地在屏幕上随机移动或漂浮，呈现出一种“星空”或“浮游”的感觉。
  * 粒子移动时应带有短暂的拖尾效果，增强动态感。
* **标题**：页面顶部左侧显示“PARTICLE VORTEX”标题。
* **底部提示**：页面左下角显示交互提示文字：“Click and hold to create black hole - Release to free particles”。

## 交互效果（重点）
* **“黑洞”创建与吸引**：
  * 当用户点击并按住鼠标左键时：
    * 在鼠标指针位置应创建一个视觉上的“黑洞”效果（例如，一个小的、可能带有吸入动画的中心点）。
    * 屏幕上所有可见粒子应开始被这个“黑洞”吸引，以线条状轨迹快速向“黑洞”中心汇聚。粒子在被吸引过程中应保持其颜色和发光效果。
    * 粒子被吸引的速度和强度应随着粒子与“黑洞”的距离而变化，距离越近吸引力越大。
* **粒子释放与散射**：
  * 当用户松开鼠标左键时：
    * “黑洞”效果消失。
    * 被吸引的粒子应从“黑洞”中心向外高速散射，回归到无吸引力的自由运动状态，但散射后仍受重力或随机漂浮效果影响，逐渐恢复到初始的随机移动状态。散射轨迹应带有明显的拖尾。

## 技术考量
* 使用HTML作为基本结构。
* 使用CSS进行基本布局和背景样式。
* 核心模拟和交互功能必须使用JavaScript实现，包括：
  * 使用 `&lt;canvas&gt;` 元素绘制粒子及其轨迹。
  * 粒子对象的管理（位置、速度、颜色、大小等属性）。
  * 实现粒子的随机漂浮运动。
  * 监听鼠标的 `mousedown` 和 `mouseup` 事件。
  * 在 `mousedown` 时计算并应用“黑洞”的引力效果，更新粒子的速度和位置。
  * 在 `mouseup` 时取消引力，并应用散射效果。
  * 粒子拖尾效果的渲染。
  * 确保动画流畅，即使在大量粒子同时移动和交互时也能保持良好的性能。
```

## ✅ 5. 响应式官网设计

### 提示词：

```
请生成一个独立的HTML文件，其中包含一个响应式的企业官网首页。

所有代码应包含在 `&lt;html&gt;` 文件内，不要引用外部库或文件。

该官网首页应具备以下功能和特点：

## 整体设计与风格
* **响应式布局**：页面应在不同屏幕尺寸（桌面、平板、手机）下自动适应并优化布局，提供良好的用户体验。必须使用 CSS Flexbox 或 Grid 来实现响应式设计。
* **整体风格**：简洁、现代。
* **配色方案**：以蓝色和白色为主色调，辅以少量灰色或强调色。
* **字体**：选择易读的无衬线字体。
* **图标**：使用简洁的图标，例如SVG或字体图标（如果可以内联嵌入）。

## 页面结构与内容

### 1. 顶部导航栏 (Header Navigation)
* **布局**：固定在页面顶部，即使页面滚动也保持可见。
* **内容**：
  * **公司 Logo**：位于导航栏左侧，可以是文本或简单的图形占位符。
  * **导航链接**：位于导航栏右侧，包含至少4-5个主要页面链接（例如：首页、关于我们、服务、案例、联系我们）。链接应具有悬停效果。
* **响应式行为**：在小屏幕设备上，导航链接应折叠成一个可点击的汉堡菜单图标，点击后展开/收起导航菜单。

### 2. 全屏轮播图 (Hero Carousel)
* **尺寸**：占据屏幕宽度，高度自适应或固定高宽比，确保在不同屏幕下视觉效果良好。
* **内容**：
  * 至少包含3张示例图片作为轮播内容。图片应具有简洁的叠加文本（例如，公司Slogan或核心价值）。
  * 示例图片应具有统一的风格，与整体设计配色匹配。
* **功能**：
  * **自动播放**：轮播图应自动定时切换。
  * **手动切换**：提供左右箭头按钮，用户可以手动切换图片。
  * **指示器**：底部应有小圆点或横线等指示器，显示当前是第几张图，并可点击切换。
* **动画**：切换时应有平滑的过渡动画。

### 3. 公司简介部分 (About Us Section)
* **布局**：居中对齐，内容区宽度适中。
* **内容**：
  * **标题**：清晰的标题，例如“关于我们”或“我们的故事”。
  * **文本描述**：一段或多段关于公司背景、使命、愿景的介绍文本（占位符文本即可）。
  * **配图**：一张或多张与公司相关的配图，图片应与文本内容形成良好排版（例如，文本环绕图片或图片与文本左右布局）。

### 4. 服务项目展示区域 (Services Section)
* **布局**：
  * 采用三列布局，每列代表一个服务项目。
  * 在小屏幕设备上，布局应自动调整为单列堆叠显示，以适应屏幕宽度。
* **内容**：
  * 每个服务项目：
    * **图标**：一个代表服务内容的简洁图标（可以是占位符或简单SVG）。
    * **标题**：服务项目的名称（例如：“网站开发”、“移动应用”、“UI/UX设计”）。
    * **简短描述**：对该服务项目的简要介绍。

### 5. 客户评价部分 (Testimonials Section)
* **布局**：居中对齐，展示至少三条客户评价。可以使用Flexbox或Grid实现卡片式布局。
* **内容**：每条客户评价卡片应包含：
  * **客户头像**：一个圆形或方形的客户头像占位符。
  * **客户姓名**：客户的姓名。
  * **评价内容**：客户对服务的简短正面评价文本。

### 6. 底部信息区 (Footer)
* **布局**：占据页面底部全宽，背景色可以与导航栏或主体内容有所区分。
* **内容**：
  * **联系信息**：公司地址、电话、邮箱等（占位符文本）。
  * **社交媒体链接**：至少包含3-4个社交媒体图标链接（例如：LinkedIn, Twitter, Facebook, Instagram），图标应具有悬停效果。
  * **版权信息**：包含公司名称和当前年份的版权声明。

## 技术考量
* **HTML结构**：语义化HTML5标签，清晰的文档结构。
* **CSS样式**：
  * 充分利用CSS Flexbox 和/或 Grid 进行布局和响应式调整。
  * 确保元素之间的间距、对齐、字体大小和行高都经过优化，在不同屏幕上保持视觉和谐。
  * 按钮、链接等交互元素应有清晰的视觉反馈（例如，悬停、点击效果）。
* **JavaScript功能**：
  * 实现顶部导航栏在滚动时固定（sticky header）。
  * 实现全屏轮播图的自动播放、手动切换和指示器功能。
  * 实现响应式导航菜单的展开/收起逻辑。
  * 确保所有交互功能（如按钮点击）都能正常工作。
```

## ✅ 6. 动画天气卡片展示页

### 提示词：
