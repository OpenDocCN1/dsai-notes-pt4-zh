## 一、如何做到全情投入

### 1、什么是精力及如何管理精力

#### （1）精力管理基础

**精力与效率：**

+ 我们对广度的热爱超过了对深度的关注，注重反应速度却不愿深入思考。

+ 精力，而非时间，是高效表现的基础。如果精力的多少、质量、集中程度和力度不恰当，我们所做的一切事情效果都会大打折扣。有技巧的精力管理是高度表现、健康和幸福的基础。

**从旧观念到新观念的转变：**

+ 旧观念：管理时间、避免压力、生活是一场马拉松、放松是在浪费时间、回报驱动表现、依靠自律、积极思考的力量。

+ 新观念：管理精力、追求压力、生活是一系列短跑冲刺、放松是有效产出的基石、目标驱动表现、依靠习惯、全情投入的力量。

+ 看到这里，我觉得我以前是铁打的旧观念。现在在慢慢向新观念转变，还有一个是依靠习惯是不用动脑就可以做的很好，依靠自律是每天都要给自己提醒，提醒久了就会有一点本末倒置。

**压力与成长：**

+ 精力才是完全点燃才华和技能的正解。

+ 精力使用不足也会消耗精力！！比如周末过度躺平。

+ 要想保持生命的跃动，我们必须学习如何有节奏地消耗和更新精力。

+ 不管面对挑战是如何紧张激烈，终点线就在100米或200米开外，清晰可见。

+ 压力并非是我们生活中的敌人，相反，它是我们成长的关键。

+ 变革的难点在于，有意做出的改变常常无法坚持下去。

**仪式习惯与精力管理：**

+ 仪式习惯的优势在于，确保我们在非必要情况下尽量减少意识精力的消耗，让它可以节省下来用在其他需要的方面。其实就是《认知觉醒》一书中所说的，养成不用动脑的习惯，不用过度思考，就知道我下一步要干嘛。

+ 回顾生活中那些积极而高效的时刻，你会发现背后少不了某些特定习惯的帮助。比如你饮食规律，很可能是采购食品的习惯和点餐的规律所致。

+ 为了确保全情投入，建立良好的仪式习惯是精力管理的最有效方式。建立仪式习惯，减少在做与不做之间纠结的精力损耗，以及对做这件事排斥心理而造成的大量精力损耗。

#### （2）保持全情投入

**全勤投入的影响：**

+ 全情投入会从根本上颠覆我们的生活方式。全情的投入才会让我们产生心流，收获健康积极的正能量，促使我们更好的生活。

+ 一天如果干了很多活，到晚上的时候会发现成就感满满，就减少了身心上的疲惫。

**保持全情投入的的三个步骤：**

+ 明确目标 —— 依照我们最深层次的价值取向去分配精力。

+ 制定变革的计划 —— 面对现实，找出会让自己分散精力的事情，努力去克服，遇事不拖延。

+ 开始行动 ——

+ 用实际行动缩小“现实的我”与“理想的我”、 “目前的精力管理方式”与“为达目标所需要的精力管理方式”之间的差距。

+ 为了追赶进度盲目地一心多用，放弃更有挑战性的长期目标而转投看似容易的紧急事件，对私人生活不管不顾等，这些习惯的恶果只会随着时间慢慢显现。

+ 比如当我们学习各种课程的时候，一定要讲究ROI！！不要盲目为了刷题而刷题。

### 2、常见障碍解析

**体能不足是罪魁祸首：**

+ 日常生活中，我们的早餐进食时间和食物的选择会影响午餐的时间，而午餐的时间又会影响午休时间和质量。蝴蝶效应般，如果一步错，就很容易导致步步错。

+ 要有良好的生活节奏和状态，之后才能更加灵活的去处理其他事情。

+ 做想拖延的事情时，告诉自己只要学5分钟，5min让自己慢慢进入初步专注的状态，事情就能坚持下去了。

**情感账户告急：**

+ 没有了情感的交流，只有琐事和会议式的沟通，这种氛围在家庭上不太妥当，也会极大削弱两个人紧靠回忆所维系的感情。

### 3、高效表现有节奏 —— 劳逸结合的平衡

#### （1）精力的节奏与全情投入

**顺应消耗与恢复的循环：**

+ 通过运动与休息的交替，人们能够保持良好的精力状态，从而最大限度地提高个人表现。

+ “张弛有度”是保持身心健康、维持正常机能和实现全情投入的关键。

**能量补偿与恢复：**

+ 在一定时间的活动消耗后，人体需要从基础生化源获取能量来实现恢复，这个过程被称为“补偿”。

+ 当精力消耗导致储备减少时，通过适当的恢复可以促使能量上升。

**避免精力的极端消耗：**

+ 过度消耗而恢复不足会导致精力衰竭崩溃，而恢复超过消耗则可能导致萎缩和衰弱。

+ 持续的健身活动能带来身心的改善，但若停止一周，曾经的改善就会大幅退步，只要停止4周，这种改善就会完全消失。就跟早起、运动，这些事情一样，放弃只要三天，坚持得1个月、3个月，直到形成肌肉记忆。

**多元化而非单线化的生活方式：**

+ 许多人错误地假设某些精力层面可以无限消耗，尤其是思维和情感方面，同时认为身体和精神方面不需要投入太多精力就能保持高效。

+ 🛴这一点也是我以前一直忽视的，即使人很累的情况下，还是要硬着头皮学下去，忽视了主动休息的重要性。事实上，要有足够的休息，才能保持更高的专注和更大效率的产出。

+ 单线化的生活和运动方式可能会导致机能障碍甚至死亡，而波动和“张弛有度”的生活节奏更有利于保持健康和实现全情投入。

#### （2）恢复精力几种方法

**利用碎片时间见缝插针地休息：**

+ 突然想起工作50min累了，我们常常想到的休息方式是玩手机。但事实上，玩手机也需要花费大量的时间去处理信息，会越来越累。这个时候感觉应该闭上眼睛，让大脑放松一些，冥想深呼吸等方式都可以，为下一个50min的工作蓄满精力。

+ 《为什么精英都是时间控》一书中讲到一个观点，精力都是有限的，你不能保持一直都是高效的精力，需要自我调节，每个人的精力高集中是有时间段的，到了界限自然会下降，要学会在下降后去自我调节，碎片化休息也许是个好办法，但不一定每个人都能掌握，这个也需要进行一定的训练后获得这项能力。

**工作中如何注意休息：**

+ 压力和恢复的平衡在任何效能至上的领域中都意义非凡。

+ 恢复周期对创造力和亲密关系都同等重要。声音通过音符间的停顿空白组成了音乐，如同字母和空白组成了单词。就在工作的空白时段，爱、友谊、深度和维度得以延伸。如果没有恢复的时间，我们的生活将在失衡中变得一片混乱。

+ 如果不腾出时间休息，你就会失去效率。

**这世界憎恶休息：**

+ 书中的罗杰跟我们中的大多数人并无不同，因为他的日常选择正是社会大众的通病。这个世界欢迎工作和活力，却无视恢复与休息，殊不知后两者正是持久的高效表现的必要因素。

+ 我们必须学会为一天画上休止符，强迫自己在固定的时间离开跑道，停止处理信息，把目标从工作成果转向精力恢复。（时间茧蛹）

+ 从最实用的角度看，全情投入的能力取决于周期性休息的能力。

#### （3）压力成瘾

+ 任何成瘾行为，包括工作，都会导致精力储备急剧消耗。

+ 高强度的精力消耗并非是过度疲劳、效能打折和体力崩溃的直接原因，持续消耗加上恢复不足才导致了这样的后果。

+ 因此，我们要慢慢地，学会把休息日和工作日分清一些。工作日要尽量做到全情投入，等到周末的时候，就尽量不想工作上的事，好好休息，去做自己喜欢的事情。

#### （4）拓展能力需要

+ 追求长期效益和健康时也会出现同样的矛盾。

+ 最佳时刻，往往发生在一个人的身心为了达成艰难目标或完成有意义的事情，而自愿达到极限的时候。

+ 就好像阶段性很难的工作，完成了会非常有成就感，然后休息，之后继续困难的工作，如此往复。

## 二、精力的四个来源

### 1、体能精力 —— 为身体添柴入火

#### （1）一些基础常识

体能与工作效能的关系：

> 体能的重要性对运动员、建筑工人和农民来说不言自明。

> 因为其他职业更看重思维劳动，所以人们容易低估体能在效能中扮演的角色。在大多数工作中，体能被完全从效能公式中抹去，然而实际操作中，体能是燃料的基本来源，即使大部分工作时间都是坐着一动不动。

精力的生理基础与管理：

> 从生理学的角度看，精力来源于氧气和血糖的化学反应。

> 应对愤怒和焦虑最简单的方法就是用腹式呼吸。这竟然也是一种呼吸方式，想起我时不时会用肚子呼吸。

> 长期过度进食则是过度“恢复”的典型代表，导致身体肥胖，损害精力。高糖高脂的食物和简单碳水化合物可以产生精力，但它们与低脂蛋白和蔬菜谷物等复合碳水化合物相比，不仅转化效率低，释放的能量也不如后者丰富。

饮食、水分摄入与体能：

> 想要维持良好表现，不仅要定期进食，还要每次摄入足以维持两至三个小时精力的食物。控制进食量在管理体重和管理精力两方面都很关键。多吃多餐跟少吃少餐一样有问题。两餐之间的零食热量应该控制在100至150卡路里之间，并选择低升糖指数的食物，例如坚果、葵花籽、水果或半条200卡的能量棒。

> 为将体能最大化，我们必须让自己更加熟悉进食适当的程度——不感到饥饿也不感到撑胀。大多数人总是陷入两个极端，花了太长时间消化食物，又一次吃太多补回来。因为精力需求到夜晚会减少，新陈代谢也会减缓，因而早上多摄入热量、晚上少摄入热量是有科学道理的。

> 喝水或许是最常被人忽略的体能再生方式。口渴不会像饥饿一样散发出明显的信号，等我们感到口渴的时候，身体或许已经缺水很久了。一家研究机构称，每天至少饮用1.8公斤水对维持体能有诸多好处。肌肉若缺水3%就会失去10%的力量和8%的速度。喝水不足也会损害大脑的注意力和协调能力。

> 多喝水还有助于健康和长寿。澳大利亚的研究员在一项2万人的调查中发现，每天喝5杯230毫升水的人比喝2杯以下的人死于冠心病的几率更小，有可能是因为缺水会升高血液黏稠的风险。

> 体重超重确实会额外带来消耗，负重前行。

健康生活方式的实践与建议：

> 早餐是一天中最重要的一餐，我们之前说过，高质量的早餐不仅能够提高血糖水平，还可以强力推动新陈代谢。

> 我们都赞同“80/20”的原则：如果你摄入的80%的食物都是健康而高效的，剩下的20%可以是你喜欢的任何食物，只要份量控制得当。

#### （2）解决步骤

**调整生理周期与睡眠：**

+ 大约有50项研究表明，人的思维能力，即反应时间、专注力、记忆力、逻辑分析及辩证能力，会随着睡眠不足而衰退。

**夜晚工作的时间：**

+ 越长、越连续、结束得越晚，你会变得越低效，也更容易犯错误。

+ 小憩20～30分钟。小憩就是一种精力恢复手段，但不能太长，小憩太长会导致更累。

**调整每天的工作节奏：**

+ 虽然日间休息对于大多数职场人过于奢侈，但短暂休息确实利于长时间保持精力。

+ 我们发现，白天能真正休息片刻的人晚间的精力也仍旧高涨。

**间歇性训练的价值：**

+ 间歇性训练的价值，不仅因为可以保持健康的身体，还因为它可以提高每天应对挑战的能力。

+ 间歇训练可以增大精力的容量，使身体可以承担更多压力，并且更加高效地恢复。

+ 严格的训练可以增强一个人在战场上的作战能力。

+ 身体锻炼是思维和情感精力的极佳源泉。

#### （3）关于体能

+ 体能精力是生活最基本的精力源。

+ 体能精力通过氧气和葡萄糖的化学作用获得。

+ 体能精力最关键的两项调节器是呼吸和进食。

+ 每天吃5～6顿低热量高营养的食物，能够为机体持续供应葡萄糖和必须的营养。

+ 每天喝64盎司的水是有效管理体力的关键要素。

+ 大多数人需要每晚7～8小时的睡眠，方可正常运作。

+ 早睡早起可以优化效能表现。

+ 间歇训练比稳态训练在锻炼体力方面更有效，在体力恢复方面更高效。

+ 为了保持全情投入的状态，我们必须工作90～120分钟就休息片刻。

### 2、情感精力 —— 把威胁化为挑战

**情绪对个人工作效能的影响：**

+ 头痛背痛都会分散我们的注意力，让我们的注意力不集中。

+ 对自己的愤怒放任不管，是导致“人生最大损失和最痛苦的失败”的关键因素。

+ 成功的控制了负面情绪，不让思想跟着感情走， 相信自己内心的智慧。

+ 如果我们激起了他人的恐惧、愤怒和戒备心，也等同于损害了他们的工作能力。

+ 员工和顶头上司之间的关系比其他因素更能决定员工的效率。盖洛普公司还进一步发现，员工的工作动力包括感受到主管或其他同事的关心、在最近7天内受到认可或表扬、以及工作环境中有人不断鼓励他们进步。换而言之，保持正面沟通是有效管理的核心。

**休闲活动与情绪之间：**

+ “休闲活动”有区分。一种目的在于纯粹释放掉即时堵住的情绪，无所谓表现和体验好坏；一种目的在于在主业之外拓展和丰富生活，这种越认真投入，获得的反馈体验越高。

+ 从科学角度看，看电视对思维和情感的影响等同于垃圾食品对身体的影响。

+ 心理学家契克森米哈里等发现，长时间观看电视会导致焦虑增长和轻度抑郁。相比之下，情绪恢复的来源越丰富、越有内涵，我们越能补充自己的精力储备，恢复力越好。有效的情绪再生使我们的表现更高效，在压力之下尤为明显。

**面对挑战和拒绝：**

+ 不要害怕被拒绝，只有被拒绝了，才能知道下一次如何更好。也不需要太看重别人的自己的想法，因为那是别人的事，自己的生活还是自己过。

+ 只有真正学会倾听他人，不插嘴，也不作武断的判定，才能公平地评判别人的能力。

**正面情感与领导力：**

+ 正面情感精力的关键因素是自信、自控、人际关系与共情。

+ 在高强度压力下调动积极情感的能力是领导力的核心。

+ 利用情感肌肉支配表现，需要依靠定期锻炼和间歇恢复的平衡。

### 3、思维精力 —— 保持专注和乐观

#### （1）思维精力：重塑专注力与积极性

体能精力既是情感能力的基础，也是思维技巧的基础。没有什么比不能集中于手边的工作更能损害工作表现和投入程度了。

任何能够调动适当的专注和现实乐观主义的行为，都能服务于良好的表现。

与身体和情感能力相同，思维能力需要平衡消耗和再生。保持专注与乐观的秘诀在于间歇地变换思维频道，达到精力休息和再生的效果。如果缺乏能让自己做到最好的思维肌肉，就可能会导致注意力涣散、过于悲观、思维固化、眼光狭窄等，则需要通过系统训练重塑这种能力。

时间管理只是通向高效精力管理的途径。每天的时间是固定的，不仅要聪明地使用时间，更要确保有限的精力用于最重要的事物。但是人们往往花大把时间做无益的事，耗费大量精力，所以时间管理的本质是精力管理。

#### （2）关于思维要记住的几个点

我们使用思维精力规划生活、集中精力。

最有益于全情投入的思维精力是现实乐观主义——看清事物真相，却仍朝目标积极努力。

优化思维精力的关键在于思想准备、构建想象、积极的自我暗示、高效的时间管理和创造力。

转换思维频道可以激活不同的大脑部分，提升创造力。

身体锻炼可以助长认知能力，思维消耗与恢复的平衡可以帮助思维精力达到最大。

如果缺乏某种思维能力，需要系统地加以锻炼，不断突破自己的舒适区并充分休息。

持续挑战大脑可以有效预防老龄化思维衰退。

### 4、意志精力 —— 活出人生的意义

#### （1）坦然面对生命的一切

尼采有句名言 ：“知晓生命的意义，方能忍耐一切。”

精神功课既是精力消耗的过程，也是精力更新的过程。例如，冥想需要调动高度的注意力来让思维平静，同时也会带来意志的开阔、内心的沟通，甚至喜悦的情感。冥想像瑜伽一样贯穿所有的精力层面，构造意志能力的同时，也提供思维和情感的再生源泉。

生命的终极意义是担起责任，找寻难题的答案，并且完成生命为每个人设定的任务。

总是保证要完成某事，结果往往食言。这种在职场是很忌讳的，要谨慎注意。

不信任他人，不愿放权。这个也是要注意的，要学会盘点身边的人力和物力，把一些不重要但紧急的事情交给他人，自己的精力要放在最重要的事情上。

这个世界上，说实话可能是成本最低的解救方案了。只要大胆承认错误，才有可能，在未来减少错误，继续进步。

#### （2）关于意志精力

思维精力是保持专注，而意志精力是能够面对困难，坦然接受生命中的一切不足。

意志精力为所有层面的行为提供动力，带来激情、恒心和投入。

意志精力源于价值取向和超出个人利益的目标。

品质——即依照价值取向生活的勇气，它是意志力量的关键因素。

最强大的意志力量是激情、投入、正直和诚实。

意志精力通过超越自身的目标和自我关心间的平衡得以维持。

拓展意志力量与拓展体能的原理相同，都要突破我们的舒适区域。

人类的意志精力甚至可以弥补严重不足的体能精力。
