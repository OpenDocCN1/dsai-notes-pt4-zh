### 图像生成过程

提交 [文本提示](https://docs.midjourney.com/fast-relax) 后，Midjourney Bot 会处理您的请求，在一分钟内创建四个独特的图像选项。此过程利用先进的图形处理单元 (GPU)，每次图像生成都计入 Midjourney 订阅中包含的 GPU 时间。要监控您的可用 GPU 时间（剩余时间快）使用 `/info` 命令。

## Prompt（提示语）

Prompt 是 Midjourney Bot 解释以生成图像的短文本短语。Midjourney Bot 将 Prompt 中的单词和短语分解成更小的部分（称为标记），并将其与训练数据进行比较，然后用于生成图像。精心制作的 Prompt 可以帮助制作独特而令人兴奋的图像

### 基本提示

基本提示可以简单到一个单词、短语或表情符号 😊。

![](img/682502fa572c811461f35409fdf9b6de.png)

Midjourney Bot 最适合使用简单、简短的短语来描述您想要看到的内容。避免使用长列表的请求和说明。

不要：`给我看一张盛开的加州罂粟花的照片，把它们画成明亮、鲜艳的橙色，然后用彩色铅笔以插画风格画出来。`

尝试：`用彩色铅笔画出明亮的橙色加州。`

### 高级提示

更高级的提示可以包括一个或多个 [图像 URL](https://docs.midjourney.com/image-prompts)、[多个文本短语](https://docs.midjourney.com/multi-prompts) 以及一个或多个 [参数](https://docs.midjourney.com/parameter-list)

![](img/568d57fbd8f70f9a191651e009759326.png)

#### Image Prompts

可以将图像 URL 添加到提示中，以影响最终结果的样式和内容。图像 URL 始终位于提示的最前面。

#### Text Prompt

您要生成的图像的文本描述。请参阅下面的提示信息和提示。写得好的提示有助于生成令人惊叹的图像。

#### Parameters

参数改变图像的生成方式。参数可以改变纵横比、模型、升级器等等。参数位于提示的末尾。

### 提示说明

#### 词汇选择

词汇选择很重要。在许多情况下，更具体的同义词效果更好。

比如 `big` 这个词语，尝试 `tiny`、`huge`、`giantic`、`enlarge` 或 `infinite`，效果会更好。

#### 复数词和集合名词

复数词的使用有很多不确定性。尝试使用具体数字。“三只猫”比“猫”更具体。集体名词也适用，例如“一群鸟”而不是“鸟”。

#### 专注于你想要的

最好描述你想要什么，而不是你不想要什么。如果你要求举办一场“不带蛋糕”的派对，你的图片中可能会有一个蛋糕。为了确保物体不在最终图片中，请尝试使用参数进行高级 `--no` 提示。

#### 提示长度和详细信息

提示可以很简单。一个单词或表情符号就可以了。但是，简短的提示依赖于 Midjourney 的默认样式，允许它创造性地填写任何未指定的详细信息。在提示中包含对您来说重要的任何元素。细节越少，多样性就越强，但控制力越弱。

尽量清楚说明对您来说重要的任何背景或细节。思考一下：

+   主题：人物、动物、角色、地点、物体

+   材质：照片、绘画、插图、雕塑、涂鸦、挂毯

+   环境：室内、室外、月球上、水下、城市中

+   照明：柔和、环境光、阴天、霓虹灯、影室灯

+   颜色：鲜艳、柔和、明亮、单色、彩色、黑白、柔和

+   心情：稳重、平静、喧闹、精力充沛

+   构图：肖像、头像、特写、鸟瞰图

## Upscale（放大）

当前的 Midjourney 和 Niji 模型版本生成 1024 x 1024 像素图像的网格。使用 U1 U2 U3 U4 每个图像网格下方的按钮将所选图像与其网格分开。然后，您可以使用 `Upscale (Creative)` 或 `Upscale (Subtle)` 工具增加图像的大小。

该 `Upscale (Subtle)` 选项可使图像尺寸翻倍，同时保留与原始图像非常相似的细节。该选项 `Upscale (Creative)` 还可使图像尺寸翻倍，但会为图像添加新的细节。尝试每个升级选项，找到最适合您图像风格的选项。

+   `Upscale` 工具使用您订阅的 GPU 分钟数。升级所需的 GPU 分钟数可能是生成初始图像网格所需的两倍。

+   `Upscale` 工具与 `--tile` 参数不兼容。
