
# 赢在AI 社区变现小组

> 来源：[https://aiyanxishe.feishu.cn/docx/UfNrdyhX9onIqGxUWhuciKm0nod](https://aiyanxishe.feishu.cn/docx/UfNrdyhX9onIqGxUWhuciKm0nod)

## 第一部分：社区概述

赢在AI社区（暂定名）是由全球AI技术爱好者，创业者、AI用户发起成立，旨在交流各种AI工具的使用技巧，评估各AI工具，提升自身应用技能，更多探索AI与各类型商业结合的商业机会，利用社区资源孵化具有商业前景的商业项目，共同分享AI行业所带来的技术红利和商业红利。

![](img/7b1362164232b78c9a89327ec723c26f.png)

### 社区愿景

做中国知名的AI应用社区

### 社区使命

让AI帮助我们提高工作效率，更好的变现个人价值

### 社区组织形式

社区采用付费会员制形式，会员缴纳年费成为会员，会员分为个人会员和企业会员。

社区设立理事会，理事会成员由社区会员选举产生，社区理事会为社区最高治理机构，负责社区章程的建立、修改，社区战略发展的规划以及社区激励制度的指定和修改。

社区下设各工作组，具体执行社区战略，完成各类工作任务。

### 目前社区组织架构

设置技术组，教研组，运营组，商学院。

+ 技术组工作职责：维护社区官网以及所属APP的升级维护。开发有商业前景的技术产品，从技术角度挖掘各种适用的AI工具，与教研组共同开发适合社区会员的知识付费课程。
+ 教研组工作职责：开发具有自主知识产权的各类AI知识付费课程，根据市场需求迭代课程，翻译海外行业资讯及时发布行业研报，为运营组输送短视频、文案等相关社区自媒体所需的内容。
+ 运营组工作职责：主要负责会员的招募，相关自媒体的资讯、内容发布，知识付费课程的市场销售，线上线下社群的维护，有关会员活动的策划执行，有关专题沙龙的组织举办，各地会员的联络，重点地区社区工作站的设立，业务指导以及社区孵化商业项目的推广。
+ 商学院工作职责：线上线下打造社区品牌，召开会员的线上线下招募会，对于社区各地分站核心人员的业务培训，业务指导。

## 第二部分：社区激励

### 1、激励形式为积分与社区通证

社区采用积分制和通证双轨制，按照1积分=1元=0.15USDT衡量积分价值。国内会员采用积分，全球用户使用社区通证。国内所有会员的贡献都以积分形式体现，国外会员贡献以通证形式发放。社区通证不私募不对外发售，凭借社区贡献行为赠与。所有会员均有唯一的会员NFT确权，也可以通过合成NFT挖矿获得社区通证，持有通证参与链上DAO治理。

### 2、积分兑换贡献值

1000积分=1贡献值，凭借贡献值可以参与社区全球分红，获得社区投票资格。

### 3、积分兑换条款

①积分作为为国内会员以及用户参与社区共建产出，包含缴纳会费，参与社区建设活动，完成社区任务产生贡献都可以获得积分。

②可以兑换社区周边产品，加现金购买精选商品，达到一定级别会员可以积分转赠，兑换通证，兑换现金。

③普通会员只可以积分兑换商品无提现权限，合伙人以及以上级别提现无金额限制和提现次数限制。

④积分奖励细则

| 积分激励范围 | 具体行为 | 例如 |
| --- | --- | --- |

| 推荐会员 | 直接推荐 | 根据规则获得对应积分奖励 |
| 成为社区建设者 | 加入社区各小组 | 认领工作任务获得 |
| 支持社区建设 | 参加活动 | 参会/点赞/转发/ |

| 突出贡献 | 做出突出贡献 | 业绩评比 |

## 第三部分：社区激励细则

### 社区会员等级

注册用户→会员→合伙人→高级合伙人→站长→联合创始人

### 晋级规则

本社区采用邀请制，所有注册都需要邀请码下载绑定推荐关系，据此进行相关激励政策。

+ 用户：根据邀请码下载或者注册就成为用户
+ 会员：缴纳会费成为会员
+ 合伙人：推荐2位会员升级为合伙人，享有相关特权

| 级别 | 晋升要求 | 权益简述 |
| --- | --- | --- |
| 用户 | 免费注册 | 部分免费权益 |
| 会员 | 缴纳会费 | 获得积分激励和享受会员权益 |
| 合伙人 | 推荐2位会员 | 获得积分兑换现金权限 |
| 高级合伙人 | 推荐5位合伙人 | 除享受全部会员权益外，享受社区分红奖励 |
| 站长 | 团队5位高级合伙人，累计30个合伙人，会员人数90人 | 除享受全部会员权益外，享受社区全球分红奖励，专项站长设立工作室补贴，活动补贴。原则每个市级不超过2人。 |
| 联合创始人 | 站长团队累计达到5位站长，团队累计有60位合伙人，会员人数达到200人，团队内有5位站长，经过理事会投票成为联合创始人。 | 除享受全部会员权益外，享受社区全球分红奖励，专项站长工作室补贴，活动补贴。进入社区治理委员会，享受专项权益，具体参照社区委员会成员权益。原则每个省级地区一位 |

### 具体奖励模式

本模式采用链动2+1系统模式

模式简述：二级分销，无限裂变

用户购买对应会员专享产品礼包，成为会员即拥有代理推广资格。可以获得相应的推广社区产品和发展会员的相应激励。推荐二个人成为会员晋升为合伙人。晋级为合伙人后脱离原推荐人团队，成立自己团队独立发展。直推奖金也对应增加。

举例说明：假设张三自己缴纳499元成为会员，也就具有了代理推广分佣的资格，随后又推荐了`A`和`B`两个代理，满足条件升级成为合伙人时，之前张三直推的市场`A`和`B`两个代理需要留给原来的上级，`A`和`B`这两个市场如果也分别推广了两个499元会员代理，(分别为`A1`，`A2`，`B1`，`B2`)升级独立老板时，也需要把他们的`A1`，`A2`，`B1`，`B2`个市场留给张三，从而张三可以获得2生4,4升8,8升16的团队架构，实现团队的自动裂变。

#### 1、直接推荐奖

代理会员直推奖100元/人

合伙人及以上级别直推奖200元.人

#### 2、见单奖

见单奖就是如果伞下第二代会员代理有报单，即499元成为会员，上一级合伙人获得200元/人见单奖励

#### 3、分红奖

合伙人级别以上的高级合伙人、站长、联创可以享受社区所有产品的全球分红。

#### 4、伯乐奖

伯乐奖又称为平级奖，是指合伙人所推荐的代理会员成为合伙人，可以享有其所发展的合伙人的收益10%奖励。此奖励是由社区单独奖励，不是从下属合伙人奖金中支出。此奖励只限所直推的合伙人，二者之间是有绑定关系。只有合伙人级别才享有伯乐奖。代理会员不享受。

#### 5、团队发展奖励

又叫管理奖，高级合伙人及以上级别享有，是指他下属的所有团队业绩的收入有一定比例的提成作为管理奖形式发放。本奖项需要完成一定额度的当月销售额才可获取。

高级合伙人享有1%，站长享有3%，联合创始人享受5%

#### 6、全球分红奖

又叫加权分红奖，是指社区所有产品销售过程中每单都有对应的分红佣金。只限高级合伙人，站长，以及联合创始人级别享受。

以会员费为例，高级合伙人每单获得5元，站长获得10元，联创15元。

#### 7、服务奖

本奖项高级合伙人、站长、联创级别专享，是为了激励更好的服务本地区会员，增加会员粘度，促进线下互动所设置，相当于服务所属地区会员的服务津贴。

+ 高级合伙人：本地区会员 15元/人
+ 站长：本地区会员 10元/人
+ 联创：本地区会员 5元/人

#### 8、其他奖项

此奖项为市场活动临时设立的奖项，主要目的刺激市场推广冲刺目标。例如：优秀推广奖，个人奖项

## 第四部分：整个社区商城规划

### 商城构想

社区的所有产品都通过社区商城进行展示销售以及报单。

本着社区属于知识付费社区的属性，通过优质内容来吸收会员，发展社区，因此以AI相关为主题，加入其他可吸引潜在会员和用户的其他知识类产品如其他热门知识付费课程和各种电子书供会员下载和使用，一方面充实内容，另一方面加入一切其他元素，便于增加会员的价值感，更能够物有所值。

商城采用目前主流的H5搭建，按照各主要功能和内容分区。

### 商城内容

+ **AI特区**：这个是本社区主打内容，主要是相关AI的知识付费课程，入门课，进阶课，高级课。会员可以免费观看，非会员付费购买观看
+ **AI产品**：例如我们已经开发的相关AI产品陈列其中，包括上架我们合作的其他第三方研发的非同质化的差异化AI产品。
+ **热门课程专区**：目前主流的各类知识付费课程，短视频、剪辑、电商运营、文艺、教育等，会员可以免费有限制次数观看，非会员付费购买观看
+ **电子书店**：各类型的电子书为会员提供有限制次数免费下载服务，非会员付费下载。
+ **精品商城**：企业会员可以上传商品供会员和非会员购买，会员按照会员价购买，非会员优惠购买。
+ **兑换专区**：会员可以凭借积分进行社区周边商品的兑换，包括带有社区标志的衣帽，文具，徽章，背包，活动入场券等周边商品。
+ **福利专区**：可以凭借积分领取社区的福利，代金券，年货，节日礼品等

### 技术建议

1. 会员下载电子书设置次数，级别越高次数越多
2. 所有视频课程是在自己服务器搭载直接播放观看还是供会员百度云盘下载，商城自动提供网密。主要是容量成本考虑。
3. 会员上传服务要求的视频课程和电子书，是否可以给与相关播放的收益分账以积分形式发放。
4. 会员观看视频完播和撰写高质量点评是否可以设置激励。

## 第四部分：其他部分

1. 对于其他非市场部分的成员激励

   建议采用积分形式人工审核发放，建议结果导向+基本酬劳相结合形式，具体另议

2. 对于企业会员，主要独特权益是可以上架商城销售，平台服务费收取比例可以参考大型电商平台抽佣制度设置

3. 相关法务问题建议

   建议会员缴纳会费有一份电子合同明确双方权利义务，以免日后纠纷。商家入驻平台也要签署相关法律文件。

4. 相关税务问题

   高于500元的提佣要代扣代缴缴纳7%的税收，这个建议咨询一下注册地税务顾问，做好预案。
