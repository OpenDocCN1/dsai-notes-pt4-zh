
> **小贴士**：阿里旗下有两款产品容易混淆——CoPaw（通义实验室，开源 Apache 2.0，面向开发者自部署）和 JVS Claw（阿里云，闭源 SaaS，面向普通用户云端使用）。名字里都带"阿里"但定位完全不同。

### NemoClaw（NVIDIA）

NemoClaw 是 NVIDIA 在 GTC 2026**（2026 年 3 月 17 日）** 发布的企业级安全 OpenClaw。合作伙伴阵容豪华：Adobe、Salesforce、SAP、CrowdStrike、Dell。

> 🔗 官网：https://www.nvidia.com/en-us/ai/nemoclaw

**核心卖点**：

+   `OpenShell` 安全运行时：沙箱隔离 + 最小权限 + 策略驱动隐私护栏——当 AI Agent 能执行 Shell 命令和读写文件时，"它干了不该干的事怎么办？"`OpenShell` 就是为解决这个问题而生

+   **隐私路由器**：前沿云端模型 + 本地模型混合使用，自动脱敏 PII（个人身份信息）——敏感数据走本地模型，普通任务走云端模型

+   **差分隐私**：基于 NVIDIA 收购的 Gretel 技术，提供数学层面的隐私保证

+   **Nemotron 模型**：NVIDIA 自研大模型

NemoClaw 解决的是企业最关心也最难的问题——安全。对于跨国企业、金融机构、医疗系统等对安全合规要求极高的场景，NemoClaw 的 `OpenShell` 沙箱 + 隐私路由器组合提供了目前最完善的企业级安全方案。但需要注意：NemoClaw 是英文界面，主要面向国际企业市场。

## 1.6 手机系统级 Agent：MiClaw 与小艺 Claw

前面介绍的所有产品，不管是云端还是本地，本质上都是"软件"——装在电脑上或跑在服务器上的应用程序。但有两款产品走了一条完全不同的路：嵌入手机操作系统。

这意味着它们不是一个你需要"打开"的 App，而是手机系统的一部分——就像 Siri 或 Google Assistant，但能力远不止接个电话、设个闹钟。

### MiClaw / Xiaomi miclaw（小米）

MiClaw 是国内首款移动端 AI Agent，直接嵌入小米 HyperOS 系统。

+   **系统级权限**：能调用通讯录、短信、日程、50+ 系统工具——这不是一个 App 能做到的事，需要系统级 API 访问

+   **MiMo 大模型**：小米自研大模型，针对手机系统场景深度调优

+   **"人-车-家"生态**：手机、汽车、智能家居联动——"帮我把客厅灯关了"这种跨设备指令它能处理

+   **数据本地化**：数据留在设备上，不上传云端

目前仅限小米 17 系列（5 款机型），邀请制封测。由于 MiClaw 深度嵌入手机 OS，没有独立的官网页面可访问，需要在小米 17 设备上体验。

### 小艺 Claw（华为）

小艺 Claw 是华为的鸿蒙版 AI Agent，同样是系统级集成。

+   **HarmonyOS 原生**：支持 HarmonyOS 6 / NEXT 全系设备

+   **四种人格预设**：信息猎手、知心朋友、办公搭子、创作天才——根据场景切换"性格"

+   **多端协同**：手机/平板/车机/PC/手表——华为全家桶联动

+   80+ Agent Skills：精选技能包

与 MiClaw 类似，小艺 Claw 作为鸿蒙系统内置功能，不提供独立的 Web 访问入口，需在支持的华为设备上使用。

### 手机系统级 Agent 对比

| 维度 | MiClaw（小米） | 小艺 Claw（华为） | 荣耀龙虾宇宙 |

| --- | --- | --- | --- |

| **系统** | HyperOS | HarmonyOS | MagicOS |

| **支持设备** | 小米 17 系列 | HarmonyOS 全系 | PC/平板/手机 |

### 为什么值得关注？

这两款产品代表了一个重要趋势——AI Agent 从"电脑上的软件"走向"手机操作系统的一部分"。当 Agent 能力嵌入系统层面，用户的交互方式从"打开一个 App"变成"随时唤醒一个助手"。

不过对大多数人来说，目前还处于观望阶段——设备限制太严格（小米 17 或华为 HarmonyOS），生态还很早期。但这个方向值得持续关注。
