## 概念辨析：Prompting、Prompt tuning还有Prompt Learning

> Prompting，指的是给语言模型输入一段特定的文本（即提示词），从而引导模型去生成特定的我们想要的输出文本。他其实就类似我们在ChatGPT里打字的过程啦。

> **Prompting refers to the process of giving a specific prompt or input text to a language model to guide its generation of a specific output text.** The prompt text can be in the form of a question, a sentence, or a few words that are related to the desired output. The language model then generates the output text based on the prompt and its own internal understanding of the language.

> In other words, Prompting is a technique used to guide the generation of specific output text using a language model, while Prompt Tuning is a technique used to adapt a pre-trained language model to a specific downstream task by fine-tuning it on task-specific data using prompts.

> Prompting Tuning（提示微调），和微调会更接近，是自动化生成“软提示”的一种方法。具体怎么work后面会介绍，不过在这里我们只需知道，Prompt tuning是微调的一种特殊形式，它是会改变模型的权重参数的，但它又比fine-tuning参数高效得多。

> **"Prompt tuning", a simple yet effective mechanism for learning ["soft prompts"](https://arxiv.org/abs/2104.08691) to condition frozen language models to perform specific downstream tasks.** Unlike the discrete text prompts used by GPT-3, soft prompts are learned through backpropagation and can be tuned to incorporate signal from any number of labeled examples. ——The Power of Scale for Parameter-Efficient Prompt Tuning

先用一个高亮块快速讲清楚提示学习的定义：

> **提**示学习（Prompt Learning）是一个非常General的术语，可以理解为涉及到提示词的机器学习范式都算是提示学习。简单来说是通过一些方法编辑下游任务的输入，使其形式上模拟模型预训练过程使用的数据与任务。比如做情感分类任务时，监督学习的做法是输入“我今天考砸了”，模型输出分类的分数或分布，而提示学习的做法则是在“我今天考砸了”后拼接上自然语言描述“我感觉很 ____”，让模型生成后面的内容，再根据某种映射函数，将生成内容匹配到某一分类标签。

> ——哈尔滨工业大学 ChatGPT调研报告

再用这个高亮块快速讲清楚Prompt Learning范式的运作原理：

> **传统的预训练+微调**：预训练完后，利用有标签的下游数据集对模型做微调，这需要改变模型的权重与偏置参数。而后，基于下游任务输入`x`，模型预测输出`y`: `P(y|x)`。

> 新范式预训练+Prompt+Predict：基于输入`x`，根据模版（Template）将其转为特定的结构化提示`x'`，`x'`是一个具有一定格式但是不完整的句子，有一些字段还没有被填充。对于`x'`，模型会基于概率对其进行填充，得到完整的输入 。基于这个 ，模型再预测输出`y`。

> Prompt learning is a general term that refers to the use of prompts in machine learning.  In the context of natural language processing, prompt learning involves training a language model to understand and respond to a specific set of prompts.

最后再额外提一嘴Prompt Engineering。语言的发展经历了四个范式：基于符号主义的全监督学习时代、基于神经网络的全监督学习时代、预训练+微调阶段和预训练+提示词+预测阶段，这四个阶段分别对应了四类工程：特征工程（手动提取特征）、结构工程（搭建更好的神经网络结构以更好的提取特征）、目标工程（选取好的目标函数）和提示工程。提示工程，指的是精心去设计提示词Prompt，以让语言模型可以生成我们想要的输出，最大的发挥语言模型的潜力。

## 开端：当我们发现一个模型做的越大越好之后……

我们在12.2.2.4中提到了，GPT-2模型的参数量达到了15.42亿，尽管其性能还不够好，但它确实证明了不断地去堆参数，把模型做的更大，模型性能还是可以继续上去的。但模型变大了以后，其他的问题就接踵而至。首先，有如下两个问题：

+ 预训练的模型大，所需要的预训练语料（数据量）就多。无监督预训练用的数据量多了，那么下游预训练的有标注数据相比之下就微不足道了。

+ 预训练的模型大，参数量多，用反向传播算一次梯度的成本剧增。微调变得又贵又不可能。

+ 此外，Fine-tuning毕竟是要基于有监督下游任务改变模型的Weights & biases的，所以很容易过拟合。

> 我们知道，GPT-2的模型参数为15亿，到了GPT-3就将达到1750亿个参数了。如此骇人听闻的参数规模，好不容易花了巨大成本预训练完，你再对他去做梯度下降，算反向传播算法，哪怕只是针对少量下游任务数据的fine-tuning，这个成本也是我们难以承受的。

> 传统的解决方案是寻找参数高效（Parameter-Efficient）的迁移学习方法，即微调的时候不改变全部的参数，只去改变部分的参数就好了。能尽可能的少更新参数并尽可能保证任务性能，那也不错。

> 但OpenAI团队不会只局限于此。他们的梦想是实现AGI，实现通用的、类似人的智能。人类可不会只擅长某一个具体的下游任务，参数高效的迁移学习再高效，毕竟也需要人为对任务做划分。因此，OpenAI更关注另一个的解决方案：能不能我们去把它应用于任何下游任务时，都不要去改模型的参数权重了，而是只需要用自然语言给模型一些提示词就可以？这就是Prompt。

> **写这么多是希望大家可以知道：Prompt工程不只是工程师们的异想天开：这是让大力出奇迹的超大型模型能在多种场合都有所作为的前置要件，也是通往AGI的必由之路。**

## 前Prompt时代的尝试：参数高效学习 Parameter-Efficient Transfer Learning

[【arxiv】](https://arxiv.org/pdf/1902.00751.pdf) Parameter-Efficient Transfer Learning for NLP

[参数高效微调指南](https://zhuanlan.zhihu.com/p/619583361) By [TimsonShi](https://www.zhihu.com/people/timsonshi)

### 参数高效的定义

+ **全面微调：**做针对下游任务的Fine-tuning时，更新模型的所有参数。这不可避免地导致模型对小的目标数据集过度拟合，继而在微调后不能用于其他任务。

+ **参数高效微调（Parameter-Efficient Fine-tuning，PEFT）：**做针对下游任务的Fine-tuning时，不更新模型全部的参数。我们可能选择性的只更新模型最上面的几层权重，也可能只去更新偏置而不去改变神经元之间的连接强弱。我们的目的是在尽可能少更新参数的情况下尽可能保证模型的下游任务的性能。

### 部分参数微调：选择法Selective Method

为了解决巨大的预训练模型的Fine-tune问题，研究人员们首先提出了部分参数微调/冻结部分参数的方法。

+ 最早的一批工作是只微调网络的最上面几层。

+ 后来人们认为可以根据人的经验和推理去微调网络中和下游任务最相关的部分。

1. 首先，我们人类对模型的参数分布是有先验知识的。例如学完了第10章，我们就应该知道，Encoder部分负责编码语言为高维的向量，而Decoder负责生成目标的句子。

2. 有了类似这样的基于先验知识的假设之后，在微调模型的参数时，我们就可以更新和目标任务最相关的那部分。例如，如果要把一个用于生成摘要的Transformer转变为生成原文的Paraphrasing，那么可能我们就只需要改Decoder的参数就行了，而不去改Encoder。

+ 更极端的做法是只微调模型偏置项或者某些行。

+ 最极端的版本可能是稀疏地更新模型，无视模型结构，只更新某些参数。

### 使用额外的参数增强现有预训练模型：附加法Additive Method

**附加法的主要思路是使用额外参数或层增强现有预训练模型**，它只训练这些新加入的参数。目前这是最大、最广为应用的PEFT方法。附加法的实现方式为适配器（这里先不提软提示）。

**适配器 Adapter**

简单来说，就是在Transformer子层后面加入小的全连接网络。
