## 金融市场的作用

### 金融市场

金融市场是人们进行借货活动的交易场所。假设时间被划分为两个时期（并且只有两个）。考虑某个人在两种商品的组合间进行选择：今年的消费和明年的消费。

+ 贷出：用今年的消费换取明年的消费。
+ 借入：用明年的消费换取今年的消费。
+ 利率：今年的消费与明年消费交换的条件。

假设A现在有20000元的收入，一年后有25000 元的收人。他可供选择的消费模式如下图所示。

如果利率r=5%，他今年可获得的最大消费为：

20000+25000/(1+5%)=43800 明年可获得的最大消费为：

20000(1+5%)+25000=46000

25000/(1+5%)=23800为一年后25000元的现值 (present value)。

20000 (1+5%）=21000元为现在20000元的未来值，或终值 (future value)。

43800元也称为他现在的财富总量。

## 绝对估值法

+ 资产价值评估原理
+ 资产是指能产生未来现金流量的资源.
+ 资产的价值取决于未来现金流量的特征.
+ 现金流量的大小；
+ 现金流量发生的时间；
+ 现金流量的不确定性.
+ 资产的价值等于未来现金流量的现值.
+ 股息现金流量贴现
+ 股票的现金流量特点
+ 股票的每期现金股息可能不同；
+ 股票的没有到期时间；
+ 一个投资者从股票投资中获得的现金流量为持有期的现金股息，以及期末出售股票的价格。

## 相对估值法

+ 相对估值法是以市场对可比资产的定价为标准，以此评估所考虑资产的价值。
+ 价值=业绩指标X乘数
+ 优点：简单。
+ 缺点：没有考虑价值的驱动因素；很少有完全可比的资产。

## 企业筹资概述

+ 资金来源：
+ 股权：
+ 外部：发行普通股票、优先股票、或股权证书.
+ 内部：利润留存.
+ 债务：
+ 商业信用：供应商,客户
+ 银行等金融机构贷款
+ 个人,企业．
+ 债券；
+ 融资租赁．

+ 权益证券的种类

+ 普通股票

+ 普通股票通常是指那些在股息和破产清算方面不具有任何优先权的证券，它代表了对公司的剩余收益权和剩余决策权。

+ 投票权：

+ 累计投票制

+ 多数投票制；

+ 分类普通股

+ 通常不同种类的普通股在投票权方面有差异.

+ 在中国注册的公司法律不允许发行分类普通股.

+ 股息：

+ 股东有按比例分享公司支付股息的权利．股息是公司对股东直接或间接投人资本的回报，它取决于董事会的决策。

+ 股息的发放不是公司的一项义务；

+ 公司支付的股息不能作为公司的一项经营费用.

+ 优先认购新股的权利：

+ 保护现有股东不受公司发行新股的影响

+ 控制权的影响

+ 股票价值的影响。

+ 优先股票

+ 优先股票属于公司的权益；但同普通股相比，在股息支付和公司清算清偿时具有优先权。

+ 优先股是指依照公司法，在一般规定的普通种类股份之外，另行规定的其他种类股份，其股份持有人优先于普通股股东分配公司利润和剩余财产，但参与公司决策管理等权利受到限制。

+ 固定股息率与非固定股息率

+ 可累积与非可累积；

+ 参与与非参与；

+ 可转换与可回购．

![](img/18a28200288f761cdd83b1932a946e22.png)

+ 上市公司不得发行可转换为普通股的优先股。

+ 非公开发行优先股的票面股息率不得高于最近两个会计年度的年均加权平均净资产收益率。

+ 上市公司发行优先股，可以申请一次核准，分次发行，不同次发行的优先股除票面股息率外，其他条款应当相同。

+ 分红条款

+ 参与性分红与非参与性分红；

+ 可累计分红与非累计分红。

+ 现金红利或股票红利。

+ 不承诺支付红利，只有在视为清算事件时才会支付延迟现金红利。

+ 对于创业者来说，累计并可参与性分红是非常不利.

+ 比较合理且对创业企业和创业者来说，如果公司童事会决定分红，风险投资者可以按照事先约定的股息先于普通股进行分配，如果普通股的分红高于优先股，优先股可以假设已转换成普通股与普通股一起进行分红。

+ 清算优先权条款

+ 清算优先权授予风险投资者，在公司被出售、清算、破产、 公司重要资产被出售时，有权得到原先投资额1倍到5倍不等的收益。

+ 对清算事件的界定非常重要.

+ 比较常见的分配方式：

+ 简单优先权：在获得投资本金和股息以及按转换为普通股后分配中选择一个。

+ 参与优先权：除了优先获得投资后，还按照可能转换的普通股按比例参与剩余财产的分配。

+ 封顶的参与优先权：返因的投资达到一定额度后就不再参与财产的分配。

+ 反摊薄股权条款

+ 它是一种用来保护原始投资者利益的约定，即后来的投资者等额投资所拥有的权益不能超过原始风险投资者。

+ 反摊薄条款可以归为两类：

+ 价格型反摊薄条款：即反对股权价值被摊薄的条款。

+ `棘轮条款`

+ `加权平均调整条款`

+ 股权回购条款

+ 该条款规定在某些情况下，风险投资者有权要求公司或大股东回购其股份。

![](img/3e7df105023c0879b445f3bb24203989.png)

+ 股票转让权限制条款

+ 几乎所有的投资协议中都包含这一条款。该条款要求股份转让之前，应事先取得其他所有股东的同意。其目的在于控制创业企业股东的身份、股权转让的时间和股权转让的方式。

+ 离职股权保护条款和竞业禁止条款

+ 根据离职股权保护条款，创业者所特有的股票必须在一定的期限以后才能充分行权。

+ 根据竞业禁止条款，禁止创业者在一定的时期以内服务于与创业企业相同的行业的其他企业，否则将承担严重的赔偿责任。

+ 控制管理权的条款

+ 集团投票权条款

+ 规定对于某些特定的事项的决策，必须取得可转换优先股的持股人的同意。

+ 如：发行新股、分红、改变董事会席位、修改期权计划等。

+ 也有：高级管理人员的雇佣、一定数额的负债或支出、非公司日常业务范围之内的合同的签署等。

+ 绝对多数投票权条款

+ 这是指对于创业企业所采取的某项措施需要经股东以及董事会均以绝对多数同意才能通过

+ 如；股票回购、实质上出售公司全部资产、控制权发生改变的兼并、选举董事会、增发新股等。

+ 其目的也在于设定事实上的否决权。

+ 股票期权计划和里程碑条款

+ 股票期权计划与前面所述的离职股权保护条款通常结合起来使用，既可激励企业者以可保护风险投资者，以利于双方之间维护较长期的合作关系。

+ 里程碑条款则是一种状态依存性安排，即当公司业绩达到一个里程碑时，应向企业者发行额外的股票，其目的了在于激励创业者。

+ 董事席位条款

+ 风险投资者往往要求其有权在公司中任命一名或多名董事，董事席位的多少与公司的董事会规模以及股份比例有关。

+ 一般较多采用两种方式：

+ 具体规定股东各方委派的董事人数。

+ 另一种常见的方式是约定保护条款，保护条款要求公司在某些事项的决策上必须取得优先股东的适当批准。

+ 优先退出权条款

+ 自动转换权条款

+ 允许风险投资者持有可转换优先股自动转换成普通股，通常是与 IPO相联系。

+ 回赎权条款

+ 回赎条款约定风险投资煮可以要求创业企业在将来的某一时间按约定的价格回购风险投资者的投资。

+ 共售权及连带权条款

+ 风险投资者退出的另一种方式是向第三方出售创业企业，共售权及连带权条款可以在这一过程中保护风险投资者的利益。

+ 当创业者向第三方出售其所持有的普通股时，共售权条款使得风险投资者有权要求将自己所持有投资与创业者一起出售。

+ 连带权条款则使得风险投资者在向第三方出售其投资时，有权要求创业者了一同出售他们所持有的普通股。当然这一条款经常会遭到创业者的强烈反对。
