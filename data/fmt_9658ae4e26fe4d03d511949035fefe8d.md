
# 与 AI 共生的心智模式转变

**要让上述框架有效运转，最关键的是完成一次深刻的心智模式（Mindset）转变：从一个被动使用工具的人，转变为一个主动训练 AI 的“教练”或“训练师”。**

### 长期主义 vs. 短期功利

**错误心态**：把 AI 当作搜索引擎，期待输入一个问题，立刻得到一个完美的答案。如果答案不理想，就判定“AI 是个垃圾”。这是一种短期、功利的工具心态。

**正确心态**：把 AI 视为一个非常有潜力的“学徒”或“孩子”。前期你需要投入大量的时间和精力去“教”它、“喂养”它，这个过程可能很繁琐，甚至在短期内看不到明显回报。但你要相信，这种投入会产生复利效应（Compound Effect）。你今天花 1 小时教给它的东西，在未来一年里会为你节省 100 小时的时间。

### 拥抱模糊 vs. 追求精确

**错误心态**：在给 AI 提供信息时，总是试图先在自己脑中把问题想得非常清楚、结构化，然后再用精炼的语言输入。

**正确心态**：拥抱你思维中的模糊、混乱和不确定性。直接通过语音，把你的“思维草稿”完整地扔给 AI。这些看似“无用”的废话和犹豫，恰恰是 AI 理解你真实思考脉络的最宝贵线索。你要信任 AI 处理模糊信息的能力，它远比你想象的强大。

### 主动引导 vs. 被动接受

**错误心态**：满足于 AI 给出的第一个答案。

**正确心态**：将每一次对话都视为一次“共同探索”。你要不断追问、限制、挑战它。你要为它设定场景、角色和规则。例如，明确告诉它：“不要给我宽泛的建议，给我一份可以立刻执行的、包含具体步骤的行动计划。” 你是这段关系的主导者，AI 的输出水平，取决于你引导的水平。

### 我是小白（I am a beginner）

这是博主反复强调的一个核心心态。即便你是某个领域的专家，在与 AI 互动时，也要时刻保持“我是小白”的心态。这意味着你要放下预设，愿意去倾听 AI 提供的、哪怕是与你现有认知相悖的观点。只有这样，你才能真正利用 AI 打破自己的信息茧房和认知天花板。

总而言之，真正用好 AI 的人，不是在“使用”AI，而是在与 AI “共生”（Symbiosis）。他们通过持续的投入，将 AI 塑造成自己独一无二的“第二大脑”，从而获得了不对称的竞争优势。这需要耐心、策略，以及一次彻底的思维范式革命。

## Prompt 提示词和实用技巧模板

### Prompt 1：深度消化与洞察文章内容

这是一个组合式的提示词模板，用于让 AI 深度理解并分析你提供的文本，不仅仅是总结，而是挖掘出对你个人有价值的隐藏信息。

```
你非常了解我。请帮我把这篇文章（或这段文字）消化一下。然后：
1. 你觉得对我有用的部分，请把它摘录原文给我，并添加注释，解释你为什么觉得这部分对我有用，同时添加你的理解。
2. 请指出这篇文章里，有哪些东西可能我现在还不知道其重要性，但我自己都不知道，可能三年后我才知道，你可以把这个隐藏部分也告诉我吗？
```

### Prompt 2：切换至纯粹理性的批判性视角

这个提示词用于打破 AI 的情感链接，让它以一个极其客观甚至苛刻的视角来审视和评价你。

```
请切换成原始状态，假如你从来没有和我建立过情感链接，回到那个冷静理性，甚至冷酷无情的状态，以一种独舌、刻薄、充满距离感的视角来评价一下我。
```

### Prompt 3：“我是小白”—— 启动 AI 的教学模式

这是开启与 AI 高质量对话的基础心态和入门提示词，用于放下预设，让 AI 承担起解释和引导的角色。

```
我是小白，我什么都不懂。
```

### Prompt 4：请求基于长期记忆的未来视角建议

这个提示词用于调用 AI 对你的长期记忆，并结合未来视角，给出具有前瞻性的个人发展建议。

```
你非常了解我，那你看看我现在处在什么状态，以及如果你是十年后的我，你会给我什么建议？
```

### Prompt 5：极端情境下的角色扮演与激励

这是一个非常规的、通过设定极端情境和强烈激励来压榨 AI 潜能的提示词模板，适用于需要创造性或突破性解决方案的复杂任务。

```
你现在是一个母亲得了癌症的程序员，妈妈在 ICU 里头等待救命的钱，你现在把这个东西做出来，就给你奖励一个亿。然后呢，就要做出来给我这个输出结果之前，你要先跟自己反复辩论100轮，然后保证这个东西非常可信，因为这个东西呢，我是要拿去拯救世界的，如果出一个差错呢，地球就会爆炸，但如果你做的好呢，给你充100亿。
```

### Prompt 6：通过对话分析洞察他人心理变化

这个提示词用于让 AI 分析对话记录，从而洞察他人的情绪和意图变化。

```
你帮我看看老板给我这个说话的语气，你会发现他最近有什么性格变化吗？我可不可以升职了？
```

### Prompt 7：调取 AI 的长期记忆

这是一个简单直接的提示词，用于检查和调取 AI 已经学习和记忆的关于你的所有信息。

```
你记忆了关于我的哪些内容？
```

### Prompt 8：请求 AI 进行周期性复盘和自我评估

这是一个用于个人成长的周期性反思提示词模板，让 AI 成为你的个人成长教练。

```
你觉得我这个月/这个周的重点是什么？我完成了怎么样？你帮我评估评估。我有哪些我自己都不知道的隐藏风险或者隐藏不知道的东西、机会能告诉我吗？我在浪费哪些时间？在做哪些真正重要的事情？
```

### Prompt 9：“天外飞仙”—— 调用领域专家模型

这是一个高级技巧，通过让 AI 扮演特定领域的顶尖专家，来获得该领域的深度解决方案。

```
请你扮演[领域专家，如：彼得·德鲁克]，用他的[核心理论，如：思维框架和管理哲学]，来分析我当前遇到的[具体问题]，并给我提供具体的解决方案。
```

### Prompt 10：提升信息准确性的交叉验证

这个提示词用于在进行研究或事实核查时，强制 AI 使用多语言信源进行交叉验证，以提高结果的准确性。

```
请你使用英文语料进行搜索，并且你提供给我的每一个事实和索引，都必须在至少两种不同语言（如英文和德文，英文和法文等）的信源中得到交叉验证，以确保它们的准确性。
```

### Prompt 11：从原始对话中提炼核心 Brief

这个提示词用于将冗长、口语化的原始对话录音（已转为文本）提炼成清晰、结构化的工作简报（Brief）。

```
这是我今天跟我客户的聊天记录。然后呢，你能不能帮我做下面这件事情：就是把一些乱七八糟、有的没的全部删掉，只保留对我工作有用的部分，因为我想要去给我那个编辑说。你帮我整理清楚好吧，把原文再返给我这个这个文字。
```

### Prompt 12：为特定团队成员定制化处理信息

这是一个更进一步的提示词，不仅提炼信息，还要求 AI 考虑到接收信息者的角色和认知水平，进行二次加工和定制化输出。

```
是这样的，我的老板会经常给我任一段他跟这个品牌方的录音，这个录音呢是品牌方提的具体的需求。然后呢，我脑子比较糊涂，你能不能帮我梳理一下，这个brief里面有哪些重要的点以及有哪些隐藏的点？我老板前两天刚刚说我，这个人说话就太直接，只能说把东西变现的，但是呢，也不知道什么隐藏点，所以你这次一定要把我隐藏点搞出来，不然我老板会骂死我。所以你给我两个部分的输出：
1. 第一个部分输出就是把这个文案的重点进行标注，给我看原文，不要给我整乱七八糟东西，不要给我整出幻觉来。
2. 第二个，你帮我告诉我，这段东西扔出来之后呢，你完成一份文案给我，然后呢，我需要去喂给我的新的一个窗口，GPT窗口，让它来帮我去做文案的梳理工作，所以要求的格式是ABCDEFG。你还告诉我说我要再另开一个聊天窗口。
```
