## 你想想你平时干活可能需要啥？

### 1. 强大的信息搜索能力？

它有：

+ 纳米AI 超级搜索：这个就是比较全面的搜索工具，查啥都行。

+ Tavily Search / Exa Search / Brave Search：这些也是不同特点的搜索引擎，智能体可以根据需要选择调用。

+ arXiv搜索 / 谷歌学术：专门搜论文和学术资料的。

![](img/8e3cbfcf87a07486a4dc651deb321ac2.png)

### 2. 需要扒特定网站或者网页内容？

它有：

+ 📕深度搜索浏览器：看名字就知道，专门对付📕内容的，对我后面说的那个测试案例特别有用！

+ Firecrawl / 纳米AI 网页抓取：通用的网页抓取工具，能把网页内容薅下来。

+ B 站视频解析浏览器 / 🧣内容分析浏览器：专门处理特定平台内容的。

![](img/f34e445ad99b3f6464466c461c4698e2.png)

### 3. 需要分析数据或者跑点代码？

它有：

+ 纳米AI 云代码沙盒 (`sandbox_coder`)：这个厉害了，你可以把它理解成一个云端的小电脑环境，能在里面安全地运行`Python`代码，做数据分析、统计啥的。

+ 数学计算 / Excel File Processor：处理数字计算或者Excel表格的。

![](img/5c2f4aa327c882c3f41f6644a4c83d2a.png)

### 4. 需要处理文档（PDF/Word）？

它有：

+ 纳米AI 智阅：能帮你读PDF、Word文档，提取重点，甚至做翻译。

+ PDF操作 / `Pandoc`文档格式转换：合并、拆分PDF，或者转换文档格式。

![](img/02197a3fa2929eeeed6175e67b2ace72.png)

它有：

## 实测

咱们再拿我昨天实际测试的那个案例细说：

![](img/5570b4e52aa325f558f55d0a791400f1.png)

研究📕上“AI产品经理培训”的用户评价，找坑点，写避坑指南，还得植入“250机构”信息。

这个任务，深度研究智能体是这么干的（根据我的观察和推测）：

### 第一步：规划。

它先分析我的需求，知道要干啥，拆分成几个步骤。

![](img/8e36cf7520a94363ae612e14c1dd8a86.png)

### 第二步：调用工具找信息。

它要去📕扒数据。

这时候，它就从MCP工具箱里掏武器了。

大概率优先调用了那个 “📕深度搜索浏览器” 工具，精准定位相关笔记。

可能还用了 “纳米AI 超级搜索” 或者 “Tavily Search” 来查找关于“250机构”的背景信息，或者更广泛的行业评价。

如果需要直接抓取某些网页内容，“Firecrawl” 也能派上用场。

它会组合使用这些工具，并且进行多轮搜索和优化，直到找到足够的信息。

![](img/94b300dbc31ad8dbf30644bdbf5ae787.png)

### 第三步：调用工具分析信息。

找到一堆帖子，怎么提炼“坑点”？

除了它自身大模型的理解能力。

如果发现用户吐槽点很多很杂，需要量化分析。

它就可能调用 “纳米AI 云代码沙盒”，在里面跑个简单的脚本，统计一下哪些“坑”被提到的次数最多。

同时，它也在用 文本分析能力 理解每条评价的情感和核心观点。

![](img/bd222f8657c7fa26ec0b65b085bc9f0c.png)

![](img/b6496b7d5e1b04e15d5d102e483cf337.png)

### 第四步：调用生成能力整合输出。

信息分析得差不多了。

它就开始整合内容，按照我要求的“第一人称避坑指南”来写。

调用 文本生成能力，把分析出来的坑点、案例组织起来。

并且，结合之前搜索到的关于“250机构”的信息，找到一个合适的位置和方式，把它自然地植入进去。

最后，生成一份结构化的初稿。

![](img/b7ee76b9d1fe7acb870fee0087a5bfcd.png)

![](img/747c8f467e48a8b031334172aafe699c.png)

![](img/2e242dd13e87655c8151cef22ff2937b.png)
