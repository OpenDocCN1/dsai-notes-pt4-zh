
# R 与 Python 在数据分析中的优势

## R 的优势

- 为分析提供了极好的灵活性
- R 使你在分析的时候更容易思考
- 由于有着十分活跃的统计与数学社区，可以持续的更新和增强分析功能优秀的数据可视化工具
- 优秀的数据可视化工具

## Python 的优势

使用 Python 进行数据预处理、数据清洗，特别针对于非结构化数据（如网页，图像，文本等）：

- 极强的灵活性，能够从自由文本、网站和社交媒体网站提取信息
- 便于图像挖掘和为分析准备数据
- 处理大量的数据的时候比 R 语言更好

## 总结

对于一个认真的数据科学家来说，R 和 Python 都应该了解。我们需要的是 R+Python，而不是 R vs Python。
