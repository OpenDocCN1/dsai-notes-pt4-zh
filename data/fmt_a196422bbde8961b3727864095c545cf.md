
# `@Web`

> 来源：[https://kcn9ut4m7icc.feishu.cn/docx/DuEYdF5uko0uB1xj2iSct7kCnrf](https://kcn9ut4m7icc.feishu.cn/docx/DuEYdF5uko0uB1xj2iSct7kCnrf)

`@Web` command searches the internet automatically to find relevant context for Cursor queries

`@Web` 命令自动搜索互联网以找到 Cursor 查询的相关上下文

## `@Web`

![](img/b8969168b1e53d808b38b4e6b88bcb4a.png)

With `@Web`, Cursor constructs a search query based on the query and the context you’ve provided, and searches the web to find relevant information as additional context.

使用 `@Web` ，Cursor 根据您提供的查询和上下文构建搜索查询，并在网络上搜索相关信息以作为额外上下文。

This can be useful to allow Cursor to find the most up-to-date information online, or to allow Cursor to scrape multiple websites in a few seconds to find the best answer, without the user having to manually search anywhere.

这可以让 Cursor 找到最新的在线信息，或者让 Cursor 在几秒钟内抓取多个网站以找到最佳答案，而无需用户手动搜索任何地方。

> When using Agent mode, Cursor will automatically search the web when it needs up-to-date information or additional context.

> 当使用代理模式时，Cursor 会在需要最新信息或额外上下文时自动搜索网络。
