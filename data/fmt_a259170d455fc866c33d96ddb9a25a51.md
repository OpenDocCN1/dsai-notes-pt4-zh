
# Prompt Hacks to Get ChatGPT to Think Differently

> 来源：[https://my.feishu.cn/docx/EYo9dRo8boDCIvxJUhHcURLwnPc](https://my.feishu.cn/docx/EYo9dRo8boDCIvxJUhHcURLwnPc)

适合希望获得更有洞见、具人性化、或更具创新输出的用户或专业人士，如创意写作、决策思维、数据解读、分析、反思等。

**提示词：**

```
“I’m probably wrong, but”…
“translate this into everyday language”…
“connect these dots for me”…
“what’s the 80/20 here?”…
“play devil’s advocate against yourself”…
“what story is the data telling?”…
“what’s the counterintuitive move here?”…
“what would I regret not knowing?”
```

```
“我可能错了，但……”…
“把这用日常语言翻译一下”…
“帮我把这些点联系起来”…
“这里的 80/20 是什么？”…
“自己给自己当反面角色”…
“数据在讲怎样的故事？”…
“这里有什么反直觉的做法？”…
“有什么我会后悔不知道的吗？”
```
