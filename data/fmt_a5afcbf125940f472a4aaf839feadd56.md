
# AI 应用开发新范式与实战

## 第一部分：传统开发 vs AI 新范式

想法 → 学习技术栈 → 编写代码 → 测试调试 → 部署上线

```
+   ❌ 门槛高：需要掌握前端、后端、数据库等多项技能

+   ❌ 周期长：从学习到上线可能需要数月甚至数年

+   ❌ 成本高：个人开发者很难独立完成
```

### AI 时代的新范式

想法 → 选择AI工具 → 自然语言描述 → 快速上线

```
+   ✅ 门槛低：会说话就能开发应用

+   ✅ 周期短：从想法到上线可能只需要几分钟到几小时

+   ✅ 成本低：个人就能完成完整项目
```

### 但核心能力要求变了

> 创意 + 数据质量 > 代码编写能力

### 第一个关键洞见

> **AI 能轻松生成代码，但无法保证数据质量。**优质真实数据 > AI 生成的虚假数据。

现在很多 AI 生成的应用，数据都是 AI 编造的。但 AI 在现阶段对于复杂领域的数据生成，胡编乱造的情况还比较严重。

所以，真实、优质的数据源是 AI 应用成功的关键。

## 第二部分：AI Coding 实战流程

### 步骤 1：数据准备（最关键的一步）

从 GitHub 开源项目 `https://github.com/Gar-b-age/CookLikeHOC` 获取菜谱数据后，需要进行整理：

![](img/8cfeedac0e61c69b0a4cafa2252de9ee.png)

**数据结构化**：

+   每道菜包含：菜名、类别、配料、烹饪步骤

+   使用统一的分隔符 `=======` 标注

+   确保数据格式清晰、易于解析

![](img/6353f6c604744646152db3453f7bb621.png)

**为什么数据准备如此重要？**

1.  **数据质量直接决定应用质量**：垃圾进，垃圾出

2.  **结构清晰，AI 才能正确理解**：格式混乱会导致解析错误

3.  **真实数据增加可信度**：用户能感知到内容的专业性

### 步骤 2：用自然语言描述需求

不需要写代码，只需要清晰地描述你的需求。

**我给秒哒的 `Prompt`**：

```
请制作一个菜谱网站，展示各类菜谱。

我已经给你提供了菜谱文件，`cook_副本.txt` 文件中包含了上百道菜谱，

包含菜名、类别、配料、步骤，每个菜谱之间用 `=======` 隔开。
```

![](img/fd28a41f99fd88bc21a5a256b3e76ebe.png)

**写好 Prompt 的要点**：

+   ✅ 清晰说明要做什么（菜谱网站）

+   ✅ 说明数据结构（字段和分隔符）

+   ✅ 让 AI 理解你的意图

+   ❌ 不用写技术细节（用什么框架、什么数据库）

### 步骤 3：AI 智能体团队自动协作

接下来，秒哒内部的 AI 团队开始工作：

1.  **AI 产品经理：撰写需求文档**

产品经理会自动生成详细的需求文档，包括：

+   整体网站描述

+   核心功能列表（浏览、分类、详情、搜索）

+   菜品分类信息

![](img/3d91b23a8510d223af1144b8d765b7eb.png)

2.  **AI 架构师：规划页面框架**

架构师会进行技术架构设计和页面框架规划。

![](img/5b8ea9116a21c006a64ea7fbaeb3431b.png)

3.  **AI 工程师：编写代码**

工程师会根据需求文档和架构设计，自动生成前端和后端代码。

4.  **AI 测试员：测试验证**

测试工程师会对各个页面和功能进行自动化测试。

![](img/035890b14473d2edcdad316995245cd6.png)

**整个过程的特点**：

+   🔄 全自动化：无需人工干预

+   👁️ 过程可见：每一步都清晰展示

+   ⏱️ 后台运行：可以退出页面，任务继续执行

![](img/2a387d64dc87709ea20c376b66cd7e09.png)

### 第二个关键洞见

> 真正的 AI 应用开发，不是"你写代码"，而是"你做产品经理"。

你的角色从程序员变成了产品经理：

+   你负责定义需求、提供数据

+   AI 负责实现技术细节

+   这是思维方式的根本转变

### 步骤 4：快速迭代优化

应用生成后，修改和迭代非常方便，完全不需要改代码。

**案例：添加新菜品**

直接对话：

```
"帮我把这几个菜谱添加到'炒菜'类别里。"
```

![](img/2ad74d604ec38d4dbcc4475538410c3a.png)

**结果**：从 4 道菜到 11 道菜，一句话完成。

![](img/66971423c7193877f41616d640970e67.png)

**迭代的优势**：

+   🚀 快速响应：想到什么改什么

+   💬 对话式交互：像和助手聊天一样

+   🔄 持续优化：随时根据需求调整

### 步骤 5：集成 AI 智能助手

网站不仅能看，还能"聊"。通过集成 AI 智能体，让用户可以交互式获取信息。

**配置流程**：

1.  在百度千帆平台创建"老乡鸡大厨"智能体

2.  上传菜谱数据作为知识库

3.  配置对话能力和提示词

4.  将智能体嵌入网站侧边栏

**用户体验**：

+   用户可以直接问："香菇鸡汤面怎么做？"

+   机器人调用知识库，给出详细步骤

+   实现了从"查看"到"对话"的升级

![](img/a8af3e0cd533e315b136d76b57b35650.png)

## 第三部分：核心方法论和洞见（3 分钟）

### 三个关键认知

1.  AI 降低的是执行门槛，不是思考门槛

+   技术壁垒在降低

+   但对创意、洞察力的要求更高

+   你要知道"做什么"，AI 帮你"怎么做"

2.  **数据比代码更重要**

+   AI 可以生成代码

+   但优质真实数据需要你去找、去整理

+   数据质量 = 应用质量

3.  **场景定位是第一步**

+   不是"我要做个网站"

+   而是"解决什么问题？服务谁？"

+   我的场景：想做饭但不会的年轻人

### 可复用的方法

**做 AI 应用的三步法**：

1.  **找痛点**：观察生活，发现需求

2.  **找数据**：获取优质真实数据（开源项目、公开数据、自己整理）

3.  **找工具**：用 AI 工具快速实现

**验证很重要**：

+   AI 生成的结果要验证

+   数据准确性要检查

+   用户反馈要收集
