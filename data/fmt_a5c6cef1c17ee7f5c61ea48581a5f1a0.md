## 人工智能与数学

### 人工智能的发展现状

当前人工智能技术正处于高速发展阶段，以深度学习为核心的生成式AI（如`ChatGPT`、`DALL-E`）实现了突破性进展，大模型在多模态理解和内容生成领域展现出类人能力。应用场景已渗透医疗、金融、教育等行业，但同时也面临算法偏见、数据隐私、能耗过高及伦理治理等关键挑战，技术落地仍需突破可靠性与可控性瓶颈。

### 人工智能的理论基础

人工智能的理论基础经历了多个阶段的演化与融合。早期以符号主义为核心，通过逻辑推理和知识表示模拟人类智能（如`ELIZA`程序）；20世纪70年代后，连接主义兴起，神经网络和反向传播算法成为重要支柱，奠定了深度学习的数学基础。当前，人工智能理论整合了混合主义思想，结合大数据与机器学习，形成以深度学习、强化学习为核心的现代框架。数学理论如概率论与统计学（支持贝叶斯网络和不确定性建模）、线性代数（处理高维数据与矩阵运算）、优化理论（驱动模型参数训练）以及信息论（指导数据压缩与传输）共同构成了AI算法的底层逻辑。此外，图论和离散数学在复杂系统建模与算法设计中发挥关键作用。

### 数学思维的应用情况

数学思维在人工智能中贯穿技术研发与应用全流程。例如：概率论与统计学支撑推荐系统的个性化建模（如电商用户行为分析）；微积分通过梯度下降法优化神经网络参数，实现图像识别与自然语言处理的高精度；线性代数中的矩阵分解技术被用于计算机视觉的特征提取。在生成式AI领域，生成对抗网络（`GAN`）依赖博弈论与优化理论的结合，而`Transformer`架构则基于自注意力机制的线性代数运算实现多模态内容生成。此外，信息论通过熵量化数据价值，优化数据采样策略。然而，数学应用也面临挑战，如高维数据导致的“维度灾难”、模型可解释性不足引发的“算法黑箱”问题，以及训练数据质量对统计推断的显著影响。当前研究正探索微分几何与拓扑学等新数学工具，以突破现有模型的泛化能力瓶颈。

## 高等数学基础

### 函数极限与连续性

#### 函数极限的定义

设函数`f`在点`x_0`的近旁有定义，但`x_0`这一点自身可以是例外。设`L`是一个实数。如果对任意给定的`ε`，存在一个`δ`，使得对一切满足不等式`0 < |x - x_0| < δ`的`x`，均有

```
|f(x) - L| < ε
```

则称当`x`趋于点`x_0`时函数`f`有`极限`，记作

```
lim_{x -> x_0} f(x) = L
```

或者更简单一些，记作

```
lim f(x) = L
```

这时，也可以说函数`f`在点`x_0`有`极限`。

`lim_{x -> ∞} f(x)` 存在的充分必要条件是 `lim_{x -> ∞} f(x)` 且 `lim_{x -> -∞} f(x)` 存在且相等。

#### 函数连续性的定义

设函数`f`定义在区间`x_0 ∈ (a, b)`上，其值域是实数集`R`。如果

```
lim_{x -> x_0} f(x) = f(x_0)
```

我们称函数`f`在点`x_0 ∈ (a, b)`连续。

也就是说，对任意给定的`ε`，存在一个适当的`δ`，使得当`|x - x_0| < δ`时，有

```
|f(x) - f(x_0)| < ε
```

由这一定义可以看出，若函数`f`在`x_0`处连续，则：

+   `f`必须在点`x_0`处有定义；
+   `f`在`x_0`这一点必有极限，即`lim_{x -> x_0} f(x) = f(x_0)`；
+   极限值等于函数值。

同极限一样，函数`f`在`x_0`处连续的充分必要条件是`f`在`x_0`这一点处既左连续又右连续。

### 导数与微分

#### 导数的定义

设函数`f`在点`x_0`的近旁有定义，如果极限

```
lim_{h -> 0} (f(x_0 + h) - f(x_0)) / h
```

存在且有限，则称这个极限值为在点`x_0`的导数，记作`f'(x_0)`，并称函数`f`在点`x_0`可导，也常记为`df/dx`。

显然，函数`f`在点`x_0`可导的一个充分必要条件是：`f`在点`x_0`的左、右导数存在且相等，这里

```
f'_-(x_0) = f'_+(x_0)
```

#### 可导与连续的关系

若函数`f`在点`x_0`可导，则`f`必在`x_0`连续；反之，则不然。

> 例1 设`f(x) = |x|`。证明：函数`f`在`x_0 = 0`处不可导，但在`x_0 = 0`处连续。

> 证明 因为

```
f'_-(0) = -1, f'_+(0) = 1
```

>

> 所以`f'_-(0) ≠ f'_+(0)`，从而`f`在`0`处不可导。

> 而

```
lim_{x -> 0} f(x) = f(0)
```

> 因此`f`在`0`处连续。

#### 复合函数求导

对于复合函数`f(g(x))`，其导数的计算要遵从链式法则。

令`u = g(x)`，则

```
df/dx = df/du * du/dx
```

#### 多元函数

1.  偏导数

设函数`f(x, y)`在点`(x_0, y_0)`的某一邻域内有定义，若极限

```
lim_{h -> 0} (f(x_0 + h, y_0) - f(x_0, y_0)) / h
```

存在，则称函数`f`在点`(x_0, y_0)`处关于`x`可偏导，并且称此极限值为函数`f`在点`(x_0, y_0)`处对`x`的偏导数，通常采用以下记号来表示：

```
∂f/∂x 或 f_x
```

同样地，可以定义函数`f`在点`(x_0, y_0)`处对`y`的偏导数，即

```
∂f/∂y 或 f_y
```

偏导数的计算方法同一元函数的计算方法。

1.  全微分

### 梯度和方向导数

1.  梯度

定义：设函数`f(x, y)`在平面区域`D`内具有一阶连续偏导数，则对于每一点`(x_0, y_0)`，都可确定一个向量：

```
∇f = (∂f/∂x, ∂f/∂y)
```

该向量称为函数`f`在点`(x_0, y_0)`处的梯度，记作`∇f`，即

```
∇f(x_0, y_0) = (f_x(x_0, y_0), f_y(x_0, y_0))
```

几何意义：梯度为等高线上点`(x_0, y_0)`处的法向量，且从数值较低的等高线指向数值较高的等高线。

1.  方向导数

偏导数反映的是函数沿坐标轴方向的变化率，方向导数本质上研究的是函数在某点沿某特定方向的变化率问题。

函数`f`在点`P`沿方向`v`的变化率如下图所示。

![](img/93e705412797c3b4c7db706023e7e477.png)

图2-3 函数沿方向`v`的变化率

考虑函数的增量与这两点间距离的比值，当`P`沿方向`v`趋于`Q`时，若这个比的极限存在，则称该极限为函数`f`在点`P`处沿方向`v`的方向导数，记作`D_v f`，即

```
D_v f = lim_{t -> 0} (f(P + tv) - f(P)) / t
```

其中，`|v| = 1`。

若函数`f`在点`P`处是可微分的，则函数在该点沿任一方向`v`的方向导数都存在，且有

```
D_v f = ∇f · v
```

其中，`θ`为`x`轴到方向`v`的转角。

可以看出，函数在某点的梯度是这样一个向量：它的方向与函数取得最大方向导数的方向一致，而它的模为方向导数的最大值。

## 导数在函数性质中的应用

### 单调性

函数的单调性，是指函数的递减或递增的性质。

设函数`f`在区间`[a, b]`上连续，在`(a, b)`上可导，那么`f`在`[a, b]`上递增（减）的充分必要条件是，`f'(x)`在区间`(a, b)`上成立。

设函数`f`在`[a, b]`上连续，在`(a, b)`上可导。如果`f'(x) > 0`（`f'(x) < 0`）在`(a, b)`上成立，那么`f`在`[a, b]`上是严格递增（严格递减）的。

### 凹凸性

![](img/05aa30180b8a8d5ffe3dfacc5ffb0dc7.png)

图2-4 凹曲线与凸曲线

+   凹曲线：曲线上任意两个不同点连接的弦始终在曲线弧的上方
+   凸曲线：曲线上任意两个不同点连接的弦始终在曲线弧的下方

因此，曲线的凹凸性定义如下：

设函数`f`定义在`[a, b]`上且连续，若对`[a, b]`中任意不同的两点`x_1, x_2`，总有

```
f(λx_1 + (1-λ)x_2) ≤ λf(x_1) + (1-λ)f(x_2)
```

则称曲线`f`在`(a, b)`上是凸的；若对`[a, b]`中任意不同的两点`x_1, x_2`，总有

```
f(λx_1 + (1-λ)x_2) ≥ λf(x_1) + (1-λ)f(x_2)
```

则称曲线`f`在`(a, b)`上是凹的。

曲线的凹凸分界点称为曲线的拐点。

设函数`f`在区间`[a, b]`上连续，在`(a, b)`内有二阶导数，则`f`在`[a, b]`上为凸函数的充分必要条件是，`f''(x) ≥ 0`在`(a, b)`内成立；而`f`在`[a, b]`上为凹函数的充分必要条件是，`f''(x) ≤ 0`在`(a, b)`内成立。

### 极值

若`x_0`是函数`f`的一个极值点，并且`f'(x_0)`存在，那么必有`f'(x_0) = 0`，即`x_0`是`f`的一个驻点。但是，若函数`f`在`x_0`处不可导，则`x_0`不会是驻点。例如，函数`f(x) = |x|`在`x_0 = 0`处取得极小值（实际上是最小值），但这一点不是`f`的驻点，因为这时`f'(0)`不存在。很明显的是，在`x_0 = 0`的左边，函数`f`是严格递减的，而在`x_0 = 0`的右边，它是严格递增的，所以`x_0 = 0`是最小值。

这种观察有其一般性，函数`f`由递减转变为递增的临界点，应是`f`的一个极小值点；而由递增转变为递减的临界点，应是`f`的一个极大值点。

函数的极值是局部概念，最值是针对区间的全局概念。

函数取极值的第一种充分条件：

设函数`f`在区间`[a, b]`上连续，`x_0`是`f`的一个驻点。

（1）如果存在正数`δ`，使得在`(x_0 - δ, x_0)`上`f'(x) > 0`，而在`(x_0, x_0 + δ)`上`f'(x) < 0`，那么`f(x_0)`是函数`f`的一个严格极大值，所谓“严格极大值”是指，当`x ∈ (x_0 - δ, x_0 + δ)`且`x ≠ x_0`时，`f(x) < f(x_0)`；

（2）如果存在正数`δ`，使得在`(x_0 - δ, x_0)`上`f'(x) < 0`，而在`(x_0, x_0 + δ)`上`f'(x) > 0`，那么`f(x_0)`是函数`f`的一个严格极小值，所谓“严格极小值”是指，当`x ∈ (x_0 - δ, x_0 + δ)`且`x ≠ x_0`时，`f(x) > f(x_0)`；

（3）如果存在正数`δ`，使得在`(x_0 - δ, x_0)`和`(x_0, x_0 + δ)`上，`f'(x)`的符号不发生改变，则`x_0`不是函数`f`的极值。

函数取极值的第二种充分条件：

设函数`f`在区间`[a, b]`上连续，`x_0`是函数`f`的一个驻点，且该点处的二阶导数`f''(x_0)`存在，那么：

(1) 当`f''(x_0) < 0`时，`x_0`是`f`的一个严格极大值；

(2) 当`f''(x_0) > 0`时，`x_0`是`f`的一个严格极小值；

(3) 当`f''(x_0) = 0`时，`x_0`可能是`f`的极值，也可能不是`f`的极值。

### 积分学

#### 不定积分

+   原函数

在区间`[a, b]`上，如果`F'(x) = f(x)`，则称`F(x)`为`f(x)`的导函数，称`f(x)`为`F(x)`的原函数，原函数与导函数是一种互逆关系。

连续函数一定存在原函数，且原函数不是唯一的，它们之间相差一个常数。

+   不定积分

如果`F(x)`为`f(x)`的一个原函数，则`F(x) + C`为`f(x)`的全体原函数（`C`为任意常数），记为`∫f(x)dx = F(x) + C`，即`∫f(x)dx`，称`∫f(x)dx`为不定积分，其中，`∫`为积分号，`f(x)`为被积函数，`x`为积分变量。

### 行列式

#### 行列式定义

##### 三阶行列式

![](img/3d052641930f2949e4a139e5750d2789.png)

##### n 阶行列式

> 由`n^2`个元素组成的算式`D`为

```
| a_11 a_12 ... a_1n |
| a_21 a_22 ... a_2n |
|  ...   ...   ...  ... |
| a_n1 a_n2 ... a_nn |
```

> 称其为`n`阶行列式，简称行列式。

> 其中，`a_ij`称为`D`的第`i`行、第`j`列的元素，`j = 1, 2, ..., n`。

当`n-1`阶行列式已定义时，`n`阶行列式为

```
D = Σ (-1)^(1+j) a_1j M_1j
```

##### 几种特殊的行列式

+   上三角形行列式
+   下三角形行列式
+   对角形行列式
+   转置行列式

##### 行列式的性质

![](img/3ccb933f16ae52c06830bc8adcb7934e.png)

性质1 行列式与它的转置行列式相等。

性质2 对换行列式的两行（列），行列式变号。

推论 如果行列式有两行(列)完全相同，则此行列式等于零。

性质3 行列式的某一行（列）中所有的元素都乘同一数`k`，等于用数`k`乘此行列式。

推论 行列式中某一行（列）的所有元素的公因子可以提到行列式记号的外面。

性质4 行列式中如果有两行(列)元素成比例，则此行列式等于零。

性质5 若行列式的某一行(列)的元素都是两数之和，则`D`等于这两个行列式之和。

性质6 把行列式的某一行(列)的各元素乘同一数然后加到另一行(列)对应的元素上去，行列式不变。

### 向量

#### 向量的基本概念

> 定义：由`n`个数`a_1, a_2, ..., a_n`组成的`n`元有序数组`α`称为一个`n`维向量。

> 其中，第`i`个数`a_i`称为该向量的第`i`个分量。

> 向量通常用希腊字母`α`表示，向量中的分量通常用拉丁字母`a`表示。

##### 向量的长度

向量的**长度**，也叫作向量的**二范数**、**模长**，记作`||α||`，其计算公式就是两点间欧氏距离公式。

对于向量`α`：

其长度公式为

```
||α|| = sqrt(a_1^2 + a_2^2 + ... + a_n^2)
```

##### 向量的运算

+   向量的相等
+   向量的加法
+   向量的数乘
+   向量的线性组合

将向量的加法和数乘组合起来，就得到了向量的线性组合。

+   向量的乘法

两个向量的乘法(也叫点积)等于两个向量对应元素之积的和。点积运算的公式如下：

```
α · β = a_1b_1 + a_2b_2 + ... + a_nb_n
```

### 向量间的线性关系

> 定义1：设向量组`α_1, α_2, ..., α_m`为`m`个`n`维向量，若有`m`个数`k_1, k_2, ..., k_m`使得

```
k_1α_1 + k_2α_2 + ... + k_mα_m = β
```

> 则称`β`为`α_1, α_2, ..., α_m`的**线性组合**，或称`β`由`α_1, α_2, ..., α_m`**线性表示**。

> 定义2：若向量组`α_1, α_2, ..., α_m`中的每个向量`α_i`均可由向量组`β_1, β_2, ..., β_n`线性表示，则称向量组`α`可由向量组`β`线性表示。若向量组`α`与向量组`β`可相互线性表示，则称这两个向量组等价，记为`α ~ β`。

向量组等价的性质：自身性、对称性、传递性。

### 矩阵

#### 矩阵的概念

这是`m`行`n`列的矩阵。位于第`i`行第`j`列的值(称为元素)用`a_ij`表示。

> 神经网络的矩阵表示形式

![](img/425a2dee0212495e01a60dc76efcd6e8.png)

大脑通过神经元之间的协作完成各种功能。受人类大脑神经系统的启发，人工神经网络的基本模型为

```
y = f(Wx + b)
```

用矩阵形式表示为

```
Y = f(WX + B)
```

#### 矩阵的和、差、数乘

两个矩阵`A`、`B`的和`A + B`、差`A - B`定义为相同位置的元素的和、差所产生的矩阵。

此外，矩阵的数乘定义为各个元素的常数倍所产生的矩阵。

#### 矩阵的乘积

对于两个矩阵`A`、`B`，将`A`的第`i`行看作行向量，`B`的第`j`列看作列向量，将它们的内积作为第`i`行第`j`列元素，由此而产生的矩阵就是矩阵`A`、`B`的乘积`AB`。

![](img/3e9ae856c8cb1f071cdcdfc986f58a75.png)

对于相同形状的矩阵`A`、`B`，将相同位置的元素相乘，由此产生的矩阵称为矩阵`A`、`B`的Hadamard乘积，用`A ⊙ B`表示。

#### 转置矩阵

设矩阵`A`

把矩阵的行与列互换得到的`n × m`矩阵，称为`A`的转置矩阵（图7-5），记作`A^T`，即

```
A^T = (a_ji)_{n×m}
```

#### 矩阵的逆

对于矩阵`A`，若存在矩阵`B`，满足

```
AB = BA = I
```

则称矩阵`A`为可逆矩阵，简称`A`可逆；称`B`为`A`的逆矩阵，记为`A^{-1}`，即

```
AA^{-1} = A^{-1}A = I
```

由定义可知，`A`与`B`一定是同阶的方阵，而且若`A`可逆，则`A`的逆矩阵是唯一的。

#### 矩阵的初等变换

> 下面三种变换称为矩阵的**初等行变换**：

> （i）对换两行（对换`i`，`j`两行，记作`R_i ↔ R_j`）；
> （ii）以数`k ≠ 0`乘某一行中的所有元素（第`i`行乘`k`，记作`kR_i`）；
> （iii）把某一行所有元素的`k`倍加到另一行对应的元素上去（第`j`行的`k`倍加到第`i`行上，记作`R_i + kR_j`）。

> 把定义中的“行”换成“列”，即得矩阵的初等列变换的定义（所用记号是把“r”换成“c”）。

> 矩阵的初等行变换与初等列变换，统称初等变换。

如果矩阵`A`经有限次初等变换变成矩阵`B`，就称矩阵`A`与`B`等价，记为`A ~ B`。

对`m`阶矩阵`A`进行初等行变换，相当于将其左乘一个相应的`m`阶初等矩阵；对`n`阶矩阵`A`进行初等列变换，相当于将其右乘一个相应的`n`阶初等矩阵。

#### 矩阵的秩

在`m × n`矩阵`A`中，任取`k`行与`k`列，对于位于这些行列交叉处的`k^2`个元素，不改变它们在矩阵中所处的位置次序，所得的`k`阶行列式称为矩阵`A`的`k`阶子式。

设在矩阵`A`中有一个不等于`0`的`r`阶子式`D`，且所有`r + 1`阶子式（如果存在的话）全等于`0`，那么`D`称为矩阵`A`的最高阶非零子式，数`r`称为矩阵`A`的秩，记为`rank(A)`。

#### 矩阵在数字图像处理中的应用

##### 图像基础

数字图像，又称“数码图像”或“数位图像”，是以二维数字组形式表示的二维图像。根据数字图像在计算机中表示方法的不同，分为二值图像、灰度图像和`RGB`图像等，如下图所示。

![](img/341be2fd3ec9f9c208019de286f0974d.png)

数字图像处理(`Digital Image Processing`, `DIP`)又称“计算机图像处理”，它是指将图像信号转换成数字信号并利用计算机对其进行处理的过程。

##### 数字图像的矩阵表示

> 在计算机中，一个二维图像通常用一个`M × N`的矩阵表示，其中`M`表示图像的行数，`N`表示图像的列数。矩阵的每个元素对应图像的1像素，元素的值表示像素的灰度值或者颜色值。在不同的图像类型中，元素的取值范围也不同。

+   二值图像

在二值图像中，像素的值取`0`或者`1`，其中`0`表示黑色，`1`表示白色。二值图像一般用来描述文字或者简单图形，占用空间少，但是颜色区分度小，只能描述轮廓。

![](img/51c9e7e3505ec7ab49b5f5e60c587fdf.png)

+   灰度图像

灰度图像的像素值取值范围为`0～255`，其中`0`表示黑色，`255`表示白色，`1～254`表示不同的深浅灰色。相比二值图像，灰度图像增加了颜色的种类，但是缺乏色彩，如图7-11所示。
