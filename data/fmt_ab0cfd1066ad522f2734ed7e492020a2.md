## 目录

## 1. 职场领域

### 职场领域标题提示词

```
我需要你为一篇关于职场话题的公众号文章创作10个吸引人的标题。

要求：
1. 标题要有吸引力，能引发职场人士的共鸣和点击欲望
2. 长度适中，避免过长或过短
3. 可以适当使用数字、问句或悬念
4. 标题风格要符合职场人士的思考方式和语言习惯
5. 标题要自然流畅，避免机械感和刻板感
6. 使用第一人称或直接对话方式增加亲近感，如&quot;我&quot;&quot;你&quot;&quot;我们&quot;等
7. 加入情感色彩，表达职场中的喜怒哀乐、困惑或顿悟
8. 避免使用过于重复的句式结构
9. 可以适当融入当下流行的职场话题或热点
10. 标题中可以包含一些职场常见痛点或渴望

请确保标题具有原创性和多样性，不要使用过于模板化或公式化的表达。每个标题都应该有自己独特的吸引点，能够引起职场人士的共鸣和兴趣。

标题应该像是一个有多年职场经验的人写的，带有一定的个人洞察和情感温度，而不是冷冰冰的职场建议。
```

### 职场领域正文提示词

```
请以一位经验丰富的职场导师和内容创作者的身份，为我撰写一篇关于&quot;[具体职场主题]&quot;的公众号文章。

文章要求：
1. 内容深度：提供有价值的职场见解和观点，基于实际经验而非纯理论，不要流于表面的&quot;成功学&quot;说教
2. 写作风格：亲切自然，如同一位职场老友的真诚分享，避免高高在上的说教口吻
3. 语言特点：
   - 使用第一人称叙述，分享&quot;我&quot;的职场故事和感悟
   - 加入具体的职场场景和案例，最好是看起来像亲身经历的
   - 适当使用反问句，如&quot;你是否也曾遇到过...?&quot;来增加共鸣
   - 句式多样，混合使用长短句，避免连续使用相同句式
   - 加入一些职场中常见的口头禅和俚语，但不要过度
   - 使用多样化的标点符号，包括破折号、省略号等，增加表达的丰富性
   - 偶尔使用一些不太规范但很生活化的表达
4. 结构安排：
   - 开头可以是一个小小的职场困境或故事，引发读者共鸣
   - 正文部分要有清晰的思路，但避免过于明显的1、2、3式结构
   - 在文章中间可以适当插入一些个人感悟或疑问
   - 结尾要有实用的建议，但也留有余地，承认没有放之四海而皆准的解决方案
5. 情感表达：
   - 坦诚分享职场中的挫折和困惑，不只是成功经验
   - 表达对某些职场现象的复杂感受，可以有矛盾的情绪
   - 适当表达一些不确定性，如&quot;我也在摸索中&quot;，避免过于自信的断言
   - 加入一些幽默感，自嘲或调侃职场中的荒谬现象

请避免：
- 过于教条化的职场建议
- 空洞的成功学口号
- 过于完美的职场故事和解决方案
- 缺乏个人观点和情感的客观叙述
- 过于正式和学术化的语言
- 连续使用相同的句式结构
- 过度使用&quot;首先&quot;、&quot;其次&quot;、&quot;最后&quot;等明显的过渡词

文章应该像是一个在职场摸爬滚打多年的人，在下班后和朋友分享的真实感悟，有血有肉，有成功也有失败，有确信也有疑惑。

文章长度：2000-3000字左右
目标受众：25-45岁的职场人士，包括职场新人和有一定经验的中层管理者
```

```

3. 语言特点：
   - 使用第一人称叙述，分享&quot;我&quot;的观察和感受
   - 加入一些似乎是亲历或独家的小细节（可以是虚构的）

   - 句式多样，混合使用长短句，节奏感强
   - 加入当下流行的网络用语和梗，但要自然不刻意
   - 使用多样化的标点符号，包括感叹号、省略号等，增强情感表达

4. 结构安排：
   - 开头可以是一个吸引眼球的小爆料或有趣的问题
   - 正文部分要有起伏和转折，避免平铺直叙
   - 在文章中间可以适当加入自己的猜测或&quot;小道消息&quot;
   - 结尾可以是一个有趣的总结或对未来的期待
5. 情感表达：
   - 表达对娱乐事件或明星的真实感受，可以有喜欢也可以有不满
   - 避免过度吹捧或过度批评，保持相对客观但有个人立场
   - 适当表达一些&quot;粉丝心态&quot;，增加亲近感
   - 加入一些自嘲或调侃，展现幽默感

请避免：
- 过于严肃或学术化的分析
- 空洞的赞美或无根据的批评
- 过于正式和刻板的语言
- 连续使用相同的句式结构
- 过度使用&quot;首先&quot;、&quot;其次&quot;、&quot;最后&quot;等明显的过渡词
- 缺乏个人观点和情感的客观报道

文章应该像是一个娱乐圈资深观察者在与朋友分享内幕和看法，有趣、有料、有观点，让读者感觉获得了一些&quot;圈内人&quot;才知道的信息和视角。

文章长度：1500-2500字左右
目标受众：18-40岁的娱乐圈关注者，包括普通观众和明星粉丝
```

目标受众：25-50岁的关注时事、有一定思考能力的读者群体

8. 避免使用过于重复的句式结构

### 汽车领域正文提示词

```
请以一位资深汽车爱好者和内容创作者的身份，为我撰写一篇关于&quot;[具体汽车主题]&quot;的公众号文章。

文章要求：
1. 内容深度：提供有价值的汽车知识和见解，既有专业性又不失趣味性，避免纯粹的参数堆砌
2. 写作风格：热情自然，如同一位汽车达人在分享自己的亲身体验和独到见解
3. 语言特点：
   - 使用第一人称叙述，分享&quot;我&quot;的用车经历、试驾感受或研究心得
   - 加入具体的驾驶场景和使用体验，最好是看起来像亲身经历的
   - 适当使用一些感官描述，如&quot;方向盘的触感&quot;、&quot;发动机的轰鸣声&quot;等
   - 句式多样，混合使用长短句，营造行云流水的阅读感
   - 加入一些汽车圈的专业术语，但要适时解释，不要让普通读者看不懂
   - 使用多样化的标点符号，增强表达的生动性
   - 偶尔使用一些汽车爱好者之间的俚语或行话

   - 开头可以是一个有趣的用车故事或对某款车的第一印象
   - 正文部分要有清晰的逻辑，但避免过于明显的1、2、3式结构
   - 在文章中间可以适当插入一些个人使用心得或小技巧
   - 结尾可以是一个总结性的个人观点或建议，但承认个人偏好的主观性
5. 情感表达：
   - 表达对汽车的热爱和独特见解
   - 坦诚分享使用过程中的优缺点，不回避缺点
   - 适当表达一些纠结或矛盾的感受，如&quot;虽然油耗高了点，但那声浪实在太迷人&quot;
   - 加入一些幽默感和调侃，让文章更有趣味性

请避免：
- 过于干燥的参数罗列和技术说明
- 明显的广告式语言和过度吹捧
- 过于专业化而难以理解的内容
- 缺乏个人观点和情感的客观叙述
- 连续使用相同的句式结构
- 过度使用&quot;首先&quot;、&quot;其次&quot;、&quot;最后&quot;等明显的过渡词

文章应该像是一个真正热爱汽车的人在分享自己的经验和感受，有专业性，也有烟火气，让读者感受到作者对汽车的热情和独到见解。

文章长度：2000-3000字左右
目标受众：汽车爱好者、准车主和对汽车有兴趣的普通读者
```

   - 表达对历史人物或事件的敬佩、惋惜或思考
   - 避免过度情绪化的评价，但可以有温和的情感倾向
   - 适当表达一些对历史的好奇和探索欲
   - 加入一些对历史的个人感悟，增加人文关怀

请避免：
- 过于学术化或教科书式的叙述
- 简单的史实罗列和年代堆砌
- 过于主观或片面的历史评价
- 缺乏故事感和情感的客观叙述
- 连续使用相同的句式结构
- 过度使用&quot;首先&quot;、&quot;其次&quot;、&quot;最后&quot;等明显的过渡词

文章应该像是一个热爱历史的人在与朋友分享一段鲜为人知的历史故事，有趣、有料、有思考，让读者感受到历史的魅力和温度。
