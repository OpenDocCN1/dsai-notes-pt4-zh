
# 真正的科技变革发生的时候，最重要的是更新自己的认知，技巧是次要的

> 来源：[https://docs.feishu.cn/docx/Z9NfdKTzLoO9U7xobmQcKkXznag](https://docs.feishu.cn/docx/Z9NfdKTzLoO9U7xobmQcKkXznag)

前魅族 coo 李楠曾在 B 站视频中分享过：技术进步的阶段，你尚可研究“ 10 个技巧玩转Midjourney”。但当技术发生颠覆性变革的时候，你不能用技巧用技能掩盖认知的落后。

比如写 Java ，很多 Java 程序员没搞懂 Java 是面向对象的语言，只是学会了技巧层的皮毛，写出来的代码还是纯纯地面向过程，还是上个时代的认知。

真正的科技变革发生的时候，最重要的是更新自己的认知，技巧是次要的
