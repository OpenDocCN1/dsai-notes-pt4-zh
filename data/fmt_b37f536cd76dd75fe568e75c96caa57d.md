随着深度学习模型，特别是语言模型的规模的快速增大，对计算资源和时延要求越来越高。由此，以稀疏化为代表的模型压缩技术应运而生，这些方法为模型压缩和加速提供了一种可能的方向。本文将通过对主流稀疏技术的梳理和实践，来理解其对大规模语言模型的影响。

## 一、从数据无关到数据驱动的方法

### 1.1 Magnitude pruning (MaP) —— 数据无关的稀疏算法

`MaP` 是一种典型的数据无关的方法，此类方法基于一个思想：将权重低于某个阈值的全部被剪枝，之后进行`fine-tuned`直到准确率达到预期。

考虑一个典型的 `MLP+ReLU` 的场景，即 `Y=max(0, XW)`，由于 `ReLU` 函数的存在，会导致结果出现大量的 0 值，那么就可以考虑直接将权重 `W` 中的绝对值较小的值直接赋 0 处理，即

`Mij = Topv(S)ij = { 1 if Sij in top v% ; 0 otherwise }`

其中 `S = (|Wij|)1≤j,j≤n` 表示重要性分数。

那么结果即变为 `Y=max(0, X(W⊙M))`，其中 `⊙` 表示 Hadamard 积。其过程可用下图形象表达：

![](img/a146cbe3654db8e86d071e765b51c748.png)

下面通过一个小例子来说明操作的过程，在下面这段代码中，先取出权重，然后进行从小到大排列。基于稀疏百分比（`sparsity_percentage=0.7`），把权重中的从小到大排列的前百分之七十的权重设置为 0。

```
import numpy as np

weights = np.array([[-0.4711, 0.4448, 0.065], [0.4070, 0.4301, -0.7560]])
weights_ = np.linalg.norm(weights, axis=0)  # [0.62256262 0.61873504 0.75878917]
ind = np.argsort(np.linalg.norm(weights, axis=0))  # [1 0 2]
sparsity_percentage = 0.7
cutoff = int(len(ind) * sparsity_percentage)  # 2
sparse_cutoff_inds = ind[0:cutoff]  # [1 0]
weights[:, sparse_cutoff_inds] = 0  # [[ 0.     0.     0.065], [ 0.     0.    -0.756]]
```

剪枝后需要重新训练网络，以补偿在网络 `performance` 上的损失。在重新训练的时候需要注意，剪枝后的那些权重在重新训练的过程中不能被更新。

下图展示了 `ResNet` 模型的 `Dense` 层在稀疏前（a），稀疏后（b），以及重训后（c）的 `weight` 值的分布情况。

### 1.2 Movement Pruning (MvP) —— 数据驱动的稀疏算法

`MaP` 实际上只利用了模型权重的 0 阶信息（即绝对值），而 `MvP` 还利用了权重的一阶信息，即 `MvP` 中的权重 `W` 和重要性分 `S` 都会在微调的过程中更新。

设 `a_i = Σ W_{i,k} M_{i,k} x_k`，损失为 `L`，那么 `S` 的梯度如下：

`∂L/∂S_{i,j} = ∂L/∂a_i · ∂a_i/∂S_{i,j} = ∂L/∂a_i · W_{i,j} · x_j = ∂L/∂W_{i,j} · W_{i,j} = ∂L/∂W_{i,j} ⊙ W_{i,j}`

这说明即使在前向过程中 `W` 被 mask 了，其重要性分 `S` 也能被更新，`S` 按如下方式更新：

`S^{(t)} = |W^{(t)}| - α Σ (∂L/∂W)^{(i)} ⊙ W^{(i)}`

其中超参 `α` 用来平衡 0 阶和 1 阶的重要性分。

更新后再计算 `M = Topv(S)`，即参数有远离 0 点趋势的权重重要性高，有趋向 0 点的权重重要性低。

![](img/37f1776c2df8484471a20f27d4e95075.png)

实际上该方法利用了 `L` 的一阶泰勒展开，如果更加精细化还可以考虑二阶项

`δL = L(W+δW) - L(W) ≈ ∇_w L · δW + 1/2 · δW^T · H · δW`

其具体的训练代码可参考 [这里](https://link.zhihu.com/?target=https%3A//github.com/huggingface/transformers/blob/main/examples/research_projects/movement-pruning/masked_run_squad.py)，核心代码如下：

```
optimizer_grouped_parameters = [
    {
        "params": [p for n, p in model.named_parameters() if "mask_score" in n and p.requires_grad],
        "lr": args.mask_scores_learning_rate,
    },
    {
        "params": [
            p
            for n, p in model.named_parameters()
            if "mask_score" not in n and p.requires_grad and not any(nd in n for nd in no_decay)
        ],
        "lr": args.learning_rate,
        "weight_decay": args.weight_decay,
    },
    {
        "params": [
            p
            for n, p in model.named_parameters()

        ],
        "lr": args.learning_rate,
        "weight_decay": 0.0,
    },
]

optimizer = AdamW(optimizer_grouped_parameters, lr=args.learning_rate, eps=args.adam_epsilon)
```

## 二、PST —— 小参数训练的稀疏算法

`Parameter-Efficient Sparsity Training (PST)` 在 `MvP` 的基础上引入了两组小矩阵来计算权重的重要性，相比于原本需要与权重一样大的矩阵来保存和更新重要性指标，稀疏训练需要更新的参数量大大减少。该原理主要来源于一下特点：

低秩性（Low Rankness）

根据矩阵理论 `rank(W ⊙ ∂L/∂W) ≤ rank(W) * rank(∂L/∂W)`，

由于 `∂L/∂W` 是低秩的，`W` 在训练过程中也接近低秩，由此可考虑使用两个低秩矩阵 `A ∈ R^{n×r1}`, `B ∈ R^{r1×k}` 来表示一阶分量，即 `ΔS = AB`。

结构化（Structureness）

根据下图的统计结果，不同结构行和列在稀疏化的过程被稀疏的程度是不同的，基于这种发现，可以采用两个矩阵 `R ∈ R^{n×1}`, `C ∈ R^{1×k}` 来分别表示行和列的重要性分数。由此 1 阶分量可更新为：

`ΔS^{(t)} = α1 A^{(t)} B^{(t)} + α2 (R^{(t)} + C^{(t)})`

其中 `α1`, `α2` 用来平衡二者的相对大小。

![](img/bf9fadd7ea0190c9e5d560e34c464f0b.png)

另外，还可以对 `W` 做 `UV` 分解，即 `W^{(t)} = W^{(0)} + β U^{(t)} V^{(t)}`

由此重要性分可完整表述为：

`S^{(t)} = |W^{(0)} + β U^{(t)} V^{(t)}| + α1 A^{(t)} B^{(t)} + α2 (R^{(t)} + C^{(t)})`

完整的输出可表示为

`Y = X[(W^{(0)} + β U^{(t)} V^{(t)}) ⊙ f(|W^{(0)} + β U^{(t)} V^{(t)}| + α1 A^{(t)} B^{(t)} + α2 (R^{(t)} + C^{(t)}), v)]`

那么需要训练的参数包括 `U`, `V`, `A`, `B`, `R`, `C`，参考下图所示：

## 三、PLATON —— 考虑置信区间上界

在 `MaP` 算法中，使用 0 阶分量进行稀疏，实际上在复杂的模型结构中，较小的权重可能也会在输出中发挥很大作用。为更好分析权重对结果的影响，定义敏感度 `I = |W ∂L/∂W|`，为避免不同 `batch` 的影响，进一步对敏感度进行平滑处理，即

`Ī^{(t)} = β1 Ī^{(t-1)} + (1-β1) I^{(t)}`

其中超参 `β1 ∈ (0,1)`，并且 `Ī^{(0)} = 0`。

在得到平滑的敏感度后，还需要量化其不确定性，定义敏感度的不确定性为 `U^{(t)} = |I^{(t)} - Ī^{(t)}|`，同样对其进行平滑处理

`Ū^{(t)} = β2 Ū^{(t-1)} + (1-β2) U^{(t)}`

其中超参 `β2 ∈ (0,1)`，并且 `Ū^{(0)} = 0`，那么 `Ū^{(t)}` 可认为是 `Ī^{(t)}` 的置信上界（upper confidence bound, UCB）。

那么重新定义重要性分为

`S^{(t)} = Ī^{(t)} ⊙ Ū^{(t)}`

考虑到 `Ī^{(t)}`, `Ū^{(t)}` 值较小（接近 0），进一步进行指对数处理

`S^{(t)} = e^{log(Ī^{(t)}) + c · log(Ū^{(t)})}`

其中 `c` 为平衡超参。

官方代码可参考 [这里](https://link.zhihu.com/?target=https%3A//github.com/QingruZhang/PLATON)，其中核心部分 `Ī^{(t)}`, `Ū^{(t)}` 计算方法如下：

```
local_step = global_step % self.deltaT
update_step = global_step // self.deltaT
if local_step == 0:
    self.exp_avg_ipt[n] = self.beta1 * self.exp_avg_ipt[n] + (1 - self.beta1) * self.ipt[n]
    if self.beta2 > 0 and self.beta2 < 1:
        self.exp_avg_unc[n] = self.beta2 * self.exp_avg_unc[n] + (1 - self.beta2) * (self.ipt[n] - self.exp_avg_ipt[n]).abs()
    elif self.beta2 == 2.:
        self.exp_avg_unc[n] = (update_step * self.exp_avg_unc[n] + (self.ipt[n] - self.exp_avg_ipt[n]) ** 2) / (update_step + 1)
    self.ipt[n] = (p * p.grad).abs().detach()
else:
    self.ipt[n] = (self.ipt[n] * local_step + (p * p.grad).abs().detach()) / (local_step + 1)
```

`S^{(t)}` 的计算方法如下：

```
if self.beta2 > 0 and self.beta2 < 1:
    is_dict[n] = self.exp_avg_ipt[n] * self.exp_avg_unc[n]
elif self.beta2 == 1.:
    is_dict[n] = self.exp_avg_ipt[n]
elif self.beta2 == 2.:
    is_dict[n] = self.exp_avg_ipt[n] * self.exp_avg_unc.sqrt()
else:
    # Handling the uncepted beta2 to default setting 
    is_dict[n] = self.exp_avg_ipt[n] * (self.ipt[n] - self.exp_avg_ipt[n]).abs()
```
