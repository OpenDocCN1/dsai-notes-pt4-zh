## 作为投保人的赔付经历

先介绍一下自己，我是徐启伟，来自山东，在上海工作，现在是一名互联网金融产品经理。

不幸患病的是我三叔，他在2023年春天患上“多发性骨髓瘤”。7年前我给投保加入了大病互助：`康爱公社`（前身为抗癌公社）和`e互助`，他们各自赔偿了超过12万元，总和超过25万元。这也是自两年前全行业的关停潮之后（包括`支付宝`的`相互宝`，`美团互助`以及`360互助`等），仅剩下的两家互助平台。期间也陆续给加入过其它互助平台，但因平台都关停了，所有互助分摊的钱相当于做公益了。

在2023年的3月份，我的堂妹告诉我，她的父亲（我三叔）被诊断出患有“多发性骨髓瘤”。尽管在我担任`360互助`的产品经理期间，我经手过150多位大病患者的赔付事宜，但当疾病发生在我自己家庭的成员身上时，我还是感到无法置信。我深知，一旦人身患重疾，不仅对个人是一次重大打击，繁重的治疗费用也对农村家庭带来毁灭性影响。实际上，由于无钱治疗，许多农村家庭不得不放弃治疗。

然后，我想起了在2016年我为三叔参加的两家互助平台，这已经是7年前的事情了。为此，我为我的大家庭的十几个亲人投保了多家互助平台的保险。如今，我一直在每月续费分摊的，仅剩下的两家是`康爱公社`、`e互助`。在经过两个月的线下调查和线上公示，到了6月底，两家平台都赔付了互助金给我的三叔，大概总额为25万元。

令人欣慰的是，在这时期，我三叔通过积极接受干细胞免疫疗法，已经完全康复。两家互助平台的互助金基本覆盖了我三叔治疗期间的自付费部分。如果没有这些钱，结果我都难以想象。

大病互助的原则是“大病共济、互帮互助、自愿参与、公开透明”，每人先在账户充值几十元，每月定期公示患者名单和享有的保障额度，所有患者都要进行线下人工调查走访真实性，类似于保险调查；当成员无异议后，再按比例进行全员分摊。大病互助与一些大公司职工互助类似，从不过是将范围扩大到社会公众自愿加入。

直到现在一直有很多人，一直吐槽、批评互助平台的各种问题，但从头至尾我从未对它们失去信任：人人为我，我为人人，虽然中间很多互助平台都退出了，但我相信它们都曾经努力过。

我由衷地感谢这些互助平台，7年了，每人每家大概分摊了1000多元，每年平均只需一、二百元的费用，可以在遇到问题时获得十多万元的赔偿。而拥有相同保额的保障，如果选择保险，可能需要多付10倍、甚至20倍的费用。

如果没有互助平台，我相信在7年前，我不可能为十几位亲人购买同等保额的保险产品，因为每人每年可能要花大几千到上万元。

## 9条买保险避坑指南

### 1、保障优先~让资金杠杆最大化

+ 保险，首先考虑保障，花最少钱得最大保障，即：资金杠杆最大化，任何与冲突的都要让路。

+ 尽量只买【消费型保险】，不买任何有理财分红或持有到期返本的~这类以获取投资收益的保险。凡是以投资赚钱为卖点的保险，都值得你警惕。很多保险产品为了满足中国人“既要又要”心理，设计成大而全：投资分红、到期返本、终身保障、保单抵押贷款等统统都加上，结果啥功能都有，但啥也干不好。

+ 只买消费险而省下的钱，每月定投`ETF`宽指数基金，持有10年、20年、40年的长期收益，99%概率远超过现在保险仅有的3%年化收益。假设股市年收益率与国家`GPT`增长率差不多，为年化6%水平，可以用【资金翻倍72法则】速算一下：“72”法则就是以1%的复利计息，72年后本金会变成原来1倍。2%复利就是36年翻1倍，用72除以年化回报率得出的数据，大概就是资金翻倍的大概年限。`72/3=24年`翻一倍，`72/6=12年`翻一倍。

+ 保险本身是反人性的，你既不希望生病，但不生病出险，是不是钱白花了？好纠结、好心塞。如果过不了这心理门槛，你一生将因买保险而煎熬。请尝试以下几个角度重新想一想：

1）买保险，可以为个人提供心理上的安慰。减轻对未知风险的担忧，知道自己拥有一份保险可以帮助建立信心，减轻生活的不确定性，提供身心健康均衡，心理健康与身体健康同样重要，去寺庙上香捐款是不是也是同样道理。

2）买保险，其实也是变相的有偿慈善。在许多国家，捐款可以享受免税或减税的待遇，这是为了鼓励人们支持慈善事业和社会公益活动。你买了保险最后没出险，相当于把款捐给了社会中生病的人，也是一种慈善和公益，侠之大者为国为民，现在国家在出台各类保费免税的政策不也是这个思路么。

3）买保险，是为整个社会的风险共担，利他利己，有助于维持社会的稳定性，让更多的人能够在需要时得到帮助。在古代富人经常修桥铺路，真的是慈善就得一个好名声，这不也是缓和与中下层人民的关系一种方式么，就你天天喝酒吃肉，我们吃糠咽菜？不做这些慈善，你说富人走在路上怕不怕？近5年来中国医疗卫生总费用中政府财政支出占比在27%-30%，而且逐年还在提升，这是国家给人民一个托底保障。你也一定看过这样的电影：孩子生病了，没钱治病，父亲赚钱，走上各种违法犯罪的道路。如果社会没有保险，压力都给政府么？谁的身边没有几个得病的亲友邻里，没有国家医保、保险这些保障，是不是很多病人和家庭都会走极端，会对你生活产生直接危害。

4）买保险，本质上是人与人之间的互助行为：我为人人，人人为我。看过《流浪地球2》电影的朋友们，相信对李雪健老师所饰演的周喆在国际舞台上那震撼人心的演讲留下深刻印象。他以一根距今已有1.5万年的人类股骨为例，生动地阐释了互助团结的真谛。在那个时代，人类大腿骨折简直等同于死亡的宣判。在野外，人们面临冻死、饿死、或被野兽吞噬的威胁。然而，考古发现却揭示了一个不可思议的奇迹——这根大腿骨竟然愈合了。这一发现象征着在那个年代，有人为墓主遮风挡雨，有人为他治愈病痛，有人为他坚定守护，最终共同创造了这个生命的奇迹。

刚开始买保险、加互助，10年以来，也一直在问自己，是不是钱白花了的问题，虽说上面这些内容有点自我催眠，但如果结果是好的，又未尝不可？

### 2、购买渠道---尽量在`微保`、`蚂蚁保`买

+ 🛰️的`微保`、支付宝的`蚂蚁保`是性价比较高、种类较多的选择。价格方面，相同保障的两家差异较小，每家都提供全面的种类选择。

+ 买大公司的保险，还是小公司的？两者差别不大，保险公司受国家监管，倒闭了还会指定其它保险公司接管，小公司为了拉客，反而更有性价比；大公司线下销售团队成熟，要留更多利润空间给团队。

+ 尽量避免通过银行网点、自媒体、熟人等途径购买保险，同时不推荐购买香港的保险，除非你对保险有足够的了解。这些渠道销售的保险，在前几年的现金价值往往远低于已交的保费，甚至只有50%。换言之，如果要退保，只能返还一半的保费，因为你支付的大部分保费被用于支付业务员的佣金和运营成本。当然，并不是说业务员不应该赚钱，他们也需要通过工作来维持生计，不能只是出于热情而从事工作。

现在，保险销售模式实际上有点类似于之前的“以药养医”模式，医生开越多的药，收入就越高。业务员是保险公司的一部分，出于利益的考虑，他们倾向于推销价格高、佣金高的保险产品。至于这些产品是否适合客户的经济水平，则需要看业务员的良心道德了。保险销售人员从前些900万，到现在不到300万人持证，从业难度的增加，你能相信良心道德？还不是抓住一个客户往死了薅。

### 3、交费方式---首选月交、年交

首选月交，而不是选择年交或一次性趸交。

现在大多是🛰️、支付宝、银行卡自动扣费，也很方便。

月交这有助于最大化现金杠杆，减小现金流支出。

支付宝里的保险大多月交、年交，有的年交保险价格会优惠7%，也可考虑一下，毕竟省不少钱。

有一些重大疾病险出险后可申请免交后期保费，万一出险可以省掉一大笔保费。

此外，建议开通次年自动续费，以避免因忘记交费而导致保单失效的情况。

### 4、医保---至少要有，否则买商业险会贵很多

+ 职工医保、居民医保、新农合三者中，至少要有其中一种，否则买商业险（医疗险）的价格将更昂贵。

+ 即使在大城市打工，公司没有给交的，也要在老家交新农合或居民医保。

+ 父母是农村的，每年也要给交400元新农合，各地政府其实都已为每人提供上千元的财政补贴了。现在网上很质疑新农合年年涨的水帖，更多为了博眼球薅流量。

+ 如果当地有【`城市惠民保`】，每年100多元的费用也是必须要加入的。

+ 医保卡绝对不外借，别人的就诊记录可能成为保险公司拒赔你的理由。

### 5、意外险---价格便宜，一定要买

+ 意外险、家庭财险每年的费用也相对较低，只有几百元。

+ 对于经常骑电动车的人，非机动骑行险是必备的。

+ 同样，常坐私家车的人应购买带有私家车保障的意外险。

+ 如果经常参与体育活动，购买运动险每天只需几毛钱，是一项安心的投资。

+ 对于常坐飞机的人，不需要每次都购买30元的飞机险，因为购买的意外险可能已经包含了各类交通工具的保障。

+ 对于租房或有房屋出租的人，购买租客险或房东险是必要的，以防火灾或电器故障等重大事故。

+ 不要过度超额买保险，事出反常必有妖，害人之心不可有，防人之心不可无，你应该听过×亲骗保的新闻，事情做过头，你想不到的祸事就来了。保险买好了，可以保命；买不好就可能挂了。不要认为保险公司好骗，买N手豪车，再买高额车险，闯毁骗保的，保险公与被骗怕了，防范心很强，以现在刑侦技术，基本逃不过调查。

+ 意外险只是保障，当然最重要提预防意外：家中用电、用气安全；不走楼底防高空抛物；路上行走不看手机；注意交通安全、学习急救常识等等。

### 6、医疗险---补充医保，加固保障

+ 购买保险要真实说明健康状况，隐瞒病情带病投保的保单，保险公司可以撤销合同，打官司你也输。

+ 两年不可抗辩条款：《保险法》中是这样规定的：“自合同成立之日起 超过二年的，保险人不得解除合同；发生保险事故时，保险人应当承担赔偿或者给付保险金的责任。”甚至有不少投保人会想：带病投保的事，只要瞒住2年就好了，以后出事了，保险公司还是会赔的。两年不可抗辩条款是投保人的“免死金牌”吗？当然不是。不然保险公司得哭晕在厕所。而至于为什么“两年不可抗辩条款”会给网友们留下一个“免死金牌”的印象，大概是因为：误导或过度渲染；中国保险宽进严出的特点；实际的判例中，法官会更多倾向于保护被保险人的权益，保险公司败多胜少。当然了，法官也不会姑息故意隐瞒、骗保的行为。

+ 有病不是不能买，有的保险是允许小病加入的，但是要加钱，个性化定价，购买时要和保险公司说明情况，与经纪人和核保员沟通的内容要截图、录音、视频存证，以及医院检查资料都存到你的个人云盘里，以防丢失。有太多这样案例了，买时没问题，理赔时各种拒赔借口一大堆。

+ 医疗险、重疾险和寿险等需要满足健康条件方能购买，因此建议在年轻健康时购买，一旦罹患重大疾病，购买将变得困难且价格会大幅上涨。不推荐购买1年期的短期医疗险，建议选择长期医疗险，并尽可能购买保证续保20年的产品。

+ 有医保了，为什么还要买医疗险？商业医疗是补充层，可以加固保障；医保有起付线、封顶线；只有在医保定点医院就医，医保才会予以报销。我国医保有“三大目录”，主要指《基本医疗保险药品目录》、《基本医疗保险服务设施目录》和《基本医疗保险诊疗项目目录》，三大目录明确了医保的保障范围，只有在目录内的医疗保障才可以享受医保报销，医疗险扩大了保障范围，覆盖免赔额，提高报销比例，基本都可以实现经社保后100%报销，可以弥补医保的报销缺口。

### 7、重疾险---补偿因病失业后的收入损失

+ 重疾险出险了，是按保额一次性给保额钱的，不像医保、医疗险，是按实际花费比例报销的。这也意味着其价格更高。

+ 不建议购买1年期的短期重疾险，实际保障期限较短，性价比较低。

+ 建议购买保额相当于2年家庭收入的重疾险，太高经济压力过大，太少了钱不够治病的。

+ 不建议购买终身险，可考虑购买至60岁退休，考虑到未来国家退休可能推迟的因素，也可以考虑购买至65岁。终身重疾险的性价比较低，大部分保费其实花在了生命最后几年的保障，因为重大疾病的发病率随年龄呈指数增长。30岁时发病率是0.1，可能70岁就成了0.7了，理论70岁那年保费=30岁保费的7倍。退休后持有重疾险意义不大，年轻时重疾治疗还能有体力抗过来，老了得个感冒都可能要命，更何况重疾了。

+ 对于2021年2月1日重疾新规前购买的保单，尽量不要退保，因为在新规中，高发病率的疾病如甲状腺癌只被视为轻疾，最多只能获得30%的赔付。甲状腺癌一般花费不超过3万，新规前买的重疾保50万，得了那就能赔50万。

+ 现在很多重疾，是可轻、中、重多次赔付的，也可以考虑这类保险，毕竟现在医疗发达，很多重疾也是可治愈的，这样多次赔付就很重要。

+ 重疾种类，是不是越多越好，保到100种、150种？不是，重疾发病率主要还是前10类，后面的概率就很低了，国家规定的重疾是25类，能保30或50种就可以覆盖99.9%了。100种、150种更多是宣传的噱头和加价的由头。

+ 不购买返保费或返保额的重疾险，其价格一般要涨很多。像之前我买的纯消费型重疾：40类重疾，保到60岁，保额75万，30岁开始投，投保20年，月交320元；同类保障返保费的，价格差不多要月500多，费用涨了50%以上。

+ 买保险优先考虑为家庭主要经济支柱投保，其次是子女，最后是老人。

### 8、寿险---只买保到退休的定期寿险就行

+ 寿险是为了确保家庭劳动支柱意外身故时，其家庭能够得到一笔经济赔偿。这笔赔偿金可以用于支付房贷、子女教育费用、日常生活支出等，够维持相对稳定的生活水平。
