
# Web版、API版区别

> 来源：[https://xuqiwei1986.feishu.cn/docx/MNypdlqEmovasPxt0oXcnFkHnPd](https://xuqiwei1986.feishu.cn/docx/MNypdlqEmovasPxt0oXcnFkHnPd)

|  | Chat GPT的Web版和API版区别 |
| --- | --- |
| Web版 | Web版是通过网页直接访问，就像我们们平常上网购物一样，只需要在浏览器输入网址 `ai.com`（或 `chat.openai.com/`） 就可以与ChatGPT进行交互了 |
| API版 | API 版需要通过官方 API 工具（`https://platform.openai.com/playground`）或编程语言进行访问，构建自己的应用，可实现功能定制，但是自己构建应用需要一些编程基础，对于没有编程经验的人来说比较困难。 |
