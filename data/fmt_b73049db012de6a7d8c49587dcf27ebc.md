## 宠物诊所的logo设计

假设你的朋友开了一家宠物诊所,这时找上你,请你帮忙设计一款logo。有了Midjourney,这根本就不成问题。接下来,我们带领大家一起为这家宠物诊所设计logo。

首先,在`ZelinAI`输入logo设计、宠物店诊所的关键词,然后翻译成英文。

得到关键词的英文表达后,就来看看Midjourney会带给我们什么样的惊喜吧!

![](img/6932ee461850a4c6732e19fee702503f.png)

在这里,其实有个小技巧。开始时,我们尽量不要限制生成范围,让Midjourney生成一个大致的图像。然后根据所生成的图像,结合我们的需求,进行范围限制来优化我们的图像

图像已经生成了,看起来效果不错,生成过程也很简单。但是你有没有发现,生成的logo里全是狗狗?这时候,如果宠物诊所的老板提出想要猫而不想要狗,该怎么办?好吧,我们来给他改改看。我们把 cat 这个词放入我们的提示语中。那么,我们的提示语就是:`logo设计,宠物诊所,猫`。

![](img/0cd0beec7a6b64ae018c84e48814ed6b.png)

再来看,我们的logo已经全是猫了。然而,宠物诊所的老板还不满意,觉得这个图像太复杂,喜欢简单一点的风格。那就满足他的要求吧!在设计logo时,我们再加两个限定词:简约和矢量。对矢量不太理解的同学可以去百度搜索了解一下。

最后,我们的提示语是:`logo设计,宠物诊所,猫,简约,矢量`。翻译成英文就是：`Logo design, pet clinic, cat, simple, vector`。最后,我们来看看生成的效果如何。

![](img/d57105bcb876114a2e2cd1121f75c4d4.png)

到这里,想必大家都已学会利用AI生成一些简单的logo。

设计一款logo,重要的不在于工具,而在于对设计的理解,丰富的想象力,以及我们的审美能力。

## 常见的Logo类型

看到这里,相信大家都已能设计简单的logo。接下来,让我为大家介绍一些logo的基础知识。常见的logo类型有品牌logo、`APP` logo等。在这里,我们主要讲解品牌logo和`APP` logo。

品牌logo是大企业的形象代表,例如苹果的logo和华为的logo。品牌logo一般分为两类:图形logo和字母logo。

**苹果的图形logo**

![](img/1d822d345d76dc73a9d4f08233210ae9.png)

**特斯拉的字母logo**

![](img/a127d7545d5820cb2db2de352e8b1d11.png)

### 图形logo:

1. Logo类型:图形logo
2. 图形描述:logo中的图形代表什么,例如苹果
3. 风格:
   - 大多采用扁平化设计:`flat`
   - 多为矢量图:`vector`
   - 简洁:`simple`

让我们用这个条件来设计一个logo

```
flat,graphic logo of apple, simple, vector, gold
```

![](img/bddb9f4a7cae5939cb6a611c09ed99f3.png)

### 字母LOGO

1、类型: `lettermark`
2、logo图形描述：纯字母，可设置字体样式
3、风格： 矢量、简洁(`simple minimal`)

我们来画个字母H的logo看看

```
letter H logo,lettermark,vector, simple
```

![](img/e1c77d11e217b865b60ae746d17c2244.png)

效果看起来还算不错

### APP LOGO

1、logo类型：`mobile app logo`
2、logo图形描述
   - `iOS` 的都是圆角矩形：`squared with round edges`
   - Logo 图形描述，比如 `an icon for an pet app`
3、风格扁平化: `flag`

我们用以上特性看看设计的logo效果如何

```
flat mobile app logo,squared with round edges,an icon for an pet app
```

![](img/edadf07a7a8c29567367a6d155b7dbf0.png)

## 进阶技巧

### 设置艺术家风格

Midjourney有个非常强大的功能,那就是可以设置模仿某位`APP`设计大师的风格来设计logo。目前`V5`版本支持模仿100多位设计大师的风格。其中,Paul Rand和Saul Bass是Midjourney支持的两位设计师。我们以他们为例,体验一下这项功能。使用方法很简单,只需在提示语后添加by Paul Rand或by Saul Bass即可。

```
flat mobile app logo,squared with round edges,an icon for an pet app, by Paul Rand
```

来看看Paul Rand风格的logo生成效果如何

![](img/3516136fa9de364189f0972c21245744.png)

再来看看Saul Bass的风格如何

```
flat mobile app logo,squared with round edges,an icon for an pet app, by Saul Bass
```

![](img/73f5cdf5c33babdd486d0ecd9e2b4dad.png)

### 去掉不需要的元素

以最开始宠物诊所的logo为例

```
Logo design, pet clinic, cat, simple, vector
```

![](img/878c9c7379fd99af5ac46ba6de17bc57.png)

从生成的logo看，都是有英文的，那如果我们不需要英文呢？我们就需要用到`No`参数了

```
Logo design, pet clinic, cat, simple, vector --no realistic color text
```

![](img/cd6a98933f2cedd6a5c816a9ebc4edcc.png)

最终生成的logo已经没有文字了

设计一款logo,最终还是需要有创意。比如,要为一个企业设计logo,应该采用什么样的表达方式才最为恰当?这需要我们有丰富的想象力。那么,如果没有丰富的想象力怎么办?我们可以使用`ChatGPT`或`Zelina`帮助我们解决这个问题
