## 即刻｜编者（Leon）部分摘录

+   **痛则思变**。学习从来不会使人进步，痛苦才会。
+   一诺千金的另一面，是有多少值千金的事，值得一诺。
+   有时候不会排优先级，是因为选择太多了。先把能放弃的放弃掉，剩下东西少了，重点就出来了。
+   **走得慢才能走得快**。紧迫感固然重，但有时紧迫感太强，急于求成，结果还需要回头来弥补。有时候多花点时间想想「你打算怎么做？」，然后再去做，这样反而会比来回修改更快。
+   情绪化的内容好些，但事实性的案例和逻辑需要深思熟虑，不是凭借感觉就能构建出来的。并且大话题总是容易空洞，是因为没有那么多细节填充，缩小范围后就能切入的更加具体，而具体的东西，才有生命力。
+   设计功能的迁移（或者升级），远比设计功能本身更费精力。
+   删除能让有价值的东西显露出来，不断新增，只会让注意力被稀释。
+   **将创造过程与改进分开**。你不能同时写作和编辑，或者雕刻和润色，或者制作和分析。当你发明时，不要选择。当你画草图时，不要检查。当你写初稿时，不要反思。一开始，创造者的思想必须从审判中释放出来。
+   有两种态度对待恐惧：认识到自己有能力处理它，保持恐惧并努力躲避。后者会把生活变成斗争，带来竞争、妒忌和恐惧，还会让周围的关系紧张。前者则是抽离，允许痛苦通过，消失，而不是任由他们被埋藏在黑暗的角落。
+   一种不同的视角：或许新东西是一种陷阱，多数事情可能就是漫长的，需要我们不断修补，才能最终看到结果。
+   **突然意识到，生命快要走完在统计学意义上的一半**，许多事一辈子根本不够用。那就和时间搏斗吧，至少留下疤痕。
+   每个人能留在世上的东西其实不多，或多或少、或长或短，都是一段故事，而已。一生很长，但故事却很短。只是，别活成别人的故事；也别，总把自己当做主角。因为，故事的结局，都不是由自己撰写。盖棺，方才有定论。
+   设计新人引导有感。工具类产品很像开放世界游戏，你永远不知道用户会怎么触发任务。但新手引导又极其重要，核心理念传达成败于此。通常有两种做法，一种是强制一套新人任务先做完，义务为先，用户烦不烦、会不会，不在考虑范畴；另一种是塞尔达式设计，利用好奇心和直觉，尽可能触发到重要任务。Notion 的许多引导就做的很安静。
+   关于精力管理。使用过度和使用不足都会削弱精力，必须不时更新。
+   越忙碌越会高看自己。逃避真相会消耗大量精力。
+   避免通过看电视等方式来恢复情绪。相反，来源越丰富，越有内涵，我们恢复的就越好。
+   做一件事越久越能理解，耐心与节制的意义和难处。
+   人们很容易看到别人的错误，但早上看到一棵树的时候想到。树的这一生，有什么错误吗？
+   欲望不仅仅会带来求之不得的痛苦，还会有反噬自身的代价。因为欲望本身就是超越自身能力的产物，强行得到之后，带来的是基石上的裂痕。所谓幸福，可能就是欲望比能力低一分。
+   **把自己摆对位置很重要**，别被人称兄道弟就瞎感动自己，降本增效时没人在乎。（裁员季有感）
+   只有在能全然拥有时，放弃才有真正的力量。
+   「插一句飞哥的：这个时代古典产品经理到底能不能行，这课题真的是未解之谜。」
+   多数时候，第一个想法都是别人的，得慢下来之后，才能慢慢涌现自己的想法。
+   理解自己，但动机很容易变成改变自己。这样其实容易陷入焦虑和挫败。
+   《**长安三万里**》有感：没有什么完美的结局，历史就是历史，只不过最后每个人都释然了，然后在历史上努力留下一丁点注脚。路漫漫，且慢慢行。
+   一以贯之的行为，就是在做品牌。
+   **关于「美化的智商：美智行为」，**除了识别，更要警惕自己迷恋上被美化过后的自己。
+   就像没有一把「普通」的锤子，世界上也没有一个「普通」的人。
+   学什么都想学好，在相当长的生命里，都是一种积极的叙述。但凡是皆有副作用，因为这也是缺乏优先级和对自己能力边界认知不清晰的表现。在少数领域学好，其他相关领域学的够用，或许更实际一些。
+   让自己想做一件事，应该避免立即去做那件事。这就像饥饿是最好的调味料那样，空置一段时间，动力就会更足。
+   如果你害怕锤子，可能自己就是那枚钉子（关于 AI 是否会替代自己）。——塔勒布
+   经常写东西（尤其是公开的），会让自己有个幻觉，以为自己写过的东西，自己都「懂了」、「实践过了」，然后就开始追逐下一个概念、方法。充其量只是知晓某些名词，成为一个“懂王”而已。
+   并不是说新方法和新想法不好，而是它们出现的时机不好。总是敞开大门，准备迎接激进的改变，只会招来混乱和猜测。你应该自信的把那扇门关上，接受这个事实：如果火车已经离开了站台，「更好的想法」才姗姗来迟，那它或许并没好到不可或缺的程度。如果它真的超级棒，那还可以搭下一班车。
+   许多产品的迭代原因，并不是发现了新需求，而是为了绩效评估时显得自己的工作量足够。
+   **着急想解决问题，是最大的问题**。
+   两个钩子。1. 发现自己想要「赶紧」完成什么事时，就拖延一下，先把自己手头的工作做好。2. 把一直没有做的事情开个小头，做做准备工作，做下规划。
+   认为碰到问题时，就必须采取行动，这种想法纯属迷信。
+   财富来源于规模，规模来源于自动化。
+   过去埋藏在地下，挖出来时是煤炭，是你今天的炉火。
+   **喜欢旧物，更多**是因为被时间和自然改造成，独一无二的模样。
+   势比人强，敬畏规律。
+   自恋是产品最大的敌人。
+   对于一个 App 来说，其品质的很大一个因素在于速度，无论是启动、加载还是响应。而很多时候，这件事并不在产品经理的优先级中。
+   飞哥：真正稀缺的不是知识，而是实践的机会。
+   Lightory：有点缺陷又何妨？降低点迭代自己的速度。
+   心有猛虎，细嗅蔷薇。欲望像猛虎，我们在这个世界上产生行动的理由，而细嗅蔷薇，则是驯服其对结果的不执，不去占有，仅仅与其在当下在一起而已。
+   **盛世十年，其实并不一定轮到自己，**以为自己在逆境会更好。衰退十年，自己也并非有多少优势。说到底，大环境对自己有影响，但有限。关键是认清自己，从小环境改造起。
+   “书读的越少，读过的书对你伤害就越大。” 许多事情也是如此，比如到底什么是改变世界的事情，经历过越多，定义越不同。
+   面对真实的自己，更难。许多时候会变成，面对理想中的自己。
+   觉察就是注意力带宽没有被占满，监督进程始终都在。
+   任何一句话，都是无数想法的叠加，所以千言万语永远无法汇成一句话，而是尽在不言中。
+   提前把时间规划好，大量 Say no，焦虑感会下降非常多。
+   恐惧源自执着与占有，逃避不是解药。
+   新冠给人的教训之一：就是作为普通人，更应该尊重概率，避免侥幸。
+   一个有趣的观点：**哲学是人类灵魂的 API 文档**。
+   成甲：尝试用价值观来规划时间。
+   **我本可以，我也可以**。一个是遗憾，另一个是妄念。一个是低估，另一个是高估。
+   凯恩斯说，世事之难，在于革故，而非鼎新。对于有技术崇拜的产品经理来说，很有警示的作用，革故大于鼎新。
+   拥有更多 → 拥有一切 → 一切的价值平等 → 毫无价值。当一切都必要（健康的身体，巨大的财富，幸福的生活，丰富的体验等等），一切就都不重要了。
+   好奇一个问题：2022 年，你因为害怕，没有做什么？有很多人是：没有敢于开始一段关系，没有敢于结束一段关系。
+   **万事相互效力，万事皆有代价**。 孟岩：所有命运赠送的礼物，早已在暗中标好了价格。
+   人们总是容易意识到自己的挣扎，却对别人的挣扎视而不见。
+   编辑能力和写作能力是完全不同的能力。前者需要的是审美，后者需要的是思辨。只不过人容易高估自己的能力，看的多了，就觉得「我也可以」。
+   flomo 最初的起源：输入框是最好的收藏夹。
+   输出不是写文章，而是对现实世界产生实际影响。
