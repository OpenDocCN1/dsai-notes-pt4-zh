## Podcast｜编者（Leon）主观摘录

+   你想得到什么，能付出什么。

+   产品沉思录是靠问题驱动的。提问的机器。

+   写作可以是艺术创作问题，也可以是工程性问题。

+   你只有在一件事上乐此不疲，才能超过别人。

+   打造个人知识体系的循环（提问-收集 feedback-再沉淀）

+   你的问题是什么，缺什么补什么。

+   古典产品经理，热爱可抵岁月漫长。

+   理性：洞察（感性洞察理性分析）、项目、商业、成本、合规

+   感性：真心热爱产品，理性的好奇心

+   答案永远在现场，警惕高级用户陷阱；「信息不对称」

+   用户感知不到的东西是没有价值的。

+   成本意识和商业化的补充

+   产品经理同时在设计两个产品。

+   第一个是在设计的产品本身；

+   第二个是在思考设计一套让产品运营的系统（经营体系）

+   第一次创业「做产品」，第二次创业「做增长」；

+   flomo 其实是一家内容品牌产品；单纯的功能已经没那么有差异化了，需要一些 story，需要一些意义。

+   什么是知识管理？

+   能够改变自己行为的信息才是知识；

+   以我为主，增援未来；

+   还是要记录过程，少记录当下的“总结”。

+   标签生来不平等。真正想说的是：

1.  多少并不是衡量价值的唯一标准；
2.  知识管理适合自己最重要，没必要对他人的东西评头论足

+   用户心理一般只有两种，“好和不好”。他们不会关注你付出了多少努力，做的有多好，也不关注某些专家的言论。

+   “用心做和做正确的事情，其实是两个不同含义。”

+   第一，以顾客的视角出发，以顾客作为唯一标准。把顾客当做唯一标准才是最重要的，不要以竞品为标准。

+   第二，了解顾客的心理。

+   了解更多东西并不会让你变得更聪明 —— 相反，是你运用你所知道的东西的方式，让你变得更聪明。

+   做 flomo 这么久，最糟糕的建议是分类。我们对分类有一个误区，认为分类是刚性的。我们认为是分类是结构的，像图书馆一样的，像金字塔一样的，像建筑一样的。而实际上分类应该是像花园一样，像植物一样，是慢慢生长出来的。

+   你能不能冒着风险去尝试做一些你自己没有做过的事情？

+   一般为个人心理设限；鼓励你自己去做对但是没有做过的事情。比如当你遇到不公平的事情，能否坚持自己去做对的事情。

+   多去了解世界，试着突破更多可能。男性和女性的差别，是教出来的，不是天生的，是自我实现的预期。

+   欲望是个奇怪的物种，一个寄生虫，会寄生在所有你没有得到的东西上，一旦得到，这个寄生虫就会跑到下一个地方。

+   马克思《巴黎手稿》 ，我像一个异化的机器的零件，拼命在把我的生命转化为商品，过程中我得到工资，用工资拼命去买我想要的东西。因为欲望的提升会导致我更努力的工作，更像是一个零件。

+   永远不要以公司为荣，让公司以你为荣，否则你是没有价值的。

+   一辈子的作品数量是有限的。

+   读书，不一定要学到知识，但是有启发，就可以了。

+   一个时代，只看一个作者，或者一件事情，可能得到的视角是比较窄的。

+   拆书，更多是拆书人自己的观点，而且文章深度取决于拆书人。

+   企业家精神。目标先做 MVP，不要经常宏观思考太多问题。

+   不断突破、突破，学习学习。

+   向内看，不要向外看。你是否在不断成长，不断准备下一次机会。

+   不要把自己认为是一个电工，要做项目的核心工程师。感性和理性两种思维方式，大家更多用的是感性思维。

+   区分哪些是资产，哪些是消耗。

+   食色 APP（你自己进入一个泥潭里，不自知，而且还说自己可以的。无知者无畏。你不知道你不知道。)

+   第一个坑，着急变现，而不是做活跃和留存，或者规模；

+   第二个坑，把融资的💰存着，而不是做规模；

+   在自己非常不擅长的领域跟所有人对战。做餐饮。

+   为了创业而创业，不是要做什么产品。把路径变成了目的。创业是路径，而不是目的。

+   我们其实选择的是自己一条最能忍受的路，而不是我们最喜欢的路。如果在一件事情上，你比别人的耐受度很高，大概率是你喜欢的，否则你不可能耐着住的。

+   人最容易骗的人是自己，人最难认知的也是自己。

+   前段时间和白光探讨说，当年做过摆摆书架、布丁动画（白光）等等。这些都是很喜欢的东西，但是我不敢去追求它。

+   就是因为骗自己说，这个东西太小众了，挣不到钱，跟着大多数人的想法，然后去做。而忽略了这些东西才是最有独特价值的地方。

+   你去追逐流行，永远追不到流行。

+   欲望会让人痛苦。

+   不是说欲望不好，只是说过大的欲望会让人痛苦。

+   会陷在恐惧里，需要做的就是和恐惧共存，而不是去克服。

+   更平静、更具体了一些，而不是惶恐，惶恐未来；然后你会把身边这些小事做好。

+   忽视机制设计带来的后果。比如，社区治理不太可能通过自净化的解决。

+   工具不是越多越好，工具背后的思维方式才是关键

+   「内容营销」不应该是求转化，而应该是如何建立声誉。我们选择一种东西，多半是买了其中的意义。今天的消费塑造我们自己。

+   Eliza 的观点：受美式教育太深。大脑有一个很奇怪的点，很多创作起源于无聊。

+   有时候并不是我们拼不出一个积木，而是我们手里的乐高都不够。有时候我们怕的不是解决问题，而是没有问题。

+   大多数人都是在吸收，没有输出。

+   在工作中，重视自己和他人的「过程知识」。德鲁克的一个很重要的观点，书上没有知识。

+   如果你没有观点，那你就不值得被关注。

+   针对一个小的功能，在一段时间内，只研究这一个问题，研究透彻。（保证思考的尖锐性）

+   如果不缺钱的话，你的余生想要做什么？
