
# Gradio 网页界面生成视频

这是一个简单的 `Gradio` 网络应用程序，您可以直接在浏览器中使用 `CogVideoX-5B` 模型生成视频。与我们的 Huggingface Space 类似，您可以使用该脚本运行一个简单的网络应用程序来生成视频。


### 导入和设置

检查 GPU 是否可用（`"cuda"`），否则会退回到使用 CPU（`"cpu"`）。下载 Real-ESRGAN 模型用于升频，下载 RIFE 模型用于使用 Hugging Face Hub 进行帧插值。使用预训练模型初始化 `CogVideoXPipeline`，为其配置调度程序。然后将模型的张量存储器格式转换为 `channels_last`，并应用 PyTorch 的 `torch.compile` 优化变压器组件，以获得更好的性能。最后，从各自的文件中加载缩放模型和帧插值模型，并且指定初始 `prompt`。

### 转换 Prompt

输入用户的基本 `Prompt`，使用 `glm-4-0520` 将其转换为适合视频生成的更详细描述性格式。根据预定义的 `prompt` 以写好的几轮对话的例子，模型最终可以给出更加适合视频生成的 `prompt`。

### 推理

使用 `CogVideoXPipeline` 根据文本提示生成视频。如果没有提供种子（`-1`），则会生成一个介于 `0` 和 `255` 之间的随机种子。如果再次使用相同的种子，这将确保生成的视频具有可重复性。

参数：

`prompt`： 描述视频内容的文本输入，也就是 `prompt`。

`num_inference_steps`： 模型在推理过程中的步数。步骤越多，输出质量越高，但也需要更多的计算时间。

`guidance_scale`： 用于控制模型输出在多大程度上遵循所提供的提示的系数。较高的值通常会产生更符合提示的结果。

`seed`：用于生成随机数的种子。如果为 `-1`，则使用随机种子。

`progress`（optional）： 用于在推理过程中跟踪进度，与 `Gradio` 的进度跟踪工具配合使用。

Pipeline 调用参数：
