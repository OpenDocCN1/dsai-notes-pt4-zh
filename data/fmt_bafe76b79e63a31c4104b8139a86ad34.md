### MCP介绍

[蓝耘元生代](https://mcp.lanyun.net/#/home)[MCP](https://mcp.lanyun.net/#/home)[广场：开启服务调用新旅程](https://mcp.lanyun.net/#/home)

![](img/afb0e0ef9f47d1b75db412a9474a17cd.png)

MCP（Model Context Protocol，模型上下文协议），2024年11月底，由 Anthropic 推出的一种开放标准，旨在统一大模型与外部数据源和工具之间的通信协议。MCP 的主要目的在于解决当前 AI 模型因数据孤岛限制而无法充分发挥潜力的难题，MCP 使得 AI 应用能够安全地访问和操作本地及远程数据，为 AI 应用提供了连接万物的接口。

作为本次活动的联合主办方，蓝耘将为参与者提供强大的技术支持和平台资源，帮助开发者和创作者更好地、部署 MCP 服务。凭借其在 MCP 领域的技术优势和丰富的应用场景支持，蓝耘平台能够为活动参与者提供全流程技术保障，推动 MCP 服务通用化进程。

## 三、活动内容

### 大赛介绍

> 蓝耘科技发起并赞助本次挑战赛，核心在于解决 AI 对接实际应用的瓶颈，推动 MCP 技术发展与通信标准化。大赛旨在通过挖掘三类 MCP 服务来达成目标：

1. 通用型服务：寻找具有广泛适用性的基础工具（如数据处理、可视化、文件管理、信息检索），支撑跨行业、跨场景的共性需求。
2. 领域型服务：激发针对特定行业（如开发、金融、营销）的专业 `MCPServer` 开发，精准破解垂直领域痛点。
3. 扩展型服务：鼓励探索 MCP 协议的前沿应用（尤其在 AI 领域）和协议功能扩展（如支持新数据类型或交互模式），开拓技术边界。

#### 具体要求

+ 保证作品原创性，禁止抄袭
+ 不得通过作弊手段影响数据统计，遵守法律法规与平台用户协议
+ 主办方享有作品使用、展示、商业宣传等权益
+ 如基于开源项目开发需严格遵守开源协议要求

### 参赛规则与路径

#### 参赛步骤

**第一步：报名初筛**

参赛者登入蓝耘 MCP 广场 https://mcp.lanyun.net/#/home，点击"上传 MCP"提交项目及 MCP 调用演示视频（支持从 GitHub 仓库快速上传）。

蓝耘组织评审团对项目进行初筛，确定通过成员名单。

**第二步：复赛阶段**

评审团对初筛通过的项目进行评审，包括代码审查、功能测试及演示性能评估，评选出进入决赛的成员。

决赛入围成员需在8月25日前，通过“蓝耘杯”MCP 开发挑战赛官方群，提交该 MCP 在实际应用场景/智能体中应用的案例。

**第三步：决赛阶段**

线上线下结合评审，决赛入围成员进行项目展示和答辩，评审团对其打分和排名，最终确定获奖项目，并公布获奖名单和颁发奖金及证书。

**第四步：结果公布**

+ 等待专家评审
+ 关注获奖公示
+ 领取相应奖励
