
# 行政部/综合管理部/办公室 OpenClaw 应用场景及对应Skills分析报告

## 一、部门核心定位

行政部/综合管理部/办公室（统称“综合行政部门”）是企业统筹协调、后勤保障、制度落地、服务支撑的核心职能部门，直接向高层管理层负责，承担着行政统筹、后勤服务、会议管理、公文处理、制度建设、固定资产管理、企业文化落地、跨部门协同等核心职能。三个部门职能协同互补、各有侧重：行政部聚焦日常行政事务、后勤保障与办公管理，综合管理部聚焦企业综合统筹、制度体系搭建与组织协同，办公室聚焦高层服务、会议统筹与公文流转，共同构成企业高效运转的“中枢神经”。该部门工作兼具强服务性、高频事务性、强协同性与兜底性，核心特点是“事务杂、统筹多、服务广、细节严”，主要负责后勤保障、行政统筹、公文处理等工作，是保障企业日常运转、提升组织协同效率、营造良好办公环境的核心支撑部门，也是OpenClaw落地适配的重点综合服务类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按行政部/综合管理部/办公室日常工作高频度、刚需度排序，兼顾三个部门职能共性，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合综合行政服务与统筹协调需求，适配后勤保障、公文处理等高频痛点，无需额外定制开发，零基础可快速落地，兼顾专业性、实用性与高效性，适配三个部门的日常工作场景。

### （一）行政统筹与公文处理类（核心职能场景）

**场景核心内容**：作为综合行政部门的核心工作，负责企业行政事务统筹、公文流转与文书管理，确保行政工作规范有序，具体包括：

+ 企业公文（通知、通报、请示、报告、函件等）的起草、审核、流转与归档；
+ 行政制度、办公规范、管理细则的起草、完善与宣贯；
+ 行政事务统筹协调、跨部门沟通对接、工作指令传达与反馈；
+ 公文台账、行政事务台账建立、更新，文书归档与管理，确保可追溯。

**应用价值**：标准化行政统筹与公文处理流程，快速生成各类公文与制度文件，提升公文流转与行政协调效率，规范文书归档管理，减少人工公文撰写与流程对接耗时，确保行政工作有序推进。

对应OpenClaw Skills：

+ `document-draft`（各类公文、行政制度、办公规范撰写与优化）；
+ `document-circulation`（公文审核、流转、归档与管理）；
+ `administrative-coordination`（行政事务统筹、跨部门沟通对接）；
+ `admin-ledger`（公文台账、行政事务台账建立与更新）。

### （二）后勤保障与办公管理类（核心执行场景）

**场景核心内容**：负责企业后勤服务保障、办公环境管理、办公物资管控，为员工提供良好的办公条件，具体包括：

+ 办公物资（办公用品、耗材、设备）的采购、入库、发放、台账管理；
+ 办公环境维护、卫生管理、办公区域规划与优化；
+ 办公设备（电脑、打印机等）的日常维护、故障对接与报修；
+ 员工后勤服务（餐饮、通勤、福利发放等）的统筹与对接。

**应用价值**：规范后勤保障与办公管理流程，简化办公物资采购与台账管理工作，提升后勤服务效率，优化办公环境，减少人工物资管理与后勤对接耗时，保障员工高效办公。

对应OpenClaw Skills：

+ `office-supplies`（办公物资采购、入库、发放与台账管理）；
+ `office-environment`（办公环境维护、区域规划与优化）；
+ `equipment-maintenance`（办公设备日常维护、故障对接与报修）；
+ `logistics-service`（员工后勤服务统筹、福利发放对接）。

### （三）会议与活动管理类（核心服务场景）

**场景核心内容**：负责企业各类会议、活动的统筹策划、组织执行与复盘，确保会议与活动顺利落地，具体包括：

+ 会议策划、会议通知、会议议程、会议材料的撰写与准备；
+ 会议场地布置、设备调试、参会人员对接、会议记录与纪要撰写；
+ 企业文化活动、员工团建、大型会议（年会、表彰会等）的策划与执行；
+ 会议与活动复盘总结、效果评估、优化建议撰写。

**应用价值**：标准化会议与活动管理流程，快速生成会议与活动相关材料，提升会议与活动组织效率，规范会议记录与复盘流程，减少人工策划与组织耗时，确保会议与活动达到预期效果。

对应OpenClaw Skills：

+ `meeting-planning`（会议策划、议程制定、会议材料撰写）；
+ `meeting-record`（会议记录、会议纪要撰写与归档）；
+ `activity-planning`（企业文化活动、员工团建策划与执行文案撰写）；
+ `activity-review`（会议与活动复盘、效果评估与优化建议撰写）。

### （四）固定资产与资产管理类（核心管控场景）

**场景核心内容**：负责企业固定资产、办公资产的登记、管理、维护与处置，确保资产安全、高效利用，具体包括：

+ 固定资产（办公设备、房产、车辆等）的登记、编号、台账建立与更新；
+ 资产日常维护、盘点、清查，资产使用情况跟踪与管理；
+ 闲置资产、报废资产的处置方案撰写、流程对接与备案；
+ 资产盘点报告、资产使用分析、优化建议撰写。

**应用价值**：规范固定资产与资产管理流程，简化资产登记、盘点与处置工作，提升资产管理效率，确保资产安全、账实相符，减少人工资产盘点与台账整理耗时，优化资产利用效率。

对应OpenClaw Skills：

+ `fixed-asset-registration`（固定资产登记、编号与台账建立）；
+ `asset-management`（资产日常维护、盘点、清查与跟踪）；
+ `asset-disposal`（闲置、报废资产处置方案撰写与流程对接）；
+ `asset-report`（资产盘点报告、使用分析与优化建议撰写）。

### （五）制度建设与合规类（核心保障场景）

**场景核心内容**：负责企业行政管理制度、办公规范的建设、宣贯与落地，确保企业运营规范合规，具体包括：

+ 行政管理制度、办公行为规范、考勤制度等的起草、完善与修订；
+ 制度宣贯材料、培训文案、制度解读手册的撰写与分发；
+ 制度执行情况跟踪、检查，违规行为提醒与纠正；
+ 制度执行效果评估、反馈收集、优化建议撰写。

**应用价值**：标准化制度建设与宣贯流程，快速生成制度相关材料与解读文案，确保制度落地到位、执行规范，减少人工制度起草与宣贯耗时，保障企业行政运营合规有序。

对应OpenClaw Skills：

+ `system-construction`（行政管理制度、办公规范起草与完善）；
+ `system-promotion`（制度宣贯材料、培训文案撰写与分发）；
+ `system-inspection`（制度执行情况跟踪、检查与违规纠正）；
+ `system-evaluation`（制度执行效果评估、优化建议撰写）。

### （六）企业文化与员工关怀类（长期赋能场景）

**场景核心内容**：负责企业文化建设、员工关怀，营造积极向上的企业氛围，提升员工归属感，具体包括：

+ 企业文化理念提炼、文化宣传文案、内部宣传材料的撰写与发布；
+ 员工关怀活动（节日慰问、生日祝福、困难帮扶等）的策划与执行；
+ 企业内部宣传（宣传栏、👸号、内部群）的运营与内容更新；
+ 员工满意度调研、反馈收集，企业文化优化建议撰写。

**应用价值**：标准化企业文化建设与员工关怀流程，快速生成宣传文案与活动方案，提升企业文化传播效率，增强员工归属感与凝聚力，营造和谐积极的企业氛围。

对应OpenClaw Skills：

+ `corporate-culture`（企业文化理念提炼、宣传文案撰写）；
+ `employee-care`（员工关怀活动策划、慰问文案撰写）；
+ `internal-promotion`（企业内部宣传内容更新、宣传材料撰写）；
+ `culture-evaluation`（员工满意度调研、企业文化优化建议撰写）。

### （七）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责综合行政部门各类文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+ 部门工作总结、工作计划、工作汇报、行政简报的撰写与规范；
+ 行政台账、后勤台账、资产台账、会议台账的整理与更新；
+ 部门内部通知、会议纪要、行政培训材料的起草与分发；
+ 行政相关公文、跨部门沟通函件、制度宣贯材料的起草与规范。

**应用价值**：实现行政文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率与跨部门沟通效率，保障综合行政工作有序推进。

对应OpenClaw Skills：

+ `work-summary`（部门工作总结、工作计划、工作汇报撰写）；
+ `ledger-manage`（各类行政、后勤、资产台账建立与更新）；
+ `meeting-minutes`（部门会议纪要、行政简报起草）；
+ `official-doc`（行政相关公文、沟通函件、政策宣贯材料撰写）。
