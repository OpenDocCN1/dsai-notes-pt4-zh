## 激活函数

### 初步总结

在神经网络中，激活函数用于将非线性引入神经元的输出。它们负责根据神经元收到的输入决定是否应激活神经元。激活函数帮助神经网络学习输入和输出之间的复杂非线性关系。深度学习中使用多种类型的激活函数，例如`sigmoid`、`ReLU`和`tanh`。

![](img/0826fe2c57a85d65baeb909a2c0c9212.png)

#### 💡 前馈传播

+ 信息流沿正向方向发生。输入用于计算隐藏层中的一些中间函数，然后用于计算输出。

在前馈传播中，激活函数是输入馈送当前神经元和其输出进入下一层之间的“门控”。

#### 💡 反向传播

+ 反复调整网络连接的权重，以最小化网络的实际输出向量与所需输出向量之间的差异。

反向传播旨在通过调整网络的权重和偏差来最小化损失函数。损失函数梯度决定了相对于激活函数、权重、偏差等参数的调整水平。

### 3 种类型的激活函数对比

#### 1. `ReLU`（`Rectified Linear Unit`）

`ReLU` 函数不会同时激活所有神经元。只有当线性变换的输出小于 0 时，神经元才会被停用。

由于只有一定数量的神经元被激活，因此与 `sigmoid` 和 `tanh` 函数相比，`ReLU` 函数的计算效率要高得多。

ReLU Activation Function

`The Dying ReLU problem`

存在一定的限制：`ReLU`的导数在负值范围使梯度值为零，由于这个原因，在反向传播过程中，某些神经元的权重和偏差不会更新。某些神经元永远不会被激活（`The Dying ReLU problem`）。

- 计算定义：

- 特点：简单高效，缓解梯度消失，但负值输出为零。

- 可视化：线性增长，负值为零。

#### 2. `Leaky ReLU`

`Leaky ReLU` 是 `ReLU` 函数的改进版本，用于解决 `Dying ReLU` 问题，因为它在负区域具有较小的正斜率。

Leaky ReLU

The derivative of the Leaky ReLU function

`Leaky ReLU` 的优点与 `ReLU` 的优点相同，此外它还支持反向传播，即使对于负输入值也是如此。

同理 `Parametric ReLU` 是 `ReLU` 的另一种变体，旨在解决轴左半部分的梯度变为零的问题。

此函数提供函数负部分的斜率作为参数 `a`。通过执行反向传播，可以学习到最合适的 `a` 值。

- 定义：

- 特点：负值有小斜率，避免“死亡`ReLU`”。

- 可视化：负值区域有小斜率。（当 `x ≤ 0`，通常 `α` 取小值如 `0.01`）

#### 3. `ELU`（`Exponential Linear Unit`）

`ELU`（`Exponential Linear Unit`）最早是在论文 "Fast and Accurate Deep Network Learning by Exponential Linear Units (ELUs)" 中提出的。这项工作展示了 `ELU` 在加速深度网络学习和提高模型鲁棒性方面的优势。

指数线性单元，简称 `ELU`，也是 `ReLU` 的一种变体，它修改函数负部分的斜率。`ELU` 使用 对数曲线 来定义负值，这与使用直线的 `Leaky ReLU` 和 `Parametric ReLU` 函数不同。

ELU Activation Function

ELU Activation Function and its derivative

`ELU` 缓慢变得平滑，直到其输出等于 `-α`，而 `ReLU` 急剧。通过引入输入负值的对数曲线来避免 `Dying ReLU` 问题。

但是局限性是 由于包含指数运算，它增加了计算时间，不会学习“`a`”的参数值（常量）。

- 定义：

- 特点：负值为指数函数，提升学习速度。

- 可视化：平滑过渡，负值为指数。

##### 绘制 `Swish` 激活函数以及其导数 曲线图

```
import numpy as np
import matplotlib.pyplot as plt

def swish(x, beta=1.0):
    return x * (1 / (1 + np.exp(-beta * x)))

def swish_derivative(x, beta=1.0):
    sigmoid = 1 / (1 + np.exp(-beta * x))
    return sigmoid + beta * x * sigmoid * (1 - sigmoid)

# 生成一系列输入值
x_values = np.linspace(-10, 10, 100)

# 计算 Swish 函数及其导数的值
y_values_swish = swish(x_values)
y_values_derivative = swish_derivative(x_values)

# 可视化 Swish 函数及其导数
plt.figure(figsize=(10, 6))
plt.plot(x_values, y_values_swish, label='Swish', color='blue')
plt.plot(x_values, y_values_derivative, label='Swish Derivative', color='red', linestyle='--')
plt.title('Swish Function and Its Derivative')
plt.xlabel('Input')
plt.ylabel('Output')
plt.grid(True)
plt.legend()
plt.show()
```

1. `GELU` 函数在负值区域略有饱和，而在正值区域近似于线性。

2. `GELU` 导数在负值区域较小，在正值区域接近 `1`，这有助于缓解梯度消失问题。

3. `GELU` 导数在原点附近较大，这可能会导致训练不稳定。

`GELU` (`Gaussian Error Linear Unit`) 是一种基于高斯误差函数的激活函数，相较于 `ReLU` 等激活函数，`GELU` 更加平滑，有助于提高训练过程的收敛速度和性能，尤其在 `BERT` 和 `GPT` 以及 `ViT` 等模型中被广泛使用。

`GELU` 的特点是：

1. 结合了高斯分布的特性，能够更好地处理神经网络中的激活值，在自然语言处理任务中表现突出。

2. 与 `Swish` 函数有关联，`GELU` 是 `Swish` 的一种特例。

总的来说，`GELU` 函数及其导数的形状都较为平滑，这有助于提高模型的训练效率和性能。

##### 近似以及导数代码段

```
# 以下是使用 Python 和 NumPy 实现 GELU 函数及其近似的示例代码：
import numpy as np
import matplotlib.pyplot as plt
import torch
import torch.nn as nn

# 生成 x 值的范围
x = np.linspace(-6, 6, 600)

# 定义 GELU 函数
class GELU(nn.Module):
    def forward(self, x):
        return 0.5 * x * (1 + torch.tanh(np.sqrt(2 / np.pi) * (x + 0.044715 * x**3)))

# 计算 GELU 函数及其导数
m = GELU()
output = m(torch.Tensor(x))
derivative = (m(torch.Tensor(x + 1e-6)) - m(torch.Tensor(x - 1e-6))) / (2e-6)

# 绘制图像
plt.figure(figsize=(10, 6))
plt.plot(x, output, label='GELU')
plt.plot(x, derivative, label='Derivative')
plt.title("GELU Function and Derivative")
plt.xlabel("x")
plt.ylabel("Value")
plt.grid()
plt.legend()
plt.show()
```

##### `Sigmoid` 与 `CDFs`代码段

```
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# 生成输入数据
x = np.linspace(-6, 6, 100)

# 计算标准正态分布的 CDF 和 Sigmoid 函数的输出
cdf = norm.cdf(x)
y_sigmoid = sigmoid(x)

# 绘制图像
plt.figure(figsize=(10, 6))
plt.plot(x, cdf, label='Standard Normal CDF', color='blue')
plt.plot(x, y_sigmoid, label='Sigmoid Function', color='red')
plt.axhline(y=0.5, color='green', linestyle='--', label='Decision Boundary')
plt.title('Standard Normal CDF and Sigmoid Function')
plt.xlabel('Input (x)')
plt.ylabel('Output')
plt.grid(True)
plt.legend()
plt.show()
```
