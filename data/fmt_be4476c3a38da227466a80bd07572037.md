
# FinGLM：开放、公益、持久的金融大模型项目

> 来源：[https://v11enp9ok1h.feishu.cn/docx/TaVyd9AuVoLwXVxeNrOcEuownOh](https://v11enp9ok1h.feishu.cn/docx/TaVyd9AuVoLwXVxeNrOcEuownOh)

## 项目介绍

> 📈 一个旨在深度解析上市公司年报的对话交互智能系统。面对金融文本中的专业术语与暗含信息，我们致力于用AI实现专家级别的金融分析。

> 🚀 在AI领域，虽然已在文本对话取得进展，但真正的金融交互场景仍然是一个巨大挑战。多方机构联手举办此次竞赛，探索金融领域AI的边界。

> 📘 上市公司年报为投资者呈现了公司的经营状况、财务状况和未来规划。专业知识是解读的关键，而我们的目标是通过AI技术让这一过程变得更简单、更准确。

## 🛠 项目框架

### 数据准备流程

+ [`PDF 转 TXT`](https://github.com/MetaGLM/FinGLM/blob/main/tools/pdf_to_txt)：

+ 转换为 TXT 格式。

+ 保留表格并合并单元格。

+ 数据切分：

+ 基础信息：例如公司名称等。

+ 财务数据：例如资产负债表等。

+ 综合信息：例如财务指标等。

+ 数据处理：

+ 计算基础公式：如营业成本率等。

+ 计算增长率。

+ 计算行业均值和排名。

+ 存入数据库：

+ 存入 `SQL`、`Mongo` 和 `ES` 中。

+ 包括建表及存储。

### 模型微调流程

+ 数据分类：如 `SQL` 数据、`ES` 数据等。

+ 选择微调策略：例如 `ptuningv2`、`lora` 等。

+ 执行微调：根据选定策略。

### 问答流程

+ 输入问题：用户输入问题。

+ `Prompt` 准备：根据问题生成 `prompt`。

+ 生成查询语句：基于 `GPU` 使用率选择生成方法。

+ 查询数据库：并返回结果。

+ 答案生成：结合问题和查询结果生成答案。

## 🌱 开源路线图

### 开源策略

1）赛事转型

+ 比赛转型为[学习赛](https://tianchi.aliyun.com/competition/entrance/532126)，允许任何人学习使用。

2）数据开源

+ 目前开源数据有 [70G/1w+份年报数据](https://github.com/MetaGLM/FinGLM/blob/main/data/reports)、[10000条人工标注评测数据](https://github.com/MetaGLM/FinGLM/blob/main/data)等。

+ 后续我们也将根据项目需求，持续迭代更新数据。

3）方案/代码/模型开源

+ 经同意，[结婚买房代代韭菜](https://github.com/MetaGLM/FinGLM/blob/main/code/%E7%BB%93%E5%A9%9A%E4%B9%B0%E6%88%BF%E4%BB%A3%E4%BB%A3%E9%9F%AD%E8%8F%9C)、[Chatglm反卷总局](https://github.com/MetaGLM/FinGLM/blob/main/code/Chatglm%E5%8F%8D%E5%8D%B7%E6%80%BB%E5%B1%80)、[nsddd](https://github.com/MetaGLM/FinGLM/blob/main/code/nsddd)、[馒头科技](https://github.com/MetaGLM/FinGLM/blob/main/code/%E9%A6%92%E5%A4%B4%E7%A7%91%E6%8A%80)、[南哪都队](https://github.com/MetaGLM/FinGLM/blob/main/code/%E5%8D%97%E5%93%AA%E9%83%BD%E9%98%9F)、[龙盈战队](https://github.com/MetaGLM/FinGLM/blob/main/code/%E9%BE%99%E7%9B%88%E6%88%98%E9%98%9F)、[安硕硕眼探企](https://github.com/MetaGLM/FinGLM/blob/main/code/finglm_all)、[随便取个名](https://github.com/MetaGLM/FinGLM/tree/main/code/%E9%9A%8F%E4%BE%BF%E5%8F%96%E4%B8%AA%E5%90%8D)等团队的方案、代码、模型完全开源，纳入 FinGLM 项目。

+ 我们将长期维护优化 [`FinGLM 项目`](https://github.com/MetaGLM/FinGLM/blob/main/code/finglm_all)，提供便捷解决方案。

4）开放交流

+ 以上团队成员将共同维护 FinGLM 项目，确保项目持续迭代。我们也欢迎更多团队来共同贡献问题和方案。

+ `[FinG`](https://github.com/MetaGLM/FinGLM#%E8%B4%A1%E7%8C%AE%E8%80%85)`LM` 开源项目出于完全公益目的，欢迎所有开发者申请加入，当然我们会进行严格审核。
