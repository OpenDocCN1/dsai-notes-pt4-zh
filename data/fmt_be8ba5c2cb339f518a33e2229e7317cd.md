## 序言

回顾上一篇（[大模型炼丹手册-理论篇](https://e0749igednw.feishu.cn/docx/LNHxd4JRKoFwr2xjGyscfX6Anlg)）的内容，大模型的整个训练流程，分为预炼、精炼和强炼三个阶段，并具有以下特点：

+ 预炼：需要海量灵材、真火，炼制时间长，非豪门巨富难以承受；
+ 精炼：仅需少量灵材、真火即可完成，炼制时间短，性价比高；
+ 强炼：炼制过程复杂、炼制难度较大，非技艺高超者难以胜任。

> 对理论部分不太了解的话，建议先通读上一篇文章，可加深对实操部分的理解

我们知道，从零开始训练大模型，代价是极其高昂，只有财力雄厚的大公司可以承受。

那我们平民玩家，数据有限、算力不足，甚至没有炼丹经验，可不可以训练大模型呢？

答案是可以的。

选择已经训练好的模型，在特定数据上继续进行训练，即大模型微调。

大模型微调实现快，门槛低，人人都能玩。

而且，本篇介绍的方法，全程零代码，有手就行~

接下来，就让我们看看，如何训练一款自己的大模型。

## 一、模型选择

目前开源社区涌现了大量的模型，种类繁多，令人眼花缭乱。

基于模型效果、热度、活跃度，在此推荐三款主流模型：

+ `Baichuan2` 7B/13B （百川智能）
+ `ChatGLM2` 6B （清华智源）
+ `LLaMA2` 7B/13B （Meta）

根据最新的评测结果，`Baichuan2` 各项指标在同尺寸开源模型中遥遥领先，可重点关注！

## 二、微调数据

微调的数据形式，主要有 2 种：单轮对话和多轮对话。

### 1、单轮对话

单轮对话的形式比较简单，就是一个问题答案对，示例如下：

```
{
  "instruction": "你瞅啥",
  "input": "",
  "output": "瞅你咋滴"
}
```

### 2、多轮对话

多轮对话，在单轮对话的基础上，新增了历史对话的内容。输入模型时，会将历史对话与当前对话拼接在一起。

```
{
  "instruction": "你再瞅一个试试？",
  "input": "",
  "output": "试试就试试",
  "history": [
    [
      "你瞅啥",
      "瞅你咋滴"
    ]
  ]
}
```

## 三、微调方法

微调主要有以下几种方式：

### 1、全量参数微调

模型所有参数均参与训练

### 2、`LORA` / `QLORA`

新增额外的参数，模型原有参数冻结，仅训练新增的参数。`QLORA` 在 `LORA` 的基础上，对原模型的参数进行了量化。

![](img/89073cbdf432849eaa93b4d99408ca58.png)

### 3、`P-Tuning V2`

与 `LORA` 类似，也是原有模型参数冻结，新增训练参数；但是参数增加的方式和位置不同。

![](img/139ac93e75f13078266b0268bd07c1d4.png)

上述方法的理论知识不必深究，只需了解其各自特点即可。

全量参数微调，显存占用高，且容易造成对旧知识的遗忘。

`LORA`、`P-Tuning V2` 只训练新增部分参数，显存占用低，也可一定程度上缓解大模型微调带来的知识遗忘现象。对原有模型参数进行量化，可进一步降低显存占用。

实际训练中，可对比 `LORA`、`P-Tuning V2` 效果，择优从之。

## 四、算力需求

单卡即可完成 6b/13b 尺寸的模型微调。本地训练，可选 RTX 3090；云服务器，可白嫖阿里云 GPU。

## 五、微调过程

尽管 `github` 上有大量的微调项目，但是，没有编程或炼丹经验的朋友很容易被劝退。

如果有一个类似的 `stable-diffusion-webui` 的界面，大家只需要点几下，就能完成模型训练，岂不美哉？

别说，还真有！

这就是 `LLaMA-Efficient-Tuning`（https://github.com/hiyouga/LLaMA-Efficient-Tuning/tree/main），提供了训练推理一体化 Web UI，简单易用。

虽然该项目最初是为 `LLaMA` 而设计，但目前已支持大量的开源模型，并预置了大量的训练数据，堪称大模型训练神器。

### 1、部署 `LLaMA-Efficient-Tuning`

此处以阿里云 GPU 服务器为例。在命令行终端依次输入以下指令：

```
pip install llmtuner==0.1.3
# 如需要启用低精度量化训练，节省显存，需安装以下包
pip install bitsandbytes==0.40.0
git clone https://github.com/hiyouga/LLaMA-Efficient-Tuning.git
cd LLaMA-Efficient-Tuning
unset http_proxy https_proxy all_proxy # 关闭代理
python -m llmtuner.webui.interface
```

运行成功后，点击界面上的 `localhost:7860` 链接，即可看到 web-ui 界面。

![](img/901147f72b2e45d538203dbb3f77120e.png)

### 2、参数配置

#### 1）模型设置

常见的开源模型基本都支持，此处我选择了 `ChatGLM2-6B`。模型路径默认是 huggingface 的下载链接。如果下载有问题，可手动下载、上传，然后填写本地路径。

![](img/fb370f3e1713e5aaffd37ea0b384aba6.png)

#### 2）训练方法

微调方法选择 `lora`，训练阶段选择 `SFT`，即监督指令微调。

> 对监督指令微调有疑问的话，可参考[大模型炼丹手册-理论篇](https://e0749igednw.feishu.cn/docx/LNHxd4JRKoFwr2xjGyscfX6Anlg)。

![](img/77fbef2b452e9cf80a78c69b604fcb08.png)

量化等级可选，如果训练过程中显存不够，可设置 4 或 8，对模型的参数进行低精度量化。数字越小，显存占用越低。

![](img/d4971c438dd2ad59bfb42b88aa04921d.png)

#### 3）训练数据

`LLaMA-Efficient-Tuning` 内置了常见的指令微调数据。

为方便效果演示，此处我选择 `self_cognition`。

该数据集用来调整模型的自我认知，即模型是谁？模型从哪里来？模型能做什么？

现在，我想修改模型的自我认知，示例数据如下：

如果训练成功，那么，当我再问类似的问题时，模型会给出我想要的答案。

#### 4）训练参数

训练参数大部分沿用默认的即可。这里主要说明以下几个参数：

+ 学习率：可理解为参数更新的幅度大小。模型微调，学习率一般设置比较小，此处默认为 `5e-5`。
+ 训练轮数：模型训练的总轮数，全量数据训练一次为一轮。此处设置为 30，即模型会重复读取数据 30 次。如果模型学习不充分，可尝试增大训练轮数，让它多学几次。
+ 批处理大小：单次输入模型的数据量。一般受显存大小限制。如果显存不够，可降低批处理大小。

![](img/45935a30f831fccd36be3b6d99bff7d3.png)

#### 5）模型保存位置

断点名称，保存训练模型的文件夹名称，可任意设置，便于区分记忆即可。

![](img/f514aea74293badfb1d41b683dcd4353.png)

上述参数设置好之后，点击开始按钮，即可开始模型训练。

训练过程中，页面上还会显示损失曲线，监控模型训练状态。正常情况下，损失会逐渐降低，最终趋于平稳，如下所示。

### 3、效果验证

训练完成之后，验证模型效果。

从 `train` 模式 切换到 `chat` 模式，进入聊天页面。

![](img/345a659ae99d0c7b8ac47deb1698c314.png)

#### 2）加载模型

+ 模型路径：大模型原有参数路径，与训练时设置的模型路径一致
+ 模型断点：训练模型的保存位置，与训练时设置的断点名称一致

设置完成之后，点击加载模型。
