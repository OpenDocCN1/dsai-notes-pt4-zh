## 二、内容

> 许荣哲是台湾知名作家、故事营销教练，被誉为“台湾故事王”。

> 他提出的【七步法故事模型】以简洁实用著称，尤其适合快速构思故事框架。

> 这个公式不仅适用于短篇小说，也适用于营销文案、演讲叙事、剧本大纲等场景。

## 30秒故事公式：公式

### 公式结构：“目标→阻碍→行动→结果→意外→转折→结局”，前4步是“顺理成章的失败”，后3步是“峰回路转的成功”。

```
1. 目标（主角的愿望或需求）  
2. 阻碍（阻止主角实现目标的障碍）  
3. 行动（主角为克服阻碍采取的行动）  
4. 结果（行动带来的直接结果，通常是失败的）  
5. 意外（超出预期的突发情况，打破现有局面）  
6. 转折（意外引发的方向逆转，找到新的解决路径）  
7. 结局（最终结果，通常是目标达成或新的领悟）  
```

# 故事梗概
## 一、基本信息
1. 选题: 讲述了一位七十岁的女性穆云在丈夫沈之洲出轨初恋陈婉后，重新审视自己婚姻，最终选择离婚，并开启新生活的故事。
2. 题材: 现实、情感
3. 类型: 现实主义、家庭伦理
4. 字数: 9000
5. 期待感: 探讨婚姻的本质、爱情与责任的冲突，以及女性在婚姻破裂后的自我救赎和新生。

## 二、故事设定
1. 背景设定: 21世纪的中国，城市生活，社会对老年人婚姻和婚外情的看法。
2. 主角:
   - 穆云：七十岁，普通公司职工，性格隐忍、坚韧、重视家庭，后期独立、积极、追求自我。
   - 分析主角人设的七步法：
      1. 目标：追求平静、幸福的晚年，以及对婚姻的完整和忠诚。
      2. 阻碍：丈夫的出轨、儿子的不理解、陈婉的出现，以及自身对过去情感的依恋和对未来的迷茫。
      3. 行动：面对丈夫出轨，选择离婚，寻找新的生活方式。
      4. 结果：与丈夫离婚，摆脱了束缚，开启了新的生活，实现了自我价值。
      5. 意外：在旅行中认识自我，重拾生活的热情和对未来的希望，获得新生。
      6. 转折：面对陈婉的挑衅，最终做出离婚决定。
      7. 结局：开始新的生活，学习钢琴，旅游，活出自我。
3. 配角:
   - 沈之洲：穆云的丈夫，七十五岁，医学教授，性格复杂，出轨，晚年患病。

4. 核心梗: 丈夫出轨初恋，妻子在老年选择离婚，追求自我.

2. 情感纽带: 亲情、爱情、对过往婚姻的回忆与反思。
3. 故事反转: 穆云发现丈夫出轨，决定离婚，打破了维持了五十年的婚姻。
4. 二次反转: 陈婉的出现，以及在网络上被揭露真相，沈之洲身败名裂。
5. 写作风格: 细腻、平实，着重于人物的心理描写，展现了老年人的情感困境和生活状态.

### 公式背后的逻辑：冲突与反转

> 许荣哲强调，故事的核心是【冲突】和【反转】。

+ 前半段（目标→结果）：建立“主角的渴望”与“现实的阻碍”之间的冲突，让读者产生共情。

+ 后半段（意外→结局）：通过“意外【戏剧化】”打破常规，引发“转折”，让故事跳出线性思维，制造惊喜感。

>

> 关键逻辑：

+ 没有阻碍的目标 = 平淡无奇，无法引发兴趣；

+ 没有意外的结果 = 可预测，失去吸引力；

+ 转折必须基于意外，且与前文伏笔呼应，避免突兀。

## 进阶用法：故事扩展

### 重复公式：嵌套结构

> 在主故事中插入子故事，每个子故事独立套用公式。

> 例：主故事是“主角寻找宝藏”，途中遇到“被诅咒的村民”，村民的故事可作为子故事：

+ 目标：村民想解除诅咒；

+ 阻碍：诅咒来自远古精灵；

+ 行动：尝试各种魔法仪式；

+ 结果：失败，村民濒临死亡；

+ 意外：主角带来关键道具（如神灯）；

+ 转折：解除诅咒，村民加入队伍；

+ 结局：村民重获新生，为主角提供线索。

### 细化环节：增加细节与情感

> 在7要素中加入情感描写、场景渲染、人物动机等维度：

+ 目标：明确主角的内在动机（如“渴望被认可”而非表面的“想赚钱”）；

+ 阻碍：具象化阻碍的强度（如“反派掌控整个王国的军队”）；

+ 意外：设置伏笔（如主角曾救过一只小鸟，后来小鸟在关键时刻叼来钥匙）。

### 变体：悲剧与开放式结局

> 公式默认是“主角成功”的正向结局，但若调整“转折”的方向，可变为悲剧或开放式结局：

+ 悲剧：意外导致更糟的结果（如主角为救他人放弃目标，最终牺牲）；

+ 开放式：结局留白，引发思考（如主角达成目标却失去初心，徘徊在十字路口）。

## 核心心法：故事的本质是“解决问题”

> 许荣哲指出，所有故事的内核都是“主角遇到问题，想办法解决问题”。

> 公式的本质是将“问题解决过程”结构化，通过以下步骤抓住读者：

1. 制造共鸣：用“目标+阻碍”让读者代入主角处境；

2. 保持悬念：用“意外+转折”打破预期，维持注意力；

3. 传递价值：用“结局”输出观点（如勇气、爱、成长）。

>

> 关键提醒：故事不必追求复杂，哪怕是微小的事件（如“找钥匙”），只要套用公式挖掘冲突与反转，也能成为引人入胜的叙事。

## 总结：如何快速掌握许荣哲故事模型？

1. 刻意练习：用小九拆解经典故事（如电影、新闻、历史事件），观察要素如何运作；

2. 从小故事开始：先写100字的微故事，熟练后再扩展；

3. 关注“意外”与“转折”：这是故事的灵魂，平时积累“脑洞素材”（如奇葩新闻、冷门知识），用于创作时打破常规。

### 案例：某乎盐选爆款《执笔》短篇小说七步法拆解

```
**1. 目标（主角的愿望或需求）**
  - 原文情节：丞相府嫡女苏云绮发现自己是一本话本里的恶毒女配，命书预言她将容貌被毁、嫁给屠夫，最终惨死。她的目标是逆天改命，摆脱命书设定的悲惨结局。
  - 七步法应用：
    - 核心矛盾：主角的生存需求（避免死亡）与命运桎梏的冲突。
    - 用户共鸣：知乎读者对 “逆袭”“反抗命运” 的题材天然感兴趣，尤其女性读者对 “摆脱物化女性的剧本” 更有代入感。

2. 阻碍（阻止主角实现目标的障碍）
  - 原文情节：
    - 外在阻碍：命书强行推动剧情，例如父亲为掩盖罪行牺牲她的母亲，未婚夫将她卖入妓院毁其清白。周围人（妹妹、父亲）的算计与背叛。
    - 内在阻碍：苏云绮一度被 “嫡女”“未来王妃” 的身份绑架，怀疑自己是否真的能打破宿命。
  - 七步法应用：
    - 具象化阻碍：通过 “命书” 这一设定，将抽象的命运具象为可对抗的 “敌人”，增强戏剧张力。
    - 双重阻碍：外在的家族阴谋与内在的自我怀疑形成递进式冲突，符合知乎文 “快节奏、强冲突” 的特点。
    
3. 行动（主角为克服阻碍采取的行动）
  - 原文情节：
    - 苏云绮利用命书的 “墨迹未干可修改” 漏洞，主动干预剧情。
      例如：
      - 提前识破妹妹的陷害，反毁其容貌；
      - 伪装成弱女子接近反派，收集父亲通敌的证据。
      - 以 “毒舌吐槽” 解构传统偶像剧套路（如 “浴桶必藏人”“清白即贞洁”），同时推动剧情。
  - 七步法应用：
    - 主动性：主角不被动接受命运，而是通过 “利用规则”（命书漏洞）和 “反套路行动”（以恶制恶）推动故事，符合知乎用户对 “爽感” 和 “强女主” 的偏好。伏笔埋设：命书的漏洞在开头被揭示，为后续转折埋下关键线索.

4. 结果（行动带来的直接结果，通常是失败的）
  - 原文情节：
    - 苏云绮虽成功阻止部分悲剧（如母亲死亡、自己被毁容），但命书不断生成新的剧情，例如她被迫嫁给屠夫后，屠夫竟是命书安排的 “新反派”。表面失败：主角看似摆脱了旧困境，却陷入新的陷阱，强化 “命运不可抗” 的危机感。
  - 七步法应用：虚假胜利：结果的 “失败” 并非真的无路可走，而是为意外转折做铺垫，符合知乎文 “反转密集” 的特点.


5. 意外（超出预期的突发情况，打破现有局面）
  - 文情节：
    - 苏云绮在与命书对抗时，发现命书的终极漏洞：只要她拒绝按照命书的逻辑行事（如拒绝雌竞、拒绝自我牺牲），命书的预言就会失效
    关键触发点：母亲的死亡让她意识到 “贤良淑德” 的传统价值观无法拯救自己，转而彻底反叛。
  - 七步法应用：

    - 颠覆性意外：意外不是偶然事件，而是主角认知觉醒的必然结果，与前文 “命书漏洞” 的伏笔呼应。
    - 价值观冲击：意外的本质是主角从 “依附男性” 到 “自我优先” 的价值观转变，引发知乎读者对女性觉醒的共鸣.

6. 转折（意外引发的方向逆转，找到新的解决路径）
  - 原文情节：
    - 苏云绮不再试图 “修改命书”，而是主动重构剧情：
    - 揭露父亲的罪行，让其自食恶果；与 “工具人” 男主合作，利用他的身份反制命书；最终写下自己的结局：成为独立女性，掌控自己的人生。
  - 七步法应用：
    - 逻辑闭环：转折基于意外（认知觉醒），同时呼应前文 “命书可干预” 的设定，避免突兀。
    - 爽点设计：通过 “打脸反派”“颠覆父权” 等桥段，满足知乎用户对 “逆袭爽感” 的需求.

7. 结局（最终结果，通常是目标达成或新的领悟）
  - 原文情节：
    - 苏云绮打破命书的桎梏，不仅存活下来，还成为朝堂上的掌权者，实现了从 “恶毒女配” 到 “独立女性” 的蜕变。
    - 价值升华：结局传递 “女性应先成为自己” 的观点，与知乎用户追求独立、反套路的价值观高度契合.
```
