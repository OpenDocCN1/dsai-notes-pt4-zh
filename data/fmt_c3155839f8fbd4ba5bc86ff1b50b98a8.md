## 大模型水印技术的发展现状 & 仍然面临的问题

大模型水印技术是近期新兴的一项技术，通过在模型生成文本过程中植入特定的特征，来实现机生文本的辨别和来源追溯。它可用于虚假新闻检测、维护学术诚信、数据和模型版权保护等场景。

目前主流的大模型水印算法是在大模型推理阶段植入水印，这类方法主要分为两大算法家族：

![](img/213d6e412c0d6034bc8a7daaaefecc50.png)

+ KGW 家族：通过干预打分向量添加水印，将词表分为红绿列表，给绿色词加偏置，使输出偏好绿色词汇；
+ Christ 家族：在打分向量生成后，用伪随机数干预采样过程，使水印文本与该随机数更相关，以此植入水印。

然而，就像所有新兴技术一样，大语言模型水印技术在使用和理解上也面临一些挑战。

1. 如何便捷地使用各个大模型水印算法进行水印添加和检测？

各类大模型水印算法不断涌现。然而它们的实现大都基于作者自身的需求，缺乏统一的类和调用接口设计，使得研究人员和大众需要投入大量精力去使用和复现这些算法。

2. 如何直观地理解各个大模型水印算法的内部机制？

大模型水印算法的底层机制相对复杂，涉及对大模型生成文本过程中打分向量生成以及采样过程的干预，不便于研究者和大众理解。

3. 如何便捷、全面的评估各个大模型水印算法？

评估角度和指标多样（包含可检测性、鲁棒性、对文本质量的影响等），且一次评估涉及多步骤，全面快速评估算法性能极具挑战。

## MarkLLM：首个开源大模型水印多功能工具包

针对刚才提到的 3 个问题，作者设计并实现了面向大语言模型水印技术的工具包 `MarkLLM`。

`MarkLLM` 的主要贡献可总结如下：

### 1. 功能角度

+ 统一的大模型水印算法实现框架：支持两个关键水印算法家族（KGW 家族和 Christ 家族）的 9 种具体算法。
+ 一致、用户友好的顶层调用接口：1 行代码实现添加水印、检测水印等各类操作。
+ 定制化的大模型水印算法机制可视化解决方案：使用户能够在各种配置下可视化不同大模型水印算法的内部机制。
+ 全面、系统的大模型水印算法评估模块：包含覆盖 3 个评估角度的共 12 个评估工具，以及两类自动化评估流水线。

### 2. 设计角度：模块化、松耦合架构设计，具有极高的可扩展性和灵活性。

### 3. 实验角度：作者用 `MarkLLM` 作为研究工具，对支持的 9 种算法做了 3 个评估角度的全面实验，在证明 `MarkLLM` 的实用性的同时，为后续研究提供了宝贵的数据参考。

### 4. 对开源社区的影响力：`MarkLLM` 在 GitHub 上线以来已经获得了较多关注，目前已有 140+ stars，并吸引了同行通过 Pull Request 进行代码贡献，以及在 issue 栏目进行交流讨论。

作者衷心希望 `MarkLLM` 工具包在为研究人员提供便利的同时，提高大众对大语言模型水印技术的理解和参与度，促进学术界和公众之间就该技术达成共识，推动大语言模型水印研究和应用的进一步发展，为大语言模型使用安全贡献力量。

作者真诚欢迎大家提出宝贵意见、相互交流学习，也十分欢迎通过 pull request 贡献代码，通过大家的共同努力维护更好的大模型水印技术生态！
