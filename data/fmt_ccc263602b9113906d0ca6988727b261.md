### 基本使用（写代码场景）

#### 写通用代码

对于业务场景里面的代码还不太能够胜任，但是写一些通用的工具方法效果还不错

![](img/54687dd17c4c2534dc9b9108fd4a3e31.png)

对应提示词如下

```
你是一个资深的算法开发工程师，请使用typescript写一个快速排序的方法
```

#### 帮忙改bug

比如下面一个简单的程序试验，他可以快速找到问题，也实验了更加复杂的逻辑型的代码，也可以找到，这里主要为了阅读的时候方便理解，重要的是你如何给他下命令

![](img/1cdb5810007ed2a3de93c81fa03a30ae.png)

对应提示词如下

```
我希望你扮演一个资深的typescript研发工程师，
接下来我会输入一段快速排序的代码，你会帮我调试这段代码。
如果代码正常，你会输出“正常”
如果代码异常，你会指出出现问题的地方，包含行号的代码，并且指出应该如何改正
我输入的代码如下：
```

#### 优化纯算法

经典的两数之和算法的暴力破解法，让他看看怎么优化，直接给出更好的题解，也有很详细的说明

![](img/7aee9c67d12205fd0e562958dc40f9ed.png)

对应提示词如下

```
我希望你扮演一个资深的python研发工程师，
接下来我会输入一段代码，你会帮我进行时间复杂度优化，并输出优化后的代码，添加注释并且说明原因
```

#### 改写代码

我们有时候可能着急使用新的编程语言解决老问题，如果之前我有个我熟悉的语言代码，我希望在新的语言环境下使用，直接让他给我改写下

![](img/ed708c76c1b7cca57e019bbf8a907e62.png)

对应提示词如下

```
我希望你扮演一个资深的研发工程师，你精通python和typescript两种编程语言，
接下来我会输入一段python代码，你会帮我转写成typescript代码，代码实现的功能需要保持一直，并且输出转换后代码和注释
```

#### 帮我写SQL

直接让他模拟MySQL，自己完成建数据库，建表和插入数据的操作

![](img/7bf6a2ce45b070f4f473b923dd9382db.png)

对应提示词如下

```
我希望你扮演MySQL服务器。
创建一个名为"DB"的数据库，并在其中创建一个名为"user"的表。"user"表中包含用户
名、年龄、性别、注册时间、备注等列。并随机插入5行记录。
请输出上述SQL语句,以及输出这些SQL语句执行后你的响应。
```
