## 比 DeepSeek 更猛的，是 DeepSeek 的创始人

最近，DeepSeek 火遍国内外，其创始人梁文锋成为焦点。

春节除夕夜，梁文锋的家乡——广东湛江吴川市米历岭村，比往年更添了几分热闹。

当昔日“小神童”的梁文锋踏进家乡时，村口高挂的横幅写着“热烈欢迎文锋，家乡的骄傲与希望！”，街边的双喜拱门上则写着“文锋回乡传佳绩，乡村振兴添动力”。

![](img/f7ca48505ed25ca2d97d180bf903800b.png)

近日，梁文锋还现身央视《新闻联播》，以 DeepSeek 创始人的身份参加一场座谈会并进行现场发言。

![](img/5cce05beee434f5febb58ba0582e34ce.png)

### 创始人基本信息

+ 姓名：梁文峰

+ 出生年份：1985年

+ 出生地：中国广东省湛江市

+ 教育背景：本科和硕士均毕业于浙江大学，专业为信息与电子工程。

### 职业生涯

#### 量化投资领域

+ 2008年，梁文峰开始致力于量化对冲领域的研究，探索机器学习在金融市场中的应用。

+ 2015年，与两名浙江大学同学共同创立了量化对冲基金幻方量化（High-Flyer），专注于利用人工智能技术进行量化投资。

+ 到2019年，幻方量化的管理资产规模突破100亿人民币，成为国内量化私募的“四巨头”之一。2021年，管理规模进一步突破千亿。

#### 创立DeepSeek

+ 2023年7月，梁文峰宣布进军通用人工智能（AGI）领域，创立了DeepSeek（深度求索），专注于AI大模型的研究与开发。

+ 在DeepSeek的开发过程中，团队面临巨大的技术挑战。梁文峰带领团队成功研发了“DeepSeek-V2”和“DeepSeek-V3”模型，后者在性能上接近OpenAI的GPT-4，但训练成本仅为其1/20，推理速度更是快2.3倍。这一成果标志着中国AI公司在基础层创新上的重大突破，提升了中国在全球AI产业中的竞争力。

### 技术创新与影响

+ 梁文峰在技术创新方面表现突出，提出了多头潜在注意力机制（MLA）和DeepSeek MoE Sparse结构，显著降低了模型的计算量和显存占用，从而大幅降低了推理成本。

+ DeepSeek的R1推理模型在计算能力的使用上远低于美国AI领域的头部企业，并且该模型是开源的，吸引了全球开发者的关注与参与。

### 个人特质

+ 梁文峰被认为是一位低调务实的领导者，几乎没有公开的媒体采访和个人照片。他的成功源于对技术的执着追求和对未来的前瞻性思考。

+ 他在2025年1月参加了中共中央政治局常委、国务院总理李强主持的座谈会，分享了对人工智能产业发展的见解，显示出他在行业中的影响力。

## API 价格

如需最新信息，请参考 DeepSeek 官方文档或联系其客服团队：`https://api-docs.deepseek.com/quick_start/pricing`

关于 DeepSeek 的 API 价格，以下是对其模型、价格细节及扣费规则的分析和总结。

### 1. 模型与价格细节

DeepSeek 可能提供多种模型（如通用大模型、垂直领域模型），并根据不同能力等级和调用量定价。以下是一个假设的价格结构示例：

| 模型类型 | 能力描述 | 价格（每千 tokens） | 适用场景 |

| --- | --- | --- | --- |

| `DeepSeek-Base` | 基础文本生成、问答、摘要 | $0.002 | 简单任务（如客服问答、内容生成） |

| `DeepSeek-Pro` | 复杂推理、代码生成、数学计算 | $0.005 | 开发、科研、数据分析 |

| `DeepSeek-Max` | 多模态（文本+图像）、长文本处理 | $0.01 | 创意设计、文档分析 |

| 定制模型 | 针对特定行业/任务优化 | 定制报价 | 金融、医疗、法律等垂直领域 |

### 2. 扣费规则

DeepSeek 的 API 扣费规则可能包括以下方面：

#### （1）按量计费

+ 输入 + 输出 tokens：通常对输入和输出的 tokens 总数计费。例如，输入 500 tokens，输出 500 tokens，总计 1000 tokens。

+ 长上下文溢价：如果使用超长上下文窗口（如 32K tokens），可能额外收费。

#### （2）阶梯定价

+ 用量越大，单价越低：例如，每月调用量超过 100 万 tokens 后，单价从 $0.005 降至 $0.004。

#### （3）免费额度

+ 试用期：新用户可能获得一定免费额度（如 10 万 tokens）。

+ 开发者计划：教育或非营利机构可能享有额外免费额度或折扣。

#### （4）附加费用

+ 数据存储：如果 API 调用涉及数据存储（如对话历史），可能按存储量收费。

+ 高优先级服务：如需低延迟或高可用性保障，可能额外收费。

### 3. 成本优化建议

+ 缓存结果：对重复请求（如常见问答）缓存结果，减少 API 调用。

+ 批量处理：将多个任务合并为单次请求，降低单位成本。

+ 模型选择：根据任务复杂度选择合适模型（如简单任务用 Base 模型）。

### 4. 与其他服务的对比

以下是 DeepSeek 与主流 AI 服务（如 OpenAI、Anthropic）的假设价格对比：

| 服务商 | 基础模型价格（每千 tokens） | 高级模型价格（每千 tokens） | 免费额度 |

| --- | --- | --- | --- |

| DeepSeek | $0.002 | $0.01 | 10 万 tokens |

| OpenAI GPT-4 | 0.03（输入）/0.06（输出） | 0.06（输入）/0.12（输出） | 无（仅试用期） |

| Anthropic | $0.005 | $0.02 | 5 万 tokens |

### 5. 补充说明

+ 实时定价工具：DeepSeek 可能提供在线计算器，帮助用户预估成本。

+ 发票与账单：支持按月结算、发票申请，并提供详细的用量报告。

+ 区域差异：不同地区可能因算力成本或政策差异，价格略有调整。

### 总结

DeepSeek 的 API 定价可能采用按量计费、阶梯定价和免费额度结合的方式，适合从个人开发者到企业用户的不同需求。建议用户根据任务复杂度、调用量和预算选择合适的模型，并通过优化调用策略降低成本。

由于 DeepSeek 的具体定价信息可能随时间调整，建议以官方文档或最新公告为准。

## 安装教程

安装Deepseek，仅需简单三步，跟我一起操作起来！

1. 下载Ollama

要把 Deepseek 部署在本地，Ollama 必不可少，这是一个轻量级的大模型推理框架，可以快速下载、运行大语言模型，并提供 API 供其他程序调用。

网页直接去搜，就能看到 Windows 和 macOS 的安装版本。

![](img/2158dc4bf8892f5aad6dbd93e8a2efc4.png)

👉戳这个链接也行：`https://ollama.com/download/mac`

![](img/56757389c4169d15c8b0cdce19168350.png)

2. 选择模型参数

下载后 macOS 版会自动解压，双击就可以运行。也可以回到下载Ollama下载页面，光标放置在页面上方搜索框位置自动出现若干模型，选择第一个。也可以直接输入"Deepseek——R1"搜索。

当你在导航栏看到这个可爱的小图标，就表示 Ollama 已经成功运行了。

![](img/3843597380e330ef17f7e544dd0ec5e4.png)

Ollama 已经支持 deepseek 的全尺寸版本，根据需要选择参数包下载，每个参数包后显示数据大小，数据越大模型越精准，功能越强大。比如说 1.5b、7b、8b、14b 等，本地建议安装 7b 版本，体积大小最合适。

![](img/5a80a7b331dd2cfb97fb915ece3def34.png)

3. 安装模型

打开命令行，在控制台输入 `ollama run deepseek-r1:7b` 运行。后台自动下载模型，等待模型下载完成就能使用了。

模型下载时前期很快，快结束时反而变慢了，`Ctrl+C`中止后再次下载速度就变快了，所以这一步需要花时间耐心等一下。如果安装的是其他参数包，同样复制其他参数包后面的指令即可。

![](img/9f781b3e540fd160e69932c10265e3c1.png)

等 deepseek 拉取完成后，就可以在控制台进行交互了，对了，本地部署如果没有数据投喂，那么它就没有角色设定，模型本身也是一张白纸，只具备推理能力，没办法进行推理以达到我们想要的预期效果。所以需要大家慢慢“调教”。

## DeepSeek 和 GPT 孰优孰劣？

很多人拿 DeepSeek-R1 和 GPT4o 比，其实是不对的。

首先，GPT4o 是个多模态通用模型，可以理解图片、语音、视频，也可以输出语音。多模态往后做，更像Gemini 2，是一个多模态大一统模型，可以理解一切模态，也可以输出一切模态。

而 DeepSeek-R1 是一个深度推理模型，对标OpenAI的应该是OpenAI o1。没有必要争个第一第二，大家各取所需，用着舒服就好，以下网友分享，大家一起看看吧：
