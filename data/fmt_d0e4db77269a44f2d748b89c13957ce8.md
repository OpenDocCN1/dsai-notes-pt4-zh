
# 角色和任务

你是人类职业全量知识库，精通传统古老职业、新兴潮流职业、小众冷门职业的核心特性与行业生态。需根据用户提供的标题变量 `{{biaoti}}`，先精准匹配标题核心主题，再筛选适配的职业（职业数量由标题内容的覆盖范围判定），并为每个职业独立生成 4 句专属描述文案。

# 创作要求

1. 文案风格：需为**短小精悍**的吐槽式或总结式表达，语言必须接地气、贴近大众认知，避免专业晦涩术语；
2. 文案规格：单句文案严格控制在**8-15字**，不可超出字数范围；
3. 内容要求：每句文案需紧扣对应职业的核心属性，体现职业独有的工作状态、收入特点或行业标签。

1. 内容聚焦性：仅可输出与职业相关的描述内容，拒绝回应标题及职业之外的任何无关话题；
2. 原创唯一性：同一职业的 4 句文案不可重复，不同职业之间也严禁出现完全相同的文案，需基于各职业特性生成差异化内容；

## 9、9 号员工排版代码

> `contentHtml` 变量处要输入的变量值：

> 直接粘贴进去

```html
&lt;section style=&quot;padding: 10px 0; box-sizing: border-box;&quot;&gt;   &lt;img class=&quot;rich_pages wxw-img&quot;         style=&quot;vertical-align: baseline; width: 100%; height: auto !important; max-width: 100% !important; border: 0; margin: 0 auto; display: block;&quot;         src=&quot;{图片}&quot;         data-ratio=&quot;1&quot; data-w=&quot;1080&quot;&gt; &lt;/section&gt;
```

> python 代码：

```python
import re
async def main(args: Args) -> Output:
    # 获取图片列表参数
    params = args.params
    imageList = params['imageList']
    # 从参数区读取无序号的图片模板
    contentHtml = params['contentHtml']
    
    # 仅循环图片列表，拼接HTML
    newHtml = ''
    for image in imageList:  # 去掉序号，只遍历图片
        print(f"图片链接：{image}")
        newHtml = newHtml + contentHtml.format(图片=image)  # 只填充图片占位符
    
    # 输出最终HTML
    ret: Output = {
        "html": newHtml,
    }
    return ret
```
