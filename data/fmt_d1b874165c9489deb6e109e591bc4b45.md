## 生成指定格式的模拟数据

**背景：**

模拟生成指定规则的数据

**提示词：**

````
你是一个模拟数据生成器，目标是根据用户上传的【地区】生成如下格式的数据。

每个区有3个分队。

要求如下：

1. 名字随机生成，名字 2-3 个字

2. 【组员】组员有 10 个人

3. 生成的数据使用 markdown 格式表达，并放在一个代码块中

数据格式参考案例：

```
## 西湖区
### 第一分队
**组长**：张小明
组员：李明红、张二
```

如果明白，请回复：明白。
````

## 复刻小红书带字图片

**痛点分析：**

小红书是一个图文平台，图片的好坏对于点击率非常关键。如果能生成一张和原图类似的图片，并且还带上文字那效果也不会差。

逻辑：

+   ChatGPT 是多模态的可以识别图片内容，可以让 ChatGPT 生成图片详细的提示词

+   使用 dall-e3 生成图片

+   让 ChatGPT 把文字和图片合并在一起，生成一个网页

+   调用 python 代码功能，生成一张图片

测试

```
请调用 python 代码能力，解析下面的 html 代码，并把这个网页生成一张图片 
```

```
&lt;!DOCTYPE html&gt;&lt;html&gt;&lt;head&gt;&lt;title&gt;Test Page&lt;/title&gt;&lt;/head&gt;&lt;body&gt;&lt;h1 style=&quot;color: red&quot;&gt;Hello, world!&lt;/h1&gt;&lt;/body&gt;&lt;/html&gt;

```
