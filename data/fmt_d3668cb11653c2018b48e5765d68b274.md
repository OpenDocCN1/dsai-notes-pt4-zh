## 论文概要

当前大语言模型在处理长文本时面临着巨大的计算挑战。随着任务需求的增长，从代码生成、文档检索到多轮对话，长文本建模的重要性日益凸显。然而，传统的全注意力机制在处理超长文本时，计算复杂度和显存消耗呈平方级增长，导致推理速度下降，训练成本高昂。尽管稀疏注意力（Sparse Attention）提供了一种解决方案，但现有方法往往在推理阶段优化计算量，仍然需要在训练过程中依赖全注意力，从而限制了其效率和可扩展性。此外，许多现有的稀疏注意力方法在实际应用中未能达到理论上的计算加速效果，主要是由于其与现代硬件架构的不兼容性，例如 GPU 计算密度的不足以及访存带宽的瓶颈。

因此，DeepSeek 团队提出了 Native Sparse Attention（NSA），一种从底层架构上优化的原生可训练稀疏注意力机制。本文将详细解读 NSA 机制的核心创新、其在计算加速方面的优势，以及实验结果所验证的性能提升。

当前的稀疏注意力机制主要有三类：固定稀疏模式（Fixed Sparse Pattern）、动态 Token 剪枝（Dynamic Token Pruning）和查询感知选择（Query-Aware Selection）。固定稀疏模式如滑动窗口注意力（Sliding Window Attention）仅关注固定范围内的 Token，尽管减少了计算量，但会导致远程依赖信息的丢失，影响推理质量。动态 Token 剪枝方法通过注意力分数筛选关键 Token，例如 KV 缓存淘汰（KV-Cache Eviction）等技术可以在解码时动态丢弃不重要的信息，然而由于这类方法主要优化推理过程，在训练时仍然依赖全注意力，因此不能真正降低训练成本。查询感知选择方法基于 Token 之间的相关性计算出重要性排名，仅保留最相关的 Token 进行计算，但受限于选择过程的计算开销，导致其理论速度提升难以在实际应用中体现。总体而言，尽管这些方法在一定程度上优化了注意力计算，但仍然存在诸多限制，如在训练过程中无法减少计算量、难以适配现代 GPU 架构，以及可能导致信息丢失影响模型表现。

NSA 机制的核心创新在于其动态分层的稀疏选择策略，结合了三种不同的注意力机制，以保证信息保留率的同时大幅减少计算量。首先是压缩注意力（Compression Attention），该机制将相邻 Token 进行块级聚合，生成较少但更具代表性的 Token，从而在全局范围内减少计算需求。其次是选择注意力（Selection Attention），该机制通过计算注意力分数，动态保留最重要的 Token 进行计算，确保模型在关注关键内容的同时避免不必要的计算开销。最后是滑动窗口注意力（Sliding Window Attention），其保留了一定数量的局部上下文信息，以保持对短程信息的精确处理能力。这三者的结合使得 NSA 在计算效率和信息保留之间取得了最佳平衡。

除了稀疏注意力机制的设计，NSA 在硬件优化方面也做出了重要改进，使其能够高效适配现代 GPU 架构，提高计算密度并减少访存瓶颈。传统全注意力计算在长文本输入下会导致大量显存占用和计算冗余，而 NSA 通过块级操作和高效的 GPU Kernel 设计，优化了算术强度（Arithmetic Intensity）以提升计算效率。在现代 GPU 计算中，算术强度指的是计算量与显存访问量之间的比例，当算术强度过低时，计算往往受制于显存带宽，而非 GPU 的算力本身。NSA 通过块级计算和连续数据加载的方式减少访存操作，使得计算过程更具 GPU 友好性。此外，NSA 采用了 Triton 优化 Kernel 进行计算，实现了类似 FlashAttention 级别的加速，使得 GPU 能够更高效地执行稀疏注意力计算。这些优化确保了 NSA 不仅能在推理过程中提升计算效率，同时也能在训练阶段减少计算开销，使其真正成为一个原生可训练的稀疏注意力机制。

在实验评测方面，NSA 在多个长文本基准测试中展现了卓越的性能，并且在计算效率上显著优于全注意力模型。首先，在通用 NLP 任务评测上，NSA 在 MMLU、GSM8K、DROP 等多个基准测试中表现与全注意力模型相当，甚至在某些任务上超越了全注意力基线。其次，在长文本任务测试中，NSA 在 64K 长度的文本处理上实现了 9 到 11 倍的速度提升，同时保持了高准确率。在 “Needle-in-a-Haystack” 任务中，NSA 能够在 64K 的文本上下文中准确检索目标信息，证明了其在超长文本推理任务中的有效性。此外，在推理速度方面，NSA 在 64K 序列长度下比全注意力模型快 6 到 11 倍，而在训练速度方面，NSA 也实现了 3 到 6 倍的加速，相比于传统的全注意力模型，其训练成本显著降低。

从应用层面来看，NSA 的出现将极大地推动长文本任务的技术进步。在代码生成、长文档检索、自动摘要、知识库问答等领域，长文本处理能力的提升可以让模型在更复杂的推理任务中表现更优。同时，由于 NSA 具有端到端训练能力，它可以被应用于更大规模的预训练任务，例如 100B 级别的超大模型训练，而不会因为计算瓶颈而受到严重限制。此外，NSA 的 GPU 友好型设计使其能够更高效地在现代硬件上运行，从而降低大模型的计算成本，使得更多团队能够负担大规模语言模型的训练与部署。

未来的研究方向可能会集中在进一步优化稀疏注意力的适用性，使其不仅能够在超长文本任务中发挥作用，还能在更广泛的 NLP 任务中展现优势。例如，目前的 NSA 仍然需要在一些任务中进行超参数调优，以确保 Token 选择机制的最佳效果，未来可能会引入自适应策略，使得模型能够根据不同任务自动调整稀疏模式。此外，NSA 在更大规模的预训练模型上的表现仍然有待进一步研究，如果可以在 100B 级别的模型上证明其可行性，它将可能成为未来主流的大模型架构之一。

综上所述，NSA 作为一种新型的原生可训练稀疏注意力机制，成功解决了现有 Sparse Attention 只能在推理阶段加速、难以适配硬件以及信息丢失等问题。它通过压缩注意力、选择注意力和滑动窗口注意力的结合，实现了信息保留与计算效率之间的最佳平衡。通过硬件优化和端到端训练支持，NSA 使得大模型在长文本任务中能够保持高性能的同时显著降低计算成本。实验结果证明，NSA 在多个长文本任务中展现了卓越的计算效率和推理能力，使其成为长文本建模领域的一项重要突破。随着未来研究的推进，NSA 或将成为大规模语言模型架构设计的关键组成部分，在更多复杂任务中发挥更大作用。
