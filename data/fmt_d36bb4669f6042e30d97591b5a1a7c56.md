
# Open WebUI 安装指南

**Ollama**默认的API服务（端口11434）没有访问控制。如果部署在对公网开放的服务上，务必通过防火墙、反向代理或修改配置来限制访问，防止被未授权调用。

以下是安装Open WebUI（原名Ollama WebUI）的详细方法，推荐使用Docker方式安装，这是最简单且能避免环境依赖冲突的方式。

## Open WebUI 的安装

### 📦 推荐方式：使用Docker安装（最简单）

这是官方推荐且最适合大多数用户的方法，能一键完成所有依赖配置。

1. **确保环境就绪**

   + **安装Docker**：请确保你的系统（[Windows/macOS/Linux](https://www.docker.com/products/docker-desktop/)）已安装 Docker Desktop 并已启动。
   + **安装Ollama**：Open WebUI需要后端 [Ollama](https://ollama.com/) 服务，请确保已安装 Ollama 并能正常运行模型（如 `ollama run llama3`）。

1. 一条命令启动 Open WebUI

打开终端（命令提示符/PowerShell/Terminal），执行以下命令：

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```

**命令参数说明**：

+ `-p 3000:8080`：将容器内的 8080 端口映射到本机的 3000 端口（之后通过 `http://localhost:3000` 访问）。
+ `--add-host=...`：让容器内能访问到你主机上运行的 Ollama 服务（默认端口 11434）。
+ `-v open-webui:/app/backend/data`：将数据持久化存储在名为 `open-webui` 的 Docker 卷中，防止重启后数据丢失。
+ `--restart always`：设置容器随 Docker 自动启动。

1. **访问与登录**

   + 打开浏览器，访问 `http://localhost:3000`。
   + 首次进入会要求**创建管理员账户**，按提示填写邮箱和密码即可。

### 🛠️ 备用方式：从源码安装（适合开发者）

如果你想使用最新开发版或进行代码定制，可以采用此方式。

1. **克隆项目与安装依赖**

```
# 1. 克隆仓库
git clone https://github.com/open-webui/open-webui.git
cd open-webui

# 2. 安装后端依赖 (确保已安装Python 3.11+)
cd backend
pip install -r requirements.txt

# 3. 安装前端依赖 (确保已安装Node.js 18+)
cd ../frontend
npm ci
```

1. **配置与启动**

   + 在 `backend` 目录下，复制环境变量文件并修改：

```
cp .env.example .env
# 编辑 .env 文件，确保 `OLLAMA_API_BASE_URL` 指向你的 Ollama 服务地址（通常是 `http://localhost:11434`）
```

   + **启动后端服务**（在 `backend` 目录）：

```
python main.py
```

   + **启动前端服务**（在 `frontend` 目录，新开终端）：

```
npm run dev
```

   + 访问 `http://localhost:8080` 即可。

### 🔧 常见安装问题与解决

| 问题 | 可能原因与解决方案 |
| --- | --- |
| **访问 `localhost:3000` 无法连接** | 1. 检查 Docker 容器是否运行：`docker ps`。<br>2. 确认端口是否被占用，可尝试将命令中的 `-p 3000:8080` 改为 `-p 3080:8080`，然后访问 `http://localhost:3080`。 |
| WebUI 中无法连接 Ollama | 1. 确保 Ollama 服务正在运行：`ollama list`。<br>2. 对于 Linux 系统，Docker 命令可能需要将 `--add-host=host.docker.internal:host-gateway` 替换为 `--network=host`，并使用 `http://localhost:11434` 作为 Ollama 地址。 |
| **如何更新 Open WebUI？** | 使用 Docker 方式更新非常简单：<br>1. 停止并删除旧容器：`docker stop open-webui` && `docker rm open-webui`。<br>2. 拉取最新镜像并重新运行上述 `docker run` 命令（数据因 `-v` 参数会保留）。 |
| **如何自定义配置？** | [可以创建自定义配置文件，详细选项请参考官方文档的 `Configuration` 部分。](https://docs.openwebui.com/configuration) |

### 🚀 安装完成后的第一步

登录后，建议进行以下操作：

1. **连接模型**：在 WebUI 设置中，确认“Ollama API Base URL”正确（通常是 `http://host.docker.internal:11434` 或 `http://localhost:11434`）。
1. **下载模型**：在 WebUI 的“模型”页面，可以直接搜索并下载新模型（如 `llama3`、`qwen3-vl`），这比命令行更直观。
1. **开始聊天**：在“聊天”页面选择模型，即可开始对话。Open WebUI 支持多模态（上传图片）、对话历史管理、角色预设等丰富功能。
