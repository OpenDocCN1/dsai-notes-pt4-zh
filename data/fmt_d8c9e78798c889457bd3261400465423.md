## 01.开启指南

方法来自👸号@老金带你玩AI，硬核AI博主，推荐关注。

一种利用Python脚本激活的方式。

**原理：** 利用脚本模拟美国地区环境，欺骗 Chrome 的验证机制。

### 步骤0：设置

Chrome浏览器 → 设置 → 语言 → 英语置顶，设置为主语言。

![](img/ea7cc4020afd7b4f6bc432dc3b8f66b8.png)

### 步骤 1：环境准备

按`Win+R`，输入 `cmd` 并回车。

输入 `python --version` 检查是否安装了Python。

![](img/cb90071ab6a276da8aa733746cc5fcad.png)

若无 Python，请前往官网下载并安装（安装时务必勾选 `Add Python to PATH`）。

### 步骤 2：部署工具 `uv`

电脑里搜索 `PowerShell`，右键选择以管理员身份运行。

执行以下命令安装 `uv` 管理工具：

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

![](img/cd28909443f5edbefedd237b7748a55f.png)

安装完成后，输入：

```
uv --version
```

确认安装成功。

### 步骤 3：执行激活脚本

下载项目文件：

访问 GitHub：`https://github.com/lcandy2/enable-chrome-ai` 项目，点击Code，下载ZIP压缩包并解压。

![](img/8465e00c75a63cc6da2b2415a6359f56.png)

进入解压后的文件夹，在地址栏输入`cmd` 并回车，进入当前路径的命令行。

依次执行以下两条指令：

```
uv syncuv
run main.py
```

**顺利的话：** Chrome 会自动重启，右上角出现 Gemini 图标。

+   运行后没图标 → 确保Chrome完全关闭。任务管理器里检查。

+   图标出来但点不动 → 把Chrome语言改成英文。

### 补充：故障排查清单

如果操作后仍未出现图标，请按以下顺序检查：

**进程残留：** 确保 Chrome 已在任务管理器中完全关闭，无后台残留进程。

**语言设置：** 再次确认 Chrome 语言设置中，`English (United States)` 处于列表第一位。

**功能标记 (Flags)：**

+   在地址栏输入 `chrome://flags`

+   搜索关键词 `Glic`

+   将其状态手动更改为 `Enabled`

**账号归属：** 若以上皆无效，大概率是 Google 账号本身的区域属性未成功判定为美国，建议直接更换原生美区账号。

### 玩法7）Google 全家桶深度打通

侧边栏只是开胃菜。真正让我觉得 Google 这次“杀疯了”的，是它把自家的全家桶给串起来了。

![](img/9d7a21847b9ace37a732a39f482f4afe.png)

这就是所谓的 Connected Apps。以前我们的数据是死在谷歌各个应用里的孤岛。Gmail里的邮件就是邮件，Docs里面就是文档。现在 Gemini 在 Chrome 里充当了一个超级连接器。

一个丝滑的场景：你正在计划去参加一个行业会议。Gemini 可以直接从你深埋在 Gmail 里的那封旧邮件中挖出会议的具体时间和地点，然后根据这些信息，在侧边栏里调用 Google Flights 给你推荐合适的航班，最后还能顺手帮你起草一封邮件发给同事，告诉他们你几点落地。

这中间你不需要切任何窗口，也不需要复制粘贴任何日期。

这种体验怎么说呢，这才是智能助手该有的样子。而且 Google 也没把这事儿做绝，它给了个开关，你可以自己决定要不要把这些应用连进来，隐私这块儿的选择权还是在你手里。

## 03.AI浏览器的未来

回过头来看，Chrome 这次更新不仅仅是加了几个功能那么简单。它其实是在重塑我们和互联网的交互关系。

这么多年了，浏览器一直是一个被动的工具。我们输入网址，它展示页面。但从今天开始，浏览器开始变得主动了。它试图理解你想干什么，并且尝试帮你去干。

![](img/1e4212decfbee8eb45cb637fd0ff651f.png)

虽然现在有些高级功能还得要是订阅用户才能用，而且像 Auto Browse这种“代理人”功能肯定还需要时间去打磨，不可能一开始就百分百完美。但我真心觉得，这个方向是对的。我们的时间太宝贵了，不应该浪费在那些机械的、重复的网页跳转和表单填写上。

如果 AI 能帮我把这些琐碎的杂事儿给办了，让我能腾出精力去搞点真正的创作，或者仅仅是多发会儿呆，那这几十美金的订阅费，我觉得值。

不管怎么说，以后打开 Chrome，别只盯着搜索框了，试着跟侧边栏聊聊，真能给你省下不是各种打开网页的时间。
