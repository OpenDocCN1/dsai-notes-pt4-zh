## 8.1 如何清晰表达需求

### 避免模糊表达

模糊表达（不推荐）：

```
帮我写个文案
```

具体表达（推荐）：

```
请帮我写一段产品描述文案，产品是智能手表，主要特点包括健康监测、运动追踪、消息提醒，目标用户是年轻白领，字数在200字左右。
```

### 提供完整信息

信息不完整（不推荐）：

```
帮我分析这个数据
```

信息完整（推荐）：

```
请帮我分析这个销售数据，分析内容包括：
1. 总体统计（总销售额、平均销售额、最高/最低销售额）
2. 按产品分类统计
3. 按地区分类统计
4. 时间趋势分析
5. 发现数据洞察和改进建议
```

### 明确输出格式

格式不明确（不推荐）：

```
帮我整理这些信息
```

格式明确（推荐）：

```
请帮我整理这些信息，输出格式为表格，包含以下列：姓名、部门、职位、入职日期。
```

### 提供必要的上下文

提供相关的背景信息，帮助 AI 理解场景：

无背景信息（不推荐）：

```
帮我写个邮件
```

有背景信息（推荐）：

```
请帮我写一封邮件，背景是：客户对我们的产品提出了一个功能需求，我们需要回复客户，告知这个需求我们已经记录下来，会考虑在后续版本中实现，同时感谢客户的反馈。
```

#### 说明使用场景

说明内容的使用场景，让 AI 调整表达方式：

无场景说明（不推荐）：

```
帮我写个介绍
```

有场景说明（推荐）：

```
请帮我写一个产品介绍，这个介绍将用于公司官网的产品页面，目标用户是潜在客户，需要突出产品的核心优势，语言要专业但不晦涩。
```

#### 说明受众群体

说明内容的受众，让 AI 调整语气和风格：

无受众说明（不推荐）：

```
帮我写个说明
```

有受众说明（推荐）：

```
请帮我写一个操作说明，受众是没有任何技术背景的普通用户，语言要通俗易懂，步骤要详细，避免使用专业术语。
```

### 使用示例引导

#### 提供参考示例

提供参考示例，让 AI 理解你的期望：

无示例（不推荐）：

```
帮我写个类似的文案
```

有示例（推荐）：

```
请帮我写一个类似的产品文案，参考以下风格：

"这款智能耳机采用先进的主动降噪技术，有效隔绝外界噪音。超长续航设计，单次充电可连续播放30小时。人体工学设计，佩戴舒适。"

产品是智能音箱，主要特点包括：360°环绕音效、防水设计、长续航。
```

#### 提供格式示例

提供格式示例，让 AI 按照你的要求输出：

无格式示例（不推荐）：

```
帮我整理成表格
```

有格式示例（推荐）：

```
请帮我整理成表格，格式如下：

| 姓名 | 部门 | 职位 | 入职日期 |
|------|------|------|----------|
| 张三 | 技术部 | 工程师 | 2023-01-15 |
```

#### 提供风格示例

提供风格示例，让 AI 模仿特定的表达风格：

无风格示例（不推荐）：

```
帮我写个幽默的文案
```

有风格示例（推荐）：

```
请帮我写一个幽默的产品文案，参考以下风格：

"还在为找不到遥控器发愁？这款智能音箱，一句话就能搞定所有家电。妈妈再也不用担心我找不到遥控器了！"

产品是智能灯泡，主要特点是语音控制、多种颜色、定时开关。
```

### 实用技巧

#### 分步骤提问

对于复杂任务，分步骤提问：

一次性提问（不推荐）：

```
帮我分析这个数据，然后生成报告，再发送给相关人员
```

分步骤提问（推荐）：

```
步骤1：请帮我分析这个销售数据，生成统计结果。
步骤2：根据分析结果，帮我生成一份分析报告。
步骤3：帮我将报告转换为适合邮件发送的格式。
```

#### 迭代优化

如果第一次结果不满意，可以迭代优化：

第一次提问：

```
请帮我写个产品文案
```

优化提问：

```
上次的文案有点太正式了，请帮我重新写一个，风格要轻松活泼一些，更贴近年轻人的表达方式。
```

#### 多版本生成

要求生成多个版本，从中选择最好的：

单版本（不推荐）：

```
帮我写个文案
```

多版本（推荐）：

```
请帮我写3个不同风格的产品文案：
1. 专业风格
2. 幽默风格
3. 温馨风格
```

### 案例示例

#### 案例：模糊 vs 清晰

对比模糊表达和清晰表达的效果：

场景：需要写一个会议通知

模糊表达：

```
帮我写个会议通知
```

AI 可能的回复：

```
好的，请问会议的主题、时间、地点、参会人员分别是什么？
```

清晰表达：

```
请帮我写一个会议通知，会议主题是"项目进度汇报"，时间是2024年1月20日14:00-16:00，地点是3楼会议室A，参会人员是项目组全体成员，会议议程包括：各模块进度汇报、问题讨论、下周计划。语气要正式、专业。
```

AI 的回复：

```
【会议通知】

各位同事：

兹定于2024年1月20日14:00-16:00在3楼会议室A召开项目进度汇报会。

会议议程：
1. 各模块进度汇报
2. 问题讨论
3. 下周计划

参会人员：项目组全体成员

请各位准时参加。

行政部
2024年1月18日
```

#### 案例：无上下文 vs 有上下文

对比有无上下文的效果：

场景：需要回复客户邮件

无上下文：

```
帮我写个回复邮件
```

AI 可能的回复：

```
好的，请问需要回复什么内容？收件人是谁？
```

有上下文：

```
请帮我写一封回复邮件。背景：客户王先生昨天发邮件询问我们的产品是否支持批量导入功能。我们的产品目前不支持这个功能，但计划在下个版本中实现。请回复客户，告知这个情况，同时感谢他的反馈，并表示会通知他功能上线的时间。
```

AI 的回复：

```
尊敬的王先生：

您好！

感谢您对我们产品的关注和反馈。

关于您询问的批量导入功能，目前我们的产品暂不支持此功能。不过，我们非常重视您的需求，已将此功能列入开发计划，预计在下个版本中实现。

一旦该功能上线，我们会第一时间通知您。再次感谢您的宝贵反馈，这帮助我们不断改进产品。

如有其他问题，欢迎随时联系我们。

祝好！

[你的姓名]
[你的职位]
[公司名称]
```

### 小技巧

1. 使用结构化表达：用编号、列表等方式组织你的需求

2. 明确优先级：如果有多个要求，说明哪些是必须的，哪些是可选的

3. 提供约束条件：说明字数限制、格式要求等约束条件

4. 说明期望结果：描述你期望得到什么样的结果

5. 保持耐心：如果第一次结果不理想，可以调整需求，再次尝试

6. 记录好的提示词：将效果好的提示词记录下来，方便下次使用

现在，试着用清晰的方式向 Claude Code 提问吧！

## 8.2 常用提示词模板

使用提示词模板可以快速获得高质量的回复。以下是一些常用的提示词模板，你可以根据实际情况调整使用。

### 产品描述模板

```
请帮我写一段产品描述文案。

产品信息：
- 产品名称：[产品名称]
- 产品类型：[产品类型]
- 主要功能：[功能1]、[功能2]、[功能3]
- 目标用户：[目标用户]
- 产品特点：[特点1]、[特点2]、[特点3]

文案要求：
1. 突出产品的核心卖点
2. 语言生动有趣，吸引目标用户
3. 字数在[字数]左右
4. 风格要求：[风格]
5. 包含行动号召
```

### 广告文案模板

```
请帮我写一个广告文案。

广告信息：
- 产品/服务名称：[名称]
- 主要卖点：[卖点1]、[卖点2]、[卖点3]
- 目标用户：[目标用户]
- 广告类型：[广告类型，如促销广告、品牌广告等]
- 推广渠道：[渠道，如朋友圈、小红书、抖音等]

文案要求：
1. 吸引眼球，有创意
2. 突出产品/服务的独特性
3. 符合推广渠道的特点
4. 包含明确的行动号召
5. 字数在[字数]左右
```

### 社交媒体内容模板

```
请帮我写一个[平台]文案。

内容信息：
- 内容主题：[主题]
- 目标用户：[目标用户]
- 发布目的：[目的，如种草、分享、互动等]
- 风格要求：[风格，如温馨、幽默、专业等]

文案要求：
1. 符合[平台]的特点和用户习惯
2. 语言生动有趣，易于传播
3. 包含相关的话题标签
4. 字数在[字数]左右
5. 包含适当的表情符号
```

```
邮件要求：
1. 主题明确，简洁有力
2. 内容清晰，逻辑清楚
3. 语气得体，符合邮件类型
4. 包含必要的行动号召
5. 格式规范，易于阅读
```
