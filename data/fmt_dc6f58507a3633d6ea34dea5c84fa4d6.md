## 免费开源教材

1. **《言语和语言处理》（Speech and Language Processing）第 3 版**：`https://web.stanford.edu/~jurafsky/slp3/`。NLP 领域的经典圣经级教材，作者是斯坦福大学的 Dan Jurafsky 和 James H. Martin，官网免费开源 `https://web.stanford.edu/~jurafsky/slp3/`。内容全面覆盖 NLP 基础概念、统计方法、深度学习模型等，从传统的语法分析、语义理解到现代的 Transformer 架构都有详细讲解，既有理论深度又配有案例，适合系统性搭建 NLP 知识体系。

1. **《神经网络方法在自然语言处理中的应用》**：Yoav Goldberg 编写的开源教材，可通过 `http://u.cs.biu.ac.il/~yogo/nnlp.pdf` 免费获取。专注于深度学习与 NLP 的结合，内容从基础神经网络讲起，逐步深入到 RNN、CNN 在文本任务中的应用，讲解精炼，适合已经掌握基础 NLP 知识，想转向深度学习 NLP 方向的入门者。

1. **《NLTK 官方配套教材》**：作为 Python NLP 入门库 `NLTK` 的官方教程，在线地址 `http://www.nltk.org/book/`。教材以实操为导向，每章节都搭配 `NLTK` 库的代码案例，涵盖分词、词性标注、文本分类等基础操作，代码可直接复制运行，能帮助新手快速掌握 NLP 基础工具的使用，衔接理论与实操。

1. 开源 NLP 入门书籍（兜哥出品）：采用 GitHub 开放式写作的中文开源教材，聚焦实用 NLP 技能。内容包含词袋模型、TF-IDF、Word2Vec 等核心模型，还有中文分词、情感分析等贴合中文场景的案例，同时讲解了 NLP 工具箱构建和数据集使用，适合零基础且偏好中文教程的学习者，内容贴近实际应用场景。

## 核心工具与官方文档

1. `NLTK`：Python 中最经典的 NLP 入门库，官网 `http://www.nltk.org/`。文档包含详细的安装指南和入门教程，支持分词、停用词去除、词干提取等基础文本预处理操作，还有丰富的语料库可供调用。新手可通过其自带的交互式教程快速熟悉 NLP 基础流程，是入门阶段必学的工具。

1. `spaCy`：适合工业级应用的 Python NLP 开源库，官网 `https://spacy.io/`。文档自带炫酷的用法示例和 API 说明，支持高效的文本处理、实体识别、依存句法分析等功能。相比 `NLTK`，`spaCy` 处理速度更快，接口更简洁，官网的案例涵盖新闻文本分析、文本相似度计算等，适合学习基础操作后尝试更贴近实际场景的开发。

1. `HanLP` 官方文档：由《自然语言处理入门》作者何晗开发的中文 NLP 开源库，官网 `https://hanlp.hankcs.com/`。文档针对中文 NLP 场景优化，提供分词、词性标注、命名实体识别等功能的详细教程，还有大量中文语料库和预训练模型可供调用，解决新手在中文文本处理中遇到的适配问题，且支持 Python 调用，入门友好。

## 优质免费视频课程

1. 斯坦福 CS224d：深度学习与自然语言处理：适合想衔接深度学习与 NLP 的学习者，课程视频可在 YouTube 搜索观看。内容涵盖词嵌入、循环神经网络、注意力机制等核心知识点，搭配课后作业和项目，能帮助新手理解深度学习模型在文本任务中的底层逻辑，不过建议先具备基础的 Python 和深度学习知识。

1. Dan Jurafsky & Chris Manning 的 NLP 系列视频：发布在 YouTube 上的免费入门视频。两位作者作为 NLP 领域权威，讲解风格通俗易懂，从语言基础概念切入，逐步过渡到 NLP 核心算法，适合零基础者初步了解 NLP 的研究范畴和核心问题，搭配他们的开源教材学习效果更佳。

1. Coursera《自然语言处理简介》：由密歇根大学开设的入门课程，可在 Coursera 平台学习，支持免费旁听。课程内容侧重 NLP 基础应用，涵盖文本分类、情感分析等常见任务，案例贴近实际，讲解节奏平缓，适合利用碎片化时间系统学习 NLP 入门知识。

## 入门实战仓库与数据集

1. NLP 入门实战代码库（chenyuntc）：可参考 GitHub 上各类 NLP 入门实战仓库，例如基于 `PyTorch`/`TensorFlow` 实现简单文本分类、词嵌入的项目。这类仓库代码简洁，注释详细，涵盖从数据预处理到模型训练的完整流程，新手可模仿代码理解 NLP 项目的开发逻辑。

1. **GLUE 基准数据集**：NLP 领域常用的通用评估数据集，包含文本相似度、情感分析等多个子任务，适合新手测试自己的模型效果。可通过官方渠道免费获取数据，搭配深度学习框架实现基础模型，熟悉 NLP 主流任务的评估方式。

1. **中文 NLP 公开数据集**：如 THUCNews 中文新闻数据集、中文情感分析数据集等，可用于中文分词、文本分类等实战。新手可借助这些数据集，结合 `HanLP` 或 `jieba` 库，动手实现中文文本预处理和简单分类模型，强化中文 NLP 实操能力。
