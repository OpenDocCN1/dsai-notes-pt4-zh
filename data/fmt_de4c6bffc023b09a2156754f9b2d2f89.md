## 六、最佳实践与高级技巧

![](img/fa1c36696cedb3ffbe85d15c78f981c1.png)

### ✅ 最佳实践清单

#### 资源选择最佳实践

+   优先使用原始文献和官方文档

+   避免混杂多个主题的资源

+   保持资源的时效性（特别是技术、新闻类）

+   对于学术研究，选择同行评审的论文

#### 提示词设计最佳实践

+   **明确指定角色/人设**：例如"作为一位数据科学家..."

+   **清晰定义输出格式**：指定使用表格、列表或段落

+   **设置限制**：指定字数、要点数量等

+   **举例说明**：给出期望输出的示例

+   **避免歧义**：使用具体词汇而非模糊描述

#### 工作流程最佳实践

+   先用`Mind Map`理解全局，再深入细节

+   `Audio Overview`用于快速复习，`Deep Dive Chat`用于精细理解

+   在创建`Quiz`之前先完成`Flashcards`学习

+   定期导出重要的笔记和报告作为备份

#### 协作最佳实践

+   为共享Notebook添加清晰的描述

+   使用标准化命名规范：[项目名]-[主题]-[版本号]

+   为他人创建`Public Notebook`时，选择`Chat only`共享模式

+   定期更新资源，保持信息最新

### 🚀 高级技巧

#### 技巧1：链式提示法（Prompt Chaining）

不依赖一个复杂提示，而是进行多个对话：

```
第一条：请分析这个资源中的三个关键观点。
[获取回复]
第二条：对于观点1，批判性评价其说服力。
[获取回复]
第三条：这三个观点中是否存在矛盾？如何调和？
```

#### 技巧2：迭代优化

+   第一次查询获取初始回复

+   基于反馈调整提示词

+   逐步完善，直到满足需求

#### 技巧3：多角度分析

```
使用自定义Instructions轮流切换视角：
- 批评者的角度
- 支持者的角度
- 实践者的角度
- 理论家的角度
对同一话题进行多轮分析
```

#### 技巧4：内容复用

+   用一份资源生成多种格式（音频+视频+文本）

+   将生成的闪卡导出创建自己的学习平台

+   将报告转化为博客文章、演讲稿等

#### 技巧5：质量控制

+   生成后一定要校对，特别是引用

+   使用`Deep Dive Chat`验证facts

+   对于重要的学术工作，交叉验证信息来源

#### 文学与人文学科

## 七、常见问题解答（FAQ）

![](img/3ec3202d8bd587db7481bd93d29e51db.png)

### Q1：NotebookLM会用我的数据训练AI吗？

**A：** 不会。您的个人数据永不用于训练NotebookLM。Google承诺保护您的数据隐私。

### Q2：我能离线使用NotebookLM吗？

**A：** 不能。NotebookLM需要在线使用。但您可以下载生成的内容（音频、视频、文档）离线使用。

### Q3：`Audio Overview`能否选择特定风格？

**A：** 是的。有4种格式选择：`Podcast`、`Brief`、`Teacher`、`Friend`。Plus版本有更多自定义选项。

### Q4：能否限制AI只基于我的资源回答？

**A：** 是的。这是NotebookLM的默认设置——所有回答都仅基于您上传的资源，从不使用外部数据。

### Q5：生成的`Video Overview`能否编辑？

**A：** 目前不能编辑生成的视频，但您可以：

+   重新生成不同风格的版本

+   修改自定义指令后重新生成

+   导出后用视频编辑软件处理

### Q6：能否将Notebook分享给特定人员？

**A：** 可以。创建后选择"分享"，可设置为：

+   特定人员（需Google账号）

+   公开链接（任何人可访问）

+   Chat-only（只能提问，不能编辑）

### Q7：`Deep Research` 有哪些限制？

**A：**

+   在Plus版本中优先级更高

+   某些受限制的网站可能无法访问

+   结果质量取决于查询的清晰度

### Q8：如何删除Notebook？

**A：** 在Notebook菜单中找到"删除"选项。注意：删除不可撤销。

### Q9：能否设置Notebook密码保护？

**A：** 目前不支持密码保护。但您可以不分享链接来保持隐私。

### Q10：支持哪些语言？

**A：** 超过80种语言。您可以上传多种语言的资源，选择输出语言。

```

### 3️⃣ 深度理解助手（学完一章后使用）

```
我需要深入理解[概念]。

请从这5个角度分析：
1. 是什么？（定义和基本特征）
2. 为什么？（产生的原因和必要性）
3. 如何用？（3-5个实际应用例子）
4. 反面是什么？（相反或对立的概念）
5. 和什么相关？（与其他概念的联系）

每个角度用1段话解释，加1个具体例子。
```

### 4️⃣ 从失败中学习（反向学习法）

```

1. 指出哪些原来看似有理的论点其实有漏洞？
2. 提供哪些证据或经历改变了他的看法？
3. 如何重新解读资源中之前支持该观点的部分？
4. 这个反方观点教给我们什么新东西？

目的：建立更全面、更批判性的理解
