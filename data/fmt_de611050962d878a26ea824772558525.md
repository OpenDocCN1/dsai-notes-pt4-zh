## 1.4 阵营二：本地安装产品详解

本地安装阵营的核心卖点是**数据不出门**——AI 跑在你自己的电脑上，对话内容、操作记录全部留在本地。对于在意隐私的用户来说，这一点比什么功能都重要。

### QClaw（腾讯电脑管家）

QClaw 是整个衍生生态中最有"群众基础"的产品。原因很简单——它打通了🛰️。在中国互联网，这三个字的分量不需要多解释。

> 🔗 官网：`https://qclaw.qq.com`

**核心卖点**：

+   **🛰️零配置绑定**：直接在🛰️聊天框操控电脑——手机发一条"帮我找上周的报告"，电脑就开始执行。14 亿🛰️用户可触达的 AI 助手入口

+   **🐧 双端接入**：同时支持 🐧 通道

+   **一键安装包**：下载后双击即用，不需要 `Node.js`、`npm`，什么技术栈都不用装

+   兼容 ClawHub 5,000+ 技能：OpenClaw 生态的大部分技能开箱即用

**与 OpenClaw 的关系**：基于 OpenClaw 框架的上层封装，不是独立开发。底层保留了 OpenClaw 核心的全部功能，但在上面加了一层精心打磨的产品体验。

**定价**：完全免费。目前内测邀请制。

QClaw 最核心的竞争力不在技术层面，而在场景洞察。"用🛰️远程控制电脑"这个需求，对出差族、远程办公者来说极为刚需——出差在外想找电脑上的文件，🛰️发一条消息就搞定；想在手机上让电脑跑个脚本，🛰️发一条命令即可执行。这种"通过🛰️远程操控电脑"的体验，目前没有第二个产品能做到。

不足之处在于闭源（无法审计底层代码），且目前仍需要邀请码才能使用。

### WorkBuddy（腾讯）

> 🔗 官网：`https://codebuddy.cn`

WorkBuddy 是腾讯的另一款产品，和 QClaw 形成了清晰的 C 端 + B 端双线布局：

| 维度 | QClaw | WorkBuddy |
| --- | --- | --- |
| **面向** | C 端个人用户 | B 端企业用户 |
| **核心场景** | 🛰️控制个人电脑 | 企业办公自动化 |
| **核心 IM** | 🛰️/🐧 | 企业🛰️/飞书/钉钉 |
| **差异化能力** | 🛰️直联 | 多 Agent 并行、企业安全审计 |

**WorkBuddy 核心卖点**：

+   **多 Agent 并行**：多窗口、多 Agent 同步工作，复杂任务动态拆解

+   **20+ 内置办公技能**：海报生成、自动化报表、会议纪要整理等——专为企业办公场景设计

+   **企业 IM 全覆盖**：企业🛰️、飞书、钉钉三大平台都支持

+   **企业安全审计**：具备权限管控能力，适合有合规要求的企业

+   下载即送 5,000 Credits：零成本开始体验

对于企业环境的办公自动化需求，WorkBuddy 比 QClaw 更为合适。多 Agent 并行在处理复杂办公任务（比如同时做数据分析+生成报告+发送邮件）时效率很高。需要注意的是，WorkBuddy 是腾讯的独立产品，非 OpenClaw 直接 fork，兼容 OpenClaw Skills 但底层架构有差异。

### AutoClaw（智谱 AI）

AutoClaw（别名"澳龙"）是智谱 AI 的作品，主打两个字：简单。

> 🔗 官网：`https://autoglm.zhipuai.cn/autoclaw`

**核心卖点**：

+   **"首个真正一键安装"**：Windows/macOS，双击即用，号称 1 分钟内开始使用——实测确实做到了

+   **AutoGLM 浏览器自动化**：这是 AutoClaw 最独特的能力——AI 像人类一样操作浏览器。不是通过 API 调用，而是真的在浏览器里点击、输入、滚动，能导航网页、填写表单、提取数据。这项能力来自智谱的 AutoGLM 技术，目前在衍生产品中独此一家

+   **Pony-Alpha-2 模型**：基于 GLM-5 的专有优化版本，专门为 Agent 场景调优

+   **50+ 预构建技能**：内容创作、办公自动化、代码生成

+   **完全免费**：$0，无条件免费

AutoClaw 有两个不可替代的优势——AutoGLM 浏览器自动化和完全免费。如果你的需求涉及大量浏览器操作（批量采集数据、自动填写表单、网页端重复操作自动化），AutoClaw 是目前的最佳选择，没有之一。

### Molili / 莫哩哩（当贝）

Molili 是国内首个基于 OpenClaw 深度定制的公测产品（注意：是公测不是内测——谁都能用，不需要邀请码）。

> 🔗 官网：`https://molili.dangbei.com`

**核心卖点**：

+   **VLA 模型核心**（Vision-Language-Action）：能"理解屏幕"和"操控软件"——看到你屏幕上显示的内容，然后像人一样操作。和 AutoClaw 的浏览器自动化不同，Molili 的 VLA 能力覆盖所有桌面软件，不限于浏览器

+   **CocoLoop 技能市场**：官方 + 社区双层技能分发

VLA 模型的"屏幕理解+操控"方向很有前景——理论上不需要任何 API 接口，AI 直接"看"屏幕就能操作任何软件。不过当贝在行业内影响力有限，产品的持续投入和生态丰富度需要时间验证。

## 1.5 阵营三：开源 / 自部署产品详解

开源阵营是技术人员的天堂——代码公开可审计，想怎么改就怎么改，想部署在哪就部署在哪。当然，代价是需要一定的技术能力。但回报也很丰厚：你对整个系统拥有完全的掌控权。

### `openclaw-cn`（中文社区版）

`openclaw-cn` 是最"正统"的中文版——它直接 fork 自原版 OpenClaw，定期同步上游更新，保留全部功能，只做三件事：中文化、网络优化、IM 适配。

> 🔗 GitHub：`https://github.com/jiulingyun/openclaw-cn`

**核心卖点**：

+   **完整中文化**：CLI / Web 界面 / 配置向导 / 报错信息全部中文

+   **国内网络优化**：所有 GitHub 依赖重新打包为 `npm` 包，支持淘宝镜像安装——解决"`npm install` 半天装不完"的老大难问题

+   **内置国内 IM**：飞书、钉钉、企业🛰️、🐧——开箱即用

+   **非阉割版**：原版有什么它就有什么。它不是"精简版"或"国产替代"，而是原版 OpenClaw 的中文翻译版

+   GitHub 4,300+ Stars，v0.1.8（2026-03-09）

安装只需一条命令：

```
npm install -g openclaw-cn@latest
# 或使用淘宝镜像（国内速度更快）
npm install -g openclaw-cn@latest --registry=https://registry.npmmirror.com
```

如果你想用原版 OpenClaw 的完整功能，但不想折腾网络问题——`openclaw-cn` 是首选。它不是"国产替代"，它就是原版 OpenClaw 的中文版。对于想在 OpenClaw 生态中做工业级部署的用户，这是我们的第一推荐。

### `LinClaw`（七牛云）

`LinClaw` 是国产衍生中**唯一完全 MIT 开源**的独立项目（`openclaw-cn` 是 fork，严格说协议继承自原版）。

> 🔗 GitHub：`https://github.com/AI-Hub-Growth/linclaw`

**核心卖点**：

+   **MIT 开源**：代码完全可审计、可二次开发、可私有化部署——对有代码安全审计要求的企业来说，这是唯一合格的选项

+   **9 大渠道**：钉钉、飞书、🐧、🛰️、Telegram、Discord、Slack、iMessage、Web——渠道数量在所有衍生产品中最多

+   **可视化管理面板**：不用纯命令行操作，降低了运维门槛

+   **私有化企业部署**：一次部署，全渠道可用

`LinClaw` 的核心价值在于"开源 + 全渠道"。如果你的企业需要同时接入多个 IM 平台（比如既有钉钉又有飞书又有 Telegram），且对代码安全性有要求（需要过合规审计），`LinClaw` 几乎是唯一的选择。GitHub Star 数虽然较少、社区处于早期阶段，但这不影响产品本身的质量。

### `CoPaw`（阿里通义）

`CoPaw` 是个"特殊选手"——它不是 OpenClaw 的 fork，而是阿里通义实验室基于自研的 AgentScope 框架独立开发的产品，对标 OpenClaw。

> 🔗 GitHub：`https://github.com/agentscope-ai/CoPaw`

**核心卖点**：

+   Apache 2.0 开源可商用：比 MIT 协议对商用授权的描述更明确——企业法务更放心

+   **钉钉/飞书原生集成**：比 OpenClaw 原版的配置简单许多

+   **端云双模式**：本地部署和云端部署自由选择，一套代码两种运行方式

+   Python + TypeScript 混合栈：72.8% Python + 22.2% TypeScript——对 Python 开发者更友好

`CoPaw` 的优势在于阿里的背书和钉钉原生集成。对于钉钉办公的团队，`CoPaw` 的接入体验会比 OpenClaw 更为平滑。但一定要注意一个关键区别——`CoPaw` 不兼容 OpenClaw 的 ClawHub 技能生态，这意味着 13,000+ 的 Skills 你用不了。如果你很依赖 ClawHub 生态，`CoPaw` 就不适合你。
