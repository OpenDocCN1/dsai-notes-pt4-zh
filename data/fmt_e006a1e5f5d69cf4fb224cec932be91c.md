+ 计划规则已展示，赛事介绍页和详情链接已提供，目前已有11领先有9分的共创积分。

#### 2、`mobile agent`技术解读

+ `mobile agent`技术理念是通过视觉大模型判断手机屏幕上的信息，并产出决策。

+ 技术关键环节包括获取手机信息、决策生成和决策失败后的修改。

+ 信息获取通过`ADB`工具连接手机，`OCR`工具提高信息识别精度，多模态大模型对图标进行描述。

+ 决策生成通过调用`ADB`实现原子操作，如截图、滑动等，大模型根据任务需求生成具体参数。

#### 3、`mobile agent`应用场景

+ 讨论了`mobile agent`在手机端的应用场景，如社交、购物、信息获取等。

+ 提出了通过大模型辅助用户进行👸号订阅、点赞等操作的想法。

+ 讨论了通过大模型优化手机拍照技术，如自动调整参数和切换滤镜。

#### 4、大模型与手机操作交互

+ 大模型输出操作内容，如`home`操作，会被解析并交给`ADB`实现。

+ 大模型输出操作后，会返回包含当前操作结果的提示。

+ 大模型返回的提示中包含操作结果和后续操作目的，帮助大模型判断操作是否合理。

#### 5、大模型与手机操作的决策过程

+ 大模型决策过程包括获取当前信息、判断操作、生成决策提示词。

+ 决策提示词会交给大模型，大模型根据提示词生成操作。

+ 决策结果会保存，影响后续操作和反思。

#### 6、大模型与手机操作的反思与计划

+ 反思过程包括判断操作是否成功，生成决策结果。

+ 决策结果会影响下一次操作，帮助提升操作精确度。

+ 计划部分包括根据决策结果调整操作，优化信息处理。

#### 7、`OCR`识别速度问题

+ `OCR`识别速度较慢，市面上已有算法能提高识别速度，但具体实现细节未详细讨论。

+ `OCR`识别的定义由讲者决定，识别出的点都是可点击的。

#### 8、`OCR`和决策模型优化

+ `OCR`结果可能不准确，决策效果不佳，需要优化。

+ 决策模型需要更多先验知识，如图标识别。

+ `ADB`工具可以用于操作手机，简化操作流程。

#### 10、`mobile agent`开发问题
