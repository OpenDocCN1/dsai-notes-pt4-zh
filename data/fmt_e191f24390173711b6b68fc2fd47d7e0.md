#### OPC 能力体系分层

##### 基础能力层

核心能力构成：包括 PDF、PPT 生成、Excel 信息处理、Web 搜索等日常通用办公核心能力，可将手动信息处理优化为自动化处理，释放大量时间。

实际应用场景：如用 do Mate 拆解 PDF 并转化为课程素材；整理凌乱文件夹，它能自动识别文件内容并分类整理；将视频写成逐字稿，帮助用户把更多精力放在选题和表达上。

![](img/5d4ac4007318f487155f64befa3dfba7.png)

##### 进阶能力层

能力核心特点：核心是能力的复制和放大，通过一次搭建可反复使用系统能力。do Mate 内置多种 skill，如百度 AI 生成动态绘本、百度百科搜索、邮箱、深度研究、学术搜索、视频解析等，可将一次性工作变成可反复调用的能力。

具体应用案例：制作个人说明书网页，输入个人信息和风格要求，do Mate 能快速生成；拆解爆款视频，利用 AI Notes for video skill 能力，可自动拆解视频并生成分析报告；进行电商数据分析，输入 Excel 表格，do Mate 能对不同电商的 SKU 数据进行分析，生成数据看板和报告；开发应用，通过许愿式方法，如让 do Mate 做一个播客生成器，它能与秒哒应用生成平台打通，快速生成并上线应用。

##### 个性化能力层

能力关键作用：决定每个 OPC 之间的上限，将个人经验转化为系统能力，通过创建专属 skill 拉开与他人差距。

skill 创建与应用：可选中技能 skill Creator，向 do Mate 提出创建需求，如创建用于页面美化的 skill，设置风格、图标等要求。创建的 skill 不仅可给 Duemate 使用，还能给 Openclaw 等支持调用 skill 的能力使用。同时，do Mate 提供 skill fatal 能力，可在安装 skill 前进行安全审计。用户还可通过链接或本地文件方式导入 skill，并对其进行优化迭代。

### 用户问题解答与总结建议

#### 用户问题解答

生成视频费用：目前生成视频作为技能能力，扣费未显示，每天登录送 1000 积分，银海老师演示使用仅消耗 70 积分，用户可放心畅玩。

视频自动生成与全流程自动化：do Mate 有官方提供的视频生成能力，也可通过创建不同 skill 能力接入视频生成 API 实现自动生成。对于运营全流程自动化，文本、图像、视频生成没问题，但自动化发布有风险，如👸号可推到草稿箱人工再审，📕和抖音风险较大。

接入其他平台大模型：目前 do Mate 不能直接切换不同模型，内置模型处理效果不错。若想使用其他平台模型，可自己写 skill 能力调用。

上下文记忆能力：do Mate 会遗忘，但官方称其记忆能力越用越懂，可记住用户偏好信息。

手机操作与接入飞书：do Mate 只有电脑端桌面应用，无手机端。可将飞书多维表格作为技能接入 do Mate 进行调用。
