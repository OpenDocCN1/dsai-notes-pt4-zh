## 一、有话题的新闻

1、Google 开始向所有 Chrome 用户推送隐私沙盒 API

随着 Chrome 115 的发布，Google 宣布开始向所有 Chrome 用户启用隐私沙盒相关 API。隐私沙盒（Privacy Sandbox）将取代第三方 Cookie，它跟踪用户的兴趣，允许广告商根据兴趣展示广告，而用户可以管理兴趣并对其归类分组。隐私沙盒代表着广告行业的一次巨大变化。Chrome 115 标志着隐私沙盒相关的 API GA（普遍可用），开发者可对其进行测试。Google 的目标是到 8 月底对 99% 的用户启用隐私沙盒相关 API，第三方 Cookie 将会继续保留一段时间。从 2024 年开始，Google 将对 1% 的 Chrome 用户禁用第三方 Cookie，然而到 2024 年底完全淘汰第三方 Cookie。（@techcrunch）

2、谷歌、微软等“七巨头”发声：自愿承诺 AI 监管八项措施

当地时间 7 月 21 日，包括谷歌、微软、OpenAI、亚马逊、Meta、Anthropic、Inflection 在内的七家顶级人工智能公司在白宫召开会议。这些企业的高管承诺，将为消费者创建识别生成式人工智能的方法，并确保在生成式人工智能工具发布前，会测试其安全性。（第一财经）

3、Meta CTO 否认取消 Quest Pro 系列，仍在开发多个原型头显

据外媒爆料，Meta 公司已经停止了 Quest Pro 的生产，并且取消了未来的“Pro”系列XR硬件的计划。不过，Meta 公司的 CTO（首席技术官）却否认了这一说法，称“不要相信你看到的一切。”（@IT之家）

4、推特改名 X 宣布打造可以交付一切的超级 app

北京时间 7 月 23 日，马斯克在个人推特上发布帖子称，不久，我们将告别推特品牌，并逐渐告别所有「鸟类」。如果今晚能有足够好的「X」标志，我们明天将在全球范围内发布。

北京时间 7 月 24 日早，马斯克在个人推特上发布帖子称，用户现在登陆 `X.com` 就能指向推特网站。（`twitter.com` 也能登陆网站。）而后北京时间 4:33 分，推特首席执行官琳达·亚卡里诺（Linda Yaccarino）正式在个人推特上宣布品牌改名的计划，同时宣布改名本身是 X 向超级 app 转型的号角。

「X 是无限交互的未来状态——以音频、视频、消息、支付/银行为中心——创建一个创意、商品、服务和机会的全球市场。在人工智能的支持下，X 将以我们刚刚开始想象的方式连接我们所有人。... X 将成为一个可以交付一切的平台。@elonmusk 我期待与我们的团队和每一位合作伙伴合作，将 X 推向世界。」

马斯克一直有想建设超级 app X 的想法。今年四月，马斯克曾一度将推特官网的经典「蓝鸟」图标，改成狗狗币的柴犬图案，还暗示过狗狗币有引进推特支付的可能性。今年 7 月，美国新罕布什尔州、密歇根州、密苏里州批准了推特的货币转移服务商牌照申请，使得建设超级 app 的愿景推进一大步，这可能是目前推特改名 X 的一大动因。（@极客公园）

5、B 站内测大模型驱动的搜索助手功能

7 月 23 日消息，本月初，哔哩哔哩面向部分用户推出了“搜索 AI 助手”功能，现可通过官方 App 进行申请，也可以在 App 内直接搜索“搜索 AI 助手”或者“AI 助手”找到这一入口并申请内测资格。根据 B 站用户反馈，一般几天内就可以通过申请。通过申请后，用户可以在 App 内的搜索框通过输入想要的词条进行搜索，搜索 AI 助手会生成对应的文字回答，并列出参考了哪些视频内容，甚至还会分析给出所参考的视频内容。据介绍，该功能由 bilibili index 大模型提供技术支持。（@IT之家）

6、索尼云游戏掌机 Project Q 运行视频泄露

![](img/ac1f9fbfb11c2997896630a562c299f1.png)

索尼官方对 Project Q 的描述为：Project Q 是今年晚些时候推出的一款专用设备，它可以让你通过 Wi-Fi 使用 Remote play 来玩安装在 PS5 主机上的任何兼容游戏。7 月 23 日消息，新掌机工程样机运行视频被泄露。从视频看，Project Q 似乎运行在安卓系统上。这款 8 英寸液晶显示屏的分辨率高达 1080p，帧率为 60fps。如果 Project Q 真的在安卓上运行，那么索尼的 Project Q 就可以被认为是罗技 G Cloud 或 Abxylute 等设备的可行替代品。然而，据 Tom Henderson 透露，索尼 Project Q 的电池续航时间约为 3 到 4 个小时。相比之下，罗技 G Cloud 宣传的续航超过 12 小时，而 Abxylute 的游戏时间超过 8 小时。Project Q 的优势在于，它配备了一个功能齐全的 DualSense 无线控制器，具有所有按钮和功能，包括自适应触发器和触觉反馈。然而，这些功能只会在串流 PS5 游戏时有用。（@cnBeta）

## 二、有态度的观点

1、王小川：国内开源模型的能力目前已经可以达到 LLaMa

在极客公园 AGI Playground 论坛上，王小川回应了外界对百川智能开源模型 Baichuan-7B 套壳 Meta 开源模型 LLaMa 的质疑。他表示，搜索公司干了 20 年，团队对语言数据有深入的理解，知道取得高质量语料的渠道，模型迭代速度很快：国内开源模型的能力目前已经可以达到 LLaMa。同时，他也预告，百川智能在未来几个月内将首次发布闭源大模型。今年，搜狗公司创始人王小川创立人工智能公司「百川智能」，一家研发并提供通用人工智能服务的中国公司，旨在打造中国版的 OpenAI。

2、英特尔 CEO：若无中国订单，全球最大芯片制造基地也没必要建了

据外媒报道，7月17日，英特尔、高通和英伟达三大芯片巨头的首席执行官（CEO）与布林肯国务卿等美高官在华盛顿举行了会议，试图游说拜登政府重新考虑对华半导体的限制政策，美国商务部长吉娜·雷蒙多、国家经济委员会主任莱尔·布雷纳德和国家安全委员会主任杰克·沙利文等政府官员均参与了与英特尔、高通和英伟达的CEO的会晤。彭博社21日报道，英特尔CEO帕特·基辛格（Pat Gelsinger）在17日的会上告诉美官员，针对中国的限制政策不但没有达到预期效果，却反而会限制美企在华的业务。他甚至警告说，“如果没有来自中国的订单，英特尔在俄亥俄州建设‘全球最大芯片制造基地’的计划就没啥必要了。”

## 三、有思考的文章

1、《周鸿祎：我的大模型产品方法论》

大模型是短暂的风口还是工业革命？是操作系统还是个人电脑？是原子弹还是 Ak47？自大模型去年强势进入人们的视野以来，人们在试图理解大模型的过程中，不断为大模型添加不同的比喻。

不同的创业者对此也有着不同的答案。

7 月 23 日，在极客公园主办的 AGI Playground 大会上，360 集团创始人，也是通过自研通用大模型「360 智脑」亲自下场，参与了本场大模型创业浪潮的周鸿祎给出了自己的答案。周鸿祎一向以十分敢说而著名，本场演讲中更是金句频出：「创业需要把大模型拉下神坛。」「不要等到大模型无所不能才开始做，只要想清楚了就可以开始干了。」「在企业里面做大模型，我们要忘掉 ChatGPT 这个榜样。」

周鸿祎在演讲中表示，大模型是一场五到十年的风口，有引发一场新的工业革命的潜质。而大模型的未来绝对不像曼哈顿计划，是尖端科学家和几亿人民币才能训练出的原子弹，而一定像是 AK47，价格便宜，火力足，分量够。而在周鸿祎眼中，创业者目前最好的「瞄准技巧」就是面向 B 端市场。

周鸿祎谈到，「现在创业者应该做什么？做垂直大模型。我们讲创业方法论，创业团队要算力没算力，要钱也不够多，要人才也不够厚。跟这些巨头竞争相比，你唯一的机会是把你所有的资源聚焦在一根针上，才能形成非常大的压强。垂直大模型，是创业者的『金光大道』。」本文是周鸿祎在 AGI Playground 大会上的演讲全文，经极客公园节选整理。（@极客公园）

2、《树莓派上运行 Stable Diffusion，260MB 的 RAM「hold」住 10 亿参数大模型》（@机器学习研究组订阅）

11 个月前 Stable Diffusion 诞生，它能够在消费级 GPU 上运行的消息让不少研究者备受鼓舞。不仅如此，苹果官方很快下场，将 Stable Diffusion「塞进」iPhone、iPad 和 Mac 中运行。这大大降低了 Stable Diffusion 对硬件设备的要求，让其逐渐成为人人都能使用的「黑科技」。现在，它甚至已经可以在 Raspberry Pi Zero 2 上运行了。

这是怎样一个概念？运行 Stable Diffusion 并不是一件容易的事，它包含一个 10 亿参数的大型 Transformer 模型，建议使用的最低 RAM/VRAM 通常为 8GB。而 RPI Zero 2 只是内存为 512MB 的微型计算机。这意味着在 RPI Zero 2 上运行 Stable Diffusion 是一个巨大的挑战。而且，在运行过程中，作者没有增加存储空间，也没有将中间结果卸载到磁盘上。
