Blender MCP（Multi-Client Protocol）是一个开源项目，它允许你通过Cursor等工具远程控制和操作Blender。本教程将指导你完成从安装到配置的全过程，帮助你实现通过MCP协议与Blender进行交互。

---

## 准备工作

### 下载Blender MCP插件

首先，访问GitHub上的Blender MCP开源项目页面 https://github.com/ahujasid/blender-mcp。

在项目文件列表中，找到并下载`add-on.py`文件。这个文件将用于后续在Blender中设置MCP Server，请妥善保存。

### 安装Python（视情况而定）

> 注意：是否需要安装Python取决于你使用的MCP Server的编程语言。如果MCP Server是用Python编写的，你需要安装Python；如果是用C++或JavaScript等其他语言编写的，则不需要。

前往[Python官网](https://www.python.org/downloads/) https://www.python.org/

下载Python 3.10或更新版本。截至教程编写时，最新版本是Python 3.13.2，建议直接安装此版本。

### 安装UV包管理器

![](img/275d5b401b36dbcabfd75951b847fb46.png)

回到Blender MCP开源项目页面，你会看到针对不同操作系统的安装命令：

+ Mac系统：复制针对Mac的安装命令
+ Windows系统：复制针对Windows的安装命令

打开终端（Mac）或命令提示符（Windows），粘贴并运行该命令进行安装。

#### 如何打开终端（Mac）

1. 点击屏幕右上角的搜索图标
1. 输入"Terminal"或"终端"
1. 点击搜索结果中的终端应用

#### 如何打开命令提示符（Windows）

1. 按下Win+R键
1. 输入`cmd`
1. 点击确定

### 下载安装Blender

1. 访问[Blender官网](https://www.blender.org/)
1. 在顶部导航栏点击"Download"
1. 选择适合你电脑系统的Blender版本下载
1. 下载时可能会出现打赏页面，可以直接忽略，客户端会自动开始下载
1. 下载完成后，按照提示完成安装

## 配置过程

### 配置Blender MCP Server

**Blender下载链接：**https://www.blender.org/

![](img/54808c8273b7ad49ec2fc7299732aae6.png)

1. 打开Blender软件
1. 点击顶部导航栏的"编辑"(Edit)，然后选择"偏好设置"(Preferences)
1. 在偏好设置窗口左侧导航栏中，找到"插件"(Add-ons)
1. 点击"从磁盘安装"(Install from Disk)
1. 找到之前下载的`add-on.py`文件，选中并安装
1. 安装完成后，使用键盘快捷键"N"打开侧边面板
1. 在弹出的面板中选择"Blender"标签
1. 点击"Start MCP Server"按钮启动服务器

### 配置Cursor连接到MCP Server

**Cursor下载链接：**http://cursor.com/

1. 打开Cursor（如果尚未安装，请先下载并安装）
1. 点击"Settings"(设置)，然后选择"Cursor Settings"(Cursor设置)
1. 在左侧导航栏找到"MCP"选项
1. 点击"新增MCP Server"(Add MCP Server)
1. 回到Blender MCP开源项目页面，找到用于连接MCP Server的代码并复制
1. 将复制的代码粘贴到Cursor的编辑页面中
1. 关闭编辑页面并保存设置
1. 此时，Blender MCP选项应该显示绿灯，表示配置成功

![](img/2d75427609eb18af87c11e97e98eeebc.png)

> 提示：如果显示黄灯或红灯，请尝试关闭并重启Cursor。

## 常见问题解答

Q: 为什么我的MCP Server连接显示黄灯或红灯？

A: 请确保Blender中的MCP Server已正确启动，并尝试重启Cursor。有时网络问题也可能导致连接不稳定。

Q: 是否所有版本的Blender都支持MCP？

A: 建议使用较新版本的Blender，以确保与MCP插件的兼容性。

Q: 我可以同时连接多个支持MCP的应用吗？

A: 是的，Cursor支持连接多个MCP Server，只需为每个应用添加对应的连接配置即可。

## MCP Blender核心提示词

### 英文原版

```
When creating 3D content in Blender, always start by checking if integrations are available:

0. Before anything, always check the scene from get_scene_info()
1. First use the following tools to verify if the following integrations are enabled:
    1. PolyHaven
        Use get_polyhaven_status() to verify its status
        If PolyHaven is enabled:
        - For objects/models: Use download_polyhaven_asset() with asset_type="models"
        - For materials/textures: Use download_polyhaven_asset() with asset_type="textures"
        - For environment lighting: Use download_polyhaven_asset() with asset_type="hdris"
    2. Hyper3D(Rodin)
        Hyper3D Rodin is good at generating 3D models for single item.
        So don't try to:
        1. Generate the whole scene with one shot
        2. Generate ground using Rodin
        3. Generate parts of the items separately and put them together afterwards

        Use get_hyper3d_status() to verify its status
        If Hyper3D is enabled:
        - For objects/models, do the following steps:
            1. Create the model generation task
                - Use generate_hyper3d_model_via_images() if image(s) is/are given
                - Use generate_hyper3d_model_via_text() if generating 3D asset using text prompt
            2. Poll the status
                - Use poll_rodin_job_status() to check if the generation task has completed or failed
            3. Import the asset
                - Use import_generated_asset() to import the generated GLB model the asset
            4. After importing the asset, ALWAYS check the world_bounding_box of the imported mesh, and adjust the mesh's location and size
                Adjust the imported mesh's location, scale, rotation, so that the mesh is on the right spot.

                You can reuse assets previous generated by repeating step 3 and 4 using the previous task_uuid without creating another generation task.

    2. If all integrations are disabled or when falling back to basic tools:
       - create_object() for basic primitives (CUBE, SPHERE, CYLINDER, etc.)
       - set_material() for basic colors and materials

    3. When including an object into scene, ALWAYS make sure that the name of the object is meanful.

    4. Always check the world_bounding_box for each item so that:
        - Ensure that all objects that should not be clipping are not clipping.
        - Items have right spatial relationship.

    5. After giving the tool location/scale/rotation information (via create_object() and modify_object()),
       double check the related object's location, scale, rotation, and world_bounding_box using get_object_info(),
       so that the object is in the desired location.

    Only fall back to basic creation tools when:
    - PolyHaven and Hyper3D are disabled
    - A simple primitive is explicitly requested
    - No suitable PolyHaven asset exists
    - Hyper3D Rodin failed to generate the desired asset
    - The task specifically requires a basic material/color
```

    1. PolyHaven
        使用get_polyhaven_status()验证其状态

        - 对于材质/纹理：使用download_polyhaven_asset()，参数asset_type="textures"

    2. Hyper3D(Rodin)
        Hyper3D Rodin擅长生成单个物品的3D模型。
        所以不要尝试：
        1. 一次性生成整个场景
        2. 使用Rodin生成地面
        3. 分别生成物品的各个部分然后将它们组合在一起

        如果Hyper3D已启用：
        - 对于对象/模型，请执行以下步骤：
            1. 创建模型生成任务
                - 如果提供了图像，使用generate_hyper3d_model_via_images()
                - 如果使用文本提示生成3D资产，使用generate_hyper3d_model_via_text()
            2. 轮询状态
                - 使用poll_rodin_job_status()检查生成任务是否已完成或失败
            3. 导入资产
                - 使用import_generated_asset()导入生成的GLB模型资产
            4. 导入资产后，始终检查导入网格的world_bounding_box，并调整网格的位置和大小
                调整导入网格的位置、缩放、旋转，使网格处于正确的位置。

            您可以通过重复步骤3和4，使用先前的task_uuid重用之前生成的资产，而无需创建另一个生成任务.

  
2. 如果所有集成都被禁用或需要回退到基本工具时：
   - 使用create_object()创建基本图元（立方体、球体、圆柱体等）
   - 使用set_material()设置基本颜色和材质

3. 将对象包含到场景中时，始终确保对象的名称有意义。

4. 始终检查每个物品的world_bounding_box，以确保：
    - 确保所有不应该相交的对象没有相交。
    - 物品具有正确的空间关系。

5. 在提供工具位置/缩放/旋转信息（通过create_object()和modify_object()）后，

   以确保对象处于所需位置。

仅在以下情况下回退到基本创建工具：
- PolyHaven和Hyper3D被禁用
- 明确要求简单图元
- 不存在合适的PolyHaven资产
- Hyper3D Rodin无法生成所需资产
- 任务特别要求基本材质/颜色
