
# veo 3 的提示词

> 来源：[https://my.feishu.cn/docx/C0URdnsgRobLtLx5FrgcLsTSnRg](https://my.feishu.cn/docx/C0URdnsgRobLtLx5FrgcLsTSnRg)

经过无数次的尝试，我发现“电影、高质量、4K、杰作”等术语毫无意义，因为 veo 3 已经以卓越为目标。以下是真正起到推动作用的因素。

## 绒毛问题

大多数人会在提示中添加质量描述词，认为形容词越多=结果越好。Veo 3 已经训练过生成高质量输出，所以这些词只是噪音而已。

## 优化提示结构

[镜头类型] + [主体] + [动作] + [风格] + [镜头移动] + [音频提示]

### 有效示例

```
中景，赛博朋克黑客疯狂打字，霓虹灯反射在脸上，银翼杀手的美感，缓慢推入，音频：机械键盘的咔哒声，远处的警报声
```

### 不是这个

```
电影高品质 4K 杰作美丽令人惊叹的中景镜头，一位华丽的赛博朋克黑客在完美的灯光下戏剧性地打字
```

## 真正重要的因素

### 技术规格

+ **拍摄类型** - 广角、中景、特写、微距

+ **拍摄角度** —— 视线水平、低角度、高角度、鸟瞰

+ **镜头选择** —— 35mm、85mm、微距镜头、鱼眼镜头

### 视觉方向

+ **照明质量** - 黄金时段、工作室照明、霓虹灯

+ **调色板** - 具体参考，例如“青色和橙色等级”

+ **风格参考** - “使用 Arri Alexa 拍摄”、“韦斯·安德森风格”

### 动作和音频

+ **具体动作** - “慢速推拉”、“手持跟随”

+ **音频元素** - “机械声音”、“环境交通”

## 提示中需要删除的单词

+ 电影❌

+ 高品质❌

+ 4K/8K ❌

+ 杰作❌

+ 美丽/惊艳❌

+ 华丽/惊人❌

+ 专业❌

+ 完美❌

## 真正有帮助的话

+ 特定相机型号✅

+ 董事姓名✅

+ 电影参考✅

+ 技术照明术语✅

+ 精确的颜色描述✅

+ 音频环境细节✅

## 之前与之后的示例

### 之前（内容丰富）

```
令人惊叹的电影杰作 4K 高品质美丽镜头，美丽的女人在完美的戏剧性灯光下优雅地穿过令人惊叹的雨中
```

### 优化后

```
中景，身穿红色外套的女子在雨中行走，银翼杀手2049电影摄影，慢速跟踪镜头，音频：雨打在人行道上，远处城市的嗡嗡声
```

## 结果

优化的提示始终产生：

+ 更可预测的输出

+ 更好的风格一致性

+ 处理速度更快（提示更短）

+ 更符合预期的结果
