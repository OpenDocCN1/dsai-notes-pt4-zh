# InternVL3_5-1B评测

本节以`MME`数据集为例，对`InternVL3_5-1B`多模态模型进行评测，包括API模型评测和非API模型评测两种方式。首先采用API模型评测方案，利用`LMDeploy`本地部署`InternVL3_5-1B`模型API，再使用`VLMEvalKit`调用模型API进行评测。然后，通过修改`VLMEvalKit`中的`internvl_chat.py`实现非API模型评测。

## VLMEvalKit安装

`VLMEvalKit`是一个专为大型视觉语言模型评测设计的开源工具包。它支持在各种基准测试上对大型视觉语言模型进行一键评估，无需进行繁重的数据准备工作，使评估过程更加简便。`VLMEvalKit`适用于图文多模态模型的评测，支持单对图文输入或是任意数量的图文交错输入。它通过实现70多个基准测试，覆盖了多种任务，包括但不限于图像描述、视觉问答、图像字幕生成等。

使用`VLMEvalKit`进行评测需要先安装，具体步骤如下：

```
# 拉取源代码
cd /root/opencompass
git clone https://gh.llkk.cc/https://github.com/open-compass/VLMEvalKit.git

# 创建虚拟环境
conda create -n VLMEvalKit python=3.11 -y
conda activate VLMEvalKit

# 编译安装
cd VLMEvalKit
# 备份原文件
cp requirements.txt requirements.txt.bak
# 移除包含 decord 的行，暂时用不到该包，先去掉避免报错
sed -i '/decord/d' requirements.txt
# 安装依赖
pip install -r requirements.txt
# 编译安装
pip install -e .
# pip install datasets
```

### 修改internvl_chat.py

`VLMEvalKit`默认采用GPU进行推理，没有适配Ascend NPU，需要修改`internvl_chat.py`文件，以支持通过NPU加载本地`InternVL3_5-1B`模型进行推理。该文件位于`VLMEvalKit/vlmeval/vlm/internvl/internvl_chat.py`。

主要修改其中`InternVLChat`类的`init`函数：

+ 在该函数中的`if use_lmdeploy:`前增加如下代码

```
import torch_npu
if torch.npu.is_available():
        self.device = torch.device("npu:0")
        self.device_type = "ascend"
```

+ 将`if use_lmdeploy:`部分修改为

```
if use_lmdeploy:
   from lmdeploy import TurbomindEngineConfig, PytorchEngineConfig, VisionConfig, pipeline
   engine_type = PytorchEngineConfig if "internvl3_5" in model_path.lower() else TurbomindEngineConfig
   vision_config = VisionConfig(max_batch_size=4)

   self.model = pipeline(
         model_path,
         vision_config=vision_config,
         backend_config=engine_type(
                 session_len=max(16384, kwargs.get("max_new_tokens", 16384)),
                  cache_max_entry_count=0.5,
                  tp=1, 
                  device_type=self.device_type,
         )
    )

else:
    self.model = AutoModel.from_pretrained(
          model_path,
          torch_dtype=torch.bfloat16,
          load_in_8bit=load_in_8bit,
          trust_remote_code=True,
          low_cpu_mem_usage=True,
    )
    self.model = self.model.to(self.device)
    self.model.eval()
```
