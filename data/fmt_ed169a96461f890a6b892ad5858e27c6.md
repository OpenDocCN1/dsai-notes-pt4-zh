构建`summarizer`的核心问题是如何将文档传递到LLM的上下文窗口中。两种常见的方法是：

1. `Stuff`：将所有文档填充到一个 `prompt` 中。这是最简单的方法，需要LLM具有足够大的上下文窗口。

2. `Map reduce`：采取 分而治之 的思想，在“`map`”步骤单独总结每篇文档，然后将所有摘要“`reduce`”为最终摘要。

## QuickStart

任何一个 `pipeline` 都可以封装在单个 `load_summarize_chain` 对象中。假设我们想总结一篇博客，可以用几行代码实现。首先设置环境变量并安装 软件包 ：

```
%pip install --upgrade --quiet langchain-openai tiktoken chromadb langchain

# Set env var OPENAI_API_KEY or load from a .env file
# import dotenv
# dotenv.load_dotenv()
```

我们可以使用 `chain_type="stuff"` ，尤其是使用有较大上下文窗口的模型时，例如：

- 16k token 的 OpenAI `gpt-3.5-turbo-1106`
- 100k token 的 Anthropic `Claude-2`

除此之外，还可以令 `chain_type="map_reduce"` 或 `chain_type="refine"` 。 这里我选取了自己写的一篇 `Agent` 文章验证生成摘要的效果。

```
from langchain.chains.summarize import load_summarize_chain
from langchain_community.document_loaders import WebBaseLoader
from langchain_openai import ChatOpenAI

loader = WebBaseLoader("https://zhuanlan.zhihu.com/p/668153266")
docs = loader.load()

llm = ChatOpenAI(temperature=0, model_name="gpt-3.5-turbo-1106")
chain = load_summarize_chain(llm, chain_type="stuff")

chain.run(docs)
```

## Stuff模式

当使用 `chain_type="stuff"` 的 `load_summarize_chain` 时，将使用 `StuffDocumentsChain`。该chain将获取一个文档列表，将它们全部插入到 `prompt` 中，并将该 `prompt` 传递给LLM：

```
from langchain.chains.combine_documents.stuff import StuffDocumentsChain
from langchain.chains.llm import LLMChain
from langchain.prompts import PromptTemplate

# Define prompt
prompt_template = """Write a concise summary of the following:
"{text}"
CONCISE SUMMARY:"""
prompt = PromptTemplate.from_template(prompt_template)

# Define LLM chain
llm = ChatOpenAI(temperature=0, model_name="gpt-3.5-turbo-16k")
llm_chain = LLMChain(llm=llm, prompt=prompt)

# Define StuffDocumentsChain
stuff_chain = StuffDocumentsChain(llm_chain=llm_chain, document_variable_name="text")

docs = loader.load()
print(stuff_chain.run(docs))
```

## Map-Reduce模式

首先用 `LLMChain` 将每个文档映射为一个单独的摘要，然后用 `ReduceDocumentsChain` 将这些摘要合并为一个 全局摘要 。

`ReduceDocumentsChain` 封装了通用的 `CombineDocumentsChain`（类似 `StuffDocumentsChain`）。

当文档的累积大小超过 `token_max` 时，在传递到 `CombineDocumentsChain` 之前增加了折叠文档的功能。

```
from langchain.chains import MapReduceDocumentsChain, ReduceDocumentsChain
from langchain_text_splitters import CharacterTextSplitter

llm = ChatOpenAI(temperature=0)

# Map
map_template = """The following is a set of documents
{docs}
Based on this list of docs, please identify the main themes 
Helpful Answer:"""
map_prompt = PromptTemplate.from_template(map_template)
map_chain = LLMChain(llm=llm, prompt=map_prompt)

# Reduce
reduce_template = """The following is set of summaries:
{docs}
Take these and distill it into a final, consolidated summary of the main themes. 
Helpful Answer:"""
reduce_prompt = PromptTemplate.from_template(reduce_template)

# Run chain
reduce_chain = LLMChain(llm=llm, prompt=reduce_prompt)

# Takes a list of documents, combines them into a single string, and passes this to an LLMChain
combine_documents_chain = StuffDocumentsChain(
    llm_chain=reduce_chain, document_variable_name="docs"
)

# Combines and iteratively reduces the mapped documents
reduce_documents_chain = ReduceDocumentsChain(
    # This is final chain that is called.
    combine_documents_chain=combine_documents_chain,
    # If documents exceed context for `StuffDocumentsChain`
    collapse_documents_chain=combine_documents_chain,
    # The maximum number of tokens to group documents into.
    token_max=4000,
)
```
