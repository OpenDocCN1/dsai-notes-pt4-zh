
## 结合目录操作

先定位目录，再操作文件：

```
请帮我在 src/components 目录下创建一个新的 Card 组件
```

## 使用文件描述

当不确定文件名时，可以用描述：

```
请帮我找到并修改处理用户登录的那个文件
```

## 上下文感知

Claude Code 会根据你的操作历史自动理解上下文：

```
（之前操作了 UserService.js）
请帮我再添加一个用户注销的功能
```

## 代码片段引用

可以引用代码中的特定部分：

```
@App.tsx 请帮我优化第 45-60 行的渲染逻辑
```

## 注意事项

1. 文件路径：确保文件路径正确，使用`/`作为路径分隔符

1. 文件权限：确保 Claude Code 有权限访问和修改文件

1. 备份重要文件：在进行大规模修改前，建议先备份

1. 工作区范围：Claude Code 只能操作当前工作区内的文件

1. 文件大小：对于超大文件，建议分批处理

现在，试着用 @ 符号指定一个文件，让 Claude Code 帮你处理吧！

## 改写文本

### 润色文本

让文本更加通顺优美：

你：请帮我润色这段文字：这个产品很好用，功能很多，价格也不贵，我觉得大家可以买。

Claude：润色后的版本：

这款产品表现出色，功能丰富多样，同时价格亲民实惠，非常值得推荐给大家。无论是日常使用还是特殊需求，都能很好地满足，是一款性价比极高的选择。

### 改变语气

调整文本的语气和风格：

你：请将这段文字改写得更正式一些：大家好，今天我们要讲的是怎么用这个软件，很简单，跟着我学就行。

Claude：正式版本：

各位好，今天我们将介绍该软件的使用方法。本教程将采用循序渐进的方式，确保每位学员都能掌握操作要领。请大家跟随我们的指导，逐步学习软件的各项功能。

### 简化文本

让复杂的文本更简洁易懂：

你：请帮我简化这段文字：鉴于当前市场环境的复杂性和不确定性，我们需要采取更加谨慎和稳健的策略来应对可能出现的各种挑战和风险。

Claude：简化版本：

由于市场环境复杂多变，我们需要采取谨慎稳健的策略来应对各种挑战和风险。

## 小技巧

1. 提供更多细节：在请求生成文本时，提供更多细节可以获得更符合需求的结果

1. 指定字数：可以要求生成特定字数的文本，例如"写一段 200 字的介绍"

1. 指定风格：可以指定文本的风格，例如"用幽默的风格写"

1. 多次尝试：如果第一次生成的不满意，可以要求重新生成或调整要求

1. 保存有用的模板：对于常用的文本类型，可以保存为模板，下次直接使用
