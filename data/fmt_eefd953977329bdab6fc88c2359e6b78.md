#### 功能说明

账号在进行敏感操作时，为了验证是本人，而不是盗号。需要用户在收到的手机`url` 上点击确认授权。

下面就是开发的`h5`页面。

已授权是可点击的（需要调用接口）。下面我们用chatGPT来实现一下。

（下图是chatGPT实现的效果）

```
要求：使用`react` + `antd mobile`+ `less`+ `alita`，创建一个页面组件。

页面逻辑如下
1. import {`confirmAuthorization`, `getPageStatus` } from "@/services/loginVerification";  // 引入接口路径
2. 进入页面后调用 `getPageStatus` 接口，判断页面状态，显示对应的文本信息
3. 点击[授权通过(如非本人请勿点击)]按钮后，调用 `confirmAuthorization` 接口，判断返回值，如果成功就显示您已授权通过，否则显示无效的访问！！

页面UI布局要求如下（整个页面`padding`为20px,下面每行间距为10px）：
第一行文本（文本样式：红色，加粗）：`XXX安全验证`
第二行文本（文本样式：缩进）：您的`XXX`账号当前正在执行高危或敏感操作，需要您亲自授权通过！，
第三行文本（右对齐）：通过 `getPageStatus` 接口返回的`data`状态显示不同的文本信息。未授权时为蓝色（(页面信息：[授权通过(如非本人请勿点击)]按钮)），已过期为红色（页面信息：无效的访问！！），已授权为绿色（（页面信息：您已授权通过））

接口一：`getPageStatus` 获取页面状态
入参：
{
    `authKey`:`string`, // 从url中获取
}
出参：
{
    `code`:0, // 0 成功
    `data`:`number` // 页面状态：0 未授权，  1 已过期， 2 已授权
}


接口二：`confirmAuthorization` 确认授权
入参：
{
  `authKey`:`string`   // 从url中获取
}
出参：
{
  `code`:0, // 0 成功
  `data`:`boolean` // true 成功， false 失败
}
```

### 使用mockjs模拟数据

痛点：

怎么快速的把后端定义的接口文档变成前端项目中的`Mock`数据，前端可以直接请求这个接口并返回模拟数据呢？

我的项目使用的 [`umi`框架](https://v3.umijs.org/zh-CN/docs/mock#%E7%BA%A6%E5%AE%9A%E5%BC%8F-mock-%E6%96%87%E4%BB%B6)， 内置了`mock`数据服务，所以我们只要把相关的接口 `umi`的要求生成代码即可。

下面我们开始吧。

解决方案：

#### 第一步：身份设置

> 你是一个数据格式生成器，我会给你一些接口定义文档。你会转换成 `umi`中 `mock`的数据格式。
>
> 注意事项：
>
> 1. 需要把标题放在url的上方，并注释起来。
>
> 2. 生成的数据，放在一个代码块中方便复制。
>
> 3. 引入： `import mockjs from 'mockjs';`  来模拟数据

#### 第二步：数据格式处理

这里为什么要进行数据格式处理呢？

所以我把原始文档拷贝到 `typora`中，把不必要的内容删除。

拷贝到`typora`中的好处是，可以把文档内容转成`markdown`格式，如果内容中包含表格文本拷贝到GPT进行识别。

## 把JSON转换成TypeScript类型定义

### 痛点说明

使用`TS`写前端代码需要定义很多数据类型，而这些数据大多依赖接口返回的数据类型。

如何快速的把接口`json`转换成 `TS`定义，可以帮我们节省很多干苦力活的时间。

也许你会想到一些在线服务：在线`Json`转`TypeScript`工具。但是这真的好用吗？

下面我们来看一个例子：

完整的`JSON`数据见url： `https://gist.github.com/tuihou123321/4339f2cd1928bb7c4b5c8855d7fbb129`。

下面是一个复杂的`json`对象，其中`pages`中的`key`都是变量，比如：`foo`,`bar`

![](img/23d4b7febc922f0bd16167386a4213fc.png)

我们使用上面提到的在线转换工具来进行测试，发现效果非常不理想。 `foo`, `bar`是变量，不应该定义在`TS`类型中。那有没有其他更好的工具来解决这个问题呢？

![](img/0dcc29305cc3bed12bf86b42fc250ad4.png)

### 解决方案

我们直接把`json`对象直接丢给chatGPT。

提示词：

```
请把下面的`JSON`对象转换成 `typescript`类型定义：
// 这里是注入的`json`代码
```

下面就是最后生成的`TS`类型定义，转换的非常不错。chatGPT在智能理解方面比普通的小工具更智能。

```
type ComponentMethodParams = Record<string, unknown>;
type ComponentMethod = {
    params?: ComponentMethodParams;
    context?: string[];
    getter?: boolean;
    wrap?: boolean;
    desc?: string;
};
type ComponentMethods = Record<string, ComponentMethod>;
type ComponentAppendButton = {
    desc?: string;
    context?: string[];
};
type ComponentAppendButtons = Record<string, ComponentAppendButton>;
type Component = {
    methods: ComponentMethods;
    appendButtons: ComponentAppendButtons;
};
type ExportComponent = {
    [key: string]: {
        desc?: string;
        component: Component;
        type: Record<string, unknown>;
    };
};
type Page = {
    title: string;
    route: string;
    filename: string;
    exportComponent: ExportComponent;
};
type Pages = Record<string, Page>;
type Module = {
    name: string;
    title: string;
    pages: Pages;
};
type AvailableType = {
    title: string;
    type: number;
};
type ExportUsage = {
    [key: string]: {
        exportComponent: ExportComponent;
        availableTypes: AvailableType[];
    };
};

// 能力清单通过配置文件生成，配置文件的格式如下：
export type Config = {
    module: Module;
    exportUsage: ExportUsage;
};
```
