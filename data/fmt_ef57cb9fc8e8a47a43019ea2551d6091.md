## 环境初始化说明

从输出来看，已经成功地运行了一个名为 `llama2:7b` 的 Docker 容器，并且其中的 `PyTorch` 环境也已经成功地初始化。这个容器使用了 NVIDIA 的深度学习容器，版本为 `23.06`，`PyTorch` 版本为 `2.1.0a0+4136153`。

然后，你看到了一些警告，这些警告来自 `gradio` 库，这是一个用于创建机器学习模型的交互式界面的库。警告表示 `generate` 函数预期有 7 个参数，但只收到了 6 个。这可能意味着你需要检查你的代码，确保你正确地调用了 `generate` 函数。

## 查看容器运行细节

### 查看容器列表

使用 `docker ps` 查看容器列表

```
chengzh@AIStudio:~$ docker ps

CONTAINER ID   IMAGE                 COMMAND                  CREATED          STATUS          PORTS                                        NAMES

20c2b7853b68   soulteary/llama2:7b   "/opt/nvidia/nvidia_…"   11 minutes ago   Up 11 minutes   6006/tcp, 8888/tcp, 0.0.0.0:7860->7860/tcp   gracious_perlman

e3e613bbfcd7   portainer/portainer   "/portainer -H unix:…"   18 hours ago     Up 3 hours      8000/tcp, 9443/tcp, 0.0.0.0:9000->9000/tcp   priceless_diffie

```

`20c2b7853b68`：就是我们 `7b` 模型所对应的容器。后续我们可以用 `20` 作为代号在命令中调用它。

+ 它使用了 `soulteary/llama2:7b` 这个 Docker 镜像。

+ 启动命令是 `/opt/nvidia/nvidia_entrypoint.sh`。这个脚本是 NVIDIA Docker 镜像中的一个入口点脚本。当你启动一个基于这个镜像的容器时，这个脚本会被首先执行。这个脚本通常用于设置一些环境变量、初始化 NVIDIA 驱动和库，以及启动用户指定的应用程序。在当前案例中，这个脚本可能在初始化后启动了你的 Python 应用。

+ 这个容器创建于 11 分钟前，状态为 `Up`（正在运行）11 分钟。它开放了 `6006`、`8888` 和 `7860` 这几个端口，其中宿主机的 `7860` 端口映射到了容器的 `7860` 端口。

+ 这个容器的名字是 `gracious_perlman`。

### 查看资源使用情况

使用 `docker stats` 查看资源使用情况

```
CONTAINER ID   NAME               CPU %     MEM USAGE / LIMIT     MEM %     NET I/O          BLOCK I/O   PIDS

20c2b7853b68   gracious_perlman   0.64%     1.244GiB / 31.22GiB   3.98%     93.3kB / 885kB   0B / 0B     89

e3e613bbfcd7   priceless_diffie   0.03%     30.8MiB / 31.22GiB    0.10%     562kB / 4.26MB   0B / 0B     14

```

`docker stats` 命令，用于展示特定容器的资源使用情况。这个命令的输出包含了 CPU 使用率、内存使用情况、网络 I/O 以及磁盘 I/O 等信息。

+ `CONTAINER ID`: 容器的 ID，这里是 `20c2b7853b68`。

+ `NAME`: 容器的名字，这里是 `gracious_perlman`。

+ `CPU %`: CPU 使用率，这里是 `0.64%`，表示这个容器正在使用 `0.64%` 的 CPU 资源。

+ `MEM USAGE / LIMIT`: 内存使用情况和限制，这里是 `1.244GiB / 31.22GiB`，表示这个容器正在使用 `1.244GiB` 的内存，而它的内存限制是 `31.22GiB`。

+ `MEM %`: 内存使用率，这里是 `3.98%`，表示这个容器正在使用的内存占其总内存限制的 `3.98%`。

+ `NET I/O`: 网络 I/O，这里是 `93.3kB / 885kB`，表示这个容器已经接收了 `93.3kB` 的数据，发送了 `885kB` 的数据。

+ `BLOCK I/O`: 磁盘 I/O，这里是 `0B / 0B`，表示这个容器没有读写磁盘数据。

+ `PIDS`: 进程数，这里是 `89`，表示在这个容器内运行了 `89` 个进程。

### 查看容器进程

```
^Cchengzh@AIStudio:~$ docker top 20

UID                 PID                 PPID                C                   STIME               TTY                 TIME                CMD

root                15307               15286               6                   03:32               ?                   00:00:51            python app.py

```

你使用 `docker top` 命令查看了容器 `20` 的进程信息。这个命令显示了在特定容器中运行的进程及其相关信息。

在这个情况下，你可以看到有一个进程正在运行，它的用户 ID（`UID`）是 `root`，进程 ID（`PID`）是 `15307`，父进程 ID（`PPID`）是 `15286`，CPU 使用率（`C`）是 `6`，开始时间（`STIME`）是 `03:32`，没有使用终端（`TTY`），已运行时间（`TIME`）是 `00:00:51`，并且它正在运行的命令（`CMD`）是 `python app.py`。

这意味着你的容器正在运行一个 Python 应用 `app.py`。
