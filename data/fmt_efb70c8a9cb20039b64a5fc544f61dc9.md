## ARM/RISCV/Intel/AMD CPU中，一条存储器读写指令的执行全过程是什么？

`https://www.zhihu.com/question/667501058/answer/3630488709?utm_psn=1820438219126349826`

在ARM、RISC-V、Intel和AMD CPU中，存储器读写指令的执行过程涉及多个关键环节，特别是在考虑内存一致性和缓存一致性时。

对于存储（`Store`）指令：

1. 指令解码：`Store`指令被解码为地址和数据，生成两个微操作（`uop`），并在存储缓冲区（`Store Buffer, SB`）中分配一个条目。

2. 写入`Store Buffer`：数据写入`SB`后即完成执行，随后会在适当的时机写入缓存。

3. `FIFO`机制：`SB`的`FIFO`设计确保`Store-Store`乱序不发生，但`Store-Load`乱序仍可能发生。使用内存屏障（如`mfence`）可防止此类乱序。

4. 缓存一致性：若`SB`中已有`Exclusive/Modified`状态的缓存行，则直接写入`L1`数据缓存；否则，需要发起请求以获取对应的缓存行，等待旧数据读入`Line Fill Buffer（`LFB`）`，然后将更改合并后写入`L1`缓存。

对于加载（`Load`）指令：

1. 指令解码：`Load`指令被解码并放入`Load Buffer（`LB`）`中，用于跟踪未完成的加载请求。

2. 内存依赖预测：通过内存依赖预测机制判断该`Load`是否与先前的`Store`有数据依赖。若无依赖，便可直接发起缓存读取请求；若有依赖，则需等待前面的`Store`完成。

3. 从缓存读取：`Load`请求通过多个级别的缓存（`L1`、`L2`、`L3`）查找，若在`L1`命中，延迟为4-5个周期；若`L1`未命中，则继续查找`L2`，依此类推，直到内存。

4. 数据回写：获取数据后，`Load`指令在从缓存中获取数据之后才能完成，并且确保数据一致性通过设计避免`Load-Store`乱序。

在整个过程中，CPU通过`Memory Order Buffer`、`Cache`系统以及特定的缓存一致性协议（如`MESI`、`MOESI`）来维持内存一致性和缓存一致性，确保多核环境中数据的一致性和程序的正确执行。

## 人人都能看懂的DPO数学原理

`https://zhuanlan.zhihu.com/p/721073733?utm_psn=1820487557647036418`

`DPO`（`Direct Preference Optimization`）是为训练能够理解人类问题并给出满意回答的模型而设计的一种方法。该方法的核心在于简化训练过程，绕过传统强化学习中的奖励模型训练步骤，直接利用人类标注的偏好数据来训练对齐模型。

首先，模型需要具备丰富的知识，以应对可能的提问。接着，模型必须理解提问或指令，并根据这些指令生成相应的回答。最终，模型不仅要给出答案，还需对齐人类的偏好。

在`ChatGPT`的训练中，模型首先通过大量数据训练出一个基础模型，然后对其进行微调，使其能够理解人类指令，最后通过强化学习（`RLHF`）进一步优化，使得模型的回答符合人类的偏好。

`DPO`的主要改进点在于：

1. 跳过奖励模型训练：直接利用人类偏好数据，简化对齐模型的训练过程。

2. 非强化学习方法：通过数学推导，简化原始的偏好对齐优化目标，以类似`SFT`（`Supervised Fine-Tuning`）的方式训练模型。

在优化目标方面，`DPO`的损失函数是从总体优化目标推导而来的，目标是找到能够最大化人类偏好的对齐模型。推导过程中，通过定义`partition function`，逐步将目标简化为`KL`散度的形式，寻找最优解。

`DPO`的优势在于：

+ 避免了奖励模型的复杂训练，降低了显存占用和训练不稳定性。

+ 直接利用偏好数据，提高了训练效率。

在偏好排序的标注方式中，有两种情况：

1. 成对偏好标注：对于一个`prompt`生成两个回答，通过`BT`模型建立奖励模型的优化目标。最终得出的优化目标允许直接训练对齐模型，绕过奖励模型的训练。

2. 多回答偏好标注：使用`PT`模型，对`K`个回答进行排序。通过类似的推导过程，得到的`DPO`优化目标也能实现对齐模型的直接训练。

综上，`DPO`通过简化训练步骤，提高了模型训练的效率和稳定性，为未来的偏好对齐模型设计提供了新的思路。

## Qwen2.5-Math 技术报告详细解读

`https://zhuanlan.zhihu.com/p/721015204`

1. 方法论

`Qwen2.5-Math` 的副标题“`Toward Mathematical Expert Model via Self-Improvement`”强调自我改进在训练中的作用。自我改进体现在以下三方面：

+ 预训练：利用 `Qwen2-Math-Instruct` 合成扩充数据，提升模型基础。

+ 后训练：`SFT` 模型与奖励模型之间通过迭代进行交互，以优化输出。

+ 推理：奖励模型引导采样过程，确保输出质量。

2. 预训练——数据工程

数据是预训练的核心。`Qwen2.5-Math` 的数据处理主要包括：

+ 数据集构建：`Qwen Math Corpus v1` 包含 700B tokens，来源于 web 数据，通过 `FastText` 进行数学相关语料的分类。

+ 去重技术：采用 `MinHash` 和 `LSH` 技术，确保相似文档的快速识别与去重。

+ 数据评分：使用 `Qwen2-0.5B-Instruct` 模型对数据进行评分，高分数据优先选用。

`Qwen Math Corpus v2` 扩展至 1T tokens，加入更多中文数据，提升模型对中文的支持。

3. 后训练 - SFT

后训练的重点在于链式推理（`CoT`）和工具集成推理（`TIR`）：

+ `CoT` 数据：总量为 2M 英文和 500k 中文，指令数据包括 580k 英文和 500k 中文。来源于 `GSM8K`、`MATH`、`NuminaMath` 等数据集。

+ `TIR` 数据：190k 带标注数据和 205k 合成数据，通过将外部工具（如 `Python`）集成到推理过程中，提升解决问题的能力。

4. 后训练 - 强化学习

奖励模型通过多样化样本构建和评分机制进行训练：

+ 数据构建：使用 206k 英文题目，`Qwen2.5-Math` 训练使用 361k 英文和 257k 中文题目，确保模型对各种问题的适应能力。

+ 模型架构：将单输出线性层改为双层 `MLP`，采用 `ReLU` 激活函数，增强评分的灵活性。

+ 强化学习方法：使用 `GRPO` 方法，相比于 `PPO`，去除价值模型，通过 n 次采样求均值。

5. 去除数据集污染

数据集污染去除使用了：

+ `n-gram` 过滤：采用 13-gram 过滤，确保相似问题不重复。

+ `LCS` 过滤：针对数学问题采用 `LCS` 过滤，有效识别表达式相似但数字不同的问题。

6. 评估

评估结果显示，`Qwen2.5-Math` 在多个数学任务中的表现超越了现有的 `SOTA`，特别是在解题能力和应对竞赛题目方面展现出色。

## RISC-V 香山处理器微架构简单介绍
