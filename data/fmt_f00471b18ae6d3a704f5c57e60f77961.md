function hasCycle(head: ListNode | null): boolean {

## 142. 环形链表二

<https://leetcode.cn/problems/linked-list-cycle-ii/?envType=study-plan-v2&envId=top-100-liked>

### 思路分析

遍历链表，类似上边 141 题，将每个节点的引用存储到一个哈希表 `Set` 中。在遍历过程中，检查当前节点是否已经存在于哈希表中。若存在，表明链表有环；若遍历到链表末尾都没发现重复节点，就说明链表无环。

### 代码实现

```
function detectCycle(head: ListNode | null): ListNode | null {
    // Set 集合的特性是存储的元素唯一，方便我们判断节点是否重复出现
    const nodeSet = new Set<ListNode>();
    let current = head;
    // 开始遍历链表，只要当前节点不为空，就继续循环
    while (current) {
        if (nodeSet.has(current)) {
            return current;
        }
        // 如果当前节点不存在于 Set 集合中，将其添加到集合中, 表示该节点已经被遍历过
        nodeSet.add(current);
         // 将指针移动到下一个节点，继续遍历链表
        current = current.next;
    }
    return null;
} 
```

### 复杂度分析

+   **时间复杂度**：`O(n)`，其中 `n` 是链表的长度。需要遍历链表一次，每次操作哈希表的时间复杂度为 `O(1)`。

+   **空间复杂度**：`O(n)`，最坏情况下需要存储链表中的所有节点。

## 2. 两数相加

<https://leetcode.cn/problems/add-two-numbers/description/?envType=study-plan-v2&envId=top-100-liked>

### 思路分析

要解决两个逆序存储数字的链表相加问题，核心思路是逐位相加两个链表的对应节点值，并考虑进位情况。我们会创建一个新的链表来存储相加结果。具体步骤为：

1.  准备一个虚拟头节点，方便后续操作结果链表。

1.  用一个变量记录进位。

1.  同时遍历两个链表，将对应节点值与进位相加，得到当前位结果和新的进位。

1.  为当前位结果创建新节点并连接到结果链表。

1.  若某个链表先遍历完，继续处理另一个链表剩余节点。

1.  最后若还有进位，添加一个新节点。

### 代码实现

```
function addTwoNumbers(l1: ListNode | null, l2: ListNode | null): ListNode | null {
    // 创建虚拟头节点
    const dummy = new ListNode();
    // 当前节点指针，初始指向虚拟头节点
    let current = dummy;
    // 进位初始化为 0
    let carry = 0;

    // 只要有一个链表没遍历完或者还有进位，就继续循环
    while (l1 || l2 || carry) {
        // 获取当前节点的值，如果节点为空则为 0
        const num1 = l1 ? l1.val : 0;
        const num2 = l2 ? l2.val : 0;

        // 计算当前位的和，包含进位
        const sum = num1 + num2 + carry;
        // 计算新的进位
        carry = Math.floor(sum / 10);
        // 当前位的值为和对 10 取余
        const digit = sum % 10;

        // 创建新节点存储当前位的值
        current.next = new ListNode(digit);
        // 移动结果链表的指针
        current = current.next;

        // 移动原链表的指针
        if (l1) {
            l1 = l1.next;
        }
        if (l2) {
            l2 = l2.next;
        }
    }

    // 返回结果链表的头节点
    return dummy.next;
}    
```

`Math.floor` 是 JavaScript（TypeScript 兼容 JavaScript 的内置函数）里的一个内置函数，其功能是对传入的数字进行向下取整操作。也就是说，它会返回小于或等于该数字的最大整数。在 `carry = Math.floor(sum / 10)` 里；`sum` 是当前位上两个链表节点的值与进位相加的总和。由于每一位节点只能存储一位数字（范围是 0 - 9），当 `sum` 大于等于 10 时，就会产生进位。借助 `Math.floor(sum / 10)`，能够得到进位的值。

### 复杂度分析

+   **时间复杂度**：`O(max(m, n))`，这里 `m` 和 `n` 分别是两个链表的长度。因为要对两个链表进行逐位处理，直到较长的链表遍历结束。

+   **空间复杂度**：`O(max(m, n))`，主要的额外空间用于存储结果链表，其长度最大为 `max(m,n)+1`（考虑最后有进位的情况）。

## 19. 删除链表的倒数第 N 个节点

<https://leetcode.cn/problems/remove-nth-node-from-end-of-list/description/?envType=study-plan-v2&envId=top-100-liked>

### 思路分析

我们知道链表的增删比较容易，就是通过修改指针的指向来操作。所以我们可以先用这种办法来解决一下问题。

+   首先遍历一次链表，计算出链表的总长度 `length`。

+   然后根据 `length` 和 `n` 计算出要删除节点的正数位置

+   接着再次遍历链表，找到要删除节点的前一个节点，修改其指针指向，跳过要删除的节点。

### 代码实现

```
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
    // 创建虚拟头节点，方便处理删除头节点的情况
    const dummy = new ListNode(0);
    dummy.next = head;

    // 第一次遍历计算链表长度
    let length = 0;
    let current = head;
    while (current) {
        length++;
        current = current.next;
    }

    // 计算要删除节点的正数位置
    let pos = length - n;
    current = dummy;

    // 第二次遍历找到要删除节点的前一个节点
    while (pos > 0) {
        pos--;
        current = current!.next;
    }

    // 删除节点
    if (current && current.next) {
        current.next = current.next.next;
    }

    return dummy.next;
}    
```

### 复杂度分析

+   **时间复杂度**：`O(L)`，其中 `L` 是链表的长度。需要遍历链表两次，每次遍历的时间复杂度都是 `O(L)`。

+   **空间复杂度**：`O(1)`，只使用了常数级的额外空间。

## 24. 两两交换链表中的节点

<https://leetcode.cn/problems/swap-nodes-in-pairs/?envType=study-plan-v2&envId=top-100-liked>

### 思路分析

+   首先创建一个虚拟头节点 `dummy`，其作用是简化边界条件的处理，尤其是当需要交换原链表的头节点时。

+   用 `prev` 指针指向当前要交换的两个节点的前一个节点，初始时 `prev` 指向 `dummy`。

+   借助 `first` 和 `second` 指针分别指向要交换的两个相邻节点。

+   对指针进行修改，完成节点的交换，然后更新 `prev`、`first` 和 `second` 指针，以便处理下一组相邻节点。

### 代码实现

```
function swapPairs(head: ListNode | null): ListNode | null {
    const dummy = new ListNode(0);
    dummy.next = head;
    let prev = dummy;

    while (head && head.next) {
        const first = head;
        const second = head.next;

        // 交换节点
        prev.next = second;
        first.next = second.next;
        second.next = first;

        // 更新指针
        prev = first;
        head = first.next;
    }

    return dummy.next;
}
```

### 复杂度分析

+   **时间复杂度**：`O(n)`，这里的 `n` 是链表的长度。因为需要遍历链表一次，对每两个相邻节点进行交换操作。

+   **空间复杂度**：`O(1)`，只使用了常数级的额外空间，如几个指针变量。

## 138. 随机链表的复制

<https://leetcode.cn/problems/copy-list-with-random-pointer/description/?envType=study-plan-v2&envId=top-100-liked>

### 思路分析

要实现链表的深拷贝，可按以下步骤操作：

1.  复制节点：遍历原链表，为每个节点创建一个值相同的新节点，并将新节点插入到原节点之后，形成新的链表。

1.  设置随机指针：再次遍历链表，对于原链表的每个节点，若其随机指针不为空，则将其下一个节点（即复制节点）的随机指针指向原节点随机指针所指节点的下一个节点。

1.  拆分链表：最后一次遍历链表，将原链表和复制链表分离，恢复原链表的结构，同时得到复制链表。

### 代码实现

```
function copyRandomList(head: Node | null): Node | null {
    if (!head) return null;

    // 第一步：复制节点并插入到原节点之后
    let current = head;
    while (current) {
        const newNode = new Node(current.val);
        newNode.next = current.next;
        current.next = newNode;
        current = newNode.next;
    }

    // 第二步：设置随机指针
    current = head;
    while (current) {
        if (current.random) {
            current.next!.random = current.random.next;
        }
        current = current.next!.next;
    }

    // 第三步：拆分链表
    const newHead = head.next;
    let original = head;
    let copy = newHead;
    while (original) {
        original.next = copy!.next;
        original = original.next;
        if (original) {
            copy!.next = original.next;
            copy = copy!.next;
        }
    }

    return newHead;
}
```

### 复杂度分析

+   **时间复杂度**：三个步骤的时间复杂度都为 `O(n)`，所以总的时间复杂度也是为 `O(n)`。

+   **空间复杂度**：除了返回的复制链表所需的额外空间外，没有使用其他与链表长度相关的额外空间。所以他的空间复杂度为 `O(1)`。

## 148. 排序链表

<https://leetcode.cn/problems/sort-list/?envType=study-plan-v2&envId=top-100-liked>

### 思路分析

我们知道数组的排序方式有很多种，而且好用，那么我们可不可以用数组来做这道题呢？当然可以，我们可以先把节点一个一个存进数组里边，存进去之后就可以调用 `sort` 来进行排序，排序完之后，在重新建一个虚拟头节点，把数组中的数据一个一个连上去，就是一个排序好的链表了。

### 代码实现

```
function sortList(head: ListNode | null): ListNode | null {
    if (head === null) {
        return null;
    }
    const values: number[] = [];
    let current: ListNode | null = head;
    // 将链表节点的值存入数组
    while (current) {
        values.push(current.val);
        current = current.next;
    }
    // 对数组进行排序
    values.sort((a, b) => a - b);

    // 用排序好的数组元素构建新的链表
    const dummy = new ListNode();
    current = dummy;
    for (const val of values) {
        current.next = new ListNode(val);
        current = current.next;
    }
    return dummy.next;
}
```

### 复杂度分析

+   **时间复杂度**：`O(n log n)`。主要时间开销在于数组的排序操作，数组的 `sort` 方法的平均时间复杂度为 `O(n log n)`，遍历链表和构建新链表的时间复杂度均为 `O(n)`，因此总的时间复杂度为 `O(n log n)`。

+   **空间复杂度**：`O(n)`。需要额外的数组来存储链表节点的值，数组的长度为 `n`，因此空间复杂度为 `O(n)`。

归并排序本质上是一种分治排序，如果我们把链表利用快慢指针进行分割然后递归的进行排序，每次排好序之后进行合并，全部完成之后就是已经排序好的链表了。所以我们需要有三个步骤，分割链表，排序链表，然后合并链表。感觉这种办法没有数组方法来得快。
