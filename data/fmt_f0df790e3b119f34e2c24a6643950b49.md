
# 🎬 B站批量剪辑工具 - 核心功能介绍

这是一个专业的视频批量生成系统，专为B站内容创作者设计。以下是它能实现的主要功能：

## 🎯 核心功能

### 1. 📝 脚本管理
- 编写和管理视频脚本
- 自动按行分段（每行一个段落）
- 实时段落数统计

### 2. 🎨 样式配置系统
- 从剪映导入样式模板
- 为每个段落配置不同的样式
- 支持文字、图片、视频、贴纸等多种元素
- 支持多元素样式（如三图逐个呈现）
- 支持额外样式叠加

### 3. 🎤 智能配音生成
- Edge TTS（免费）：支持多种中文音色
- MiniMax TTS（高质量）：支持情感控制和克隆音色
- 智能增量生成：只重新生成修改的部分
- 语速调节：0.5x-2.0x 倍速

### 4. 🎬 视频草稿生成
- 一键生成剪映草稿文件
- 自动应用样式、动画、转场
- 支持多元素时间线（按关键词逐个显示元素）
- 自动生成字幕

### 5. 📁 项目化管理
- 独立的项目工作空间
- 素材库管理（表情包、视频、音效、产品图）
- 配置文件自动保存
- 支持项目导入导出

### 6. 🔄 增量生成
- 智能检测脚本和配置变化
- 只重新生成修改的部分
- 大幅提高工作效率

## 🚀 工作流程

编写脚本 → 配置样式 → 生成配音 → 生成视频草稿 → 导入剪映 → 导出最终视频
