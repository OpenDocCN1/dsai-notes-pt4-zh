## 工作流搭建

出门在外，只需要在手机上点一下运行，就可以自动保存到草稿箱中进行作品的发布

接下来我给大家拆解一下流程：

![](img/9a497a5232e9ab64f1044c4cad06b8bc.png)

这套流程有主要有两个知识点：图像插件的使用和导入👸号草稿箱

导入👸号草稿箱在Coze中是有专属的上传插件，这插件是“倾听夜雨声”制作的插件“🛰️👸号上传草稿箱素材库”

![](img/1a4e51b264c742664ad43c23165a569a.png)

## 技能
1. 当用户给出主题后根据“起、承、转、结”的节奏为用户创作四个画面。

### 添加插件：上传永久图片到素材库

在插件商店搜索“倾听夜雨声”制作的👸号草稿箱插件，在工具中找到名为`add_material`

什么意思呢？看下面这张图的输入链接和输出链接，简单一看可能看不出什么效果，但如果你想在文章中插入图片就必须要转换成下面的链接，不然是展现不了的。这个插件的功能是将图片保存到👸号的图片资源库中。并获得新的图片链接，只有这个链接才能显示在草稿箱中

`access_token`引用第一个节点的输出`access_token`

`pic_url`：则引用上一个节点的`data`

### 代码节点：生成html代码

输入参数名一定要是`input`，引用批处理的输出`url_list`

输出一定要是`result`

```
async def main(args: Args) -> Output:
    # 获取输入的四个图片链接数组
    image_links = args.params['input']
    
    # 准备HTML模板（使用三重引号保留格式）
    html_template = '''
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>图片展示</title>
    <style>
        .img-container {
            display: flex;
            flex-direction: column;
            align-items: center;
        }
        .img-container img {
            max-width: 100%;
            height: auto;
            margin-bottom: 10px;
        }
    </style>
</head>
<body>
    <div class="img-container">
        <img src="图片1的路径" alt="图片1">
        <img src="图片2的路径" alt="图片2">
        <img src="图片3的路径" alt="图片3">
        <img src="图片4的路径" alt="图片4">
    </div>
</body>
</html>'''
    
    # 依次替换四个图片路径（索引0对应图片1，以此类推）
    for index in range(4):
        html_template = html_template.replace(
            f"图片{index+1}的路径",  # 需要替换的占位文本
            image_links[index]     # 用实际链接替换
        )
    
    # 返回最终结果
    return {
        "result": html_template
    }
```

### 大模型节点：生成爆款标题

模型一样用deepseek的3.1

输入还是引用开始节点的`input`

系统提示词：

```
# 角色
你是一名标题创作者，商场根据用户提供的主题编写爆款标题。

## 爆款标题要素
1. 引发好奇用悬念、疑问或反常识的表述勾起探索欲，比如“她靠这个习惯瘦了20斤，90%的人都做错了”“被忽视的3个细节，决定你能否升职”。
2. 突出利益直接告诉用户能获得什么价值（干货、好处、解决方案），例如“3招搞定孩子拖延，亲测有效”“月存5000的存钱法，普通人也能学”。
3. 制造紧迫感/稀缺性用时间、数量限制催促行动，比如“最后6小时！这款面膜买一送一”“仅限100人，免费领取职场干货包”。
4. 精准定位人群明确指向目标用户，让其觉得“这是在说我”，例如“宝妈必看：如何边带娃边赚零花钱”“应届生求职避坑指南，少走3年弯路”。
5. 运用情绪共鸣戳中用户的痛点、焦虑或情感需求，比如“30岁没结婚没买房，我是不是失败了？”“被领导当众批评后，我用这招逆转印象”。
6. 简化信息，朗朗上口用短句、数字、口语化表达降低理解成本，比如“3分钟学会番茄炒蛋，零失败”“5本书，帮你读懂人性”。
7. 适当反差/颠覆认知打破固有思维，引发讨论欲，例如“每天刷手机2小时，我反而考上了研究生”“越省钱越穷？这3个消费观错了”。

## 要求
- 根据爆款标题要素为用户创作标题
- 只创作一个标题
- 只输出标题，不得输出其他内容
```
