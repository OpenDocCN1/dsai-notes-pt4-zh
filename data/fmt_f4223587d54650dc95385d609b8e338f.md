
# 自定义 Markdown 中文递归文本分割器

```python
from langchain.text_splitter import MarkdownHeaderTextSplitter
from text_splitter.chinese_recursive_text_splitter import ChineseRecursiveTextSplitter
from typing import List, Any, Iterable
from langchain_core.documents import Document


class md_cr_TextSplitter(ChineseRecursiveTextSplitter):
    def __init__(
        self,
        keep_separator: bool = True,
        is_separator_regex: bool = True,
        chunk_size: int = 250,
        chunk_overlap: int = 50,
        **kwargs: Any,
    ) -> None:
        super().__init__(**kwargs)
        self.keep_separator = keep_separator
        self.is_separator_regex = is_separator_regex
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap

        self.md_text_splitter = self.init_TextSplitter(mode='markdown')
        self.cr_text_splitter = self.init_TextSplitter(mode='ChineseRecursive')

    def init_TextSplitter(self, mode='markdown'):
        if mode == 'markdown':
            headers_to_split = [
                ("#", "标题1"),
                ("##", "标题2"),
                ("###", "标题3"),
                ("####", "标题4"),
            ]
            text_splitter = MarkdownHeaderTextSplitter(
                headers_to_split_on=headers_to_split
            )
        else:
            text_splitter = ChineseRecursiveTextSplitter(
                keep_separator=self.keep_separator,
                is_separator_regex=self.is_separator_regex,
                chunk_size=self.chunk_size,
                chunk_overlap=self.chunk_overlap,
            )

        return text_splitter

    def split_documents(self, documents: Iterable[Document]) -> List[Document]:
        # texts, metadatas = [], []
        documents_res = []
        for doc in documents:
            source = doc.metadata['source']
            docs_md = self.md_text_splitter.split_text(doc.page_content)

            # metadata附上,不然知识库问答的时候链接无法显示
            for dm in docs_md:
                dm.metadata['source'] = source
                # dm.metadata = dict(dm.metadata, **doc.metadata)

            docs_md_cd = self.cr_text_splitter.split_documents(docs_md)
            documents_res.extend(docs_md_cd)
        return documents_res
```

核心是在 `split_documents` 的定义，先调用 `MarkdownHeaderTextSplitter`，再使用 `ChineseRecursiveTextSplitter`，充分分割文档。

走过的坑不赘述，这段代码的强调点：

+ 如我这种组合不用调整 `_split_text`，而只要调整 `split_documents` 即可，所以不跟 chatchat 官方给出的几个样例调整 `_split_text` 不一样，这个比较坑了，笔者回看 `RecursiveCharacterTextSplitter` 源代码才意识到直接调整 `split_documents` 即可

+ [tests/custom_splitter/test_different_splitter.py](https://link.zhihu.com/?target=https%3A//github.com/chatchat-space/Langchain-Chatchat/blob/master/tests/custom_splitter/test_different_splitter.py) 中的 `make_text_splitter` 函数是 chatchat 源码中使用的，可以作为测试函数

+ `metadata['source']` 其中 `source` 是文件地址，后续会在知识库查询中，呈现每段 `chunk` 的来源，这个一定记得在每个 `chunk` 的 `Document.metadata` 属性中加上

+ 目前 `.md` 格式不太友好，还是建议改成 `txt`、`pdf`、`docx` 等其他格式，举个例子，

## 2.2 修改一些配置文件

需要有几步的修改：

+ `text_splitter` 文件夹下面要放入你自定义函数的 `.py` 文件

+ 然后修改 `__init__.py`（[__init__.py](https://link.zhihu.com/?target=https%3A//github.com/chatchat-space/Langchain-Chatchat/blob/master/text_splitter/__init__.py)）

```python

```

+ 修改 `kb_config.py` 文件中的配置项目，`text_splitter_dict` 和 `TEXT_SPLITTER_NAME`：

```python

```

改完就可以开始测试。

这里留意修改 `TEXT_SPLITTER_NAME` 的作用方式，比如你之前用其他分词器已经加载过一些文档了，

此时调整成自定义的 `md_cr_TextSplitter` 并重启后，之前加载的文档还是之前的分词器分块的，之后才是 `md_cr_TextSplitter`，所以如果你需要用自定义的批量刷文档，最好新建一个知识库。

同时删除知识库内的文档，好像 `faiss` 还会保留原先的，所以有可能会有重复内容 `chunk`；

所以更换新的分词器，还是新建一个知识库比较好。
