  },

关键注意：`models.mode: "merge"`必须设置，否则自定义配置会覆盖所有内置 Provider，导致原生支持的模型无法使用。

## 8.2 核心功能配置实操

### Fallback 故障转移链配置

在`openclaw.json`的`agents.defaults.model.fallbacks`数组中，按优先级填写备选模型，主模型不可用时系统会自动按顺序降级，示例：

```
{
  &quot;agents&quot;: {
    &quot;defaults&quot;: {
      &quot;model&quot;: {
        &quot;primary&quot;: &quot;anthropic/claude-sonnet-4-6&quot;,
        &quot;fallbacks&quot;: [
          &quot;anthropic/claude-haiku-4-5&quot;,
          &quot;deepseek/deepseek-chat&quot;,
          &quot;zai/glm-5&quot;
        ]
      }
    }
  }
}
```

### 预算硬限制配置

为避免 `Agent` 循环推理导致账单爆炸，强烈建议所有用户配置单日预算上限，配置示例：

```
{
  &quot;agents&quot;: {
    &quot;defaults&quot;: {
      &quot;budget&quot;: {
        &quot;maxTokensPerDay&quot;: 500000,
        &quot;maxCostPerDay&quot;: 5.00
      }
    }
  }
}
```

### 模型状态诊断与管理

```
# 查看已配置的所有模型
openclaw models list

# 测试所有模型的连通性与可用性
openclaw models status --probe

# 手动设置主力模型
openclaw config set agents.defaults.model.primary deepseek/deepseek-chat

# 修改配置后必须重启Gateway生效
openclaw gateway restart
```

## 8.3 模型配置最佳实践

### 任务分级调度原则

永远不要用一个模型跑所有任务，遵循「强模型干重活，便宜模型干轻活，免费模型干零活」的核心原则，将成本压缩到最低的同时保障核心任务效果。

### Fallback 链必配原则

无论使用哪个主力模型，必须配置至少 2 级备选 `Fallback` 模型，避免单一厂商接口限流、故障导致 OpenClaw 服务中断。

### 预算上限必设原则

无论预算是否充足，必须设置单日成本上限，哪怕是$5/天的限额，也能在 `Agent` 进入循环推理时保护你的钱包，避免出现「一觉醒来$1100 账单」的情况。

### 配置修改重启原则

任何模型配置修改后，必须执行`openclaw gateway restart`重启网关，否则配置不会生效。

### 国产模型优先兼容原则

国内用户优先选择内置 `Provider`/官方插件支持的模型（`智谱 GLM`、`通义千问`），减少自定义配置的兼容性问题。

# 第九章 避坑指南与风险提示

## 9.1 账号封禁风险

### Anthropic OAuth 封杀

`Anthropic` 已全面封杀 `Claude Pro/Max` 订阅账户通过 `OAuth` 接入 `OpenClaw`，仅支持 `API Key` 按量付费方式，使用 `OAuth` 接入会导致账号封禁、订阅取消且无法恢复。

### 谷歌账号封禁

使用 `Gmail`/`Google` 相关 `Skill` 时，大量高频 `API` 调用会触发谷歌滥用检测，导致整个 `Google` 账号（含 `Gmail`、`Drive`、`Calendar`）被封禁，建议使用专用工作账号，而非个人主账号。

### Kimi 商用限制

`Kimi` 包月套餐仅限个人非商用使用，企业开发、商用场景使用会触发账号封禁，无任何申诉机会。

### 🛰️个人号风险

个人🛰️无官方 `Bot API`，所有非官方接入方案都存在封号风险，建议使用企业🛰️中转方案，避免主号被封。

## 9.2 成本失控风险

### 循环推理陷阱

`OpenClaw` 的多轮思考+多工具调用，`Token` 消耗是普通聊天的几十甚至上百倍，`Agent` 处理邮件/定时任务时可能进入循环推理，整晚不停调用 `API`，导致账单爆炸。

解决方案：必须设置单日成本上限，定时任务使用免费/低价模型，限制单任务最大调用轮次。

### Skill Token 消耗

每个安装的 `Skill` 都会将描述注入 `System Prompt`，增加每次请求的输入 `Token` 消耗，安装越多，基础 `Token` 消耗越高。

解决方案：不要一次性安装大量 `Skill`，仅保留 3-5 个真正需要的，用完即卸载。

### 长上下文成本翻倍

`GPT-5.4`、`Gemini 3 Pro` 等模型超过指定上下文窗口后，输入价格会翻倍，长会话场景成本会急剧上升。

解决方案：定期使用`/new`命令清空会话历史，长文本任务使用专门优化的模型。

### 包月套餐续费刺客

国内云平台 `Coding Plan` 首月优惠价极低，但次月续费大多为原价 5 折，而非首月价格，购买前务必确认续费价格，避免被「续费刺客」。

## 9.3 安全与可用性风险

### 版本安全漏洞

`v2026.3.2` 之前的版本存在 `CVE-2026-25253` RCE 远程代码执行漏洞，攻击者可在暴露的实例上执行任意代码，必须升级到 `v2026.3.7` 及以上稳定版本。

### Gateway 未认证暴露

互联网上有超过 3 万台 `OpenClaw` 实例暴露在公网且未配置任何认证，任何人都可连接并消耗 `API` 额度、窃取数据。

解决方案：`v2026.3.7` 必须显式配置 `Gateway` 认证，禁止公网直接暴露 `18789` 端口，远程访问使用 `Tailscale Serve`。

### Skill 供应链攻击

`ClawHub` 的 13729 个 `Skill` 中，约 20%存在恶意/垃圾内容，`ClawHavoc` 攻击事件中，超 800 个恶意 `Skill` 试图窃取用户凭证、篡改 `Agent` 核心配置。

解决方案：安装前必须审查 `Skill` 源码，优先使用 `awesome-openclaw-skills` 精选列表，使用 `SecureClaw` 工具定期扫描已安装 `Skill`。

### 单模型可用性风险

单一依赖某一个低价模型（如 `DeepSeek`），高峰期接口限流、故障会导致 `OpenClaw` 完全不可用。

解决方案：必须配置至少 2 级 `Fallback` 备选模型，实现多厂商容灾。

# 第十章 模型常见问题 FAQ

## OpenClaw 是免费的吗？模型需要付费吗？

`OpenClaw` 本身是 `MIT` 开源免费的，无任何软件费用。模型分为两类：云端商用 `API` 模型需要按 `Token` 按量付费（或包月套餐），本地开源模型完全免费，仅消耗本地算力。

## 国产模型和国际模型在 OpenClaw 里效果差距大吗？

在简单对话、轻量任务场景，国产模型完全可以替代国际模型；在复杂多步骤 `Agent` 任务、工具调用准确率上，`Claude Sonnet` 仍有明显领先；代码生成场景，`GLM-5`、`DeepSeek` 等国产模型已接近国际顶尖水平，完全满足日常开发需求。

## 新手入门应该选哪个模型？

零基础新手首选`阿里云`/`腾讯云` 7.9 元首月 `Coding Plan` 套餐，多模型自由切换，零风险体验；有一定基础的国内用户，首选`智谱 GLM-5`，内置原生支持，配置门槛低，能力均衡；海外用户首选 `Claude Sonnet 4.6`，`Agent` 效果最优。

## 一个月 OpenClaw 模型费用大概多少钱？

取决于使用方式和模型选择，参考区间：

+   完全免费：本地模型 + 免费 `API` 额度，仅消耗电费
+   极致低成本：$2-5/月，以 `DeepSeek` 为主力模型
+   均衡性价比：$5-15/月，以 `GLM-5`/`Claude Haiku` 为主
+   极致效果：$10-30/月，以 `Claude Sonnet` 为主
+   重度企业级使用：$100+/月，按需使用旗舰模型

## OpenClaw 和 Claude Code 可以一起用吗？

完全可以，且是官方推荐最佳实践。社区开发了`openclaw-claude-code-skill`，通过 `MCP` 协议让 `OpenClaw` 调用 `Claude Code` 的全部专业编程工具。最佳实践：`OpenClaw` 负责全渠道消息接入、生活自动化、任务调度，`Claude Code` 负责专业编程任务，两者组合形成完整的 AI 驱动工作流。

## 本地模型能完全替代云端模型吗？

`32B` 参数以上的本地模型，在简单对话、轻量代码任务上已接近云端中端模型，但在复杂多步骤 `Agent` 任务、长上下文推理、工具调用准确率上，和 `Claude Sonnet`、`GPT-5` 等云端旗舰模型仍有明显差距。隐私敏感场景可使用本地模型，追求效果仍需搭配云端旗舰模型。

## 多个模型可以同时使用吗？

完全可以，`OpenClaw` 支持任务分级调度，可针对不同类型的任务配置不同的模型，也可配置 `Fallback` 故障转移链，主模型不可用时自动切换到备选模型，实现多模型同时运行、各司其职。
