### 1. 配置环境

1. 在群文件中或者 [网盘(点击下载)](https://www.123pan.com/s/P8OAjv-Glhtv.html) 找到 `Termux` 并安装。如果安装不成功请检查手机是否已经安装过 `termux`/`zerotermux`，部分手机安装时需要关闭网络。

1. 启动 `Termux`，打开 `termux`，输入下方的完整命令并回车。脚本编辑：

```
curl -O https://raw.githubusercontent.com/hopingmiao/termux_using_Claue/main/tisac.sh && chmod +x tisac.sh && ./tisac.sh
```

1. 等待脚本自动下载安装，直到出现脚本主界面，如果出现报错，请检查自己的魔法是否有问题。安装失败或者中途卡住多半是魔法问题，换一套配置重新运行指令即可。

### 2. 配置 Clewd 与 酒馆

1. 输入 `2` 以启动酒馆，出现绿色网址（如：`http://127.0.0.1:8000/`）代表成功启动；若无自动跳转，则需要自行复制网址到浏览器打开，打不开的话尝试换个浏览器。

> 注意：`Termux` 需要挂在后台才能正常运行，请使用锁后台等方法对 `Termux` 进行保活；

> 华为/荣耀：手机管家-启动管理-`Termux` 设置为手动管理-勾选允许后台活动。

1. 稍等片刻弹出欢迎页，填写用户名进入酒馆。注意不要勾选 `Enable simple UI mode`，会导致功能缺失。

![](img/cbfebafcc1d54da046cb2e10e222fef0.png)

1. 回到 `Termux`，对着手机左上部分边缘屏幕右滑，然后点击 `NEW SESSION`。第一次会比较难滑出来，实在不行可先在手机系统设置中关闭全面屏手势。

## 二、手动部署 Clewd+酒馆（Termux）

### termux 下安装 Ubuntu 或者其他完整 Linux 环境

+ 首先更新包管理器（没换源开魔法）：

```
apt update && apt upgrade  
pkg update && pkg upgrade
```

+ 安装 Ubuntu 环境：

```
pkg install proot-distro 
proot-distro list # 可以省略
proot-distro install ubuntu
```

+ 添加 Ubuntu 到自启动：

```
echo "proot-distro login ubuntu" >> /data/data/com.termux/files/home/.bashrc
source /data/data/com.termux/files/home/.bashrc # 刷新自启动文件
```

+ 命令执行完后变成这样就是进入了 Ubuntu 环境，称为初始环境：

+ 由于配置了自启动，每次打开 `termux` 就会默认进入 Ubuntu 环境，可以重新把酒馆也部署在 Ubuntu 里面，如果要退出 Ubuntu 回 `termux` 打开酒馆记得新开一个终端页面（不会的别急，下面有说），然后输入：

```
exit
```

### 更新包管理器，下载 git 等命令

```

```

```
echo "export PATH=$PATH:/root/node-v20.10.0-linux-arm64/bin" >> /etc/profile
source /etc/profile
```


+ 直接用 `git` 下载最新版酒馆和 `clewd`：


### 配置相应文件

+ 修改 cookie 文件：

```
vim /root/clewd/config.js
```

+ 我这里安装 Ubuntu 环境时，默认安装了 `vim` 编辑器（如果没有则运行以下代码进行下载）

```
apt install vim
```

+ **vim 使用方法（重难点）**：

1. 打开文件后一开始随便按动键盘都是输入不了任何字符进入 `config.js` 文件的：

![](img/706d03dcaf5934217cd30095dfed1a39.png)

2. 按一下键盘上的英文字母 `i` 进入编辑模式：

![](img/2340183d383b2630a797b3f78f81514b.png)

3. 编辑完成后按一下 `ESC` 退出编辑模式：

![](img/ab3827fa4c77fc5ea54093c59ebfb8a0.png)

**进入编辑模式后，找到 `CookieArray :[]` 这一栏，在 `[]` 里面输入 `cookies`，本地部署需要使用英文双引号 `""` 来包裹每一个 [曲奇，英文逗](https://clewd.pages.dev/) 号隔开**，曲奇太多的话，可使用一键整理工具来处理

> 标准格式例如：`["cookie1","cookie2","cookie3","cookie4"]`，

4. 这个时候输入英文 `:wq!` 进行强制保存（注意：输入的是 `:wq!`），`:wq` 是普通保存，一般情况下两个都行，输入完进行回车。（如果不小心无处或者弄错不想保存，则输入 `:q!` 进行不保存强制退出）

![](img/80c30eceda2fb0e1ac2ac337687d170c.png)

5. 酒馆和 `clewd` 自启动两个选一个，两个不能同时存在

+ **设置 `clewd` 自启动**：

```
echo "cd /root/clewd" >> /etc/profile
echo "bash start.sh" >> /etc/profile
echo "cd /root" >> /etc/profile
```

+ **设置酒馆自启动**（不会自动跳转到浏览器页面，要输入地址 `127.0.0.1:8000` 进入，建议直接在浏览器里面保存酒馆书签）：

```
echo "cd /root/SillyTavern" >> /etc/profile
echo "bash start.sh" >> /etc/profile
echo "cd /root" >> /etc/profile 
```

+ **二选一执行后，刷新页面保存更改生效**：

```
source /etc/profile
```
