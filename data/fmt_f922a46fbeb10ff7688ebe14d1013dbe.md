---

三层结构：

+ 元数据（`SKILL.md` 头部）：名称 + 简介

+ 指令（`SKILL.md` 正文）：告诉 Claude 怎么做、读哪些文件

+ 资源（其他文件夹）：模板、示例、方法论等

> 路径你自己定：写 `templates/` ，Claude 就去读 `templates/` ；写 `docs/` ，就去读 `docs/`

---

### 场景：你说"帮我检查选题"，Claude 做了什么？

第 1 步：启动时，提示词里已经有书架目录

当你打开 Claude Code，系统自动把所有 Skills 的「名称 + 简介」写进提示词：

系统提示词

![](img/6431d44fce175af1611c8490e481fdd6.png)

Claude 不用去找，一开始就知道有哪些 Skills 可用。

关键：只有「名称 + 简介」，没有具体内容 → 省 Token

---

第 2 步：选书

你说"帮我检查选题"

→ Claude 匹配：哪个 Skill 的简介最相关？

→ 选中《写作助手》

---

第 3 步：翻目录（读 `SKILL.md`）

打开《写作助手》的 `SKILL.md`，看到指令和文件路径：

`skill.md` 内容

![](img/549f71e8b526e2825c50e64411573b5b.png)

你要"检查选题" → 找到路径 `methods/03-market.md`

> 路径是你自己定的，`SKILL.md` 里写什么路径，Claude 就去读什么文件。

---

第 4 步：读章节，执行任务

Claude 读取 `methods/03-market.md`，执行检查，返回结果：

✅ 受众明确

⚠️ 痛点需补充

✅ 选题有实用性

## 四、从 0 开始写一个 Skill

### 3 步搞定

3 个步骤

---

### 第 1 步：创建文件夹

在 `~/.claude/skills/` 下创建一个文件夹，名字就是你的 Skill 名称。

> Claude Code 会自动识别这个目录下的所有 Skills

---

### 第 2 步：写 `SKILL.md`

```
---
name: my-skill
description: 一句话描述这个 Skill 能做什么
---

# 使用说明

当用户说「xxx」时：
1.读取 templates/xxx.md
2.执行 xxx 任务
3.返回结果
```

---

关键：

+ `name` + `description` 是元数据，Claude 启动时自动加载

+ 正文是指令，告诉 Claude 怎么做

---

### 第 3 步：添加资源文件

```
~/.claude/skills/my-skill/
├── SKILL.md           ← 元数据 + 指令
└── templates/         ← 资源文件（你自己定义）
    └── xxx.md
```

资源文件夹的名字和结构你自己定，`SKILL.md` 里写什么路径，Claude 就读什么文件。

---

### 验证是否生效

```
&quot;我有哪些可用的 Skills？&quot;
```

Claude 应该能列出你刚创建的 Skill。

---

### 懒人方案：让 AI 帮你生成

不想手动写？直接用这个提示词：

```
帮我创建一个 Skill：

名称：[例如：weekly-report]
功能：[例如：帮我写周报]
使用场景：[例如：用户说&quot;写周报&quot;时，整理本周工作生成周报]

生成到：~/.claude/skills/[名称]/
包含：SKILL.md + 必要的资源文件
```

Claude 会自动帮你创建完整的 Skill 结构。

### 写作前：找素材

+ 📕 → 搜关键词，看高互动话题

+ 👸号监控 → 看阅读量高的文章，学结构

### 写作中：语音口述 + Skills 检查

#### 语音口述

工具：闪电说

+ 先说痛点 → 读者为什么要看

+ 再说方案 → 我要教什么

+ 逐步展开 → 每个要点

+ 最后总结 → 读者能得到什么

---

#### Skills 辅助检查

```
我：帮我检查一下这篇文章

Claude：
✅ 覆盖人群：3类
✅ 章节密度：合理
⚠️ 第七章内容较薄，建议补充示例

得分：85/100，可以发布
```

> 方法论在 Skills 里，Claude 自动检查，不用手动对照清单

---

### 发布前：排版

工具：Obsidian + AI 排版插件

+ 写完 Markdown → 一键转换格式 → 复制到👸号

---

## 附录 A：完整生成提示词模板

> 第五章提到的完整版，直接复制使用

```
我要创建一个 [领域] Skill，帮我生成完整结构。

## 基本信息
- Skill 名称：[例如：writing-assistant]
- 领域：[例如：自媒体写作]
- 使用场景：[例如：检查文章质量、诊断数据不佳原因]

## 文件位置
生成到：~/.claude/skills/[skill名称]/

## 核心功能
我需要这个 Skill 帮我：
1. [功能1 - 例如：写作前的选题检查]
2. [功能2 - 例如：写作中的结构优化]
3. [功能3 - 例如：发布前的终审打分]

## 我的定位
[about-me.md 内容]

## 检查框架
- 写作前：目标用户、选题验证、先验调研
- 写作中：结构检查、表达优化
- 发布前：标题优化、终审打分
- 发布后：数据诊断

## 我的成功案例
[粘贴你的成功案例]

## 我的失败教训
[粘贴你的失败教训]

## 我的方法论
[粘贴你学到的方法论]

## 架构要求
1.生成完整的 YAML frontmatter（`name` + `description`）
2.在 `workflows/` 目录创建独立的检查文件
3.每个 workflow 包含：
   - 具体检查项（checkbox 格式）
   - 重要程度标注（⭐数量）
   - 我的成功/失败案例对照
4.使用渐进式披露结构（`SKILL.md` 引用 `workflows`）

## 输出格式
请按照以下结构生成所有文件内容：
1.先生成目录结构说明
2.然后逐个文件输出完整内容
3.最后提供安装和验证步骤
```
