## 案例 1：代码生成与补全

**目标**：根据自然语言描述生成可用代码，并添加注释。

### 功能 1：需求转代码

**简介**：将功能需求直接转化为 Python/JavaScript 代码。

**步骤**：

1. **输入指令**（明确语言和功能）：

```
用 Python 写一个爬虫：  
- 目标网站：https://example.com/news  
- 需求：抓取所有标题和发布时间，保存为 CSV  
- 要求：用 requests 和 BeautifulSoup，添加异常处理  
```

2. **调用模型**：设置 `temperature=0.3`（平衡稳定性与灵活性）。

3. **输出结果**：

```
import requests
from bs4 import BeautifulSoup
import csv

url = "https://example.com/news"
try:
    response = requests.get(url, timeout=10)
    soup = BeautifulSoup(response.text, 'html.parser')
    # 提取所有新闻条目
    articles = soup.select('.news-item')
    with open('news.csv', 'w', newline='') as f:
        writer = csv.writer(f)
        writer.writerow(['标题', '时间'])
        for item in articles:
            title = item.select_one('.title').text.strip()
            time = item.select_one('.time').get('datetime')
            writer.writerow([title, time])
except Exception as e:
    print(f"抓取失败: {e}")
```

**技巧**：

+ **细化要求**：明确指定库版本（如 `BeautifulSoup4`）避免兼容问题

+ **防御性指令**：添加“考虑反爬机制”或“设置随机延迟”提升代码健壮性

def quicksort(arr):  
    # 基线条件：数组长度≤1时直接返回  
    if len(arr) <= 1:  
        return arr  
    # 选择中间元素作为基准值  
    pivot = arr[len(arr)//2]  
    # 划分左（小于基准）、中（等于基准）、右（大于基准）三部分  
    left = [x for x in arr if x < pivot]  
    middle = [x for x in arr if x == pivot]  
    right = [x for x in arr if x > pivot]  
    # 递归排序左右部分并合并  
    return quicksort(left) + middle + quicksort(right)  
```

        self.timeout = timeout
