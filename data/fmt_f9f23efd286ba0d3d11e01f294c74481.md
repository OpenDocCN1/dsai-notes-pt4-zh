
# open-webui v0.6.5 版本的主要更新亮点

> 来源：[https://qianniucity.feishu.cn/docx/OeDBdewgxoquVHxur5ccHIhYnyd](https://qianniucity.feishu.cn/docx/OeDBdewgxoquVHxur5ccHIhYnyd)

v0.6.5 是 Open WebUI 项目发布的一个最新版本，它在之前版本的基础上带来了多项新功能、改进和错误修复。这个版本继续巩固了 Open WebUI 作为 LLM 用户首选前端的地位，特别是在增强本地模型的使用体验和扩展模型能力方面。

## v0.6.5 版本的主要更新亮点（直接基于发布说明）

### 增强的 Ollama 集成与能力

+ 支持 Ollama 的助手模型（Assistant Model）： 明确支持 Ollama 后端中的 "assistant" 类型的模型，能更好地利用模型特性。

+ 为 Ollama 模型添加 Web Search 工具： 这是一个非常重要的更新！通过 Open WebUI，可以直接为基于 Ollama 运行的模型启用网页搜索功能，让本地模型也能获取实时信息，回答更具时效性的问题。

+ **Ollama 模型下载指示器：** 在 UI 中能看到模型下载的进度，提升用户体验。

### 改进的工具调用（Tool Calling）功能

+ **自定义工具创建 UI：** 引入了用户界面，可以直接在 Open WebUI 中创建和管理自定义工具，无需手动编辑配置文件，大大降低了工具使用的门槛。

+ 支持 LiteLLM 的工具调用： 将工具调用功能扩展到通过 LiteLLM 连接的模型后端，提高了跨平台/模型的工具可用性。

+ 支持 LiteLLM 的流式传输（Streaming）： 提升使用 LiteLLM 时模型的响应速度和用户体验。

### 用户界面与体验提升

+ **模型标签过滤：** 在模型选择列表中可以根据标签过滤模型，方便管理大量模型。

+ 增强的 Markdown 支持： 改进了对 Markdown 格式的支持，例如代码块可以显示标题。

+ 改进的助手提示词（Assistant Prompt）自定义： 提供更多选项来配置模型助手的行为。

+ **改进的管理员面板：** 提升了多用户或部署环境的管理能力。

### 其他改进与修复

+ 包括性能优化、多项错误修复，以及一些后台服务的改进等。

## 值得推荐的更新（基于历史更新趋势和 v0.6.5 的突出特性）

基于 Open WebUI 近期的发展趋势和 v0.6.5 版本包含的更新，以下几点是尤其值得推荐和关注的：

### 强化了本地模型（Ollama）的能力边界

+ **网页搜索工具（Web Search Tool for Ollama）：** 这是 v0.6.5 中一个非常突出的功能。以前，本地运行的模型受限于训练数据，很难回答关于最新事件的问题。通过集成网页搜索，Open WebUI 直接为本地模型赋予了实时信息获取的能力。这极大地提高了本地模型的实用性和竞争力，是推动本地 AI 应用发展的重要一步。如果你主要使用 Ollama，这个功能本身就非常值得更新到 v0.6.5。

+ **更深的 Ollama 集成：** v0.6.5 对 Ollama "Assistant Model" 的支持以及下载指示器等，都显示 Open WebUI 正努力最大化利用 Ollama 提供的特性，为用户提供流畅、功能丰富的本地模型体验。

### 让工具调用（Tool Calling）变得更加易用和普适

+ **自定义工具创建 UI：** 工具调用是扩展 LLM 能力（如执行代码、访问外部服务）的关键。v0.6.5 引入的 UI 界面，让不熟悉编程或配置文件的用户也能轻松创建和管理工具，这大大降低了利用工具调用来增强模型能力的门槛。这是一个重要的用户友好改进。

+ **跨后端工具支持：** 将工具调用扩展到 LiteLLM，意味着 Open WebUI 正在构建一个更通用的工具调用框架，未来无论使用哪个后端模型，都有可能利用上工具的能力。

### 持续优化用户体验和多后端支持

+ **UI/UX 改进：** 模型标签过滤、更好的 Markdown 支持、下载指示器等都是细节上的提升，但它们共同使得 Open WebUI 的日常使用更加便捷和舒适。

+ LiteLLM 性能提升（Streaming）： 针对 LiteLLM 后端的流式传输支持，解决了响应延迟的问题，使得 Open WebUI 在连接更广泛的远程模型时也能保持良好的性能体验。
