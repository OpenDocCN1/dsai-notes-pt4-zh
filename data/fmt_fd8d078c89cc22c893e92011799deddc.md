
# Overview  概览

> 来源：[https://kcn9ut4m7icc.feishu.cn/docx/P3R2d5YZpoNivGxByH5cO6vjnKb](https://kcn9ut4m7icc.feishu.cn/docx/P3R2d5YZpoNivGxByH5cO6vjnKb)

Overview of all `@` symbols available in Cursor for context and commands

Cursor 中所有可用 `@` 符号的概述，用于上下文和命令

In Cursors input boxes, such as in Composer, Chat and `Cmd K`, you can use `@` symbols by typing `@`. A popup menu will appear with a list of suggestions, and it will automatically filter to only show the most relevant suggestions based on your input.

在光标输入框中，例如在作曲家、聊天和 `Cmd K` 中，您可以通过输入 `@` 来使用 `@` 符号。将出现一个弹出菜单，其中包含建议列表，并且它将根据您的输入自动过滤，仅显示最相关的建议。

## Keyboard Shortcuts  键盘快捷键

You can navigate through the list of suggestions using the up/down arrow keys. You can hit Enter to select a suggestion. If the suggestion is a category, such as Files, the suggestions will be filtered to only show the most relevant items within that category.

您可以使用上下箭头键在建议列表中导航。按 Enter 可选中建议。如果建议是一个类别，例如 Files ，则建议将仅显示该类别中最相关的项目。

### Available @ Symbols  可用的 @ 符号

Here’s the list of all `@` symbols available:

这里列出了所有可用的 `@` 符号：

+   [`@Files`](https://docs.cursor.com/context/@-symbols/@-files) - Reference specific files in your project

`@文件` - 引用项目中的特定文件

+   [`@Folders`](https://docs.cursor.com/context/@-symbols/@-folders) - Reference entire folders for broader context

`@文件夹` - 引用整个文件夹以获得更广泛的上下文

+   [`@Code`](https://docs.cursor.com/context/@-symbols/@-code) - Reference specific code snippets or symbols from your codebase

`@代码` - 引用您代码库中的特定代码片段或符号

+   [`@Docs`](https://docs.cursor.com/context/@-symbols/@-docs) - Access documentation and guides

`@Docs` - 访问文档和指南

+   [`@Git`](https://docs.cursor.com/context/@-symbols/@-git) - Access git history and changes

Git - 访问 Git 历史和更改

+   [`@Notepads`](https://docs.cursor.com/context/@-symbols/@-notepads) - Access notepads

`@便签` - 访问便签

+   `@Summarized Composers` - Work with summarized composer sessions

总结作曲家 - 与总结作曲会话工作

+   [`@Cursor Rules`](https://docs.cursor.com/context/@-symbols/@-cursor-rules) - Work with cursor rules

`光标规则` - 使用 `光标规则`

+   [`@Web`](https://docs.cursor.com/context/@-symbols/@-web) - Reference external web resources and documentation

`@Web` - 引用外部网络资源和文档

+   [`@Link (paste)`](https://docs.cursor.com/context/@-symbols/@-link) - Create links to specific code or documentation

`@链接（粘贴）` - 创建指向特定代码或文档的链接

+   [`@Recent Changes`](https://docs.cursor.com/context/@-symbols/@-recent-changes) - Create links to specific code or documentation

`近期更改` - 创建指向特定代码或文档的链接

+   [`@Codebase`](https://docs.cursor.com/context/@-symbols/@-codebase) - Reference your entire [codebase](https://docs.cursor.com/chat/overview) as context (Chat only)

`@代码库` - 将整个代码库作为上下文参考（仅限聊天）

+   [`@Lint Errors`](https://docs.cursor.com/context/@-symbols/@-lint-errors) - [Reference lint errors](https://docs.cursor.com/chat/overview) (Chat only)

`@Lint 错误` - 引用 `lint` 错误（仅限聊天）

+   [`@Definitions`](https://docs.cursor.com/context/@-symbols/@-definitions) - [Look up symbol definitions](https://docs.cursor.com/cmdk/overview) (`Cmd K` only) There are also some other symbols that can be used:

`@定义` - 查找符号定义（仅限 `Cmd K`）还可以使用一些其他符号：

+   [`# Files`](https://docs.cursor.com/context/@-symbols/pill-files) - Add files to the context without referencing

文件 - 将文件添加到上下文中而不进行引用

+   [`/ Commands`](https://docs.cursor.com/context/@-symbols/slash-commands) - Add open and active files to the context

命令 - 将打开和活动文件添加到上下文
