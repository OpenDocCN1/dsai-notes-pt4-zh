## 二、上干货(万字文档)-上

### 末日题材分类

#### （一）丧尸末世流：受众最广（70%）

> 丧尸流的核心是**生存压力可视化**—— 读者能直观感受到被**追猎的恐惧”和 反杀的爽感**，且丧尸设定可深可浅。

**子题材**

**关键细节**：丧尸设定既真实又微创新

> 新手写丧尸别只写咬人、走得慢，一定要加 1-2 个 “小变异点” 拉开差距：

+ **基础款丧尸**：视觉退化（靠声音定位），弱点在太阳穴（捅刺即可致死），被抓伤 12 小时变异（给主角 “处理伤口的时间压力”）；

+ **特殊变异体**（前期出现 1-2 种即可）：

+ 速度型：瘦长体型，跑速快但防御低（可用钢丝陷阱绊倒，再补刀）；

+ 胖子型：行动慢，肚子里有未消化的物资（杀了能捡 “意外收获”，符合爽点）。

+ 参考《末日蟑螂》：早期只设计 3 种丧尸，靠 “听觉 / 速度 / 防御” 差异制造战术区别，前期 3 阶足够。

#### （二）末日基建流：男频女频都适用（20%）

> 囤货流的核心是“**满足读者‘未雨绸缪’的心理**”，优势是 “物资清单可查、安全屋改造有逻辑”，新手不用凭空想象。

> **2025 年最火的是 “重生 + 空间囤货”，因为 “预知未来” 能天然制造 “信息差爽点**。

> **流派分支**：

+ **硬核基建派**：《我在末世有套房》主角利用空间异能囤积物资，建立自给自足的避难所，通过 “太阳能发电系统”“雨水收集装置” 等细节还原生存细节。

+ 军事权谋派（满级难度很大，没市场）：《第九特区》以 “待规划区” 为背景，主角从底层警员成长为割据势力领袖，融合 “药线生意”“盐岛争夺” 等元素，展现资源战争的残酷性。

+ **科技复兴派**：《末日之重启文明》主角带领团队逆向研发 “核聚变反应堆”“基因修复药剂”，将末日背景转化为科技树攀爬游戏。

1. **两**大核心模块：捡垃圾/囤货 + 安全屋（漫剧《漫夏联盟》就是10月份的大爆款）

##### 模块 1：囤货清单（分 “必写项” 和 “加分项”，避免流水账）

+ **必写项**（生存刚需，制造 “紧迫感”）：

1. 水 / 食物：矿泉水（按 “每人每天 2 升” 算，主角空间囤 1000 升）、压缩饼干（保质期 3 年）、罐头（肉罐优先）；

1. 药品：抗生素（头孢 / 阿莫西林，治伤口感染）、碘伏 / 纱布（处理外伤）、退烧药（末日发烧 = 致命）；

1. 工具：撬棍（撬门 / 防身）、打火机 / 火柴（取火 + 消毒）、多功能工兵铲（挖地 / 砍树）。

1. 参考《末日：开局空间异能，只想摆摆烂》：主角重生后第一站去超市 “扫货”，重点写 “抢最后两箱矿泉水时和大妈争执”，既写实又有冲突。

+ **加分项**（体现 “细心”，拉满代入感）：

+ 日用品：女性卫生用品（别漏，体现细节周全）、肥皂（比洗衣液省水）、电池（手电筒 / 收音机用）；

+ 反套路物资：宠物粮（末日可能遇到流浪狗，可驯化当警戒犬）、种子（后期种田铺垫）

##### 模块 2：安全屋改造（让读者有 “养成感”）

> 新手别写 “凭空变出城堡”，要写 “一步步改造” 的过程，

> 改造路径：

1. 选址：优先老小区顶楼（只有一个入口，易防守）或 一楼带院子的房子（可围栅栏，种蔬菜）；

1. 初级改造（前 10 章完成）：

+ 门：加装钢板（找五金店定做，花光重生带的钱，制造 “资源压力”）；

+ 窗：钉木板 + 贴防爆膜（防止丧尸撞碎玻璃）；

+ 预警：门口挂铃铛（有人靠近会响），院子里埋铁丝（绊倒夜袭者）；

1. 中级改造（20 章后）：

+ 能源：太阳能充电宝（网购现成的，不用写 “高科技”）；

+ 储水：接雨水收集桶（配过滤棉，解决后期缺水）。

+ 参考《我在末世有套房》：主角每次改造都对应 “新危机”—— 比如发现丧尸会爬墙，立刻加焊防盗网，逻辑闭环。

#### （三）末日变异流：有一定难度，但是写好很吃香（5%）

> **变异流比丧尸流有**想象空间，优先选环境诱发的小变异

> — 比如 “红雾 / 辐射导致生物变异”，人类要么觉醒异能，要么被污染成怪物，设定简单且冲突强。

>

> 2025 年最火的是 “**精神变异 + 克苏鲁元素**”，因为 “看不见的恐惧” 比 “具象的怪物” 更抓心。

#### 新人易写的 2 种变异方向

##### 方向 1：环境诱发型（变异逻辑清晰，不用圆 “异能来源”）

+ 核心设定：比如 “红雾笼罩全球，吸入者 50% 变成‘畸变体’，5% 觉醒异能，45% 无变化”；

+ 畸变体设计（新手 3 种足够）：

+ 树妖：红雾里的树长出手腕粗的根须，会缠绕活人吸收体液，弱点是怕火（用打火机 / 酒精就能对付）；

+ 影怪：只能在阴影里移动，被强光照射会消散（主角觉醒 “手电筒异能”，完美克制）；

+ 异能设计（“弱开局 + 强关联”，避免后期崩）：主角觉醒 “红雾净化”—— 初期只能净化 1 平方米的雾（自保），升级后能净化畸变体（反杀），终极能净化小区域（建安全区）。

+ 参考《全球进化》：红雾变异的核心是 “生物链重构”，人类从顶端跌落，新手可聚焦 “小区 / 街道” 的小范围变异

##### 方向 2：精神污染型（悬疑感拉满，文笔要求低）

+ 核心设定：“血月出现后，人类会看到‘幻觉怪物’，抵抗力弱的会疯掉（变成‘狂徒’），主角能‘看见幻觉但保持理智’，还能‘触摸幻觉’”；

+ 写作公式：遇袭（看到 “无头骑士” 砍人，旁人以为是疯子伤人）→ 主角破局（用刀砍中 “骑士的影子”，幻觉消失）→ 暴露能力（被幸存者当成 “异类”→ 要么被崇拜，要么被排斥）→ 揭秘（血月是外星信号，幻觉是精神攻击）。

+ 参考《从红月开始》：主角的 “精神家人”（爸爸 / 妈妈 / 妹妹）其实是精神污染的产物，新手可简化成 “主角能和幻觉对话，获取信息”，既神秘又不用复杂设定。

#### （四）系统重生流：一般是重生+系统，也有单独分类（70%）

1. **系统流写法**

+ 核心设定：主角获得“系统”，可升级、打怪、兑换技能或物资。

+ 创作要点：

+ 系统的来源（外星、神秘、AI、异界等）。

+ 系统界面、任务、奖励机制。

+ 主角通过系统成长，逆袭成王。

+ 经典案例：

+ 《末世超武系统》：主角通过系统获得超武能力，在末世中崛起。

+ 《末世大回炉》：主角重生并绑定系统，可“回炉重炼”物品，不断变强。

2. **重生流写法**

+ 核心设定：主角重生回末日爆发前，利用记忆改变命运。

+ 创作要点：

+ 主角提前布局，囤积物资、招募队友。

+ 改变关键节点，拯救亲友，建立势力。

+ 经典案例：

+ 《黑暗文明》：叶晨重生回末日当天，利用未来记忆保护亲友，改变人类命运。

+ 《末世大回炉》：楚涵重生，用古武与科技结合对抗丧尸。

+ 重生囤货流的核心爽点是 “**对比**”—— 【前世惨，今生爽；别人慌，我稳赚】

+ 写作模板：

> 前世：你把最后半瓶水给了 “闺蜜”，结果被她推给丧尸当诱饵；今生：重生后第 3 天，“闺蜜” 上门哭求借水，你看着空间里的 1000 升水，笑着说 “我也没有”，转头关上门喝冰可乐（打脸爽点）；中期：别人还在抢罐头时，你已经用囤的种子种出了青菜，甚至能用 “多余的蔬菜换别人的武器”（信息差爽点）。

#### （五）规则重构流：类似规则怪谈，但更硬核（40%）

> **规则重构流是末日题材中较为硬核的分支，聚焦于【物理法则突变】或【超自然现象】导致的认知危机。**

#### 核心设定与创作要点

+ **规则异变：**涉及基础物理常数改变、逻辑悖论实体化、因果关系紊乱等世界根本规则的异常。这种变化应该是系统性、无法用现有科学完全解释的。

+ **生存逻辑：**在非常规环境下，角色必须摒弃常识，通过观察和实验理解新规则，建立全新的生存策略。成功依赖于敏锐的观察力、灵活的思维和冒险精神。

+ **探索与解谜：**故事推进依赖于收集异常现象数据、寻找模式、提出假说并验证。角色往往需要付出代价才能获取关键信息，增加故事的紧张感和成就感。

+ **理性叙事：**即使面对超常现象，也要保持内部逻辑的一致性和角色反应的合理性。角色的专业背景（如物理学家、工程师、程序员）知识可以增强故事的专业质感。

#### 经典案例

+ 《死在火星上》：

+ 天瑞说符的作品，讲述主角独自被困火星上的生存故事。

+ 通过严谨的技术细节描写，展现了在极端孤立环境下如何维持生命支持系统、解决技术故障的心理压力。

+ 《泰坦无人声》：同样是天瑞说符的作品，考察队在土卫六的科研站点遭遇了一系列无法用常理解释的诡异现象。作品通过科学团队的视角，描绘了当理性遭遇超自然时的认知危机和心理变化。

#### 注意：绝对不能碰的 5点（写了必被删）

1. **真实敏感元素**：别写真实地名（如 “北京朝阳区爆发丧尸”）、真实机构（用 “安全局” 代替 “某部委”）、真实名人；

1. **过度血腥暴力**：可以写 “杀丧尸喷血”，但别写 “活剖幸存者”“吃人细节”（平台会判定 “低俗”）；

1. **负面价值观**：别写 “主角主动屠杀无辜幸存者”“宣扬法西斯主义”（可以 “被迫反击”，但不能 “主动作恶”）；

1. **科学硬伤**：比如 “用矿泉水浇电线发电”（常识错误，读者会骂），不确定的细节问AI（如 “碘伏能不能消毒丧尸抓伤”）；

1. **战力失控**：别让主角 “从杀丧尸变成毁星球”（70% 弃文是因为后期变成玄幻）。
