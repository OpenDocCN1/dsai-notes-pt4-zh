# **超级个体实如何打造的！**

**超级****个人是最近非常流行的一个概念，他比个**人IP难度更多，所要涉及到的方面也更多，因为，你一个人，就要支撑起一个团队的工作！

其实，个人IP[做的只是](https://www.zhihu.com/search?q=%E4%B8%AA%E4%BA%BA%E5%93%81%E7%89%8C&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A%22631051258%22%7D)一个人设，一个品牌，靠着个人品牌的影响力，来吸引更多的流量！

但是，超级个体不一样，他不仅仅需要你做流量，还需要你自己设计产品，完成成交！

我们经常说，一个完整的商业闭环，最起码要有：产品，客户，成交率这个三个因素组成！

这要是放在一个公司，最起码要成立三个部门：产品研发部，营销部，成交部！

但是，一个超级个体，就要一个人支撑着三个部门的工具！

所以，想要成为一个超级个体，并没有说的那么简单！

首先，你要打造自己的IP，只有这样，才会更容易获取流量！

其次，你要涉及自己的产品，不管是实体的，还是虚拟的！

最后，你还要自己维护客户，经营私域，设计成交流程！

所以，这是一个全能的工作，既然是全能的工作，就需要系统的学习！而我们这套笔记，就是覆盖了想要成为一个超级个体所需要的所有细节内容！

对于想要往这方面发展的兄弟们来说，是非常有用且全面的一套课程！

当然，想要赚钱，其实有两个思路：

1、自己完成一个商业闭环；

2、成为别人商业闭环当中的一个环节。

其实，并不是所有人都有能力去支撑一个商业闭环的，所以，有的时候，去成为别人商业闭环中的一个环节，反而成了捷径！

就比如，你就会做流量，那么你加入一个成熟的商业闭环，你只负责引流，其他成交和产品都交给合作伙伴，你只要等着分钱就好了！

这样赚钱效率，反而会更高！

所以，我们这套笔记内容，你也可以自己给自己做一个判断，到底是自己要成为一个超级个体，还是在这几个环节中，挑出一个你自己擅长，且能顺利完成的工作，让他成为你的一技之长呢？

可能，看完整篇笔记的内容，你就知道该怎么做了！

# **第一部分：定位**

# **一、个人****IP定位**

## **1、根据竞争对手找定位**

在你看到的所有竞争对手里面，你认为，你可以成为谁那样的人！

因为如果你单独靠自己想象，是很难想象出来，你会成为谁，但是如果你眼前有一个标杆，或者榜样，你立马就可以说出，你要成为谁那样的人！

所以，你需要充分的去拆解你的竞争对手！

**A、寻找产品**

通过关键词搜索，深度挖掘你所在行业的产品关键词！

常用的关键词拓展工具：百度[营销工具](https://www.zhihu.com/search?q=%E8%90%A5%E9%94%80%E5%B7%A5%E5%85%B7&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A%22631051258%22%7D)、5118关键词扩展！

**B、产品拆解**

[拆解竞争](https://www.zhihu.com/search?q=%E4%BA%A4%E4%BB%98%E6%96%B9%E5%BC%8F&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A%22631051258%22%7D)对手的产品、市场规模、销售方式、产品价格、流量来源、交付方式等内容！

**C、挑选产品**

你要看哪些内容可复制，能长久，有复购，数据好，你能做！

按照这个要求，至少找出10个作为备选！

## **2、根据定位打造个人****IP**

**A、形象统一**

不管是在公域还是私域，你的昵称、头像、身份定位、经历、简介、标签、标志性形象，都要是一样的！

**B、价值统一**

你所输出的价值、个性、接人待物的方式、印象锚点，也都要保持一致！

**二、行业定位**

其实，所谓行业定位，主要还是定位用户人群！

**1、用户画像**

包括因素：性别，年龄，身份，习惯，地域，收入，偏好，需求等

**2、用户需求**

你会他不会，你懂他不懂，你有他没有

当你的专业遇到对方的需求，就会形成成交

## **3、痛点挖掘**

从来没有买过此类产品

在同行那里买过此类产品

用户选择买你产品的理由

一定是在你满足用户需求的同时，还保持一定的相关性和差异化！
