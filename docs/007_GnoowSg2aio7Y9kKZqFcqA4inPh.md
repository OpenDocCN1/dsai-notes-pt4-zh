# 所有无法解决的问题，最终一定会在更高纬里自动瓦解

小时候丢了钥匙，回家肯定要挨揍，觉得天都塌了，人生无望，现在回看，能有多大的事，钥匙丢了再配一把就是，成本2块钱而已，很多事儿，十年之后再看，不值一提。

每天问我问题的人很多，但真正问问题的很少，大多数人并非求知而来，要么是求认可，要么是想获得心态按摩，毕竟小智作为过来人，按摩技术比较管用，控心态，一旦需要借助外力来调整，就完了，因为随时可能崩溃，随时一塌糊涂，靠自驱，靠自己的力量来平衡，才是王道。公司一高管近期心态有些问题，号被封的封，限流的限流，状态全无，我一直在观察，没有干预，我助理说，要不聊聊？我说，不用，每个人都有自己的必经之路，这是对方的命运，会迈过去的。这两天，心态调好了，问题解决了，一切的问题，在不知不觉中都得到了解决。

三年前，我是个强迫症重度患者，遇到问题一定要立即解决，否则浑身难受，这也让我特痛苦，死命地盯着自己的所有细节，同时也死命盯着员工干的每一件事，都说，所有遇到的人，都是面镜子，照见自己，在工作中，对他人苛刻，其实是对自己的苛刻，在这种折腾下，发现很多问题无法解决，于是加倍痛苦，我是在什么时候放下的呢，就因为一句话；

尊重他人命运，尊重他人的人生轨迹，同时，也尊重自己的。

所有无法解决的问题，最终一定会在更高纬里自动瓦解。

问题的本身，可能从源头上就是错的，把水管接到粪坑里，水不能喝是一定的，非得要排查其中问题，管子的问题？净水器的问题？何必呢，跳出局外，拔高一个问题来看，它根本就不属于是个问题。试想一下，在过去的某个问题中，是不是类似。

从更高纬的角度思考问题，如果够不着，往后推十年来做决策也行，前两天一朋友来拜访我，他说，我感觉我什么风口都抓住了，就是没赚到钱，现在回头看，都是小打小闹，是因为格局不够吗？我说，如果今天让你穿越回10年前，你面对你正在干的生意，会如何决策？他说，一定会干大100倍。我说，时间的力量。现在，你在做决策时，或者思考问题时，如果是10年后的你，会怎么做？他说，懂了我说，我坚信私域IP这件事，是打心底的坚信，因为10年后的我，回到今天一定会卯足了劲地干私域，拉1000个矩阵，拉1万个矩阵，流量做大10万倍，所以我今天必须要这么干。

创业路，九死一生，我庆幸我都活过来了，**途中遇到了无数**的问题，我是怎么解决问题的？思考型的问题，**要么以十年后来**推，要么就是那句；所有无法解决的问题，最终一定会在更高纬里自动瓦解。执行型的问题，那更简单了，几乎所有执行层面的问题，都有标准答案，找个牛逼的人问就好了，

雷军说的时候，我草，我狠狠地共鸣上了。别瞎琢磨，别瞎折腾，搞什么创新，为了差异化而差异化，我觉得都是傻逼行为，你要是玩私域玩引流，你给我发个大红包，请我吃顿饭，我跟你说的方法论，比你研究测试3个月都靠谱，踏在前辈的肩膀上才是捷径。

**

**你的问题，不可能是独一无二的，你的问题，在别的成功者身上发生了千百遍，他是怎么解决的，能抄就抄，抄不会就问。

一干IP的哥们儿，一年下来赚百来万，又是折腾体系，又是折腾员工，死活上不了千万，然后给参哥交了个私董会，当面问了，对方回答；把你变现的那个动作重复100倍。抱着这句话回去，奉为圭臬，把其他无效动作全砍了，专注盯一个点，今年才不到10月份，已经赚了快2000万了。当然，在这儿我并不是神话谁谁，关于这个问题，有可能是他自己内心早有了答案，也有可能是从万千条路中，选出了一条最优解，可能性有很多，但最终结果是美好的，问题也得到了解决。

赚1000万，就一个字就能赚到——“干”。

不需要什么天赋，也不需要太高的智商，干就完了。但是别瞎干，会跑竞品很重要，比如说，我觉得很牛逼的打法，波波的路子，2019年我就给他付过费，当时他在广州搞分享会，五月美妆，冷爱等IP做嘉宾分享，接触过波波，我觉得这哥们儿能力很强，文案，钩子，思维，都是天花板级别，做IP，必起，然后很快就看到他从这个赛道走向了顶峰。要是跑他的体系咋跑，很多人只会傻逼逼分析他怎么运营，内容怎么做，抖音怎么做，甚至有人会嘲讽，哎呀，他抖音都封了，或者一个视频就几百点赞，没啥了不起的。

我觉得跑一个人的体系，必须跑明白3点：

1.流量 2.转化 3.产品交付

对方的流量打法，付费流还是免费流，内容怎么打？这只是其一。对方销转话术模板，第一句话怎么说的，你怎么回对方又是怎么回的，1：1复刻下来。我可以这么跟你说，波波的销转负责人江洋，销转能力绝对是王者级的，不像是机器式互动，也不像员工客服的答复，就是一个有血有肉有温度的人，在一步一步引导，有感情化得推向成交，而这背后，就是模板化，SOP的员工做到的，很牛逼。

**对方的有哪些产品？**产品分别是怎么交付的，真的跑竞品，把对方所有产品都买一遍，然后把对方所有交付全部记录下来，就像有的人跑我的体系，就看我几个视频，就得出一个结论；小智飞书文档做得牛逼，然后呢？没有了...不是这么跑的，我的内容布局；1.多少个矩阵 2.什么内容 3.在哪些平台 4.在哪些渠道。我是怎么做转化的，公众号文章？朋友圈？私聊？我有哪些产品，每个产品怎么交付的，付费全跑一遍。最后再找我面对面聊两次，这套体系才算跑完，能够学到50%

跑3个竞品，一套体系就出来了，剩下的，都是执行而已。所以哪来的那么多思考，什么规划，什么布局，扯淡的，这些问题，早就有了标准答案，去拿就行了。
