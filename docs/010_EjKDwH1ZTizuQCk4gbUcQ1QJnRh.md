# 超级个体应该拥有什么样的能力？

我们可以分别列出来：

### 1.强人物

招人喜欢，背景强，资源资源强，有一定的影响资源

自己+编导顶级策划（伯乐）

### 2.强故事

很强的故事模板，经历，经验，等等

第一类

自己人生活成了故事——你的人生就是笑话

第二类

提取故事,设计故事

把某一块故事拿出来

也需要伯乐去设计

### 3.强内容

非常会做内容

简称（大稿子）

专业mcn，策划，写大稿子

### 4.强专业内容

在某个领域有一定的深耕，比如：某个领域专家设计，直播运营，等等

还有就是自己巨专业，也可以是巨专业策划

拥有巨强的学习能力，调查加研究，可以更新迭代知识

这个非常费时间

### 5.强模型转化

可以理解为：操盘手，前端后端，商业，框架能力都很强的复合型人才

前面三个都需要都需要掌握什么样的能力？

1.声与气顿挫

2.说话的表达框架，表达支撑

3.表情，手势，头势

4.摄影拍摄加导演

5.及时提问能力

6.提问访谈能力

7.剪辑与后期

8.破坏是创新，完全创新式策划，无中生有最厉害

9.归纳整合能力，复盘能力

10.拥有自己的知识库体系

**这也是筛选的最低标准！**
