# 核心概念

> 来源：[https://hyperspace.feishu.cn/docx/JwgAdGmxjoGystxeCEgc9AlOn0b](https://hyperspace.feishu.cn/docx/JwgAdGmxjoGystxeCEgc9AlOn0b)

## 一、文心一言

文心一言是知识增强的大语言模型，基于飞桨深度学习平台和文心知识增强大模型，持续从海量数据和大规模知识中融合学习具备知识增强、检索增强和对话增强的技术特色。文心一言有五大能力，文学创作、商业文案创作、数理逻辑推算、中文理解、多模态生成。

## 二、Prompt

AI 模型提示词。在训练有监督学习或无监督学习的模型时，Prompt 可以帮助模型更好地理解输入的意图，并作出相应的响应。此外，Prompt 还可以提高模型的可解释性和可访问性。通俗地说，就是给 AI 模型提供一个“提示”或“指引”，帮助它更好地理解和完成任务。

## 三、可视化编排

平台提供了一种通过可视化界面，拖拽套件连接组合，快捷搭建业务流完成智能体开发的方式；此模式下平台已内置了如下能力，可开箱即用。

+   模型： 平台提供百度文心一言的大模型，开发者可直接调用。

+   数据： 可上传自有数据，支持模型对数据进行索引和提炼，服务用户。

+   框架： 平台内置对话式的 C 端模板样式，支持在对话场景下服务用户。

+   组件： 平台内置 C 端组件，如欢迎气泡语组件等，开发者可一键进行配置。

## 四、链

在可视化编排的开发模式下，平台提供了一系列开发套件，套件是业务流程的构建块，它们由定义其功能的输入、输出和配置参数组成。链是其中最重要的套件类型，它可以让我们把多个套件组合成一个插件，比如我们创建一个链，这个链可以接受用户的输入，然后通过提示词模板格式化用户的输入为提示词，然后把这个提示词输入给大语言模型，最终模型输出结果。我们也可以把一些链组合在一起，构建更复杂的链。
