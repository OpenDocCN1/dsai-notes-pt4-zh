# 如何入驻

---

[文心智能](https://passport.baidu.com/v2/?reg&tpl=&u=)体平台支持百度统一账号登录，如无百度账号可点击立即注册。

打开[文心智能体平台官网首页](https://agents.baidu.com/)，点击右上方 “登录” 按钮，登[录后点击 “立即进入”](https://agents.baidu.com/center) 按钮，就可以看到文心智能体平台体验中心页面。
