# 导入破限（即破除道德限制文件）的时候发现第一个界面和教程的不一样怎么办？

一般来说，导入破限的时候，是以下界面：

![](img/8794d0c167981d6cdf9420c316b29f8b.png)

我们可以看到这个界面导入和导出两个按键来对破限进行导入导出。

但是有的时候，在酒馆之中显示的是以下界面：

![](img/9274f2b9504150749cbddfd3b78a8da2.png)

如上图，可以看到，导入和导出的按键消失了。

**这个时候应该如何解决呢？**

解决办法如下：

![](img/d2db327eca49ed63562e7bdbff941994.png)

**如上图所示**

第一步，点击第5个酒馆窗口，然后会跳转到如上界面。

![](img/a56e9848cb3915ba5e7b3addb09e3204.png)

# 聊天界面变成只有半个屏幕了怎么办？

## 第一种情况

那就是第一种情况

![](img/496fcc93c52a8c26570a14df51daf241.png)

只剩下半个屏幕了

这说明你乱按到了“老婆模式”

这里科普一下：

![](img/566f108bab089b688b2c4f3a9fae86f0.png)

# 如何手动开启和关闭破限开关？

很多时候

萌新在上手酒馆时

会遇到卡的角色忽然变成魅魔的情况

或许可能是因为在过正常剧情的时候

开启了

NSFW的破限导致的

这个时候建议关闭包含NSFW的破限来正常过剧情

以下是关闭破限开关的方法（仅限新版酒馆）：

![](img/a9b4cb9d130adcbf081bf408538f3f6a.png)

如上图箭头所指的几个按钮

如果那几个按钮移到了右边

变成了蓝色（或者是你自己预设的颜色）

则是开启了破限

而变成灰色（如下图）

则是关闭了破限

**如果点不了**

**可能是卡了**

**多试几次**

![](img/8504c5229a4fa68a5d967060eca610ec.png)

对于一些不同于上图格式的破限

通常都会附有使用说明

![](img/3d737de4a4d4aeefd49c2e81608bfd9c.png)

点击编辑，阅读后关掉，照自己的需求操作即可

注意，使用说明是不能开启的，开了就直接发给AI了
