
# 0.AI视频制作工作流

> 来源：[https://vcn0zlxse9ua.feishu.cn/docx/UoOLdEzCqohXy5xkWH6cNTE5nPg](https://vcn0zlxse9ua.feishu.cn/docx/UoOLdEzCqohXy5xkWH6cNTE5nPg)

## 工作流程

![](img/cd721890e6a8044cb4deefa3b3cba2ae.png)

## 1. 创意脚本生成

创意脚本是AI视频制作的基础，它决定了视频的主题、情节和风格。可以使用文本生成类的AIGC工具来生成创意脚本，如Deepseek、ChatGPT、Claude、Kimi、Grok等。

示例提示: "我需要做一条AI创意短片，内容是'小米Su7 Ultra、薯队长（📕IP吉祥物）、冬季场景、春季场景、上海东方明珠塔'，我需要你为我写下这条短片的创意脚本，大概9个分镜"

## 2. 图像提示词生成

在有了创意脚本后，可以利用AI大模型根据分镜描述或图片内容反推出图像提示词（Prompt）。推荐使用Kimi，其操作流程与生成创意脚本类似。

示例提示: "我需要用AIGC工具创作一个短片。接下来，我会给你发送脚本内容。你需要根据我发送给你的信息，帮我生成StableDiffusion所需要的Prompt，注意，生成英文提示词后，再给我一份中文翻译的提示词，方便我查看"

## 3. 图像生成

根据生成的图像提示词，使用图像生成工具生成所需的图片。常见的图像生成工具有Midjourney、SD等。在生成图片前，需要明确视频的视觉风格、色调、画面构图、光影效果、景别以及画幅比例等关键要素。

![](img/524b3eb3fa7c14b26ab9da825c04d680.png)

## 4. 视频合成

将生成的图片等素材组合成完整的视频。可以使用多种AI视频生成工具，如：

+ Runway
+ 可灵
+ 海螺
+ 即梦

## 5. 后期剪辑与音效处理

### 后期剪辑

推荐 `剪映`

对合成的视频进行剪辑，调整视频的节奏、画面顺序等，使视频更加流畅和吸引人。可以使用专业的视频剪辑软件，如Adobe Premiere Pro、Final Cut Pro等也有其他一些AI视频剪辑工具，如闪剪、快剪辑等。

### 音效处理

为视频添加合适的背景音乐、音效和配音等，增强视频的感染力。可以使用Audacity等音频编辑软件进行音效处理，也有一些AI工具可以实现语音合成，如讯飞智作可进行语音合成、人脸建模、唇形预测等。
