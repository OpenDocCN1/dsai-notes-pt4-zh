## ✏️课代表✏️

- OpenAI 的创新在于将大量无标签文本用于模型的非监督预训练，然后通过针对性的监督微调适应特定任务，这种方法显著提升了模型的泛化能力。

- GPT 系列模型的发展历程被划分为三个阶段：早期探索阶段（GPT-1 和 GPT-2 的发展），能力跃迁阶段（GPT-3 及其变体如 Codex 和 InstructGPT 的出现），以及里程碑阶段（GPT-4 和 GPT-4O 的推出，标志着人工智能发展的新纪元）。

- GPT 模型的核心思想是通过预测下一个单词来捕捉文本的生成过程，这种方法使得模型能够更准确地理解和模拟人类语言。

- OpenAI 在推动人工智能安全和对齐人类价值观方面做出了显著贡献，特别是通过强化学习与人类反馈相结合，提高了模型遵循指令和避免生成有害内容的能力。

- 随着模型规模的扩大，GPT 系列展现了更强大的语言理解和生成能力，同时也引发了关于超人级智能监管和安全问题的讨论。
