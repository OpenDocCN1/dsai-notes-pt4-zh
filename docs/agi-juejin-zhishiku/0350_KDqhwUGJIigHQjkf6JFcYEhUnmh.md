我个人认为，OpenAI 通过 ChatGPT 带来的[，除了模型和产品交互界面的革命（见前文 ](https://km3dl0ffdl.feishu.cn/wiki/ATIlwX3PvimTLIk157aco8JKnxJ)LLM时代**的产品设计革命：大模**型带来的人机交互范式的转换是如何影响产品设计的？ ），还有 科技发展范式的革命 ：

传统的科技发展范式是：

1、高校、研究机构、科学家在某个前沿科技领域取得革命性突破；

2、研究成果在学界引起轰动（或者默默无闻）、但在业界寂寂无名；

3、几十年后，某个天才企业家在该前沿科技领域锐意进取，用第一性原理思考，无意之中发现了该科研成果，并尝试在业界商业化；

4、又过了几年几十年，该公司成功商业化，技术改变了业界、也改变了全世界；

5、就在该技术已经成为如空气一般稀松平常的某一年，诺贝尔物理学/化学奖公布，耄耋之年的科学家A获此殊荣，媒体纷纷跟进梳理他改变世界的历史。

**——你可以看到，**产学研是**分开的**：1） **既在主体上**分开；2） **也在时空上分开**；这也导致了科学研究造福人类的速度是 缓慢的 。

但 OpenAI 通过以 ChatGPT 为**代表的 LLM 研发，似乎一**直在展示： 科技发展是可以产学研一体的。

如今的 OpenAI（Anthropic、Inflection等第一梯队的AI公司同理）， 同时是研究和商业化应用的最前沿 ，这保证他们能以任何传统的高校、科研机构或者公司（比如当年的贝尔实验室）都难以望其项背的速度推进AI研究和应用，以完成他们的AGI理想：

1） OpenAI 走在 LLM 科研的最前沿，吊打任何高校和科研机构 。他们拥有最强的算法能力、可能最强的算力（核心是背靠微软、拥卡无数）、最强的数据（依赖亿级用户的数据积累、数据飞轮）；

相比之下，本应该在科研上走在最前面的高校和研究机构，因为缺**乏 LLM 所需要的核心算力**，只能反而 通过算法采摘「低垂的果实」 ，通过类似 Chain of Thought 的方式去突破——这些当然是有价值的，但是他们完全没用动到核心的模型的权重，没法从根本上改变研究方向；

2） **OpenAI 走在 LLM 产品和商**业化的最前沿，（可能）领先所有商业公司 ：ChatGPT 是史上最快 MAU 破亿产品，目前可能MAU达到2.8亿、营收破百亿人民币，拥有无可比拟的数据飞轮（比如宝贵的用户问答训练集）；

——当然，这和行业是有密切联系的，LLM作为纯代码层面的「线上技术」，应用可能天然就比类似锂电池等「物理技术」更快。

即便如此，由于科技在人类历史上的颠覆性意义（《三体》里描述的科技发展促进文明爆发式前进），这种科技发展范式的转换仍然是革命性的，从长远来看， 这可能是比LLM技术本身对人类历史影响更大的事情。
