## 注册与登录

【从此步骤开始不区分 Mac/Win，即两种版本账号注册方式一致】软件装机完成后，按软件引导提示进行注册。

可以根据个人喜好选择主题颜色和语言。

可以自主选择是否配置命令，如不需要，可以点击跳过，进入账号登录页面。

账号登录页面——选择登录按钮进行初次注册。

### 三种注册方式

此环节开始有部分步骤需要配置 🛜 环境，可根据步骤提示进行配置。

| 账号授权1: Github 授权 | 账号授权2: Google 授权 | 直接注册 |
| --- | --- | --- |
| 选择 Github 授权登录 | 选择 Google 授权登录 | 个人邮箱直接注册 |

✅ 无论是 GitHub 账号还是 Google 账号，授权成功后，会跳转回 Trae 页面，则为注册成功。

⚠️ 注册完成后的两种情况：

| IP 在国内 | IP 在国外 |
| --- | --- |
| 此处跳转回 Trae 官网页面，Trae 页面会显示 `App Unavailabe`，此时需要手动配置全局 🛜 环境至软件可用的国家或地区，清单在此文档最后的链接。 | 首先会显示 `login successful` 角标，其次跳转软件使用以及下载页面 |

💡 注册完成后，不会自动登录，登录以及使用需要可以访问谷歌的 🛜 环境，如果登录后退出，也需要重新配置 🛜 环境进行登录。

白话：不注册不登录可以用 IDE 但用不了 AI 功能（`chat&builder`），只要登录了就可以无限制使用功能。并且完成登录后，没有谷歌 🛜 环境也可以正常使用全部功能。

目前可支持的国家或地区详见：

`https://docs.trae.ai/docs/supported-countries-and-regions?_lang=zh`
