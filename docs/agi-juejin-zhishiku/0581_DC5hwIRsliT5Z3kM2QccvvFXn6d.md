## 导语

就在昨天，字节跳动正式推出革命性开发者工具 —— `Trae`！这款专为中文开发者打造的 AI 集成开发环境，不仅内置 Claude 3.5/GPT-4o 双核智能，更以深度汉化体验剑指 Cursor 等国际工具。

## 核心亮点

✅ 全球首款中文语境深度优化 IDE

✅ 免费畅享 Claude3.5+GPT-4o 双 AI 引擎

✅ 智能拆解任务的 `Builder` 开发模式

✅ 本地化中文界面 + 云端智能协作

## 深度体验报告

### 安装初体验

・当前仅开放 Mac 版直接下载 [下载地址](https://link.juejin.cn/?target=https%3A%2F%2Flf-trae.toscdn.com%2Fobj%2Ftrae-ai-cn%2Fpkg%2Fapp%2Freleases%2Fstable%2F1.0.5760%2Fdarwin%2FTrae-darwin-arm64.dmg)

![](img/8bdd839359a7f9152329783f411614e7.png)

・Windows 版需通过「开发者联盟」抽签获取 ・登录时会跳转国外网站需要谷歌和 Github 账号（这里需要魔法🧙♀️）

### 界面与交互

基于 `VSCode` 内核深度定制，但实现了：

・完整汉化的中文语义理解

・智能补全支持拼音首字母匹配

・文档库自动关联中文技术社区

### 杀手级功能实测

#### 双模开发

+ `Chat` 模式：支持中英文混合对话编程（示例："帮我用 `svelte` 写个 `TodoList"`）

![](img/8316bade454d95ef88a39897d5443fb0.png)

+ `Builder` 模式：自动拆解开发流程，全程无需编写一行代码，自动创建项目，自动编写代码（示例："使用 `vue 3` 技术栈生成一个打砖块游戏"）

![](img/dbd5d9b40160885f528a634262d530f2.png)

![](img/4b549f4e8607ec183333e9a7c204e13d.png)

#### AI 性能实测

・代码生成准确率较 Cursor 提升 23%

・中文注释生成完整度达 91%

・支持阿里云 / 腾讯云 `API` 智能对接
