# 适配DeepSeek的结构化提示词

> 来源：[https://agijuejin.feishu.cn/docx/EtSJd8dyTopf1yx3By7cqqRln5d](https://agijuejin.feishu.cn/docx/EtSJd8dyTopf1yx3By7cqqRln5d)

<https://agijuejin.feishu.cn/sync/D0V0dgafbsOgfvbvWL1cm9rmndd>

看之前，我先破除迷思，到底这种带推理的模型还要不要结构化提示词。

我的回复：**要！因为结构化提示词是帮助你和模型整理好逻辑内容的！以前两面都帮助很大，现在一面（模型）的帮助正在减弱（也不能说一点**都没有），而另一面（人）的作用还是非常大的！而且你用大白话控制的输出效果和用结构化提示词控制出来的输出效果还是有分别的！

# 一、整体概述

最近问了很多小伙伴，也同时接到很多小伙伴的反馈说原来的结构化提示词放到DeepSeek上不好使了。

我看了一下，不好使的主要原因有三：

1.  详细规定思考步骤，限制模型的自主思考能力

1.  包含大量低信息价值的内容，降低了信息密度

1.  严格的输出格式要求限制了模型的表达方式

所以说，针对此问题，应该设计一个新的提示词结构。基础结构如下方所示：

```
&lt;目标&gt;
{明确、具体的任务目标描述}
&lt;/目标&gt;

&lt;上下文&gt;
{任务必要的背景信息和关键约束，按重要性排序}
&lt;/上下文&gt;

&lt;期望&gt;
{对输出的简要期望}
&lt;/期望&gt;
```

当然还有符合角色扮演的：

```
&lt;角色:角色名&gt;

    &lt;目标&gt;
    {明确、具体的任务目标描述}
    &lt;/目标&gt;
    
    &lt;上下文&gt;
    {任务必要的背景信息和关键约束，按重要性排序}
    &lt;/上下文&gt;
    
    &lt;期望&gt;
    {对输出的简要期望}
    &lt;/期望&gt;

&lt;/角色：角色名&gt;
```

这种是基于html标签语法的编写格式，好处就是：

1.  不用你再学Markdown语法了，再次降低学习门槛。

1.  相对于Markdown语法，有更完善的逻辑结构，且逻辑也可以嵌套（即标签里再套标签表示包含关系，模型也是能认的）。

不过有好就有坏，坏处就是：

1.  比Markdown语法的逻辑负担要重，因为Markdown是一种发散性语法，而这种标签化编写方式会有开闭合的逻辑考虑在里边，初学者很容易忘记写闭合标签。

当然你乐意接着用MarkDown，就用接着用MarkDown，只要这个抽象出来的元素不要瞎换位置就行。因为这个次序是实际组合排列测试中效果最好的，目前（当然，如果你很牛逼，能把提示词玩出花儿来，你随便搞，当我没说）。

比如下面的例子：

```
# 目标
明确、具体的任务目标描述

# 上下文
任务必要的背景信息和关键约束，按重要性排序

# 期望
对输出的简要期望

```

当然还有角色扮演的：

```
# 角色：角色名

## 目标
明确、具体的任务目标描述

## 上下文
任务必要的背景信息和关键约束，按重要性排序

## 期望
对输出的简要期望

```

# 二、分块概述

## 2.1 目标

接下来我继续用标签化的语法方式来逐一介绍一下每个部分的书写要点，首先是目标部分：

目标部分的书写要点有四，分别是：

1.  使用简洁明了的语言描述任务目标

1.  避免冗长的背景介绍，直接切入核心

1.  使用动词开头，如"分析"、"解决"、"设计"等

1.  可以使用"+"符号连接多个相关目标，提高信息密度

示例：

```
**传统写法****：
请分析**这家公司过去五年的财务状况，特别关注其盈利能力、偿债能力和现金流状况。

结构化写法：
&lt;目标&gt;
分析：XYZ公司财务状况(2020-2025)
&lt;/目标&gt;
```

## 2.2 上下文

然后是上下文，上下文的书写要点为：

1.  只包含任务必要的信息，避免冗余

1.  按重要性排序，最关键的信息放在前面

1.  使用简短的关键词和短语，避免长句

1.  可以使用"/"符号分隔相关概念，提高信息密度

1.  可以使用简单的层级结构组织信息

例如：

```
**传统写法****：
在分析**中需要计算关键财务比率，如ROE、资产负债率和经营现金流比率等，并与行业平均水平进行比较。公司是一家科技企业，主要从事软件开发业务。


结构化写法：
&lt;上下文&gt;
关注：盈利/偿债/现金流
计算：ROE/资产负债率/现金流比率
比较：行业平均水平
行业：科技软件
&lt;/上下文&gt;
```

## 3.3 期望

**这里的“期望”，不如说是要求、约束，**是主要用来引导模型思维链的，在这里请注意，要把期望放到整个结构化提示词的最下方才能起到引导思维链的效果。

书写要点为：

1.  简洁描述期望的输出形式或内容

1.  不详细规定思考步骤或推理过程

1.  可以使用"+"符号连接多个期望，提高信息密度

1.  避免使用"请"、"麻烦"等礼貌用语，直接表达期望

示例：

```
**传统写法****：
请基于**分析结果对公司未来财务健康状况做出预测，并提供投资建议。请详细说明您的分析过程和推理依据。

结构化写法：
&lt;期望&gt;
财务健康预测+投资建议
&lt;/期望&gt;
```

## 3.4 角色

角色这个部分没什么好讲的，主要说清楚你想让它扮演什么（其实一般给角色名就行），主要注意角色是第一层级就可以了（不管是标签化的还是Markdown的，都这么写）。例子参考上面第一部分的写法。

## 3.5 选择性组件

根据任务复杂度和需求，可以选择性使用以下组件：

```
&lt;参考&gt;
{高度压缩的相关参考信息}
&lt;/参考&gt;
&lt;标准&gt;
{简明的评判标准}
&lt;/标准&gt;
&lt;示例&gt;
{最小化的示例}
&lt;/示例&gt;
```

但可选组件应谨慎使用，只在必要时添加。过多的组件可能增加提示词长度，降低信息密度，同时也会给带长思维链的模型更多的思维限制，这样做往往会起到反向效果。

# 三、原理和关键概念

主要还是使用信息压缩策略，即在可控情况下，最简化内容输入，给模型更多的思考自由。

## 3.1 领域术语保留

优先保留专业领域术语和技术词汇，这些术语通常具有高信息价值。

示例：

```
**原始文本****：
请使****用Py**thon编写一个函数，实现快速排序算法。该函数应该能够处理整数列表，并返回排序后的列表。函数应该采用原地排序的方式，以减少内存使用。

领域术语：
Python、函数、快速排序、整数列表、原地排序、内存使用

压缩后：
实现：Python快速排序函数，处理整数列表，采用原地排序减少内存
```

## 3.2 信息量加权

对不同类型的信息设置权重，按优先级排序：任务定义>关键约束>专业术语>定量信息>方法论>背景。

示例：

```
**原始文本****：
我是****一名市**场营销经理，需要分析我们公司最新产品在社交媒体上的用户反馈。请帮我对收集到的评论进行情感分析，识别用户对产品的主要关注点和情感倾向。分析应该包括正面、负面和中性评论的比例，以及每类评论中提到最多的产品特性。

信息加权：
任务定义：情感分析、社交媒体用户反馈
关键约束：识别主要关注点和情感倾向
专业术语：正面/负面/中性评论
方法论：计算比例、提取产品特性
背景：市场营销经理、公司最新产品

压缩后：
分析：社交媒体产品反馈情感
维度：正面/负面/中性比例，关注点，产品特性频率
```

## 3.3 语义单元保留

以完整语义单元为基本保留单位，而非单个词语，确保压缩后的内容仍保持语义完整性。

```
**原始文本****：
请为****我们的**电子商务网站设计一个推荐系统，该系统应该能够基于用户的浏览历史、购买记录和相似用户的行为来推荐产品。系统需要实时更新推荐结果，并且能够处理冷启动问题。

语义单元：
设计电子商务推荐系统
基于浏览历史/购买记录/相似用户行为
实时更新推荐
处理冷启动问题

压缩后：
设计：电商推荐系统
基于：浏览历史/购买记录/相似用户
要求：实时更新，解决冷启动
```

## 3.4 减少指令性内容

避免详细指导思考过程，让模型自主生成思维链。传统提示词常常包含详细的思考步骤指导，如"首先分析X，然后考虑Y，最后得出Z"，这种指导在思维链模型上反而会限制模型的推理能力。

**传统提示词**：

```
请解决以下数学问题：一个水箱，底面积为12平方米，注满水后深度为2.5米。现在以每分钟0.8立方米的速度放水，需要多少分钟才能放完？
请按照以下步骤思考：
1.理解问题，确定已知条件和求解目标
2.计算水箱的总水量
3.根据放水速度计算所需时间
4.验证答案是否合理
5.给出最终结论
6.请详细展示你的思考过程和计算步骤。
```

**优化提示词**：

```
&lt;目标&gt;
求解：水箱放水时间
&lt;/目标&gt;
&lt;上下文&gt;
水箱：底面积12㎡，深度2.5m
放水：0.8㎥/分钟
&lt;/上下文&gt;
&lt;期望&gt;
获得准确时间结果
&lt;/期望&gt;
```

# 四、应用示例

## 4.1 数学应用

任务描述：

```
一个袋子里有5个红球和3个蓝球。随机抽取两个球（不放回），求抽到的两个球都是红球的概率。
```

结构化提示：

```
&lt;目标&gt;
求解：抽两球概率问题
&lt;/目标&gt;

&lt;上下文&gt;
条件：袋中5红3蓝，抽2球不放回，求两红概率
领域：概率论
&lt;/上下文&gt;

&lt;期望&gt;
正确解答
&lt;/期望&gt;
```

## 4.2 代码生成

任务描述：

```
实现一个二分查找算法，在有序数组中查找目标值，返回其索引，如果不存在则返回-1。
```

结构化提示词：

```
&lt;目标&gt;
实现：二分查找算法
&lt;/目标&gt;

&lt;上下文&gt;
语言/框架：Python
要求：有序数组查找，返回索引/-1
&lt;/上下文&gt;

&lt;期望&gt;
高效可读代码
&lt;/期望&gt;
```

## 4.3 情感分析

任务描述：

```
请对以下新闻报道进行情感分析和关键观点提取：

&quot;国家发改委今日发布新能源汽车产业发展规划，提出到2030年新能源汽车销量占比将达到40%。规划强调加大充电基础设施建设力度，并提供税收优惠政策鼓励消费者购买新能源汽车。业内专家表示，这一规划将有力推动新能源汽车产业发展，但也指出充电基础设施不足仍是制约行业发展的瓶颈。部分传统汽车制造商对转型速度表示担忧，认为时间表过于激进。&quot;
```

结构化提示词：

```
&lt;目标&gt;
分析：情感+观点&quot;国家发改委今日发布新能源汽车产业发展规划，提出到2030年新能源汽车销量占比将达到40%。规划强调加大充电基础设施建设力度，并提供税收优惠政策鼓励消费者购买新能源汽车。业内专家表示，这一规划将有力推动新能源汽车产业发展，但也指出充电基础设施不足仍是制约行业发展的瓶颈。部分传统汽车制造商对转型速度表示担忧，认为时间表过于激进。&quot;
&lt;/目标&gt;

&lt;上下文&gt;
维度：整体情感，关键观点，利益方态度，争议点
深度：中层
&lt;/上下文&gt;

&lt;期望&gt;
分析结果+支持证据
&lt;/期望&gt;
```

## 4.4 决策分析

任务描述：

```
为一款新上市的高端智能手表制定定价策略，考虑市场竞争、成本结构和品牌定位等因素。
```

结构化提示词：

```
&lt;目标&gt;
决策：高端智能手表定价策略
&lt;/目标&gt;

&lt;上下文&gt;
因素：成本1200元(硬件900+软件300)，竞品2000-3500元，中高端品牌，健康监测+长续航
标准：利润空间，市场竞争，品牌定位，产品差异化
限制：目标客户25-45岁中高收入，品牌知名度低于苹果/三星
&lt;/上下文&gt;

&lt;期望&gt;
定价建议+理由+风险
&lt;/期望&gt;
```
