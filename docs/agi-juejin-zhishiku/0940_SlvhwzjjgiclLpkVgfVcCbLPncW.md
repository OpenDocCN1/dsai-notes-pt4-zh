## ✏️课代表✏️

+ 大模型在数据查询领域的应用可以通过 `Python` 代码或 `SQL` 语句两种方式实现，但两种方式都对大模型的能力有较高的要求。

+ 现有的数据查询框架，如 `DBGDP` 和 `pandas as AI`，虽然能够生成 `SQL` 语句，但 `DBGDP` 缺乏纠错机制，而 `pandas as AI` 通过自纠错提高了生成准确性。

+ `VA` 项目通过引入检索机制，降低了大模型生成 `SQL` 语句的难度，提高了生成准确性。

+ `VA` 项目允许用户参与到模型的训练中，通过用户的反馈和修正，不断提升模型的查询准确度。

+ 利用本地大模型（如 `Qwen2-7b` 模型）进行数据查询，可以实现快速且准确的查询结果。

+ `VA` 项目的可视化界面简化了用户操作，使得非专业人士也能够方便地使用和调试大模型进行数据查询。

+ 随着用户的不断迭代和数据集的完善，`VA` 项目能够适应更复杂的数据结构和业务需求，展现出较高的适应性和实用性。
