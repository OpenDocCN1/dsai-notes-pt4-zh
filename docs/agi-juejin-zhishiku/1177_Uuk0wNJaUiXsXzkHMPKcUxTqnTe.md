## 1亿个“外包”生成新的数据

我们看一下腾讯的观点，引入了Persona Hub——一个由网络数据自动整理的10亿个多样化角色的集合。这10亿个角色（约占世界总人口的13%），作为世界知识的分布式载体，可以挖掘LLM中几乎所有的视角，从而有助于为各种场景大规模创建多样化的合成数据。通过展示Persona Hub在大规模合成高质量数学和逻辑推理问题、指令（即用户提示）、知识丰富的文本、游戏NPC和工具（功能）等方面的应用，我们证明了基于角色的数据合成具有多功能、可扩展性、灵活性和易用性，有可能推动合成数据创建和应用的范式转变，对LLM的研究和发展产生深远影响。

Persona Hub 可以促进以十亿级别的规模创建合成数据，模拟来自各种真实世界用户的多样化输入（即用例）。如果将这些数据用作查询目标 LLM 的输入以大规模获得其输出，那么 LLM 的知识、智能和能力将有很高的风险被倾倒并且容易被复制，从而挑战最强大的 LLM：GPT-4。

如图1所示， 创建数据包括两个关键要素，问题和角色，进行排列组合，例如：搬家公司司机和数学问题结合，可以生成类似小学生的应用题。角色可以与广泛的数据合成提示（例如，创建数学问题或用户提示）配合，引导 LLM 以相应的视角合成数据。Persona Hub 中的10亿个角色可以促进各种数据合成场景下的十亿级别的合成数据创建。

## 合成数据集的关键问题

1.数据的准确度

加入原始的黄金种子语料{prompt:answer}集合是准确的，那么LLM生成的新的数据集 {{prompt: new answer} ,{new prompt:answer} {new prompt: new answer} }都面临一种问题，新生成的问题和答案，如何保证准确性?

1.数据的广度

人的知识是优先的，LLM也是。如何保证LLM生成的数据可以覆盖世界上已知的知识范围，或者说那些是LLM生成死角？生成的数据，是像 5年高考3年模拟一样，可用覆盖我们的高考题，可用把世界知识更新一遍？

2.数据的深度

1+1=2的知识，人类已经熟悉。如果只是换个外壳，核心逻辑必变，新生成的知识其实是无效的，冗余的。
