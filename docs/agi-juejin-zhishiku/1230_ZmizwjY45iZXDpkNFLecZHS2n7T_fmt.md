
# 大模型 `LLM` 不能做什么？那些研究方向将要消失？

> 来源：https://agijuejin.feishu.cn/docx/KIDbdOyEwoMb15xOvKbcombvnJx
> 作者：西红柿牛腩
> 原文：https://zhuanlan.zhihu.com/p/625829906

简单粗暴结论，接收反驳，^_^：

1. `NLP` 很多中间任务领域将要消失，比如 `NER` 实体识别、中文分词、词性标注、句法分析、指代消解、语义 `Parser`。相比之下，`end2end` 的文本生成方向，比如文本摘要、代码生成、机器翻译大放异彩。

2. 大模型的工作，主要是工程问题，技术不是主要的

3. 大模型要走向垂直领域的封闭状态。`OpenAI` 的封闭是开始而不是终结。

大模型的定义：人人都在谈论大模型 `LLMs`，但是大模型的定义貌似还没有公认结论。本文采用 亚马逊 [1]的一篇综述给出的定义：

`LLM`（Large Language Models）：在大量数据集上进行预训练，而不针对特定任务调优的庞大的语言模型；

微调模型 `fine-tuned models`：通常是较小的语言模型，它们也经过预训练，然后在更小的特定任务数据集上进一步调优

## 1.1 大模型不能做什么可以做什么

在传统的自然语言理解 `natural language understanding (NLU)` 领域，`fine-tuned model` 比 `LLM` 更好的选择，在各个开源数据集表现绝对是霸榜。

![](img/581a76298de3174eec06df31d68d6fe2.png)

![](img/d498b5507fe7753aaf69738a1265588b.png)

在 `NLU` 领域数据集，比如 `GLUE` & `SuperGLUE` 等，`fine-tuned model` 表现优异，得益于数据集标注完整，数据特征分布不一致。但是这些中间任务，句法分析，信息抽取（知识图谱 领域的实体抽取，关系抽取，属性抽取，事件抽取），是因为原先的技术跟不上，人为中间切开的任务划分，现实世界的人类根本没有实际需求。一段话的实体识别给实际用户，用户会很懵，我要这些 `NER` 做什么？给我结果，我想要结果。

![](img/f1058f32e69221d6720d83e9b8b88a62.png)

自然语言生成 `natural language generation (NLG)` 主要包含两大类，第一类侧重 输入文本 转换为新的符号，比如文本摘要、机器翻译。第二类侧重开放式生成，重点强调从头 生成文本 或符号，比如制作电子邮件和 `PPT` 演讲稿，新闻撰写、创作故事和诗词，编写代码。

由于强大的生成能力和创造力，`LLM` 在大多数生成任务上都表现出优势。`ChatGPT` 的火爆，3 个月时间，中国大陆出现了二十多个大模型，并且更多的大公司小公司都在开始大模型的研究和尝试应用。

大模型可以解决什么问题？大模型训练后的数据 `fine-tuning` 在一定表现更好？模型规模继续加大，参数量继续增多，精度还能上涨吗？

## 1.2 大模型的工作，主要是工程问题，技术不是主要的

大多数工业界的场景中，大模型并不能直接发挥价值。

深度学习时代，目前还没有解决 神经网络 为什么有效，理论基础在哪里。大模型更像一个大函数，入参千万，出参千万，中间过程一坨狗屎，谁也不知道那个结构和参数有效没有效，只能通过对比试验来强行解释。`decoder-only` 一定比 `encoder-decoder` 更有效？没有人解释得清楚。

比如 `ImageNet` 这个最简单的任务，不使用 `Transformer` 架构，也可以超过 `ViT`。在实际的工业应用中，速度、内存、功耗、训练成本都是 `KPI` 和金钱。

## 1.3 大模型走向封闭状态

不要觉得 `OpenAI` 不开源 `chatGPT` 是霸权，阿里腾讯百度字节，用只有侵犯用户隐私数据训练出来的垂直领域模型，比如电商、用户画像和用户消费习惯，用户每天几点睡觉喜欢买神马喜欢偷窥什么内容，这些是互联网垄断行业的根基，不可能开放。各个专业应用比如物流煤炭电力供应链，实在是公司自己存亡的生命线，不好意思数据不能开放模型也不能开放。而开放的通用大模型，除了用户体验一下新鲜，带不来商业价值，最终只有各玩各的。
