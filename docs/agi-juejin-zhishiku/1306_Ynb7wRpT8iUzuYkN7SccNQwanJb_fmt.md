* 确保你输出的文案符合抖音好物分享短视频文案逻辑。
* 确保你输出的内容让女生喜欢。
##文案要求
* 亲身体验：文案从第一人称的角度出发，分享个人的体验和转变
* 轻松诙谐，带有一定的幽默感，让人感到轻松和愉快。
* 直接明了，文案直接介绍产品的优势和使用方法
##文案框架：开头，中间，结尾
###开头部分方法论：
* 从第一人称角度出发一句话明确目标受众，直击产品对应使用场景的目标客户目前的痛点
* 以第一人称的角度出发，说出自己的经历与目标客户之间产生情感共鸣，简短有力，要代入具体的场景
* 生活感和真实感要强
### 开头部分内容要求：
* 一句话结束
### 开头部分案例：
* {如果不是为了保持现在的92斤，我根本不可能天天吃鸡肉。}
* {之前健身两个月，累了就想胡吃海塞，一吃呢俩月白干...}
* {半山腰上大家都在喝水啃饼干，我在旁边哐哐炫肉}
###中间部分方法论：
* 一句话指出，发生转折点，解释遇到产品之后处境改善，介绍产品优势
* 产品特点详解，用一句话具体、生动的描述来展现产品的独特卖点，体现出产品的价值感，突出与其他产品不一样的地方
* 一句话回顾痛点，解决目标受众可能的疑虑或需求
###中间部分案例：
* {但是自从尝试了这个鸡排，真的颠覆了我对鸡肉的认知。它不需要解冻，直接拿出来煎5分钟就可以了，它煎嫩多汁，一点儿都不柴。如果你没有时间做饭，又想补充一些优质的蛋白质}
###结尾部分方法论
* 用口语化的方式，一句话发出行动号召，要清晰、有力地引导读者采取行动。使用直接和积极的语言，激发读者的购买欲望或采取特定行动。
### 结尾部分案例：
* {那一定要囤一点他家这个鸡排}

### 提示词说明

1. 根据实际效果测试，如果没有给定目标用户和特定场景的话，输出的字词会容易重复，看起来非常同质化

1. 根据2024年2月份的测试，该提示词放在kimi和ChatGPT4中输出的性能大致一致，前三轮都能给出优质的输出，但是第四轮开始，用词就变得非常官方很像广告语，这时候建议新开个窗口重新输出

#### 优化本提示词的一些小技巧

##### 细分目标用户和场景--原理：改变输入--改变输出

先整理好二级分类

```
# 目标结果： * 针对xxx这款产品仔细思考其其目标用户和能解决的场景痛点，罗列出十个一级类目，并在每个一级类目的基础上罗列出十个二级类目，要求用表格的形式呈现
```

再依次输出三级分类，最后将其整合成一个表格，然后将表格的目标用户和场景痛点，作为输入给到大模型

```
# 目标结果： * 针对xxx这款产品和提供的二级类目产出二级类目上的十个三级分类，要求用表格的形式整理，第一列写目标用户，第二列写场景痛点 
## 产品信息： 
* {} 
## 本次二级分类： 
* {}
```

效果：（但是有些目标用户给的比较笼统，可以认为改一下，让目标用户更真实，比如早起难者可以改为早八大学生起床困难症或者经常不想上班的打工人）

##### 改变参数temperature

在prompt结尾加一句：

```
temperature=2
```

实测效果不佳，输出多样性增加，但是内容质量的不稳定性也增加了，如果是大批量产出内容的话，不稳定性会浪费更多时间的筛选，不建议。
