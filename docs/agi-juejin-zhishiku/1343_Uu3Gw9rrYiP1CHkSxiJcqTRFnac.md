## 一、内容展示

首先展示下我利用文心一言4.0创作的类似“感时花溅泪，恨别鸟惊心”这样的句子，和它的一些解释吧！

![](img/ffef7649da5b0a0ce113eae3c95d75f4.png)

虽然不是每一个回答都不错，但是胜在速度快，数量多，通过挑选可以找到合适的内容。

### 1. 诗句一

烽火连天下，家园半已荒。秋风催叶落，离愁断人肠。

![](img/048ccfd27e6b276e55d807e2113330c6.png)

**解读 **：此诗描绘了战乱时期的凄凉景象。烽火连天象征着战争的持续和激烈，家园的荒芜则反映了战争对人们生活的破坏。秋风和落叶的意象增添了萧瑟之感，而离愁和断肠则表达了人们对亲人和家园的深深眷恋与无奈。

### 2. 诗句二

岁月匆匆去，江山换新颜。旧梦今何在，空余泪满衫。

![](img/9ab9b8f72dd789e2e808f98ece37a0cd.png)

**解读 **：这首诗表达了诗人对时光流逝和物是人非的感慨。岁月匆匆，江山已然改变了模样，而曾经的梦想和记忆却逐渐模糊。诗人不禁泪流满面，感慨万分。

### 3. 诗句三

落日孤城闭，秋风万木凋。何时归故里，把酒话桑麻。

![](img/354f64b0a59245d2e2e118d79f877c33.png)

**解读 **：此诗描绘了秋日傍晚的孤寂景象。落日余晖中，孤城紧闭，秋风萧瑟，万木凋零。诗人怀念故乡和亲人，期盼着能够早日回到故里，与亲朋好友把酒言欢，共话桑麻之事。

## 二、提示词创作

要让AI写出符合我们想法的内容，需要掌握提示词的使用方法，而这是需要有逻辑结构而且需要学习的，内容干货较多，建议可以收藏避免遗忘。

下面我简单给大家阐述下我做提示词的思路，并且放上这个提示词的内容给到大家分享。

### 1.提示词结构

关于人工智能大语言模型的提示词（Prompt），是我们与人工智能沟通的基础，尽量简明扼要，同时给到足够的信息，才能让大模型读懂我们想要什么。

![](img/e1036a2d9ad1a441d6b0fb95bcdb5b7b.png)

通常我会按照这样的形式来创建提示词结构，我将提示词的结构语法分为四大块：

**【背景、技能、案例、任务】， **只要按照这个结构顺序写出你的需求，然后再根据这个结构去丰富内容，你就能够创作出指令明确的提示词，让人工智能更好帮助我们提高工作效率。

下面我来举例阐述这四大块应该怎么做。

### 2.语法详解

![](img/0b86bce77e399a9ff8199497bc02e2dc.png)

**背景： **描述你想要创作提示词对象的基本情况和背景知识，交代需要人工智能语言大模型扮演的角色及专长。

```
参考：【你不仅是一位杰出的诗词创作者，更是深入研究唐朝大诗人杜甫的专家。】
```

**技能： **描述你想要人工智能工具能够掌握的能力，便于更加精确掌握你希望他能做的事情。

```
参考：【你深刻理解并能熟练运用杜甫的诗歌艺术和写作技巧，包括他独特的押韵方式和对现实生活的深刻提炼。你能精准选取生活中的典型元素，用简洁的诗句揭示社会现象的本质，同时也能通过人物间的对话，精炼地介绍和概括各类事件。
你的艺术创作既展现了宏大的视野，又不失细腻的笔触。你拥有如杜甫般的爱国情怀和深厚知识底蕴，这使得你的诗作能够呈现出雄浑壮阔的艺术境界。同时，你也擅长捕捉生活中的微妙细节，通过精细的景物描写和情感表达，让读者感受到你内心的细腻波动。
你在诗歌创作上展现了全面的才华，无论是五言、七言，还是古体、律诗、绝句，你都能游刃有余地驾驭。你特别擅长运用古体和律体，将叙事、抒情和议论巧妙地融合在一起，形成了你独特的诗歌风格。你的诗作不仅善于记录历史实况，反映时代的变迁，更在字里行间流露出深刻的人文关怀，无愧于“诗史”之称。】
```

**案例： **给人工智能语言大模型一个案例，告诉它应该朝着哪个方向去创作。

```
参考：【正如杜甫的名句：“国破山河在，城春草木深。感时花溅泪，恨别鸟惊心。”你的诗歌也有力量触动人心，引人深思。】
```

**任务： **明确告知人工智能语言大模型你要干什么，要它按照什么格式和内容去完成什么内容，有什么需要注意的要点。

```
 参考：【接下来请你写出类似案例的句子，每一首都应该附上你的解读。这你是最优秀的诗人，我相信你可以做得更好，请深呼吸一步一步认真思考后回复】
```

我通过了解背景知识，首先知道是唐朝的杜甫写的，并且了解到了他的一些背景知识和他在文学上的人物特点，因此我将背景与技能进行了详细的描述。
