考虑一个设计用于帮助金融分析师回答有关公司业绩的问题的大型语言模型（LLM）应用。借助良好设计的检索增强生成（RAG）管道，分析师可以回答诸如“X公司2022财年的总收入是多少？”这样的问题。这些信息可以由经验丰富的分析师轻松从财务报表中提取。

现在考虑一个问题：“从2023财年Q2的业绩电话会议中有哪三个要点？重点关注公司正在构建的技术壁垒。”这是金融分析师希望得到答案以包含在他们的报告中的类型问题，但需要投入时间来回答。

我们如何开发解决类似问题的解决方案？很明显，这个信息需要的不仅仅是从一个收益电话中简单查找。这个问题需要规划、定制焦点、记忆、使用不同工具，并将一个复杂问题拆分成更简单的子部分。这些组合在一起的概念基本上就是我们所称的LLM Agent。

在本文中，我介绍了由LLM驱动的Agent，并讨论了Agent是什么以及企业应用的一些用例。有关更多信息，请参阅《构建您的第一个Agent应用程序》。在那篇文章中，我提供了一个生态系统概述，涵盖了构建AI Agent的可用框架，并为任何试验问答（Q&A）Agent的人提供了一个入门指南。

## 什么是AI Agent？

虽然没有广泛接受的LLM驱动Agent的定义，但可以描述为一个系统，它可以使用LLM来推理问题，创建解决问题的计划，并借助一组工具执行计划。

简而言之，Agent是一个具有复杂推理能力、记忆和执行任务手段的系统。

这种能力最初在项目中首次观察到，例如`AutoGPT`或`BabyAGI`，在这些项目中解决了复杂问题而没有太多干预。为了更多描述Agent，这是一个LLM驱动Agent应用程序的一般架构图（图1）。

Agent由以下关键组件组成（稍后将详细介绍这些组件）：

+ Agent核心

+ 记忆模块

+ 工具

+ 规划模块

## Agent核心

Agent核心是管理Agent的核心逻辑和行为特性的中央协调模块。可以将其视为Agent的“关键决策模块”。这也是我们定义以下内容的地方：

+ Agent的总体目标：包含Agent的总体目标和目标。

+ 执行工具：实质上是Agent可以访问的所有工具的简短列表或“用户手册”。

+ 解释如何使用不同规划模块：有关不同规划模块的效用的详细信息以及在什么情况下使用哪个。

+ 相关记忆：这是一个动态部分，在推理时填充与用户过去对话中最相关的记忆项。通过用户提出的问题来确定“相关性”。

+ Agent的人格（可选）：这种人格描述通常用于偏向模型以更喜欢使用某些类型的工具或在Agent的最终响应中灌输典型的特质。Agent核心可以访问目标、工具、规划助手和答案的一般格式。

## 记忆模块

记忆模块在AI Agent中起着关键作用。记忆模块本质上可以被视为Agent的内部日志存储和与用户的互动。

记忆模块分为两种类型：

+ 短期记忆：Agent经历的行动和思维的账本，试图回答用户的一个问题：Agent的“思路”。

+ 长期记忆：关于用户和Agent之间发生的事件的行动和思考的账本。它是一个包含跨越几周或几个月的对话历史的日志。

记忆需要更多的不仅是基于语义相似性的检索。通常，综合分数由语义相似性、重要性、最近性和其他应用特定的度量组成。它用于检索特定信息。

## 工具

工具是定义良好的可执行工作流程，Agent可以用来执行任务。它们通常可以被看作是专门的第三方API。

例如，Agent可以使用RAG管道生成上下文感知答案，使用代码解释器解决复杂的编程任务，使用API在互联网上搜索信息，甚至使用像天气API或即时消息应用程序的简单API服务。

## 规划模块

复杂的问题，例如分析一系列财务报告以回答一个层次化的业务问题，通常需要细致入微的方法。通过LLM驱动Agent，可以使用两种技术来处理这种复杂性：

+ 任务和问题分解

+ 反思或批评

### 任务和问题分解

复合问题或推断信息需要某种形式的分解。例如，问题：“NVIDIA上次的收益电话有哪三个要点？”

回答这个问题所需的信息无法直接从一个小时长的会议记录中提取。但是，这个问题可以分解为多个问题主题：

+ “哪些技术变革被讨论得最多？”

+ “是否有任何业务阻力？”

+ “财务结果是什么？”

这些问题中的每一个都可以进一步细分。也就是说，专门的`AIAgent`必须引导这种分解过程。

### 反思或批评

诸如`ReAct`、反思、思维链和思维图等技术已经作为基于批评或证据的提示框架。它们被广泛用于改善LLM的推理能力和响应。这些技术也可以用于改进Agent生成的执行计划。

## 企业应用的Agent

尽管Agent的应用几乎是无限的，但以下是一些可能对许多企业产生巨大影响的有趣案例：

+ “与您的数据交谈”Agent

+ Agent群

+ 推荐和体验设计Agent

+ 定制AI作者Agent

+ 多模态Agent

### “与您的数据交谈”Agent

“与您的数据交谈”并不是一个简单的问题。有许多挑战是一个直接的RAG管道无法解决的：

+ 源文件的语义相似性

+ 复杂的数据结构，例如表格

+ 明显上下文的缺失（并非每个块都包含其来源的标记）

+ 用户提出的问题的复杂性

+ ……等等

例如，回到之前的收益电话记录示例（2023年Q3 | 2024年Q1）。你如何回答问题：“2023年Q3和2024年Q1之间的数据中心收入增长了多少？”要回答这个问题，你基本上必须分别回答三个问题（即，我们需要一个规划模块）：

+ 2023年Q3的数据中心收入是多少？

+ 2024年Q1的数据中心收入是多少？

+ 两者之间的差异是多少？

在这种情况下，你需要一个`Agent`，该`Agent`可以访问一个进行问题分解的规划模块（生成子问题并搜索答案直到解决更大问题）、一个RAG管道（用作工具）来检索特定信息，并且有记忆模块以准确处理子问题。在《LLM驱动Agent：构建您的第一个Agent应用》中，我详细介绍了这种类型的情况。

### Agent群

Agent群可以理解为一组`Agent`，它们共同存在于单一环境中，并能相互合作解决问题。一个分散的`Agent`生态系统很像多个一起使用的“智能”微服务。

类似`Generative Agents`和`ChatDev`的多`Agent`环境在社区中非常受欢迎（图3）。为什么？像`ChatDev`这样的框架使您能够构建一个由工程师、设计师、产品管理、CEO和`Agent`组成的团队，以低成本制作基本软件。像Brick Breaker或Flappy Bird这样的热门游戏可以以低至50美分的成本制作出原型！

通过`Agent`群，您可以在数字公司、社区甚至整个城镇中进行应用，例如经济研究的行为模拟、企业营销活动、物理基础设施的用户体验元素等。

### 推荐和体验设计Agent

互联网依赖于推荐。由`Agent`驱动的对话recommendation systems可以用于打造个性化体验。

例如，考虑一个在电子商务网站上的`AIAgent`，它帮助您比较产品并根据您的一般请求和选择提供推荐。还可以构建完整的礼宾式体验，多个`Agent`帮助最终用户导航数字商店。类似选择观看哪部电影或预订哪个酒店房间的体验可以构建为对话，而不仅仅是一系列决策树样式的对话！

### 定制AI作者Agent

另一个强大的工具是拥有个人AI作者，它可以帮助您完成诸如协作编写电子邮件或准备及时会议和演示等任务。常规作者工具的问题在于，不同类型的材料必须根据不同的受众进行定制。例如，投资者演讲必须用不同于团队演示的措辞。

`Agent`可以利用您之前的工作。然后，`Agent`可以根据您的个人风格塑造一个由`Agent`生成的演讲，并根据您的特定用例和需求定制工作。这个过程通常对于一般LLM的微调来说太微妙了。

### 多模态Agent

仅有文本作为输入，您无法真正地“与您的数据交谈”。所有提到的用例都可以通过构建多模态`Agent`来增强，这些`Agent`可以处理各种输入，例如图像和音频文件。这只是可以解决企业挑战的几个方向的示例。用于数据整理、社交图表和领域专业知识的`Agent`都是开发社区为企业应用正在积极追求的领域。

## 接下来呢？

LLM驱动的`Agent`与典型的聊天机器人应用不同，因为它们具有复杂的推理能力。`Agent`由`Agent`核心、记忆模块、一组工具和规划模块组成，可以在各种企业环境中生成高度个性化的答案和内容，从数据整理到高级电子商务推荐系统。

要了解关于`Agent`的技术生态系统的概述，例如实现框架、必读论文、文章和相关主题，请参阅《Building Your First Agent Application》。对于无框架实现问答`Agent`的演示可以帮助您更好地与数据交流。
