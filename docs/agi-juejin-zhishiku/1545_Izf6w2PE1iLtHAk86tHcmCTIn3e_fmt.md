今天我们来简单聊聊如何为我们的智能助手`LLM`（大型语言模型）打造更棒的工具。下面是一些写工具时的小技巧，可以帮助减少与`Agent`交互时的意外：

+ 编写有用的工具提示词：确保工具描述简洁且信息量足够，让智能体能够正确使用工具。

+ 使工具对部分输入更“宽容”：比如，更新邮件草稿，我们可以让助手只提供草稿`ID`，其他信息默认从邮件本身获取。这样助手就算少输入一些信息，也能完成任务。

+ 输入验证和`Agent`错误处理：如果助手调用工具的方式有问题，我们可以通过返回提示让它自己纠正。比如，更新草稿时没提供草稿`ID`，我们就告诉助手：“你没给`ID`哦，记得要提供。”

+ 提供与工具相关的简单函数：有时候助手处理一些简单的日期计算可能会遇到困难。我们就可以在工具里加个简单的函数，让它直接获取当前日期。

+ 从执行更改的函数返回中加一些提示：有些函数执行数据变更，返回的数据可能对助手没啥用。这时，我们可以在返回值里加些提示，帮助助手理解它做了什么。

+ 最后一点，如果工具返回的数据太大，超出了助手的处理范围，我们就需要考虑用索引来存储响应，让助手能够读取。

最后，开发中调试工具的一个好方法是问助手它自己有什么工具，接受什么参数，用来干嘛的。这样可以帮助我们找出提示中的不足，或者找出为什么助手用不好我们开发的工具。
