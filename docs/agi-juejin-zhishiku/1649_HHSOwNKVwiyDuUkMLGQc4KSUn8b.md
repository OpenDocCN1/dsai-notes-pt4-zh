## ✏️ 课代表 ✏️

- Ollama 0.3.0 版本的发布标志着工具调用能力的正式支持，这是一个重要的更新，使得 Ollama 能够更加灵活地与工具集成。

- 通过示例代码和 agent 构建过程，强调了 Ollama 的开源性和易于使用的特点，以及如何利用 Ollama 提供的模型和库来实现复杂的功能。

- 强调了使用 land graph 来构建 agent，这有助于清晰地表示和理解 agent 的执行流程和决策逻辑。

- 讨论了 Ollama 与 OpenAI 接口的兼容性问题，尤其是在 embedding 接口上的差异，并指出了社区中相关的讨论和进展。

- 提醒大家关注 Ollama 的官方发布和社区更新，以便及时了解最新的功能和改进。
