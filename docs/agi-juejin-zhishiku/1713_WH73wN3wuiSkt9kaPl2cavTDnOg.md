# ✏️课代表✏️

+   Flux Control Net 模型在安装和使用时可能会遇到报错，但通过正确的分支切换和命令行操作可以解决。

>

+   Control Net 的参数设置对最终图像的质量有显著影响，强度和结束时间不宜设置过高，以避免过拟合和图像崩坏。

>

+   Control net 的训练集可能存在缺失或过拟合，导致在处理某些类型的图像时效果不佳。

>

+   LoRA 集合在实际应用中可能会表现出与预期不符的效果，例如动画 LoRA 在提高强度时图像反向变得写实。
