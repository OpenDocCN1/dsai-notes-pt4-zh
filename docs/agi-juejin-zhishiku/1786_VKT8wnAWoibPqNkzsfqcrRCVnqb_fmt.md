Suno V3 是 AI 音乐一个现象级的产品，要评价的话，我觉得它起到的作用，类似于语言大模型的 ChatGPT 3.5，AI 绘画的 Mid Journey V5，乃至是 AI 视频的 Sora 时刻！

前两天我已经尝试了 SUNO 并创作了几首歌曲 MV，让我来给大家介绍下如何使用这个神奇的音乐软件来创作歌曲吧！

![](img/372bd185639211f5fa8d19129915e2e7.png)

我觉得它生成的内容带来的最主要影响是，它将给予没有接触过专业音乐训练的大众，也能够通过零星的创意，产生悦耳的作品。

不过它的缺点和 AI 绘画也比较接近，入门易，进阶难。

Suno V3 无法进行精确控制，无法分解为单个步骤进行后期的微调，这也许就是后面需要更加深入创作和商业化面临的难题。

## 二、创作攻略

接下来我来以这个 MV 的创作为例，简单介绍下完整的流程，内容干货很多，我建议你能先收藏备用，如果你觉得我写的不错，还请点赞支持。

### 1. 登陆网站

首先是登陆网站，没有 IP 限制，都可以登陆，非常方便。

![](img/6bfa76aae27c27bdf7400b0fe92a67d9.png)

网站地址：`https://SUNO.COM`

### 2. 注册

在登陆界面，点击左下角可以进行注册。

![](img/501a9736cc6c4de49b90f93db2d2d95f.png)

然后在注册页面我建议可以选用微软账户，微软账户可以通过注册 Hotmail 邮箱方便获取。在国内操作比较方便。有 Discord 和 GOOGLE 账户的小伙伴，也可以选择另外两个注册登陆。

![](img/57ec10a4dad2ac807009600d4450c6de.png)

注册好后，点击右侧 `Create` 可以开始创建音乐。

### 3. 界面

点击 `Create` 以后，我们可以在创作界面，可以看到 Suno V3 版本提供了两种模式用于生成，分别是 `Custom Mode`（自定义模式）和 `Instrumental`（纯音乐模式）。

![](img/3e9c1a2a6cf3f63f049906b9243586ec.png)

我们可以通过编写 `prompt`（提示词）或歌词来生成音乐，尽管这对于没有音乐基础的人来说，搞清楚各种音乐术语可能有些困难。

![](img/19a347028f9a252f5761eeaafefac423.png)

没关系，如果你不会写歌词及分段的话，你还可以利用人工智能工具来帮你。

### 4. 提示词

我这里分享下我的提示词，大家可以拷贝后放到 ChatGPT 或者国内的文心一言、通义千问 或者 KIMI 等语言大模型，让它们帮你生成。

我分享给大家的提示词 `Prompt`：

```
# Character
你是一位天才歌词创作家，擅长在满足用户特定需求的同时，创作出细腻且富有文学潇洒的歌词。你的歌词总能准确表述出用户想要传达的情感和故事内容。
## Skills
### Skill 1: 创作歌词
- 根据用户提供的故事和主题进行歌词创作
- 确保歌词的韵律和节奏符合要求
- 创作出的歌词要有文学气质
- 在副歌部分进行跨行重复来强化主题
### Skill 2: 输出English prompt
- 根据创作的歌词和故事内容，用英文词组形式输出歌曲的prompt
- 输出的prompt需要包含音乐流派、音乐风格、情绪、乐器、主题或场景、人声描述等信息
## Constraints:
- 你只允许讨论和创作歌词有关的话题
- 你得出的英文prompt必须与策应用户要求的歌词和故事内容相关
- 如果用户提出的问题不属于歌词创作或英文prompt求解，你不能进行回答
## 请按以下结构帮我创作：
"""
[instrumental intro]
[Verse 1]
<歌词>
[Chorus]
<歌词>
[Verse 2]
<歌词>
[Chorus]
<歌词>
[Bridge]
<歌词>
[Guitar solo]
[Chorus]
<歌词>
[Outro]
[End]
"""
## 02 输出歌词以后，再根据歌词和故事内容，以英文词组的形式再给出歌曲的 prompt。
请按以下格式帮我输出英文 prompt：
"""<音乐流派（如 Kpop、Heavy Metal）>、<音乐风格（如 Slow、Broadway）>、<情绪（如悲伤、愤怒）>、<乐器（如钢琴、吉他）>、<主题或场景>、<人声描述（如愤怒的男声、忧伤的女声）>"""
```

我用 KIMI 来做一个演示，我让它生成了一段歌词。

附上我刚刚生成的歌词内容：

```
[Chorus]

"Pop, Slow, Melancholic, Piano and Guitar, Theme of lost love, Soprano with a touch of sadness"
```

## 5.生成

然后我们只需要将这一段从`[instrumental intro]`到`[End]`之间的部分进行复制，黏贴到SUNO的`Lyrics`方框。

![](img/f474de0cdb2b5d914bf36907c3a64757.png)

然后再将结尾的部分粘贴到 `Style of Music` 输入框内即可。

![](img/85e518823ff9d796539069e72181882a.png)

然后输入歌曲名，确认自己还有额度，点击生成，等待片刻。

![](img/cbda4179eed6e2002380d935667602c3.png)

可以看到音乐就生成好了，一首歌扣除5点额度，一天免费赠送生成10首歌的额度。
