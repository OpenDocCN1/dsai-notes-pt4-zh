## 二、制作教程

### 1. 画面制作

我以Whee+Dreamina为例，来介绍下怎么利用AI工具制作动态壁纸。

首先登陆WHEE网站，选择文生图

[  ](https://link.zhihu.com/?target=https%3A//www.whee.com/%3Fchannel%3Donlinetrial%26utm_content%3Ddlkw)

![](img/2d9e7e1c10ff85ab99b5e025343f38fe.png)

进入后输入你想要的画面提示词，我分享下我这个画面的提示词：

```
高品质，杰作，超高分辨率，风景大片，星空，湖水，夜晚，绝美场景，山脉，萤火虫，草原，特殊角度，冲击力画面
```

![](img/b5b290b2ba4a208e5f64db226f043f89.png)

![](img/d5239a586f82943c19662893f54990a3.png)

在风格模型里面可以选择赛级风光，这样能够出更好的风光壁纸画面效果。

![](img/0d798d19c056305b7b4452c33af3f0b2.png)

画面比例根据需求进行设置， [采样器 ](https://www.zhihu.com/search?q=%E9%87%87%E6%A0%B7%E5%99%A8&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)选择增强光影的DPM，适当可以调高画面的细节。

接下来我们将生成的壁纸下载下来，图片部分就准备好了。

## 三、变现思路

### 1. [流量广告](https://www.zhihu.com/search?q=%E6%B5%81%E9%87%8F%E5%B9%BF%E5%91%8A&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)

相信大家在短视频平台上都刷到过这种视频，也有人会被吸引点进去看，当你点进去后这些流量最终都会变成钱。

![](img/1de6ff2273e16d870874376519d3ea24.png)

疫情过后，旅游一直是一个热门的话题。

[先是淄博烧](https://www.zhihu.com/search?q=%E5%86%B0%E5%9F%8E%E5%B0%94%E6%BB%A8&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)烤盛[宴风靡一时](https://www.zhihu.com/search?q=%E5%86%B0%E9%9B%AA%E7%8E%8B%E5%9B%BD&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)，再有天津大爷英勇一跳搅动江湖，紧接着 冰城尔滨 的 冰雪王国 梦幻出圈，一波波热潮让国人的旅行热情持续燃烧！

[当下，各路](https://www.zhihu.com/search?q=%E4%B8%87%E4%BA%BA%E7%A9%BA%E5%B7%B7&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)旅友正揣测着下一座即将C位出道的城市爆款，谁会是下一个 万人空巷 奔赴的目的地呢？这悬念吊足了大家的胃口！

而在这些一夜之间刷爆朋友圈的网红城市背后，那些静待发掘的景点与活动无疑也少不了精心策划和大力推广。

![](img/e03d491f1252463af81a01ae253ddcb9.png)

它们是如何被推向公众视野的呢？答案就在抖音、视频号、小红书等视觉图文社交平台上，一篇篇诱人心动的攻略如同繁星点点，点亮探索未知城市的道路；同时，大众点评、美团、携程等团购巨头亦纷纷架起桥梁，一站式解决出行前后的种种需求。

而这些平台又都有共同的特点，那就是支持POI绑定，支持旅游产品分销。景点推广文案部分不用说了，稍微喂点语料，爬取一下景点的简介、攻略、游客体验就能做到批量化生成。

那么重点就是视频内容如何吸引人，怎么能获取大的流量，[从而获](https://www.zhihu.com/search?q=%E7%96%97%E6%84%88&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)取订单。 这些看起来让人内心得到 疗愈 的视频大片，就是用我刚刚介绍的方法做的AI视频，随后通过AI工具或Photoshop等专业软件稍加润色，并混搭各类炫酷特效元素，便轻松诞生出了引人入胜的作品。

![](img/b68157d7388e5669bb7bc86545bb161a.png)

倘若我们能够巧妙运用真实景点照片作为基[础，比如湖](https://www.zhihu.com/search?q=AI%E6%8A%80%E6%9C%AF&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)光山色、繁花似锦的画面，辅以 AI技术 添加如梦似幻的天空特效，是不是就能迅速吸引观众眼球，进而带动销售转化呢？

同样道理，对于民宿、宾馆乃至酒店场景，若是能在室内实拍的基础上，通过AI手段营造窗外飘雪的冬日仙境或是绿意盎然的春天景色，岂不是也能高效聚集流量？

![](img/54f4c92774c052c352fbde3d78f1d876.png)

为了实现这一目标，可以按照以下步骤操作并寻找变现途径：

+   以治愈系风景类的大V账号为标杆，运用AI工具创作一系列充满治愈力量的风景视频，借此快速积攒粉丝群体；

+   以抖音为例，一旦粉丝数达到1000，即可解锁团购带货功能；

+   深入多个网络平台挖掘当红景点资源，收集整合相关文案及精美图片素材；

+   利用AI技术对所选景点进行 [二次创作 ](https://www.zhihu.com/search?q=%E4%BA%8C%E6%AC%A1%E5%88%9B%E4%BD%9C&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)，制作出富有感染力的治愈系景点图片和文案，搭配上合成的真人语音解说或是悠扬悦耳的背景音乐；

+   将精心制作的视频发布出去，并巧妙挂载相关的景点团购链接；

+   随着视频热度攀升，适时引导粉丝参与团购购买，实现流量向销量的有效转化。

### 2.其他思路

而除了这个变现的方案外，也还有其他更加直接的变现思路也供大家参考：

**销售动态壁纸： **[手机支持](https://www.zhihu.com/search?q=%E5%B0%8F%E7%A8%8B%E5%BA%8F&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)动态壁纸，你可以向感兴趣的用户销售；此外，通过入驻壁纸 小程序 ，用户每次下载壁纸，你可获得少量的广告收益。

![](img/b0674bfc079c95ece1b0e3e61a4b551c.png)

**定制素材包： **根据客户的需求，使用AI技术生成个性化图像，创建专属视频素材库，每个定制视频进行售价，可以喜迎不少兴趣者。

**教学收徒： **通过你的视频吸引学习者，引导他们加入微信进行教学，根据提供的课程价值设定价格。

![](img/b1e7c4e24caa4525e8f0b9f5e0c536df.png)

**链接带货： **根据视频风格，如治愈系视频可推荐心理学书籍，农村风格视频可推广当地特产，如蜂蜜、特色菜脯等，这类账号吸粉能力强，变现能力佳。

## 结语

制作风景视频的核心在于传递情感，因此内容制作时需针对特定用户群体，避免发布杂乱无章的视频，专注于提供情感价值。

[对于新手而](https://www.zhihu.com/search?q=%E4%BD%BF%E7%94%A8%E5%B7%A5%E5%85%B7&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689826454%7D)言，最大的挑战不是如何 使用工具 ，而是缺乏执行力。

只要坚持每天更新，就一定能取得成效。
