## **三、T 恤衫定制**

现在已经是2024年了，现在还穿那种[大家都一样](https://www.zhihu.com/search?q=%E7%BD%91%E4%B8%8A%E5%BA%97%E9%93%BA&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)的T恤真是太out了，去那些 网上店铺 看看，要不就是设计老气[横秋的，要](https://www.zhihu.com/search?q=TT%E6%81%A4%E8%A1%AB&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)不就是拿来做团体服的，怎么看怎么不对劲。 我们可以通过AI绘画来进行 TT恤衫 的绘制！

[进行T恤衫](https://www.zhihu.com/search?q=%E7%BB%98%E5%9B%BE%E5%B7%A5%E5%85%B7&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)定制是一个很好的变现方向。有了AI 绘图工具 的帮助，它能让你的创意涌现，化身为时尚设计师，轻轻松松就设计出充满创意的T恤。

不仅如此，AI绘画还能帮助你快速搞定团队服装或是企业推广的特制T恤，实实在在进行变现，下面我就以WHEE为例来说下怎么进行T恤衫的定制吧。

### **使用工具**

1、WHEE 2、Photoshop

### **出图步骤**

**1、提示词模板**

完整的一个通用性提示词语法是这样的：

```
(quality),(subject),(style),(action/scene),(artist),(filters)
```

> **(quality)： ****代表画面的品质，通常我****们选用 Best ****Quality 最高**质量来控制

> (subject)： 代表画面的主题,形成画面的主要内容,这是所有提示词的组成最关键部分。

> (style)： 代表画面效果的艺术风格。

> (action/scene)： 代表动作、场景，主要用来描述了主体在什么场景，做了什么事情。

> (artist): 代表艺术家名字，对于特定的风格强化，如梵高风格很好用，平时可以不用加。

**(filters)： **代表细节补充描述。这是让画面更加丰富，更加具有个性和可控细节的。 [1]

稍加修改，这套公式就能应用在T恤设计上，变成了：品质+T恤图案+画面风格+主体内容+材质+干净背景。

举例我要小猫咪的图案，可以这样输入：

```
最高画质，T恤图案，二维插画风，猫咪头像，纯白背景，简单背景
```

![](img/33dedbf2f760f99779cd705e6543b23c.png)

为了增加二维的效果，我还采用了模型商店里面的“扁平人物插画”。从中我挑选出了一个简单的图案作为效果。

**2、用 PS 设计T恤衫**

T 恤衫的图案设计好了，下一步我们就用PhotoShop把图案合成到白色T恤衫上。 第一步:用 PS 打开白色T恤衫的底图（网上自己找一个），Ctrl+J复制得到一个图层0拷贝，对图层1执行:Ctrl+Shift+U去色。

![](img/5bf3055f78c557b31208e9c02e53f389.png)

第二步:执行:文件一另存为，将文件保[存成PSD](https://www.zhihu.com/search?q=%E5%A4%8D%E5%88%B6%E5%9B%BE%E5%B1%82&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)文件，记住保存路径，然后删除 复制图层 1。

第三步:把我们设计好用于T恤上的图案拖到这个PS窗口内，得到新的图层1，执行:Ctrl+T将图层1调整到适当的大小和位置，然后在图层面板的图层1上单击鼠标右键，将图像转化为智能图层。

![](img/e933d1394cbda1e753f360af9bf28378.png)

第四步:对图层1，执行:滤镜-扭曲-置换，参数如下图，文件选择第二步保存的PSD图像。

![](img/e18af49cd34db18f4dc61b6f409119c8.png)

![](img/d4f12041846a48ea9d8ce61065873f1b.png)

说明:水平刻度和 [垂直缩放值 ](https://www.zhihu.com/search?q=%E5%9E%82%E7%9B%B4%E7%BC%A9%E6%94%BE%E5%80%BC&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)控制效果的强度和力量，大的值将创造较大的折痕，小的[值将创造较](https://www.zhihu.com/search?q=%E6%B7%B7%E5%90%88%E6%A8%A1%E5%BC%8F&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)小的折痕。 第五步:将图层的 混合模式 改为:正片叠底或颜色加深，如下图，效果在这时已经就出来了。

![](img/6cb7b2fdfb4069e3848e416d62855b6f.png)

最终效果如下，我们设计的图案和T恤衫的褶皱完美融合在一起，这样一件我们自己专属的T恤衫就完成了。

![](img/d0c278c40e15ad9bb49d7aa1f9884fd9.png)

### **注意事项**

以上只是做效果图，可以放在自己的店铺、[朋友圈](https://www.zhihu.com/search?q=%E6%8A%A0%E5%9B%BE&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689830546%7D)里。实际制作只需要输出图片，然后 抠图 ，把图片给到厂家就可以给你打印了。
