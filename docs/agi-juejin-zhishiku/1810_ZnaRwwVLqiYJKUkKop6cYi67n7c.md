
# AI绘画入门教程——了解AI绘画软件及网站

> 来源：[https://agijuejin.feishu.cn/docx/Wx0Ud2zsoozGjkxOuw2cbpPHnrh](https://agijuejin.feishu.cn/docx/Wx0Ud2zsoozGjkxOuw2cbpPHnrh)

随着2022年末ChatGPT的走红，AI的潜力逐渐被大众所认可。其中，AI绘画作为新兴技术也随之崭露头角，成为人们不可或缺的好帮手。

AI绘画的基本原理就是让AI为设计师提供设计支持，从而帮助用户完成图形设计。因此，即使你没有设计和绘图的技能，也能轻松实现自己的需求，只需简单地向AI传达信息。目前很多AI绘画的小程序如Midjourney、Stable Diffusion等，都在国内外广受欢迎。

这些小程序不仅能够辅助包装设计、周边产品的研发，还能为数字人在短视频和直播画面中的应用提供支持。此外，越来越多的企业在招募AI绘图师，这也为新兴行业提供了新的机遇。

可以说，AI绘画技术的出现，将会对传统的设计业产生颠覆性的影响，提高了工作和生产效率，替代了基础设计的工作，同时带来了新的行业和职位，让每个人都能快捷高效地完成自己的设计需求。

对于想要了解AI绘画这个领域的小伙伴来说，寻找合适的AI绘画软件或网站是第一步。那么，让我先从如何寻找合适的网站和软件开始吧。

![](img/38b9ca9948fd4ed6ae7190d9574ea1fc.png)

AI绘画软件目前主流的主要是Midjourney 和 Stable Diffusion。其他国内网站基本都是这两个软件的平替产品。

## 一、Midjourney

![](img/7b6a5b0c1393cb65db703cd0e438b8bd.png)

### 1. 重点提示（Midjourney）

Midjourney是一种在线服务（Discord无法在国内注册，🐧频道比较难以申请），需要每个月缴纳固定费用，其使用门槛较低，但是可控性不足，相对于SD而言，上下限差距并不明显。

### 2. 软件介绍（Midjourney）

Midjourney是一款由总部位于旧金山的独立研究实验室Midjourney, Inc.创建和托管的人工智能程序和服务。它是基于Discord平台（目前也已经登陆Slack以及国内的🐧频道）的，在进行自然语言描述时（称为“提示”），可以快速生成对应的图像。Midjourney还支持“图生图”功能，为用户提供更多在线AI图像服务。使用Midjourney需要先登录Discord账号（或者是Slack及🐧频道），然后在聊天界面发送指令即可获得AI图像服务。

### 3. 特点介绍（Midjourney）

1. 它无需高性能硬件，只需通过🪜访问Discord（国内可通过🐧频道申请）即可使用。
2. 部署过程非常简单，没有复杂的门槛。
3. 它的使用难度较低，只需复制提示词并选择选项即可。
4. 该系统的上限/下限差距很小，即使不进行特殊操作，它也能够立即生成讨喜的图片。但是，它的掌控范围也相对较小。
5. 该系统的可控性很弱，没有插件或LORA，生成的画面风格也很固定。它必须在全程联网的情况下运行，因此难以在本地保存数据。
6. 该系统无法自定义想要的模型，仅能使用官方提供的功能模型，无法按需进行细化定制。

## 二、Stable Diffusion

![](img/99bbfd806ff0b85a9f7d90f64c51a993.png)

### 1. 重点提示（Stable Diffusion）

Stable Diffusion是完全免费的开源软件，是一种可以在本地运行的软件，但是使用门槛相对较高。在使用Stable Diffusion进行AI绘画时，可以获得极高的效果上限。

### 2. 软件介绍（Stable Diffusion）

Stable Diffusion是一款深度学习文本到图像生成模型，于2022年发布。该模型由Stability AI、多位学术研究者和非营利组织合作开发而成，并采用了潜在扩散模型。

目前，Stable Diffusion的源代码和模型均已开源，AUTOMATIC1111在Github上维护了该项目，全球开发者共同参与维护。由于完整版对计算机配置有一定要求，国内多位开发者开发了不同版本的封装包以便更好地推广Stable Diffusion。Stable Diffusion的最大特点是它可以在离线状态下在大部分消费级硬件上运行，只需配备至少8GB显存的中等GPU即可。建议使用12G以上显存的显卡。

### 3. 特点介绍（Stable Diffusion）

1. 硬件要求高，需要本地的独立显卡，否则速度会非常慢。
2. 它的环境部署略微麻烦，需要从GitHub上下载很多文件，并且需要一定的Python知识。如果使用国内技术大牛打包的整合包，会稍微简单一些，但仍需要从网盘下载，也较为麻烦。
3. Stable Diffusion的界面有很多内容，需要比较复杂的学习过程才能掌握其各种功能。不过，一旦掌握之后，其上限极高，可以生成非常精致的图片。
4. 它还具有极强的可控性，可以随意换风格和形态，出图的数量也非常多。
5. 它可以训练自己的模型，完全按照自己的想法来生成所需的内容。总之，Stable Diffusion是一种难上手但极具潜力的图像处理工具，可以完全本地运行，无需联网。

## 三、国内平替软件

由于Midjourney使用需要网络环境，Stable Diffusion需要一定的硬件支撑。如果实在搞不定建议使用国内的平替软件，没有门槛，也容易上手，基本上不需要教程了，提示词可采用中文，自己摸索即可，如果有问题可以在评论区询问或私信我。
