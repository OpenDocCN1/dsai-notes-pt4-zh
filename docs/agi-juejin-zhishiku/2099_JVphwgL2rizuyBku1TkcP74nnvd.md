## 🌟 技术突破

### 💡 GPT-4o 不香了！Claude 3.5 Sonnet：AI 新王，免费且智能

机器之心｜[阅读原文](https://juejin.cn/post/7382470660776050742)

Anthropic 公司推出的 Claude 3.5 Sonnet 大模型在智能水平和基准评估中超越了 GPT-4o 和前代 Claude 3 Opus。该模型在运行速度和成本上与 Claude 3 Sonnet 持平，同时在研究生水平推理、本科生知识水平和编码能力方面设立了新的行业标准。Claude 3.5 Sonnet 在视觉推理任务中表现出色，并且通过 Anthropic API 和亚马逊云科技 Bedrock 等渠道提供服务，价格为每百万输入 token 3 美元，输出 token 15 美元。此外，Anthropic 还推出了 Artifacts 功能，允许用户与 Claude 交互生成代码和文档，进一步推动 AI 向协作工作环境的演变。

### 💡 斯坦福 AI 视频生成工具 Hedra 免费试用

量子位｜[阅读原文](https://mp.weixin.qq.com/s/02I7IYKea1AbozmJcEUiBQ)

斯坦福初创公司发布 AI 视频生成工具 Hedra，支持 30 秒逼真视频生成，与 Luma 相媲美。Hedra 集成音频、图像、视频于一体，提供文字转音频、角色描述生成图像等功能，一键生成视频。尽管存在角色畸变等技术挑战，但官方积极回应用户反馈，并计划推出更多功能，如 16:9 视频尺寸和 API 接入。Hedra 由斯坦福顶尖研究团队开发，旨在建立多模式创作工作室，目前已开放免费试用。

### 💡 清华发布首个通用城市时空预测模型 UniST

量子位｜[阅读原文](https://mp.weixin.qq.com/s/4rxmEx-8cYfgWHX6ct9gag)

清华大学电子系城市科学与计算研究中心推出 UniST，这是首个无需自然语言的纯时空通用模型。UniST 利用超过 20 个时空数据集和 1.3 亿个样本点，构建了城市时空数据，并通过基于 Transformer 的架构和时空掩码策略，实现了对城市时空动态性的统一建模和精准预测。该模型展现出强大的零样本学习能力，参数规模仅 20M，已在多个城市应用场景中验证其通用性和泛化能力，为智能城市建设提供了新的数据支持和决策依据。

### 💡 北大发布 RoboMamba：多模态机器人大模型

机器之心｜[阅读原文](https://mp.weixin.qq.com/s/ED2bnE6NDT83zlF9QXHg6Q)

北京大学推出 RoboMamba，一款面向通用和机器人场景的多模态大模型。该模型集成视觉编码器与高效状态空间语言模型，具备视觉常识和机器人任务推理能力。通过创新微调策略，RoboMamba 能在极低训练成本下掌握多种操纵位姿预测技能。在通用和机器人评估基准上，展现了出色的推理能力，推理速度比现有模型快 7 倍，为机器人操作领域带来突破性进展。

### 💡 GPT-4o 刷新 ARC-AGI 基准，71%准确率创纪录

新智元｜[阅读原文](https://mp.weixin.qq.com/s/avkGFdvi4NwosJHg8xDqfA)

GPT-4o 在通用人工智能基准测试 ARC-AGI 中取得重大突破，公共测试集准确率达到 50%，训练集保留子集高达 71%，成为新的最高记录。尽管该成绩未满足 ARC 奖项资格，但已显著超越此前记录。Ryan Greenblatt 通过精心设计的提示和迭代优化，使 GPT-4o 在视觉和编码任务中表现出色。尽管存在视力和编码错误等弱点，但通过规模化有望解决这些问题，进一步提升性能。
