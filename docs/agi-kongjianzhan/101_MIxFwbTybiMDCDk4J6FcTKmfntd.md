# 方法：六种提示词框架

> 来源：[https://agispace.feishu.cn/docx/M32md0vUHoqJKyxrkt4cD6Abnjb](https://agispace.feishu.cn/docx/M32md0vUHoqJKyxrkt4cD6Abnjb)

## **框架一：GOAL ****框架**

+   **Gap (差距)**: 你当前的位置和目标之间的差距是什么？

+   **Objective (目标)**: 你的具体目标是什么？

+   **Approach (方法)**: 你打算采取什么方法或步骤来达到你的目标？

+   **Limitation (限制)**: 有什么可能限制你达到目标的因素？

## **框架二：START**** 框架**

+   **Situation (现状)**: 你现在处于什么情况？

+   **Target (目标)**: 你的目标是什么？

+   **Action (行动)**: 为了达到目标，你需要采取哪些行动？

+   **Resource (资源)**: 你需要哪些资源或帮助？

+   **Timeline (时间线)**: 你自己设定了哪些时间节点？

## **框架三：DREAM ****框架**

+   **Desire (愿望)**: 你想要实现什么愿望或目标？

+   **Reason (原因)**: 为什么你有这个愿望？

+   **Effort (努力)**: 你愿意为此付出多少努力？

+   **Assistance (帮助)**: 你需要什么帮助才能实现这个愿望？

+   **Milestone (里程碑)**: 你设定了哪些里程碑来衡量进展？

**案例**:

> **用户问题**: 我需要提高我的英语水平，特别是口语和听力。

> **用户问题**:  我想接下来的一年内换工作，进入一个新的行业。

> **用户问题**: 我想成为一名成功的摄影师。

```
Gap: 我的英语阅读和写作很好，但口语和听力较弱。
Objective: 我的目标是能流利进行日常对话和理解英语新闻。
Approach: 我打算每天练习英语对话，并且每天听英语广播。
Limitation: 我平日工作忙，每天只能抽出30分钟学习时间。
```

```
**Situation****: 我目前在****金融行业工作****，但对当前的职位****不满意。
Tar**get: 我的目标是转行到科技行业的产品管理岗位。
Action: 我需要参加相关课程，了解科技行业的最新动态。
Resource: 我需要找到相关的在线课程和行业内的导师。
Timeline: 我计划六个月内完成学习，然后开始投递简历。
```

```
Desire: 我希望能够以摄影为生，并在这个领域内获得认可。
Reason: 摄影是我的热情所在，我想通过我的作品讲述故事。
Effort: 我愿意全职投入，并不断学习新技术和风格。
Assistance: 我需要专业的指导和市场营销知识来推广我的作品。
Milestone: 我设定的第一个里程碑是在艺术画廊举办个人展览。
```

## **框架四：****  ****PATH****框架**

+   **Problem (问题)**: 你面对的问题是什么？

+   Alternatives (可选方案): 你考虑了哪些解决方案？

+   **Tactics (策略)**: 你打算采用哪种策略来实施这些方案？

+   **Hurdles (障碍)**: 实施过程中可能遇到哪些障碍？

## **框架五：LEAP**** 框架**

+   Learn (学习): 你想学到什么新知识或技能？

+   Evaluate (评估): 你当前的理解或技能水平如何？

+   Aspire (志向): 你的长远目标是什么？

+   Plan (计划): 为了达到这个目标，你的具体计划是什么？

## **框架六：NEED**** 框架**

+   **Necessity (必要性)**: 你为什么需要这个？

+   Expectation (期望): 你期待的结果是什么？

+   Execution (执行方式): 你想如何达到这个结果？

+   **Detail (细节)**: 有哪些特定的细节或条件需要满足？

>

**用户问题**:  我的小型企业需要提高社交媒体的影响力。

**用户问题**:  我想改善我的写作技能，特别是在创意写作方面。

**用户问题**:  我想学习如何编程，但不知道从哪开始。

```
**Problem****: 尽管我们有社交媒体账****号，但我们的跟****踪和参与度很低**。
Alternatives: 我们考虑过增加广告预算、改进内容质量或进行竞赛促销。
Tactics: 我们决定先从提高内容质量开始，然后根据结果调整策略。
Hurdles: 我们可能缺乏创造高质量内容的内部资源。
```

```
**Learn: 我想学习如何写出吸引人的故事和复杂的**角色。
Evaluate: 目前，我可以写出基本的故事结构，但在创造引人入胜的情节和角色上还欠缺。
Aspire: 我希望能够出版自己的小说或短篇故事集。
Plan: 我计划每天写作，参加在线创意写作课程，并读更多的小说来研究不同作者的写作风格。
```

```
**Necessity: 我需要学习**编程，因为我想转行成为一名软件开发者。
Expectation: 我希望能够掌握一门编程语言，并完成至少一个项目，以增强我的简历。
Execution: 我想通过在线课程和实践项目来学习。
Detail: 我需要知道哪种编程语言最适合初学者，以及推荐的学习资源。
```
