## 课程介绍

在ChatGPT Prompt Engineering for Developers 中，您将学习如何使用大型语言模型 (LLM) 快速构建新的强大应用程序。使用 OpenAI API，您将能够快速构建学习创新和创造价值的功能，而这在以前是成本高昂、技术含量高或根本不可能的。这门短期课程由 Isa Fulford (OpenAI) 和 Andrew Ng (DeepLearning.AI) 教授，将介绍 LLM 的工作原理，提供即时工程的最佳实践，并展示如何在应用程序中 用 LLM API 来执行各种任务，包括：

+ 总结（例如，为了简洁而总结用户评论）
+ 推断（例如，情感分类、主题提取）
+ 转换文本（例如，翻译、拼写和语法纠正）
+ 扩展（例如，自动撰写电子邮件）

此外，您还将学习编写有效提示的两个关键原则，如何系统地设计良好的提示，并学习构建自定义聊天机器人。所有概念都通过大量示例说明，您可以直接在 Jupyter 笔记本环境中使用这些示例，以获得快速工程的实践经验。

## 与 OpenAI 合作

我们很高兴与 OpenAI 合作提供这门课程，旨在帮助开发人员有效利用法学硕士。本课程反映了对使用最新法学硕士模型提示的最佳实践的最新理解。

## 谁应该加入？

ChatGPT Prompt Engineering for Developers适合初学者。只需要对 Python 有基本的了解。但它也适合想要接近即时工程前沿并使用法学硕士的高级机器学习工程师。
