## 1、蓝海战略
是指在商业策略中寻找或创造没有竞争的新市场空间，也就是“蓝海”，从而避免在充满激烈竞争的现有市场（“红海”）中竞争。这种策略鼓励企业通过创新开发新的产品或服务来创建全新的需求和市场，实现市场的非竞争状态。核心在于通过差异化和低成本实现价值创新，为消费者和企业本身创造未被满足的需求和新的增长机会。

### Prompt
运用蓝海战略来评估[我的商业决策]。思考这一决策如何能够开辟一个全新的市场空间，避免与现有市场的直接竞争。

## 2、护城河分析
护城河分析是一种评估公司竞争优势持久性的框架，源自于投资界，尤其是沃伦·巴菲特对于选择投资对象的准则。"护城河"比喻企业为维持其市场地位和盈利能力而形成的一系列竞争优势，如品牌认知、专利技术、规模经济、网络效应等，这些优势像是围绕古城的水沟，保护它免受竞争对手的侵袭。通过护城河分析，可以评估商业决策是否增强了企业的这些核心竞争优势，从而提高了其市场地位的稳固性和盈利能力的持续性。

### Prompt
从护城河分析的角度审视[我的商业决策]。判断这一决策是加强还是削弱了企业的竞争优势。

## 3、SWOT分析
SWOT分析是一种战略规划工具，用于评估企业或项目的优势（Strengths）、劣势（Weaknesses）、机遇（Opportunities）和威胁（Threats）。这种分析方法有助于明确决策的方向，通过全面评估内部环境的优劣势以及外部环境的机遇和威胁，来制定最符合实际情况的策略。在商业决策过程中应用SWOT分析，可以帮助决策者更清楚地识别决策所面临的内外部因素，确保决策能够充分利用企业的优势，规避劣势，抓住机遇，应对威胁。

### Prompt
将SWOT分析应用于[我的商业决策]。详细列出这一决策的优势、劣势、机遇和威胁。

## 4、OODA环（观察、定位、决策、行动）
OODA环是一种决策模型，由美国军事战略家约翰·博伊德（John Boyd）提出，用于描述决策过程中的四个连续循环步骤：观察（Observe）、定位（Orient）、决策（Decide）和行动（Act）。该模型强调快速、灵活的决策和行动，以适应和利用不断变化的环境。在商业决策中应用OODA环，意味着持续收集和分析信息，快速适应环境变化，明智地作出决策，并迅速执行，以保持竞争优势。

### Prompt
采用OODA环对[我的商业决策]进行评估。逐步审视每个阶段，以明确行动步骤和可能的结果。

## 5、艾森豪威尔决策矩阵
艾森豪威尔决策矩阵是一种时间管理工具，用于优先排序任务或活动的重要性和紧急性。该矩阵将任务分为四个象限：紧急且重要、重要但不紧急、紧急但不重要、既不紧急也不重要，帮助个人或组织识别哪些任务应优先处理，哪些可以延后或委托他人完成，从而更有效地分配时间和资源。

### Prompt
利用艾森豪威尔决策矩阵来对[我的商业决策]相关的任务进行排序。区别哪些是紧迫的，哪些是重要的。

## 6、零基思维
零基思维是一种决策过程，它要求从零开始重新考虑决策，而不是仅基于现有的情况或过去的选择。这种思维方式鼓励人们质疑现状，重新评估所有的选项和假设，从而可能发现更好的解决方案或决策路径。在商业决策中，零基思维有助于识别固有的偏见和约束，鼓励更开放和创新的思考。

### Prompt
对[我的商业决策]采用零基思维。提问：“如果以现在的所知重新考虑，我还会做出同样的决策吗？

## 7、成长型思维
成长型思维是一种心态，认为人们的基本能力，如智力和才能，是可以通过努力、学习和面对挑战来发展的。这种思维方式鼓励个体看待失败为成长和学习的机会，相信能力不是固定的，而是可以通过持续的努力和训练来改善。在评价商业决策时，采用成长型思维有助于识别学习和适应的机会，以及决策如何能够促进个人或组织的发展和进步。

### Prompt
以成长型思维来评价[我的商业决策]。关注学习、适应力以及信念——才能是可以通过努力培养的。

## 8、波特五力分析
波特五力分析是迈克尔·波特提出的一种框架，用于分析行业的竞争结构。这个模型包括五个力量：行业内的竞争者竞争程度、潜在的新进入者威胁、替代品或服务的威胁、供应商的议价能力和消费者的议价能力。通过分析这些力量，企业可以更好地理解行业环境，制定策略以提高自身的竞争地位。波特五力分析强调了理解和应对这些外部力量的重要性，以优化企业的市场定位和盈利能力。

### Prompt
将[我的商业决策]放在波特五力分析的框架下进行考量。重点关注行业内的竞争程度、新竞争者进入的难易度、替代品的威胁程度、供应商的议价力以及消费者的议价力。

## 9、客户需求满足框架
客户需求满足框架是一种专注于客户需求的分析工具，用于识别和理解客户的核心需求，以及如何通过产品或服务来满足这些需求。这种框架强调深入理解客户的期望、偏好和痛点，以便更有效地定位产品和服务，从而创造更大的价值。在商业决策中，通过这个框架来审视决策有助于确保企业的方向和战略与客户的需求紧密对齐，促进客户满意度和忠诚度。

### Prompt
通过客户需求满足框架来审视[我的商业决策]。深入理解客户的核心需求，并分析此决策如何有效满足这些需求。

## 10、产品与市场的契合度评估
产品与市场契合度（Product-Market Fit）评估是指衡量产品或服务与其目标市场需求之间的匹配程度。这一概念强调了在正确的市场中提供正确的产品的重要性，即产品能够解决市场上存在的具体问题或满足特定需求。通过评估产品与市场的契合度，企业可以调整其产品特性、营销策略和业务模型，以更好地满足市场需求，从而提高成功的可能性。

### Prompt
通过产品与市场契合度的角度来评价[我的商业决策]。判断此决策是否使产品更贴近市场需求，从而满足市场的期待。

## 11、创新者困境分析
创新者困境是克莱顿·克里斯滕森提出的一个概念，用于描述企业在面对颠覆性创新时的困境：即在满足现有客户的需求和维护现有市场地位的同时，可能忽视或无法抓住颠覆性创新带来的机会。这种分析鼓励企业在做出商业决策时，不仅要考虑如何优化和增强现有产品和服务，也要警惕潜在的创新，这些创新虽然可能在初期不符合现有客户的需求，但长期来看有可能彻底改变市场格局。

### Prompt
在创新者困境的视角下审视[我的商业决策]。思考在满足现有客户需求的同时，是否可能忽略了潜在的颠覆性创新机会。

## 12、飞轮效应分析
飞轮效应是吉姆·柯林斯在其著作中提出的概念，用来描述企业通过持续的努力在某一领域积累动能，最终形成自我增强的正向循环的过程。每一个小的进步和成功都是飞轮转动的动力，随着时间的推移，这些小的努力会积累起来，为企业带来突飞猛进的发展。在商业决策中，飞轮效应分析帮助决策者理解如何通过一系列小的、连贯的努力，逐步构建起公司的竞争优势。

### Prompt
基于飞轮效应来分析[我的商业决策]。探讨此决策如何能够形成正向循环，每一步努力都为后续的发展增添动力。

## 13、黑天鹅事件分析
黑天鹅事件是纳西姆·尼古拉斯·塔勒布提出的概念，指的是那些极不可能发生但一旦发生会产生巨大影响的不可预测事件。在商业决策中考虑黑天鹅事件，意味着要评估那些看似不太可能但可能对企业产生重大负面影响的风险，并制定相应的风险管理和应对策略，以提高企业在面对不确定性时的韧性和适应能力。

### Prompt
将[我的商业决策]放在黑天鹅理论的考量下进行评估。思考那些罕见但影响巨大的意外事件对决策的潜在影响。

## 14、精益创业方法应用
精益创业是由埃里克·莱斯提出的一种创业方法论，强调使用最小可行产品（MVP）快速上市，然后基于市场反馈进行产品或服务的迭代开发。通过构建-测量-学习的循环过程，精益创业鼓励创业者以最小的资源消耗来验证市场假设，从而降低失败风险，提高创业成功的可能性。在商业决策中应用精益创业原则，有助于企业更灵活地调整战略，快速响应市场变化。

### Prompt
应用精益创业的原则来指导[我的商业决策]。侧重于最小可行产品的快速迭代、构建-测量-学习的循环过程，以及根据反馈进行及时调整。

## 15、互惠原则考量
互惠原则是社会心理学中的一个概念，指的是人们倾向于回报那些曾经帮助过他们的人。在商业决策中，通过先给予客户价值，企业可以建立信任和正面的关系，从而在长期内获得更大的回报。这种原则鼓励企业在与客户、合作伙伴和员工的互动中采取先行提供价值的策略，以促进更加稳固和有益的长期关系。

### Prompt
在互惠原则的指导下评估[我的商业决策]。思考如何通过先行提供价值来促成更大的长term回报。

## 16、平均足图分析法
平均足图分析法（Point and Figure Charting）是一种古老的技术分析工具，通过绘制价格变动的“X”和“O”来忽略时间因素，专注于价格变动的幅度，从而提供市场足迹的直观视图。这种分析法有助于识别市场趋势和可能的转折点，为投资和商业决策提供支持。在商业决策中使用平均足图分析法，可以帮助决策者更清晰地理解市场动态，作出更为明智的决策。

### Prompt
利用平均足图分析法来审视[我的商业决策]。该技术通过提供市场趋势的直观视图，辅助做出更为明智的决策。

## 17、双曲贴现分析
双曲贴现是行为经济学中的一个概念，描述了人们倾向于选择立即获得较小回报，而非延后获得更大回报的倾向，即对即时回报的偏好远大于对未来回报的偏好。在商业决策中考虑双曲贴现，意味着要识别和评估决策过程中可能存在的短视行为，确保决策不仅满足即时的需求，也顾及长期的利益。

### Prompt
在考虑双曲贴现的背景下评估[我的商业决策]。识别人们倾向于偏好即时回报而忽视长term利益的心理倾向，并分析其对决策的影响。

## 18、Kano模型
Kano模型是一种用于产品开发和顾客满意度分析的工具，它将产品特性分为五类：必需品、一维特性、激励特性、无差异特性和反向特性。通过区分这些特性，Kano模型帮助企业识别哪些功能或服务能够显著提升顾客满意度，哪些是顾客认为理所当然的基本要求。

### Prompt
利用Kano模型来评估[我的商业决策]。分辨出哪些功能或方面能够提升客户满意度，以及哪些功能是客户认为理所应当的。

## 19、预先失败模式分析
预先失败模式分析（FMEA）是一种预防性的分析工具，旨在识别产品设计、制造或服务过程中的潜在失败模式，评估失败的潜在影响，并采取措施减少或消除故障发生的可能性。应用于商业决策，这种分析有助于提前识别可能的问题和风险，从而实施有效的风险缓解策略。

### Prompt
在最终确定[我的商业决策]之前，执行一次预先失败模式分析。提前预测可能的问题，并制定相应的风险缓解策略。

## 20、持续改进（Kaizen）
Kaizen是日本的一种改善哲学，意味着“持续的改进”，涉及到企业的每一个成员，从高层管理到前线员工。它鼓励持续寻求改进的机会，无论是工作流程、产品质量还是员工的工作条件。在商业决策中应用Kaizen哲学，意味着考虑决策如何能够促进企业的持续渐进式改进，提高效率和竞争力。

### Prompt
将改善（Kaizen）哲学应用于[我的商业决策]分析中。思考这一决策如何促进企业的持续渐进式改进。

## 21、约束理论
约束理论（Theory of Constraints, TOC）是由艾利·戈德拉特提出的管理哲学，旨在通过识别和管理生产或项目中的瓶颈（约束）来提升性能。这种方法认为，任何系统的输出仅能由系统的最小限制因素决定。在商业决策中运用约束理论，有助于找出限制组织达到更高性能的关键瓶颈，并通过系统的改进来解决这些问题，从而实现整体性能的提升。

### Prompt
找出[我的商业决策]中的主要约束，并策划解决方案。

## 22、颠覆性创新
颠覆性创新（Disruptive Innovation）是克莱顿·克里斯滕森提出的概念，指的是一种新的技术、产品或服务打破传统市场规则，为市场带来根本性变革的创新。这类创新往往起初被主流市场忽视，但最终能够改变行业格局，创造新的市场和价值网络()。在商业决策中考虑颠覆性创新，意味着要评估决策是否能够挑战现有市场规则或开辟新市场，从而为企业带来长期的竞争优势。

### Prompt
[我的商业决策]是如何挑战现有市场或开辟新市场的？

## 23、钩子模型
钩子模型（Hook Model）是尼尔·艾尔的概念，用于描述如何通过触发器、行动、可变奖励和投资四个步骤，创建能够吸引用户习惯的产品。这个模型帮助设计和营销人员理解如何制造并维持用户的产品使用习惯，从而提升用户参与度和产品粘性。应用钩子模型于商业决策，可以探索决策如何影响用户行为，以及如何通过产品设计和用户体验促进用户习惯的形成。

### Prompt
对[我的商业决策]应用钩子模型。这一决策如何形成用户习惯或提升用户参与度？

## 24、林迪效应
林迪效应（Lindy Effect）是一个观念，认为某些事物的未来生命周期与其已经存在的时间成正比，特别是对于非物质的技术或理念而言。换句话说，一个理念或技术存在得越久，它未来继续存在的预期寿命就越长。在商业决策中考虑林迪效应，有助于评估某一策略或产品的长期可行性和持久性。

### Prompt
根据林迪效应，[我的商业决策]基于其历史表现，其持续时间的可能性有多大？

## 25、价值链分析
价值链分析是迈克尔·波特提出的一个概念，用于分析企业内部活动如何创造价值及竞争优势。价值链将企业的活动分成主要活动（如生产、营销、销售和服务）和支持活动（如采购、技术开发、人力资源管理等），帮助企业识别哪些活动是创造价值的，哪些地方可以改进以增加价值。在商业决策中进行价值链分析，可以帮助明确决策如何影响企业运营的各个方面，以及如何通过优化这些活动来提高竞争力。

### Prompt
通过价值链分析来深入了解[我的商业决策]。它将如何影响企业的运营、物流、营销和销售？

## 26、临界点
临界点是指系统或过程中的一个转折点，此处即使是微小的变化也可能导致大规模的影响或变革。在商业和管理领域，识别决策的临界点可以帮助管理者了解哪些看似不显著的改变可能会对企业产生重大的正面或负面效果。考虑到临界点，决策者可以更谨慎地评估决策的潜在影响，以及如何通过小幅调整促成大的改进。

### Prompt
[我的商业决策]是否正处于一个临界点，即微小的变化可能引发巨大的影响？

## 27、净推荐得分（NPS）
净推荐得分是一种衡量顾客满意度和忠诚度的指标，通过询问顾客他们多大程度上愿意向他人推荐该公司、产品或服务来计算得出。NPS是一个从-100到100的分数，可以帮助企业理解顾客的忠诚度及其对企业的总体感知。在商业决策中考虑NPS，可以帮助评估这些决策可能如何影响顾客的满意度和推荐意愿。

### Prompt
我们的[商业决策]可能如何影响净推荐得分？基于这一决策，客户是否会更加倾向于推荐我们？

## 28、情景规划
情景规划是一种战略规划方法，通过构建未来的多种可能情景来帮助决策者思考和准备未来的不确定性。这种方法不是试图预测未来，而是探索不同未来可能发生的事件和趋势，以及这些不同情景下的应对策略。应用情景规划于商业决策，可以增加组织对未来可能发展的适应性和灵活性。

### Prompt
根据[我的商业决策]构想多种未来情景。哪一种最有可能发生，我们应如何做好准备？

![](img/6f743940e518ec89da3956cd69e8dbd9.png)

## 29、决策树分析
决策树分析是一种图形化的决策支持工具，它通过树状图模型来表示决策和其可能的后果，包括偶发事件的结果、资源成本和效用。这个工具帮助决策者可视化决策过程，评估不同决策路径下的潜在结果，并计算各种结果的概率。在商业决策中应用决策树，可以清晰地识别各种决策方案及其潜在的风险和收益，从而做出更为信息化和逻辑化的决策。

### Prompt
利用决策树对[我的商业决策]进行图解。可能的结果及其概率是什么？

## 30、营销的4P（产品、价格、地点、促销）
营销的4P模型是一种经典的营销理论框架，指的是产品（Product）、价格（Price）、地点（Place，即分销）和促销（Promotion）。这四个要素是营销策略中的核心组成部分，企业通过调整这四个方面来满足目标市场的需求，实现销售目标。在商业决策中考虑4P，有助于确保产品和服务的营销策略是全面和协调的，以及如何调整这些要素来最大化市场影响力和盈利能力。

### Prompt
通过营销的4P分析[我的商业决策]。它对每个要素有何影响？

## 31、六顶思考帽
六顶思考帽是爱德华·德·波诺提出的一种思考和决策会议技巧，旨在通过六种颜色的帽子代表不同的思考角度和心态，如事实（白帽）、情感（红帽）、负面判断（黑帽）、正面寻求（黄帽）、创新（绿帽）和过程控制（蓝帽）。这种方法鼓励参与者从多个视角考虑问题，有助于生成更全面、深入的见解和解决方案。在商业决策过程中采用六顶思考帽，可以促进团队的创造性思维和有效沟通。

### Prompt
采用De Bono的六顶思考帽方法来审视[我的商业决策]。从事实、情感、负面、正面、创新和管理等不同角度进行考量。

![](img/2e569a39e6df6ee25c71d131b02cf4cc.png)

## 32、红队策略
红队策略是一种安全和管理策略，其中一个独立团队（称为“红队”）对另一个团队的策略、产品或系统进行挑战和检验，以发现潜在的弱点或问题。在商业决策中使用红队策略，可以通过模拟对手的角度来测试企业的策略或假设，从而增强决策的健壮性和可靠性。

### Prompt
采用红队策略对[我的商业决策]进行挑战和检验。在此过程中，我们能发现哪些潜在的弱点？

## 33、锚定偏误
锚定偏误是一种认知偏误，指的是人们在做决策时过分依赖（或“锚定”）于第一次获得的信息。这可能导致后续的判断和决策被这个初始信息影响，即使该信息可能不相关或不准确。在商业决策中意识到锚定偏误，有助于决策者识别并校正因过度依赖初始信息而可能产生的偏差，从而做出更加客观和全面的决策。



# 商业决策思维模型与方法

### prompt

在做出[我的商业决策]时，是否有最初的信息对我产生了过大的影响？尝试抛开这个先入为主的信息，重新进行评估。

## 34、金字塔原理

金字塔原理是芭芭拉·明托提出的一种思考、学习和沟通的结构化方法。该原理建议在表达思想时，先从最重要的结论开始，然后陈述支持这一结论的理由或论点，类似于构建一个倒置的金字塔。这种结构化的沟通方式有助于清晰、高效地传达信息，确保听众能够快速抓住要点。在商业决策中应用金字塔原理，可以帮助决策者更加有逻辑和条理地组织决策论证，明确决策的主要论点和支撑证据。

### prompt

依据金字塔原理来组织[我的商业决策]的论证，首先明确结论，随后陈述支撑这一结论的论点。

## 35、关键少数（帕累托原理的延伸应用）

关键少数原则是帕累托原理（也称为80/20原则）的延伸，即在许多情况下，大约20%的原因会导致80%的结果。在商业决策中识别关键少数意味着找到那些最重要的因素或活动，它们对实现目标有着决定性的影响。这有助于决策者优化资源分配，聚焦于那些能够带来最大影响的领域。

### prompt

找出在[我的商业决策]中那些至关重要的少数因素，这些因素将带来最显著的影响。

## 36、敏捷方法论

敏捷方法论是一种强调通过持续迭代的开发和测试来管理项目的方法。它支持灵活的需求变更，鼓励团队协作，追求快速交付高质量结果。在商业决策中融入敏捷开发框架，意味着决策过程将采取迭代式的方法，允许快速响应变化，持续调整和优化决策路径。

### prompt

[我的商业决策]如何融入敏捷开发框架中？采用迭代式的开发周期是否能够促进其更好的实施？

![](img/d7a9ddced3c6046b536faf04841007f2.png)

## 37、平衡计分卡

平衡计分卡是一种战略规划和管理系统，用于将组织的商业活动与其长期目标相对应，从财务、客户、内部流程和学习与成长四个维度进行综合评估。这种方法有助于组织从多个角度全面了解其绩效，确保各方面均衡发展。在商业决策中应用平衡计分卡，可以促使决策者综合考量决策对组织的全面影响。

### prompt

运用平衡计分卡对[我的商业决策]进行全面评估，从财务、客户、内部流程和成长四个维度进行考量。

## 38、跨越鸿沟

跨越鸿沟模型由杰弗里·摩尔提出，主要关注新技术或产品从早期市场向主流市场的过渡。这个模型识别了不同类型的采纳者：创新者、早期采纳者、早期多数、晚期多数和落后者，并强调在技术采纳的生命周期中，存在一个“鸿沟”或“裂缝”需要被跨越，即从早期采纳者到早期多数的转变。在商业决策中考虑跨越鸿沟，意味着需要制定策略来吸引早期主流市场，确保产品或服务能够成功实现市场扩张。

### prompt

在技术采纳的生命周期中，[我的商业决策]将如何帮助产品或服务从早期采纳者成功过渡到早期主流市场？

## 39、弱联系的影响力

社会网络理论中的弱联系概念由马克·格兰诺维特提出，指出人际网络中那些不那么紧密的联系（弱联系）在传播信息、获取新知识和机会方面扮演着至关重要的角色。在商业决策中考虑弱联系的影响力，意味着认识到那些边缘的或不频繁的联系可能为企业带来新的视角、信息或资源，从而影响决策的成败。

### prompt

在我们的人际网络中，那些较为疏远的联系（即弱联系）将如何影响我的商业决策的成败？

![](img/07b2b2a4e1927d63a28b8ffcfb1932ca.png)

## 40、亲和性分组法

亲和性分组法是一种将信息、想法、问题或解决方案按照自然关联或主题进行分组的技术，常用于组织思维、促进创新和问题解决的讨论过程中。通过将相关联的点归类，可以更容易地识别模式、趋势和潜在的解决策略。在商业决策中应用亲和性分组法，有助于整理和分析决策相关的各种信息和观点，从而做出更加有根据的决策。

### prompt

采用亲和性分组法，针对我的商业决策，将相关的想法、主题或议题进行归类。从中能够观察到哪些规律或模式？

## 41、五因素探究法

五因素探究法，也称为“5 Whys”，是一种简单但有效的问题解决技术，通过反复询问“为什么”来探究问题的根本原因。这种方法有助于深入分析问题，避免仅解决表面现象而非深层次原因。在商业决策过程中，使用五因素探究法可以揭示决策背后的根本原因，确保解决方案能够有效地解决问题。

### prompt

运用五因素探究法深入分析我的商业决策，以揭示该决策背后的根本原因或关键动因。

## 42、所有权偏好效应

所有权偏好效应，或称为禀赋效应，是行为经济学中的一个概念，指人们倾向于对自己拥有的物品赋予高于市场价值的估值。这种偏好影响了人们对交换和决策的看法，可能导致在决策时过分重视现有资源而不是潜在的最优选择。在商业决策中识别和理解所有权偏好效应，有助于确保决策过程中评估的客观性和理性。

### prompt

重新审视我的商业决策，检查我们对资产的评估是否受到了所有权感的影响，而非资产本身的真实价值。

## 43、关键少数原则

这个概念与之前提到的“关键少数（帕累托原理的延伸应用）”相同，强调在任何群体或系统中，往往是少数关键因素或人员对结果产生最大影响。在商业决策中识别这些关键少数，无论是影响者、决策因素还是资源，都是实现高效和有效决策的重要步骤。

### prompt

在我商业决策的背景下，哪些关键的少数人或要素能够成为推动成功的决定性力量？
