# 为什么代理是生成式人工智能的下一个前沿｜麦肯锡

> 来源：[https://agispace.feishu.cn/docx/Bu5FdGWMKoKLIdxB3qEc0zT8nNh](https://agispace.feishu.cn/docx/Bu5FdGWMKoKLIdxB3qEc0zT8nNh)

+   **研究背景**：

+   过去几年，生成式AI（gen AI）展现出强大能力和潜力，其发展正从知识型工具向基于gen AI的“智能体”（agents）演进，这些智能体能够在数字世界中执行复杂的多步骤工作流程，从思考转向行动。

+   **agents的价值**：

+   agents有望自动化处理一系列复杂的长尾用例，这些用例具有高度可变的输入和输出，传统上难以以成本或时间高效的方式解决。例如，商务旅行涉及众多不同的行程安排和在线平台操作，目前很多部分仍需手动完成，但gen AI赋能的agents可以从三个重要方面缓解这种复杂和开放式用例的自动化难题。

+   **管理多样性**：许多业务用例和流程具有线性工作流程，相对简单，易于在基于规则的系统中编码和自动化，但规则系统在面对意外情况时往往表现出“脆弱性”。而基于基础模型的gen AI智能体系统能够处理各种不太可能的情况，实时适应并完成特殊任务以完成流程。

+   **自然语言指令**：目前自动化用例需要分解为一系列规则和步骤并转化为计算机代码，这一过程成本高且费力，需要专业技术知识。而智能体系统使用自然语言作为指令形式，使复杂工作流程的编码更快、更容易，甚至可以由非技术员工完成，这有助于整合专业知识、扩大gen AI和AI工具的使用范围，并促进技术和非技术团队之间的协作。

+   **与现有工具和平台协作**：智能体系统除了分析和生成知识外，还可以使用工具并在更广泛的数字生态系统中进行通信，例如与软件应用程序协作、搜索网络信息、收集和编译人类反馈，甚至利用其他基础模型。这使得智能体系统能够更高效地完成任务，而无需进行大量的手动系统集成或数据整理工作。

+   **agents的工作方式**：

+   agents可以支持跨行业和业务功能的高复杂性用例，特别是对于涉及耗时任务或需要各种专业类型的定性和定量分析的工作流程。其工作过程一般遵循四个步骤：用户提供指令、智能体系统规划、分配和执行工作、智能体系统迭代改进输出、智能体执行行动。

+   **潜在用例**：

+   **贷款承销**：金融机构准备信用风险备忘录评估信贷或贷款风险，这是一个耗时且高度协作的过程。基于agents的解决方案可以设计一个多智能体系统来处理各种信用风险场景，减少审查周期时间，提高内容质量，能够遍历多个系统并理解来自多个来源的数据，并展示工作过程，便于快速验证输出。

+   **代码文档和现代化**：大型企业的遗留软件应用程序和系统现代化过程复杂、成本高且耗时。AI agents有潜力简化这一过程，例如部署专门的智能体作为遗留软件专家分析旧代码、记录和翻译代码段，同时质量保证智能体可以审查文档并产生测试用例，提高生产力并降低软件开发的总体成本。

+   **在线营销活动创建**：设计、启动和运行在线营销活动涉及众多软件工具、应用程序和平台，工作流程高度复杂。agents可以帮助连接数字营销生态系统，例如营销人员使用自然语言描述相关参数，智能体系统在营销专业人员的协助下开发、测试和迭代不同的营销活动想法，提高营销效率。

+   **企业领导者的准备工作**：

+   虽然agent技术尚处于初期阶段，但企业领导者应了解agents并考虑其核心流程或业务需求是否可以通过智能体系统和能力加速。一旦确定了潜在用例，组织可以开始探索不断发展的智能体领域。

+   为了准备智能体系统的到来，组织应考虑三个关键因素：相关知识的编码、战略技术规划、人在回路控制机制。具体包括将业务流程定义和记录为编码工作流程以训练智能体、组织数据和IT系统以确保智能体系统与现有基础设施有效接口、建立人在回路控制机制以平衡自主性和风险等。

+   **智能体系统的风险**：

+   **潜在有害输出**：大型语言模型可能提供不正确信息或执行不良后果的行动，gen AI agents在高度可变场景中独立执行任务时这些风险会增加。

+   **人与智能体信任问题**：用户对智能体系统缺乏信任可能会限制其学习和改进，而过度信任可能导致用户不加批判地接受建议或给予智能体过多自主权。

+   **工具滥用**：智能体能够访问工具和数据，如果被故意滥用可能会很危险，例如开发易受攻击的代码、创建钓鱼诈骗或黑客攻击敏感信息。

+   **拟人化**：随着智能体越来越具有类人能力，用户可能会过度依赖它们或错误地认为它们与自己的利益和价值观完全一致。

+   **总结**：

+   超过72%的公司正在部署AI解决方案，对gen AI的兴趣日益增长，公司可能会将agents等前沿技术纳入规划过程和未来AI路线图。agent驱动的自动化具有革新整个行业的潜力，但该技术仍处于早期阶段，在实现其全部能力之前需要大量开发。在部署AI agents之前，需要进行大量测试、培训和指导。
