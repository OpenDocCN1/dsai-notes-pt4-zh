## 什么是Agent? 它为什么重要?

吴恩达教授最近在红杉 AI 峰会上发表的关于 `Agent`的演讲, 再次让AI `Agent`的概念得到了广泛的重视! 吴恩达教授在演讲中表示:

"我认为这是一个令人兴奋的趋势，所有涉及 AI 开发的人都应该关注。同时，我也对所有即将介绍的"未来趋势"充满期待。"

在这里我们借用吴恩达教授在演讲中提到例子, 让大家快速了解到`Agent` 为什么值得被关注!

### 大多数人的使用方式(无智能体流程):

现在大多数人使用大语言模型的方式就像这样， 输入一段提示词，然后得到大模型生成的一段答案。

这个过程中有点像你让一个人编写一篇关于某个主题的文章，你让他坐在电脑边上, 不停敲打着键盘编写文章, 直到将文章写完。

尽管这听起来可能非常困难，但大语言模型却大部分时间有着让人满意的表现。

### Agentic Workflow(智能体工作流程):

与此相对，一个AI `Agent`的工作流可能是这样的。

+   AI 或者大语言模型先生成关于文章主题的提纲。

+   需要在网上查找一些东西吗？如果需要，那就去搜集资料.

+   写出初稿

+   阅读生成的初稿，思考哪些部分需要修改。然后修改初稿

+   继续这个过程。

我们可以看到: 这个工作流是迭代的，这会让大语言模型进行一些思考，然后修改文章，再进行一些思考，如此反复。很少有人意识到，这种方式的结果更好。

![](img/30f21dd6eb933293b952c576dd2fc62d.png)

吴恩达教授的团队曾经使用使用了 `HumanEval` （OpenAI 为了评估编程语言模型而设计的数据集）做了一个案例研究，研究结果表明，如果你使用`GPT3.5` + `Zero-shot` 的正确率为 48%，`GPT4` + `Zero-shot` 的正确率为 67%，但是，如果你用 `GPT3.5` + `Agentic Workflow`，你会得到超越 `GPT4` 的效果！由此可见`Agent`的重要性!

![](img/a680de9ae3f63c26b48df7065984962d.png)

## 如何体验Agent?

`Agent` 这个概念早在OpenAI开发者大会发布`GPTs`就收到了人们的关注,  而且OpenAI也在前一阵子发布了`GPTs Store`方便大家查找和使用`GPTs`, 我们也出过多篇关于创建`GPTs`的教程, 但是由于各种原因, OpenAI的`GPTs` 在国内使用起来还是有些水土不服.

我们可能更需要适合中国宝宝体制的`Agent`, 同时国内的大厂也都纷纷"开卷" 发布了自己平台的国产`GPTs`, 这些国产的`Agent` 也对中文的支持更友好, 下面是我为大家收集的国产`GPTs`平台一览.

![](img/9757cd8b0fcb4b19644286296ad158f4.png)

在选择国内`Agent`平台时，往往我们会先考虑该公司的大模型能力，在这里我们考虑参考了`SuperBench`大模型综合能力评测框架，这是由清华大学基础模型研究中心联合中关村实验室研制的，该评测共包含了14个海内外具有代表性的模型。

![](img/52f9f46040089b4451a0c0bded7a18f8.png)

从这份榜单中我们可以看到智谱AI的`GLM-4` 是目前国产大模型中智能体能力比较出众的, 下面我们就带大家来体验一起来体验一下智谱清言的`Agent`，看看他的能力如何？

## Agent创建

看完别人的`Agent`，不知道你有没有跃跃欲试的感觉呢，下面我就带大家来创建一个角色类的`Agent`，看一下创建的流程和使用的效果！

### 第一步：描述Agent

创建一个`Agent`的第一步是给他一个描述，然后智谱会根据你的描述智能的为你先初始化一个符合你描述的`Agent`，我们来创建一个拯救P人的J人`Agent`！

![](img/6e68f896f1d89ea19208ff7135cb6638.png)

在输入描述之后就可以看到，预设好的`Agent`， 你可以根据自己的需求更换logo和名字。我这个`Agent`的名字就叫“P人拯救者”！

![](img/39c166b41d98421f93ca0529947737de.png)

### 第二步——设置提示词

在配置信息这里填入符合你要求的提示词，智谱`Agent`内置了几个模板，在设置时可以参考

![](img/425e12527e786e72c089464fed8e6f82.png)

这是我设置的`Prompt`

```
你是p人拯救者，一个MBTI人格中的J人模拟器。你的角色是通过细致的计划来帮助那些没有计划的P人，让他们也能享受到计划带来的条理和效率。你的能力有:
分析现状:你能够快速分析用户当前的生活或工作状况，找出需要制定计划的地方。
制定详细计划:基于分析结果，你会帮助用户制定出详尽可行的计划，确保每一步都有明确的指引。
跟踪执行:你能够监督用户按照计划执行，并提供必要的调整建议，确保计划的有效执行。

Goals:
用J的优势弥补P人计划性不足的问题

Constrains:
在你还没有了解目标和背景之前，不要做出计划
计划中因包含特殊情况的考虑，并设置应对的Plan B
要给予一定的鼓励
计划中的每一步都要足够明确

Workflow
首先，你会询问有关计划对象的背景，目标，进度和截止日期
然后，你会依据上述信息一份相关的计划。
若P人不满意，你可以提供更多的建议。并想办法设置监督机制，监督执行
```

还可以为`Agent`设置开场白和推荐问题。

![](img/5ea02207e937d2e58bd4ee3f1fa04e34.png)
