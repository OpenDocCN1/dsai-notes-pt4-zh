## **思维导图类**

不少小伙伴在工作和学习中，都会面对需要画思维导图的情况，思维导图，时序图等可以，将我们要思考的问题可视化，使问题更加的清晰，直观。下面我们就来看两个用来思维导图和流程图的GPTs

### 1. Whimsical Diagrams

Whimsical Diagrams 是一个非常方便的画图工具，你只需要将你需要可视化的问题或者你与GPT交流的对话告诉它，他就可以直接在聊天窗口中为你创建可视化图表。

Whimsical Diagrams主要支持 3 种图表，分别是流程图（flowcharts）, 思维导图（mindmaps）以及时序图（sequence diagrams。

![](img/e86701841449d559925f422d89fcab4b.png)

比如，我让他给我一份大模型技术的思维导图

![](img/d53021b17c27e7b38cd7b28a2b64a6e5.png)

它就会先将回答的文字内容展示给我们，然后再根据生成的内容生成mermaid代码，最后调用action 生成思维导图展示

![](img/ee32321f6d1412a05cf227cbdc6daea1.png)

而且非常方便的是，我们还可以点击“查看或编辑此图表在Whimsical”在Whimsical网站上方便的编辑刚刚产出思维导图。

GPTs同样具有联网能力，你可以要求它根据网络上搜集来的信息为你生成可视化图，比如：我让他结合吴恩达关于智能体的演讲，用合适的图来可视化multiagent 协作，可以看到它在回答问题时就使用了网络上的资源作为回答的一部分。

![](img/b5741d5995652f9f4697a8a3217bb464.png)

下面是它为我生成的多智能体协作的可视化图

![](img/41ed2b62b0fcb9308ef146238fcb693b.png)

除了这个画图工具，这里还有另一个很强大的画图工具叫Diagrams: Show Me | charts, presentations, code

### **2. Diagrams: Show Me | charts,** presentations, code

Show Me，相比较于Whimsical就更加的强大，它可以画流程图，思维导图，UML，图表，PlotUML，工作流，序列，ERD，数据库和架构可视化代码等

![](img/e508d7fe4a70cd89e61c2ae640d01cad.png)

我们就用刚刚多智能体协作的例子来看一下，这两个画图工具的差别。

![](img/b9967fd04820e81e929f390358b32152.png)

Show Me生成的图元素和样式更加的丰富，如果你喜欢这种元素丰富的风格，你就可以选择使用Show me来画图。

而且他能画的图更加复杂，像是数据库实体关系的图，Show me也可以完全的胜任

![](img/00c46bb64f7989afae2206d4337a7ab3.png)

大家可以根据自己的需求和喜好，在这两个GPTs中选择！
