# AI时代的爆款应用是什么样？文心一言App先来打个样

最近有朋友问我，去年科技圈关于大模型的“军备竞赛”还搞的如火如荼，比算力、比参数...为何短短一年时间，就好像没有大厂再提这事儿了？

我回答道，大模型，就好比一部手机的操作系统，你开发那么多操作系统，对于用户来说有用吗？真正对用户有价值的，是手机的的各项软件，各种应用。其实我这个回复，是引用的百度创始人李彦宏的观点。除了“类手机操作系统”的观点，去年李彦宏在公开场合还表示：

![](img/46ea5e6eb8c1036e3b85b09f3bae8f41.png)

**李彦宏**

百度CEO

很多行业、企业甚至城市都在买卡、囤芯片，建智算中心()，想从头训练自己的专用大模型，殊不知这样练出来的大模型是没有智能涌现能力的。“不断地重复开发基础大模型是对社会资源的极大浪费。”

的确如此，随着大模型规模的不断扩大，其训练和推理所需的计算资源也在急剧增加，成本也越来越高。但是，大模型并非万能的，在实际应用中，我们往往发现，尽管模型在训练数据上表现优异，但在面对真实世界的复杂场景时，其性能却大打折扣。这是因为大模型往往过于依赖大规模数据集，而忽视了实际应用中的具体需求和约束。

**正因****如此**，步入今年，越来越多的企业和开发者开始关注“AI原生应用()”。

AI原生应用针对特定任务进行优化，无需庞大的计算资源，就能在较短时间内实现高效推理。同时，它们更容易适应不同的场景和需求，提供个性化的解决方案。

李彦宏此前曾提到，AI原生应用要能解决过去解决不了或解决不好的问题，而不是对移动互联网APP和PC软件的简单重复。

具体而言，AI原生应用应该满足三个基础条件：

①能够用自然语言交互。

②充分利用大语言模型的理解、生成、推理、记忆等能力。

③每个应用的交互不超过两级菜单，所以交互会更简单。

文心一言是国内国内最早发布、最早开启测试，目前也是首个全面放开的大语言模型，这一领跑也延续在了文心一言App上。相信很多朋友都使用或者体验过文心一言App，用它来解决生活、工作、学习中方方面面的问题。

![](img/ad8b9bd2bee716f3aa6d820788314059.png)

作为一个随身的智能助手，文心一言APP最核心的能力就是问答。当然了，相较于传统的“一搜一答”，文心一言还支持用户上传图片完成交互，“随拍随问”、“随拍随创”。

![](img/5e426d6af05f65fb93ba4adb77fe9ed1.png)

另一方面，文心一言APP具备“个性化、定制化解决”能力。无论是总结文档，还是提供建议，都可以根据用户的个性化需求，提供定制化的答案和解决方案，成为每个人身边的“万能搭子”。

![](img/3783bcf3ab8900ee11a023f0b0e4378e.png)

在定制化需求中，创作是最有难度、最刚需的场景之一。基于百度深厚的中文积累，文心一言APP更懂中文，已经在写营销文案、汇报、评语、节日祝福、视频脚本等方面，为用户提高创作效率。

![](img/1f13a686fc2a09414db855eae507c541.png)

最新数据显示，文心一言App月活已超千万，核心用户群体主要汇聚在中国的一二线城市，超过半数在35岁以下。过去一年，用户在文心一言App上进行了超过14.3亿次的调用。在最新一期的《中国AI大模型平台排行榜》上，文心一言位列🛰️指数()热度TOP5的榜首。在“不卷大模型，卷应用”的路上，文心一言App可以说已经打了个样。能够看到，继文心一言之后，讯飞的星火、抖音的豆包、月之暗面的kimi、秘塔搜索等，也都紧随其后纷纷赶来。AI原生应用产品一时间也开始“拥挤”、“内卷”起来。

未来大模型的发展趋势会是什么？我们拭目以待。
