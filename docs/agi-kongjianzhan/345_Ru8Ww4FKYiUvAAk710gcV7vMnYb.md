### 【超长文内容理解与总结】

![](img/3888ce5510df790a91024d88371884b9.png)

在我们日常工作中，查阅文档或浏览材料内容，需要分析并提取其中核心要素，经常会花费我们不少的精力。但现在交给AI很快就可以辅助完成。我们在【橙篇】中给定一篇系统架构设计指南：

![](img/9ff23f30b485acae4157438d351c78c2.png)

上传近18MB的PDF文件，让橙篇帮我们提取材料中常见经典的系统架构设计风格。

![](img/44a7328f23102031c33adba65650bcb9.png)

可见，在超长篇内容中提及的系统架构风格()，橙篇将其分点依次陈列了出来。

![](img/edc34748c3c26120290947355d1cfae1.png)

在【Kimi】中给定同一篇系统架构设计指南：

![](img/fa5d9627c330717fa4f57b98ba27153c.png)

但是，只给阅读了前36%，提示说这个对话已经超过了 20 万字，超出了对话的最大长度，也就是超过了 token。

**从**上面看到，针对超长篇内容，橙篇对于文章内容在理解和总结上依然具备全面性、逻辑性，实际做到了超长图文无损处理，且目前无任何收费项目。


![](img/872a90eccad74e383d0232826f65ea1c.png)

+

```
支持100MB、50个文件上传：pdf、doc、xlsx、ppt、txt、image
```

![](img/2368f854ed767b52b161d782a9078a59.png)

**K**imi的文件上传数量略逊于橙篇（100个文件）。这里，在上述基础上添加四种风格，向 Kimi 发起提问：

![](img/cb9c395b046dde621b7ca4735bf64cd1.png)

从上面看到，Kimi 简洁地给出了图片中包含的七种，针对图片这种处理技术，之前我们可以通过 OCR 技术，识别出文字内容，进行处理。

如今，通过橙篇、Kimi 在线就可以解析处理，尤其是橙篇在图文方面作了无损处理，对于需要提取图片中的文字内容，方便复制粘贴，极其便捷！

![](img/21ca4ac6950b80be75f40ded50014bfe.png)

那么，若是给定没有文字的卡通动漫色彩图片，AI 是否能不能正常理解？在 Kimi 中选择发送图片，图片文件里面没有包含文字发不出去，不支持解析。

![](img/c90ba8fab88edab323616bf122b3f8fb.png)

同样，在橙篇中发送图片，它是否能告诉我们图片中卡通人物所在环境的行为动作？选择发送，让人震惊的是预测结果迅速地分点罗列了出来。

### 【内容生成与编辑】

基于橙篇超长文解析技术处理，对于我们来说已经非常友好了，不仅可以对文本进行编辑、复制，还可以通过智能化处理：润色、续写、扩写、概括总结等。

，时长00:22

接下来，我们以实际的场景进行切入-以历年系统架构设计师考试的论文为例：

在【长文写作】输入：

+

```
请参考以下文件，生成一篇长文～参考文章的主题以及风格，撰写一篇万字长文！
```

![](img/eb04780fef54bb98772c584db6f865ca.png)

![](img/e9b5eb5694430dfcfd63c17de3d9f9ec.png)

**橙篇 **可以对生成的大纲，根据实际需要加以调整，每个大纲分层甚至可以二次上传参考文献，在此基础上继续生成长文。

![](img/ecdbf0b9b12687edbe9e36599834f849.png)

**上万字的内容创作，对于一个内容创作者来说这一万字意味着几天甚至**数十天都有可能！但橙篇生成只需10分钟。

![](img/236d84d319715ba311251f1407216249.png)

说实话，这个生成的文档属实有点震惊到我，无论格式还是内容，都基本达到了论文应有的质感。此外，我们直接通过橙篇网页端就可以完成生成论文的二次编辑，包括图片、表格等不同格式的插入，内容的校正，大纲格式的整理，减少了在多个端来回切换的流程。这也着实让人联想到之前高考作文、高阶架构职称论文考试数千字都需要花费数小时之久，噫嘘唏，只能感叹 AI 成长速度恐怖如斯，仅供用于学习参考！同样，我们在 Kimi 中以真题材料作为输入，进行论文撰写：

![](img/7de21339a37c49a775210f3e42993204.png)

![](img/17332aa52c4e42af576bd40cf3ce0976.png)

可见，Kimi 虽然能生成框架，但离实际使用还差很远。橙篇不仅在内容理解和总结上更具全面性、逻辑性，而且论文的基本格式，以及参考文献的格式都符合专业垂类领域的标准。

### **体验总结**

综合来看，橙篇对于文案内容创作者来说无疑是划时代的变革，无论算力还是使用体验都远超 Kimi，说“Kimi”平替实属有些贬低了。橙篇确实代表了目前国内 C 端 AI 的尖端力量，算是百度厚积薄发的良心之作，一个橙篇即可抵 Kimi+AI 搜索+WPS+… 趁现在免费，推荐大家使用！
