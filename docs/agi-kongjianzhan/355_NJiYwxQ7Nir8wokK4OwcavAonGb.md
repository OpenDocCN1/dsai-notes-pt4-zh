## **我们为什么需要API？**

每次提到API，相信可能不少人都会问出这个问题？

我们现在有着GPT， Claude()各种各样的聊天机器人，那么我们为什么还需要使用API呢？

这些聊天机器人，虽然强大，但是你也只能在他们网页中使用，如果我们想把AI的能力带到别的地方，我们就需要API的加持。

API 就像一个召唤器，可以在任何时间，任何地方召唤AI来协助我们！

无论是代码，还是翻译工具，甚至是自动化，我们统统都可以调用API来实现。

同时，API也可以帮我们规避掉，国外AI网站的各种条件（懂得都懂！

甚至你想在Chatbox()中任意切换不同模型来获得更好的回复结果，那可能也只有使用API可以做到！

## **我们如何获得API？**

像GPT， Claude， Gemini() 等国外大模型的API，都是可以在官网绑定付款信息后直接获得。但与他们网页版聊天机器人一样，付款卡，网络等问题成为了我们好多朋友头痛的问题！

而其他途径的API，可能存在稳定的途径难找，价格虚高，“挂羊头卖狗肉”等现象，很多都是你付款后就消失没影了🏃‍♀️，或者是隔天就被封了（说得就是你 Claude！）

（有遇到过我说的情况的小伙伴们，可以在我们的评论区，吐槽避雷！）

很多时候我也在想，要不要动手搭一个大的AI集成平台，大家自己挑选自己想用的API？
