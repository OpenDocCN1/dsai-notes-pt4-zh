## o1 的正确体验方式

17号，OpenAI 宣布将 o1-mini 速率限制提高7倍，从每周 50 条消息增加到每天 50 条消息。而 o1-preview 的速率限制从每周 30 条消息增加到每周 50 条消息。

![](img/faf65a472bed30acfe9f6ce30545f874.png)

同时，o1-mini 开始在免费用户的界面中出现，但目前被归类在 Alpha 模型中，还不能正常使用。

![](img/fea267ce257200d77b36265e580b1847.png)

关于 API 方面， o1-preview 与 o1-mini 的API不支持系统提示词（system prompt），不支持工具使用（联网搜索等）、批量调用或者图像输入。

新模型引入了“**推理 token**”的概念——这些 token 在 API 响应中不可见，但仍会按照输出 token 的形式计费。正是有它们的存在，新模型才表现出种种神奇的推理能力。

![](img/3d056e19a9d8ce1fa05aec953abf99b5.png)

不过，想从 o1 里面套出这些“神奇 token”还可能会被封号，很多人在问 o1 关于其思维链的时候就会被拒答，还会收到 OpenAI 团队的邮件警告！显然，o1 的思考过程被人为强制隐藏了。

![](img/1a36e9431ac62d8a2366d29c6ec6ae87.png)

## o1 是如何思考的？

![](img/7d04d1ebd34af6cadf4aa52727629de9.png)

目前在使用界面上看到的思考过程并不是原始的推理 token，而是将步骤再加工，总结成了容易阅读的精简形式。

有趣的是 OpenAI 也并不完全知道如何使用该模型。它是一个名称模糊的预览版本，需要用户帮助定义。

OpenAI 应用研究负责人 Boris Power 将 o1 形容为:

> 这次发布的模式更类似于最初 GPT-3 的发布，而非 ChatGPT 的发布。这是一个全新的范式，某些人会发现它在某些领域具有难以置信的价值，甚至连我们 OpenAI 也无法预测它的全部潜力。

> 然而，它并不是一个可以立即使用并轻松为所有人创造新价值的大众化产品。

> 我相信我们很快就会迎来另一个像 ChatGPT 那样的重大突破时刻！

![](img/ce42abf345ad693ca3e2aee64c8a62bd.png)

1.  如何写 o1 提示语
1. 保持提示简单, o1 不需要过多指导，它可以自己找到最佳路径。避免使用 CoT， 因为思维链技术已经是模型推理的一部分，所以在提示中输入你自己的推理可能会阻碍性能。使用分隔符（如 “###”）、XML 标签来保证质量，要清楚地指示提示的不同的部分限制无用的上下文，请确保提供模型的信息仅包含最相关的。在推理时提供大量信息可能会使模型“过度思考”并需要更多时间来获得答案。

收到提示时 o1 会幕后在做什么？

我整理出了一个几天看下来可信度较高的推测，来自于伯克利 AI 博士 Nathan Lambert 内森·兰伯特 --

⌛**️ **o1 在推理时非常昂贵，但并非因为它更大。它的规模最多与 GPT-4 相当。考虑到它必须生成大量的 token，我怀疑它可能更小。它在每个 token 上做了更多的工作（比如自我评分）。

如果模型并没有明显变大，那么我们需要解释模型的高推理成本。o1-preview 对每百万输入 token 收费 15 美元，每百万输出 token 收费 60 美元。这与 Claude 3 Opus 的价格相同。如果模型既没有变大，也没有生成很多 token，那么计算资源去哪里了？ 我猜测是一种并行解码形式，我们可以粗略地称之为强化学习语言模型解码。

简单来说，o1 会生成多个候选项，然后对它们进行评分。每一步产生的决策数量是可以配置的。这种并行和分支生成需要一个与普通聊天机器人明显不同的推理堆栈，这解释了高昂的价格和"价格预期1-2年内会下降"的说法。

![](img/7a3c8be5fc41bd37e87c36fe4fee6c6d.png)

本质上，o1 是一个模型，但这个模型既是生成模型又是过程奖励模型，它使用了一种我们以前没见过的不同生成策略。这可能是一个带有特殊评分 token 的生成模型，或者是一个带有可以在生成过程中交错使用的独立回归头的生成模型，对上了OpenAI 解释o1"只是一个模型"的说法。

## 为什么叫 o1

上篇文章我才吐槽过为什么不叫 GPT5，几天接触下来，o1在技术背景、使用场景等都跟GPT系列有很多不同：

1.  OpenAI o1 代表了 AI 能力的一个新层次，名称被重置为1。“Preview” 表示它是完整模型的早期版本

1.  “Mini” 表示它是 o1 模型的较小版本，优化为更快的速度。

1.  “o” 代表OpenAI。

1.  o1 不是一个“系统”，它是一个能够在给出最终答案之前生成长链推理的模型，Just one model！

1.  o1 的图标象征着一个拥有非凡能力的外星人👽。
