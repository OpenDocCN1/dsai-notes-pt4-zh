# 搞定视频号下载

> 来源：[https://xodnytdcaw.feishu.cn/docx/K4l6deCxKoegFSxh7MYcQjgqnKg](https://xodnytdcaw.feishu.cn/docx/K4l6deCxKoegFSxh7MYcQjgqnKg)

每次看到超赞的视频号内容想保存却无从下手？这款神器简直绝了！一个按钮搞定所有视频号下载，连家里老人都能秒懂操作！

## 软件下载

https://github.com/ltaoo/wx_channels_download

> 迅雷云盘下载

> https://pan.xunlei.com/s/VOXNsSH2yrt68jPfe3ry7ZDKA1?pwd=jn8b#

### 运行软件

下载软件之后，右键程序，**选择以管理员身份运行**

首次打开会**自动**安装证书，等待软件界面提示「服务已正确启动」就说明可以正常使用（请关闭你的呆狸软件）

![](img/d76a4842cb6d6b4e93f154f1c20dd48d.png)

### 下载视频

打开你收藏的视频号。然后点击视频右下角就可以直接下载，点更多菜单可以根据你需要下载

![](img/a257d30bb034f60a72ccd0aafe0c1527.png)
