# IPhone13 pro这样设置多用5年

> 来源：[https://xodnytdcaw.feishu.cn/docx/YbibdY5ACovmc1xbUQJcatk7nWd](https://xodnytdcaw.feishu.cn/docx/YbibdY5ACovmc1xbUQJcatk7nWd)

## 设置

Apple ID->查找->查找我的iPhone->全部打开

无线局域网---启用wapi

通知-通知风格

+   短信---->标记（关闭）

+   其他的APP类似

通用

+   关于本机->名称 自定义手机名称 热点或是蓝牙的时候都能清楚显示

+   安装IOS屏蔽更新

关闭后台app刷新

显示与亮度----原彩（关闭）

辅助功能-----显示与文字大小

+   降低透明度（开启）

+   增强对比度（开启）

+   降低白点值25-40  创建自动化(晚上7点打开，白天6点关闭)

+   自动调节亮度（开启）

+   色彩滤镜----色调（强度0 色调自己舒服的位置）

+   触控->轻点背面->轻点两下->快捷指令（滑动到最底部）->支付宝健康码

电池-电池健康与充电---开启优化电池充电（开启）

隐藏与安全性-跟踪

+   定位服务 通用->进入对应app设置为使用期间/用不

+   允许App请求跟踪（关闭）

+   Apple广告---关闭个性化广告（关闭）

照片

+   共享相薄（关闭）

+   保留原片（开启）

相机

+   录制视频---HDR视频（开启）

+   格式--高效

+   保留设置---全部打开

+   微距控制（关闭）
