# 案例1 小红书 > 微信 > 神图君

变现内容：AI绘画

公域引流：小红书笔记/小红书群

私域变现：微信小程序“神图君”

变现方式：

A. 用户看广告下载图片，提成大概0.12元/次

B. 用户注册“神图君”会员，免广告下载图片，提成9.9元x70%=6.93元/人次

启发：这个路径长，不过平台让利还算不错，给创作者做了变现运营和提现服务

# 案例2 油管 > Gumroad

变现内容：Notion多维表格

公域引流：油管视频

私域变现：Gumroad挂商品 https://gumroad.com/

变现方式：

用户点击购买，平台收取10%服务费，支付渠道费用另算（Stripe，Paypal）

启发：这个路径短，并且可以卷美元，溢价高

# 案例3 CivitAI > 爱发电

变现内容：C站上的LORA模型创作行为

公域引流：C站

私域变现：引流到爱发电平台 https://afdian.net/ （类似https://www.buymeacoffee.com/)

变现方式：粉丝按月订阅支持创作者

启发：这个路径也短，属于自愿自持创作者，收益变现不好（毕竟国内白嫖的多）

# 案例4  小红书AI绘画+饰品日用品（ChatGPT细聊的结果）

公域引流：小红书笔记、群

私域变现：小红书店铺商品

变现方式：1688一件代发

启发：用stable diffusion的controlnet结合真实上架的商品做笔记（实践中）
