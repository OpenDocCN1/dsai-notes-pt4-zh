## 市场营销活动方案指令 Prompt 一览

注：

- 在提问 Prompt 中需要加入产品、面向对象等具体的信息素材，以便 GPT 更好地输出定制化回答。
- 一份完整的活动策划案需要用户不断地通过 Prompt 引导启发，需要多轮对话配合完成。
- 以下是摘录的部分市场营销相关 Prompt 👇

1. 请编写一份市场营销活动大纲，以应对我们向［理想用户画像］展示我们的［产品］时，陷入沉没成本谬论。考虑如何以未来的收益，而不是过去的投资为重点，来构建我们的产品/服务价值，并考虑到如何克服任何改变或决策偏见的阻力。
2. 请编写一个营销活动大纲，在向我们的［理想客户画像］定位我们的［产品/服务］时，使用收益递减法则。请考虑如何优化我们所提供的价值与成本，并如何有效地将这个价值传递给目标受众。
3. 请编写一份营销活动大纲，利用帕累托法则来确定对于［理想客户画像］最重要的［产品/服务特点］，并专注于最大化这些特点的影响力。考虑如何优先考虑其余［20％/80％］的特点，以增加客户体验的价值。
4. 请撰写一个市场推广活动大纲，向［理想客户画像］推介我们的［产品/服务］时考虑到蝴蝶效应。考虑到小的变化或行动如何产生巨大而不可预测的影响，以及如何预测和管理这些潜在的影响。
5. 使用Pratfall效应撰写一个营销活动大纲，利用幽默或自嘲的方式强调产品或服务的不完美或错误，并创造出相应的信息和优惠。使用这种方法使产品更加贴近目标受众，增加转化率。
6. 使用最小化努力原则编写一份营销活动大纲，旨在使产品或服务尽可能易于使用和方便。找到减少目标受众采用和使用产品所需的努力的方法，并创建强调这些优势的信息和优惠，以提高转化率。
7. 使用定锚调整启发法编写市场营销活动大纲，以逻辑和渐进的方式呈现信息。考虑受众的初步印象和假设，并将信息和优惠锚定在这些初步点上。然后，根据额外的信息进行调整，以提高转化率。
8. 用代表性启发法编写市场营销活动大纲，吸引［理想客户人设］。找到代表受众期望的原型或刻板印象，并创建与该原型类似的信息和优惠，以提高转化率。
9. 为避免赌徒谬误，请编写一个市场营销活动大纲，以有意义和准确的方式呈现数据和统计数据。强调考虑全面的信息的重要性，不要依赖过去的表现作为未来结果的保证。使用数据来证明［产品/服务］的有效性，以及它如何帮助［理想客户人设］实现他们的［目标］。
10. 使用边际分析原则，请概述考虑各种增长策略的边际成本和边际收益的市场营销活动。确定正在考虑的［策略］，并根据它们对活动的整体
11. 编写一个市场营销活动大纲，避免依赖刻板印象或典型的例子来针对［理想客户人设］。使用代表性启发法考虑全面的信息，并避免判断中的偏见和错误。使用数据和统计数据支持考虑全面信息的价值。
12. 编写一个市场营销活动大纲，考虑到［理想客户画像］可能会产生心理上的排斥。强调使用［产品/服务］提供的自主权和自由，并避免可能被视为控制或限制的语言或优惠信息。强调受众在使用产品时的选择和控制权。
13. 编写一个市场营销活动大纲，解决［理想客户画像］可能存在的邓宁－克鲁格效应。解释继续教育和学习［产品/服务］的重要性，以做出明智的决策。使用数据和统计数据支持学习的价值，以避免过高估计自己的能力。
