# 新手的第一个问题：选择哪个AI图像生成平台？

> 来源：[https://jalicvoygc0.feishu.cn/docx/Rw5RdmlIioULbBxs4WRcVfBXngh](https://jalicvoygc0.feishu.cn/docx/Rw5RdmlIioULbBxs4WRcVfBXngh)

作者：chaseleantj

当人们想要制作AI图像时，最常见的问题是：应该选择Midjourney、DALL-E 3、Adobe Firefly 2还是Stable Diffusion？经过6个月的实验和生成超过50,000张图像，一个专家给出了他的见解。

1. Midjourney：美学与故事情感的最佳选择

Midjourney是目前最受欢迎的平台之一，特点是生成具有极高美学价值和情感氛围的图像。该平台适合艺术和故事情感的创作，但存在三个主要缺点：用户界面不友好，不能上传和编辑自己的图像，以及难以生成具有一致性的多张图像。

2. DALL-E 3：多功能与实用性并存

DALL-E 3的优势在于多功能性和实用性，特别适合制作漫画、填色书图像、矢量图、标志和T恤设计。该平台能够很好地听从复杂的指令，并且是唯一一个可以生成文字的AI图像平台。然而，它在生成逼真和电影风格的图像方面稍逊一筹。

3. Adobe Firefly 2：逼真至极，但价格不菲

Adobe Firefly 2的主要优势在于生成极其逼真的照片，其细节之多让人难以区分真假。但是，该平台的价格相对较高，且在其他类型的图像生成方面表现一般。

4. Stable Diffusion：无限的控制和自定义，但难度大

Stable Diffusion具有几乎无限的控制和自定义能力，特别适合专业用户和品牌。该平台允许用户下载多种风格，同时还有一个名为ControlNet的功能，用于控制图像的具体姿态和风格。但是，这一切都需要相当高的学习曲线和强大的硬件支持。

**总结：选择哪个，看你的需求**

总体而言，每个平台都有其适用的场景和优势。如果你追求美学和情感，Midjourney是不二之选。如果你需要多功能和实用性，DALL-E 3会是一个好选择。如果你想生成逼真的照片，Adobe Firefly 2值得考虑。而如果你是一个愿意投入时间和资源进行深度定制的专业用户，Stable Diffusion可能是最适合你的。
