# midjourney指令说明

mj大家用的比较少，细讲一下

![](img/e047809e5d28fb4f65011969a32005be.png)

![](img/d6653cd8c55900ece4adf3afb4d495e8.png)

然后就是跑图，跑完图之后的ID就是图片编码，可以理解成mj上的图片链接。

U1/V1之类的跟MJ一样！

📢U**指的是：U**pscale，指针对这张图**片放大和**填充更多**细节。当你****挑出满意**的图片之后可以使用U指令进行单张图片的细化放大。

📢V指的是：Variation，指针对这张图片进行变体微调。再生成一组图片！

U1-U4指分别代表是左上、右下、左下、右下4个位置

![](img/a836f4d25aba822eef52247b9cc8ef91.png)

我们的指令只需要打数字，就能匹配对应的效果，比如图上的9，代表V4，代表右下角的图进行微调

👉5代表再来一次（相同prompt继续抽卡）

![](img/ffc7cd8d680cd1ccc77cf8635814ffed.png)

![](img/4e5a7718e4aced6ed94776b1966d5d97.png)

然后如果你是放大图片，还能进行下一步，看图就懂了。

哦对了这是**M**idjourney5.2 版本新功能，提供了三种缩放选择，分别是1.5倍、2倍以及「1.0到2.0」之间的自定义缩放。

然后上下左右几个箭头是也是新版的无限拓展，效果是图3这样的。是不是觉得跟PSAI的功能很像😉

# 指令详细介绍

#### 版本

![](img/8a57ab73ba904398607d1d48a67a189e.png)

#### 图片长宽比

+   5:4 多用于传统打印

+   3:2 多用于照片打印

+   7:4 比例接近于 HD TV 的比例，或者是智能手机

#### **NIJI**

[这个其实 Niji ](https://spellbrush.com/)模型，是 Midjourney 跟 Spellbrush 一起开发的。「niji」是日语「にじ」，意思是「彩虹」 或者 「2D」。

它在生成动漫类的图片上，比较在行。举个例子，prompt 是 fancy peacock，左图是 v5 模型，右图是 niji v5模型，右图更偏向于漫画风格：

![](img/5332a7af75b097a170607d820c4b65c6.png)

然后niji有多个版本，**大家用默认就行，或者用****指令**** -niji 5 **因为4真的太垃圾了（🥺不过比我画的好，岂不是我更垃圾）
