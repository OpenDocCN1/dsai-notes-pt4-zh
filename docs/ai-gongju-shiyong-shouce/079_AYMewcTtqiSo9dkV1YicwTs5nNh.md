
# NO.04姿势生图（DIY人像）

> 来源：[https://my.feishu.cn/docx/HKuIdUmdFogBjExfdRpci4C7nOd](https://my.feishu.cn/docx/HKuIdUmdFogBjExfdRpci4C7nOd)

姿势生图是官方刚发布的新功能！

## 操作方法

大概是这样的：

+ 整体（打过游戏的无门槛上手）
+ **左键**-控制**角度**（365度无死角，不要做涩涩的事情
+ **右键**-控制**方位**（其实就是让画面上下左右移动
+ **滚轮**-控制**距离**（近景大头贴、大长腿特写or远景全身照
+ **局部控制**

局部控制需要点击连接点，然后拖动球体上的线条来控制方向

![](img/f81863997aa6df3b42849685bede4de4.png)

MAC没有右键，可以点头部的点实现右键和滚轮功能

![](img/f0c55c563eda8751e7cadb052949f838.png)

局部控制需要点击关节上的连接点
