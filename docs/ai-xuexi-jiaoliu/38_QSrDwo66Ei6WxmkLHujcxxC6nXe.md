## DeepSeek是什么？

DeepSeek（中文名：深度求索）是由杭州深度求索人工智能基础技术研究有限公司开发的一款人工智能模型。它的英文名“DeepSeek”结合了“深思”（Deep）和“探索”（Seek），寓意通过深度学习技术探索未知领域。

DeepSeek 是一款功能强大的人工智能模型，能够回答各种问题、撰写文章、编写代码、进行文案创作以及处理复杂的推理任务。然而，它并非万能。如果提问过于随意，得到的回答可能较为简单，特别是在未启用深度思考模式的情况下。因此，我们应理性看待 DeepSeek，既不过度美化，也不贬低，它只是一个优秀的工具，尚未达到“无所不能”的境界。

DeepSeek-R1 是 DeepSeek 最新的深度推理模型，对标 OpenAI 的 OpenAI o1，而非 GPT4o。GPT4o 是多模态通用模型，能够处理图片、语音、视频等多种形式的数据，而 R1 目前的功能相对有限。

## DeepSeek怎么用？

目前，DeepSeek 提供了以下使用方式：

1. **网页版**：访问 https://chat.deepseek.com 直接使用。
2. **App**：在手机应用市场搜索“deepseek”，下载并安装即可。

**DeepSeek 的聊天界面**提供了**三种模式**：基础模型、深度思考（R1） 和 联网搜索，用户可以根据不同场景和需求灵活选择。

![](img/b1bfa1a7b44d6d9fbc3d283abb3a4e83.png)

+ **基础模型**：去年 12 月升级到 DeepSeek-V3 版，性能媲美全球顶尖的开源和闭源模型（如 GPT-4、Claude-3.5-Sonnet、Qwen2.5、Llama-3.1 等）。
+ **深度思考（R1）**：这是 DeepSeek 的最新推理模型，因其免费、开源和极低价的 API，成为国内外热议的焦点，甚至被称为“国运”级模型。
+ **联网搜索**：基于网络搜索结果回答问题，即 RAG（检索增强生成），可以理解为 DeepSeek 的 AI 搜索功能。

界面右侧的附件按钮支持上传文档、图片等信息，但不能与联网搜索同时使用。

![](img/aca2335f73c87d711f073b1d6bc9010e.png)

**总结**：

+ 如果只是简单提问，使用基础模型即可。
+ 如果需要推理过程或深度思考，选择深度思考模式。
+ 如果需要查询互联网上的最新资料，勾选联网搜索功能。

## DeepSeek和ChatGPT的区别

DeepSeek 和 ChatGPT 都属于大语言模型（Large Language Models, LLMs），但它们的设计目标和应用场景有所不同。

1. **DeepSeek 模型**

   + **类型**：DeepSeek 是一个 **垂直领域知识 + 推理模型**。
   + **特点**：
     + 针对特定领域（如法律、医疗、金融等）进行优化，提供更精准的答案。
     + 强调 **复杂推理能力**，能够处理复杂的逻辑问题和多步推理任务。
     + 通常用于需要深度专业知识和高效决策支持的场景。
   + **应用场景**：
     + 专业领域的问答系统。
     + 复杂问题的推理和解决。
     + 高效的知识检索和分析。

2. **ChatGPT 模型**

   + **类型**：ChatGPT 是一个**通用对话生成模型**，基于 OpenAI 的 GPT 系列。
   + **特点**：
     + 专注于 **自然语言对话**，能够生成流畅、连贯的文本。
     + 适用于广泛的通用任务，如聊天、写作、翻译、编程辅助等。
     + 强调 **交互性** 和 **通用性**，而非特定领域的深度知识。
   + **应用场景**：
     + 聊天机器人。
     + 内容创作（如写作、文案生成）。
     + 通用问答和知识查询。

3. **区别**

4. **共同点**

   + **基础技术**：两者都基于 **大语言模型（LLMs）**，使用 Transformer 架构。
   + **预训练 + 微调**：都通过大规模预训练和特定任务微调来提升性能。
   + **自然语言处理**：都能理解和生成自然语言文本。
   + **应用领域**：都可用于问答系统、知识检索等任务，尽管侧重点不同。

5. **总结**

   + **DeepSeek** 更适合需要 **深度领域知识和复杂推理** 的场景，例如专业领域的决策支持。
   + **ChatGPT** 更适合 **通用对话和广泛任务**，例如聊天、写作和日常问答。

两者各有优势，选择取决于具体需求：如果需要专业性和推理能力，DeepSeek 更合适；如果需要通用性和交互性，ChatGPT 是更好的选择。

## DeepSeek使用技巧

**DeepSeek-R1** 作为一个推理模型，会通过 分步骤推导 来解决问题，生成详细的推理过程，并尝试解释每一步的逻辑。它基于训练数据中的模式和规则，会对生成的内容进行合理性评估。

结合模型特性和实践经验，整理以下提升交互效率的核心技巧：

### 一、结构化提问技巧

| **技巧类型** | **操作建议** | **示例对比** |
| --- | --- | --- |
| **场景限定** | 前置关键背景信息 | 模糊："翻译这句话" → 精准："作为跨境电商客服，请将以下英文产品描述翻译成中文口语化表达：..." |
| **任务分解** | 对复杂问题分步骤提问 | 模糊："写行业分析报告" → 精准："请先列出新能源汽车行业2023年三大趋势，再给出竞品分析框架" |
| **格式指定** | 明确期望的呈现形式 | 模糊："介绍杭州景点" → 精准："以表格形式对比西湖、西溪湿地、良渚遗址的景点特色、门票价格、推荐游览时长" |
| **知识锚点** | 关联具体时间/数据/文献 | 模糊："最新的AI进展" → 精准："基于2023年Nature期刊发表的论文，总结大语言模型领域的三项关键技术突破" |

### 二、领域优化策略

1. **行业知识调用**

   + 激活提示："作为[金融分析师/医疗顾问/法律从业者]，请用专业术语解释..."
   + 示例："请以二级市场研究员的视角，用市盈率、市净率等指标分析当前光伏板块估值水平"

2. **中文语义增强**

   + 利用DeepSeek对中文语境的深度理解：

```
# 模糊提问
"成语接龙"
# 优化提问
"请以'数字化转型'开头，进行四字成语接龙，要求每个成语需与企业战略相关"
```

3. **多轮对话管理**

   + 通过上下文关联实现精准迭代：

```
用户：给出新能源汽车电池技术发展路线图
AI：提供三元锂/磷酸铁锂/固态电池技术对比
用户：请重点展开固态电池的商业化瓶颈
```

### 三、响应质量控制

| **需求类型** | **指令模式** | **效果说明** |
| --- | --- | --- |
| **深度论证** | "请用SWOT分析法论证..." | 强制结构化思考 |
| **可信度验证** | "请标注观点出处到2019年后" | 控制知识时效性 |
| **复杂度调节** | "用高中生能理解的语言解释量子计算" | 自适应表达层级 |
| **错误修正** | "上文中关于GDP增速的数据需要重新核对" | 启动事实校验机制 |

### 四、技术特性适配

1. **合规性优势**

   + 自动过滤敏感内容，可直接询问："如何合法合规开展数据跨境传输？"

2. **领域强化路径**

   + 通过提示工程激活垂直知识库：

```
"基于《网络安全法》相关条款，分析用户画像收集的合规边界"
```

3. **效率优化技巧**

   + 在复杂计算场景下使用分步指令：

```
"第一步：计算2022-2023年中国GDP年均增长率
第二步：用该增长率预测2025年经济总量
第三步：分析预测结果的潜在误差来源"
```

### 五、避错指南

1. **避免宽泛表述**

   + ✖ "说说人工智能"
   + ✔ "对比深度学习与符号主义AI在自然语言处理中的方法论差异"

2. **防范时效错位**

   + 对2023年12月后的信息主动说明：

```
"关于2024年最新政策，建议查阅主管部门官网核实"
```

这是因为模型训练数据的时效性限制等原因。

3. **消除歧义**

   + 对多义词添加限定：
     + ✖ "苹果的市值"
     + ✔ "截至2023年12月，Apple Inc.(NASDAQ:AAPL)的市值"

通过以上方法，可显著提升与DeepSeek的交互质量。建议结合具体场景尝试不同指令模式，持续优化提问策略。

## DeepSeek 万能提示公式

基于对DeepSeek-R1技术特性的深度理解，结合案例实践，设计为以下普适性提示公式：

```
[角色定义]（我是谁）+[背景约束]（啥条件）+[任务分解]（要干啥）+[输出规范]（怎么输出）+[验证机制]（怎么验证）
```

**以下是公式分解说明。**

1. 角色定义（Role Anchoring）

```
"作为[领域专家角色]，需要处理[具体场景]的问题..."
```

示例:

"作为资深金融分析师，需要为私募股权基金评估AI医疗项目投资可行性..."

2. 背景约束（Context Bounding）

```
# 时空限定
"背景：2023年中国网络安全审查办法修订后..."

# 知识边界
"限于《民法典》合同编相关规定..."

# 能力设定
"假设具备Python数据处理基础..."
```

3. 任务分解（Task Decomposition）

```
/* 复杂问题结构化 */
"请分三步分析：
Step1. 收集2020-2023年行业关键指标
Step2. 建立回归模型验证假设
Step3. 评估政策变化对预测的影响"
```

4. 输出规范（Output Specification）

```
[格式要求]
"以Markdown表格呈现，包含以下列：
- 技术路线
- 研发周期
- 成本估算
- 风险等级"

[风格指导]
"使用证监会年报披露格式，重要数据加粗显示"
```

5. 验证机制（Validation Protocol）

```
# 交叉验证
"请同时提供：1)主流方法论 2)深度求索技术白皮书中的方案 3)两者差异分析"

# 可信度标识
"关键结论后标注数据来源年份及置信度百分比（如：据IDC 2022报告，置信度85%）"
```

掌握此公式后，可通过调节各模块参数适配90%以上的专业场景需求。建议从简单应用开始，逐步叠加复杂度训练提示工程能力。
