
# 新必应（New Bing）国内申请与使用教程

> 来源：[https://aiyanxishe.feishu.cn/docx/UjgddOABiobzHexvqYqcigmhnhe](https://aiyanxishe.feishu.cn/docx/UjgddOABiobzHexvqYqcigmhnhe)

## 新必应申请

下载安装 Edge dev 版本，这个版本可以直接申请（不用🪜）使用。

Edge dev 下载链接：https://www.microsoftedgeinsider.com/zh-cn/download/dev

![](img/996ba14c8ea70509e29a0e30cc93f83e.png)

安装后浏览器集成新必应入口截图（右边）

![](img/462700d4561426ff587658ee11a32b4c.png)

安装完成后，点击右上角必应图标，会弹出申请按钮，登录账号加入等待列表。

![](img/29b8ff87751c8d1f931f49b7ca84c695.png)

登录微软账号，申请加入，然后会有一封邮件通知你已加入等待列表。

![](img/493da7da7fa44c394e78c760280b0c6a.png)

等待微软通过后，你会收到欢迎邮件，你就可以使用新必应。

![](img/759c040ab0f0a27c37b430c03326f169.png)

## 新必应使用教程

需要先下载安装 HeaderEditor 插件。

[HeaderEditor 下载链接](https://link.juejin.cn?target=https%3A%2F%2Fmicrosoftedge.microsoft.com%2Faddons%2Fdetail%2Fheader-editor%2Fafopnekiinpekooejpchnkgfffaeceko)

HeaderEditor 配置截图：

请按截图来配置，配置参数有：

```
// 匹配规则
^http(s?)://(.*).bing\.com/(.*)
// 头名称
x-forwarded-for
// 头内容
8.8.8.8
```

设置完就可以使用了。
