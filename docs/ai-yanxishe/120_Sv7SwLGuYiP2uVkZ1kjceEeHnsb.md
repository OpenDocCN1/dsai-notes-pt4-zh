Coze 允许你不管是否懂编程，都能快速打造出各种各样的聊天机器人、智能体、AI应用和插件。想象一下，无需深入代码丛林，你就能创建自己的AI伙伴，多么酷的事情啊！

现在跟着本教程，不管你是代码新手，还是老司机，Coze都能让你轻松玩转AI。现在，大家都来试试手气，看看能创造出什么样独一无二的AI作品吧。（欢迎评论区留下你的 bot链接哇，互相体验，互相建议，越来越好！）

提前准备

## 注册帐号

可以使用抖音帐号和手机号注册登录。

![](img/77b623021473e7eec927683cf185f701.png)

登录后，可以点击左下角的昵称，进入设置页面，可以设置个人基本信息，以及添加 bot 支持的渠道（后面用的时候介绍）。

![](img/f533e356ff6f2b0a5ede48ee7b524d07.png)

## 创建 Bot

在主页，直接点击我想创建一个 Bot，即可进入 bot 创建流程。输入你期望bot的功能和名字即可。

![](img/127819e122ca2a2c66cab7e054ac69da.png)

## 详细配置 Bot

点击上面回复的 Bot 链接，即可进入详细配置页面。

![](img/b6f9f24a1753eaad5a400bbfd3d183da.png)

下面详细介绍下，第一部分是 bot prompt 编辑区域。

![](img/f6a8015009b3d0fa94bd4991e23d06b2.png)

第二部分是 bot 拓展区域（我是这么理解的），可以给机器人添加插件、工作流、知识库、数据库等。

![](img/ea5398dc52ecb161341aad3b03424b54.png)

点击打开可以看到有一堆插件工具，比如新闻阅读、旅行计划，甚至还有生产力工具和图像理解API。这就像是一个万能工具箱，里面什么都有，最主要，都是中文的，咱用起来方便啊！

![](img/7d007b2855ec9df9d681b82ab45d497d.png)

它还能管理知识库，让AI和你的数据亲密互动，简直就像是在给你的AI小伙伴装上了大脑。

![](img/3e3ceb7a841b441a8e4b54e3e96c645a.png)

第三部分是预览调试区域。当你的AI机器人开发完成后，Coze 还提供预览和调试的功能。这就像是给你的AI小伙伴做个终极测试，确保它能完美上线。

![](img/e23891912474da3565013b3b2d916da8.png)

## 发布 Bot

以上都配置好，即可发布，发布可以选择关联 豆包APP、飞书、微信等。这里先关联飞书测试下。

![](img/d3d4498985fb7f23f4ed93369ea67fc0.png)

提交后等审核完成即可。

![](img/1bf0a06fea7ff11150ec2edd41a5c25b.png)

## 审核发布 Bot

电脑网页进入飞书管理后台，点击 工作台 -- 应用审核，即可进行，自己手动通过下即可

注意：如果你公司使用，需要公司飞书管理员登录后台审核。

![](img/867a1ddd014ab5c9b2195db4055434ac.png)

xxxxxx 改成你自己的飞书域名前缀

https://xxxxxx.feishu.cn/admin/appCenter

## 使用 Bot

在 飞书 APP 搜索自己的机器人名称即可，比如我的是简说Python爆笑机器人，点击机器人进入对话页面。

![](img/24a10279b4e54cca5d175e3483b4a1a9.png)

在对话页面输入自己的问题即可获取回复，速度很快！

![](img/53aa322c0c6edd17d1a908ef112330bf.png)

## 精进 Bot

在 主页 个人空间里可以看到自己创建的机器人。

![](img/f493ec4918b355cda0953d820deef7f5.png)

点击进入后可以再次进行编辑优化，盲猜这部分是bot id。

![](img/54145c1842c0a93d152228ff51329408.png)

## 如何变现

目前有几个思考方向，后续陆续补充相关内容：

+   飞书/微信机器人助手，卖服务给学生就是AI老师，给企业就是AI企业助手，给商家就是AI客户机器人

+   做自媒体：可以生成一些相关bot，然后整个流程自动化起来，我只需要手机发个主题，然后优化文案，再将文案发给 bot 通过工作流帮我发到各个平台，自媒体变现途径就多了！

+   销售给自己：对，这个含义其实是通过先 coze 开放的这个功能，生成一些对自己生活、工作有帮助的bot，提升自己的能力，毕竟，自己才是最值钱，要赚钱也得先有自己。

## 进阶使用

基于广场Bot快速创建

主页点击Bot，可以看到很多官方提供的 Bot（以后肯定会越来越多），点击选择一个自己喜欢的，即可进入 Bot 配置详情页面。

![](img/db74d7e561efe0861aa8d745c8f4dc30.png)

比如我点击了小红书文案输出大师，在配置页面你完全可以看到这个 Bot 的所有配置信息，包括：Prompt、使用的插件等内容。

你还可以点击创建副本，然后就可以直接基于自己需求进行二次创作了。

![](img/ee79dc07f8bca9640d1da054dde4156d.png)

## Bot API 调用

我发现 Bot 部署到飞书后，实际上就是一个一个的飞书机器人，那么我们是可以在飞书开发者中心，通过API去调用各种 Bot 的。
