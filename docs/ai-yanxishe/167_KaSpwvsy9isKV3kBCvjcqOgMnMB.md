# 58 UXD｜AIGC赋能品牌设计—全新定义品牌符号

> 来源：[https://aiyanxishe.feishu.cn/docx/LT0AdKR34oG3BVxDTfEcknBgnmd](https://aiyanxishe.feishu.cn/docx/LT0AdKR34oG3BVxDTfEcknBgnmd)

美事作为58同城内部办公平台，承载了每一位员工和管理者沟通、协作、流程、管理、工具等方方面面的场景。美事在前期的品牌建设中只有Logo图形，缺少品牌符号，以至于在推广时视觉表现单一，为了强化品牌设计传播，增强用户对美事品牌的感知，完善美事品牌体系，我们开始尝试美事品牌符号的设计，旨在运用到设计传播时，形成有美事品牌感知的图形符号识别。

![](img/ef98849d6985a35a062fc561e01973b6.png)

在品牌设计传播中，品牌标志的使用会面临局限性，为了确保品牌能够更好的拓展使用，保证一致性且便于记忆，需要用统一的符号化视觉培养用户对美事品牌的感知，于是进行了美事品牌符号的提炼。

![](img/971bb684d82cc92fd3e55429454cd12a.png)

品牌符号设计需要延续美事品牌的基因，通过将Logo中最有记忆点的部分进行优化，提炼出具有美事品牌调性的品牌图形。从Logo中提取的“叶子”图形，它不仅代表了美事6.0对5.0的传承，也见证了其中的成长。在保留原有型的基础上进行优化，让图形更有体积感、更容易记忆、更便于延展。品牌符号弥补了品牌标志在不同场景下视觉应用的局限性。

![](img/b659efb796be359673ebdc85b1898be1.png)

![](img/b2b7a4d59a71b0be01230fcb9e951f9e.png)

品牌符号补充表达品牌认知的定位及调性，基于美事“让工作成为一种美事”的品牌理念，将品牌符号通过有视觉张力及想象力的画面，将品牌的主张和调性进行概念化的诠释和演绎。

![](img/c2b19cdeec0dbc5943fd1c4a54774f5b.png)

·「连接」打破沟通壁垒，让工作更高效

·「目标」明确目标方向，高效达成

·「成长」创新突破，和企业共同成长

![](img/1774196e0feb3749d16cd21eedc05ed6.png)

·「凝聚」提升凝聚力，创造更大价值

·「探索」拥抱变化，用于探索，走出舒适区

·「开放」开放、吸收、完善自我

通过AI绘图降低试错成本，提升效率

由于品牌理念较为抽象，导致设计成本过高，有很大的试错性，使用AI绘图可以很好的解决这一问题，通过不断生成符合自己预期的图片做前期提案，将通过的方案进行合成与精修，显著提升效率。

![](img/8f600bfa07c0b01dd9a408c78854a5ad.png)

**AI绘制品牌概念图全流程**

提炼传达品牌理念的关键词，如“探索”。根据自己想象和要构建的画面找到合适的参考图（图片来着互联网），将找好的参考图导入Midjourney作为垫图，再通过精准的描述和后缀的设置，不断生成画面。

![](img/515e13be38bd1ae04538264fa5154ef0.png)

选择合适的图片或多张图片，与品牌符号做融合，并处理修整，调整颜色，丰富细节，得到最终效果。

![](img/6995140e7560a3f764fcce0d4fed0db2.png)

通过AI绘图，后期搭配3D、手绘、合成等手段，高效完成了整套品牌符号的概念演绎。

![](img/6248db423b297bc7f607376d1e596da1.png)

![](img/38690cf083104e1a8ae7af8bee2b67c6.png)

**符号视觉应用**

为了更好的触达落地场景，形成稳定的品牌感知，保证视觉风格一致性，基于图形符号进行了视觉延展。符号应用遵循美事品牌颜色，蓝绿配色来使用，分别以浅色和深色为方向，列举了当3D人物、真实人物和物体元素为视觉主体时的展示效果，丰富了视觉形态，以适配不同的落地场景。

![](img/aea06c065797e3cc12b46f9a8fe83aac.png)

**通过AI精准生成所需人物素材**

作为品牌符号在运营场景下的使用示例，要保证整体的视觉一致性，确保人物统一，才能起到规范作用。在确定3D人物样式后（仅作示例使用），真实人物的性别、样貌、服饰和举止要尽量贴合3D人物，这就导致需要的人物素材很难从素材网站获取，使用AI生成更加便捷。

![](img/94811bf710f7465a6ef55e8cd0e8f38c.png)

根据3D人物形象延伸关键词，对真实人物形象进行准备描述，通过AI生图及后期处理得到理想素材。

![](img/d84a6b60b664696d3de0af98437e1b98.png)

全新定义品牌符号只是美事品牌建设的一个开始，我们还会持续不断地完善美事品牌体系，通过形成稳定的视觉感受，加深用户对美事的品牌感知，将设计成果不断落地到业务场景中，助力业务快速发展。
