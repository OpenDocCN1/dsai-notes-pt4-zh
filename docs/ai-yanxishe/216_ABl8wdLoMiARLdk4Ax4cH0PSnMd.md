# GPTs怎么赚取收入？

> 来源：[https://aiyanxishe.feishu.cn/docx/KJWXdvlfXonU9jxP9gMcbHWOnDf](https://aiyanxishe.feishu.cn/docx/KJWXdvlfXonU9jxP9gMcbHWOnDf)

GPTstore目前刚上线，据官方消息，Builder收入计划预计在2024年1月～3月（第一季度）开展。主要是根据用户与上线的GPTs的互动度给予相应的报酬，后续会有对应的收入价格标准。

+   这个计划有一个前提是**「美国builders」**，这个不用过多担心，谁开发的都一样，只不过帐户是需要有美户，订阅计划一样，这个相信难不倒各位的，毕竟看一下GPTstore，不少项目都是国人佳作，到时应该也是八仙过海，各显神通～

+   还有一点是store会建立一个新的审核系统，包括自动审核和人工审核，其次用户还可以举报GPTs，因此旁门左道的路子肯定是不通的了，需要更贴切的用AI解决大众的需求，来赢取更多的互动和使用。
