
# Open AI 官方：创建GPTs像呼吸一样简单

> 来源：[https://aiyanxishe.feishu.cn/docx/KlRldURG5o0ed4x3GF6crrRsnlg](https://aiyanxishe.feishu.cn/docx/KlRldURG5o0ed4x3GF6crrRsnlg)

GPT Builder 是 OpenAI 官方推出的一款工具，让用户更加方便地创建属于自己的 GPTs (聊天机器人)。你不需要设置复杂的参数，只需要通过和 GPT Builder 对话，它会根据你的指示来设置 GPTs 的各种特性，比如名字、头像、对话风格等，就像你的私人小助手。

有趣的是，GPT Builder 本身也是一个 GPTs，它内置了指令，能够根据你的对话来更新它自己的参数。这个工具的开发是为了更好地理解用户的需求，同时也展示了 GPT 在遵循指令方面的能力。对于更高级的用户，虽然推荐使用手动配置界面来编辑 GPTs 的详细参数，但 GPT Builder 仍然是一个不错的入门工具。
