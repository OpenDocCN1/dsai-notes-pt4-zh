**项目说明：**

MumuLab基于阿里云百炼、通义灵码等平台打造虚拟童话世界，借助大模型和多智能体的应用提供儿童故事创作和亲子互动、关注儿童陪伴。不仅能够自动生成奇思妙想的故事情节，还能生成形象和配音以及与虚拟角色进行对话，构建一个属于大朋友和小朋友的童话世界。下一步计划是为小朋友准备一个开心有意义的六一儿童节。

+   AI给了几个方向，个人觉得儿童故事、角色扮演和宠物都是好的思路。

### [AI+动画](https://aiyanxishe.feishu.cn/wiki/M9j9w4EnviBsLakrLXGcdc6tnmb?from=from_copylink)

+   还有一个想法就是借助Ai互动大屏，给孩子更多趣味的展示，比如：借助AI互动功能大瓶的视频采集和音频采集，孩子走过大屏前，就给孩子面部表情卡通化处理，让更多孩子走进场景，当然也可以大屏生成奥特曼打怪兽/元宇宙城堡/太空探索的AI场景。

+   对的，我之前整理过AI+动画的场景，如果能让孩子变身动画人物，比如植物大战僵尸，奥特曼和怪兽，孩子自己就能玩的很开心

![](img/988921e1adf50ff74da28f0ca67d1891.png)

+   大屏互动问题是好解决的，现在有成型的方案，现在略微需要调整的是把大屏人物重新处理成动画或卡通形象，基本就没问题了。如果想做的更好，就加上声音识别和调教。比如：孩子说：赛文奥特曼来帮忙，屏幕出现赛文奥特曼，和你一起打怪兽，孩子说：我要去大海，屏幕背景切换到海底寻宝场景。

+   如果没有大屏，用投影仪 是不是可以解决这个场景

+   不行的，投影仪的产品目前没有算力和交互体验，只能做简单的展示

+   交互交给云端，手机解决数据交互 ，或者搞个物联网的小盒子 解决交互

+   云端交互成本有点高了，5-8万一个月

+   这个场景 如果放进学校，只有投影仪

+   这块微软小冰有个解决方案，就是搞一个算力盒子，放在屏幕边上，既提供算力支持，也提供视频和音频的接纳处理

+   对的 理论上 通的

+   大屏 使用在广告的互动方面 倒是蛮好的

### 第三老师

+   我觉得可以考虑一个“第三老师”的概念。除了学校和家里，小朋友的其他时间是被严重分散的，有大量课内外的第三学习场景，除了户外体育运动，几乎其他场景都可以被整合在一个入口下。可以把创意类科目作为核心场景切入，提供一个引导创造和分享的平台，激发小朋友的内容创造力
