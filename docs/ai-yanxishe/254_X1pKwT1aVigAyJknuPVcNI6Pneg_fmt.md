
# 第七篇：AI 数字人的优势在哪?

> 来源：[https://aiyanxishe.feishu.cn/docx/XXDFdUHhfoI1U1xQfVzc5wEJnph](https://aiyanxishe.feishu.cn/docx/XXDFdUHhfoI1U1xQfVzc5wEJnph)

数字人主要是用来替代真人出镜的，那用数字人有什么好处呢?本文就来解析一下。

## 一)真人出镜主要有三大痛点

1. 出镜要保证效果，都需要梳妆打扮一番，保持良好的形象，费时费力。
2. 出镜要想有好的效果，需要补光灯、合适的布景、收音设备、安静的环境等，这个环境条件很难稳定保持。
3. 个人IP很多人都是兼职在做。每天下班时间不固定，或者个人私事较多时，很难保证持续固定的投入精力去拍摄内容，导致内容的稳定输出难；而一次性拍多条，又会导致内容的实时性差，不好跟进热点。

## 二)数字人可以非常好的解决真人出镜的问题

+ 数字人复刻个人形象，形象稳定性不变形。
+ 数字人可以搭配各种虚拟背景，声音输出也不受环境影响。
+ 准备好文案就可以生成真人口播的视频内容，投入精力小得多，确保内容可以高频更新。

## 三)数字人直播带货的优势

### 1)打造一个传统的真人主播直播间，成本是非常高昂的

主要有以下几方面成本：

直播场地费用：一个10平米的直播间，装修和租金费用，一年就得十几万元。

直播设备：为了保证好的直播效果，需要高清摄像头、补光灯、话筒等设备，设备成本至少得上万元。

主播和中控人员工资：直播带货，至少需要1个主播和一个中控，两个人一场直播4小时的工资也至少要一千元。

### 2)数字人的直播间，成本就低多了

除了数字人直播的费用外，不需要额外的场地，不需要额外的直播设备，更没有主播和中控的人员费用。

### 3)除了成本低以外，数字人主播还有额外的优势

1. 忠诚：数字人主播可不存在做大以后单飞的可能性，最近大家看到的董宇辉和东方甄选的冲突，是不会在数字人主播身上出现的。
2. 可控：数字人的话术都是提前设定好的，不存在临场说错话的问题。
3. 永不疲倦：人类主播是需要休息的，而数字人主播可以实现全天候的直播，打造一个永远在线的直播间。

## 四)数字人直播的局限

当然，数字人也不是说100%秒杀真人主播，它也有自身的应用局限。

**话术要提前预置**：数字人的直播话术需要提前完整的写好，不存在直播时随意发挥的空间。要让数字人直播，至少要准备1-2小时的直播话术，这就需要AI写作工具来帮忙。

**平台限制**：比如抖音，目前就不允许纯粹的数字人直播，必须要与真人主播搭配才可以直播。
