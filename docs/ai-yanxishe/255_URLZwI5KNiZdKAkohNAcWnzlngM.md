
# 第八篇：AI 数字人的成本由哪些部分组成?

> 来源：[https://aiyanxishe.feishu.cn/docx/Cl2UdPIteo4toexKnWtcW49CnqE](https://aiyanxishe.feishu.cn/docx/Cl2UdPIteo4toexKnWtcW49CnqE)

前面分析了AI 数字人的优势，这一节就说说数字人的成本，让大家心里有数。

数字人的成本，主要有以下四大项

![](img/9e035394de121a1dd6d06ceaf751a278.png)

## 1、形象和声音

数字人分为公模和复刻。

公模指的是数字人软件中预置的形象和声音，优点是能快速上手，不额外收费。建议刚开始想跑通数字人业务的时候，先拿公模练手。

流程跑通后，要做自己的个人IP，就需要复刻自己的形象和声音了，这时候会产生对应的费用。首先，个人要拍摄原始的训练视频，找专业场地加拍摄，大约1000元左右。数字人平台会根据训练视频来进行形象复刻。形象复刻也有多种技术路线，生成的数字人形象清晰度会有差别，因此价格也不同，如果选择 Heygen 平台，可实现 0成本克隆形象和声音，也有像微软小冰可实现几百元克隆，要求更高的现在市场价复刻一个高质量的形象大约是4000元，复刻声音也大约是4000元。所以，要生成一套可用的个人数字人形象，总成本从几百元到上万元不等。

## 2、短视频生成

数字人平台生成数字人短视频，按分钟收费。根据平台的不同，视频生成价格每分钟约5-20元。

## 3、直播实时链接

具备实时链接功能的数字人平台，可以实现真人接管。也就是在直播过程中，真人可以操控数字人说话，说预设的文本中没有的内容，由数字人的形象来播放。这种技术因为要实时生成数字人内容，所以价格高一些，每个月的价格大约在1000-5000元。
