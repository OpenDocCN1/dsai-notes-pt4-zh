# 数字人做虚拟故事视频如何变现？

#

拍摄传统的视频段子，我们需要专门的演员，摄影，灯光，就算最简单的人员配置也得 2-3 人，对于个人而言很难完成。但是借用 AI 数字人技术，我们是能轻松实现虚拟故事的创作。

我们先来看案例展示：

## **案例一：段老湿与蔡九（韭菜）**

段老湿利用 AI 绘画制作的两个 IP 人物，段老湿与菜九，讲述知识付费割韭菜的段子。

![](img/6e55e4dee68a194ebb43ba803a9e41e0.png)

## **案例二：马四爷**

马四爷的职场段子，主要追热点实践，讲述职场的段子。

通过 AI 技术，制作类明星的卡通 IP ，将热点事件或者是广为吐槽的职场事件编成有共鸣感的段子，因为形式新颖，段子质量高，播放量和粉丝量抖很高。

而我们需要的技术，仅仅是简单的 AI 绘画技术，照片说话的数字人技术，如果需要自己喜欢的声音，加上声音克隆技术就可以完成。

而这些技术，前文基本都已经介绍过，可以说门槛已经很低了。

这里需要注意的是，虽然没直接引用明星的肖像，但是还是可以看出来，因此为了避免麻烦，还是建议尽量不采用名人的肖像来制作 IP。

当然毕竟未使用明星肖像，也没有大的问题，这个就需要每位船员自己衡量了。

![](img/4c1746b7140fd2f79ac6262f31cce790.png)

**变现形式也分平台，**以视频号**来说，可以**开通视频号分成计划，也可以接商单广告，马四爷的账号已经接到了苹果手机，理想汽车的广告了，可以说变现还是很客观的。

而**段老湿与菜九的账号**，因为是刚开始做，暂时没有接到广告，但是段老湿做视频的目的，一个是宣传破局，一个是做知识付费避坑，变现形式是知识付费。

因此，各位船员，可以根据定位法则，去找对标账号，做适合的领域，比如情侣段子，比如搞笑段子等等。再有更暴力的，就是寻找高质量的真人实拍段子，去模仿就好啦。懂了么？
