# 数字人做名人名言类视频如何变现？

> 来源：[https://aiyanxishe.feishu.cn/docx/StHLd4PLno5Xxnxpoe9ciRj8nVc](https://aiyanxishe.feishu.cn/docx/StHLd4PLno5Xxnxpoe9ciRj8nVc)

#

名人名言，思维账号，这个赛道一直以来流量都很大，在 AI 破局俱乐部，也举办过这种账号的快闪活动，很多人都拿到结果，有的几天涨粉过万起号成功，有的通过橱窗带货一个月变现上万的。

![](img/888e1fba776dd9e28820f6e0891bfc2e.png)

![](img/436dd49b967a000a93d826a56a5fcc80.png)

这种账号的本质，就是利用有高认知话术，引发人们的共鸣，从而引发点赞，评论，收藏，甚至是关注，从而导致视频本身流量大。但是有一个比较大的缺点就是门槛较低，同质化严重，从而大量类似账号泛滥而没有流量，更不用说变现了。

但是，任何赛道，本身就是需要差异化的运营，一味的单一模仿势必是行不通的，因此如果想做这个赛道的，建议从以下几个方向入手：

第一：**不要用公模**，可以去设计专属的 IP 形象，在前面英语的案例中，数据较好的视频都是使用了差异化的形象。

第二：增加背景，更换发型，衣服等局部细节，去重。这一点是很多人都不会注意的，很多人都是有追热心态的，觉得这种类型视频简单流量大就盲目的去模仿，殊不知，如果只是简单的用同一形象，甚至是共模去做，连最基本的去重都做不到，重复的视频怎么会有流量呢？

第三：用数字人做短视频，应该都是有目的的，要不吸粉到私域，要不通过视频变现。那在做的时候，其实就应该想好自己侧重的目标是什么，如果是吸粉，那在账号装修，视频话术设置的时候都应该考虑加你私域的钩子。

如果是通过视频变现，那就得考虑好变现形式，如果是要带货，那就应该在设计整个视频的结构，同时在话术设计时，一定要穿插着商品展示及卖点，同时还要科学选品，这样才有可能卖出去。

如果只是模仿形式，不去思考对标账号的变现逻辑，甚至是自己做这个的目的是什么都不清楚，只是为了去做而做，那么变现将与你无缘。
