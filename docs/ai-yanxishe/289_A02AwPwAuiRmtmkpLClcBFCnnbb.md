# 声音克隆工具：Clone-voice，免费开源，操作简便

> 来源：[https://aiyanxishe.feishu.cn/docx/Bepsdv1emoITkZxyBkucgqYxnBd](https://aiyanxishe.feishu.cn/docx/Bepsdv1emoITkZxyBkucgqYxnBd)

今天我要向大家介绍一款令人惊叹的免费开源声音克隆工具：Clone-voice。

![](img/44ad4e637b2c76c31e835c724c595fc3.png)

它的强大功能令人瞩目，可以克隆出任何人的声音，而且目前支持中文、英文、日语和韩语四种语言。最重要的是，这款工具使用非常简便，对电脑配置要求也不高。

只需从github上，下载预编译版本文件，减压后，双击打开一个.exe 文件，就会跳转到一个 Web 界面。在这个界面上，你可以选择想要克隆的语言，然后上传你录制好的音频文件，输入需要克隆的文字内容，最后点击开始生成按钮，稍等片刻，你就能得到一个与原始声音极其相似的克隆声音了！

![](img/9a0717f511596d6adb6f092f4cb84c60.png)

Clone-voice 采用了先进的人工智能技术，可以分析和模拟人类声音的特征，从而实现高质量的声音克隆。无论你是想为自己的视频制作配音，还是想与朋友进行有趣的语音聊天，这款工具都能满足你的需求。

总的来说，Clone-voice 是一款非常实用和有趣的声音克隆工具，它为我们提供了一种全新的创作和娱乐方式。如果你对它感兴趣，不妨亲自尝试一下，相信你一定会爱上它的强大功能和便捷操作！
