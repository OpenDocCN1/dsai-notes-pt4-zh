# 一个10秒的AI视频，6天变现3.5万

> 来源：[https://aiyanxishe.feishu.cn/docx/OX4Cd5Tibo3gS2xJDZTcr5oAnFc](https://aiyanxishe.feishu.cn/docx/OX4Cd5Tibo3gS2xJDZTcr5oAnFc)

今天给大家分享一个所有人都能做的小项目。

# 一、项目原理

通过小程序推广计划，上传一张照片通过AI自动生成视频，然后发布。

主要利润是广告收入。不要小看这个广告收入，有人在六天内实现五位数的变现。

不用露脸，不用直播，只需要上传一张照片生成一个视频，改变发布入口就可以变现，不要说你学不会这么简单的操作。

# 二：项目过程：

首先我们在抖音搜索，点击右上角【放大镜】搜索:小程序推广计划。

![](img/7c1e0ef755df343d5dfac7cfa6d6d5c1.png)

然后，点进去，就能看到幸福拍小程序。

![](img/5a64dd99f197394e80341848407c393e.png)

当我们点击进入这个界面，可以看到目前最高收益是35857.85元。

我们点击综合排序，选择收益最高的，可以看到这个收益最高的视频。

![](img/c38f752503a374a231b8463b5ad51ee1.png)

然后点击这个视频进入，点击左下角的蓝色链接，选择一个模板，点击加号，上传一张照片，然后直接点击立即制作，它就会自动为你生成一个视频。

![](img/2f7c47a54c89fba9c3e8af51237b53e6.png)

我们将视频保存到相册后，返回抖音主页，重复上述操作，再次返回界面，点击上传视频完成任务，然后点击相册。

![](img/964915667ada0926e2ad6dd75a27f08d.png)

导入保存的视频，然后单击“下一步”以查看该任务是否已添加。

![](img/e9f003c6f4f0902696fb19f16f33d48a.png)

最后，添加一个标题并点击发布。

# 三：结算方式

只要用户点击你视频左下方的蓝色链接制作视频，看完广告就会有收获。一次的单价大概是0.2到0.4元。1000次广告是400元。

![](img/8336519f025d4d1c86a8a74b375ddab9.png)

比如这个账号爆了一个视频，3月21日发布，至今赚了5位数，也就6-7天。

不要以为靠运气，有时候运气也是实力的一部分。成功其实很简单，简单的事情，重复做！

# 四、项目门槛

需要达到1000粉丝才能开通小程序推广计划或者挂载。
