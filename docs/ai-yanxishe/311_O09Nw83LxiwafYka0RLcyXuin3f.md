# 偏科太严重！ChatGPT考高三物理得零分！

> 来源：[https://aiyanxishe.feishu.cn/docx/VzxfdJ6eHozUOlx1kzxcNUhCnSi](https://aiyanxishe.feishu.cn/docx/VzxfdJ6eHozUOlx1kzxcNUhCnSi)

今日（6月1日），“ChatGPT高三考试仅物理得零分”冲上热搜。

新京报贝壳财经6月1日报道，近日，在搜狐号创作者大会上，在场嘉宾讨论了ChatGPT对知识直播领域的影响。

![](img/25d11c5f37613ce0c1fac5b3b879a3db.png)

图片来源：新京报贝壳财经视频截图

同济大学物理教授吴於人称：“**有人把高三的卷****子弄到上面去给他们做选择题，ChatGPT做下**来的时候，英语、历史、文字性的东西都考得非常好，成功率非常高，但是只有物理得零分。”

![](img/a33e2f5320aaf80bfd6bce267ec05836.png)

图片来源：新京报贝壳财经视频截图

张朝阳认为物理是要解决实际问题的，他表示：“机器和人还是有本质区别的，人脑的思考和认知过程和机器的算法是完全不一样的。既**要认识到AIGC的工具带来的方便性和影响，而且这种影**响放在十年的尺度上来说是巨大的，天翻地覆的；另外也不要过度的夸大它，我觉得人是很重要的，原创内容是很重要的。人的精神、思想和想法是非常重要的，这是机器取代不了的。变与不变，要综合地观察。”

![](img/d30bad75056c7662c3d661cc1afd8333.png)

图片来源：新京报贝壳财经视频截图

此外，财经网报**道****，在近日举办的****2023清华大学首**席财务官论坛暨CGMA100北亚管理会计领袖峰会上，清华大学中国经济思想与实践研究院院长李稻葵教授认为，宏观经济学与会计学存在方法论的一致性。从浅显的角度来讲，宏观经济学与会计学都是在分析和研究企业以及经济运行的信息。从更深层次的角度来讲，会计的本质是经济系统的“传感器”，给推动社会经济发展的决策者提供了科学决策的基础，从这一角度来讲，ChatGPT永远代替不了会计。

![](img/d5ac802a9e194ccf1976e9353ea80a51.png)

此前，关于AI取代人类的话题，李彦宏、罗翔也对此发表过观点。

据第一财经，“**我不担心****大模型**会让工作消失，我认为未来会有更多的工作产生。”5月18日，百度首席执行官李彦宏在2023天津世界智能大会上表示。

![](img/3f7f06c191bba1ec49b8d4a233f67f94.png)

图片来源：视觉中国VCG111380782709

他举例说，汽车取代马车，的确让马车夫的工作消失了。但是今天，汽车产业成为全球最大的工业体系之一，创造的就业岗位数以亿计。30年前，打字员的工作消失了，但网络工程师、游戏开发等工作却出现了。

据中国网财经，4月26日，中国政法大学刑事司法学院教授罗翔在华南师大附中公开讲座，提到当下很火的ChatGPT，罗翔说：“很多人都跟**我**说，你现在要开始学习ChatGPT，否则2年以后就会被淘汰。我当然也开始学习，但是我始终把它作为一个工具，因为ChatGPT永远无法告诉你当你老婆和你妈妈一起掉到河里，应该先救谁的问题。”

**他**还表示：“人跟人工智能最大的不同，在于人除了有理性还有感性，我们不是单纯地靠着理性去生活。我们永远不用担心它会取代我们，因为我们是人，是万物之灵。
