### 🗓️ 第一阶段：Week 1-2 项目基础建设 + 初步外联

#### ✅ 对内

+   **公司品牌建设：**

+   确立公司全称、愿景/使命/价值观（VIS）

+   设立临时官网/OnePager（Notion或简版落地页即可）

+   建立对外Pitch材料（中英文BP、投资者推介材料）

+   **内部分工和机制明确：**

+   明确“产品线负责人 + 商务负责人 + 融资负责人”三位一体角色

+   工时制度、周会机制、任务看板（Notion / 飞书OKR）上线

+   建立🛰️群/飞书内部沟通机制，做好文档同步

#### ✅ 对外

+   **融资准备启动：**

+   商业负责人对接Hashkey萧峰，获取投前建议

+   整理投资人清单（CSDN关系网 + Web3资源）

+   **政策资源对接：**

+   核心BD负责约见前海政府、申请创业扶持/税务政策优待

+   调研与AI+Web3或RWA相关的专项政策/科技计划

---

### 🗓️ 第二阶段：Week 3-4 产品原型上线 + 投资人闭门会

#### ✅ 对内

+   **产品原型推进：**

+   核心开发基于CEX技术完成交易产品前端Mock

+   （如可能，集成AI推荐或个性化匹配组件）

+   上线网页版V0.1：包括交易所界面 + 项目发行页（白名单预约）

+   **产品策略明确：**

+   Coderwa首批发型定位（如数字股权/版权/SAFT）

+   形成完整RWA流程SOP（从企业接入到Token化）

+   **视觉体系（VIS）：**

+   输出主Logo、统一品牌配色、字体、网站Banner（可通过Figma/Upwork快速外包）

#### ✅ 对外

+   **融资实质推进：**

+   举办小型线上闭门会（3-5家机构）进行项目试讲

+   商务负责人负责轮询式沟通，记录机构反馈

+   **合作方寻找：**

+   核心策划/BD寻找首批愿意进行RWA发型的合作企业

+   目标包括：科技园区企业、数字资产项目方、AI项目、教育科技公司等

---

### 🗓️ 第三阶段：Week 5-6 预上线 + 战略对接

#### ✅ 对内

+   **平台V1测试：**

+   增加发型流程、基础KYC模块

+   接入模拟钱包/充值/发型流程

+   **内容体系搭建：**

+   策划产出RWA + AI行业白皮书或行业洞察文章（用于对外话语权建立）

+   准备第一批产品教程、FAQ、宣传视频（短视频号/官网用）

#### ✅ 对外

+   **正式开始种子轮融资谈判：**

+   邀请对接的机构实地访问或面对面Pitch

+   若HashKey明确反馈，则优先推进

+   **首批发型合作签约：**

+   对接3-5家企业，完成发型意向书

+   尝试与政府一同宣布“Web3+企业资产数字化试点”计划

## 🧩 产品设计与定位

### 🎯 目标：

+   明确：Coderwa 是什么样的平台、服务谁、怎么使用

---

### 📌 产品设计五步法

#### Step 1️⃣ - 定义核心产品角色（Week 1）

> 建议产出：一页产品定位图 + 用户旅程图（User Journey Map）

---

#### Step 2️⃣ - 模块功能拆解（Week 2）

> 建议产出：产品PRD草图（可用Notion/Figma整理）

---

#### Step 3️⃣ - 竞品快速调研（Week 2）

> 建议产出：1页竞品对比表 + 产品功能差异化列表

---

#### Step 4️⃣ - 产品原型V0草图（Week 2）

+

+   构成：

+   首页（发型推荐/资讯/入口）

+   发型流程页（资料上传 -> 模板选取 -> 合约预览 -> 发型）

+   项目页（项目介绍、融资进度、评级等）

+   个人资产页（我的投资、KYC状态、提币等）

> 由产品/策划/开发联合确定页面结构，输出原型图（V0.1）

---

#### Step 5️⃣ - 用户验证与反馈（Week 3末）

+   面向前海政府、Hashkey投资人、小企业客户

+   邀请早期用户测试流程，重点验证：

+   哪些信息对企业来说是障碍？

+   Token化对他们是否足够透明？

+   钱包、资产操作是否清晰？
