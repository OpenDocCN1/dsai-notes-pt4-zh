#### 五、Code RWA 短视频团队（3 人）分工方案

#### 一、核心角色与职责

##### 1. 内容主理人（1 人）：聚焦 “选题落地 + 专业背书”

+   **核心任务**：

+   负责 20 个选题的脚本撰写（侧重知识科普类、案例拆解类、技术解析类），确保每篇脚本包含 “痛点引入 + 数据支撑 + 差异化亮点”（如《电磁枪公司 RWA 发行全记录》需嵌入 GitHub 数据、估值公式等硬核内容）。

+   担任出镜主播（优先负责个人号内容，如 “技术负责人王博士” 人设），把控口播节奏与专业术语的通俗化表达（如将 “PageRank 算法” 类比为 “代码界的学术引用排名”）。

+   对接内部资源（极客邦项目池、评估模型数据），确保案例拆解的真实性（如极客邦基金案例需核对项目代码开源率、LP 退出周期等细节）。

+   **输出物**：每日 1 篇脚本（300-500 字）、每周 3 次出镜拍摄、每月 2 次选题优化建议（基于运营反馈调整方向）。

##### 2. 剪辑专员（1 人）：聚焦 “视觉呈现 + 平台适配”

+   **核心任务**：

+   负责视频剪辑（含官方号 + 个人号），针对不同平台特性调整风格：抖音 / 视频号用 “快节奏 + 大字幕 + 动画贴纸”（如技术解析类用 MG 动画演示代码评估流程）；B 站用 “分屏对比 + 数据图表”（如《房产 RWA vs Code RWA》用表格可视化差异）。

+   把控视觉统一性：官方号固定 “科技蓝 + 代码流动画” 片头，个人号用 “办公室实景 + 手写板书” 转场，强化品牌记忆点。

+   优化视频钩子：前 3 秒设计 “痛点提问 + 悬念”（如《代码引用 1000 次 = 估值涨 20%？》开头用 “你的代码可能值 10 万，但你不知道” 引发好奇）。

+   **输出物**：每日完成 2 条视频剪辑（含封面、字幕、BGM），每周同步 3 个平台的格式适配版本（如抖音 16:9 竖屏、B 站 16:9 横屏）。

##### 3. 运营专员（1 人）：聚焦 “流量放大 + 转化落地”

+   **核心任务**：

+   负责多平台发布与排期：按 “知识科普类（周一 / 周四）、案例拆解类（周二 / 周五）、互动问答类（周日）” 的节奏分发，抖音侧重 “短平快”（30 秒内），B 站侧重 “深度解析”（5 分钟以上）。

+   社区互动与线索收集：在评论区用 “分层话术” 回复（官方号用 “专业术语 + 白皮书指引”，个人号用 “口语化解答 + 私信引导”），标记询问 “评估工具”“合作细节” 的高意向用户，每日同步给商务团队。

+   数据复盘与选题反哺：每周跟踪 20 个选题的播放量、完播率、互动关键词（如 “合规”“代码评估” 出现频次），输出《内容优化建议》（如发现技术解析类完播率低，建议增加动画占比）。

+   **输出物**：每日发布 3-4 条视频（覆盖抖音、视频号、B 站），每周 1 份数据周报，每月更新 1 次 “高意向用户画像”。

#### 二、协作流程（周循环）

1.  **周一同步会**：内容主理人同步本周 5 个选题的脚本方向（如周一确定 “技术解析类 2 篇 + 互动问答类 1 篇”），运营专员反馈上周用户高频问题（如 “代码刷分” 疑虑），剪辑专员提出视觉呈现建议（如用动态图表展示评估模型）。

1.  **日常协作**：

+   内容主理人每日 12 点前交付脚本→剪辑专员 24 小时内出初版视频→内容主理人 4 小时内反馈修改意见→剪辑专员 6 小时内定稿→运营专员按排期发布。

+   运营专员实时收集评论区问题，每晚 8 点同步给内容主理人，作为次日脚本的素材（如用户问 “开源代码如何评估”，优先安排《粉丝提问：我的代码开源了，能直接发 RWA 吗？》）。

1.  **周日复盘会**：三人共同分析数据（如知识科普类播放量高于行业趋势 30%，可加大产出），调整下周选题权重（如互动问答类互动率低，减少至每周 1 篇）。

#### 三、核心 KPI（量化目标）

+   内容主理人：脚本通过率 100%（无专业知识错误）、出镜视频完播率≥40%（高于平台平均 10%）。

+   剪辑专员：视频制作时效（从接脚本到定稿≤36 小时）、视觉风格统一率 100%（用户无 “账号混乱” 反馈）。

+   运营专员：单条视频平均互动率≥5%（评论 + 点赞 + 转发 / 播放量）、高意向用户周新增≥20 人。

#### 四、分工亮点

1.  **专业壁垒强化**：内容主理人聚焦 “专业度”（确保代码评估、合规逻辑无偏差），避免多人参与导致的信息失真。

1.  **用户反馈闭环**：运营专员直接衔接内容生产，让用户疑问快速转化为选题（如 “LP 退出难” 的高频提问，催生《代码拆分术》选题）。

1.  **轻量高效协作**：通过 “脚本 - 剪辑 - 发布” 的线性流程减少沟通成本，3 人即可支撑每周 15-20 条优质内容的稳定输出。
