# 网易CodeWave发布人工智能开发能力，全面升级企业智能研发新模式

> 来源：[https://aiyanxishe.feishu.cn/docx/YMbUdZToDoqz8pxf5JJcvaEUnae](https://aiyanxishe.feishu.cn/docx/YMbUdZToDoqz8pxf5JJcvaEUnae)

2025年10月14日，网易CodeWave举办“用AI重构研发方式”主题沟通会，正式对外发布多项智能开发能力，支持从需求梳理、产品构思、开发部署、迭代等全流程研发智能化。作为面向企业研发场景的开发平台，网易CodeWave采用可视化与AI融合的开发方式，支持每一步操作可由AI自动完成，同时保留人工布局与精细调整的空间，进而打造更可控、更规范、更落地的智能开发新模式。

![](img/40c147742665acb316c014fe095a0529.png)

### 多个核心AI能力全新发布，AI覆盖应用开发的全生命周期

网易CodeWave此次上线的AI开发能力包括：PSD设计稿生成页面、智能产品设计、智能生成应用、智能资产生成与接入等核心功能，贯穿从创意构思、需求定义、原型设计、应用开发到持续迭代的完整流程。不仅显著提升研发效率与体验，更打破技术壁垒，让产品、运营等非技术人员储备也能深度参与开发协作，真正实现标准化和谐模式。

![](img/2c28d6c893c7af5520794b5cef60c975.png)

产品设计场景下，只需要一个简单明确的需求描述，CodeWave智能产品设计助手就可以通过人机多轮对话交互的形式，实现从想法到落地，从模糊到澄清的产品设计全过程；甚至可以直接生成产品原型，完整包含菜单、列表、表单、按钮等元素，快速验证视觉与交互的可行性。

应用创建后，系统会自动将原型生成至CodeWave，包括对应的数据实体、数据结构、枚举、服务端逻辑、前端页面等，并支持在线发布预览和导出全栈源码；发布后的应用如果需要调整或补充模板，也可以通过[智能设计应用]进行二次智能调整——同样是通过自然语言描述需求。CodeWave AI 会保存对话上下文，从应用创建到发布，再到后续调优。

此外，网易CodeWave还具备智能代码生成、智能代码补全、智能代码解读、智能代码分析、智能SQL生成等辅助编程能力，全方位赋能企业与开发者，缩短开发链路，提高研发效能，让研发价值最大效率体现在业务场景中。

### AI在企业开发中不只图“快”，更图“可控”与“规范”

AI技术快速演进，然而，在企业研发场景下，大模型仍难以支撑完整的应用开发流程。这源于自然语言本身存在表达模糊、上下文缺失等问题，难以准确描述复杂系统的业务逻辑。特别是在ERP、CRM等企业级场景中，全自动智能体模式难以有效落地。此外，编程大模型虽然擅长处理通用问题，但对个性化的企业开发框架、架构设计和领域知识的掌握也比较有限。

网易数智副总经理、网易CodeWave总经理王桐在沟通会上说，与个人开发者开发不同，企业往往要求开发的应用是长期可使用、可修改的，这也就要求AI带来的效果不仅仅局限在“快”，而更要确保“可用、可控、可落地”。而作为面向企业开发场景的智能开发平台，网易CodeWave通过选择更成熟的规格驱动开发（Spec-Driven Development）方式达成这一点。

规格驱动开发，简单来说，就是在软件开发过程中，以明确、详细的规格说明作为整个开发流程的核心驱动力。这里的规格说明，涵盖了软件系统的功能需求、性能指标、接口定义、数据格式等各个方面，它就像是建筑施工中的蓝图，为开发者们清晰地描绘出软件最终要达成的样子。

举例来说，同样用AI做开发，网易CodeWave通过将混乱的需求文档标准化，之后进行详细的设计变成一份规范（specification），让开发团队可以在完善的设计基础上，在AI辅助下做好需求拆解和任务拆分，继而由不同的角色在开发过程中实现对应的内容，并在过程中把控质量。

![](img/75f11f49558598e0d7d8ba71f39ea6a7.png)

AI直接生成代码的方式仍需要专业开发者的补充、修改，也就是说，实际上没有降低企业中软件开发的门槛。网易CodeWave坚持“人机协同、可控可管”的理念，通过可视化开发的能力与AI生成能力深度融合，构建步进式协同开发模式：AI每生成一步，开发者均可在可视化界面中确认、干预或调整，确保开发过程透明、可追溯。

面向未来，网易CodeWave将以“全链路研发智能化”为核心方向，推动AI Coding从代码生成迈向覆盖产品全生命周期的系统级智能化。以“可控、可管、可落地”的AI能力，网易CodeWave为企业数字化转型提供坚实的技术底座，持续推动AI开发从概念走向实践，切实提升企业在数智化转型过程中的研发水平。
