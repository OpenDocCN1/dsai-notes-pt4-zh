## 百度飞桨

一水的是CC0。

CC0 使科学家、教育工作者、艺术家和其他受版权或数据库保护内容的创作者和所有者能够放弃对其作品的权益，从而尽可能完全地将其置于公共领域，以便其他人可以自由地为任何目的构建、增强和重新使用其作品，而不受版权或数据库法的限制。

它为创作者提供了一种在法律允许的最大范围内放弃其作品的所有版权和相关权利的方法。

## Starcoder Data

+ 数据量：783GB的代码，86种编程语言
+ 数据内容：Starcoder Data是一个以编程为中心的数据集，Salesforce CodeGen、Starcoder 和 StableCode 使用 Starcoder 数据进行训练
+ 下载地址：`https://huggingface.co/datasets/bigcode/starcoderdata`
+ 国内访问：`https://hf-mirror.com/datasets/bigcode/starcoderdata`

Big Code项目介绍：

`https://www.bigcode-project.org/docs/about/mission/`

Big Code是一个开放的科学合作组织，致力于开发大型语言模型。近日他们开源了一个名为 SantaCoder 的语言模型，该模型拥有 11 亿个参数，可以用于 Python、Java 和 JavaScript 这几种编程语言的代码生成和补全建议。

训练 SantaCoder 的基础是 The Stack（v1.1）数据集。

Stack v2.0 是根据 Software Heriage Archive 提供的公共 GitHub 代码构建的。它可能包括 GitHub 上不再存在但由 Software Heritage 存档的存储库。在训练 StarCoder 1 和 2 模型之前，运行额外的 PII 管道以从代码文件中删除姓名、电子邮件、密码和 API 密钥。欲了解更多信息，请参阅论文。
