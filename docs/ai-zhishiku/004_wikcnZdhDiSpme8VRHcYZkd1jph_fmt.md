## 5、什么是 API

API 是 Application Programming Interface（应用程序编程接口）的缩写，是指一组定义了软件组件之间相互通信的规范。API 允许不同的应用程序之间互相交互，使得软件开发人员能够使用已经编写好的代码来实现他们自己的应用程序。
