
# Midjourney 更新，搞怪风格【weird】指令让你的图片更加独特

> 来源：[https://my.feishu.cn/docx/ZerYd3aUboco9WxZ2ECc6Opsnrb](https://my.feishu.cn/docx/ZerYd3aUboco9WxZ2ECc6Opsnrb)

Midjourney 官方近日宣布，他们已对 Midjourney 进行了更新，增加更多新功能。

据官方介绍，这次一共有 3 个更新：

- `/turbo`模式，以～2 倍的价格创造～4 倍的速度
- 探索新风格的`--weird`参数
- `Mega`会员计划

今天我们着重介绍一下第二点参数：`--weird`

`--weird`指令，用户可以利用该功能生成更加诡异风格的图片。该功能提供 0-3000 的不同参数，数值越大，生成的图片就越诡异。
