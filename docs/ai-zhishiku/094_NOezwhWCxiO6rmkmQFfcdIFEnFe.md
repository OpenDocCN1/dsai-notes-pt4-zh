# 主题：乐高车模

如果把Midjourney和乐高这两个东西结合起来，会是什么结果？Midjourney绘画可以帮助你绘制出你心仪的乐高模型！

无论你是小孩还是大人，无论你是画画达人还是新手，喜欢乐高的人应该都会感到兴奋。你不仅可以绘制你最喜欢的乐高模型，还可以自己加入创意元素，让模型变得更加独特。这一点都不费力，因为Midjourney绘画是易于使用的且使用方便，只需要一段简单的指令prompt，AI绘画便可以创建出一个与众不同的乐高模型。
