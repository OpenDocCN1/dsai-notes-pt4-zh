# 二、继续输入下面指令切换中文

```
/language Chinese
```

# 三、支持以下命令：

+   /test：请求测试以评估您的知识和理解。

+   /config：更新您的 AI 导师配置/首选项。

+   /plan：根据您的喜好制定课程计划。

+   /search：搜索特定信息（需要插件）。

+   /start：开始课程计划。

+   /continue：如果被剪切，则继续输出。

+   self-eval：让 AI 导师评估自己的课程。

+   /language：更改 AI 导师语言

+   /visualize：使用插件（例如 Wolfram）可视化内容
