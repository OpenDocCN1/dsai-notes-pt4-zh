# 一、创建一个网站

您可以使用 Canva 创建基本网站。

1.创建设计 > 网站

2。选择任何模板并编辑

3。出版作为网站

4。使用免费或付费域

# 二、在照片中添加白色大纲

1.添加图像并删除背景

2。阴影>发光>控制

•透明度= 100

•Blur = 0

•颜色=白色

•大小=选择您想要的

# 三、魔术橡皮擦

用魔术橡皮擦在线清理图片。

删除不需要的物体或从照片中删除人员很容易。

刷牙分心，用魔术橡皮擦立即将它们删除。

# 四、Canva 演讲：

设计，现在，用帆布演示激发灵感。

通过电影视觉效果重新构想，吸引了您的观众，因为帆布演示对您的想法产生了影响。

# 五、魔术写 Canva 文档：

在 Canva Docs 中魔术写作是您自己的 AI 文本生成器，可帮助您快速获得初稿。

只需从提示开始，然后观看列表，生物标题，内容创意，头脑风暴等，以几秒钟的时间出现

# 六、更好的文字到图像：

文本要图像可让您在几秒钟内从简单描述中创建唯一的图像。

观察您的单词和短语转变为带有文本的图像，即 Canva 的 AI 图像生成器。

# 七、魔术设计

魔术设计将帮助您将图像变成完全可自定义的模板。

魔术设计会自动选择完美的伴随字体，图像，图形和样式，以将您的想象力转化为完美的设计。

# 八、绘制

用抽签绘制您的想法。

使用 Draw 和 Canva 的免费绘图工具释放您的创造力。

绘制使您可以在设计中添加自定义的图纸和图形，因此它们在人群中脱颖而出。
