## 【20250221】动态 | Google Veo 2携手Freepik全球首发，AI视频生成掀新高潮

Google与Freepik合作，率先在Freepik平台推出Veo 2——其最先进的AI视频生成模型，带来无与伦比的真实感、精确度和流畅动画。这一战略合作标志着Google将技术首发权交给合作伙伴，巩固Freepik在全球AI内容创作领域的领先地位。Veo 2现已独家上线，前1万名用户可获2次免费生成机会，引发创作者热烈反响。Veo 2在细节、物理模拟和指令遵循上远超其他模型，预计不久后将扩展至Google AI Studio，推动2025年AI视频生成技术的新突破。

## 【20250218】动态 | 马斯克推出的 Grok-3 人工智能模型，以其在数学和科学问答等领域的突破性成绩，引起了业界关注。

该模型由 20 万块 GPU 训练而成，不仅在多个基准测试中超越了 DeepSeek R1 等竞争对手，刷新了 SOTA 记录，还推出了能够展示思维过程的推理模型 Grok-3 Reasoning 和首个 AI 智能体「DeepSearch」，后者用于深入互联网搜索。Grok-3 的发布对 OpenAI 的 GPT-4.5 构成了挑战，AI 大佬 Karpathy 对其推理能力给予了高度评价。Grok-3 的功能将逐步上线，包括 API 和语音助手版，展望在 AI 领域发挥更大的影响力。
