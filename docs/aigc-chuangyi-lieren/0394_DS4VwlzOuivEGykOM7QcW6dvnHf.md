
# Gemini

> 来源：[https://aigcreative.feishu.cn/docx/VTn1dFO2voOoUbxbvyxcE2f8n8b](https://aigcreative.feishu.cn/docx/VTn1dFO2voOoUbxbvyxcE2f8n8b)

Google 的 Gemini 是一款由谷歌公司开发的多模态大型语言模型，它具有处理文本、图片、音频和视频等不同类型数据的能力。Gemini 模型分为三个不同的版本，分别是 Gemini Ultra、Gemini Pro 和 Gemini Nano，以适应不同的使用场景和设备要求。

## 使用场景

1. **Gemini Ultra**：作为最强大的版本，Gemini Ultra 在多任务语言理解（MMLU）基准测试中取得了超越人类专家的成绩，显示出其在处理复杂问题上的巨大潜力。它适合用于需要高度理解和推理能力的场景，如高级研究、复杂数据分析等。

2. **Gemini Pro**：这个版本是中等规模的模型，它能够击败 GPT-3.5，并可扩展多种任务。Gemini Pro 的一个主要应用是通过 Bard with Gemini Pro 形式提供服务，允许用户以文字指令的方式体验 Gemini 的能力，并计划在未来支持音频与图像交互。

3. **Gemini Nano**：针对移动设备和特定任务设计，Gemini Nano 已经开放给所有 Android 14 开发者，允许他们在手机系统中调用 Gemini 的能力，用于开发具有 AI 功能的应用。

## 用法

使用 Gemini 模型的基本步骤如下：

1. **访问官网**：用户可以通过访问 Google Gemini 的官网或者通过 Google Cloud 的 Vertex AI 来使用 Gemini Pro。

2. **登录账号**：用户需要使用 Google 账号登录，以便使用 Gemini 的服务。

3. **输入 Prompt**：在 `makersuite` 中，用户可以输入文本提示（Prompt），然后点击“run”按钮来获取结果。这些 Prompt 和结果都可以被保存起来。

4. **选择模型版本**：在 Gemini Pro 的界面中，用户可以选择不同的模型版本，例如 `Gemini Pro` 或 `Gemini Pro Version`，后者支持将图片作为 Prompt 输入。

5. **使用 API**：对于开发者来说，Google 提供了 Gemini 的 API，他们可以通过 API 来集成 Gemini 到自己的应用中。Google 还对 API 进行了优化，包括系统指令、JSON 模式以及函数调用优化，以便开发者可以更好地控制模型的响应和输出。

6. **多模态理解**：Gemini 1.5 Pro 版本特别强调了其多模态理解能力，用户可以上传视频或音频文件，Gemini 会根据内容进行深度总结和分析。例如，用户可以上传一部电影的预告片，并要求 Gemini 生成影评或者总结电影内容。

## 安全性和限制

在使用 Gemini 时，用户需要注意遵守相应的使用条款和限制，确保生成的内容符合法律法规和社会道德标准。此外，对于商业用途或大规模使用，用户可能需要考虑 Gemini 的收费模式和 API 调用限制。

综上所述，Google 的 Gemini 是一款功能强大的多模态 AI 模型，适用于多种使用场景，并且提供了灵活的使用方法和 API 接口，使得开发者和普通用户都能够根据自己的需求来利用其先进的 AI 能力。
