
# 20241214-OpenAI Day 7/12：发布Projects功能，按照项目来组织和管理文件

![](img/70c1a924d57390112bed7b4fe85f4070.png)

今天是OpenAI马拉松式发布会第7天，OpenAI最新发布了——ChatGPT项目管理“Projects”功能。

![](img/193bc267516c27229b84fb02cc81ac38.png)

这项功能的推出，解决了用户长时间以来的痛点：每次与ChatGPT对话时，需重复上传文件和数据，浪费时间。

![](img/e162a72d67a4feba57b1517f63afca90.png)

而现在，ChatGPT项目管理“Projects”让用户可以将所有相关资料、文件、聊天记录等集中到一个“项目”中，方便随时调取使用，大大提高了工作效率。

## 一、轻松管理多个任务

通过**项目管理**，用户可以将多个任务、文件和对话归类整理在一个项目内，避免重复操作。

![](img/f93b8ae4eb30069271c30b8d28b68adc.png)

比如，如果你在做一个活动的策划，只需上传相关资料，所有新的对话都能直接引用这些内容，提升了信息的整合和利用效率。

## 二、实际应用案例

![](img/f836ff11829665fc6c3db0c2647eece5.png)

OpenAI在发布会上展示了这个功能的应用。

例如，组织一个“秘密圣诞老人”活动时，用户可以将规则、预算和参与名单上传到项目中，ChatGPT就能帮助管理活动、发送邮件、处理参与者信息等，避免繁琐的手动操作。

## 三、更多个性化定制

项目管理还支持为每个项目设置**自定义指令**，比如在写作项目中，你可以指定写作风格，而在编程项目中则设置技术要求。这种灵活性使得ChatGPT可以更精准地满足不同用户的需求。

![](img/8b4c0fa288311d8bf76afea3c75e8137.png)

![](img/94c42f7b992b833400aac191131c25ad.png)

虽然功能已经上线，但由于是逐步推开，并不是每个用户都能立刻体验到。尚未解锁的用户需要耐心等待。

**ChatGPT项目管理**的推出，意味着ChatGPT不再只是一个简单的对话工具，它将成为用户高效管理工作、项目和任务的全能助手。

未来，随着更多功能的增加，ChatGPT将能提供更加个性化和智能化的服务，帮助用户提升工作效率。
