# 20251022-OpenAI的Atlas浏览器：它不只是想“浏览”，它是想“动手”

> 来源：[https://aigcreative.feishu.cn/docx/VuRZdwSQeoy3JUxA5XVc0qKsn6f](https://aigcreative.feishu.cn/docx/VuRZdwSQeoy3JUxA5XVc0qKsn6f)

大家好。

**刚刚，Op**enAI，推出了一个AI浏览器，叫 Atlas。

![](img/36245a49551a98c4eaa2915ecc48cded.png)

我估计很多人第一反应都跟我差不多：“怎么又是一个浏览器？”

毕竟，咱们电脑上Chrome、Safari、Edge这些已经很够用了，多一个浏览器好像没太大必要。但转念一想，这可是OpenAI。他们为什么要这么做呢？他们家的产品，总想在体验上做点不一样的东西。

先看看官方产品视频：

![](img/8f505701789d4fd95eeb142b998792f5.png)

[9a144e647eb51ab50877a38d804a1be2.mp4](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/UHTsbhiKIoCqagxp7UfcRwKYntk)

所以，我还是第一时间在我的Mac上装了它（目前只有macOS版，Windows和手机用户还得等等），没熬夜看直播，早上花了点时间用了用。

![](img/0de1abf1b752ee77f00ec8ca319be925.png)

现在，我来跟你们聊聊，这个Atlas，到底只是个噱头，还是真有什么新东西？

我的初步结论是：它的想法确实不小。它不只想当个工具，它可能想成为一个助手。

### 01.看起来差不多，用起来才发现不同

打开Atlas，第一眼看过去，界面很干净，是现在流行的简约风格。

![](img/24ac91c1d14d96940f1e8a4228b30d6c.png)

启动时，它也会很常规地问你要不要从Chrome导入书签、密码这些数据。（跟其他浏览器套路一样。）

![](img/87b0598673e9869345928d49cf4026d3.png)

![](img/30d7d7f9a84db12bbced04a6d42554b1.png)

![](img/9f476e377dfa8add12ae36246ab5bfe1.png)

![](img/29f2fbb46b2186a7adab70468599ceec.png)

它的新标签页，就有个小小的不同。它不是一个大大的搜索框，而是一个ChatGPT的聊天框。当然，你还是能用它来搜索，但它的意思很明显：“你可以直接问我。”

![](img/200e0b67f4c6961fcbad938f9ea811d5.png)

那就直接开问：

![](img/4aabfd999cba6d90bf6362ef0a201f4a.png)


![](img/ad3f4a34f2369b3941004d633c721733.png)


![](img/e378ba564b8a40f27f1893265d14b984.png)

![](img/b8b871e12886b4cc682c34a72ec939ed.png)

但真正让我感觉到它和普通浏览器不一样的地方，是它的侧边栏。

以前我们用ChatGPT，是怎么用的？

比如我看到一篇很长的文章，想让它帮我总结一下。我得先选中文字，复制，然后切换到ChatGPT的标签页，粘贴，然后再输入我的问题：“帮我总结一下”。

这个过程，其实有点打断思路。

在Atlas里，我在看那个长文章的页面上，直接点一下侧边栏的ChatGPT图标，它就“知道”我正在看这个页面。我直接在侧边栏问它：“这篇文章主要讲了什么？”

![](img/c2d8761196cbe4c86b7c6694d26e3894.png)

![](img/9c44ae4e07a2a298baa3ba1c120fc8de.png)

它很快就给我答案了。

这个体验，怎么说呢，就是很**流畅**。

它省掉了“复制粘贴”这个步骤，我不需要离开当前的页面。就像个集成在旁边的助手，我随时可以问它关于当前页面的问题。

我试着用它来对比两个不同电商网站上的产品参数，它也能直接抓取两个页面的信息，然后给我列个表。说实话，就凭这个“与页面对话”的体验，它已经比“Chrome浏览器 + ChatGPT插件”的组合要好用一些了。

### 02.真正想做的：它想替你“动手”

但如果Atlas只是做到了侧边栏聊天，那顶多算个体验优化，还谈不上有多大新意。

![](img/17e41bf7ca7883116041b30182fd9c93.png)

![](img/bc171eedc485ee013937c6339476393f.png)

它真正核心的功能，藏在一个叫“代理模式”（Agent Mode）的地方。

这个功能目前还是个预览版，得是Plus付费用户才能用。但就是这个还在测试中的功能，让我感觉到了它未来的方向。

简单说，以前的AI，是帮你出主意，告诉你该怎么做。而这个代理模式，是试着帮你“去办事”。

**你提出需求，它来操作。**

OpenAI的演示是，你给它一个菜谱，它自己去生鲜网站上，把所有食材加进购物车，然后下单送到你家。

这个听起来很厉害，我得自己试试。

![](img/d6642d3cc3aa933816b326a434f38995.png)

我没试那么复杂的，就试了个简单的。我跟它说：“帮我到京东上买一台小米17 Pro”

接下来的情况就有意思了。

![](img/7b88c0354ef70023bf716d391b530f19.png)

![](img/d2dfbda0ce415c63de4c29ad4936c6c3.png)

![](img/01c4fcf30b116be7cf6f35d73f07fb72.png)

好家伙，直接给我找到，加购物车了！

但你明白这种感觉吗？**这是一个很重要的方向**。

我**们用了这么多年的**浏览器，一直是个阅读器或者导航器，我们是操作者。而Atlas想做的，是一个执行器，我们是指挥官。它希望把我们从很多重复的点击、滚动、填表里解放出来。

如果这个**代理模式**未来真的成熟了……那我们以后上网的方式可能会发生很大的变化。

### 03.值得注意的地方：你敢让它“记住”一切吗？

好了，接下来说个重点，也是我比较在意的地方。

这个“代理模式”之所以能这么智能（理论上），是因为它背后还有一个功能，叫“浏览器记忆”（Browser Memories）。

![](img/6f6155a983d8abb25539b5b318128248.png)

这个功能，默认是关闭的，需要你自己去手动打开。

它是干嘛的呢？它不像传统的历史记录，只记一个网址。它会记住你浏览过的页面的“事实”和“上下文”。

举个例子。你上周看过一件衣服。这周你忘了在哪看的了。

你如果用Chrome，你只能在历史记录里搜关键词，然后在一堆链接里慢慢找。

但如果你开了Atlas的“浏览器记忆”，你可以直接问它：“我上周看的那件红色夹克是哪个牌子的？” 它就能直接告诉你答案。

听起来很方便，对吧？

**但是。**

我一看到这个功能，就想起了之前Windows的Recall功能。

这几乎等于是在给AI一本关于你自己的详细日记。把我们所有的浏览数据，不只是网址，还包括页面内容，都交给AI来“记忆”……

这背后，其实是一种信任的交换。

OpenAI当然也说，这些数据是受你控制的、你可以随时删除、你可以开隐身模式……所有我们能想到的隐私保护措施，它都提到了。

可问题是，我们愿意用多少隐私数据，去交换AI的智能和自动化呢？

关于这一点，我个人，目前还是有点保留意见的。

### 04.总结一下：所以，我到底换不换？

聊了这么多，回到最初的问题：我会不会把主力浏览器换成Atlas？

我的答案是：暂时还不会，但我会留着它，在需要AI帮忙的时候用它。

它现在给我的感觉，优点和缺点都非常明显。

它的AI能力，尤其是与页面对话和那个初级的代理模式，确实是目前所有浏览器里最强的。如果你是个重度AI用户，每天都要用ChatGPT处理很多事情，那这个浏览器给你的体验提升会很明显。

但作为一款日常用的主力浏览器，它在浏览器的基本功上，比如插件生态（虽然它基于Chromium，但生态兼容性还需要时间验证）、多设备同步的稳定性等等，跟Chrome这种成熟的产品比，还需要时间。

所以，我的建议是：

如果你是AI爱好者、喜欢尝试新东西：那值得去下载一个体验下。尤其是那个“代理模式”，可以去感受一下它想去的那个“未来”是什么样的。

**如果你是普通用户**：我建议可以先观望一下。等它的Windows、手机版都出了，等它的“代理”功能更成熟了，也等大家对那个“浏览器记忆”的隐私问题讨论得更明白了，再考虑是不是把它当成主力也不迟。

总的来说，Atlas不是来跟Chrome抢“谁更快”的。它是在尝试一个全新的方向。

它在问我们所有人：“你用了这么多年浏览器，是不是可以换个方式来上网了？”

这个新功能一出来，Google和微软，估计也得认真对待了。
