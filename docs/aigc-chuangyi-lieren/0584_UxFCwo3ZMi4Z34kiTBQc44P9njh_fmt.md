## 什么是AI绘画？

AI绘画，也称为人工智能绘画，是指利用人工智能技术进行绘画创作的一种新兴领域。它通过计算机程序和算法模拟人类绘画过程，实现自主创作和艺术表现。

AI绘画技术的核心是深度学习。深度学习模型可以从大量图像数据中学习和分析，从而掌握绘画的基本规律和技巧。基于此，AI绘画系统可以根据用户的输入，生成各种风格的图像作品。

AI绘画的应用场景非常广泛，包括：

+ 艺术创作：帮助艺术家创作新的艺术作品，探索新的艺术风格。

+ 设计：用于平面设计、工业设计、建筑设计等领域，提高设计效率和质量。

+ 娱乐：用于游戏开发、动画制作、虚拟现实等领域，创造更加逼真和沉浸式的体验。

+ 教育：用于美术教育、艺术史教育等领域，帮助学生学习绘画知识和技巧。

AI绘画技术的發展带来了以下优势：

+ 降低了绘画的门槛，让普通人也能轻松创作艺术作品。

+ 提高了绘画的效率，可以快速生成各种风格的图像。

+ 拓展了绘画的可能性，可以创造出人类无法想象的画面。

当然，AI绘画技术也存在一些挑战，例如：

+ 版权问题：AI绘画作品的版权归属尚不明确，存在侵犯版权的风险。

+ 伦理问题：AI绘画作品可能被用于虚假信息传播、恶意攻击等目的，存在伦理风险。

## 公式：如何写Prompt？

> 主题(加下面的)
> + 环境(背景，周围)
> + 气氛(烈日下，雾蒙蒙，恐怖的，风暴席卷的)
> + 灯光(顶光，霎气光，漫反射的，强对比的)
> + 色彩(低饱和度，颜色鲜艳的，花里胡哨的，强反射的主色调，某种颜色是是accent color)+ 构图(黄金分割，三分法的，电影镜头，广角，鸟瞰图)
> + 风格参考(超清细节的，照片级别的，写实的，抽象的，2D/3D，4k8k，数字雕刻，概念艺术，水墨水彩，海报，某个软件，某个游戏，艺术家，艺术平台)
