## 常用指令

Midjourney 使用指令来控制图像生成过程。指令可以分为以下几类：

### **基础指令**

+   /settings: 查看和修改 Midjourney 设置

+   /help: 显示帮助信息

+   /info: 显示当前版本信息

+   /about: 显示关于 Midjourney 的信息

+   /quit: 退出 Midjourney

### **生成图像指令**

+   /imagine: 生成图像

+   /prompt: 指定图像描述

+   /seed: 指定随机种子

+   /variations: 生成图像变体

+   /upscale: 提高图像分辨率

+   /style: 指定图像风格

+   /quality: 指定图像质量

+   /aspect: 指定图像宽高比

+   /mask: 使用遮罩生成图像

### **高级指令**

+   /blend: 混合两张图像

+   /inpaint: 修复图像

+   /edit: 编辑图像

+   /animate: 生成动画

+   /loop: 生成循环动画

+   /slerp: 生成图像插值

+   /checkpoint: 保存模型检查点

+   /restore: 恢复模型检查点

### **其他指令**

+   /join: 加入聊天室

+   /leave: 离开聊天室

+   /mute: 静音聊天室

+   /unmute: 取消静音聊天室

+   /clear: 清除聊天记录

### 以下是一些常用的 Midjourney 指令示例

+   /imagine a photorealistic portrait of a young woman with long brown hair and green eyes, wearing a red dress: 生成一张年轻女子半身肖像，长棕色头发，绿色眼睛，穿红色连衣裙

+   /prompt a landscape painting of a mountain range in the style of Bob Ross: 生成一幅山脉风景画，风格模仿 Bob Ross

+   /seed 12345: 使用随机种子 12345 生成图像

+   /variations 4: 生成 4 张图像变体

+   /upscale 2x: 将图像分辨率提高 2 倍

+   /style anime: 使用动漫风格生成图像
