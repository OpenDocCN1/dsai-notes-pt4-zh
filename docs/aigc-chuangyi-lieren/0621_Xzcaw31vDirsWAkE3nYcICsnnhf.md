今天给大家介绍 2 款 Midjourney 辅助插件。

以下是这两款插件：Trace Journey /InsightFace 以及使用方法。

Trace Journey 是一款 Midjourney 辅助工具，可以处理 Midjourney 生成的图片，一般用来转换矢量文件。InsightFace则是一款换脸插件。
