## 公司介绍

FLUX.1 是由黑森林实验室（Black Forest Labs）推出的一款开源 AI 图像生成模型，其创始团队曾是 Stable Diffusion 的创始团队。

![](img/18f1274de45f35bf8073ec93a4d80ab0.png)

该项目提供了多种版本以满足不同用户的需求，包括三种变体：

+ `FLUX.1 [pro]`：为专业用户提供最先进的性能，包括图像生成、提示遵循、视觉质量、图像细节和输出多样性。目前，Black Forest Labs 正在逐步增加其 API 中的推理计算能力。此外，该变体还可以通过合作伙伴 Replicate、fal.ai 和 mystic 获得，并为企业提供专用和定制化的解决方案。

+ `FLUX.1 [dev]`：为非商业应用提供的开放权重模型，从 `FLUX.1 [pro]` 直接提炼而来，具有类似的质量和提示遵循能力，但效率更高。该模型的权重可在 HuggingFace 获得，并可在 Replicate、fal.ai 和 mystic 上直接尝试。商业应用需要通过电子邮件联系。

+ `FLUX.1 [schnell]`：为本地开发和个人使用量身定制的最快模型，开源发布在 Apache2.0 许可证下。与 `FLUX.1 [dev]` 类似，其权重可在 Hugging Face 获得，推理代码在 GitHub 上。该模型也可在 Replicate、fal.ai 和 mystic 上使用。
