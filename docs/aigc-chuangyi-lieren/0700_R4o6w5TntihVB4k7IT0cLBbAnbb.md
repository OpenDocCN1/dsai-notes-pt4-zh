# 什么是 FLUX

FLUX 是由 Black Forest Lab**s 开发的新图像生成模型，****这些人是 Stable D**iffusion 背后的主脑()。FLUX 标志着 AI 生成艺术领域的重大进步。这款最先进的模型有三种不同的变体：FLUX.1 [pro]：FLUX.1 系列的巅峰，提供顶级的图像生成性能。FLUX.1 [dev]：一个开放权重、指导蒸馏模型，设计用于非商业用途。它提供与 FLUX.1 [pro] 类似的质量和提示遵循，但效率更高。FLUX.1 [schnell]：最快的模型变体，优化用于本地开发和个人使用，并在 Apache 2.0 许可下提供。FLUX.1 模型在提示遵循、视觉质量、图像细节和输出多样性方面表现出色。它们以卓越的精度处理文本，忠实地遵循复杂的场景组成指令，并比以前的模型更准确地生成手部图像。

#  什么使 FLUX.1 特别？

**

FLUX.**1 重新定义了 AI 生成艺术的可能性。以下是其**突出的特点**：文本准确性：FLUX 轻松处理复杂的单词和**重复的字母，**不像旧模型。这使它非常适合需要文本精度的设计。复杂组成：FLUX 擅长解释和执行**详细的**对**象放置和**场景组成指令，从复杂的提示中生成准确**的场景。逼真的手部：过去**，生成逼真的手部一直是 AI 艺术模型的挑战。FLUX 在这方面取得了显著进步，生成手指数量正确且位置准确的手部图像。虽然不完美，但比以前的模型有显著改进。效率：FLUX 的 dev 和 schnell 变体在尺寸和速度上更高效，同时提供与 pro 版本类似的质量，促进更快的迭代和实验。多样性：FLUX 可以生成广泛的艺术风格，从写实到绘画到插图，开辟新的艺术表达途径。以下是一些简单实测的图：
