2010虎年至今，已经推出16款Q萌的生肖鹅，成为鹅厂小伙伴特有的送礼佳品。

今年，借助AIGC技术，人人都可以成为设计大师，借此时机，我们将首次面向全社会征集：腾讯2026马年「生肖企鹅」的联名设计师。下一只生肖企鹅长什么样，你说了算！

不需要：

+   专业的3D建模技能

+   绘制复杂的图纸

+   花费大量时间渲染模型

只需要：

**带上天马行空的想象力，把**剩下的交给混元3D AI创作引擎：

+   **说句话：** “一只可爱的企鹅，戴着可爱的萌萌马头的帽子，穿着马甲”

+   **丢张图：** 把你手画的草图，或设计/生成的图片喂给混元。
