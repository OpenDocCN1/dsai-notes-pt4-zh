# GPT Search

> 来源：[https://aigcreative.feishu.cn/docx/SKuRdus2CoRimBxDQbhcKNJvnNc](https://aigcreative.feishu.cn/docx/SKuRdus2CoRimBxDQbhcKNJvnNc)

就在昨天（2024年6月），OpenAI公司宣布了一项可能彻底改变我们搜索习惯的新技术——SearchGPT。这不仅仅是一个简单的搜索引擎升级，而是一场搜索革命的开始。

![](img/d6fc070fccfaa465af5e0bb1bc4cb1d1.png)

SearchGPT是一个实验性的新功能，它将人工智能的强大能力与互联网上的信息相结合，旨在为用户提供快速、及时的答案，并且提供清晰、相关的来源。想象一下，你不再需要在多个网页间来回切换，只为找到一个靠谱的答案。SearchGPT能够直接、快速地回应你的问题，并且提供最新的网络信息。

这个原型目前只向一小部分用户和发布者开放，目的是为了收集反馈。虽然这个版本是临时的，但OpenAI计划将这些功能的最佳部分直接集成到未来的ChatGPT中。这意味着，我们所熟悉的聊天机器人将变得更加智能和高效。

SearchGPT的设计初衷是让你能够像与人交谈一样，提出后续问题，并且随着每次查询，共享的上下文也会不断增加。这种交互式的搜索体验，让信息的获取变得更加自然和直观。

OpenAI还特别强调了与发布者和创作者的合作。他们希望帮助用户发现发布者的网站和体验，同时为搜索带来更多的选择。SearchGPT在搜索结果中突出显示高质量的内容，并且通过对话界面提供多个用户参与的机会。

《大西洋月刊》的首席执行官Nicholas Thompson表示，AI搜索将成为人们浏览互联网的关键方式之一，而在这些早期阶段，技术的发展必须以尊重和保护新闻业和发布者的方式进行。这表明，SearchGPT不仅仅是一个技术产品，它还承载着对内容创作者和发布者的尊重。

此外，SearchGPT还提供了一种方式，让发布者可以管理他们在SearchGPT中的表现，这样发布者就有了更多的选择。重要的是，SearchGPT是关于搜索的，与训练OpenAI的生成式AI基础模型是分开的。即使网站选择退出生成式AI训练，它们也可以出现在搜索结果中。

![](img/a717847dcd8fb7044beaa517de7dad01.png)

OpenAI还计划在本地信息和商业等领域不断改进体验，并计划从用户和发布者那里获取对原型的反馈，将最佳体验带入ChatGPT。这表明，SearchGPT的发展是一个持续的过程，它将随着用户和发布者的反馈而不断进化。

SearchGPT的推出标志着搜索技术的一次重大飞跃。它不仅提高了搜索的效率和准确性，还为发布者和创作者提供了新的机遇。随着技术的不断进步，我们可以期待一个更加智能、更加个性化的搜索未来。
