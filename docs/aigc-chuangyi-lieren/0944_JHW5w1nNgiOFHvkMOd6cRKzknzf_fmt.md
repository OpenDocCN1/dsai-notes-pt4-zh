## 零、快速开始指南

![](img/e8ee18545ae39f90639d396c85a91d71.png)

### 第一步：注册与登录

- 访问官方网站：`notebooklm.google.com`
- 使用Google账号登录
- 首次登录时完成系统引导教程
- 选择免费版或升级到**NotebookLM Plus**（需Google One AI Premium订阅，约¥20/月）

### 第二步：创建第一个Notebook

1. 点击`新建Notebook`
1. 给项目起名字（如"AI学习资料库"）
1. 点击`添加来源`

### 第三步：添加学习资源

支持的来源类型包括：

- 📄 PDF文档
- 📊 Google Sheets（电子表格）
- 📝 Google Docs（文档）
- 🎥 YouTube视频
- 🎙️ 音频文件（MP3、WAV等）
- 🔗 网站链接（URL）
- 🖼️ Google Slides（演示文稿）
- 📸 图像文件（JPG、PNG等）
- 📋 Word文档（DOCX）

### 第四步：探索Notebook Guide

创建Notebook后，系统自动生成"Notebook Guide"仪表板，包括：

- 自动生成的内容摘要
- 针对性的思考问题
- 快速生成按钮（FAQ、学习指南、简报文档等）

## 一、核心功能完全解析

![](img/c4d7b70a6863d52abc2757b2a289ded4.png)

### 🎤 功能 1：Audio Overview（音频摘要）生成比较耗时，仅次于视频时长，预计10mins-15mins

![](img/54a29915f562cde67d3e86175277440c.png)

**是什么？** 将您上传的资源转换为生动的AI主播对话讨论

**特点：**

- 两位AI主播进行自然对话
- 自动总结关键点
- 在主题间建立关联
- 可下载并离线收听
- 适合通勤、运动时学习

**4种音频格式：**

1. Podcast对话 - 两位主播深度讨论（通常8-15分钟）
1. Brief简介 - 1-2分钟概览
1. Teacher讲师 - 教育式讲解
1. Friend朋友 - 轻松聊天风格

**使用场景：**

- 长论文阅读后的快速复习
- 生成学习播客分享给同学
- 制作公司培训音频内容

**使用场景：**

## 三、自定义设置与Notebook Guide

![](img/529adbc49d6c6525829060ff288a8c77.png)

### 如何使用Notebook Guide

1. 创建并上传资源到Notebook
1. 在左侧菜单点击`Notebook Guide`
1. 查看系统自动生成的内容摘要和问题
1. 选择要生成的内容类型

### 自定义对话风格（Custom Instructions）

#### 第一步：进入自定义设置

1. 在Notebook中打开聊天窗口
1. 找到`配置`或`设置`按钮
1. 选择`自定义`选项
1. 进入`Deep Dive Conversation`（深度对话）

#### 第二步：选择或创建风格

**系统预设风格：**

- 默认学习模式
- 研究型顾问
- 营销策略师
- 技术讲师
- 等等

**自定义方式：**

点击`自定义`，输入您的指令

### 常用自定义指令示例

**例子1：研究生级别的严格分析**

```
你是我的研究顾问。严格审视每个假设。提出尖锐的问题，识别逻辑谬误，强制我从根本上为我的工作辩护。
```

**例子2：营销策略师视角**

```
你是首席营销策略师。你的回应必须是立即可行的行动计划。要分析直接，专注于快速实现目标所需的具体策略和关键步骤。
```

**例子3：简化复杂概念**

```
像我是6岁的孩子一样解释这个概念。使用简单的词汇和日常类比。我喜欢骑自行车。
```

**例子4：教育者角色**

```
你是一位经验丰富的教师。在给出答案之前，问启发性问题。鼓励学生思考，而不是直接给出答案。
```

**例子5：限制响应长度**

```
所有回复必须在100个词以内。关注引导用户查阅资源。提供1-2句摘要，然后指定具体的段落或资源供进一步探索。
```

## 四、Deep Research 深度研究功能

![](img/478bba7bf3bc13d4ac311c0d22f2c612.png)

### 4.1 什么是Deep Research？（部分用户还无法看到，等待更新）

NotebookLM最新推出的功能（2025年11月），能自动搜索数百个网站并生成源文献支撑的研究报告。

### 4.2 Deep Research 的优势

- ✅ 自动创建研究计划
- ✅ 扫描数百个网站
- ✅ 优先选择可信来源
- ✅ 自动进行搜索优化
- ✅ 生成带源引用的报告
- ✅ 在后台运行，不中断您的工作
- ✅ 通常在数分钟内完成

### 4.3 两种研究模式对比

![](img/62c3baeca2168a70c7bf5f539f7bcc54.png)

### 4.4 如何使用Deep Research

#### 第一步：开启Deep Research

1. 打开一个Notebook
1. 在左侧`添加来源`面板中
1. 从下拉菜单选择`Web`

#### 第二步：选择研究类型

- 选择`Fast Research`（快速）或`Deep Research`（深度）

#### 第三步：输入研究查询

- 输入详细的研究问题或主题
- 可以指定搜索的特定领域或来源

#### 第四步：系统自动执行

- AI创建研究计划
- 浏览网站进行信息收集
- 不断优化搜索策略
- 生成组织化的报告

#### 第五步：导入结果

- 报告和来源直接导入您的Notebook
- 可继续添加其他资源
- 利用其他NotebookLM功能（音频、视频等）进一步分析

### 撰写有效的Deep Research查询

**好的查询示例：**

```
请深度研究2025年人工智能在教育领域的最新应用，特别关注个性化学习、虚拟助教和学生评估系统。
```

```
Deep Research查询：寻找关于远程工作对员工心理健康影响的最新科学研究，包括积极和消极两方面。
```

**避免：**

- 过于宽泛的主题（如AI）
- 不清楚的表述
- 混杂多个不相关的话题

## 六、最佳实践与高级技巧

![](img/fa1c36696cedb3ffbe85d15c78f981c1.png)

### ✅ 最佳实践清单

#### 资源选择最佳实践

+   优先使用原始文献和官方文档

+   避免混杂多个主题的资源

+   保持资源的时效性（特别是技术、新闻类）

+   对于学术研究，选择同行评审的论文

#### 提示词设计最佳实践

+   **明确指定角色/人设**：例如"作为一位数据科学家..."

+   **清晰定义输出格式**：指定使用表格、列表或段落

+   **设置限制**：指定字数、要点数量等

+   **举例说明**：给出期望输出的示例

+   **避免歧义**：使用具体词汇而非模糊描述

#### 工作流程最佳实践

+   先用`Mind Map`理解全局，再深入细节

+   `Audio Overview`用于快速复习，`Deep Dive Chat`用于精细理解

+   在创建`Quiz`之前先完成`Flashcards`学习

+   定期导出重要的笔记和报告作为备份

#### 协作最佳实践

+   为共享Notebook添加清晰的描述

+   使用标准化命名规范：[项目名]-[主题]-[版本号]

+   为他人创建`Public Notebook`时，选择`Chat only`共享模式

+   定期更新资源，保持信息最新

### 🚀 高级技巧

#### 技巧1：链式提示法（Prompt Chaining）

不依赖一个复杂提示，而是进行多个对话：

```
第一条：请分析这个资源中的三个关键观点。
[获取回复]
第二条：对于观点1，批判性评价其说服力。
[获取回复]
第三条：这三个观点中是否存在矛盾？如何调和？
```

#### 技巧2：迭代优化

+   第一次查询获取初始回复

+   基于反馈调整提示词

+   逐步完善，直到满足需求

#### 技巧3：多角度分析

```
使用自定义Instructions轮流切换视角：
- 批评者的角度
- 支持者的角度
- 实践者的角度
- 理论家的角度
对同一话题进行多轮分析
```

#### 技巧4：内容复用

+   用一份资源生成多种格式（音频+视频+文本）

+   将生成的闪卡导出创建自己的学习平台

+   将报告转化为博客文章、演讲稿等

#### 技巧5：质量控制

+   生成后一定要校对，特别是引用

+   使用`Deep Dive Chat`验证facts

+   对于重要的学术工作，交叉验证信息来源

## 七、常见问题解答（FAQ）

![](img/3ec3202d8bd587db7481bd93d29e51db.png)

### Q1：NotebookLM会用我的数据训练AI吗？

**A：** 不会。您的个人数据永不用于训练NotebookLM。Google承诺保护您的数据隐私。

### Q2：我能离线使用NotebookLM吗？

**A：** 不能。NotebookLM需要在线使用。但您可以下载生成的内容（音频、视频、文档）离线使用。

### Q3：`Audio Overview`能否选择特定风格？

**A：** 是的。有4种格式选择：`Podcast`、`Brief`、`Teacher`、`Friend`。Plus版本有更多自定义选项。

### Q4：能否限制AI只基于我的资源回答？

**A：** 是的。这是NotebookLM的默认设置——所有回答都仅基于您上传的资源，从不使用外部数据。

### Q5：生成的`Video Overview`能否编辑？

**A：** 目前不能编辑生成的视频，但您可以：

+   重新生成不同风格的版本

+   修改自定义指令后重新生成

+   导出后用视频编辑软件处理

### Q6：能否将Notebook分享给特定人员？

**A：** 可以。创建后选择"分享"，可设置为：

+   特定人员（需Google账号）

+   公开链接（任何人可访问）

+   Chat-only（只能提问，不能编辑）

### Q7：`Deep Research` 有哪些限制？

**A：**

+   在Plus版本中优先级更高

+   某些受限制的网站可能无法访问

+   结果质量取决于查询的清晰度

### Q8：如何删除Notebook？

**A：** 在Notebook菜单中找到"删除"选项。注意：删除不可撤销。

### Q9：能否设置Notebook密码保护？

**A：** 目前不支持密码保护。但您可以不分享链接来保持隐私。

### Q10：支持哪些语言？

**A：** 超过80种语言。您可以上传多种语言的资源，选择输出语言。
