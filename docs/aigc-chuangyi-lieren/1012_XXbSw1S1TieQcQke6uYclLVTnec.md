在追捧、观望和质疑等多个声音之下，人形机器人再次站上风口。

炒虾、叠衣服、煮咖啡、做家务、进工厂……人形机器人的每一个突破都代表着其正在实现从0到1，也预示着其正在从科幻逐步走进现实。

进入2024年，在人工智能全球热潮持续涌动之下，人形机器人关注度再次攀升。特别是春节期间Sora的横空出世，带动人形机器人“火”上加“火”。

高**工机器人注意到，2月26日早间，机器人概念股大幅高开高走，板块指数强势上涨4.**32%，板块内个股更是掀起一波涨停潮。中威电子、华研精机、迈赫股份、信邦智能、丰立智能、兰剑智能、天准科技等多家机器人相关企业出现20%涨停，克来机电、机器人、江苏北人等机器人相关企业涨超10%。

**紧接着在2月27日，人形机器人相关上市公司再次出圈。包括雷赛智能**、步科股份、汉宇集团、夏厦精密、北部湾港、怡合达、德昌股份、天奇股份、泰晶科技、鸣志电器等超10家上市公司新增了“人形机器人”概念。

究竟是谁点燃了人形机器人这把“火”？

# **AI赋能，科技巨头入场**

随着人工智能（AI）技术的飞速发展和机器人技术的持续进步，“AI+机器人”组合已成为推动各行各业发展的核心动力。

在此背景下，人形机器人作为AI原生应用的典范，尤其展示了人工智能与机器人技术融合的深度，及其模拟人类行为与互动的巨大潜能。这一结合赋予人形机器人执行复杂的物理任务，同时也使它们能够掌握高级认知功能，包括语言理解、情感识别以及学习和适应等。

换而言之，AI技术的持续进化将进一步提升人形机器人的智能化水平，它们将能更自主地与人类合作，更深层次地融入我们的日常生活与工作之中，充分展示AI原生应用的巨大潜力和价值。

**也正是**基于这一可期的前景，越来越多的科技巨头相继入局。在2月份，业内先是见证了OpenAI携其视频生成模型Sora引发行业轰动，紧接着谷歌推出了“下一代AI模型”-Gemini 1.5，该模型能够处理高达100万tokens的复杂上下文。同时，特斯拉也发布了Optimus最新视频，展示了其在行走和动作流畅度上的显著改进。

更加吸引行业关注的是，**2月25日，人工智能初创公司Figure AI宣布获得新一轮融资，总金额达6.7**5亿美元，投资方包括英伟达、微软、OpenAI以及亚马逊创始人贝索斯等科技巨头。

具体来看，英伟达和亚马逊旗下的一支基金各投入5000万美元，英特尔旗下风投机构将投资2500万美元，LG旗下公司LG Innotek投资850万美元，三星旗下投资机构将投入500万美元，贝索斯通过其名下的投资公司Explore Investments LLC承诺投资1亿美元。

特别值得关注的是，2月24日英伟达宣布成立“GEAR”部门，专注于通用具身智能体的研究，并将于3月18-21日举办的GTC 2024会议上发布加速计算、生成式AI以及机器人领域的最新成果。而早在2023年ITF世界大会上，英伟达创始人CEO黄仁勋就曾提到，下一波人工智能浪潮将是一种被称为具身AI的新型人工智能。

业界预测，如果英伟达发布的机器人领域成果超预**期，可能会给整个人形机器人板块带来催化。高工机器人产业研**究所（GGII）数据也显示，2030年全球人形机器人市场规模将达到150亿美元。

# **车厂引入，落地可期**

汽车行业一直处于技术的前沿，特别是在自动驾驶、传感器技术、机器视觉和人工智能等关键领域领先。这些前沿技术与人形机器人的研发有许多共通之处，既可以直接转化应用，也可以通过灵活调整，以适应新的应用场景。

此外，人形机器人能够与汽车行业产生协同效应，例如将机器人技术融入自动驾驶汽车中，实现更加智能化的人机交互和服务体验。在安全与可靠性方面，汽车行业的高标准也为人形机器人领域提供了参考和应用模板。

因**此**，汽车制造商的介入不仅能够把确保汽车安全方面的丰富经验和严格标准带入人形机器人的设计与开发，还有助于推进两个领域的技术融合与创新。高工机器人注意到，包括特斯拉、比亚迪、小米、小鹏、蔚来、华为等多个知名车企已开始探索人形机器人的研发和应用。

就特斯拉来说，其引领着人形机器人的创新浪潮，陆续推出“擎天柱”原型机以及第二代人形机器人产品Optimus Gen2。比亚迪则通过对智元机器人的投资，正式踏入人形机器人领域。小鹏汽车也在其汽车科技日上公布了自研的双足人形机器人PX5。而小米则在2020年就已开始探索人形机器人领域，并相继推出“全尺寸人形仿生机器人”CyberOne和“小米铁蛋2”。华为也不例外，与深圳乐聚机器人公司合作，推出首个基于鸿蒙系统的人形机器人“夸父”。

从某种程度上讲，特斯拉、比亚迪、华为等汽车制造业巨头加入，不仅能够发挥现有技术、资源及专业知识等优势，还将进一步推动人形机器人产业链快速放量。

**当**然，人形机器人走进汽车工厂正逐渐成为趋势。今年1月，人形机器人初创公司Figure宣布与汽车巨头宝马达成协议，正式将其人形机器人Figure 01引入宝马的汽车制造工厂。

**2月22日，优必选也在其官方🛰️视频号中展示旗下人形机器人Walker S最新视频，在视频中W**alker S于蔚来工厂参与了门锁质检、车灯盖板检测、安全带检测、贴车标等工作。

可以预见，未来还将会有更多的汽车制造厂商引入人形机器人，这不仅标志着人形机器人技术的成熟和实用性得到了工业界的认可，也预示着未来智能制造领域将迎来更深层次的人机协作和自动化创新。

# **政策加持，抢占市场制高点**

人形机器人代表着人工智能、机器人技术、传感器技术、计算机视觉等多个领域的集成和创新。而中国作为全球最大的制造国，有着强烈推动技术创新的意愿，以保持在全球科技竞争中的领先地位。

同时，人形机器人不仅是未来发展的趋势，更拥有广阔的潜在市场和技术外溢效应，有望成为继智能手机和新能源之后的下一波重大机遇。

在这样的背景之下，我国近年来陆续出台了一系**列**政策，以促进人形机器人领域的快速发展。据高工机器人不完全统计，仅2023年就有约10项国家和地方级的人形机器人相关政策出台，包括北京、上海、深圳、重庆等。值得一提的是，上海浦东新区的人形机器人制造业创新中心项目投资金额达10亿元。

**工信**部印发《人形机器人创新发展指导意见》也强调，将人形机器人产业视作继计算机、智能手机、新能源汽车后的颠覆性产品，充分肯定人形机器人的发展潜力和应用前景，到2025年初步建立人形机器人创新体系，2027年形成完整的产业链供应链体系。

进入**2**024年，国家层面的政策进一步为人形机器人发展注入动力。1月29日，工信部等7部门联合印发《关于推动未来产业创新发展的实施意见》，旨在打造标志性产品，做强未来高端装备。其中，还特别提到了突破人形机器人关键技术，如高转矩密度伺服电机、高动态运动规划与控制、仿生感知与认知、智能灵巧手、电子皮肤等。

2月19日，国务院国资委召开“AI赋能产业焕新”专题推进会上，也强调了中央企业在全局工作中应重视发展人工智能，深入推进产业焕新，加快布局和发展智能产业。

综合以上政策，人形机器人产业政策导向十分明确，预示着未来人形机器人将成为众多产业竞逐的新赛道。

# **技术破局，产业链蓄势待发**

在产业各界的努力下，通用人形机器人多项关键技术加速迭代，产业供应链体系正在逐步建立，人形机器人新产品也相继面世。

特别是在2023年，**超10家**企业推出创新的人形机器人产品，包括追觅科技的通用人形机器人，傅利叶智能的GR-1，智元机器人的远征A1，宇树科技的Unitree H1，达闼科技的XR4（七仙女），小鹏汽车的PX5，乐聚机器人的夸父（KUAVO），开普勒的先行者K1、先行者S1和先行者D1，中国电科21所的电科机器人1号，特斯拉的Optimus Gen-2等等。

从应用层面来看，这些人形机器人产品的问世进一步丰富了人形机器人的应用场景，涵盖工业制造、服务、教育科研、特种、工厂、医疗、家庭、仓储物流、安防巡逻等众多领域。

而随着AI多模态领域的快速迭代，人形机器人产业也将迎来更深层次的技术**赋**能，再加上主机厂产品的陆续发布，预示着机器人产业将向商业化落地迈出坚实的步伐。高工机器人的最新调研也显示，多家企业样机迭代已处于最后冲刺阶段及量产前夕，预计今年工业场景或将率先打响落地第一枪。

若将2023年视为人形机器人产业的开端之年，那么2024年无疑将成为人形机器人加速发展的关键年，届时人形机器人领域的核心零部件厂商也将迎来新一轮放量。

**对于人形机器人来说，传感器、减速器、无框力矩电机、空心杯**电机、丝杠等是不可或缺的核心零部件环节，目前在各个环节也已形成一批优秀的企业在加码布局。

**在传感器环节，**奥比中光、舜宇光学等正在重点布局视觉传感器，坤维科技、鑫精诚、蓝点触控等正在重点布局六维力传感器，而汉威科技、申昊科技等则在重点布局柔性触觉传感器。

**在减速器环节，**中大力德等厂商已在人形机器人领域展开布局。据中大力德方面透露，公司持续关注人形机器人发展空间和机遇，正在与相关客户积极对接。

**在电机环节，**伟创电气、雷赛智能、步科股份均已成功研发出用于人形机器人的无框力矩电机，还有杭州三相、常州运控、三瑞智能、大族电机、易尔泰、禾川科技等多家厂商也都已有突出的表现。

在开发无框力矩电机产品的同时，伟创电气和雷赛智能还成功研发出用于人形机器人的空心杯电机。当然，还有鼎智科技、鸣志电器、江苏雷利、昊志机电、五颗星马达、唯川科技、双环全新、万至达电机等一大批厂商也在空心杯电机部分重点发力。

**在丝杠环节，**新剑传动、恒立液压、秦川机床、贝斯特、五洲新春、鼎智科技等厂商也都已有产品可用于人形机器人。据了解，鼎智科技的滑动丝杆、行星滚柱丝杆均可用于人形机器人；新剑传动的滚柱丝杠已实现先批量化生产，目前已于部分人形机器人本体建立合作，产品已经送样。

**在总成环节，**三花智控、银轮股份、拓普集团、新兴装备等企业也已将人形机器人作为重点聚焦方向。三花智控在今年1月宣布，拟投资50亿元用于建设机器人零部件等项目。近日，其直投基金三花资本也跟投了坤维科技的A2轮融资，而这笔资金也将会用在人形机器人等领域的高端传感器产品线布局。

拓普集团在今年1月也宣布，拟投资50亿元人民币，在宁波经济技术开发区建设机器人核心部件生产基地。在此之前，拓普集团还规划了年产百万台人形机器人执行器项目，目前其研发的人形机器人执行器已多次向客户送样，项目进展顺利。

# **人形机器人产业化落地在何时？**

尽管人形机器人市场火热，但究竟何时才能实现产业化落地，目前尚不明确。

对于人形机器人产业化落地，业界观点多样，有专家预测2024年有望成为人形机器人量产元年。而工信部则相对保守的预估，到2025年人形机器人将实现量产。更有一些声音认为，人形机器人实现量产还需要3年，甚至5年。

在2023年高工机器人年会暨十周年庆典上，多位机器人**产业链企业高层也表明了自己的看法和预**测。天机董事长陈曦表示，“我个人的看法是非常乐观的，三年之内应该是可以实现的。”

**配天机器人总经理索利洋则认为，“现在人形机器人普遍存在着可靠性问题。尽管大家都在努力，但是人形机器人的**可靠性仍然需要进一步的提升。”格创东智新能源事业群总经理李楠博士也认为，“短期内，人形机器人在工厂制造环节很难落地。”

**国讯**芯微CTO蒋琛也判断，人形机器人要真正落地还为时过早，希望人形机器人在半年后将成本控制到30万，五年后实现特斯拉提出的目标，将成本控制到2万美金以内，届时各家核心零部件企业会找到最优的组合方案。

**在梅卡曼德创始人、CEO邵天兰看来，人形机器人最终还**是在服务业更有前景，而不是面向制造业的。在制造业里，大家关注的是产品，人形机器人可能只是“打酱油”初步展示一下。而服务业本质上是服务于人，人才能服务于人。

借助AI技术的推动，高工机器人产业研究所(GGII)判断，乐观情况下，2025年中国人形机器人有望迎来产业化落地元年，预计2026年中国人形机器人市场规模将达到30亿元，2030年有望突破380亿元。
