# 02

说到语音输入法这个赛道，目前真正值得关注的玩家，只有三个：豆包、🛰️输入法、Typeless。

**🛰️输入法**推出有一段时间了，核心优势是嵌在🛰️生态里，使用场景天然存在，体验做得相当不错。我深度用了一段时间，它的语音输入功能在日常对话场景里表现很稳，中英混合识别也不错。而且它是腾讯做的，用户信任度高。在🛰️里聊天的时候用它，体验非常顺滑。

**Typeless**是一个被很多用户低估的产品。它的语音输入体验在独立工具里算是做得相当用心的，界面干净，没有广告，交互逻辑清晰，在技术爱好者群体里有不错的口碑。我认识好几个做独立开发的朋友，办公环境里就装的是Typeless，日常写文档、回消息都在用。而且它是收费的，你敢信，一个输入法每个月几十块钱？相信很多人都不会掏这个钱的。

![](img/8f2b301477662d4ac6b3004d2d284cea.png)

但豆包这一次，做到了更进一步。

🛰️输入法的语音输入，本质上还是传统语音识别技术加一个交互界面，底层能力有天花板，遇到复杂语境、专有名词、快速的连读，还是会出错。

Typeless的体验不错，但它没有流式输出，你说一句话，得等它处理完才能看到结果，中间的等待感是明显的，而且响应速度也比豆包慢半拍。

豆包不一样。

它的底层是豆包大模型，模型能力直接决定了语音识别的上限。

![](img/d09fba0ebee3e337f960b38141fe100c.png)

你说话的速度再快，它跟得上；你夹杂术语，它能理解；你说一半停下来思考，它不会自作主张帮你补全；你改了主意想说别的，它能实时修正。

而且它的流式输出几乎没有延迟，你说完的瞬间，文字就已经在屏幕上了。

这就是模型能力差距带来的体验差距。

不是一个功能点上的优化，是整个底层的升维。

# 03

我研究了一下豆包语音输入法Mac版的具体能力，有几个点值得专门说。

![](img/adccfe74d0420ec2cebeacb2b3efc739.png)

第一个是**跨应用使用**。

豆包语音输入法是一个独立的App，安装之后在系统层面接管你的键盘输入。你在Word里能用，在🛰️里能用，在飞书里能用，在浏览器里也能用。不需要打开任何特定软件，不需要切换到某个特定界面，直接说话就行。

第二个是**中英混合识别**。

这一点我用下来非常满意。跟朋友聊技术话题，里面会夹杂英文术语，它能准确识别哪些是中文哪些是英文，而且不会把英文单词按中文拼音去识别。这个能力看似简单，实际上对模型的要求非常高。

第三个是**标点符号的智能处理**。

以前的语音输入法，你得专门说"逗号"、"句号"、"感叹号"，它才知道怎么断句。豆包不需要，你正常说话的语气、停顿、情绪，它自己判断该用什么标点符号。我中间有几段说得比较激动的段落，它自动给我加了感叹号，而且加得还挺准确的。

# 04

说了这么多产品层面的事，最让我感慨的是这件事背后的意义。

语音输入法这个赛道，近一年涌入了大量的创业者和独立开发者。

有做浏览器插件的，有做独立App的，有在各种效率工具里集成语音输入功能的，还有把语音输入做成硬件卖到几百块的。

Typeless就是其中一个代表。它不是大厂做的，是一个小型团队花了很多心思做出来的产品，在技术圈里有相当不错的口碑。

但豆包一出来，这类产品面临的压力是巨大的。

![](img/e0bf282577c440010bcf6d7a2122ed07.png)

这个市场的逻辑原本是：巨头看不上这块市场，觉得太小，资源投入不值得。所以创业者和独立开发者能活，有空间。

但现在豆包入场了，而且上来就是免费、高质量、Mac版直接给。

豆包一个产品的资源投入，可能等于这个行业所有创业者加起来的总和。

它免费了，别人怎么收费？

它模型能力更强，别人的准确率怎么追？

它流式输出体验更好，别人的延迟怎么降？

这是降维打击。

豆包语音输入法Mac版一出来，我们这些Mac用户多了一个几乎完美的免费工具。以前你要么忍受系统自带输入法的识别质量，要么花点钱买讯飞或者Typeless的会员，现在不需要了。你什么都不用装，什么钱都不用花，说话就行。

而且豆包能持续迭代。随着豆包大模型能力的提升，语音输入法的能力也会同步提升。你现在用到的这些能力，可能只是起点，不是终点。

![](img/a3ee53b29e483d3e86d3df736a3d5ac3.png)

唯一的问题是：Windows版本什么时候出？

所以如果你用的是Windows电脑，可能还需要再等一等。

不过以豆包这个迭代速度，不会太久。

# 06

最后说说我对这件事的一个判断，也是这篇文章我最想说的那句话。

语音输入这个赛道，目前形成了**三强格局**：豆包、🛰️、Typeless。

豆包背后是字节跳动的大模型能力，🛰️输入法背后是腾讯的生态优势，Typeless背后是独立开发者的产品信仰。三者都在这个赛道上投入了大量心血。

![](img/5bbd8e2131cdb56522fd1aa9d20d9853.png)

但这场仗的结局，可能从一开始就是注定的。

不是因为资源多少，不是因为团队大小，而是因为AI时代的竞争，本质上是模型能力的竞争。谁能持续提升模型能力，谁就能持续提升产品体验。大厂有数据、有算力、有人才、有资金持续迭代模型。独立开发者做的产品，模型能力天花板是看得见的。

Typeless做得再好，它的语音识别引擎依赖的是第三方接口，它自己无法改变底层的模型能力。🛰️输入法做得再好，它本质上还是一个交互层面的优化，不是底层模型的突破。

豆包不一样，它是字节自研的大模型，模型能力是自己的，可以持续迭代，可以快速优化，可以不断突破天花板。

这意味着，三强格局只是一个暂时的状态。最终，这个赛道的格局会向头部集中，模型能力最强的产品会拿走最大的市场份额。

这不是 Typeless的悲剧，这是整个独立AI产品时代的缩影。

以后，靠产品体验和用户体验打天下的独立开发者，会越来越难。

大厂的模型能力一旦追上来，产品层面的那点优势根本不够看。 Typeless今天面临的困境，以后会有越来越多的独立AI产品面临同样的问题。

![](img/a5e297ddd58ab9c8feffdcf90e136b4c.png)

但我依然觉得，这是最好的时代，也是最卷的时代。

豆包在前方持续迭代，🛰️输入法在身后紧紧追赶，Typeless这样的独立产品也在用自己的方式寻找生存空间。

三者互相竞争、互相推动，语音输入的体验只会越来越好。

最终受益的，还是我们这些用户。
