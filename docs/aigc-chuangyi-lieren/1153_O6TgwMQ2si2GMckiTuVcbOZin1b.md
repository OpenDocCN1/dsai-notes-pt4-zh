# 20240324-卷起来了！Kimi Chat引领，国内AI巨头纷纷跟进长文本大战

> 来源：[https://aigcreative.feishu.cn/docx/PZEDdjMLloJiqhxXY8acDzHrnQb](https://aigcreative.feishu.cn/docx/PZEDdjMLloJiqhxXY8acDzHrnQb)

> 链接：https://mp.weixin.qq.com/s/M3m3HI4ipzme0LzMKyZpug

每一次创新都可能引发一场行业风暴。

最近，一款名为Kimi Chat的人工智能聊天工具因其出色的长文本处理能力而迅速走红，不仅在用户中掀起了一股热潮，更是激起了国内科技巨头们的激烈竞争。

![](img/28f7728029e562276e274a3d674958e8.png)

Kimi Chat，这款由月之暗面科技有限公司开发的AI聊天工具，自去年10月首次亮相以来，就以其能够处理高达20万汉字的长文本输入而备受关注。

![](img/ca1559f5ee0ebd7695c20b14d5dfbd85.png)

它的主力卖点——长文本处理能力，使得用户可以轻松阅读《三体》、《马斯克传》等大部头作品，甚至与书中角色进行互动。Kimi Chat的免费使用策略，更是让它迅速积累了大量的粉丝。

本周，Kimi Chat进行了重大迭代，将长上下文窗口扩大了10倍，达到了惊人的200万字。这一更新让Kimi Chat的能力远超市场上的其他同类产品，如Claude3、GPT-4 Turbo等。用户们可以在短时间内迅速成为任何新领域的初级专家，这种体验让Kimi Chat的热度飙升。

![](img/5b418895c35c70ab135e989138edd4d1.png)

然而，随着用户数量的激增，Kimi Chat的服务也开始面临挑战。本周四下午，Kimi Chat的小程序、App和网页版突然出现无法正常使用的情况。官方解释称，由于系统流量持续异常增高，远超预期的资源规划，他们已经进行了5次扩容，但依然难以承受用户的热情。

![](img/0d8b09f36fe10eda7556791285450d90.png)

Kimi Chat的爆火不仅在用户中引起了轰动，更是引起了国内科技巨头的注意。百度、360和阿里巴巴等公司纷纷宣布将升级自己的长文本处理能力，以应对这一新兴市场的需求。

**1、百度文心一言宣布将在下个月版**本升级，开放200万到500万字的长度。

**2、360智脑正在内测500万字的处理能**力，并计划将其集成到360AI浏览器中。

3、阿里通义千问则直接推出了1000万字的处理能力，并且立即可用。

这场由Kimi Chat引发的长文本大战，不仅仅是技术上的竞争，更是一场关于用户体验和商业模式的较量。Kimi Chat的免费策略虽然赢得了用户的喜爱，但也给公司带来了巨大的运营压力。如何在提供免费服务的同时，保持公司的健康发展，这是Kimi Chat以及所有参与这场竞争的公司都需要面对的问题。

![](img/7bc0aa516a703787cdf5951a9067d754.png)

Kimi Chat的爆火甚至影响到了股市。一些与Kimi Chat相关的概念股出现了涨停现象，投资机构也开始关注AI应用板块，特别是涉及长文本处理的场景应用。这一切迹象都表明，大模型领域即将迎来更加激烈的竞争和更大规模的投资。

在这个大模型应用落地的元年，厂商们不再只是展示技术实力，而是开始更加关注产品的商业化落地和用户体验。Kimi Chat的成功，或许将引领国内大模型市场的思路从基础能力演变转向对产品本身、客户需求细节的理解。

![](img/a205684f121b5104ad037acc6130eb39.png)

随着这场长文本大战的持续升温，我们有理由相信，未来的人工智能将更加贴近人们的生活，为用户带来更加丰富和便捷的体验。而这场竞争，无疑将推动整个行业向前发展，让我们拭目以待。
