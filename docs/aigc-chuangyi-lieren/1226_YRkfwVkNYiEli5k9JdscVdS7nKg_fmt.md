
# 20240530-一场科技革命：普华永道如何通过生成式AI颠覆商业模式

生成式AI的竞技场还在扩大，各路玩家疯狂拥入，这股力量正成为改变世界商业模式的核心力量。

普华永道（PwC）作为全球领先的咨询公司，正积极利用这项技术，推动企业在效率和利润方面实现前所未有的突破。今天我们将深入探讨普华永道如何通过AI颠覆已有的商业模式，看看这场科技革命将会带来什么样的深远影响。

## 巨额投资背后的期待

普华永道在AI领域的投资力度可谓惊人。仅在美国，公司就投入了10亿美元用于AI和生成式AI（GenAI）的发展。这一巨额投资并非心血来潮，而是基于对未来的精准预判和对AI技术的坚定信心。

普华永道的最新全球CEO调查显示，68%的CEO认为GenAI将在今年提升员工效率，44%的CEO预计这将带来利润增长。

这些数据不仅反映了市场对AI的高期望，更显示出普华永道在引领这一潮流中的坚定步伐。普华永道自身已经在运营中体验到了AI带来的显著效益，并且帮助客户实现了类似的成功。

## 从AI工厂到全员AI技能提升

普华永道的AI成功不仅仅依赖于技术的先进性，更得益于其全方位的生态系统策略。公司在AI工厂中不断研发新解决方案，与AWS、Anthropic、Google、Meta、Microsoft和OpenAI等主要AI技术供应商建立了紧密的联盟关系。同时，普华永道还与Adobe、Google、Microsoft、Oracle、Salesforce、SAP和Workday等企业应用供应商合作，将GenAI功能集成到他们的产品中。

更为重要的是，普华永道将AI技术应用于自身产品和服务中，并通过广泛的AI技能提升计划My AI，让全公司75000名员工都能掌握并运用这些新技术。据统计，95%的员工自愿参与了My AI项目，总计投入超过360000小时学习AI相关技能。这不仅提升了员工的个人能力，也为公司的整体创新能力打下了坚实基础。

## 各部门的效率提升

AI技术在普华永道的各个部门中都带来了显著的效率提升。例如，在IT部门，生成式AI使得软件开发过程的生产力提高了20%到50%。通过定制工具，开发团队可以更快速地综合数据、编写和审查代码、生成文档，并进行细致的故障排除。这些改进不仅节省了大量时间，还显著提高了开发质量。

在财务部门，AI工具帮助大大加快了数据分析、文件总结和生成的速度。一个典型的例子是，AI工具能够在几秒钟内创建新合同的初稿，并从现有合同中提取关键信息。这样的效率提升，使得财务团队能够专注于更高价值的工作，如战略规划和风险管理。

在市场营销领域，生成式AI模型不仅帮助生成了高质量的营销内容，还通过自动化文档处理、风险审查和数据分析，提高了整体工作效率。营销团队借助AI技术，能够更快地生产内容，并根据数据进行更精准的市场定位和客户沟通。

## 案例：从销售到客服的全面变革

普华永道在帮助客户实现AI转型方面也取得了显著成就。例如，在一家大型金融机构中，生成式AI使得建议书生成速度和效率提高了15%到20%，而一家快餐连锁店的平均订单价值则增长了10%到15%。

![](img/5fa193241cd90ba79ac8f00e368ecfae.png)

在客户服务领域，AI技术同样展现了强大的威力。对于零售、游戏、酒店和家具公司，AI使得呼叫中心的处理时间减少了25%，放弃率降低了67%，错误路由的电话减少了70%。这些改进不仅提高了客户满意度，也显著降低了运营成本。

在治理、风险和合规（GRC）领域，AI技术帮助全球一家食品和饮料公司提升了日志审查员的生产力，并减少了误报。另一家大型美容和个人护理公司则通过AI改善了协作效率，增加了索赔节省。

## 五大指南：引领未来的变革

普华永道不仅自己成功应用了AI技术，还总结出五大指南，帮助其他企业在AI浪潮中获得成功：

1. 选择快速实现价值和规模的用例

最有影响的AI用例应具备两个特点：能够快速提供价值，并能迅速在组织内扩展。普华永道通过“深度检索”模式，训练AI在文档或数据中搜索特定信息。这种模式一旦成功应用，可以迅速扩展到其他领域，如合同、税务法规、财务报告等，实现指数级的价值创造。

2. 同时推进GenAI和数据

在使用类似的GenAI基础模型时，数据的质量和独特性将成为企业的竞争优势。通过分阶段推进数据现代化，企业可以在每个阶段解锁新价值，并赢得利益相关者的支持。GenAI还能利用以前难以组织的数据，降低成本并缩短实现价值的路径。

3. 提升技能并重新定义工作方式

使用GenAI技术不需要大量招募新的AI专家，而是通过提升现有员工的技能，实现高价值、风险管理的输出。普华永道的My AI计划就是一个成功的例子。重新思考工作方式，利用AI助理完成简单工作，让员工专注于更高价值的任务，将极大提升整体创新能力。

4. 通过负责任的AI加速AI项目

负责任的AI不仅不会拖慢AI项目的进程，反而会加速其发展。普华永道的负责任AI工具包涵盖了战略、治理、控制、网络安全等方面，旨在减少AI模型中的偏见，提高可靠性，实现合规性，保护数据和隐私。

5. 用开放架构未来证明AI

在AI技术快速发展的今天，成功的AI项目应具备开放架构，以便随时适应新的技术创新。普华永道的生产心态和平台无关的开放架构方法，确保了他们能够不断利用AI生态系统中的最新成果。

## 结语

普华永道的AI变革展示了生成式AI在商业应用中的巨大潜力。从巨额投资到全员技能提升，从各部门的效率提升到客户案例的成功，普华永道通过AI技术实现了真正的变革。这不仅为其他企业提供了宝贵的经验，也为我们揭示了未来商业模式的发展方向。

在这场科技革命中，掌握AI技术并善加利用的企业，必将在竞争中脱颖而出。
