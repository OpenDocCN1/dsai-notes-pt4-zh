# 20241029-“史上最强AI巨兽！全球最大液冷超算Colossus诞生，只用122天建成！”

谁能想到，全球最大、最强的AI液冷超级计算机Colossus已经完成部署。

这座由美超微和伊隆·马斯克的xAI公司合作打造的超级巨兽，不仅代表了尖端科技的突破，更引领了AI计算领域的新高度。

Colossus的核心装备是10万张NVIDIA H100 GPU——这个庞大规模几乎是过去所有AI超级计算机的总和，并且还在扩充中，预计将增加5万张H100和5万张H200 GPU，总数将超过15万张。

这不仅是规模的升级，更是对人类工程能力的巨大挑战和验证。

#### 10万颗GPU的液冷巨兽，仅用122天建成

Colossus的诞生速度让人惊叹不已——这座集成了10万颗GPU的AI运算集群，仅用了122天便完成了搭建。这种高效建造能力并非仅仅依靠人力，而是得益于工程团队精密的计划和执行能力。每个运算机柜内包含8个液冷机架，每个机架内装有8组NVIDIA HGX H100平台，总计一个机柜便配备了64个GPU和16个CPU。如此高密度的配置，使得这座设施的整体算力达到前所未有的高度。

#### 静音液冷：AI超级计算机的“静谧革命”

面对大规模运算带来的高温问题，Colossus引入了最先进的液冷系统。这种液冷设计不仅高效地控制了温度，还大大降低了运行噪音。每个机柜背后的热交换器系统也功不可没，它通过持续循环冷却液，确保了系统在极端运算条件下也能稳定运行。而这样的液冷系统，不仅是为了让机器“冷静”工作，也极大提升了能源使用的效率，减少了传统风冷系统所带来的高能耗。

#### 网络速度是家用网络的400倍：800GB每秒的“光速”传输

在网络架构方面，Colossus展现了远超普通家用网络的性能。虽然它采用了常见的乙太网基础，但其速度却比家用网络快了400倍之多。每台服务器配备了NVIDIA Bluefield 3超级网卡和NVIDIA Spectrum X交换器，能够实现高达800GB每秒的网络传输速度。如此极速的网络支持，是大规模AI计算的关键因素，特别是在多节点并行运算中，速度决定了一切。这种设计不仅满足了超算的需求，还为未来更大规模的AI运算预留了足够的扩展空间。

#### 弃用传统存储：网存架构迎接AI数据洪流

AI训练对存储空间的需求堪称“黑洞级”，为此，Colossus放弃了传统的本地存储，转而采用网络存储架构。这种创新设计允许所有GPU和CPU服务器可以快速访问庞大的数据集，不仅提升了系统的存储效率，还增强了整体的灵活性。这种布局也表明，Colossus不仅是为了短期的AI项目而建，而是对未来海量数据的提前准备。

#### Tesla Megapack确保供电稳定：解决毫秒级波动难题

为了应对大规模AI训练时瞬时激增的电力需求，Colossus采用了Tesla Megapack电池组。这种设计不仅能解决传统供电系统的瓶颈，还能够应对训练启动时的毫秒级供电波动问题，确保了整个系统的稳定性。AI运算对电力的需求比想象中复杂，尤其是数万个GPU同时启动时，瞬时电流波动可能影响整体运行，而Tesla Megapack无疑为这一难题提供了答案。

#### Colossus的意义：不只是“快”，更是AI技术的未来

Colossus的出现不仅仅是全球AI计算领域的重大里程碑，更是整个科技行业的一次革命性突破。从建造速度、液冷系统、网络架构到供电设计，Colossus都在挑战AI超算的极限，展现了人类在技术与工程上的非凡实力。

它的诞生，也让人们开始重新审视AI超级计算机的未来。Colossus不单单是为了服务于某个单一AI项目，它更像是人类探索未知边界的起点。未来，随着AI在更多领域的应用与普及，这样的超级计算机或许将不再稀有，但Colossus所树立的行业标杆将长久存在，激励着无数科技创新者去打破更多的极限。
