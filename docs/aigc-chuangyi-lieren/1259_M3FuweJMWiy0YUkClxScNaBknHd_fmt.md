## 01.

飞书为什么要把自己一个这么核心、这么受欢迎的功能，开放给所有人，甚至包括竞争对手的用户去用呢？

首先得看看现在办公软件的市场是个什么情况。

目前，钉钉和企业🛰️已经占了绝大部分市场，很多公司从上到下都已经习惯了在这些平台上沟通和处理工作。

这种用户习惯一旦养成，就很难改变。

对于飞书来说，虽然产品做得不错，用户体验也很好，但想让一个已经全面使用钉钉的公司下决心换掉整个平台，这个成本太高了。

不光是钱的问题，更是全员工作习惯迁移的问题，很折腾人。

![](img/467b85c4546592fbdecf06193e21b30e.png)

所以，想靠整个“全家桶”去跟对手正面竞争，难度很大。

那路不好走，就换个思路。

飞书的这个新策略，其实就是换了个打法：与其想方设法说服整个公司换平台，不如先让你免费试试我手里最好用的这一个工具。

这个工具，就是多维表格。

![](img/079ba32eb9bf680db61016a54f7f83c0.png)

可能有人觉得，不就是个表格吗？能有多大吸引力？

如果你用过的话就会发现，飞书这个多维表格，跟我们平时用的Excel不太一样。

![](img/ac18237d923f99c01a372e0bc362c625.png)

它除了灵活的视图、可视化的看板和自动化流程外，最核心的区别，在于它被设计成了一个AI原生的工具。

AI不再是一个悬浮在旁边需要你单独对话的机器人，而是像水和电一样，深度融入到了表格的每一个单元格和工作流里。

![](img/13d15e69144ecbd2a75078934038194d.png)

我给你举几个多维表格及注入AI能力后，工作场景会发生什么变化的例子。

### 栗子1：知识信息梳理，多维表格不二之选

首先就是咱们【创意猎人】的飞书AI知识库（浏览器直达：www.aigcreative.cc），就是基于飞书建立起来的。

知识库里有大量的利用多维表格及其AI的能力来梳理呈现的内容。

不敢相信，没有便利、强大的多维表格，这些内容的梳理，要搞到何年何月，效率提升不止百倍。

![](img/1b87501c2ce323c5b31965f5626ce47a.png)

### 栗子2：对于市场运营来说，AI成了内容创作的“副驾驶”。

以前我们做内容规划，定下选题后，从想标题到写大纲再到配图文案，每一步都得亲力亲为。

现在在多维表格里，流程可以变得非常“丝滑”。

你可以建一个“内容创作台”，里面有几列，分别是“选题”、“关键词”、“目标人群”。

当你填好这几列后，可以新增一个“AI智能”列，让AI来帮你干活。比如：

![](img/977fe6fa3be2a5b6fab22b7de65da3ca.png)

+   **批量生成标题：** 让AI根据你的选题和关键词，自动生成5个吸引人的标题供你选择。

+   **快速生成大纲：** 选定一个标题后，再让AI根据标题，生成一份结构清晰的文章大纲。

+   **撰写社媒文案：** 甚至可以直接让AI根据文章核心内容，生成一段适合在🧣或📕发布的推广文案。

这样一来，AI帮你完成了60%的重复性创意工作，运营同学就能把更多精力放在核心的策略和内容深度上。

### 栗子3：对于产品经理来说，AI变成“数据分析师”。

一个产品每天都会从应用商店、用户群、客服等渠道收到大量的用户反馈，这些信息混杂在一起，又多又乱，手动整理费时费力。

现在，你可以把所有反馈都汇总到一张多维表格里。然后，AI就能大显身手了：

![](img/8c0b5a27563ae24bf9ba4e5be5a14c79.png)

+   **自动打标签：** 新增一条用户反馈后，AI可以自动阅读内容，并给它打上标签，比如“Bug提交”、“功能建议”、“UI吐槽”等等，实现自动分类。

+   **情感分析：** AI还能分析每条反馈的语气，判断用户的情绪是“积极”、“消极”还是“中性”。

+   **总结摘要：** 如果一条反馈特别长，AI可以自动提取核心要点，生成一段摘要。

有了AI的预处理，过去可能需要一个团队花半天才能整理完的用户反馈，现在几分钟就能自动归类分析完毕，让团队能更快地响应用户需求。

你看，通过这些例子，AI变成了HR的助手、运营的搭档、产品经理的分析师。

它把过去很多复杂、耗时的工作，都变得简单和自动化了。

## 02

过去，这种好东西是被“锁”在飞书整个套件里的。

你想用，就得接受它的所有，包括IM、文档、日历等等。这对很多已经深度使用钉钉和企微的企业来说，是一个几乎不可能接受的“搬家”成本。

![](img/34a032c722296f76f5645503d2bfd47d.png)

现在，飞书把这个锁给解了。

它等于是在对所有潜在用户说：你不需要改变你现有的沟通习惯，不用放弃钉钉的打卡和审批。

你可以继续留在你原来的“房子”里，但我们允许你把你最核心、最需要效率的那间“书房”，升级成我们飞书的。

这就是所谓的“Best-of-Breed”（最佳单品）策略。

它抓住了现代企业一个很实际的需求：我不想再被迫接受一个什么都有、但很多功能都只是“及格水平”的“全家桶”了。

我希望每一个环节，都能用上那个领域里最好用的工具。

飞书的这一步，就是顺应，甚至是在推动这个趋势。

## 03

想明白这一点，再来看飞书的策略，就清楚多了。

它把这个功能强大、又能解决实际问题的工具独立出来，免费让你用。

当你的团队用它解决了招聘、内容管理、项目协作等核心问题，并且用得很顺手之后，这个工具就成了你工作流中不可或缺的一部分。

![](img/72ec35bb5c86edac9f622abf53bb4c3b.png)

这背后其实是一个非常经典的增长战略，我们可以称之为“产品驱动增长”（Product-Led Growth）。

传统的企业软件打法，是靠销售团队去一家家攻克决策者，签合同，然后自上而下地推广。这个过程漫长且昂贵。

而飞书现在走的，是一条更贴近互联网产品的路。

它不直接卖整个“解决方案”，而是把一个体验足够惊艳的单点工具，免费给你用。

它赌的是，只要你用了，你就会被它的产品力所折服。

这个工具，就成了它最好的“销售员”。

当一个团队，甚至只是一个部门里的几个人，开始自发地用飞书多维表格解决实际问题后，他们会把越来越多的核心工作流和业务数据沉淀在这个工具里。这就形成了一种“数据引力”。

数据是有重量的。

![](img/af256b99eefcca5d502fb6369422cc89.png)

当一个公司的项目管理、客户信息、产品路线图这些核心数据，都开始围绕飞书多维表格运转时，它自然就会像一个引力中心，开始吸引其他应用向它靠拢。

到那个阶段，公司管理层可能就会发现一个新问题：我们最重要的业务数据和流程，已经跑在飞书的系统上了。那么，为了让数据流转更顺畅、员工协作体验更好，我们是不是应该把沟通和文档工具，也换成飞书呢？

你看，这个逻辑就从“我要不要换平台”变成了“我如何才能更好地利用我已经深度依赖的工具”。

通过这种方式，飞书就把一个高高在上的平台迁移决策，分解成了一个自下而上的、几乎无法逆转的演变过程。

## 04

战争，正在从“入口之争”转向“数据之争”。

所以，钉钉和企微面临一个两难的境地。

如果他们选择封锁，就会显得封闭，违背开放平台的趋势，还可能惹恼那些真正有需求的用户。

但如果他们选择开放，就等于允许一个极具竞争力的对手，在自己的腹地里建立“根据地”，争夺最核心的用户数据和业务场景。

这无论怎么选，都很难受。

![](img/8597883bf5348e19cec359cb8a48e054.png)

目前看来，最可能的走向，就是像钉钉那样，加速迭代自己的同类产品，并以免费策略应战，一场围绕“新一代表格”的军备竞赛已经不可避免。

对我们普通用户和企业来说，巨头们的战争，短期内总会带来红利。

我们有了更好的选择，能以更低的成本，用上更专业的工具。

但同时，也要多一分思考：当我们的核心业务流开始依赖一个跨平台的集成工具时，数据安全、供应商风险、以及未来可能的平台变动，都是需要提前考量的。

飞书的这一步棋，看似只是一个产品的开放，实则是对整个协同办公市场底层逻辑的一次冲击。

它押注的是“卓越产品力”本身，而不是平台捆绑。

这场好戏，才刚刚开始。
