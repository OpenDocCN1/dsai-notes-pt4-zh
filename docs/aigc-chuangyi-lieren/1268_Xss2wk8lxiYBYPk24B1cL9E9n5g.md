
# 20251019-电商噩梦！用AI P图发霉枸杞骗仅退款：我们离全民造假还有多远？

> 来源：[https://aigcreative.feishu.cn/docx/WLPjdLCQpocomAxIUjRccglhnvd](https://aigcreative.feishu.cn/docx/WLPjdLCQpocomAxIUjRccglhnvd)

今天在网上看到个事，说实话，看得我心里挺不是滋味的。

有个网友分享了自己的经历。他买了枸杞，然后想退款，但估计是没什么正当理由。

他就用了现在的AI工具“豆包”，发了张枸杞的照片，给AI下指令说：“把这个P成发霉的样子”。

![](img/0a8593f6c060cdcb1e845abe17214c44.png)

![](img/cbbd95624a3e2311d8b043014b390e12.png)

豆包也很实在，它分不清你这个指令背后的目的是什么，就老老实实地执行了。

很快，一罐看着还不错的枸杞，就被AI处理成了一罐长满绿毛、看起来已经变质的发霉枸杞，效果还挺逼真。

然后，这位网友就拿着这张AI生成的“证据”，去找平台申请了“仅退款”。

结果，还真就成功了。

![](img/6f9091ce388b532bba7d58708f0597ea.png)

这事儿发出来之后，讨论的人很多。有人觉得他聪明，会用新技术，也有很多人觉得这事儿做得不对。

我个人是觉得，这事儿真让人笑不出来。

## 01.AI只是工具，它不懂“对错”

我们得先分清一件事。在这整个过程里，AI有错吗？

其实没有。

无论是豆包还是别的什么AI，它就是一个工具，一个执行者。

你给它指令，它就去完成。你让它P出发霉的样子，它就调动数据，去模拟发霉的质感和颜色。它不会，也没法去想你拿这张图要干什么。

AI没有道德观，它只认算法和数据。

但使用它的人是有的。

以前，你想P一张图去骗人，多少还有点技术门槛，你得会用P图软件，得花点时间。

现在呢？门槛几乎降到了零，动动嘴、打行字就行了。

当这个网友让AI造假时，他心里是清楚自己在做什么的。

这个行为，不管他自己觉得是“恶作剧”还是“小聪明”，结果就是让一个商家白白蒙受了损失。

再往深了说，如果这种行为被大家模仿，觉得这是个“薅羊毛”的好办法，那平台和消费者之间好不容易建立起来的“仅退款”这类信任机制，不就慢慢被破坏了吗？以后真正遇到问题的消费者，想要维权是不是会变得更难？

## 02.技术的边界，是使用者的底线

我一直觉得，AI这个东西，它本身没有好坏之分，只是它的能力很强。

![](img/24958978b7415c68c961645e359480d0.png)

技术越强大，其实就越考验使用它的人。

AI能帮我们做很多好事。比如，它可以帮我们修复模糊不清的老照片，让家人的记忆更清晰；它也能被拿来做坏事，比如伪造声音和视频去进行诈骗。

它能帮你写代码、写文案，提高工作效率；它也能被用来批量制造假新闻，混淆视听。

这次的“发霉枸杞”事件，就是一个很典型的技术滥用。

所以说，技术的边界到底在哪？

其实不在算法本身，不在技术有多先进，而在于用它的人，心里有没有那条底线。

## 03.善用AI，是每个人都需要有的素养

我们可以预见，未来，AI肯定会像我们现在用手机和网络一样普及。每个人都能很方便地使用它来处理各种事情。

![](img/6beec7f0e01cbe5bcfce647a3db22b95.png)

到那个时候，“会不会用”已经不重要了，更重要的是“怎么用”。

“善用AI”，可能会成为我们每个人都需要有的一种素养。

这不只是说要遵守法律法规，更多的是一种发自内心的自我约束。这关乎道德，也关乎我们整个社会的信任基础。

你想想，当你选择用AI去造假、去欺骗的那一刻，可能暂时占了一点小便宜，但实际上，你是在破坏整个社会最宝贵的东西——诚信。

## 04.最后，我想说：

AI不懂善恶，但人是懂的。

![](img/a23b044c1c97aa527639c70b3ebca286.png)

真正的聪明，不是研究怎么用AI去占便宜、钻空子，而是踏踏实实地用它来提高效率、改善我们的生活。

我们希望看到的进步，也不是靠这种小聪明，而是大家能一起去维护一个更诚信、更可靠的环境。

还是那句话：

AI可以替你思考，但它不能替你做人。

工具就在你手里，是用来建设还是用来破坏，这个选择权，一直在我们自己手里。
