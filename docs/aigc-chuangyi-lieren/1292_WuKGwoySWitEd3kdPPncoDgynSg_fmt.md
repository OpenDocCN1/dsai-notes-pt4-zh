
# 20240424-Photoshop革新：AI的魔法，让创意变得触手可及

> 来源：[https://aigcreative.feishu.cn/docx/Dcz7d6xknoyfE9xOvvlcYbn1nkc](https://aigcreative.feishu.cn/docx/Dcz7d6xknoyfE9xOvvlcYbn1nkc)

在数字创意领域，Adobe Photoshop一直是行业的领头羊。

今天，Adobe在MAX London创意大会上，为我们带来了全新Photoshop beta版本，它不仅提升了创意工作的效率，更将AI技术与创意设计紧密结合，为设计师们带来了前所未有的创作体验。

首先，让我们来聊聊这个新版本的最大亮点——Generative Fill功能。

这个功能通过引入“参考图像”，让设计师能够以前所未有的方式激发灵感，实现他们心中的创意构想。简单来说，就是Photoshop现在可以根据你提供的一个参考图片，帮你生成与之风格相似的图像内容，大大提升了创作的灵活性和自由度。

而另一个引人注目的新特性，就是“生成图像”功能。这可是Photoshop首次实现直接在软件内将文本转换为图像的能力。想象一下，你只需输入一段描述，Photoshop就能自动为你生成一张与之匹配的图像。这不仅大大缩短了从构思到成品的时间，也让那些不擅长绘图的创意人士，能够轻松地将脑中的想法转化为视觉作品。

除此之外，Photoshop的新版本还带来了一系列令人兴奋的工具，比如“调整画笔”、“改进的字体浏览器”和“调整预设”。这些工具的加入，无疑会让设计师的工作流程更加顺畅，同时也让Photoshop变得更加易于上手。

在AI创新方面，Adobe展示了其深厚的技术积累。新版本的Photoshop背后，是Adobe Firefly Image 3 Foundation Model的强大支持。这个模型不仅提升了图像生成的质量和真实感，还确保了生成内容的版权合规性。Adobe通过训练模型使用合法授权的内容，如Adobe Stock，确保了生成的内容可以安全地用于商业用途，而不会侵犯版权或其他知识产权。

更值得一提的是，Adobe在AI创新的同时，也展现了其对社会责任的承诺。Photoshop中的Firefly功能会自动为生成的内容附加“内容凭证”，这就像是数字内容的“营养标签”，提供了关于内容的详细信息，包括AI是否参与了创作或编辑过程。这一举措不仅增加了内容的透明度，也是对消费者知情权的尊重。

Adobe的这一更新，无疑将创意工作推向了一个新的高度。它不仅为专业设计师提供了更强大的工具，也降低了创意工作的门槛，让每个人都能够轻松地实现自己的创意愿景。这不仅是技术上的一次飞跃，更是对创意自由的一次深刻诠释。

在MAX London的活动中，Adobe还展示了如何将Firefly与Creative Cloud、Express和Experience Cloud结合，为世界级的活动体验提供动力。这表明Adobe正在将AI技术融入到其整个产品生态中，为用户带来更加丰富和连贯的创意体验。

总的来说，Adobe Photoshop的这次更新，是对创意工作方式的一次重大革新。它不仅提升了设计师的工作效率，更重要的是，它让创意变得更加触手可及。无论是专业设计师，还是刚刚入门的新手，都能在这个新版本中找到属于自己的一片天地。

随着数字创意领域的不断发展，我们可以预见，AI技术将在其中扮演越来越重要的角色。Adobe的这次更新，无疑为整个行业树立了一个标杆。未来，我们有理由期待，更多的创新和突破将不断涌现，让创意工作变得更加多元和精彩。
