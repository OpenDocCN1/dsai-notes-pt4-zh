在科技飞速发展的今天，人工智能（AI）已经成为各行各业的得力助手。然而，如何最大限度地利用AI，提高工作和生活的效率、简化任务流程，是每一个使用AI的人需要关注的焦点。

而与AI交互的关键，是如何写好提示词？写好了提示词，才能让AI输出你想要的结果。

今天，我们来揭秘9个提示词框架，它们不仅能帮助你更好地指挥AI，还能在日常工作中大显身手，效率直接翻倍！

#### 1. E.R.A：设定期望，分配角色，明确行动

+   **Expectation**: 说明你期望的结果是什么。你需要明确地告诉AI你希望它帮你实现什么目标。例如，你希望改善饮食习惯、提高工作效率或是完成一项复杂的任务。

+   **Role**: 指定AI需要扮演的角色，以这个身份来回答你的问题。这个角色可以是专家、顾问、朋友等，以便AI更好地理解你的需求并给出更合适的建议。

+   **Action**: 明确告诉AI它需要做什么。详细描述你希望AI执行的具体任务和步骤，这样可以确保AI按你期望的方式行动。

**示例:**

+   **Expectation:** 我希望改善我的饮食习惯，达到健康生活的目标。

+   **Role:** 你是一位专业的营养师，能提供权威的饮食建议。

+   **Action:** 请你根据健康饮食的原则，为我制定一个月的营养食谱，确保每天的饮食均衡且丰富，并且每周的食物搭配不重复。

这个框架简单而高效，特别适用于那些需要明确结果的任务。通过设定期望、分配角色和明确行动，你可以确保AI在执行任务时有清晰的指导。

#### 2. A.P.E：行动目的，目标明确

+   **Action**: 指派具体任务给AI。明确地告诉AI你希望它完成什么具体的任务，例如编写一份报告、设计一个计划或提供某种建议。

+   **Purpose**: 解释执行该任务的目的。让AI理解为什么要完成这个任务，这样可以帮助它更好地把握任务的方向和重点。

+   **Expectation**: 明确期望的结果。详细描述你希望最终得到的结果是什么，例如一份详细的报告、一个可行的计划或是一组有效的建议。

**示例:**

+   **Action:** 设计一个详细的饮食计划，确保营养均衡。

+   **Purpose:** 通过这个饮食计划，改善我的整体健康状况，帮助我培养健康的饮食习惯。

+   **Expectation:** 我希望得到一份详细的食谱，包括每日的三餐和零食建议，并确保营养素的摄入充足且多样化。

这个框架适用于需要在执行任务前明确动机和目的的情况。它帮助你和AI对齐目标，确保最终结果符合预期。

#### 3. T.A.G：任务行动，目标清晰

+   **Task**: 清晰地描述你希望AI完成的任务。用简洁明确的语言说明你希望AI做什么，例如撰写一篇文章、设计一个计划或分析一组数据。

+   **Action**: 详细描述完成该任务的步骤。列出具体的行动步骤或流程，让AI明白需要做什么，以及如何一步步完成任务。

+   **Goal**: 解释最终目标。告诉AI你希望最终实现什么样的结果，这样可以确保它在执行任务时有明确的方向。

**示例:**

+   **Task:** 生成一个月的营养食谱。

+   **Action:**

1.  设计每日的饮食结构，包括三餐和健康零食。

1.  选择各种健康食材，确保每日营养均衡。

1.  提供简易的食谱，便于准备和烹饪。

+   **Goal:** 最终目标是得到一个详细且易于执行的饮食计划，帮助我维持健康的饮食习惯。

通过T.A.G框架，你可以确保AI在执行任务时有明确的步骤和目标，从而提高任务的成功率和效率。

#### 4. C.A.R.E：背景信息，具体行动，期望结果，示例辅助

+   **Context**: 提供任务的背景信息。详细说明任务的背景和上下文，帮助AI更好地理解你的需求和任务的重要性。

+   **Action**: 具体描述需要AI执行的任务。详细说明你希望AI执行的具体任务和步骤，确保任务描述清晰明确。

+   **Result**: 说明期望的结果。告诉AI你希望最终得到的结果是什么，确保它在执行任务时有明确的目标。

+   **Example**: 提供一个详细的示例以便AI理解。通过具体的例子，让AI更好地理解你的需求和期望。

**示例:**

+   **Context:** 我由于工作繁忙，经常吃外卖，导致饮食不规律。

+   **Action:** 请你为我设计一个月的营养食谱，包括每天的三餐和健康零食，确保五天内没有重复。

+   **Result:** 我希望得到一份详细的、多样化的食谱，包括所需的食材和简单的烹饪步骤。

+   **Example:** 例如，周一早餐可以是燕麦粥配水果，午餐是鸡肉沙拉，晚餐是烤鱼配蒸蔬菜，健康零食可以是坚果或酸奶。

C.A.R.E框架通过提供详细的上下文和示例，确保AI能够准确理解任务，提高任务的准确性和效率。

#### 5. R.A.C.E：角色扮演，详细行动，上下文信息，期望结果

+   **Role**: 指定AI的角色或身份。明确告诉AI它需要扮演什么角色，例如顾问、专家或分析师，以便它能更好地提供帮助。

+   **Action**: 详细描述需要AI执行的任务。提供清晰的任务描述和步骤，确保AI知道需要做什么。

+   **Context**: 提供任务的上下文信息。说明任务的背景和相关信息，帮助AI更好地理解任务的重要性和你的需求。

+   **Expectation**: 说明期望的结果。告诉AI你希望最终得到的结果是什么，确保它在执行任务时有明确的目标。

**示例:**

+   **Role:** 你是一名营养师，擅长制定健康饮食计划。

+   **Action:** 请你为我设计一个为期一个月的营养食谱，包括三餐和健康零食，确保饮食均衡且富有变化。

+   **Context:** 我因为工作繁忙，饮食不规律，导致健康状况不佳。

+   **Expectation:** 我希望得到一份详细的饮食计划，包含每日的食谱和所需的食材清单，帮助我改善饮食习惯，提升健康水平。

R.A.C.E框架通过指定角色和提供详细的上下文信息，使AI的响应更加个性化和针对性。

#### 6. R.I.S.E：角色扮演，输入信息，步骤分析，期望结果

+   **Role**: 指定AI的角色或身份。明确告诉AI它需要扮演什么角色，以便它能更好地理解和执行任务。

+   **Input**: 提供相关资料和数据。提供足够的信息和数据，帮助AI更好地理解任务和背景。

+   **Steps**: 详细描述任务的执行步骤。列出具体的步骤和流程，让AI明白需要如何一步步完成任务。

+   **Expectation**: 说明期望的结果。明确告诉AI你希望最终得到的结果是什么，确保它在执行任务时有明确的目标。

**示例:**

+   **Role:** 你是一名营养师。

+   **Input:** 我的工作繁忙，饮食不规律，经常依赖外卖和零食。

+   **Steps:**

1.  分析我的饮食习惯和营养需求。

1.  根据健康饮食原则，设计每日的三餐和零食。

1.  提供简易的烹饪步骤和食材清单。

+   **Expectation:** 我希望得到一份详细的食谱，确保营养均衡，便于执行，帮助我养成健康的饮食习惯。

R.I.S.E框架通过逐步分析和提供详细步骤，使AI的响应更加有条理和科学。

#### 7. R.O.S.E.S：角色扮演，目标明确，场景描述，预期解决方案，步骤分析

+   **Role**: 指定AI的角色或身份。明确告诉AI它需要扮演什么角色，以便它能更好地理解和执行任务。

+   **Steps**: 详细描述

任务的执行步骤。列出具体的步骤和流程，让AI明白需要如何一步步完成任务。

R.O.S.E.S框架通过详细描述目标、场景和步骤，确保AI能够提供一个全面且可执行的解决方案。

#### 9. C.O.A.S.T：上下文信息，目标描述，行动步骤，场景信息，任务最终目标

+   **Context**: 提供任务的背景信息。详细说明任务的背景和上下文，帮助AI更好地理解你的需求和任务的重要性。

+   **Objective**: 明确你的任务目标。详细说明你希望AI帮助你实现的具体目标。

+   **Actions**: 详细描述需要执行的步骤。列出具体的步骤和流程，让AI明白需要如何一步步完成任务。

+   **Scenario**: 提供任务的场景信息。说明任务的背景、原因和重要性，帮助AI更好地理解任务。

+   **Task**: 明确最终任务和预期结果。告诉AI你希望最终实现的结果是什么，确保它在执行任务时有明确的方向。

**示例:**

+   **Context:** 我的工作生活节奏快，经常吃外卖和速食，我知道这很不健康，所以我希望改善这种情况。

+   **Actions:**

1.  分析我的饮食习惯和健康需求。

1.  设计一个月的营养食谱，包括每日的三餐和健康零食。

1.  提供具体的食谱和食材清单。

+   **Scenario:** 我每天工作繁忙，常常没有时间准备健康的饮食，导致依赖外卖和速食。

+   **Task:** 我需要一个详细的、易于执行的营养食谱，确保营养均衡且便于准备，帮助我养成健康的饮食习惯。
