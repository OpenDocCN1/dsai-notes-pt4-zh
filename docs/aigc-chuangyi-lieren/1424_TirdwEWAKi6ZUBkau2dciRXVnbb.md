# 20240909-Adobe：此生成式AI功能不适用于您所在地区

> 来源：[https://aigcreative.feishu.cn/docx/WJGydxAMdoDHz6xVTCOc2FVknlg](https://aigcreative.feishu.cn/docx/WJGydxAMdoDHz6xVTCOc2FVknlg)

在设计和创意领域，提到Adobe这个名字，很多人都会竖起大拇指。

毕竟，这家软件巨头凭借Photoshop、Illustrator、Premiere Pro、After Effect等一系列明星产品，早已成为无数创意工作者的“最佳拍档”。

![](img/59d513dddf383050249870a399aee638.png)

可以说，Adobe在图形、视频处理等领域的影响力无人能及，曾经是行业的标杆。在我心中，音-图-视频领域的老大哥，一直是Adobe。

然而，在如今火热的生成式AI浪潮中，这位“老大哥”却显得有些滞后，特别是在中国市场，Adobe的AI新功能更是让人“干着急”。

### Adobe与生成式AI：慢半拍的创新？

最近几年，AI技术几乎席卷了各行各业，从图像生成到文本处理，生成式AI的应用场景不断扩展。面对这样的趋势，Adobe自然不会缺席。公司推出了名为Firefly的生成式AI工具，并将其整合进自家王牌产品Photoshop和Illustrator，旨在让用户轻松创建图像、设计元素和视觉效果。

![](img/f96c753802df6191e02574f7e12e7d89.png)

![](img/2c47a4250b741fd5043da20d2446f1a5.png)

从操作体验上看，Adobe将AI融入到系列软件的操作中，结合的相当紧密，让设计师们能够更快速、智能地完成工作，极大地提升了工作效率。

![](img/7b68bb0535669c89af9b1286da1b57e5.png)

然而，相比其他科技公司，Adobe在AI领域的布局显然起步较晚。无论是AI工具的推出速度，还是实际应用效果，都没有带来太大的震撼。在生成式AI已经成为诸多设计类产品的“标配”时，Adobe的Firefly看起来并不具备什么突破性的创新。对于那些期待Adobe能凭借AI再次掀起行业变革的用户来说，或许略显失望。

### 生成式AI融入Adobe生态：工具虽好，却不适用

尽管Firefly的创新不算颠覆性，但其与Photoshop、Illustrator等产品的结合，还是让许多创意工作者感到便利。以往需要耗费大量时间和精力的设计工作，现在只需输入简单的提示语，AI便能为你生成各种图像素材。

![](img/b49c1e989930dc8ebfede682ca7c3483.png)

这种简化了操作流程、提高了工作效率的工具，无疑是设计师们的“福音”。特别是对于那些在赶项目、交稿时间紧张的工作环境下，Firefly的加入让Adobe的产品线显得更加智能、实用。

但问题来了：这项功能在中国，根本无法使用！

![](img/bde1b261c723a499248194cea0f06e53.png)

### 中国市场：功能屏蔽，用户失望

打开Adobe的Firefly功能时，许多中国用户迎来了同一个提示：“此功能不适用于您所在的地区”。这种提示对于那些购买了Adobe订阅服务、满怀期待体验生成式AI功能的用户来说，简直是一盆冷水。这不仅意味着他们无法享受Adobe的新技术，还让许多创意工作者感到Adobe在全球化服务上的差距。

![](img/3a5058234b27cd2b748d9c18d92bfc9b.png)

要知道，中国是全球第二大经济体，Adobe在中国的用户群体也是相当庞大。生成式AI功能的缺失，直接影响了Adobe在中国市场的竞争力。与国内其他AI设计工具相比，Adobe的“地域限制”不仅让用户倍感遗憾，也让公司错失了进一步巩固市场的机会。

### 展望未来：AI技术还能走多远？

虽然Adobe的生成式AI在中国市场暂时无法使用，但不容忽视的是，AI技术的未来依然充满了无限可能。生成式AI有潜力彻底改变设计、广告、影视等多个行业的生产方式。而对于Adobe来说，如何在全球范围内提供更无缝、更本地化的AI服务，或许将决定其未来的行业地位。

![](img/a306e0e99789d17a9f59495b774cf331.png)

Adobe的生成式AI工具虽然为其产品增色不少，但在全球化推广上还有不少问题亟待解决。特别是在中国市场，用户的需求与期待正在不断增长，如何应对本地政策与技术限制，将是Adobe在未来竞争中必须面对的挑战。

AI技术的不断发展，或许会带来更多颠覆性的创新。

未来，Adobe是否能加快步伐，抓住这波浪潮，给全球用户带来更加优质的体验？

我们拭目以待。
