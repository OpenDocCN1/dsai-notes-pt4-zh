
# 20250613-豆包小技巧：简单一招，去掉生成图片的水印

> 来源：[https://aigcreative.feishu.cn/docx/ADCIdxLhvoYvqnxbaI3crdgInab](https://aigcreative.feishu.cn/docx/ADCIdxLhvoYvqnxbaI3crdgInab)

如今，AI绘画工具层出不穷，从Stable Diffusion到Midjourney，再到国内用户常用的“豆包”，AI正在以惊人的速度“进化”，为我们的创意落地提供了很多方便。

但随之而来的，是一个不大不小的问题——许多AI工具会为生成的图片打上难以去除的水印或“AI生成”的标志。

这件事，有利有弊。

**一方面，** 为AI生成内容打上标签，有助于提高信息的可信度和透明度，让人们能清晰地分辨出哪些是人类创作，哪些是AI生成，这在一定程度上能有效规避AI技术被滥用的风险。

**然而，** 对于许多普通用户和AI博主而言，这些水印却带来了不小的麻烦。

当你想将AI生成的精美图片用于设计素材、社交媒体分享或是个人收藏时，一个显眼的水印往往会破坏画面的整体美感和协调性，甚至影响其后续的编辑和使用。

特别是对于国内用户基数庞大的“豆包”来说，其图片生成功能非常便捷，但水印问题也同样突出，给不少使用者带来了困扰。

去水印也很简单，借助第三方的工具，方法也有很多，甚至可以用魔法来打败模型，用另一个AI来去水印。

那么，有没有什么简单又快速的方法，省去上面的这个步骤，就去掉豆包生成图片的水印呢？

答案是，**有的。**

这两天一位群友@KA21 提供了一个思路，挺有效挺方便的，分享给大家。

1、打开“豆包”电脑Windows客户端——“图像生成”，随意输入一段提示词：

![](img/95651fece29753b27d54dffa122d37aa.png)

2、得到一组4张图片：

![](img/d001e7bb4b4a30b949b6a43143b3f916.png)

随便点击一张（第四张），下载原图，可以看到，这张图片的右下角是有水印的：

![](img/a9437aa45dc58f7bc97a28d33fbea663.png)

3、接下来进入正式操作；选中第四张，点击“变清晰”

![](img/e3d3127ccc2fe637e9ed0e6e536a17d4.png)

4、点击这个缩略图，右键—“图片另存为”，立马就可以得到一张没有水印的图片了。如下图：

![](img/5d86c3c633e7524c28f3757ce267d379.png)

![](img/119d9c2f8358a1233adc54ab08eb19c2.png)

![](img/bc221b28a3792be4216db161b3cdeb48.png)

![](img/d3e5b063ed67c4b5755c67c2ebbbbf6e.png)

5、但是，这张图，并不是高清的，刚才点击了“变清晰”，这会还没能得到高清图，那怎么办呢？

可以套娃！对，套娃。

那就再来一遍！

![](img/cd54461d242ef2cd17f32b86f700e5a7.png)

6、此刻，第二次存出来的这张缩略图，就是第一次点击“变清晰”，得到的那张超清图！4K的图！

![](img/a9439ff63439fcff25b0096c93922e06.png)

![](img/d1f406e1452024add86e8cd7f4ffa1b7.png)

7、如果分辨率、清晰度还不够，是不是可以继续套娃呢？那这样下去是不是可以得到8K、16K...的图呢？

答案书：不行，图片尺寸还是4K，但是图片却越来越大了！也越来越清晰了。

但对于一般的使用场景，4K的图，足够了。

![](img/1d890a7a62530b2e0a7a7f41c4b18c69.png)

对于这个“水印”，今天的这个操作，其实可以大致的猜猜：最终的水印，应该是在最后你选择导出的时候，额外添加的第二层水印，合成后导出的。

所以，在这导出前的“变清晰”操作，“缩略图”采用的是它的一个中间态，没有水印，利用这个小漏洞，保存了没有水印的图片出来。

好了，以上就是今天豆包“无水印”的使用小技巧，希望能对你有用。

## 总结与思考：关于“水印”的未来

通过这个简单的小技巧，我们暂时解决了豆包图片水印带来的困扰。

但这背后，也引发了我们对于AI生成内容规范的更深层次思考。

平台的“水印”策略，初衷是好的，它像一个“免责声明”，提醒着内容的来源。

然而，一刀切的强制水印，在某种程度上也限制了AI作为创作工具的潜能和用户的正当使用体验。

未来，我们是否可以期待一种更智能、更灵活的解决方案？

例如，平台提供可选择的、可编辑的“AI身份标识”，或者开发出能够被特定工具识别，但在视觉上几乎无感的“隐形水印”。

这样既能满足内容溯源和监管的需求，也能最大限度地保护创作者的自由和作品的完整性。

作为AI领域的观察者与AI的重度使用这，我们乐于见到技术的每一次进步，也期待着平台能推出更加人性化和完善的功能。

在此之前，希望这个小小的“技巧”，能为你在使用豆包生图的过程中提供一些的便利和乐趣。
