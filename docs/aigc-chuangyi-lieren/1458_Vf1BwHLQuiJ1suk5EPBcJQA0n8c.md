# 20250916-我们可能高估了ChatGPT的“神奇”，也低估了它的“日常”

> 来源：[https://aigcreative.feishu.cn/docx/Nzw9dachWoJD8Cxm09TcbSVfnrf](https://aigcreative.feishu.cn/docx/Nzw9dachWoJD8Cxm09TcbSVfnrf)

朋友们好，我是创意猎人。

最近一直在关注AI，特别是ChatGPT。我们平时总讨论它能做什么大事，能怎么改变世界。但前两天，OpenAI自己发了份研究报告，基于海量用户的真实数据，聊了聊大家到底在用它做什么。

看完之后，我挺有感触的。感觉我们平时聊的那些宏大叙事，和大多数人真正在用的场景，还是有些错位的。它真实的模样，和我们想象的可能不太一样。

#### 不再是少数人的工具

首先一个很明显的变化是，用它的人越来越多了，而且用户构成也越来越均衡。

以前总觉得，用ChatGPT的主要是程序员或者文字工作者这些，算是科技圈的常客。但数据告诉我们，情况已经变了。比如性别比例，现在女性用户已经超过了一半。这其实是个挺重要的信号，说明AI工具不再是少数人的专属，而是真的开始被大家普遍接受了。

我身边就有朋友，不是做技术工作的，也开始用它来安排旅行计划，或者帮孩子查资料，用得很自然。对他们来说，这东西没什么神秘的，就是一个方便的工具，跟手机里的地图、天气App一样，需要的时候就打开用一下。

报告还提到，在一些收入水平没那么高的国家和地区，用户增长速度反而更快。这也说明，AI正在成为一种很基础的信息服务，帮助更多人跨越信息鸿沟，这确实是一件好事。

#### 大家用它，主要是在“请教”和“办事”

那大家具体在用它做什么呢？报告里把用法分成了三类，我觉得这个划分很贴切。

第一类是“请教”，占了差不多一半（49%）。

这不是简单的查询，更像是把它当作一个顾问。我们不再是问“一加一等于几”，而是会问“我准备向老板提一个加薪申请，该怎么说比较得体？”或者“家里有土豆和鸡蛋，能做什么简单又好吃的菜？”。你看，这些都是生活和工作中很具体的场景，我们希望获得建议和指导。AI在这里的角色，更像一个见多识广、随时待命的朋友。

第二类是“办事”，占了四成（40%）。

这个我们都很熟悉，就是让它帮忙完成具体任务。写一封邮件、整理会议纪要、草拟一份活动方案、或者解释一段代码。这是把它当成一个助手，帮我们处理那些程序性的工作，节省时间和精力。相信这也是我们大多数人最开始接触它的原因。

第三类比较少，但很有趣，叫“个人表达”，占了11%。

这更偏向个人探索和思考。比如有的人会跟它聊聊天，把它当成一个安全的树洞，梳理自己的想法和情绪；有的人会用它来做一些开放式的头脑风暴，探索一些创意的可能性。这种用法已经超出了单纯的工具属性，带有一些精神陪伴和思维伙伴的感觉了。

总的来看，那些我们以为很“酷”的用法，比如搞艺术创作、做复杂的科学计算，其实在普通人的使用中占比并不高。绝大多数的对话，都围绕着日常生活中那些实际、甚至有些琐碎的需求展开。

#### 它的价值，体现在工作和生活的方方面面

报告里还提到一个数据，大约三成使用和工作有关，七成和生活有关。

我觉得这个比例很有意思。它不像很多软件，一打开就是纯粹的工作模式。ChatGPT很自然地融入了工作和生活两个方面。

你既可以用它来提高工作效率，也可以用它来解决生活中的小问题。它的价值，一部分是能用生产力来衡量的，但更多的价值，体现在改善我们日常生活的质量上。比如，它帮你快速规划好周末出游的路线，让你省下了查攻略的时间，可以更好地陪伴家人，而这部分价值，是很难用数字去衡量的。

所以总的来说，这份报告给我的感觉是，AI技术正在以一种非常“平实”的方式融入我们的生活。

它没有我们想象中那么遥远和神秘。它的普及，靠的不是什么颠覆性的功能，而是在日常的请教、办事和思考中，一点点地被更多普通人所接受和使用。

也许一个技术真正成熟的标志，就是我们不再觉得它神奇，而是觉得它好用、平常。就像现在这样。
