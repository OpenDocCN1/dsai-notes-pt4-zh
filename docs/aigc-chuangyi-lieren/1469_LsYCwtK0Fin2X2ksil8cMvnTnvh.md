# 20251208-某国产AI的幻觉有点大啊，直接把我🛰️号扒出来了？还成了某神秘组织头目？

> 来源：[https://aigcreative.feishu.cn/docx/Q9bddKMlZoJa4WxzxvIcSytWn1b](https://aigcreative.feishu.cn/docx/Q9bddKMlZoJa4WxzxvIcSytWn1b)

大家好。

昨天有个事儿，说实话有点把我整不会了。

咱们平时聊科技、聊AI，大多是站在使用者的角度，夸夸这个功能好用，吐吐槽那个生成太慢。

但昨天下午，我实实在在地体验了一把被AI背刺的感觉。

那种荒诞感，真就跟看了集《黑镜》似的。

事情是这样的，昨天下午我正在家里码字，🛰️突然弹出来一个好友申请。也没啥备注，就光秃秃的一个名字。我寻思可能是哪位读者或者同行想交流，手一滑就给通过了。

结果那边也没跟我客套，上来就是一张截图发来，加上一句：“比较冒昧~~正在用XX，在学习coze，AI就把你推给我了。”

![](img/1f9a663f0b2ee9982d41189b0f5c610c.png)

我当时盯着屏幕，满脑子都是问号。

![](img/50c3e052a2de578f253d853f6c06b962.png)

iThinkAi？这是个啥？我跟这玩意儿有一毛钱关系吗？

我回了个尴尬+疑问的表情包。

对面估计也懵了，把他跟这个AI的聊天过程截图发了过来：

![](img/d4ebfb79c0823ba8b6bfda856828b206.png)

好家伙，我不看还好，一看直接血压飙升，这哪是人工智能啊！

在那张截图里，这个AI煞有介事地给用户列了个“三步走”战略。前两步还挺正常，什么去知乎搜、去👸号蹲。到了第三步，高能来了，它直接写道：

“直接私信主理人 何先森Kevin，🛰️号：hykxxxxxx，备注 加入iThinkAi 即可。”

![](img/29fa7196c9526677b88e3a128e71d877.png)

看到这儿我真是气笑了。

这就很离谱？！这🛰️号确实是我的，名字也是我的，但我压根就不知道这个 iThinkAi 是个什么组织，更没在那个空间里打包过什么工作流。简单查了一下，也不知道是个啥~~

![](img/b39efa5744922085d4e0ef907e63302e.png)

笑归笑，作为一直在AI圈子里摸爬滚打的人，我冷静下来想了想，这事儿背后折射出的问题其实挺典型的。

咱们得聊聊这个“锅”到底是怎么甩到我头上的。

懂点技术的朋友应该听说过 RAG，也就是检索增强生成。

简单说，就是AI自己不知道答案，它得先去网上搜一圈，把搜到的信息嚼碎了，再喂给你。

我估摸着，昨天那个AI的脑回路大概是这样的：

它先去全网搜“iThinkAi”，可能搜到了一些零碎信息，但没找到具体的联系人。紧接着，它又搜到了我的“飞书AI知识库”。

这点我得承认，我的知识库里确实有大量关于 Coze 扣子、AI工作流的内容，而且因为大家捧场，搜索权重可能还挺高。最关键的是，为了方便大家交流，我在知识库显眼的位置留了🛰️号。

于是，灾难性的**逻辑缝合**发生了。

这个AI为了讨好用户，为了显得自己“无所不知”，它强行把这两个孤立的信息点给焊死在一起了：

iThinkAi 是搞AI工作流的。

Kevin 也写过AI工作流相关的文章，而且看起来挺专业。

Kevin 留了🛰️号。

结论：Kevin 就是 iThinkAi 的老大，找他准没错。

![](img/fab638efbc186d519b694c0c0fb267a4.png)

这就是典型的张冠李戴，也就是所谓的幻觉。

它把两个客观存在的事实，通过一种看起来很顺滑但完全错误的逻辑，捏造成了一个虚假的关系。

这事儿虽说是个乌龙，但我细想一下，后背还真有点发凉。

你想啊，今天它只是让我莫名其妙变成了一个陌生社群的“管理员”，顶多就是多几个朋友加我🛰️，费点口舌解释一下。但如果它把我的联系方式关联到了什么“售卖假课”、“金融诈骗”或者“非法软件”的词条下呢？

那这就不是幻觉了，这是直接把我的名誉按在地上摩擦。

![](img/b3b92cb1381bc1d99d8fe6d589aea866.png)

**现在的国**产大模型，在这方面真的有一种过度服务的心态。就像那种特别热情的导购，明明店里没你要的货，为了不让你走，硬是从隔壁库房给你拿个长得像的凑数，还拍着胸脯说这就是你要的。

讲道理，作为用户，我们其实更希望AI能诚实一点。

不懂就是不懂，没找到就是没找到。

你大可以说“我没找到直接联系人，但这里有几位相关领域的专家你可以关注”。而不是为了凑出一个看似完美的闭环答案，就把无辜路人的隐私直接给卖了。

而且这里面还有个隐私边界的问题。

![](img/97fd1ec693561f4b30501cc9df9ea6e0.png)

我的🛰️号在我的飞书AI知识库里是公开的，那是为了方便读者跟我建立联系。但这并不意味着AI有权利把它抓取出来，作为一个错误指令的一部分，分发给那些原本不需要联系我的人。

这实际上已经是一种数据的滥用了。

所以啊，兄弟们，经过这事儿我是真有个建议给你们。

现在咱们用AI用的越来越顺手，查资料、写代码、甚至问路都靠它。

但对于它给出的那种特别确切的信息，尤其是涉及到具体的人名、联系方式、法规条文这些东西，千万得留个心眼。

别它给啥你信啥，稍微动动手指二次核实一下。

不然就像昨天加我那位朋友一样，满怀期待地跑过来，结果发现找错门了，俩人都尴尬。

![](img/447fff79927d964f03337dc2c49e801c.png)

**至于大模**型厂商那边的朋友，如果你们能看到这篇文章，也真心希望能把事实对齐这块再打磨打磨。

咱们不需要一个只会在那儿一本正经胡说八道的懂王，我们需要的是一个靠谱的助手。
