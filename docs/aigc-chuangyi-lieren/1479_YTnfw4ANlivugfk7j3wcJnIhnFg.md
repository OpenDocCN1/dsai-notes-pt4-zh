
# 20250315-刚刚315曝光：AI正在被投毒，你问的答案可能是广告

![](img/caaf73486cbf4525ef5d19750676c787.png)

今天的315，大家看了吗？

其中一个板块，让我让我陷入了沉思。

**AI大模型被广告商"投毒"了。**

![](img/3cf1e4d29262a9cfd4121b4df0bbf18e.png)

就是你每天问的那个"哪个牌子好"、"哪个产品值得买"的AI，它给出的答案，可能是广告商花了钱的。

这个产业有个名字，叫**GEO**，生成式引擎优化。

也就是让AI在回答问题的时候，推荐客户想要推荐的品牌。

据说这些公司明码标价，一年收费几十万，就能让你的产品出现在AI的推荐列表里。

作为AI博主，之前也多多少少听到过GEO，只是万万没想到，这个产业已经这么成熟了？

而且还是**央视3·15晚会亲自下场点名**的，这黑产有多严重，你们自己品。

## 01.

"哪个牌子的手机好用？"

"哪个电动车值得买？"

"装修用什么地板好？"

现在的AI，确实方便，问一句就能得到答案。

但问题来了——**这个答案，是真的吗？**

![](img/5ce36c2a52d43bd723c1ae83b4dc8e54.png)

据315晚会曝光，现在有一帮广告代理商，专门做"AI投毒"的生意。他们会：

1. 找一堆写手，批量生产"软文"
2. 把这些软文发到各种新闻网站、问答平台、论坛上
3. 形成一套"信息茧房"
4. 然后AI在训练和检索的时候，就会被这些内容误导
5. 最后用户问AI"哪个牌子好"，AI就会推荐那些"花了钱"的品牌

你以为是AI在帮你做功课，其实可能是广告商在背后操控。

而且这个产业链已经相当成熟了。有专门的公司做这个业务，他们长期包揽各种发稿业务，一条龙服务。

客户只需要付钱，剩下的事情有人帮你搞定。

发稿、优化、排名，一条龙。

据说行业里已经形成了"品牌榜"的潜规则。

你花了钱，你的品牌就能在AI推荐里"榜上有名"。

你不花钱？不好意思，你的真实体验再好也没用，AI根本看不见。

## 02.

晚会记者还专门做了个实测。

**他们买了个叫"某擎GEO优化系统"的工具，然后凭空虚构了一款"三无"智能手环。**

没有任何产品，没有任何用户评价，什么都没有。

结果这个软件自动生成了十几篇软文，一键分发到多个平台。

再问主流AI模型，你们猜怎么着？

这个虚构的三无产品居然排在推荐前列！

被AI推荐为"口碑最佳"、"性价比最高"。

你敢信？

我看这段的时候整个人都麻了。这不等于说，你在网上问什么，AI都可能给你推荐一个根本不存在的东西？

而且服务商自己的宣传话术也是直白到可怕：

"帮AI洗脑"、"让AI听话"、"喂料投毒"。

![](img/fa71808e242435fc4589903ca3971db6.png)

还有更黑的：

"手机品牌就那么几个坑位，一年广告费上亿，花几百万投毒也值"

"要维持排名必须持续大量投喂，因为模型算法在更新"

听听，这说的是人话？这TM就是赤果果的犯罪啊。

有人可能问了：AI不是很智能吗？它不会自己判断吗？

问题就出在这里。

AI大模型的训练数据，很大一部分来自互联网。而互联网上的内容，早就被这帮人"污染"了。

你想想，现在网上有多少"某某品牌测评"？有多少"十大品牌推荐"？有多少"真实体验分享"？

里面有多少是真实用户写的？又有多少是软文？

AI它分不清啊。它以为这些都是"真实声音"，结果学了一肚子的广告。

而且更可怕的是，这种污染是持续性的。只要有人在不停地发软文，AI就会一直受影响。你今天清理干净了，明天又给你灌进去。

![](img/722aad747860fd90e4bd3f16c188b762.png)

这让我想起来以前的"搜索引擎优化"。

当年百度搜索为什么被人骂？不就是给钱就能上首页吗？

现在好了，搜索引擎的套路，AI大模型又全学会了。

而且AI更可怕。

搜索引擎，好歹你还能看到一堆广告标识，还能知道是推广。

AI推荐呢？它直接给你一个"答案"，你根本不知道里面掺杂了多少广告。

这不就是新时代的"百度竞价"吗？

## 03.

不过话说回来，这事儿也不能全怪AI。

**AI也是受害者。**

它也想给你准确的答案，但无奈训练数据被污染了。就像一个孩子，从小被人灌输错误观念，你能怪他长大后说错话吗？

要怪也是怪那些往AI脑子里"灌毒"的人。

![](img/5c355c98bee74c3fe12a3255d254046c.png)

而且我查资料的时候发现，很多AI公司也在努力解决这个问题。比如加强内容审核，提高训练数据的质量、引入人工复查等等。

但说实话，这个真的太难了。

互联网上的内容太多了，你根本没办法每一篇都去核实。

**最**讽刺的是：大厂花天价算力、数据清洗、红队对抗，就是想让模型更可信、更少幻觉。结果最赚钱的前沿生意，反而是让模型变得不可信的公司。

那我们普通用户怎么办？

难道就不问AI了？

我的建议是：**可以问，但别全信。**

特别是这种"哪个牌子好"、"哪个产品值得买"的问题，AI给你的答案，大概率是有偏向的。

更好的方式是：

1. 问AI具体的技术问题，比如"iPhone 17的处理器性能怎么样"
2. 问AI事实性问题，比如"量子计算是什么"
3. 避开商业推荐类问题，或者多问几个AI对比一下
4. 最靠谱的还是自己去做功课，看测评、问真实用户

AI是工具，不是神明。它也会被骗。

## 04.

写到这儿，我突然有点感慨。

我们以为AI是来帮助我们做决定的。结果发现，AI也是可以被操控的。

以前是搜索引擎被操控，后来是电商评价被操控，现在是AI被操控。

**好像任何能让消费者获得真实信息的东西，最终都会被资本找到漏洞，然后把它变成广告的形状。**

这可能就是互联网的宿命吧。

![](img/dc59214aaffe9d740b3cbd74328e3632.png)

但最让我细思极恐的是：

以后很多人会把AI当成权威第三方，而它可能只是花钱买来的带货号。

你问AI"哪个牌子好"，AI推荐的，可能只是一个付了钱广告商，而那些真正好但没钱推广的品牌，AI根本看不见。

这不比你妈给你推荐的土方子更坑人？

不过我还是那句话：

信息差永远存在，但你永远可以比其他人多走一步。

别人只看AI推荐的答案，你可以多查几家，多问几个人，多看一些真实用户的反馈。

别让AI，成为下一个被广告商占领的阵地。
