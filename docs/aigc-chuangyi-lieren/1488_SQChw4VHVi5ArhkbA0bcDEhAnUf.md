# 20241019-谷歌Google大刀阔斧重组AI部门！搜索巨头的未来野心

> 来源：[https://aigcreative.feishu.cn/docx/AdK2du4sxoDomdxYyFjcvSoqnCe](https://aigcreative.feishu.cn/docx/AdK2du4sxoDomdxYyFjcvSoqnCe)

谷歌（Google）近期宣布了一项重大组织架构调整，此举旨在加速其人工智能（AI）布局，进一步巩固在AI领域的领军地位。这一决定再次印证了谷歌对AI技术的高度重视，也让人看到了其在AI发展上的雄心。

![](img/1ebf38ad1b0e6529c5ec3e55611196e3.png)

# **Gemini项目的“大迁移”**

此次重组的重头戏之一，是谷歌的Gemini应用团队将正式并入DeepMind部门。Gemini被认为是谷歌在AI领域的尖端技术展示平台，而DeepMind则是谷歌旗下专注于前沿AI研究的核心部门。由Sissie Hsiao领导的Gemini团队，此番将由知名AI科学家Demis Hassabis全面接管。

![](img/39487afaedf0b1f8e3367d3b13776a1d.png)

这意味着，谷歌试图通过更加紧密的内部协作来加速AI模型的研发和应用。据内部人士透露，此次重组的关键目标是**缩短反馈周期，确保新模型可以更快地投入市场**。这对于谷歌在AI竞赛中的速度和效率提升无疑是一个加分项，特别是在全球科技巨头纷纷发力AI的背景下。

# 高层换血！搜索和广告业务迎来新掌门

除了AI团队的重新部署，谷歌在搜索和广告业务上的人事调整同样引人注目。原搜索、广告和商业产品负责人Prabhakar Raghavan，将卸任这一职位，转而担任谷歌的首席技术官（Chief Technologist）。在新岗位上，他将与CEO桑达尔·皮查伊（Sundar Pichai）紧密合作，为公司的技术发展方向提供战略指导。这一调整显示出谷歌在战略上的新思考：把Raghavan这样一位在搜索领域有着深厚经验的技术大咖提升到更高的技术领导位置，希望通过他的技术见解推动整个公司的AI进程。

![](img/222964fbf800598f45339db2a7061c0d.png)

与此同时，Nick Fox将接替Raghavan，成为知识和信息团队的新掌门。Fox在谷歌AI战略的制定和执行上有着丰富经验，这次上任将帮助谷歌在搜索业务的智能化和数据挖掘上继续发力。特别是在竞争激烈的搜索市场中，谷歌希望通过更强大的AI技术增强用户的搜索体验，保持其在全球搜索引擎市场的霸主地位。

# **全力进军AI：谷歌的“新豪赌”**

此次重组的背后，显现出谷歌对AI技术的不懈追求。近年来，谷歌在AI方面的投入持续加大，无论是搜索引擎的智能化升级，还是DeepMind在前沿研究上的进展，都体现了其在AI赛道上的决心。然而，面对微软、Meta等竞争对手的迅猛发展，谷歌也意识到**加快速度、提升效率**的重要性。

![](img/84ea2e05de823f3ea287783cfdf9303d.png)

Gemini团队与DeepMind的合并，将让AI技术更好地服务于谷歌的核心业务。随着更多AI技术被应用于谷歌的广告、搜索、地图等产品中，用户将体验到更智能、更高效的服务。与此同时，这一调整也可能引发AI领域的新一轮竞争浪潮。

# **谷歌重组，未来可期？**

无论如何，这次谷歌的大规模调整意味着其AI战略进入了一个新的阶段。谷歌的目标不只是做AI的引领者，更是要在不断变化的技术格局中保持领先地位。
