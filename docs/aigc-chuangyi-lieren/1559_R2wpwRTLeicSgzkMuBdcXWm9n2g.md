# 吴晓波-《预见》系列

> 来源：[https://aigcreative.feishu.cn/docx/VDzddfhAIoAC0ZxgHticHq8AnKf](https://aigcreative.feishu.cn/docx/VDzddfhAIoAC0ZxgHticHq8AnKf)

吴晓波是一位著名的中国财经作家，出生于1968年9月9日，浙江宁波人，毕业于复旦大学新闻系。他以其深刻的商业洞察力和卓越的写作能力而闻名，被誉为当代中国最知名的财经作家之一。

吴晓波的职业生涯始于新华社，这段经历为他打下了扎实的新闻写作基础，并培养了他对事实的严谨态度。他后来成为《东方早报》的财经记者，并创办了“蓝狮子”财经图书出版品牌，出版了多部影响深远的作品，如《大败局》、《激荡三十年》等。其中，《大败局》一书分析了多个中国新兴企业的兴衰历程，广受读者好评，并被评为“影响中国商业界的二十本书”之一。

除了写作，吴晓波还涉足教育领域，曾担任上海交通大学和暨南大学EMBA课程教授，并在哈佛大学担任访问学者。他还创办了浙江省中科商学研究院，并长期从事公司研究。

吴晓波不仅在学术界有贡献，还在企业界有所作为。他曾担任多家企业的独立董事，如优刻得科技股份有限公司，并在履职中表现出色，维护了公司及股东的利益。此外，他还通过自媒体平台分享知识，成为新媒体时代知识转化财富的代表人物。

吴晓波的作品不仅限于商业领域，他还撰写了关于杭州城市记忆的书籍《人间杭州：我与一座城市的记忆》，展现了他对城市文化和历史的深刻理解。

吴晓波以其多方面的成就和对中国经济发展的深刻洞察，成为一位备受尊敬的财经作家和思想家。
