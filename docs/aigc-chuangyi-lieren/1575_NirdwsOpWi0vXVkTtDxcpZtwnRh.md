
# 王煜全前哨大会2021：科技让生活更好

> 来源：[https://aigcreative.feishu.cn/docx/Ut5kdG7tKorXrwxwK5fcloVOn3f](https://aigcreative.feishu.cn/docx/Ut5kdG7tKorXrwxwK5fcloVOn3f)

2021年12月18日，王煜全的个人年度演讲“前哨大会2021”如约而至。

![](img/243a07f0035095d553430d8eb4c07727.png)

在这场演讲中，王煜全带你感受了12个未来场景，以及10个2022年即将发生的产业趋势。

本届前哨大会还有一个变化，那就是全程采用虚拟制作，科技感非常强，让人耳目一新。

我们正在迎来这样一个精彩的时代，科技的浪潮呼啸而来，其中孕育着大量的新机会。

以下为王煜全前哨大会演讲的精彩要点，与你分享。

## 第一部分 科技赋予生活意义

1. 以前是适应过去的应试需求，未来是适应社会的能力需求。
2. 未来越来越少的人会讨论高考，而是讨论技能、能力、未来机会。未来需要什么样的知识，就应该去掌握这些知识。
3. 未来教育的趋势是社群化学习，孩子们需要的前沿知识在社群的集体智慧里，不在课堂里。
4. 年轻人不是真的想“躺平”、想“内卷”，而是想找到生活和工作的意义。这是一个不乏机会的时代，与其哀叹今天的机会不属于我，不如实实在在去为未来做好准备。
5. 未来社会需要的能力不是智商，也不是情商，而是人类的机器智商。也就是人理解机器、控制机器、协调机器，让机器为人类服务的能力。
6. **每个时代的首富**，都是那个时代的科技企业家。
7. 传统投资观念有一句老话“不要把鸡蛋放在同一个篮子里”，也就是分散风险。我认为恰恰要把鸡蛋放在同一个篮子里，这个创造财富的篮子叫做科技企业。
8. 要在不确定的时代寻找确定性的机会，找到未来的成功者然后下重注，才是正确的投资方法。
9. 大机构抗风险能力不如散户，因为承受不起市值的巨大波动。只有坚定持有的个人才能真正享受到科技的红利，也许这个人就是看懂科技的你。
10. 疾病像个定时炸弹，整个家庭都会面临巨大的财务压力、精神压力。所幸的是，现在已经有越来越多的先进科技帮我们的父母管理健康。
11. 科技是今天问题的解，也是塑造未来的力量。如果我们提前知道未来社会是什么样，那我们就能提前为未来做好准备。
12. 今天新一轮的科技潮流，叫做 **服务的规模化**。以前的出行是买车，未来出行可以直接获得出行服务。人工智能可以把服务能力规模化复制，每个人都能享受到全世界最顶级的服务。
13. 超级城市化是大势所趋，房价越来越贵而居住空间越来越小，现代人会有缺失感。科技带来的“虚拟满足感”会让我们感觉拥有一切。
14. 以前的出行是舟车劳顿的痛苦体验，未来出行将是我们最愉快的时光。
15. 未来能够快速规模化、连锁化的餐饮不仅仅是肯德基、麦当劳，机器人为餐饮行业带来的变革，让所有高端餐饮品牌都能够拥有复杂菜品制作的能力。
16. 未来社会是技术与文化的双向选择、协同进化。技术的选择决定文化方向，文化的选择促进技术发展。
17. 电竞正在崛起成为一个超越一切体育运动、影视媒体的新物种。如果你的孩子喜欢看电竞，不要轻易否定，他们看的或许是娱乐，你看到的也许是机会。
18. 游戏化能够提升我们做任何事情的效能，如果获取知识也可以游戏化，学习的效果当然会更好。比如，我们的教科书为什么不能编写得像金庸小说一样精彩呢？
19. 游戏可以成为孩子们用来训练自己适应未来的工具，在游戏里学习协作、自由创造。在Roblox里设计一个美丽城市的孩子，可能就是未来的城市设计师。
20. 任何科技的普及都符合“跨越裂谷理论”，包括五类用户：创新者、早期使用者、**早期主流、晚期主流**和落伍者。科技给五类人群带来的利益并不均衡，要敢于做前16%的主动行动者。
21. 科技就是未来，早使用科技，你就越早获益。看懂未来，主动行动去拥抱未来，你就是生活赢家。

## 第二部分 科技推动社会进步

1. 2022年买车，一定要看两个指标。一个是看有没有GPU，第二个是看有没有激光雷达。
2. 2022年将出现一大波虚拟人，推动元宇宙概念持续热。未来虚拟人会越来越普及，很快会出现24小时连续直播的网红主播。
3. 人类文明的核心是拥有一个巨大的知识库，任何个人都无法拥有登月所需的所有知识，但是我们登上了月球。以前承担人类知识积累责任的是互联网，未来将是元宇宙。
4. 元宇宙里将出现 **超级服务者**，为我们每个人提供服务。未来元宇宙不光拥有智能生命，还会成为智能社会。
5. 未来机器人会无所不在，中国的下一个大疆，将是一家机器人公司。
6. 自动驾驶汽车就是一种机器人，芯片是计算单元，传感器是感知单元，轮子是运动单元。特斯拉不只是一家汽车公司，而是一家机器人公司。
7. 服务规模化时代的社会将会格外美好。未来你想做饭，你才去做饭；你想开车，你才去开车。因为你想获得的任何服务，都会有智能系统随时为你提供。
8. 中国未来如何摆脱芯片技术的制约？其实，芯片产业受制于人这个问题问错了。以前重要的技术在未来都不会那么重要。今天的芯片产业已经出现了弯道，弯道才能超车。
9. 我们容易看到的是那些容易感受到的东西，但是我们感受不到的部分也在经历一场革命。这场革命的深远程度、重要程度，一点也不亚于我们能够感受到的部分。这就是制造革命、供应链革命和能源革命。
10. 未来制造技术的进化速度将会大大加快。有了数字孪生，不光软件可以实现快速迭代，硬件设备甚至整个工厂，都可以实现快速迭代。
11. 当新能源成为主流，我们将看到万物接电的时代到来。就像互联网成为基础设施后，谷歌、亚马逊这样的巨头随之涌现，未来新能源产业还有巨大的机会等待发掘。
12. 先进制造的引领者叫金属3D打印，按需提供零配件，能够实现整个供应链系统的优化。未来科技产品越来越复杂、零配件越来越多，先进制造的市场已经开始启动，未来潜力巨大。
13. 不光要技术的创新，还需要文化的创新，支持创新的 **文化是一个经济体**长期发展的关键。在一个 “亲创新” 的文化里，企业敢于创新，政府鼓励创新，社会接纳创新。

![](img/5fe33e5cd6d730cdd2243583e20591eb.png)

14. 一个社会的创新水平不取决于创新引入的速度，而是先进科技引入的深度。中国虽然没有发明二维码，但是普及了二维码，而普及深度才能带来整个社会价值的提升。
15. **以前企业是**招产品经理，未来是招服务经理。
16. 一切行业皆是服务业，服务规模化使得每家企业都有一次重新塑造产品的机会。每个企业都要重新思考，我是不是把以前提供给用户的产品变成了服务？
17. 未来会诞生 **健康管理运营商**，他们整合分析多方数据，为我们的健康提供服务。健康管理是一个巨大的市场，它会颠覆整个健康保险产业。
18. 未来显示无所不在，我们会不习惯裸眼看到的世界。一个更加智能化的环境，让我们随时随地可以用最便捷和快速的方式接入虚拟世界。
