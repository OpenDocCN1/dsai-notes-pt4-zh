
# 刘润-《进化的力量》系列

> 来源：[https://aigcreative.feishu.cn/docx/UmlRdOdXhoqtkhxWs3DcXmksn9c](https://aigcreative.feishu.cn/docx/UmlRdOdXhoqtkhxWs3DcXmksn9c)

刘润是一位国内著名的商业咨询顾问，出生于江苏南京，毕业于南京大学，并获得复旦大学MBA学位。他是润米咨询的创始人，并且是线上音频课程《刘润·5分钟商学院》的主理人。在职业生涯中，刘润曾在微软工作了近14年，担任战略合作总监，并在2013年写了一封离职信，该信阅读量超过百万。

刘润不仅在微软取得了成功，还为多家知名企业如海尔、百度、恒基地产、中远国际、晨兴资本和康宝莱等提供战略咨询服务，被誉为互联网转型专家。他每年10月都会举办“进化的力量·年度演讲”，为创业者和企业家提供年度规划的参考方向。

此外，刘润还与得到App合作发布了《5分钟商学院·基础》和《5分钟商学院·实战》音频课程，至今已有约50万付费订阅者。他的👸号“刘润”在商业领域具有很高的影响力，被评为“最具收藏价值的公号”之一。

刘润的成功不仅得益于个人的努力，也与时代背景密切相关。他的成功在很大程度上是时代造就的，如果没有时代的东风和一些幸运，他可能无法达到今天的高度。
