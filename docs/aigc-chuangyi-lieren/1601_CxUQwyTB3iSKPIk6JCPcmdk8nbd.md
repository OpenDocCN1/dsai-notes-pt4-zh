
# 任泽平-十大预测系列

> 来源：[https://aigcreative.feishu.cn/docx/YkZAdgpf4oTfmuxZ7mIcwikFnKb](https://aigcreative.feishu.cn/docx/YkZAdgpf4oTfmuxZ7mIcwikFnKb)

任泽平，男，汉族，1979年3月出生于山东枣庄，是中国著名的独立经济学家。他拥有清华大学经济管理学院博士后学位和中国人民大学经济学博士学位。任泽平在经济学领域有着丰富的研究和实践经验，曾担任国务院发展研究中心宏观经济研究部研究室副主任、国泰君安证券研究所董事总经理、首席宏观分析师等职务。

作为专业财经头部"泽平宏观"的创始人，任泽平在宏观经济分析方面有着卓越的贡献。他出版了多部专著和译著，包括《宏观经济结构研究》《从奇迹到成熟：韩国转型经验》《大势研判：经济、政策与资本市场》《房地产周期》等。这些著作不仅展示了他在经济学领域的深厚造诣，也为读者提供了深刻的经济分析和见解。

在职业生涯中，任泽平曾在多个知名机构任职。2017年12月，他加入恒大集团，担任首席经济学家，主要负责宏观经济分析、市场发展方向及行业发展动向研究。在恒大期间，他为恒驰汽车的建立提供了理论支持，并在全球范围内收购新能源汽车产业链上下游公司，为恒大集团的发展做出了重要贡献。

此外，任泽平还积极参与社会活动和公共事务。他曾担任中国民营经济研究会副会长、中原银行首席经济学家，并在多个平台上发表意见领袖文章，探讨中国经济和社会发展问题。他还与阿里巴巴首任COO关明生进行对谈，探讨中小企业在变局时代如何生存和发展。

任泽平的事迹成就不仅体现在他的学术研究和职业成就上，还在于他对社会经济发展的深刻洞察和积极贡献。他的工作和思想为中国乃至全球的经济发展提供了宝贵的参考和启示。
