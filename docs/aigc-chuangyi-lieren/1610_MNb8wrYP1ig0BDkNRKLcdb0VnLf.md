# 管清友-金融系列

> 来源：[https://aigcreative.feishu.cn/docx/TaqodeoL0oWXE9xcIepcSarrnFb](https://aigcreative.feishu.cn/docx/TaqodeoL0oWXE9xcIepcSarrnFb)

管清友，1977年12月出生，是一位杰出的经济学家和金融理论研究者。他毕业于中国社会科学院研究生院，获得经济学博士学位，并在清华大学完成博士后研究。管清友的职业生涯涵盖了多个重要职位和领域，包括民生证券副总裁、研究院院长，清华大学国情研究中心（现为国情研究院）能源与气候变化项目主任，以及中国海洋石油总公司宏观处处长、调研处处长。

作为如是金融研究院院长和如是资本创始人，管清友在经济与金融理论研究方面有着深厚的造诣。他的研究领域广泛，涉及宏观政策与改革、金融市场、世界能源格局、能源安全和能源政策、油价波动周期、气候变化以及碳货币等方面。他是国内最早系统论述石油-美元计价结算体系及其影响、减排与碳交易等议题的学者之一。

管清友的主要成就包括被评为十大青年经济学人、中国青年金融学者奖和新财富最佳分析师。他还担任了多个知名企业的独立董事，包括美的集团和南华期货，并在海南大学经济学院担任教授。

此外，管清友还积极参与公共政策研究和社会事务。他曾提出提高粮食收购价以反哺农民的建议，并在多个论坛和媒体上发表关于经济和金融问题的见解。他的代表作品包括《管清友的股票投资课》、《后天有多远》、《刀锋上起舞》、《石油的逻辑》和《中国应对全球气候变化》等。

管清友在经济学和金融学领域取得了显著的成就，他的研究和实践对中国经济和社会发展产生了深远的影响。
