# 安装方法说明（重要）

直接将 **zip**** 文件拖进插件管理的界面就可以**，不用解压！不用解压！不用解压！

> 为什么不是 crx 后缀？因为如果是 crx 后缀需要在PC电脑端的 chrome 和 edge 插件市场注册，不然安装不了，暂时不准备发布插件市场，后续重构后计划发布，手机浏览器狐猴和kiwi必须使用 crx 后缀，从0.0.7版本开始都会发布该格式
