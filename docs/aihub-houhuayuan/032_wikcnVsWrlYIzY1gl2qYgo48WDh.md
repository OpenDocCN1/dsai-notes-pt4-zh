# 简化结构

记住这个口诀：**令景入格**

| 分步 | 对应英文 | 说明 | 例子 |
| --- | --- | --- | --- |
| 给出指令（**令**） | Statement | 你希望 ChatGPT 做什么 | 提供最流行的机器学习框架全面概述，包括他们的优点和缺点。包括现实生活中的例子和案例研究，以说明这些框架如何在各个行业中成功应用 |
| 背景信息（**景**） | Insight | 背景信息和上下文（坦率说来我觉得用 Context 更好） | 这个博客的读者是有兴趣了解机器学习最新进展的技术专业人士 |
| 输入（**入**） | Personality | 你希望 ChatGPT 以什么风格或方式回答你 | 在回应中，混合使用 Andrej Karpathy, Francois Chollet, Jeremy Howard和Yann LeCun的写作风格 |
| 格式（**格**） | Experiment | 要求 ChatGPT 为你提供多个答案 | 给我多个不同的例子 |

# 最完备结构

记住这个口诀：能角景令风例（英文CRISPE）

| 分步 | 对应英文 | 说明 | 例子 |
| --- | --- | --- | --- |
| 能力和角色（**能角**） | Capacity and Role | 你希望 ChatGPT 扮演怎样的角色 | 作为机器学习框架主题的软件开发专家，以及专家博客作者 |
| 背景信息（**景**） | Insight | 背景信息和上下文（坦率说来我觉得用 Context 更好） | 这个博客的读者是有兴趣了解机器学习最新进展的技术专业人士 |
| 给出指令（**令**） | Statement | 你希望 ChatGPT 做什么 | 提供最流行的机器学习框架全面概述，包括他们的优点和缺点。包括现实生活中的例子和案例研究，以说明这些框架如何在各个行业中成功应用 |
| 个性风格（**风**） | Personality | 你希望 ChatGPT 以什么风格或方式回答你 | 在回应中，混合使用 Andrej Karpathy, Francois Chollet, Jeremy Howard和Yann LeCun的写作风格 |
| 要多个例子（**例**） | Experiment | 要求 ChatGPT 为你提供多个答案 | 给我多个不同的例子 |
