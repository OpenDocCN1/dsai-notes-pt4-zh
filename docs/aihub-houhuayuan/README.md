#  ⛳️  知识空间简介

欢迎来到《AIHub》的知识空间页面！这里旨在提供一个全面系统、易于理解的AI学习路径，帮助您了解AI的从概念到应用等各方面知识，同时提供持续迭代的工具，将学习到的知识应用到实际的工作流程中，在大时代下比别人早走几步，更重要的是希望引发您思考：「我可以用AI做什么，帮助自己更强大」。

> 本空间的缘起：自ChatGPT于2022年底发布以来，AI相关项目和文章呈现百家争鸣的状态，但是，如何从这么多内容中筛选出有价值信息，尤其帮助对AI不熟悉的用户更快建立认知，实际应用有效的工具，帮助自己节省时间，也顺便可以帮助到更多人，是做AIHub插件以及现在建立这个知识空间的初衷。

> 本知识库会**持续更新**，所以**不妨将这个地址 ****Ctrl****+D**** 保存到你的收藏夹里面​**
