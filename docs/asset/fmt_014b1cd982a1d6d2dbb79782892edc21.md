> 我估计你们没学过向量微积分，因为学过向量微积分的同学看西瓜书就不成问题，根本不会选择来看我的十日谈。所以对于向量微积分的推导，我这里不会继续讲，它的推导思想和上面是一脉相承的，你如果真的不理解你就把矩阵展开成多元函数自己推。我这里就直接写结果。

> 这个方法好是好，但是有个问题。如果表格矩阵很大，进行反复的矩阵乘法、求逆都是很消耗资源的操作。对计算机而言，一次性对大批量数据进行处理有可能使得**内存溢出**，或报错`MemoryAllocationError`（内存无法继续分配）。但对计算机而言，少量多次高度重复的计算操作对它而言是不会感到厌倦的。有个想法叫梯度下降法，也可以用来求解函数`J`的极值。

> 梯度下降是一种迭代算法，不需要一次性处理所有的数据。它的基本思想是：通过不断调整模型的参数（比如线性回归中的斜率和截距），以最小化目标函数（通常是损失函数，如均方误差）。它就像一个爬山的人，逐步试探着，每次移动一点点，朝着最陡峭的下坡方向走去，最终可能到达山谷的最低点。

> 想象一下，你站在一座山的某个位置，想要尽快下山。你会怎么做？梯度下降法的做法是——看看脚下，找到最陡峭的那个方向，然后迈一步。每一步都朝着当前看来最可能让你下山最快的路径走，从而逐步接近山脚。数学上来说，这其实就是沿着目标函数的负梯度方向更新参数。通过这种方式，每隔一段时间（即每次迭代），它就能用相对较少的数据计算出一个梯度，进而调整模型参数，逐步逼近最优解。

> 这种分步骤、逐次优化的过程，大大降低了对内存和计算资源的要求。每次迭代只需要处理部分数据（比如一个批次的数据），而不是整个庞大的数据集，因此它可以很好地应对大数据量的问题。

```
def gradient_descent(x_start, y_start, learning_rate, num_iterations):&quot;&quot;&quot;
    使用梯度下降法优化函数 f(x, y)
    参数:
    - x_start, y_start: 初始点
    - learning_rate: 学习率
    - num_iterations: 迭代次数
    返回:
    - history: 历史点记录，包含迭代过程中的 (x, y)
    &quot;&quot;&quot;
    history = []
    x = x_start
    y = y_start
    history.append((x, y))  # 记录初始点
    for _ in range(num_iterations):
        dx, dy = grad_f(x, y)  # 计算梯度
        x -= learning_rate * dx  # 更新x
        y -= learning_rate * dy  # 更新y
        history.append((x, y))  # 记录更新后的点
    return history
```

### 2.2 回归模型的过拟合与正则化

#### 备注

> 我估计这里可能基础不好的同学可能会提三个问题：

1.  为什么正则化是在损失函数后面加上那个玩意，系数`\lambda`起到了什么作用

2.  正则化为什么可以对异常样本产生约束，怎么解释这一点

3.  我怎么知道该用`L1`正则还是`L2`正则

> 这里deepseek的回答大概率不太行。我这里解释一下：

1.  损失函数后面加上那一堆就是为了约束住系数，因为异常样本其本质就是因为某些误差项被放大了，而我加上一个系数成分在求偏导的时候能通过`\lambda`把这个误差项修正过来。误差的本质就是影响系数。

2.  你推导它的求导公式就知道了，本质上后面的部分是类似于加速过程中的一个缓冲带，`\lambda`太大的时候就相当于刹车。这个机制在梯度下降的时候很明显。

3.  关于问题三：

    +   `L1` 正则化（`Lasso`）：如果需要进行特征选择，或者认为数据中包含大量不重要的特征，`L1` 正则化会更合适，因为它可以将一些参数压缩为零，实现稀疏解。

    +   `L2` 正则化（`Ridge`）：如果想要平滑模型参数，且认为所有或大部分特征都有一定的关系，但需要防止过拟合，`L2` 正则化会更合适，因为它会减小参数值，但不会让参数变为零。
