
# 20240315-SpaceX "星舰" 完成第三次关键飞行测试，“虽失联，但取得巨大进展！”

> 来源：[https://aigcreative.feishu.cn/docx/NeXJdicv2oIDEbxQ1yJcpvB0nHw](https://aigcreative.feishu.cn/docx/NeXJdicv2oIDEbxQ1yJcpvB0nHw)

> 链接：https://mp.weixin.qq.com/s/chgDwCpht599R3HQ4B6DIg

美国太空探索技术公司（SpaceX）在北京时间21点25分成功进行了其“星舰”（Starship）重型运载火箭的第三次无人飞行测试。这次测试标志着SpaceX在实现其宏伟愿景——使人类成为多行星居民——的道路上迈出了重要一步。

在此次测试中，星舰的33台发动机均正常发动，发射升空后不久，星舰按照预定计划成功进行了热分离，这一成果已超越前两次试飞。然而，在返回过程中，超重型火箭在返回途中丢失，尽管如此，SpaceX发言人丹·霍特(Dan Huot)在直播中表示，这次试飞仍然取得了宝贵的数据和经验。

星舰在发射后的28分钟内成功完成了舱门开关测试，并在47分钟后执行了二次点火演示，猛禽发动机点火顺利成功。尽管在重返大气层过程中失去了星舰，任务提前结束，但这次试飞仍然被视为星舰项目的一个里程碑。

![](img/659a822a1571fa074215c43c5fe1e77b.png)

SpaceX创始人埃隆·马斯克（Elon Musk）在社交媒体上强调了星舰的重要性，他表示：“星舰虽失联，但取得巨大进展。”星舰的设计目标是实现完全、快速的可重复使用，这将是完成各类太空任务，包括人类定居火星的关键。

SpaceX在2023年的航天发射和卫星部署方面取得了显著成就，计划在2024年进一步增加发射次数和入轨质量。星舰的成功对于SpaceX的未来发展至关重要，有望大幅降低太空旅行成本，推动人类探索太空的新纪元。

星舰项目自2016年启动以来，经历了多次迭代和测试，SpaceX不断在失败中学习和进步。星舰的成功将不仅实现马斯克的火星殖民梦想，还将为太空旅行、月球探索以及地球洲际快速运输提供新的可能。

![](img/82a89ac25c207006d7a87c05198a9cb0.png)

随着星舰项目的不断推进，SpaceX正逐步实现其改变人类太空探索历史的愿景。星舰的未来测试将更加注重技术的完善和安全性的提升，为人类在太空的持续存在和探索开辟新的道路。
