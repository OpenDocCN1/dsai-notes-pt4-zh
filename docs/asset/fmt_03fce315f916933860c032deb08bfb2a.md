### Clawdbot 是什么？

Clawdbot 是由 @steipete (Peter Steinberger) 开发的一款开源个人 AI 助手，它具有以下特点：

+   **本地运行：** 在你的计算机上运行（支持 Mac, Linux, Windows, Raspberry Pi 或云端 VPS）。

+   **连接聊天应用：** 通过你已在使用的应用连接（WhatsApp, Telegram, Discord, iMessage, Slack）。

+   **全系统权限：** 拥有完整的系统访问权限（可执行终端命令、编写脚本、安装技能）。

+   **模型通用：** 使用任何 LLM 提供商（Claude, GPT, Gemini, DeepSeek, Perplexity）。

+   **持久记忆：** 保持持久记忆（跨会话记住所有内容）。

+   **自我进化：** 具备自我改进能力（可以通过与它交谈来增加新功能）。

+   **开源项目：** 拥有 9.7k GitHub 星标，1.3k 次 Fork。

**官方链接：**

+   网站: `https://clawd.bot`

+   GitHub: [`https://github.com/clawdbot/clawdbot`](https://github.com/clawdbot/clawdbot)

+   文档: `https://docs.clawd.bot`

+   X 账号: `https://x.com/clawdbot`

**为何流行：** 人们正在购买 Mac Mini 以便 24/7 全天候运行 Clawdbot，将其作为个人 AI 员工。

**病毒式传播原因：** 它让人感觉像是“未来”——一个真正能做事而不仅仅是聊天的 AI 助手。
