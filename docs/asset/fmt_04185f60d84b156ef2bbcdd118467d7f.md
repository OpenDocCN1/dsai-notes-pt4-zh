
# 医学研究的告知同意

> 来源：[https://docs.feishu.cn/docx/GZXNdVN78oWX35xawoccyCOZnDg](https://docs.feishu.cn/docx/GZXNdVN78oWX35xawoccyCOZnDg)

**问：**发现某公立医院抽血单子上有这样的告知，我被抽血的动作表示了我的同意？

**答1：**努力了，但不多。

**答2：**深圳医院的小程序会有告知。

**答3：**可能是35273给的勇气。但这个合法性基础未被《个保法》吸收，所以已经无效了。

> 以下情形中，个人信息控制者收集、使用个人信息不必征得个人信息主体的授权同意：……

> k) 个人信息控制者为学术研究机构，出于公共利益开展统计或学术研究所必要，且其对外提供学术研究或描述的结果时，对结果中所包含的个人信息进行去标识化处理的。

> 《个人信息安全规范》 5.6 征求授权同意的例外

**答4：**是单独告知了、有进步啊，但如何行使“不同意”的权利呢？

**答5：**医学教学和科学研究很难解释成解释成法定义务吧，得取得单独同意吧。比实际情况中大多数的简单粗暴直接使用的进步好多了，很多血液制品的实验室研究数据，细思极恐。

**答6：**《健康医疗数据安全指南》（GB/T 39725-2020）也有类似规定。

**答7：**考虑到这个是2020年国标，没有对齐《个人信息保护法》的规定，还是无法用作“合法性基础”啊，医院好难。

**答8：**我接触过的临床招募里面，一般知情同意书是伦理委员会要过模板的～有的会增加个保条款～还是会有同意

**答9：**《基本医疗卫生与健康促进法》的法律责任章节里只提到了告知义务，没有提到同意权或者选择权（当然不排除归在医学伦理规范里）。

![](img/9bcfec284f3376f143e57617ebd65556.png)

![](img/4f0708cfe01b1d86be27b7a6efb20e65.png)

**答10：**《基本医疗卫生与健康促进法》2020年6月生效，说了要“按规定履行告知”义务，但没有免除“同意”；个保法2021年11月生效。按照“新法优于旧法”原则，还是需要按照个保法要求找到“合法性基础”。

《基本医疗卫生与健康促进法》第32条规定“开展…医学研究应当…取得知情同意”，否定了还有其他合法性基础，那医院是不是还是按照“个保法”来开展医学研究更合适、能多一些合法性基础的选择项？

**答11：**应该是超出的；《基本医疗卫生与健康促进法》我理解不能提供合法性基础，但是第32条和第102条似乎构成了责任的分层（应当取得知情同意，但违反告知义务导致行政处罚），所以在实践层面，医院先保告知义务。

**答12：**最近，国家网信办和药监局一直在调研个人信息保护法和医药行业的法律法规及标准的冲突适用问题。

总结：没有“正当利益”这个合法性基础，还是比较麻烦的。
