# 机器人投资与行业动态

## 有哪些投资机构格外青睐机器人赛道？

贡献人：

`https://mp.weixin.qq.com/s/oHGfENAf-21ht5uwcjvnbQ`

近年来，中国机器人行业取得了显著进步，技术突破包括人工智能、感知技术、自主导航等。这些技术进步驱动了机器人行业的快速发展，吸引了资本的关注和投资。根据《2023-2024年中国机器人赛道投融资报告》，国内机器人行业在一级市场的融资情况经历了波动，但总体呈现出增长态势。尤其是在“非接触式”需求激增的背景下，服务机器人、仓储物流机器人、医疗机器人等领域的需求持续增长。2021年，国内机器人行业融资事件数量和总金额创下历年新高，其中涌现了多笔超十亿的大额融资事件。然而，2022至2023年，融资交易数量和金额再次下降，尤其是融资金额降幅较大。机器人行业的平均每笔融资金额自2019年开始增加，反映了市场对“明星”企业的资金集中投资。早期投资仍然是主流，但战略投资占比逐年增加。投资活动以人民币为主导，上海、广东、北京等地区是投资热点，其中以上海融资金额最高。奇绩创坛和清水湾资本等机构在2023年活跃度最高，主要投资于早期阶段的机器人公司。

## 机器人赛道很火，那么`VC`们把钱都投到哪些环节了？

贡献人:

`https://mp.weixin.qq.com/s/ruGsbip4PJizuz07jkFCoQ`

《2023-2024年中国机器人赛道投融资报告》展现了国内机器人行业投融资情况。行业技术进步带来资本的关注和投资。三大产业链环节（上游、中游、下游）投资分布不均，中游尤其是服务机器人和工业机器人领域依然是投资热点，反映了市场对机器人技术需求的持续增长和巨大潜力。不同细分赛道投资偏好也有所变化，医疗机器人领域的投融资比例明显增加，显示出投资者对医疗健康领域机器人应用前景的高期待。政策支持和行业创新推动了医疗机器人领域的发展。机器人行业融资情况呈现连续性和变化，投资者更趋向于关注技术成熟度和产品市场接受度，投资更趋向于理性。

## Cohere Command R Fine-Tuning: 技术细节

贡献人：

`https://cohere.com/blog/commandr-fine-tuning`

`Cohere`公司推出了`Command R`微调技术，该技术在企业级用例上表现出色，成本比市场上最大的模型低多达15倍。`Command R`是`Cohere R`系列模型中的较小版本，是一种可扩展的前沿大型语言模型（`LLM`），旨在面向企业级工作负载。微调允许企业将公司特定的语言和文档纳入其模型中，使其针对企业的独特需求高度定制。`Command R`与其他行业领先的模型相比，成本低廉，企业可以调整高达五个超参数，有效优化模型性能，同时成本仅为其他行业领先模型的十五分之一。

`Command R`模型在长文本任务上进行了优化，例如高级检索增强生成（`RAG`）以减轻引用与幻觉，工具使用以自动化复杂的业务工作流程，以及支持10种语言的多语言支持，以便轻松集成到全球业务运营中。与其他大型模型相比，该模型在高效性和强大的准确性之间取得平衡，使企业能够跨越概念验证，实现与`AI`的生产环境集成。`Command R`微调技术立即可供企业和开发人员使用，并可在`Cohere`平台上访问。

## `LLM`拒绝请求的机制分析

贡献人：

`https://www.alignmentforum.org/posts/jGuXSZgv6qfdhMCuJ/refusal-in-llms-is-mediated-by-a-single-direction`

这项研究探讨了大型语言模型（`LLM`）如何在微调过程中发展出拒绝有害指令的能力。研究发现，拒绝行为通过模型的“拒绝方向”来调控，这是残差流中的一个单一方向。通过操纵这一方向，可以影响模型的拒绝行为：移除该方向将阻止模型拒绝有害指令，而添加该方向则使模型错误地拒绝无害指令。这种发现为通过修改模型权重简单而有效地“越狱”提供了方法，这种方法无需细致调整或推断时干预，验证了我们对模型可解释性的理解，并展示了安全微调的脆弱性。

## 播客｜科技巨头们开始抢电？聊聊`AI`用电荒和核聚变创业热

贡献人：

`https://mp.weixin.qq.com/s/EeY-9jQBfnOTTvEN9hmbQw`

「`AI`用电荒」

1. `AI`耗电现状：美国的`AI`数据中心耗电量已经达到了纽约市的用电量，占美国总电量的2.5%。
2. 未来电力需求预测：预测显示，`AI`的用电量在未来几年内可能会翻倍，从目前占美国总电量的2.5%增长到7.5%或更高。
3. `AI`用电的特殊性和波动性：`AI`的用电特征与传统负载不同，会出现短时间内的剧烈波动，这对电网稳定性构成挑战。
4. 美国电力行业面临的挑战：未来三五年内，`AI`的增长可能会与居民用电需求产生冲突，导致电力短缺。
5. `AI`与能源转型的负担：`AI`的增长意外地加重了能源转型的负担，电力供应可能成为`AI`发展的瓶颈。
6. 硅谷公司数据中心布局：硅谷公司在短期内通过抢占现有电网容量来满足数据中心的电力需求，长期则考虑与电力公司合作，提前规划基础设施。
7. 中国电力供应结构：中国拥有多样化的发电方式和较好的基础设施建设能力，这为数据中心的建设和电力供应提供了优势。

「能源现状与解决办法」

1. 中国核能规划：中国的核能发展采取“三步走”策略，包括热堆、快堆和核聚变堆的发展。
2. 科技巨头的新难题：在发展`AI`的同时，科技巨头需要考虑气候变化问题，这增加了成本和复杂性。
3. `AI`能源消耗减少的可能性：随着`AI`训练数据的耗尽或`GPU`效率的提高，`AI`的能源消耗有可能减少。
4. 核能的潜力：核能，包括核裂变和核聚变，作为未来能源解决方案的潜力被对比分析。
5. 核裂变与核聚变的选择：核裂变技术相对成熟，但存在原材料和核废料处理问题；核聚变则被视为更清洁、更可持续的能源解决方案。
6. 核聚变发电的时间表：尽管科学问题已接近解决，但核聚变发电的商业化仍面临巨大的成本挑战。
7. `Helion Energy`与微软的对赌协议：`Helion Energy`承诺在2028年为微软提供50MW的电站，价格为每度电一美分。
8. 核聚变公司的流派：核聚变公司采取不同的技术路线，如托克马克和磁惯约束性聚变（`MIF`）。

「未来对策」

1. 数据中心选址问题：美国、中国和欧洲在数据中心选址时考虑数据资产和算力需求，如中国的“东数西算”工程。
2. 电网负担解决方案：能源转型和分布式储能是减轻电网负担的潜在解决方案。
3. `AI`与能源行业的互补：`AI`技术可以赋能核聚变和其他能源行业，帮助解决复杂的设计和调度问题。
