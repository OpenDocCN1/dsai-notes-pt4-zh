## 第二步：爆款题材与本地化创作技巧

### 3 大题材（国内玩剩，国外爆火）

> 划重点（要考的）

+ **节奏调整**：西方读者反感「开篇慢热」，前 3 章必须出现核心冲突（如「主角被背叛 + 获得金手指」）

+ **文化适配**：将「高考压力」改为「魔法学院考试」，「职场内卷」替换为「公会排名竞争」

+ **敏感内容**：避免涉及宗教冲突（如伊斯兰教地区禁用「猪」相关比喻）、种族歧视（角色肤色描写需中立）

#### 「换皮」修仙流

+ 核心逻辑：保留「升级打怪」框架，替换东方元素为西方奇幻设定。

+ 术语转换：

`筑基期` --> `Level 1 Mana Core`

`灵力` --> `Mana/Energy` --> Royal Road 评论区高频搜索词

`宗门` --> `Magic Guild` --> 符合西方「公会文化」认知

+ 成功案例：《Nanomancer Reborn - I've Become A Snow Girl?》在 Webnovel 女频总榜排名第一，评分 4.8/5，核心设定为「魔法核心升级」。

#### 狼人 / 吸血鬼 Romance

+ 痛点：欧美女性读者对「`Alpha` 男性 + 禁忌之恋」毫无抵抗力。

+ 公式：「霸道狼人总裁 × 平凡人类女主」+「月圆之夜变身」+「家族权力斗争」。

+ 数据：Chereads 平台 `Werewolf` 分类点击量占总 `Romance` 类目的 35%，相关作品平均收入比普通都市文高 2 倍。

#### LitRPG 系统流

+ 平台偏好：Scribble Hub 和 Royal Road 男性用户占比超 70%，对「属性面板 + 任务系统」极度痴迷。

+ 模板参考：

```
【系统提示】
任务：击杀 10 只哥布林
奖励：+5 力量，解锁技能「火球术」
失败惩罚：等级 - 1
```

### 新手首选 3 大平台入驻攻略

#### 1. GoodNovel（低门槛，适合短篇）

+ **注册流程**：

1. 官网提交 5000 字稿件→2. 编辑 72 小时内回复→3. 选择独家 / 非独家合约（独家分成更高）。

+ **签约福利**：

+ 3 万字达标获 $100 签约奖；

+ 月更 25 天 + 5 万字，额外 $150 更新奖。

+ **发布技巧**：标题含 `Billionaire`、`Werewolf` 等关键词，封面用橙红色调（数据显示点击率提升 27%）。

#### 2. Wattpad（社区流量，适合新人）

+ **冷启动策略**：

+ 发布前 3 章时，每章末尾加互动问题（如「女主该原谅渣男吗？评论区投票」）；

+ 加入 `#Wattys2025` 话题，参与平台征文大赛（获奖作品可获流量扶持）。

+ **收益关键点**：广告分成与「读者停留时间」挂钩，章节字数控制在 1500-2000 字（完读率最高）。

#### 3. Royal Road（硬核奇幻，适合慢热长篇）

+ **过稿秘诀**：

+ 世界观设定需详细（如魔法体系、种族分布），首章附「势力地图」；

+ 每周更新≥3 章，保持「连载稳定性」是上榜核心（前 100 名作品平均更新频率 4.2 章 / 周）。
