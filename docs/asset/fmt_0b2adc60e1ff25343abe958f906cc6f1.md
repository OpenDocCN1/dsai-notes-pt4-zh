
# MCP 服务管理（添加或删除）

帮我管理 MCP 服务（添加或删除）。

我会提供配置信息，格式如下：

```json
{
  "mcpServers": {
    "服务名": {
      "command": "命令",
      "args": ["参数列表"]
    }
  }
}
```

请你根据我的需求：

## 添加服务

1. 提取配置中的服务名、`command`、`args`
2. 转换成命令：`claude mcp add-json <服务名> '{"command": "xxx", "args": [...]}'`
3. 执行安装
4. 安装完成后测试是否可用

## 删除服务

使用命令：`claude mcp remove <服务名>`
