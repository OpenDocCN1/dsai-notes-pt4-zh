
# 邮件gateway在境外算数据出境吗

> 来源：[https://docs.feishu.cn/docx/DDRbdX6aEoNtqhxI8tec2mDun8b](https://docs.feishu.cn/docx/DDRbdX6aEoNtqhxI8tec2mDun8b)

**问**：在考虑统计出境数据时，如果email服务器部署在中国，但是邮件的gateway在境外，相当于email技术上会通过境外的gateway，但实质上不会被境外主体访问，这种因邮件部署出境的个人信息需要计入出境数量吗？

**答1：**盲猜一个，我感觉是要计入的，之前就网关这个问题请教过同事，我理解你们的场景技术上其实还是可以在网关查看所接收和分发的信息的

**答2：**“实质上不会被境外主体访问”，这个比较难证明和说明吧。结合此前群里讨论过的关于跨境的认定，即境内数据被境内的外国人访问应否认定为跨境的问题，您所说的这种情形被认定为跨境，更符合规定的情形吧。

**答3**：“数据出境”和“被境外主体访问”我理解是or的关系。两者符合其一即构成。
