## 7.1 多账号实操运营

+   一个身份证能实名两个账号认证，可以借用身边家人、朋友身份信息，进行多账号运营。
+   每个账号可以定位不同的垂直领域，避免产生同质化的内容
+   每个账号，可以创作同一领域不同类型的内容
+   字数控制在20-500以内。

## 7.2 用AI批量生产内容

+   想好账号的垂直领域后，给AI指定不同的提示词，从而得到不同领域，不同类型的内容，AI生成内容，人工最后审核一下，有时候AI会抽风给不对的内容。
+   可以给AI输入不同的语气口吻，让AI随机选择一种语气输出，但核心思想不能变，变的只是表达方式，比如措词激进、亢奋、平静等。
