回答：

用户反馈分显示反馈和隐性反馈：

+ 显示反馈：用户点赞、点踩、投诉或提交建议，但用户参与度低，仅在极不满意时反馈，后台日志量级小；
+ 隐性反馈：通过后台日志观察，如AI回答未说完被用户打断、跳出页面（说明回复不满足需求），上下文对话中用户吐槽蓝心小微，或用户让AI放歌却刚开头就中断（说明歌曲不符需求）。

提升bad case挖掘效率的思路：可基于模型优化，先训练专门模型，经监督微调、强化反馈学习链路后，让模型对日志中潜在负反馈做零样本/少样本挖掘，再由外聘人工标注员review，向模型反馈挖掘对错，经几轮迭代得到大量可用的隐性反馈；当时较有效的TOP2手段是“AI初步筛选+人工标注员复核”，且后台会聚合显示反馈的问题，直接用于策略。
