## 2️⃣ 📌 [Github 趋势榜第一！开源 Agent 开发神器，任意文档转 JSON、MD](https://mp.weixin.qq.com/s/uidETW3Uw8zMBQh41MG7xg)

IBM 开源的文档解析工具 Docling 登上 Github 趋势榜首，支持将多种格式文档转换为 JSON 和 Markdown。

Docling 具备多格式支持、OCR 能力、页面布局/表格还原、与 LLM 集成和简单易用等特点。

通过几个简单的代码行，Docling 能够处理 PDF、DOCX、PPT 等多种格式文档，适用于企业级搜索、Agent 开发和 RAG 场景。

实测显示，Docling 在表格还原度上表现优异，尽管在复杂排版处理上存在小瑕疵，但总体效果令人满意。

Docling 的性能报告显示，处理速度和稳定性符合实际生产环境的需求，尤其在非扫描件和不开启 OCR 的情况下解析速度更快。

关键词：文档解析，Docling，JSON，Markdown，Agent 开发

## 3️⃣ 🤖 刚刚，OpenAI Agent 来了！

OpenAI Agent的推出标志着AI智能体可以24/7全天候工作，执行定时任务。

用户可以设定ChatGPT在特定时间完成一次性或周期性任务，如监控股票价格、撰写科幻故事等。

通过GPT-4o模型，用户可以在ChatGPT界面设定任务，并通过网页和应用推送通知。

ChatGPT有10个活跃任务的限制，超出则需暂停或删除现有任务。

该功能目前仅对ChatGPT Plus、Team和Pro用户开放，且不支持语音聊天、文件上传等。

关键词：AI智能体，定时任务，ChatGPT，GPT-4o，用户体验

## 6️⃣ 🧬🎯 [扩散模型也能推理时Scaling](https://mp.weixin.qq.com/s/kQPU93QOh2Gmr1yx4uFiiw)，谢赛宁团队重磅研究可能带来文生图新范式

谢赛宁团队研究扩散模型推理时scaling，发现增加推理时间计算能显著提高样本质量。

研究提出了一个基础框架，通过搜索去scaling NFE，在多种生成任务和模型规模上带来改进。

确定了验证器和算法两个关键设计轴，分析了不同验证器与生成任务的匹配度。

论文表明，推理时计算预算影响scaling性能，为文生图领域带来新的研究方向。

研究还探讨了搜索算法和验证器在实际应用中的有效性，以及推理计算在不同维度上的效果。

关键词：扩散模型，推理时scaling，生成任务，验证器，算法
