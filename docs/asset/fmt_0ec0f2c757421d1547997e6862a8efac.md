`Agent`作为一种智能系统，能够利用其深厚的语言理解和生成能力，帮助你解决各种问题，从技术支持到创意激发，再到信息搜集。它的灵活性使得它适用于多种场景，无论是研究、写作、教育还是娱乐。通过与`agent`互动，你将体验到智能和效率。本系列文章参考`langchain`官方文档，带领大家一起学习`agent`的基础知识，探索基于`agent`的高级应用，为你打开人工智能之门。

为了更好地理解`agent`框架，我们创建带2个工具的`agent`：一个工具用于在线搜索，另一个工具查询已经加载到索引里的特定数据。

## 设置：`LangSmith`

根据定义，`agent`在返回面向用户的最终输出之前，会采取一系列自决策、输入依赖的步骤。这使得调试`agent`变得特别棘手，而可观察性变得尤为重要。只需要设置有关`LangSmith`的以下环境变量，就可以自动跟踪所有步骤：

```
export LANGCHAIN_TRACING_V2="true"
export LANGCHAIN_API_KEY="<your-api-key>"
```

## 定义工具

首先创建要使用的两个工具：`Tavily`（在线搜索）和基于本地索引的检索器。

### Tavily

在`LangChain`中有内置工具可以轻松使用`Tavily`搜索引擎作为工具。要注意的是，使用`Tavily`需要API密钥-它们有免费额度，但如果你没有或不想创建，则可以忽略此步骤。

当创建API key后，需要按照下面的方式导入：

```
export TAVILY_API_KEY="..."

from langchain_community.tools.tavily_search import TavilySearchResults

search = TavilySearchResults()
search.invoke("what is the weather in SF")
```

### Retriever

在我们自己的一些数据上创建`retriever`。

```
from langchain_community.document_loaders import WebBaseLoader
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

loader = WebBaseLoader("https://docs.smith.langchain.com/overview")
docs = loader.load()
documents = RecursiveCharacterTextSplitter(
    chunk_size=1000, chunk_overlap=200
).split_documents(docs)
vector = FAISS.from_documents(documents, OpenAIEmbeddings())
retriever = vector.as_retriever()

retriever.get_relevant_documents("how to upload a dataset")[0]
```

我们可以很容易地将检索器转换为工具（正确使用`agent`所需的格式）

```
from langchain.tools.retriever import create_retriever_tool

retriever_tool = create_retriever_tool(
    retriever,
    "langsmith_search",
    "Search for information about LangSmith. For any questions about LangSmith, you must use this tool!",
)
```

### 工具

现在我们已经创建了两个工具，然后创建工具列表用于下游任务。

```
tools = [search, retriever_tool]
```

## 创建`Agent`

既然已经定义了工具，接下来就可以创建`agent`了。我们将使用`OpenAI Function agent`，有关该类型`agent`的更多信息，以及其他可选`agent`，请参阅 指南。

首先，选择想要引导`agent`的LLM。

```
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)
```

接下来，选择要用于引导`agent`的prompt。如果想查看此prompt的内容并访问`LangSmith`，你可以访问 https://smith.langchain.com/hub/hwchase17/openai-functions-agent

```
from langchain import hub

# Get the prompt to use - you can modify this!
prompt = hub.pull("hwchase17/openai-functions-agent")
prompt.messages
```

prompt内容

```
[SystemMessagePromptTemplate(prompt=PromptTemplate(input_variables=[], template='You are a helpful assistant')),
 MessagesPlaceholder(variable_name='chat_history', optional=True),
 HumanMessagePromptTemplate(prompt=PromptTemplate(input_variables=['input'], template='{input}')),
 MessagesPlaceholder(variable_name='agent_scratchpad')]
```

现在，我们可以使用LLM、`prompt`和工具初始化`agent`。`agent`负责接收输入并决定要采取的动作。至关重要的是，`Agent`不执行这些操作——这是由`AgentExecutor`完成的（下一步）。有关如这些组件的更多信息，请参阅 概念指南。

```
from langchain.agents import create_openai_functions_agent

agent = create_openai_functions_agent(llm, tools, prompt)
```

最后，我们将`agent`（大脑）与`AgentExecutor`内部的工具（它将重复调用`agent`并执行工具）相结合。

```
from langchain.agents import AgentExecutor

agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
```

## 运行`Agent`

现在可以对一些query运行`agent`！请注意，目前这些都是无状态查询（不会记住以前的交互）。

```
agent_executor.invoke({"input": "hi!"})
```

中间过程

```
> Entering new AgentExecutor chain...
Hello! How can I assist you today?

> Finished chain.
```

输出结果

```
{'input': 'hi!', 'output': 'Hello! How can I assist you today?'}
```

```
agent_executor.invoke({"input": "how can langsmith help with testing?"})
```
