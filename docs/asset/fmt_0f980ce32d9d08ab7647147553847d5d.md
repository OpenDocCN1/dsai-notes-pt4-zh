
# 产品部/产品管理部（PMO） OpenClaw 应用场景及对应Skills分析报告

## 一、部门核心定位

产品部/产品管理部（PMO，Project Management Office）是企业产品规划、项目管控、需求落地、迭代优化的核心职能部门，直接向高层管理层负责，承担着产品战略规划、需求管理、项目统筹、产品迭代、落地交付等核心职责。两个部门职能高度协同、各有侧重：产品部聚焦产品本身的规划、设计、迭代与优化，聚焦“做正确的产品”；产品管理部（PMO）聚焦产品相关项目的统筹管控、流程规范、资源协调与落地交付，聚焦“正确地做产品”，共同构成企业产品从规划到落地的完整管理体系。该部门工作兼具极强的专业性、系统性与落地性，核心特点是“需求驱动、项目闭环、迭代优化、价值导向”，主要负责产品规划、项目管控、需求落地等工作，是保障产品有序推进、实现产品价值、提升企业核心竞争力的核心支撑部门，也是OpenClaw落地适配的重点产品管理类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按产品部/产品管理部（PMO）日常工作高频度、刚需度排序，兼顾两个部门职能共性，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合产品规划、项目管控与需求落地需求，无需额外定制开发，零基础可快速落地，兼顾专业性、实用性与高效性，适配两个部门的日常工作场景。

### （一）产品规划与战略类（核心职能场景）

**场景核心内容**：作为产品部/PMO的核心工作，负责企业产品战略规划、产品路线图制定与产品定位，确保产品发展贴合企业战略与市场需求，具体包括：

+ 产品战略规划、中长期产品发展规划的撰写与落地推进；
+ 产品路线图制定、产品版本规划，明确各阶段产品发展目标；
+ 市场调研、用户需求分析，结合行业趋势制定产品定位与优化方向；
+ 产品规划复盘、效果评估，结合市场变化与用户反馈优化产品战略。

**应用价值**：实现产品规划标准化、战略落地规范化，明确产品发展方向与阶段目标，减少产品规划的盲目性，确保产品贴合市场需求与企业战略，为产品落地与迭代提供清晰指引，提升产品核心竞争力。

对应OpenClaw Skills：

+ `product-strategy`（产品战略规划、中长期发展规划撰写）；
+ `product-roadmap`（产品路线图制定、产品版本规划）；
+ `market-research`（市场调研、用户需求分析与产品定位）；
+ `strategy-review`（产品规划复盘、效果评估与战略优化）。

### （二）需求管理类（核心执行场景）

**场景核心内容**：负责产品全生命周期需求的收集、梳理、分析与管控，确保需求贴合用户需求与产品目标，具体包括：

+ 用户需求、市场需求、业务需求的收集、整理与分类归档；
+ 需求分析、需求优先级排序，撰写需求规格说明书（PRD）；
+ 需求变更管理、需求落地跟踪，及时同步需求变更信息至相关部门；
+ 需求复盘、需求效果评估，优化需求管理流程，提升需求质量。

**应用价值**：实现需求管理标准化、流程化，提升需求收集与分析效率，明确需求优先级，减少需求变更带来的内耗，确保需求落地贴合产品目标与用户需求，提升产品用户体验。

对应OpenClaw Skills：

+ `requirement-collection`（各类需求收集、整理与分类归档）；
+ `requirement-analysis`（需求分析、优先级排序与PRD撰写）；
+ `requirement-change`（需求变更管理、变更同步与管控）；
+ `requirement-review`（需求复盘、效果评估与流程优化）。

### （三）项目统筹与管控类（核心攻坚场景）

**场景核心内容**：负责产品相关项目的统筹规划、进度管控、资源协调与落地交付，确保项目按时、按质、按量完成，具体包括：

+ 产品项目计划制定、项目任务分解、责任分工与时间节点明确；
+ 项目进度监控、风险排查，及时解决项目推进中的问题；
+ 项目资源协调（人力、物力、技术），推动跨部门（研发、测试、运营）协同；
+ 项目复盘、交付评估，总结项目经验，优化项目管理流程。

**应用价值**：实现产品项目管理标准化、闭环化，提升项目推进效率与管控水平，减少项目延期、资源浪费等问题，确保项目按时交付，降低项目管理成本，提升跨部门协同效率。

对应OpenClaw Skills：

+ `project-planning`（产品项目计划制定、任务分解与分工）；
+ `project-monitoring`（项目进度监控、风险排查与问题解决）；
+ `resource-coordination`（项目资源协调、跨部门协同推进）；
+ `project-review`（项目复盘、交付评估与流程优化）。

### （四）产品迭代与优化类（核心落地场景）

**场景核心内容**：负责产品全生命周期的迭代规划、优化升级与效果跟踪，持续提升产品价值与用户体验，具体包括：

+ 产品迭代计划制定、迭代功能规划，明确迭代目标与时间节点；
+ 迭代过程跟踪、功能测试对接，确保迭代功能符合需求规范；
+ 产品上线后的数据跟踪、用户反馈收集，分析迭代效果；
+ 产品优化方案撰写、落地推进，持续优化产品功能与用户体验。

**应用价值**：实现产品迭代标准化、高效化，提升迭代推进效率，确保迭代功能贴合用户需求，持续优化产品体验与产品价值，增强产品市场竞争力，提升用户粘性。

对应OpenClaw Skills：

+ `product-iteration`（产品迭代计划制定、迭代功能规划）；
+ `iteration-tracking`（迭代过程跟踪、测试对接与管控）；
+ `data-tracking`（产品上线后数据跟踪、用户反馈收集）；
+ `product-optimization`（产品优化方案撰写、落地推进）。

### （五）产品文档与交付类（核心保障场景）

**场景核心内容**：负责产品相关文档的撰写、整理、归档与交付，确保产品文档规范、完整、可追溯，具体包括：

+ 需求规格说明书（PRD）、产品原型说明、用户手册的撰写与修订；
+ 产品相关文档（项目计划、测试报告、迭代报告）的整理与归档；
+ 产品交付文档的准备、审核与交付，配合相关部门完成交付验收；
+ 产品文档更新、版本管理，确保文档与产品实际情况一致。

**应用价值**：实现产品文档标准化、规范化管理，确保文档完整、可追溯，减少文档撰写与整理耗时，为研发、测试、运营等部门提供清晰指引，保障产品交付顺利推进。

对应OpenClaw Skills：

+ `product-document`（PRD、用户手册、原型说明撰写与修订）；
+ `document-archive`（产品相关文档整理、归档与版本管理）；
+ `delivery-document`（产品交付文档准备、审核与交付）；
+ `document-update`（产品文档更新、同步与管控）。

### （六）跨部门协同与沟通类（基础支撑场景）

**场景核心内容**：负责产品相关跨部门协同、沟通对接，推动各部门高效配合，确保产品落地与迭代顺利推进，具体包括：

+ 与研发、测试、运营、市场等部门的日常沟通对接，同步产品需求与项目进度；
+ 跨部门协同会议策划、会议纪要撰写，推动协同问题解决；
+ 产品相关信息同步、需求传达，确保各部门对产品目标与要求认知一致；
+ 跨部门协同效果评估，优化协同流程，提升协同效率。

**应用价值**：打破跨部门协同壁垒，减少沟通成本与协同内耗，确保各部门高效配合，推动产品需求落地、项目推进与迭代优化，提升整体工作效率。

对应OpenClaw Skills：

+ `cross-department-communication`（跨部门日常沟通对接、信息同步）；
+ `coordination-meeting`（跨部门协同会议策划、会议纪要撰写）；
+ `demand-communication`（产品需求传达、认知同步）；
+ `coordination-evaluation`（跨部门协同效果评估、流程优化）。

### （七）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责部门各类产品、项目相关文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+ 部门工作总结、工作计划、工作汇报、产品简报的撰写与规范；
+ 产品台账、项目台账、需求台账、迭代台账的整理与更新；
+ 部门内部通知、会议纪要、产品培训材料的起草与分发；
+ 产品相关公文、跨部门沟通函件、交付对接材料的起草与规范。

**应用价值**：实现产品管理部门文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率与跨部门沟通效率，保障产品规划、项目管控、需求落地工作有序推进。

对应OpenClaw Skills：

+ `work-summary`（部门工作总结、工作计划、工作汇报撰写）；
+ `ledger-manage`（各类产品、项目、需求台账建立与更新）；
+ `meeting-minutes`（部门会议纪要、产品简报起草）；
+ `official-doc`（产品相关公文、沟通函件撰写）。
