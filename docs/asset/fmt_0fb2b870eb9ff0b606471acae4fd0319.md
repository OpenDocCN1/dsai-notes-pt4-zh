## 五. 推荐一个开源的论文阅读神器模板

这个模版是我前几天刚开始学习使用飞书多维表格的AI工作流的时候了解到的，感觉十分惊艳，在此推荐一下。

+   这是一位香港教育大学的博士生搭建的模版，行文至此时，打开📕，刚好刷到了这位博士的📕账号，昵称是Cynthia的学术世界，主页有视频，可以去看看原视频，可以学习一下这个工作流的搭建思路，并迁移到自己的应用里面去。

+   只要在飞书多维表格新增一行，然后上传一篇论文的pdf，两分钟即可实现结构化的文献速读，每上传一篇，就得到准确率很高的结构化论文解读

+   飞书表格可以支持很多很多行，那么上传了多篇之后，就成了一个结构清晰的论文知识库

![](img/71efcb2fc426a9c645a189d794fe8552.png)

### 1. 唯一需要人工操作的步骤：上传PDF文献

+   操作：将需要阅读的文献以PDF格式上传到飞书多维表格中。这是整个流程的第一步，也是唯一需要人工操作的步骤

![](img/a8a05e841708939907708c513892a23a.png)

### 2. AI工作流启动

+   先用kimi从`附件`这一列的pdf中提取摘要

![](img/ec58a87c0cc2241887a1a276a89e1c59.png)

![](img/efa92470cceca66a6c42102981eda55c.png)

+   然后用Kimi阅读助手字段捷径，从PDF中提取理论机制、理论贡献、研究设计、核心发现等信息

+   还有利用总结这个字段捷径得到论文的总结
