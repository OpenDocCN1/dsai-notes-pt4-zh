
Transformers 已成为现代深度学习的基石。传统上，这些模型依赖多层感知器（MLP）层在通道之间混合信息。本文介绍了一种新颖的架构——Kolmogorov-Arnold Transformer (KAT)，用 Kolmogorov-Arnold 网络 (KAN) 层替换了 MLP 层，从而增强了模型的表达能力和性能。然而，将 KAN 集成到 Transformers 中并非易事，特别是在扩展时。具体来说，本文识别了三个关键挑战：(C1) 基础函数。KAN 中使用的标准 B 样条函数未针对现代硬件上的并行计算进行优化，导致推理速度变慢。(C2) 参数和计算效率低下。KAN 为每个输入输出对需要一个独特的函数，导致计算量极大。(C3) 权重初始化。由于 KAN 中的可学习激活函数，权重初始化非常具有挑战性，而激活函数对深度神经网络的收敛至关重要。为了解决上述挑战，本文提出了三个关键解决方案：(S1) 有理基。使用有理函数取代 B 样条函数，以提高与现代 GPU 的兼容性。通过在 CUDA 中实现这一点，实现了更快的计算速度。(S2) 组 KAN。通过一组神经元共享激活权重，以减少计算负担而不牺牲性能。(S3) 保持方差的初始化。仔细初始化激活权重，确保跨层的激活方差保持不变。通过这些设计，KAT 能够有效扩展，并轻松超越基于传统 MLP 的 Transformers。

![](img/f8f93595f2e1a51f3d44a181f67e4962.png)

## LLMs + Persona-Plug = 个性化LLMs

贡献人：

链接：`https://arxiv.org/abs/2409.11901`

个性化在众多语言任务和应用中起着至关重要的作用，因为即使具有相同需求的用户也可能根据其个人兴趣偏好不同的输出。这促使了各种个性化方法的发展，旨在使大型语言模型（LLMs）生成符合用户偏好的定制化输出。其中一些方法涉及为每个用户微调一个独特的个性化 LLM，但这种方法对于广泛应用来说成本过高。替代方法是通过检索用户的相关历史文本作为示例，采用“即插即用”的方式引入个性化信息。然而，这种基于检索的策略可能会打断用户历史的连贯性，无法捕捉用户整体的风格和模式，导致次优性能。为了解决这些问题，本文提出了一种新颖的个性化 LLM 模型。该模型通过一个轻量级的插件式用户嵌入模块，建构每个用户的专属嵌入，模型通过建模用户所有的历史上下文来实现。通过将这种嵌入附加到任务输入中，LLMs 能够更好地理解并捕捉用户的习惯和偏好，从而无需调整其自身参数就能生成更个性化的输出。在语言模型个性化（LaMP）基准上的多项任务实验表明，所提出的模型显著优于现有的个性化 LLM 方法。

![](img/6c8da66e51b0990349e50cfd23db7aad.png)

## To CoT or not to C oT? CoT主要对数学和符号推理有帮助

贡献人：

链接：`https://arxiv.org/abs/2409.12183`

通过提示进行链式思维（CoT）是从LLMs中激发推理能力的默认方法。但是，这种额外的“思考”对于哪些类型的任务真正有帮助呢？为了分析这个问题，本文对100多篇使用CoT的论文进行了定量元分析，并对14种模型的20个数据集进行了自己的评估。研究结果表明，CoT主要在涉及数学或逻辑的任务上表现出较强的性能优势，在其他类型的任务上的提升要小得多。在MMLU上，不使用CoT直接生成答案的准确率与使用CoT的准确率几乎相同，除非问题或模型的响应包含等于号，这表明存在符号运算和推理。在此基础上，本文分析了CoT在这些问题上的行为，通过分离规划和执行，并将其与工具增强的LLM进行比较。CoT的大部分提升来自改善符号执行，但在使用符号求解器方面表现不佳。研究结果表明，CoT可以有选择地应用，在保持性能的同时节省推理成本。此外，结果还表明有必要超越基于提示的CoT，转向新的范式，以便更好地利用中间计算，以适应LLM应用的整个范围。

## 量化指令优化大语言模型的全面评估

贡献人：

链接：`https://arxiv.org/abs/2409.11055`

以往的研究工作仅使用如perplexity或少数基本知识任务等有限的度量标准，以及一些旧的数据集来评估量化LLMs的表现。此外，尚未对最近推出的最大规模模型（如Llama 3.1，高达405B）进行彻底的评估。本文评估了在7B至405B范围内的各种量化方法（GPTQ、AWQ、SmoothQuant和FP8）对指令优化LLMs（指令优化LLMs）的性能。使用13个基准测试，评估了6种任务类型的性能：常识问答、知识与语言理解、指令遵循、幻觉检测、数学和对话。主要发现是：(1) 将更大的LLM量化到与较小的FP16 LLM相似的大小时，通常在大多数基准测试中表现更好，除了幻觉检测和指令遵循；(2) 性能随不同的量化方法、模型大小和位宽而显著变化，权重仅方法通常在较大模型中产生更好的结果；(3) 任务难度对由于量化引起的精度下降影响不大。(4) MT-Bench评估方法在区分近期表现优异的LLMs方面具有有限的鉴别能力。

## GRIN: GRadient-INformed MoE

贡献人：

链接：`https://arxiv.org/abs/2409.12136`

专家混合（Mixture-of-Experts, MoE）模型通过专家路由实现稀疏计算，相较于密集模型，它们在扩展上更为有效，因为仅激活了一小部分专家模块。然而，稀疏计算给传统的训练方法带来了挑战，因为离散的专家路由阻碍了标准的反向传播，从而影响基于梯度的优化，而梯度优化是深度学习的核心。为了更好地实现MoE的扩展能力，我们引入了GRIN（梯度指导的MoE训练），该方法结合了稀疏梯度估计来进行专家路由，并配置了模型并行性以避免token丢失。在自回归语言建模中应用GRIN，我们开发了一个top-2的16×3.8B MoE模型。该模型仅激活了6.6B的参数，但其表现超越了7B的密集模型，并匹敌使用相同数据训练的14B密集模型。在多种任务上的广泛评估显示，GRIN显著提升了MoE的效能，分别在MMLU、HellaSwag、HumanEval和MATH上取得了79.4、83.7、74.4和58.9的成绩。
