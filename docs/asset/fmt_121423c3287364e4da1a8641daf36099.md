## 自己创建 Skills

### 对话创建一个清理缓存 Skills

直接和`TRAE`说话，AI帮你生成`Skill`也是可以的：

比如阿星经常`mac`内存满满的，所以每次都要手动清理资源库的缓存`Caches`文件夹，所以你干脆直接把这个文件夹的地址复制下来，让`skills`记住。

![](img/6679bcef80488a936b0e6ad0566944bb.png)

```
"创建一个Skill，自动清理/Users/xingyang/Library/Caches目录下的文件到回收站"
```

直接发它就开始给你匠心制作了😂

![](img/5501b3f5cbac8f33e56130119095e23e.png)

它自己立马对清理缓存这个`skills`进行了详细描述

```
# 缓存清理器

## 功能描述

此技能可以自动清理 /Users/xingyang/Library/Caches 目录下的所有文件和子目录，并将它们移动到回收站，而不是直接删除，以确保数据安全。

## 适用场景

- 系统磁盘空间不足时
- 应用程序运行缓慢，怀疑缓存过多时
- 定期维护系统，保持系统清洁时
- 用户明确要求清理缓存目录时

## 使用方法

当用户提到以下内容时，应调用此技能：
- "清理缓存"
……

# 计算清理前的空间

initial_space=$(du -sh /Users/xingyang/Library/Caches 2>/dev/null | cut -f1)

……

```

![](img/b14d3123dfd3da25ae419d0ae4785070.png)

![](img/d02bf7c666bb2f2e1a7964f8e8fe802f.png)

它会老老实实告诉你项目里的执行代码和你之后用什么命令唤醒它！
它已经给你放到文件夹里了
直接告诉他清理缓存即可，我每次大概能清理个3个G。

### 手动创建一个优化提示词 Skills

阿星平常最常用的还有`EARS`简易需求语法开发提示词，让普通提示词瞬间变得专业。

它的原理长这样，每次`ai coding`的时候我都要重新说一遍，干脆用`Trae` `skills`封装成固定工作流就可以了。

```
需求陈述： <这里写你的需求>

梳理以上需求，使用EARS（简易需求语法）对需求进行精确改写； 

识别需求所属领域，请找到能处理相关任务相关领域的成熟理论； 

提取需求陈述中提供的示例，

按如下格式构造能够引导大语言模型更高质量完成任务的增强提示词：

role

[根据具体需求填入相应的专业角色定位]

goals/skills

[列出该角色应具备的核心目标和技能]

workflows

[描述完成任务的具体工作流程步骤]

examples

[从需求陈述中提取的具体示例]

formats

[指定输出的具体格式要求]
```
