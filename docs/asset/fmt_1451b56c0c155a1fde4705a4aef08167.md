
# 构建可运行的Agent

```python
from langchain.agents.output_parsers import XMLAgentOutputParser

# Logic for going from intermediate steps to a string to pass into model
# This is pretty tied to the prompt
def convert_intermediate_steps(intermediate_steps):
    log = ""
    for action, observation in intermediate_steps:
        log += (
            f"<tool>{action.tool}</tool><tool_input>{action.tool_input}</tool_input>"
            f"</tool_input><observation>{observation}</observation>"
        )
    return log


# Logic for converting tools to string to go in prompt
def convert_tools(tools):
    return "\n".join([f"{tool.name}: {tool.description}" for tool in tools])
```

构建可运行的`agent`通常涉及以下几个方面：

1. 中间步骤的数据处理。这些步骤需要以语言模型可以识别的方式表示，应该与`prompt`中的指令紧密地耦合。

1. `prompt`本身。

1. 模型，如果需要的话，要包括停止标记。

1. 输出解析器 - 应该与`prompt`指定的格式一致。

```python
agent = (
    {
        "input": lambda x: x["input"],
        "agent_scratchpad": lambda x: convert_intermediate_steps(
            x["intermediate_steps"]
        ),
    }
    | prompt.partial(tools=convert_tools(tools))
    | llm.bind(stop=["</tool_input>", "</final_answer>"])
    | XMLAgentOutputParser()
)

agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
agent_executor.invoke({"input": "what is LangChain?"})
```

## JSON Chat Agent

有些语言模型在编写JSON方面表现特别出色。该`agent`使用JSON格式化其输出，以便支持聊天模型。

### 安装依赖

```python
from langchain import hub
from langchain.agents import AgentExecutor, create_json_chat_agent
from langchain_community.tools.tavily_search import TavilySearchResults
from langchain_openai import ChatOpenAI
```

### 初始化工具

```python
tools = [TavilySearchResults(max_results=1)]
```

### 创建Agent

```python
# Get the prompt to use - you can modify this!
prompt = hub.pull("hwchase17/react-chat-json")

# Choose the LLM that will drive the agent
llm = ChatOpenAI()

# Construct the JSON agent
agent = create_json_chat_agent(llm, tools, prompt)
```

### 运行Agent

```python
# Create an agent executor by passing in the agent and tools
agent_executor = AgentExecutor(
    agent=agent, tools=tools, verbose=True, handle_parsing_errors=True
)
agent_executor.invoke({"input": "what is LangChain?"})
```

### 使用聊天历史

```python
from langchain_core.messages import AIMessage, HumanMessage

agent_executor.invoke(
    {
        "input": "what's my name?",
        "chat_history": [
            HumanMessage(content="hi! my name is bob"),
            AIMessage(content="Hello Bob! How can I assist you today?"),
        ],
    }
)
```

### 使用聊天历史

```python
# Get the prompt to use - you can modify this!

# Construct the ReAct agent
agent = create_react_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

from langchain_core.messages import AIMessage, HumanMessage

agent_executor.invoke(
    {
        "input": "what's my name? Only use a tool if needed, otherwise respond with Final Answer",

    }
)
```

## Self-ask with search

本节展示如何使用搜索`agent`实现自问自答。

### 安装依赖

```python
from langchain import hub
from langchain.agents import AgentExecutor, create_self_ask_with_search_agent
from langchain_community.llms import Fireworks
from langchain_community.tools.tavily_search import TavilyAnswer
```

### 初始化工具

我们将初始化想要使用的工具，它提供答案（而不是文档）。

该`agent`只能使用一个工具，并且它的名称必须为`Intermediate Answer`。

```python
tools = [TavilyAnswer(max_results=1, name="Intermediate Answer")]
```

### 创建Agent

```python
# Get the prompt to use - you can modify this!
prompt = hub.pull("hwchase17/self-ask-with-search")

# Choose the LLM that will drive the agent
llm = Fireworks()

# Construct the Self Ask With Search Agent
agent = create_self_ask_with_search_agent(llm, tools, prompt)
```

### 运行Agent

```python
# Create an agent executor by passing in the agent and tools
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
agent_executor.invoke(
    {"input": "What is the hometown of the reigning men's U.S. Open champion?"}
)
```

## OpenAI assistants

[Assistants API](https://link.zhihu.com/?target=https%3A//platform.openai.com/docs/assistants/overview)允许用户在自己的应用中构建AI助手。`Assistant`具有指令，并可以利用模型、工具和知识来响应用户查询。`Assistant API`目前支持三种类型的工具：代码解释器（Code Interpreter）、检索（Retrieval）和函数调用（Function calling）。

你可以使用OpenAI工具或自定义工具与`OpenAI Assistant`进行交互。当仅使用OpenAI工具时，可以直接调用`Assistant`并获得最终答案。当使用自定义工具时，可以用内置的`AgentExecutor`或者自定义的执行器运行`Assistant`和工具执行循环。

下面展示与`Assistant`进行交互的不同方式。作为一个简单的例子，我们构建一位可以编写和运行代码的数学辅导员。

### 仅使用OpenAI工具

```python
from langchain.agents.openai_assistant import OpenAIAssistantRunnable

interpreter_assistant = OpenAIAssistantRunnable.create_assistant(
    name="langchain assistant",
    instructions="You are a personal math tutor. Write and run code to answer math questions.",
    tools=[{"type": "code_interpreter"}],
    model="gpt-4-1106-preview",
)
output = interpreter_assistant.invoke({"content": "What's 10 - 4 raised to the 2.7"})
```
