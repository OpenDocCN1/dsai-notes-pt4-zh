## 第一、建立飞书多维表格

首先，咱们先打开飞书文档的主页，然后点击：多维表格--新建多维表格。

![](img/665649b5c38e6291b7f6824c9b95d92d.png)

接着先把所有的表格给删除，方便我们创建新的单元分列。

![](img/7113ad6b494c3e942dffb6ddd4de9c6e.png)

多余的删除完之后就是下面这样的状态。

![](img/8812cac4c18fd7eb67240ed4e65cc5ab.png)

接下来，咱们分别按照顺序创建：

1. 分镜序号
2. 原始分镜图片
3. 画面描述词
4. 静态分镜图片
5. 动态视频提示词
6. 动态视频

首先，咱们先来创建第一个分镜序号（类型：编号）

右键点击文本，然后选择：**修改字段**

![](img/0ac8c8689b0c5c7669a93a440800cc66.png)

上一步做完之后，再点击：文本。

这个时候会弹出分栏，我们选择自动编号。

这样就不需要在后续制作过程中不用再手动填写数字。

![](img/44e7e094a28bc84afa2cd68d4d19dd30.png)

选择完自动编号之后，下一行有编号类型，

咱们选择自增数字。

![](img/8525c16cfeda46b6e7962d92cf43e989.png)

这一个分列创建好之后，

开始创建原始分镜图（类型：附件）

点击表格旁边的+号，然后选择文本--附件

这一步就算完成了

![](img/e8431ec46cf2134db755f3daab5d8f94.png)

后面的分列都按照刚才的方式分别创建

静态图提示词（类型：文本）

静态分镜图片（类型：附件）

动态视频提示词（类型：文本）

动态视频（类型：附件）

下面就是我创建好的模板

![](img/ad81dcde3d6846f70a4e7dca76a999bf.png)

这一步做完之后，紧接着就到了最关键的时候，选择添加字段捷径，

没有这一步就没有办法用AI工具。

## 第二、逐个添加字段捷径

以下这些表格需要添加的字段捷径对应的AI工具

1. 静态图提示词（文本）的字段捷径是AI图片理解

2. 静态分镜图片（附件）的字段捷径是AI生图

3. 动态视频（类型：附件）的字段捷径是AI视频生成

咱们在添加的时候，一定要注意不能添加错，

不然在下一步在火山方舟创建大模型API的时候对不上号。

首先咱们先在需要添加字段捷径的分列上右击选择修改字段。

![](img/f8bb806f94fb6f42078fdcad79234acd.png)

接着咱们在文本下方选择探索字段捷径，

然后在放大镜的后面搜索：**图片理解**

再接着选择：**AI图片理解（豆包）**

这里我比较推荐用豆包，

因为使用方便

同时大家也能看到有其他的字段捷径，

但是目前不知道如何开通API

豆包只需要用火山引擎就可以开通

同时，豆包的图片理解程度比较高。

对比下面的Kimi（图片理解）就远不如豆包。

![](img/8f0dd5e88daf7d294b59c67bb17f3fde.png)

字段捷径选择完之后，

咱们紧接着下拉列表

在原图这一栏选择原始分镜图。

这样我们上传的图片再加上一个提示词模板，

就能够直接被豆包进行图片分析，

写出相类似的提示词。

![](img/0ad1bd33c589415ee29143ab00c86c62.png)

上一步做完之后，

在原图这个分栏的下方有一个自定义指令，

这里相当于提示词的填写。

![](img/fb96b01e507e1a030f6238f7c5d5e1a1.png)

我把自己经过多次迭代，出图相对比较精准的提示词分享给你：

```
**请**反推这张图的静态图分镜提示词，具体的描述这图片的镜头视角、景别、图片风格、图片比例、图片背景、人物道具外观形象、人物站位、动作和画面的描述。反推提示词的时候把图片中的文案给去掉。
提示词格式模板如下：
镜头视角；景别；图片风格；图片比例9:16；图片背景；人物道具外观形象：年龄、性别，国籍，发型、穿着；人物站位画面构图；人物动作描述；画面描述
```

这个提示词可能在实际使用过程中会有水土不服的情况，

大家在使用的过程中可以根据自己的需求进行优化和改善。

在生成范围这一栏里面，先不选择自动更新，

然后点击确定，会弹出一个提示框，咱们先选择保存配置，

等咱们上传图片之后再来修改选择生成。

这样就不会浪费额度。

![](img/a9e97276f8b5fbe2e0a25c91e5061ada.png)

![](img/633bd7706e70886a37dd25aaa329f045.png)

接下其他的几个字段捷径都是按照上面的方法去添加。

![](img/b37979e0aea4c7920af5793e5d2fb9c0.png)

![](img/adf08b5ecd8e7da0635a311c60c1a911.png)

图片生成这里需要的地方是你要根据自己的需求选择图片比例

![](img/eae9b5a82600ba1f6604a85682bdfeac.png)

动态视频的配置是在自定义指令中添加动态视频提示词

选择图片生成选择静态分镜图

![](img/6d4dbb8da8e1ee1050bd7ee2d362b163.png)

到了这一步之后，字段捷径咱们就算配置完成了。

这个步骤算是比较简单的。

不是很难。

10分钟就能做好。

## 第三、创建关联账号

接下来就到更加重要的环节，

创建关联账号。

这几个字段捷径免费的额度很低。

所以想长期使用需要购买额度，

生图的成本是2毛一张。

视频的话6秒钟1080p高清大概为3元一条。

不过也有羊毛可以薅。

对于觉得生图成本比较高的，

我的解决办法是用coze做一个出图工作流

然后链接到飞书多维表格里面去，

搭建豆包生图的工作流需要开通会员，

9.9一个月（包含3万的资源点）

额度也够基础使用。

![](img/6079040f864e570f8145834bf3ec44c6.png)

足够我使用的。

其次，关于`字段捷径是AI图片理解、AI生图和AI视频生成`分别对应的开通网页有些不一样。

大家在关联账号的时候会注意到，关联账号会有豆包大模型和火山引擎。

![](img/6b09db20830b947b864d8f7a94bd3b83.png)

![](img/67a5ce13a03e221750c17ae424a1bea1.png)

这两个不同的API调用接口，就要去对应的网页开通。

属于火山引擎的字段捷径则需要登录火山引擎的网站去开通API。

链接直达：`https://console.volcengine.com/ai/ability/detail/1`

属于豆包大模型的字段捷径则需要登录火山方舟

链接直达：`https://console.volcengine.com/ark/region:ark+cn-beijing/overview?briefPage=0&briefType=introduce&type=new`

![](img/81a34bf24b368fbcac44b95368018389.png)

所以咱们在创建API和关联账号的时候，

一定要区分清楚这2个不同的API接口平台。

接下来咱们进入到正题。

#### 第四步、复制API key

做完上一步之后会自动弹出以下这个界面，

咱们根据箭头的指示，

点击选择API Key并复制。

这个步骤是为了获取密钥。

![](img/a55cac9b92769ff26e84927bda0328c7.png)

咱们进去之后会看到以下这个画面，

然后你会看到“选择使用”这个按钮，

要选择你刚才创建的API名称，

我这里是图片理解2，

所以我就使用这个，

接着会在中间弹出来密钥。

咱们直接复制密钥就可以。

这里需要注意，一定不要直接点击下面的蓝色按钮：复制使用。

我在这个环节卡了很多次，最后是发现是自己复制错了。

因为你直接复制使用，会把一整串的数字给复制进去。

后面输入到关联账号成功，但是字段捷径会出现没有访问权限。

因为关联账号是不会提示你的密钥和ID是否正确。

AI视频生成的方法跟AI图片理解的步骤一样，

点进模型广场，下拉看到视频生成这一栏，选择这四个的那一个都可以。

这个章节的最后，

我再教大家如何用飞书批量下载插件，

批量下载图片和视频，同时让文件自动标上正确的序号。

首先点击插件--附件批量下载

接下来会看到这个画面：

![](img/891bffc2bdbde63e773f1e0592790185.png)

这个配置里面，咱们在附件字段、文件命名方式和下载方式上做改动。

第一个先把你不需要下载的字段给删除，

我这里只想下载生成静态分镜图，

就把其他的全部删除。

![](img/de67b485e955ee80fd1e61310ddead7b.png)

这样你下载的图片就会按照顺序标上序号数字。

接着选择打包的方式下载。

文件命名方式选择：**从表字段选择**
