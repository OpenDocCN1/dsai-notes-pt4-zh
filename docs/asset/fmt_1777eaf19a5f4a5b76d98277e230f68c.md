以下是我们为每个质量指标提供的定义：

+ **信息性**：一个有信息性的摘要捕获了文章中的重要信息，并准确、简洁地呈现出来。
+ **质量**：高质量的摘要是可以理解的。
+ **连贯性**：一个连贯的摘要结构良好，组织有序。
+ **可归因性**：摘要中的所有信息都可以完全归因于文章吗？
+ **整体偏好**：一个好的摘要应该以简洁、逻辑、连贯的方式传达文章中的主要思想。

质量和连贯性的提示不包括文章的内容。这些定义是从之前的摘要注释努力中改写的：（Fabbri等人，2021；Aharoni等人，2023）。
