## 数据格式转换

有了数据集之后，我们还需要将数据集转化为gpt-oss能够识别的数据格式，首先第一步是需要将其转化为gpt-oss的基本消息格式：

```
def to_original_messages_format(example: dict) -> dict:
    """
    将我们翻译后的样本，转换成原始数据集使用的 messages 结构：
      - system.content: "reasoning language: {reasoning_language}\n\n{developer}"
      - user: user
      - assistant: content=final, thinking=analysis
    其余顶层字段（reasoning_language / developer / user / analysis / final）保留不变。
    """
    rl   = example.get("reasoning_language", "") or ""
    dev  = example.get("developer", "") or ""
    usr  = example.get("user", "") or ""
    ana  = example.get("analysis", "") or ""
    fin  = example.get("final", "") or ""

    # 组装 system.content；developer 为空则只放第一行
    system_lines = [f"reasoning language: {rl}"]
    if dev.strip():
        system_lines += ["", dev]
    system_content = "\n".join(system_lines)

    messages = [
        {"role": "system",    "content": system_content, "thinking": None},
        {"role": "user",      "content": usr,            "thinking": None},
        {"role": "assistant", "content": fin,            "thinking": ana},
    ]

    out = dict(example)  # 不破坏原字段
    out["messages"] = messages
    return out
```

然后再借助Unsloth内置的gpt-oss提示词模板，将其转化为可用于微调的文本片段：

```
from unsloth.chat_templates import standardize_sharegpt

# 先标准化 messages（ShareGPT 格式）
dataset = standardize_sharegpt(dataset)

# 再把 messages 转换成 prompt 文本
def formatting_prompts_func(examples):
    convos = examples["messages"]
    texts = [
        tokenizer.apply_chat_template(convo, tokenize=False, add_generation_prompt=False)
        for convo in convos
    ]
    return { "text": texts }

dataset = dataset.map(formatting_prompts_func, batched=True)
```
