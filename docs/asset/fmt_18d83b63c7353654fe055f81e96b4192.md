
# 实体店项目与内容经营思考

我做这个实体店项目，只要是项目就一定会有周期，哪天抖音改革，流量不行了，那项目就死了。但是人，只要永远真诚利他，那么你就能认识到越来越多的朋友，朋友的互帮互助会帮你渡过项目不稳定的周期

## 2、这个时代，内容才是王道

最近龙哥禁止所有人留联系方式，要沟通直接在评论区沟通，我也非常赞成。我也不喜欢用各种奇奇怪怪的引流方式把人引进来，这样的人来也心态着急，不适合交朋友

我更希望是，因为你喜欢我的内容和想要和我交这个朋友

而且当下大环境不好，只有真诚的人和高质量的内容才能穿越内卷的周期。所以大家可以多多分享高质量内容在赚钱里。

## 3、实体店流量是未来趋势

我做这个项目9个月了，我仍然觉得自己未上道。实话说经常看赚钱这个项目月入十万，那个项目月入十万，我真的很焦虑，因为对比来看，我自己这个项目，需要有人每天到店，运营好抖音账号，运营好私域，才能做到月入几万，真的不轻松。而且我妈作为实体店老板，还要服务客人，打扫卫生，调制中医产品，药酒膏药，真的很累但是我知道这个项目值得做，因为，赚钱，别人都在搞的项目，那已经是红海中的红海了。要找潜在市场不小，竞争不大的市场

据我观察，会做线上流量的实体店老板真的少之又少，我也很理解，因为一个实体店老板能做好线下服务已经很累了，所以大部分实体店老板都是请第三方视频公司去帮忙运营，但又因为价格问题而难倒了（普遍上万），所以我写了这个帖子希望能帮到实体店老板们

## 4、我也不知道我未来的路在哪，持续探索

说实话，我今年大三，我也迷茫，我不知道这条路未来的路在哪，是开分店，品牌招商，还是做第三方流量公司帮实体店老板做流量，还是做一个自媒体IP,分享个人成长和商业化内容，像粥左罗老师一样（因为我喜欢粥老师的内容和形式），我真的不知道

我只知道，我手上有什么牌我就打什么，手上有什么路我就去走。有实体店在这儿，我知道可以做线上流量我就去做；我只知道我在大学有时间，我就更新自己的👸号（目前更新了100多期了），写自己喜欢的内容。其他的慢慢探索吧，所以我依然得好好在赚钱里面深耕学习，向各位前辈学习，听从前辈的教导

所以各位圈友，如果你也迷茫不知道啊做什么，不妨多交点朋友，不妨多参加现在聚会，我就是在赚钱圈友的帮助下得知了抖音本地生活这个赛道。多看看大家在做什么，不妨多参加一下航海实战
