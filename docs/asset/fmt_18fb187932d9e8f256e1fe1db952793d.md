## 三、双系统对比与选择建议

| 维度 | QClaw | OpenClaw (Wukong) |
| --- | --- | --- |
| 核心定位 | 个人 AI 助手 + 自动化工作流 | 企业办公 + 浏览器增强 |
| 文档处理 | 依赖 Tencent Docs（在线） | 原生 Office 全家桶（本地） |
| 信息获取 | 17搜索引擎 + ArXiv + 📕 | 钉钉生态 + 12306/携程/大众点评 |
| 平台支持 | Win(30)/Mac(33)/Linux(15) | Win/Mac/Linux 全平台 |
| 最佳用户 | 自媒体创作者、研究员、极客 | 企业办公人员、商务人士 |
| 特色功能 | 财报追踪、创业验证、去AI味写作 | 钉钉全家桶、差旅查询 |

选择建议：

- 如果你是内容创作者或需要信息聚合，优先使用 QClaw
- 如果你是企业用户或需要深度文档处理，优先使用 OpenClaw
- 两者可以共存互补，QClaw 负责"找信息"，OpenClaw 负责"写文档"

## 四、快速使用指南

### 4.1 安装路径

QClaw Skills 位置：

```
# Windows
%USERPROFILE%\QClaw\resources\app.asar.unpacked\assets\skills\

# macOS
~/Applications/QClaw.app/Contents/Resources/app.asar.unpacked/assets/skills/
```

OpenClaw Skills 安装：

```
# 复制 skill 文件夹到：
Windows: %USERPROFILE%\.agents\skills\
macOS/Linux: ~/.agents/skills/
```

### 4.2 常用命令示例

场景 1：整理桌面文件（QClaw）

```
# Windows
powershell -ExecutionPolicy Bypass -File file-skill/scripts/organize.ps1 "~/Desktop" -Phase phase1

# macOS
bash file-skill/scripts/organize.sh ~/Desktop phase1
```

场景 2：搜索📕热点（QClaw）

```
xiaohongshu/scripts/search.sh "春节旅游攻略"
```

场景 3：查看日程（QClaw）

```
# macOS（使用 AppleScript）
bash schedule-skill/scripts/calendar.sh list --start 2026-03-21 --end 2026-03-21

# Windows（使用 PowerShell）
powershell -File schedule-skill/scripts/calendar.ps1 list -Start 2026-03-21 -End 2026-03-21
```

场景 4：处理 PDF（OpenClaw）

```
# 提取 PDF 文本
openclaw run pdf-document-handler --action extract --input report.pdf

# PDF 转 Word
openclaw run pdf_convert_to_word --input report.pdf --output report.docx
```

场景 5：查询火车票（OpenClaw）

```
openclaw run 12306-train-query --from 北京 --to 上海 --date 2026-03-22
```

## 五、关键注意事项

### 5.1 版权与合规

- 版权归属：所有 Skills 归原软件开发商（QClaw/OpenClaw）所有
- 使用范围：提取仅用于学习研究，商用请遵守原软件许可协议
- API 密钥：涉及第三方服务的 Skills（邮件、钉钉、📕、12306 等）需自行配置 API 凭证

### 5.2 平台兼容性

- macOS 独占：QClaw 的 `niuamaxia-scheduler` 仅支持 macOS（依赖 `AppleScript`）
- Windows 差异：QClaw 在 Windows 上支持 30 个 Skills（比 macOS 少 3 个系统级功能）
- Linux 限制：QClaw 在 Linux 上仅支持 15 个基础 Skills

### 5.3 依赖要求

| 复杂度 | 数量 | 依赖说明 | 代表 Skills |
| --- | --- | --- | --- |
| ⭐ 简单 | 10 | 无需外部依赖或仅需 `curl` | `tarot`, `cantian-bazi` |
| ⭐⭐ 中等 | 15 | 需要 Python/Node 基础环境 | `file-skill`, `email-skill` |
| ⭐⭐⭐ 复杂 | 8 | 需要 API Key、多依赖、外部服务 | `dingtalk-workspace`, `xiaohongshu` |

### 5.4 安全提示

- 使用 `skill-vetter` 审查第三方 Skills 代码安全性
- 涉及财务数据的 Skills（`earnings-tracker`, `xlsx-spreadsheet-handler`）建议在本地环境运行
- 浏览器增强类 Skills（MBB）会访问实际网站，请注意账号安全
