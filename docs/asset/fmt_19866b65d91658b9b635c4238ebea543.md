### Karpathy探讨`LLMs`的真正用途：语言只是历史遗留，核心在于符号建模

https://x.com/karpathy/status/1835024197506187617

有点悲伤和困惑的是，`LLMs`（“大语言模型”）和语言的关系其实不大，这只是历史遗留问题。它们其实是用于对符号流进行统计建模的通用技术。更好的名字可能是自回归变压器或类似的东西。

它们并不在乎这些符号是否恰好代表了文本片段。它们同样可以代表图像小块、音频片段、动作选择、分子或其他任何东西。如果你能把问题简化为对符号流的建模（针对任何离散符号集的任意词汇），你就可以“扔给`LLM`处理”。

事实上，随着`LLM`技术栈变得越来越成熟，我们可能会看到大量问题逐渐收敛到这种建模范式。也就是说，问题被固定在“下一个符号预测”，只是符号的使用和含义根据不同领域发生变化。

如果是这样的话，也有可能深度学习框架（例如`PyTorch`及其类似工具）对于大多数问题来说过于通用了。成千上万的操作和层可以随意重新配置，但如果80%的问题只需要使用`LLM`，这些复杂的配置还有必要吗？

我并不完全认同这个观点，但我认为它有一半是对的。

### Blaho分享：`OpenAI o1`团队`AMA`内容总结

https://x.com/btibor91/status/1834686946846597281

我们今天在与`OpenAI o1`团队的`AMA`小时中学到的内容总结：

+   `OpenAI o1` 代表`AI`能力的新层次，计数器重置为1

+   “预览版”表示这是完整版模型的早期版本

+   “`Mini`”代表`o1`模型的缩小版，优化了速度

+   o - 代表`OpenAI`

+   `o1` 不是“系统”，它是一个在给出最终答案前会生成长推理链的模型

+   `o1`的图标象征着拥有非凡能力的外星人

`o1`模型的大小和性能

+   `o1-mini`比`o1-preview`小得多且速度更快，因此未来会向免费用户提供

+   `o1-preview` 是`o1`模型的早期检查点，既不大也不小

+   `o1-mini`在`STEM`任务上表现更好，但世界知识有限

+   在某些任务上，特别是与代码相关的任务上，`o1-mini`表现优于`o1-preview`

+   `o1`的输入符号与`GPT-4o`一样，使用相同的分词器

+   与`o1-preview`相比，`o1-mini`可以探索更多的推理链

输入符号上下文和模型能力

+   `o1`模型即将支持更大的输入上下文

+   与`GPT-4o`相比，`o1`模型在处理较长和更开放的任务时不需要像以前那样拆分输入

+   `o1`可以在提供答案前生成长推理链，与之前的模型不同

+   当前没有办法在推理过程中暂停来添加更多上下文，但正在为未来的模型探索这一功能

工具、功能和即将推出的特性

+   `o1-preview` 目前不使用工具，但计划支持函数调用、代码解释器和浏览

+   工具支持、结构化输出和系统提示将在未来更新中添加

+   用户未来可能可以控制思考时间和符号限制

+   正在计划启用流式输出，并在`API`中考虑推理进展

+   `o1`的多模态功能已内建，旨在在诸如`MMMU`之类的任务中达到最先进的性能

推理链（`CoT`）

+   `o1`在推理过程中生成隐藏的推理链

+   目前没有计划向`API`用户或`ChatGPT`展示推理链符号

+   推理链符号被总结，但不能保证完全忠实于实际推理过程

+   提示中的指令可以影响模型如何思考问题

+   强化学习（`RL`）被用于改进`o1`的推理链，而`GPT-4o`无法仅通过提示达到其推理链性能

+   思考阶段看似较慢，因为它总结了推理过程，尽管生成答案的速度通常较快

`API`和使用限制

+   `o1-mini`对`ChatGPT Plus`用户有每周50个提示的限制

+   在`ChatGPT`中所有的提示计数相同

+   将推出更多`API`访问等级和更高的速率限制

+   `API`中提示缓存是一个受欢迎的请求，但尚无时间表

定价、微调和扩展

+   `o1`模型的定价预计每1-2年降价一次

+   一旦速率限制提高，将支持批量`API`定价

+   微调已在计划中，但暂无时间表

+   `o1`的扩展因研究和工程人才而受到瓶颈

+   未来几代模型中，推理计算的新扩展范式可能会带来显著收益

+   逆向扩展目前不显著，但个人写作提示显示，`o1-preview`的表现只比`GPT-4o`稍好（甚至稍差）

模型开发和研究见解

+   `o1`通过强化学习训练以实现推理性能

+   该模型展示了创造性思维，并在诸如诗歌之类的横向任务中表现出色

+   `o1`的哲学推理和广泛推理能力（例如破译密码）令人印象深刻

+   研究人员使用`o1`创建了一个`GitHub`机器人，能够准确通知相关`CODEOWNERS`进行审查

+   在内部测试中，`o1`自己给自己出难题来衡量其能力

+   宽泛的世界领域知识正在增加，并将在未来版本中改善

+   未来版本的`o1-mini`计划使用更新的数据（当前是2023年10月）

提示技术和最佳实践

+   `o1`从提示风格中受益，尤其是在提供边缘案例或推理风格时

+   与早期模型相比，`o1`模型对提示中的推理线索更敏感

+   在检索增强生成（`RAG`）中提供相关上下文可以提高性能；不相关的片段可能会削弱推理能力

总体反馈和未来改进

+   由于处于早期测试阶段，`o1-preview`的速率限制较低，但会逐步提高

+   正在积极研究改进延迟和推理时间

显著的模型能力

+   `o1`能够深入思考诸如“生命是什么？”之类的哲学问题

+   研究人员发现`o1`在处理复杂任务和从有限指令中进行广泛推理的能力令人印象深刻

+   `o1`的创造性推理能力（如通过自我测验来评估其能力）展示了其高水平的问题解决能力

### 北大对齐团队独家解读：`OpenAI o1`开启「后训练」时代强化学习新范式

https://mp.weixin.qq.com/s/FXGdJA8OyZvLl89rXJiyAQ

`OpenAI o1`模型在数学、代码、长程规划等复杂问题上取得显著进展，技术突破的背后离不开强化学习（`RL`）与后训练阶段（`Post-Training`）的计算量扩展，以及新扩展律的应用。

1. 后训练扩展律（`Post-Training Scaling Laws`）

+   **后训练阶段的关键**：`OpenAI o1`在发布后，凭借强化学习和推理阶段思考计算量的提升，取得了突破性进展。这个新扩展律提出，模型的计算量不再仅与参数量有关，还包含`RL`探索时`LLM`推理的计算量。推理和反思的时间同样影响模型最终表现。这意味着在后训练阶段投入足够的算力至关重要。

+   **模型表现**：`o1`在竞争性编程（`Codeforces`）中达到了第89百分位，在美国数学奥林匹克竞赛（`AIME`）中跻身前500名，并在`GPQA`的物理、生物和化学问题上超越了人类博士水平的准确性。

2. 强化学习与隐式思维链

+   隐式推理（Rationales）：`o1`的技术突破不仅在于强化学习（`RL`），还在于模型学习了生成合理推理过程的能力，这种隐式的推理过程对模型解决复杂问题至关重要。

+   **`MCTS`与`STaR`的结合**：传统的蒙特卡洛树搜索（`MCTS`）和强化学习（`RL`）方法被用于诱导模型生成合理推理过程，而非直接搜索答案。类似于`STaR`[1]的扩展，`o1`使用`RL`和自我引导（Bootstrap）生成合理推理，将这些推理融入训练过程，从而使模型学会如何思考问题。

+   **引入`Critic Model`**：面对复杂推理任务，模型引入了更强的`Critic Model`来提供准确的反馈，优化推理过程。这使得模型能够在更复杂的问题上实现更细粒度的监督和奖励。

3. 技术要点

+   **动态推理`Token`**：`o1`引入了动态的`Reasoning Token`来触发“隐式思维链”，使模型在生成答案前能够进行深入思考。这极大地减少了不必要的计算资源消耗，赋予模型更强的推理能力。

+   **推理时间作为扩展维度**：`o1`模型的性能提升不仅依赖于预训练阶段，更在于`Post-Training`阶段的`RL`训练和推理时间的投入。推理时间成为新的扩展维度，为模型提供更强的思考能力。

4. 数据飞轮与未来展望

+   **数据飞轮**：通过自我反思，`o1`模型不断生成高质量训练数据，形成数据飞轮，促进自我强化和性能提升。

+   `Post-Training`为突破方向：随着参数规模扩展的边际效益递减，模型性能的进一步提升将依赖于`Post-Training`阶段的强化学习和推理。`o1`的发布标志着`RL`下`Post-Training Scaling Laws`时代的到来，强化学习和隐式思维链的探索成为大模型未来突破的关键。

### `KAN`的横空出世，彻底改变了神经网络研究范式！

2024年4月，麻省理工学院（`MIT`）和加州理工等机构的研究人员推出了一种全新的神经网络架构——`Kolmogorov-Arnold Network`（`KAN`）。该架构突破了传统神经网络的“黑盒”问题，为神经网络研究带来了全新的透明性和可解释性。

1.  神经网络的局限性与`KAN`的诞生

+   神经网络目前是`AI`领域最强大的工具，但其一个基本组件——多层感知器（`MLP`），一直以来都是“黑盒”，很难解释其内部工作原理。

+   `KAN`的诞生，源于20世纪数学家`Kolmogorov`和`Arnold`的数学思想。他们证明，任何多变量函数都可以转换为一系列单变量函数的组合。然而，由于这些单变量函数的不平滑性，该理论曾被认为在实际神经网络中不可行。

+   `MIT`研究生`Ziming Liu`勇敢地重新探讨了`KAN`，并发现了其新的应用潜力。在导师`Max Tegmark`的关键建议下，他们尝试了多层`KAN`架构，成功展示了`KAN`的可行性。研究团队后来扩展到多达六层的`KAN`，证明其在处理复杂输出函数时的卓越性能。

1.  `KAN`的技术优势

+   **不同于`MLP`的函数拟合方式**：`KAN`通过使用非线性、可学习的函数作为“边”，而非数值权重，使其在函数拟合上更加灵活和敏感。

+   **可解释性**：`KAN`不仅能给出预测，还能解释预测的背后原理，揭示物理过程的数学方程。例如，`KAN`能够准确地表示某个函数，并以更具可解释性的方式连接数据点。

+   **科学任务中的优势**：在科学领域的实际任务中，`KAN`展现出压倒性优势。它在处理数学的“纽结理论”和凝聚态物理中的`Anderson`局域化问题上，都比`MLP`表现更优。

1.  `KAN`在科学界的影响

+   研究团队展示了三层及多层`KAN`在科学任务中的应用潜力，为进一步研究铺平了道路。`KAN`不仅实现了预测，而且解释了预测的原因，这正是`MLP`难以做到的。

+   在几个月内，`KAN`引起了`AI`研究界的高度关注，并激发了多方跟进研究。例如，清华大学团队研究的`Kolmogorov-Arnold-informed Neural Network`（`KINN`）在求解偏微分方程方面优于`MLP`。

+   新加坡国立大学研究人员分析`KAN`和`MLP`的性能，指出`KAN`在科学任务中的可解释性明显优于`MLP`，而`MLP`则在计算机视觉和音频处理方面表现更佳。
