## 活动周期与流程

### 活动整体周期

2025/8/4（周一）开始第一个赛道的投稿审核，后续每周推出一个新赛道，预计推出五期赛道主题，共持续五周。

### 流程说明

+ **赛道发布：**每周一上午 10 点，当周赛道主题准时揭晓，新一轮的创作比拼同步开启。

+ **用户投稿：**用户有一整周的时间（周一至周日）围绕当周主题进行创作和投稿。划重点：所有投稿作品需使用 `aily` 工作助手参与完成！

+ **数据统计：**

+ **评奖周期定义：**作品评选具有时效性，评奖数据统计周期，并非按自然周计算，而是针对每一个独立的作品。

+ **统计方式：**从某个作品[审核后发布在提示词社区的](https://www.feishu.cn/community/prompts)那一刻起，开始计算 7 天（即 168 小时）。系统将在 7 天后，自动抓取并锁定该作品在飞行社平台「提示词」社区上的最终「点赞数、收藏数、使用数」，作为其最终评奖依据。

![](img/554f5eecad04fc0c39711b0fd34d7174.png)

**例如：**用户在周二早上 10:00 提交了投稿作品，飞行社于周三晚上 20:00 审核并在提示词社区上线了作品，那么该作品的点赞数统计截止时间为下周周三晚上 20:00。

![](img/00554b80fe3674020ee0042682bb93ce.png)

+ **内容展示机制：**

+ **作品投稿**后不会立即在飞行社提示词社区公开展示，需经过人工审核。只有通过审核的有效作品才能在提示词社区展示（预计审核时间：1-3 个工作日）。

+ **链接访问权限说明：**

+ 因社群成员来自不同企业，请注意：

+ 分享发布的链接默认仅限本公司内部成员可见

+ **若需开放外部访问权限，请直接在社群内联系，申请将作品开通至互联网可见**

+ 对话链接获取方式：在 `aily` 工作助手对话/页面 右上方开启分享后方可获取分享链接

![](img/85f5445aa9d6f23d3d504fa30c3088e4.png)

![](img/a7f2acf81c10ac061244fec22326531a.png)

+ **开奖与公告：**

+ 为了给所有作品（包括周日晚上提交的作品）留出完整的 7 天统计时间，获奖名单的公布会有一定延迟。

+ 公示时间：在赛道发布当日的**下下周的周三**，在[赛事相关飞书群](https://bytedance.larkoffice.com/docx/YQIwdEN5Hoxf6Fx8o47cViUDnsL#doxcnnspGXiTPh2v0kwo2GOPmef)及本文档底部，将定期公布**上周**所有赛道作品的最终获奖名单；对于中奖的同学，我们会通过飞书联系您填写收件地址。

> **例如：**在第 3 周的周三，公布第 1 周赛道的获奖者。
