### 评估任务价值

评估哪些重复任务值得优化：

你：请帮我评估这些重复任务，哪些值得用 AI 优化？

Claude：已评估各任务的优化价值：

高价值任务（强烈建议优化）

1. 撰写报告（每周/每月）

+ 耗时：2-4 小时

+ 频率：高

+ 标准化程度：高

+ 优化收益：节省 70-80% 时间

1. 整理会议纪要（每周多次）

+ 耗时：1-2 小时

+ 频率：高

+ 标准化程度：中

+ 优化收益：节省 60-70% 时间

1. 生成统计报表（每月）

+ 耗时：3-5 小时

+ 频率：中

+ 标准化程度：高

+ 优化收益：节省 80-90% 时间

1. 撰写产品文案（每周）

+ 耗时：1-2 小时

+ 频率：中

+ 标准化程度：中

+ 优化收益：节省 50-60% 时间

中价值任务（建议优化）

1. 回复常见问题（每日）

+ 耗时：30 分钟

+ 频率：高

+ 标准化程度：高

+ 优化收益：节省 50-60% 时间

1. 格式化文档（每周）

+ 耗时：1 小时

+ 频率：中

+ 标准化程度：高

+ 优化收益：节省 70-80% 时间

1. 数据清洗（每月）

+ 耗时：2-3 小时

+ 频率：中

+ 标准化程度：高

+ 优化收益：节省 80-90% 时间

低价值任务（可选优化）

1. 安排会议（每周）

+ 耗时：30 分钟

+ 频率：中

+ 标准化程度：低

+ 优化收益：节省 30-40% 时间

1. 发送通知（每周）

+ 耗时：15 分钟

+ 频率：中

+ 标准化程度：中

+ 优化收益：节省 40-50% 时间

优化建议：

优先优化高价值任务，可以立即节省大量时间。中价值任务可以根据实际情况逐步优化。低价值任务可以暂时保持现状。

## 用 AI 自动化处理

### 自动化报告生成

你：请帮我创建一个自动化流程，每周自动生成周报。

Claude：已创建周报自动化流程：

#### 步骤 1：收集数据

+ 从项目管理工具导出本周任务完成情况

+ 从销售系统导出本周销售数据

+ 从客户管理系统导出客户反馈

#### 步骤 2：使用 AI 生成周报

```
请帮我根据以下数据生成周报：

本周任务完成情况：
[粘贴任务数据]

本周销售数据：
[粘贴销售数据]

本周客户反馈：
[粘贴客户反馈]

周报要求：
1. 包含本周工作总结
2. 包含数据分析
3. 包含问题与建议
4. 包含下周计划
```

#### 步骤 3：人工审核和调整

+ 审核生成的周报

+ 根据实际情况调整内容

+ 补充遗漏的信息

#### 步骤 4：发送周报

+ 发送给相关人员

+ 保存周报存档

> 时间节省：

+ 原耗时：30-40 小时

+ 现耗时：30-45 分钟

+ 节省时间：70-80%

### 自动化会议纪要

用 AI 自动整理会议纪要：

你：请帮我创建一个自动化流程，自动整理会议纪要。

Claude：已创建会议纪要自动化流程：

会议纪要自动化流程

步骤 1：录音或记录

+ 使用录音设备录制会议

+ 或使用笔记软件记录会议要点

步骤 2：转录或整理

+ 将录音转录为文字

+ 或整理笔记内容

步骤 3：使用 AI 生成会议纪要

```
请帮我根据以下会议记录生成会议纪要：

会议记录：

会议纪要要求：
1. 提取会议要点
```
