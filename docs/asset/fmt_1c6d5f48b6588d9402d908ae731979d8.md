## 自定义预设

> 参考 `https://github.com/lllyasviel/Fooocus/tree/main/presets` 中其他预设的配置，然后在启动脚本 `run.bat` 里面调整启动参数，比如下面这个（其实动漫风和真实风启动脚本 `run-xxx.bat` 也是使用 preset 的参数）

> ```
> python entry_with_update.py --preset name_of_your_preset
> ```
>
> 如果你不清楚如何使用建议不要自己尝试。
