
# WordPress 网站搭建教程

## 下载并上传 WordPress

![](img/1ab860ffa0e3103619202a9f11d65df8.png)

之后大家可以下载wordpress官方插件https://cn.wordpress.org/latest-zh_CN.zip

下载好之后，选择上传

![](img/c7515cc22efcc6bf60986e988829e34c.png)

上传好之后解压

![](img/bd4484ee48b7c91a88f39666c718384c.png)

之后就可以删除这个压缩包了

![](img/ce1f13fae9a9ff6a30097831aa5a0099.png)

![](img/efdd2fde373389162592e680eda123cb.png)

## 配置 PHP 版本

## 导入数据库

之后就是配置数据库，大家在文件管理中上传我给大家的数据库源码

![](img/b9b4fd3e4eea087bed593eaa99bd4b9b.png)

在这个文件夹的目录底下把我们数据库传上去（其实传到哪个位置都行，主要在这方便）

![](img/de4d2580c38cb4147c11dbe7f6d43d1b.png)

上传完成后，点击数据库

![](img/520a4959e9bae8decbe131497c2ba96b.png)

把我们的数据库导进去

![](img/c8951263a0858c8ac92326a75ed90b52.png)

要选择导入，而且要记住我们在上面上传的数据库位置，之后导入就可以了

![](img/e8587eeac8c13ba230c944d6b2f18226.png)

## 修改网站配置

在导入数据库后，我们要修改一下网站，要不然就会从你们的网站跳到我的网站（其中如果涉及到账号密码的，我们可以在这个位置看到）

![](img/97f88bc80c96e2cc5c9eaa1e1a3d9eb8.png)

选择好我们自己对应得数据库，点击进去

![](img/81264de47f4a1e9f6c809dd38bcc84ad.png)

选择其中的这个选项

![](img/8063dc1f7335d9474887bac3c3fc424e.png)

把这边的网站，改成你自己的网站，名称什么的也改一下

![](img/713ff57714dcce80310c7fbb7bc466de.png)

确认好之后就可以进我们自己的网站了，在进入网站的时候让你选择语言，就选择简体中文，会让你填写数据库账号密码，你就按照这边的填写就行，别自己编。

![](img/ed0d68d5f3369d98b107de865fa18280.png)

这样就可以进去你的网站后台了

## 上传并启用主题

选择文件，这个文件我们要上传这个主题，我给大家把网盘地址放过去

## 上传图片资源

现在我们上传文件，让这些图片显示出来

由于我们几年来的图片内存较大，超出了网站上传的上限，我们需要用到ftp工具，到网盘下载这个工具，它可以让你的电脑文件和网站文件相互连接

![](img/8324a8341a4850f4015e6db53b012e57.png)

这里的ftp地址，账号，密码，都在你自己后台保存着

![](img/ffdbf72a2f81a40455858d143624735d.png)

![](img/a19614331292ebf9f9967e37556b28b4.png)

连接之后就是我上面显示的那样，你先把网盘给你的图片文件下载到电脑上面，在电脑端选择好我网盘给你打包的图片文件

![](img/e05c3789030fa0c6f7f0e6846ec4fb89.png)

确定好电脑上传的文件和要上传到网站的位置（位置如图，大家自己选择)

![](img/f349dc506347eca9ffeb490c054f1849.png)

之后右键我们的文件，选择上传

之后就开始上传了

![](img/41755c7ae6dd5684ac00a8d5e3298445.png)

上传完成后

![](img/42a64c9225b1743dcacd20d1cfe87a4e.png)

解压文件

![](img/a37a3d3b4ffe21fee284295d7ce5cf90.png)

之后就可以把解压包删除掉了，再把这个文件夹里面的文件剪切出到`content/uploads`目录下面，就像我这样，就可以把里面多余的那个uploads文件夹删除了

![](img/bd94de5b9ff88ec992dd069f17b22646.png)

之后你就会发现，我的网站图片可以正常显示了

![](img/c78ab3acd3dd28bd537a7339cd93932f.png)

## 修改文章作者

大家还可以看到，我们文章的作者都是默认的wangzai。我们要调换回去自己ip的名称

用另外一个浏览器在我们的网站另外创建一个账号，（这个账号密码一定要记住）这个账号就是你要用的ip，也就是管理员，

我们在后台添加用户

![](img/261a1771a476583232d03eb6b85e041a.png)

![](img/f16391e323d7a7988b2e5a02eec53ad2.png)

注册好账号之后，我们在网站后台修改一下我们刚注册好的账号权限（相当于默认是A,你自己的是B，我们想要把B替换成A，需要先注册B，再用A的账号权限给B开通管理权限，最后再登陆B的账号把A删除掉）

![](img/51ed67068f1c580563abee62bad7b599.png)

之后我们登陆B的账号，进入网站后台

![](img/7dadb2f8d0f39d660fdefd47ebaff30b.png)

选择删除

会提醒你把文章转给谁，转给你自己的IP

![](img/c8943266c40f3d4465a04733a34c8e0b.png)

![](img/b10cb3ac110427c4509c4b070666e8c2.png)

不出俩分钟，文章就变成你自己的了

![](img/2ff2130f851a21c5e8663d48592f4366.png)

其他的什么都不要看，直接选择一元试用

选择俩个

![](img/6c2b4dc90bd24302abb6367ddc470308.png)

把我们的域名放进去，一个是加www 一个不加

![](img/5e2e03bd4e59e2a686e953d3a5112c6b.png)

![](img/33d17478dee72e4958e28da5636d9d92.png)

![](img/f2cac64653dcca1f4c670fa48229cb6a.png)

在证书颁布后

![](img/3b66b41495a965d2cd2432e5b9524a43.png)
