## 功能概述

EchoAgent 是整个狼人杀游戏中的“主持人（Moderator）”，它继承自 `AgentBase`，但并不像 `ReActAgent` 那样使用大模型。它只是把传入的内容包装成消息对象 `Msg` 并原样返回。

## 代码详解

```python
class EchoAgent(AgentBase):
    """Echo agent that repeats the input message."""
```

+   定义主持人名称为 "Moderator"。

```python
def __init__(self) -> None:
    super().__init__()
    self.name = "Moderator"
```

```python
async def reply(self, content: str) -> Msg:
    """Repeat the input content with its name and role."""
    msg = Msg(
        self.name,
        content,
        role="assistant",
    )
    await self.print(msg)
    return msg
```

+   `reply()`：核心方法。
+   构建一条 `Msg`（`AgentScope` 的标准消息格式）。
+   `role="assistant"` 表示这是 AI 角色（非用户）。
+   调用 `await self.print(msg)` 输出日志（控制台显示“Moderator: ...”）。
+   返回这条消息。

主持人的作用相当于：

+   广播公告（如“天黑请闭眼”、“狼人请睁眼”）
+   给各个角色发私信（如“女巫，你是否使用解药？”）

```python
async def handle_interrupt(self, *args: Any, **kwargs: Any) -> Msg:
    """Handle interrupt."""
```

+   预留接口，用于中断机制。

```python
async def observe(self, msg: Msg | list[Msg] | None) -> None:
    """Observe the user's message."""
```

+   主持人不需要存储记忆，也不需处理观察逻辑，因此为空实现。

# 2. 玩家状态管理：Players 类

## 功能概述

`Players` 是整个游戏的“数据中心”，维护所有玩家的身份、状态（生死）、分组、映射关系。它相当于一个小型数据库，让游戏逻辑得以运行。

## 初始化结构

```python
def __init__(self) -> None:
    self.name_to_role = {}
    self.role_to_names = defaultdict(list)
    self.name_to_agent = {}
    self.werewolves = []
    self.villagers = []
    self.seer = []
    self.hunter = []
    self.witch = []
    self.current_alive = []
    self.all_players = []
```

+   `name_to_role`：玩家名 → 角色
+   `role_to_names`：角色 → 所有玩家名（反向映射）
+   `name_to_agent`：玩家名 → 对应的 `ReActAgent` 对象（便于直接调用）
+   `werewolves` / `villagers` / `seer` / `hunter` / `witch`：按身份分类的存活者列表。
+   `current_alive`：当前仍存活的所有 `ReActAgent` 对象。
+   `all_players`：所有玩家（包括死亡）。

## 添加玩家

```python
def add_player(self, player: ReActAgent, role: str) -> None:
```

功能：把一个 `ReActAgent` 注册进游戏系统，并更新各映射表。

逻辑：

1. 建立 `name_to_role`、`name_to_agent`。
1. 记录进 `role_to_names[role]`。
1. 添加到 `all_players`。
1. 分类存入具体阵营列表（狼人、村民、女巫等）。
1. 把玩家加入 `current_alive`。

若出现未知身份（非法字符串），会抛 `ValueError`。

例子：

```python
players.add_player(agent1, "werewolf")
players.add_player(agent2, "seer")
```

## 更新玩家状态

```python
def update_players(self, dead_players: list[ReActAgent]) -> None:
    """Update the current alive players."""
```

功能：移除死亡玩家，从所有阵营列表中同步清理。

实现：每个身份列表都执行过滤：

```python
self.werewolves = [_ for _ in self.werewolves if _.name not in dead_players]
```

最终更新 `self.current_alive`，确保后续阶段的逻辑（如投票、查验）只作用于仍存活玩家。

## 打印身份表

```python
def print_roles(self) -> None:
    print("Roles:")
    for name, role in self.name_to_role.items():
        print(f" - {name}: {role}")
```

+   用于调试：在游戏开始时打印各玩家身份（实际游戏中主持人隐藏，但控制台调试时输出）。

## 判断胜负

```python
def check_winning(self) -> str | None:
```

功能：判断是否满足游戏结束条件，并生成相应提示信息。

关键逻辑：

1. 拼接角色总览字符串：

```python
true_roles = (
    f'{names_to_str(self.role_to_names["werewolf"])} are werewolves, '
    f'{names_to_str(self.role_to_names["villager"])} are villagers, '
    f'{names_to_str(self.role_to_names["seer"])} is the seer, '
    f'{names_to_str(self.role_to_names["hunter"])} is the hunter, '
    f'and {names_to_str(self.role_to_names["witch"])} is the witch.'
)
```

+   提供最终战报时显示所有真实身份。

1. 胜负条件：

+   狼人胜利：狼人数量 * 2 ≥ 存活人数

    意思是“狼人数量 ≥ 平民+好人数量”，即狼人控制投票局面。

+   村民胜利：`not self.werewolves`（所有狼人已死）。

1. 生成提示语：

```python
return Prompts.to_all_wolf_win.format(...)
return Prompts.to_all_village_win.format(...)
```

+   使用在 `prompt.py` 定义的模板输出自然语言提示。

1. 若都不满足，返回 `None`（继续游戏）。

## 数据流动关系

| 功能点 | 来源 | 输出 | 在 `game.py` 中的使用 |
| --- | --- | --- | --- |
| `majority_vote` | 投票结果列表 | (赢家, 计票报告) | 夜间狼人投票、白天全民投票 |
| `names_to_str` | 玩家对象列表 | 拼接字符串 | 广播台词中动态插入名字 |
| `EchoAgent` | 系统主持人 | 输出消息对象 `Msg` | 所有阶段的台词输出者 |
| `Players.add_player` | 初始分配 | 建立映射 | 游戏开局角色分配 |
| `Players.update_players` | 死亡名单 | 更新存活列表 | 夜晚和白天死亡后调用 |
| `Players.check_winning` | 当前状态 | 返回胜利公告 | 每回合末检查游戏是否结束 |
