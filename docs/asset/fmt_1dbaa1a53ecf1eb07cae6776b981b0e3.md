
## 五、短视频制作与多平台分发

+   形式：口播 + 屏幕录制

+   结构：

1.  抛出痛点场景（"你是否每天要手动..."）

2.  展示工作流界面（拖拽、连线、配置）

3.  运行结果（"看，30秒处理完1000条数据"）

4.  不主动引导私信（避免平台识别引流）

### 步骤3：多平台分发(RPA分发)

+   平台：抖音、📕、视频号、快手、B站、油管（抖音、📕、b站这三个效果很好)

+   频率：日更或2更（不强求日更）

### 客户筛选：避免被平台识别为引流

**我的策略**：

+   ❌ 不是：别人一问就直接给🛰️号

+   ✅ 而是：先聊需求，确认是目标客户再给🛰️

**筛选流程**：

```
平台私信
↓
先聊需求（你具体想做什么？）
↓
确认能做 + 对方是目标客户
↓
这时候才给微信号
↓
微信深度沟通
```

**为什么这样做？**

+   抖音/📕对引流打击很严

+   直接发🛰️号容易被识别

+   先聊需求，平台无法判断你是引流还是正常咨询

+   提高了客户精准度（过滤掉无效咨询）

### 定价策略：从报范围到参考淘宝

#### 我的定价演变

**阶段1：报一个范围**

+   心里估算：这个需求值300元

+   报价：400-600元之间

+   最终成交：一般在500左右

+   逻辑：给客户还价空间，也是给自己空间

**阶段2：判断刚需程度**

+   在聊的过程中观察客户：

+   如果是刚需、很着急 → 价格报高一点

+   如果没啥兴趣、随便问问 → 随便报个价（反正不会买）

+   关键：使劲聊，聊得越多越能判断

**阶段3：参考淘宝定价**

+   步骤1：把客户需求描述整理好

+   步骤2：去淘宝问价格

+   例如：淘宝报1000元

+   步骤3：我报800元左右

+   逻辑：比淘宝便宜20%，客户觉得很划算

#### 转化成交：脸皮要厚，但要有方法

#### 我的成交心理学

**核心理念**：

+   脸皮要厚（但要有方法）

+   要揣摩客户心理，要不卑不亢

+   提供情绪价值

+   学会"趁虚而入"

**客户心理分析**：客户犹豫时，只有两种情况：

1.  觉得价格贵了→ 解决：适当降价

2.  不是刚需，需求不明确→ 解决：挖掘需求、帮解决实际问题（一般来找你买工作流的，这个是它的内容生产环节。那么你继续深挖一下，就再问一下他有没有内容分发环节，需不需要矩阵运行？这个时候还可以卖他一套影刀rpa 矩阵分发系统。）

#### 我的话术原则

+   ❌ 不夸大效果（"这个工具能让你月入十万"，实事求是，并不是说你买了这套工作流，别人能成爆款，你就能成爆款。）

+   ❌ 不制造焦虑（"不学就落伍了"）

+   ✅ 真诚沟通需求（"你具体要解决什么问题？"）

+   ✅ 如实说明能力（"这个我做得到，那个可能需要再研究"）

+   ✅ 超预期交付（多做一点，客户会记住）

+   ✅ 使劲聊（提供情绪价值，建立信任，聊得越多，对方露出的细节越多，然后再从细节入手。）

**核心：使劲聊**

+   聊得越多，客户越信任你

+   聊得越多，越能判断真实需求

+   聊得越多，越能识别是不是刚需

+   形成"本能刺激"，客户不好意思拒绝

+   在某个瞬间，他就会成交

+   说到这里，大家会觉得使劲聊，会不会太浪费时间？肯定会浪费时间，但是前期要把这些每一步都走好，形成一个SOP，后面不管是用程序化，还是带别人，都是游刃有余。

> 关键洞察：成交不是一次对话完成的，而是持续触达+情绪价值+趁虚而入。客户不是在理性的那一刻买单，而是在情绪波动的某一瞬间下单

### 变现模式

## 六、底层逻辑：为什么这个模式能跑通？

### 程序员的"降维打击"优势（我就是一个考试80分的人，但是让我去教40分的20分的人，那还是绰绰有余)

**技术理解的本质**：

```
低代码工具 = 拖拽UI + API调用 + 简单判断逻辑（相对简单)
程序员的核心能力 = 理解业务逻辑 + 抽象复杂问题+各种AI辅助
```

**为什么1天能学会？**

+   n8n：本质是API编排，程序员天天干这个

+   影刀RPA：模拟鼠标键盘，原理简单，要耐心

+   扣子：比n8n还简单，生态很丰富

+   真正的门槛：不是会用工具，而是理解客户的业务需求

#### 关键1：流量（让别人知道你）

自媒体的长尾流量还是很恐怖的，特别是加了SEO的搜索流量，全是精准客户

大量的发，不断的发就有推送。相比于那些混剪的，这种录制视频的更有优势，因为我们绝对的原创，符合平台的优质作品的价值。

#### 关键2：信任（让别人敢找你）

这个时候很关键的一点，就是真诚。能出镜就出镜，因为一个人的真实状态是说不了假的，大家都被教育多了，真诚才是必杀技。

#### 关键3：能力（洞悉问题和真能解决问题）

很多用户是感觉可以这样，但是并不知道具体的。所以要把用户的情况问全问清晰了，这样才能做到尽善尽美。

### 隐藏的巨大价值：赚钱+赚项目

每一个客户来找我做工作流，他们都会把自己的项目完完整整地讲一遍：

+   他们的业务逻辑是什么

+   他们的工作流程是什么

+   他们的痛点在哪里

+   他们想解决什么问题

这意味着什么？

表面上是：我在帮客户做工作流，赚钱 实际上是：我在免费学习各个行业的业务流程

## 七、避坑指南：我踩过的那些坑

### 坑1：追求视频质量完美，不要“屎上雕花"，先发再说

### 坑2：技术方案没考虑环境，导致多做无用功

+   现象：Mac开发，客户用Windows

+   后果：重新部署，浪费时间

+   建议：一开始必须问清楚系统环境

+   教训：不要假设客户和自己环境一样。后面要形成sop。

### 坑3：RPA依赖第三方软件升级

+   现象：影刀操作剪映，剪映升级就失效

+   后果：方案推翻重来

+   建议：评估技术方案时，要考虑稳定性

+   教训：RPA不是万能的，要考虑软件更新风险

### 坑4：先干活再谈钱

+   现象：客户说"帮我改一下"，我就开始改

+   后果：改完了对方说"太贵了"

+   建议：先谈好价格，再开始工作

+   教训：这是做生意，不是做慈善

### 坑5：直接给🛰️号被识别

+   现象：别人一问就直接发🛰️号

+   后果：账号被限流/封号

+   建议：先聊需求，确认是目标客户再给🛰️

+   教训：平台对引流很敏感，要学会"伪装"

### 坑6：定价随意没有标准

+   现象：看心情定价，300-800随口说

+   后果：有时定价太低亏了，有时太高客户跑了

+   建议：建立定价体系（简单/中等/复杂）

+   参考：先去淘宝问价格，再报自己的价
