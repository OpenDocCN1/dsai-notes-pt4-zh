
# AI工具导航

## AI办公与PPT工具

### ChatPPT

ChatPPT是必优科技旗下面向PPT使用者提供的AI生成PPT软件，产品基于 [ChatGPT](https://www.zhihu.com/search?q=ChatGPT&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D) 与韦尼克模型，面向PPT用户提供可通过自然语言指令与Chat模式进行PPT文档创作的AI创作服务。

[  ](https://link.zhihu.com/?target=https%3A//chat-ppt.com/)

### 美图PPT

[美图AI](https://www.zhihu.com/search?q=%E7%BE%8E%E5%9B%BEAI&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D)PPT是国内知名P图软件美图秀图旗下的美图设计室推出的免费在线AI生成PPT设计工具，用户只需输入一句话，便可以轻松打造精美PPT。无论是什么类型风格的PPT，美图AI都可以帮你打造，如行业分析、工作汇报、创意设计方案、企业团建策划、部门工作总结等。

[  ](https://link.zhihu.com/?target=https%3A//www.x-design.com/ppt/)

### MindShow

MindShow是国内独立开发者开发的输入内容自动生成演示工具，帮你省去排版的烦恼，让想法快速展示

[  ](https://link.zhihu.com/?target=https%3A//www.mindshow.fun/)

## 四. 设计类

![](img/d5bc97a2801d7aa6e6882ba935074578.png)

### 1.美图设计室

[美图设计室](https://www.zhihu.com/search?q=%E9%82%80%E6%83%85%E5%87%BD&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D)最新推出AI海报生成工具，用户只需输入一句话，AI便能生成各种风格的海报，包括日常问候、节日祝福、电商主图、生日视福、邀情函等各种模板品类。

除开AI海报外，美图设计室还可以AI生成Logo、Al生成PPT、AI生成绘画、图片抠图等。

[  ](https://link.zhihu.com/?target=https%3A//www.x-design.com/poster/)

### 2.智绘设计

智绘设计是腾讯推出的多场景智能设计平台，提供特有的AI创意创作功能，包括智能人像与商品报图、风格动漫化、智能消除笔、智能多尺寸、智能配色等。

[  ](https://link.zhihu.com/?target=https%3A//zhihui.qq.com/platform/intro)

### 3. Fabrie

Fabrie是一个面向全球设计团队打造的白板协作平台，该产品已推出AI设计助手Fabrie Al，可帮助设计师在白板上更捷地获取灵感、快速渲染、迭代设计方。只需选择预设场景模板，补充颜色、材质、背景细节即可生成不错的设计效果图。

[  ](https://link.zhihu.com/?target=https%3A//www.fabrie.cn/ai/)

## 五.视频制作

![](img/6e07c2178eed427be2efa3caa6a93181.png)

### 1.一帧秒创

一帧秒创是基于秒创AIGC引擎的智能AI内容生成平台，为创作者和机构提供AI生成服务，包括文字续写、[文字转语音](https://www.zhihu.com/search?q=%E6%96%87%E5%AD%97%E8%BD%AC%E8%AF%AD%E9%9F%B3&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D)、文生图、图文转视频等创作服务，通过对文案、素材、AI语音、字幕等进行智能分析，快速成片，零门槛创作视频。

[  ](https://link.zhihu.com/?target=https%3A//aigc.yizhentv.com/)

### 2.腾讯智影

腾讯智影是由腾讯推出的一款AI智能创作工具，融合了AI数字人、AI文字配音TTS、文章转视频等多项AIGC能力。

[  ](https://link.zhihu.com/?target=https%3A//zenvideo.qq.com/)

### 3.百度度加

度加创作工具是由百度出品的、人人可用的AIGC创作工具网站，度加致力于通过AI能力降低内容生产门槛，提升创作效率，一站式聚合百度AIGC能力，引领跨时代的内容生产方式。

[AI成片](https://www.zhihu.com/search?q=%E7%99%BE%E5%AE%B6%E5%8F%B7&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D)。创作者输入文本或者选择百家号的图文，即可由AI自动一键制作视频。在娱乐、科技、社会、资讯等领域，文字成片的效果几乎不逊于剪辑师创作，而且速度更快，产量更高，质量更稳定。

[  ](https://link.zhihu.com/?target=https%3A//aigc.baidu.com/home)

## 六.音频制作

![](img/37b5f08e8b2a92659c66ab480e694950.png)

### 1.网易天音

是网易云音乐推出的一站式AI音乐作工具，无需乐理知识，一键上手。音乐爱好者或者歌手只需输入灵感，AI便可以辅助完成洞、曲、编、唱，生成AI初稿后，支持词曲协同调整。

[  ](https://link.zhihu.com/?target=https%3A//tianyin.163.com/)

### 2. TME Studio

[TME Studio](https://www.zhihu.com/search?q=TME%20Studio&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D)

TME Studio是由[腾讯音乐娱乐公司](https://www.zhihu.com/search?q=%E8%85%BE%E8%AE%AF%E9%9F%B3%E4%B9%90%E5%A8%B1%E4%B9%90%E5%8F%B8&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3206590319%7D)推出的一款AI音乐生成工具，由旗下银河音效、MUSE、天琴实验室、Tencent A Lab共同打造，助力音乐爱好者，让创作更简单。

[  ](https://link.zhihu.com/?target=https%3A//y.qq.com/tme_studio/)

### 3.魔音工坊

魔音工坊是由出门问问推出的一款先进的配音工具和高效多人音频协同创作工具，可以智能将文字转换成语音，支持多种语言和语音风格，包括中文、英文、日语、韩语等。

该工具集成了先进的深度学习技术，可以根据不同的文本内容和语境，生成自然流畅的语音。用户可以在魔音工坊的官方网站上输入需要转换的文字内容，选择喜欢的语音风格和声音类型，点击”朗读”按钮，即可快速将文字转换成语音。

[  ](https://link.zhihu.com/?target=https%3A//www.moyin.com/)
