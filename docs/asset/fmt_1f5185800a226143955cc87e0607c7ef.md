## 子目录

口语练习顺序：`part2` → `part1` → `part3`

## Prompt

### `part1`:

```
**问题：****
帮我**把上面四句话换行一下然后发给我
帮忙按句子拆分，并生成段落，同时每一句英文要翻译成中文。

答案：
帮忙按顺序拆分成段落，并且把前面的序号给去掉。
```

```
按照序号分段生成，然后以下面的格式生成给我：
（1） Yes. In a company……
（2） ……

请开始生成
```

### `part3`:

```
帮我把上面四句话换行一下然后在每一句话的前面加下 「▷ 」，比如：
▷ Do you think ……

按照这个格式发给我
```
