## 一、Seedance 2.0 是什么？为什么突然爆火？

### 核心特性

Seedance 2.0 最大的亮点在于多模态参考能力。相比 1.0 版本，它支持同时输入：

+   图片（最多 9 张）
+   视频（最多 3 段）
+   音频（最多 3 段）
+   文本提示词

单次生成可输入最多 12 个文件，生成视频长度 4-15 秒。

### 为什么全球网友都疯了？

用行业人士的话说："运镜"这项曾经令导演引以为豪的能力，被 Seedance 2.0 直接集成到了模型里。

## 二、快速上手：两种入口模式

### 模式 1：首尾帧模式（新手必选）

**适用场景**：仅有一张首帧图或尾帧图 + 文字提示词

**操作流程**：

1. 上传一张图（定下画风）
2. 写一句描述
3. 生成视频

**经典案例**：

+   上传九宫格分镜图 → 一句提示词 → 完整视频生成
+   上传一张人物照 → 描述"这个女孩在雨中奔跑" → 视频成片

**适合人群**：刚入门、想快速体验的创作者

### 模式 2：全能参考模式（进阶必选）⭐

**适用场景**：需要混合输入图片、视频、音频和文字

**核心优势**：

+   解锁导演级全部能力
+   精准复刻运镜、动作、氛围
+   支持视频延长、场景补全、音乐卡点

**何时选这个模式**：

+   素材超过一张图
+   包含参考视频或音频
+   需要高度定制化效果

## 三、掌握 @ 符号：解锁模型理解力

Seedance 2.0 最核心的玩法是`@语法`。这是用户与模型的"交互暗语"。

### 为什么一定要用 @ ？

模型不会自动猜测你的意图。如果你不明确告诉它每个素材的用途，它就可能乱用。

### @ 符号的常见用法

### 实战案例

**场景**：制作品牌广告 **上传素材**：

+   `@产品图`：产品照片
+   `@运镜视频`：参考视频（展示相机运动方式）
+   `@配乐`：15 秒背景音乐

**提示词**：

将`@产品图`放在画面中央，参考`@运镜视频`的旋转跟随方式，从俯拍推进到侧面特写，营造高级感。`@配乐`同步卡点，画面配色为冷色调，电影级色彩分级。

**结果**：高质感商业视频秒出

## 五、进阶技巧：多视频与一致性控制

### 场景 1：多个镜头保持人物一致

**难点**：生成多个镜头时，角色容易"换脸"

**解决方案**：

1. 第一次生成 → 保存最满意的镜头截图
2. 第二次生成 → 将截图作为`@参考图`上传
3. 在提示词中明确说：`@第一个镜头的女生`作为主角，保持服装和脸部一致

### 场景 2：多个片段无缝衔接

**提示词结构**：

首段（0-3秒）：建立场景
中段（3-5秒）：推进故事
尾段（5-7秒）：转折或高潮

**具体写法**：

开始：缓慢推轨推近建立场景
然后：主角进入，动作加快
最后：2秒轻柔向右平移，引出下一幕

### 场景 3：音乐卡点

上传音乐文件后，提示词中加入：

`@音乐1` 中 `X秒`处的鼓点，同步主角的转身动作

模型会自动对齐画面与音乐节奏。
