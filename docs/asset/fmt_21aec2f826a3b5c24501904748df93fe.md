## 二、核心梗思路

### 1.首先，先狂补这些小说，AI拆文分析

这类型文也有区分2种。然后拆文分析 [AI拆小说-全网最全指南（底层思路+pormpt）](https://rq547mr4oez.feishu.cn/wiki/OMY9woSQWiD3ZEkZf5ncJYCFnff?from=from_copylink)

+ 1、虐身虐心版。

+ 前期一定是要虐到女主崩溃，拉足仇恨，然后女主回归复仇，虐渣打脸。

+ 大致分：有娃版、无娃版

+ 代表作：《厉总，夫人她罪不至死》、《重生后，渣总追妻火葬场》、《替身竟是本王自己》

+ 2、先婚后爱版。

+ 前期女主不一定爱男主或者人间清醒，两个人也没有啥深仇大恨，只是没有感情，结个婚几年都没有怎么见面的那类。

+ 因为某个插曲，两人离婚，一般是女主主动提出。之后，两个人仍旧避免不了接触，解开一些误会，日久生情复婚。

+ 代表作：《封少娇妻，有孕出逃》《非正式婚姻》《先婚后爱》：顾先生的甜宠娇妻》《直女难撩》《二婚》

### 2.总结框架（起承转合）

整个套路结构，从男女主关系出发，大概可以分四个部分，按照起、承、转、合方式。

+ 起：点明矛盾点

+ 开篇点明矛盾点

+ 例如撞破男主出轨，白月光女配示威，绿茶女配挑衅女主患病受伤等。

+ 直接抛出这个重点，不要铺垫太多导致节奏拖沓读者失去兴趣。

+ 虐点事件后点明人物态度

+ 主要渲染女主悲伤绝望的情绪。

+ 其次是男主的冷漠无情+女配的得寸进尺。

+ 承：加深虐点后释放

+ 你得去堆积情绪，让女主忍无可忍、无需再忍，让读者跟着咬牙切齿、天天劝分。

+ 比方说女主受伤男主就说她装，女配受伤男主就着急得不得了。

+ 比如说女主开篇得知自己重病，在承这一部分就可以写她吐血晕厥确诊绝症。

+ 然后，情绪释放，咔嚓一下俩人分手了，大家乐见其成。

+ 这里要暗戳戳写一下男主的犹豫动摇，铺垫一下男主态度冷漠的原因，比如心里有白月光没有认清自己的真心等，不然后面不好圆。

+ 转：追妻名场面

+ 你得搞得跌宕起伏，不能让男主那么轻易把人追回来，好好设计一下拉扯。

+ 比如，女主抗拒，男主紧追，女主态度刚松动一些，又出了点事儿把俩人关系拉远，再靠近再来拉远，这样来回几遭，过程中，让男主逐渐表明心意，态度愈发坚定。

+ 同时，女主因为男主的表现，有原谅他的迹象，读者也开始期待两人复合。

+ 合：重新合体

+ 误会解除，两个人看到了彼此的闪光点，明白了对彼此的感情，顺利地在一起，追妻也就完成了。

+ 从情绪看，从女主愤怒、委屈、生气，到男主后悔、难受，到拉扯时的酸甜苦辣，再到怦然心动时的高甜，整个过程，就像过山车一样。

### 3.套路得人心

#### 虐身虐心套路：

+ 人设：

+ 女主人设：前期柔弱，后期强势。（可糅杂破产千金梗、替身梗）

+ 男主人设：狠厉无情，冷傲偏执。（前期就是瞎了眼，各种相信女配）

+ 注：男主前期肯定又渣又蠢，但一定不能和女配发生亲密关系，否则后面救不回来。除非你打定主意后面换男主。

+ 开篇三章重点：男女主感情状态+虐点（拉仇恨）+钩子+突出人设。

+ 目前的感情状态阐述：

+ 1、比如男女主目前结婚几年，是否经常见面。是否已发生关系，频率如何？

+ 2、比如当初是为什么结婚？（交易条件是什么）

+ 3、比如婆媳关系如何，女主在这个家里的地位怎么样？（是否被欺负，还是被佣人拥戴？）

+ 虐点（拉仇恨）：

+ 逼堕胎、逼怀孕、认错人、陷害杀人、软禁、监狱、逼输血、癌症、家破人亡、各种陷害误会。

+ 突出人设：塑造的角色一定要有一个人物形象。

+ 1、男主虽然前期渣且眼瞎，但肯定是个有魅力的男人，不然也不会引得女主女配以及别的女人前仆后继。

+ 2、女配一定要够讨厌，讨厌到你写起来都觉得烦就对了。不管是白莲花还是绿茶婊，不要崩人设。

+ 3、女主前期一定是弱的，心里卑微（因为这段婚姻是她求来的）+身体虚弱（多多少少都被虐出毛病了）。她弱，但仍旧有期望。积攒够了，就离婚。

#### 先婚后爱套路：

+ 人设：

+ 女主人设：人间清醒，有稳定工作（或者暗戳戳有实力）。（独立，自主）

+ 男主人设：矜贵冷傲霸总。（比虐文版的稍微好一点，有苏点撩点）

+ 开篇三章重点：男女主感情状态+离婚原因+钩子+突出人设。

+ 目前的感情状态阐述：

+ 1、比如男女主目前结婚几年，是否经常见面。是否已发生关系，频率如何？

+ 2、比如当初是为什么结婚？（交易条件是什么）

+ 3、比如婆媳关系如何，女主在这个家里的地位怎么样？（是否被欺负，还是被佣人拥戴？）

+ 离婚原因：

+ 这类文没有前一种那么虐，一般都是婚姻是一潭死水的那类。

+ 所以离婚原因的设置一般是误会。

+ 比如误会男主有了心上人，不想耽误他也不想作践自己，干干脆脆提离婚。

+ 突出人设：塑造的角色一定要有一个人物形象。

+ 1、男主没有虐文版本这么渣，所以就按照标准总裁文套路写就行。有钱有权有势，肩宽窄腰大长腿，成熟男人有魅力。

+ 2、女主的刻画更加重要。要么自己有非常牛逼的职业，比如律师、医生等；要么自己之前都在当全职太太，其实学历高能力强，出去找工作都被抢着要的；要么就是家世非常牛逼，能继承亿万家产的那种。（总结就是不怕离婚，可净身出户，不图男主啥东西，自己能养活自己。）

### 4.需要注意的事情

1. 一开始给男女主绑定的时候，要松一些，方便解绑

1. 单恋、暗恋不自知、契约婚姻、替身文学、长辈要求、娃娃亲等等，都可以。

1. 男女主虽然在一起，但关系是不稳定的、摇摇欲坠的。这样，外部的一些力量，才能将男女主的关系击碎。

1. 设计一系列情节，推动女主彻底放弃男主

1. 这些情节可以是递进的，一步步挑战女主的忍耐力。

1. 比如，一开始只是男主忽略女主，后来偏心别人、冤枉女主，再后来针锋相对。

>

1. 追妻是一个过程，推动男女主重新认识对方

1. 有几个必要点：

（1）男主发现女主优点，开始欣赏女主

（2）男主发现自己的问题，开始改变

（3）男主主动行动

1. 同时，虽然这个套路叫“追妻火葬场”，但女主也同样要向前迈步。

1. 她可以在男主行动时，发现男主的优点，意识到自己的感情，继而改变态度和决定。

>

1. 男女主需要有一定的人格魅力，是一般意义上的好人

1. 优秀的男主，才值得女主喜欢，才能让女主后期回心转意，读者也乐意见两人复合。

1. 同样，有很多闪光点、性格又好的女主，才值得男主努力追求。

>

1. 促使男女主分开的矛盾和冲突，需要在追妻过程中解决

1. 也就是，有误会就解开，男主没长嘴就长嘴，白月光诬陷的小伎俩被戳穿等等……

1. 最好是让男主主动搬开，横亘在两个人之间名为矛盾和冲突的大山。

>

1. 注意不要让读者对男主产生类似渣男的刻板印象，不然后期想洗白，会很艰难

1. 也就是前期压情绪时，千万不要让男主做出突破底线的事情，不要让他给女主带来无法挽回的伤害，不然很容易把男主写成渣男。

1. 到时候读者持续劝分，要求女主不要回头，中后期可就圆不回来了。

> 由于种种误会和阴谋，男主误以为女主背叛了自己，投向了敌军的怀抱。怒火中烧的他，亲手将女主囚禁，百般折磨。直到后来，他才发现这一切都是一个精心策划的圈套，而女主从始至终都深爱着他，甚至为他付出了巨大的牺牲。

> 幡然醒悟的男主，陷入了深深的自责和悔恨之中。他该如何弥补自己犯下的过错，重新赢得女主的芳心？而伤痕累累的女主，又是否能够放下心中的怨恨，原谅这个曾经深深伤害过她的男人？

>

> 我希望这部小说能够展现出以下几个方面的冲突和张力：

> * 爱情与恨意： 男主对女主的爱恨交织，从最初的深爱到误解后的仇恨，再到最终的追悔莫及，我希望能够细腻地展现出这种情感的转变。

> * 救赎与原谅： 男主犯下大错后，如何寻求救赎，而女主又是否能够放下心中的伤痛，最终选择原谅，这是贯穿整个故事的主线。

> * 乱世与爱情： 动荡的时代背景下，他们的爱情之路注定充满荆棘和坎坷，这也为故事增添了一份悲壮和宿命感。
