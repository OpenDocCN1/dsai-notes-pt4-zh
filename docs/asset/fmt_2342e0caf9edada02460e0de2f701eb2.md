### 【`Stability AI` 发布 `Stable Code 3B` 模型】

1 月 16 日，`Stability AI` 发布全新代码模型 `Stable Code 3B`，在 `3B` 参数的规模之下，可实现与 `CodeLLaMA 7b` 等大 `2.5` 倍的模型相媲美的代码补全能力。`Stable Code 3B` 对硬件要求也不高，用 `MacBook Air` 等普通笔记本电脑也能离线运行，而且支持高达 `100K` 的上下文大小，可以更方便、更精确地辅助编码。

### 【`MiniMax` 发布 `MoE` 大语言模型 `Abab6`】

1 月 16 日，`MiniMax` 全量发布大语言模型 `Abab6`。据介绍，`Abab6` 是国内第一个千亿参数量以上的基于 `MoE` 架构的大语言模型。

![](img/2af9a49efb0216a578f5261e1f3fc54a.png)

![](img/ea20793e30659c282caafc3c352a8d3d.png)

图片来源：`MiniMax` 🛰️👸号；`Abab6` 参数图、官方示例

更大的模型意味着 `Abab6` 可以更好地从训练语料中学到更精细的规律，完成更复杂的任务。`2023` 年 `4` 月，`MiniMax` 发布开放平台，其平均单日的 `token` 处理量达到了数百亿。

### 【元象开源上下文窗口长度 `256K` 大模型】

1 月 16 日，元象发布全球首个上下文窗口长度 `256K` 的开源大模型 `XVERSE-Long-256K`，支持输入 `25` 万汉字。该模型全开源，可免费商用。
