
# Claude code实践：如何从0到1搭建一个👸号自动化创作工作流

> 来源：[https://xuqiwei1986.feishu.cn/docx/HN3UdrmUOoxuNbxVLCWcXhSSnDg](https://xuqiwei1986.feishu.cn/docx/HN3UdrmUOoxuNbxVLCWcXhSSnDg)

大家好，我是周行。

刚参加完赚钱的垂直小号内测航海，发现用AI写作时有个很大的痛点，就是很难兼顾质量和数量。

> 用`Chat GPT`、`Gemini`或`豆包`这些`AI`大模型，一次只能输出一篇，写多了还会同质化；

> 用飞书+`DeepSeek`或者`coze`倒是可以批量生产大量文案，但文章质量却很难得到保证。

所以，花了几天时间用`Claude code`+`Obsidian`搭建了一个👸号自动化创作工作流。

这个工作流可以实现从选题到创作到排版的整个👸号创作流程。

并且根据你创作的领域和需求，还可以做一些细节的调整。

> 例如做`AI`自媒体，数据和信息很重要，`Claude code`会自动检索多个网络内容，进行交叉验证，保证数据有效性。

> 例如想要批量创作，但又要保证风格一致和避免同质化，`Claude code`可以通过风格文档和审校流程规避风格和同质化问题。

> 如果希望加入个人IP的元素，`Claude code`还可以参考你指定的IP形象，生成包含IP角色的文章配图。

这篇文章可能会有些长，适合有以下需求的朋友：

1. 同时运用多个👸号，希望实现AI自动化创作，自己拿到文章就可以直接发布；
2. 投入时间有限，想写👸号但又不想让AI水文；
3. 了解用`Claude code`创作内容的基础思路。

## 为什么用Claude code+Obsidian

`Claude code`作为主要创作工具，可以完全实现从选题到创作到配图交付的整个工作流程。并且开通权限后，可以完全自动化执行，执行完验收结果就可以。

![](img/1be8d22346776dec9d6c026da5d4b260.png)

Obsidian主要用于可视化呈现，当然这个你用`VS ide`或者`Cursor`也是可以的。

但`Obsidian`的优势在于可以插入图片，直接看到终稿效果。并且加上插件后，可以一键同步到👸号草稿箱，省时省力。

![](img/9190f033fa712fc70d55c332ec9e8c66.png)

不过我觉得最有价值的一点，是`Claude code`和`Obsidian`都是本地工具。你所有的数据都是储存在本地的，`AI`可以随时学习，调用。

你不只是在搭建一个自动生产的工作流，还是在搭建本地知识库。

**创作，即是积累。**

你用的时间越久，搭建的知识资产就越多。而这些知识资产，又可以成为素材，支撑`Claude code`创作出更符合你个人特色的内容。

## 需要做哪些准备工作

### 一、`Claude code`

打开命令行工具，用代码安装就可以。如果没用过编程的，可能要先安装`Python`和`Nodejs`。

```
npm install -g @anthropic-ai/claude-code
```

[安装好后，可以用`Any Router`的](https://anyrouter.top/register?aff=mPsM)中转API接入：https://anyrouter.top/register?aff=mPsM

这个新用户会送100美金的额度，每天签到还有25美金，只要量不大基本就够用了。或者也可以用`droid`，去闲鱼上买个`API`，会送2000万`token`，也能用很长时间。

你如果有`Claude`的订阅的话，用官方的会更稳定。篇幅有限，这里就不细说了。

### 二、`Obsidian`

直接官网下载：https://obsidian.md/

安装好工具后，需要下载一个👸号排版插件。

打开`Obsidian`➡️找到左下角设置（齿轮）➡️找到第三方插件➡️点击浏览

![](img/b55465f70eddf257d596677b5cc4f2a3.png)

这里有两个插件选择。

一是`MP Preview`，你现在看到这篇文章的排版，就是用`MP`做的。`MP`可以排版和一键复制，但没办法直接同步到草稿箱，复制后还是得自己打开👸号黏贴。

用这个的原因是我在写不同领域的内容，自己复制到👸号会更可控。

二是`Wechat public platform`，如果你只有一个👸号，那这个插件会合适很多。只要配置好👸号的`appid`，`secret`和`IP`白名单，就可以一键同步到草稿箱。

### 三、`豆包生图API`

如果你希望保持风格一致，每个图片上都有你的`IP`形象出现，例如这样：

![](img/33dd37e034e91ba4ed501df52faf5a69.png)

用`豆包 Seedream 4.0`效果会好很多。可以保持风格一致，并且可以参考本地的`IP`形象图片。

`API`可以从官网、火山引擎或其他第三方`API`渠道获取。

官方和火山引擎基本是0.2元/图。第三方`API`渠道推荐用`APICore`，生成费用是官网的一半，0.1元/图。地址：https://api.apicore.ai/register?aff=Fu1Y

当然，如果你不需要`IP`形象，只要配上合适的图就行，那用谷歌的`nano banana`会便宜很多，才0.05元/图。

### 四、`Pexels图库API`

可选项，如果你希望给文章配实拍照片，可以申请一个`Pexels`的`API`。地址：https://www.pexels.com/api/

登录后，点击`Your API Key`，进入申请界面，基本秒过，还是免费的。

![](img/804442027c88fbec2bcb51b790ea5d2c.png)

### 五、风格文档和示例文案

如果有自己的写作风格，直接提供示例，让`AI`多维度分析，生成风格文档就行。

如果要模仿特定风格，也是一样，准备几个示例文案就行。

## 具体的搭建流程

下面这张是整体的工作流程图。看起来很复杂，实际上复杂的只有提示词。具体的提示词，我会放在最后面。

这部分主要拆解下搭建方法和工作流的运行流程。

为了方便理解，我会直接用`AI自媒体`这个领域的内容创作作为案例，来详细说明搭建过程。

![](img/657f8881da3ad1ce0a428dd3cf5e1e52.png)

### 第一步：创建项目文档

在项目文件夹下，一共需要创建5个项目文档。

每个文档前面我都加了编号，这个编号的作用是为了可以快速找到对应的文件，告知`AI`需要在哪里调整。其实不需要这一步也没关系，但有的话，会更可控。

![](img/0493cdce8e3bddac3b23e7127002bdd5.png)

+ `00_refer`：用来存放风格文档和参考文章。`Claude code`在每次创作初稿前，都会先学习语言风格，确保创作出风格一致的文章。

+ `10_topic`：批量创作用的文件夹。你可以自己找好多个选题，放进文档里；也可以直接让`AI`设计多个选题，创建`topic`文档。

![](img/aa58840cc59318243924c0f5064510ec.png)

+ `20_brief`：主要用于有特定需求的时候，比如说推广某个产品，`brief`就可以放在这个文件夹里。`Claude code`会读取`brief`文件，同时检索网络素材，全面了解产品。

+ `30_knowledge`：这个文件夹，主要用于存放网络检索到的相关素材，以及对`brief`的分析。

![](img/2a09c54521c2bccbce1877d6f23f6169.png)

+ `40_tests`：如果是需要用户实测的选题，`Claude code`会自动生成任务清单。只要按照任务清单完成测试，并把结果写进任务清单，后续`AI`创作时就会使用这部分素材。

![](img/9e6c834473ec47b9b8139fa59ecc3031.png)

+ `50_images`：本地配图比使用图床更稳定，这个文件夹就主要用于存放文章里的配图。

以上几个项目文件夹，是基于我的写作需求创建的。你完全可以根据自己的需求和习惯，创建对应的文件夹。

### 第二步：设计提示词

`提示词`和市面上的大部分`提示词`没啥区别，基本上就是按照角色+技能+任务+规则+流程的格式设计。

比较不同的地方是，多了一个`任务判断机制`和`文件管理&调用机制`。

![](img/533a14b17b7ba75cd822628370df7c94.png)

在你提供需求以后，`Claude code`会自动判断，你当前需要执行的是哪一类任务，然后按照特定的工作流程去执行。

文件管理和调用，就是在提示词里明确说明，你在做哪些事情的时候，必须去找到对应文件夹。

比如信息搜索和管理，`Claude code`在收集信息后，会把内容整理好放在`30_knowledge`文件夹里面。

到初稿创作阶段，`Claude code`除了会到指定文档学习我的语言风格以外，还会回顾`knowledge`文档的信息，确保在创作时，风格一致、信息真实。

![](img/24435680bced988647db0596751d277f.png)

另外，为了保证内容质量，还加了一个审校的流程。

完成的初稿，会进行三次审校。这样出来的内容，就基本上不会有同质化和水文的问题。

并且因为以前写的文章，也都在同一个文件夹里，还可以做到跨文章的同质化修正，避免账号发了很多篇内容，基本都是一个调子。

![](img/ed3dfb42dc905eb9c3ed2fb3ab77cb6d.png)

当然，整个提示词会复杂很多，为了不影响阅读，我还是放在最后面。朋友们读完以后，自取就行。

依靠`任务判断机制`和`文件管理机制`，这套提示词完全可以按照你自己的需求量身定制。

比方说，我是写`AI自媒体`的内容，需要数据真实、需要实际体验测试，所以这套提示词对我来说半自动化是最好的，所有重要决策还是由我来做。

但如果你是写流量主，只要确保内容有价值、风格一致、不同质化，你完全可以全自动化生成。

同时准备多个选题，让`Claude code`根据选题逐一生成、审校和配图。

这期间你该干嘛干嘛，等全部完成后，你再去检查一遍就行。

如果`提示词`太复杂，担心不知道怎么修改，也没问题。万事用`AI`，直接让`Claude code`来改。

例如你想改成职场领域的，你可以这么说：

> @（`提示词文档`） 我想把这个提示词改成职场领域的提示词，我不需要信息搜索和验证的功能，但我希望提示词可以充分挖掘35岁左右职场人群的普遍痛点，生成一个职场人群报告。另外，案例务必保证真实，优先从我的个人素材库（`XX`文档）里选取，如果没有合适的案例，你可以上网搜索寻找，但不能虚构。

你只要用自然语言，把你的需求告诉`Claude code`，它就会吭哧吭哧帮你改好。

测两次，优化迭代一两版，一个专属你自己的提示词就搞定了。

### 第三步：配置API

主要需要配置`API`的，是配图阶段。

这个不需要你会编程，也不复杂。按照工作流走一遍配图的流程，到配图阶段一般会有提醒。

你再把你准备好的`API`甩给`Claude code`就好了。

例如我接`APICore`的`豆包`绘图`API`时，完全不知道怎么做。我就是把网站的说明文档和`API`丢给`Claude code`，告诉它：

> 这是`豆包`的`API`：xxxx
>
> 这是`API`网站的说明文档：xxxx
>
> 我希望每张配图都有统一的`IP`形象，`IP`形象图你可以从`50_images`里读取。然后抽象的概念要转化为具体日常的场景，整体风格与`IP`形象风格一致。

搞定，反正有什么卡点，万事问`AI`就行了。

## 常见问题Q&A

1. 写出来的文章，`朱雀`检测还是有`AI`味怎么办？

首先明确，👸号其实并不禁止用`AI`创作，真正禁止的是用`AI`水文，生成一些垃圾无脑的内容。所以，只要写出来的内容是有价值的，就会有推荐。

这一点，朋友们可以拿👸号的爆款文章去测试。我之前测过，基本一半左右的都是`AI`生成。

然后，如果真正想去除`AI`味，你必须保证你给到`AI`的参考文章，就得是真人创作，而不是`AI`创作的。从源头上避免，`AI`写出来的内容，有`AI`味的概率就会低很多。

2. 如果想创作多个领域、不同风格的文章，怎么处理？

思路是相通的，能搭建起一个风格的👸号创作工作流，就可以搭建起多个不同的工作流。

如果你不想每次打开不同的项目文档，可以在上一级文档放一个`CLAUDE.md`，设计一套专门用于调度的提示词。

这样只要你打开项目，`Claude code`就会自动读取`CLAUDE.md`。你只要提需求，它就知道你当前需要创作的是什么类型的内容。

3. 如果搭建工作流的时候，遇到卡点怎么办？

万事用`AI`，出现什么问题或效果不如你预期，直接把问题丢回给`Claude code`，让它自己解决。

或者有什么流程上不明白的地方，直接来找我交流也是可以的。
