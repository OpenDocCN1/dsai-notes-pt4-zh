# 简介

BISHENG 是一款 **开源** AgentOps，专攻办公场景，已有大量行业头部组织及世界500强企业在使用。

BISHENG团队：开放诚恳、长期主义、关注业务价值不炫技，为帮助企业实现LM应用落地，全力以赴！

> “毕昇”是活字印刷术的发明人，活字印刷术为人类知识的传递起到了巨大的推动作用。我们希望“BISHENG”同样能够为智能应用的广泛落地提供有力支撑。欢迎大家一道参与。

## 1.1 BISHENG特点

> 详见：[BISHENG与同类平台对比](https://dataelem.feishu.cn/wiki/FKC8wbDysiwCb0ktScscBXLZnZf)

1. 具备专家级品味的通用Agent **灵思**（企业版Manus）：通过 [AGL](https://github.com/dataelement/AgentGuidanceLanguage)（Agent Guidance Language），将领域专家的偏好、经验与业务逻辑融入 AI 之中，让 Agent 在处理任务时能具备「专家级品味」，实现远超同类通用Agent的效果。

![](img/eafb3f4b0443596e4279a037ae6fd4e1.png)

2. 独具特色的[BISHENG workflow](https://dataelem.feishu.cn/wiki/R7HZwH5ZGiJUDrkHZXicA9pInif)

3. 🧩独立、完备的应用编排框架：可在一个框架下实现各类任务（同类workflow产品需要被 bot 调用，或划分成 chatflow 与 workflow 来完成不同类型的任务）。

4. 🔄 Human in the loop：支持用户在Workflow执行的中间过程进行干预和反馈（包括多轮对话），而同类产品只能从头执行到尾。

5. 💥 强大：支持成环、并行、跑批、判断逻辑以及所有逻辑的任意自由组合；支持多类型输入输出、撰写报告、内容审核等复杂场景。

6. 🖐️ 易用、符合直觉：如成环、并行、批量运行操作，在同类产品中用户需借助专门组件实现，在BISHENG中只需完全按照直觉连接成“流程图”即可（画圈成环、并列即并行、多选即批量）。

![](img/a6fb67303fbb46c90a35b0b1cbd309f7.png)

7. 专为企业应用而生：文档审核、固定版式报告生成、多智能体协作、规范制度更新差异比对、工单问答、客服辅助、会议纪要生成、简历筛选、通话记录分析、非结构化数据治理、知识挖掘、数据分析...平台支持高复杂度企业应用场景构建，支持数百个组件与数千个参数的深度调优。

![](img/2662515525797808c500749f1d2317b9.png)

8. 企业级特性是应用落地的基本保障：效果自评测、使用数据回流标注、数据集管理、微调、安全审查、RBAC、用户组管理、分组流量控制、SSO/LDAP、漏扫修复、高可用部署、监控、统计...

![](img/285bef1b73ff7e98498d25457cd8ebea.png)

9. 高精度文档解析：5年海量数据沉淀，高精度文档解析模型支持免费私有化部署使用，包括高精度印刷体、手写体与生僻字识别模型、表格识别模型、版式分析模型、阅读顺序模型、公式识别模型

![](img/125add7a0470e93e67bbb2c4684c6c43.png)

10. 大量企业场景落地最佳实践分享社区：开放的应用案例与最佳实践库。

## 1.1 输入节点逻辑重构与增强

1) **策略解耦**：拆分输入节点文件处理策略，支持选择“解析内容”（提取文本）、“不解析”（保留原始文件供多模态/代码节点使用）或“存入临时知识库”，满足多样化业务场景；

2) **智能推荐问题**：支持配置基于本次对话上下文，自动生成并展示 3 个推荐问题。

## 1.2 报告节点渲染优化

支持识别 Markdown 标题及加粗样式，并自动转换为 Word 文档样式，提升文档输出美观度。

+ **开源版**：预置标准看板，涵盖用户数量、应用数量、知识库数量、用户反馈 4 大核心维度数据。

+ **商业版**（[商业拓展套件](https://dataelem.feishu.cn/wiki/Ie9mwjuJNihYE1k3nSJcfhFfnnc)）：预置全量看板数据，支持基于 11 张中间表自定义组件维度及指标，并支持多看板管理。

## 2.1 全生命周期管理

支持看板的新建、复制、重命名、删除、发布、分享与下线，管理后台支持按角色授权看板管理和使用。

## 2.2 拖拽式布局与交互

支持看板组件的自由拖拽、缩放、复制，支持全屏演示模式。
