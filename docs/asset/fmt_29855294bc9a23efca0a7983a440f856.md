## 1️⃣ 阿里开源`R1-Omni`，多模态情感识别

🤖

+ 阿里通义实验室开源多模态情感识别模型`R1-Omni`，引入强化学习与可验证奖励（`RLVR`），提升推理、准确性和泛化能力。

+ `RLVR`避免依赖复杂奖励模型，直接依情感预测准确性给奖励，为优化提供方向。

+ 受`DeepSeek-R1`启发，用`EMER`和`HumanOmni`数据集微调，助模型学习多模态情感识别。

+ 测试显示，`R1-Omni`在多数据集表现优秀，泛化能力强。

+ 开源地址：[R1-Omni](https://github.com/HumanMLLM/R1-Omni)

关键词：多模态情感识别，`R1-Omni`，强化学习，开源模型

## 3️⃣ 谷歌等最新研究，合成数据可将大模型数学推理提升8倍

🤖

+ 研究表明人类公开高质量文本训练数据或在2026年耗尽，合成数据成有效替代方案。

+ 谷歌等研究人员提出正负面两种合成数据类型，正面数据提供正确示例，负面数据助模型避免错误。

+ 利用`DPO`方法优化负面数据，为解题步骤分配优势值，助模型动态调整策略。

+ 经正负面合成数据预训练的大模型，在数学推理任务性能比仅用正面数据提升8倍。

+ 该研究表明大模型通过纠正错误能更有效掌握数学逻辑和解题技巧。

关键词：合成数据，大模型，数学推理，正面数据，负面数据

## 6️⃣ 在GSM8K上比GRPO快8倍！厦大提出CPPO，让强化学习快如闪电

🎯

+ 厦大纪荣嵘团队发现`GRPO`训练开销大，提出加速版算法`CPPO`并开源代码。

+ `CPPO`通过对完成结果剪枝提升强化学习速度，引入动态分配策略提高GPU利用率。

+ 实验显示，使用`Qwen-2.5`系列模型时，`CPPO`在`GSM8K`基准上比`GRPO`快8.32倍，`MATH`基准上快3.51倍。

+ `CPPO`在不牺牲准确度前提下，保留模型在分布外任务的泛化能力。

+ 奖励曲线证明，`CPPO`收敛速度更快且训练稳定性强。

关键词：强化学习，`GRPO`，`CPPO`，训练效率，泛化能力
