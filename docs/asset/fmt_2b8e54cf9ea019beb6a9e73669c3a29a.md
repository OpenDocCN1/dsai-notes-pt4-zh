### Balance 为 0 的原因

从截图中看，`PROMO CODE` 类型的交易 `Balance` 都是 0，而 `PURCHASE` 类型有正确的 `Balance` (230, 130)。

原因：在 `redeemPromoCode.ts` Cloud Function 中，我们写入 `transaction` 记录时没有包含 `creditsAfter` 字段。
