# 🤔 如何本地部署

如果只是想简单体验，或者本地算力充足，希望保护数据安全，那么可以考虑本地部署的方案。本地部署优势：

1. 响应更快更稳：避免网络延迟
2. 灵活定制模型：可针对性优化
3. 数据更安全：敏感信息不离本地
4. 节省长期成本：无订阅费用
5. 支持离线使用：断网仍可运行
6. 自由切换模型：适配不同需求
