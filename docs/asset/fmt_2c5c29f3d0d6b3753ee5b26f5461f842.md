
# GDPR下企业免责

> 来源：https://docs.feishu.cn/docx/H4b2dMhL2oQDI2xsj0Ac9boPnF0

## 问：在欧盟的数据保护问责框架下，是否有关于企业履行了什么样的程序可以免责的制度安排？（p.s. 这里的免责不包含义务的豁免）

### 答1：要分事前事后。没有定规一定免责，认证也不是绝对的。有监管机构沟通机制，但各国的实践及水平不一。

## 追问：行政处罚有比较丰富的指导和案件资源（比如EDPB5月新出的guideline），但就像您说的，各国行政执法机制不一，只考虑mitigating factor是比较草率的。比如在过错追责的机制下，企业的哪些行为可以作为抗辩事由呢？

### 答2：其实征求意见稿04/2022也已经给出了比较多的面向。但具体的就很难说了。可能当地的DPO比较有发言权。这块对我们来说借鉴意义有限，尤其是监管决定事先不和我们打招呼的情况下。先抄作业，跟着做体系慢慢完善。各部门监管，也是一样的心态。
