## 2️⃣ AAAI 2025 | 北航、港城大提出POI-Enhancer：基于大模型的POI表征学习增强框架

+ 北航和港城大联合提出的POI-Enhancer框架，利用大语言模型增强兴趣点表征学习。
+ 通过设计专门的提示词和特征对齐，POI-Enhancer有效提取并融合LLM中的地理知识。
+ 实验表明，该框架能显著提升多个基线模型在兴趣点推荐、分类和流量预测等任务上的表现。
+ 框架包含提示生成、特征提取、表征增强和多视图对比学习等多个模块。
+ 研究证明了从LLM中提取地理知识并融合到兴趣点表征中的可行性与有效性。

### 关键词

## 3️⃣ 阿里通义、港科大等提出RAG与长文本对比新框架，助力智能路由决策机制设计

+ 阿里巴巴通义实验室联合香港科技大学与宾夕法尼亚州立大学提出了RAG与长文本处理的新框架，探索RAG和长文本语言模型在不同任务类型和上下文中的相对优势。
+ 研究通过LaRA Benchmark系统性比较了RAG和长文本LLMs，发现RAG在计算效率上有显著优势，尤其在处理超长文本时。
+ 实验结果显示，RAG对于基础能力较弱的模型性能提升显著，而长文本LLMs在处理结构严谨的学术文本时表现更佳。
+ 研究还发现，随着上下文长度的增加，RAG的优势变得更加明显，而在不同文本类型中，学术论文上表现最佳，小说文本上表现最差。
+ LaRA Benchmark为未来RAG和长文本LLMs的研究提供了新的方向，包括开放性问题的评估和复合任务的模拟。

### 关键词
RAG，长文本LLMs，LaRA Benchmark，计算效率，智能路由决策

## 5️⃣ The Batch：797 | 扩散模型生成文本

+ 硅谷初创公司Inception Labs推出Mercury Coder，一款扩散模型生成代码的工具，具有小型和迷你版本。
+ Mercury Coder工作原理类似图像扩散模型，通过逐步去噪改进输出，速度快且性能出色。
+ Inception Labs联合创始人论文描述了使用分数熵训练文本扩散模型的方法，提升了模型性能。
+ Mercury Coder在速度上比同类小型代码模型快3.5到18倍，在编码任务基准测试中表现优异。
+ 文本扩散模型比自回归模型更快速，有望进一步加速文本生成，推动智能体和推理发展。
