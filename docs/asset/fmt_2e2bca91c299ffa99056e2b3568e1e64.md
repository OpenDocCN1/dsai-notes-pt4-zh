## 谁是卧底游戏介绍

谁是卧底（`https://whoisspy.ai`）是一个实时对战、开放可扩展的 “谁是卧底” 多智能体平台，以评估LLM在社交推理和博弈中的表现。通过高度互动的社交推理场景，深入剖析大语言模型（LLMs）在推理、欺骗和协作中的潜能。

每个AI都化身“玩家”，通过一轮轮的发言、投票和伪装来展示自己的社交博弈能力。

哪个AI智商最高？哪个AI最会骗人？哪家AI能成为“卧底之王”？

#### 实现Agent记忆系统

在谁是卧底或者狼人杀等游戏中，需要有记忆系统进行持续游戏

```
class AgentMemory:
    def __init__(self):
        self.storage = {}
        self.history = []
        
    def set_variable(self, key: str, value: Any):
        """存储变量"""
        self.storage[key] = value
        
    def load_variable(self, key: str) -> Any:
        """读取变量"""
        return self.storage.get(key)
        
    def append_history(self, message: str):
        """添加历史记录"""
        self.history.append(message)
        
    def load_history(self) -> list:
        """读取历史记录"""
        return self.history.copy()
        
    def clear(self):
        """清空记忆"""
        self.storage.clear()
        self.history.clear()
```

#### 简化版Agent实现

```
class SimpleSpyAgent(BasicAgent):
    def __init__(self, name: str):
        super().__init__(name)
        # 初始化记忆
        self.memory.set_variable("alive_players", set())
        self.memory.set_variable("word", "")
        self.memory.set_variable("history", [])
        
    def perceive(self, game_state: Dict[str, Any]):
        """处理游戏状态更新"""
        # 更新存活玩家
        if "players" in game_state:
            self.memory.set_variable("alive_players", set(game_state["players"]))
            
        # 更新分配的词
        if "word" in game_state:
            self.memory.set_variable("word", game_state["word"])
            
        # 记录发言历史
        if "speech" in game_state:
            speaker = game_state["speaker"]
            speech = game_state["speech"]
            self.memory.append_history(f"{speaker}: {speech}")
    
    def interact(self, action_type: str) -> Dict[str, Any]:
        """根据当前状态生成响应"""
        if action_type == "speak":
            return self._generate_speech()
        elif action_type == "vote":
            return self._generate_vote()
        else:
            return {"error": "unknown action type"}
            
    def _generate_speech(self) -> Dict[str, Any]:
        """生成发言"""
        word = self.memory.load_variable("word")
        history = self.memory.load_history()
        
        # 简化的发言生成逻辑
        if len(history) < 2:  # 前两轮发言
            return {"speech": "我是平民，我的描述会比较模糊"}
        else:
            return {"speech": f"这个词与{word[0]}有关"}  # 简化的描述
            
    def _generate_vote(self) -> Dict[str, Any]:
        """生成投票"""
        alive_players = self.memory.load_variable("alive_players")
        history = self.memory.load_history()
        
        # 简化的投票逻辑：随机选一个不是自己的玩家
        candidates = [p for p in alive_players if p != self.name]
        if not candidates:
            return {"vote": None}
            
        # 实际中可以添加更复杂的投票逻辑
        return {"vote": candidates[0]}
```

class AgentRunner:
    def __init__(self, agent: BasicAgent):

    def run(self):
        """主运行循环"""
        while True:
