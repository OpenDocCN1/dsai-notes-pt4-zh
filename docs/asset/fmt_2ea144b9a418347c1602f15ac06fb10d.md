
# 你对AI的应用在哪个层次？

> 来源：[https://my.feishu.cn/docx/JgcwdRtRgo97R1xkRshcLTGVn5d](https://my.feishu.cn/docx/JgcwdRtRgo97R1xkRshcLTGVn5d)

不同人群对AI的应用层次，大致可分为以下三大层级：

![](img/8b8feef0653560a7629b1126388d3ba5.png)

## 1. Layman (外行人)

+ 对AI的认知有限，可能停留在“高科技”的模糊印象。
+ 与AI的互动方式简单，例如使用“你好，AI！”这样的基本指令。
+ 对于如何应用AI工具缺乏了解。

## 2. Beginner (初学者)

+ 开始尝试使用AI工具来解决问题，例如使用AI绘图工具生成图片。
+ 主要应用方式为“Prompt-Reflection”（提示-反馈），即通过不断调整提示词来优化结果。
+ 对AI的基本概念有所了解，例如模型训练、参数调整等。

## 3. Deep User (深度用户)

+ 深入理解AI，并能进行更复杂的应用，主要体现在三个方向：
+ Tool User (工具使用者): 能够熟练使用各种AI工具，并在不同场景中应用它们，以及理解其背后的工作原理，能够进行简单的调整和优化。例如，利用AI工具进行数据分析、自动化任务等。
+ `Planning (规划者)`: 能够将AI工具和推理程序融入到工作流程中，进行系统性的规划和执行。例如，设计一个自动化流程，并使用AI工具进行监控和优化。
+ Multi-agent (多智能体): 能够协调多个AI智能体协同工作，实现更复杂的目标。例如，设计一个由多个AI机器人组成的团队，完成一项复杂的任务。

总而言之，随着对AI和推理程序的理解和应用能力的提升，用户可以从简单的指令互动，逐渐发展到工具使用、流程规划，最终达到多智能体协同应用的深度层次。
