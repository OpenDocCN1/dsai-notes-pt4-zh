
# SD局部重绘（图片如何增加细节）

> 来源：[https://my.feishu.cn/docx/QiifdaMHcoSAWUxcdxncxJKGnlf](https://my.feishu.cn/docx/QiifdaMHcoSAWUxcdxncxJKGnlf)

## 第一步：选择模型

根据想要的效果选择模型，如果不知道可以多尝试几个模型，找到合适自己的。

![](img/50acdc7577d88e4753972a7426bfa433.png)

## 第二步：上传图片到图生图局部重绘，用笔刷画出需要增加的地方

![](img/450e1a5b076f4989ee1ebe2f9f9d8ad4.png)

## 第三步：写提示词

提示词也需要自己不断的尝试。

比如池塘，水池，锦鲤池出来的效果就完全不一样。

池塘　                            水池　　                             　锦鲤池

![](img/3fb29b5ace711f84f6ccc6b877d77693.png)

![](img/37265b5431f61487a585625163c40d9a.png)

![](img/ef11eb66b3f9bdc33e1088a1753169d93.png)

如果你不知道如何描述可以照一张自己想要的效果图用图生文的功能看看AI如何写关键词：

![](img/5964468faf386d44beb6f8705aab605e.png)

## 第4步：检查尺寸出图

![](img/dd02a7cbafcbc1c845e8e626a21575d5.png)

尺寸记得点三角形统一。如果超过1024分辨率需要处理一下。以相同倍率相除。比如：4032除以4和3024除以4。

![](img/650d7a33df26addd45a52dcb9193f8d5.png)
