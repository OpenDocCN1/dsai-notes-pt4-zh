
# 机器学习模型可解释性方法

## 模型无关的解释方法

+ `Model-agnostic`：不需要知道模型的类型和参数，将模型近似于黑盒进行研究，可以适用于不同结构的模型（`CNN`、`SVM`等）。

### 基于特征分析的解释方法

特征分析技术（`Feature Analysis`）可以应用于任何神经网络，用于实现比较、分析和可视化神经网络的神经元和网络层的表达。通过特征分析，可以识别对模型决策影响大的敏感特征以及模型对这些特征的处理方式。例如，通过特征分析，我可以去知道某个神经元或者是某一个网络层是负责做什么的，例如负责分类、识别边缘或者识别图像质地、纹理，比如更高级的，在人脸识别中识别五官轮廓。

#### 特征可视化（`Feature Visualization`）

我们可以通过卷积神经网络从原始图像的像素中学习抽象特征和概念。首先，图像经过许多卷积层，在这些卷积层中网络学习到新的且越来越复杂的特征；之后，转换后的图像特征通过全连接层，输出分类或预测结果。

从下图我们可以看出，较低层的卷积层学习到边缘和简单纹理等特征；后面的卷积层学习到更复杂的纹理和图案等特征；最后的卷积层学习诸如对象或对象部分等特征；全连接层学习将来自高级特征的激活连接到要预测的单个类。

[特征可视化](https://link.zhihu.com/?target=https%3A//distill.pub/2017/feature-visualization/)（`Feature Visualization`）的核心思想是，通过找到使特定单元激活最大化的输入，显式地展示出网络学习到的特征。不同级别的单元都可以进行特征可视化，如下图所示：A) 卷积神经元，B) 卷积通道，C) 卷积层，D) 神经元，E) 隐藏层，F) 类别概率神经元（`Class probability neuron`），这些结构都可以进行特征可视化。在神经网络中神经元通道数量过于大的时候，可以以通道或者卷积层为单位进行可视化。

#### 网络剖析（`Network Dissection`）

[网络剖析](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1711.05611)（`Network Dissection`）的核心思想是：神经网络的单元（如卷积通道）学习到的是解耦的特征，可以将 `CNN` 通道的高度激活区域与人类概念（对象、部件、纹理、颜色等）相联系，并量化分析模型不同隐藏单元的语义特征。

![](img/455ec7748a423e6fa4a2a8d233a3bb24.png)

Bau, D., Zhou, B., Khosla, A., Oliva, A., & Torralba, A. (2017). Network Dissection: Quantifying Interpretability of Deep Visual Representations. 2017 IEEE Conference on Computer Vision and Pattern Recognition (CVPR), 3319-3327. abs/1711.05611

论文作者构建了一个带有不同语义概念的图片数据集 `Broden`，里面每张图都有逐像素（`pixel-wise`）的标记（颜色，纹理，场景，物体部分，物体等），即对于一张图片包含的语义概念，都有对应的 `label map`，我们接下来就用这个数据集来理解一个训练好的网络学习的语义概念。

对于一个训练好的网络模型，输入 `Broden` 中的所有图片，然后收集待解释的单元 `k` 在所有图片上的激活图（`activation map`，或称特征图 `Feature map`），这里待解释单元 `k` 可以是某一个神经元、通道、卷积层；之后将激活图插值放大到原图大小后，将大于设定阈值的值设为1，其余为0，从而只关注响应较大的区域；将这些区域作为待解释的单元 `k` 的语义表征，得到一个标记高度激活的区域的、二值的激活掩码（`mask`）。

为了找到待解释单元 `k` 识别的人类概念，将激活掩码与与所有数据集中的标记概念进行比较。计算[激活掩码 `M_`](https://link.zhihu.com/?target=https%3A//learnopencv.com/intersection-over-union-iou-in-object-detection-and-segmentation/) `k` 和真实语义概念 `label map` 的掩码 `L_c` 之间的 [IoU 分数](https://link.zhihu.com/?target=https%3A//learnopencv.com/intersection-over-union-iou-in-object-detection-and-segmentation/)（`Intersection over Union`，交并比）：

其中    代表数据集的样本数。如果 `IoU` 大于一定值，即待解释单元 `k` 和对应的语义概念重合率较大，即意味着该神经单元是对这个概念的检测器。

对于给定的输入图像和经过训练的网络（固定权重），我们将图像向前传播到目标层，放大激活以匹配原始图像大小，并将最大激活与实际的像素分割情况进行比较。

作者在 [`ImageNet`](https://link.zhihu.com/?target=https%3A//www.image-net.org/)和 [`Places`](https://link.zhihu.com/?target=http%3A//places2.csail.mit.edu/)上训练了多种网络 [`AlexNet`](https://link.zhihu.com/?target=https%3A//paperswithcode.com/method/alexnet)， [`VGG`](https://link.zhihu.com/?target=https%3A//paperswithcode.com/method/vgg)， [`GoogLeNet`](https://link.zhihu.com/?target=https%3A//paperswithcode.com/method/googlenet)， [`ResNet`](https://link.zhihu.com/?target=https%3A//paperswithcode.com/method/resnet)等典型的 `CNN` 模型上实验，可视化和标定各个网络的神经元；实验结果发现，每种网络内部都有可解释性的语义神经元出现，下图是 `ResNet`，`GoogLeNet` 里出现的检测五种概念：房子、狗、火车、植物、飞机的神经元。

我们可以总结一下基于特征分析的两种方法：

+   方法优点：
    +   通过特征可视化，可以了解到神经网络首先学习简单的边缘和纹理检测器，之后的更高层中学习抽象部分和对象检测器；
    +   网络剖析扩展了这些结论并使网络单元的可解释性变得可测量；
+   方法缺点：
    +   许多特征可视化图像包含一些没有文字或心理概念的抽象特征，但这不意味着对图像的解释；
    +   网络剖析需要使用概念在像素级别标记的数据集，这些数据集需要花费大量精力来收集。

### 基于概念分析的解释方法

这个方法的名字叫 [`TCAV`](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1711.11279)。其中，[`概念激活向量`](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1711.11279)（`Concept Activation Vectors`，`CAVs`）：将一个概念定义为一个向量，而 `TCAV`（`Testing with CAV`）用 `方向导数`（`directional derivatives`）来量化模型预测对 `CAV` 学习到的底层高级概念的敏感度，从而解释模型对特定概念的学习程度。

`TCAV`的优点有：

+   `Accessibility`：不需要用户有深度学习的经验；

+   `Customization`：适应任何概念（比如性别），而且不受限于训练过程中所考虑的概念；

+   `Plug-in readiness`：不需要重新训练或修改模型就可以直接工作；

+   `Global quantification`：可以用单个量化度量解释类别或一组示例，而不只是解释单个数据输入。

其步骤是：

1.  定义一个感兴趣的概念；例如，可以选择一组表示一个概念的样本集，找到一个单独的有概念标签的数据集；

1.  计算目标的 `CAV`

1.  根据第 1 步给出的概念，在模型第 `l` 层的激活空间中寻找一个表示该概念的向量；之后定义一个概念激活向量（`CAV`）作为超平面的法线，将模型激活过程中没有概念的例子和有概念的例子分开；

1.  例如，收集一组针对类别 `C` 的正例 `P_C`（如条纹对象的图像）和一组任意的负例 `N`（如一组随机图像），然后训练一个二元线性分类器来区分两个集合数据在目标模型第 `l` 层激活，这个分类器 `v^l_C` 即为一个针对概念 `C` 的线性 `CAV`；

1.  计算方向导数和概念敏感度

1.  类别 `k` 对概念 `C` 的“概念敏感性”可用方向导数计算，表示为：

### 基于规则提取的解释方法

我们知道，可以很容易地构造出 [`决策树`](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Decision_tree)（`Decision Tree`）的逻辑规则解释。比如

![](img/a0b0ba42180208b2a26f264ffd122f1e.png)

周志华, (2016). 机器学习，北京: 清华大学出版社. 4.2

就可以写作这样的逻辑：

```
if (纹理==清晰) and (触感 == 硬滑) then 好瓜;
if (纹理==清晰) and (触感 == 软粘) then 坏瓜;
if (纹理==清晰) and (根蒂 == 蜷缩) then 好瓜;
if (纹理==清晰) and (根蒂 == 稍蜷) and (色泽 == 青绿) then 好瓜;
...
if (纹理==模糊) then 坏瓜;
```

可以抽取出逻辑规则

对于一个神经网络，我们可以构建出等效的决策树，实现对原模型的逻辑规则解释。步骤是先计算黑盒模型的稀疏局部对比，构造输入样本、正常扰动样本和对抗样本的三元组关系，然后创建自定义的布尔特征集，利用布尔特征构造原模型的决策树等效模型。
