
While many of the prominent LLMs (such as Llama3) used today are “dense” models (i.e. without enforced sparsification), Mixture-of-Experts (MoE) architectures [are becoming](https://the-decoder.com/gpt-4-architecture-datasets-costs-and-more-leaked/) increasingly popular for navigating tradeoffs between “knowledge” and efficiency, used perhaps most notably in the open-weights world by Mistral AI’s “Mixtral” models (8x7B and 8x22B), and rumored to be used for GPT-4. In MoE models, only a fraction of the parameters are “active” for each step of inference, with trained router modules for selecting the parallel “experts” to use at each layer. This allows models to grow in size (and perhaps “knowlege” or “intelligence”) while remaining efficient for training or inference compared to a comparably-sized dense model.

虽然当今使用的许多著名的LLMs（例如Llama3）都是“密集”模型（即没有强制稀疏），但专家混合（MoE）架构在“知识”与效率之间的权衡中变得越来越流行。在开放重量世界中最显著的使用可能是 Mistral AI 的“Mixtral”模型（8x7B 和 8x22B），并且有传言称用于 GPT-4。在 MoE 模型中，只有一小部分参数对于每个推理步骤都是“活跃的”，并且经过训练的路由器模块用于选择在每一层使用的并行“专家”。与同等大小的密集模型相比，这允许模型的大小（可能还有“知识”或“智能”）增长，同时保持训练或推理的效率。

See this [blog post](https://huggingface.co/blog/moe) from Hugging Face for a technical overview, and this [video from Trelis Research](https://www.youtube.com/watch?v=0U_65fLoTq0) for a visualized explainer.

请参阅 Hugging Face 的这篇博文了解技术概述，查看 Trelis Research 的视频了解可视化解释。

## Chapter 19: Instruct Fine-Tuning 第19章：指导微调

Instruct fine-tuning (or “instruction tuning”, or “supervised finetuning”, or “chat tuning” – the boundaries here are a bit fuzzy) is the primary technique used (at least initially) for coaxing LLMs to conform to a particular style or format. Here, data is presented as a sequence of (input, output) pairs where the input is a user question to answer, and the model’s goal is to predict the output – typically this also involves adding special “start”/”stop”/”role” tokens and other masking techniques, enabling the model to “understand” the difference between the user’s input and its own outputs. This technique is also widely used for task-specific finetuning on datasets with a particular kind of problem structure (e.g. translation, math, general question-answering).

指令微调（或“指令调整”、“监督微调”或“聊天调整”——这里的界限有点模糊）是用于哄骗的主要技术（至少在最初）让 LLMs 符合特定的风格或格式。在这里，数据以（输入，输出）对的序列呈现，其中输入是要回答的用户问题，模型的目标是预测输出 - 通常这还涉及添加特殊的“开始”/“停止”/“角色”标记和其他屏蔽技术，使模型能够“理解”用户的输入与其自己的输出之间的差异。该技术还广泛用于对具有特定类型问题结构（例如翻译、数学、一般问答）的数据集进行特定于任务的微调。

See this [blog post](https://newsletter.ruder.io/p/instruction-tuning-vol-1) from Sebastian Ruder or this [video from Shayne Longpre](https://www.youtube.com/watch?v=YoVek79LFe0) for short overviews.

请参阅 Sebastian Ruder 的博客文章或 Shayne Longpre 的视频以获取简短概述。

## Chapter 20: Low-Rank Adapters (LoRA) 第 20 章：低阶适配器 (LoRA)

While pre-training (and “full finetuning”) requires applying gradient updates to all parameters of a model, this is typically impractical on consumer GPUs or home setups; fortunately, it’s often possible to significantly reduce the compute requirements by using parameter-efficient finetuning (PEFT) techniques like Low-Rank Adapters (LoRA). This can enable competitive performance even with relatively small datasets, particularly for application-specific use cases. The main idea behind LoRA is to train each weight matrix in a low-rank space by “freezing” the base matrix and training a factored representation with much smaller inner dimension, which is then added to the base matrix.

虽然预训练（和“完全微调”）需要对模型的所有参数应用梯度更新，但这对于消费级 GPU 或家庭设置通常是不切实际的；幸运的是，通过使用低阶适配器 (LoRA) 等参数高效微调 (PEFT) 技术，通常可以显著降低计算要求。即使数据集相对较小，这也可以实现具有竞争力的性能，特别是对于特定于应用程序的用例。LoRA 背后的主要思想是通过“冻结”基础矩阵并训练具有更小的内部维度的因子表示来训练低秩空间中的每个权重矩阵，然后将其添加到基础矩阵。

## Chapter 21: Reward Models and RLHF 第 21 章：奖励模型和 RLHF

One of the most prominent techniques for “aligning” a language model is Reinforcement Learning from Human Feedback (RLHF); here, we typically assume that an LLM has already been instruction-tuned to respect a chat style, and that we additionally have a “reward model” which has been trained on human preferences. Given pairs of differing outputs to an input, where a preferred output has been chosen by a human, the learning objective of the reward model is to predict the preferred output, which involves implicitly learning preference “scores”. This allows bootstrapping a general representation of human preferences (at least with respect to the dataset of output pairs), which can be used as a “reward simulator” for continual training of a LLM using RL policy gradient techniques like PPO.

“调整”语言模型最突出的技术之一是人类反馈强化学习（RLHF）；在这里，我们通常假设 LLM 已经经过指令调整以尊重聊天风格，并且我们另外还有一个根据人类偏好进行训练的“奖励模型”。给定输入的不同输出对，其中人类选择了首选输出，奖励模型的学习目标是预测首选输出，这涉及隐式学习偏好“分数”。这允许引导人类偏好的一般表示（至少相对于输出对的数据集），它可以用作“奖励模拟器”，使用 RL 策略梯度技术（如 PPO）持续训练 LLM。

For overviews, see “[Illustrating Reinforcement Learning from Human Feedback (RLHF)](https://huggingface.co/blog/rlhf)” from Hugging Face and “[Reinforcement Learning from Human Feedback](https://huyenchip.com/2023/05/02/rlhf.html)” from Chip Huyen, and/or this [RLHF talk by Nathan Lambert](https://www.youtube.com/watch?v=2MBJOuVq380). Further, [this post from Sebastian Raschka](https://sebastianraschka.com/blog/2024/research-papers-in-march-2024.html) dives into RewardBench, and how reward models themselves can be evaluated against each other by leveraging ideas from Direct Preference Optimization, another prominent approach for aligning LLMs with human preference data.

有关概述，请参阅 Hugging Face 的文章“说明根据人类反馈进行强化学习 (RLHF)”和 Chip Huyen 的“根据人类反馈进行强化学习”，和/或 Nathan Lambert 的 RLHF 演讲。此外，Sebastian Raschka 的这篇文章深入探讨了 RewardBench，以及如何利用直接偏好优化的思想来相互评估奖励模型本身，直接偏好优化是另一种将 LLMs 与人类偏好数据对齐的重要方法。
