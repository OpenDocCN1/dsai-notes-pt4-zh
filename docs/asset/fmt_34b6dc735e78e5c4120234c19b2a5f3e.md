## TameMe!

+ 产品功能
+ 陪伴感：手机桌面组件
+ 成就感：AI agent 小猫，云养猫，AI 不完美的地方是小猫的有趣
+ 治愈感：生图功能集成，比如 AI 发动态，AI 社交
+ 专属感：小猫会把你的特性记住，存在向量数据库里
+ 问题
+ 主页小猫的形象很难有更多的变化
+ 主页小猫 3D 形象制作费用
+ Agent 成本太高
+ 商业化：跟一些慈善机构的洽谈，帮他们的产品优化，然后把产品给他们；toB形式将产品送给他们（？）
