
+ `~/openclaw/workspace`: AI 助手的工作沙箱

如果遇到权限错误，修复主机目录的所有权：

```
sudo chown -R $USER:$USER ~/.openclaw
sudo chown -R $USER:$USER ~/openclaw/workspace
```

[citation](https://blog.promptlayer.com/how-to-install-openclaw-step-by-step-guide-formerly-clawdbot-moltbot/)

**步骤 3: 进入容器配置**

```
# 进入容器
docker exec -it openclaw bash

# 运行配置向导
openclaw onboard

# 退出容器
exit
```

**步骤 4: 使用 Docker Compose（推荐）**

创建`docker-compose.yml`文件以简化管理：

```
version: '3.8'

services:
  openclaw:
    image: openclaw/openclaw:latest
    container_name: openclaw
    restart: unless-stopped
    ports:
      - "18789:18789"
    volumes:
      - ~/.openclaw:/root/.openclaw
      - ~/openclaw/workspace:/root/openclaw/workspace
    environment:
      - NODE_ENV=production
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
```

启动服务：

```
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

## 4.4 配置文件详解

OpenClaw 的所有配置存储在`~/.openclaw`目录中。理解配置文件结构有助于进行高级定制和故障排查。

**配置目录结构**

```
~/.openclaw/
├── config.json          # 主配置文件
├── gateway.json         # 网关配置
├── channels/            # 通信渠道配置
│   ├── telegram.json
│   ├── whatsapp.json
│   └── web.json
├── skills/              # 已安装技能
├── credentials/         # API 凭证(敏感)
│   ├── openai.key
│   ├── anthropic.key
│   └── google.key
└── logs/                # 日志文件
    ├── gateway.log
    └── skills.log
```

**主配置文件 (`config.json`)**

```
{
  "version": "2026.3.0",
  "workspace": "/home/user/openclaw/workspace",
  "defaultModel": {
    "provider": "openai",
    "model": "gpt-4-turbo"
  },
  "gateway": {
    "port": 18789,
    "host": "localhost",
    "authToken": "your-secure-token-here"
  },
  "channels": {
    "enabled": ["telegram", "web"],
    "default": "telegram"
  },
  "security": {
    "allowedContacts": [],
    "allowedDomains": [],
    "sandboxMode": true
  },
  "logging": {
    "level": "info",
    "maxFiles": 7,
    "maxSize": "10m"
  }
}
```

**关键配置项说明**

+ `workspace`: AI 助手的工作目录，所有文件操作都在此沙箱内进行
+ `defaultModel`: 默认使用的 AI 模型
+ `gateway.port`: 网关服务监听端口（默认 18789）
+ `gateway.authToken`: 访问控制令牌，务必设置强密码
+ `channels.enabled`: 启用的通信渠道
+ `security.sandboxMode`: 启用沙箱模式以限制文件系统访问
+ `security.allowedContacts`: 白名单联系人（仅这些用户可以使用助手）
+ `security.allowedDomains`: 白名单域名（限制网络访问）

**网关配置 (`gateway.json`)**

```
{
  "rateLimit": {
    "enabled": true,
    "maxRequests": 100,
    "windowMs": 900000
  },
  "cors": {
    "enabled": true,
    "origins": ["http://localhost:3000"]
  },
  "webhook": {
    "enabled": false,
    "url": "",
    "secret": ""
  }
}
```

+ `rateLimit`: 限制请求频率，防止滥用
+ `cors`: 跨域资源共享设置，用于 Web UI
+ `webhook`: 外部触发器配置，可用于集成其他服务

**修改配置**

可以通过以下方式修改配置：

1. **命令行参数**：`openclaw gateway --port 8080`
2. **环境变量**：`export OPENCLAW_PORT=8080`
3. **直接编辑配置文件**：`nano ~/.openclaw/config.json`

修改配置后需要重启网关：

```
openclaw gateway restart
```

**安全最佳实践**

+ 将`~/.openclaw`目录权限设置为 700：`chmod 700 ~/.openclaw`
+ 定期轮换`authToken`
+ 不要将配置文件提交到版本控制系统
+ 使用环境变量管理敏感信息（如 API Keys）

## 4.5 首次运行与验证

完成安装和配置后，需要验证 OpenClaw 是否正常工作。本节介绍如何进行首次运行测试和常见问题排查。

**启动网关服务**

```
# 启动网关
openclaw gateway start

# 查看启动日志
openclaw logs --follow
```

如果一切正常，你应该看到类似以下的输出：

```
[INFO] OpenClaw Gateway v2026.3.0
[INFO] Workspace: /home/user/openclaw/workspace
[INFO] Loading skills... 12 skills loaded
[INFO] Starting gateway on http://localhost:18789
[INFO] Telegram channel connected
[INFO] Gateway is ready 🦞
```

**验证网关状态**

```
# 检查网关是否运行
openclaw gateway status

# 运行系统诊断
openclaw doctor
```

`openclaw doctor` 会检查：

+ Node.js 版本
+ 依赖包完整性
+ API Key 有效性
+ 网关连接状态
+ 通信渠道配置
+ 工作空间权限

**访问 Web 控制面板**

打开浏览器访问`http://localhost:18789`，你应该看到 OpenClaw 的 Web 控制面板。首次访问需要输入`authToken`（在配置向导中设置的令牌）。

控制面板功能包括：

+ 实时聊天界面
+ 技能管理（安装/卸载/配置）
+ 系统监控（CPU、内存、请求统计）
+ 日志查看器
+ 配置编辑器

**测试通信渠道**

**Telegram 测试**

1. 打开 Telegram 应用
2. 在搜索框中输入你的 bot 用户名（配置时创建的）
3. 点击 “Start” 开始对话
4. 发送测试消息： “Hello, who are you?”
5. 如果 bot 回复，说明配置成功

**WhatsApp 测试**

1. 打开 WhatsApp
2. 扫描配置时生成的 QR 码（如果尚未扫描）
3. 向 bot 号码发送消息
4. 等待回复

**Web UI 测试**

直接在控制面板的聊天界面输入消息并发送。

**功能验证测试**

执行以下测试以验证核心功能：

1. **基础对话**

```
你: 你好,请介绍一下自己
Bot: 我是 OpenClaw,你的个人 AI 助手...
```

2. **文件操作**

```
你: 在工作空间创建一个名为 test.txt 的文件,内容是 "Hello OpenClaw"
Bot: 已创建文件 test.txt
```

验证文件是否存在：

```
cat ~/openclaw/workspace/test.txt
```

3. **网络搜索**（如果安装了搜索技能）

```
你: 搜索 OpenClaw 的最新新闻
Bot: [返回搜索结果]
```

4. **技能调用**

```
你: 列出所有已安装的技能
Bot: [显示技能列表]
```

**常见问题排查**

**问题 1: 网关无法启动**

症状：`openclaw gateway start`失败或超时

解决方案：

```
# 检查端口是否被占用
lsof -i :18789

# 如果被占用,杀死进程或更换端口
openclaw gateway --port 8080

# 查看详细错误日志
openclaw logs --level debug
```

**问题 2: API 认证失败（“0 tokens used”）**

症状：Bot 不响应，日志显示认证错误

解决方案：

```
# 验证 API Key 是否正确
cat ~/.openclaw/credentials/openai.key

# 重新配置 API Key
openclaw config set model.apiKey "sk-..."

# 重启网关
openclaw gateway restart
```

**问题 3: 技能安装失败**

症状：安装技能时报错

解决方案：

```
# 清除 npm 缓存
npm cache clean --force

# 重新安装技能
openclaw skill install <skill-name>

# 如果是编译错误,安装构建工具
# macOS:
xcode-select --install
npm install -g node-gyp

# Linux:
sudo apt install build-essential python3 -y
</skill-name>
```

**问题 4: Telegram bot 无响应**

症状：发送消息后 bot 不回复

解决方案：

1. 检查 bot token 是否正确：`openclaw config get channels.telegram.token`
2. 验证网关是否运行：`openclaw gateway status`
