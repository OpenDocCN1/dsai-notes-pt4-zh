## 定义请求文件 request.py 并执行

### 创建 request.py
创建 `request.py` 文件。脚本内容示例如下。

```python
import requests
import json

# 定义请求，更换具体的ip地址
url = "http://192.168.0.49:8000/v1/completions"
headers = {
    "Content-Type": "application/json"
}
data = {
    "model": "deepseek",
    "prompt": "San Francisco is a",
    "max_tokens": 100,
    "temperature": 0
}

# 发送POST请求
response = requests.post(url, headers=headers, data=json.dumps(data))

# 打印响应内容
print(response.json())
```

### 执行命令请求
执行命令 `python request.py`。

```bash
python request.py
```
