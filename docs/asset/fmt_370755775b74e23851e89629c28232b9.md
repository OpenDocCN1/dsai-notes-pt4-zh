# 提示词表现测试 - ChatGLM2 130B

在针对 130B 模型的测试当中，由于其参数量和 ChatGPT 网传的 175B较为接近，故采用ChatGPT 作为对比。实际结果中显示，ChatGLM2-130B 在多轮对话（调用模型内部知识库）、情感分析、文本总结、以及内容分类方面都和 ChatGPT 相当，甚至在规范化输出上强过 ChatGPT 一点。
