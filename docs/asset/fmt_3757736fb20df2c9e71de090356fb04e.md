# 5. 配置事件订阅

> ⚠️ **重要**：必须先完成「OpenClaw 插件安装与配置」后再进行此步骤，否则会提示 `应用未建立长连接`。

## 步骤

1. 进入「事件与回调」

![](img/2cd09ffa0707c2638bd09187e2bea596.png)

2. 订阅方式选择「使用长连接」

![](img/88420ba21196c999354aca39dc69cca0.png)

3. 点击「+ 添加事件」

4. 在「消息与群组」分类中勾选：

| 事件名称 | 事件标识 | 说明 |
| --- | --- | --- |
| 接收消息 | `im.message.receive_v1` | 接收用户发送的消息（必需） |
| 消息已读 | `im.message.message_read_v1` | 用户已读消息通知（可选） |
| 机器人进群 | `im.chat.member.bot.added_v1` | 机器人被拉入群聊（可选） |
| 机器人被移出群 | `im.chat.member.bot.deleted_v1` | 机器人被移出群聊（可选） |

![](img/04218d8fb44755462b10ece80fd1f8bd.png)

5. 点击「确定」保存

### 消息接收说明

+ 单聊场景：接收所有消息

+ 群聊场景：默认仅接收 @ 机器人的消息

+ 如需接收群聊所有消息：在「机器人」配置页勾选「接收群聊所有消息」

## 6. 回调配置

1. 点击回调配置

2. 点击订阅方式的小图标

3. 选择长连接接受回调

![](img/a00b0d8f9ea5f9cf26405e4b9a44e723.png)

## 7. 发布版本

> ⚠️ **重要：** 所有配置修改必须通过「创建版本」并发布后才能生效。

1. 点击页面顶部「创建版本」

![](img/b070ec02bcdd049313af60b4739666ba.png)

2. 填写版本号（如：`v1.0.0`）和更新说明

3. 点击「保存」

![](img/25501361696760487f5a18620f89cc41.png)

4. 保存以后会弹窗提示是否要发布，选择确认发布

![](img/3e5b787f99963d0cfa99edbc99098b02.png)

5. 等待审核通过（小型企业通常立即通过），不勾选外部群使用是免审的

# 📬 接入企业🛰️

## 前期准备

当前，可用企业🛰️智能机器人接入 OpenClaw。

在将 OpenClaw 接入企业🛰️之前，请确认当前设备已经完成：

1. 客户端已安装企业🛰️最新版本

2. 在本地设备安装 OpenClaw；或者在腾讯云轻量应用服务器 Lighthouse 实例中部署了 OpenClaw

## 1. 以长连接方式创建智能机器人，获取 `Bot ID` 和 `Secret`

![](img/d9a793fd422fbf73ba08d9d2a73b449f.png)

## 2. 关联企微机器人与 OpenClaw

虾语（来自 [Openclaw 连接企业🛰️](https://nxmlezyuz55.feishu.cn/docx/CQBcdj2SBo4v3JxPYXJcHvWunbI)），直接复制给已经配好了大模型的 OpenClaw，让它来操作：

> 请帮我安装企业微信的 `channel`，`@wecom/wecom-openclaw-plugin`，相关说明在下面：在本地终端部署 OpenClaw 并关联机器人
> 以本地部署为例，在本地终端，输入以下命令，安装企微插件。
> `openclaw plugins install @wecom/wecom-openclaw-plugin`
> 安装成功提示如图。
> 重启 OpenClaw。
> `openclaw gateway start` openclaw 网关启动

> `openclaw channels add`
> 在 `select channel` 步骤，选择 channel 为企业微信。
> 输入企业微信机器人 `Bot ID`、`Secret`。
> 选择 `finish`。选择完成。
> 选择配对方式，选择 `Pairing`。
> 完成后续配置，并可看到配置渠道成功。
> 在企业微信中，保存机器人，并跟他发消息。会收到一个配置密钥。
> 复制此信息最后一行，并输入在终端中，完成配对。
> 此时可在企业微信中正常对话。
