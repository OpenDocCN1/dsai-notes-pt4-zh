
# 单点监督旋转目标检测方法：`PointOBB`

> 来源：[https://v11enp9ok1h.feishu.cn/docx/RUdpdgD28o8fSjxGNJ5cKX4en1e](https://v11enp9ok1h.feishu.cn/docx/RUdpdgD28o8fSjxGNJ5cKX4en1e)

> “遥感大模型的关键一步”

# 引言

随着数据驱动产生大模型涌现能力的理论在各种场景下获得成功论证，遥感大模型也呼之欲出。近期许多单位都开始不断的做大自己的数据集，希望可以先一步做出自己的大模型。但是，我们似乎忽略了一个问题，就是数据的标注成本也在随着数据的增加不断的增长。尽管社区开始尝试使用水平框标注来进行弱监督形式的旋转检测，但是水平框的标注也很花时间和人力啊！所以，目前的主流思路就是，使用点进行标注，这样省时省力，而且对于小目标和特别小的目标，单点标注可谓是相当友好的。

现有研究主要通过`Point-to-HBox-to-RBox`或`Point-to-Mask-RBox`的方式实现从点到旋转框的转换，不过从这么多to就看出来了，转来转去。前者，你的成功取决于前面的`HBox`的努力，后者，属于拿大刀砍蚊子，耗费力气还很难命中目标。

其实说起来要想解决也很简单。我们就不转了，直接端到端的从`Point`直接到`RBox`，这样问题似乎就迎刃而解了。

于是，在这样的背景下，本篇工作`PointOBB` 就通过单点标注提出了一种新的弱监督学习方法，不仅的减少了标注成本，还提升了检测的效率。

该方法的详细介绍可参见arXiv论文《PointOBB: Learning Oriented Object Detection via Single Point Supervision》和GitHub代码库。

> arXiv：`https://arxiv.org/abs/2311.14757`

> GitHub：`https://github.com/Luo-Z13/pointobb`

# 工作的难点

`PointOBB`能够直接从点标签得到对应的旋转框，作为伪标签来训练常规的旋转检测器。遵循现有的多实例学习（Multiple Instance Learning，`MIL`）范式，来设计网络结构。

现有大量关于多实例范式的研究（如`OICR`）已经揭示了`MIL`本身的不稳定性，也就是网络会倾向于感知物体最具辨别性的部分而不是它的准确尺度和边界。这一缺点在复杂的遥感影像中被进一步放大了：在实验中发现，`MIL`不仅会出现自然场景中“局部聚焦”的情况，还会出现“背景预测”问题，即对于一些需要上下文信息的目标（尤其是小目标），预测框会过大导致包含无关的背景。

综上，`MIL`的尺度感知不稳定性对于生成精确的旋转框是一个阻碍，能否找到方法解决这一问题呢？

# 方法介绍

`PointOBB`整体框架是基于3个独立的视图来设计的，结构如下：

![](img/3fd691a8ff26928f8f2408d08691fa24.png)

基于原始视图，文中通过随机缩放来创建一个缩放增强视图，通过随机旋转/翻转来创建一个旋转/翻转增强视图，并且在训练的过程中，这两个增强视图会基于一个渐进式的多视图切换策略来进行转换，让网络渐进地先进行较基础的尺度感知学习，然后进行角度学习和预测。

基于上述两个增强视图，文中分别针对尺度和角度的学习设计了两个模块，前者用于增强网络对目标尺度的感知能力，缓解`MIL`的不稳定性；后者则专注于在点标签下基于自监督对称学习来预测基于密集特征图的角度，并与稀疏的目标进行配准来赋予准确的角度。

## 尺度增强模块

该模块基于原始视图和缩放增强视图构建，其核心是Scale-Sensitive Consistency（`SSC`）损失。在基于点标签以固定尺度和比例生成一组候选框后，通过`MIL`的双流结构可以得到它们对应的两类置信度分数：`cls_score` 和 `ins_score` ，在该组内二者的维度都为 `RN×C` ， `N` 为该组内候选框数量， `C` 为类别。`SSC`损失旨在最小化原始视图和缩放视图的同源候选框组之间置信度分数分布的差异。

出发点：对于相同的目标，不论在何种分辨率的视图下，其准确边界应该是不变的。因此当通过随机缩放创建增强视图后，由于候选框也随之缩放，因此符合目标真实边界的预测框应该是与原始视图保持一致的。

基于此，首先对分数进行分布转换，令设定的基础尺度数量为 `G` ，将原始的`RN×C`通过`reshape`转换为 `RG×K` ，这里的 `K` 为尺度无关变量的数量，如比例 × 类别。转换后，基于余弦相似度衡量每个（尺度）组的分数分布的相似度差异：

这里值越小表示相似度越高，`SSC`损失如下：

为了查看`SSC`损失是否起到效果，文中对分数分布以等高线的形式进行了可视化：

## 角度获取模块

该模块基于原始视图和旋转/翻转增强视图构建。如何基于点标签从无到有学习物体的角度呢？在`H2RBox-v2`中对物体对称性进行了探索，我们注意到其中有一个十分有意思的实验：在`HBox`标签出现噪声（尺度失准）扰动时，检测器的性能仍然较为稳定，也就是说，在缺乏尺度信息的点标签设置下，自监督角度学习也可能是准确的。

但是这里面临两个问题：缺乏准确的`Box`边界，常规目标检测器中的样本分配策略无法正常使用；并且预测到的角度是基于密集特征图的，而基于`proposal`的目标是稀疏的，需要从密集预测中为目标计算出对应的角度。对此，文中采用了`Dense-to-Dense`的样本分配和`Dense-to-Sparse`的角度匹配策略。

具体到`Dense-to-Dense`，由于未知目标大小，文中朴素地在每层特征层上在点标签周围的圆形区域内选取正样本。具体到`Dense-to-Sparse`，对于基于特征金字塔预测的密集角度和代表物体的`proposal`，根据`proposal`的尺度进行映射计算，将其分配到特定`level`，然后计算该层`proposal`中心范围内角度预测值的平均值作为角度预测值，赋予`proposal`最终的角度。

### 涴实验

可以看出，`SSC`损失能够带来巨大的性能提升，当然`Dense-to-Sparse`的分配优化也能够起到效果。

![](img/4b17381601323829adfd6d61fc5533aa.png)

对不同视图上`MIL`损失的使用、`SSC`损失中分布转换时的分组方式以及点标签的生成范围设置进行了实验。可以看出，两个增强视图可以看作起到数据增强的效果，对于整体精度都有提升。在以中心点为标签点（0%范围）时，性能有所下降，这可能是由于网络聚焦于部分类别的中心区域（如篮球场中心的圆圈），而模拟真实人工标注误差生成标签点（10%/20%范围）能够避免网络聚焦于中心局部区域。

![](img/f42eb60084c4d57f4cf5cfc9a8512d62.png)

此外还对所使用的渐进式策略和角度分支的设置进行了探究。结合图5(a)和表5，当断掉角度分支和基础网络的梯度回传时，发现其收敛变慢，并且精度下降。因此采用接通梯度，共同优化网络的方式。结合图5(b)和表5，如果在训练的一开始就引入角度分支，那么初始的`MIL`学习的收敛速度会变慢，并且从精度上看也会受到影响，因此文中基于对网络学习收敛过程的观察，设置两个渐进式阶段，逐步引入角度的学习和角度的预测过程，同时从缩放增强视图切换到旋转/翻转增强视图，进行角度和尺度的协同优化。

## 总结

本文对单点监督旋转目标检测进行了探索，但其实可以看到目前`Point`监督的性能和`RBox`/`HBox`监督的性能差异还是较为明显的，当然目前旋转检测领域对于点监督方法的探索也刚刚起步，后续的改进空间还是很大的，个人总结一些可能的改进方向如下：

+ 针对特定类别的改进。现有的点监督方法对于部分边界定义模糊或需要上下文信息来识别的特定类别（如桥梁、高尔夫球场）的检测精度较差，可能可以考虑加入上下文特征或者额外的图像信息来进行改善；

+ 探索`anchor-free`的方法。现有的点监督方法（包括通用目标检测）都是根据预先定义大小形状的`anchor`来进行的，而在全监督目标检测中`anchor-free`和`anchor-based`的方法都出现不少优秀的研究，那么在点监督（或其他弱监督）设置下能否也去探索`anchor-free`的做法呢？个人觉得点监督下这类做法其实难度更大，可能需要引入新的自监督信息；

+ 端到端的框架。本文的方法遵循现有的大多数点监督范式，即基于点生成`RBox`伪标签，然后训练检测器，但端到端地直接训练一个旋转目标检测器是更加general的。实际上在点监督旋转目标检测领域，同期工作`Point2RBox`已经实现了端到端的范式；而在基于点监督的其他领域如水平目标检测、全景分割中，目前的方法可能都还是基于生成伪标签的做法，相信在这些任务中，探索端到端的方法也是有意义的。
