
6.如果你在深圳，建议你参加工作日活动。深圳人都是除了主业，还有副业的，工作日的局基本上都不是”牛马“，深圳工作日的局也特别多。他们的赚钱之道五花八门，社群创始人、保险主理人、多家美团超市老板、👸号变现几十万的大佬等等，每一个都会让你开眼，原来钱还可以这么赚。

# 📝 一个月赚回赚钱票价

我每天都在风向标里溜达，想捡个赚钱的信息，但是看的越多越焦虑，越来越不知道自己要干什么。龙哥说如果要进行下一个知识付费，你就要至少赚回10倍，那我要赶紧赚呀。焦虑啊，一直没转到好的切入点。后来瞎溜达，看到了证券撸羊毛，我前几年每年要算年化的时候，迫使自己疯狂搞主业之外的钱，做过这些，我知道稳赚的。我就想目前没有找到切入点，但是我必须要赚钱呀，一个月赚回了赚钱票价。也告诉了苏苏，她也赚了波，她拉我进赚钱，我应该反馈下她，哈哈。就证券撸毛而言，从以前到现在我应该赚了好几倍票价。有人说现金流不丰富，怎么撸呢，我当时钱都在投资上，现金流很差，朋友教我撸信用卡，一环套一环，因为这是稳定收益，所以没啥风险。其他高风险的不建议撸信用卡哈。如果你私域丰富，也可以自己赚佣金，放单子给他们做。我自己不做这些，不是广告，只是给大家说个撸鸡腿机会。

# 🚀 中了风向标

和苏苏闲聊，她说你去📕发要投资，肯定很多人来找你。当时我本来也想投项目，也想看看人家做什么。于是发了📕做测试，粉丝量小几百的账号，浏览量冲到了1000多，不停有人回复，私聊，又有种风好像要来的感觉。因为写了在北京的缘故，大部分是电影这个赛道，还有其他汽车电池、火锅店、面馆等，原来大家都在做这些，我看了也觉得是个很有趣的测试，最后因为没有我特别感兴趣的项目，都没有深聊下去。过了几天，📕的违规警告来了。最后为了凑3条，把这个发成了风向标，还中标了。后来在风向标群里，有人说合伙人看了觉得有启发，那种帮助到别人的感觉很不错呀~没想过自己也能无心插柳，帮助到别人。

# 🔍 总结

今年我听说，之前港股打新赚几百万的人，后来去玩了A，全亏完了。靠运气赚了的钱，终将回去啊。此文不构成任何投资建议，我的原则是从来不拉任何人投资，拉人投资在我眼里和杀人放火差不多。我也算曾经抓到过小风口的人，起起伏伏，一个资质平庸，但又疯狂想搞钱的女孩，瞎折腾搞了很多，成功的很少。目前我在疯狂找项目，就是不想打工啊。测了盖洛普，我的沟通和交往靠前，这才知道为什么我面试会比较容易过。但是以往的打工经历，几乎没展示过我的优势。上周的北京线下，有圈友说我表述自己的瞎折腾经历、吐槽很有趣。那我是不是应该往自己擅长的地方去深耕赛道。播客和访谈，最近也有了解，但是吧，为爱发电对我目前来说太难了，肯定是希望正反馈快，变现快的项目（谁不想呢）。现在是迷茫期，也希望跑通项目的大佬带带我，也许我不是最聪明的那个，但是我执行力杠杠的！听话照做没问题。不白嫖，知识付费老韭菜。最后，祝看过帖子点赞的靓仔，靓妹日进斗金！
