
```python
import os
import json
from openai import OpenAI, APIError, AuthenticationError
import numpy as np # 导入 numpy 用于向量计算

# --- 安全地获取硅基流动 API Key ---
# 推荐从环境变量读取
api_key = os.getenv("SILICONFLOW_API_KEY")
if not api_key:
    raise ValueError("请设置环境变量 SILICONFLOW_API_KEY (通常以 'fk-' 开头)")

# --- 初始化 OpenAI 客户端，指向硅基流动 API ---
# 注意 base_url 是硅基流动的地址
client = OpenAI(
    api_key=api_key,
    base_url="https://api.siliconflow.cn/v1"
)

print("\n\n--- 场景七：使用硅基流动 Embeddings API (bge-m3) ---")

# --- 准备要嵌入的文本列表 ---
texts_to_embed = [
    "今天北京天气真不错",
    "阳光明媚，适合出去散步",
    "如何学习用 Python 进行数据分析？",
    "深度学习模型训练需要大量计算资源",
    "北京的天气今天很好" # 与第一句意思非常接近
]

print("待嵌入的文本:")
for i, text in enumerate(texts_to_embed):
    print(f"  {i}: {text}")

# --- 定义余弦相似度计算函数 ---
def cosine_similarity(v1, v2):
    """计算两个 numpy 向量之间的余弦相似度"""
    # 确保输入是 numpy 数组
    vec1 = np.array(v1)
    vec2 = np.array(v2)

    # 计算点积
    dot_product = np.dot(vec1, vec2)

    # 计算各自的 L2 范数 (向量长度)
    norm_v1 = np.linalg.norm(vec1)
    norm_v2 = np.linalg.norm(vec2)

    # 计算余弦相似度
    if norm_v1 == 0 or norm_v2 == 0:
        # 避免除以零错误（如果向量是零向量）
        return 0.0
    else:
        similarity = dot_product / (norm_v1 * norm_v2)
        # 由于浮点数精度问题，结果可能略微超出 [-1, 1] 范围，进行裁剪
        return np.clip(similarity, -1.0, 1.0)

try:
    # --- 调用 Embeddings API ---
    print("\n--- 正在调用硅基流动 Embeddings API ---")
    response = client.embeddings.create(
        model="BAAI/bge-m3", # 指定使用 bge-m3 模型
        input=texts_to_embed
    )

    # --- 提取嵌入向量 ---
    embeddings = {}
    for item in response.data:
        # item.embedding 是一个包含 1024 个浮点数的列表
        embeddings[item.index] = item.embedding
        print(f"  获取到文本 {item.index} 的向量 (维度: {len(item.embedding)})")

    # --- (可选) 打印 Token 使用情况 ---
    usage = response.usage
    if usage:
        print("\nToken 使用情况:")
        print(f"  提示 Token 数: {usage.prompt_tokens}")
        # Embeddings API 通常只有 prompt_tokens
        print(f"  总 Token 数: {usage.total_tokens}")

    # --- 计算并打印两两之间的语义相似度 ---
    print("\n--- 计算文本间的语义相似度 (余弦相似度) ---")
    num_texts = len(texts_to_embed)
    # 使用 numpy 格式化输出浮点数
    np.set_printoptions(precision=4, suppress=True)

    similarity_matrix = np.zeros((num_texts, num_texts))

    for i in range(num_texts):
        for j in range(i, num_texts): # 仅计算上三角和对角线
            if i == j:
                similarity = 1.0 # 文本与自身的相似度为 1
            else:
                similarity = cosine_similarity(embeddings[i], embeddings[j])

            similarity_matrix[i, j] = similarity
            similarity_matrix[j, i] = similarity # 矩阵是对称的

            # 打印两两比较结果
            if i != j:
                 print(f"  文本 {i} vs 文本 {j}: {similarity:.4f}")

    # (可选) 打印完整的相似度矩阵
    print("\n相似度矩阵:")
    print(similarity_matrix)

    # 找到与第一句话最相似的句子（除了它自己）
    similarities_to_first = similarity_matrix[0, 1:] # 获取第一行，排除第一个元素（自身）
    most_similar_index = np.argmax(similarities_to_first) + 1 # +1 因为我们排除了索引0
    print(f"\n与文本 0 '{texts_to_embed[0]}' 最相似的句子是:")
    print(f"  文本 {most_similar_index}: '{texts_to_embed[most_similar_index]}' (相似度: {similarities_to_first[most_similar_index-1]:.4f})")


except AuthenticationError as e:
    print(f"\n认证错误: API Key 可能无效或权限不足。请检查 SILICONFLOW_API_KEY。 {e}")
except APIError as e:
    print(f"\nAPI 调用出错: {e.status_code} - {e.message}")
    if e.response and e.response.content:
       try:
            error_details = json.loads(e.response.content.decode('utf-8'))
            print(f"  错误详情: {error_details}")
       except:
            print(f"  无法解析的错误响应内容: {e.response.content[:500]}...") # 打印部分原始响应
except Exception as e:
    print(f"\n发生意外错误: {e}")
    traceback.print_exc()
```

## 代码解释

1. 导入 `os`、`json`、`openai`、`numpy` 和 `traceback` 库，分别用于环境变量读取、错误详情处理、OpenAI 客户端、向量计算和错误追踪。

2. 从环境变量 `SILICONFLOW_API_KEY` 读取硅基流动的密钥。

3. 创建 `OpenAI` 客户端实例，关键在于 `api_key` 使用硅基流动的 key，`base_url` 设置为 `https://api.siliconflow.cn/v1`。

4. 定义一个包含多个中文句子的列表 `texts_to_embed`，这些句子有的语义相近，有的差别较大。

5. `cosine_similarity` 函数：使用 `numpy` 实现余弦相似度的计算。它接收两个向量，返回一个介于 -1 和 1 之间的相似度分数。增加了对零向量的处理和结果裁剪。

6. 调用 `client.embeddings.create()` 发起请求。
   - `model="BAAI/bge-m3"`：指定使用硅基流动平台上的 `bge-m3` 模型。
   - `input=texts_to_embed`：传入待嵌入的文本列表。

7. 遍历 `response.data` 列表，将每个文本的嵌入向量（`item.embedding`）存储在 `embeddings` 字典中，键是文本在原列表中的索引。打印向量维度以确认。

8. 显示 API 返回的 token 消耗信息。

9. 计算相似度：
   - 使用嵌套循环遍历所有文本对（`i`，`j`）。
   - 调用 `cosine_similarity(embeddings[i], embeddings[j])` 计算相似度。
   - 将结果存储在 `similarity_matrix` 中，并实时打印比较结果。
   - （可选）打印完整的对称相似度矩阵。

10. 使用 `np.argmax` 找到与 `embeddings[0]` 最相似的向量（排除了自身），然后打印对应的原始文本和相似度分数。

11. 错误处理：捕获 `AuthenticationError`（API Key 问题）、`APIError`（硅基流动 API 返回的错误，尝试解析错误详情），以及其他通用异常。
