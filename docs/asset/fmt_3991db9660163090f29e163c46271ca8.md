## 素材模板生成与提炼

专门用于生成或提炼**素材模板**的DeepSeek提示词，包括故事素材、数据素材和金句素材的生成方法：

👉 告诉deepseek（通用模式+联网模式）：

```
**请根据以下要求，****生成/提炼爆款****素材模板：
1. ****素材类型：  
故****事素材 / 数据素****材 /**** 金句****素材（****请选择一种****）
2.内**容领域：职场 / 情感 / 健康 / 理财 / 科技 / 教育（请选择一种）
3.情绪触发点：  
好奇 / 焦虑 / 共鸣 / 警示 / 启发 / 行动（请选择1-2种）
4. 输出要求：  
生成：请提供3个符合要求的素材模板，包含通用框架和示例。  
提炼：请从&#x27;如果是提炼，请在此处粘贴需要分析的内容&#x27;中提炼出1个素材模板，并给出优化建议。  

示例输出格式：

模板： &quot;___通过___方法，从___逆袭到___&quot;  
示例： &quot;小林通过坚持写作，从月薪3000的普通职员逆袭为年入百万的自媒体人&quot;  
适用场景：职场、成长  
情绪标签：启发、行动  
```
