## 字节AI产品（智能客服平台）一面（已过）

### 面试BG

+ 方向：字节AI客服产品方向  
+ 面试体验：5颗星★★★★★，面试的小姐姐很专业，也很有耐心，很真诚地给了蛮多建议。整体感觉没其他博主说的那么push，但是该追问的地方也追问到了。  
+ 时间：2月份官网投递-2.26一面  
+ 背景：211本（HZAU）-985硕（WHU）2段大厂产品  

### 面试问题

1. 你在自我介绍中谈到了阿里小蜜和京东JIMI，它俩在业务功能上的区别？

   + 基础功能：阿里小蜜在命名实体识别、用户意图识别、自动问答等基础功能上能覆盖京东JIMI的功能，且更注重上下文理解与多轮对话，这与阿里在QWEN大模型上的积累有关。  
   + 问答策略：京东JIMI以检索式问答为主，通过`DeepQA`在大量历史用户咨询语料中寻找问答对并迅速给出回答；阿里小蜜则在检索基础上，结合用户画像、知识图谱综合生成混合式回答。  
   + 知识管理：京东JIMI根据用户画像+商品知识库进行回复，例如用户问订单发货时间，直接从订单知识库调取信息回答；阿里小蜜采用全域知识图谱模式，针对不同业务（如淘宝、飞猪、菜鸟）动态调整语言模型，理解特定术语并给出符合当前业务的回答，这与阿里业务条线众多相关。  
   + 交互形式：京东JIMI以文本为主；阿里小蜜交互形式多样，通过文本+语音+图像的多模态交互辅助用户理解。  
   + 场景覆盖：京东JIMI以电商客服为主；阿里小蜜除服务淘天外，还服务物流（菜鸟）、金融（蚂蚁）、出行（飞猪）等场景。  

2. 介绍一下你在上一份实习所做的功能设计？

   从用户具体使用场景、场景痛点（必要性）、其他竞对厂所采取的方案（竞分）以及用户访谈的结果表现这四个维度来全方面阐述功能设计，且因多次面试大厂，对功能设计流程已倒背如流。  

3. 具体展开讲讲每一个子功能？如果你做的功能无法兜住用户的query怎么办？

   从兜底回复和功能拒答两个方面回答，当被追问为何不直接联系客服时，以功能点排期优先级不高尚未开发作答。  

4. 如何提高你刚才提到的意图识别的准确率？

   结合在vivo团队做的中控意图相关经验，从拓展意图垂类的丰富性和模拟测试找出过召、误召的badcase两个方面给出答案。  

5. 如何衡量你所做的产品是否达到了效果？关注的指标有哪些？

   因实习仅三个月，项目只做到demo阶段，未拿到埋点测试数据。若完整跟完项目，会从业务价值角度，即B端和C端两个视角考虑业务指标。  

6. 你是否在业务需求上，和你的MT发生路线上的冲突？有的话，你是如何解决的？

   先复述问题缓冲思考时间，再结合面试官之前挑战的打通客服热线功能问题，以想做尽善尽美的demo但排期、时间不允许，MT告知“完成比完美更重要”来作答。  

7. 你未来的职业规划是什么？是产品嘛？

   首先确定是产品方向，具体想从事AI、语音智能体方向，过往实习经历也在向该方向发展。  

### 反问

+ 面试反馈  
+ 对实习生的期待  
+ 团队具体的业务  
+ 是日常还是暑期，有转正的HC吗  

### 总结复盘

+ 字节的面试官非常专业，面试流程较长，对每一个点都深挖很到位，同时足够有耐心让面试者说完自己的想法。  
+ 面试的小姐姐很真诚，建议可以联系离职的前司同事要数据作为过往实习经历的数据支撑。  
+ 面试过程要保持松弛，不是所有问题都能准备到，松弛的状态能更好地接住面试官的提问和挑战。而获得松弛感的办法是多面试，面试多了会对面试场景脱敏，甚至可以和面试官聊面试问题之外的话题展现思考。

## 小米-语音唤醒产品实习（凉经）

### 面试BG

+ 方向：小爱同学车载语音唤醒方向  
+ 面试体验：4颗星★★★★，1月份投递时，用的还是没完善修改好的简历。本以为挂了，但业务面试官年后初九就给我打了电话，直接在电话里进行了面试。当时自己正在外面和同学聚会，不得已赶忙找了个安静的地方接听电话面试。答的问题也相对比较匆忙，面完就知道自己彻底凉了。  
+ 时间：1.16官网投递-2.5评估-2.6一面-2.7流程终止  
+ 背景：211本（HZAU）-985硕（WHU）1段大厂产品  

### 面试问题

1. 介绍  

面试官自我介绍，说自己来自小米小爱同学语音唤醒部门（一般给候选人打电话都是HR，没想到小米直接是业务老师打电话过来），想对我进行一次简短的电话面试，然后问我方不方便。我当时接到电话一脸懵，下意识回答方便，然后他就开始根据简历一一盘问我。事后复盘，自己应该说暂时不方便，然后约一个时间（起码让自己有一定的缓冲准备时间）。  

2. 你在简历写到，你曾在咨询公司做战略分析，谈谈你是如何做的。

   一月份投递简历时，我很老实地按时间先后顺序把实习经历从前往后写，后面意识到这个问题，才把与所投岗位不相关的实习通通删掉，只保留产品相关的实习经历，所以我就没准备上一段战略实习的回答内容。没想到面试官狠狠追问，我也只能硬着头皮去回忆之前的工作内容。  

3. 你觉得你这段工作内容，能体现你价值的点在哪里？

   这个问题，我尝试从信息资料整合、数据分析、视角选取等角度阐述，没阐述完面试官打断了我，说我做的内容都过于dirty，没体现出我的价值，换个人来一样可以做资料整合、数据分析和政策解读，我只能唯唯应诺（已经感觉很push了）。  

4. 谈谈你在上一段产品经历中，所做的功能设计。

   这个还好，在面试前，算是把团队的功能设计文档、prd内容倒背如流，加上一些我自己的语言去表述，显得不是刻意去背的。在里面我谈了和小米su7的小爱同学车载语音，说自己做了一定了解（没想到立马给自己埋了雷，面试官紧接着就问小爱和我做的功能上有何差异，我只好说竞品里没做小米的汽车）。  

5. 那谈谈你对车载语音的理解吧，可以以你做的竞品车为例。

6. 我们团队有一部分内容是做数据挖掘相关的，比如基于线上用户行为数据，做一些行为分析，包括一些算法的指标，你有关联性比较大的经历吗？

   说实话我确实没这方面关联度较大的经历，可能这一块更偏向策略产品相关，但若是硬要去谈也不是不可以扯，但当时感觉已经凉了，搜肠刮肚地也没说到太相关的，只能说自己会`sql`，会数据分析，但没有实际的业务支撑，太单薄了。

## 虾皮AI产品一面面经

### 面试BG

+ 方向：AIGC产品方向  
+ 面试体验：5颗星★★★★★，面试的小哥蛮幽默的，反问环节问有无什么反馈，他说我表现很好、BG也很好，但就是咖啡店的环境太嘈杂了、刚开始的网太卡了哈哈。  
+ 时间：3.16BOSS投递-3.18一面  
+ 背景：211本（HZAU）-985硕（WHU）2段大厂产品  

### 面试问题

1. 什么是蓝心小V？

   没想到还有人不知道蓝心小V，只好打个比方，vivo的小V相当于是apple的siri，小米的小爱，华为的小艺，一个手机agent。同时，我也在讲过往在蓝心小V方向也涉及部分生文、生图等技能垂类，和咱们岗位较为匹配巴拉巴拉。  

2. 你提到了意图识别的准召率的提高了**%，如何提高的？

   我首先介绍了1.0意图方案识别方案（正则表达式匹配关键词等），其次2.0方案采取的是（基模 + `Prompt` + `RAG`），后者可以通过大模型去理解用户`query`的意图，尤其是模糊意图的识别准确率会大大提高。

   我举了例子，比如用户的`query`是“帮我播放两个男人在天台决斗的电影”，传统意图识别方案只能捕捉关键词，无法返回正确结果。而通过LLM的CoT，模型基本上可以推断出用户想看的电影是《无间道》，因此其准召率大大提高。  

3. 我理解的是对自然语言query的识别过程，比如我想喝一杯瑞幸的咖啡，模型是如何处理的？

   首先，我们要做意图改写，用户的意图会被改写为生活服务（原子意图），之后会匹配生活服务-订外卖这一垂类意图。之后模型会采集其`query`中的`slots`，比如外卖名称：瑞幸咖啡，时间：现在等等，之后跳端到三方应用比如美团、饿了么上进行订外卖。

   在这一过程，不同意图的边界会存在模糊，有些`query`可能会被不属于该意图召回，这种属于过召，尤其是小V接入DS之后，很多本不该走大模型闲聊、百科、联网搜的`query`都被过召了....  

4. 什么是过召？什么是漏召？你们的解决方案是端侧还是云侧？耗时等指标如何？

   蓝厂的解决方案是端云协同，涉及意图识别的部分一般是由端侧的3B小模型来实现的，而涉及复杂的意图，比如闲聊、问答、生文生图就要走云端算力。耗时是用户非常敏感的一个指标，因此涉及意图识别主要是依靠手机端的小模型来完成，耗时在几百毫秒以内，可以接受。  

5. 你在前前司做的这个功能的场景是什么？解决什么问题？

   这个算是老生常谈的面试问题了。依靠STAR法则，先讲业务背景（特定场景下特定需求），其次讲我们做的这个功能如何满足用户的需求，demo的子功能有哪些，未来的迭代方向等等。  

6. 你提到了横测，你对哪个新势力的车印象比较深？

   我又一次谈到了蔚来，并且提到了它的情感增益维度，具体可移步我面蔚来智能座舱的帖子哈哈。  

7. 横测如何做的？或者说它指标体系如何构建的？

   我从技术专业测评和体验测评两个维度做了展开，重点讲了体验测评维度的指标体系是如何搭建的，分为哪些一级指标、二级指标巴拉巴拉。  

8. 我看你是学社会学的，你研究的方向是什么？论文也是这个方向的吗？

   这个就总结：是纯闲聊了哈哈。  

### 反问

+ team的具体业务  
+ 和传统功能性产品的区别  
+ 面试反馈  
+ 面试流程  

### 总结

虾皮没想到还有自己专门的面试网站，打破了以往用飞书/腾讯会议面试的习惯，还好带了电脑。

面试的小哥人蛮帅，说话也很幽默真诚，具体从他那里了解到业务负责的具体方向，也就是通过模型生成图文以替换虾皮东南亚和南美商家的图文，以提高电商的GMV。

但我个人感觉业务线的价值没那么高，同时偏向策略产品一点，对AI的垂类主要是做内容生成这一块。

## 字节AI产品二面

### 面试BG

+ 方向：字节AI客服产品方向  
+ 面试体验：4颗星★★★★，面试官鸽了两次，晚上七点面试，面试官略显疲惫。  
+ 时间：2月份官网投递-2.26一面-3.7二面  
+ 背景：211本（HZAU）-985硕（WHU）2段大厂产品  

### 面试问题

1. 自我介绍  
2. 展开上一段实习的功能：从场景出发，介绍用户用车痛点及产品子功能如何解决。  
3. 多模页面交互的具体形态：以豆包为例，说明回复包含TTS、文字、图片、视频双瀑布流等。  
4. 功能效果评估及指标：区分业务指标和功能评估指标，从语音落域、场景满足度、性能三方面评估，可拆解为二级指标。  
5. 落域准确性指标的评估：界定为实际落域数/预测落域数，介绍云端测试及人工标注团队的标注测试。  
6. 功能检索数据并给到用户的过程：涉及LLM底层原理，面试官考察可迁移复现能力，面试者复盘时认为从语料库、`token`、`RAG`角度回答更佳。  
7. 功能回答形式：有固定模板和自由发挥两种，自由发挥为模型对超出预训练题目的生成。  
8. 数据在SFT还是RAG中训练：两者都会涉及，车企FAQ适合作为SFT标注数据，爬取的PGC适合在RAG中作为外部知识库。  
9. AI产品经理的作用：作为链接用户和模型的中间人，了解模型边界和用户痛点。  
10. 发现需求并推动功能上线：与字节一面问题一致，直接照搬回答。  
11. 上一份实习的不足：同上。  
12. 创业项目：首次被问，表述杂乱啰嗦。  
13. 对AI技术的痴迷：比较近期常用AI类APP（如monica、元宝等）因数据生态差异导致内容不同。  
14. 到岗时间及base地：确认相关信息。  

### 反问

+ 面试反馈：表述有点小啰嗦  
+ 对实习生的期待  
+ 对实习生的培养
