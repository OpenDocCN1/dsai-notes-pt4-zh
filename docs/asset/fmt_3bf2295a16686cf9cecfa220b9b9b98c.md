## 什么是 ChatGPT 插件

ChatGPT 插件是专为chatgpt服务定制的神奇工具，就像您的网络浏览器的插件一样，ChatGPT 插件添加了新功能，可以使它们使用起来更有用和有趣。这意味着 ChatGPT 可以成为一个超级工具，可以处理互联网上的各种事情，例如找到天气情况或股票价格等问题的答案，帮助您在线购物，甚至预订酒店、餐厅、活动门票。这几乎就像ChatGPT 有了新的眼睛和耳朵，让它可以学到更多东西，做更多令人惊奇的事情。

## 一些插件的功能介绍

### 浏览网络web Browsing

Web Browsing插件允许ChatGPT从 Web 访问信息。该插件使用Bing API访问网络。此API允许ChatGPT向Bing发送请求并接收包含ChatGPT 正在寻找的信息的响应。

例如，如果ChatGPT想要检索特定城市的天气预报，它可以向 Bing API 发送请求并接收包含该城市当前温度、湿度和风速的响应。它还可以从多个搜索结果中读取数据，并以简洁的格式向用户提供答案摘要。

![](img/95f1e559f8bcb43aeae55dad5024674c.png)

### 自动任务（发邮件、处理文档、IM信息发送等）- Zapier

文档检索插件允许 ChatGPT 从各种来源检索文档，例如 Google Drive、Dropbox 和 OneDrive。这将非常有趣，因为用户可以用自然语言从他们关心的来源中搜索与他们最相关的信息。想象一下，能够查找您上次旅行的收据，并能够通过查看您的文件、笔记、电子邮件或任何其他文档进行回复。

Zapier ChatGPT 插件可让您连接数以千计的应用程序（如 Google 表格、Gmail 或 Slack）并直接在 ChatGPT 内自动执行任务。这为您节省了上下文切换的时间和麻烦，因为您可以让 ChatGPT 为您在另一个应用程序中执行任务。

### 阅读PDF-AskYourPDF

让该插件去阅读一份在线的英文pdf文档，并且给出文章的主题内容，然后用中文输出。这个简直是阅读英文文档的神器。但是注意的是，一定要辨别它的输出结果是否正确，结果有一些叙述是明显有错误的，比如页码。

#### 使用方法：`https://askyourpdf.com/upload`这里上传文档，然后会生成一个`id`，chatgpt直接问这个`id`就行，或者一些其他可访问的链接也都是可以的

### 语言学习-speak

ChatGPT的Speak插件是一个专门用于处理与语言学习相关的问题的插件。它可以帮助用户翻译和解释特定的词语或短语，解释特定外语短语的含义和用法，或者解释在特定情况或上下文中如何用外语说或做某事。

### 旅行计划/机票酒店-[Trip.com](http://Trip.com)

这个插件是Trip.com的API，它可以帮助用户轻松获取定制的旅行产品推荐和行程规划，包括酒店和航班，

这个插件可以帮助用户在规划旅行时更加方便快捷地获取所需的信息。

### 美食制作-Tasty Recipes

食谱检索插件。它的主要功能是帮助用户查找食物、饮料、餐饮计划选项以及食谱。当用户询问与食谱相关的问题时，可以使用这个插件来获取答案。

![](img/93646d0c8642bc895204c9a7f9d94857.png)

### 完美prompt-perfect

perfect插件是用来重述或重构用户输入的。这个插件的目标是改进ChatGPT的回应质量。它会评估用户的输入，如果需要，将其转化为更清晰、更具体、更有上下文的提示。插件处理包含要重述的用户输入的JSON对象，并使用GPT-3.5-turbo模型进行重述。然后，重述的输入以原始数据的形式返回，以便融入ChatGPT的回应。用户可以通过键入"perfect"来启动这个插件。

![](img/a2aac46403ab4e2ddee75caf74188ce9.png)

## 插件开启方式

1. 升级成为plus付费用户。
2. web的左下角点击设置选项。
3. Beta features里边开启web浏览以及插件功能。
4. 会话选择GPT-4。
5. 下拉列表中开启GPT-4的插件，一个会话可以选择3个插件，插件可以从下拉列表中的插件市场下载。

Ps:

如果你是plus用户，但是没有以上选项也不要着急，该功能正在陆续开放中，预计本周会给plus用户全部开放（20230515-20230521）
