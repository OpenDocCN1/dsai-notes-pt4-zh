
# 申请API

> 来源：[https://xuqiwei1986.feishu.cn/docx/SEG2dDaeEoE36ZxkAvbcxUYsnog](https://xuqiwei1986.feishu.cn/docx/SEG2dDaeEoE36ZxkAvbcxUYsnog)

GPT-4 API 已经全量开放，只要之前开发者支付过 API 账单那就可以直接使用 GPT-4 API，无需再进行额外申请。

但这并不意味着 GPT-4 API 面向所有用户开放，可能是为了避免白嫖，OPENAI 限定只有之前支付过 API 账单的开发者才能获取，也就是只申请账号并且有免费额度的用户仍然只能使用 GPT-3.5 API 不支持 GPT-4。
