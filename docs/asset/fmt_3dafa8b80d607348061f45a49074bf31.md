
# 数据安全事件负责部门

> 来源：[https://docs.feishu.cn/docx/FxuIdHtkToBQjkxEVfBcMYfqnbb](https://docs.feishu.cn/docx/FxuIdHtkToBQjkxEVfBcMYfqnbb)

- **问**：如何理解《数据安全法》中：“各地区对本地区工作中收集和产生的数据及数据安全”负责的？以上海为例，这一条是在说上海市政府需对上海政务数据、公共数据总负责、还是当发生大的数据安全事件时，对上海当地所有组织的数据安全向上级担责？

- **答1**：《上海市网络安全事件应急预案》中，如果数据被破坏构成网络安全事件（分为特别重大、重大、较大、一般）的，是由上海市网信办和上海市公安局应急联动中心主要负责处理的。
