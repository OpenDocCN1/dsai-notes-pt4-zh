## 2、部署步骤

+ 步骤1: 启动并登录`Mysql`，创建编码为`utf8mb4`的数据库，导入项目中`/sql/xx.sql`文件。

+ 步骤2: 打开之前复制的文件`/server/like-admin/src/main/resources/application-dev.yml`。

+ 步骤3: 找到`datasource`项，修改`url`项的地址为数据库`ip`地址，地址`/`后面为数据库名称，`username`项为数据库账号，`password`项为数据密码，然后保存。
