## 持续流量筛选

### 筛选目标

+ Shorts，AI相关，不露脸
+ 能赚钱：年收入>20万元
+ 可持续：播放量大体趋势在保持或增长

### 筛选条件

（由于数据限制，近似估计）

+ 能赚钱：近一年播放量>1亿
+ 2024年注册，总视频量≥20，总播放量>2000万
+ 2023年注册，总视频量≥50，总播放量>1亿
+ 2022年注册，总视频量≥100，总播放量>1.5亿
+ 2021年及以前注册，总视频量≥150，总播放量>2亿
+ 可持续：
  + 没有断更：最近一次更新在2周内
  + 视频播放量分布相对平均，而非只靠个别爆款
  + 视频播放量大体趋势在保持或增长
  + AI相关，不露脸
