
# PodSecurityPolicy 已弃用与移除说明

从 Kubernetes 1.21 版本开始，`PodSecurityPolicy`（PSP）已被标记为已弃用，从 Kubernetes v1.25 开始 `PodSecurityPolicy` (PSP) 准入控制器已被移除。
