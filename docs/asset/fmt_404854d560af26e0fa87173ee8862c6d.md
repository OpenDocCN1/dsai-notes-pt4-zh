
# 【模版】AI视频制作模板（建议复制）

> 来源：[`https://datawhaler.feishu.cn/docx/PNsDd8LfgoGTNzxHRMvcDBQOnsh`](https://datawhaler.feishu.cn/docx/PNsDd8LfgoGTNzxHRMvcDBQOnsh)

> 结合传统电影创作制作流程，将部分拍摄与创作流程替换为AI工具。可以先找自己喜欢的视频风格作为参考，学习着自己做一个。大家可以复制这个文档，填上自己的内容~

## 1. 灵感创意

### 1.1 主题确定

+   **灵感来源**：简述获得创作灵感的来源和背景。

+   **主题描述**：明确作品的核心主题和想要传达的信息。

### 1.2 故事梗概

+   **基本情节**：概述故事的基本情节和主要事件。

+   **角色设定**：描述主要角色及其特性。

## 2. 策划与预制

### 2.1 剧本撰写

+   **情节发展**：详细描述故事情节的发展，包括起始、冲突、高潮、结局。

+   **对白脚本**：撰写角色对白和旁白。

+   对话撰写：根据角色设定和情节发展，撰写角色之间的对话，确保对话既自然又能有效推进故事情节。

+   旁白撰写：是否需要旁白来解释背景信息、描述场景转换或表达内在思想，加深观众对故事的理解。

### 2.2 视觉风格与角色造型

+   **美术设计**：确定视频的视觉风格、色彩方案和美术背景。

+   **角色造型**：设计角色的外观，利用AI工具生成或调整角色造型。

### 2.3 分镜头脚本编写

+   **镜头规划**：基于剧本的详细情节，规划每一个镜头的构图、角色位置、动作等。

+   **视觉指导**：明确每个场景的视觉风格，包括照明、色调和氛围，确保它们与故事情绪和主题相契合。

+   **动作序列**：详细描述角色在场景中的动作和交互，以及相机的移动方式。

+   **对话与旁白**：指定哪些对话或旁白将在特定镜头中出现，以及对话的定位。

+   **过渡与特效**：规划镜头之间的过渡效果以及任何需要的视觉特效，为后续的视频编辑提供指导。

## 3. AI技术准备

### 3.1 选择AI工具

+   **AI视频制作工具**：列出将使用的AI视频制作工具，如AI动画生成器、AI配音工具等。

+   **素材生成**：确定用于生成背景、场景、角色等的AI工具。

### 3.2 素材准备

+   **素材收集**：收集需要输入到AI工具中的素材，如文本描述、基础图像等。

## 4. 制作过程

### 4.1 AI生成内容

+   **场景与背景**：使用AI工具生成视频所需的场景和背景。

+   **角色动画**：利用AI生成或调整角色动画和表情。

### 4.2 音频制作

+   **AI配音**：使用AI配音工具为角色生成配音。

+   **音乐与音效**：选择或使用AI工具创作背景音乐和音效。

### 4.3 视频编辑

+   **AI剪辑工具**：使用AI视频编辑工具组合场景，调整节奏和转场。

+   **特效添加**：利用AI特效工具增加视觉效果。
