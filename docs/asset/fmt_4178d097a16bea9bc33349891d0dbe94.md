## 本地测试端口问题

打开本地测试端口 `http://localhost:3000` 进行测试。

`localhost:3000` 无法访问的原因：Vite 项目的默认端口是 5173，而不是 3000（3000 通常是 React Create App 或 Next.js 的默认端口）。

检查项目配置 `package.json#L1-25`，发现项目使用的是 Vite（`"dev": "vite"`，第 7 行）。

### 解决方案

请尝试访问以下地址进行本地测试：

👉 `http://localhost:5173`

### 小贴士

如果确实需要使用 `localhost:3000`（例如为了匹配某些写死的 Redirect URL），可以修改 `vite.config.ts` 来强制使用 3000 端口。
