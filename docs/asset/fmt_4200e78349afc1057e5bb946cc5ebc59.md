
# MateGen 快速开始

`mategen = MateGenClass(api_key = 'YOUR_API_KEY')`

然后即可使用`chat`功能进行单次对话或多轮对话：

`mategen.chat("你好，很高兴见到你！")`

` ▌ MateGen`初始化完成，欢迎使用！
