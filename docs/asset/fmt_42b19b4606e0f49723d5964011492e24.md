
# AI 生成代码配置与启动指南

AI 生成代码后，按以下步骤配置和启动：

## 配置和启动步骤

1. **安装依赖**：

```
npm install
```

1. **配置环境变量**：

```
cp .env.example .env
```

编辑 `.env` 文件，填入你的 API 密钥和配置

环境变量说明：

+ `OPENAI_API_KEY`：蓝耘 API 密钥

+ `OPENAI_BASE_URL`：蓝耘 api 地址

+ `CHATLOG_API_URL`：chatlog 服务地址（默认 `http://127.0.0.1:5030`）

+ `PORT`：Web 服务端口（默认 3000）

1. 确保 `chatlog` 服务已启动：

```
./chatlog server
```

1. **启动 Web 服务**：

```
npm run dev
```

1. **启动 Web 服务**：

```
npm run dev
```

1. **访问界面**：

打开浏览器访问 `http://localhost:3000`

### 5.3 使用 Web 界面

1. 在搜索框输入关键词，找到想要分析的群聊

1. 从下拉列表中选择群聊

1. 选择要分析的日期（默认今天）

1. 点击"🚀 生成总结"按钮

1. 等待 20-60 秒，AI 会自动分析并展示结果

生成的报告包含：

+ 📊 数据统计卡片

+ 📝 总体概述

+ 🔥 热点话题分析

+ 🕸️ 人物话题关系图

+ 💬 精彩引用

+ ⭐ 活跃用户排行

+ ☁️ 高频词云

### 5.4 常见问题

问：AI 生成的代码有错误怎么办？

答：可以向 AI 描述具体的错误信息，让 AI 帮你修复。例如：

```
运行时出现错误：[错误信息]
请帮我修复这个问题。
```

**问：想修改某个功能怎么办？**

答：直接向 AI 描述你的需求，例如：

```
我想在页面上添加一个&quot;导出PDF&quot;按钮，点击后可以将报告导出为PDF文件。
```

**问：可以自定义样式吗？**

答：可以！向 AI 描述你想要的样式，例如：

```
请把背景色改为蓝色渐变，卡片改为深色主题。
```
