
# 应用号产品理念与愿景

## 需求背景与市场观察

这个需求来自于哪里呢？我们自己也观察到发现越来越多的创业公司它做的第一个产品就是基于🛰️的👸号来做的，而不是去开发一个APP，因为一个APP的推广成本实在是太高了。相比来说，👸号能够实现大致同样的事情，并且也能获得它的用户，并且用户可以在🛰️里面获得的成本或者传播的速度会更好一些。

## 从服务号到应用号的产品定位

但是我们的本意并不是要做成一个只是传播内容的平台，我们一直说我们是要做一个提供服务的平台，所以后面我们甚至专门拆分出一个服务号出来，但是服务号还是没有达到我们的要求，说服务号可以在里面提供服务为主，所有的服务号还是基于一个诉求，这不是我们想看到的。现在我们将开发一个新的形态，叫做应用号。我们现在每换一部手机，手机里面的APP就要重新装，我相信大部分用户也是这样的。现在APP重复的安装率已经越来越低，但是有的时候你要找一个功能，你还得重新再安装一下这个APP。现在很多用户会在🛰️钱包里面买火车票，因为对一些不是很高频度的需求来说不需要再按一个安装，可是从👸号里面去装一个功能其实也不容易，我们希望存在一种新的👸号的形态，这种形态下面用户关注了一个👸号，就像安装了一个APP一样，他要找这个👸号的时候就像找一个APP一样，进去使用这个👸号，在平时这个号不会向用户发东西的，所以APP就会很安静的存在那里，等用户需要的时候找到它就好了，这样的话我们可以尝试做到让更多的APP有一种更轻量的形态，但是又更好使用的一种形态来存在，这是我们在探讨的一种新的👸号形态，叫应用号，这里只是提前剧透一点点东西。
