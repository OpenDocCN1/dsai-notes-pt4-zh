
# 主体性批判：福柯、德里达与当代反思

## 福柯：权力、规训与主体的生产

### 从压迫模式到生产模式：权力的转向

如果说拉康从精神分析和符号学的角度诊断了主体的裂开，福柯则从历史和权力的角度来分析主体是如何被生产、规范化和规训的。

福柯的工作跨越了几十年，其思想不断演进。但一个贯穿始终的主题是对权力的重新理解。在19世纪和20世纪早期的理论中，权力通常被理解为压迫性的、否定的、禁止性的——某个权力中心（君主、阶级、父权）对那些无权者施加它的意志。权力本质上是说"不"的：禁止、限制、压制。

福柯论证这个模式是不充分的。虽然权力确实有这些否定的、限制性的方面，但它的最深层的、最有效的操作是生产性的。权力不仅压制已经存在的东西；它产生新的东西。特别是，权力产生主体。

福柯在《规训与惩罚》中进行了这个论证。他追踪了从古代残忍的公开处刑到现代监禁系统的转变。表面上看，这看起来像是一个人道主义的进步：用私密的、"人道的"监禁取代公开的、暴力的处刑。但福柯论证，真实的转变更加微妙而深刻。

在古代，权力通过展示（spectacle）来操作。国王在公共广场上，以戏剧化的、几乎宗教式的仪式，在犯人的身体上表现其绝对权力。这是权力的一种表演，其意义在于对观众的震慑。权力被着眼于身体的外部、着眼于一个戏剧性的时刻。

### 圆形监狱与监视

现代监禁系统引入了一种完全不同的权力机制：监视（surveillance）。边沁的"圆形监狱"(Panopticon)——一个中央的监视台被一圈监狱牢房所环绕，使得守卫可以随时观察任何囚犯，但囚犯永远不知道他们是否正在被观察——成为了现代权力的象征符号。

### 在圆形监狱中发生了什么？

关键不在于实际的观察，而在于被观察的可能性。一个囚犯，知道他可能在任何时刻被观察，逐步地开始内化这个视线。他开始观察自己、规范他的行为，好像他正在被观察。监视变成了自我监视。

这个转变的意义是深刻的。权力不再是外部强加的、需要被某个中央权力不断地维持。相反，权力已经被内化、被主体自己所维持。现代的规训权力工作的方式是通过产生规范的主体——那些已经学会了如何监视和规范他们自己的主体。

### 生物权力与对生命的管理

在《性的历史》的第一卷中，福柯引入了生物权力（biopower）的概念。这是权力的另一个维度，涉及对整个人口的生命、身体、健康、生育、死亡率的管理和规制。

当福柯说权力"管理生命"时，他指的不是直接的、暴力的、对身体的攻击，而是一种更微妙的、在人口层面上运作的权力：通过医学话语、卫生标准、教育、统计学、公共政策，对人的身体、性、健康、再生产的形成。

例如，考虑一下《性的历史》。人们通常认为，在维多利亚时代，有一个关于性的强大的禁止：性话题不能被公开讨论，性行为被压制，性被一般化地禁止。但福柯论证，事实是完全相反的。维多利亚时期看到了关于性的话语的爆炸。医生、心理学家、教育工作者、道德家，他们都开始不断地、系统地谈论性、分类性的形式、诊断性的异常、规范化性的行为。性从一个被压制和沉默的话题，变成了一个被不断地、详细地、权力性地言说的话题。

为什么这是权力的一个形式？因为通过这个关于性的科学话语，性被带入了知识和权力的领域。男性和女性开始根据这个科学话语来理解他们的性身份。他们开始认可或否认关于他们的性的陈述。他们开始优化、规范、改正他们的性行为，根据医学和心理学的权威。性的看似"解放"的话语，实际上是一个权力的微观物理的形式，通过知识和话语来规范和塑造生活。

### 话语与主体的构成

福柯关键的洞见是，话语不仅描述现实；话语产生现实、产生主体。一个"疯狂"的人、一个"同性恋"的人、一个"犯罪分子"——这些不是预先存在的自然类别，等待被科学发现。相反，这些是通过医学、心理学、刑法等话语系统而被生产出来的类别。

在文艺复兴之前，没有"精神病患"这样的东西。当然，有人被认为是疯狂的、被魔鬼附身的、或在智慧上有缺陷的。但"精神病患"作为一个现代医学类别——一个有可识别症状的、可诊断的、可治疗的疾病的人——这是一个现代的、通过精神医学话语而被构成的产物。

同样，"同性恋"这个词在19世纪中期才被发明出来——首先作为一个医学类别，然后是一个心理学范畴，最后成为一个身份。在这之前，有同性的性行为，但没有"同性恋的人"这样的东西。这个身份正是通过科学话语而被创造出来的。一旦这个身份被创造，人们就开始根据这个身份来理解他们的存在、他们的欲望、他们的身份、他们的生命项目。

这对主体的观点有激进的含义。主体不是先在的，然后被表示、被描述、被命名。相反，主体是通过话语系统、权力-知识网络而被从零开始生产出来的。我成为一个"主体"，一个可识别的、有身份的、可管理的个体，正是通过被纳入各种规范化的话语中——医学的、教育的、法律的、心理学的。

但这不意味着主体完全是权力的被动的接收者。福柯也承认反抗和对权力的反向利用（reverse discourse）。被医学标签化为"疯狂"或"同性恋"的人可以接受这个标签，但赋予它新的意义、用它来进行反抗、用它来组织集体运动。权力-知识的同一话语可以被用来对抗当初生产它的权力。

## 第十二层：德里达与解构——差异、延异、与他者

如果福柯关注的是权力如何通过话语产生主体，德里达关注的是语言、符号、意义本身的根本不稳定性，以及这如何影响我们关于主体、认同、责任的思考。

### 差异与延异：意义的无限展延

德里达的解构项目从一个相当技术性的语言学观察开始，但它有着激进的哲学含义。德里达注意到，在索绪尔的结构语言学中，有一个基本的论断：符号（一个标记(sign)）由两个部分组成——能指(signifier)（声音的或书写的形式）和所指(signified)（概念、意义）。一个符号的意义来自于它与另一些符号的差异——"cat"这个词有意义，因为它与"dog"、"bat"等不同。

但德里达论证，这个差异的逻辑有着更深层的、被索绪尔未曾充分认可的含义。符号不仅通过与其他符号的差异而获得意义；所指本身也从未能够完全出现、完全在场。所指总是被延迟的、被推迟的、被转移到其他的符号。为了理解"树"这个词，我需要理解其他的词——"植物"、"木头"、"生长"等等。而为了理解这些词，我又需要理解更多的词。这个连锁永远不会停止；意义总是在符号之间的网络中移动，从来不会在某个最终的、超越符号的地点停留。

德里达用一个新造的词"差延"(différance)来描述这个过程。这个词在法语中听起来像"差异"(différence)，但拼写不同（差延加了一个"a"）。"差延"捕捉了两个同时发生的运动：差异(difference)——符号通过相互区别而获得意义——和延异(deferral)——意义被持续地推迟、被延迟到其他的符号。

这对主体有什么含义？这意味着主体本身不能有某个基本的、透明的、完全在场的身份。我对我自己的理解，我对我的身份的定义，都必须通过语言和符号来进行。但正因为语言和符号本身永远无法完全地现场、永远被差延所标记，我的身份和自我理解也永远无法完全现场、永远被相互延迟。

### 他者与责任的不可能性

德里达后来的工作，特别是在《赞幽灵》和关于伦理学和司法的著作中，更深入地思考了主体与他者（Other）的关系。在这个思考中，他提出了一些深刻的伦理论点。

当我与另一个人相遇时，这个他者对我提出了要求——一个我无法完全满足、无法完全回应的要求。他者，在其绝对的特殊性和不可还原性中，超越了我的理解、我的知识、我的范畴。当我试图将他者纳入我的知识框架中——当我说"他是一个X类型的人"、或"根据这个或那个标准，他是这样的"——我正在执行一种暴力：将他者的特殊性还原为普遍的范畴。

在这个观点中，主体对他者的无限的、不可能的责任是根本的伦理位置。我对他者负责，但我永远无法完全满足这个责任。他者的需求超过了我的能力、超过了我所有的理由和计算。这不是一个我可以通过遵循规则或原则来满足的责任。相反，这是一个绝对的责任，它先于所有的规则和原则。

德里达在这个背景下讨论了决定（decision）和司法(justice)。一个真正的决定不能仅仅是应用一个预先存在的规则或原则。如果我所做的只是遵循规则，那就不是一个决定；那是对规则的机械应用。一个真正的决定涉及进入一个不可计算的域（incalculable realm），在这个域中，没有规则可以预先指导我，我必须承诺一个我无法完全证明的东西。

在这个框架中，主体是一个必须决定的、因此是有责任的存在。但这个责任不能被规范化、不能被融入一个制度化的司法系统。恰恰相反。每一次我进入一个既存的司法系统，我都多少地背弃了对绝对他者的绝对责任。司法总是某种妥协、某种在不可能的责任的要求与制度化的法律和程序之间的折中。

## 当代"主体性"的污染与其批判性重建

### 第一部分：从哲学概念到日常评价的坠落

#### 关键的转化发生了什么

值得注意的现象——"主体性"被转化为一个可观察的、可量化的、可评价的属性——代表了从存在论的维度到心理学的/行为学的维度的根本背离。这个背离不是无害的语言漂移；它改变了这个词能够做什么、不能够做什么。

当某人说"这个人主体性好强"或"他表现出很强的主体性"时，他们在说什么？通常指向的是：

+ 这个人有强烈的自我意见，不容易被外部影响所动摇
+ 这个人敢于表达异议、反抗权威
+ 这个人的行为看起来"自主"、"自决"、不被其他力量驱动
+ 这个人显得有"独立的判断力"

反之，当说"她缺乏主体性"或"这表现了主体性的缺失"时，隐含的是：

+ 这个人似乎没有自己的想法，容易被影响、被"洗脑"
+ 这个人的行为显得被动、被他人或外部力量所驱动
+ 这个人似乎不能为自己做决定
+ 这个人显得"盲目"地跟风或顺从

问题在于：这些都不是关于主体性的。

在我前面论述的所有哲学传统中——从笛卡尔到德里达——没有一个理论家会谈论某些人拥有"更多的主体性"而另一些人拥有"更少的主体性"，就好像主体性是一个可以在人与人之间进行等级比较的属性。

笛卡尔的"我思故我在"是一个普遍的、形式性的论断。每一个思维的存在都通过思维的行为确认了其存在。思维不分程度——要么你在思维，要么你不在；一个人的思维不能比另一个人的"更多"或"更好地符合'我思'这个条件"。

康德的超越主体是所有理性存在者的普遍条件。没有某个理性存在者比另一个理性存在者更具有超越主体性。

黑格尔的精神虽然表现出等级制的发展，但这涉及的是整个人类历史和文化的发展，而不是个体之间的比较。每一个个体都是这个过程中的一个环节，都参与其中。

尼采谈论的是权力意志——这是所有生命的根本特征，不是某些个体拥有而其他个体缺乏的东西。他关于"奴隶心态"和"贵族精神"的讨论不是关于主体性的拥有，而是关于一个人如何关系自己、如何关系权力、如何关系生命的根本立场。而且关键是，尼采不会说奴隶心态代表"更少的主体性"；他会说它代表了对权力、对力量、对创造的一种不同的关系方式。

拉康明确地论证，每一个进入象征秩序的人都是一个主体——都被语言所穿透、都被欲望所标记、都是分裂的。没有"更完整的主体"与"更分裂的主体"这样的区别。分裂、缺乏、被他者所构成——这不是某些主体的特征，而是所有主体的条件。

福柯关于权力如何生产主体的论述，同样不允许一个"更自由的主体"与"更受权力束缚的主体"的比较。权力是无处不在的、是生产性的、是所有主体性的条件。没有某个位置不被权力所穿透；没有某个主体比其他主体"更脱离权力"。

德里达关于差延和他者的论述表明，所有身份都是不稳定的、所有关系都通过某个无法完全掌握的他者。这不是某些主体的特征；这是主体存在的根本条件。

#### 这个转化如何发生的

这个转化不是意外的；它反映了当代特定的权力配置和文化倾向：

##### 1. 心理学化的传播

存在论和哲学性的问题（"什么使得某物成为一个主体"）被逐步地转化为心理学的或行为学的问题（"这个人表现出了多少心理自主性"）。这个转变有深刻的社会根源。心理学在20世纪成为了知识和权力的主要技术之一（福柯会这样说）。心理学话语将注意力从结构问题转向个人心理配置。

当一个人显得被动时，结构性的分析会问：什么样的权力关系、什么样的经济约束、什么样的话语环境导致了这种被动性？但心理学化的分析问：这个人的心理是什么样的？他/她有某种"依赖性格"吗？他/她缺乏"自信"或"自主性"吗？

"主体性"被吸收到了这个心理学的框架中，变成了一个关于个人心理特征而不是存在论条件的问题。

##### 2. 新自由主义的量化逻辑

在新自由主义资本主义中，一切都必须被量化、被测量、被比较、被优化。不可量化的、不可约化的东西变成了令人不安的。"主体性"——如果它被理解为某种形而上的、不可观察的条件——是令人不安的。但如果"主体性"被重新定义为一个可以被评估、被比较、被改进的属性，那就变成了有用的、可管理的。

在这个逻辑中，人力资源部门可以评估员工的"主体性"；教育系统可以尝试"增强学生的主体性"；自助文化可以出版关于"如何发展你的主体性"的书籍。主体性变成了某种可以被消费、可以被购买（通过参加研讨会、阅读书籍、进行心理治疗）的商品。

##### 3. 自我改进文化中的内化

与新自由主义的量化逻辑相关的是一种广泛的自我改进、自我优化、自我监视的文化。人们被教导去不断地评估和改进他们的各个方面——他们的"情商"、他们的"抗压能力"、他们的"适应性"、他们的"创造力"、现在，他们的"主体性"。

在这个框架中，如果你显得"缺乏主体性"，那不是因为你所处的权力结构、制度或压迫的问题，而是因为你需要做出心理改变、需要自我改进、需要发展这个属性。这将责任从外部结构转移到了内部自我。这是新自由主义的一个特征转变：对压迫的结构分析被转化为对个人缺陷的心理分析。

##### 4. 社交媒体文化的表现性维度

社交媒体强化了一种对所有事物都必须是可见的、可表现的、可评价的这样的逻辑。主体性变成了一个必须在你的个人形象中表现出来的东西——通过你说什么、你穿什么、你"点赞"什么、你如何评论。"有主体性"变成了一种个人品牌。

在这个背景中，说某人"缺乏主体性"变成了可能的，因为主体性现在是某个可以在表面上读取的东西——通过他们如何呈现自己、他们是否有"自己的观点"、他们是否"敢于与众不同"。

#### 这个转化做了什么：权力效果

这个概念的腐败不仅仅是语言上的不精确；它有着非常实际的、危险的权力效果。

##### 隐蔽的权力运作和评价

当某人说"这个人缺乏主体性"时，他们在进行一个权力宣言。他们在说："根据我的判断标准，这个人的行为显得不够自主、不够独立、不够我所认可的方式。"这是一个评价、一个判断、一个权力行为。

但关键的隐蔽性在于：因为"主体性"听起来像是一个理论术语、一个来自哲学或心理学的术语，这个权力宣言似乎在说某个关于客观现实的东西，而不是在执行权力。评判者可以躲在理论的外衣后面，说"我不是在评判你；我只是在指出你缺乏主体性这个事实。"

这使得权力关系变得不可见、不可质疑、看起来像是中立的事实陈述。

##### 他人内在生活的非法入侵

说某人"缺乏主体性"涉及对这个人的意识、动机、自主性、内在生活的一个极其有侵入性的判断。这个判断往往是基于表面现象的——某个人的言语风格、衣着、社交表现、在课堂或会议上的可见性。但内在生活呢？

一个看起来沉默、看起来顺从、看起来被动的人，可能有着极其丰富的、批判的、深度的内在生活。他/她可能选择沉默出于多种原因：谨慎、深思熟虑、对权力的策略性理解（知道什么时候说话、什么时候沉默）、羞怯、语言困难、对说话空间是否安全的准确评估。

一个看起来充满自信、看起来"有主体性"的人，可能充满了无意识的、被内化的压迫，可能在盲目地重复他/她被教导去说什么，可能在表现一个自己并不真的相信的角色，可能正在利用特定的权力形式（比如，男性的、异性恋的、白人的、中产的权力）来声称一种"真实性"或"自主性"。

但是，基于表面现象，我们做出了关于这个人的根本性质的判断。这是一种认识论的暴力。

##### 将结构性问题个人化

这可能是这个转化最危险的效果。当我们说某个人"缺乏主体性"时，我们隐含地将问题定位为这个人的内在特质，而不是定位为这个人所处的社会结构、权力关系、制度限制。

一个具体的例子：一个来自贫困背景的学生，在大学课堂上不经常发言。他/她可能被描述为"缺乏主体性"——"不敢表达自己"、"太被动"、"需要更强的自我意识"。

但真实的情况可能是：这个学生充分地意识到课堂空间中的权力动态——他/她知道自己的口音可能会被嘲笑、他/她的观点可能会被削低、他/她缺乏与那些来自特权背景的学生相同的"文化资本"。他/她的沉默不是缺乏主体性的标志；它可能是一种明智的、战术的、甚至是反抗的行为——对他/她知道对他/她而言不安全的空间的理性回应。

但当我们说"这个学生缺乏主体性"时，我们否定了这个诊断。我们把责任放在学生身上——他/她需要更自信、更敢于发言、更有"主体性"。我们没有看到（或者我们选择不看）课堂空间本身的权力结构——它如何对某些学生有利，对其他学生不利；它如何奖励某些形式的表达，压制其他形式。

##### 创造新的等级制和污名

任何评价维度都会创造等级制。如果某些人有"更多的主体性"而其他人有"更少的主体性"，那么必然会产生一个等级：那些处于量表高端的人被视为更好、更自主、更"进步"；那些处于低端的人被视为较差、被动、需要改进。

在实践中，谁被认为"缺乏主体性"？这通常与其他形式的社会压迫相交织：

+ 女性比男性更有可能被描述为"缺乏主体性"（女性的谨慎、女性的关系性倾向、女性对冲突的避免被重新解释为缺乏自主性）
+ 来自被压迫种族/民族的人比处于权力位置的人更有可能被这样描述
+ 工薪阶层比中产和上层阶级比例更高
+ 年轻人比成年人更有可能
+ 有心理健康问题或神经差异的人比"正常"的人更有可能

换句话说，那些已经以其他方式被系统性地贬低的人，也更有可能被说"缺乏主体性"。这个新的评价维度叠加在现有的压迫上，强化和合理化它们。那些处于权力位置的人不仅在经济上、政治上、社会上拥有优势；他们还拥有"更多主体性"的荣誉。

##### 阻止实际的权力分析

最后，将"缺乏主体性"用作解释，阻止了我们进行更深入的、更有效的权力分析。

当一个工人显得被动、似乎没有反抗他的剥削性的工作条件时，说"他缺乏主体性"比说"工作的组织方式——监督、时间规制、任务分割、对组织的决定的缺乏发言权——压抑了任何反抗的可能性"更简单。
