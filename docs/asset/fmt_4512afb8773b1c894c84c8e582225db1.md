
# AI 工具与资源列表

## 图像与模型

+ [Stable Horde](https://stablehorde.net/) - 一个由 Stable Diffusion 工作人员组成的众包分布式集群。

+ [DiffusionDB](https://diffusiondb.com/) - 所有公共应用、开发人员工具、指南和 [Stable Diffusion](https://airtable.com/shr0HlBwbw3nZ8Ht3/tblxOCylXV8ynh7ti) 插件的列表。Airtable 版本。

+ [PublicPrompts](https://publicprompts.art/) - 为 Stable Diffusion 提供免费提示的集合。

+ [Stableboost](https://stableboost.ai/) - Stableboost 是一个 Stable Diffusion WebUI，让你可以快速生成大量图像，以便你能找到完美的图像。

+ [Hugging Face Diffusion Models Course](https://github.com/huggingface) - 由 @huggingface 提供的关于扩散模型的在线课程的 Python 材料。

## 视频

+ [RunwayML](https://runwayml.com/) - 神奇的 AI 工具，实时协作，精确编辑等。你的下一代内容创作套件。

+ [Synthesia](https://www.synthesia.io/) - 从纯文本中快速创建视频。

+ [Rephrase AI](https://www.rephrase.ai/) - Rephrase 的技术使得超个性化视频创作规模化成为可能，从而推动参与度和业务效率。

+ [Hour One](https://hourone.ai/) - 将文本转换为视频，特色虚拟主持人，自动进行。

+ [D-ID](https://www.d-id.com/) - 一键创建和互动交流头像。

+ [ShortVideoGen](https://shortgen.video/) - 使用文本提示创建短视频和音频。

+ [Clipwing](https://clipwing.pro/) - 一个将长视频剪辑成数十个短视频片段的工具。

+ [Recast Studio](https://recast.studio/) - AI 驱动的播客营销助理。

+ [Based AI](https://www.basedlabs.ai/) - AI 直观界面，用于视频创作
