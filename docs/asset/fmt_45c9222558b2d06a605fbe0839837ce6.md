## 前言：本教程解决的问题、工具上手难度以及需要付出的各项成本

> 本文价值：帮大家把行动成本降得足够低，使用 ai 自动化工具，让你言出法随。

> 过去，你要写一篇👸号文章，需要找选题，需要写正文，有配图，然后排版审查，再发布。

> 使用这个 AI 工作流教程，你只需要找到一篇你觉得写的好的👸号文章，然后把这个链接发送给这个工作流，它就能帮你根据内置的提示词生成原创 ip 文章并直接排版好发送到你👸号草稿箱，你只需要去👸号草稿箱审查发布就 ok；

> 另外我还做了另外一个 AI 工作流，你可以输入任何观点、想法、选题标题，它就能生成文章，并且排版好，保存到你👸号草稿箱。

> 本文教程能把你过去纠结几个小时，甚至几天的情绪内耗、行动成本降低到一秒，只需一念起。

> Ai 写作的核心在于品味审美（你知道什么是好的，你知道什么是不好的？你知道什么样的文章对于你这个赛道来说是最合适你的）和思路（提示词：把你的思路写出来，让 ai 执行的命令就是提示词），这个才是无可替代的，有壁垒的。

> 本教程提供了一个 AI 工作流模板，你可以把任何的内容，能以一秒钟的启动成本转化成属于你自己的原创 ip 内容。

> 上手难度：极低，且全程大白话，保姆级陪伴，没有专业术语，因为我也不是程序员。你不需要像 n8n、claude agent 那样需要魔法、需要软件部署、需要云服务器、需要寻找并且配置 API。你只需要跟着教程走，半小时就能搞定流程，剩下的时间可能是花几个小时甚至几天去调制你的提示词。本文后面会分享调制提示词、优化写作提示词的方法。

> 此外，coze 也可以使用 claude、gemini、gpt 这些国外模型，使用 http 请求节点，配置好 api 就可以了。这点和 n8n 一样，只是因为 api 是国外的原因，需要开魔法保持请求的网络通畅。

> 备注：我用的就是官网的 coze.cn 版本。gemini 的 api 是我在闲鱼买的中转 api，因为我没有海外卡去买 gemini api，所以直接使用 gemini 的 api 是什么情况我还不太清楚。

> 消耗成本的金钱成本：使用本工作流生成一篇文章并发布到👸号草稿箱，消耗的 coze 资源点在 50～100 之间。一般来讲，一个 coze 账号每天赠送的 500 个资源点可以生成 5～8 篇，保险点，一般生成 5 篇是足够的。此外，你可以花费 9.9 元的巨款买个会员，会得到一个月 3 万资源点，至少可以生成 300 篇文章了。矩阵玩家可能消耗的金钱成本是 10-1000 倍。

> 消耗成本的时间成本：

> 1、你寻找对标文章的时间，理论上，熟练后一分钟找到两篇文章是是很正常的事，就是你看到哪篇适合你，你就点进去看，觉得不错，就把链接保存下来。把你每天刷手机的几个小时中抽出 30 分钟用来刷对标，找文章足够了。

> 2、你可能不需要找对标文章，那就是你找选题，你想选题的时间，这个因人而异。

> 3、你审查文章的时间，或者对文章做修改的时间。 Ai 生成的内容无法 100%满足你的预期，所以我们需要适当修改，或者直接删掉这篇文章。 Ai 批量生成文章，走的就不是精细化的路子了，而是从文章当中选择好的发布出去。

## 一、AI 生成文章会限流？

开始之前先回答几个大家都非常在乎的问题，不一定对，这只是我的感受。但是我相信我的判断我的感受。

因为这几个问题，经常有一些朋友在心理作祟，所以还是写一点，把大家的可能存在的心结去掉。

> Ai 生成的文章会限流吗？

> 不会。 Ai 是大势所趋，平台拦不住的。2023、2024 年的时候，各大平台可能会若隐若现的限制 ai 生成的内容，但是在 2025 年，大势所趋，堵不如疏。

> 平台限制的不是 ai 生成的内容，而是垃圾内容，是高度同质化、高度模板化的内容，以及其他过度营销，黑五类，敏感类目这些内容。

> 这点你用不用 AI 都是一样，你手打搞出这些内容也会限流，甚至封你号，封你 ip，和 AI 和技术无关。

> 每天发布那么多文章会限流吗？

> 站在平台角度来讲，为什么多发文章就要被限流，这讲不通啊？

> 假设你是一个班的班主任，你会打压班级里面的活跃分子吗？他又没有破坏班级没有破坏集体，为什么要打压？

> 平台根本不在乎你每天发多少文章，只在乎你发的内容能不能给平台创造价值，给平台贡献利益。比如，你拉长了用户使用🛰️的时长，你提高了用户使用🛰️👸号的频率，你给🛰️带来了收入，他感谢你还来不及呢。

> 当然，这种发布多文章不是说你非要去挑战上限，一个账号一天发几百几千篇。但是做自媒体就大胆一点，你一天想发 10 篇 20 篇 30 篇就勇敢冲，没有那么多正确答案的，也没有那么多的错误答案，大家都是在摸索。

> 使用👸号 api 接口发布文章会限流吗？

> 不会。平台开了这个口子，就意味平台支持通过这种方式来上传文章，发布文章。

> 要不然平台闲的，无缘无故开 api 干嘛？钓鱼执法吗？

> 只要平台提供，只要平台不明确禁止，那就法无禁止一切皆可为。

> 多个👸号在同一个 ip 登录可以吗？

> 这个就见仁见智吧，有的人说不能超过三个，有的人说不能超过 5 个，有的人说不能超过 20 个，有的人说随便，无所谓。

> 你觉得怎么样做能让自己心安就怎么做，不要让这个动作成为心里的一根刺。后面内容不行，运营不行，选题不行，就总是觉得是自己 ip 问题。

> 使用个体工商户或者企业账号来注册的👸号发布文章有流量吗？

> 肯定的说，有。因为我就有几个号是用个体工商户注册的，其中我拿了三个来测试，一个账号发了大概一周文章后，从之前都是零阅读，突然变成了 4 位数甚至 5 位数的阅读量。不过剩下那两个号二十多天了没啥动静，都是零阅读。不过这种情况不止用个体工商户或者企业号注册的账号是这样，个人身份注册的号也会这样，某种程度上来讲，每个账号都有它的生命周期。

> 除此之外，你有空可以看看🛰️👸号有不少流量大的账号，它都是以个体工商户或者企业为主体注册的的，既然平台允许我们通过个体工商户来注册👸号，那么平台没有理由去限制。

> 我们看到看到这些号少，那是因为用个体工商户注册👸号的数量本身就比不上个人身份注册。

> 当然这个仁者见仁，智者见智。如果你很担心不使用个人身份注册的👸号发文章会受到各种隐形的限制，那为了心安，就用个人注册身份的👸号。

## 二、准备工作

### 1、注册 coze 账号并充值会员

注册链接：https://www.coze.cn/home

注册成功后如果出现这个页面就点击导航栏的【开发平台】

![](img/ead14fba6399907f6b25df45c5c1a653.png)

如果直接进入了这个页面，那就对了。

![](img/9797d8b2081e6ab205bb44aa42876f83.png)

如果你每天生成的文章超过 5 篇，那就开个会员。如果不超过，那就不用开。因为你生成文章的时候，资源点不够的话，coze 就会停止你的工作流，导致任务中断。

![](img/e3d934bc8e758d1074d22cf412666621.png)

### 2、注册飞书或者飞书多维表格

这个可选，有没有都可以。看你待会选择的工作流决定。

直接在浏览器一搜，就有网址。

### 3、准备👸号的 `AppID` 和开发者密码，配置 ip 白名单

> 注意：👸号没有实名认证的，无法获取开发者密码。

![](img/d606e66a9c9df70806c433bd202b52c8.png)

打开👸号，去设置与开发里面找到【开发接口与管理】，点击打开，点击启用开发者密码，跟着提示去操作就行了。记住，这个开发者密码一定要复制下来保存好。

![](img/02c2427b157c835a83cb20f562edcda6.png)

IP 白名单的配置在安全中心里面，在你启用了开发者密码之后才会打开。

如果后面你在安全中心找不到的话，那就在开发接口管理那里，多刷新一会。

![](img/e46f5d3674527e19b06365c45fd9c56b.png)

> 要配置的 ip，我们在后面的节点里面再打出来，因为 ip 白名单不是一成不变的，是随着我们节点使用的插件的变化而变化的。
