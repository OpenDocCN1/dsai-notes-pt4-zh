## 四、绘图模式及参数详解

### 绘图模式

+   以下分类方式主要基于官方API接口请求参数的类型

| 底模类型 | Star-3 Alpha | Flux.1 Dev | | SDXL | |
| --- | --- | --- | --- | --- | --- |
| 绘图模式/触发词 | 星流文生图 | FLUX文生图 | FLUX图生图 | SDXL文生图 | SDXL人脸参考 |
| 是否支持切换底模 | 否 | 是 | 是 | 是 | 是 |
| `Lora`最大串联数量 | 0 | 5 | 5 | 5 | 5 |
| 支持的通用参数类型 | `--ar`：绘图比例 | `--ar`：绘图比例 | `--ar`：绘图比例 | `--ar`：绘图比例 | `--ar`：绘图比例 |
| 支持的高级参数类型 | `line`、`depth`、`pose`、`IPAdapter` | `IPAdapter` | `denoise`（重绘幅度）、`IPAdapter` | `XL_canny`、`XL_depth`、`XL_pose`、`XL_IPA` | `InstantID` |

### 通用参数

+   `--ar`：指定生成图片的宽高比，支持1:1, 4:3, 3:4, 16:9, 9:16，不写则默认1:1
+   `--enhance`：使用LLM API增强提示词，不写则默认不开启
+   `<Ckpt:modelId>`：指定使用的底模(星流生图模式下不支持)，`modelID`可以是预设的底模名称，也可以是32位的`UUID`（`UUID`获取方式详见本章第4小节）
+   `<Lora:weight,modelId>`：指定使用的`Lora`模型和权重(星流生图模式下不支持)，`modelID`是32位的`UUID`

切记在使用`<Ckpt:modelId>`或`<Lora:weight,modelId>`指令时，32位的`UUID`不要换行（🛰️聊天中换行相当于插入了空格符号，会破坏`UUID`的完整性），否则指定的模型不会生效

### 高级参数

+   `<controlType:weight,imageUrl>`：指定使用的`ControlNet`类型、权重和控制图像链接
+   `<IPAdapter:weight,imageUrl>`：指定使用的`IPAdapter`权重和风格参考图像链接
+   `<denoise:weight,imageUrl>`: 图生图模式指定的重绘幅度和控制图像链接
+   `<InstantID:imageUrl>`：SDXL人脸参考模式指定的控制图像链接
+   不知道如何获取`imageUrl`？

可以安装本人开源的[`Img2Url`插件](https://github.com/Lingyuzhou111/Img2Url)(点击蓝字跳转)，通过在🛰️聊天窗口上传图片即可获得对应链接：

### 预设底模

除了星流绘画底模无法选择以外，FLUX和SDXL的绘画底模都经过精挑细选，新手建议使用默认底模，熟练了之后可以再在插件目录下的`config.json`文件中根据个人喜好自定义添加或者修改底模名称及其对应的`UUID`。

+   预设星流绘画底模（不可更改）：
+   Star-3 Alpha：Prompt理解更强、美学质量更高的新一代大模型
+   预设FLUX绘画底模（可自行添加）：
+   `F1_dev`：Flux.1Dev，FLUX生图模式默认底模
+   `F1_Photo`：蓦然回首人像模型，适合生成真实感人像
