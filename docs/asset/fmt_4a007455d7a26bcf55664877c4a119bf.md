
# 基于 LangChain 和 GPTCache 的文档问答实践

本节探索了如何使用[langchain](https://www.zhihu.com/search?q=map_reduce&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A689450121%7D)基于开源LLM在一组文档上进行问答，以`stuff chain`为例验证效果。对于`map_reduce`，`refine`和`map_rerank`等类型的`chain`，感兴趣的同学可参考官网文档自行验证。

## 准备工作

首先导入必要的packages

```
import time
import torch
from gptcache import cache
from gptcache.manager import CacheBase, VectorBase, get_data_manager
from gptcache.similarity_evaluation.distance import SearchDistanceEvaluation
from gptcache.embedding import LangChain

from langchain.document_loaders import PyPDFLoader
from langchain.embeddings import HuggingFaceEmbeddings
from langchain import HuggingFacePipeline
from transformers import AutoTokenizer, pipeline, AutoModelForCausalLM
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.vectorstores import Milvus
from langchain.chains.question_answering import load_qa_chain
from gptcache.adapter.langchain_models import LangChainLLMs
```

设置本地模型及文件路径

```
data_file = "../data/中华人民共和国证券法(2019修订).pdf"
model_path = "/root/models/Baichuan2-13B-Chat"
embed_path = "/root/models/bge-large-zh-v1.5"
```

## 加载embedding模型

官方教程中使用 `onnx` 作为 `embedding` 模型，但它仅支持512个token，而且只支持英语。为了验证中文问答效果，我们利用 `langchain` 提供的方法加载文本 `embedding` 模型，其中 `gptcache.embedding.langchain` 类实现用 `LangChain` 为指定文本生成文本嵌入。

```
embeddings = HuggingFaceEmbeddings(
    model_name=embed_path,
    model_kwargs={"device": "cuda"},
    encode_kwargs={"normalize_embeddings": True},
)
encoder = LangChain(embeddings=embeddings)
```

## Cache初始化

初始化`cache`有两种方式，一是用`map cache`（精准匹配缓存），二是用`DataBase cache`（相似搜索缓存），建议使用第二种方式。

定义`get_content_func()`函数获取`question`形成`prompt`：

```
# get the content(only question) form the prompt to cache
def get_content_func(data, **_):
    return data.get("prompt").split("Question")[-1]
```

### 相似匹配缓存初始化

当初始化`GPTCache`时，需要配置下面四个参数：

+   `pre_embedding_func`：提取特性向量之前的预处理

+   `embedding_func`：提取文本特征向量的方法

+   `data_manager`：用于缓存管理的`DataManager`

+   `similarity_evaluation`：缓存命中后的评估方法

采用`sqlite`作为缓存数据库，还支持 `postgresql`，`mysql`，`mariadb`，`sqlserver` 和 `oracle`等作为缓存数据库。

采用`milvus`作为向量数据库，相似度评估采用`SearchDistanceEvaluation`，基于向量搜索距离判断相似度，特点是简单、速度快，但准确度不是很高。 此外还有几种相似度评估方法，例如，

+   `OnnxModelEvaluation`用模型评估两个问题之间的相关度。但由于是小模型，只支持512个token，但准确度比基于距离的方式要高。

+   `NumpyNormEvaluation`计算 `llm`请求 和缓存数据两个嵌入向量之间的距离，也是又快又简单，准确度和基于距离的方法几乎一样。

+   `KReciprocalEvaluation`使用 `K-reciprocal`算法 为重排序计算相似度,召回多个缓存数据比较。这种方法需要召回多次，时间消耗较多，相对来说准确度更高。

+   `CohereRerankEvaluation`用 `cohere rerank api` 服务, 准确度更高, 需要付费调用。

+   `SequenceMatchEvaluation`，序列匹配，适合多轮对话场景, 分别对每轮对话评估相似度, 然后通过比例得到最终分数。

+   `TimeEvaluation`评估缓存创建时间，避免使用过时的缓存 。

+   `SbertCrossencoderEvaluation`用`sbert`模型做重排序评估，是当前已知最好的相似度评估方法。

```
cache_base = CacheBase('sqlite')
vector_base = VectorBase('milvus', host='XX.XX.XX.XX', port='19530', dimension=encoder.dimension, collection_name='cache')
data_manager = get_data_manager(cache_base, vector_base)
cache.init(
    pre_embedding_func=get_content_func,
    embedding_func=encoder.to_embeddings,
    data_manager=data_manager,
    similarity_evaluation=SearchDistanceEvaluation(),
)
```

## 数据准备

加载数据，写入`milvus`库。

```
loader = PyPDFLoader(data_file)
documents = loader.load_and_split()
text_splitter = RecursiveCharacterTextSplitter(chunk_size=512, chunk_overlap=32)
texts = text_splitter.split_documents(documents)

vector_db = Milvus.from_documents(
    texts,
    embeddings,
    connection_args={"host": "XX.XX.XX.XX", "port": "19530"},
)
```

## 加载LLM

这里没有选择调用`OpenAI API`，而是选择加载开源LLM。`langchain` adapter 提供了标准接口与`langchain`支持的`LLM`连接。

```
tokenizer = AutoTokenizer.from_pretrained(model_path,
                                          device_map="auto",
                                          trust_remote_code=True,
                                          torch_dtype=torch.float16)

model = AutoModelForCausalLM.from_pretrained(
    model_path,
    torch_dtype=torch.float16,
    trust_remote_code=True,
    device_map="auto",
)

pipeline = pipeline(
    "text-generation",
    model=model,
    tokenizer=tokenizer,
    return_full_text=True,
)

hf_llm = HuggingFacePipeline(pipeline=pipeline)
llm = LangChainLLMs(llm=hf_llm)
```

## stuff chain

在 `stuff chain` 模式下验证效果，同一个问题问两次，第三次问一个相似问题。执行时间分别为49.67s、0.52s和0.53s。可见使用缓存机制后，同样或相似问题的查询响应时间得到大幅度降低。

```
chain = load_qa_chain(llm, chain_type="stuff")

query = "公司首次公开发行新股，应当符合哪些条件？"
docs = vector_db.similarity_search(query)

st = time.time()
result = chain({"input_documents": docs, "question": query}, return_only_outputs=True)
et = time.time()
print("The first execution time:", et-st)
print("result:", result)

st = time.time()
result = chain({"input_documents": docs, "question": query}, return_only_outputs=True)
et = time.time()
print("The second execution time:", et-st)
print("result:", result)

similar_query = "公司首次公开发行新股，要符合什么条件？"
docs = vector_db.similarity_search(similar_query)

st = time.time()
result = chain({"input_documents": docs, "question": similar_query}, return_only_outputs=True)
et = time.time()
print("A similar query execution time：", et-st)
print("result:", result)
```
