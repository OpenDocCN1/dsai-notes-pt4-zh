
# 利用 100 个AI工具来帮助 Web3 创业

> 来源：[https://aiyanxishe.feishu.cn/docx/EjdTdNjO9oY7pPxjm7xcWSlGnid](https://aiyanxishe.feishu.cn/docx/EjdTdNjO9oY7pPxjm7xcWSlGnid)

当下ChatGPT 让人工智能（AI）非常火热，让我们看看有哪些 AI 工具（或自动化工具）来帮助我们进行Web3创业。

工具包含：寻找创业想法、招聘、构建网站、编写文案、创建视频等。

[AI研习社](https://zl49so8lbq.feishu.cn/wiki/wikcnu3kSXr75E50w8PFefhJMYf) - 中文AI教程、AI工具、AI商业研究集合地。

[ChatGPT讨论](https://discord.com/invite/ZFbE6NH57q) - 有教程和资源分享的ChatGPT社区。

Hugging Face - 建立、训练和部署最先进的模型，开源代码。

## 找寻Web3创业想法

[ChatGPT](https://chat.openai.com/) - 可以通过分析数据和使用预测分析法来识别潜在的机会，帮助寻找web3的商业想法。它也可以用来发现新技术及其潜力。

> 还可参考原作者 [Julian](https://linktr.ee/julianivaldy) 的另一篇文章：[ChatGPT X Web3: AI如何帮助你建立和发展你的Web3公司](https://julianivaldy.medium.com/chatgpt-x-web3-how-ai-can-help-you-build-grow-your-web3-company-f8ac26a68a9c)

[IdeasAI](http://ideasai.com/) - 提供由人工智能（OpenAI）产生的商业想法。

[FlowGPT](https://flowgpt.com/) - 结合ChatGPT，及令人兴奋的提示，构建创业想法。

[Infosys](https://www.infosys.com/)和[Alteryx](https://www.alteryx.com/)是分析和自动化的工具，帮助你的企业做出数据驱动的决策。

[IBM Watson](https://www.ibm.com/watson)是一整套商业工具，使用自然语言处理、机器学习和深度学习功能。

[Albus](https://www.springworks.in/albus/)将协助你为新的商业战略、设计和营销内容提供创意。

[Olli.ai](https://www.olli.ai/)将为你可视化任何数据，如果你正在进行市场调查，这将会很方便。

No-Code AI Model Builder允许你建立自己的AI模型。

[Spate](https://www.spate.nyc/)可以预测美容和健康行业的下一个主要消费趋势，这可以帮助你决定你未来的产品（如果你在这些行业中）。

## 人才雇佣

[Textio](https://textio.com/products/recruiting)将通过消除任何社会偏见来帮助你优化招聘信息，并为你提供可追踪的分析。

[Adaface](https://www.adaface.com/)将让你创建自定义技能评估，以节省你审查候选人的时间。

[Pyremetrics](https://www.pymetrics.ai/)是一个人才管理平台，使用行为洞察力和审计的AI。

[Turing](https://www.turing.com/)使用人工智能驱动的深度审核平台，为你的资源需求雇用和管理合适的远程开发人员、技术负责人和其他人。

[Fetcher](https://fetcher.ai/)将候选人的采购和外联工作自动化，让你有更多的带宽来专注于招聘的人性化方面。

## 整理你的工作

[Zia](https://www.zoho.com/zia/) - 自动安排会议，发送电子邮件，以及文件管理。

[Supernormal](https://supernormal.com/)、[Fireflies](https://fireflies.ai/)、[Wingman](https://www.trywingman.com/)——都是记录会议笔记的工具。[Sembly](https://www.sembly.ai/)不仅能将会议对话转换为文本，还能为你提供可操作的见解。

[Detangle](https://detangle.ai/) - 总结任何视频、音频或文本。

[YouTube Summary](https://chrome.google.com/webstore/detail/youtube-summary-with-chat/nmmicjeknamkfloonkhhcjmomieiodli/related)是一个免费的Chrome扩展，可以让你通过OpenAI的ChatGPT人工智能技术快速访问你正在观看的YouTube视频的摘要。

[Pickle](https://www.pickleai.com/) - 将转录电话/视频通话记录并获得对话摘要。

[LegalRobot](https://legalrobot.com/)将为你分析任何法律文件。

[tl;dr](https://app.tldrmail.co/)将通过电子邮件每天一次向你发送你的未读邮件的摘要（只适用于英语）。

[TheGist](https://www.thegist.ai/)将对slack频道或slack话题进行总结。

[Albus](https://www.springworks.in/albus/)将协助你为新的商业战略、设计和营销内容提供想法。

[Grammarly](https://www.grammarly.com/)将确保你的拼写正确。

[Towords](https://www.towords.io/)会把YouTube视频变成博客文章或新闻通讯。

[Automata](https://byautomata.io/)将把任何内容变成Linkedin帖子、推特、新闻通讯等。

[QuillBot AI](https://quillbot.com/)是一个在线写作助手，使用人工智能和机器学习来转述句子。

[Neuraltext](https://www.neuraltext.com/)帮助你撰写和发布高质量的SEO内容。

[Jasper](https://www.jasper.ai/)将在几秒钟内为任何媒体大规模地创建书面内容。

[LongShot](https://www.longshot.ai/)将协助撰写长篇的SEO内容。

[GhostWryter](https://ghostwryter.net/)是Google Docs的写作助手。

[Wordtune](https://www.wordtune.com/)将把你的文章转化为有趣的、有吸引力的和真实的文本。

[Tribescaler](https://tribescaler.com/)将为你的Twitter话题产生吸引人的钩子。

[Feedhive](https://www.feedhive.com/)将为你提供有吸引力的社会媒体帖子模板。

[GliaStudio](https://www.gliacloud.com/en/)将帮助你从新闻内容、社交帖子、体育赛事直播和统计数据中生成视频。

[FilmForge](https://filmforge.uwu.ai/)、[InVideo](https://invideo.io/)和[Synthesia](https://www.synthesia.io/)将从文本输入生成视频。

[Vidon](https://www.vidon.ai/)将从博客文章中生成视频。

[Murf](https://murf.ai/)和[Listnr](https://www.listnr.tech/)将文本转换为语音、画外音和口述。

[Descript](https://www.descript.com/podcasting)将通过自动转录、编辑和发布剧集，帮助你制作专业的声音播客。

[Krisp](https://krisp.ai/)将消除视频中的背景噪音。

[Kontent](https://kontent.ai/)是一个模块化的内容平台，使内容和工程团队能够创建、组织和重用有价值的内容，使每一个体验都一致和相关。

## 创建高质量的设计和视觉效果

[Midjourney](https://www.midjourney.com/app/)和[Dall.E](https://openai.com/dall-e-2/)将为你提供奇妙的文字到图像/图像到图像的视觉效果。

MiDaS by Hugging Face从一个单一的图像计算相对深度图像。

Depth Map Viewer将简单的二维图像+计算相对深度转换为一个动画图像。

LeiaPix Converter是一个免费的图像处理工具，能够将2D图像即时转换为美丽的3D光场图像。

[Image Enlarger](https://imglarger.com/)将提高图像的分辨率。

[VanceAI](https://vanceai.com/)是一个图像编辑和增强器。

[iPiccy](https://ipiccy.com/)允许你编辑照片并创建拼贴画或设计。

[Hotpot](https://hotpot.ai/)可以从文本中生成图像，提升照片的档次，删除物体，恢复旧照片，以及更多。

[AUVA](https://www.aiva.ai/)是一个人工智能，可以合成情绪化的原声音乐。

[Adobe Enhance](https://podcast.adobe.com/enhance)可以提高你的录音的音频质量。把你的iPhone变成一个专业的麦克风。

[WallSaidLabs](https://wellsaidlabs.com/)将文本实时转换为语音。

[Brandmark](https://brandmark.io/)将为你创建一个商业Logo或名片。

[Fontjoy](https://fontjoy.com/)将生成字体组合。

[Uizard](https://uizard.io/)将让你从手绘的草图中建立线框。

[Descript](https://www.descript.com/)是一个编写、记录、转录、编辑、协作和分享视频和播客的工具。

[Runway](https://runwayml.com/)帮助你进行视频编辑、协作等。
