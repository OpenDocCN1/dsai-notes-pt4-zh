## 常见问题

### 地区问题

因为国内的ip地址被 OpenAI 禁止访问，所以我们需要使用电脑上的代理功能，去代理一个 OpenAI 可以支持的 IP 地址，这个地址需要是住宅 IP 地址。如果是服务器地址，大概率是有很多人用过的，当你在用这种IP 去注册时，就会检测到你滥用。如果不知道什么是住宅 IP 的话。请去百度

### 手机号码问题

这个我经过测试发现几乎没有限制，出现注册失败，没有几个是因为手机号的问题。只要不是被用过的国外手机号都可以，如果你没有手机号，就去上面的接码平台上接一下就行。如果提示你的号码存在滥用行为，那么相信我，这不是手机号的问题，而是你 IP 的问题。说明你用的这个 IP 地址已经被很多人用过，并且注册过很多 OpenAI 账号。

住宅 IP 因为相对干净，所以不会被封禁。一个 IP 在大量注册账号后，官方就会封禁这个 IP。除了手机号被使用的问题外，其他的都是 IP 地址的限制
