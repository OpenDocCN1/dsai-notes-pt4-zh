
# SpecFusion

## 核心模块

1. 模式管理器：`Foundation Mode` 和 `Change Mode` 的统一管理
2. 规范生成器：自动生成规范文档的模板系统
3. 验证引擎：多层次的规范质量验证机制
4. AI 集成层：与各种 AI 工具的集成适配器

## 技术栈

+ 语言：`Python 3.8+`
+ CLI 框架：`Click`
+ UI 渲染：`Rich`（提供美观的命令行界面）
+ 模板引擎：`Jinja2`
+ Git 集成：`GitPython`
+ 包管理：支持 `uv`（推荐）和 `pip`
