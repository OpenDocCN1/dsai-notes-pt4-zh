## Tag组件

![](img/bf2006bfcda358238843934fe000d832.png)

[2024-11-28_14-43-00.mp4](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/Qp3qbhoaMo3AYtxSzYicUAulnYc)

最近看了一下好像Github没有高度自定义的Tag开源网页组件，所以用Cursor搓了一个，它可以：

+ 🎨 多种配色方案和渐变选项
+ 🔄 交互效果（比例、光泽、指针）
+ ✨ 自定义样式支持
+ 🎯 辅助功能
+ 📱 响应式尺寸
+ ❌ 可关闭的标签，带有淡出动画
+ 🖼️ 图标支持
+ 🛠️ 高度可定制（边框、阴影、不透明度等）

已经发布到Github和`npm`，地址分别是
