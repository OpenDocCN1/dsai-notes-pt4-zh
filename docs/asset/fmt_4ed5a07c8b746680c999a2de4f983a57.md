# 通过API调试让AI更懂你的需求

前面第4部分中提到：我们在让AI帮我们编程时，要尽可能“想办法把话说清楚”。这一点刘小排老师做到了极致。他在开发一个AI产品时，会先查看API文档，然后通过Postman调试，然后把API文档、API示例、示例输入和示例输出一并发给AI，这样AI往往能更加明确他的需求，在他圈定的范围内给出更加合理的代码。

接下来，我们就调试一下Nano-Banana生图的API，为后面AI更懂我们的需求并在网站中增加Nano-Banana生图功能做准备。

> 假设我们使用的是Fal.ai的`fal-ai/gemini-25-flash-image/edit`模型：

> https://fal.ai/models/fal-ai/gemini-25-flash-image/edit/playground

我先访问这个模型的页面：

![](img/3a4e363e95eba18c9dce24b937e68fc3.png)

可以看到这个模型支持输入Prompt、上传多张参考图片、设置图片生成数量、设置图片生成格式。点击上方“API”菜单可以查看这个模型的API文档：

![](img/b47b22d80d6ca0e5d65c713c42b97dc8.png)

那么，我们应该怎样调试这个API，让AI更加“听话”地输出我们想要的代码呢？其实过程并不复杂，主要有三个步骤：

+   准备API Key；
+   构建这个API的`CURL`语句；
+   通过Postman调试API的`CURL`语句。

## 步骤1：准备API Key

在开始调试API之前，我们需要先准备好所使用API平台的API Key。

登录Fal.ai网站后，点击右上角“Account”进入用户中心，点击“API Keys”菜单进入API Key页面，然后点击“Add key”按钮添加一个新的API Key。

![](img/bf0d74e7c4d5238414d9fb62121a8b0e.png)

生成新的API Key之后，记得马上复制这个API Key并保存好，因为这个Key只显示1次。

![](img/740ed53af451bb2556c613a819eea151.png)

后面，我们在调试API的过程中需要使用到这个Key。

## 步骤2：构建这个API的`CURL`语句

你可以先查看API的文档，很多API文档中往往有各种语言版本的示例代码，找到其中`CURL`的那个。如果你找不到或者不确定，可以把API文档发给ChatGPT，让它帮你构建适合在Postman工具中调试的`CURL`语句。

![](img/619e038beaf1fadb74d4f7205172709a.png)

ChatGPT输出了“同步直返”和“队列三段式”两种`CURL`的调试方式。接下来，我们开始调试“队列三段式”的`CURL`，因为ChatGPT在后面的沟通中建议在我们的Nano-Banana生成图片的网站中使用“队列三段式”的方式。

## 步骤3：通过Postman调试API的`CURL`语句

接下来，打开Postman网站：

> https://www.postman.com/

登录Postman后，进入一个Workspace（如果第一次登录，需要创建1个Workspace）：

![](img/0cbf3dc71de0376110bf1aa0a4ab41ca.png)

点击“Import”按钮导入ChatGPT给你输出的“提交请求”的`CURL`语句：

&quot;https://storage.googleapis.com/falserverless/example_inputs/nano-banana-edit-input.png&quot;,

&quot;https://storage.googleapis.com/falserverless/example_inputs/nano-banana-edit-input-2.png&quot;;

```
curl -X POST &quot;https://queue.fal.run/fal-ai/gemini-25-flash-image/edit&quot; \
    -H &quot;Authorization: Key $FAL_KEY&quot; \
    -H &quot;Content-Type: application/json&quot; \
    -d &#x27;{
        &quot;prompt&quot;: &quot;make a photo of the man driving the car down the california coastline&quot;,
        &quot;image_urls&quot;: [
        ],
        &quot;num_images&quot;: 1,
        &quot;output_format&quot;: &quot;jpeg&quot;
    }&#x27;
```

点击“Import Into Collection”保存。

接下来，我们需要关注`Headers`和`Body`这两项，`Headers`中需要配置API Key，而`Body`中包含我们这个API调试的示例输入（你可以理解为是我们发送给API的参数）。

打开`Headers`，把这里边的`$FAL_KEY`改成刚刚复制的API Key：

打开`Body`，可以看到显示一段`json`代码，包含`prompt`、`image_urls`、`num_images`和`output_format`这4个发送给API的参数，分别是生成图片时的描述、参考图（多张）、输出图片的数量（1~4张）和输出图片的格式（`jpg`/`png`），你可以根据你的需要修改这些参数。

![](img/86ff7256ffc9d5495494642f7a7e45f5.png)

接下来，点击“Send”发送请求给API。很快API返回“200 OK”，表示请求成功，返回了一段`json`代码，实际上，这就是我们API调试成功后需要用到的示例输出（你可以理解为API返回的结果）。

![](img/79753afb5dabec97285ce2077ab8787c.png)

![](img/cce8455db8ad3b20bc409f229c05a02d.png)

这里包含有一个后面两个`CURL`调试需要用到的`request_id`，我们需要把它替换到接下来需要调试的`CURL`语句中的`<REQUEST_ID>`中。如果调试返回错误，你就需要把错误发送给ChatGPT检查原因，并重新构建正确的`CURL`语句。

接下来，调试“轮询状态”的`CURL`语句：

```
curl -X GET \
    &quot;https://queue.fal.run/fal-ai/gemini-25-flash-image/requests/&lt;REQUEST_ID&gt;/status&quot; \
    -H &quot;Authorization: Key $FAL_KEY&quot;
```

与第一个`CURL`调试一样，通过“Import”导入第二个`CURL`，然后把`$FAL_KEY`改成刚刚复制的API Key。

![](img/6c5b1342095fd72b5312fa22df8449a2.png)

![](img/08e35abf65638567e5c7a0c0aa629c82.png)

点击“Send”发送请求，结果出现“405”报错。

![](img/01d4355f34c9bd82577eecf4a357599e.png)

我们把这个错误反馈给ChatGPT：

![](img/d4ede0fcb332654291c5994005c677b9.png)

ChatGPT调整了“轮询状态”和“获取结果”的`CURL`语句（去掉了`GET`链接中的“edit”）。

重新调试“轮询状态”的`CURL`，这次返回“200 OK”，调试成功，返回一段`json`代码，这是“轮询状态”的`CURL`的示例输出。你可能会问，那这个`CURL`的示例输入是什么？点开`Body`会发现并没有内容，因为这个`CURL`发送的是`GET`请求，不是`POST`，因此参数已经包含在请求的链接中，因此没有其它示例输入。

接下来，调试“获取结果”的`CURL`语句：

```
curl -X GET \
    &quot;https://queue.fal.run/fal-ai/gemini-25-flash-image/requests/&lt;REQUEST_ID&gt;&quot; \
    -H &quot;Authorization: Key $FAL_KEY&quot;
```

与“轮询状态”的`CURL`语句同理，这个`CURL`语句发送`GET`请求，参数已经包含在`GET`请求的链接中。调试成功显示“200 OK”，返回一段`json`代码，这是“获取结果”的`CURL`的示例输出。

![](img/a8ab85b6ede0d3954c415f9a4d919c35.png)

就这样，我们通过API调试，集齐了小排老师在深海圈课程中提到的API四要素。下一部分，我们把这些API信息整理放在我们的Prompt中，让AI更懂我们的需求，并输出合理的代码。
