### 姚期智院士大模型新研究：思维图DoT，用数学理论确保AI逻辑一致性

https://mp.weixin.qq.com/s/pzn802jOIHeL0L9L_yaytw

姚期智团队提出了大语言模型（LLM）推理新框架“思维图”（DoT），对现有的链式推理（CoT）进行重要改进。该框架通过有向无环图（DAG）建模推理过程，提升了模型的推理复杂度和准确性。不同于CoT线性推理，DoT能够更好地捕捉推理中的复杂关系，并避免依赖外部控制或多个模型协作。DoT的推理过程包括三个角色：提议者、批评者和总结者，它们通过生成、批评和综合命题，完成逻辑推导。每个推理步骤通过DAG节点和边的拓扑关系建模，确保逻辑一致性和无环特性。

DoT的核心创新在于将推理过程形式化为数学拓扑斯理论（Topos Theory），以确保逻辑推理的可靠性。与CoT相比，DoT不依赖于多个模型的协作，而是在单个模型中通过DAG实现复杂推理，降低了训练和部署的难度。每个节点表示命题或批评，边则表述节点间的依赖关系。通过自然语言的批评反馈，DoT还能让模型从错误中学习，更真实地模拟人类思维方式。

团队利用拓扑斯理论对DoT进行了严格的数学形式化处理，模型的推理过程得到了理论上的逻辑一致性保障。这一框架不仅简化了部署流程，还为未来推理专用AI模型提供了新的设计思路。

### Rabbit推出基于网络的通用大动作模型代理：跨平台操作成焦点

https://techcrunch.com/2024/09/23/rabbits-web-based-large-action-model-agent-arrives-on-r1-as-early-as-this-week/

Rabbit公司计划于10月1日发布基于网络的通用版大动作模型（Large Action Model, LAM）代理，这一代理能够在任何网站上执行常见任务，如购买票务、注册网站、玩在线游戏等。与之前仅限于特定应用程序或服务的版本不同，此次发布的LAM能够识别屏幕上的按钮、字段和图像，并根据学习到的网页操作知识执行任务。

该代理通过分析任务步骤并执行操作，展示出较高的自动化潜力，但依然依赖于用户的提示精度。CEO Jesse Lyu承认，虽然模型能够进行任务规划，但其在跳过不必要步骤或优化用户偏好方面仍有局限。此外，该系统并不收集用户数据来改善模型，但未来可能引入“教学模式”以帮助用户定制任务执行方式。

Rabbit公司还在开发一个桌面版代理，旨在控制桌面应用程序，如文字处理器和音乐播放器。虽然该技术仍处于早期阶段，但目标是构建跨平台的通用AI系统，能够操作用户所有服务。

### 国产AI芯片行业简评

https://mp.weixin.qq.com/s/c0XFavJVlGAl0xlG8n9cbg

国产AI芯片行业呈现两极分化态势，一方面燧原科技和壁仞科技等企业逐步迈向IPO，另一方面砺算科技等公司则面临资金困境。芯片行业高投入、高风险的特点，使得“赢者通吃”的局面日益凸显。数据显示，2023年已有1.09万家中国芯片相关企业注销或吊销。

壁仞科技等公司在美国制裁和国内政策支持下，加快了技术突破，尤其是在GPU设计方面。壁仞科技的BR100 GPU芯片和燧原科技的“邃思2.0”训练芯片均采用了高性能的设计，并在大模型训练中取得了显著进展。燧原科技通过自研架构和指令集，推出了部分兼容CUDA生态的产品，强化了芯片间的互联技术，大幅提升了集群计算的效率。

天数智芯专注于通用GPU产品开发，旗下“天垓100”芯片支持多种AI模型训练，并在7nm制程下实现了高效算力。摩尔线程坚持全功能GPU路线，发布了多款产品，并通过MUSA工具包支持复杂并行计算。沐曦集成电路则通过GPGPU路线切入市场，逐步向图形渲染GPU发展。

尽管国产芯片在7nm制程内取得了一定突破，但其生态建设依然是亟待解决的问题，特别是在兼容CUDA和构建软硬件协同系统方面。国产替代的道路漫长，企业需不断探索盈利模式，才能在全球竞争中站稳脚跟。

### 科技巨头如何拥抱核能以应对数据中心能耗挑战

https://techcrunch.com/2024/09/23/how-big-tech-embraced-nuclear-power/

随着数据中心的飞速增长，微软、亚马逊等科技巨头正逐渐转向核能，以解决其碳排放目标与能耗需求之间的矛盾。最近，微软与Constellation Energy签署了一项协议，计划重启三里岛核电站的一个反应堆，以应对日益增加的数据中心电力需求。

目前，数据中心消耗了美国约4%的电力，预计到2030年这一数字可能增长至9%。大型科技公司的超大规模数据中心，如微软、谷歌和亚马逊的运营中心，已占据了60%到70%的数据中心能耗。微软计划到2030年实现碳负排放，但由于数据中心扩展，其碳排放在过去四年增长了40%。与此同时，谷歌的碳排放在过去五年增长了48%。

核能因其可以持续多年以最高效率运行，被科技公司视为解决能耗问题的一个重要手段。微软已与Constellation签署了一项为期20年的协议，此外还投资了小型模块化反应堆公司Last Energy。亚马逊也在三里岛附近收购了一座与核电厂直接相连的超大规模数据中心，并招聘核工程师以推动核能发展。

投资者也对核能寄予厚望，微软联合创始人比尔·盖茨投资了核能初创公司TerraPower，微软前首席技术官Nathan Myhrvold也通过知识产权公司投资了该领域。然而，核能初创企业仍面临工程和监管方面的挑战，同时核电在社会接受度上仍然落后于风能和太阳能。

尽管如此，重启旧核电厂可以帮助科技公司暂时缓解电力需求的增长，未来它们仍需寻找更广泛的替代能源解决方案

### RAG的以知识为中心的基准框架和实证研究

https://arxiv.org/abs/2409.13694

检索增强生成（RAG）通过集成检索机制来增强生成模型，使这些模型能够访问和利用外部知识源。尽管有其优势，但 RAG 遇到了重大挑战，尤其是在有效处理现实世界的查询和减轻幻觉方面。KDD Cup 2024 CRAG 竞赛通过将网页和模拟 API 合并为知识源，增加了在大型语言模型（LLMs）。在本文中，我们提出了一种新颖的 RAG 基准测试，旨在应对这些挑战。我们的工作提供了一套全面的实验结果，为 RAG 的研究提供了有价值的见解。我们彻底检查了整个 RAG 过程，包括知识源的选择、检索、组织和推理。我们研究的主要发现包括使用代理自动选择知识源的影响以及噪声块对 RAG 推理的影响。此外，我们进行了详细的实验来分析各种超参数对 RAG 性能的影响。为了支持进一步的研究，我们已公开提供我们的结果、相关代码和 CRAG 数据集的解析版本，为 RAG 方法的进步做出了贡献，并为该领域的未来工作奠定了坚实的基础。

### 只使用反应式注意力切片进行长上下文检索

https://arxiv.org/pdf/2409.13695

为大型语言模型（LLM）。由于为较长的上下文窗口训练模型在计算上成本很高，因此使用了许多替代解决方案，例如 Retrieval Augmented Generation（RAG）。然而，大多数现有的 RAG 方法都采用基于嵌入的检索，这在长上下文中是不足的。

为了应对这些挑战，我们提出了一种基于注意力的检索技术，You Only Use Reactive Attention slice（YOURA）。YOURA 利用一种称为 reaction score 的新型检索启发式方法对输入上下文中每个句子与查询句子的相关性进行排名。直观地，我们测量每个标记的注意力分数如何对查询 “反应”，并贪婪地检索反应最灵敏的句子。在内部，YOURA 为整个 input 上下文生成一个标记索引的向量（称为反应向量）。为了将每个句子映射到标记索引向量，我们提出了一种嵌入无关的句子生成率（EASY），这是一种尽力而为的标记摆动算法。

我们在六个 LongBench QA 数据集中的三个开源预训练 LLM。我们的技术实现了高达 30% 的 vLLM 推理吞吐量改进，用于服务长上下文查询，其质量得分与简单而有效的截断中间方法几乎相同。

### Wormhole：用于协同进化序列的概念感知深度表示学习

https://arxiv.org/pdf/2409.13857

识别和理解共同进化序列中的动态概念对于分析 IoT 应用程序、金融市场和在线活动日志等复杂系统至关重要。这些概念为连续数据的底层结构和行为提供了有价值的见解，从而能够更好地做出决策和预测。本文介绍了 Wormhole，这是一种新颖的深度表示学习框架，具有概念感知性，专为共同进化的时间序列而设计。我们的模型提供了一个自表示层和一个时间平滑度约束，以确保对动态概念及其过渡的稳健识别。此外，通过识别潜在空间中的突然变化来检测概念转换，这标志着向新行为的转变 - 类似于穿过虫洞。这种新颖的机制准确地辨别了共同进化序列中的概念，并精确定位了这些虫洞的确切位置，增强了所学表征的可解释性。实验表明，这种方法可以有效地将时间序列数据分割成有意义的概念，为分析复杂的时间模式和推进概念漂移的检测提供了有价值的工具。

### 使用在合成先验上训练的 Transformer 的 One-shot 世界模型

https://arxiv.org/abs/2409.14084

世界模型是真实世界环境的压缩空间和时间表示，允许训练代理或执行规划方法。但是，世界模型通常是根据来自真实世界环境的观察结果进行训练的，并且它们通常不会为其他真实环境启用学习策略。我们提出了 One-Shot World Model（OSWM），这是一种 transformer 世界模型，它是从先前分布中采样的纯合成数据中以上下文学习方式学习的。我们的先验由多个随机初始化的神经网络组成，其中每个网络都对所需目标环境的每个状态和奖励维度的动态进行建模。我们采用先验拟合网络的监督学习程序，在随机的上下文位置屏蔽下一个状态和奖励，并查询OSWM以根据剩余的过渡上下文进行概率预测。在推理期间，OSWM 能够通过提供 1k 过渡步骤作为上下文来快速适应简单网格世界以及 CartPole 健身房和自定义控制环境的动态，然后能够成功训练环境解决代理策略。然而，转移到更复杂的环境目前仍然是一个挑战。尽管存在这些限制，但我们认为这项工作是追求纯粹从合成数据中学习世界模型的重要垫脚石。
