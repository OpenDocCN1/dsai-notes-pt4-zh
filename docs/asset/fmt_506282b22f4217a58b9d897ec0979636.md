# 三、定义模型结构：卷积神经网络

## 1、为什么要用卷积神经网络？

图片数据量大，运算量大。比如说一个`200 * 200`的彩色图片，那么它就有`200 * 200 * 3 = 120000`个特征。（乘3代表彩色图片包含 RGB 三个图层）

我们知道，在当下这个时代， `200*200` 的照片算是非常非常小了，光它就有 12 万个特征。之前我们谈到过，每个特征我们都会为它准备一个权重，这个权重会存放到神经元里面。那么光这张彩色照片都有 12 万个权重，如果需要一步步去调试和计算，效率就会有点太低了。而且因为我们这个特征一多，网络也复杂，很容易导致过拟合。

因此，我们要采用一种新的神经网络来解决这种图片分类的问题，也就是卷积神经网络。

卷积神经网络模拟人类的视觉处理流程，能够快速高效地提取特征，更大幅度地减少运算量。

## 2、卷积神经网络的层

**卷积层：**

+ 卷积层是用来提取特征的；
+ 通过 [Image Kernels](https://setosa.io/ev/image-kernels/) 了解卷积运算；
+ 使用多个卷积核（`filter/kernel`）对图像进行卷积操作；
+ 卷积层有权重需要训练，卷积核就是权重；
+ 附上一个专门讲解卷积神经网络的网址：https://cs231n.github.io/convolutional-networks/。

**池化层：**

+ 最大池化层用于提取最强的特征
+ 扩大感受野，减少计算量
+ 池化层没有权重需要训练

**全链接层：**

+ 作为输出层
+ 作为分类器
+ 全连接层有权重需要训练

## 3、训练过程

了解了卷积神经网络的层之后，下面我们用这些知识点，来完善上面的代码。具体代码如下：

```javascript
import * as tf from '@tensorflow/tfjs';
import * as tfvis from '@tensorflow/tfjs-vis';
import { MnistData } from './data';

window.onload = async () => {
  // 加载mnist数据
  ……

  /**
   * 卷积神经网络
   */
  // sequential连续型模型
  const model = tf.sequential();
  // 第一层卷积神经网络
  model.add(
    tf.layers.conv2d({
      inputShape: [28, 28, 1], // 图片的宽度、高度和channels
      kernelSize: 5, // 用奇数会更好提取
      filters: 8,
      strides: 1, // 移动步长
      // 激活函数设置成relu，可以移除掉一些不常用的特征。
      // 如果特征小于0，就输出0.如果大于0，就输出它自己。
      activation: 'relu',
      // 卷积初始化，设置了之后能够加快模型的收敛速度
      kernelInitializer: 'varianceScaling'
    })
  );
  // 最大池化层
  model.add(
    tf.layers.maxPool2d({
      // 设置池化的尺寸，设置成2个
      poolSize: [2, 2],
      // 超参数
      strides: [2, 2]
    })
  );

  // 手写数字：第一轮提取横竖
  model.add(
    tf.layers.conv2d({
      kernelSize: 5,
      filters: 16,
      strides: 1,
      activation: 'relu',
      kernelInitializer: 'varianceScaling'
    })
  );
  // 手写数字：第二轮提取直角
  model.add(
    tf.layers.maxPool2d({
      poolSize: [2, 2],
      strides: [2, 2]
    })
  );
  // 把高维的特征转化成一维，也就是把高维数据放到最后一层dense层去做分类
  model.add(tf.layers.flatten());
  // 最后一层，全链接层
  model.add(
    tf.layers.dense({
      units: 10, // 神经元10个，0-9
      activation: 'softmax', // 多分类的激活函数
      kernelInitializer: 'varianceScaling'
    })
  );
};
```
