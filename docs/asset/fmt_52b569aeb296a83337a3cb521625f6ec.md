## 二、思路

### 1、先饿补这类小说

> 不管是都市种田文还是其他类型的种田文，都是有着完善的经济体系，利用种田元素获取资源，再用资源转化成自己所需，提升社会地位满足主角的需求带来安全感，嵌入到正常的装逼打脸或者升级冲突的剧情中去。

>

> 当然有个重点要注意，**就是经济体系不要崩，**就是收获永远是跟不上消耗的，就是无论赚多少钱收获多少资源，都是永远不够的，当你的收获超过你的需求的时候期待感就没有了，也就是崩了。

> 所以写的时候要控制收益，金手指不能开太大，要有各种限制。

>

> **按照种田类型区分：**

+ 有开农场，种田收获植物的(包括采集植物)。

+ 有山里捕猎，收获各种猎物的(包括养殖动物，林场，牧场)。

+ 有出海打鱼钓鱼，收获鱼获的（也包括养殖鱼的，或者溪流湖泊池塘）。

+ 在金手指上区分，有获得某个种植空间的，某个种植技能，养殖技能，或者其他的发现鱼获的技能，或者直接是某种匹配种田文的异能金手指）（比如说加速生长，变异）。

### 2、总结类型

#### 都市种田文：

书单：《大山果园1988》《美国牧场的小生活》《黄金渔场》

核心本质：

+ 主角通过各种手动不断地收获一些种田收获，然后变现赚钱获得财富，在通过这些财富提升社会地位，撩妹享受生活，装逼打脸。

+ 把种田属性看成一个金手指。

#### 历史种田文，和都市向有明显的区别。

书单：《摸鱼王爷被迫营业》《工业大明从北平开始》《我在大明肝生活技能》

核心本质：

+ 是发育发展势力，继承或者建立一个势力，圈一个领地基地或者类似的概念，有着严谨的经济体系，突出钱和资源、人口的重要性。

+ 主角永远缺钱缺资源不缺挣钱获得资源的能力和途径，在这个经济体系和世界观下，可以用钱和资源转化成自己势力人口的实力，就是不断地收获和消耗。

#### 玄幻种田文：

书单：《异世之虫族无敌》《机械神皇》《开局一枚建城令》

核心本质：

+ 一些升级向的皇帝流、领主流，召唤流，爆兵流，用资源（钱、晶核、物资，甚至是气运属性点这种无形之物）快速转化成自己手下势力人设的实力提升获取更多手下人口，这类题材就是升级向的种田文。

+ 非权谋，不走仕途，不升级，主要是经商赚钱，开工厂，外国历史几乎全是历史种田文，可以只赚钱和资源，利用钱和资源武装自己，富可敌国，也可以建立势力，抵御其他政权势力，能武力对抗国家，比如说用钱养兵，囤积粮食，战马，武器，获取人口。

#### 科幻重生/末世种田文：

书单：《开局中奖3000万》

其实，末世种田文不少，甚至比玄幻更多一点，记不起来了，懒鸟的几本书，疯狂建村令，农夫凶猛，开局一枚建城令，其实科幻向的发到玄幻品类去了。 游戏也是领主基地类的，和科幻很类似。

#### 仙侠种田书单：

书单：《逐道长青》《修仙从沙漠开始》

核心本质：

+ 继承或者建立家族势力，种植开采资源，或者通过副业炼丹炼器猎妖，交易收集各种修炼资源，发展家族势力，提升家族成员的实力，在横推一个个其他修仙势力。

+ 掠夺资源（灵脉，地域，人口等等）这些。

#### 奇幻种田文：

书单：《国王》《哈兰德领主》《放开那个女巫》《我在异界种田封神》

核心：

+ 奇幻的领主种田文从过去现在到未来，都是一个长青题材。主流是领主种田，

+ 成为某地领主，然后通过各种经济和战争手段，积累财富，把财富资源转化成人口和手下实力，抵御其他种族或者其他领主的入侵，反过来扩大领地，到了一定程度就是信仰封神，从最初的争夺领地资源到争夺人口信仰。

> 第二阶段：崭露头角，发家致富（约20万字）

> *   林依依利用空间种植出高品质的茶叶、药材等，并研究出新的制作工艺，打造出独具特色的产品，在当地市场打开销路。

> *   开设店铺，创立自己的品牌，将生意拓展到附近的城镇，积累财富，成为当地小有名气的商人。

> *   利用现代知识，帮助村民改良种植技术、养殖技术，带领村民共同致富，受到村民的尊敬和爱戴。

> *   林依依的事业发展引起叔叔婶婶的嫉妒，他们设计陷害，想要抢夺林依依的财产，但都被林依依机智化解。

>

> 第三阶段：爱情事业双丰收（约15万字）

> *   林依依的才华和善良吸引了年轻有为的县令公子注意，两人相识相爱。

> *   林依依在县令公子的帮助下，将事业发展到更广阔的天地，开设工厂，发展手工业，带动当地经济发展。

> *   叔叔婶婶的阴谋最终败露，受到法律的制裁，林依依一家终于过上了安稳幸福的生活。

> *   林依依与县令公子喜结良缘，婚后育有一子，生活美满幸福。

>

> **四、亮点和看点：**

> *   **新颖的穿越元素：** 女主自带淘宝空间，可以购买现代商品，为古代生活带来了无限可能，也为故事增添了许多趣味性和新意。

> *   **励志的奋斗故事：** 女主从一个落魄的农家女，通过自己的努力和智慧，最终实现事业爱情双丰收，她的故事充满了正能量，能够引发读者的共鸣。

> *   **温馨的亲情描写：** 女主与弟弟、奶奶之间的亲情，以及与青梅竹马的友情，都描写得细腻感人，为故事增添了温暖的基调。
