## Pro会员能干啥？值40刀吗？

先看免费版有多惨：

+ 每月只能做5个项目
+ 不能绑自己的域名
+ 不能用数据库
+ AI生成次数有限制

Pro会员解锁后：

+ 项目数量无限
+ 自定义域名（绑上你自己的域名）
+ `Supabase`数据库（能存数据了）
+ AI生成次数无限
+ 优先客服

老金觉得最值的是自定义域名。

做个产品落地页，绑上 xxx.com 域名，逼格瞬间拉满。

要是用免费版那个 xxx.lovable.app 的域名，客户一看就知道你是临时搞的。

## 3个坑，老金帮你踩过了

用下来发现几个问题，提前告诉你：

**坑1：需求说太模糊，AI会乱搞**

你说"做个博客"，它可能给你整个四不像出来。

正确做法：说清楚要什么。

> "做一个技术博客，要有文章列表、标签筛选、`Markdown`渲染，风格参考少数派"

**越具体，出来的越接近你想要的。**

**坑2：改样式比较磨叽**

每次改颜色、字体，AI都要重新生成一遍。

不像传统建站工具拖拽就改。

如果你是完美主义者，要有心理准备，可能要调好几轮。

**坑3：数据库功能有门槛**

虽然集成了`Supabase`，但你要是完全不懂数据库，可能会卡住。

老金建议：先做静态网站练手，熟悉了再碰数据库。

## 老金的4个使用技巧

既然薅了，就好好用。

**技巧1：需求写具体**

别说"做个网站"，要说"做个AI工具导航网站，首页要有搜索框、工具卡片、分类标签，点击卡片跳转详情页"。

**技巧2：分步调整**

先让AI生成基础版，然后一点点改。先布局，再颜色，最后加功能。

别一次提一堆需求，AI会晕。

**技巧3：先看模板**

Lovable有个Templates页面，里面全是现成模板。

先`fork`一个接近的，基于它改，比从零开始快10倍。

**技巧4：导出代码**

免费期做的项目，记得把代码导出来。

万一以后不续费了，至少代码还在手里，可以自己部署。
