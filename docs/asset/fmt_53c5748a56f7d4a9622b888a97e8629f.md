
## 文生视频模型训练

```
DATA_ROOT="/path/to/my/datasets/disney-dataset" #预处理后数据集路径
CAPTION_COLUMN="prompts.txt" # 提示词路径
VIDEO_COLUMN="videos.txt" # 视频路径
MODEL_PATH="THUDM/CogVideoX-5b" # 模型绝对路径

cmd="accelerate launch --config_file $ACCELERATE_CONFIG_FILE --gpu_ids $GPU_IDS training/cogvideox_text_to_video_lora.py \
  --pretrained_model_name_or_path $MODEL_PATH \
  --data_root $DATA_ROOT \
  --caption_column $CAPTION_COLUMN \ # Encode 后数据集位置
  --video_column $VIDEO_COLUMN \ # Encode 后数据集位置
  --id_token BW_STYLE \  # 无需修改
  --height_buckets 480 \ # 视频高
  --width_buckets 720 \ # 视频宽
  --frame_buckets 49 \ # 视频帧率
  --dataloader_num_workers 8 \  # num_workers
  --pin_memory \ # 默认
  --validation_prompt "\"BW_STYLE A black and white animated scene unfolds with an anthropomorphic goat surrounded by musical notes and symbols, suggesting a playful environment. Mickey Mouse appears, leaning forward in curiosity as the goat remains still. The goat then engages with Mickey, who bends down to converse or react. The dynamics shift as Mickey grabs the goat, potentially in surprise or playfulness, amidst a minimalistic background. The scene captures the evolving relationship between the two characters in a whimsical, animated setting, emphasizing their interactions and emotions:::BW_STYLE A panda, dressed in a small, red jacket and a tiny hat, sits on a wooden stool in a serene bamboo forest. The panda's fluffy paws strum a miniature acoustic guitar, producing soft, melodic tunes. Nearby, a few other pandas gather, watching curiously and some clapping in rhythm. Sunlight filters through the tall bamboo, casting a gentle glow on the scene. The panda's face is expressive, showing concentration and joy as it plays. The background includes a small, flowing stream and vibrant green foliage, enhancing the peaceful and magical atmosphere of this unique musical performance\"" \
  --validation_prompt_separator ::: \ #分割符
  --num_validation_videos 1 \  #验证集视频数
  --validation_epochs 10 \ # 10 轮验证一次
  --seed 42 \ # 训练和验证时候的种子
  --rank 128 \ # Lora Rank
  --lora_alpha 128 \ # Lora_Alpha
  --mixed_precision bf16 \ # 混合精度训练
  --output_dir $output_dir \ #输出地址
  --max_num_frames 49 \ #帧率
  --train_batch_size 1 \ # 对于 RTX4090，只能为1
  --max_train_steps $steps \ #最大训练数
  --checkpointing_steps 1000 \ # 保存点
  --gradient_accumulation_steps 1 \ # 梯度累计
  --gradient_checkpointing \ # 默认需要打开
  --learning_rate $learning_rate \ # 学习率
  --lr_scheduler $lr_schedule \ # 默认使用 ADAM
  --lr_warmup_steps 400 \ 
  --lr_num_cycles 1 \
  --enable_slicing \ #  对于RTX4090 必须开启
  --enable_tiling \ #  对于RTX4090 必须开启
  --enable_model_cpu_offload \ # 对于RTX4090 必须开启
  --load_tensors \ 载入预处理数据集， 对于RTX4090 必须开启
  --optimizer $optimizer \
  --beta1 0.9 \ 
  --beta2 0.95 \
  --weight_decay 0.001 \
  --max_grad_norm 1.0 \
  --allow_tf32 \
  --report_to wandb \  #可视化工具
  --nccl_timeout 1800"
```

修改完脚本之后，我们运行微调脚本：

```
bash train_text_to_video_lora.sh
```

如果你使用单张`RTX4090`，对于本数据集，通常需要10个小时才能完成3000`steps`的`Lora`训练。

因此，你可以使用`nohup`进行管理：

```
nohup bash train_text_to_video_lora.sh > $(date +"%Y-%m-%d_%H-%M-%S")_cogvideox_lora.log 2>&1 &
```

这样，你就可以后台运行了。

## 图生视频模型

图生视频的脚本与文生视频基本相同，主要区分点

+ 需要使用`CogVideoX-5B-I2V`作为基座模型。

+ 脚本会自动将数据集中所有视频第一帧设置为图像传入。

+ 对于验证集，你需要单独准备一张图像作为验证。

其他部分的修改与文生视频相同。

## 模型使用

训练完成后，需先将`LoRA`保存。默认情况下，模型保存结果文件名为:

```
cogvideox-lora__optimizer_adam__steps_3000__lr-schedule_cosine_with_restarts__learning-rate_1e-4
```

其中，会包含训练的步数，学习率，学习策略等信息。进入文件夹，可以查看`adapter`模型权重。

在这里，我们提供了一个简单的脚本，用于部署微调模型的推理。
