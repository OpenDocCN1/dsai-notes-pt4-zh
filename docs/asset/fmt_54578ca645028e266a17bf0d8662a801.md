### 上海电信 59 改 5 元无忧套餐

#### 进度跟进

让拨打 中国移动上海本地客服 热线 `0210000`

> 上海电信客服：`10000`（本地直拨）

> 外地拨打上海电信：`021-10000`

> 上海电信监督热线：`021-58520000`中国电信上海公司

```
1. 取消我号码上所有政企标签和政企流量包，我是个人用户，并非政企客户。

2. 终止“星卡承诺消费策略59元”的长期合约，且不收取违约金，该合约是代理商违规绑定的，我并不知情。

3. 协助我将套餐变更为上海电信5元保号套餐（如5元无忧卡）。
```

```
我于2022年1月在杭州大润发，通过饿了么外卖代理商办理了一张上海电信星卡。当时代理商承诺月租为19元，并未告知任何附加合约或政企套餐绑定。

近期我发现，该号码被违规绑定了以下内容：

1. 政企行业流量包：10GB和20GB国内流量包，标注为“政企行业专属”，但我是个人外卖骑手，并非政企单位用户。

2. 长期消费合约：“星卡承诺消费策略59元”，合约期至2051年，此合约我完全不知情，也未签署任何协议。

3. 以上绑定导致我无法根据自身需求，变更为5元保号套餐，严重侵犯了我的自主选择权。
```
