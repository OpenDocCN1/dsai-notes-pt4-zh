## 模型架构：`3D U-Net` 和 `DiT`

与文本到图像的扩散模型类似，`U-net` 和 `Transformer`仍然是两种常见的架构选择。

> Google 有一系列基于 `U-net` 架构的扩散视频建模论文，而 OpenAI 最近的 `Sora` 模型则利用了 `Transformer` 架构

`VDM`采用标准扩散模型设置，但具有适合视频建模的更改架构。它将 2D `U-net` 扩展为适用于 3D 数据，其中每个特征图表示帧 x 高度 x 宽度 x 通道的 4D 张量。此3D U-Net在空间和时间上进行分解，这意味着每一层仅在空间或时间维度上运行，但不能同时在两者上运行：

+ 加工空间

1. 2D `U-net` 中的每个旧 2D 卷积层都扩展为仅空间 3D 卷积；准确地说，3x3 卷积变成了 1x3x3 卷积
2. 每个空间注意力块仍然作为空间注意力，其中第一个轴（ frames ）被视为批量维度

+ 处理时间

1. 在每个空间注意块之后添加时间注意块。它对第一个轴 ( frames ) 进行关注，并将空间轴视为批量维度。相对位置嵌入用于跟踪帧的顺序。时间注意力块对于模型捕获良好的时间一致性非常重要

## 基本视频扩散模型

一系列交错的空间和时间超分辨率扩散模型，包括 3 个 `TSR`（时间超分辨率）和 3 个 `SSR`（空间超分辨率）组件

![](img/c0b60a6646cabd627689d82cd4378153.png)

基础去噪模型同时对具有共享参数的所有帧执行空间操作，然后时间层混合跨帧的激活以更好地捕获时间一致性，这比帧自回归方法效果更好

![](img/322dac458dc27e5667c4966df4535b6f.png)

`SSR`和`TSR`模型都以与通道方式的噪声数据  连接的上采样输入为条件。`SSR` 通过双线性调整大小来上采样，而 `TSR` 通过重复帧或填充空白帧来上采样。

`Imagen Video` 还应用渐进式蒸馏来加速采样，每次蒸馏迭代都可以将所需的采样步骤减少一半。他们的实验能够将所有 7 个视频扩散模型提炼为每个模型仅 8 个采样步骤，而感知质量没有任何明显损失。

为了实现更好的扩展工作，`Sora`利用 `DiT`（扩散变压器）架构，该架构对视频和图像潜在代码的时空补丁进行操作。视觉输入被表示为一系列时空补丁，充当 `Transformer` 输入标记

### 调整图像模型来生成视频

> 扩散视频建模的另一个重要方法是通过插入时间层来“膨胀”预先训练的图像到文本扩散模型，然后我们可以选择仅微调视频数据的新层，或者根本避免额外的训练。新模型继承了文本-图像对的先验知识，因此有助于减轻对文本-视频对数据的要求。

然而，`LDM`的预训练自动编码器还存在一个问题，它只能看到图像而不能看到视频。

天真地使用它来生成视频可能会导致闪烁伪效，而没有良好的时间一致性。因此，视频 `LDM` 在解码器中添加了额外的时间层，并使用基于 3D 卷积构建的分片时间鉴别器对视频数据进行微调，而编码器保持不变，以便我们仍然可以重用预训练的 `LDM`。在时间解码器微调期间，冻结编码器独立处理视频中的每个帧，并使用视频感知鉴别器强制跨帧进行时间相干重建。

![](img/2795aced2a4e17c9246b9337692eb7e6.png)

与视频 `LDM` 类似，稳定视频扩散的架构设计也是基于 `LDM`，在每个空间卷积和注意力层之后插入时间层，但 `SVD` 对整个模型进行微调

> 训练视频 `LDM` 分为三个阶段：

+ 文本到图像的预训练很重要，有助于提高质量和提示跟随性
+ 视频预训练有利于分离，并且理想情况下应该在更大规模的精选数据集上进行
+ 高质量视频微调适用于具有高视觉保真度的较小的预字幕视频

`SVD` 特别强调数据集管理在模型性能中的关键作用

他们应用剪切检测管道来为每个视频获取更多剪切，然后应用三种不同的字幕生成器模型：

1. 用于中帧的 `CoCa`
2. 用于视频字幕的 `V-BLIP`
3. 基于前两个字幕的字幕

> 然后，他们能够继续改进视频数据集，方法是删除运动较少的剪辑（通过以 2 fps 计算的低光流分数进行过滤）、过多的文本存在（应用光学字符识别来识别具有大量文本的视频）或普遍较低的视频。

> 美学价值（使用 `CLIP` 嵌入注释每个剪辑的第一帧、中间帧和最后一帧，并计算美学分数和文本图像相似度）。实验表明，经过过滤的更高质量的数据集可以带来更好的模型质量，即使该数据集小得多

首先生成远处关键帧，然后添加时间超分辨率插值的关键挑战是如何保持高质量的时间一致性。`Lumiere`采用时空 `U-Net` (`STUNet`) 架构，通过一次传递一次性生成视频的整个时间持续时间，消除了对 `TSR`（时间超分辨率）的依赖成分。 `STUNet`在时间和空间维度上对视频进行下采样，因此昂贵的计算发生在紧凑的时空潜在空间中

### Training-Free Adaptation免训练适应

如果我们天真地随机采样一系列潜在代码，然后构建解码后的相应图像的视频，则无法保证对象和语义在时间上的一致性。

> `Text2Video-Zero`通过增强预训练的图像扩散模型来实现零镜头、免训练的视频生成，该模型具有两个关键的时间一致性机制：

+ 使用运动动力学对潜在代码序列进行采样，以保持全局场景和背景时间一致
+ 使用第一帧上每个帧的新跨帧注意力重新编程帧级自注意力，以保留前景对象的上下文、外观和身份

![](img/e8b6a07814340d2f335da4723198737f.png)

使用运动信息对潜在变量序列  进行采样的过程描述如下：

+ 定义一个方向  用于控制全局场景和相机运动；默认情况下，我们设置 `δ=(1,1)` 。还定义一个控制全局运动量的超参数 `λ>0` 。
+ 首先随机采样第一帧的潜在代码，
+ 使用预先训练的图像扩散模型执行  向后更新步骤，例如论文中的稳定扩散（`SD`）模型，并获得相应的潜在代码 其中
+ 对于潜在代码序列中的每一帧，我们通过  定义的扭曲操作应用相应的运动平移以获得
+ 最后对所有  应用 `DDIM` 前向步骤以获得

![](img/46ebe09648508dc5de680dad35189b05.png)

> `ControlVideo`旨在生成以文本提示 `τ` 和运动序列（例如深度或边缘图） 为条件的视频。它改编自`ControlNet`，添加了三个新机制：

1. 跨框架注意力

> 在自注意力模块中添加完全跨框架交互。它通过将所有时间步长的潜在帧映射到  , ,  矩阵来引入所有帧之间的交互，这与 `Text2Video-zero` 不同，`Text2Video-zero` 仅配置所有帧以关注第一帧。

2. 交错帧平滑器是一种在交替帧上采用帧插值来减少闪烁效果的机制

> 在每个时间步 `t` ，平滑器都会对偶数或奇数帧进行插值，以平滑其相应的三帧剪辑。请注意，平滑步骤后帧数会随着时间的推移而减少。

3. 分层采样器利用分层采样器来实现在内存限制下具有时间一致性的长视频

> 一个长视频被分割成多个短片，每个短片都选择一个关键帧。该模型预先生成这些具有完全跨帧注意力的关键帧，以实现长期一致性，并且每个相应的短片都是根据关键帧顺序合成的。
