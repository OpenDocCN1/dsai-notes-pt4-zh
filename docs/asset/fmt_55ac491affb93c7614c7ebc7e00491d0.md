
# 第1章 风云人物

宋霜序坐在飞机的经济舱里，望着窗外渐渐接近的城市轮廓。
燕城，五年了，这座城市在她记忆中，早已褪去了年少时的青涩滤镜，如今，只剩下略显模糊的轮廓，像一幅年代久远的油画，蒙上了一层薄薄的尘埃。
可即便如此，当它再次真实地出现在眼前时，她心中还是涌起一种说不清道不明的情绪，像是久别重逢的亲切，又像是即将揭开伤疤的不安，两种感觉交织在一起，让她心头微微一颤。
舱内的广播响起，甜美的女声提醒乘客系好安全带，飞机即将降落。
安全带的卡扣声“咔哒”一声，仿佛是命运的齿轮开始转动，将她拉回现实。
她轻轻叹了口气，合上手中的书本——那本被翻得有些卷边的《百年孤独》。
书页间夹着一张泛黄的书签，上面是她和舒扬的合影，照片里的两个女孩笑靥如花，青春洋溢。
如今，物是人非，舒扬病重，而她也早已不是当年那个天真烂漫的少女了。
下了飞机，宋霜序步履匆匆地走出机场，夜晚的凉风拂过脸颊，带来一丝燕城的秋意。
虽然已是夜晚，但燕城的灯火依旧璀璨夺目，像一颗颗闪耀的星辰，散落在城市的每一个角落。
街道上车水马龙，喇叭声、引擎声交织在一起，充满了生机与活力，与她记忆中的那个宁静小城截然不同。
她伸手拦下一辆出租车，司机是一位中年男人，他热情地打招呼：“小姐，要去哪儿？”。
“去第三医院。”宋霜序回答道，语气中带着一丝急切，她甚至没有心思去和司机寒暄，只想尽快见到舒扬。
车子启动后，她靠在座椅上，闭上双眼。
脑海中浮现出学姐舒扬那张温暖而坚定的脸庞，以及她在电话中透露出的虚弱声音。
几天前，那个深夜，电话铃声突兀地响起，打破了夜晚的宁静。
舒扬的声音从听筒里传来，虚弱得让她几乎不敢相信自己的耳朵。
舒扬告诉她自己生病了，而且病得很重，语气中带着一种令人心碎的平静。
这个消息如同晴天霹雳，让宋霜序心中充满了担忧和不安。
她恨不得立刻飞回燕城，陪在舒扬身边。
五年了，她们之间联系不多，但那份深厚的友情却从未改变。

与此同时，在燕城名流圈内，一则关于“飞雪创新科技CEO回国探望学姐”的消息迅速传开，引发众多关注与猜测。
有人认为这是商业合作信号，也有人揣测其中隐藏更深层次意义……各种流言蜚语，像长了翅膀一样，在燕城的上空飞舞。
另一边厢，当沈聿接到妹妹回国消息时，他正在办公室处理文件。
放下电话后，他微微皱眉：为何没有提前告知？难道是发生了什么事？他心中隐隐有些不安。
岳子封见状调侃道：“怎么？你那宝贝妹妹回来了，你不高兴啊？要不要请她吃饭？毕竟你们兄妹感情那么好。”
“不用了，”沈聿摇摇头，语气冷淡，“她应该有自己的安排。”
虽然嘴上这么说，但他内心深处，还是忍不住对妹妹表示关心，并主动拨通电话询问情况。
在简短交流后，两人约定见面时间地点，以便更详细了解彼此近况及未来计划……
夜幕降临时分，当宋霜序准备离开医院之际，却意外发现司机已等候多时。
正当她松口气准备上车时，却猛然察觉到车内竟然坐着一个神秘男人！他是谁？为何会出现在这里？这背后究竟隐藏什么秘密？
未等细想清楚，那神秘男人已缓缓抬头，用低沉而磁性的嗓音说道：“你好……我们终于见面了。”

## 微调版（字数2828），一次性生成未润色

宋霜序站在机场出口，深吸了一口熟悉的空气。
燕城的秋风带着一丝凉意，裹挟着城市特有的气息，轻拂过她的脸庞，让她感到一阵久违的亲切。
五年，整整五年了，她终于踏上了这片熟悉的土地。
五年时间，足以改变很多事情，也足以让一个人脱胎换骨。
她从一个青涩的留学生，一步步成长为一家科技公司的CEO，肩负着责任和压力，在异国他乡打拼出一片天地。
然而，无论走到哪里，她的心始终牵挂着这片土地，牵挂着这里的人，尤其是那个躺在病床上的人——她的学姐，舒扬。
手机铃声突兀地响起，打破了宋霜序的思绪。是司机打来的。
“宋总，您现在方便接电话吗？”司机的声音恭敬而谨慎，带着一丝小心翼翼的试探。
“方便。”宋霜序的声音平静而坚定，带着上位者的沉稳和果断。
“宋总，请问您现在在哪里？我去接您。”
“我已经出来了，麻烦你直接去第三医院。”
宋霜序语气中带着一丝不易察觉的急切，但她依旧保持着惯有的冷静，仿佛任何事情都无法扰乱她的心绪。
挂断电话，宋霜序坐上那辆熟悉的黑色豪华轿车，隔着车窗，目光落在窗外熟悉的街景上。
高楼林立，车水马龙，一切都是那么熟悉，却又透着一丝陌生。
五年时间，燕城也发生了巨大的变化，变得更加繁华，更加现代化。而她，也早已不是五年前那个懵懂的女孩。
车窗外的景色渐渐模糊，宋霜序的思绪飘回到了几天前。
那天，她收到了舒扬的短信，短短几行字，却如同一道惊雷，在她平静的心湖中掀起滔天巨浪：“霜序，我病了，你回来一趟吧。”
舒扬，那个在她生命中留下浓墨重彩一笔的女人，那个曾经陪她走过青春岁月，分享喜怒哀乐的挚友，如今却躺在病床上，与病魔抗争。

“你是谁？”宋霜序的声音冷，眼神中闪过一丝警惕。
男人微微一笑，眼神中带一丝戏谑，“霜序，好久不见，你还是这么漂亮。”
宋霜序的心中一紧，她认出了这个男人——贺庭洲。她的心中涌起一股愤怒，但表面却依然保持冷静，“贺庭洲，你在这里做什么？”
贺庭洲微微一笑，眼神中带着一丝玩味，“霜序，你回国了，难道不想见见我吗？”
宋霜序冷冷地看了他一眼，没有回答。她知道，贺庭洲的到来意味着今晚的饭局将会变得更加复杂。
然而，她的心中却充满了坚定。无论前方有多少困难，她都不会退缩。
续前行，夜色渐浓，城市的灯火在车窗外闪烁。
宋霜序的心中充满了复杂的情绪，但她知道，她已经做好了迎接一切挑战的准备。
