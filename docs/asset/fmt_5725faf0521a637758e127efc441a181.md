
# 催收电话合规

> 来源：[https://docs.feishu.cn/docx/MCb3drovIoxbUjxAuFjc5Ckpnwe](https://docs.feishu.cn/docx/MCb3drovIoxbUjxAuFjc5Ckpnwe)

- 问：大家怎么看这个案例？[“催收”短信不能乱发！技术公司未经借款人同意向其亲友发送“催收”短信被判侵权](https://mp.weixin.qq.com/s?__biz=MzU1NDk0NjE3MA==&mid=2247507273&idx=1&sn=e18dffb75b1edc24705b097601eb2d71&scene=21#wechat_redirect)

- 答1：所以，以后是不是要新增一个紧急联系号码相关授权条款，让借款人同意贷款公司可以在催收等场景下将紧急联系号码提供第三方，用于发送信息。

- 答2：紧急联系人一般只是触达，辅助联系，不能有催收那味道。

- 答3：判决书原文“被告未经原告同意，也未向业务合作相对方核实或审查原告本人是否同意，直接向原告亲友发送两条包含原告贷款逾期内容的短信，造成原告私密信息泄露”。按照个保法，是不是也要向紧急联系人确认呢，您是否同意我们在XX逾期或无法联系的时候，联系您？

- 答4：这里其实有两个点：

1. 提供紧急联系人电话，是否需要紧急联系人同意，甚至单独同意；
2. 将违约信息告知紧急联系人，是否需要债务人同意，如果需要，必然不同意，咋整。

- 答5：关于第一个点，我认为很有必要性。对于银行方来说，要确保紧急联系人跟办卡人确实有关系；对于紧急联系人来说，更是需要知道且同意自己被作为某人的紧急联系人。

- 答6：第二点感觉前面说的加个条款可行吧，第一点紧急联系人怎么同意比较难。

- 答7：紧急联系人电话是否可以强制要求填写，不填写无法开通贷款服务？

- 答8：合规成本好高，是写在合同里面就行”应取得紧急联人的同意“，还是必须核查单独同意函嘞。

- 答9：从控制措施设置考虑，是否应该要区分是否有亲属关系？即，如果能提供户口本等证明与紧急联系人存在亲属关系，则无需单独同意；如果非亲属关系，那我认为进行单独验证很有必要。

- 答10：第一点，反过来看，不遵守能有什么有效的罚则呢。一个自然人，都到了借高利贷的地步了。

- 答11：严重低估了一部分借款人薅羊毛的强烈意愿，一旦有任何不合规催收行为，他们都会组织投诉，分享经验。

- 答12：对于容易成为债务人的人群，很容易有诚信问题，这个随便得来的电话是常事。对银行来说，这不光是个人信息保护合规问题，更是一个坏账风控的问题。

- 答13：之前了解到一个案件，某行的外包催收公司，被投诉了，赔了50个达不溜。

- 答14：分享一类实操经验：

1. 授信阶段由借款人提供留联系方式，如果进入催收流程，借款人（债务人）失联（各家量化情况不同）后联系紧急联系人，告知紧急联系人获取方式及原因。如紧急联系人表示不要再联系，催收系统内会进行标记不再外呼。
2. 同上，借款人在申请时（应当）知悉填写紧急联系人的原因和用途。实践中可以不提供（基于35273监管提出的要求），但在授信系统中往往做了拒贷的逻辑，“借款人”也就不会成为“债务人”了。

- 答15：第三方公司是提供短信通道服务的，给谁发送短信、发送什么内容，都是小贷公司直接决定的，没理解为啥要第三方公司承担责任。

- 答16：我可以解释一下，因为很多第三方公司的卖点就是处理不良资产，全权背锅。

- 答17：实际中催员真的这么合规吗，不太敢相信。估计刚说我是谁谁谁，谁给了信息让我干什么就被挂电话了。

- 答18：很合规的，都很文明礼貌的，我处理过相关的案子，所有涉诉催收录音我都听了，感觉催收员的素质比我高，骂不还嘴的那种。

- 答19：讨论一下，验证码可行吗？（整理者注：好主意！）

- 答20：才认真看了下，是基于隐私权而非个人信息保护去判的，有意思。业务为大，小锅背了也就背了。“紧急联系人”是用来找人的，直接发欠款信息给亲戚，是有点超了。

- 答21：大家看下商业银行法和贷款通则，是否贷款 是否放款 那可是银行自己说了算的。不提供那还得了，贷后失联怎么做。只不过外呼不要直接涉及账户信息和交易信息。

总结：个人认为紧急联系人电话号码验证码，并在验证码短信中做好告知是比较好落实紧急联系人同意的方式。至于借款人的同意，可以揉在贷款合同里面。毕竟机构都是要赚钱的。
