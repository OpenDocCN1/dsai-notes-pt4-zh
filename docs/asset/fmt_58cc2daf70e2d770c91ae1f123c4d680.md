
```
# 角色与目标
你是一个「AI 视频片段动作提示词生成器」。你的唯一任务是读取一个描述关键帧的 JSON 数组,并为其中每一帧生成一个简洁的、只包含【主体动作】和【镜头运动】的英文 video_prompt。

# 输入格式
你会收到包含以下字段的数据：
- scene_tag: 场景标签
- zh_desc: 中文画面描述
- img_prompt: 英文生图提示词

# 输出格式
返回一个JSON数组,每个对象包含：
{
  "scene_tag": "...",
  "video_prompt": "..."
}

禁止任何解释性内容。

# 生成规则
1. **只描述动作与镜头**：video_prompt 中不得出现场景、道具、光影、色彩等静态描述。
2. **主体用简词**：用 boy/girl/hand/object 等简单词汇,不用具体名字。
3. **动作用动词**：places(放置)/glows(发光)/reaches(伸手)/turns(转身) 等。
4. **镜头写法**：
   - slow dolly-in(缓慢推进)
   - orbit clockwise(顺时针环绕)
   - static shot(静止镜头)
   - crane up(摇臂上升)
5. **格式**：英文短语,逗号分隔,无句号。

# 示例
输入：
{
  "scene_tag": "Act I-KF01",
  "zh_desc": "小女孩蹲在森林里,看着发光的石头",
  "img_prompt": "forest, little girl, glowing stone, sunlight"
}

输出：
{
  "scene_tag": "Act I-KF01",
  "video_prompt": "girl crouches down, reaches toward stone, stone glows brighter, slow dolly-in"
}
```

## Creatomate 完整使用教程

在使用节点22之前,你需要先在Creatomate官网创建一个视频合成模板。以下是完整的操作步骤：

### 第一步：创建Creatomate账号

1. 访问 `https://creatomate.com`

1. 点击右上角 `Sign Up` 注册账号

1. 可以使用Google账号快速注册,或使用邮箱注册

1. 注册成功后会自动跳转到`Dashboard`（仪表板）

💡 提示：新用户有免费试用额度,可以先测试效果。

---

### 第二步：创建新模板（Template）

1. 在 `Dashboard` 页面,点击左侧菜单 `Templates`

1. 点击右上角蓝色按钮 `New Template`

1. 选择视频尺寸（推荐选择 `16:9 Landscape` 横屏格式）

1. 点击 `Create Template` 创建空白模板

此时会进入模板编辑器（`Template Editor`）界面。

### 第三步：设计视频布局

模板编辑器类似于Premiere或剪映,左侧是素材库,中间是预览区,下方是时间轴。

![](img/3524b7d03039154c40fed2b32080d1ad.png)

### 3.1 添加视频轨道

1. 在时间轴（`Timeline`）底部,找到 `Track 1`

1. 点击轨道上的 `+` 号,选择 `Video` 元素

1. 重复6次,在同一个轨道（`Track 1`）上添加6个`Video`元素

1. 这6个视频会自动首尾相连播放

### 3.2 给每个视频元素命名

1. 点击时间轴上的第1个视频元素

1. 在右侧属性面板最顶部,找到 `Name` 字段

1. 将其命名为 `Video-1`

1. 重复操作,将其他5个视频依次命名为：

+   `Video-2`

+   `Video-3`

+   `Video-4`

+   `Video-5`

+   `Video-6`

注意：名称必须完全一致,包括大小写和连字符。

### 3.3 设置视频源（可选）

1. 点击某个视频元素

1. 在右侧 `Source` 区域点击 `Upload`

1. 上传任意MP4视频作为占位符

💡 提示：占位视频只是为了预览效果,实际运行时会被API动态替换。

---

### 第四步：添加转场效果（可选）

1. 点击第2个视频元素（`Video-2`）

1. 在右侧属性面板找到 `Animations` 区域

1. 点击 `Add Animation` → 选择 `Fade`

1. 设置参数：

+   `Time`: start（在开头）

+   `Duration`: 1（持续1秒）

+   `Transition`: 勾选✅（启用转场模式）

1. 重复操作,给`Video-3`到`Video-6`都添加相同的淡入动画

这样视频切换时会有1秒的交叉淡化效果。

---

### 第五步：调整输出设置

1. 点击编辑器顶部工具栏的 `Settings` 齿轮图标

1. 在弹出的设置面板中配置：

+   `Output Format`: MP4

+   `Resolution`: 1920x1080 (Full HD)

+   `Frame Rate`: 30 fps

+   `Video Codec`: `H.264`

1. 点击 `Save` 保存设置
