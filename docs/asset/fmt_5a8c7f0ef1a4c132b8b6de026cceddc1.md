
# 普通程序员想往 LLM 方向发展，该怎么转型呢？

> 来源：`https://qianniucity.feishu.cn/docx/VjEeduNNjoYyFCx6pspc22sOnVh`

## 问题

问：如果是在国内普通做后端 Java 开发的程序员，想往 LLM 方向发展，该怎么转型呢？

## 回答

答：往 LLM 转方向没有想象中那么复杂。关键是两点：第一，有这个念头；第二，付诸行动。只要行动起来，还能迅速得到正反馈，这样自驱力也更强。而获得正反馈并不困难，完全可以小步快跑，同时避免“不小心”花冤枉钱报几千块的课程。我总结了一些实用建议，按照这个思路去实践，一定能收获正反馈。

## 学习方法

如果你要开始学和 LLM 有关的方向，我的方法是“以 AI 编程为切入点，再逐步深化 LLM 方向”。简单来说，先充分利用 AI 辅助工具做编程，可以借此快速入门；另一方面，AI 编程能显著提高效率，同时出问题时还能随时向 AI 提问，边学边提升。

## 具体建议

1. **利用 AI 编程工具开始动手:** 你可以先注册一个 Cursor 账号，用它试试看，两周的免费体验完全 0 成本。这段时间，用它不断地生成代码、交流复杂的 Prompt（提示词），做代码自动补全甚至简单的逻辑规则设定，不断探究它哪些“行”，哪些“不行”。直接从上手实测入手，你能逐步了解 LLM 的核心价值。

2. **用 AI 编程开展一个 LLM 相关的 Side Project:** 本职工作中的开发内容大概率天花板较高，不一定立刻用上这些新技术，但没关系，你可以发展一个兴趣类的 Side Project（成长平台）。例如目标明确，做翻译小工具、文档问答或 AI 聊天机器人类的轻量原型都是不错的切入口。同样，以前本就复杂的事，上手 AI 编程后能明显适配业务；而 Side Project 和实践最快让你入门，积累成就感。

3. **把 AI 当私人导师:** 在写代码或做项目开发时，遇到任何知识点卡瓶，问 AI，请它具体解释，或者利用它补注释、逐帧`debug`。“工具 + 老师”的方式双重辅佐，你不仅学知识更高效，还实时掌握新语言背后的思考方式。

通过实战加深理解，这时正反馈积累得会很快。从工具上手到开发切入点清晰，你很快能够在“LLM 高阶开发”过渡期脱离 Java 开发者的传统当前，不局限于现有语言或固定业务能力积累。

## 总结

总而言之，记住“三件事”——立刻实践、及时反馈、不间断演进。只要全程让 AI 如影随形，一路推进，定能把握 LLM 流程化应用的解决关键路径！

行动大于一切，向前推进，沉浸后自然超越！
