## 神经网络如何建模？

+ 人工神经网络是以生物神经元为模型的
+ 生物神经元的连接被建模为权重
+ 正权重反映兴奋性连接，而负值表示抑制性连接
+ 所有输入都经过权重修改并求和。此活动称为线性组合
+ 最后，激活函数控制输出的幅度。例如，可接受的输出范围通常在 0 到 1 之间，也可以是 -1 到 1 之间

## 什么是感知器？

+ 感知器是神经网络的基本单元，也是单层神经网络
+ 感知器是一个线性分类器。由于它使用已经标记的数据点，因此它是一种监督学习算法
+ 激活函数应用步进规则（将数值输出转换为 +1 或 -1）来检查加权函数的输出是否大于零

## 如果您想将电子邮件分类为垃圾邮件或正常邮件，则输出层需要多少个神经元？

要将电子邮件分类为垃圾邮件或普通邮件，只需要在神经网络的输出层中有一个神经元

> 例如，为了指示电子邮件是垃圾邮件的概率，您通常会在估计概率时在输出层中使用逻辑激活函数

## 什么是神经网络？

+ 神经网络是由人工神经元或节点组成的神经元网络或电路
+ 神经网络既可以是生物神经网络，也可以是人工神经网络。人工神经网络是用于解决人工智能问题的网络
+ 人工网络可用于预测建模、自适应控制和可通过数据集进行训练的应用。网络内可进行基于经验的自学习，从而从一组复杂且看似不相关的信息中得出结论

## 神经网络如何获得最佳权重和偏差值？

+ 神经网络通过误差梯度获得最佳权重和偏差值
+ 要决定是否增加或减少当前权重和偏差，需要将其与最佳值进行比较
+ 这是通过权重和偏差的误差梯度找到的：

![](img/703a931bd3bd944f4d4fb4b21027c0df.png)

+ 梯度值是通过一种称为反向传播的选定算法来计算的
+ 优化算法利用梯度来改善权重值和偏差

## 神经网络中的损失函数是什么？

+ 神经网络在设计和配置模型时需要选择一个损失函数
+ 在优化模型时，目标函数要么是损失函数，要么是其负函数。目标函数被寻求最大化或最小化（分别输出具有最高或最低分数的输出）。通常，在神经网络中，误差应该最小化
+ 损失函数应该将复杂模型的所有方面简化为单个标量值，以便对候选解决方案进行排序和比较
+ 设计师选择的损失函数应该捕捉问题的属性，并受到对项目重要的关注点的驱动

## 什么是激活函数？

+ 激活函数应用步进规则（将数值输出转换为 +1 或 -1）来检查加权函数的输出是否大于零
+ 节点的激活函数定义了在给定节点的一个输入或一组输入的情况下节点的输出
+ 激活函数可以分为三类：
  + 岭函数
  + 径向函数
  + 折叠函数

## 激活函数的作用是什么？

+ 激活函数有助于将神经元的输出值按照要求限制在一定限度内。如果未设置限度，则输出将达到非常高的幅度。大多数激活函数将输出转换为 -1 到 1 或 0 到 1
+ 激活函数最重要的作用是能够为神经网络添加非线性。现实生活中的大多数模型都是非线性的，因此激活函数有助于创建非线性模型
+ 激活函数负责决定是否应该激活神经元

## 前向传播和后向传播有什么区别？

+ 前向传播是指输入数据在网络中向前传播。每个隐藏层接受输入数据，根据激活函数进行处理，然后将其传递给后续层
+ 反向传播是根据前一个时期获得的错误率对神经网络权重进行微调的做法。适当调整权重可确保较低的错误率，从而使模型更加可靠

## 说出一些神经网络的应用？

> ANN 的一些应用包括：

+ 系统识别与控制：车辆控制、轨迹预测
+ 医学诊断：识别癌症，仅使用细胞形状信息区分高度侵袭性的癌细胞系和侵袭性较低的癌细胞系

+ 地球科学：水文学、海洋建模、海岸工程、地貌学
+ 网络安全：区分合法活动和恶意活动

## 神经网络如何实现无监督？

神经网络用于无监督学习，以学习输入数据的更好表示。

> 神经网络可以学习从文档到实值向量的映射，这样对于内容相似的文档，生成的向量也相似。这可以使用自动编码器来实现，自动编码器是一种经过训练的模型，可以使用重构误差作为成本函数，从较小的表示中重构原始向量。

还有一些专门为聚类而设计的神经网络

最广为人知的是自组织映射 (SOM)

## 深度学习和人工神经网络有什么区别？

+ 当研究人员开始创建大型人工神经网络时，他们开始使用“深度”这个词来指代它们
+ 随着深度学习这个术语开始被使用，人们普遍理解它代表深度人工神经网络，而不是浅层人工神经网络
+ 深度人工神经网络和深度学习通常是同一回事，并且大多互换使用

## 什么是自组织映射？

+ 自组织映射 (SOM) 是一类自组织聚类技术。
+ 它是一种无监督形式的人工神经网络。自组织映射由一组排列成矩形或六边形网格的神经元组成。网格中的每个神经元单元都与一个固定维数的数值向量相关联。自组织映射的学习过程涉及调整这些向量以提供输入数据的合适表示
+ 自组织映射可用于对矢量格式的数值数据进行聚类

## CNN如何用于时间序列预测？

+ CNN能够学习并自动从原始输入数据中提取特征，这一能力可以应用于时间序列预测问题。可以将一系列观察结果视为一维图像，CNN 模型可以读取该图像并将其提炼为最显著的元素
+ CNN的能力已在时间序列分类任务中得到充分证明，例如基于来自健身设备和智能手机的原始加速器传感器数据自动检测人类活动
+ CNN支持多变量输入、多变量输出，可以学习任意但复杂的函数关系，但不需要模型直接从滞后观测中学习。相反，模型可以从与预测问题最相关的大型输入序列中学习表示

## 如果 MLP 过度拟合训练数据，您如何调整这些超参数来尝试解决问题？

你可以在基本 MLP 中调整的超参数包括：

+ 隐藏层的数量
+ 每个隐藏层的神经元数量
+ 每个隐藏层都使用激活函数，其中 `ReLU` 函数是一个很好的默认函数
+ 输出层，一般来说，对于二元分类你会需要逻辑激活函数，对于多类分类你会需要 `softmax` 激活函数，对于回归你不需要激活函数

> 如果 MLP 过度拟合训练数据，您可以尝试减少隐藏层的数量并减少每个隐藏层的神经元数量。

## 卷积神经网络（CNN）和循环神经网络（RNN）之间有什么区别，以及在哪些情况下应该使用它们？

> 卷积神经网络在将数据用于全连接层之前，会先对数据进行卷积：

+ 它们最适合用于需要位置不变性的情况，也就是说，无论特征在输入样本中的什么位置，您都希望捕获它们
+ 想象一下，一张有各种动物的图片。如果你使用卷积神经网络来判断图片中是否有猫，那么无论猫在图片中的哪个位置（顶部、底部、左侧或右侧），它都会识别出这只猫。这对于图像分类非常有用

> 循环神经网络是保持输入样本间状态的神经网络。它们会记住之前的输入样本，并利用这些样本对当前输入样本进行分类：

+ 当数据的顺序很重要时，它们最有用。例如在语音（前面的单词有助于识别当前单词）、视频（帧是有序的）以及文本处理中
+ 一般来说，与时间序列数据（带有时间戳的数据）相关的问题很适合用循环神经网络来解决

## 什么是反向传播以及它是如何工作的？

+ 反向传播是一种用于训练人工神经网络的技术
+ 它首先计算关于每个模型参数（所有权重和偏差）的成本函数的梯度
+ 接下来，它使用上一步的梯度执行梯度下降步骤。此反向传播步骤通常使用许多训练批次执行数千或数百万次，直到模型参数收敛到（希望）最小化成本函数的值
+ 为了计算梯度，反向传播使用反向模式自动微分：
  + 它首先沿正向（即从输入到输出）遍历图形，以计算当前训练批次的每个节点的值
  + 然后它进行第二遍，这次是反向（即从输出到输入），一次计算所有梯度

## 如何知道你的模型是否受到梯度消失问题的影响？

+ 模型在训练阶段会改进得非常慢，并且训练也有可能很早就停止，这意味着任何进一步的训练都无法改善模型
+ 更接近模型输出层的权重将经历更大的变化，而更接近输入层的层不会发生太大变化（如果有的话）
+ 在训练模型时，模型权重呈指数缩小并变得非常小
+ 模型权重进入 0 训练阶段

## 如何知道你的模型是否正在遭受梯度爆炸的问题？

> 有一些细微的迹象表明你在网络训练期间可能遭受梯度爆炸，例如：

+ 该模型无法利用您的训练数据（例如损失不佳）
+ 模型不稳定，导致每次更新时的损失变化很大
+ 模型损失 `NaN` 在训练期间发生

> 如果你遇到了这些类型的问题，你可以深入挖掘一下，看看是否存在梯度爆炸的问题。你可以使用一些不太明显的迹象来确认是否存在梯度爆炸：

+ 在训练过程中，模型权重很快变得非常大
+ 模型权重在训练期间变为 `NaN` 值
+ 1.0 在训练期间，每个节点和层的误差梯度值始终高于该值

## 如何在 PyTorch 中定义神经网络模型？

> 在 PyTorch 中定义神经网络的基本步骤是：

1. 定义架构并初始化神经网络：此步骤涉及定义一个扩展类的类 `Module`。在此类上，我们定义模型元素，例如线性层、正则化层、激活函数等
1. 定义前馈算法：前馈算法将被封装在 `forward` 函数中，其目标是将输入数据传递到计算图（即我们的神经网络）中
1. 最后一步，您可以通过实例化模型并传递数据来测试模型

```
# Step 1: Model definition
class Net(nn.Module):
    # Define model elements
    def __init__(self, n_inputs):
        super(Net, self).__init__()
        self.layer = Linear(n_inputs, 1)
        self.activation = Sigmoid()

# Step 2: Forward propagate input
def forward(self, X):
    X = self.layer(X)
    X = self.activation(X)
    return X

# Step 3: Test model
my_nn = Net()
result = my_nn(some_data)
print(result)
```

## forward() 和 backward() 在 PyTorch 中有什么区别？

+ 在 PyTorch 中，`forward()` 方法用于计算神经网络模型的前向传递，它定义了模型从输入到输出的运行方式
+ `backward` 函数计算当前张量相对于某个标量值的梯度。在神经网络模型环境中，`backward()` 计算模型参数相对于给定损失函数的梯度

总结一下：`forward()` 方法指定了模型的运行方式，而 `backward()` 方法计算了用于优化模型参数的梯度
