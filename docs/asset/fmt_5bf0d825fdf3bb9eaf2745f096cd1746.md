## 为什么选择 NextJS 作为自己最主要的技术平台？

NextJS作为最热门的全栈web平台，生态环境是最好的，几乎所有的上下游都有其配套资源。我们是技术小白，没有那么多时间精力去追过于新的技术框架，一招鲜是最好的。无论是建站还是web App，用 Next 一把梭就对了。

### 从哪儿开始？

今天和群友讨论从哪儿开始学习web技术？从 HTML + CSS 开始，还是从 JS 开始？还是从React/Vue开始？

从我个人学习的经历来看，我是比较传统地从前端三件套出发的。从无JS的网页，到用 HTML + CSS + JS 响应式静态网站这样一路学来的。

但我从React就只是看了一点概念，没有上手写项目。然后就开始高频使用 Cursor + NextJS 来构建项目了。虽然都是一些小项目、以前端为主的，但是已经让我上手有些感觉了，什么是web App，全栈了。

所以我建议学web App开发的小伙伴，可以以NextJS为核心来学习web App开发，HTML + CSS，JS，React这些前置知识可以碰到问题再去看文档、问Cursor，而不用按部就班来学。尤其是JS，很多技术内容我们在开发web App时未必用得上
