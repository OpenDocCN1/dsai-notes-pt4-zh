## 13.2 如何沉淀知识为可复用文档

### 记录示例

问题：如何使用 Claude Code 生成高质量的产品文案

记录：

```
# 使用 Claude Code 生成产品文案

## 问题描述
需要生成高质量的产品文案，要求突出产品卖点，吸引目标用户。

## 解决方案

### 步骤 1：准备产品信息
- 产品名称
- 主要特点（至少3个）
- 目标用户
- 文案风格
- 字数要求

### 步骤 2：使用提示词模板
```

> 请帮我生成产品文案：

> 产品信息：

+   产品名称：[产品名称]

+   主要特点：[特点1]、[特点2]、[特点3]

+   目标用户：[目标用户]

```

### 步骤 3：生成文案
- 上传产品信息
- 使用提示词模板
- 生成文案

### 步骤 4：人工审核
- 审核文案内容
- 调整不准确的内容
- 优化表达方式

### 步骤 5：保存结果
- 保存最终文案
- 记录使用反馈
- 总结经验教训

### 关键步骤
- 步骤 2：提示词模板是关键
- 步骤 4：人工审核保证质量

### 注意事项
- 产品信息要准确完整
- 提示词要清晰明确
- 人工审核不能省略
- 要记录使用反馈

### 结果验证
- 生成的文案质量高
- 符合产品特点
- 吸引目标用户
- 包含行动号召

### 编写清晰的操作指南

主题：如何使用 Claude Code 生成会议纪要

操作指南：

```
# 使用 Claude Code 生成会议纪要

## 目标
快速生成高质量的会议纪要，节省整理时间。

## 前提条件
- 已安装 Claude Code
- 有会议录音或记录
- 熟悉 Claude Code 基本操作

## 操作步骤

### 步骤 1：准备会议记录
1. 录制会议或记录会议要点
2. 整理会议记录，确保完整
3. 保存为文本文件

### 步骤 2：上传会议记录
1. 打开 Claude Code
2. 点击上传文件按钮
3. 选择会议记录文件
4. 确认上传成功

### 步骤 3：生成会议纪要
使用以下提示词：
```

请帮我根据会议记录生成会议纪要：

会议记录：

[粘贴会议记录]

会议纪要要求：

1.  提取会议要点

1.  整理决议事项

1.  列出待办事项（包括负责人和截止日期）

1.  包含下次会议安排

1.  格式规范，结构清晰

```

#### 步骤 4：审核会议纪要
1. 检查会议纪要的完整性
2. 核对关键信息的准确性
3. 调整不准确的内容
4. 补充遗漏的信息

#### 步骤 5：发送会议纪要
1. 保存最终版本
2. 发送给参会人员
3. 保存会议纪要存档

#### 注意事项
- 会议记录要完整准确
- 提示词要清晰明确
- 人工审核不能省略
- 要及时发送会议纪要

### 常见问题

Q：会议纪要不准确怎么办？
A：人工审核时调整不准确的内容，补充遗漏的信息。

Q：如何提高会议纪要的质量？
A：提供更完整的会议记录，优化提示词。

#### 案例保存示例

案例：使用 Claude Code 优化产品文案

案例描述：

需要为智能手表生成产品文案，第一次生成的文案不够吸引人，需要优化。

问题分析：

+   第一次提示词不够具体

+   没有明确目标用户

+   没有明确风格要求

优化提示词，增加具体要求：

```
请帮我生成产品文案：

产品信息：
- 产品名称：智能手表
- 主要特点：健康监测、运动追踪、消息提醒
- 目标用户：年轻白领

文案要求：
1. 突出产品的核心卖点
2. 语言生动有趣，吸引年轻白领
3. 字数在 200 字左右
4. 风格要求：时尚现代
5. 包含行动号召
```

+   生成的文案质量显著提升

+   更符合目标用户需求

+   包含明确的行动号召
