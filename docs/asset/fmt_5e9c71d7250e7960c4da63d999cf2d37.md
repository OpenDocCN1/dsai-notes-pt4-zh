## 系统和软件初始化过程

### 操作系统

之前经过确认`Windows`跑`LLM`没有问题，我也乐得就用它，为了图省事，组装硬件的时候就让小伙帮我做好系统，结果呢，小伙用的映像是一个什么电脑店的系统，第一次开机在没有联网的情况下就给我咣咣咣地装了七八个名字看上去很熟的不靠谱的软件，小伙倒是帮我把这些软件都删除了，当时我有点犹豫要不要铲了重装，后来看了看自启动的服务，然后用`OS`自带的防病毒软件扫了一下，似乎还比较干净，就抱着侥幸心理由他去。然后就狠狠填补了一下职业生涯的重大空白——在我基本把驱动软件和网络环境折腾好，按照最佳安全实践，给`administrator`账号改名并禁用之后，系统再也无法登录了，人生第一次出现这种情况，挣扎着尝试修复了五分钟，放弃，用微软原厂的方法烧了一个纯净的`USB`安装介质，含泪铲掉重装。

### 主板驱动

这次配的机箱叫海景房，就是机箱有两面玻璃，里面一共九把风扇加上显卡 水冷和内存的灯带，可以在主板协调下发出绚烂的光污染，我年纪大了，对这个是排斥的，我希望最好不要有灯，看着闹心，小伙说现在就是这风气，硬件都有灯，可以用软件关掉。所以系统装好之后，第一时间赶紧装主板驱动程序，找到相关功能，把风扇和内存的灯关掉，显卡的灯没找到关的地方，好在它也比较低调，算了不关也行。结果，今天我又经历了第二次反转，到了下午差不多一切就绪，我准备在朋友圈给大家得瑟下，结果风扇的灯再也点不亮了。

### 部署Docker环境

+ 安装`hyper-v`

+ 安装`WSL`，这里有个细节需要注意，要启用`Windows 更新 > 高级设置 > 接受其他Microsoft产品的更新`这个选项，否则如果仅从Microsoft Store下载`Ubuntu 22.04` 是无法启用`WSL`的。（这是今天唯一的知识点收获）

+ 安装 `Windows Docker Desktop`，其实直接在`WSL`用命令行安装`docker`也可以，但是并不是推荐的做法，为了避免后续可能的坑，还是服从最佳实践吧。

### 网络设置

+ 和之前预想稍微有出入，这个主板没有带`WiFi`，所以还得用网线连接。

+ 无缝连接国际互联网，这是一个很高级的操作过程，简单来说是用`hyper-v`在本机运行一个软路由，细节不展开了，也请大家不要追究。
