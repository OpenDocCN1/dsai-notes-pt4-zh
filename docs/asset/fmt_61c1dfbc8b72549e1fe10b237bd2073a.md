# 方法论

**用 AI** 创作的核心原则是：“不要让 AI 代替你思考，而是让 AI 激发你思考。”

正确的做法应该是，希望你能自己先开始创作，创作遇到瓶颈时，再让 AI 出马。

+ 让他生成一些内容，启发你

+ 让AI扮演读者提问激发灵感
