
# 3D 模型质量与文件格式

## 模型质量等级

+ `low` ≈5000：低面数，可能用于移动端或低性能设备。
+ `med` ≈18000：中等面数，平衡细节和性能，适用于 PC 或主机游戏。
+ `high` ≈30000：高面数，适合影视渲染或高精度模型。

## 3D 文件格式对比

| 格式 | 特性 | 典型应用场景 |
| --- | --- | --- |
| USD | - Pixar 开源格式，支持分层组合场景  - 兼容材质、动画与物理模拟数据 | 影视动画流程（如 Omniverse 协作） |
| FBX | - Autodesk 主导的跨平台格式  - 完整保留骨骼动画与蒙皮权重 | 游戏开发（Unity/Unreal 引擎适配） |
| OBJ | - 仅含几何与 UV 数据  - 无动画与材质信息，需配合 `MTL` 文件 | 静态模型交换（ZBrush 到 Maya 拓扑） |
| STL | - 三角面片集合体  - 无色彩/材质信息 | 3D 打印基础格式（快速切片） |
| GLB | - `glTF` 的二进制封装格式  - 集成 `PBR` 材质与骨骼动画，支持压缩传输 | Web3D 展示（`Three.js`/`Babylon.js` 加载） |
| 3MF | - 现代 3D 打印标准格式  - 支持多材料/颜色/纹理信息 | 高保真打印（如全彩砂岩/多材质喷射打印） |
