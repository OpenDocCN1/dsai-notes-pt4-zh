
# HR数据出境需要单独同意吗

> 来源：[https://docs.feishu.cn/docx/BxTjdJ6y4oDlmRxuUkjcJP0Yn2e](https://docs.feishu.cn/docx/BxTjdJ6y4oDlmRxuUkjcJP0Yn2e)

**问：**HR信息出境现在必须走单独同意路径吗？

**答1：**分享两个信息给你参考：（1）收集、对外提供、跨境传输是独立的数据处理活动，需要各自的合法事由，不能混同，网数条例第73条第（八）项也是这个逻辑；（2）有项目中，网信办已经要求补正提供员工同意出境的支撑文件。

**答2：**国可以用劳动规章或者员工手册作为合法性基础，前提是要经过民主程序。网信办对于员工个人信息出境可能有补充的指导意见，我们听说在各个部门内部沟通中。

**答3：**但是个保法合法基础加履行劳动合同就是出境场景。

**答4：**员工数据出境要单独同意的话，实务中如果员工不肯签同意书，公司不能因为这个解除劳动合同，然后么……

总结：基于人力资源管理所必需出境的论证需要谨慎论证。
