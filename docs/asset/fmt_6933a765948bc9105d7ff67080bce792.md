## 工作流设计

### `ReportCrawl`（目前还是需要人工去做）

1. `Report` → 指「财报」
2. `Crawl` → 网络「爬取」
3. 合起来就是「财报爬取」流程。

### `Split2DB`

1. `Split` → 「拆分」文件（PDF/Excel/Word 等）
2. PDF——纯文字==》WPS
3. 纯文字==》数据抽取
4. 2 → to 的谐音，表示「到」
5. `DB` → Database
6. 数据库合起来就是「把文件拆分并写入数据库」。

### `ARAgeCalc`

1. `AR` → Accounts Receivable（应收账款）
2. `Age` → 账龄
3. `Calc` → Calculation（计算）合起来就是「应收账款账龄计算」。
