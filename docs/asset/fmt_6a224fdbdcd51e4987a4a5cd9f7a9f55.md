# 赛事介绍：LIC·2024 语言与智能技术竞赛

> LIC：由 [中国中文信息学会（CIPS）](http://www.cipsc.org.cn/) 和 [中国计算机学会（CCF）](https://www.ccf.org.cn/)联合主办，百度公司、中国中文信息学会评测工作委员会和中国计算机学会自然语言处理专委会承办的中文NLP顶级赛事，迄今已举办五届，已成为中文NLP领域内最权威、最热门的赛事之一。

> 本次 2024语言与智能技术竞赛（LIC）与上海少年儿童出版社有限公司合作，竞赛将由上海少年儿童出版社提供面向真实应用场景的“十万个为什么”系列特色数据集

> 诚邀具有AI原生创新思维的开发者、创业者们，结合自身的专业背景与“想象力”，一同挖掘文心大模型的无限应用潜力！共同推动语言理解与交互技术发展！

## 🫀 赛事解读

+ 【赛题主题】：LIC·2024 语言与智能技术竞赛
+ 【开发者任务】
+ 基于“十万个为什么”系列特色全量数据集
+ （初赛仅开放[天文数据](https://aistudio.baidu.com/datasetdetail/269367)，但设计整体方案时最好考虑全部数据）
+ 基于文心ERNIE大模型能力：使用 [`ERNIE Bot SDK`](https://github.com/PaddlePaddle/ERNIE-Bot-SDK)、[`AppBuilder-SDK`](https://github.com/baidubce/app-builder?tab=readme-ov-file) 等均可
+ 设计并开发具有产业价值的大模型原生应用产品
+ （初赛）提交应用技术方案构思设计PDF
+ （复赛）在飞桨星河社区发布产品demo（`Gradio`/`Streamlit`/静态网页），提交应用链接&演示视频&展示PPT
+ （决赛）线上答辩，10 min PPT展示 + 5 min Q&A
+ 【参考方向】

> 赛事有两大方向（RAG应用 & 多模态创意类应用），分别评选：
> 1 个一等奖(￥3w)、1 个二等奖(￥2w)、1 个三等奖(￥1w)、2 个优胜奖(￥5k)

1. 基于《十万个为什么》的RAG应用：场景化知识问答、知识检索、知识推荐应用等

结合搜索技术和知识图谱等方法，来提升信息的相关性和实用性。

这种应用通常涉及到从大量文档或数据源中检索信息，并将这些信息以更合适的方式展示给用户，提高结果的相关性和准确性，增强用户体验

1. 《十万个为什么》多模态创意类应用：十万科普儿童绘本（漫画插图、有声绘本）、“十万”故事机、十万竞赛游戏等

+ 【限制】
+ 基于“十万个为什么”系列特色全量数据集，数据集仅可用于本次赛事
+ 基于文心ERNIE大模型能力：[`ERNIE Bot SDK`](https://github.com/PaddlePaddle/ERNIE-Bot-SDK)、[`AppBuilder-SDK`](https://github.com/baidubce/app-builder?tab=readme-ov-file) 等方案
+ （复赛）在飞桨星河社区发布产品demo（`Gradio`/`Streamlit`/静态网页）
+ 【评审方案】
+ 线上初赛：评测委员会（来自中国中文信息学会、中国计算机学会、飞桨&文心大模型官方、少儿社专家）通过评分标准打分，选出决赛入选队伍（预计40-50支，邮件通知）。
+ 评分标准：
+ 创新性——考察 需求洞察、产品定义 能力（30%）
+ 实用性与可行性——考察对于 产品落地 的可行性思考（30%）
+ 技术实践——对 文心大模型 能力运用 及 技术思路&难度（40%）
+ 复赛评分标准：
+ 完整性——考察应用产品开发完整性&是否发布至星河社区（50%）
+ 技术实践——对文心大模型能力运用及技术思路&难度（50%）
+ 决赛：决赛将以线上答辩的形式进行，具体要求和安排另行通知。
+ 评审标准：
+ 创新性（20%）、实用性与可行性（25%）、完整度（25%）、技术实践（30%），
+ 加分项（5%）：飞桨星河社区上的 “热度” 数据（数据收集至答辩前一天）。
