# 学习

## 我们从一年的大型语言模型构建中学到了什么（第一部分）

贡献人：

`https://www.oreilly.com/radar/what-we-learned-from-a-year-of-building-with-llms-part-i/`

在过去的一年中，我们通过与大型语言模型（LLMs）的实践，总结了一系列关键的技术细节和最佳实践。我们发现，尽管 LLMs 在实际应用中的表现已经足够 “好 enough”，但要构建真正有效的产品，仍需深入的技术工作。我们强调了提示技术（prompting）的重要性，包括 n-shot 提示、连续思维（chain-of-thought）和提供相关资源等方法，以提高模型的性能和可靠性。此外，我们还探讨了如何通过结构化输入和输出来优化模型的处理过程。

在信息检索方面，我们提出了检索增强生成（RAG）技术，它通过将相关文档的摘要直接提供给模型，有效地提升了输出的质量和准确性。我们认为，RAG 在整合新知识时比传统的细化调整（fine-tuning）更为高效。在工作流程优化方面，我们提倡将复杂任务分解为简单的子任务，并通过多轮对话来提高模型的执行效率。

评估和监控是确保 LLMs 产品质量的关键环节。我们建议使用基于实际输入 / 输出样本的单元测试，以及利用 `LLM-as-Judge` 进行输出评估。我们还提出了 “实习生测试” 来检验生成内容的实用性。在面对 LLMs 可能产生的内容安全和幻觉问题时，我们强调了使用守护策略和内容过滤器的重要性。通过这些技术细节和策略的实施，我们有信心，LLMs 将能够更好地服务于各种应用场景，并为未来的发展奠定坚实的基础。

## 重温SSM（一）：线性系统和 `HiPPO` 矩阵

贡献人：

`https://kexue.fm/archives/10114`

文章首先介绍了 SSM 的概念，指出 SSM 起源于 `S4`，并且在深度学习中有多种变体，如 `Mamba`。作者苏剑林强调，线性系统既足够简单又足够复杂，可以通过指数函数和三角函数的组合来拟合复杂函数。`HiPPO` 矩阵的推导基于正交基函数逼近动态更新的函数，提供了一种优雅的数学方式来记忆和逼近函数。文章接着讨论了有限压缩的概念，即如何用有限维向量来存储信息，并通过傅里叶级数和勒让德多项式的例子来说明这一点。在探讨线性初现时，作者通过推导展示了如何从函数基的逼近出发，得到线性 ODE 系统。文章还提供了一般框架，用于推广特定的函数基和时间映射。通过引入勒让德多项式，作者展示了如何使用这些多项式来简化推导过程，并得到 `HiPPO` 矩阵的解析解。在邻近窗口和整个区间的讨论中，作者分别介绍了 `LegT` 和 `LegS` 的概念，并给出了相应的推导和结论。最后，文章对 SSM 的理论和实际应用进行了延伸思考，指出 SSM 的线性特性和记忆能力与所选函数基和假设紧密相关。

## 压缩激活对并行训练的影响

贡献人：

`https://zhuanlan.zhihu.com/p/701798876?utm_psn=1781747681532571648`

文章探讨了在模型并行训练中压缩激活对提高大规模`Transformer`模型训练速度的影响。研究发现，与数据并行性不同，模型并行性中的激活不是低秩的，需要不同的压缩策略。作者实现了并评估了基于剪枝、学习和量化的压缩算法，结果显示基于学习的压缩，特别是自动编码器（`AE`），在保持模型精度的同时能提供最高达18%的端到端加速。此外，训练超参数如批大小和序列长度对压缩方法的性能有显著影响，而模型的早期层对压缩更为敏感。这项研究为模型并行性压缩算法的未来发展提供了重要见解。
