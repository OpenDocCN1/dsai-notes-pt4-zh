
```parser.add_argument(&quot;--model_name&quot;, default=&quot;fnlp/moss-moon-003-sft-int4&quot;,
                    ...)
```

把`default`参数改为`fnlp/moss-moon-003-sft`

然后再设置一下多卡加速，把GPU参数设置为四个显卡的编号

