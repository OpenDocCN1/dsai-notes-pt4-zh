### 2.1、【视频模型测评】首帧图生视频

写文生视频、写实记录、声画同步：`sora2`、`veo3.1`（`可灵2.6`、`viduQ2`、`wan2.6`、`即梦3.5pro`在努力）

动作和拓展能力：`海螺2.3`、`viduQ2`电影大片、`veo3.1`、`wan2.6`、`即梦3.5pro`

5秒和10秒效果差别明显，用10秒加速剪辑效果更好

相比几个月前，当时所有模型都难以实现的动作，现在几乎所有新模型都能够实现，那么我们对模型会提出更高的要求：无中生有，声画同步。

### 2.2、【视频模型测评】首尾帧生视频

备注1：`可灵`首尾帧断档式领先，`海螺2`、`即梦3.5pro`也很强但是细节处理不如`可灵`。

备注2：（按照严格程度）`mj`＞`万相`＞`即梦`（通过给魔法女孩加衣服才过审核，`mj`加的最多，`万相`其次，`即梦`再次）

备注3：`MJ`分成`high`和`low`两个视频风格，价格相同，但是`low`的效果不好，可以闭眼`high`。

备注4：`智谱`首尾帧比较喜欢上特效

### 2.3、【视频模型测评】文生视频+声画同步

为什么各个媒体上这么多`Sora2`的视频爆款，但是我们自己做出来很难爆款？

因为`Sora2`免费，做的人太多了，门槛太低，竞争激烈。

【`Sora2`】断档级领先，无论是电影级的影视制作、模拟`POV`和摄像头的现场纪实、漫画动画的制作，都处理的非常好。`Sora3`会是什么样子？

【`veo3.1fast`】比想象中的表现要差，期待谷歌的下一代产品。

【`可灵2.6`】虽然还距离`Sora2`有明显差距，但是比我想象的表现好。

【`wan2.6`】很惊喜的进步，水平接近`可灵2.6`

【`即梦3.5pro`】还差把劲儿

【`grok`】事实比看到的案例要差，因为案例是大量抽卡得到的。但是`grok`免费且默认提供很多首帧图的选择可供抽卡。

### 2.4、【视频模型测评】参考生视频+声画同步

`即梦`、`智谱`也有，但是水平一般，就不放了。

测试看点：

没有图片的信息传递，视频模型到底能不能精准表达不同景别下的空间关系、道具、音效、背景等信息。

在极高难度提示词指令下，模型的表现水平。

【`可灵O1`】：

1、复杂动作未表现出来。未完整执行提示词的剧情。

2、较精准表达景别的层次，音效和运镜良好。

3、三人及以上的角色参考，任务识别错误。其他问题不大。

【`ViduQ2`】：

0、`viduQ2`在这组测评里面吃亏在只有5秒时长（会员8秒），`可灵O1`和`Sora2`都有10秒时长。

1、两个及以内角色支持声画同步，再多角色只支持配音。动作表现和提示词遵循的完整度较好。缺少运镜和部分场景表达。

2、精准表达景别的层次，音效和运镜较差。

3、除了转场出现空间关系错误，其他问题不大。

【`Sora2`】：整体表现很好，如果不那么专注于刻意的对话，表现会更好。对于多重。

1、复杂动作未表现出来。浪费了很多时间在静止画面的人物对话上（在我未写台词的情况下）。

2、缺少人物，反而过度表达对话。

3、同景别的人物引用表达准确、专场和动作也及格。但是依然话唠。

【`wan2.6`】看起来还差把劲儿。

```
人物从静态站姿开始，表情由平静转为自信的微笑。
第1秒时，她使出一个充满力量的、杂技般的旋转踢腿。这一踢腿产生可见的冲击波，震散水坑里的积水，并让周围的杂物颤动。同时，一个由发光紫色粒子组成的漩涡从她的动作中爆发出来。

镜头对整个动作进行持续、戏剧性的慢动作环绕拍摄，并以快速推近她最终胜利的微笑结束。时长：10秒。
```

```
分镜脚本与模型能力测试点解析
这是一个将上述提示词拆解成的“导演分镜脚本”，清晰地展示了每个阶段的目标。

第一幕：启动与爆发 (时间: 0-3秒)

脚本描述: 视频开始，画面中的女性表情从静态的平静变为充满自信的微笑。紧接着，她以一个爆发力十足的旋转踢腿打破静止，动作带起冲击波和粒子漩涡。

考验的模型能力:
角色一致性与微表情: AI能否在不改变角色核心面部特征的前提下，生成一个流畅、自然的表情变化？这是对角色锁定的基础考验。
复杂人体动画: “杂技般的旋转踢腿”远超简单的走路或转身，考验模型对人体运动学和动态美感的理解。
物理环境交互: 冲击波震散水坑和杂物，考验模型是否理解“力”与环境的因果关系，能否生成符合物理逻辑的次级动画。
粒子特效生成: 凭空创造出“发光粒子漩涡”，并使其动态与角色动作相关联，考验特效的生成与绑定能力。

第二幕：转化与创造 (时间: 3-7秒)

脚本描述: 粒子击中目标，凭空出现的“影子怪物”经过一个“故障艺术”风格的视觉效果（闪烁、像素化），然后爆炸并“重生”为全新的生物——水晶狐狸精灵。

考验的模型能力:
凭空生成与多阶段状态转换: 这是整个测试中最核心的挑战之一。它要求模型理解一个`A -> B -> C -> D`的复杂转换链（粒子 -> 影子 -> 故障态 -> 爆炸 -> 水晶狐狸）。这极大地考验了模型的逻辑推理和概念转换能力。
风格化视觉特效 (VFX): “闪烁和像素化”考验模型实现特定艺术风格特效的能力。
创造性实体生成: “水晶狐狸精灵”是模型根据文本描述创造的全新、高质量的动态生物，考验其想象力和生成稳定性。
镜头控制（持续性）: 在这个混乱的阶段，镜头需要开始并保持平滑的“慢动作环绕”，考验模型在复杂动态下维持稳定运镜的能力。

第三幕：互动与收尾 (时间: 7-10秒)

脚本描述: 主角优雅落地，一只新生的精灵主动飞过来与她的手进行亲昵互动。环境因魔法而产生细微变化（雨水蒸发）。镜头完成环绕并快速推近，定格在主角胜利的微笑上。

考验的模型能力:
多主体智能互动: 这是难度最高的测试点。它要求模型不仅要维持主角和多个新生成精灵的一致性，还要精准执行一个特定、带有情感的互动（“亲昵地蹭手”）。这考验模型对空间关系、动作意图和角色关系的深度理解。
精细环境特效: “雨水蒸发成蒸汽”是比冲击波更细微的环境交互，考验模型处理细节特效的能力。
高级运镜组合: “慢动作环绕”+“快速推近”是一个复杂的运镜指令，考验模型执行复合镜头语言的能力，以及在不同速度间切换的流畅度。
叙事闭环: 最终的特写微笑不仅是考验角色一致性的收尾，也是对模型能否理解并完成一个微型叙事（危机 -> 解决 -> 胜利）的最终检验。
```
