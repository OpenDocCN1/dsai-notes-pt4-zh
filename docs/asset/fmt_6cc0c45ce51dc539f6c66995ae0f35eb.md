# 学习感悟

1.  **完成比完美更重要**，能把一件小事做完整，本身就很不容易。

1.  没有最好的工具，只有最适合自己的工具。工具的使用一定会越来越越简单。

1.  AI工具所能到达的程度，也是个人想象力的上限。无法让AI做出超越个人想象力的场景，每个人基于自己不同背景知识下神经元随机链接所产生的灵感还是AI无法模拟的领域。
