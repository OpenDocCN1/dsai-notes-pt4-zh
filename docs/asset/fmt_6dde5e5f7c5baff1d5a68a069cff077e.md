
# 深圳惠民保保障详解与百万医疗险选择建议

## 一、深圳惠民保保障内容

### 1、赔付比例提高

[拓展医](https://www.zhihu.com/search?q=%E9%97%A8%E8%AF%8A&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)保目录内保障范围，覆盖住院、门诊特定病种以及[及经单行支](https://www.zhihu.com/search?q=%E4%BF%9D%E9%99%A9%E6%9D%A1%E6%AC%BE&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)付的国谈药品医疗费用（因病情需要经医生同意，符合国谈药品清单且在保险条款范围内的医疗费用）。

自己掏的钱超过1.6万的部分，能报销80%（原深圳重疾险最高报销70%），医保目录外是70%。

### 2、覆盖群体广了

原先的“深圳重疾险”针对特定病种群体用户，仅提供17种特药清单，升级后的“深圳惠民保”在此基础之上，新增了罕见病专项保障，具体病种也给各位列出来了，见下图：

![](img/fd8202834328b390c601d0f258952807.png)

针对这6大罕见病群体，年报销额度50万，免赔额1万。

另外，如果你是连续参保“深圳重疾险”满3年的，最高可报销70%；满1年或不满1年的，报销50%。

### 3、增值服务多了

深圳惠民保一共提供6项增值健康服务，见下图：

![](img/8f6952b1b68dc7a4772ac01acf8f43ce.png)

像[癌症早筛](https://www.zhihu.com/search?q=%E7%99%8C%E7%97%87%E6%97%A9%E7%AD%9B&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)、疾病评估等，这些服务针对父母还是蛮实用的。

毕竟如果单独叫父母去体检，他们就会很抗拒，现在买产品送服务，接受度更高。

写到这，大家应该对深圳惠民保也有了一定了解，可以看出它确实适合一些特定人群。

如果你对深圳惠民保还是青睐有加，那请注意这3点：

### 1️⃣ 注意报销比例

深圳惠民保针对五大责任分别设置了不同的报销比例：

> **责任一：医保目录内报销80%**；
>
> 责任二：医保目录外报销70%；
>
> 责任三：门诊合规药品报销50%；
>
> 责任四：罕见病或指定药店购药，按参保“深圳重疾险”年数报销，最高70%；
>
> 责任五：港澳药械通指定药械报销50%。

可以看到，相较于百万医疗险的社保内外100%报销，深圳惠民保确实存在报销比例低的问题。

### 2️⃣ 注意免赔额

从第一部分的产品基本盘也可以看到，责任一、二、四都有1.6万的免赔额，责任三免赔额更高。

我们都知道，绝大多数的百万医疗险免赔额只有1万。

**并且，深圳惠民保的免赔额设置**方式，是医保目录内和医保目录外分开计算的，也就是1.6万+1.6万，一共是3.2万。

你看，这报销门槛又比百万医疗险高了很多。

### 3️⃣ 注意报销范围

**责任二医保目录外个人自费费用**报销仅限药品费+检查检验费，其余均不予报销，比如自费耗材。

如果治疗需要涉及到一些高端器材或设备，只能自费解决。

下面，我们通过一个例子，来给大家演示一下深圳惠民保与百万医疗险的报销区别。

假设[小A](https://www.zhihu.com/search?q=%E5%B0%8FA&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)[住院医疗费](https://www.zhihu.com/search?q=%E5%89%A9%E4%BD%99%E8%B4%B9%E7%94%A8&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)花了20万，医保报销10万，其中剩余费用医保内3万，医保外7万。

分别用某款百万医疗险（免赔额1万，不限社保，100%报销）和深圳惠民保（医保内外免赔额各1.6万，医保内报80%，医保外70%）报销。

**用某款百万医疗险：**扣除1万免赔额后，剩下9万都报销，算下来，自己只要掏1万。

**用深圳[惠民保](https://www.zhihu.com/search?q=%E6%83%A0%E6%B0%91%E4%BF%9D&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)：**只能报(3-1.6)x80%+(7-1.6)x70%=4.9万，也就是说，自己要掏5.1万。

可以看出，对于同一笔住院医疗费，用百万医疗险能报销的费用，比惠民保多很多。

## 二、有了惠民保，还需要买百万医疗险吗？

后台也经常能收到大家的留言，比如：

> 我有医保，还需要买惠民保吗？
>
> 买了惠民保，还要买百万医疗险吗？
>
> 买了百万医疗险，还要买惠民保吗？
>
> ......

![](img/ee65440eda172480d53dece39383a9a7.png)

如果非要纠结两者到底哪个好？其实并没有那么非黑即白。

从**价格、投保门槛**角度来说，惠民保胜出。

因为惠民保不限年龄、职业，基本没有健康告知，门槛比百万医疗险低得多。

对于很多买不到[商业保险](https://www.zhihu.com/search?q=%E5%95%86%E4%B8%9A%E4%BF%9D%E9%99%A9&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)的人来说，惠民保肯定要比百万医疗险好。

但从**保障角度**来说，百万医疗险胜出。

百万医疗险，扣除1万免赔额后，不限社保，100%报销。

而[大部分惠民保](https://www.zhihu.com/search?q=%E7%99%BE%E4%B8%87%E5%8C%BB%E7%96%97%E9%99%A9&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)，免赔额更高，报销比例也不是100%，比如前面提及的深圳惠民保，针对不同责任、医保目录内外，分开设置免赔额，报销比例也逊色于百万医疗险。

我们知道，疾病越严重，医保范围外的费用往往越高。

大病之所以让人难以负担，就是因为很多费用社保无法报销。

惠民保如此设置，保障作用减弱不少。

除此之外，百万医疗险常见的就医绿色通道、住院垫付等服务，惠民保也很少有。

从**产品可持续性**来说，百万医疗险也更好一些。

续保是医疗险的重中之重，如果续保条件不好，身体万一变差，可能买不了，保障就会中断。

[而惠民保多](https://www.zhihu.com/search?q=%E4%BF%9D%E8%AF%81%E7%BB%AD%E4%BF%9D&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)为一年期产品，买一年保一年，不保证续保，无法确定来年还能不能继续买。

如果到期忘记重新投保，或者说错过了集中投保时间，就会出现保障真空期。

相比之下，百万医疗险有保证续保的产品。

一般保证[续保](https://www.zhihu.com/search?q=%E7%BB%AD%E4%BF%9D&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)的时间为6年、10年或20年，只要在续保期间内都能保，续保稳定性更强。

因此，结论就是：

[**对于买了惠民保**](https://www.zhihu.com/search?q=%E5%8C%BB%E7%96%97%E4%BF%9D%E9%9A%9C&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028431786%7D)的朋友，如果还能买百万医疗险的话，我是建议再搭配一份百万医疗险，以获得更全面的医疗保障。

### 一、深圳惠民保，保障内容

深圳惠民保凭借着[不限年龄](https://www.zhihu.com/search?q=%E6%97%A2%E5%BE%80%E7%97%87&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028998986%7D)、不限疾病、老少同价88元/人、既往症也可买可赔，一时间冲上热搜。

先看这款产品的整体保障：

![](img/efc1cb9247dcc3e79385dc982c6cc1b3.png)

先来个省流版，如果你是这4类人群，重点关注：

+ **年龄超过60岁的**

+ **已经生过大病的**

+ **买不了常规百万医疗险的**

+ **买其它保险被除外承保的**

深圳惠民保背后的主承保单位是[中国人寿](https://www.zhihu.com/search?q=%E4%B8%AD%E5%9B%BD%E4%BA%BA%E5%AF%BF&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028998986%7D)，共同承保的还有人保、[平安健康](https://www.zhihu.com/search?q=%E5%B9%B3%E5%AE%89%E5%81%A5%E5%BA%B7&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3028998986%7D)等传统大牌保司。

我总结了这款产品的3大亮点，接着往下看。

自己掏的钱超过1.6万的部分，能报销80%（原深圳重疾险最高报销70%），医保目录外是70%。
