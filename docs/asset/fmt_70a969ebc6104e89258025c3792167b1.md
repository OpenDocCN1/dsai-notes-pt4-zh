
# 《会计法》

> 来源：[https://rxq0zfnkm77.feishu.cn/docx/VaZ9dFRTMofhJHx8BgvcK2PhnOe](https://rxq0zfnkm77.feishu.cn/docx/VaZ9dFRTMofhJHx8BgvcK2PhnOe)

为什么采购需要了解《会计法》？

采购直接涉及资金使用与发票入账，必须符合会计法规。

避免因违规合同、虚假发票导致审计风险。

与财务部门沟通顺畅，提升采购专业性。

## 一、基本认知

《会计法》是采购业务顺利入账和资金合规使用的基础法律。

采购人员不是会计，但必须理解其中涉及资金、票据、预算、责任的条款。

---

## 二、采购需关注的核心条款

### 1. 会计核算与凭证管理

- 合法凭证要求：所有采购支出必须有真实、合法、有效的合同与发票。
- 禁止行为：不得使用白条、虚假发票入账。
- 采购提醒：供应商选择要注意其开票资质。

### 2. 预算与资金控制

- 采购必须在批准的**预算范围内**进行。
- 严禁超预算支出、私自拆分合同规避审批。
- 对于财政资金或国企资金，更要严格执行。

### 3. 内部控制与审批流程

- 采购支出需履行审批手续，符合单位财务制度。
- 严禁设“小金库”，不得绕过财务直接支付。
- 实务中要保留完整的采购、验收、付款流程记录。

### 4. 会计监督与审计配合

- 会计部门有权监督采购的资金合规性。
- 审计时，采购合同、付款凭证、验收记录都会被抽查。
- 采购人员需积极配合提供资料。

### 5. 法律责任

- 伪造、变造合同或发票的采购行为，个人要承担法律责任。
- 采购与财务人员可能共同被追责。
- 单位可对违规人员进行处分，严重的涉及刑事责任。

---

## 三、采购实务中的应用

**下单前**：确认预算 → 合同合法 → 供应商合格。

**付款前**：发票正规 → 审批流程完整 → 财务复核。

**存档时**：合同、验收单、发票、付款凭证要齐全。

**日常工作**：理解财务提出的“发票规范、预算控制”要求，不与财务产生冲突。

---

## 四、学习建议

- 学习《会计法》时，重点放在：核算凭证、预算控制、审批流程、责任条款。
- 配合本单位财务制度，建立一份**采购业务合规清单**，随时对照。
- 定期关注财政部或审计署的新规，避免政策滞后。
