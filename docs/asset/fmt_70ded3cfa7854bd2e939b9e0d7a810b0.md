
# 致谢

还有陪我加班的a梦，一起追星的彩笺，教我做app的超人，鼓励支持我的康昊、一格，分享情报的邬轼，催更的东君，帮我debug的夏哥、无形、蔡上上，告诉我都不是事的羊上上。

无法一一列举，有太多太多的帮助和温暖，还有坦诚的交流和分享。

![](img/9fb61e8f897e47c509a417c309f9f846.png)

经历过职场的冷暖，我从未期待，还能再次拥有大学社团那样真挚的伙伴关系。

但在这里，在scai，我感受到了。

我从未想过自己还会有这样的运气。

更没有想到，会有这样的运气，得以和小排老师相遇相识。

做scai以来，小排老师一直告诉我们：

**好产品，是送给世界的礼物。**

**好产品，会自传播。**

我见证了兔老师产品诞生的过程。

Demoday上，在一众自嗨或无聊的产品中，兔老师讲述了她的产品，是如何从解决科研领域存在已久的痛点开始，打动了国内外学生和老师群体的心，在一篇文章的助力下不断破圈，口耳相传。

真诚的分享，感染了现场所有人，很多人自发想要帮忙宣传，让它走得更远。

我在台下热泪盈眶。我觉得非常感动，能够见证一个好产品的诞生。

## 回到原点

去北京的第一天，下着小雨。

小排老师和我说，我过往经历的所有一切，都是为我去做这个产品准备的。

连点成线，就成了六六。

他说，很多人会需要我的产品。

他说，还有很多需要我产品的人，不知道它的存在。

你是怎样的人。

你相信什么，热爱什么。

你会做怎样的产品，书写怎样的故事。

我相信好产品的价值。

我相信真诚自有万钧之力。

我相信常识，相信先打动自己，才有可能让别人感动。

我相信专注做好过程，结果会自然到来。

scai的文化衫上印着一句话，make something people love.

小排老师说过，有很多尚未被解决的问题，正在苦苦等待一个好产品。

希望大家可以为世界带来更多好产品，书写属于自己的故事。
