ChatGPT 在中国区的 苹果和安卓商店都没有上线。

所以我们需要注册美区的应用商店账号，才能进行下载。

今天，我们来教学 IOS（苹果）的美区账号申请，和下载 ChatGPT 流程。

## 一、注册美区 `AppleID`。

进入 `AppleID` 官网 `https://appleid.apple.com/`，在左上角找到“创建你的 Apple ID”

![](img/86057d5b17316ec8ab50300fb572a01e.png)

接下来就是填表格。

![](img/87d303d7871c988b98f41599ff6dbcb6.png)

### 注意事项：

- 姓名不要用中文。
- 国家就填成“美国”。
- 生日要大于 18 岁。
- 邮箱不能用以前注册过 Apple ID 的。
- 密码中不要出现如生日之类的个人敏感信息，否则后面的验证会失败，要重来。
- 手机号码用自己的真实手机号。

然后点击注册，就会给邮箱和手机分别发送验证码，只要审核通过就可以。

这里我遇到了电脑网页端在申请时异常的问题，切换手机登陆就好了，如果有人遇到相同问题，用手机操作试试。

![](img/2afd04b6f2f01100a8ec7f27d54dd2df.png)

![](img/27daf1d391e1c6465107ffb869da5090.png)

恭喜你！现在，你已经拥有一个美区账号了。

## 二、下载 ChatGPT

打开 APP Store，点击搜索，右上角。

![](img/530b69ca8a0ee39a73d6276c20ba69de.png)

拉到底部，退出当前账号。

![](img/cce27ab7c6f747f43387afc8425bf37f.png)

拉到顶部，登陆新账号。

![](img/c0d0076583cc3177edc0bd9e16ee9077.png)

登陆时候选择第二个，不是 XXX？，否则会默认填写之前的 ID

![](img/2de735409d2c571e2ef7b9a182c9cfd1.png)

这时候，你还没办法下载，还有一些其他信息要填写，随便点击一个获取，输入密码后，会有这个弹框。

![](img/45168b9f761841bf3405b89981b6b138.png)

点击“检查”，同意条款，下一页。

![](img/74bd9c4a9606c8cdbfd6b094d2c2c28f.png)

重点来了，付款信息会有一些检测。

付款方式：选择 无

其他随便填。

州和邮政编码需要绑定。

如我填写的加利福尼亚州 邮政编码是 90001～96162。

手机号随便 7 位数。

![](img/dc755ad9e80bb4a1d9d50ba2615d87fd.png)

然后就完成了。

![](img/0e25292d2f1e076f857ede7d1cacd3cd.png)

搜索 ChatGPT，白色的这个是正版。

![](img/e3f2350a8b57dc29379ac19816927342.png)

点击获取，重新输入一遍密码就可以了。

大功告成！
