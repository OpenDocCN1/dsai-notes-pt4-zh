这个教程无需你会剪辑或者编程等技能，只要你有手就能跑完这个教程。

场景介绍：短视频作为时代风口，很多人都想零基础上手制作短视频，但不知如何做起。在本课程，你将利用deepseek帮助你写脚本，在即梦AI上利用生成的脚本用来生成多个短视频，最后在剪映上剪辑。

前言：本教程的入门将以校园vlog为主题，大家学习完后不要吝啬自己的想象力，可以自由发挥主题，eg：科幻、恐怖、浪漫、动作、犯罪、地球日、奇幻、纪录片、喜剧、亲子、惊悚、科普~~~

## 高级（专业流程+创意表达，1小时以上）

核心目标：打造质感高级、有个人风格的Vlog，掌握AI工具链联动。

### 专业策划与分镜

+ 分镜表模板：

| 分镜 | 画面描述 | 工具实现 |
|------|----------|----------|
| 1 | 镜头缓缓推进书桌 | 剪映「镜头缩放」关键帧动画 |
| 2 | 虚拟背景替换 | 即梦AI「抠图换背景」+DeepSeek修复边缘 |
| 3 | 动态数据可视化 | DeepSeek API调用生成课程表动画 |

### 2. AI工具链深度整合

+ 即梦AI+DeepSeek联动：

1. 用即梦AI生成“咖啡杯蒸汽”特效视频 → 导入剪映。

1. 用DeepSeek处理视频：“增强对比度，降低噪点” → 重新导入剪映叠加。

+ 自动化工作流：

+ 剪映导出视频后 → 用DeepSeek Coder自动压缩体积至50MB以内。

### 3. 高阶剪辑技巧

+ 多轨道剪辑：

+ 新建「音频轨道」：叠加环境音和ASMR音频。

+ 新建「特效轨道：添加「光斑」特效动态跟随人物移动。

+ 关键帧高级应用：

+ 选中片段 → 点击「关键帧」→ 调整“位置”参数制作镜头平移效果。

### 4. 专业发布策略

+ 平台适配：

+ 抖音：竖屏裁剪 + 添加「热门BGM」标签。

+ B站：横屏输出 + 添加「逐帧字幕」（用剪映「动画字幕」功能）。

+ 版权规避：

+ 音乐：使用剪映「版权音乐」库或即梦AI生成的纯音效。

+ AI素材：确认即梦AI Pro版授权条款（商用需订阅）。

#### prompt（提示词）的简单教学

一、背景 + 需求 + 约束条件

eg：我是一名专门做科幻片的短视频博主（背景信息），想要利用即梦AI生成12个5秒的视频（明确需求），请帮我生成一篇以“地球爆炸”为主题的科幻小说，并用12段提示词能概括完生成的科幻小说，要求提示词在即梦ai上生成视频后要有电影级运镜（格式要求）
