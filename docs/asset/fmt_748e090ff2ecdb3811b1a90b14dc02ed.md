大致风格可整理为：

- Prompt 围绕春节，强调节日氛围和文化元素，设计了不同的角色和场景，如：

1. **固定角色春节发言**：如 CEO、销售代表、人力资源经理等
2. **企业内部沟通**：针对员工、管理层等内部角色的鼓励、感谢和祝福
3. **客户关系维护**：针对客户、合作伙伴等外部角色的感谢和祝福
4. **文化传承与教育**：针对学生、读者等群体的文化教育和节日知识分享
5. **社会责任与公益活动**：针对社会弱势群体的关怀和支持。
6. **个人生活与健康**：针对个人及其家庭的健康、幸福和生活改善。
7. **产品春节营销方案设计**：如促销活动描述、媒体账号文案、产品发布通稿、App 界面更新等
8. **信息总结与压缩**：如大段祝福信、活动策划、邀请函、工作安排等
9. **祝福语转成诗句**：将长段的祝福语转成清晰明了的诗句

- Prompt 一般包含诸如 情感积极、目标明确、有字数限制 等基本要素

1. **情感积极**：Prompt 要求表达正面的情感，如感激、鼓励、祝福等，以传递温暖和积极的情绪
2. **目的明确**：每个 Prompt 都有明确的目的，如鼓励团队、感谢客户、激励员工等
3. 部分 Prompt 要求与特定群体（如客户、员工、捐助者等）进行互动，考虑建立和维护良好的关系
4. **有字数限制**：Prompt 均有明确的字数要求

- Prompt 构建公式可大致整理如下：

1. 角色 + 节日 + 情感 + 目的 + 字数限制

例如：“假如你是企业 CEO，请为全公司员工撰写一段 50 字的春节鼓励祝福。”

2. 场景 + 角色 + 节日 + 互动方式 + 目的

例如：“在春节来临之际，作为图书馆馆长，为读者准备一段 60 字的文化教育风格的祝福。”

3. 节日 + 角色 + 目标群体 + 期望效果

例如：“春节将至，作为环保组织负责人，向社会传达一段 70 字的激励环保风格的祝福。”

4. 角色 + 节日 + 活动类型 + 目的 + 参与指南

例如：“假如你是旅行顾问，请提供一段 50 字的探险期待风格的春节祝福给客户。”

5. 角色 + 节日 + 产品/服务 + 优势 + 目标客户

例如：“假如你是建筑师，请为合作伙伴和客户设计一段 60 字的创新合作风格的春节祝福。”

**自动规则打分指标说明**

规则打分模式下，忽略停用词后，

> 该分类下的两个指标，更适用于 分类/判断 的客观问题

**准确度**：正确预测（标注与预测完全匹配）的样本数与总样本数的比例

**`F1` 分数**：精确率和召回率的调和平均数

**NLP 中机器翻译 / 文本摘要 等生成类任务常用的评价指标**

> 该分类下的指标，更适用于总结类的任务

**`ROUGE-1`**：将模型生成结果和标注结果按 `1-gram` 拆分后，计算出的召回率（`n-gram` 指一个语句里面连续的 `n` 个单词组成的片段）

**`ROUGE-2`**：将模型生成结果和标注结果按 `2-gram` 拆分后，计算出的召回率（`n-gram` 指一个语句里面连续的 `n` 个单词组成的片段）

**`ROUGE-L`**：将模型生成结果和标注结果按最长公共子序列（longest-gram）拆分后，计算出的召回率

**`BLEU-4`**：将模型生成结果和标注结果分别按 `1-gram`、`2-gram`、`3-gram`、`4-gram` 拆分后，计算出的加权平均精确率（`n-gram` 指一个语句里面连续的 `n` 个单词组成的片段）
