+ 提高采集效率

+ 解放创作双手

#### Ai加工

`1`：kimi改写    `0`：直接搬运

kimi改写：利用提示词进行正文改写，标题不改写

直接搬运：搬运原文标题+内容

```
模仿下面这段话，保持标题与原文相同，用口语化输出小红书风格的正文，需要与原文同格式，但注意开头不要打招呼，也不要引入原文的作者名称，删除原文标签，正文不能超过800字。
原文如下：
标题：{{variables.title}}
正文：{{variables.content}}
```

可在源码中修改提示词，修改后右上角进行保存

| ![](img/e7be09730f972fb184f95fb68d2eb5e5.png) |
| --- |

#### 是否保存

`1`：保存草稿   `0`：直接发布（不推荐）

保存草稿：图文存入草稿箱，进行定时发送，可设置两天内定时发送。

定时发送属于手工操作

| ![](img/a57ea760a20e4d23a4b9a30f4f2a9295.png) |
| --- |

直接发布：编辑完成后由程序自动发布，请确认相关内容合规性！可在👸号后台关闭安全保护。

| ![](img/2e89ff8ec6bc10511750f438d47c275c.png) |
