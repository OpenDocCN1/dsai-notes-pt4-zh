
+ 当前多数基于 LLM 的推荐系统都依赖于单轮指令跟随方法。将它们扩展到多轮对话场景可以提高这些推荐模型的泛化能力；
+ 随着 LLM 的研究继续支持更长的上下文长度，将使得能够对长行为序列进行建模；
+ LLM 可以扩展对多模式指令和反馈的支持，以更深入地了解用户意图和偏好；
+ AI 生成的内容 (AIGC) 还可以补充人类生成的内容，为 LLM 创建更高效的训练和微调策略。
