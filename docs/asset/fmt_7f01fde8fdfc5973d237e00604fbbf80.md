## 一、前言：文档定位与价值说明

随着生成式 AI 技术的普及，Prompt（提示词）作为人机交互的核心语言，其工程化能力已成为 AI 应用落地的关键竞争力。本手册系统梳理了 17 个主流 Prompt 框架，结合新兴方法论与行业实践，旨在为 AI 从业者、产品经理、内容创作者等提供从理论到实操的全流程指南。

### 文档特色：

1. 结构化体系：从基础框架到复杂场景解决方案，覆盖 90% 以上 AI 交互场景；
2. 实操导向：每个框架附带行业案例与迭代策略，避免 “理论脱离实践”；
3. 动态更新：收录 2024-2025 年新兴框架（如 STAR、PDCA），同步全球技术趋势。

## 二、引言：Prompt 工程的底层逻辑

### Prompt 工程的本质与价值

Prompt 工程是通过结构化语言引导 AI 模型生成预期输出的方法论，其核心在于：

+ 认知对齐：将人类意图转化为模型可理解的指令结构；
+ 误差控制：减少因语义模糊导致的输出偏差（据研究，优质 Prompt 可提升 40% 模型响应准确率）；
+ 效率提升：通过框架化设计，避免重复调试，缩短 AI 应用开发周期。

### 框架设计的核心原则

+ 明确性：避免歧义（如用 “生成 300 字产品卖点” 替代 “写一段文案”）；
+ 场景化：结合角色、背景等上下文信息（如 “作为电商运营，撰写 618 促销文案”）；
+ 可评估：设定输出标准（如 “包含 3 个用户痛点解决方案”）。

## 四、Prompt 框架

### 1. BROKE 框架

#### 原理

+ 融合 OKR（目标与关键成果）方法论，通过背景（Background）、角色（Role）、目标（Objectives）、关键结果（Key Results）、演变（Evolve）五要素构建结构化 Prompt
+ 演变步骤包含三种优化策略：
  + 改进输入：针对答案不足迭代背景、目标与关键结果
  + 改进答案：在对话中修正模型输出缺陷
  + 重新生成：保持 Prompt 不变多次生成结果进行优化

#### 功能

+ 精准对齐任务目标与评估标准，适用于需要量化效果的场景
+ 通过迭代机制持续优化 Prompt，提升模型输出质量

#### 使用场景

+ 目标管理：如内容创作互动率提升、产品转化率优化
+ 项目规划：技术方案迭代、营销活动策划

#### 优点

+ 数据驱动的目标追踪体系
+ 支持动态优化的灵活结构

#### 缺点

+ 初始设置需明确量化指标
+ 复杂任务需多次迭代调整

#### 示例

```
Background：作为电商运营，需提升新品详情页转化率
Role：你是资深电商文案策划专家
Objectives：使详情页停留时长提升30%
Key Results：CTR（点击通过率）提升至8%，加购率提升15%
Evolve：每周分析热力图数据，优化文案排版与卖点顺序
```

### 2. COAST 框架

#### 原理

+ 涵盖背景（Context）、目标（Objective）、行动（Actions）、场景（Scenario）、任务（Task） 五维要素
+ 通过系统化拆解复杂问题，构建全场景任务描述体系

#### 功能

+ 将大型项目分解为可执行的具体步骤
+ 确保各维度要素在 Prompt 中被充分考虑

#### 使用场景

+ 战略规划：企业国际化拓展、技术路线图制定
+ 复杂问题解决：跨部门协作项目、危机公关处理

#### 优点

+ 全景视角覆盖任务全要素
+ 支持从宏观到微观的任务拆解

#### 缺点

+ 简单任务使用时可能过度复杂
+ 需完整掌握各维度信息

#### 示例

```
Context：新能源汽车品牌计划进入欧洲市场
Objective：3个月内建立本地化营销体系
Actions：①调研欧盟环保法规 ②组建本地运营团队 ③开发多语言官网
Scenario：预计2025年Q4遭遇欧盟碳关税政策调整
Task：制定包含政策应对预案的市场进入计划
```

### 3. CRISPE 框架

#### 原理

+ 包含能力与角色（Capacity & Role）、洞察（Insight）、声明（Statement）、个性（Personality）、实验（Experiment）五要素
+ 通过角色定位、背景洞察、任务声明、风格设定与方案实验构建丰富 Prompt

#### 功能

+ 精准定义模型输出的角色定位与内容风格
+ 支持多方案对比实验，提升决策质量

#### 使用场景

+ 创意内容创作：广告文案、剧本撰写
+ 决策支持：商业方案评估、技术选型建议

#### 优点

+ 支持高度个性化的内容生成
+ 多方案实验机制提升创意多样性

#### 缺点

+ 各要素需详细构思，耗时较长
+ 风格设定需明确参考标准

#### 示例

```
Capacity & Role：作为科技行业资深分析师
Insight：元宇宙产业正处于技术成熟度曲线的泡沫破裂期
Statement：撰写2025年元宇宙硬件发展趋势报告
Personality：采用Gartner技术成熟度模型分析框架，语言严谨但具备前瞻性
Experiment：提供AR/VR头显、触觉反馈设备、空间计算平台三个方向的发展预测
```

### 4. CHAT 框架

#### 原理

+ 聚焦角色（Role）、背景（Background）、目标（Ambition）、任务（Task）四核心要素
+ 通过场景化角色设定与目标导向任务描述，提升交互针对性

#### 功能

+ 构建拟人化交互场景，适用于需要情感共鸣的场景
+ 明确目标与任务的对应关系，提升模型理解准确性

#### 使用场景

+ 客服支持：产品售后咨询、用户问题解答
+ 个性化服务：职业规划、健康管理建议

#### 优点

+ 交互场景贴近真实对话
+ 目标与任务的强关联性提升响应精准度

#### 缺点

+ 需提供充足背景信息以确保准确性
+ 复杂场景下目标拆解可能不充分

#### 示例

```
Role：青少年心理辅导师
Background：16岁高中生面临升学压力，出现失眠焦虑症状
Ambition：帮助学生建立健康的压力管理机制
Task：设计包含时间管理技巧、情绪释放方法、家长沟通策略的三步干预方案
```

### 5. CARE 框架

#### 原理

+ 由上下文（Context）、行动（Action）、结果（Result）、示例（Example）构成结构化提问框架
+ 通过场景设定、任务描述、结果预期与案例参考，提升模型理解效率

#### 功能

+ 为复杂任务提供清晰的执行路径指南
+ 示例参考帮助模型精准把握输出标准

#### 使用场景

+ 教育与培训：软件操作指南、流程培训材料
+ 专业报告生成：市场调研分析、技术可行性研究

#### 优点

+ 结构化逻辑降低沟通成本
+ 示例参考有效减少理解偏差

#### 缺点

+ 简单任务使用时可能过于繁琐
+ 示例准备需要额外资源投入

#### 示例

```
Context：跨境电商企业计划拓展日本市场
Action：分析日本消费者购物习惯与电商平台规则
Result：形成包含选品建议、物流方案、合规要点的市场进入报告
Example：报告中需包含"日本消费者对商品包装环保等级关注度达78%"等具体数据引用
```

### 6. CREATE 框架

#### 原理

+ 基于清晰（Clarity）、相关信息（Relevant info）、示例（Examples）、避免含糊（Avoid ambiguity）、迭代修补（Tinker） 五大原则
+ 通过精准定义任务、提供关键信息、示例参考、语言优化与持续迭代，提升 Prompt 质量

#### 功能

+ 确保任务描述无歧义，降低模型误解概率
+ 迭代机制支持 Prompt 持续优化

#### 使用场景

+ 数据分析：报表生成、数据可视化需求
+ 技术文档撰写：API 接口说明、开发规范制定

#### 优点

+ 极简原则易于上手使用
+ 迭代机制适应需求变化

#### 缺点

+ 复杂任务需多次迭代才能完善
+ 信息完整性要求较高

#### 示例

```
Clarity：撰写AIGC技术在电商客服场景的应用白皮书
Relevant info：包含智能问答、工单分类、情绪分析等技术模块的落地案例
Examples：参考《2024年客服行业AI应用趋势报告》的结构
Avoid ambiguity：明确区分"文本生成客服话术"与"语音交互系统"的技术差异
Tinker：根据行业专家反馈调整技术路线图部分的图表展示方式
```

### 7. RACE 框架

#### 原理

+ 包含角色（Role）、行动（Action）、结果（Result）、示例（Example）四要素
+ 通过角色定位、任务行动、结果预期与案例参考，构建目标导向的 Prompt

#### 功能

+ 明确执行主体与任务边界，提升输出相关性
+ 结果导向的设计确保任务达成可衡量

#### 使用场景

+ 营销内容创作：产品卖点文案、促销活动策划
+ 运营方案制定：用户增长策略、社群运营计划

#### 优点

+ 结构简洁易操作
+ 结果可量化评估

#### 缺点

+ 复杂任务需结合其他框架使用
+ 角色定位需精准匹配场景

#### 示例

```
Role：高端护肤品品牌内容运营
Action：创作新品精华液的社交媒体推广文案
Result：文案需突出"抗初老"核心卖点，附带用户试用对比图拍摄建议
Example：参考"早C晚A"护肤概念的传播文案结构
```

### 8. RISE 框架

#### 原理

+ 由角色（Role）、输入（Input）、步骤（Steps）、期望（Expectation）构成
+ 通过角色定义、信息输入、步骤规划与结果期望，构建详细的任务执行指南

#### 功能

+ 将复杂任务拆解为可执行的具体步骤
+ 明确输入输出标准，提升任务完成度

#### 使用场景

+ 项目管理：软件开发流程、活动筹备计划
+ 工作流程设计：审批流程优化、跨部门协作机制

#### 优点

+ 步骤化指导提升执行力
+ 输入输出标准化降低沟通成本

#### 缺点

+ 前期规划需投入较多时间
+ 动态场景下步骤调整灵活性不足

#### 示例

```
Role：敏捷开发项目经理
Input：已收集用户故事池与优先级排序
Steps：①召开迭代规划会议 ②拆分用户故事为开发任务 ③制定燃尽图跟踪计划
Expectation：2周迭代周期内完成80%计划任务，缺陷率控制在5%以内
```

### 9. ROSES 框架

#### 原理

+ 包含角色（Role）、目标（Objective）、场景（Scenario）、预期解决方案（Expected Solution）、步骤（Steps） 五要素
+ 通过全场景要素定义，构建深度问题解决框架

#### 功能

+ 支持复杂问题的系统性分析与解决方案设计
+ 场景化思考确保方案落地可行性

#### 使用场景

+ 商业咨询：战略规划、商业模式设计
+ 技术方案制定：架构设计、系统集成方案

#### 优点

+ 全方位覆盖问题解决全流程
+ 场景化设计提升方案实用性

#### 缺点

+ 信息收集成本较高
+ 要素完整度要求严格

#### 示例

```
Role：智慧城市解决方案架构师
Objective：设计某二线城市交通拥堵治理方案
Scenario：2025年城市机动车保有量预计突破300万辆，现有道路资源增长有限
Expected Solution：包含智能交通信号控制、动态停车引导、共享出行激励的综合解决方案
Steps：①交通流量数据采集 ②瓶颈路段识别 ③方案原型设计 ④试点区域验证
```

### 10. RTF 框架

#### 原理

+ 由角色（Role）、任务（Task）、格式（Format） 三要素构成
+ 通过明确执行角色、任务内容与输出格式，提升交互效率

#### 功能

+ 确保输出结果符合预设格式要求，便于后续处理
+ 角色定位提升任务执行专业性

#### 使用场景

+ 报告撰写：财务报表、学术论文
+ 信息汇总：会议纪要、数据简报

#### 优点

+ 格式标准化提升工作效率
+ 结构简洁易操作

#### 缺点

+ 创造性任务可能受格式限制
+ 复杂格式需提前明确规范

#### 示例

```
Role：金融行业研究员
Task：分析美联储2025年货币政策走向
Format：制作包含利率预测曲线、经济指标影响矩阵、情景分析的PPT简报，共15页以内
```

### 11. ICIO 框架

#### 原理

+ 包含指令（Instruction）、背景信息（Context）、输入数据（Input）、输出指示器（Output Indicator） 四要素
+ 通过清晰指令、背景支撑、数据输入与输出标准定义，构建精准的任务交互框架

#### 功能

+ 确保模型在特定场景下准确理解任务需求
+ 数据驱动的输入输出设计提升结果可靠性

#### 使用场景

+ 内容生成：新闻稿撰写、技术文档翻译
+ 智能推荐：商品推荐系统、内容分发算法

#### 优点

+ 数据与指令的结合提升结果准确性
+ 输出标准明确便于结果验证

#### 缺点

+ 数据准备需要专业知识
+ 复杂任务的输出指示器设计难度高

#### 示例

```
Instruction：生成某新能源汽车品牌2025年Q2季度财报解读文章
Context：该品牌当季交付量同比增长45%，但毛利率下降3个百分点
Input：近三年财报数据、行业平均毛利率水平、竞争对手同期表现
Output Indicator：文章需包含财务指标对比分析图表，重点解释毛利率变动原因，字数控制在1200-1500字
```

+ 通过任务行动、目标目的与结果期望的明确界定，提升交互效率

#### 功能

+ 快速对齐任务执行与目标达成的关系
+ 简洁结构适用于快速任务描述

#### 使用场景

+ 日常工作沟通：会议安排、任务分配
+ 简单内容生成：社交媒体短文案、邮件撰写

#### 优点

+ 极简结构易于快速应用
+ 目标导向确保行动有效性

#### 缺点

+ 复杂任务描述不够充分
+ 缺乏场景化背景支撑

#### 示例

```
Action：撰写公司年度总结大会邀请函
Purpose：邀请全体员工及重要合作伙伴参加年度总结与表彰活动
Expectation：邀请函需包含时间地点、议程安排、着装要求，风格正式且富有感染力
```

### 13. TAG 框架

#### 原理

+ 包含任务（Task）、行动（Action）、目标（Goal） 三要素
+ 通过任务定义、行动规划与目标设定，构建基础任务管理框架

#### 功能

+ 将抽象目标转化为具体可执行的任务
+ 行动与目标的关联确保任务方向正确性

#### 使用场景

+ 个人任务管理：学习计划、健身安排
+ 小型项目执行：部门内工作优化、流程改进

#### 优点

+ 轻量化设计易于日常使用
+ 目标导向提升任务执行力

#### 缺点

+ 复杂项目需结合其他框架使用
+ 缺乏过程管理机制

#### 示例

```
Task：优化部门内部文件审批流程
Action：①调研现有流程痛点 ②设计新审批节点 ③测试新流程效率
Goal：将平均审批时间从3天缩短至1.5天，审批通过率保持95%以上
```

### 14. TRACE 框架

#### 原理

+ 包含任务（Task）、请求（Request）、行动（Action）、上下文（Context）、示例（Example） 五要素
+ 通过任务定义、需求请求、行动规划、场景上下文与案例参考，构建完整的任务指令体系

#### 功能

+ 全方位覆盖任务执行所需信息
+ 示例参考确保模型准确理解需求

#### 使用场景

+ 专业报告生成：市场分析、技术白皮书
