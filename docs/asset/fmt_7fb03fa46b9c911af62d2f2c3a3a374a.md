
# 豆包生图与图片下载自动化脚本指南

只要没有对奇怪形象的出图需求（比如brainrot），这个脚本简直就是神中神，是我最骄傲的作品之一。但豆包在最近一次大更新中更换了出图引擎，出图质量不如前。而且一次提示词能产出的图片上限已经被写死为10张。但你仍然可以调整它，使用任务切割方法来每次产出10张以内的图片。

## 百倍增效的图片下载工具

这个事就又是一个让人头疼的东西。豆包生图确实生了不少图，但好几百张图分布在各个聊天对话栏中。怎么把它们下载下来呢？我试过手动下载，或者使用豆包网页自带的批量下载功能。但豆包的图片较大，下载时有的快有的慢，一不小心位置顺序就会错位。一个故事剧本动辄对应大几十张图，一张一张点实在是让人难以接受。

我早期就是一个一个点的，一个五六十张图片的故事我能点10分钟，十个故事我就得点100分钟，点的让人想死。所以我又做了一个图片下载的自动化脚本，将100分钟的人工操作成本降低为5秒内。对的，你没看错，就是这么夸张。

使用的仍然是网页模拟器的方法。下面这个脚本有1500行，和上面的豆包生图工具相辅相成。

它的逻辑是可以自动检测豆包主页的对话栏中的纯数字图片栏，进去之后找到图片位置，一个一个地下载。因为上面生图的脚本在生图完成后，会自动按顺序将对话栏重命名为纯数字。如此配合，在上面的生图脚本跑完后，我只需运行这个下载脚本，选择我要下载的对话栏，然后点击开始，你就可以去玩了。人工操作成本真的不夸张，10秒内，不管你有多少张图片要下载，都是10秒内。
