## 阿里巴巴与苹果合作，为中国`iPhone`提供AI服务

2月14日，路透社消息，阿里巴巴确定与苹果合作，为中国`iPhone`提供AI服务。阿里巴巴集团董事会主席蔡崇信在迪拜举行的世界政府峰会上确认了该消息。受此消息影响，阿里巴巴股票大涨8%，创三年以来新高。

蔡崇信表示，由于监管等问题，苹果需要寻找一个中国本土的科技企业进行合作，为其手机提供服务。苹果与中国的多家科技公司进行了谈判，最终选择了阿里巴巴。此前，苹果曾与百度和`DeepSeek`接触，但因技术等原因最终放弃，转向阿里巴巴。

阿里巴巴作为国内最大的互联网公司之一，在云计算、大数据、AI等领域有着深厚的积累和技术优势。其自研的`Qwen`系列多模态大模型是全球下载和使用量最高的开源模型之一，在电商、翻译、智能客服、物流、语音助手、监控等场景中表现非常出色。

在智能语音交互方面，阿里巴巴发布的`Qwen2-Audio`语音模型对中文语义理解进行了深度优化，可以强化苹果的`Siri`助手，实现更精准、更智能的语音交互。用户可以通过简单的语音指令，让`Siri`完成查询信息、购物下单、设备控制等复杂操作。

此外，阿里巴巴发布的视觉多模态大模型`Qwen2.5-VL`可以作为一个视觉Agent来自动化操作电脑、手机。例如，根据用户的行程日期，自动预订飞机票。`Qwen2.5-VL`还能理解超过1小时的长视频，并定位特定时间点发生的事件，极大节省审阅视频的时间。

此次合作将为苹果用户提供更强大的AI功能，同时也为阿里巴巴的技术拓展了新的应用场景。

## 🛰️灰度测试接入`DeepSeek R1`满血版

## `OpenAI` CEO Sam Altman公布`GPT-4.5`和`GPT-5`发展路线

2月16日凌晨，`OpenAI` CEO Sam Altman公布了`GPT-4.5`和`GPT-5`的发展路线，并表示未来`OpenAI`旗下产品将简化分类。Sam Altman介绍，接下来`OpenAI`将会推出`GPT-4.5`，该模型内部命名为「`Orion`」，将作为`OpenAI`最后一个非思维链模型推出。

此后，`OpenAI`将会推出集成化模型系统，来统一`O`系列模型以及`GPT`系列模型。据Sam Altman透露，`GPT-5`将作为一个集成了`OpenAI`多项技术的系统进行发布，其中包含`o3`模型，同时`o3`模型将不再单独进行发布。

Sam Altman还公布，`ChatGPT`免费版将能够对`GPT-5`进行无限制的聊天访问，而`Plus`/`Pro`订阅会员依旧能够拥有更高的智能水平访问权限，支持`Deep Research`、语音聊天等功能。此外，Sam Altman在早些时候表示，未来将扩大`ChatGPT`的`Deep Research`免费试用权限。目前，`Deep Research`已向`ChatGPT Pro`会员开放，每月最多可访问100次。

## 字节豆包提出`Dense Video`多模态大模型`Sa2VA`

2月12日，字节跳动、北京大学等机构的研究者提出了`Sa2VA`，这是市面上第一个结合`SAM-2`和`LLaVA-like`的视频多模态大模型。`Sa2VA`结合了`SAM-2`和`LLaVA`的优势，实现了时空细粒度的理解。

`Sa2VA`设计了一套统一的指令微调格式，整合了五种不同的任务，超过20个数据集一起进行联合训练。该模型在多个视频理解和图像理解、视频指代分割和图像指代分割的任务上均取得了领先的效果。

`Sa2VA`的主要特点包括：

+   多模态融合：结合了`SAM-2`的感知能力和多模态大语言模型的推理能力，支持图像、视频细粒度感知以及对话、分析等任务。

+   统一的指令微调：通过单次的指令追随训练，`Sa2VA`可以仅使用一种参数来实现上述所有任务。

+   强大的分割能力：`Sa2VA`通过微调`SEG`令牌的方式连接多模态大语言模型和`SAM-2`模型，支持图像和视频的分割任务。

此外，研究者还提出了一个新的`Benchmark`，`Ref-SAM-2v`以及对应的训练数据集。`Sa2VA`在多个数据集上进行联合训练，并在多个任务上取得了领先的结果。

`Sa2VA`的模型结构包括多模态大语言模型和`SAM-2`模型两部分。多模态大语言模型部分使用了已经经过预训练的模型，包括一个视觉编码器，将视觉特征转换成维度和大语言模型一致的视觉令牌。`SAM-2`模型部分则负责生成分割结果。

`Sa2VA`在多个任务上表现出色，包括图像和视频的`caption`生成、对话、指代对象分割、`GCG`、视觉指代物体`caption`等。此外，`Sa2VA`还可以很好地扩展到开放场景中，如电影或网络视频的分析。

## 阿里通义千问`Qwen`主导全球开源大模型榜单

近日，全球最大AI开源社区`Huggingface`发布了最新的开源大模型榜单（`Open LLM Leaderboard`），榜单显示排名前十的开源大模型全部是基于阿里通义千问（`Qwen`）开源模型二次训练的衍生模型。

`Open LLM Leaderboard`是目前全球最具权威性的开源大模型榜单，其测试维度涵盖阅读理解、逻辑推理、数学计算、事实问答等。

通义千问`Qwen`大模型已经成为全球最大的开源模型族群。在海内外开源社区中，`Qwen`的衍生模型数量已突破9万，超越美国`Meta`公司旗下的`Llama`系列开源模型，位居全球第一。在`Huggingface` 2024年的开源模型下载中，`Qwen`模型系列中的`Qwen2.5-1.5B-Instruct`的下载量占总下载量的26.6%，是全球下载量最高的开源模型。

此外，此前爆火的`DeepSeek`公司基于`R1`推理模型蒸馏了6个模型开源给社区，其中有4个模型来自`Qwen`。近期，著名AI科学家李飞飞团队用较少的资源和数据训练出的`s1`推理模型，同样以`Qwen`模型为基础模型。

## `Adobe` `Firefly`视频模型进入公开测试阶段

近日，`Adobe`宣布其`Firefly`视频模型正式进入公开测试阶段，成为业界首个标榜“商业安全”的AI视频生成工具。

该模型能够基于文本或图像生成1080p高清视频片段，支持精确的摄像机控制、镜头构图以及动态图形制作。为确保内容安全性，`Firefly`仅使用`Adobe Stock`授权素材和公共领域内容进行训练，`Adobe`承诺绝不会使用用户生成的内容进行模型训练。

`Adobe`还推出了`Firefly`创意套件的全新定价方案，起价9.99美元。具体订阅方案如下：

+   标准版：每月9.99美元，可生成20个视频。

+   专业版：每月29.99美元，可生成70个视频。

此外，`Firefly`新增了音频翻译和口型同步功能、3D场景参考生成功能，并加强了与其他`Adobe`平台的集成能力，为用户提供更强大的创作支持。
