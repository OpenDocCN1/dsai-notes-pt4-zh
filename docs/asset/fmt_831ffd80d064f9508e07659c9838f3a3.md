
# Anthropic 与 Claude Code 发布会纪要

## Claude Code 演示

- Claude Code 首先创建了一个待办事项列表 (to-do list) 来规划整个问题。
- 开始探索代码库，从当前打开的文件获取上下文。
- IDE 集成允许内联查看 `diff`，方便接受或提供反馈。
- 可以选择逐个批准编辑，或使用自动接受模式。
- Claude Code 工作了 90 分钟（演示为加速版），完成了任务。
- 添加了表格功能，编写了测试来验证更改，并迭代直到 `lint` 和测试通过。
- 演示了在本地运行 Excalidraw，新表格组件功能正常（创建 3x3 表格、重新定位、拖拽调整大小、改变边框图案和颜色、添加文本到单元格）。
- 这个复杂任务仅通过一个提示在 Claude Code 中完成。

## GitHub 集成演示

- 使用 `GitHub CLI` 为刚才的更改创建 PR。
- 通过在 PR 评论中 @Claude，要求其更新文档。
- 这会触发一个运行 Claude Code 的 GitHub Action。
- Claude Code 会在 PR 中评论其工作进展，并在完成后提交 `commit`。
- 同样可以在 GitHub Issue 中 @Claude 来创建 PR。

## 总结

- Claude Code 现已在所有常用开发场景可用：终端、远程环境（如 GitHub）、IDE。
- 无论是交互式使用还是异步使用，它都是一个多功能的编码 Agent。

## Michael Gersenhaber：Anthropic 平台赋能 Agent

- **自我介绍**：Michael Gersenhaber，API 平台产品负责人。
- **AI 生成代码的普及**：提问现场多少人使用 AI 生成代码（几乎所有人），多少人其应用核心功能由 AI 驱动（几乎所有人）。
- **平台愿景**：
  - 世界上大多数应用将由已在解决世界问题的人构建。
  - 无论经验如何，我们都是软件工程师。
  - 编写代码只是开始，还需要快速构建稳定、安全、可维护的 AI 应用。
- **Anthropic 平台**：一个完整的工具包，用于构建顶尖的 AI 应用和 Agent，已为全球各领域 AI 交付提供动力。
- **案例**：
  - 金融：TurboTax 帮助数百万客户通过联邦税务解释器自信报税。
  - 医疗：诺和诺德使用 Claude 在不到 10 分钟内起草临床研究报告（而非 15 周）。
  - 编码：世界上最好的编码助手运行在 Anthropic 平台。
- **平台核心**：
  - **模型推理服务**：通过 `Messages API` 可靠访问 Claude。
  - **基础工具**：如提示缓存，优化性能和成本（超过 50% 的输入 `token` 被缓存）。Notion 案例：利用此功能在保持快速响应的同时处理大量上下文。
  - **提示缓存 `TTL` 延长**：从 5 分钟延长到 1 小时。
  - **构建 Agent 的强大基石**：
    - 文件 API (`Files API`)。
    - 代码执行工具 (`Code Execution Tool`)：让 Agent 能在生产环境中编写并运行自己的代码。
  - **平台组件的组合性**：
    - 这些不是孤立功能，而是可以协同工作的构建块。
    - Claude 如同 Agent 的架构师和总包商，智能地决定需要哪些“材料”（工具）、以何种顺序、如何组合，以创造远超单个元素能力的作品。
  - **示例：复杂金融分析 Agent**：
    - 使用 `MCP` 访问财务数据。
    - 启动代码执行进行统计分析。
    - 搜索网络获取实时市场数据。
    - 使用引用 (`citations`) 来确保准确性和合规性。
    - 根据结果进行迭代和优化。
  - **开发者工具**：
    - 提示改进器 (`Prompt Improver`) 和 评估 (`Evaluations`)。
    - 新的可观察性 (`Observability`) 特性，帮助更快投产和扩展。
  - **`Cookbooks` 和指南**：展示如何实现记忆等功能。
  - 未来将为这些功能提供编程式访问，并直接托管在平台上。
- **核心目标**：帮助开发者更快交付更好的 AI。Anthropic 平台是构建行业领先 Agent 的路径。

## Mario Rodriguez (GitHub)：深化与 Anthropic 的合作

- **感谢与开场**：很高兴来到这里，分享 GitHub 与 Anthropic 之间不断深化的合作。
- **GitHub 的核心信念**：
  1. 为开发者提供选择。
  2. 为开发者提供最佳体验。
- **合作回顾**：
  - 去年 GitHub Universe 上宣布了与 Anthropic 的合作，将 Claude Sonnet 3.5 支持引入 VS Code 和对话式体验中。
- **重大宣布**：
  - `GitHub Copilot` 现已支持 `Claude Sonnet 4` 和 `Claude Opus 4`！（Dario 宣布后已立即上线）。
- **未来展望：Agentic 编码**：
  - 代码的未来是 Agentic 的。
  - `VS Code` 中的 Agent 模式是自主的结对编程伙伴，能基于自然语言指令执行多步编码任务。
  - 亲身体验到 Claude 智能直接嵌入编辑器如何帮助开发者理解复杂代码库、更快编码、提高生产力，且无需离开熟悉环境。
  - **单线程 vs 多线程**：当前的编辑器内体验仍是单线程的，未来是多线程的。开发者在编辑器中应如同身处等候室，工作在后台进行。
  - `GitHub Copilot` 编码 Agent：
    - 周一宣布的，是自主、异步的“同行程序员”（peer programmer），直接嵌入 GitHub。
    - 目前由 `Claude Sonnet` 驱动。
    - 选择原因：`Claude` 展示了强大的软件工程和编码知识、强大的问题解决能力（找到正确位置进行编辑）、出色的指令遵循能力（尤其在工具使用和 `MCP` 方面）。
    - `Anthropic API` 提供的提示缓存极大帮助他们以经济高效的方式构建这些体验。
  - **AI 原生平台**：
    - GitHub 正在从 `AI-infused` 平台转变为 `AI-native` 平台。
    - 覆盖从创建到部署的整个软件开发生命周期 (`SDLC`)，其上层是一个 Agentic 层。
    - 开发者将成为积极的协作者，人类处于中心地位（`Copilot` 的 `Co` 代表此意）。
    - 与 Anthropic 持续合作：
      - 通过 `Claude Code SDK`（Kat 演示的）将 `Claude Code` 和强大的 `Claude Code SDK` 直接集成到 GitHub 的 Agentic 平台中。
      - 为定制 `Claude Code`、从 GitHub 内的新界面远程调用等开辟了新可能性。
- **总结**：对双方合作以及为开发者带来的成果感到兴奋。

## Mike Krieger 与 Dario Amodei 炉边谈话/Q&A

- **感谢各位讲者**：Mario, Michael, Kat。Mike 对 GitHub 集成表示喜爱。
- **深入 Claude 4**：
  - **研究方向与开发者期望**：讨论 `Claude 4` 的研究方向，以及开发者对 Anthropic 的下一步期望。
- **Dario 谈可解释性的紧迫性**：
  - 抽象来看，每次发布新级别的模型，能做的事情就更多。
  - 坚信 `Claude 4` 之后还会有 `Claude 4.1` 等，就像 `Sonnet 3.5` -> `Sonnet 4` 的迭代。
  - AI 能做的事情的边界在不断扩展。
  - **任务自主性**：模型自主工作的能力将远超目前。让模型自由运行并赋予其完成任务的能力。
  - **网络安全任务**：对此领域非常兴奋，可以看作是更高级的编码任务。
  - **生物医学和科学研究**：`Opus` 在这方面尤其强大。
  - **`Machines of Loving Grace`** (`Dario` 的文章)：`Dario` 曾写道希望这成为产品路线图，现在正在实现。
  - **模型的"涌现"时刻**：模型开发过程并非完全线性，有时在最后阶段能力才真正整合和显现。这可能与模型与人类的互动、最终调整或人们逐渐习惯如何提示有关。
  - **可解释性与神经科学的相互启发**：
    - 最初认为神经科学能指导 `AI`，但实际启发有限。
    - 反过来，可解释性研究中发现的模型内部模式（如视觉模型中高低频检测器的分离）有时会在神经科学中得到验证或启发。
    - 核心理念：世界存在固有的结构，无论是人工还是生物学习系统，都可能发现这些相同的结构。
  - **未来 5-10 年展望**：
    - 10 亿美元市值、1 名员工的公司何时出现？`Dario`: 2026 年。
    - 给使用 `Claude` 构建应用的开发者的建议：
    - `Dario`：“保持雄心 (`Be ambitious`)。” 构建超出当前认为可能的东西。即使现在模型做不到，下一代模型（可能 3 个月、2 个月甚至 1 个月后）就可能做到。提前布局，即使“碰壁”也是有益的，因为这让你准备好了所有其他部分。
  - **Mike 总结**：在先进研究中也看到类似情况，研究团队可能早已构建了原型，等待模型能力跟上。
  - **结束语与特别感谢**：
    - **特别福利**：所有现场参会者将获得 `Anthropic` 最高级别套餐 `Max 20X` 的三个月免费使用权。
    - 期待看到大家用 `Claude` 构建的应用。
