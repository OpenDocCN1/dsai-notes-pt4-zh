# 五、常见问题

**Q: 哪些工具免费？**

A: 即梦、可灵、Pika、Suno都有免费额度。

**Q: 哪些工具国内可用？**

A: 即梦、可灵、网易天音都国内直连。

**Q: 新手从哪个开始？**

A: 做图 → 即梦；做视频 → 可灵；做音乐 → Suno

**Q: 效果最好的是哪个？**

A: 做图 → Midjourney；做视频 → Seedance / VEO3；做音乐 → Suno

**Q: Stable Diffusion还值得用吗？**

A: 不推荐了，已经过时，有更好的替代品。
