
| 方案 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- |
| AWS Secrets Manager | 与AWS生态深度集成 | 仅限AWS | AWS用户 |
| HashiCorp Vault | 跨平台、功能强大 | 需要额外维护 | 多云环境 |
| Azure Key Vault | 与Azure集成良好 | 仅限Azure | Azure用户 |

### 1.3 密钥轮换自动化

**自动轮换流程**：

```
检查密钥过期 (90天)
       ↓
生成新密钥
       ↓
存储到Vault（备份旧密钥）
       ↓
更新所有服务（Kubernetes滚动更新）
       ↓
等待5分钟观察
       ↓
验证新密钥
       ↓
成功 → 撤销旧密钥 → 通知成功
失败 → 回滚到旧密钥 → 告警通知
```
