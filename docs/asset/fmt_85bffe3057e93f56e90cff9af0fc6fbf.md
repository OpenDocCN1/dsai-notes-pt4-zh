
# AigcPanel

AigcPanel是一款革命性的AI数字人系统，旨在简化用户的环境配置，使得视频合成和声音合成变得更加容易。用户只需下载一个安装包，即可实现开箱即用的体验，告别繁琐的设置过程。其强大的功能包括视频生成、声音合成和声音克隆，适用于多种操作系统，并且支持中英文界面，完全开源，便于用户个性化定制。
