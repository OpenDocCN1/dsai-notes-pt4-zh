### 组合结构代码节点 (`175205`)

- **描述**：编写代码，处理输入变量来生成返回值
- **标题**：组合结构
- **节点类型**：`5`
- **输入参数**：
  - `times`: 来源：节点 `190452` 的 `outputList`
  - `image`: 来源：节点 `186729` 的 `data`
  - `texts`: 来源：节点 `116278` 的 `textList`
  - `aduio_urls`: 来源：节点 `186289` 的 `Group1`
  - `width`: `1920`
  - `height`: `1080`
- **输出**：`captions`、`imgs`、`audios`

```python
import json
async def main(args: Args) -> Output:
    params = args.params
    times = params['times']
    image = params['image']
    texts = params['texts']
    aduio_urls = params['aduio_urls']
    width = params['width']
    height = params['height']

    captions = []
    imgs = []
    audios = []

    # 处理图片的缝隙
    img_start = 0
    draft_end = 0
    for index, element in enumerate(texts):
        start = img_start
        end = int(img_start + int(times[index]['duration'] * 1000000))

        audios.append({
            "audio_url": aduio_urls[index]['data']['link'],
            "duration": int(times[index]['duration'] * 1000000),
            "start": start,
            "end": end
        })

        captions.append({
            'text': element,
            'start': start,
            'end': end,
            "in_animation": "渐显"
        })
        if start > img_start:
            start = img_start
        img_start = end
        draft_end = end
    #背景图
    imgs.append({
            "image_url": image,
            "width": width,
            "height": height,
            "start": 0,
            "end": draft_end
        })
    # 构建输出对象
    ret = {
        "captions": json.dumps(captions),
        "imgs": json.dumps(imgs),
        "audios": json.dumps(audios)
    }

    return ret
```
