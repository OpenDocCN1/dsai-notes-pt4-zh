2.  **顾客计件费**：6-8元/件，100件/天，收入250元。
3.  **衍生业务**：社区团购等，月入2000，年入2万。

### 📊 营收预期

+   **平淡年**：营收20万，利润14万。
+   **业务熟**：第二年利润可达16万。
+   **业务翻倍**：年利润可达35万，但需更多人工。

### 🏢 选址与运营

+   **选址**：入住率高的成熟小区，年轻人多更佳。
+   **营业时间**：12小时，需雇人，年成本7万。
+   **社区团购**：销售额10%，月入2000。

### 🚨 风险提示

+   **竞争**：与快递公司关系不好，可能被竞争对手取代。
+   **巨头竞争**：如杭州马的鸟站，数据整合优势，小驿站难以抗衡。

### 📉 行业现状

+   **派件费降低**：有的地方降至两三毛。
+   **人工成本**：全年无休，人工成本高。
