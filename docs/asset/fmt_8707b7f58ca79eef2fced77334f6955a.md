# 实现简单的检索增强生成（RAG）

### 引言

大语言模型（LLM）虽然知识渊博，但其知识通常截止于训练时间点，并且无法访问私有或实时更新的信息。检索增强生成（Retrieval-Augmented Generation，RAG）是一种强大的技术，旨在解决这个问题。RAG 通过结合信息检索（Retrieval）和文本生成（Generation），让 LLM 能够基于从外部知识库检索到的相关信息来回答问题或生成内容。这不仅提高了回答的准确性和时效性，还能有效减少模型的“幻觉”现象，并允许模型利用特定的、非公开的数据。

在本场景中，我们将构建一个非常基础的 RAG 流程：

1. 创建一个小型的本地“知识库”（几段文本）。
2. 使用 `AOAI Embeddings API`（`text-embedding-ada-002`）将知识库内容和用户问题转换为向量。
3. 通过计算向量相似度，从知识库中“检索”出与问题最相关的信息片段。
4. 将用户问题和检索到的信息片段一起“增强”输入提示，发送给 `AOAI Chat API`（`gpt-4o-mini`）。
5. 由 AOAI 模型根据提供的信息生成最终的、有依据的回答。

### 前提条件

+ **API Keys：**

  + AOAI API Key（用于 Embeddings 和 Chat Completion）：环境变量 `AOAI_API_KEY`。

+ **Python 库：**

  + `openai`：用于调用 AOAI 的 API。（`pip install openai`）
  + `numpy`：用于向量计算（余弦相似度）。（`pip install numpy`）

### 核心 RAG 流程

1. 嵌入知识库（Embed Knowledge Base）：将知识库中的每个文本块转换为向量。
2. 嵌入查询（Embed Query）：将用户的查询文本转换为向量。
3. 检索（Retrieve）：计算查询向量与知识库中所有向量的相似度，找出最相似（最相关）的文本块。
4. 增强（Augment）：构建一个新的提示，包含原始查询和检索到的相关文本块，并指示模型基于该文本块回答。
5. 生成（Generate）：将增强后的提示发送给 LLM（AOAI Chat）获取最终答案。
