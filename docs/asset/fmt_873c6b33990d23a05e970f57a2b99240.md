
# 20251221-谷歌最牛的两个AI产品打通了！这才是AI该有的样子

> 来源：[https://aigcreative.feishu.cn/docx/QkpYdMV51oToZNxvrp2cypJInbf](https://aigcreative.feishu.cn/docx/QkpYdMV51oToZNxvrp2cypJInbf)

![](img/bb93a1600ac482571dcfd6cd09175466.png)

大家好，我是创意猎人。

今天想跟大家聊聊谷歌的两个王牌产品：Gemini与NotebookLM，刚推出的两个新功能。

说实话，这次更新如果不是特意去翻日志，很多人可能直接就滑过去了。它没有那种特别炸裂的演示视频，也没有什么惊天动地的参数突破，但作为一个天天趴在电脑前码字、整资料的人，我看完这两个改动，心里反而觉得特别踏实。

这就是那种你会默默点头，心想“嗯，终于改了，早该这样了”的功能。

简单说，这次谷歌主要是在它的NotebookLM和Gemini之间搭了一座桥，顺便给NotebookLM加了个做表的能力。

## 01.

我先说说第一个变化，也是我觉得最实用的一个：Gemini现在能直接读取NotebookLM里的笔记了。

以前的情况其实挺割裂的。

大家知道，NotebookLM是个好东西，我一直在推荐大家使用。我把它当成是一个专门读文档的阅读器，什么几十页的财报、晦涩的论文，扔进去它就能给我讲得头头是道。

但问题是，它是个封闭的屋子。我在这个屋子里整理好的思路、划好的重点，想拿到外面的Gemini里去用，去结合最新的网络信息写点东西，那就不行了，得手动搬运，复制粘贴搞得人很烦。

昨天我打开Gemini，发现在对话框那个平时用来传图片的加号里，多了一个NotebookLM的选项。

![](img/9bf8483478273f963d8e87c0e84a5257.png)

这一步打通，意义其实挺大的。

这意味着，我在NotebookLM里辛辛苦苦养的那些资料库，终于可以在Gemini这个更大的舞台上用了。

举个我自己的例子：

![](img/30f3659964ccc2f1bc28225daf0da26a.png)

我手里存了一堆关于AI行业发展的年度总结PDF报告，都放在NotebookLM里。以前我想写一篇关于“2025AI发展趋势报告”的文章，我得两头跑。

![](img/57a4eba508a6ab82fef7c9aff48bc5f8.png)

现在我在Gemini里，直接挂载那个笔记本，然后跟Gemini说：你结合我这些报告里的观点，帮我梳理一份：2025AI发展趋势报告。

![](img/a92d2642dc3006676867d3364192ca81.png)

这时候的Gemini，就不再是一个只会泛泛而谈的AI助手了，它更像是一个手里拿着我也读过的书、咱们有共同语言的搭档。

![](img/daa4836ee3e28d69291bb0d6bbb9af0d.png)

这种沟通效率的提升，是用过就能感觉到的顺滑。

再说说第二个更新，NotebookLM加了个Data Table，也就是输出数据表的功能。

![](img/7034e3d7d7872dd6e22b87160fd2a473.png)

这个功能怎么说呢，属于那种“雪中送炭”型的。

之前NotebookLM虽然能总结文本、输出PPT，但一旦涉及到数据对比，它吐出来的文字经常是混成一团的。

比如我丢进去一份阿里巴巴的2024年的财报：

![](img/1358e835657303c3ae3f9941dc55f387.png)

![](img/70551f02f685960ef870a175deb297ac.png)

现在有了Data Table，它能直接把数据抽出来，列个表。第一列是业务板块，第二列是平台/品牌，等等！几百页的财报的主要数据干货，一下子就提取出来了。

![](img/c209566b7a766ebc589519b6f4961484.png)

这就很直观了。对于那些经常要做竞品分析、或者需要从一堆乱七八糟的文档里抠数据的人来说，这功能能省不少在Excel里敲格子、做分析的时间。

## 02.

聊完功能，其实我更想聊聊这两个小改动背后，我看到的一些东西。

我觉得谷歌现在的思路变得很清晰，也很务实。它不再执着于去搞那些花里胡哨的炫技，而是开始琢磨怎么把手头这些散落的工具串起来，真正解决咱们工作流里的痛点。

![](img/d41504db5000be4442875988f5107531.png)

大家有没有发现，现在AI工具有个通病，就是“聊得很开心，干活很费劲”。因为AI大模型虽然知识渊博，但它不懂你的私人背景，也不懂你具体项目的上下文。

谷歌这波操作，其实是在构建一个很实在的个人知识体系。

NotebookLM就像是你的私人图书馆，或者是你的第二大脑。你把你信任的、经过筛选的、高质量的文档都存在里面。这里面的东西是准确的，是你认可的。

![](img/4424c348913a11e5b9603990cdc2f25f.png)

而Gemini就是那个聪明的办事员。

以前这个办事员进不去你的图书馆，只能在街上（互联网）瞎打听。现在谷歌给了这个办事员一把钥匙。当你需要干活的时候，你让Gemini拿着钥匙进图书馆查资料，查完了再结合外面的新鲜事，给你交付结果。

这种配合，既解决了大模型容易胡说八道的“幻觉”问题，毕竟它是基于你给的文档在说话；又解决了传统文档管理死板的问题，毕竟Gemini能听懂人话，能灵活处理。

## 03.

从产品战略上看，谷歌这是在下一盘稳棋。

它没像OpenAI那样急着去推各种新奇的交互界面、应用，而是利用自己生态全的优势，把Google Drive、Docs、NotebookLM和Gemini全部打通。

![](img/1c483f7c654fe596509433bbdfa90d15.png)

这也给了我一点启发：对于咱们普通用户来说，未来的AI核心竞争力，可能不在于你用了多牛逼的模型，而在于你有没有建立起一套属于自己的、数字化的知识库。

因为模型大家都能用，那是通用的能力。

但你的NotebookLM里存了什么，你平时积累了多少高质量的行业认知，这才是你的护城河。

当AI能顺滑地调用你的这些积累时，它才能真正变成你的个人超级助理。

所以，别小看这次那个小小的加号按钮，它可能就是从“玩AI”到“用AI”的一个分水岭。

## 04.

我建议大家真的可以去试一下。

把你电脑里那些平时懒得看但又不得不存的文档，一股脑丢进NotebookLM里建个Notebook，然后去Gemini里调用一下试试。

哪怕只是让它帮你写个周报，或者整理个会议纪要，那种“它居然真的懂我意思”的感觉，还是挺不错的。

科技产品，最后还是得回归到好用、耐用上。

谷歌这次，我觉得路走宽了。

好了，关于这两个产品的新功能就先聊这么多。
