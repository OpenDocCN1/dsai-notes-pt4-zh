
# 模型训练参数配置

## 超参数说明

| `max_steps` | 最大训练步数 | 100 | 训练总步数。示例里设置为 100 步，通常需要调大。 |

| `learning_rate` | 学习率 | 2e-4 | 初始学习率，常见范围 1e-5 ~ 5e-4。中文推理链任务常用 2e-4。 |

| `optim` | 优化器 | "adamw_8bit" | 使用 8bit AdamW 优化器，显存更省。需要 bitsandbytes 支持。 |

| `weight_decay` | 权重衰减 | 0.01 | L2 正则化系数，有助于防止过拟合。 |

| `lr_scheduler_type` | 学习率调度策略 | "linear" | 学习率随训练进度线性下降，常见且稳定。 |

| `seed` | 随机种子 | 3407 | 保证实验可复现。 |

| `output_dir` | 输出目录 | "outputs" | 保存模型权重和检查点的路径。 |

| `report_to` | 日志工具 | "tensorboard" | 指定日志后端；这里启用 TensorBoard。 |

| `logging_dir` | 日志目录 | "./logs" | 存放日志文件的目录。 |

| `logging_strategy` | 日志记录策略 | "steps" | 按步数记录训练指标。 |

| `logging_steps` | 日志记录频率 | 1 | 每 1 步记录一次，便于实时观察训练过程。 |

## 推理示例

```
from transformers import TextStreamer

messages = [
    {"role": "system", "content": "reasoning language: 简体中文\n\n"},
    {"role": "user", "content": "你好，好久不见，请介绍下你自己！"},
]
inputs = tokenizer.apply_chat_template(
    messages,
    add_generation_prompt = True,
    return_tensors = "pt",
    return_dict = True,
    reasoning_effort = "low", 
).to(model.device)

_ = model.generate(**inputs, max_new_tokens = 1024, streamer = TextStreamer(tokenizer))
```
