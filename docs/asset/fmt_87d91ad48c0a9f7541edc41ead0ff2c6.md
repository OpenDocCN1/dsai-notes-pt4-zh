
# MCP 和 AI 知识库的对比

> 来源：`https://qianniucity.feishu.cn/docx/WFmbdqqLvoEC6kxY6v8cjZOYnJe`

> LLM + 知识库 和 Anthropic MCP 都是为了增强 LLM 的能力，但它们在连接方式、知识库类型、上下文管理和 AI 代理支持等方面存在一些关键区别。MCP 提供了一种更标准化、更灵活、更强大的方式来连接 LLM 和外部数据源，并支持更复杂的 AI 应用场景。

## 打个比方

假设 LLM 是一位厨师，知识库是各种食材。

+ **LLM + 知识库：** 就像厨师需要自己去市场购买食材，并将食材进行处理和加工，才能烹饪出美味的菜肴。

+ **Anthropic MCP：** 就像厨师可以通过一个 "智能厨房系统" 直接获取所需的食材，并自动完成食材的处理和加工，从而更专注于烹饪本身。

## LLM + 知识库 的常见实现方式

1. 将知识库嵌入到 LLM 的 `prompt` 中：将部分知识库内容作为上下文信息添加到 LLM 的 `prompt` 中，引导 LLM 生成更准确的回答。这种方法适用于知识库内容较少的情况。

2. 使用向量数据库：将知识库内容转换成向量表示，存储在向量数据库中。当用户提问时，将问题也转换成向量，并在向量数据库中搜索语义相似的知识片段，然后将这些知识片段作为上下文信息提供给 LLM。

3. 使用搜索引擎：将知识库内容索引到搜索引擎中。当用户提问时，使用搜索引擎检索相关的知识片段，并将这些知识片段提供给 LLM。

## LLM + 知识库 与 Anthropic MCP 的区别

虽然 LLM + 知识库 可以实现类似的功能，但 Anthropic MCP 在以下方面具有一些优势：

1. 标准化：MCP 提供了一个通用的标准，用于将 LLM 连接到各种数据源，而 LLM + 知识库 的实现方式通常比较 ad-hoc，缺乏统一的标准。

2. 灵活性：MCP 支持连接到各种类型的数据源，包括代码库、数据库、API 等，而 LLM + 知识库 通常更侧重于文本类型的知识库。

3. 上下文感知：MCP 可以更好地维护上下文信息，例如在多轮对话中记住之前的交互历史，而 LLM + 知识库 在这方面可能存在局限性。

4. AI 代理支持：MCP 支持开发能够代表用户执行任务的 AI 代理，而 LLM + 知识库 通常更侧重于问答和信息检索。

总的来说，Anthropic MCP 可以视为 LLM + 知识库 的一种更高级的形态，它简化了 LLM 访问和利用外部知识的过程，并为构建更复杂的 AI 应用提供了基础。
