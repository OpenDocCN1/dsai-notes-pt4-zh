## 2️⃣ 🔮 [谈谈DeepSeek `Engram`](https://mp.weixin.qq.com/s/L7YawzhHCACBQsiEb7w-Tw)：Conditional Memory

`DeepSeek` 提出 `Engram` 条件记忆范式，与 `MoE` 条件计算形成对偶，分离静态知识检索与动态推理，解放 `FFN` 专注复杂任务。

架构采用哈希 `N-gram` 检索（分词压缩+多头哈希）、上下文门控融合静态知识与动态上下文，多分支设计增强适应性。

稀疏性分配发现U形定律：混合 `MoE`（75-80%）与 `Engram`（20-25%）参数最优，`Engram` 内存规模与性能呈幂律关系。

有效加深网络：早期层注入 `Engram` 加速预测收敛，长上下文任务释放注意力资源，性能显著优于 `MoE` 基线。

系统效率优化：确定性检索支持内存卸载（CPU DRAM/NVMe），预取与计算重叠，吞吐量损失可忽略。

### 关键词

`Engram`，条件记忆，`MoE`，稀疏性分配，长上下文

## 3️⃣ 🎯 吴恩达开新课教OCR！用Agent搞定文...

🎯 吴恩达推出新课《Document AI: From OCR to Agentic Doc Extraction》，介绍智能体文档提取（`ADE`）方案，其在 `DocVQA` 基准测试准确率达99.15%，还涵盖本地代码运行与 `AWS` 部署指南。

🔥 2025年后 `OCR` 重回技术专项，`DeepSeek`、智谱、阿里千问、腾讯混元等大厂密集更新 `OCR` 技术，如 `DeepSeek-OCR` 的视觉压缩、腾讯 `HunyuanOCR` 开源等。

🧠 `ADE` 方案解决传统 `OCR`（如 `Tesseract`、`PaddleOCR`）压平文档丢失结构信息的问题，通过三大支柱（视觉优先、数据为中心、智能体化）提升效果。

📊 `ADE` 搭载 `DPT` 模型，可精准解析巨型表格、手写公式、弯曲印章证书等复杂文档，还引入视觉接地技术实现数据块溯源。

☁️ 课程提供 `AWS` 部署全流程，能自动将 `S3` 存储的 `PDF` 解析为结构化 `Markdown`，结合知识库与智能体做成行业知识助手。
