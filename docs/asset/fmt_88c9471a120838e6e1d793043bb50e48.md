
# 首例数据出境安全评估获批的讨论

> 来源：[https://docs.feishu.cn/docx/EWwEdNEJ3obHorxH58ocIxd5nhb](https://docs.feishu.cn/docx/EWwEdNEJ3obHorxH58ocIxd5nhb)

**-问：**大家怎么看：全国首个获批数据出境安全评估案例落地北京？

**-答1：**北京总共只交了16份，10家完成完备性审核，数量还是比较少。

**-答2：**好奇国航项目里面的数据接收方是谁。

**-答3：**也许是国航境外分支机构。

**-答5：**或许可以看看他的隐私政策。

> 您的数据可能由在您的所在国家以外工作的国航员工处理。我们的服务提供商也参与了那些数据的处理，他们与国航一起，共同提供网络预定引擎服务、电脑预定系统服务、在线支付管理服务以及电子邮件服务。

![](img/4dd3a25ebb31734d13c423dde2703605.png)

**-答6：**是不是类似在国外转机，在国航订票需要把客户信息给到国外的航司。以及还有境外对入境人员的检查？

**-答7：**那在转机场景下，域外法该写哪个国家呢，感觉全球都要写了。还有在转移的风险。拿隐私政策中的美国政府举例，他们会配合签数据协议吗，真是头大。他们的数据保护能力也不好填。

**-答6：**之前做过类似的调研，好像机票的PNR（passage name record）一般会共享到第三国。比如美国那边要求运营往返美国或者途径美国的航空公司要向国土安全部和海关和边境管理局提供PNR。目前实践不知，反正美国与欧盟的实践就是签订专门的PNR协议来确定对方的安全保障能力符合相关的规定。

**-答7：**这种专项领域数据跨境传输 按理说ICAO/IATA这种国际组织应该介入协调吧。
