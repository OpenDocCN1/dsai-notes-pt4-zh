# 分享输出

## 「交个朋友」分享

首先是「交个朋友」的嘉宾，现场分享的是直播行业的协作。

在没有听这种分享之前，小编可能在想，直播行业好像更多的是在镜头面前做展示，那为什么直播行业会需要用到多维表来协作呢？

一番输入之后，才发现原来直播背后需要这么多的东西去支撑。一场大型的直播，需要至少提前一个月，就先把主题定好，然后接下来就需要商务老师去完成一个招商的动作。其中还有一个重要环节是选品，选品的好坏，能否上架，这些数据都需要有地方来存放。而类似这样的数据存放等操作，就用到了飞书多维表来处理。

多维表解决了这家企业的几个痛点：

+ 协作问题 —— 每个员工都能及时看到目前整场直播的一些相关数据，包括新增的、减少的品类等等，一人修改，即能做到多端同步，确保了信息的及时性。不再像以前excel那样，修改完excel的数据后，还要发到各个群同步，每个人手上拿到的版本还有可能不一样。

+ 权限问题 —— 一般来说，整场活动的所有数据里，总有一些数据是敏感的，这些数据可能只能给部分人看，而部分人不能看。而多维表格的高级权限，就做到了这个功能。只需简单的配置操作，就可以短时间做到：合适的数据，分享给组织内合适的人。

+ 通知问题 —— 比方说开播前要临时加个品或者调了个品，那这个时候就需要去通知到上下游的协作人员。这个事情换在以前，可能需要每个协作人员打电话通知过去。而这件现在，就交给了飞书多维表的自动化来处理。

后面嘉宾还聊到了用`飞书集成平台`和`飞书开发平台`去处理更复杂的自动化和权限问题。一番听下来，小编有一种乡下人出来见世面的感觉。最后，再对这一趴做个小小的总结收尾：直播领域里有这么多好玩的东西可以探索，而协作平台去结合直播领域里的各种场景，碰撞出来的火花，更是动人心弦。

## 「联影医疗」分享

第二位分享的是「联影医疗」的运营小姐姐。嘉宾分享了他们用多维表解决了这家企业目前存在的三个问题，如下所示。

### 1️⃣从无到有 —— 解决系统缺失造成的难题（销售临床应用培训部）

当大型医疗设备在交付给医院之后，需要企业培训部的老师到现场给医院的医生、物理师还有技师做技能培训，帮助用户更好地将设备系统投入到临床使用。而在这个过程中，并不是每个环节都非常顺利的。

比如：可能会遇到`医院A`原本定这个月让企业去装机器，那企业的员工可能就申请了这个月出差。申请完了之后，医院A突然说院内的人力安排不过来，这个月没法装机了。对「联影医疗」而言，这意味着需要重新安排人力资源，并对现有存在问题进行复盘和调整。

而多维表格就帮企业在这一部分做到了提效赋能，以前可能临时出现个紧急情况，得一级一级地传递下去。而现在，则只需要及时更新多维表里面的状态，管理者就可以及时知道目前可能遇到的情况，及时做好人力分配和下一步的计划。

### 2️⃣从有到精 —— 解决大型系统触达不到的细枝末节（生产管理部）

生产管理部有一个`MES系统`，MES系统可以理解为是ERP的下游系统。然而，由于业务的复杂性，生产磁体的周期可能长达1.5个月，甚至更长的可能需要三四个月。在生产过程中，很多工序状态都难以准确把控。例如，是否能确保某个环境的温度始终适宜，或某次操作后磁体的性能是否达标。此外，当出现问题时，很难追溯到具体是哪一个员工的操作导致的。

那生产管理部当前面临的主要问题就包括这三点👇🏻：

+ 系统的排期过于宽泛，导致过程中的质量难以掌控。

+ 员工的工作效率难以统计和评估。

+ 当发生事故时，责任的追踪和定位变得困难。

针对上述情况，「联影医疗」通过多维表格的流程自动化、附件上传等功能来解决了此类问题。

例如，当产线出现问题时，工人可以直接使用手机拍照图片并上传多维表格，通过自动化及时通知到对应负责人。如果`xxxmin`内没有被响应，会加急到该员工的`+1`或`+2`上级，及时通知到相关人员来解决产线问题。

最后做个小小的总结：这家企业通过多维表格，做到了所有环节效率透明化、数据分析实时化。通过更精细化的管理，赋能更高维度的生产，然后促进产线流程质量大幅度的改善，达到正循环的效果。
