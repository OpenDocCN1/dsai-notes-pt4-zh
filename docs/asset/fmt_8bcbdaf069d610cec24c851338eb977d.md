# 1、认识 DeepSeek

## 1.1 DeepSeek 简介

DeepSeek（深度求索）是一家专注于开发先进大语言模型及相关技术的创新型科技公司，成立于2023年7月。

它由国内知名量化资管公司幻方量化创立，以低成本、高性能的大语言模型技术迅速崛起。

DeepSeek的核心优势在于其强大的硬件资源和技术积累，是“大厂外唯一储备万张A100芯片”的公司。

DeepSeek的技术以创新和高效著称，其模型架构如MLA（多头潜在注意力机制）和DeepSeekMoE架构等，大幅降低了显存占用和计算量。

2024年5月发布的DeepSeek-V2模型，凭借创新架构和极低的API定价（每百万tokens输入1元、输出2元，仅为OpenAI GPT-4 Turbo的百分之一）引发行业关注。

2025年1月，DeepSeek发布的DeepSeek-R1模型进一步提升了性能。

DeepSeek坚持开源路线，主动向全球开发者分享核心技术成果，推动人工智能的普惠发展。其创始人梁文锋强调原创式创新，主张通过开源生态和技术沉淀构建护城河。

## 1.2 三种模式：快速问答、深度思考和联网搜索

**快速问答（V3）** DeepSeek-V3 为自研 MoE 模型，671B 参数，激活 37B，在 14.8T token 上进行了预训练。DeepSeek-V3 多项评测成绩超越了 Qwen2.5-72B 和 Llama-3.1-405B 等其他开源模型，并在性能上和世界顶尖的闭源模型 GPT-4o 以及 Claude-3.5-Sonnet 不分伯仲。

处理**规范性**的任务时，用 V3 比较合适。比如，写会议纪要文件，这种内容的格式一般相对固定，只需要填充内容即可，那么使用 V3 模型辅助，效率更高。

**深度思考（R1）** 是DeepSeek的一个高级推理模式，专门用于处理复杂的逻辑推理、数理分析、编程代码等需要深度思考的问题。它通过多步骤的链式推理，展示详细的思维过程，帮助用户理解AI是如何逐步解决问题的。这种模式适合需要深入分析和多维度解答的复杂问题，例如解决数学难题、分析技术趋势等。

• 特点：回答更准确、全面，逻辑性更强；用户可以观察AI的思考过程，增加对AI的理解和信任；适合需要深入分析的复杂问题。

联网搜索是DeepSeek的AI搜索功能，基于RAG（检索增强生成）技术。开启联网搜索后，DeepSeek不仅依赖预训练的知识库，还能实时从互联网上检索最新信息，从而提供更全面、准确的答案。这种模式特别适合回答2023 年之后的最新事件、实时新闻、新兴技术等问题。

• 特点：能结合网络信息，提供最新、全面的答案；适合需要最新信息的复杂问题，如实时新闻、最新政策；回答速度相对较慢，因为需要联网检索。

使用场景

**快速问答**（V3）：不需要自由联想，适合处理规范性的任务，比如写会议纪要等。

深度思考（R1）：适合需要深度分析和逻辑推理的复杂问题，例如解决数学难题、分析技术趋势。

联网搜索：适合需要最新信息的问题，例如实时新闻、最新政策、新兴技术等。

注意事项

深度思考模式适合复杂问题，但可能需要更多时间来生成答案。

联网搜索需要网络连接，且回答速度可能因网络状况而异。

> 注：同时开深度思考和联网搜索，按现在的算力，基本上就是服务器繁忙，所以建议可以开一项。
