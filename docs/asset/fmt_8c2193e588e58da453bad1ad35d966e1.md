## 配置示例

```
api_base = "https://api.deepseek.com"
api_key = "YOUR_DEEPSEEK_API_KEY"
```

## 调用示例

```
# 使用 LiteLLM 调用 DeepSeek 模型
response = completion(
    model="deepseek/deepseek-chat",  
    messages=[{"role": "user", "content": "你好，好久不见！"}],
    api_base=api_base,
    api_key=api_key
)
```

## 输出示例

```
print(response)
```
