
# 从密集到稀疏

对于需要混合专家模型（`MoE`）训练的场景，可以利用现有的密集模型作为初始化基础，快速扩展到稀疏模型。`Sparse Upcycling`通过将密集模型的部分层替换为`MoE`层，实现了在相同计算资源下更高效的模型训练。

## 增强大模型智能：数学推理能力的提升策略与实践

https://zhuanlan.zhihu.com/p/717002127?utm_psn=1812276074937212929

大语言模型的训练过程可分为四个阶段：预训练、监督微调（`SFT`）、奖励模型训练以及人工反馈强化学习（`RLHF`）。预训练阶段是最为消耗资源的，通常需要大量`GPU`和长时间的训练。`SFT`阶段旨在优化模型的指令对齐能力。训练奖励模型和进行`RLHF`进一步增强模型在指令处理和人类偏好理解方面的能力。

为了增强模型的数学推理能力，构建了混合指令系统，其中逻辑推理通过思维链（`CoT`）模式处理，而复杂计算则采用程序思维（`PoT`）模式。为了补充数学数据的不足，采用了合成数据技术，通过自指令（`Self Instruct`）方法扩展高质量数学指令，并利用模型的多样性和质量筛选机制生成更广泛的训练数据。

在模型训练中，特别是在`RFT`（拒绝采样）阶段，通过较小参数模型如`LLaMA`生成和筛选推理路径，并通过`Reward Model`和`Critique Model`进行质量过滤和多样性选择，以提升模型的推理能力。`DPO`和`PPO`方法在优化模型表现时，也展示了其在处理复杂问题方面的潜力，尤其是在数学推理任务中。最终，通过动态`loss`加权方法，进一步提升了模型在处理难题时的表现。

## `SFT` 的局限性

https://zhuanlan.zhihu.com/p/717275921?utm_psn=1812771850553524224

1.  **缺乏负反馈机制**：`SFT` 的训练过程是基于条件概率的学习，模型只知道哪些 `token` 是正确的，但无法识别错误的 `token`。这导致模型可能会提高错误 `token` 的概率，因为它无法直接学习到这些 `token` 是错误的。这种缺乏负反馈机制的问题使得模型难以避免生成错误的结果。

2.  **单向注意力的局限性**：`SFT` 训练中，模型只能关注前面的 `token`，无法“向后看”。这放大了 `transformer` 结构的单向性缺陷，尤其在处理含有否定意义的句子时，模型可能会错误地增加错误 `token` 的概率，因为它无法利用句子后半部分的信息进行校正。而 `RLHF` 通过 `reward_model` 提供反馈，可以有效弥补这种局限性。

3.  **局部训练与全局优化的差异**：`SFT` 是一种局部的、有偏的训练方法，只关注每个 `token` 的局部信息，因此训练上限较低。而 `RLHF` 在更新每个 `token` 的概率时，考虑了整个句子的上下文信息，因而可以实现更高的训练上限。此外，`RLHF` 的损失函数是加权的，相较于 `SFT` 的平均损失，能够更精准地优化模型的表现。
