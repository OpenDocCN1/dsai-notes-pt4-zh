
# Agree和Consent的区别

> 来源：[https://docs.feishu.cn/docx/OxmEdEjwwooNv7xcbWacdvJ8nPh](https://docs.feishu.cn/docx/OxmEdEjwwooNv7xcbWacdvJ8nPh)

**- 问**：这个代销金融产品时的这个告知书，大家怎么看？

![](img/fe5097c6138e7791e0120e468be01620.png)

**- 答1：**三连问：

1.这里的所有信息收集使用都是基于“同意”么？

2.这样的一揽子告知能构成有效的“单独同意”么？

3.能允许用户逐一拒绝和撤回么？

**- 答2：**

1.不是，应该有**履行合同所必需和履行法定义务**；

2.取决于单独同意的**颗粒度**，感觉是业务和法务拉扯妥协的结果，但感觉比没做好，好歹对敏感个人信息和对外提供分别单独同意了；

3.在再代销金融产品的背景下，处理敏感信息和提供给管理人，其实都是履行合同所必需的，不然就别买了。上述三个问题其实指出了另一个问题，如果是其他合法性基础还走了`同意`的路径，那么就要提供撤回同意的渠道，等于给自己挖坑了。

**- 答3：**感觉是律师也业务妥协扯皮的结果，也能满足一些不是很专业和严苛的监管方要求。

**- 答4：**我觉得公示进个人信息授权书中，也并不必然会产生撤回权，这里还是要检视走的是哪一项合法性基础。除非授权书中对撤回权已经做了相应约定。我是觉得这里走的就是“合同”的基础，不过认为“同意”也有道理，他这个就是把个人信息处理部分单独摘出来了嘛。有些双保险的思路。

**- 答5：**是的，`同意`（`agree`）合同和`同意`（`consent`）处理个人信息是两种`同意`。如果有涉外业务，更是要特别区分。要是境外隐私律师听到这俩“同意”居然被当做是一回事儿，估计会夜半惊坐起，撞墙泣血痛心疾首。

**- 答6：**沿着这个思路谈些看法，欢迎同行指教。双保险用起来可能有风险，我当时在hr背调`consent` letter中加入了`同意`＋人力资源管理必需的双法律基础条款。如果企业在规章制度或者集体合同里没说明，那就走`同意`。这样对企业开展对候选人的背调工作方便一些。但由此产生的问题是：规章制度或集体合同里原本没有，后来另加这种背调目的就很不合适。另外就是当候选人行使撤回权时，我们的扯皮行为似乎有些不太合适。所以我觉得双保险条款可能不太符合个保法下第五条的诚信原则。

**- 答7**：虽然构成处理个人信息所需的“单独同意”很成问题，但这个页面中是把`同意`处理个人信息和`同意`服务合同设计为“分项勾选”的，这点还是有道理的。法务能坚持到这样也不容易了。

**- 答8：**高老师对此也有论述：**高富平**丨`同意`≠授权——个人信息处理的核心问题辨析。

**- 答9：**`eudic`找了个解析 `agree`的力度跟`consent`区别不小。

![](img/b94180b3869d8ee55e93d51771c4928e.png)

**- 答10：**是的，境外隐私领域律师（不仅是欧盟）很少会使用`agree`或把`agree`与`consent`混同。“同意”作为我国个保法领域的核心甚至基石范畴，某种程度上是个舶来品宝宝（不是从自合同法滥觞而来），可惜一经翻译就和“`agree`”无法区分了。当下很多对“同意”问题的误解都与对这个范畴的理解有千丝万缕的关联。

**- 答11：**“隐私政策”文件无论怎么写都是无法完成“单独同意”功能的，甚至“单独同意”就是用于打破“以隐私政策获得一揽子统一”。现在比较稳妥的方式还是单行告知文案+单独勾选+单项可撤回。但这个场景下，还是有空间走“法定义务”或合同必需——不过，但是，可是，有的监管方只认“同意”，对其他合法性基础默认忽略。

**- 答12：**境外数据隐私法中“同意”的发展历程已有很深的探讨。从欧美两地历程（分见Kosta，2013；Faden和Beauchamp，1986，等等）看，可见比起合同中的“同意”，数据隐私中的“同意”更接近医学和临床试验语境中基于主体自主性伦理的“同意”。尽管一直存在是否能够混同的争论，但“`Approval`”“`Authorization`”等说法渐渐变得少见。相应地，“时光机”般的争论正在国内发生，或大致对应于“同意”性质的意思表示说/违法阻却说/二者混合说的争论，似无定论（杨，2021的说法是“……既有区别又有联系”）。由于各地发展历程背后的深刻差异，这里可能不宜照搬、也无法照搬。再次➕1的是目前只有`同意`可能稍微体系化，其他合法性基础的具体解释和实践落地仍待进一步展开（实际上作为重要参照的`GDPR`也还没有完成各合法性基础的体系化，虽然或许可以说完成了大部分）。之外，对同一信息-处理交错援引不同合法性基础是否在高水平的视角下满足透明性等原则，也有讨论空间。
