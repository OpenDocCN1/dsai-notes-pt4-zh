
## 开启训练

### 预训练

```
xtuner train pretrain.py --deepspeed deepspeed_zero1
```

注意替换模型和数据集的位置分别位于23行27行

```
pretrained_model_name_or_path = './internlm2_5-1_8b-chat'

data_files = ['./datasets/pretrain.jsonl']
```
