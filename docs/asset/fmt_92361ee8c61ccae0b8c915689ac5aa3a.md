
# JinaURL Reader

JinaURL Reader 是 Jina AI 的 URL 读取服务的 Python 客户端，经过优化，可从 URL 提供更清晰、对 LLM 可读的内容。该 reader 提供一定额度的免费调用次数。无需注册 API 也可使用。

## 快速开始

```python
from camel.types.enums import JinaReturnFormat
from camel.loaders import JinaURLReader

jina_reader = JinaURLReader(return_format=JinaReturnFormat.MARKDOWN)

response = jina_reader.read_content("https://www.InternLM.cn/home")

print(response)
```
