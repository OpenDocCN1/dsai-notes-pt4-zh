## 使用别名简化命令

但这边有个不方便的地方，`python -m debugpy --listen 5678 --wait-for-client`这个命令太长了，每次都打很麻烦。这里我们可以给这段常用的命令设置一个别名。

在`linux`系统中，可以对 `~/.bashrc` 文件中添加以下命令

```
alias pyd=&#x27;python -m debugpy --wait-for-client --listen 5678&#x27;
```

然后执行

```
source ~/.bashrc
```

这样之后使用 `pyd` 命令(你可以自己命名) 替代 `python` 就能在命令行中起debug了，之前的debug命令就变成了

```
pyd ./myscript.py
```

如果是windows也可以在`powershell`中实现类似操作，但会比较繁琐

1. 确定配置文件的位置

首先，你需要知道`$PROFILE`变量存储的是当前`PowerShell`会话中可用的配置文件的路径。在`PowerShell`中，输入`$PROFILE`并按回车键，它会显示当前用户的配置文件路径（通常是`CurrentUserAllHosts`类型的配置文件路径）。

```
$PROFILE
```

输出可能类似于：

```
C:\Users\用户名\Documents\PowerShell\Microsoft.PowerShell_profile.ps1
```

1. 创建或编辑配置文件

如果`$PROFILE`显示的路径不存在（即配置文件尚未创建），你可以使用`New-Item`命令创建它。如果文件已经存在，你可以直接编辑它。

### 创建配置文件（如果尚不存在）

```
if (!(Test-Path -Path $PROFILE)) {  
    New-Item -ItemType File -Path $PROFILE -Force  
}
```

### 编辑配置文件

你可以使用任何文本编辑器来编辑配置文件。

这将在记事本中打开配置文件（如果文件已存在），或者创建一个新文件（如果文件不存在）。

1. 将命令添加到配置文件中

在打开的编辑器中，将以下命令添加到文件的末尾：

```
function pyd {  
    python -m debugpy --wait-for-client --listen 5678  
}
```

1. 保存并关闭配置文件

在编辑器中保存文件并关闭它。

1. 重启`PowerShell`

为了使更改生效，你需要重启`PowerShell`会话。关闭当前`PowerShell`窗口，并重新打开一个新的窗口。

1. 测试别名

在新的`PowerShell`会话中，输入`pyd`并按回车键，它应该执行`python -m debugpy --wait-for-client --listen 5678`命令。

通过以上步骤，你就成功地将特定命令添加到了`PowerShell`配置文件中，并创建了一个可以在每次启动`PowerShell`时使用的别名。
