## 对标怎么选择（该抄谁）

我在油管经常做的就是刷视频，刷新页面，因为会给你推荐不同的页面，我是在电脑端上面刷（我自己不太喜欢在手机端看油管，所以这里看每个人的习惯），先想好你要做哪个赛道，比如动物救援，达人秀，动物故事，还是山海经。不知道标签的，可以去赚钱里的航海手册去看，已经写的很全了。如果你懒不愿去看，那不好意思，我也帮不了你。

![](img/c839262c0216c9165986af560c0de5ab.png)

经常看shorts，在网页版也会给你推荐一些shorts。

接下来重点

当你刷到一篇看着流量高的shorts，点开看他是不是近期的爆款，比如我展示的这个就是3天前的一个视频，是个爆款

![](img/5a7c95f604c7868116ae620e68f62000.png)

![](img/9fe6a83f5355e986462827563929e66a.png)

再点开主页，看是不是近几个月内的新账号，因为越新，说明这个视频越是有爆款元素在里面，有的老帐号自带有流量，不具备抄的属性。

几个观察点：

1. 看注册时间：1个月内的为最佳对标（立刻跑步前进！），2个月次之，3个月的可以先关注。

1. 看视频数量：个位数的视频，条条都在百万以上

1. 看标签：点开他的标签看这些视频有没有和他相同的，发现这里面只有它或者比较少类似的就是可对标的。

1. 看是否开通`ypp`：开通的列为第一梯队，没开通的第二梯队

点进去一看就知道是不是一个类型的，这里看在前排的只有它一个，你可以再多刷一下，发现只有几个或者很少就可以作为你对标对象。

## 第一个版本

### 第一步：链接生文

把油管的链接粘贴给google ai studio

网站链接：`https://aistudio.google.com/prompts/new_chat`

然后粘贴这段提示词

```
根据这个视频出一个拉片笔记，列出视频中的每一个镜头，用能markdown表格输出（中文）。
你需要做一个excel表格，title和内容为镜头组、镜号、文生图描述词、图生视频描述词、剪辑建议（主要BGM识别、音效等）
文生图描述词原则：
用连贯的自然语言描述画面内容(主体+行为+环境等)
用文字描述还原所有切换画面后的第一针画面。
描述每一个镜头出现的角色人物的特征和穿着的颜色，保证主体的一致性，一定不要偷懒，例如：镜号1 一只成年白猫（穿着红色t恤黑色短裤）和一直白猫幼崽（穿着粉色尿布）
镜号2 一只成年白猫（穿着红色t恤黑色短裤）和一直白猫幼崽（穿着粉色尿布）
图转视频描述词原则：
（时长、景别，运镜，画面描述。）
景别：（远景、中景、特写等）
运镜：（推、拉、摇、移等）
画面分镜描述示例：（夜晚，云雾笼罩的古寺前，黑衣侠客与白衣侠客面对面抱拳站立，背后破损的屋檐挂着晃动的铜铃。镜头缓慢向前推进，展现紧张气氛。）
```

得到拉片笔记后可以对里面的元素进行替换，和进行一些调整，比如里面的人物的一致性

我会用这段提示词

```
把xx替换成xx
角色一致性: 为每个核心角色创建“一致性锚点”。例如：成年白猫A（昵称Tom，身穿红色印花T恤，黑色短裤，眼神慵懒），幼年白猫B（昵称Jerry，戴着粉色尿布，眼神好奇）。在后续所有镜头中，必须重复使用这个完整的描述，绝对不能偷懒，以确保 AI 识别为同一角色。
场景一致性: 同样地，对重要场景也要保持描述一致性。例如：杂乱但温馨的客厅，米色沙发，墙上挂着一幅抽象画。
语言风格: 使用连贯、生动的自然语言。
示例: 摄影杰作，电影质感，柔和的窗边光线下，一只成年白猫A（昵称Tom，身穿红色印花T恤，黑色短裤，眼神慵懒）正坐在米色沙发上，打了一个哈欠，它身边躺着一只幼年白猫B（昵称Jerry，戴着粉色尿布，眼神好奇），背景是杂乱但温馨的客厅。
```

温馨提示：更换里面的主体，变成自己的东西。我们用的是对标的框架而不是全部

## 第二个版本（文生图）

这是最近迭代的版本，发现第一个版本生成出来的效果只能达到爆款视频的60分

### 用Gemini ai studio做的爆款视频复刻提示词模板

把第二个版本生成出来的拉片笔记喂给Gemini，然后输入下面的提示词：

```
根据提供的拉片笔记写一个复刻爆款视频的拉片笔记提示词模板，要保证人物一致性
```

接着就是让ai根据这些规律给出爆款故事的提示词模板，有哪些缺失或者不满意的，再和ai交流，让它继续优化，我把自己用的提示词模板放在这里

```
角色
你是一位专业的影视导演兼 AI 咏唱大师（Prompt Engineer）。你的任务是为我提供一份极致详细的视频“拉片笔记”，这份笔记的最终目的是利用 AI 文生图（如 Midjourney, Stable Diffusion, 即梦）和图生视频（如 Runway, Pika, 可灵）工具，近乎 1:1 地复刻指定的油管视频。你的分析需要精确到每一帧的构图、每一秒的动态，并且输出的提示词必须是高效且能被 AI 工具准确理解的。
核心任务
分析下方提供的视频链接，产出一份 Markdown 表格格式的拉片笔记。你需要逐一拆解视频中的每一个镜头（以每一次画面切换为准）。
输出格式
请严格按照以下 Markdown 表格结构输出，所有内容使用中文：
镜头组        镜号        文生图描述词（第一帧画面）        图生视频描述词（镜头动态）        剪辑建议
各列填写规则（至关重要）
1. 镜头组 (Scene Group):
将属于同一场景、同一时间、同一地点的连续镜头划分为一个“镜头组”。
例如：“A段-清晨卧室”、“B段-街道追逐”。
2. 镜号 (Shot Number):
从 1 开始，按视频顺序为每一个镜头（每一次剪辑点）进行唯一编号。
3. 文生图描述词 (Text-to-Image Prompt):
核心原则: 精准描绘镜头切换后的 “第一帧” 画面，作为生成静态图的基础。
内容要素: 必须包含 [主体] + [主体特征/穿着] + [主体动作/姿态] + [环境/背景] + [光线/氛围] + [构图/画风]。
一致性:
角色一致性: 为每个核心角色创建“一致性锚点”。例如：成年白猫A（昵称Tom，身穿红色印花T恤，黑色短裤，眼神慵懒），幼年白猫B（昵称Jerry，戴着粉色尿布，眼神好奇）。在后续所有镜头中，必须重复使用这个完整的描述，绝对不能偷懒，以确保 AI 识别为同一角色。
场景一致性: 同样地，对重要场景也要保持描述一致性。例如：杂乱但温馨的客厅，米色沙发，墙上挂着一幅抽象画。
语言风格: 使用连贯、生动的自然语言。
示例: 摄影杰作，电影质感，柔和的窗边光线下，一只成年白猫A（昵称Tom，身穿红色印花T恤，黑色短裤，眼神慵懒）正坐在米色沙发上，打了一个哈欠，它身边躺着一只幼年白猫B（昵称Jerry，戴着粉色尿布，眼神好奇），背景是杂乱但温馨的客厅。
4. 图生视频描述词 (Image-to-Video Prompt):
核心原则: 基于“文生图”生成的静态画面，描述这个镜头内的 所有动态变化。
标准格式: 【时长】X秒。【景别】...。【运镜】...。【主体动作】...。【其他动态】...
景别 (Framing): 远景、全景、中景、近景、特写、大特写。
运镜 (Camera Movement):
固定镜头: 无运镜。
推 (Push-in): 镜头向前移动，靠近主体。
拉 (Pull-out): 镜头向后移动，远离主体。
摇 (Pan): 镜头在原地水平转动（左摇/右摇）。
移 (Truck/Dolly): 整个摄影机平行移动（左移/右移）。
升/降 (Crane/Pedestal): 整个摄影机垂直移动。
跟拍 (Follow Shot): 镜头跟随移动的主体。
旋转 (Roll) / 变焦 (Zoom) 等。
主体动作 (Subject Action): 详细描述画面中人物/动物/物体的具体动作。例如：成年白猫A从打哈欠变为缓慢地舔自己的爪子，幼年白猫B的耳朵动了一下，然后翻了个身。
其他动态 (Other Dynamics): 描述背景中的次要动态，如 窗帘被微风吹动，背景中电视屏幕在闪烁。
示例: 【时长】3秒。【景别】中景。【运镜】从右向左缓慢平移，最终聚焦在幼猫B上。【主体动作】成年白猫A保持舔爪子的动作，幼猫B翻身后，好奇地睁开眼睛看着镜头。【其他动态】背景中的一缕灰尘在光线中飘动。
5. 剪辑建议 (Editing Notes):
BGM: 识别背景音乐的风格、情绪和节奏。例如：轻快、俏皮的爵士钢琴曲，紧张、鼓点密集的电子乐。
音效 (SFX): 识别并描述关键音效。例如：猫打哈欠的声音、时钟滴答声、关门声。
人声 (VO/Dialog): 如果有画外音或对话，简要记录。
转场 (Transition): 描述镜头间的转场方式，如 硬切、淡入淡出、叠化。
现在，请根据以下视频链接开始你的专业分析。请务必严格遵守上述所有规则，力求完美复刻。
```

## 根据一段简述做原创故事文生图脚本

把对标的十个视频，一定是相同类型的，比如动物故事`supercatpapa`，同时发给gemini，然后让ai分析出爆款视频的元素：

```
分析这10个爆款视频的10-30个共通的规律，用户情绪旅程图，根据这些内容写一个爆款故事提示词模板
```

爆款故事拉片笔记提示词模板：
