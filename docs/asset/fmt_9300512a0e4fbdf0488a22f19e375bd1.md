
# `NeRF-HuGS`：使用启发式引导分割的非静态场景中改进的神经辐射场

> 作者：社区同学-王逸帆

> 导读：在本篇论文中，我们探讨了神经辐射场（Neural Radiance Fields，`NeRF`）在新视角合成和三维场景重建方面的卓越性能。尽管`NeRF`的效果在处理静态场景时表现出色，但在遇到动态干扰物，如移动物体或阴影时，其性能会受到影响，导致生成的图像出现不希望的伪影。为了解决这一问题，提出了一种创新的方法——启发式引导分割（Heuristics-Guided Segmentation, `HuGS`）。

> 论文链接：https://arxiv.org/abs/2403.17537

## 预备知识：什么是`NeRF`

神经辐射场（Neural Radiance Fields，`NeRF`）是一种先进的机器学习技术，用于创建场景的隐式三维表征。与传统的基于几何的三维模型（如点云或网格）不同，`NeRF` 通过从多视角捕获的图像学习场景的连续体积表示，从而能够生成从任意新视角观察的 2D 图像。

![](img/217523fc58080e2e7e7f0cebc2adfcd6.png)

`NeRF` 的核心是体渲染技术，它采用以下步骤来实现场景的视觉重建：

+ 将场景视为由无数粒子组成的连续体，每个粒子具有特定的密度和颜色。
+ 忽略外部光源和内部反射，假设外射光和内射光互相抵消，场景中的粒子只通过自身发光来贡献最终图像的像素值。
+ 对于给定视角图像中的每个点，计算从相机出发并经过该点的射线上所有粒子的颜色和密度的积分，以确定该点的像素值。

如下图所示，给定三维空间中的一个粒子 `p` 的位置 `(x,y,z)` 和从相机看该点的方向 `d(，φ)`，`NeRF` 使用一个多层感知机（`MLP`）预测出该粒子的颜色 `c(RGB)` 和密度。对同一条射线上的所有粒子都进行预测，获得每个粒子的颜色和密度，再使用体积渲染技术沿射线对所有粒子进行积分，即可得到图像上对应点的像素预测值。

![](img/0bce33a4240d21f1ce6755aa7b78e9eb.png)

将实际捕获的图像像素值作为真值，通过最小化预测颜色 和 真实颜色 之间的误差，即可对上述过程进行自监督训练。在推理时，给定相应的视角参数，对图像上所有点都进行上述预测操作，获得每个点的像素值，就可以重建出对应视角的图片，实现隐式构建该场景的三维表征模型。

![](img/9df61960e915f674ffbf2304fe6a3638.png)

`NeRF` 技术的强大能力在于其能够快速从多视角图像中重建场景，并生成逼真的 2D 视图。例如，B站 UP 主影视飓风的视频【“重建”一座山只需10分钟？神奇的 `NeRF` 技术能怎么用】展示了 `NeRF` 如何在短时间内从一组图像中重建出复杂的 3D 场景。

## 论文的贡献与创新

`NeRF` 模型通过学习场景的连续体积表示来进行 3D 重建。如果场景在不同视图之间发生变化，例如物体移动或光照条件改变，模型将难以捕捉到一致的3D结构，在摄影时任何表现出运动或不一致性的内容，都可能在重建的3D模型中引入伪影，降低重建质量。因此在训练 `NeRF` 时，多视图图像的内容必须保持一致且静态。而在实际作业中，这样的瞬时干扰物几乎是不可避免的，例如，在户外环境中，行人和车辆可能在图像采集期间随机出现，而室内拍摄可能受到摄影师投下的阴影的影响。

为了避免静态场景中出现的瞬时干扰物，很自然的想法就是预先移除图像中瞬时干扰物，在训练 `NeRF` 时仅计算静态物体部分的 `loss`，使得神经网络在训练时免受瞬时干扰物的影响，进而消除伪影。

![](img/b6496d05a4f1d7dd29cc93ebdd7761e7.png)

但手工标记这些瞬时干扰物，逐像素地提取并移除是一项极其耗时的任务，该论文的贡献就在于提出了一种创新的解决方案——启发式引导分割(Heuristics-Guided Segmentation, `HuGS`)。该方法通过结合手工启发式算法和先进的分割模型，可自动精确地从复杂场景中分离出静态元素，构建静态元素的分割掩膜。将该方法作为一种`Pipeline`应用于`NeRF`进行三维重建的过程中，可有效地消除伪影，提升`NeRF`进行三维重建的效果。

![](img/7f3ac501080f9a7d3f97d2913570d9a5.png)

## 相关工作

为了减轻静态场景中出现的瞬时干扰物对`NeRF`建模的影响，现有解决方案大致可分为两类：

+ **基于分割的方法**：通过使用预训练的语义或视频分割模型来识别瞬时干扰物与静态场景，并利用这些信息来辅助`NeRF`的训练。这些模型可以产生准确的结果，但存在严重限制：
  + i) 它们需要额外的先验知识，如瞬时干扰物的语义类别或图像作为视频帧的时间关系，这在实践中很难满足，因为不可能枚举所有可能的干扰物类别，且图像可能无序。
  + ii) 语义分割无法区分同一类别中的静态和瞬时对象。
+ **基于启发式的方法**：利用手工设计的启发式规则在`NeRF`训练期间从静态场景中分离瞬时干扰物，由于它们不需要先验知识，因此更具普适性。然而，设计能够准确分离的启发式规则是困难的，例如，`NeRF-W` 观察到瞬时对象的密度通常较小，并基于这一假设来约束`NeRF`训练，但这可能导致产生不是瞬时对象的小密度雾状残留；`RobustNeRF`通过颜色残差来区分瞬时像素和静态像素，因为在`NeRF`训练中瞬时像素更难以拟合，但这同样使得静态对象的高频细节难以拟合，这可能导致`RobustNeRF`在处理瞬时干扰物时也忽略它们。

## 解决方案

![](img/a51785bd9565dc82631daaa650db4851.png)

启发式引导分割方法流程如图所示，采用两个互补的启发式分支来提取静态图。首先将受到瞬时干扰物影响的静态场景的无序图像输入两个分支，第一个分支是基于运动恢复结构（Structure from Motion，`SfM`）技术，`SfM` 是一种从多个图像中恢复 3D 结构的技术，该方法首先提取图像的特征点，如角点、边缘或其他具有独特纹理的区域，然后进行两两图像对特征匹配，使用匹配的特征点对来估计每对图像之间的相对相机姿态，最后通过三角测量的方法，计算每个匹配点在3D空间中的坐标，从而构建起一个稀疏的 3D 点云。显然，匹配到的每个静态对象特征所对应的2D匹配点数量是远大于瞬时对象的，该论文基于跨输入图像的出现频率来区分静态和动态特征，将筛选出的静态特征点作为提示点，引导 `SAM`（Segment Anything Model） 生成具备高频纹理图案特征的静态分割掩膜。

第二个分支则是基于颜色残差的思想，如相关工作中所提到的，由于在 `NeRF` 训练中瞬时像素更难以拟合，因此可基于颜色残差来区分瞬时像素和静态像素，这对于低频纹理静态元素尤其有效。这里首先预先训练一个 `NeRF`（大概迭代几千次），使用这个 `NeRF` 模型预测输入图像的颜色，计算预测的颜色与实际颜色之间的残差，获得颜色残差灰度图，然后将平均颜色残差作为阈值，保留低于阈值的像素，并将其转换为二值掩膜。

最后将上述两个分支的预测结果相叠加，便可以获得综合高频和低频信息的静态分割掩膜。此外，在第一个分支中，由于特征点的误分类或 `SAM` 分割错误可能会错误地包含一些瞬时对象，为了消除这些这些对象，论文在这里基于颜色残差对合并后的分割掩膜进行了过滤，去除掉颜色残差过大的像素点。最后将其作为提示再次引导 `SAM` 生成更为精准的静态图。这个静态图随后可以作为 `NeRF` 训练过程中的损失权重，以排除动态干扰物的影响。

## 实验论证

该研究通过一系列精心设计的实验来验证`HuGS`方法的有效性。论文使用了 Kubric、Distractor 和 Phototourism 三个数据集来进行评测，这些数据集涵盖了从合成到真实世界的多样化场景，以验证 `HuGS` 在各种场景的有效性，以下数据集的具体介绍：

+ **Kubric数据集**：一个合成数据集，提供了受控的非静态场景，其中包括简单几何体在空房间中的摆放，并且场景中的物体在帧之间具有时间关系。这个数据集的特点是可控性强，可以用于验证 `HuGS` 在处理具有明确动态和静态元素分离的场景时的效果。
+ **Distractor数据集**：包含真实世界的室内场景，每个场景中有1至150个干扰物。这个数据集的特点是干扰物的数量和类型多样，可用于测试 `HuGS` 在处理真实复杂环境中的鲁棒性。
+ **Phototourism数据集**：由在线收集的四个文化地标的照片组成，这些照片含有各种瞬态干扰物，如行人和车辆。这个数据集的特点是场景的外观因拍摄环境和设备的不同而变化很大，用于评估 `HuGS` 在处理外观变化显著的现实世界场景中的能力。

实验中使用峰值信噪比（`PSNR`）、结构相似性（`SSIM`）和感知损失（`LPIPS`）作为评价指标，实验结果如上表所示，结果表明，`HuGS` 在所有数据集上均能显著提高`NeRF`模型的视图合成质量。在 Kubric 数据集上，`HuGS` 证明了其在处理合成动态场景中的有效性。Distractor 数据集的结果展示了 `HuGS` 在处理真实世界复杂干扰物时的鲁棒性。Phototourism 数据集上的表现证明了 `HuGS` 能够适应场景外观的显著变化，并有效提升渲染质量。

## 论文贡献

该论文提出了一种新的启发式引导分割方法 `HuGS`，该方法等价于结合了 `SfM` 启发式和颜色残差启发式对 `NeRF` 进行数据增强，这种能够提取不同纹理特征的静态场景元素，增强了对静态场景元素的捕捉能力，可有效改善 `NeRF` 在非静态场景中的训练效果。并且论文在 Kubric、Distractor 和 Phototourism 等多个具有不同特点的数据集上进行广泛的实验，验证了 `HuGS` 在减少伪影和提升三维重建质量方面的优越性。

## 不足之处

尽管该研究提出的 `HuGS` 方法在多个数据集上展现出了显著的性能提升，但仍存在一些局限性，并可作为未来工作的基础：

+ **对特定场景的挑战**：尽管 `HuGS` 在处理常见遮挡和反射时表现出色，但在处理极端情况下的遮挡（例如，极少可见的静态对象）和高反射材料仍然存在局限性。
+ **启发式设计的改进空间**：尽管结合了 `SfM` 启发式和颜色残差启发式，但仅使用了较简单的 `SfM` 算法，可以进一步改进以处理稀疏视图或由瞬态干扰物主导的场景，此外，尽管 `SAM` 是最先进的分割模型之一，它仍然无法处理非常微弱的阴影，这一局限性可能在某些情况下导致渲染质量的降低，可尝试采用更强大的分割模型。
+ **可能存在信息丢失**：过度的像素移除可能会导致监督信号不足，从而可能降低模型相对于在干净图像上训练的性能。因此，另一种可能的改进是将该方法与 2D/3D 修复技术结合起来，这可以预测由于去除瞬态像素而缺失的内容，以协助 `NeRF` 训练。
