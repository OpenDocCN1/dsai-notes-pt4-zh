
# 2023-08-01当了15年的班主任，才敢告诉你的小学真相

> 来源：[https://xuqiwei1986.feishu.cn/docx/Di4cdShqCol5fRxroGccAhLxnkh](https://xuqiwei1986.feishu.cn/docx/Di4cdShqCol5fRxroGccAhLxnkh)

1、小学教育主要还是依赖家庭教育，父母是孩子最好的榜样，家长应以身作则，做孩子最好的老师

2、父母在教育上偷的懒，未来都会加倍偿还，且教育成本巨大

3、小学成绩具有一定的欺骗性，家长不要看的太重，初高中才会显示学霸潜质，但小学一定要养成良好的学习习惯，比如课前预习、认真审题、不漏题、计算不出错……一定要透过成绩看本质，比如是不是因为学习习惯不好，才导致成绩差，还是其他原因

4、上小学一定要当班干部，因为你初中可能想当都当不上!还有的好处是:锻炼表达能力、拉进和老师的关系、提升统筹事务的能力，哪个都很重要!

5、一二年级抓拼音、抓识字量，语文学好了，其他学科也会受益，否则对文字理解、断句都是问题，谈何正确答题?

6、一二年级还要狠抓认真写字的习惯，字可以不用写出笔风，但一定要工整，以后都是电脑阅卷，字迹不工整，扫描不出来，老师也看不懂。让老师看得懂，这样到了中考才会因为书写潦草而吃亏。

7、一二年级可以选喜欢的爱好，个人推荐比如画画，书法。锻炼孩子学坐的住的能力，还能培养兴趣。选好了就要督促孩子坚持下去。初中练习时间真的很少。

8、1-3年级的学习别抓太紧，多带孩子运动，既强身健体，又锻炼孩子的专注力，运动是世界上最便宜的“聪明”。

9、三四年级除了大量阅读，还要养成每日听说读写英语的习惯，如此，英语不用补课，满分的卷子，考个90分以上简直就是玩一样。英语差的孩子，无非就是不愿意听读、不愿意背记而已。

10、三年级前一定要培养好孩子学习习惯，不知道如何培养孩子习惯的，就去看好习惯带来好成绩这本书，里面针对小学学习习惯做了很全面的总结，包括教孩子如何预习、如何听课、写作业、制定计划都写得很详细

11、四年级开始减掉兴趣班，只保留一两种孩子特别感兴趣的，五六年级重点抓阅读和历史，六年级重点抓数学。

12、语文上面，该背的务必提前背，记忆是理解之母，先混个脸熟。古诗词背诵越早背越好，先从小学生必备古诗词129首开始入手，不仅仅小的时候记忆好，而且还给初中节省更多时间，初中一上来要接触很多新学科，背起来费劲，先混个脸熟。初高中直接吃老本，孩子会很轻松。

13、数学逻辑思维，这个不用上培训班，只要让孩子去玩:魔方、数学华容道、拼图、乐高、数独、围棋五子棋等，周末抽出30分钟陪孩子玩一玩，就可以简单高效的去提升孩子的逻辑思维。

14、小学把英语学得越精越好。单词记得越多越好，不然初中门门主课压力大，被打击得没自信

15、英语关键是兴趣培养出来的，重视英语，趁孩子语言敏感期启蒙英语，尊崇听-说-读-写规律，坚持磨耳朵、看英语启蒙动画等大量的输入，分级可以从raz入手都可以。小学知识还简单学的扎实一点，在扎实的基础上多积累一些词汇和阅读。

16、陪养孩子自主学习的能力也很重要。小学全靠父母给计划、催学习的，初中越来越学不动。缺少内驱力!要让孩子学会自主安排学习，独立完成自己的作业任务。给孩子看相关内容的绘本、书籍，像《漫画小学生时间管理》这种都是直接正向引导，没有说教，让孩子在漫画故事中，学习知识，提升自我管理能力

17、不复习不写作业，很多孩子和家长都会忽略这个问题，看似浪费时间，实则提升效率。写作业前一定要把所有的准备工作做完，才能开始写作业(吃东西、上厕所、喝水)等杂事，一旦开始写作业，在一个固定的专注期内要做到不离开座位。

18、不要觉得孩子聪明就任由孩子懒惰，作业不写，题不做，以为凭着聪明劲儿就会学懂小学知识，当然，有可能成绩还不差，但是也悄悄的给孩子灌输一种错误思想，同时也会养成一种坏习惯。

19、阅读一定要有“功利性”一二年级培养阅读兴趣后，三年级开始要引导“功利性”读书，多读名人传记，科普，时政。五年级课文中就要求读四大名著了，名人传记激励孩子的自驱力，科普要联系生活实际，时政重在培养思辨能力。

20、初中要学的政治、历史、地理、生物、物理、化学越早启蒙越好，在小学要有意识的提前接触这些学科知识，小四门启蒙以培养学科兴趣为主，五六年级注重学科思维的培养。暑假让孩子去阅读这方面的桥梁书、看纪录片、参观博物馆，去做一个启蒙

21、学会检查和提问。孩子自己做的作业自己检查，遇到不会的不要马上问，先思考，实在不会的再提问，这样才能把知识学透彻。

22、让孩子当“小老师”，家长当“大学生”，“小老师”能把“大学生”教会，才算把知识吃透了。(费曼学习法)

23、勤用错题本，检查出来的错题，收集在错题本上，方便以后定期订正复习，错题本是学霸必备技巧。

24、坚持每天阅读，哪怕只有10分钟对孩子也是受益无穷的。关键在于坚持，对孩子的语言发展能力、识字量、拓展视野都是有帮助的。要给孩子选择合适的书籍，精读+深入读

25、计算要准确，一些孩子很聪明，但考试的时候总是得不到满分，归根到底还是基本功不扎实，计算是每日必做的事情。不要觉得孩子聪明就会马虎，其实马虎就是掌握不牢固的表现。

26、大声朗读，无论英语还是语文，大声朗读会更有效果。

27、不要有拖延的习惯，有事立马就去做。成绩差的孩子，99%都有拖延症，不但学习上拖拖拉拉，生活上也磨磨蹭蹭的。
