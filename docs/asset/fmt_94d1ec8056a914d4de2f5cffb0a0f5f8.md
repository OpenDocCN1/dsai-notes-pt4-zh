
# 2023-07-13【民生银行】王建宇：AIGC可提高融资效率 需防范过度依赖风险

> 来源：[`https://xuqiwei1986.feishu.cn/docx/Kf1kdYeodoqdJoxeAZScE0HTnch`](https://xuqiwei1986.feishu.cn/docx/Kf1kdYeodoqdJoxeAZScE0HTnch)

引用`https://baijiahao.baidu.com/s?id=1771265748280471360&wfr=spider&for=pc`

中国民生银行数据管理部副总经理王建宇。

新京报贝壳财经讯（记者姜樊）今年以来，ChatGPT掀起了金融行业对生成式人工智能（AIGC）的关注热潮，包括民生银行在内的多家银行正在积极布局和研究相关技术。

7月12日，在2023新京报贝壳财经夏季峰会“AI如何助力金融行业服务实体经济”圆桌论坛上，中国民生银行数据管理部副总经理王建宇表示，银行业有望通过AIGC技术优化资源配置、降低融资成本、提升融资效率、降低风险发生率，更好地服务于实体经济发展。

“我们非常惊讶于ChatGPT的功能。”王建宇表示，以此为代表的AIGC技术在文本和图像理解、内容生成方面让人印象更加深刻。这项技术在智能客服、智慧办公、代码生成、风险防范等方面的应用都值得探索。

据介绍，在Chat GPT爆火之后，民生银行还从多个部门抽调相关人员组建了专门的研究团队。该团队已针对Chat GPT前期应用状况进行跟踪，目前民生银行内部还针对部分开源模型进行了预研，并探索和研究该技术未来可应用的场景。

王建宇指出，在服务实体经济的过程中，银行最基础的工作是“了解你的客户”（KYC）。如在甄别客户时，银行需要通过多种渠道和工具对其情况进行了解。相比此前智能搜索的技术，AIGC可以通过海量数据给出独到的分析，可为金融机构提供更为精准的信息内容。这有助于优化银行资源配置，提高融资效率。

对于银行内部而言，大模型也将有助于提高银行自身的办公效率。王建宇指出，银行业务条线众多，银行从业者很难掌握全面的银行业务知识。因此，若能通过技术来为银行内部员工提供自然语言的培训辅助功能，就可极大提高办公效率。

值得注意的是，当前AIGC技术在金融领域的商业化落地仍存难点。王建宇指出，相对于其他行业而言，银行需要大模型给出更为精准、严谨的答案，而非目前市场上的通用模型所提供的模糊答案。因此，他期待具有行业深度的模型尽快问世，让这项技术真正地运用到银行实际的业务中。

此外，新技术可能带来的风险挑战亦是金融机构关注的重点之一。在王建宇看来，当前AIGC技术在发展的过程中要特别注意数据安全和隐私保护方面的相关风险。

“金融机构使用模型可能具有不确定性，这也会给金融机构带来一定的风险。”王建宇表示，如何保证模型在进行相关业务决策时保持可解释性、稳定性将是探索重点。

王建宇还指出，若金融机构过度依赖AI技术而没有进行应急预案准备，则可能导致在AI出现问题时相关业务出现服务中断的问题。因此金融机构还应防范AI技术发展所带来的业务连续性方面的风险。
