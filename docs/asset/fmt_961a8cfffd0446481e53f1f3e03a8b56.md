

# 360周鸿祎：大模型布局与智能化展望

![](img/c1e94b67c092066c486618922c001c6f.png)

“我们坚持核心技术研发，已经形成‘双千亿’大模型布局。”5月18日，第七届世界智能大会在天津开幕，大会由天津市人民政府、国家发改委、科学技术部等多部委共同举办，吸引了智能科技领域的院士专家和世界500强知名企业家参会。三六零(601360.SH，下称“360”)集团创始人周鸿祎在会上发表主题演讲并展示了两款大模型产品“360智脑”以及AI生图工具“360鸿图”，天津市委书记陈敏尔等与会领导现场观看演示。

展示过程中，“360智脑”体现了强大的理解力和推理力，在回答天津经济社会发展的相关问题时内容详实、条理清晰。“360鸿图”则按要求生成了一张2025年天津滨海新区的图景。

演讲中，周鸿祎预言，未来中国不会只有一个大模型，每个城市、每个政府部门都会有自己的专有大模型。城市、政府专有大模型不仅能为领导和政府决策提供支持，还能成为办公人员强大的助手。当大模型和政府的业务系统融合，还会变成政府各个业务板块的“副驾驶”，甚至成为智慧政府、智慧城市的总调度室。

周鸿祎表示，未来数字化的高峰一定是大模型推动下的智能化，人工智能的指数级跃变将带来巨大发展机遇。他认为，GPT是通用人工智能，在很多维度上已经超越了人类，其最大的意义是人类第一次把所有知识进行了重新编码和存储，代表着超级人工智能时代的到来，将对人类社会的发展产生深远影响。

周鸿祎认为，大模型将会带来一场新工业革命，能够像“发电厂”一样，把从前难以直接使用的大数据加工成“电”，赋能千行百业。他强调，大模型的发展水平关系到国家生产力水平，因此中国一定要迎头赶上。他对于中国能够打造自己的大模型深信不疑，同时也提醒中国发展大模型要坚持长期主义，要脚踏实地的补足短板。

周鸿祎介绍，360通过“两翼齐飞”的人工智能发展战略，已经在核心技术、场景布局和产品打磨上取得了一些成果。他邀请现场嘉宾及市民到360展台体验360大模型产品，并表示大语言模型需要高质量的训练和反馈，才能更智能。

# 百度李彦宏：大模型改变世界

**5月26日上午**，在北京举办的2023中关村论坛全体会议上，百度创始人、董事长兼首席执行官李彦宏发表题为《大模型改变世界》的演讲。他说，人工智能的诞生，让我们可以用自然语言跟电脑进行交互，这会带来提示词革命。10年后，全世界有50%的工作会是提示词工程。提出问题比解决问题更重要。

“最近一段时间，人工智能再次成为人类创新的焦点，越来越多的人认可第四次产业革命正在到来，而这次革命是以人工智能为标志的。”李彦宏表示，当下，我们正处在一个以大模型为核心的人工智能新时代，大模型改变了人工智能，大模型即将改变世界。

## 大模型怎么重新定义人工智能？

简单来说，过去我们理解的人工智能，是想让机器学会什么技能，就教它什么技能。教过的有可能会，没教过的就不会。而在大模型、大算力、大数据环境下，以前没给机器教过的技能，它自己就会了。与此同时，人工智能发展方向从辨别式走向生成式，例如从辨别式的搜索引擎，变为生成式的用AI进行文学创作、写报告、绘制海报等。

李彦宏认为，大模型重新定义了人机交互。人工智能的诞生，让我们可以用自然语言跟电脑进行交互。自然语言人机交互会带来提示词革命。也就是说，未来的应用，是通过自然语言的提示词来调动原生AI应用实现。这意味着，未来你的薪酬水平，将取决于你的提示词写得好不好，而不是取决于你的代码写得好不好。10年后，全世界有50%的工作会是提示词工程。提出问题比解决问题更重要。李彦宏举例说，我想查一下“4月份，我的公司有哪些产品的毛利率，超过了疫情前的水平？”这个事，在过去很可能需要我的助理花半天一天时间才能获得。今天，如果计算机懂你的自然语言，一秒钟之内就可以给你一个表格。

李彦宏还认为，大模型会重新定义营销和客服，会催生AI原生应用。“百度正在用AI原生思维重构所有的产品、服务和工作流程。百度要做第一个把全部产品重做一遍的公司，不是整合，不是接入，是重做，重构。”李彦宏表示，文心一言的发布，让百度成为全球科技大厂中第一个发布GPT大模型产品的公司，文心大模型3.5版本将很快推出。

“未来，所有的应用都将基于大模型来开发，每一个行业都应该有属于自己的大模型，大模型会深度融合到实体经济当中去，赋能千行万业。”李彦宏说。
