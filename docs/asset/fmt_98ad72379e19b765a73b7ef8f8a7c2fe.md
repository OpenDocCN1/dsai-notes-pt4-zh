
# 第一期课程群（已完结）

> 来源：[https://my.feishu.cn/docx/NNYXdDD2IosLgDxkFJ2cfhWNnqh](https://my.feishu.cn/docx/NNYXdDD2IosLgDxkFJ2cfhWNnqh)

本课程为 **Claude Code 课程**，采用「课程直播 & 回放 + 🛰️陪伴群」形式。

## 一、你将获得什么

+ 参与老金主讲的 Claude Code 系列课程
+ 加入 **付费学员专属🛰️群**
+ 获取课程相关的：
+ 讲解资料
+ 课后补充说明与长期沉淀内容
+ 可在陪伴群内持续跟进课程相关问题（非 1 对 1 私教）

> 本产品为「学习陪伴型课程」，不是单次录播售卖。

---

## 二、如何加入

1. 完成课程付费（🛰️找老金）
2. 添加老金飞书账号（备注🛰️名）
3. 由老金拉你进入 **付费学员专属🛰️群 与 飞书群**
4. 进**飞书群**后，课程相关阅读与资料 **权限将自动开放**

## 三、关于退费规则（重要）

+ **仅参加一次课程**的学员，如不继续参与，可申请退费
+ **参加第二次课程（含直播或回放）**，即视为已确认接受本课程与陪伴形式
+ 自第二次课程开始，**不再支持退费**

> 是否“参加”，以实际进入课程内容（直播或回放）为判断依据。

---

## 四、课程内容说明

课程详细内容与安排请见下方【课程详单】图片。

**课程详单：**

1、环境与安装，以及配套好用的软件
2、基础使用说明
3、Command系统
4、MCP系统
5、Hook系统
6、Skill系统
7、Plugin系统
8、综合实战 （收集需求后分批讲解，涉及多少个案例暂未定）

---

**以下需要注意的几点：**

**1、想花少时间就知道怎么使用的**，直接看上方的录播资料的 AI总结 和 视频 即可。

2、本文章很多是繁琐的，用于理解原理，看不懂没关系，对使用来讲作用不大，属于锦上添花。

+ 优势：有很多案例可供参考
+ 劣势：
+ 老金我只审核了Win的操作，Mac以及Linux需要自行实验。
+ 教程文章内均为常规详细教程，如中转站等等不会提到，特殊用法请看直播视频。

3、录播中会带有其他非Claude Code本身相关的内容，如MCP ROUTER这种路由器，或者CC Switch等其他相关软件的推荐及使用。
