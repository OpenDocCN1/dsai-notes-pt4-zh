
# 在美国如何进行税务申报？

> 来源：[https://docs.feishu.cn/docx/FNtEdbagnofezgx8nbDcXS4Snoc](https://docs.feishu.cn/docx/FNtEdbagnofezgx8nbDcXS4Snoc)

> 在美国，公司报税是一项严谨而复杂的任务，要求企业精细管理财务，遵守复杂的税收法规。

下面是自主报税的说明，当然你也可以让中介帮你操作！

## 美国公司注册后什么时候报税？

每年都要向相关机构提交税务报告，报告包含上一个报税年一整年的所得税或其他税款的信息。

报税通常分为两部分，联邦个人所得税（Federal Taxes）需提交给美国国税局 IRS，而州税（State Taxes）需要提交给居住地州/地区政府。若已缴纳税大于计算报税金额，则可以获得退税。

通常联邦税报税截止日期为4月15日，每年可能会因假日等原因有调整。州税报税截止日期通常与联邦税一致，部分州可能另行规定日期。2024年的报税季为1月29日 - 4月15日。

如果没有注册美国公司，而是通过第三方平台在美国进行销售，这也相当于在美国有销售行为。

根据中美之间的税收协议，卖家需要缴纳美国税收，如加州（仓库所在地为加州）所得税。如果是零售业，还需要缴纳销售税。

## 美国公司报税的方式有哪些？

美国公司注册后，需要每年进行申报税款，无论美国公司是盈利还是亏损，都必须按时进行。很多情况是不需要缴纳税款的，如没有实际经营业务或是公司属于亏损状态，但申报的动作必须进行。

根据美国公司经营情况可以选择合适的报税方式，通常分为两种，无经营报税和有经营报税：

+ 无经营报税：公司没有开户、没有盈利、没有用于注册任意平台或是没有运作，可以进行“零申报”。

+ 有经营报税：公司有开设银行账户，并且有盈利，则需要做账报税。

美国税局对于税务的稽查是相当严格的，所以不要企图可以蒙蔽税局的双眼，违规报税。公司适合哪种申报方式就选择哪种，不要贪图便利而违规越线。

## 美国公司报税需要什么资料？

美国公司报税前，首先需要明确公司注册时的报税类型，根据不同的公司报税形式，会有不同的税法。

在明确好公司的报税类型后，就需要了解公司申报的基本资料，通常有：公司名称、公司EIN、公司报税周期、公司股东、公司盈利表等。

注意：如果公司销售额超过25万美金，就需要另外申报资产负债表；如果是中国公司为股东公司，还需要额外申报5472表格。

## 美国公司零申报有哪些条件？

如果美国公司从未开始运营或已准备注销，则可以办理零申报，有运营的公司需要进行会计师核数(即审计)后进行申报。

符合其中一方面的即为有运营事务，不能进行零申报：

+ 已经在美国银行账户中留有运营记载（业务记录）；

+ 已经在政府海关或物流公司中留有进出口记载；

+ 已经与美国客商有过供销联系；

+ 已经在美国招聘过雇员；

+ 已经委托在美国进行代理或销售；

+ 已有允许或授权在美国运用专利，商标设计等资料；

+ 已有允许或授权在美国运用动产收取租金、租借费等金钱交易；

+ 已有其它来自或产生于美国的盈利。

如果美国公司有经营，选择“零申报”以后，美国税务局在7年内仍有权要求检阅公司账目，并且税局可以通过银行账户信息、海关记录等对您的美国公司进行查账。

如果公司提供的文件不符合“零申报”条件，会被税务局会认为是不诚实的表现，不仅需要补交此前的税费，出现瞒税漏税情况严重的，轻则要求重新补做，重则离岸账户被强制关停，被政府列入“黑名单”，甚至被检控。

若是企业有子公司或关联公司，几年都不做账，很容易造成账目资料缺失，从而不能形成完整的财务链条，无法通过审计。

通常，美国税局会允许企业补申报和补缴税款，但这并不能免除罚款和被控诉。并且即使重新补做审计和税务申报，在实际操作上的难度也不小。

## 注册了美国公司不营业，需要做审计报税吗？

一般情况下，如果你注册美国公司后不在美国经营，没有和美国产生贸易往来，就不需要做账和交税，但是要报税，可以进行零申报，美国各州情况不同所需费用也不同。

如果说注册美国公司后在美国本土经营，产生费用的话那就要交税，并且需要美国会计师来做账，收费情况视企业的收入情况而定（一般为利润额的8%-10%）。

对于正规经营的公司来说，基本税种都要缴纳、申报。一般不实地经营的公司，只需缴纳注册特许经营税（商业税）、基本州税，这个税各州收取数额不同。

此外，除了公司收入税需要申报，公司的销售税和薪资税也需要申报，这两种税就比较复杂了，通常都是联系美国专业会计师进行申报，或者可以寻求代理帮忙做。

> 总的来说，经营美国公司不要企图在税务上有偷税瞒税的行为，对于这些违法行为美国税局的打击力度是相当大的，不要心存侥幸心理。
