
# 如何为clewd添加秘钥

> 来源：[https://docs.feishu.cn/docx/OBRSdmL5eoAdIzxpWFcch1EdnLb](https://docs.feishu.cn/docx/OBRSdmL5eoAdIzxpWFcch1EdnLb)

## replit云端

本篇作者：

先找到Secrets界面，点击New Secret

![](img/2547383c0b0121eff44e01847d9543ef.png)

Key中填入`ProxyPassword`，`value`填写你要的密码，点击Add Secret

![](img/4c31813bf7142ff77cd40d17d9f5a8a4.png)

添加完后重启clewd，也就是`stop`后再`run`一次

最后在酒馆填入反代的地方，在`Proxy Password`输入密码

![](img/26897ac211599ef45a0353887d35180a.png)
