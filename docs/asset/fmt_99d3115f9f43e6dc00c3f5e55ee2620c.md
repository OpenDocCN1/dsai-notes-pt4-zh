## 大语言模型背景下的观点

### 模型初始化以及激活函数适配性对于模型收敛性影响

衡量网络是否“消失”或者“爆炸”的指标，输出0均值、1方差是非必要的，这里我们用二阶（原点）矩来代替，它可以看成是L2模长的变体，跟方差的作用类似，都可以用来衡量指标是否“消失”或者“爆炸”，但它相对来说更普适和简单。包括`Xavier`初始化针对`sigmoid`、`tanh`的适配、“微调”后的`Elu`函数等。

| 模型 | 激活函数 | 对收敛性的影响 | 优点 | 缺点 |
| --- | --- | --- | --- | --- |
| `ResNet` | `ReLU` | 稳定训练并支持更深的网络结构，减少梯度消失问题。 | 减少梯度消失；支持残差连接，允许更深的网络。 | 可能会出现“死神经元”现象，即某些神经元不再激活。 |
| `Vision Transformer` | `GELU` | 提高收敛速度，提供更平滑的线性与非线性区域过渡，改善训练过程中的梯度流动。 | 减少梯度消失，保持平滑性，适合处理复杂模式。 | 对超参数的调优依赖性较强，可能需要更多的实验。 |
| `Llama3` | `SwiGLU` | 通过非单调特性改善优化过程，使得收敛更加高效，适应复杂的任务。 | 结合了激活函数和线性单元的优点，适合大规模模型。 | 由于其复杂性，可能导致解释性较差，难以理解其内部机制。 |

### 通过层归一化稳定方差对于模型收敛性影响

相比激活函数这种简单的“微调”，更直接的处理方法是各种Normalization方法，如`Batch Normalization`、`Instance Normalization`、`Layer Normalization`等，这类方法直接计算当前数据的均值方差来将输出结果标准化。去掉center后的`Layer Normalization`（`Root Mean Square Normalization`，`RMSNorm`）在Google的`T5`、`Llama3`中均被使用，替换掉了`LayerNorm`，实验结论上还有提升，性能上也有优势（无需计算`Mean`）。

### 残差对于模型收敛性的影响

`Post Norm`结构，它也是原版`Transformer`和`BERT`所使用的设计。然而，这种做法虽然稳定了前向传播的方差，但事实上已经严重削弱了残差的恒等分支，所以反而失去了残差“易于训练”的优点。

![](img/f5cf24c604ac0468abf4dc8bc4b96eeb.png)

![](img/a1407b1b5b0e806709f2402efdda4ccf.png)

`Post Norm` 保证了主干方差恒定，每层对输出都可能有较大影响。代价则是模型结构中没有从头到尾的恒等路径，梯度难以控制。通常认为会更难收敛，但训练出来的效果更好。

`Post Norm` 和 `Pre Norm` 相反，它每 `Norm`一次就削弱一次恒等项的权重，变相更突出残差项的（但是梯度还是递减的，只不过总体看更加偏向于残差项）。

所以其实 `Post-N` 和传统的深度网络都一样有梯度消失的问题，而 `Pre Norm` 避免了这种问题，让训练变简单，但是带了新的问题，即网络退化问题。

## 归一化函数

### 1. Batch Normalization（批量归一化）

- 目的：`BN` 通过计算每个批次的均值和方差来标准化输入，使输出具有零均值和单位方差。这有助于加速训练并稳定模型。

- 计算：对每个`mini-batch`计算均值和方差，然后进行标准化。（Per channel across mini-batch）

其中 是批量大小， 是一个很小的数字，用于数值稳定性。 和 是可学习的缩放和偏移参数

https://pytorch.org/docs/stable/generated/torch.nn.BatchNorm2d.html

```
import torch
import torch.nn as nn

class BatchNorm(nn.Module):
    def __init__(self, num_features, eps=1e-5, momentum=0.1):
        super(BatchNorm, self).__init__()
        self.eps = eps
        self.momentum = momentum
        # 可学习的缩放和偏移参数
        self.gamma = nn.Parameter(torch.ones(num_features))
        self.beta = nn.Parameter(torch.zeros(num_features))
        self.running_mean = torch.zeros(num_features)
        self.running_var = torch.ones(num_features)

    def forward(self, x):
        if self.training:
            batch_mean = x.mean(dim=0)
            batch_var = x.var(dim=0, unbiased=False)
            x_norm = (x - batch_mean) / torch.sqrt(batch_var + self.eps)
            # 记录移动平均的 running_mean、running_var 
            self.running_mean = self.momentum * batch_mean + (1 - self.momentum) * self.running_mean
            self.running_var = self.momentum * batch_var + (1 - self.momentum) * self.running_var
        else:
            x_norm = (x - self.running_mean) / torch.sqrt(self.running_var + self.eps)
        
        return self.gamma * x_norm + self.beta
```

### 2. Layer Normalization（层归一化）

- 目的：在每个样本的特征维度上进行归一化，适用于`RNN`等序列模型。

- 特点：对每个样本的所有特征进行归一化，不依赖于`batch`的大小。

其中， 是特征维度。

```
class Naive_LayerNorm(torch.nn.Module):
    def __init__(self, num_features, eps=1e-5):
        super(Naive_LayerNorm, self).__init__()
        self.eps = eps
        self.gamma = torch.nn.Parameter(torch.ones(num_features))
        self.beta = torch.nn.Parameter(torch.zeros(num_features))

    def forward(self, x):
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        x_norm = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_norm + self.beta
```

https://pytorch.org/docs/stable/generated/torch.nn.LayerNorm.html

```
import torch

# NLP Example

# Activate module

```

### 3. Instance Normalization（实例归一化）

[Instance Normalization](https://arxiv.org/abs/1607.08022): The Missing Ingredient for Fast Stylization

- 目的：在图像生成和风格迁移中常用，对每个样本的每个通道计算均值和方差进行归一化。

- 特点：通常用于风格迁移任务，能够保持样本之间的风格差异。

其中， 和 分别是高度和宽度。

```
class InstanceNorm(nn.Module):
    def __init__(self, num_features, eps=1e-5):
        super(InstanceNorm, self).__init__()
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(num_features))
        self.beta = nn.Parameter(torch.zeros(num_features))

    def forward(self, x):
        mean = x.mean(dim=(2, 3), keepdim=True)
        var = x.var(dim=(2, 3), keepdim=True, unbiased=False)
        x_norm = (x - mean) / torch.sqrt(var + self.eps)
        return self.gamma * x_norm + self.beta
```

### 4. Group Normalization（组归一化）

- 目的：将特征通道分成若干组，在组内计算均值和方差进行归一化，适用于小`batch size`的情况。

- 特点：在图像分类等任务中表现良好，尤其是在小`batch`情况下。

其中， 是批量大小， 是通道数， 是组数。

```
class GroupNorm(nn.Module):
    def __init__(self, num_groups, num_channels, eps=1e-5):
        super(GroupNorm, self).__init__()
        self.num_groups = num_groups
        self.eps = eps
        self.gamma = nn.Parameter(torch.ones(num_channels))
        self.beta = nn.Parameter(torch.zeros(num_channels))

    def forward(self, x):
        N, C, H, W = x.size()
        x = x.view(N, self.num_groups, C // self.num_groups, H, W)
        mean = x.mean(dim=(2, 3, 4), keepdim=True)
        var = x.var(dim=(2, 3, 4), keepdim=True, unbiased=False)
        x_norm = (x - mean) / torch.sqrt(var + self.eps)
        x_norm = x_norm.view(N, C, H, W)
        return self.gamma * x_norm + self.beta
```

#### 直观理解

![](img/d0ea887027e71946a2651de63b71c8ce.png)

+ `BatchNorm`：`n`×`c`×`w`×`h` -> `nwh`×`c`，那么我们的意思是 `nwh`。对于每个通道（`c`），我们减去其相应的平均值，该平均值是在整个批次和所有像素上计算得出的。`N`本书`c`页，将每本书第`c`页所有文字(`w`∗`h`)取均值和方差。insight:对于不同的样本来说，某个通道学习的信息都是某个维度、颜色的信息，学习一个固定的`feature`，`batch`一般很大。

+ `LayerNorm`：`n`×`c`×`w`×`h` -> `cwh`×`n`，那么我们的意思是 `cwh`。对于每个示例（`n`），我们用相应的平均值减去它，该平均值是在所有通道和像素上计算的。对于`embedding`层: `n`×`token`×`embedding_dims` -> `embedding_dims`× (`n`×`token`)，该平均值是在`embedding_dims`计算的。`N`本书`c`页，将第`n`本书所有页所有文字(`w`∗`h`)取均值和方差。相应地就是每个`token`的`embedding_dims`(4096个值)做均值和方差。`batchsize`不会很大，数据不定长，不同句子之间的关系不紧密。

+ `InstanceNorm`：`n`×`c`×`w`×`h` -> `wh`×`cn`，那么我们的意思是 `wh`。对于每个通道（`c`）和每个示例（`n`），我们用相应的平均值减去它。`N`本书`c`页，将第`n`本书第`n`页所有文字(`w`∗`h`)取均值和方差。

+ `GroupNorm`：`n`×`c`×`w`×`h` -> `swh`×`gn`，其中 `c` = `sg`。这将几个通道分成同一组，我们在 `swh` 上做平均值。然后，我们减去每个组（`g`）和每个样本（`n`）及其相应的平均值。`N`本书`c`页，将`c`页书分为`s`组，将第`s`组所有文字(`w`∗`h`)取均值和方差。

可以自行验证`Norm`之间的等价性关系，其中差别仅在于归一化的范围。

### 5. RMS (Root Mean Square) Normalization

作用位置：对每个`Transformer` block 的输入进行归一化，而不是对输出进行归一化。（pre-normalization方式），`RMSNorm` 是层归一化（`LayerNorm`）的扩展。使用 `RMSNorm` 的原因是 `LayerNorm` 中的计算开销。这使得改进变得缓慢且昂贵。`RMSNorm` 实现了与 `LayerNorm` 相当的性能，但运行时间减少了 7%∼64%。`RMSNorm` 通过完全删除 `LayerNorm` 中的(`Mean`)平均统计量来简化 `LayerNorm`。
