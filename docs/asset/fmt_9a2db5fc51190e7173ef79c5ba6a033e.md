
你会发现，如果他用 `Q` 这个错误的分布来替代你的习惯 `P`，可能会导致更多错误购买的情况。这种“错误信息”带来的额外代价，就是相对熵（KL散度）

---

KL散度衡量的是：如果我们使用错误的分布 `Q` 来编码或描述实际的分布 `P`，我们会多消耗多少额外的信息量。简单来说，它回答了一个问题：

> “如果我们按照分布 `P` 来生活，但有人却坚持按照 `Q` 的分布来看待世界，我们会遭受多大的信息损失？”

最终

但需要注意，KL散度（相似熵）之间并不对称，因为基准不一样。例如：你拿着手电筒去找东西，你对“物体在这里”的确信程度不同于“物体不在这里”。

由于我们在训练模型时，`P(x)` 是固定的（数据集已知），所以我们可以不用看真实分布的信息熵 ，只要看交叉熵 就好了，最小化KL散度，也相当于最小化交叉熵

+ 是真实类别的分布（多元情况，比如猫、狗、鸟，猴），通常是one-hot编码，比如 `P = [0, 0, 1, 0]`

+ 是模型预测的概率分布，例如 `Q = [0.1, 0.2, 0.6, 0.1]`

+ 注意：若是有多个预测，则最终需要除以 `N`（与MSE类似）
