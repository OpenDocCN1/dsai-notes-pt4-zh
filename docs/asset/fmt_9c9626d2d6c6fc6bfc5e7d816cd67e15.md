## 2️⃣ 🌐 北邮、美团联合提出`AgentRefin`：微调的也能让`Agent`模型学会反思？

+ 北京邮电大学与美团联合提出`AgentRefine`框架，旨在通过轨迹中的观察让模型学习纠正错误。
+ 实验表明`AgentRefine`在多样化智能体任务的泛化能力上显著超越了最先进的智能体微调工作，并展现出更好的鲁棒性。
+ 该研究建立了智能体泛化与自我修正之间的关联，并为未来的研究提供了新范式。
+ 数据构建受桌面角色扮演游戏(`TRPG`)启发，分为脚本生成、轨迹生成和验证三个部分。
+ `AgentRefine`在推理任务`HotpotQA`的`EM`和`F1`指标上优于其他方法，证明了其推理问题的泛化能力。

> 关键词：AI，智能体，微调，泛化，鲁棒性

## 3️⃣ 🧬 `WWW` 2025 | 即插即用、轻松涨点！用不确定性助力图结构学习，提升`GNN`性能

+ 图神经网络（`GNN`）在图结构数据处理上表现出色，但存在图结构缺陷问题，如错误边和缺失边等。
+ 为解决这些问题，图结构学习算法（`GSL`）应运而生，通过优化结点连接和边权重来提升`GNN`性能和鲁棒性。
+ 现有基于相似度的`GSL`模型存在缺陷，如依赖嵌入相似度而忽略节点信息质量，以及图结构的对称性限制了捕捉复杂关系的能力。
+ 本文提出了`UnGSL`，一种轻量级插件，利用节点不确定性（信息熵）优化图结构，提高灵活性并过滤低质量节点信息。
+ 实验表明，`UnGSL`在多个数据集上提升了`GSL`模型的准确性、鲁棒性和效率，且计算开销小，可即插即用。

> 关键词：图神经网络，图结构学习，不确定性，信息熵，鲁棒性

+ [`论文地址`](https://arxiv.org/abs/2502.12618)

## 4️⃣ 🚀 全球首个混合推理模型！`Claude 3.7 Sonnet`来袭，真实编码力压一切对手

+ `Anthropic` 发布了全球首款混合推理模型 `Claude 3.7 Sonnet`，提供即时响应和扩展思考能力。
+ `Claude 3.7 Sonnet` 支持标准和扩展思考模式，`API` 用户可控制模型思考时间。

+ 模型在 `SWE-bench` 和 `TAU-bench` 上实现 `SOTA` 性能，尤其在编码和前端 web 开发方面。

## 5️⃣ 🧠 阿里开源推理模型`QwQ`！可联网搜索，思维链裸奔，开发者玩疯了

+ 阿里通义千问团队推出`QwQ-Max-Preview`深度思考模型，支持联网搜索和多种任务，如写代码、数学题和创意写作。
+ `QwQ-Max-Preview`基于`Qwen2.5-Max`构建，展现出在数学、编程和通用任务中的强大能力。
+ 模型在实际测试中展现了代码编写和游戏开发的能力，尽管存在一些不稳定和偏差。
+ 通义千问团队计划开源`QwQ-Max`和`Qwen2.5-Max`，并推出`Qwen Chat App`，以及更适合端侧的小尺寸推理模型。
+ 阿里的`Qwen`系列模型在全球开源模型中具有重要影响力，`QwQ-Max-Preview`的开源将进一步推动AI技术的发展。
