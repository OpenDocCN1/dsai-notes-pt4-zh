
# 运营人该怎么和数据打交道？

> 来源：[https://my.feishu.cn/docx/doxcnlTFQdZcqX2X6djIRFkHwWe](https://my.feishu.cn/docx/doxcnlTFQdZcqX2X6djIRFkHwWe)

身为互联网运营，不可避免地需要与数据打交道，尤其是内容运营和电商运营。

很多实习生刚进入互联网行业的时候，就会被分配很多记录日常数据的任务。

而身为一个运营，关于数据，首先要明确这一点：不是为了记录而记录。

记录数据只是开始，记录日常数据的目的，是为了调用、分析、加工，并最终为工作提供参考。

数据的记录、处理、加工、分析，是互联网运营人工作中的重要一环。

从一个运营在日常工作中如何看待数据、如何把握工作和数据之间的关系，就能够看出来这个运营的工作能力和工作价值。

那么，运营应该如何做好数据？可以从以下几个方向努力。

## 1. 准确、完整、高效、持续地记录日常数据

准确，意味着数据的记录不能有较大的误差和偏误；

完整，指的是所需要的数据内容都应该尽可能记录在日常所需数据中，不能有所缺失；

高效，不要让数据记录这种低创造性的工作耗费大量的精力，要找到更高效的记录手段，这其中也包括数据的自动化、报表化；

持续，数据记录是长期要做的事情，记录的时间越长，提供的信息就越丰富。

## 2. 明确业务关键数据，让数据开口说话

要清楚地知道，哪些数据是直接反应你的工作效果的，哪些数据是和你的目标直接相关的，包括过程数据和结果数据，有了与业务直接相关的数据，就有了工作调整的方向。

举例，电商运营要时刻关注自己商品详情页的访问率、访问到开通的比率、不同产品的UV价值，依靠这些数据，作为改进选品策略的一句；

内容运营要知道，一篇文章的阅读量、跳出率、完读率，分别与文章的哪部分有关，要从哪些方面改进；

## 3. 重视数据协同

和自己的合作部门做好协同，确保数据来源稳定可靠、信息准确无误；同时，也要及时地把相关数据同步给自己的合作方，让合作方知道你的工作成果；最后，要积极地与数据各个环节设计到的合作方进行数据复盘，不断梳理彼此的工作，也从合作方获得不同的视角。

举例，在用资源提供的资源位进行推广营销时，一定要即使和资源提供方进行复盘，要让对方知道，我们用你的资源位达成了怎样的产出，为对方提供了怎样的价值；而运营和资源合作方复盘的时候，也应该去主动了解，对方资源位有怎样的特点，用户群体画像，对产出的影响。

能否用好数据、做好数据，是评价一个运营人是否成熟、是否可靠的重要指标。

## 4. 运营人要用好自己的BI

运营不是BI，掌握高级的算法和会写复杂的代码不是运营的职责；

身为运营，要用好自己的BI，学习数据分析的技能和逻辑自然是好事，但更高难度的数据分析，应该交给自己的BI，而不要想着自己去亲力亲为，更不要把大量精力投入在所谓的数据分析课上。
