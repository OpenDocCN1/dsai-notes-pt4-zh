
# BEV 特征对齐与多传感器融合

## 对齐与特征处理

+ 预测目标在相邻帧之间的平移而非直接预测速度，这样任务转化为预测目标在相邻两帧中的移位，这可根据 BEV 特征图的差异来测量。

+ 两个特征图为自车坐标系，先将两个特征按静态对齐（此时静态对齐，BEV 特征、动态和自车不齐）；然后将两帧特征对齐，将静态特征对齐（将前一帧的覆盖的特征 `crop` 出来，盖到与此时帧相同的位置）。最后将两个特征 `cat` 起来即可

![](img/ae5d633f05faf025f6bd567564adb5a7.png)

对齐的时候需要区分运动车辆、静止车辆。把前一帧的 BEV 特征根据自车运动信息与当前帧的 BEV 特征对齐。

> 结论：直接 `concat` 性能下降，加入 `R&T` 对齐后提高，数据增强提点明显

## `BevFusion`

> 一种多传感器融合技术，它可以将来自不同传感器（如 `LiDAR` 和相机）的数据融合到一个统一的 BEV 表示中。`BevFusion` 的优点在于它能够结合多种传感器的优点，从而在物体检测和跟踪任务中取得更好的性能。

![](img/d44f02c5e0e318e71da2cfc1b73603e2.png)

1. 相机端采用 BEV 算法生成 BEV 特征，如 `bevformer`、`LSS`

1. `LiDAR` 端用 3D 卷积提取 BEV 特征，与相机端特征 `concat` 起来。

1. 采用通道注意力，全局池化 + 1*1 卷积表示相机端和 `LiDAR` 端特征的权重比。

## `DETR3D`

> `DETR3D` 是一种用于重建图像连续深度的方法，与传统的离散深度分布不同。它的核心方法是围绕连续深度预测展开，通过先预测深度图，然后利用原始图像和深度图将其映射到 3D 点云空间。

![](img/1caa669c84378e5f1bf07b1bfe5a1fe9.png)

> `DETR`：优雅的 2D 目标检测算法。`DETR3D`，与 `DETR` 的思想一致，直接在多视角图片上进行 3D 检测。采用将 object query 经过 `transformer` 获得 3D 参考点，然后投影到图像，提取特征获得 3D 检测框。

[DETR3D：通过 3D 到 2D 查询从多视图图像中检测 3D 对象.pdf](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/H8jbbNdyYo7CmbxilHycA6g7nJg)

![](img/38bfde1bf90ea9942e4f37c40d92c660.png)

[DETR：用于端到端物体检测可变形变压器.pdf](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/A7MhbsnexoCFaMxioYyc7Id0nAf)

`DETR3D` 的过程可以总结如下：

1. **深度图预测：**首先，使用 `DETR3D` 模型对输入图像进行处理，预测出连续的深度图。这个深度图表示了图像中每个像素点的深度值。

1. **3D 点云映射：**接下来，使用原始图像和预测的深度图，将图像中的像素点映射到 3D 点云空间。通过计算每个像素点的 3D 坐标，可以得到一组表示场景中物体位置的点云数据。

1. **3D 到 2D 的 BEV 空间构建：**在 3D 点云空间中，通过将点云投影到图像平面上，构建了一个称为 Bird's Eye View（BEV）空间。BEV 空间是在俯视图中观察场景时所看到的视角，它提供了一种更直观的场景表示方式。

1. **2D 图像特征查询：**`DETR3D` 使用预先设定的 object query，这是一组表示物体的特征向量。这些特征向量类似于锚点，用于查询图像中与之匹配的物体特征。

1. **特征提取：**通过使用 `transformer` 模型，将 object query 转换为参考点（3D box 的中心点坐标），然后将这些参考点投影到图像像素上。接下来，提取图像中与参考点相对应的目标特征。

![](img/1d9ef7762aa25ee954eb141b879b2720.png)

> `DETR3D` 输出的目标特征可以用于物体检测、定位和跟踪等任务，以实现对场景中物体的全面理解和分析。这种基于连续深度预测和 3D 点云的方法使得 `DETR3D` 在处理图像和场景中的物体时能够更准确地捕捉到深度信息，并提供更丰富的视觉理解能力。

简单来说，BEV 转换流程：

+ ① 输入是多视角图像特征以及预先设定的 object query（比如 300 个 256 维，是一个 embedding 的向量，意义类似 anchor，随机初始化找物体）

+ ② object query 通过 `transformer` 生成 reference points（3d 参考点，也就是 3d box 的中心点坐标）

+ ③ 将点投影到图像像素

+ ④ 图像特征提取

+ ⑤ 输出目标特征

## `PETR`

> 在 `DETR3D` 上进行改进，认为其存在的问题：参考点索引图像特征不准确，投影到图像位置会有偏差。另外，参考点投影到图像特征来更新 object query 不充分，对全局特征考虑不完整。并且采样过程比较复杂。

改进方法：2D 特征 + 3D 编码，获得了 3D 特征。省略了采样和投影的过程。

![](img/6a7d16f3c2ba49c661b195cf773ad40f.png)

![](img/3aab7a61efd4dae196c599757247458e.png)

> 简单来说，即为增加一个 3D 坐标生成器，将相机视锥空间的点离散为 W*H*D 并投影到 3D 空间中。将 3D 的位置编码到 2D 图片的特征中。通过 `FC` 到相同的通道数。

## `BEVDepth`

> 它将点云数据投影到 BEV，然后利用 `CNN` 预测每个像素的深度信息。`BEVDepth` 的优点在于它能够产生高质量的深度图，这对于导航和物体检测等任务非常有用。

2D->3D 目前的缺点：深度不可靠。

> ① 没有明确的深度监督。

> ② 网络无法利用相机的内外参数，无法有效推断像素深度。

> ③ 深度估计网络额外耗费时间。解决方法：引入深度监督，内外参数。

![](img/2d40943d97c66b4ab20a03545be54960.png)

核心：

深度网络：输入图像特征和相机参数。输出图像特征和深度分布。将相机的参数扩维，视为加权特征。输出深度分布。

>

深度监督：来源于点云投影的深度，来辅助深度估计网络的训练。外参有偏差，导致点云深度有偏差，因此引入 `Depth refinement` 网络来校准。获得 BEV 特征。
