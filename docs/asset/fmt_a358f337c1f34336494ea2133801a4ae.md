
# Azure AI 文档智能自定义模型

## 自定义模型

允许用户在不确定使用哪个模型最合适时提交表单。

自动将表单发送给正确的自定义模型进行分析。

### 自定义模型类型

**自定义模板模型**：适用于具有一致视觉对象模板的表单。

**自定义神经网络模型**：适用于不太一致或半结构化/非结构化表单。

### 管理自定义模型

在单个`Azure AI 文档智能`资源中可以创建数百个自定义模型。

用户在发送表单进行分析时必须指定模型标识。

### 使用组合模型

创建自定义模型后，将它们组合成一个组合模型。

使用`Azure AI 文档智能工作室`或`StartCreateComposedModelAsync()`方法在GUI中执行此操作。

提交表单进行分析时，指定组合模型的模型ID。

通过检查`docType`字段确定用于分析的自定义模型。

### 组合模型的容量

免费(F0)层最多500个自定义模板模型，5个组合模型。

标准(S0)层最多5000个自定义模板模型，200个组合模型。

单个组合模型最多包含100个自定义模型。

### 自定义模型兼容性

自定义模板模型只能与3.0到2.1 API版本中的其他自定义模板模型组合。

自定义神经网络模型只能与其他自定义神经网络模型组合。

自定义神经网络模型不能与自定义模板模型组合。

### 组装组合模型

**创建组合模型的背景**：在民意调查公司中，需要创建一个组合模型来分类并正确分析不同版本的政治性民意调查表格。

**在文档智能工作室中创建组合模型**：需要`Azure`订阅中的`Azure AI 文档智能`资源和一组经过训练和标记的自定义模型。

在`Azure AI 文档智能工作室`的“自定义模型”页面中选择“模型”并选择要组合的模型。

选择“组合”后，输入组合模型的“模型 ID”和“说明”，然后选择“组合”。

![](img/8fe1d4560293069c00e9bc27384d3b21.png)

**在代码中创建组合模型**：

```
List<string> modelIds = new List<string>()
{
    firstCustomModel.ModelId,
    secondCustomModel.ModelId,
    thirdCustomModel.ModelId,
};

BuildModelOperation operation = await client.StartCreateComposedModelAsync(modelIds, modelDescription: "Composed model example");
Response<DocumentModel> operationResponse = await operation.WaitForCompletionAsync();
```

将所有自定义模型的模型ID组装到一个列表中，并将该列表传递给`StartCreateComposedModelAsync()`方法。

创建组合模型后，使用相同的代码将表单发送给模型进行分析，并在调用中指定组合模型的模型ID。

在结果中，使用`docType`属性来确定用于分析每个文档的组成自定义模型。

```
import os
from dotenv import load_dotenv
from azure.ai.formrecognizer import FormRecognizerClient
from azure.core.credentials import AzureKeyCredential

task = FormRecognizerClient.begin_recognize_content
def analyze_invoice(form_recognizer_client, file_path, invoice_total):
    with open(file_path, "rb") as f:
        form_data = f.read()
    # Need to determine which method to send the form to
    task = form_recognizer_client.begin_recognize_receipts(form_data)
    analyzed_result = task.result()
    for receipt in analyzed_result:
        for name, field in receipt.fields.items():
            if name == "VendorName":
                print("Vendor Name: '{}'".format(field.value))
            if name == "InvoiceTotal":
                if field.value is not None:
                    print("Invoice Total: '{}' with a confidence score of '{}'".format(
                        field.value, field.confidence))
                    # Add to invoice total, and filter by confidence > 0.75
                    if field.confidence > 0.75:
                        invoice_total += field.value
                    
    return invoice_total

def main():
    try:
        # Get configuration settings
        load_dotenv()
        form_endpoint = os.getenv('FORM_ENDPOINT')
        form_key = os.getenv('FORM_KEY')
        # Create client using endpoint and key
        form_recognizer_client = FormRecognizerClient(
            form_endpoint, AzureKeyCredential(form_key))
        # Analyze all files in the folder c:\app1\invoices
        folder_path = r"C:\App1\Invoices"
        invoice_total = 0
        for filename in os.listdir(folder_path):
            if filename.endswith(".pdf"):
                file_path = os.path.join(folder_path, filename)
                print("Analyzing file: {}".format(file_path))
                invoice_total = analyze_invoice(form_recognizer_client, file_path, invoice_total)
        print("\nTotal Invoice Amount: {}".format(invoice_total))
    except Exception as ex:
        print(ex)

if __name__ == '__main__':
    main()
```
