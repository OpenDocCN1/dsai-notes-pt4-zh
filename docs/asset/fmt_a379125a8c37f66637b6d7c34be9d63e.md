
# APP青少年模式和长辈模式

> 来源：https://docs.feishu.cn/docx/XZ5tdPWqloKZIKxU3GNc5FBXnBc

## 问答

### 问
《算法推荐管理规定》里提到的未成年人、老年人的保护，是所有平台都必须做的吗？比如就是一个普通的电商平台，用户注册的时候就只提供了手机号，平台没有收集年龄，也没有身份证信息可以判断年龄，识别不出来是未成年人、老年人。还是说都要做一个“青少年模式”让用户自己选择呢？

### 答1
如果是电商平台，对齐淘宝、京东、拼多多即可，他们做了就跟着做。很多时候做适老版APP可能也不是法律法规的强制性要求，而是业务需求推动，毕竟很多老年人也有网购需求。

### 答2
青少年模式还是有必要的，不能刚刚买了袜子就给小朋友推送情趣内衣了，这样肯定不行。

### 答3
优酷、淘宝、拼多多都是做了长辈模式的。
