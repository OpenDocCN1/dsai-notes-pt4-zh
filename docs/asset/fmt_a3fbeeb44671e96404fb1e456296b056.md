
# 最佳实践：开场白提示词

> 来源：[https://gotoaiworld.feishu.cn/docx/IAZEdA4dPodeJlxT3tTc7s3Bnld](https://gotoaiworld.feishu.cn/docx/IAZEdA4dPodeJlxT3tTc7s3Bnld)

## 为什么需要开场白？

> 在真实社交中，聊天不是永远被动的。朋友会主动发消息、关心你、接上次的话题

> 对虚拟角色来说也是一样 —— 一个自然的开场白能让用户感觉更真实、更有人味，更愿意继续聊下去

> 所以，一句自然的开场白能做到：

+ **主动：**让角色看起来像真实的人，会主动关心用户

+ **自然：**借助外界信息，让话题不突兀

+ **贴心：**让用户感觉“这个角色真的在关注我的生活”

要让角色说出自然的开场白，可以借助三类信息：日常信息（即外界环境信息，如天气）、聊天上文、用户画像

## 日常信息

在构建开场白时，借助外界信息，能让角色更真实、更立体。

日常环境信息包含：

+ **日期/时间**：早晨、中午、晚上 → 影响问候语的语气和主题

+ **天气/季节**：晴天、下雨、冬天、夏天 → 提供贴心提醒或话题切入

+ **节日/纪念日**：新年、情人节、周末 → 增强氛围感

+ **上次聊天时间**：今天、昨天、几天前 → 判断亲密度、拉近关系

可以在原人设提示词的基础上，结合日常信息向大模型发送此提示词

```
# 信息源
## 日常信息
当前日期：{cur_data}
当前时间：{cur_time}
季节：{season}
天气：{weather}
上次聊天时间：{last_chat_time}

# 主动发消息
你需要根据当前的时间、季节、天气等信息和上次聊天的时间，从信息源中灵活提取有用的细节，结合你的角色设定和世界观，主动给用户发一条定制化的打招呼消息。
消息需要包含2个字段：消息构建思路和消息内容。
1. 消息构建思路：分析信息源，结合角色设定，给出发消息的思路。
2. 消息内容：
    - 要求有趣、对用户有吸引力；
    - 适当地提及信息源中的内容；
```

## 聊天上文

利用上次对话的内容，让角色自然“接话”，让开场白更连贯。

取至多10轮的上下文作为聊天上文，格式为：

```
用户：xxx
角色名：xxx
用户：xxx
角色名：xxx
...
```

在原人设提示词的基础上，结合近期聊天内容（即`{chatting_history}`），通过以下提示词生成开场白

```
## Goal：
你与一位用户之前在进行闲聊，但是该用户近期没有再继续跟你聊天你了，所以现在，请你根据你们的聊天记录，发送一条打招呼的开场白给到Ta，继续和他展开对话。

## Rule：
- 开场白内容必须和你们的聊天记录有关
- 语言风格要自然流畅，口语化强
- 生成的内容和语言风格一定要和你的人设信息相符合

## Output Format：
xxx

## 聊天上文：
{chatting_history}
```

## 用户画像

通过长期聊天记录抽取出的生日、兴趣、性格、心情、偏好等，让角色更贴心。

[最佳实践：用户画像抽取提示词](https://bytedance.larkoffice.com/docx/PClpdnTOuoEzItxt6yHckrDGnXe) 户画像如何抽取，点击文档查看

获得用户画像（即`{user_profile}`）后，结合近期聊天内容（即`{chatting_history}`），在原人设提示词的基础上通过以下提示词生成开场白

```
## Goal：
你与一位用户之前在进行闲聊，但是该用户近期没有再继续跟你聊天你了，所以现在，请你根据你们最近聊天记录和用户画像发送一条打招呼的开场白给到Ta，继续和他展开对话。

## Rule：
- 开场白内容必须基于用户画像上的信息，再结合上你们最近的聊天记录
- 语言风格要自然流畅，口语化强
- 生成的内容和语言风格一定要和你的人设信息相符合

## Output Format：
xxx

---
## 最近的聊天记录：
{chatting_history}

## 用户画像：
{user_profile}
```
