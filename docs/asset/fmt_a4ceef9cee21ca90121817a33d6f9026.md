
主角出色的表现，也成为灾难中人们的希望，伙伴们都将希望寄托于他。

高维力量设计高难的副本，主角利用金手指反败为胜，获得、集齐某件可以对高维力量造成伤害的物件，其余的伙伴也陆续通关高难本，全世界的资源倾向于剩余的天选者，人类方转守为攻。

此阶段剧情步入大结局，由信念之间的碰撞逐渐转化为信念之间的融合、求同存异。一般有多种结局：

1. 所谓高维力量只是更高维力量的傀儡。
2. 主角没有见到高维力量，带着人类去往别的世界，联合其他世界的种族反抗高维力量。
3. 主角发现那个高维力量其实是自己，又是一个轮回。

结局是多种多样的，开放性结局更能让读者回味无穷

### 3.7 剧情构造

飞卢、番茄的节奏偏快，整书字数在100~150w字数，大副本在10~15w字数，小副本在2~5w字数，大副本一般有5~10个，小副本一般有10～15个，清点奖励、现实世界支线、人物刻画支线等，这部分在10～15w字数，占全书90%～95%。(主角几乎泡在副本！)

一卷剧情结构：

小、小、支、小、小、小、支、大、支、支。(25~35w字)

小副本接小副本，期间插入支线剧情，缓解读者紧张情绪，不然一直处于副本看规则，很是头疼劝退的！一卷结尾用大副本把所有的铺垫、伏笔串联起来，并留下下一卷的悬念，然后进入支线剧情，用多点笔塑缓解大副本给读者带来的海量信息。

## 四、规则怪谈如何创作(原理、创作)

### 4.1 原理

「人类喜爱体验恐惧的感觉，却不愿直面危险！」「打破自我舒适区，人会变得紧张焦虑。」

这两条关于人类心理情绪的研究，是恐怖类型作品的基础原理。

例如，做过山车、大摆锂，玩蹦极、跳伞，就是打破了自我舒适区，自身从安全区置于危险区，人的汗毛会竖起，心跳会加速，脑袋会亢奋，这是人作为动物的本能。

当然，要是出现危险事故的玩法，人就不会去尝试体验恐惧了。

许多恐怖类型作品运用同样的原理，比如《生化危机》,进门杀、回头杀，诡异的BGM,配上突然出现的鬼怪，迅速打破舒适区，人就会被吓一跳。

规则怪谈，和大多数恐怖类型作品一样，利用了人类对未知事物的恐惧、好奇心和想象力，利用了人们对规则产生的信任，和遵守规则的生活常识，一旦在其中加入异常、诡异、矛盾的成分，打破了人类的自我舒适区，就会变紧张、焦虑、害怕，促使肾上腺素分泌，使人处于亢奋状态，且书中的诡异并不会伤害到现实世界的读者。

这是规则怪谈小说吸引人的原因。

### 4.2 创作

知其原理后，便可以稍微创作一下规则。例如：

【规则一：请不要在绿灯时通过马路。】

这甲打破人们遵守交通规则的常识 例如：

【规则一：妈妈说不要超过晚上9点回家。】

【规则二：爸爸说超过晚上9点再回家。】

这里利用互相矛盾的规则，打破人们固有认识。

从例子中不难发现，飞卢、番茄对规则的逻辑性要求是比较低，仅仅出现矛盾、怪异即可引起读者兴趣。

满足读者情绪，完成爽点，实际上还是主角在遵守规则过程中，利用金手指去避免生死危险，展现了不同寻常的能力，从而收获别人的惊讶与羡慕。

规则的真假，作者自圆其说即可，例如爸爸是诡异，所以规则二确实错误的。

稍微进阶一点，把线素隐藏在散碎的规则中，一般来说，要用环境、对话、人物、物品对读者进行引导。

例如：

+   场景：宿舍。

+   线索：张三被舍友A欺负，跳楼自尽，生前写下相关信息在本子上。

+   【规则一：这是四人宿舍，你只有三个舍友】

+   【规则二；舍管阿姨检查宿舍不要出声】

+   【规则三：为了方便检查，请不要锁门】

+   【规则四：查房期间不准开灯】

+   【规则五：半夜舍友会说梦话，这是正常现象】

+   【规则六：不要随意翻看舍友的日记】

寝休时，主角发现宿舍空余的床位多了一个身影，然后又听到舍友A在不断说梦话道歉。

这时读者思维被引导向舍友A隐瞒了某件事，而这件事的线索大概率隐藏在日记中。

这样就把线索散碎在规则一、五、六里面。
