
# 产品功能更新

## 知识库元数据
### 1.1 🏷️ 知识库级元数据定义
支持 `String`、`Number`、`Time` 三种数据类型；提供 6 个内置元数据字段（`document_id`、`document_name`、`upload_time`、`update_time`、`uploader`、`updater`）。

### 1.2 📝 文档级元数据赋值
为单个文档灵活添加、编辑、删除元数据标签。

### 1.3 🔍 工作流元数据过滤
文档知识库检索节点/问答节点支持元数据过滤；支持多条件组合（`AND`/`OR`）与丰富的过滤操作符。

### 1.4 🔌 API 接口支持
提供元数据增、删、改、查的相关 `API` 接口。

## 看板与图表
### 2.3 📈 丰富的看板组件
内置柱状图（基础/堆叠/分组）、条形图（基础/堆叠/分组）、折线图（基础/堆叠/面积）、饼图、环形图、指标卡以及全局时间查询组件，满足多样化数据展示需求。

### 2.4 🔧 精细的图表配置
支持维度/指标拖拽配置、数值格式自定义、复杂筛选和排序条件以及个性化样式配置。

## 系统管理
### 3.1 📚 知识库文件解析优化
优化 `docx`、`ppt` 文件的处理逻辑，解决部分边界情况解析失败问题。

### 3.2 👥 系统管理优化
支持按角色授权“工作台”与“管理后台”空间访问，增加对看板操作行为的审计日志记录。

## 文档组织与检索
为知识库提供精细化的文档组织和检索能力，支持在工作流中实现精准的文档召回。

## 模型管理与体验
### 2.1 🎨 模型管理优化
"通义千问"更名为"阿里云百炼"；模型广场新增 10 个主流厂商的 `API Key` 获取和模型文档快速入口。

### 2.2 ⚡ 使用体验提升
工作流预置问题/变量引用实时同步更新、模型微调权限优化等多项改进。

## 语音交互
### 1.1 语音输入 (ASR)
在输入框中点击“麦克风”图标，直接通过语音输入文字。

### 1.2 语音播报 (TTS)
AI 回复消息旁新增了“扬声器”图标，点击即可收听语音播报。

### 1.3 模型支持
后台系统模型设置中支持配置 `ASR` 模型与 `TTS` 模型，已支持 `OpenAI`、`Azure`、`通义千问` 模型服务提供方格式。

## Markdown 渲染增强
### 2.1 Markdown 渲染增强
会话内容现已支持渲染 `Echarts` 图表和 `Mermaid` 流程图。

要渲染图表，请使用 `echarts` 代码块，并将配置写入其中，示例如下：

```echarts
{
  "title": {
    "text": "ECharts 入门示例"
  },
  "tooltip": {},
  "legend": {
    "data": ["销量"]
  },
  "xAxis": {
    "data": ["衬衫", "羊毛衫", "雪纺衫", "裤子", "高跟鞋", "袜子"]
  },
  "yAxis": {},
  "series": [{
    "name": "销量",
    "type": "bar",
    "data": [5, 20, 36, 10, 10, 20]
  }]
}
```
