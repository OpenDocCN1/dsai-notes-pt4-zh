
# AI 图像生成工具

+ **💬 [ChatGPT](https://chatgpt.com/)：**官方 OpenAI 产品。使用 `GPT-4o` 生成高质量图像，支持多种风格和详细控制，适用于创意表达和内容创作。

+ **🎬 [Sora](https://sora.com/)：**官方 OpenAI 产品。通过 `GPT-4o` 生成逼真的图像，支持文本-图像组合和场景重建，适用于电影和动画等视觉创意场景。（注意：`Sora` 访问目前有限制）

+ **🤖 `gpt-image-1` API：**由 OpenAI 官方开发的最新图像生成模型可以通过 API 访问，并提供：

+ ✅ 更加准确、高保真度的图像

+ 🎨 多样的视觉风格

+ ✏️ 精确图像编辑

+ 🌎 富有的世界知识

+ 🔤 一致的文本渲染
