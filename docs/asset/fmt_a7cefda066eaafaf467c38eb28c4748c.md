# 七、私人定制类产品

接下来，让我们聊一下我称之为"私人定制类"的AI产品。这个分类的命名有其特殊原因：

1. 这类产品主要允许用户对AI模型进行个性化选择。

3. 支持用户设计和实现一系列自定义的工作流程。
4. 这些产品通常需要一些前端技术知识，以便更好地创建内容和优化使用体验。
