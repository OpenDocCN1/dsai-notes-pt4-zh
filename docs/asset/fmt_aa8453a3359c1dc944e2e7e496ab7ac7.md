## 🔔AI情报助手早报「12月08日」

### 1️⃣ 微软、上海交通等发布首届数据污染报告，开闭源模型皆被污染

+ 首届数据污染报告指出，自然语言处理中的评估数据被无意中包含在预训练数据集中，影响模型评估结果。
+ 报告由麻省理工、上海交通、哈佛大学等20多家机构联合发布，共包含42个受污染的源、91个数据集和566个污染条目。
+ 数据污染问题在文本评分、问答和多项选择问答等任务类型中最为严重，知名数据集`MMLU`、`GLUE`和`ai2_arc`也存在污染。
+ 大多数污染证据针对闭源模型，如`GPT-3`和`GLaM`，开源模型如`FLAN`和`Mistral`也受到一定程度的污染。
+ 最新发布的模型更易受到最近发布的数据集污染，如`GPT-4`主要受2018至2022年数据集的污染。

关键词：数据污染，自然语言处理，模型评估，闭源模型，开源模型

### 2️⃣ 贾佳亚、徐立研究工作获 SIGGRAPH Asia 2024 时间检验奖 | AI 顶会直击

+ SIGGRAPH Asia 2024在日本东京举办，贾佳亚和徐立的研究工作获得时间检验奖。
+ 贾佳亚团队的《`TEXGen: a Generative Diffusion Model for Mesh Textures`》论文，提出了一种新的3D纹理测试方法，不依赖于预先训练的2D扩散模型。
+ 徐立作为一作的论文《`Structure extraction from texture via relative total variation`》提出了一种新模型，有效分解图像中的结构信息和纹理。
+ 会议论文提交数量呈直线上升，共收到900篇论文，接受率达29.4%。
+ 获奖论文中，有华人参与的论文共4篇，展现了华人在AI领域的研究实力。

关键词：SIGGRAPH Asia，AI研究，纹理测试，图像分解，华人学者

### 3️⃣ 深度 | DeepMind高级研究总监专访：AI是否能够实现真正的艺术创作？

+ 🎨 AI技术在艺术创作领域取得显著进展，但真正的创造力仍源于人类。
+ 🤖 DeepMind高级研究总监`Douglas Eck`认为，AI模型可以生成新颖内容，但艺术的社会层面和人类经验不可替代。

+ 🧬 AI生成的艺术作品引发关于原创性、版权和艺术家角色的讨论。

### 4️⃣ 马斯克起诉OpenAI：要求开源产品，36页诉状大公开！

+ 马斯克再次起诉`OpenAI`，指控其违反垄断法并要求恢复开源产品理念。
+ 诉状指出`OpenAI`与微软市场垄断，董事会成员交叉任职，违反《克莱顿法》和《谢尔曼法》。
+ `OpenAI`被指背离非营利初衷，马斯克要求重新审视开源承诺，阻止其成为营利企业。
+ 开源模式有助于AI技术的广泛传播和创新生态的繁荣，对全球开发者和研究人员有积极影响。
+ 网友对`OpenAI`的封闭态度表示遗憾，认为应保持开源透明，马斯克的行动可能为行业设立先例。

关键词：`OpenAI`，垄断法，开源，非营利，AI技术

### 5️⃣ 今日开源（2024-12-02）：`INTELLECT-1`，首个以去中心化形式训练得到的10B大模型，1万亿token数据训练

+ `INTELLECT-1`是全球首个去中心化社区协作训练的10B参数语言模型，使用1万亿英语文本和代码`token`进行训练。
+ `GLM-Edge`是由清华大学团队开发的对话生成模型，基于`Transformer`架构，专注于中文对话生成。
+ `minRLHF`是一个最小化的`RLHF`实现，提供了一个小型、清晰、可解释的`GPT`实现，用于教育和展示语言模型训练和推理。
+ `GitDigest`是一个Web界面，将`GitHub`代码库转换为`LLM`提示的文本摘要，提供智能格式化和统计数据。
+ `Report`项目提供了一种替代`Jupyter Notebook`的方法，通过生成`Python`文件进行数据分析和可视化，输出静态`HTML`页面。

关键词：去中心化，10B参数模型，对话生成，LLM提示，数据分析
