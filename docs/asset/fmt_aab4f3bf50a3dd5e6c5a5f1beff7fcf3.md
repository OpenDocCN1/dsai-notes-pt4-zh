
# 2025-02-02平民流量手册（一），聊聊普通人副业创业能用的实在技能

> 来源：`https://xuqiwei1986.feishu.cn/docx/IGVUdwknToXADrxFcGNcYDpHnWe`

本文主要讲述了普通人在开启副业走向个体创业过程中可用的技能与思维框架。核心观点是通过掌握一些方法和思维，实现提效降本，助力创业之路走得更稳。重点如下：

### 占位思维
在互联网中，主动搜索流量价值高，关键词分为真实与伪需求，找到长尾且精准的关键词很重要，如“上海陆家嘴大闸蟹礼盒品牌哪家强”，通过占据关键词入口，可独享流量。

### 四小时流量高手速成法
以📕为例，花3小时加30-50个同行，收集资料、整理热门模板，模仿优秀同行，还可从同行处获取行业百问百答，此方法在各大平台通用。

### 选择即经营
基于场景下的需求选择产品或服务，如“看病”场景下有陪诊等多种需求，产品可衍生出一整盘货，如鲨鱼裤可衍生出瘦腿袜等，要考虑流量与客户价值，符合“五高”标准。

### 流量平台逻辑
抖音是推送逻辑，淘宝是古典搜索逻辑，📕约70%搜索逻辑、20%多推送逻辑，🛰️生态流量分配有变化，搜一搜等入口的调整会影响流量走向。

总之，文章提供了很多实用的创业思路和方法，对创业者有很大的启发和帮助。
