## 2️⃣ 🧚🏻‍♀️ 陶哲轩新论文“太反直觉”：再战Erdős问题，证明44年数学猜想是错的

+ 陶哲轩最新论文在数学领域取得重大进展，证明了一个存在44年的数学猜想是错误的。
+ 论文中提出了一个反直觉的猜想，即存在一个递增的自然数级数，使得对任意有理数t，级数和都是有理数。
+ 该研究颠覆了传统直觉，通过迭代逼近法解决了无限维度问题，扩展了对Ahmes级数的理解。
+ 陶哲轩的方法避免了数论难题，依赖有理数集的可数稠密性，将Stolarsky猜想转化为无限维问题。
+ Erdős问题#266的解决不是陶哲轩的第一个成就，他之前已解决过其他Erdős问题，展现了其在数学领域的深厚实力。

## 5️⃣ 🧠 写给小白的大模型应用科普：RAG篇

+ RAG（Retrieval-Augmented Generation）是一种结合检索增强生成的技术，旨在解决大模型在实际应用中遇到的“幻觉”问题。
+ 大模型的“幻觉”问题表现为在生成内容或回答问题时输出不完全正确或错误的内容。
+ RAG通过结合实时信息检索技术，为大模型提供外部数据和上下文，以生成更丰富、准确、可靠的内容。
+ RAG与模型微调是提高大模型适应性和准确性的两种方法，各有优势和适用场景。
+ RAG架构包括数据索引和查询两个阶段，实际应用中需针对不同场景进行优化设计。

### 关键词
RAG，大模型，人工智能，自然语言处理，知识检索

## 6️⃣ 🧚🏻‍♀️ 瞎聊: SFT模型为何不如Pretrain模型

+ 文章探讨了SFT模型相较于Pretrain模型在知识掌握上的不足，提出了分布差异导致幻觉的观点。
+ 讨论了SFT训练中可能遇到的问题，如局部最优解和数据质量问题，但认为这些不足以解释SFT模型的不足。
+ 分析了SFT模型可能因为学习特定模式而改变了传统语言模型的续写能力。
+ 通过哲学角度的“捷径”概念，指出SFT模型可能因为省略关键推理步骤而产生知识幻觉。
+ 提出如果不省略推理步骤，模型可能不会产生幻觉，暗示了o1技术路线的潜在价值。

### 关键词
SFT模型，Pretrain模型，知识幻觉，推理步骤，o1技术路线

## 4️⃣ 🚀 Pandas要退休了，速度狂飙50倍！

+ Pandas可能不再是数据分析的首选工具，因为FireDucks的出现，它的速度比Pandas快50倍。
+ 从Pandas迁移到FireDucks非常简单，只需更改一行代码即可。
+ FireDucks的多核处理能力和基于Lazy Execution的特性使其在复杂数据处理场景中表现更优。
+ 与Pandas的Eager Execution不同，FireDucks在需要结果时才执行计算，这可以减少不必要的中间计算和提高效率。
+ 即使在Eager Execution模式下，FireDucks的速度也远超Pandas。

### 关键词

+ 该研究发表在《Nature Methods》上，RhoFold+的成功展示了其学习底层结构原理的能力，对RNA研究领域具有重要意义。🧚🏻‍♀️
