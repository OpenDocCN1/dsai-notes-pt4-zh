### 市场常见方案对比

### 我的建议

采用标准版，简化为 2 个核心统计：

+   `Current Balance`: 当前可用积分
+   `Total Purchased`: 累计购买积分（不含赠送）

或者保持 4 个，但修复计算逻辑。

但由于需要配置 Firebase Admin SDK 的服务账号密钥，让我提供一个更简单的方法：

### 方法 A: 在 Firebase Console 的 Cloud Shell 中运行

1.  访问 Firebase Console
1.  点击右上角的 Cloud Shell 图标
1.  粘贴以下代码并运行：

```javascript
// 在 Firebase Cloud Shell 中运行
const admin = require('firebase-admin');
admin.initializeApp();

const db = admin.firestore();

async function generateCodes() {
  const batch = db.batch();
  const codes = [];
  const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';
  for (let i = 0; i < 50; i++) {
    let code = 'PSTRY-';
    for (let j = 0; j < 6; j++) {
      code += chars.charAt(Math.floor(Math.random() * chars.length));
    }
    codes.push(code);
    const ref = db.collection('promoCodes').doc();
    batch.set(ref, {
      code: code,
      credits: 100,
      isRedeemed: false,
      redeemedBy: null,
      redeemedAt: null,
      expiresAt: new Date('2025-12-31'),
      description: '首批推广优惠码'
    });
  }
  await batch.commit();
  console.log('✅ 生成了 50 个优惠码:');
  codes.forEach((c, i) => console.log(`${i+1}. ${c}`));
}

generateCodes();
```
