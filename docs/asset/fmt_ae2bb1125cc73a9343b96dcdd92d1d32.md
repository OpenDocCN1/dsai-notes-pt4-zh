## 8.1 Skill 开发基础

### 8.1.1 核心概念

**什么是 Skill？**

Skill 是 OpenClaw 的能力扩展包——一个 Markdown 文件，用自然语言告诉 AI 如何完成特定任务。

**三要素关系：**

```
Tools（工具）= 手 → 执行能力
Skills（技能）= 教科书 → 使用方法
Memory（记忆）= 大脑 → 经验积累
```

**Skill 生命周期：**

1. **发现**：扫描 `skills` 目录，读取 frontmatter
2. **匹配**：LLM 根据 `description` 选择合适的 Skill
3. **执行**：加载指令到 System Prompt，调用 Tools
4. **缓存**：快照会话开始时的 Skills，后续复用

**标准文件结构：**

```
my-skill/
├── SKILL.md       # 核心文件（必需）
├── README.md      # 说明文档（推荐）
├── scripts/       # 辅助脚本（可选）
└── examples/      # 示例数据（可选）
```

### 8.1.2 开发环境搭建

**快速配置：**

```bash
# 1. 创建 Skills 目录
mkdir -p ~/.openclaw/workspace/skills

# 2. 配置路径（~/.openclaw/openclaw.yaml）
skills:
  extraDirs:
    - "~/.openclaw/workspace/skills"
  watch: true        # 启用热重载
  autoload: true

# 3. 验证环境
openclaw skills list
```

## 8.2 Skill 开发规范

### 8.2.1 命名规范

**✅ 好的命名：**

+ `weather-check`（小写 + 连字符）
+ `github-pr-reviewer`（清晰描述功能）
+ `data-csv-analyzer`（动词 + 对象）

**❌ 避免：**

+ `WeatherCheck`（驼峰命名）
+ `wc`（过于简短）
+ `my-awesome-skill`（主观描述）

**Description 原则：**

+ 一句话说清功能
+ 包含关键词（便于 LLM 匹配）
+ 避免技术细节
+ 控制在 100 字符内

### 8.2.2 代码结构

**标准 `SKILL.md` 结构：**

```markdown
---
name: skill-name
description: 一句话描述功能
metadata:
  openclaw:
    requires:
      env: [API_KEY]
      bins: [curl, jq]
    primaryEnv: API_KEY
---

# Skill 标题

简短介绍（1-2句）

## Prerequisites
列出前置要求

## Instructions
### Step 1: [动作名称]
清晰具体的指令

## Output Format
明确输出格式

## Error Handling
- 错误情况 1：处理方式
- 错误情况 2：处理方式

## Examples
实际使用示例
```

**指令编写四原则：**

1. **清晰步骤**：分解为明确的步骤
2. **具体示例**：提供代码和输出示例
3. **明确错误处理**：列出常见错误及应对
4. **约束 AI 行为**：用 `NEVER`/`ALWAYS`/`MUST` 明确规则

### 8.4.2 错误处理

1. **输入验证**：执行前捕获错误

3. **恢复策略**：指数退避重试
4. **优雅降级**：提供部分结果
