## 示例调用

例如：

```
result = agent.invoke(
    {&quot;messages&quot;: [{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;请问今天杭州和南昌哪里更冷？&quot;}]}
)
```

## 访问消息内容

```
result[&#x27;messages&#x27;][-1].content
```
