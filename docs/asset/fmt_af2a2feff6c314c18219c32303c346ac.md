## 四、常见问题

### 读取文档失败？

**可能原因：**

+ 文档链接格式不对
+ 没有文档访问权限
+ 飞书应用权限不够

**解决方法：**

1. 确认链接格式：`https://xxx.feishu.cn/docx/xxxxx`
1. 在飞书里打开文档，确认你能看到
1. 检查应用权限是否包含查看文档

### 写入文档没有编辑权限？

**原因：**

OpenClaw 创建文档后，默认只给你查看权限

**解决方法：**

+ 让OpenClaw 自动添加你的管理权限
+ 如果失败，刷新页面试试
+ 或者手动在飞书里设置权限

### 会不会泄露数据？

**不会。**

+ OpenClaw 在你本地运行
+ 数据不经过第三方
+ 飞书 API 是官方接口，安全可靠
+ 你的飞书凭证只保存在本地配置文件

### Obsidian 在哪里？

**默认位置：**

+ Mac/Linux：`~/Documents/notes/`
+ Windows：`C:\Users\你的用户名\Documents\notes\`

**可以改吗？**

+ 可以，在 OpenClaw 配置里修改
+ 或者直接告诉AI：把笔记保存到XXX目录

### 能处理多大的文档？

没有限制。
