> 来源：[https://docs.feishu.cn/docx/WcohduotlowH0kxfNIScLUN4nuh](https://docs.feishu.cn/docx/WcohduotlowH0kxfNIScLUN4nuh)

## 课程推荐

+ 吴恩达机器学习系列课程：[中英字幕]吴恩达机器学习系列课程_哔哩哔哩_bilibili 由浅入深介绍机器学习，很好的入门学习资料，非常适合想要机器学习的同学。

+ 亲自动手学习深度学习：前言 — 动手学深度学习 2.0.0 documentation 网站详细介绍从编程环境搭建到自己动手搭建机器学习的过程，对编程感兴趣的同学可以尝试学习。

## 书籍推荐

+ 《[深度学习](https://wx.zsxq.com/mweb/views/weread/search.html?keyword=%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0)》该书是深度学习领域经典教材，详细介绍了基本的数学工具和机器学习的概念。

+ 《[深入浅出神经网络与深度学习](https://wx.zsxq.com/mweb/views/weread/search.html?keyword=%E6%B7%B1%E5%85%A5%E6%B5%85%E5%87%BA%E7%A5%9E%E7%BB%8F%E7%BD%91%E7%BB%9C%E4%B8%8E%E6%B7%B1%E5%BA%A6%E5%AD%A6%E4%B9%A0)》非常好的神经网络入门读物。

+ 《BERT基础教程：Transformer大模型实战》深入介绍BERT 的工作原理。
