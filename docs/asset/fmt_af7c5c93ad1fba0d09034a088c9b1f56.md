
**意义**：AUC 取值范围在 0 到 1 之间。AUC = 1 表示模型能完美区分正例和反例；AUC = 0.5 意味着模型预测效果等同于随机猜测；AUC 越接近 1，模型性能越优；越接近 0.5，模型性能越差。

### 2.5.4 代价敏感错误率与代价曲线

> 此章节在2.5.2 查准率 / 查全率 / F1其实已经有过相关理念的讲解，可以回过去再看看

在分类任务中，犯不同类型的错误（正例预测成假例、将假例预测成正例）往往会造成不同的损失，即非均等代价(unequal cost)，此时需考虑引入代价敏感（cost-sensitive）来“敏感” 地权衡不同代价。

> 为什么要引入代价敏感（cost-sensitive）？

> 在医疗诊断中，将患病判断为未患病（假反例 ）的代价可能远高于将未患病判断为患病（假正例 ）的代价。也就是俗话说的“不怕一万，就怕万一”。

> 拿近期的“外卖大战”举例：

> 非均等代价：用外卖平台优惠券时，“券过期浪费 15 元优惠” 和 “为凑满减多花 20 元买不需要的东西”，两种损失（代价）不一样（比如前者更让人心疼哈哈，奶茶喝到肚子里就是自己的，不需要的东西买了放家里吃灰）。

> 代价敏感：因为两种代价不等，所以在下单前，我们会对自己不愿承受的代价（或者说“后果”）特别敏感。比如对“浪费优惠券”特别敏感，会想办法凑单用上；对“为了用券而多花冤枉钱”更敏感，就会宁愿让券过期。

#### 二分类代价（`cost`）矩阵

是将正例误判为反例的代价， 是将反例误判为正例的代价

|  | 预测类别 - 第0类 | 预测类别 - 第1类 |
| --- | --- | --- |
| 真实类别-第0类 | 0 | `cost_{01}` |
| 真实类别-第1类 | `cost_{10}` | 0 |

#### 代价敏感错误率

```
E(f;D;cost) = \frac{1}{m} \left( \sum_{x_i \in D^+} \mathbb{I}(f(\boldsymbol{x}_i) \neq y_i) \times cost_{01} + \sum_{x_i \in D^-} \mathbb{I}(f(\boldsymbol{x}_i) \neq y_i) \times cost_{10} \right)
```

+   是样本总数。

+   是正例样本集合， 是反例样本集合 。

+   是指示函数，当分类器 对样本 预测错误（预测值 与真实标签 不同 ）时为 1，否则为0

+   是将正例误判为反例的代价， 是将反例误判为正例的代价

ROC曲线在非均等错误代价下，演变成了“代价曲线”，其中`p`是样例为正例的概率，这个公式通过计算正例概率代价，确定代价平面中的横坐标，它对不同错误代价进行了归一化处理，其中`FNR`（假负例率，`FNR = 1 − TPR`），`FPR`（假正例率）。该公式计算的是归一化代价，作为代价曲线的纵坐标，综合反映了不同错误率和错误代价下的总体代价情况。

#### 代价曲线绘制原理

+   已知ROC曲线是用真正例率（TPR）和假正例率（FPR）绘制 。对于ROC曲线上一点 ，先算出

+   在代价平面上，连接点 到 形成线段，这条线段下的面积代表该条件下的期望总体代价 。因为线段两端分别对应极端情况（全判为反例和全判为正例 ），线段上点反映不同阈值下的代价情况。

+   遍历ROC曲线上每个点，都转化为代价平面上的线段，取所有线段的下边界。下边界围成的面积就是学习器在所有条件下的期望总体代价 。通过比较不同模型代价曲线下的面积，能选出在代价敏感场景中总体代价最小、性能最优的模型 。

## 2.6 比较检验

> 有关统计假设检验（hypothesis test）的数理知识，墙裂建议直接翻茆诗松老师的《概率论与数理统计》

在某种度量下取得评估结果后，是否可以直接比较以评判优劣？NO！因为：机器学习 → “概率近似正确”

+   测试性能不等于泛化性能

+   测试性能随着测试集的变化而变化

+   很多机器学习算法本身有一定的随机性

> 统计假设检验（`hypothesis test`）为性能比较提供了重要依据：

+   两学习器比较

+   交叉验证 `t` 检验 (基于成对 `t` 检验)

+   `k` 折交叉验证;  5x2交叉验证

+   McNemar 检验(基于列联表，卡方检验)

+   多学习器比较

+   Friedman + Nemenyi

+   Friedman 检验 (基于序值，`F`检验; 判断“是否都相同”)

+   Nemenyi 后续检验 (基于序值，进一步判断两两差别)

## 2.7 偏差与方差

在回归任务中，泛化误差可通过“偏差 - 方差分解（bias-variance decomposition）”进行拆解为：

+   偏差平方：代表期望输出与真实输出的差别 ，刻画学习器的拟合能力。

+   方差：反映同样大小的训练集的变动所导致的性能变化 ，体现学习器的稳定性。

+   噪声 ： 表示训练样本的标记与真实标记有区别，代表当前任务上任何学习算法所能达到的期望泛化误差下界 。

泛化性能由学习算法的能力、数据的充分性以及学习任务本身的难度共同决定。

#### 偏差-方差窘境（bias-variance dilamma）

一般而言，偏差与方差存在冲突：

+   训练不足时，学习器拟合能力不强，偏差主导

+   随着训练程度加深，学习器拟合能力逐渐增强，方差逐渐主导

+   训练充足后，学习器的拟合能力很强，方差主导

即在欠拟合时，偏差主导泛化误差，而训练到一定程度后，偏差越来越小，方差主导了泛化误差。因此训练不要贪杯，适度辄止。
