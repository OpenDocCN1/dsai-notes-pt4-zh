+   可推导 derivability

+   扩展新规则情况下，稳定

+   逻辑上具有蕴含关系

一般性判断：判断的普遍性或通用性

+   泛型：一个判断中各变量的所有可替代实例的一般性

+   参数化：与符号重命名有关的一般性
