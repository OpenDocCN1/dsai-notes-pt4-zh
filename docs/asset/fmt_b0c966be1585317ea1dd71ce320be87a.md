
# 闪念记录器

今天分享的是我们 Mixlab AI 编程训练营 22 期学员 Yin 做的作品，北极星——闪念记录器。

Yin 说自己有 ADHD（注意力缺陷多动障碍），在做一件事的时候，脑子里总会冒出别的想法。比如写项目方案写到一半，突然想起猫粮没买了，马上打开淘宝，买完半天才发现自己本来在干什么。这个场景一说出来，我觉得很多人都会心一击——不一定是 ADHD，但谁没有过做着正事突然被闪念打断的经历？

她观察到的问题是：这些闪念如果不记下来，会一直在脑子里晃悠，反而更容易打断主线任务；但如果停下来去处理，又会彻底打断心流状态。所以她做了这个工具——让你能快速记录闪念，但不会因此中断正在做的事。

整个界面的设计很有意思。中间是一个会呼吸的圆形，代表你当前的主任务，比如「写项目方案」。当你脑子里冒出别的想法时，随手在屏幕上点一下，输入几个字，这个闪念就会变成一颗小卫星，围着主任务转。她说这些小卫星会转得比较快，就是故意不想让你一直盯着看，让你把注意力留在主任务上。但如果你真想看某个闪念，也可以点住它，它就会停下来。

演示的时候有个细节让我印象深刻。她围着「写项目方案」这个主任务，记了七八个闪念：买猫粮、买新年装置、周二要谢太岁、文创项目要发货、教研项目交付报告……有生活的事，也有工作的事，完全是随手记下来的碎片。等她点开「星系」按钮，所有记录都出现在下面，每条都标注了记录时间和当时在做什么主任务。她还做了一键整理的功能，AI 会按工作和生活分类这些闪念，或者你也可以搜索某个关键词，找出相关的所有记录。

她提到一个想法让我觉得有意思。她说这个工具不是让你去处理这些闪念，而是先把它们「接住」，让它们有个地方待着，你的大脑就不用一直惦记了。等主任务完成了，再回过头去看这些记录，该处理的处理，该忽略的忽略。这个逻辑听起来很简单，但确实戳中了一个很实际的需求——不是所有闪念都值得马上处理，但如果不记下来，它们就会一直占用你的注意力。

她说想把这个做成真正的产品。我觉得这个方向挺有意思的，因为它解决的不是时间管理的问题，而是注意力管理的问题。现在很多工具都在帮你规划任务、提醒 deadline，但很少有工具专门处理那些「做正事时冒出来的杂念」。如果真能帮人在不打断心流的情况下，把这些闪念都接住，我想看看它会长成什么样。
