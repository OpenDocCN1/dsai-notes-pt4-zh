## 卖账号，代充plus

由于注册chatGPT需要国外手机号，很多人为途省事就购买成品账号。也有部分人想升级plus，但是需要国外的信用卡支付，需要找人代付。所以催生出这个产业。

这个产业的特点：

+ 门槛低
+ 离钱近，前期不用做大量铺垫

产业业务范围：

+ 成品账号
+ plus代充等  （博主可代充：见底部🛰️ ）

## 卖chatGPT API

结合GPT的能力做成一个新的产品都需要调用GPT的API。不管是镜像站、智能客服、AI相关的扩展产品。尤其是大公司模型训练需要大量的api keys。

目前主要分为两种：3.5， 4.0两个版本。还有直连、转发API的区别。

## 套壳ChatGPT(山寨ChatGPT)

各种👸号、小程序、app、 网站打着ChatGPT的旗号，不用科学SW就可以使用chatGPT。吸引了一大批用户。chatGPT是免费的，但是使用他们的产品却是收费的。

注意点：现在openAi开放出来的api, 虽然也是3.5的版本，但是比chatGPT官网的要低。效果还是差距比较大，所以能用原版就不用套壳的。

收费模式一般有两种

+ 卖提问条数
+ 订阅制：免费试用7天。后面按包月、包年计费。注意：很多人开通后，忘记取消订阅，或不知道怎么取消订阅。后面就一直在扣钱。
