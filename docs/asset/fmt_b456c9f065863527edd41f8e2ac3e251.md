## 三、进入正题

架空历史文，简单来说，就是在一个与现实历史相似，但又独立的虚拟世界里讲故事。

所以，可玩性就非常大。

对于新手作者来说，是一个值得尝试的题材。

架空历史文有两个最为重要的特点。

1. 真实感：虽然这个世界天马行空，但得让读者感觉自己好像真的在那儿一样。

2. 文明传承：它承载着人类的历史文明，反映了作者对现实世界的深刻思考。

能否实现这两点，是一部架空类小说优秀或平庸的最大分野。

### 《庆余年》火爆就是构建的架空世界兼备共性与个性。

### 一、架空历史文的经典框架

在《庆余年》中，通过创新的国度设定和种族设定，构建了一个独特的架空世界。

这个世界不仅仅是传统意义上的玄幻空间，而是融合了历史与现代、东方与西方的元素，形成了一个多元且动态的对话性空间。

让你在阅读的同时，既能感受到历史的厚重，又能体验到虚构的自由。

#### 1、多元社会框架

《庆余年》中的社会形态设定既有历史的轮回感，又兼备现代感。是怎么设计？

+ 以朝代为依托的古时形态：

+ 猫腻设计构建的“庆国”，其政治经济形态参照了古代封建王朝，但随着故事的发展，逐渐揭示了这个世界实际上是现代地球毁灭后的某个时空。小白用户的代入感都非常强。

+ 以现世为依托的未知形态：

+ 范闲和其母叶轻眉从现世社会穿越到庆国，带去了现代政治思想文化和先进物质文明，改变了庆国的社会形态。

+ 叶轻眉设立监察院监督特权阶级，保护平民利益；她实行经济改革，兴修水利，设立邮路驿站，为庆国的强大奠定了基础。

#### 2、种族设定框架

《庆余年》中的种族设定同样别具一格。

神族、人族、魔族不再是简单的善与恶的代表，而是各自有着复杂的背景和追求，这种设定让故事的冲突和角色的动机更加丰富和立体。

不同的种族不仅是故事中的角色，也承载着特定的文化象征和价值观。

+ 神族：

+ 神族的形象被赋予了新的特点，比如神庙，范闲为例，作为叙事文本中的欲望主体，范闲一直试图寻找自己重生到架空王朝庆国的原因，在种种线索的推进中逐渐感应到了自身与未知“神庙”的某种关联。据此，“神庙”就在某种程度上便成为了促发欲望主体范闲为探求真相而展开行动的欲望对象，随着范闲最终找到神庙并发现它原来仅仅是个具有千万年历史的军事博物馆，小说的故事情节也走到了尾声。

+ 人族：

+ 以范闲为代表的人族，通过智慧和勇气，推动了社会的进步和变革。

+ 叶轻眉，同样是一个由现代穿越到古代的穿越者，一度凭借自己掌握的现代化的军事技术帮助自己的情人庆帝坐上了皇位，却也同样因为自身过于现代化的思想观念威胁到了封建皇权，而被以皇权为代表的封建社会所抹杀。

+ 魔族：像庆帝等反派BOSS，他们不再是传统意义上的邪恶势力，而是构成了故事中复杂冲突和多元价值观的一部分。

划重点：无论角色的塑造，还是角色的共鸣都有很强的立体感。里面的人物，你闭上眼睛是不是都能清晰的回忆起来？

### 二、架空历史文的设计内核

#### 构建架空世界的内在逻辑和运作机制，关键在于设定秩序层和价值观念层。

#### 1、重设生存法则

生存法则不仅是角色成长的动力，也是故事冲突的来源。

+ 单维度的力量衡量规则：

+ 《庆余年》中建立了一个等级分明的修炼体系，这个体系通过具体的修炼等级来衡量角色的力量和地位。

+ 这种单维度的力量衡量规则为小说中的社会秩序提供了一个清晰的框架，同时也成为了人物行动和发展的基础。

+ 明确的等级制衡准则：

+ 在这个架空世界中，不同等级之间的制衡关系被明确地设定出来。

+ 虽然等级高的角色拥有更大的权力和力量，但他们也受到相应的制约和挑战。

+ 这种制衡机制防止了权力的绝对集中，为故事中的冲突和斗争提供了动力。

#### 2、重塑价值观念：矛盾冲突

+ 自主至上：

+ 范闲展现了强烈的个人主义。他的行为和选择都是基于个人意愿和判断，对个体自由和自我实现的重视。

+ 这种价值观念与传统集体主义有所区别，反映了现代社会中个体意识的觉醒和强调，与传统的冲突。

+ 比如，范闲的三个人生目标：第一，我要生很多很多的孩子。第二，我要写很多很多的书。第三，我要过很好很好的生活。

+ 亲我原则：

+ 人物的行动和选择往往以个人或亲近人群的利益为出发点。

+ 在《庆余年》中，范闲对家人和朋友的保护和关爱体现了“亲我原则”。这种原则在一定程度上塑造了人物的道德选择和行为动机。

+ 探讨了道德和伦理问题，如个体与集体的关系、权力与自由的平衡等。来增加故事的复杂性和深度。

主要体现在以下几个方面：

#### 1、空间书写：多重空间场所转换叙事

![](img/fe4f53ec692c14914922b695b368d531.png)

+ 以空间为表征的人物形象序列：

+ 通过空间场所的转换来塑造人物形象和推动情节发展。

+ 范闲的成长历程与他所经历的不同空间场所紧密相关，每个新空间的探索都伴随着人物性格的深化和故事情节的推进。

+ 以空间位移实现情节发展：

+ 小说中的情节发展往往与主角范闲在不同空间场所之间的迁移有关。

+ 通过空间的转换，猫腻创造了一个动态发展的叙事结构，使得故事的进展与空间位移相辅相成。

#### 2、叙事特征：与金庸小说、其他玄幻小说相对照

+ 谋篇布局：线索繁多，悬念丛生

+ 设置了多条故事线索并行发展，这些线索相互交织，形成了一个悬念丛生的故事网络。

+ 与金庸的武侠小说相比，猫腻在保持故事紧凑性的同时，也增加了情节的复杂性和不可预测性。

+ 这个方法小白浅尝辄止哦

+ 语言风格：具象性与听觉化

![](img/717f20187c6ab09415a7da3af17fd438.png)

+ 叙述语言上追求形象性和直观性，使得读者能够在阅读过程中形成清晰的视觉或听觉印象。

+ 这种语言风格使得《庆余年》不仅在文字上引人入胜，也为影视改编提供了丰富的素材。

### 四、架空历史文的爽点在哪

我不剧透，主线剧情我就不说了。爽点总结下来主要是两个方面：

敲黑板了：

#### 1、映射国民心理

+ 通过其架空世界反映了中国国民的心理状态和集体记忆。

+ 小说中的人物和事件与现实社会中的问题和挑战相互映照，引发读者对个人与国家、传统与现代之间关系的深入思考。

+ 小说中对科技发展的双刃剑效应进行了探讨。通过设定一个科技与文明发展交织的复杂世界，作者表达了对科技可能带来的伦理道德问题和人类未来命运的担忧。

#### 2、寓“爽”于乐

+ 作为一部网络小说，其审美特征之一是将快感追求融入阅读乐趣中，提供了一种“寓爽于乐”的阅读体验。

+ 主角一路开挂：范闲在小说中拥有众多的金手指，如他的母亲叶轻眉留给他的神秘箱子、五竹叔的保护、各种武功秘籍等。他在成长过程中不断地战胜强敌，解决各种难题，让读者在阅读过程中感受到了一种强烈的爽快感。

#### 3、现代思想烛照古代时空：

+ 范闲是一个带着现代人思想的私生子，他降临在“庆国”这个古代世界中，以“科幻小说大赛”为开端，展开的冒险。

+ 这种现代思想与古代文化的碰撞，让读者在阅读过程中感受到了强烈的新奇感和反差感。

#### 4、情感纠葛：

+ 小说中描绘了范闲与多位女性角色之间的情感纠葛，包括林婉儿、海棠朵朵等。

+ 这种情感线的设置让读者在阅读过程中感受到了一种甜蜜的爽快感。

#### 5、权力斗争

+ 描绘了庆国朝堂上的权力斗争，范闲在其中扮演了重要的角色。

+ 他在权力斗争中不断地战胜对手，最终成为了庆国的权臣。

+ 这种权力斗争的描写让读者在阅读过程中感受到了一种刺激的爽快感。
