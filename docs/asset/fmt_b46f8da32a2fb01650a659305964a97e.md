
# Softmax 算子融合与优化

依次运行的情况下，一共 4 次 `load / store` 每元素。

融合后，只需为 `K` 个候选元素计算最终的 `Softmax` 值。其他的 `softmax`，不用算了。

+   内存访问从 `(3V)读 + (1V)写 + (1V)读 = 5V` 次降至 `(1V)读 + (K)写 ≈ 1V` 次。

+   加速比 = `5V / 1V = 5x`
