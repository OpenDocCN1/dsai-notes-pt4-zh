
# 工作坊与应用配置指南

## 节点基础配置

+ 通知范围：选择该节点的输入内容将通知到的智能体，当前节点输入内容将添加到通知范围内智能体的上下文中。
+ 资料库（非必填）：可选择资料库作为该层内容的补充

![](img/852c6cb64e572e1ce8364faa478cd2bc.png)

![](img/a2a9124403a743af71f75b42cd5c5d4f.png)

## 智能体组内容设置

+ 发言顺序：设置这一组智能体的发言顺序，有三种顺序可选择 顺序发言、按需发言、自由发言
+ 顺序发言：按照设定顺序发言；
+ 按需发言：需要在智能体组内选择一个智能体设置为主持人，由主持人智能体来选择合适的智能体发言；
+ 设置主持人：选择一个智能体作为主持人，来选择合适的智能体发言
+ 按需结束：由主持人智能体判断信息是否收集完备，是否结束
+ 自由发言：由智能体随机发言。
+ 智能体组：选择多个智能体
+ 最大轮数：设置结束该节点的最大轮数。
+ 选择顺序发言时，指定发言几轮。最多设置为10轮
+ 选择按需发言/自由发言时，指定最大会话数，即累计最大发言次数。最大设置为50次
+ 通知范围：选择该节点的输入内容将通知到的智能体，当前节点输入内容将添加到通知范围内智能体的上下文中。
+ 资料库（非必填）：可选择资料库作为该层内容的补充

## 容器

+ 资料库（非必填）：可选择资料库作为该层内容的补充

## 应用

大家都知道，好的AI提示词可以降本增效。然而，在ChatGPT中我们调教了一个非常牛的模型，但并不能把它分享出来让更多人去用。其实，ZelinAI就能解决此问题。接下来我们将刚才创建的模型打包为 AI 应用，然后分享出去让更多人感受ChatGPT的魅力。

### 应用类型说明

目前支持创建5种方式的应用：H5应用、API应用、BOT应用、数字人应用、工作坊应用。

**创建 H5 应用**：基于选择的智能体创建 H5 应用，H5 应用可以在电脑以及手机端打开直接使用；

**创建 API 应用**：基于选择的智能体创建 API 应用，创建完成后，会给出该应用的 API，便于调用该 API 进行二次开发；

**创建 BOT 机器人应用**：基于选择的智能体创建 BOT 应用，可以创建🛰️、企业🛰️、钉钉以及飞书的智能机器人；

**创建数字人应用：**基于选择的智能体创建数字人应用，数字人可基于该智能体进行交流问答。

**创建工作坊应用：**基于选择的工作坊创建应用，该应用可以在电脑以及手机端打开直接使用

![](img/3bbc6cd78d9bc4e66994382f25f1802d.png)

### 创建 H5 应用

基于选择的智能体创建H5应用，H5应用可以在电脑以及手机端打开直接使用。

![](img/f65e25a401212d76ec364af24d59e6cc.png)

+ **应用名称**：【Midjourney 绘图提示】

+ **应用英文名称**：【Morning Image Prompts】

+ **应用图标**：

![](img/a708ba685bdce9c70f304aa93d1afa33.png)

+ **应用介绍 & 应用英文介绍**：

> Midjourney 提示词生成器，输出【关键词】即可生成4个 Midjourney 提示。

> 例如：

> prompt 1:

> `/imagine prompt: Clear morning light shines through a forest canopy, --ar 3:2 --v 5`

+ **风格**：对话风格、问答风格

+ **选择模型**：这里选择刚刚创建的模型2【Midjourney】

![](img/e4172fb26a9d7c44c2991dc5067d85a2.png)

+ **引导语**：介绍自己的应用，以及如何使用

> 请输出我们要 AI 绘图的【关键词】，即可生成4个 Midjourney 提示。

> 输入：【清晨的第一缕阳光】

> 输出：Prompt 1, 2, 3, 4:

```
`/imagine prompt: Clear morning light shines through a forest canopy, lighting up a small clearing where a deer grazes on leaves, using a 70-200mm lens, f/4 aperture, --ar 3:2 --v 5`
```

+ **添加推荐问题：**引导语中可以添加推荐问题，用户使用应用时可直接点击推荐问题进行发送，引导用户使用。

![](img/e0e842261c0c70082a11618b0f39ceab.png)

+ **菜单栏：**添加菜单栏固定回复内容，支持图、文、图文混合和链接形式。该预设的回复内容不会消耗tokens。

![](img/720415fd0e0f85719af7909151ffb58c.png)

![](img/403bacf3b3459c771a7dda0232dec4f4.png)

+ **输入&输出设置**：支持文字和语音输入输出。输出的语音时可以选择自动播放，选择不同语种的播音员等。

![](img/2e8cd6e4c0932340a74a4eff97de15f6.png)

![](img/5def6533c61814f61dfb2cd535e22439.png)

![](img/8b0f751b2f530238f41b84be92c7e9c1.png)

+ **是否付费**：可以将应用免费分享或设置免费使用次数的限制，也可按时间和次数进行收费。

+ **应用属性**：私有自用，或者公开。设置为私有将不会展示在个人的应用主页当中。

+ **是否加入应用市场**：可将制作好的AI应用加入到应用市场中，审核通过后，应用可以被更多的用户使用。推荐加入。

+ **选择分类**：

![](img/d323a77c4a5b7b961b48d4b6cea97f28.png)

+ **设置背景图：**可设置移动端的应用使用背景图。

设置完毕之后，点击“**完成并分享**”，应用则创建完成。通过以上操作，我们就真正实现了零代码构建自己的AI应用。

### 数据概览

在数据栏中，我们可以清晰看到自己应用的总用户数、总互动量、总PV量、总赞量、总费用消耗以及总收益。这些数据可以帮助我们更好地了解用户使用行为和偏好，从而制定更加有针对性的策略，提升应用的用户黏性和留存率，以及查看应用的收益和消费，便于把控和调整价格。另外，我们后期可以根据这些数据来分析用户的活跃时间、地域分布、使用设备等，以便更好地优化产品功能和用户体验。因此，及时更新并深入分析这些数据对于我们的应用来说至关重要。

### 创建 BOT 机器人应用

基于制作好的智能体创建BOT应用，可在🛰️中进行群聊或1v1好友回复，可用于私域社群维护、产品及优惠福利推介、个人分身等场景。

一个[BOT机](https://kaokaofs.feishu.cn/docx/RiOkdKRHVo257MxWLH4cxihznTh#part-Q3jldLpZYonK4ux7mrQcYNj5nkZ)器人可以绑定一个🛰️号，可以设置基于多个不同的智能体服务不同人群，实现针对不同群体进行自动回复。除此之外，BOT应用还可以具备设置关键词回复、主动招呼设置、定时发送消息等功能（具体设置请查看内容设置）

#### 创建方式

专业版、旗舰版、企业版可以使用BOT应用。在应用中点击“创建BOT应用”，选择需要购买的BOT个数，BOT有效期时间同版本有效期，一个BOT价格=1499元/年，购买时结算价格会根据版本剩余时间计算。

支付完成后可以看到拥有的BOT个数以及创建个数。

#### 内容设置

在内容中可添加多个智能体针对不同人群使用，智能体可开启或关闭使用，开启后即可按照设置的内容进行自动回复。

下面介绍各项设置

![](img/b9e31956dcd4b342dae9e17bc7e29405.png)

**选择智能体：**选择制作的智能体关联BOT应用

![](img/c0962941422c97984f10a00f990e650a.png)

![](img/649a690f9ecad584ca66eb594a000997.png)

**启用时间设置：**可选择全天/时间段。

+ 全天：全天开启自动回复

+ 时间段：可设置多个启用时间段，在设置的时间段内，BOT机器人才会进行回复

![](img/220487a044fce087197cd98da375bc6c.png)

**人员服务设置：**可添加多组回复对象设置

+ 指定人群设置：绑定🛰️后可选择好友和群聊，选择指定人群作为这一组的服务对象

+ 注意：多组回复对象的人员选择不可以重复

**关键词设置：**可针对指定的关键词进行回复。

+ 关闭时，选中的人员发送任何消息都可以进行回复

+ 开启时，仅针对选中人员发送包含关键词内容的信息进行回复

![](img/e29c068f4e207432ea8553ef4da4159c.png)

**主动招呼设置：**开启后，可设置多条主动发送的消息内容，该内容会在设定发送时间内随机抽取一条发送给指定人员。

+ **招呼内容：**可添加多条招呼内容，有文字、图片、视频三种类型可设置，文字内容前可添加称呼，称呼为该🛰️好友的昵称设置

![](img/d5d59d121d0ff6078da1cc8d84f58bc6.png)

![](img/ec94e53c862633e4366ebed6fda5207d.png)

![](img/88322ff7cf588344ec2adad062635730.png)

![](img/64b7cbf8664b83dca433c3fb4d8c4635.png)

+ **发送时间：**可选择时间点或时间段，在设置的时间内随机发送一条招呼内容

+ 时间点：在设置的时间点内容随机发送一条招呼内容

+ 时间段：在设置的时间段内的随机时间点随机发送一条招呼内容

![](img/9463088d15e7458ab2589e5fff8007fc.png)

![](img/d4b02e93ff249993ed650d4dcab8cd14.png)

+ **循环设置：**可设置指定日期或间隔天数进行发送

+ 指定日期：可添加多个未来日期进行发送

+ 间隔天数：可选择间隔天数进行循环发送，如“每隔1天循环一次”即为每天发送一次

![](img/df476272e154bc96525ebeb740ac07ab.png)

![](img/f7249c060296cd2ed12e1dc75e03efb9.png)

设置完成后保存即可生效。

设置完一个智能体后可再添加其他智能体完成人员服务设置

+ 注意：同一个人员不可以出现在多个智能体的设置中

### 创建数字人应用

基于选择的智能体创建数字人应用，数字人可基于该智能体进行交流问答。

数字人的基本信息设置和更多设置与H5应用的相同，在内容设置上有区别

内容设置：

+ 选择智能体：选择创建的智能体

+ 设置数字人：选择创建的数字人形象后，进入编辑详情

![](img/36e004b6fc5003381c2cb904ee13ffe0.png)

+ 角色和声音：同数字人形象里的配置，同时也支持修改

+ 输出设置：分为横屏和竖屏设置（对应在电脑端和移动端的显示）。可设置背景和站位

+ 背景：可选择默认颜色或自行上传图片

+ 站位：横屏可选择三种站位（靠左、靠右、居中），竖屏默认居中站位

![](img/4872690b664d30cf79014562388bc47f.png)

### 创建工作坊应用

基于选择的工作坊创建应用，该应用可以在电脑以及手机端打开直接使用。

基本信息的填写与H5应用相同，包含应用名称、图标和简介

内容设置：选择一个工作坊，以及设置引导语

![](img/55bf79261c272b0617f5384552973594.png)

注意：工作坊付费价格的设置是**运行一次**的，即运行完整工作坊一次，与H5应用的交互一次不同
