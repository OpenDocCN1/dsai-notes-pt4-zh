## 从continuous batching到`vLLM`中的batching

贡献人：

`https://zhuanlan.zhihu.com/p/688551989`

网页探讨了 `vLLM` 中的 batching 技术，这是一种用于优化大模型推理过程的算法。与传统的 naive batching 相比，continuous batching 通过在每次 token 生成前动态进行 batching，有效地减少了内存碎片，提升了并行处理能力和吞吐量。`vLLM` 项目进一步通过引入三个双端队列（waiting、running、swapped）来管理请求，并采用特殊的算子设计，使得可以将多个请求作为一个 batch 处理，从而进一步减少了显存碎片。此外，`vLLM` 考虑了显存的有效利用和请求的优先级，实现了一个更加合理的调度策略。在实际应用中，`vLLM` 通过在 prefill 和 generation 阶段保持 `GPU` 利用率，以及在内存管理上的优化，确保了在有限的显存资源下实现高效的大模型推理。

## RL 与 LLMs 的交叉研究

贡献人：

`https://zhuanlan.zhihu.com/p/710781211`

本文综述了决策智能与强化学习领域的最新研究，特别是大型语言模型（`LLMs`）与强化学习（`RL`）结合的交叉研究。首先，介绍了直接偏好优化（`DPO`）方法，它通过简单的分类损失优化策略，避免了传统 `RLHF`（`RL` from Human Feedback）的复杂性和不稳定性，提高了模型对齐人类偏好的效率。此外，文章探讨了如何利用 `MCTS`（Monte Carlo Tree Search）增强 `LLM` 的推理能力，包括 `TS-LLM` 框架和 `LATS`（Language Agent Tree Search）框架，这些框架通过引入学习的价值函数和自我反思功能，提高了 `LLM` 在推理和决策任务中的性能。最后，`ELLM`（Exploring with LLMs）方法通过利用 `LLMs` 的背景知识，提供目标建议，引导智能体进行有效的探索，显著提升了探索效率。
