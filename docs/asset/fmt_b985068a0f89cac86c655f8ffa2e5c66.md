## 一、什么是📕种草&为什么要做📕种草？

> 我看很多圈友分享过📕引流、📕电商，甚至小红书博主商单变现。很少有人去做小红书种草，但种草才是📕最开始的基因。

我知道现在📕在大力发展内部电商，直播以及买手。但是我们看24年底📕出的商家排行榜就知道了，上榜的企业和个人，年GMV其实也就做到了几千万，上亿都很少。这个数据对于📕这么一个月活几亿的平台而言，并不出彩，甚至有点难看。

**事实上，用户还是把📕当成种草平台，他会在📕上去搜生活中各个问题的解决方案，种草完了之后，去淘宝、拼多多等第三方平台去购买。这才是大部分用户的📕使用路径。**

我一直认为，种草平台做电商很别扭：姐妹我以为你是真诚分享，结果你在后面挂个链接是什么意思，你是想赚我的钱？挂了链接之后，就从真诚分享变成了利益相关，用户的信任度就会降低。很多用户对商家充满不信任感，但是对同类素人用户的话，深信不疑。

**所以，我们的策略是：**

1. 通过📕KOC和KOL去发布真诚分享的种草内容；

1. 通过自然流和付费流的相互作用，去产生爆文；

1. 再通过评论区的暗示和引导，让用户自发去第三方电商平台搜索及下单。

**这个策略的核心优势：**

+ 不管是小品牌和大品牌都能玩，小品牌的ROI还能做的特别高

+ 不需要太多的人力物力，只要懂方法，一个人就能hold住一个小品牌的📕种草

+ 具有确定性，不会像其他的项目或者策略一样，只有投入没有产出

+ 相当于两个平台同时发展，📕的流量，也可以赋能第三方平台的店铺流量

+ 可持续投入和放大。因为是付费买内容和买流量，等跑通闭环后，该模式具备持续放大的能力。

## 二、什么样的品牌适合做📕种草？

并不是所有的商业模式或者说是品牌，都适合在📕上玩种草的。部分品牌适合直接在📕进行转化，如低客单价产品：生活日用品（纸巾、调味料）、虚拟资料产品、零食类、玩具类、低价男装女装。

重点是低客单，决策短的小商品，适合在📕直接转化。低客单价产品玩种草，亏钱概率会比较大。

部分商家适合在📕上引流，也不适合种草。如卖高客单服务类商家，如知识付费、留学咨询、高考志愿、考公培训等等，服务类高客单商品，适合私域引流。什么样的品牌适合📕种草：

+ **拥有第三方店铺**，希望把📕人群种草到第三方店铺进行成交变现的；

+ **比较建议中高客单**，刚需品（解决某个痛点），商品需要一定品质保障和品牌背书的商家；

+ **类目**如母婴用品（奶粉，尿不湿，保湿霜，消毒器）、家电（冰箱、电视、净水器）、家具（沙发、桌子）、数码产品（相机、手机、平板、录音笔）等等

视野有限，大家可以自行对号入座，看自己是否合适。但其实也不需要局限于拥有淘宝、拼多多、京东等第三方店铺，也可以是👸号、小程序、国外的话独立站，这些都叫你的产品和品牌，也是比较适合📕种草。

比如，你做了一个小程序，能免费使用DeepSeek，我们就可以找素人和达人去产生内容，引流到你的小程序。这种比自己做账号推广，可能效率会很高不少！

## 三、寻找📕优质的KOC和KOL

### 3.1 什么是素人、KOC、KOL和KOS？

| **分类** | **定位** |

| --- | --- |

| **KOL** | **关键意见领袖者**，行业权威人士，一般指网红大v，有庞大的粉丝基数与粉丝粘性强，账号带有一定的影响力，且有很大的流量曝光 |

| **KOC** | **关键意见消费者**，自己就是消费者，热衷于分享各类好物，能营销自己的朋友，粉丝产品消费行为，与KOL相比，粉丝基数没有那么大，但有一定的推广影响力 |

| **KOS** | **关键意见销售**，指的是那些具备专业销售能力及大量垂类行业，品牌知识储备的内容创作，一般会有品牌自有的KOS。指的是品牌子账号。 |

| **素人** | 在使用📕的普罗大众 |

对于小品牌小商家，最容易接触，性价比最高的其实是KOL、KOC和素人，**尤其是KOC**：

+ KOL粉丝量较多，产生的内容质量较好，相应的，合作价格也比较贵；

+ **KOC粉丝量会比较少，合作价格低。部分KOC内容质量也会很好**，而且很配合。预算低的小伙伴，优先考虑；

+ 素人的问题是比较难找，沟通困难。市面上有提供素人铺量服务的，但是我不是很建议大家去做。

### 3.2 2025年还能不能做素人种草？

我的回答是不建议，我们做过，踩过很多坑，你给总结一下（注意我这里是针对中小商家，如果自己手上本身就有上百素人账号的，那就另当别论了）：

+ 素人种草沟通困难，因为走的是水下，经常会出现笔记不收录、笔记过两天删除的情况出现。需要耗费大量的时间精力去对接，得不偿失；

+ 如果你去找那种提供素人的机构合作，很多那些素人账号都是不能用的，都是那些速成账号。量大出奇迹在这些速成账号里，行不通；

+ 📕现在已经明确表明，禁止做素人软广，轻则素人号被封，重则品牌会被扣分，影响品牌在📕上的流量。

所以，如果是做种草的小伙伴，更建议跟KOC和KOL合作，走蒲公英平台的报备种草。或者自己做矩阵，自己走素人种草，如果能跑通矩阵的话，这个也可以。

### 3.3 找到合适的KOL和KOC达人

> 📕种草能不能成功，找到合适的达人至关重要！找达人其实是一个技术活，我们是因为本身有在做博主矩阵，知道哪些是数据好的真博主，哪些是假博主，才能做到这么好的投放数据。下面分享下👇

#### 3.3.1 找达人的官方平台-蒲公英

![](img/172e51fb51c3efc2d3ea1bef4e35e05e.png)

通过官方的蒲公英平台的博主广场，可以找到我们相关领域的，不同粉丝数，不同报价的博主，筛选功能足够我们找KOC使用。相关设置项：

+ **博主笔记类目**，找自己相关领域的；

+ **粉丝量**，就找1w以下的。1w以上的，要么价格高，要么价格低但是号不行。（预算高的小伙伴随意，我们是因为操盘的品牌本身营销预算不高，才只能找KOC合作）；

+ **合作报价**，筛选图文，选择你能接受的价格往下的；

+ **近30日粉丝数上升**，这个勾选，代表着这个博主账号是有流量的，非死号。

差不多这些，就可以筛选啦。当然还有很多其他的选项可以勾选，但是勾太多，符合要求的就会比较少。因为我们预算比较低，所以别希望找到完美符合要求的，而是要找那些账号活跃度高，内容和粉丝量契合的就行。以我们家居家纺类的项目为例，我的设置项：

+ 博主笔记类目：家居家装

+ 粉丝量：0.1~0.5w

+ 合作报价：0-500

+ 近30日粉丝数上升：这个勾选

这样筛选出来的博主，再通过阅读中位数进行筛选：

![](img/dc0bcfdc3c65c5965ff85f7a7ad37cd7.png)

**遇到心仪的博主，可以点击进去看他的主页。博主主页主要看几个点：**

+ **报价：**是否符合约算；

+ **阅读量：**勾选自然流量，把付费流量剔除；

+ **看阅读和互动比：**阅读和互动在1:10往上，属于正常。如果阅读太低，互动太高，这种博主属于刷数据博主，需要剔除；

+ **内容调性：**主要是看他生产的内容，是否符合我们的产品。看他内容的用户，是不是我们产品的潜在用户。

如果这些都OK，就可以对博主进行邀约，等待博主的回复，拿取联系方式，用🛰️进行沟通。

![](img/0949c6480bc5903e5a6622f1622ac5a0.png)

筛选完一个博主后，可以看左边，有一个相似博主推荐，可以点击进入，系统会主动选择相似博主推荐给你。这个功能很好用，能帮我们节省很多时间。这么一顿操作下来，相信我们已经有了不少心仪的博主可以邀约要求。

**这里要注意，并不是每一个博主都会接受邀请，或者接受我们的合作邀请。合作率大概也只有50-60%左右。所以我们需要多找一些博主，以备不时之需。**

#### 3.3.2 通过信息流筛选

自己相关领域的内容，在📕刷的多了，📕就会给我们在信息流推荐相关的内容和博主。我们要做的就是平时刷到相关内容的时候需要额外思考一下：

+ 这个内容是谁产生的？

+ 他的粉丝量和报价多少？

+ 我们是否能跟他进行合作？

通过这种方式，我们也能找到一些优质的并且蒲公英还能筛选到的一些博主（有些博主压根没有入驻蒲公英）。

为了跟品牌爸爸省钱，达人给出信息之后，一定要聊返点！！很多小伙伴可能还不清楚什么是返点

> 博主商单有个不成文的规定，博主跟品牌方合作，作为媒介方一般是可以拿返点的（返现），返现的金额一般是博主商单完成，拿到钱之后，需要把谈好的返点私下打到媒介方的账户上。
>
> 以前📕的返点一般是5%，10%给个辛苦费。现在很多返点都开始30%，40%往上走，还有很多媒介称公司要求必须45%返点，不然不给上报的。

**具体返点怎么聊？**

还价就完事了，博主填的返点是20%，直接问30%行不行，脸皮厚一点的问40%行不行。这里你放心，博主不会因为听到媒介这种高返点要求，就选择不合作的。博主已经被市场教育过了，他们顶多跟你讨价还价。具体话术：

> 宝子我们后期是会投流的，返点能不能再给高一点，30%行吗？
>
> 宝子品牌方要求返点在30%以上，你看你这边返点能再高一点吗？

博主填完信息后，我们会和品牌做更进一步的筛选，根据预算和博主的近期数据，确定最终的合作人选。
