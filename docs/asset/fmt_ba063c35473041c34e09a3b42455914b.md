
# 白色 Smartisan T1 手机发布会

## 产品设计与生产

最后补充再来第五条，原来计划只有四条的，这个就是我们之前在网上发了 1、2、3、4 之后很多人问到这样一个问题，这毕竟是一个科技公司 CEO 的演讲，难道跟科技产品一点关系也没有吗？有的人被我假惺惺的嘴脸震惊了，明明是预谋好的，装什么孙子，我们把大菜正式端出来。今天我们终于经过半年死去活来的折磨之后，终于要给大家上菜了，这个就是我们期待已久的白色的 SmartisanT1 手机，今天要正式发了，虽然它相对于我们原来黑色版的没有什么本质上的变化，但是美就是生产力，这个是非常重要的一点。一直以来我们搞不出来，有人说你们机器有什么难的，人家不锈钢都做出来了。我们的问题是这样的，由于设计上采用了一个非常冒险的方式，所以使得我们的手机正面板的边框、中框和后面板的边框和后面板紧挨着并且全是白色，这在生产上基本是智商式的行为，所以一直没有生产出来，我们跟供应商的拉锯，并且增加 110 块钱的成本情况下终于弄出来了，但是好像售价不会涨 110 块钱的，尽管我们内部也挣扎过，最后决定既然上次 3000 降到 2480，现在还有什么脸再要回来 110 块钱，即便卖，何况我们也亏不了，基本能保本，这样的话我们把按原来的 2480 块钱推出来，给大家欣赏一下它的一些美图，第一次亮相。

外国人这些人表达感情不要太当真。真的非常漂亮，请允许我个人认为这是有史以来最漂亮的白色手机。上次 5.20 的时候秀过这个画面，我们精巧的把光线和距离传感器藏到了听孔的凹槽内，实现最完美的表现，底部的三个纽，出厂批次不同有的是三灯有的是单灯的，大家不要挑这个，我们供应商有单灯有三灯的，买到哪个是哪个，如果你介意可以退货，我们客服很难换货，我们不知道哪个是单灯哪个是三灯的，还有人说我们不地道，其实不是的，供应链就是这样的，整个行业普遍做法就是当什么非功能性的东西有小改动的时候，束不另行通知，全世界的电器都是这么做的，希望你们能够理解。就是好看，没别的，白色的配上我们设计的所有 UI 都是完美的，我们为了这个也精心设计了五款彩色的玻璃贝壳，你可以随意换，首先白的手摸上去不会成为指纹采集器，黑的一摸就能看出来，白的看不出来，还有黑的磨一点容易花，白的磨花了看不出来，即便如此如果用的久了，用的不耐烦了还有五款彩色半透明玻璃，这个不是二次透明塑料包裹的，还是玻璃，仍然 2480 块钱，只生产一款 4G 版 32GB 容量。最后有一个不大不小的坏消息，仍然不是现货，今天开始接受预订，300 元预订，目的是为了确定订单数，没有别的意思，10 天内开始发货，前期只能在我们的官方网站 `WWW.T.TT`，如果订单数很高我们可能通知你可能要再晚一点，我们一天的产能 1000-1500 之间，因为良率非常的低，我们既然设定这个产品，无论如何要把它做下去，最后卖多少不重要，这是个心愿。

## 面向女性用户的市场突破

还有一直以来困扰我们的一个问题，今天我也想有一个突破，就是长期以来我们发布以后，一直到今天始终有人说我们是一款男性手机，这个是我很难过的一件事，而且我觉得对我的同事们很愧疚的一件事，因为我们这个是男性手机，我要负很大的一个责任，或者准确的说我父母要承担一部分责任，就是因为如果一个企业的老板外形跟我这样的话，一般来讲只能做男性产品了，所以我觉得很对不起我的同事们。把白色手机打扮这么好看，让女孩子看了喜欢。接下来公司对我们不满已久的同事们，我们工程师帅哥奇多，这个是人类非常罕见的事情，我们公司长期以来不满足我们产品被消费者当成男性手机这部分同事，揭竿而起，纷纷回家自己置办了行头，要求我们高远摄影师给这些同事拍一些照片，我们出去到科技论坛，科技活动聚会拿着白色手机去跟女性用户谈谈心，他们想搞这样一个活动。所以我就没有拦阻，最后我说看了照片再说，最后我看了照片还是很震惊的，这个是我们公司随便找了一些帅哥，是他们自发组织起来的帅哥联盟，要不遗余力的把我们的手机制造成为是男女通杀的手机，所以凑了这么一个班子，这里面有设计师、工程师、产品经理。考虑这有点太严肃了，要求他们放松一点，后来他们拍了笑容的帅照，仍然显得非常帅，所以他们决定等我从前台撤出以后，用三个月的时间把它打造成一部女性手机，或者说是男女通杀的手机。我也指出了批评意见，这个穿的太装了，如果到科技论坛搞聚会，他们穿成这样进去非常不好，显得很病态，所以他们又拍了一些休闲照，我们已经跟中关村的 3W 咖啡在 12 月 26 日已经订了第一场白色手机交流会，注意仅限女性参加，而且我们公司我也是不被允许参加的，因为会吓跑女性用户，他们和我们协同主办这样的活动，是白色手机，有产品经理、设计师、工程师去给这些女性用户讲一讲我们手机到底是怎么回事，深入谈一下。

## 硬广：许岑老师幻灯片制作教程

最后结尾之前再插播几条硬广，第一个硬广是这样的，我们创业，我在英语培训时代就有很早跟我们一起做事的许岑老师，早期支持者非常熟悉他，早年演讲总是出来给大家唱歌，现在他也长不动，年老色衰也唱不动。还有他突然到了男人的年龄阶段突然繁殖欲望爆发，他想做全职的奶爸生一个孩子在家，早年跟我辞了职回家照顾孩子，最近他的孩子刚刚成功的造出来，这是这周跟孩子的一个摄影，许岑老师在这里给你们讲不是没有原因的，多年以来我的大型演讲的幻灯片做的非常专业和非常漂亮，被很多人拿去模仿，而且很多人要求在网上提供我们原片的下载，后来许晨老师考虑到回家做全职奶爸准备重操旧业，本来是这里做产品经理的，他想做英语家教，他想了想幻灯片有那么多人要，现在企业里做 PPT 比做表格的挣钱，做表格比做 WORD 挣钱，他说比起英语教学科不可以搞幻灯片教学，后来他做了制作精良的幻灯片制作教程，淘宝尝试 90 块钱昂贵价钱做视频教程，没有想到发布 48 小时售出 1300 份，发布两个月卖出 7300 份，按照这个收入未来两年不用工作就可以带这个孩子了，我们很多同事也帮他转发了一下，我们同事包括我们公司很多同事也买了这个视频课程，最后大家用的都感觉非常好，所以你们有兴趣的话也可以到淘宝上搜索一下许岑这个名字，找幻灯片教程，如果你在企业里的工作需要用幻灯片做一些事情，这个教程是非常非常好的，这么多年我的演讲都是许岑老师帮我做的幻灯片。
