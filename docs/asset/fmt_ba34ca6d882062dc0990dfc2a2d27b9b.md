#### 加载 checkpoint

修改 `web_demo.sh`

```
PRE_SEQ_LEN=128

CUDA_VISIBLE_DEVICES=0 python3 web_demo.py \
    --model_name_or_path ../chatglm-6b \                                 # model checkpoint
    --ptuning_checkpoint output/pt-self-cog-128-1e-2/checkpoint-3000 \   # prefix checkpoint
    --pre_seq_len $PRE_SEQ_LEN
```

现在就可以正常启动 WebUI 了

```
bash web_demo.sh
```
