## ✏️ 课代表

+ 大语言模型的误解：公众对大语言模型存在一些误解，需要正确区分不同类型的模型。
+ 开源与闭源模型的选择：开源模型允许用户访问模型的细节并自行部署，而闭源模型通常通过 `API` 提供服务，用户无需关心模型的内部结构。
+ 模型评估的重要性：评估大语言模型时，应该超越传统的 `benchmark`，采用更为公正和准确的基于人类反馈的评估方法。
+ 智能体的作用：将大语言模型封装为智能体可以增强模型的交互能力，使其更适合实际应用。
+ 产品级别应用的发展：产品级别的应用如 ChatGPT 等，展示了大语言模型在实际产品中的应用前景，以及如何通过前端 `UI` 和插件市场提升用户体验。
+ 模型性能的多元评价：通过对比不同模型在各种任务中的表现，提出了对模型性能评估的多元化视角。
+ 大语言模型的多样性：介绍了多个来自不同公司和研究机构的大语言模型，展示了该领域的多样性和竞争性。
