
# 苹果美区账号注册方法

> 来源：[https://xodnytdcaw.feishu.cn/docx/GCFgdv7xBoWYGRxv2EzcFCwynnd](https://xodnytdcaw.feishu.cn/docx/GCFgdv7xBoWYGRxv2EzcFCwynnd)

## 方法1

打开 `https://account.apple.com/account` 直接注册，手机电脑都行

1. 点击 创建你的 Apple 账户

2. 国家选 美国

3. 手机号也随便填，中国手机号也行，验证码一填就完事了

![](img/0c7d932fc3c8ca2ffc2c8ec9a12060e2.png)

添加地址 `https://account.apple.com/account/manage/section/payment`

关闭双重认证

测试下，现在关闭不了 2026/02/13

背景：切换美区 `Apple ID` 每次都需要验证码，通常是因为开启了双重认证（2FA）或在非信任设备上登录

参考：多个 `Apple ID` 切换不用每次双重认证的好办法。 - V2EX

`https://discussionschinese.apple.com/thread/255325610?sortBy=rank`

设置——第一个 `apple ID`———登陆与安全性——关闭双重认证

## 方法2

1、找一部安卓机，下载 `Apple Music`

2、创建 Apple 账户，国家地区选择“美国”

3、再找一台苹果设置，登录刚注册账户，爽用

![](img/fb1595a692514be27802a269010de86d.png)

### 场景问题

苹果登录的时候二次验证要绑一个手机号？

绑 86 的就行，不影响

## 避坑指南

+ 新注册邮箱（`Gmail`/`Outlook` 最佳）。

+ 密码中不要包含你注册 `Name`（名字）中 3 个以上 的重复字符

+ 用未注册过 `ID` 的号码。如果自己号码都注册过，用他人号码完成注册，注册成功后记得立刻换绑成自己的号码。

+ 设备限制：每个设备好像是五个 `ID`
