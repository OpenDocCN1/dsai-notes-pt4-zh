# 第2章：18万人在线

第二个广告是围裙品牌,2500块。第三个是保温箱,4000块。

为了配合直播时间,陈默得早上5点半就开始准备。他要在7点前把卤味做好,赶上早高峰直播。下午3点又要开始准备晚高峰的直播。

一天两场直播,每场一个小时,加上准备时间,他几乎没时间休息。

更大的问题是产量。

以前陈默一天卤20斤左右,够卖一上午的。现在直播间的订单越来越多,有人要快递发货,有人要买十斤八斤的,一天20斤根本不够。

老汤跟不上了。

"陈先生,你好。"男人递过名片,"我是星辉MCN公司的商务经理,我叫老张。"

陈默接过名片。星辉MCN,商务经理张明,手机号,🛰️号。

这是她这周第三次来。前两次都因为排队太长,等了半小时还没轮到,她放弃了。

那时候他刚失业,不知道怎么做卤味,每天起早贪黑学着岳父的手法,一点一点把老汤养起来。

那时候他一天只赚300,但心里踏实。

现在他一天能赚上千,但开始失眠了。

他掏出手机,看了看银行卡余额。4.2万,是三个月前的两倍多。

但他觉得自己丢了什么东西。

那个东西说不清,摸不着,但它曾经在那锅老汤里,在张姨的笑容里,在李叔啃完卤藕后的满足里。

现在没了。

# 第3章：变了味的汤

5万。陈默在心里算了算,够半年房贷了。

"产能怎么办?"陈默问,"我现在一天只能做50斤。"

"这个简单。"老张说,"我们可以帮你联系代工厂,统一配方,批量生产。你只需要定期去厂里指导,保证口味一致就行。"

"陈先生,你考虑一下。"老张说,"下周五之前给我答复,5万签约金可以先预付一半。"

锅里的汤汁还在滚,但颜色已经淡了。为了赶产量,他这个月稀释了三次老汤——加水,加预调包,加冷冻食材。

岳父留下的汤底,三十年的底子,现在锅里剩下的可能不到原来的十分之一。

其他的都是新加的水和料包。

陈默伸手舀了一勺汤,尝了尝。

味道变了。没有以前那种醇厚的回甘,只有香料的刺激和味精的鲜。

这不是老汤了,这是快餐店的卤水。

"喂,小陈吗?"是张姨。

"张姨,怎么了?"陈默问。

"我今天下午去你摊位买了半斤鸭脖。"张姨说,"回家吃了,觉得不对劲。"

陈默心里一紧。"哪里不对劲?"

"这汤,是不是换了?"张姨的声音很平静,"我吃了你三个月卤味,知道那个味道。今天这个,不是。"

陈默不知道该说什么。

"小陈,我不是来找你麻烦的。"张姨说,"我就是想告诉你,算了,我以后去别家买。"

这是他这个月第三次抽烟。从不抽烟的人,现在一周抽三根。

老赵,45岁,陈默的前同事,现在还在公司做高级产品经理。

"你混得还行啊。"老赵说,目光在摊位上扫了一圈,"直播挺火的,我看在线人数都十几万了。"

他看着陈默,眼神里有点复杂。"老陈,你现在算是转型成功了。"

老赵走后,陈默独自坐在摊位前。

那天他在工位坐了两个小时,看着电脑屏幕发呆。十五年职业生涯,最后只换来一纸通知。

他以为自己会很难受,但其实没有。

真正难受的是回家后,面对林薇和女儿。林薇说"没事,咱们慢慢来",但眼神里有焦虑。女儿问"爸爸你不上班了吗",他不知道怎么回答。

那时候他以为,只要找到新工作就好了。

但三个月过去,投了几十份简历,没有一个回音。42岁,产品经理,上一份年薪38万,市场上没人要他。

所以他来摆摊。接手岳父的摊位,学做卤味,一点一点把老汤养起来。

那时候他一天只赚300,但心里踏实。他记得每个老顾客的脸,记得他们的口味习惯。张姨说他的卤味"有国营食堂的味道",李叔说他的老汤"养得不错"。

他以为自己找到了新的活法。

但现在,他又迷失了。

直播带来了钱,带来了流量,带来了所谓的"成功"。但同时也带走了老汤的味道,带走了老顾客,带走了他心里那点踏实。

陈默站起来,走到卤锅前。

锅里的汤汁还在滚,颜色淡,香味弱,和岳父留下的那锅完全不一样了。

他伸手摸了摸锅沿。铜锅还是那个铜锅,被火烧得发黑的锅底还是那个锅底。

但里面的东西,已经不是了。

手机震了几下,陈默拿起来看。

林薇:"老公,MCN的合同你考虑得怎么样了?5万签约金能解决不少问题。"

小鱼:"叔,合同尽快签吧,他们说下周五是最后期限。这个机会错过就没了。"

老张:"陈先生,考虑好了吗?签约金可以先预付2.5万,明天就能到账。"

陈默看着这些消息,没回。

他关了手机,坐在摊位前,看着那锅老汤。

窗外,杭州的夜晚开始下雨。雨点打在菜市场的铁皮屋顶上,发出噼啪的声音。

陈默想起岳父教他做卤味的那天。

那时岳父已经病重,躺在床上,说话很费力。他让陈默把卤锅搬到床边,一点一点教他怎么调火候,怎么下料,怎么养老汤。

"做吃的,急不得,骗不了人。"岳父说,"老汤要养,一天都不能断。断了,就不是那个味了。"

陈默当时点头,说记住了。

但他现在做的,和岳父说的完全相反。

他把72小时压到48小时,把文火改成中火,把老汤稀释了三次,加了预调包,用了冷冻食材。

他为了赚钱,为了流量,为了所谓的"成功",把岳父留下的东西一点一点毁掉了。

陈默站起来,走到卤锅前,关了火。

锅里的汤汁停止翻滚,慢慢平静下来。水面上浮着一层油,混着香料的碎渣。

这不是老汤。

这是他用一个月时间,亲手毁掉的东西。

陈默掏出手机,看着屏幕上的消息。

林薇在催,小鱼在催,老张在催,所有人都在告诉他:签约,赚钱,这是你唯一的机会。

但陈默突然不想签了。

他想起张姨说的话:"我吃了你三个月卤味,知道那个味道。"

他想起李叔说的:"这卤味,急了。"

他想起岳父说的:"做吃的,急不得,骗不了人。"

陈默关了手机,坐在摊位前,听着雨声。

雨越下越大,菜市场里空荡荡的,只有他一个人。

他不知道自己该怎么办,但他知道自己不能继续这样下去了。

不能。

"陈先生,来了。"老张站起来,指了指对面的位子,"坐。"
