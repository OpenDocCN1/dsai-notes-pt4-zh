OpenAI发布Atlas才两天，...

+ 微软在OpenAI发布Atlas两天后推出Edge浏览器，功能与ChatGPT Atlas等相似，有Ask Copilot侧边栏及Agent模式，但Agent模式存在信任、速度和准确率问题。
+ 微软还升级Copilot，推出虚拟形象Mico，增加长期记忆及Copilot Groups多人协作功能。
+ AI浏览器是好方向，但目前不成熟，Edge适合习惯使用者，更推荐Perplexity的Comet。
+ Atlas需ChatGPT会员且仅支持macOS，Comet产品成熟，支持macOS和Windows。
+ 现在注册安装Comet可白嫖一个月Perplexity Pro会员。

关键词：AI浏览器，Edge，Copilot，Atlas，Comet

+ `LangChain`于2025年10月24日宣布完成1.25亿美元融资，估值达12.5亿美元。

+ 其在开源开发者中人气高，GitHub上有11.8万星标和1.94万复刻分支。
