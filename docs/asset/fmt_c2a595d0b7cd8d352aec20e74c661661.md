## 7.7 启用 HTTPS（加密访问）

GitHub Pages 默认支持 HTTPS，但需要手动启用：

1. 进入 Settings → Pages
2. 找到 "`Enforce HTTPS`" 选项
3. 勾选这个复选框
4. 等待几分钟生效
5. 你的网站会强制使用 https:// 访问

## 常见问题完整汇总

### 问题 1：找不到 Settings

**原因：**

- 可能没有登录
- 可能在别人的仓库（你没有权限）

**解决：**

- 确认已登录
- 确认在自己的仓库页面

---

### 问题 2：Settings 里没有 Pages

**原因：** 仓库是私有的

**解决：**

1. Settings → General
2. 滚动到底部 Danger Zone
3. Change visibility → Make public
4. 输入仓库全名确认

---

### 问题 3：Pages 没有 Source 选项

**原因：** 仓库没有 `index.html`

**解决：** 先创建 `index.html` 文件

---

### 问题 4：网站显示 404

**可能原因：**

1. 部署还没完成 → 等待 2 分钟
2. 文件名不对 → 必须是 `index.html`
3. 文件不在根目录 → 移到根目录
4. 网址输错了 → 检查网址格式

---

### 问题 5：修改后网站没更新

**解决步骤：**

1. 确认修改已提交（查看文件是否更新）
2. 等待重新部署（1-2分钟）
3. 清除浏览器缓存（Ctrl+Shift+Delete）
4. 强制刷新（Ctrl+F5）
5. 用无痕模式访问

---

### 问题 6：样式不显示

**检查：**

1. CSS 文件路径是否正确
2. CSS 文件是否已上传
3. 文件名大小写是否一致
4. 使用相对路径：`./css/style.css` 或 `css/style.css`

---

### 问题 7：图片不显示

**检查：**

1. 图片路径是否正确
2. 图片文件是否已上传
3. 文件名大小写是否一致
4. 图片格式是否支持（.jpg、.png、.gif、.svg）

---

### 问题 8：JavaScript 不工作

**检查：**

1. 按 F12 打开控制台查看错误
2. JS 文件路径是否正确
3. JS 文件是否已上传
4. 是否有语法错误

---

### 问题 9：Actions 部署失败（红叉）

**解决：**

1. 不要使用 GitHub Actions 方式
2. 删除 `.github/workflows` 文件夹
3. Settings → Pages
4. Source 改为 `Deploy from a branch`
5. 重新部署

---

### 问题 10：想改仓库名

**步骤：**

1. Settings → General
2. 最顶部 Repository name 输入新名字
3. 点击 Rename
4. ⚠️ 网址也会变：https://用户名.github.io/新仓库名/

---

### 问题 11：想删除仓库

**步骤：**

1. Settings → General
2. 滚动到最底部 Danger Zone
3. Delete this repository
4. 输入完整仓库名：用户名/仓库名
5. 确认删除
6. ⚠️ 删除后无法恢复，网站也会下线

---

### 问题 12：提交时出现冲突

**原因：** 多人编辑或多处编辑导致冲突

**解决：**

1. 如果用网页编辑，GitHub 会提示冲突
2. 选择保留哪个版本
3. 或者手动合并

---

### 问题 13：文件上传失败

**可能原因：**

1. 文件太大（单个文件 > 25MB）
2. 网络不稳定

**解决：**

1. 压缩文件大小
2. 分批上传
3. 使用 Git LFS（大文件存储）
4. 换个时间或网络重试

---

### 问题 14：部署很慢

**原因：**

- GitHub 服务器在国外
- 网络延迟

**解决：**

- 耐心等待（通常 2-5 分钟）
- 可以去 Actions 页面查看进度

---

### 问题 15：网站访问慢

**原因：** GitHub Pages 服务器在国外

**解决方案：**

1. 使用 CDN 加速
2. 压缩图片大小
3. 压缩 CSS/JS 文件
4. 使用国内托管服务（如 Gitee Pages）

## 关键规则和注意事项总结

### ✅ 必须做的事情

1. 仓库必须是 `Public`（公开）

- 私有仓库需要付费

1. 首页必须叫 `index.html`

- 全部小写
- 不能是其他名字

1. `index.html` 必须在根目录

- 不能在子文件夹里

1. Source 选择 `Deploy from a branch`

- Branch 选择 `main` 或 `master`
- 文件夹选择 `/(root)`

1. 文件命名规范

- 只用英文、数字、短横线、下划线
- 不用空格和中文
- 注意大小写

1. 提交后要等待

- 等待 30秒 - 2分钟让 GitHub 部署
- 查看 Actions 确认部署完成

1. 更新后要强制刷新

- Ctrl+F5 或 Command+Shift+R
- 清除浏览器缓存

---

### ❌ 不要做的事情

1. ❌ 不要把仓库设为 `Private`

- 会导致 Pages 无法使用

1. ❌ 不要用中文命名

- 仓库名、文件名都不要用中文

1. ❌ 不要在文件名里加空格

- 用短横线代替：`my-page.html` 而不是 `my page.html`

1. ❌ 不要把 `index.html` 放子文件夹

- 必须在根目录

1. ❌ 不要用 GitHub Actions

- 除非你很熟悉
- 新手用 `Deploy from a branch`

1. ❌ 不要频繁修改

- 每次修改都会重新部署
- 建议本地测试好再提交

1. ❌ 不要上传超大文件

- 单个文件不要超过 25MB
- 仓库总大小不要超过 1GB
