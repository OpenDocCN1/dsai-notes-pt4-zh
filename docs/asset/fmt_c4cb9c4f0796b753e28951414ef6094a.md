### 自定义样式css代码

> 主题我自己的使用
> 样式---自定义css样式（添加如下代码）

紫色

```css
/*自定义样式，实时生效*/

/* --- 全局属性 --- */
#nice {
    font-family: Optima-Regular, Optima, PingFangSC-light, PingFangTC-light, &quot;PingFang SC&quot;, Cambria, Cochin, Georgia, Times, &quot;Times New Roman&quot;, serif;
    padding: 10px;
    font-size: 16px;
    color: #353535;
    word-spacing: 0.5px;
    letter-spacing: 0.5px;
    border-radius: 16px;
}

/* --- 段落 --- */
#nice p {
    line-height: 1.75;
    margin: 0.8em 0;
    font-size: 16px;
    color: #353535;
}

/* --- 一级标题 (蓝色保留，如需改为橙色请告诉我) --- */
#nice h1 {
    border-top: 2px solid #2b4fed;
    text-align: center;
    font-size: 1.3em;
    margin-top: 40px;
}

#nice h1 .content {
    display: inline-block;
    font-weight: normal;
    background: #2b4fed;
    color: #ffffff;
    padding: 3px 15px;
    border-radius: 0 0 13px 13px;
}

/* --- 二级标题 (无线条/无标记/Claude色) --- */
#nice h2 {
    margin-top: 30px;
    margin-bottom: 10px;
}

#nice h2 .content {
    font-size: 20px;
    font-weight: 700;
    color: #D97757; 
    display: inline-block;
    padding-left: 0;
    border-left: none;
}

/* --- 三级标题 (文字#D97757，背景接近白色) --- */
#nice h3 {
    margin-top: 25px;
}

#nice h3 .content {
    background: rgba(217, 119, 87, 0.08); 
    color: #D97757;                      
    padding: 5px 12px;
    border-radius: 8px;
    font-size: 16px;
    font-weight: bold;
    display: inline-block;
}

/* --- 引用 (左侧粗边线 + 暖色背景) --- */
#nice blockquote {
    font-style: normal;
    border-left: 6px solid #D97757 !important; 
    padding: 20px 20px;
    line-height: 1.75;
    border-radius: 13px; 
    color: #444;
    background: #fdfaf7; 
    margin: 1.5em 0;
}

#nice blockquote p {
    margin: 0;
    color: #353535;
    font-weight: 500;
}

/* --- 链接 (网址颜色) --- */
#nice a {
    color: #D97757; 
    font-weight: 500;
    text-decoration: none;
    border-bottom: 1px solid #D97757;
}

/* --- 代码块 (修复显示问题) --- */
#nice pre {
    background: #282c34 !important;
    padding: 15px !important;
    border-radius: 13px;
    margin: 15px 0;
    overflow-x: auto;
    display: block;
}

#nice pre code {
    color: #abb2bf !important;
    font-family: Menlo, Monaco, Consolas, monospace;
    font-size: 14px;
    line-height: 1.6;
    background: transparent !important;
    display: block;
    white-space: pre;
}

/* --- 行内代码 --- */
#nice :not(pre) &gt; code {
    color: #D97757;
    background: rgba(217, 119, 87, 0.08);
    padding: 2px 5px;
    border-radius: 4px;
    font-size: 0.9em;
}

/* --- 列表 --- */
#nice ul, #nice ol {
    color: #D97757; 
    font-size: 16px;
}

#nice li section {
    color: #353535;
}

/* --- 加粗 --- */
#nice strong {
    font-weight: 700;
    color: #000000;
}

/* --- 斜体 (使用#D97757) --- */
#nice em {
    color: #D97757;
    font-style: italic;
}

/* --- 分隔线 --- */
#nice hr {
    height: 1px;
    border: none;
    margin: 40px 0;
    background-image: linear-gradient(to right, rgba(217, 119, 87, 0), rgba(217, 119, 87, 0.5), rgba(217, 119, 87, 0));
}
```
