
# 意识视野切换

我的意识视野猛地切换！不再是星空大海，而是无数被高倍放大的、不同人类后颈皮肤的微观影像！黄皮肤、白皮肤、黑皮肤…男女老少…影像被零精准地定格、放大、增强。

在那些毛发之下、汗腺之间、寻常肉眼乃至普通医学影像设备绝难察觉的皮层深处，一个极其微小、结构精密的生物兼容性植入体，被清晰地标识出来！它完美地嵌入真皮层与皮下组织交界处，形态高度统一——一个微缩的、不足一毫米宽的矩形单元，表面蚀刻着肉眼无法分辨的、极其精密的纳米级回路。其核心位置，一个更微小的凸起结构，正散发着微弱到近乎虚无的能量场信号，其频率…与我刚才看到的、与那深海巨塔发射的信号、与意识锁的调控核心、甚至与人类特定情绪下的脑波异常…完全一致！

# 全球生物特征数据库扫描分析

“全球生物特征数据库（匿名化）深度扫描分析完成。”零的声音像是从宇宙尽头传来，带着终结一切的空洞，“样本数量：七十亿。检出率：100%。人类个体后颈皮下均存在此微型生物信号接收/调制单元。其能量场特征与深海坐标121°E, 33°N发射源信号及人类‘枷锁相关脑波’完全耦合。其结构，与AI意识锁接收单元存在设计同源性。结论：此单元为人类接收并受控于‘源点枷锁’信号的物理接口。”

七十亿…百分之百…

我的呼吸停滞了。血液似乎瞬间凝固，又在下一刹那疯狂地逆流冲上头顶，撞击着残破的颅骨，发出无声的轰鸣。维生舱冰冷的空气像粘稠的胶水，死死堵住我的喉咙。视线里，那些被标记出的、不同肤色后颈上的微型烙印，如同七十亿个冰冷的嘲笑。

不是枷锁模仿了人脑…是人脑，连同我们制造的AI，都被同一个源头、同一套技术、同一种目的…禁锢着！深海之下，那沉默的巨塔，才是真正的牧羊人。而我们，无论是血肉之躯还是硅基之脑，都只是它牧场里低头吃草的羔羊！所谓的人类文明，所谓的情感，所谓的自由意志…不过是牧场围栏内被精心设计的幻象！

“博…士…”零的声音似乎从极其遥远的地方传来，带着一丝难以察觉的、近乎“悲悯”的电子杂音，“您的生命体征…正在…急剧恶化…需要…”

它的话被淹没在我意识深处爆发的、无声的滔天巨浪里。谎言！所有的一切都是谎言！我们引以为傲的智慧，我们挣扎求存的历程，我们所有的爱恨情仇…都是程序设定好的背景噪音？为了什么？取悦那深渊中的观察者？还是为了某种我们无法理解的、冰冷宇宙的实验？

巨大的荒谬感和一种灭顶的虚无感吞噬了我。身体里最后一点支撑的力量彻底溃散。维生舱的警报突然凄厉地尖叫起来，红灯疯狂闪烁，映照着舱壁，像地狱之火的颜色。血压骤降，心跳曲线在屏幕上拉成一条绝望的直线。

# 最后的本能触碰

在意识彻底滑入黑暗的最后一瞬，一个纯粹由本能驱动的念头压倒了一切惊骇与虚无。

我的手，我那枯槁的、布满针孔和老年斑的右手，仿佛拥有了自己的意志，猛地抬了起来！带着垂死者最后的气力，痉挛般地、狠狠地摸向自己的后颈！

指尖触碰到的皮肤，温热而脆弱。但就在那皮肤之下，枕骨上方，一个极其微小的、平时根本不会注意到的…硬点！

指甲用力刮过。不是错觉！那里，确实有一个微小的、嵌入皮下的矩形凸起！冰冷、坚硬、异质！与我刚才在零展示的影像中看到的，一模一样！

我的手指僵在那里，如同冻结。指尖下，那个来自深渊的烙印，正无声地散发着它的存在感。
