
# Figma怎么切换中文 Figma如何安装中文插件

> 来源：[https://v11enp9ok1h.feishu.cn/docx/KYK1dfgYkoRa3dxrWmQczEsSnTf](https://v11enp9ok1h.feishu.cn/docx/KYK1dfgYkoRa3dxrWmQczEsSnTf)

## 一、Figma怎么切换中文

由于Figma是一款由国外开发的设计软件，所以目前没有中文版。在Figma的设置中找到语言设置选项后发现，官方现在只提供了英语和日语两种语言选项。

![](img/e21305fb554df62f98600b4ed11d7043.png)

图1：语言设置

因此，如果我们希望将 Figma 切换为中文，就需要借助一些辅助的方法来实现。

最简单的一种方式是在网页版 Figma 中进行设置。网页版的 Figma 允许我们在不下载应用的情况下直接在线使用。此时，我们可以借助浏览器的翻译功能将内容翻译为中文。具体操作是打开浏览器设置，找到语言设置类目，将首选语言设置为简体中文，然后重启浏览器。回到Figma中，在靠左侧的位置鼠标右击，在上下文菜单中找到【翻译为中文】选项。这里要注意在Figma左侧位置点击鼠标右键，在中间画布位置点击的话会把对Figma本身的操作调出来。

![](img/f288d7c2c0885726a2b989b0798bccb3.png)

图2：翻译为中文

这样浏览器会自动翻译页面内容。但用这种中文翻译方式翻译的并不完全，可能会有翻译不准确或者未翻译的情况。如下图图3所示的分享按钮就没有翻译到。

![](img/c789e221b6834f673cfc3bf62a8fb6e8.png)

图3：汉化后的界面

为了更加彻底地解决这个问题，我们还是得安装中文插件。

## 二、Figma如何安装中文插件

为了让Figma适应国内设计的需要，Figma引进国内后，就有很多开发者制作了汉化的插件。可以根据需要用关键词【Figma汉化插件】进行检索，下载合适的插件。

这里将以FigmaCN这款插件作为示例进行演示。FigmaCN是一款Figma中文的插件，它经过设计师人工翻译的校准，翻译不会很生硬，而且大小层级的菜单都翻译了，能够满足日常使用的需要。

以安装到Chrome浏览器为例，我们下载好FigmaCN后，把它解压到本地的文件夹中，记住所在文件夹的位置。打开Chrome，在地址栏输入`chrome://extensions`后回车，打开插件管理页面。在页面右上角，有一个【开发者模式】的开关，我们点击启用。对插件的设置需要在该模式启用时才可操作。点击左侧“加载已解压的扩展程序”按钮，在打开的弹窗里选择刚才解压的文件夹。

![](img/e5caecf306c5f9fa4c94e4ff46935ddc.png)

图4：选择扩展程序

刷新Figma页面即可生效，可以看到页面已经被翻译成中文。在其他浏览器中使用Figma时，我们也可以用Figma中文插件进行翻译。

![](img/8f4dea841e832d527ee2c093596179d9.png)

图5：插件汉化后的界面

以上就是Figma怎么切换中文，Figma如何安装中文插件的全部内容。切换到中文界面后，我们可以更加直观地理解和操作Figma，提高工作效率。安装中文插件能帮助我们更好地处理中文排版和字体，确保设计效果符合中文用户的需求。
