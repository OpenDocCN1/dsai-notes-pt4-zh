## 何者社区介绍

+ **社区背景与定位**：何者社区是专注于法律科技领域的高质量社区重新认识一下：何者 Hezher 法律科技社区｜附法律 AI 应用手册，2025年1月启动品牌，旗下业务线已运营数年。核心社群自2023年初启动，现有3000多位实名制法律科技爱好者，成员构成包括70%法律人（律师、法务、法学院师生、司法行政人员等）及AI行业从业者、创业者、投资人等，形成良好交流氛围。社区定位从最初服务自身AI项目的用户群，逐步转变为偏公益属性的交流平台，强调社会价值优先于商业价值。

+ **核心业务板块**：拥有法律科技知识库，与飞书深度合作并被收录为官方社区，在法律平台排名第一，曾进入全品类知识库前十，累计10万+商业网站用户访问学习。同时开展多元化活动，包括法律AI共创培训、互联网大厂参访学习（秉持"拥抱新技术先看天花板"理念）、法律AI共创大赛（如2024年8月与厦门律协举办全国首届法律AI创创大赛，对标海外黑客马拉松模式）。此外，与21家知名法律科技公司深度合作，联合律所法务（数据资源方）、法律科技公司及AI公司（技术资源方）共创项目，并提供数字化转型咨询服务，孵化面向律所和企业法务部门的定制化B端法律科技产品。

+ **举办路演日活动的动因**：源于2025年6月启动的共创项目，初衷是在各城市举办本地生态活动构建社区内容。同时，响应国家"产教融合""职普融通"政策导向，专注法律领域人工智能通识教育，旨在共创法律人日常工作运用AI的方法论。为识别真正好用的AI工具，计划开展法律科技产品测评活动，针对法律检索、合同起草审查等不同领域建立测评标准和样本数据集，通过科学框架筛选优质产品推荐给用户。此外，认为厂商与用户面对面交流至关重要，因此举办本次法律科技路演日。

## 参会人员与活动安排

+ **参会人员构成**：截至活动开始，报名人数达100多位。参会机构中，30%来自律师事务所，包括观涛律所、景天城、大成等；企业涵盖腾讯、字节、美团、英特尔集团及商汤、阶跃星辰等AI公司；投资机构有国字投、广发证券等；高校和科研机构包括莱顿大学、上海交大、华中科技大学及上海人工智能实验社等。

+ **活动开场致辞安排**：特别邀请上海法律科技协会副会长、上海律协法律科技委卫新主任做开场致辞。上海作为法律科技发展的优质土壤，2023年底上海市政府发布20号文鼓励法律科技发展，2024年初上海律协在魏主任带领下举办首届"最受上海律师欢迎的法律产品大赛"，筛选出20多家优质产品，2025年4月成立全国首家专业性法律科技协会——上海法律科技协会，主导法律科技发展传播、人才培训教育及产品大赛举办等工作。

## 卫新主任致辞

+ **对合者社区及活动的评价**：卫新主任作为合者社区早期参与者和付费用户，感谢社区组织本次活动，认为该活动具有创新性和意义。对比上海律协产品大赛从官方层面为产品提供复制和背书，合者社区的法律科技路演会将用户、评委与科技公司拉到同一现场，以用户体验为首要标准进行及时反馈和测评，形式独特且独立。同时感谢秘塔和AlphaGPT 两家获奖企业开放姿态展示新功能并接受用户吐槽质疑。

+ **对法律科技产品发展的三点建议**：
  + 一是以用户为老师，强调法律科技产品是"用出来的"，鼓励用户大胆提问、真诚反馈，认为用户互动是产品迭代的宝贵意见，代表行业产品方向；
  + 二是以场景为基石，指出法律科技需聚焦解决律师法务痛点，实现场景落地，而非炫技，回顾七八年前新兴法律产业论坛中300多家企业多数未盈利的情况，强调解决实际问题的重要性；
  + 三是以生态扩大价值，介绍上海作为全国法律科技高地的优势，包括2023年11月市委20号文、2023年底上海律协成立全国首个法律科技委员会（负责为全上海律师定制购买法律科技产品，推动行业数字化转型），以及2025年4月成立的上海市法律科技协会（市级社会团体，合者社区为理事单位）。

+ **上海法律科技协会工作预告**：预告2025年7月底世界人工智能大会（WAIC）期间，协会将组织法律科技专业分论坛，并面向全国组织新一年法律科技产品大赛，覆盖法务公司、仲裁鉴定、公检法等领域。同时正在建设法律科技人才库，推动法律科技专项扶持基金设立，出台发展应用扶持标准，推进产学研一体化评价机构建设，诚邀各方加入生态链，实现单点突破到群体跃迁，促进协作与共赢。

## 秘塔科技产品分享

+ **公司及产品理念概述**：秘塔科技首席运营官王一快（王益为）介绍，公司以AI产品品味和"有用"为核心理念。认为品类体现厂商对新一代AI应用的理解，当前国内AI产业缺乏想象力，存在跟风现象，而秘塔注重理解模型最强能力并匹配相应产品形态。"有用"则通过收费验证，强调AI产品应直接完成任务，收费模式可从传统SaaS订阅转向计件式，如深度推理报告定价9.9元/份。

+ **AI产品的品味：“今天学点啥”**：`https://metaso.cn/study`

+ 该产品是秘塔对AI产品品味理解的体现，获黑神话悟空制作人冯骥评价为"2025年继DeepSeek R1后最有创意的AI产品"。用户可搜索任意严肃topic（如法律、金刚经、小学数学等），基于秘塔2亿篇文章书籍的免费数据库，选择内容后AI自动分章节，用户可设置AI人格（如张爱玲、专家级别）、讲课风格（如暴躁老哥）、音色（如阳光女孩、智慧大爷）及输出语言（中/英文），30秒到1分钟内生成带逐字稿的PPT课件和视频，支持导出。

+ 应用场景包括开车时听课、快速准备汇报材料等，如某跨国公司法务曾用其快速生成GDPR新规的中英双语视频、PPT及逐字稿。产品主要通过导出视频等增值服务收费（约2-3元/次），用户粘性较高，已有不少老师使用超100小时。

+ **有用：MetaLaw，点击试用👉**：`https://flxyj.meta.law/`

+ 针对法律专业群体，2023年12月推出Beta版本，采用搜索增强技术消除模型幻觉，获律师认可，卖出15000个账号（499元/月）。随着DeepSeek R1等基础模型推理能力提升及裁判文书公开数量减少（总量约1.7亿篇，且质量参差不齐），原有依赖类案的模式受限，遂升级为基于模型对法律法规理解直接生成深度推理报告。

+ 报告结构包括核心法律责任分析、相关案例辨析、结论与建议，引用案例均有真实案号可跳转验证，生成时间约1分钟，质量优于律师助理一天工作量。应用场景包括律师谈案，可快速生成详实报告（约5000字）并定制律所logo，帮助拓宽案源。收费9.9元/份，已在大成、昊天等前100大律所测试，反馈为合伙人欣喜、年轻律师担忧，被认为是当前深度法律研究的"版本答案"。

+ **现场演示与互动答疑**：现场演示了针对"公司非因劳动者原因停工停产期间，高管仍按原薪资水平给自己发放高额薪资，公司能否追回"问题的深度推理报告生成过程，报告涵盖法律分析、案例引用、追回建议等。

+ 互动中解答了关于劳动仲裁前置、多救济手段策略、与国际竞品（如Google Gemini、ChatGPT的Deep Research功能）对比、数据库差异、本地化部署、付费模式（先试用2-3份，满意后付费）、报告验证（案号真实可查，需用户自行核对原文）、产品迭代（依赖基模能力提升而非用户反馈数据）、细分领域区分（受限于开发能力和盈利不确定性暂不做）等问题，并收集到"今天学点啥"产品全屏设计体验不佳及建议特色音效收费等用户反馈。

## iCourt及AlphaGPT 系列产品介绍

+ **iCourt公司背景**：I拓的基因是“法律人加工程师”，最早的30多位成员非法律人即工程师，创业12年，在北京拥有名为“day one”的法律科技大楼，在全国有五个主要办公室，海南是基地，主要业务分布在多个城市，其👸号为“法秀”，旨在让法律人更优秀。

+ **AlphaGPT 产品发展**：AlphaGPT 产品在法律人日常工作中功能强大，自2016年上线以来成为国内前沿且权威的法律大数据库。AI出现后，上线了AlphaGPT ，在法律咨询、法律研究、合同审查等方面全程提供强大功能，且阿尔法产品已进入第8个年头，每月不断迭代，AI相关功能迭代更快，基本每周都在更新优化。

## AI大模型相关知识与应用探讨

+ **提问技巧迷思破除**：探讨了用户在使用大模型时关于提问技巧的疑问，指出在DeepSeek开启推理型大模型时代后，用户无需专门学习提示词，正常提问即可得到专业答案，若问题不够全面可继续追问校正。

+ **推理型大模型技术特点**：说明推理型大模型能听懂用户需求并进行深度推理，主流分为基于DeepSeek代码开源自研推理模型（如互联网大厂）和直接接入DeepSeek底层技术订阅其推理能力（如法律行业科技公司）两类。

+ DeepSeek能力边界与黄金公式：分析DeepSeek并非万能，其运作遵循“接收问题-调用数据-调用技能-输出答案”的黄金公式，模型能力受数据和技能影响，可能出现“幻觉”，并解释了数据调用的公开性判断标准及技能分类与水平判断方式。

## AlphaGPT 产品介绍与实操演示

+ **AlphaGPT 与通用大模型区别**：AlphaGPT 是在通用大模型基础上，增加法律专业数据和法律应用场景专门技能训练形成的法律人专用工具，与通用大模型相比，在法律垂类领域数据和技能更具针对性。

+ **AlphaGPT 数据与技能优势**：拥有全球最大中文法律数据库，数据每日更新，涵盖案例、法规、裁判观点等，并通过工程师对模型的微调训练和法律专业团队（如清华大学法学院老师带领）的技能训练，提升其专业性。

+ **四大核心功能模块**：详细介绍了法律检索（含法律咨询、案例检索，法律咨询分法律咨询、法院全息、实务研究和进阶分析四个模式）、合同审查（支持单合同审查、合同比对审查，可选择审查立场和尺度，提供多种导出版本）、文书起草（含特定类型文书和自由起草，未来将上线要素式诉状撰写功能）、法律意见生成（主要针对民事案件，可生成包含多板块内容的法律意见书，助力提升客户体验和报价），并进行了相关实操演示，包括账号登录、功能操作、结果导出等。

## 产品应用价值与行业赋能

+ **提升工作效率与创收**：多位律师反馈使用AlphaGPT 节省时间、提高谈案成功率，如快速生成方案签约、节省人力成本、高效处理法律咨询和合同审查等，尤其利于常法业务等专业化路线的律所实现集约化服务。

+ **辅助模拟法庭与知识管理**：可用于模拟法庭，正反方角度分析案件完善准备思路，同时有助于律所知识管理。

+ **行业赋能与交流**：iCourt通过👸号、视频号、线上线下活动等帮助律师打造个人影响力和专业度，欢迎律师分享专业内容，也组织年轻律师到各地律协进行专业课培训。

## 互动问答

+ **AI工具定位与价值**：AI小助理在法律问题解决的前期步骤效率高，但方案的可采纳性判断和决策责任仍需专业人士承担，希望借助技术探索新型商业模式推动行业发展。

+ **英文功能支持情况**：当前产品基于DeepSeek板块具备英文功能，可支持翻译及英文合同审查，但因未进行专门训练，效果暂不能期待过高。

+ **模拟法庭功能规划**：团队曾认真调研过模拟法庭场景，但短期内不会单独增加该功能。现有案例已总结如何借助工具实现相关模拟，包括模拟被告与原告辩护律师提问方式转换，以及律所邀请客户参与、团队分别担任法官和双方律师的全流程互动环节，其中涉及利用AI生成材料、合同脱敏等准备工作。

+ **合同脱敏解决方案**：合同脱敏若需本地解决，需安装本地脱敏客户端，目前产品脱敏环节仍在云端进行。对于律师专有数据库不想上传的问题，因大模型已在工信部备案，数据安全有严格要求，技术上无法实现不上传数据使用功能；若涉及私有化部署，建议考虑私有云部署，而非本地机部署，因一体机硬件投资成本高且不实惠。

+ **法官信息查询与更新机制**：基于裁判文书数据构建的.8亿案例库，具备可视化功能，输入地区如“徐汇”可定位至上海徐汇区人民法院，快速查看该区域所有公开数据对应的法官信息，包括法官审理案件类型、裁判结果、相关当事人及熟悉律师等。数据更新与年限相关，会保留法官历史案件数据，如1995-2000年的案例，但裁判文书公开比例约15%，数据仅供参考。

+ **产品模块与试用权限**：产品包括 Alpha 和 AlphaGPT 两个模块，分别解决不同问题，支持单独或整体开通及选模块采购。当前提供的试用未开通 Alpha 模块，若有强烈需求可单独提供帮助，免费版本无相关界面功能。

+ **案例分析功能的扩写意义**：对于案例分析功能下的扩写功能，虽工程师最初不理解其必要性，但该功能对用户体验提升显著，不会从根本上影响模型推理。对于难以清晰表述问题的律师，此功能能提供安全感、缓解焦虑，且不影响模型通过推理理解问题。

+ **追问补全信息功能迭代**：针对生成报告前追问补全信息的功能，团队近期正对多个功能进行MCT升级，反见板块已具备反向确认的雏形，后续所有功能都将加入该迭代，且产品每周都会进行迭代优化。

+ **法律阅卷功能适用范围**：法律阅卷功能未特别区分阅卷类型，原定内容集中于法律类文件，如案件材料、卷宗等，可对其进行梳理，但不适合用于阅读非法律类文章，优势在于法律问题回答。刑事案件可使用该功能，同时还有专门的智能证据系统供刑事案件律师使用，可在线阅卷并自动生成阅卷笔录、质证意见、庭审笔录等，该系统18年上市且目前正在进行AI化升级。当前PPT中的阅卷功能更多是根据用户要求梳理内容，尚未达到直接生成可提交法院的证据目录及材料的阶段，因中间需确认、分卷、标记、撰写证明目的等步骤。

+ AI工具对律师价值与客户关系的影响：从客户角度，产品作为垂类工具，主要接触对象为企业法务部及法律咨询公司，普通案件当事人接触存在阻碍，一是产品收费，二是其作为非专业人士难以清晰表述问题且未必信任AI答案，更多可能是拿着AI答案向律师求证，律师需应对此场景而非担心客户使用工具。

+ **年轻律师的成长路径**：年轻律师在技术应用能力上具有优势，工具可帮助其快速提升专业能力，但仍需积累实践经验。未来法律服务竞争是市场竞争，建议年轻律师通过讲课、写文章、运营自媒体等方式打造专业影响力，以获得合作伙伴信任。

+ **当事人首次沟通信息处理**：当事人首次见面沟通时，语音录入或形成简要案情情况并快速输出法律意见的场景，可通过法律咨询功能直接输入问题获取分析答案，或使用法律意见功能实现。产品支持语音输入，输入后会转成文字，建议检查调整文字，若产品无此功能，可配合🛰️等工具解决。
