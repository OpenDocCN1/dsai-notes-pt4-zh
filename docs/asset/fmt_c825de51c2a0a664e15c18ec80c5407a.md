## 接口请求

| 传输方式 | https |
| --- | --- |
| 请求地址 | `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
| 调用方式 | 同步调用，等待模型执行完成并返回最终结果或 SSE 调用 |
| 字符编码 | UTF-8 |
| 接口请求格式 | JSON |
| 响应格式 | JSON 或标准 Stream Event |
| 接口请求类型 | POST |
| 开发语言 | 任意可发起 http 请求的开发语言 |

### 接口请求参数

| 参数名称 | 类型 | 是否必填 | 参数说明 |
| --- | --- | --- | --- |
| `model` | `String` | 是 | 所要调用的模型编码。 |
| `messages` | `List<Object>` | 是 | 调用语言模型时，将当前对话信息列表作为提示输入给模型；按 总长度超过模型最长输入限制后会自动截断，需按时间由旧到新排序；模型可接受的消息类型包括`System message`、`User message`、`Assistant message`和`Tool message`。可接受的格式为`json`数组。见下方`message`消息字段说明 |
| `request_id` | `String` | 否 | 由用户端传参，需保证唯一性；用于区分每次请求的唯一标识，用户端不传时平台会默认生成。 |
| `do_sample` | `Boolean` | 否 | `do_sample`为`true` 时启用采样策略，`do_sample`为`false` 时采样策略`temperature`、`top_p`将不生效 |
| `stream` | `Boolean` | 否 | 使用同步调用时，此参数应当设置为`Fasle`或者省略。表示模型生成完所有内容后一次性返回所有内容。 |
| `temperature` | `Float` | 否 | 采样温度，控制输出的随机性，必须为正数  取值范围是：(0.0,1.0]，不能等于 0,默认值为 0.95  值越大，会使输出更随机，更具创造性；值越小，输出会更加稳定或确定  建议您根据应用场景调整 `top_p` 或 `temperature` 参数，但不要同时调整两个参数 |
| `top_p` | `Float` | 否 | 用温度取样的另一种方法，称为核取样  取值范围是：(0.0, 1.0) 开区间，不能等于 0 或 1，默认值为 0.7  模型考虑具有 `top_p` 概率质量`tokens`的结果  例如：0.1 意味着模型解码器只考虑从前 10% 的概率的候选集中取`tokens`  建议您根据应用场景调整 `top_p` 或 `temperature` 参数，但不要同时调整两个参数 |
| `max_tokens` | `Interger` | 否 | 模型最大输出 `tokens` |
| `stop` | `List` | 否 | 停止词，目前仅支持单个停止词，格式为`["stop_word1"]` |
| `tools` | `List` |  | 模型可以调用的工具列表 |
| `type` | `String` | 是 | 工具类型，目前仅支持`function` |
| `function` | `Object` | 是 |  |
| `name` | `String` | 是 | 函数名称。 |
| `description` | `String` | 是 | 用于描述函数功能。模型会根据这段描述决定函数调用方式。 |
| `parameters` | `Object` | 否 | `parameter`字段需要传入一个 `Json Schema` 对象，以准确地定义函数所接受的参数。若调用函数时不需要传入参数，省略该参数即可。样例： |
| `tool_choice` | `String`或`Object` | 否 | 控制模型是否调用定义的函数。 |

模型可接受的消息类型包括`System message`、`User message`、`Assistant message`和`Tool message`，不同的消息类型格式不同，具体如下：

#### System message

| 参数名称 | 类型 | 是否必填 | 参数说明 |
| --- | --- | --- | --- |
| `role` | `String` | 是 | 消息的角色信息，此时应为`system` |
| `content` | `String` | 是 | 消息内容 |

#### User message

##### 纯文本格式

调用`glm-4`、`glm-3-turbo` 模型时，使用此格式的 `User message` 。

| 参数名称 | 类型 | 是否必填 | 参数说明 |
| --- | --- | --- | --- |
| `role` | `String` | 是 | 消息的角色信息，此时应为`user` |
| `content` | `String` | 是 | 消息内容。内容仅为文字消息时类型为`string`。 |

##### 内容分块数组

仅在调用`glm4-v`模型时，使用此格式的 `User message` 。

此时`content`是一个数组，其中的元素是一个内容块，一个内容块是文本类型或图片类型。

| 参数名称 | 类型 | 是否必填 | 参数说明 |
| --- | --- | --- | --- |
| `role` | `String` | 是 | 消息的角色信息，此时应为`user` |
| `content` | `String`或`List` | 是 | 消息内容。`List`中包括消息的各个部分。各部分可以分别为文字或图片消息。以下为文字部分和图片部分的传参格式。 |
|  | `Object` |  | 文字类型 |
| `type` | `String` | 是 | 此时应为`text` |
| `text` | `String` | 是 | 消息文字内容 |
|  | `Object` |  | 图片类型 |
| `type` | `String` | 是 | 此时应为`image_url` |
| `image_url` | `String` | 是 | 图片链接或图片的`base64`编码 |

内容分块数组的示例：

```
{
    "role": "user",
    "content": [
        {
            "type": "text",
            "text": "图里有几个人，他们可能要去哪里"
        },
        {
            "type": "image_url",
            "image_url": {
            }
        }
    ]
}
```

#### Assistant message

| 参数名称 | 类型 | 是否必填 | 参数说明 |
| --- | --- | --- | --- |
| `role` | `String` | 是 | 消息的角色信息，此时应为`assistant` |
| `content` | `String` | 否 | 消息内容。如果消息中包括了`tool_calls`字段，`content`字段为空。 |
| `tool_calls` | `List` | 否 | 模型产生的工具调用消息 |
| `id` | `String` | 需要填写`tool_calls`时必填 | 模型调用的工具 |
| `type` | `String` | 需要填写`tool_calls`时必填 | 模型调用的工具类型，目前只支持`function` |
| `function` | `Object` | 需要填写`tool_calls`时必填 | 模型调用的函数 |
| `name` | `String` | 需要填写`tool_calls`时必填 | 模型调用的函数名称 |
| `arguments` | `String` | 需要填写`tool_calls`时必填 | 模型调用函数时传递的参数，为`json`格式。 |

#### Tool message

| 参数名称 | 类型 | 是否必填 | 参数说明 |
| --- | --- | --- | --- |
| `role` | `String` | 是 | 消息的角色信息，此时应为`tool` |
| `content` | `String` | 是 | `tool message`消息内容，为工具被调用后返回的结果。 |
| `tool_call_id` | `String` | 是 | 产生此消息的函数的唯一标识。 |

## 非流式调用

### 请求示例

```
from zhipuai import ZhipuAI
client = ZhipuAI(api_key="") 
response = client.chat.completions.create(
    model="glm-4",  
    messages=[
        {"role": "user", "content": "你好"},
        {"role": "assistant", "content": "我是人工智能助手"},
        {"role": "user", "content": "你叫什么名字"},
        {"role": "assistant", "content": "我叫chatGLM"},
        {"role": "user", "content": "你都可以做些什么事"}
    ],
)
print(response.choices[0].message)
```
