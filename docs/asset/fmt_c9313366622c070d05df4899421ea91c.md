
# 数据跨境新规动态

> 来源：[https://docs.feishu.cn/docx/KpYxdpBWloj3Udx1nJrcWaP5njb](https://docs.feishu.cn/docx/KpYxdpBWloj3Udx1nJrcWaP5njb)

- **问：**有人知道之前国庆节前发布的数据跨境流动新规草案有动静了吗？SCC备案到底还做不做啊？

- **答1：**问属地网信办，**不同地方不一样**。

- **答2：央办、上海CAC等建议按照现行规定**照做，但也有部分北方CAC暂时不接受备案了，要等规定出台。

- **答3：**据说是，网信办积极推进，但有些反对意见所以推迟了。
