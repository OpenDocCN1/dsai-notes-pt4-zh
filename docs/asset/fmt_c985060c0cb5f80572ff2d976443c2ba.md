### 1️⃣ 关于 Creem Webhook 和终端关闭

+ 不删除 Creem Dashboard 里的其他 Webhook 可以吗？
+ 可以，但不推荐开启。只要您确保那些指向 `localhost` 或 `ngrok` 的 Webhook 处于 `Disabled` (禁用) 状态，它们就不会产生影响。如果它们是 `Enabled` 的，Creem 发送请求时会失败（因为您关闭了终端），虽然不影响生产环境的成功支付，但在 Creem 后台会看到很多报错日志，比较碍眼。
+ 只要保留那个指向 `us-central1-copypose...` 的生产 Webhook 是 `Enabled` 状态即可。
+ 现在终端可以放心全部关闭吗？
+ 完全可以。只要 Creem 也就是 Live 模式下的 Webhook 配置的是 Firebase Cloud Functions 的地址（即 `https://us-central1-...` ），您的支付系统就在云端独立运行了，与您本地电脑的终端无关。您可以随时关闭 `ngrok`、`npm run dev` 等所有终端。
