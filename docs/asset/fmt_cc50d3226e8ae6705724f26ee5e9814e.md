```
COT_prompt = '请一步步思考并得到答案。'
```

```

                    model="text-davinci-003",
                    prompt=question1+COT_prompt,
                    max_tokens=1000,
                    )
```

```
# 答案为11个球
response_gpt3_q1["choices"][0]["text"].strip()
```

```
'分析：罗杰一开始有5个网球，他再买了两盒网球，每盒有3个网球，\n\n答案：罗杰现在总共有11个网球。'
```
