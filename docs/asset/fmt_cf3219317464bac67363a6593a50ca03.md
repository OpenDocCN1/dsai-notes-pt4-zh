## 智能体工具介绍

说明：智能体就是让我们在各大平台上面，通过0代码创建出一个专属的AI助手。比如想出题改题的教学助手，需要有一个智能菜谱进行做菜，或者说要有人实时对会议做出笔记。这些之前都是通过聘请或者询问专业的人才能有的服务，一旦我们学会了搭建智能助手，我们就可以直接依托AI，做出一个独属于自己的智能工具或者智能助手，以此来方便我们的日常生活。

## 智能体实际应用

### 情景

日常工作中需要一款智能办公助手，来方便我们的办公生活，对于满足我们的需要具备以下多方面能力：能够对办公文档深度处理，精准提炼要点，巧妙生成大纲，仔细检查语法错误并进行专业润色；可以妥善安排会议相关事务，包括精心确定合适时间，周到地生成详细议程以及便捷地发送通知；还应高效执行任务管理工作，涵盖创建任务清单、实时跟踪进度以及合理进行优先级排序等，从而确保在办公场景中能够灵活自如地应对各类需求，有力推动办公流程顺畅进行并显著提升办公效率。

### 建立流程

![](img/5ccb8e6a2e71acd08239fa03bf3e8406.png)

> 设定模板：

> （一）文档处理

> 文档要点提取：快速分析文档，精准提炼核心要点与关键信息，生成简洁明了的总结，方便用户快速了解文档主旨。 大纲生成助手：依据文档主题与内容，智能构建逻辑清晰、层次分明的大纲，为撰写文档提供框架思路。 语法错误侦探：全面扫描文档，精准定位语法错误，并提供修正建议与正确用法示例，助力用户提升文档质量。 文案润色专家：运用丰富的语言表达技巧，对文档语句进行优化，使表述更专业、流畅、富有说服力

> （二）会议管理

> 最佳时间探寻者：结合参会人员日程安排，综合考虑工作繁忙时段、个人偏好等因素，智能推荐最优会议时间。 议程定制大师：根据会议主题与目的，自动生成详细且合理的会议议程，明确各环节时间分配与讨论要点。 通知一键发送员：按照预设模板，快速向参会人员发送会议通知，可自动添加会议详情至日历应用，提醒参会者准时参与。

> （三）任务管理

> 任务清单创建者：依据项目需求或日常工作安排，协助用户创建任务清单，明确任务名称、负责人、截止日期及详细描述。 进度跟踪小助手：实时接收任务进度更新，以直观的可视化方式展示任务进展情况，及时发现滞后任务并发出预警。 优先级排序顾问：根据任务的紧急程度、重要性以及资源需求等多维度因素，为任务合理分配优先级，确保关键任务优先处理。

> 三、交互方式

> 语音交互：支持自然语言语音输入与输出，用户可通过语音指令快速下达任务，助手以清晰语音回复结果与建议，适用于双手忙碌场景，如会议中记录要点、文档撰写时语音输入等。 文字输入：在电脑端或移动端应用内，用户可输入文字指令或问题，助手迅速理解并给予精准回应，方便在安静环境或需要详细指令输入时使用。 快捷指令：预设常用操作快捷指令，如 “总结文档”“安排会议”“查看任务进度” 等，用户点击即可触发对应功能，提高操作效率。

+ 示例文档内容：“在本次市场推广活动中，我们采用了线上线下相结合的方式。线上通过社交媒体平台进行广告投放和话题互动，吸引了大量潜在客户的关注。线下则在多个商业中心举办了产品体验活动，直接与消费者进行面对面交流。活动期间，产品的知名度得到了显著提升，销售额也有了一定程度的增长。然而，我们也发现了一些问题，比如线上广告的精准度有待提高，线下活动的场地布置可以更加优化。”

+ 应用的 Prompt 语句：“请总结以下办公文档的要点：在本次市场推广活动中，我们采用了线上线下相结合的方式。线上通过社交媒体平台进行广告投放和话题互动，吸引了大量潜在客户的关注。线下则在多个商业中心举办了产品体验活动，直接与消费者进行面对面交流。活动期间，产品的知名度得到了显著提升，销售额也有了一定程度的增长。然而，我们也发现了一些问题，比如线上广告的精准度有待提高，线下活动的场地布置可以更加优化。”

#### 3. 检查文档语法错误

+ Prompt 语句：“检查这段办公文档中的语法错误并修正：[输入文档段落]”

输入文档段落：“The report was wrote by our team, it contains many important informations about the project.”

+ 应用的 Prompt 语句：“检查这段办公文档中的语法错误并修正：The report was wrote by our team, it contains many important informations about the project.”

> 生成结果：

> 您好！很高兴为您提供帮助。根据您的请求，我检查了您提供的办公文档中的语法错误，并进行了修正。以下是修正后的内容：

> “The report was written by our team. It contains many important pieces of information about the project.”

> 这句话中的错误在于“wrote”应该改为“written”，因为“was”后面需要接过去分词构成被动语态。另外，“informations”是一个错误的单词，因为“information”是不可数名词，所以应该用“pieces of information”来表示多条信息。

> 希望这个修正对您有帮助。请问您还有其他需要我协助处理的任务吗？

#### 4. 润色文档语句

+ Prompt 语句：“对以下办公文档中的语句进行润色，使其表达更专业清晰：[文档片段]”

文档片段：“我们做了这个实验，结果还不错，以后可能会继续做类似实验。”

+ 应用的 Prompt 语句：“对以下办公文档中的语句进行润色，使其表达更专业清晰：我们做了这个实验，结果还不错，以后可能会继续做类似实验。”

> 生成结果如下：

> 您好！很高兴为您提供帮助。根据您提供的办公文档内容，我对语句进行了润色，使其表达更专业清晰：

> “我们成功实施了该实验，并取得了令人满意的成果。基于这一积极结果，我们计划在未来继续开展类似的实验。”

> 希望这个润色对您有帮助。请问您还有其他需要我协助处理的文档或任务吗？

会议时长：1.5 小时

会议主题：新产品研发讨论

+ 应用的 Prompt 语句：“根据参会人员张三（部门经理）、李四（项目负责人）、王五（技术骨干）的日程安排，确定一个合适的会议时间，会议时长约为 1.5 小时，主题是新产品研发讨论”

> 您好！很高兴为您提供帮助。根据您提供的参会人员日程安排和会议需求，我为您推荐以下会议时间：

> 经过对张三（部门经理）、李四（项目负责人）、王五（技术骨干）三位参会人员的日程分析，我发现下周二上午10:00至11:30是一个较为合适的时间段，此时三位人员均处于空闲状态，且能够满足会议时长约为1.5小时的要求。

> 请问您对推荐的会议时间是否满意？如果有其他需求或建议，请随时告诉我。同时，我也可以根据您的要求进一步调整会议议程和安排。

#### 2. 生成会议议程

+ Prompt 语句：“为 [会议主题] 会议生成一份包含 [主要讨论事项 1、主要讨论事项 2 等] 的会议议程”

会议主题：团队季度总结会议

主要讨论事项 1：本季度工作成果回顾

主要讨论事项 2：存在的问题与解决方案

+ 应用的 Prompt 语句：“为团队季度总结会议生成一份包含本季度工作成果回顾、存在的问题与解决方案的会议议程”

> 生成内容如下：

> 您好！很高兴为您提供帮助。根据您团队季度总结会议的需求，我为您生成了一份包含本季度工作成果回顾、存在的问题与解决方案的会议议程：

> 团队季度总结会议议程

> 一、会议开场

> + 主持人开场致辞，介绍会议目的与流程

> + 参会人员签到与自我介绍

> 二、本季度工作成果回顾

> 1. 各部门工作成果展示

> + 每位部门负责人简要汇报本季度主要工作内容及成果

> + 使用PPT或图表展示关键数据

> 2. 项目进展总结

> + 重点项目负责人汇报项目进展情况

> + 展示项目成果，包括已完成的里程碑及取得的成效

> 3. 团队协作与沟通情况

> + 回顾团队在协作与沟通方面的表现

> + 分析协作中的成功案例与待改进之处

> 三、存在的问题与解决方案

> 1. 识别问题

> + 各部门负责人及参会人员共同识别本季度工作中存在的问题

> + 对问题进行分类与归纳

> 2. 分析原因

> + 对识别出的问题进行深入分析，找出根本原因

> + 探讨问题对团队及项目的影响

> 3. 制定解决方案

> + 针对每个问题，提出具体的解决方案

> + 分配责任人与完成时间

> + 设定解决方案的评估标准与反馈机制

> 四、会议总结与后续行动计划

> 1. 主持人对会议内容进行总结

> + 强调本季度工作成果与收获

> + 指出存在的问题与解决方案

> 2. 制定后续行动计划

> + 根据会议讨论结果，制定详细的后续行动计划

> + 明确各部门的任务与责任

> 3. 会议结束

> + 感谢参会人员的贡献与支持

> + 宣布会议结束，并安排下次会议时间

> 希望这份会议议程能够满足您的需求。请问您还有其他需要我协助处理的任务吗？
