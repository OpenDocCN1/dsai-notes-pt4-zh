
# 如何比较两个概率分布

我们只需将一个概率分布从另一个中减去。更多细节可以查看 [交叉熵](https://www.zhihu.com/search?q=%E4%BA%A4%E5%8F%89%E7%86%B5&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A677202804%7D) 和 Kullback–Leibler 散度。

但请注意，这是一个过于简化的例子。更现实地，我们会使用比一个单词更长的句子。例如 - 输入：“je suis étudiant”，期望输出：“i am a student”。这实际上意味着我们希望我们的模型依次输出概率分布，其中：

+ 每个概率分布由一个宽度为 `vocab_size`（在我们的玩具示例中为 6，但在现实中可能是 30,000 或 50,000）的向量表示。
+ 第一个概率分布在与单词 “i” 相关联的单元格中有最高的概率。
+ 第二个概率分布在与单词 “am” 相关联的单元格中有最高的概率。
+ 此类推，直到第五个输出分布表示 `<end of sentence>` 符号，它在 10,000 元素词汇表中也有一个相关联的单元格。

经过多轮训练以后，可能会得到：

![](img/b15a5fdb226f403b33de97be74479ade.png)

现在，因为模型一次产生一个输出，我们可以假设模型正在从概率分布中选择概率最高的单词，并丢弃其余的。这是一种做法（称为贪婪解码，greedy decoding）。

另一种方法是保留比如前两个单词（比如 “I” 和 “a”），然后在下一步中，运行模型两次：一次假设第一个输出位置是单词 “我”，另一次假设第一个输出位置是单词 “一个”，并且保留在考虑第 1 和第 2 位置时产生较少错误的那个版本。我们重复这个过程，对第 2 和第 3 位置 [...等等](https://www.zhihu.com/search?q=%E6%9C%AA%E5%AE%8C%E6%88%90%E7%9A%84&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22article%22%2C%22sourceId%22%3A677202804%7D)。这种方法被称为 “束搜索”（beam search，相对而言，贪婪算法每次只找出一个最优的单词）。在我们的例子中，束大小（`beam_size`）= 2。这也意味着在所有时候，两个部分假设（未完成的翻译）被保留在内存中。而最优束（`top_beams`），也是两个。而这个 `beam_size`，也只是模型的一个超参数。
