### Leopard：针对文本丰富的多图像任务的视觉语言模型

文字丰富的图像是引导整体理解的核心视觉元素，在现实世界的应用中非常普遍，例如演示幻灯片、扫描文档和网页快照。涉及多个文本丰富的图像的任务尤其具有挑战性，因为它们不仅需要理解单个图像的内容，还需要推理多个视觉输入之间的相互关系和逻辑流。尽管这些场景非常重要，但目前的多模态大语言模型（MLLM）在处理此类任务时却举步维艰，这主要是由于两个关键挑战：（1）针对文本丰富的多图像场景的高质量指令微调数据集稀缺；（2）图像分辨率与视觉特征序列长度之间难以平衡。

为了应对这些挑战，来自圣母大学和腾讯集团的研究团队及其合作者提出了 Leopard，一种专为处理涉及多幅文本丰富图像的视觉语言任务而设计的 MLLM。首先，他们整理了约一百万个高质量的多模态指令微调数据，专为文本丰富的多图像场景量身定制。其次，他们开发了一个自适应高分辨率多图像编码模块，可根据输入图像的原始长宽比和分辨率动态优化视觉序列长度的分配。在各种基准测试中进行的实验证明，他们的模型在文本丰富的多图像评估中能力出众，在一般领域的评估中也具有很强的竞争力。

### 哈佛、MIT 团队推出 LLM 泛化能力动态评估框架 Scylla

虽然大语言模型（LLMs）在理解复杂查询和执行复杂任务方面表现出了非凡的能力，但它们的泛化能力往往与记忆力密切相关，因此需要更精确的评估。为了应对这一挑战，来自哈佛大学、麻省理工学院的研究团队及其合作者推出了 Scylla，这是一个动态评估框架，可定量测量 LLM 的泛化能力。

Scylla 通过评估模型在分布内（ID）和分布外（OOD）数据上的表现，将泛化与记忆区分开来，并通过 5 个复杂度级别的 20 个任务进行评估。通过大量实验，他们发现任务复杂度与 ID 和 OOD 数据之间的性能差距之间存在非单调关系，他们称之为 generalization valley。具体来说，这一现象揭示了一个临界阈值（他们称之为临界复杂度），在这个阈值上，对不可概括行为的依赖达到了顶峰，这表明 LLM 的概括能力达到了上限。随着模型大小的增加，临界复杂度会向更高的任务复杂度转移，这表明在过度依赖记忆之前，较大的模型可以处理更复杂的推理任务。

利用 Scylla 和临界复杂度的概念，他们对 28 种 LLM 进行了基准测试，其中既包括开源模型（如 LLaMA 系列），也包括闭源模型（如 Claude 和 GPT），从而提供了更鲁棒的评估，并对 LLM 的泛化能力有了更清晰的认识。

论文链接：

https://arxiv.org/abs/2410.01769

### ComfyGen：文本到图像生成的提示自适应工作流程

文生图的实际应用已经从简单的单一模型发展到结合多个专业组件的复杂工作流程。虽然基于工作流程的方法可以提高图像质量，但由于可用组件数量众多、相互依赖关系复杂，而且依赖于生成提示，因此制作有效的工作流程需要大量的专业知识。

来自 NVIDIA 和特拉维夫大学的研究团队推出了提示自适应工作流程生成这一新颖任务，其目标是根据每个用户的提示自动定制工作流程。他们提出了两种基于 LLM 的方法来解决这一任务：一种是基于微调的方法，它从用户偏好数据中学习；另一种是免训练方法，它使用 LLM 来选择现有流程。与单一模型或与提示无关的通用工作流程相比，这两种方法都能提高图像质量。他们的工作表明，与提示无关的流程预测为提高文生图的生成质量提供了一条新途径，是对该领域现有研究方向的补充。

### 港大、字节团队提出分钟级长视频生成模型 Loong

生成内容丰富的分钟级长视频依然充满挑战。在自然语言处理领域，自回归大语言模型（LLM）在生成连贯的长 token 序列方面取得了巨大成功，而自回归 LLM 在视频生成方面的探索却仅限于生成几秒钟的短视频。

在这项工作中，来自香港大学和字节跳动的研究团队深入分析了阻碍基于自回归 LLM 的视频生成器生成长视频的挑战。根据观察和分析结果，他们提出了一种新的基于自回归 LLM 的视频生成器——Loong，其可以生成分钟级长视频。

具体来说，他们将文本 token 和视频 token 建模为自回归 LLM 的统一序列，并从头开始训练模型。他们提出了从短到长的渐进式训练和损失再加权方案，从而缓解长视频训练中的损失不平衡问题。他们还进一步研究了推理策略，包括视频 token 重新编码和采样策略，以减少推理过程中的错误积累。结果表明，Loong 可以在 10 秒视频上进行训练，并可扩展到生成以文本提示为条件的分钟级长视频。

### 字节新研究：使用合成数据进行视频指令微调

视频大型多模态模型（LMM）的开发一直受阻于从网络上收集大量高质量原始数据的困难。为了解决这个问题，来自字节跳动、南洋理工大学和北京邮电大学的研究团队提出了另一种方法，即创建一个专门用于视频指令跟随的高质量合成数据集——LLaVA-Video-178K。该数据集包括详细字幕、开放式问答（QA）和多项选择 QA 等关键任务。通过在该数据集上进行训练，结合现有的视觉指令微调数据，他们推出了全新的视频大型多模态模型 LLaVA-Video。

实验证明，LLaVA-Video 在各种视频基准测试中都取得了优异的性能，突出了数据集的有效性。

### 苹果推出零样本度量单目深度估计模型 Depth Pro

苹果团队提出了一种用于零样本度量单目深度估计的基础模型。模型 Depth Pro 能合成具有高清晰度和高频细节的高分辨率深度图。预测结果是绝对规模的度量，而不依赖于可用的元数据，如相机内参。该模型速度极快，在标准 GPU 上 0.3 秒即可生成一幅 225 万像素的深度图。

这些特性得益于多项技术贡献，包括用于密集预测的高效多尺度视觉 transformer、结合真实和合成数据集以在精细边界追踪的同时实现高精度度量的训练协议、估算深度图中边界精度的专用评估指标，以及 SOTA 单幅图像焦距估算。广泛的实验分析了具体的设计选择，并证明 Depth Pro 在多个维度上都优于之前的研究成果。

### 清华团队提出高效精确的注意力量化方法 SageAttention

Transformer 架构在各种模型中占主导地位。作为 transformer 的核心，注意力的计算复杂度为 `O(N^2)`，而线性变换的计算复杂度为 `O(N)`。在处理大长度序列时，注意力成为最耗时的部分。虽然量化已被证明是加速模型推理的有效方法，但现有的量化方法主要侧重于优化线性层。

为此，清华大学团队首先详细分析了注意力量化的可行性。随后，他们提出了一种高效、精确的注意力量化方法 `SageAttention`。他们方法的 OPS（每秒操作数）分别比 `FlashAttention2` 和 `xformers` 高出约 2.1 倍和 2.7 倍。`SageAttention` 的准确性也优于 `FlashAttention3`。综合实验证实，他们的方法在包括大语言处理、图像生成和视频生成在内的各种模型中几乎没有端到端指标损失。

https://arxiv.org/abs/2410.02367

### 加州大学、Meta 提出模型合并新方法

模型合并（如模型汤）是指将具有相同架构的不同模型合并在一起而无需进一步训练的做法。来自加州大学洛杉矶分校和 Meta 的研究团队提出了一种模型合并方法，解决了针对非英语语言的目标任务微调大语言模型（LLMs）的困难，因为在非英语语言中往往无法获得特定任务的数据。

他们将重点放在数学推理上，在没有语言数学数据的情况下，通过组合语言和数学能力来促进跨语言迁移。从同一个预训练模型开始，他们分别对英语数学指令数据和目标语言通用指令数据的“专家”进行微调。然后，他们将数学“专家”的顶部和底部 transformer 层直接替换为语言“专家”层，从而提高了目标语言中的数学成绩。

在数学基准 MGSM 上，合并后的模型在数学教学数据稀缺的四种主要语言中的表现比单个专家和其他合并方法高出 10%。此外，这种层交换简单、成本低廉、直观，因为它是基于对每个“专家”微调过程中最重要参数变化的解释性分析。以这种方式成功地重新组合 LLM 进行跨语言转移的能力，为未来结合模型专业知识、创建模块化解决方案和跨语言转移推理能力提供了可能性。

论文链接：

https://arxiv.org/abs/2410.01335

### 耶鲁团队：智能源于预测复杂性的能力

来自耶鲁大学的研究团队及其合作者，通过研究基于规则的系统的复杂性如何影响为预测这些规则而训练的模型的能力，来探索人工系统中智能行为的出现。

他们的研究重点是基本细胞自动机（ECA），这是一种简单但功能强大的一维系统，能产生从琐碎到高度复杂的各种行为。通过在不同的 ECA 上训练不同的大语言模型（LLMs），他们评估了规则行为的复杂性与 LLMs 所表现出的智能之间的关系，这反映在它们在下游任务中的表现上。

研究结果表明，规则的复杂度越高，模型表现出的智能就越高，这一点可以从它们在推理和国际象棋走棋预测任务中的表现得到证明。无论均匀系统还是周期系统，通常还有高度混沌的系统，都会导致较差的下游表现，突出了有利于智能复杂性的“甜点”。他们推测，智能源于预测复杂性的能力，而创造智能可能只需要接触复杂性。

论文链接：

https://arxiv.org/abs/2410.02536

### 并非所有 LLM 推理都是一样的

在这项工作中，来自 Mila、Google DeepMind 的研究团队探讨了大语言模型（LLM）解决小学数学（GSM）问题的能力。

为此，他们评估了 LLM 在解决成对的现有数学单词问题时的表现，这样第二个问题的答案就取决于第一个问题的正确答案。研究结果表明，大多数 LLM 在推理方面存在明显差距，即解决成对组合问题与独立解决每个问题之间存在性能差异。这种差距在规模较小、成本效益较高和数学专业化的模型中更为明显。此外，指令微调方案和代码生成对不同规模的 LLM 有不同的影响，而在 GSM 上进行微调会导致任务过拟合。

分析表明，推理能力的巨大差距并不是因为测试集泄漏，而是由于额外上下文的干扰和糟糕的两跳推理造成的。总体而言，除了在标准基准上的表现，LLM 在推理能力上存在系统性差异。

论文链接：

https://arxiv.org/abs/2410.01748

### Meta Llama 团队提出“最弱链接法则”

大语言模型（LLM）的开发和评估主要集中在单项能力上。然而，这忽略了现实世界任务中经常需要的不同类型专业知识的多种能力的交叉，即交叉能力（cross capabilities）。

为了系统地探索这一概念，Meta 的 Llama 团队首先定义了七种核心个人能力，然后将它们配对形成七种常见的交叉能力，每种能力都由人工构建的分类法提供支持。在这些定义的基础上，他们提出了 CrossEval，这是一个由 1400 个人工标注的提示组成的基准，每个单项能力和交叉能力都有 100 个提示。为确保评估的可靠性，他们让专业标注人员参与评估 4200 个模型响应，收集了 8400 个带有详细解释的人类评分作为参考示例。

研究结果表明，无论是在静态评估中还是在尝试增强特定能力时，当前的 LLM 都始终表现出“最弱链接法则”（Law of the Weakest Link），即交叉能力表现受到最弱部分的严重制约。具体来说，在 17 个模型的 58 项交叉能力得分中，有 38 项得分低于所有单项能力，有 20 项得分介于强与弱之间，但更接近于较弱的能力。这凸显了 LLM 在交叉能力任务中的表现不佳，因此识别和改进最弱能力成为未来研究的重点，从而优化在复杂、多维场景中的表现。

https://arxiv.org/abs/2409.19951

### Illustrious：一个 SOTA 动漫图像生成模型

在这项工作中，Onoma AI 团队分享了在他们的文生图动漫图像生成模型 Illustrious 中实现“SOTA”级质量的见解。为了实现高分辨率、动态色彩范围图像和高还原能力，他们重点关注了模型改进的三个关键方法。首先，他们深入研究了 batch 大小和 dropout 控制的意义，这可以更快地学习基于可控 token 的概念激活。其次，他们提高了图像的训练分辨率，这影响了在更高分辨率下对人物解剖结构的准确描绘，通过适当的方法将其生成能力扩展到 2000 万像素以上。最后，他们提出了细化的多级标题，涵盖所有标签和各种自然语言标题，作为模型开发的关键因素。

通过广泛的分析和实验，Illustrious 在动漫风格方面展示了“SOTA”级性能，超越了插图领域中广泛使用的模型，并以开源的特性推动了更简便的定制和个性化。

### 阿里团队推出全能创作者和编辑器 ACE

扩散模型作为一种强大的生成技术已经出现，并被发现适用于各种场景。现有的大多数基础扩散模型主要是为文本引导的视觉生成而设计的，并不支持多模态条件，而多模态条件对于许多视觉编辑任务来说是必不可少的。这种局限性使得这些基础扩散模型无法成为视觉生成领域的统一模型，就像 GPT-4 在自然语言处理领域一样。

阿里团队提出了全能创作者和编辑器 ACE，它在各种视觉生成任务中都能达到与这些专家模型相当的性能。为了实现这一目标，他们首先引入了一种统一的条件格式，称为长上下文条件单元（LCU），并提出了一种新颖的基于 transformer 的扩散模型，该模型使用 LCU 作为输入，旨在对各种生成和编辑任务进行联合训练。此外，他们还提出了一种高效的数据收集方法，以解决缺乏可用训练数据的问题。它包括使用基于合成或聚类的管道获取成对图像，并利用微调的多模态大语言模型为这些成对图像提供准确的文本指示。为了全面评估模型的性能，他们在各种视觉生成任务中建立了人工注释配对数据基准。

大量的实验结果证明了模型在视觉生成领域的优越性。得益于模型的一体化功能，他们可以轻松建立一个多模态聊天系统，用一个模型作为后台，响应任何图像创建的交互请求，避免了视觉智能体通常采用的繁琐管道。

### 斯坦福大学提出室内四足移动操纵系统 DoggyBot

基于学习的方法在四足运动方面取得了很好的效果。然而，有几项挑战阻碍了“四足系统”学习需要与环境和人类互动的有用的室内技能：缺乏用于操纵的末端执行器、仅使用模拟数据的语义理解能力有限、室内环境中的可穿越性和可到达性较低。

来自斯坦福大学和加州大学圣地亚哥的研究团队提出了一种在室内环境中进行四足移动操纵的系统。该系统使用一个前端安装的机械手来操纵物体，一个在仿真中使用自我中心深度训练的低级控制器来实现攀爬和全身倾斜等敏捷技能，而预训练的视觉语言模型（VLMs）则使用一个第三人称鱼眼和一个自我中心 RGB 摄像头来实现语义理解和指令生成。

他们在两个未见过的环境中对系统进行了评估，没有收集任何真实世界的数据或进行任何训练。他们的系统可以在这些环境中实现零样本泛化并完成任务，例如在爬过一张大床后按照用户的指令取回随机放置的玩具，成功率高达 60%。

### Embodied-RAG：用于检索和生成的通用非参数具身记忆

机器人的探索和学习能力是无限的，但所有这些知识都需要可搜索和可操作。在语言研究领域，检索增强生成（RAG）已成为大规模非参数知识的工作场所，但现有技术并不能直接应用于多模态、数据高度相关、感知需要抽象化的具身领域。

为了应对这些挑战，卡内基梅隆大学团队推出了 Embodied-RAG，这是一个框架，通过非参数内存系统增强了具身智能体的基础模型，该系统能够自主构建用于导航和语言生成的分层知识。Embodied-RAG 可在不同环境和查询类型中处理各种空间和语义分辨率，无论是特定对象还是环境的整体描述。Embodied-RAG 的核心记忆结构是语义森林，存储不同详细程度的语言描述。这种分层结构使系统能够在不同的机器人平台上高效地生成对上下文敏感的输出。

他们证明，Embodied-RAG 能有效地将 RAG 与机器人领域衔接起来，成功地处理了 19 种环境中的 200 多项解释和导航查询，突出了它作为通用型非参数系统的前景。
