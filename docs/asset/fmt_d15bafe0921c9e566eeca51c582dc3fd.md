采集抖音短视频字段说明：

1. 支持抖音网页版筛选功能，包括排序、发布时间、视频时长、搜索范围、内容形式；
2. 支持的采集字段：账号昵称、账号粉丝数、视频链接、视频描述、视频标签、点赞数、收藏数、评论数、分享数、是否带货、发布时间、关键词。

关于多维表格里，短视频分类「低粉爆款」短视频的定义解释。可以根据自己的行业类目，做数值修改。非常灵活。

```
# 多维表格的短视频类型公式判断
IFS([点赞数]&lt;=300,&quot;⬜️低赞视频&quot;,AND([点赞数]&gt;300,[点赞数]&lt;=1000),&quot;🟧普通视频&quot;,[点赞数]&gt;500,IF([点赞粉丝比]&gt;3,&quot;🔥低粉爆款&quot;,&quot;🟥高赞视频&quot;))

---------------------------------------- 分割线 ---------------------------------------------
条件逻辑详解：
第一条件：低赞视频
如果 点赞数 ≤ 300 → 返回 ⬜️低赞视频。
含义：点赞数很低，属于低质量视频。

第二条件：普通视频
如果 300 &lt; 点赞数 ≤ 1000 → 返回 🟧普通视频。
含义：点赞数中等，属于普通质量视频。

第三条件：高赞或低粉爆款
如果 点赞数 &gt; 500 → 进入嵌套的 IF 判断：
若 点赞粉丝比 &gt; 3 → 返回 🔥低粉爆款。
否则（点赞粉丝比 ≤ 3）→ 返回 🟥高赞视频。

含义：
当点赞数很高（&gt;500）时，进一步考虑粉丝互动效率：
高互动效率​（点赞粉丝比 &gt; 3）：可能粉丝少但传播强，标记为🔥低粉爆款。
正常互动​（点赞粉丝比 ≤ 3）：标记为高质量🟥高赞视频。
```
