
# 20241017-揭密：AI大模型正悄悄改变中国职场！

> 来源：[https://aigcreative.feishu.cn/docx/I5CXdshi6obef2x1KSdcCOHVngC](https://aigcreative.feishu.cn/docx/I5CXdshi6obef2x1KSdcCOHVngC)

人工智能已经悄无声息地改变了我们的生活，而其背后的推动力之一便是大语言模型技术。

![](img/82ace9aa831e0de629caf6f79c5ecb20.png)

根据北京大学国家发展研究院与智联招聘的最新研究报告，大语言模型技术的崛起，正全面重塑中国劳动力市场，尤其是对一些特定职业带来了深远影响。让我们来看看这场变革是如何发生的！

## 大模型崛起：高薪岗位与技能需求飞速增长

2024年上半年，招聘市场上人工智能相关的岗位需求火爆，大语言模型相关岗位（如自然语言处理、深度学习等）招聘数量同比增长显著，翻了一倍还多。其中，自然语言处理岗位的招聘数量同比增长111%，深度学习岗位增长61%，机器人算法岗位增长76%，智能驾驶系统工程师岗位增长49%，导航算法岗位增长47%。

![](img/c78b2ac2fec1cb71f2793de0f75b11f0.png)

这些岗位的平均招聘月薪也相应上涨，自然语言处理岗位平均月薪达到了24007元，同比增长11%。深度学习岗位的薪资也接近26279元。相比之下，2023年上半年，自然语言处理岗位的平均月薪为21635元，深度学习岗位为25721元，薪资的增长幅度相当明显。

![](img/bcc08c384eee9bac2dea388ccee063ec.png)

显然，大模型技术作为未来的主流方向，吸引了企业和资本的高度关注。这些高薪资背后的原因在于对技能的严格要求——企业需要的不仅仅是会使用`Python`或`C++`等编程语言的人，还需要能够熟练掌握机器学习框架（如`PyTorch`、`TensorFlow`）和神经网络（如`CNN`、`DNN`、`RNN`）并具备丰富经验的人才。

![](img/5808fba7bd7ee258640ce809eef98428.png)

从技能要求来看，自然语言处理和深度学习岗位中，`Python`是最受欢迎的编程语言，而`PyTorch`、`TensorFlow`、`C/C++`、`Java`等技能紧随其后。此外，神经网络如`CNN`、`DNN`、`RNN`等也是这些岗位的必备技能。这些数据表明，具备这些技能的人才在市场上非常抢手。

## 编辑、翻译受冲击最大，研发岗位反而加快调整步伐

你以为只有程序员才和AI扯上关系？错！报告指出，编辑、翻译、客服等职业受到大语言模型影响最大，这些岗位的“大语言模型影响指数”明显高于其他职业。2024年，编辑/翻译岗位的影响指数达到了0.89，相比2022年上升了0.09。而研发岗位的招聘则相对快速地做出了调整，指数有所下降。这一现象的背后，其实反映了不同职业对技术革新的响应速度：研发岗位涉及的互联网行业本身就在技术前沿，对大语言模型技术的适应性自然更快。

![](img/a60c8a9ecc5f0225a2abfed40348714b.png)

有趣的是，大模型工具不仅改变了这些岗位的供需状况，还提升了招聘要求。编辑、客服等职业对本科及以上学历的要求普遍上升。

![](img/d86d1c3d2af8dee0ebfa7e27b5b56dd8.png)

例如，2024年上半年，编辑岗位中要求本科及以上学历的比例较2022年提高了4个百分点。销售、市场等岗位也在经验要求方面水涨船高，企业希望招聘到的员工不只是会做事，还要能善于利用AI工具来提高工作效率。

## 一线城市和中西部省会成为AI浪潮的先锋

从地域差异来看，一线城市和部分中西部省会城市的劳动力市场受大语言模型技术的影响最大。例如，北京、上海、深圳等城市凭借在人工智能技术上的雄厚基础，成为技术革新的排头兵。2024年上半年，北京市招聘的人工智能相关岗位数量占全国的19.1%，深圳和上海分别占10.0%和9.0%。这些城市在技术创新和人才供给方面具有明显的优势。

![](img/755003a639a15d71f1ff4fa8bde8c5e1.png)

![](img/ea0b355cd250c78e22872a00cab7ccc1.png)

而中西部城市如成都、西安等，由于经济结构中服务业占比较高，AI对其劳动力市场也有显著影响。例如，成都的“大语言模型影响指数”高于其“人工智能发展指数”排名，显示出该城市在服务业和运营中心方面承接了较多与大模型相关的工作岗位。

![](img/37112a0ce82ac63625cf9cf6ca825806.png)

显然，AI技术的发展正在重新定义劳动力市场。越是经济发达的城市，越是需要快速适应AI浪潮的冲击；越是依赖传统制造业的城市，可能面临相对滞后的风险。面对这一趋势，城市和企业必须积极采取措施，优化产业结构，推动技术创新，以确保在这场技术浪潮中占得一席之地。

## 未来的机会与挑战：你准备好了吗？

大模型的发展带来了诸多挑战，但它也创造了无数机遇。对于职场人来说，最好的应对方式就是不断学习，提升自身的技术能力，特别是熟练掌握AI工具和相关技术。而对于企业和城市来说，如何在技术革新中迅速适应、提升竞争力，是接下来发展的重中之重。

![](img/c915bd388ef0336870c1c85fc734903c.png)

AI不是终结者，而是推动者。在这场变革中，那些能与AI共舞的人，将会成为未来职场的赢家。那么，你准备好迎接这个大模型时代了吗？
