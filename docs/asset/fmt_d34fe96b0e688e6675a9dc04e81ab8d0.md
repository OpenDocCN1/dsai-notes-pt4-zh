+   演讲者介绍了一个基于两个轴优化法学硕士的框架：

+   *即时工程*：优化的起点。

+   *检索增强生成（RAG）*：用于上下文优化。

+   *微调*：用于 LLM 优化。

+   *以上所有*：结合所有技术。

+   策略：

+   介绍新信息。

+   最大限度地减少代币使用。

+   介绍新信息。
