
# 学会夸人

> https://m.okjike.com/originalPosts/646e093d9b85b0f294aae2e0?s=eyJ1IjoiNWM2M2I4YzQ2ZWEwOWYwMDBmMzk4ZWM3IiwiZCI6M30%3D

社会心理学中有一个效应叫[阿伦森效应]，即人们会越来越喜欢-那些对自己喜欢、赞美程度不断加深的人。

而这种[夸赞]就是表达对ta人喜欢的一种非常好的方式。

因为夸赞能让ta人感到：

- 自己是有价值的。
- 自己的优点是能被看见的。
- 自己的努力是值得肯定的。
- 自己是独特的，是有闪光点的。

可以想象一下，当你认真完成某件事但没有自信的时候，朋友突然跑过来跟你讲：”这件事情你完成的好出色！从排版、细节方面就能看出你的认真。”

在这一瞬间，你会发觉自己的快乐值冲上顶端，自己的努力被看到。

而你也会在夸奖中继续开启下一次的认真，循环往复，越来越好。

主动发出夸奖的人其实也会很开心！

其中的底层逻辑是：

被夸奖的人：夸奖 - 激发积极情绪 - 强化行为 - 持续被夸奖的行为。

夸奖的人：仔细观察 - 正向描述行为 - 激发积极情绪 - 强化行为。

具体怎么夸，用2个关键词来概括。

### 夸行为

从ta人所做的行为出发，仔细观察其中值得夸赞的地方。

如当妈妈做了一桌好吃的饭时，可以说”妈妈今天做的全都是我爱吃的！有一个会照顾人的妈妈我感到很幸福！”

### 夸细节

不要泛泛地夸（如有责任感），而是从具体事情的细节出发去夸。

如好朋友做了好看的美甲，就可以说：”你的美甲真好看，好配你的肤色，你真有眼光！知道自己适合什么颜色。“

所有夸赞的词语本质上【肯定的言语】，无论对朋友、家人亦或恋人，这种言语都特别特别重要！
