## 基于线程 ID 续接对话

当我们再次进行对话时，直接带入线程 ID，即可带入此前对话记忆：

### 传入线程 ID 再次调用 Agent

```
response = agent.invoke(
    {&quot;messages&quot;: [{&quot;role&quot;: &quot;user&quot;, &quot;content&quot;: &quot;你好，请问你还记得我叫什么名字么？&quot;}]},
    config
)
```
