## 1️⃣ Qwen2.5 VL！重要的模型说三遍！

> [Qwen2.5 VL！重要的模型说三遍！](https://mp.weixin.qq.com/s/qNyMpJZijmOfO8-uhThWpg)

+ Qwen2.5-VL是Qwen家族的最新视觉语言模型，具备识别物体、分析图像中文本和图表、理解长视频等能力。📌

+ 模型增强了视觉理解、代理性、视频理解、视觉定位和结构化输出功能，适用于金融和商业领域。🔮

+ Qwen2.5-VL支持动态分辨率和帧速率训练，优化了视觉编码器，提升了训练和推理速度。🚀

+ 提供了30亿、70亿和720亿参数的模型，开源代码和体验平台，方便开发者和用户使用和体验。🤖

+ 模型支持使用`transformers`库进行推理，也兼容魔搭`API-Inference`，便于直接调用。🔗

> 关键词：视觉语言模型，Qwen2.5-VL，图像理解，视频分析，结构化输出

## 2️⃣ 刚刚！DeepSeek 再发新模型Janus-Pro 7B，统一多模态理解与生成

> [刚刚！DeepSeek 再发新模型Janus-Pro 7B，统一多模态理解与生成](https://mp.weixin.qq.com/s/9ToRpZnEOfG82wnbBcF-Xg)

+ DeepSeek 团队发布了创新型多模态框架 Janus-Pro，能同时处理多模态理解和生成任务。

+ Janus-Pro 基于 `DeepSeek-LLM-1.5b-base`/`DeepSeek-LLM-7b-base` 构建，支持图像输入并使用特定 tokenizer 进行图像生成。

+ 该模型将视觉编码分为独立通道，同时保持单一 `transformer` 架构进行处理，提高了系统的灵活性。

+ 在 `GenEval` 和 `DPG-Bench` 基准测试中，Janus-Pro 的表现超越了统一模型，媲美专门的任务型模型。

+ 项目采用 MIT 许可证开源，开发者可通过 GitHub 和 Hugging Face 获取完整代码，有望成为下一代统一多模态模型的重要选择。

> 关键词：多模态框架，Janus-Pro，DeepSeek，图像生成，开源模型

## 3️⃣ 让大模型互联网「冲浪」，通义实验室WebWalker解锁复杂信息检索新技能

> [让大模型互联网「冲浪」，通义实验室WebWalker解锁复杂信息检索新技能](https://mp.weixin.qq.com/s/Y-yGC6sobN0WITMayKcfzg)

+ 通义实验室和东南大学合作，推出WebWalker，旨在解决复杂信息检索问题。

+ WebWalker通过模拟点击操作深入网页，挖掘深层信息，提高检索效率。

+ WebWalkerQA基准测试评估大模型在多步骤网页交互中的能力，覆盖教育、会议等领域。

+ WebWalker框架结合Explorer Agent和Critic Agent，优化大模型的网页导航和信息获取。

+ WebWalker与`RAG`系统结合，展现出在信息检索问答任务中的协同效果，提升性能。

> 关键词：WebWalker，信息检索，大模型，`RAG`系统，网页导航

## 4️⃣ 开源版Operator原生AI智能体来了？字节跳动开源UI-TARS模型

> [开源版Operator原生AI智能体来了？字节跳动开源UI-TARS模型](https://mp.weixin.qq.com/s/-sgoEFmjYI4anipkrmyS1A)

+ 字节跳动开源了UI-TARS模型，一个原生GUI智能体，具备GUI增强感知、统一动作建模、System 2推理和迭代式反思训练等创新点。

+ UI-TARS在多个基准测试中表现出色，特别是在AndroidWorld基准上任务成功率达到46.6%，超过GPT-4o。

+ 该模型通过端到端的方式学习和执行任务，将感知、推理、记忆和动作统一在一个模型中，展现了强大的泛化能力和自我改进能力。

+ UI-TARS集成了大规模数据集和高质量GUI教程，通过标注「思维」来增强模型的推理模拟，填补感知与动作之间的空白。

+ 模型支持在线轨迹bootstrapping、反思微调和`Agent DPO`等技术，使其能够在实际使用中不断迭代进步。

> 关键词：AI智能体，GUI交互，开源模型，基准测试，端到端学习
