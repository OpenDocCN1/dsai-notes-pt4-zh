### 4.2 批量问答

```
POST /qa/batch
```

**请求体**：

```
{
    "questions": [
        {"id": "q1", "question": "问题一"},
        {"id": "q2", "question": "问题二"}
    ],
    "options": {
        "parallel": true,
        "max_concurrent": 5
    }
}
```

**响应**：返回 `batch_id`，通过 `GET /qa/batch/{batch_id}` 轮询结果。

### 4.3 获取历史会话

```
GET /qa/sessions/{session_id}?page=1&page_size=20
```

**响应**：

```
                "answer": "...",
                "created_at": "..."
            }
        ]
    }

```

### 4.4 获取单条问答记录

```
GET /qa/records/{qa_id}
```

**响应**：返回完整的问答记录，包含 `sources` 和 `graph_path`。
