
# Installation 安装

> 来源：[https://kcn9ut4m7icc.feishu.cn/docx/UnljdTnwVoBXnRxCIEUcLI4Cn5b](https://kcn9ut4m7icc.feishu.cn/docx/UnljdTnwVoBXnRxCIEUcLI4Cn5b)

Learn how to install, set up, and use Cursor with AI features like Chat, Tab, and Composer

学习如何安装、设置和使用 Cursor，并利用其 AI 功能，如聊天、标签和作曲家

## Installation 安装

1. Visit [`cursor.com`](https://cursor.com/) and click the “Download” button

访问 `cursor.com` 并点击“下载”按钮

1. The installer for your operating system will automatically download

操作系统安装程序将自动下载

1. Run the installer and wait for installation to complete

运行安装程序，等待安装完成

1. Launch Cursor via the Desktop shortcut or from the Applications menu

启动 Cursor，可通过桌面快捷方式或从应用程序菜单进行

## Setting up 设置

On your first launch, you’ll be prompted to configure a few settings to ensure you get up and running quickly!

在您首次启动时，系统将提示您配置一些设置，以确保您能快速开始使用！

+ Keyboard shortcuts - If you are coming from a different editor, you can choose the default shortcuts you want to start with, so they are as familiar as possible.

键盘快捷键 - 如果您来自不同的编辑器，您可以选择您想要开始使用的默认快捷键，以便它们尽可能熟悉。

+ Language - If you want the AI to talk to you in a different language, you can enter the name of the language you want to use. This can be configured further in [Rules for AI](https://docs.cursor.com/context/rules-for-ai).

语言 - 如果您想让 AI 用不同的语言与您交谈，您可以输入您想要使用的语言名称。这可以在 AI 规则中进行进一步配置。

+ Codebase Indexing - Cursor indexes your codebase locally to provide better AI suggestions. Learn more in Codebase Indexing.

代码库索引 - Cursor 在本地索引您的代码库，以提供更好的 AI 建议。更多信息请参阅代码库索引。

+ CLI Shortcuts - You can choose to install `cursor` and `code` commands to launch Cursor from the terminal

CLI 快捷键 - 您可以选择安装 `cursor` 和 `code` 命令，从终端启动 Cursor

After configuring these settings, you’ll be prompted to import your VS Code settings. If you accept, this will import your extensions, themes, user settings, and keyboard shortcuts into Cursor, so you can get started right away.

配置这些设置后，系统将提示您导入 VS Code 设置。如果您同意，这将导入您的扩展、主题、用户设置和键盘快捷键到 Cursor 中，以便您可以立即开始使用。

Next, you’ll be asked about your data [preference](https://docs.cursor.com/account/privacy). Read more about them on our privacy page

接下来，您将需要选择数据偏好。更多关于这些信息，请参阅我们的隐私页面

If you ever need, you can trigger this view by launching `cursor` with the terminal like this

如果您需要，可以通过在终端中启动 `cursor` 来触发此视图，如下所示：

Copy 复制

```
cursor --user-data-dir=/some/new/path
```

## Logging In 登录

1. Once you click “Sign Up” or “Login”, you’ll be prompted to setup an account. You can choose to use your email, or sign up with Google or GitHub.

一旦您点击“注册”或“登录”，系统将提示您设置账户。您可以选择使用您的电子邮件地址，或者使用 Google 或 GitHub 进行注册。

1. Once signed in, you’ll be sent back to Cursor and you’ll be ready to start coding!

一旦登录，您将被送回 Cursor，并准备好开始编码！

If you’re using Cursor for the first time, you’ll get a 14-day free [trial](https://cursor.com/features) of Cursor Pro as soon as you sign up. Learn more about Cursor Pro on our website.

如果您是首次使用 Cursor，您将在注册后立即获得 Cursor Pro 14 天的免费试用。在我们的网站上了解更多关于 Cursor Pro 的信息。

## Additional settings 附加设置

Cursor is designed to be flexible and customizable, so you can configure it to your liking. You can access all of your settings by:

Cursor 设计得灵活且可定制，因此您可以将其配置成您喜欢的样子。您可以通过以下方式访问所有设置：

### Cursor settings 设置

+ Access via gear icon, `Cmd/Ctrl + Shift + J`, or Command Palette > Cursor Settings

通过齿轮图标访问，`Cmd/Ctrl + Shift + J`，或命令面板 > Cursor Settings

+ Configure AI features and Cursor-specific preferences

配置 AI 功能和 Cursor 特定首选项

### Editor settings 编辑设置

+ Access via Command Palette (`Cmd/Ctrl + Shift + P`) > `Preferences: Open Settings (UI)`

通过命令面板访问（`Cmd/Ctrl + Shift + P`）> `Preferences: Open Settings (UI)`

+ Adjust editor behavior and appearance

调整编辑器行为和外观
