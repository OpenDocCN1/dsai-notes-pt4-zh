
确定了达人合作名单之后，就要跟达人友好的商量发布档期，发布内容类型，以及品牌的内容要求等等。内容感强一些的，可以直接跟博主指定需要什么样的内容，让博主去完成即可（我们一般是这么操作）。内容感不强的，就跟博主扔一个品牌合作BF，确定一个大致的内容方向，剩下的让博主自己发挥创意。

## 4.1 品牌BF的创建和编辑

BF全称是brief，简单来说，里面写的就是对博主发文的一些基本要求。我给大家列一个品牌的BF，大家可以参考

![](img/044337337e6b528c37b4b3fa45f41c11.png)

[某品牌冰箱合作Brief.pdf](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/Dv7ObtQY3oEQ4FxCo9EcrqNxn4e)

给了模版，我相信大家也会套用了，这里主要是再强调一下我觉得必须要写的：

+ 品牌文化，品牌故事，让达人深度了解品牌

+ 产品的卖点和优势

+ 希望的内容方向

+ 拍摄要点和注意事项

+ 必带话题

## 4.2 三类📕最受欢迎的种草笔记类型

我相信很多人找了达人之后，不知道应该让他们写什么。你只能相信那个达人的网感，但达人的内容感觉其实是不可控的，尤其是如果我们找价格低，粉丝量也比较少的达人的时候。这里分享一下，在我看来📕种草效率最高的三种笔记类型：

### 4.2.1 测评种草类型

![](img/80af2cebf021b2ef121b4a93724935ad.png)

![](img/5eadd6853c6ef76807ac8b4fe1b91706.png)

![](img/5542180e6241ad0c530fbf6ce3b60666.png)

测评可以是单测，也可以是多品测评。面向的用户其实是真正想要买这类产品的核心目标用户。真想买的，才会花时间去看测评。小预算的小伙伴，可以着重打这个内容类型！

**测评文案模版：**

1. 多品测评的，给出多品测评原因，如产品痛点、价格痛点等

2. 对多款产品进行比较分析，然后给出用户有用的参考意见

3. 可以从多维度测评产品：比如产品的功能、产品成分、产品外包装、产品适用人群、产品的使用说明、产品属性、产品外观、使用效果、使用的感受以及价格方面等去分析测评

4. 分享自己的看法和安利产品，综合测评结果，发表一下自己的看法。

**这里有一个过审关键点：**不要说别的产品多不好，而是要说自己的产品有多好，不说别人家的缺点，说自己家的优点！

### 4.2.2 好物种草类型

![](img/045247973a330f4d7ccb3c0a250e91d2.png)

![](img/3b73efb10a5ff183b534128091502b68.png)

这种笔记在📕还是很常见的，直接说痛点和推荐。也是最难火和最难做的，因为很容易过渡，就做成硬广。但是这种笔记也是必不可少的，有利于我们的种草转化！好物种草文案模版：

1. 自身痛点：从第一人称视角出发，搭建真实生活场景，讲述自己的痛点，问题。这个痛点抓取很关键，他是用来圈人群的。

2. 解决方案引：有了痛点之后，我是怎么做的，用了什么方法，自然而然的引入某款产品

3. 产品卖点：引出产品了，就要好好介绍一下产品的卖点了。从产品本身特点出发来分析，语言要生动有趣，写的更真实具体一点。多一些发自内心的阐述，更能吸引到用户

4. 结尾总结。结果可以真实的告诉大家这款好物是真实亲测有效的，甚至可以不当下转化，就说用2个礼拜后给反馈，让大家蹲蹲蹲。（两个礼拜后，再去投流这个笔记，可信度很高）

### 4.2.3 教程种草类型（干货）

![](img/d7223ad412ee1fe4ac088e3e32fe0a3d.png)

![](img/c90be1526b852f1fb1283fa7bb0ce308.png)

教程类型的，就是先告诉你这个东西怎么解决，如何祛痘？空调怎么买？去西安旅行怎么订酒店？顺势可以引出祛痘产品、美的空调以及XX酒店之类的。比较适合那些喜欢自己找答案人群，也是核心用户。教程种草文案模版：

1. 首先是标题引入痛点，再告诉你我有多少种解决方案，吸引那些被痛点困扰的人

2. 输出正确的方法和经验总结。可以是讲自己遇到的困难，走过的弯路，然后今天总结自己的新得体验，总结了16条，条条干货。这里需要输出真正的干货内容

3. 产品推荐环节，输出完干货，就到了产品推荐环节了，这里适当的引入产品，说是自用，或者用了多少年了，讲一下产品的一些细节，使用体验，适用人群，注意事项等等。

这里的核心还是不能太广，还是分享贴，只是以教程的方式开头吸引用户。

## 4.3 种草内容的评论区打造

种草的内容，尤其是投流的内容，评论区打造是至关重要的。甚至有些评论，是必须出现在评论区的。

我按照优先级排列，给大家依次罗列一下：

| 评论功能 | 评论示例 |
| --- | --- |
| 引导用户，让用户知道购买渠道 | 1. 哪里买的？，某宝搜XXX即可 |
| 解决用户对产品的直接疑问 | 1. "这款精华需要早晚都用吗？" → 回复："早晚各用一次效果更好，搭配按摩手法吸收更快哦 |
| 对比型素人评论 | 1. "博主咱俩买的一样！XX比某大牌精华好用多了！价格才三分之一" |
| 互动型素人评论 | 看了博主的帖子我买了，姐妹们等我反馈！（后面一排蹲蹲蹲，过两天再来回复效果，会比较好） |
| 素人好评型 | 1. "感谢博主救我烂脸！现在男朋友都夸皮肤好 |
| 场景型评论 | 核心是产品其他的使用场景，笔记里没提到的。 |
| 负面处理型 | 可以有意识的弄点负面评论，这个负面，一定不能是产品的主要卖点，而是次要卖点，甚至是可有可无的卖点、或者说是反向夸的。 |

结合自己的产品进行有效真实的评论布局。重度投流的笔记，这几个评论最好都上上去，能增加转化效果。

# 五、📕品牌投放策略

## 5.1 品牌投放各个阶段的预算分配

其实很简单，核心的逻辑是，没有优质内容时，就把预算往达人侧偏移。有优质内容时，预算往投流侧偏移。但是两者都不能停。

| 投放阶段 | 阶段目标 | 预算分配 |
| --- | --- | --- |
| 内容摸索期 | 探索适合自己产品的内容方向 | KOL：70% |
| 爆文打造期 | 内容摸索完之后，接下来就是根据摸索打造爆文 | KOL：50% |
| 声量放大期 | 持续打造爆文，累计声量，进行用户心智占领 | KOL：40% |
| 日常运营期 | 这个时候，我们已经有了一定数量的爆文笔记。 | KOL：20% |
| 产品破圈期 | 日常运营的时候，如果能稳定，其实已经能吃到一定的用户了。 | KOL：40% |

## 5.2 如何评价种草效果？

我们内容也产出了，广告也投了，那如何判定我们的效果好坏呢？最直观的其实是销售额，我合作的品牌，是只在📕做推广，站内直通车什么都没有，所以，默认所有的销售额都来自📕，这种情况下，我们只要看站内提供的数据即可。

当然，也需要看📕内部的数据，并且如果品牌不只是在📕投放，那📕的投放数据也是必须要参考的。📕种草的营销方式存在已久，业内也有很成熟的评价方案。非原创，只是照搬了一些术语，供大家参考

**1、点击表现**

| 量化指标 | 定义 | 计算公式 | 举例 |
| --- | --- | --- | --- |
| CPM | 千次曝光成本(Cost permile)指广告主为获取1000次广告展示次数所需要支付的费用 | CPM | 某品牌在📕信息流投放共花费了1000元，获得了10000次展示，这意味着，该品牌需要花费100元才能获得1000次广告展示 |
| CPC | 点击成本(Cost per click)指广告主为获取一个广告，点击所支付的费用 | CPC | 某品牌打造一篇爆文花费了1000元，共获得了2000次点击那么该品牌需要花费0.5元才能获得一次广告点击 |
| CTR | 点击率(Click through rate)指广告点击次数占广告曝光次数的比率 | 广告点击次数/曝光量 | 某品牌在📕信息流投放了一篇笔记内容共获得10000次展示，其中有500人点击那么该笔记的点击率有5%每获得100次展示，就会获得5次用户点击 |

**2、互动表现**

| 量化指标 | 定义 | 计算公式 | 举例 |
| --- | --- | --- | --- |
| CPE | 每次用户参与的成本（Cost per engagement） | CPE | 假设某品牌在广告投放期间共花费了1000元，其中用户参与点赞评论等互动行为共500次，那么该品牌需要花费2元才能获得一次用户参与的行为 |
| CVR | 转化率(Conversion rate)📕广告投放中CVR是指广告为实现目标转化所付出的成本 | CVR | 假设某品牌在📕上投放了一条广告，其中100人进入了商品详情页，最终有10人完成了购买那么转化率为10% |

分享下我们的数据，可以给大家一个参考：

+ CPM（千次曝光成本） = 20.15

+ CPC（点击成本）= 0.15

+ CTR（点击率）=13.5%

+ CPE（互动成本）=1.35

数据截止于25年3月15日，是自然流+投放一起的数据总和。如果是投流的数据的话，我们的CPE（互动成本）在2-3之间。

如果品牌是淘宝店铺的话，其实📕是有小红星项目的，能精确定位到每篇看过📕笔记的用户的进店、关注、加购、成交等信息。就能更加量化投放效果。

## 5.3 📕种草笔记聚光投放相关问题

关于如何投放，其实写起来也是很大的一个篇幅。聚光计划如何键？关键词如何投放等等...可以看一下赚钱有关📕聚光投放的教程，我感觉大差不大，就不在这里浪费笔墨和篇幅。着重讲一下碰到的一些情况和处理方法。

### 5.3.1 素材投不出去，如何优化？

1. 开放定向，增加人群或者搜索词

2. 检查内容问题

检查封面和标题是否用户感兴趣？优化素材（封面+标题）反复测试，检查搜索词是否与素材匹配。

### 5.3.2 素材互动成本高如何优化？

1. 降低互动单价。有时候单价降低，也不妨碍曝光和互动

2. 优化素材正文，观察效果

3. 评论区维护，评论区没做好也会导致互动成本高。

### 5.3.3 投流后店铺数据没涨，如何优化？

1. 维护评论区，大概率是评论区没有做到位，导致的种草效果差

2. 笔记素材不精准导致的用户人群不精准，不是核心目标用户，种草效果会差。需要调整素材重新投放

3. 很多产品没办法当下转化，需要等一段时间。这个看产品定。

# 六、与品牌的合作方式

像这种📕种草的营销方式，如何与品牌进行合作？我们其实跑的也不是很成熟，我就列一下可能的一个合作方式。

1. **联营合作**

   联营合作的意思是，成立一个新品牌，或者直接在原有品牌上进行合作。但是收益不区分是否是从📕来的，我们直接从总的GMV中去分成。这是目前我们的合作方式。具体分成比例多少，看行业，以及看你们的执行细节。比如是否需求投流，营销费用谁出等问题。每个行业都不同，具体数字我就不说了，对大家也没有参考价值

2. **品牌📕种草全案+执行**

   负责品牌在📕的全部营销方案，并执行到位。具体细节和品牌商量着定，比如需要多少篇种草笔记，测评笔记，自然流量曝光需要多少，投流ROI需要做到多少。可以一口价，也可以签对赌协议。部分mcn是用这种合作方式在跑。

# 七、如何找品牌以及普通人如何入局？

像我们的品牌或者商家，都是我们做自媒体博主矩阵的时候，积累下来的，认识一些品牌方，也有一些成功的合作，所以他们信任我们，愿意跟我们合作。

但这毕竟是被动的，如何主动的去找品牌？

其实方法有很多，但是我正在做的，并且我唯一推荐的，只有一种：在📕搭建自己的商业IP，通过自己的专业和内容，去吸引品牌。我给自己设计的产品是社群+陪跑+📕营销种草。

+ 📕课程+社群：价格很低199-365，属于付费门槛

+ 陪跑定位高客单：适合那些我做商业IP吸引过来，但是不知道怎么做📕，想学习的人

+ 📕营销种草：就适合想入局📕的品牌方，跟他们进行联营或者全案合作。

这是我们目前正在做的，但是还没做出多少成绩。日后做出成绩了再来分享~

# 八、项目的一些特别说明

别看我们花三个月时间，营销费用才每月1-2w，就能做到单日最高4w，月销售80w的业绩，他是有原因的。并不是来一个品牌就能这么操作的。

1. 本身品牌在📕上有一定的积累，人家之前也自己出过爆款

2. 产品足够给力，质量不差的情况下，价格在市面上是比较有竞争力的

3. 客单价比较高，又属于刚需产品

我总结的三者，其实缺一不可。这三个客观因素外，才是我讲的那些方法论和实操经验。千万不要忽略客观因素就盲目实操，每个类目，每个产品都不一样。
