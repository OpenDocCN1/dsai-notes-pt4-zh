# 三、风向标心得总结

掌柜很喜欢研究风向标，是因为我觉得能够在这个过程验证自己的商业思考，锻炼产品、流量、运营、转化等多方面的能力。和大家分享下我的部分思考：

## 1、风向标平台很多，重点是掌握方法，并且要聚焦

本文分享的多数是📕如何寻找风向标，那么对于👸号、抖音、快手、视频号、🧣、推特、X平台等，道理都是相通的，第一性原理和迁移能力任何时刻都要搬出来，用它！

而且我建议重点聚焦，不知道大家发现没？掌柜在赚钱发的所有风向标中，几乎全是📕平台，是因为我知道自己的时间精力有限，在一个平台充分挖掘，才可能中标更多，而且从创作者的角度看，他们也会“一鱼多吃”，也就是在其他平台，说不定刷到的也是这个博主。

同时，在所有的📕风向标中，AI+📕赛道是我重点聚焦的赛道，我一直坚信，做任何项目都应该垂直化+聚焦化，子弹击中打，才有穿透力！

再谈下各平台的超级标，我觉得所有的平台未来都会走向细分垂直化，这是方法，也是趋势，比如：👸号（垂直小号）、📕（垂直小号）、抖音（垂直小号）、知乎（垂直小号），其实你会发现，自媒体发展的逻辑本就是：让普通人和小IP更容易被看到，很多商业模式都在一点点地打破重构。

**再迁移一下，放到你自己的项目上，你也需要做垂直，记住：世界也许是个草台班子，但我们不能是！**

## 2、客户的注意力在哪，你的生意就在哪，钱就在哪

当下大家的注意力，早已从传统的线下转移到了线上。一个成年人，每天大部分的自由时间，都花在了手机上。如果她是女生，那么很大程度上在📕，女性的消费力量远高于其他人，这就是为啥很多人选择📕变现的原因。

对于想快速跑通闭环的人来说，📕是不错的试水平台；

对于想做女性用户生意的人来说，📕有非常垂直的方向；

对于想做高客单价的主理人来说，📕有天然的筛选机制；

## 3、📕每一种变现方式的背后，都是一套体系

在📕，能做到万粉以上的博主，常常会通过接广告、直播带货、笔记带货，无货源电商、知识付费等方式，进行变现。

选择[任意一种](https://zhida.zhihu.com/search?content_id=709059515&content_type=Answer&match_order=1&q=%E4%B9%B0%E6%89%8B%E7%94%B5%E5%95%86&zhida_source=entity)变现方式，你都可以获得不错的副业来源。2023 年，📕将“电商”、“直播”业务合二为一，组建交易部。和淘宝的“货架电商”、抖音的“兴趣电商”不同，📕的电商叫做“买手电商”。

如今📕已经入局了团购、本地商业化，有非常多的IP博主和小商家出现，做个人IP本质，就是经营信任。他们通过做轻资产投入的自媒体运营，把生意盘活，把超级个体模式跑通。

如果你也能掌握搭建这些商业体系的方法，如果你把我上面讲到的所有锦囊，📕平台所有的变现方式研究一遍，那么我相信你离财富不远了。所以自媒体是风口，是趋势，我们普通人就应该多关注，多参与，多实战，才有可能拿到结果！也才能利用好像📕这样的平台，变现不少。

## 4、人生发财靠机会，东方不亮西方亮

2000 年要买房、2008 年要做电商、2013 年要做👸号、2018 年要做抖音。这些风口，只要你能抓住一个，就起飞了。当下也是如此，如果你在📕上发现了一个不错的项目，对于新手可以快速0-1跑通，对于高手可以思考如何1-N放大。

无论是小财还是大财，都需要你的能力匹配上对应的机会，为了寻找这样的机会，我们才会研究风向标，而且研究过程中，说不定你会遇到志同道合的伙伴，最终的变现路径，也许不是中标、不是实操项目，而是和你的合伙人开公司，搭盘子，开启人生的无限可能～

此时变成了：东方不亮西方亮，无心插柳柳成荫，未来那么远，谁能说得准呢，哈哈哈～
