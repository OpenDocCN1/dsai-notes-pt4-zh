## b）注意事项

**注意：**

1. 思维导图要列清楚该模块要实现的功能，细化到每个流程细节。

2. `指令`架构里面不需要太多细节，要简单清晰明了为主，细节可以在模块的评论里面写。

3. 在落地写指令的时候要严格规范缩进来让系统识别成绩

4. 符号的用法一定不要搞混。[`这是功能/函数`]、<`这是变量或调用`>、`**这是粗体**`、`*这是斜体*`、

你们说，我这种用思维导图+指令架构图去写指令的方法，是降低了指令门槛还是拉高了指令天花板🤣
