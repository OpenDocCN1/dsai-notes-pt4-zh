## AI行业发展迅猛人才紧缺

过去一年，人工智能产业浪潮席卷全球，《中国互联网发展报告（2024）》指出，截至2023年12月，我国人工智能核心产业规模达5784亿元，同比增长18%；从企业数量来看，截至2024年7月，我国AI企业数量超过4500家，产业竞争力持续增强。

《新一代人工智能发展规划》中提到，预计到2030年，中国人工智能核心产业规模将超过1万亿元人民币，带动相关产业规模超过10万亿元，成为全球主要的AI创新中心。

![](img/5b4c37252c738e0dbe32ed071d67ec23.png)

从2024年开春，到2024年年中第二季度招聘情况来看，AI行业招聘需求持续增长，人才紧缺，将会是自移动互联网后新的一波时代浪潮！

![](img/ee8ca3de1a3bef9a113903d5d1719784.png)

![](img/558c6b372b8bddf779177b4d5799e3a5.png)

目前，AI行业的共识就是：AI产品经理特别紧缺，大小公司都缺。我最近和字节，腾讯，百度的资深AI产品沟通，他们都反馈：在大量为新项目招人，只要有AIGC项目经验，学历别太差就能拿到面试机会。

![](img/3f46241727e9e07317c79875428352e9.png)

在AI领域，尤其是现在最火热的AIGC领域，招聘量最大的就是两类岗位，分别是研发类和产品类，可以看到热招岗位排名靠前的5个岗位中有4个是研发岗位，1个是产品岗位。

这两类岗位的薪资也是最丰厚的，建议大家求职这两类岗位，其中与算法相关岗位对技术要求很高，入职门槛自然也高，AI产品经理作为非技术岗，行业需求大的同时薪资水平与其他非技术职位相比非常具有竞争力。

## 关于课程的常见问题

### 上课的方式以及提供哪些服务

+ 报名之后，老师会了解你的职业履历，教育背景，求职意向，根据每个人的实际情况提供针对性的学习意见，确保每个人都能学会课程。

+ **如果是对生成式AI了解不深的同学**，免费赠送价值899元的涵盖ChatGPT，Midjourney，Stable Diffusion产品的AI课程，深度讲解大语言模型原理，diffusion模型原理，热门AI产品发展现状，使用技巧，产品设计思路等等

+ 课程会深度讲解**机器学习**（K邻近算法，线性回归，逻辑回归，朴素贝叶斯，支持向量机，K-means聚类算法）深度学习（卷积神经网络，循环神经网络，AI绘画），大模型技术，AI产品项目管理等，所以就算没有算法基础或项目管理经验的小伙伴也不用担心。

![](img/d0f973267cdaf1060d1b3a8ca4db4379.png)

在学习的过程中，遇到没弄懂的概念或原理都可以记录下来，在答疑课上提交给老师统一回答。这样确保大家能掌握AI产品经理必备的算法模型问题。

+ 结合每个人的背景会**带做2-3个AI产品项目**，并辅导包装润色到个人简历中

> 如：AIGC提效项目，从竞品分析到原型图，PRD文档撰写，模型训练数据，产品评审全流程带学。

均为实战项目，每个项目都有对应的方法论，最终产出可落地的模型以及项目作品集。

![](img/fea215b75e262006323c53a1fcb5a3e3.png)

+ 一对一修改简历和模拟面试，为每一位学生提供一对一简历修改，面试辅导，模拟面试，无需额外付费

+ **一对一带学群**，多位老师在线及时回复学生在学习过程遇到的问题，有问必答

+ 直播课时间为每周两到三次，具体上课时间，根据大家方便的时间来定，上课时间基本为晚上和周末，每两周专门设立答疑课，可与其他老师同学一同交流疑问，直播时间有事无法参与的可以通过录播回看学习，不会耽误学习进度1.8小班制，基本每月一期，每一期学员20~30人，每期四个老师，两个助理带一个班，小班制老师面向的学员更少，有充分的时间和精力回答各位学员的问题，学习氛围也更好。

### 课程周期

+ 整个课程持续三个月，三个月的持续直播课学习，再加三个月陪跑带学。

+ 节奏快点的小伙伴，可以提前把往期学员的录播课提前开给大家，然后学习过程中，不会的随时带学群学习，也可以同步跟班学习，这样时间把控在一个月左右时间转行成功

+ 课程都在晚上或周末开始，方便大家下班在空闲之余学习

### 非计算机专业的，算法会不会太难学了

首先我们求职的是AI产品经理，非研发岗位，不会像算法工程师那种岗位对于算法的要求那么高。AI产品经理需要重点掌握的是：常见算法的实现原理，应用场景，优缺点

**只需要知道在什么业务场景下，使用什么技术框架，解决什么问题，实现什么样的效果即可**

和算法工程师交流同频，工作时降低沟通成本，更高效的完成任务。

这些内容都会在课程中教给大家，保证入职之后可以马上开始工作，不会受制于算法听不懂，而出现无法正常工作的情况。

**所以，不用担心算法原理问题**
