
# 常用命令

| `/prefer option set` | 创建自定义变量，最多可设置20个自定义变量（只支持参数，例如：使用`--xphoto`代替`--hd --ar 7:4`） |
| `/prefer option list` | 列出所有设置的变量 |
| `/blend` | 将两个图像中的元素混合在一张中 |
| `/show number` | 使用任务ID生成原图 |

## 否定用法

`--no` 加你不想要的所有东西。
