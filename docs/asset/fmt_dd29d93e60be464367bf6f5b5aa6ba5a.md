## ✏️课代表✏️

- AI 模型的回答能力受限于其背景知识的范围，通过外部知识库的辅助，可以显著提升回答的准确性和相关性。
- 知识库的搭建方式多样，既可以手动输入知识点，也可以导入现有文档或同步网站数据，以适应不同的需求和场景。
- 应用的配置灵活，用户可以根据需要选择 AI 模型、调整回复参数，并且可以关联一个或多个知识库，以提供更加精准的信息。
- 问题优化和搜索模式的设置对检索结果的质量至关重要，可以通过调整相关度阈值和优化问题来提高命中率。
- FastGPT 支持 API 集成，使其能够轻松融入到现有的业务流程和系统中，提高了系统的可扩展性和灵活性。
- 高级编排功能使得用户可以自定义应用的工作流程，实现更加复杂的问题分类、处理和数据交互。
