## 六、理解生成模型的工作原理

要更好地使用 Gemini 3，理解其文本生成机制至关重要。

### 6.1 两阶段生成过程

这个过程是确定性的——相同输入总会产生相同的分布。

生成式模型的文本生成分为两个阶段：

#### 第一阶段：概率分布生成（确定性）

当你输入提示`"The dog jumped over the ..."`时，模型会生成后续词元的概率分布：

`[("fence", 0.77), ("ledge", 0.12), ("blanket", 0.03), ...]`

这个过程是确定性的——相同输入总会产生相同的分布。

#### 第二阶段：解码（可选随机性）

模型将概率分布转换为实际文本。简单策略是选择最可能的词元（确定性），但也可以通过采样引入随机性。

### 6.2 温度参数

温度控制解码过程中的随机程度：

+   `温度 = 0`：仅选择最可能的词元，完全确定性

+   `温度 > 0`：引入随机性，数值越高越不可预测

+   Gemini 3 推荐：保持默认温度 1.0，避免意外结果

## 七、实践建议与注意事项

### 7.1 根据任务复杂度调整提示词

+   简单任务：使用基础结构化模板，避免过度工程化

+   中等复杂度：添加规划和验证步骤

+   高复杂度/智能体：使用完整的智能体系统指令

### 7.2 迭代优化

提示词工程是一个迭代过程：

1.  从简单模板开始

2.  测试并观察输出

3.  根据结果调整结构和指令

4.  逐步添加约束和验证步骤

### 7.3 多模态应用

当处理图片、音频或视频时：

+   确保文本指令清晰引用每种模态

+   使用统一的结构处理不同类型的输入

+   明确说明期望的分析维度
