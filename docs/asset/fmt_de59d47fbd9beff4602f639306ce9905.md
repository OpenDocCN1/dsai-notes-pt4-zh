
# 三方账户登录后再要求收集手机的合规性

> 来源：[https://docs.feishu.cn/docx/LGvidfeNDoFDA5xdqc3cg8Kdnyf](https://docs.feishu.cn/docx/LGvidfeNDoFDA5xdqc3cg8Kdnyf)

- **问：**请教大家，App使用第三方账号登录后，再要求提供手机号码的注册流程，属于未经用户同意强制收集信息行为，这个评估的依据来源是哪里呀？

- **答1：**1.这流程有无收集主体的隐私政策确认；2.第三方账号登录后实名制已经完成，没有必要场景不需要手机号码；3.在输入手机号码位置是否可被跳过。如果无法跳过，必须输入，也属于强制收集。

- **答2：**我以为是违反必要原则，结果认定未经同意收。看了下几个大平台，有强制提供手机号的，也有不强制但设置了这一步。我还以为变成得二选一的实名义务，找了半天没看到检测的依据来源。但划到了“未经同意收集”这项里行为里。

- **答3：**你为什么要手机号，什么时候要，也不一样。比如游戏绑手机号，送钻石违规，实名认证就合规。

- **答4：**那还是要看app类型和功能，是否必要增加二次强实名，不必要的话，用户选择第三方视为已完成后台实名义务。

- **答5：**做Oauth不是必须需要手机号的，而是看你这个平台本身收集手机号的必要性。三方登录都是Oauth。可以看看这篇：https://www.ruanyifeng.com/blog/2019/04/oauth_design.html。技术上，手机号不是必须有的。看你App种类，是不是一定要收集这个手机号。如果不是必须的，那就超范围。

- **答6：**我理解违反了必要性原则，收集行为没有在必要场景下申请。《App违法违规认定方法》“以欺诈、诱骗等不正当方式误导用户同意收集个人信息，如故意欺瞒、掩饰收集使用个人信息的真实目的”属于未经用户同意收集使用个人信息，这里的收集目的原本是为了留存自有用户信息，但以实名认证作为掩饰。不过这种操作是否属于“掩饰”的范围还有些勉强和存疑。

- **答7：**监管可能会认为是违反必要性原则，可以尝试用《互联网用户账号信息管理规定》的实名认证要求，结合41391认定的本产品APP类型及需要收集的个人信息（即必要性），去综合判断和回应监管（如果监管提出这个问题）。
