这不是讲大道理的栏目，而是想做一件很具体的事：去找到那些已经通过 AI 真正赚到钱的人，把他们的故事拆开讲出来，给还在观望的普通打工人，提供一些可参考的样本。

一边，是「万象 AI 实验室」里那群已经把 AI 用到副业、内容创作、本职工作的朋友；另一边，是脉脉上越来越多对「AI + 职场」「AI 副业」好奇的职场人。

「脉向 AI」就站在这两拨人中间——我们会持续邀请已经用 AI 赚到钱的创作者 / 开发者，聊聊他们是怎么起步、踩过什么坑、赚到第一笔钱之后又怎么走下去的。

首期，我们把镜头对准很多 Python 同学都很熟悉的一个名字：程序员晚枫。

## 本期嘉宾：程序员晚枫，用 Python 把时间变成“房贷级”现金流

程序员晚枫的履历，很容易让人记住：

+ 本科读法学，后来转行成了 C++ 程序员；
+ 业余时间写了一个自动化办公开源库 `python-office`，主打“一行代码搞定大部分办公自动化”；
+ 再围绕这个库，做社群、录课程、写教程，在各个平台开了几十个账号。

更重要的是，他把这一整套东西，真的跑成了一条“房贷级”的第二收入线在公开复盘里，他写得很直接：自媒体和开源项目赚到的钱，买过车、买过房，还在很长一段时间里承担了每个月的房贷和日常生活费。

如果只看今天的结果，很容易觉得这是“少数人的天赋故事”。但把时间线拉长，你会发现：这条路其实是他一点一点、从一个个小脚本“抠”出来的。

## 副业线是怎么长出来的？

刚工作那几年，晚枫的日常和大多数打工人一样：白天沉在 Excel、Word、各种业务系统里做重复操作——改模板、合并表格、录发票、整理报表；下班时脑子已经被这些细碎的流程耗得差不多了。

“工作不算难，就是纯粹消耗人。”他后来这样形容那段时间。

某天，他冒出一个念头：“既然这些步骤都能写成规则，那为什么不让电脑自己干？”

于是，他开始自学 Python。最早写的，都是给自己用的小工具：

+ 有的专门用来合并一整个月的 Excel；
+ 有的负责批量改名、整理文件夹；
+ 还有做发票识别、对账的小脚本。

脚本越写越多，他干脆把常用能力抽出来，整理成一个库，起名 `python-office`。

这个库从 2022 年发布到现在，已经迭代了四十多个版本；到 2024 年底，累计下载量超过二十多万次，在 GitCode 上拿到 G-Star 毕业项目推荐。

![](img/8654adb5cf0f53cfe3b77ca95abb297d.png)

![](img/9582c7136e798a86ad4dde6377573ef4.png)

有了这个“工具底座”，他顺势往外延伸：

+ 录一整套自动化办公课程；
+ 在 B 站、👸号、知乎、视频号等平台开了几十个账号，分享 Python + 自动化办公的案例；
+ 搭了两个个人网站，把教程和案例系统化沉淀下来。

在一篇复盘里，他第一次系统地算了一笔账：靠程序员主业 + 自媒体副业，他在重庆买了房和车；后来，仅靠自媒体收入就足以覆盖房贷车贷。

如果用一张简单的路径图来概括他的这几年，大概是：重复劳动 → 写脚本给自己省时间 → 抽象成工具 → 围绕工具做内容和课程 → 发展成稳定的副业收入线。

这就是一个非常典型、也非常朴素的“万象 AI”路径。

## 普通打工人怎么起步？

## 先别想“大产品”，先拿回时间

很多人看到晚枫的故事，第一反应都是：“我不会写太多代码，还来得及吗？”

他的答案一直很务实：先别想做产品，先学会用 AI 和自动化，把时间从重复劳动里抢回来。

他给普通上班族总结了三类最适合入手的场景：

1）把“批量活”交给脚本

凡是需要成百上千次重复点击的任务，基本都值得被改造一次：

+ 合并几十上百个 Excel；
+ 批量转换、加水印、拆分 PDF；
+ 录入发票、对账、清洗数据。

这些工作几乎不需要创造力，本质上是“机械执行规则”，非常适合交给脚本来做。

如果你完全不会写代码，可以先从“抄作业”开始：用现成的 `python-office` 之类的工具，照着文档和示例改参数、改路径。

当你第一次把一整周的加班量压缩到几分钟脚本执行时，你会非常直观地感受到——时间可以被放大。

2）把“憋稿子”变成“提要求”

周报、复盘、邮件，是很多人最焦虑的一块。晚枫现在处理这些事情，基本遵循三步：

+ 把要点列成条目，丢给大模型（比如 DeepSeek），让 AI 先起草一版；
+ 自己专注于“改语气、补细节”，而不是从零开始码字；
+ 用小脚本统一格式、插入固定模板，一次生成多个版本发给不同对象。

整个过程中，你的角色，从“苦哈哈憋稿的人”，变成了“给 AI 下指令、做终审的人”。

3）把“碎任务”和 FAQ 自动化

还有一类工作，不难但特别磨人：

+ 每天早上要打开好几个系统看数据，再手动拼成一份“今日要点”；
+ 同事和业务方反复问：“模板在哪？”“流程怎么走？”“制度在哪看？”

这些完全可以交给自动化去做：

+ 写一个定时任务，自动抓数据、做简单统计，再发一封摘要邮件给你；
+ 搭一个简单的“内网 FAQ 机器人”，把高频问题收集起来，用问答的形式统一回复。

晚枫的建议是：如果你能做到“每周用 AI + 自动化干掉一件最烦的重复活”，你的生活节奏会明显不一样。

一天省出 1 小时，一年就是几百个小时，可以压到学习、副业或休息上。

## “安全感三件套”：技术力、代表作和第二收入线

在自己的内容里，晚枫经常聊“程序员的安全感从哪儿来”。

他不太相信“只靠某一个东西”，而是把安全感拆成了三块：

1）技术力：保证“现在有饭吃”

AI 出来之后，“技术深度”的定义悄悄变了。过去更多是在问：你熟不熟悉某个框架的底层实现？现在更重要的是：你能不能把 AI 当成一个生产力放大器，用它解决本来要花很多时间才能搞定的问题。

在他看来，会不会高效地用 AI 写代码、调试和做自动化，已经成了程序员之间一个非常现实的“分水岭”。

2）代表作：保证“未来有路走”

`python-office` 这个项目，是一个很好理解的“代表作”样本：从一开始只服务自己，到下载量几十万、被写进教程和教材；再到带来加入 Python 中国组委会、参与线下大会、给企业做自动化改造的机会。

这些东西，很难用一个简单的数字来衡量，但直接决定了：当你想做下一步选择时，你手里握着多少张“牌”。

3）第二收入线：给心态加缓冲垫

当自媒体 + 开源项目的收入可以覆盖房贷车贷时，你对职业周期的感受会不一样：“即便哪天主业出问题，我还有别的选择。”

这种“备份通道”带来的，是非常实在的心理安全感。

晚枫给自己的总结很简单：技术力保证现在，代表作打开未来，第二收入线帮你扛住波动。

## 培训营、AI 副业项目太多？他只看这三件事

做内容这些年，晚枫看过太多“3 天速成”“7 天月入十万”的海报。

他现在给项目做筛选，基本只看三点：

1）是在“教渔”，还是只是在“卖鱼”？

愿意花时间讲工具原理、适用边界、拆需求、做流程、怎么调试的，是在“教渔”；只围绕几张收益截图转、塞一堆话术和固定脚本的，更像是在“卖鱼”。

2）宣传话术合不合理？

一看到“零基础 + 几天速成 + 保高薪/保接单”这种组合，他基本直接关网页。AI 确实把写代码门槛拉低了，但没有降低理解业务、设计系统、真正解决问题的门槛。

3）录播视频之外，还有没有“土壤”？

他会优先看：

+ 有没有活跃社区，可以长期提问、晒实践；
+ 有没有机会接触真实场景，而不是永远停留在“练习题”。

如果一个项目只卖录播，没有后续的陪伴、实践和反馈，他会非常谨慎。

## 写给「万象 AI 实验室」和所有还在观望的人

如果把这期专栏压缩成一句话，大概就是：先别急着问“AI 能帮我赚多少钱”，不如先问一句：“AI 能不能先帮我省下一点时间和力气？”

当你用 Python + AI，真真切切搞定了一个每天都在烦你的问题——那份报表、那堆发票、那串周报、那些重复回复……

你会发现，“玩 AI”不再是一句口号，而是日程表里可以写下的一行字：今天，把这条最烦的流程自动化掉；明天，多出一小时属于自己的时间。

当你在自己身上，反复尝到这种“时间复利”的甜头，再去思考“怎么把它变成副业、变成收入线”，就不再是空想，而是顺理成章的下一步。
