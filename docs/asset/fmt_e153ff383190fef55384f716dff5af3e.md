
英伟达的 GB200 GPU 采用 Blackwell 架构，通过 NVLink 技术实现了高效的 CPU-GPU 通信，显著提升了性能。该 GPU 提供四种机架形态，包括 GB200 NVL72、GB200 NVL36x2、GB200 NVL36x2（Ariel）和 x86 B200 NVL72/NVL36x2，以适应不同的数据中心需求。NVL72 形态每机架功率高达 120 千瓦，需要液冷系统，而 NVL36x2 形态每机架功率为 66 千瓦，更适合大多数数据中心基础设施。GB200 NVL36x2（Ariel）版本为了满足 Meta 的推荐系统需求，增加了 CPU 核心和内存容量。计算托盘的最大 TDP 为 6.3 千瓦，主要由 Bianca 板和风扇消耗。GB200 的核心 Bianca 板集成了两个 Blackwell GPU 和一个 Grace CPU，采用了高速 NVLink 连接，支持高达 600Gb/s 的双向带宽。网络方面，GB200 包括前端、后端、加速器互连和带外管理网络，后端网络可选 Nvidia 的 Infiniband 或 Spectrum-X 以太网交换机。NVLink 扩展互连使用 ACCs 或光纤实现，可连接 576 个 GPU，但成本和功耗较高。后端网络预计将从 ConnectX-7 过渡到 ConnectX-8，以支持更高的数据传输速率。前端网络参考设计中采用了 Bluefield-3，但实际部署可能会有所调整。

# 一键式RWKV RAG、RWKV-Keras、新论文...RWKV社区7月动态

`RWKV-6-World` 14B 模型作为纯 RNN 大语言模型，在多语言处理方面展现了卓越性能，并与 Llama2 13B 等模型相比表现更优。RWKV 中文官网上线，提供了关于 RWKV 架构、研究成果和使用教程的全面信息。

在技术层面，`RWKV RAG` 项目实现了本地 RAG 系统的简单搭建，支持 `LoRA`、`State tuning` 等微调方法，并计划适配多模态和知识图谱功能。`RWKV-Keras` 项目支持多种后端，包括 `jax` 和 `pytorch`，通过 `rwkv6-keras-operator` 项目提供了高效的推理和训练能力。`rwkv.cpp` 项目的更新，提高了 CPU 上的推理速度。

# 2024年 Agent构建思路进展

贡献人：

`https://zhuanlan.zhihu.com/p/712013790?utm_psn=1802055109745704960`

文章详细探讨了 Agent 构建的技术细节，包括 LLM 能力的演进预判，如 GPT-5 的预期发布和闭源及开源模型的发展趋势。文章指出，合成数据在提升 LLM 能力上的重要性，但同时也提到了其在横向拓展性上的局限。作者强调，构建 L1 级 Agent 时，应关注人类知识的提取、意图对齐与可解释性、以及需求与软件工程的结合。在 Agent 构建的一般原则中，提到了 workflow 的构建效率、系统层设计的容错性，以及如何通过 AI 辅助构建和人工调教 workflow 来降低成本。此外，文章还讨论了 L1 级 Agent 的具体构建技术，如 Prompt 调优、结构化内部表达方式、以及如何设计低延迟方案。对于 L2 级 Agent，作者提出了未来可能的构建途径，包括仿真环境的重要性和自主探索新问题的策略框架。
