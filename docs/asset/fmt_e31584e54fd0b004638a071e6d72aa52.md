### 配置 `Code in JavaScript` 节点（格式处理器）

这个节点是“翻译官”，负责将 AI 返回的“原始数据”转换成飞书能“看懂”的“消息卡片”，且我们要把其中的 Markdown 文档提炼出来。

将下面这段我们最终调试成功的完整代码复制粘贴到这个 `Code` 节点中：

```
const item = $items("蓝耘")[0];

let aiMarkdownContent = item.json.choices[0].message.content;

aiMarkdownContent = aiMarkdownContent.replace(/^`{3}(markdown)?\n/, '').replace(/\n`{3}$/, '').trim();

const feishuCardObject = {

  "config": {

    "wide_screen_mode": true

  },

  "elements": [

    {

      "tag": "markdown",

      "content": aiMarkdownContent

    }

  ]

};

item.json = feishuCardObject;

return item;

```
