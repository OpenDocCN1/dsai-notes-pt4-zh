
# 隐私政策对数据分析的披露

> 来源：[https://docs.feishu.cn/docx/H4PXdDmOQoqm1LxQFgRc2vUhnFf](https://docs.feishu.cn/docx/H4PXdDmOQoqm1LxQFgRc2vUhnFf)

- 问：现在隐私政策里会写到关于收集行为数据做分析处理（不包括营销和个性化这种`user`有感知的方式）吗

- 答1：`cookie policy`里一般会有。隐私政策中以提示援引链接还是直接一个章节的形式将`cookie`关于行为的追踪写进来。印象中，现在有的隐私政策就是直接一个章节写`cookie`，并没有单独的`cookie policy`了。当然，海外对于`cookie policy`有的是要求额外做`banner`弹出。

- 答2：似乎也会写吧 因为一般会全面地告知收集各类数据的目的 比如通过埋点收集用户行为数据“用于优化产品提升用户体验”这些不一定是在`cookies policy` 中，个人感觉在隐私政策中这类相关描述还蛮常见。

- 答3：关于“优化产品提升客户体验”这点作为处理目的的必要性，其实我个人觉得可以商榷，现在很多都有写，但一些新的立法例如汽车数据若干规定之后，还能不能概括的写“优化产品提升客户体验”我是有疑问的。概括的说确实不合适，我以前都是建议如果真的想提这一点，业务侧必须明确给我解释针对什么产品何种情形下提升什么体验，如果涉及敏感数据我会直接拒绝。

- 答4：我也觉得不行。35273里面有写这个，类似用户体验。但是个保法没有把处理者的合法利益作为合法性基础。因此，提升消费者体验这种，为了改善`app`运营的，还是豁免不了同意。

- 答5：如何理解“仅以”和“强制”也非常`tricky`。

![](img/bc46fc1861177a49cae861857c5bbdb5.png)

- 答6： 因为实践中收集用户行为数据往往可能会涉及多重的目的“除了优化产品”有些则是跟踪产品使用的情况，乃至做些个性化推荐之类的，而有些可能不与用户进行关联 而是仅仅有一些操作行为统计目的。我只是觉得可以展示在隐私政策层面作为告知，因为可能确实是收集数据的目的的一种 至于处理数据的合法性基础，当然还是要依据法律规定的合法性基础才能处理，并不是说写在隐私政策里是为了豁免同意之类的意思。

- 答7：我是觉得“优化产品和服务”“提升客户体验”作为业务诉求是没问题，关键是怎么把这个诉求写出来，概括的一句话恐怕不行，但并不是完全`say no`。例如，客户选择向处理者主动发送错误报告用以排查特定产品的错误的，也是优化产品，这种我个人会觉得可以。
