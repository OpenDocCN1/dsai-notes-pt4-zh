
# 数据出境法律文件的签署

> 来源：[https://docs.feishu.cn/docx/HaFjdWM2iozZk5xJyqicfcyYn9n](https://docs.feishu.cn/docx/HaFjdWM2iozZk5xJyqicfcyYn9n)

**-问：**如境内数据处理者A将数据直接传输至实际处理数据的境外接收方C，但出于商业的考量数据跨境传输协议是A的境外关联公司B公司与C签署的（AB是一套人马），B公司不进行任何数据处理活动，个人理解该种情形下出境申报披露的境外接收方应渗透到C公司？那是否需要在A和C之间补充签署协议呢？境外接收方的认定标准为何？（是以签署传输法律文件为准吗？）

**-答1：**类似案例不需要，建议直接问网信部门。

**-答2：**就境外接收方的判定而言，基本原则是该境外接收方应是能够就出境数据的安全承担法律责任的实体。另外，在使用境外的系统或者应用程序来接受从中国出境的数据的情况下（例如使用Workday），即使该等境外的系统或者应用程序是数据出境的第一接收点，此类系统或者应用程序的提供商不应被视为境外接收方，此类系统或者应用程序应作为数据链路的一部分或者由境外接收方再转移出境数据的第三方（视具体情况而定）。
