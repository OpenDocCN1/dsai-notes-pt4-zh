
# Learning Hub- CrewAI

## 官方核心资料

1. `CrewAI` 官方文档：作为最权威的入门指南（`https://docs.crewai.com/`），文档包含入门介绍、核心概念解析、快速上手等核心板块。其中 “快速入门” 章节可让新手几分钟内搭建简单的研究 / 报告多智能体团队，清晰讲解了智能体定义、任务创建等基础操作；还详细阐述了 `API` 用法、运行时细节、项目布局模式等内容，适合系统理解框架设计逻辑和技术细节，同时能了解其与其他多智能体框架的核心差异。

1. `CrewAI` 官方博客入门教程：`blog.crewai.com` 上的《Build your First CrewAI Agents》（`https://blog.crewai.com/getting-started-with-crewai-build-your-first-crew/`）是纯英文分步教程，专为新手设计。内容涵盖开发环境搭建、用 `CLI` 工具创建项目、通过 `YAML` 配置智能体和任务等，还明确了系统需 `Python` 3.10 - 3.13 版本、`uv` 包管理器等要求，步骤清晰且附带命令校验方法，能帮助学习者规范完成首个智能体团队搭建。

1. `CrewAI` GitHub 开源仓库：仓库（`https://github.com/crewAIInc/crewai`）是框架源码和示例的核心来源，遵循 MIT 开源协议。其中 `examples` 目录包含多个实战案例，比如内容创作、数据分析等场景的智能体配置代码，可直接复制运行体验；`README` 文件清晰列出安装命令、基础调用示例和项目结构，同时能通过查看提交记录、`PR` 和社区问题，了解框架迭代逻辑和常见问题解决方案，适合想从源码层面学习的学习者。

## 中文实战教程与博客

1. 《从零入门 `CrewAI`: 多智能体协作框架实战指南》：发布于 CSDN 的保姆级教程，非常适合零基础学习者。文章先讲解 `CrewAI` 的定义、核心优势和典型应用场景，再拆解 5 个核心组件，随后一步步教读者完成环境搭建，还以 “`Python`+`YAML` 配置” 模式为例演示多智能体系统搭建，附带完整安装命令和代码示例，文末还提供可直接运行的源码，能快速掌握核心实战流程。

1. 《万字长文解析基于 `CrewAI` 创建 Agent 的各个细节》：CSDN 的深度教程，聚焦 `CrewAI` 创建智能体的细节知识点。内容涵盖智能体角色设计、任务拆分技巧、协作流程优化等，还补充了不同场景下的参数调优建议，适合入门后想深入掌握智能体开发细节的学习者，帮助提升搭建系统的稳定性和效率。

1. 《`CrewAI` 教程：构建协作式 AI 智能体团队》：相关中文整合教程，整合了多个实操场景。比如讲解如何结合 `crewai - tools` 工具集实现网络搜索、PDF 解析等功能，还演示了 “研究员 + 撰稿人 + 编辑” 的内容创作智能体团队搭建，清晰呈现智能体间的任务委派和上下文共享过程，让学习者直观理解多智能体协作逻辑。

## 视频教程

1. Codebasics 的 `CrewAI` 初学者完整速成课程：发布于 YouTube 的免费视频教程，时长约 3.5 小时，适合可视化学习的初学者。课程从智能体 AI 基础知识讲起，逐步演示智能体和团队的创建、端到端任务运行等操作，通过实际演示和通俗讲解，帮助学习者快速掌握框架基础用法，长篇格式的内容能完整覆盖入门核心知识点。

1. `CrewAI` 智能体 AI 教程：同样发布于 YouTube，适合想快速了解基础概念的学习者。视频清晰梳理了智能体、团队、角色、任务等核心概念，以及智能体协作的底层逻辑，搭配简单的实操演示，能帮助学习者快速建立对 `CrewAI` 的认知框架，为后续实战打下基础。

## 辅助学习渠道

1. `CrewAI` 社区论坛：可通过官方文档跳转进入，能与全球开发者和学习者交流问题。比如环境配置报错、智能体协作逻辑异常等问题，都能获取一手解决方案，还能了解行业内基于 `CrewAI` 的创新应用案例。

1. GitHub `CrewAI` 主题索引：通过 GitHub 的 “`crewai`” 主题标签，可浏览社区开发的无代码 / `GUI` 工具、封装组件等。这些第三方工具能简化智能体搭建流程，适合用于快速原型设计和演示，同时也能借鉴他人的项目思路拓展自身开发视野。
