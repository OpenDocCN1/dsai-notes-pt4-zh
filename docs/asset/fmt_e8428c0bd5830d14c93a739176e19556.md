用`root`权限更新 Ubuntu/Debian 的软件源包索引

```
sudo apt update
```

使用`curl`命令安装`nvm`版本管理工具，版本为0.39.1

```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
```

重新加载shell环境：

```
source ~/.bashrc
```

使用`nvm`安装最新版本的`Node.js`：

```
nvm install node
```

用`root`权限在系统上安装`git`版本控制系统

```
sudo apt install git
```

克隆`clewd`到本地（这一块全部复制进去都可以，`#`后面的东西他不会读取）

```
#克隆clewd修改版到本地
git clone https://github.com/teralomaniac/clewd.git
#切换当前目录到clewd的目录
cd clewd
#用一键脚本安装依赖并启动clewd
bash start.sh
```

### 填入 cookie

不过第一次运行不会启动`clewd`，而是生成`config.js`配置文件，需要填cookie进去

![](img/51441744a3726ab93f9f09913c24295.png)

看到如上图就是正确的了。

点击左上角的绿色圈圈，来到桌面，点左下角的文件管理，里面的排序是按照abcde顺序排的，先找到`root`文件夹（可能是`home`文件夹），然后点击`clewd`，路径找到`config.js`文件，按照图，把你的cookie填入`"Cookie"`后面的引号内，记得删掉“SET YOUR COOKIE HERE”。

![](img/bc8551dc9343b8196641d6c94a526c09.png)

还有个非常重要的!!!!!! 把`ProxyPassword`设置个密码如下

```
&quot;ProxyPassword&quot;:&quot;123&quot;,
```

如果有多个cookie，则清空`"Cookie"`后，按照如下格式，把cookie都填入`"CookieArray"`：`[]`中

```
格式如下，在[]中分别用&quot;&quot;包裹cookie，用英文逗号分隔，但结尾不能有逗号例如&quot;CookieArray&quot;: [&quot;cookie1&quot;,&quot;cookie2&quot;,&quot;cookie3&quot;]

#举例：
&quot;CookieArray&quot;: [
&quot;sessionKey=sk-ant-sid01-bTiK8Mf6XqHODdxmwV&quot;,&quot;sessionKey=sk-ant-sid01-Sokt3wB7c3Yx_PIbLK&quot;,&quot;sessionKey=sk-ant-sid01-YylqgeaI6X0YxIWBS3E3gCN7Fg1hR754lT-RtN&quot;,&quot;sessionKey=sk-ant-sid01-ycbnhdXsaJOnKDOUT_NnvIHejk42n&quot;;
    ],
    
#不用试啦我给的假cookie
```

填好cookie后，右边三个点，点击然后`save`

接下来在`clewd`的目录下，输入命令`bash start.sh`

`clewd`！启动！

像下面这样显示了反代地址和你的邮箱，就算部署成功了

把这个反代地址复制到剪切板：

`http://127.0.0.1:8444/v1`

### 如何更新？

切换当前目录到`clewd`的目录

`cd clewd`

用`update.sh`一键脚本即可更新

`bash update.sh`
