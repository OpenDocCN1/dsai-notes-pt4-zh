### Q10: 怎么省钱

#### 综合省钱策略：

1. **选择合适的模型**

+ 简单任务：Haiku（最便宜）

+ 日常开发：Sonnet（性价比高）

+ 关键决策：Opus（按需使用）

2. **优化Token使用**

+ 定期 `/compact` 压缩对话

+ 完成任务后 `/clear` 清空

+ 简洁描述需求

3. 避免不必要的Extended Thinking

+ 简单问题直接问

+ 只在需要深度分析时用 think

4. **监控使用量**

+ 定期 `/cost` 查看费用

+ `/context` 检查Token使用
