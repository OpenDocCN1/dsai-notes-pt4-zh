Overlay Communication（又称覆盖通信）是一种在网络中添加虚拟网络层的技术，用于改进网络性能和扩展网络功能。通过覆盖通信，可以在现有的网络架构上增加一个虚拟的网络层，这个虚拟层与底层网络相互独立，可以实现更高效、更安全和更灵活的通信方式。

覆盖通信的主要思想是，在应用层和传输层之间添加一个中间层，这个中间层可以通过使用不同的协议、路由和拓扑结构来优化网络通信。在覆盖通信中，应用程序会将数据包发送到覆盖网络中，然后由覆盖网络负责将数据包传输到目标地址，从而实现更快速、更可靠的通信。

### 4.1.1 Threat Model

下面我们要考虑这种 relay 的风险。

考虑风险时，我们需要定义攻击者的行为模式：`Insider Byzantine Attacker`。

`Insider` 表示攻击者本身是网络的组成部分（ASes），而且攻击者可能控制着不止一个 ASes，但是攻击者并没有能力看到网络的全貌；

`Byzantine` 是一种攻击模式，表示攻击者的攻击方式是不稳定的。长期、一致的攻击会容易被发现，因此攻击者采取间断式的、不同方式的攻击，就比较难被检测到了。

攻击者的目标是在目的 IP 信息隐藏在数据包中的情况下，得知数据包的最终目的地。

## 4.2 Anonymizing Proxy

`Anonymizing Proxy`是一种网络代理服务器，可以隐藏用户的真实 IP 地址，从而保护用户的隐私和安全。当用户使用 `Anonymizing Proxy` 时，所有的网络请求都会通过代理服务器进行转发，从而隐藏用户的真实 IP 地址。`Anonymizing Proxy` 可以用于访问被封锁的网站、保护个人隐私、加速网络连接等。

![](img/73cd19d68b90069592c525562af528fd.png)

+   如果攻击者在 `sender` 和 `proxy` 之间，`sender` 丧失匿名性；
+   如果在 `proxy` 和 `receiver` 之间，`receiver` 丧失匿名性；
+   如果两个攻击者串通对比 `ingress` 和 `egress` 代理流量，则匿名性失效；
+   如果 `proxy` 本身是 `attacker`，匿名性同样失效。

#### 4.2.4.1 Source Routing

Source Routing / Path Addressing 允许发送者指定一个包的部分或者全部路由

源路由技术中，数据包的路由路径是在数据包的头部中指定的，这意味着发送方可以选择数据包的路由路径，而不是让网络中的路由器根据它们的路由表来自动选择。

#### 4.2.4.2 POF-Based Source Routing

POF - Protocol Oblivious Forwarding

![](img/d0ab13d6410f9636789623288e9a706e.png)

`POF-Based Source Routing` 是一种网络通信协议，其中 `POF` 代表 `Protocol Oblivious Forwarding`，意为协议无关的转发。

在传统的网络协议中，路由器需要了解特定的协议来进行转发，而 `POF-Based Source Routing` 采用了一种新的转发机制，即从数据包的源头开始指定数据包的路径。在此过程中，`POF-Based Source Routing` 不需要了解任何特定的协议，而只需要遵循指定路径进行数据包的转发。

绑定端口，源给了一个栈，里面说了要怎么走

这种方式可以带来许多好处，比如更加高效和灵活，可以适应不同类型的网络环境和应用场景。同时，`POF-Based Source Routing` 也可以提高网络的安全性，因为它可以在数据包的源头就确定数据包的路径，避免了路由器被攻击的风险。

总之，`POF-Based Source Routing` 是一种协议无关的网络通信协议，可以在网络通信中带来许多好处。
