## Cherry Studio 安装与启动

### 一、下载 Cherry Studio

1. **访问下载页面**

+ 打开浏览器，访问 [Cherry Studio 官网](https://github.com/CherryHQ/cherry-studio) 或 `GitHub` 仓库。

+ 选择适合您操作系统的版本（Windows、Mac 或 Linux）进行下载。

1. **选择版本**

+ **Windows**：下载 `.exe` 文件。

+ **Mac**：下载 `.dmg` 文件。

+ **Linux**：下载 `.AppImage` 或 `.deb/.rpm` 文件。

---

### 二、安装 Cherry Studio

1. **Windows 系统**

+ 找到下载的 `.exe` 文件，双击运行。

+ 在安装向导中，点击“下一步”，选择安装路径（默认路径为 `C:\Program Files\Cherry Studio`），然后继续点击“下一步”完成安装。

+ 安装完成后，在开始菜单中找到“Cherry Studio”并点击启动。

1. **Mac 系统**

+ 找到下载的 `.dmg` 文件，双击打开。

+ 将 Cherry Studio 图标拖拽到“应用程序”文件夹中，完成安装。

+ 安装完成后，在“应用程序”中找到 Cherry Studio 并打开。

1. **Linux 系统**

+ 如果下载的是 `.AppImage` 文件，在终端中运行以下命令赋予执行权限：

```
chmod +x CherryStudio-*.AppImage
```

然后运行以下命令启动：

```
./CherryStudio-*.AppImage
```

+ 如果下载的是 `.deb` 或 `.rpm` 文件，使用以下命令安装：

+ `.deb` 文件：

```
sudo dpkg -i 安装包名.deb
```

+ `.rpm` 文件：

```
sudo rpm -ivh 安装包名.rpm
```

+ 安装完成后，在应用列表中找到 Cherry Studio 并启动。

---

### 三、启动 Cherry Studio

1. **首次启动**

+ 双击桌面图标（Windows/Mac）或通过终端（Linux）启动应用程序。

+ 首次启动时，可能需要同意用户协议或进行初始化配置。

1. **主界面**

+ 启动后，您将看到 Cherry Studio 的主界面，左侧是功能导航栏，右侧是内容显示区域。

---

### 四、常见问题排查

1. **安装失败**

+ 检查系统是否满足最低硬件要求（如内存、存储空间）。

+ 确保下载的安装包完整，必要时重新下载。

1. **启动失败**

+ 检查是否有其他程序占用端口或资源。

+ 确保操作系统版本支持 Cherry Studio。

## Cherry Studio 接入模型（以 DeepSeek 为例）

### 一、获取 DeepSeek API 密钥

1. **注册 DeepSeek 账号**

+ 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)，使用手机号或邮箱注册账号并登录。

1. **创建 API 密钥**

+ 登录后，点击左侧菜单中的 `API Keys`，然后点击“创建 API Keys”。

+ 复制生成的 API 密钥，妥善保存（密钥仅在创建时可见）。

---

### 二、在 Cherry Studio 中添加 DeepSeek 模型

1. 打开 Cherry Studio

+ 启动 Cherry Studio，点击界面左下角的“设置”按钮。

1. 添加 DeepSeek 模型服务

+ 在设置窗口中，选择“模型服务”选项卡。

+ 点击“添加”按钮，选择“深度求索”（DeepSeek）作为模型服务。

+ 在“API 密钥”字段中，粘贴您刚刚复制的 DeepSeek API 密钥。

+ 在“API 地址”字段中，输入 `https://api.deepseek.com`。

+ 点击“检查”按钮，确保连接成功。如果显示绿色对勾，说明配置完成。

---

### 三、选择并使用 DeepSeek 模型

1. **选择模型**

+ 在 Cherry Studio 主界面中，点击左侧的“AI 助手”按钮。

+ 在对话窗口顶部，选择“深度求索”分组中的模型（如 `deepseek-r1` 或 `deepseek-v3`）。

1. **开始对话**

+ 输入您的问题或需求，例如“用 `Python` 编写一个计算斐波那契数列的函数”。

+ DeepSeek 模型会根据您的输入生成相应的回答或代码。

---

### 四、常见问题排查

1. **模型未连接**

+ 检查 API 密钥是否正确，或确认网络连接正常。

+ 确保 DeepSeek 账号已激活且 API 密钥未过期。

1. **显存不足**

+ 如果使用本地模型，建议降低模型版本（例如从 `32B` 切换至 `7B`）。

## Cherry Studio 使用助手

### 一、选择内置助手

1. 打开 Cherry Studio

+ 启动 Cherry Studio，点击左侧导航栏中的“AI 助手”按钮。

1. **浏览助手列表**

+ 在助手列表中，您可以浏览 300+ 预配置的助手，这些助手按功能分类（如“代码生成”、“翻译”、“写作”等）。

+ 使用搜索框快速查找特定助手，例如输入“代码生成”或“翻译”。

1. **选择助手**

+ 点击您需要的助手名称，右侧会弹出对话窗口。

1. **开始对话**

+ 在对话窗口中输入您的需求，例如“用 `Python` 编写一个计算斐波那契数列的函数”，助手会根据您的输入生成相应的代码或回答。

---

### 二、创建自定义助手

1. **添加助手**

+ 在“AI 助手”页面，点击“添加助手”按钮。

1. **配置助手信息**

+ 为助手命名，例如“我的翻译助手”。

+ 选择一个基础模型（如 `DeepSeek-R1` 或 `OpenAI GPT-4`）。

+ 根据需要调整其他参数，如温度（控制生成内容的随机性）和最大输出长度。

1. **添加插件（可选）**

+ 为了使助手具备更多功能，您可以从插件市场中选择并添加所需的插件。例如，添加“翻译插件”或“代码格式化工具”。

1. **保存助手**

+ 配置完成后，点击“保存”按钮。您的自定义助手将出现在助手列表中。

1. **使用自定义助手**

+ 在助手列表中选择您刚刚创建的助手，开始对话。

---

### 三、多模型对话

1. **启用多模型对话**

+ 在对话窗口顶部，点击“多模型”按钮，选择多个模型（如 `DeepSeek-R1` 和 `OpenAI GPT-4`）。

1. **输入问题**

+ 输入您的问题或需求，例如“用 `Python` 编写一个计算斐波那契数列的函数”。

1. **查看结果**

+ 多个模型会同时生成回答，您可以对比不同模型的回复，选择最合适的答案。

---

### 四、导出对话记录

1. **导出对话**

+ 在对话窗口中，点击“导出”按钮，选择导出格式（如 `Markdown`、`Word` 或长图片）。

+ 保存对话记录到本地，方便后续查看或分享。

---

### 五、常见问题排查

1. **助手无响应**

+ 检查模型服务是否连接正常，确保 API 密钥正确输入。

+ 确认网络连接正常。

1. **助手响应缓慢**

+ 可能是网络延迟或服务器负载过高，建议稍后再试或重新启动应用程序。

## 文档和数据处理

以下是 Cherry Studio 文档与数据处理 的详细操作步骤：

---

### 一、上传文件

1. **打开文件管理**

+ 启动 Cherry Studio，点击左侧导航栏中的“文件管理”按钮。

1. **上传文件**

+ 点击“上传文件”按钮，选择本地文件（支持文本、图片、`PDF`、`Office` 文档等多种格式）。

+ 或者直接将文件拖拽到文件管理窗口中。

1. **查看上传文件**

+ 上传完成后，文件会显示在文件列表中，点击文件名即可预览内容。

---

### 二、处理文件

1. **使用 AI 助手分析文件**

+ 在文件列表中，右键点击文件，选择“使用 AI 助手分析”。

+ 在弹出的对话窗口中，输入您的需求，例如“总结这篇文档的主要内容”或“提取关键数据”。

+ AI 助手会根据文件内容生成相应的回答或分析结果。

1. **翻译文件**

+ 右键点击文件，选择“翻译”。

+ 选择目标语言（如英语、日语等），AI 助手会将文件内容翻译成指定语言。

1. **提取数据**

+ 对于表格或结构化文档，可以使用 AI 助手提取特定数据。例如，输入“提取表格中的销售额”，助手会生成相应的数据列表。

---

### 三、WebDAV 文件同步

1. **配置 `WebDAV`**

+ 在“设置”中，选择“`WebDAV`”选项卡。

+ 输入 `WebDAV` 服务器地址、用户名和密码，点击“检查”按钮，确保连接成功。

1. **同步文件**

+ 在文件管理中，点击“同步”按钮，选择本地文件夹与远程 `WebDAV` 文件夹进行同步。

+ 文件会自动同步到远程服务器，方便跨设备访问。

---

### 四、创建知识库

1. **添加嵌入模型**

+ 在“设置”中，选择“嵌入模型”选项卡，添加 `BAAI/bge-m3` 等嵌入模型（无需 API 密钥）。

1. **创建知识库**

+ 点击左侧的“知识库”图标，选择“添加本地文档”。

+ 输入知识库名称（如“个人学习库”），上传文件并选择嵌入模型进行向量化处理。

1. **使用知识库**

+ 在对话窗口中，选择已创建的知识库，AI 助手会根据知识库内容生成回答。

---

### 五、导出与备份

1. **导出文件**

+ 在文件列表中，右键点击文件，选择“导出”，保存为 `Markdown`、`Word` 或长图片格式。

1. **备份数据**

+ 在“设置”中启用 `WebDAV` 或手动备份数据，确保数据安全。

如需进一步帮助，请参考 Cherry Studio 官方文档 或加入社区讨论。

## 附录

### 启用 Cherry Studio 网络搜索功能

1. 升级 Cherry Studio

+ 打开 Cherry Studio，点击左下角的“设置”按钮。

+ 在“关于我们”中检查更新，确保软件版本为最新（当前最新版本为 `v1.0.6`）。如果无法更新，请前往 Cherry Studio 官网 下载最新安装包。

1. **注册 Tavily 账号**

+ 在设置界面中，选择“网络搜索”，点击“点击这里获取密钥”。

+ 跳转到 [Tavily 官网](https://tavily.com/)，点击“Sign Up”注册账号。

+ 输入邮箱和密码，完成注册并登录。

1. **获取 API 密钥**

+ 登录 Tavily 后，在个人账号页面找到 `Key` 位置，点击复制 API 密钥。

1. 配置 Cherry Studio

+ 返回 Cherry Studio，在“网络搜索”设置中粘贴复制的 API 密钥。

+ 确保“联网”开关已开启（联网标识为蓝色）。

1. **测试联网功能**

+ 在对话界面中，点击“联网”按钮（地球图标），输入问题测试联网搜索功能。例如：“今天的最新新闻是什么？”。

+ 如果成功获取实时信息，说明联网功能已启用。

### 注意事项

+ Tavily 免费用户每月有 1000 次搜索额度，超出需付费。

+ 如果遇到网络问题，建议刷新页面或使用🪜工具。

如果您在操作过程中遇到问题，请参考 Cherry Studio 官方文档 或联系技术支持。
