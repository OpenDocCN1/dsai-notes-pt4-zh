## 大模型推理序列并行

贡献人：

https://zhuanlan.zhihu.com/p/9816504195

本文探讨了大模型推理阶段的序列并行策略，特别是不同推理阶段对序列并行方法的需求差异。推理阶段的序列并行比训练时要复杂，因为每个推理阶段对数据的处理方式有所不同。

在`Prefill`阶段，与训练的前向过程类似，可以使用交换`kv`的`RingAttention`方法。这一阶段的操作流程涉及将`Q`、`K`、`V`数据分布到不同的卡上，每张卡计算一部分数据，但需要交换`kv`数据才能完成计算。`RingAttention`方式通过交换`kv`来保证各卡能够获得完整的`K`和`V`数据，同时进行负载均衡，确保每张卡计算的工作量相等。

在`Decode`阶段，`Q`的`token`数量为1，而`K`和`V`的数量则非常大。此时交换`kv`的方式不再适用，因为交换的数据量过大，难以有效进行通信与计算重叠。此阶段更适合使用交换`Q`的分布式`Attention`策略。通过交换`Q`，每张卡持有完整的`Q`数据，但计算过程仍为分块`Attention`，这时可以采用`Tree-decode`或`RingQ-decode`策略，以减少通信量和计算负载的瓶颈。

`Prefix-Cache`阶段的序列并行则处于两者之间，`Q`的数量为`N`，而`K`和`V`的数量为`M`。此时是否交换`Q`或`kv`取决于通信和计算的负载，但一般来说，交换`Q`比交换`kv`更为合适。此阶段可以使用`RingAttention`或`RingQ-decode`策略，具体取决于任务的通信需求。

文章还探讨了分块`Attention`的计算，尤其是在`Q`、`K`、`V`不能一次性计算完成的情况下，如何将其分块进行处理。分块`Attention`将`Q`、`K`、`V`分为多个子块，分别计算后合并结果，这一方式已经被诸如`FlashAttention`和`FlashInfer`等实现所广泛采用。通过这种方法，可以更好地处理内存和计算的限制，提升效率。

此外，文章分析了不同推理阶段如何结合分布式架构和网络拓扑来优化序列并行。在多卡多机的环境中，`RingKV`适用于单机多卡的高效通信，但在跨机时，其带宽利用率较低。相比之下，`AllReduce`在多机环境下能够充分利用带宽，特别是结合`Double Tree`架构，通过减少通信量来提高效率。

总的来说，序列并行在大模型推理中的实现需要根据具体的推理阶段、计算负载以及通信需求来选择合适的策略。在`Prefill`、`Decode`和`Prefix-Cache`等不同阶段，应灵活调整数据交换和分布式计算方式，以达到最优的性能和效率。

## 白话版Scaling Laws for Precision 解读

https://zhuanlan.zhihu.com/p/6848989432

本文探讨了精度、模型参数量和训练数据量之间的关系，重点分析了后训练量化（PTQ）对大规模语言模型（LLM）的影响。PTQ是一种方法，即模型在预训练时使用较高精度（如`bf16`），然后再量化为较低精度（如`int4`）。研究发现，训练过程中使用的token与模型参数的比率越高，PTQ导致的性能下降越显著。文章提出了一个公式来预测这一损失，公式考虑了模型的参数量、训练token数以及量化后的精度，结果表明，训练数据量越大，PTQ导致的性能损失越大；而模型参数量越大，损失则越小；量化后精度越低，性能下降越明显。文章还指出，存在一个临界点，超过这个数据量后，继续增加训练数据可能会导致PTQ性能下降，但这个临界点的具体数值并不是固定的，而是与模型架构和数据量的平衡有关。

另外，文章还指出，训练时使用较低精度（如`int8`）的模型会比高精度（如`bf16`）模型在PTQ时表现得更鲁棒。这是因为低精度训练能使模型更好地适应量化噪声，减少PTQ过程中的性能损失。然而，低精度训练也有一个反向效应，即会减少模型的有效参数量，增加模型对量化的敏感度。一般来说，鲁棒性效应占主导地位，因此低精度训练通常能更好地应对PTQ带来的性能退化。

在低精度训练方面，文章还提出了当量化精度低于5位时，PTQ引起的性能下降会急剧加剧。针对这一发现，作者建议在实际应用中应避免将模型量化到低于5位，除非有特定需求和优化技术。此外，文章还提出，训练时使用7-8位精度通常是最优选择。相比之下，16位精度训练存在冗余，而低于4位的精度则需要大幅增加模型规模才能维持性能。

研究还分析了不同量化方法的效果，尤其是针对权重、激活值和注意力计算的量化。研究表明，量化过程中权重、激活值和注意力计算的效果是独立且可乘的，因此可以根据不同组件的量化需求做出调整。在固定计算预算下，增加模型参数量通常会带来更好的性能，尤其是在训练精度为8位时，这种策略表现较为优越。

最后，作者提出了一些实践建议：在计算预算有限的情况下，应优先选择7-8位的训练精度，并尽可能增加模型的参数量；避免使用低于4位的训练精度。如果模型规模受到限制，则应根据训练数据量和token/parameter比率调整训练精度，以确保性能最大化。

## 人机对齐：从RLHF到DPO

https://zhuanlan.zhihu.com/p/10059528011

本章围绕AI对齐问题展开，阐述了如何通过不同技术方法实现AI行为与人类意图的对齐。首先，AI的对齐问题提出了人工智能是否能够准确理解和执行人类的价值观和意图的问题。监督学习（`SFT`）在一定程度上能让AI理解人类的偏好，但仍存在局限性：首先，数据获取困难；其次，监督学习难以捕捉复杂的、细微的偏好差异；最后，它缺乏探索机制，无法主动适应新的情况。

为了克服这些问题，引入了强化学习中的一种新方法——`RLHF`（从人类反馈中强化学习）。`RLHF`通过让人类对模型输出进行比较评分，训练奖励模型来指导AI的学习。与传统的问答数据不同，`RLHF`通过选择题形式的比较数据，减少了人类标注数据的收集难度。这一过程分为三个步骤：首先使用人类标注数据对预训练模型进行监督微调；然后训练一个奖励模型来评估不同输出的质量；最后，通过`PPO`算法进行策略优化，根据奖励模型的反馈调整模型参数。

强化学习的核心是让智能体通过与环境的互动，通过试错不断优化决策，而`PPO`算法则通过限制策略更新幅度，确保训练的稳定性和数据的高效利用。然而，`RLHF`的挑战在于其复杂性和计算成本高，而且容易出现“对齐税”问题，即为了优化奖励模型，可能导致模型在其他任务上的性能下降。

为了解决`RLHF`的不足，提出了`DPO`（直接偏好优化）方法。`DPO`摒弃了强化学习，通过数学模型（如`Bradley-Terry`模型）直接从人类的偏好数据中学习，避免了复杂的强化学习步骤。`DPO`利用监督学习进行训练，过程简单、稳定性高、计算成本低，并且能有效实现与`RLHF`相当的对齐效果。

实践中，`Huggingface`的`TRL`库提供了多种后训练方法，如`PPO`和`DPO`，简化了对齐训练的实施。用户可以通过`TRL`库轻松地使用`DPO`进行模型训练，具体过程包括准备人类反馈数据、初始化`DPO`训练器、设置训练参数等。

总的来说，本章详细讨论了人机对齐的挑战与解决方案，特别是通过`RLHF`和`DPO`两种方法在强化学习和监督学习的框架下，分别在复杂性、效率和稳定性方面做出的创新与改进。

## 具身智能Vision-Language-Action的思考💡

https://zhuanlan.zhihu.com/p/9880769870

目前具身智能`VLA`（`Vision-Language Action`）领域的主要方案可以分为几种不同的技术路线。第一种是经典的 `encoder-decoder` 型 `Transformer` 架构，这种方式通常从头开始训练，将机器人状态和视觉观测作为潜在条件，通过基于查询的 `Transformer` 解码器来生成动作。代表性的方案包括 `ALOHA(ACT)`系列、`RT-1` 和何凯明提出的 `HPT`（`Hybrid Pre-training Transformer`）。

第二种方案是拥抱预训练的大规模语言模型（`LLM`）或视觉语言模型（`VLM`）。通过将动作视为 `token` 进行直接预测，这种方式借鉴了成熟的语言模型，并能够有效利用预训练和规模化的经验，降低了训练成本。`RT-2` 和 `OpenVLA` 就是这一方案的代表，它们通过将动作作为 `token` 进行直接预测，提升了效率和可扩展性。

第三种方案采用扩散模型（`Diffusion Model`），这种方法通过多步降噪过程来建模细粒度的动作，特别适用于灵巧任务。扩散模型在动作轨迹的生成方面具有独特优势，因为它能够逐步优化动作输出，生成更精细的动作轨迹。`DiffusionPolicy` 和 `RDT-1B` 是这一技术路线的代表。

第四种方案是 `LLM` 和扩散模型的结合，借鉴了最近在通用生产与理解一体的大模型上的成功。通过将 `LLM` 用于压缩多模态表征，同时使用扩散模型来精细化生成动作轨迹，这种组合能够在多模态任务中提供更强的表现力。`Octo` 和 `π0` 就是这一方向的代表，它们通过结合 `LLM` 和扩散模型提升了模型的推理能力和动作生成精度。

第五种方案结合了视频生成与逆运动学。首先通过视频生成模型根据初始帧和指令生成运动视频，然后使用逆运动学从视频中推断出相应的动作。这种方法的优势在于可解释性强，但对视频生成质量和指令跟随能力依赖较大。代表方案包括 `UniPi`、`RoboDreamer` 和 `UniSim`，其中 `UniSim` 更是通过视频生成模型提供了一个闭环仿真环境，为强化学习算法的探索提供了新的途径。
