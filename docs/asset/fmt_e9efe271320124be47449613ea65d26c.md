## 更新线程ID重新开启对话

而如果更新线程ID，则会重新开启对话：

### 配置新线程ID

```
config2 = {
    "configurable": {
        "thread_id": "2"  
    }
}
```

### 调用Agent并获取响应

```
response2 = agent.invoke(
    {"messages": [{"role": "user", "content": "你好，你还记得我叫什么名字么？"}]},
    config2
)
```

### 查询消息历史

```
response2['messages']
```
