## 📝 回答您的问题

### 推荐码的生成机制

推荐码从哪里来？

+   每个用户在首次注册成功的瞬间，后端会自动生成一个唯一的推荐码并保存到该用户的 `userProfiles` 文档中。
+   用户无需手动创建，系统自动分配。

如何生成？

格式：`PS-` + 8位随机字母数字（大写）

示例：`PS-AB3K9M2Q`

生成逻辑（Cloud Function 中执行）：

1.  生成随机 8 位字符串
1.  查询 Firestore 确保全局唯一
1.  如果重复则重新生成
1.  写入用户文档

---

### 优惠码管理方式（Firebase Console 操作指南）

创建优惠码的步骤：

1.  登录 Firebase Console
1.  进入项目 → Firestore Database
1.  点击 `promoCodes` 集合（首次需要创建）
1.  点击 "Add document"
1.  填写字段：

```
code
+   : "INFLUENCER2024" (优惠码)
credits
+   : 100 (积分数量)
maxUses
+   : 50 (最大使用次数，不填则无限)
isActive
+   : true
expiresAt
+   : 选择日期（可选）
```

优点： 无需开发管理后台，零成本 缺点： 需要手动操作，适合少量优惠码场景
