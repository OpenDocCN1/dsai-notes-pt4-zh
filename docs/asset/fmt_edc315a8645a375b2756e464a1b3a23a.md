
## Step 4：获取回调配置信息

![](img/9d4973465dc3b77985704eb28c3bf9b9.png)

在刚创建的应用里，找到“接收消息”，点击“API 接收”，然后点“随机获取”，系统会生成两个参数：

![](img/6dad60117cde9a83664122a53907ced9.png)

+ `Token`
+ `EncodingAESKey`

“接收消息”URL 一栏先空着等第六步骤操作完再点【保存】

把这两个值保存下来。同时，在“我的企业”页面找到你的企业ID，也记录好。

![](img/6b5528ba98cf9abaeb7af78d4765d75c.png)

## Step 5：把参数填回

把刚才在企业🛰️后台拿到的几个参数，填回服务器上的配置文件里。

![](img/0c6a5616157f04072d8ca9f5a0897efc.png)

填完之后，等待配置生效

## Step 6：填写回调地址

打通完成回到企业🛰️后台，在应用的“接收消息”URL 一栏，填入：

![](img/e1ba249031c2718e2ea1319c87a21b24.png)

`http://你的服务器IP:18789/wecom/agent` （假如我的ip地址是0.0.0.0 则此处应该填写：`http://0.0.0.0:18789/wecom/agent`）

![](img/063fcb3d69e7b0ad8df994b8a09eb573.png)

保存，如果没有报错，说明打通成功了。注意：以上端口号和插件包名以 OpenClaw 官方文档为准，正式操作前建议对照官方文档核实。添加至个人🛰️：在企业微信后台 我的企业 -> 🛰️插件 中，使用个人🛰️扫描邀请二维码。这时候打开🛰️，找到刚才创建的企业应用，发一条消息试试——龙虾回应了，就说明它已经住进你的🛰️了。有一点需要说明：🛰️里这个智能体不能被拉进群聊，只能单独对话。因为它本质上是一个企业应用，不是一个账号。如果你需要在群里用，企业🛰️那边是可以的。龙虾养进来了，但有几件事得提前说清楚。第一，权限能给小就给小。 OpenClaw 拥有和你一样的系统权限，理论上它能操作你授权给它的一切。所以第一次用，建议先拿一个测试邮箱、测试文件夹试水，别上来就把最重要的东西交给它。确认它的行为符合预期之后，再逐步扩大授权范围。第二，重要操作前做好备份。 OpenClaw 在处理大量信息时，有概率“遗忘”之前的安全指令——这不是bug，是大语言模型的底层机制决定的。前面 Meta 安全总监的故事就是前车之鉴。凡是涉及邮件批量操作、文件整理这类“不可逆”的任务，先备份，再放行。第三，记住紧急停止命令。 如果发现龙虾跑偏了，在🛰️里发送 `/stop`，可以立即中断它正在执行的任务。这个命令建议提前记下来，关键时刻能救命。第四，别让它自己和别的AI说话。 OpenClaw 支持 Agent 之间互相通信，但这个功能目前风险较高——两个AI互相对话很容易产生不可预期的行为。初期使用建议关闭这个选项，等你对它足够熟悉之后再考虑开放。
