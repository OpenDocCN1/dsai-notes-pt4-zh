
# 给年轻人的一点话

> 来源：[https://docs.feishu.cn/docx/J2TEdJu7BovTWbx3NqoclxHXnqg](https://docs.feishu.cn/docx/J2TEdJu7BovTWbx3NqoclxHXnqg)

不必刻意追求那些过度复杂或对经验要求极高的领域，这些领域很可能会让初入职场的你感到沉重。

相反，**去找经验可能成为包袱的领域**，专注于开发对年轻人有实际用处的产品，面向消费者的应用（ToC）可能更为合适。避免那些需要深厚的人脉关系、高深技术能力或丰富经验（比如芯片设计）的行业。

关键在于创造人们需要的东西，我们需要思考的方式不同于常规，不必过分遵循既定规则。如果你的兴趣在于学术研究，那么追求成为一名教授可能是更好的选择。
