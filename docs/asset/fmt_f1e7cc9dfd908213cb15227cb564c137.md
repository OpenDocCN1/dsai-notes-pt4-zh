
# 隐私计算的应用情况

> 来源：[https://docs.feishu.cn/docx/G24GdHDFcokrGyxeeWEcWckfnXb](https://docs.feishu.cn/docx/G24GdHDFcokrGyxeeWEcWckfnXb)

**-问：**隐私计算现在商业情况如何？

**-答1：**数交所在用。

**-答2：**大厂们想对外卖用户画像数据，也在用这个吧。

**-答3：**但上海数交所的有一点对企业来说可能不太好的是，每次挂产品都要自己委托第三方律师出合规评估意见，广州就不用企业花钱，广州数交所自己帮忙评。不然上数交所能不能卖钱不知道，先花一笔钱，从老板角度肯定想着那就再等等，不利于数交所推广。

**-答4：**现在缺公信力，或者说是交易对手间的互信，自评可能要很以后了。上数这不是还有名嘛，不一定只图利，看是不是对公司有价值了。

**-答5：**说到这个合规评估，见到有律师收个一两万，直接按模板签字的服务方案。就当前的数据质量跟采集情况来看，可能还不到自评的时候。
