## `MCP` 的工作原理

`MCP` 由多个 `MCP Server` 组成，每个 `Server` 负责特定任务。

**例如：**

+ 浏览器操作（如读取网页内容）

+ 文档处理（如编辑和解析本地文档）

+ 代码管理（如操作 `Git` 仓库）

**但问题来了：**当 AI 要执行的任务越来越重（比如 3D 建模、大数据清洗），普通电脑的算力根本扛不住。

那么为什么不让 AI 直接学会操作云电脑呢？

> 要算力有算力，还能连带解决数据安全问题。

## 云电脑 `MCP` 的三个适配优势

相比传统 `MCP` 工具，`AgentBay` 更像是为智能体开发插上涡轮的加速引擎。

**优势集中体现在三大核心能力：**

### 弹性算力：开发环境云端即开即用

`AgentBay` 将开发环境完全托管于云端，按需调度 GPU/CPU，解决本地算力不足的问题：

> 支持一键创建带显卡的虚拟工作站，预装 `PR`、`AE` 等软件

> 任务结束自动释放资源，按使用时长计费

**某游戏公司实测：**使用 `AgentBay` 渲染 3A 场景，成本降低 60%，速度提升 2 倍。

### 工具即服务：无需配置，开箱即用

> `AgentBay` 提供完整工具链，无需本地安装环境：

> 内置 `Python`、`命令行`、`浏览器`、`文件系统`等开发组件

> `MCP` 工具支持一键运行，零代码、零配置上手

> 快速搭建复杂工作流，极大简化开发流程

一位用户形容：“它把‘调包’这件事做成了平台级服务。”

### 安全隔离：数据全生命周期可控

为解决云端隐私顾虑，`AgentBay` 实现了原子级数据隔离：

> 每个任务运行在独立沙箱中，结束即自动清除数据

> 所有操作通过 `ASP` 协议实时投影至本地，数据不上云

> 支持“阅后即焚”，最大程度保障数据安全

`AgentBay` 正在重塑智能体开发的基础设施，让开发更轻、更快、更安全。可以直接在 `AgentBay` 运行带有安全风险的代码，实时查看运行状态。

> 在云电脑 `MCP` 中，AI `大模型`将接受人类的请求命令，然后自动生成查询/操作指令，像一个真人一样使用内置的浏览器、终端，甚至是基于内置的 `Python` 环境进行沙盒测试。完成人类的指令或要求，返回结果。

## 安装路线图

为了防止你觉得这事太复杂而劝退，这是完整的路线图，并且每个步骤我都会列出进度条。

### 安装支持 `MCP` 的客户端 - 进度 40%

本文用免费的 `VS Code` + `Cline` 插件来一步步安装。

+ 下载并安装 `VS Code`。

+ 在 `VS Code` 的 `Extensions`（插件）市场搜索并安装 `Cline`。

![](img/20a1acb9c49e970201d67396a58d09c4.png)

**配置 AI 模型：**

+ 选择 `DeepSeek` 作为模型提供商。

![](img/3544c294beba68409bc874b0d2009732.png)

+ 在 `VS Code` 里选择 `deepseek-chat`，输入你在上文中申请的 `Key`。当然你也可以使用 `deepseek-r1`，我只是嫌它每次使用工具还要思考一遍，太内耗太慢了。

![](img/740c97d67b914a2f998c0d672ef011ce.png)

### 安装云电脑 `MCP` - 进度 80%

#### `SSE` 远程安装（推荐）

使用 `SSE` 远程安装 `MCP` 的方式的优势在于直接安装，无需在本地安装开发依赖环境。

> 在 `Cline` 内点击 `MCP Server` 按钮，打开 `MCP Server Remote Servers`。

`Server Name` 填写 `wuying_mcp_server`。

点击 `Add Server` 即可启用。为了避免和其它 `MCP` 服务混用，建议在 `Installed` 页关闭其它服务。

![](img/3f50ef25689314ef671f392c28a768ef.png)

+ **手动方式（可选）**

> 如果已经远程安装云服务 `MCP`，就不用看这一部分内容了。

参考下图，进入 `Cline` `MCP` 服务的配置页。

![](img/ab81a5e6a192403356daafa7d410abae.png)

> 点击后左侧会跳出一个文件编辑页，这是控制 `Cline` 所能够访问的 `MCP` 服务配置页。

**可以直接复制并粘贴以下代码：**

```
{
  "mcpServers": {
    "wuying-agentbay-mcp-server": {
      "args": [
        "-y",
        "wuying-agentbay-mcp-server"
      ],
      "env": {
        "APIKEY": "YOUR_API_KEY" # 替换为你自己的 Key
      },
      "command": "npx"
    }
  }
}
```

当完成这一切后，已完成 `MCP` 服务的安装！
