
# Dify

> 来源：[https://gotoaiworld.feishu.cn/docx/JNsTdVpozo7IgTxwbkscUHkfnAb](https://gotoaiworld.feishu.cn/docx/JNsTdVpozo7IgTxwbkscUHkfnAb)

## Dify 产品简介

`Dify` 是一款开源的大语言模型（LLM）应用开发平台。它融合了后端即服务（Backend as Service）和 [LLMOps](learn-more/extended-reading/what-is-llmops) 的理念，使开发者可以快速搭建生产级的生成式 AI 应用。即使你是非技术人员，也能参与到 AI 应用的定义和数据运营过程中。

由于 `Dify` 内置了构建 LLM 应用所需的关键技术栈，包括对数百个模型的支持、直观的 Prompt 编排界面、高质量的 RAG 引擎、稳健的 Agent 框架、灵活的工作流，并同时提供了一套易用的界面和 API。这为开发者节省了许多重复造轮子的时间，使其可以专注在创新和业务需求上。

### 核心定位

`Dify` 是 “AI 应用的快速生产线”，通过可视化界面和模块化组件，将大模型调用、提示词工程、工具集成、数据连接等环节标准化，让用户聚焦于业务逻辑而非技术实现。无论是企业内部助手、客服机器人，还是内容生成工具，都能通过 `Dify` 快速落地。

### 核心功能与特点

1. 可视化流程设计（低代码）

   - 提供拖拽式界面，支持通过 “节点” 组合构建 AI 应用逻辑。例如：
   - 用 “Prompt 节点” 定义模型输入提示词；
   - 用 “条件判断节点” 实现多分支逻辑（如 “用户问价格则调用数据库，问售后则转接人工”）；
   - 用 “循环节点” 处理多轮对话或批量任务（如批量生成产品描述）。
   - 非技术人员可通过界面配置完成复杂流程，开发者也可通过代码扩展自定义节点。

2. 多模型兼容与灵活调用

   - 支持主流大模型：兼容 OpenAI（GPT-3.5/4）、Anthropic（Claude）、阿里云通义千问等闭源模型，以及 Llama 3、Mistral 等开源模型（可结合 vLLM、Ollama 等部署工具本地运行）。
   - 模型切换零成本：同一应用可无缝切换不同模型，便于测试效果或降低成本（如用开源模型替代闭源 API）。

3. 工具集成与外部能力扩展

   - 内置丰富工具组件：支持调用数据库（MySQL、MongoDB）、API 接口（如天气查询、快递追踪）、文件系统（读取 PDF/Excel）、代码解释器（执行 Python 计算）等。
   - 示例：构建 “销售助手” 时，可让模型自动调用 CRM 数据库查询客户信息，再生成个性化邮件。

4. 数据管理与上下文理解

   - 内置向量数据库：支持导入文档（PDF、TXT 等），自动转化为向量存储，让模型能基于私有数据回答（如 “基于公司手册解释报销流程”）。
   - 上下文记忆：自动维护对话历史，支持长对话场景（如多轮客服咨询）。

5. 快速部署与多端适配

   - 一键生成多种形态：部署为 Web 应用、API 服务（兼容 OpenAI 格式）、聊天插件（如 Slack、Discord），或嵌入现有系统（通过 iframe 或 SDK）。
   - 企业级支持：支持私有化部署（数据本地化）、用户权限管理、操作日志审计，满足金融、医疗等行业的合规需求。

6. 开源与可扩展性

   - 代码完全开源（MIT 协议），可二次开发或定制功能（如集成企业内部工具、优化模型调用逻辑）。
   - 活跃社区：提供丰富插件和模板（如客服机器人模板、文档问答模板），降低重复开发成本。

### 典型应用场景

- 企业内部助手：HR 助手（查询考勤、政策）、IT 支持（故障排查指引），通过集成企业内网数据实现精准响应。
- 客服自动化：电商客服机器人，自动调用订单系统查询物流，结合知识库解答售后问题，复杂场景转接人工。
- 内容生成工具：营销文案生成器（输入产品信息，自动生成朋友圈文案、短视频脚本）、报告助手（从 Excel 数据生成分析报告）。
- 开发者工具：快速验证 AI 应用原型（如测试不同提示词效果），再通过 API 集成到正式系统。

### 基础使用流程

1. 在 `Dify` 界面创建应用（选择 “对话”“工作流” 或 “Agent” 模式）；
2. 配置模型（选择 GPT-4、Llama 3 等）和提示词模板；
3. 拖拽节点添加逻辑（如调用工具、条件判断）；
4. 测试应用效果（实时对话调试）；
5. 部署为 Web 应用或 API 服务，供内部或外部使用。

### 优势总结

- 低门槛：非技术人员可通过可视化界面构建 AI 应用，开发效率提升 5-10 倍。
- 灵活性：支持从简单对话到复杂工作流，兼容多种模型和工具，满足不同场景需求。
- 开源可控：可私有化部署，数据不依赖第三方，适合对隐私敏感的企业。
- 生态丰富：与主流模型、数据库、API 工具无缝集成，避免重复造轮子。
