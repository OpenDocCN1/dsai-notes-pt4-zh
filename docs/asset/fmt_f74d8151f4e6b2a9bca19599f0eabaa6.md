## 二、思路（资料和素材取材于互联网）

> 女频嘛，咱也就不藏着掖着了，爱情是绝对的主体，其地位就如同升级之于男频一样。
>
> 当然也有淡化甚至没有爱情的，但这个我们之后聊。
>
> 在爱情的主题下，主要分为两个大主题：纯爱(耽美)/言情。
>
> 言情很好懂啊，纯爱则不是老哥们日常聊的那个‘纯纯的恋爱’，而是主要代表‘男男关系’。
>
> 纯爱准确的说不止包括男男，考虑到各位老哥的接受程度，本贴只讲言情不讲纯爱，如果有少数老哥也想看纯爱的科普........其实女频的男男和男女没什么本质区别。
>
> 无论女频男频，本质都是网文，要义都是爽，至少对于大多数作品来说都是这样的。
>
> 所以女频的恋爱关系经常会优惠于女性，也就是在一段恋爱关系中使女性有意无意的受惠，而使伴侣有意无意的付出。
>
> 我并无意批判这个现象，因为男频也是一个道理，本质上是为了服务自己的读者。
>
> 我在这里罗列一下下文分类中频繁出现这类情节的tag
>
> − ‘女性受惠而伴侣付出类型的tag’ ...女尊、舔狗、养鱼、火葬场
>
> 在女频的生态位中，被最多人认可的其实是剧情和感情兼具的长篇剧情文章以及正常感情为主的文章。
>
> 过于注重撕逼或者对伴侣过于不友好的类型，虽然有大量的厕纸作品，但是很少能够被广泛的认可。
>
> 从这点上看，其实男频和女频的顶端生态位很类似，只是男性的升级线或多或少的被转化成了女性的情感线罢了。
>
> 所以，女频生态总结(很主观)：

+ 顶端以剧情和文笔过关，毒性很少的文章为主
+ 中层则充斥着各类细分分类的作品，也会有很多主题为撕逼/虐主角/虐主角另一半等不和谐因素的作品
+ 底端则什么都有，突出一个群魔乱舞，甚至是毁三观（囧）

> 分类的依据和食用说明：
>
> 我的分类参考了晋江的官方分类，但是有所改动。
>
> 一是完全照搬意义不大，很多背景方面的东西男频也有，没啥意义。
>
> 二是一些女频独有的tag又分的太细，不适合科普文章。
>
> 所以我自己大概总结了一些一些比较重要的背景或者是著名老梗，tag分的很不科学，请见谅。
>
> 我一开始还打算去晋江排行榜上一本本看文案来分析，后来实在太折磨了，遂作罢。
>
> 这一套分类主要也是为了大略的介绍一下女频的情况，所以真的很不科学。

+ 文章类型：我也不知道该叫啥，反正是一些著名老梗或者其他类别的tag，因为比较出名或者是经久不衰所以我单拎出来提一嘴。
+ 穿越大类：男女通吃的穿越，大概介绍一下整个穿越类的细分以及同样题材在男女频的不同。
+ 爱情关系：大概把网文里主流的爱情关系罗列了一下，主要用于描述女主和男主之间的情感类型。
+ 以上tag并不互斥，举例：一本穿书的粉丝类型正常恋爱文。

### 文章类型

+ **咸鱼：** 不太了解男频是不是有这个类型，但女频有一些(不算很多)。主旨要义是主角快乐躺平，然后依靠‘其实很强的实力’、‘其他人的善意’或者‘他人的爱慕’活得愉快。有基本上躺平整本书的，也有躺半本然后支楞起来的。

+ **女尊：** 一般为古代背景，反转世界。简单的说就是男女地位互换，女的当官打仗男的在家，女的三妻四妾男的是妻妾。有些作品里男的能怀孕，甚至有的作品里女的有吉儿，而男的吉儿.....大多数应该是有吉儿的。(我不咋看女尊)

+ **失忆：** 著名老梗，不用多介绍了。近些年统治力有所下降，但仍然是一个好用的桥段，火葬场/替身类作品常用情节。

+ **姐妹：** 并不是姐妹情深，而是姐妹撕逼，还包括了闺蜜撕逼等小类别。主题就是父母偏心+姐妹的道德败坏以及主角的打脸。还有所谓的变体‘真假千金’——也就是狸猫换太子，家里小孩被换了，多年后找回真孩子的狗血剧情。依据作品不同，真假千金分别作为主角和正面人物，突出一个扭曲

+ **明星：** 懂得都懂，主角是明星的娱乐圈作品，大部分是和其他明星谈恋爱，少量会和经纪人之类的谈。听说会有人改编真实明星的事迹拿来写文，不过我不看娱乐圈文也不追星，所以我也不清楚。

+ **粉丝：** 懂得都懂，上面那个的小妹，主角是非明星的娱乐圈作品。有些是粉丝，有些是经纪人化妆师什么的，还有的是女主是娱乐公司总裁，精神主旨同上。

### 穿越大类

+ **重生：** 老朋友了，主要分两大类(有的时候这两大类互相渗透)。第一类和男频很类似，主角穿越后利用信息差开挂，有的还会有‘前世我有眼无珠和A谈恋爱，忽视了舔狗/看起来不咋样的B，这次我懂啦，选B这类剧情。还有一类不止主角穿越，还有别人穿越，其他穿越者多为曾对主角不好(或者没能救下主角)，在这辈子决定幡然悔悟/就地黑化，和火葬场分类有所重合。

+ **穿书：** 本质是一种开了未来视挂的穿越，女频有的时候会套娃，穿越套着别人穿书、穿书套着别人重生，突出一个贵圈真乱。这个门类也经常出现各种系统文。

+ **穿越：** 朴素的穿越，朴素的味道。女频里的穿越，尤其是穿越古代不止有参与权谋改变时代的，还有很多开店做胭脂/茶/奶茶/美食的作品。

+ **系统：** 突出一个玩儿，分为给土著发系统、给穿越者发系统，给重生者发系统。有些文章里男女主都有系统，我还见过系统之间谈恋爱的

+ **快穿：** 和无限流很像，大多数为穿越者依赖系统不断完成任务然后在各个世界中穿越，大多数为魂穿，根据每个世界的长短不同还分为快穿和慢穿。经常能凑齐各种背景，并且主角通常扮演同类型角色，例如：都扮演炮灰、都扮演小白花式无害角色之类的。

### 爱情关系

+ **正常恋爱：** 没啥好说的，有些比较甜，有些比较曲折而已。那种轻度的有小三、有闺蜜或者有人搞事情的都可以归到这类。朴实无华，但很强。

+ **帮扶：** 没有上一个那么火，但是某种程度上是好作品的密码。既有伴侣互相帮助打脸装逼的，也有互相扶持艰难求生的。如果有老哥对女频文感兴趣，可以从这类文章入手，可能会比较舒适一点。(未来幻想和玄幻分类中帮扶向会稍微多一些)

+ **舔狗：** 唉，没啥可说的。女频一般不会写的特别露骨，具体表现主要是‘无缘无故的掏心窝子的爱’。更多作为一种配角元素或者部分桥段出现。

+ **养鱼：** 主要描写主角因为某种原因(乐意/系统任务)开始与多个人进入暧昧/恋爱关系，并且努力维持各个鱼彼此不相见的故事。突出一个扭曲，图一乐就算了，搞笑类型的养鱼文读起来会稍好一些

+ **替身：** 男主角/女主角因为某些原因心里有一个无法磨灭的前任(男神/女神)，另一半因为长得像而作为代替品，一般后期会直接转入火葬场。突出一个愈发扭曲

+ **火葬场（包括变种什么死人文学）：** 近些年被总结出的新标签，简而言之主要就是男方曾经因为某种原因一直伤害/漠视女方，女方经历了反复折磨之后决心jojo我不做舔狗啦！男方发现没舔狗了很不适应，遂反过来当女方的舔狗，维持了舔狗守恒理论。(不是)根据文章类型不同，有些可以复合，有些不行。

+ **大女主：** 另外一个很适合男性阅读的女频分类。简单的说就是女频的升级流，女主摸爬滚打面对世界，性格一般也比较男性化。恋爱相对较少，精品也会多一些。我个人推荐如果想入手女频可以先从这个门类开始
