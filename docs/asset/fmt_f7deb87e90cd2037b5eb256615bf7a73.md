As part of the Study, this Report asks: How can data-intensive activities and technologies that have an impact on individuals be conducted in a fair and ethical manner while achieving the desired benefits?

This Report is accompanied by the Enhanced Elements, the Data Stewardship Values, the Model EDIA and the Model Oversight Process. Altogether the documents accompanying this Report provide a workable framework encompassing data-privacy values and ethics along with fairness suitable for flexible adoption for the whole life cycle in processing personal data.

In order to help implement the Enhanced Elements and the Values, a Model EDIA and a Process Oversight Model have been drafted.

### 《應用人工智能的高層次原則》

香港金融管理局，《應用人工智能的高層次原則》 (2019)

`https://www.hkma.gov.hk/media/chi/doc/key-information/guidelines-and-circular/2019/20191101c1.pdf`

金管局明白過份規限或硬性的規定，或會窒礙人工智能相關科技進一步發展，因此金管局將這些原則制定為高層次原則。銀行可按情況相稱地採納這些原則，以反映其人工智能應用程式的性質及所涉風險水平。

1. 董事局及高级管理层须为应用人工智能所引致的结果负责
2. 银行应确保相关开发人员具备所需的专业能力及经验
3. 银行应于设计阶段采取足够措施，确保应用程式具适当程度的可解释性，与有关程式的重要性相称。
4. 银行应制定有效的数据管治框架，确保使用高质量和相关的数据。
5. 银行应严格核实及测试已受训的人工智能模型，确保准确合适才投入运作使用。
6. 人工智能应用程式的使用结果应可以接受持续稽查，并保存记录
7. 对第三方供应商实施有效的管理监察
8. 在提供相关服务前，向消费者披露该服务是以人工智能技术推动和当中所涉及的风险
9. 定期检视及持续监察，遵守数据保护规定，实施有效的网络安全措施，制定风险缓减措施及应变计划。

**建議措施：**

![](img/cf9299f0d52691f0a6819e2e56b80820.png)

- 人工智能策略及管治；
- 機構應制定人工智能策略及成立人工智能管治委員會（或類似組織），以引領人工智能的開發及使用。
- 機構應制定人工智能策略。人工智能策略亦應包含使用人工智能的目的以及如何使用人工智能的相關指引。

- 人工智能模型的開發及人工智能系統的管理；及
- 與持份者的溝通及交流。

一般來說，機構應以風險為本的方式開發、管理及使用人工智能系統。因此在考慮及採用下述建議措施時，機構應務求所採取的措施與人工智能系統可能構成的風險相稱。

#### 核心二：风险为本的人为监督

在管理人工智能系統方面，應採取風險為本的方式。在這方面，機構需要就開發及使用人工智能進行全面的風險評估，有系統地識別、分析及評估風險，包括私隱風險。對於高風險的人工智能系統，機構應在整個人工智能的生命周期內建立及持續實施風險管理機制，並將相關資料記錄存檔。

風險評估的主要目的是讓機構採取適當的風險管理措施，從而減低已識別的風險。

**人為監督**是減低使用人工智能的風險的主要措施。人工智能系統的風險評估結果會顯示使用人工智能系統時所需的適當人為監督的程度。

風險較高（即很可能對持份者造成重大影響）的人工智能系統，須有較高程度的人為監督︰

#### 核心三：全生命周期合规

![](img/3766f28d18f0ba7a8e2365b0b0bdc38a.png)

**准备数据阶段：**

确保数据质素（即大陆称的“素质”，语境中的意思与“质量”一样），數據質素對人工智能系統的公平性至為重要。

- 機構必須採取措施，確保遵從《私隱條例》的規定
- 在開發及使用人工智能時減少所使用的個人資料數量，可減低私隱風險。
- 确保数据质量（公平性）
- 妥善記錄處理數據的情況

**开发模型阶段：**

機構應了解不同機器學習演算法的特點，揀選符合其需要的演算法。

**人工智能管理阶段：**

機構應不斷監察及檢視人工智能系統，因為應用人工智能系統的風險因素，包括訓練數據的相關性及人工智能模型的可靠性，會隨著時間而改變。

定期进行风险评估、定期检视、定期新數據調校及再訓練人工智能模型

#### 核心四：與持份者的溝通及交流

持份者应该是取的stakeholder的意思

開發及使用人工智能系統的機構應與持份者（尤其是個別的消費者及規管者）有效地溝通及交流。有效的溝通亦是建立信任所必需的。

主要原則︰透明度與可解釋性

**【沟通】**需要披露的：

（1）是否使用人工智能系統；
（2）使用人工智能系統的目的、益處、限制及效果，除非有關披露會對商業敏感資訊造成損害
（3）人工智能系統的風險評估結果，除非有關披露會對商業敏感資訊造成損害。

**【交流】**

（1）機構亦應向個人提供途徑讓他們改正不準確之處、作出反饋、尋求解釋、要求人為介入及／或退出使用人工智能（如適用）。
（2）在為人工智能作出或輔助作出的決策提供解釋

#### 香港监管者认为的高风险AI

人工智能应用：

- 是否在公众严格关注和/或经常提起诉讼的领域内？
- 例如对个人的日常生活和隐私产生重大影响的IoT应用程序
- 是否应用于新的（社会）领域（即人工智能尚未在香港使用的领域）？
- 是否具有高度自主性？是否使用在复杂的场景中？是否会做出对个人或实体有重大影响或对其产生法律后果的自动化决策？
- 是否会处理敏感个人信息？
- 是否做出复杂的决策？
- 是否涉及系统性的观察或监控？（包括视频监控、网络行为跟踪）
- 是否涉及对个人的评估或评分？
- 个人信息是否会被大规模处理？
