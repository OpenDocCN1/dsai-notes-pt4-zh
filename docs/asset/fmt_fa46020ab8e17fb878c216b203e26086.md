## 引言

2026 年 3 月，一场"全民养虾"的热潮正在席卷整个中文互联网。

OpenClaw——这个以龙虾为吉祥物的开源 AI Agent 项目，在不到三个月的时间里从 9,000 Star 飙升到约 32 万（~320K），一举超越 `React` 成为 `GitHub` 有史以来 Star 数最高的软件项目。这只"龙虾"点燃了一场空前的 AI Agent 竞赛：腾讯、字节、阿里、百度、华为、小米、智谱、月之暗面……几乎所有你叫得出名字的国内科技公司，都在 2026 年 3 月密集推出了自己的 OpenClaw 版本。加上国际企业版和开源社区版，整个生态已经有 27+ 个衍生项目。

如果你现在还没听说过 OpenClaw，那说明你可能错过了 2026 年最重要的技术浪潮之一。它不是一个小众极客玩具——从产品经理到内容运营，从独立开发者到金融分析师，各行各业的人都在讨论如何用 AI Agent 来提升自己的工作效率。不夸张地说，这是继 `ChatGPT` 之后最具影响力的 AI 应用形态。

然而，面对铺天盖地的信息，你大概率正处于这样一种状态：打开知乎搜"OpenClaw"，出来一堆国产版本推荐——ArkClaw、KimiClaw、QClaw、AutoClaw……每个都说自己最好用，你看得头皮发麻。再到📕一搜，又是各种"保姆级教程""三分钟部署"，但每篇用的版本都不一样。你想问一句"到底该选哪个"，评论区里又吵成一片。

这一章，就是来终结这种混乱的。我们用一张"全景地图"帮你看清整个生态——谁是谁，各有什么绝活，什么场景该选谁。就像逛一个大型百货商场，我们先拿到楼层导览图，然后一层一层逛过去，最后在出口处拿到一份清晰的场景推荐表。

## 1.1 OpenClaw 原版速览

在聊衍生产品之前，我们先花两分钟搞清楚"源头"长什么样。只有理解了原版的能力边界，才能看懂衍生产品在"补"什么、在"改"什么。

### OpenClaw 是什么

OpenClaw 是一个开源的个人 AI 智能体（Agent）框架，`MIT` 协议，`GitHub` ~320K Stars。你可以把它理解为——给大语言模型装上"手脚"的工具箱。大模型负责"想"，OpenClaw 负责"做"：执行命令、操作文件、浏览网页、收发消息、记住你说过的话。

它不是一个聊天机器人，而是一个**能行动的 AI 助手**。你说"帮我把这个文件整理一下"，它不只是告诉你怎么做，而是真的动手去做。

> 🔗 官网：`https://openclaw.ai`

核心能力一览：

| 能力 | 说明 | 为什么重要 |
| --- | --- | --- |
| **持久记忆** | 跨会话保留上下文，AI 能记住上次聊到哪里 | 不再每次对话都从零开始，真正的"私人助理"体验 |
| **Shell 命令执行** | 直接操控电脑——运行脚本、管理文件、调用系统命令 | 从"嘴上说说"变成"动手去做" |
| **浏览器操作** | 像人一样浏览网页、填写表单、提取数据 | 自动化网络任务，不再手动重复操作 |
| **20+ 消息通道** | WhatsApp / Telegram / Discord / Slack / 飞书 / 钉钉 / 🛰️…… | 在你常用的 IM 中直接与 AI 对话 |
| **定时任务** | 7x24 自动化工作流，不需要你盯着 | 真正的"数字员工"——你睡觉它干活 |
| **ClawHub 技能市场** | 13,000+ 即装即用的 `Skills`，类似 `App Store` | 社区共享的能力，装上就能用 |

最新版本：`v2026.3.13`（采用日历版本号 `CalVer`，看版本号就知道发布日期）。

### 为什么会有这么多衍生版本？

看到这里你可能会问：原版已经这么强了，为什么还要搞这么多衍生版？这不是重复造轮子吗？

这个问题的答案，在 2026 年 3 月和半年前已经截然不同了。

事实上，原版 OpenClaw 如今已经做了大量中国用户友好的改进：`openclaw-cn` 社区版提供了完整中文化，飞书已有官方插件，国内主流模型（`DeepSeek`、`Qwen`、`GLM` 等）通过 `SiliconCloud` 即可接入。所以"原版不支持中文""原版只能用海外模型"这些早期的痛点，现在已经不再成立。

那为什么衍生产品还在不断涌现？核心原因是两个：

**第一，降低门槛**。原版 OpenClaw 的完整部署仍然需要 `Node.js`、`npm`、`API Key` 配置、命令行操作——这对技术人员来说不难，但对普通用户而言仍是一道门槛。衍生产品把这些步骤封装成"打开网页就能用"或"下载双击就能用"，让 `AI Agent` 触达更广泛的人群。

**第二，商业化战略**。每家大厂做自己的 OpenClaw 版本，本质上是在抢占 `AI Agent` 这个新入口。字节做 ArkClaw 是为了把用户留在飞书生态，腾讯做 QClaw 是为了强化🛰️的"超级 App"地位，阿里做 JVS Claw 是为了绑定云服务客户。对大厂来说，谁掌握了 `AI Agent` 的入口，谁就掌握了下一代人机交互的流量。

| 驱动力 | 具体表现 | 代表产品 |
| --- | --- | --- |
| **降低使用门槛** | 零部署云端版、一键安装包、手机 `App` | StepClaw、AutoClaw、MaxClaw |
| **绑定自有生态** | 深度整合自家 `IM` / 云服务 / 模型 | ArkClaw（飞书）、QClaw（🛰️）、JVS Claw（阿里云） |
| **抢占 `Agent` 入口** | 系统级嵌入，成为 `OS` 的一部分 | MiClaw（小米 `HyperOS`）、小艺 Claw（鸿蒙） |
| **垂直场景深耕** | 针对特定行业做深度适配 | MaxClaw（内容/金融）、DuClaw（搜索） |
| **企业安全合规** | 沙箱隔离、数据脱敏、私有化部署 | NemoClaw（`NVIDIA`）、LinClaw（七牛云） |

理解了这些驱动力，后面看每个衍生产品时你就会发现——它们不是在"山寨"OpenClaw，而是在各自的赛道上做差异化竞争。就像安卓手机厂商都基于同一个开源系统，但小米做性价比、华为做影像、`OPPO` 做快充——每家都有自己的战略考量。

## 1.2 三大阵营：看清生态格局

面对 27+ 个产品，最怕的是"看花了眼"。所以我们**先用一个简单的**分类法把整个生态理清楚——三大阵营分类法。

就像逛百货商场，我们先看楼层导览图，再决定去哪层逛。

### 阵营一：大厂云端托管

**代表产品**：ArkClaw（字节）、KimiClaw（月之暗面）、MaxClaw（MiniMax）、StepClaw（阶跃星辰）、DuClaw（百度）、JVS Claw（阿里云）

**共同特点**：

+   零部署——打开网页或 `App` 就能用，连软件都不用装

+   云端 7x24 在线——不占你的电脑资源，关机也能运行

+   按订阅或 `Token` 收费——有的免费体验，有的需要月付

**适合谁**：不想折腾技术，想"打开就用"的人。如果你听到`Node.js`、`npm`会头疼，这个阵营就是为你准备的。

> 🔗 ArkClaw：`https://www.volcengine.com/experience/ark?mode=claw`

> 🔗 KimiClaw：`https://kimi.moonshot.cn`

### 阵营二：大厂本地安装

**代表产品**：QClaw（腾讯）、WorkBuddy（腾讯）、AutoClaw（智谱）、Molili / 莫哩哩（当贝）、EasyClaw（猎豹）

**共同特点**：

+   提供一键安装包——下载、双击、开始用

+   数据留在本地——你的对话内容和操作记录不上传云端

+   多数完全免费——不需要订阅

**适合谁**：在意数据隐私，想在自己电脑上运行的人。如果你的原则是"我的数据我做主"，本地安装就是你的选择。

> 🔗 QClaw：`https://qclaw.qq.com`

### 阵营三：开源自部署

**代表产品**：`openclaw-cn`（中文社区）、LinClaw（七牛云）、CoPaw（阿里通义）、NemoClaw（NVIDIA）、原版 OpenClaw

**共同特点**：

+   代码可审计——想看底层逻辑随时看

+   支持私有化部署——数据完全可控，想部署在哪就部署在哪

+   需要一定技术能力——至少会用命令行

**适合谁**：企业、开发者，想深度定制的人。如果你的需求是"我要完全掌控这个系统"，开源阵营就是你的天堂。

> 🔗 openclaw-cn GitHub：`https://github.com/jiulingyun/openclaw-cn`

### 三大阵营对比速览

| 维度 | 阵营一：云端托管 | 阵营二：本地安装 | 阵营三：开源自部署 |
| --- | --- | --- | --- |
| **代表产品** | ArkClaw / KimiClaw / MaxClaw | QClaw / AutoClaw / Molili | `openclaw-cn` / LinClaw / CoPaw |
| **部署难度** | 零（打开即用） | 低（双击安装） | 中~高（需命令行） |
| **数据位置** | 云端（厂商服务器） | 本地（你的电脑） | 自主可控（你说了算） |
| **费用模式** | 订阅制/`Token` 计费 | 多数免费 | 免费（模型费另算） |
| **定制空间** | 低（厂商提供什么用什么） | 低~中（有限配置项） | 高（源码级定制） |
| **适合人群** | 非技术用户 | 隐私敏感用户 | 企业/开发者 |
| **典型心态** | "我想打开就用" | "我想数据留在自己电脑上" | "我想完全掌控" |

### 设备生态维度

除了按`部署方式`分类，还可以从`设备类型`的角度看整个生态。这个视角揭示了一个值得关注的趋势——`AI Agent` 的能力正在从电脑桌面向手机系统层面渗透：

| 设备层级 | 代表产品 | 核心特点 |
| --- | --- | --- |
| **手机系统级** | MiClaw（小米）、小艺 Claw（华为）、荣耀龙虾宇宙 | 深度嵌入手机 `OS`，能调用通讯录、短信、系统 `App` |
| **手机 `App` 级** | JVS Claw、MaxClaw、StepClaw | 手机上装个 `App` 就能用，不需要系统级权限 |
| **桌面级** | QClaw、WorkBuddy、AutoClaw、LinClaw | 安装在电脑上运行，操控桌面软件和文件 |
| **纯云端** | ArkClaw、KimiClaw、DuClaw | 网页打开即用，不挑设备 |

当 `Agent` 从"你主动打开的软件"变成"手机操作系统的一部分"，它就不再是工具，而变成了随时待命的助手——这是 `Siri`、`Google Assistant` 升级方向的终极形态，只不过能力远超传统语音助手。

## 1.3 阵营一：云端托管产品详解

云端托管的核心卖点是**零门槛**——不需要装软件、不需要配环境、不需要懂技术。打开网页或 `App`，几分钟内就能拥有一个 7x24 在线的 `AI 助手`。我们来逐一看这个阵营里的六个选手。

### ArkClaw（字节跳动 · 火山引擎）

ArkClaw 是字节跳动旗下火山引擎推出的云端 `SaaS` 版 OpenClaw。对于飞书办公的团队而言，它几乎是最自然的选择——飞书文档、日程、审批全部打通，不需要额外配置权限。

> 🔗 官网：`https://www.volcengine.com/experience/ark?mode=claw`

**核心卖点**：

+   **零安装云端模式**：打开网页即用，7x24 在线运行

+   **飞书深度集成**：无需配置权限即可处理日程安排、文档表格——这是 ArkClaw 区别于其他云端产品的最大差异化

+   `Seed 2.0` 深度协同：字节自家大模型与 ArkClaw 联调优化，复杂任务表现突出

+   **内置 `Token` 优化**：平台层面帮你降低使用成本

**定价**（2026 年 3 月参考价）：

+   `Coding Plan Lite`：9.9 元起（含 7 天体验）

+   `Coding Plan Pro`：49 元/月（持续使用）

在云端阵营中，ArkClaw 的定价是最亲民的——49 元/月比 KimiClaw 的 199 元便宜四倍。对于飞书办公的团队来说，这几乎是"最省心"的入口。不过需要注意的是，它深度绑定火山引擎平台，不开源，后续如果想迁移到其他方案，成本会比较高。

### KimiClaw（月之暗面）

KimiClaw 是目前云端阵营中用户基数最大、模型能力最强的选手。背后的 `Kimi K2.5` 是万亿参数级的开源旗舰模型，在 `Agent` 场景中的表现在国产模型中数一数二。

> 🔗 官网：`https://kimi.moonshot.cn`

**核心卖点**：

+   **`Kimi K2.5` 模型**：万亿参数，原生多模态（视觉 + 文本 + 代码 + `Agent`）

+   **多 `Agent` 协作**：单任务最多 100 个"分身"并行处理 1500 步——目前衍生产品中并行能力最强的
