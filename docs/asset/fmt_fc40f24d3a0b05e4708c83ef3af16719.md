
# 探索GPT的Mention艾特功能，ChatGPT 进化中的下一代重要特性及其未来潜力

> 来源：[https://agispace.feishu.cn/docx/IzcadY8khouZo6xAGjpcPpDhnFf](https://agispace.feishu.cn/docx/IzcadY8khouZo6xAGjpcPpDhnFf)

这周末GPT那边出了一个新功能，官方专业术语叫“mention”，什么意思呢？就是在使用GPT4的时候，可以@出各种GPTs，如下图所示：

![](img/d42889c1e348700c83adc68ae4484888.png)

这样就可以直接在主对话窗口唤起各种GPTs进行使用了，就像是一次对话中具备了N个助手一样！而无需像之前那样，想要使用什么功能，还得单独打开具体的GPTs，无需在对话窗口之间进行跳转或复制粘贴内容来保持对话继续进行。对话的所有内容都保留在一个位置，使得从一项任务切换到具有不同 GPT 的另一项任务变得非常简单。

![](img/d650bd0672b35ababce5ac73b0f006fa.png)

## 想象一下可能性

借助 GPT 艾特唤起功能，可以在同一次聊天中执行更多操作。假设你正在开发一个项目。一个 GPT 可以帮助您编写代码，另一个可以设计一个很酷的图标，第三个可以帮助您部署所有内容。这就像拥有一个专家团队，一切只需艾特一下即可。

尽管看起来很简单，只是一个小小的弹出窗口，但它带来的变化却是巨大的。它使 ChatGPT 的使用变得更加智能、更加有趣。

接下来，我将分享 Twitter 上看到的尝试 GPT Mention 的大神的一些案例，他们将如何巧妙的运用这个技巧来实现一些骚操作的。

![](img/845b6312a909f3a4dc62170749317e8e.png)

推特上的这个大神，是先用GPT帮他总结一篇文章的主要内容，概括文章主旨要点，然后@他自己开发的一个GPTs，让它这个GPTs进行保存概括出来的文章主旨到他的Notion笔记里面。

![](img/f2545f1939e2d031c8689cf3911e5fa0.png)

而这个人呢，是先使用GPT的Ai PDF这个GPTs帮他阅读论文，然后在直接使用Grimoire这个GPTs帮他实现论文里面的代码。ChatGPT 提及（“@”）是一个非常巧妙的功能。它是一个强大的工具，可以同时探索不同 GPT 模型的全部功能。当我们继续见证人工智能的快速发展时，有太多的东西值得我们尝试并拥抱了。
