admin.firestore.FieldValue.serverTimestamp()

## 根因定位

让我修复 `redeemPromoCode.ts`：

Analyzed

`redeemPromoCode.ts#L1-114`

问题根源找到了！

`redeemPromoCode.ts` 没有初始化 Firebase Admin。比较一下 `deductCredits.ts`，它有这段代码：

```typescript
// Initialize Firebase Admin if not already initialized
if (!admin.apps.length) {
  admin.initializeApp();
}
```

但 `redeemPromoCode.ts` 没有。虽然在 `index.ts` 中已经初始化过了，但模块加载顺序可能导致问题。另外，更安全的做法是使用 `new Date()` 代替 `serverTimestamp()`，这样更可靠。
