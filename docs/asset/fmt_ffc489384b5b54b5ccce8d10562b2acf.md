随着人工智能技术的不断进步，其在教育领域的应用已经从传统的辅助教学工具发展到了更加复杂和深入的角色扮演教学。例如，通过模拟真实世界中的对话技巧，AI可以提供不同的场景框架，从而增强学生的实际应用能力和沟通能力。

然而，AI教育的低龄化也引发了一些争议，比如是否适合所有年龄段的学生。但随着教育部门和企业对AI教育价值的认可以及相关技术和资源的不断丰富和完善，AI在K12教育中的应用前景仍然被广泛看好。

### AI Agent基础概念

![](img/e8b1e93c008438814f9f72edcb6a724e.png)

![](img/4c5eea11ae7d3eb29d3820bb8120980e.png)

![](img/3f3c5d8b0336e95a7d7fdeacb34c3a49.png)

![](img/b4522e32ff006baa8ecde5bb9115f3cc.png)

https://arxiv.org/abs/2309.07864

OpenAI应用研究主管翁丽莲(Lilian Weng)撰写过一篇blog: LLM Powered Autonomous Agents，将 Agents 定义为LLM + memory + planning skills + tool use，即大语言模型、记忆、任务规划、工具使用的集合。

其中，LLM是Agent的大脑，属于“中枢”模型，要求有以下3种能力：

1. planning skills：对问题进行拆解得到解决路径，既进行任务规划

1. tool use：评估自己所需的工具，进行工具选择，并生成调用工具请求

1. memory：短期记忆包括工具的返回值，已经完成的推理路径；长期记忆包括可访问的外部长期存储，例如知识库
