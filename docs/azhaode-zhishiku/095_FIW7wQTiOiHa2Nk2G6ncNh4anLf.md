构建用户对未来家的想象，是家装家居多年来持续探索的方向， 如今 利用AI 技术，我们设计了一款搭配产品， 用户只需提供心仪的 商品 图 片，选择 自 己想要的风格， 便可快速生成一张 围绕该商品的场景 搭配， 当前主要面向商家，未来 希望人人都可以 用它来 装修自己的家 。

# **#01**

# **项目背景**

“ 家作”是由AI驱动、致力于为家装家居商家带来产品和场景灵感的创意工具。覆盖住宅家具与家居用品，支持场景棚拍与图片编辑，比传统降低90%以上的人力或财务成本。

# **#02**

# **设计特点**

**1）沉浸感官体验。 **整体界面主要采用 深色沉浸式外观，突显看图效果，让工作流更专注，其次行动点使用荧光绿色，代表生图过程中的快速，也传递一种年轻与生机；

![](img/dd95003b2983450f9e8059bd98af61ff.png)

▲ 沉浸感官

**2）高效界面布局。 **左编辑右结果，满足普适的阅读顺序。 左编辑，采取数字和模块化分组，强化操作步骤感；右结果，采用流式布局，一次出4张结果，兼顾25%的好图率与浏览效率；

![](img/ae631e7dd11a4597c14a20ba4e36f5e6.png)

▲ 高效布局

**3） 缓解等待焦虑 。 **分阶段出图，先出低分辨率，用户挑选后，再输出高分辨率，缓解整体等待时长；

![](img/6254235fe8d5c071c09732512272d73b.png)

▲ 缓解等待

**4）个性化编辑。 **支持商品的增加、删除与替换，提升出图后的二次编辑能力，另外在功能介绍上，我们也采取动图说明，提升产品功能的传递效率；

![](img/9745b4f98ad3a7c90a2760867dfbe16f.png)

▲ 个性化编辑

**5）品牌设计。 ** “家作”谐音同“佳作”，寓意是让人人生成的作品都是佳作，字母LOGO为三角形的屋顶，象征着家，并将字母AI巧妙地融入到品牌LOGO中。

![](img/1f3306a4046b1850838d2d683ca10283.png)

▲ 品牌设计

**生图流程。 **  生图的核心逻辑是扩图。与主流的差异是，我们会在淘宝海量的商品上训练模型，再结合行业运营对风格趋势的把控，在根据商品的特征及用户的选择， 先搭配软装，再搭配硬装环境，最后渲染出图。

![](img/2b906534509a47ac233ca394c105deab.png)

▲ 生图流程

# **#03**

# **商家使用**

目前已有数千个家居商家使用我们的产品，我们与部分核心商家一起打磨产品，调研他们的核心工作流，主要分5步：“产品设计、训练风格、图像生成、美工修图、主图打标”，目前AI能力主要应用在“训练风格”与“图像生成”，未来我们希望家作可以一站式完成商家的出图工作。

![](img/43e44b077c0a93ce4afb6974dfeef7bd.png)

▲ 商 家工作流程

商家较多应用在2个场景中，场景1： 多人多面投放。 主题沙发不变，沙发的背景风格多 变，素材按照人群喜好来投放。 场景2： 测试场景反向棚拍。 针对头部商家，他们会生成多个虚拟场景，投放至线上，选取点击率高的，反向搭棚拍摄，提升棚拍效率。

![](img/e7fcb2e58d551b8ac1b767315e1c17bb.png)

▲ 商家主要应用场景

商家目前遇到的共性问题主要为2个。问题1： 怎样避免同质化问题？解法： 让AI学习商家的3D素材风格/实拍风格，获得更接近商家预置风格。

![](img/4768964384668af57675efbf613308e0.png)

▲训练自定义模型

问题2： 怎样出一张好看的图？ 解法： 商品白底图质量决定最终生成效果好坏。 提升白底图质量，要求 曝 光充分、层次分明、搭配丰富、颜色干净，简单说 白底图较“真”，那么生成出来的场景也为“真”。

![](img/1c99e562634efb273443614bd49a18f4.png)

▲ 生成好图经验

# **#04**

# **未来规划**

围绕效果图，纵向细化出图效率与出图质量，横向结合商家服务上下游扩展功能，上游商品定制，下游图生视频。最终愿景：希望家作致力于家装家居行业产品设计、包装与推广的一站式智能创作平台。

![](img/954e729ffdb4699aa3ce7037b5876c9f.png)

▲ 未来规划

# **写在最后**

家装本质 在在解决“人 与居住”的关系，几年前我们一直探索用3D方式帮助用户构建未来家的想象， 如 今我们 用AI帮助用户“更快、更好、更简单”看到自己未来的家，不但探索从生效果图、到视频等多种媒体形式，而且产品受众也希望从家具设计师，到装修爱好者，最终让人人都可以自己装修房子，让装都像换衣服一样简单。
