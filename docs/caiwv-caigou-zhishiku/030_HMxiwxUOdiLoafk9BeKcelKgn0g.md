# 采购常用表格函数公式

#### **一、供应商管理类公式**

**1. 供应商自动评分**

```
=SUMPRODUCT((质量得分*40%)+(交期得分*30%)+(服务得分*30%))
```

**说明**：设置质量、交期、服务三要素权重自动计算综合得分

**2. 供应商等级划分**

```
=IF(综合得分&gt;=90,&quot;A级&quot;,IF(综合得分&gt;=80,&quot;B级&quot;,&quot;C级&quot;))
```

**效果**：自动标注供应商等级（可配合条件格式变色）

**3. 黑名单供应商筛选**

```
=FILTER(供应商表,(交货延迟次数&gt;3)*(质量投诉率&gt;5%),&quot;无&quot;)
```

**提示**：动态显示不合格供应商名单

#### **二、成本分析类公式**

**4. 采购价波动监控**

```
=([本月单价]-[上月单价])/[上月单价]
```

**应用**：自动计算价格涨跌百分比

**5. 批量采购折扣计算**

```
=IF(采购量&gt;=1000,单价*0.9,IF(采购量&gt;=500,单价*0.95,单价))
```

**示例**：500件以上95折，1000件以上9折

**6. 运输成本分摊**

```
=ROUND(总运费*（产品体积/总体积）,2)
```

**技巧**：按体积/重量比例分摊物流费用

---

#### **三、订单管理类公式**

**7. 交期预警提示**

```
=IF(剩余天数&lt;=3,&quot;紧急&quot;,IF(剩余天数&lt;=7,&quot;预警&quot;,&quot;正常&quot;))
```

**设置**：

+   剩余天数 = 交货日期-TODAY()

+   配合条件格式红黄绿三色提醒

**8. 采购订单状态跟踪**

```
=IF(AND(已交货数量=0,&quot;未开始&quot;,IF(已交货数量&lt;订单数量,&quot;进行中&quot;,&quot;已完成&quot;))
```

**进阶**：添加进度条（开始-选项卡→数据条）

**9. 缺货紧急采购标识**

```
=IF(库存量&lt;安全库存,&quot;★紧急采购&quot;,&quot;&quot;)
```

#### **四、库存管理类公式**

**10. 经济订货批量(EOQ)**

```
=ROUND(SQRT((2*年需求量*单次订货成本)/(单位库存成本)),0)
```

**参数说明**：

+   年需求量：产品年采购总量

+   单次订货成本：每次下单产生的费用

+   单位库存成本：产品单价*库存持有费率

**11. 库存周转率**

```
=销售成本/平均库存金额
```

**注意**：

+   销售成本 = 期初库存 + 采购成本 - 期末库存

+   平均库存 = (期初库存 + 期末库存)/2

**12. 呆滞库存标记**

```
=IF(最后出库日期&lt;TODAY()-180,&quot;呆滞&quot;,&quot;&quot;)
```

#### **五、对账结算类公式**

**13. 自动对账差异查找**

```
=IF(VLOOKUP(订单号,供应商对账单!A:D,4,FALSE)≠实收数量,&quot;差异&quot;,&quot;一致&quot;)
```

**原理**：跨表比对订单数量

**14. 账期到期提醒**

```
=IF(付款截止日期-TODAY()&lt;=7,&quot;即将到期&quot;,&quot;&quot;)
```

**15. 增值税计算**

```
=ROUND(含税金额/(1+税率),2)  //计算不含税价
=不含税金额*税率           //计算税额
```

#### **六、数据分析类公式**

**16. 采购品类ABC分类**

```
=IF(累计占比&lt;=80%,&quot;A类&quot;,IF(累计占比&lt;=95%,&quot;B类&quot;,&quot;C类&quot;))
```

**步骤**：

① 按采购金额降序排序

② 计算累计百分比

**17. 供应商集中度分析**

```
=SUM(LARGE(采购金额列,{1,2}))/SUM(采购金额列)
```

**解读**：计算TOP2供应商占比

**18. 价格趋势预测**

```
=FORECAST.ETS(下月日期,价格列,日期列)
```

**说明**：用指数平滑法预测未来价格

### **效率提升技巧**

1.  **批量生成采购订单号**

```
=TEXT(日期,&quot;YYMM&quot;)&amp;&quot;-&quot;&amp;ROW()-1
```

**示例**：自动生成“2407-001”格式单号

1.  **物料编码智能补全**

```
=IFERROR(VLOOKUP(&quot;*&quot;&amp;输入码&amp;&quot;*&quot;,编码表,2,0),&quot;未找到&quot;)
```

1.  **多条件筛选供应商**

```
=UNIQUE(FILTER(供应商表,(地区=&quot;华东&quot;)*(等级=&quot;A&quot;)))
```
