## 一、为什么订单跟踪是采购的核心能力？

+ 直接影响成本：延迟交付=企业停线损失，早到=库存积压资金占用

+ 供应商管理抓手：80%的供应商问题暴露在订单执行环节

+ 职场加分项：能系统跟踪订单的采购，3年内晋升概率提升57%

## 二、采购跟单全流程详解

### 阶段1：订单下发（Day 1-2）

#### 1. 订单确认书（PO）签发

**必含7要素**：

+ 物料编码+版本号（防新旧版本混淆）

+ 精确到小时的交付时间（如9月20日14:00前到厂）

+ 违约责任条款（例：延迟1小时扣款0.1%，协商设定）

+ 特殊包装要求（如防静电袋需用粉色标签）

+ 验收标准文件编号（如WI-023 外观检验规范）

+ 对账单模板（带唯一流水号防止篡改）

+ 紧急联系人清单（供应商生产/品质/物流负责人24小时电话）

**❗避坑点**：

+ 要求供应商手写签字+盖章扫描回传（防止PS伪造）

+ 同步将PO上传至公司ERP系统并@财务锁定付款条款

### 阶段2：生产跟进（Day 3-15）

#### 2. 原材料备料跟踪

**操作细节**：

+ 要求供应商每日下班前发送原材料库存日报表（含批次号/库位照片）

+ 对关键物料（如芯片）要求第三方检测报告（如SGS成分分析）

#### 3. 生产排程验证

**突击检查项**：

+ 通过供应商MES系统截图确认实际排产日期

+ 要求拍摄生产看板（重点看紧急插单情况）

+ 查验模具保养记录（预防批量不良）

#### 4. 过程质量监控

**实用工具**：

+ 首件检验报告（要求视频展示测量过程）

+ 巡检记录表（每小时记录关键参数如注塑温度）

+ 静电手环测试记录（电子件必查）

#### 5. 进度异常处理

**经典话术**：

“李经理，系统显示贵司今日计划产出5000pcs，实际入库仅3200pcs，请立即提供：

① 缺件物料清单及到货时间

② 补产计划表（需细化到每班次追产数量）

③ 明日产能保障措施

---

### 阶段3：物流追踪（Day 16-20）

#### 6. 发货前确认

**必须留证**：

+ 装箱视频（展示外箱贴标/封箱过程）

+ 车辆信息备案（车牌号+司机身份证+GPS绑定）

+ 重量比对（毛重与系统数据偏差超2%则开箱复查）

#### 7. 在途监控

**跨国订单要点**：

+ 提前确认HS编码和原产地证明

+ 要求物流商每小时更新地理围栏信息

+ 预留清关应急预案（如香港中转仓快速换单）

#### 8. 到货前准备

**内部协同SOP**：

✅ 提前24小时通知仓库预留特定卸货区（如防尘要求区域）

✅ 协调质检部校准检测设备（如拉力计归零）

✅ 准备快速入库通道（针对JIT物料）

---

### 阶段4：交付验收（Day 21）

#### 9. 到货即时查验

**5分钟快速筛查法**：

+ 外箱是否有水渍/变形（用强光手电侧照）

+ 封箱胶带刀口是否整齐（二次封装常有毛边）

+ 扫码枪验证批次号与PO一致性

#### 10. 争议处理流程

**现场取证要点**：

+ 质量问题：保留原包装状态拍照+视频记录测试过程

+ 数量短缺：双方签字确认未拆箱剩余件数

+ 单据异常：立即冻结对账单并启动财务审计

---

### 阶段5：闭环管理（Day 22-25）

#### 11. 供应商绩效更新

**数据化呈现**：

📉 OTD（按时交付率）计算公式：

（实际合格到货日期 - PO要求日期）≤0 的订单数 / 总订单数 ×100%

📉 DPPM（百万件不良率）：

退货数量 ÷ 到货总数 ×1,000,000

#### 12. 采购订单归档

**合规要求**：

+ 纸质文件：热敏纸需复印保存（防字迹消失）

+ 电子文件：哈希值存证（防后期篡改）

## 三、3大高频场景应对方法

### 场景1：供应商谎称“设备故障”拖延交期

**破解方法**：

+ 要求视频连线查看设备报警代码（提前百度代码含义）

+ 查验设备点检记录（对比历史故障时间规律）

+ 启动备份模具时同步扣罚模具转运费

### 场景2：到货后生产线投诉尺寸偏差

**责任界定技巧**：

+ 调取供应商首件确认邮件（是否经我方批准）

+ 测量未拆包装产品（排除仓储环境影响）

+ 核对检测设备校准证书有效期

### 场景3：物流显示签收但仓库未收到

**取证步骤**：

① 要求物流公司提供带时间戳的签收照片

② 比对仓库地磅数据（看是否有未登记进库重量）

③ 查询车辆北斗轨迹是否真实到厂
