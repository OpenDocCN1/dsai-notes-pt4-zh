## 🔥 啥是盈亏平衡点？

简单说就是👉 不赔不赚的采购量！

举个栗子🌰：

便利店进网红零食，进价5元/包，卖8元

房租水电每月3000，卖多少包回本？

`3000÷（8 - 5）= 1000包`！这就是盈亏平衡点！

采购时用它算清：这个价买多少才不会亏！

## 💸 用它选供应商立省20%！

电商采购手机壳案例📱：

✅ A供应商：10元/个，无起订量

✅ B供应商：8元/个，但要订5000个

怎么选？算就完事！

🔍 成本计算：

固定成本（运费+仓储）2000元

可变成本：A 10元/个，B 8元/个

📊 平衡点公式：

假设卖15元/个

👉 `A利润5元/个，平衡点=2000÷5 = 400个`

👉 `B利润7元/个，但总成本8×5000 + 2000 = 42000元`

`平衡点=42000÷7 = 6000个`

预计卖3000个选A！能卖8000个冲B！
