# 采购最容易踩的坑：只看价格，不看总成本

> 来源：[https://rxq0zfnkm77.feishu.cn/docx/YanEdL1pzot3Jyx5TtKcTE6ynJe](https://rxq0zfnkm77.feishu.cn/docx/YanEdL1pzot3Jyx5TtKcTE6ynJe)

很多采购新人刚入行时，最容易把一件事理解简单：

觉得采购成本控制，就是把价格谈低。

这话不能说完全错。

但如果你真这么干，很容易走偏。

因为采购里最常见的一个坑就是：

单价看起来降了，企业的总成本却没降。

有些单子，价格确实压下来了。

但后面质量不稳、返工增加、补货频繁、交期延误、库存积压，最后企业花出去的钱一点没少，甚至更多。

所以，采购真正该理解的，不是“谁报价低”，而是：

**谁的总成本更优。**

这才是采购成本控制的起点。

---

## 一、采购成本控制，先别急着谈价，先把成本看全

很多人一提成本，第一反应就是采购价。

但采购工作里，成本从来不只是采购价。

真正完整的成本，通常至少包含两部分：

### 显性成本

就是你在合同、报价单、付款单上能直接看到的部分，比如：

+    采购单价

+    运费

+    税费

+    包装费

+    装卸费

这部分最容易比，也最容易拿出来汇报。

### 隐性成本

这部分才是真正容易让采购翻车的地方，比如：

+    不合格品返工返修成本

+    延期交付造成的停线损失

+    临时补货带来的加急物流成本

+    库存积压成本

+    异常处理带来的管理成本

很多采购做决策时，只看前面那张报价单，

没去想后面这一连串代价。

结果就是：

买的时候觉得便宜，用的时候才发现贵。

所以我一直觉得，采购做成本控制，第一步不是砍价，

是先把账看全。

---

## 二、为什么很多采购“降本”做了，老板却不买账

因为你降下来的，可能只是**单价**，不是**总成本**。

举个很典型的场景：

两家供应商做同一类包材。

A 报价低一点，

B 报价高一点。

如果你只看单价，肯定先选 A。

但真正合作后发现，A 的质量波动大，到货也不稳定，车间经常返工，紧急补货也多。

最后算下来，A 虽然便宜几分钱，企业整体付出的成本反而更高。

这就是很多采购容易掉进去的误区：

把“采购价低”误当成“采购做得好”。

老板真正关心的，不是你把单价压了多少，

而是你有没有帮企业把整体成本和风险一起控下来。

---

## 三、采购降本，先学会这几个最基础但最实用的方法

很多人一说降本，就想到“跟供应商狠狠干一轮”。

其实没那么复杂。

对大多数采购来说，先把基础动作做好，已经能产生明显价值。

### 比价采购

这是最基础的动作。

至少找 3 家供应**商做对比，

但这里有个**前提：不能只比价格，要比条件。

要一起看的包括：

+    是否含税

+    是否含运费

+    交期多久

+    起订量多少

+    付款条件怎样

+    质量和服务表现如何

有的报价便宜，只是因为没把运费算进去；

有的报价看起来高，其实含税含运费、交期也更稳。

所以，比价不是比数字，

是比综合性价比。

---

### 集中采购

**很多企业明**明采购量不小，但价格一直谈不下来，原因很简单：

需求太散。

今天这个部门买一点，明天那个部门买一点，规格还不统一，量也聚不起来，当然很难谈。

如果能把同类物料整合起来，做统一采购，通常会带来几个变化：

+    议价能力更强

+    采购效率更高

+    管理更容易标准化

+    异常也更容易控制

采购不是量越碎越灵活。

很多时候，量越散，成本越高。

---

### 优化物流

有些采购做降本，只盯采购价，不看物流，这也很可惜。

比如：

+    明明不是急单，却总在走高成本运输方式；

+    明明可以合并发货，却一直零散送货；

+    明明能提前计划，却总靠临时加急补货救火。

这些动作看起来不是采购价，

但最后都是采购成本。

真正成熟的采购，会把运输方式、到货节奏、批量安排一起纳入成本控制。

---

### 控采购批量，别让库存把利润吃掉

有些采购为了拿更低价格，一次压很多货。

表面上单价便宜了，实际上库存占用、呆滞风险、仓储压力全上来了。

所以采购不能只问一句：

“能不能再便宜点？”

还要多问一句：

“这个量，现在买这么多，值不值？”

---

## 四、采购想把成本控制做好，光会谈还不够，还得会看数据

我一直觉得，采购到了一定阶段，差距不只在沟通，

更在数据能力。

因为很多事，如果没有数据，你只能靠感觉。

而靠感觉做采购，做久了很容易吃亏。

采购基础阶段，先把 Excel 用起来就已经很实用了。

### 用 VLOOKUP 做价格匹配

比如：

+    调历史采购价

+    匹配不同供应商报价

+    快速比对价格变化

它的价值很简单：

少手工查，少出错。

### 用数据透视表做汇总分析

比如：

+    哪家供应商采购额最高

+    哪类物料涨价最明显

+    哪个月采购金额异常

+    哪类物料成本占比最高

数据不整理，你看到的永远只是零散信息。

做成透视表，结构就出来了。

### 建一张标准化报价对比表

采购很多基础工作，说白了就是把信息整理清楚。

一张好用的报价对比表，至少要放这些字段：

+    物料名称

+    规格型号

+    供应商名称

+    含税单价

+    运费

+    交期

+    付款条件

+    历史价格

+    差异说明

表格一标准，

后面比价、分析、汇报都会顺很多。

---

## 五、采购成本控制，最后控的其实不是价格，是判断力

做久了你会发现，采购真正值钱的地方，不是把供应商压到多低，

而是你能不能在这些因素之间做平衡：

+    价格

+    质量

+    交期

+    风险

+    库存

+    协同效率

单价最低，不一定最好；

供应商最便宜，也不一定最省钱。

真正专业的采购，做成本控制时看的是：

这个方案，对企业来说是不是总成本更优。

这才是采购该有的判断力。

---

## 六、写在最后

采购成本控制，不是把“便宜”两个字做到极致。

而是把采购这件事，做得更稳、更值、更可持续。

如果你现在还是采购新人，我建议你先把这三个基本功练扎实：

+    能拆清楚成本构成

+    能用基础方法做降本

+    能用工具把数据整理出来

先把这三件事做顺，你看成本的视角就会完全不一样。

到那个阶段，你就不会只盯报价单上的一个数字了。
