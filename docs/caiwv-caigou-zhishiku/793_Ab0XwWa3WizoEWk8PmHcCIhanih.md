
# 《政府采购法》

> 来源：`https://rxq0zfnkm77.feishu.cn/docx/DDjvdZytaoOcQtxurVscNQqunYd`

采购为什么要了解《政府采购法》？

采购人员了解《政府采购法》，不仅是为了合法合规、规避风险，更是为了提升专业性和职业竞争力，在实际工作中保障采购活动的透明、公正和高效。

## 合规性要求

- 作为采购从业人员，必须确保所有的采购活动合法合规。
- 《政府采购法》明确了采购方式、程序、监督和责任，如果不了解，容易触碰法律“红线”。

## 防范风险

- 不懂政策，可能导致违法操作：如违规选择供应商、程序不合规等。
- 违法后果严重：轻则质疑投诉、废标；重则承担行政、刑事责任。

## 提升专业性与竞争力

- 掌握法律知识，可以在谈判、招投标、供应商管理等环节有理有据。
- 让采购人员具备“政策理解力”，成为专业的合格采购人。

## 维护公平与透明

- 法律的核心原则是“公开、公平、公正”。
- 遵守法律能避免暗箱操作，保障采购人和供应商的合法权益。

## 政策与业务紧密挂钩

- 许多采购活动（特别是涉及财政性资金）必须严格遵循《政府采购法》。
- 即使是企业采购，也会参考政府采购的流程、制度来提高规范性。
