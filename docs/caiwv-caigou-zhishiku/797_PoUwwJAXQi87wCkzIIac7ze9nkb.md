# 2 常见风险与规避

> 来源：[https://rxq0zfnkm77.feishu.cn/docx/Q7RPdR55ZoAviwxObXzc4SDFnjz](https://rxq0zfnkm77.feishu.cn/docx/Q7RPdR55ZoAviwxObXzc4SDFnjz)

## 一、定义 / 概念

采购风险，是指在采购过程中，因合同不清、供应商问题、流程失控、廉洁失守或信息失真等原因，导致企业出现损失、争议、延误、审计问题甚至法律责任的可能性。

风险控制，不是为了让采购“什么都不敢做”，

而是为了让采购在做事时，有判断、有预案、有底线。

一句话总结：

采购风险控制的核心，不是等出问题再处理，而是提前识别、提前拦住。

---

## 二、为什么采购必须学会识别风险

采购是连接外部供应商和内部需求部门的岗位。

很多问题，最后都会从采购这里穿过去。

如果采购没有基本风险意识，最容易出现三种情况：

1.   事情做完了，但证据没留；

1.   合同签了，但责任没写清；

1.   供应商用了，但底没摸透。

风险控制做得好，采购就更像“前置管理岗”；

做不好，采购就永远在后面补锅。

## 三、采购中最常见的几类风险与规避方法

### 1. 合同风险

最常见的问题，不是没合同，而是合同写得太模糊。

比如：

+    “质量合格”没定义标准；

+    “尽快交货”没有具体日期；

+    “按行业标准执行”没有写明依据；

+    异常处理、违约责任、赔偿边界没有约定清楚。

**规避方式：**

+    把质量标准、验收方式、交期节点写明；

+    写清楚异常处理流程；

+    对关键项目补充违约责任和索赔条款；

+    重要合同走法务审签。

**一句话：**

合同不是形式，合同是出了问题以后你能不能说清楚的底牌。

---

### 2. 供应商风险

供应商风险不只是“会不会报价高”，

更包括：

+    资质造假；

+    履约能力不足；

+    财务状况不稳；

+    过度承诺、实际做不到；

+    临时断供或质量失控。

**规避方式：**

+    核查营业执照、资质证书、授权文件；

+    通过公开渠道核验企业信息；

+    对关键供应商做现场审核或电话背调；

+    关键品类保留备选供应商。

---

### 3. 廉洁风险

采购是最容易接触外部利益诱惑的岗位之一。

如果边界感不清，很容易从“小意思”“行业习惯”一步步滑到违规甚至违法。

《反不正当竞争法》明确禁止经营者通过财物或其他手段向交易相对方工作人员等实施商业贿赂；明示折扣、佣金必须如实入账。采购场景里，最直接的要求就是：不能收、不能暗、不能私下换资源。

**规避方式：**

+    遵守公司廉洁制度；

+    公开比价、公开留痕；

+    回避利益冲突；

+    重大项目多人参与评审；

+    礼品、接待、返利按制度申报。

---

### 4. 流程风险

很多采购问题不是坏心，而是流程意识差。

比如：

+    审批没走完就先下单；

+    单一来源没有依据；

+    应招标项目拆分规避；

+    采购方式和项目性质不匹配。

依**法必须招标的项目，不得**化整为零规避招标；政府采购也强调公开透明、公平竞争、公正和诚实信用。对采购来说，程序本身就是风险防线。

**规避方式：**

+    先判断项目类别和金额区间；

+    先确认采购方式再启动动作；

+    例外情形必须走审批；

+    全流程留痕。

---

### 5. 留痕风险

很多采购并不是没做事，

而是出问题时拿不出证据。

比如：

+    口头答应改交期，没有书面确认；

+    需求变更没有邮件留存；

+    质量异议没有正式函件；

+    比价记录只有🛰️聊天，没有归档。

**规避方式：**

+    重要事项书面确认；

+    会议纪要、邮件、报价、合同统一归档；

+    关键节点拍照、签字、扫描备份；

+    建采购台账。

---

## 四、案例 / 场景代入

某采购员收到供应商报价后，因项目着急，没完整核验资质，也没把验收标准写进合同。

后面到货后出现质量争议，供应商坚持说“按行业常规已经合格”，采购方内部又拿不出清晰书面标准，最后只能边用边补救，损失了时间，也失了主动权。

这个案例里，问题不是单一失误，

而是合同风险 + 供应商风险 + 留痕风险一起叠加了。

---

## 五、常见误区 / 避坑提醒

### 1. 风险控制等于拖流程

不是。真正好的风险控制，是让后面少返工、少扯皮、少背锅。

### 2. 只在出问题后才想起留痕

那时候通常已经晚了。

### 3. 觉得老供应商就不会出问题

越熟的合作关系，越容易在流程上放松。

### 4. 把风险都推给法务或质量

采购是第一道门，不是转发站。

### 5. 风险识别只盯价格

价格只是风险的一部分，质量、交付、流程、廉洁都算。

---

## 六、总结

采购风险控制，核心就一句话：

把本来会在后面爆掉的问题，尽量拦在前面。

对采购新人来说，先把这几类风险看懂：

+    合同风险

+    供应商风险

+    廉洁风险

+    流程风险

+    留痕风险

基本功就已经比很多人扎实了。
