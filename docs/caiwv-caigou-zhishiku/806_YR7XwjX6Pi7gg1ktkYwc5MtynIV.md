# 3 问题解决能力

> 来源：[https://rxq0zfnkm77.feishu.cn/docx/CPy4dTygro5YSUxhuSKcXCfZnwf](https://rxq0zfnkm77.feishu.cn/docx/CPy4dTygro5YSUxhuSKcXCfZnwf)

## 一、定义 / 概念

问题解决能力，是指采购人员在面对交付延迟、不合格品、需求变化、供应异常等突发情况时，能够快速判断、组织资源、制定方案并推动解决的能力。

采购不是只在“顺利的时候”工作，

真正考验水平的，往往是出问题的时候。

一句话总结：

采购的问题解决能力，不是会不会着急，而是出事后能不能迅速把局面稳住。

---

## 二、为什么采购必须具备问题解决能力

采购流程里，异常几乎不可避免。

供应商可能延误，质量可能波动，内部需求也可能临时变化。

问题来了以后，采购最怕两种反应：

+    只会催，不会判断；

+    只会汇报，不会拿方案。

真正有效的问题解决，不是“把问题报上去”，

而是先把情况搞清、把影响评估出来、把可选方案拿出来。

---

## 三、采购问题解决的基本步骤

### 1. 先确认问题到底是什么

比如交付延迟，到底是：

+    原材料没到？

+    产能不足？

+    工艺异常？

+    物流受阻？

如果问题根因没搞清，后面所有动作都容易偏。

---

### 2. 评估影响范围

采购不能只看“这单晚了”，

还要看：

+    会不会影响生产排期；

+    会不会影响客户交付；

+    会不会引发额外成本；

+    是否涉及合同责任。

---

### 3. 快速拿出备选方案

采购面对问题时，不能只有一句“出问题了”。

更有价值的做法是带着方案去同步，比如：

+    协调供应商加急生产；

+    分批交货，先保关键部分；

+    临时启用备选供应商；

+    内部协调替代物料或调整排期。

---

### 4. 推动跨部门协同解决

采购很多异常，不是采购自己一个人能解决的。

质量异常要拉质量，交期异常要拉计划或生产，付款问题可能要拉财务。

所以问题解决能力里，包含很强的协调能力。

---

### 5. 事后复盘，避免重复发生

问题解决不是“火灭了就完了”。

还要回头看：

+    根因是什么；

+    哪个环节预警不够；

+    下次怎么提前拦住。

---

## 四、案例 / 场景代入

某关键零部件供应商临时通知：因设备故障，原定周五交货要延后 5 天。

如果采购只是把这个消息转给内部，项目就会直接被动。

更成熟的做法是：

+    立即确认真实延误原因与恢复时间；

+    评估是否影响产线；

+    与供应商谈分批交付可能；

+    同时启动备选供应商询价；

+    向内部同步风险和两个可选方案。

这时采购就不是“传坏消息的人”，

而是“带解决方案的人”。

---

## 五、常见误区 / 避坑提醒

### 1. 出事只会催供应商

催是动作，不是方案。

### 2. 只报问题，不带建议

领导最怕听到“出事了”，却听不到“怎么办”。

### 3. 没搞清根因就急着处理

这样容易头痛医头、脚痛医脚。

### 4. 只解决当下，不做复盘

同样的问题就会反复出现。

### 5. 问题处理中不留痕

异常记录、责任确认、补救措施都要形成书面资料。

---

## 六、总结

采购的问题解决能力，核心不是“反应快”这么简单，

而是能判断、能协调、能拿方案、能复盘。

一句话总结：

成熟采购遇到问题，不只是把火扑灭，而是尽量别让同样的火再烧第二次。
