## SCMP供应链管理专家是什么？

SCMP（Supply Chain Management Professional）是由中国物流与采购联合会（CFLP）推出的供应链管理领域权威职业认证，旨在培养和认证具备系统性供应链管理能力的专业人才。该认证结合国际供应链理念与中国本土实践，被国内企业广泛认可。

核心信息：

+ **认证机构**：中国物流与采购联合会（CFLP）。
+ **课程内容**：覆盖供应链战略、计划与运营、采购管理、物流管理、供应链金融、数字化供应链等模块，注重理论与实际场景结合。
+ **适用对象**：供应链、物流、采购、生产计划、仓储管理等相关岗位从业者。
+ **考试形式**：笔试或机考，部分级别需提交案例分析报告或论文。
+ **证书价值**：国内供应链领域“黄金证书”，助力职业晋升、企业供应链优化及行业竞争力提升。

## 建议哪些人考取SCMP证书？

以下人群考取SCMP证书的收益显著：

1. **供应链从业者**：包括物流、采购、生产计划、仓储管理等岗位人员，需系统提升专业能力。
2. **企业中高层管理者**：负责供应链战略规划、流程优化或成本控制的部门负责人（如供应链总监、运营经理）。
3. **跨行业转岗者**：从其他领域（如销售、IT）转向供应链管理，需快速建立专业知识体系。
4. **学生及职场新人**：供应链相关专业学生或初入职场者，增强就业竞争力。
5. **企业内训需求**：企业希望提升团队供应链管理能力，SCMP可作为标准化培训体系。

## 关于课程的常见问题

### Q1：SCMP分为几个等级？

SCMP主要分为两个等级

+ 助理供应链管理专家认证（ASCMP）
+ 供应链管理专家认证（SCMP）

（注：不同等级报考条件与考试难度逐级递增）

### Q2：课程学习方式是怎样的？

+ 主流模式为 线上录播+直播方式学习
+ 学习周期通常为3-6个月，根据必修＋选修课程不同。

### Q3：报考条件是什么？

+ 助理级（ASCMP）：大专及以上学历，无经验要求（在校生可报考）。
+ 供应链管理师（SCMP）：本科+1年相关经验，或大专+3年经验。

### Q4：考试难度和通过率如何？

+ 难度适中，部分考题需结合实践案例才能理解，通过率约60%-75%。
+ 未通过者可申请补考（通常有1-2次免费机会）。
