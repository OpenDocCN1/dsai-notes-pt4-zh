
# 🏹ChatGPT注册方法

> 来源：[https://sg0n3b2id7.feishu.cn/docx/H9u6dUouyoOMPSxKHBZcYvDunob](https://sg0n3b2id7.feishu.cn/docx/H9u6dUouyoOMPSxKHBZcYvDunob)

## 注册方法

## 1 网络环境准备

+ 上网环境需能登录Google（你懂的）
+ 国内和香港地区不行
+ 以下注册过程全程保持该网络（开魔法）
+ 自己的可用邮箱，任意邮箱均可，可以使用国内邮箱，例如”🐧’‘邮箱，”网易”邮箱

## 2 登录官网注册账号

+ 访问`https://chat.openai.com/auth/login`
+ 点击Sign up注册账号
+ 填入注册邮箱以及密码
+ 进入注册邮箱验证
+ 准备进行手机验证
+ 具体步骤可参考下图

![](img/4d538419ec790b147e2c1ee291ec9369.png)

## 3 获取手机验证码

+ 登录网站`https://sms-activate.org/cn`
+ 注册网站账号
+ 密码至少8位，且必须包含拉丁字母和数字，至少一个大写字母。
+ 注册过程需要收邮箱邮件激活，这一步耐心等待，有的人等了20分钟才收到。
+ 网站右上角进行充值
+ 选择支付宝，充值0.17usd，约等于1RMB，11卢布
+ 左侧服务列表选择openai
+ 获取一个手机号码 填入到2.21中的验证手机号的界面中
+ 等待获取验证码

![](img/ecd9a40328f4b8db7d7baf85d66d7021.png)

## 4 填入手机验证码完成注册

+ sms网站中获取到的验证码填入手机验证码页面
+ 按网页提示进行下一步即可注册完成

## 5 问题解决方法

### 5.1 页面提示说不能在当前国家服务

+ 确保自己网络环境正常，登录以下网站，看到自己的IP不是国内或者HK`https://whatismyipaddress.com/`
+ 开全局魔法
+ 清理浏览器cookie
+ 浏览器隐私模式登录
+ 关闭电脑网络设置里的ipv6协议
+ 检查自己的代理环境，有些确实是不能访问，只能更换环境

![](img/4b6d0548898eea8859858ab97c7afbd4.png)

### 5.2 收不到验证码

+ 20s收不到的话，就直接点×，释放掉刚才的手机号，换个手机号，此次操作不收费
+ 换个区域，印度不行就换马来西亚、巴西、德国等，印尼有概率黑号，不是很推荐。
+ 由于网站用户太多的原因，有可能试了很多次都没成功，不要灰心，继续尝试，或者换个时间段尝试

### 5.3 是否一定要使用印度的？

+ 印度便宜，当然你可以选择贵的区域

### 5.4 openai注册显示太多次手机验证请求

+ 等一段时间再尝试，至少3分钟以上，不同的人还是有差异的，可以暂时先去忙别的
+ 重新换个OpenAI账号 ，即换一个邮箱进行注册，而不是换一个手机号，如果显示同一个ip内注册账号过多，你需要再换一个ip，最简单的实现方法是代理换个节点，然后是换个设备，用电脑的可以把宽带改成手机热点当网络。
