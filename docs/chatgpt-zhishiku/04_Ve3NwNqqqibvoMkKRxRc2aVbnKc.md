# 2、普通号和plus号有什么区别？

普通号永久使用，但是容易掉线，没有提问次数限制，回答质量一般。

plus每个月要续费，不易掉线，每3个小时只能提问25次，回答质量很好。

详细了解可以看这个：https://www.bilibili.com/video/BV1m24y1s7zC/?spm_id_from=333.337.search-card.all.click&vd_source=c4c46f20474ad88697b5ceb841680802

![](img/b945f2467d79d2effd1c5f61fb3f7ba3.png)

![](img/77205be4dc5a5e11c3af3b569863f055.png)
