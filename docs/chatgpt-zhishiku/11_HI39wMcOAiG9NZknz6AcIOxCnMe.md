
# 🎗️OpenAI官方的最佳实践指南-Prompt

> 来源：`https://sg0n3b2id7.feishu.cn/docx/K2zedQpfbovrXxxsIZJc4kaMnWb`

原文英文版地址：`https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-openai-api`

## 通过用###或“””分隔指令和上下文

AI 不知道什么是指令，什么是待处理的内容，用符号分隔开来会更利于 AI 区分

**不太有效的❌**：

```
将下面的文本总结为要点列表。

{此处输入文字}
```

**有效 ✅**：

```
将下面的文本总结为最重要的要点列表。

文本：&quot;&quot;&quot; 
{此处输入文本} 
&quot;&quot;&quot;
```

## 尽可能详具体的说明上下文、结果、长度、格式、样式等

**不太有效的❌**：

```
写一首关于 OpenAI 的诗。
```

**有效 ✅**：

```
以{著名诗人}的风格写一首关于 OpenAI 的鼓舞人心的短诗，重点介绍最近的 DALL-E 产品发布（DALL-E 是一种文本到图像的 ML 模型）
```

## 通过示例阐明所需的输出格式

**不太有效的❌**：

```
提取下面文本中提到的实体。提取以下 4 种实体类型：公司名称、人名、特定主题和主题。

文字：{文字}
```

**有效 ✅**：

```
提取下面文本中提到的重要实体。首先提取所有公司名称，然后提取所有人员姓名，然后提取具体话题，最后提取总体主题。

格式：
公司名称：
人员名称：
具体话题：
总体主题：

文本：{text}
```

## 减少“蓬松”和不精确的描述

**不太有效的❌**：

```
提取下面这个产品的描述要简短，几句话就行，不要太多。
```

**有效 ✅**：

```
使用 3 到 5 句话的段落来描述该产品。
```

## 与其说什么不该做，不如说什么该做

**不太有效的❌**：

```
以下是代理和客户之间的对话。不要询问用户名或密码。不要重复。

客户：我无法登录我的帐户。
代理人：
```

**有效 ✅**：

```
以下是代理和客户之间的对话。代理将尝试诊断问题并提出解决方案，同时避免询问与个人身份信息相关的任何问题，如不要询问用户名或密码等。而是让用户参阅帮助文章 www.samplewebsite.com/help/faq

客户：我无法登录我的帐户。
代理人：
```

## 其他使用技巧

### Step by Step （Zero-Shot Chain of Thought([2])）

这是最简单也是我最常用的一个技巧。只需要在每个问题结尾加上一句就可以让答案更准确：

```
Let‘s think step by step
```

翻看了其他大神写的Prompt文章([3])，下面的语句效果可能更好：

```
Let&#x27;s work this out in a step by step way to be sure we have the right answer.
```

### 魔法打败魔法

适合小白或不知道该如何提问时，可以假装要考其他AI让ChatGPT帮你整理提问思路，例如：

```
“文心一言”是一款AI会话模型，我想通过它来帮我制定一份出行计划，我该如何提问。
Let&#x27;s work this out in a step by step way to be sure we have the right answer.
```
