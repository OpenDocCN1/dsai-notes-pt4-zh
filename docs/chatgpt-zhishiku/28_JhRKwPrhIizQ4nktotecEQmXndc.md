
# OpenAI手机版应用正式发布！使用教程来了！

> 来源：[https://sg0n3b2id7.feishu.cn/docx/C2PldRlUYoXbSnxsWrfceQO3nod](https://sg0n3b2id7.feishu.cn/docx/C2PldRlUYoXbSnxsWrfceQO3nod)

![](img/3f8760167f3ba8e3f298037f1eb40956.png)

OpenAI ChatGPT IOS版本应用正式发布了，主要内容如下

+ 目前只支持美区的IOS ID下载
+ IOS系统版本需要16.1及以上
+ 支持通过语音模型`Whisper`语音输入
+ `GPT4`使用没有限制，网页端是3小时25条，app暂时没有限制
+ 手机版本暂不支持插件功能
+ 可以跨设备同步记录
+ 内购`plus`价格19.9USD

![](img/a21374190f4d364eaae190df3ac45d79.png)

## 体验感受

1. 速度很快，`gpt4`要比网页快得多
1. 手机发热明显，平常玩大型游戏都没这么烫
1. 支持中文语音提问，识别率非常好
1. 目前还不支持网络浏览以及插件功能
1. 可以直接`App Store`购买`Plus`服务了
1. 人们很热情，`APP`刚推出就到应用市场第二名了
