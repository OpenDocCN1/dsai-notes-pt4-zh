## 介绍

Midjourney是由同名的研究实验室开发的人工智能程式，根据文本生成图像，于2022年7月12日进入公开测试阶段，使用者可透过Discord的机器人指令进行操作。

## 开发团队

由Leap Motion的创办人大卫·霍尔兹领导的同名研究实验室

## 用途与场景

+ 人像卡通化：将人物照片转换成有趣的卡通形象。

+ 轮廓生成：可以根据输入的文字描述生成对应的图像轮廓。

+ 色彩生成：利用GAN模型，可以生成具有艺术感和创意的彩色图像。

+ 视频换脸：可以实现对视频中人物的面部进行换脸操作。

+ 视觉问答：通过图像识别和自然语言处理技术，可以实现对图像的问题回答。

+ 人脸合成：可以将不同人物的面部特征进行合成，生成新的面孔。

## 常见问题

### Discord是什么

一款专为社群设计的免费即时通讯社交软件，类似于飞书，但功能更为强大，可对接机器人与各种程序API，能够在上面发开自己工具，有网页版与手机版APP。

### Midjourney需要安装吗？

Midjourney目前不用安装，它通过Discord的对话机器人模式返回生成结果，使用方式只需要在Discord输入命令+提示词即可，所以出图能力与你的电脑无关，因为真正运算出图的是云端服务器。

> 目前Midjourney已无免费额度，想用AI绘画功能需开通会员，一共有10美元，30美元，60美元三种套餐

## 基本使用方法

1. `/imagine + 提示词`

2. 可以多个提示词，提示词之间用逗号或空格分开

3. 提示词可以是描述画面的一句话，也可以是绘画风格，光影，真实性，人物特点补充等等

## 使用技巧

### 使用discord表情符号对生成做出反应

+ ✉️ 信封表情符号会将带有种子编号和工作 ID 的图像发送给您的个人消息。如果结果是一组图像，它将发送每个单独的图像。您可能需要通过在表情符号列表中输入“envelope”来寻找此表情符号。

+ ⭐️ 将图像标记为“收藏”，会将图像发送到#favorites 频道。

+ ❌ 随时取消或删除图像，它也从网络画廊中删除。

### 使用参考图

在提示中添加一个或多个图像 URL，将使用这些图像作为视觉灵感来源。你可以将文字与图像混合使用，也可以单独使用图像。 由于对社区公共内容的法律上的担忧，Midjourney 目前不提供使用类似stable diffusion的初始图像的功能。

注意事项：

+ 喂图链接位于提示词的前面

+ 仅仅是利用图像作为灵感来源，并不是从图像开始进行变化创作；

+ 可以使用多个参考图，但目前无法对不同的参考图应用不同的权重；

+ `--iw + number`命令调整参考图与文本的权重（0.5 将图像权重减半，2 将图像权重两倍）

+ `/blend` 命令是针对移动用户优化的简化图像提示过程

> 在discord私信中上传图像，以防止其他服务器用户看到图像

> 喂图在 Midjourney 网站上所有人可见，除非用户购买最高等级会员

> 喂图格式：`/imagine + 参考图链接 + 提示词`（链接和提示词之前用空格）

获取参考图链接方法：

1. 单击消息输入框左边的加号。选择上传文件，然后发送消息

2. 在图像右键，菜单选择复制链接，将链接粘贴即可使用

### 让机器明白想要风格

1. `describe`命令-图片生成描述语

2. 参考图 + `/describe` + 提示词实现精准控制

3. 使用 `--iw` 设置参考图权重
