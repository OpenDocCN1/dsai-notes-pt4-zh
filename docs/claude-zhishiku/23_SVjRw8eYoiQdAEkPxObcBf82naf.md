# 正文

教程基于1Panel终端，理论上其他终端也可以

实验性解决办法，不保证所有人可行

## 1.打开服务器终端

![](img/1f1de4f1bfceb4cfb989562f6eba8ff5.png)

## 2.输入下面代码然后回车

```
wget -N https://gitlab.com/fscarmen/warp/-/raw/main/menu.sh &amp;&amp; bash menu.sh
```

输入2回车，即选择简体中文，之后等到安装依赖进入菜单界面

依次选择1 1 1 3

![](img/871f19670258a70eab7ffaebaf0984ad.png)

## 3.成功换ip

![](img/eacf8c6e0a94afd27202af67129db38e.png)

> 确保Clewd和SillyTavern都是host网络

至此应该已经可以了，请在酒馆自行测试回复

如果还是不行可以试试下面方法

## **继续更换****IP**

```
warp
```

输入4回车关闭warp再打开更换ip

![](img/64591562342714d95ed834d26a54b3bb.png)
