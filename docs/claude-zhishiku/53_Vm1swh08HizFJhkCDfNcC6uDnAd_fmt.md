## `PList` 是什麼？高大上？

`PList` 用人話說就是角色特色/角色特徵，讓 `Claude` 去快速理解你的角色的特徵。

舉例：福利蓮。

紅色圈是角色特徵，精靈.魔法使.雙馬尾.藍色雙眼.精靈耳朵.白皮膚。

`[葬送的芙莉蓮(角色名) =精靈,魔法使,雙馬尾,藍色雙眼,精靈耳朵,白皮膚]`，好我們現在就已經簡單的把芙莉蓮的角色外觀特色放進所謂的 `PLIST` 了。

那藍色圈呢？藍色圈是芙莉蓮的背景（注意！背景可以不用全取進去，只要放你認為重要的就行，當然你覺得全部都重要也可以全放，但是要是你覺得用不到的可以省略）。

好那我們想把角色個性加進 `PLIST`。

有好幾種寫法，這裡只介紹兩種。

### 第一种角色个性写法

```
[[葬送的](https://zh.moegirl.org.cn/%E8%B5%96%E5%BA%8A)芙莉蓮(角色名) =精靈,魔法使,雙馬尾,藍色雙眼,精靈耳朵,白皮膚, 個性冷靜,熱衷週遊各方蒐集魔法, 喜歡賴床 , 喜歡的花卉是冬天綻放的冰柱櫻, 對戀愛方面遲鈍]
```

好，這樣我們就把背景寫進去了，簡單吧？

### 第二种角色个性写法

```
[葬送的芙莉蓮(角色名) =精靈,魔法使,雙馬尾,藍色雙眼,精靈耳朵,白皮膚;

[芙莉蓮](https://zh.moegirl.org.cn/%E8%B5%96%E5%BA%8A)的個性=個性冷靜,熱衷週遊各方蒐集魔法, 喜歡 賴床 , 喜歡的花卉是 冬天 綻放的冰柱櫻, 對戀愛方面遲鈍; ]
```

這樣也可以！對，`PList` 其實沒有所謂的固定寫法，只要將角色的要素簡化放進去就行。

最後我們把背景放進去，藍色框內的就算是背景，一樣兩種方式舉例。

## `Ali Chat`

再來我們談談 `Ali Chat`。

`Ali Chat` 的意思簡單來說就是“透過對話讓 `Claude` 學習角色如何說話”。

那對話呢？對話哪裡來？

我們找簡單的，wiki 上就有了。

我們拿茨木童子這位當成例子。

![](img/a82ebd017af5f0aed9035027cb0dfd71.png)

找找看 wiki 上是不是有語音對話？對，就是那個。

![](img/71f90066aff76dee0f99ef38e191b0ab.png)

(圖截自：Mooncell - 玩家共同构筑的FGO中文Wiki)

### 例子1

召喚的時候

茨木童子：“是要辦祭典了吧？ 是嗎，是嗎。 呵呵呵。 透過靈基的改動，吾獲得了享受祭典之鬼的生活方式喔！ 吾乃茨木童子。 乃凌辱慶典的存在！ ……（咀嚼咀嚼）。”

### 例子2

提升與茨木童子的牽絆後的對話

茨木童子：“吾只是外表改變了而已。 本質一點也沒變。 吾可是鬼啊。”

### 例子3

喜歡的東西？

茨木童子：“ 咬上去，無情地啃噬，咬碎，邊品味邊吞下……哈哈哈。 甜美得妙不可言！ 倘若能和酒吞一起品嚐，更是至高無上的……唔。 怎麼了。 吾不是在說點心啦！ 絕對不是！”

### 例子4

關於聖杯？

茨木童子：“ 能實現願望的杯子嗎。 若能再得到，讓吾想想……我先要堆積如山的食物！ 那東西是叫馬卡龍吧！ 吾要全部吃光，這次一定能成為足以俯視你的大鬼！ 哇哈哈哈哈！”

</茨木童子對話範例>

到此，`AliChat` 就結束了，簡單不簡單？

`AliChat` 實際上可以配合角色的動作、角色的神情等方式去加強 `Claude` 對角色的理解，不過本教程是傻瓜教學，不教這個，你只要知道可以加，但不加也可以。
