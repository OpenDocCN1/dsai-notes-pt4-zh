## DeepSeek 日常办公实战

### 课程目标：

通过培训，参与者能够了解 DeepSeek 的背景与应用场景，熟练使用其功能及其与多维表格的集成（如飞书），实现类 Agent 工作流，提升日常办公效率，涵盖研究、文档处理、数据分析、自建 Chatbot 及本地应用开发。

### 目标人群：

+ 非技术员工（如行政、市场、运营等）
+ 对 AI 工作流和自动化感兴趣的职场人士

### 课程时长：

2天或者6小时

### 课程大纲：

#### 模块 1：DeepSeek 背景与应用场景

+ 任务：
  + 了解 DeepSeek 的技术背景
  + 掌握其开发特点与优势
  + 识别典型办公应用场景
  + 理解使用时的注意事项

+ 方法：
  + [通过讲解](https://www.reuters.com/technology/artificial-intelligence/what-is-deepseek-why-is-it-disrupting-ai-sector-2025-01-27/)了解 DeepSeek 的起源，如“由中国公司开发，训练成本低于 600 万美元，使用 Nvidia H800 芯片”（参考 Reuter: What is DeepSeek and why is it disrupting the AI sector?）。
  + 分析其性能优势，如“DeepSeek-R1 模型媲美 [OpenAI](https://www.bbc.com/news/articles/c5yv5976z9po) o1，擅长数学和编码任务”（参考 BBC News: What is DeepSeek - and why is everyone talking about it?）。
  + 结合案例识别场景，如“生成市场报告、分析财务数据、自动化会议纪要”（参考 [DeepSeek 官网](https://www.deepseek.com/)）。
  + [讨论注意事项](https://www.washingtonpost.com/technology/2025/01/27/what-is-deepseek-ai-china-us-stock-fears/)，如“服务器位于中国，避免输入敏感数据”（参考 Washington Post: What is China’s DeepSeek AI and why is it worrying U.S. tech investors?）。

#### 模块 2：有效提示词基础

+ 任务：
  + 理解提示词结构
  + 学习具体提示词示例
  + 迭代优化提示词
  + 实践简单任务

+ 方法：
  + 使用提示词如`解释什么是 AI，50 字以内`测试基本响应。
  + 尝试具体指令如`写一句正式会议邀请，20 字以内`练习清晰表达。
  + 从`写一封邮件`迭代为`写一封 100 字的客户感谢邮件，语气专业`优化输出。
  + 实践任务如`生成一条团队问候语，轻松风格`，熟悉 DeepSeek 反应速度。

#### 模块 3：研究和写作

+ 任务：
  + 撰写市场研究报告
  + 创建项目规划报告
  + 撰写行业分析

+ 方法：
  + 使用提示词如`基于最新数据，撰写一份关于 AI 行业趋势的报告，包含 3 个主要发现`。
  + 注意 DeepSeek 信息可能基于预训练数据，可能不包含实时信息，需验证准确性。
  + 编辑输出以符合公司风格，如添加品牌语气或调整格式。

#### 模块 4：文档处理任务

+ 任务：
  + 整理汇报资料
  + 财务数据分析
  + 供应商招标资料对比
  + 合并多个营销报告
  + 撰写职位描述
  + 对比候选人简历
  + 创建项目计划
  + 更新技术报告

+ 方法：
  + 使用提示词如`从以下文本中提取关键点，格式为清单`整理汇报资料。
  + 上传数据，提示`分析这些财务数据，指出收入增长趋势`完成分析。
  + 输入`比较以下两个供应商的报价，列出优劣点`进行招标对比。
  + 使用`合并以下报告，总结主要营销策略`整合多份文档。
  + 提示`为市场经理职位撰写描述，强调分析能力和领导力`生成职位描述。
  + 输入`比较以下两份简历，指出适合市场经理职位的候选人`对比简历。
  + 使用`为新产品发布创建项目计划，包括时间表和预算`规划项目。
  + 提示`更新这份技术报告，添加最新 AI 发展趋势`优化报告。

#### 模块 5：数据分析和可视化

+ 任务：
  + 分析市场趋势
  + 客户反馈调查
  + 分析营销数据
  + 处理财务数据
  + 对比销售业绩
  + 生成数据洞察报告

+ 方法：
  + 提示词如`分析以下市场数据，总结 3 个主要趋势并描述可视化建议（如折线图）`。
  + 输入`从以下反馈数据中提取关键情绪和需求，生成分析总结及柱状图描述`分析反馈。
  + 提示`分析这些营销数据，指出 ROI 最高的活动并建议饼图展示方式`处理营销数据。
  + 使用`从以下财务数据中识别收入增长点，生成表格和趋势描述`分析财务。
  + 输入`比较以下两组销售数据，分析差异并建议条形图呈现`对比业绩。
  + 提示`基于以下数据集，生成 200 字数据洞察报告，包含可视化推荐`汇总报告。

#### 模块 6：高级提示词和定制

+ 任务：
  + 定制输出风格
  + 使用上下文一致性
  + 集成外部工具
  + 探索高级功能

+ 方法：
  + 提示词如`写一份报告，语气正式，符合公司品牌`调整风格。
  + 输入`基于之前讨论，补充项目计划细节`保持上下文一致性。
  + 提示`生成一份表格，适合导入 Excel`实现工具集成。
  + 使用`为团队协作生成实时任务清单`测试高级功能。

#### 模块 7：组合技术本地 Chatbot 应用（Volc Engine API + Cherry Studio）

+ 任务：
  + 配置 Volc Engine API 互联网搜索
  + 安装并设置 Cherry Studio
  + 实现专属聊天功能
  + 搭建个人知识库（RAG）
  + 集成搜索与知识库
  + 本地测试与部署

+ 方法：
  + 使用 Volc Engine API 启用搜索功能，提示如`搜索最新的 AI 行业新闻并总结前 3 条`。
  + 下载并初始化 Cherry Studio，创建本地 Chatbot 项目。
  + 配置 Chatbot 只回答公司相关问题，如`我们的产品特点是什么？`。
  + 上传公司手册创建知识库，启用 RAG 功能，提示如`从手册中提取休假政策并回答`。
  + 结合搜索和知识库回答问题，如`公司政策与行业标准相比如何？`。
  + 测试问题如`最近 AI 趋势是什么？`和`我的年假有多少天？`完成部署。

#### 模块 8：DeepSeek 与多维表格集成：类 Agent 工作流

+ 任务：
  + 分析股票走势
  + 创作小视频脚本
  + 自动化会议纪要整理
  + 客户反馈分析
  + 项目任务分配

+ 方法：
  + 在飞书多维表格中设置列如股票代码、日期范围，提示`根据历史数据分析股票 [代码] 在 [日期范围] 的走势，生成趋势总结和建议`。
  + 设置列如视频主题、目标受众、时长，提示`为 [主题] 创作一个 [时长] 的小视频脚本，面向 [受众]，包含开头、亮点和结尾`。
  + 输入会议文本，提示`从 [文本] 中提取关键点和行动项，格式化为清单`整理纪要。
  + 设置反馈内容列，提示`分析 [反馈内容]，识别情绪并提取核心需求，输出为简短报告`。
  + 输入项目目标、团队成员、截止日期，提示`根据 [目标] 为 [成员] 分配任务，生成描述和优先级，截止日期为 [日期]`。

#### 模块 9：伦理、实践考虑与最佳实践总结

+ 任务：
  + 检查数据隐私
  + 验证输出准确性
  + 讨论公司政策
  + 识别潜在偏差
  + 总结 DeepSeek 使用技巧
  + 优化工作流设计
  + 建立长期学习机制

+ 方法：
  + 提示`检查以下输入是否含敏感信息`，评估隐私风险，[避免因服务器位于中国而泄露数据](https://www.washingtonpost.com/technology/2025/01/27/what-is-deepseek-ai-china-us-stock-fears/)（参考 Washington Post: What is China’s DeepSeek AI and why is it worrying U.S. tech investors?）。
  + 输入`验证以下报告中的数据是否合理`，[确保输出准确性，](https://www.deepseek.com/)结合外部来源（如 DeepSeek 官网）核查。
  + 讨论并总结 AI 使用规范，提示如`总结 AI 使用的最佳实践，50 字`，确保符合公司政策。
  + 使用`分析以下输出是否存在偏见`，识别潜在问题并调整提示词。
  + 提炼经验，如`始终使用具体提示词（如‘300 字报告’而非‘写报告’）提升输出质量`。
  + 优化工作流，如`将 DeepSeek 分析结果导入飞书多维表格，结合手动校对确保准确性`。
  + 建立学习机制，如`加入 DeepSeek 社区，每月测试[新功能](https://mashable.com/article/deepseek-ai-r1-how-to-try-iphone-desktop)并分享案例，提升团队能力`（参考 Mashable: DeepSeek AI: How to try DeepSeek R1 right now）。

## DeepSeek 开发者实战指南

### 课程目标：

帮助开发人员掌握 DeepSeek 的技术特性与开发技能，通过 API 调用、Agent 设计、低代码开发、代码辅助工具、本地化部署、生产优化、高级框架集成及多模态开发，构建高效、智能的 AI 驱动应用。

### 目标人群：

+ 有编程基础的开发人员（如熟悉 Python、API 调用）
+ 对 AI 集成开发、Agent 设计或本地化部署感兴趣的工程师

### 课程时长：

3天或者18小时

### 课程大纲：

#### 模块 1：DeepSeek 技术概览

+ 任务：
  + 理解 DeepSeek 的技术背景与核心优势
  + 掌握其运作机制（MoE 切换机制简述）
  + 对比 DeepSeek 与主流模型
  + 了解 API 获取与本地部署方式

+ 方法：
  + 介绍背景：由中国公司开发，低成本（V3 训练成本约 278.8 万 GPU 小时），高性能（R1 媲美 GPT-4o，支持 128K 上下文）。
  + 简述 MoE 机制：基于 Mixture-of-Experts，每次激活部分参数（如 V3 的 671B 中仅 37B 激活），突出高效推理特性。
  + 模型对比：DeepSeek-R1 vs. GPT-4o（推理速度、成本）、LLaMA（开源性）、Grok（上下文长度），强调 R1 的性价比。
  + API 获取：注册 [DeepSeek 官网](https://platform.deepseek.com) 或第三方（如 Hugging Face）申请密钥；本地部署简介：开源模型下载（如 V3），细节留给模块 6。

#### 模块 2：调用 DeepSeek API 实现编程

+ 任务：
  + 配置 DeepSeek API 环境
  + 实现基本编程任务（如代码生成、调试）
  + 处理复杂场景（如长上下文代码补全）

+ 方法：
  + 配置 API：注册 [DeepSeek 平台](https://platform.deepseek.com)，获取 API 密钥，安装 Python SDK（如 `deepseek-api`）。
  + 示例：提示`生成 Python 快排算法`，展示 API 调用代码，解析返回结果。
  + 长上下文应用：输入完整项目代码，提示`补全缺失的数据库连接函数`，展示 128K 上下文的优势。

#### 模块 3：AI Agentic 设计模式与 AutoGen

+ 任务：
  + 理解 Agentic 设计理念
  + 使用 AutoGen + DeepSeek 开发智能 Agent
  + 实现多 Agent 协作任务

+ 方法：
  + 参考吴恩达课程，介绍 Agentic 模式：自主决策、工具调用、上下文记忆。
  + 配置 AutoGen：安装 `autogen` 库，绑定 DeepSeek API，定义 Agent（如“代码生成 Agent”和“代码审查 Agent”）。
  + 示例：实现多 Agent 系统，提示`Agent 1 生成 REST API，Agent 2 优化代码并添加注释`，展示协作结果。

#### 模块 4：使用 Dify 进行低代码/无代码开发

+ 任务：
  + 掌握 Dify 平台基础
  + 集成 DeepSeek 构建 RAG 知识库问答
  + 创建 Agent 应用
  + 实现自动化工作流
  + 开发复杂 Dify RAG 场景

+ 方法：
  + [介绍 Dify](https://dify.ai)：开源低代码平台，连接 DeepSeek API（Dify 官网）。
  + RAG 知识库问答：上传公司文档，配置问答工作流，提示`回答“休假政策是什么？”`。
  + Agent 应用：创建智能助手，提示`根据输入生成客户回复邮件`。
  + 自动化工作流：设计流程（如`输入客户反馈→分析情绪→生成报告`），展示批量处理能力。
  + 复杂 RAG：结合多文档和外部数据源，提示`从手册和新闻中对比公司政策与行业标准`。

#### 模块 5：使用 Roo Code + VS Code 实现代码开发 Copilot

+ 任务：
  + 配置 Roo Code 环境
  + 使用 DeepSeek 增强编码效率
  + 实现复杂开发任务
  + 对比 DeepSeek 与 GitHub Copilot
  + 提供 Roo Code 最佳实践与定制

+ 方法：
  + 安装 Roo Code：在 VS Code 中添加扩展，绑定 DeepSeek API。
  + 示例：提示`创建 Django REST API 模板`，生成并插入代码。
  + 高级任务：提示`调试 Python 脚本中的内存泄漏`，展示推理能力。
  + 对比 Copilot：DeepSeek（成本低、128K 上下文）vs. Copilot（云依赖、短上下文），突出 R1 的优势。
  + 最佳实践：设置快捷键触发 DeepSeek、定制提示词（如`生成符合 PEP8 的代码`）、定期更新 Roo Code 配置。

#### 模块 6：DeepSeek 的本地化部署、微调、RAG 与生产优化

+ 任务：
  + 本地部署 DeepSeek 模型（概念与演示）
  + 微调模型适配需求（最佳实践）
  + 实现 RAG 功能（含实时数据集成）
  + 对比 RAG 工具（LlamaIndex vs. LangChain）
  + 优化推理性能
  + 部署到生产环境（含安全考虑）
  + 监控生产应用（含隐私保护）

+ 方法：
  + 部署：下载 DeepSeek-V3（Hugging Face），使用 LM Studio 运行 7B 蒸馏模型（低硬件需求，如 16GB RAM），展示启动流程。
  + 微调：介绍 LoRA，提示`用公司代码库优化模型生成内部 API 风格代码`，推荐 Axolotl。
  + RAG：上传文档并结合 SerpAPI，提示`从手册和实时数据回答“公司政策与最新行业标准相比如何？”`，用 LangChain 演示动态问答。
  + RAG 对比：LlamaIndex（轻量、易集成）vs. LangChain（复杂推理、功能丰富），简述适用场景。
  + 优化：使用 vLLM 提升推理速度，提示`优化 7B 模型处理 100 个并发请求`。
  + 生产部署：部署到 AWS，配置负载均衡，强调避免输入敏感数据（因服务器隐私风险），展示安全部署脚本。
  + 监控：设置日志记录，提示`检测响应时间和错误率，确保不泄露隐私数据`。

#### 模块 7：LangChain 与 DeepSeek 集成

+ 任务：
  + 理解 LangChain 基础

# DeepSeek-VL2 多模态应用说明

## 介绍多模态特性
DeepSeek-VL2 支持图像处理（动态平铺视觉编码）和文本推理，参考 GitHub - DeepSeek-VL2。

## API 配置
下载模型（如 `https://huggingface.co/deepseek-ai/deepseek-vl-1.3b-base`），绑定 API，测试图像输入。

## 示例应用
提示“描述上传的图片内容”生成图像描述；提示“从合同图片中提取关键条款”实现文档理解。

## 提示设计
优化多模态输入，如“分析图片中的表格并总结数据”，展示提示技巧和输出调整。
