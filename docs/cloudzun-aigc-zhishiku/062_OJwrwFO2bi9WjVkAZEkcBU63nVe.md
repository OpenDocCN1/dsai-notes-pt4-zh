# Azure Databricks 数据工程与机器学习综合培训

> 来源：[https://zsyhjtnsa5.feishu.cn/docx/SLPId8fOmoLrihxCG6Bcu3PdnIe](https://zsyhjtnsa5.feishu.cn/docx/SLPId8fOmoLrihxCG6Bcu3PdnIe)

## **课程概述**

本课程旨在提供一个关于 Azure Databricks 平台的全面、综合性培训。课程内容融合了数据工程和机器学习两大核心领域，从 Azure Databricks 的基础概念和核心引擎 Apache Spark 入手，逐步深入到如何利用平台构建企业级的数据湖仓（Data Lakehouse），并最终掌握在其上构建、训练、部署和管理端到端机器学习解决方案的全过程。学员将通过理论与实践相结合的方式，获得在 Azure 上利用 Databricks 处理和分析大规模数据，并从中提取业务价值的实战能力。

## **课程目标**

完成本课程后，学员将能够：

+   熟练操作 Azure Databricks 工作区环境，包括集群、笔记本和作业。

+   使用 Apache Spark 和 Delta Lake 进行大规模数据的提取、转换和加载（ETL）。

+   构建和管理可靠、可扩展的数据湖仓（Data Lakehouse）解决方案。

+   使用 Delta Live Tables 和 Databricks 工作流自动化数据管道。

+   利用 Scikit-Learn、PyTorch 等框架在 Databricks 中训练和评估机器学习模型。

+   使用 MLflow 对机器学习实验进行全生命周期管理。

+   应用 AutoML、Hyperopt 等工具自动化模型开发与优化过程。

+   将训练好的模型部署到生产环境，并进行有效管理。

## **目标受众**

+   希望利用云平台进行大数据处理和分析的数据工程师。

+   希望在分布式环境上构建和部署模型的数据科学家和机器学习工程师。

+   负责设计和实施云端大数据战略的技术经理和解决方案架构师。

+   希望从传统数据仓库转向现代数据湖仓架构的开发人员和 DBA。

+   **为保证课程中的动手实验能**够顺利完成，客户需要提前准备好有效的国际版 Azure 订阅。

## **课时**

+   建议课时：5 天共计30小时（包含理论讲解、演示和动手实验）

## **课程内容**

### 第一部分：Azure Databricks 核心基础

+   Azure Databricks 探索：了解 Azure Databricks 云服务及其在数据分析中的作用，并熟悉 Databricks 工作区、集群、笔记本等核心概念。

+   在 Azure Databricks 中使用 Apache Spark：学习 Apache Spark 的核心原理，并在 Databricks 环境中运行 Spark 作业，进行大规模数据转换、分析和可视化。

### 第二部分：数据工程与数据湖仓 （Data Lakehouse）

+   **执行数据分析**：学习数据加载方法，集成 Azure Data Lake 等数据源，并使用协作式笔记本进行探索性数据分析（EDA）。

+   使用 Delta Lake 管理数据：了解 Delta Lake 的核心特性（ACID 事务、架构强制、时间旅行），利用其确保数据的一致性、完整性和版本控制能力。

+   使用 Delta Live Tables 构建数据管道：学习如何使用 Delta Live Tables 来声明式地构建实时、可扩展且可靠的数据处理管道。

+   使用 Azure Databricks 工作流部署工作负载：学习编排和自动化复杂的数据处理管道、机器学习工作流和分析任务。

### **第三部分：机器学习解决方案**

+   **训练机器学习模型**：学习如何利用 Scikit-Learn、PyTorch 等常用框架在 Databricks 的分布式环境中训练模型。

+   使用 MLflow 进行生命周期管理：学习使用 MLflow 管理机器学习生命周期，包括实验跟踪、模型打包、版本控制和注册。

+   **调优超参数**：使用 Hyperopt 库自动扩展和优化模型超参数，以提升模型性能。

+   **使用 AutoML**：利用自动化机器学习（AutoML）来简化和加速构建有效机器学习模型的过程。

+   **训练深度学习模型**：利用 Horovod 和 Spark 来分布式训练深度学习模型，以处理复杂的预测、计算机视觉和自然语言处理任务。

+   **管理生产中的机器学习**：学习如何将模型部署到生产环境中以获得实时或批量洞察，并简化从开发到部署的整个流程。
