## 基本 AI 概念

### 什么是 AI？

简而言之，AI 就是一种模仿人类行为和能力的软件。 关键工作负载包括：

+   机器学习 - 它通常是 AI 系统的基础，也是我们“教”计算机模型进行预测并根据数据得出结论的方式。

+   计算机视觉 - 通过相机、视频和图像直观地解释世界的 AI 功能。

+   自然语言处理 - 计算机理解书面或口头语言并作出相应反应的 AI 功能。

+   文档智能 - 与管理、处理和使用表单及文档中的大量数据有关的 AI 功能。

+   知识挖掘 - 从大量通常非结构化数据中提取信息以创建可搜索的知识存储的 AI 功能。

+   生成式 AI - 以各种格式（包括自然语言、图像、代码等）创建原始内容的 AI 功能。

### 什么是机器学习，它如何构成大多数 AI 解决方案的基础？

机器学习是人工智能的一个分支，它结合了计算机科学和数学，是大多数现代 AI 应用程序的基础。它通过从大量数据中学习来工作，数据科学家使用这些数据来训练机器学习模型，使其能够根据数据中发现的关系进行预测和推断。例如，机器学习可以用于农业技术公司，通过传感器数据帮助农民做出决策，或用于手机应用识别和分类野花。Microsoft Azure 提供 Azure 机器学习服务，这是一个基于云的平台，用于创建、管理和发布机器学习模型，并提供自动化机器学习、设计师、数据指标可视化和 Jupyter Notebook 等功能。

### 什么是生成式 AI，它在 Microsoft Azure 中如何体现？

生成式 AI 是一种 AI 功能，用于创建原创内容，通常以聊天应用程序的形式与用户进行自然语言交互，并能以自然语言、图像、代码和音频等多种格式返回回复。在 Microsoft Azure 中，可以通过 Azure OpenAI 服务来构建生成式 AI 解决方案，该服务将 OpenAI 的模型和 API 与 Azure 云平台的安全性与可扩展性结合起来，支持多种基础模型选项，并可在 Azure AI Studio 中进行管理、开发和自定义。

### 自然语言处理 （NLP） 的主要功能和应用是什么？

自然语言处理 （NLP） 是 AI 的一个领域，专注于创建能够理解书面和口头语言的软件。NLP 使软件能够分析和解释文本、解释口头语言并合成语音响应、自动翻译语言以及解释命令并确定适当的操作。例如，NLP 被用于虚拟现实游戏，让玩家能够通过对话控制游戏。Microsoft Azure 通过 Azure AI 语言和 Azure AI 语音提供 NLP 解决方案，包括文本理解、语音识别和合成、实时翻译以及对话转录等功能。

### 计算机视觉在 AI 中扮演什么角色，它有哪些核心任务和应用？

计算机视觉是 AI 的一个领域，负责处理视觉对象。它通常基于机器学习模型，应用于相机、视频或图像的视觉输入。核心任务包括图像分类（根据内容分类图像）、对象检测（识别图像中单个对象的位置和类别）、语义分割（根据所属对象分类图像中的像素）、图像分析（从图像中提取信息，如标签和描述性标题）、人脸检测、分析和识别（找出人脸并识别个人）以及光学字符识别 （OCR）（从图像中检测和读取文本）。例如，Seeing AI 应用利用计算机视觉为盲人和弱视群体描述附近的人、文字和物体。Microsoft Azure 通过 Azure AI 视觉提供计算机视觉服务，支持图像分析、人脸识别和 OCR 等功能。

### 文档智能和知识挖掘如何帮助管理和利用非结构化数据？

文档智能是 AI 的一个方面，用于管理、处理和使用在表单和文档中发现的大量各类数据，能够创建自动处理合同、健康文档和财务表单等的软件。Microsoft Azure 中的文档智能（Azure AI 文档智能）可以管理和加快从扫描文档中收集数据，并支持预生成模型和自定义模型。知识挖掘则是一个术语，描述从大量非结构化数据中提取信息以创建可搜索知识存储的解决方案。Microsoft Azure 的知识挖掘解决方案，如 Azure AI 搜索，利用内置的 AI 功能（如图像处理、文档智能和自然语言处理）来对以前不可搜索的文档编制索引，并从中快速提取和显示见解。

### 人工智能面临哪些主要的挑战和风险？

人工智能虽然能极大地造福世界，但也存在潜在的挑战和风险。这些包括：

+   偏差：训练数据中的偏差可能导致模型产生歧视性结果，例如贷款审批模型产生性别歧视。

+   错误：系统故障可能造成伤害，例如自动驾驶车辆遇到系统故障并引发碰撞。

+   数据暴露：如果存储不安全，用于训练 AI 系统（如医疗诊断机器人）的敏感患者数据可能被暴露。

+   适用性不足：解决方案可能不适用于所有人，例如家庭自动化助手不为视觉障碍用户提供音频输出。

+   缺乏信任：用户可能不信任复杂系统，不清楚其决策依据，例如基于 AI 的金融服务工具提供的投资建议依据是什么。

+   责任归属：AI 驱动的决策可能导致责任归属问题，例如无辜的人因基于面部识别的证据被判有罪时，谁该负责。

### Microsoft 提出了哪些负责任 AI 的原则来应对这些挑战？

Microsoft 遵循六项原则来确保 AI 应用程序在提供解决方案的同时不产生意外的负面影响：

+   公平：AI 系统应公平对待所有人，避免基于性别、种族等因素产生偏见，并应努力识别和减少模型中的偏见。

+   可靠和安全：AI 系统应可靠且安全地运行，特别是对于自动驾驶或医疗诊断等涉及生命安全的系统，需要严格的测试和部署管理。

+   隐私和安全：AI 系统应保护并尊重隐私，因为其基于大量个人数据。即使在训练完成后，数据和决策的隐私和安全性也需持续考虑。

+   包容：AI 系统应成为人们的有力助手，并惠及社会各个阶层，不分身体能力、性别、性取向、种族等因素。

+   透明度：AI 系统应是可理解的，用户应充分了解其用途、工作方式和局限性。

+   问责：应有相关人员对 AI 系统负责，设计和开发人员应在管理和组织原则的框架内工作，以确保解决方案符合道德和法律标准。

### Microsoft Azure 如何支持负责任 AI 的实现？

Microsoft Azure 通过其服务和功能支持负责任 AI 的实现。例如：

+   Azure 机器学习：该服务能够解释模型并量化数据中每个特性对模型预测的影响，从而帮助数据科学家和开发人员识别并减少模型中的偏见，这体现了“公平”原则。

+   人脸服务：Microsoft 停用了用于推断情绪状态和标识属性的人脸识别功能，以防止误用导致用户受到成见、歧视或服务遭受不公平拒绝，这同样体现了“公平”原则。通过在设计和开发过程中融入这些工具和指导原则，Azure 致力于帮助开发者构建符合负责任 AI 标准的解决方案。

## 机器学习概念简介

https://learn.microsoft.com/zh-cn/training/modules/fundamentals-machine-learning/

### 什么是机器学习？

机器学习是一种利用过去观测数据来预测未知结果或值的技术。其核心理念是将机器学习模型视为一个封装了数学函数的软件应用，该函数能根据一个或多个输入值（称为“特征”，通常用 `x` 表示）计算出输出值（称为“标签”，通常用 `y` 表示）。这个定义函数的过程被称为“训练”，训练完成后，模型可以通过“推理”过程预测新的值。机器学习模型通常分为监督式学习和无监督式学习两大类。

### 监督式机器学习和无监督式机器学习有什么区别？

监督式机器学习的训练数据包含已知特征值和已知标签值。模型通过学习特征与标签之间的关系进行训练，以便预测未知特征的标签。常见的监督式学习包括回归和分类。

无监督式机器学习的训练数据只包含特征值，不包含任何已知标签。算法通过识别训练数据中观测特征之间的相似性来发现数据中的模式和结构。聚类分析是无监督式学习最常见的形式，它将观测数据根据相似性分组到离散的簇中。

### 什么是回归，它如何工作？

回归是监督式机器学习的一种形式，其模型预测的标签是数值。例如，预测冰淇淋销量基于温度，或预测房屋售价基于其面积和卧室数量。回归模型通过将训练数据拟合到一个函数中来工作，该函数可以将输入特征（`x`）映射到输出数值标签（`y`）。线性回归是一种常用算法，它通过数据点绘制一条直线，以最小化直线与数据点之间的平均距离。模型的评估通常使用平均绝对误差 （MAE）、均方误差 （MSE）、均方根误差 （RMSE） 和决定系数 （R²） 等指标来衡量预测的准确性。

### 什么是分类，它有哪些类型？

分类是监督式机器学习的一种，其中标签表示一个类别或“类”。它用于预测观测数据所属的类别。分类主要有两种类型：

+   二元分类：模型预测两个互斥结果中的一个，本质上是预测“真”或“假”（例如，患者是否患有糖尿病）。它计算目标类标签为“真”的概率。

+   多类分类：模型预测多个可能类中的一个（例如，识别企鹅的物种是阿德利企鹅、巴布亚企鹅还是帽带企鹅）。多类分类可以使用“一对其他 （OvR）”算法（为每个类训练一个二元分类器）或“多项式算法”（创建一个返回所有类概率分布的单个函数，如 `Softmax` 函数）来实现。

### 如何评估分类模型？

分类模型的评估通常从创建一个“混淆矩阵”开始，该矩阵显示了正确和不正确的预测数量，包括：

+   真负数 （TN）：实际为负，预测也为负。

+   假阳性 （FP）：实际为负，预测为正。

+   假负数 （FN）：实际为正，预测为负。

+   真正 （TP）：实际为正，预测也为正。

基于混淆矩阵，可以计算以下指标：

+   准确性 （Accuracy）：模型正确预测的比例（（TN+TP） ÷ （TN+FN+FP+TP））。

+   召回率 （Recall）：模型正确识别的阳性病例的比例（TP ÷ （TP+FN）），也称为真阳性率 （TPR）。

+   精准率 （Precision）：预测为阳性且实际也为阳性的比例（TP ÷ （TP+FP））。

+   F1 分数 （F1 Score）：召回率和精准率的综合指标，是它们的调和平均值。

+   曲线下面积 （AUC）：通过绘制接收者操作特征 （ROC） 曲线来评估，该曲线比较了不同阈值下的真阳性率 （TPR） 和假阳性率 （FPR）。AUC 越接近 1.0，模型性能越好。

### 什么是深度学习？

深度学习是机器学习的一种高级形式，它试图模拟人类大脑的学习方式。它的核心是创建“人工神经网络”，这些网络由多层“神经元”组成，这些神经元使用数学函数模拟生物神经元中的电化学活动。这种多层结构使得该技术被称为“深度学习”，其生成的模型通常被称为“深度神经网络 （DNN）”。深度学习模型通过迭代地调整神经元之间的“权重”来最小化预测值与真实值之间的“损失”，从而学习如何从输入特征预测输出标签。

### 转换器模型在自然语言处理中扮演什么角色？

转换器模型是当今生成式 AI 应用（特别是语言模型）的核心架构，用于执行自然语言处理 （NLP） 任务，例如情感分析、文本摘要、语义相似性比较和生成新自然语言。它们通过大量文本训练，能够学习词汇之间的语义关系，并使用这些关系生成有意义的文本序列。转换器模型由两个主要组件组成：

+   编码器块：用于创建训练词汇的语义表示（“嵌入”）。

+   解码器块：用于生成新的语言序列。

它们利用“标记化”将文本分解为离散单元，并利用“嵌入”将这些标记表示为多维数值向量，捕捉它们的语义属性。关键的“注意”机制使得模型能够量化序列中不同标记之间的关系强度，特别是在生成下一个标记时关注最有影响力的标记。

### 转换器模型如何生成人类般的语言？

转换器模型，特别是那些仅使用解码器块的模型（如 GPT 模型），通过一个迭代过程生成文本。它们从输入序列开始（称为“提示”），并利用其在训练过程中学习到的标记嵌入、位置编码和多头注意层。在每一步，模型都会根据到目前为止的序列，通过计算和分配权重给每个标记，来预测下一个最有可能的标记。这个过程递归地进行，每次生成一个输出标记，并将新生成的标记添加回序列作为下一次迭代的输入。这种能力使模型能够将一致的句子串联起来，但这种“魔力”并非源于“知识”或“智能”，而是基于其庞大的词汇量和根据训练数据中词语之间的关系生成有意义序列的能力，从而产生与人类响应难以区分的输出。

## Azure 中的机器学习入门

https://learn.microsoft.com/zh-cn/training/modules/design-machine-learning-model-training-solution/

### Azure 机器学习工作室是什么？

Azure 机器学习工作室是一个基于浏览器的门户，用于管理机器学习资源和作业，并访问各种机器学习功能。它允许用户执行数据导入和浏览、创建和使用计算资源、在笔记本中运行代码、使用可视化工具创建任务和流程、使用自动化机器学习训练模型、查看已训练模型的详细信息（包括评估指标和负责任的 AI 信息），以及部署已训练的模型进行推理。

### 在 Azure 中训练机器学习模型有哪些服务选项？

在 Azure 中，有多种服务可用于训练机器学习模型，包括：

+   Azure 机器学习：一个云服务，提供端到端的机器学习项目生命周期管理，支持数据准备、模型训练和评估、模型注册和管理、模型部署以及负责任的 AI 原则应用。它提供 UI 驱动的工作室和代码优先的 Python SDK 或 CLI 体验。

+   Azure Databricks：一个数据分析平台，利用分布式 Spark 计算进行高效数据处理，可用于数据工程和数据科学，也可与其他服务（如 Azure 机器学习）集成。

+   Microsoft Fabric：一个集成分析平台，旨在简化数据工作流，支持数据准备、模型训练、预测生成和 Power BI 报表可视化。

+   Azure AI 服务：预构建机器学习模型的集合，通过 API 提供，用于图像物体检测等常见任务，其中一些模型可使用自定义数据进行训练。

### 训练机器学习模型时，如何选择计算选项？

训练机器学习模型时，需要选择计算资源，即执行训练过程所需的计算能力。选择计算选项时需要考虑以下因素：

+   CPU 或 GPU：对于较小的表格数据集，CPU 通常足够且经济高效。对于图像或文本等非结构化数据，GPU 更强大、效率更高。对于较大的表格数据集，如果 CPU 计算能力不足，也可以使用 GPU。

+   通用型或内存优化型：通用型计算具有平衡的 CPU 与内存比率，适合使用较小数据集进行测试和开发。内存优化型计算具有较高的内存与 CPU 比率，非常适合内存中分析、处理大数据集或在笔记本中工作。选择最佳计算选项通常需要反复试验，并通过监视计算利用率来决定是否需要扩展或缩减计算资源。

### 机器学习解决方案的六个核心步骤是什么？

一个精心设计的机器学习解决方案通常遵循以下六个核心步骤：

1.  定义问题：明确模型应该预测什么，以及成功的标准是什么。

2.  获取数据：识别数据源并获得访问权限。

3.  准备数据：探索数据，并根据模型要求进行清洗和转换。

4.  训练模型：选择算法和超参数，通过试验和错误来训练模型。

5.  集成模型：将模型部署到终结点以生成预测。

6.  监视模型：跟踪模型的性能，并根据需要进行重新训练。 这个过程通常是迭代和连续的。

### 什么是自动化机器学习 （AutoML），它如何简化模型开发？

自动化机器学习（AutoML）是 Azure 机器学习的一项功能，它自动执行机器学习模型开发中耗时且迭代的任务。通过 AutoML，用户可以在 Azure 机器学习工作室中设计和运行训练实验，而无需编写代码。它提供分步向导来运行机器学习训练作业，支持回归、时序预测、分类、计算机视觉和自然语言处理等多种任务。AutoML 会自动分配计算资源，并允许用户使用自己的数据集。

### 如何为机器学习模型准备数据？

数据是机器学习的基础，其数量和质量直接影响模型的准确性。准备数据通常涉及以下步骤：

1.  确定数据源和格式：识别数据的来源（例如 CRM 系统、事务数据库、IoT 设备）及其当前格式（例如表格、半结构化、非结构化）。

2.  设计数据引入解决方案：这是一个提取、转换和加载 （ETL） 或提取、加载和转换 （ELT） 的过程。通常，原始数据会从源中提取，通过 Azure Synapse Analytics 等服务进行复制和转换，然后存储在服务层（如 Azure Blob 存储）中，以便进一步处理，例如在 Azure 机器学习中训练模型。这可以通过数据引入管道实现，管道可以手动触发或按计划自动执行。

### 部署机器学习模型到终结点有哪两种主要方式？它们之间有什么区别？

将模型部署到终结点主要有两种方式：

1.  获取实时预测：模型在接收到任何新数据时立即对其进行评分，通常用于移动应用或网站等需要即时响应的场景。实时预测的计算资源（如 Azure 容器实例 ACI 或 Azure Kubernetes 服务 AKS）需要始终运行，以便模型能够即时返回结果，因此会产生持续的计算成本。

2.  获取批量预测：模型分批对新数据进行评分，并将结果保存为文件或数据库。这适用于不需要即时响应，但需要定期处理大量数据的场景，例如每周预测销量。批量预测通常使用计算群集，可以在触发评分时预配，并在没有新数据时缩减到零节点，从而显著节省成本。

选择哪种部署方式取决于预测生成频率、结果需求时效性、预测是单独还是批量生成，以及所需的计算成本。

### 在设计机器学习解决方案时，定义问题的重要性体现在哪里？

定义问题是机器学习解决方案设计的第一步，至关重要。它涉及到明确以下几点：

+   模型应产生的输出：例如，是预测分类值（分类）、数值（回归），还是从文本中提取见解（NLP）。

+   所需的机器学习任务类型：根据数据和预期输出，确定是分类、回归、时序预测、计算机视觉还是自然语言处理。这决定了可用于训练模型的算法类型。

+   模型成功的条件：定义衡量模型性能的指标（如准确性、精度），这些指标将用于评估模型是否成功执行其任务。



清晰地定义问题有助于在整个设计过程中做出正确的决策，包括数据准备、模型选择、训练和评估，从而制定出成功的机器学习解决方案。

# 生成式人工智能概念简介

`https://learn.microsoft.com/zh-cn/training/modules/fundamentals-generative-ai/`

## 什么是生成式 AI？它能做些什么？

生成式 AI 是人工智能的一个分支，专门用于创建原创内容。它能够接收自然语言输入，并以各种格式（如自然语言、图像、代码等）生成相应的响应。例如，您可以要求它撰写求职信、为花店设计标志，或编写一段 `Python` 代码来执行数字加法。

## 语言模型是如何“理解”文本的？

语言模型通过以下几个关键步骤来“理解”文本：

- 标记化（`Tokenization`）：首先，将文本分解成具有已知含义的字符串，称为“标记”（`token`），通常代表单词。然后，这些标记被转换为数字，使计算机能够处理它们。这包括根据规则（例如空格）拆分单词，并删除“停用词”（如“the”、“a”）等干扰词，然后为每个独特的标记分配一个数字。

- 词嵌入（`Word Embeddings`）：通过深度学习技术，单词被表示为多维向量（称作“嵌入”）。这些向量能够捕捉单词之间的语义关系。语义上相似的单词在向量空间中具有相似的方向。通过计算这些向量之间的余弦相似度，模型可以确定单词之间的相关性。

- 架构发展（`Architecture Development`）：语言模型的设计（即其架构）随着时间不断演进，以更好地捕获单词的上下文。早期的循环神经网络（`RNN`）试图通过维护一个“隐藏状态”来记住句子中的上下文，但存在信息丢失或相关信息被淹没的挑战。

## Transformer 架构在语言模型发展中扮演了什么角色？

`Transformer` 架构是生成式 AI 应用的关键。它于 2017 年由 Vaswani 等人在论文《Attention Is All You Need》中引入，彻底改变了模型理解和生成文本的能力。`Transformer` 引入了位置编码和多头注意力机制，使其能够并行处理单词，而不是像 `RNN` 那样顺序处理，从而大大提高了效率和性能。

## Transformer 架构的关键创新点是什么？

`Transformer` 架构的两个主要创新是：

- 位置编码（`Positional Encoding`）：在将文本转换为向量时，位置编码将单词在句子中的位置信息与单词本身的语义信息结合起来。这使得模型无需按顺序处理文本也能理解单词的顺序和位置对句子含义的重要性。

- 多头注意力（`Multi-head Attention`）：这是 `Transformer` 处理文本的核心技术。注意力机制允许模型将新信息映射到已学习的信息，以理解其内容。多头注意力意味着模型可以并行地多次处理单词，从句子中提取不同类型的信息，从而更有效地捕捉上下文和关系。

## 大型语言模型（`LLM`）和小型语言模型（`SLM`）有什么区别？

语言模型通常分为两类：大型语言模型（`LLM`）和小型语言模型（`SLM`）。

大型语言模型（`LLM`）和小型语言模型（`SLM`）在多个方面存在差异，主要体现在训练数据、参数数量、语言生成能力以及部署和微调的便利性上。

以下是它们之间的主要区别：

- 训练数据：

- `LLM` 使用大量文本进行训练，这些文本通常通过从互联网和其他正式出版物中获取数据来代表广泛的通用主题。

- `SLM` 则使用更小、更关注特定主题的数据集进行训练。

- 参数数量：

- `LLM` 在训练时具有数十亿（甚至数万亿）的参数，这些参数是应用于向量嵌入的权重，用于计算预测的令牌序列。

- `SLM` 的参数通常少于 `LLM`。

- 语言生成能力：

- `LLM` 能够在各种对话上下文中展示全面的语言生成功能。

- `SLM` 专注于特定的词汇，这使得它们在特定对话主题中有效，但在更通用的语言生成方面效率较低。

- 部署和微调：

- `LLM` 的庞大尺寸可能会影响其性能，并使其难以在本地设备和计算机上部署。使用更多数据微调 `LLM` 以自定义其主题专业知识可能非常耗时且成本高昂，因为它需要大量的计算能力。

- `SLM` 较小的尺寸可以提供更多部署选项，包括在设备和本地计算机上的本地部署；并且使其更快、更轻松进行微调。尽管如此，`SLM` 的微调也可能耗时且成本高昂。

## 开发者如何利用语言模型来构建生成式 AI 应用程序？

开发者通常不需要从头开始训练模型。他们可以使用预先训练好的语言模型来构建生成式 AI 应用程序。有些模型是开源的，可以公开使用；而另一些则在专有目录中提供。开发者可以根据应用程序的需求，选择大型语言模型（`LLM`）或小型语言模型（`SLM`），并进行微调以适应特定主题或任务。

## 如何通过提示工程提高生成式 AI 的响应质量？

生成式 AI 助手的响应质量不仅取决于所使用的语言模型，还取决于用户提供的“提示”（`prompts`）。“提示工程”描述了改进提示的过程。可以通过以下方法改进生成式 AI 助手的响应：

- 设定具体的、希望助手执行的目标。

- 提供信息来源，将响应基于特定的信息范围。

- 添加上下文，最大限度地提高响应的相关性。

- 为响应设置明确的预期（例如，格式、语气、长度）。

- 根据以前的提示和响应进行迭代，以优化结果。

此外，代理通常会优化提示，例如添加系统消息来设置模型行为的约束和风格，或包含当前会话的对话历史记录以保持上下文。

## 语言模型是如何实现“上下文”理解的？

语言模型理解上下文的能力是其能够生成连贯和相关文本的关键。在 `Transformer` 架构出现之前，循环神经网络（`RNN`）试图通过顺序处理单词并维护一个“隐藏状态”来捕捉上下文。然而，这种方法存在局限性，即重要信息可能在长序列中被稀释或丢失。

`Transformer` 架构通过其独特的“注意力”机制克服了这些挑战。它允许模型并行处理句子中的每个单词，并且通过计算单词之间的“查询”、“键”和“值”向量，模型能够识别句子中哪些单词对理解当前单词或预测下一个单词最重要，从而有效地捕捉和利用长距离的上下文信息，而不会像 `RNN` 那样随着序列的延长而遗忘早期信息。位置编码也进一步确保了单词顺序的上下文信息被保留。

# 自然语言处理概念简介

`https://learn.microsoft.com/zh-cn/training/modules/introduction-language/`

## 什么是自然语言处理（`NLP`）的基础？

自然语言处理（`NLP`）的基础涉及通过计算机对文本进行统计分析，以推断语义含义。这通常从将文本分解成称为“令牌”的基本单元开始，然后进行各种分析，如统计技术和深度学习模型，以理解语言。

## “令牌化”在 `NLP` 中意味着什么？

“令牌化”是 `NLP` 中的第一步，指将文本主体（语料库）分解成更小的单元，称为“令牌”。最简单的情况下，每个不同的单词都可以视为一个令牌。然而，根据特定的 `NLP` 问题，令牌也可以是部分单词、单词与标点符号的组合。例如，短语“we choose to go to the moon”可以分解为“we”、“choose”、“to”、“go”、“the”、“moon”等令牌。

## 在令牌化过程中有哪些重要的文本预处理概念？

在令牌化过程中，有几个重要的文本预处理概念可以提高分析效果：

- 文本规范化：在生成令牌之前，选择删除标点符号并将所有单词转换为小写。这有助于提高依赖单词频率的分析的整体性能。

- 停用词移除：移除“the”、“a”、“it”等干扰词。这些词通常对语义意义贡献不大，排除它们有助于解决方案更好地识别重要词。

- `N` 元语法：将多个词视为一个组（例如，“I have”、“the moon”）。一个词是 `unigram`，两个词是 `bi-gram`，三个词是 `tri-gram`，以此类推。这有助于机器学习模型更好地理解文本。

- 词干分析：一种算法技术，用于在计数之前合并具有相同词根的词（例如，“power”、“powered”和“powerful”都被视为同一令牌）。

## `Naïve Bayes` 在 `NLP` 中是如何应用的？

`Naïve Bayes` 是一种统计技术，最初用于电子邮件过滤，以区分垃圾邮件和非垃圾邮件。它通过比较两个文档来确定哪些令牌与被标记为垃圾邮件的电子邮件相关联。换句话说，这种方法发现哪些词组（通常称为“词袋特征”）只出现在一种类型的文档中，而不出现在另一种类型中。例如，“miracle cure”、“lose weight fast”和“anti-aging”这些词可能在关于可疑健康产品的垃圾邮件中更频繁地出现。尽管它比简单的基于规则的模型更有效，但它相对简单，因为它只考虑单词或令牌的存在，而不考虑位置。

## 什么是 `TF-IDF` 以及它在 `NLP` 中的作用？

`TF-IDF`（词频-逆文档频率）是一种统计技术，它通过比较一个文档中单词的频率与整个文档库中单词的频率来评估单词的重要性。通过理解单词使用的上下文，`TF-IDF` 可以根据特定主题对文档进行分类。它常用于信息检索，以帮助理解要搜索的相关词汇或令牌。`TF-IDF` 计算一个分数，该分数基于单词或术语在一个文档中的出现频率与其在整个文档集中的总体频率的比较。该技术假设在一个特定文档中频繁出现但在许多其他文档中相对不频繁出现的单词具有高度相关性。

## 语义语言模型是如何工作的？

语义语言模型通过将语言令牌编码为称为“嵌入”的向量（多值数字数组）来工作。这些向量表示多维空间中的方向和距离。语义上相似的令牌会产生方向相似的向量。例如，“狗”和“小狗”的嵌入向量会指向几乎相同的方向，而“滑板”的向量则会指向一个截然不同的方向。现代语言模型在此基础上更为复杂，通常使用更多维度和多种方法来计算嵌入，从而支持各种 `NLP` 任务。

## “语料库”在 `NLP` 的上下文中是什么意思？

在 `NLP` 的上下文中，“语料库”是指用于机器学习任务的大型结构化文本文档集合。语料库是训练、测试和评估各种 `NLP` 模型的基础资源。

## 机器学习如何应用于文本分类，例如情感分析？

机器学习通过使用分类算法（如逻辑回归）来训练模型，该模型基于一组已知的分类对文本进行分类。这种方法的常见应用是训练将文本分类为“正”或“负”的模型，以执行情感分析或观点挖掘。通过使用标记化的文本作为“特征”和情感（0 或 1）作为“标签”来训练模型，该模型能够封装令牌与情感之间的关系。例如，包含“great”、“tasty”等词的评论更可能被分类为“正面”，而包含“terrible”、“slow”等词的评论则更可能被分类为“负面”。

# Azure 中的自然语言处理入门

## `Azure AI` 翻译功能如何工作？

实体链接 则在识别出实体的基础上，通过链接到特定引用来帮助消除实体的歧义。对于识别出的实体，服务会返回相关的维基百科文章的 URL。例如，如果识别出“西雅图”，它可能会提供西雅图维基百科页面的链接。

# 计算机视觉概念简介

`https://learn.microsoft.com/zh-cn/training/modules/introduction-computer-vision/`

## 计算机视觉的主要目标是什么，它与图像处理有何不同？

计算机视觉的主要目标是从图像中提取意义或可操作的见解。这通常需要创建机器学习模型，这些模型通过大量现有图像进行训练以识别特征。这与图像处理不同，图像处理侧重于通过应用滤镜（例如，模糊、锐化、颜色反转或边缘检测）来修改图像的像素值以创建视觉效果。虽然两者都涉及图像，但计算机视觉的目标是“理解”图像，而图像处理的目标是“修改”图像。

## 卷积神经网络（CNN）在计算机视觉中扮演什么角色？

卷积神经网络（CNN）是计算机视觉中最常见的机器学习模型架构之一。它是一种深度学习架构，使用滤镜从图像中提取数字特征图。这些特征值随后被输入到深度学习模型中，以生成标签预测，例如图像分类场景中图像的主题。CNN 通过在训练过程中调整滤镜权重来提高准确性，直到它们能够最好地提取有助于识别不同对象的特征。

## CNN 如何训练以识别图像中的对象？

CNN 的训练过程包括几个步骤。首先，将带有已知标签的图像输入到网络中（例如，苹果、香蕉、橙子）。然后，使用一个或多个滤镜层从每个图像中提取特征，生成称为特征图的数值数组。这些特征图被展平为单维特征值数组，然后输入到全连接神经网络中。神经网络的输出层使用 `softmax` 或类似函数为每个可能的类别生成概率值。在训练期间，将这些预测概率与实际类别标签进行比较，计算模型中的“损失”，并调整神经网络和滤镜核中的权重以减少损失。此过程会重复多个“时期”，直到学习到一组最佳权重。

## 图像处理中的“滤镜”或“卷积”是如何工作的？

图像处理中的滤镜（也称为卷积核）是一个或多个像素值数组，用于通过修改图像的像素值来创建视觉效果。滤镜通过在图像上“卷积”来工作。这意味着滤镜核会滑过图像的每个小块（例如 3x3 像素），计算每个像素值与相应权重值的加权和。这个结果成为新图像中的一个像素值。这个过程在整个图像中重复，从而产生一个新图像，其中原始图像已被转换。例如，拉普拉斯滤镜可以突出图像中对象的边缘。

## 什么是转换器模型，它最初是为哪个 AI 领域开发的？

转换器模型是另一种神经网络架构，最初是在自然语言处理（NLP）领域开发的。它们通过处理大量数据来工作，并将语言“标记”（代表单个单词或短语）编码为基于矢量的“嵌入”（数值数组）。这些嵌入旨在捕获标记之间的语义关系，使得常用语境中的标记具有更紧密对齐的向量。转换器的成功促成了文本分析、翻译和语言生成等复杂 NLP 解决方案的开发。

## 多模态模型如何将计算机视觉与自然语言处理相结合？

多模态模型是受转换器在 NLP 中成功启发而开发的。它们通过使用大量带字幕的图像进行训练，这些图像没有固定的标签。多模态模型包含一个图像编码器，它从像素值中提取图像特征，以及一个语言编码器，它创建文本嵌入。整个模型封装了自然语言标记嵌入和图像特征之间的关系。这种方法允许模型理解图像和相关文本数据之间的连接。

## 什么是基础模型，它们在现代视觉模型中如何使用？

基础模型是预训练的通用模型，它们在大量数据上进行训练，并作为构建各种专业任务的自适应模型的基础。在现代视觉模型中，多模态基础模型利用互联网上大量带字幕的图像进行训练，并包含语言编码器和图像编码器。用户可以与这些基础模型进行交互并对其进行调整，以执行特定的计算机视觉任务，例如图像分类（识别图像所属的类别）、对象检测（定位图像中的单个对象）、图像字幕（生成图像的适当描述）和图像标记（为图像编译相关文本标签列表）。

## 现代视觉模型有哪些关键发展，它们有望实现什么？

现代视觉模型的主要进展包括卷积神经网络（CNN）的持续改进以及转换器架构的出现，后者最初在自然语言处理中取得成功，并已应用于图像数据。这导致了多模态模型的发展，这些模型结合了图像和文本数据，通过学习图像特征和自然语言标记嵌入之间的关系来理解带字幕的图像。这些模型通常作为在大量互联网数据上预训练的“基础模型”发布。这些尖端的发展有望推动人工智能解决方案的进步，使其能够实现更复杂的计算机视觉任务，例如生成图像描述或执行更细致的对象识别。

# AI 驱动的信息提取概念简介

`https://learn.microsoft.com/zh-cn/training/modules/introduction-information-extraction/`

## 什么是 AI 驱动的信息提取？

AI 驱动的信息提取是一种利用人工智能技术从各种类型的内容中自动获取可操作洞察的方法。这些内容可以是结构化的（如发票、表格）或非结构化的（如电子邮件、录音、图像和视频）。核心思想是通过机器学习模型处理数据，从而取代手动检查，以识别、提取和理解数据中的关键信息。

## 信息提取过程通常包含哪些步骤？

信息提取过程通常遵循以下四个步骤：

1.  源识别：确定信息所在的位置以及是否需要将其数字化。

1.  提取：利用基于机器学习的多种技术来理解和提取数字化内容中的数据。

1.  转换和构造：将提取的数据转换为结构化格式，例如 JSON 或表格。

1.  存储与集成：将处理后的数据存储在数据库、数据湖或分析平台中，以供进一步使用。

内容类型和所需的洞察类型决定了信息提取所需的技术。

## 光学字符识别 （OCR） 在图像数据提取中扮演什么角色？

光学字符识别 （OCR） 是计算机视觉技术的基础组成部分，它允许计算机识别图像中包含文本的元素。它使用经过训练的机器学习模型将单个形状识别为字母、数字、标点符号或其他文本元素，从而将图像中的打印或手写文本数字化并逐行逐字地读取。邮政服务在早期曾利用此功能实现基于邮政编码的邮件自动分拣。

## 什么是文档智能，它与 OCR 有何关系？

文档智能是一种 AI 功能，它扩展了 OCR 的能力，不仅处理文本，还能为其附加语义含义。语义含义指的是在给定上下文中，单词、短语或符号的预期含义或解释，它关注单词或句子实际传达的内容，而非仅仅是文本定义。例如，在处理收据时，文档智能可以结合 OCR 将文本数字化，并提取出商家名称、购买日期、商品价格和总计等具有语义意义的字段值。

## 在表单中提取数据时，“字段值对”和“边界框”是什么意思？

在表单中提取数据时：

+   字段值对 用于描述数据的语义含义。字段名称 是数据输入的键或类型（例如“地址”），而值 则是与字段名称对应的特定内容数据（例如“主街 123 号”）。

+   边界框 用于识别表单中的数据。它是围绕特定数据片段的坐标（例如 `[4.1， 2.2]`，`[4.3， 2.2]`，`[4.3， 2.4]`，`[4.1， 2.4]`），机器学习模型通过识别这些边界框坐标位置中的模式来解释文档或表单中的数据。

此外，数据提取结果还会关联一个介于 0 和 1 之间的置信度百分比，表示可能的准确度级别。

## 什么是多模态数据提取？

多模态数据提取是指将多种 AI 驱动的信息提取技术组合起来，对多种形式的内容（从文档到视频和音频）执行数据提取。除了视觉和文档智能，它还可以包括：

+   自然语言处理 （NLP）：用于从书面或口语中查找关键短语、实体、情绪等。

+   语音识别：提取口语并将其转录为可处理的数据（通常是文本）。

+   生成式 AI：通过允许用户定义自己的字段和字段描述来增强数据提取过程，尤其适用于处理非结构化内容。

这种组合可以帮助数字资产管理、工作流自动化和生成更深层次的洞察。

## 知识挖掘中的数据提取如何运作？

知识挖掘解决方案旨在从大量通常是非结构化的数据中自动提取信息。其过程包括：

1.  文档破解：打开文档格式（如 PDF），将内容提取为 ASCII 文本，以便进行分析和索引。

1.  AI 扩充：对原始内容应用 AI 以提取更多信息，例如为照片添加字幕或评估文本情绪。

1.  知识存储：将 AI 扩充管道的输出保留在此处，以供独立分析或下游处理。

1.  搜索索引填充：生成的数据（通常序列化为 JSON 格式）填充搜索索引，该索引结构类似于带有字段、数据类型和字段属性的表格。 当用户进行搜索查询时，搜索引擎会在搜索索引中查找相关信息，从而实现可搜索性。

## AI 驱动的信息提取在哪些方面对搜索解决方案有所贡献？

AI 驱动的信息提取通过使数据具有可搜索性，极大地增强了搜索解决方案。它通过以下方式支持搜索解决方案的组件：



+   AI 驱动的信息提取：确保了内容在被编入索引之前得到丰富和结构化，从而使搜索更有效。

+   执行引擎：能够跨填充了 AI 提取和扩充数据的搜索索引执行查询。

+   排名引擎：可以根据相关性、新鲜度、受欢迎程度或 AI 信号对搜索结果进行排序，这些信号通常来源于 AI 提取的深度信息。

通过这些贡献，AI 驱动的信息提取使得从大量数据中检索相关信息成为可能，从而提供一个功能强大的搜索体验。

## Azure AI 内容理解服务有哪些主要功能？

Azure AI 内容理解是一项基于生成式 AI 的多模式分析服务，能够分析多种格式的内容以提取洞察。它的功能包括：

+   文档分析：超越了简单的 OCR（光学字符识别），能够根据预定义的架构从基于文本的表单和文档中提取字段及其对应的值。例如，它可以从发票中识别并提取供应商名称、发票号码、项目明细等信息，即使这些字段的标签不同或没有标签。

+   音频分析：可以分析音频文件，提供转录、摘要和其他关键洞察。例如，它可以从语音邮件中提取呼叫者、消息摘要、请求的操作和回拨号码等信息。

+   图像和视频分析：支持分析图像和视频，以根据自定义架构提取信息。例如，它可以从会议视频或图像中识别并统计现场和远程参会者数量、会议地点等信息，甚至可以用于分析通话期间发言人及其内容，以及会议概要和行动清单。

## Azure AI 搜索如何在知识挖掘解决方案中发挥作用？

Azure AI 搜索是一个用于索引和搜索数据的云服务，它通过集成 AI 技能和与其他 AI 服务（如 Azure AI 视觉和 Azure AI 文档智能）协同工作，成为构建数字资产管理和知识挖掘解决方案的强大平台。其核心功能包括：

+   索引器：定义了一个可重复的过程，用于从各种数据源（如 Azure 存储容器中的文档或数据库）引入数据。

+   文档破解：从文档中提取内容，例如从 PDF 文档中提取文本和图像数据。

+   应用 AI 技能：利用 Azure AI 视觉生成图像的标签和标题，使用 Azure AI 语言生成情感或命名实体，以及使用 Azure AI 文档智能从表单中提取字段值，从而从数据中检索信息并生成字段层次结构。

+   创建可搜索索引：将提取的字段保留为可搜索的索引，用户可以基于关键字和筛选条件在其中搜索信息。

+   知识存储：除了创建可搜索索引，Azure AI 搜索还可以将提取的数据资产保存到 Azure 存储中的知识存储中，包括字段值表、提取的图像以及表示数据结构的 JSON 文档。

## Azure AI 文档智能和 Azure AI 内容理解在表单和文档处理方面有何区别？

虽然 Azure AI 内容理解和 Azure AI 文档智能都可以从表单和文档中提取字段，但它们有不同的侧重点：

+   Azure AI 文档智能：专门设计用于支持复杂的文档和表单处理场景。它提供了一个大型的预构建模型库，涵盖了从简单的收据到复杂的税单等多种表单类型。此外，它还支持使用带有标记示例的文档来训练自定义模型，从而处理特定的、复杂的文档类型。

+   Azure AI 内容理解：更侧重于多模式内容分析，包括文档、音频、图像和视频。在文档方面，它强调基于架构的字段提取，即使字段名称不同或缺失也能识别。

总的来说，Azure AI 文档智能在处理特定、复杂表单方面具有更强大的预构建模型和自定义模型训练能力，而 Azure AI 内容理解则提供更广泛的多模式内容理解能力，适用于需要从多种数据类型中提取信息的场景。

## Azure AI 视觉图像分析可以提供哪些类型的洞察？

Azure AI 视觉图像分析服务主要用于从照片或小型扫描文档中提取洞察，包括：

+   自动字幕和标签生成：能够分析图像并生成描述图像的标题、针对图像中主要对象建议的一组密集辅助字幕，以及帮助对图像进行分类的标签集合。例如，它可以识别“一个男人牵着狗散步”，并生成“户外”、“汽车”、“狗”等标签。

+   对象检测：可以检测图像中常见对象和人员的类型和位置。

+   光学字符识别 （OCR）：当图像包含印刷文本或手写文本时，可以使用 OCR 技术识别每行文本的位置和内容以及每个单词。这对于从名片等简单文档中提取少量自由格式文本非常有用。

## Azure AI 服务如何支持数据捕获和业务流程自动化？

Azure AI 服务通过其强大的信息提取能力，能够显著支持数据捕获和业务流程自动化：

+   数据捕获：服务能够智能扫描图像以捕获和存储数据值。例如，使用 Azure AI 视觉从名片中提取联系信息。

+   业务流程自动化：通过从表单中读取数据并利用这些数据触发工作流。一个典型的例子是从发票中提取成本中心和计费信息，并将其自动路由到相应的应付账款部门进行处理，从而实现业务流程的自动化。

## 如何使用 Azure AI 服务实现会议摘要和分析？

Azure AI 服务能够分析和汇总录制的电话对话或视频电话会议中的要点，从而实现会议摘要和分析。

+   Azure AI 内容理解：特别适用于此场景。它可以分析会议的录制视频或音频，并根据预定义的架构提取关键信息，例如参会者（现场和远程）、会议地点、讲话人及其内容、讨论概要以及会议中指定的行动列表。这可以自动化团队会议的记录和任务分配，大大提高效率。

## Azure AI 服务在数字资产管理 （DAM） 中的应用是什么？

在数字资产管理（DAM）中，Azure AI 服务通过自动化数字资产（如图像或视频）的标记和索引来管理它们：

+   Azure AI 搜索：结合 AI 技能管道，能够系统地从图像或视频中提取和索引信息。

+   Azure AI 视觉图像分析：可以自动为图像生成描述性标题和相关标签，例如识别图片中的对象、场景或活动。 通过这些能力，可以轻松创建可搜索的库存照片库或视频库，使用户能够通过关键字和筛选条件快速找到所需的数字资产，从而简化数字资产的管理和检索。

## 知识挖掘的核心概念和 Azure AI 服务的贡献是什么？

知识挖掘是从结构化和非结构化数据中提取关键信息，用于进一步分析和报告的过程。Azure AI 服务在这一领域做出了重要贡献，其核心概念包括：

+   信息提取：利用 AI 模型从多种格式（文本、音频、图像、视频）中识别和提取关键数据点。

+   模式识别：通过学习和应用预定义或自定义的架构，识别数据中的结构和关系。

+   洞察生成：将提取的信息转化为有意义的洞察和可操作的数据。

Azure AI 服务通过以下方式支持知识挖掘：

+   Azure AI 搜索：作为核心平台，通过索引器、AI 技能和可搜索索引，系统地从各种数据源中提取和组织信息，并能将提取的数据保存到知识存储中，供后续分析。

+   Azure AI 内容理解：提供多模式分析能力，从复杂的文档、音频、图像和视频中提取结构化洞察。

+   Azure AI 文档智能：专注于从各种表单中精准提取字段和值，无论是预构建模型还是自定义模型。

+   Azure AI 视觉图像分析：从图像中提取视觉洞察，如对象检测、OCR 和描述性标记。

例如，从扫描的记录中编译人口普查数据以填充数据库，这就是一个典型的利用 Azure AI 服务进行知识挖掘的场景，它将非结构化数据转化为可分析的结构化信息。
