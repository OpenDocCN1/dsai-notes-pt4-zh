
# 基于 AI 开发平台的企业级应用构建实战

> 来源：[https://zsyhjtnsa5.feishu.cn/docx/Kgpvd4ZoWohvLqxdSHUcUCebnKh](https://zsyhjtnsa5.feishu.cn/docx/Kgpvd4ZoWohvLqxdSHUcUCebnKh)

## 课程目标：

通过为期四天的强化培训，使学员全面掌握 AI 开发平台的核心功能与应用构建方法。课程将覆盖从平台基础操作、提示词设计、可视化工作流编排，到外部 API 工具封装和模型微调的全流程，确保学员能够独立开发、调试并部署满足复杂业务需求的 AI 应用。

## 培训对象：

招投标工程监理的业务人员、开发人员（统一授课）

## 建议课时：4 天（24 小时）

## 课程大纲

### 模块一：AI 开发平台核心功能解析 （对应需求 1）

+ 目标：掌握 AI 开发平台各项核心功能的使用方法。

+ 内容看点：

   1. 平台导览与核心理念：介绍平台作为 LLMOps 的价值，熟悉仪表盘、应用管理界面。

   1. 模型管理：

      - 连接与配置大语言模型（以 DeepSeek API 为例）。
      - 管理模型供应商与凭证，理解不同模型的成本与能力差异。

   1. 数据集管理（知识库）：

      - 创建第一个知识库。
      - 上传业务文档（如：历史标书、技术规范）。
      - 理解文本处理、分块与向量化的后台机制。

   1. 应用编排与发布初探：概览工作流画布与 API 发布界面，为后续课程建立宏观认知。

+ 实践环节：学员登录平台，完成模型配置，并创建、上传文档到自己的第一个“招投标知识库”。

### 模块二：提示词精讲与实战（对应需求 2）

+ 目标：掌握基于平台开发工具设计、调试并优化提示词的方法。

+ 内容看点：

   1. 提示词核心原则：角色扮演、清晰指令、提供示例、思维链（CoT）。

   1. 平台提示词编辑器实战：

      - 在平台内为“聊天机器人”或“工作流”应用编写系统指令（System Prompt）。
      - 变量的使用：如何在提示词中插入动态内容（如用户名、查询问题）。

   1. 调试与优化：

      - 利用平台的“调试与预览”功能，实时查看模型输出。
      - 迭代优化提示词，引导模型生成更精准、更符合格式要求的回复。

+ 实践环节：针对“自动生成监理周报摘要”的场景，在平台内进行提示词的设计、调试与优化。

### 模块三：低代码 AI 应用构建（对应需求 3）

+ 目标：掌握通过拖拽节点方式构建一个包含完整业务逻辑的 AI 应用工作流。

+ 内容看点：

   1. 工作流画布核心概念：理解节点（Node）、连接线（Edge）与数据流。

   1. 关键节点使用方法详解：

      - 开始/结束节点：定义工作流的输入与输出。
      - 大模型调用节点：如何在工作流中调用 LLM 并使用模块二设计的提示词。
      - 知识库配置接入节点：实现 RAG，让工作流具备基于私有知识的问答能力。
      - 代码执行节点：如何嵌入 Python/Node.js 脚本处理简单的数据逻辑。

+ 实践环节：构建一个“内部规范查询助手”工作流：用户输入问题 -> 接入知识库检索 -> 大模型根据检索内容生成答案。

### 模块四：低代码 AI 应用构建 - 进阶 （对应需求 4）

+ 目标：掌握通过复杂逻辑构建应用的方法。

+ 内容看点：

   1. 变量管理与数据传递：

      - 如何在不同节点之间传递和使用变量（如将知识库的检索结果传递给 LLM 节点）。

   1. 高级逻辑控制节点：

      - 条件判断（`If/Else`）：根据特定条件（如问题类型）让工作流走向不同分支。
      - 并行与循环（如有支持）：如何设计并行任务提升效率，或处理需要循环迭代的场景。

+ 实践环节：升级“规范查询助手”：增加一个条件判断节点，如果知识库未找到答案，则引导工作流走向“转人工客服”的分支。

### 模块五：API 封装与 `Agent` 工具实现 （对应需求 5）

+ 目标：掌握实现外部 API 从接入、定义、调试到最终发布为 `Agent` 可调用工具的方法。

+ 内容看点：

   1. `Agent` 与工具（`Tool`）的概念：为何需要让 AI 调用外部工具？

   1. API 封装全流程：

      - 接入：在平台工具创建界面，配置 API 的 `URL`、请求方法（`GET/POST`）和认证方式（API Key）。
      - 定义：用自然语言清晰描述工具的功能、输入参数和输出格式，以便 `Agent` 理解和调用。
      - 调试：在平台内直接测试 API 工具，确保连接成功、数据返回正常。
      - 发布与使用：将封装好的工具发布，并在 `Agent` 或工作流中进行调用。

+ 实践环节：提供一个公共天气或汇率查询 API，引导学员将其封装成一个可被 `Agent` 调用的工具。

### 模块六：`Agent` 应用与工作流整合

+ 目标：理解 `Agent` 的工作模式，并将其与工作流、工具进行综合应用。

+ 内容看点：

   1. Dify `Agent` 概念解析：理解其“思考-行动”循环的工作模式。

   1. 为 `Agent` 设计 Prompt：如何引导 `Agent` 规划任务、选择并使用工具。

   1. 综合应用：在一个工作流中，先通过知识库回答问题，如果问题涉及实时信息，则调用上一步封装的 API 工具。

+ 实践环节：构建一个“项目信息查询助手”，它既能回答内部规范，又能调用外部 API 查询实时建材价格。

### 模块七：模型定制工坊（对应需求 6）

+ 目标：掌握使用 AI 开发平台进行模型微调的方法。

+ 内容看点：

   1. 理论先行：何时选择微调（`Fine-tuning`）vs。 RAG? （深入讲解微调的优势与适用场景：改变模型说话风格、学习特定领域术语、掌握新技能）。

   1. 平台化模型微调流程详解：

      - 数据准备：讲解并演示微调所需的数据集格式（如 JSONL 格式的指令-回答对）。
      - 数据集上传：将准备好的数据上传到平台的训练模块。
      - 启动训练任务：在平台界面选择基础模型、配置超参数（如 `Epochs`）、启动微调任务。
      - 监控与管理：查看训练任务状态、训练日志和（如有）性能指标。
      - 部署与调用：如何将微调后的专属模型部署，并在应用中进行调用。

+ 实践环节：提供一份包含“招投标行业特定术语和沟通风格”的小型数据集，指导学员在平台上完成一次完整的模型微调流程。

### 模块八：结业项目：构建“全流程招投标智能辅助系统”

+ 目标：综合运用四天所学，从零到一构建一个复杂的、有实际价值的 AI 应用。

+ 项目要求：

   1. 知识库能力：能回答关于公司历史项目和技术规范的问题。

   1. 工具调用能力：能调用外部 API 查询最新的法规或供应商信息。

   1. 定制化模型能力：使用上午微调好的模型，生成带有公司特定风格的正式文书片段。

   1. 复杂工作流：通过逻辑判断，智能地选择是使用知识库、调用工具还是直接生成。

+ 形式：分组进行，讲师巡场辅导，最后进行成果演示与分享。
