
# Windows Server 系统安全与运维管理

> 来源：[https://zsyhjtnsa5.feishu.cn/docx/GoBDdaqoYoN21YxhxCdcZ38Snpf](https://zsyhjtnsa5.feishu.cn/docx/GoBDdaqoYoN21YxhxCdcZ38Snpf)

## 课程梗概

本课程系统性地介绍了 Windows Server 环境中的核心安全配置与管理任务，涵盖身份验证与授权、文件系统与访问控制、共享资源管理、系统更新与维护、恶意软件防护、网络防火墙、加密技术以及故障排除与性能监控等内容。通过理论与实践结合，帮助学员掌握 Windows Server 安全策略的部署、管理与优化，提升企业环境中的安全防护能力。

## 课程目标

+ 理解 Windows Server 中的身份验证机制及用户账户管理方法

+ 掌握 NTFS/ReFS 文件系统特性及文件访问权限配置

+ 学会配置共享文件夹并合理结合 NTFS 权限

+ 熟悉 Windows Server 更新策略及 Windows Update 管理

+ 了解常见安全威胁及使用 Microsoft Defender 进行防护

+ 掌握 BitLocker 和 EFS 等加密功能的使用与恢复

+ 掌握系统性能监控、故障诊断与问题解决的基本流程和工具

## 目标受众

+ 系统管理员

+ 网络管理员

+ 安全运维工程师

+ IT 支持人员

+ 希望提升 Windows Server 安全管理技能的技术人员
