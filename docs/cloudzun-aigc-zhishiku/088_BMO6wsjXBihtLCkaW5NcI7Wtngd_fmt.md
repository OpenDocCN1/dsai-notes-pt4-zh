
# MS-4022: 使用 Copilot Studio 扩展 Microsoft 365 Copilot

> 来源：`https://zsyhjtnsa5.feishu.cn/docx/VkoyduvaZoKgLExWItJc2JoYnYT`

## 课程描述：

本学习路径旨在教授如何利用 Microsoft Copilot Studio 构建智能体（agent），从而扩展 Microsoft 365 Copilot 的功能。学员将学习如何使用低代码工具创建声明式智能体，添加自定义知识、工具和连接器，并将其部署到 Microsoft 365 环境中。课程结束时，学员将具备创建专门智能体的实践技能，以提高组织内部的生产力和效率。

## 目标受众：

- 对使用 Copilot Studio 构建智能体感兴趣的 IT 专业人员和开发人员。
- 熟悉 Microsoft 365 Copilot 并希望扩展其功能的用户。

## 先决条件：

- 基本了解 Microsoft 365 Copilot 及其工作原理。
- 具备访问 Copilot Studio 环境并创建智能体的权限。

## 课程大纲

### 模块 1：Microsoft 365 Copilot 声明式智能体简介

#### 学习目标：

- 确定哪些场景适合使用声明式智能体自定义和扩展 Microsoft 365 Copilot。
- 描述自定义知识和自定义操作的功能。

#### 主要课题：

- 什么是声明式智能体？
- 声明式智能体的工作原理。
- 何时使用声明式智能体。

### 模块 2：使用 Copilot Studio 构建第一个 Microsoft 365 Copilot 声明式智能体

#### 学习目标：

- 创建一个针对特定场景定制的智能体，以扩展 Microsoft 365 Copilot。
- 使用自定义知识库确保智能体提供相关且准确的回复。

#### 主要课题：

- 创建新的声明式智能体。
- 添加自定义知识来源（如上传文档或指向公共 URL）。
- 添加建议的提示。
- 实践练习：创建智能体并添加自定义知识。

### 模块 3：使用连接器工具扩展 Copilot Studio 中的声明式智能体

#### 学习目标：

- 使用连接器工具将声明式智能体连接到外部服务和数据源。
- 配置开箱即用的连接器，并将其添加到扩展 Microsoft 365 Copilot 的智能体中。

#### 主要课题：

- 创建新的连接器工具。
- 配置连接器工具。
- 将连接器工具添加到声明式智能体。
- 测试连接器工具。

### 模块 4：使用提示工具扩展 Copilot Studio 中的声明式智能体

#### 学习目标：

- 通过使用提示工具自定义智能体的生成式回复。
- 制作自定义提示，针对大型语言模型（LLM）测试提示，并将提示工具添加到声明式智能体。

#### 主要课题：

- 创建提示工具。
- 测试提示工具。
- 将提示工具添加到声明式智能体。

### 模块 5：部署自定义智能体到 Microsoft 365 Copilot

#### 学习目标：

- 发布和部署您创建的自定义智能体，使其在 Microsoft 365 Copilot 中可用。
- 了解如何通过 Teams 或 Microsoft 365 管理中心提交和管理智能体。

#### 主要课题：

- 发布智能体。
- 在 Microsoft 365 Copilot 渠道中启用智能体。
- 提交智能体供管理员审批和发布（例如发布到企业内部应用商店）。
- 故障排除和监控智能体性能。
