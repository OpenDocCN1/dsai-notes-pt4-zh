# 产品需求文档（PRD）

## 1. 应用目的
为在线购物者提供一个水果产品订购的静态原型，展示基本购物流程和界面设计。

## 2. 目标受众
有兴趣在线订购水果产品的用户，适用于桌面和移动设备浏览。

## 3. 功能特性

### 3.1 页面与导航
- **商品列表页（Products）**：展示所有水果产品，含名称、单价、图片（Emoji），可选择数量并添加至购物车。
- **商品详情页（ProductDetails）**：显示选中产品的详细信息，含名称、描述、单价、图片（Emoji），可返回商品列表。
- **购物车页（ShoppingCart）**：展示已添加商品，含名称、数量、总价，可修改数量或移除商品。
- **结算页（Checkout）**：显示购物摘要，含所有商品、数量、价格、总价，提供“处理订单”按钮。
- **左侧导航菜单**：允许用户在上述页面间切换，宽度小于300px时显示缩写。

### 3.2 数据与交互
- 使用静态数据集，包含10种水果产品（名称、描述、单价、Emoji图片）。
- 所有数据存储于前端，无后端或数据库集成。
- 用户可在商品列表页选择数量并添加商品至购物车。
- 购物车支持数量修改和商品移除。
- 结算页显示购物摘要和总价。

### 3.3 用户界面与样式
- 动态自适应布局，适配桌面和手机屏幕。
- 左侧导航菜单，宽度小于300px时自动收缩为缩写。
- 基础视觉样式，界面简洁美观，无需高度精修或完全响应式。

## 4. 技术需求
- 前端技术：HTML、CSS、JavaScript（不使用框架）
- 数据：静态数组或对象，包含10种水果产品及相关字段
- 图片：使用Emoji作为产品图片
- 无后端功能（无身份验证、支付、数据库等）

## 5. 非功能性需求
- 页面加载速度快
- 基本浏览器兼容性（主流桌面和移动浏览器）
- 简单可读的代码结构，便于后续扩展

## 6. 用例场景（示例）
1. 用户浏览商品列表，选择苹果，查看详情后返回列表。
2. 用户将香蕉和橙子添加至购物车，修改数量，移除橙子。
3. 用户进入结算页，查看购物摘要并点击“处理订单”。
