## 课程大纲

面向具备编程基础的生成式人工智能技术爱好者和应用开发者们。通过本课程学习后，学员将掌握以下设计、实施和优化大模型驱动解决方案的专业能力：

+ 精通提示词技巧，掌握检索增强和微调的原理与流程。
+ 熟练使用`LangChain`、`Llama-Index`等开发组件。
+ 掌握工程化评测方法，并了解大模型的规范与安全性。
+ 能够使用阿里云百炼平台完成大模型应用的开发、测评、部署与发布。

### 课程内容

#### 第一章：大模型应用开发 (占比 17%)

+ **1.1 `API` 调用**通过`OpenAI API`调用大模型掌握`model`、`temperature`、`top_p`等核心参数实现批量生成与流式生成

+ **1.2 对话管理**理解并应用消息与对话历史

#### 第二章：大模型提示词工程 (占比 15%)

+ **2.1 构建高效提示词**掌握提示词框架（要素、分隔符、模板）理解并有效利用系统角色提示词

+ **2.2 任务导向的应用开发**识别大模型的适用场景开发应用实践（如意图分类、文档审阅与自动修订）

#### 第三章：大模型检索增强（RAG）(占比 20%)

+ **3.1 RAG 应用构建**使用`LlamaIndex`构建 RAG 应用理解 RAG 核心要素：文件解析、文本切片、段落召回与重排序

+ **3.2 RAG 优化**召回优化：句子窗口检索、自动合并检索等实战优化：优化文本解析、标题改写、表格内容增强等

+ **3.3 自动化评测**了解`RAGAS`指标体系掌握 RAG 系统的评测方法

#### 第四章：大模型的微调 (占比 16%)

+ **4.1 微调理论**微调的作用、前提、基本步骤与常用算法

+ **4.2 微调实践**微调数据集的构建微调参数介绍与选择微调模型的评测方法

#### 第五章：多 Agent 及多模态应用 (占比 16%)

+ **5.1 智能体构建**基于百炼`Assistant API`构建智能体理解智能体运行机制

+ **5.2 多模态应用**生成多模态内容（文本、图像、视频）构建个性化语音助手

+ **5.3 复杂 AI 应用**实践多模态交互技术解决方案了解 AI 在医疗、教育等行业的应用

#### 第六章：生产环境应用实践 (占比 16%)

+ **6.1 内容安全合规**识别大模型开发中的内容安全问题了解内容安全合规的检测类型及常用方案

+ **6.2 云上部署安全**了解云服务环境下应用系统的安全要素与解决方案

+ **6.3 模型部署**掌握在云服务（`ECS`、`FC`、`PAI`）中部署模型的方案学习使用`vLLM`进行大模型部署利用函数计算（`FC`）实现 AI 助手的快速发布

## 实验练习

本课程的整体内容以项目式结构进行组织。通过项目式课程设计，学员能够系统掌握所需的核心概念与技能，并运用所学知识解决实际问题。

课程中，学员将扮演教育内容开发公司的一员，首先负责构建一个基于大模型的答疑机器人，以应对新员工入职过程中频繁出现的答疑需求；随后，当公司需要开发教育课程时，学员将借助大模型生成多种形式的教学内容，助力公司达成业务目标。

通过这两个项目的实践训练，旨在引导学员深入思考如何将大模型能力应用于不同行业，最终使其具备面向多样化业务场景，设计并实施大模型驱动解决方案的能力。

+ 为了更贴近实际工作场景，同时有更好的学习体验，建议通过`PAI DSW`上提供的`Notebook`环境进行本节的学习。

+ 亦可访问[GitHub](https://github.com/AlibabaCloudDocs/aliyun_acp_learning/tree/main/LLM_ACP_EN)或[AtomGit](https://atomgit.com/alibabaclouddocs/aliyun_acp_learning)上的课程代码库。
