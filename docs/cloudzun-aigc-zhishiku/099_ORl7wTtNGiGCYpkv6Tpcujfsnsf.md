# 课程大纲

## 培训目标

通过本培训，学员将能够：

+   理解大模型的基本概念与工作原理，具备与相关技术团队有效沟通和协作的基础知识。

+   掌握提升大模型应用效果的关键方法，包括提示词工程、RAG 及 Agent 等常用技术。

+   认识大模型应用过程中可能面临的安全与合规风险，了解相应的防控与治理策略。

+   学会结合实际业务场景，运用大模型处理文本分析、信息抽取、内容生成、翻译及图表分析等任务。

+   初步具备构建面向私有领域知识问答机器人的能力，能够运用所学方法解决实际问题

## 课程内容

**第一章：大模型概念 **

+   人工智能与大模型基础

+   大模型的工作方式

+   大模型的常见应用场景

**第二章：提示词工程**

+   提示词基础与技巧

+    提示词框架

+   业务应用

**第三章：增强大模型应用的能力 **

+   借助 API 让大模型自动化地处理任务

+   大模型插件插件的工作原理

+    RAG（检索增强生成）的工作原理

+   如何通过 RAG 增强大模型在垂直领域的表现

+   改进 RAG 应用效果的方法

**第四章：大模型 Agent **

+   Agent 原理与结构

+   ModelScope-Agent

+   Multi-Agent 系统

+   Agent 系统优化

**第五章：大模型应用的安全合规**

+   大模型的风险识别

+   大模型风险的治理建议与防控方法

+   大模型应用的备案要求与流程
