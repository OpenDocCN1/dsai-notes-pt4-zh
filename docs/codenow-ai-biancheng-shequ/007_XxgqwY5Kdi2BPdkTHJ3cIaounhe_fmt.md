### 3小时前置线上课程

### 2天线下实战（更充足的动手时间，更深入的技术指导）

#### 第一天：Vibe Coding × 文档驱动开发

**核心工具：Gemini 3 Pro + Google AI Studio**

+ AI原生开发思维升级

从“写代码”转向“写产品文档”：你不再是开发者，而是AI团队的指挥官。

+ 用 Gemini 3 Pro 实现 Vibe Coding
+ 上传产品说明书、UI 参考图、Mermaid 架构图
+ 利用 Google AI Studio 的 多模态能力（文本 + 图像 + 代码）生成高保真前端与逻辑
+ 掌握 System Prompt 与 User Prompt 的分工策略，精准控制 AI 输出
+ 文档即代码：高质量 PRD 写作指南
+ 功能描述 + 用户场景 + 交互流程
+ 用 Mermaid 表达业务逻辑
+ 设计系统嵌入：参考图 vs 代码片段
+ **实战：生成你的第一个可交互原型**

在 Google AI Studio 中，仅凭一份文档，驱动 Gemini 3 Pro 生成完整应用代码。

> ✅ 第一天结束，你已掌握“用文档指挥AI”的核心能力，并拥有可运行的前端原型。

---

#### 第二天：AI IDE 工作流 × 3小时黑客松

核心工具：Cursor 2.0 + GitHub + Vercel

+ Cursor 2.0：从AI IDE 到 AgentOS
+ 多Agent协作：一个写前端，一个调API，一个跑测试
+ 直接操作终端、文件系统、浏览器
+ 真正实现“语言即操作系统”的开发体验
+ **端到端开发流程实战**
+ 将第一天生成的代码导入 GitHub 仓库
+ 使用 Cursor 2.0 完善功能：添加状态管理、API 调用、错误处理
+ 掌握 基于文档 + 敏捷开发：让 Cursor 自动跟进任务列表迭代代码
+ **高效 Debug 技巧**
+ 利用 Cursor 的聊天上下文理解错误日志
+ 通过“解释这段代码”快速定位问题
+ 模拟用户操作，自动生成测试用例
+ **3小时黑客松：从代码到上线**
+ 在导师（Shadow × 薛志荣）一对一指导下，完成项目终版
+ 一键部署至 Vercel，获得可公开访问的 URL
+ 项目路演 + 即时反馈，打磨产品逻辑与用户体验

> ✅ 95% 学员在训练营结束时，已拥有一个部署上线、可分享、解决真实场景问题的AI原生应用。
