Hey,各位小伙伴们!你们听说过"赤脚开发者"吗?不,这不是什么新出的编程语言,而是AI时代的一群新兴开发者!还记得那些"赤脚医生"吗?他们在医疗资源匮乏的年代,为基层群众提供了宝贵的医疗服务。而今天,我们有了"赤脚开发者"!

赤脚开发者是谁?简单来说,他们是:

+ 既不是专业程序员,也不是完全的小白用户
+ 了解身边人的实际需求,能提供灵活的解决方案
+ 借助AI工具,快速开发出满足小众需求的应用

想象一下,你的邻居突然变身"软件工程师",为你量身定制一个管理杂物的app,是不是很酷?这就是赤脚开发者的魅力所在!

说到赤脚开发者的实战,不得不提薛志荣的"7天7个项目"挑战。他用`Cursor`这个AI编程工具,在短短12小时内完成了5个小项目和1个大项目!来看看他都做了些什么:

1. 给老手机和`Kindle`开发了个励志日历
2. 搞了个能读链接、推送目标的🛰️AI机器人
3. 做了个`Chrome`插件来管理目标
4. 开发了个问题拆解的小网页
5. 开发了个多模态文本输入框和`LLM`执行模块
6. 最后让励志日历，`Chrome`插件和🛰️机器人实现了联动

相关介绍：`https://mp.weixin.qq.com/s/0ePMVuM_4LM8uG2u-yAfBw`

薛志荣说:"基于`Cursor`的AI编程极大提高了我的开发效率。我这几个项目基本就没写过代码,纯属问问题和复制粘贴就搞定了。"

那么`Cursor`是什么?简单说,它就是一个超级强大的代码编辑器,基于`Visual Studio Code`开发,但是深度整合了AI功能。很多用户都说,用了`Cursor`之后,写代码都不用手了!

听起来是不是很神奇?但是,要用好`Cursor`,还是需要一些技巧的。为了降低大家的入门难度，提高使用技巧，我们发起了本次AI编程训练营。本训练营，适合以下几类用户：

- 初学者：对编程感兴趣但没有太多经验的人，可以通过AI编程减轻学习编程的难度。
- 对`AI`技术感兴趣的人：想了解和应用生成式`AI`技术的人。
- 有产品创意的人：有明确产品想法并希望将其实现的人，AI编程可以帮助他们快速上手开发。
- 自由创作者和创意工作者：希望通过编程实现创意项目的人，尤其是那些对解决问题和学习新事物感兴趣的人。
- 有经验的开发者：虽然你可能已经习惯使用`VSCode`和`Copilot`，但`Cursor`也提供了新的功能和效率提升的机会。
- 希望参与社群学习的人：喜欢通过互动和合作学习编程的人，社群提供了丰富的交流和指导机会。
