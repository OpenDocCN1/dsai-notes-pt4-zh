## 课程结构（6大模块）

🧩 技能篇 — Skills 是什么，能做什么

+   同样的任务，有 Skill 和没 Skill 的差距在哪？通过真实对比场景建立直觉。

+   涵盖实战方向：文档生成 ·  研究流程固化 · 个人工作流

💻 环境篇 — 国内无梯子安装与配置 Claude Code

+   最佳 + 省钱的接入方案， Web Search 配置注意事项一次讲清，不走弯路。

⚠️ 注意篇 — 踩过的坑，你不必再踩

+   Token 消耗机制：加载即占用上下文，多 Skills 叠加成本显著

+   按层加载策略：元数据常驻 → 内容按需展开 → 脚本按需执行

+   四者边界厘清：Skill · Command · Subagent · MCP，各自能做什么、不能做什么

🛠 开发篇 — 把你的工作流变成一个可复用的 Skill

+   什么任务值得做成 Skill？判断标准先行。

+   SKILL.md 必要字段 + 可选脚本/模板文件，结构完整拆解。

🔍 发现篇 — 你不需要从零开始

+   90% 的场景已经有人做好了 Skill，找到直接用。

+   三条获取路径：下载现成的 · 命令行一键安装 · 让 Claude 帮你生成

+   现场演示：10 分钟装好一个能用的 Skill。

✏️ 改造篇 — 把别人的 Skill 变成自己的专属工具

+   找到一个现成 Skill，改两处地方，变成专属你的版本。
