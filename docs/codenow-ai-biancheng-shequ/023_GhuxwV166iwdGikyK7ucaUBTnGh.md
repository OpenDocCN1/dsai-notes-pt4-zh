## 🌍 为什么现在要学 Claude Code？

AI 正在从“聊天机器人”变成能帮你跑任务的“智能员工”。但很多人还停留在问一句答一句——你不会写代码，就只能让 AI 干碎活儿；会点 Prompt，它能帮你改文案；而一旦掌握了 Claude Code + Agent（智能体），你就能把一个复杂目标丢给它：比如“整理我上周会议录音里的观点，按项目分类，周五前给我一份带排期的简报”——然后它真的去查文件、听录音、写文档、排时间线，中间几乎不用你插手。

这就是 Agent 的价值：它不是被动的工具，而是能拆任务、做判断、持续跟进的有脑子的伙伴。

## ✨ 谁适合学习？

+ **纯 0 基础**：不懂代码，甚至没写过复杂提示词，但想“教 AI 替我搞定重复工作”；

+ **设计师 / 创意人**：想做风格调研、素材整理、灵感聚合，不想在软件里反复切来切去；

+ **文科 / 运营 / PM**：常要做情报梳理、报告框架、内容统筹，希望把“找资料–整理–排版”交给 AI，自己只负责决策。

你不用懂编程，只要会用中文下指令就行。

## 🎯 学完你能做到什么？（用自然语言指挥 AI 干活）

1. **把模糊需求变成可执行计划**：你说“帮我研究竞品动态”，Claude Code 自己拆成：去哪里搜、怎么比、输出什么表；

1. **建自己的情报 Agent**：自动抓行业新闻→筛关键点→生成每日/周简报，不用天天刷屏；

1. **定制入职/项目文档**：输入公司背景，自动生成新人指引、流程模板、常见问题库；

1. **安全可控地自动化**：知道什么时候让它全自动跑，什么时候停下来让你确认（避免乱操作）。
