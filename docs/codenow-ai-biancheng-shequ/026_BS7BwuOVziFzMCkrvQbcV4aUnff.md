# Agent API化专项：让你的 AI 能力被任何界面调用

> 来源：[https://now.feishu.cn/docx/GYmWd7IKRo34wOxtRtTcCz2Onde](https://now.feishu.cn/docx/GYmWd7IKRo34wOxtRtTcCz2Onde)

把你的 Agent 变成可被任何界面调用的 AI 能力 让 Claude，OpenClaw 不只是聊天工具——一次 API 化，处处可复用

## 课程结构（100分钟）

### 1、先建立正确认知：为什么要把 Agent API化

+   两种自动化路径：全自动化 vs GUI交互式

+   核心价值：一次构建，到处调用

### 2、OpenClaw API化配置

+   启用 API 模式（openclaw.json）

+   Token 获取与 Session Key 管理

+   调用格式：兼容 OpenAI LLM API 规范

### 3、将 Skill API化实战

+   Claude Code 无头模式：claude -p + --dangerously-skip-permissions

+   脚本语言选择与让 Cursor 代写的技巧

+   跨文件调用 Skill 的路径写法

### 4、案例参考：从文件读取构建 Agent 状态 API

+   三个核心文件：CLAUDE.md / state.json / memory.md

+   在 soul.md 植入状态写入指令

+   前端轮询实现实时状态展示

### 5、数据处理与 GUI 构建

+   数据结构选型：SQLite vs Markdown 的稳定性差异

+   流程：数据文件 → API 文档 → Next.js / Electron 界面

+   用真实数据 mock 占位，让界面从第一天起就对

### 6、完整项目演示：HCI Insight 数据平台

+   情报官定时抓取 → 数据入库 → GUI 可视化展示

+   引入 OpenClaw API：个人 context 融入所有查询

+   引入 Claude Agent API：点击即触发 Skill，生成论文拆解报告
