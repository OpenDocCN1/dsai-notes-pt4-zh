# 零基础学生的知识管理之旅

> 来源：[https://now.feishu.cn/docx/VJKWdgusFo0azqxcRricuMkInKg](https://now.feishu.cn/docx/VJKWdgusFo0azqxcRricuMkInKg)

**Shadow**: 很高兴你参加了我们的AI编程训练营。作为一名数字媒体艺术专业的学生，是什么让你对AI编程产生兴趣的？

**学生**: 其实我之前从未接触过编程，一直觉得这是理工科学生的专属领域。但最近我看到了关于"Vibe Coding"的文章，觉得这种"氛围编程"的方式似乎降低了入门门槛，让我这种零基础的人也能尝试做点东西出来。

我平时需要阅读和收集大量的艺术设计类文章和资料，知识管理一直是我的痛点。每次看到有用的文章，我都要手动保存到Obsidian，然后添加标签、整理笔记，这个过程特别耗时。我总觉得在AI时代，知识管理应该是更加自动化的，但市面上现有的工具要么太贵，要么功能不符合我的需求。

当我了解到MixLab的AI编程训练营已经帮助了100多位非技术背景的学员实现自己的项目，我觉得这可能是我解决问题的机会，所以专门从深圳过来参加。

**Shadow**: 在参加训练营前，你有尝试过自己解决这个知识管理问题吗？或者使用过哪些工具？

**学生**: 尝试过很多方法，但都不太理想。一开始我用Notion，但它的知识连接不够强；后来转到Obsidian，虽然双向链接功能很棒，但每次添加内容都要手动操作，而且搜索和分类功能对于我这种收集大量信息的人来说还不够智能。

我曾经想自己做一个工具，在网上买过一些教编程的网课，看了几节就放弃了。对我来说，编程的学习曲线太陡峭了，光是理解基础概念就花了很多时间，更不用说实际开发一个应用了。

最痛苦的是，我觉得自己浪费了太多时间在重复性工作上。比如我正在做一个关于沉浸式艺术展的研究，每次看到相关文章都要手动摘录、分类、打标签，然后才能形成自己的知识体系。这个过程占用了我至少30%的研究时间，但它本质上是可以自动化的。

**Shadow**: 那么在训练营中，你具体学到了哪些内容，开发出了什么样的项目？

**学生**: 训练营的体验完全超出我的预期！我原本以为学习编程需要几个月甚至更长时间，但在短短两天的线下课程中，我竟然做出了一个知识管理工具的雏形。

首先是环境配置和基础知识学习。导师手把手教我们配置开发环境，这个步骤如果我自己来做可能会卡住好几天。然后我们学习了如何用自然语言描述需求，让AI理解并生成相应的代码。

在项目开发方面，我学到了前端界面设计的实现方法，以及如何使用LLM来处理和分析文本内容。在导师的指导下，我成功实现了几个核心功能:

一是界面设计，我做了一个简洁的前端页面，可以上传和显示文章内容；

二是知识图谱功能，能够自动分析文章之间的关联性并可视化展示；

三是内容提取功能，用LLM自动从文章中提取重点信息和关键概念。

最让我惊喜的是，这些功能都是通过自然语言描述实现的，我不需要深入理解复杂的编程语法，更像是在"指导"AI完成任务。

**Shadow**: 听起来你做的进展很不错。使用这个工具后，与之前相比，你的知识管理流程发生了哪些变化？

**学生**: 虽然工具还处于早期阶段，但我已经能看到它的潜力。目前我正在测试这些功能，特别是LLM提取信息的部分，看它能多准确地识别出文章中的核心概念和观点。

最让我兴奋的是看到知识图谱开始形成的那一刻，因为它直观地展示了不同文章和概念之间的联系。这对我的研究非常有帮助，让我能更清晰地看到自己在探索的领域中的知识结构。

当然，目前还需要手动上传文章，但相比之前的流程已经简化了很多。我希望随着功能的完善，这个工具能真正帮我节省大量整理文献的时间，让我把更多精力放在真正的创意思考上。

**Shadow**: 从完全不懂编程到能开发自己的知识管理工具，这种转变一定很有成就感。在学习过程中，你觉得哪些因素帮助你克服了技术障碍？

**学生**: 最关键的因素是训练营的教学方式。"边做边学"的模式让我看到了具体的成果，这种即时反馈极大地增强了我的学习动力。

还有就是现场指导的价值。当我遇到技术问题时，比如API接口调用失败或者界面显示异常，导师能及时提供帮助，避免我在一个问题上卡太久。这种支持让我保持了学习的连续性和积极性。

实践项目的选择也很重要。因为是解决自己实际面临的问题，所以每一步进展都能感受到直接的价值，这比做一个抽象的练习项目更有吸引力。

**Shadow**: 现在距离训练营结束已经有一段时间了，你后续对你的知识管理工具做了哪些改进？对于想学习AI编程但可能还在犹豫的同学，你有什么建议？

**学生**: 这两周我主要对三个方面进行了优化：一是增强了LLM提取信息的准确性，通过调整提示词让它能更精准地识别出学术文章中的核心概念；二是改进了知识图谱的展示方式，添加了节点分类和筛选功能；三是解决了一些界面响应的问题，让操作更流畅。

我目前正在学习课程中关于爬虫的内容，希望能添加自动从网页获取信息的功能，这样就不用手动复制粘贴文章了。我还想将我个人的知识管理方法论融入到工具中，比如按照"概念-理论-案例-实践"的框架自动组织信息。

对于那些想学习AI编程但还在犹豫的同学，我有几点建议：

首先，不要被"编程"这个词吓到。AI编程和传统编程完全不同，更像是用自然语言表达你的需求，让AI帮你实现。我是学艺术的，逻辑思维并不强，但还是能做出东西来。

其次，从解决自己实际问题入手。当你有明确的目标，比如我的知识管理工具，学习动力和效果会好很多。问问自己有什么重复性工作可以自动化，或者有什么创意想法想实现。

第三，不要害怕犯错。我第一次尝试做界面时遇到了很多问题，但每解决一个问题都会学到新东西。AI编程的好处是你可以不断尝试不同方案，失败成本相对较低。

最后，参加系统培训很有价值。虽然网上有很多零散的AI工具教程，但系统学习能帮你建立完整的知识框架和思维方式。MixLab的训练营不仅教技术，更重要的是教我们如何思考问题和设计解决方案。谢谢MixLab给了我这个机会！
