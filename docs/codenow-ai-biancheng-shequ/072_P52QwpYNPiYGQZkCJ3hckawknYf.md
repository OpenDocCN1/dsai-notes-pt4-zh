# 再见996！产品经理用AI编程做数据分析，辅助决策#AI编程线下训练营 - 产品经理回访

Shadow：作为一个电商产品经理，是什么原因让你决定要学习编程的？

产品经理：(叹气)真的是被逼的。我们是做跨境电商的，上个月公司进行了一轮大裁员，我们产品部从8个人缩减到3个人。但工作量不仅没少，反而因为要做新的选品和营销功能，任务量在疯狂增加。最惨的是技术团队也裁了不少人，每次找他们帮忙都要排期等很久。

Shadow：这确实很艰难。那现在工作强度怎么样？

产品经理：别提了，基本上9106是常态。我家刚出生的孩子都是我爸妈在带。最痛苦的是做选品分析，以前我们有专门的数据分析师，现在走了之后只能自己手动收集数据。一个品类要看几百个商品的评论，还要分析竞品的销量和定价，光是复制粘贴数据就要花好几天。

Shadow：那你现在用AI编程是怎么解决这些问题的？

产品经理：说个最近的例子。上周我们要分析美妆品类，需要分析亚马逊和TikTok Shop上最热销的几款面霜的用户评论。按以前的方式，我要一条条复制评论到Excel，然后慢慢分类统计。在学习完AI编程后，我写了个小工具，一晚上就把所有评论都爬下来了，还自动按好评差评分了类，甚至能分析出用户最关心的功效点。

Shadow：听起来确实提高了不少效率。具体是怎么操作的？

产品经理：我就告诉AI"我要爬取亚马逊上这个面霜的所有评论，然后按评分分类，统计评论里提到最多的功效词。"AI直接生成了代码，我只要把商品链接换成自己要分析的就行。最棒的是，它还能自动生成词云图和趋势分析，我可以直接放到选品报告里。现在选品分析的效率提高了至少5倍。

Shadow：除了评论分析，还有其他应用场景吗？

产品经理：当然有。比如做竞品分析时，我们要研究📕上最火的美妆博主都在推什么产品。以前要一个个点开笔记看，现在我用AI写了个工具，输入关键词就能批量爬取笔记内容，自动提取产品信息和价格。前两天老板临时要看防晒产品的市场分析，我一个晚上就整理出了100个博主推荐的防晒产品数据，还包括每个产品被提到的频次和平均价格。

最重要的是，这些工具做好以后可以反复使用。现在每周的选品分析，原来要忙到凌晨的工作，下午就能搞定，终于能早点回家看看孩子了。

Shadow：听起来AI编程给了你很大帮助。对于工作前景有什么新的想法吗？

产品经理：现在反而更有信心了。因为我不仅会做产品规划，还能自己做数据分析和市场调研。前几天跨境部门的同事知道我会这个，纷纷来找我帮忙做选品分析。老板现在开会我都能拿出详实的数据支撑，感觉地位比以前稳固多了。

重点是现在带项目更轻松了。以前找技术部门做个简单的数据统计都要排期，现在很多事情我自己就能搞定。那些重复性的工作都用工具自动化了，我终于有时间思考更有价值的产品方向。

Shadow：你觉得AI编程对电商产品经理最大的改变是什么？

产品经理：就是让我们能真正做到"数据驱动决策"。以前很多决策都是靠经验和直觉，现在我能快速获取和分析大量数据。比如要不要上新一款产品，我能在一天之内收集完所有竞品数据和用户评论，用数据支撑决策。

特别是在现在这种环境下，公司都在强调高效和降本，一个人要干多人的活。AI编程就是我的"得力助手"，帮我自动化大量重复性工作，让我能把时间花在更有价值的事情上。

以前觉得编程很遥远，现在发现学会了真的能改变工作方式，告别996~~
