
# 搭建个人博客

> 来源：[https://now.feishu.cn/docx/Dv1fdQ5EuoYDGrxdNmncGrbTnwc](https://now.feishu.cn/docx/Dv1fdQ5EuoYDGrxdNmncGrbTnwc)

使用`bolt.new`，5分钟开发一个具有Tag功能的`Astro`个人博客，跑分100

## 关于`bolt.new`

[`bolt.new`](https://bolt.new/)是[StackBlitz](https://stackblitz.com/)的AI建站平台

![](img/c04d605309829a79018c6f9b08fa922e.png)

**主打就是一站式**在线提示问答，运行，编辑并部署全栈web应用 - “Prompt, run, edit, and deploy full-stack web apps.”

## 快速实践

[咱们没有废](https://astro.build)话，这[就来体验一下b](https://docs.astro.build/zh-cn/concepts/why-astro/)olt.new，做个`Astro`博客（`Astro`简介 ps: 个人非常推崇用`Astro`建博客站、文档站，性能很好。推荐大家把教程里的博客项目跑一遍，对`Astro`有个简单了解。个人很喜欢`Astro`对内容优化的特性，适合做静态、内容为主的网站）

1. 点击第一项：Start A blog with Astro。等待`bolt.new`部署

2. 部署完成后，输入提示词：“帮我给`Astro`博客项目添加Tag（分类标签）功能”

3. 等待AI更新代码，博客应该能正常显示并具有了Tag功能了

4. 如果当点击`About`页面标签出现bug，可以直接复制错误信息代码，让`bolt.new` `debug`

5. OK，目前博客就有了Tag功能了，可以一键部署到`netlify`了（见`Astro`一键部署到`netlify`或`zeabur`等免费服务器资源）。可以去我之前部署的站点去看看效果`https://astro-blog-with-tag.netlify.app`

![](img/eecd063111dffcd528bb51f0da95c301.png)

6. 后面我们可以复盘一下，看看我们能和AI学习到一些什么开发经验

7. 这很重要。用AI跑通项目不是唯一的目的，我们掌握项目开发经验才是最重要的。
