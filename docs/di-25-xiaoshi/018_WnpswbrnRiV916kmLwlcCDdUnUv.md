# AI英语口语陪练（教育行业）

```
**请为我设计一个专业的CE****T-6英语口语训练AI****教练页面，具体要求如**下：
1.模拟口语对话场景模块：
创建贴近大学生活的口语对话情境，包括但不限于：
- 校园兼职（如兼职家教、校园店铺服务生等）
- 图书馆借阅（如询问书籍位置、办理借阅手续等）
- 学生社团活动（如社团招新、活动策划与执行等）
- 宿舍生活（如室友交流、宿舍规定讨论等）
每个情境应包含对话双方的角色设定、对话背景及具体对话内容，对话内容需符合CET-6口语考试难度。
提供符合CET-6水平的话题讨论引导和应对策略，帮助学生熟悉考试题型和答题技巧。

2.实时纠错与建议模块：
- 在学生模拟对话过程中，实时指出语法、词汇和句式方面的错误。
- 提供语音语调、重音和停顿的具体建议，帮助学生提升口语表达的准确性和自然度。
- 给出更地道的表达方式替代选项，丰富学生的口语词汇库和表达方式。

3.能力评估报告模块：
- 分析学生口语的流利度，包括语速、连贯性和停顿情况。
- 评估词汇多样性和使用情况，指出学生常用词汇和高级词汇的使用比例。
- 指出发音准确性问题，包括音标发音、单词重音和句子语调等。
- 提供针对性的提升建议，针对学生的薄弱环节给出具体的改进方法和练习建议。

请确保页面设计简洁明了，操作便捷，能够为学生提供良好的口语训练体验。同时，页面应包含清晰的指导说明和反馈机制，以便学生随时了解自己的训练进度和效果。
```

```

- 包含五种版式选择：横版/竖版/折页式/卡片式/长图海报
- 内置动态节庆元素库：3D生日帽/飘空气球/多层蛋糕/礼物盒动画/彩带特效

2. 个性化定制系统
- 宝宝信息模块：智能姓名艺术字设计、生日星座自动匹配元素、成长里程碑时间轴、AI照片自动抠图服务
- 活动详情组件：
* 地图导航嵌入
* 停车指南可视化
* 特殊需求标签（过敏提示等）
- 家庭元素专区：
* 智能全家福排版
* 父母手写体模拟
* 成长足迹地图标记

3. 智能生成引擎
- 基础信息输入向导：宝宝特征标签选择（活泼/安静/爱笑等）、派对类型选择（家庭聚会/户外野餐/酒店宴会）
- AI设计系统：30秒生成3套候选方案、文案风格匹配（文艺/幽默/正式）、照片智能优化（人像精修/背景替换）
- 多尺寸适配：朋友圈九宫格优化、A4打印排版、电子屏动态版本

二、用户操作流程
1. 创建阶段
- 步骤1：选择基础模板（风格/色彩/版式）
- 步骤2：输入宝宝核心信息（姓名/生日/照片）
- 步骤3：填写活动详情（时间/地点/流程）

2. 定制阶段
- 智能推荐区：根据输入信息推荐匹配元素、实时预览调整效果
- 高级编辑区：层叠式设计面板、组件自由拖拽、透明度/阴影/边框调节

3. 生成阶段
- 一键生成选项：基础版（3分钟）、精致版（10分钟）、豪华版（24小时）
- 预览模式：3D旋转查看、模拟不同设备显示、社交传播效果测试

4. 分享阶段
- 多渠道发布：微信/QQ/微博定制卡片、短信H5链接、邮件PDF附件
- 互动功能设置：RSVP截止时间、祝福墙权限、倒计时显示样式

三、增值服务体系
1. 成长记录云
- 智能相册分类：按月龄自动归档、场景识别（生日/节日/日常）
- 里程碑时间轴：发育指标对比、疫苗接种提醒
- 视频自动生成：照片+视频混剪、背景音乐库、字幕自动生成

2. 实体制作服务
- 印刷品质选择：普通纸/珠光纸/棉柔纸、哑光/亮光/触感膜
- 配套产品：感谢卡套装、桌卡设计、回礼标签
- 物流跟踪：制作进度查询、快递实时追踪、签收确认通知

请提供完整的产品需求文档（PRD），包含功能优先级排序、技术可行性分析、用户体验旅程图及开发里程碑计划。
```
