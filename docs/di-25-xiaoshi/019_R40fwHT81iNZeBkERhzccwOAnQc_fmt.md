# 🎉 场景能力总结

在测试过程中，能感受到模型能力的提升所带来的各种创意想象🎨。通常情况下，一次生成不大可能达到想要的效果。

如果在提示词不够具体的情况下，很容易会发生图像错位、胡乱拼接等问题，导致生成的图片非常魔幻怪异。

所以提示词要尽量减少模糊词如「某某风情」或者「某某氛围」等，使用「结构」「装饰」「色彩配比」等更具体的词汇，让模型更加理解你的意图。

而如果在提示词满意的情况下，建议反复生成，选出最符合预期的那一张。

值得一提的是，有时候生成的图片基本符合预期，但可能会有一些小问题，比如尺寸或者位置不对，物品上有一些影响观感的标识等。这个时候就不建议再次生成，可以直接继续输入建议性的提示词来进行微调，调整到自己想要的效果即可。
