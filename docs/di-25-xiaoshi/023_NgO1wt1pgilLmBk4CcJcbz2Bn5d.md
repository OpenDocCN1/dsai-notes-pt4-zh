# 一、🦄基础介绍

## 1、什么是ima？

从官方的信息出来，先来了解下ima是什么？

IMA（腾讯AI智能工作台）是腾讯推出的一款集成了多种 AI 功能的工具，旨在帮助用户高效管理知识、提升工作效率的 AI 工具。

## 2、ima能做些什么？

ima有以下7大核心功能：

| **核心功能** | **功能说明** |
| --- | --- |
| 信息获取与问答 | **智能搜索**：基于全网信源或你的个人知识库，去快速检索并提供所需要的信息。 |
| 多模态内容解读 | **文本解读**：对文章、网页等进行详细的解读和分析。 |
| 个性化知识管理 | **知识整理**：方便地整理、分类和检索个人知识资源。 |
| 写作辅助 | **主题写作**：协助确定写作主题，并生成大纲。 |
| 创意与设计支持 | **画图功能**：根据描述生成相应的图像。 |
| 共享与协作 | **共享知识库**：创建或加入共享的知识库，实现团队协作。 |
| 其他实用功能 | **AI划词工具栏**：选中文字即可快速获取相关信息。 |

## 3、ima支持的平台有哪些？

了解了ima的核心功能后，下面我们来看看，ima支持的平台有哪些？

ima有一个很大的好处是，几乎所有平台都支持。其中包括：PC端、移动端和小程序端。除了iOS客户端以外，其他各个端口都可以支持和使用。

# 三、🐱搭建个人知识体系

PC端和小程序端的一些入口，我们简单了解了下。下面就是，从「个人知识体系」这个概念入手，看看用 ima 这款工具，能给我们日常个人知识体系里，碰撞出一些什么样的火花💥

## 1、知识管理链路

ima打通了知识管理的链路：收藏知识 → 管理知识 → 应用知识 → 共享知识。

下面我们看看，这四个步骤，分别在里面是怎么应用的。

### （1）收藏知识

在日常生活当中，我们几乎每一天都会看大量的信息。这些信息可能会是pdf、doc、png、jpeg、ppt等各种各样的格式，那在产生信息的那一刻，我们就可以把这些东西，上传到我们的 ima 知识库里面。

![](img/f7d6317d236cc6135e516f04802247e8.png)

那如何上传呢？可以上传到 ima 的个人知识库：

也可以上传到 ima 的共享知识库：

### （2）管理知识

**那有了知**识之后，**我们就可**以给知识打上标签🏷。可以对多个文件进行批量打标签：

![](img/91d2faa796884cf2e286a1b95799bc7a.png)

也可以对**单个文件**进行打标签：

### （3）应用知识

打完标签之后，相当于脑袋里已经把知识做了一个分类。那接下来，就是应用这些知识啦~

**可以发现**右边有个聊天框，下方**我们可以**选择指定标签进行提问，也可以选择指定模型进行提问。

### （4）共享知识

知识管理链路的最后一个步骤是：**共享知识**。比如上面我们通过ima，沉淀了一些很不错的内容，并且想要对外部共享出去。怎么操作呢？

**第一步：**先添加到个人知识库。

![](img/93e50583149dc29a0797da6b8288c093.png)

**第二步：**在共享知识库里面，添加「个人知识库」里面的笔记。

![](img/d14aa83930f27d531c1106664fc199dc.png)

**第三步：**复制链接或者生成二维码的方式，分享出去。同时可以对不同的成员，进行权限控制。

![](img/02c482ce830ca8c8247c8b0184534a5a.png)

**个人**感**觉，**「共享知识」这个功能对于个人和团队而言，都是非常不错的选择。团队可以在内部，一起看到共享的内容。如果是个人的话，也可以把自己沉淀过的内容，分享到互联网上。

## 2、基于🛰️生态做事情

讲完「知识管理链路」，下面来讲讲，ima这个工具，基于🛰️强大的生态，还能做哪些事情。

### （1）导入👸号文章

当我用ima去试这个功能的时候，内心有一句OS：果然自家娃在自己的沃土中汲取养分，终成栋梁之材。

对于国内的用户来说，每天基本都会用🛰️，同时，并且还会看大量的🛰️👸号文章。

所以，当你在想要对🛰️阅读过的文章，进行进一步解读和总结的时候，就可以直接在手机端，通过小程序的方式，把文章导入到ima上面。

ima会把这篇文章，放到「个人知识库」下。然后你就可以直接对这篇文章，进行「打标签」、「提问」和「总结」等各种操作。

![](img/0a70dcbdb34ea315a08ea04d5756e377.png)

![](img/cce64c774eb118c74e27a1f2a14eb0e0.png)

![](img/9b1a0682993f5e1405733b2ac93d8f25.png)

这个功能给我的感觉是，依托于腾讯内部的生态，让大家在🛰️内，就能够一次性把自己的知识，沉淀到ima上。同时，你不用担心它会看完就不见了，因为你之后在PC端去打开ima的时候，同样可以看到这篇文章。那就在很大地程度上，打破了时间和空间的限制。

### （2）导入🛰️聊天文件

除了👸号文章外，ima还可以导入🛰️里面，聊天记录里的pdf、doc等格式的文件，还可以上传本地的图片、以及可以直接拍照上传内容。

对于**本地上传图片**的功能来说，感觉对于职场人和学生党，都有很不错的场景可以应用。

比如，跟同事老板一起开会，可能里面有一页ppt很重要，那么就可以随手把它拍照上传到ima，同时让ima帮忙做图像理解，比如：你可以给我讲讲，这也PPT里面，主要讲解了什么内容，以及我接下来的工作需要聚焦于哪一方面呢？

对于大学生来说，上课的时候，老师的PPT过的太快，还没来得及学会，老师就翻页了。所以针对这种场景，也会是个很不错的选择。

# 五、🐅和大模型的应用

聊完应用，最后再来聊聊，ima和大模型层面的量子纠缠。

## 1、模型支持：已支持DeepSeek-R1

ima除了支持混元模型之外，还已经支持了DeepSeek-R1，这个对于当下比较流行的模型趋势来说，无疑是能更好的增加用户粘性的方式之一。

假如以后有新的比较爆发性的模型，那ima大概率也能同时支持上来。

![](img/94ad24a11c69e075cefac566f21f1193.png)

## 2、检索增强生成RAG

第二个大模型层面的应用大概就是RAG，**检索增强生成**。上面我们也有演示了在个人知识库或者共享知识库里面，直接去搜索和整理内容。

那这个就相当于ima在平台上直接打出了RAG**，并且还支**持全网搜索，同时也可以基于自己知识库的内容去做进一步的个性化输出。在高质量输入情况下，推导出高质量的输出。

早期像飞书知识库、百度文库、网盘、包阅等平台，都很适合拿去做RAG，包括最近刚上线的「飞书智能知识问答」、「FlowUS AI」，也基本上是同种类型的知识库应用。

小编去年刚接触RAG概念的时候，还是用扣子、文心等智能体平台，需要先去做数据清洗等步骤，再去做个性化输出。

# 六、🐌未来的可能性探索

在对ima做完了测评以后，再来碎碎念一些对这款产品的可能性探索：

1.  目前内存空间很有限，感觉未来有可能会出RSS订阅服务。

1.  ima在**记笔记**方面的「编辑器」，功能还不够强大，感觉未来编辑器可能还会有新的功能。

1.  在「三 2、」这一部分中我们提到了，基于🛰️生态区做了一些事情。那未来有可能也支持直接对特定的🛰️聊天记录进行总结。比如我妹经常给我发四五十条很长的语音，一次性听完和转文字都会有点耗时。那ima是不是也有机会可以对语音的内容进行总结，并返回给用户总结内容。

1.  目前ima貌似是不支持手机端桌面小组件的，如果未来可以跟cubox一样，支持桌面端小组件，直接通过「链接」的方式，把诸如36氪、极客公园等媒体的文章快速导入进来，那产品的可能性buffer，就更高了。

1.  目前在应用层面，还是会依赖于需要更精准的Prompt，未来感觉可能ima可以先阅读下文献，然后问用户说，我检测到目前有xxx、xxx和xxx几部分的内容，你会更偏向于让我输出哪部分的内容。如果是这样的话，就可以让用户的注意力更加聚焦。

# 七、🦁结语

ima知识库的本质还是RAG的方式，其中较为不一样的一点是，结合了自家🛰️生态的入口。🛰️连接了人与人，而ima则连接了人与知识。以前，我们把东西存起来，过了半年一年之后，有可能这个东西永久的在网盘里面吃灰。

但是呢，现在有了 AI 知识库，可以很简单的通过一些指令，去把我们收藏过的、许久未打开看过的，给进行总结和提炼，这样能够更好地应用留存的文件。期待国内的内容存储工具，玩出越来越多的花🎄。
