## 一、喂图

意义：从第一张起，可反复上传优化图片，来达到自己想要的图片。

喂图过程：上传单张或者一组（4 到 5 张，目前没有限制多少张，但一般来说 4 张刚刚好，太多会给 AI 带来困扰）到 Midjourney 输入框里，这里的上传有两种方法：

1. 点击输入框前方的加号上传。
2. 鼠标选择图片或一组拖到软件里，回车，点击上传后的图片，在左下角“在浏览器打开链接”打开后复制浏览器上的链接，返回主界面，在输入框里“`/imagine`：粘贴刚才复制的链接+你所描述的关键词，就是所谓的”喂图“

### 常见问题

**1. 小白新手找不到输入框频道。**

答：找到 Midjourney 白色图标，点击进去，找带数字结尾的频道，或者在自己社区里添加 Midjourney 机器人。

官方白色图标频道：

![](img/f6d1d43e704d66cb990c14cdd7609f24.png)

社区频道添加 Midjourney 机器人

![](img/2909c7332d9d92f38b6911f1dc1a6e25.png)

在这里搜索。

选择第一个

![](img/ebd064770ac801c5123e57c3bd815e0a.png)

添加到自己服务器，后面点击授权即可。

**2. 喂图出错。**

答：正确步骤：上传照片回车后，在输入框打 `/` 会弹出选择弹窗，选择 Midjourney 白色图标里 `/imagine` 后面粘贴图片地址，图片地址后面需要 + 空格，再次加图片后在 + 空格，+ 关键词。

**3. 比例为什么调整不出来。**

答：官方命令较为严谨，需要注意格式：`--ar 16:9`

## 二、关键词

### 1. 儿童读物

人物描述 + `children's book illustration` + 风格 / `children's book illustration` + 描述

注意：以上两种格式都可以。

例子：可爱的小女孩在旷阔的山林午夜中奔跑，童话风格

翻译：Sweet little girl running in the middle of the night in the open forest，`children's book illustration`，Fairy tale style `--ar 16:9`

![](img/c218f8055a8344d4ba28255ed7d709a6.png)

例子：小公主坐在一只山羊背上，大草原上，童话风格。

翻译：The little princess sat on the back of a goat on the prairie，`children's book illustration`，Fairy tale style。

### 2. 对称图标

描述词 + `icon design symmetrical,flat`

注意：简洁单一的对称元素。

例子：五花肉的横切面

翻译：A cross section of pork belly，`icon design symmetrical,flat`

![](img/7bbd73766d0e80f578299cd12c07b9b3.png)

例子：透明玻璃的 3D 盾牌

翻译：`3D shield with clear glass`，`icon design symmetrical,flat`

![](img/64eaf4ebc50951366068e6be8fe1de11.png)

### 3. 游戏列表

`game sheet of` + 描述词

注意：这里 `sheet` 表示多个的意思，把多个物体展现在一张图像中。

例子：宝箱道具

翻译：`Game sheet of`，treasure chest prop

![](img/6a2af6ae9f38ab934b4692f3a3c4a35d.png)

例子：五颜六色的宝石

翻译：`Game sheet of`，Colorful gems

![](img/5ca5367dfbe8792e4041cb78508f8d05.png)

### 4. 黑暗中灯光效果

`Blacklight` + 描述物体

注意：是一种风格，偏暗的。

例子：火焰山

翻译：`Blacklight`，Flaming mountain

![](img/d7bdd510d18b373226be443677c2b891.png)

例子：七星宝塔震河妖（不知道为什么会想起这个）

翻译：`Blacklight`，Seven star pagoda shaking river demon

![](img/f0e70ccde6c88af7887ef54a9fd74493.png)

### 5. 图案设计

描述 + `pattern`

注意：没有注意事项

例子：印度风图案

翻译：Indian style, `pattern`

![](img/c297008ad1512a7738cbf8ef4a362c24.png)

例子：花朵图案

翻译：`flower pattern`

![](img/71d3d8f95b88caedd907a1d864821696.png)

### 6. 装修/建筑设计

`Interior Design` + 描述文字

注意：也有另一种关键词 - `Architecture`。

例子：欧式风格，家具有办公桌，台灯，书架，木板

翻译：`Interior Design`，European style, home with desk, lamp, bookshelf, wooden board

![](img/5ce3963a2a1c4326be1a4878cac9502c.png)

例子：极简风格，有落地窗，客厅

翻译：Minimalist style, floor-to-ceiling Windows, living room，`Architecture`

![](img/3d413be18c5ab3b877528b631cd6dbb4.png)

### 7. 独有风格（Explode 艺术家）

`Explode` + 物体描述词 + `by Nychos`

注意：这位艺术家画风具有放射性。

例子：木星星球

翻译：`Explode Jovian planet by Nychos`

![](img/79f1859133772e8a89ff02fb88ae2389.png)

例子：毒液

翻译：`Explode venom by Nychos`

![](img/2b18f59d53e45f4c35e5af5857494ac2.png)

### 8. 字符艺术

描述物体 + `ASCII art`

注意：这种电脑字符艺术形式偏小众，但很惊艳。

例子：海龟

翻译：`turtle ASCII art`

![](img/5b1020bf8b7dad923c511b2972549a2b.png)

例子：黑客帝国

翻译：`Matrix ASCII art`

![](img/d51be7afa416e54d5db3840342dd41bc.png)

### 9. 欧普艺术

`Op art portrait` + 描述文字

注意：现代的错觉艺术。

例子：正方体错落有致的台阶

翻译：`Op art portrait` A rectangular set of steps

![](img/a6df1af0c0e9e98b6d44fe22a7157d18.png)

例子：一只橘猫

翻译：`Op art portrait` An orange cat

![](img/c407afedbc0077ddf802610a111670d6.png)

### 10. 粘土风格（图标）

`Tiny cute isometric`（等距）+（物体）+ `maxemoji`，`soft lightingsoft pastel colors` + `3Dicon` + `clay` + `blender 3d` + 名人画风（或者背景颜色）

注意：

1. 等距 + 物体 + `maxemoji`，`soft lightingsoft pastel colors` / `pastel background` + `3Dicon` + `clay` + `blender 3d` + 背景颜色 = 等距粘土物体

2. `yasuko blythe dolls`（安子布莱斯娃娃 / 也可以换成其他知道的娃娃名称） + 灯光 / 颜色 / 背景 / 材质 + `clay`（粘土） + `style Yoshitomo Nara`（良奈吉友画风 / 或者其他名人风格）= 人偶

例子：`Tiny cute isometric coffee shop`，`maxemoji`，`soft lightingsoft pastel colors`，`3Dicon`，`clay`，`blender 3d`，Blue background

翻译：可爱的等距咖啡店，表情符号，柔和的灯光柔和的粉彩，3D 图标，粘土，blender 3d，蓝色背景。

![](img/495b23f001bdeb0ae1d1b4d3b44bcfe5.png)

例子：`yasuko blythe dolls`，`pastelbackground`, `soft lighting`, `soft pastelcolors`, `3d icon clay render`, `blender3d`，`Yoshitomo Nara`

翻译：安子布利娃娃，柔和的背景，柔和的灯光，柔和的色彩，3d 图标粘土渲染，blender 3d，风格吉友奈良。

例子：`Ball-Jointed Doll`，`pastelbackground`, `soft lighting`, `soft pastelcolors`, `3d icon clay render`, `blender3d`，`Yoshitomo Nara`

翻译：BJD 娃娃，柔和的背景，柔和的灯光，柔和的色彩，3d 图标粘土渲染，blender3d，吉友奈良
