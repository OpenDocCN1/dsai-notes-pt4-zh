# 提示词工程AI秘籍

> 来源：[https://yigather.feishu.cn/docx/D0usdylTtoC84wxaQz6cLACsncd](https://yigather.feishu.cn/docx/D0usdylTtoC84wxaQz6cLACsncd)

大模型需要深度学习提示词，因为它们是基于海量数据训练的通用工具，而提示词能像"导航指令"一样明确任务边界、输出格式和知识范围，帮助模型从"模糊发散"转向"精准聚焦"，避免答非所问。例如，当询问"如何提高工作效率"时，加上"作为项目经理，需要3条基于时间管理理论的实践建议"的限定，模型就能生成更专业的答案。

![](img/4d428457d17f34bb7d795634d919142e.png)

例如，将模糊的"介绍AI"优化为："用比喻手法向中学生解释人工智能原理，对比人脑学习机制，300字以内，避免数学公式"。
