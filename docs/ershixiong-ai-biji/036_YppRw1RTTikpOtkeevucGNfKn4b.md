# 如何合理的使用 AI 辅助编程

> 来源：[https://qianniucity.feishu.cn/docx/LcDldwelXon1FDxJ1c4cv5ohn1d](https://qianniucity.feishu.cn/docx/LcDldwelXon1FDxJ1c4cv5ohn1d)

使用AI生成代码时，关键在于保持对整体架构的掌控。如果完全放任AI自由生成代码，随着项目的复杂度增加，代码的可维护性可能会迅速下降。因此，一个更高效且易于维护的做法是，先由开发者设计好整体架构，明确各个模块的功能，并尽量降低模块之间的耦合度。然后，可以将这些模块的具体实现交给AI完成，同时提供清晰的需求和规范。通过这种方式，不仅可以充分利用AI的效率优势，还能确保代码结构清晰、易于维护和扩展。

此外，对于复杂的代码生成和维护，关键在于确保模块之间的耦合度低。在与AI交互时，要尽量将任务所需的现有代码和需求说明清晰地提供给AI。如果需要传递的信息过多，AI可能难以生成理想的结果，因此保持任务描述简洁明了也非常重要。
