# Monica：AI 助手

> 来源：[https://qianniucity.feishu.cn/docx/UZTUdEyADokb9mxDpS1cEijSnqg](https://qianniucity.feishu.cn/docx/UZTUdEyADokb9mxDpS1cEijSnqg)

> **Monica**** 是一个基于浏**览器的 AI 助手扩展工具，定位为个人的 AI 智能副驾。它通过浏览器插件的形式，整合了多种 AI 能力，如网页总结、文本翻译、邮件撰写、代码解释、写作助手等，让用户在浏览网页或办公过程中可以随时调用 AI 提供帮助。

你可以把 Monica 理解为「浏览器里的 ChatGPT 增强版」，但它不止于对话，而是全方位提升你的日常生产力。

---

## **🌟 核心功能一览**

### **🧠 多语言 AI 聊天**

支持对接多个模型平台（如 OpenAI、Claude、Gemini 等），可以与 AI 进行自然语言对话，支持中英文自由切换。

### **📑 网页总结 & 阅读助手**

在浏览网页时，Monica 可以自动提取网页内容并生成摘要，快速获取关键信息，非常适合阅读长文、论文、新闻、技术文档等。

### **🛠 写作助手 & 重写工具**

支持邮件撰写、文章润色、营销文案生成等场景。你只需要给出关键词或初稿，Monica 就可以帮你快速完成高质量内容。

### **🌍 文本翻译与解释**

自动识别网页或剪贴板文本，支持 AI 翻译，并能结合上下文进行解释，非常适合阅读英文原文或技术资料。

### **👨‍💻 编程辅助**

对于开发者，Monica 可以提供代码解释、代码优化建议、bug 识别、正则表达式生成等实用功能，极大提升开发效率。

### ✨ 一键提示工程（Prompt 工具库）

内置大量高质量 prompt 模板，涵盖写作、学习、职场、生活等场景，也支持用户自定义模板，复用效率极高。

## **💻 使用方式**

Monica 主要以浏览器扩展的形式存在，目前支持：

+   ✅ Google Chrome

+   ✅ Microsoft Edge

+   ✅ Brave 等 Chromium 内核浏览器

安装后可通过 **快捷键** 或点击插件按钮调出 AI 面板，操作简洁直观。

## **🔐 模型平台支持**

Monica 不绑定特定模型，而是支持用户自定义接入：

你可以绑定自己的 API Key，也可以使用 Monica 提供的统一接口服务。

## **💰 价格与版本**

Monica 提供免费版和付费订阅版两种：

+   **免费版**：可以绑定自己的 API Key，自定义部分功能

+   **付费版**：提供高级功能，如多模型切换、上下文更长、多开标签页支持、更多 Prompt 模板等

## **🔧 应用场景示例**

+   学生：用于论文总结、翻译外文文献

+   上班族：快速撰写工作邮件、会议记录、报告草稿

+   自媒体：高效生成脚本、写作灵感

+   开发者：阅读文档、代码优化、正则调试

+   翻译者：上下文增强的翻译解释助手
