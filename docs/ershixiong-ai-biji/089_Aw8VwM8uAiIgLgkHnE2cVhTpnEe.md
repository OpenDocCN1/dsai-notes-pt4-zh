### 🎯简介

21st.dev 是一个开源的 AI 网站 UI 组件市场，让你能像安装 npm 包一样，轻松获取并使用专业的 UI 组件，帮你在几分钟内打造出高质量的 AI 产品界面。

## **📌 关键功能亮点**

**✨ 即用即取：**像 npm 一样，直接复制所需组件代码，立即集成到项目中。

**🎨 AI 界面特化：专**门为 AI 产品设计的现代化 UI 组件，完美契合 AI 应用场景。

**🔌 无缝集成：完**全兼容 React + Tailwind CSS + shadcn/ui，零配置即可使用。

**🚀 多平台支持：支**持 v0、Cursor、Bolt 等主流 AI 开发平台。

**🌈 开源共创：人**人都能贡献组件，持续成长的开源组件生态。

**⚡️ 快速开发：**省去 UI 设计和开发时间，让你专注于产品核心功能。
