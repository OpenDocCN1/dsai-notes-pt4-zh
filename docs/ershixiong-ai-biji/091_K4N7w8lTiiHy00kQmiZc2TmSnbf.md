
# Cursor 中 MCP Server 安装异常处理

> 来源：[https://qianniucity.feishu.cn/docx/H0MgdSkSKoTUnVx0QiYc2oT1nwd](https://qianniucity.feishu.cn/docx/H0MgdSkSKoTUnVx0QiYc2oT1nwd)

在配置 MCP Server 时，如果遇到异常问题，可以按照以下步骤进行处理：

1. 进入 Cursor 的 MCP 配置页面：导航至 Cursor Settings > MCP。
2. 检查异常提示（`tips`）：Cursor 已对异常情况进行了详细的日志记录，您可以根据提示信息找到问题的原因。
3. 查看 `console` 日志：如果发现异常信息，可以将相关日志发送给 Cursor 团队，以便他们进一步分析和解决问题。
4. 查看 `output` 输出：确保所有配置步骤已正确执行，避免遗漏或配置错误。
