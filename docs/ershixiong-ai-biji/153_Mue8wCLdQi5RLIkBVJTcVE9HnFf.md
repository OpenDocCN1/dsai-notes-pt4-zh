# DeepSeek 开源周：五天五项技术突破，解锁 AI 开发的“隐藏武器”

> 来源：[https://qianniucity.feishu.cn/docx/NGbhdvXm3oqNSDxOs3Ic7IJZn20](https://qianniucity.feishu.cn/docx/NGbhdvXm3oqNSDxOs3Ic7IJZn20)

这周（2025年2月24日至2月28日），DeepSeek 掀起了一场技术风暴。他们启动了“开源周”（#OpenSourceWeek），每天发布一个经过生产验证的代码项目，总共五项。这些并非花哨的噱头，而是 DeepSeek 内部团队打造的核心工具，支撑着像 DeepSeek-V3 和 R1 这样的 AI 巨擘。现在，他们把这些“隐藏武器”开源，邀请全球开发者一起来探索 AGI（人工通用智能）的边界。让我们逐日拆解这五项发布，看看它们到底带来了什么。

---

# 一、五天五项技术发布

1.  2月24日：FlashMLA —— 解码速度的“推进器”

+   是什么：FlashMLA 是一个针对 NVIDIA Hopper GPU（如 H800）优化的解码内核，专为大语言模型（LLM）加速生成过程设计。

+   技术亮点：支持 BF16 精度，采用分页键值缓存（块大小64），内存带宽达 3000 GB/s，计算性能 580 TFLOPS。

+   为什么有趣：想象你在用 AI 聊天，以前它慢吞吞地“思考”，现在 FlashMLA 就像给它装了个火箭引擎，回答快到让你怀疑它是不是偷偷预判了你的问题。

+   在哪里找：GitHub（deepseek-ai/FlashMLA）已开放。

1.  2月25日：DeepEP —— MoE 模型的“通信中枢”

+   是什么：DeepEP 是首个为混合专家模型（MoE）定制的专家并行（EP）通信库，优化训练和推理中的分布式协作。

+   技术亮点：高效全对全通信，节点内用 NVLink，节点间用 RDMA，支持 FP8 精度，通信与计算重叠提升效率。

+   为什么有趣：MoE 模型就像一个团队，DeepEP 是那个确保每个人都听指挥的“调度员”。有了它，数百个“专家”能无缝配合，让 AI 处理复杂任务时如鱼得水。

+   在哪里找：GitHub（deepseek-ai/DeepEP）已就位。

1.  2月26日：DeepGEMM —— 矩阵计算的“核弹”

+   是什么：DeepGEMM 是一个支持 FP8 的通用矩阵乘法（GEMM）库，为密集和 MoE 矩阵运算提供超高性能。

+   技术亮点：在 Hopper GPU 上实现 1350+ TFLOPS，代码简洁到像教学示例，采用即时编译（JIT）技术。

+   为什么有趣：矩阵运算是 AI 的命脉，DeepGEMM 就像一个超级计算引擎，让模型训练和推理快得像开了外挂。写代码或解数学题，AI 从此不再拖后腿。

+   在哪里找：GitHub（deepseek-ai/DeepGEMM）已上线。

1.  2月27日：DualPipe & EPLB —— 并行优化的“指挥官”

+   是什么：DualPipe 是一种双向流水线并行算法，EPLB 是专家并行负载均衡器，共同优化大规模模型的资源分配。

+   技术亮点：DualPipe 实现计算与通信重叠，EPLB 确保 MoE 模型中专家任务均衡，提升整体吞吐量。

+   为什么有趣：这俩就像工厂里的“指挥官”，一个管生产流水线，一个管工人调度。有了它们，训练 V3 或 R1 这种巨无霸模型就像开了全自动生产线，效率拉满。

+   在哪里找：GitHub（具体链接见 DeepSeek 官方公告）。

1.  2月28日：3FS —— 数据访问的“光速通道”

+   是什么：3FS（Fire-Flyer File System）是一个并行文件系统，充分利用 SSD 和 RDMA 网络，加速 AI 数据读写。

+   技术亮点：在 180 节点集群中实现 6.6 TiB/s 读取吞吐量，每分钟处理 3.66 TiB 数据。

+   为什么有趣：数据是 AI 的“粮食”，3FS 就像一个光速传送带，喂得快消化也好。以后 AI 翻资料、学新东西，可能比你刷手机还顺畅。

+   在哪里找：GitHub（deepseek-ai/3FS）今日发布。

# 二、这些发布的“硬核”在哪里？

这些项目不是随便写着玩的，而是 DeepSeek 在生产环境中锤炼出的利器。它们覆盖了解码（FlashMLA）、通信（DeepEP）、计算（DeepGEMM）、并行优化（DualPipe/EPLB）和数据访问（3FS）五大领域，直接助力了 DeepSeek-V3（6710亿参数）和 R1 的成功。简单来说，这些工具让 AI 跑得更快、算得更准、吃得更饱，堪称技术栈的全方位升级。

# 三、开发者与用户能收获什么？

+   对开发者：这五项开源项目就像一份“技术大礼包”。想加速模型推理？用 FlashMLA。想优化分布式训练？DeepEP 和 DualPipe/EPLB 帮你搞定。想提升数据效率？3FS 在等着你。直接去 GitHub 下代码，动手就能改出自己的 AI 神器。

+   对社区：全球开发者都能拿来改造，几个月后可能就有人基于这些工具搞出新的 AI 突破，整个行业都会热闹起来。
