# 很对人对 GPT-4.5 表示失望，你怎么看

> 来源：[https://qianniucity.feishu.cn/docx/JJ4edTMLAoLSMax1Ctocg58vnlf](https://qianniucity.feishu.cn/docx/JJ4edTMLAoLSMax1Ctocg58vnlf)

很多人对 GPT-4.5 表示失望，这个现象确实在近期（截至2025年2月28日）的讨论中很明显，尤其是在 OpenAI 发布会后。我从技术和用户预期的角度来聊聊这件事，尽量直白点，把失望的原因拆开看，同时分析下这反应了啥。

# 失望从哪来？

1.  **预期被过度拉高**
OpenAI 的 CEO Sam Altman 之前放了不少豪言，比如说 GPT-4.5 是“最大的模型”“像跟一个有思想的人聊天”。加上发布会前各种“4.5小时倒计时”的营销噱头，大家脑子里想的可能是革命性的突破，结果出来后发现只是个“加强版 GPT-4o”。这种落差感直接导致失望。就像你期待一顿满汉全席，结果端上来的是加了点料的炒饭，能不嘀咕吗？

1.  **性能提升不够炸裂**
从技术上看，GPT-4.5 确实有进步：SimpleQA 准确率从 GPT-4o 的 38.6% 提到 62.5%，幻觉率从 61.8% 降到 37.1%，知识广度和对话自然度也有提升。但问题在于，它没带来“质变”。比如在 MMLU（多任务语言理解）这种常见基准上，进步很小；在数学、科学等需要深度推理的领域，还不如自家的 o3。对比 DeepSeek R1 的开源震撼或者 Claude 3.7 Sonnet 的免费强力，GPT-4.5 的提升显得有点“挤牙膏”。

1.  **定价离谱，性价比存疑**
API 价格直接炸了：输入 $75/百万 token，输出 $180/百万 token，比 GPT-4o 贵好几倍。普通用户还得掏 $200 的 ChatGPT Pro 订阅才能用。对比 Anthropic 的 Claude 3.7 免费开玩，或者 DeepSeek R1 的超低成本，GPT-4.5 这收费让人觉得“花大钱买了个小升级”，性价比崩了。

1.  **功能局限，没新意**
GPT-4.5 还是个传统 LLM，不带链式推理（CoT），没法像 o1/o3 那样“慢慢思考”。多模态功能也只限于搜索、Canvas 和文件上传，语音、视频这些高期待的东西没影儿。演示里吹的“情感智能”“对话更自然”，实际用起来跟 GPT-4o 差距不大，感觉像是换了个更会聊天的皮肤，没啥颠覆性。

1.  **竞争对手太猛**
这周 Claude 3.7 Sonnet 免费上线，代码和推理能力直逼 GPT-4.5，甚至在智能体编码基准上超车。DeepSeek R2 传言也在路上，成本低性能强。OpenAI 的光环被分走不少，GPT-4.5 没拿出碾压级的表现，自然有人觉得“也就这样”。

# 我怎么看？

客观来说，GPT-4.5 不是垃圾，技术上确实有进步，尤其在知识覆盖、幻觉控制和对话流畅性上，比 GPT-4o 更稳。但它的问题在于“用力不对地方”。OpenAI 花了大成本搞了个“更大更全”的模型，却没解决用户最想要的痛点，比如真正的推理能力或者更实用的多模态功能。加上定价和宣传的失策，失望几乎是必然的。

从另一个角度看，这也反映了 AI 发展的现状：单纯靠堆数据和算力已经到瓶颈了。GPT-4.5 的提升是“量变”，但大家期待的是“质变”——像从 GPT-3 到 ChatGPT 那种跳跃式体验。OpenAI 自己也说了，这是最后一个非推理模型，下一代 GPT-5 可能会融合 o3 的技术，往统一化、推理型方向走。那 GPT-4.5 就更像个过渡品，难怪有人觉得鸡肋。
