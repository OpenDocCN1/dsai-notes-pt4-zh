# 简介

Anthropic MCP 是一个开放标准协议，用于在 AI 模型和外部数据源之间建立安全连接。它通过主机进程、客户端和服务器的架构，让 AI 应用能够访问文件系统、数据库等外部资源，突破了传统 LLM 仅能文本交互的限制。开发者可以使用任何编程语言创建符合 MCP 规范的应用，实现 AI 能力的标准化扩展。

## 📌 MCP 核心亮点

🔗 标准化连接：基于开放协议的安全双向通信标准，支持多种通信方式和数据传输。

🚀 扩展能力：无缝对接外部数据源、文件系统、数据库等资源，突破 LLM 的能力边界。

⚡ 开发友好：提供多语言 SDK 支持，采用简洁架构设计，让开发者快速上手部署。

🌐 广泛兼容：支持各类 LLM 模型，实现跨平台运行，确保工具生态互通互联。

💡 场景丰富：从 AI 应用增强到 IDE 集成，从数据查询到文件管理，应用场景全面覆盖。

⚙️ 架构优越：采用模块化低耦合设计，标准化接口确保系统稳定可靠运行。
