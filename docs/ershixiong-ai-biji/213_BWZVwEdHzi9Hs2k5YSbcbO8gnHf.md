# NLWeb 的命令行工具（CLI）的功能、使用方法和主要命令。

> 来源：[https://qianniucity.feishu.cn/docx/Yoord9x2aoDKkYxUcUAcfKFYnih](https://qianniucity.feishu.cn/docx/Yoord9x2aoDKkYxUcUAcfKFYnih)

主要内容总结如下：

+   **CLI 作用**：
NLWeb CLI 用于简化配置、测试和运行应用，帮助用户交互式地完成环境变量和设置的配置，无需手动编辑配置文件。

+   **启动方式**：
通过执行 ⁠source setup.sh⁠ 脚本，临时将 nlweb 命令加入 PATH 并创建别名。

+   **主要优势**：

+   简化配置流程，自动检测并引导设置所需环境变量。

+   记忆用户偏好（如 LLM 提供商、检索端点），并存储到配置文件。

+   检查环境和服务连接，确保配置正确。

+   提供交互式设置和一致的环境变量管理。

+   **常用命令**：

常用参数包括 ⁠-h/--help⁠（帮助）和 ⁠-d/--debug⁠（调试输出）。

+   **配置文件与环境变量**：
CLI 管理 YAML 配置文件（如 LLM 和检索端点配置），并帮助设置和持久化 API key、服务端点等环境变量到 ⁠.env⁠ 文件。已存在的环境变量会被自动检测并复用。

+   **高级用法**：

+   可随时切换 LLM 提供商或检索端点，CLI 会自动更新配置。

+   支持调试模式，输出详细日志。

+   提供虚拟环境的自动化设置和激活方法。

+   支持通过 CLI 加载 RSS 数据。

整体上，NLWeb CLI 提供了便捷、交互式的配置和管理体验，适合开发、测试和生产环境下的多种需求。
