# 如何在行业大会上高效地和客户交朋友？

> 来源：[https://docs.feishu.cn/docx/MS9id4BSjo4tofxKTR8cy8zLnAb](https://docs.feishu.cn/docx/MS9id4BSjo4tofxKTR8cy8zLnAb)

> 作者：[泛函同学的一切 | 这是一篇阅读量 4w+ 的个人说明书](https://to7e2gkmim.feishu.cn/wiki/wikcnl2UCXsXjLBgGBnt3GDCI7g)

去年因为在一家做 AI 的创业公司，所以经常有机会和老板一起去参加行业大会。

去得多了，自己琢磨出了一套 SOP，靠这套 SOP 交到了不少有意思的朋友，感觉还挺有用的。

今年 AI 这个圈子里的行业大会也不少，我猜朋友们也需要，所以我来展开写写。

首先呢，不怎么去行业大会的朋友可能会觉得，行业大会里，最该做的，是好好听分享嘉宾讲的内容。

这样想很正常，因为每个行业大会在宣传的时候，都会着重强调，我们请了哪些特别厉害的嘉宾，聊哪些特别热门的话题。

但是呢，听内容，倒真不必放在特别高的优先级上。

因为行业大会里分享的所有内容，大概率都会变成👸号、播客等更加用户友好的内容形态再发出来，到时候再学习也不晚。

所以，参加行业大会最重要的，是认识这里面的人，让这些人成为你的合作方和客户。

在行业大会上社交是个 ROI 很高的事情，毕竟参加行业大会是一件很贵很麻烦的事情，能来的都是对这个领域热情很高的人，且都有社交需求，很容易聊上。

那怎么和人搭上话呢？

这里就有些详细的技巧了：

1️⃣

在行业大会开始之前，早点到现场，然后打开地图 App 或者大众点评搜索离这里最近的咖啡馆，然后自己走过去一趟，背熟路线。

2️⃣

行业大会开始后，去认真听嘉宾的分享，但是在听的时候，你一定要持续地问自己这个问题：“如果我和一个陌生人聊起这场分享的内容，我们会聊什么？”

带着这个问题听，嘉宾分享的所有内容，会很自然地变成你的社交弹药，和人聊天时，就能快速找到话题了。

3️⃣

再厉害的嘉宾，讲得久了，一定有人听不动了，会跑到会场外透气。

在听了一个小时左右后，你就该意识到，时候到了，该去抓人了。

4️⃣

你来到会场外，但凡一个人看起来没太多事情，你就可以过去搭话了。

话题开头模板大概是这样的：“你好呀，我刚刚在这个会场有看到过你，我一直都很想认识一下这个领域的朋友，所以想来和你打个招呼。”

假设对方没有拒绝你，那么就可以接着聊下去了；

如果对方表示“有事”或者流露出了明显不愿意聊天的样子，那咱也不用灰心，礼貌地道个别，去抓下一个人就行。

这里要多说一句，你自己大可不必担心对方不愿意和你聊。

以我当 I 人的经验，那些在门口落单的人的心理活动，大概是这样的：

“大家怎么都是三五成群地来的呀，我也好想加入他们呀，但是直接过去会不会不太好？”

“我也好想认识点这个领域的人呀，但是我该怎么搭话呢？”

“要是有个人来主动找我的话就好了5555……”

所以有时候你去主动开启聊天，还会不小心给人一种「自己终于被拯救了」的感觉，对方还挺开心的。

5️⃣

如果对方愿意聊下去，那么我们可以这么展开话题：

“刚刚 xx（嘉宾名）的分享我真的特别有启发，因为我是做在一家 xx 公司 xxx 业务的，所以 ta 说的那几个点我真的太有感触了……”

你看，通过这样的方式，我们就丝滑地完成了自我介绍。

如果你一上来就说我是 xxx 公司的 xx 负责人，那么可能会“销售感过重”，而且如果你的公司很大很有名的话，可能有显摆 title 的嫌疑，有概率引起对方本能的反感。

以嘉宾分享的内容切入，把自己的介绍作为话题的背景信息补充给对方，这样就丝滑多了，不容易让人反感。

6️⃣

通常这么聊完之后，对方也会很自然地介绍自己的公司和业务，你俩就了解彼此了。

当对方介绍完，就可以夸夸这个领域，然后掏出手机加🛰️了。

怎么夸这个领域呢？这个就看平时的积累了，得多看看这个领域头部公司的 PR 稿，以及各种大号对这个领域的测评文章。

你就能很快学会，这个领域的人，是怎么给其它人传递该领域的价值的。

比如，做 Agent 你就说，吴恩达说过 Agent 大趋势，这条路很有希望；

做 RAG 的你就说，RAG 真的是大模型落地性价比最高的方式；

做开源的你就说，开源的力量真的很神奇，感觉开源世界的进步速度真的太超越大众的预期了；

……

通常聊到这里，🛰️加上之后，你可以去找下一个人了。

但如果你的目标并不是“多”，而是“深”，那么你应该和这个人说，附近有家很不错的咖啡，我刚好熟悉路，要不我们一起去那边聊聊。

把人约到了咖啡馆，我们就能去聊得很多很深了，这时我们不该急着离开，聊上一两个小时都是值得的。

这里需要注意到的是，话题最终一定得从公司行业这些大格局的东西，回归到对方这个人身上。

对方是创始人，就得聊聊 ta 一开始为什么决定做这个，有哪些感性的感受；

对方是从业者，就得聊聊为什么当初来到这个行当，感受如何；

对方是媒体人，就得聊聊见过的那么多人里，哪些印象最深刻；

这样你俩才能顺利地交上朋友。

如果对方是和朋友一起来的，刚好就可以一起认识一下朋友们，那么自然而然就认识更多人了。

7️⃣

在大会结束的一天晚上，做两件事情：

对于深聊过的人，你们聊的时候必然提到了不少文章、播客、视频之类的东西，记得当天发了；

发完这些之后，可以顺便发一下公司或者业务的介绍。

这里有个细节，打开介绍的舒适感：长图>小绿书>视频号>👸号>飞书文档>PDF 文件。

所以只有 PDF 材料的赶紧做个长图，球球了。

对于没深聊过的人，简单发段文字的介绍，配个长图并且说一声“有机会一起喝个咖啡”。

这时候通常对方都不会拒绝，直接聊上。

然后，给自己在🛰️上设个提醒，一周之后，得真的去约对方喝个咖啡，这时候成功率很高。

9️⃣

我以前是 ENFP，对于那时的我来说，社交是一个毫无顾虑的事情，我可以很丝滑地开启，没有心理卡点。

但印象深刻的是，那时候经常因为太过热情搞砸各种事情，看似很受欢迎，实际上常常让朋友和同事皱眉。

现在我自己成了 INTJ，社交对我来说，压力也不小。

但我感觉现在社交的成功率高多了，因为我把各种细节都琢磨明白了。

以前的社交勇气是性格天然，现在的社交勇气是努力复盘而获得的。

实不相瞒，后一种勇气，让我觉得更坚实，更有信心，比当 E 人的时候舒服多了。
