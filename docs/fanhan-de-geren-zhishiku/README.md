# 🫂我希望你如何和我沟通

---

## 多批评我

+   虽然没有一个人真的喜欢被批评，但是实事求是的说，我目前取得的一些成就，很大程度来源于几个关键的节点上，那几个关键的人，对我的几次关键的批评。

+   我还只是一个20岁出头的年轻人，还有大把事情做不好，有大把道理不理解，我需要一些客观的批评能够让我客观地面对自己、面对问题。

+   所以，如果我哪里做得不好的话，🙏🏻请务必直截了当地告诉我，我一定会努力认清现实，努力改进的。

+   当你批评我时，如果你想让事情运转得更好，如果你想帮助我成长，可以参考👇🏻这个案例：

> 我真的非常非常非常感谢我的上一任老板对我的那次批评：

1.  你这一次交付的结果真的质量很低。

1.  确实，你的行动力很强，你能很快地完成任务。

1.  我也知道你比较焦虑，并且在通过快速地做事、做更多事来缓解焦虑。

1.  但是，你总是将一个任务马虎地完成之后，就急于开始下一个任务了，甚至同时做着好几个任务。

1.  于是，一个任务做完之后，由于交付的质量很低，所以它并没有能够给你带来足够的成就感，并没有能缓解你的焦虑。

1.  然后你就进入了一个死循环，永远忙碌、永远低质量交付、永远能力得不到提高、永远焦虑。

1.  你应该做的事情是，将一个任务完成以后，对这个任务进行一次检查，并多花一些时间优化它，等到保证了这个任务的交付质量之后，再开始做新的任务。

1.  这样，你才能走出那个死循环。

+   我犯的错+我犯错的原因+改进方案+改正错误的好处。

+   提前感谢你未来对我的批评，提前感谢你让我变得更好。
