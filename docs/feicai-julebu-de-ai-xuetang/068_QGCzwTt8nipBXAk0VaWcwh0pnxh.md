## Claude Code Sub Agent数字员工团队搭建方法

这套方法主要是为了解决一个痛点：当我们面对复杂的多专业协作任务时，传统的AI一问一答模式往往力不从心。

单个AI既要懂产品又要会设计还要能编程，结果就是什么都做得不够专业。而且上下文一长，前面分析的内容后面容易被新任务干扰。这就像让一个人同时胜任团队里所有岗位，效果肯定不理想。

所以我们用Claude Code的`Subagent`功能组建了一个专业分工的数字员工团队。每个`Subagent`都有独立的上下文窗口和专业提示词，就像真正的专业员工一样，在自己的"办公室"里专注完成工作，不会被其他任务打扰。

比如你想做产品开发，可以组建"产品经理+设计师+前端工程师+后端工程师"的团队；想做营销活动，可以搭配"市场调研员+文案策划+设计师"；想写研究报告，就用"数据分析师+内容编辑+格式排版员"。每种场景都能找到合适的专业组合。

方法的核心是用Claude Code的`Subagent`功能，每个专业角色都是一个独立运行的AI智能体。主控Agent负责整体流程调度，决定什么时候该哪个专家出场。每个`Subagent`会在独立环境中深度执行任务，还能主动搜索最新信息，工作成果自动传递给下一个环节。

需要注意的是，`Subagent`模式质量更高，但token消耗也更大，每次调用都需要重新初始化上下文。所以比较适合对质量要求高的重要项目。

这套方法特别适合需要多专业协作但缺乏相应团队的个人或小企业，让你能够组建一个专业分工明确的AI团队，从想法到最终交付物，提升工作效率和专业度。

### 核心功能模块

#### /团队协调

**智能角色调度** - 基于`CLAUDE.md`的协调规则，主控Agent会根据对话内容和用户指令，智能判断何时调用哪个`Subagent`。按照"需求分析→设计规范→代码实现→部署配置"的标准流程执行，每个`Subagent`在独立上下文中完成专业工作后，将结果返回给主控Agent展示给用户。协调者负责引导整个流程，确保各环节顺利衔接。

#### /专业分工

**独立`Subagent`工作** - 每个专业角色都是独立运行的`Subagent`，拥有专属的系统提示词和工作环境。产品经理、设计师、前端工程师、后端工程师等都在各自的上下文窗口中深度执行任务，不会被其他工作干扰。这种黑盒工作模式让每个角色能够专注发挥专业能力，输出高质量的工作成果。

#### /成果传递

**标准化文档流转** - 每个`Subagent`按照预设格式输出专业文档：产品经理生成`PRD.md`、设计师输出`DESIGN_SPEC.md`、开发工程师交付完整项目代码、后端工程师提供部署配置。这些文档会自动传递给下一个`Subagent`作为工作基础，确保整个协作链条的信息完整性。

#### /智能调研

**实时信息搜索** - 各`Subagent`在独立工作时会主动使用`web_search`工具获取最新信息，比如产品经理调研市场趋势、设计师查找设计趋势、工程师寻找技术方案。由于每次调用都会重新初始化，`Subagent`能够基于最新信息进行专业分析和决策。

#### /质量控制

**专业反馈机制** - 用户可以在任何阶段提出修改意见，对应的`Subagent`会被重新调用来更新工作成果。由于每个角色都有独立上下文，修改过程更加专注和准确。主控Agent负责协调修改流程，确保各环节的修改能够有效同步。

> 注：本方法基于Claude Code的`Subagent`功能设计，token消耗相对较高但专业度更强。特别适合对质量要求高的重要项目，以及需要多专业深度协作的复杂任务。你可以根据具体需求自定义专业角色和团队规则，最终效果取决于你的角色设计和项目复杂度。

## 配置团队规则和角色

请你跟着视频中的操作步骤，使用Claude Code的`Subagent`功能创建专业AI团队。配置完成后，你的项目应该包含以下内容：

```
project/
├── CLAUDE.md                    # 团队协调规则（手动创建）
├── .claude/agents/
│   ├── product_manager.md       # 产品经理Subagent（自动生成）
│   ├── designer.md              # 设计师Subagent（自动生成）
│   ├── frontend_developer.md    # 前端工程师Subagent（自动生成）
│   └── backend_engineer.md      # 后端工程师Subagent（自动生成）
├── PRD.md                       # (运行时生成)
├── DESIGN_SPEC.md               # (运行时生成)
└── ...
```

**配置步骤：**

1. **创建团队规则** - 在项目根目录手动创建`CLAUDE.md`文件，复制团队协调规则内容

1. **创建Subagent** - 使用Claude Code的`/agents`指令，选择`Create New Agent`逐个创建4个专业角色

1. **配置系统提示词** - 为每个`Subagent`复制对应的专业系统提示词，设置描述和工具权限

1. **设置颜色标识** - 为不同`Subagent`选择不同颜色，便于在协作时区分谁在工作

**重要注意事项：**

+   `CLAUDE.md` 必须放在项目根目录，文件名大小写严格按照要求，这是Claude Code识别团队规则的关键文件

+   `Subagent名称` 必须与`CLAUDE.md`中指定的调用名称完全一致，否则会导致角色召唤失败

+   **系统提示词** 要完整复制，包含角色定位、技能描述、工作流程等所有内容，确保`Subagent`能够正确理解自己的职责

+   `Description设置` 要准确描述每个`Subagent`的调用时机，这影响Claude Code的智能判断

+   **工具权限** 建议全选，确保`Subagent`能够使用`web_search`等必要工具

+   如果你要添加新的角色，需要同时在`CLAUDE.md`中添加对应的流程环节，并创建相应的`Subagent`

这种标准化的配置确保了Claude Code能够正确调度你的AI团队，任何配置错误都可能导致协作流程中断。记住，`Subagent`模式的token消耗较高，但专业度和工作质量会明显提升。

## 👀 先睹为快

使用这套`Subagent`数字员工团队方法，我们组建了一个三人专业开发团队，成功开发了一个完整的个人创作者网站前端静态页面。整个团队包括产品经理、设计师、前端工程师三个独立的`Subagent`，每个都在自己的专业领域深度工作，完整展现了从模糊想法到产品需求文档(`PRD.md`)，再到设计规范(`DESIGN_SPEC.md`)和前端项目代码的全流程协作。

这个网站前端实现了完整的界面展示：包含首页的品牌展示、知识库内容介绍、学习路径规划、企业咨询预约表单等模块。每个页面都有精心设计的布局，采用深色主题，参考了OpenAI官网的设计语言。网站还包含了完整的响应式设计，在移动端和桌面端都有良好的显示效果。

每个`Subagent`都在独立的上下文中展现了专业能力：产品经理进行市场调研和功能拆解，设计师搜索最新设计趋势制定视觉规范，前端工程师编写高质量的`HTML/CSS/JavaScript`代码。整个过程就像真正的专业团队在协作，每个角色专注于自己的专业领域。

重要说明：本演示案例专注于前端静态页面开发，展示的是可以在浏览器中直接运行的`HTML/CSS/JavaScript`代码。虽然我们的团队配置中包含了后端工程师角色（用于后续的数据库和API开发），但这次演示主要验证前端开发流程的完整性。如果你需要完整的全栈开发，包括后端API、数据库设计、部署配置等，完全可以调用后端工程师`Subagent`来完成相应工作。

你也可以根据自己的需求添加其他专业角色，比如测试工程师、数据分析师、文案策划等，组建更符合你项目需求的专业团队。

> **重要说明：**

+   本演示案例专注于前端静态页面开发，展示的是可以在浏览器中直接运行的`HTML/CSS/JavaScript`代码。虽然我们的团队配置中包含了后端工程师角色（用于后续的数据库和API开发），但这次演示主要验证前端开发流程的完整性。如果你需要完整的全栈开发，包括后端API、数据库设计、部署配置等，完全可以调用后端工程师`Subagent`来完成相应工作。

+   你也可以根据自己的需求添加其他专业角色，比如测试工程师、数据分析师、文案策划等，组建更符合你项目需求的专业团队。

+   **提示词质量决定团队能力**。每个`Subagent`的专业水平完全取决于你编写的系统提示词质量。建议先使用我们提供的基础版本，在实际使用中根据效果逐步优化角色设定、工作流程和输出标准。

+   **严格按照配置要求操作**。`CLAUDE.md`文件必须放在根目录，`Subagent`的名称必须与调用指令完全对应，任何配置错误都会导致角色召唤失败。建议严格按照视频演示的步骤操作。

+   **建议从简单任务开始**。如果你是第一次搭建AI团队，先从相对简单的项目入手，比如内容创作团队、营销策划团队等，逐步尝试更复杂的产品开发协作。

+   **合理控制成本**。`Subagent`模式的工作质量很高，但token消耗也比较大。建议用于重要项目或对质量要求高的工作，日常简单任务可以考虑其他方式。

+   **充分利用反馈机制**。在任何环节发现问题都可以直接提出修改意见，对应的`Subagent`会被重新调用来处理。及时的反馈能让最终结果更符合你的期望。

+   **理解协作而非替代**。这套方法是让AI团队协助你完成工作，你仍需要提供清晰的需求、做出关键决策、把控整体方向，`Subagent`负责在各自专业领域深度执行。
