## 文章扩写提示词框架介绍

在内容创作过程中，扩展文章往往是一项耗时且极具挑战的任务。无论是为了增加内容细节、丰富论据支持，还是单纯为了达到特定的字数要求，创作者在扩写过程中经常会遇到诸如思路枯竭、风格不一致等问题。在这种情况下，保持文章整体的质量和逻辑连贯性尤其困难，特别是当创作者必须在较短的时间内实现字数目标时。

这套文章扩写提示词框架正是为了应对这些创作痛点而设计的，提供了系统化的扩写支持，以帮助创作者高效地进行内容扩展，同时确保内容质量不受影响。

该框架特别适合🛰️👸号文章作者、头条号作者等内容创作者。通常情况下，创作者会先构思文章大纲，然后进行写作。而通过这套框架，创作者可以基于原文或大纲直接生成完整的文章。如果文章的长度不够达标，创作者还可以通过扩写功能继续延展内容，且新生成的部分与原文风格保持一致。这种扩展过程使创作更为高效和可控。

通过这套框架，创作者能够明确地一步步引导扩写过程，确保最终生成的文章不仅达到预定的字数目标，还能保持逻辑上的一致性和与原文风格的精准还原。该框架的结构化流程能够使扩写工作更加可控且高效，无论是短期快速需求，还是长期内容的逐步扩展，创作者都可以从中受益良多。

### 框架核心结构与详解

1. 目标字数与需求确认：精确扩写目标

扩写开始之前，明确的目标是最为关键的一步。本框架首先引导创作者确认扩写的目标字数，并通过对原文内容的分析，确定扩写的方向和重点部分。这确保创作过程从一开始就有了明确的路径和清晰的规划。

+ 需求确认：创作者需要提供原文内容以及目标字数，框架会基于这些信息为扩写过程进行初步规划。

+ 重要性：每一步扩写都围绕最终目标展开，避免冗余内容和不必要的扩展。

2. 扩写执行：逐步扩展并保持风格一致

在扩写过程中，保持文章原有的风格和语气至关重要。框架会分析原文的风格特征——如正式程度、句式结构、情感表达等——并在扩写时确保风格保持一致，避免扩写后的内容与原文产生突兀的风格差异。

+ 扩展细节：逐段逐句进行内容扩展，包括增加描述细节、丰富论据、添加新的示例，从而增强文章的说服力和逻辑连贯性。

+ 风格匹配：通过细致分析原文，框架确保扩写部分的用词、句式和语气无缝契合原有部分。

3. 字数检查与反馈调整：确保达标并符合预期

每一步扩写完成后，框架会自动进行字数统计，以确保扩写的进度和方向符合用户的需求。同时，创作者可以实时监控扩写内容的质量，提出修改建议或进一步的需求。

+ 字数统计：创作者可以随时输入指令 `/字数检查`，框架将提供即时的字数统计报告，帮助创作者了解扩写完成情况，确认是否达到目标字数。

+ 反馈调整：创作者可以根据扩写内容提出修改意见，框架会根据反馈进行内容优化，以确保文章质量和一致性。

4. 内容定稿与润色：整合润色，生成最终内容

在扩写达到目标字数并经过创作者确认后，框架将原文与扩写的部分进行合并去重，生成完整的内容。同时，框架会对合并后的文章进行整体编辑，确保内容的逻辑性、流畅性和连贯性，使最终定稿的文章能够完全符合创作者的预期。

+ 合并去重：将扩写部分与原文进行合并，并去除重复内容，确保文章精简有力。

+ 润色定稿：创作者可以在扩写完成并达到目标字数时，输入指令 `/定稿`，框架将进行整体润色编辑，增加语言的流畅度和文章逻辑的紧密度，提升整体质量。

### 为什么选择这套扩写提示词框架？

系统化扩展支持，确保内容一致性

这套文章扩写提示词框架通过系统化流程帮助创作者逐步实现内容的扩展。从明确需求到逐步扩写，再到字数检查和内容定稿，每一步都围绕创作者的目标展开，确保扩写后的文章既能达到字数要求，又在逻辑和风格上保持原文的一致性。

保持文章风格，提升内容质量

在扩写文章时，最常见的问题之一就是扩写后的内容与原文风格不符，导致整体文章显得不协调。该框架通过对原文进行详细的风格分析，确保扩写后的内容无缝融入，既丰富文章内容，又不会让读者察觉到明显的风格断裂，从而提升整体文章的阅读体验。

灵活调整与实时反馈，显著提升创作效率

创作者可以在扩写的每一步对内容进行实时检查，并提出进一步的需求或调整意见。框架根据这些反馈迅速调整内容，确保每个部分都符合预期。这样的反馈与调整机制，不仅让扩写过程更加灵活，还显著提高了创作效率。

**重要说明：**这套提示词框架推荐使用 Claude 3.5 Sonnet、ChatGPT-4 和 Kimi 模型，这些模型具备卓越的内容生成和逻辑推理能力，能够确保扩写内容的高质量和逻辑一致性。需要注意的是，目前市面上的大多数大模型每次输出文章的长度通常限制在约 3000 字以内。如果您希望生成超过 3000 字的内容，建议分段生成并进行人工拼接，以确保整体内容的连贯和完整。
