
# ChatGPT搜索功能

> 来源：[https://feicaiclub.feishu.cn/docx/AREldkqEyoOCoQxWHqrcvNCKnjc](https://feicaiclub.feishu.cn/docx/AREldkqEyoOCoQxWHqrcvNCKnjc)

![](img/32c440dd5c747f75e6422d6b92e27e87.png)

现在，您可以通过链接到相关网络资源的快速、及时回答，享受更好的搜索体验。

ChatGPT现已具备比以往更强大的网络搜索能力。您可以获得快速、及时的答案，并附带相关网络资源的链接，以前这些信息通常需要通过搜索引擎获取。这个新功能结合了自然语言界面的便捷性和最新的体育比分、新闻、股票行情等实时信息的价值。

ChatGPT会根据您的问题自动选择是否进行网络搜索，或者您可以通过点击搜索图标手动启动搜索功能。

![](img/5840b847310c86a480e647667ecb7be7.png)

此功能将在`chatgpt.com`网站（会在新窗口中打开）以及桌面和移动应用程序中提供。今天，ChatGPT Plus用户、团队用户和SearchGPT候补用户即可使用。企业和教育用户将在未来几周内陆续获得访问权限，免费用户将在接下来的几个月内逐步开放。

## 旨在为您提供更好的答案

在网上找到有用的信息往往需要花费不少精力，通常需要多次搜索并查看大量链接才能找到优质来源和所需信息。

现在，通过ChatGPT，您可以用更自然、对话的方式提出问题，系统会选择从网络中获取信息来回答。您还可以通过跟进问题深入探讨，ChatGPT会根据整个对话的上下文，为您提供更贴合的问题答案。

我们还与新闻和数据提供商合作，提供实时信息，并为天气、股票、体育、新闻和地图等类别推出全新视觉设计。

![](img/339a4cd72f53d08578412f92964b572a.png)

## 直接获取来源

聊天内容中现在会附带来源链接，例如新闻文章和博客，让您能够进一步了解相关信息。点击回答下方的“来源”按钮，即可在侧边栏查看参考资料。

![](img/c426e2a66ec85ed1f747b587a54b429d.png)

ChatGPT搜索功能帮助用户直接与高质量的网络内容互动，使其成为对话的一部分。通过将搜索与聊天界面结合，用户可以用全新的方式获取信息，而内容创作者也能够接触到更多读者。我们希望帮助用户发现更多出版商和网站，同时为搜索体验提供更多选择。

我们与新闻行业进行了广泛合作，并认真听取了全球出版合作伙伴的反馈，其中包括美联社、阿克塞尔·施普林格、康泰纳仕、Dotdash Meredith、金融时报、GEDI、赫斯特、世界报、新闻集团、Prisa（《国家报》）、路透社、《大西洋月刊》、《时代周刊》和Vox Media等。任何网站或出版商都可以选择出现在ChatGPT搜索中（会在新窗口中打开）。如果您有反馈意见，请发送电子邮件至publishers-feedback@openai.com。
