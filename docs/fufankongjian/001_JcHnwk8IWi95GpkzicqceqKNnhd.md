#   ❓猜你想问

**Q：社区内容是收费的吗？**

+   我们是**公益社区**，社区内所有内容都是**免费**的，但是其价值完完全全是对标市面上价值万元的品质课程（并且市面上很多付费课程交付结果跟我们公开课质量都不是一个量级），还请小伙伴们且行且珍惜～

Q：完全0基础可以入门学习大模型吗？

+   我**们欢迎所有对大模型**技术感兴趣的小伙伴来一起学习一起玩！社区的内容排布以及整理的学习路径，甚至是老师们的公开课内容，新手友好度都非常高～

+   而且现在大模型行业还是蓝海市场，非常多小伙伴都是零基础/跨行转入的，门槛相对来说还较低～

**Q：我在别的地方看到你们的课件，加上好友后发现并不是九**天老师的课程 / 他们的课程质量并不好？

+   请**认准赋范空间**！！我们承诺且保证，社区以及赋范空间所有课程，均为以九天老师为首的教研团队独家研发，课程内容已申请多项专利，我们也一直在积极打击市面上盗内容的无良商家，对于那些自己不能产出内容，盗我们技术内容进行引流割韭菜的行为深恶痛绝！还请小伙伴们擦亮眼睛不要上当受骗！（当然，豪不吹嘘的说，这也侧面反映了我们课程内容的优质～

**Q：赋范空间有没有大模型课程？**

+   有**！我们有《大模型A**gent开发》和《大模型原理与训练》两门系统大课，Agent开发偏企业应用落地，原理课更偏核心的原理详解，课程都是采取“每周直播+录播回放”的形式，目前已更新内容有100+小时，并在持续更新中

+   课程都是由**九天老师**带领精心研发，课程品质绝对优质！相较于公开课会更加体系，也会更加深入，小伙伴们参与过我们公开课直播的，相信大家就能感受到老师们的技术实力和授课水平！

+   更重要的是我们的**学员专享服务**，我们同时设有答疑群，授课讲师均在群内，课程上有任何问题，随时问！还有1v1咨询服务，不管是求职、写论文还是工程项目指导，都是别家另外花钱的服务！

Q：你们不是公益社区吗？怎么还卖课？

+   社区内容均为免费！公开课直播社群成员均可免费参与～

+   我们从来不否认自家有大模型课程，也不认为这是一件不可说的事情🤗，相反，由于市面上课程鱼龙混杂，教研老师们对技术负责，更对学员负责，精心研发出来的好课程能在这个时代的风口，被需要的同学看到，对你对我们而言，都是一件幸事～

+   同时，也期望小伙伴们能够理解“我们”，我们每节正课公开课的内容都是老师们精心研发且跑通后才编排课件讲给大家的，搞大模型是烧钱的，老师为学员们研发一个「MateGen智能助教」动辄耗资上百万，我们能吃上饭才能有持续的优质免费内容更新～

+   付费正课与公益的公开课两者并无冲突关系，如果社区内容能够满足你的部分学习需求，我们也会非常开心，不管是否是付费学员，我们都衷心欢迎大家来社区一起学习进步！

Q：你们的免费公开课和付费课程有什么区别吗？

+   首先，我们交付的任何一节课都是由教研团队精心研发，大家上过九天老师的公开课应该也能感受到，我们交付的项目对标的都是别家付费的课程项目

+   以GraphRAG六小时合集来说，九天老师是独家研发修改底层源码，最高程度地适配本地大模型运行，属于是别家付费也学不到的内容；

+   再举个比较近的例子，KTransformers技术二月中旬刚出来，九天老师立马开了低成本部署ds满血版的公开课直播，后来因其不支持并发不到一周又开了Unsloth的动态量化技术讲解，在3月初，修改了KT的源码实现了KT+Unsloth联合部署方案并提交了KT官方，3月4日的公开课，5号被KT官方采纳建议并更新至Github

+   其实“独家研发+深入原理详解+源码二次开发”一直是我们大模型课程的风格，主打的就是项目不仅能够跑出来，还要小伙伴们能够结合自己的企业数据以及业务情况快速适配调整

![](img/3132e144f37d0273ce0fdf5c08482ed1.png)

+   至于公开课和付费正课的区别，简单说起来公开课相当于付费课程的入门级别教程！例如GraphRAG，在付费正课中，我们会花公开课3倍以上的时间，深度体系化的讲解，帮助学员弄清楚每一个步骤为什么这样做，能够迁移至实际企业应用中！
