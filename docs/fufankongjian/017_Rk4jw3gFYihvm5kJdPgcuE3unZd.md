# 1.1 开源大模型指南

> 来源：[https://kq4b3vgg5b.feishu.cn/docx/OGEid4DPmoXxblxR95Gc04ycnoh](https://kq4b3vgg5b.feishu.cn/docx/OGEid4DPmoXxblxR95Gc04ycnoh)

开源大模型项目是围绕开源大模型（即可以将大模型部署到本地的大模型）、针对国内初学者、基于 Linux 、Ubuntu系统的专属大模型项目。

针对各类开源大模型提供包括环境配置、本地部署、高效微调等技能在内的全流程指导，简化开源大模型的部署、使用和应用流程，让更多的普通学生、研究者更好地使用开源大模型，帮助开源、自由的大模型更快融入到普通学习者的生活中。

# 本项目的主要内容包括：

1.  基于 Linux 、Ubuntu系统的开源 LLM 环境配置指南，针对不同模型要求提供不同的详细环境配置步骤；

1.  针对主流开源 LLM 的部署使用教程，包括DeepSeek系列、Qwen系列、LLaMA系列、ChatGLM等；

1.  开源 LLM 的部署应用指导，包括参数/超参数详解，命令行调用、在线 Demo 部署、LangChain 框架集成等；

1.  开源 LLM 的全量微调、高效微调方法，包括分布式全量微调、LoRA、ptuning 等。

> **学习建议：**

## **项目受众**

本项目适合以下学习者：

+   想要使用或体验 LLM，但无条件获得或使用相关 API；

+   希望长期、低成本、大量应用 LLM；

+   对开源 LLM 感兴趣，想要亲自上手开源 LLM；

+   NLP 在学，希望进一步学习 LLM；

+   希望结合开源 LLM，打造领域特色的私域 LLM；

+   以及最广大、最普通的学生群体。
