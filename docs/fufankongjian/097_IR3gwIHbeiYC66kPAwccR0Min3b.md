# 1.2 在线大模型指南

> 来源：[https://kq4b3vgg5b.feishu.cn/docx/Jbd0dueldop9Y1xM02ac2mD9n9g](https://kq4b3vgg5b.feishu.cn/docx/Jbd0dueldop9Y1xM02ac2mD9n9g)

本文档的在线大模型项目是围绕在线大模型（即相较于开源大模型性能更优但不能部署在本地的大模型）、针对国内初学者的专属项目。

针对各类在线大模型提供包括账号注册、功能详解、API调用等技能在内的全流程指导，简化在线大模型的使用和应用流程，让更多的普通学生、初学者也能快速上手！

# 本项目的主要内容包括：

1.  针对主流在线LLM的介绍和应用开发教程，包括GPT系列、Claude系列、GLM等；

1.  在线LLM 的参数详解，包括参数/超参数详解、、API-KEY获取本地调用、功能实现等；

> **学习建议：**

> 在线大模型更倾向于使用并开发在线的大模型，相较于开源大模型对安装部署部分涉及较少，想要学习的同学们可以把精力更多放在模型功能熟悉、应用开发层面。这里把0基础入门所需要的所有知识都已经分门别类的放好，可以放心食用。

> **安心学习！！**功能[熟悉和应用](https://kq4b3vgg5b.feishu.cn/wiki/TMvpwSerXidBiGk7rh3cknZ4nVe)开发，在每一期文档都有详细的手把手教学！在线大模型的性能介绍与功能使用，几乎在每个相关项目的开篇都有详细介绍。更有企业级实战项目（已落地）手把手带你把所学知识融会贯通！如果你需要尽快获得特点知识请移步提个需求吧~会安排加急派送哦。

> [注：如同学在](https://kq4b3vgg5b.feishu.cn/wiki/PnJ3wT9LgixMEMkxlnkcu19UnFd)学习完本项目之后，想用实际项目进行练手请移步热门项目实战按需自取。

## **项目受众**

本项目适合以下学习者：

+   想要使用或体验 LLM，但不知道该如何注册并调用API；

+   希望长期、低成本、大量应用 LLM；

+   对在线 LLM 感兴趣，想要亲自上手在线 LLM；

+   熟悉低代码开发，希望进一步学习LLM定制化项目开发；

+   希望结合在线 LLM，打造领域特色的RAG、Agent；

+   **以及最广大、最普通的学生群体。**
