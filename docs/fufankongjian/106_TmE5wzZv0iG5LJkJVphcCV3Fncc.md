## 模型介绍

OpenAI Realtime API 是 OpenAI 推出的一款低延迟、多模态对话式 API，旨在为开发者提供构建接近实时交互体验的能力。Realtime API 通过 WebSocket 协议实现持久连接，支持低延迟的实时通信，并集成了功能调用（Function Calling），使开发者能够触发外部操作或引入动态上下文。

当前（截至 2025 年 2 月 27 日），Realtime API 的核心模型基于 `gpt-4o-realtime-preview`，这是 GPT-4o 系列的一个预览版本，专为实时音频和文本交互优化。该模型继承了 GPT-4o 的多模态能力，并针对低延迟场景进行了增强，提供自然的语音处理和高质量的输出。

该 API 支持文本和音频作为输入与输出，能够实现自然的语音到语音对话，适用于需要快速响应和多模态处理的应用程序，一些使用场景如下：

+ 语音助手：构建低延迟的对话式 AI，支持自然语音交互。
+ 客户支持：实现自动语音应答系统，提升用户体验。
+ 语言学习：提供实时语音反馈，帮助用户练习发音。
+ 实时翻译：支持多语言语音输入和输出，适用于会议或跨语言交流。
+ 游戏开发：为 NPC 提供自然对话能力，增强沉浸感。
