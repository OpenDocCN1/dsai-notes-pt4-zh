## 技术介绍

Agentic RAG 是传统检索增强生成（RAG）框架的下一代变体，通过将 AI 智能体（Agent）作为核心组件，显著提升了系统的灵活性、上下文理解和任务处理能力。传统 RAG 依赖静态的检索-生成流程，而 Agentic RAG 引入了动态规划、多智能体协作和自我优化机制，使其特别适合复杂、多步骤任务，如多轮对话、长文档分析和决策支持。

具体来说：它将 AI 代理合并到 RAG 管道中，以编排其组件并执行简单信息检索和生成之外的其他操作，以克服非代理管道的限制。代理 RAG 最常见的是指在检索组件中使用代理。通过使用可访问不同检索器工具的检索代理而变得代理，例如：

+   矢量搜索引擎（也称为查询引擎），通过矢量索引执行矢量搜索（如典型的 RAG 管道）

+   `Web search` 网页搜索

+   任何以编程方式访问软件的 API，例如电子邮件或聊天程序

Agentic RAG 适合以下领域：

+   法律文档分析：智能体可进行深入研究，合成法律信息。

+   客户支持：处理复杂查询，结合产品信息和历史交互生成个性化回答。

+   研究与开发：辅助科学文献审查和数据分析。

+   医疗：结合 CT 扫描和患者记录生成综合分析报告。

............

Agentic RAG 是一个新兴概念，随着 AI 技术进步，可期待更复杂的实现，如多智能体协作、实时学习和更高效的优化机制。Agentic RAG 与传统 RAG 比较：

| 特性 | Agentic RAG | 传统 RAG |

| --- | --- | --- |

| 核心组件 | 智能体（Agent）管理全流程 | 静态检索-生成流程 |

| 检索策略 | 动态调整，基于上下文 | 固定关键词或相似性搜索 |

| 生成优化 | 自我反思和迭代优化 | 单一生成，无反馈循环 |

| 适合场景 | 复杂、多步骤任务 | 简单关键词匹配、短文档 |

| 多模态支持 | 是（文本、图像、表格） | 有限（主要文本） |

| 计算成本 | 高（多次 LLM 调用） | 低（嵌入生成和搜索） |

> Agentic RAG 是 AI 信息处理领域的重大进步，通过智能体增强 RAG 的灵活性和准确性。
