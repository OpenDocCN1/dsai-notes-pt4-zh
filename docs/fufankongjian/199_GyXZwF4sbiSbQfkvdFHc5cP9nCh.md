# 框架介绍

LangChain 是一个开源框架，旨在简化基于大型语言模型（LLM）的应用程序开发。该框架由 Harrison Chase 于 2022 年 10 月发起，迅速成为 GitHub 上增长最快的开源项目之一，直到现在仍然在以一个飞快的速度不断进行迭代升级。它支持 Python，适用于构建各种 LLM 驱动的应用程序，如聊天机器人、智能搜索、问答工具、摘要工具以及能够执行机器人流程自动化（RPA）的 AI 代理。

![](img/adbb813c771fa8d61217080a565dc8b8.png)

LangChain 的核心目标是解决 LLM 集成和扩展的复杂性问题。LangChain 通过提供一个通用的框架，简化了 LLM 与外部数据源、软件工作流和工具的连接，使开发者能够构建更强大、更灵活的应用程序。

目前最新版LangChain的核心功能如下：

| #### **模块类别** | #### **示例功能** |
| --- | --- |
| **模型接口封装** | OpenAI、Claude、Cohere、Qwen 等模型统一调用方式 |
| **输出结构化** | 自动从模型中解析 JSON、Schema、函数签名、文档等 |
| **Memory 管理** | Buffer、Summary、Entity、Conversation Memory 等 |
| **Tool 接入** | Web 搜索、SQL 数据库、Python 执行器、API 代理等 |
| **Agent 架构** | ReAct、Self-Ask、OpenAI Function Agent 等调度机制 |
| **RAG 集成** | 多种 Retriever、Vector Store、文档拆分策略 |
| **Server/API 发布** | 快速将链部署为 Web 服务或 A2A Agent |
| Debug &amp; Callback | Token 使用统计、LangSmith 可视化追踪等 |

但LangChain并不是简单的开发框架，而是一个模型增强器+应用组装工具箱。
