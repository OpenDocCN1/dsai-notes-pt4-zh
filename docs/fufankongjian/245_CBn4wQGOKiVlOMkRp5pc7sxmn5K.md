# Harness Engineering

> 来源：[https://kq4b3vgg5b.feishu.cn/docx/B56qdFIrco5vTPxaAN5cjofYnJe](https://kq4b3vgg5b.feishu.cn/docx/B56qdFIrco5vTPxaAN5cjofYnJe)

## 框架介绍

Harness Engineering 是一种面向大型语言模型（LLM）应用的新型工程范式，专注于将模型能力“工程化编排”，以构建稳定、可控、可扩展的 AI 系统。它强调通过任务拆解（Task Decomposition）、流程编排（Orchestration）、工具调用（Tool Use）与反馈机制（Feedback Loop），让多个 AI Agent 在统一框架下协同工作，从而完成复杂任务。

该范式源于对传统 Prompt Engineering 的升级，结合了类似 LangGraph 和 LangChain 所代表的“流程化、状态化”设计思想，并进一步强化了对 Agent 行为的约束与调度能力。其理念可追溯到 Harrison Chase 等人在多代理系统方向的探索，但 Harness Engineering 更强调“让 AI 像团队一样工作”。

Harness Engineering 适用于构建各类复杂的 LLM 应用场景，例如多角色协作的 AI Agent 系统、自动化软件开发流程（产品→开发→测试）、企业级智能助手，以及具备长期记忆与自我迭代能力的 AI 工作流系统。其核心目标不是“让模型更聪明”，而是“让系统更可靠、更可控、真正能落地”。
