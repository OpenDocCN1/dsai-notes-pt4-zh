# 热门项目实战

> 来源：[https://kq4b3vgg5b.feishu.cn/docx/CbATdDNjUo4oT9xM1QBcXsdNnRf](https://kq4b3vgg5b.feishu.cn/docx/CbATdDNjUo4oT9xM1QBcXsdNnRf)

**本部分主要**是围绕已落地的实战项目，集合赋范空间独家研发的大模型企业级项目，从项目架构梳理，当下前沿热门技术/开发框架/热门大模型、到最后形成完整前后端的落地项目。让学习者从功能实现，到开发框架，及最后整合成为一个能用得上的企业级项目，完整的走下来。代码逐行讲解，代码打包带走，支持二次开发的优势，让更多的普通学生、研究者少走弯路，能更好的使用大模型的进阶技巧！
