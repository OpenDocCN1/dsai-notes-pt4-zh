# 最强统一智能体，ChatGPT Agent重磅发布！

> 来源：[https://kq4b3vgg5b.feishu.cn/docx/NaWSdsMvMoGPxrxzAetcwdYtnSc](https://kq4b3vgg5b.feishu.cn/docx/NaWSdsMvMoGPxrxzAetcwdYtnSc)

这场发布会的核心是推出了一款名为 ChatGPT Agent Mode（智能代理模式）的全新功能。这代表了AI从一个聊天机器人向一个可以为你自主执行复杂任务的“代理人”的重大演进。

下面为你详细梳理发布会的各项内容。

---

## 发布了什么？ 🚀

OpenAI 发布了 ChatGPT Agent Mode，一个集成在 ChatGPT 内部的全新功能。

它本质上是一个**AI智能代理**，**可以理解复杂**的、多步骤的指令，然后自主调用一个配备了浏览器、代码终端和各类API的虚拟计算机来完成任务。它不仅仅是回答问题，更是实际执行操作。

这个新功能整合并进化了OpenAI之前的两个独立工具：“Operator”（擅长与网页图形界面交互）和“Deep Research”（擅长深度信息研究）。

---

## 有什么特色？ ✨

**Agent **M**ode 的特色在于其强大**的工具整合能力和智能化、协同化的工作方式。

---

## 用户应用场景有哪些？ 🧑‍💻

发布会通过几个生动的案例展示了Agent Mode的广泛应用场景：

1.  **个人生活助理**:

+   **场景**: 为朋友的婚礼做准备。

+   **执行过程**: Agent自动访问婚礼信息网站，了解着装要求、天气和地点 -> 在网上搜索符合“中等奢华”要求的服装和鞋履选项 -> 搜索并对比婚礼场地附近的酒店空房情况 -> 提出合适的礼物建议 -> 最后生成一份包含所有研究结果和链接的综合报告。

1.  **商业采购与定制**:

+   **场景**: 为团队订购500张定制的笔记本贴纸。

+   **执行过程**: Agent使用图像生成API根据提供的吉祥物图片设计贴纸样式 -> 访问用户指定的电商网站（Sticker Mule）-> 上传设计稿并设置订单数量 -> 将商品加入购物车，并停在支付页面前等待用户确认和接管支付。

1.  **数据分析与报告生成**:

+   **场景**: 分析内部评估数据并制作一份PowerPoint演示文稿。

+   **执行过程**: **Agent通过API****连接到Go****ogl**e Drive，找到并读取指定的评估数据文件 -> 编写代码处理数据并生成图表 -> 调用图像API创建装饰性图片 -> 将所有内容整合并生成一个可直接下载和编辑的 .pptx 文件。

1.  **复杂行程规划**:

+   **场景**: 规划一个在单个赛季内访问全部30个美国职业棒球大联盟（MLB）球场的最佳路线。

+   **执行过程**: Agent搜索所有球队的赛程，特别是特殊的“Hello Kitty之夜” -> 编写代码进行路线优化 -> 最终生成一份包含详细行程、日期和地图的电子表格 (Spreadsheet)。

## 还有什么其他值得关注的？ ⚠️

1.  **技术核心与演进**: Agent Mode是**强化学习**在AI产品应用上的一个重要里程碑。它标志着OpenAI的产品策略——将多个单一功能的工具（Operator, Deep Research）融合成一个更强大、更通用的统一解决方案。

1.  **性能的飞跃**: 发布会展示了多个基**准测试（如Humanit**y's Last Exam, WebArena）的结果，表明Agent Mode在推理、浏览和解决真实世界任务的能力上，相比之前的模型（如GPT-4）有了显著的、甚至是翻倍的提升。

1.  ⚠️ 重点强调：安全风险与用户责任:

+   **新的攻击面**: OpenAI坦诚，功能强大的Agent也带来了新的安全风险，特别是**“提示词注入 (Prompt Injection)”**攻击。恶意网站可能会通过隐藏的指令欺骗Agent，让其泄露用户信息或执行恶意操作。

+   **缓解措施**: OpenAI已经通过模型训练（使其忽略可疑指令）和多层实时监控系统来防御此类攻击。

+   **用户须知**: 官方**强烈建议**用户将此视为一项前沿技术，并保持警惕。对于输入信用卡号、密码等高度敏感信息，应使用“接管模式” (Takeover Mode) 自行输入，而不是直接在提示词中提供给Agent。随着技术和社会的发展，针对AI代理的攻防也将不断演进。
