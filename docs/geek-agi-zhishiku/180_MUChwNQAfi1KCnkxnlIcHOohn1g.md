### 一、内容创作类

#### 案例 1：小红书爆款文案代写

【路径拆解】

+   定位：美妆 / 母婴 / 家居垂类

+   获客：闲鱼发布 “AI 原创文案代写” 服务

+   操作链：客户给需求→用 DeepSeek 生成 5 版文案→人工微调→交付

+   收益：

+   基础版：50 元 / 篇（纯 AI 生成）

+   精修版：150 元 / 篇（含配图建议 + 关键词优化）

+   关键点：

+   建立选题库（如 “100 个家居痛点清单”）

+   用 Canva 制作样案例图
