## **什么是 GPTs**

chatgpt 是一个基于人工智能的聊天平台，最新版本可以让你与世界上最先进的语言模型GPT-4进行对话，获取即时答案，寻找创意灵感，学习新知识，或者只是为了娱乐。chatgpt 不仅可以理解你的文字，还可以看到你的图片，听到你的声音，甚至为你创造新的图片。chatgpt 的目标是成为你的智能伙伴，帮助你实现你的想法和目标。

为了让chatgpt 更加贴合你的个性化需求，chatgpt 最近推出了一项新功能：GPTs。

GPTs 是指定制化的chatgpt 版本，可以为你提供更专业，更有用，更有趣的服务，你可以从数百个已经创建好的GPTs 中选择一个，或者自己创建一个GPT，然后与之对话。创建一个GPT 不需要任何编程知识，只需要给它一些指令和额外的知识，以及选择它可以做的事情，比如搜索网页，制作图片，或者分析数据。

你可以在 chat.openai.com/create 上尝试创建一个GPT。

ChatGPT 开发的这个强大的功能让我无比兴奋！这个功能开启了无限的可能性，让每个人都可以创建 GPT 应用程序，有手就行。

## **GPTs 使用方法**

使用 GPTs 的方法非常简单，你只需要在 chat.openai.com 上登录你的账号，然后选择你想要使用的GPT，或者创建一个新的GPT。

如果你选择了一个已经存在的GPT，你可以直接与之对话，或者查看它的介绍和指南，了解它的功能和用法。

如果你创建了一个新的GPT，你需要给它一个名称，一个描述，一些指令和额外的知识，以及选择它可以做的事情。

你可以随时修改或者删除你创建的GPT，或者与其他用户分享你的GPT。

OpenAI 的目标是让 chatgpt 成为你的智能伙伴，帮助你实现你的想法和目标。

### **一、GPTs创建入口：**

温馨提示：ChatGPT官方仅对Plus用户（GPT-4账号）开放了GPTs功能，需要满足该条件才可创建GPTs。

1、点击**Explore**，进入GPTs的应用界面。

![](img/4b1312b18b6106fffb2e5a7cff3b15d2.png)

2、点击**Create a GPT**，即可开始创建GPTs。

![](img/0e6f350a1276a419b438202820f6330c.png)

### 二、 如何创建并完善GPTs ？

首先，点击Create a GPT后进入到“新GPT”创建页面。

![](img/f7f44f13475a91de27ee0e8204159a38.png)

把创建GPTs的想法，在创建者界面告诉GPT生成器。它会引导你一步步创建你的GPTs，包含“命名 → 生成头像 → 明确功能 → 调整 →生成”流程。

![](img/c56bbc984dac2609e4d36ac200b9e09d.png)

如果你想修改配置项内容，点击Configure即可修改。

![](img/7098a6d7bc64022159709eb20a8c5a9c.png)

这里你可以调整：

+   **Name **命名，即给你的GPTs起一个适宜的名字

+   **Description **描述，即对你创建的GPTs写一句话介绍

+   **Instructions** 主要功能，即描述你的GPTs要解决什么问题

+   Conversation starters 预设问题，即预设一些你希望推荐用户提问的问题，比如：帮我写一篇未来科技发展前景的文章。

![](img/f6ff559ba7111f9aa7cb47045698075e.png)

+   **Knowledge** 知识库，即GPTs所需学习的知识及数据的上传入口，比如专业性很强的内容，像法律、医学知识等，可以将相关内容进行上传，丰富GPTs的认知和理解力。

![](img/addd1d67f3f417550c7737583c087eeb.png)

+   **Capabilities **性能，即对应的就是联网搜索、Dalle绘画、代码解释器。

![](img/ae3f5a185d27c689425181300cf0f0e1.png)

### **三、GPTs创建完成**

上述操作完成后点击保存，恭喜你创造了自己的AI产品，成为全球拥有GPTs应用的一员啦！若需要将GPTs进行发布，可参考下述操作方式：

+   **Only me**：仅自己可用；

+   Only people with a link：获得分享链接的用户均可使用；

+   **Public**： 对全部用户可见

![](img/328c4ccffb98446c44db7271af0b9228.png)
