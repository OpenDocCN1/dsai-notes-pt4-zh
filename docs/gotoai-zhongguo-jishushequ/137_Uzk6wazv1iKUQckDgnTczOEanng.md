# **免费开源教材**

1.  **《Linux 101》**：由中国科学技术大学 Linux 用户协会编写的免费在线讲义，专为零基础读者设计，官网链接为https://101.lug.ustc.edu.cn/。内容从 Linux 起源和开源文化讲起，逐步覆盖系统安装、文件操作、进程管理、用户权限等核心知识，还包含脚本编程、容器技术等实用内容。每章配有思考题和拓展阅读，部分章节还有配套直播视频，适合系统性打基础。

1.  《The Linux Command Line》：William Shotts 所著的开源书籍，500 多页篇幅详尽讲解 Linux 命令行相关知识。从终端基础操作到复杂命令组合运用都有涉及，还包含文本处理、管道与重定向等核心技能，适合想深耕命令行操作的入门者。可通过 Linux 文档项目相关渠道免费获取电子版，搭配实操练习能快速提升命令使用熟练度。

1.  《Introduction to Linux》：来自 Linux 文档项目的免费开源教材，系统介绍 Linux 的基础概念，涵盖文件系统、命令行、网络配置等核心内容。虽然部分内容版本稍旧，但对 Linux 基础逻辑和核心原理的讲解足够扎实，能帮助初学者建立对 Linux 系统的整体认知，适合作为入门启蒙读物。

1.  《Bash Beginners Guide》：同样出自 Linux 文档项目，专为 Shell 脚本初学者打造。内容从 Bash 基础语法入手，逐步引导学习者编写简单脚本，解决日常重复操作问题。对于想入门自动化运维的新手来说，是掌握 Shell 脚本入门知识的优质免费资料。

# **权威官方与社区文档**

1.  **Ubuntu 官方文档**：Ubuntu 作为新手友好型发行版，其官网（https://help.ubuntu.com/）提供免费的入门手册《Ubuntu Manual》。内容涵盖系统安装、桌面操作、软件管理等基础内容，步骤清晰且适配最新版本，适合选择 Ubuntu 作为入门系统的学习者查阅。

1.  **Linux 内核文档**：地址为[https://www.kernel.](https://www.kernel.org/doc/html/latest/)org/doc/html/latest/，虽偏向底层，但包含 Linux 系统的核心设计理念和基础架构介绍。入门阶段可选择性阅读基础章节，帮助理解系统运行的底层逻辑，为后续深入学习打下基础。

1.  **GNU Bash 官方手册**：GNU 官网推出的《Bash Reference Manual》，聚焦 Linux 命令行和 Bash 相关知识。详细讲解命令行语法、参数使用及常见问题，是学习命令行和 Shell 脚本的权威参考，适合搭配脚本入门教材同步学习。

# **优质免费视频课程**

1.  B 站 “Linux 零基础入门到精通”：黑马程序员、尚硅谷等机构均有免费上传该系列课程。以黑马程序员的课程为例，内容涵盖 Ubuntu 系统安装、常用命令、文件权限、Shell 脚本等基础模块，每节视频都有实时操作演示，代码和步骤可直接模仿，适合偏好视频学习的新手。

1.  中科大 Linux 101 配套直播视频：配套《Linux 101》教材的直播记录视频，可在 LUG FTP 或 YouTube 观看。视频由教材编写者讲解，对书中重点知识和实操案例进行现场演示，能解决看书时遇到的实操困惑，强化学习效果。

1.  Coursera《Linux for Everybody》：由密歇根大学开设的免费旁听课程。课程从 Linux 基础概念讲起，延伸到远程登录、文件管理、脚本编程等内容，案例贴合实际应用场景，适合利用碎片化时间系统学习，还能通过课后测验检验学习成果。

# **实操练习平台**

1.  **Linux Journey**：网址为https://linuxjourney.com/，是交互式 Linux 学习平台。以闯关形式讲解 Linux 基础，每个知识点后都配有在线终端供即时操作，无需本地安装系统，适合新手快速熟悉常用命令和基础操作。

1.  **OverTheWire**：网址为https://overthewire.org/wargames/，通过游戏化方式训练 Linux 技能。从基础命令到系统漏洞挖掘，难度逐步提升，新手可从 Bandit 关卡开始，在闯关过程中巩固命令行、文件权限等知识，趣味性强且能强化实操能力。

1.  **实验楼 Linux 入门课程**：平台提供免费的 Linux 基础实验环境，课程涵盖常用命令、Shell 脚本、服务器搭建等内容。学习者可在云端直接操作，无需担心本地环境配置问题，实验步骤详细，适合零基础者通过实操巩固知识。
