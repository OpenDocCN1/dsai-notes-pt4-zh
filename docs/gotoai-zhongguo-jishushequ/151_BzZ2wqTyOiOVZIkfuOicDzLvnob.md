
# Python 入门

> 来源：`https://gotoaiworld.feishu.cn/docx/QfXIdDHdFozHUtxfBKHcUZtvnjd`

## 经典免费开源教材

1. 《简明 Python 教程》（A Byte of Python）：专为零基础小白设计，内容简洁易懂，无复杂概念堆砌，涵盖 Python 核心语法和基础应用。支持在线阅读，还有中文版，非常适合作为入门的第一本教材，能快速帮助读者建立 Python 编程的基本认知。
1. 《Think Python》：全称《Think Python: How to Think Like a Computer Scientist》，以培养编程思维为核心，而非单纯讲解语法。书中通过大量实例和练习，引导读者像计算机科学家一样思考问题。该书为开源免费，可在官网下载电子版，适合想扎实打好编程基础的学习者。
1. 《Dive into Python 3》：开源的进阶入门教材，适配 Python3 版本，提供 HTML 和 PDF 两种免费版本。内容从实际代码出发，讲解 Python 的核心特性和编程技巧，书中案例贴近实际开发场景，学完后能具备基本的 Python 开发能力。

## GitHub 热门开源实战教程

1. `Python - 100 - Days`（`https://github.com/jackfrued/Python - 100 - Days`）：星标超 12 万的热门项目，也就是《Python100 天从新手到大师》。教程难度低，规划了 100 天的学习路径，从基础语法到 Web 开发、数据分析等领域逐步深入，前 15 天的内容还配有视频讲解，零基础也能轻松跟上，非常适合系统学习。
1. `learn - python`（`https://github.com/trekhleb/learn - python`）：以代码 + 注释的形式讲解 Python 所有基础语法，每个知识点都搭配实战代码示例，既是入门教程，也可作为后续回顾知识点的速查表，适合喜欢通过代码实例理解知识的学习者。
1. `practical - python`（`https://github.com/dabeaz - course/practical - python`）：由《Python Cookbook》作者编写的入门教程，经过实际教学验证。教程包含课后练习，内容贴近实战，能帮助学习者快速掌握实用的 Python 编程技能。

## 中文友好型入门网站

1. 菜鸟教程（Python 板块）（`https://www.runoob.com/python3/python3 - tutorial.html`）：中文界面无语言障碍，内容从 Python 环境搭建到语法、函数、模块等基础知识点，讲解细致且每个知识点都配有在线可运行的实例，随时可以动手测试，适合零基础且英语薄弱的初学者。
1. 廖雪峰的 Python 教程（`https://www.liaoxuefeng.com/wiki/1016959663602400`）：国内非常受欢迎的 Python 入门教程，结构清晰，语言通俗。从变量、数据类型等基础内容，逐步过渡到面向对象、错误处理等进阶知识，还包含常用模块的讲解，适合系统性梳理知识。

## 权威官方及交互式学习平台

1. Python 官网教程（`https://www.python.org/about/gettingstarted/`）：最权威的学习资源，内容涵盖 Python 安装、基础语法到高级特性，始终保持与最新版本同步。适合追求权威内容，想了解 Python 原生特性的学习者。
1. Codecademy（Python 板块）（`https://www.codecademy.com/learn/learn - python - 3`）：无需配置本地环境，直接在浏览器中编写和运行 Python 代码，且能即时获得反馈。课程以交互式练习为主，边学边练，能快速提升实操能力，适合喜欢动手实践的初学者。
1. Coursera《Python for Everybody》：由密歇根大学教授讲授的免费课程，课程体系完整，从零基础讲起，兼顾理论与实践，还会通过实际项目帮助学习者巩固知识，适合喜欢系统化、课堂式学习的人群。
