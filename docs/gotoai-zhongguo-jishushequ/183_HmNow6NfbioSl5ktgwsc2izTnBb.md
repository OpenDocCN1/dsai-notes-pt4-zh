# **经典免费开源教材**

1.  《Pro Git》（第二版、第三版）：Git 领域的权威圣经，作者是 Git 社区核心成员 Scott Chacon 等，内容从基础安装、本地版本控制，到远程仓库协作、分支管理、冲突解决等均有详细讲解，还涵盖 Git 底层原理。支持在线免费阅读，也可下载 PDF、epub 等格式，适配不同学习场景，入门到进阶都能使用，官网地址：https://git-scm.com/book/zh/v2。

1.  《G[it: The Simple Guide](https://rogerdudler.github.io/git-guide/)》：如其名，是极简风格的入门教材。摒弃复杂理论，直奔核心操作，用简洁的文字和步骤讲解仓库创建、提交、分支等基础功能，搭配少量必要命令示例，适合想快速掌握 Git 基本用法、不想纠结底层原理的初学者，在线阅读地址：https://rogerdudler.github.io/git-guide/。

1.  **《Git Immersion》**：以实践为核心的开源教程，通过一系列逐步递进的实操练习帮助学习者理解 Git 操作。每个知识点都配套对应的命令实操，比如从初始化仓库到分支合并，一步步引导动手操作，能加深对 Git 功能的理解，适合喜欢通过实践巩固知识的用户，地址：https://gitimmersion.com/。

# **GitHub 开源实战教程**

1.  git - crash - course（https://github.com/Git - Training/git - crash - course）：专为新手设计的快速入门项目，内容聚焦 Git 核心命令和基础流程。以 “教程 + 代码示例” 的形式，讲解版本提交、回退、远程仓库关联等入门必备技能，还附带常见问题排查，适合快速熟悉 Git 基础操作。

1.  git - simple - guide（https://github.com/jaywcjlove/git - simple - guide）：中文精简版 Git 教程，星标量较高。整理了 Git 最常用的命令，每个命令都配有中文说明和使用场景，比如不同场景下的git add用法、分支创建与合并命令等，可作为入门速查手册，也适合快速上手实操。

1.  learn - git - branch（https://github.com/pcottle/learn - git - branch）：主打分支管理学习的开源项目。通过可视化的交互界面，模拟 Git 分支的创建、合并、冲突解决等操作，能直观理解分支的核心概念，解决新手对分支操作的困惑，搭配实例代码，边练边学更高效。

# **中文友好型入门网站**

1.  **菜鸟教程 Git 板块**（https://www.runoob.com/git/git - tutorial.html）：零基础友好的中文教程，从 Git 安装配置开始，逐步讲解版本库、提交修改、分支管理等基础内容。每个知识点都配有可直接参考的命令示例，比如本地仓库创建、远程仓库克隆等操作步骤清晰，还标注了常见错误及解决办法，适合英语薄弱的初学者。

1.  **廖雪峰的 Git 教程**（[https://www.liaoxuefeng.com/](https://www.liaoxuefeng.com/wiki/896043488029600)wiki/896043488029600）：国内超热门的 Git 入门教程。用通俗的语言拆解 Git 核心概念，比如工作区、暂存区的区别，通过 “创建文件→提交→修改→回退” 的连贯案例，让新手快速理解 Git 工作流程，后期还涉及 GitHub 协作，衔接实战场景。

1.  **Git 官方中文文档**（https://git - [scm.com/docs](https://scm.com/docs)）：权威且全面的中文参考资料。涵盖所有 Git 命令的详细用法，包括参数说明、示例代码等。虽然偏文档属性，但入门阶段可用于查阅特定命令（如git commit git merge）的细节，适合学习中遇到命令疑问时精准查询。

# **交互式实操平台**

1.  Learn Git Branching（https://learngitbranching.js.org/）：可视化交互式学习平台，无需本地安装 Git。通过游戏化的关卡设计，从基础的提交、分支创建，到复杂的分支合并、变基等操作，都能在网页上实时操作并查看效果，直观理解 Git 的版本变化，攻克分支操作的学习难点。

1.  **Try Git**（https://try.github.io/）：浏览器端的交互式教程，包含 25 个入门挑战。引导学习者在网页终端中输入 Git 命令，完成仓库创建、文件提交、远程同步等任务，每个步骤都有提示，操作错误时会给出纠正建议，适合零基础用户快速熟悉 Git 命令的实际使用。

1.  GitHub Learning Lab（https://lab.github.com/）：GitHub 官方推出的免费交互式课程，包含 Git 与 GitHub 协作的入门内容。通过完成实际任务，比如创建仓库、提交修改、发起 Pull Request 等，掌握 Git 在团队协作中的应用，适合想衔接 GitHub 实战的学习者。
