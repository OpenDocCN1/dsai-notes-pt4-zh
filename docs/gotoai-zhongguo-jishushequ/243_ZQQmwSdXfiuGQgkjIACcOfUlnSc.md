## JetBrains 全家桶

系列产品专注于不同语言，功能强大，智能化程度高：

- `IntelliJ IDEA`：主打 Java 开发，也支持 Python、Kotlin 等，社区版免费，旗舰版付费。
- `PyCharm`：Python 专用，社区版免费，专业版支持 Web 开发等高级功能。
- `WebStorm`：前端开发神器（HTML/CSS/JavaScript/TypeScript 等）。
- `PhpStorm`：PHP 开发工具。
- `GoLand`：Go 语言专用。
- `RubyMine`：Ruby 开发。
- `CLion`：C/C++ 开发。
