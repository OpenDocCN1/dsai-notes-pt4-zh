+   为何Transformer成为大模型“标配”？：从GPT-1到GPT-4、LLaMA、文心一言的技术传承

# 第二部分：Transformer核心架构与数学原理

### 第1章：Transformer整体架构解析

+   经典结构总览：编码器（Encoder）+解码器（Decoder）的“编-解”框架

+   输入与输出流程：

+   文本→Token化→嵌入（Embedding）→位置编码（Positional Encoding）→编码器→解码器→输出序列

+   各模块协同逻辑：编码器捕获全局依赖，解码器实现生成式建模（以机器翻译为例）

### 第2章：核心组件1：自注意力机制（Self-Attention）

+   注意力的本质：“动态加权求和”——让模型学会“关注输入中重要的词”

+   数学原理详解：

+   三步计算：Query（查询）、Key（键）、Value（值）的矩阵生成

+   注意力分数：通过点积计算相似度（score = Q·K^T / √d_k）

+   权重归一化：Softmax函数的作用（将分数转化为0-1的权重）

+   输出计算：Attention(Q,K,V) = Softmax(score)·V

+   直观理解：用“机器翻译”案例可视化注意力权重（如“猫”一词如何关注“吃鱼”）

### 第3章：核心组件2：多头注意力（Multi-Head Attention）

+   多头注意力的设计逻辑：“并行学习不同类型的注意力模式”

+   计算流程：

+   投影拆分：将Q/K/V通过不同线性层拆分为h个“头”（如h=8）

+   多头并行计算：每个头独立计算注意力

+   拼接输出：将h个结果拼接并通过线性层整合

+   优势：捕捉多维度依赖（如语法依赖、语义关联、长距离指代）

### 第4章：核心组件3：位置编码（Positional Encoding）

+   为何需要位置编码？：Transformer无递归结构，需显式注入位置信息

+   经典实现：正弦余弦编码（Sinusoidal Encoding）

+   公式解析：PE(pos, 2i) = sin(pos / 10000^(2i/d_model))

+   原理：通过不同频率的正弦/余弦函数区分位置，确保相对位置可计算

+   现代改进：可学习位置编码（GPT系列）、旋转位置编码（RoPE，LLaMA/讯飞星火）

### 第5章：编码器与解码器细节

+   编码器（Encoder）：

+   结构：多头自注意力（无掩码）+前馈神经网络（FFN）+残差连接+层归一化

+   功能：将输入序列编码为“富含上下文的向量表示”（如“猫吃鱼”→编码为包含“猫是主体，鱼是对象”的向量）

+   解码器（Decoder）：

+   结构：掩码多头自注意力（防止关注未来Token）+编码器-解码器注意力+FFN

+   功能：基于编码器输出生成目标序列（如翻译时“逐个生成目标语言的词”）

+   前馈神经网络（FFN）：简单的两层线性变换+ReLU激活，作用是“增强非线性表达能力”

# 第三部分：Transformer与大语言模型（LLM）的演进

### 第1章：从Transformer到GPT：解码器的胜利

+   GPT架构的简化：仅保留Transformer解码器，移除编码器

+   因果掩码（Causal Mask）：确保生成时“只能看到前面的词”（避免未来信息泄露）

+   预训练+微调范式：

+   预训练：在海量文本上做“下一个词预测”（语言建模任务）

+   微调：针对具体任务（如分类、问答）调整模型参数

+   案例：GPT-2到GPT-4的架构变化（层数从12→96，隐藏维度从768→12288）

### 第2章：其他Transformer变体与大模型

+   BERT与编码器：双向注意力的优势与局限（适合理解任务，不适合生成）

+   T5：“文本到文本”的统一框架（所有任务转化为序列生成，编码器+解码器全保留）

+   国产大模型的创新：如文心一言的“ERNIE增强”（知识图谱融合Transformer）、讯飞星火的“动态注意力”

### 第3章：注意力机制的优化与挑战

+   长上下文困境：Transformer的O(n²)复杂度（n为序列长度）导致长文本计算成本激增

+   优化方案：

+   稀疏注意力：仅关注部分Token（如Longformer的滑动窗口注意力）

+   近似注意力：用低秩矩阵近似QK^T（如FlashAttention的IO优化）

+   分段注意力：将长文本拆分为块，块内全注意力+块间稀疏注意力（GPT-4的处理方式）
