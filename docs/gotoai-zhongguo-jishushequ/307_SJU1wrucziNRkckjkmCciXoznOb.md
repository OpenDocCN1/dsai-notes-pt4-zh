### DeepLearning.AI Short Courses

A collection of free, concise courses from Andrew Ng's team and industry experts (OpenAI, LangChain, etc.), focused on quickly mastering a specific skill.

+   Generative AI for Everyone - A non-technical introduction to Generative AI, its potential, and its value proposition.

+   [ChatGPT Prompt Engine](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/)ering for Developers - Learn prompt engineering best practices for application development.

+   [LangChain for LLM App](https://www.deeplearning.ai/short-courses/langchain-for-llm-application-development/)lication Development - Learn the fundamentals of the LangChain framework to build powerful applications.

+   LangChain: Chat with Your Data - Focused on building Retrieval-Augmented Generation (RAG) applications with LangChain.

+   [Building Systems ](https://www.deeplearning.ai/short-courses/building-systems-with-chatgpt/)with the ChatGPT API - Learn how to chain multiple prompts together to build complex systems.

+   Finetuning Large Language Models - Learn when to apply finetuning and how to do it effectively.

+   How Diffusion Models Work - A deep dive into the principles behind text-to-image models like Stable Diffusion.

+   [Vector Databases: from Embedd](https://www.deeplearning.ai/short-courses/vector-databases-embeddings-applications/)ings to Applications - Learn the core concepts of vector databases and their application in semantic search and RAG.
