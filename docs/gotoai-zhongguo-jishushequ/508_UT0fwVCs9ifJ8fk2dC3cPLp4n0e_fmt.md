## 八、部门清单使用建议（OpenClaw 场景分析专用）

1. 按 “部门→核心职责→高频重复工作→OpenClaw 可替代场景” 展开分析

2. **优先覆盖**：

   - 人力、财务、行政、法务、客服、销售、市场、运营、采购、质量
   - 这些部门文案、报表、台账、合同、通知、总结、数据统计最多

3. 可按企业规模（小 / 中 / 大 / 集团）、行业（制造 / 互联网 / 金融 / 服务）增删部门
