
# 董事会办公室/董秘办 OpenClaw 应用场景及对应Skills分析报告

> 来源：[https://gotoaiworld.feishu.cn/docx/HI2bdMdiooSuJ1xOWrlcYVaonMd](https://gotoaiworld.feishu.cn/docx/HI2bdMdiooSuJ1xOWrlcYVaonMd)

## 一、部门核心定位

董事会办公室/董秘办（简称“董秘办”）是企业董事会的常设办事机构，核心承担董事会事务管理、信息披露、投资者关系管理、合规管控、治理体系建设等职能，直接服务于董事会、监事会及管理层。该部门工作兼具高度专业性、严格合规性与严谨性，核心特点是“合规要求高、文书规范严、事务流程细、对外对接多”，主要负责董事会相关会议组织、信息披露文件起草、投资者沟通、公司治理规范等工作，是保障企业规范治理、信息透明、合规运营的核心部门，也是OpenClaw落地适配的重点合规类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按董秘办日常工作高频度、刚需度排序，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均严格遵循监管要求与企业治理规范，无需额外定制开发，零基础可快速落地，同时兼顾合规性与高效性。

### （一）董事会会议管理类（核心职能场景）

**场景核心内容**：董秘办作为董事会会议的组织统筹部门，全程负责会议筹备、材料准备、纪要撰写、决议跟进等工作，流程规范、要求严谨，具体包括：

+ 董事会、监事会、股东大会的会议通知、议程、议案材料起草与分发；

+ 会议签到、会议记录、会议纪要的撰写、审核与归档，确保纪要真实、完整、规范；

+ 会议决议梳理、行动项分解、落实跟踪与进度反馈，形成闭环管理；

+ 会议资料汇编、归档，配合监管部门检查与内部审计，确保会议流程可追溯。

**应用价值**：规范会议组织流程，简化会议材料准备与纪要撰写工作量，确保会议文件符合监管要求与公司治理规范，提升会议效率与决议落地成效，减少人工整理与归档耗时。

对应OpenClaw Skills：

+ `board-meeting-minutes`（董事会、监事会、股东大会会议纪要撰写）；

+ `meeting-plan`（会议通知、议程、议案材料起草）；

+ `action-item`（会议决议行动项分解、跟踪台账生成）；

+ `document-archive`（会议资料汇编、归档目录生成）。

### （二）信息披露类（合规核心场景）

**场景核心内容**：信息披露是董秘办的核心合规职责，需严格按照监管要求，及时、准确、完整地披露企业重大信息，撰写各类披露文件，具体包括：

+ 定期报告（年度报告、半年度报告、季度报告）的初稿起草、数据汇总、内容梳理；

+ 临时报告（重大事项公告、关联交易公告、资产重组公告、权益变动公告等）撰写；

+ 信息披露核查清单、披露流程说明、披露文件审核辅助材料整理；

+ 披露文件归档、监管报送、信息披露台账建立与更新。

**应用价值**：规范信息披露文件格式与内容，简化报告起草与数据汇总流程，降低披露失误风险，确保信息披露符合监管规定，提升披露效率与准确性。

对应OpenClaw Skills：

+ `disclosure-report`（定期报告、临时报告起草）；

+ `data-stat`（披露数据汇总、核对与整理）；

+ `compliance-check`（信息披露合规核查清单生成）；

+ `ledger-manage`（信息披露台账建立与更新）。

### （三）投资者关系管理类（对外对接场景）

**场景核心内容**：负责企业与投资者、分析师、监管机构的沟通对接，维护良好的投资者关系，传递企业经营信息，具体包括：

+ 投资者沟通话术、回复口径、问询函回复材料撰写；

+ 投资者调研活动方案、接待流程、调研纪要撰写；

+ 投资者关系活动记录、投资者反馈梳理、沟通总结报告；

+ 投资者关系手册、宣传材料、经营亮点解读文案整理。

**应用价值**：标准化投资者沟通流程与话术，快速生成各类沟通与接待材料，提升投资者沟通效率与专业度，维护企业良好的投资者形象。

对应OpenClaw Skills：

+ `investor-communication`（投资者沟通话术、问询函回复撰写）；

+ `reception-plan`（投资者调研接待方案、流程安排）；

+ `meeting-minutes`（投资者调研纪要撰写）；

+ `promotion-copy`（投资者关系宣传材料、亮点解读撰写）。

### （四）公司治理与合规类（基础保障场景）

**场景核心内容**：统筹企业公司治理体系建设，确保企业治理符合监管要求与公司章程，具体包括：

+ 公司章程、董事会议事规则、监事会议事规则等治理文件的初稿起草与修订；

+ 公司治理自查报告、合规检查报告、治理专项整改报告撰写；

+ 董事、监事履职台账建立、履职报告起草、履职评价材料整理；

+ 监管政策解读、治理规范培训材料、合规提示文案生成。

**应用价值**：规范公司治理文件起草流程，简化合规自查与整改材料准备工作，助力企业完善治理体系，确保合规运营，规避治理风险。

对应OpenClaw Skills：

+ `governance-draft`（公司章程、议事规则等治理文件起草）；

+ `compliance-report`（治理自查报告、合规检查报告撰写）；

+ `performance-report`（董事、监事履职报告起草）；

+ `training-material`（治理规范培训材料、合规提示文案生成）。

### （五）关联交易与重大事项管理类（风险管控场景）

**场景核心内容**：负责企业关联交易、重大投融资、资产重组等重大事项的统筹协调与材料准备，确保流程合规、信息透明，具体包括：

+ 关联交易协议初稿、关联交易公告、关联方清单梳理与更新；

+ 重大事项可行性研究报告初稿、决策议案、审批材料起草；

+ 重大事项进展跟踪、进度汇报、相关文件归档；

+ 关联交易台账、重大事项台账建立与动态更新。

**应用价值**：规范重大事项与关联交易的材料准备流程，简化台账管理与进度跟踪工作，确保重大事项决策合规、流程可追溯，规避关联交易风险。

对应OpenClaw Skills：

+ `related-transaction`（关联交易协议、公告起草）；

+ `project-report`（重大事项可行性研究报告、议案起草）；

+ `progress-report`（重大事项进展汇报、简报撰写）；

+ `ledger-manage`（关联交易、重大事项台账管理）。

### （六）监管对接与材料报送类（合规刚需场景）

**场景核心内容**：负责与证券监管机构、交易所、行业主管部门的对接，及时报送各类监管材料，配合监管检查，具体包括：

+ 监管问询函、核查函的回复材料起草与整理；

+ 监管要求的各类报表、报告、备案材料的撰写与报送；

+ 监管检查配合材料、整改方案、整改报告撰写；

+ 监管政策收集、解读、内部传达材料整理。

**应用价值**：快速响应监管要求，规范监管材料撰写与报送流程，提升对接效率，确保监管材料符合要求，配合监管检查顺利推进。

对应OpenClaw Skills：

+ `regulatory-response`（监管问询函、核查函回复撰写）；

+ `report-draft`（监管报表、备案材料起草）；

+ `rectify-report`（监管整改方案、整改报告撰写）；

+ `policy-analyze`（监管政策收集、解读材料整理）。

### （七）文书与档案管理类（基础支撑场景）

**场景核心内容**：负责董秘办各类文书、文件的起草、整理、归档与管理，确保文件规范、可追溯，具体包括：

+ 董事会相关公文、函件、通知、请示、报告的起草与规范；

+ 各类治理文件、会议材料、披露文件、监管材料的归档与检索；

+ 董秘办工作台账、工作总结、工作计划撰写；

+ 文件借阅登记、档案保管、到期文件清理等日常管理工作。

**应用价值**：实现文书撰写与档案管理规范化、高效化，减少人工整理与归档耗时，确保各类文件可追溯、可查询，提升部门日常工作效率。

对应OpenClaw Skills：

+ `official-doc`（董事会相关公文、函件起草）；

+ `document-archive`（各类文件归档、检索目录生成）；

+ `work-summary`（董秘办工作总结、工作计划撰写）；

+ `ledger-manage`（文书借阅、档案管理台账生成）。
