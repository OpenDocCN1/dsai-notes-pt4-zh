
# 战略规划部/企业发展部 OpenClaw 应用场景及对应Skills分析报告

> 来源：[https://gotoaiworld.feishu.cn/docx/OOsJdEvmpogiuKxnQ4CcRA2Xn3V](https://gotoaiworld.feishu.cn/docx/OOsJdEvmpogiuKxnQ4CcRA2Xn3V)

## 一、部门核心定位

战略规划部/企业发展部（简称“战略部”）是企业战略制定、发展统筹、布局落地的核心职能部门，直接服务于企业高层决策，承担着战略研究、规划编制、布局统筹、发展研判、项目推进、绩效跟踪等核心职能。该部门工作兼具前瞻性、系统性与专业性，核心特点是“分析多、报告多、规划多、研判多”，主要负责企业中长期战略规划、年度经营计划、产业布局、市场研判、重大项目统筹等工作，是推动企业高质量发展、实现战略落地、规避发展风险的核心支撑部门，也是OpenClaw落地适配的重点分析研判类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按战略规划部/企业发展部日常工作高频度、刚需度排序，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合部门战略研判与规划落地需求，无需额外定制开发，零基础可快速落地，兼顾专业性与高效性。

### （一）战略规划编制类（核心职能场景）

**场景核心内容**：作为企业战略制定的核心部门，负责统筹企业中长期战略规划、年度经营计划的编制、修订与完善，确保规划贴合企业发展实际、适配行业趋势，具体包括：

+   企业中长期（3-5年）战略规划、发展纲要的初稿起草、框架搭建与内容完善；
+   年度经营计划、季度战略落地计划的编制、分解与优化，明确核心目标与实施路径；
+   战略规划编制说明、实施细则、目标分解方案的撰写；
+   战略规划修订报告、调整方案的起草，结合行业变化与企业经营实际优化战略布局。

**应用价值**：简化战略规划框架搭建与内容撰写流程，提升规划编制效率，确保规划逻辑严谨、内容贴合企业实际与行业趋势，为战略落地奠定基础，减少人工梳理与修改耗时。

对应OpenClaw Skills：

+   `strategy-plan`（中长期战略规划、发展纲要起草）；
+   `business-plan`（年度经营计划、季度落地计划编制）；
+   `plan-explain`（战略规划编制说明、实施细则撰写）；
+   `plan-adjust`（战略规划修订报告、调整方案起草）。

### （二）行业与市场研判类（核心支撑场景）

**场景核心内容**：负责跟踪行业发展趋势、市场动态、竞品情况，开展研判分析，为企业战略决策提供数据与依据，具体包括：

+   行业发展趋势、政策导向、技术变革的调研与分析报告撰写；
+   竞品分析报告、市场格局研判、竞争对手优劣势梳理；
+   市场需求分析、消费趋势研判、市场机会与风险识别报告；
+   行业数据汇总、研判摘要、决策参考材料整理与提交。

**应用价值**：简化调研数据整理与分析流程，快速生成规范的研判报告，帮助高层精准把握行业趋势、识别市场机会与风险，提升决策的科学性与前瞻性。

对应OpenClaw Skills：

+   `industry-analyze`（行业趋势、政策导向分析报告撰写）；
+   `competitor-analyze`（竞品分析、市场格局研判报告撰写）；
+   `market-analyze`（市场需求、消费趋势分析报告撰写）；
+   `data-extract`（行业数据汇总、研判摘要提炼）。

### （三）重大项目统筹类（落地执行场景）

**场景核心内容**：负责企业重大战略项目、产业布局项目、投融资项目的统筹协调、进度跟踪与落地推进，具体包括：

+   重大项目可行性研究报告、项目建议书、立项报告的初稿起草；
+   项目进度跟踪、节点管控、推进台账建立与更新；
+   项目推进简报、阶段性总结、问题整改报告撰写；
+   跨部门项目协同协调、资源调配辅助，确保项目按计划落地。

**应用价值**：规范重大项目材料起草流程，实现项目进度跟踪数字化、规范化，提升项目推进效率，及时梳理项目问题并推动整改，确保战略项目落地见效。

对应OpenClaw Skills：

+   `project-report`（项目可行性研究报告、立项报告起草）；
+   `project-track`（重大项目进度跟踪、推进台账生成）；
+   `progress-report`（项目推进简报、阶段性总结撰写）；
+   `coordination-document`（跨部门项目协同协调材料撰写）。

### （四）战略落地与绩效跟踪类（闭环管理场景）

**场景核心内容**：负责战略规划与年度经营计划的落地跟踪、绩效管控，确保战略目标分解到位、执行到位，具体包括：

+   战略目标分解、责任分工、执行细则的撰写与完善；
+   战略落地进度跟踪、绩效指标统计、执行情况分析报告；
+   战略落地过程中问题梳理、整改方案、优化建议撰写；
+   年度/季度战略落地总结、绩效评估报告撰写。

**应用价值**：实现战略落地跟踪与绩效管控规范化、高效化，简化指标统计与分析流程，及时发现并解决战略落地中的问题，确保战略目标达成。

对应OpenClaw Skills：

+   `strategy-implement`（战略目标分解、执行细则撰写）；
+   `performance-stat`（战略绩效指标统计、执行情况分析）；
+   `rectify-report`（战略落地问题整改方案、优化建议撰写）；
+   `summary-report`（战略落地总结、绩效评估报告撰写）。

### （五）企业发展研判与风险管控类（前瞻防控场景）

**场景核心内容**：负责研判企业发展态势，识别发展风险，提出防控建议，保障企业可持续发展，具体包括：

+   企业发展态势分析、经营状况研判、发展瓶颈识别报告撰写；
+   战略风险、市场风险、产业风险等各类风险排查与评估报告；
+   风险防控方案、应对措施、预警机制文案撰写；
+   企业发展优化建议、转型升级方案起草。

**应用价值**：简化发展研判与风险排查流程，快速生成风险评估与防控报告，帮助企业提前识别发展风险、制定应对措施，规避发展瓶颈，推动企业转型升级。

对应OpenClaw Skills：

+   `development-analyze`（企业发展态势、经营状况研判报告撰写）；
+   `risk-assess`（各类发展风险排查、评估报告撰写）；
+   `risk-control`（风险防控方案、应对措施撰写）；
+   `optimize-plan`（企业发展优化建议、转型升级方案起草）。

### （六）政策研究与解读类（支撑决策场景）

**场景核心内容**：负责收集、整理、解读国家及地方相关产业政策、行业法规，为企业战略制定与经营决策提供政策支撑，具体包括：

+   国家及地方产业政策、税收政策、扶持政策的收集与整理；
+   政策解读报告、政策适配分析、政策利用建议撰写；
+   政策落地可行性分析、政策红利挖掘、政策申报辅助材料整理；
+   政策变化预警、政策调整对企业影响的研判报告。

**应用价值**：简化政策收集与解读流程，快速生成政策分析报告，帮助企业精准把握政策导向、挖掘政策红利，规避政策风险，确保战略规划与政策导向同频。

对应OpenClaw Skills：

+   `policy-collect`（产业政策、行业法规收集与整理）；
+   `policy-analyze`（政策解读、政策适配分析报告撰写）；
+   `policy-utilize`（政策利用建议、政策申报辅助材料撰写）；
+   `policy-warning`（政策变化预警、影响研判报告撰写）。

### （七）文书与报告管理类（基础支撑场景）

**场景核心内容**：负责部门各类文书、报告、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+   部门工作汇报、工作总结、工作计划的撰写与规范；
+   战略研究报告、研判材料、项目材料的归档与检索；
+   部门内部通知、会议纪要、工作简报的起草与分发；
+   各类战略台账、项目台账、政策台账的建立与更新。

**应用价值**：实现文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类报告、台账可追溯、可查询，提升部门日常工作效率。

对应OpenClaw Skills：

+   `work-summary`（部门工作总结、工作计划、工作汇报撰写）；
+   `document-archive`（战略研究、项目材料归档与检索目录生成）；
+   `meeting-minutes`（部门会议纪要、工作简报起草）；
+   `ledger-manage`（战略、项目、政策相关台账建立与更新）。

## 四、应用价值总结

OpenClaw可全面替代战略规划部/企业发展部战略规划编制、行业研判、项目统筹、战略落地跟踪、政策解读等高频重复性、事务性工作，兼顾专业性与前瞻性，实现战略规划规范化、研判分析高效化、项目推进精细化、政策利用精准化，有效解决部门“分析工作量大、报告撰写繁琐、台账管理复杂”的痛点，帮助部门工作人员从繁琐的事务性工作中解放出来，聚焦战略研判、布局优化、重大项目落地等高价值核心工作，预计可提升部门整体工作效率60%–75%，为企业战略决策与高质量发展提供有力支撑。
