
# 投资部/投融资部 `OpenClaw` 应用场景及对应Skills分析报告

> 来源：[https://gotoaiworld.feishu.cn/docx/DO6odooX1oEtiGxg4K7cY5GIn2b](https://gotoaiworld.feishu.cn/docx/DO6odooX1oEtiGxg4K7cY5GIn2b)

## 一、部门核心定位

投资部/投融资部是企业统筹投资、融资及资本运作的核心职能部门，直接服务于企业高层决策，承担着项目挖掘、尽职调查、投融方案制定、风险评估、投后管理、资本运作等核心职能。该部门工作兼具高度专业性、风险导向性与价值导向性，核心特点是“调研多、报告多、方案多、风控严”，主要负责企业对外投资、对内投融资、项目尽调、投融决策支撑、投后赋能及资本运作等工作，是实现企业资产增值、优化资本结构、拓展发展空间的核心支撑部门，也是`OpenClaw`落地适配的重点专业类部门。

## 二、核心应用场景及对应`OpenClaw` Skills

本章节按投资部/投融资部日常工作高频度、刚需度排序，明确各场景核心工作内容、应用价值及对应`OpenClaw` Skills，所有Skills均贴合部门投融专业需求与风险管控要求，无需额外定制开发，零基础可快速落地，兼顾专业性、合规性与高效性。

### （一）项目挖掘与尽职调查类（核心职能场景）

**场景核心内容**：作为企业投资项目的源头把控部门，负责挖掘优质投资项目、开展全面尽职调查，为投融决策提供核心依据，具体包括：

+ 优质投资项目挖掘、项目信息收集、项目初步筛选与评估；

+ 尽职调查报告（财务尽调、法律尽调、业务尽调）的初稿起草、数据汇总与内容梳理；

+ 尽调底稿整理、尽调问题梳理、风险点识别与说明；

+ 项目可行性初步分析、项目适配性评估报告撰写。

**应用价值**：简化项目筛选与尽调材料撰写流程，提升尽调效率，规范尽调报告格式，精准梳理尽调风险点，为投融决策提供全面、规范的支撑，减少人工数据汇总与报告修改耗时。

对应`OpenClaw` Skills：

+ `project-dig`（优质投资项目挖掘、信息整理与初步评估）；

+ `due-diligence`（尽职调查报告、尽调底稿撰写与整理）；

+ `project-feasibility`（项目可行性初步分析、适配性评估报告）；

+ `risk-identify`（尽调风险点识别、风险说明撰写）。

### （二）投融方案制定类（核心执行场景）

**场景核心内容**：负责结合企业发展战略与项目实际，制定科学合理的投资、融资方案，明确投融规模、方式、流程与风控措施，具体包括：

+ 投资方案、融资方案、资本运作方案的初稿起草、框架搭建与内容优化；

+ 投融额度测算、成本分析、收益预测、还款计划（融资）撰写；

+ 投融方案实施细则、流程安排、责任分工的撰写；

+ 方案对比分析、优化建议、备选方案的起草与梳理。

**应用价值**：简化投融方案框架搭建与内容撰写流程，提升方案制定效率，确保方案逻辑严谨、数据准确、贴合企业实际，为投融方案落地提供清晰指引，降低方案制定的专业门槛。

对应`OpenClaw` Skills：

+ `investment-plan`（投资方案、资本运作方案起草）；

+ `financing-plan`（融资方案、还款计划撰写）；

+ `cost-benefit`（投融成本分析、收益预测撰写）；

+ `plan-compare`（投融方案对比分析、备选方案起草）。

### （三）风险评估与管控类（核心保障场景）

**场景核心内容**：投融工作风险管控的核心部门，负责对投融项目、方案进行全面风险评估，制定防控措施，规避投融风险，具体包括：

+ 投融项目风险评估报告、风险等级划分、风险影响分析撰写；

+ 财务风险、市场风险、法律风险、政策风险等各类风险排查与防控方案制定；

+ 风险预警机制、应急处置方案、风险跟踪台账建立与更新；

+ 投融风险复盘、风险整改报告、优化建议撰写。

**应用价值**：规范风险评估流程，简化风险排查与防控方案撰写工作，精准识别投融风险点，建立完善的风险管控体系，降低投融风险，保障企业资产安全。

对应`OpenClaw` Skills：

+ `risk-evaluate`（投融项目风险评估报告、风险等级划分撰写）；

+ `risk-prevent`（各类投融风险防控方案、应急处置方案制定）；

+ `risk-track`（风险跟踪台账建立、风险预警文案撰写）；

+ `risk-review`（风险复盘、整改报告、优化建议撰写）。

### （四）投后管理类（闭环运营场景）

**场景核心内容**：负责已投项目的后续跟踪、赋能与退出管理，确保投资价值实现，具体包括：

+ 已投项目进度跟踪、经营状况监测、财务数据汇总与分析；

+ 投后管理报告、季度/年度投后复盘报告、项目增值赋能方案撰写；

+ 项目退出方案、退出时机研判、退出流程梳理与材料准备；

+ 投后风险跟踪、问题整改、优化建议的提出与落实。

**应用价值**：实现投后管理规范化、数字化，简化投后跟踪与报告撰写流程，及时掌握项目经营状况，推动项目增值，确保投资退出有序推进，最大化投资回报。

对应`OpenClaw` Skills：

+ `post-investment`（投后管理报告、投后复盘报告撰写）；

+ `project-monitor`（已投项目进度、经营状况监测与分析）；

+ `exit-plan`（项目退出方案、退出流程材料起草）；

+ `value-enhancement`（项目增值赋能方案、优化建议撰写）。

### （五）融资对接与资本运作类（对外协同场景）

**场景核心内容**：负责对接金融机构、投资人、中介机构，推进融资工作落地与资本运作，具体包括：

+ 融资对接函、推介材料、商业计划书（融资版）的起草与优化；

+ 与金融机构、投资人的沟通话术、回复口径、问询回复材料撰写；

+ 资本运作（并购、重组、上市辅助）相关材料、议案的起草；

+ 融资进度跟踪、对接纪要、融资总结报告撰写。

**应用价值**：标准化融资对接流程与材料，快速生成各类推介与沟通材料，提升融资对接效率与专业度，推动融资工作与资本运作顺利落地。

对应`OpenClaw` Skills：

+ `financing-connect`（融资对接函、推介材料、商业计划书起草）；

+ `investor-communication`（与投资人、金融机构沟通话术、问询回复撰写）；

+ `capital-operation`（并购、重组等资本运作材料、议案起草）；

+ `progress-report`（融资进度跟踪、对接纪要、总结报告撰写）。

### （六）数据统计与报告类（支撑决策场景）

**场景核心内容**：负责投融数据统计、分析，撰写各类投融报告，为高层决策提供数据支撑，具体包括：

+ 投融项目数据、财务数据、收益数据、风险数据的汇总与统计；

+ 月度/季度/年度投融工作报告、数据分析报告撰写；

+ 投融指标完成情况分析、差距总结、优化建议撰写；

+ 投融数据台账、报表的建立与更新，数据解读材料整理。

**应用价值**：实现投融数据统计自动化、规范化，简化报告撰写与数据解读流程，确保数据准确、报告规范，为高层投融决策提供直观、全面的数据支撑。

对应`OpenClaw` Skills：

+ `data-stat`（投融数据、财务数据汇总与统计）；

+ `investment-report`（投融工作报告、数据分析报告撰写）；

+ `indicator-analysis`（投融指标完成情况分析、优化建议撰写）；

+ `ledger-manage`（投融数据台账、报表建立与更新）。

### （七）文书与档案管理类（基础支撑场景）

**场景核心内容**：负责部门各类投融文书、文件、档案的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+ 部门工作总结、工作计划、工作汇报的撰写与规范；

+ 投融项目材料、尽调报告、投融方案、合同协议的归档与检索；

+ 部门内部通知、会议纪要、工作简报的起草与分发；

+ 投融相关合同、协议初稿的辅助起草与规范。

**应用价值**：实现文书撰写与档案管理规范化、高效化，减少人工整理与归档耗时，确保各类投融文件、档案可追溯、可查询，提升部门日常工作效率，规避档案管理风险。

对应`OpenClaw` Skills：

+ `work-summary`（部门工作总结、工作计划、工作汇报撰写）；

+ `document-archive`（投融项目、方案、协议等材料归档与检索目录生成）；

+ `meeting-minutes`（部门会议纪要、工作简报起草）；

+ `contract-draft`（投融相关合同、协议初稿辅助起草）。

## 四、应用价值总结

`OpenClaw`可全面替代投资部/投融资部项目尽调、投融方案制定、风险评估、投后管理、融资对接、数据统计等高频重复性、事务性工作，严格贴合投融专业要求与风险管控标准，实现尽调规范化、方案精细化、风控常态化、数据高效化，有效解决部门“报告撰写繁琐、数据统计复杂、风险排查耗时”的痛点，帮助部门工作人员从繁琐的事务性工作中解放出来，聚焦项目挖掘、投融决策、风险管控、价值增值等高价值核心工作，预计可提升部门整体工作效率55%–70%，为企业投融工作有序推进、资产增值与高质量发展提供有力支撑。
