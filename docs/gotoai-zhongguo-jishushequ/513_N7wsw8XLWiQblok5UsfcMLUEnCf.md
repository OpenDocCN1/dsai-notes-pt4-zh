
# 审计部/内审部 `OpenClaw` 应用场景及对应Skills分析报告

> 来源：[https://gotoaiworld.feishu.cn/docx/BeKwdtJZ1oWfnaxjmA4cSvBgnlg](https://gotoaiworld.feishu.cn/docx/BeKwdtJZ1oWfnaxjmA4cSvBgnlg)

## 一、部门核心定位

审计部/内审部（简称“审计部”）是企业内部监督、风险防控、合规管控的核心职能部门，独立于各业务部门，直接向董事会、审计委员会或高层管理层负责，承担着内部审计、合规核查、风险监督、整改跟踪、内控评价等核心职能。该部门工作兼具高度严谨性、独立性与合规性，核心特点是“核查细、报告严、台账全、闭环强”，主要负责企业财务审计、运营审计、合规审计、内控审计、专项审计及整改跟踪等工作，是保障企业规范运营、防范经营风险、提升管理效能、维护资产安全的核心监督部门，也是`OpenClaw`落地适配的重点监督合规类部门。

## 二、核心应用场景及对应`OpenClaw` Skills

本章节按审计部/内审部日常工作高频度、刚需度排序，明确各场景核心工作内容、应用价值及对应`OpenClaw` Skills，所有Skills均严格遵循审计规范与合规要求，贴合部门监督核查需求，无需额外定制开发，零基础可快速落地，兼顾专业性、合规性与高效性。

### （一）各类审计报告撰写类（核心职能场景）

**场景核心内容**：作为审计工作的核心输出，负责各类审计报告的起草、编制与完善，确保报告真实、准确、规范，全面反映审计发现、问题及整改建议，具体包括：

+   财务审计报告、运营审计报告、合规审计报告、内控审计报告的初稿起草与内容优化；

+   专项审计报告（如资金审计、采购审计、项目审计、离任审计）的撰写与梳理；

+   审计发现问题汇总、原因分析、整改建议、责任认定相关内容撰写；

+   审计报告附件、佐证材料整理与说明，确保报告逻辑严谨、依据充分。

**应用价值**：简化审计报告框架搭建与内容撰写流程，规范报告格式与表述，提升报告撰写效率，确保审计报告贴合审计规范与企业管理要求，减少人工梳理与修改耗时，保障审计成果精准输出。

对应`OpenClaw` Skills：

+   `audit-report`（各类常规审计报告、专项审计报告起草）；

+   `audit-findings`（审计发现问题汇总、原因分析撰写）；

+   `rectify-suggest`（审计整改建议、责任认定相关内容撰写）；

+   `audit-attachment`（审计报告附件、佐证材料整理与说明）。

### （二）审计计划与方案制定类（核心执行场景）

**场景核心内容**：负责统筹审计工作规划，制定年度、季度审计计划及具体审计项目方案，明确审计范围、目标、流程与方法，具体包括：

+   年度审计计划、季度审计计划的编制、分解与优化，贴合企业战略与风险防控重点；

+   单个审计项目方案（审计范围、审计目标、审计流程、审计方法、时间安排）的起草；

+   审计计划实施细则、责任分工、审计标准的撰写与完善；

+   审计计划调整报告、方案优化建议的起草，结合审计实际情况动态调整。

**应用价值**：规范审计计划与方案制定流程，简化编制工作量，确保审计工作有序推进、重点突出，贴合企业风险防控需求，提升审计工作的计划性与针对性。

对应`OpenClaw` Skills：

+   `audit-plan`（年度、季度审计计划编制与分解）；

+   `audit-project-plan`（单个审计项目方案、实施细则起草）；

+   `plan-adjust`（审计计划调整报告、方案优化建议撰写）；

+   `audit-standard`（审计标准、责任分工撰写）。

### （三）审计核查与底稿管理类（基础核心场景）

**场景核心内容**：负责开展具体审计核查工作，整理审计底稿，确保审计过程可追溯、核查结果真实可靠，具体包括：

+   审计核查清单、核查记录表的起草与规范，明确核查要点与标准；

+   审计底稿整理、分类、归档，包括核查证据、访谈记录、凭证复印件等相关材料；

+   审计核查过程记录、工作小结、核查疑点梳理与说明；

+   审计底稿审核辅助材料、底稿检索目录的生成与完善。

**应用价值**：标准化审计核查流程与底稿管理规范，简化底稿整理与归档耗时，确保审计过程可追溯、核查证据齐全，提升审计核查的规范性与效率，规避审计风险。

对应`OpenClaw` Skills：

+   `audit-checklist`（审计核查清单、核查记录表起草）；

+   `audit-working-paper`（审计底稿整理、分类、归档）；

+   `audit-record`（审计核查过程记录、工作小结撰写）；

+   `document-archive`（审计底稿检索目录、审核辅助材料生成）。

### （四）整改跟踪与闭环管理类（核心保障场景）

**场景核心内容**：负责审计发现问题的整改跟踪、督促落实，建立整改闭环管理机制，确保问题整改到位，具体包括：

+   审计整改台账建立、更新，明确整改责任人、整改时限、整改措施；

+   整改过程跟踪、整改情况核查、整改成效评估报告撰写；

+   整改逾期预警、未整改问题督促、整改不力问责建议撰写；

+   整改总结报告、整改闭环说明、长效机制建议撰写。

**应用价值**：实现审计整改跟踪数字化、规范化，简化整改台账管理与报告撰写流程，确保审计发现问题闭环管理，推动企业完善管理、规避同类风险再次发生。

对应`OpenClaw` Skills：

+   `rectify-track`（审计整改台账建立、整改过程跟踪）；

+   `rectify-evaluate`（整改成效评估、整改核查报告撰写）；

+   `rectify-warning`（整改逾期预警、督促文案撰写）；

+   `rectify-summary`（整改总结报告、长效机制建议撰写）。

### （五）内控评价与风险排查类（风险防控场景）

**场景核心内容**：负责企业内部控制体系的评价与优化，开展常态化风险排查，防范经营风险，具体包括：

+   内部控制评价报告、内控流程优化建议的撰写；

+   企业经营风险、财务风险、合规风险、内控风险的常态化排查与评估；

+   风险排查清单、风险评估报告、风险防控措施撰写；

+   内控缺陷识别、缺陷整改跟踪、内控体系完善建议撰写。

**应用价值**：简化内控评价与风险排查流程，快速生成评价报告与风险防控措施，帮助企业识别内控缺陷与经营风险，完善内控体系，提升风险防控能力。

对应`OpenClaw` Skills：

+   `internal-control-evaluation`（内控评价报告、内控优化建议撰写）；

+   `risk-inspection`（常态化风险排查、风险评估报告撰写）；

+   `risk-control-measure`（风险防控措施、缺陷整改建议撰写）；

+   `internal-control-defect`（内控缺陷识别、缺陷跟踪报告撰写）。

### （六）合规审计与监督类（合规管控场景）

**场景核心内容**：负责企业合规管理的审计与监督，确保企业经营活动符合法律法规、行业规范与企业制度，具体包括：

+   合规审计报告、合规检查报告的起草与梳理；

+   企业制度合规性检查、流程合规性核查、违规行为排查；

+   合规风险提示、合规整改建议、合规培训材料撰写；

+   违规行为调查、调查记录、处理建议报告撰写。

**应用价值**：规范合规审计流程，简化合规检查与报告撰写工作，及时发现违规行为与合规风险，推动企业合规运营，规避合规风险与法律责任。

对应`OpenClaw` Skills：

+   `compliance-audit`（合规审计报告、合规检查报告撰写）；

+   `compliance-inspection`（制度合规性、流程合规性核查）；

+   `compliance-warning`（合规风险提示、整改建议撰写）；

+   `violation-investigation`（违规行为调查记录、处理建议报告撰写）。

### （七）文书与档案管理类（基础支撑场景）

**场景核心内容**：负责部门各类审计文书、文件、档案的起草、整理、归档与管理，确保审计工作规范、可追溯，具体包括：

+   部门工作总结、工作计划、工作汇报、审计简报的撰写与规范；

+   审计报告、审计底稿、核查材料、整改材料的归档与检索；

+   部门内部通知、会议纪要、审计工作制度的起草与分发；

+   审计相关公文、函件、问询函的起草与规范。

**应用价值**：实现审计文书撰写与档案管理规范化、高效化，减少人工整理与归档耗时，确保各类审计文件、档案可追溯、可查询，提升部门日常工作效率，保障审计工作的连续性与规范性。

对应`OpenClaw` Skills：

+   `work-summary`（部门工作总结、工作计划、工作汇报撰写）；

+   `document-archive`（审计各类材料归档、检索目录生成）；

+   `meeting-minutes`（部门会议纪要、审计简报起草）；

+   `official-doc`（审计相关公文、函件、问询函起草）。

## 四、应用价值总结

`OpenClaw`可全面替代审计部/内审部审计报告撰写、审计计划制定、底稿管理、整改跟踪、内控评价、合规核查等高频重复性、事务性工作，严格遵循审计规范与合规要求，实现审计工作规范化、核查高效化、整改闭环化、档案标准化，有效解决部门“报告撰写繁琐、底稿整理耗时、整改跟踪复杂”的痛点，帮助审计人员从繁琐的事务性工作中解放出来，聚焦审计核查、风险识别、内控优化、合规监督等高价值核心工作，预计可提升部门整体工作效率55%–70%，为企业规范运营、风险防控、管理提升提供有力的审计支撑。
