# 销售部/商务部/业务部 OpenClaw 应用场景及对应Skills分析报告

## 一、部门核心定位

销售部/商务部/业务部（统称“业务部门”）是企业直接创造营收、链接客户、实现市场突破的核心业务部门，直接向高层管理层负责，承担着客户拓展、需求挖掘、订单洽谈、商务对接、业绩达成、客户维护等核心职能。三个部门职能各有侧重但高度协同：销售部聚焦终端客户拓展与订单达成，商务部聚焦商务洽谈、合同履约与合作对接，业务部聚焦整体业务统筹与市场布局，共同构成企业营收增长的核心引擎。该部门工作兼具强业绩导向、高频客户对接性与高效执行性，核心特点是“客户多、沟通多、文案多、台账杂”，主要负责客户开发、商务洽谈、合同签订、订单跟进、业绩统计、客户维护等工作，是推动企业营收增长、拓展市场份额、维护客户关系的核心部门，也是OpenClaw落地适配的重点业务类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按销售部/商务部/业务部日常工作高频度、刚需度排序，兼顾三个部门职能共性，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合业务拓展与商务对接需求，无需额外定制开发，零基础可快速落地，兼顾专业性、实用性与高效性，适配三个部门的日常工作场景。

### （一）客户拓展与对接类（核心职能场景）

**场景核心内容**：作为业务部门的核心工作，负责客户挖掘、客户对接、需求了解，搭建稳定的客户体系，为订单达成奠定基础，具体包括：

+   潜在客户挖掘、客户信息收集、客户画像梳理与分类管理；

+   客户对接话术、跟进话术、需求挖掘话术的撰写与优化；

+   客户初次接洽、需求沟通、产品/服务推介的文案与话术支撑；

+   客户跟进记录、需求台账建立与更新，确保客户跟进不遗漏。

**应用价值**：标准化客户拓展与对接流程，快速生成各类对接话术与推介材料，提升客户拓展效率与对接专业度，规范客户信息管理，减少人工话术撰写与台账整理耗时，助力快速挖掘优质客户、推进对接进程。

对应OpenClaw Skills：

+   customer-development（潜在客户挖掘、客户信息整理与分类）；

+   customer-communication（客户对接话术、跟进话术、推介话术撰写）；

+   customer-profile（客户画像梳理、需求台账建立与更新）；

+   promotion-copy（产品/服务推介文案、对接材料撰写）。

### （二）商务洽谈与合同管理类（核心执行场景）

**场景核心内容**：负责商务洽谈、合作方案制定、合同起草与履约跟进，确保订单达成与合作顺利推进，具体包括：

+   商务洽谈方案、合作建议书、报价单的起草与优化；

+   销售合同、合作协议、框架协议的初稿起草、条款梳理与规范；

+   合同洽谈话术、条款协商回复口径、异议处理话术撰写；

+   合同台账建立、履约进度跟踪、合同归档与检索管理。

**应用价值**：简化商务方案与合同起草流程，规范合同条款与洽谈话术，提升商务洽谈效率与成功率，实现合同管理规范化、履约跟踪高效化，减少人工起草与台账管理耗时，规避合同管理风险。

对应OpenClaw Skills：

+   business-negotiation（商务洽谈方案、合作建议书起草）；

+   contract-draft（销售合同、合作协议初稿起草与规范）；

+   quotation（报价单、合作报价方案撰写）；

+   contract-manage（合同台账建立、履约跟踪、归档管理）。

### （三）订单跟进与履约交付类（闭环运营场景）

**场景核心内容**：负责订单签订后的跟进、履约推进、交付对接，确保订单顺利完成，提升客户满意度，具体包括：

+   订单进度跟踪、生产/服务履约进度对接、交付计划制定；

+   订单跟进简报、履约情况汇报、交付异常处理说明撰写；

+   客户交付对接、验收沟通、验收报告辅助撰写；

+   订单异常（延期、变更）处理方案、客户沟通话术撰写。

**应用价值**：实现订单跟进与履约交付规范化、高效化，简化进度跟踪与报告撰写流程，及时处理履约异常，确保订单顺利交付，提升客户满意度，减少订单流失风险。

对应OpenClaw Skills：

+   order-track（订单进度跟踪、履约进度对接）；

+   delivery-management（交付计划、交付对接材料撰写）；

+   exception-handle（订单异常处理方案、沟通话术撰写）；

+   progress-report（订单跟进简报、履约情况汇报撰写）。

### （四）业绩统计与报告类（支撑决策场景）

**场景核心内容**：负责部门业绩数据统计、分析，撰写各类业绩报告，为高层决策与业绩优化提供数据支撑，具体包括：

+   个人/团队业绩数据、订单数据、客户数据的汇总与统计；

+   月度/季度/年度业绩报告、业绩分析报告、业绩差距总结撰写；

+   业绩目标分解、达成情况跟踪、优化建议撰写；

+   业绩台账、报表建立与更新，数据解读材料整理。

**应用价值**：实现业绩数据统计自动化、规范化，简化业绩报告撰写与数据解读流程，确保数据准确、报告规范，帮助高层精准掌握业绩情况、识别业绩短板，助力业绩目标达成。

对应OpenClaw Skills：

+   performance-stat（业绩数据、订单数据汇总与统计）；

+   sales-report（业绩报告、业绩分析报告撰写）；

+   target-decomposition（业绩目标分解、达成情况分析）；

+   ledger-manage（业绩台账、数据报表建立与更新）。

### （五）客户维护与关系提升类（长期发展场景）

**场景核心内容**：负责存量客户维护、关系深化，提升客户粘性与复购率，挖掘客户二次合作与转介绍价值，具体包括：

+   客户回访计划、回访话术、回访记录撰写与整理；

+   客户满意度调研、反馈梳理、优化建议撰写；

+   客户维护文案、节日问候、合作致谢函的撰写；

+   客户投诉、诉求处理话术与解决方案撰写，客户关系修复。

**应用价值**：标准化客户维护流程与话术，简化回访与反馈梳理工作，提升客户维护效率与专业度，深化客户关系，提高客户复购率与转介绍率，降低客户流失率。

对应OpenClaw Skills：

+   customer-maintenance（客户回访计划、回访话术撰写）；

+   satisfaction-survey（客户满意度调研、反馈梳理）；

+   letter-draft（客户致谢函、节日问候文案撰写）；

+   complaint-handle（客户投诉、诉求处理话术与方案撰写）。

### （六）市场与竞品分析类（支撑拓展场景）

**场景核心内容**：负责跟踪市场动态、竞品情况，分析市场需求，为客户拓展与业务优化提供支撑，具体包括：

+   市场需求分析、市场趋势跟踪、目标市场定位报告撰写；

+   竞品产品/服务、价格策略、客户群体的分析与梳理；

+   市场竞争优势、短板分析、业务优化建议撰写；

+   市场调研问卷、调研报告的起草与整理。

**应用价值**：简化市场调研与竞品分析流程，快速生成分析报告与优化建议，帮助业务人员精准把握市场需求、识别竞争优势，优化客户拓展策略与业务模式。

对应OpenClaw Skills：

+   market-analyze（市场需求、市场趋势分析报告撰写）；

+   competitor-analyze（竞品分析、竞争优势梳理）；

+   market-research（市场调研问卷、调研报告起草）；

+   business-optimize（业务优化建议、拓展策略撰写）。

### （七）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责部门各类业务文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+   部门工作总结、工作计划、工作汇报、业务简报的撰写与规范；

+   客户台账、订单台账、业绩台账、合同台账的整理与更新；

+   部门内部通知、会议纪要、业务培训材料的起草与分发；

+   业务相关公文、函件、问询回复的起草与规范。

**应用价值**：实现业务文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类业务文件、台账可追溯、可查询，提升部门日常工作效率，保障业务工作有序推进。

对应OpenClaw Skills：

+   work-summary（部门工作总结、工作计划、工作汇报撰写）；

+   ledger-manage（各类业务台账建立、整理与更新）；

+   meeting-minutes（部门会议纪要、业务简报起草）；

+   official-doc（业务相关公文、函件、问询回复起草）。
