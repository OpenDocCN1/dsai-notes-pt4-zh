# 市场部/品牌部/营销部 OpenClaw 应用场景及对应Skills分析报告

## 一、部门核心定位

市场部/品牌部/营销部（统称“营销品牌部门”）是企业塑造品牌形象、拓展市场影响力、推动产品/服务转化、维护用户关系的核心职能部门，直接向高层管理层负责，承担着品牌建设、市场推广、营销策划、用户运营、舆情管理、市场调研等核心职能。三个部门职能协同互补、各有侧重：市场部聚焦市场调研、渠道拓展与推广落地，品牌部聚焦品牌定位、形象塑造与口碑传播，营销部聚焦营销活动策划、转化攻坚与用户运营，共同构成企业品牌建设与市场增长的核心体系。该部门工作兼具强创意性、高频传播性与高效落地性，核心特点是“文案多、活动多、调研多、传播多”，主要负责品牌推广、营销策划、市场调研、用户运营、舆情应对等工作，是提升企业品牌影响力、推动产品/服务转化、拓展市场空间的核心支撑部门，也是OpenClaw落地适配的重点创意营销类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按市场部/品牌部/营销部日常工作高频度、刚需度排序，兼顾三个部门职能共性与差异化需求，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合品牌建设与营销推广需求，无需额外定制开发，零基础可快速落地，兼顾创意性、专业性与高效性，适配三个部门的日常工作场景。

### （一）品牌建设与传播类（核心职能场景）

**场景核心内容**：作为品牌部核心工作、市场部与营销部协同工作，负责品牌定位、形象塑造、口碑传播，提升品牌知名度与美誉度，具体包括：

+   品牌定位方案、品牌理念、品牌口号的起草与优化，明确品牌核心价值；

+   品牌传播文案（公众号、视频号、小红书等新媒体）、宣传海报配文、品牌故事撰写；

+   品牌推广活动（发布会、公益活动、品牌联动）策划方案与执行文案起草；

+   品牌口碑监测、口碑维护文案、正面传播素材整理与输出。

**应用价值**：简化品牌文案与推广方案撰写流程，丰富传播素材，规范品牌传播口径，提升品牌传播效率与专业性，塑造统一、正面的品牌形象，减少人工创意打磨与文案修改耗时，助力品牌影响力提升。

对应OpenClaw Skills：

+   brand-positioning（品牌定位方案、品牌理念、口号起草）；

+   brand-copy（品牌传播文案、海报配文、品牌故事撰写）；

+   brand-promotion（品牌推广活动策划方案、执行文案起草）；

+   brand-reputation（品牌口碑维护文案、正面传播素材整理）。

### （二）营销策划与活动落地类（核心执行场景）

**场景核心内容**：负责各类营销活动策划、方案落地与效果跟踪，推动产品/服务转化，达成营销目标，具体包括：

+   线上线下营销活动（促销活动、节日营销、直播活动、社群营销）策划方案起草；

+   活动执行方案、流程安排、物料文案、活动话术的撰写与优化；

+   活动预热、引爆、复盘全流程文案与传播素材输出；

+   营销活动效果跟踪、数据统计、复盘报告撰写与优化建议提出。

**应用价值**：标准化营销活动策划流程，快速生成活动方案与各类物料文案，提升活动策划与落地效率，规范活动执行流程，助力活动效果最大化，减少人工策划与素材撰写耗时。

对应OpenClaw Skills：

+   marketing-plan（线上线下营销活动策划方案起草）；

+   activity-execution（活动执行方案、物料文案、话术撰写）；

+   activity-promotion（活动预热、引爆文案与传播素材输出）；

+   marketing-review（活动复盘报告、效果分析与优化建议撰写）。

### （三）市场调研与分析类（核心支撑场景）

**场景核心内容**：负责市场调研、需求分析、竞品研判，为品牌建设与营销策划提供数据支撑，具体包括：

+   市场调研方案、调研问卷、调研提纲的起草与规范；

+   市场需求分析、用户画像梳理、消费趋势研判报告撰写；

+   竞品营销策略、品牌推广、产品卖点的分析与梳理；

+   调研数据汇总、分析摘要、决策参考材料整理与提交。

**应用价值**：简化市场调研流程与报告撰写工作，快速生成调研方案与分析报告，帮助团队精准把握市场需求、识别竞品优势，为品牌定位与营销策划提供科学依据，提升决策准确性。

对应OpenClaw Skills：

+   market-research（市场调研方案、调研问卷起草）；

+   market-analysis（市场需求、消费趋势分析报告撰写）；

+   user-portrait（用户画像梳理、需求分析撰写）；

+   competitor-analysis（竞品营销、品牌策略分析）。

### （四）用户运营与转化类（闭环运营场景）

**场景核心内容**：负责用户获取、激活、留存、转化，维护用户关系，提升用户粘性与转化效率，具体包括：

+   用户运营方案、社群运营规则、用户跟进话术的撰写与优化；

+   用户分层管理、精准营销文案、转化引导话术的撰写；

+   用户反馈收集、梳理、优化建议撰写，用户投诉处理话术与方案；

+   用户转化数据统计、转化效果分析、转化策略优化建议撰写。

**应用价值**：标准化用户运营流程，快速生成运营文案与话术，提升用户运营效率与转化效果，深化用户关系，降低用户流失率，助力实现用户价值最大化。

对应OpenClaw Skills：

+   user-operation（用户运营方案、社群运营规则撰写）；

+   conversion-copy（精准营销、转化引导话术撰写）；

+   user-feedback（用户反馈梳理、优化建议撰写）；

+   conversion-analysis（用户转化数据统计、效果分析撰写）。

### （五）舆情管理与危机应对类（风险防控场景）

**场景核心内容**：负责品牌舆情监测、负面舆情应对，维护品牌形象，规避舆情风险，具体包括：

+   舆情监测方案、监测台账建立与更新，舆情动态梳理；

+   负面舆情应对方案、声明文案、回应话术的撰写与优化；

+   舆情复盘报告、舆情风险防控建议、舆情应对流程规范撰写；

+   正面舆情引导、舆情公关文案的撰写与传播。

**应用价值**：规范舆情管理流程，快速响应负面舆情，生成应对文案与方案，降低舆情对品牌的影响，维护品牌正面形象，规避舆情风险。

对应OpenClaw Skills：

+   public-opinion-monitor（舆情监测方案、监测台账建立）；

+   crisis-response（负面舆情应对方案、声明文案、回应话术撰写）；

+   public-opinion-review（舆情复盘报告、风险防控建议撰写）；

+   public-opinion-guide（正面舆情引导、公关文案撰写）。

### （六）营销物料与文案创作类（基础支撑场景）

**场景核心内容**：负责各类营销品牌物料、文案的创作与优化，为推广、活动、传播提供支撑，具体包括：

+   产品/服务推广文案、海报文案、短视频脚本、推文的撰写与优化；

+   宣传手册、宣传单页、展会物料等线下物料文案的起草；

+   营销邮件、短信推送、社群推文等精准触达文案的撰写；

+   文案审核、修改、优化，确保文案贴合品牌调性与营销需求。

**应用价值**：提升文案创作效率与质量，丰富营销物料储备，规范文案调性，减少人工创意打磨与修改耗时，为各类营销品牌活动提供高效的文案支撑。

对应OpenClaw Skills：

+   marketing-copy（推广文案、海报文案、短视频脚本撰写）；

+   material-copy（线下宣传物料、手册文案起草）；

+   precision-copy（营销邮件、短信、社群精准触达文案撰写）；

+   copy-review（文案审核、修改与优化）。

### （七）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责部门各类营销品牌文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+   部门工作总结、工作计划、工作汇报、营销品牌简报的撰写与规范；

+   营销活动台账、品牌传播台账、舆情台账、用户台账的整理与更新；

+   部门内部通知、会议纪要、营销品牌培训材料的起草与分发；

+   营销品牌相关公文、函件、合作对接材料的起草与规范。

**应用价值**：实现营销品牌文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率，保障营销品牌工作有序推进。

对应OpenClaw Skills：

+   work-summary（部门工作总结、工作计划、工作汇报撰写）；

+   ledger-manage（各类营销品牌台账建立、整理与更新）；

+   meeting-minutes（部门会议纪要、营销品牌简报起草）；

+   official-doc（营销品牌相关公文、函件、合作材料起草）。
