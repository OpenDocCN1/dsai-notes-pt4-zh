# 公关部/企业传讯部 OpenClaw 应用场景及对应Skills分析报告

## 一、部门核心定位

公关部/企业传讯部是企业声誉管理、信息发布、媒体关系维护、危机处置、品牌形象传播及企业社会责任落地的核心职能部门，直接向高层管理层负责，承担着对外发声、媒体对接、舆情监测、危机公关、公关活动策划、ESG/CSR传播、官方材料输出等核心职能。两个部门职能高度协同、一脉相承：公关部聚焦危机处置、媒体关系与声誉维护，企业传讯部聚焦信息传递、品牌传播与企业形象塑造，共同构成企业对外沟通的核心体系。该部门工作兼具极强合规性、高度敏感性与快速响应性，核心特点是“文案严、口径统、反应快、风险高”，主要负责新闻发布、媒体沟通、舆情应对、危机处理、ESG/CSR传播、公关活动落地等工作，是企业对外形象的“喉舌”与声誉安全的“防火墙”，也是OpenClaw落地适配的重点合规传播类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按公关部/企业传讯部日常工作高频度、刚需度排序，兼顾两个部门职能共性，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均严格遵循公关传播规范与合规要求，贴合部门对外沟通与声誉管理需求，无需额外定制开发，零基础可快速落地，兼顾专业性、合规性与高效性，适配两个部门的日常工作场景。

### （一）新闻发布与官方发声类（核心职能场景）

**场景核心内容**：作为部门核心工作，负责企业各类官方信息的起草、发布与传播，确保对外发声统一、合规、严谨，具体包括：

+   新闻稿、通稿、官宣稿、官方声明稿的初稿起草、内容优化与审核；

+   企业重大事项、合作签约、新品发布、人事变动等相关公告撰写；

+   对外沟通统一口径、答记者问话术、常见问题（FAQ）梳理与更新；

+   新闻发布会、新品发布会的主持词、高管发言稿、背景材料撰写。

**应用价值**：规范官方文案撰写流程，快速产出合规、严谨、统一的新闻与公告内容，确保对外发声口径一致，提升信息发布效率，减少人工文案打磨与修改耗时，维护企业官方形象。

对应OpenClaw Skills：

+   press-release（新闻稿、通稿撰写与优化）；

+   official-statement（官方声明、各类公告起草）；

+   media-QA（媒体问答口径、FAQ生成与更新）；

+   speech-draft（发布会主持词、高管发言稿、背景材料撰写）。

### （二）媒体关系与沟通对接类（核心执行场景）

**场景核心内容**：负责企业与各类媒体（传统媒体、新媒体）的对接与关系维护，推动正面传播，具体包括：

+   媒体邀请函、采访提纲、沟通函、致谢函的起草与优化；

+   媒体对接话术、采访回复口径、采访素材整理与提供；

+   媒体报道监测、报道摘要整理、传播效果总结报告撰写；

+   媒体合作方案、专访策划、媒体沙龙活动方案起草。

**应用价值**：标准化媒体沟通流程与材料输出，提升媒体对接专业度与响应速度，维护良好的媒体关系，推动企业正面信息传播，简化媒体监测与总结工作。

对应OpenClaw Skills：

+   media-communication（媒体沟通话术、各类函件撰写）；

+   interview-outline（采访提纲、专访策划方案起草）；

+   media-monitor（媒体报道监测、摘要整理、传播总结撰写）；

+   media-cooperation（媒体合作方案、媒体活动策划）。

### （三）舆情监测与危机公关类（核心防线场景）

**场景核心内容**：负责企业舆情监测、风险研判与危机处置，维护企业声誉安全，具体包括：

+   舆情日报、周报、月报及专项舆情简报的撰写与提交；

+   负面舆情研判、风险等级评估、舆情预警与应对建议撰写；

+   危机声明、致歉公告、负面舆情回应口径的起草与优化；

+   危机处置方案、公关应对话术、后续沟通文案的撰写与落地。

**应用价值**：提升舆情监测与危机响应效率，规范危机应对流程与表达，快速产出应对文案，降低负面舆情对企业声誉的影响，筑牢企业声誉“防火墙”。

对应OpenClaw Skills：

+   public-opinion-report（舆情简报、舆情分析报告撰写）；

+   crisis-response（危机公关方案、应对话术撰写）；

+   crisis-statement（危机声明、致歉公告起草）；

+   risk-warning（舆情风险提示、预警文案撰写）。

### （四）品牌声誉与企业形象传播类（核心支撑场景）

**场景核心内容**：负责企业品牌声誉维护与正面形象传播，传递企业核心价值，具体包括：

+   企业故事、品牌故事、社会责任故事的撰写与传播；

+   高管专访稿、人物专访稿、企业观点稿的起草与优化；

+   年度品牌传播计划、传播主题文案的撰写与落地；

+   企业正面形象塑造、口碑维护文案的输出与传播。

**应用价值**：统一企业形象输出口径，丰富正面传播素材，提升品牌美誉度与企业公信力，助力企业塑造积极、专业的对外形象。

对应OpenClaw Skills：

+   brand-story（品牌故事、企业故事撰写）；

+   executive-profile（高管专访、人物专访、观点稿撰写）；

+   reputation-building（品牌声誉维护、正面传播文案输出）；

+   brand-communication-plan（年度品牌传播计划、主题文案撰写）。

### （五）ESG/企业社会责任（CSR）类（重点场景）

**场景核心内容**：负责企业ESG与社会责任相关工作的传播与落地，提升企业社会形象，具体包括：

+   ESG报告摘要、企业社会责任报告初稿的起草与梳理；

+   公益活动、环保项目、乡村振兴等相关文案与新闻稿撰写；

+   社会责任案例总结、成果传播、公益合作方案起草；

+   公益倡议书、捐赠声明、社会责任宣传文案的撰写。

**应用价值**：规范ESG/CSR相关材料输出，丰富社会责任传播素材，提升企业社会公信力与品牌美誉度，助力企业履行社会责任、传递正能量。

对应OpenClaw Skills：

+   esg-report（ESG报告摘要、企业社会责任报告撰写）；

+   csr-activity（公益活动文案、新闻稿、案例总结撰写）；

+   social-welfare（公益倡议书、捐赠声明撰写）；

+   csr-cooperation（公益合作方案起草）。

### （六）公关活动与展会/发布会执行类（落地场景）

**场景核心内容**：负责各类公关活动的策划、落地与传播复盘，提升企业对外影响力，具体包括：

+   新闻发布会、行业论坛、峰会、签约仪式等公关活动策划方案起草；

+   活动流程安排、主持稿、活动通稿、背景资料的撰写与优化；

+   活动总结、传播效果复盘报告、优化建议的撰写；

+   活动邀请函、欢迎词、致谢函的起草与分发。

**应用价值**：一站式产出公关活动全流程文案与方案，规范活动执行流程，提升活动落地效率与传播效果，减少人工策划与材料撰写耗时。

对应OpenClaw Skills：

+   pr-event-plan（公关活动策划方案起草）；

+   event-document（活动流程、主持稿、通稿、背景资料撰写）；

+   event-summary（活动总结、传播效果复盘报告撰写）；

+   event-invitation（活动邀请函、欢迎词、致谢函撰写）。

### （七）对外材料与企业介绍类（基础支撑场景）

**场景核心内容**：负责企业各类对外宣传材料的起草与规范，确保对外介绍口径统一，具体包括：

+   企业简介、品牌手册、宣传PPT文案的起草与优化；

+   对外介绍口径、标准化介绍词的梳理与更新；

+   官网介绍、👸号简介、对外展示材料文案的撰写；

+   对外合作、展会展示相关宣传文案的起草。

**应用价值**：统一企业对外介绍体系，避免口径混乱，提升对外宣传材料的专业性与规范性，助力企业塑造统一、正面的对外形象。

对应OpenClaw Skills：

+   company-intro（企业简介、品牌介绍撰写与优化）；

+   presentation-copy（宣传PPT文案、品牌手册文案撰写）；

+   intro-caliber（对外介绍口径、标准化介绍词梳理）；

+   exhibition-copy（展会、对外展示相关文案撰写）。

### （八）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责部门各类公文、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+   部门工作总结、工作计划、公关周报、月报、工作简报的撰写与规范；

+   媒体台账、舆情台账、公关活动台账的建立、整理与更新；

+   部门内部通知、会议纪要、公关工作培训材料的起草与分发；

+   公关相关内部请示、汇报、审批材料的起草与规范。

**应用价值**：实现公关文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率，保障公关工作有序推进。

对应OpenClaw Skills：

+   work-summary（部门工作总结、工作计划、各类简报撰写）；

+   ledger-manage（媒体、舆情、公关活动台账建立与更新）；

+   meeting-minutes（部门会议纪要、公关培训材料起草）；

+   official-doc（公关相关公文、请示、汇报材料起草）。

## 四、应用价值总结
