# 电商部/新零售部/线上运营部 OpenClaw 应用场景及对应Skills分析报告

## 一、部门核心定位

电商部/新零售部/线上运营部（统称“线上运营部门”）是企业布局线上渠道、实现线上营收增长、打通线上线下融合、优化线上用户体验的核心职能部门，直接向高层管理层或业务部门负责，承担着线上店铺运营、流量获取、转化提升、用户运营、活动策划、数据复盘、供应链对接等核心职能。三个部门职能协同互补、各有侧重：电商部聚焦平台店铺（电商平台、自有商城）运营与订单转化，新零售部聚焦线上线下融合运营、私域流量搭建与全渠道履约，线上运营部聚焦线上流量运营、内容传播与用户留存，共同构成企业线上业务增长的核心体系。该部门工作兼具强数据性、高频运营性与高效转化性，核心特点是“运营细、数据多、活动密、节奏快”，主要负责线上店铺运营、流量推广、营销活动、用户维护、数据复盘等工作，是企业拓展线上市场、提升线上营收、实现数字化转型的核心支撑部门，也是OpenClaw落地适配的重点线上运营类部门。

## 二、核心应用场景及对应OpenClaw Skills

本章节按电商部/新零售部/线上运营部日常工作高频度、刚需度排序，兼顾三个部门职能共性，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合线上运营与营收增长需求，无需额外定制开发，零基础可快速落地，兼顾专业性、实用性与高效性，适配三个部门的日常工作场景。

### （一）线上店铺运营类（核心职能场景）

**场景核心内容**：作为线上运营部门的核心工作，负责各类线上店铺的日常运营、维护与优化，确保店铺正常运转、提升店铺权重，具体包括：

+   电商平台店铺（淘宝、京东、拼多多等）、自有商城、小程序店铺的日常运营与维护；

+   店铺装修、商品上架、标题优化、详情页文案撰写与优化；

+   店铺日常巡检、订单处理、售后对接、评价管理与维护；

+   店铺权重提升、橱窗优化、类目运营、平台规则适配与合规运营。

**应用价值**：标准化线上店铺运营流程，快速生成商品详情页、标题等运营素材，提升店铺运营效率，优化店铺展示效果，规范订单与评价管理，助力店铺权重提升与合规运营，减少人工运营与素材撰写耗时。

对应OpenClaw Skills：

+   store-operation（线上店铺日常运营、维护与巡检）；

+   product-optimize（商品标题、详情页文案撰写与优化）；

+   store-decoration（店铺装修、橱窗优化、类目运营）；

+   order-management（店铺订单处理、评价管理与维护）。

### （二）流量获取与推广类（核心执行场景）

**场景核心内容**：负责线上流量的获取、推广与优化，提升店铺曝光量与访客量，为转化奠定基础，具体包括：

+   付费推广（直通车、钻展、信息流广告等）方案策划、文案撰写与优化；

+   免费流量（自然搜索、内容种草、社群引流）运营与推广；

+   推广素材（海报、短视频脚本、推广文案）的撰写与输出；

+   推广数据监测、效果分析、优化调整建议撰写。

**应用价值**：规范流量推广流程，快速生成推广方案与素材，提升流量获取效率与推广ROI，精准定位目标用户，减少人工推广策划与素材打磨耗时，助力店铺曝光与访客量提升。

对应OpenClaw Skills：

+   paid-promotion（付费推广方案、文案撰写与优化）；

+   free-traffic（免费流量运营、社群引流与种草文案撰写）；

+   promotion-material（推广海报、短视频脚本、文案输出）；

+   promotion-analysis（推广数据监测、效果分析与优化建议）。

### （三）线上营销活动策划类（闭环运营场景）

**场景核心内容**：负责各类线上营销活动的策划、落地与复盘，提升店铺转化与营收，具体包括：

+   平台大促（618、双11、年货节）、店铺日常促销、节日营销活动策划方案起草；

+   活动规则、优惠券设置、满减活动、秒杀活动等文案与流程撰写；

+   活动预热、引爆、复盘全流程运营文案与传播素材输出；

+   活动数据统计、转化效果分析、复盘报告与优化建议撰写。

**应用价值**：标准化线上营销活动策划流程，快速生成活动方案与各类运营素材，提升活动落地效率与转化效果，规范活动执行流程，助力活动目标达成，减少人工策划与素材撰写耗时。

对应OpenClaw Skills：

+   online-marketing（线上营销活动、大促活动策划方案起草）；

+   activity-rule（活动规则、促销文案、流程撰写）；

+   activity-promotion（活动预热、引爆文案与传播素材输出）；

+   activity-review（活动数据统计、复盘报告与优化建议撰写）。

### （四）用户运营与私域搭建类（长期发展场景）

**场景核心内容**：负责线上用户的获取、激活、留存、复购，搭建私域流量体系，提升用户粘性与终身价值，具体包括：

+   私域流量（企业🛰️、社群、👸号）搭建与运营，用户分层管理；

+   用户运营文案、社群话术、复购引导话术的撰写与优化；

+   用户画像梳理、精准推送文案、老用户召回活动策划；

+   用户反馈收集、梳理，产品与服务优化建议撰写。

**应用价值**：标准化私域运营与用户管理流程，快速生成运营文案与话术，提升用户运营效率与复购率，搭建稳定的私域流量体系，降低获客成本，实现用户价值最大化。

对应OpenClaw Skills：

+   private-traffic（私域流量搭建、社群运营与管理）；

+   user-operation（用户分层管理、运营文案与话术撰写）；

+   repurchase-guide（复购引导、老用户召回活动策划）；

+   user-feedback（用户反馈收集、梳理与优化建议撰写）。

### （五）数据统计与复盘类（支撑决策场景）

**场景核心内容**：负责线上运营各类数据的统计、分析与复盘，为运营优化与决策提供数据支撑，具体包括：

+   店铺数据（曝光量、访客量、转化率、客单价）、推广数据、活动数据的汇总与统计；

+   月度/季度/年度线上运营数据报告、数据分析、短板总结撰写；

+   运营指标完成情况分析、优化调整方案、增长策略撰写；

+   数据台账建立、更新，数据解读材料整理与提交。

**应用价值**：实现线上运营数据统计自动化、规范化，简化数据报告撰写与解读流程，确保数据准确、分析到位，帮助管理层精准掌握运营情况，推动运营策略优化与营收增长。

对应OpenClaw Skills：

+   operation-data（店铺、推广、活动等数据汇总与统计）；

+   data-report（线上运营数据报告、数据分析撰写）；

+   indicator-analysis（运营指标完成情况分析、优化方案撰写）；

+   data-ledger（运营数据台账建立、更新与解读）。

### （六）供应链与履约对接类（基础支撑场景）

**场景核心内容**：负责线上订单的供应链对接、履约交付，确保订单顺利完成，提升用户体验，具体包括：

+   线上订单与供应链对接、库存管理、发货进度跟踪；

+   履约交付异常（缺货、延期、破损）处理方案、客户沟通话术撰写；

+   库存预警、补货计划、供应链优化建议撰写；

+   物流信息跟踪、客户物流咨询响应、履约满意度反馈收集。

**应用价值**：规范供应链与履约对接流程，简化订单跟踪与异常处理工作，提升履约效率，减少履约异常对用户体验的影响，确保订单顺利交付，提升客户满意度。

对应OpenClaw Skills：

+   supply-chain（线上订单与供应链对接、库存管理）；

+   fulfillment-track（订单履约进度、物流信息跟踪）；

+   exception-handle（履约异常处理方案、沟通话术撰写）；

+   inventory-warning（库存预警、补货计划撰写）。

### （七）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责部门各类线上运营文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+   部门工作总结、工作计划、工作汇报、运营简报的撰写与规范；

+   店铺运营台账、推广台账、活动台账、用户台账的整理与更新；

+   部门内部通知、会议纪要、运营培训材料的起草与分发；

+   线上运营相关公文、跨部门沟通函件、平台对接材料的起草与规范。

**应用价值**：实现线上运营文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率与跨部门沟通效率，保障线上运营工作有序推进。

对应OpenClaw Skills：

+   work-summary（部门工作总结、工作计划、工作汇报撰写）；

+   ledger-manage（各类线上运营台账建立、整理与更新）；

+   meeting-minutes（部门会议纪要、运营简报起草）；

+   official-doc（线上运营相关公文、沟通函件撰写）。
