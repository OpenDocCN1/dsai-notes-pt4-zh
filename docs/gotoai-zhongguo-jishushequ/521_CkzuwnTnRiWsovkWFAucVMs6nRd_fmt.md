
# 人力资源部（HR） OpenClaw 应用场景及对应Skills分析报告

> 来源：[https://gotoaiworld.feishu.cn/docx/Eebyd4ITpoT7nExbYE8c3Avfnnc](https://gotoaiworld.feishu.cn/docx/Eebyd4ITpoT7nExbYE8c3Avfnnc)

## 一、部门核心定位

人力资源部（HR）是企业人才引育留用、组织效能提升、员工关系维护、合规管理的核心职能部门，直接向高层管理层负责，承担着人才招聘、员工培训、薪酬福利管理、绩效管理、员工关系处理、人事合规、组织发展等核心职能。作为企业“人才管家”，HR部门贯穿员工“入、转、调、离”全生命周期，统筹企业人才队伍建设与组织能力提升，是保障企业正常运转、激发员工活力、支撑战略落地的核心支撑部门。该部门工作兼具强合规性、高频事务性、强协同性与人文性，核心特点是“事务杂、合规严、协同多、细节重”，主要负责人才招聘、员工管理、薪酬绩效、培训发展等工作，是OpenClaw落地适配的重点职能支撑类部门，可有效解决HR日常事务繁琐、重复性高的痛点。

## 二、核心应用场景及对应OpenClaw Skills

本章节按人力资源部（HR）日常工作高频度、刚需度排序，明确各场景核心工作内容、应用价值及对应OpenClaw Skills，所有Skills均贴合HR全流程工作需求，适配合规管理、员工服务、人才发展等核心痛点，无需额外定制开发，零基础可快速落地，兼顾专业性、合规性与高效性，适配HR部门日常工作场景。

### （一）人才招聘与配置类（核心职能场景）

**场景核心内容**：作为HR部门核心工作，负责企业各岗位人才的招聘、筛选、面试与配置，搭建适配企业发展的人才队伍，具体包括：

+ 招聘需求梳理、岗位说明书撰写与优化，招聘渠道筛选与对接；
+ 招聘文案、招聘海报、招聘启事的撰写与发布，简历筛选与初筛话术撰写；
+ 面试提纲、面试话术、面试评价表的制定，面试流程对接与跟进；
+ 录用通知、入职指引、背景调查相关材料的撰写与整理，新员工入职对接。

**应用价值**：标准化人才招聘全流程，快速生成招聘相关文案与材料，提升招聘效率与简历筛选精准度，规范面试流程，减少人工文案撰写与流程对接耗时，助力快速招到适配人才。

对应OpenClaw Skills：

+ `recruitment-demand`（招聘需求梳理、岗位说明书撰写）；
+ `recruitment-copy`（招聘文案、海报、启事撰写与优化）；
+ `interview-management`（面试提纲、话术制定，面试评价表撰写）；
+ `onboarding-guide`（录用通知、入职指引、背景调查材料撰写）。

### （二）员工入转调离与人事档案类（核心执行场景）

**场景核心内容**：负责员工全生命周期人事手续办理、人事档案管理，确保人事工作规范有序，具体包括：

+ 新员工入职登记、劳动合同签订、社保公积金缴纳对接；
+ 员工调岗、晋升、轮岗相关手续办理，人事变动通知撰写；
+ 员工离职面谈、离职手续办理、离职证明撰写，离职原因分析；
+ 员工人事档案建立、更新、归档与管理，确保档案合规可追溯。

**应用价值**：规范员工入转调离全流程手续，简化人事档案管理工作，提升人事手续办理效率，确保人事档案合规完整，减少人工档案整理与手续对接耗时，保障员工人事权益。

对应OpenClaw Skills：

+ `personnel-procedure`（员工入转调离手续办理、人事变动通知撰写）；
+ `labor-contract`（劳动合同签订、相关协议撰写与审核）；
+ `resignation-management`（离职手续办理、离职证明撰写、原因分析）；
+ `personnel-file`（员工人事档案建立、更新、归档与管理）。

### （三）薪酬福利与考勤管理类（核心保障场景）

**场景核心内容**：负责企业薪酬福利体系搭建、考勤管理，保障员工薪酬合规发放，提升员工满意度，具体包括：

+ 薪酬体系设计、薪酬核算、工资条制作与发放说明撰写；
+ 社保公积金、带薪休假、节日福利等福利政策制定与宣贯；
+ 考勤制度制定、考勤数据统计、考勤异常处理与说明；
+ 薪酬福利台账、考勤台账建立、更新与归档，相关数据统计分析。

**应用价值**：标准化薪酬福利与考勤管理流程，简化薪酬核算与考勤统计工作，确保薪酬合规发放、考勤管理规范，提升员工满意度，减少人工核算与台账整理耗时。

对应OpenClaw Skills：

+ `salary-welfare`（薪酬体系设计、薪酬核算、福利政策制定）；
+ `salary-calculation`（工资条制作、薪酬发放说明撰写）；
+ `attendance-management`（考勤制度制定、数据统计、异常处理）；
+ `salary-attendance-ledger`（薪酬福利、考勤台账建立与管理）。

### （四）绩效管理与考核类（核心激励场景）

**场景核心内容**：负责企业绩效管理体系搭建、考核实施，激发员工工作动力，提升组织效能，具体包括：

+ 绩效考核制度、考核指标（KPI/OKR）制定与优化；
+ 考核方案、考核表、考核通知的撰写与发布，考核流程对接；
+ 考核结果统计、分析，考核面谈话术、考核反馈撰写；
+ 绩效考核复盘、优化建议撰写，考核结果应用指导。

**应用价值**：规范绩效管理与考核流程，快速生成考核相关材料，提升考核实施效率，确保考核公平公正，助力激发员工动力，推动组织效能提升。

对应OpenClaw Skills：

+ `performance-system`（绩效考核制度、考核指标制定与优化）；
+ `performance-assessment`（考核方案、考核表、考核通知撰写）；
+ `performance-feedback`（考核结果分析、面谈话术、反馈撰写）；
+ `performance-review`（绩效考核复盘、优化建议撰写）。

### （五）员工培训与发展类（长期赋能场景）

**场景核心内容**：负责员工培训体系搭建、培训实施与人才发展，提升员工专业能力，支撑企业发展，具体包括：

+ 培训需求调研、培训计划制定、培训方案与课件撰写；
+ 新员工入职培训、在岗员工技能培训、管理层培训的组织与执行；
+ 培训讲师对接、培训现场组织、培训效果评估与总结；
+ 员工职业发展规划、人才梯队建设方案的撰写与落地。

**应用价值**：标准化员工培训与发展流程，简化培训方案与课件撰写工作，提升培训实施效率与效果，助力员工能力提升与人才梯队建设，支撑企业长期发展。

对应OpenClaw Skills：

+ `training-demand`（培训需求调研、培训计划制定）；
+ `training-material`（培训方案、课件、培训通知撰写）；
+ `training-implementation`（培训组织、效果评估与总结）；
+ `talent-development`（员工职业发展规划、人才梯队建设方案撰写）。

### （六）员工关系与合规风控类（核心维稳场景）

**场景核心内容**：负责员工关系维护、劳动纠纷处理、人事合规风控，营造和谐的工作氛围，具体包括：

+ 员工沟通、员工关怀活动策划与执行，员工满意度调研与分析；
+ 劳动纠纷调解、仲裁对接，纠纷处理方案、沟通话术撰写；
+ 人事相关法律法规解读、合规手册撰写，确保人事工作合规；
+ 员工投诉处理、反馈收集，优化建议撰写，维护员工权益。

**应用价值**：规范员工关系管理与合规风控流程，快速处理劳动纠纷与员工投诉，提升员工满意度与归属感，规避人事合规风险，营造和谐稳定的工作氛围。

对应OpenClaw Skills：

+ `employee-relation`（员工关怀、满意度调研、沟通对接）；
+ `labor-dispute`（劳动纠纷调解、处理方案、沟通话术撰写）；
+ `hr-compliance`（人事法律法规解读、合规手册撰写）；
+ `employee-complaint`（员工投诉处理、反馈收集与优化建议）。

### （七）文书与台账管理类（基础支撑场景）

**场景核心内容**：负责HR部门各类文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+ 部门工作总结、工作计划、工作汇报、HR简报的撰写与规范；
+ 人事台账、招聘台账、薪酬台账、培训台账的整理与更新；
+ 部门内部通知、会议纪要、HR培训材料的起草与分发；
+ HR相关公文、跨部门沟通函件、人事政策宣贯材料的起草与规范。

**应用价值**：实现HR文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率与跨部门沟通效率，保障HR工作有序推进。

对应OpenClaw Skills：

+ `work-summary`（部门工作总结、工作计划、工作汇报撰写）；
+ `ledger-manage`（各类HR台账建立、整理与更新）；
+ `meeting-minutes`（部门会议纪要、HR简报起草）；
+ `official-doc`（HR相关公文、沟通函件、政策宣贯材料撰写）。
