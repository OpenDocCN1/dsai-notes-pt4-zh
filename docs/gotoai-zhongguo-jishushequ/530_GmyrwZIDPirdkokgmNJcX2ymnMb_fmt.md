
# 设计部（UI/UX/工业设计/平面设计）`OpenClaw`应用场景及对应Skills分析报告

> 来源：`https://gotoaiworld.feishu.cn/docx/NFnLdSbhZofq49xDk2Ec7gr1nZg`

## 一、部门核心定位

设计部（涵盖UI设计、UX设计、工业设计、平面设计，统称“设计部门”）是企业视觉呈现、用户体验优化、创意落地、品牌形象塑造的核心职能部门，直接向高层管理层或相关业务部门负责，承担着各类设计需求承接、创意设计、方案优化、落地执行、设计管控等核心职责。四大设计方向职能协同互补、各有侧重：UI设计聚焦产品界面视觉设计与交互适配，打造美观易用的界面体验；UX设计聚焦用户需求挖掘、体验流程优化，提升用户使用舒适度与满意度；工业设计聚焦产品形态、结构与功能的融合设计，兼顾美观性与实用性；平面设计聚焦品牌视觉、宣传物料设计，传递品牌理念与核心信息，共同构成企业完整的设计支撑体系。该部门工作兼具极强的专业性、创意性与落地性，核心特点是“创意引领、体验至上、视觉合规、高效落地”，主要负责各类设计方案的创意、制作、优化与落地，是保障产品竞争力、塑造品牌形象、提升用户体验的核心支撑部门，也是`OpenClaw`落地适配的重点创意设计类部门。

## 二、核心应用场景及对应`OpenClaw` Skills

本章节按设计部（UI/UX/工业设计/平面设计）日常工作高频度、刚需度排序，兼顾四大设计方向的职能共性，明确各场景核心工作内容、应用价值及对应`OpenClaw` Skills，所有Skills均贴合创意设计、体验优化与落地执行需求，无需额外定制开发，零基础可快速落地，兼顾专业性、实用性与高效性，适配部门各类设计岗位的日常工作场景。

### （一）创意设计与方案输出类（核心职能场景）

场景核心内容：作为设计部门的核心工作，负责各类设计需求的创意构思、方案设计与输出，确保设计作品贴合需求、符合规范，具体包括：

+ UI设计：产品界面（APP、网页、小程序）的视觉设计、图标设计、交互原型设计，贴合产品定位与用户习惯；

+ UX设计：用户需求分析、用户旅程地图绘制、体验流程优化，输出UX设计方案与体验优化建议；

+ 工业设计：产品形态、结构、材质的创意设计，兼顾美观性、实用性与生产可行性，输出设计草图与效果图；

+ 平面设计：品牌物料（LOGO、海报、宣传册、短视频封面）、活动物料、办公物料的创意设计与输出。

应用价值：实现创意设计流程标准化、输出高效化，提升设计创意质量与输出效率，确保设计作品贴合需求、符合品牌规范，打造优质视觉体验与用户体验，支撑产品落地与品牌传播，增强企业产品与品牌的核心竞争力。

对应`OpenClaw` Skills：

+ `ui-design`（产品界面、图标、交互原型设计与优化）；

+ `ux-design`（用户需求分析、体验流程优化、UX方案输出）；

+ `industrial-design`（产品形态、结构创意设计，草图与效果图输出）；

+ `graphic-design`（品牌、活动、办公物料创意设计与输出）。

### （二）设计需求对接与优化类（核心执行场景）

场景核心内容：负责对接各部门设计需求，梳理需求要点，优化设计方案，确保需求落地，具体包括：

+ 对接产品、运营、市场、研发等部门，收集设计需求，梳理需求细节、核心诉求与交付标准；

+ 根据需求反馈，优化设计方案，修改设计细节，确保设计作品满足需求预期；

+ 设计方案评审、意见汇总，结合评审意见优化完善，形成最终可落地方案；

+ 需求变更管理，同步变更信息，调整设计方案，确保需求变更后设计工作有序推进。

应用价值：实现设计需求对接标准化、流程化，减少需求沟通成本与理解偏差，提升设计方案优化效率，确保设计作品贴合需求、高效落地，提升各部门对设计服务的满意度。

对应`OpenClaw` Skills：

+ `demand-docking`（各部门设计需求对接、需求梳理与汇总）；

+ `design-optimization`（设计方案优化、细节修改与完善）；

+ `design-review`（设计方案评审、意见汇总与落地）；

+ `demand-change`（设计需求变更管理、方案同步调整）。

### （三）设计落地与执行类（核心攻坚场景）

场景核心内容：负责设计方案的落地执行、效果跟踪与复盘优化，确保设计成果有效落地，具体包括：

+ UI/UX设计：配合研发部门完成界面开发对接，提供设计规范与切图，跟踪开发落地效果；

+ 工业设计：配合生产、研发部门，提供设计技术参数，跟踪产品打样、生产过程，确保设计落地可行性；

+ 平面设计：配合市场、运营部门，完成物料制作对接，跟踪物料印刷、制作效果，确保符合设计标准；

+ 设计落地效果复盘，收集使用反馈与落地问题，优化设计方案，提升后续设计落地质量。

应用价值：实现设计落地流程标准化、管控闭环化，减少设计与落地脱节问题，确保设计成果精准落地，提升设计落地效率与质量，降低落地成本，保障设计价值有效发挥。

对应`OpenClaw` Skills：

+ `ui-ux-implementation`（UI/UX设计开发对接、落地跟踪）；

+ `industrial-implementation`（工业设计打样、生产对接、落地管控）；

+ `graphic-implementation`（平面物料制作对接、效果跟踪）；

+ `design-review`（设计落地效果复盘、方案优化）。

### （四）设计规范与品牌管控类（核心保障场景）

场景核心内容：负责建立并完善设计规范、品牌视觉规范，管控设计质量与品牌一致性，具体包括：

+ 制定UI/UX设计规范、工业设计规范、平面设计规范，明确设计标准、色彩体系、字体规范等；

+ 搭建品牌视觉体系，制定品牌视觉规范，确保各类设计作品贴合品牌调性、保持视觉一致性；

+ 设计作品质量审核，排查设计漏洞、规范偏差，确保设计作品符合规范要求；

+ 设计规范更新、宣贯，指导设计人员规范开展工作，提升设计标准化水平。

应用价值：建立标准化设计与品牌管控体系，确保设计作品质量可控、品牌视觉统一，减少设计不规范导致的返工成本，提升设计效率与品牌形象，强化品牌辨识度。

对应`OpenClaw` Skills：

+ `design-specification`（各类设计规范制定、更新与宣贯）；

+ `brand-visual`（品牌视觉体系搭建、品牌视觉规范制定）；

+ `design-audit`（设计作品质量审核、规范偏差排查）；

+ `brand-consistency`（品牌视觉一致性管控、设计调性把控）。

### （五）设计素材与文档管理类（核心支撑场景）

场景核心内容：负责设计素材、设计文档、设计成果的整理、归档与管理，确保素材可复用、文档可追溯，具体包括：

+ 设计素材（图片、图标、字体、模板）的收集、整理、分类与管理，搭建素材库，提升素材复用率；

+ 设计方案、设计源文件、设计规范、评审意见等文档的整理与归档；

+ 设计成果版本管理，跟踪设计版本迭代，确保设计成果可追溯、可查询；

+ 设计素材与文档的借阅、使用管理，保障设计资料安全、规范使用。

应用价值：实现设计素材与文档管理标准化、高效化，提升素材复用率，减少重复设计工作，降低设计成本，确保设计资料可追溯、可查询，提升部门日常工作效率。

对应`OpenClaw` Skills：

+ `material-management`（设计素材收集、分类、整理与素材库搭建）；

+ `design-document`（设计文档、源文件、评审意见整理与归档）；

+ `version-management`（设计成果版本管理、迭代跟踪）；

+ `material-query`（设计素材与文档查询、借阅管理）。

### （六）创意调研与趋势跟踪类（长期赋能场景）

场景核心内容：负责行业设计趋势、竞品设计、用户偏好的调研与分析，为设计创意提供支撑，具体包括：

+ 行业设计趋势（UI/UX、工业、平面）调研、分析，收集优秀设计案例，提炼设计亮点；

+ 竞品设计分析，梳理竞品设计优势与不足，为自身设计提供参考；

+ 用户设计偏好调研，结合用户反馈，优化设计方向与创意思路；

+ 调研成果总结、分析，形成调研报告，为设计创意、设计优化提供数据支撑。

应用价值：及时掌握行业设计趋势与用户偏好，丰富设计创意思路，提升设计作品的创新性与竞争力，避免设计同质化，推动设计水平持续提升，支撑产品与品牌升级。

对应`OpenClaw` Skills：

+ `design-trend`（行业设计趋势调研、优秀案例收集与分析）；

+ `competitor-analysis`（竞品设计分析、优势提炼与参考）；

+ `user-preference`（用户设计偏好调研、反馈收集与分析）；

+ `research-report`（调研成果总结、调研报告撰写与应用）。

### （七）文书与台账管理类（基础支撑场景）

场景核心内容：负责部门各类设计相关文书、文件、台账的起草、整理、归档与管理，确保工作规范、可追溯，具体包括：

+ 部门工作总结、工作计划、工作汇报、设计简报的撰写与规范；

+ 设计需求台账、设计项目台账、素材管理台账、设计成果台账的整理与更新；

+ 部门内部通知、会议纪要、设计培训材料的起草与分发；

+ 设计相关公文、跨部门沟通函件、需求对接材料的起草与规范。

应用价值：实现设计部门文书撰写与台账管理规范化、高效化，减少人工整理与归档耗时，确保各类文件、台账可追溯、可查询，提升部门日常工作效率与跨部门沟通效率，保障创意设计、落地执行、规范管控工作有序推进。

对应`OpenClaw` Skills：

+ `work-summary`（部门工作总结、工作计划、工作汇报撰写）；

+ `ledger-manage`（各类设计需求、项目、素材台账建立与更新）；

+ `meeting-minutes`（部门会议纪要、设计简报起草）；

+ `official-doc`（设计相关公文、沟通函件撰写）。
