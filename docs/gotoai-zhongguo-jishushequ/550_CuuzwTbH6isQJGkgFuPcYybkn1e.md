## 一、官方核心资源（教材编写首选）

### 1. 官方文档库（权威且完整）

+   **OpenClaw 中文文档**（https://openclawcn.com/docs/）

核心价值：**全场景学习路线+中文本地化覆盖**，按新手/进阶/深度路径组织，含安装指南、核心概念、渠道配置、国产大模型对接、Gateway 运维等模块。

教材适配点：可直接提取为**基础理论章节**，新增“国产模型配置实操”“企业级 Gateway 安全加固”小节。

+   **OpenClaw 官方文档中心**（https://docs.openclaw.ai）

核心价值：多语言覆盖+HTTP API 完整参考，含模型 Provider 指南、工具系统详解、术语表。

教材适配点：作为**开发者进阶章节**核心素材，补充 API 实战案例（如技能开发接口调用）。

### 2. 官方学习指南（结构化课程）

+   《OpenClaw 从入门到精通》（GitBook，https://yeasy.gitbook.io/openclaw_guide）

核心价值：**分角色学习路径+生产就绪模板**，覆盖个人/开发者/企业/架构师四类读者，含配置样例、故障排查检查单。

教材适配点：可直接改编为**教材主干**，补充华南企业（如汽车/制造）落地案例。

+   **小龙虾教程中心**（https://xiaolongxia.app/tutorials）

核心价值：**分课时结构化课程**，含“10分钟快速开始”“7天掌握 OpenClaw”“源码架构剖析”等模块。

教材适配点：提取为**培训课件大纲**，配套 step-by-step 实操步骤。
