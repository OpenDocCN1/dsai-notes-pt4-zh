
# AI+音频

> 来源：`https://gotoaiworld.feishu.cn/docx/UJmLd4W1soD0ZhxcVp7c7Iicnjb`

## 音频/AI音乐生成

1. Suno：音乐生成工具，旨在通过简单的文本提示生成高质量的音乐作品。它被称为“音乐界的ChatGPT”。`https://suno.com/`

2. Udio：人工智能音乐生成器，旨在让任何人都能轻松地创作出具有情感共鸣的音乐。`https://www.udio.com/`

3. 网易天音：AI快速编曲作词与编辑，一键DEMO，歌声合成。`https://tianyin.music.163.com/#/`

4. TME Studio：腾讯旗下。支持音乐分离，MIR计算（提取音乐的BPM、节拍调性，和弦进行等），辅助写词，智能曲谱。`https://y.qq.com/tme_studio/index.html#/`

## AI语音转文字/文字转语音

1. 飞书妙记：音视频转文字的效率工具，旨在帮助用户在会议、培训、访谈、课堂等不同场景中高效整理和记录音视频内容。`https://www.feishu.cn/product/minutes`

2. 讯飞智作：AI文字转语音、语音合成、智能配音、AI虚拟主播等。`https://peiyin.xunfei.cn/?utm_source=ai-bot.cn`

3. VoiceMarker：AI文本到语音生成工具。`https://voicemaker.in/`

4. Clipchamp：可以使用各种语言和口音的语言为视频创建免费的画外音，旁白生成器。`https://clipchamp.com/zh-hans/features/ai-voice-over-generator/`

5. Speechify：文字转语音朗读软件。`https://speechify.com/zh-hans/?landing_url=https%3A%2F%2Fspeechify.com%2Fzh-hans%2F`

6. 通义听悟：AI会议转录和总结工具，支持一键高亮要点、智能提炼总结、高效记录、整理和共享音视频内容。多种字幕，自动区分发言人，总结关键词，议程、摘要、代待事项和问题。`https://tingwu.aliyun.com/?utm_source=ai-bot.cn`
