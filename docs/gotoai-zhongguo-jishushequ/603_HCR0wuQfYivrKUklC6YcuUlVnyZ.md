> 来源：[https://gotoaiworld.feishu.cn/docx/GWKTdHAiYoDutcx7ZIlcmguynof](https://gotoaiworld.feishu.cn/docx/GWKTdHAiYoDutcx7ZIlcmguynof)

Learn to install Unsloth locally or online.

https://docs.unsloth.ai/get-started/install-and-update

Unsloth works on Linux, Windows, NVIDIA, AMD, Google Colab and more. See our system requirements.

Recommended installation method

Copy

```
pip install unsloth
```

**For uv**

Copy

```
pip install --upgrade pip &amp;&amp; pip install uvuv pip install unsloth
```

To update Unsloth

Copy

```
pip install --upgrade --force-reinstall --no-cache-dir --no-deps unslothpip install --upgrade --force-reinstall --no-cache-dir --no-deps unsloth_zoo
```
