# **官方核心资料**

1.  **Dify 中文官方指南**[dify-china.com：这是](https://www.dify-china.com/guide.html)入门的核心权威资料（https://www.dify-china.com/guide.html ）。内容覆盖平台核心功能、Docker 部署步骤、模型配置、工作流编排、智能体开发等全流程知识。不仅详细讲解了 OpenAI、Ollama 等主流模型的接入方法，还提供了工具集成、企业级安全配置等实操技巧，同时包含多模态能力扩展等进阶内容，适合系统搭建 Dify 技术体系。

1.  Dify GitHub/Gitee 开源仓库dify-china.com：作为开源项目核心载体，GitHub 仓库（https://github.com/langgenius/dify ）和 Gitee 镜像仓库（https://gitee.com/iafoot/dify ）可获取完整源码与部署脚本。仓库中docker目录提供一键部署的配置文件，examples目录包含各类应用示例；README 文件清晰列出安装命令、系统要求等基础信息。通过查看源码可理解平台架构，还能在 Issues 区获取常见问题解决方案，适配想从底层学习的学习者。

# **中文实战教程与博客**

1.  《Dify 构建智能体和工作流应用 零基础入门到精通》：发布于 CSDN 的保姆级教程，特别适合零基础学习者。内容从 Docker Desktop 安装开始，一步步教读者克隆代码、部署 Dify，还详细讲解了模型配置（含本地 Ollama 模型接入）。后续通过实战演示聊天应用、知识库、智能体的创建流程，比如搭建带必应搜索功能的新闻智能体，附带完整代码和操作截图，可直接跟着完成首个 Dify 应用开发。

1.  《升级 Dify 版本并修改配置文件突破单文件 15MB 限制》：CSDN 的实操技巧类文章。聚焦 Dify 知识库的常见痛点，讲解如何通过升级版本和修改配置文件，解决大文件上传受限问题。该教程可辅助学习者应对知识库搭建中的实际问题，还附带开源教材库链接，方便获取测试用的大体积 PDF 文件用于实操练习。

# **视频课程**

1.  《Dify 的 LLMOps 之路：零基础蜕变至大模型开发实战精英》：CSDN 程序员研修院的免费视频课程。课程从平台介绍、Docker 部署讲起，逐步深入模型配置、Prompt 工程、工作流编排等核心内容。包含小说创作工具、智能客服系统等多个实战项目，还讲解了 API 发布、自定义函数编写等拓展技能，适合偏好可视化学习的初学者系统提升。

1.  **B 站 Dify 实操系列视频**：B 站有多位开发者上传免费入门视频，比如《10 分钟部署 Dify 并搭建本地知识库》《Dify 智能体工具调用全流程演示》等。这类视频多以实操演示为主，步骤紧凑，搭配语音讲解，能快速掌握部署、知识库创建等高频操作，适合快速解决单点入门问题。

# **辅助学习与开源教材补充**

1.  **Dify 社区与讨论区**：GitHub 的 Discussion 板块和 Discord 社区，可与全球开发者交流问题。无论是部署时的容器报错，还是智能体协作逻辑问题，都能获取一手解决方案，同时可了解行业最新应用案例。

1.  **配套开源教材库**：若搭建知识库需要测试素材，可参考 GitHub[ 的 ChinaTextbook 仓库（htt](https://github.com/TapXWorld/ChinaTextbook/)ps://github.com/TapXWorld/ChinaTextbook/ ）。该仓库包含从小学到大学的各类 PDF 教材，可用于测试 Dify 的文档解析、知识库检索功能，适配知识库相关的实战练习。
