### 一、免费开源教材与实战手册

1.  《Neo4j 实战》（开源配套资料）：对应同名纸质书的 GitHub 开源仓库，包含书中所有案例代码和数据集。内容从 Neo4j 安装配置、Cypher 查询语言基础，到图数据建模、索引优化，再到 Java/Python 连接开发，覆盖入门核心知识点，代码可直接运行测试，适合边学边练。

1.  《Neo4j 3.x 中文入门手册》：社区开发者整理的开源中文教材，聚焦基础操作与实战。涵盖图数据库概念、Neo4j 桌面版使用、Cypher 语法详解，还有电影推荐、社交网络分析等经典案例，语言通俗，适合零基础且偏好中文教程的学习者，可通过 CSDN 或 GitHub 搜索获取。

1.  **《Graph Databases **for Beginners》（英文开源）：Neo4j 官方推出的免费入门电子书，官网可下载。以图文结合的方式讲解图数据库核心概念、Neo4j 架构优势，以及 Cypher 基础查询，搭配简单案例帮助理解图数据思维，适合快速建立对 Neo4j 的基础认知。

### 二、权威官方文档

1.  **Neo4j 官方入门教程**：官网地址[https://neo4j.com/de](https://neo4j.com/developer/get-started/)veloper/get-started/，是最权威的入门资料。提供分步指南，涵盖环境搭建、Cypher 查询、数据导入导出、应用开发等基础内容，支持选择不同语言（Python/Java 等）的开发案例，文档随版本更新，确保内容适配最新功能。

1.  **Cypher 查询语言官方手册**：地址[https://neo4j.com/docs/cy](https://neo4j.com/docs/cypher-manual/current/)pher-manual/current/，详细讲解 Cypher 语法规则、函数用法、查询优化技巧。包含大量示例代码，从简单的节点创建、关系查询，到复杂的路径分析、聚合统计，是学习 Cypher 的核心参考，入门阶段需重点研读。

1.  Neo4j Python 驱动官方文档：针对 Python 开发者的入门指南，讲解如何通过neo4j库连接数据库、执行 Cypher 查询、处理返回结果。包含完整的代码示例，比如数据插入、查询遍历等操作，适合已掌握 Python 基础，想快速实现 Neo4j 开发的学习者。

### 三、优质免费视频课程

1.  B 站《Neo4j 零基础入门到实战》：多位 UP 主（如 “尚硅谷”“黑马程序员”）提供免费课程，以尚硅谷课程为例，内容涵盖图数据库原理、Neo4j 安装配置、Cypher 语法精讲、实战项目开发（如电商知识图谱构建）。每节视频配有实时操作演示，步骤清晰，适合偏好可视化学习的新手。

1.  Neo4j 官方 YouTube 教程：官方发布的免费入门视频，包含 “Cypher 101”“Neo4j Desktop 使用” 等系列。讲解简洁直观，通过案例演示核心操作，适合搭配官方文档同步学习，同时可提升英文技术视频理解能力。

1.  **Coursera《Graph D**atabases with Neo4j》：可免费旁听的入门课程，由 Neo4j 认证讲师授课。内容从图数据库基础概念讲起，逐步延伸到 Neo4j 建模、查询优化、应用开发，案例贴近实际业务场景，适合利用碎片化时间系统学习。

### 四、入门实战资源与平台

1.  **Neo4j Sandbox**：官网免费在线实验环境（https://neo4j.com/sandbox/），无需本地安装。提供多个预设数据集（如电影数据库、北加州道路网络），可直接在浏览器中编写 Cypher 查询、可视化图数据，适合新手快速练习查询语法和数据操作。

1.  GitHub Neo4j 入门实战仓库：推荐neo4j-examples仓库（https://github.com/neo4j-examples），包含多个入门级项目，如基于 Python 的电影推荐系统、中文知识图谱构建案例。代码结构清晰，注释详细，可模仿学习从数据建模到查询开发的完整流程。

1.  Neo4j Bloom 可视化工具教程：Bloom 是 Neo4j 自带的可视化工具，官方文档和社区教程提供免费指导。通过拖拽操作即可生成复杂图数据可视化结果，适合入门阶段直观理解图数据结构和关系，辅助 Cypher 查询调试。
