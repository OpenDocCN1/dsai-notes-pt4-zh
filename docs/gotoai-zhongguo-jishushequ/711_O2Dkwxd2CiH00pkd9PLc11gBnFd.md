# IEEE Xplore

收录 2025 年 ICITCE 等会议论文，涉及工业技术与计算机工程中的 GPU 应用（如智能电网优化、边缘计算加速），并提供 GPU 架构相关的专利分析（如异构计算能效优化）。

# SIGGRAPH 与 GTC 大会

1.  SIGGRAPH 2025：NVIDIA 发布 Blackwell 架构的 RTX PRO 系列 GPU，展示物理 AI 与数字孪生技术，推动 GPU 在工业仿真和机器人领域的应用。

1.  NVIDIA GTC：全球顶级 GPU 技术峰会，2025 年预计将发布新一代 DGX 系统、CUDA-X AI 库更新及量子计算与 GPU 融合方案。

# arXiv 与预印本平台

实时追踪 GPU 架构前沿研究，如 2025 年发布的《Dynamic Tensor Core Scheduling for AI Workloads》探讨 Blackwell 架构的硬件调度优化，《OpenCL 3.0 在嵌入式 GPU 上的能效分析》提供开源生态的技术洞察。
