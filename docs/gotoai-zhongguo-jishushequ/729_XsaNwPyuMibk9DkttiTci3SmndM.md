#### AI-900：Azure AI 基础认证

**核心模块：**

1. AI 基础概念：机器学习、深度学习、自然语言处理等基础原理 learn.microsoft.com。
1. Azure AI 服务：认知服务（计算机视觉、语音识别）、Azure 机器学习、生成式 AI（Azure OpenAI Service）learn.microsoft.com。
1. 伦理与合规：责任型 AI 原则、数据隐私保护 learn.microsoft.com。

**备考建议：**

- 学习路径：Microsoft Learn AI-900 官方课程 learn.microsoft.com。
- 辅助资源：Udemy 模拟考试（240 + 题，含拖拽题和热点题）。

#### AI-102：Azure AI 工程师助理认证

**核心模块：**

1. Azure 认知服务：计算机视觉（Custom Vision）、自然语言处理（Text Analytics）、语音服务（Speech SDK）。
1. 生成式 AI：Azure OpenAI Service 的 GPT 模型调用、Prompt 工程、检索增强生成（RAG）。
1. 知识挖掘：Azure AI 搜索（Cognitive Search）、文档智能（Document Intelligence）。
1. 对话式 AI：QnA Maker、Bot Framework 的设计与部署。

**备考建议：**

- 学习路径：Microsoft Learn AI-102 官方课程。
- 实验要求：通过 Azure Portal 完成 15 + 个真实场景实验，如智能客服系统搭建。
- 实战工具：使用 Python SDK 和 REST API 进行端到端解决方案开发。

### 4、行业价值与职业发展

**薪资溢价：**

- AI-102 持证者平均薪资高于行业水平 20%，在生成式 AI 领域的薪资涨幅可达 30%。

**企业需求：**

- 金融、医疗、智能制造等行业优先录用具备 Azure AI 认证的工程师，尤其在 AI 解决方案设计和大模型部署领域。

**职业路径：**

- 基础认证（AI-900）→ 专家级认证（AI-102）→ 进阶方向（Azure 数据科学家、物联网 AI 解决方案架构师）。

### 5、关键注意事项

**考试更新：**

- 考试内容会随 Azure 服务升级调整，例如 AI-900 在 2025 年 5 月更新了生成式 AI 和 Azure AI 服务的最新命名 learn.microsoft.com。
- 建议考前 30 天通过 [微软认证更新页面](https://learn.microsoft.com/zh-cn/credentials/certifications/) 确认最新考试大纲。

**补考政策：**

- 未通过考试需等待 24 小时后可重新预约，12 个月内最多尝试 5 次，每次需重新支付全额费用 trainingsupport.microsoft.com。

**认证关联：**

- AI-900 是 AI-102 的推荐前置认证，但非强制要求。
- 持有 AI-102 证书可进一步考取 Azure 数据科学家认证（DP-100）或 AI 开发者认证（AI-204）。

通过以上信息，可系统规划 Azure AI 认证备考路径，结合官方资源与实战练习，有效提升认证通过率及职业竞争力。

### 本文档的目的

本学习指南应帮助你了解考试的预期内容，并包含考试可能涵盖的主题摘要以及指向其他资源的链接。本文档中的信息和材料可以帮助你在准备考试时集中精力学习。

### 考试更新

我们的考试会定期更新，以反映执行某一角色所需的技能。我们提供了两个版本的技能测评目标，具体取决于你参加考试的时间。

我们始终首先更新考试的英语版本。一些考试已本地化为其他语言，在英语版本更新后大约八周进行更新。虽然 Microsoft 会尽一切努力更新本地化版本，但有时考试的本地化版本可能未按此计划进行更新。其他可用语言列在“考试详细信息”网页的“安排考试”部分。如果考试不以你的首选语言提供，你可以请求额外 30 分钟时间来完成考试。

### 截至 2025 年 5 月 2 日

#### 受众概况

对你而言，此考试是展示机器学习和 AI 概念以及相关 Microsoft Azure 服务知识的机会。此考试的考生应熟悉考试 AI-900 的自定进度或讲师引导式学习材料。

该考试面向具有技术和非技术背景的考生。不需要数据科学和软件工程经验。但是，了解以下内容会让你受益匪浅：

- 基本云概念
- 客户端-服务器应用程序

Azure AI Fundamentals 可用于准备其他基于 Azure 角色的认证，例如 Azure Data Scientist Associate 或 Azure AI Engineer Associate，但这不是其中任何一个的先决条件。
