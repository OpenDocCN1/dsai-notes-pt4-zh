# 最新最全！奥特曼、马斯克、黄仁勋等18位AI领袖对大模型的预测金句

> 来源：[https://gotoaiworld.feishu.cn/docx/ZH81dqYjQoLI7QxwCLdcTQqnnfb](https://gotoaiworld.feishu.cn/docx/ZH81dqYjQoLI7QxwCLdcTQqnnfb)

> 在人工智能迅速发展的当下，众多行业领袖对其未来趋势和影响进行了预测和展望。这些预测不仅涉及技术层面的突破，也关乎社会、经济甚至哲学层面的深远影响。

**埃隆·马斯克（xAI）**

2024年4月他表示，新的人工智能模型最快可能在明年年底或2026年超越人类智力，这比他之前预测的2029年有所提前。

过去人工智能发展的主要制约因素是高性能芯片的缺乏，但这一限制正在得到缓解。未来一两年，人工智能发展的关键将是电力供应能否跟上。

**黄仁勋（英伟达）**

未来，全球AI产业规模将高达100万亿美金，比之前IT时代的3万亿美元高出33万倍以上，具有强大的市场前景。

未来10年，英伟达计划使深度学习的计算能力再提高100万倍。到那时，英伟达将实现持续学习，不再是现在这样先学习后应用的模式。

物理人工智能正引领AI领域的新浪潮，它们深谙物理定律，并能自如地融入我们的日常生活。为此，物理人工智能不仅需要构建一个精准的世界模型，以理解如何解读和感知周围世界，更需具备卓越的认知能力，以深刻理解我们的需求并高效执行任务。

**扎克·伯格（Meta）**

开源是解决AI安全问题的一个重要途径，因为它允许社区共同改进和部署AI技术。他透露，Meta有意开源其价值高达100亿美元的AI模型，但同时强调不会开源其产品，以保持竞争力和控制。

山姆·奥特曼（OpenAI CEO）

未来将有10到20个大语言模型在全球范围内“存活”并发挥重要作用，中国将会拥有自己独特的大语言模型。

米拉·穆拉蒂（OpenAI CTO）

GPT-3表现出与蹒跚学步的孩子相似的智力，GPT-4所展示的智力堪比聪明的高中生，未来几年，用于特定任务的“博士级智能”就会出现。

戴密斯·哈萨比斯 (DeepMind)

通用人工智能将在10年内实现，与人类的认知能力相匹配。

**杰夫·贝索斯（亚马逊）**

人类有很多方法可以让自己灭绝，人工智能可能会帮助我们避免这样做，它们实际上可能会拯救我们。

**桑达尔·皮查伊（谷歌）**

最佳的搜索形式应当是叙述性答案与其他网站链接的完美结合，为用户提供更深入的探索机会，而不是完全由聊天机器人主导。

**周鸿祎 (360 )**

2024年将会是大模型场景之年，To C场景将出现杀手级应用。

**李彦宏 (百度)**

智能体正在爆发，只是说它现在基数还比较小，大家的体感没有那么强烈。由于它门槛足够低，能够让更多人进来，大家发挥聪明才智，指不定哪条路跑通了，它就是一个Super APP。

**徐立（商汤科技）**

大模型本质上是在做一个记忆的事情，记住世界的知识。而它仅有的一点点智力，完全来自于对知识背后高阶的思维逻辑。所以在垂直行业里，如何构造高阶思维逻辑的合成数据，是制胜和差异化的关键，也是中国人工智能之路的关键。

**杨植麟（月之暗面）**

AGI（通用人工智能）最终会是一个跟所有用户co-work（协作）产生的东西。

从GPT-3.5到GPT-4，解锁了很多应用；从GPT-4到GPT-4.5再到GPT-5，大概率会持续解锁更多，甚至是指数型的应用。所谓“场景摩尔定律”，就是你能用的场景数量会随着时间指数级上升。

Sora马上可以用到视频生产过程中，但如果跟语言模型结合，就能把这个世界建模建的更好，就有可能打通数字世界和物理世界，比如自动驾驶或者一些家务，理论上都是打通物理世界。

**张鹏（智谱AI ）**

目前大模型在语言和文字能力上已经接近甚至略微超过人类的平均水平了，下一步是“脱虚向实”，就是不再局限于成为一个缸中大脑，让它能够走入到实际的生活和工作中去创造实际的生产力。

**陈剑毅（美图）**

AI视频技术将在未来几年内完成电影技术百年发展的蜕变，并在网文小说和教学内容领域初步实现商业化应用。

**马云（阿里）**

在工业时代人类是知识驱动，是知识的竞争，而在数字时代，人类将是智慧驱动，是创造力和想象力的竞争，是领导力、担当力、责任的竞争，是独立思考的竞争。

**任正非（华为）**

人工智能平台公司对人类社会的直接贡献可能不到2%，98%都是对工业社会、农业社会的促进。

**吴恩达（计算机科学家）**

AI是一种通用技术，像电力一样用途广泛，即使没有技术核心进展，世界各地都有很多用例等待被发现和构建。

在个人笔记本电脑或工业PC上运行的边缘AI的能力实际上比大多数人认为的要好得多，这将推动很多设备的销售。

当前人工智能的相关监管措施对防止某些问题产生几乎没有任何效果，反而可能阻碍技术的进步，更倾向于没有监管，而不是目前的低质量的监管。

**凯文·凯利（《连线》杂志主编）**

10年后，训练数据将不再重要。我们不需要数百万个数据就能拥有推理能力，AI的发展将超越当前对大量训练数据的依赖。这对初创企业来说是一个巨大的优势，因为他们不需要拥有所有这些数据。

未来AI可能与人类建立起深厚的情感纽带，类似于人与忠诚宠物之间的友谊。

95%的AI应用将变得隐形，广泛融入日常生活中，帮助人们在虚拟与现实世界中自由穿梭。

更重要的问题不是我们是谁，而是我们想成为谁，这是AI的终极魅力，它照亮了“我们是谁”的迷雾，也激励着我们该成为什么样的人。
