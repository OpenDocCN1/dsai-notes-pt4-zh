以下是一些AI智能硬件相关的技术社区、研究机构和Blog网站：

### 技术社区

+   **DeepSeek技术社区**：可找到志同道合的朋友，共同探索AI技术的奥秘。

+   **电子发烧友论坛**：面向电子工程师，提供电子资料、行业资讯以及交易对接，在智能硬件行业有一定专业性。

+   **极客迷**：DIY学习与分享社区，有科技、生活等不同频道，有不少智能硬件作品分享。

+   **筑梦创造**：致力于打造专业化的创客资讯分享平台，设有创客社区等栏目。

+   **雷锋网**：深圳的科技媒体，在智能硬件大潮中关注智能硬件，是大型智能硬件活动的主力参与方。

+   **点名时间**：中国最大的众筹平台，募集项目以智能硬件类为主，可发现潜力项目。

+   **MakerLab**：创客们的学习交流平台，提供产品、教程，也有开发板销售。

+   **雷科技**：专注智能生活和前沿科技的科技博客，提供智能硬件资讯、产品评测等，开展线下活动。

+   **戴客网**：可穿戴设备之家，提供智能手表、手环等产品的资讯、评测。

+   **面包板社区**：整合了多家知名媒体资源，为电子工程师和产业供应链人士打造的学习、分享、交流平台。

+   **EDA365电子论坛**：中国最大的互连设计专业论坛，有众多电子工程师、创客等用户，涵盖多个电子硬件方向。
