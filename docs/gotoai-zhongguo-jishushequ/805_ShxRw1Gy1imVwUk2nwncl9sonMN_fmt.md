## 1. AI绘图工具

### 1.1 Draw.io

`https://app.diagrams.net/`

![](img/979596bf4672363fecfcc59cac9fc90e.png)

使用 Draw.io + ScreenToGif 制作动态业务流程图并生成 GIF 的详细操作指南，结合搜索资源中的实用技巧和优化方案：

#### 一、准备工作

1. 工具安装

   - Draw.io：访问 `https://www.drawio.com/`，选择在线版或下载桌面客户端（支持 Windows/macOS/Linux）。

   - ScreenToGif：从官网（`https://www.screentogif.com/`）下载免安装版，解压后直接运行（需提前安装.NET 6 Desktop Runtime，若提示缺失可通过官网下载）。

2. 流程图设计基础

   - 在 Draw.io 中新建文件，选择「流程图」模板或空白画布，拖拽形状（如矩形、菱形）代表业务节点，使用连接器（直线 / 折线 / 曲线）连接节点表示流程方向。

   - 右键点击画布空白处，选择「选择边线」可批量选中所有连接线，方便统一设置动画效果。

#### 二、核心操作：在 Draw.io 中启用流动动画

1. 基础动画设置

   - 启用流动效果：选中需动态展示的连接线，右侧「样式」面板勾选 `Flow Animation`，立即看到虚线从起点向终点流动的效果。

   - 参数调整：

     - `Flow Duration`：数值越小流动速度越快（默认 500ms，建议复杂流程设为 800-1000ms）。

     - `Flow Timing`：选择动画缓动效果，如 `Ease In`（渐入）或 `Linear`（匀速），避免突兀。

     - `Flow Direction`：支持 `Normal`（正向）、`Reverse`（反向）、`Alternate`（来回交替），可模拟数据往返流程。

2. 高级动画技巧

   - 分阶段动画：若需多组线条按顺序流动，可通过「选择→右键→排列顺序」调整图层，配合 ScreenToGif 的分屏录制实现分步动画（如先录制 A 线条流动，再录制 B 线条流动，最后合并帧）。

   - 动态颜色变化：在「样式」面板中为连接线设置 `Stroke Color` 渐变，配合流动动画可增强视觉引导（如红色→绿色表示流程状态变化）。

#### 三、录制与导出：用 ScreenToGif 生成 GIF

1. 录制参数优化

   - 区域选择：打开 Draw.io 流程图，调整窗口大小至内容完整显示，避免录制多余空白。在 ScreenToGif 中点击「录像机」，拖动边框框选流程图区域，或按快捷键 `Ctrl+Shift+F` 全屏录制。

   - 帧率设置：

     - 简单流程：15-20 FPS（平衡流畅度与文件大小）。

     - 复杂动画：25-30 FPS（减少卡顿，但文件体积增大）。

   - 快捷键控制：按 `F7` 开始录制，`F8` 停止，支持中途按 `F7` 暂停调整画面。

2. 编辑与导出

   - 剪辑冗余内容：录制完成后进入编辑界面，点击时间轴上的帧缩略图，按 `Delete` 删除无效片段（如录制开始前的等待画面）。

   - 调整播放速度：选中需加速的帧，点击「编辑→延时」，输入更小数值（如将默认的 66ms 改为 40ms）；若需减速则输入更大数值。

   - 导出设置：

     - 循环次数：选择「无限循环」或指定次数（如 3 次），避免过长导致卡顿。

     - 颜色优化：勾选 `Remove Duplicate Frames`（移除重复帧）和 `Optimize Colors`（优化颜色），文件体积可减少 30%-50%。

     - 格式选择：优先导出为「GIF (Animated)」，若需更高压缩比可尝试「AVI→转 MP4」（需第三方工具如格式工厂）。

#### 四、进阶技巧与优化方案

1. 文件大小控制

   - 动态逻辑简化：避免所有线条同时流动，按业务阶段分批次展示动画（如审批流程可分「提交→审核→通过」三阶段），每阶段录制后合并帧。

   - 画质与体积平衡：在 ScreenToGif 导出时，将 `Quality` 设为 60%-80%，颜色数限制为 128 色，文件体积可压缩至原大小的 1/3，且肉眼几乎察觉不到画质损失。

2. 兼容性增强

   - 背景透明处理：在 Draw.io 的「文件→属性」中勾选「透明背景」，导出时 GIF 背景与网页 / PPT 等载体无缝融合。

   - 移动端适配：录制区域宽度不超过 640px，避免在手机端显示不全；导出前使用🛰️ / 钉钉等工具预览，若出现模糊可尝试将帧率提高至 25 FPS。

3. 多工具协同

   - 动态 SVG 过渡：若需更高精度动画，可在 Draw.io 中导出动态 SVG（勾选 `Include animations`），通过 Lively SVG 工具进一步调整路径动画参数后转为 GIF。

   - 字幕与注释：在 ScreenToGif 编辑界面点击「文本」工具，添加白色描边字体标注关键节点（如「步骤 1：数据采集」），增强可读性。

#### 六、示例操作流程

1. 设计采购审批流程图

   - 节点：「提交申请→部门审核→财务复核→采购执行→归档」。

   - 动画设置：连接线按顺序启用流动效果，`Flow Duration` 设为 700ms，`Flow Timing` 选 `Ease Out`，`Flow Direction` 设为 `Normal`。

   - 颜色区分：审核节点用红色连接线，通过后变为绿色。

2. 录制与导出

   - 录制区域：框选流程图主体，排除左侧形状库和顶部菜单栏。

   - 帧率设置：20 FPS，录制时长约 8 秒（5 个节点流动各占 1.6 秒）。

   - 导出参数：循环 3 次，颜色数 128，质量 70%，最终文件约 1.2MB。

通过以上步骤，可快速生成专业级动态业务流程图，适用于培训课件、项目汇报、技术文档等场景。关键在于合理规划动画节奏，平衡视觉效果与文件性能，必要时结合分阶段录制和后期剪辑实现复杂动态逻辑。
