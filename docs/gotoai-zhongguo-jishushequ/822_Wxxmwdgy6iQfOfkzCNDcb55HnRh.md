
# 专科院校 + 计算机科学与技术专业学生12个月成长计划

> 来源：[https://gotoaiworld.feishu.cn/docx/FIT7dwGXPou49IxsJ49cvuDQnKg](https://gotoaiworld.feishu.cn/docx/FIT7dwGXPou49IxsJ49cvuDQnKg)

## 一、规划总览

+   **目标岗位**：大模型运维技术员、轻量化部署工程师、AI 数据处理工程师、Prompt 工程师（初级）

+   **核心能力**：`Python` 实用编程、数据标注与清洗、轻量化模型部署、低代码大模型应用开发

+   **薪资预期**：应届生 8-15K（一线城市）、3 年经验后 15-25K（可转型大模型应用开发岗）

## 二、分月学习规划表

### 第一阶段：基础技能入门（1-3 月）

| 月份 | 学习重点 | 实战项目 | 技能认证准备 |
| --- | --- | --- | --- |
| 1 月 | 1. `Python` 基础（变量 / 函数 / 循环、文件操作）2. 数据处理工具（`Pandas` 基础清洗、`Matplotlib` 简单可视化）3. 办公自动化（Excel 数据处理、PDF 解析） | **数据整理小工具**：开发 “简历信息提取器”，批量解析 PDF 简历并生成 Excel 统计表（技术栈：`PyPDF2`+`Pandas` + 正则表达式，日均处理 500 份以上） | 1. 注册 `GitHub` 账号，掌握基础提交 / 分支操作。开始 Codecademy “`Python` 入门” 免费课程 |
| 2 月 | 1. 数学基础（矩阵加减乘除、概率基础概念）2. 机器学习常识（分类 / 回归任务认知、模型输入输出逻辑） 标注工具使用（`LabelStudio` 文本 / 图像标注、`Prodigy` 基础） | **多模态数据标注项目**：1000 条 “文本意图 + 图像目标” 标注任务，制定标注规范文档：客服对话文本、电商商品图，标注准确率≥98%） | 1. 推进 “`Python` 入门” 课程至结业 2. 准备 `Python` PCEP 认证（侧重基础语法与数据处理） |
| 3 月 | 1. `Linux` 常用命令（文件管理、权限设置、进程查看）2. `Git` 基础操作（克隆 / 提交 / 冲突解决）. 大模型 API 认知（`ChatGLM` / 文心一言 API 调用流程） | **API 调用演示工具**：“多模型问答对比器”，输入问题同步调用 3 个开源模型 API 并展示结果：答案对比、响应速度统计、历史记录保存） | 1. 完成 PCEP 认证考试 2. 注册 `Hugging Face` 账号，熟悉模型下载流程 |

### 第二阶段：核心能力攻坚（4-6 月）

| 月份 | 学习重点 | 实战项目 | 技能认证准备 |
| --- | --- | --- | --- |
| 4 月 | 1. 数据工程基础（数据去重 / 降噪、标注质量检查）2. 轻量化模型认知（`MobileBERT`、`TinyLlama` 等小模型特性）3. `Hugging Face` 基础（模型加载、简单文本生成） | **标注质量检测工具**：开发 “标注错误识别器”，自动检测文本标注中的实体漏标 / 错标问题技术栈：`Pandas` + 规则引擎，错误识别准确率≥85%） | 1. 学习 `Hugging Face` “模型入门” 官方教程。了解 AWS “AI 数据处理” 认证基础模块 |
| 5 月 | 1. Prompt 工程基础（指令设计、格式规范、少样本提示）2. 向量数据库入门（`Chroma` 本地部署、数据插入与查询）. 低代码工具使用（`Dify` 平台应用搭建） | **本地知识库问答工具**：基于 `Chroma`+`Qwen-1.8B`，搭建 “计算机基础问答系统”：PDF 上传、语义检索，响应时间≤2 秒） | 1. 完成 `Hugging Face` “Datasets 库” 实操课程2. 准备 `TensorFlow Lite` 开发者认证（侧重轻量化部署） |
