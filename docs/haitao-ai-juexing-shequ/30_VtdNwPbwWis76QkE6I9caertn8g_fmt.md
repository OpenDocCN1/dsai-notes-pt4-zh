
# 脆皮年轻人，自创五音疗愈视频火了

太有创意了，有小伙伴给我发了这样的视频，古人五音疗.愈，节奏感音乐搭配古代跳舞的视频，是不是和前些时间爆火的“回答我”似曾相识，古人+音乐+YS也是最近出圈的秘籍。连央妈也进行了转发，侧面说明了大家对健康的重视。

之前案例多是使用Coze工作流搭建难度有点大，今天我们尝试用Kimi+即梦+剪映实操复刻一下，新手小白也可轻松制作。

## 生成图片

首先找几个对标案例，直接截图去问Kimi。

![](img/e5b466b8410180ae7f84fc4a52c2b700.png)

参考Kimi给的结果我们总结出绘画提示词，并到即梦AI进行生图，选择符合要求的图片保存下来。

没有即梦额度的也可以直接使用我下面的绘画智能体进行调试，白嫖Coze每天免费的额度。

绘画智能体：`https://www.coze.cn/store/agent/7490927150757871635?bot_id=true`

```
一群中国古代人演奏音乐，欢快的场景，搭配乐器等元素，全身照、工笔画风格
```

![](img/526fd29f45b2f8a95b02d10141267361.png)

## 图生视频

使用即梦AI，选择图生视频，上次生成好的图片，填写提示词。

```
一群人在欢快的演奏音乐，身体跟着节奏跳动
```

![](img/ca468fc5b09b9653002908e719368ec3.png)

也可以使用海螺AI，将图片转换为视频，每天也有免费的使用额度。

![](img/34ebd38af55b337f2968ef8965fb1f0f.png)

看下最终生成的视频效果。

![](img/2f165014bbe1ba568a19b57174a5ad81.png)

## 剪映剪辑

然后打开剪映，导入生成好的视频素材，选择合适的配乐，二次剪辑后导出。
