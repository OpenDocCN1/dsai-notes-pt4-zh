# 使用说明

1.  **简介：**

这里是 [🚩河林的个人说明书](https://jid6vvjfdm.feishu.cn/wiki/wikcnWNsxWnlGFWJkKZS6kmTPfc)知识空间，你可以通过我的个人说明书了解我

1.  **整理目的：**

我把对我有长期价值的思考碎片整理在这个知识库里，用来梳理我的个人知识体系。

1.  **整理原则：**

+   绝不记录搬运、抄袭、剪藏的内容，每一篇记录均是自己重述、思考、发展之后的想法。

+   知识库的写作原则是真诚的自我剖析，以认识并面对自己为首要目的。

+   内容来源于我在flomo中记录的笔记，发在即刻上的闪念，记录在朋友圈的碎碎念等等。

+   对于启发我输出的明确输入源，我会在文档中标注出处。
