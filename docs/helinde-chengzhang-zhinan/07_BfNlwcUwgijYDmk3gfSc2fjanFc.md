# 直播：请嘉宾直播时需要避开的坑

> 来源：[https://my.feishu.cn/docx/FM7ed3evroCw3Wx7TPxcPnbYnsg](https://my.feishu.cn/docx/FM7ed3evroCw3Wx7TPxcPnbYnsg)

视频号直播的一个坑：

所有要找品牌方的产品专家、课程研发老师、课程讲师等专家来合作带货或者卖课的直播，都一定要小心。

因为不是所有的专家老师都适合直播！！！一定要划重点！

不是说专家老师不优秀的意思，而是：

①专家、老师们，一定是非常优秀的业务人员，但是不一定适合口头表达；

②专家、老师们，介绍自己的产品的时候，容易陷入产品视角，而缺乏用户视角，说出来的话用户听不懂、不关心、不感兴趣

③专家、老师们，介绍自己的产品的时候，很容易陷入自嗨，一张口就滔滔不绝，区分不了重点，主播不打断，根本停不下来。

④如果控制不好干货分享、产品转化、逼单促单的比重和节奏，找不到机会卖货、促单的话，产品转化就很难上去。

所以要明确，我们请专家老师来直播的目的到底是什么，想要发挥什么样的效果，在前期一定要和嘉宾沟通好自己想要达成的效果和期望的实现方式，态度要积极，把主动权牢牢把握在自己手里。

直播运营、主播要和嘉宾核对好这4点：

1.不要沉溺于细节知识的讲解，而是要讲可观察到的直观效果

2.控制所谓干货内容的比重，要面向用户视角，加一点能调动用户情绪的“湿货”

比如可以从专家视角讲，有多少用户用了我们的产品之后，给到的好评反馈多么感人，一下子就成了忠实老粉用户，一用就是好几年

比如在研发过程中，有什么不为人知的小故事，让这个产品比别的产品更厉害

3.用户们都喜欢听故事，要发挥自身优势，给用户上价值

4.把嘉宾的价值放大化，凸显产品的优惠

比如，嘉宾老师平时一节课要几千块，今天我们的产品，100节课算下来还不到3000块，拿便宜几十倍的价格，上专家的大师课！

5.该逼单促单的时候，一定要配合主播，把控场的决策权交给主播

直播运营只有做到这几点，才算是能做好一场配合成功的嘉宾直播专场。
