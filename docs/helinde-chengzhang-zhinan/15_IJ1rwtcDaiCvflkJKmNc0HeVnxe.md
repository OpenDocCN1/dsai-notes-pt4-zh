**我的笔记：**

抖音的流量来自算法推荐，提高流量概率的方法是矩阵化。

🛰️团队的产品观：基于底层社交逻辑出发

+   社交=账号+关系+内容

+   关系？🛰️的4层关系：推荐、搜索、订阅、社交。

+   账号？🛰️建立了4种账号：🛰️、🛰️群、👸号、视频号。

+   内容？**单图文（私聊、群聊、朋友圈）、复杂图文（👸号）**、音频（视频号）、短视频和直播（视频号）。

🛰️的流量来自于场景矩阵。

+   私域：私聊、群聊、朋友圈；

+   公域：**看一看（👸号）、听一听（音乐音频）、搜**一搜、问一问（问答社区）、短视频、直播间。
