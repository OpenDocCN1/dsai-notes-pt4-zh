# 内容：对把产品功能外化的思考

> 来源：[https://my.feishu.cn/docx/doxcnVt6IpC6MTBqdDQ9NaG4Abe](https://my.feishu.cn/docx/doxcnVt6IpC6MTBqdDQ9NaG4Abe)

从产品体验设计的角度来讲，我们要尽可能地把产品价值外化、显现出来，让用户相信并且能实际体验到。

但无叶风扇这一品类的产品，在把风力外化这方面天然是有缺陷的，因为它天生缺少“视觉”层面带来的刺激，你很难在使用无叶风扇的时候有一种“它正在正常运转、风力很强”的安心感。

或者说把2款风力相同的风扇放在一起，一款有叶，一款无叶，用户也很容易出于心理原因觉得无叶风扇的风力“没那么强”。

这好像也不能说是产品品类本身的问题，因为无叶风扇被设计出来，显然是为了解决其他痛点：比如空间占用、产品体积过大、有叶风扇的安全隐患等等问题；

但是在风力感观方面，从产品体验的角度来讲，无叶风扇似乎天然处于劣势。

而相对的，电动牙刷在功能外化上就比普通牙刷有明显的优势。
