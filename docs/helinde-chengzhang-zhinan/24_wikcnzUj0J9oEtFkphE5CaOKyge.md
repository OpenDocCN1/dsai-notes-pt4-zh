
# 内容：写文案最忌讳自嗨

> 来源：[https://my.feishu.cn/docx/doxcntyBObqw8sq2OwURvHW1Bkb](https://my.feishu.cn/docx/doxcntyBObqw8sq2OwURvHW1Bkb)

写文案，最忌讳的就是自嗨。

自嗨就是自己觉得很爽，然而用户无动于衷。要从用户视角出发，就需要时刻问自己这几个问题：

1. 用户很忙，ta为什么要看你的文字？
2. 用户很难说服，这个世界上那么多骗子，ta为什么要信任你？
3. 用户很累，你都要ta来做决策了，为什么还要ta来动脑子？
4. 用户很穷，ta为什么要花钱买你这个产品？
