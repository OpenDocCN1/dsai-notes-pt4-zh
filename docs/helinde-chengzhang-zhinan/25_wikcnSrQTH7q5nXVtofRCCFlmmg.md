# 内容：姜dora对自己的内容创作的思考

> 来源：[https://my.feishu.cn/docx/BnBQdOYfPohW5VxG0ezcSViTnLb](https://my.feishu.cn/docx/BnBQdOYfPohW5VxG0ezcSViTnLb)

2023/5/1

这一篇是我听这一档播客的笔记：

dora的偏见：

B站目前是对内容质量最高的平台，B站能爆的内容在各个平台大概都可以爆。

dora的slogan：

+   为-1到5岁的职场人提供精神力量和解决方案。

+   16-25岁左右的互联网原住民，是传播最主力的人群，想要爆款就得靠这些人群的推动。

dora的商业模式：

+   服务好大面积的C端群体后，向B端收钱。

+   一个朴素的逻辑是找到谁给你钱，要为对你掏钱的人负责和忠诚。

+   知识工作是非劳动密集型的，很难被替代、很难被外包的，高度依赖一两个人的产出。

+   赠送全平台的资源包分发，体现出自己的竞争优势。

dora：

面向C端持续收钱，是对IP的“提现”，但是持续分享优质免费内容，是对IP的“积累”和“储蓄”。

dora：博主到底挣什么钱？

+   影响力

+   产品

+   商品

做博主前的建议？

1.  不要被做博主这个词给迷惑了，真正的目的是要挣钱，而一个能挣钱的博主，就要拥有好的销售能力，和好的制作产品、课程的能力，这些都是dora的经验给她带来的积累。

1.  要做博主，一定要在自己的优势领域内做加成，用自己擅长的方式做成自己想做的事情。

做不好内容，肯定也做不好直播；直播只是配菜。

dora：

做内容IP的人，就是要不断复现自己生命中的闪光时刻、流星时刻。

dora的第一性原理：

1.职业为本：做任何事情都要带着职业精神去认真对待，不能敷衍。

2.理解自己：了解自己是一个什么样的人，生命中的什么时刻是闪闪发光的

3.理解运营
