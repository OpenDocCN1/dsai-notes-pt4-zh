# 品牌为什么要去找一家营销咨询公司？

> 来源：[https://my.feishu.cn/docx/UIpHdmnthodVBvxVBVhcwn2Wn0d](https://my.feishu.cn/docx/UIpHdmnthodVBvxVBVhcwn2Wn0d)

这一篇是对播客《[读书笔记：小马宋《营销笔记》](https://jid6vvjfdm.feishu.cn/wiki/wikcnkNPSDfRdLnD3jBvKrPHEae)费圈内人 VOL.1 品牌真的需要营销咨询吗？》的笔记，嘉宾是小马宋营销咨询公司的枪上花老师，可以结合小马宋的书《营销笔记》一起看 。

营销咨询：帮助企业更好地传递它的价值。

选择客户的指标：有钱就接

营销咨询方案是定制化的产品，而不是标品；问题在哪，解决方案就在哪。

+   调研分析

+   产出

+   落地

品牌凭什么要找一家营销咨询公司？

+   精力人力不足：老板不可能亲力亲为，公司内部的部门也存在人力局限，所以有一部分工作有外包需求，让营销咨询公司去投入更多的工作量，去做更深度的工作。

+   企业也需要外部视角

餐饮行业的竞业规定：没办法完全避开，但是会对企业信息保密。

餐饮行业最关键的点：

+   营销不是核心，产品复购才是核心。

+   成本能不能降低、产品能不能好吃、能不能做出利润。

营销咨询的效果如何评估：

+   回报周期很长，很难短期看到回报

一线有神明：

+   营销咨询很多收获和增量信息都来自于现场；

why小城大店、大城小店？

+   小城能娱乐的地方很少

消费者任务理论：用户买你的东西不是为了商品本身，而是为了解决他在生活中的

某个问题。

——出自《与运气竞争》

由消费者任务理论引申出的对营销的启示是：在做调研的时候，应该关注你的产品在解决消费者的问题中扮演了什么样的角色。

基于这个视角，就可以从产品经理的视角，去设计方案，解决用户的问题。

决定营销方案好坏的最主要的要素：

结合企业的禀赋，用长板去解决问题。

营销是一个放大器，企业是需要一整套经营活动，才能把事情做成的，不是靠单纯的营销去做起来的。

营销咨询是奢侈品消费。

少看方法论：

真正有效的方式是去看大量的客户，从问题中找实际的解决方案，而不是去发明和迷信各种营销概念、理论、名词；方法论是抽象的，但是每个方法遇到的背景、问题、条件都不一样。

乙方的杠杆就在于能看到大量的客户，能吸收他们的经验。
