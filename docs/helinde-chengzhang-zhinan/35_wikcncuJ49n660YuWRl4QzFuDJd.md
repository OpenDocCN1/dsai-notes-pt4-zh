# 运营人：从打杂工到操盘手

> 来源：[https://my.feishu.cn/docx/doxcnh86APmdABhTH6GaWFQFPif](https://my.feishu.cn/docx/doxcnh86APmdABhTH6GaWFQFPif)

[运营人，从打杂工到操盘手。](https://mp.weixin.qq.com/s/4mR38usKdIYCyM47wnG0tA)

看了老黄的这篇文章，总结下我的收获：

运营人，从打杂工到操盘手，为什么这么复杂？

因为运营贯穿了公司业务始末，从起点的流量端，到终点的商业化，实现成交，都由运营链接，形成闭环。

所以理解运营，本质上离不开一家公司业务的整体架构，这也是为什么不同公司的运营岗位设置千差万别，甚至同样名字的运营岗位，干的事情有时候也完全不同。

但是，运营终究还是有底层规律的，微观层面的运营一般包含四要素：

用户、业务目标、工作场景、核心工作手段。

起点都是用户，终点都是业务目标，工具是场景和工作手段。

逻辑上串联整个流程的，是数据分析和数据漏斗。

归根结底，所有运营工作的导向，都是为了让用户与产品产生联系。

最终而言，运营就是一个要上下贯通的岗位，向下从微观角度要修炼各类专项能力，向上从宏观角度要思考企业如何跑通整体业务。

它是一个跑通一整个业务闭环的能力。

运营复杂之处就在于，向下的微观角度要处理大量琐碎的事情，全面拓展各项专项能力，而只有在微观修炼到一定层级之后，才能够向上突破，这一层是锁死很多运营人的一个范围；

而微观突破之后，就需要向上宏观延伸自己的业务视角，打造跑通整个业务闭环的能力，也就是所谓的操盘手层级，这一层又是完全不同的视野。

而现实业务中，微观和宏观的两条线，界限并不是严格分明的，大部分都是要同时并行的。

这就是对运营的考验之处了：

要有综合能力和专业素养；

要有微观技能和宏观视野；

要能够上下贯通、打造闭关的业务能力；

当然，并不是说所有运营都必须要做到这些，才是一个好运营，而是说这是一个优秀运营的努力方向，能达到这样的要求的人，绝对是一个优秀的超级运营了。
