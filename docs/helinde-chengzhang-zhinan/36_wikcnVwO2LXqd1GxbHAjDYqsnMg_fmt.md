
# 工作留痕的重要性

> 来源：`https://my.feishu.cn/docx/doxcnonNMNimL11D6mmyA7EOoNc`

## 职场新人常见错误

职场新人，最容易犯的错误是什么？

1. 因为对流程不熟悉，而在工作流程、关键环节、关键信息上出现失误；

2. 因为对工作不熟悉，而在事项确认、工作分工上领会意思不到位，自己失误或者被老员工套路；

工作失误，和低级错误，都会影响到自己实习期、试用期的评价，严重的，还可能造成公司事故。而能够避免踩坑，避免犯错的关键一招就是：工作留痕。在需要确认的事情上，及时留痕，确保你按照共识去执行，而不是跑偏了；在需要你去操作的事情上，及时留痕，事后追溯起来，你有证据可以保护自己；

## 工作留痕的重要性

工作留痕的重要性就在于：

1. 保留证据，回溯追责的时候有依据；

2. 还原过程，便于及时复盘，还原来龙去脉；

3. 保存信息，规避因自己的遗忘、失误而犯错的可能性；

4. 确认共识，提高整体工作的效率；

## 如何做好工作留痕

那么怎么做好工作留痕呢？具体执行的时候，可以注意做好这几件事：

1. 会议纪要同步共识。会议之后，一定要同步会议纪要；如果没人写，就提出来这个问题；会议都是时间短、事项多、人数多的，每个人的认知可能有所偏差，会议纪要就是为了凝聚共识、同步结论，避免认知偏差带来的风险；

2. 项目邮件同步进展。项目取得关键进展或者有关键变化的时候，要发邮件向项目协同方同步；

3. 工作群内检查操作。在只有你个人执行而且无法回溯的关键操作上，把每一步的关键信息截图保留，并发群内确认检查、同步信息；

4. 工作软件沟通确认。关键任务，最好在工作软件上询问并确认内容，阐述清楚自己的理解，询问对方的意图；避免因口头表达的局限性带来的问题；做好工作留痕四个字，是一个职场新人保护自己、提高效率、认真工作的一大利器。
