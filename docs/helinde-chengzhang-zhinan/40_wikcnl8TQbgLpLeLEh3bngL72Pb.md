# 工作的对接方，职级越高，你越不要怯场

> 来源：[https://my.feishu.cn/docx/doxcnQJluUORKsYFd8UmGmVIX5e](https://my.feishu.cn/docx/doxcnQJluUORKsYFd8UmGmVIX5e)

这几天业务部门的一个领导一直私戳我，向我表示不满，觉得我作为资源方没有给她们部门的产品提供足够的资源位，他们的销售指标压力很大，需要我多排一些流量给他们。

对方职级很高，title是运营专家，比我高出了至少三级。

而我应对的思路也很简单：

首先不卑不亢地表明我的态度：我之前怎么做的，接下来依然会怎么做，但是我会阐释清楚我这么做的依据，把我的视角下对方业务存在的问题和我们资源方的决策依据重述一遍。

我的原则一直不动摇，不论你职级多高，如果你不能给我提供足够说服我的依据，我依然是不会继续改变我的结果。

换句话说，我就是要考验你能拿出多少诚意和说服力。

我为什么敢这么做？因为错的是对方，而不是我，对方的流程就不合理。

所有的资源位对接都是我和对方部门的与我同级的同学确定的，双方之前达成了一致；如果要有变动，那么也应该是那个和我同级的同学先来找我，而不是你这个运营专家。

如果有问题，就应该在当时提出来，而不是发现目标很难完成之后，再来找我们要位置；

如果你无法提供新的充分的依据，说服我去改变我之前的运营规划，即使你职级再高，也没有半点作用。

这也是我想和大家说的，尤其是一些职场上的新同学一定要知道这一点。

对方职级越高，越亲自找你，就越说明是ta的问题，说明他们内部没有能力在这之前就把问题给处理好。

如果对方的高级领导来找你，就说明她的下属，也就是和我同级的部下并没有达到自己的工作目的。

那么这次沟通就不仅是对方考验你，也是你考验对方的机会。

如果对方的处理方式越高明，那么就欣然接受，服务好双方的共同利益，也给对方留下一个好印象，表明一个良好的合作态度。

如果对方的处理方式让你感到压力，让你感到不适，那么一定是对方的问题。越是这种时候，越需要坚持自己的原则，不要动摇自己的底线。

如果对方的高职级领导说几句话，就能让你推翻之前的运营决策，那么你的岗位也就没必要存在了。
