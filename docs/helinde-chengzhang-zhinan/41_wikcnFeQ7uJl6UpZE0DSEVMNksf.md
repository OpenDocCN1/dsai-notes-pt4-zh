# 使用即刻几个月后的感受

> 来源：[https://my.feishu.cn/docx/CmccdVJMQoePVaxVZJscF0FTnIc](https://my.feishu.cn/docx/CmccdVJMQoePVaxVZJscF0FTnIc)

用了即刻好几个月了，想从【关注机制】和【圈子信息】这2点，说一说自己用即刻体验上比较好的地方。

1.当我在即刻关注一个人，不是为了吃瓜和热点，而是基于信任和好奇。

能让我产生这种关注行为，很大的原因是即刻本身积累了非常好的用户资产，以及整体的社区氛围会以记录生活+信息输出为主。

2.即刻会在动态首页把【我关注的人最近新关注了这些人】推送给我。

这种推荐机制减少了我关注用户和筛选信息源的精力，也会让我觉得在一定程度上弥补了信息差，和我关注的人保持了同频。

3.也因为这种关注机制，粉丝基数（或者在圈内的影响力）大的关键用户关注了你，就成为在即刻里获得强曝光和快速涨粉的一种方法，很多用户应该都有过这种经历。

4.基于兴趣爱好和职业身份设立的用户圈子，聚集了很多优质信息。

也因为即刻本身用户体量、用户画像以及之前的社区发展历程的原因，即刻的圈子划分能够相对垂直、细分。

在这样不同的圈子内，因为有高频的交流和讨论的积累，所以比别的平台更容易聚集各自领域的优质、前沿的信息。

典型代表之一当然就是「AIGC探索者」这个圈子，以及之前的web3相关讨论。

5.关注推荐+圈子讨论的机制，让同频的人构筑起了各自维度上的同温层，营造出一种“志趣相投的人一起做事情”的感觉。

最近大家很多人在提的“让AIGC洪流先发生在即刻”以及瓦总发起的 #AIHackathon 活动，就是这种氛围的最好的体现。

6.我很喜欢即刻的yellow page，是一个我觉得很有新意的功能，之前还写过一条粗浅的分析贴。

而实际上，在决定是否要关注一个人的时候，我相信很多人都和我一样，看的不是ta的yellow page，而是ta的【简介】和【置顶帖】。

在即刻有一种很容易涨粉的动作就是：把自己在即刻的多条优质输出，用链接+索引的形式整合在一条即刻里，然后分发或者置顶。

这样的一条「即刻串」很多时候是能比 yellow page 得到更高的曝光和点击的，转粉效果也更好。

对我的启示当然是要多输出优质内容，争取能攒出一条这样的「即刻串」

纯个人主观碎碎念，不一定对。
