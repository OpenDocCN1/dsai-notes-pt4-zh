
# 2023年的消费趋势观察

> 来源：[https://my.feishu.cn/docx/HmCSdnfHWokKADxA3uecJhJjn3e](https://my.feishu.cn/docx/HmCSdnfHWokKADxA3uecJhJjn3e)

2023/4/16

最近在关注一些2023年的新消费趋势，看了几个报告，很有意思。

淘宝去年年底发布了一份《淘宝2023兴趣消费报告》，里面总结了12种2023年可能从小众转变为主流的消费趋势：

微瑕拾荒捡漏、单向奔赴养宠、轻断网、仿真当妈、心流手工、极客养植、日抛变美、中式美学炫饭、小家养颜、科技整活、五感疗愈、华流混搭

《新榜2023消费趋势报告》报告里也总结了2023年可能的11种消费趋势：

季节潮流仪式感、情绪治愈、高质量美护、精致懒宅、户外风、反向旅游、人间清醒式购物、硬核养生、单人乐活、看颜值不分性别、人宠共生。

能看到①精致自在的单人生活（个人消费+独居空间），②现代人的五感疗愈和情绪治愈，都成为2份报告里共同提及的消费品类。

报告上提到的很多消费机会，有许多可能非受众的群体是完全无法理解的，也有许多在现在看来仿佛已经过气（比如围炉煮茶），被认为是精致包装的伪需求和商家营销的噱头。

但我自己看了几份报告之后，还是有些启发的，给我的启发在于，作为营销人需要做的，可能并不在于抄答案，去看哪一个细分品类有机会然后去all in或者模仿，而是在于退一步，不带成见的去看待每一个细分的消费趋势，为什么会成为趋势。

综合下来，我感觉后疫情时代消费者们的购物心理有这么几个可以捕捉到的特点：

1. 不趋同，不想向主流（传统）价值观和审美导向献媚。

2. 重视在自己的小空间自娱自乐，打造小天地。

比如宠物生活、小家养颜、收纳整理。

3. 经济实用主义，追求性价比。

不一味迷信大牌和新品，愿意挖掘二手、古着的魅力。

4. 追求情绪价值的满足，通过五感疗愈来解压。

寄托于用自己喜欢的方式来消费，来满足自己的精神需求，追求背后的价值体验、情绪收获。

关于情绪价值，得到的蔡钰老师的《商业参考》系列和新开的课程《产品魅力30讲》，会有丰富详尽的阐释。

最近听了几档好物推荐的播客，能感受到这些消费趋势，已经或多或少地在年轻一代消费主力军中的日常生活中有所体现了。
