# 用ABC原则设计自己的行为

> 来源：[https://my.feishu.cn/docx/doxcnXt44fELASCArbkj9Doyuvb](https://my.feishu.cn/docx/doxcnXt44fELASCArbkj9Doyuvb)

思维模型要建立在人上面，而不是建立在术上面。我们要让我们的行为变得可设计，就需要遵循ABC原则，建立一种自己的行为场景和规则。

Anchor：锚点

Behavior：行动

Celebrate：庆祝

即，在我……的时候，我会做……的事情，做完之后我会……的奖励我自己

设计A，设计锚点，形成稳定的提示；

设计B，设计行为，让行为足够小，能够发生；

设计C，设计庆祝，满足我们的动物脑，满足内心的小孩的欲望
