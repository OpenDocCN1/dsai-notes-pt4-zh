# 不要靠意志力坚持

如果我们想长期做一件事情，那么不要让做这件事需要靠意志力去坚持 ，因为意志力靠不住，而且意志力不是无限的，它本身是一个有限资源，如果每次做事都要调动意志力，那么它终有耗尽的时候。

——这是我从《微习惯》这本书里收获的感悟。

# 做自己喜欢做，但是别人可能不爱做的事情。

这样做事情，才会给你带来有杠杆的不对称收益，而且你喜欢做的事情，你一定是做起来毫不费力的，而且是符合你自身天赋和特质的，这样做起来才更轻松，而且能坚持。

不要在乎这件事情热不热门，能不能给你带来财富。

首先它是你喜欢的，那么就用心去做就好了，至少你是快乐的，而且能给你带来情绪价值，让你充实；

其次，在你最喜欢的事情上，你最有可能成为专家，而现在的时代，任何一个领域，只要你成为头部，就绝对不缺机会，只要你找到发挥自己优势、满足社会需求、为市场提供价值的方式，前景一定不会差。

# 不要做让你自己觉得着急的事情。

因为你如果特别着急做一件事， 说明你不太喜欢它，想赶快结束做别的事情。

# 培养一个让你受益的核心习惯

我们总是想建立习惯，有一种思路是我们可以去培养一些核心习惯。核心习惯代表这个习惯能激发起其他习惯的改变。

一旦你建立起这样的核心习惯，就相当于迭代了你的整个行动系统， 有一个非常强大的向心力去指引你的行动，你的生活的各个方面都会越来越好。

比如运动健身是一个核心习惯，当你长期保持运动的习惯的时候，改变可能是多方面的，可能发生的改变包括但不限于更健康的饮食、更良好的睡眠、更充裕的精力管理以及更快速执行的行动力等等；

比如有价值的阅读（这里必须加一个限定是有价值的阅读），等等。
