
# 管理好自己的注意力

> 来源：[https://my.feishu.cn/docx/doxcnHNX8rANImiNcUJP3FxSRVh](https://my.feishu.cn/docx/doxcnHNX8rANImiNcUJP3FxSRVh)

保持高效能的一个秘诀，管理好自己的注意力，处理好主动关注和被动关注的范围。

不要耗费自己大量的时间去主动关注那些所谓的热点、新闻，新闻和热点层出不穷，会无限涌入，而你的注意力是宝贵而且有限的。

想要保持高效的输入，就应该把注意力留给你需要长期、深度关注的领域。

至于那些所谓的热点和新闻，如果它足够重要，重要到你不得不知道，那么它肯定会主动找上你来的，不要担心错过，你只需要被动等它找上门就好。
