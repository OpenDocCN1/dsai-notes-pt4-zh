
# 我们需要怎样的知识管理工具？

> 来源：[https://my.feishu.cn/docx/doxcnx8uSc6LgUj2NG3dKfigNKF](https://my.feishu.cn/docx/doxcnx8uSc6LgUj2NG3dKfigNKF)

## 【今日复盘：我们需要怎样的知识管理工具？】

分享一下我今天的关于知识工具的一些思考。

在一些学习社群或者工作社群里，经常看到有人抛出这样的话题：

“大家都在用什么工具管理自己的输入信息呀？有没有好的工具推荐？”

我想分享一下我自己的经验，我今年开始借助一些高效的工具去建立我的知识管理和任务管理系统，我也非常享受这个迭代自己的工作流程，精进自己的个人日程的过程，至少我实践了半年以来，能感受到对自己的提升确实是非常明显的，获得感很强。

在这其中，我喜欢的工具（主要是flomo和notion）对我的工作流的优化带来了质的飞跃，但是关于知识管理和任务管理，我还是要说，工具本身真的不重要。

用什么工具管理知识，关键都是看自己的需求是什么，要带着需求和问题找工具；而不是前提和需求都还没有明确，就到处提问：“有没有好的知识管理工具推荐？”、“大家都在用什么软件管理自己的信息呀？”。

如果你现在的工作流很顺手，那就没必要改；在你想要找一个工具之前，肯定是要意识到自己有什么不顺手的问题，察觉到自己这种别扭的感觉，然后带着这个精准的需求，去寻找什么工具能解决和帮助自己。

最后，回答一下这个问题的答案，我们需要什么样的知识管理工具？

1. 不破坏自己的原有习惯，能完美融入并让自己的工作流更加顺畅。
2. 在第一点的基础上，能解决自己在输入信息方面的某些痛点，解放自己的创造力，提高效率的。
3. 学习成本适中，能够容易上手的。
4. 潜在风险小的：比如不会侵犯隐私、没有停止服务跑路的风险、团队稳定不会对核心功能做特别激进的改动的。
