
# 给自己设置限量的目标

> 来源：[https://my.feishu.cn/docx/doxcnC0W2ev1GzYVZWDt4dxAg1f](https://my.feishu.cn/docx/doxcnC0W2ev1GzYVZWDt4dxAg1f)

给自己限量而非目标，让自己缓慢释放自己的灵感和选题。

对自己保持限制，能让自己保持对这件事情持续的热情，来和自己的欲望玩耍。

保持欲望最好的方式就是抑制它。

杀死欲望最好的方式就是满足它。
