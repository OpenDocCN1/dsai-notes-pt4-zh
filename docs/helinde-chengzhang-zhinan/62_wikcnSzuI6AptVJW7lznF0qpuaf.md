
# 不要想着憋大招

> 来源：[https://my.feishu.cn/docx/doxcnDXIDRLC8CQN6iyLt2ZzvJc](https://my.feishu.cn/docx/doxcnDXIDRLC8CQN6iyLt2ZzvJc)

最近在持续主动地去破除一个自我欺骗的幻觉，就是“憋大招”。它通常表现为： ——这本书值得一读，等我周末的时候，我去花几个小时把这本书看完。 ——等我抽个时间，花几个小时，肯定能把这篇文章写得特别精彩。 ——下次抽个时间，我去一口气把这门课学完。总而言之，就是宁愿把事情堆到一个时机去大力完成，放一个大招，也不愿意每天轻微做一点点，积少成多，平A输出。这种自我欺骗往往表现成拖延症的样子，但又不是仅此而已，我之所以经常会冒出这样的想法，实际是因为内心里隐含着一种比较，或者说自己施加给自己的暗示：比起每天去投入整块时间去做这件事，肯定更专注、更高效、更有收获。碎片时间带来的收益太过轻飘飘，收获转瞬即逝，就像落地就消融的雪花，在大脑里写不下印记。为什么说这种心理一种自我欺骗呢，因为从现实角度来讲，它有这么几个站不住脚的地方：

1. 专注力有限：我的注意力永远是一种稀缺的资源，我一天花6个小时啃完一本大部头、学完一门精品课的想法只会是我的一厢情愿，因为一旦到了这个时候，我根本拿不出这么长时间的高质量专注力。专注力是没办法储蓄提取的资源，我没办法在周一到周五每天存一点点，然后到周日再集中大量提取出来，它并不是这么工作的。没有就是没有，没办法从过去借过来。

2. 拖延：我幻想的是，找个时间憋大招。而现实是，事情永远是做不完的，我当下的每一个决定，都是连续的，可传导的。我当下的“不做这个事情”的决定会不断地自我强化，让我一直把这件事情拖延下去，从而优先级一降再降，一直在等待一个“完美的时机”，而这个时机其实永远不会等到。

3. 无聊：一旦我真的坐下来，打算死磕一个任务的时候，我发现没过多久，攒大招的激情就会被枯燥重复的无聊感所取代，并不是因为我选择的任务过于枯燥重复，而是当我把任务限定在某一个具体的事情上的时候，我永远接触的是在同一个范围内的信息，而且我知道不会有惊喜了，我投入的时间越多，新信息给我带来的刺激感就越少。最后动力会越来越衰减，根本撑不到憋出大招的时候。

所以我最近开始实践的做法，简单说就是时刻在多项目之间切换，每天进步一点点。核心理念是付出灵活可变的微小努力。实践起来就是不再妄想憋个大招，而是把自己的精力在平时碎片化的时间缓慢释放出去，而且要同时投入在多个项目上，每一个项目上设定限额，不要花太多时间。

比如不再想着抽一大段时间去看完一本书、一门课程，而是让自己一天里看一节书、学一节课、写一段文章、背一句日语句子，同时达成这几件事。在每个项目上，每次的实际进展很少也无所谓，但要让自己尽可能频繁地去刷进度，而且每次要在尽可能多的项目上有进展。

在多个项目上保持灵活的微小进展，目前实践下来，让我能直接体会到的好处是：

1. 自动化思考：即使每次收获的新知很少，但每次都为它留出了一定的注意力，自己的日常的碎片思考以及自动化程序结合起来，不断加工和处理这些信息，让自己保持在一种积极接受与之相关的信息的状态，保持思考的活跃，时刻准备接受新灵感的激发。

2. 保持热身：通过日拱一卒，不断给自己输入与项目相关的新信息，就像是给水缸换水那样，能通过每次一点点的净化和更新，给自己这个领域的思考回路和执行回路做训练，形成肌肉记忆；比隔一段时间再费大力唤醒，效果要好得多。即使突然应对起来，也不会感到生疏和迟钝。

3. 激发兴趣：一直在不同任务间切换，就不会一直在同一个圈子里打转，能随时跳出现在的思维，所以没有枯燥感。而且每次只要完成微小的进步就能得到满足，获得成就感的机会也明显增加了，因此能给我注入源源不断的动力，让我把这件事情持续做下去。最近的体会就是这些。
