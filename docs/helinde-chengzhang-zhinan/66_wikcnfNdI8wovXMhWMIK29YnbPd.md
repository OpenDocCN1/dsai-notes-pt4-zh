# 给自己正向的激励

> 来源：[https://my.feishu.cn/docx/HlbydMfgkorRYFxp2pfcOsPQnsd](https://my.feishu.cn/docx/HlbydMfgkorRYFxp2pfcOsPQnsd)

最近在用Notion建立自己的日常打卡记录表，我会模拟RPG游戏里主人公升级打怪的行动，对每一件做到的事情赋予分值，做的过程中我想到的是：

用分值给自己做成的事情做记录、积累，本身就是一个正向的自我肯定的过程，每一次正向的分值，都是一次小的自我肯定，是积累信心和建立行动力的一次实践。

同时，我在我的参考模板的基础上，删除了原作者设立的“坏习惯”和“扣分项”的机制，因为我觉得这样是一种负向的自我反馈，而对我来说，平时接收到的负向反馈已经足够多了，反而没有必要再自我强化。

我很认同一种观点：

与其想方设法纠正自己的错误，不如把精力拿来做正确的事情，养成好的习惯。

改掉错误的习惯，并不能我自动成为一个更好的人；做对的事情，才是让自己变得更好的更近的方法。
