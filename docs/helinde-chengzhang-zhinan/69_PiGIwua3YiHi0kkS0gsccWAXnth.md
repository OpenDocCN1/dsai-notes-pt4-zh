# 不要让自己成为这样的人

> 来源：[https://my.feishu.cn/docx/PexKd9ogtomCmkx91ITcmalDnkh](https://my.feishu.cn/docx/PexKd9ogtomCmkx91ITcmalDnkh)

2024/4/21：

有的人「独立思考」的方式：看到别人发表观点，自动忽略其观点的合理性，永远先找不合理之处，习惯性反驳「我有不同看法/我就不是这样的。」

有的人「检索信息」的方式：把微信群当搜索引擎，遇到什么问题不会搜索，而是先发群里问一问。

有的人「利用AI」的方式：不管别人问什么问题，都先回一句「这个AI可以做啊、试试AI？」

有的人「交流学习」的方式：加到微信说一句想和你“互相交流“，但其实只是单方面向对方提问自己想知道的知识，而根本不在意自己能给对方提供什么价值。

有的人「祛魅大V」的方式：看到他的爆款先空口鉴抄，找一找是不是抄袭了某个国外博主的创意，同时咒骂一句能火都是因为他背后有个好爹/有资本，然后心满意足地离去。

有的人「学习大V」的方式：崇拜他的呼风唤雨，艳羡他的流量，喜欢听他们讲追上风口的故事、方法，但是不肯踏实打磨大V们成长起来所用到的基本功、专业技能。

有的人「自我放弃」的方式：遇到挫折，就反复背诵“这世界是旷野，不是轨道”和“这世界就是个草台班子”，用这两句话当做自己心安理得摆烂的合理性支撑。

有的人「做自媒体」的方式：日更没有主题的流水账，建立自己的“终身成长陪伴群”，然后开始记录自己的统计字数，用日更天数和输出字数包装自己，而根本不考虑面向的用户、人群需求、输出内容的价值。

给自己的注脚：时刻保持警惕，不要让自己成为「有的人」，共勉。
