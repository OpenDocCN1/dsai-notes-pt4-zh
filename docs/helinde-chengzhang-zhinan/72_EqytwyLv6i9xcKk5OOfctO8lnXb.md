+   知识星球加价、升级后的的收获和思考

- 收获1：内容升级

- 独家案例

- VIP社群

- 线下闭门会

- 收获2：通过收费筛选出了高净值用户：价格是筛选用户的门槛

- 收获3：逼着每天生产原创内容

+   对于一个平台运营来说，运营平台的能力只在这个平台才有，这个能力不代表出来之后能把事情做好；离开平台之后，才能知道谁在裸泳。

+   创业的感受

- 不稳定

- 自己左右自己所有的时间

- 不需要被他人给的评价所束缚

+   出圈的代价：不在你的维度和话语体系的人开始来骂你，把你降低到他的档次

+   创业过程中收获的观点：

- 产品完全不重要

- 因为产品能做的事情、能改进的空间非常小

- 能做优化、能做改进的就是运营策略

- 运营解决的是效率、成本、协作、获客方式的问题

- 在存量市场的不断优化，运营的重要性越来越重要，而能从更高维度破局的方法当然是技术创新。

- 预期和能力一定要匹配

- 公司成立一定要有稳定的现金流，收入要大于成本，要证明自己有盈利能力

- 从小事做起、做好：小公司的优势，能和客户产生信任关系
