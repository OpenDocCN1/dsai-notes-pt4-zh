
# 用kimichat生成文章大纲

> 来源：[https://my.feishu.cn/docx/IsaFdCUmhokQg3xuDqJcPawFnhc](https://my.feishu.cn/docx/IsaFdCUmhokQg3xuDqJcPawFnhc)

2024/4/2

经常看👸号会看到那种「万字长文总结……」的文章

很多内容确实也很优质，但是如果按顺序读的话，至少需要三四十分钟，很难一次读完，而且不是每一部分都需要细读。

有些文章作者会自己带上一、1、1.1的标题，但是在开头没有附上大纲的话，就得重复上下翻去找上下文，也比较麻烦。

所以可以用kimi直接读取链接生成一下标题大纲结构，粗略浏览一遍文章的主要内容，然后再反复阅读自己感兴趣的部分，会方便很多。
