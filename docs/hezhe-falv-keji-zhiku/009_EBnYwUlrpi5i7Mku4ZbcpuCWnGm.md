# **💬例会沟通机制**

社区每周将召开共创例会，由各项目负责人汇报项目进度。

会议工具：飞书网络研讨会，将分享到【🛰️群】和【飞书群】，共创伙伴登录飞书入会。

# **🏆共创榜单公示**

社区将定期公示各位共创伙伴的贡献，并评选出【月度共创之星】、【季度共创之星】、【年度共创之星】等荣誉，获得社区提供的各类权益。

# **⭐️共创成果发布**

社区将定期发布共创成果，包括但不限于：

1.  各项目的共创进度，以周报/月刊/季刊的形式对外发布

1.  各项目的共创成果，如法律 AI 应用工作流、法律科技工具测评文章
