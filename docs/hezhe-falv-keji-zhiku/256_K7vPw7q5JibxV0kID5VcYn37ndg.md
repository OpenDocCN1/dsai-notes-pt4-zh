# 法律数据智能负责人

## **职位描述**

法律数据智能负责人，负责构建和扩展法律数据智能的职能，以支持组织内的数据利益相关者，包括但不限于诉讼、调查、隐私、数据保护、信息治理和法律运营等。

法律数据智能负责人将研发和实施数据分析策略、政策和程序，确保有效/高效地识别、保存、收集、分析、处理、生产以及整合，敏感、有用和必要（简称“SUN”）的数据，以支持法律请求和商业举措。

这个角色提供了一个激动人心的机会，通过将“SUN”数据转化为可操作的信息、洞察和情报，为法律和更广泛的组织创造价值。

## **工作职责**

+   为法律数据智能这一职能提供战略领导和方向，包括：研发和实施数据分析策略、政策和程序，同时定期评估和完善程序以持续改进流程，以最大化地提升运营效率

+   与数据利益相关者协作，以确定法律数据智能相关需求；对程序化的解决方案进行创新，以满足同样的需求

+   监督和管理法律数据智能项目，确保有效/高效地识别、保存、收集、分析、处理、生产和整合敏感、有用和必要的数据，以支持法律请求和商业举措

+   提倡评估、选择和实施由 AI 驱动的数据分析工具、平台和技术，从而确保效率、精确性和可扩展性

+   建立和维护与外部服务商的关系，并确保其遵守服务水平协议和质量标准

+   通过设定目标、定期反馈和年度评估等，来积极地管理团队绩效；促进员工参与和团队协作的文化

+   保持对于电子发现行业发展的最新了解，包括最佳实践、技术进步、影响数据利益相关者的法律和/或监管框架的变化；作为相关领域的主题专家提供支持

## **职位要求**

+   美国律师协会认可法学院的法学博士学位

+   至少在美国一个州的律师协会注册，并且为活跃会员

+   至少 8 年为大型公司、律师事务所、电子发现服务商或政府工作的电子发现、诉讼支持和法律科技经验

+   至少 5 年的领导经验

+   精通联邦民事诉讼规则（FRCP）、法律数据智能（LDI）和电子发现参考模型（EDRM）以及数据保存、收集、处理、审查和分析策略

+   对信息治理参考模型（IGRM）以及围绕数据保护和隐私的监管框架有工作知识

+   熟练使用电子发现技术，包括成功使用 AI 驱动的数据分析工具、平台和技术优化，来加速大量数据的审查和分析

+   出色的解决问题的能力，并对风险管理有兴趣和天赋

+   强大的沟通和人际交往能力，能够领导多元化的团队，并在组织内保持跨职能关系

## **其他技能、经验和认证**

+   构建和扩展电子发现、诉讼支持或者法律科技职能的经验

+   以下认证在证明相关知识和经验方面很有价值：认证的电子发现专家（CEDS）；认证的信息隐私专业人士（CIPP）；认证的信息治理专业人士（IGP）；认证的信息专业人士（CIP）；认证的档案管理员（CRM）；认证的信息安全管理者（CISM）；认证的信息系统安全专业人员（CISSP）
