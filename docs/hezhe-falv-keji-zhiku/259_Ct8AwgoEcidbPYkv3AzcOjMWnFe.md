# 我，一个法科生，试过几家律所后，进了一家互联网公司

> 来源：[https://docs.feishu.cn/docx/X9IldK9PWoBAIcxxiVWcQBvenZc](https://docs.feishu.cn/docx/X9IldK9PWoBAIcxxiVWcQBvenZc)

> 本文首发于 2020 年。

---

同学们稳住，offer会有的，今年春招有点难，很多应届生为了找工作都焦头烂额。

受疫情影响，有的应届生秋招已经签三方的 offer 被毁约，有的秋招没拿到 offer ，压力本来就大，加上受疫情影响岗位少了也没法去一线城市面试，想在毕业前找到工作，怎么办？

很多法科生打算毕业之后专业对口，其中公检法是国家编制，受到疫情的影响比较小，但很多律所、公司都在降低用人名额，很多法科生面临最难的下半年。但是，如果把视野放大一点，我们法科生的选择还是有很多的。

**一、短暂的律所实习经历**

我是2013年入学，2017年毕业的法科生，现在已经工作2年了。

在法学院读书时，每届大二的暑假学院都会要求实习，学院会提供一些实习名额，通常都是师兄师姐所在的律所。

我一共在3家律所待过，前2家就是经过学院推荐进去的。

之所以说是短暂的经历，是因为律所和法学院的运作机制有很大的区别。

作为一个还在读书或者刚毕业的法科生，你需要花很长的时间去适应，然后才能真正进入办案阶段，这其实也是为什么，近年来法律培训机构兴起的原因之一。

从象牙塔走向社会，法科生进入律所面临最大的挑战，就是如何去解决一个个具体而复杂的问题，将所学转化为应对一个个挑战的解决方案。

当你进入一家律所，你首先要面对的不是怎么谈客户，而是怎样高效地搜集材料，怎样让别人愿意与你合作，如何与客户快速建立信任关系，这些都非常具体，前2次实习，我基本都在学习如何处理这些问题。

我的第3次律所实习，是在广州盈科刑事部做主任助理，那是我自己主动去参加一些律所举办的活动，然后才拿到的 offer 。

当时的我，认为找律所一定要“跟对师傅”。这在当时是一个很朴素的认知，找到一个“好师傅”传帮带当然是好事，但大所带来的平台也是很好的资源。

这里有一个很关键的点，那就是盈科刑事部以诉讼业务为主，明星律师的光环效应非常明显。

我在实习期间跟着主任见过几次客户，谈判过程经常会超出我的预料范围，还有开庭时主任的应变能力和诉辩技巧，确实可以学到很多实践经验。

如果你想要做诉讼业务，或者想要加入的律所主要做诉讼业务，那么找到一个好师傅是至关重要的。

除此之外，律所或团队的氛围也很重要，尽可能加入一些经常举办业界交流或者内部学习的律所，有利于提升你对律师这个职业的认知。

对我来说，与律所实习的经验相比，思维逻辑的训练非常有用，受用也更加持久。

比如广州盈科刑事部的学习氛围就非常浓厚，基本上每周都会组织大家学习优秀的辩护词，看看大状们都是怎么去论证辩护要点的，每个人都打印出来比比画画。

这种学习氛围其实就是“学习小组”，我们当时就建了一个🛰️群，之后每一个律师助理都会进群，后来还加入了很多律界大咖，其中就包括《完美的合同》作者吴江水。

这种学习小组的学习方式延续至今，让我在工作中对协同工具的应用非常顺畅，包括我最近在研究的DAO（Decentralized Autonomous Organization，分布式自组织），作为一个基于区块链的原生产物，理解起来也很容易。

**二、进入互联网创业公司**

我的律所实习在毕业前就结束了，毕业后我没有马上找工作，而是做了一段时间大数据研究的工作。具体来说，就是分析海量的司法判决书，从而得出一些数据分析结果，可以用于法律风险预测。

2018年，我加入了一家北京某互联网创业公司 。

公司的主要业务是公司法中的一个细分领域 —— 股权，具体包括股权设计、股权激励、股权融资等等。

你可以理解为律所中专门做股权业务的团队，只不过我们把它当成一家公司来 run ，而且由于这个业务具备巨大的商业价值，公司现在还拿到了两轮融资。

之所以要加入这么一家创业公司，当时的我纯粹是喜欢公司的环境，但现在看来其实代表了律师业的一个演化趋势，那就是非诉律师的兴起。

如果你今天到北京、上海的 CBD区，你会发现很多律师是根本不出庭的，他们一般被叫做“非诉律师”，也叫商业律师。你可能听过说“红圈所”，就是通商、环球、海问、竞天公诚、君合、金杜、中伦、方达这些顶级律师事务所，一般也叫“大所”，它们主要做非诉业务。

由于公司法律业务太复杂，一个律师不可能同时懂合同、懂信托、懂债券发行、懂并购、懂股权，但每一个细分领域都值得做深。

因此，如果你想去做非诉律师，其实有很多选择。你可以从自己的兴趣出发，选择想要从事的领域。

对于主要做非诉业务的律所，“跟对师傅”的重要性就不是很高了，因为一个非诉的 case 非常复杂，往往需要调用各方资源，并不是一个明星律师就可以主导的，所以平台也很重要。

后来，随着大公司对法律服务的需求大幅增长，还有的法科生直接进入公司法务部做法律相关工作，成为甲方爸爸的员工。

当然，根据公司的体量，法科生在公司里的工作也不尽相同。

在大公司中，各个岗位的专业化程度要求较高，职务稳定。如果你进入大公司的法务部，基本上就是做法律相关的工作，比如审合同、处理纠纷等等。

但在创业公司中，基本上所有的事情你都会有所涉及，什么都要做一点，这就对法科生提出了更高的素质要求，或者需要更强的适应能力。

相比之下，我更推荐法科生加入一家高速增长的创业公司，你的成长速度可能会呈指数级增长。

**三、法科生职业的可能性**

一般来说，法科生加入创业公司有两个选择，一是进入法务部做法律相关的工作，二是做除了法律以外的其他一切工作。我选择的正是后者。

事实上，只要不是对专业技能有很高要求的工作（比如coding），都值得去尝试，并不一定要专业对口。

或者你也可以思考一下，法学生的专业对口就是法律吗？还是学法律训练出来的思维逻辑能力？

在梁宁老师的《增长思维30讲》中提到一个小游戏：用10张卡片，写出你的10个关系，最后砍掉7张，留下3张，这就是你最重要的3个关系。

在职业选择的过程中，你应该要找到那些笃定的关系，比如你与所学专业的关系，你与客户需求的关系，这才是你的增长底牌。

当你找到你的增长底牌，你就会发现更多职业的可能性。

作为一个法科生，毕业后想去做律师，那么你和客户的关系就是非常重要的关系。

这时，你对自己的定位是什么呢？是律师吗？还是法律服务的提供者？

传统的法律服务提供者就是律师，诉讼律师帮助客户“解决问题”，非诉律师帮助客户“避免问题”。

但你想过没有，很多客户（不论是个人还是企业），除了打官司、写合同，他们还有学习法律知识的需求、运用法律产品提高工作效率的需求等等。

这些都是还没有被满足的需求，任何解决这些需求的工作，都会是不错的选择。

我在互联网公司的主要工作是做内容运营，就是看到了这些客户需求的存在。

同时，内容对于客户生命周期的管理也非常重要，可以极大地激发客户的需求。

具体来说，当一个客户有了法律服务的需求，他的第一步行为通常就是去学习。比如上网搜索信息或者去看书，如果可以自己解决问题最好，省得去问别人或者花钱请律师。

这时，你就可以通过👸号、知乎、头条等自媒体矩阵输出内容、包装课程，在客户产生需求的第一时间就被你的自媒体渠道捕捉到。

在客户了解你的过程中，就会发现你很强，那他可能在观望之后成为你的客户。事实上，传媒这个行当正处于一个变革的时候，人们对资讯的需求不断上升。

媒体正在由一个“独立”的行当，到正在处于某种缩小的过程中，几乎所有的其他行当都在“+媒体”，甚至每个人都在提升自己的媒介素养。在新媒体时代，个体成为信息的首次发布者，很多信息都要由自己发布。

不论是律所、法律科技公司、法律自媒体，还是法院、检察院、政府等政务机构，都缺乏具有媒介素养的人才。

律所、法律科技公司需要持续获客，除了花钱打广告，就是通过自家🛰️👸号进行市场推广、建立品牌。法院、检察院、政府也要通过网站、电话热线、🛰️👸号提供政务服务。

对于刚毕业的法科生来说，如果你的法律专业知识够硬，具备一定文字功底及原创能力，审美水平过关，或许你也可以尝试一下这个角色。

当然，写作的门槛说高不高说低不低，因为法科生通常都会比较“专业范儿”，写出来的文章可能没有“说人话”，还需要在文章写作、编辑上也需要下功夫。

因此，对于法科生来说，求职的心态也要产生一种变革：你将来就是去当律师，还是可能去企业、律所、公检法，运营它的👸号？

除了内容运营，其实还有很多岗位值得法科生去尝试：

+   前台部门：主要是指引流部门，包括市场和销售。市场通过渠道BD、内容运营等方式吸引流量，然后由销售进行转化。在法律行业，没有专业知识根本解决不了客户的问题，所以，如果你性格擅长与人接触，可以试试市场和销售。

+   中台部门：主要是指服务部门，包括直接为客户提供法律咨询服务的股权架构师、为客户开发产品的产品经理。如果你想在一个垂直领域深耕，成为这个领域的专家，那么可以尝试一下股权架构师这个角色（或者其他领域的专家）；如果你很有创造力，对客户需求敏感，并且希望用你的法律知识设计出一个产品（想想就很酷），那么法律产品经理也是个不错的选择。

+   后台部门：主要是指留存部门，包括为客户提供增值服务的客户成功部门、为产品研发提供技术支持的研发部门。如果你喜欢为客户提供持续的服务，提高客户留存率，那你可以试试客户成功；如果你的 coding 能力很强，也可以试试自己写代码开发产品。

求职岔路口上分岔出的每一条道路，都决定了我们未来的生存状态和自我价值实现的方式。

多了解一条路，也就多了一个选项。寻常之路不意味着就是必然之路。走不寻常路，敢为人先者，方能先人一步。
