
# 律师做内容：我从“发弹幕”中获得的启发

> 来源：[https://docs.feishu.cn/docx/BcBpdOvsRorOsCx4y0ycBJ2dn6c](https://docs.feishu.cn/docx/BcBpdOvsRorOsCx4y0ycBJ2dn6c)

awsl、yyds、yygq、fgnb ...... 这些话你应该听过，但你可能不知道从哪儿来的。

其实，这些都是原本活跃在视频的弹幕里，从“二次元”世界流行到大众生活里来的词。

在过去两年，二次元和弹幕大放异彩，不仅制造流行语，还制造了很多焦点事件。

弹幕看似简单，却造就出了估值 400+ 亿美金的 B 站。

事实上，弹幕已经不仅仅是一种用户评论，它还能筛选出高价值用户，正在成为一种新的第三方点评工具，是判断好社区的标志之一。

而这些，恰恰是律师做内容必须了解的：

+ 律师做内容，不是公益普法，而是要筛选出潜在客户；
+ 律师做内容，不是要成为作家，而是要构建个人品牌；
+ 律师做内容，不应该是自嗨，而是要和读者充分互动。

下面详述。

## 1. 发弹幕本质上就是一种创作

众所周知，上网冲浪是一种非常健身益脑的体育活动，唯一的问题就是费眼。

我在工作之余，就经常在 B 站、斗鱼、虎牙等平台，用弹幕和主播激情互动。

弹幕，顾名思义，就是在看视频的时候，大量的评论会从屏幕上飘过，就像游戏里密集的子弹一样。

可以说，弹幕刷新了年轻人看视频的方式。

就像 Rock 在脱口秀大会里说的，他就是一个标准的“前浪”，因为他从来不会在看视频的时候发弹幕。

![](img/dbb09e01c4516e2cf296246e3a945475.png)

当然，这只是节目效果。前浪后浪和年龄没多大关系，也不是只有年轻人才会发弹幕。

发弹幕，本质上就是一种创作。

因为随着技术的发展，不再是只有专业人士才能生产内容了。

在像 B 站这类平台中，人人都可以参与二次创作 —— Up 主创作的是视频，用户创作的是弹幕。

对平台来说，弹幕的出现，可以最大程度地激活用户的积极性和粘性，因为不是人人都能做视频，但是人人都可以发弹幕。

门槛越低，参与的人就越有热情。发弹幕，就是最低成本的创作。

用户们围绕在同一个视频里飙弹幕的样子，像极了🛰️群的斗图。

进一步看，“弹幕”就像我们在看书时写下的“读书笔记”，类比到较为严肃的文学领域，则被称为“评注”。

什么意思？

我们来拆解一下：

我们在什么时候会写读书笔记？在看书的时候。哪些人会写读书笔记？是那些热爱学习、喜欢独立思考的人。

当然，有的人更倾向于在电脑、平板、手机上写下自己的感想，甚至有的人博闻强识，直接刻在了脑子里。这些都是读书笔记。

我们再来看“弹幕”。

我们在什么时候会发弹幕？在看视频的时候。哪些人会发弹幕？是那些在认真看视频，并对视频内容输出自己观点的人。

换句话说，承载弹幕的媒介是视频，承载读书笔记的媒介是书。不论是发弹幕，还是写读书笔记，本质上都是在消费内容。

不论是发弹幕的人，还是写读书笔记的人，都是之于特定平台方的“高价值用户”。

前者的平台方，比如 B 站；后者的平台方，比如出版社。

不仅如此，这些高价值用户，对内容产业上的每一环都是非常有价值的，比如内容创作者、作者、书店等等。

那明白这一点，对你有什么用呢？

别急，我们再来看看弹幕之于视频的重要性。

## 2. 弹幕已经成为视频的组成部分

首先，弹幕的作用，是对视频内容的补充。

比如有些弹幕会给没有字幕的视频配上字幕，有些会对视频里出现的科学知识进行解释。

换句话说，弹幕是对完整的视频内容进行的解构、补充和二次生产。所以你可以看到，弹幕和视频其实是可以分离的，有时弹幕的精彩程度，丝毫不亚于视频本身。

之所以会出现“弹幕”这种评论类型，是因为每一个看视频的人，他的需求都是不同的。

用户在第一次写下弹幕时，那是对他对视频内容的理解。但当他已经看过这个视频时，他现在看第二遍，其实是想看看别人对这个情节的理解，和我有什么不同。或者他只是心想，让我看看谁又发了哪些沙雕弹幕？

更重要的是，弹幕已经成为这条视频是否值得一看的评价标准。

弹幕越来越像大众点评上的评价：了解这些信息，你就能做出更好的决策。

类比到律师行业，大部分律师输出的内容，就像淘宝店铺，不论你装饰的多精美，商品有多物美价廉，客户还是将信将疑。

但如果你的店铺好评如潮，那就不一样了。

因此，真正能对客户产生吸引力的内容，往往都有很强的“互动性”。

这种互动形式有很多，比如 B 站的“弹幕”、淘宝店铺的“好评”、知乎的“问答”、得到的“知识城邦”、🛰️生态的“评论区”，比如“高转发率”的👸号文章，用户的每一次转发，都可能在朋友圈的评论区产生交互。

等等，等等，等等。

这就是一个简单的，判断客户是否喜欢你内容的维度。而这些具有强互动性的平台，本质上就是“社区”。

一个好的社区，必然会有良好的互动机制。

律师做内容，不能埋头苦干，而是要选好你所依附的平台，尤其是具有强互动性的平台。

有了平台的赋能，你的内容影响力才会被尽可能地放大。

## 3. “弹幕文化”是好社区的标志

弹幕的本质是用户互动，这和社区氛围其实是一个“一而二，二而一”的事情。

用户互动可以促进社区化，但你要先有社区氛围，用户才会愿意互动。

不然用户根本就懒得打字。

大家都是很忙的，给彼此一点空间好吗？

就像 B 站有弹幕，但又不仅有弹幕一样，网易云音乐的评论区功能其实不是最重要的。

最重要的，是由评论区所衍生出来的一种社区氛围。

为什么？

还是以弹幕举例。

弹幕质量的高低，其实反映了社区的质量。

如果一个平台只有内容，没有弹幕、评论、评注，那它就只是一个媒体。

它的商业模式，就只有接商业广告，没有很大的想象力。原因很简单，从媒体跨界到做产品、做服务，需要完全不同的能力。

进一步说，这类平台上的内容创作者，要想获得更多客户，那就只能花更多的钱打广告。

类比到律师行业，一个良好的社区，就是一个很好的获客来源。

设想一下：

一个没有互动的平台上，都是什么样的用户？

律师在平台上发表文章、观点、视频，但用户没有互动，那么结果就有两个：

一是用户看完就走了，他获取到了一些知识，然后他就满足了，并不会产生付费行为。

二是用户看完了内容，然后去找律师，但由于他没有相关的专业背景，他对你的内容一知半解，因此对于自己遇到的问题、找到的律师，其实都不精准。

那么，怎样才能找到适合自己的社区呢？

我认为，有一点需要注意的是，并不是所有拥有弹幕文化的地方都叫社区。

比如综艺节目，观众之间可以通过弹幕实时交流，这算是技术对节目形式的一个革新，但仍然没有打通节目本身和观众之间的隔阂。

因为这些弹幕观众看得见，但嘉宾自己看不见，也无法对观众的反馈作出及时的互动，等于又回到了读观众来信的电视媒体时代。

好的社区，应该是“创作者和用户间”、“用户和用户间”，都能形成良好的互动。

在图文领域做的好的社区，比如知乎，它的互动机制是“邀请回答”。

在视频领域做的好的社区，那就多了，比如抖音、快手、视频号、B站等等，它的互动机制就是极其强大的直播功能。

比如说用户看直播，会和主播怎样互动呢？

在直播行业中，互动主要是指用户关注主播、给主播评论、点赞、私信、打赏等等。

其中，“打赏”就是一个很重要的互动形式。

在斗鱼、虎牙等直播平台，用户也被称为“水友”。水友在看直播时会发弹幕，主播也会和弹幕聊天，甚至可能会产生“交易”。

比如当水友想看主播玩什么游戏时，最直接的方法就是打赏，然后发弹幕“命令”主播：你玩这个游戏给我看。

简直就是现代公司的股东制度。

这就是一个好社区的延展性。

听到这里，你可能也更加理解，为什么🛰️要重点发力视频号了。因为能够消费视频的用户，远远大于能够消费图文的用户。

打造更活跃的🛰️生态，势在必行。

最后，我们可以复盘一下：

你所依附的平台，有社区文化吗？又或者说，你所理解的社区文化，是什么样子的？

祝你早日找到适合自己的社区。
