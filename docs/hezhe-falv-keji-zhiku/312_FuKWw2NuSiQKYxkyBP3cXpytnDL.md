# 阅读外文网站/文献

> 来源：[https://docs.feishu.cn/docx/M2mVdi06CoQZlRxxtKwcnridnmb](https://docs.feishu.cn/docx/M2mVdi06CoQZlRxxtKwcnridnmb)

> 本工作流来自：何者 Hezher 社区发起人

---

## 场景

研究人员平时需要查阅海外资讯或文献，获取最新的研究动态和学术成果。

## 工作流程

+   调研：查询与想了解的问题相关的网站。

+   访问：登录外文网站，以访问需要了解的讯息。

+   翻译：将外文网页内容准确翻译成中文，以便快速理解。

+   总结：对外文网页的关键信息进行总结，提取重点内容，提高阅读效率。

## 操作指引和工具推荐

+   **调研**：考虑到我们想访问的是海外信息，推荐优先使用基于英文语料训练的 AI 工具，其次才是国产 AI 工具

+   操作指引：清晰、准确地提出你想研究的问题，让 AI 给你推荐一些信息源

+   推荐工具：

+   ChatGPT：https://chat.openai.com/

+   豆包：[doubao.com](https://doubao.com/)

+   Kimi：https://kimi.moonshot.cn/

+   **访问**：有的外文网站可以直接访问，而有的外文网站则需要“🪜”

+   如需推荐合适的🪜，可联系：18825075686（🛰️）

+   **翻译**：可以使用独立的翻译软件，也可以使用浏览器插件进行翻译

+   操作指引：将需要翻译的文件/内容，上传/复制到翻译工具中，让它全文翻译或者翻译特定段落；如果使用浏览器内嵌的翻译插件，可以直接点击“翻译”按钮对网页全文翻译，也可以选中特定内容后右键点击“翻译”

+   推荐工具：

+   各大 AI 工具，如 ChatGPT、豆包、Kimi 等

+   Safari 浏览器（苹果电脑）- 自带翻译功能

+   谷歌浏览器 - 自带翻译功能

+   豆包-浏览器插件-翻译

+   **总结**：将需要总结的网页或文件，上传到 AI 软件或 AI 工具的浏览器插件中，让它帮助你总结内容

+   操作指引：将需要总结的文件/内容，上传/复制到 AI 工具中，让它进行概括和总结

+   推荐工具：

+   各大 AI 工具，如 ChatGPT、豆包、Kimi 等

+   豆包-浏览器插件
