# “这也算法律科技产品？”

> 来源：[https://docs.feishu.cn/docx/RUqOd5EjvoqUm5xPTRncCBAOnFe](https://docs.feishu.cn/docx/RUqOd5EjvoqUm5xPTRncCBAOnFe)

> 不要自我设限。

“做个小互动，法律人最高频使用的法律科技产品是什么？”

在康达律所青训营法律科技微论坛上，无讼的副总裁庄总提问道。

短暂的互动后，咔，一张 Microsoft Word 的图片出现在屏幕上。庄总说，我个人认为，是 Word、WPS 等各种文件编辑器。这时就有一些律师朋友表示疑惑 ：

**“这也算法律科技产品吗？”**

庄总说怎么不算呢？垂直领域的科技产品，本质上都是通用科技对专业领域的赋能。

我听到这里会心一笑，然后对坐在旁边的凤梅姐说，那我觉得法律人最高频使用的法律科技产品，是「🛰️」。

是的，垂直领域的科技产品，本质上都是通用科技对专业领域的赋能。就这么简单。但是，不论是学术界和实务界，都有很多人在试图定义什么是法律科技，旁征博引，搞得非常复杂，似乎法律科技很高大上。

Come on. 根本没什么意义好吧。

法律科技，不就是新科技对法律行业的赋能么？就像十年前的「互联网+」，还有近几年火起来的「AI+」一样，就是互联网技术和 AI 技术与其他领域的融合。

"Silence your ego." 法律行业没什么高大上的，就是一个垂直领域而已。

所以，从狭义上看，法律科技其实就是通用科技与法律领域的融合，但从广义上看 —— 如果通用科技可以直接被法律行业使用，那通用科技怎么就不能称为法律科技呢？比如，业内有专门的律所管理系统，但也有律所直接用钉钉、企业🛰️或飞书在线办公、管理案件，还有各种 ERP、CRM 系统。

因此，这种定义，有意义，但意义不大。

事实上，很多律所或律师为了提高竞争力，已经使用了很多科技产品，比如：

+   **智能手机/移动通信/笔记本电脑**：手机、电话号码和和笔记本电脑能让我们实现「移动办公」，而不必坐在办公室里，这是非常重要的科技产品，只不过越是重要的科技，越容易变得稀松平常。

+   **社交 app**：毫无疑问，现在和未来人们都会在互联网上交流互动。

+   **视频会议软件**：沟通和协作是律师成功的核心，面对面沟通是需要的，但并不总是可实现的，相反在线沟通更加高效。

+   **文字处理工具**：Word、WPS 和各种在线文档，律师的生产力工具。

+   **文件存储工具**：如果使用本地文件，那么通常需要用电脑或 U 盘来存储文件；如果使用在线文件，那就需要在线存储工具，比如阿里云，可以让你更方便地访问文件，以及在任何地方工作和协作。

+   **在线扫描工具**：文档数字化的能力对律师来说至关重要，比如律师阅卷，因此扫描工具就很重要了。以前可能需要专门的扫描仪，或者拍照回去手动抄写，现在很多手机应用就自带扫描、提取文字功能。

+   **文档自动化工具**：通过技术不同程度地简化文件的起草和修改，降低人工成本。

+   **法律检索工具和搜索引擎**：法律人在日常工作中需要查询非常多的信息，法律问题需要用专门的法律检索系统，非法律问题则用各种搜索引擎，比如🛰️、百度。

+   **时间跟踪和计费工具**：很多律所和律师都是按小时计费，所以准确的时间跟踪和计费就是律所和律师盈利的关键，于是市场上就有一些专门的时间跟踪和计费工具，以取代手动监控时间和处理账单。

+   **电子签名**：有法律效力的在线签名技术，可以提高律师和客户之间的协作效率，并减少人为错误。

+   **在线支付**：支持在互联网上付款，使客户付款更容易、更方便，从而使律师可以更快地获得律师费。

+   **客户关系管理（CRM）**：协调律师与客户在营销和服务上的交互，以增加新用户、提高老用户粘性。

+   **虚拟接待员服务**：通过技术接收电话、社交 app 信息或邮件等潜在客户信息，降低人工操作的成本。

+   **客户门户网站**：让客户了解案件情况的入口，可以提高客户的满意度。

以上工具，很多通用产品都可以提供，比如🛰️、Microsoft Office、WPS、钉企飞等，只要用得溜，其实就可以满足律师的大部分需求，但学习成本比较高，而且不是专门为律师开发的，所以可能也没那么好用。

与之相对的，市场上也有专门为法律人设计的法律科技产品，比如法律检索系统，威科先行、北大法宝、Alpha 等等，还有整合了多种工具的律所管理系统，比如法蝉。

忘掉“法律行业”、“法律人”、“法律科技”这些限制，从自身的实际需求出发，选择适合自己的工具，你就会发现更大的天地。这，或许才是真正的「技术派律师」。
