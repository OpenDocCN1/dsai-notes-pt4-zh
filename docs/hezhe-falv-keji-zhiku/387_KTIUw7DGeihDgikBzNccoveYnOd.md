# 🙌关于法天使

法天使-中国合同库（fatianshi.cn），一家聚焦“合同”的法律科技公司，2015年成立于北京，由资深律师与IT工程师联手创办，目标是建设中国合同库，为全社会各种交易提供合同模板和工具，从而提升中国社会合同水平。国家市场监督管理总局政府合同示范文本独家支持单位及《合同起草审查指南》团体标准发起单位。

核心产品为中国合同库及合同助手工具，目前合同库中包含社会经济各行各业近2000类交易场景的10000个合同模板，数十万条合同规则、条款和审查点。

自主研发的合同助手工具，结合大模型智能检索，便于法律人快速起草各类合同、动态生成各类高质量合同，当前已有超过34万法律人专业用户。所撰写出版的《合同起草审查指南》多卷本和《中国合同库》20册系列书籍，畅销数十万册。

# 💡 合同起草审查工具

## 📚法天使合同库

> 法律人公认好用的模板库

法天使-中国合同库是对中国境内合同范本及法律文书、合同条款、合同相关知识进行体系化分类、结构化整理、工具化应用的专业数据库。经过9年建设，已经拥有超34万法律人专业用户，内容较为完备。

合同是法律人的高频工作场景。优质全面的合同范本，有助于帮助法律人提高常见合同文本的起草、审查品质和效率，有助于律所/企业层面节省合同文本整理的基础性重复性工作，投入更多精力做好律所/企业内部资源为核心的知识管理。

合同库的建设需要持续投入、动态更新，法天使作为专注于这个领域的机构，能减轻律所/企业在对应领域的重复建设，成为有力的外部支持。

## 💻法天使合同助手

> **法天使为法律人**提供高品质、高效率的合同工具——法天使合同助手，助力法律人高效完成合同起草审查工作

法天使合同助手是多维度数据库，还匹配合同编辑器；2023年引入大模型技术，为合同库提供了新的能力——AI搜合同，用户以直白对话可快速找到好模板；2024年新增AI搜审查点功能，用自然语言可快速检索《合同起草审查指南》中全部合同审查要点。

法天使合同助手有12大核心功能，包括中国合同库、AI搜合同、AI搜审查点、条款库、法规库、工商信息库、工具箱、条款组、填空项、自动编号、合同套装、批量生成功能。

### **使用端口**

法天使合同助手可在法天使官网（fatianshi.cn）使用，也可嵌入Word/WPS文档中使用，还可在手机App、微信小程序中使用。

### AI搜合同

法天使合同助手，全新升级AI搜合同功能。用户只需用自然语言描述交易场景，系统便能从近万个合同模板中找到最佳匹配。

+   **电脑端**

电脑浏览器登录法天使官网https://www.fatianshi.cn/，点击首页“AI搜合同”，输入您的合同需求，AI会快速协助推荐所需模板，并支持5轮对话交互，模板定位更精准。

![](img/10b4dd3f7d2b5a1707f43a06c0c7be6e.png)

![](img/402b4ef8006a2400254d2c7e8883e957.png)

+   **手机端**

手机微信打开“法天使”公众号，点击菜单栏“合同库-搜合同”，再点击搜索框右上角的「法小天合同检索机器人」即可使用。

### AI搜审查点

法天使合同助手，新增AI搜审查点功能，嵌入《合同起草审查指南》数百万字知识库，涵盖公司、知产、劳动、婚家、建工等多领域内容。用户以自然语言，可快速找到各类合同起草审查要点和相关知识。

+   **电脑端**

+   电脑浏览器登录法天使官网https://www.fatianshi.cn/，点击首页“AI搜审查点”；

+   输入您的合同需求，AI会快速检索相关合同审查要点或知识；

+   同时提供关联模板和所属课程；

+   支持不限轮次对话交互，审查合同前问一问，更好地抓住审查要点。
