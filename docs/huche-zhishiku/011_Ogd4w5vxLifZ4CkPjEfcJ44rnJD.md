
# 胡扯社群资源共创规则（已废弃）

> 来源：[https://huchegames.feishu.cn/docx/SPRydzS0uo0jfWxM77zc5ccZnFf](https://huchegames.feishu.cn/docx/SPRydzS0uo0jfWxM77zc5ccZnFf)

## 原则草案

1. 提供共创资源的可积分，积分单位（胡）。
2. 每提供 1 个资源积分 1 胡。在提交界面设置的资源价值，为上传者认定的资源价值，最终以审核为准。
3. 提供共创资源者，可进入「胡扯社群共创」飞书群。
4. 共创资源对进入「胡扯社群共创」飞书群的群友完全免费。
5. 「胡扯VIP」群构建中，共创群友可使用积分兑换 VIP 权限。

## 共创资源提交

建议使用飞书登录后再提交，这样曾老师可以基于提交的资料直接拉群。

https://huchegames.feishu.cn/share/base/form/shrcn8oZJ6OTkhVaAYvtJhwsZWj

## 进入「胡扯一下」，要求曾老师拉群

提交共创资源后，进行如下两步：

1. 进入「胡扯一下」飞书群。
2. 群中添加曾老师飞书账号，要求曾老师拉群进入「胡扯社群共创」飞书群。
