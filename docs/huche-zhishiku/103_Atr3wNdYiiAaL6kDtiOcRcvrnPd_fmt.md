
# Deepwiki：程序员们真的不用写文档了

> 来源：[`https://huchegames.feishu.cn/docx/RWmNdWN1oofmtexxBd3cKp75ntf`](https://huchegames.feishu.cn/docx/RWmNdWN1oofmtexxBd3cKp75ntf)

> 🔗 原文链接：`https://mp.weixin.qq.com/s/Spfnf7ZiHCkIQwbzfHlOCA`

给我一个 Github 库，送你一个 完整 Wiki。

DeepWiki 真是一个让人惊艳的文档工具。提供一个 Github 地址，它会使用 $500 每月的 `Devin.ai` 工具分析这个库，并自动生成一个 Wiki 网站。

`https://deepwiki.com/`

为了测试，我提供了一个自己在 11 年前写的 `lua` 库：

`https://github.com/zrong/lua`

![](img/cac724a284c8e125c5b950ae82b35311.png)

过了 5 分钟左右，DeepWiki 生成了关于这个 `lua` 库的 Wiki：

`https://deepwiki.com/zrong/lua/`

Wiki 对这个库项目提供了对库功能的分析，给出了每个模块的结构和用法。

![](img/cd848f50bc6e4bb1225c92f99caba905.png)

我在 Wiki 中继续对 `Devin` 提出问题：

> 如何调用库中工具进行 `socket` 通信？请给出一个实际的例子。

`Devin` 搜索了库并给出了相应的范例：

![](img/f6855c81635363d1fd25789f4569ceb4.png)

具体回答如下：

`https://deepwiki.com/search/-socket_2d2e1388-399c-4513-acd3-e02d8064c652`

1. 程序员最讨厌写文档
