## **构建代理的三大核心支柱**

演讲围绕构建代理的三个关键部分展开：构建 (Build)、连接 (Connect) 和优化 (Optimize)。

1.  **构建 (Build):**

+   **基础模型：** 以 Claude 4 系列作为基础，具备增强的推理能力、记忆支持、改进的工具调用和远程规划能力。

+   **可复用组件：** 提供可复用的组件，以节省宝贵的工程资源。

1.  **连接 (Connect):**

+   模型的智能程度取决于用户引入的数据。

+   帮助用户引入更多上下文，以增强模型的智能。

1.  **优化 (Optimize):**

+   交付可靠、稳定、高性能且经济高效的服务。

## **一、构建 (Build) - 代码执行工具 (**Code Execution Tool)

+   **需求背景:**

+   许多任务（如高级数据分析、电子表格深度分析）仍需要传统软件开发能力。

+   人工编写的代码具有可审计性、高性能和可重复性。

+   Anthropic 模型擅长编写代码，因此可以赋予 Claude 一个“计算机”来编写和执行代码。

+   **工作原理示例 :**

+   客户端调用 Claude。

+   请求被发送到一个隔离的容器（每个组织都有专用容器）。

+   Claude 判断后选择代码执行工具，编写 Python 代码。

+   代码在容器中执行。

+   执行结果（标准输出、标准错误、生成文件）返回给模型。

+   模型基于结果进行推理，并给出回答（例如，第42个答案，Opus 的幽默）。

+   **API 与设置 :**

+   设置非常简单，使用核心的 Messages API，新增了 "tools" 模块。

+   一个方法调用即可实现强大功能。

+   **Shopify 应用案例:**

+   Shopify 正在使用代码执行工具，通过其 "Sidekick agents" 帮助商家构建店面，进行 A/B 测试并获取洞察。

+   **现场演示 :**

+   **演示1：简单查询:**

+   使用 Opus 4 的命令行客户端。

+   查询“第100个质数是什么？”

+   Claude 成功调用代码执行工具，生成 Python 代码，执行并返回正确答案，并给出幽默回应。

+   **演示2：A/B 测试分析:**

+   通过 Files API 上传 A/B 测试结果文件。

+   要求 Claude 分析数据、比较、计算统计显著性、关键指标并给出建议。

+   模型首先分析电子表格结构，然后编写更深层次代码提取洞察。

+   如果初步结果不理想，模型会进一步深入分析（例如，Opus 不会轻易放弃）。

+   最终给出业务建议并附带分析依据。

+   **代码执行工具总结:**

+   Anthropic 托管的计算环境。

+   灵活、开发者可控，容器隔离。

+   提供50个免费容器小时，支持付费扩展。

+   即日可用。

## 二、连接 (Connect) - 引入外部数据与工具

+   A. 网页搜索工具 (Web Search Tool)

+   **需求背景:**

+   模型训练数据有时间限制，需要获取最新信息（如金融、法律、编码API文档等）。

+   实时信息至关重要。

+   **工作原理示例:**

+   查询：“过去三个月宣布的最重要的技术突破是什么？哪些上市公司会受益？”

+   Claude 不仅转换查询，还会对整体任务进行推理。

+   首先进行广泛查询以了解技术突破，从搜索引擎获取结果（标题、URL、内容）。

+   模型基于上下文决定下一步，可能深入某个趋势（如小型语言模型）查找相关公司。

+   整个过程可能涉及多次搜索迭代，都在一个API调用内完成。

+   最终报告会附带引用和脚注。

+   **API 与功能:**

+   基于 Messages API，工具调用方式类似代码执行。

+   可限制搜索域（如特定于客户支持）。

+   可控制最大搜索轮次以节省 token。

+   **Cora 应用案例:**

+   Cora 用于构建消费者代理，重视实时更新的信息。

+   **现场演示:**

+   演示1：SWE-bench 得分查询:

+   查询 Anthropic 模型自3.5版本以来的 SWE-bench 得分。

+   模型自主决定搜索策略和迭代次数。

+   演示2：结合代码执行与网页搜索:

+   问题：“一小时内有多少头大象能通过金门大桥？”

+   模型通过网页搜索获取数据（桥的承重、大象行走速度）。

+   然后使用代码执行工具进行计算。

+   最终给出答案（7000头，看似合理）。

+   **网页搜索总结 :**

+   Anthropic 的“代理式搜索能力”。

+   模型自主决定搜索策略，支持引用，完全可审计。

+   高度可组合，开发者可控，价格合理，即日可用。

+   **B. MCP (模型选择的插件/工具)** 连接器 (MCP Connector)

+   **需求背景:**

+   行业对 MCP (Model-Chosen Plugins/Tools) 热情高涨，生态系统迅速发展。

+   Claude AI 已支持远程 MCP。

+   客户希望在自己的代理中利用 MCP 生态系统。

+   **工作原理示例:**

+   复杂场景：客户端 + 3个不同的 MCP（如 Asana, 图像生成, 邮件发送）。

+   任务：“创建一封关于我的Asana项目状态的邮件，包含创意和激励性图片，并发送给团队。”

+   Claude 协同多个 MCP：

1.  调用 Asana MCP 获取任务列表（通过 OAuth 安全认证）。

1.  可能需要多次调用 Asana MCP 来定位具体项目和任务。

+   **图像生成与邮件发送:**

+   **图像生成：** Anthropic 当天不发布图像模型，但有大量 MCP 可用。

+   许多图像 MCP 是本地的，但 Claude AI 支持远程 MCP。

+   Cloudflare 提供 MCP 远程服务，可将本地 MCP 安全托管。Anthropic 已将一个开源 MCP 托管在 Cloudflare 上。

+   模型调用此服务生成“火箭发射”的激励图片。

+   **邮件发送：** Claude 整合任务信息和图片，撰写邮件。

+   使用 Zapier MCP 服务器发送邮件（Zapier 连接了数百个企业服务）。

+   Anthropic 配置为仅暴露 Gmail 功能。

+   **现场演示结果:**

+   成功展示了收到的包含任务状态和图片的邮件。

+   **API 与设置:**

+   基于 Messages API，新增 mcp_servers 属性，列出 MCP 服务器的 URL 和名称。

+   需要时传递 OAuth token。

+   **可用远程 MCP:**

+   已有多款远程 MCP 上线（任务管理、支付、视频创建等）。

+   **Zapier 应用案例:**

+   Zapier 认为这对其共同客户非常有价值，客户可以用 Anthropic MCP API 和 Zapier MCP 轻松构建强大代理。

+   **完整流程演示:**

+   再次演示了从 Asana 获取任务 -> 代码执行分析数据 -> 网页搜索相关新闻 -> MCP 生成图片 -> Zapier MCP 发送邮件的完整流程。

## 三、优化 (Optimize)

+   提示缓存 (Prompt Caching):

+   复用常用提示部分，节省容量、成本和延迟。

+   原5分钟缓存命中时间，现提供新选项可延长至1小时，仍享受90%缓存命中折扣。

+   批量处理 (Batch Processing):

+   高效处理大量数据。

+   现已支持网页搜索、代码执行和 MCP 连接器。

+   是异步的代理式 API，提供50%折扣。

+   **优先层/专用容量 (Priority Tier / **Dedicated Capacity):

+   为需要高可靠性和专用容量的客户提供。

+   即日起可购买月度容量包，享受折扣和99.9%可靠性。

## **总结与展望**

+   **构建：** Claude 4、远程规划、代码执行。

+   **连接：** 通过网页搜索和 MCP 连接器引入数据。

+   **优化：** 提示缓存、批量处理、优先层。

这是一个全面且强大的工具集，旨在赋能开发者构建复杂、智能且高效的代理应用。
