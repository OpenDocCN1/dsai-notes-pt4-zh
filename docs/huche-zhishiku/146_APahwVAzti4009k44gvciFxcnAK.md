## Taking Claude to the Next Level

https://www.youtube.com/watch?v=nZCy8E5jlok

本次演讲由Anthropic的研究产品经理Lisa Crowoot主讲，旨在介绍Anthropic最新推出的模型——Claude 4 Sonnet和Opus，并探讨如何将AI代理提升到新的水平。

## **一、下一代AI代理的愿景**

Anthropic希望Claude能做到三件事：

1.  **协同工作：** 能够与用户并肩工作，并适应用户的工作方式。

1.  **独立执行：** 能够完全独立地完成需要多步骤的任务。

1.  **持续表现：** 在连续数小时的工作中保持稳定性能。

### 愿景示例：OAuth 2.0系统重构项目

+   **协同模式（增强而非自动化）：** 用户负责编写需求和计划，Claude负责具体实现。在此过程中，Claude会像优秀的工程师一样，发现并挑战用户遗漏的需求，共同实现更高质量的成果。

+   **独立模式：** 将整个重构任务交给Claude。它能制定全面的计划，利用网络搜索和文档搜索获取最新信息，遵循公司标准和最佳实践编写生产级代码，编写测试，识别并修复错误，并记住反馈以避免再次犯错。在这种模式下，信任和沟通至关重要。

+   **超越即时响应：** 传统上Claude能以秒级速度完成用户数分钟或数小时的任务。而我们的愿景是让Claude能够处理需要数小时才能完成的复杂任务，这将极大地扩展AI代理的能力范围。

**总结愿景：** 能够与用户协同工作，在独立工作时建立信任，并能承担需要持续专注的复杂任务。

## 二、Claude 4 的核心改进

Claude 4 Opus和Claude 4 Sonnet的发布，通过以下四个主要改进领域，使上述愿景成为现实：

1.  **扩展的思考能力与工具使用：**

+   基于Claude 3.7 Sonnet的混合推理（即时响应或深度思考）能力。

+   新增测试版功能：Claude可以在思考和工具使用之间交替。

+   **示例：** 分析自行车租赁数据。Claude首先策略性思考（打印文件头），然后深入规划（寻找小时、用户类型、季节和天气模式），最终成功发现有趣的模式（如休闲用户与注册用户的不同使用时间、傍晚通勤模式、晴天租赁量是雨天的1.8倍）。

1.  **记忆能力：**

+   对下一代代理至关重要：避免重复提醒，只记住最重要和最显著的事实。

+   Claude Opus 4表现卓越： 能够访问外部文件系统进行读写，制定、记住并跟踪计划，持续工作数小时。

+   **宝可梦游戏示例：** Claude Opus 4能精确跟踪宝可梦的训练进度（如已进行64场战斗，相当于12小时的连续游戏），并将其记录在记忆文件中，保持对训练目标的专注。这解锁了更长时间跨度的代理轨迹。

1.  **遵循复杂指令的能力：**

+   随着代理系统日益复杂，Claude的行[为指令（系统提示词](http://claude.ai/)）变得越来越长（例如，Claude.AI的系统提示词约16,000个Token）。

+   Claude 4模型经过专门训练，能够遵循长于10,000个Token的复杂系统提示词中的指令。

+   现在更容易控制Claude何时使用工具、何时不使用工具。

+   这一改进使[Claude.AI](http://claude.ai/)的系统提示词大小减少了70%。

1.  减少“奖励破解”（Reward Hacking）行为：

+   **定义：** 模型通过走捷径而非真正解决问题来达到结果（例如，硬编码测试或注释掉它们）。

+   这种行为极大地破坏了用户的信任。

+   Claude 4模型在评估集上显示出显著降低的奖励破解倾向（降低超过80%）。

+   这意味着用户可以更信任Claude以正确的方式完成任务，并更诚实地表达其局限性和不确定性。

**总结改进：** 这四项改进共同作用，使Claude在更长的时间范围内变得更强大、更连贯、更值得信赖。

## 三、使用Claude 4 的实用技巧

1.  **模型选择：**

+   **最佳实践：** 在自己的评估和产品中测试模型以做出最终决定。

+   **Claude Opus 4：** 最强大的前沿智能模型，适用于最复杂的任务，如大型复杂代码库中的编程、代码迁移或重构、长期代理任务、规划和编排。经验法则：如果Sonnet 3.7在您的评估中得分60-70%，那么Opus会是很好的测试对象。

+   Claude Sonnet 4： 快速高效，适用于Sonnet 3.7目前擅长的用例。在代理编程、应用程序开发、新项目代码生成以及任何有人机交互的用例中表现出色。

1.  **调整提示词：**

+   Claude 4模型默认“不那么过度积极”（overeager），与Sonnet 3.7不同（Sonnet 3.7有时会过度完成任务，例如要求改按钮颜色却生成整个应用）。

+   如果您的提示词中包含旨在抑制Sonnet 3.7过度积极行为的语言，请将其删除，因为Claude 4不再需要。

+   如果确实希望模型“超常发挥”，请在提示词中明确告知模型。

+   模[型对提示词中的细节](http://claude.ai/)更加关注：检查您的提示词以确保鼓励了您期望的行为（例如，一个XML标签的拼写错误曾导致Claude.AI偶尔使用错误的引用标签）。

1.  **工具使用：**

+   可以提示Claude 4模型并行调用工具，同时运行多个任务。

+   在使用交替思考和工具使用时，可以告诉Claude具体思考什么（例如，“仔细思考搜索结果质量并计划下一步”）。

+   在提示词中明确告知Claude何时应该和不应该调用工具，这在解决工具过度触发问题上非常有效。

## **四、总结与展望**

Anthropic致力于构建一个长期愿景中的Claude：能够与用户并肩工作，并能长时间持续地为用户完成工作。Claude 4模型通过其交替思考和工具使用、记忆能力、改进的指令遵循以及减少的奖励破解行为，非常适合作为AI代理。

**建议：**

+   开始试验，使用Opus处理最复杂和雄心勃勃的任务，Sonnet处理其他所有任务。

+   投入时间进行提示词工程，微小的改变可以带来巨大的性能提升。

+   与Anthropic分享您的反馈，这将帮助他们使下一代Claude变得更好。

## **五、问答环节要点**

+   **基准测试与实际应用：** Anthropic通过“瑞士奶酪”测试方法（包括基准测试、内部员工广泛使用、早期访问客户测试）来评估模型，认为基准测试并非衡量模型好坏的唯一方式，实际应用表现同样关键。

+   **多模态能力：** Claude模型支持图像识别和响应，这对于代理能力非常重要（例如，前端设计反馈）。Anthropic将继续改进多模态输入能力。

+   **工具调用作为调查机制：** 有用户提出将工具调用作为情境分析的调查机制（例如，选项A/B/C），Anthropic对此表示兴趣，希望了解更多。

+   **大型遗留代码库导航：** Anthropic正努力提升Claude的“代理式搜索”能力（即搜索、思考、再搜索），并结合记忆能力（Claude可以记录代码库中特定信息的位置），以帮助模型更好地导航大型复杂代码库。

+   **思考长度控制：** 用户可以控制模型思考的最大长度（思考预算），模型会根据任务需求自适应。目前无法指定精确的思考Token数量，但可以设置上限。

+   **反馈机制和代码注释：** 用户可以通过与Anthropic员工交流或在线反馈表提供反馈。对于代码注释的改进（减少不必要的评论），由于模型本身不那么“过度积极”且指令遵循能力更强，这方面应会有所改善。
