## 曾老师的公众号

「曾嵘胡扯的地方」是一个关注AI、游戏、互联网前沿资讯的公众号。撰稿人曾老师基于丰富的创业经验和公司管理经验，多年的游戏研发经验，全栈编程和自研+自发经验，二十多年的写作经验，持续以公众号为阵地，进行高频输出和有效讨论。公众号追求松弛感，提供正能量，为群友提供价值，为行业做点贡献。
