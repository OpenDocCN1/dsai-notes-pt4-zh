## 如何控制3D视图视角

+ 按住鼠标中键可以360度观察物体，另外在左上角“编辑”-“偏好设置”-“视图切换”-“围绕选择物体旋转”，这时候中键选择会跟着你选中的物体

+ `shift + 鼠标中键`是平移观察

+ 滑轮缩放空间

+ 摄像机视图

## 如何控制物体模型？

+ 点击物体按`x`删除

+ `shift+A` 新建物体

+ 移动物体快捷键是`g`（点击一下而不是持续点击）`g`状态下按`xyz`就会水平垂直上下移动

+ 缩放物体快捷键是`s`（点击`s`后拖动鼠标）`s`状态下按`xyz`就会水平垂直上下缩放，基础设置是以你当前视图中心放大缩小，在左上角“编辑”-“偏好设置”-“视图切换”-“缩放至鼠标位置”

![](img/c4919680ee8cf741f260e1e0a34e5b60.png)

+ 旋转快捷键是`R`，`R`状态下按`xyz`就会水平垂直上下缩放

+ 隐藏物体快捷键是`h`，`shift+h`没有选中物体隐藏

+ `shift+D` 移动并复制物体

## 游标和原点

游标在哪里｜新建物体出现在哪里｜`shift + 右键`就行｜需要鼠标

`shift + s` 选择选中项到游标，让选中物体转移到游标

![](img/c67fd1070a26824e687712b301c7b15b.png)

`shift + c` 游标快速回到中心点

游标可以作为物体旋转的轴心点使用

![](img/cbe797efa93d100c30d8d1a85fc4e89c.png)

![](img/0c1c558aeded339450abe06b52c60849.png)

切换原点后，要在选项取消仅影响原点

同理，选择物体后，选项选择仅影响原点，按`G`就可以将原点移动到物体之外的地方。再关闭仅影响原点后，这时候猴头会跟着原点位置变化而变化

不同物体都受原点影响

![](img/4b93706c9cdeeaccd45597b0bffe7d61.png)

### 坐标系和轴心点

在`G`移动模式下，按住`ctrl`移动可以吸附网格进行移动

红色线是`X`轴，绿色是`Y`轴

![](img/0f0b2226f8c9f7cedbaa66e1b395d51d.png)

以物体本身为坐标系来移动，默认是全局坐标系，在选择物体全局坐标系情况下，你按一下`z` 再按一下`z`就会从全局切换到局部

![](img/0e18dbbb4e65a18a92be44776050ba9d.png)
