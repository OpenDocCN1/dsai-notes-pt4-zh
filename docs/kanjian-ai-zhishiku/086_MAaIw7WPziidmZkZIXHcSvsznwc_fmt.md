
# 20241018日报

> 来源：[https://jlqyxzzvbk.feishu.cn/docx/Ts7Wdxt1Font1CxjXhkcEz7yntY](https://jlqyxzzvbk.feishu.cn/docx/Ts7Wdxt1Font1CxjXhkcEz7yntY)

+ **Suno** 推出图片和视频生成音乐功能，用户可上传视频或图片，输入提示词，即可生成带配乐的30秒视频。
+ **Hallo2** 发布音频驱动生成说话视频模型，输入人物图片和音频，即可生成该人物说话的视频，并实现嘴型同步、最高4K画质、最长1小时。
+ **TANGO** 推出通过音频生成说话视频的功能，用户可提前提供录制好的半身或全身视频，TANGO会将输入音频和嘴型同步，并选用合适的视频实现音频和动作相匹配。
+ **Anthropic** 对 Claude iOS 和 Android 应用进行了全新改版，并推出了 iPad 版本，同时新增了对移动端项目的支持。用户可以在移动端搜索聊天记录、添加项目知识以及修改每个项目的自定义指令。
+ **Google** 为 NotebookLM 推出新功能，包括自定义音频概述、团队协作以及在工作时收听音频概述等。
+ **Luma AI** 推出使用 Emoji 作为提示词生成视频的功能，用户只需输入任何 Emoji 即可生成视频。
+ **OpenAI** 发布 ChatGPT Windows 桌面应用早期测试版，ChatGPT Plus、Enterprise、Team 和 Edu 用户均可参与测试。
+ **Perplexity** 推出企业版最受欢迎的功能——内部知识搜索，用户可同时搜索组织文件和网络信息。
+ **Perplexity** 发布 Perplexity for Finance，提供实时股票报价、历史收益报告、行业同行比较和公司财务的详细分析，并配有友好的用户界面。
+ **Perplexity** 推出 Spaces 功能，允许所有用户自定义 Perplexity 以重复使用，用户可以上传和存储文件、搜索文件和网络信息、选择 AI 模型、编写自定义指令以及邀请他人进行协作搜索。
