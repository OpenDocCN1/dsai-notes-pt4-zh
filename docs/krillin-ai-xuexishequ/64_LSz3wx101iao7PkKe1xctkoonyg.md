Use web content as context by linking to external websites and resources

使用外部网站和资源链接，将网络内容作为上下文

## Paste Links 粘贴链接

In order for Cursor to visit a link before paste the link and you’ll see that the link is “tagged”

为了在粘贴链接之前让 Cursor 访问链接，你会看到该链接被“标记”

![](img/b896769d947e06ab3896ed1a3820bf99.png)

## Remove Links 删除链接

By default, we automatically parse links and turn them into `@Links` in Chat. If you prefer to have the link as plain text, click on the link and then click `Unlink`.

默认情况下，我们会自动解析链接并将它们转换为 Chat 中的 `@Links` 。如果您希望将链接作为纯文本显示，请点击链接然后点击 `Unlink` 。

You can also paste without formatting (hold `Shift`) to make sure the link is not tagged

您也可以粘贴不带格式的内容（按住 `Shift` ）以确保链接未被标记
