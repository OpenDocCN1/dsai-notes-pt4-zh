## 一、常用AI助手推荐

首先和大家分享几个我常用的AI写作工具：

1. ChatGPT：最全能的写作助手，可以用来查找语法错误、润色文本、翻译，甚至模拟同行评议

2. Grammarly：老牌语法检查工具，对学术写作很友好

3. DeepL：翻译质量优于谷歌翻译，特别是学术文本的翻译

## 二、核心提示词模板

1. 文本打磨

作为非母语者，我们写英文难免有些表达不够地道。这组提示词可以帮你改善语言表达：

```
 As a non-native English speaker, kindly help me revise the following text for improved understanding and clarity.
 
 请以母语者的视角帮我修改以下文本，使其更流畅、更专业。
```

2. 增强说服力

基金申请最重要的就是要说服评审专家，这个提示词能帮你提升文本的说服力：

```
 Please provide feedback on my writing style and how I can make it more persuasive and compelling for the grant reviewer.
 
 请分析我的写作风格，提供建议让它对评审专家更有说服力。
```

3. 优化申请结构

好的结构能让评审专家快速抓住重点。这是我常用的结构优化提示词：

```
 I want to improve the overall structure of my Specific Aims. What tips do you have to structure it more effectively?
 
 请帮我优化研究目标部分的整体结构，使其更清晰有力。
```

4. 对标基金要求

每个基金项目都有其特定的要求，这个提示词能帮你更好地对标：

```
 How can I better align my proposal to specifically address the [insert specific criteria] outlined in this funding announcement?
 
 如何让我的申请更好地契合该基金项目的[具体要求]？
```

5. 标题优化

一个好标题能让评审印象深刻：

```
 Suggest five potential titles for a grant proposal that will attract readers while encompassing the research question and key elements.
 
 请根据我的研究内容，建议5个既能吸引评审注意，又能突出创新点的标题。
```

6. 应对挑战

提前预判可能的质疑，准备充分的应对策略：

```
 Help identify potential challenges that may arise with my proposed aims and suggest strategies to address them.
 
 请帮我找出研究方案中可能存在的挑战，并提供应对策略。
```

## 三、实用小贴士

1. **善用组合**：建议将相关提示词组合使用。比如，先用语言优化提示词完善表达，再用结构优化提示词调整框架。

2. **具体化**：提示词中的方括号要替换为具体内容。比如基金项目的具体要求、研究目标等。

3. **迭代优化**：不要期待一次就完美，可以根据AI的反馈逐步改进。

4. **保持批判**：AI只是助手，最终还是要靠我们的专业判断。特别是涉及专业内容时，一定要仔细核实。
