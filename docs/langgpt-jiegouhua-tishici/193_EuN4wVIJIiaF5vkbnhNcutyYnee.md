## 大赛规则

### 初赛规则

1. 通过专属大赛页面进行报名，并加入大赛服务群；

2. 参赛选手可免费领取两个月ZelinAl专业版使用权 (报名成功后自动分配)及讯飞星火tokens以及培训；

3. 参赛选手进行企业级AI应用构建并提交到应用市场比赛专区；

4. 以应用热度作为唯一评选标准，热度高排在前；

5. 最终以应用排名进行选取，如果一个人有多款应用，则仅录入成绩最好的应用；

### 决赛规则

1. 线下赛场地由天九集团提供；

2. 初赛排名前50名进入决赛；

3. 主办方根据难、中、易三个档每档设置3道题，由选手自由选择，难度越高分数越高，每位选手只能选择1道，并在规定时间完成；

4. 评选时，会根据题目验证集进行评判，如果分数相同，则先提交的分数高；

5. 评价维度:待以上题目确认后ZelinAl相关同事给出相应评价维度；

6. 对线下比赛进行排名，排名完成后，公布成绩及获奖名单并举办颁奖仪式；
