
# 1、LLM & LLMOps研究

> 来源：[https://my.feishu.cn/docx/R3ybdOYyJozUVaxN9NvcLH3OnCf](https://my.feishu.cn/docx/R3ybdOYyJozUVaxN9NvcLH3OnCf)

LLMOps 是大型语言模型运维（Large Language Model Operations）的缩写，涉及管理支持大语言模型的应用程序生命周期的工具和最佳实践。

## 特性说明

Coze 非开源，但是基于头条的流量，所以用户量大，插件和工作流多，向量模型较差，知识库调用准确度差强人意。

Fastgpt、Dify、LinkAI 等支持本地部署，也支持企业定制，插件和工作流需要自己搭建，知识库私密性强，支持不同的模型配置，定制化更高。

因此，个人创作者推荐用 Coze，个人开发者推荐使用 Dify，企业推荐用 Fastgpt、Linkai。
