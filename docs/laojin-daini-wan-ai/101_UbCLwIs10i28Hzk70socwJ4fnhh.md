# 11 Power Words That Supercharge AI Prompts

> 来源：[https://my.feishu.cn/docx/QiQddYGO4oLqWCxf6HFcBTRUnL3](https://my.feishu.cn/docx/QiQddYGO4oLqWCxf6HFcBTRUnL3)

**使用场景或用例：**适用于希望优化 prompt 表达力的用户，如营销文案、报告撰写、分析解读等场景；通过引入关键词提升 AI 响应精准与风格。

```
actionable, concise, insightful, simplified, bullet‑pointed, prioritized, strategic, persuasive, comparative, contextual, visual
```

```
可执行（actionable）、简洁（concise）、有洞察力（insightful）、简化（simplified）、要点化（bullet‑pointed）、优先排序（prioritized）、战略性（strategic）、有说服力（persuasive）、对比性（comparative）、有背景（contextual）、视觉化（visual）
```
