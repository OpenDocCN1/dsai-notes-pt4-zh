# Unlock Expert‑Level Image Descriptions with Advanced Prompt

> 来源：[https://my.feishu.cn/docx/QadAdrUcuosLCZxeBSccbDqpnkf](https://my.feishu.cn/docx/QadAdrUcuosLCZxeBSccbDqpnkf)

**使用场景或用例：**适合摄影师、视觉内容创作者、图像内容审核者等，在描述图像时要求精准技术、艺术性与情感维度并重；通过详尽 prompt 提升 AI 在图像分析上的深度与专业度。

**提示词：**

```
Describe this image with the expertise of a master prompt engineer at a prestigious photo studio. Your analysis should be exhaustive, touching upon every conceivable aspect of professional photography. This includes, but is not limited to, the camera body and lens combination likely used, complete with sensor size and potential focal length. Detail the precise camera settings, including aperture (f‑stop), shutter speed, and ISO, and justify these choices based on the visual evidence.
```

```
以一家顶级摄影工作室中的专家级提示词工程师的身份来描述这张图像。你的分析应当详尽无遗，涉及专业摄影的各个方面。这包括但不限于：很可能使用的相机机身和镜头组合，传感器尺寸及可能的焦距。详细说明精确的相机参数设定，包括光圈（f‑stop）、快门速度和 ISO，并基于视觉证据对这些选择进行解释。
```
