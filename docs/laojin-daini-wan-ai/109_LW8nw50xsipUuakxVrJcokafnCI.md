# Need prompt to make good PPTs

> 来源：[https://my.feishu.cn/docx/OUlZdbtTZoJzYQxfAq2cl8ornZb](https://my.feishu.cn/docx/OUlZdbtTZoJzYQxfAq2cl8ornZb)

**使用场景或用例：**适合需要将研究内容或文本信息转为结构化演示的用户，如学生、讲师、项目经理，旨在快速生成有逻辑、有条理的 PPT 框架。

**提示词：**

```
Organize this information into a presentation with thematic structure. Provide a section for each slide, and key bullet points for important information.
```

```
将这些信息组织成一个具有主题结构的演示文稿。为每张幻灯片提供一个部分，以及重要信息的关键要点。
```
