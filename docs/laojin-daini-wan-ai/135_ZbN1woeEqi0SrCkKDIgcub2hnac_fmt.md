> 来源：[https://my.feishu.cn/docx/NhHBdRDgiok4PaxoDmOcD1T5n6f](https://my.feishu.cn/docx/NhHBdRDgiok4PaxoDmOcD1T5n6f)

## ChatGPT Canvas 是什么？

老铁们，咱就说平时用ChatGPT做写作或者编程时，有没有发现对话框有时候太局限？

尤其是你只想改某一段话，结果它偏要给你改整篇。

编程时更是如此，想要管理代码版本？几乎没戏。

好在OpenAI看到了这个问题，推出了 ChatGPT Canvas！

这个Canvas其实是个独立的工作窗口，能让你在里面进行更高效的写作和编程，不再被局限在小对话框里。

简单来说，Canvas就是一个嵌入ChatGPT的文本和代码编辑器，它能帮助你更精准地操作，让工作效率大幅提升。

## 核心功能解析：Canvas能做什么？

### 1. 精准操作，告别“全篇乱改”

用过ChatGPT的小伙伴都知道，很多时候我们只想润色某一句话，结果它把整篇文章都改了，气人不？

Canvas解决了这个问题，你可以直接选中某段文字或者代码，ChatGPT会根据上下文提供精准修改，而不会影响其他部分。

### 2. 实时编辑，效率倍增

Canvas不仅让你能直接在生成的内容上编辑，还大大简化了反复输入提示词的繁琐过程。

写作时可以随时调整文字，编程时也能实时修改代码，操作起来更加顺手，再也不用为反复提示抓狂了。

### 3. 版本管理，回溯没问题

编程小伙伴肯定都知道，代码的版本管理有多重要。

Canvas支持你在不同代码版本间快速切换，并且每次修改都会被记录下来。即使改错了，也能一键回到之前的版本，再也不用担心“历史迷路”。

## 怎么用Canvas？老金教你

讲了这么多，具体如何上手呢？别急，老金来手把手教你：

### 1. 先确保你是ChatGPT Plus或Team会员

如果还没订阅，那就赶紧登录ChatGPT，订阅Plus或者Team会员，因为Canvas功能目前只有付费用户才能用。

### 2. 选择支持Canvas的GPT模型

进入ChatGPT首页，左上角选择 `GPT-4o with Canvas`，这个模型支持Canvas功能，非常适合需要编辑和协作的写作或编程项目。

![](img/523bf0f28795d8c639d7c286f87af5a5.png)

### 3. 如何开启Canvas窗口？

当你生成的内容超过10行时，Canvas会自动启动。如果想手动开启，可以直接在对话框里输入 `open a canvas/in canvas`、`open a coding canvas`，分分钟搞定！

> 注意：canvas开启后，不能实时联网，因此让他先进行搜索。

![](img/28cb5afc09effa42bebf04a14b75a294.png)

为此，我们可以让它先进行搜索后，再开启canvas，以上下文形式传入信息。

## 快捷操作指南

Canvas为大家提供了很多快捷键，能让工作效率翻倍。下面是老金为你整理的几个实用功能，拿好不谢：

### 写作快捷键：`open a canvas/in canvas` 开启

> 不选择片段，双击按钮则会全文编写

+ 建议修改：选中文本后，ChatGPT会给出内联建议，帮助你优化文章的语法和结构。

+ 调整长度：通过滑动条快速调整文章的长度，短文长文随你切换。

+ 改变阅读水平：可以根据受众调整文章的阅读难度，从幼儿园水平到研究生水平随意转换。

+ 添加润色：帮你检查文章的语法、清晰度和一致性，让文章质量更上一层楼。

+ 添加表情：增加 `Emoji`，看起来更加生动有趣，适合📕等。

![](img/a6d96805de4a0f7b0043d2b89cc0a35a.png)

### 编程快捷键：`open a coding canvas` 开启

> 不选择片段，双击按钮则会全文编写

+ 增加注释：提供代码注释，便于查看，尤其利好我这样看不懂代码的小白。

+ 增加日志：若存在运行 `BUG`，可以增加日志，以便于观察到底是哪里出了问题。

+ 代码审查：选中代码段，ChatGPT会给出优化建议，提升代码的结构和性能。

+ 修复 Bug：自动检测代码中的错误并提供修复方案，`Bug`轻松搞定。

+ 代码移植：支持一键将代码转换成其他语言，比如 `Python`、`Java`、`JavaScript` 等，开发效率瞬间提升。

## 进阶使用技巧

虽然Canvas还处于测试阶段，但已经展现出强大的功能。这里有几个进阶小技巧，能让你用得更加得心应手：

### 1. 恢复历史版本

万一不小心改错了代码或文章怎么办？别慌，Canvas右上角有个“撤销”按钮，点击它可以轻松回到之前的版本。写作和编程都特别好用，再也不怕误操作了。

### 2. `Markdown` 格式支持

在Canvas里，你可以使用基础的 `Markdown` 格式，比如加粗、斜体、项目符号等。这让文章的排版更加整洁，代码也更加清晰明了。

### 3. 更改历史查看

清晰的查看更改记录，以不同的颜色进行了区分。

## 常见问题解答（FAQ）

### 1. ChatGPT Canvas需要付费吗？

是的，Canvas功能目前只对Plus和Team会员开放。

### 2. Canvas可以在手机上用吗？

暂时还不行，目前Canvas功能只支持网页版。

### 3. Canvas支持图片处理吗？

暂时不支持图片上传功能，但未来可能会推出。

### 4. 如何恢复Canvas的历史版本？

点击Canvas界面右上角的“撤销”按钮，可以回到之前的编辑版本。

### 5. Canvas支持什么格式？

目前仅支持基础的 `Markdown` 格式，未来可能会加入更多高级格式化功能。
