## 技术架构

扣子空间的底层核心是MCP（Model Context Protocol，模型上下文协议）技术架构，通过标准化协议层抽象，将传统AI的"工具驱动"执行模式升级为"意图驱动"。这意味着AI不再需要预设流程，而是能深度理解用户意图后，自主选择合适工具组合完成任务。

例如，当用户需求为"生成杭州旅游攻略"时，MCP会自动协调高德地图插件获取景点数据、墨迹天气插件获取实时天气、图像生成工具制作景点示意图，最终整合成结构化网页。

目前已有十几个可调用的插件，如高德地图、飞书、音乐生成、墨迹天气、图像生成等。这些扩展的插件能满足部分需求，未来开发者还能通过"扣子开发平台"发布自定义插件，拓展Agent的能力边界。

## 保姆级实操｜三个“一句话” 实操案例

### 案例 1｜10 分钟做个“记账小网页”（用 HTML 预览）

目标：做个能**填写收入/支出并导出 CSV**的小网页。

怎么做（就1步），丢口令：

```
做一个可填写“日期/类别/金额/备注”的记账网页：  
要求：  
① 表单提交后把记录追加到下方表格；  
② 表格支持删除/编辑；  
③ 提供“导出 CSV”按钮；  
④ 样式简洁，移动端自适应。  
请给 index.html / style.css / app.js 三文件代码。
```

直接生成完成，测试可用，右上角还有手机模式预览。

![](img/0e1b438986a6d79c8132d895be236bce.png)

切换成代码后，右侧就变成下载了，可以把代码下载到本地，继续优化并使用。

## 优势与局限

### 优点在哪？

**简单**：这玩意儿最大的好处就是没门槛。不管你是不是程序员，拖进来就能用，就跟聊天一样简单。

**全能**：功能给得足。小到帮你回个邮件，大到给你生成一份带数据图表的报告，甚至直接给你搭个小网站，它都能一条龙给你办了。老金我实测，15分钟搞定个带地图的旅游攻略，比自己吭哧瘪肚弄快多了。

**有潜力**：它现在已经内置了一些像金融、用研领域的专家机器人。更关键的是，它支持自己开发插件，生态是开放的。这就跟给手机装APP一样，以后能干的事儿只会越来越多。

### 缺点是啥？

**有点“笨”**：有时候你话说的复杂了，它容易犯迷糊，得多跟它“掰扯”几轮才能听明白。得有点耐心去调教。

**有点“慢”**：干复杂的活儿它得一步一步来，所以会花点时间。要是用的人一多，服务器压力大，偶尔也会卡一下，毕竟免费的午餐嘛，可以理解。

**能力有限**：免费版在处理复杂逻辑和存东西方面还是有瓶颈的。想让它干特别专业的重活儿、大活儿，目前还差点意思，估计得等未来的企业版了。

### 未来能有啥期待？

现在这Coze啊，就像个啥都懂一点的全能实习生。官方的说法是，以后会请来各行各业的领域专家，比如法律专家、营销专家给你打下手，那时候就更专业、更靠谱了。

再加上它不是已经开源了嘛，这就给了各路大神自己动手魔改的机会。

大家一起添砖加瓦，这个AI Agent的生态才能越玩越大，越玩越有意思。路还长，但值得期待！
