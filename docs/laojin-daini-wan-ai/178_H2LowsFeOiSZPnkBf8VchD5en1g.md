
# Reddit MCP

> 来源：[https://my.feishu.cn/docx/O7s2deQmyoq2l1xSHgfcw60Xnod](https://my.feishu.cn/docx/O7s2deQmyoq2l1xSHgfcw60Xnod)

平时喜欢刷 Reddit 的最新热门帖子，需要一条条点开，然后看底下评论，不知不觉半天时间就过去。

现在可以将 `MCP Reddit Server` 这个 MCP 服务器，接入到 AI 助手，帮我们快速获取 Reddit 的热帖，了解最新动态。

支持获取任意 `subreddit` 的热门帖子，抓取完整的内容和评论，支持处理文字、链接和图片。

GitHub：https://github.com/adhikasp/mcp-reddit

## 主要功能

- 获取任意 `subreddit` 的热门话题和讨论内容
- 抓取帖子详细信息，包括评论和互动数据
- 支持文本、链接、图集等多种 Reddit 内容类型
- 提供命令行工具，方便开发者测试和调试

可与 `Claude Desktop` 等 MCP 客户端无缝集成，一键安装即可使用。喜欢逛 Reddit 的同学，可以安装体验看看。
