## 邮件转发配置

打开网页：https://dash.cloudflare.com/

注册后，直接添加域，选择Free计划。

![](img/56c4e47bd6273a03c7816e9b49f855b3.png)

无脑下一步，前往激活就行，什么也不用动。

![](img/876ca9d186cdc95e7ff3112e23223370.png)

这里的两个地址复制回腾讯云。

![](img/a582f13aa61afea7930eb03ab4e89403.png)

Cloudflare里继续下一步，这里显示24小时，实际上几分钟就行。

这里放着等待，然后进行邮箱转发的操作，还是在Cloudflare上。

![](img/8c926807b31d63b4d7a3a8f7998f10df.png)

右下角跳过新手指引，你会看见这样一个页面，挨个点击。

![](img/4fab5078021b2189af7ecc0f78314ca1.png)

启动路由。

![](img/0c9d4ee3396b0bf88ecb14240b7f1d1f.png)

添加邮箱地址并验证，在目标地址里输入。

![](img/7936188b077a7096593754391e281ccf.png)

去你的目标地址邮箱里，进行验证。

![](img/4d6d831d113071774d4ff3a212f274f7.png)

![](img/ebd17ffb0e5fe04b4c1104acde1bd6ca.png)

进行编辑。

![](img/b9ee99dcfd1fc86f4d748b169f91e889.png)

## Windsurf

同理操作即可，原理上没有区别。

额外增加上面作者写的这个操作即可：

```
在Windsurf 中打开命令面板(Ctrl/Cmd + Shift + P),键入Windsurf:Provied AuthToken,然后点击 Enter。
将令牌粘贴到输入框中并提交
需要手动复制 Token 输入。如果遇到注册成功 Token 处于未知的，应该是注册过程中网络没有打开获取 Token 导致的，可以手动获取。最好确认一下网络能够正常注册并且获取 Token。
```
