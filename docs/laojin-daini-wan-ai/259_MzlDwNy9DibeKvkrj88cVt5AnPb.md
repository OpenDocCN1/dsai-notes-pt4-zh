## 使用注意事项

1. 运行环境要求：

   + [确保你有](https://www.google.com/intl/en_pk/chrome/)一个chrome浏览器；如果你没有；下载地址
   + 登录一个账号。
   + 稳定的网络连接
   + 足够的系统权限

2. 使用过程中：

   + 请勿手动关闭浏览器窗口
   + 等待程序自动完成所有操作
   + 看到"脚本执行完毕"提示后再关闭程序

## 运行方法

### Mac 版本

1. 打开终端，进入应用所在目录

2. 运行命令：授权文件可以执行

   ```
   chmod +x ./CursorPro
   ```

3. 运行程序：

   - 在终端中运行：

     ```
     ./CursorPro
     ```

   - 或直接在访达（`Finder`）中双击运行

提示：如果遇到下面的问题；[解决方案](https://sysin.org/blog/macos-if-crashes-when-opening/)

![](img/e36df35bf608373baddc3f2669d0d6b5.png)

### Windows 版本

直接双击运行 `CursorPro.exe`

## 运行效果

双击后，会出现 Windows 阻拦，点击更多信息后，下方会出现仍然运行。

![](img/1ca0acb05152cce3d15f363ae4ebd12b.png)

开启 Cursor 的情况下，点击运行。

![](img/f7523b9916e54213541f19cb77ac5d70.png)

出现按回车退出，代表执行完成。

![](img/38b55a5d219f5f5c4aa5bbaea0161b4e.png)

## 常见问题解决

程序运行过程中卡住：

- 检查网络连接
- 重启程序重试
