## 一、核心王炸：AI 规则生成器 (Generate Cursor Rules)

这绝对是 0.49 最亮眼的功能！

以前写 Cursor 规则（告诉 AI 项目背景、代码规范等）得手动。

现在只需要在聊天框里潇洒地敲下 `/Generate Cursor Rules`，回车！

AI 就会自动分析你的项目代码库，帮你生成一套包含项目概述、文件结构、关键组件/库、甚至设计系统信息的 `.cursor/rules.md` 文件！

彻底解放双手！

极大降低了使用“规则”功能的门槛，尤其是对新手或者项目庞大的情况，简直是神来之笔。

AI 生成的规则让你更快地让 AI “懂你”的项目，后续的编码、调试自然更精准高效。

细节：它会尝试识别项目的主要框架和结构，生成更有针对性的规则。

## 二、沟通升级：多模态上下文支持图片 (MCP Image Support)

现在你可以直接把图片拖拽或粘贴到 Cursor 的聊天框里！

让 AI “看到”图片内容。

遇到 UI 问题、设计稿还原、或者某个 Bug 的截图吧。

直接甩图给 AI！

比你费劲描述半天强多了！

沟通更直观！

解决问题自然更快！

想象一下...

直接把设计稿扔给 AI...

让它帮你写对应的代码...

爽不爽？！

细节：这让 Cursor 的理解能力从纯文本扩展到了视觉层面，交互更丰富。

## 三、精准操控：Agent 终端命令可编辑/跳过 (Improved Agent Terminal Control)

用过 Agent 模式（让 AI 自动执行一系列任务）的朋友可能遇到过...

AI 有时会生成一些你不想执行的终端命令。

现在！Agent 在执行每个终端命令前，会给你一个机会：

你可以选择编辑这条命令！

或者干脆跳过它！

掌控力 Max！

避免了 Agent 执行错误或危险的命令。

让你在使用自动化功能时更加安心和灵活。

![](img/38130536adeb7074e04bddce20fe2f37.png)

## 四、代码审查利器：优化的 Diff 查看 (Optimized Code Review)

在代码审查（Code Review）或者查看 AI 修改的代码时...

新版本增加了一个醒目的 查看更改 (View Changes) 按钮。

点击这个按钮！

代码的差异（`diff`）会以更清晰、更优化的方式展示出来。

哪里增了、哪里删了、哪里改了...

一目了然！

大大提高了 Code Review 的效率。

![](img/236a19642902d01ed7a25282b59d63e5.png)

## 五、一劳永逸：全局忽略文件列表 (Global Ignore List)

现在你可以在 Cursor 的设置里！

配置一个全局的忽略文件/文件夹列表了！

像 `node_modules`, `.git`, `dist` 这些...

几乎每个项目都不希望 AI 去扫描分析的文件或目录...

只需要在全局设置一次！

就能应用到你打开的所有项目中。

再也不用每个项目都去 `.cursorignore` 里重复配置了！

省心！

![](img/c23c8b90d44f3bc4493f15445ff2d5be.png)
