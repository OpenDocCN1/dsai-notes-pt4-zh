# 指令列表

> 来源：[https://my.feishu.cn/docx/XXYgdo1O7oSdO5xdc4Rc8jfInbh](https://my.feishu.cn/docx/XXYgdo1O7oSdO5xdc4Rc8jfInbh)

您可以通过输入命令与 Discord 上的 Midjourney Bot 进行交互。命令用于创建图像、更改默认设置、监视用户信息以及执行其他有用的任务。

Midjourney 命令可以在任何Bot 频道中使用，在允许 Midjourney Bot 运行的私人 Discord 服务器上，或者在与 Midjourney Bot 的直接消息中使用。

## 指令

[/fast](https://docs.midjourney.com/fast-relax)

切换到快速模式。

[/prefer remix](https://docs.midjourney.com/remix)

切换 Remix 模式.

[/relax](https://docs.midjourney.com/fast-relax)

切换到Relax模式。

[/turbo](https://docs.midjourney.com/fast-relax)

切换到 Turbo 模式。

[/public](https://docs.midjourney.com/stealth)

对于专业计划订阅者：切换到公共模式

[/stealth](https://docs.midjourney.com/stealth)

对于专业计划订阅者：切换到隐身模式

[/imagine](https://docs.midjourney.com/quick-start)

使用提示生成图像

[/blend](https://docs.midjourney.com/blend)

轻松将两幅图像融合在一起。

[/describe](https://docs.midjourney.com/describe)

根据您上传的图像编写四个示例提示。

[/prefer suffix](https://docs.midjourney.com/settings-and-presets)

指定添加到每个提示末尾的后缀。

/prefer variability

使用图像网格下方的**V1** **V2** **V3**和**V4**按钮在高和低变化之间切换。

[/shorten](https://docs.midjourney.com/shorten)

提交一个长提示并收到有关如何使其更简洁的建议。

[/show](https://docs.midjourney.com/show-job)

使用图像作业 ID 在 Discord 中重新生成作业。

[/tune](https://docs.midjourney.com/style-tuner)

根据您的提示生成 Style Tuner。Style Tuner 可让您打造自己的 Midjourney 风格并自定义您的工作外观。

[/info](https://docs.midjourney.com/info)

查看有关您的帐户以及任何排队或正在运行的作业的信息。

/help

显示有关 Midjourney Bot 的有用的基本信息和提示。

/invite

获取 Midjourney Discord 服务器的邀请链接。

[/list_tuners](https://docs.midjourney.com/style-tuner)

生成您已创建的所有 Style Tuner 的列表。

/prefer option set

创建或管理自定义选项。

/prefer option list

查看您当前的自定义选项。

[/settings](https://docs.midjourney.com/settings-and-presets)

查看和调整 Midjourney Bot 的设置

[/subscribe](https://docs.midjourney.com/plans)

为用户的帐户页面生成个人链接。

/userid

获取您的 Midjourney 用户 ID
