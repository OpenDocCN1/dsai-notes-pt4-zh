# Describe（描述）

> 来源：[https://my.feishu.cn/docx/Mr8zdtogRowOpaxpeiMcGPEtn0b](https://my.feishu.cn/docx/Mr8zdtogRowOpaxpeiMcGPEtn0b)

#### 该/describe命令允许您上传图像并根据该图像生成四个可能的提示。使用该/describe命令探索新词汇和美学动作。

+   描述功能会生成具有启发性和提示性的提示建议。它不能用于完全重现已上传的图像。

+   **Discord 和**网站之间的 Describe 工作方式略有不同。使用/describeDiscord 中的命令将生成完整的提示，而网站将提供单词和短语建议，以帮助您构建自己的提示。

+   再次“描述”同一幅图像将会提供不同的建议。

## 在 Discord 中

### 使用**/describe**命令

**在 Discord**** 中使用** Mi[djo](https://docs.midjourney.com/v1/docs/image-prompts)urney Bot 时，请使用该/describe命**令。您可以**通过输入图片的 URL（选择该link选项；在此处找到有关在 Discord 中使用图片 URL 的更多信息）或选择存储在设备上的图片（使用该image选项）来提供要描述的图片。

![](img/74b7ddd72bf8d195684b72bb6b66fe88.png)

生成建议后，点击**/imagine**该提示对应的编号按钮。您将有机会在提交之前编辑文本。

**/describe**您还可以使用🔄按钮在同一图像上再次运行命令，或者🎉 Imagine all使用按钮一次生成包含所有四个提示的图像（尽管您没有机会先编辑它们）。

### **/describe**Discord 中的一个例子

如果您使用**/describe**下图中的命令，Midjourney Bot 将建议四个可能生成类似图像的提示：

![](img/8c7653d74fa2cd620a3a0f4a8fa5d0b6.png)

1️⃣ 用紫色圆珠笔在白色背景上画一张波斯猫脸，带有紫色的皮毛，风格不明的艺术家。

2️⃣ 一幅用紫色铅笔画的波斯猫，白色背景，仿照 John Beastman 的风格。

3️⃣ 用紫色铅笔画的一只可爱的波斯猫，白色背景上简单的线条，细节精致，构图优美，具有超现实主义风格，边缘锐利，焦点清晰。

4️⃣紫色铅笔画的异国短毛猫，简单的线条搭配白色背景，细线条和柔和的色彩在特写肖像中营造出柔和细腻的氛围。素描风格将猫描绘成可爱而梦幻的形象，正面的细腻线条展现出复杂的细节。水墨画技法使用低饱和度的深黑色调来创造艺术家的风格。

遗产**/describe**

+   默认情况下，Discord**/describe**会生成最适合版本 6 的提示。

+   如[果您](https://docs.midjourney.com/v1/docs/model-version-5)**在 Discord** 中将默认的 Midjourney 版本设置为 5.0，将生成更短的提示，以便与旧版本/describe配合使用。

## 在 WEB 上

### 来自 Imagine Bar

点击想象栏中的图标可访问网站上的图片参考选项。如果您想要描述的图片尚未出现，您可以从此视图上传。上传后，将鼠标悬停在图片上以显示图标，然后单击该图标以生成建议。

![](img/644e81da0820854041dfe47f7ba22645.png)

**该网站不会像 Di**scord 那样生成完整的提示建议/describe，而是会为您提供各种单词和短语供您使用。单击其中一个生成的短语会将其添加到当前提示的末尾。单击“重新滚动”按钮可生成新的描述，单击“返回”按钮可返回到图像选择工具。

![](img/838453a01eeec80b1e89cbba1aa330fb.png)

### 从工具选项卡

点击侧边栏底部的工具菜单，进入[描述](https://www.midjourney.com/describe)页面。页面将自动填充您[上传的所有图片](https://docs.midjourney.com/v1/docs/using-images)。

**您可以将图像从计算**机拖放到页面上以生成完整提示的建议，就像您/describe在 Discord 中看到的那样。

将鼠标悬停在提示上，然后单击 +copy 按钮将其复制到剪贴板。
