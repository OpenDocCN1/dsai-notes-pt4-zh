
# 作业ID（恢复、升级等使用）

> 来源：[https://my.feishu.cn/docx/Sa9Fdhj5todEcPxKRMrc96vxnA7](https://my.feishu.cn/docx/Sa9Fdhj5todEcPxKRMrc96vxnA7)

您可以使用`/show`具有唯一作业 ID 的命令将作业移动到另一个服务器或渠道，恢复丢失的作业，或刷新旧作业以进行新的变化、升级，或使用更新的参数和功能。

`/show`只对你自己的工作起作用。

---

## 查找职位编号

作业 ID 是 Midjourney 生成的每张图片的唯一标识符。

如下所示：`9333dcd0-681e-4840-a29c-801e502ae424`可以在所有图片文件名的第一部分、网站上的 URL 以及图片的文件名中找到。

### 在网络上

Options您可以通过选择> Copy>找到会员图库中任意图像的作业 ID `Job ID`。

![](img/571d078340d6f28580aae7b174d85435.png)

### 从 URL

在您的 Midjourney 图库中查看图像时，作业 ID 位于 URL 中。`https://www.midjourney.com/jobs/9333dcd0-681e-4840-a29c-801e502ae424?index=0`。

### 从文件名

查看从图库下载的图像时，作业 ID 是文件名的最后一部分。`User_cat_cloud_spirit_9333dcd0-681e-4840-a29c-801e502ae424.png`

### 使用 Discord 表情符号反应

使用信封表情符号 ✉️ 对您已完成的工作做出反应，Midjourney Bot 将向您发送带有其工作 ID 的直接消息。如果您没有收到来自机器人的直接消息，请检查您的 Discord 隐私设置。

![](img/feced6245e9b1f8eeb557072be9f139f.png)

`/show <Job ID #>`在任意机器人频道中使用来恢复工作。
