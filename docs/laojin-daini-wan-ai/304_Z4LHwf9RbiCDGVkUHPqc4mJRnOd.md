# --p（个性化）

> 来源：[https://my.feishu.cn/docx/TNmQdSSgxoa1AYxjQa9cvBf2nDg](https://my.feishu.cn/docx/TNmQdSSgxoa1AYxjQa9cvBf2nDg)

在 midjourney.com 上创建您自己的个性化图像，并在图像上使用个性化参数。

当您对来自社区的图像进行排序和喜欢时，Midjourney 会记录您喜欢的图像类型，并根据这些偏好为您生成图像。

**--p****在 Discord 或网站**的想象栏中将或添加--personalize到提示的末尾。

![](img/a9b2388e5c55958c25458de27384363a.png)

[

个性化使用您在网站上](https://www.midjourney.com/explore?tab=likes)[的图片排](https://www.midjourney.com/rank)名和点赞 (❤️)数据来打造您的独特风格。您自己图片的点赞数不计入。

+

+   随着您对更多图像进行排名和❤️，您的个性化将会不断发展。

+   默**认情况下，--p** 会应用您个性化的最新版本，但您也可以使用旧版本或其他用户的个性化，方法是使用带有参数的个性化代码：--p code。

+   **--p**与 Midjourney 版本 6 和 6.1 兼容。

**--p**只有在网站上对足够多的图片进行排**名和/**或 ❤️ 后，您才可以使用。如果您--p在数据不足的情况下尝试使用，您将看到一条错误消息，指示您进行更多排名。

## 个性化代码

随着您继续喜欢和对网站上的图片进行排名，您的个性化设置会随着时间的推移而不断发展。您可以通**过将该**样式的唯一个**性化代码添加到参**数来切换回旧版本（或使用其他用户的个性化样式）--p，如下所示：--p code。

+   当您使用 时**--p****，您当**前的**个性化代码将自动**添加到提示中：--p->--p code

+   要查找旧个性化代码，请使用/list_personalize_codesDiscord 中的命令。您最近的个性化代码将列在顶部，最旧的代码列在底部。

+   您可以通过浏览 Midjourney 提要中的图像或要求他们分享来找到其他用户的个性化代码。

+   **您可以通过组合代码在同一个提示**中混合多种个性化设置：--p code1 code2

## 设置中的个性化

**在 Discord**** 上，**您可以使用🙋 PersonalizationMidjourney 设置中的按钮（/settings在您使用机器人的任何地方运行该命令）将--p参数自动添加到您的所有提示中。

**在网站**上，您可以在设置窗口中打开个性化，以自动添加--p到所有提示中。单击想象栏中的图标以访问网络上的设置窗口。

## 个性化风格

使用时**--p**，[**--stylize**](https://docs.midjourney.com/v1/docs/stylize)( **--s****) 参**数控制对图像应用的个性化**程度。**较低的--s值将限制个性化，而较高的--s值将增加个性化。stylize 参数接受从 0 到 1000 的值。默认值为 100。

提示示例：**/imagine prompt** a cat in a field of poppies
