
# `--stop`（停止）

> 来源：[https://my.feishu.cn/docx/KCvndzFW0ox5gxxWHrvcOvOmnDb](https://my.feishu.cn/docx/KCvndzFW0ox5gxxWHrvcOvOmnDb)

使用 `--stop` 参数在流程中途完成作业。以较早的百分比停止作业可能会导致结果更模糊、更不详细。

`--stop` 接受值：`10–100`。

默认 `--stop` 值为 `100`。在升级 `--stop` 时不起作用。
