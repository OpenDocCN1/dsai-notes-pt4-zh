# --tile（重复拼接）

> 来源：[https://my.feishu.cn/docx/FG2tdL1fsoodpbxhHjwcrMF4nKf](https://my.feishu.cn/docx/FG2tdL1fsoodpbxhHjwcrMF4nKf)

#### 该--tile参数生成的图像可用作重复图块，为织物、壁纸和纹理创建无缝图案。

**--tile**适用于[模型版本](https://docs.midjourney.com/models) ，**1** **2** **3** **test** **testp** **5** **5.1** **5.2**并且仅生成单个图块。使用类似[无缝图块检查器](https://www.pycheung.com/checker/)的图样制作工具来查看图块重复。**6****

--til**e
