# 常用插件

> 来源：[https://my.feishu.cn/docx/BPdKd6RgmoyJ5qxe2l4crENanke](https://my.feishu.cn/docx/BPdKd6RgmoyJ5qxe2l4crENanke)

### 推荐插件

AIGODLIKE-ComfyUI-Translation，多语言翻译

[ComfyUI-Manager](https://link.zhihu.com/?target=https%3A//github.com/ltdrdata/ComfyUI-Manager)，节点管理器

ComfyUI-Custom-Scripts，增强UI功能

ComfyUI Impact pack，丰富的自定义节点包

ComfyUI_UltimateSDUpscale，分块放大图片

comfyui_controlnet_aux，ControlNet辅助预处理器

### 可选插件

efficiency-nodes，简化工作流程并减少总节点数

ComfyUI-WD14-Tagger，查询图像标签

segment_anything，分割图像中的元素

rembg-comfyui-node-better，去除背景

### 推荐设置

中文界面：安装了翻译插件后，点击设置>AGL>Locale>中文

提示词文本补全：安装了Custom-Scripts节点后，点击设置>pysssss>Auto Completer>自定义语句>加载>保存

在自定义节点上显示节点名称：安装了节点管理器后，点击管理器>表情>名称(隐藏内置)
