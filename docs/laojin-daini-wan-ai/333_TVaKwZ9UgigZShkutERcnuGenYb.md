## **工作流说明：**

### Redux：图像风格的魔术棒

+   **应用场景**：你可以根据需要调整图像的颜色、光线、纹理，甚至转换成油画、卡通画等不同风格，或者简单地提升照片的亮度、对比度等。

+   **优势**：创造无限，操作简单。只需文字描述，就能实现各种效果。

### Depth/Canny：精准编辑的利器

+   **应用场景**：精准编辑图像中的结构，不仅可以局部风格迁移，还能保持原有结构完整性，避免图像变形。

+   **优势**：灵活的控制，让你可以像指挥家一样，调整每个细节。

### Fill：图像修复与扩展

+   **应用场景**：去除照片中的干扰物、修复老照片，甚至扩展风景照的边界，给你一个更宽广的视野。

+   **优势**：无缝融合，精确控制，让你轻松创造出完美的图像。
