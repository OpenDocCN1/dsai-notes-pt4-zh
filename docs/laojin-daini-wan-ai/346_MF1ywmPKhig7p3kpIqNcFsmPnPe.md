# Git 安装 - 拉取GIT项目必备

> 来源：[https://my.feishu.cn/docx/WdvFdtomkoIsOHxZBCgc0xgPnJg](https://my.feishu.cn/docx/WdvFdtomkoIsOHxZBCgc0xgPnJg)

一个开源的分布式版本控制系统，可以有效、高速地处理从很小到非常大的项目版本管理，简单理解就是拉取开源项目用的。

打开地址：https://git-scm.com/download/win

选择自己电脑对应的版本，现在一般都是64位的。

![](img/33c27b50714075893a45acf15c2b61b2.png)

选择路径，一直下一步。

![](img/6a5162f3d71d95355dff4122782a2ec2.png)

直到安装完成，就可以在本地使用Git指令安装项目了。

![](img/5a0db77ed857877f0fafe11c4eeaaa7c.png)

如果不确认是否安装，可以使用win+R输入cmd

![](img/eb1d62a803f2ef3caa6072e6212ee90c.png)

再粘贴以下代码查看，如果有版本，则代表已安装。

```
git --version
```
