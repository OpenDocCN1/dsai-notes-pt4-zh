# Docker Desktop安装

> 来源：[https://my.feishu.cn/docx/UE9KdRPdTonvttxEriicFSSPnGg](https://my.feishu.cn/docx/UE9KdRPdTonvttxEriicFSSPnGg)

Docker 的桌面版本，它是一个易于安装和配置的桌面应用程序，允许用户在个人计算机上直接运行 Docker。

打开网址，根据系统进行选择，如图中标注的是Windows系统-64位。

https://docs.docker.com/desktop/install/windows-install/

![](img/1d8d8c0a3a61a1f840a2c6793b150b8d.png)

下载后，双击下载项目，出现下图，点击ok，开始加载文件。

![](img/3de3195064deafcaad1721a62a524a33.png)

点击“close and restart”重启电脑

![](img/821ba76c94e26cdc16c96bc9880bb9c0.png)

重启后，点击：“Accept”

![](img/5db5cc24e5be09c3a65a60569225ca17.png)

选择第二个即可，点击"Finish"

![](img/727b91c69765bf409f76ff68803dca08.png)

选择不需要登录。

![](img/9b4d85636e6f2661809762fa5cb2f0da.png)

直接跳过。

![](img/2317dbf86d778367e8e77e1b446ad289.png)

然后会进入Docker Desktop。此处完成。

![](img/17dcc0afb49c016ead836cd11d6b59fa.png)
