下载地址：https://www.python.org/downloads/

按需下载自己需要的版本。

![](img/be39b34a32d6f07f8ffbdc00d38481b8.png)

安装时勾选“Add Python to PATH”选项，这会自动将 Python 添加到系统路径。

安装后，win+R输入CMD，打开命令提示符。

![](img/fc41f5b0210dd2a8d6b55033bde1624d.png)

输入python --version，如果有对应版本信息，则安装成功。
