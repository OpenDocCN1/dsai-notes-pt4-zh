## 两家公司基本面

先看硬数据。

**智谱AI**

+ 上市日期：2026年1月8日  
+ 股票代码：2513（AI我一生，这谐音绝了）  
+ 募资规模：约43亿港元  
+ 估值：超511亿港元  
+ 定价：每股116.2港元  

**MiniMax**

+ 上市日期：2026年1月9日  
+ 股票代码：00100  
+ 募资规模：约46亿港元  
+ 估值：461-504亿港元  
+ 定价区间：151-165港元  

老金我算了一下，两家估值都在500亿港元上下，MiniMax定价更高一些。

但这个数字意义不大，关键要看商业模式和盈利能力。

## 商业模式对比

这是老金我觉得最有趣的地方：两家公司走的完全是两条路。

**智谱：To B路线，大客户为王**

智谱是2019年从清华计算机系技术转化出来的，基因就是学术派。

商业模式以私有化部署为主，占收入的85%左右。

客户主要是大型政企，走的是"技术深度"路线。

老金我之前测试`GLM-4.7`的时候就发现，这个模型在编程方面确实很强。

在`LiveCodeBench V6`评测中拿到84.9%的开源SOTA分数，超过了`Claude Sonnet 4.5`。

在全球百万用户盲测的`Code Arena`中，`GLM-4.7`位列开源第一、国产第一。

**MiniMax：To C路线，海外突围**

MiniMax是2022年闫俊杰创立的，员工平均年龄29岁，年轻得很。

商业模式以C端产品订阅为主，70%以上收入来自海外。

他们的产品矩阵挺丰富的：

+ 海螺AI（视频生成、智能助理）  
+ 星野（AI情感陪伴，月活千万级）  
+ MiniMax Audio（语音生成）  

老金我用过海螺AI的视频功能，画质确实逼真，电影级运镜算是一个亮点。

从2024年10月到2025年3月，海螺视频月访问量全球第一，超过Sora和Runway。

## 财务数据对比

这块老金我必须说实话：两家都在亏钱。

**智谱**

+ 2022-2024年收入：5740万→1.245亿→3.124亿元  
+ 年复合增长率：130%  
+ 2025上半年：1.91亿元（同比+325%）  
+ 毛利率：50-56%  
+ 累计亏损：超62亿元（3年半）  

**MiniMax**

+ 2023-2025年9月收入：346万→3052万→5343万美元  
+ 海外收入占比：73.1%  
+ 毛利率：63-69%（API业务）  
+ 累计亏损：约93亿元（2年多）  

老金我观察到一个有趣的点：MiniMax的API业务毛利率居然高于智谱的私有化部署毛利率。

这说明什么？

MiniMax在成本控制上可能做得更好，或者定价策略更聪明。

## 基石投资者阵容

这块很能说明资本市场的态度。

**智谱**

IPO之前已经完成8轮融资，累计超83亿元。

投资方包括阿里、腾讯、红杉资本、高瓴资本。

**MiniMax**

基石投资者认购超27亿港元（约3.5亿美元）。

阵容豪华得很：阿布扎比投资局（ADIA）、阿里巴巴、博裕资本、IDG、易方达基金、泰康人寿等14家。

老金我看到一个数据：MiniMax目前券商认购已超额97倍。

这说明市场对MiniMax的热情确实很高。

## 老金的分析

说了这么多数据，老金我总结一下两家的核心差异：

**智谱像勤恳做国内项目的技术大佬**

+ 国内收入占90%  
+ 深耕B端，大客户稳定  
+ 技术底蕴深厚，学术背景强  
+ 风险：依赖少数大客户，收入集中  

**MiniMax像冲全球市场的产品创业者**

+ 海外收入占70%以上  
+ C端产品矩阵丰富  
+ 用户增长快，付费转化好  
+ 风险：C端竞争激烈，用户留存是挑战  

老金我个人觉得，从投资角度看：

+ 如果你看重稳定和技术深度，智谱可能更适合  
+ 如果你喜欢高增长和全球化故事，MiniMax可能更有想象空间  

不过老金我必须强调：这不是投资建议！

股市有风险，入市需谨慎。

老金我就是帮你整理信息，最终决策要你自己做。
