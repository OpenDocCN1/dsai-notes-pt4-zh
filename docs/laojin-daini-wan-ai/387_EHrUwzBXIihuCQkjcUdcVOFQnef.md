# **安装方法：**

## 方法1：**私聊机器人**

#auth 密码   ----  管理员认证

#installp 地址.git   ----   安装（国内连接经常不好使，发生冲突安装失败的话，在文件里直接删除对应文件夹，然后重新安装）

#scanp    ----  安装成功后，激活插件

配置：大部分插件均需要进行配置，在对应的插件目录下，配置Config文件。

配置完成后，继续私聊机器人，#reloadp 插件名   ----  重载插件配置

![](img/8e59bc3047991c5ce889327d940c10b7.png)

## **方法2：直接安装**

在Github等网站上直接下载源码文件。

![](img/3d5cb9d7231960d49aa65388679c335f.png)

上传至云服务器

![](img/c414ccf36278aca2aaa5731d00253986.png)

#scanp    ----  安装成功后，激活插件

配置：大部分插件均需要进行配置，在对应的插件目录下，配置Config文件。

配置完成后，继续私聊机器人，#reloadp 插件名   ----  重载插件配置

# **安装失败解决办法：**

插件目录下，右键删除后，重新安装即可。
