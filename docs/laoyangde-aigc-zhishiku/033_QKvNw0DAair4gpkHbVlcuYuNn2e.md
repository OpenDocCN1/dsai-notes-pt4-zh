# 二、核心梗思路**（来自大神@犄角啊犄角）**

## **1.   替身文的概念及特点**

**替身文，即主角为了某种目的，扮演或**替代他人，成为某人的“代餐恋人”的故事。

> 这种替代可能是自愿的，也可能是被迫的，可能是真实的，也可能是虚假的。

> **替身角色会经历**从替身身份到她本身真实身份的转变。

> 替身文可以融合多种元素，如马甲、双替身(互为替身)、契约婚姻、恋爱合约、错认白月光(错把真爱当替身，就 小美人鱼那种)、伪替身(误会)、失忆、真假干金、穿书、豪门总裁、替嫁、系统、脸盲 …..

> 感情线构思集中在四个框架上：追妻火葬场(男二上位)、先婚后爱、破镜重圆、强取豪夺。

**创作情节时的底层逻辑****以信息差为主****：**

+   ① 被迫替身：我以为自己是正派女友，结果你把我当替身。

+   女主是替身(信息差):读者知，男主知，其他人物知，反派知，女主不知。

+   ②被迫替身：我自知是替身，不敢有非分之想。你爱我不自知，追妻火葬场。

+   男主爱女主(信息差):读者知，反派知，其他人物知，女主不知，男主不知。

+   ②双替身：你以为我是替身，其实你才是替身

+   女主把男主当替身(信息差):读者知，女主知，其他人物有知有不知，反派不知，男主不知。

+   ③伪替身：我以为你把我当替身，结果压根没有替身。

+   没有替身(信息差):读者知，男主知，女主不知，其他人物有知有不知，反派不知。

+   女主爱男主(信息差):读者知，女主知，反派知，其他人物有知有不知，男主不知。

+   男主爱女主(信息差):读者知，男主知，反派知，其他人物有知有不知，女主不知。

+   ④主动替身：职业替身的我一心搞钱，结果你却跟我谈感情。

+   女主是替身(信息差):读者知，女主知，男主知，反派不知，其他人物有知有不知。

+   男主爱女主(信息差):读者知，男主知，反派知，其他人物有知有不知，女主不知。

## **2.** **替身文中的角色设定**

> 主角作为“替身”,在外貌、性格或其他特征上与“被替代者”有较为明显的相似，

> 这些相似点也会成为**(男女主冲突)** (女主和反派冲突)的引爆点。

> 在人物关系上，替身与被替代者可以是亲缘关系，也可以是陌生人。亲缘关系更容易产生冲突。

**Step1.** **构** **思** **女** **主** **人** **设**

> 女主设定分为两**种** **，**第一种主动成为某人的替身，第二种为被迫成为某人替身。

>

> **一** **、主动替身(包含：双替身)**

> 主动替身：主角会把替身当成职业，把男主当成老板，把与男主恋爱或亲热当成工作。

> 双替身(互为替身)：你以为我是替身，其实你才是替身。

> 主角身为替身的同时，也将男主视为某人的替身，一边赚钱一边白嫖男主。

> 主动替身要注意人物行为与内心的反差感，即表面笑嘻嘻，内心MMP。

>

> 女主性格：以人间清醒、演技派、事业脑、扮猪吃虎、伪装小白花、钓系美人为主。

> 女主身份：

+   ①受剧情之力或系统任务限制：马甲大佬、豪门舔狗干金…..

+   ②事业危机：黑红明星、抢夺继承权的大小姐、谋夺皇位的长公主….

+   ③身份所迫：联姻豪门假千金、不受宠的替嫁庶女、求生的奴隶、被主母虐待的侍女....

+   ④家庭变故：母亲病危的大学生、破产欠债的大小姐、哥哥得罪大人物的小家碧玉….

>

> **二** **、被迫替身(包含：伪替身)**

> 人物性格标签以单纯倔强、外柔内刚为主

> 被迫替身：由于某个原因，女主不得不成为某人的替身。关于替身身份，女主可以知情(自我安慰),也可以不知情(虐女主)。

> 伪替身：女主以为自己是某人的替身，其实是误会。女主以为男主想当金主，其实男主想当男友。

> 双方都误以为对方 不爱自己，患得患失。(信息差引起认知错误，从而导致彼此更深的误会)

> 女主身份：

+   ①主仆关系：佣人、侍女…...

+   ②上下级关系：总裁秘书、实习生、长官下属、徒弟...

+   ③契约关系：替嫁的庶女、孤儿、穷学生、豪门真干金….

+   ④报恩关系：寒门之女、罪臣之女、副将遗孤、世交遗孤….

**Step2.** **构思男主人设**

> 男主身份一般为霸总或类霸总的上位者身份，如摄政王、太子、丞相、联盟首领….. 由于替身文的本质是追妻火葬场，所以男主前期与后期存在较大的反差。

> 前期：狂妄霸道、冷酷无情、傲娇(口嫌体正直)、淡漠疏离、自以为是、偏执、放荡不羁、纨绔...

> 后期：腹黑恋爱脑、温柔有服务意识、宠妻狂魔…...

## **3.** **替身文中的情节构建**

> 替身文的情节需要围绕替身和主角之间的关系展开，主要从三方面入手：

+   ①替身女主给男主生活带来的影响(替身存在的必要性)

+   ②身为替身的女主在男主心中地位的变

+   ③身为替身的女主与男主之间的心理博弈

下面给大家列举几个情节构建的思路：

设定元素一：传统替身+错认白月光+追妻火葬场+破镜重圆

> 看点：女主前期不知道自己是替身，后期爱上男主后发现，先宠后虐，宛宛类卿

> (前期我以为你爱我，但你却不爱我。后期你爱上我了，但我怀疑你真的爱我吗?)

> 故事框架：

> 起：女主在不知情的前提下，被迫作为某人替身，成为男主的未婚妻/情人/夫人

+   交代信息：

+   ①女主为什么成为替身：报恩、报仇、筹钱救人....

+   ②男主为什么包养女主：对于白月光求不得、反抗家族安排…..

+   **情绪点：**

+   ① 读者知道女主是替身，为女主的付出感到不平。

+   ②男主爱不自知，将女主当替身，冷淡女主。

> 承：白月光回国，男主在白月光与女主之间摇摆(委屈女主，捧白月光)→女主被羞辱，被抛弃，(男配或贵人帮 助)女主离开(带球跑、死遁)

+   **交代信息**：

+   ①女主因替身受了什么委屈与羞辱?(二选一永远被放弃，明确女主的替身身份) “你要像她，这样我才会疼你。你不能太像她，你不配。”

+   “不许笑，笑了就不像她了。”

+   ②女主如何离开?(是否有男配?男配存在能刺激男主追妻，引发后续的修罗场情节) 情绪点：

+   ①白月光出现，反复对女主先虐后宠，逐渐认知自己真实心意。

+   ②女主感情耗尽选择离开，彻底与男主决裂。

> 转：女主归来， 一心搞事业(养崽),男主后悔追妻，女主成为感情中的主导者，男主疯狂补偿，卑微求爱过程中， 发现自己错认白月光

+   **交代信息：**

+   ①女主为什么归来?归来时她的转变是什么?

+   ②男主为什么后悔，后悔后做了哪些行为?(纠缠&补偿)

+   ③女主以什么态度对待男主?(逃避、惧怕、冷漠)

+   ④男主什么时候发现女主才是自己真正的白月光?(加深男女主之间的羁绊)

+   **情绪点**：

+   ①男主意识到自己爱上了女主，开始追妻

+   ②女主拒绝男主，男配上场，反复虐男主，男主各种求怜爱，女主冷漠以待

> 合：女主和男主破镜重圆，女主事业走向巅峰，男主化身宠妻狂魔

+   **交代信息：**

+   ①女主的事业线成就有哪些?

+   ② 男主如何获得原谅?(契机事件) 情绪点：

+   ①一同经历重大危机，女主对待男主的态度逐渐软化

+   ②男主实际行动上宠妻

设定元素二：替身+追妻火葬场+男二上位+马甲+系统

+   ①女主因系统任务，不得不扮演霸总的替身情人，每天兢兢业业与女配周旋，扮演情根深种的苦情替身

+   ②任务结束，女主拿着奖励和巨额分手费飞速抽身，头也不回

+   ③女主离开后，白月光本性暴露，霸总发现自己爱上了替身女主

+   ④女主再度出现，女配挑事被打脸，霸总追妻火葬场，众人这才发现女主竟是马甲大佬

+   ⑤女主拒绝霸总，男二上位，两人撒糖

>

> 这里扩展一个关于“追妻火葬场”的底层逻辑：

> 前期男主因为某个误会或者立场原因，对女主态度恶劣，甚至做出一些伤害女主的行为

> 这阶段，作者要重点展现男主对女主的与众不同的细节表现，让读者都知道男主未来必将爱上女主或者其实男主深 爱女主而不自知。

> 从这一刻开始，读者就会自发脑补和搜寻男主爱着女主的证据，并且期待着男主意识到自己的感情 那一刻，以及之后男主如何挽回女主。

> 以上情节套路的设定其实就包含三个部分：

+   ①给读者细节和线索，设置悬念，建立期待目标；

+   ②铺垫情节，延迟满足，不断提高读者的期待值；

+   ③满足读者的预期，并建立新的期待目标。

设定元素三：双替身+翻车掉马+破镜重圆+系统/穿书

+   ①女主因剧情或系统限制，扮演替身，配合男主演出。男主把女主当成替身的同时，女主把男主当成白月光的替身。

+   ②女主白月光归来，男主发现女主居然把自己当替身，女主翻车掉马。男主勃然大怒，两人一拍两散。

+   ③女主离开后，男主发现自己爱上女主，开始追妻，女主前期拒绝，后期逐渐接受。

+   ④女主和男主共同经历危机后，破镜重圆，开始撒糖甜蜜蜜。

## **4.** **替身文的创作注意事项**

替身文是典型的强情绪类型文，这类文要注意主角的心理描写。

**其中包括女主(男主)对自己替身身份的认知**、接受程度，对待男主的情感变化以及内心冲突。

> 一 **、细** **节** **铺** **垫** **：**

+   ①男主能为替身女主做连为了白月光都没做过的事情

+   ②男主以为某件事只有白月光能做到，结果发现替身女主也能做到，而且做得更好。

+   ③男主以为自己心情糟糕是因为白月光，实际则是因为替身女主(认识内心的契机)

>

> **二** **、态** **度** **对** **比** **：**

+   ①白月光与替身对待男主的态度

+   白月光真面目：无事不登三宝殿，对主角时好时坏，将主角当备胎，多次利用主角；

+   替身女主：日久生情，对主角掏心掏肝，真心对待主角，反被主角利用。

+   ②男主对待白月光与替身的态度

+   结束替身关系之前：追捧白月光，对替身只有利用；冷淡替身，回忆白月光的各种美好。

+   结束替身关系之后：拥有白月光后，无法接受替身离开；冷淡白月光(在白月光和替身之间摇摆不定),回忆替身的 各种美好。

+   结束替身关系之前：谁当替身都一样，又不是非女主不可 结束替身关系之后：所有替身都不如女主

+   ③白月光对待男主的态度 发现替身前：冷淡

+   发现替身后：距离拉近(危机感)

>

> **三** **、虐** **点** **加** **码**：

+   ①主角不知道自己其实是某人的替身

+   ②主角和白月光恰巧有同样的小名(宛宛类卿)

+   ③当主角和白月光同时出意外，男主选择救白月光，哪怕主角这边更加危急
