## 四、仿写案例~

### 仿写三个层次：《具体见[《仿写》的三个层次直播详解](https://rq547mr4oez.feishu.cn/wiki/F9gHwbDbni1386kI3ivcC0PSnRb?from=from_copylink)》

+ 初级仿写：即“翻译”：中译中不可取、英译中、中译英
+ 中级仿写：即“改写”：换元法（背景/人物/等），变成情节卡
+ 高级仿写：即“取经”：是仿情绪，节奏，通用"情节卡模板”。

====
##  一、基本信息
1. 选题: 一位少女在复杂的家庭关系与情感纠葛中寻找自我与归属。
2. 题材: 现代言情
3. 类型: 都市情感小说
4. 字数: 100万
5. 期待感: 主人公在面对家庭压力、情感困扰和个人成长的过程中，如何找到自己的位置和幸福.
##  二、故事设定
1. 背景设定: 故事发生在现代都市燕城，围绕着豪门家族的生活与情感纠葛。
2. 主角: 
    - 宋霜序：年龄18岁，性格坚韧而敏感，背负着被家族抛弃的阴影。 
    - 人设七步法：
        - 目标：寻找自我价值与归属。
        - 阻碍：家庭关系复杂，外界压力大。
        - 行动：努力工作，与朋友合作创业。
        - 结果：逐渐理解自己内心的真实想法。
        - 意外：与贺庭洲的相遇与互动让她重新审视自己的情感。
        - 转折：意识到对沈聿的依赖与喜欢。
        - 结局：接受自己的身份与过去，努力向前。
3. 配角: 
    - 沈聿：霜序的哥哥，对她关爱有加，是她心灵的支柱。
    - 贺庭洲：复杂而神秘的人物，与霜序产生微妙关系。
    - 舒扬：霜序的学姐，身患重病但乐观开朗，是她的重要支持者。
4. 核心梗: 家族关系、暗恋、成长与自我发现。
5. 核心内容: 
    - 危机: 家庭矛盾、病痛与事业困境交织。
    - 伏笔: 对沈聿的感情暗涌，对贺庭洲的不解与吸引。
    - 悬念: 霜序能否克服内心障碍，与沈聿之间的关系如何发展？
    - 爽点: 与贺庭洲互动中的幽默与火花。
##  三、故事脉络
1. 核心冲突: 主人公在家庭期望和个人追求之间挣扎，尤其是对沈聿和贺庭洲之间微妙的情感纠葛。
2. 情感纽带: 对家人的依赖，对朋友的信任，以及对爱情的渴望与迷茫交织在一起。
3. 故事反转: 从被动接受家庭安排，到主动选择自己的生活道路，逐渐成长为独立个体。
4. 二次反转: 与贺庭洲之间不断升温的关系，让她重新审视自己的内心世界及对沈聿的依赖。
5. 整体节奏:
    - [引入宋霜序回国] [引发关注（家族背景和心理状态）] [紧张]
    - [舒扬生病] [推动剧情（友情支撑）] [焦虑]
    - [遇见贺庭洲] [新关系建立（微妙吸引）] [期待]
6. 写作风格: 情感细腻，语言清新流畅，兼具幽默与深度。
====

# 第1章 风云人物

宋霜序坐在飞机的经济舱里，望着窗外渐渐接近的城市轮廓。
燕城，五年了，这座城市在她记忆中，早已褪去了年少时的青涩滤镜，如今，只剩下略显模糊的轮廓，像一幅年代久远的油画，蒙上了一层薄薄的尘埃。
可即便如此，当它再次真实地出现在眼前时，她心中还是涌起一种说不清道不明的情绪，像是久别重逢的亲切，又像是即将揭开伤疤的不安，两种感觉交织在一起，让她心头微微一颤。
舱内的广播响起，甜美的女声提醒乘客系好安全带，飞机即将降落。
安全带的卡扣声“咔哒”一声，仿佛是命运的齿轮开始转动，将她拉回现实。
她轻轻叹了口气，合上手中的书本——那本被翻得有些卷边的《百年孤独》。
