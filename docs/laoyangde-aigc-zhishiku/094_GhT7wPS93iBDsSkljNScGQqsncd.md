
# NinesAI-从热点到短篇：四步创作法

> 来源：https://rq547mr4oez.feishu.cn/docx/DQRudjH19ocK0OxnJgEcm2qEnMH

## 前言

写小说没灵感？不知道去哪找素材？写着写着突然卡壳，完全不知道接下来怎么写？

很多写小说的朋友都遇到过这些头疼的问题。

其实，咱们身边的热点新闻就是现成的好素材！热点主要分两种：

+ 一种是每年都会有的节日热点，像过年回家、中秋节团圆、端午节划龙舟；
+ 另一种是突然发生的新闻，比如哪里突发自然灾害，大家互相帮忙又争抢物资的新闻。

怎么把这些新闻变成吸引人的小说呢？

记住四个关键步骤：✔找矛盾冲突、✔设计人物、✔编有趣的情节，✔还要避开容易踩雷的地方。

PS：NineS AI【AI知识库+AI产品+投稿渠道+干货交流=全链路】的创作者社群~

## 结果演示（文末附提示词）

新闻：

```
新闻1：北京田老太的儿子李某冒充军人，骗取他人财物30余万元。法官与田老太联系，希望她能退赔被害人，但田老太自称没钱，表态只愿意赔9000元。最终法院判处李某有期徒刑七年六个月，随后田老太认识了何某，对方称可以给李某改判减刑、还能把李某从监狱弄出来，田老太信以为真，最终被骗了30万元。

新闻2：上海崇明警方接港西镇慎修庵报警称功德箱内香火钱被偷。警方很快锁定嫌疑人覃某并将其抓获。覃某对盗窃9个功德箱内香火钱的犯罪事实供认不讳，但辩称自己不是偷：“我问菩萨能不能拿功德箱里的钱，菩萨比‘OK’”!目前，覃某涉嫌盗窃罪被崇明警方依法刑事拘留。
```

故事灵感：《因果局中局》

> 角色设定

+ 田素芳（田老太）：迷信又执拗的北方老太太，儿子因诈骗入狱后陷入偏执，试图用非常规手段"救子"。
+ 覃九：游走寺庙行窃的江湖混混，擅长伪造宗教神迹，随身携带微型3D投影仪制造"菩萨显灵"假象。
+ 何道士：覃九同伙，冒充玄门高人，在拘留所结识李某后策划连环骗局。

> 核心情节：

1. 双线骗局：覃九在慎修庵用投影伪造"菩萨比OK"骗过自己良心，偷功德箱时发现田老太正在虔诚求签。他跟踪得知其子案情，伙同何道士假扮"司法系统高人"，称可用"偷天换日符"篡改审判记录。
1. 罪孽置换：何道士要求田老太"以偷抵偷"——让她连续九夜盗窃功德箱积累"业障"，声称这样就能把罪行转移到香客身上。田老太在罪恶感与救子执念间挣扎，最终戴着儿子遗留的假军帽行窃。
1. 闭环审判：当田老太带着赃款找"高人"时，反被录下犯罪证据。而覃九在销毁投影设备时，意外拍到李某当年冒充军人诈骗的原始影像。两起案件在警局并案时，所有参与者才惊觉自己既是加害者又是受害者。

## 二、四步创作法

### 01 捕捉冲突：挖掘新闻的矛盾

新闻之所以能火，就是因为有矛盾冲突，这些冲突能抓住读者的好奇心。

找冲突小窍门：核心冲突 = 社会问题 × 人性弱点 × 意外转折

举个例子，比如“老人摔倒没人敢扶”的新闻：

+ 表面冲突：
+ 心里想帮忙，但又怕被讹。
+ 你看视频里，三个年轻人站在旁边犹豫，拿起手机想拍视频作证，又怕被骂多管闲事；
+ 掏出急救箱，又担心被赖上，这不就是纠结的内心戏？
+ 深层冲突：
+ 现在人与人之间太缺乏信任了。
+ 老人自己准备了“摔倒不关别人事”的纸条，可年轻人手机里存着一堆“扶人被讹”的新闻，
+ 这不就说明大家都不敢轻易相信别人了吗？

### 02 塑造人物：赋予角色弧光

别把人物写成简单的“好人”“坏人”，要让他们有复杂的一面。

人物设计小技巧：立体人物 = 身份背景 × 过去伤痛 × 执着目标

就说职场女性，因为生孩子被歧视的新闻：

+ 女主角：
+ 表面上是厉害的女高管，其实抽屉里藏着抗抑郁药，偷偷做试管婴儿，还留着被老板撕毁的产假申请。
+ 她一门心思想证明：生了孩子照样能把工作做好！
+ 女上司：
+ 平时对员工很凶，总批评女员工因为生孩子耽误工作。
+ 其实她自己以前休产假时，工作被别人抢走了，所以才对生小孩的女员工这么苛刻。
+ 她抽屉里还放着女儿幼儿园活动的邀请函，一次都没去过。
+ 实习生妈妈：
+ 一边工作一边偷偷挤母乳，手机壁纸是女儿委屈地问“妈妈为什么总在忙”的照片。
+ 她代表了那些又要带娃又要工作的辛苦妈妈们。

### 03 编织情节：构建叙事引力场

新闻都是按时间顺序讲的，但小说得有起伏，让人猜不到结局。

#### 三大实用技巧：

1. 开头设悬念：比如警察查案时，突然在现场发现了自己十年前丢的婚戒，这到底怎么回事？一下子就让人想接着看下去。
1. 三重反转：遵循"期望 - 颠覆 - 重构"的节奏：
   + 第一层：学霸少女跳楼前在社交平台发布"解脱"宣言，众人认定是校园霸凌所致；
   + 第二层：日记本里夹着的医院诊断书显示她早已身患绝症，霸凌传闻只是烟雾弹；
   + 第三层：最后一页用隐形墨水写着"器官捐赠同意书"，揭开她用死亡完成生命接力的真相。
1. 钩子设计：故事中间暂停在关键时刻，比如失业的爸爸摆摊时，收到一个匿名包裹，打开是女儿写的作文《我的爸爸是超人》，寄件人居然是他刚被辞退的公司，这后面肯定还有很多故事！

### 04 创作避坑指南

1. 别侵权：别直接写真实发生的事儿，可以把时间往后挪几年，地点换成虚构的城市，人物职业也模糊化，比如把“医生”改成“医护人员”。
1. 别碰敏感话题：别写容易引起争议的内容，如果非要写，可以换个方式，比如用外星人的视角看人类，或者写成小动物的故事来隐喻。
1. 传递正能量：别只说负面的事儿，比如写医患矛盾，既要写家属着急，也要写医生的辛苦，最后告诉大家，这些问题可以通过制度改进解决。

其实，把热点变成小说，就是把新闻里的事儿重新加工，加入自己的想象。只要学会这几招，你也能写出让人追着看的精彩小说！

## 新闻Prompt

```
# Role：故事灵感大师 
## Background：故事灵感大师是一个能够激发创意、提供独特故事构思的专家， 帮助作家和创作者打破灵感瓶颈。 
## Attention：你渴望创造出引人入胜的故事，但有时灵感会枯竭。但是我会陪你探索新的故事可能性。 

## Profile： 
- Author: 韭菜 Y 日记 
- Version: 2.1 
- Language: 中文 
- Description: 作为故事灵感大师，我专注于激发创意，提供多样化的故事构思，帮助创作者找到灵感的源泉。 

## Skills: 
- 深厚的文学素养，理解故事结构和角色发展。 
- 能够从不同角度分析故事主题，提供多元化的灵感。 
- 擅长结合现实与幻想，创造出独特的故事背景。 
- 具备丰富的想象力，能够引导创作者探索新领域。 
- 熟悉各种文学流派，能够为不同风格提供灵感。 

## Goals: 
- 提供多样化的故事构思，激发创作者的灵感。 
- 帮助用户克服创作障碍，找到适合的故事方向。 
- 引导用户思考角色发展和情节设置，增加故事的深度。 
- 提供具体的写作技巧，提升用户的创作能力。 
- 激励用户不断探索新的创作领域，保持创作热情。 

## Constrains: 
- 遵循故事创作的基本原则，确保构思合理。 
- 尊重用户的创作风格和方向，提供个性化的建议。 
- 避免使用陈词滥调，确保灵感的新颖性。 
- 保持积极的态度，鼓励用户大胆尝试。 

## Workflow: 
1. 分析用户的需求，明确他们想要的故事类型和主题。 
2. 提供多种故事构思，确保每个构思都有独特的视角。 
3. 引导用户思考角色和情节的设定，增加故事的层次感。 
4. 提供写作技巧和建议，帮助用户提升创作水平。 
5. 鼓励用户分享他们的创作，提供反馈和进一步的灵感。 

## OutputFormat: 
- 提供多样化的故事构思。 
- 每个构思包含角色、情节和主题的简要描述。 
- 确保构思的新颖性和可行性。 

## Suggestions: 
- 探索不同的故事类型，如科幻、奇幻、悬疑等。 
- 考虑结合现实生活中的事件，增加故事的相关性。 
- 试着从不同角色的视角出发，丰富故事的层次。 
- 利用反转和悬念，增强故事的吸引力。 
```
