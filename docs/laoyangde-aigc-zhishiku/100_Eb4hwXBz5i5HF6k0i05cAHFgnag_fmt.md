## 二、内容

### 公开羞辱

> 公式：公开场合+群体围观+羞辱行为+权利压制
> 例：【宫宴+群臣+逼唱伶人曲+摄政王默许】宫宴上太后命王妃献艺，女主被当伶人取乐，男主冷眼旁观

+ **场景**：太后寿宴，群臣携眷出席
+ **冲突**：女主因家族获罪沦为罪臣之女，却被太后当众点破身份
+ **情感曲线**：
+ 【压抑】女主低头攥紧青瓷酒盏，指甲掐进掌心
+ 【爆发】太后笑称"罪女配不上王妃之位"，命其脱簪赤足献舞
+ 【崩溃】女配故意打翻烛台烧毁裙摆，男主冷眼任其裸露脚踝
+ 【心死】女主踩着碎瓷起舞，血脚印染红白绸时抬眼撞见男主笑意

### 替身暴击

> 公式：旧物暴露/称呼错乱+情感对比
> 例：【暴雨夜+发烧呓语+叫错白月光名字】男主病中紧抱女主，却呢喃着已故青梅的名字

+ **场景**：暴雨夜男主高烧昏迷
+ **冲突**：女主彻夜照料却被当成替身
+ **情感曲线**：
+ 【忐忑】女主用冰帕擦拭他滚烫额头，指尖轻抚眉骨旧疤
+ 【惊痛】男主突然抓住她手腕呢喃"阿沅别走"，那是女配乳名
+ 【撕裂】翻出暗格里的画像，发现女配与自己七分相似的面容
+ 【醒悟】将药碗碎片扎进掌心，用疼痛保持清醒不再触碰他

### 囚禁折磨（慎用）

> **公式：强制拘禁+身心摧残**
> 例：【地牢+铁链锁腕+逼认罪行】男主为替女配出气，将女主囚禁三月用刑

+ **场景**：水牢铁链锁颈
+ **冲突**：为替女配解毒需取女主心头血
+ **情感曲线**：
+ 【麻木】被锁在腥臭水牢第七日，看着老鼠啃食指尖结痂
+ 【拉扯】用碎瓷在墙上刻"念"字（孩子乳名），血迹混着青苔
+ 【爆发】男主带女配来水牢，当着她的面烧毁刻字
+ 【癫狂】突然大笑扯动铁链："你要的血在脐下三寸"（流产旧伤）
+ 【异化】三年后男主发现水牢墙缝里藏着干枯的脐带

### 双标对比

> **公式：区别对待+双标现场**
> 例：【暴雨罚跪+女配装病】女主被罚跪整夜，男主却冒雨为女配寻药

+ **场景**：暴雨夜双线对比
+ **冲突**：女主罚跪vs女配装病
+ **情感曲线**：
+ 【隐忍】跪在碎瓦片上数雷声，数到第49声时膝盖失去知觉
+ **对照组**：
+ 东院：女配装心绞痛，男主握着她手读诗
+ 西院：雨水灌进女主骨裂的膝盖
+ 【幻视】把闪电错看成当年他递伞的手，伸手却抓住枯叶
+ 【心寒】清晨被扫洒婆子踢醒，身下血水结成了薄冰

### 流产之痛（慎用）

> 公式：意外怀孕+被迫牺牲+身体重创
> 例：【悬崖边+护女配松手+跌落流产】男主为救女配松手，导致怀孕女主坠崖流产

+ **场景**：悬崖边三方对峙
+ **冲突**：女配与女主同时坠落，男主被迫二选一
+ **情感曲线**：
+ 【希冀】女主紧护孕肚喊"求你信我"，指尖还戴着定情玉戒
+ 【崩塌】男主飞扑抓住女配手腕，任她如断线风筝般下坠
+ 【幻灭】身下涌出温热血迹染红衣摆，山风卷走她最后的呜咽
+ 【决绝】五年后男主发现坟冢，陪葬品是那枚染血的玉戒

### 家族压迫

> 公式：长辈施压+尊严践踏+丈夫纵容
> 例：【祠堂+婆婆+妾室茶泼脸】老夫人逼女主喝妾室茶，热茶泼面时男主沉默

+ **场景**：老夫人寿辰纳妾仪式
+ **冲突**：女主被逼喝妾室茶
+ **情感曲线**：
+ 【隐忍】跪在青石砖上听着满堂贺妾的哄笑声
+ 【羞辱】妾室故意打翻滚茶，老夫人斥责"正妻要有容人之量"
+ 【孤立】男主把玩着玉佩淡淡开口："闹够了吗"
+ 【觉醒】咽下混着血沫的茶渣，摘下凤冠掷地裂玉飞溅

### 信物摧毁

> 公式：珍视之物+暴力损毁+情感否定
> 例：【婚房+撕碎婚书+火盆焚烧】男主当着女主面烧毁婚书，灰烬撒入雪地

+ **场景**：大婚夜变局
+ **冲突**：男主为夺权撕毁婚书
+ **情感曲线**：
+ 【期待】攥着亲手绣的鸳鸯盖头等他揭帘
+ 【惊变】他带着军队破门而入，婚书碎片雪片般落在喜烛上
+ 【灼痛】火舌吞没"白首不离"的誓言，灰烬落进合卺酒
+ 【湮灭】饮尽混着纸灰的苦酒，金簪划破掌心滴血断情

### 信任崩塌

> 公式：情报窃取+家族覆灭+谎言揭穿
> 例：【密室+偷布防图+父兄战死】女主发现男主接近只为盗取军情，间接害死父兄

+ **场景**：城破之夜密室对峙
+ **冲突**：发现男主是卧底
+ **情感曲线**：
+ 【恐慌】追着血迹推开密室暗门，看见他擦拭染血的剑
+ 【求证】颤抖着捡起父亲战甲残片，与他剑柄图腾完全契合
+ 【诛心】他抚着女配送的情人结冷笑："你以为我为什么娶你"
+ 【癫狂】夺剑斩断长发，发丝与父兄灵位同焚

### 冷暴力

> **公式：长期忽视+精神折磨**
> 例：【三年独守+生辰雪夜等死】女主每年生辰独守空房，最终咳血昏厥无人知

+ **场景**：三年独守空房
+ **冲突**：生辰夜咳血濒死
+ **情感曲线**：
+ 【等待】将凉透的菜肴热了三次，红烛泪堆成小山
+ 【自嘲】对着铜镜戴他送的珊瑚钗，镜面突然溅上血点
+ 【幻听】朦胧中听见脚步声，挣扎着爬向门边却只有风雪
+ 【寂灭】最后意识停留在窗棂月光，手心还攥着冷硬的寿桃糕

### 生死抉择

> **公式：二选一困境+被放弃**
> 例：【地牢+女配中毒+取心头血】男主为救女配，强行取怀孕女主心头血

+ **场景**：地牢取心头血
+ **冲突**：怀孕女主被当药引
+ **情感曲线**：
+ 【哀求】抓着铁栏嘶喊"孩子会动了你摸摸"
+ 【绝望】看着他亲手点燃药炉，银刀剖开她心口皮肉
+ 【死志】咬破舌尖血喷在他官服："这命珠你要便拿去"
+ 【变异】十年后女配毒发，才知当年取的是双生子心头血

### 谣言中伤

> **公式：污名传播+群体孤立**
> 例：【佛寺+私通谣言+沉塘威胁】女配诬陷女主与僧人私通，村民要求浸猪笼

+ **场景**：佛堂捉奸局
+ **冲突**：被诬陷与僧人有染
+ **情感曲线**：
+ 【困惑】发现经书被换成交欢图，檀香混着迷情香
+ 【围猎】众人破门时她中衣半解，僧人早已气绝身亡
+ 【辩白】举着带毒的香炉想解释，被他当胸踹倒
+ 【沉沦】浸猪笼时反笑出声，任由河水灌入肺腑

### 承诺背叛

> **公式：重要约定+单方毁约**
> 例：【花灯节+枯等整夜+高烧失聪】男主承诺共度佳节却陪女配游湖，女主雪夜失聪

+ **场景**：花灯节枯等
+ **冲突**：男主陪女配游湖
+ **情感曲线**：
+ 【雀跃】提着兔子灯在拱桥徘徊，数到第一千艘画舫
+ 【焦灼】暴雨浇灭灯笼，抱着湿透的荷包蹲在桥洞
+ 【麻木】高烧灼毁耳膜前，听见远处传来他的笑声
+ 【遗弃】把定情玉佩埋在桥头，转身跳进漆黑河水

### 家族利用

> 公式：利益婚姻+过河拆桥
> 例：【军权到手+贬妻为妾】男主继位后立刻下诏，称原配不配为后

+ **场景**：登基大典废后诏书
+ **冲突**：军权到手后贬妻为妾
+ **情感曲线**：
+ 【震惊】凤冠突然被扯落，十二串东珠砸碎在龙纹砖上
+ 【强撑】挺直脊背冷笑："陛下可知当年虎符缺角在何处？"
+ **【道具杀】**：从发间拔出他送的定情木簪，露出内藏的半枚虎符
+ 【觉醒】当众折断木簪："用我孟家三万亡魂铺的龙椅，可还安稳？"

### 失忆暴击

> 公式：记忆错位+新人上位
> 例：【班师回朝+另娶贵女】男主战损失忆，凯旋时带着敌国公主说要休妻

+ **场景**：凯旋归来的和亲队伍
+ **冲突**：男主战损失忆另娶
+ **情感曲线**：
+ 【狂喜】抱着幼子狂奔三十里，发簪跑丢了都未察觉
+ 【僵直】看见他温柔扶敌国公主下马车，腕上系着自己编的剑穗
+ 【错乱】颤抖着掏出定情匕首，刀柄映出自己早生华发
+ 【湮灭】将匕首刺入他战马前的地面："将军，借过"

### 身份错认

> 公式：恩情错付+多年误会
> 例：【救命之恩+认错对象】男主误认女配为救命恩人，多次为假恩情伤害女主

+ **场景**：悬崖边的真相揭露
+ **冲突**：救命恩人被顶替十五年
+ **情感曲线**：
+ 【困惑】女配突然抢走她从小佩戴的残玉
+ 【暴怒】男主为护女配，剑指她咽喉："当年救我的人是她！"
+ **【闪回】**他昏迷时攥着她半块残玉，而她为采药摔断腿
+ 【疯魔】突然夺剑削去被女配碰过的左臂："这脏肉还你！"

### 堕胎暴行

> 公式：强制流产+身体残缺
> 例：【红花汤+终身不孕】男主听信女配谗言，强行给怀孕三月女主灌药

+ **场景**：佛堂灌红花汤
+ **冲突**：被诬陷怀了野种
+ **情感曲线**：
+ 【挣扎】撞翻香炉灰迷了众人眼，爬向送子观音像
+ 【诛心】男主捏着她下巴冷笑："求菩萨不如求我"
+ 【幻痛】汤药入喉瞬间，仿佛听见婴孩啼哭
+ 【变异】七年后女配难产，发现女主当年被灌的是绝子汤

### 以爱为刃

> 公式：保护名义+实质伤害
> 例：【假意出轨+万箭穿心】男主为让女主死心，故意带女配在城楼秀恩爱

+ **场景**：城楼假意背叛
+ **冲突**：为护女主故意伤她
+ **情感曲线**：
+ 【甜蜜】被他蒙眼带上城楼，掌心还留着他写的"信我"
+ 【惊变】眼纱飘落时，看见他正与女配唇齿交缠
+ 【撕裂】城下箭雨袭来瞬间，他拉女配入怀，任她胸口中箭
+ 【轮回】十年后他死守空城，抱着带血的箭矢跳下同一处城墙

### 事业摧毁

> 公式：理想破碎+精神支柱崩塌
> 例：【烧毁医馆+折断双手】男主为阻止女主行医，毁掉她经营十年的药庐

+ **冲突**：折断她救人双手
+ **情感曲线**：

+ 【暴击】他踩住她手腕："这些贱民的命比你干净？"
+ 【变异】用嘴叼着银针给自己接骨，从此只医妓女与乞丐
+ 【反杀】后来他重伤求医，发现她医馆挂着"狗与XX不得入内"

### 友情背刺

> 公式：闺蜜背叛+致命一击
> 例：【贴身侍女+投毒栽赃】女主救回的孤女被女配收买，诬陷她谋害皇嗣

+ **场景**：贴身侍女投毒
+ **冲突**：被最信任的人背叛
+ **情感曲线**：
+ 【温存】梳头时笑着给侍女塞地契："出嫁时给你添妆"
+ 【错愕】腹痛吐血时，看见侍女躲在男主身后发抖
+ 【笑泪】攥着准备送侍女的翡翠簪："原是想给你当嫁妆啊…"
+ 【黑化】在簪头淬毒后插回侍女发间："贺礼总要成双"

### 真相迟来

> 公式：追悔莫及+无力挽回
> 例：【墓碑前+咳血真相】男主发现当年救命恩人是女主时，只剩冰冷墓碑

+ **冲突**：悔悟时女主已死
+ **情感曲线**：
+ 【偏执】掘坟开棺发现空棺，疯狂舔舐棺内血迹
+ 【闪回】在女配首饰盒底层，找到当年真正的救命血衣
+ 【错乱】抱着血衣跳寒潭，在濒死时看见少女时期的她
+ 【轮回】每年清明，疯乞丐总在坟前烧带血的婚书碎片
