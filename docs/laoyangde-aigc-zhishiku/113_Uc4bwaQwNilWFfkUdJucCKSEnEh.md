### **人物平，加缺点。**

+   **含义：** 如果人物显得平淡无奇、缺乏吸引力，一个有效的方法是给他/她添加**缺点**。

+   **应用：** 完美无缺的角色往往虚假且难以亲近。合理的缺点（如傲慢、懒惰、胆小、口无遮拦、优柔寡断、贪财、嫉妒等）能让人物更真实、立体、有趣，甚至产生反差萌。缺点也是推动情节（人物因缺点犯错、陷入困境）和人物成长（克服缺点）的动力。

+   **例子：** 福尔摩斯的毒瘾和社交障碍；钢铁侠的自负和酗酒；《傲慢与偏见》中达西先生最初的傲慢。

### **配角弱，加特征。**

+   **含义：** 如果配角的存在感弱、形象模糊，可以通过赋予其**鲜明特征**来强化。

+   **应用：** 配角不需要像主角那样全面展开，但需要有让人记住的“点”。这个特征可以是**外貌特征**（独特的疤痕、穿着、发型）、**行为习惯**（不停转笔、说话结巴）、**特殊技能**（特别会做饭、记忆力超群）、**口头禅**、**一个执念**或**一种气质**（总是乐呵呵、阴郁）。

+   **例子：** 《哈利·波特》中卢娜的古怪言论和胡萝卜耳环；海格的巨大体型和对危险生物的喜爱；纳威的健忘和后来的勇敢。

### **显身份，服饰定。**

+   **含义：** 人物的**身份、地位、职业、性格甚至时代背景**，可以通过其**服饰、装扮**来直观地展现。

+   **应用：** 服饰是塑造人物的第一视觉印象。国王的皇冠与华服、乞丐的破衣烂衫、医生的白大褂、战士的盔甲、商人的精致西装、艺术家的波西米亚风格、黑客的连帽衫... 精心设计的服饰能瞬间传递大量信息。

+   **例子：** 《红楼梦》中各个人物精细的服饰描写体现其身份地位和性格（如王熙凤的华丽张扬，林黛玉的素雅清冷）；电影中超级英雄的战服是其标志。

### **没起伏，写成长。**

+   **含义：** 如果人物在故事中没有变化和发展（显得扁平），就要着重描写他/她的**成长弧光**。

+   **应用：** 人物的成长（或堕落）是故事的核心魅力之一。设计人物在经历事件后，在**观念、能力、性格、目标**上发生的变化。这个变化可以是积极的（懦弱变勇敢）、消极的（善良变堕落）或复杂的。

+   **例子：** 几乎所有的经典主角都有成长弧光：哈利·波特从懵懂男孩到成熟领袖；《肖申克的救赎》中安迪在绝境中保持希望并最终获得自由；《绝命毒师》中老白从懦弱老师变成冷酷毒枭。

### **主角感，配角衬。**

+   **含义：** 主角的存在感和重要性，需要通过**配角**来衬托和对比。

+   **应用：**

+   **对比衬托：** 用配角的普通、懦弱、愚蠢、邪恶等特质，反衬主角的非凡、勇敢、智慧、善良。

+   **互动体现：** 主角在配角群体中的领导力、影响力、独特见解或行为方式，能强化其主角地位。

+   **关系网：** 配角与主角的关系（亲友、爱人、对手、导师等）定义了主角的一部分身份和情感世界。

+   **例子：** 孙悟空的神通广大在八戒的贪懒好色和沙僧的忠厚老实衬托下更显突出；蝙蝠侠的正义感在小丑的疯狂邪恶面前更加坚定。

### **记忆点，口头禅。**

+   **含义：** 让人物被读者/观众记住的一个有效方法，是赋予其标志性的**口头禅或习惯用语**。

+   **应用：** 一句独特、符合人物性格、在关键时刻或特定情境下反复出现的话语，能迅速成为人物的标签。这比单纯的外貌描写更容易留下印象。

+   **例子：** 灰太狼的“我一定会回来的！”；樱木花道的“我是天才！”；007的“摇匀，不要搅拌”；谢耳朵的“Bazinga!”。

### **没个性，语调调。**

+   **含义：** 如果人物缺乏个性，可以通过塑造其独特的**说话方式、语气语调**来区分。

+   **应用：** 每个人说话都有特点。考虑人物是**语速快慢、用词文雅还是粗俗、喜欢用长句还是短句、有没有口音、习惯用什么感叹词、是冷静理性还是情绪外露、是幽默风趣还是刻板严肃**等等。独特的语言风格是内在性格的外显。

+   **例子：** 《红楼梦》中王熙凤的泼辣爽利、林黛玉的伶俐尖刻、薛宝钗的圆融得体，语言风格截然不同。

### **没行动，给欲望。**

+   **含义：** 如果人物缺乏主动性，显得被动或无所作为，就需要赋予他/她强烈的**欲望、目标或需求**。

+   **应用：** **欲望/目标**是驱动人物行动的核心引擎。一个清晰、强烈、有时甚至是不切实际的欲望，能让人物主动出击，推动情节发展。欲望可以是外在的（财富、权力、复仇、爱情）或内在的（认同、自由、救赎、自我实现）。

+   **例子：** 于连·索雷尔（《红与黑》）对上流社会的渴望驱动他的一切行动；麦克白夫人对权力的欲望导致其疯狂；《飞屋环游记》中卡尔实现妻子遗愿的渴望驱使他飞向南美。

### **言行举，合性情。**

+   **含义：** 人物的**语言、行为、举止**必须符合其**身份、性格、经历和当下情境**。

+   **应用：** 这是人物塑造最基本也最重要的原则——**一致性**和**可信度**。一个粗鲁的莽夫不会突然说出文绉绉的诗句（除非有特殊原因）；一个谨慎的侦探不会在危险现场鲁莽行事。人物的言行是其内在逻辑的外化。

+   **例子：** 诸葛亮运筹帷幄时的从容淡定符合其智慧军师形象；张飞在长坂坡的怒吼符合其勇猛刚烈的性格。

### **塑人物，层次清。**

+   **含义：** 塑造成功的人物，关键在于使其具有**清晰的层次感**。

+   **应用：** 避免人物非黑即白（除非特定类型）。好人有小缺点或阴暗面，坏人可能有可悲的过去或一丝温情。人物在不同人面前、不同情境下可能展现不同面貌（公开形象 vs 私下形象）。内心想法与外在表现可能有差异。这种复杂性（层次感）让人物更真实、丰满、耐人寻味。

+   **例子：** 《三国演义》中曹操的雄才大略与多疑奸诈并存；《冰与火之歌》中绝大部分角色都是复杂的“灰色人物”。
