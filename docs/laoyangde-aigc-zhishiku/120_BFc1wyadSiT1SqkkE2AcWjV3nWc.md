# 二、上干货

### 场景画面感定义

+   简单说： 就是用文字精准描绘出一个具体时空下的环境、人物和事件，让读者在脑海中能像“看”电影一样清晰地“看”到、感受到它。

+   关键要素：

+   时间 & 地点： 故事发生的具体时刻和场所。

+   人物： 谁在场？他们在做什么？

+   环境： 周围的景物、氛围、天气、光线等。

+   互动： 人物与环境、人物与人物之间的动作、对话、情绪反应。

+   核心目标： 营造身临其境的体验，激发读者的感官想象（视、听、嗅、味、触、意）。

### 场景叙事的六种类型（可视化html）

+   **场景是叙事的最小单位，小故事由若**干场景组成，场景直接承载着期待点和爽点！

+   理解不同的叙事方式，就像导演选择不同的摄影机位和视角，直接影响读者“看到”什么、感受到什么。

> 新手提示：

+   代入感优先： 主角多用主观叙事，让读者跟着主角走。

+   视角统一： 一个场景内，主要视角（尤其是主角）不要频繁切换，避免读者混乱。

+   熟悉度变化： 新角色出场多用客观叙事，等读者熟悉了，可适当切到该角色的半主观叙事。

+   神秘感塑造： 想保持神秘的角色（如扫地僧），尽量用客观叙事（通过他人视角感知他）。

# 三、提示词

```
# 小说画面感强化
- 核心目标：让读者像观看电影一样沉浸于场景，激活多重感官体验。

## 1. 镜头语言选择（必选1-2种）
### 根据场景情绪选择叙事视角  
- 客观镜头  
 - 环境细节：[时间+地点+光影+气味+声音]
 - 人物动态：[服饰/动作/微表情]
 - 例：暮色中的古寺，檀香混着铁锈味，残阳把斑驳的刀痕拉得老长。  

- 主角视角（关键体验用）  
 - 感官激活：[视觉焦点+身体感受+心理活动]  
 - 例：掌心黏腻的冷汗提醒我，那柄抵在喉间的刀正泛着幽蓝的光。  

- 特效镜头（高潮场景用）  
 - 动态渲染：[能量流动/空间扭曲/色彩爆发]  
 - 例：剑阵嗡鸣的刹那，万千金纹如裂瓷般爬满夜空！  

## 2. 景别组合拳（至少切换2次）
### 像导演一样运镜：  
1. 远景定基调：[环境氛围+空间感]  
 - 例：暴雪吞没了苍茫的北疆荒原  
2. 全景立关系：[人物与环境互动]  
 - 例：他的黑斗篷在雪幕中撕开一道飘摇的裂口  
3. 特写抓引爆点：[关键细节放大]  
 - 例：冻裂的指关节死死扣住腰间断刀的豁口  


### 3. 画面感增效器（任选1-3项）
- 感官叠加  
 - 视觉+其他感官：[血色夕阳]+[喉咙泛起血腥味]  
- 动态细节  
 - 普通→生动：[他握刀]→[刀柄的缠麻绳在他掌心吱呀呻吟]  
- 色彩冲击  
 - 强化记忆点：[青石巷里飘过一柄胭脂红的油纸伞]  

### 4. 情绪爆破五镜头法（高潮场景专用）
1. 分镜（群像反应）：  
   - [配角A瞳孔地震] + [反派攥碎茶杯]  
2. 总镜（氛围概括）：  
   - &quot;死寂如冰层封住整个大殿&quot;  
3. 解镜（动机补丁）：  
   - &quot;毕竟这招失传三百年的禁术现世了...&quot;  
4. 回镜（焦点重现）：  
   - [主角剑尖滴落的血在祭坛上灼出青烟]  
5. 主镜（行动转折）：  
   - &quot;她舔掉嘴角血渍，剑锋突然转向东方——&quot; 

## 3. 避坑指南
 - 视角混乱→锁定单场景核心视角（尤其忌主角/反派频繁切换）  
 - 描写脱节→环境与人物必须产生交互（如：狂风吹乱她发丝=环境作用于人）  
 - 节奏拖沓→用概括镜头跳过渡剧情（例：&quot;三天的跋涉缩成脚底的血泡&quot;）  

### ✨ 应用示例  
原始句：他在雨中战斗  
强化后：  
 [远景] 墨云压塌了城楼飞檐，暴雨在青砖上炸开万千银箭。  
 [全景] 玄甲身影在雨幕中撕扯，每次挪步都溅起血水泥潭。  
 [特写+主角视角] 冰雨顺着眉骨流进眼眶——他尝到铁锈味的模糊视野里，那道金色刀光正撕裂雨帘！  
```
