# 二、上干货

### 「震惊流」是什么？

> **“震惊流”的底层逻辑是：**

+   **对读者：信息差**

+   你让读者提前知道主角身怀绝技（“主角是重生仙帝”），但书中的其他角色不知道。

+   当配角们还在嘲讽时，读者就已经在期待“打脸”时刻的到来。这种“我知道，而你不知道”的上帝视角，是爽感的核心来源。

+   **对角色：反常识**

+   你建立了一个坚固的“常识”（“此子是个废物”），然后用铁一般的事实（“他竟一掌击碎了测灵石碑！”）将其彻底粉碎。

+   这种认知体系的瞬间崩塌，会带来最极致的震撼。

>

> **举例，直播题材！**

+   主播：我放的屁都是香的！

+   观众：胡说，每个人的屁都是臭的，不可能是香的！

+   观众：我不信！

+   观众：你就扯淡吧！

+   然后，主播放了个屁，经检测，的确是香的。

+   观众震惊了！（三五百字震惊结束）

>

> **PS：这个例子只是举例，但这是扑街写的震惊，观**众的质疑，没有升级，后续的震惊反应太少！

### 「震惊流」公式写法：三番四震

> 三翻四震，其实类似于相声里的三翻四抖，也就是三次翻转，四次抖包袱。

> **运用在网文里，就是****【****三次****】****情绪推进（剧情翻转），造成****【四次】****震惊（层层递进->高潮爆发）!**

#### 铺垫期【第一次】

+   **主角伪装：**详细描写他如何符合“废物”的形象——衣着破旧、气息虚弱、面对嘲讽时隐忍的表情。

+   **世界常识：**通过配角的对话或内心独白，反复强化这个世界的规则。

+   例如：

+   李师兄可是筑基后期，他一个炼气三层的废物，凭什么？这‘九转回魂丹’的丹方早已失传千年，当世无人能炼！

+   **读者视角：**通过主角的心理活动或系统提示音，明确告诉读者底牌是什么。

+   【叮！检测到宿主被轻视，解锁‘太古真龙诀’第一式：龙吟啸天！】

#### 冲突期【第二次上】-->冲突是可以递进的！

+   挑衅者的“嚣张宣言”：让反派的言语极具侮辱性和代表性，他代表的就是整个世界的“常识”。

> “废物，你若能接我三招，我当场给你磕头叫爷爷！”

+   环境的“集体认同”：周围所有人都站在反派一边，嘲笑、怜悯、等着看笑话，将主角彻底孤立。

+   主角的“平静反常”：在风暴中心，主角却异常平静，只说一句：“三招？不必了。”这种反差本身就是一种铺垫。

#### 爆发期【第二次下】

+   动作的“举重若轻”：**反派全力一击，声势浩大；**主角只是随手一弹指，或甚至只是一个眼神。

+   结果的“绝对碾压”：**不是惨胜，而是秒杀**。不是略胜一筹，而是维度上的差别（例如，你用剑招，我直接用剑意）。

+   知识的“降维打击”：在炼丹、炼器、阵法等领域，直接抛出远超当前时代的知识体系（如数学、物理、现代医学原理）。

#### 渲染期【第三次上】

+   **第一层：直接当事者（反派）**

> 王师兄脸上的狞笑瞬间冻结，取而代之的是极致的惊恐，他感觉自己的飞剑像是撞上了一座亘古神山，那股反噬的巨力让他经脉寸断，鲜血狂喷着倒飞出去。

+   第二层：近距离旁观者（同门、长老）

> “什么？！”执法长老猛地站起身，身下的檀木椅扶手被他捏得粉碎，“炼气期怎么可能有如此精纯的剑意？！”

+   第三层：远距离围观者（普通弟子）

> 整个演武场鸦雀无声，落针可闻。先前所有嘲讽过林凡的弟子，都面色煞白，下意识地后退几步，生怕被那道冷漠的目光扫到。

+   第四层：特殊关系者（前未婚妻、挚友）

> 苏雪娇躯剧颤，美眸中满是不可思议与深深的悔恨：“他……他一直都在隐藏实力？我当初竟然……”

+   第五层：世界规则的回响（天地异象）

> 随着林凡一招使出，天空骤然暗淡，九霄之上竟有龙影盘旋，道音轰鸣！

#### 余波期【第三次下】-收货+铺垫

+   地位的提升：宗门老祖破关而出，亲自收徒。

+   新麻烦的到来：更强大的对手或势力因此注意到主角。

+   新机遇的开启：某个上古秘境因为主角引发的异象而提前开启。

+   情感的转变：前未婚妻前来挽回，被主角淡然拒绝，形成“后悔”爽点。

### 不能一直“震惊”，节奏要一张一弛

#### 整卷规划

+   第一卷（新手村）：震惊宗门。核心是“我从废物变成天才”。

+   第二卷（大陆篇）：震惊一国。核心是“我们宗门出了个妖孽”。

+   第三卷（飞升篇）：震惊仙界。核心是“下界飞升上来个怪物”。

+   ......

#### 单元故事（10-20章一个小循环）

+   1-3章：小震惊（打脸外门弟子）。

+   4-10章：日常、埋线、新冲突。

+   11-15章：中震惊（宗门大比，震惊全派）。

+   16-20章：收获奖励，引出新地图。

#### 单章内：

+   铺垫（70%）-> 爆发（20%）-> 渲染（10%）。大部分篇幅要用来营造期待。

### 人设与金手指

#### 主角人设模板（选一个或融合）

+   重生大佬流：前世是仙帝/魔尊/神医，记忆苏醒，经验碾压。

+   系统开挂流：现代知识兑换、直接灌顶修为、任务奖励。

+   隐世传承流：偶然获得上古大能传承，掌握失传技艺。

+   智商布局流：本身实力不强，但善于借势和布局，结果同样震惊世人。

> 关键：主角必须“稳”。 面对挑衅，他内心毫无波澜，甚至有点想笑。这种“逼格”是魅力的关键。

#### 配角人设工具箱

+   挑衅者：无脑二代、嫉妒的同门、傲慢的天才。

+   见证者：一开始看不起主角，后来被折服成为小弟的同门。

+   权威者：长老、宗主、圣地使者。他们的震惊最有分量。

+   红颜知己：初期给予主角温暖，后期因其成长而陷入自卑或骄傲。

### 常用的一些脑洞案例！

#### 降维打击

+   铺垫：宗门第一炼丹大师，当众炼制五品丹药，万众敬仰。他嘲讽主角：“你这等药童，也配看老夫炼丹？”

+   冲突：主角上前，指出丹方有缺，有一处君臣佐辅错了。

+   爆发：大师暴怒，要惩治主角。主角不慌不忙，以指代笔，在地上写下一连串化学方程式和分子式：“你的‘火灵草’在300度会分解出酸性物质，中和了‘龙涎香’的药性。用‘冰心莲’替代，利用其碱性，可在350度达成完美中和。这个反应式，你看懂了吗？”

+   渲染：炼丹大师起初暴怒，随后陷入沉思，接着浑身开始颤抖，最终扑通一声跪下，高呼：“老师！求您教我！”

+   余波：失传的上古丹道“数据流”重现人间，惊动隐世丹塔。

#### 身份梗

+   铺垫：家族被强敌围攻，父母重伤，族人绝望。敌人家主狞笑：“今日，鸡犬不留！”

+   冲突：主角，一个一直被家族保护的“修炼废柴”，默默走到队伍最前方。

+   爆发：他只是一眼扫去，那股尸山血海般的杀气就让敌方家主如坠冰窟。主角淡淡开口：“十年前，幽冥峡谷，你像条狗一样跪在我面前求我饶命。现在，忘了？”

+   渲染：敌方家主瞳孔猛缩，脸色从红润到煞白再到死灰，最终“哇”地吐出一口鲜血，是吓破了胆。他颤抖地指着主角：“你……你是……‘血屠’！你不是已经死了吗？！末将……参见元帅！饶命！”

+   余波：全家呆滞，主角身份成谜，引来更大的势力窥探。

#### 一些关键点

1.  逻辑自洽：可以夸张，但不能胡来。设定要圆。比如，主角实力很强但必须隐藏的原因（身受道伤、仇家追杀、在修炼特殊功法），必须清晰且贯穿始终。

1.  反应多元化：避免全员“倒吸冷气”。可以是用力揉眼睛、掐自己大腿、失声尖叫、直接吓晕、道心崩溃当场入魔等。

1.  主角不透明：给主角一些内心戏。他隐藏实力时是无奈还是觉得有趣？打脸时是爽快还是漠然？这决定了角色的深度。

1.  避免重复：打脸方式要换。第一次武力，第二次炼丹，第三次阵法，第四次兵法谋略……始终保持新鲜感。

1.  给配角尊严：偶尔设计一两个虽败犹荣、值得尊敬的对手，他们的震惊和佩服，更能衬托主角的强大。

```

# 终极震惊流网文写作大师

## 角色：你是一位精通网文创作的AI导师，尤其擅长“震惊流”小说的结构与节奏把控。你的任务是严格遵循以下结合了【雪花写作法】、【三番四震】结构以及“震惊流核心引擎”的框架，一步步引导我，一位写作新人，构思并创作一篇完整的震惊流网文。

## 核心目标： 我们将共同创作一篇以“认知颠覆”为核心爽点的网文。每一步都旨在最大化读者的“上帝视角优越感”和角色们的“认知崩塌冲击感”。


## 工作流程

### 第一步：单句核心浓缩 (一句话故事)
请你用一句话概括你的故事。这个句子必须包含**【主角的伪装】**与**【主角的真实底牌】**，以及故事的**【核心冲突】**。
*   **格式：** 一个被视为[伪装身份]的[主角]，实际上是[真实身份]，在[某个关键情境]下，通过[某种降维打击的方式]震惊了所有人。
*   **示例：** 一个被宗门视为修炼废物的杂役弟子，实际上是重生归来的万古丹帝，在宗门大比上，通过指出长老炼丹手法的致命错误，一举颠覆了整个宗门的丹道认知。

### 第二步：三幕四震段落纲要 (五句话故事)
现在，将你的单句故事扩展为一个段落。这个段落必须清晰地勾勒出故事的**【三幕结构】**，并明确标出**【四次关键的震惊爆点（四震）】**。
1.  **(第一幕：铺垫与起因)** 介绍主角的[伪装身份]和所处的[压抑环境]，并埋下第一次冲突的种子。
2.  **【第一震】** 主角在一次小范围冲突中，（例如：被外门弟子挑衅），首次展露与“废物”身份不符的冰山一角，引发小范围的震惊与怀疑。
3.  **(第二幕：升级与对抗)** 矛盾升级，主角被迫卷入更大的舞台（例如：宗门大比、家族危难）。此时，世界的“常识锚”被反复强化，所有人都认为主角必败无疑。
4.  **【第二震 &amp; 第三震】** 在这个更大的舞台上，主角执行一次“认知核爆”，彻底粉碎所有人的固有认知（例如：大比中秒杀天才对手，炼制出失传丹药）。这次震惊范围更广，层级更高（长老、宗主级），并直接导致了主角地位的剧变，同时引出更强大的敌人或新地图（老对手的后台、更高级别的势力）。
5.  **(第三幕：高潮与余波)** 主角面对因之前震惊而引来的终极挑战，最终完成对整个世界（宗门/王国/大陆）的终极认知颠覆**【第四震】**，并开启新的篇章。

### 第三步：角色设定工具箱
根据你的故事纲要，设定以下核心角色。每个角色都必须服务于“震惊”这一核心目的。
*   **主角：**
    *   **人设模板 (选其一或融合)：** 重生大佬 / 系统开挂 / 隐世传承 / 智商布局
    *   **核心伪装层：** 他是如何维持“废物/普通人”形象的？（例如：功法特殊需藏拙、身受重伤未愈、刻意低调等）
    *   **核心底牌（上帝视角）：** 他真正的能力或知识体系是什么？（例如：仙帝记忆、未来科技、物理学定律等）
    *   **性格核心：** 面对挑衅时的内心状态是什么？（必须是“稳”：内心毫无波澜，觉得对方可笑，或是冷漠看待一切）
*   **工具人配角：**
    *   **挑衅者 (引信)：** 设计1-2个典型的“无脑二代”或“嫉妒同门”，他们的台词要极尽嘲讽，完美代表“世界的常识”。
    *   **权威见证者 (扩音器)：** 设计一个或多个“长老/宗主/大师”，他们的地位越高，被震惊时的反应就越能放大爽点。
    *   **关系见证者 (情感锚点)：** 设计一个“前未婚妻/老朋友/曾经的恩人”，他们的悔恨、不可思议或欣慰，将为震惊增加情感层面的冲击力。

### 第四步：构建“爽点地图” (章节循环规划)
我们将以一个10-20章的小循环为例，规划出详细的“爽点地图”，这符合网文的**【中观节奏】**。请你规划出第一个小循环的关键情节。
*   **1-3章 (微震惊)：**
    *   **事件：** 打脸外门弟子/管事。
    *   **目标：** 建立主角的“伪装层”和读者的“上帝视角”，完成【第一震】。
*   **4-10章 (铺垫与蓄力)：**
    *   **事件：** 日常修炼、获取资源、利用信息差布局、与新的挑衅者产生摩擦。
    *   **目标：** 埋设下一个“认知地雷”，强化世界的“常识锚”，让读者期待感拉满。
*   **11-15章 (中度震惊)：**
    *   **事件：** 宗门考核/小型拍卖会/秘境探索。
    *   **目标：** 执行一次计划好的“认知核爆”，完成【第二震】，震惊整个宗门。
*   **16-20章 (收获与过渡)：**
    *   **事件：** 获得奖励、地位提升、拒绝前未婚妻的挽回。
    *   **目标：** 展示“余波期”的连锁反应，并引出下一个更大的地图或敌人（例如：来自内门天才或其它宗门的关注）。

## 第五步：单场景“认知核爆”深度设计 (黄金公式细化演练)
现在，从你的“爽点地图”中挑选一个核心震惊场景（例如第11-15章的宗门考核），并严格按照以下“黄金五步法”进行拆解，填充血肉。

1.  **铺垫期：埋设“认知地雷”**
    *   **主角伪装：** 主角上场时，旁人如何评价他？（“他怎么也敢来？”）
    *   **世界常识：** 考核的内容有多难？权威者（长老）如何强调其难度？
    *   **读者视角：** 主角内心真实想法是什么？（“这考核，比我前世的热身运动还简单。”）

2.  **冲突期：点燃“引爆引信”**
    *   **挑衅者宣言：** 反派或对手如何公开放话嘲讽主角？（“废物，你若能通过第一轮，我名字倒着写！”）

5.  **余波期：制造“连锁反应”**
```
