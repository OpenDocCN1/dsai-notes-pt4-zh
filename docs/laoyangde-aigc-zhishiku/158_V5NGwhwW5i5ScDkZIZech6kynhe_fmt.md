## 书籍简介

在当前社会，写作已经逐渐成为人们的第二职业选择。文章中指出，写作门槛虽然低，但想要在这个领域取得成绩并不容易。

对于那些怀揣文学梦想的人，找到入门的正确章法有时是一项困扰。

从提笔胆怯到成为写作高手，本书通过16大方法、8大步骤和9种写作技巧，为读者提供了有效解决写作难题的基础方案。

## 书籍内容

书中从写作的基础知识讲起，重点介绍了以下几类写作技法：

1. 影视剧本写作：包括编剧入门基础知识、故事大纲创作技巧、人物与人物小传的创作、故事素材的选择、故事分集和分场的写法、台词写作技巧、剧本初稿及反复修改、故事结构的分类、与资方、平台的合作流程及注意事项。

1. 漫画剧本写作：涉及漫画剧本创作常识、故事线处理及人设塑造、漫画分镜头脚本的创作、如何组合完整的漫画文字脚本、经典项目案例分析、漫画编剧的职业规划。

1. 网文写作：讨论了什么是网文、如何找准写作风格定位、如何写长篇小说的大纲、书名与简介的写作秘诀、开篇写作技巧、高质量人设的打造、剧情丰富方法、正文需要避免的“雷区”和“毒点”。

1. 短篇小说写作：从零开始，介绍了小说构思七大要素、经典人物的塑造、人物的特殊性、完整性、多面性和逻辑性、短篇小说投稿注意事项、知乎风小说写作要点、打造爆款知乎风短篇小说。

1. 影视向 IP 与出版小说写作：探讨了什么样的小说更适合影视改编、适合影视改编的小说类型、新人在写影视向小说时应注意的问题、男性向 IP 和女性向 IP 的区别、青春向 IP 和成人向 IP 的区别、影视向 IP 和出版向小说的写作区别、开头如何写能吸引影视制作方。
