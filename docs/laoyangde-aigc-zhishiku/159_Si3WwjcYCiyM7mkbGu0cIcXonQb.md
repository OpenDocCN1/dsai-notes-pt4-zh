# 写小说找资料必备20个宝藏app

> 来源：[https://rq547mr4oez.feishu.cn/docx/C5sFdVOGgoO0SFxFaXGcrTbGnCc](https://rq547mr4oez.feishu.cn/docx/C5sFdVOGgoO0SFxFaXGcrTbGnCc)

20个找资料的宝藏app

# 1.全历史

![](img/765365b330b0240a1c52f62e7b83ba58.png)

**一个**以编年表、关系图谱、代表人物、事件节点形式去展现各国历史的软件。

除文章形式之外，还有词条、人文科普视频、历史趣谈、各国各朝代帝王皇后的大盘点、音乐美术心理哲学的发展史，甚至还收录了各国的古籍经典、古迹遗址（文字介绍+3d展示）

# 2.华夏风物

![](img/3c17e5255fbe608dca6cacfadad1a346.png)

主要收录全国各个城市的风土人情，小到美食特产、大到人文景观起源发展，全部都有。

比如北京特产小吊梨汤，口感、特点、食材、工艺一一全部说的明明白白；比如天府号酱肘子，除了前面说的这些之外，甚至还介绍了历史典故和吃法

其他美食类app：下厨房、香哈菜谱

# 3.西窗烛

古诗文app，收录了大量的诗词曲赋经典。

各种主题分类非常的清晰，每天还会随机推送一个句子，甚至还有一些用户收集的主题诗单，能挖到各种冷门的绝妙美句。

# 4.典读

![](img/d4b31f075b514bf0be02e50ef4996af8.png)

主要收录各种国内外的文学经典、诗词散文典故，还有一些听书的资源和经典解读。

内有名句摘抄分类，收录各种名人名言台词语录等等（包含电影和动漫内容），有根据主题心情给这些摘抄进行分类。

# 5.每日故宫

![](img/180645d2c3dc66c0ae77f6899f3d2350.png)

可以让你在故宫云溜达，各种藏品都有介绍，非常详细。

# 6.中华珍宝馆、7.故宫陶瓷馆

![](img/f26319746eac6762c6d0fed377e9742e.png)

前者主要展示书画，后者主要展示瓷器

# 8.国家博物馆

有个虚拟展厅，语音讲解非常详细，不定期的会有各种文化专题展，比如古代服饰、古钱币之类。

# 9. 看鉴微视频

![](img/9c084abda567873a836ce79f819e8624.png)

纪录片大全，国内外的都有，如《手术200年》《无饭不起早》《百家姓》《三十六计》《玉石传奇》《本草中国》《小师傅》等。

收录资源免费，自有资源需vip，年费98元。

同类推荐：b站和央视网的纪录片分区

# 10.知源中医

03:22

![](img/88e7385f5ccbc2969c606c1983501e60.png)

收录中医药膳方剂、医学经典、教材、歌诀，可查食物特性。

# 11.中医通

![](img/e8c34c4e5bb85ae8bae436889e905183.png)

可查疾病表征（包括望闻问切）、名家医案、方剂剂量、经络穴位。

课程需vip，但写小说查资料免费内容足够用了。

# 12.有来急救百科

![](img/68e4d1e4fec1feda36385510cd21297e.png)

各种急救小知识，比如中毒、冻伤、骨折该怎么处理，从急救知识的原理到手把手操作，视频讲解超详细。

良心app，全免费，没广告。

# 13.🛰️读书

![](img/d292e56d6737d97af251e491bdf8694b.png)

白嫖党最爱的APP没有之一，各种畅销书基本都有

# 14.博看书苑

凡是在图书馆能看到的各种图书期刊杂志这个app基本都有，像《意林》《读者》《故事会》《爱格》等等。

但注册时需要授权码，授权码各个大学的图书馆和市立图书馆一般能提供

# 15.国家数字图书馆

![](img/a17e8e1c51055b417e62ca4be8394e51.png)

除了图书期刊之外还有很多公开课资源。

其他公开课资源：b站、慕课

# 16.超星学习通（超星移动图书馆）

![](img/d94df3bcbb1a273d6609db4ebf339e1f.png)

内置资料搜索功能，除了常规的一些书籍之外还有很多专业课教材，比如《中国古代文化常识》《花样滑冰》等等比较老的一些书的电子扫描版。

# 17.学习强国

![](img/ac9a92b91ee92ec1dbcfabe4309ecd8a.png)

电视台-公开课、影视-纪录片、网络视频-网络纪录片、强国医生、法律科普……

资源基本免费，完全没广告，祖国的良心支持。

# 18.纪妖

妖怪百科，古籍传说当中有妖怪基本都有收录，内容也比较考究。

# 19.贝克街推理学院

其实是一个游戏社区，只有安卓版，里面有一个百科分类，有很多用户总结的犯罪推理的一些小知识。

# 20.中国法律

法律条款、案件的例子等等
