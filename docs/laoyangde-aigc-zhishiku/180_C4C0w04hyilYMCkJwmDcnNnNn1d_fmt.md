## 二、短篇拆书思路和Prompt

### 第1步：故事梗概

+ 故事背景：介绍故事发生的时代、地点等背景信息
+ 主要人物：列举主要角色，简要描述他们的性格、目标和动机
+ 故事情节：按照时间顺序，概述故事的主要情节和发展线索

### 第2步：主线剧情分析

+ 开篇：事的起始事件；包括场景、人物和事件；引发主要冲突的问题。
+ 铺垫：高潮之前的重点情节，如何引起读者注意力的？
+ 高潮：如何解决主要冲突？重要决策上如何做选择？重大转折点在哪？最紧张的部分怎么写的？
+ 结尾：故事最终结果人物，命运的走向，给读者印象深刻的点。
+ 支线剧情分析
+ 支线 1：比较支线剧情和主线剧情的差异和相似之处，分析这种对比如何增强故事的复杂性。
+ 支线 2：支线 3：(同上)

### 第3步：角色分析

+ 主角：
+ 性格特点：分析他的性格特点，标注一些相关情节来体现这点
+ 目标动机：想想它们如何推动故事的发展
+ 成长转变：包括他如何面对挑战、克服困难以及思想上的升华
+ 配角：
+ 角色关系：配角与主角的互动方式，对主角产生什么样的影响
+ 性格行为：分析性格，经典的行为，在故事中的作用是什么？对情节的影响
+ 情节推动：如何推动故事的发展？增加情节张力？
+ 反派：
+ 人物背景：有什么样的背景，包括出身、学识、经历等
+ 角色冲突：与其他角色之间的冲突，是如何影响故事发展的
+ 人物狐线：成长、变化、最终结局

### 第4步：主题与情感

+ 主题与情感分析
+ 主题：爱、人性、战争；成长、友谊；爽文；
+ 情感表达：角色之间的情感纽带，和情感变化；正义、勇气。

### 第5步：风格和技巧

+ 写作风格与技巧
+ 叙事风格：视角（第一人称、第三人称有限视角还是全知视角）节奏，以及高潮和低谷的分布。
+ 叙事技巧：倒叙、插叙
+ 人物刻画：外貌、语言、行为、心理
+ 情节构建：悬念、伏笔、意外、转折等手法

### 第6步：感悟与评价

+ 个人感悟与评价
+ 个人感悟：你对情节、人物、主题的理解
+ 总结优点：有哪些引人入胜的情节、深刻的角色等
+ 不足之处：尝试找错，刻意去找情节漏洞、角色行为不合理的地方

在文学创作和分析中，读者和作者经常需要对故事的情节、节奏、优点、人物设定和情绪变化进行深入的理解和分析。这种分析有助于把握故事的核心元素，提升叙事技巧，以及增强读者的阅读体验。

## Attention：

- 熟练掌握起承转合等叙事技巧，并能概括全文内容。

- 能够识别引起情绪变化的情节，并生成情绪折线图。

## Workflow:

3. 分析故事节奏，按照三幕式结构进行划分并统计字数。

5. 梳理人物形象、关系、情绪变化和动机，列出具体情节。
6. 识别情绪变化的情节，生成情绪折线图。

- 故事节奏分析建议：注意段落之间的过渡，保持故事的流畅性。

- 人物设定梳理建议：深入挖掘每个人物的背景和心理，增强人物的立体感。

### 故事情节概括

+ 起：影帝周逢颐为了赌气，娶了叙述者。结婚三年，周逢颐与初恋唐月茹的关系始终纠缠不清，叙述者表面上是周逢颐的妻子，实际上却是一个可怜的替身。
+ 承：叙述者在婚姻中始终保持沉默，甚至在意外怀孕后选择瞒着周逢颐打掉孩子，因为她意识到自己并不爱周逢颐，而是爱着他已故的哥哥。
+ 转：随着时间的推移，周逢颐似乎开始对叙述者产生了感情，但就在叙述者怀孕之际，唐月茹回国，两人和好，叙述者被抛弃。
+ 合：叙述者经历了被背叛、被侮辱，最终决定离婚。在离婚过程中，她发现自己怀孕了，但周逢颐并不知情。叙述者对周逢颐彻底失望，决定结束这段关系。

### 故事节奏分析

故事按照三幕式结构进行划分：

+ 第一幕：叙述者与周逢颐的婚姻生活，以及她的内心感受。字数统计需根据全文具体分布。
+ 第二幕：唐月茹的回归，叙述者与周逢颐关系的转变，以及叙述者怀孕的情节。字数统计同上。
+ 第三幕：叙述者决定离婚，与周逢颐的冲突，以及最终的决裂。字数统计同上。

### 故事优点拆解

+ 故事以紧凑的情节和复杂的人物关系吸引读者。
+ 叙述者的冷静和坚强，以及她对周逢颐和唐月茹关系的深刻理解，为故事增加了深度。
+ 故事中的情感冲突和道德抉择，引发读者的共鸣。

### 人物设定梳理

+ 叙述者：一个内心强大，面对背叛和不公仍保持冷静的女性。
+ 周逢颐：一个在爱情和责任之间挣扎的男性，最终选择了旧爱。
+ 唐月茹：周逢颐的初恋，她的回归成为故事转折点的关键人物。

### 情绪变化分析

情绪变化的情节包括：

+ 叙述者在婚姻中的忍耐和沉默。
+ 叙述者打掉孩子后周逢颐的愤怒和不解。
+ 叙述者在唐月茹回归后感到的背叛和心痛。
+ 叙述者决定离婚时的坚决和释然。

情绪折线图将展示从叙述者的平静到愤怒，再到最终的释然和坚强的情绪轨迹。

### 结论

> 故事通过叙述者的视角，展现了一段复杂的婚姻关系和人物之间的情感纠葛。通过深入的人物塑造和情感变化的描述，故事成功地引起了读者的共鸣，并对人物的心理和动机进行了深刻的探讨。

## 四、然后，人工在拆

### 作品概述

《幼薇》现代言情，虐恋。知乎点赞6.7万。

标题采用直述主题式，直接以主人公“幼薇”的名字命名。直接点明故事的主要内容，告诉读者本故事主要讲幼薇的故事。

PS：一个好的名字是多么重要！！比如说柳如烟，我一定会点进去看看是啥。

一句话故事：“我跟爱人替身先婚后爱，白月光回国后他选择了白月光，我选择离婚并替爱人报仇。”

故事主题是四个人的爱恨情仇。

> 创意的点，就在于打破故事的一般设定。一般故事设定，都是主角深爱着对方，最后被抛弃，而后爱恨纠缠不断。

> 她的设定高明之处，就在于女主之所以选择男主，只不过是男主长着一张酷似女主心爱的人。

> 出其不意，意想不到的设定，极大满足了读者的猎奇心理。

### 故事结构

导语采用概括叙述法，故事主概简单直接地呈现在读者眼前，不拖沓，不做作，直截了当告诉读者，喜欢就请进，不喜没关系，绝不耽误大家时间。

一句“我爱的人，是他死去的哥哥”，看到这，我直叹：“这个剧情绝了！超狗血！好喜欢！”引得我不自觉地看下去。

在信息爆炸的时代，吸引力是成功的第一秘诀。恭喜她成功了。

### 人物塑造

+ 通过幼薇，周承颐，唐月茹，周承昱的四个角色建立复杂的关系网络，增强故事的情节发展和角色的塑造。
+ 唐月茹的矫揉造作，茶里茶气，突出“绿茶本色”。周承颐一碰到唐月茹，就智障。
+ 幼薇自从疼爱她的人走后，就一直拒绝他人的好意，用坚强的冷静的姿态，武装脆弱的内心。
+ 周承昱一直在幼薇的记忆中，张扬不羁，打抱不平，聪慧，打架是常事，是家长老师眼中的不良少年。

### 叙事技巧

采用顺叙法，插叙法，补续法及插叙法，多种叙述手法并用，让故事节奏松弛有度，起伏跌宕，增加阅读体验。

### 情感描写

作者采用反衬和对比的写法及联想和回忆的写法。

通过周承颐对待幼薇和唐月茹的态度，来反衬幼薇的心理变化，使其看清周承颐的人品，并对其失望，最后下定决心离婚。

通过联想和回忆，突出玉牌对幼薇的重要性，而周承颐的态度，更加能够坚定离婚的信念。

![](img/3e307d6453771cea5473a0b52eaf9631.png)

### 细节处理

有两处细节处理，我感觉很有亮点。

+ 一处是在同学会上，唐月茹的受辱过程，步步紧逼，对应周承颐的反应，从慢吞吞开口，到护着她离开。情节紧凑，层层推进，看得很过瘾。
+ 另一处是周承昱被风带走了，一个“风”字，既有画面感，又给读者留下无限的想象和遐想。“风，怎么会将人带走呢？”“又是在什么样的情景下被带走的呢？”

### 语言风格

多用短句，少用长句，语言朴实无华、简洁明快，让人感到亲切自然，让读者快速理解和感受到故事的主题和情节。

### 结尾处理

采用首位呼应式的结构。

结尾处，幼薇靠在周逢昱的墓碑旁，喃喃低语：“就说说，你还没听过的，我喜欢你这件事吧”，与导语“我爱的人，是他死去的哥哥”，相呼应。让整个故事有头有尾，形成一个完整的闭环。这种结尾方式能够让读者感受到故事的完整性和连续性。

### 总结

> 每一个爆款文，不是随随便便得来的。每一个成功，都需要不断地打磨锤炼。

《幼薇》最成功的要属导语部分，一个预想不到的故事设定，赚足了读者的眼球，让读者不得不跟随作者的脚步，走进情节中，了解故事的发展。

但是缺点：故事情节对抗与冲突不够激烈，而且小三，正宫，渣男的对手戏，总缺点新意。如果把维度提高一个维度，估计会更有看点。还有对于母亲的回忆，我个人认为可以删掉。周承昱的剧情太少了。
