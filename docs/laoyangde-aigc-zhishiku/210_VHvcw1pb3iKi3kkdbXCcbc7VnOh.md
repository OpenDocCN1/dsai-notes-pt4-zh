## 二、上干货

### 故事主题

> “捡漏”核心贯穿全文：从捡玫瑰花、奢侈品，到捡投资机会、男主的心，通过“捡漏”串联“搞钱”与“恋爱”。

> 核心设定：【清醒财迷女主+自我攻略型男主+弹幕助攻+捡漏（信息差）+恶毒女配+女主地位逆袭】

### 人设分析

人物标签：核心逻辑就是“讨喜”（让读者喜欢，幻想成的样子）

+ 女主：精明务实，爱财但不贪心，行动力超强，利用聪明才智赚钱，同时有策略地攻略男主。

+ 人物弧光：从“大学捡花卖花的穷打工妹”成长为“毕业创业投资的富企业家”。

+ 人物动机：

+ 因父母偏心致穷、缺钱，“穷”驱动她捡漏、搞事业；

+ 理性大于冲动，一切以搞钱为主（甚至拒绝加纪延🛰️，除非影响赚钱）

+ 前期为搞钱追男主，后期被男主纯情打动，真心沦陷

+ 男主：表面高冷，实则傲娇纯情、爱脑补，被女主“直球打法”吸引，自我攻略。

+ 人物动机：

+ 因“被拒”失落，女主主动表白满足其情绪需求；

+ 好友“拱火”+女主“深情表白”（男主视角），让他既慌张又加深对女主的印象

+ 嘴上傲娇，身体诚实（“点开对话框217次”），外冷内热纯情小狗

+ 反派：爱虚荣的双胞胎姐姐林苑（反向助攻）

+ 配角：纪延（助攻）【看似冷酷直男，实则最强助攻】

> CP反差

+ 男主：有教养的富二代，“自我攻略”的“爱脑”（侧重谈恋爱）

+ 女主：聪明努力的创一代，一切以“搞钱”为主（侧重搞事业）

+ 核心：男主不傲慢，女主不因穷自卑，双方都利用资源搞钱；男主主导感情线，女主主导事业线，双线推进

+ 感情线：男主被动抗拒→男主内心动摇→男主主动倒贴→男主彻底沦陷

+ 事业线：捡漏→卖花→炒股→投资游戏公司→创业当老板（每次搞钱都和男主有关）

> 对照组反差

+ 女主林染：穷学生，靠捡漏赚钱，不受父母待见

+ 姐姐林苑：白富美，习惯当反派，深受父母宠爱【前期高傲，后期狼狈】

+ 核心逻辑：双胞胎“主角与反派”长得一样但性格相反，制造误会与冲突

### 金手指分析

> 【弹幕系统概念】

> 上帝视角外挂，既帮女主“支招解决危机、扭转处境”（智囊团+助攻），又“实时吐槽剧情和人物”（增强读者代入感）

> 【弹幕作用】

+ 打破信息差：让读者和主角知晓其他人物真实状态，看清男主“自我攻略”

+ 制造笑点：点破主角行为背后的真实想法，以反差感造梗（如“池也嘴角比AK还难压”“妹宝，我恨你是块木头”）

+ 增强读者代入感：弹幕本身是“读者视角”，方便硬核代入

+ 埋下伏笔钩子：借弹幕向读者透露伏笔/回收伏笔，引发对后文的期待

> 【弹幕设定亮点】

+ 提供策略：危机时弹幕直接给解法，帮女主逆风翻盘（如“卖花被抓时，靠弹幕支招反转，获男主同情”）

+ 制造笑点：通过“读者知道→主角不知道”的信息差，吐槽角色内心戏（如“轻要哭哭误打成‘亲他一口’”）

### 剧情节奏

#### 【起】阶段一：反套路开局

+ 导语/开篇剧情：女主捡花时偶遇男主，直接开口“追”他；男主误认双胞胎，对“林染”产生印象。

+ 金手指+反套路+关系破冰：

+ 弹幕“上帝视角”支招“捡人比捡花值”（笑点）；

+ 女主听劝“直球追男主”，实则动机是“搞钱”（反套路+信息差）

+ 情感曲线：男主“错愕→好奇”（对林染产生印象）；女主“目标明确”（搞钱为主，恋爱为工具）

+ 03-04剧情：女主卖花被男主抓包，弹幕教“装可怜+反客为主”，男主误会

+ 冲突推进：卖花被抓（冲突）→弹幕支招（策略）→男主误会“她爱惨了我”，对女主更感兴趣（反转）

+ 情感曲线：男主“表面严肃→内心动摇”（首次主动接触）；女主“搞钱成功（赚8000），尝到利用男主的甜头”

#### 【承】阶段二：暧昧拉扯→双向套路推进

+ 05-08剧情：生日宴捡漏奢侈品，姐姐刁难被男主打脸

+ 爽点叠加+反派退避：富豪区“捡宝”赚20万；男主对姐姐冷淡（“你哪位？不认识”），女主暗爽

+ 情感曲线：男主“刻意制造机会（邀女主赴宴）→关注加深”；女主“搞钱+打脸姐姐（爽点）→开始习惯男主存在”

+ 09-15剧情：女主偷听投资消息、打游戏展现实力，男主持续偶遇

+ 细节铺垫+暧昧升温：女主“一心二用”（带飞男主+偷听商机）；男主“每天制造偶遇等女主打招呼”

+ 情感曲线：男主“被动接受→主动靠近（改去图书馆）”；女主“关注男主，保持联系”

#### 【转】阶段三：关系突破→直球反撩→误会解除

+ 16-18剧情：男主邀女主回家打游戏，女主“表面赴约，实则计划去富豪区捡垃圾+投资学长项目”

+ 细节铺垫+暧昧升温：女主“信息差搞钱”；对男主产生“生理性喜欢（味道、心跳加速）”。

+ 情感曲线：男主“主动靠近→主动出击（邀打游戏）”；女主“搞钱优先级下降，开始在意男主反应”。

+ 19-20剧情：女主试玩学长游戏，男主误会吃醋，女主主动亲吻，弹幕口误神助攻“强吻”

+ 情感爆点：强吻名场面（男主脸红到脖子根）；弹幕翻车（“轻要哭哭”误打成“亲他一口”）

+ 情感曲线：男主“傲娇→小狗（被亲后手足无措，主动报备行程）”；女主“攻略男主→真正心动（心跳、心口涟漪）”。

+ 21-23剧情：球赛名场面+姐姐造谣被打脸

+ 高潮爽点+反派退避：男主当众澄清“喜欢的一直是林染”，姐姐惨败；女主“投资游戏赚千万”曝光，双高碾压

+ 情感曲线：男主“明确心意，护妻狂魔上线”；女主“事业感情双丰收，摆脱原生家庭阴影”。

#### 【合】阶段四：双强HE+解怨过去

+ 24-26剧情：揭秘“高三游戏结缘”伏笔，女主主动求婚

+ 伏笔回收+反套路结局：

+ 纪延小号使用者是男主（男主早是“金主”，加深宿命感）；

+ 女主掌握感情主动权（“要不要跟我结个婚？”）。

+ 情感曲线：男主“纯情小狗属性拉满（求婚三次被拒仍坚持，听到结婚喜极而泣）”；女主“搞钱机器→敢爱敢做”。

+ 27-28剧情：创业成功，事业逆袭，打脸偏心父母

+ 爽点：女主公司上市，父母面试保洁被拒；男主告白“她不必顶峰相见”（尊重女主）。

+ 情感曲线：“套路攻略→真心相爱，关系升华”。

### 情感曲线

+ 男主情感曲线：被动抗拒→内心动摇→主动倒贴→彻底沦陷

+ 抗拒：误认女主是姐姐→拒告白→被“捡花执念”打动，被动加🛰️

+ 动摇：刻意制造偶遇→因纪延吃醋→关注女主动静（“为什么不发圈？”）

+ 倒贴：被强吻后破防→护妻升级（球赛澄清）→明确告白

+ 沦陷：暴露“恋爱脑”→强调平等尊重（“她不必配得上我，做好自己就好”）

+ 女主情感曲线：功利利用→爱不自知→正式心意→真心沦陷

+ 利用：表面追男主，实则搞钱→对男主颜值心动，却拒绝承认

+ 不自知：春心萌动，关注男主口味，却“装睡”

+ 觉醒：主动亲吻后正视心意→认真经营感情

+ 沦陷：事业有成仍选男主→主动求婚，确认“爱他是灵魂契合，非功利”

### 情节构建套路技巧

> 主角有明确目标（搞钱、攻略）→利用金手指（弹幕）解决问题→通过关键事件（生日宴、篮球赛）推进关系→反派制造冲突（林苑刁难）→最终达成HE

> 套路总结：危机/机遇→弹幕给策略/主角急中生智→执行策略→反转局面→正反馈（获财富/感情进展）→负反馈（埋后续冲突隐患）

> 举例：卖花被抓（危机）→弹幕支招“装委屈+打感情牌”→女主说“看到花就想起你”→男主误会“睹物思人”（反转）→男主主动，姐姐又搞事（负反馈）

### 爽点设计

#### 事业线爽点

> 围绕【捡漏→变现→升值】结构设计：

+ 不劳而获：捡垃圾赚差价、帮室友抢票、男主生日宴捡垃圾、雨中捡名表，直接变现20万。

+ 信息差赚钱：偷听富豪对话炒股、投资学长游戏公司，从20万滚到千万。

+ 打工仔反转：“捡漏”贴合年轻读者对“副业”“信息差致富”的向往，降低逆袭门槛，满足暴富幻想

#### 感情线爽点

> 围绕【反撩→反差→护短】结构设计：

+ 反撩与反撩：女主主动撩、掌握主动权；男主被动招供、自我攻略。女主“直球搞钱+感情自洽”，契合当下读者需求。

+ 人设反差感：男主“表面高冷校草，私下望妻小狗”；女主“表面财迷，实际清醒自信、敢爱敢行动”。

+ 护短与误会：男主生日宴打脸姐姐、篮球赛霸气澄清误会
