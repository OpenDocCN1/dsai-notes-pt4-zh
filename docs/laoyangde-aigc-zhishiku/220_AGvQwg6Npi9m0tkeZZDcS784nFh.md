## 二、上干货（原剧本找老杨要吧）

```
## 1-1 日 外 天庭-斩仙台
人物：孙悟空（斗战胜佛装扮）、李天均、净文菩萨、吕洞宾、赤脚大仙、奎木狼、哪吒、李靖、数十名天兵天将
【全景】云雾缭绕的斩仙台，数十名天兵天将持械肃立，诸神或立或悬，皆将目光投向台中央的李天均，气氛肃穆压抑
【中景】李天均囚服加身，脖颈与手腕套着锁仙链
△李靖（语气凝重）：妖人李天均，屠戮佛教伽蓝十六祖，其罪当诛
【中景】孙悟空、哪吒、净文菩萨等神仙面部特写
△吕洞宾（咋舌，面露惋惜）：凡间数百年来，灵气稀薄，飞升者寥寥无几，好不容易出了个天纵之才，竟落得如此下场
△赤脚大仙（接话，语气感慨）：是啊，自当年大圣大闹天宫后，西牛贺洲还是头一回出这么大的乱子
△奎木狼（抬手指向高处，声音压低）：慎言，那大圣今日也来了，就在上头看着呢
【特写】高处云台上，孙悟空捻着佛衣边角，啃食仙桃
△孙悟空（挑眉，漫不经心）：嗯，谁在念叨俺老孙
△哪吒（转向孙悟空，打趣）：猴头，你今天怎么有兴致来这？自打成了斗战胜佛，你不是闭关就是神游，连蟠桃会都懒得露面
△孙悟空（撇嘴，双臂抱胸）：俺老孙好歹也是佛门中人，来看看这个把西牛贺洲搅得天翻地覆的小辈，不过分吧
△哪吒（轻笑）：哼，信你才有鬼
△孙悟空（翻个白眼）：爱信不信
【中景】镜头切回斩仙台中央，李天均垂头，肩头微颤
△李天均os：本以为穿越西游世界，拜得名师便能逍遥长生，不曾想百余年就要身死道消，师傅，我可能要辜负您老人家的好意了
△李靖（厉声质问）：李天均，你可知罪
△李天均（抬头，眼神桀骜）：罪？我何罪之有
【中景】净文菩萨衣袂翻飞，面色冷厉
△净文菩萨（怒目而视，字字铿锵）：尔本凡尘飞升之仙，却藐视天庭律法，擅闯阴曹地府，干预轮回大事，罔顾佛法，蔑视西方圣教，于西牛贺洲境内屠戮伽蓝十六座，焚毁佛经三千卷，残害佛门弟子数以千计，此等滔天罪业，人神共愤
△李天均（冷笑，语气愤懑）：那是他们活该！
```

### 看选题：反套路西游同人爽文

1. **绑定经典 IP，降低认知门槛**：依托西游世界观，沿用孙悟空、哪吒、李靖等大众熟知的神话角色，自带 IP 流量与情怀滤镜，能快速让观众代入剧情。

1. **切入反套路视角，制造强冲突**：打破传统西游中 “佛门慈悲” 的固有设定，以凡间飞升仙李天均屠戮佛门败类为核心矛盾，将 “天庭审判” 变为 “伪善正道” 与 “草根正义” 的对峙，颠覆了传统仙神叙事的价值取向，契合当下观众对 “反权威、求真义” 的情绪需求。

1. **叠加转世渊源设定，深化情感联结**：通过昊天镜闪回，将李天均与孙悟空的前世渊源（孩童时期给被压五指山的悟空送食）串联，让简单的审判事件升级为 “故人护短” 的情感羁绊，丰富了故事层次。

### 看人设：角色标签鲜明

1. 核心主角：李天均 —— 反叛型正义仙者

+ 身份是凡间灵气稀薄时代的天纵飞升者，修行仅 200 年却敢挑战佛门权威；

+ 性格上，桀骜不驯且心怀苍生，不认天庭与佛门定义的 “罪”，敢于在斩仙台痛斥佛门僧侣敛财、纵妖害民的虚伪行径，其 “以杀止恶” 的行事准则，是传统仙神秩序的 “叛逆者”，也是底层苍生的 “守护者”。

1. 关键配角：孙悟空 —— 护短重情的佛系斗战胜佛

+ 打破 “成佛后清心寡欲” 的刻板印象，保留了齐天大圣的桀骜与重情特质：前期以吃瓜姿态围观，却因李天均的坦荡发言当众赞赏；后期发现李天均与自己的前世渊源后，瞬间展露护短姿态，甚至以金箍棒威慑净文菩萨，实现了 “佛性” 与 “猴性” 的平衡，成为剧情的关键转折点。

1. 对立反派：净文菩萨 —— 伪善的佛门卫道士

+ 作为核心冲突制造者，其人设标签为 “双标、记仇、维护佛门虚名”：无视门下僧侣的恶行，只揪住李天均屠戮佛门的行为大做文章，甚至要借昊天镜将其形神俱灭，以此维护西方教清誉，是典型的 “伪正义” 反派，精准激发观众的反感与对主角的共情。

1. **辅助配角：功能性极强的诸神群像**

+ 火德星君、水德星君：前者直爽敢言，多次暗讽佛门虚伪，后者沉稳谨慎，形成性格互补，承担 “侧面佐证主角正义” 的功能；

+ 哪吒：自带俏皮属性，既打趣孙悟空的过往，又在关键时刻传讯杨戬，推动剧情走向高潮，同时调节严肃审判的压抑氛围。

### 单元故事：单事件闭环 + 闪回插叙

> 1-10 集为一个完整的**斩仙台审判单元**，整体叙事呈 “主线对峙 + 闪回补渊源” 的交织结构：

1. **主线：斩仙台的正义对峙**

+ 开端（1-2 集）：李天均被押斩仙台，李靖宣读其 “屠戮佛门十六祖” 的罪名，李天均当庭翻供，痛斥佛门败类的恶行，引发诸神议论；

+ 发展（3-4 集）：净文菩萨执意请出昊天镜，欲追溯李天均根脚将其形神俱灭，李靖出面劝阻，孙悟空当众力挺李天均的坦荡；

+ 高潮（5-9 集）：昊天镜启动后，闪回李天均前世与孙悟空的渊源，诸神得知李天均是当年给五指山下悟空送食的孩童后人，孙悟空立场彻底转向护短，净文菩萨陷入被动；

+ 升级（10 集）：净文菩萨仍执意定罪，孙悟空以金箍棒威慑，哪吒传讯杨戬，为单元故事留下强悬念。

1. **闪回线：前世渊源的情感补充**闪回片段（5-9 集）并非独立单元，而是服务于主线的关键伏笔，既解释了孙悟空护短的动机，也让李天均的 “正义底色” 更具合理性 —— 其护苍生的执念，源于前世爷爷（给悟空送食的老者）被强盗所害的经历，实现了 “前世因果” 与 “今生抉择” 的逻辑闭环。

### 总结可以学习的点

1. 选题：借力经典 IP 做创新，降低门槛又造反差

+ **绑定成熟 IP，快速撬动受众**：新人可借鉴其 “西游同人” 的创作思路，依托大众熟知的经典世界观与角色（如孙悟空、哪吒），减少观众的认知成本，同时自带 IP 情怀流量，更容易吸引初始受众。

+ **切入反套路视角，制造强冲突**：打破 IP 固有设定的 “安全区”，如该剧本颠覆 “佛门慈悲” 的传统标签，塑造 “伪善佛门” 与 “正义叛逆仙者” 的对立，新人可通过这种 “反权威、反刻板印象” 的视角，快速打造剧情独特性，契合当下观众的情绪需求。

1. 人设：让角色 “标签鲜明 + 动机落地”，避免扁平

+ 主角塑造要 “有立场 + 有反差”：李天均并非完美圣人，而是 “以杀止恶” 的反叛正义者，既有桀骜不驯的性格标签，又有 “护苍生” 的清晰动机（前世爷爷被恶徒所害）。新人塑造主角时，要赋予其明确的价值立场和可追溯的行为动机，避免 “工具化”。

+ **配角要 “功能化 + 记忆点”**：每个配角都有专属作用和性格记忆点，如孙悟空 “佛性外壳下的猴性护短”、哪吒 “俏皮拱火的氛围调节剂”、净文菩萨 “伪善双标的反派标杆”。新人可给配角分配具体剧情功能（推动冲突、补充信息、调节氛围），再叠加 1-2 个鲜明性格标签，让群像不杂乱。

1. 叙事：小场景 + 插叙伏笔，低成本打造高张力

+ **聚焦核心场景，浓缩戏剧冲突**：1-10 集全程以 “斩仙台” 为核心场景，所有矛盾（审判对峙、诸神站队、渊源揭秘）均在此展开，无需复杂的场景切换，既降低了创作和制作成本，又能让冲突高度集中，新人可学习这种 “单一场景锁冲突” 的写法，避免剧情松散。

+ 用闪回插叙补全伏笔，串联情感与逻辑：通过昊天镜的 “闪回”，自然补全李天均与孙悟空的前世渊源，既解释了孙悟空护短的动机，又让主角 “见恶必杀” 的行事准则有了合理依据。新人可借助这种 “主线对峙 + 插叙补背景” 的结构，在不打乱叙事节奏的前提下，丰富人物层次、埋下情感伏笔。

1. 情绪把控：精准设计 “爽点 + 钩子”，留住观众

+ **每集植入小爽点，持续释放情绪**：从李天均当庭痛斥佛门伪善，到孙悟空当众赞赏其坦荡，再到悟空祭出金箍棒威慑净文菩萨，每集都有 1-2 个能激发观众共情或解压的爽点。新人可在每集设置 “打脸反派、坚守正义、强者护短” 等低成本爽点，维持观众的追更欲望。

+ **钩子要 “层层递进”，制造悬念**：剧情钩子从 “李天均为何杀佛门” 到 “昊天镜会揭露什么秘密”，再到 “孙悟空如何护短”“杨戬入局会带来什么变数”，层层升级，让观众始终保有好奇心。新人设计钩子时，要遵循 “解决一个疑问，抛出新悬念” 的逻辑，避免一次性暴露所有信息。

1. 对话：台词贴合人设，同时推动冲突

+ **台词要 “人设化”**：孙悟空的口语化台词（“嘿嘿嘿，好，说的好”“什么时候轮到你教俺老孙做事”）保留了齐天大圣的桀骜；净文菩萨的台词则充满刻板的伪善（“亵渎佛门者，活该万劫不复”“罪孽岂能相抵”），新人要让角色台词符合其身份和性格，避免 “千人一口”。

+ 台词兼具 “冲突性 + 信息性”：李天均与净文菩萨的对峙台词，既激化了矛盾，又向观众揭露了佛门的恶行；水德星君对昊天镜的解释台词，既补充了世界观，又为后续剧情埋下伏笔。新人撰写台词时，要避免无意义闲聊，让每段对话都承担 “推动冲突” 或 “传递信息” 的作用。
