
# UI 设计技巧

## Social Login 社交登录

社交登录可提高转化率，因为用户可以轻松加入到你的 App。

将社交媒体登录选项放在页面顶部可以提高用户体验和方便性。

对于那些更关注隐私的用户，提供其他选择也是很重要的，比如使用电子邮件和密码进行身份验证。

在保护用户数据和隐私的前提下，为用户提供多种登录选项可以增加用户满意度和使用率。

![](img/db392585b6563e1cde273fa81a38604a.png)

## Design Better Menus 设计更好的菜单

菜单经常有可读性问题。

使它们看起来和功能更好的快速技巧是在每个操作旁边添加一个图标。通过这种方式，你可以帮助用户直观地识别操作，而无需阅读整个文案。

此外，如果适用于菜单的用例，突出显示活动选项卡也是一个好习惯。

![](img/210cdb2cb598546a579057c30aae52aa.png)

## The Gutenberg Principle 古腾堡原则

古腾堡原则（又称 Z 型布局）是指，用户的视线从左上角区域到右下角区域按照 Z 形路径移动。

将你的 CTA（Call to Action） 放在此流程的未尾以引导用户采取行动是一种很好的做法。

![](img/0ecd84b8c8b8f03ea2664f9d1ca67d1a.png)

## 不再强调危险的行动

在产品设计中，要淡化删除等危险操作，让危险的操作看起来更像是次要动作。

始終尝试淡化删除等危险操作。

+ 你必须优先考虑默认操作，而不是危险/不可逆的操作。

+ 使用多个特征使元素看起来像次要动作：颜色（更浅）、大小（更小）、类型（不一样的类型）、位置（视觉上不重要的位置）等。

![](img/e9e63d4b2a1b04c6381fc50135a4f4e2.png)

## Delete Model 删除模态

注意按钮的文案，避免通用的脱离上下文的文案，例如“是”或“否”。

相反，请使用一句话来清楚地传达按钮的操作。

![](img/e6c72e83918862f0379550561d290ec8.png)

## Validate Deletion 确认删除

绝不允许用户在未经确认的情况下删除某些内容。

人们总是误点击，丢失信息会永远伤害并造成与你的产品相关的糟糕记忆！

确保你的 UI 支持（内联或弹出） 删除验证。

即使是撤销功能在这些情况下也很有用，尽管有时由于工程限制而无法实现。

![](img/fa1eb758d5f6c137c87ae9c603dc01e5.png)

## Align Uneven Elements 对齐不均匀的元素

在许多情况下，你必须对齐尺寸不均匀的元素。

即使你将元素之间的间距设置为相同，视觉效果也似乎不对。

解决此视觉问题的最佳方法是为所有元素设置相同的宽度。

提示：选择最大元素的宽度井将其应用手所有其他项目。

![](img/e64d8e6d8d5dce72b0af0ed93f4001cd.png)

## Always Have a CTA 始终只有一个 CTA

在你网站的首屏部分始终只有一个 CTA 按钮，你产品的许多访问者可能永远不会向下滚动着陆页。

因此，你需要为他们提供立即转换的选项。

![](img/7c0fb4c4c90f0426daea087bfc31a92c.png)

## The Perfect Header 完美的标题

> 一个好的标题需要将注意力放在标题上，然后将读者引导到描述中，描述必须是可读

实现此层次结构的一些快速技巧包括：

1. 标题的字体粗细更强；

1. 一致的类型比例系统。最常见的是 x1.25，也就是说如果标题是 40px，副标题就必须是 40/1.25= 32px。

1. 降低字幕的对比度；

1. 描述文本的适当行高；

1. 左对齐，提高可读性；

![](img/b21d46139936ad507d73478f0036b775.png)

## Empty State With Templates 带模板的空状态

使用模板升级你的 UI 空状态！

与其让人们从头开始创建内容，不如让他们的生活更轻松。

使用预制模板帮助他们更快地体验你产品的价值，同时提高你的产品使用率。

![](img/c353899acd340ca8626cf9526dc04593.png)

## Inform Users Beforehand 事先告知用户

永远不要让用户猜测你的用户旅程的下一步是什么。

请记住，转化率可能很低，因为人们害怕按下按钮。

强烈的信息（如“预订”） 会增加压力，并让人们怀疑他们是否会被收费。

![](img/ea4ec6d307a8e4f73bbfb7a6e72aeb97.png)

## 透明头像的一致性设计 1

许多平台（如 Twitter）允许 PNG 头像，这会导致 UI 不一致。

为避免此问题，请为与应用程序背景相同的头像添加微妙的边框和背景颜色。

![](img/4fb95a6ab6c64d09b8b0ef3d09428205.png)

## 透明头像的一致性设计 2

另一个是，确保透明头像一致性的视觉技巧是在它们周围添加一个微妙的边框，与背景颜色相同。

边框看起来像是背景的一部分，并将其与封面部分区分开来。

![](img/69b8ab9aa42f9f854456027db4035e9b.png)

## 一致的边界半径

当圆形图像包含在具有小边框半径的卡片中时，它们通常看起来很奇怪。

使用简单的经验法则：

+ `Outer Radius` = 2 `*` `Inner Radius`

精确的公式比较复杂，因为你需要考虑到两个边框之间的间距，所以让我们简单点！

![](img/381020dd94f748103b757480d6e71914.png)

## 如何应用品牌颜色

颜色是任何用户界面的核心元素。

UI 设计中最常见的错误之一是品牌颜色的过度使用。

通过仅使用原色突出显示界面中最重要的元素来避免这种情况。对于其余元素，结合主色的色调和阴影。

![](img/2ad673cbe0f87036103c8da40687c32a.png)

## 区分选定的项目

始终确保用户选择的项目一目了然。

更改背景颜色是实现它的一种简单易行的方法！

它使用户体验更好，因为用户可以轻松找出已经选择了哪些元素。

![](img/3595b51a32fd275c324ab0e44d809dd9.png)

## 使用更好的链接按钮

链接很重要，你需要善待它们的外观。

很多时候，按钮比链接效果更好。

特别是当链接不在文章的页眉、页脚或正文中时。

始终使文案具有可操作性，并暗示他们发起的行动。

![](img/7544ed4eda02debbb42feb5a577f6e8e.png)

## 用媒体引导用户注意力

利用视觉效果来引导用户的注意力，人们倾向于跟随另一个人的视线。

利用这种效果，提示人们关注单个元素（A）或滚动（B）。

![](img/4c9712108f0940f8a573a8e0501e963f.png)

## Permpt User to Scroll 提示用户滚动

你的产品需要提示用户滚动以更好地传达产品的价值。

特别是当标题内容不足以描述产品价值时。

提示用户滚动的一个简单技巧是向他们展示下一模块的一部分。

这样，用户就会知道网站上有更多信息，并且会好奇地进一步探索。

![](img/6b110f92c2c619f9eb3851e92b98fa72.png)

## 突出强调最佳价格

始终突出最佳定价计划并使其弹出。

通过这种方式，可以帮助用户确定最常用的计划并宣传产品的最高报价。

要突出计划，请使用多种设计方式，例如颜色、大小、高度、阴影！

![](img/33501d8d8f3f5d2b2ec7f442774cca6f.png)

## 避免全宽段落的出现

长行会使用户感到厌烦并产生可读性问题。

通过将线条的宽度限制在 500 像素和 700 像素之问来解决这个问题。

除了像素，你还可以限制每行的字符数。

在 CSS 中，使用`ch`单位很容易设置： `10ch` is x10 times the width of the character 0

![](img/aec7e81e27c8e59bdb0c7b12a2f70d58.png)

## 使卡片看起来可以点击

在许多情况下，卡片无法表明它们是可点击的。

设计师省略了 CTA 按钮，只依赖于用户的体验或/和悬停效果。

在设计中，永远不要让用户想象任何东西，这始终是一个好习惯，而是使用可操作按钮来提示可点击性并描述操作。

![](img/e64fce99d62d8008fd78b61351ccbf99.png)

## 让输入的内容不言而喻

增强输入字段的两个“秘密”武器是占位符文本及其类型。

1. 利用占位符文本来指导用户，而不是仅仅重复标签。

1. 通过为常用输入使用预定义值来限制错误的输入源（例如添加国家代码）。

![](img/be8c2410926401ce3b7b8fa7491f0645.png)

## 选择正确的元素

让用户输入他们的信息尽可能简单。

选择正确的 U 元素在升级 UX 中起着重要作用。

例如，使用数宇选择器来输入整数数值而不是通用文本字段。

在电子商务购物车中，大多数用户最多会购买 1 或 2 件商品。-/+ 按钮使他们的输入过程更快。

![](img/91377c295a67b2c40be863b41d911d85.png)

## 增强层次结构

视觉层次在设计中很重要，因为它可以提升用户体验井引起用户注意。首要任务是突出主要行动 （又名 CTA）。

1. 在这种情况下，启动预订流程的按钮是主要的 CTA。

1. 然后需要使文本可读并区分元素类型。例如标签不得看起来像主按钮。

1. 使用文本属性 （粗细、大小、行高） 来破解视觉注意力和层次结构。

![](img/2b59df42026e5aa63ba72ab5831fdeb1.png)

## 让工具提示具有响应性

一旦用户将鼠标悬停在元素上，就会激活经典的工具提示… 但是移动设备不支持悬停效果。

要解决这个问题，请在按钮旁边添加一个可点击的帮助图标。当移动用户点击图标时，显示补充工具提示文本。

![](img/3a7195be717157141b1f44fff3cc72e8.png)

## 谨慎地选择图表类型

折线图可能看起来更时尚，但井不适用于所有情况。

当 x 轴的选项有限时，条形图是最合适的图形类型。

另外，折线图可能会引入错误的中间值。

对于具体示例，假设只有每月订单总数（不是个别天数）的数据

折线图让数据看起来是每天的，这是不正确的！

![](img/ed84cd530ace6e956f67799bae68a751.png)

## 支持带有标签的图标

由于不同的人的经验水平甚至他们的文化，圈标经常会使用户感到困惑或被误解。

解决此可访问性问题的方法是在图标附近添加一个微妙的文本标签，以描述其用法。

请牢记此信息，尤其是对于不支持悬停效果的移动界面。

![](img/d0efe3dae7810ab2f414569271e0d3b7.png)

## Use Labels Cleverly 巧妙的使用标签

标签的一个智能用例是在具有预定义值的颜色选择器上。

根据应用程序的上下文，你甚至可以省略标签。考虑将它们留给那些难以识别颜色的色盲人士。

![](img/df98dce09daf97565db2a19125f4c7ae.png)

## 显示有用的快捷方式

键盘快捷键可提高工作效率并为高级用户节省时间。

然而，有时很难记佳它们。

利用 Fitts 定律：将快捷键放在操作按钮旁边。

这样，用户就不需要记住操作。获取目标的时间是到目标的距离和大小的函数。

![](img/7fc0a687934ecf6b2b12d092a9def8a6.png)

## User Hate Surprises 用户讨厌的惊喜

通过简单的 UX 复制调整，你可以避免误解并提升你的产品体验。这是语音消息应用程序 Yac 的真实示例。

我真的花了 30 分钟想知道该应用程序是否会自动发布我的声音频道中的消息或让我先听并编辑它。

最后，我将其录制在手机上，然后用录制的消息点击“录制”按钮。

一个微小的细节会带来如此多的摩擦！

![](img/6fe4256749f7dcfe4234ec0c669320ea.png)

## Prioritize UX 优先考虑用户体验

Instagram 最近推出了商店。

将其放置在“活动”选项卡的位置的决定并不是随机的…

1. 更容易到达，因为它在拇指区

1. 更多意外点击 bc 用户将到达活动选项卡

这可能会带来更好的转化，但会使用户体验变差 10 倍。

让 10 个用户恼怒比多得到一个客户更糟糕。

![](img/77b25579efb5a27be2f682a94ae8f031.png)

## 破解视觉层次结构

用这些简单的技巧破解视觉层次：

+ 降低次要信息的不透明度

+ 使用粗体字重来强调

+ 按固定比例缩放标题的大小（例如 x1.25）

+ 将元素排列到左側 （对于 LTR 用户）

+ 将相关元素组合在一起

![](img/949f72a368052a90bf69e286c95d0319.png)

## 视觉上分离的元素

更喜欢用空格在视觉上分隔菜单部分。空白使 UI 看起来更干净，并要求用户减少认知工作。

在下面的示例中：

+ A 对所有东西都使用分隔线

+ B 在部分之间使用分隔线

+ C 只使用空格

A 过于复杂并且会分散用户的注意力，但是 B 和 C 都可以用于现实生活中的用户界面。

B 更注重区段的区分。C 使用户界面看起来更干净。

![](img/0f8a819c69d8dda3b78703796b526b2d.png)
