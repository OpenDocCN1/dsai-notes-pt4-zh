### 最近观察和思考

**1**

**2**

在工作沟通上，可能邮件往来比 IM 工具更合理。

IM 工具更便利，同时也意味着反复，比如老板、PM、开发反复，以及沟通成本的增加。

如果是 邮件往来，反而会促使对方更专注，尽量减少错误。无论是产品写文档，还是开发写代码，邮件往来次数不能太多，就会逼着对方多次检查、进而减少错误。

+   在人人都在讲故事的时代 用产品说话 已经是稀缺诚实

有两句话要**刻在石头**上，**问题是不可避免的**，**问题是可以解决的**。

终点不是 AGI，而 AGI 可能是一个方向。

过去一年（2024 年），在你脑海中最重要的几件事是什么？有哪些 AI 范式级的变化。

1.  长思考的推理模型，比如 GPT-o1，核心是反思能力与自我反思（不与外界发生交互）。即模型不断产生新的假设，不断自我验证对错与否，重复以上「假设-验证」过程。

1.  多轮 Agent 强化学习的 Agentic 模型（与外界发生很多交互），比如边思考边操作（比如调用搜索、使用浏览器、写代码），通过多轮操作的方式解决一个问题。

**Ag**e**nt** 最重要能力是「通用性」，多轮和工具。让 AI 去训练 AI，Benchmark 不够好，没有好的观测。

L1-L5 可能不是线性的。

有概率的非共识：**如何提升 Agent 的泛化。**
