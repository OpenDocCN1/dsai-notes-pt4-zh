## 最近经历

### 生活

距离 2023 年结束，还有不到 60 天。

真的是“时光如梭，物是人非”。还记得高中刚开始的时候还用这句写作文开头，之前感受不深，可现在是切切实实感受到了。

**距 2023 年结束，还有**

最近，时常会想到，当时选择离开的动机。可能不一定是最好的选择，但一定是当下正确的选择。

最初是和阿珂聊了很多，虽有略微影响，但没有下决心。让我下决定的是看乔帮主在斯坦福的演讲，他提到「如果今天是你生命的最后一天，你还会做你现在做的事情吗？」

我认真的想了两天，不会！

既然如此，那就去做想做的事情。和家属聊之后，获得了支持；再和 Ld 聊之后，然后就报备了。

为什么是两天？因为在判断原因和结果推演。

给自己两天时间去思考判断本质原因，判断**自己是在逃避现实，还是说**真的有其他考虑。热头脑思考，冷头脑决策。让自己冷静下来，才能做出理性的合理决策。

第一，从更多可能出发的话，理论上 Gap 会有更多可能。更多的输入、写作输出，学代码、尝试开发 App 等等，都是可能。

第二，重要的是在场。关于 AIGC 这么久，不能只是看别人做事情。虽然和大佬（归藏、张无常、马丁等）还是有一些差距，但我相信，持续保证每次进步一点点，就能滚出巨大的雪球。

第三，本就一无所有，还有什么好失去的呢？更何况，对比以往，我开始更加在乎时间了。

## 最近观察和思考

**产品定位不同，策略不同。**

想到之前做调研的时候，奶牛快传的 Web 页账号登录。

不只是能做到那么简单，本质原因是产品定位问题。奶牛快传的定位是，尽快让用户取到文件，至于用户登录不登录，不重要。

举个例子，两个 App 有同样的功能。第一个 App 的北极星指标是关注有多少注册用户，而另一个 App 的北极星指标是每天的使用频次。

明显后者更合理，毕竟若使用频次无提升，即便有再多的注册用户，也无济于事。 #自省

**看人不能止于表面。**

一个人是被其生存处境、生存模式塑造的，优点、弱点。

笨小孩，通过努力变优秀得到正反馈，然后持续希望自己变优秀。只让别人看到自己好的、优秀的一面，这样才能获得更多的安全感。但这样的模式下，只会自己回避自己的缺点，很难发现和审视自己的缺点。 #自省

### 书籍

《金翼：一个中国家族的史记》

> 作者林耀华：人类学家、社会学家和民族学家

讲述两个家族成员的两种适应生活的方式：一种是固守传统，依靠祖传田产为生；另一种是接受现代教育和基督教思想的影响。

尤其是文中对家庭以及家庭成员的行为描述简直细致入微，让我想到了之前看电影《Avatar 2 》中的一句：“萨利之家共进退”。“家庭”这个无形的纽带，使小图克可以无畏困难选择折返救家人。

最后，再次感谢书中提供的“谱系表”（不用我自己再写一遍了）。

**以下是部分摘录：**

+   事实上，我们的生活可以简练地勾绘出来。日常交往的圈子好比一个由竹竿构成的保持微妙平衡的网络，用橡皮带紧紧地绑在一起。当太用力地拉动其中一条带子以致断裂时，整个网络就会混乱崩溃。每一根紧紧相连的竹竿就好比生活中与我们相关的一个人，将其中任何一根完全抽离，我们都会混乱、痛苦，直至崩溃，而所有的结点都会暂时松弛。

+   命运就是人际关系和人的再调适。

+   切换环境，不同的环境会认识不同的人，更会拓宽你对外界的认识与联系。

+   生意上的成功让长辈们认为他是前程远大的人。【谁有钱有权，谁就是对】

+   你和朋友的关系好，不代表你孩子和朋友的孩子还能好。

+   真金不怕火炼，玉不琢不成器。同样，人在克服危机之后更强大。

+   因为自己经历过许多艰难险阻，所以意识到让孩子接受教育是多么重要。

+   在为财富奋斗的过程中，身边的其他人总是会犯“红眼病”。

1.  《普罗米修斯》｜一般

科幻电影，一部关于科学家、资本家、雇佣军的冒险旅程，关于人类起源和外星生命的探索。

这些人各自心怀鬼胎，有人是为了解开人类起源的谜团、有人为了长生不老、还有人选择牺牲自己而拯救全人类。

给足了我们想象的空间，为什么有高级智能生物？为什么要造出可以杀人的生命体？为什么好不容易寻找到的高级智能生物想要毁掉地球、毁掉全人类？

1.  《幸福终点站（The Terminal）》｜推荐

+   有人的地方就会有规则，有人的地方也能打破规则。

剧中有很多没用的、能够进入美国领土的小技巧，不过我相信这些已经过时且无用了，哈哈。

电影的核心是要探讨我们应如何面对生活中的等待和不确定性，于我而言，这更像是一个成长故事。我们迷茫，但也努力通过学习技能的方式，在充满变数的人生中，为自己寻求更好的生活。

在不确定的生活里，尝试、努力寻找那一丝确定性，即便一无所依、一无所靠。

1.  《终极面试》｜推荐

+   主动性、观察力、相互作用。

+   我们只看见我们想看见的。

+   懂得倾听、注重细节、有同情心。

剧情是一家实力雄厚且神秘的生物制药公司的公开招聘，目的是招聘一位 CEO 助理（因为 CEO 是完完全全的 I 人）。

8 个候选人被带到一个全封闭的房间「群面」，一人一支笔、一张试卷（纸），要求是在 80 分钟内，寻找到他们给出的问题并解决。还有三条规则，第一，不能与警卫和考官说话；第二，不能损坏试卷；第三，不能离开房间。

80 分钟，对人性的考察：8 个人从主动发起合作到陷害他人，有人为达目的不择手段。

再结合范冰前两天发的[关于职场的推](https://x.com/XDash/status/1717121213250838686?s=20)，真就职场现状了。
