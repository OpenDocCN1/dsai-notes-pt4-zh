
# 读《箭术与禅心》后记：专注与体验

> #读书笔记 #禅宗 #哲学
>
> 关于禅宗的书，强调**”心“和”无我“**，即专注和体验。

+ “心”，指心灵的集中、内在的平静。强调专注，专注到像呼吸一样自然，专注到像湖水一般平静。

+ “无我”，指一种类似于超越自我意识的状态。强调体验，不可言传，亦无法言传。

写到这里，不由想到由王晶导演、由李连杰与洪金宝主演的电影《倚天屠龙记之魔教教主》末尾的一个片段。

张三丰（洪金宝）对着李连杰（张无忌）说，“太极拳，重其义，不重其招。你忘记所有的招式，就练成了太极拳。”

由此，专注学习一招一式（体验），然后忘记所有招式（无我，内化于心），便是太极拳的奥秘所在。

以及，可以和生活中很多地方关联起来，比如读书，常听人说，“读书者，先将书读薄，再将书读厚。”

“把书读薄”，就是梳理脉络、理解主旨与核心观点，而“将书读厚”，便是抽丝剥茧，与自身体系关联。如此，才能内化于心，从而学以致用。

## 摘录

正确的呼吸与深沉的专注。无我、无所求，这种专注的感觉也越强烈。

以行动来直接切入禅的精神。禅是活生生的体验，不存在于任何言语文字中。

如果一个人真心希望成为某一项艺术的大师，仅靠技术性的知识是不够的。必须要使技巧发自于无意识之中。

佛教中的禅宗，它完全不是一种推论出来的结论，而是一种直接的体验。

只有那冥思的人，完全达到空灵无我的境界，才能与那「超然的实体」合而为一。

正确的呼吸。吸气之后要轻轻地把气向下压，让腹肌紧绷，忍住气一会儿，然后再尽量缓慢平均地吐气，停顿一会儿，再快吸一口气─就这样不停地吸进呼出，自然形成一种韵律。

如果一开始就教你技巧，他就无法使你信服这种方法的决定性重要，你必须以自己的努力去遭受挫败，你才会准备好抓住他抛给你的救生圈。

因为你不肯放开你自己。你没有等待完成，却准备迎接失败。

真正的阻碍，是你用心太切。越是执着于目标，越无法成功，目标也会越来越远。要学习正确地等待。

坐下前就开始「收心」，心神集中于一会要做的事情。

他只能像个早上醒来的人考虑一天的计划，而不是一个得到开悟的人在本然状态中生存与行动。

一旦你真正成为无我时，你可以在任何时候中断。努力练习这个吧！
