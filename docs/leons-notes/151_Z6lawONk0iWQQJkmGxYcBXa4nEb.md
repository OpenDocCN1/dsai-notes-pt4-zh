# 读《卓有成效的管理者》后记：如何更好的自我管理

> 来源：[https://leonzhang.feishu.cn/docx/WQhmdtMKcoiE8fxMBRTcYs98nEd](https://leonzhang.feishu.cn/docx/WQhmdtMKcoiE8fxMBRTcYs98nEd)

> #管理 #目标导向 #决策

> 管理者及知识工作者应该如何更好的自我管理，以及为什么必须卓有成效，才能创造最大价值。

> 那么，如何创造最大价值呢？

1.  以目标为导向，明确组织目标，做好关键决策并将其分解为可执行的任务；

1.  重视时间管理，有效利用时间，集中精力完成最重要的工作；

1.  用人唯贤，无需事必躬亲，充分发挥下属的积极性和创造性；

1.  思虑周全，注重沟通，有效地与他人沟通，达成共识；

1.  持续学习，不断更新知识和技能，适应变化的环境。

在“效能”（doing the right things）与“效率”（doing things right）的观点上，德鲁克和段永平的看法相同。德鲁克的认为“效能”比“效率”更为重要，管理者应该关注做正确的事，而不仅仅是提高工作效率。段永平的观点是，做正确的事情胜过正确的做事情。

在“做正确的事”与“正确的做事情”中，核心区别在于前者更关注目标、战略和方向，而后者更关注操作、执行和效率。前者强调在选择和规划阶段明确正确的方向，而后者注重在实施阶段采取正确的行动。

两者观点的趋同可归因于对市场经济、商业实践和社会因素的共同影响。管理受这些因素影响，而投资则依赖于高效管理和商业实践带来的经济结果，这也是两者观点趋同的原因之一。

所以，无论是德鲁克的管理理论还是段永平的投资理论，两者核心关注的都是战略性的决策，关注的是公司背后的目标、战略和方向。错误的方向必然会产生不必要的资源消耗，虽不至于说一定与最终结果截然不同，但不可否认的是迈出的每一步都有可能是弯路，而这也突显了关键决策的重要性。

## 摘录

+   德鲁克认为人性是不完美的，因此人所创造的一切事物，包括人设计的社会也不可能完美。

+   1999 年 1 月 18 日，90 岁高龄的德鲁克回答“我最重要的贡献是什么”这个问题时，他写道：我着眼于人和权利、价值观、结构和规范去研究管理学，而在所有这些之上，我聚焦于“责任”，那意味着我时把管理学当作一门真正的“博雅技艺”来看待的。

+   管理所关心的是行动和应用，而成果正是对管理的考验。而且管理深深触及着一些精神层面关切的问题，像人性的善与恶。

+   当你不能找到好的研究灵感时，可以去翻翻德鲁克的著作；当你对企业实践困惑不解时，也可以把先生的著作放在床头。一个高效的组织，如果缺乏有效的管理者和员工，组织的效率也不可能得到实现。

+   一个有责任心的工作者应该能去到他自己，能设立较高的绩效标准，并且能控制、衡量并指导自己的绩效。首先，卓有成效的管理者必须能自如地掌控他们自己的想法、情绪和行动。即内在意愿在先，外在成效在后。

+   管理者应该学会的三门课。第一，必须学会对自己负责。第二，更重要的是向上看，而不是向下看。管理上司比管理下属更重要。所以要问自己，“我应该为组织贡献什么？”第三，必须休息修习基本的素养。

### **卓有成效是可以学会的**

+   智力、想象力及知识，都是我们重要的资源。

+   “体力工作”重视“效率”，通常用数量和质量来衡量。而“效率”，是指“把事情做对”的能力，而不是“做对的事情”的能力。

+   知识工作者必须进行自我管理。工作动力取决于是否具有有效性及他在工作中能够有所成就。如果工作缺少有效性，那么他对做好工作和做出贡献的热情将会很快消退，他将成为朝九晚五在办公室消磨时间的人。

+   衡量知识工作主要应看其结果，不能用数量来衡量，也不能用成本来衡量。

知行合一。再伟大的智慧，如果不能应用在行动上，也将只是毫无意义的资料。

+   每一位管理者都要面对的现实是，一方面要求他们具有有效性，一方面却又使他们很难达成有效性。影响因素有：第一，时间经常被他人打断；第二，被迫忙于“日常运作”；第三，本身处在一个“组织”中；第四，受到组织的局限。

+   若想提高管理者的绩效和成就，唯一办法就是提高有效性。 有效性是一种后天的习惯，是一种实践的综合。最伟大的钢琴家，如果不肯辛勤演练，也一定无法演奏莫扎特的曲子。

+   成为卓有成效的管理者，在思想上必须养成习惯。

- 第一，知道时间应该用在哪里。

- 第二，重视对外界的贡献，为成果而工作。

- 第三，善于利用长处，不止自己，还有上司/同事/下属的长处等。

- 第四，集中精力于少数重要的领域。重要的事先做，不重要的事放一放，甚至不做。

- 第五，善于做有效的决策。重视正确的战略，而非令人眼花缭乱的战术。

### 掌握自己的时间

有效的管理者会优先从**时间安排**上着手，清楚自己的时间应该用在什么地方，而非工作或工作计划，因为时间是一项限制因素。时间也是最特殊的一项资源。时间的供给，丝毫没有弹性，也完全没有替代品，而且是做事情必备一个条件。

有效的管理者于其他人最大的区别，就是他们非常珍惜自己的时间。 集中时间，短时高效地做一件事情。如果将时间分割开来使用，纵然总时间相同，结果时间也肯定不够。

有效性的基础：第一，记录时间；第二，管理时间；第三，统一安排时间。

+   第一，记录时间需处理某一工作当时记录，不能事后凭记忆补记。时间控制和管理非一劳永逸，必须持之以恒。（每天记录，连续三四周为一个时段，一年内记录两三个时段。)

+   第二，有系统的时间管理，减少不必要的工作。

- 第一，找出「不必做，做了也浪费时间」的事情。问自己“这件事如果不做，会有什么后果？”如果没有任何影响，就该立刻取消。

- 第二，哪些活动可以由他人代自己参加而不影响效果？

- 第三，自己是否有在浪费别人的时间？比如，是否是高效地开会。

时间是最稀有的资源。分析自己的时间，也是系统地分析自己的工作，鉴别工作重要性的一种方法。

### **我能贡献什么**

**重视贡献是有效性的关键**：重视贡献，就是重视有效性。

+   重视结果的人，其所作所为可能会与其他人截然不同。对知识工作者来说，更需要重视贡献。

+   所谓“通才”，就是一位能将其所专的一个小领域与其他广大知识领域联系的专家。

+   重视贡献，能够让你在一团乱麻似的事务中理出轻重缓急来。

+   有效的人际关系，需着眼于贡献：互相沟通、团队合作、自我发展、培养他人 。

+   个人能否有所发展，很大程度上要看是否重视贡献（/结果）。

**高效会议**

+   事前想清楚会议目的，目的是什么或应该是什么，应该提前准备什么。

+   自问：“为什么要召开这次会议？为了某项决策？为了宣布什么？还是澄清应该做些什么？

### **如何发挥人的长处**

+   为实现目标，必须用人所长——用其同事、上级、本身之所长，可以给自己带来真正的机会。

+   任何人都必定有很多缺点和短处，而缺点和短处几乎是不可能改变的，使其不发生作用即可。用人决策，不在于如何克服人的短处，而在于如何发挥人的长处。

由于日本“终身雇佣”制的存在，反而让日本企业的管理者可以不参考人的缺点，从而根据下属的能力来发掘和选拔能做事的人。

+   古来许多军事名将，几乎没人不是以自我为中心，自高自傲的人物，（但是反之却不尽然，自高自傲者未必能成为名将）。同样的，人要向上，必须有大志，自视甚高，以天下为己任（同样地，反之也未必尽然）。

+   任何一项人事任命都是一个赌注，打仗也是如此。抓住人的长处，至少是合理的赌注。用人所长是管理者必须具备的一种素质，是一个组织工作是否有效的关键，也是知识工作者和社会不可或缺的素质。

+   凡是成功而升迁得快的主管，其下属也是最容易成功的。反之，如果上级主管的能力不够，下属通常是无法爬升上去的。有效的管理者常自问：“我的上司究竟能做好什么？他曾有过什么成就？要使他发挥他的长处，他还需要知道些什么？他需要我完成什么？”至于上司不能做些什么，那就不必细究了。

+   俗语说：“观人易，察己难。”

### **要事优先**

+   卓有成效如果有什么秘诀的话，那就是善于集中精力。且总是把重要的事情放在前面先做，而且一次只做好一件事。

+   低估了完成一件任务所需要的时间。———这个经常遇到。

+   需要做的事情很多，但时间有限，并且更需要“整块时间”。在一段时间内集中精力，努力干好一件事。

+   第一项原则，摆脱不再有价值的过去。今天是昨天所做决策和所采取行动的结果。

+   第二项原则，先后次序（优先级）的考虑。

**帮助确定优先次序的重要原则**：重将来而不重过去；重视机会，不能只看到困难；选择自己的方向，而不盲从；目标要高，要有新意，不能只求安全和容易。

### **决策的要素**

+   有效的决策，是一套系统化的程序，有明确的要素和一定的步骤。

+   决策的五点特征：

+   第一，了解问题的实质，如果问题是经常性的，需要通过建立规则或原则的决策才能解决。

+   真正经常性的问题；某一特殊情况下偶然发生，但是一项经常性问题；真正偶发的特殊事件；首次出现的“经常事件”。

+   第二，找出解决问题时必须满足的界限，即找出问题的“边界”条件。

+   第三，认真思考解决问题的正确方案是什么，以及方案必须的条件，必要的妥协、适应及让步事项。

+   第四，决策方案要同时兼顾执行措施，让决策变成可以被贯彻的行动。

+   第五，执行过程中重视反馈，以印证决策的正确性及有效性。

+   **有效的决策人常需花费不少时间来确定问题的属性。如果问**题的属性判断错了，其决策必为错误的决策。

+   常犯的四个错误：

+   第一，没有了解问题症结所在，对问题缺乏经常性的认识和原则。

+   第二，误将真正的新问题视为旧病复发，因而仍用旧原则。

+   第三，对某些根本性问题的界定似是而非。

+   第四，看到问题的部分，而没有看清全貌。“一知半解”有时比“全然不知”更为可怕。

+   **决策的五个要素**：

+   第一，先从最高层次的观念方面去寻求解决方法。

+   第二，确认决策应遵循的规范，决策的目标是什么？最低应该达成什么目的？应该满足什么条件。边界条件越清楚，做出的决策越有效，越能达成决策的目的。

+   第三，是研究“正确”的决策是什么，而不是研究“能为人接受”的决策是什么。

+   第四，化决策为行动。将行动的承诺纳入决策中，否则便是纸上谈兵。

+   第五，应在决策中建立一项信息反馈制度，以便经常对决策所预期的成果做实际的印证。若想了解赖以做出决策的前提是否仍然有效，或者是否已经过时，亲自检查才最为可靠。而且，这种前提迟早是要过时的，因为现实绝不会一成不变。

+   决策者也常常要留意是否有非常事件出现。他一定经常自问：“这一解释能说明某些事件吗？能说明所有同类的事件吗？”问题的解答后，还可能引发什么结果？最后，当出现了别的非常事件时，当出现了他的解答所不能解释的事件时，或者当发生的结果竟与预期不符时，他又回过头来重新检讨原来的问题。

+   优秀的人也不全是对的，对的人也不一直都是对的。福特曾洞察到人们诉求，“一匹更快的马”是个错误需求。同样，他也坚信自己开发的“T 型”车必将是永远受欢迎的车型。 #Resource/分享/素材

+   我做什么事情，才会让我在职场上比别人更有竞争力？我能做出什么贡献？#Core/Thinking/Question

+   组织和 Leader 期望我有怎样的贡献呢？做些什么？才能使自己的知识和能力得到最大的发挥。

+   谁需要我的产出，并使它产生效益？

### **有效的决策**

+   决策是一种判断，是若干项方案中的选择。所谓“选择”，通常不是“对”与“错”之间的选择，最多只是“大概是对的”与“也许是错的”之间的选择。而绝大多数的选择，都是任何一项方案均不一定优于其他方案时的选择。

+   决策的过程往往先从其本人“见解”（尚未证实的假设）开始的，若见解不能获得证实，就毫无价值可言。有效的决策人通常必先假定传统的衡量方法并非适当的衡量方法。

+   如何做正确的决策，**最好的办法就是仿效法院的判案方案，从两方的辩论中求取事实**真相，尽量使相关的事实都能摆在我们面前。

+   为什么必须要有反面意见，主要有三项理由：

+   第一，唯有反面意见，才能保护决策者不致沦为组织的俘虏。

+   第二，反面意见本身，正是决策所需的“另一方案”。

+   **第三，是反面意见可以激发想象力。想象**力需要被激发后才能充分发挥出来，否则它只能是一种潜在的、尚未开发的能力。

+   多个选择，对比之间可能会有什么收获和风险，不做又可能有什么损失。

+   如果利益远大于成本及风险，就该行动。

+   行动或不行动，切忌只做一半或折中。

+   有效的决策者不会等得太久，也许一两天，最多一两个星期。只要“守护神”不在他耳朵边，他便会尽快行动。

### **管理者必须卓有成效**

+   如何做到卓有成效。

+   第一步，记录好时间的使用情况，分析时间记录并改进。

+   第二步，把眼光集中在贡献上。

+   第三步，充分发挥人的长处。

+   第四步，要事优先，掌握自己的时间。

+   第五步，有效的决策，合理的行动。有效的决策，固然有赖于一定的步骤、分析的能力；有效的决策，本质上是一种行动的规范。

+   管理者的自我提高往往要比卓有成效的训练更为重要。
