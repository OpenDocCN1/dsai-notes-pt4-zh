# 读《商业的本质和互联网》后记：商业的本质是增长

> #读书笔记 #商业

> 商业的本质是增长，互联网只是一种工具，没有改变商业的本质。

书中大量引用了德鲁克、约瑟夫·熊彼特的思路，运用经济学原理分析与互联网相关的商业模式，试图验证一些“基本且众所周知的法则”，为研究创新的方法论提供案例。

### 摘录

约瑟夫·熊彼特认为：创新是对现有经济与行业格局的破坏，即”创造性毁灭“。

乔布斯，一个以自我为中心的创新者，毕生奋斗的目标是“在雨中留下一点痕迹。”

“我记得（年轻时）花了很多时间仔细阅读书籍和杂志。” 拉里·佩奇持续更新自己的知识，以“活到老，学到老”勉励自己。

单位成本=总成本（固定成本+可变成本）/产量

固定成本并非一成不变。影响固定成本的主要不是时间，而是产量和设计产能（ 比如要新增加产品线）。

这个世界上失败的并购远远多于成功的。

国画大师齐白石曾对弟子说：“学我者生，似我者死。”商业之道与艺术相遇。

孙子兵法有云：知己知彼，百战不殆；不知彼而知己，一胜一负；不知彼，不知己，每战必殆。

经济学可以支持企业在战略、策略和商业三个层面上的决策。

**德**鲁克指出，创新的高风险其实是个错觉，产生错觉的原因是企业家“缺乏方法论，违背了基本且众所周知的法则。”

为客户创造价值。资本回报率才是判别公司效率的关键指标。
