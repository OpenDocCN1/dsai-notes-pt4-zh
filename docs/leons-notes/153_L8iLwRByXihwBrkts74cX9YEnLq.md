
# KK 的《5000 天后的世界》｜摘录

> 来源：`https://leonzhang.feishu.cn/docx/KI3vdnyU6oGamqx2YmYc0ncangf`
> 作者：KK（凯文·凯利）

AI 将成为社会中的重要组成部分，融入并影响着我们的生活。在食品、交通、能源、教育等产业帮助我们解决一些当前无法解决的事情。

书中也提到，我们个人如何提前建立能够匹配未来的能力，也很多。比如“活到老，学到老”、“依靠数据判断未来“、”正确认识自己“、”保持适应能力与学习能力“、“不断挑战自己，不断学习新鲜事物”...

### 部分摘录（有修改）

+ 凯文·凯利这样的预言家，他的诀窍是“倾听科技”，活到老学到老。
+ 不断的追问：“科技想要什么？”
+ 爱因斯坦所言，“想象力比知识更重要。因为知识是有限的，而想象力囊括整个世界”。想象力是人类最宝贵的能力。
+ 历史告诉我们，孤立主义只有死路一条，唯有开放系统才有可能通过熵减走向有序。哪怕再小的复利（即持续良性的迭代），也蕴含着无穷的能量。
+ 个人认为要根据技术发展过程中的数据进行判断，不要基于对未来的想象做判断，一定要依靠数据。
+ 如果一项科技可以让生活变得更轻松，从而使人们有更多的时间陪伴家人，那么这就是一项好的科技。

### 个人如何提前建立能够匹配未来的能力

+ 对年轻人来说，在学习的同时开阔眼界，甚至为期两年的旅行任务。一个人无论多大年纪，都可以通过旅行丰富自己。
+ 比尔盖茨和杰夫贝索斯等人的共通之处，就是可以正确地认识自己。
+ 应该训练自己找到最迅速且最适合自己的学习方法，要始终有保证学习速度和理解深度的意识。
+ 世界变化太快，一生中可能需要调整很多次做事的方式，也可能需要不断重新清空旧的知识体系从头学习。所以拥有强大的适应能力和学习能力才至关重要。
+ 相信只要不断追求，就可以在和自己职业无关的领域有所发现。因为没有相关知识，难免会经历烧脑的过程，这就促使我必须不断学习。不断挑战自己，所以才有机会不断学习新鲜事物。
+ 人越成功就越难以找到自己存在的意义。究其原因，可能是成功将人与现实社会隔绝。越是成功就越想追求完美，而且这种对完美的极致追求根本停不下来。
+ 写作：乐于去展现一个事物的结构和理论，让更多的人了解它。
+ 很多人并不真的了解自己。凯文·凯利说过：“什么是自己有别于他人的最擅长的领域，这才是最难回答的问题。想要找到答案，就必须进行极其认真的自我剖析。”
+ 凯文说过：“只有写下来，才能知道自己是否真的明白。”

### 风险（失败）与创新

+ 科学的基础就是失败，所有的进步都来自失败，创新也是如此。
+ 只有保持几分饥饿的状态，才能有继续创新的可能。【仿佛看到了少楠】
+ 年轻人如果体会过这种贫困的生活，在遇到高风险的时候就不会那么恐惧。

### 生命的意义以及时间

+ 未来的人生要以日计算。耶路撒冷的修行活动，内容是如果生命还有 6 个月时间，你回做些什么。从今以后，要以“日”为单位来计算生命的余额。

### 逆向思维

+ 质疑人们习以为常的事情，学会推翻常理进行思考。
+ 学会使用颠覆常识、质疑常理的态度思考问题、思考未来，这样才有可能在平平无奇中发现新的线索。
+ 构想未来，其实一半在于构想，剩下的一半在于寻找论据和方法，帮助我们实现构想。

### 经济学术语

+ 赢者通吃：在市场竞争中，最后胜利者获得所有或大部分的市场份额，失败者往往被淘汰出市场而无法生存。
+ 回报递减/递增：指在投入生产要素后，每单位生产要素随着所能提供的产量增加发生递减的现象。
+ 网络效应：用户增加得越多，对用户就越有利。群体越多边际效用越高。这一点适用于任何一种网络关系。
+ 次生效应：是一种由地震伴生的作用产生的效应。比如由于地震所造成的人们心理的损害，往往比地震直接损失还大。 次生效应所形成的灾害称次生灾害或间接灾害。
