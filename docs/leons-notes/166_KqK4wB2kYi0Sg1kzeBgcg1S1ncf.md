### why

#### 为什么说“特别”呢？

首先本次时间和地点都比较偏，时间是下午1点钟，选址在1号线终点站「湘湖」附近的一家茶室。按照正常的茶话会逻辑，大概率会先适当问下大家都住在哪个区域。第一，方便选址；第二，可以尽可能的照顾大家时间（毕竟是周末嘛）。

反常的是，没有。

其次，“开始”之前，dong要求我们闭上眼睛思考几个问题（类似于冥想），比如感受现在的环境，比如音乐以及周边人的嘈杂；你们今天过来是带有什么样的目的，想要获得什么？你们对今天迟到的人怎么看待？以及为什么还不结束？

最后，他解释道，最近在学习「易学」，是故意挑选了这样的时间和地方，故意给大家增加难度，想看一下到底有多少人来。

> 我当时下意识以为对方是锤友，没想到对方说最近在学习「易学」，感觉被打开了新世界，发现好多之前经历过的事情，用易学解释都说的通，那也算不了了之。因为老罗在之前smartisan OS的发布会门票上也玩过一次这样的「游戏」，他当时故意把门票卖1000块一张，原价好像是20块。

### 一些记录

+   “形而下”和“形而上”

+   荐书 #books/《OKR法则》

+   考虑清楚自己的工作和生活的平衡点。

+   工作流程规范化，SOP；

+   共享文档，让leader补充事情并确认截止时间，让对方知道你的工作；

+   在商业上，人脉很重要，背后有人和没人，是两件完全不同的路。小世界App，上海公司。

+   业务无非是，增长、留存、收入

+   抽象需求池需求，出方案，最后数据落脚点可能是增长、或者留存、或者收入，让leader给出意见。（了解公司业务，比如对比去年是增长还是下降，因为什么下降？）

+   两条路。①基于当下业务做扩展。②不用公司的钱，另开辟一条新的业务线。（不懂业务，很难做出新的东西）

+   作为管理层，人少的时候，一定要搞好关系；当业务体量大的时候，跟不上节奏的人一定要优化掉，否则会耽误团队的发展。

+   告诉你框架，或者你直接和我对业务流程图；

+   套自己直属leader的话，了解部门和公司未来发展方向；

+   这是我周六周日自己的时间做的，你有时间的时候能不能帮我看下；

+   **因果。接**受很多人给自己带来的痛苦。不迎不拒，能改变的只有自己。

### 总结

第一，有些事情虽然是自己之前了解的，但自己可能没有执行的很好，还需要努力；

第二，陌生人前表达还需加强，自己在陌生人多的场合还是会不自觉的紧张，思绪会被打断；

第三，没有经过训练或者没有痛彻的顿悟，很难做到对生活的态度是“不惧不迎”，对生活种种释然。
