> 🔗 原地址： [我与萨姆·奥尔特曼的对话｜盖茨播客](https://leonzhang.feishu.cn/wiki/XP0IwwGzfi9RWDkM59Uc2BCUnZf?from=from_copylink)

Bill 让 Sam 展望未来两年，有哪些重要里程碑。Sam 回答，

+   **第一，多模态**。语音输入、语音输出，图像和视频。当前 GPT-4 的推理能力和可靠性有限，可能回答一万次中，只有一次回答是最好的，但它不一定知道是哪一次，所以可靠性提升很重要。

+   **第二，可定制性和个性化以及联网**。人们的需求各不相同，**不同的风格和侧重点**，以及还要能够接入用户自己的数据「Email、日历」，并互联网连接。

**GPT 提高生产力的领域**

+   **编程领域**。让程序员的工作速度/效率提升三倍。通过 Agent 的方式，让 GPT 写一个 App。

+   **医疗保健和教育**。

+   **机器人领域**。首先需要的是**智能和认知**，然后才能想办法让它适应物理特性。

+   **创造性工作**，GPT 模型的幻觉是一种特性，而不是缺陷，它能让你发现新事物。

**2**

23 年 12 月份 Dev-Da**y**，关注点聚焦在了「市场竞争和产品壁垒」。

第一，AI 产品的壁垒之一：数据壁垒。如「非公开的私有数据、非公开的标注数据、未标注的用户个性化数据」。

**第**二，AI 产品的 PMF 是什么？目前常见的方向有几种方向，AI + 图生图、AI + 效率工具、AI + 角色扮演、AI + 视频生成、AI + Copilot 等。

+   **AI + 图生图**。常见有 Midjourney、Stable Diffusion、妙鸭相机等。低频、低需求，忠实用户还是偏少数。

+   **AI + 效率工具**。是否能准确理解语言中的指令，是否能准确调用功能/控件，其本质还是模型本身的能力。

+   **AI + 角色扮演**。通过 System Prompt 构建人物属性，常见有 Pi。

+   **AI + 视频生成**。图生视频、视频内容优化等，常见如通义千问的 AI 图生视频。其中，不包括虚拟人直播。虚拟人底层为开源技术，通常需要真人采样才能实现，且过程和结果几乎不通过 AIGC 生成内容，故虚拟人直播不包含在内（“虚拟人”根据是否支持 3D 形态，AI 驱动、人工接管等分为 CG 动画虚拟人、中之人驱动、超写实 AI 虚拟人、2D 真人数字人等）。

+   **AI + Copilot****.** 常见有 Windows 11 Copilot 键、以及部分智能手机 AI 功能（如通话录音总结），核心是在终端续航与功能间寻找平衡点。

**3**

从应用层需求来说，只有 OpenAI 做到了**同时满足 LLM 的三个基础能力项，即 Function Calling（**函数调用）、Long Context （长上下文处理，>100k tokens）、System Prompt（角色扮演）。

### Thinking

**1**

朋友说她自己有个不好的想法是，「当看到别人在同一领域做得优秀的时候，就无法接受自己做出很平庸的东西来，进而直接放弃自己想做的事情」。

我也有过这种想法，最终自己给自己的结论是「完成 > 完美」。

有句老话是，“十指各有长短，何况人乎？” 一定程度上，差异化的内容可能才能满足不同受众群体的需要。

每个人受原生家庭、生长环境的影响，大家的受教育程度、学识也是不同的，学习同一内容后得到的结论也深浅不同，所以差异化在多数情况下是存在的，不可忽略。

基于「每个人对事物的理解深浅不一」，很多事情就好理解了。比如在教育上的差异，以大学教授为例，清北复交与普通本科院校的教育水平是一定存在差距的。如此，为何不让这些普通院校的老师上课直接播放清北复交这类院校的的线上课程？本质上是没有一门课程能够同时适合所有的学生。

由此，人人都有独特的价值，只有通过不断尝试，才能发掘自己的潜力并不断成长。更不要被别人的优秀成就而劝退了自己喜欢的事情，不去尝试就永远不知道结果，「完成 > 完美」。

**2**

稀缺。你所或缺的东西，会俘获你的大脑，占据你的心智带宽，影响你的思维决策。

**3**

你是否知道自己是为了什么而在做什么？你真正想做的事情到底是什么？是否是抛开个人滤镜的真实认识？是否会修正你的真实想法？充分的去经历，然后才有可能知道自己真正想要什么。

**4**

存在主义最核心的命题是「**存在先于本质」**，这意味着人的本质是由他的存在决定的。或者用更通俗的话来说，人生的价值和意义都是人们通过实际生活中的行动创造出来的。换言之，外在事物，或者「生活本身是没有意义的，除非你去赋予它意义」。

**5**

有些人看待「**个人信誉**」就和信用卡差不多。立下 Flag，就相当于借用了自己的信用，然后搞清楚一共借了多少并在将来还掉。如此循环，个人信誉值越累积越多，从而进行正循环。

**6**

判断一个人的智力是否属于上乘，就看他脑子里是否能同时容纳下两种不同的思想，而无碍于其处世行事。

**7**

写作可以是职业发展的产物之一。基于职业，有经历和阅历，然后写作是副产物。写作是梳理了自己的想法，提出新问题和指向下一段职业发展方向的一个中转点。

**8**

炒股就是在「买预期卖现实」。举个例子。“2023 年拼多多连续三个季度增长，其中第三季度财报同比增长 94%”，2023 年 11 月 27 日拼多多的美股最高收盘价为 145.27，对比 26 日收盘的 118.70，涨幅约 22.38%。

**9**

“士为知己者死”是双向奔赴的，并非只是下属的一厢情愿。

**10**

状态/心情不好、内耗的时候就选择动起来。

### 精神鸦片

**1**

很多东西是做了之后才知道的，为人子女、结婚、生子、为人父母，哪一样是自己知道才去做的？还不都是做了才知道，边做边学。所有的事情，工作、旅行、装修，最难的都是第一步，一旦跨出去第一步，其实整个过程当中最艰难的部分就应该过去了。

**2**

好的生活、幸福的经历是不能带来成长的；能让你成长东西，就是让你痛苦、让你反思的东西。

**3**

最消耗生活质量的东西，就是焦虑。别人无法贩卖给你焦虑，是你自己焦虑。

**4**

我们会毁灭于自己所憎恶的东西，还是会毁灭于我们开心的东西？一定会毁于开心的东西，因为这些东西太爽了。没有任何成就能离得开艰辛的努力，不要成为欲望的奴隶，虽然在放纵中你觉得自己是自由的，但其实是被奴役的。

**5**

You never know what hand you'll get dealt, You take life as it comes at you. To make each day count. 世事难料，随遇而安就好，切莫虚度光阴。
