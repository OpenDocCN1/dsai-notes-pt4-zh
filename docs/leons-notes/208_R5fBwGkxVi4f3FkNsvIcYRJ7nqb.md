
# 乔布斯的回归｜1997年Macworld大会上的演讲

1997年8月6日，在波士顿召开的这次Macworld大会上，乔布斯还不是苹果的正式CEO，他刚被苹果董事会任命为临时CEO还不足一月时间。

![](img/56fb24b57a87036441a1cf2d489379bf.png)

事实上，乔布斯重回苹果公司也还不到一年时间。1996年12月，苹果花费4.29亿美元收购了乔布斯的Next，乔布斯才以“非正式顾问”身份回归苹果。这时，距离他离开苹果已经过去了近11年。

1997年7月，由于糟糕的业绩表现，把乔布斯带回苹果的时任CEO吉尔·阿梅里奥受到了董事会的驱逐，这才有乔布斯的取而代之。

在这次Macworld大会上，临时CEO乔布斯的任务是向外界做一个关于苹果的status report。

乔布斯在演讲开头谈及一些外界对苹果的看法，诸如“Apple 已经无足轻重”，“Apple 的执行力已经不能做任何事情”，“Apple 的文化是无政府状态，你无法管理它”。他逐一反驳了这些观点，

![](img/02c72300ab5abe1df354697bdb8f5a31.png)

1. 苹果的确不如以前那样辉煌，但目前的苹果在个别细分领域还是占据领先地位的。
2. 苹果的执行力非常好，只是他们用在了错误的道路上。
3. 最后一点，乔布斯说苹果的员工已经迫不及待的希望有个正确的战略带领他们前进。

接着乔布斯用柱状图展示了苹果当前最大的问题，销量问题，两年时间下滑了30%。乔布斯说，我们打算从5个方面着手进行改变。

![](img/30fbd1a3d2ca3f528b880b80c4ab185e.png)

## 1. 更换董事会成员

乔布斯宣布了6位新董事会成员，这是为乔布斯进行改革扫清障碍，老的董事会中有些成员不太支持乔布斯，因此乔布斯逼迫他们辞职，成立了支持自己的新董事会。具体细节可以参考《乔布斯传》。

## 2. 更加专注

乔布斯说苹果要专注于自己擅长的领域，那什么是苹果擅长的领域呢？乔布斯用了一系列数字证明苹果在以下两个领域是处于明显领先地位的。

### 内容创作领域

> 在广告、图形设计、出版等领域，80%的电脑是Macintosh；
>
> 在互联网领域，64%的网站是在Mac电脑上开发的；

### 教育领域

> 乔布斯说苹果是世界上最大的教育供应商，这是很多人没有意识到的；
>
> 在教育系统中，60%的电脑是苹果电脑，64%的计算机老师使用的是苹果电脑；
>
> 这是一个年收入超过20亿美元的business；

## 3. 提升核心资产

在这部分，乔布斯先是对着台下观众很煽情的说，苹果的核心资产是你们，你们是一个接近2500万的活跃用户群，是你们坚持相信苹果的产品仍然是世界上最好的。乔布斯说苹果没有照顾这些用户，他的这番话把台下观众感动的稀里哗啦。

接下来乔布斯又理性的说苹果的核心资产在以下两个方面，

### 苹果的品牌

> 乔布斯说如果你请一个人列举5个著名的品牌，那苹果一定会和Nike、可口可乐、迪士尼这些人尽皆知的品牌一样被列举出。

### Mac OS

> 乔布斯说Mac OS是苹果的重中之重，它有2500万活跃用户，成千上万的开发者在这个平台上赚钱，而Mac OS 8发布两周就卖了120万拷贝。

## 4. 合作

这部分是整个演讲中最关键的一块，如果你仔细观察会发现，乔布斯先是喝了口水，并且在很长一段时间一直是低着头讲的，这些行为语言都表明他对接下来要讲的内容并不是很有底气。

乔布斯先说了一些比较官方的话用来引出下面的内容，苹果处在一个生态系统中，苹果需要别人的帮助，也需要帮助别人，破坏性的关系对谁都没有好处。

接下来乔布斯宣布苹果将会开展一段很有意义的合作关系，于是keynote的大屏幕出现了Microsoft的logo，此时台下的观众反应并不积极，掌声也不强烈。

乔布斯接着一条一条的具体解释和微软的合作将是怎么进行的，

> 专利交叉许可协议，两家公司的现有专利以及未来5年内取得的专利都将开放给对方使用，来解决长达10年的专利纠纷。
>
> 微软承诺在接下来五年中为Macintosh开发Office软件
>
> 乔布斯宣布微软IE浏览器将成为Macintosh默认浏览器（台下嘘声一片），不过苹果提倡选择自由，苹果将会开发其它浏览器给用户使用。（台下欢呼一片）
>
> Mac平台将支持Java
>
> 乔布斯宣布微软将购买苹果公司1.5亿美金的股票（台下又是嘘声一片），但是没有投票权。（台下欢呼一片）

乔布斯说如果苹果想要继续前进，重新健康和繁荣起来，就必须抛弃苹果必须赢微软必须输这种想法。如果有人打算帮俺们，那太好了，因为苹果需要一些尽可能的帮助。如果我们搞砸了，那不是别人的错，是我们自己的错。

如果你希望在Mac上使用上Office，那就应该对开发Office的这家公司表示感谢。（这段演讲很有霸气。）

## 5. 进入新领域

乔布斯说苹果需要进入新的产品领域，不过在这次报告中没有展开阐述。

这次大会之后，乔布斯重掌苹果，终于实权在握，可以按照自己的意愿去进行大刀阔斧的改革，他重建了董事会，削减产品线，修复和微软的关系，推出《Think different》广告帮助苹果进行品牌重塑，苹果从此起死回生，重回健康和繁荣之路。乔布斯带领那个在垂死边缘挣扎的苹果成为了当今世上市值最高的商业公司，不得不说这是商业史上最伟大的一次逆转奇迹。

## 写在最后

之所以写这篇文章是因为昨天在YouTube上闲逛看了这个视频，之前只知道有这么个视频，但是一直没看。看完后觉得这个演讲真是太帅了，就想写点东西。

为了写这篇文章，又把视频看了三四遍，并查找了很多资料，说实话挺累的也挺废时间的。不过整个过程下来还是挺有收获，我觉得这就够了。

说说我对这个演讲的感受吧：

1. 这是我看过的乔布斯最棒的演讲，比他斯坦福大学的那个演讲更好。
2. 整个keynote的思路非常清晰，一步一步引领观众。
3. 有理有据，用数字证明自己的观点。
4. 有些话不一定非得从自己的嘴里冒出来，别人说出来可能更管用。
5. 幽默是最管用的。
6. 让观众感受到他们和你是一体的。
7. 什么时候该煽情，怎么煽情这很重要，不要显得做作。
8. 如果你必须要给用户一个大棒，那么记得一定要再给用户一个甜枣。
9. 即使是乔布斯，也有错的时候。
10. 还有很多，总之这个视频值得再看几回。

注1：直至2003年6月，苹果才推出自家的Safari浏览器，同时微软也终止开发苹果版的IE浏览器。Mac OS X v10.3仍保留IE，但至10.4版苹果就仅预装Safari浏览器。

注2：在演讲当中，盖茨通过卫星连线到现场，并投影在会场的大屏幕中，乔布斯曾称这是他整个Keynote生涯中犯过的最严重的错误，因为那样看起来显得微软很Big brother，而苹果很渺小，乔布斯很渺小。这个场景跟苹果在1984年拍摄的一个名叫《1984》的广告十分相似，广告中把苹果描绘成一个反抗Big brother（当时的IBM）的形象。这部广告的创意来自奥威尔的同名小说，有兴趣可以看看。

注3：在演讲的最后，乔布斯以极富感染力的语气说了一些关于Think different的话语，他认为苹果电脑的用户都是Think different的，这群人代表了这个世界的创新精神，他们有改变世界的欲望，苹果就是要make tools for those kinds of people，因为在普通人眼中，这群人是疯子，而在苹果眼中他们是genius。没错，这段话其实是为97年秋季苹果发布的新广告《Think different》做的铺垫。这只广告影响深远，重新定义了苹果的文化，为当时衰弱的苹果品牌注入了新的活力。
