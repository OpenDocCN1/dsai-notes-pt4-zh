
# 贝索斯2005年致股东信

> 🔗 原文链接：https://www.cmtzz.cn/news/27476

2005年亚马逊推出Amazon Prime业务，会员免配送费，提升会员粘性的同时对用户进行了分类筛选。同时，前瞻性的利用“大数据”来辅助“物流中心”的投资决策。贝索斯在文中举例阐述了“长期利益”与“短期利益”的取舍问题。允许“第三方销售”在亚马逊平台与其自营业务公平竞争，这一举措在短期内会对业绩产生负面影响，但是长期来看却是“以用户为中心”以及“注重长期价值”的最好体现（2000年“第三方销售”产品数量占比6%,上升至2005年的28%，在15年超过50%）。纵观互联网巨头的成长史，都有过类似“自我革命”的经历：NETFLIX的线上业务与“邮购DVD租赁”、腾讯的🛰️与🐧、美团的外卖与“到店”。只有敢于牺牲短期利益，专注长期利益的企业才能长成参天大树。

## 致我们的股东：

我们在亚马逊网站做出的许多至关重要的决定都可以用数据分析来完成。数据分析还可以告诉我们，决策的结果究竟是正确的抑或是错误、出色的抑或是糟糕的。这是我们最喜欢的决策方法。

开设新的物流中心就是个例子。我们使用现有的物流网络历史数据来预计季节购物高峰，为新产能建立数学模型。我们通过观察预期的产品种类，包括产品规格和重量，来决定我们需要的仓储空间以及设备，来处理小尺寸可分类商品或是通常单独运送的大尺寸商品。为了缩短配送时间，减少出库运输成本，我们在邻近用户、交通枢纽和现有设施的基础上分析新建物流中心的位置。定量分析改善了用户体验和我们的成本结构。

同样地，我们大部分存货采购决策能够运用数学模型和定量分析。我们希望库存产品在有需求的时候，能够立即提供给用户而不断货；为了维持相关的库存成本，我们希望把库存总量降到最低，从而降低产品价格。为了同时达到这两个目标，需要保持适量的库存。

我们使用历史采购数据来预测客户对产品的需求以及这种需求的变化；我们使用卖家的历史业绩数据来预计补货时间；我们根据入库和出库运输成本、仓储成本和预期用户地点，来决定这种产品在配送网络中的储存位置。使用这种方法，我们能够保证仓库中有一百多万种独特的商品立即提供给客户，同时每年的库存周转率超过14次。

上述决策要求我们做出某些假设和判断，但是这些决策、判断和看法只能起到初步作用。大量繁重的任务会用数学方式来完成。

然而正如您期望的那样，并非我们所有的重要决策都能用这种羡煞旁人的数学方式来解决。有时候在只有很少或根本没有历史数据的指导下，我们根本不可能进行前瞻性实验，毕竟这实在太不切实际了。尽管数据、分析和数学模型都能发挥作用，但是在做这些决策时考虑到的主要因素还是主观判断。[1]

我们的股东都知道，我们决定全年不断地为用户提供低价商品，而我们的效率和规模效应使这种做法切实可行。这就是个不能通过数学方法来完成重要决策的例子。

实际上，我们在降低价格的时候，就已经违背了我们的数学模型，因为这个模型的结论显示我们聪明的做法应该是上调价格。我们掌握了大量与价格弹性相关的数据。通过精确的计算，我们可以预计把价格降低一定幅度将导致产品销量一定比例的增加。除了少数例外的情况，短期内产品销量的增加不足以补偿价格的下降。

然而，我们对价格弹性的定量理解局限于短期内。我们可以预计降价在本周和本季度内的影响，但不能精确预计持续降价在今后五年、十年或更长时间内对我们业务的影响。我们的判断是，以降价的形式提高对用户的回报率，实现规模经济，会建立长期的良性循环，带来金额更高的自由现金流，从而为亚马逊带来更宝贵的价值。

我们对免费送货服务和Amazon Prime计划作出了类似的判断，这两项功能在短期内耗资不菲——但我们相信它们在长期内会有非常重要的价值。

另一个例子是，2000年我们邀请第三方直接在我们“首要零售不动产”——网站的产品细节页面与我们展开竞争。

把亚马逊自营的产品细节页面做得跟第三方商家商品的页面一模一样，看起来是有风险的。公司内外的热心人士都担心这种方法会蚕食亚马逊的自营业务，在用户至上的理念下作出的创新通常会面临这种情况——没有办法可以提前证明这样做会带来好处。

我们的买家指出，邀请第三方加入亚马逊网站，会导致库存预计更加困难，如果我们把产品细节页面“拱手”让给第三方买家，我们可能会受到多余库存的困扰。然而，这样的判断太简单了。如果第三方可以在特殊商品上提供更好的价格或更好的功能，那么我们希望我们的用户很容易得到这种优惠。

历史证明，第三方销售获得了成功，并成为了我们业务的重要组成部分。第三方销售产品数量占总产品数量的比例从2000年的6%提高到2005年的28%，同时零售收入增长了两倍。

以数学为基础的决策需要广泛的共识，而以判断为基础的决策经常会引起争议，至少要等到付诸实践才能得到证明。任何不愿意忍受争议的机构，就算是在做出以数学为基础的决策时，也会保持谨慎克制。而在我们看来，这样做确实是限制争议了，但也把创新和长期价值创造限制了。

1997年致股东的信件为我们的决策理念奠定了基础，下面附上这封信的部分内容（点击可阅读1997年的致股东信）：

+ 我们将继续毫无保留地专注于用户至上的理念。

+ 我们的投资决策将继续基于“长期市场领导地位”这一目标，而非关注短期的盈利以及华尔街的短期反应。

+ 我们将继续批判地评估我们的项目以及投资决策的有效性，以果断抛弃那些不能提供相应回报的项目，而追加投资那些运作良好的项目。同时，我们将继续从我们的成功及失败中汲取经验教训。

+ 我们将毫不犹豫地投资那些有助于提升我们市场领导力的机会。这些投资有的可能会得益，有的或许不会，但我们至少能从每一个案例中汲取有价值的经验教训。我们会结合自身善于使用强有力的定量分析的企业文化，大胆做出决策。对于这点，您们完全可以信赖我们。在这个决策过程中，我们将继续坚持用户至上的理念。在我们看来，这是为股东创造价值的最好方式。

杰夫·贝索斯

亚马逊创始人、首席执行官

[1]“非结构化'决策过程的结构”是由HenryMintzberg，Duru Raisinghani和AndreTheoret在1976年撰写的一篇引人入胜的论文。他们研究机构如何制定战略性的“非结构化”决策，而不是更可量化的“运营”决策。您可以在论文中找到的其他金石之言包括：“管理学家对运营决策的过度关注可能会导致组织更容易采取不适当的行动方案。”他们并未探讨严格定量分析的重要性，只注意到它得到了失衡的研究和关注，可能因为它更容易量化。
