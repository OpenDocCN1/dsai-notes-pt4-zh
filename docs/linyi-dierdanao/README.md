# 林逸LinYi's第二大脑

> **创**造知识而不分享，是精英主义；只分享而没有创造知识，是营销；唯有以分享为目的的知识创造，才是真正的思想领导力。

当前，AI的浪潮正在以前所未有的力量重塑整个世界。如果我们仅仅旁观，可能会错失时代的机遇和发展；而如果被眼花缭乱的AI信息包围，却缺乏足够的理解，又容易陷入焦虑与迷茫。

因此，我希望把我自己**看到的、听到的、学到的**东西系统化搭建成一个知识库，既帮助大家正视AI、关注AI的发展，也在繁杂的信息中抽丝剥茧、沉淀思考，避免停留在表面的追逐。

期待与你一起，在AI变革的浪潮中保持清醒、持续成长，不止于关注，更在于理解与实践。
