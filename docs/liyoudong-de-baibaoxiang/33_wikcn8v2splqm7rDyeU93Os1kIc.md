
# 用Midjourney分解图片关键词

> 来源：[https://docs.feishu.cn/docx/FFkKd2nNWoqkLBx86vaccvEQnZf](https://docs.feishu.cn/docx/FFkKd2nNWoqkLBx86vaccvEQnZf)

## 背景

如果你正在学习AI绘画，但是如果找不到兴趣点，在关键词上反复扑街，生成的图片总是和自己想要的大相径庭，可能会在两三天之内就放弃了。别担心，今天就讲讲如何利用Midjourney分解图片关键词

## 分解图片关键词

首先先找到你想要生成的类似风格的一张图片，比如我选的是下面这张图片↓

![](img/0e50997246303d98caa9d22a41abf2c8.png)

然后进入midjourney频道，输入`/describe`，然后会跳出来一个框框如下↓

![](img/f57b3169d55680df132bae5a6efadb56.png)

选中指令，将你选好的照片拖进去如下↓

![](img/ac186ac5351d04887a927633d03b9420.png)

发送出去就会收到4个propmt

![](img/85dfb667259d36b697e77dcb05049970.png)

下面分别有1,2,3,4 四个选项，选择其中任意一个即可生成对应的四张图片，生成效果如果不满意的话可以点击右下角的重置，midjourney会重新为你生成四个propmt

![](img/336df8944834e0e9c3e89d5d761260da.png)

我随机点了一个，生成的效果如下↓

![](img/34cfa72b8c36511a7e18c97ba9263975.png)

## 优化生成效果

如果想要脸部手部效果更加真实，可以在关键词末尾加上`--v 5`这个指令，注意在`--v`前后都要留一个空格，我随机在另一个propmt后加上了这个指令，生成的图片如下↓
