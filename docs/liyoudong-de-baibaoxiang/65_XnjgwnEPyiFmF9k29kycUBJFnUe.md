# 引流

## 小红书，怎么在评论区引导加群，在群内又怎么引导加微信？

看看优秀的案例，其他人是怎么玩的，去模仿 。

引流没有 100% 安全的方法 。一直在更新玩法

## 怎么判断违规过的小红书账号是否要换机换号?

如果只是单篇笔记违规，不影响 。

如果大量的笔记，阅读量都到不了 100，或者所有笔记都搜索不到，且尝试了几个月还是这样，换号 。如果有违规提醒找客服后也无法申诉，长期限流就换号 。

## **发了一些笔记，发现观看量是200~30**0，且点赞和粉丝基本没有。这是什么问题？

有浏览，没赞藏。大概率是笔记的问题，优化笔记。

如果账号没有异常，没有收到违规提醒。继续发笔记 。

切记要多参考对标库，然后模仿发笔记，最好不要自己随性而发。
