#### 分类问题是否可以使用MSE作为损失函数?

+   不可以，因为分类问题的标签都是离散的，而MSE是连续的损失函数，不适用于离散输出。

#### **过拟合怎么处理?**

+   过拟合指的是在训练集上面表现良好，在测试集上表现差的情况。

**过拟合的原因通常是**模型复杂、参数过多，常见的处理方法有:

+   增加数据量；

+   增加训练数据集简化模型；** **

+   减少模型参数量，如减少层数，降低模型复杂度正则化；

+   在损失函数中增加正则化，限制模型参数的大小，如L1/L2正则dropout；

+   在模型中增加dropout，其实也是一种简化模型的方式early-stop；

+   训练过程中当模型效果在验证集上不再提升时，提前停止训练

#### L1、L2正则化的效果、区别、原理?

+   都是通过限制模型参数的大小，达到降低模型复杂度的目的。

+   L1正则化是在损失函数中增加各参数绝对值求和的部分，

+   L2正则化是在损失函数中增加各参数平方求和的部分，L1正则化可以使得部分参数为0，相当于减少参数个数;

+   L2正则化会使得所有参数都趋于较小的值，但不会为0

#### drop的原理，在训练测试时的区别?

+   dropout是一种常用的正则化方法，其原理是在每一次选代时使一部分神经元失活，也就是输出为0，从未防止过拟合。在训练时，会以概率p丢弃一部分神经元，使其输出为0，从而产生多个不同的子网络，每个子网络都只学到了一部分信息，使模型更加鲁棒。在测试时，drop是关闭的。为了保证训练和测试一致，有两种方案，一种是在测试时每个神经元的结果都乘以p来保证得到同样的期望;另一种是在训练的时候将丢弃完的结果除以(1-p)来进行还原。

#### SGD、RMSprop、动量法、Adam介绍

+   介绍一下神经网络训练常用的优化算法有哪些，整体来看，有两大类方向，一类是调整学习奉使得训练更稳定，另一类是对梯度估计进行修正让训练更快。

+   首先是SGD，它是随机梯度下降，每次更新梯度时随机选取一个样本来更新，它的缺点是容易陷入局部最优点，收敛速度慢，所以我们一般会使用小批量梯度下降，即每次梯度更新选择一批样本做梯度更新，比如64个样本/128个样本，学习率的大小随批量大小增大而增大。

+   标准的梯度下降中，每个参数都是使用相同的学习率进行更新的，但是每个参数在各自维度上的收敛速度不同，有自适应的学习率是更好的选择。RMSprop就是这样的，它将每个参数的学习奉都除以梯度平方的指数衰减移动平均，如果某个参数累积的偏导数比较大，那它的学习牵就比较小，反之如果某个参数累积的偏导数比较小，那么它的学习奉就相对大一些。

+   动量法是使用之前一段时间的梯度信息，使用一段时间负梯度的加权平均作为梯度更新，这样当某个参数在最近一段时间梯度不一致时，其参数更新就比较小，如果某个参数在近一段时间梯度更新一致时，其参数更新就比较大，起到了加速的作用。

+   Adam是RMSprop和动量法的结合，不但使用动量法更新参数，还自适应调整每个参数的学习率，本质上都是为了优化得更快更好。

#### BN和LN介绍

+   BN可以对网络的任何一层进行归一化操作，一般用在仿射变换之后，激活函数之前，对某一层的单个神经元的净输入进行归一化操作，训练阶段使用的是某一个批次的均值方差，测试时使用的是全部训练集的均值方差，通过移动平均获得。BN可以使得训练过程中的输入分布保持一致，使得训练更加容易。BN可以理解为对单个特征进行归一化，使得激活医数分布在线性区间，让模型梯度更新得更快。

+   LN是对中间层的所有神经元的净输入进行归一化，其均值和方差使用的是某一层神经元输入的均值和方差。LN可以理解为是对所有的特征进行归一化，那显然如果对[身高、体重、年龄]这三个特征进行LN，会因为各自的量纲不同产生很大的影响，也没有什么意义，那为什么需要LN呢?LN更适合用于NLP相关的任务，它是针对一句话进行归一化的。

#### 样本不均衡问题怎么解决?

+   对样本进行上采样或者下采样，使得比例变得合理:对损失函数进行优化，如二分类交叉熵损失，根据正负样本比例m:n，对损失函数进行加权，使得a/1-a=n/m，相当于给样本少的类别更高的权重;也可以使用focal loss，是从样本难易学习的角度看的，给难的样本更高的权重;

#### 介绍一下大模型的tokenizer?

+   在大型语言模型(Large Language Models，LLMs)中，Tokenizer是一个关键组件，它负责将原始文本转换成模型可以理解的输入格式。这个过程通常涉及将文本分解成更小的单元，这些单元被称为tokens。Tokens 是模型训练和推理过程中的基本处理单位。以下是几种常见的Tokenizer 类型及其特点:

+   Byte Pair Encoding(BPE)BPE 是一种基于字待级别的分词算法，它从字符开始，逐步合并出现频率最高的字符或字符组合，形成更长的词汇单元。优点:无监督学习，适应性强，能有效处理未登录词(0ut-of-Vocabulany,OOV)。缺点:可能导致词汇表过大，处理速度较慢，且在合并时可能产生歧义。

+   WordPieceWordPiece 类似于 BPE，但它是基于子词(subword)级别的分词算法，通常用于处理未分词的文本。优点:语言无关性，词汇控制灵活，有效处理 OOV。缺点:可能导致词的不连续性，处理 00V 时可能产生语义困惑。

+   SentencePieceSentencePiece 是一个多语言分词器，它通过无监督学习自动识别多种语言的词汇，并进行分词。优点:语言无关性，动态词汇表，分词效果好，显著降低 00V 问题。缺点:分词复杂性，模型大小可能较大，分词结果可能不唯一。

#### 现在常用的位置编码有哪些，以及原理?

+   正弦位置编码(StnusotdalPositionalEncoding):这是Transformer模型中最初提出的位置编码方法。它通过正弦和余弦函数的组合来表示位置信息。对于给定的位置pos和维度i，位置编码的计算公式如下:PE(pos,2:)=sin(pos/10000^(2i/d_ model))PE(pos,2i+1)=cos(pos/10000^(2i/d_ model))其中，d-model是模型的隐藏层维度。这种方法的优点是能够为模型提供一种周期性的、可微的位置信息，使得模型能够学习到序列中元素的相对位置关系。

+   绝对位置编码(Absolute PositionalEncoding):在某些变体的Transformmer模型中，如BERT，位置信息是通过一个固定的、可学习的嵌入向量来表示的。这些嵌入向量在训练过程中学习，并且与词嵌入相加。这种方法允许模型学习到位置信息，但与正弦立置编码相比，它不具备周期性。

+   相对位置编码(Relative PositionalEncoding):在某些模型中，如XLNet，位置信息是通过计算序列中元素之间的相对位置来表示的。这种方法可以捕捉到元素之间的相对距离，而不是绝对位置。相对位置编码通常需要额外的计算，因为它涉及到序列中所有元素之间的距离计算。

#### 模型加速推理方式

+   模型推理加速是提高深度学习模型在实际应用中响应速度的关键技术，尤其是在需要快速处理大量数据的场景中。以下是一些常见的模型推理加速方式:

+   量化(Quantization)

量化是将模型中的权重和激活值从高精度(如32位浮点数)转换为低精度(如8位或16位)表示的过程。这可以显著减少模型大小和计算需求，从而加速推理过程。

+   模型剪枝(Pruning)

剪枝是通过移除模型中不重要的权重(接近于零的权重)来简化模型。这减少了模型的复杂度，降低了计算量，同时通常对模型性能的影响较小明

+   知识蒸馏(Knowledge Distillation)

知识蒸馏是一种将大型模型(教师模型)的知识迁移到小型模型(学生模型)的技术。学生模型在保持较小的同时，尽可能地模仿教师模型的行为，从而在推理时达到类似的性能。

+   硬件加速(Hardware Acceleration)

使用专门的硬件加速器，如GPU、TPU(TensorProcessingUnit)或FPGA(现场可编程门阵列)，可以显著提高模型的推理速度。这些硬件通常具有高度并行的处理能力，专为深度学习计算优化。

+   多线程和多进程(Multi-threading and Multi-processing)

在CPU上，通过多线程或多进程并行处理多个推理请求，可以提高整体的吞吐量。

+   批处理(Batch Processing)

对于可以并行处理的请求，将它们组合成批次进行推理可以提高硬件利用率，减少空闲时间，从而提高推理速度。

+   使用模型压缩技术(ModelCompression Techniques)

如权重共享、参数共享等技术可以在不显着损失模型性能的情况下减少模型大小，从而加速推理。
