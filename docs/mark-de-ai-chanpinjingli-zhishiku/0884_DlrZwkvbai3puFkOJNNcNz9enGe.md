## 保存常用提示词

### 提示词模板

将常用的提示词保存为模板：

> 你：请帮我创建一个文案生成的提示词模板。

> Claude：已创建文案生成提示词模板：

#### 提示词内容：

```
请帮我写一段[类型]文案，产品/服务是[产品名称]，主要特点包括[特点1]、[特点2]、[特点3]，目标用户是[目标用户]，风格要求是[风格]。

要求：
1. 突出产品/服务的核心卖点
2. 语言生动有趣，吸引目标用户
3. 字数在[字数]左右
4. 包含行动号召
```

#### 示例：

```
请帮我写一段产品描述文案，产品是智能手表，主要特点包括健康监测、运动追踪、消息提醒，目标用户是年轻白领，风格要求是时尚现代。

要求：
1. 突出智能手表的核心卖点
2. 语言生动有趣，吸引年轻白领
3. 字数在200字左右
4. 包含行动号召
```
