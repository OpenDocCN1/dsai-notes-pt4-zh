# Gemini3生成的项目简单部署上线

> 来源：[https://qqs7y1hozd1.feishu.cn/docx/GxsddxehBow9SGxrd7ccxG7jn8b](https://qqs7y1hozd1.feishu.cn/docx/GxsddxehBow9SGxrd7ccxG7jn8b)

文章使用Gemini 3大模型生成代码并将其部署为网站或小程序的全过程。内容包括：

> 1) 在Gemini官网或AI Studio中使用Canvas/B功能生成代码；

> 2) 纯前端应用的部署流程，通过Cloudflare Pages或国内云服务器实现；

> 3) 小程序的创建与部署方法。文章强调AI大大缩短了从想法到产品的开发周期，为非技术背景创作者提供了强大支持，适合有一定基础但缺乏部署经验的新手学习。

![](img/b3671b19debe3fddef58eebcc21bd937.png)

**如**果是在aistudio里操作，选择 build 即可进入编码模式 （我更喜欢用这个，后面的举例都是用aistudio）。

![](img/b3c00ca7f85c89680dca7b32052161a0.png)

![](img/096f9b33b39fadc793acf9cc45789ed6.png)

同样的，右侧也会出现一个代码，预览模式。

![](img/19c86b2896096b0e74dac454eab9de82.png)

![](img/94a74421b3f39c92549c8865f8c6bf3e.png)

好了，你现在知道哪里能用，也能一句话让 AI 帮你实现了，觉得效果还不错，就回到了本文的主题：那我怎么部署呢？或者说变成我自己的一个应用？

这个要真展开了说其实也复杂，会涉及域名，服务器，甚至可能还涉及后台，数据库，api 之类的，我们尽量让大家可以实现从 0 到 1，从最简单的开始。

> **第一种情况，也是最简单的，纯前端页面**，不涉及后台，数据库，也不需要 api。

拿我昨天用 gemini 3 复刻的流光卡片搞的一个文字卡片应用：

![](img/a92f635266963dae72519236ae9d198f.png)

地址：card.zlbigger.com

这是一个纯前端应用，无需任何后端服务与数据库，即开即用，全部基于 React 实现（现在绝大多数 AI 大模型生成都是这个），离线即可运行。

完成后，界面右上角会有一个下载的标识：

![](img/3316a00ec90412ed7764c8066aa2a36b.png)

直接把代码下载下来，会得到一个压缩包，解压后可以看到相关代码：

![](img/c769ad9420861bc2453f2af9aedc494d.png)

然后找一个你熟悉的 AI 编辑器工具，比如Trae，cursor等，打开这个项目，你可以继续在这个上面改，比如加个统计代码，换个背景图的颜色，加个自己的自拍照，加个自己的联系方式等等。

**然后就是让它构建项目，会生成一个 dist 的目录，**比如你直接说，帮我构建 dist 目录。

![](img/bcef8595d37d48e1956fdfc0398caeb9.png)

![](img/b3b73fc480e728f14362dfc427dc8b1c.png)

你就会看到这个/dist 目录，里面是构建好的可直接运行的前端页面。

然后就进入到「部署」环节，让所有人都能看到你的创意，本质上是需要一个域名，一个服务器（或者叫运行代码的空间）。

可以先在cloudflare免费体验下这种成就感。

![](img/f466d572c8c9be92c2b2316746a5a66c.png)

![](img/2a84cf4d2159c16f9c62ff87e3885a68.png)

![](img/6394edbad98fd02059e40056dd5b66d3.png)

进入到这个 page 页面，创建一个项目，上传 dist 目录（其他的文件可以不要）。

![](img/bc569653c972a6be677528ce639b09dd.png)

点击部署站点。

![](img/bd2ad8bc32fbf45b3c0e7bb7e25bc413.png)

我们会看到已经匹配了一个 cf 下的二级域名，点击就已经可以直接访问到了，如果你不想买域名，到这里其实就已经把你的想法部署上线了。

![](img/fc64cb915c4f3a05e35a85d8eee7374f.png)

你有需要更新的，点击右上交的创建部署，更新即可。

![](img/bb772ba5a61010ce0df0ef3abb8696f0.png)

如果你觉得这个访问地址不够自我，需要用自己的域名，那就自定义域名即可，把这个地址加入到 cname 里解析到你自己的域名，比如这样：

![](img/888abcfbedd164b5dd87a697a42fd1f3.png)

然后你输入 card.zlbigger.com这个域名就可以访问了。

![](img/453a93d60b50689715a6625532e8f9ff.png)

上述过程你就完成了一个从想法到实现，再到部署上线的全过程。

同样的，如果你要做国内市场，你可以买腾讯云，阿里云的产品（性价比很高），备案即可（现在备案的速度很快），原理是一样的

域名解析，服务器上放文件，同时服务器匹配域名。

3，最后我们再说说怎么把这种类型的变成小程序，甚至会更简单一些，因为也不用服务器了，甚至都不用域名。

你注册好小程序，下载一个开发者工具。

用这个叫挪车宝的举例。

![](img/b683ccb6a0be611835bab048f6ae57ff.png)

我也是现在 AIstudio 里实现，满意了之后点击下载。

![](img/d3a7683b2ba41703c04f699c8d4051d9.png)

用 AI 编辑器运行这个项目，对代码进行微信小程序版本改造。

![](img/edd491c274fb0bea02a99602ab5d3265.png)

帮我改造成一个微信小程序的应用，保持现在的功能和设计风格，细节等一直，放在，目录xiaochegnxu 里

![](img/52a9ef67ea09a7b69c3ace1e0150289d.png)

怎么一边预览一边修改呢，简单，打开上面让你下载的微信开发工具。

![](img/0f73e68146369e2612337a3fef65d56e.png)

![](img/b1a037ad73d97fbea68926756eb04f00.png)

导入项目，目录定位到前面对应的小程序所在目录，比如这个项目的目录叫xiaochengxu

对应的 appid 就是让你注册的小程序后台对应的 id（会跟你的微信关联）。

这样的话，你就可以一边在 AI 编辑器里口述修改，另一边在微信开发工具上实时预览效果。
