# GPT Image 2 来了，今天起，你看到的每一张图都不可信

> 来源：[https://qqs7y1hozd1.feishu.cn/docx/AAQTdh64QoTn7oxdjNGcaCa8nOd](https://qqs7y1hozd1.feishu.cn/docx/AAQTdh64QoTn7oxdjNGcaCa8nOd)

玩文生图这么久了，也经历过无数次被颠覆、被炸裂。

特别是经历了去年把我们震碎过的 Nano Banana 之后，我们的阈值，可能早就被这帮硅谷卷王们拔到了天上。

我以为，再有什么新模型上线，最多也就是哦，还不错。

但是。

当 GPT Image 2 正式上线，当我知道连这些图都是它生成的之后，我心里还是没忍住，狠狠地骂了一句：卧槽。

比如这个：

![](img/42957560decf3f4ad4b6f6d23d06f7a6.png)

还有这个：

![](img/9259abd87542099b58d3447a9eae7a40.png)

还有一些证件之类的图，有多真实呢？发出来可能会违规的程度。

你非常清楚地知道，以前的任何一种模型，都绝对、绝对生不出这种程度的图。

真的是遥遥领先。

放个 Arena 的数据图给你们看看这个 GPT Image 2 的提升有多大吧。

![](img/12af14422e7d169ef19443fcee34fa6a.png)

一骑绝尘。

今天，还是老规矩，我直接上手几个项目，带你们直观地感受一下，这玩意现在到底有多变态。

而且，这次不仅是模型本身强，搭配上 Lovart 独家的工作流，那个爽感，简直了。

为什么一定要到 Lovart 上去玩，来，上个我再其他文章下看到的评论截图：

![](img/a4eb81778783397b0308da229362722d.png)

**www.lovart.ai/**

**手搓一个小潘带货**

文章开头的那个潘金莲带货图，就是我弄出来的，也是最近 Image 2 的最火玩法。

第一步，我先在 Lovart 里调出最新的 GPT Image 2，让它生成一个潘金莲在抖音直播卖武大郎炊饼的场景。

![](img/d1fdee59a90154fdc0477d69747f0383.png)

结果一出来，我真的跪了。

这光影，这皮肤的质感，还有那惟妙惟肖的抖音 UI 界面，连右下角的购物车链接都像模像样。

但是，看着看着我感觉不够味。

小潘怎么能穿现代装呢？卖炊饼必须得有那种大宋风情啊，我发现是我提示词没要求古装风格。

简单，输入指令：换一套古装。

![](img/23f9d9dde2c3e5bd83e321a8d4a7096a.png)

只能说，太精准了。

除了人物服装及形象，其他全都没有变！连她手里拿着的那块炊饼的角度，都分毫不差。

我一细看，不对。

左上角那个抖音号的头像，还是现代的头像，这不穿帮了吗？

强迫症发作，我用 Touch Edit 局部重绘，把它改成了古装头像。

![](img/8bf6eeebe81f8aebc5b48c5d8841fc28.png)

完美。

![](img/3fece48bbf06571b59d4c214057e2e8e.png)

既然已经有了直播画面，那就干脆跑个视频吧。

我直接 Lovart 调用图生视频，一句话把它转成了视频。

一个小潘活灵活现叫卖烧饼的视频，就这么诞生了。

视频详情

既然小潘都来了，那干脆多出点镜。我又让 GPT Image 2 设计了一个国风手游《金瓶梅》的新手抽卡页面，当期 SSR 角色就是潘金莲。

![](img/0f8f91649b85fa0bf56d1eb880013266.png)

画风极其华丽，属性面板、技能描述、甚至连抽卡按钮的质感都拉满了。

![](img/3af82a066436fead046dd9c1aed69b56.png)

然后，还在 Lovart 中用 Seedance 2.0 把这张图生成了视频。

她背后那些复杂的灯效、漂浮的花瓣，甚至连抽卡机的光效都配上了音效。

这就是现在的 AI 工作流，一张图，一套组合拳，直接给你手搓出一个商业级的 Demo。

**城市宣传海报直出**

玩够了搞怪的，咱们来点正经的商业设计。

我在 Lovart 里输入了在 X 上来来的玩法：

![](img/f1c2cc96eb3f4dcdaf0bf2a299923f55.png)

GPT Image 2 给出的结果相当有设计感：

![](img/c6291361cbb73340f9ec8ee1599bc406.png)

云雾缭绕，仙气缥缈。国潮手绘风格与现代地标完美融合，SPRING 2026 和竖排宣传语的排版极其优雅。

如果这个很中意，之前介绍过，在 Lovart 中，它还支持直接导出 PSD 分层文件。

![](img/8231fefe5f4185a11c9063215c20101c.png)

这就意味着你可以直接把 PSD 交给设计师同事去改。

现在呢？一句 Prompt 直出，连排版带图层给你分得明明白白，在专业图像编辑工具里直接微调图层、改字体，不用重新生成，不用重新排版。简直是效率的超级飞升。

不仅如此。

把它放在真实的广告灯箱上看看是什么效果呢？

如果你记得 Lovart 的 Mockup 样机功能，就知道这时候该用上它了。

找一张电梯广告牌的实拍背景图，点击 Mockup。

![](img/d414010af9437dc1df114fb0bf6d902b.png)

然后把刚才那张广州的海报拖进去，一键合成。

![](img/61cd3ec72482de9185a15af8ee74b60e.png)

贴合得就像是 AI 自动计算了广告牌的物理尺寸，还计算了周围金属墙壁的光线折射。太贴合了，简直是实拍级别。

![](img/89de86e914f925bcf183fcdc28f98f7b.png)

我觉得这风格太棒了，我想做更多城市的。但每次都写这么长的 Prompt 太反人类了。

正好，Lovart 支持把一次满意的创作对话，直接保存成可复用的 Skill。

还是老步骤，开启思考模式。然后在 Skill Book 里点击创建 Skill。Lovart 会自动从我刚才的对话里，把双重曝光、S 型构图的底层逻辑给提取出来。

![](img/45df6f05a5ce0f1eff5d7c43c3a61cd9.png)

保存之后，在 Skill Book 里就能随时调用了。

![](img/c19a0ff7e90c3d1e861f8c64982795cc.png)

接下来，我只要点击这个 Skill，填入城市名字，以及对应的信息。

![](img/b97e13603dc1382466abb6df1f435472.png)

一会，相同风格的北京海报和西安海报就生成了，都非常好看。

![](img/07f8e6b27c0c5dac8c019498ae84cefb.png)

只能说，有了这个技能封装，再生成类似的东西，不用再写繁琐的提示词。速度快了很多，而且质量完全没有降低。

这就叫工具的杠杆率。

**时光穿梭：怀旧网站**

为了测试这玩意对年代感和冷门知识的还原度，我又做了一个中国 80 年代怀旧网站的页面。

![](img/3110b78e13d252ff6f6c0d71473f80ec.png)

大家知道，生成现代极其精美的图不难，但生成那种带有粗糙历史颗粒感的东西，极难。

但我拿到图的那一刻。

只能说，细节太多，回忆满满啊。

那种中国八十年代信息网的大字报式横幅、经典的 16 色像素图标、Win95 时代的按钮质感。

这感觉太对了！

![](img/89b68282b6306e7443d3576632e7ff6c.png)

基于这个，我又用 Lovart 把这段对话提取成了 Skill，顺手跑了一大堆当时流行的 BBS 论坛和聊天室的截图。

![](img/b539f61a495cf82ca2be55e4a40c9333.png)

![](img/a11497140071cacaa5a18c75c170fe1a.png)

看着图里那些长城居士、海风轻轻的 ID，看着那些绿色的代码字体。

我感觉回到了轻舞飞扬和痞子菜的年代，它不仅懂画画，还懂时代。

**商业套图与精准换装**

接着，咱们来看看电商和自媒体人最头疼的排版图。

我用 lovart 自带的官方 Skill 生成了一套大疆 Pocket 4 的亚马逊产品套图。

![](img/cf86ff2690177d741ee753df6cafcaf9.png)

主图、卖点图、使用场景图，排版极其清晰，文字基本准确。这种效率，那些靠外包做详情页的电商老板看了估计要沉默。

![](img/72aa3facf764cb19bcabc5a4006f1381.png)

然后，我又让它生成了一张网红美女的一周穿搭指南。

![](img/2e31433ef1d0e6b57b6f1dfee466d838.png)

包含 7 列内容，从周一到周日，每日详细穿搭形象、配饰缩略图、配色方案、穿搭说明文字，全中文显示，字迹清晰。

![](img/f92eb2667f7060b0fffb4dc0c745a387.png)

如果你对里面某天的风格不喜欢，比如周日的运动风，你想换成去海边玩的。

简单。

用上 Lovart 的精准编辑 Touch Edit，框选周日那一列，输入修改为度假休闲风。

![](img/f39496cb4690ad7656e1d6b904b03e26.png)

两秒钟后，原本的瑜伽裤变成了飘逸的长裙，连带下面的配饰缩略图里的运动鞋都变成了沙滩草帽。

![](img/8a1049f42076986aa0ac0da99cdd28c4.png)

精准修改，完美！

**以假乱真的文档与回单**

最后两个案例，稍微有点邪修，但也最能说明问题。

我试了一个试卷生成的效果。

提示词：照片级逼真的南阳市高一数学试卷,包含米白色微皱纸张质感、黑色文字、真实文档摄影效果。

生出来的图，大家自己看吧。

然后，我通过 Lovart 的文字修改功能，直接把标题里的南阳市改成了玉林市。

![](img/1d97d5dbd475e40123d7319090dbbbdc.png)

一点 PS 痕迹都没有。

**最后一个案例，我想用实证**告诉大家，从今往后，什么图都不要信。

![](img/4985a26587e683dea4475b1675e2caa6.png)

生成的图片带公章，带流水号，带银行公章。

我想了想，还是不放了图片了，避免带来不必要的麻烦。

因为已经到了无法分辨真假的程度。
