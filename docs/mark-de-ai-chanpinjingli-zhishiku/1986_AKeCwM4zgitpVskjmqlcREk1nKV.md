# 北京校招_互联网大厂汇总

## 头部互联网企业（第一类）

字节跳动（海淀区）：全球知名的互联网科技公司，旗下拥有抖音、今日头条、TikTok等多款热门产品，以算法推荐和短视频业务为核心，业务覆盖内容、社交、游戏、教育等领域。

京东（通州区）：中国最大的自营电商企业之一，业务涵盖零售、物流、科技、健康等领域，总部位于北京亦庄经济开发区。阿里巴巴（朝阳区）：全球电商与云计算巨头，核心业务包括淘宝、天猫、阿里云、钉钉等，在北京设有多个重要业务部门和研发中心。

腾讯（海淀区）：以社交、游戏、云计算、文娱等业务为主的科技公司，旗下包括🛰️、🐧、腾讯云、腾讯视频等产品，在北京设有多个办公室与研究院。

百度（海淀区）：中国领先的搜索引擎公司，业务拓展至人工智能、自动驾驶（Apollo）、智能云、大数据等领域，积极推进AI产业化落地。

华为（昌平区）：全球领先的信息与通信技术（ICT）基础设施和智能终端提供商，在北京重点布局通信研发、云计算、智能汽车解决方案等业务。

美团（朝阳区）：领先的生活服务电子商务平台，主要业务包括外卖、到店、酒店旅游、出行等，构建本地生活服务生态。

## 中型互联网与创新企业（第二类）

小米（海淀区）：以智能手机、IoT设备为核心的科技公司，构建智能硬件生态链，并积极拓展汽车等新业务。

网易（海淀区）：业务涵盖游戏、音乐（网易云音乐）、教育、传媒等多个领域，是中国重要的互联网内容与服务提供商。

📕（朝阳区）：生活方式社区与电商平台，用户通过图文、短视频分享生活经验与消费心得。

快手（海淀区）：短视频与直播社交平台，致力于打造内容社区与电商闭环生态。

滴滴出行（丰台区）：提供网约车、顺风车、共享单车、自动驾驶等出行服务。

新浪🧣（海淀区）：中国最具影响力的社交媒体平台之一，集热点讨论、娱乐、视频等内容于一体。

搜狐（海淀区）：老牌互联网媒体公司，业务覆盖新闻、视频、游戏、信息检索等。

凤凰网（朝阳区）：面向全球华人的综合媒体集团，提供新闻、视频、财经等多类内容。

## 垂直领域代表企业（第三类）

### 文化娱乐与社区平台

+   豆瓣（东城区）：文艺社区平台，涵盖书籍、影视、音乐评论与小组交流。

+   B站（朝阳区）：年轻人喜爱的视频社区，以ACG、知识、生活类内容为主。

+   爱奇艺（海淀区）：领先的综合在线视频平台，提供影视、综艺、动漫等内容。

+   知乎（海淀区）：高质量问答社区与内容平台，覆盖多个专业领域。

+   🐧音乐（东城区）：腾讯旗下音乐流媒体服务商，提供音乐播放与社区功能。

+   掌阅科技（海淀区）：数字阅读平台，提供电子书与原创文学内容。

### 房产与汽车服务

+   贝壳（朝阳区）：房产交易与服务平台，提供二手房、新房、租赁等服务。

+   汽车之家（海淀区）：汽车消费与生活服务平台，内容涵盖资讯、评测、社区等。

### 手机/通信类企业

+   OPPO、vivo：智能终端设备制造与服务企业。

+   中兴：综合通信解决方案提供商。

+   瑞斯康达：光传输与接入设备供应商。

+   奕斯特：聚焦通信与集成电路设计。

+   京东方（BOE）：全球半导体显示产品龙头企业。

### 新能源汽车企业

+   特斯拉：电动汽车与清洁能源公司。

+   蔚来汽车：智能电动汽车制造商，注重用户体验与服务生态。

+   理想汽车：专注于增程式智能电动SUV的研发与制造。

+   小鹏汽车：智能电动汽车公司，强调自动驾驶与智能座舱技术。

### 人工智能与芯片企业

+   旷视科技、商汤科技、依图科技：计算机视觉与AI算法代表性企业。

+   第四范式：聚焦企业级AI解决方案。

+   云知声：专注语音人工智能技术。

+   地平线、寒武纪：AI芯片设计与研发企业。

+   格灵深瞳：计算机视觉技术公司，深耕安防、零售等领域。

+   中星微电子：多媒体芯片研发企业。

+   深鉴科技（已被收购）：曾专注于深度学习加速解决方案。

+   遥感科技：AI遥感数据处理与分析服务商。

+   九识（Nreal）：AR眼镜与内容生态开发商。

### 外企互联网与科技公司

+   微软：软件、云服务与人工智能全球巨头。

+   Google：在北京设研发与业务团队，聚焦AI、广告与开发者生态。

+   Amazon：电商与AWS云计算服务的重要基地。
