# 贡献者 FAQ

> 来源：[https://deepwisdom.feishu.cn/docx/AH5Cd5Gu6ofug3xqaDwcSZ4Ynzc](https://deepwisdom.feishu.cn/docx/AH5Cd5Gu6ofug3xqaDwcSZ4Ynzc)

### 如何让维护者修改我的 PR？

通常，我们建议审查者首先通过评论对 PR 提供反馈，然后提交者再次提交以进行迭代并获得合格的 PR。在特殊情况下，维护者也可以直接修改 PR 以更快地合并。

你可以在 PR 页面右侧的[允许维护者编辑和访问机密]选项上打勾，以允许维护者直接修改你的 PR。如果遇到权限问题，你可以参考 GitHub 允许对 PR 进行修改的相关规定。

### 为什么我的 issue 或 PR 被关闭了？

一般来说，有以下几种情况：

1.  Issue 或 PR 已经过时（30 天）且创建者没有跟进。

1.  Issue 已经解决，无需跟进。

1.  PR 内容已在其他已合并的 PR 中实现，无需再次提交。

1.  内容严重不符合 issue 或 PR 创建模板格式或行为准则。

通常，我们会在关闭之前做出回应并解释原因。如有必要，创建者可以再次打开它，并欢迎继续讨论。

### 我必须按照 Issue 或 PR 模板格式填写并创建吗？

我们强烈建议创建者按照相应的模板格式提交，这将有助于我们更清楚地了解 issue 或 PR，并帮助我们更有效地跟进。

如果模板中缺少某些内容，也是可以接受的。总的来说，我们希望创建者提供尽可能完整的信息。

### 为什么我的 issue 或 PR 没有得到回应？

我们[贡献者指南](https://deepwisdom.feishu.cn/wiki/Oimhwi4M7iJsjQkhD79cv6Ucnqb)安排工程师定期检查并及时跟进 issue 或 PR 的新更新。但是，由于时间安排和复杂性问题，可能会有一些延迟。如果你清楚你的 issue 或 PR 涉及的模块，你可以直接在 中邀请 [参考审查者]。此外，你还可以在 Discord 或微信群中发布相应的 issue 或 PR 进行讨论。
