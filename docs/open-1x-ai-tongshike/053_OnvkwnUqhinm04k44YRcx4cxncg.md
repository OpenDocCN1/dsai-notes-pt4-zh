# 文本AI使用推荐工具

## 文心一言

### 简介

百度推出的在线AI智能对话工具，具备文本理解与输出、逻辑推理、图片生成能力，搭配插件使用可以解锁文档解析、图片解析等功能。目前分为4.0版本（付费）以及3.5版本（免费），3.5版本至多可选择3个插件。它可以直接发送指令，风格可以包括在指令中，但目前不支持设置参数，默认生成一张，升级4.0付费版之后可以一次生成4张。

### 使用

![](img/0d70d8f53e693e0979edb903d8685f7c.png)

文心一眼的特点有：

+   注重情感表达与意境营造：强调情感与文辞的和谐统一，注重通过文字来传达细腻的情感和营造深远的意境，让读者能够感受到作品所蕴含的情感共鸣和独特韵味，类似于中国传统文学中对 “意境” 的追求，使作品更具感染力和艺术价值。

+   善于运用意象：擅长使用意象来表达抽象的概念和情感，借助自然景物、历史典故等元素，使文字更加生动形象，富有诗意，让读者在阅读过程中能够通过联想和想象更好地理解和感受作品的内涵。

## [秘塔写作猫](https://xiezuocat.com/)

### 简介

不仅支持中文写作，还支持英文等多种语言，满足不同用户的需求。它可以一键生成文案和智能配图，能够基于输入的关键信息自动生成文案，并推荐合适的图片，增强内容的吸引力。同时，还具备文本纠错和润色功能，自动检测并纠正文本中的错误，提升写作质量。

### 使用

点击AI写作可以看到下面的文体，根据需要选择：

![](img/90440a28a40a4bf6bc29bbcdd4dc2b95.png)

秘塔写作猫的优势在于

+   多种写作模式支持：涵盖说明文、议论文、故事文等多种写作模式，无论何种类型文本，均可按需为用户给予写作指导与建议.

+   可靠的语法和拼写纠正：内置强大的语法和拼写检查功能，可及时捕捉并修正文章中的语法错误与拼写错误，有效提升文章的准确性和质量.

秘塔写作猫主要应用于议论文，论文的写作，由于篇幅限制，这里就让读者进行后续的尝试。

## [Kimi](https://kimi.moonshot.cn/)

### 简介

由月之暗面科技有限公司开发的AI聊天工具，支持长文本处理和多语言对话，提供高效、智能的交互体验。

### 使用

Kimi最主要的特点有：

1.  能够较好地处理长文本，理解其中的复杂逻辑和信息，这个 prompt 可以充分发挥其长文本处理优势

prompt语句：基于你对长文档的深度理解与分析能力，请详细剖析这份参考资料，提取关键观点、争议点以及潜在解决方案，并整合为一篇逻辑清晰、条理分明且专业度高的 2000 字总结文章，重点突出不同学者观点的对比与融合。
