# 第一步：了解 Datawhale

Datawhale成立于2018年——是国内AI领域最大的开源学习组织，汇聚了众多有开源精神和探索精神的开源贡献者，致力于构建开源学习社区，和学习者一起成长。

成立5年来，Datawhale开源学习成为全国知名的学习活动，覆盖了海内外2000多所院校，不断吸引具有影响力的顶尖学者、知名教授、企业家、青年贡献者等在此分享知识和远见，成为关注青年人才成长的主阵地，加快高校和产业的链接，持续推动青年AI人才培养。

# 第二步：了解【AI+X 高校行】

## ❤️ 初心

**AI+X 高校行活动 **融合人工智能企业最新技术与应用场景、Datawhale丰富的学习资源、以及高校创新火种，打造独特的AI学习体验，激发高校学生的学习热情和应用能力，促进AI与各高校专业交融。

> **AI+X：**希望将人工智能（AI）与各个学科和行业（X）结合，

> 激发无限潜力和创造力（X），让年轻人拥有更多可能性（X）

> **高校行**：把AI带到10座城市，100所高校，影响10000名高校师生

+   **对高校学生**：增强学生将理论与实践结合的能力，激发学习兴趣，提升在AI 领域的就业竞争力。

+   **对高校教师**：接触前沿的AI知识和案例，丰富教学内容，拓宽研究视野，提升科研成果的应用价值。

+   **对学校**：加速人工智能及相关学科的建设和发展，提升学校在该领域的影响力。

+   **对社会**：促进AI 人才教育培养，促进人工智能与各行各业的深度融合，推动技术创新和应用。

## ✨ 活动设计

![](img/259ee1554db5537ff08b035074dcfa31.png)

**（活动时长：1.5-2 小时）**

**设计理念：**

我们希望这个活动能更接地气，就是身边的同学/榜样和大家一起交流、学习、动手实践，这样更能互相激励和促进

+   **动手实践学 AI ？**

+   “大家不要有什么心理负担，动手学就是了”  —— 李沐

+   大模型动手实践项目和指导，提供免费算力等资源支持

+   **Datawhale 见面交流**

+   **我应该如何学？**

+   听听身边同学/ 学长学姐在用什么学习资源，按什么学习路线学，交流交流。认识一些志同道合的朋友。

+   **未来怎么就业？毕业能干啥？**

+   探讨如何找到自己的兴趣和热爱，追求理想的工作和生活。嘉宾分享，帮助打开视野，看到更多的可能性。

# 第三步：如何参与

## 🏫 高校：活动组织方

+   **1）安排活动场地：**学生能带电脑（最好有插座或者摆电脑的桌子）

+   **2）活动组织和宣传**：意思就是名字所示，物料准备（横幅、助教证书等）

+   **3）动手实践主讲人/助教：**先学习教程，然后带教其他同学

+   **4）活动主持人：**意思就是名字所示

+   **5）活动后宣传**：由高校团队负责整理宣传文章，Datawhale 会转发～

## 🐳 Datawhale：资源支持方

+   **1）动手实践教程：**精心打磨的教程，以及配套的技术辅导小哥哥

+   **2）活动流程 SOP**：有可参考的活动策划方案和组织经验分享

+   **3）活动物料**：海报（我们有模板），Datawhale 文创小礼品

+   **4）学习资源**：动手实践的算力、数据、任务场景等学习资源支持

+   **5）活动嘉宾**：邀请行业、学界专家、优秀学习者参与交流分享

# 第五步：我有其他问题

## 👩 活动人数

需要召集多少人？

+   往期活动我们在其他学校基本上都是 100 以上。

+   但每个学校情况不同，专业人数、学校规模、人工智能/计算机开设时间不同，所以能参与活动人数肯定会有差异

+   只要每次活动能组织到不少于 30 名同学参与，我们就会支持你来办活动。
