# 扣子空间怎么玩？现场笔记

## 网页

一键优化的按钮！优化提示词。

手机端、电脑端都可以显示网页。

局部修改和编辑的功能。

## 海报

文本的能力很强。

文字生成之后还能修改。用各种AI工具来修正。

先生成有趣的文案 -> 输出有意思的海报。

## 播客

文章/链接发进去看解说。

语气特别自然。

## PPT

一键生成。线上编辑。

## 文本

整活儿。**创意。**

## 其他玩法

基础文字创作 -> PPT、网页、海报、播客。

+   把播客链接加到网页里。

+   基于文本，制作网页、播客。

+   把图片/图片链接添加到网页中。

学习别人的方法。如何处理的。查看回放。

做同款的案例是很好的学习材料。
