## 如何将修改后的代码上传创空间发布？

> 需要先有一个创空间，

> 通过[谜撰：寻味(开发者版本)](https://modelscope.cn/studios/AgentScope/find_the_taste/summary)[创建游戏并复制创空间的步骤可见](https://datawhaler.feishu.cn/wiki/N2IowK6YkigGoJkydS8cNWBZnGc#Xg36d1RIqolMkdx9iWGcmJjrnAf) 🎮 零代码制作自己的游戏应用

> 直接创建空的创空间可见 [如何创建一个创空间？](https://datawhaler.feishu.cn/wiki/N2IowK6YkigGoJkydS8cNWBZnGc#STu2djFrgojiGzxQWZFcyZqnnRd)

1.  获取已有的代码，可以是[官方框架](https://github.com/modelscope/agentscope)，或是创空间代码，对代码进行修改和调试

1.  获取官方框架代码克隆命令：[agentscope](https://github.com/modelscope/agentscope)、modelscope-agent

![](img/802180a74dbbbc43701cc2a0f9cdc19f.png)

![](img/dd63566ccf26bbe44b9f1cad82025cbc.png)

1.  获取创空间代码克隆命令：可直接在克隆完成的页面获取，或进入【空间文件】-【下载创空间】获取

![](img/28f6d8b92669e41cc6c8ab065580f3e7.png)

![](img/6232a9f46004c2dc36725893180562c7.png)

![](img/c01c7128af48ac9ac1ade4ea2d5410a6.png)

![](img/ebd074a22f8053eefcb92e8bb4aff639.png)

![](img/dcd1a9cd87505312618333942eed0c23.png)

1.  **将相**关**代码 git clo**ne到本地或魔搭Notebook：

> 复制对应的git命令，在本地找一个文件夹，打开终端界面，粘贴命令并回车

> PS：若第一步直接git clone的是创空间的代码，这一步可省略

1.  克隆到本地

![](img/c94e0264855787e09177bffb64374063.png)

![](img/8ad9575368dabd1a24865057ebc4777f.png)

![](img/ddebd521d8c59a39e014c4a6ff47bf69.png)

1.  创建魔搭Notebook详见如何使用魔搭Notebook在线编程环境

1.  进行调试

1.  调试可能需要下载agentScope等库，复制的创空间使用python app.py运行代码

![](img/a680b7b60d8e66eab7f9ce0e5e508344.png)

1.  可能需运行如下命令安装相关包

```
pip install --upgrade pytorch-lightning
pip install --upgrade pip
pip install agentscope
pip install gradio
pip install dashscope
pip install colorist
pip install inquirer
pip install modelscope_studio
python app.py
```

![](img/67251489efda96345f4fd16fd1ab92de.png)

1.  修改后的代码复制到目标创空间目录下，将代码push到创空间中

![](img/7985b922f44cc4fc1cd89c1dcd5f510c.png)

然后使用如下命令将代码push到创空间

```
 cd 相应目录名
 git add .
 git status(此命令选用，是用于查看状态的，可能显示一堆信息)
 git commit -m &quot;随便写点啥&quot;
 git push
```

![](img/2f03002ab4784634ea64b68d5d96ca71.png)

![](img/8f1fa9ef96d5bfa276860b07e955a4fc.png)

1.  最后再刷新创空间，并【重启空间展示】即可

## 如何使用魔搭Notebook在线编程环境？

> 使用魔搭Notebook进行在线编程和调试！目前CPU环境都是长期免费的哟！

> 同时建议大家可以跑一跑官方示例代码！大胆地把运行结果贴出来！

> 开发赛事应用，从跑通官方案例开始！

1.  获取代码克隆命令，详见[获取已有的代码](https://datawhaler.feishu.cn/wiki/N2IowK6YkigGoJkydS8cNWBZnGc#XCNqdsZyIo3lzwxjUygcYWKHncc)

1.  打开[魔搭Notebook](https://modelscope.cn/my/mynotebook/preset)

![](img/346a1f50a6dca7907c7f3e1de298272b.png)

![](img/524d90d98f5626d599af8c2a90e03c95.png)

![](img/921f1d24f7fabf09394c6081974f16a2.png)

1.  可以使用魔搭Notebook在线尝试官方示例代码

官方代码详见：[notebook代码](https://github.com/modelscope/agentscope/tree/main/notebook)、[Examples](https://github.com/modelscope/agentscope/tree/main/examples)

![](img/b637109a8d55edc4acba7e81d0507733.png)

![](img/22e40847cf9e5a52571f740fc09c53a0.png)

> 注**意每次重新开启n**otebook时，除了 .ipynb 外的文件均会被清除，需确保每次在线编辑调试后的代码均push到相应的创空间，否则代码将丢失！！！

> pip安装的包和库也均需要重新安装，可通过如下命令安装相关环境：

```
git clone https://github.com/modelscope/agentscope.git

pip install --upgrade pip

pip install -e .

pip install -e .[distribute]
```

## 创空间发布失败怎么办？

> 通过一个问题示例，带大家了解要如何排查日志，并截取有效信息求助
