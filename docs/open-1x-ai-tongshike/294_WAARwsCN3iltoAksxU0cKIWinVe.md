### 赛题解读

1.  **赛题主题**：**K12教育**

1.  **开发者任务**：聚焦小学、初中、高中生的**学习或生活场景**，使用[**AppBuilder**](https://cloud.baidu.com/product/AppBuilder)创作AI原生应用

1.  **参考方向**：

+   **益智游戏**：**寓教于乐**，有趣好玩的益智游戏，帮助学生在玩中学到知识，如”成语接龙助手“；

+   **角色扮演**：通过角色，帮助学生更好地**学习理解知识点**，或帮助**家长和孩子互相理解**，如：

+   “诗人李白”、“教育专家孔子”、“数学家华罗庚”、“外国朋友Alice”；

+   **家长****：根据家**长的教育痛点创建应用，帮其提高效率，如：“生成口算题助手“、”看图写话助手“；

+   **家教**：创建帮助学生或家长答疑解惑、**提升学习效率**等类型的应用，如”地道英语对话帮手“等。

1.  **限制**：

+   参赛作品必须**紧扣K12主题**，不符合主题的作品将无法通过**审核**。

+   作品提交并通过审核后，**应用名称和应用描述不可更改**，请在提交作品前谨慎操作。

+   **提交的作品（**包含标题、描述、内容）要求正向积极，且必须遵守相关法律法规，安全合法合规。

+   **参赛者可以提交多个作**品，数量不限，但作品之间不得高度相似，否则主办方将不予审核通过。

+   **严禁以任何形式刷应用数据**，一经查实，将取消参赛者的参赛资格及评选资格。

+   [**评审方案**](https://datawhaler.feishu.cn/wiki/UgjawQdu9iQnwfkFIy9c4fGInTf#FK9tdxFFGoJnKTxT6tAcXnponyd)：

AI Agent基础概念

![](img/e8b1e93c008438814f9f72edcb6a724e.png)

![](img/4c5eea11ae7d3eb29d3820bb8120980e.png)

![](img/3f3c5d8b0336e95a7d7fdeacb34c3a49.png)

![](img/b4522e32ff006baa8ecde5bb9115f3cc.png)

https://arxiv.org/abs/2309.07864

OpenAI应用研究主管翁丽莲(Lilian Weng)撰写过一**篇blog: LLM Powered Au**tonomous Agents，将 Agents 定义为LLM + memory + planning skills + tool use，即大语言模型、记忆、任务规划、工具使用的集合。

其中，LLM是Agent的大脑，属于“中枢”模型，要求有以下3种能力：

1.  planning skills：对问题进行拆解得到解决路径，既进行任务规划

1.  tool use：评估自己所需的工具，进行工具选择，并生成调用工具请求

1.  memory：短期记忆包括工具的返回值，已经完成的推理路径；长期记忆包括可访问的外部长期存储，例如知识库
