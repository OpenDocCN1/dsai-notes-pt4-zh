### 你知道刚刚发生了什么吗？

> 刚刚我们跑通了 Baseline，想必你一定很好奇这背后发生了什么吧？

> 在学习的过程中，不单单要知道如何做，更要知道为什么要这样做。这样我们在遇到同类型的问题时，才能举一反三。

> 一般情况下，拿到一个赛题之后，我们需要明确：

> 1）这是一个什么场景下的赛题；

> 2）这个赛题要解决什么问题。

> 深度思考这些问题，既能帮助我们更好地解决相关问题，更能让我们在后续遇到相关问题时，更好地完成迁移。

>

### 本次学习活动的关联赛题是一个 **CV问题**

> CV 通常指的是计算机视觉（Computer Vision），它是人工智能的一个分支，专注于使计算机能够从图像或多维数据中解释和理解视觉信息。计算机视觉的应用包括图像识别、物体检测、场景重建等。

>

> 本次CV任务较为特殊，属于**图像识别分类**的一个分支，赛题任务是【开发并优化Deepfake图像检测模型】

## 什么是 Kaggle、Jupyter Notebook、Python、CV、深度学习？

+   **Kaggle** 是一个在线平台，提供数据科学和机器学习竞赛、数据集、工具和学习资源。

**数据科学家和**机器学习工程师可以在Kaggle上参与各种竞赛，解决实际问题，并分享他们的代码和模型。

**Kaggle**上可以创建云端运行的代码环境，运行 Jupyter Notebook 文件

+   **Jupyter ****Notebook**** **是一个开源的 Web 应用程序，允许用户创建和共享包含实时代码、方程、可视化和解释性文本的文档。

它广泛用于数据清理和转换、数值模拟、统计建模、机器学习等领**域。我们的 **Baseline 就是上传在Kaggle上面的一个Notebook，复制并 start session后我们可以运行Python代码，也可以学习到其他的人的代码。在Notebook中我们可以查看到这个代码的输入（Input），输出（Output）和日志（Logs）。

![](img/fec3f7bf7f6b1fde088313c0a43cb91c.png)

+   **Python** 是一种广泛使用的高级编程语言，以其清晰的语法和代码可读性而闻名。

Python 支持多种编程范式，包括面向对象、命令式、函数式和过程式编程。它在数据科学、机器学习、Web开发、自动化脚本等领域中非常流行

+   **深度学习**是机器学习的一个子领域，它使用类似于人脑中的神经网络结构的人工神经网络来模拟和解决复杂问题。深度学习在图像识别、语音识别、自然语言处理和其他许多领域中表现出色，是当前人工智能研究的热点之一
