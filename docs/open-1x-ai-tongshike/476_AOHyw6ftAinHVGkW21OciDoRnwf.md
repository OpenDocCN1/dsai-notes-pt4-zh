## 8.2上分交流会QA汇总

| Question | Answer |
| --- | --- |
| 电力价格使用`ABM`就可以完全捕捉到所有信息吗？ | 不一定，还可能需要天气风力，水利和降雨之类的数据帮助机组做额外的一些决策 |
| 搭建模型后，如果出现了截断差（在一个阶段里都是2、300，一个小时后突然变成-80），这个应该怎么处理？ | 可以通过观察负价出现的时间段，比如如果考虑到在节假日出现的情况，可以通过调整它在节假日的影响因子去影响报价，在构建离散特征的时候通过0或1来分开之后再进行判断 |
| 光辐量和温度是相关的能不能作为影响因子？怎么计算呢？ | 光辐量可能不是最重要的，最重要的可能是光辐再市场中的一个价格，价格基本可以反映到火电的价格上的。 |
| 代码能力太弱了，该怎么去学习才能将自己的思路转化为代码呢？ | 可以提供一个思路给你，刚开始上手ai的时候，可以将每一个节点的输入输出都写下来，即使你不知道中间可能是由神经网络处理输出的，但是你可以想象有一个黑盒，它帮助你实现这个过程，后面就是不断地实现配合，然后通过学习不断地积累比如数据序列，探索比较基础的多层感知机来训练，然后不断地实现白盒化，然后你的方法就会越来越多了。 |
| 在时间序列的尝试中，我做了一个`LSTM`简单的模型，预测效果很不好是为什么？ | 因为我们的测试集是有03年7月1号到04年4月18号这么一个长的时间段，`LSTM`预测这种长序列的话`LSTM`效果不是很好。 |
| 有没有比较好的特征因子可以让预测效果有明显提升的，或者有什么方法可以找到该特征因子呢？ | 有一个名叫`TOAD`的库可以很好的挖掘，它可以根据区分度之类的帮你做特征筛选，筛选到只剩一两个关键特征。 |
| 数据里面的负电价是什么情况？ | 一个主要原因是当日的总负荷太低了，电量卖不出去，又因为发电机组厂商由于有人员管理，水电的成本，而且发电机组不是像我们现实中的电脑一样随意开关，考虑到这些成本所以电是由无仓储性的，所以为了保证电量能卖得出去，会将电以一个很低的价格卖出去。 |
| 在时间序列方法中，采用华北地区的北京地区的数据，并且加入了降水量，辐照日射，风速的特征列，但是由于数据不好找，只找到了每个月的历史平均数据，但是结果不但没有什么明显的变化，甚至出现了更差的结果这是为什么呢？气象数据为一个月一次的 | 这个考虑到的是频率太低了，因为电力交易县官资产交易频率是15分钟一次，就是说数据是一小时变动一次，直接用三月的平均数据模糊的模拟气象变化可能会误导模型。 |
| 该如何构造一个比较好的线下验证策略 | 可以借鉴一下金融风控方面的机器学习相关的思路，就是分一个分一个时间外样本截取验证集，就比如从验证集开始和训练集分段之间的一个月，例如选取23年9月份开始作为验证集，训练集就可以截取一个23年8月份到9月份这一部分作为一个时间样本，因为这一部分距离我们预测的时间节点比较接近,拿来做预测可能比较更加实际的效果 |
| 对影响因子的确定有点疑惑，是随机产生的还是根据计算计算计算出来的？ | 比较常用的就是一般最开始是根据经验或者随机出来，然后根据视神经网络训练出来，通过训练集在每一次迭代过程中，通过梯度下降更新参数。 |
| 在训练数据和测试数据分布差异很大的时候常规操作就是把分布差异大的这个特征给删除掉以保持训练数据和测试数据在同分布的情况下，但是因为有的时候这个差异很大有有时候差异又很小，该怎么去量化是否同分布的这样一个标准呢？ | |

| 代码里计算`sorted_unit`的累计和以及找到一个满足总需求的机组报价有什么用呢？ | 每个电力市场都有电力需求，我们从煤炭成本最低的发电厂开始累计找到花费最低的满足电力需求的组合，再经过乘上煤炭价格，也就是找到了市场出清价格。 |
| 关于`"Not a directory: data/"`....的报错 | 这个是因为代码是按照`unit`和`electricity price`两个数据集文件放在一个和主函数放在同根目录下叫做`data`的文件夹操作的，解决方法为创建`data`文件夹，并将两个数据集放在里面，或者检查自己的文件夹名字是否正确？ |
| 数据集有什么使用规范？ | 赛方提供的数据可以自由使用，可以使用外部数据（但必须是公开可访问的），并且最后审核要提供来源链接。 |
| 为什么选择`ABM`，而不是其他算法 | 这个主要源于赛方在任务中提到“期待选手使用`ABM`模型刻画市场主体博弈行为”。虽然比赛用时间序列也可以做，但第一次比较规模的AI+社会科学比赛，我们希望这个教程能多提供尝试其他方法的可能性，而单纯做时间序列教程的话和往期教程重合度较高。当然最终比赛的评价不会倾向于哪种算法，即不会因为使用了`ABM`就比同等分数下时间序列方案的评价高。 |
| 数学建模国赛问题可以用`ABM`模型吗？  （哪些类问题才适合考虑该模型） | 数学建模国赛当然是可以使用`ABM`模型的，一般会在B题或C题中出现。以往的国赛题目有考察元胞自动机和博弈的任务，比如以前的一个老题穿越沙漠，其实就是多主体博弈的模型。另外，近年的C题也有考察的趋势，重点仍然是在数据问题当中考察多个主体的优化。 |
| 为什么要叫AI+经济呢？具体哪里涉及到AI呢？ | AI+经济主要源于这次比赛的主题。本届是第一次设立社会科学赛道，并将背景放在了市场主体博弈上，赛方提供了机组信息帮助能刻画主体的博弈来模拟现实的市场出清，在这方面可以尝试一些AI方法如多智能体强化学习。 |
| 如果假设`agent`是理性人，`agent`可以知道哪些信息，又应该怎么做决策，这个问题想得到解答 | 理性决策往往是一个理论模型，在现实的交易模型当中其实很多条件不满足理性。如果是一个理性决策，那么它对未来数据的变化应该是要充分已知的，并且能够完备地告诉你这个决策过程受哪些因素影响。而我们在实际建模的过程中，我们可能并不能100%地完整列出所有的影响因素，但是也OK，也可以去做这个模型。举个例子，比如我们之前做过一个题目是预测黄金和比特币的价格并给出交易策略，那么如果我是纯理性的决策，就应该是在信息全部透明的情况下做这个问题，我不需要去预测，因为未来的价格如何我是清清楚楚知道的。就是这个区别。 |
| 如果使用`abm`方法，那一个`agent`应该具有什么确定的行为 | 这个其实不同的人建模思路不太一样吧，可能比较个性化？ |
| 如何在不提交文件之前预估自己的分数 | 这个你可以用自己的数据集做一些切分，交叉验证可以有个初步的估计。 |
| 可以讲解一下：线性回归如何转换报价到现实市场出清价格吗？ | 一般来说现实机组的报价会考虑到很多因素，例如自身成本随发电量上升、启停成本、爬坡成本、发电效率、运维成本、标煤价。但我们没有这样的信息，只知道边际标煤耗和发电效率。因此我们尝试用线性回归将目前的边际成本信息拟合到真实的报价，也就是用模拟的价格拟合到真实的出清价格。 |
| 如何在不提交文件之前预估自己的分数？ | 可以做线下验证，这个方法有很多，比较常见的是将已知标签数据按一定比例切分为训练集和验证集，对训练集进行训练后对验证集进行预测，从而避免过拟合（前提是训练集、验证集、测试集分布相似）。当然也可以考虑使用交叉验证，时间序列的按时序分割等。 |
| 为什么耗煤量和价格之间的拟合函数使用线性回归 | 因为最简单，这也是叫`Baseline`的原因。 |
| 商家提交卖单之前知道市场需求量吗？ | 一般日前市场会给出第二天的24h总负荷预测，卖家可以根据不同时段的总负荷申报不同的价格。而在实时市场卖家会获知每个交易点的负荷。 |
| 能量转换效率是怎么影响到`agent`的定价决策的 | 发电成本=边际标煤耗x标煤单价÷锅炉效率+其他成本，能量转换效率越低，机组的成本就越高。也更加说明机组所属电厂应该市场力较弱，很难与大电厂抗衡，更可能采取跟随大部队报价的方式。 |
| task1 中 捕食者-被捕食者（`Predator-Prey`）模型 可以讲解一下吗？ | 捕食者-被捕食者模型实际上是一个微分方程组，详情可以参考《数学建模导论》第二章中的讲解。它其实也有几个版本。我举个例子： 海洋中有两种鱼类，一种肉食鱼类一种草食鱼类，那么如果不考虑捕食关系二者就应该是以逻辑斯蒂模型变化 |
| 可以给一个时间序列模型的脚本吗 | 可以参考这个[时间序列笔记](https://f0jb8szntbu.feishu.cn/docx/K6VedoAXBoLsvVxiXWqcYeZ1nPd?from=from_copylink)，Task3中也将会提供一个示例程序。 |
| `ABM`既然能解决原本的方程问题， 是否可以考虑只用`ABM` | 理论上是可以的，但是策略的设置与迭代方法其实需要很多经济学背景知识来支撑，还是要花点心思的哟 |
| `abm`在b站上的教程有点少，`abm`会对电脑性能要求很高吗 | 得看主体的个数和交互的规则，如果做很真实的`ABM`模拟，通常会需要跑满`CPU`好几天。如果是比较简单的策略，模拟步数较少的话会很快。 |
| `ABM`在TASK1里的体现在哪部分啊？边际成本吗？ | `Baseline`给的方案就相当于每个机组都不考虑其他机组和环境，只按自己边际成本报价，是非常简单的一个情况。 |
| 老师`abm`能具化解释他自己的经济逻辑吗 | |
| 有使用`docker`的教程吗，什么情况下适合用`docker` | `docker`这个可以到菜鸟教程上有简单使用方法。不过这里我们不需要用`docker`，其实我们打数据科学竞赛`docker`多半用不上，因为它本身就类似于虚拟化隔离起来的沙箱环境，一般是我们做服务器后台管理运维人员需要掌握的内容多一些 |
| + “假设机组突然报一个低价，原来边际成本是300元，现在报200元，最后发现市场以350元出清，导致自己损失了本来可能赚的150元” 这个描述是否有误？ | 市场以350元出清时，所有报价低于或等于350元的机组都会被调度成交，且成交价格为350元。也就是说，即使机组报200元，它仍然会以350元的价格成交。 |
