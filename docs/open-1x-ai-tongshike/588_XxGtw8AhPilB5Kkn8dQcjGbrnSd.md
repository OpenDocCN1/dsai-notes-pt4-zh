# Custom自订模式作曲：使用Meta标签标注歌词结构

Meta标签有以下几种：

+   Intro：前奏

+   Verse：主歌，4-8行

+   Pre-Chorus：过渡（可选）

+   Chorus：副歌，重复性旋律

+   Break：间奏，纯音乐

+   Bridge：转折点，

+   Outro：尾奏

使用GPT创建歌词：

> **你**:

> 你是一位才华横溢的歌词创作大师，请你写一首带有文青风的歌词，描述一个都市女生虽然物质生活没啥有很充裕，但是生活中很多小确幸，让她觉得心满意足（请你在歌词中多举几个例子）。

> 音乐的风格是流行民谣风、并带有一些Lo-f和R&B的元素。

> 歌曲的结构是[Verse1]-[Chorus]-[Verse2]-[Chorus]-[Bridge]-[Chorus]-[Outro](结构标签两旁要加上方括号)
