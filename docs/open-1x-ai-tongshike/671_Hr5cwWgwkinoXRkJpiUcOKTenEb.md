# Deepseek使用指南：提示词的演变

> 来源：[https://datawhaler.feishu.cn/docx/UupqdtgDzoIdSSxPDC3c1DBtnef](https://datawhaler.feishu.cn/docx/UupqdtgDzoIdSSxPDC3c1DBtnef)

# 一、前言

2024年可谓是AI技术爆发的一年。OpenAI 于年底推出了 ChatGPT o1首次赋予了生成式AI逻辑推理能力，宣告着推理模型的到来。而随后在2025年春节 DeepSeek-R1 的横空出世更是掀起了一股AI浪潮，让AI得以真正的进入国人眼中。但开发者们很快发现了一个棘手的问题：那些在通用模型（如GPT-4o、Claude 3.5）上效果显著的传统提示词，在面对具备推理能力的模型时，效果却不尽如人意。

# 二、传统提示词

传统提示词体系主要面向 ChatCPT-4o 、 Claude 3.5 sonnet 、Deepseek v3 等通用模型

## （一）传统框架

### 1、Co-STAR

+   **C (Context)**：背景信息

+   **O (Objective)**：任务目标

+   **S (Style)**：写作风格

+   **T (Tone)**：情感语调

+   **A (Audience)**：受众

+   **R (Response)**：响应格式

### 2、BROKE

+   **B (Background)：**背景信息

+   **R (Role)：**扮演角色

+   **O (Objectives)：**任务目标

+   K (Key Results)：关键结果

+   **E (Evolve)：**改进策略

### 3、CRISPE

+   C (Capacity and Role): 扮演角色

+   **I (Insight):** 背景信息

+   **S (Statement)：** 任务目标

+   **P** **(Personality)：**输出格式

+   **E** **(Experiment)：** 实验示例（如果不需要，可无）

## （二）传统提效提示词

### 1、思维链引导

"Let's think step by step"曾是模型理性推理的黄金法则，它通过强制分步思考，帮助通用模型规避跳跃性逻辑错误。

### 2、角色扮演

"你是XXX"这类角色设定明确定义AI助手的角色（比如让它扮演教师、医生或程序员），设定它的行为准则（如回答的语气和风格），以及规定它的工作范围和限制。这就像是在AI助手的"大脑"中植入了一个基础设定，指导它如何理解和回应用户的问题。

> 需要注意的是，论文 “Wh**en ‘A** Helpful Assistant’ Is Not Really Helpful: Personas in System Prompts Do Not Improve Performances of Large Language Models ”  [1] 提到在系统提示中添加角色对LLM回答事实性问题的准确率无显著提升，甚至可能轻微降低性能

### 3、少样本提示

少样本提示通过提供少量示例（如1-5个）和任务提示，引导模型执行特定任务，在文章创作等场景中实现风格拟合。其优势在于：

+   通过示例降低模型理解任务的成本

+   通过风格锚定减少输出的随机性

+   通过案例库构建可复用的提示模板

# 三、新型提示词

相比起其他的推理模型，Deepseek的推出导致提示词的变化更多，因此，本部分主要以Deepseek为讲解对象。

## （一）核心准则

早期的通用类模型需要用户一步步指导操作，但随着技术的发展，推理模型自己就懂“如何从问题推导到答案”。这时，再在提示词中人工拆解步骤就像强行给赛车装限速器。多位用户实操效果也表明：直接说需求反而比复杂模板生成质量更高。因此，用自然语言说人话，把思考过程交给AI，才是当前最优解。

## （二）要素公式

> 【身份】+【背景】+【目的】+（风格 / 禁忌）

其中：

+   **身份：**明确用户定位（如“我是一位大学生”）

+   **背景：**提供必要上下文（如“现在我要学习数据结构与算法”）

+   **目的：**聚焦核心需求（如“请你为我讲解排序算法”）

+   **风格 / 禁忌：**可选增强（如“请用日常场景进行类比讲解”）

**注意：**用户给到模型的信息越多，模型的表现越好

## （三）提示词要点

### 1、说人话：

Deepseek等推理模型所输出的回答通常信息密度、内容深度较大。为降低其信息密度，方便阅读理解，常用以“说人话”为代表的提示词，如要控制其降低的程度，可采用“我是小学生/初中生/高中生/大学生”来调控。

### 2、少样本提示

与先前的模型不同，Deepseek 的研究人员在论文 "DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning"  [2] 中提到 DeepSeek-R1 对提示非常敏感。少量提示一致地降低了其性能。因此，论文建议用户直接描述问题并使用零示例设置指定输出格式，以获得最佳结果。

# 四、结语

提示词能力终将成为每个人必备的数字素养。随着模型的发展，其理解能力和逻辑能力会越来越强，提示词的门槛势必会越来越低，但这并不表明提示词能力并不重要，它终将会化成每个人所应该拥有的能力。这就好比汽车刚出现的时候，汽车司机学习开车的难度大、门槛高，但是随着汽车产业的不断发展，如今的驾驶证已经变得非常普及，很多人都能轻松拥有。

从长远来看，我觉得有两个要点仍是非常重要的。第一个就是表达清晰。这就好比甲方和乙方对接工作，甲方得把自己的需求明明白白地告诉乙方，让乙方清楚知道要做什么、做到什么程度。只有这样，乙方才能更好地开展工作。第二个要点就是不断迭代。在工作过程中，乙方需要根据甲方的反馈，不断地调整和改进自己的工作，尽可能地贴合甲方的需求。提示词也是这个道理，我们要根据模型的特点和自己的需求，不断思考、尝试，让提示词变得更完善，这样才能更好地发挥模型的作用。

未来，随着模型理解能力、推理能力的增强，提示词可能形成更为简易的交互方式。但无论如何演进，其本质始终未变——提示词是人与AI协作的桥梁，而这座桥梁的稳固性，取决于我们对需求的洞察力与对技术的迭代力 。
