# 自注意力机制

##  自注意力机制在做什么

自注意力机制是Transformer的核心，我之前经常看到资料说自注意力是计算输入序列中所有元素之间的相关性。

看到过很多次这种言论，就是不理解这是在做什么，直到看到一篇文章给很详细的解释。

如下图所示，两个句子中，都有bank这个单词，但是这两个单词的意思截然不同，我们一眼就可以看明白，但是AI不行，要让AI明白这个单词在不同句子中的意思，我们就可以使用自注意力机制，自注意力机制经过计算bank和river之间的相关性，以及bank和money之间的相关性。便可以知道不同的两个句子中bank的意思究竟是什么。

![](img/1acb849fc1cb5f939a237719b2f1cb58.png)

例子2：

A dog ate the food because it was hungry

在这个句子中，it是一个指代词，我们通过自注意力机制，便可以知道it指代的是dog，因为dog和hungry的相关性最高。

![](img/3c63fbac06f895d581804b60252c70d6.png)

# 位置编码

transformer中另外一个核心的内容便是位置编码，位置编码使得大规模并行训练成为可能，也是因为大规模并行训练才出现了涌现，让我们可以看到一点AGI的曙光。

在transformer之前，处理序列任务，大部分使用地是RNN和LSTM，他们在处理序列时会将序列中地内容逐个输入神经网络，从而让神经网络去理解序列中文字地前后顺序，但是Transformer并没有采用这种方式，而是采用了位置编码地形式来表示每个词在句子中地位置。

假如我们有一个句子，I am good，我们可以得到他的嵌入矩阵如下（数值以及维度都是虚拟的）

![](img/d2c474f8e713a7e6b186427f82b39fd2.png)

我们创建一个矩阵P，矩阵P便是位置编码，我们将矩阵X与矩阵P相加，便可以得到一个新的X矩阵，此时新的X矩阵中，不仅包含了单词的信息，还包含了单词的位置信息。

![](img/270f516058b726ec9eac17d54dd5396a.png)

通过位置编码，我们便可以并行地将整个输入序列一次性输入到神经网络中，而不需要像RNN和LSTM那样逐个输入了，提高了效率地同时，也让模型尺寸变地更大，从而引发了这场LLM革命。

# 编码器

Transformer中地编码器，可以叠加多个，每个编码器中都包含多头注意力层，叠加和归一组件，前馈网络层，如下图所示

![](img/7ac325a7f59ff25fdab8f6550f413cdd.png)

多头自注意力层在前面已经介绍过了，下面我们介绍一下叠加和归一组件，和前馈网络层

## 叠加和归一组件

即叠加和归一组件同时连接一个子层的输入和输出，如图1-33所示（虚线部分）

同时连接多头注意力层的输入和输出，同时连接前馈网络层的输入和输出。

![](img/91c7434656aaf137b2bd4d28acfd3c58.png)

叠加和归一组件实际上包含一个残差连接与层的归一化。层的归一化可以防止每层的值剧烈变化，从而提高了模型的训练速度。

## 前馈网络层

前馈网络由两个有ReLU激活函数的全连接层组成。前馈网络的参数在句子的不同位置上是相同的，但在不同的编码器模块上是不同的。

# 解码器

解码器与编码器类似，编码器中叠加了多个编码器，而解码器中也是由多个解码器叠加而成。

在解码器中，每个解码器都有两个输入，一个是前一个解码器的输出，一个是编码器最终的输出，这与编码器是不同的。如下图所示。

![](img/8a1b635d21601b38dbb5ecdf54dc87ff.png)

解码器，由带掩码的多头注意力层，多头注意力层，以及前馈网络层组成，如下图所示

![](img/f00841f4d292c5d32ccc548902e2811a.png)

解码器的运行逻辑是词语接龙，每次运行后，都会输出输入句子+后面一个单词，之后再将解码器的输出重新送入解码器的中，直到解码器输出结束标记后才结束，如下图所示。

### 是什么

由上面的介绍可知，在解码器的运行过程中

时间步为1时，输入的值只有一个开始标记<sos>
