## 向量

对于线性代数的研究，我们先从线性代数的中心运算问题谈起。可以发现，线性代数的中心运算都是针对向量而言的。

如此，我们假设有两个向量 `v` 和 `w`，把这两个向量相加就得到 `v + w`，如此有了向量的加法；接着用数字 `c` 与 `d` 分别乘两个向量得到 `c v` 与 `d w`，如此有了向量的数乘；最后将加法和数乘这两种运算进行组合，就可以得到线性组合 `c v`。

### 一个重要问题

一个向量 `u`、`v`、`w`，它的线性组合是数乘 `c`。对于两个向量 `u`、`v`、`w`，它们的线性组合是 `c u + d v`。对于三个向量 `u`、`v`、`w`，它们的线性组合是 `c u + d v + e w`。

假设 `u`、`v`、`w` 是三维空间中的向量，且 `u`、`v`、`w` 不为零向量，可以发现：

1. 所有 `c u` 的组合形成一条通过原点的直线。

1. 所有 `c u + d v` 的组合形成一个通过原点的平面。

1. 所有 `c u + d v + e w` 的组合形成一整个三维空间（注意第三个向量 `w` 不能够与另外两个向量 `u`、`v` 共面）

## 矩阵

### 矩阵的概念

关于矩阵的概念，我们先从三个简单的向量开始谈起。这里给出三个向量如下所示：

三个向量 `u = [1, -1, 0]^T`、`v = [0, 1, -1]^T`、`w = [0, 0, 1]^T`

将这三个向量放到三维空间里，在三维空间里他们的线性组合是 `x1 u + x2 v + x3 w`，即

**向量组合** `x1 [1, -1, 0]^T + x2 [0, 1, -1]^T + x3 [0, 0, 1]^T = [x1, x2 - x1, x3 - x2]^T`

接下来我们就用矩阵将上面的形式进行变换，得到矩阵乘向量，即 `A x` 变成矩阵 `A` 的列，上面的线性组合进而变成矩阵 `A` 乘向量 `x`。

**矩阵乘向量，列的组合** `A x = [[1, 0, 0], [-1, 1, 0], [0, -1, 1]] [x1, x2, x3]^T = [x1, x2 - x1, x3 - x2]^T`

`A x = [[1, 0, 0], [-1, 1, 0], [0, -1, 1]] [x1, x2, x3]^T = [x1, x2 - x1, x3 - x2]^T = [b1, b2, b3]^T = b`

关于向量的组合转换为矩阵乘向量是列的组合。既然有列的组合，那么行的组合也可能会存在，从行的组合看矩阵，就是计算矩阵的每一行与向量 `x` 的点积：

`A x` 是行的点积

`A x = [[1, 0, 0], [-1, 1, 0], [0, -1, 1]] [x1, x2, x3]^T = [(1, 0, 0) · (x1, x2, x3), (-1, 1, 0) · (x1, x2, x3), (0, -1, 1) · (x1, x2, x3)]^T`

### 线性方程组思想

前面，我们都是数字 `b` 是已知，右侧的 `x` 未知，我们利用 `A` 乘 `x` 得到向量 `b` 的组合。

现在我们考虑向量 `b` 已知，要求解向量 `x`，这样就是一个求解线性方程组的问题。

原问题：计算线性组合 `A x`，求出 `b`。

新问题：什么样的 `x` 的线性组合可以产生特定的向量 `b`？

这是一个逆反问题——找出输入向量 `x` 得到想要的输出 `b`。

## 线性方程组

线性代数的中心问题是求解一个方程组（或称方程式系统）。

这些方程式是线性的，也就是说只会出现未知数乘以数字。

接下来，让我们先从简单的线性方程组谈起，只考虑有两个未知数的两个方程式的情况：

1. 从行图的角度来考虑线性方程组的解

> 行  行图显示两条直线交于一点(解)

1. 从列图的角度来考虑线性方程组的解

列图的角度即从向量列的线性组合的角度出发，将方程组表示成向量列的线性组合的形式：

向量的线性组合等于向量 `b`

`x [1, 3]^T + y [-2, 2]^T = [1, 11]^T = b`

上面等式的左边有两个列向量，这样求解线性方程组的问题就转变成了如何找到左边两个向量的线性组合等于右侧的输出向量 `b`。

将行图得到的结果（3，1）代入组合中，等式两边成立。

> 列  列图组合左侧的列向量产生右侧的向量 `b`

根据前面向量是如何得到矩阵的过程，我们可以将向量的列的组合进一步转化为系数矩阵 `A`。

方程式左侧的系数矩阵是 `A` 矩阵：

**系数矩阵** `A = [[1, -2], [3, 2]]`

结合前面所提到的方程式，我们可以将方程式转化为矩阵问题 `A x = b`：

**矩阵方程式** `A x = b` `[[1, -2], [3, 2]] [x, y]^T = [1, 11]^T`

将求得的方程组的解的数值代入，可得矩阵-向量乘法：

**行的点积，列的组合** `A x = b` `[[1, -2], [3, 2]] [3, 1]^T = [1, 11]^T`

### 矩阵表示法说明

我们先从简单的 2×2 矩阵谈起，一个 2×2 矩阵的第一行包含 `a11` 与 `a12`，第二行包含 `a21` 与 `a22`。

第一个下标表示行数，第二个下标表示列数，所以，`aij` 是第 `i` 行第 `j` 列所对应的单元。为了书写简单起见，可以将 `Aij` 写成 `A(i, j)`。

`A = [[a11, a12], [a21, a22]] = [[A(1, 1), A(1, 2)], [A(2, 1), A(2, 2)]]`

对于 `m×n` 的矩阵来说，行的下标 `i` 由 1 到 `m`，列的下标 `j` 由 1 最多到 `n`，总共有 `mn` 个单元 `aij`。

特殊地，一个 `n` 阶的方形矩阵有 `n^2` 个单元。
