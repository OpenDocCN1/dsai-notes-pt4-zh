# 1 什么是梯度下降

在非线性优化问题中，选择梯度方向（负梯度方向）作为迭代方向的**理论依据来自于最速下降法，其核心思想**是：在当前位置，沿着使目标函数下降最快的方向迭代，可以使误差收敛速度达到局部最优。

## 1.2 什么是梯度下降 Gradient Descent

梯度下降是一阶迭代优化算法，其核心思想是通过不断调整模型参数，使得损失函数最小化。

简单来说，就是**选取适当的初值** **，不断迭代更新** **的值，极小化目标函数直至收敛。**

> 在梯度下降算法中，每次迭代都涉及到计算当前参数位置的梯度，然后根据设定的步长调整参数。步长决定了每次更新的步伐大小，这一选择对算法收敛速度及效果至关重要。

### 1.3.1 固定学习率 VS 自适应步长

**固定学习率（** **为常数）：**步长完全由梯度模长决定。

缺点：在Hessian矩阵条件数大时，不同方向梯度差异大，可能导致震荡。

自适应步长（如Adam、RMSProp）：根据历史梯度动态调整等效学习率，间接控制步长。

优点：在不同方向自动适配步长，减少震荡，加速收敛。

### 1.3.2 学习率衰减

随着迭代进行逐步减小学习率 ，强制缩小步长，使参数在极值点附近精细调整。

例：求 ，求梯度下降的过程

```
import numpy as np

# 定义目标函数
def f(x, y):
    return x**2 + 3*y**2

# 定义目标函数的梯度
def grad_f(x, y):
    df_dx = 2*x  # 对x的偏导数
    df_dy = 6*y  # 对y的偏导数
    return np.array([df_dx, df_dy])

# 梯度下降算法
def gradient_descent(starting_point, learning_rate, num_iterations, epsilon):
    # starting_point 是一个包含初始 x 和 y 值的列表或数组
    x, y = starting_point
    
    for i in range(num_iterations):
        gradient = grad_f(x, y)
        
        # 更新参数
        x -= learning_rate * gradient[0]
        y -= learning_rate * gradient[1]
        
        # 打印当前迭代的参数和函数值
        print(f&quot;Iteration {i+1}: x = {x}, y = {y}, f(x, y) = {f(x, y)}&quot;)
        
        # 检查梯度的范数是否小于 epsilon
        if np.linalg.norm(gradient) &lt; epsilon:
            print(f&quot;Converged after {i+1} iterations.&quot;)
            break
    
    return x, y

# 算法参数
starting_point = [4.0, 6.0]  # 初始点
learning_rate = 0.1  # 学习率
num_iterations = 100  # 最大迭代次数
epsilon = 1e-6  # 收敛阈值

# 运行梯度下降算法
optimal_params = gradient_descent(starting_point, learning_rate, num_iterations, epsilon)
print(f&quot;Optimal parameters: x = {optimal_params[0]}, y = {optimal_params[1]}&quot;)
```

# 2 梯度下降的变体和优化算法

在机器学习中的无约束优化算法，除了梯度下降以外，还有最小二乘法，此外还有牛顿法和拟牛顿法。

> 梯度下降 VS 最小二乘法

> 梯度下降法是迭代求解，适合大规模数据集和高维优化问题，但需要调整学习率。

> 最小二乘法计算解析解，适合小规模数据集，且可以直接求解，但计算复杂度高。

**最小二乘法**

+   特点：

+   解析解：通过矩阵运算直接求解最优参数，公式为 。

+   不需要迭代：直接计算，不需要选择学习率。

+   优点：

+   计算速度快，精度高，适合样本量较小且特征维度较低的情况。

+   理论基础扎实，结果易于解释。

+   缺点：

+   计算复杂度高：需要计算 的逆矩阵，复杂度为 ，其中 n 是特征维度。

+   数值稳定性问题：当 不可逆（奇异矩阵）时，无法直接求解。

+   不适用于大规模数据集：随着样本量和特征维度的增加，计算量和存储需求会急剧上升。

**梯度下降法**

+   特点：

+   迭代求解：通过逐步迭代更新参数，每次迭代沿着负梯度方向移动。

+   需要学习率：学习率的选择至关重要。学习率过大可能导致不收敛，过小则收敛速度慢。

+   适用性：适合大规模数据集，因为每次迭代的计算复杂度较低。

+   优点：

+   实现简单，计算复杂度低（每次迭代只计算梯度）。

+   适合大规模数据集和高维参数优化。

+   缺点：

+   收敛速度可能较慢，尤其是接近最优解时。

+   可能陷入局部最小值或鞍点。

> 当样本量小，且存在解析解，最小二乘法优于梯度下降法，计算速度很快；

> 当样本量大，切最小二乘法需要求一个非常大的逆矩阵，此时使用迭代的梯度下降法更有优势

在梯度下降法的迭代中，除了梯度值本身的影响外，另一个很重要的参数是每次取的步长，且这个参数的选择非常重要：

+   步长值取得越大，收敛速度就会越快，但是带来的可能后果就是容易越过函数的最优点，导致发散；

+   步长取太小，算法的收敛速度又会明显降低。

我们希望找到一种比较好的方法能够平衡步长。

SGD

**优点**：训练速度快，适合在线学习，可能逃离局部极小（非凸优化）。

**缺点**：准确率下降，收敛不稳定，需精调学习率，不易于并行实现。

**MBGD**

优点：平衡计算效率和稳定性，适合GPU并行加速，广泛应用。

缺点：需调参选择 batch size，噪声可能影响收敛。

1.  **MBGD**：深度学习默认选择，batch size 通常取2的幂次（如64、128），充分利用GPU并行性。

# 3 代码实践和调参技巧

梯度下降是机器学习和深度学习中常用的优化算法之一，用于最小化损失函数并找到模型参数的最优解。以下是梯度下降调参的详细步骤和策略：

1.  **初始化参数**

+   随机初始化：参数的初始值可以随机设定，通常使用小的随机数，例如从标准正态分布中采样。

+   零初始化：在某些情况下，也可以将参数初始化为零向量，但这可能导致所有参数更新相同，尤其是在对称的网络结构中。

1.  **学习率调整**

+   固定学习率：适用于少量数据的简单模型或目标函数是凸函数的情况。

+   学习率衰减：通过逐步减小学习率来提高收敛速度和稳定性。常见的学习率衰减方法包括：

+   倒数衰减：学习率随迭代次数的增加而逐渐减小。

+   指数衰减：学习率以指数方式衰减。

+   余弦衰减：学习率按照余弦函数的形式变化，有助于稳定训练过程。

+   循环和重启：通过突然提高学习率来跳出局部最小值，例如使用学习率调度器在特定的迭代次数后重置学习率。

1.  **批量大小选择**

+   批量梯度下降（BGD）：使用整个数据集计算梯度，适合小型数据集。

+   随机梯度下降（SGD）：每次迭代只使用一个样本，适合大规模数据集。

+   小批量梯度下降（MBGD）：每次迭代使用一小部分样本（小批量），通常在32到256之间，适合大多数深度学习模型。

1.  **迭代次数确定**

+   固定迭代次数：设定一个固定的迭代次数，例如1000次。

+   动态停止条件：根据损失函数的变化来决定是否停止训练。例如，当损失函数的变化小于某个阈值（如1e-4）时停止训练。

1.  **正则化参数调整**

+   L2正则化：添加L2正则化项来防止过拟合，正则化参数（如λ）需要通过交叉验证来调整。

+   早停法（Early Stopping）：在训练过程中监控验证集的损失，当验证损失在连续几次迭代中没有改善时停止训练，以防止过拟合。

1.  **使用优化算法的高级特性**

+   动量（Momentum）：在梯度下降中引入动量项，帮助加速收敛并减少震荡。动量参数通常设置在0.8到0.99之间。

+   自适应学习率算法：使用如Adagrad、RMSprop、Adam等自适应学习率算法，这些算法能够自动调整每个参数的学习率。
