
# `OpenDuckMini`: 开源双足机器鸭演示

> 来源：[https://datawhaler.feishu.cn/docx/S8bOd7nfsoI8d3xz65bcf4HXnEg](https://datawhaler.feishu.cn/docx/S8bOd7nfsoI8d3xz65bcf4HXnEg)

<https://player.bilibili.com/player.html?bvid=1hxZnYfEjo>

开源双足鸭式机器人`OpenDuckMini`，白菜价舵机也能玩具身智能和强化学习！

经过两个星期的深入研究，我们完整复现并魔改了双足机器人开源项目`OpenDuckMini`。它基于舵机和3D打印，成本仅三四千块钱。可以跑Isaac Sim仿真训练、Mujoco物理引擎验证、sim2real具身智能部署、实时运行PPO强化学习算法，能够站立平衡不倒。也可以训练并部署自己的强化学习策略，接入自己的多模态大模型和AI小智语音交互。

就像英伟达老黄在GTC大会上演示的迪士尼机器人一样，带来互动陪伴和情绪价值。
