# **大主题：AI Infra**

>

> DOCA学习适宜人群：对AI网络感兴趣的开发者，包含networking/HPC/云/数据中心/边缘这些领域

>

> DOCA 能够快速创建应用程序和服务，以卸载、加速和隔离数据中心工作负载。

> 借助 DOCA， 开发者可以通过创建软件定义、云原生、DPU 和 SuperNIC 加速的服务，并支持零信任保护，从而满足现代数据中心的性能和安全需求。

>

> DOCA-Host 包含 NVIDIA BlueField 和 ConnectX® 设备所需的所有主机驱动和工具。
