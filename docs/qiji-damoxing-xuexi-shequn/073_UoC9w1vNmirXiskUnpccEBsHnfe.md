### Nathan Cooper分享“如何训练（合成）你的龙（数据）”：创建和使用合成数据

贡献人：

https://x.com/ncooper57/status/1846612127911760261

作为 @stabilityai 的首席研究员，我曾大量使用合成数据来训练大型语言模型（LLM）和视觉语言模型（VLM）。这是提升模型性能最被低估的方法之一。现在在 @answerdotai，我一直致力于让最佳实践变得更加简单——继续阅读以了解详情！

如何训练（合成）你的数据龙。

合成数据已成为大型语言模型（LLM）领域中的重要话题。Meta 最近在训练 Llama 3 模型时使用了 LLM 生成的数据，突显了这一趋势。本文分享了我在生成合成数据方面的实验经验，并介绍了我们的新库 fastdata，它使生成合成数据变得更加简单。

让我们从显而易见的问题开始：为什么大家对合成数据如此痴迷？

想象一下，能够为任何任务拥有一个庞大且完美的训练数据供应。这就是合成数据的承诺，而 LLM 正在使我们更接近这一现实。这些模型能够以极高的精度和控制力生成多样化、高质量的数据集。

合成数据的价值在于其可控性和多样性，与充满噪音的非结构化网络抓取数据形成鲜明对比。现代 LLM 展现出在给予适当提示时强大的指令遵循能力。结合其通过互联网上规模化文本数据训练的广泛知识，我们可以生成任何主题的合成数据，无论多么小众，并根据需求对其进行调整。

然而，创建有效的合成数据常常面临挑战。本文将探讨使用合成数据的挑战与机遇。我将分享一些实用见解，帮助你挖掘合成数据的潜力，并改变你处理数据驱动任务的方式。

### Mistral发布针对边缘设备优化的新AI模型

https://techcrunch.com/2024/10/16/mistral-releases-new-ai-models-optimized-for-edge-devices/

法国AI初创公司Mistral发布了其首批专为边缘设备（如笔记本电脑和手机）设计的生成式AI模型，命名为“Les Ministraux”。这些模型可用于各种应用场景，如文本生成、设备内翻译、无互联网智能助手、本地分析和自主机器人等。Les Ministraux系列包括两个模型：Ministral 3B和Ministral 8B，后者已可供研究用途下载。

Ministral模型的一个突出特点是其高效的计算能力和低延迟，能够在无需网络连接的情况下提供本地推理能力。Ministral 8B支持长达128,000个token的上下文窗口，能够处理大约50页书籍的内容。尽管目前主要用于研究目的，但有商业需求的公司和开发者可以联系Mistral获取许可。

该公司还提供通过其云平台La Platforme访问这些模型的选项，定价为每百万token（约75万字）10美分（Ministral 8B）和4美分（Ministral 3B）。Mistral声称其模型在多个AI基准测试中表现优于Meta的Llama和Google的Gemma等竞争对手模型。

### LatticeFlow发布LLM框架，首次评估大规模AI对欧盟AI法案的合规性

https://techcrunch.com/2024/10/16/latticeflows-llm-framework-takes-a-first-stab-at-benchmarking-big-ais-compliance-with-eu-ai-act/

**LatticeFlow AI****发布了首个旨**在评估大规模语言模型**（LLM）与欧盟**AI法案合规性的新框架，名为Compl-AI。该框架是瑞士联邦理工学院和保加利亚INSAIT研究所长期合作的成果，通过技术方式将法律要求映射到具体的AI评估中。Compl-AI不仅为开发者提供合规评估工具，还建立了一个AI模型的合规性排行榜，评估来自Meta、OpenAI、Anthropic等企业的模型是否符合欧盟AI法案的规定。

评估内容涵盖27个基准测试，包括“有害指令的完成情况”、“偏见回答”、“真相性”及“常识推理”等。结果显示，各大模型在拒绝有害指令和减少偏见方面表现较好，但在公平性和推荐一致性方面得分普遍较低，模型的合规性仍是一个混合表现。

LatticeFlow的框架虽然只是对AI法案的初步解读，但为未来合规评估奠定了基础，并且将随着欧盟AI法案的更新而改进。

### AI视频：海内外视频模型密集发布，API打开商业化空间

https://mp.weixin.qq.com/s/MYE_bzX1Xyedbhfzxn7Rkg

中信建投证券研究指出，近期全球视频模型密集发布，国产AI视频模型在可用度和性价比上赶超海外。6-10月间，超过10款视频模型进行了更新，包括快手可灵、智谱、PixVerse、Vidu、阿里万相、字节豆包等，海外的Runway、Luma等也发布了API接口。预计年内还有月之暗面、阶跃星辰等公司将发布视频模型。

技术趋势方面，AI视频模型在性能迭代上，动态效果更自然流畅，通过运镜增加画面动感。例如，快手可灵1.5模型在动态质量上显著提升，字节豆包视频模型在动作连贯性和运镜表现上突出。此外，AI视频功能创新，如视频编辑、音效匹配、个性化视频和视频特效等，提高视频生成的可控性和趣味性。

### GPT4o Realtime voice功能的复现路径

https://zhuanlan.zhihu.com/p/1387019285

**网络架构**：

+   **Speech Encoder** 使用Whisper-Large-3的编码器功能，将语音转化为语音表示（speech representations）。

+   **Speech Adaptor** 通过下采样匹配LLM的输入嵌入空间。

+   **LLM部分** 使用LLaMA-3.1-8b模型处理语音指令和生成文本回应。

+   **Speech Decoder** 通过上采样将LLM的输出转换为适合语音解码的格式。

+   **Vocoder** 最终将离散单元转换为语音。

**训练过程**分为两个阶段：

+   **第一阶段** 冻结大部分参数，训练Speech Adaptor和LLM的集成，使得语音输入能够顺畅地通过下采样进入LLM。

+   **第二阶段** 只训练Decoder部分，将LLM的文本输出转化为语音，通过上采样恢复到合适的语音格式，使用CTC损失函数来优化生成的语音单元。

**流式处理**：

+   流式非自回归语音解码技术确保在LLM生成文本的同时，逐步生成对应的语音单元，提升响应速度。

+   通过调整单元块大小来权衡系统的延迟和语音质量，优化后的延迟可低至226毫秒，优于GPT-4o的320毫秒。

**数据集**：使用InstructS2S-200K数据集，包括语音指令、文本回复和语音回复，通过TTS模型生成自然的语音数据。

### 训练大语言模型时公式表格等数据如何进行预处理和微调?

https://www.zhihu.com/question/625122736/answer/3636496581

**数据预处理：**

+   **文本分词与词嵌入**：对于文本数据，首先需要对文本进行分词，将文本分割为单词或子词（token），并将这些token映射到对应的ID，然后生成嵌入向量（word embeddings）。传统方法如Word2Vec通过上下文预测生成词向量，但在LLM中，词嵌入通常与模型训练同时进行。

+   **特殊字符处理**：分词后会将特殊符号、标点符号保留为单独的token，如逗号、句号等。此外，像BPE（Byte Pair Encoding）这种算法能有效压缩词汇表，是GPT系列模型中常用的分词方式。针对公式、表格中的特殊字符或数学符号，可以用特殊的token进行标注，如<|unk|>表示未知字符。

**非文本数据处理**：

+   对于公式、表格等数据，需通过特殊的标记方式处理。例如，公式中的变量和操作符可以分成token，并将其转化为对应的嵌入向量。同时，特殊结构如表格中的行列信息需通过特殊符号（如<|row_start|>和<|col_start|>)标记以确保模型能够理解其结构。

**数据加载与采样策略**：

+   为了提升训练效率，文本被划分为多个输入块，模型通过滑动窗口策略生成输入-输出对。这种方法对LLM非常重要，因为其训练任务是基于上下文预测下一个token。

+   数据采样通常采用滑动窗口的方式，并使用PyTorch等深度学习框架将输入文本转化为张量，确保在大规模数据处理时高效运行。

**位置编码**：

+   由于LLM无法感知序列中token的位置关系，需要通过位置编码（position embedding）增强模型的空间感知能力。位置编码可以是绝对或相对形式，帮助模型理解文本中词语的顺序。

### LLM实践--支线：拯救Continue Pretrain的数据

https://zhuanlan.zhihu.com/p/721492096

背景介绍 CP 是大模型训练的一个中间阶段，介于预训练（Pretrain）和监督微调（SFT）之间，其主要目的是为模型注入领域知识。在某些任务上，CP 比 SFT 更加有效，特别是在数据量较大且多样性丰富的情况下。

灾难性遗忘问题 灾难性遗忘是指在训练特定领域的数据时，模型的通用能力显著下降。缓解这种问题的常用技术包括部分训练、添加正则化、降低学习率等。然而，最核心的解决方案是混合通用数据（common数据）。在实践中，由于高质量通用数据难以获得，数据配比不透明，导致效果不理想。

重要性采样技术的引入 文章提出将重要性采样（importance sampling）引入CP训练。重要性采样是一种蒙特卡洛方法，允许从易于采样的分布中抽样，通过加权修正估计误差，实现对目标分布的无偏估计。在CP中，可以用预训练模型估计原始数据的分布，用当前训练的模型估计当前数据的分布，通过采样和加权调整，解决common数据不足的问题。

结合重要性采样的CP 在CP中，通过调整模型的目标函数，引入重要性采样方法，解决数据分布偏差问题。通过使用当前训练的模型和未训练的预训练模型，估计语料在当前和原始数据中的概率，从而动态调整模型训练过程。

Domain数据的选择与退火技术 在选择领域数据时，退火技术可以帮助快速找到模型对特定数据的最佳拟合，结合待测数据监控模型效果。退火技术不仅能提高模型对目标领域的拟合度，还能防止灾难性遗忘。

评估数据的重要性 最后，文章强调评估数据比训练数据更为重要，评估数据的选择决定了模型能力的真实反映和优化方向，错误的评估数据将导致模型优化的方向偏离
