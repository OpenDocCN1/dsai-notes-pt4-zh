### 吴泳铭：AI最大的想象力不在手机屏幕，而是改变物理世界

https://mp.weixin.qq.com/s/OYoeQJIPF54arDgFFhRSSw

### 漫谈AI应用：AI+代码，生产力领域的应用先锋

https://mp.weixin.qq.com/s/BumD83VVWKIdh22dqxo_4w

AI+代码是当前AI应用中最实用且商业化领先的场景之一。2023年CSDN的调研报告显示，约90%开发者已开始使用代码生成工具，认为其显著提升了开发效率。GitHub Copilot是这一领域的代表，2024年4月已拥有超过180万付费用户，收入规模达到数亿美元。代码生成本质上是一种较为标准化的“语言”生成任务，复杂度低于纯文本生成，因此更适合大模型应用。

Cursor作为一款由大模型驱动的IDE，在本地灵活调用GPT、Claude等大模型，并具备“生成”和“解释”两大核心功能。它不仅提供代码补全，还支持行内、文件、项目级的代码生成和编辑。相比传统的AI+代码插件，Cursor的优势在于其深度理解开发者需求，实现了高效的商业落地。Cursor的成功表明，AI应用能力不仅依赖模型的能力上限，还需要对应用场景的深刻理解。模型能力提升AI应用的上限，而场景理解决定了能否兑现该上限。

Cursor提供了Freemium商业模式，用户可通过付费获得更高级的模型使用权限，并已积累超3万名企业客户。其功能包含代码补全、对话修改、交互式编辑和项目全局修改，支持多种编程语言。与GitHub Copilot等产品相比，Cursor将AI能力深度融合到开发流程中，实现了“无感应用”，使AI能力最大限度融入原生产品形态。类似的AI+文字生成领域，WPS AI通过“伴写”功能实现了自然调用AI来辅助用户编写文案。

AI+代码的商业化成功在于其标准化和大模型的优越表现。根据PapersWithCode测评，多数大模型在HumanEval评估中的通过率达到75%以上，说明编程任务本身适合大模型发挥。国内外的AI+代码应用也纷纷涌现，如GitHub Copilot、Codeium、Cursor、aiXcoder、iFlyCode、CodeGeeX等，提供多样化的功能和服务。Cursor的成功启示是，AI应用需深刻理解用户需求，并融入原生应用，实现无感优化。此外，技术进展、行业竞争和商业化风险仍需警惕，以确保AI+代码应用的持续发展。

### KAN结合Transformer，真有团队搞出了解决扩展缺陷的KAT

https://mp.weixin.qq.com/s/ZpY56qNPPd_XAT_3uXP-Dg

Transformer 是现代深度学习的核心。传统 Transformer 利用多层感知器 (MLP) 层来融合通道信息。近期，研究者提出了一种替代方案——Kolmogorov–Arnold Transformer（KAT），利用 Kolmogorov-Arnold Network（KAN）层替代 MLP 层，提升模型表现。

新加坡国立大学的研究团队发现，将 KAN 集成到 Transformer 中面临三个挑战：(C1) 基函数，传统的 B 样条函数未针对现代硬件优化，计算速度慢；(C2) 低效的参数和计算需求，KAN 为每个输入输出对设计特定函数，计算量大；(C3) 权重初始化，由于可学习的激活函数，初始化难度高，影响网络收敛。

为应对这些挑战，研究团队提出了三项改进：(S1) 引入有理基函数，替换 B 样条以提升计算效率，并使用 CUDA 加速计算；(S2) Group KAN，通过共享神经元激活权重，减少计算负载；(S3) 方差保持初始化，确保激活方差稳定，避免层间数值不稳定。基于这些改进，团队提出了 Group-Rational KAN (GR-KAN)，用于替代 Transformer 中的 MLP。

实验结果显示，GR-KAN 具备高计算效率和易实现性，可无缝集成到视觉 Transformer（ViT）中。其设计允许从 ViT 模型加载预训练权重以进一步优化。实验证明，KAT 在图像识别、目标检测和语义分割任务上性能优于传统 MLP 基础的 Transformer。在 ImageNet-1K 上，KAT-B 实现了 82.3% 的准确率，超越同规模的 ViT 模型 3.1%；使用 ViT 的预训练权重初始化后，准确率提升至 82.7%。

为克服 KAN 的扩展性难题，研究团队提出了 Group-Rational KAN，通过共享参数减少计算量，提高扩展性，并采用有理函数取代 B 样条，以增强计算效率。相比于传统多项式，有理函数更适合并行计算，且在复杂行为建模方面更具优势。

在目标检测和实例分割实验中，KAT 表现优于其他模型，尤其在小模型上，以最小的计算开销实现显著性能提升。语义分割实验中，KAT 在性能和计算成本间取得平衡，比基于 ViT 的模型表现更佳。

KAT 的提出为 Transformer 的设计提供了新的思路，通过对传统 MLP 层的替代和优化，展示了在深度学习模型中融合不同计算层的潜力。

### **FedNE：基于代理辅助的 Neigh**bor Embedding 嵌入用于降维

贡献人：

链接：https://arxiv.org/abs/2409.11509

联邦学习（Federated Learning, FL）迅速发展成为一种有前景的范式，能够在不交换本地数据的情况下，促进分布式参与者之间的协作模型训练。尽管FL在计算机视觉、图学习和自然语言处理等领域有广泛的应用，但在FL背景下有效用于数据可**视化的数据**投影模型**的开发至关重**要，然而这**一领域仍然**未得到充分探索。邻居嵌入（Neighbor Embedding, NE）是可视化复杂高维数据的基本技术，但协作学习一个联合的NE模型存在困难。关键挑战在于目标函数，因为有效的可视化算法如NE需要在数据对之间计算损失函数。本文介绍了FedNE，一种将FedAvg框架与对比NE技术集成的新方法，无需共享数据。为了解决缺乏跨客户端排斥（inter-client repulsion）的问题，这对于全局嵌入空间中的对齐至关重要，我们开发了一种代理损失函数，每个客户端学习并相互共享。此外，我们提出了一种数据混合策略，以增强本地数据，旨在缓解由本地kNN图构建的不可见邻居和错误邻居的问题。我们在合成和真实世界数据集上进行了全面的实验。结果表明，与几种基线方法相比，我们的FedNE能够有效地保留邻居数据结构并增强全局嵌入空间中的对齐。

### **自对比前向前向算法**

链接：https://arxiv.org/abs/2409.11593

前向前向（Fo**rwar**d-**Forw**ard, FF）算法是一种新近提出的纯前向模式学习方法，能够局部且逐层地更新权重，并支持监督和无监督学习。这些特性使其非常适用于脑启发学习、低功耗硬件神经网络以及大型模型中的分布式学习等应用。然而，尽管FF在手写数字识别任务上表现出色，其在自然图像和时间序列上的性能仍然存在挑战。一个关键的限制是需要为对比学习生成高质量的负样本，尤其是在无监督任务中，目前缺乏多样化的解决方案。为了解决这一问题，我们引入了**自对比前向前向（Self-Contrastive Forward-Forward, SCFF）**方法，灵感来源于自监督对比学习。SCFF生成适用于不同数据集的正负样本，超越了现有的本地前向算法，在MNIST（多层感知机：98.7%）、CIFAR-10（卷积神经网络：80.75%）和STL-10（卷积神经网络：77.3%）上的无监督分类准确率。此外，SCFF首次实现了前向前向训练循环神经网络，开启了更复杂任务以及连续时间视频和文本处理的大门。

### Moshi: a speech-text foundation model for real-time dialogue

贡献人：

https://zhuanlan.zhihu.com/p/720818708?utm_psn=1820060061046800385

Moshi 是一款两个月前刷屏的语音对话模型，最近发布了其权重和论文。这款开源模型具有7.6B参数，专注于实时语音对话，并提供了详细的技术报告，非常适合跨领域的研究者入门。

Moshi 基于经典变换器架构，引入了一种离散编码（RVQ），可以接收多种输入并输出多种结果。其主要目标是处理语音中的双工工况（模型能够边说边听），并通过文字提升输出语音的逻辑性。在浅层上拉一个输出头用于生成文字，增强语音对话的逻辑表现。

"Inner Monologue" 是 Moshi 采用的关键技巧之一，即在生成语音 token 时同步生成文字 token，从而提升语音生成的效果。这一方法也曾在其他工作中出现，如 Mini-Omni、Llama-Omni，以及更早的 SpeechGPT-Gen。在 Moshi 中，“先生成”文字指的是文字相对于声学 token 更早产生，虽然与语义 token 是同步生成的。通过这种方式，模型在生成声学 token 时已经提前获取了语义信息。

Moshi 采用 ASR + 独立 LLM-judge 的评估方式，科学地测量了生成语音 token 的语义可理解性。除了 Inner Monologue 技巧外，稍微引入一些延迟（delay）也能有效提升语音生成质量，相当于在生成声学 token 时参考了一些未来的语义 token。

Moshi 对双工对话能力的评测非常科学，涵盖了暂停、留空和重叠等情形，特别是对非打断的回复有明显优势。这种全面的评测方法为其双工对话性能提供了充分的证明。

Moshi 的一大亮点是将语音视为一种外语处理。然而，目前还没有达到如 LIMA 那样只需极少文字-语音对齐数据就能实现准确对齐的工作。虽然通过生成文字来带动语音是一个捷径，但增加了复杂性，对编辑等任务不利，还需要 word-alignment。未来值得探讨的是是否存在更简化的模态对齐方式，以降低复杂性。

### 技术上，如何复现 o1?（9.15 更新）

搞 o1 首先需要一个能进行“长”生成的基模型，这与“长 context”不同。长生成往往出现自激噪声，或生成结果逐渐变得锐利，导致后半段质量下降，例如写小说“烂尾”等。多模生成模型也常在结尾处出现模糊或静音。基模型还需具备较强抗噪能力，特别是大模型表现更优，小模型容易被context中的错误带偏。考虑到CoT（Chain of Thought）本质上是trial-and-error，需要大模型从复杂context中筛选有用信息。

**数据方面**，如果起步是模仿学习（SFT），需要规划一定量的数据。比如将问题分解成步骤由人类演示，或模型按类似ReAct/Reflection/RePlan的方式CoT，然后由人类打分。数据量初期可由人类生产，后期通过Self-Play扩充。此外，RL部分需要大量Reward Model数据，考虑到CoT数据非常长，大概率采用PRM（Partial Reward Model），标注CoT的第一个错误点。自动定理证明器（ATP）中的“tactics”可借鉴，比如O1具备数学归纳法，可能将ATP的证明转换为自然语言CoT数据。

**算法方面**，需要数据效率高的算法，可能是某种MCTS（蒙特卡罗树搜索），因为o1适合验证容易的问题。当前难点在于系统和算法的配合，特别是大规模推理造数据不可避免。o1-mini的存在值得关注，据说其数学能力更强但推理更“无理”。推测可能先有o1-mini，再用它的大量roll数据训练o1-preview，或者两者交替互为师徒。

**FAQ**：

1.  **o1在多模态理解生成中的应用**：o1改变了LLM，使得存在verifier或需要满足约束的应用都受到影响。例如，以前多模生成中的指令跟随难题，如生成高一致性的多视角图，o1能反复修改生成。可以想象o1自言自语，在画布上不断调整，最终达到约束要求。

1.  **对AI搜索和角色扮演的影响**：复杂的二次搜索需要均衡成本和时间预算。o1展现了这一潜力，并支持工具调用。对于角色扮演，o1提供了不“烂尾”的生成框架，适用于“乐而不淫”、“文似看山不喜平”等约束条件的创作。

### Triton TTIR To TTGIR

https://zhuanlan.zhihu.com/p/695613807?utm_psn=1819883613040304128

本文主要介绍了Triton编译中TTIR到TTGIR的转换及优化过程，涉及GPU block配置、layout属性设置、指令转换等技术细节。

TTIR到TTGIR主要通过调用add_convert_triton_to_tritongpu_pass方法，将TTIR中的非法操作转换为TTGIR中的合法操作，并添加GPU block、layout等属性。通过populate...方法将各种操作转换为TTGIR中的相应操作。最终的转换会给模块添加num-warps和threadsPerWarp属性。

Triton中layout的概念非常重要，它描述了线程加载元素的方式、warp中的线程排布以及block内的warp排布等。Triton中主要的layout类型包括BlockedEncodingAttr、MmaEncodingAttr、SliceEncodingAttr、DotOperandEncodingAttr和SharedEncodingAttr。其中，BlockedEncodingAttr用于描述数据以block的方式计算，而MmaEncodingAttr是为矩阵乘法计算而定义的layout。

在TTGIR优化阶段，Triton进行了多项优化pass：

1.  Coalesce Pass优化（合并加载）：针对tt.load、tt.store等操作，合并访存操作，减少bank冲突和指令数量。该pass通过分析layout轴信息，决定如何进行访存合并，最终生成一个新的BlockedEncoding，实现更高效的访存。

1.  Remove Layout Conversions Pass：消除冗余的layout转换操作，因为这些操作代价昂贵。此pass包含多个Pattern，尝试移除或简化layout转换，例如合并连续的转换、将转换操作移出循环等。

1.  Accelerate Matmul Pass：将blocked layout转换为mma layout，以加速矩阵乘法计算。通过匹配tl.dot操作，将其输入和输出关联到mma layout，并将转换操作插入到TTGIR中，优化矩阵计算性能。

1.  Optimize Dot Operands Pass：优化dot操作的输入，主要涉及layout变换，使其更适合GPU执行。

1.  **Pipeline Pass**：通过在共享内存中使用多倍缓冲区形成pipeline效果，掩盖共享内存操作的延迟。一般情况下，开启多stage能够提升性能，但若占用过多共享内存，反而会降低并行度。

整个优化流程中，部分pass会多次调用，且调用顺序会影响最终的优化效果。

### Kolmogorov-Arnold Transformer

贡献人：

链接：https://arxiv.org/abs/2409.10594

Transformers 已成为现代深度学习的基石。传统上，这些模型依赖多层感知器（MLP）层在通道之间混合信息。本文介绍了一种新颖的架构——Kolmogorov-Arnold Transformer (KAT)，用 Kolmogorov-Arnold 网络 (KAN) 层替换了 MLP 层，从而增强了模型的表达能力和性能。然而，将 KAN 集成到 Transformers 中并非易事，特别是在扩展时。具体来说，本文识别了三个关键挑战：(C1) 基础函数。KAN 中使用的标准 B 样条函数未针对现代硬件上的并行计算进行优化，导致推理速度变慢。(C2) 参数和计算效率低下。KAN 为每个输入输出对需要一个独特的函数，导致计算量极大。(C3) 权重初始化。由于 KAN 中的可学习激活函数，权重初始化非常具有挑战性，而激活函数对深度神经网络的收敛至关重要。为了解决上述挑战，本文提出了三个关键解决方案：(S1) 有理基。使用有理函数取代 B 样条函数，以提高与现代 GPU 的兼容性。通过在 CUDA 中实现这一点，实现了更快的计算速度。(S2) 组 KAN。通过一组神经元共享激活权重，以减少计算负担而不牺牲性能。(S3) 保持方差的初始化。仔细初始化激活权重，确保跨层的激活方差保持不变。通过这些设计，KAT 能够有效扩展，并轻松超越基于传统 MLP 的 Transformers。

专家混合（Mixture-of-Experts, MoE）模型通过专家路由实现稀疏计算，相较于密集模型，它们在扩展上更为有效，因为仅激活了一小部分专家模块。然而，稀疏计算给传统的训练方法带来了挑战，因为离散的专家路由阻碍了标准的反向传播，从而影响基于梯度的优化，而梯度优化是深度学习的核心。为了更好地实现MoE的扩展能力，我们引入了GRIN（梯度指导的MoE训练），该方法结合了稀疏梯度估计来进行专家路由，并配置了模型并行性以避免token丢失。在自回归语言建模中应用GRIN，我们开发了一个top-2的16×3.8B MoE模型。该模型仅激活了6.6B的参数，但其表现超越了7B的密集模型，并匹敌使用相同数据训练的14B密集模型。在多种任务上的广泛评估显示，GRIN显著提升了MoE的效能，分别在MMLU、HellaSwag、HumanEval和MATH上取得了79.4、83.7、74.4和58.9的成绩。
