# 普通人用AI的最佳顺序：先提示词，后工作流，最后再考虑智能体

> 来源：[https://my.feishu.cn/docx/UHVDddNJ4oaFz3xCAsQcA7HAnkb](https://my.feishu.cn/docx/UHVDddNJ4oaFz3xCAsQcA7HAnkb)

分享一个，在我们普通人使用AI的时候，可以尽量参照的一个原则：

**能用提示词，就不用工作流**

**能用工作流，就不用智能体**

能用一个智能体，就不用多个智能体

这是一个很容易理解也很实用的观点，可以称之为【使用AI的“奥卡姆剃刀原则”或“最小化复杂度原则”】。对于普通AI用户来说，遵循这个原则可以让我们在享受AI带来便利的同时，最大程度地避免不必要的麻烦、成本和风险。

下面我简单梳理一下这个原则背后的逻辑，便于知其然并知其所以然。

### 首先，我们来理解这几个概念的层级关系：

+   提示词 (Prompt)：这是最基础、最直接的与AI交互的方式。你给AI一个指令，它给你一个结果。

+   例子：“帮我写一封邮件，向客户介绍我们的新产品。”

+   工作流 (Workflow)：这是将多个固定的步骤串联起来，形成一个自动化的流程。每一步通常由一个或多个提示词驱动，但整个流程是预先设计好的、线性的。

+   例子：设定一个流程：1. 自动抓取某个网站的最新文章 → 2. 使用AI对文章进行总结 → 3. 将总结翻译成英文 → 4. 自动发送到你的邮箱。

+   智能体 (Agent)：这是一个更高级的概念。你只给智能体一个最终目标，它会自己思考、规划、决策并调用工具来完成任务，过程不是固定的。它拥有一定的自主性。

+   例子：你对智能体说：“帮我研究一下最近电动车市场的趋势，并生成一份分析报告。” 它可能会自己决定去搜索新闻、查看股票数据、分析社交媒体评论，然后整合信息。

+   多个智能体 (Multi-Agent System)：这是一个协同工作的AI团队。每个智能体有不同的角色（如研究员、作家、评论家），它们互相协作、沟通，共同完成一个复杂的宏大目标。

+   例子：目标是“开发一款新的App”。一个产品经理智能体负责定义需求，一个程序员智能体负责写代码，一个测试员智能体负责找bug。

### 为什么遵循能少则少的原则？

这个原则的核心是在能解决问题的前提下，选择最简单、最可控、成本最低的方案。

1.  **能用提示词，就不用工作流**

+   简单性与可控性：一个提示词的结果最容易预测和调整。如果结果不理想，你只需要修改这一个提示词。而工作流涉及多个环节，任何一个环节出错，都可能导致整个流程失败，排查问题更复杂。

+   成本与效率：一个提示词通常意味着一次AI调用，速度快，成本低。而一个工作流可能包含5个步骤，就需要调用5次AI，时间和金钱成本都会成倍增加。

+   适用场景：许多日常任务，如写作、翻译、总结、代码解释等，一个精心设计的提示词就完全足够了。只有当任务本身需要固定的、多步骤的串行处理时，才需要考虑工作流。

一句话总结：不要用大炮去打蚊子。如果一句话能说清楚，就别写成一本操作手册。

1.  **能用工作流，就不用智能体**

+   可靠性与稳定性：工作流的路径是确定的、可预测的，一旦A发生，B就会接着发生，然后是C。它的可靠性远高于智能体。智能体因为有自主决策能力，其行为有时会变得难以捉摸或不稳定，可能会陷入死循环，或者做出一些意想不到的骚操作，导致任务失败。

+   成本可控性：工作流的成本是固定的（比如5个步骤5次调用）。智能体的成本可能失控，因为它为了达成目标，可能会自行决定进行大量搜索、调用多种工具，产生巨量的API费用，这对于普通用户是很大的风险。

+   技能门槛：设计一个稳定的工作流，比构建一个可靠的智能体的技术门槛要低得多。智能体的设计需要考虑如何规划、如何选择工具、如何处理错误和意外情况，非常复杂。

一句话总结：如果有一张清晰的地图（工作流），就不要让一个新手司机自己摸索着开车（智能体）。

1.  能用一个智能体，就不用多个智能体

+   指数级增长的复杂性： 如果说从工作流到单个智能体，复杂性是线性增长的，那么从单个智能体到多个智能体，复杂性就是指数级增长的。你需要管理它们之间的通信、协调、任务分配、目标对齐、冲突解决……这几乎是在模拟一个人类组织，难度极高。

+   天价的成本： 多个智能体之间的每一次沟通和协作，都可能是一次AI调用。一个复杂任务下来，调用次数可能是成千上万次，成本高到无法想象。

+   当前技术的局限： 多智能体系统目前仍然是AI研究的前沿领域，远未达到普通人可以稳定使用的程度。它们是用来探索通用人工智能（AGI）可能路径的屠龙之技，而不是用来处理日常任务的宰牛之刀。

一句话总结：如果你连管理一个超级员工（单个智能体）都觉得吃力，就千万别尝试去管理一个AI创业团队（多个智能体）。

### 给普通人的实践建议

这个原则就像一个决策树，帮助你选择最合适的AI工具：

1.  先问自己：我的任务，能不能通过和AI的一次或几次对话（高质量的提示词）解决？

+   如果可以，就停在这里。这是90%以上普通用户的最佳选择。

1.  如果任务包含多个固定的、重复的步骤，提示词无法一次性完成，再考虑：我能不能把这些步骤设定成一个自动化的快捷指令（工作流）？

+   例如，每天早上自动获取天气和新闻摘要。现在一些AI工具的定时功能（如ChatGPT、智谱）可以帮你实现。

1.  只有当你的任务目标非常开放、过程高度不确定、需要AI自己探索和决策时，才需要考虑智能体。

+   例如，“帮我规划一个为期一周、预算5000元的日本自由行，并预订机票酒店。” 这种任务目前对大多数人来说，交给智能体还不如自己动手或结合多个提示词来完成更可靠。

1.  至于多个智能体，目前可以完全忽略。 对普通人来说，它更像是一个科幻概念，而非实用工具。

**核心思想：始终从最简单的工具开始尝试。只有当简单的工具确实无法满足你的需求时，才逐级向上**寻找更复杂的解决方案。这能让你在享受AI红利的同时，保持最高的效率和最低的风险。
