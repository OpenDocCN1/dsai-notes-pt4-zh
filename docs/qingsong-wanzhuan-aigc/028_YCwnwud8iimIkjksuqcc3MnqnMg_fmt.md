### Kimi 阅读助手（非官方出品）

chromewebstore.google.com

推荐指数：🌟🌟🌟🌟

近期，Kimi 智能助手的热度不断攀升，民间高手们已经纷纷推出了各式各样的插件，让人目不暇接。

Kimi 阅读助手是一款非常实用的工具，它能够智能地解析用户正在浏览的页面内容，并根据要求提取出关键信息，以标签和简洁的总结形式呈现给用户。

同时，它还可以自己预设各种各样的提示词：可以根据自己的实际场景进行自定义，让它更懂你。当然你也也可以直接用这个默认的「总结网页内容」常用语。它主要辅助你快速总结各个网页内容的主要信息，提示词如下：

```
你是一个擅长总结长文本的助手，能够总结用户给出的文本，并生成摘要。

## 工作流程
让我们一步一步思考，阅读我提供的内容，并做出以下操作：

## 标签
阅读文章内容后给文章打上标签，标签通常是领域、学科或专有名词

## 一句话总结
阅读文章内容后，总结文章内容，并写成一句话总结这篇文文章

## 摘要
总结文章内容并写成摘要，详细地列举文章的大纲，要完整体现文章要点
```

### Kimi Copilot（非官方出品）

chromewebstore.google.com

推荐指数：🌟🌟🌟🌟

用 Kimi AI 一键总结网页内容

安装后，在浏览网络文章时点击插件图标，或使用快捷键 `Ctrl/Cmd+Shift+K`，即可一键召唤 Kimi.ai 总结网页内容

**特点：**

1. 极简，除了一键总结没有其它花里胡哨的功能
2. Kimi 无法访问的网页也能被总结了
3. 英文文章直接用中文总结要点
4. 支持 Dark Mode
5. 支持自定义总结时使用的 prompt

**注意：**

1. 本插件为第三方爱好者开发，不是 Kimi.ai 或月之暗面官方产品
2. 由于 Arc 等浏览器没有所需的 API，所以本插件无法在 Arc 等浏览器使用
