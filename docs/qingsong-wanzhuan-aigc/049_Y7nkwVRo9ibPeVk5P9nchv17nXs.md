
# 有什么核查信息准确率的AI提示词吗？

> 来源：[https://my.feishu.cn/docx/XilYdlYtyoyOWIxhbBocAZ2snHb](https://my.feishu.cn/docx/XilYdlYtyoyOWIxhbBocAZ2snHb)

以下为提升信息准确率核查的AI提示词设计框架及具体案例，结合多场景需求整理而成：

## 一、角色设定型提示词

```
# 角色设定 + 核查标准
"你作为专业事实核查员，需根据以下标准验证信息真实性：
1. 确认信息源是否为政府官网(.gov/.gov.cn)、权威媒体(人民网/新华社)或学术数据库（知网/万方）
2. 对比近3年内的最新研究数据（优先引用2023年后文献）
3. 检查数据逻辑链：原始数据→统计方法→结论推导是否存在断裂
4. 标注存疑内容并说明理由（如'该数据未标注样本量，置信区间不明'）
请对以下内容进行核查：[输入待验证文本]"
```

适用场景：新闻稿件、学术论文数据验证

## 二、分步核查指令

```
# 分阶段验证流程
"执行以下核查步骤：
1. 信息溯源：提取文本中所有数据及结论，标注原始来源（期刊/报告/机构）
2. 交叉验证：通过Google Scholar检索近5年相关论文，比对数据一致性
3. 逻辑检测：绘制论点推导流程图，标记未证实的假设（如'假设A未引用支撑文献'）
4. 风险评级：按[可信｜待验证｜存疑]三级分类输出核查报告"
```

适用场景：科研数据分析、商业报告审核

## 三、数据准确性专项提示

```
# 数据维度验证
"针对以下数据陈述：
- 检查数字单位是否统一（如亿元/万美元混用）
- 验证同比/环比计算是否合规（基期选择是否合理）
- 识别非常规数据波动（如'GDP增长率从5%突增至20%'需重点标注）
- 输出格式要求：[原始数据]→[验证结果]→[修正建议]表格"
```

适用场景：经济报告、市场分析

## 四、多源交叉验证指令

```
# 多平台比对指令
"执行跨平台验证：
1. 在国家统计局官网查询[关键词]年度数据
2. 比对世界银行数据库的对应指标
3. 检索知网近3年核心期刊相关论文的结论
4. 若多方数据差异＞10%，标注争议点并生成对比图表"
```

适用场景：政策解读、行业白皮书

## 五、实时信息更新提示

```
# 时效性验证模板
"验证信息时效性：
1. 标注所有时间敏感型结论（如'最新研究显示'需确认研究发布时间）
2. 检查政策类信息是否附带文号（如'国发〔2024〕XX号'）
3. 对超过2年未更新的数据添加'需复核'标记
4. 输出带时间戳的核查记录表"
```

适用场景：法律法规解读、医疗指南更新

## 提升准确率的辅助策略

### 限定知识范围

```
"仅基于2023年后SCI/SSCI期刊、国家统计局白皮书数据进行验证"
```

### 强制反馈机制

```
"对无法验证的内容，必须标注'需人工复核'并说明原因"
```

### 可视化输出

```
"用Mermaid流程图展示验证路径，用红色/黄色/绿色标注风险等级"
```

## 注意事项

需配合「分步追问」策略，例如在初步核查后追加：

```
"请用反证法检验结论：如果[数据A]错误，是否会影响[结论B]成立？"
```
