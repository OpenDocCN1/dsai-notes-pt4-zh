## 构建全局思维链

对大模型的 Prompt 应用CoT 思维链方法的有效性是被研究和实践广泛证明了的。

一个好的结构化 Prompt 模板，某种意义上是构建了一个好的全局思维链。 如 LangGPT 中展示的模板设计时就考虑了如下思维链:

> **Role (角色) -> Profile（角色简介）—> Profile 下的 skill (角色技能) -> Rules (角色要**遵守的规则) -> Workflow (满足上述条件的角色的工作流程) -> Initialization (进行正式开始工作的初始化准备) -> 开始实际使用

一个好的 Prompt ，内容结构上最好也是逻辑清晰连贯的。结构化 prompt 方法将久经考验的逻辑思维链路融入了结构中，大大降低了思维链路的构建难度。

构建 Prompt 时，不妨参考优质模板的全局[思维链](https://link.zhihu.com/?target=https%3A//web.okjike.com/u/752D3103-1107-43A0-BA49-20EC29D09E36)路，熟练掌握后，完全可以对其进行增删改留调整得到一个适合自己使用的模板。例如当你需要控制输出格式，尤其是需要格式化输出时，完全可以增加 Ouput 或者 OutputFormat 这样的模块（可参考附录中的 AutoGPT 模板）。例如即友 李继刚 就构建了很多结构化 Prompt，其他修改同理。

# 为什么要用“伪代码”形式的 Prompt？

“伪代码形式”和“自然语言形式”，这两者不仅在结构上有差异，适用的场景和优势也不同。

---

## 伪代码形式 vs 自然语言形式的对比

| **对比维度** | **伪代码形式** | **自然语言形式** |
| --- | --- | --- |
| **结构化** | 高度结构化。每一步都有明确的输入、处理、输出，便于自动化执行。 | 非结构化。基于对话形式，适合人类用户，容易理解，尤其是对不熟悉技术的用户。 |
| **执行效率** | 更高效。伪代码有明确的执行逻辑，AI 不需要推导上下文，减少了理解偏差，任务完成速度更快。 | 执行效率较低。自然语言需要 AI 理解上下文，尤其在复杂任务中，容易导致逻辑混乱或理解不准确。 |
| **扩展性和重用性** | 极具扩展性和重用性。伪代码模板可以适用于不同场景，只需修改部分逻辑，即可用于类似任务。 | 扩展性较弱。每个新任务通常需要重新编写或大幅修改，难以在不同场景中重复使用。 |
| **清晰度和可控性** | 逻辑非常清晰。每个步骤都明确，确保了任务的顺序执行和可控性。适合需要精确控制的场景。 | 清晰度较弱。虽然对话形式灵活，但步骤间的逻辑不够明确，尤其在复杂任务中容易遗漏或跳过关键步骤。 |
| **用户友好性** | 适合具备一定技术背景的用户。由于伪代码需要一些逻辑推理和技术理解，初学者可能需要一定的学习成本。 | 非常友好。自然语言形式更贴近日常交流，用户不需要掌握技术知识，直接表达需求即可。 |
| **创造性和灵活性** | 灵活性较低。伪代码更关注于执行的准确性和效率，AI 在严格结构下工作，较少创意性发挥的空间。 | 灵活性高。自然语言允许 AI 根据上下文进行推理，有时可能会带来更具创意的解决方案，特别适合探索性任务。 |

---

## 伪代码形式 vs 自然语言形式的优势与不足

#### 1. **伪代码形式**

+   **优势**：

+   **逻辑清晰**：伪代码形式具有明确的步骤划分，输入、处理和输出非常清楚。AI 在执行任务时不需要推导，可以直接按照逻辑执行，适合自动化处理复杂任务。

+   **高效执行**：AI 可以快速理解和执行伪代码中的指令，减少了对自然语言理解的依赖，因此任务执行速度更快。

+   **可扩展性**：伪代码形式可以很容易重用。通过修改部分参数或逻辑，可以适用于不同的任务场景，具备较强的模块化和扩展性。

+   **不足**：

+   **用户门槛较高**：伪代码要求用户有一定的逻辑思维能力或编程经验，对不熟悉技术的人可能显得不够直观。

+   **创意有限**：由于伪代码强调结构化和精准执行，AI 在处理时缺乏灵活性，不太适合需要创意性解决方案的任务。

#### 2. **自然语言形式**

+   **优势**：

+   **用户友好**：自然语言更贴近人类的表达方式，尤其适合对技术不熟悉的用户，便于直接传达需求和互动。

+   **灵活性高**：自然语言允许 AI 自由推理和解读用户需求，特别适合创意性或探索性任务。在这些任务中，AI 能够根据上下文提供更多元化的解决方案。

+   **不足**：

+   **不够结构化**：自然语言形式缺乏明确的步骤和逻辑划分，容易导致任务执行中的理解偏差或逻辑混乱，特别是在复杂任务中。

+   **效率较低**：由于 AI 需要额外时间进行上下文推理，任务执行效率较低，尤其在多步骤的复杂任务中。

---

### **结论：为什么伪代码形式更好？**

伪代码形式在复杂任务、多步骤执行和自动化场景中有明显的优势。它提供了清晰的结构和逻辑步骤，确保任务可以高效、精准地执行，适合重复性、可扩展的场景。

而自然语言形式更适合与人类的直接互动、简单任务或需要创意的场景。根据任务的不同需求，选择适合的形式可以更好地达到目标。

因此，**伪**代码形式在自动化、复杂任务和高效执行中表现更好，而自然语言形式则更适合人机交互、简单任务和灵活处理的场景。
