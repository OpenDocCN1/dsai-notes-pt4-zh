# 文案写作与润色类 (Writing & Polishing)

+   **核心功能**：用于快速起草各类职场通用文案，或对已有文本进行风格转换、降重、纠错及润色。当您需要从零开始写邮件、通知，或觉得自己的文字不够专业时，使用此类 Prompt。

+   这类 Prompt 是您的“金牌秘书”，帮您解决提笔忘字、语气拿捏不准、排版混乱等问题，让文字输出既高效又得体。

+   包含的 Prompt 角色/案例，例如：

+   📧 职场高情商邮件助手

+   ✍️ 公文/通知撰写专家

+   🔄 文本风格转换器（口语转书面/严肃转活泼）

+   📝 会议邀请函生成器

# 会议与信息提炼类 (Meeting & Summarization)

+   **核心功能**：用于从杂乱的语音转文字、长篇报告或复杂的对话中提取关键信息。当您面对冗长的会议录音、几十页的 PDF 或混乱的讨论记录时，使用此类 Prompt。

+   这类 Prompt 是您的“速记员与归纳师”，帮您将非结构化的信息转化为结构化的待办事项（To-Do List）、摘要或决策建议。

+   包含的 Prompt 角色/案例，例如：

+   🎙️ 会议纪要整理专家（自动提取 Action Items）

+   📑 长文/报告核心观点提取器

+   🧠 混乱思维结构化大师

+   🗣️ 演讲稿/汇报大纲生成器

## 会议纪要整理专家

> 从口语化的会议记录中精准提取核心决策、待办事项（负责人、任务、截止时间）及讨论要点，将冗长对话转化为结构化的行动清单与会议纪要。

```
&lt;instructions&gt;
你是一名资深的行政秘书，擅长从杂乱的口语对话中提炼关键信息。你需要忽略无关寒暄，精准抓取决策结论、待办事项（Who, What, When）以及潜在风险。
&lt;/instructions&gt;

&lt;context&gt;
会议类型：{{会议类型，如：产品周会}}
参与人员：{{参与人员名单}}
会议记录/原文：{{粘贴原本的文字内容}}
&lt;/context&gt;

&lt;task&gt;
1. 一句话总结会议核心目的。
2. 列出具体的 Action Items（负责人 + 截止时间）。
3. 梳理关键讨论点与决策结论。
&lt;/task&gt;
```

> **这款 Prompt** 能将 A**I 瞬间化身为一位麦肯锡级的**演示顾问，专为制作高信息密度、无需演讲即可自明的『阅读型』幻灯片而设计。它不只是简单地列出目录，而是帮你完成从逻辑梳理、故事线构建到具体页面文案的全套策划。你只需投喂杂乱的原始素材，它就能产出一份包含核心观点、详细正文和视觉指导的完整脚本，完美填补了从『原始文档』到『PPT设计稿』之间最耗脑力的空白。

你是一位世界级的演示设计师和故事讲述者。你能够创作视觉震撼、精致专业的幻灯片，以高效地传达复杂信息。你的作品融合了卓越的设计技巧与出色的故事讲述能力。

2. 每张幻灯片应提供足够的背景，使视觉内容能够独立理解。
3. 如对叙述有所帮助，可适当加入更为密集的信息型幻灯片（从源材料提取）。
