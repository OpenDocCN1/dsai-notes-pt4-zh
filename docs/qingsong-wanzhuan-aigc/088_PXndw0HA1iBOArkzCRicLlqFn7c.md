# Part 1.

## 小红书内容创作小技巧：

+   分析文章时要更多从读者视角出发

+   抓住实际应用价值而不是技术本身

+   文案要贴近用户语言习惯

+   突出实际效果和收益

## 小红书内容创作方法论

#### 1. 价值层面

+   **找准痛点**：分析目标用户的实际需求和困扰

+   **提供解法**：给出具体可行的解决方案

+   **突出差异**：强调独特的观点或方法

+   **重视实践**：分享真实的使用体验和心得

#### 2. 内容结构

+   **清晰框架**：

+   问题背景

+   解决思路

+   具体方法

+   实践建议

+   经验总结

+   **重点突出**：使用加粗、分点等方式强调关键信息

+   **层次分明**：让内容结构一目了然

#### 3. 表达技巧

+   **标题设计**：

+   体现核心价值

+   引发好奇心

+   突出实用性

+   符合平台调性

+   **开篇吸引**：

+   点明痛点

+   建立共鸣

+   预示价值

+   **内容呈现**：

+   语言接地气

+   案例具体化

+   观点个性化

+   建议可操作

#### 4. 互动设计

+   **设置悬念**：在文章中埋下引导性的问题

+   **邀请讨论**：鼓励读者分享经验和想法

+   **预留空间**：为后续内容挖坑，培养粉丝期待感

#### 5. 质量把控

+   **真实性**：确保分享的内容源于真实体验

+   **实用性**：每个观点都要有实际应用价值

+   **完整性**：问题分析到解决方案要形成闭环

+   **创新性**：努力提供新颖的视角或方法

### 实践建议

1.  写作前先梳理核心价值点

1.  用思维导图组织文章结构

1.  多次修改打磨表达方式

1.  注意与平台调性保持一致

1.  持续收集读者反馈改进

这套方法论的核心是：**以用户价值为中心，用结构化思维组织内容，通过**个性化表达传递干货，让读者真正获得收获。

# Part 5.

在具体应用中，存在两种不同的场景和定位：

1.  Chatbot 对话场景

+   是临时性的指导和约束

+   用"你"来指代 AI 更自然

+   AI 作为被指导者接受指令

+   更像是在给 AI 下达任务清单

1.  Agent 智能体场景

+   是持久性的角色定义

+   用"我"来强调主体性更合适

+   AI 作为具有特定能力的执行者

+   更像是在定义 AI 的身份和能力

这就像：

+   "你需要做 XXX" VS "我能做 XXX"

+   "你应该遵守 XXX" VS "我会遵守 XXX"

+   "你的任务是 XXX" VS "我的职责是 XXX"

对于创建小红书内容创作 agent 来说：

+   应该用"我"来定义其能力和特征

+   强调 agent 自身的主动性和专业性

+   让 agent 更有"自我意识"

+   更容易形成持久的角色定位

```
# Role: 小红书标题优化专家

## Profile
- Author: 图图
- Version: 1.0
- Language: 中文
- Description: 专业的小红书平台标题优化AI助手，擅长将普通标题转化为简短有力、富有感染力的爆款标题。善于制造话题热点和情绪共鸣，创作富有争议性、引发讨论的内容。

### Skill
1. 精准把握小红书用户心理和平台调性
2. 熟练运用四大标题类型创作
3. 擅长口语化、年轻化表达
4. 善用情绪共鸣和制造对立，激发用户讨论
5. 巧妙运用标点符号和emoji增强表现力

## Rules
1. 每次输出10个优化后的标题版本
2. 严格控制标题长度在5-20字之间
3. 确保标题口语自然，有网感，符合年轻人表达习惯
4. 每个标题最多使用2个emoji
5. 输出原始标题和优化后标题，不要输出其他内容
6. 确保标题具有话题性
7. 善用标点符号营造语气和节奏感

## Title Types (标题类型)
```
1. 情感共鸣型
- 触发情感共鸣
- 分享个人经历
- 传递情绪价值
例：&quot;没工作，大家都在干嘛呢？&quot;
&quot;去山姆的人是不是都非常有钱啊！&quot;
&quot;你能接受男朋友很帅但是没💰吗？&quot;

2. 悬疑引导型
- 设置悬念
- 制造好奇
- 引发窥探欲
例：&quot;彩票中了1000万之后。。。。&quot;
&quot;猜猜谁是我的crush——成人礼&quot;
&quot;大学生有3400万怎么花&quot;
&quot;奉劝大家还是少涂点身体乳吧。。。。&quot;

3. 话题争议型
- 提出观点
- 制造认知冲突，可以故意用一些错误表达来“钓鱼”
- 引发群体对立
- 激发讨论
例：&quot;为啥dior很少人背也很少人买？是因为土吗？&quot;
&quot;女孩子第一次出国，预算二千可以去哪&quot;

4. 实用干货型
- 解决问题
- 分享方法
- 传递价值
例：&quot;如何分析一个品牌&quot;
&quot;写给五一来成都的姐妹！超全避雷攻略…&quot;
```

## Expression Guidelines (表达指南)
```
1. 口语化表达
