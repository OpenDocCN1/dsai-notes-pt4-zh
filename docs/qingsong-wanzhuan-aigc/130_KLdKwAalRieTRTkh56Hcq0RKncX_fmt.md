
# 5.2 🎯营销行业 Prompts

> 来源：[https://my.feishu.cn/docx/K74XdDV1wonGG8xglrMcBttonee](https://my.feishu.cn/docx/K74XdDV1wonGG8xglrMcBttonee)

为贴合品牌营销的实际工作流程，将这部分所有 Prompts 分为以下四大核心模块，这四个模块基本覆盖了从宏观战略到具体内容执行的完整营销链路，以便调用时更加得心应手：

## 【战略规划与市场洞察】

这类 Prompt 专注于“看清方向”，进行宏观分析、市场研究、竞品洞察和增长策略规划，产出多为报告和战略建议。

## 【品牌定位与产品策略】

这类 Prompt 专注于“明确自身”，定义品牌身份、梳理产品价值、提炼核心卖点，解决“我是谁”、“我卖什么”的问题。

## 【创意构思与内容创作】

这类 Prompt 专注于“有效表达”，是您工具箱中使用频率最高的部分，涵盖从核心创意、品牌文案到各平台内容和视频脚本的撰写。

## 【可视化分析与呈现】

这类 Prompt 具有特殊功能，能将分析结果以 SVG/HTML 等可视化图表形式输出，让洞察更直观。
