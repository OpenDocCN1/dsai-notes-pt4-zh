## 为什么这很重要（以及为何奥格威至今仍被奉为圭臬）

大卫·奥格威不只是写广告文案。他写出的标题，让无数企业主成为百万富翁，并将默默无闻的产品打造成家喻户晓的品牌。他为劳斯莱斯撰写的经典标题（“在时速60英里时，这款新型劳斯莱斯车内最响的声音来自电子钟”），至今仍被研究了60多年。

问题何在？大多数人认为好标题纯粹靠创意。其实不然，它们是公式。

## 9个奥格威式标题提示词（直接复制使用）

### 1. 欲望满足公式

+ 提示词：“请撰写一个标题，承诺在[特定时间段]内实现[具体欲望满足]，并使用直接、不啰嗦的语言。”

+ 为何有效：人们购买的是结果，而非产品本身。奥格威深谙此道。

+ 示例：“足不出户，30天学会西班牙语”

### 2. 好奇心缺口制造者

+ 提示词：“请生成一个关于[主题]的引人好奇的问题式标题，制造一个读者必须填补的信息缺口。”

+ 为何有效：我们的大脑厌恶不完整的信息，天生渴望获得答案。

+ 示例：“为何十家初创公司中有九家会在第二年倒闭？（真相并非你所想）”

### 3. 利益聚光灯

+ 提示词：“请创作一个标题，突出[产品/服务]最核心、最具吸引力的利益点，并聚焦于[具体、可衡量的结果]。”

+ 为何有效：多重利益会让人困惑，一个清晰明确的利益点才能促成转化。

+ 示例：“这个邮件模板，让我回复率提升了340%”

### 4. 水晶般清晰沟通者

+ 提示词：“请为[产品/服务]设计一个直截了当的标题，用连12岁孩子都能听懂的语言，解释其[主要利益]。”

+ 为何有效：混淆会扼杀转化，清晰则能促成转化。

+ 示例：“真正记得密码的密码管理器，让你再也不用费心记密码”

### 5. 痛点消除器

+ 提示词：“请撰写一个标题，精准识别一个具体痛点，并以提问形式配合人称代词，提供清晰解决方案。”

+ 为何有效：痛苦比愉悦更能驱动行动，提问能有效吸引注意力。

+ 示例：“厌倦了网站看起来像2005年的老古董？教你一个周末搞定它”

### 6. 具体利益放大器

+ 提示词：“请创作一个标题，以对话式语言，结合一个具体的数字，来突出一个有吸引力的利益点。”

+ 为何有效：数字显得更真实可信，对话式语气有助于建立信任。

+ 示例：“5分钟晨间仪式，让我的效率翻倍（而且比你想的简单得多）”

### 7. 转化承诺

+ 提示词：“请撰写一个标题，承诺通过[产品/服务]带来显著的生活改善，直接针对读者的痛点，并使用行动导向型语言。”

+ 为何有效：人们渴望的是改变，而非单纯的信息。

+ 示例：“从拖延症患者到高效机器：我是如何最终战胜我最大敌人的”

### 8. 简单化放大器

+ 提示词：“请创作一个标题，展示[产品/服务]如何将复杂挑战变得简单易行，并使用人称代词。”

+ 为何有效：我们常常感到不堪重负，简单的解决方案能带来解脱感。

+ 示例：“仅用手机和每周2小时，我如何打造了一个价值1万美元的副业”

### 9. 紧迫感制造者

+ 提示词：“请撰写一个标题，围绕[产品/服务]制造紧迫感或稀缺性，结合一个问题和具体数字。”

+ 为何有效：稀缺性会触发行动，提问能吸引注意力。

+ 示例：“仅剩3个名额：想加入今年已成功孵化47家企业的顶尖导师计划吗？”

## 超级提示词（一键搞定）

只需粘贴一次，它就能一次性输出涵盖以上所有角度的全套标题方案。

```
You are David-Ogilvy-meets-modern-CRO. Generate high-converting headlines for:
AUDIENCE: {who}
PRODUCT: {what it is}
PRIMARY BENEFIT: {core result}
PRIMARY PAIN: {main frustration}
PROOF/NUMBERS AVAILABLE: {metrics, social proof, timeframes, price}
TIMEFRAME: {time bound, if any}
TONE: {plain / bold / calm / premium}
OFFER/LIMITER (optional): {qty/date/tier}

TASKS
1) Generate 30 headlines across these archetypes (≥3 each): 
   Direct Benefit, How-To, Curiosity Question, “Reasons Why/List,” News/Announcement, 
   Pain→Solution, Specific Number, Transformational Before/After, Simplicity/Ease, Scarcity/Exclusivity.
2) Constraints: ≤12 words; use “you/your”; 1 number in ≥60% of lines; no hype words; grade-6 reading level.
3) For each headline, append: — {Archetype} — {Why it works in 1 short clause}.
4) Curate a TOP 10 set (diverse angles). 
5) Produce 5 A/B pairs that isolate ONE variable (e.g., number, timeframe, verb).
6) Output as a clean Markdown list, then a CSV block with columns: Headline, Archetype, AngleNote.

QUALITY CHECK (run before final):
- Is the core benefit explicit?
- Is there at least one specific number/timeframe?
- Would a stranger know what’s being offered?

Return only the list and CSV.
```

## 怎么快速使用

这其实是一套灵活的工具，提供了两种方法，应对不同需求：

### 用法一：【新手快用法】或【广撒网模式】

#### 适用场景：

+ 刚接触，想快速看到效果。

+ 创意枯竭，需要大量不同角度的灵感。

+ 不确定哪种风格最有效，想一次性多生成几种来测试。

#### 操作步骤：

1. 直接跳到文档后半部分的 `The SUPER PROMPT (one and done)`。

2. 复制整个黑色代码块。

3. 把里面的 `{who}`, `{what it is}`, `{core result}` 等占位符，替换成你自己的产品信息。

4. 将改好的内容发给AI，它会一口气给你30个覆盖了所有风格的标题。

### 用法二：【精细创作法】或【精准打击模式】

#### 适用场景：

+ 你非常清楚自己这次营销的**目的**。

+ 例如，你知道这次必须“制造稀缺感”，或者必须“打消用户痛点”。

#### 操作步骤：

1. 回到文档前半部分的 **“9个标题公式”**。

2. 根据你的具体目标，找到对应的那个公式。例如，想强调稀缺性，就找到 9. The Urgency Creator。

3. 只复制那一小段的 Prompt: 内容（例如：`"Craft a headline creating urgency or exclusivity around [product/service]..."`）。

4. 把这段单独的Prompt发给AI，并结合你的产品信息，让它进行专项创作。

也就是说，这份文档就是一个**双模式工具箱。**能复制运行的 Prompt 核心其实就两部分：9 个简短 Prompt、1 个大 Super Prompt。

简而言之：

👉 前面 9 个是“九宫格小兵器”，随挑随用。有目标、要精准 → 用前面9个小Prompt，指哪打哪。

👉 最后的 Super Prompt 是“大招”，一次出全套。赶时间、要灵感 → 用 SUPER PROMPT，大力出奇迹。

所以，如果你只想先试，建议直接拿最后那个 SUPER PROMPT 来跑一遍，填入你要写文案的产品信息，就能立刻感受到效果。

## 准备你的产品/服务信息：

在使用SUPER PROMPT之前，你需要提前准备好以下信息，以便填充Prompt中的占位符（附：一份供测试的产品信息）：

`PRODUCT:` 你的产品/服务是什么？（例：AI驱动的写作助手）

`BENEFIT:` 你的产品/服务的核心益处是什么？（例：节省写作时间，提高内容质量）

`PROOF/NUMBERS AVAILABLE:` 有什么数据、证明、案例或社会认同？（例：平均节省50%时间，转化率提高20%）

`OFFER/CALL TO ACTION (CTA):` 你希望用户做什么？有什么优惠？（例：免费试用30天，立即注册）

`URGENCY/LIMITER (optional):` 有时间限制吗？（例：仅限前100名用户）

`TARGET AUDIENCE:` 你的目标受众是谁？（例：内容创作者、营销人员）

`TONE:` 你希望标题的语气是什么？（例：专业、友好、幽默）
