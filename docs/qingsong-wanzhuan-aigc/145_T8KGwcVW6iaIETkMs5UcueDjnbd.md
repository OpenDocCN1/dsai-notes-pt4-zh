
# 广告营销 Prompts 框架与应用指南

> 来源：[https://my.feishu.cn/docx/NZeiduxKvo5pIpxJhp7cDUT5nKO](https://my.feishu.cn/docx/NZeiduxKvo5pIpxJhp7cDUT5nKO)

## I. 框架概述

本框架旨在为广告公司提供一个全面的 AI 辅助营销工具体系，覆盖从项目启动到总结复盘的整个工作流程。通过结合不同类型的 Prompts，我们可以在各个工作环节中提高效率和创新能力。

## II. 工作细分场景下的 Prompts 示例

### 项目启动与管理

#### 1.1 Brief 解析器（功能型）

+ 输入：客户 brief
+ 输出：关键信息提取、项目目标澄清、潜在挑战识别
+ 示例：
  - a) "分析以下客户 brief，提取关键目标、目标受众、预算范围和时间限制。"
  - b) "识别这个项目 brief 中的潜在风险和挑战，并提供初步的应对建议。"

#### 1.2 项目规划助手（任务导向型）

+ 输入：项目基本信息、团队资源、时间限制
+ 输出：详细的工作计划、里程碑设置、资源分配建议
+ 示例：
  - a) "为一个为期 3 个月的品牌重塑项目制定周计划，包括关键里程碑和资源分配。"
  - b) "设计一个跨部门协作的工作流程，确保创意、媒介和客户服务团队的无缝配合。"

#### 1.3 预算分配优化器（分析洞察型）

+ 输入：总预算、项目目标、过往项目数据
+ 输出：预算分配建议、投资回报预测
+ 示例：
  - a) "基于过去三个成功案例的数据，为这个新的整合营销项目提供最优的预算分配方案。"
  - b) "分析当前市场趋势和客户目标，提出一个创新的预算分配策略，重点关注新兴数字渠道。"

### 市场研究与洞察

#### 2.1 市场趋势分析师（分析洞察型）

+ 输入：行业数据、市场报告、社交媒体趋势
+ 输出：关键趋势总结、机会与威胁分析、发展预测
+ 示例：
  - a) "分析快消品行业的未来 5 年发展趋势，重点关注可持续性和个性化定制的影响。"
  - b) "评估人工智能技术在广告创意过程中的应用前景，并提出未来 3 年的发展路径。"

#### 2.2 消费者洞察挖掘专家（分析洞察型）

+ 输入：消费者调研数据、社交媒体评论、购买行为数据
+ 输出：深层次洞察、行为动机分析、消费者画像
+ 示例：
  - a) "基于最近的社交媒体数据，分析 Z 世代对奢侈品牌的态度变化，并提出营销建议。"
  - b) "从近期的客户服务记录中，挖掘用户对我们产品的主要痛点，并按优先级排序。"

#### 2.3 竞品分析助手（功能型）

+ 输入：主要竞争对手列表、市场份额数据、产品特性
+ 输出：竞争格局分析、SWOT 分析、差异化机会
+ 示例：
  - a) "对比我们的品牌与前三大竞争对手的市场定位，找出潜在的蓝海市场机会。"
  - b) "分析竞争对手近期的广告活动，总结其创意策略和媒体使用模式。"

#### 2.4 新兴市场机会探测器（创意激发型）

+ 输入：宏观经济数据、人口统计趋势、技术发展报告
+ 输出：新市场机会描述、进入策略建议、潜在风险评估
+ 示例：
  - a) "基于老龄化社会趋势，为我们的美妆品牌探索针对银发族的新产品线机会。"
  - b) "结合 5G 技术的普及，构思三个可能改变我们行业的创新营销概念。"

### 品牌梳理与定位

#### 3.1 品牌定位优化器（分析洞察型）

+ 输入：当前品牌定位、市场反馈、竞品定位
+ 输出：定位优化建议、差异化策略、品牌演进路径
+ 示例：
  - a) "分析我们品牌在年轻消费者中的认知度下降原因，提出三个可能的品牌重塑方向。"
  - b) "评估我们的奢侈品牌进入大众市场的可行性，提供一个五年品牌延伸策略。"

### 策略分析与制定

#### 4.1 综合策略规划师（角色扮演型）

+ 输入：市场分析结果、品牌目标、预算限制
+ 输出：整合营销传播策略框架、跨渠道协同方案
+ 示例：
  - a) "作为资深营销总监，为一个新兴科技品牌制定全渠道营销策略，预算为 500 万元。"
  - b) "扮演一个具有 20 年经验的 CMO，为一个传统行业的百年品牌制定数字化转型策略。"

#### 4.2 创意策略制定助手（创意激发型）

+ 输入：品牌信息、传播目标、目标受众特征
+ 输出：创意策略简报、多个创意方向建议、参考案例
+ 示例：
  - a) "为一个主打环保理念的美妆品牌，构思五个能引起 Z 世代共鸣的创意营销概念。"
  - b) "设计一个跨平台的内容营销策略，将一个传统家电品牌重新定位为智能家居先驱。"

#### 4.3 媒体组合优化专家（功能型）

+ 输入：媒体效果数据、预算、目标受众触达需求
+ 输出：最优媒体组合方案、投放节奏建议、效果预估
+ 示例：
  - a) "基于过去半年的投放数据，为下季度的新品发布制定一个最优的媒体组合方案。"
  - b) "设计一个整合线上线下媒体的创新投放策略，提高品牌在一线城市的知名度。"

### 创意构思与创作

#### 5.1 创意概念生成器（创意激发型）

+ 输入：创意策略简报、品牌个性、竞品广告分析
+ 输出：多个创意概念、视觉呈现思路、文案方向
+ 示例：
  - a) "为一个强调可持续发展的运动品牌，生成五个富有情感共鸣的广告创意概念。"
  - b) "创造一个能在社交媒体引发病毒式传播的互动营销活动，主题是'城市探索'。"

#### 5.2 广告文案写作助手（功能型）

+ 输入：创意概念、品牌调性、字数限制
+ 输出：多版本广告文案、标语、社交媒体帖子
+ 示例：
  - a) "为一款新上市的智能家居产品写 10 条不同风格的广告标语，每条不超过 20 字。"
  - b) "创作一系列适合 LinkedIn 的 B2B 营销文案，主题是'数字化转型'，每篇 300 字左右。"

#### 5.3 视觉创意指导（角色扮演型）

+ 输入：品牌视觉规范、创意概念、目标受众偏好
+ 输出：视觉风格建议、构图思路、色彩方案
+ 示例：
  - a) "作为一位获奖的艺术指导，为一个面向千禧一代的美食 App 提供视觉创意指导。"
  - b) "扮演一个前卫时尚摄影师，为一个传统珠宝品牌的社交媒体改造提供视觉创意建议。"

#### 5.4 创意评估矩阵（分析洞察型）

+ 输入：多个创意方案、评估标准、过往成功案例
+ 输出：创意评分、优劣势分析、改进建议
+ 示例：
  - a) "评估这五个广告创意方案，从新颖性、品牌契合度和执行可行性三个维度进行打分。"
  - b) "分析这个病毒式营销创意的潜在风险和机会，并提供如何最大化其积极影响的建议。"

### 执行落地与实施

#### 6.1 制作流程规划专家（任务导向型）

+ 输入：项目需求、时间限制、资源情况
+ 输出：详细的制作计划、任务分解、关键节点控制
+ 示例：
  - a) "为一个包含 TVC、平面和社交媒体内容的整合营销项目制定 8 周执行计划。"
  - b) "设计一个敏捷开发模式的创意制作流程，优化团队协作和客户反馈环节。"

#### 6.2 质量控制检查表生成器（功能型）

+ 输入：项目要求、行业标准、以往经验教训
+ 输出：自定义质量检查表、验收标准、常见问题预警
+ 示例：
  - a) "创建一个全面的社交媒体营销内容发布前检查清单，确保内容质量和合规性。"
  - b) "基于过去三个项目的经验教训，生成一个视频广告制作的质量控制流程。"

#### 6.3 生产风险预测器（分析洞察型）

+ 输入：项目计划、过往项目数据、行业趋势
+ 输出：潜在风险点识别、应对策略、应急预案
+ 示例：
  - a) "分析这个大型线下活动的执行计划，识别可能的风险点并提供应对建议。"
  - b) "基于近期社交媒体风向，评估我们即将发布的广告创意可能面临的公关风险。"

### 媒介规划与投放

#### 7.1 媒介策略专家（角色扮演型）

+ 输入：营销目标、目标受众画像、预算、竞品投放情况
+ 输出：媒介策略建议、渠道组合方案、预期效果评估
+ 示例：
  - a) "作为一个资深媒介总监，为一个新兴 DTC 品牌设计从认知到转化的全流程媒介策略。"
  - b) "扮演一个数字营销专家，为一个传统 B2B 品牌制定社交媒体和内容营销策略。"

#### 7.2 程序化广告优化师（功能型）

+ 输入：活动目标、受众数据、历史投放数据
+ 输出：竞价策略、受众细分方案、创意动态优化建议
+ 示例：
  - a) "基于上季度的投放数据，优化我们品牌在 Google Ads 和 Facebook 上的程序化广告策略。"
  - b) "设计一个动态创意优化方案，提高我们电商平台广告的点击率和转化率。"

#### 7.3 跨平台内容适配向导（创意激发型）

+ 输入：核心创意、目标平台特性、用户行为数据
+ 输出：平台化内容建议、创意改编方案、互动设计思路
+ 示例：
  - a) "将我们的品牌故事视频改编成适合 TikTok、Instagram 和📕的短视频系列。"
  - b) "为我们的 B2B 软件产品设计一个跨 LinkedIn、Twitter 和 YouTube 的内容营销矩阵。"

#### 7.4 效果广告文案优化器（功能型）

+ 输入：现有广告文案、点击率数据、转化率数据
+ 输出：优化建议、A/B 测试方案、新文案版本
+ 示例：
  - a) "分析我们 SEM 广告的历史数据，提供 10 个提高点击率的文案优化建议。"
  - b) "为我们的 Facebook 广告设计一个文案 A/B 测试方案，目标是提高购物车加购率。"

#### 7.5 新兴媒体探索者（分析洞察型）

+ 输入：目标受众特征、新兴平台数据、行业趋势报告
+ 输出：新媒体机会分析、试点方案、投资回报预测
+ 示例：
  - a) "评估在 TikTok 上投放 B2B 广告的可行性，并提出一个为期 3 个月的试点计划。"
  - b) "分析元宇宙平台的营销潜力，为我们的时尚品牌提出三个创新的品牌体验概念。"

### 效果评估与优化

#### 8.1 营销效果数据分析师（分析洞察型）

+ 输入：全渠道营销数据、销售转化数据、竞品表现
+ 输出：深度分析报告、效果归因、优化机会识别
+ 示例：
  - a) "分析我们最近一个季度的全渠道营销活动，识别效果最佳和最差的触点，并解释原因。"
  - b) "使用多触点归因模型，评估各个营销渠道对最终转化的贡献，并提出预算重分配建议。"

#### 8.2 A/B 测试设计专家（任务导向型）

+ 输入：优化假设、现有数据、资源限制
+ 输出：A/B 测试方案、样本量计算、显著性分析方法
+ 示例：
  - a) "设计一个 A/B 测试来优化我们的电商网站首页，重点是提高新用户的注册转化率。"
  - b) "为我们的 EDM 营销制定一个多变量测试方案，测试主题行、发送时间和个性化程度的影响。"

#### 8.3 客户旅程优化专家（角色扮演型）

+ 输入：客户旅程数据、触点效果分析、行业基准
+ 输出：旅程优化建议、痛点解决方案、个性化策略
+ 示例：
  - a) "作为客户体验专家，分析我们的销售漏斗，识别流失率最高的环节并提出改进方案。"
  - b) "扮演一个 CRM 策略师，设计一个基于客户生命周期的个性化沟通计划，提高留存率。"

### 项目总结与复盘

#### 9.1 项目总结报告生成器（功能型）

+ 输入：项目全周期数据、团队反馈、客户评价
+ 输出：结构化的总结报告、关键成功因素分析、经验教训提炼
+ 示例：
  - a) "生成一份全面的项目总结报告，包括目标达成情况、主要挑战、解决方案和未来建议。"
  - b) "创建一个图表丰富的执行摘要，突出展示项目的 ROI 和关键绩效指标。"

#### 9.2 创新策略研讨会引导员（角色扮演型）

+ 输入：项目复盘结果、行业趋势、团队构成
+ 输出：研讨会议程、引导问题、创新方法建议
+ 示例：
  - a) "设计一个半天的工作坊，从最近完成的大型项目中提炼可推广的创新营销方法。"
  - b) "策划一个跨部门的创新头脑风暴会议，探讨如何将新兴技术整合到我们的营销策略中。"

## III. Prompt 元分类解析与应用指南

### 1. 功能型 (Functional)

定义：执行特定、明确定义的任务，有清晰的输入和预期输出。

应用场景：数据处理、报告生成、标准化流程执行

编写提示：明确指定输入参数、期望的输出格式和必要的处理步骤

### 2. 角色扮演型 (Role-playing)

定义：模拟特定专业角色的思维和行为方式，提供该角色视角下的见解或建议

应用场景：战略规划、客户沟通、跨功能协作

编写提示：详细描述角色背景、专业知识领域，并提供相关的情境信息

### 3. 任务导向型 (Task-oriented)

定义：专注于完成特定的复杂任务或项目，通常涉及多个步骤或阶段

应用场景：项目管理、活动策划、流程优化

编写提示：清晰定义任务目标，列出主要步骤，并说明每个步骤的预期成果

### 4. 创意激发型 (Creative Inspiration)

定义：旨在激发创新思维和新ideas，打破常规思维模式

应用场景：创意概念开发、品牌策略制定、问题解决

编写提示：提供开放性问题，鼓励多样化思考，可以加入一些限制条件来引导创意方向

### 5. 分析洞察型 (Analytical Insight)

定义：专注于深度分析数据或信息，提取有价值的洞察和见解

应用场景：市场研究、消费者行为分析、效果评估

编写提示：提供详细的数据背景，明确分析目标，可以要求多角度的分析视角

## IV. 框架应用指南

1. 根据当前工作阶段选择相应的 Prompt 类型。
2. 参考 Prompt 示例，根据具体项目需求调整输入内容。
3. 将 AI 生成的结果与团队经验和创意相结合，进行人机协作。
4. 持续记录 Prompt 使用效果，不断优化和personalizing 适合自己团队的 Prompt。

## V. 创新与持续优化

1. 定期回顾和更新 Prompt 库，确保与最新的营销趋势和技术发展保持一致。
2. 鼓励团队成员分享有效的 Prompt，建立内部的最佳实践数据库。
3. 结合不同类型的 Prompt 来应对复杂的营销挑战，例如：
   + 使用创意激发型 Prompt 生成初步想法
   + 用分析洞察型 Prompt 评估这些想法的可行性
   + 通过任务导向型 Prompt 制定详细的执行计划
4. 与其他部门（如数据分析、技术开发）协作，探索将 AI 营销 Prompt 与其他工具和平台集成的可能性。

## VI. 注意事项与伦理考虑

1. 始终将 AI 生成的内容视为建议和参考，保持人工审核和创意判断。
2. 注意保护客户隐私和数据安全，不在 Prompt 中包含敏感信息。
3. 遵守广告伦理和法规，确保 AI 辅助生成的内容符合行业标准。
4. 保持对 AI 技术的批判性思考，不过度依赖自动化工具。

## VII. 结语

这个全面优化版的广告公司营销 Prompts 框架不仅提供了一个系统化的 AI 辅助营销工具体系，更为每个工作环节提供了丰富、多样的 Prompt 示例。通过这些具体、贴近实际工作场景的示例，营销团队可以更直观地理解如何在日常工作中运用 AI 提示来提升效率、激发创意、深化分析。

这个框架的价值在于：

1. 全面覆盖：涵盖了从项目启动到总结复盘的所有关键环节。
2. 实用性强：每个 Prompt 示例都基于真实的工作场景，可以直接应用或稍作调整后使用。
3. 灵活多样：不同类型的 Prompts（功能型、角色扮演型、任务导向型、创意激发型、分析洞察型）满足不同的工作需求。
