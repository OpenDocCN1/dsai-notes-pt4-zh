## ChatGPT 面向营销场景的用例与提示词

这是OpenAI学院设立的一个专为市场营销人员设计的ChatGPT应用指南和提示词库。它系统地围绕 活动策划、市场研究、内容创意、数据分析和品牌传播 这五大核心营销职能，为每个环节提供了具体的应用场景（Use case）和可以直接复制使用的提示词（Prompt）。其核心用途是帮助营销团队快速将AI工具融入工作流，从而激发创意、提升内容生产和数据分析的效率，并优化营销决策。

### 一、市场活动策划与策略 (Campaign planning & strategy)

#### 可视化市场活动时间线

```
为我们即将开展的多渠道市场活动创建一个时间线。关键日期和里程碑是：[在此插入信息]。以水平时间线的形式输出，包含阶段、负责人和截止日期。
```

#### 头脑风暴市场活动创意

```
为我们即将到来的[活动/发布会]构思5个创意市场活动点子。受众是[在此插入目标人群]，我们的目标是[在此插入目标]。每个点子需包含一个主题、一句口号以及1-2个核心策略。
```

#### 草拟创意简报

```
为我们的下一次付费媒体活动创建一份创意简报。以下是目标、受众和我们提供的产品/服务：[在此插入信息]。简报中需包含目标、受众洞察、语调、所需素材和关键绩效指标(KPI)等部分。
```

#### 构建信息框架

```
为一款新产品构建一个信息框架。产品详情如下：[在此插入信息]。输出一个包含3大支柱的表格：核心优势、论证要点和情感触发点。
```

#### 构建客户旅程图

```
为我们的[产品/服务]创建一个客户旅程图。我们的典型客户是[在此插入客户画像]。请将其划分为不同阶段，并说明每个阶段的目标、触点和潜在痛点。以表格形式输出。
```

### 二、竞争与市场研究 (Competitive and market research)

#### 竞争对手内容分析

```
研究排名前5的竞争对手是如何构建其博客内容策略的。分析需包括其语调、主题、发布频率、SEO重点和行为召唤(CTA)。请提供URL、关键要点，并用表格总结其通用策略和突出战术。
```

#### 研究购买者行为的新兴趋势

```
研究2024年[某类型]购买者在研究和评估[某行业]产品时的行为趋势。内容需包括行为转变、内容偏好和渠道使用情况。请引用来源，并以带有要点的简报形式呈现。
```

#### 研究区域性活动的基准数据

```
研究2024年针对[某地区]的数字营销活动的典型点击率(CTR)、每次点击成本(CPC)和转化率。重点关注[广告渠道]。请提供来源链接，并用表格按国家/地区比较各项指标。
```

#### 研究竞争对手在行业活动中的参与情况

```
汇总我们的竞争对手在[即将举行的活动]中的参与情况。包括展位活动、演讲环节、赞助情况和媒体报道。以表格形式输出，并附上链接和分析。
```

#### 研究营销人员适用的AI工具

```
按功能（如文案撰写、策划、分析、设计）研究最受推荐的营销人员[AI工具]。创建一个表格，包含其功能、定价、优缺点和主要应用场景。请附上来源。
```

### 三、内容与创意开发 (Content & creative development)

#### 草拟产品发布邮件

```
为我们的新产品撰写一封发布邮件。请使用以下关于产品和目标受众的信息：[在此插入详情]。邮件应具吸引力和说服力，并按市场营销邮件的格式排版，以便审阅。
```

#### 生成广告文案变体

```
为一个[渠道]广告活动创建5个不同的广告文案版本。活动主题和受众信息如下：[在此插入背景信息]。每个版本应测试不同的吸引点或语调。
```

#### 创作社交媒体系列帖子

```
草拟一个由3篇帖子组成的社交媒体系列，用于推广[活动、产品或里程碑]。请使用以下背景信息：[在此粘贴详情]。每篇帖子都应包含文案和建议的视觉内容描述。
```

#### 撰写客户亮点帖子

```
根据这个成功故事撰写一篇客户亮点帖子：[在此粘贴关键细节]。使其具有对话感、真实性，并与我们的品牌声音保持一致。以LinkedIn帖子的草稿形式输出。
```

#### 创作解说视频脚本

```
为一段60秒的关于[产品/主题]的解说视频撰写脚本。脚本需要涵盖以下内容：[在此插入信息]。使其语言精练、清晰，并提出视觉或动画建议。
```

### 四、数据分析与优化 (Data analysis & optimization)

#### 识别表现最佳的营销渠道

```
分析这份营销绩效电子表格，并识别投资回报率(ROI)最高的渠道。文件包含第一至第二季度在邮件、社交媒体、付费搜索和活动等渠道的营销活动数据。请总结排名前3的渠道，并创建一个按渠道显示ROI的图表。
```

#### 揭示客户流失模式

```
审阅这份客户流失数据集，并找出流失客户的共同特征。使用客户任期、产品使用情况和支持工单等列来归纳洞察。输出一份简短的摘要，并附上一个图表或表格，显示导致流失的主要风险因素。
```

#### 总结调研结果

```
从这份活动后的客户反馈调查中总结洞察。文件包括满意度评分和开放式回答。请提供一个3点的执行摘要和一张显示主要满意度驱动因素的图表。
```

#### 预测下季度的潜在客户数量

```
使用过去6个季度的历史潜在客户数量数据，预测下一季度的预期潜在客户数量。突出显示任何趋势、季节性模式，并输出一个简单的预测图表。
```

#### 优化活动预算分配

```
基于这份包含过往活动支出和回报的电子表格，为下一季度推荐一个修订后的预算分配方案。重点是最大化投资回报率(ROI)，同时减少在表现不佳渠道上的支出。以表格形式输出新的分配百分比。
```

### 五、视觉与品牌传播 (Visual & brand communication)

#### 制定品牌风格指南大纲

```
为[公司/产品]创建一个品牌风格指南的大纲。需包含字体排印、调色板、标志使用、语调、图像风格以及“应做与不应做”(do’s/don’ts)等部分。
```

#### 构思视觉化叙事

```
围绕[主题]为一个品牌活动构思3个视觉化叙事概念。每个概念需包括一个名称、视觉风格和关键叙事元素（如故事弧、情绪、色彩等）。
```

#### 创建视觉活动情绪板

```
为我们的[活动或品牌更新]创建一个包含4张视觉图的情绪板。主题是[描述主题]，基调应为[描述基调]。请使用写实或插画风格。
```

#### 评估品牌一致性

```
审阅以下营销素材[插入链接/文件]，并从语调、视觉和信息传递方面评估其品牌一致性。提出3个优点和3个不足之处，并附上改进建议。
```

#### 更新品牌识别概念

```
为更新我们的品牌识别提出3个创意方向。包括可能的调色板、字体风格、视觉主题和语调更新，以契合[受众/市场变化]。
```
