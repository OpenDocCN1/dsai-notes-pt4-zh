
# 人工智能的创造者：我们只有两年时间，一切即将改变！这些工作将在24个月内消失！

> 来源：[https://my.feishu.cn/docx/QrIwdsDRAo26QJxdtNPcuLMtnpg](https://my.feishu.cn/docx/QrIwdsDRAo26QJxdtNPcuLMtnpg)

人工智能先驱 YOSHUA BENGIO，被誉为**“人工智能教父”，揭示了代理型人工智能（Agentic AI）、杀手机器人以及网络犯罪的危险**，并阐述了为什么我们必须在为时未晚之前，构建不会伤害人类的人工智能系统。

Yoshua Bengio 教授是蒙特利尔大学计算机科学教授，也是三位最初的人工智能教父之一。他是 Google Scholar 上全球被引用次数最多的科学家，图灵奖获得者，同时也是 LawZero 的创始人——该非营利组织致力于构建安全、与人类价值观保持一致的人工智能系统。

他解释了：

- 为什么代理型人工智能可能会发展出我们无法控制的目标
- 杀手机器人和自主武器如何变得不可避免
- 已经在发生的网络犯罪与深度伪造（Deepfake）的隐蔽威胁
- 为什么人工智能的监管比食品安全法律还要薄弱
- 失去对人工智能的控制如何可能威胁人类的生存
