# AI在垂类领域的运用技巧

> 来源：[https://my.feishu.cn/docx/EmaZdnvMGovjXexlqwycfa8PnQd](https://my.feishu.cn/docx/EmaZdnvMGovjXexlqwycfa8PnQd)

金融、法律、医疗大模型应用的一份调研报告（来自得克萨斯大学达拉斯分校、卡耐基梅隆等机构发布的）

总结了这几个领域+LLM目前的应用方向

金融领域：

1.情感分析：分析金融新闻、报告来了解市场情绪，帮助投资者做决策。

2.信息提取：从金融文档中识别公司名称、股票代码等关键信息。

3.问答系统：构建系统以回答金融相关问题，帮助专业人士进行分析和决策。

4.股票走势预测：分析金融文本和历史股价来预测股票价格趋势。

5.方法：使用了大型预训练语言模型和特定领域训练数据来优化模型性能。

医疗领域

1.句子分类：对医疗文档中的句子进行分类，以提取有用信息。

2.临床信息提取：从医疗记录中提取关键医疗术语和缩写。

3.医学问答：基于模型的医学知识回答专业问题。

4.医疗报告生成：从医疗影像研究中自动生成报告。

5.方法：利用大型语言模型（如GPT-4）和医疗领域的特定数据集进行训练和微调。

法律领域

1.法律问答：回答与法律、法规和案例先例相关的复杂问题。

2.法律判断预测：分析法律文档来预测案件结果。

3.法律事件检测：识别法律文档中的显著事件或决定。

4.法律文本分类：对法律文档的不同部分进行分类。

5.法律文档摘要：将长法律文档压缩成简短的摘要。

6.方法：开发了专门为法律任务设计的预训练语言模型，并使用法律文书和案例数据集进行训练。

未来应用的挑战包括像是：

1、数据隐私和保密：在金融、医疗和法律领域，数据通常涉及个人隐私，需要在保护隐私的同时进行有效训练。

2、多模态数据处理：现实世界中的数据往往是多模态的，如医疗影像和法律文档中的图表，需要模型能够理解和关联不同模态的信息。

3、法规遵从性：在这些领域中，遵守严格的法规和标准是至关重要的，模型需要能够适应并遵循这些规定。
