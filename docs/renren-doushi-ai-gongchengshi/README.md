# 参与AI的**三个原则**

1.研究AI时，获取一手信源，而不是AI新闻。

**2.用AI解决实际问题。**

**3**.“AI的核心是为人服务。”对这句话的理解是：AI是工具，只是比其他工具更有价值。你可以用AI做决策，执行……等事情，但核心是你的需求。

#[市场（来源于42章经）](https://mp.weixin.qq.com/s/0XOBiRjjTR8KZIB5eRxS5g)

1）市场还早，大模型能力未达标，现在能落地能赚钱的公司大多是套壳的、擦边的、蹭的，真信 AGI，真想做 AI 的大多都在痛苦挣扎。

2）目前市场上所有的产品都将成为先烈和炮灰。这件事我们在移动互联网时代见的太多了，大部分产品会随着时间发展而淘汰，小部分产品会逐渐升级迭代成完全不同的逻辑。

我们实际上也看到了一些未来的方向和机会。

1）所有的现存外包场景都有机会用 ai 的方式和组织结构重做一遍，并扩大 n 倍。

2）大多双边平台都有机会被 ai 改造，非标服务可被 ai 标准化，生成式内容可把双边平台变成单边即可成立并快速起量。

3）大多复杂产品和交互形态都有机会被 ai agent 简化成聊天类产品交付，大幅降低使用门槛

4）内容生成即渠道，解构渠道

2024 年我们判断企业和选择项目的标准就是：

要不然就是能够落地的，能有规模性收入和利润的公司（这类公司我不仅不会介意你不够 AI，反而还会介意你太 AI），要么就是足够创新的公司（surprise me, pls)，而对创始人的要求就是想的够清楚，学习能力够强，最好能兼具生意能力和优秀创业者的特点。

个人点评（24年7月23日）：

#目前的AI

1.对于AI，我个人认为AI是能够成为各类产品底层的服务。

2.不用迷信AI，目前（2024年4月28日）的AI，还存在一定的缺点，很难生成满意的标准化产品，离不开人工参与。所以，如果你担心AI取代你的工作，不如先试着了解AI。可以预见的未来，AI会重度参与到我们生活的方方面面。

3.AI的边界，受限于使用它的人。如果使用者的能力不够，无法给出优质的指令（目前），那么AI也只会生成比较粗糙的内容。

4.举几个实际例子好了：翻译中的些许错漏，数据分析中存在的数据错误……这些错误在面对B端服务的时候，是很致命的问题。AI的准确性会影响AI的使用频率。
