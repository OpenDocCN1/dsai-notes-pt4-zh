## 一、前言：为什么这次不一样？

这些年我折腾过各种副业，但每次不持续的原因都有个共同点——让我很烦，很不自在，很不舒服、很不情愿。

**不说成果吧，那种感**觉就很糟糕。好像心里有个声音在说：这不是你该做的事。

但这一次，做AI自动化工作流，完全不一样。每天接触的都是新鲜的东西，反馈很舒服，内心也能接受。

我仔细想了想为什么，后来发现——以前写代码，我是按照项目经理的设计，按部就班地写。我就是个螺丝钉，负责其中一个小环节。

但现在做工作流，从设计到实现到部署，全是我自己说了算。这种掌控感，是当螺丝钉完全没法比的。

更重要的是，对于我们程序员来说，**n8n**、扣子、RPA这些东西，本质上就是低代码。我们本来就有编程经验，大脑里的神经元早就连接好了。一两天就能上手，根本不需要从头建立新的连接。这就像——你本来就会开手动挡车，现在让你开自动挡，还需要重新学吗？

这就是我为什么想把这个经历分享出来的原因。

它不仅让我赚到了钱，更重要的是，它让我找到了一个舒服的状态、更是一个长期的方向。

如果你也是程序员，如果你也在找副业，希望我的经历能给你一些启发。

**分享一个最近的感悟**：

前段时间看了个电视剧叫《老舅》，里面有个烧烤摊老板，最后成了最有钱的人。

为什么呢？因为老舅跟他说了一句话：你要去深耕这个行业，要找到蓝海。

于是他就离开了东北，去了广东开烧烤摊。你想啊，东北一条街有十几家烧烤摊，内卷得要死。 但广东呢？一条街一家烧烤摊都没有，他去就是刚需，就是蓝海。

但反观老舅自己，很聪明，却没有坚持自己的行业。20多年做了20来个行业，最后把身体累垮了，还没赚到钱。

这就是我想说的：**找到刚需，找到蓝海，然后深耕。**

AI自动化工作流，就是我找到的蓝海。而这一次，我不打算再换了。因为真的很好玩。

## 二、赛道发现：从超级标开始试水

### 起源：亦仁的超级标 + 别人的真实变现

![](img/967f01dbc41516b427912e24b95fa7f8.png)

我为什么开始关注AI工作流？

说实话，起因很简单。看到亦仁发了超级标，内容是关于AI自动化工作流。我一看，诶？这个好像挺适合程序员来玩的。

我看到别人的真实案例。有人用n8n工作流应用到公众号，有人用工作流做视频制作。关键点是什么？非常提效，而且真的能赚到钱。

这才是让我心动的根本原因。

于是我就抱着试一试的心态开干了。一开始没接触，我以为这是个多么高大上的东西。但当你一接触之后发现，这就是当年你看不上，但是现在你求之不得的东西。

它本身就是一个低代码平台。而低代码平台是先在我们程序员圈子里先流行起来的。我们当时也做过但是效果不太好。就是自己好久没关注这个，没想到在其他应用领域可以变得如此广泛。低代码不难，对于程序员上手来说，就个把小时就上手了。但是对于普通人来说，还是有一定定的门槛。

![](img/982583c57749e5ee00d556f776181837.png)

但我发现一个核心点：技术本身不难，难的是把业务逻辑理清楚。

程序员看低代码工具，就像老司机看自动挡汽车——上手快，但要开好还是得懂驾驶原理。

### 第一次尝试(最小的MVP)："垃圾视频"也能引流？

10月22号那天，我发了一个视频，内容是我写的一个pdf转markdown的Python脚本。

当时为什么要写这个脚本？因为我用cloud code来辅助读书，但很多书是pdf格式的，AI读起来很慢，我就想把它转成markdown，这样AI就能更好地理解和提取内容了。

发完我就没管了，也没想着会有什么效果。结果突然发现有人评论"求分享"、"这个怎么做"，私信里每天都有人来问。我当时就想，哦？这个好像有点意思。这不就是风向标吗？这不就是异常点吗？

![](img/2a281b3fb7858c5985214e630be7ce04.png)

![](img/d5df22baa71c03a89bf6d0e6893cb147.png)

这个经历让我明白了一个道理：**我觉得垃圾不重要，用户觉得有用才重要。播放量**不高没关系，精准流量多就够了，赚钱就行。

而且我发现了，这就是在用我们的**专业去打别人的业余。**别人觉得很难的东西，对我们程序员来说可能就是一两个小时写个脚本的事。这种技术壁垒，才是我们的核心竞争力。

### 为什么这个赛道有机会？赚什么钱？

#### 优势1：AI编程、工作流的"最后1公里"问题

这就像共享单车——

+   地铁到家，只有1公里，走路太累，打车太贵

+   共享单车解决了这"最后1公里"的问题

有了AI编程工具，写代码本身对很多人来说不难了。你想啊，现在有Cursor、Claude Code、工作流这些工具，敲个提示词就能生成代码，真的不难。

**95%的项目会帮你完善，但是总有会出现一两个问题，会耽误你很长时间。而**我们解决的就是这种问题。要是没有接触过AI、工作流那个那更是多，更是我们的客户。

#### 优势2：多维身份结合-程序员+做过多个副业项目。

**多**维身份结合 = 竞争优势。如果我一个学科得60分，那么我两个学科就是120分。那就大于一个学科的100分。

+   我会技术（程序员背景）

+   我也在航海混了10多期，每次航海东拼西凑一点，虽然我不是很精通，但是我知道它是什么，然后我就用ai去查。反而挺好用的。

很多人要么只会技术，要么只会自媒体。但这两个能力结合在一起，威力就大了。

**为什么？**

因为懂技术的人，不一定懂流量； 懂流量的人，不一定懂技术。

但我两个都懂：

我能做出技术方案，还能录视频、发自媒体、接单、交付。

这就是我的护城河。

技术 + 自媒体 = 1+1 > 2

#### 优势3：跟随着ai一起进步、顺势而为

当我自己脑子不够用的时候，这个时候ai每一次升级，相当于就是在带动我升级。主动拥抱ai，与ai共舞，这必将是趋势。

## 三、实际案例：不同的变现方式，没接单成功也能赚到钱

### 案例1：地坪大哥的888元订单

#### 为什么我要自动化自己？

说实话，一开始做视频的时候，我还在用手动操作。

剪辑、导出、上传...每一步都要我自己点。一边做一边想：如果我自己都手动操作，怎么去让客户信服？

这就像一个卖健身房的教练，自己一身肥肉，你怎么相信他能把你练好？

所以我决定：用影刀RPA来操作剪映剪辑视频，然后再发布视频到各个主流平台。

具体怎么做呢？

1.  影刀RPA操作剪映：自动剪辑、添加特效、导出视频

1.  影刀RPA操作发布平台：自动上传到抖音、视频号、小红书

1.  使用飞书多维表格来控制状态

1.  全程自动化，我只需要提供素材

我把这一流程录了下来，发布到自媒体上。(如图)

![](img/c3760fca192b89d85db65a54d6835293.png)

![](img/bc8a371d74102f62291e590af6899dcf.png)

![](img/0ec3353135acb6c2f463a9c6bb64d312.png)

![](img/d6a54af3d75e043822b9d04895c65958.png)

#### 第一单生意：地坪大哥是怎么找上门的？

视频发出去没多久，有个大哥私信我。

他说他是做车库地坪施工的，看我用RPA自动剪辑发布视频，想让我帮他做个类似的。

我一看，诶？这个需求挺有意思。

但我没马上答应，而是先聊需求：你具体要解决什么问题？

大哥说，他每天要拍很多施工视频，但手动剪辑太慢了，想自动化混剪+发布。

聊了几轮，确认是刚需，我报了888元。

大哥二话不说，直接转账了。

![](img/b5a1f9696884a87aaf04adc80a722a9a.png)

最后混剪没使用影刀RPA操作剪映，因为剪映经常升级。会导致元素无法识别。这样的话客户会经常来找我，我就会很麻烦。于是我又把我们航海里面的claude code的编程的技术又拿出来了。直接手搓了一个混剪的工具。这样操作简单，客户开心，我也舒心。

![](img/3537cd42f2c427396075710c4a5adf5e.png)

这件事让我明白了一个道理：

互联网就是一个巨大的市场，发布自媒体视频就像摆地摊：

+   **你出摊，他就有钱**

+   客户购买的原因千奇百怪：

+   觉得你长得像他初恋

+   今天股票大涨了，高兴

+   彩票中奖了，就想花钱

+   没有任何原因，就是想买

**核心认知**：

+   ❌ 错误理解：我要等视频做完美了再发

+   ✅ 正确理解：把自己暴露出来，只要"出摊"，就会有人来买

**地坪大哥为什么买单？**

他说："看到当年他创业的样子。"

这不是刚需，这是一种情绪价值的共鸣。如果他没遇到我，他可能会找别人，或者根本不买。

> **关键洞察**：不要纠结"为什么有人会买"，而是要先"出摊"。你永远不知道客户为什么买单，但你不出摊，就永远没机会

#### 收获与反思

+   收入：888元

+   启示1：不要一开始承诺太死，方案可能需要多次迭代

+   启示2：客户买的不是技术，而是"能解决问题的稳定方案"

+   启示3：**真诚沟通很重要（**大哥说"看到当年创业的样子"）

+   就是所有接到的自媒体项目，在生财都能找到解决方案。所以大家一定要用好生财AI：https://scys.com/ai ，写到这里我出现一个很简单的逻辑。就是你接到单，你就到身材ai来查询一下。如果有现成的或者出现了很多的案例，你就接。哈哈哈哈

就是说，你不能私下联系客户，说"你直接找我，便宜点"。

+   热门场景的自动化需求

+   标题生成：用AI工作流自动生成

#### 步骤2：录制方式

+   形式：口播 + 屏幕录制

+   结构：

1.  抛出痛点场景（"你是否每天要手动..."）

1.  展示工作流界面（拖拽、连线、配置）

1.  运行结果（"看，30秒处理完1000条数据"）

1.  不主动引导私信（避免平台识别引流）

#### 步骤3：多平台分发(RPA分发)

+   平台：抖音、小红书、视频号、快手、B站、油管（抖音、小红书、b站这三个效果很好)

+   频率：日更或2更（不强求日更）

### 客户筛选：避免被平台识别为引流

**我的策略**：

+   ❌ **不是**：别人一问就直接给微信号

+   ✅ **而是**：先聊需求，确认是目标客户再给微信

**筛选流程**：

```
平台私信
↓
先聊需求（你具体想做什么？）
↓
确认能做 + 对方是目标客户
↓
这时候才给微信号
↓
微信深度沟通
```

**为什么这样做？**

+   抖音/小红书对引流打击很严

+   直接发微信号容易被识别

+   先聊需求，平台无法判断你是引流还是正常咨询

+   提高了客户精准度（过滤掉无效咨询）

### 定价策略：从报范围到参考淘宝

#### 我的定价演变

**阶段1：报一个范围**

+   心里估算：这个需求值300元

+   报价：400-600元之间

+   最终成交：一般在500左右

+   逻辑：给客户还价空间，也是给自己空间

**阶段2：判断刚需程度**

+   在聊的过程中观察客户：

+   如果是刚需、很着急 → 价格报高一点

+   如果没啥兴趣、随便问问 → 随便报个价（反正不会买）

+   关键：**使劲聊，聊得越多越能判断**

**阶段3：参考淘宝定价**

+   步骤1：把客户需求描述整理好

+   步骤2：去淘宝问价格

+   例如：淘宝报1000元

+   步骤3：我报800元左右

+   逻辑：比淘宝便宜20%，客户觉得很划算4. 转化成交：脸皮要厚，但要有方法

#### 我的成交心理学

**核心理念**：

+   脸皮要厚（但要有方法）

+   要揣摩客户心理，要不卑不亢

+   提供情绪价值

+   学会"趁虚而入"

**客户心理分析**： 客户犹豫时，只有两种情况：

1.  **觉得价格贵了**→ 解决：适当降价

1.  **不是刚需，需求不明确**→ 解决：挖掘需求、帮解决实际问题（一般来找你买工作流的，这个是它的内容生产环节。那么你继续深挖一下，就再问一下他有没有内容分发环节，需不需要矩阵运行？这个时候还可以卖他一套影刀rpa 矩阵分发系统。)

#### **我的话术原则**：

+   ❌ 不夸大效果（"这个工具能让你月入十万"，实事求是，并不是说你买了这套工作流，别人能成爆款，你就能成爆款。）

+   ❌ 不制造焦虑（"不学就落伍了"）

+   ✅ 真诚沟通需求（"你具体要解决什么问题？"）

+   ✅ 如实说明能力（"这个我做得到，那个可能需要再研究"）

+   ✅ 超预期交付（多做一点，客户会记住）

+   ✅ **使劲聊**（提供情绪价值，建立信任，聊得越多，对方露出的细节越多，然后再从细节入手。）

**核心：使劲聊**

+   聊得越多，客户越信任你

+   聊得越多，越能判断真实需求

+   聊得越多，越能识别是不是刚需

+   形成"本能刺激"，客户不好意思拒绝

+   在某个瞬间，他就会成交

+   说到这里，大家会觉得使劲聊，会不会太浪费时间？肯定会浪费时间，但是前期要把这些每一步都走好，形成一个SOP，后面不管是用程序化，还是带别人，都是游刃有余。

> **关键洞察**：成交不是一次对话完成的，而是持续触达+情绪价值+趁虚而入。客户不是在理性的那一刻买单，而是在情绪波动的某一瞬间下单

## 七、避坑指南：我踩过的那些坑

### 坑1：追求视频质量完美，不要“屎上雕花"，先发再说

### 坑2：技术方案没考虑环境，导致多做无用功

+   现象：Mac开发，客户用Windows

+   后果：重新部署，浪费时间

+   建议：一开始必须问清楚系统环境

+   教训：不要假设客户和自己环境一样。后面要形成sop。

### 坑3：RPA依赖第三方软件升级

+   现象：影刀操作剪映，剪映升级就失效

+   后果：方案推翻重来

+   建议：评估技术方案时，要考虑稳定性

+   教训：RPA不是万能的，要考虑软件更新风险

### 坑4：先干活再谈钱

+   现象：客户说"帮我改一下"，我就开始改

+   后果：改完了对方说"太贵了"

+   建议：**先谈好价格，再开始工作**

+   教训：这是做生意，不是做慈善

### 坑5：直接给微信号被识别

+   现象：别人一问就直接发微信号

+   后果：账号被限流/封号

+   建议：先聊需求，确认是目标客户再给微信

+   教训：平台对引流很敏感，要学会"伪装"

### 坑6：定价随意没有标准

+   现象：看心情定价，300-800随口说

+   后果：有时定价太低亏了，有时太高客户跑了

+   建议：建立定价体系（简单/中等/复杂）

+   参考：先去淘宝问价格，再报自己的价
