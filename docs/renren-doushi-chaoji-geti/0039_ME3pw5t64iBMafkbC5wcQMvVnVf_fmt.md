## 先说结论

如果让我把这几个月的测试结果压成一句话，我会这么说：

2026 年的闲鱼矩阵微付费，在我看来，确实很像 2023 年的📕自然流和截流。

我这么讲，不是为了把话说得更刺激一点。

而是因为它同时满足几个条件：

1.  还能做矩阵铺量

1.  能承接明确需求

1.  能往私域导流

1.  投产比能打出来

1.  平台还没有被所有同行彻底打透

1.  账号和环境还有可操作空间

对我来说，一个值得认真看的流量入口，不是“偶尔有人跑出来了”，而是它同时具备这些条件，而且能持续验证。

闲鱼现在给我的感受，就是这样。

### 我们为什么会认真盯上这条线

这条线不是我们看别人讲得热闹，才临时决定做的。

去年 10 月开始，我们就和蝎子团队一起反复下场实测。

到 12 月，线下自营打 `AI` 粉和私域粉，已经能做到几千万曝光、每天稳定进线百人。

到 2026 年 1 月，这套东西在我们自己手里，已经不再是“能不能跑”的问题，而是“怎么把它跑得更稳”的问题。

也是从那个阶段开始，我越来越确定，这条路值得认真拿出来复盘。

因为它已经不是一个空判断了。

它背后有我们自己踩过的坑，也有一组组实测出来的数据。

### 我们自己跑到了什么

先讲结果。

到 2026 年 1 月，我们自己的自营账号，在闲鱼上做 `AI` 粉和私域粉，单月总曝光突破了 3000 万。

每天稳定进线超过 100 人。

单粉获客成本最低的时候，做到过 6 毛 左右。

更关键的是，这不是某一天突然爆了。

而是连续稳定出量。

对我来说，这一点比“某条链接偶然起量”更重要。

因为真正能做成业务的，不是某一次运气好，而是你有没有把前面的动作跑顺，让它开始稳定出量。

更适合下面几类业务：

+   服务类

+   咨询类

+   资料类

+   教学类

+   引流型产品

+   需要先拿咨询、再做私域承接的业务

如果你现在本来就在找一个低成本测试前端获客的入口，闲鱼值得做。

但前提是，你得接受它是搜索电商逻辑，不是短视频逻辑。

### 完成标准

> 你开始实操前，脑子里先记住一句话：

> 闲鱼拼的不是谁会喊，而是谁把基建、关键词、链接和数据跑顺。

## 二、准备阶段：先把基建搭对

先把设备、账号、`IP`、店铺基础权限准备好，别等到开始发链接了才发现前面没搭对。

### 准备清单

+   1-5 台干净安卓设备

+   可持续使用的支付宝/闲鱼账号

+   稳定的网络环境

+   鱼小铺权限

+   基础记录表：关键词、链接、类目、数据记录表

+   需要导流时用到的承接素材：网盘、备注图、二维码图、🛰️号图

### 具体动作

#### 设备怎么选

设备不需要贵，核心是干净、稳定、能长期跑。

你没必要上来就用贵设备，我们实测下来三折叠、苹果17promax和几百块钱的安卓机一样能跑，关键看设备环境是不是干净。

对大多数人来说，300 到 600 的安卓机就够用，重点不是设备有多贵，而是你后面能不能稳定铺开。

如果设备以前跑过别的平台，先确认设备环境有没有处理干净，再决定要不要继续用。

#### 账号搭建准备

通过系统性地模拟真实买家行为，在7天内快速、高效地提升新账号的初始权重。

闲鱼是基于“搜索”和“推荐”的电商平台，账号权重直接决定了后续商品获得的自然流量。

精细化的养号行为，本质是向平台算法证明“我是一个有价值的真实用户”，从而获得更高的信任与流量分发。

#### IP 和环境怎么配

这条线必须坚持 `1 机 1 卡 1 `IP``。

账号多的时候，再考虑软路由这类方案。

能开就尽早开。它会影响你后面的发布数量、权益和流量上限。

+   知道自己后面怎么持续补账号

+   鱼小铺能开则开

## 三、养号阶段：7 天到底怎么养

### 先记住养号的原则

养号不是放着等 7 天，而是连续 7 天模拟真实用户行为。

闲鱼是搜索电商，平台更看重你的真实浏览、搜索、互动、交易行为。你养号太敷衍，后面链接天然就弱。

![](img/922f358621ffdfa76430ad1a9750bd37.png)

### 7 天执行表

### 每天固定动作

+   刷推荐页 30-60 分钟

+   用搜索框搜不同类目

+   每个商品停留 15 秒以上

+   看商品详情，不要点进去就秒退

+   点“我想要”或做简单咨询

+   做签到

+   做任务中心里的免费任务

### 养号完成的判断标准

+   你已经连续 7 天在用这个号

+   中间没有频繁切换环境和账号

+   有搜索、浏览、互动、任务、交易这些完整动作

+   账号不是空号状态

## 四、模板调研：先找词，再找模板

### 先记住一个原则

模板调研不是抄同行，而是找到你该卡进去的关键词入口。

闲鱼不是你想卖什么就发什么，而是用户搜什么，你能不能出现在他的搜索结果里。

### 三种调研路径

#### 精准大类关键词调研

这是你的赛道统称词。

比如：

+   私域获客教学

+   抖音获客教学

+   📕获客教学

+   创业项目

+   论文服务

![](img/a7a7845a0630b4e536b30c8ad2297850.png)

这种词的特点是：

+   搜的人多

+   做的人也多

+   竞争最激烈

适合拿来干两件事：

+   先看这个赛道在闲鱼到底有没有需求

+   先找出头部同行的封面、标题、类目和表达方式

#### 衍生关键词调研

当大类词太卷，就往下拆。

比如“私域获客”这个大类，下面可以继续拆成：

+   SPA 获客

+   教培获客

+   创业粉获客

+   旅游获客

+   本地服务获客

![](img/516d74e41f40b6f0b18282fc4470b61f.png)

又比如“兼职”这个词，还可以继续拆成：

+   代发

+   代写

+   代拍

+   某具体兼职方向

衍生词的好处是：

+   人群更细

+   需求更具体

+   竞争通常更小

+   转化率往往更高

#### 周边产品关键词调研

这是很多人最容易忽略，但有时最好用的路径。

当你的主赛道词太敏感、太高危、太高净值，或者用户本身不习惯直接在闲鱼搜主词时，就用周边产品切入。

比如：

+   雪茄不一定好直接打，但雪茄剪、雪茄钳、烟灰缸这些周边词更好切

+   高客单业务不一定先打主服务，可以先用相关咨询、周边产品、周边资料做入口

![](img/23ced12e6f5d93c028df1188c3acfe84.png)

> 核心原则只有一个：

> 只要最终吸进来的人群是对的，入口不一定非要打最直白的大词。

### 调研后你至少要产出什么

每个赛道至少整理出 3 组东西：

+   5 个大类关键词

+   10 个衍生关键词

+   5 个周边产品关键词

同时，把每类词下跑得不错的同行链接整理出来，看 4 个点：

+   主图怎么写

+   标题怎么写

+   类目怎么选

+   价格怎么挂

### 完成标准

> 你发布前，手里至少有一份词表，而不是脑子里凭感觉有几个词。

## 五、发布前准备：先把链接做成能测的状态

先做出 2-4 条可测试的链接，再进入微付费阶段。

### 具体动作

#### 第一天先发 2-4 条链接

不要一上来铺十几条，也不要只发一条。

第一天发 2-4 条的目的，是为了拿到初步数据，后面从里面选出最值得投的一条。

#### 主图和标题优先处理好

闲鱼里用户最先看到的就是主图和标题，所以这里是点击率核心。

主图重点：

+   放关键词

+   放痛点

+   放卖点

+   要让用户一眼知道这条链接跟他的需求有关

标题重点：

+   带上核心关键词

+   不要太虚

+   要让用户知道你在解决什么问题

#### 类目不要凭感觉选

同样的赛道，不同类目、不同主图、不同标题，最后跑出来的价格和咨询量可能完全不一样。

所以类目本身也是要测的。

![](img/eff8d3e7eead5c48e5844654e509aa8d.png)

#### 发完先别急着投

先放 24 小时，看基础曝光、浏览、想要，再决定投哪条。

另外，用别的账号去搜你铺的关键词，确认你的链接能不能被搜到。如果搜不到，先别着急投。

### 发完先自检

+   链接能不能搜到

+   主图上有没有核心关键词

+   标题里有没有关键词

+   类目是不是你刻意选来测试的

+   价格是不是你能承受的

+   描述是不是至少把交付说清楚了

## 六、微付费起号：真正开始跑数据

### 这一步的核心不是赚钱，是两件事

1.  快速测出哪条链接值得继续打

1.  让店铺尽快积累有效成交和评价数据

### 具体动作

#### 24 小时后先选链接

从你发的 2-4 条链接里，优先挑：

+   浏览高的

+   想要高的

+   咨询意愿强的

不要只盯曝光。曝光高不等于这条链接值得投，浏览和想要更能说明用户是否愿意点进来、愿不愿意继续往下走。

#### 用超级擦亮里的自定义询单去测

微付费阶段，核心不是大投，而是小预算测。

建议动作：

+   每次先选 1 条链接测

+   单条计划先按小预算跑

+   先跑 1 周左右，再看是否继续放大

#### 预算怎么理解

你前期的预算，是拿来买判断的。

重点不是“今天一定要回本”，而是用尽可能小的成本，尽快确认：



+ 这条链接能不能带来咨询
+ 这条链接吸来的用户准不准
+ 这个类目和表达能不能接住需求

## 微付费阶段最常见的 3 种情况

### 情况 1：空烧

表现：

+ 钱在花
+ 曝光在涨
+ 咨询很少甚至没有

说明：

这条链接被看到了，但没把人点进来。

优先改：

+ 主图
+ 标题

不要先乱改投放设置。先把“用户为什么不点”解决掉。

### 情况 2：能烧动，但出价偏高

表现：

+ 有咨询
+ 预算能消耗
+ 单个咨询价格明显偏高

说明：

人群还没完全跑准，或者当前类目、词、主图的匹配度还不够好。

优先动作：

+ 先观察 2-3 天
+ 同时复盘类目、人群、关键词
+ 如果这条链接本身咨询质量不错，不要一上来就砍掉

### 情况 3：曝光低、浏览低、咨询低

表现：

+ 各项数据都弱

说明：

这条链接整体就不强，不值得继续烧。

优先动作：

+ 直接放弃
+ 重新换词、换主图、换表达、换链接测试

### 完成标准

> 当你出现下面的状态时，说明这一步已经跑顺了：

+ 至少有 1 条链接能稳定带来咨询
+ 你开始知道什么样的主图和标题能把用户吸进来
+ 店铺开始有成交和评价数据

## 七、数据优化：怎么看曝光、浏览、想要

通过数据判断问题出在哪一层，而不是凭感觉乱调。

### 三个核心数据先看懂

+ 曝光：你的链接被平台推到别人眼前了没有
+ 浏览：别人看到了之后，愿不愿意点进来
+ 想要/咨询：点进来之后，愿不愿意继续往下走

### 数据判断速查表

### 你每天复盘时就盯这几件事

+ 哪条链接的浏览最高
+ 哪条链接的想要最多
+ 哪条链接开始出现稳定咨询
+ 哪条链接反复优化还是没起色

你后面要做的不是“所有链接都救”，而是把有机会成为爆款的链接维护好，把弱链接及时换掉。

### 完成标准

> 你已经能根据数据判断：

+ 该改主图还是改标题
+ 该改描述还是改类目
+ 该继续烧还是直接放弃

## 八、导流与承接：咨询来了以后怎么接

### 先记住导流原则

优先走 拍下后导流。

不要一有私信就急着硬拉。很多号不是死在没流量，而是死在太急。

### 标准顺序

1. 用户拍下链接
1. 你先完成发货动作
1. 发导流承接内容
1. 用户按备注、二维码或🛰️号来加你
1. 你在🛰️里继续承接和转化

### 承接内容怎么放

常见做法是用一个网盘页，把几样东西一次性放好：

+ 备注说明
+ 🛰️号
+ 二维码
+ 简单引导语

这样用户点开后，不用反复问你，也更清楚下一步该干嘛。

小技巧：优先用夸克，毕竟他也属于阿里体系下面的

百度网盘还需要复制到浏览器才可以看

### 两种最常见情况怎么处理

#### 已读未加

说明用户看到了你的导流信息，但没行动。

这时候要补一句提醒，不是催命，而是让他知道：

+ 你要给他安排什么
+ 为什么现在就该来加
+ 晚了会损失什么

重点是补“行动理由”，不是单纯再发一遍二维码。

#### 未读未加

说明用户买了，但还没真正看信息。

这时候要做的是提醒触达，让他回来看消息，而不是立刻追加一堆新话术。

### 哪些动作最容易把前面白做

+ 没拍下就急着硬导流
+ 导流话术太直白
+ 咨询一多就乱发违规内容
+ 链接刚起来就把号搞废

### 完成标准

> 你至少已经有一套固定承接顺序：

+ 拍下后怎么发
+ 网盘里放什么
+ 已读未加怎么补
+ 未读未加怎么提醒

## 九、自然流阶段：号起来后每天怎么维护

### 进入自然流阶段的标志

+ 微付费阶段已经有稳定咨询
+ 店铺有基础成交和评价
+ 不只一条链接有反应
+ 停掉付费后，依然有自然咨询进来

### 每天固定动作

#### 每天上新 1-2 条链接

就算已有链接在跑，也要保持上新。

原因有两个：

+ 新链接会带来额外曝光
+ 你永远不知道下一条会不会成为新的爆款链接

#### 每天复盘数据

重点看：

+ 哪条链接还在持续进咨询
+ 哪条链接开始掉量
+ 哪条链接浏览高但咨询低

#### 继续做日常任务

**签到、任务中心、闲鱼**币这些动作，不是起号阶段才做，而是只要你在跑闲鱼，就要持续做。

#### 用闲鱼币去放大强链接

闲鱼币更适合投给已经跑出浏览和咨询的链接，快速把人群标签拉正，而不是瞎投给弱链接。

#### 把回复效率拉上来

自然流阶段，回复慢会直接影响店铺状态。

如果你号多，可以用工具统一收消息、做自动回复，但前提是你的基础流程已经跑顺。

### 日常维护清单

+ 每天上新 1-2 条
+ 每天做签到和免费任务
+ 每天看链接数据
+ 每天优先回复有效咨询
+ 每天观察爆款链接有没有掉量
+ 每天把弱链接和强链接分开处理

### 爆款链接的 3 个不要

1. 不要乱改爆款标题
1. 不要频繁上下架爆款链接
1. 不要大改爆款主图

爆款链接可以微调，但不要大动。很多人不是没爆款，而是把有机会的链接自己折腾死了。

### 可以加上的放大动作

+ 闲鱼币折扣
+ 两人小刀
+ 闲鱼联盟返佣

这些动作的本质都是增加链接的点击和分发概率。

### 完成标准

> 你已经进入“每天维护店铺”的状态，而不是“今天有空就看看，没空就放着”。
