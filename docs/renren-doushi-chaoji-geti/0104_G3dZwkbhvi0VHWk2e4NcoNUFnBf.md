# 一、店群投入成本介绍篇

> 以10个店铺为例，100个店就是成本*10

+   1、一次性固定成本

+   1、小红书实名账号-70元/个

+   2、一台500元左右的电脑主体，单台电脑可以挂在8-10个店铺

+   3、个体户营业执照成本，150左右/个，一个个体户挂4个店铺

+   2、动态成本

+   1、关联手机号套餐，5-8元/月

+   2、一个创客贴会员，10元/月

+   3、一个百度网盘的会员，13/月

+   4、阿奇索会员，138/年

+   5、电费+客服费用 暂不统计

> 以10个店铺为例【用阿奇索场景】

1、固定成本

70*10+500+150*2=1500

2、动态成本/年

5*10*12+10*12+13*12+138*10=2256

> ----------------------------------------------------------------------------------------------------------------

> 1、第一年:  1500+2256=3756

> 2、第二年起:2256/年

> ----------------------------------------------------------------------------------------------------------------

>
