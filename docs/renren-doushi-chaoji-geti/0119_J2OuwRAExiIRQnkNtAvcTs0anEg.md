# 四、短视频平台的选品技巧

主流平台分为电商平台和短视频平台，这两类平台的底层逻辑有一些差别。

我们的选品原则也是结合平台性质展开的，具体阐述如下：

## （1）技巧一：产品的功能或特点容易通过短视频展示

拍短视频的时候，要优先选择**强视觉差异或核心功能**的单品（如可伸缩餐桌）**，方便在视**频中展示卖点。原因是短视频是“货找人”的场域，用户在刷t**k的时候本来只是**消遣一下，不像电商平台是带着目的性的“人找货”，所以要抓住用户是冲动消费为主导的这个特点。

> 可伸缩餐桌参考图：

![](img/d876a47910fe2cdbfdb6d43fefa08263.png)

尽量不要选择平平无奇的产品，比方说一个没啥特点的桌子。

也不用担心卖的太奇特了，别人光看不买，这只是引流步骤，接下来我们还有销转，还会给客户私发我们的产品单。

## （2）技巧二：优先选择“自带评论基因”的产品

**咱**们总是听说做线上要有网感，那么清秋给大家分享，培养网感的一条路径：刷短视频的时候，先不看评论，自己揣测用户会说什么，这是锻炼大家找爆点的能力，更是创业需要的揣摩人性、揣摩用户心理的手段。同样刷视频，我们比别人多做一步，我们就更能在残酷的市场竞争中活下来。

那么这个应用到选品上，我们可以想一想，面对这个产品，有什么想说的吗？如果除了问价之外想不到用户还会说什么，那这个产品的产品力就不是特别好。当然，这种情况下这个产品不是不能选，具体还要结合其他因素分析。

咱们第六部分的酒水柜，这个产品的“产品力”就很好，所以没有复杂的剪辑就爆了，tiktok的用户自发讨论这个柜子装香水、墨西哥卷的场景balabala

## 原视频的爆点是什么？

首先清秋先分析脚本做得好的地方，也就是爆点，然后再分析哪里还可以优化。

**优点：**

①**多机位拍摄+运镜**：

多机位的好处，清秋觉得第一点是**从视觉上增加信息密度**。我们刷短视频的时候，耐心程度都是随进度条递增的，也就是说，开头的时候决定了用户是不是留下来继续看。而这个章鱼沙发开头就是有一些运镜技巧在的，而且拍摄团队很巧妙的把沙发拆装成单个座位和整个章鱼的步骤省略掉，直接展示成果，这也是增加信息密度。

关于信息密度这个点，清秋稍微展开说一下：举个例子，一个女生口播：“很多人都担心自己的闺蜜会和老公...”、“咱们就说这个女人的格局一定要大...”背景恰好就是自己的闺蜜和老公在后面聊天，那她如果说就在自己的房间里说，肯定没有这种多一层视觉信息效果好。就算她再讲述一下闺蜜和老公聊天，这个进程也很慢，开头的信息不够爆炸，违背了耐心递增的原则。

## 办公桌-埃及

![](img/7030f8cab5eebc8fc9708e51a1decfd4.png)

[Download (4).mp4](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/LLjHberhIol66yxEU8XcMILonXc)

这**个视频是7月8号发布的，有**1101条评论。用的是埃及语言，一款非常普通的桌子，评论区几乎清一色全都是问价的，而且基本都是埃及人。清秋推断是埃及市场太好做了，大蓝海。这整个视频都平平无奇。

如果清秋做这条视频，我会在短视频下面写1-2行的文案：

短视频下面通常有一个能显示两行文案的地方，这个地方我们一定要写，不能空着。而且最好就写1-2行，不要让用户还要点开。

原因有三：

1️⃣这相当于平台多给了我们一次展示卖点、制造话题的机会，不写就是浪费这个机会。而且最好和视频里面加的字不一样，不要照搬。大家想一想，抖音刷的视频，是不是这里的字和视频里的都是不重复的？因为这又是我们一个增加信息量的机会。

2️⃣语言本身就能起到流量筛选器的作用，比方说我们就想做德国，打上德语小字能帮我们过滤到其他非目标国家用户，他们刷到就划走了，能使我们的人群更垂直。

3️⃣写1-2行就不用说了，这让用户一眼看到重点信息，字多了阅读麻烦，用户可能就不想看了。推荐这里放一些幽默的梗。
