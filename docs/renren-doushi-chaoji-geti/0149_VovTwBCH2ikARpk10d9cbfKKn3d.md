# 第一次选择，北漂这10年让我成长，去见识，去尝试

90后的小镇做题家，记得是在06年应该是我开始接触互联网，开始了我的网络生涯，所谓的网瘾少年，通宵打游戏，结果成绩从班级里面的前三名一路跌到倒数前三名。

考试一落千丈后在思考自己未来的生活，只能靠自己，上大学觉得也是去学校打游戏(年少无知)，

觉得浪费时间，自己去报计算机的培训机构，当时就是单纯的觉得互联网计算机有前途，有意思。

期间有一个很有意思的事情，让我终身难忘，学校需要让学生兼职(有偿)去一些展会发传单，报名制，我成了唯一一个没有被选上的幸运儿，当时的打击很大很大，以至于后来特意去体验了下发传单。

+   **QQ空间制作**

自己在线下买的流量卡帮别人卡QQ黄钻红钻等等其他的,大概当时官方的价格一个月一项是10块钱，做下来一般都是一个月4钻会员都是25块钱左右，一张卡的成本在10块钱，利润还算可以。

当时很多卡盟也在做这部分认识的朋友做猫池做淘宝的那一批都赚到几百万的样子。

+   **倒爷**

个人比较喜欢QQ号，所以一直在做倒爷搞一些数字的东西，一般都是低买高卖，还有屯一些稍微好一些的56789位的QQ号等着客户来卖，属于靓号类业务，各位平台的账号也在做，比如一些邮箱什么的，

当时哪有什么投资理念，要有投资理念搞一些域名也赚钱了~还是认知不够，

## 焦虑是好事会推着你走出舒适圈，

北漂近10年，期间面临了很多种跳槽的选择，前几年还好，主要是在沉淀，成长，

到了后面5年左右，基本上都是在躺平的状态，但是好像一直都在跳槽的路上，

拿过几次不错的offer，但最终都没有跳出舒适圈。

现在想想确实要提前逼着自己去尝试，

看着眼前的利益最终会因小失大。

老东家每次都给涨工资，挽留，自己舍不得，把自己框死。

俗话说人挪活树挪死，人还是要不断的破圈，长知识，

不要当井底之蛙，跳出来后会发现有不一样的天地。

最主要的还是自身原因，

认知不够，没有清晰的规划

最终的结果错过了最好的职场机遇。

北漂的后几年感到一种深深的焦虑。

表面上看，我的生活还算不错，有稳定的工作，不错的收入

每天的工作内容变得越来越重复，没有新的挑战，也看不到太大的成长空间。

我开始怀疑，如果继续这样下去，10年后的我会是什么样子？

北京的生活成本很高，房租、交通、餐饮，每个月的开支都不少。

虽然工资也在涨，但总感觉达不到自己的要求，

思考自己未来的路，难道我的一生就是这样按部就班地过下去吗

开始频繁地失眠，躺在床上想着各种问题，真正想要的是什么。

竞争力在哪？如果明天我从这里离职，我还能做什么？

这些问题让我越来越焦虑，也让我意识到，要做出改变了。

**我心里只有一个念头：

要换一条路，**去试，哪怕再苦一点，大不了重头再来，本来就一无所有，我还年轻。

## 职场生涯的最后挣扎

回到石家庄后，然后紧接着就是我一年4份的工作历程开始，

![](img/311ea2dfe2c750ebc6c8196be266aa0e.png)

职场上有一个这样的说法，如果在一家公司待的时间够久，

出来后大概率很难稳定，因为你已经适应了当时的那套工作模式，

下面开始验证~

+   第一份，在一家上市公司的做软件的项目经理，比较轻松自由，就是薪资水平不太高，一般就是朝9晚6，也没人盯着。一周的工作不到2天就可以做完，剩下的时间基本上就是天天打游戏，生活规律一些， 调整下这个一下状态。维持不到1年，自己的状态调整的差不多，躁动的心开始不安起来，觉得工资太低，没有什么发展前途，收入不够自己消费的，当时有房贷，如果各种消费加起来以及后面的考虑就开始又物色新工作。

+   第二份：在一家外地的初创公司(几十个人)里面做项目经理和阿里云在做合作，

+   第三份：一家上海的做医疗智能化产品，负责整个华北区的业务团队的管理 。

+   第四份，一家上市公司，在本地的分公司，无论是从行业前景或者工作内容，以及发展来说还算不错，各种五险一金按照全额缴纳，福利水平都还行，业内算比较不错的。

当再次选择离开，这次，自己也不解释。

因为成长有时候就是在别人眼里的“折腾”

如果不能坚持，那就宁愿重新开始，只要方向还在，慢一点又如何

# 写给正在勇敢尝试的圈友们

回顾这几年的经历，我最大的感悟是：选择比努力更重要，方向不对，努力白费

比如说我而言，**找对圈子（生财）+ 选对赛道（AI+公**众号）+ 用对方法（从0到1再到规模化）

找对圈子、选对赛道、用对方法，这三件事，决定了你能不能从泥里开出花。

所以给正在选择的三句话：

+   认清自己，而不是模仿别人；

+   顺着时代的风，而不是对着风跑；

+   做能让你心亮起来的事，而不是只算投入产出比。

你会发现，当路选对了，风吹过来时，你轻得像叶子。

## **从0到1，如何迈出第一步**

**很多人问我要怎么从 0 **开始

先去做，先去摔，再去改。

不要追求一开始就做得很完美，先做出来再说。

我的第一篇文章写得很烂，第一个公众号的定位也不清晰，

**行动是治疗恐惧的良药，很多时候，**你以为的“难”，往往只是自己大脑的幻觉。

试着去做一个最小的项目，试着赚到第一个一百块。

那不单单是“钱”，而是一颗信心的种子，

一旦发芽，就再也回不去了。

只有当你验证了模式的可行性，再考虑加大投入。

互联网时代最珍贵的，是速度，

小步快跑、快速试错、一点点验证。

每多一次尝试，你就多一次靠近成功的机会。

我们每周都会调整一次，根据数据反馈来优化运营方法。

## **从1到10，如何规模化放大**

当你有了第一个结果，记得真正的考验，才刚开始。

放大不是拼命，而是**如何正确的复制**

只有当经验被标准化，你才能用一双手，带动更多手。

然后是团队，别害怕找人。

一个人很快，但一群人能翻山。

你要学会相信别人，让彼此成就。

更要学会借力

借技术的力，让效率暴涨

借平台的力，让曝光翻倍

借人的力，把你推到更高的舞台

别逞强，一个人的能力精力有限，一定要合作，共赢。

> **要学会借力、借势、借智。**

## **如何应对挫折和焦虑**

没人能一直状态好，创业、写作、内容、副业……任何路上都有坑。

接受不确定性，创业就是在不确定性中寻找确定性，要学会接受这种不确定性，而不是被它击垮。

也曾在流量跌到谷底时，彻夜难眠，后来学会接纳，没人能一直赚钱，一直有流量，调整好心态再次出发即可。

**坚持不一定成功，但放弃，一定失败，你能忍**住不放弃的那一刻，就是奇迹开始的那一刻。

一个人走得快，一群人走得远，找到同频的伙伴，可以在你迷茫的时候给你方向，在你沮丧的时候给你力量。

## ** 给三类圈友的个人分享**

### **还没开始的**

很多人想得太多，做得太少。与其纠结于各种可能性，不如先迈出第一步。

+   选择一个成本低的项目开始

+   设定一个最小的目标（比如赚到第一个100块）

+   给自己设定一个时间期限（比如3个月）

### **快要放弃的**

> 刚开始一定是没有收入的，但是你能坚持下去，就PK掉了90%的人

大部分人都会在最困难的时候放弃，如果你能坚持到最后，就已经超过了大多数人。

我知道，那种心碎的焦虑，别灰心，你能熬下去，就赢了九成的人。

降低期望，重塑方向，关注成长，能力的积累，永远比短期收益更重要。

这一段难熬的路，正是你破茧成蝶的必经之路。

### **想要放大的**

> 打开自己，从单兵作战变成团队作战，走出去看一看

单打独斗有天花板，要想做大必须学会借力。

+   参加更多的线下交流活动

+   主动分享自己的经验和资源

+   寻找合适的合作伙伴

一个人可以走得很快，但一群人才能走得更远。
