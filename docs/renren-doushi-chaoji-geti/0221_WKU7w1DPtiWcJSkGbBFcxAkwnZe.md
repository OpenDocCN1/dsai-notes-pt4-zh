## 穿越周期的流量公式与矩阵公式

这两三年，我应该说拿到了一个又一个的结果，也提炼出了能穿越流量周期的方法论。

无论是PC还是移动时代，我就是通过这套底层打法，穿越周期持续拿到了一些结果。无论是客户还是自己项目，绝非碰运气都有大结果。

+ 陪跑客户（建材业）：账号数量 300+，全年创收 2000W+

+ 面授学员（快消品）：账号数量 200+ ，月营收 100W+

+ 合伙项目（旅游业）：账号数量 600+，日均加微 1200+

+ 自己项目（机器人）：账号数量 20+，📕霸屏度 70%

首先是关于流量。

新媒体时代的流量 = 内容 × 账号 × 分布。如果放到 PC 网站，流量 = 内容 × 网站 × 分布。

我一直认为我并不怎么懂 SEO，但比较搞笑的是：

+ 我曾经是佐卡伊珠宝网奠基人，日均访客十万，比后面第二名到第十名的总和还要多。

+ 我也曾经是新浪爱问 SEO 负责人，日均访客千万，这个体量的搜索 UV 就是超级巨无霸。

非要说我做对了什么，就是整天琢磨怎么把内容搞得多多的（不要想当然，认为搞多就是搞大量的垃圾）。在内容量级优势之下，那些各种想当然的小操作，毫无意义。

其次是关于矩阵获客。

在长期与大量的实践中，我提出了一个非常科学简单粗暴管用的矩阵获客公式 —— 矩阵获客 = 内容力 × 基建力。当然，到了今天这个公式也需要升级一下逼格了。矩阵获客公式 —— 矩阵获客 = 内容力 × 基建力 × AI 力。

流量公式与矩阵获客公式，差不多有一一对应的相通之处。

内容力是打赢矩阵获客的最重要的力。搞矩阵，不要被看起来繁杂的玩法欺骗了，真正重要的只有一条：你用有效的内容去平台换取流量，以海量优质内容来释放矩阵获客的威力。很简单的道理，发一篇内容有一篇内容的流量，那么为什么不多发呢？

好的内容力有四个要素：低成本、高效率、大规模、有效性

矩阵获客中最大的成本一定内容成本。很多人模式跑通了，但往往是内容成本打不住。

+ 劣质的内容，动不动就废号，地主家也没有这么多号让你瞎搞

+ 优质的内容，一人一天两三篇，你赚到的血汗钱都给了小编了

我举个我自己的例子，我在入局旅游赛道项目之前，合伙人实际上是已经跑通了模型的。但一旦扩量，就可能面临亏损。这些号分了多种打法。其中有一种打法数据是这样的：一条线索的背后是两个号+每个号发三条视频。也就是说一条线索背后是六条视频。一条线索是30到80，一般生产六条视频的人力成本是远远高于 80 的。这么说吧，一个熟手，一天产出五条视频，那就是能手中的能手了。如果把一条视频的成本干到一两块钱一条呢？是不是就豁然开朗了。

特别需要注意的是：**内容的生产，一定要集约化**。对，就是苏联模式的集约化。因为确实一个人能一天干出一千条作品，如果干不出，那就再加两个人。但千万不能分配到十几个甚至几十个人。

基建力主要包括三个要素：账号、设备与网络。

如何搭建基建，本质就是个信息差，属于你看懂了就秒懂。B 站上有大量的教学，动手强一点的完全可以自己搞定。不要怕，相信自己，我是认真的。

不过，需要注意的是，**基建力更底层是「组织力」**。举个例子：你能调动多少账号？可以思考下，是不是对很多公司来说，搞定上千个账号这是很小 case 的事情，而对你来说，搞定几十个就犯难。

AI 力，这个提法是我最近加上去的。我确实也是受不了大家天天提 AI，我感觉我不提 AI 好像就是上个世纪的老古董了。就算是作为强调吧，把 AI 力加入到了公式。确实，做矩阵获客本质就是从效率中攫取利润，而 AI 恰恰是效率革命的代名词。当然，我之前就是干 RPA 的，所以从一开始就是构建 AI 自动化体系，一开始就是玩的内容量级优势并形成了「内容工厂」体系化的产品。

以上流量公式、矩阵获客公式，我认为能够帮助大家抓住主要脉络，从而不被各种繁杂套路所干扰。这也是我一直所在践行并行之有效的。

## 矩阵获客超级模型——轻 IP矩阵

在多个陪跑和合伙项目实践中，我提炼出了三个超级矩阵模型：图文矩阵、货架矩阵、轻 IP 矩阵。

三个矩阵模型都很强大，但我认为轻 IP 矩阵最应该被大家先了解和应用。接下来也主要讲讲轻 IP 矩阵。

轻 IP 矩阵相对来说没有图文矩阵、货架矩阵那么简单粗暴。很多时候，轻 IP 矩阵就是图文矩阵 + 轻 IP，或者就是货架矩阵 + 轻 IP

IP 与非 IP 的一个根本区别，就是「人」的元素。所以轻 IP 一定是要有人的元素的。大多数情况下轻 IP 矩阵更管用，而且更具有普适性。所以，有条件，能上轻 IP 矩阵，就坚决要上。

本文前面提到的建材项目，就是纯粹的货架矩阵，招式极为简单粗暴，就是自动扒爆款文案AI二改，然后做音画匹配。别人还在搞真人出镜念脚本介绍产品，我直接一招怼别人百倍的作品，然后就完事了。必须承认的是，就单个作品而言，真人出镜的作品数据是要好一些的。但架不住我量级大。

我也意识到，可以在保住量级优势的情况下，让货架矩阵增加轻 IP 元素，可以非常轻松地让数据变得更好一些。尤其是在做旅游项目的实践中，得到肯定的答案。

旅游赛道，做了将近两千个号。非常有趣，玩这个赛道，我把这三个超级模型都用上了。

+ 素人号：玩图文矩阵 + 轻 IP 矩阵

+ 专业号：货架矩阵 + 轻 IP 矩阵

单从账号与内容量维度评估，素人号数据好处简直不要太多。这么说吧，一天出 50 条内容，一个月的轮回就是 1500。然后一个基本的计算就是 1500 除以 1~2，也就是说一天可以出 750 到 1500 的客资。

但素人号在绝对基数上，远不如专业号有优势。这里的专业号包括专业机构号和专业形象号（并不需要认证的号）。

无论是出于补量还是出于抢占旅游赛道更多份额的考虑，是一定要干专业号的。

旅游赛道有个特点，并不是适合做强 IP，你们也基本上看不到什么旅游赛道的强 IP，倒不是没有那种很能打的 IP 人设，而是这种 IP 真要把影响力转化为客资的话，容易出现翻车的情况。

总之，不管是什么原因，不管是什么赛道，强 IP 是不具备普适性的。强 IP 强在 IP 这个人身上，既然具体到个人，则往往是脆弱的，产能是严重不足的。

强 IP 的落地点在于人，受众爱恨这个人是大于内容本身的。在短视频中，这个人的脸、声音是要印刻在受众脑海中的。要把一个人的脸和声音印刻在受众脑海，这不是一般人能搞得定，而且很多时候我们要求这个 IP 应该是创始人、主理人。如果是其他人做 IP ，往往还会带来其他管理上的问题。总之，强 IP 非常具备普适性。

轻 IP 的落地点不是 IP，只是人偶尔露了个脸，但绝不是全程露脸。也就是说让内容带有人的温度就可以了。

很多兄弟没有搞明白其中的奥妙，感觉自己做 IP 出镜困难，就搞了个数字人，然后数字人全程或者大篇幅露脸，美其名曰做个轻 IP。这就是瞎搞。你哪怕就是让数字人偶尔露个脸，都比你数字人全程露脸都要强。数字人是做轻 IP 的一种比较好的素材，而不是做强 IP 的好的替代。轻 IP 天生就不能大篇幅露脸的。大篇幅露脸的还算是轻 IP 吗？

我在包括在旅游在内的好几个赛道通过轻 IP 矩阵模型拿到了非常不错的效果。我揭露下我玩轻 IP 矩阵的底层逻辑

1. 人员定位：出镜人员的定位是演员，而不是口播。演员注重拉表现力，口播注重念好脚本。这个定位一下子把出镜人员的威力发挥出来了，而且你的选角范围面也豁然开朗。00后的伙伴们，几乎人人都是戏精。嗯，你压根就不缺出镜人员的。

2. 出镜时机：出镜人员在关键位置出镜，比如开头、结尾以及中间重要片段。由于只需要在关键片段拉表现力，大多数人可以放肆的去表演。可以把各种动作、表情都夸张起来。就算念出一句话，他都能歇斯底里整出来。

3. 素材倍增：出镜人员来来回回表演好关键片段，可以一句话喊八百次，变着花样喊。就算我们只用这种原生的硬素材，也是能够得到指数级的作品量。因为每喊一次，就可以理解为有一个新的作品即将诞生。

那么问题来了，只有关键片段，怎么构成一个完整的作品？

一个完整的作品，本质上是由一个完整的文案脚本串联起来的。接下来只需要把缺失的文案对应的声音和画面补上去就万事大吉了。

1. 怎么补上缺失的文案？你可以反向理解，直接基于完整的文案，把人员出镜文案、声音、画面替换过来。所以文案仍然是完整的。

2. 怎么补上缺失的声音？除了人员出镜声音，其他的文案声音直接克隆即可。这里无需担心违和。人员出镜部分是表演性质，不出境部分就是四平八稳介绍旅游景点（你也可以想象成你的任一产品服务）。你要是全程都是表演性质的介绍产品服务，受众大概也听不清楚你想讲什么。

3. 怎么补上缺失的画面？这就是典型的音画匹配。一个小技巧：准备素材一定要清单式地准备。大家更好理解的是卖某个产品，你可能会正面、侧面、底部、顶部都去拍，你可能会对每个卖点进行拍摄，而且是一个角度一个卖点拍多组。

我们来排演一下

关键片段（表演八百个片头）：大爷~大爷~，你千万不要去内蒙啊。这里有三个天坑你遭不住呀大爷~

补位片段（AI二创八百个）：第1个天坑：××

补位片段（AI二创八百个）：第2个天坑：××

最后说一下产能，目前旅游项目只有 200 多个账号升级到轻 IP矩阵，每天供应视频数量 600+，除了基座性质的人员，专门负责内容生产的有三位小伙伴

这个产能我是很满意了。嗯，还是得靠 AI 自动化啊。不然前面拆解的那么细致，光靠人来手搓拼装，一天能干出 10 个就要烧高香了。AI自动化万岁。
