# 一.个人经历

我叫蔡喵喵，本科，坐标西安。事业单位设计院合同制员工，综合岗呆了7年。现在在YouTube项目成功变现，开通两个ypp，成功把副业变主业找到“人生第二曲线”课题也从“如何上班拿工资”转变为“如何赚到钱”。

3年前是我人生比较低谷的时刻吧当时不知道我的人生应该去向何方，想换工作增加收入又碍于学历、工作经验、自身技能种种因素觉得自己被困死了，不知道我能有什么可能性，在一档《识人识己》的播客里知道了讲盖洛普的毅然老师约她做职业咨询，当时老师了解到我的情况后给我打了一通电话，和我讲根据我的情况在这个“职场”环境中，可能找不到我的位置，和我沟通退了钱在《识人识己》第44期免费帮我解读了我的盖洛普做了个微咨询。

其实当时听完老师的咨询我放声大哭，觉得自己是不是被判了“死刑”自己在职场真的没有选择了吗？这场微咨询毅然老师讲“朝着有光的地方走”“把自己变成有光的人”我牢记了这句话。就把自己的精力放在自我探索上了。

## 3.建立自己的赚钱逻辑

这两年虽然没有赚到钱但是明白了一些道理就是“商业基本逻辑”。

我们在单位的体系下离真实的赚钱太遥远了，不知道一个项目最根本的是怎样赚到钱的。

拿最小单位来举例子。

我认为一个是**投入**一个是**产出**。投入就是**成本**，产出就是**收益**。

投入越小试错成本越小，如果准备10万元，每次测试一个项目花费1万，那十次的试错机会。如果一次性投入十万，就只有一次试错机会。对于普通人来说对商业逻辑一无所知怎么可能一次尝试就成功了，那等于出门就中彩票了，不要觉得一次就会成功，那是极端案例。我们需要尽可能多次尝试，尽可能压低每次试错的成本。

**还有我**认为一**个商**业模式看看是不是能行得通得看两个因素：一个是客单价一个是流量。

比如一个社群定价99元陪跑一年，陪跑是1v1的微咨询，社群答疑，直播课等等。

我们先算账如果想挣到1w块钱就是得需要101个用户。先不说这101个用户转化的时间精力成本，交付一年还需要1v1答疑101次，这中间耗费的精力成本远大于1w，所以这个定价就是不科学的。

项目几乎都可以用这两个因素来衡量，比如小红书店铺买一件衣服利润是30赚10000得卖333件，那我应该做的就是扩大购买。

而小而美的项目做1v1咨询只有服务10个人的精力，想赚1w块那每个人就是1000块，就容易的多

可以想想商业模式通不通先算算账。是精力比较宝贵要高客单。还是利润低点需要的是成交量高。

# 四.辞职之后的复盘

我的主业事业单位合同制的员工，在体制内合同制员工被称为“临时工”拿着挺低的工资，没有话语权，没有任何反抗的余地。单位的日常状态是人人为了少干活在推诿，事情推到我这边我总是不想和别人掰扯这活到底谁干，费的心力成本比我干完这个活大得多，所以我就干了，后来领导不作为加上我不会推脱基本科室80%的活给我一个人做，设计院市场不好能砍的福利都砍了。我的岗位是综合岗，杂七杂八的事情会往我这里堆，领导曾经为省1万多的安装系统的钱，让我免费给全单位的人安装系统。为省广告设计的钱，让我设计单位的宣传页，都是工作职责外的活。在这个月单位没有和我商量直接派给我了一个倒查十几年专班排查的活，我知道这个活一干就会耗掉我至少半年的精力，还有我很在意单位不和我这名“临时工”商量直接通知我就把这么大的活甩到我身上，压垮骆驼的最后一根稻草来了，我感觉自己完全没有再待着的必要，“逃命般”的辞职了。

## 1.意识到这份工作其实只是职场“工具人”

辞职后我回溯了7年间的经历，感受也逐渐清晰。在我辞职以后领导还以我没有干完这个月，这个月还给我发工资为理由要求我把“专班排查的活”干完。当时我回绝了领导可能也是我唯一的说**了“不”。其实领导只在意“活”有没有被干完，他有没有“犯错误”。**如果ai可以干这个活，那我本质和ai并没有区别。只是被吩咐，只是在照做，我只不过是一个干活高效的工具罢了。意识到这一点我感到幸好辞职了，我是一个人啊，活生生的人啊。在工作里没有成长，没有获得感，没有话语权，这些都没有我。我不想当个工具。如果不离开这里我将会一直被当工具的使用下去。

## 2.“离开体制不是失去保障，而是获得了自我定价的主动权”

我离开之后给领导详细的分门类总结了各项工作，罗列了工作和工作要点。大领导拿着表格表扬我工作不少做的细致。后来给我这个岗位安排了两个人接应，应为工作太多忙不过来。一名有编制的**正**式职工一名合同制员工，而他俩加起来的薪资是我工资的三倍多，两个人干我一个人的活。在体制内我没有发言的任何机会，没有和领导谈工资的权利，我无论干多少活，干的多么优秀只能牢牢被定死在这三分之一的工资上。对于这样的不平等条约我终于可以说“不”了，我在做项目，我的价值由我创造的产品和服务决定，不是在依附这个组织的评判，我拿回来了属于自己的定价权。

## **3.专注于未来，而非过去**

离开之后我无数遍的复盘，有没有可能还有比较好的解法，哪**里还**能做的更好。思来想去，答案是没有。我能做的已经是自我改造自几的最好的方案了。对于工作里的“他们”我不能改变，也没有可能去改变。既然我已经做到了最好，无力改变过去。不能用别人的错误来惩罚自己，现在我的收入、我的成长、我的价值，都由我自己说了算。我想化这种“愤怒”为养料，继续在我的生命中燃烧。

## 盖洛普是一体两面的，重新解读

旧世界的解读：“体谅、排难、适应、和谐”内耗四件套前十占了三个

新世界的解读：

体谅第一：我的同理心，离职前还在和交接的同事讲“岗位避坑法则”。

排难第二：一直找寻问题的解决方法。

思维第三：复盘分析的能力。
