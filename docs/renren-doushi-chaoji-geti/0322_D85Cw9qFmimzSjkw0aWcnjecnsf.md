## 添加服务器

选择顶部菜单的「服务器」

![](img/a1ccf1da14f1e94e4d826fcf27ddbb9a.png)

点击创建

![](img/043e6bc2b39f0b75f37b7560b67b2739.png)

选择「添加自己的服务器」

![](img/3fb8431185be28fffd9646b9aaf55cfc.png)

可以看到添加自己的服务器的要求

> 1、最小配置：1 核 CPU，2G 内存。所以买服务器的时候尽量买 2G 的内存起步的。

> 2、端口的开放，这里需要开放的端口是：80、443、4222、6443、30000-32767

> 每家的服务器供应商配置规则不一样，有些只需要关闭防火墙就行，有些是配置安全规则。

> 比如 raksmart、阿里云都是需要单独在网站上配置安全规则的。

![](img/c449485828af82f0cbcc2fa1a7ffa624.png)

下面就是添加自己的服务器

填写的信息如下：

> 1、IP，服务器的 IP 信息

> 2、端口，服务器的端口

> 3、用户名，登录服务器的用户名

> 4、密码，一般选择使用密码

这个会稍微复杂点，会需要在你的域名管理服务那里新增 DNS 的记录。

这里拿 cloudflare 举例来说：

> 3、IP 地址，填写我们刚部署的服务的 IP 地址

> 4、关闭代理状

部署服务的 IP 可以在服务的面板看到

# 总结

先来个总结吧

> 核心点 1：搞到服务器，从哪里弄来都行，方式有很多

> 核心点 2：zeabur 部署 n8n 的模板服务。

其实重点就是这两个点，如果你全程熟悉的话，基本 30 分内就搞定。

其实这套模式不仅可以很丝滑的部署 n8n 服务，其他服务也不在话下。

比如 wordpress 服务，继续已经有的模板构建服务。

如果你是自己服务，项目直接放到 github 里后就可以直接在 zeabur 部署。

最精彩的就是部署配置文件还可以让 Claude code 帮我们写，不用我们自己担心怎么配置。

最后安装好 zeabur mcp，页面都不用点开，直接 Claude code 部署帮我们都配置好，简直不能太丝滑。

这个我们后面也可以去讲。
