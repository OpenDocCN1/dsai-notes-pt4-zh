
# 未来，无人知晓，但我选择勇敢

> 来源：[https://xuqiwei1986.feishu.cn/docx/Y20cd2zyfo7jsRx3jsKcucmjnkI](https://xuqiwei1986.feishu.cn/docx/Y20cd2zyfo7jsRx3jsKcucmjnkI)

创业这条路通往真正的自由，却无人敢走。

hi，我是孟湄。

还记得，在义乌的工作室，经常是凌晨两点，我还在看后台的投放数据。一边规划第二天的直播排期，一边思考下一步的直播策略。

经常是，两点睡、八点起，每天选品、调话术、面试主播、盯投放，累死累活，但依然没赚到什么钱。

我迭代复盘直播间投放和成交逻辑，试图尝试建立起一种可以自动化、有积累、有沉淀的业务模式。但最终迎来的不是爆单，而是政策变动、业务清零。

那一刻，我不想骂人，也不想再试了。我只想问自己一句：我到底在干什么？我真的适合做这个项目吗？

这不是我第一次跑项目，但却是最让我怀疑自己的那一次。

再完美的 SOP，也带不出一个烂项目。

我终于开始思考：或许这不是能力问题，是方向问题。

## 从「大卷比」到「无欲则刚」

很多人问我，为什么你不继续在大厂，非要跑义乌创业？又是喜欢的推荐策略方向，还进了大厂，职业发展也还不错。

说实话，我一开始也没想走。

在最后一家公司打工时，同事都说我「钝感力十足」，老板的管理手段，好像对我并没有产生什么影响。

当时我只是笑笑，没法解释。

哪有什么钝感力，不过是看透了这场游戏的虚无，提前把精力押在了别处。

我精力有限，没时间关注老板背后的意图。因为晚上我还要搞副业。

**无欲则刚**。当你不再把升职、加薪、大厂光环当成唯一信仰时，那些曾经能轻易影响你情绪的 PUA 和画饼，瞬间就显得苍白无力了。

我当时给自己的标准很简单：事情交给我，不会落到地上。完成，但不追求完美。

每天把手上的活做好，尽量不在工作上花费太多的精气神。至于老板是怎么想的，他为啥这么说，他有啥意图，我真的没心思琢磨。

其实我也不是一直就这样的，你可能想不到，之前的我，是一个不折不扣的大卷比。

## 大厂，我的执念

普通211本科，无实习经验，毕业就扎进互联网做产品经理。当时最大的目标就是进大厂、升职级、带团队、拿股票。

原谅我，曾经就是这么「没出息」。

毕业几年，我几乎每1-2年跳一次槽，从小厂一点点挤进所谓的大厂。

在互联网整体氛围还不错的那几年，「大厂光环」的简历加持作用是实打实的。

我是卷王中的卷王。那几年，几乎没有双休日，生活的所有变量都收敛进了一个目标函数：

如何成为更高级别的产品人。

每天的生活状态就是：白天九点多上班，晚上十点多下班。下班回家之后，还在看书、想需求。

周末学SQL、学用户增长逻辑、学推荐系统、看各种提升思维逻辑、沟通、认知心理学的书。

每天除了工作，还是工作，连自己的休息时间，也在想产品策略的事情。我所有的一切，都是为了成为高阶产品经理。

那时，还有一个稳定的大厂年薪百万的算法工程师前男友。

我甚至一度以为，自己这辈子，估计就这样按部就班地活了：

在北京，结婚、生子、买房、还贷，老老实实打一辈子工。

## 是什么改变了这一切？

转折点是2021年的互联网寒冬。黑天鹅事件「滴滴退市」，中概股股价腰斩，未上市的公司暂缓上市。

资本不再相信「DAU即未来」的故事，所有公司被逼着从跑马圈地转向自负盈亏，然后，就是大裁员，大厂、小厂无一幸免，甚至大厂裁得更狠。

我第一次身临其境地意识到：行业宏观走势对个体的碾压。个体在行业趋势面前，脆弱得不堪一击。

在时代下行的趋势里，个体的命运，是被一只看不见的巨手所操控。

我拼了命地内卷，却无法抵抗整个行业的下行。

我无法接受，把人生最黄金的二十年，连同所有的技能、人脉、希望，All-in 在职业的牌桌上，最终却可能和这个行业一起，被时代无情地抛弃。

赢了，不过是一份体面的薪水；输了，就是整个价值体系的崩塌。

我意识到，把命运完全焊死在一条船上，跟行业绑死，才是最大的不稳定。

打工提供的稳定，本质上是另外一种脆弱，依赖行业和外部系统的健康。

就像你在沉船上拼命划水，可方向是错的，你只是死得慢一点。

更可怕的是，你的一切能力和资源，都只在这个行业里通用。一旦船沉了，你就连逃生筏都没有。

那一刻我理解到：所谓的稳定，不过是人类用想象力编织的最昂贵的脆弱幻觉。

任何依附于外在系统（公司、行业、婚姻）的生存，本质上，都是一种巨大的、脆弱的不稳定。

风一吹，就散了。

更讽刺的是，那个我以为会携手共渡一生的稳定伴侣，在领证前夕告诉我：其实我从来没有爱过你，对你更多的是责任和亲情。

结婚生子的稳定人生剧本被彻底撕碎。

当人生两条规划好的主路同时被堵死，我被迫开始思考「终极命题」：当人生只剩下自己，我，到底想活出怎样的人生？

我想要，无论行业兴衰，都能在自由市场里随时赚到钱的能力。

不靠风口，不靠平台，就靠自己。

在任何环境下，仅凭自己的能力，就能从自由市场里可以持续赚到钱的能力。

我希望，当行业这条「大船」开始漏水时，我有能力踹了它，跳进大海里，还能活下去。

当巨轮沉没时，你要有踹开甲板纵身入海的决绝。

## 搞钱先搞脑

当一个人开始独自面对旷野，最初的感觉只有荒凉和迷茫。

从意识到打工没出路，到真的有行动，我花了一年。

最开始像海绵一样，疯狂研究和留意这个世界上所有能赚钱的事。起初，两眼一抹黑。

看着抖音、📕上无数人都在赚钱，而自己还在原地踏步，那种焦虑、内耗、浮躁，极其无助。

不过，幸运地是，看了这两本对我影响巨大的书《纳瓦尔宝典》和《原则》。

纳瓦尔给我底层价值观，达利欧给我行为操作系统。

一句话概括我学到的东西：财富=专长+杠杆（来自纳瓦尔）；痛苦+反思=进步（来自达利欧）

+ 纳瓦尔教会我：靠出租自己的时间永远无法致富。你要构建产品，会销售，用杠杆，做复利的事。

+ 专长是指自己做起来像是玩，但对其他人来说是工作一样的事情。

+ 非社会培训可以培养出来的技能，因为社会如果可以培养你，就可以培养成千上万个你，你就不具备独特性了。

+ 而杠杆，有三种：

+ 人力杠杆：雇人

+ 资本杠杆：用钱生钱

+ 无边际成本杠杆：写作、媒体、代码

他说：努力不是问题，方向才是问题

+ 达利欧教会我：勇敢地直面失败，从每一次的错误中总结经验，迭代认知，这是唯一成长的路径。

于是，我的人生价值观里，清晰地多了两条：

+ 寻找自己的「专长」点位，并坚持做有杠杆、有复利的事；

+ 勇敢追求我想要的，并敢于直面失败，保持头脑开放。

理论武装完毕，我开始试着下场，把手弄脏。

## 四场真实的创业试炼

觉醒是惨烈的，行动是笨拙的。带着荒原求生的紧迫感，我开始了边打工，边副业的探索。

我想知道，如果只靠自己，我能靠啥赚钱？

于是我开始了系统性的项目测试，寻找信息差，搭建SOP（标准作业流程），探索和验证自己的专长，拥抱失败与迭代。

权当做是锻炼心力和勇气的刻意练习。

因为我觉得，离市场最近，就是买卖，把东西卖给别人，所以我最先考虑了电商。

## 第一个项目：闲鱼倒卖二手雪具

我的第一次套利，源于一个偶然的发现。

刚入门滑雪时，我为了给自己配一套顶级装备，查了无数资料，结果发现这个市场，信息差巨大。一大批新手凭着一腔热血买下顶配雪具，滑了两次就发现自己并非那块料，然后低价挂上闲鱼。这些装备成色极好，价格却极低。我看到了这个缺口：专门在闲鱼收顶配二手，再倒卖给懂行的玩家。就这样，我倒腾了几套顶配的雪板、固定器，小赚了2-3千块。核心逻辑很简单：利用信息差，赚那些因前置功课不足而着急出手的小白的钱。但我知道，这不是一门好生意。规模化困难：强依赖人工，需要时刻紧盯闲鱼，第一时间买下低价的雪具；季节性强，雪季一过，货就容易砸手里；资金占用大，一块雪板至少 2-3k，卖也只能赚几百，批量囤货的话，风险太高。于是，我赚到一点零花钱后就收手了。

+ 项目里滋养我的点：挖掘信息差和研究顶配雪具的过程，那种发现机会的快感。

+ 消耗我的点：低水平的搜索帖子、找帖子的工作。我喜欢动脑子，而不是拼体力。

+ 得到的认知：没有杠杆的生意，是靠低水平重复和堆时间换钱，不是我想要的。

元能力：市场调研、挖掘「信息差」。

## 第二个项目：淘宝卖虚拟产品

这个项目，是我第一次真正跑通一个完整的电商闭环。

产品是知识付费学来的虚拟品类，成交在淘宝，获客靠付费投流。为了跑通它，我做了三件事：

+ 差异化主图：在淘宝双列信息流里，主图决定生死。我设计了跟其他同行比，一眼就看到的主图。

+ 卖点铺满购买路径：把用户最关心的卖点，在主图、SKU（商品规格）、详情页第一屏、客服开场语里反复强调，形成曝光效应，打消用户疑虑。

+ 自动化客服：这个项目有巨大的客服工作，我无法忍受重复回答“在吗”、“怎么用”这种低水平问题。我花了好几个晚上，把所有用户可能问到的问题都预设了关键词，并搭建了一套能自我运转的对话流。那一刻，我感受到了代码自动化的魅力：用一次性的系统构建，去替代无数次的重复劳动。

我优化完主图，再配上投放，两个星期就卖了 1000 单，赚了 2w。这个项目的意义远超于数字，它第一次向我证明：不靠打工，我真的能赚到钱。

项目能赚钱，核心在于：

+ 付费请教，选对了品。选品定生死，是永恒的真理；

+ 优化了购买路径上的关键环节；

+ 跑通了投放，用钱换时间，在同行抄走我的主图之前，赚到了第一桶金。

滋养我的点：

+ 设计自动回复机器人，看着它高效工作，我极有成就感；

+ 分析投放后台数据，从中获得洞察，优化策略

消耗我的点：

+ 毫无护城河，产品和主图很快被同行原封不动地抄走，陷入低价内卷；

+ 面对大量喜欢占小便宜、沟通低效的用户，感觉自己被严重消耗。

认知收获：

+ 没有产品的差异化，低价内卷面前不堪一击；

+ 所有环节都尽量自动化/工具化去提效

元能力：用户路径拆解、自动化工具提效。

## 第三个项目：视频号 ADQ 卖货

经历了前两个项目，我隐约感觉，电商这条路似乎特别适合产品经理做，因为需要用户洞察去选品，需要数据驱动去做投放。

恰巧，在线下课接触到了「视频号ADQ投流带货」的模式，用腾讯ADQ（广点通广告平台）为短视频投放引流，在视频号小程序里成交。

我意识到，表面上看这类项目是“电商+投放”，但我隐约感觉到，似乎这跟我的旧能力圈恰巧吻合，可能是个外行看着繁杂，但恰巧能发挥出来产品经理优势的项目：

+ 选品，依赖用户洞察（产品经理基本盘）；

+ 投放，依赖对推荐系统和ROI（投资回报率）的理解（我本就是做推荐策略的）；

+ 转化，依赖文案、SKU组合（淘宝项目已验证过）；

+ 剪辑，当时是远程招了两个剪辑，然后线上对接，所以只需要写清楚具体需求文档就好了，这简直是产品经理PRD文档的降维打击

其余的，盯投放数据、搭 SOP 体系，这些都是我原本在职场中驾轻就熟的事情。

我直接冲了。白天上班，晚上熬夜，每天晚上从十点忙到凌晨两点。不到一个月，我跑通了整个闭环。我们曾一天消耗投放费用超过6万，单日订单突破600单，累计GMV（商品交易总额）近百万。

这是我人生第一次，不靠平台红利，纯靠自己建模和实操，把一个项目从0做到了闭环。

这个项目核心能赚钱的点，在于：

+ 选品与用户需求分析：广告投放的载体是短视频，需要兼具种草和转化的效果。用户先看到短视频，被种草，最后成交。所以要分析视频号目标人群，和这波人群的真实需求点，找到这波人群潜在消费习惯和需求点，才能做出更好的成交；

+ 理解平台底层逻辑：ADQ 是一套oCPM 推荐系统，决定最终排序的因子是「预估转化率」、「预估点击率」、以及出价，因为本身就是推荐策略产品经理，对推荐系统的理解天然地就让我更有优势；

+ 全链路资源整合能力：选品、对接剪辑（当时还是线上对接，线上指挥剪辑干活）、落地页、数据盯盘、投放策略、供应链对接、投放，每个环节都建立了sop 文档。

不过，在我们起量很猛的时候，被平台抽查，结果发现合作的供应链发的竟然是三无产品（我当时一脸懵逼，也是第一次知道这个年代，还有三无产品。）结果，账号被封，资金冻结，还被罚了一大笔钱。项目死得猝不及防。

认知收获：

+ 投放是一门科学：付费买量是最稳定、可预测的商业模型。一旦ROI跑通，就能标准化、批量复制。现在很多人依然没有花钱买量的习惯，因为投放买量，确实非常占资金（不管从资金占用上，还是资金回转周期上，都没有自然流量来的灵活）。但实际上，付费投放是电商、知识付费行业最成熟、最稳定、最可预测的模式；

+ 电商链路里最不透明、也最关键的变量，是供应链：无论前端数据多漂亮，供应链不稳定，一切都是空中楼阁。在大量爆单的情况下，供应链的供货能力与稳定性，至关重要。（从某种程度上来说，也能理解为什么网红带货容易暴雷，实际上，暴雷的不是网红，是背后的供应链，很多时候，供应链品控和质量不在线时，出来面对消费者情绪的就只能是带货的网红。）

滋养我的点：

+ 识别关键的 20%：理清业务模式，精准定位“哪个环节最重要”以及“做到什么程度能成”，这让我特别有成就感；

+ 投放看数据：这次是大额消耗，任何决策都会实时影响数据。我享受那种「提出假设-验证猜想-观察数据-迭代认知」的深度思考闭环。你能想象吗？每天凌晨盯盘，看第一单在几分几秒出现，是我最开心的事。

元能力：

+ 业务的结构化拆解：整个项目的链路拆解，选品-剪辑-投放-计算 ROI，每个环节都建立了自己的评估标准和决策机制；

+ 产品化+系统化能力：在极短时间内搭建了文档系统、流程 SOP、数据报表，并用数据+流程管理整个链路流程；

+ 商业洞察+决策力：我不只是跑通了个项目，而是构建了整个业务的商业模型，从拆解环节→聚焦关键→快速验证→动态迭代的完整闭环。

这是我第一次在现实世界中看到：自己长期训练的产品经理底层能力：结构化拆解、数据洞察、快速执行验证、迭代复盘，也可以在自由市场中赚到钱。

我有点膨胀，那种「我真的可以」的自我认同感，油然而生。

虽然项目最终因为供应链事故翻车，但它给我的意义远超项目本身：我开始理解到了商业的本质，甚至有了「现在好像可以考虑离职创业的底气」。

在ADQ投流项目跑通之后，我开始动摇，想从副业变成全职创业。

## 第四个项目：义乌直播带货创业

### 为什么会做这个项目？

我碰的电商项目，从传统的货架电商，到短视频兴趣电商，在电商的几种业务模式中，直播带货一直没有尝试过，又经常看朋友圈有人靠直播单场卖几万，甚至小团队每月做几十万净利润。于是自己跃跃欲试，想试试直播带货。

这个业务模式是用微付费撬动短视频的免费流量，给直播间引流，在直播间成交。而直播间的密集成交，又会反哺到短视频的免费流量，整体是一个螺旋上升的循环。

这是一个小资金、撬动「大利润」的项目玩法，相比纯付费项目，资金占用少、利润率又高。

对我有吸引力巨大。

更巧的是，当时因为工作「投入度不够」，我被老板优化，拿了一笔 `N+1` 的赔偿金。

于是就有了后面的故事，和现在的我。

### 这个项目的核心环节是什么？

短视频种草+直播成交的逻辑，影响成交的核心点有三个：

+ 种草视频：决定了直播间是否能精准引流；

+ 主播：决定了直播间是否能留人与成交；

+ 有节奏的投放策略：决定了 ROI 是否能持续正向循环。

我最初对这个项目的判断，是一个短平快项目。

这个业务逻辑，天然会出现「重复」、「搬运」、「纯卖货」的种草短视频，而这些内容恰恰是平台最不欢迎的。

从平台长期发展的角度，一定希望平台的内容优质、有调性、有价值的，重复、搬运、纯卖货的视频，非常伤害用户体验，如果我是视频号的内容策略产品经理，第一批治理的内容就是这些「垃圾」。

所以整个项目生命期会比较短，但会有比较大的利润空间，所以我想借着信息差赚个两三个月的块钱。

我知道，这是在跟时间赛跑，同行多、门槛低，某个直播间爆了之后，同行可以搬你的素材开直播。用相同素材开直播的人多了之后，谁能打爆，就是一个概率游戏了。

本质上还是一个比谁快的项目，所以我非常卷，执行也非常快。

今年年初过完年，我用三天时间极限搬完北京的家，退掉租房，一头扎进了那个传说中的电商之都，义乌。

你能想象吗，我一个小姑娘，拎个小行李箱，从北京跑义乌，风风火火，一周内租房、招主播、注册工作室、买设备、招助理……

我甚至为了让员工快速上手，还搭了一套超级完整的全流程 SOP，清晰到可以直接拿去做知识付费。

然后，搭好工作室的第三天，就小爆了一场，赚了几千块。

我当时觉得自己牛逼坏了，执行力爆表，仿佛已经看到了胜利的曙光。我以为，马上就能猛赚一大笔了。

然而，现实很快就给了我一记响亮的耳光。执行越快，亏得越快。

### 为什么最终不做了？

不是没跑通，是根本做不下去了。

到义乌没多久，就赶上视频号平台规则巨变。315、两会、 415 的清朗计划……一系列针对电商的政策组合拳，直接把我那套「短视频引流到直播间，用付费撬动免费」的底层逻辑给掐断了。

于是我不得不暂停项目。虽然在数据层面跑通了小闭环，但在结构层面我看清了：这是一个无护城河、无复利、资源不掌控的高随机性游戏。

### 认知总结

+ 平台规则是天花板，模式红利必须跑赢平台治理周期：一旦平台收紧政策，你的模型再完美都得重构。结构思维再强，也架不住平台规则调整。

+ 真正能做的项目，核心资源必须能自己掌控：投流模型我可以控制，品也可以控制，但更核心的主播我控制不了，因为优秀主播从不在市面流通。这等于整个杠杆点不在我手里。

+ 竞争内卷+无结构复利：无法复利的努力都是消耗型努力，不值得长期投放人生资源。

这是一个「今天做的事情，明天没任何复利」的概率游戏。

思考、拆解在概率面前，变得滑稽可笑。

当同行用铺团队、拼体力就能对冲概率的风险时，我所谓的深度思考，一文不值。

短期、平台红利、门槛低、小白友好、来钱快的项目，我再也不想碰了。

这个项目里，有我的元能力体现吗？有。

+ 结构化拆解：从平台逻辑反推出整个投流到成交的环节，梳理完整的直播运营手册，涵盖选品、主播培训、直播脚本、数据看板、复盘逻辑，招进来的新人2周就能跑起来，全靠文档+制度配合节奏。

+ 系统性思考识别增长点：意识到种草视频、主播是决定能不能成的核心环节，而这两个能力，我当时的团队都不具备



# 创业认知与自我重塑

我曾在极短时间内做出果断决策，招人、搬家、注册公司、启动投放、搭建 SOP、做数据看板，一切执行都很漂亮。我跑得飞快，但方向错了。

我以为自己能掌控大局，但有些东西不是靠努力就能赢，是这个系统天然存在硬上限。平台、主播、政策，都不是我能掌控的。

真正值得做的事，要么是能被复利的积累（如内容、工具、系统），要么是有足够资本护城河的闭环生意。

我一度陷入深深的无力感和意义感崩塌，甚至开始怀疑：

+ 自己是不是不适合创业？
+ 是不是所谓的会拆解业务、系统化思考、执行力强根本不值钱？

后来，我去参加了一场电商的线下培训课，想看看电商还有什么其他玩法。

**下课后我找**主办方老师聊天，把这段经历讲给他听时，他只说了四个字：发心不正。

### 振聋发聩

看着老师在台上分享，他从大学开始一路在电商行业摸爬滚打，他眼里闪着光。你能清晰地感受到，他是真的热爱、真的相信自己正在做的事情。

而我呢？电商对我来说，是热爱的事情吗？还是只是一个赚快钱的工具？我喜欢的其实是，拆解其商业模式带来的智力快感。

坐在台下的我，第一次发自内心地羡慕一个人。我羡慕他，能一路做着自己笃信的事，并赚到钱。

我开始彻底质疑自己走在这条创业路上的方向，于是开始记录👸号，开始输出思考，也开始重新梳理，到底什么才是我真正擅长的路。

这个项目的起落，成为我自我认知断裂与重塑的分水岭。

### 它不是失败，它是成长的代价

如果说 ADQ 项目让我意识到，我可以靠基本能力赚到一笔钱，那么义乌项目让我意识到：什么样的项目，才更能适合我，更能发挥出来我的优势。

从义乌来到杭州，我好长一段时间，都在思考，未来要怎么走。

最近才渐渐舒缓过来，开始复盘过去几年所有的尝试和失败。

### 第一次，倒卖二手雪具

赚了 2-3k。我发现，我享受的不是讨价还价，而是挖掘「价格差」的过程。但这个生意需要拼体力、占资金，没有杠杆，我很快放弃了。

### 第二次，淘宝卖虚拟产品

赚了 2w。我享受的不是当客服，而是设计自动回复机器人系统，以及分析后台投放数据的过程。但这个生意没有护城河，很快陷入低价内卷，我再次放弃。

### 第三次，视频号ADQ投放卖货

跑出 100w GMV。我享受的不是卖货本身，而是精准选品、拆解投放模型、从数据中找到增长杠杆的快感。

### 第四次，义乌直播带货

亏了不少。我享受的不是拼人力、比谁快的游戏，反而搭建 SOP、帮朋友解读直播间数据会让我很兴奋。

这个项目，让我彻底明白，今天做的事情如果不能让明天变得更好，那本质上就是一种高级的体力活。

我把这些项目中的享受和厌恶的点，一条条列在纸上。

+ 我享受的，是深度的思考、系统的构建、业务的拆解、杠杆点的寻找；
+ 我厌恶的，是低水平的重复、无休止的客服、无积累的内卷、以及依赖概率和运气的游戏。

我突然又想到，从我开始搞副业开始，到正式创业，就有好多朋友想跟我合伙，我不懂为什么，好像自己并没有特别刻意地表现出来某些能力。

不过，又好像，这么多人能向我发出合作邀请，某种程度上，是不是我还是有一些「作用」的？

那么或许，我是不是直接把「我这个人」作为一个产品，向大家提供服务呢？

过去，我总想着，我要做什么项目才能赚钱？

现在我不再问，什么能赚钱，而是回到原点，问自己：我到底想做什么？我的核心价值是什么？我有啥组合技能，能帮谁解决什么痛点问题？

我把我所有项目经历中展现出的能力，做了一次盘点：

+ **底层能力：**快速学习、结构化拆解、深度思考、战略规划、同理心洞察…
+ **表层技能：**定位增长杠杆、搭建业务模型、投放数据分析、写SOP、项目统筹…

这些能力，在打工人的评价体系里，可能只是几行字。但在另一个世界里，它们是极其稀缺的。

### 那就是早期创业者的世界

我终于明白，过去我一直在术的层面折腾，追逐风口、模仿模式，却忽略了最核心的问题：我的道是什么？

这四次惨痛、但值得的试炼，让我最终打磨的，是一个极其适合创业的心态和能力。

我又联想到，这几天在帮身边几个同样在创业中挣扎的朋友，看他们业务现在应该怎么走、哪个环节是当前杠杆最大的点。

当我帮朋友一针见血地指出，他当前业务中的核心问题时，他恍然大悟的反应，让我体验到了前所未有的价值感。还被朋友反馈说「你好适合做商业咨询啊」。

我突然意识到：这些年，我真正打磨的，不是某个具体的业务能力，而是一个非常适合创业的底层操作系统，是我这个「人」本身。

这也能解释，为什么总有朋友想找我合作。他们看到的，可能就是我这个人的价值。

他们不缺产品，不缺努力，他们缺的，是一个能帮他们跳出执行细节、梳理战略、找到增长杠杆的「外脑」和「合伙人式顾问」。

于是，我决定不再寻找下一个项目，而是把我这套能力，打包成一个服务，去赋能那些和我一样，渴望建立自己事业的同路人。

而这，恰恰是我最擅长且最享受的事情。

### 我不再需要去做一个具体的项目

我可以成为很多项目背后那个思考和规划系统。

## 写在最后

从大厂出走，到义乌梦碎，我绕了一个大圈，亏了不少钱，但买来一个最宝贵的教训：

一个人最大的护城河，不是你所在的平台，不是你跟对的风口。

而是你那套独特的、可迁移的、被市场验证过的能力组合。

当环境剧变，当规则改写，当红利消失，这套能力，就是你安身立命的根本。

这些年，我一直在寻找「稳定」。我曾以为，稳定是大厂的工牌，是北京的房本，是那个看起来永远不会离开的伴侣。

后来我才发现，真正的稳定，从来不是向外寻求依赖，而是向内构建核心。

真正的稳定，不是焊死在某公司的工位上，而是反脆弱式的混乱，是你走到任何地方，都可以从市场中赚到钱的能力。

它意味着，你拥有了定义自己人生的权力。

现在的我，依然不知道人生的终极意义是什么。但我不再为此焦虑。

我开始做自己的个人商业顾问服务，把自己过去几年摔打出来的能力打包，去赋能那些和我一样，渴望建立自己事业的同路人。

我不知道这条路能走多远，但这一次，我的发心，前所未有的端正。

因为，我正在做一件，能让我的今天，为我的明天积累价值的事情。

这就够了。

所以，回到最初那个荒凉的问题：**当船要沉了，我们怎么办？**

不是寻找另一艘更大的船（跳槽），也不是祈祷风浪停止（期待行业回暖）。

### 答案是：造一艘属于自己的船

它可能不大，但足够坚固；它可能不快，但方向由你掌控。

### 打工的本质与创业的真谛

打工的本质，是把生命和时间批发给一个估值；创业的真谛，是把能力和服务零售给整个市场。

前者赌别人不沉船，后者赌自己能造船。
