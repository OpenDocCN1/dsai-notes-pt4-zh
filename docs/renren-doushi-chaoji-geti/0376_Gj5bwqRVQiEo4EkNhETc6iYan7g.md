## 3.2 怎么做好内容赛道？

+   微博热点创作，本质是追** #热点# **创作对平台有益的内容，从而得到平台分成，内容可以从【新料补充】、【观点阐述】、【经验分享】、【感受共鸣】、【事实纠错】五个方向创作有价值的信息，带上独有热搜词+相关的标签，更容易得到平台的青睐，

+   **通过追热点，在垂直领域按照五个方向输出带有#热搜词**#的内容，这样一条有价值的信息就完成了。

+   在创作方向上，深入思考和梳理，逐步确立自己的创作坐标，并由此发掘源源不断的选题灵感。通过借助AI工具提升效率，不断地沉淀个人品牌和个人定位。

+   通过观察#热点#，快速提炼#热点#的价值，个人经验，或者对智搜**进行纠错，平台收录**有价值的信息，就有对应命中的激励分成受益了。

+   不要自己随意发微博，一定从热搜里面去找热点，通过热点分享自己真实的案例和经验。

## 3.3 怎么做垂直领域的账号？

+   在博文后面加入该领域的垂直标签，需要持续发布至少一周带垂直标签的热搜，平台才会对该账号打上对应的标签；

+   在创作者中心出现【**V影响力指数**】后，再去进行兴趣认证，这样通过的几率大大增加。

### 技能 1: 深度创作微博热点内容
1. 深入剖析用户提供的信息，通过搜索工具等途径，全面补充用户未总结到的新料，如：

## 7.1 多账号实操运营

+   一个身份证能实名两个账号认证，可以借用身边家人、朋友身份信息，进行多账号运营。

+   每个账号可以定位不同的垂直领域，避免产生同质化的内容

+   每个账号，可以创作同一领域不同类型的内容

+   字数控制在20-500以内。

## 7.2 用AI批量生产内容

+   想好账号的垂直领域后，给AI指定不同的提示词，从而得到不同领域，不同类型的内容，AI生成内容，人工最后审核一下，有时候AI会抽风给不对的内容。

+   可以给AI输入不同的语气口吻，让AI随机选择一种语气输出，但核心思想不能变，变的只是表达方式，比如措词激进、亢奋、平静等。
