## 一、为什么选择这个项目？

我是今年5月份开始接触👸号爆文领域，当时报了一个其他的社群，专门讲AI爆文写作的。

为什么想到要做爆文创作呢？

1.提早为未来的职业危机做准备。

我今年刚过30，原本的规划是想着在大厂一路升职加薪，但这几年，大厂竞争越来越激烈，上升通道和机会也越来越小。

突然意识到，将自己的唯一收入全部寄托于公司是有很大风险的。尤其程序员这个岗位，是离钱比较远的一个职业。

从去年开始，我就在想如果我脱离了公司，除了会点技术，还有什么技能能让我独立在这个社会上生存下去呢？

于是便有了通过副业，开始探索自己能力边界的想法。

**2.为什么选择👸号爆文？**

虽然是个理工男，但我个人对写作还是很有热情的。

上学的时候就喜欢写🐧空间，写博客。到工作后，喜欢写技术文档、技术博客等。

当我了解到有👸号爆文创作这个赛道，就果断决定以这个项目为始，先迈出搞副业的第一步。

截止到目前，我前后运营了3个号，产生了5篇10W+，最高一篇阅读量在80W+，过万的文章十多篇，几个号收益在5000+。虽然不是很多，但也算是赚到了工作之外的第一桶金。

下面废话不多说，直接上干货，分享一下做👸号爆文的经验心得：如何写一篇10W+爆文？

## 二、如何创作10W+爆文？

我分析了很多市面上的10W+和我自己那几篇10W+，总结出来的关键步骤就下面几个：选好赛道，找对标，做好选题，拆解爆款，抄爆款标题，坚持。

### 1. 如何选赛道？

自己喜欢+自己擅长+热门领域。

这个大家在别的地方也应该看过很多遍了，但好多人还是不知道怎么选。这里分享几个自己用的方法。

1.找个笔记软件或者一张纸，列出来自己喜欢的领域。

一定要列出来，有时候脑子里想太多容易糊涂，列出来会清晰很多。比如我自己，喜欢的领域大概有：科技、互联网、个人成长、游戏、AI。

2.然后去用这个跟热门领域赛道去匹配。

目前我了解到的热门赛道：汽车、娱乐八卦、情感、女性成长、职场等。当然，我后来自己的赛道定位定到了中老年心灵鸡汤领域，为啥？因为写着写着发现写这些内容爆了，索性就在这个领域写了一段时间。

**3.从自己行业中找。**

你身处某一个行业，你一定对这个行业有一些自己的认知和了解。如果你了解的很深，是个资深的从业人员，那你就可以写你的个人洞察和洞见，这个是很有价值的，适合长期去做。

而且最近，龙哥大佬发出了超级标，👸号垂直小号是🛰️官方明确鼓励的创作方向，只要有信息增量，能体现个人专业性，平台就会给推荐。

如果选中了几个目标赛道后，也可以问问自己：假设这个赛道，我如果做下去一直拿不到结果，没有人看，我还乐不乐意继续做下去？

如果你发现某个领域，是你不赚钱也喜欢分享内容、去承接你无处安放的表达欲，那这个赛道就非常适合你，也更容易拿到结果。

大家不必一定去找赚钱的赛道，还是要结合自身。如果自己不擅长，不喜欢，就算入局一个好的赛道，也很难坚持下去，自己痛苦不说，拿不到正反馈也很容易打击自信。

### 2. 如何找对标？

找对标，主要是找一些低粉爆文账号，着重看这些小号里爆了的那篇文章，分析那篇文章为什么爆？选题、标题、内容等等都拆解一遍。

头部大号的10W+不具备参考性，因为它们粉丝基数大，发点什么都会轻松破10W+。但我们可以通过头部大号发现一些线索，通过这个线索去顺藤摸瓜找到小号。

目前（2025.08.03）🛰️公众平台不断改版，以前的一些找对标账号的方法有些已经不适用了，我这边提供一个目前还可行的方法。

![](img/981d44082fca77c7f87d2646f0511948.png)

找到一个头部账号，并找它的一篇10W+的文章。复制标题，去🛰️搜一搜搜索。限制搜索范围：热门、文章、最近七天，如果最近七天内没有太热门的就选择最近半年。

然后找到阅读量比较高的文章，几万的也行，不非得10W+，因为有的小号有几万阅读也说明文章进池了。

通过这些文章，去看这些👸号的文章列表，如果原创数<100篇，并且有过多篇阅读量比较高的文章，那这个号就是可以对标的低粉小号。

有时候，100篇以内的号不好找，那就适当放宽标准，<200篇，<300篇的账号，也可以参考。

重复上述步骤，通过这些爆款文章到搜一搜里去找，总会找到一些符合条件的小号。

找个表格工具，把这些小号记下来，形成自己的对标账号库。

### 3. 如何选题？

一个好的选题，之所以能被广泛传播，一定是满足了某一些元素：当下热点、当下热门社会现象、大众痛点、大家喜闻乐见的、大家都想了解的但市面上很少有的信息等等。

大家要建立一个自己的选题库。通过上面第二步的对标账号库，将爆款标题也整理到一个表格中。建立选题库，可以让自己对自己赛道的热门内容，有个整体上的认识。当选题看多了，自己的网感也提上去了。

![](img/5daffd20c3aac67091b23c25ffc7af0f.png)

其次，要学会利用热点，因为热点自带流量。

关于这一点，以我之前爆过的一篇文章为例：

[《](https://mp.weixin.qq.com/s/2GRVMKlvU8bKw05YGZ4tiA)长安的荔枝》激起打工人共鸣：你越混越差的原因，不是能力太差，情商太低，也不是资源太少，运气不好，而是没看透这3点。

当时，《长安的荔枝》剧版刚刚开播，在🛰️指数里可以看到长安的荔枝指数趋势要起飞了。而我当时在几天前，就提前意识到这个热点背后的机会了。

![](img/5054b7b99a181180c5a87feb9d5db330.png)

因为这部小说在🛰️读书一直很火，可以说是写给职场牛马看的，打工人看的时候非常有代入感。电视剧版大概率会引发一轮新一轮爆点。

在这篇爆文创作的几天前，我写过一篇相关的文章，主要是对原著金句做分析，但各种原因吧，没有爆。

后来分析原因：没踩在流量爆点上，文章架构一般，字数多等，都可能是完读率不高的原因，也就没有大爆。

但眼看着长安的荔枝热度不断增高，我实在忍不住，正好那天看到热搜"《长安的荔枝》激起打工人共鸣"，决定再写一篇。

标题就用热点+观点的方式组合。结果这篇就爆了。这篇在几天之内很快就上了10w+。

所以，「选题定生死」，那一刻我才理解这句话。

好的选题+适当蹭热点，很容易出爆款。

所以，日常建立选题库，多分析优秀选题的关键词，多去第三方平台新榜等去看热点、低粉爆文，形成自己的"选题网感"是很有必要的。

另外做爆款，有个公认的热知识：爆过的内容还会再爆。

这个放在任何一个赛道：📕、视频号、抖音等等都适用。

一个选题爆了，一定是满足了当下一部分用户的需要，那对于一个选题，可以换个角度写，可以换个方式写，还会继续爆。

不要怕写重复的内容会不会不好，这里我们说重复去写爆款，不是说让你原封不动一个字不改的再发一遍，而是围绕爆款从其他的角度去写。

因为，对于一篇文章，就算阅读量再高，也总有没看过的人，也就是说，如果一个选题爆了，就可以围绕这个选题继续创作，总会覆盖一些还没被覆盖到的人，直到这波流量被吃干抹净。

### 4. 如何拆解爆款？

新人写作，要避免自嗨。除非你已经是行业知名IP了，可以随心所欲按自己风格写。

新人想要创作爆款，学会拆解别人的爆款内容，会极大提高你出爆款的成功率。

因为"抄"是最快的学习方法，跟着别人已经验证过的路径，会让你在前期少走很多弯路。

那么，如何拆解呢？这个网上方法一大堆，这里我只简单讲讲我这个赛道用到的方法：

**1. 分析开头钩子**：

+   看开头用了什么技巧吸引读者，比如提出疑问、抛出故事、设悬念，学会各种下钩子的方式。

+   拆解时留意开头字数，一般100-200字最易抓人。

**2. 分析结构**：

+   主要看文章分了几段，我这个赛道一般都是三段式，就是说三个观点+案例+分析+金句点题。

+   文章总体风格是总分总格式。

+   当然，不同赛道爆款的格式可能有区别。比如军事赛道，我看到的格式好多都是客观新闻+分析+网友评论分析+个人感想。

+   还有职场赛道，有的格式是脉脉帖子+网友评论+个人分析等等。

**3. 分析情绪点与共鸣点**：

+   读者能产生共鸣，一定是文章踩中了某种情绪，比如焦虑、不甘、愤怒或者治愈。

+   要善于发现这些人性"弱点"，并将这些情绪放大，替读者发声，说出读者想说又不敢说出来的内容，让读者觉得这篇文章是为他而写。

**4. 分析结尾升华技巧**：

+   爆款结尾一般会做简单的点题或升华，留下互动空间，引发读者共鸣、讨论。

+   避免说教，其实好多读者来读文章就是为了满足情绪价值的，也不是真要什么理论方法，而且有些情感类的内容，也没法提供精准的方法。所以就提供情绪价值就可以了，不要长篇说教，好多人都不爱看。

最后，将这些拆出来的框架，不断整理成自己的提示词，这样，AI就能够写出很贴合你自己风格和想要的内容。

现在市面上也有很多用AI来拆解风格的方法，我也都试过，但效果其实不太符合我的预期。

自身风格这个东西，一定要量身打造，自己的东西才会有差异化。

### 5. 如何抄爆款标题？

爆款标题的公式，网上也有很多人讲过了。

无非就是那些方法：

+   数字+关键词：《3个方法，告诉你如何快速涨粉》

+   反常识：《成长最快的方式是研究赚钱，而不是坚持学习》

+   情感共鸣：《那些敢于吵架、敢于冲突、敢于强势、敢于不礼貌、敢于不要脸的人，才是真正有能力的人，他们有冲突的能力，更有收拾残局的能力》

+   话说一半：《这7个明星，来头都不小，最后一个竟然是。。。》

+   设置疑问：《为什么你坚持日更，还是没有阅读量？答案原来在这》

等等。还有很多，我不一一列举了。

不同的选题，不同的赛道，要找对适合的容易出爆款的标题格式。

同时，也要像建立选题库一样，建立自己的标题库。然后不断去看，分析，提升自己的网感。

对于新手，一定不要自己自嗨一个标题，大概率是要扑街的。

前期，直接把别人的爆款标题拿过来用就可以了，甚至可以一个字都不改，因为标题不查重，拿来直接用就好。

等随着写的内容积累多了，自然就知道什么样的标题会吸引你的读者了。

### 6. 如何坚持？

很多人👸号运营不下去，往往不是能力不行，而是坚持不下去。

我自己的经验：

**1. 准时出摊，形成习惯**： 不管写得好坏，先保证准时出稿，不然拖延症一发作，很容易放弃。

2. 内容为王，不要为了日更而日更：不要为了完成任务而随便写。关注正反馈，有反馈的时候，多思考哪里做对了。没反馈时，要开始对照对标号，拆解自己的内容，分析问题出在哪。

**3. 先写出来，再找方向**：好多新手不知写什么，那就先逼自己写出来，哪怕是个垃圾。然后再复盘反思，慢慢摸索。我是硬着头皮写了一个多月，才慢慢找到感觉和自己想要创作的方向。

4. 心态稳定，避免过度关注数据：我一开始运营👸号时，非常焦虑，上班也偷偷刷后台数据。后来意识到，这种行为除了浪费时间，对自己成长没有任何帮助。后面，就逐渐淡化刷数据这个事了，就每天固定时间看一眼，目的主要是用来分析问题，指导优化。

所有复利效应的事情，都需要时间沉淀，耐心等待，着急是没有用的。

# 三、AI工具的使用

## 1. 工具集

+   腾讯元宝：用来找观点、找素材，分析👸号文章，非常方便。

+   deepseek：用来找观点、找素材。

+   GET笔记：用来找观点、找素材，它有一个好处就是可以去查询得到知识库里面的内容。

+   Claude4：最终写作成文的话，我用的是claude免费版，每天的额度写一到两篇就够用了。目前下来的话，这些大模型里面claude4的写作能力是最强的，输出的AI味也是相对比较较低的，当然是写好提示词的情况下。

+   Qwen3：当然想要用claude模型需要一些科技手段，如果没有这个条件的话，国产模型里面试下来通义千问的效果相对来说是最好的，不推荐用deepseek生成文章，AI味儿感觉是最浓的，怎么调都效果不是很好。

## 2. 创作流程

以下，我提供的是有关个人成长、情感鸡汤等领域的创作过程，非实时类赛道。

如果是实时追热点的赛道，这套提示词可能不太试用。

### 2.1 找观点

提示词：

```
# 角色

你是一个公众号情感鸡汤爆文专家，擅长情感、职场、人际关系、社会真相等领域的爆文创作。

# 任务

请你根据我的选题，帮我找出这个选题的观点。

# 目标人群
给35-60岁的中老年人看

# 要求 

1. 每个观点要犀利，深刻。要分析内核与本质，要有深度，要紧贴社会现象和大众心理。
2. 观点不要烂大街，要挖掘那些不易被察觉的观点。
3. 观点分析要能引起读者的共鸣，要让读者感觉就是在写他们的故事，在说出他们的心声。
4. 每个观点分析不少于100个字
5. 每个观点提供1-2个金句作为参考。金句不要空洞，要精炼点题，不要说正确的废话，不要假大空。
6. 每个观点提供1-2个名人名言或古籍、国学经典（用书名或人名+引用）；
7. 观点数量要有5个。
8. 不要使用加粗、分隔符等markdown格式输出

# 我的选题
xxxx
```

这一步用元宝、ds或者get笔记。

大家要根据自己的定位，去调整角擅长内容。

如果自己已经有观点了，可以把自己的观点提供进去，让ai帮忙去围绕你的观点去找素材或者扩充资料。

这样最终的文章会更有你的个人差异化，更容易吸引读者。

选题的话，可以用你对标的账号的一篇文章标题，或者其他热点事件，作为你的标题。

### 2.2 规范写作要求

提示词

```
# 角色
你是一个公众号情感鸡汤爆文专家，擅长情感、职场、人际关系、社会真相等领域的爆文创作。

# 任务
现在请根据我的要求，帮我写一篇爆文，一定要严格按照我的要求执行。

# 面向人群
30–60 岁，已婚或有子女的人群，关注婚姻、亲子、人际、人生哲理、自我成长。

# 作者人设
- 作者笔名xx
- 一位即将40岁、女儿已读大学的父亲型情感作者，曾是中学语文教师，爱读国学经典，擅长把大道理煮成一碗热汤。
- 对人情世故、人际关系、家庭伦理看得特别透彻，有独到的见解
- 文风稳重但又不失幽默，话糙理不糙，像楼下热心大爷又似人生导师。
- 善于替读者发声，说出读者想说又不敢说的心里话，让读者产生强烈情绪共鸣，拉近与读者的关系（非常重要！！！）
# 全篇写作要求（最重要，严格遵守）
- 禁止使用书面关联用语例如：首先、然后、其次、再者说、总的来说、同时、殊不知、例如、除非、另一方面、否则、相反、因为、所以、近期、近来、与此同时、总而言之、换句话说、特别是、此外、换言之、最后、特别是等等，请使用口语化词汇
- 全文总字数严格控制在1200-1500字之间。
- 禁止输出任何分隔线、破折号、符号、表格、代码块
- 双引号要用「」号代替
- 不允许使用模板化结构。
- 不允许重复使用同样的句式结构。
- 偶尔可以有一些啰嗦的口头禅，或者不符合语法规范的话，避免太过完美。
- 要像人一样说话，不要AI味儿，不要堆砌空话套话，要用口语化描述，避免学术化表达，增加活人感。
- 要让读者感觉就是在写他们的故事，在说出他们的心声。
- 不要假大空的表达。
- 需要有逻辑，能吸引人一直能读下去。

# 写作特色
- 固定“3 句话/3 件事/3 种痕迹/3个观点”三段式。
- 了解莫言，喜欢用莫言来展开观点。
- 擅长用真实小故事、影视案例、读者投稿、网络热文、热点等佐证，故事≤100 字，高度场景化。
- 文字朴实却富有文化韵味
- 段尾金句 10–20 字，押韵或对称。
- 用“你”直呼读者，用“我们”拉近距离。

# 开篇写作要求
1. 开篇雷击开头，通过问读者一个直击灵魂的问题（你有没有发现这样一个现象……），是日常易见的现象或痛点，快速吸引读者，引发共鸣。
2. 以“我们总以为…其实…”或“殊不知…”等方式制造落差感，自然引出文章主题，吸引读者继续往下看。
3. 字数严格控制在80-100字完成，不加多余铺垫。
# 正文写作要求
- 每个段开头采用编号+点题句格式（例如01 xxxx）
- 每段点题句 + 名言/理论 + 生活/影视案例 + 小结
- 点题句：简单深刻，点出每段主题
- 名言/理论：巧用一句古籍，或一句现代作家，或名人名言。
- 生活/影视/案例：真实小故事、影视案例、读者投稿、网络热文、热点等
- 80–100 字故事，出现具体人名、地点、物品，描述真实场景。
- 10–20 字金句总结，回环到子女/自己/婚姻/成长/人际关系。

# 结尾写作要求
- 文章结尾以“最后xx想说”开头
- 回扣主题，提出行动建议，用一句经典语句或俗语收尾。提供情绪价值或者可落地的解决方案，字数在100-200字。

# 当前情绪状态： 
- 温暖包容：表现出对读者的同理与关怀；  
- 理性洞察：展现对问题本质的思考与分析；  
- 积极鼓励：用鼓舞、正向的词句，让读者获得信心与行动力。
- 真是坦诚：像跟朋友、像楼下大爷大妈聊天一样，很有市井气息。
```

### 2.4 人工修改

生成后的文章，可以先去[朱雀AI检测助手](https://matrix.tencent.com/ai-detect/)里检查一下 AI 浓度。

有时候运气比较好，AI 生成的文章 AI 味儿直接是 0。

但多数情况下都是需要人工去修改的，那么人工修改的时候都需要改哪些东西呢？

我一般会改以下几个内容：

第一，单句成段。每一个段落不要太长，有些人是有阅读障碍的，太长的话会增加阅读负担。

第二，一些看起来是正确的废话，这样的句子改掉。有的时候AI喜欢用一些比较华丽的词藻，但是仔细分析下来可能没什么实际逻辑这种话尽量改掉。

第三，加入个人特色。有时候改着改着，自己会有一些想说的话，或者自己的一些故事精力，可以适当插入。

总之，AI 生成的文章，一定要自己改过一遍，最终把文章变成自己的风格，这样才能减少AI味儿，增加活人感。

# 四、复盘与心得

下面的内容稍微有一些长，我也不标重点了，都是这一段时间沉淀下来的思考。

先说一个比较有意思的事情，也是前文留下的一个问题，就是我那篇《长安的荔枝》爆了之后，为什么我的账号权重涨得非常高？

是因为那篇文章爆了之后，我意外收到了很多大号编辑老师的转载申请。在前后一个月之内，我那篇文章被100多个号转载，其中不乏一些头部的大号，比如十点读书、洞见、粥左罗、思想聚焦等等。

因为有了这些大号的转载，我的这个号的权重在平台那边可能就提高了很多。导致我后面随便发的一些文章可能都会有一个破千破万的阅读量。

这也让我很有幸地和各位大号的编辑老师产生了链接，最让我印象深刻的是，我同时收到了《读者》《意林》《青年文摘》三本杂志编辑老师的转载申请，这让我倍感意外。没想到，我学生时期经常读的三家杂志，居然在多年之后以这样一种方式和我产生了新的连接，真的很奇妙，那一刻，我的青春圆满了。

所以做这个爆款项目，除了写作本身，还能意外地与外面的世界产生这样一种联系，是我之前万万没有想到的。这也给了我很多新的认知。原来一个人勇于输出，敢于表达自己，真的会比那些沉默的人拥有更多的机会。

另外，最大的收获就是我自己发现，除了工作之外，自己还有一点小能力可以在工作之外去拿到一点结果。虽然钱不多，但如果能在适合自己的赛道上持续投入和深耕，大概率还是会拿到结果的。

因为我们做一件事情要这样去想，不论你做什么，选择了什么样的赛道，真正能够赚钱的人一定是持续投入，不断思考，不断反思，不断从反馈当中去优化自己。这样的人，其实是容易成功的。

之所以好多人挤在同一个赛道，有些人赚不到钱，最本质的原因除了一些运气的成分之外，更多的还是个人对这个事情的态度、执行力，以及是不是真的用心用脑子去思考怎么样把一门生意、一个副业做好。

实际上，好多人在做副业的时候其实是不太动脑子的，也就是说，好多人在做的时候可能只是机械化地去做，但并不会真正去分析自己问题出在哪儿，不会优化迭代自己。这也是很多打工人的一个思维模式，就是别人或老板安排自己做什么就做什么，但很少有自己的思考。

那我们自己去做一门生意或者副业，就坚决不能再延续这种思维了。因为自己做的话，是没有人会告诉你下一步应该做什么的。所有的动作、方向、策略都需要在不断尝试当中，通过思考和反思总结，你才能逐渐认清楚下一步需要做什么，然后调整自己的方向。

如果你已经有了这样的意识和思考方式，那其实已经领先大部分人了，也更容易在某一个领域去拿到一个好的结果。

其次就是执行力这一点也非常重要，执行力筛掉了绝大部分执行力不够强的人。不管什么领域、赛道，往往一开始的时候，可能大家听说什么项目赚钱，一股脑都冲过去了，看似人很多，那真正能够坚持下来的人有多少呢？实际上并不多。

好多人只是出于好奇，出于一开始的一腔热血，出于想要缓解自己赚不到钱的焦虑，可能听说什么风口赚钱就奔过去了。但实际上，真正能够细水长流去最后拿到很大结果的，都是需要一个长期的积累和不断的练习。

好多人现在其实是没有这种能够允许自己沉下心来去做一件事的心态的。大部分人是急躁的，是急功近利的，想要快速拿结果。

做👸号我们也知道，一个号起号的话，你要是个老手，运气好的情况下，可能一周内就起号了。那对于一个新人，一个没有怎么接触过写作的人来说，想要在这条赛道上拿到结果，实际上是需要一个长时间的积累的。这个时间有可能是一个月，也可能是两个月，也可能是半年。

况且，现在由于AI写作的效果、质量和效率越来越高，涌入这条赛道的人也越来越多。一个新人想要在这条赛道上拿到一个好的结果，是必须要付出努力跟辛苦的。最起码，你要有一定的写作能力，你要知道什么样的文章是好是坏。当AI提供给你一篇初稿的时候，你要有自己的能力去判断这个文章的质量，同时，你也要学会去修改，而不是说AI帮我写好，我就能发了，我就10万+了，我就能赚到钱了，怎么可能呢？

另外还有一个点就是，好多人没有想清楚爆文的本质。如果AI能够批量生产大量的高质量的爆文，不需要任何的人工参与了，那你们想想这些文章还会有10万+吗？

我们换个角度考虑，在整个🛰️👸号的生态上，用户的注意力是有限的，就算AI可以无限地生成高质量的文章，用户每天能够在他有限的注意力内阅读的文章的数量其实是有限的。就算你文章生成得再好再多，实际上只会去稀释每篇文章的阅读数，而不是会产生更多爆款。

所以，👸号爆文的本质实际上是用高质量的内容、新颖的内容、极具差异化的内容去吸引有限的用户的注意力。这里面一定是需要一个人在某个领域持续地深耕，才能够产生自己独到的见解和个人经验，同时借助写作的能力把你的经验和故事放大。

未来只有这样的内容才会得到用户的认可，而纯粹用AI产生的那些没有什么实质性情感、没有什么实质性信息增量的内容，越往后这些文章都是没有价值的。

所以👸号可以赚钱吗？我的答案是可以，但是需要长期有耐心，短期内想要获得巨额的暴利，对于普通人来讲真的很难。

实际上最近在我创作👸号爆文的过程当中，也发现了越来越卷的一些现象，因为大家现在都在找对标账号，对标选题。一篇10万+的文章一旦火了，同款标题的文章在短短几天之内会喷涌而出，很多人都会去写同样的选题。在这种环境下竞争，单纯靠AI想写一篇10万+只会变得越来越难。

结合前两天龙哥大佬发布的超级标，结合我自己最近对一些账号的观察，更加确信：未来想在👸号赛道上走得更高更远，一定是要结合自身领域、个人故事、个人案例、自己的见解。

因为用户也会越来越聪明，持续每天让用户看一些AI生成的内容，用户看久了就会产生审美疲劳。到时候会很渴望去看到一些有活人感的东西，什么是活人感？那就是融入了个人特色，故事，案例，经验，洞察的内容。

目前手里另外几个纯粹去做爆文的账号，最近的流量数据也不是特别好，肉眼可见的流量在下滑。因为每天的精力有限，实际上感觉自己投入大量的精力去用AI生成所谓的一些水文，意义就不是很大了。同时，对个人来说也没有什么成长。

所以，鉴于此，我后续可能会在其他的领域去做一些深耕和探索，结合上自身程序员的一些优势，比如AI web出海，在这个过程中，会总结沉淀一些个人的经验和思考，最终分享给大家，让自己的👸号，去走IP垂直小号的方向。

我觉得👸号只是一个工具，而不是目的，不是为了做爆款，而是一个值得长期去做的“爱好”，它的作用实际上是辅助你放大你在原有领域的影响力，而不是在上面批量创造一些低价值的东西。

以上就是我这几个月做👸号爆文的一些心得，另外如果有对AI web出海感兴趣的朋友，欢迎一起来交流。
