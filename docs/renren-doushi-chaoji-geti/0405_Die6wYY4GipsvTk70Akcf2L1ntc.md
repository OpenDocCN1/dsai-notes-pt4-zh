# 一：矩阵账号管理工具和指纹浏览器的区别

这是很多小白整不明白的一个地方。我着重说一下这个，里面有我自己的一些理解，理解不对的欢迎各位指正。

在我的理解范围内，所谓的矩阵账号管理系统，就是一个浏览器窗口，然而指纹浏览器可以创建无数个窗口。

矩阵账号管理工具（在我的理解这个只能叫一键分发平台）

大家可以直接去网上搜这个关键词，你搜到的工具其实都是一种类型的，一个工具集合了几十个平台的官网，你可以用这一个工具登陆到各种平台，添加各个平台的账号，给你的账号做记录（可以直观的看到你哪个账号掉线了，账号整体数据，等等）。我这随便截一个我常用平台的图。

![](img/3130e0470fef4638db3c907df209ef7c.png)

![](img/2e33fbcf851f3172461e0a293fb1df27.png)

**指纹浏览器**

指纹浏览器概念就太大了，我只能尽力用最简短的话用我自己的理解给大家解释一下这个东西。你买了一台电脑，先连了一条网线，下载了一个浏览器，用浏览器登陆了某个平台的账号，比如我在👸号登陆了旺仔的账号，👸号后台就给我旺仔这个账号做了一个身份标识：相当于我们一个人出生之后就有了一个身份标识，我自己的标识是哪国，哪个省，哪个市，哪个区的身份证号为***的旺仔。平台那边给我登记的电脑信息可能就是，一个用联想的，win11系统的，用什么字体的，user-Agent为***的一个吊毛。（我这忽略了很多人家识别设备的技巧，但是大概表达一下这个意思就行，毕竟我不是行业专家）

我们来类比一下，这个user-Agent是独一无二的，那就相当于我们身份证号码了。正常情况下这个东西是不好改的，但是用了这个指纹浏览器之后，就可以逃避平台的检测。

还是拿人打比方，身份证为***的旺仔爱看擦边视频，这小子是个色鬼，但是我如果能换一下身份证号，那只要我不再犯这个错误，那谁也不知道旺仔之前居然是个色鬼。

类比指纹浏览器，你用***的user-Agent被封号了，平台就标记了你这个user-Agent，你如果还顶着这个user-Agent去做账号，人家就检测到你小子是给平台添乱的，重点盯上你了。

指纹浏览器就又给了你一个欺骗平台的机会。

上面说的大家要有点想象力，因为如果让我正式的讲，我可能写几千个字也给大家讲不明白。

## 下面我们来正式说一下这二者的实用范围吧。

我先说答案，如果你手上只有1-3个同一平台的账号，（比如你有俩个抖音号，俩个快手，三个📕等等）我推荐你用矩阵账号管理工具。如果是同一个平台超过了三个账号以上，我推荐你使用指纹浏览器。（比如你有5个抖音号要每天运营）

### 下面我具体来说一下情况。

你要做一个自媒体博主，你打算每天发一个作品，但是你打算发到全网的自媒体平台里面，视频号，抖音，快手，📕等等，你在这些平台各注册了一个账号，每天的任务就是把做好的一个作品发到这一堆平台上，那我推荐你用矩阵管理工具，因为这个确实省事。因为你就算是抖音号被封了，但是📕是检测不到你这抖音这边有违规的，那对于📕来说你还是一个没有案底的优秀创作者。

如果你要做抖音平台的矩阵账号，你上了10个账号，要批量推广你的业务，那必须要这10个账号做到没有关联，这必须要用到指纹浏览器。这样就你被抖音封了一个号，其他九个号案底还是干净的。

# 二 自媒体矩阵之ip和设备的问题

今天和大家继续分享ip和设备的问题。本文很多地方是针对📕做矩阵的，现在对于查设备和ip最严格的感觉就是📕了，如果📕的设备和ip解决了，基本其他平台不会出什么大问题（除了抖音跳实名）

## ip

我先来说一下ip。你搞了一个WiFi，只要你有设备连接这个wifi，那么这些设备就都是同一个ip。你可以自己验证一下，我给大家放俩个截图，一个是电脑连接的，一个是手机连接的，这样大家就一目了然了。

![](img/c52ef6d1ade865d8c1f51122e7d4a062.png)

![](img/a52a11ef1a3bdbbbf69db54951b5968f.png)

不懂的可以自己到这个网站查一下：https://tool.lu/ip/

如果你用的手机卡的流量，那么你都有自己的一个独特的ip。这就是我们常说的一机一号一ip中的一ip了。

如果说我们手机上的ip解决了，但是我们用电脑端发布的，电脑端的ip是你的宽带ip，这个是无法像手机一样方便的，那就需要购买ip了。购买ip的一般会让你选择对应的项目和市的ip。你尽量选择你手机账号登陆所在市的ip，如果没有的话，可以选择附加市的，不要跨度太远了。

这样就不是严谨意义的一号一ip了，而是一号俩ip。只要你这俩个ip是固定使用的，不是今天一个，明天一个，后天又一个，那就没有一点问题。

（此处推荐大家一个ip一个号，如果实在条件有限，那就三个号一个ip，ip的钱省不得）

我这对接了一个专业人士，到时候能给大家压缩一下ip成本，等我到货了测试一下，可以的话群里通知大家，他这个东西可以把咱们的宽带切割成200个ip，价格是1288，可以说号越多越值。

我们再来说一下为什么ip要不一致？

最主要的是防关联，我上一篇分享的矩阵账号管理工具，主要是针对电脑的关联做了一定的解释。

ip也是同样一个道理，如果你这个ip被平台封过号，相当于你这个ip在平台留下案底了，下次你再有新号和这个ip是同一个号，那这个号就是人家的重点关注对象了，可能别人新的ip违规一次只封号三天，但是你这个ip就直接永久封号了，就是这个原因。

至于ip的原理我就不脱裤子放屁了，如果真想知其然知其所以然，你用自己的手段到YouTube搜“不良林”，这哥们的视频非常专业。

## 卡的分类

接下来我给大家说一下手机卡的问题，这有几种卡，老是容易混淆概念，我按照我的理解提三个概念吧，后面挨个给大家拆解。（有缺失的欢迎大家补充）

**虚卡：注册卡**

**实卡：厅卡，副卡，小号。**

### **虚卡（注册卡）**：

我理解的虚卡就是注册卡，所谓注册卡，就是比如你一次激活充值了15，这15就能用一年，这一年内你可以一直接码。各个平台的都可以收到，大家可以看下面的商家介绍。这些注册卡实际可以用流量，但是一个g收你200，这谁受得了。

![](img/899af25562b434eea987a9f43ff536d3.png)

### 实卡

#### 厅卡

这个东西一度困扰我很久，后来才发现我纯是被这些名称忽悠了，厅卡说人话就是：正常费用接打电话，正常费用刷用流量，正常费用收发短信的卡。这是我们最常用也是最常见的卡，一个月几十几百套餐缴的卡就是厅卡。就是这么简单。

#### 副卡

这个卡，相当于你自己的厅卡，每个月套餐收费是200，套餐里有200G流量，200分钟通话，像我下面截图的移动，你申情了三张副卡，这三张副卡每个月每张卡的费用是10块钱，共用你厅卡套餐里面的流量，通话。之后你这四张卡每个月的成本就是200+30。副卡功能和厅卡是一模一样的，效果也是同样的，在功能性上和厅卡一样。副卡是有大用的，我后面会说这个。

![](img/7f8c890e19d41819c139c4a59b147648.png)

#### 小号

小号这个大家不能理解为副卡，按照他的功能性，你可以把他理解为一个注册卡，甚至注册卡会给你一张卡，这个小号都不占你的卡槽，直接用软件就行。像我常用的一个是联通小号，现在看了一下好像关闭渠道了，这个卡我只能说不建议用，性价比完全被注册卡秒杀。这个小号你可以理解为：完全没有实体卡，但是可以接短信的一个东西。

![](img/218429077d1edcb7508ad1ce2e9e67a7.png)

#### **流量卡（物联卡）：**

这个概念非常模糊，因为每个人叫法都不一样，我就被误导了很长时间，我按照我的理解来给大家解释一下这个东西。

首先我们要基于自己是一个互联网人的身份来定义，有很多网上宣传的所谓的“流量卡”，实际他是实卡，再细分一下也就是所谓的套餐里面流量很多的厅卡。

我理解的真正的流量卡是物联卡，也就是只有上网功能的卡。这个原理是运营商独立给大厂提供的卡，比如**单车找移动申请了一条专线，要给自己的每个单车配一个物联卡从而实现联网功能，但是这个公司不老实，实际把这些卡卖给私人了，完事自己弄了一个充值渠道，别人用1个g的流量收1块钱，你不能直接把钱缴给移动，而且必须通过他们公司的充值渠道缴费，钱也是到账他们公司了，可能他找移动拿货价就是1毛。他就每个g赚9毛。

现在常用的是随身wifi，不存在卡这个东西了。这个比较屌的就是开关机可以跳ip，而且比较干净。有需要这个的可以私聊我 可以给大家开个代理，我推荐的套餐是19元/月/500G。开通代理后分佣是每次充值返利40%，自用相当于一个月20的套餐只花12元。（这有一个很大的缺点，就是网速可能会比较慢，但是我们核心是为了换ip，所以可以忽略）

## 一：设备

这大家可以看我第二部分设备那边，这主要给大家说三点需要注意的坑

一：不要买工作室退休的手机，这些基本都被玩费了，这种设备基本都会跳。

三：不要用非常老的手机，比如家人都淘汰好几年的那种设备，常见的踩坑的就是现在苹果17都马上要出了，还有人用苹果6做项目，这要注意。

号码可以看我文章的第三部分，必须要厅卡，不连wifi，全程用流量，像我注册新号的时候，不登录账号先上去刷会视频，第二天或者晚点再随便给视频点赞，这时候提示要登陆账号，直接用厅卡一键登陆，头像和昵称直接跳过，完事继续刷一会，该点赞点赞。几乎没遇到过跳核对的问题。

## 三：ip

次之就是用我上面说的物联卡里面提到的随身WiFi，这个比较神奇的就是开关一次就会换ip，换出来的ip还很干净。

# 五：账号掉线问题

这个我感觉是最容易理解的一个，这个我们需要挂在环境上，正常操作俩三天，这样相对才会稳一些。前几天掉线是正常的，掉了就登，完事养号，养稳定了就不容易掉了。

常见的就是🛰️电脑版，抖音，📕。

这些原理都相似，就是因为你还没等环境挂稳，你就开始做营销动作了。比如🛰️刚登陆一个新电脑，你就想着抓紧群发，强制退出都算是运气好，尤其像🛰️这种nb的东西，绝对要挂稳了再操作，你比如正常和人聊天，👸号看看文章什么的。

像📕，抖音这种平台，就正常刷视频，点赞，在那挂一会。（注意：📕用户网页和创作者中心是不通用的。抖音是通用的）

📕我这给了大家一个rpa脚本，大家自行网页下载使用，可以比特同时多开养号。（记得📕用户端和创作者端都登上）

![](img/0ee290373bf7a359741632e07a59f571.png)

就像视频号这种24小时失效的，这种基本无解，市面上有一个工具是可以平板登陆你的🛰️，之后检测掉线后平板给你登陆账号，这个其实没什么必要。
