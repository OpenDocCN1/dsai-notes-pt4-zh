### 关于VIBE CODING

摘抄一些之前总结的心得，来自👸号专栏：看榜单里面的话。

赚钱其实是需要基础设施的。

人生的基础设施是现金流，因为有吃喝拉撒睡的消费重力。

AI WEB赚钱的基础设施是API，支付收款，登录注册这些代码技术，是产品用户关键词场景等需求，是各个平台的操作按钮。

海外网站，最起码是技术流程，就是各种按钮操作，coudflare vercel github 域名注册商，有些概念可以不懂，但是要能够跟着做。

其次是支付收款，所有平台都是会审核的，而且各种设置是需要代码逻辑不出问题的。

最后是API的结果处理，其实很多都是小细节，小BUG，小设计。

我改了个很简单的套壳 API，变量名弄了很久，后面又修改设计，又有一些小修小补现在还在等审核。

之前总是奇怪怎么别人这么忙，现在发现其实是事情是真多，就跟你要一个人盖一座大楼一样，哪怕是一个房子，也需要砖头水泥钢筋，硬装软装，水电煤，家电家具等等。

有一个准则:修改bug，你要先理解bug。 ai自己不一定能修好bug，但是绝对能给帮助你理解bug，弄明白你就可以让ai帮你修好bug

把CURSOR当成人，项目伙伴，先把事情聊清楚，再干活，充分沟通，交流关于项目的一切认知信息

要运用项目管理意识，比如你跟公司行政小伙伴说，帮我搭建个阅读室，可能她很快帮你弄完了，但是你一看并不满意，与你的想法相差甚远，可能你的想法包括:要多大面积、要放多少书、什么类型的书、风格是什么样的..等等 N 多个点，前期的目标对齐很重要

让cursor 每次都是深度思考，全盘核査，仔细阅读之类的，主要是反复查看具体的BUG对应的代码文件和哪一行代码是什么

干活AI可能经常出错，但是当老师，绝对是最在行的。那我们就只需要花更多的时间更仔细地学习就好了

AI讲的很细，真的是每个文件，每个代码，每个规则给我仔细讲解，还做了可视化的项目结构图，网页结构图，代码结构图

新开会话最好是完成单独项目。cursor会按照既定的路线图默认去做，而不是先讨论

新开会话我感觉就像是换了实习生，得接手老项目

主要是我们不清楚你具体的项目情况，而且A如此强大几乎无所不知无所不能，所以一切都依赖于A1。我感觉主要的回复就是人工心里按摩和大概思路和方向以及我是怎么做的

一天最低要问AI一百个问题 我们有一整年 几千个小时去学习 基本功要扎实

用CLAUDE41.先让CURSOR通读项目告诉你页面结构和代码文件，你自己也要看一熟悉下 2.截图错误的地方和错误代码和错误日志 3.给出本质问题和所有可能解决方案基本上这步骤可以解决所有问题
