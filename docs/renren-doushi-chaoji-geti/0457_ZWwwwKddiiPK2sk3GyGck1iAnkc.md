## 一、缘起：为什么我们要跑“素人代发模型”

简单介绍一下跑这个代发模型的背景，方便大家了解我们的初衷和过程中犯的错误。

新增了一个剪辑师生态社群的后端，一开始是自己在研究模板，测模板，尝试建立一套低门槛、可执行、可快速验证变现能力的“内容代发模型”。新加入的一个哥们儿（称他为G先生吧）找我了解情况，问要不要一起测？我想着这个提议挺好，凡事有商有量，效率也高一点。

## 二、⚙️ 项目执行阶段（时间轴详解）

### ✅ 4.21 - 5.9｜基础验证期

于是在4月21号就开始分工测模板，主要是在📕上测，为什么选择📕？我们是从红薯号、操作的便利性等各方面综合考量，📕最容易上手、成本最低。

G先生测视频类的，我测图文类的。测了几天发现效果不太理想，中途做了几万字的讨论和调整，这里先略过，不在本文的讨论范围，时间很快来到了51。

51期间有一次沟通，就说自己的几个号打不出来，养号什么的也挺麻烦的，其他号在跑着项目，不想投入更多账号，那就用代发吧。我和G先生都有过用代发的经历，手上也有一些兼职，一拍即合。

因为假期原因，拖了几天，假期过完终于要开工了！于是开始研究模板、讨论分工、制定流程，但因为各自手上都有业务，进度还是很慢，时间来到5.10，不能再拖了，要快速把人数搞起来，再拖下去就凉凉了。也就是这个心理，导致后续很多动作的变形。

我们一开始想着筛选出100个执行力还不错的，20个打代发，40个打项目A，40个打项目B。

#### 阶段小结:目标修正

+ 形式选择：以📕平台为主
+ 内容方向：图文与视频并行测试
+ 模型目标：从零开始测试一套 "非个人品牌依赖型" 的赚钱路径

#### 阶段小结

+ 构建结算系统：每日结算、截图发红包
+ 群里开始出现“代发赚几十块”、“群友互相催打卡”现象
+ 意外封群：由于人数激增 + 活跃度高，被风控
+ 临时应急预案：重新拉群，数据回填，群速恢复

#### 优化动作：

+ 教程转为飞书文档链接，优化承接路径
+ 表格统计标准化，每天统计时间固定化

**成果：**

+ 群人数回升至200+，激励活跃者做课代表维护群秩序一天引入百人左右
