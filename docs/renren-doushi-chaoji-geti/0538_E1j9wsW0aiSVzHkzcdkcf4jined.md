# 一、勇敢组局

对于大部分没有组过局的人来说，第一次组局还是多少有点考虑过多的。

会想到：

万一自己组局没人来怎么办 ？

组局成功了，参与的小伙伴体验感不好怎么办 ？

参与的小伙伴会不会有各种诉求，自己的局不能满足怎么办？

…………

其实这些问题我都预想过，但一想到自己也经常给自己的小伙伴说，不要在做一件事之前就预想各种困难，或许你在苦苦思索的困难，在你真正的去执行的时候，是不存在的。

所以，如果你想做一件事情，勇敢的去做，如果你想组局，那就勇敢的组局。

最后组局反馈证明，大家都对此次组局挺满意的。

## 2.2准备内容

我们的主题是如何利用好生财！

那么作为组局官肯定得分享一些自己的使用心得。

一边自己总结自己的内容，还简单的写了个思维导图。

还去多学习拓展其他人的使用心得，所以找到罗卜哥去要一下他整理的思维导图。

总想着把这一次组局给组织好，让大家都能有所收获！

## 2.3找聚会地点

人都是偏向于熟悉。

所以我的第一选择是之前海盐老师组局时的咖啡店。

过了两天想想，上次海盐老师组局是周中，所以人不多，但我组局是周末，人估计会很多。

如果到时候可能没地方坐，那就尴尬了。

所以，打了个电话咨询了一下，说周末是人比较多，只能早点到。

又想到，咖啡店是一个开放的空间可能不适合交流。

所以，又开始找茶室。

发现大部分茶室，要么是3-4个人，要么是8-12个人，而我们一共7个人。

这就尴尬了，太小的坐不下，太大的又不值当。

而且有时间限制（虽然后来看细节知道，原来可以加时）。

于是想到了一个朋友开有茶室，但更多的是内部使用。

所以，我就问了一下，没想到这位阿姐说可以免费给我们提供使用，还给我们提供茶点什么的。当然，后续我也给阿姐发了红包表示感谢。

这也为后来我们聊到找地点的时候闲聊说，要是有个生财茶室就好了，这样就可以经常组局，又可以引流外部的人过来了解生财，再转化为圈友。

# 三、流程准备

虽然说我们生财都是搞钱话题，但是每个人做得项目都不一样，水平也不一样。

同一个局可能聊的话题会很散，就需要一个流程来限定，确保我们聊天内容都围绕我们的聚会主题。

所以，对于本次组局，我就写了个话题流程。

大家可以参考：

## 3.1、集合破冰 （ 14:00 -14:30 ）

顺时针，进行简单的自我介绍。

希望涵盖内容：自己擅长的技能、所处的行业、兴趣所在、能够提供什么资源、困惑所在。

## 3.2、话题圆桌讨论 （14:30 - 16:30）

### 3.2.1 你是怎么加入生财的 ？

契机和感想，以及为什么加入生财 ？

### 3.2.2 生财使用经验分享，如何利用好生财？

主要是老圈友分享，分享一下使用经验，让新圈友可以更快的学习应用！

### 3.2.3 新的一年，在生财的目标 ？

可以聊一聊在生财有什么想要达成的目标

### 3.2.4 聊一聊自己做过的项目

最好是包含成功和失败的项目，都有什么收获 ？

成功经验可以鼓舞大家去做项目，失败经验可以分享出来避坑！

## 3.3、自由社交

本环节，可自由小团体交流，一对一交流，不设限制。

如无其他安排，可作如下选择：

### 3.3.1.真人图书馆

对感兴趣的人，进行提问、追问，把对方当作书籍一样进行阅读，是第一轮自我介绍环节的延伸。

### 3.3.2.不定向话题自由讨论

一些参考问题如下：

最近这段时间最让我困感与苦恼的事情是什么？

最近这段时间，我有什么感悟想分享给大家？

如何选择项目 ？

# 四、组局交流

作为组局官一定不能迟到。

因为这次的组局就是因为你而把大家链接在一起的。

而且也是你自己找的地点，更是需要自己提前去打点了。

因为有了我们的流程，基本上整个组局交流都是围绕流程去分享。

这个也受到了圈友们的认可。

都觉得有一个固定流程，大家有更强的主题感，就不会不知道分享什么。

基本上流程都挺顺畅的，每个圈友都分享了自己的一些想法。

线上聊千遍，不如线下见一面。

线下交流之后，彼此的信任感是非常不一样的。

也加深了对各位圈友各自业务的了解。

这样也方便后续的合作。

> PS：交流的内容都太丰富了，也是组局经验不足，没有很好的做下记录。

>

> 所以，后续组局的圈友也可以开下飞书妙计记录各位圈友的发言，然后可以做个总结

# 五、组局后续

在交流过程中，刘掌柜讲到了一个非常好的点。

那就是记住你周围20个圈友的所有产品。

还举例了北京某圈友的案例。

我觉得说得非常对，因为之前也有人找我说想要做数字人，刚好我们组局有个伙伴就是做这块的，如果早点认识知道有这个业务，就可以对接了。

组局结束后，刘掌柜还用心的做了个总结，并且在群里介绍参与的圈友。

我觉得这一点就做得非常好，让各位圈友知道聚会的都有谁，大致有什么业务，也可以对接起来。
