# **三、搭建情侣飞行棋后台**

## ①搭建情侣飞行棋后台

通过搭建情侣飞行棋后台后，会获得自己对应推广链接，将推广链接的域名植入到🛰️订阅号后，用户通过点击该链接付费后获得的收益，就可以在后台实时看到，并可以实时提现到自己的支付宝账号中。

搭建的后台大家可以去某宝自行搜索，目前市面上的价格也是层次不齐，什么价位的都有，而且进入小程序的速度也很慢，主要还是看所使用的服务器，一些小商贩为了节约成本都是选用虚拟服务器。

我们为了游戏的稳定和用户体验感，特意花重金联合腾讯员工开发小程序，同时使用机房服务器，只为给用户带来最好的游戏体验。
