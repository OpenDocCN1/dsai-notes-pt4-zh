## 一、为什么要做 IP？

做每一件事情之前，都先问自己为什么要做这件事。你在抖音、知乎、📕上面看到那么多人在分享做个人 IP 的方法。

你是不是就开始盲目地认为自己该做个人 IP ？但你有没有真正想清楚，做个人 IP 到底对你有什么好处呢？

### 1、适应未来的商业模式

以前赚钱都是 B to C，中间隔着好几层渠道呢，但现在都是 C to F 了，客户有需求，厂家再根据需求去搞生产下订单。

但这里就出现了一个问题，以前商家是不需要直接面对用户的，但是现在直播间卖货，你是需要一个形象的，这个形象就是商品的代言人，来回答用户的各种问题的。

谁来做？你找主播，辛苦把人家的卖货能力培养起来了，最后人家跑了，带着你的客户跑了，你找谁评理去？所以，你要做创始人IP。

如果你没有公司，就是个人 IP，个人 IP 可以把流量导给那些有交付能力的人，比如我4年前刚做社群的时候，就是靠个人 IP 来分销各大平台的知识付费产品，把我的付费社群做起来的。

[100个社群运营技巧系列](https://articles.zsxq.com/id_w9ht8x4mokiw.html)

而创始人 IP 就直接把流量导给自己的产品和交付后端就行了，中间不需要任何渠道，既保证了利润，又防止被抢走有价值的商业流量。

### 2、节省你的营销成本

问你个问题，如果你的公司原来每年需要花掉 500万 来做推广，然后才能有 200 万利润，而现在做个人 IP 只需要花50万来投一投豆荚或者知＋，你做不做？

当然做，这是一个性价比的问题，做个人 IP 就是为了节省营销成本嘛。就好像特斯拉的广告很少，因为马斯克就是一个行走的超级 IP，他本身就是免费的广告牌。

我之前一直纠结一件事情，如果我不需要出来写东西，分享自己的价值观，也能通过自己构建的一个系统来赚到钱，那我还要不要出来做 IP？（这个可能也是很多赚钱圈友会想的一个问题）

答案就是：我还得做。因为你想把业务模式放大，营销成本就一定会提升，节省成本就是增加收益。而无论你是企业还是个人，做 IP 都可以帮你节省一大笔金钱和时间成本。

### 3、放大你的个人商业价值

说一个很残酷但又很真实的例子，同样的一套课程，我有 IP，我就敢卖1999元/人，你没有 IP，你可能连 99 元都卖不出去。

就好像你身边的那位 Tony 老师，以前给你剪头发是 30 块钱，后来人家成为网红了，你花 500 块钱都约不到了。这就是 IP 能量，它可以提高一个人的商业价值，可以让一个人的产品具有更高的溢价性。

你可能会有疑问，比如说我找你来做咨询，你跟我聊的东西，非常简单，就是平常我身边朋友跟我聊的，甚至是一模一样，你凭啥敢收我1000元/H 的咨询费呢？

想一想，如果你把自己去咨询一位大咖的经历写成文章，再配上你们俩个的合影，别人看了会不会觉得你也变牛了呢？你的客户看了，是不是觉得你家产品更值得信赖了呢？是不是就有了信任背书了呢？

所以，我经常和我的付费会员聊天，一定要做 IP 营销，哪怕你们的产品没有任何变化，当你这个人因为 IP 值钱了之后，你的产品也就更值钱了。

## 二、IP 到底是什么？

你可能听了太多关于 IP 的概念，感觉说的都对，但却又没办法把它们合并在一起。

**其实，真正有价值的东西，逻辑都非常简单， IP 就是核心价值＋标签。** 我们经营 IP 就是用自己的核心价值在他人心智里留下一个标签，当他们在有需求的时候，脑袋里可以第一个蹦出你这个标签。

IP=核心价值＋调性（文化特质＋外貌形象）

### 1、核心价值

这个世界的社交系统是极其复杂的，所以我们识别一个人的重要工具就是“标签”。

无论你对外输出多少价值，用户记住你的方法永远是几个简单的标签。

例如，芷蓝在赚钱人眼中的标签就是【会发朋友圈】【会做社群运营】【在做个人IP】等等，而你在其他人眼中的标签有可能是【会玩PPT】【健身教练】【电商玩的好】等等。

也就是说，用户记住我们的第一选项是“你是干什么的？”、“你会什么？”

**所以，核心价值是你的一技之长！**

在旧社会，社会分工没有现在这么复杂，我们记住一个人的名字基本都是“王木匠”、“豆腐张”或者“郑屠夫”之类的名称。间接说明，你只有会一个核心技能，别人才会去记你的名字，如果你啥也不会，别人就会叫你“李老二”或者“张老三”这样的称呼。

### 2、外在形象

如果一个人既有一技之长，又有一个鲜明的外在形象，那么他的个人品牌在用户的大脑里就会更加清晰。

比如叶茂中老师的红五星帽子（这里缅怀一下叶老师，这些年来一直在看和研究他的书籍），比如乔布斯的牛仔裤，比如扎克伯格的T恤，比如迪克牛仔的大波浪卷发。

退一步说，如果一个人没有一技之长，但是却有一个让人过目不忘的外在形象，用户也能记住他，只是这个外部形象不能为你变现罢了。

外在形象包括：穿衣风格、面部特征、发型配饰、社交网络头像等。

比如在我的朋友圈训练营课程中，第二讲就是【朋友圈四件套】的打造，这个四件套里就包含了头像和朋友圈封面，这就是一个人在🛰️这个平台的个人形象所在。

### 3、文化特征

文化特征就是一个人说话的风格是什么？性格特点是什么？行为方式是什么？

比如说老罗说话就经常会自黑，冯巩一上台就会说“我想死你们了”，包括一个人的工作态度和诚信口碑之类的外在表现都属于文化特征。

试想一下，如果一个人啥也不会，而且相貌平平，但一直做事很靠谱，是不是也可以在你的印象里留下“做事稳重”这个标签，这也是个人IP。

以上就是构成 IP 的3个基础要素， 其中核心价值凌驾于外在形象和文化特征之上。

也就是说，2和3是加分项，如果没有核心价值，2和3的意义不大。

## 四、怎么做定位？

想要搞清楚怎么做定位，你就先知道我们为什么要做定位，以及什么是定位！

第一个问题：我们为什么要做定位？

1、定位可以帮助你确定商业变现逻辑

2、定位可以帮助你确定内容输出体系

3、定位可以帮助你减少行业竞争对手

第二个问题：什么是定位？

市面上关于定位的文章、课程和书籍一大堆，你看多了可能会脑袋疼，觉得说的都对，却又无法在大脑里形成一个完整的知识体系。其实不用那么纠结，只要能帮助你解决上面我说的 3 个问题，那就是一个正确的定位方法。

对于我来说，定位就是一句话：

**你能通过出售xx产品/服务，帮助xx人，解决xx问题，或者建立一个xx的需求场景。**

比如说，我能通过出售我的付费社群，帮助自媒体新手快速通过内容平台赚到副业的第1块钱。

比如说，我能通过出售我的 IP 营销训练营，帮助自媒体全职创业者通过 IP 营销实现深度变现。

记住，定位不是标签，你说你的定位是一个医生，这就不对，医生是标签，而帮助儿童解决不爱吃饭，或者脾胃不和的问题，这个才是定位。

**标签＝身份≠定位**

关于为什么要定位，定位是什么，以及如何做定位，之前在赚钱发过详细的文章，这里就不再赘述。

## 五、如何做内容？

时刻记住，内容是个人 IP 变现的唯一武器，好的内容永远值钱。

你只有承认内容对自己的重要性，才会去认真对待内容生产这件事，如果你有“写不写都可以”或者“写多写少”都可以这种心态，注定你没办法通过内容获取优质流量，也没办法把优质的内容变成优质的产品，也没办法把优质的流量＋优质的产品，变成钱。

### 1、什么是内容？

宽泛来讲，文字、图片、视频是内容的 3 种基础形态，而文字和图片属于冷内容，视频属于热内容。

用户接受热内容要比接受冷内容更容易些。比如说西游记这部小说，读原著对于人们来说是最难的，稍微容易一点是看连环画，最爽的就是看电视剧和电影了。

为什么会这样？因为冷内容需要人们主动去思考，而热内容创作者利用图片＋声音＋文字的形式，降低了用户的思考难度，降低了用户接受信息的门槛。

这就是为啥很多人不愿意读书，却喜欢刷短视频的原因。但在这个时代，只要你的内容足够优质，越是高价值的用户，越愿意主动参与到与你创作冷内容的深度链接中。

很多人问我：芷蓝你不做短视频，只写长文，能赚到钱吗？有人愿意为你付费吗？现在都是短视频时代了，你不做短视频，是不是在和时代对抗？

首先，我不是不做短视频，而是不擅长做短视频，我也做，就是做的少而已，没有镜头感，对着镜头说话会比较别扭。（不过我参加本期抖音同城航海，拍了不下100个视频，已经锻炼的不错了，所以还是要多练）

其次，并不是一定要做短视频才能赚到钱，事实证明一些拥有高付费能力和意愿的用户，恰恰不喜欢刷抖音，不喜欢看那些短视频平台上的内容。 他们喜欢读长文，不喜欢非碎片化的内容，喜欢阅读文字，并且愿意深度思考。 为什么海报这个媒体不会被短视频代替， 因为海报可以被人们的目光凝视， 短视频做不到。

只要他们觉得你的文字或者服务对他们有价值，会毫不犹豫的为你付费，因为他们知道，时间才是最宝贵的。

### 2、什么是好内容？

判断内容好不好的唯一标准就是：有没有人肯为你的内容付费？

就像郭德纲曾经说过一句话：判断这个相声演员行不行的唯一标准就是“有没有人愿意买票听你的相声。”

好的内容，在我看来有2个维度：价值维度、逻辑维度。

#### ① 价值维度是什么？

关于内容的3个价值，之前我已经分享过很多次了，即情绪价值、时间价值和认知价值。

#### 什么是情绪价值？

你给用户讲述一个故事，用户看了之后伤心、流泪、大笑、恐惧、痛苦，这些都是情绪，用户通过消费你的内容，获取上面这些情绪，就是情绪价值。

你在抖音上看到的那些情景剧，基本都是提供情绪价值的，不过多说一句，输出情绪价值的门槛较高，而且变现方式不明朗，所以大家谨慎选择。对我来说，情绪价值通常是用来辅助认知价值来进行输出的。

比如说我要给大家分享创业方法，先提供一段自己的创业经历，让大家感同身受，能够快速进入这个场景之中，然后再去分享认知类的内容，大家就更容易接受了。

#### 什么是时间价值？

凡是能帮助用户节省时间的产品或者服务，用户都愿意为此买单，内容也一样。

比如你的定位是：帮助喜欢旅行的青年规划小众出游路线，用最少的钱获得最好的旅行体验。

那么，如果你写了一篇《适合大学生穷游的25个小众旅行景点》，这个就是在帮助用户节省时间。类似的还有你经常看见的书单推荐，100个宝藏 APP 推荐等等。

让用户觉得，看完你这篇文章就不用去看别人的了，不用再去自己一个个的找了，这样就是为他们节省了时间价值，他们愿意为你的内容消费，甚至愿意购买你后端产品，满足他们更深层次的需求。

举个例子，其实我有个会员就是做小众旅行规划的，他在抖音和📕上分享的，就是刚才我说过的类似内容，一些小众景点推荐啊，一些旅行必备的好物推荐，还有一些防踩坑经验汇总等等。

他后端的产品就是“旅行规划咨询”，可以根据你的需求，帮你定制行程，包括民宿预定、背包行路线规划、旅行向导和低价火车票预定等等。现在通过📕来引流，上个月参加我的📕行动营，成交了4单，客单价都是8000元以上。

#### 什么是认知价值？

认知价值就是为用户提供新的知识、看待问题的新角度、思考问题的新逻辑。

做内容，最难的就是提供认知价值，原因有2点。

第一，你只有长时间专注于某个领域才能够生产有深度的内容，而现在每个领域都有很多牛人，你能够输出的内容，其它牛人也可以输出。用户看谁不看谁，还要看你的人格魅力，也就是个人 IP 里的“文化特征”和“外表形象”。

比如同样是知识口播，如果你是一个颜值超高的小姐姐，用户自然愿意关注你，谁不愿意一边学知识一边看美女呢？

第二，你是否能把专业的知识说给普通人听？也就是我之前所说的，你要在自己的大脑和用户的大脑之间，建立一个认知接口，把专业内容包装成有趣、大家爱听的东西。

#### ② 逻辑维度是什么？

当一个人接受信息的时候，如果它是有逻辑的传递，那么接受程度就会很高，相反如果是信息数量的堆砌，没有任何逻辑模型，那么就算你传递的信息质量很高，用户的体验也会大打折扣。

举个例子，我做内容生产时，严格按照金字塔或者黄金圈这 2 个逻辑模型来输出，不光要让用户知道“我在说什么”，还要让用户知道“我是怎么说的”。这样，当我描述完一件事之后，用户就能以最小的认知成本来理解好几周我说的内容了。

当然，更高级的方法是，你还要给用户一个把信息放进自己大脑里的逻辑，就是告诉他如果把我传递给你的知识和自己大脑里的知识知识做链接。新的知识要符合已有旧知识的搭建逻辑，才能真正变成你可以运营的知识。

总结一下，内容是个人 IP 变现的唯一武器，好的内容为用户提供情绪价值、时间价值和认知价值，在通过内容传递价值时，一定要有逻辑，这样你的内容抵达用户心智后，才能展现它的完整价值。

### 3、如何创作内容？

开始分享这部分前，请大家务必记住一句话，这句话是学习自媒体内容创作的原点法则，无论你学习任何自媒体内容创作技巧，都以这句话为原则。

“爆款内容是可以被批量生产的，自媒体创作者不要靠灵感，要靠模板。” 请先记住这句话，别问为什么，你会在我接下来的文章中找到答案，并暗自认同。

#### 第一步：找对标

当你确定了自己的定位后，接下来不要着急去写东西，先在内容平台找到自己的对标账号，也就是你的同行。哪怕你之前是做传统媒体的，对于内容有着较高的感知度，也依然要这么去做。

因为每个平台的网感和算法是不一样的，优质内容要符合这个平台用户喜好和算法逻辑才有可能被发现并推荐给相对应的标签用户。

举个例子，你看知乎的高赞回答，仔细去看他们的第一句话，就会发现这句话特别吸睛，大概率能把人的注意力锁定在这里，接下来一定是给你一个目录，让你识别到这篇文章/回答的价值，然后才开始一点点地叙述。

这个就是价值前置，就是知乎这个平台的网感，就是知乎网友们愿意看的逻辑。

找到和你定位相同的账号，看看他是怎么把你们这个领域的专业知识包装成平台用户和算法喜欢的样子进行输出的，至关重要。

至于怎么找对标账号？你可以使用蝉妈妈或者 5118 这样的工具来搞定，比如我自己素材库里的「商业 IP 拆解表」已经把现阶段各个行业和领域内的头部账号列举出来了，并且按照多个维度展示了他们的变现方式以及其它信息。

#### 第二步：去模仿

我们找对标账号是为了做以下几件事情：

#### ① 观察他们的内容输出体系

这个体系包含了样式和内容，比如你看下面这个抖音账号，它的输出样式就是找几个人排队回答自媒体营销的相关内容，答对的有奖励，答错的有惩罚。

![](img/de10eb50174efb13e016cd81ce560d88.png)

点开的他的主页，全是这个模式，唯一在变化的就是一些道具，比如某人会抗一个水桶，某人会拿着一个锤子。视频封面都是黄色大字标出内容主题，风格一样。

这个就是输出体系，他有可能是在看到某个博主发这类视频之后，自己去模仿了，然后数据不错，就全力 all in 这类内容的输出。

![](img/87416fef0c88387f4915fbc7369501b6.png)

再看我的探店抖音账号，内容逻辑也是一样的，先拍探店产品特写，然后给一张全景图，然后进店＋环节介绍，最后是推荐语，变化的只是产品而已，输出模式不变。

建立自己的内容输出体系至关重要，它是一种约束，就好像唐诗的五言和七言格律，没有这个约束会大大降低你的输出频率，有了这个约束，你只需要把想做的话题内容话题按照固定的格式放进来修改即可。

在模仿对标账号的时候，我们需要注意自己的模仿成本，也就说这个博主的风格，拍摄环境以及其它拍摄成本，你能 cover 的住吗？比如你属于轻声细语的柔美外边，能去模仿那些在直播间大吼大叫的博主吗？比如你大学刚毕业，能去模仿那些开保时捷和法拉利的剧情吗？

内容对标，还需要成本对标才行，找到最适合自己模仿的账号，才能达到一样的效果。

#### ② 摸清他们的商业变现路径

我经常会在抖音、📕和知乎上面通过查看博主的个人介绍、内容引流钩子，去加他们的🛰️，看看他们到底是怎么从引流到卖产品变现的。

其实就算定位相同，变现方式不一定相同，因为一个定位下，还可以服务不同的用户，比如抖音上有很多美食博主都是通过视频带货佣金来变现的。

但是，美食也分高端和低端啊，比如我经常关注的一个博主“稻草放毒”，专门就是高端食材带货，一瓶矿泉水200多，属于收藏级别，还有各种龙虾、鱼子酱、顶级牛排等等，甚至连一袋包子都要68元，这就是服务高端人群的。



所以，多看别人的完整商业变现路径，有助于优化你的内容创作和变现逻辑。

## ③ 快速进行内容输出

内容体系也清晰了，变现路径也明白了，接下来直接输出内容。

这个阶段，你要暴力一点，做自媒体账号初期，一定不要想太多，不要有完美主义，最好是像素级模仿，把对标账号里的内容素材和案例换成自己的就行。我们要以变现为导向，借鉴一定比原创更高效，我们是为了卖产品、卖服务，不是写小说写散文，无非就是阳春白雪或者下里巴人。

为啥要快？这么做就是为了抢时间，你要知道，当一个定位下的某个爆款内容模板火了，各路模仿者会接踵而来，但这个领域的用户量是固定的，所以当用户审美疲劳后，你这个内容模板就不爆了。

### 第三步：做模板

当你进行模仿快速输出后，无非就 2 个结果，一个是反馈不错，另外一个就是毫无声响。

如果毫无声响，说明你的模仿有问题，回到第2步，换一个账号去模仿，或者仔细研究一下自己在模仿的过程中忽略了哪些细节？

我经常跟我的学员说：模仿一定要做到像素级别，比如说你模仿抖音上的一个知识 IP 做口播，并不是把它的内容结构模仿过来就 OK 了，他的表情，他的一些口语常用词，甚至推一下眼镜的动作，都有可能是流量密码。在你不知道他的内容为什么会火的时候，就要把所有细节全部拿过来。

如果反馈不错，这个时候，千万不要自嗨，千万不要自嗨，千万不要自嗨，重要的话我说 3 遍，因为我看到太多人因为自嗨把好好的一手牌给打烂了。

记住芷蓝这句话：当你的内容不知道什么原因火了的时候，最重要的事情就是把【火】无限复制，一直复制到它【不火了】为止。

这个复制的过程，其实就是生产模板的过程。换句话来说，一个内容模板的意义在于可以让你在某个定位下，把自己的输出的所有内容，都按照一个固定的格式来展现。

然而我们追求的是爆款模板，也就是说，按照这个固定格式展现，至少有 70% 以上的概率会爆掉，会有很好的数据反馈，会帮助你快速涨粉和引流。

![](img/76a103b6ff792f527ab556d37727c153.png)

比如说，我自己这边有正在通过爆款内容模板来制作📕账号矩阵，一个模板数据反馈不错，立刻复制到其它的账号上，从结果上来看，效果是很明显的，每天能稳定引流 150-200人左右，只要爆过的帖子，用这个模板去写新帖子依然会爆。

![](img/8c623491c61cc92a77a1c3505c37c138.png)

当然，爆款模板你不能准备一个，在我们多个项目小组的测试中，沉淀出了很多爆款模板，并且把它们制作成了 PPT 格式，这意味着当你拿到这个模板之后，不需要再去思考怎么写一篇📕帖子，直接把你的内容放进去，或者说把一些数据图放进去，然后等着平台给你反馈就行了。

如果一个模板不爆，就换另外一个模板，直至找到适合你所在行业和领域内容所展示的模板为止。另外，大家一定要记住，爆款模板这个玩法只适合📕、知乎或者抖音图文内容输出模式。

如果你是输出视频或者写文章，那么这个所谓的模板就是一种【场景】，就好像金字塔写作法一样，你需要把自己的内容按照一个爆款【场景】来输出才行，就比如上面提到的“排队回答问题”一样。另外，我非常建议大家在从📕、知乎和抖音引流时，先把流量导入到👸号，然后再用👸号＋关键词回复的方式导入到自己的🛰️。

为什么要这样做？

① 防止🛰️号以为营销被封，导致流量浪费

② 👸号可以积累用户，未来多一个私域触点＋接广告变现

③ 用户到了👸号还可以看到你之前的内容，有助于留住用户

### 建议大家多制作下面这样的内容钩子，多准备几张，不同的资料不同的内容可以放在不同的平台和账号，建立素材库十分有必要，提高内容生产效率。

## 七、产品怎么做？

在分享这个版块之前，请大家先思考一个问题：对于我们普通人来说，没有钱，没有人脉，没有背景，那么最好的产品是什么呢？

### 答案：一定是知识付费产品。

为什么？芷蓝根据这几年做自媒体的经验，给你以下 3 个理由，看完你就懂了。

### 1、成本极低

创业赚钱，首先要想成本。

我家老爷子那个年代，从体制里出来自己去单干（那阵不流行叫创业）首先要解决的问题就是资金，你没钱上哪进货去啊？你没钱怎么建厂子啊？你没钱怎么给工人发工资啊？你没钱连一辆拉货的小面包车都买不起。

所以，创业资金这个门槛就拦下了一批想自己干的人，放在这个时代也是一样的。

很多人并不知道自媒体这种轻资产创业的模式，他们甚至感知不到自己在得到 APP、抖音、知乎上面买的一套课程也能叫做产品？他们只是觉得“今天我花钱买了点知识”。

ok，正是这种认知上的信息差，给正在看我这篇文章的小伙伴们带来了优势。

你做一套知识付费产品，需要什么钱吗？最多也就是一台电脑＋一部手机而已，甚至连电脑都不需要，我会员社群里的某个宝妈，拿着一部手机就录制了一套《7节课教你拍好日常亲子照》的课程。

这套课程 199 元，她现在已经卖出了 73 个，而且在这 73 个学员里，还成交了 2 个 2999元/人 的私教产品，你可以算一下 199✖️73＋2999✖️2 等于多少钱。

说到这，你需要再思考一个问题，那就是产品的交付成本。如果你开一家门店卖货，无论是什么货，都会有各种乱七八糟的售后问题，你每多卖出一个商品，这个售后的成本就多增加了一点。

而知识付费产品不同，当你把课程做出来后，你的边际成本就已经降到最低了，你卖出1套是这个成本，你卖出10000套还是这个成本。

总结一下，知识付费产品在成本上是有极大优势的，无论是制作还是销售，对于我们普通人来说都是友好的。

### 2、无需人脉

互联网的好处就是，只要你的产品质量有保证，只要你会运营，就不需要到处托关系找人，平台的流量就能让你赚到盆满钵满。

我小时候，只要家里有啥事，无论是做买卖还是上学找工作，听到最多的一句话就是：看看托托那谁，他以前是xx局管xx事的，跟我xx是老同学。

生活在关系型社会里面，干啥都要靠关系。但咱是普通人，普通人哪有啥关系？有关系我们还普通吗？还能没钱嘛？所以，当你做产品卖产品的时候，就要摆脱传统社交关系的束缚，比如做做课＋卖课。

只要课程做的好，你放到抖音学浪上面，你放到小鹅通上面，你放到荔枝微课上面，不需要靠关系也能赚到一大笔钱。

这个就是产品即流量，运营即流量，没关系没人脉，咱照样赚钱。

### 3、传播优势

如果你把一套课程只当产品来卖，只能说你想的太简单了。

之所以要做课程，不光是它能当一款产品来帮你变现，它还是一个传播你个人 IP与核心价值理论模型的最好载体。

不太明白？唐僧西天取经你知道吧，你觉得从西天取回来的这些经书最大的价值是什么？当然是传播佛学了，当然是给众生普渡了。

你再想想，很多名人都会出书，你觉得他们是指望着通过卖书赚的这点钱来致富吗？当然不是，一本书真正的意义在于它能够给你做信任背书，它能传播你的核心价值。

一套课程，你卖99元，如果上完你这套课程的用户，完全认可了你在课程中提到的逻辑，那么他很有可能会再买你一个高价咨询，就是这个意思。

我们知道了做知识付费产品对于跟人 IP 营销的意义，接下来再看到底要怎么做一款产品。

### 第一步：做好选题

选题对于做课非常重要，你的课程好不好卖，以及能卖到什么程度都是由选题决定的。

其实，这就相当于为你的课程做定位，原理和之前给大家讲的 IP 定位是一样的，既要适合你自己，卖着顺手，又要符合市场需求，有更高的天花板，最后才能轻松地变现。

关于选题，你一定要记住芷蓝的这句话：

普通人做课程一定是面向问题，而不是面向知识，要做的是解决用户的具体问题，而不是给用户做科普，给他们一套系统的知识理论。

什么是科普和系统知识理论？

① 中国历史 50 讲

② 人像摄影大全课程

③ 销售理论18讲

以上这 3 类都是系统课程，不要做，不要做，不要做！

为什么不要做？因为用户不感兴趣，很多东西在网上也查的到，即使买了也学不完；而这种大课你自己又不好做，可能做一半觉得无聊就放弃了。

那你要做的是什么课程？

① 5节课，教你用手机把自己的女朋友拍的又美又仙

② 7节课，手把手教你成为一个抖音团购达人

③ 财务/HR必须要掌握的10种 Excel 技巧，学完早下班涨工资

以上这 3 种就是面向一个具体场景下问题的，课程短小而精悍，而且还带着你自己的应用场景，用户很快就能学完，学完就有收获感，还能帮助你传播。

ok，当你确定了自己要做什么类型的课，就要开始研究具体的选题内容，这里芷蓝给大家3个建议。

① 市场必须有需求，不能是伪痛点

② 这个领域你必须做出成绩，有案例课晒

③ 把这个领域的所有痛点全部罗列出来，然后进行组合＋筛选，最后选出5-7个痛点，这个就是你的选题

### 第二步：确定提纲

怎样才能设计一个让客户秒下单的提纲呢？这同样也是个技术活，芷蓝给大家以下 3 个建议。

### （1）设计误区

① 大纲过于系统化

这个和刚才说的一样，就是不要做那种大而全的课程标题

② 目录标题过于学术化

比如，就像我刚才写到的“让用户秒下单的提纲”这个就让用户很有购买和学习欲望，可如果你写“怎么设计一个科学的提纲”就是过于学术化，用户会不感兴趣。

### （2）核心思维

刚才给大家分享了设计课程大纲的 2 个误区，只要你能够避开，至少做出来的东西不会太差。

接下来，芷蓝再给大家讲讲在做大纲目录设计时，需要遵循的 2 个核心要素，围绕着这 2 个要素去做，会让用户更快识别到你的课程价值，并且有下单的冲动。

### ① 价值思维

一定要记住，用户买你的课程不是为了要这个课程本身，除非他是做盗版的，想要转卖课程，否则他们要的都是结果，想通过学习你的课程解决自己的问题。

a 多用数字，抓住注意力

比如：3个步骤 15 分钟，让你彻底掌握怎么合并表格！

b 提出问题，引发思考

比如：2022年，为什么人人都需要做副业？

c 提升网感，引发共鸣

比如：让社群更活跃的 3 个神秘配方是什么？

多罗列一些有网感的互联网词汇，就能让你的标题和用户产生共鸣，再次强调不用写成教科书式的标题。

### ② 结构思维

无论你的课程有多少节，无论你的课程目录要怎么写，你都要遵循一个结构思维，就是让用户清晰地感知到自己的学习进度以及学习深度。

什么是学习进度？举个例子，比如说这套课程的第一节课是《用户喜欢什么样的课程？》从结构上来说，其实是在告诉你“什么是好课程”以及“我们为什么要做好课程”。

知道黄金圈法则的同学一眼就看明白了，其实第一节课解决的问题依然是 Why 和 What。

### （3）制作步骤

刚才给大家分享了设计目录大纲的 2 个核心思维，接下来跟大家说说具体操作的 4 个步骤。

① 问题清单

之前已经说过，我们做课程是为了解决用户的具体问题，那么制作课纲的第一步就是要先把用户的这些具体问题，或者说痛点一一列出来。

这是一个筛选的过程，可能针对一个领域，你能列出 100 个问题，但是你的课程不能把这 100 个问题全部说清楚。因为有的问题是伪需求，有的问题可以和其它问题合并到一起，所以我们要先罗列，然后再筛选＋合并。

② 逻辑归纳

当你的痛点清单筛选出来后，就该对这些痛点进行逻辑归纳了。

其实这个归纳逻辑有很多种，比如说常见的基础篇、实操篇、进阶篇，这 3 大篇章就可以容纳大部分的课题类型了。

③ 提纲导图

归纳出提纲逻辑之后，就可以用思维导图这个工具了，从大模块开始，做出细分的具体提纲内容。

④ 迭代优化

经过上面这 3 步，你已经把提纲的逻辑和具体的提纲标题写出来了，最后一步就是迭代优化。

### 第三步：填充内容

选题也做好了，提纲也列好了，接下来就是如何把课程内容填充进去。

关键就是填充什么内容，才能用户觉得这套课程有价值，有实操性，值得购买呢？这里就要用到芷蓝的“好课3模块”原理了。

### （1）应用原理

为什么一节课程，甚至是一套课程里必须要有应用原理呢？本质上来说，课程就是经验的沉淀和传播。

没有原理，你在课程里分享的各种方法和知识点，就不能被串联在一起；没有原理，你的经验就不能以一种高效的方式传递给用户；没有原理你课程就会显得不高级，用户就不愿意给你主动传播，或者说在传播的时候，跟别人讲不清楚。

你也可以把原理理解成为一种介质，它的作用就是串联知识、传播知识、提升高级感。

那么，知道了原理的好处，要怎么萃取自己课程的专属原理呢？

① 自己沉淀，如果你在某一个领域已经深耕多年，一定会有一套自己的应用原理，这个是很自然的。如果没有沉淀出来，说明你做的还不够好。

② 模仿修改，有的人可能就属于实战派，方法论已经内化到他的行为记忆中，并且自己就是不擅长做逻辑归纳这种工作。

### （2）具体案例

理论体系确实好记，也更容易被传播，但它是抽象的，如果你想让用户更好地吸收和理解你的理论体系，就需要用更具体、更形象的案例来解释它。

① 优先选择自己的案例，然后是和你有关联的

② 讲案例要讲关键部分，它的作用是解释你的理论体系，不要浪费用户的时间

③ 不要带偏主题，时刻围绕着你的理论体系

### （3）实操方法

写课程，第一步是告诉用户你的应用原理，这个是抽象化的，第二步通过为用户分享具体案例，来为你的应用原理做解释说明。

到第二步，用户已经明白了你的原理逻辑，知道了这个原理是什么，以及我为什么要用这个原理。

紧接着第三步，你就要告诉用户怎样具体地去应用这套原理？这就要求你把抽象概念还原成具体实操方法。

什么是方法？其实一句话就说清楚了：方法就是流程步骤。

### 第四步：理论萃取

思考一个问题：如何才能把你的课卖出更高的价格？

从表象上来看，用户购买你的课程是为了解决一个具体问题，但如果你能把解决一个具体问题的方法，提炼萃取出一个更高级的理论体系，那么你的课程对于他来说就变成了一个重要的思维模型。

一个经典的思维模型，永远要比一个解决方案更值钱，那么你的课程价格就提上来了。

### （1）提炼中心思想

这个观点可以是一句话，最好是金句，说出来能够让学员眼前一亮的金句，比如说“流量不等于留量”，当然也可以是一个词，比如说“产品思维”或者“流量思维”等等。

提出中心思想后，你还要给它和一个合理的解释，拿刚才那句话“流量不等于留量”来举例子，你给它的解释就可以是：不能够变现的流量，再多也是数据，能够变现的才叫做留量。

想象一下，用户学完之后，跟他的同事或者老板分享你的课程，对方问这个课程主要讲的是什么，这个时候，只需要用一句话就能说清楚，这个就是有效降低了课程的传播成本。

### （2）理论模型化

第一种方法是：比喻

比如说池塘理论就是把用户比喻成鱼，把流量比喻成水，把私域流量池比喻成一个你自己挖掘的池塘。

第二种方式是：跨界组合

如果你既是一个医生，又是一个私域营销高手，那么就可以从医学和营销这两个领域中挑选有一些元素进行跨界组合。（赚钱圈友一定知道我说的是谁@梁靠谱）

最后就做出了：望闻问切4步成交法

第三种方法是：改造升级

改造升级就是在原有的理论上进行修改，比如我的“朋友圈四有”理论其实是从柚子妹的朋友圈 3 要素这个理论上改造升级的。

还有牧场理论，也是由池塘理论改造过来的，只不过是换了一个比喻而已，同样你还能改造成农场理论、森林法则等等。

不在于你改造的是什么，在于你改造后是不是有使用意义，能把能把你自己的那套理论装进去。

说句题外话，你自己萃取出一个理论模型后，一定要“奔走相告”！

什么意思？就是你要刻意增加这个模型的曝光度，无论是写文章还是拍视频，都要高频率地去分享。

就像脑白金的广告一样，说的次数多了，即使不是什么至理名言，当别人遇到某个具体场景的问题时，也能第一时间想起你说的那个模型。

世界上本来没有路，走的人多了就成了路。

世界上本来没有这个理论，说的人多了，就成了真理了。

### （3）模型的表现形式

① 公式型

利润=产品✖️流量✖️转化率

个人IP=核心价值＋文化特征＋外表形象

以上这些就是公式型表现形式，它的好处就是可以让用户更清晰地了解一个核心理论到底是什么？

② 流程型

个人 IP 打造 5 步法：定位→内容→流量→产品→变现

这个就是流程型表现形式，它的好处就是可以方便用户去按照步骤实操这个模型。
