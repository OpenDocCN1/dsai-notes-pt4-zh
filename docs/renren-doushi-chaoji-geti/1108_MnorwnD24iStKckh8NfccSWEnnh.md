## 一、为什么要开通一拖六账户?

市场定期涌现基金套利机遇，且这些机会往往伴随着购买限额。以近期的印度基金LOF为例，每个基金账户的申购限额仅为100元。然而，若投资者拥有多个场内基金账户（最多可达6个），则单次申购额度可增至600元，从而实现6倍的套利收益。

然而，这些账户分散于不同的券商，这无疑增加了操作的复杂性。若能将这些账户集中于单一券商，投资者便能一次性完成所有操作，无论是申购还是赎回，都将更为便捷高效。在基金套利中，能够迅速卖出是至关重要的，因此集中账户操作将使投资者在套利机会中占得先机。

## 二、什么是一拖六账户？

### 关于证券账户的相关规定与操作模式说明

根据现行规定，每位投资者凭身份证可开设的证券账户数量有明确限制：具体来说，每位投资者最多可以开设3个沪市A股账户、3个深市A股账户、3个上海封闭式基金账户以及3个深圳封闭式基金账户。

将这六种不同类型的基金账户集中绑定至单一券商账户的操作，被形象地称为“一拖六”模式。以深市账户为例，所谓的“一拖六”拖拉机账户，即是指一个账户下同时拥有3个深市股东账户和3个深市封闭式基金账户。

### 套利投资的策略与市场定位

套利交易是一种利用市场价格差异来获取利润的策略。其核心思想在于，在价格较低的市场购入资产，随后在价格较高的市场出售，以此赚取两者之间的价差。这种策略在基金投资中同样适用，投资者可以在一个市场中以较低的价格买入基金，然后在另一个市场中以较高的价格卖出，从而实现利润的套取。

在金融投资领域，套利的类型多种多样，包括外汇套利、期货套利、对冲基金套利以及可转债套利等。对于个人投资者而言，可转债套利（尤其是新债申购）和开放式基金套利是较为适宜的选择。

值得注意的是，许多基金在单日申购时存在限额，例如兴全合宜基金对单个账户的日申购限额为1万元，兴全合润基金的日申购限额为3000元，而富国天惠基金的日申购限额为1万元。限额的存在意味着，当场内申购基金的数量受限时，资金可能会转向场内购买，从而推高基金的市价。这种市价与申购净值之间的差异，为套利提供了空间。为了能够申购更大规模的资金，投资者需要通过增加账户数量来实现，但这需要开通佣金较低的账户，以保持套利的经济效益。

成功的套利需要在扣除手续费和资金占用期间的利息成本后，确保最终利润为正。套利盈利的计算公式可以表示为：套利盈利 = 卖出价格 - 买入价格 - 手续费 - 资金利息成本。

套利的原理基于一级市场和二级市场的价格形成机制。

一级市场通常在每个交易日结束时更新一次价格，而二级市场的基金价格则由市场供求关系决定，被称为市价，并在交易时间内实时波动。正是不同市场间的价格差异，以及供求关系的变化，为套利者提供了盈利的机会。

## 五、清楚适合套利的基金品种

在进行套利操作时，选择基金产品需满足一个关键条件：该基金必须在一级市场和二级市场均有交易，即能够同时在场外和场内进行买卖。这种双重交易机制为投资者提供了溢价和折价的机会，从而创造了套利的可能性。

然而，并非所有基金都具备在场内交易的条件。以下是几类常见的可以在场内交易的基金类型：

1. ETF基金：这类基金对套利资金的要求较高，通常至少需要50万元人民币，因此对于资金量较小的普通投资者而言，可能不太适合进行套利操作。ETF基金更适合在场内进行交易。
2. LOF基金：投资者若希望在场外申购后在场内卖出，或在场内买入后在场外赎回，需要完成转托管的手续。
3. QDII基金：其操作方式与LOF基金类似。
4. 封闭式基金：其套利逻辑在于，在基金到期前的几个交易日内，投资者可以在场内以折价购买基金，并在2至3个月后基金转为开放式后在场外进行赎回。

封闭式基金同样适合普通投资者，但可操作的套利机会相对较少。

5. 分级基金：其套利逻辑较为复杂，主要包括以下几个步骤：

   + 在基金折价时，投资者可以按比例购买A类和B类子基金；
   + 然后将A类和B类子基金合并为母基金；
   + 最后进行赎回。在基金溢价时，通常不建议进行套利操作。

   由于分级基金的套利流程较为复杂，且中国证监会已经提高了分级基金的交易门槛，要求投资者在申请权限开通前20个交易日的日均证券类资产不低于30万元人民币，因此这类基金不太适合普通投资者参与。

在考虑进行基金套利时，投资者应根据自己的资金情况、投资经验和风险承受能力，审慎选择合适的基金产品，并充分了解相关的套利策略和操作流程。

## 六、寻找套利机会

套利机会的发现与把握，需要敏锐的市场洞察力和快速的行动力。以下是几种常见的套利机会及其操作策略：

### 市场普遍看涨时的溢价套利

在牛市初期或市场热点形成时，投资者可以通过以下步骤进行溢价套利：

+ 场内申购，场内卖出：利用市场溢价，通过场内申购后迅速卖出以获利。
+ 场外申购，场内卖出：在场外市场申购后，通过跨系统转托管，实现快速卖出。

#### 案例分析

2006年11月23日，南方高增长基金宣布大比例分红并暂停申购，导致连续涨停。投资者通过场内申购和场外认购后转托管，实现了高额溢价收益。

### 市场普遍看跌时的折价套利

在熊市初期或市场利空消息频出时，折价套利成为可能：

+ 场内买入，场内赎回：在市场折价时买入，通过场内赎回以减少损失。

#### 注意事项

+ 赎回费率可能较高，尤其是短期内的赎回。
+ 操作时间跨度较长，可能需要数天至半月。
+ 需要对市场行情有准确的预判。

### 长期暂停申购基金重启时的溢价套利

当基金公司因故暂停申购后重启，通常会出现溢价套利机会。此时，由于申购通道关闭，溢价难以被市场抹平，重启申购时即为套利良机。

### 个股停牌但有重大利好消息时

当个股因重大利好消息停牌，投资者可通过持有相关基金进行间接投资，实现套利。

### 封闭式基金到期套利

封闭式基金到期前，若出现折价，投资者可在到期日前买入，到期后基金停牌并复牌，从而实现折价套利。以5%的折价率计算，年化收益率可达约20%。

### 总结

无论是场外还是场内，基金申购和赎回都应基于净值。尽管场外申购费率较低，但转托管手续繁琐且到账时间较长。相比之下，场内申购流程简洁，到账迅速，更适合进行基金套利。

### 风险提示

套利虽有利可图，但风险亦不容忽视。市场波动可能导致买入卖出间隔时间内的价格不利变动，从而带来亏损风险。尽管底仓套利方法可降低风险，但投资者仍需保持警惕。

### 成功套利的关键

成功的套利需要投资者具备扎实的金融知识、熟练的操作技能和敏锐的市场嗅觉。只有那些准备充分、洞察先机的投资者，才能在瞬息万变的市场中捕捉到套利机会。
