# 交通银行-银证“荐面礼上礼”

# 1、活动内容

**一、活动名称： **银证“荐面礼上礼”

**二、活动日期： **2024年2月1日——2024年12月31日

虽然活动时间周期很长，但是整个活动的奖品是有限制的，奖品领完活动就会截止。

**三、活动玩法与攻略：**

1、首次绑定自己名下任意证券账户，即可得1个66元贴金券

注意：如果之前已经开过其他证券账户的，直接登录其他证券账户去操作换绑即可，无需新开证券户。如果自己名下一个证券账户都没有，可以新开一个证券账户，开的时候直接绑定就可以了。

**2、绑定成功后，完成银证转账，转到证券户1000元，保**留1个交易日，即可再得1个66元贴金券。

因**为这个**活动需要走推荐人的二维码才能参加，所以为了回馈卡友，凡是走群主推荐的，成功完成任务后，群主再奖励 33 元现金红包。

# 整个任务下来可以得：66+66+33=165元。

轻轻松松就撸到手了。
