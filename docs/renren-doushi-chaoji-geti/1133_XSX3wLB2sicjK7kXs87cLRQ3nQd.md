# 一键查询：个人名下所有证券账户~~~中国结算APP

> 来源：[https://xuqiwei1986.feishu.cn/docx/Jq6Wd4xYnohNCJxsLZTcd4b2nac](https://xuqiwei1986.feishu.cn/docx/Jq6Wd4xYnohNCJxsLZTcd4b2nac)

很多人都开过好几个证券开户， 时间久了， 开过的券商太多， 最后， 怎么也想不起来 自己之前在 哪些券商 开过帐户 ，哪个已经销掉户 或者哪个帐户还没销。以及自己的沪A、深A股东账号又分别是多少。 怎么办呢？ 下面我说一下：

![](img/86ccb410320db927faae248f0b9e19db.png)

① 搜索【中国结算营业厅】微信公众号，或点击下面公众号链接

![](img/079d13fb717516cede1023c07f22913b.png)

② 进入公众号以后，点击最下方菜单的【我的账户】，在子菜单中选择【账户注册】

![](img/688ea3a9c45dbeb8fed69d9dbfbcd860.png)

③如果您之前有注册过中国结算公司的账号，点击下图最下方的【已有账号，点此登录】，然后直接跳转到第④步；如果您没有注册过，请按照下图的步骤依次输入【手机号】-【昵称】-【短信验证码】，然后勾选【我已阅读】，点击【下一步】设置密码，注册成功以后跳转到第④步登录。

![](img/16c1d9b073457b2298efe80331226af7.png)

④依次输入【手机号】-【登录密码】-【验证码】，然后点击【登录】。如果您忘记了用户名和密码，可以点击下面的【忘记用户名】和【找回密码】找回。

![](img/b74d8d8bc1195e6dabccae61b684e06d.png)

⑤登录成功以后，点击【已关联账户数/总账户数】

![](img/618daee5ee18fcd0fa3971b7de2985b2.png)

⑥在我的一码通页面可以看到您的一码通号，我们所有的证券账户都挂在一码通号下面。在这里，我们可以回顾一下自己的开户历史，查看过去我们一共开过几个证券账户，分**别是在哪个证**券公司开户的，还有账户类型，开户时间和首次交易日期。红框里的证券账户都是带***的，如果我们想查看具体的账户号码，还需要点击【我的证券账户】旁边的 眼睫毛标识 ，然后输入验证码进行验证。

![](img/d455263e33ef372242f44102baf89fa8.png)

⑦完成认证以后，可以看到您名下所有的完整的证券账户号码。

![](img/4585b900022e5c463edd91d729c73e39.png)
