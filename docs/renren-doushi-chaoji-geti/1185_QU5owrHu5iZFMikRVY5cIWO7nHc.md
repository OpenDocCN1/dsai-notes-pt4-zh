# **杭州银行-宝石山理财活动**

4月新户活动，最高利率可达12.3%

确实好久没发理财活动的攻略了，季末换季以来，一直没有什么好的理财活动，这次介绍的杭州银行属于 万亿级城商行，相对民营来说稳健许多。服务好、人性化，历史表现极其优异。

首先我们分析活动，这次的活动是有硬性的指标的；

仅限无杭银1类卡用户参与 ，其次开 户需要验证地理信息，仅限 北京、上海、广东、江苏、安徽、浙江 。

不是以上地区的小伙伴能参与么，当然可以，不过 你需要先虚拟定位到上面发的这些地区中的任一地区 ，然后再开户即可参加， 只需要在开户的时候虚拟一次定位即可 。

然后网开的电子户就都是2类户，不需要担心什么1类户的问题了。

一、确定是以上（或虚拟定位）到地区后可扫码注册：

**二、注册、转账攻略： **

扫码之后，输入手机号、验证码，点击接受邀请，即可跳转到注册页面。

注册的手机号建议和你后面要绑定的银行卡预留手机号一致。

注册之后，实名认证，然后点击去开户， 绑定一张其他银行一类卡，即可开通杭州银行电子二类户。

![](img/9ab30dea6d0a64ee7c72dbdbc236f263.png)

开通电子账户之后，在APP-我的-电子账户即可进行资金转入转出，也可以查看你开的电子卡号，可以从绑定的一类户银行APP直接转账到这个二类户。

**特别提示一下 **， 绑定的一类卡银行有的限额，如果需要大额资金进出，则复制你的杭州银行卡号，从一类户银行APP转账过去 ，具体操作如下（比如本王绑定的一类卡是中行卡，就只能走中行APP转到杭州银行卡）：

![](img/e4860e7fe82f1de5baff9668751f16b2.png)

二类卡资金进出都只能通过绑定的一类卡，其他卡转不进来也转不走钱，从这个角度上说，二类卡比一类卡资金更安全，多了一重保护。

转入之后，就可以在杭银直销APP做风险测评、买理财、薅羊毛、赚收益了。

# **余利宝无限卡有什么用？**

支付宝里面的钱，如果想提现到银行卡，还需要给支付宝手续费，提现1千元的手续费为1元。

但是， 支付宝开通“余利宝”后，支付宝收到钱，自动转入余利宝，再通过余利宝，可以免费提现到银行卡！

这样通过余利宝倒一下就能实现免费提现！

**有个问题：**

虽然余利宝里的钱提现到银行卡，是免费的，且没有额度限制。 但是支付宝余额转入到余利宝是有额度限制的！

![](img/21332196800a5b1a11cd673b0b4be544.png)

**余利宝无限卡的作用：**

**支付宝转入不限额**

**余利宝提额全免费**

支付宝APP - 余利宝 - 精选服务右滑“更多” - 余额自动转入 - 关闭
