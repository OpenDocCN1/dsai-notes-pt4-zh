# 谷歌 Gmail 邮箱自动转发到国内邮箱

有时候没办法访问谷歌 Gmail 邮箱，又不想错过谷歌 Gmail 邮箱内的邮件，怎么办？

很简单，只需设置一下：将谷歌 Gmail 邮箱收到的邮件，自动转发到国内其他邮箱就行了！

谷歌Gmail邮箱，怎么设置自动转发到国内其他邮箱呢？方法如下：

### 1.打开谷歌Gmail邮箱后，点击右上角的设置图标：

![](img/6a83b62a725ed7fb83163f2440f26c18.png)

### 2.弹出【快捷设置】后，点击【查看所有设置】

![](img/a17cf0bc9b935977cdfcdc6301a642a1.png)

### **3.进**入所有设置页面后，点击 切换到【转发和POP/IMAP】，再点击【添加转发地址】。

![](img/b12556cb9c245c69311d134e98d5a0e1.png)

### 4.输入：要转发到国内的对应邮箱地址！再点击【下一步】。

![](img/92f6d2927e4f1123afdaed78515eb6e2.png)

### 5.弹出确认窗口后，点击【继续】。

![](img/86b48f3ccad8ef98f42a6bea30dfb12f.png)

### 6.然后就会提示：系统已向 你的国内邮箱，发送了确认码，以验证权限。

![](img/f46eff59a246c7d323087cb4966daaba.png)

### **7.这时你要接收：谷歌Gmail邮箱 自**动转发的国内邮箱，就会收到一封确认邮件！

![](img/934b4219c4703f6061321d9cd645abe1.png)

### 8.打开这封邮件，按提示，点击：对应的链接，进行确认！

![](img/a7b531d82fb433091e0c52898efffa45.png)

### 9.点击 确认链接地址，进入网页 界面如下：请点击【确认】。

![](img/577b6d5b77f3d6121358f1ea6e136b3d.png)

### **10.确认成功！**

![](img/0b873b26fe3f0c462751474444327941.png)

### **11.然后，再回到【转发和****POP**/IMAP】设置界面，点击：开启转发功能！

![](img/8dcd5e706f87803ecc88d6b6b7aeb6dc.png)

### 12.然后，再滚动到页面底部，找到并点击【保存更改】。

![](img/c20da650b082b61bf5fda7a45b198266.png)

确认保存设置后，以后你的谷歌Gmail邮箱收到新邮件，就会自动转发到国内的邮箱了！

### **13.测试：用邮箱a，给google邮箱发邮件，看看邮**箱b（这个邮箱刚才转了邮箱）是否收到邮件
