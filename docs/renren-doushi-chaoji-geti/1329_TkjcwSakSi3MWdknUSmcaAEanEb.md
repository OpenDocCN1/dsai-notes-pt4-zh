
# 2023-06-01奇富科技@自研大模型发展历程：诠释AI与金融的完美融合

> 来源：[`https://xuqiwei1986.feishu.cn/docx/N6PHdrPQvopGhZxTFJhccb4Wnmb`](https://xuqiwei1986.feishu.cn/docx/N6PHdrPQvopGhZxTFJhccb4Wnmb)

`http://finance.china.com.cn/roll/20230601/5991007.shtml`

近期，奇富科技的大模型团队与某国有银行省分行进行了一次重要交流。这次交流中，奇富科技回顾了自研大模型的发展历程，以及其在金融行业的应用取得的成果。

在交流中，奇富科技的团队成员分享了自研大模型的探索之路。奇富科技之所以能够成为国内第一个研发金融行业通用大模型的公司，得益于过去多年的人工智能积累。

回顾起初的阶段，奇富科技专注于构建金融模型，用于解决特定的金融问题。通过对海量的金融数据进行分析和建模，成功地开发了一系列模型，用于营销获客、风险评估、信用评分、欺诈检测等领域。在这些业务环节的AI运用验证了奇富科技的技术实力和应用潜力。

其中，AI应用最显著的成果是奇富科技智能风控引擎`Argus`，在AI深度应用方面，它实现了社区发现挖掘、层级联邦学习、策略机器人等子领域的创新突破，有效赋能客群识别能力和风险管理水平，为金融机构提供贷前、贷中、贷后全方位的风险防控技术支持，让金融机构快速得到准确的审核结果。奇富科技在`Argus`的助力下，单次交易筛选变量数十万个、筛选风控模型超过3000个、约98%的授信申请和99.5%的订单申请实现全自动审核。

另一AI利器是智能获客引擎`Glaucus`，它可以实现270亿次的运算，能在2ms内快速判断流量价值、流量的竞争力以及流量最适配的创意，并输出出价系数和创意ID, 峰值处理能力可达每秒41w次；智能运营，精细化经营的实践和能力建设，用户标签达到30个大类1000+的数量，支持秒级的实时策略，海量并发支持千万级别的用户互动。

在交流中，奇富科技强调了过去的人工智能积累对于实现金融行业通用大模型的重要性。在多年的研发和实践中积累的大量金融领域知识和经验，使得奇富科技比其他同行能够更好地理解金融问题的本质，并针对性地改进和优化大模型的设计和训练。

交流的最后，奇富科技团队展望了未来的发展方向，计划进一步拓展大模型的应用领域，包括更精细化的风险管理、更个性化的对客交流，以及金融市场趋势预测等。同时，奇富科技也将与更多金融机构展开合作，共同推动金融科技创新，为金融行业的数字化转型提供支持。
