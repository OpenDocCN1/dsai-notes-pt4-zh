
# 2023-09-14用AIGC来薅内容平台的羊毛？趁早打消这个念头-36氪

继文心一言正式面向所有用户开放后，腾讯的混元、阿里的通义千问也陆续与大家见面了。一时间，中文AI大模型也迎来了一轮集中爆发，无论是真的将AI视作生产力工具，还是将其作为谈资，许多朋友都不约而同地加入到了这场热潮中。自然而然的，借助AI大模型这一轮红利挣钱的声音又一次出现了。

最近这段时间，相信在🛰️朋友圈、知乎、🧣、📕、抖音等社交平台上，大家都看到了不少诸如用AI大模型写👸号文章、用文心一言写📕等日入上千的内容。看到这里，有些朋友可能已经按捺不住，准备用文心一言、ChatGPT等批量生成内容，好从内容平台上赚一笔流量费了。

不过有这类想法的朋友先别急，因为这可能并不是一条发财的路，而是个巧妙的陷阱。因为这一模式，其实并非首次出现，自从互联网厂商发现流量的价值后，吸引流量就变成了他们的要旨，但厂商自身的产能与海量的用户又有着不可调和的矛盾，仅凭厂商自己很难满足用户对于信息的需求，这时引入UGC内容也成为了一种解决方案，自媒体这个概念也正是在这一时期诞生。

![](img/89f6f72a9e49d709bd5837f45a0470a9.png)

那么问题来了，内容创作者做自媒体是为了挣钱，而个人的力量毕竟是有限的，所以通过自动化脚本批量产出内容，进而在内容平台上吸引用户点击，显然就更有效率。所以早在十余年前，使用自动化脚本的“内容农场”就已经大量出现，这类内容农场的核心工作就是批量生成“小编体”，诸如“XX到底是怎么回事呢”、“XX相信大家都很震惊，但是XX到底是怎么回事呢，下面就让小编带大家一起了解吧”这类。

相信在大家的网上冲浪时，这类内容多少都有看到过。但显然这样的内容在质量上只能用“垃圾”来形容，毕竟这一类脚本只能做到简单的内容拼接重组，相比凝聚了人类智慧火花的文字就显得更呆板、且无趣。虽然大家可能第一次会被骗点击，但事不过三，这也是为什么曾经风光无限的“移动内容聚合第一股”趣头条，仅仅上市不到五年就只能黯然退市。

![](img/b106045e29bc5f9741c4ad0f666ea451.png)

从某种意义来说，使用AI大模型生成内容与使用脚本来产出内容在本质上是一样的，但架不住AI厂商将AI大模型的能力渲染得天花乱坠，以至于在一部分网友的认知里，AI大模型生产的内容在可读性、趣味性等维度已经有了质的飞跃。既然如此，使用ChatGPT等产品制造的内容，在质量上也就有了比拟素质在线的内容创作者的资格。

但遗憾的是，哪怕目前最强大的GPT-4、或是还在不断强化中文理解能力的文心一言，都还无法做到产出有爆款潜力的内容。其实这些AI大模型作为聊天机器人其实是合格的，相信用过ChatGPT、New Bing、文心一言的朋友，往往都会感觉到它们的回答是有“人味”的。然而它们在写作、特别是商业写作层面则难当大任，更是极其依赖人工的后期调整。

![](img/217b886a63b344f03a08fce77cfe5986.png)

此前，《黑镜》制片人查理·布洛克就曾用ChatGPT写了一集《黑镜》的剧本，但他对ChatGPT写作结果的评价是，“乍一看似乎很有道理，但第二眼看就是一坨屎，它所做的就是查找《黑镜》所有剧集的大纲，然后把它们混在一起。再深入挖掘一下就会发现，实际上没有任何真正的原创思想”。其实不仅仅是内容创作领域的专业人士，AI写作即便是在普通人看来也并不合格。

如今在互联网上，使用AI生成信息的网站已经出现，但大多数受众的评价则是“不明所以”。而造成这一结果的原因很简单，大型语言模型（LLM）由于拥有人类望尘莫及的数据处理能力，所以在标准化场景上具有优势，比如公文写作、知识问答等方面，并且在客观内容上的表达也是AI的强项。但在理解和表达情感方面则还存在一定的困难，偏偏内容平台以及用户需要的却是独创、个性化、情感丰沛，以及带有强烈主观色彩的内容。

![](img/27412ca102f06222ed8ba85f360bff74.png)

不然的话，诸如百度百科、维基百科这样的产品才应该是最受欢迎的内容平台，可现实却是大家更愿意去知乎、抖音、X、Reddit。即便是忽略技术的局限性，单纯从商业逻辑来讲，用这类AI大模型产品来写👸号文章日入上千的说法，其实也有问题。原因则更简单，因为从ChatGPT点燃AIGC赛道算起，到现在为止也不过才一年时间，所以AIGC的红利还在，既然是一个有利可图的生意，参与者不但不闷声发大财、反而还公开宣扬，这是不是有点反直觉？

需要注意的是，普通用户使用AI大模型几乎是没有门槛的，诸如OpenAI的API接口授权费也都是直接挂在官网上，每个Token对应的价格是0.006美元，国内市场文心一言提供的智能写作服务则是198元/月。如果一门生意既很赚钱、又没门槛，那么它必然就会与主流存在巨大的信息差，可偏偏在用AI大模型薅内容平台羊毛这件事上，局内人不仅没有藏着掖着、反而还在大肆宣扬。

![](img/b32c676a872e5c617da3763d0f349d70.png)

事出反常必有妖，渲染用大模型批量产出内容赚钱的人，看中的是“卖课”，也就是教你如何用AI这门生意。然而，这门生意才是有信息差的，因为这帮人并没有告诉大家，内容平台现在正在严打AI创作内容。就在最近这段时间，抖音、🛰️等平台都发布了特定内容需主动添加标识的公告，也就是创作者在发布由人工智能生成的内容时，需添加声明“内容由AI生成”，并对所产生的后果负责。

![](img/01b19c1f9b7b1d80b7bdc5bfc35cf40e.png)

准确来说，现阶段内容平台欢迎以AI为题材的内容，但对用AI生成的内容则是警惕的。承前所述，现阶段AI生成的内容还存在死板、僵硬的问题，与平台需要的优质内容压根就不沾边，这才是渲染“用ChatGPT写👸号，一天广告收入上千”的人隐藏起来的信息差。

因此在AI大模型能理解、并复现人类情感之前，AI生成的文字与早前内容农场显然并没有本质的区别。
