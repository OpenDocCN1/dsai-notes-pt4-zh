# 哈银消金人工智能金融服务平台，助力绿色金融ESG发展

今年4月，国家发展改革委等11个部门联合印发《碳达峰碳中和标准体系建设指南》，其中强调积极参与国际标准制定，在能源、工业、金融等重点行业和领域实现绿色低碳发展。

哈银消费金融作为持牌消费金融机构，积极践行ESG理念，以数字化驱动业务发展为核心建设思想，综合运用多项业界领先的数字化科学技术，建立了“人工智能金融服务平台”。该平台通过技术创新，以人工智能、大数据、云计算等数字技术可实现人工智能核心技术的快速研发、训练、测试及运用，加快模型部署和策略迭代速度，破解传统金融难以触达的难题，为金融消费者提供更数字化、智能化的消费金融服务，为企业的可持续发展夯实基础。

据了解，哈银消费金融的“人工智能金融服务平台”，具有“数字化、跨平台、高扩展、易操作”的特点，针对传统消费金融业务的信贷审核流程，通过该平台可以简化海量高维数据处理流程，在线上就可以高效完成，减少了纸张使用的碳足迹，也减少了相应的人力、时间成本。该平台打破了时间与空间限制，实现了“秒申”“秒批”“秒贷”，较传统业务流程实现80%以上的效率提升。

另外，消费金融业务涉及到大量的个人信息和敏感数据，对消费金融机构的风控能力提出了更高的要求。对此，“人工智能金融服务平台”基于云计算、大数据支持、科学应用多项前沿技术，建立了严格的数字包容性金融业务风险控制模型和反欺诈能力。该平台可有效完成数据加载、存储、标记和预处理，实现模型监控全过程管理，提高建模效率，实现业务灵活适应和快速迭代，为客户提供更好的服务。

截至2023年5月，通过科技赋能实现资产管理2400余亿，普惠金融服务触达4000万余人，科技成果转化方面，输出国家发明专利3项，软件著作权5项。

借助“人工智能金融服务平台”，哈银消金的研发、管理以及数字化风控能力和水平均呈现逐年提升趋势，ESG治理水平不断提高，逐步实现全渠道触达客户、对客户进行全生命周期的高效服务和长期运营，提升用户体验。同时实时洞察客户全链路风险，有效管理信用风险及欺诈风险，提升自营线上线下产品、合作渠道产品、资产输出产品的风险控制能力。
