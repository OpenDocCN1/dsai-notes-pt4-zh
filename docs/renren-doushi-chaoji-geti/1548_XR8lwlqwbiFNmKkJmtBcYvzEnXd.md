ChatGPT和各类大模型的陆续问世，点燃了国内创业者们的激情。

在这一轮大模型热潮中，「人才」成为各大科技公司、创业团队和研究机构激烈抢夺的关键。

然而，目前AIGC领域的尖端人才，仍存在较大缺口。

《新一代人工智能发展规划》提出「强化部署高端人才队伍」，AI尖端人才远远不能满足需求，国内外真正能研发大模型的人才「加起来也就百十号人」。

到底招募什么类型人才，有利于模型研发？去哪里招募大模型研发人才？如何培养大模型核心研发人才？

于是乎，量子位智库 《AIGC大模型人才全景报告》 正式启动，通过报告对大模型人才系列问题作出系统性回答，提供全景式框架认知。

在 《AIGC大模型人才全景报告》 中，我们将基于国内外领先企业的大模型团队配置进行分析，与大家一同分享大模型人才发展的新动向。

报告中将包括：

+ 中国大模型产业全景图
+ 国内外大模型人才团队配置
+ 大模型人才评估模型
+ 大模型人才发展阶段和趋势研判
+ 大模型团队配置案例

现在，量子位智库正式邀请AIGC大模型行业的从业者，关注并参与到 《AIGC大模型人才全景报告》 征集中。一起推动中国AGI和大模型产业更快、更稳、更强发展。

本报告将于 **9月初** 对外发布。量子位后续也会举办围绕大模型人才的沙龙分享活动，感兴趣的企业欢迎联络~
