## 产品概述

[IT之家](https://www.ithome.com/)[8 月](https://www.doubao.com/) 17 日消息，字节跳动旗下 LLM 人工智能机器人 “豆包”现已开始小范围邀请测试，用户可通过手机号、抖音或者 Apple ID 登录。

![](img/06e20a15175ac6dd7d1322fc6ead25f1.png)

据称，“豆包”是字节跳动公司基于云雀模型开发的 AI 工具，提供聊天机器人、写作助[手以及英语学习助手等](https://www.doubao.com/)功能，它可以回答[各种问题并](https://lf9-apk.ugapk.cn/package/apk/nova_ai/17672_1000000/nova_ai_45941475a_v17672_1000000_e4cd_1692102073.apk?v=1692102075)进行对话，帮助人们获取信息，支持 网页 Web 平台，iOS 以及 安卓平台，但 iOS 需要 使用 TestFlight 安装。

![](img/ba10d3f4b71f287ac06bf53b589b27ec.png)
