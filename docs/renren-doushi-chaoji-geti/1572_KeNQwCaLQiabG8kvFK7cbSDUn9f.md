大家都知道，ChatGPT 这种大语言模型在某些特定的问题上，能力比较捉急。其中一方面就是它是一个语言模型，很难去处理数学问题。

比如，我让 ChatGPT 计算一下：

```
8 + 4 =？
```

模型可以给出正确答案：

![](img/db8d152829cff07f5485aa66997e8d14.png)

这样简单的数学计算，换成其它的大语言模型应该都能答对。（要是哪个大语言模型连这个都答不对，那指定是通过做模型来圈钱的）

但是，语言模型的本质上是根据数据关联性，来对后续输出文字做预测。

直白点说，语言模型就是记住了 `8 + 4` 和 `12` 之间的紧密关系。因此可以回答出来。但是毕竟语言模型，即便再大，参数再多，拟合能力再强，也是有上限的。自然数加法无穷无尽，语言模型是记不住的。

比如，我问语言模型：

```
23894 + 987332 等于多少？
```

模型的回答大概率（99.999%）是错误，像 ChatGPT 给出了一个非常接近，但是依然是错误的答案。

![](img/65bba66c2ef90ad378f6748c9143ed23.png)

我拿计算器算了一下，正确答案是 `1011226` ，ChatGPT 仅有一位回答错误。

我换了一下别的语言模型，绝大多数给出的结果（不借助编程插件等等工具），都是错误的。

![](img/770c49560d163746a8007af45e9246e9.png)

当然，这也无可厚非，语言模型的本质决定了这种数学问题是很难解决的，因为它无法穷举完，模型自然也学不完，另外就是，数学是抽象的，从输入到输出结果，单单从 `23894 + 987332` 等于 `1011226` 这二十多个字符来看，前后联系是不紧密的。

## 解决办法

### 一、加入编程语言插件

这种方式，就是把数学问题，转换成了一个编程问题，让编译器或者解释器来操作。

```
请编写 python 代码帮我解决如下问题：
23894 + 987332 等于多少？
```

![](img/8b165f353e2a58681f94f5a2d2979db4.png)

这样一来，拿着python 的计算结果，返回给 ChatGPT，就可以得到正确的结果。

当然，我感觉一些大模型已经具备了这种能力。

![](img/eb0690fbf73681fff60b2cfef3ce5252.png)

虽然从网页上看，没看到调用编程的痕迹，但是从结果上来看，我估计这个厂商大概率是加入了编程插件的。

### 二、让语言模型学会数学法则

数学问题是抽象的，可以说，从输入 `23894 + 987332` 到输出 `1011226` ，中间过程是个黑盒，这一点和语言模型本身就很像。

我们需要利用模型的小样本学习能力，把这个计算过程显式化。就像我们小学时候背 `20` 以内的常用加法 ，以及 加法计算法则 一样，我们默认，一个合格的语言模型，也是满足这样的能力的。

那么，就可以给语言模型定义加法计算规则。

```
请帮我完成一道多个整数相加的加法题。
我将先告诉你加法计算法则，再给你做一个示范，展示出详细计算步骤。

多个整数加法计算法则：
1、如果加法包含多个整数相加，形如 a + b + c + ... + x 的形式，需要先计算 a + b，得到 y，然后计算 y + c，以此类推，最后得到结果。
2、计算两个整数相加，需要先从两个数的个位开始，如果这两个数字的加和小于或等于 9，则直接作为最后结果的个位数字，向十位数进 0；如果两个数字的加和大于 9，则需要向十位数进 1，大于 10 的部分作为个位数字。
3、再次计算两个数字的十位数，如果两个数字的十位数，与前一位进位的数字，三个数字相加，得到的数字小于或等于 9，则直接作为最后结果的个位数字；如果这三个数字的加和大于 9，则需要向百位数进 1，大于 10 的部分作为十位数字。
4、百位、千位、万位数字，以及之后的所有位数的进位方法同十位数。
5、如果在十位、百位、千位、万位，以及之后的任一位数，相加的两个数字都是 0，则加法计算完毕，返回最终结果。
6、如果在十位、百位、千位、万位，以及之后的任一位数，其中一个加数是0，另一个非0，则按照正常的加法计算方法计算即可。

举例计算 15 + 128 + 9。
1、首先拆分上式计算步骤。首先计算 15 + 128，然后计算它们的和 + 9。
2、计算 15 + 128。两数的个位数分别是 5 和 8，两者加和为 13，大于 9，向十位数进一位， 大于 10 的部分为 3，则加和结果的个位数为 3。
3、两个数的十位数分别是 1 和 2，前一位进位为 1，1 + 2 + 1 = 4（此处仍按照加法法则计算，略）。4 小于 9，因此，直接将该数字作为加和结果的十位数，向前一位进 0。
4、两个数的百位数分别是 0 和 1，前一位进位为 0，0 + 1 + 0 = 1（此处仍按照加法法则计算，略）。1 小于 9，因此，直接将该数字作为加和结果的百位数，向前一位进 0。
5、两个数的千位数都是 0，因此，加法计算 15 + 128 完毕，总结排列上面的各位计算结果为 143。
6、然后计算 143 + 9。计算方法同理，略，最终结果为 152。

根据上面的整数加法计算法则，与样例。请写出详细计算步骤，计算：23894 + 987332 + 295 = ？
```

上面这一大段，看起来挺啰嗦的，但是这就是教会大语言模型如何计算加法的法则，中国小学生学习加法计算，都需要按照上面的步骤来完成。

自然语言对这个加法计算法则显式得表达出来，一个具备足够学习模仿能力的语言模型，自然可以将正确结果输出出来。这实际上就是交给大语言模型的一个标准化 `自然数加法计算prompt`模板 。

当然，我试了一下，GPT4可以正确回答出来，但是 ChatGPT 以及其它大语言模型都不能很完整准确的返回正确结果。

![](img/2ad5f753c4421179795da074e348c5cb.png)

![](img/aa2ab29456e3948a257f968e7142359f.png)

从这个结果来看，GPT4 还是非常强大的！！！不仅仅是模型记忆的数据多，更强在对复杂的长文本小样本学习的精确把握上。

## 语言模型能够解决数学问题吗？

我们的例子只举了一个自然数加法的例子，其实数学的加法，涵盖范围就很广，还包括 小数、分数加法，负数加法，带有变量的加法，复数加法 等等。

每一种数域的加法的具体实现方法都有所区别。当然，除了 加法计算 之外，数学涵盖的东西涉及方方面面，方程、矩阵、几何、复数、函数，微积分，以及各种定理和法则等等。

单单一个加法计算，对于中国人来说，简直是易如反掌，家常便饭，但是用自然语言表达出来，都是一篇挺长的 `prompt`，那么，像数学中更加抽象的概念和内容，如果用自然语言描述起来，是非常非常繁杂的。

所以，这就引出了这个问题， 大语言模型，能够真正解决数学问题吗？

这就回到了一个非常根本的问题，语言是一种形象思维，而数学是一种抽象思维。数学中的符号、数字，都是一种形象化的表达，背后的抽象思想是很难用语言表达出来的。本质上，让语言模型去解决数学问题，还是一种模仿行为。

举个例子： `f(x)=x+1` 这样的函数，语言模型可以认识到， `x` 是一个自变量，因为绝大多数时候，人们在处理数学问题的时候，都默认把 `x` 当作自变量未知数。 但是，如果函数中的 `x` 被换做 小狗 ，那么语言模型很有可能发生崩溃，因为它从来没有见过，汉字也可以代表抽象的自变量含义。

除非，我们给语言模型显式地提供教学： `f(.)`括号中的内容，不论是什么，都可以当作自变量未知数 。

### 数学对现实问题的抽象

当然，数学是为了解决现实问题的，我们上述的内容都是利用抽象的符号和数字来描述数学。

如果真正让语言模型采用数学方法解决现实问题，这种从现实到抽象的映射，也是一个复杂的问题。打一个比方就很好理解：

```
给一个三岁小孩展示三个苹果，再拿走一个，提问小孩，还剩几个苹果？
小孩大概率可以正确回答，还剩2个苹果。

但是此时如果问小孩，假设有三个橘子，拿走一个，还剩几个句子？
有一部分小孩是回答不出来还剩几个的。
```

这就是，从具象的现实世界到抽象的映射，存在一个 gap，这个gap，语言模型同样存在，即便语言模型学会了 `3-1=2` ，但是如果没有充足的语料学习，还是回答不了三个橘子的问题。

### 几何空间问题

此外，几何问题涉及空间概念，单纯语言模型是不足的，还需要有图像模型参与。

这个就不用多谈了吧。

所以，利用语言模型，可以从一定程度上解决数学问题，前提就是，充分满足语言模型的特性，提供充足的语言表达，利用语言模型的小样本学习能力。当然，整个过程都是一种模式的学习，而非对本质的理解

### 编程的局限性

此外，编程语言是个好东西，可以和语言模型相辅相成，配合解决数学问题，但是，这里又有一个问题： 不是所有数学问题都能够通过编程来完成。

将某些数学问题（比如定积分、非欧几何推理）转化为编程问题，需要复杂的设计和抽象，这个过程又会陷入到语言模型无法处理抽象逻辑的问题上去。

## 语言模型解决数学推理

除了数学的抽象之外，层层递进式推理也是数学的一个重要特点。

比如，我计算方程问题：

```
x+2323y = 91824
23x - 892y = -1923
```

为了解决这个问题，我们不仅仅需要让语言模型懂得 二元一次方程组的计算法则 ，比如下面这样子的一个 `prompt`：

```
请帮我求解一道二元一次方程组。
我将利用一个示范，给出计算方法。

举例求解方程组：
a + b = 5
a - 2b = 2
计算步骤如下：
1、首先分析该二元一次方程组，其中有两个算式，两个待求解参数，a 和 b，算式中涉及的计算主要是加减法、乘法。
2、观察其中一个参数 a，在两个式子中，a 对应的系数都是 1，是相同的。因此，可以进行两式相减，消除掉参数 a。
3、两式的等号两边分别相减，可得到 (a + b) - (a - 2b) = 5 - 2，根据括号化简法则，合并同类项，可以得到 a + b - a + 2b = 5 - 2 = 3，即 3b = 3。
4、得到化简后的计算公式为 3b = 3，其中只有一个参数 b，其系数为 3。式子两边同时除以 3，即可得到 b = 3/3，化简可得到 b = 1。
5、然后将 b = 1 带入方程组的任何一个式子，例如 a + b = 5 中，可以得到 a + 1 = 5。
6、a + 1 = 5 中只有一个参数 a，其中 a 的系数为 1。对式子两边同时减去 1，合并同类项，即可得到 (a + 1) - 1 = 5 - 1 = 4，化简可得到 a = 4。
7、最后结果为 a = 4，b = 3。
其中，计算步骤中省略了某些加减法计算法则，请根据需要，结合加减法、乘除法计算法则进行计算。

根据二元一次方程组的求解方法，并结合示范样例，求解方程组：
x + 4y - 5 = - 2
2x - y/2 = 1
其中，x = ？，y = ？
```

同时，本文提到的 自然数加法法则，整数加法法则 ，语言模型都需要懂得并很好地应对，这样才能解出未知数来。这就涉及到一个层级处理的问题。

语言模型应当根据当前状态，推断下一步该干什么。

这就涉及到一个数学推理的问题，这里的推理，并不仅仅像平面几何、立体几何那样，根据若干定理和公理，顺其自然地往下推断即可，而是对于每一步计算步骤，都要自发地判断该采用什么数学计算方法解决接下来的问题。

比如，在计算方程、积分、乘法的时候，解题过程中，都需要涉及到加法计算。这种推理问题，和 AutoGPT 里的解决问题的方式非常像。

```
【当前问题】：二元一次方程组计算
【当前状态】：两方程相减，消除系数
【当前手段工具】：编程工具，数学加减法则
【决策】：根据当前状态和工具，判断应当采用数学加减法则来解决消除系数后的方程化简。
【实施】：……
```

这种语言模型替代决策的方式，应用实在太多，可以应用插件，也可以应用中数学问题中，还可以应用在机器人控制中，让语言模型充当机器人的大脑，控制机器人行为决策，真正达到智能。
