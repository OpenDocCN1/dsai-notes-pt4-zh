### **  ****五、开放平台 **

除了可以在网页上使用鱼聪明外，鱼皮本身作为程序员，当然也考虑到了程序员朋友们的需求啦。

所以我们提供了开放平台，让你在程序中使用 AI 助手！

![](img/5bf7c1050a9b87535a8ebb59544ba4e5.png)

只需要使用我们开源的 SDK（工具代码），就能轻轻松松，只用几行代码使用 AI 助手能力！

示例代码如下，可以选择要使用的助手：

```
// 构造请求
DevChatRequest devChatRequest = new DevChatRequest();
devChatRequest.setModelId(1651468516836098050L);
devChatRequest.setMessage(&quot;鱼皮&quot;);

// 获取 AI 助手的回复
BaseResponse&lt;DevChatResponse&gt; response = client.doChat(devChatRequest);
System.out.println(response.getData());
```

由于我们目前人力有限，所以只能先提供 Java SDK，大家如果感兴趣的话，欢迎贡献其他语言的 SDK 哦~

### **  ****我们的优势 **

肯定有同学要问啦，现在网上的 AI 工具那么多，为什么选择用鱼聪明 AI 呢？

如果你是一个有点儿技术、能摸索的同学，你当然可以自己搞 AI 账号、自己用开源项目搭建；当然，这也意味着你要自己维护和承担账号、服务器费用，注意开源项目中的一些漏洞。

但是，使用鱼聪明 AI， 不需要任何的门槛！也不需要自己搞账号！

现在 **试运营期间 **，所有用户每天都可以免费领 50 根鱼毛（可用 50 次对话），而且注册就送 50（可以累积）。我们在后台对内测用户做了数据分析，发现对绝大多数同学来说，每日 50 次足够了。

当**然，我们的系统背**后，也承担了巨量的费用，人力 + 服务器 + AI 服务 + 网安费等等；我们做这款产品，肯定也是 希望能有收益的 ，总不能让公司破产吧。

所以我们也提供了 **会员服务 **，但我们的优势在于：

**1）只有月度会员，不搞年**费！不搞终身！ 你需要用的时候开通即可 。

2）会员的价格 **甚至低于 GPT 官方 **！来算一笔账：19.9 元可以领 3000 根鱼毛，0.006 元每次，一次不足**一分！而使用 OpenAI** GPT 3.5 模型官方平均 0.014 元一次， 我们比官方还便宜 2 倍 ！

**我敢说，这绝对已经**非常良心了，我们现在 每天有上万名用户 ，大家算一算成本就知道了。

目前是试运营阶段，大家感兴趣的话建议赶紧试试，薅一波鱼毛，等后面我们的用户数多了、成本太高的话，我们也可能会调整策略，还请大家理解。
