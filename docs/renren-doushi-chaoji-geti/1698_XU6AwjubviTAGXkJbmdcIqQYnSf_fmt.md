
# ChatGPT与审计创新：跨越数字化鸿沟的关键技术

> 来源：[https://xuqiwei1986.feishu.cn/docx/GFMWdHJnCoDytwxg0Y2cvUcsnag](https://xuqiwei1986.feishu.cn/docx/GFMWdHJnCoDytwxg0Y2cvUcsnag)

大家好，我是航仔，一名国企员工，21年转型做内部审计，在对审计和信息化一窍不通的情况下勇敢地（bei hu you）抗下了部门审计数字化转型的大旗。也正是因为对数字化有一些浅显的研究，在2月份AI绘画与ChatGPT航海开船的时候，义无反顾的报了名。随着航海的深入，越来越觉得ChatGPT这玩意儿真香，每天都花大量的时间学习、实践、总结。下面对近几个月的学习做一个复盘总结。

## 一、第一份ChatGPT作业

4月份的时候，写了一篇感想[审计师轻松玩转ChatGPT](https://cufj3zjdqv.feishu.cn/docx/GwzTd0RUYo2bvrxXWayc62l7ned)，让ChatGPT帮我总结了这个工具在审计领域的应用场景，并在赚钱里交了作业。写的时候手里没数据，就让ChatGPT帮我编一些数据，然后再反手把这些数据扔给它，让它帮我分析总结。那次算是ChatGPT在工作中的初体验，比较务虚。

## 二、制定被审计单位考核机制

有一天，领导让我们针对被审计单位在审计项目中的配合、沟通、整改等方面制定一个考核机制，当时我们都挺发愁的，因为大家脑子不够用，百度也搜不到，同行又不肯借给我们抄作业，憋了半天几个人憋出来5条，但都很勉强，根本拿不出手。突然想到ChatGPT，马上上手调教。

![](img/99607f387c5e7693920df32c072ccd45.png)

不到2分钟，这家伙给我列了30条出来，我把这些内容复制到Excel表中，筛选出其中15条，然后再丢给ChatGPT，让它帮我优化

![](img/9a209d4fe1b94d6d2a5a5d724ed0d9f5.png)

![](img/c6f5ad07905f073fdc59c2301a46d7fb.png)

![](img/e071af758ea590ded526c6fee5a75ca2.png)

经过反复几轮的优化调整，最终成型了一篇比较完整的《被审计单位考核指标表》，随后根据它的建议，还制定了奖惩机制、评估机制、反馈机制、考核结果应用机制等内容，算是形成了一份相对之前较为完整的考核机制。（不过领导没催，就还没交作业，怕写作业太快了，会一直被薅羊毛，哈哈）

## 三、帮领导写《党建引领 转型提升》心得体会

今年是“党建引领 转型提升”年，集团前前后后布置了好多作业，其中有一份作业是让中层领导写心得，围绕“三个意识（即危机意识、市场意识、发展意识”与“价值创造”写一份心得。作为领导的笔杆子，我当仁不让地主动接手了这份作业。之前写党建方面的材料，绝对要抓耳挠腮哼哧哼哧写两天，再让领导改个五六回合才能交差。这次就不一样了，10分钟让ChatGPT帮我写完交稿，领导看完大加赞赏，一遍通过！以下是我的调教过程。

![](img/06c03dab5bb9e548cbdc5171b2455e34.png)

莫名其妙写了“翻译”两个字，怪不得这家伙后面一直在给我翻译，让我纳闷儿了半天。。。

![](img/0ace30a0312ba1fdfb23b0c31b95474e.png)

喂完材料，ChatGPT立马给我写了一份研讨方案，根据这个方案我马上发出一个会议通知，让部门成员按照此方案参加会议并对“三个意识”和“价值创造”展开研讨。随后我又让ChatGPT帮我写一份心得。

随着调教的深入，ChatGPT在10分钟之后交给了我一份相对不错的答卷，我稍微修修改改之后打印给领导看，一遍通过。我心里惊呼“这也太TM牛逼了吧！”

## 四、编写被调研材料

现在ChatGPT已经成为了我日常办公的必备工具，在提质增效方面是真的棒，这里也感谢刀姐风向标探索家Club中的各位大佬，每天都在无私分享各种知识，作为潜水运动员，每天爬楼学习就是一种幸福（憨笑脸）。
