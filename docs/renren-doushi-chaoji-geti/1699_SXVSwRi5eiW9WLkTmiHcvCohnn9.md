# 玩赚chatGPT的交付手册都看不懂，我是如何硬卖训练营赚到钱

> 来源：[https://xuqiwei1986.feishu.cn/docx/TNpydTF9qowGTbxy1JEcMAUDnEW](https://xuqiwei1986.feishu.cn/docx/TNpydTF9qowGTbxy1JEcMAUDnEW)

大家好，我是阿黛，刚加入生财的萌新。

今年2月，成为黄小刀同学玩赚chatGPT训练营第一期学员，说起学员这个身份，我多多少少有点心虚，因为在训练营，甚至后来我还做了某一期的志愿者，但其实我并没有学会如何注册什么的基本功，我是有天直接跑到刀姐她们办公室玩儿，让石头教练直接装到我手机上的。

感谢你，石头教练。

刀姐是了解我的，玩赚chatGPT训练营刚开放，她在群里看见我就说，我怀疑你都看不懂我们的交付手册。这是真的，我真的看不懂，之前我一直做的传统行业，做地产开发营销管理十多年，后来自己创业，业务也是广告策略销售顾问相关，妥妥互联网小白一枚，所以我就直接跳到变现那一阶段了。

其实我的成绩在我们分销团队完全说不上嘴，很多人的收益至少都是万元以上，甚至有的一天都是万元。

但我自己对这个成绩，还挺满意，因为我面向的客户群体，都跟我一样身处传统行业已久，对互联网没那么敏锐，也会认为前沿科技跟自己没什么相关，在这样的基本盘下，加上我自己也不懂，挖掘出这些需求，也算说得过去。

但是接到刀姐团队的邀请让我分享，还是挺意外的，同时也有点点窃喜，在普通人里，成绩也许真的还算过得去？所以我也把内容同步到这里，希望能鼓励到和我一样的互联网小白。

随手赚并不需要多么高深的能力，有手，敢下场，就能拿到结果。

![](img/3997519d9dd6af03d4e431a3f8b05c34.png)

一．我怎么敢在不了解的状况下做出推荐

我跟刀姐做网友多年，我知道她的筐里没有烂杏，出品值得信赖；我也不是什么产品都卖谁的产品都推。

去年十月我加了她的无人直播群，很快她就发现，依我这样的智商，别说上手操作，就连理解都很困难。

于是12月份，chatGPT在国内刮那阵小风的时候，她们团队就将它和百度问答结合起来，做了个项目给我们玩儿，交付很详尽，那会儿卖这个我就已经赚了一波，还有小伙伴通过这个引流2000多人，变现50万。

所以我就知道这会是个大项目，自己不懂不要紧，风这么大的时候当然要抱大腿薅羊毛了。第一时间自己买一个，也第一时间加入分销团队。

我是什么也没弄懂，但销售这件事就是得快快跑，有时候慢了连汤都喝不着。比如，我现在是会了一点点，但我这个时候才开始卖的话客户早被别人抢完了。

江湖武功，唯快不破，认准的事别犹疑，直接下场就是。有什么问题在过程中去解决去优化。

**二．我是通过什么渠道卖出去的**

我主要是通过微信，微博和公众号是辅助。

两个微信号，加起来可能3000人，且重复的多，还有一些是村子里的老乡，公众号是我练习手感的作业本，粉丝不足千人，微博多一点，粉丝2万人，但就活跃程度来看，我怀疑很多根本是僵尸粉。情况就是这么个情况。

前面也有说过我微信成员的基本盘，但里面也不乏有文案、策略、品牌相关的从业人员，他们对新事物天然敏感一些，这应该是第一波直接成交的。

微博和公众号持续时间久一些，在转换对接平台之后，我偶然进去，第一个平台还有成交的订单，那会儿我朋友圈已经更换链接，所以就只会是公众号和微博看到产生的成交。

**三．有什么技巧**

**1.微博**

学会蹭热点

特别是热搜标签，加一个曝光量增加几十倍，曝光量高成交量才高。比如这个，那天我发现有个热搜#香港大学宣布禁用ChatGPT#

于是马上点进去，写自己的观点：

就跟强盗已经来了，出个命令赶紧关门闭眼一样，假装不存在吗？然后单方面宣布获胜？我觉得在力所能及之下，去尝试一下，哪怕尝尝鲜也是很好的。至少不会对 ChatGPT 感到特别的陌生，就像早些年，用的都是翻盖手机，谁能想象得到，苹果推出了智能手机后，世界会变化如此之巨大呢？学会使用它，熟练运用，提升自己的工作效率没什么不好的。

于是一条微博就产生了2万多次的浏览。

这个就要求及时性了。过了时效就会错过流量。

![](img/f18c671f0b5a2d00e0335b0327c7ff6a.png)

然后就是加入超话，相当是已经筛选过的兴趣小组，都是有需求的精准流量，每条chatGPT相关都加上超话，就会有关注。

**2.微信**

朋友圈仍然是主要成交阵地。私域里的成交，信任是第一基础，虽然我自己玩不明白这个东西，但我知道这是个好东西。

从2015年我开始销售家乡腊肉开始，也让大家知道了，我筐里没烂杏，所以有需要的话首选我成交。

这个是我长期经营的好处。腊肉连续销售八年，品质始终如一；微信运动推出之前，连续几年的每天一万步，风雪无阻；公号每周写一篇，持续了八十几周….诸如此类的记录，让我整个人看起来就是靠谱的。

我没有自己的体验过程，所以在分享的时候，我一直很谨慎：

我没有为了成交故意制造焦虑，只是平实的描述运用场景，在对照之下，有需要的人就会知道是不是适用于自己。

我没有为了成交夸大交付内容，没有过分承诺，一直就是实事求是的说明这是个什么产品，训练营有哪些内容。

而且光说你在用什么做什么什么的其实也不够，关键是写明白学这个能解决他的什么问题。

也仅限于朋友圈分享，从不私发信息打扰，因为说的够清楚，所以我基本没有售前，也没有售后。除了几个因为小助理挂了之后没人拉他们进群，跟我确认。

没人和我说话，就是默默下单，我打开手机就能看见佣金丝滑入账，还是很爽的。

![](img/45322da87efef1052e2d544255f48310.png)

关于朋友圈的内容，可能很多人没有意识到我们拥有一个多么大的素材库，我们知识星球的chatGPT风向标，每天都有最前沿的咨询，最新鲜的玩法。我会挑出来一些容易理解的、有用有趣的，自己再组织语言结合训练营写。

另外，我还会在微博上截取一些行业相关的权威媒体报道，比如，财经网报道的：

中国知名4A广告公司，蓝色光标，发邮件要求全面停止创意设计、方案撰写、文案撰写、短期雇员四类相关外包，全面拥抱AI。

相关从业人员看见，自然会产生紧迫感。

![](img/18d21226085664f1f24b4bcc087fb658.png)

后来刀姐的新书京东霸榜之后，又可以借力打力，这是社群实力的强佐证，加上组合优惠，也能促进成交。

当然还有我个人，虽然没有体验的过程，但有参与的过程，比如在100多人里意外的中选志愿者，还有付费让人给我生成荒野餐桌的海报等。

![](img/d23a03d559e6d694153f5f6039623b6c.png)

**另外，朋友圈更新要保持频率。**

不能想起来了发一条，然后几天不更新。销售是需要持续发力的，哪怕中途成交量没有那么高，心态也要稳，依旧坚持更新，训练营每周日开营，那么周四开始，我就会格外勤快一点。

直到现在，除了找我下过单的人，以及通过训练营和生财链接进来的人，其他的人虽然都还是没什么反应，但通过我这几个月的强势推广，已经有了记忆植入，哪怕后来频次减少，有一天他发现自己还是需要的，就会想到我在做这个。

**不想朋友圈含广量那么高怎么办？**

很简单，发送新的删除旧的，除非是自己特喜欢或者转化率特高的保留；

间隔40分钟以上，就很少会有人发现你在刷屏；

形式多样化一些，有时候只发图，链接放评论区，

这样也能避免内容折叠。

![](img/8c4372b0c3fdbe43fc654408fc75f1c4.png)

**3.公众号**

我的公众号是当博客写的，纯练手的作业本，粉丝虽然不多，但应该爱看我写的东西，所以在公众号的推介，硬广少，就一篇，其他的都是软文，结合了自己的一些事情。

![](img/0e60a8f21c33f21942f89237a0164453.png)

**四．后续计划**

很多伙伴可能有自己的主业，分销一段时间之后就会回归，但我作为一个刚下场的互联网小白，兴致勃勃的，还只是个开始，后续有机会的话，会给出更多的商业场景，用AI写文章画画、算命分享好物写情书什么的，以期获得B端客户，如果获得订单，就跑到刀姐探索家俱乐部那里摇人成交，我继续中间商赚差价。

![](img/83fbf809025c13eb319f21a8b9379036.png)

以上，就是我毫无保留、所有的分销心得了。希望对大家能有一些启发，我们一起有玩有赚。
