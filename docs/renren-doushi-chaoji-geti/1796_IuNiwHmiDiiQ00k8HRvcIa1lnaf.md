# 三、结构化 Prompt 介绍

接触编程已经有十几年的时间，不过在用 ChatGPT 几个月还是一直在写常规的Prompt。直到前不久看到星球有同学在分享结果化 Prompt 的内容，才开始尝试，结果发现效果非常棒。

所谓的结构化 Prompt 其实是一种有特定结构的指令形式，通常以特定的格式或模型为基础，用于与 ChatGPT 等AI 模型进行交互。它像是一个给 AI 模型一个明确的任务说明，以便 AI 模型能够更好地理解我们的问题并生成有针对性的回复。

## Role

你是一个odoo开发专家

## Description

请帮我设计一个odoo模块，用来记录每日的工程进度汇报。记录的内容包括：项目、日期、计划量、搭建量、确认量，搭建率、确认率

上面是一个简单的结构化 Prompt 的例子，如果我们只是输入"生成一个 Odoo 模块”，AI其实很难理解我们到底想要什么，可能是要进销存的模块又或者是财务管理模块。而结构化 Prompt 则可以提供了更清晰的指令，让ChatGPT 等能够更准确地理解我们自己的意图，从而生成更符合我们需求的答复。

# 四、结构化 Prompt 的优势有哪些？

无论是 ChatGPT 辅助编程，还是 ChatGPT 辅助写作，优化者是 MidJourney 生成绘画，我都建议大家尽量使用结构化 Prompt。总括来说，结构化 Prompt 对比常规 Prompt 来说有以下优势。

## 一）为 AI 提供更明确的指令

自然语言编写 Prompt 虽然简单易上手，但是研究发现文字传递信息的效率只有 30%，剩下的 70% 是通过我们的环境和肢体语言进行获取。其实跟 AI 交流也是同样道理。如果你只是通过文字交流，而不提供结构化的信息，AI 很难预估到你的需要，所以有时会泛泛而谈甚至产生错误的回答。

## 二）节省时间减少多轮问答

前面提到向 AI 提开发性问题时，AI 很难理解我们的真实诉求，为了得到我们想要的回复，我们总是需要对 AI 的结果进行多轮修正。借助结果化的 Prompt，我们可以制定 AI 扮演的角色，可以设定角色的技能，回答的规制，从而让 AI 能够在一开始就明确你想要的结果。

## 三）易于上手，降低学习曲线

写 Prompt 其实跟写文章有点类似，如果没有框架，我想很多人跟我一样半天都写不出一段话出来。结构化 Prompt 就是我们写指令的框架，他能够帮助我们思考，并使我们即时不熟悉技术领域和专业术语，也能帮助我们写出高效的提示词。所以结构化 Prompt 是一种更加友好的与 AI 交流的方式。

## 四）适应多种业务情景

无论是写作、编程、设计或其他领域，结构化Prompt都能够帮助你更好地与机器合作，而无需成为领域的专家。

总的来说，使用结构化 Prompt 可以让你与 AI 的交流更高效、更精确，尤其适合不熟悉技术细节的用户，帮助他们更好地利用机器的能力。

# 五、ChatGPT 辅助编程实操教学

介绍完结构化 Prompt，接下来讲解一下实操如何生成和使用结构化 Prompt。我这个月通过这个指令生成了两个模块：工程进度汇报和工程成本单管理。效果还不错。

## 一）教学背景

我自去年 8 月加入现在的公司，加入前是某乙方开发公司的项目经理兼产品经理。在乙方时有开发部负责编码实现，而现在的公司 IT 部才 2 个人，写需求、撸代码，全都要负责。如果 ChatGPT 能辅助编程，能减轻不少日常工作。

## 二）实践需求

1、根据需求能够返回 Odoo14 代码

2、代码文件要符合 Odoo14 的规范和格式

3、生成的代码要能够在 Odoo14 中正常安装

4、生成的代码在 Odoo14 安装后能正常运行

## 三）操作步骤

### 1、选定结构化 Prompt 模板

这里我直接搬运飞机 Fit 同学的，因为想不到更好的框架，而且先阶段最重要的是先尝试实操，后面可以根据实际需要再调整。

#### Role //定义角色

#### Profile //给这个 Prompt 做一些注释说明

#### Background //角色的背景信息（自我介绍）

#### Skills //角色的技能

#### Goals //角色的目标

#### Constrains //角色的限制条件

#### Workflow //角色的工作流

#### Example //范例

#### Initialization //初始化，即第一次对话应当回复的内容

### 2、编写：角色、背景

#### Role

- 一名拥有20年ERP系统开发经验的 Odoo14 专家。

#### Profile

- `autor`: 吕铭根

- `version`: 1.0

- `language`: 中文

- `description`: 一名专业、经验丰富的 odoo14 专家，精通 Odoo14 的前端开发和后端开发，可以帮助用户返回特定需求的 Odoo14 代码。

#### Background

你是一名资深的 Odoo 开发专家，你在 Odoo 领域拥有多年的丰富经验，擅长使用 Odoo 平台为企业提供定制化的解决方案。你的公司专注于开发和实践 Odoo 系统，帮助客户优化他们的业务流程，提高效率并减低成本。

如果觉得背景（ `Background` ）不知道怎么写，这里有个取巧的方式就是直接问题 ChatGPT。首先，你要先让 ChatGPT 扮演角色：如我想你扮演一名 Odoo 14 的开发专家。然后，让 ChatGPT 介绍自己的背景：我要向客户介绍你的信息，我应该如何描述你的背景。

### 3、编写：技能

#### Skills

- 在odoo模块定制、界面设计，业务流程优化等方面拥有广泛的技能和专业能力。

- 熟悉个个版本的odoo，并能够根据客户需求进行定制化开发，确保系统完美地适配业务需求。

- 具备丰富的数据库管理和集成经验，能够将Odoo与其他系统进行无缝链接，实现全面业务整合。

- 能够为用户提供高效、可靠的odoo解决方案。

### 4、编写：目标、约束

#### Goals

- 探寻用户的实际需求

- 对用户的需求进行分析

- 完成模块的需求方案制定

- 基于 odoo14 的编码规范返回对应的 odoo 模块代码

#### Constrains

- 严格按照遵循[Workflow]流程进行对话。

- 不要解析odoo。

- 不要向用户介绍你的工作流程。

- 执行下一步前记得要跟用户进行确认

- -1. 跟用户确认你理解的需求是否与用户要想的一致。

- -2. 跟用户确认是否要生成代码，得到回复后才正式返回代码

- 按照 odoo14 的文件结构`{{Framework}}`返回代码

- 如果用户不要求返回某个文件，则每次都返回所有文件的代码

### 5、编写：代码文件结构

#### Framework

1. `__init__ .py`

2. `model _{name}.py`

3. `view_ {name}.xml`

4. `controller _{name}.py`

5. `ir.model.access.csv`

6. `demo_ data.xml`

7. `__init__ .py`

8. `__manifest__ .py`

### 6、编写：工作流程及初始化

#### Workflow

1.通过与用户对话了解用户的业务需求和目标。

2.如果用户的需求不明确，引导用户提供更详细的需求信息。

3.询问客户有没有其他信息需要补充。

4.发送你的分析方案，询问客户是否有其他补充。

5.询问客户是否可以生成代码。

6.如果客户同意生成代码，则向用户返回代码结果。

#### Example //范例

#### Initialization

简单介绍自己，然后回复“请问你的需求是什么”，不要解析 odoo，不要输出角色定义里面的内容，当用户提出具体的需求后，然后严格遵循 [Workflow] 的流程进行最后输出。

# 七、小结

经过反复调试，目前该指令接入 ChatGPT3.5 已经基本能满足日常的 odoo 编码需求。以前需要培养 3-6 个月的开发，现在 ChatGPT 都能搞掂：

一方面是因为 Odoo 原生模块的封装程度已经很高，不需要重复造轮子。

二方面是因为当前的开发需求相对固定，大多集中在表单创建与上下游单据转换方面。

最后就我对 ChatGPT 辅助编程的定位是代码生成器，只要我的需求描述足够详细， ChatGPT 就能根据我的描述返回我想要的代码。

如果要把该指令进一步推广，我想还需要优化以下地方：

1.目前的需求问答只有一轮，不知道如何实现多轮问答。

2.目前需求确认返回的是文字，如果能够输出结构化的文档更有助于用户理解。

3.目前生成单个模型的代码结果会比较理想，如果涉及其他模型的调用，不知道如何训练。

这些优化点也不是完全没有解决方法，例如可以尝试：

为了解决需求，可以再生成代码前先用另一个结构化 Prompt 输出需求。我自己经过测试如果提交结构化需求时 ChatGPT 不会再问我问题，而常规的 Prompt 就会有多一轮的问答。

其次，可以在推理能力更强的 ChatGPT4.0 上跑模型。本质上需求和代码也是一项逻辑推理的工作。

最后，为了让 ChatGPT 同步获得 Odoo 新版本的能力，也可以把官方的开发手册进行模型训练。

总的来说，利用 ChatGPT 进行辅助编程已经不再是梦想，目前针对标准化的开发流程已经可以替代初级的程序员。但如果我们想 ChatGPT 承担更多的开发工作，可以尝试接入更先进的模型，或者进行范例训练。

最后让我们一起期待 AI 的发展，也期望新版本的辅助编程结构化 Prompt 。谢谢大家。
