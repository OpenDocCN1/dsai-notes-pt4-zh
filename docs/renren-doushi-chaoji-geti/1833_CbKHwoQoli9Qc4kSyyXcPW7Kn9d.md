# 四、lora的安装与使用

因为头疼配置，直接选择青椒云，然后在选择朱尼酱大佬直接打包好的镜像。

青椒云链接：`https://www.qingjiaocloud.com/`

![](img/fbbb0e731f6aafbce7e036812b46beba.png)

## 1、素材准备

这里需要强调一下，训练集非常非常重要！

这是模型的学习材料，直接关系你的lora能不能成功，泛化性好不好。

### 1）照片准备

a、20-30张；

b、高清晰度；

c、多角度(尽量不要重复）

中景、近景、远景；上下左右，更多更充分、更丰富的数据；

d、背景、妆容、服装尽量简单：

我第一次用了出去玩的写真，练了4个多小时都没出来；

e、瑕疵处理：

有些比较明显的瑕疵且不想输入给模型的，比如肤色太暗、痘痘啥的可以微p。

但是不要美颜过度，会影响模型效果。

### 2）tag打标

正确的、丰富的tag非常重要，把你的特征转成文字、数据并正确学习的重要一步！

**可以按照这个模板进行打标：**

主题（人物`1boy1girl`、触发词）；

主要的人物特征（发色）；

动作、视角、光影效果、其他。

另外，想要保留的特征就不要放到tag里，比如你希望发色永远不变，是你自带的一个特征，就不需要标注。

Tag检验：原tag生成图片的时候越像tag打得越好。

### 3）上传

用网盘把自己的照片传到云，这里我用的是夸克网盘

## 3、选模型，确定权重

我这里出来了10个模型，而且要确定每个在0-1内哪个权重更合适，所以建坐标系，横纵坐标一个是模型，一个是10个权重，选最合适的那个。

### 调整模型位置

因为后续选择lora和用坐标系处理的时候需要改lora的位置，这里我们提前准备好。

1、把练好的10个lora模型复制到SD的lora文档里；

2、用xyz插件的时候需要把10个lora放到x轴对比，这里需要把lora复制到扩展模型文档里。

![](img/1dcfe89f523cf630f2ad4e324a8d30f6.png)

![](img/35c7dd2ae8bd184f0dcd46d2348bf729.png)

### xyz轴调整

这里用到的功能是扩展模型：先启用，再选择10个模型中的任意一个：

x轴选"模型"，在右边的下拉框中选中这10个模型；

y轴选"模型权重"，在右边的框中填写权重“0.1,0.2,0.3,.04,0.5,0.6,0.7,0.8,0.9,1”

![](img/26509a87f493d4edf2990c9e7a860081.png)

![](img/e97ef8416ee1889b45abd572d42053d8.png)

点击“生成”，图片大概是这样，然后选择比较像、脸没有崩的模型和权重就可以了。

![](img/c1d3daf830de9af9a7680586d9f48810.png)

## 4、泛化性测试

选中lora，在模型上，**不一定要选底膜(训练时的模型)**，有点玄学，多测试下同一类型的，看哪个表现好就用哪个。

可以用一个其他发色测试一下，我整了个粉色头发，效果还不错，基本就可以用啦~

整个过程自己手动调整参数，直接用的大佬的服务器，所以炼丹过程其实差不多，我练了几次，效果和输入的图片相关性比较大，建议大家在炼丹前好好处理下图片。
