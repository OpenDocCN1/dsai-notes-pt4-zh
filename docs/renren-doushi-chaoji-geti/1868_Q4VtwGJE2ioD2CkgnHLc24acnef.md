## 前言与准备

大家好，我是 C 妹，两颗 AI 之心获得者。好久没在破局出现了，小林批评 C 妹，在破局收获那么多，就要多在破局输出，多提供价值，不要怕写得不好，输出了，能帮到一个人就是有价值的。

所以今天 C 妹就来写一个 0 基础新手用 SD 完成头像的教程，教程涉及到的 AI 绘画网站是免费的，想体验 AI 绘画的小伙伴可以放心使用。

这里介绍一个宝藏网址：liblib，是国内的一个原创 AI 模型网站，现在这个网站已经支持在线使用 SD 画图，点这个链接就可以画，每天都有免费的额度画图：`https://www.liblib.art/sd`。

在 lib 首页搜索麦橘，找到麦橘写实，点击后会进入大模型详情页。

![](img/ce848ad9a0abde1fa5e0af400d42fd51.png)

往下拉有很多作者的模型使用建议，咱们听劝，按着作者写的来就行。

![](img/0d5d75bda8e0f76e333fe42ce2c30dd8.png)

点击右边的【立即生图】按钮，直接进入 lib 的在线 SD 生图页面，且大模型自动切换成麦橘写实了。

![](img/35a1da4079e1e28f1b14dd7da26f3478.png)

## 在线生图配置

接下来是 SD 页面的一些参数配置，可以就按照我这个来，提示词可以先单描述自己想做的图。

![](img/a732da19e882fe344f86b72c8ded89d4.png)

![](img/34aa6b28f33762c12bbb8ed2e86904a3.png)

Controlnet 要选一下，上传自己的任意照片。其余配置按照 C 妹的来即可。

![](img/f279eacb936f1ad21c0d73b8b13864e8.png)

都选择完以后，点击右上角的生成，等待生成就好。

![](img/9c03fa2d29664b09e8699a54946ad2e4.png)

最后我们可以看一下用大模型作者推荐的采样器，restart 和 Euler 生成的图分别是啥样的。

![](img/98a619bcf671fd40acd2e64ba9436df0.png)

![](img/8b1fdf46a2af1aaa1ade901cb2c80e7e.png)

可以看到，在没有叠加任何 lora 的情况下，生成的图和原图很相似。这就是麦橘写实大模型的魅力。下面我们随便加个 lora 试试看。比如这个皮克斯少女的 lora，注意看详情页里作者推荐的一些参数，然后点击右边的加入模型库，可以把这个 lora 添加进 SD 在线生图的页面里，方便选择。

![](img/6a5a692cf202fdcb6df9b07d5a44a0de.png)

加入后我们回到刚才的在线成图页面，找到 lora，选择皮克斯少女，选择之后不需要在提示词里加 lora 触发词了。

![](img/f8a4d13237074046c1a9ee7d32640200.png)

然后按 lora 详情页作者推荐的参数配置，把正负向提示词粘贴进去，改一下参数，点击生图。

![](img/4348c051b0dea72aae2ca4f7cea97e2f.png)

看一下最后的成图效果。

![](img/513c3fe9cec988fdd148c84165a6cce2.png)

## 学习建议与结尾

到这里，大家就走完 SD 的成图流程了，是不是很简单，很有意思。也恭喜你，成为了一个初级 AI 画师。

不要担心页面上那么多生词看不懂，你就尽管去改配置，改参数，先多做几张图看看。玩累了就休息一会，想深入学习的时候再去搜资料看。

让兴趣驱动自己去学习，就是最好的学习方式（推荐 B 站 Nenly 同学的教程，讲解 SD 讲得很细）。
