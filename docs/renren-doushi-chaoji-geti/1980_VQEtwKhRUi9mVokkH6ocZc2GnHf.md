## **赛事题目**

# **—**

**📝 A****I 效率工具**

通过大模型优化日常工作场景或企业生产场景，将AI嵌入到工作环节之中，使得人效较低的工作流环节通过AI赋能的方式得到升级，以此探索AI原生工作能力的场景未来。举例：

+   **Case 1 **: 基于产品维修和使用手册的知识问答，基于原始文档，构建问答功能，回答范围仅限于原始文档，即回答内容仅能够通过原始文档提取、总结、推理得出，不允许使用文档以外的知识回答

+   **Case 2 **: 通过将大语言模型的逻辑能力与互联网、文档等外部工具相结合，构建智慧搜索应用、智慧文档应用、智慧表格应用等智慧应用场景，通过自然语言操作逻辑改变人类使用工具的方式，降低办公门槛

**📝 A****I 社交助手**

利用大模型的语言和理解能力，深度理解并解决现如今社交模式中的痛点和潜在需求，利用AI构建新时代AI原生的社交场景和基础设施。举例：

+   **Case 1: **通过提示词工程或微调的方式构建千人千面的聊天机器人，生成拥有固定语言风格的聊天机器人，如特朗普风格，文言文风格，武侠小说风格等，或构建属于个人独特个性的机器人人格

+   **Case 2 : **将大语言模型的逻辑能力应用于日常工作交流之中，以模型的语言能力赋能个人能力，从而提高自然人同一时间内与外界交流的能力上限，赋能个人社交场景

**📝 A****I 智慧教育**

利用大模型的学习能力和逻辑能力，赋能个人成长和自我教育的应用场景，使AI带来的创新赋能个人或群体的智能成长。举例：

+   **Case 1 : **高校介绍和专业报考推荐系统，基于原始文档，构建高效介绍和报考推荐功能，高校介绍和推荐仅限于原始文档，即回答内容仅能够通过原始文档提取、总结、推理得出，不允许使用文档以外的知识回答，能够通过对话功能了解报考需求和进行相应推荐

+   **Case 2 : **少儿教育助教机器人，针对某个学习教育，提供助教机器人，包含基础的学科类问答功能

+

**📝 其****他创意**

+   面向未来场景的、可基于大模型实现的应用都值得鼓励，AI如何赋能人类未来值得被重新探寻与定义，欢迎任何超越以上三个场景的创意参与。
