## 大赛介绍

### 百度“文心杯”创业大赛

+   大模型浪潮席卷全球，技术代际变革引领的新时代即将来临。百度作为拥有全栈AI技术的领先科技公司，长期深耕大模型研发，具备中文领域最先进的自然语言处理能力。百度已率先开启新一代大语言模型“文心一言”内测，引发各行各业的广泛关注。

+   这趟通往星辰大海的AI征途不只有百度独行，无数充满潜力的创业萌芽也在落地生根。我们希望百度积淀多年的AI大模型技术为创业者奠定坚实基座，与创业者共创、共建，共同打造开放繁荣的AI大模型生态。

+   立足新时代的起点，百度诚挚邀请创业者参与百度“文心杯”创业大赛。在这里，我们助力创业者挖掘行业的创新潜力，打造优秀的产品服务，构建卓越的用户体验。这里是我们和创业者共同成就梦想的起点，是创新活力汇聚的中心，是创业成长爆发的平台。

### 参加大赛能够 收获什么？

+   大赛获奖团队将赢取丰厚的资金与资源支持：

+   一等奖： 1,000万元 早期投资（现金+资源）

+   二等奖： 500万元 早期投资（现金+资源）

+   三等奖： 200万元 早期投资（现金+资源）

+   此外，获奖团队还有机会获得一系列创业加速扶持：

+   与多家顶级基金的资深投资人面对面交流

+   专属大模型技术指导，与百度AI大咖深度交流机会

+   媒体宣传与曝光，扩大市场声量与影响力

+   获奖者结成“校友群”，收获创业路上的可靠伙伴

### 我们期待什么样的 参赛者？

+   我们对早期创业者敞开大门：不限背景，不论AI技术及产品先锋、连续创业者、高校学生，不论即将创业还是已踏上创业之路……

+   只要您对AIGC/大模型技术充满创业理想，有意愿且有能力基于百度文心大模型构建应用，我们都欢迎您的报名。

## 参赛须知

*参赛者在报名前请确保已经阅读并且愿意遵守以下比赛规则，如有任何违反比赛规则的操作，主办方有权取消参赛资格

### 报名规则

+   每名参赛者（团队参赛视为一名参赛者）在项目报名阶段仅可以提交一份创业项目参赛申请，不能提交两份及以上的申请。

+   参赛者提供的信息需真实、有效、合法，提交的创业项目资料、产品demo必须为参赛者原创，不得抄袭、盗用他人作品，也不得由团队外的人员（以参赛报名时提交的团队信息、或公司主体已签署劳动合同的人员为准）代为撰写或开发。

+   在进入demo开发环节前，参赛者有权随时退出，但必须向以下邮箱发出正式退赛申请：aigcsupport@baidu.com。

+   如项目通过筛选进入demo环节，必须现场参与路演日和项目终评，不支持远程。路演日将在位于北京的百度总部举办。

+   参与面试和现场路演的成员需为创始人本人或核心成员，且在本次比赛后继续担任该创业项目的负责人/核心高管。

### 声明

+   因不可抗力或其他原因，主办方将有权合理调整赛事进程，具体通知将通过本网站即时发布。在符合法律法规要求的范围内，百度拥有对本次“文心杯”创业大赛规则的解释权。

+   未经百度的事先书面许可，参赛者不得向任何第三方披露基于参赛所获取的来自百度的保密信息，也不得擅自基于本次比赛以百度名义进行任何的对外宣传。

## 参赛者问答

### 参赛报名有门槛要求吗？

+   我们欢迎所有创业者参赛，不设置硬性资格门槛。但受限于大赛评审流程，参赛者需有能力及意愿基于文心大模型搭建应用，或将文心大模型与已推出的产品结合。请注意，任何通过创业团队以外的人员代为开发demo的行为将被视作违反比赛规则，主办方有权取消参赛资格。

### 创业方向有限制吗？

+   只要与AIGC/大模型相关的创业方向均可报名参赛。参赛者所选方向的市场前景、以及AI大模型在相关场景下的增量价值，将作为大赛评审维度之一。

### 团队规模有限制吗？

+   团队规模不限，可以1人参赛，也可以多人参赛。

### 报名参赛收费吗？

+   本次比赛报名不收取任何费用。请警惕任何以本次比赛名义向参赛者收取报名费用的个人或机构，如有信息可以向aigcsupport@baidu.com反映举报。

### 逾期申请是否会受理？

+   请务必在2023年6月25日24:00前提交参赛申请，逾期申请无法被受理。

### 如何确认报名状态？

+   报名成功后，报名页面将会有“提交信息成功”的提示。如需修改或补充报名信息，请向aigcsupport@baidu.com发送邮件。

### 评审规则会从哪些维度制定？

+   本次大赛将邀请百度业务大咖与AI资深技术专家、顶级基金投资人联合评审，从团队潜力、产品及技术的竞争力与创新性、商业模式前景及可行性等不同维度对参赛项目进行评审选拔。

### 如何快速上手demo开发？

+   我们将提供 [《大模型应用开发技巧与实战》 ](https://aistudio.baidu.com/aistudio/course/introduce/28611)与 《基于大模型的优质Prompt开发课》 课程资源，了解大模型技术原理，上手模型微调和应用开发实战，释放大模型强大生成能力。

### 参赛期间涉及demo开发的费用 谁来承担？

+   Demo开发环节，百度将开放文心大模型相关能力并提供百度智能云的算力资源（但参赛者应遵守与接口调用、算力资源相关的使用规则，以及经参赛者确认的相关协议要求），基于本次比赛使用的上述百度资源不收取费用，其余demo开发成本由参赛者自行承担。

### 是否有其他参加本次大赛的“快速 通道”？

+   大赛官网为本次比赛的唯一报名渠道。请勿相信其他任何声称百度“文心杯”创业大赛报名渠道、尤其是宣传“特殊报名通道”、“快速通道”的人或机构，如有信息可以向aigcsupport@baidu.com反映举报。

### 其他问题

+   若您在申请过程中遇到其他问题，请邮件咨询aigcsupport@baidu.com。
