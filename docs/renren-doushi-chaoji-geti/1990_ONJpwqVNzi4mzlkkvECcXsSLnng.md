+   面试

+   面试流程

+   1.准备自我介绍

+   文字稿要准备好

+   300-400字

+   1-2分钟

+   不要太长，没有重点

+   峰终定律

+   给对方留下记忆点

+   2.剖析自我，亮点/特长

+   1.你对自己有没有清晰的自我认知

+   2.亮点和特长

+   总结和反思过往的工作经历

+   讲故事

+   故事要短

+   学习能力

+   讲细节

+   具有真实性

+   一线经验

+   真实性

+   不要讲假大空

+   奖状

+   升职

+   加薪

+   3.项目介绍

+   引导面试官先介绍自己的岗位需求

+   吸引面试官

+   做好底稿

+   STARS

+   S是指Summary，即总结

+   项目过程中最印象深刻/最有难点

+   也要先整理好

+   实战的项目

+   脱敏

+   呈现形式

+   Axure链接

+   PRD

+   流程图

+   事后要求提供实战项目，脱敏

+   4.反问面试官

+   Don't

+   我没有问题了

+   你很自信，你以为进来很容易了

+   你不想进来

+   你不知道要问啥，没有准备

+   Need

+   1.未来规划

+   我进来了之后干嘛

+   这个岗位有什么要求，我是还不够的？需要提升的

+   2.对刚刚的面试的回顾

+   我的亮点是什么，缺点是什么

+   我要提升的是什么东西

+   3.问团队的细节（关心）

+   IT/产研占比/产品人数

+   晋升路线

+   成立多久，最早的员工待了多久

+   试用期的考核主要是哪些？

+   直属Leader是谁？背景是什么？是不是脱产管理？

+   面试过程

+   1.先引导面试官做项目介绍，了解这个岗位的真实需求是什么？

+   2.如何向面试官证明自己的团队管理能力？

+   1.定义产品框架

+   做什么产品

+   边界/定义

+   场景/价值

+   2.团队管理

+   团队规范

+   项目规范

+   原型

+   文档

+   工作流

+   团队赋能

+   培训

+   辅导

+   验收/审查

+   团队成功

+   所有人的优缺点 1on1

+   实现部门/项目/团队的共同目标

+   拆解任务/分配

+   管理者方面

+   承担责任/抗住压力

+   争取利益/资源

+   3.补充

+   尽量不做脱产管理

+   1.产出不太好量化

+   2.风险抵抗性低

+   3.职业发展受限

+   团队管理是渐进滚动

+   由粗到细

+   管理和实际业务两手抓

+   对比Offer

+   1.对公司的考量点

+   公司是否稳定

+   公司的业务是否持续向上

+   整体福利，待遇怎么样

+   2.对未来职业规划的考量点

+   团队的气氛如何，工作磨合是否顺利

+   成长空间是否足够大，对自己的职业发展是否有很大的帮助

+   行业方向是否匹配，未来跳出来了之后会不会不好找工作了

+   入职->转正

+   1.安全度过试用期

+   2.发挥个人优势，补充团队
