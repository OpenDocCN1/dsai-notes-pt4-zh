# 试用期转正

![](img/965c275c0331eeeb8dfa1dfa5b156d4f.png)

故事背景：阿珍是入职拼夕夕的初级产品经理，同属于电商事业部。在3个月的试用期之后，阿珍的试用期述职报告大概如下：

【自我介绍&关键目标】

各位领导同事，大家好，我是电商事业部新来的产品经理阿珍，主要负责与供应商管理相关的业务模块。在试用期前，我就和我的领导阿强共同商量，确定了我试用期要达成的关键目标是熟悉并掌握目前和供应商管理相关的业务和现有系统模块、功能，快速上手业务。

在关键目标定下之后，结合产品手册和历史迭代的需求文档，我自己绘制了供应商的入驻、变更、管理、审查等业务的流程图，同时梳理了已有功能模块的信息结构图并和同事、领导确认过，保证自己对业务的理解没有偏差。

【具体工作】

在试用期中，我参与到了2次功能迭代中，其中【供应商信息标记】功能是我在和运营同事沟通的过程中挖掘出来的。需求背景是运营同事在寻找供应商时，时常会遇到联系方式失效的情形，后来复盘得知失效原因是供应商那边的人员变动，导致提供旧的联系方式跟着失效。不过因为供应商信息更新不及时以及运营组内的信息差，还会出现多个运营同学打同一个失效的电话的情形，一定程度上降低了工作效率......(这里讲具体工作内容，因为试用期往往负责的内容相对简单，讲好背景、问题挖掘的过程、如何做、以及最后效果如何、是否解决了问题等等）

【反思和提升】

在我负责的新功能上线后，前面几天我发现极少有人使用新功能。于是我通过向运营同学回访，得知大部分同学都不知道上线了这个新功能，同时更新日志中也只是一句话提及，于是只有很少一部分运营同学注意到。于是我单独制作了一页使用说明，并配备对应的截图和gif动图作为素材，在运营同学的群中对新功能进行说明。随后过了一周，基本所有的供应商都被打上了对应的标记，并运营组长统一在每月底对供应商信息进行跟踪和更新。

【致谢】

在短短3个月试用期中，我在我领导阿强身上学到很多，目前也可以和团队内的其余产品伙伴配合，流畅地完成日常的功能迭代。同时功能上线过程中，也麻烦到了测试部门的xxx同学，还有运营组的xxx同学们也给我的需求调研提供了很多想法以及建议。我能感受到自己处在一个蓬勃、上升、配合高效的团队之中。

编者结语：上面这个例子只是随手一编的故事，具体的述职一般还是会通过ppt的形式进行呈现，希望大家能从思维导图和文字版的故事中，体会到整个试用期述职报告的核心框架，并能够完整地展示自己的工作产出！
