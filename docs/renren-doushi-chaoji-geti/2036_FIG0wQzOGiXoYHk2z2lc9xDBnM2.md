# 相互宝引发回忆杀：人生除了生死，其他都是擦伤

2023-07-11 15:56 · 十万个品牌故事

消失了一年多的相互宝，突然再次成为关注焦点。

送它上热搜的，是金融管理部门7月7日晚发布的蚂蚁集团整改公告，公告里提到了于2022年1月底关停的相互宝。

没想到，时隔一年半，相互宝还能引发网友一大波回忆杀。

数以万计的留言，虽然绝大多数每条只有短短十几个字，但只言片语中，已然体会到，什么叫 “人生除了生死，其他都是擦伤”。

挑一些大家感受一下：

我姐姐41岁，肝癌报了10万，但是杯水车薪，维持了三年无力继续治疗去世了。——米粒（河南）

我妈突发脑溢血，相互宝赔了10万，不吹不黑，实事求是。——爱吃辣辣椒啊（江西）

相互宝真的给我赔了30W，肾移植，在郑大一附院河医院区王主任给我做的手术，现在复查是刘磊副教授。——插花弄玉（河南）

朋友肺Ca，相互宝陪了十万，很快到账。——踏雪寻梅你好（湖北）

同村伯母癌症也赔了十万。——蒿鼠徐家志（江西）

我母亲宫颈癌赔付十万，现在母亲走了。真的感谢相互宝，在家里最需要钱的时候给予援手。——吃吃吃吃吃吃醉（陕西）

我也是，19年肺结节手术确诊早期肺腺癌，赔了30万，很感恩，我们全家都参与了互助。——Sue的彩虹（广西）

老爸21年查出癌症，相互宝补助了我父亲10万元，这笔资金维持了我父亲将近两年的治疗。——未来Too（安徽）

![](img/18ef2fee7d3ec8ad49d34730d709a569.png)

大家发现没有？把这些评论里透露出来的信息提炼一下，就是一张相互宝成员的高清画像：

**这些**网友的IP地址，绝大多数是安徽、江西、河南、陕西、广西等中西部地区；描述家庭状况，最高频的词语是“同村”“隔壁村”“县医院”“我们普通人家”；被帮助过的对象，大多是“我爸”“我妈”“同村伯母”……

这张画像，被学者验证过。

南开大学卫生经济与医疗保障研究中心对4.2万名相互宝成员做了走访调研，发现相互宝成员中，约33%来自农村和县城，30%年收入低于5万元，10%除了相互宝没有其他任何社会保障。

最近有一篇名为《如此打工30年》的爆款文，文章描述的“第一代农民工”，正是这些网友的“我爸”“我妈”“同村伯母”：

**他们对于疾病，58%的人“能忍则忍”，终于忍不住时，往往也到了摊上**大事的时候；他们人到晚年，50%以上存款不到5万元，而每月养老金只有100多元。

读到这里，大家应该能理解，为什么他们如此怀念和感念相互宝？因为相互宝是他们和他们的子女在摊上大事时，仅剩不多能抓住的救命稻草。

经历三年疫情，我想不仅是草根阶层，就是生活在一线城市的中产家庭，也体会到了“时代的一粒沙，落在个人肩山就是一座山”的无力感，以及在陷入绝境时，有人伸手拉了你一把的重生感。

这也是为什么，当有人跳出来喊话相互宝退费，更多人站出来说相互宝的好。

要知道，通过相互宝获得救助的人，在它被关停时，已经超过了20万。

这些自发的感念和辩护，让我想起电影《我不是药神》里，为印度仿制药代理商程勇求情的大妈。

![](img/2b103d1fc9b0717268403535117c0cca.png)

**未经他人苦，莫说他人愚。**

而相互宝，也经受得住这样的怀念、感谢和支持。

我是一个风险意识很高的人，在我研究过的同类保险中，相互宝成员每年交的钱最高不超过188元，费用最低，没有之一。

此外，相互宝的管理费8%，也是全市场最低，没有之一。

连很多公益组织收取的管理费都在10-15%之间，也就是说，相互宝的管理费比公益组织还低一大截。

但是，要维持相互宝的安全规范运转，成本其实很高。

我认识的一位医学院毕业的朋友，几年前入职了蚂蚁，做相互宝保险理赔审核员，每天的工作是梳理保险理赔规则，看海量病理报告、影像学报告，核实申请人信息的真实性和有效性。

他说他同事还有学临床医学、法医鉴定、中医、药学、护理学等专业的，“明明是一家互联网公司，却凑齐了半个医学院。”

这位朋友还告诉我，相互宝还招募了许多调查员，前往遍布全国的村镇乡县调查取证，审核患病成员的申请，和他们的核实进行交叉验证。

就在我写这篇文章的时候，相互宝的创始人尹铭在他朋友圈发了一篇文章，首次披露了一组数据——

相互宝累计有超过1亿用户参与互助，救助了205337位患病成员；

相互宝有17万荣誉会员，每月参与额外分摊，不计回报；

相互宝有745万赔审员，一共写下711507条赔审观点；

**相互宝有3700名调查员，1000名审核员，累计审核了2**092万页资料，相当于14万本高中课本。

![](img/c4f4142e4b23d5db101e5f7c91095266.png)

由于调查理赔成本高，直到关停那天，相互宝也没有实现盈利，从未赚过一分钱。

尹铭还在文中透露说，2022年1月关停相互宝时，为了妥善安置相互宝成员，相互宝母公司蚂蚁集团为此投入了近50亿成本。

可以说，直到关停，相互宝也做到了体面和负责任。

所以你也能理解，为什么还有这么多人念着相互宝的好。因为相互宝所凝聚的，不仅仅是互助金，更有数以亿计的普通人的信任和善意。

相互宝已经成为历史，但人性中的善意不会。
