
# 2023-07-04你知道通过代理商买云服务器，比直接去官网买要便宜很多吗？不管是阿-今日头条

你知道通过代理商买云服务器，比直接去官网买要便宜很多吗？不管是阿里云还是腾讯云，找代理商买就是要便宜一些。很多人都知道我是阿里云和腾讯云的代理商，但是很少有人通过我去买服务器，总觉得羊毛出在羊身上，好像通过代理商买云服务器被套路一样。这样想的人，只能说你是外行了，你是真不懂这里面的道道。今天就有一个客户，要买阿里云ECS服务器，他根据配置选择好以后，发现一年要9800多。问我这个配置行不行，我说这个配置没问题，运行系统绰绰有余。

不过，如果通过我去帮你买的话，同样的配置，同样的订单，我可以给你打个九折。这个客户说，怎么可能啊，你还能改阿里云官网的价格吗？我说，官网的价格不能改，但是我可以让你花九折的钱在阿里云上买到同样的配置，而且下单以后，你可以在阿里云的订单列表里面看到。客户说，如果能便宜那当然可以了。我说，前提是你需要把9800打九折的费用，也就是8800多先转给我，我帮你去买，需要走代付的模式才行。这时候客户有点犹豫了，为什么要转给你，让你来买呢？我说，只有这样我才能给你打九折啊。

可能是客户对我说的这种模式有点疑虑，不太相信我说的话，他最后说，算了，也没剩多少钱，先不用了吧。我说，如果你觉得不靠谱就算了，你自己买吧，只要配置没问题就行。后来我又说，你既然找我们开发软件，十多万都可以花，都可以相信我们，为什么到买服务器这种小事上就觉得我说的不靠谱了呢。他说，你不是程序员吗，做软件你们比较擅长，做事比较靠谱，但是买阿里的东西，估计你们就不擅长了。我说，那确实是，程序员最擅长的就是开发软件，但是买服务器这种事，我们再不擅长也比你擅长吧，我们天天跟服务器打交道呢，不说我们是专家吧，怎么也算是内行人吧。客户说，那倒是，主要是觉得你们没那么大的本事，不太可能可以低价买到阿里云的东西。最后我说，云服务器也没多少钱，无所谓了，实在不行你就自己去买吧，有什么问题再找我，买好以后把账号密码给我就行。客户说，好的。

结果呢，下午客户就给我发消息说，还是你来帮我买吧，我买的话只能是9800多，你们买的话还能便宜1000块钱呢。我说，行，你把8800多转我吧，一会我帮你买。刚说完，没几分钟他就把钱转过来了。其实，我刚才还想说呢，上午你还觉得我说的不靠谱呢，怎么吃个中午饭就觉得我又靠谱了啊，哈哈。不过这话我没好意思说，还是那句话，既然双方能合作，就说明对方是可以相信的，要不怎么合作呢。

下午我就用客户的手机号注册了阿里云，按照他发的截图选择的完全一样的云服务器配置，就给他下单了。下单以后我还专门把订单详情截图发给他了，告诉他，这个配置是不是跟你刚才说的完全一致，订单金额显示是9800多，实际你只花了8800多。然后他说，对，没错，还是你们厉害。

我为什么要说这事呢，就是说，专业的事交给专业的人去干。这句话看起来简单，做起来不容易，其实，能够快速地把专业的事交到专业的人的手里，这也是一种能力。为什么有些老板自己的能力不强，却可以把很多事做成功呢？说白了，就是他可以快速找到能帮他把这事做成的人，你能说这不是一种能力吗？做软件也一样，有哪个老板擅长写代码搞编程的呢，不都是找人做的吗？要不就是自己招程序员开发，要不就是找软件公司外包开发，最后的结果就是，公司有软件可以用了，这就达到目的了，不一定非要自己很懂，不一定非要自己干。有些人就是这样的，自己不懂反而不相信别人，非要自己乱查乱搜索，就不愿意花钱去找专业的人帮他做。这就和有些人生病了一样，不愿意去医院，不相信医院，非要自己查书买药吃是一样的。

我觉得，之所以有些人不愿找专业的人去帮他做专业的事情，原因无非有三个：

① 为了省钱；

② 不信任他人；

③ 过于自信；
