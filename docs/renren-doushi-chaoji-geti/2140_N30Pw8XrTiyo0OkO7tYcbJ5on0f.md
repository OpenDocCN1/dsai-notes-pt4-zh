# “我们自愿放弃做栋梁”，家长群的一段发言走红，网友：太真实了

首发 2023-07-18 18:34 · 艾弥儿

前段时间，一位父亲和老师的聊天记录刷爆了朋友圈，这位父亲表示： “我们自愿放弃做栋梁，愿做一名普通的市井小民，同时也接受孩子的平庸。”

一句话直接狠狠戳中了网友，中国父母向来是望子成龙、望女成凤，为了让自己的孩子赢在起跑线，中国父母在教育上可谓不遗余力。

![](img/4e52b6594fa85ab2ebdad9e38a58ab79.png)

家长的心声

这也就造就了一种新的说法：鸡娃。“鸡娃”的意思就是父母给孩子打鸡血，不断地给孩子安排各种学习活动，超越同龄人，最终出人头地的孩子。

![](img/e547ceedff39da811ec8109597887f97.png)

# 逼出来的“鸡娃”

上海的李妈妈就是一个典型的鸡娃家长，在孩子还在上幼儿园中班的时候，李妈妈就让他学习一年级的知识，还给他报了英语辅导班，让他学会用英语进行自我介绍。

每天放学还后要去上乐高课，训练立体几何思维能力，周末在家的时候还要刷题，基本没有休息的时间。

李妈妈这么做就是为让孩子考上全上海最好的私立小学，考上了最好的私立小学，才有更大的机会考上最好的中学，然后才能考上最好的大学，然后出人头地。

![](img/1700781a0738b2dbb8fa669136dd3948.png)

为了考上最好的私立小学，李妈妈已经准备了三年。但是等到了小李**上小学的时**候，上海市的政策改了，要实行 摇号上学 。

李**妈妈摇到了**小区门口的小学，此前，只有学习不好，或者实在没办法的孩子，才会来这所学校上小学，所以这所小学也被大家戏称为 “菜小” 。

摇到了“菜小”也就意味着小李没资格考最好的私立小学了，得知这个消息的这一刻，李妈妈崩溃了，她直接站在办公室痛哭。

冷静下来后，李妈妈想尽办法给小李办转学，她找遍所有的人脉关系，电话打了一个又一个，可所有人说的都是没办法，名额太紧张了，根本没有空出来的。

直到开学，李妈妈也没把转学办成。

![](img/a72eb920845eec79495b1b43c9fee622.png)

**思前想后，李妈**妈决定开启更硬核的 “鸡娃”模式 。

既然“菜小”和私立小学的教学质量存在差距，那自己就亲自上阵，督促孩子完成更多的学习任务，缩小和私小学生的差距。

从此以后，小李的生活被安排的满满当当。他每天一睁眼，面临的就是妈妈的催促。

在上学的路上，李妈妈都在和小李复习昨天学的知识，临到学校门口，李妈妈又给小李安排了今天的学习任务。

“今天教的单词必须全部记住，晚上回家默写，错了一个抄20遍。完事后去乐高班。回来后先跳绳，跳完绳下楼玩15分钟，然后再做其他科目，可以吗！？”

听到小李不情不愿的说出可以两个字后，李妈妈才匆匆忙忙的赶去上班。

![](img/9e5d1749a767f1f8cf499471b8d7e5e5.png)

因为小区门口的小学不布置作业，李妈妈晚上就自己出数学题让小李做，做完数学题后，紧接着小李就得练习拉大提琴，而且必须要练够一个小时。

少一分钟都不行，要是练着练着犯困了，李妈妈手里的戒尺就会敲在他的身上。

挨打挨多了，小李都挨出经验来了：“打屁股不疼，屁股上肉多，打手可疼了。”

这话听得让人忍不住的心酸，李妈妈也心疼自己儿子，但为了能让小李赢在起跑线上，超过同龄孩子，李妈妈不得不狠下心来。

等默写完单词，上完乐高班，默写完单词，跳完绳，做完数学题，练完大提琴，就到了晚上10点了。

到了周天，李妈妈还要跨过大半个上海，带小李去练习足球，按李妈妈的说法就是，德智体美劳要全面发展，光学习好不行，还得有一副健康的体魄。

![](img/dbd5b444d1dbd444b2027a7632ce1e7d.png)

李妈妈给小李的这些安排，都是精确到分钟的，别说自由的玩耍了，能自由的睡觉都快成了一种奢望了。

一开始，李妈妈也不是“鸡妈”，她也希望孩子能拥有一个健康快乐的童年，顺其自然的发展。

可眼看着别人家的孩子都在学绘画、唱歌、乐器，而自家孩子啥也不会，于是，她开始焦虑。

为了不让儿子被人落下，她也给孩子报了乐高班、大提琴班、足球班。用李妈妈的话说就是：“现在就这么个环境，逼着你不得不‘鸡娃’。”

![](img/f4cc7ef6cf4f6e6ce21376057bec0a8d.png)

# 被逼的家长

在鸡娃这方面，李妈妈还算正常，不是很过分。有些家长鸡娃起来，甚至算的上骇人听闻。

**在一档访谈节目**上，一位妈**妈骄傲的说：**“一个寒假，我儿子刷了 367张试卷 ，做完了 7本辅导书 ！”

![](img/a80e85240587fde5f0084e64d0bca89d.png)

听到这话，在场的嘉宾都震惊了，其中一位嘉宾问道：“他现在才一年级啊，整天做试卷，那放寒假的意义在哪里！？”

**听到这话，**这位妈妈当场谈起了自己的 教育观念：

“我对孩子的教育理念是没有快乐的童年。人就两种选择，一种是小时候享福，长大后吃社会上的苦；另一种是现在学会坚强、强韧、坚毅、抗压，那长大后才有资格有能力快乐！”

“而且现在所有的家长都在这么做，你给他玩的话，难道你不心慌、不忧虑、不担心吗？”

这样残酷而现实的教育理念，让在场所有人都说不出话来。

还有更极端的家长，为了孩子赢在起跑线上，辞掉百万年薪的工作陪孩子读书，还有的把房子卖了，给孩子报天价辅导班。

![](img/14a5fb6afdf608dc38d579d3753cf07a.png)

之所以会出现鸡娃现象，和社会风气以及观念是脱不开的，各种教辅机构，为了为获得更多的客源，疯狂的向家长贩卖焦虑。

公交站、地铁口，贴满了教辅机构的招生海报，有些教辅机构的招生人员，特地潜入家长圈，给家长们“凭空”制造焦虑。

甚至还有教辅机构机构直接打出“今天你不把孩子送来我们这，明天我们就培养你孩子的竞争对手”这样的招生口号。

这样的话，直接把家长的焦虑情绪给拉满了，在这样的社会风气观念的裹挟下，绝大部分的家长都会尽最大努力去给孩子报各种辅导班，被迫“鸡娃”。

![](img/441a2c3606441298aa0ed3bcca18b0cb.png)

事实上，鸡娃是有很大副作用的，家长不是不知道，只是他们认为，只要孩子能赢在起跑线上，这点“小小的副作用”根本不算什么。

![](img/6918fc85a7eb4d57737d2f13cc1ad6d6.png)

# “鸡娃”副作用

50年前，德国的一家机构做过一个实验，他们找了50所幼儿园，让里面的孩子顺其自然的学习玩乐，然后又找了另外50所幼儿园，让里面的孩子进行超前学习。

一开始，后面50所幼儿园里面的孩子在学习方面展现出了优势，但到4年级后，这个优势就不明显了，大部分孩子还出现了成绩下滑的情况。

而且他们在社交和自我表达上，远远不如前面50所幼儿园里出来的孩子。

后续观察发现，在幼儿园里进行超前学习的孩子长大后更容易受到挫折，心理承受能力更差。

![](img/33845f273ccca6c0db3b85aeab1babd7.png)

中国的心理学家也发现，家庭给孩子的压力越大，孩子就越容易出现心理问题。近些年来中小学生厌学，抑郁的情况越来越多。

这也就意味着，我们的“鸡娃”教育的确出现了“副作用”。

最开头那位“不愿孩子做栋梁”的父亲，就是“鸡娃”的受害者。不过，他发现的很及时，当孩子出现问题之后，这位理智的父亲立即退出了“鸡娃”行列。

父亲和老师的聊天记录曝光后，引起很多家长的共鸣，他们也受够了“鸡娃”，他们更希望孩子快快乐乐的，而不是被繁多的兴趣班、课后作业压得喘不过气来。

![](img/8775509d83f9474ec5284869c1d1e628.png)

人的一生有三个阶段，第一个阶段是接受父母的普通，第二个阶段是接受自己的普通，第三个阶段是接受子女的普通。

“栋梁”只是凤毛麟角，是很少的一部分人，绝大部分人都是普通的人。如果真的能力有限，成不了少数的栋梁，那做一个开开心心的普通人，这也没有什么不好。

如果孩子真的解不出这道题来，那就让他好好吃饭吧。

当然，“不做栋梁”不是让孩子躺平摆烂不思进取，而是适可而止，凡事有个度，就让孩子做孩子该做的事，不要放纵不管，也不要逼的太紧。
