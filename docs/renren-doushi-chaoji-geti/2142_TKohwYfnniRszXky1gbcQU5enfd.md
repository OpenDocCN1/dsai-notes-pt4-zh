# 胖东来8页报告火了！顾客与员工争执，员工获5000元精神补偿

2023-06-30 23:17 · 金羊网

最近在河南许昌，一位顾客与胖东来的员工发生了争执，引起了广泛的讨论。

胖东来随后公开了一份8页的“顾客与员工发生争执事件的调查报告”，这份报告非常详细，不仅包括了封面和目录，还对处理方案做了详细说明。根据调查报告显示，胖东来承认在服务过程中存在问题，因此决定将管理人员全部降级3个月，并携带礼物和500元的服务投诉奖品上门向顾客致歉。

然而，顾客在事后坚决拒绝了500元的投诉奖品。胖东来认为，顾客权益受到了损害，可以通过投诉渠道来反馈问题，但不能在现场高声责怪员工，因为这是对员工人格和尊严的严重伤害。因此，胖东来决定给予员工5000元的精神补偿。

对此，不少网友也发表了看法，“谁对谁错先不说，但是在互联网上这么详细的调查报告还是第一次见。”“这样的公司才是以人为本。”“态度端正，好企业。”“第一次在生活中看到了陪审小组！”“神仙企业啊！”“尊重爱护顾客，但是绝对不是以贬低员工为代价。”
