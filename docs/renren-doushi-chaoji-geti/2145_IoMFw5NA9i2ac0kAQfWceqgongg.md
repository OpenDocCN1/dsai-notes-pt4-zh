### 3. Python 之禅是什么意思？- 魔法三禁忌

Python 之禅就像是 Python 世界里的《霍格沃茨魔法学校规章制度》和魔法三禁忌，只不过它更加简洁，而且充满哲学味儿。✨

🪄 让我们一起拿出魔法棒，想象自己站在 Python 的魔法世界里。这里没有黑暗魔法，只有简洁、优雅和力量。🌌

Python 之禅（The Zen of Python）是一组关于如何写**出好的 Python 代码的指**导原则。这些原则简单但深刻，就像魔法公式一样：" 简单胜于复杂，复杂胜于复杂化 "。

Python 之禅鼓励你写出简单、明确的代码，就像是用最简单的咒语解决问题。它让你避免使用复杂和冗余的代码，因为在这个魔法世界里，简单就是力量。🔮

### 7. 在 Python 中如何进行对话？- 打印（print）和输入（input）

在课前预习的小故事中，哈利接过了巨人海格手中的黄色信封。他小心翼翼地拆开了它，取出了一张羊皮纸📜。

神奇的是，羊皮纸开始发出微光，仿佛注入了魔力一般。💫 随着这股亮光，纸上逐渐浮现出一行字，就像是这些字被“打印（print）”在了一个魔法屏幕上。

接着，哈利通过语音输入（input）了他的回答💬。就这样，他们之间展开了几轮对话，最终确认了前往霍格沃茨魔法学校的计划。🏰

在这个场景描述中，魔法信封和哈利通过 “打印（print）”和“输入（input）” 进行了对话和交互。在 Python 编程中，我们也经常使用input和print来进行输入与输出的交互🔁。

这就是我们即将学习的第一个“魔法口令”，具体如何施咒将在下一小节“让子弹飞”🚀中详细介绍。

### 8. 在 Python 中信息怎么流通？- 变量与赋值

在 Python 中，信息是如何流通🔄的呢？类似上面的魔法信封收到哈利的回应后，这些信息会如何存储和流通？

在 Python 中，信息流通通常遵循这样的路径：信息产生 -> 信息被存储 -> 信息被调取使用。

**这就引出了 Python **中的一个重要角色—— 变量（Variable） 。信息流通（通常）可以这样：信息通过输入或运算产生 -> 信息被存储在计算机中 -> 信息通过变量被调取使用。

变量的概念可能有点抽象，理解起来有些费劲。让我们用魔法世界的场景来做个类比。

在《哈利波特》原著中，有一种魔法叫做“港口钥”🔑（Portkey ，也叫“门**钥匙”）。这种魔法能让**人瞬间从一个地方传送到另一个地方。“门钥匙”通常是一个 被施了特殊咒语的物体 ，比如旧鞋👟、木棍🪵或者是一把椅子🪑等

当人们触摸这个物体时，他们会被立即传送到一个预定的目的地📍。例如，在《哈利波特与火焰杯》中，哈利和其他人触摸了一个看似普通的三强争霸赛奖杯，但实际上它是一个“门钥匙”，将他们传送到了一个远离霍格沃茨的墓地。

![](img/973bbb659cce62f6a7d68441889ffe81.png)

**从 Pyth**on 编程的角度来看，**这个“东西**”（ “门钥匙” 🔑）可以被视为一种 “变量”** 。**当我们命名一个变量时，就像是对某一个物体施展了特殊的咒语，“访问”这个变量时（触摸 “ 门钥匙”），就可以使用这个变量关联的“值/信息/数据”（目的地中的物品）。

这里有几个关键信息：

变量可以灵活地命名，就像“门钥匙”可以是旧鞋、木棍或者是一把椅子等。

** 使用**变**量前，**需要将变量和“值/信息/数据”连接起来，这个动作叫做 赋值 （Assignment）；这就像是对某个物体施加特殊咒语 -- 将“门钥匙”🔑和目的地📍建立连接，将目的地 赋值 给“门钥匙”。

通过变量，可以访问与这个变量关联的“值/信息/数据”；就像触摸“门钥匙”时，会被传送到预定的目的地，进而可以访问那里的一切。

变量只是一个标签或地图点位，它本身不存储“值/信息/数据”🚫。
