
# 再见爱人

自己看了再见爱人，里面对爱情婚姻的感悟很触动，最后的终极36问，每个问题都直逼人心，以下是我的感想，不知道大家面对这些问题会做怎样思考🧐

心理学36问，用来增进双方了解，通过36问达到目标：1、自我揭露，建立信任；2、建立平等关系；3、形成整体意识

1. 你心中完美的一天是什么样子的？早上睡到太阳升起，阳光照在屋子里，看着旁边熟睡的爱人，我起床去早市买菜，回来做早餐，把爱人叫醒，他会顽皮的睡懒觉，我拍了拍他的屁股让他起床吃早饭，早饭后两个人一起简单整理屋子，然后一起出去玩，可以逛街或者去休闲方式或者去户外看看风景，晚上回来一起做完饭也可以在外面吃点好的，然后看个电影或者直接回家，然后一起窝在沙发上看电视，或者各自做些自己的事情，最后一起在床上缠绵入睡

2. 如果你可以活到90岁，但身体状态保持在30岁的状态，那这60年你想要怎么过？和爱的人一起旅行，走到一个喜欢的地方就留下来在那里生活，如果生活几年又想去其他地方了就换个城市，只要有爱的人陪伴在身边就好

3. 你人生中最感激的是什么？感激的太多，但最感激的（人、事、物）此刻却是没有想清楚

4. 如果可以改变你长大的过程你想要改变什么？什么都不要改变，虽然我的家庭、童年、学历、工作都不够优秀，但这些成就了现在的自我，和很多人比现在的自我过的并不太差，如果改变了成长过程的某个因子，我可能就不会认识一些人，也可能过的比现在更差，所以还是什么都不要改变的好

5. 如果你可以选择世界上任何一个人，你想让谁做你晚餐的客人呢？邀请我的初恋东升，因为从大学毕业我们就断了联系，虽然对他的感情已经淡然很早就放下了，但还是想能再见见他，知道他过的好不好

6. 在打电话之前，你有没有排练过你想要说的话？为什么？一般没有，只有和重要的人说话之前，我会在脑子里反复排练，因为我想和他表达清楚自己的意思，让他接受我的想法，我是那种心里藏不住事情的人，面对自己爱的人内心的情感全部暴雷在自己的言行与表情，爱你就会直接说出来，也会实际行动表达出来

7. 人生到目前为止，你最难忘的回忆是什么？难忘的回忆很多：1.在一个寒冷动态的马路上前任蹲下来给我系鞋带。2.和一个曾经的爱人在景区拥抱接吻自拍。3.在新疆玩，和他一人戴一只手套，把他的手放在我的手里取暖。4.在新疆他给我涂身体乳。虽然都是很小的事情，爱人对我的某个小的行为就会让我很触动难忘，记在心里

8. 你觉得你的爱人应该有的美好品质列五个。真诚、善良、成熟、积极乐观、有上进心，这五个品质也是我对自己的要求

9. 用我们做主语，造三个句子。我们一起旅行、一起看日出日落、一起看山川湖海；我们能彼此相爱；我们能彼此陪伴；

10. 完成这个句子：“我希望我有一个能和他分享……的人。”我希望我有一个能和他分享未来的生活的人

11. 告诉你对面的人，你喜欢他什么，必须诚实，说一些你平时不会和他表达的话。

12. 如果你想和我成为亲密的朋友，请分享你认为很重要并一定要我知晓的事情。没有想出答案，因为我是藏不住事情的人，因此如果你是我的朋友你一定会知道我的事情

13. 告诉我你喜欢我的什么，一定要中肯诚实，不要说那些和第一次见面的陌生人就能说的泛泛之谈。给我的整体感觉包括外形和性格是我喜欢的类型，你善良真诚，给我一种温暖的感觉

14. 分享给我你一生中一个尴尬的瞬间。一般是别人觉得尴尬，我不觉得尴尬，大脑自动清楚尴尬瞬间，哈哈哈

15. 你最近一次在别人面前哭是什么时候？被谁弄哭的？还是自己哭的？在出差的晚上，那是一个新城到处在建工地，路上漆黑一片除了我没有任何人和车，自己刚刚结束了一段感情，回想自己的过往内心就觉得非常难受，走在漆黑的马路上就一个人默默的流泪

16. 如果今晚你要死了，却没有机会和任何人交流，你最后悔没有告诉某人什么事？你为什么到现在为止没有说呢？我和所有爱过的人都表达过自己的感情，因此没有什么后悔的事，只有没能在一起的遗憾。唯独对父母，我自认为不是一个孝顺的儿子，想告诉他们，儿子对不起，让他们操心了

17. 如果你的家（包括你的所有财产）着火了。在救了爱的人和宠物外，你还有时间安全地再冲进去捡回一个东西。会是什么呢？为什么？手机，这是互联网时代呀，哈哈哈

18. 家中所有的人中，谁的死会让你最不安？为什么？我的姐姐，如果姐姐不在了，我在家中就真的没有任何能够交流的人了

19. 我会和你讲一个很私人化的问题，请你换位思考告诉我如果是你，你会如何处理。你觉得我在面对这个问题的时候是什么感觉呢？

20. 如果水晶球能告诉你关于你自己、你的人生、未来或者任何其他事情的真相，你想知道什么？我未来在什么时候死去，知道自己的四期后，会更加珍惜活着的时间，过好每一分钟

21. 有没有某样东西/某件事让你魂牵梦绕很久却没有实现的呢？为什么还没做呢？去大理。看了黄渤的电影心花路放，那首去大理就一直萦绕心头，很想有机会去大理看看，至今没有爱人陪我去

22. 你一生最大的成就是什么？无

23. 友谊中你最珍惜的是什么？雪中送炭

24. 婚姻（亲密关系）中你最珍惜的是什么？互相理解，你懂我、我懂你

25. 你最珍贵的记忆是什么？无

26. 你最糟糕的记忆是什么？无

27. 如果你知道一年后你会突然死去，你会改变现在的生活方式吗？为什么？不会改变生活方式，就继续这样生活，但会在这一年里更珍惜时间，珍惜身边的人，把自己没说的话没做的事做掉

28. 爱情和感情在你的人生中起了什么作用？是人生中让我在孤独无助中的希望

29. 你的家庭多亲密？你觉得自己的童年比大多数人都快乐吗？家庭关系并不亲密，对童年无感

30. 你觉得你和母亲的关系怎么样？不亲密

31. 你有想过你会怎么死吗？我希望自己是因为一场事故突然离世，很快的离开。最不能接受在病痛的漫长时间的折磨下，人的身体和意志被摧残中离开

32. 举出你和我的三个共同之处。

33. 如果你明天一觉醒来，拥有了某种新的品质或者能力，那会是什么呢？拥有社交牛逼症，人见人爱吧，哈哈哈

34. 爱与喜欢在你人生中有什么区别？喜欢只是他身上的某个点吸引了我以至于产生喜欢的情感，会欣赏他，再甚者想和他发生什么，但止步于此。爱是想关心他，照顾他，考虑到他的感受，愿意为他付出满足他的一切需求，想和他一起分享自己未来的人生
