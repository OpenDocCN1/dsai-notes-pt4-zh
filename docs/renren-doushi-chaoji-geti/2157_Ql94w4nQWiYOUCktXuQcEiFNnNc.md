**这两天，官**方公布了去年 2022年一年的出生人口数量，是 956万 。因此，我也想赶在2023年年底之前， 预测一波今年（2023年）的出生人口总数 。

## **预测数据**

要预测今年的出生人口数量，那么就得先找到过往的统计数据，主要就是采集过往年份的出生人口数量。首先我从网上找到了一张2011年到2022年的出生人口数据统计表格，由于表格是图片形式，我用了一些工具将其转换成 excel 形式。 感兴趣可以关注我的公众号，回复【人口数量】获取这个统计文件 。

![](img/8e453a90eb3b3f247920028d5eef9ad8.png)

## **预测方法**

预测方法也非常简单，那就是做出假设，每年出生人口的变化都是在过去几年的基础上进行线性变动的。

说的大白话一点：

+   假**设前年出生了 1000**万，去年出生了 900万，那么我大概率可以预测今年出生人口在 800万上下，因为这构成了等差数列，实际上就是 人口变化符合线性变化 。

+   当然了，除了符合线性变化之外，还有 趋势变动，也就是，出生人口到底是下降的速度更快了，还是更慢了 ，说得学术一点，尤其是放在机器学习这块，起个高大上的名字叫做动量。如果预测今年出生了820万，那么说明人口下降趋势变慢了，如果出生了770万，那么说明人口下降趋势更加快了。

知道原理就可以开始画图了，当然，为了

## **实施过程**

主要就是写几个 python 代码，画图用的 matplotlib，虽然画出来丑，但是能看就行了，要啥自行车啊？？？这是我花了20分钟画出来的图，可以先对历年的出生人口有个直观的感受：

![](img/ff8a6abd62e3ec563d5184ac6bf06e94.png)

有几个需要注意的点：

+   图中，2016年由于二胎政策的放开，黄色线在2016年有一个高峰，也就是70后的二胎生育意愿出现一个短暂的释放。可以说政策是影响生育的一个非常重要的影响因素。

+   在2011年，一孩是主力生育大军，二孩只占少数比例，而到了2022年，一孩的生育数量和二孩已经不相上下。

+   三孩数值始终是相对平稳的。

#### **趋势统计**

统计一下历年人口变化趋势，也就是今年的出生人口，减去上一年的出生人口，得到下图：

![](img/4a333f1cb250a9cb742f690bd4f08300.png)

+   正值代表当年人口相比上一年，生的更多了，生育力旺盛；负值代表生的更少了，生育人口逐年下降。

+   从统计图表中可以看出，在2016年之前，出生人口还是大致处于逐年增多的趋势，而2017年开始，除了三胎人数很稳定，其余，也包括总数，生育力逐年降低。

进一步，需要统计这个趋势的变化率：

![](img/df06711cb8a6a239d89db2c31acc2d3d.png)

变化率表示的是 **人口出生的变化速率 **，其实就是物理里的加速度。如果变化速率为正值，表示人口出生的人数更多，且呈现爆炸式增长，或者人口减少的更慢；反之，则表示人口增长的更慢，或者衰减的更加迅速。

这个图中，数值变化还是比较剧烈的，真的就……挺难找出什么规律的。不过我也硬着头皮预测吧，统计局每年又有多少数据特别准呢？你说是不是？？？

庆幸的是， **近些年的数据还是浮动不那么大的，也就是着重考虑 2020、2021、**2022年即可，可以看出这几年浮动数值相对更加围绕 0，也就是更加符合线性规律 ，且这几年都处于人口减少的年份，2019年为负值，也就是2019年相对 2018年，人口减少的速度比较慢。而2020年和2021年，相比上一年则人口下降幅度更加剧烈，很明显，由于前几年疫情的缘故，人们生育意愿和能力都受到了很大的冲击。

不过，到了2022年，变化浮动速率已经接近 0 了，尤其是1胎、2胎、3胎都呈现逐渐接近0 的特征，这就说明当年的人口下降还是非常接近线性模型了。

## **开始预测2023年的**

好了，根据变化浮动速率表格：

![](img/4968a1b00907b508ef2773ead6a1ae6d.png)

根据这组数据，算出一个2023年的浮动率：

+   总人口浮动率：**-3.7万**

+   一孩浮动率：**-2.4万**

+   二孩浮动率：**-0.87万**

+   三孩浮动率： **-3.2万**

换句话说，预测值中，2023年的生育数量下降的趋势会略微减缓一点。当然，我只是预测一个最大似然值，实际上，2023年的出生人口数应该是一个概率范围，我们就大致假设它是正态分布的。这个先暂且不表。

然后就可以预测 2023年的出生人口最大似然值啦！！！

**根**据前面步骤反推过去，算出来是 2023年出生人口 847万 ，其中一孩出生人口 411.6万，二孩出生人口 303万，三孩出生人口 129万 。

#### **出生人口的浮动范围**

还剩下一个出生人口的概率分布范围没提，由于我们假设了它是正态分布的，而且从前面人口变化浮动速率图中，我们也可以看出，数值大致就是围绕 0 点上下波动的，波动范围越剧烈，说明数值变动范围越大。这更加说明了三胎数值的相对稳定。

那么，我直接拿着这组数据计算方差和标准差了。说实话，由于2011年~2016年，尤其是 2016，由于政策原因，波动太大，数据没有参考性，我就把 2016 给剔除了，当然，连带着会导致 2017年的数据也受到波动，因为我是拿前后两年数据进行关联性统计的。所以，所有的统计都不包括 2016 和 2017 两年。

此外，人口数量越多，方差越大，人口数量越小，方差越小，这是很自然的事情，我也把这种情况考虑进去。

+   总人口标准差： **15万**

+   一孩标准差： **11万**

+   二孩标准差： **10万**

+   三孩标准差： **4万**

由于一个标准差大概就是正态分布中大约68%的概率，为了使我们的预测尽可能覆盖95% 以上的可能性，那么就取2个标准差吧。

![](img/e3057bb156fb8d9f561e37bde15510c6.png)

可以计算得到最终结论：

**2023年的出生人口预测为 847**万，浮动范围为 817万~877万之间。

## **后记**

当然了，现在已经有很多渠道的消息，比如医院妇产科产妇建档的数据，有说今年出生 700多万的，还有根据今年上半年各地地方统计数据，推算今年出生 800万出头的。加之今年属于疫情后的第一年，还需要考虑经济形式，以及年轻人们的生育观念的变化等等，各种情况很难判断。

在我的预测里，也就不一一考虑了。总之，我这里仅从数据统计角度来预测的，是骡子是马，明年再看看咯。
