# **公众号流量主的变现逻辑？**

**1.1、什么是流量主**

公众号流量主是指符合一定条件的微信公众号运营者，自愿将公众号内指定位置分享给广告主作广告展示，从而按月获得广告收入的运营者。

直白点也就是我们平时阅读公众号文章时看到作者插入的文中广告或底部广告（最常见的2种）。

**公众号广告位概览：**

## **1.2、流量主变现逻辑**

只要开通流量主功能，然后发布内容，有曝光和点击基本都能产生收益。

![](img/ff2cbc519dfd5c552615bf2897a61c54.png)

**● 收益计算方式：**

流量主收益主要是根据广告的曝光率与点击量来计算的，当然也和文章阅读量、拉取量及点赞分享收藏等一系列传播途径有关。

也就是说， 只要你所发布的内容数据越来越好 ，那对应的收益就会越来越高。

# **如何开通公众号流量主？**

**2.1、注册公众号**

>>> 打开微信公**众平台官网：** https://mp.weixin.qq.com/ ，一般我们选择做 【订阅号】 就行了。

![](img/67590bf9497296e46065ac521d39dc3b.png)

**>>注册类型选择：**

**a、个人主体：**

**可注册1个账号 **， **结账方便 **，个人银行卡就行，所以，想多注册几个个人账号的话，可以找亲戚、朋友的身份证去注册。

**b、个体工商户：**

**可注册2个账号 **，注册第二个时候需要先认证一个才可以注册，可以两个浏览器同时提交注册，卡注册认证这个环节，这样就可以不需要认证就能注册两个账号。

提现的是绑定个体法人银行卡，申请对公的个体可以提现到对公，不过能提现到个人，就没有必要提现到对公。

**c、公司主体：**

可注册2个账号（可突破50个） ，公司申请的账号不是一次性申请50个，而是可以分批申请，第一次2个，申请后可以申请五个，15天后可以申请5个，以此类推，最后申请五十个。

**公司主体突破注册基本流程：**

> 1、先注册第一个公众号，进行认证，需支付300元认证费用

> 2、第1个认证通过后可获得5个名额，1周后提交注册（无需认证也可用）

解锁的注册数量是一次5个增加，时间会有差异。

# **如何提高公众号流量主收益？**

**提高流量主收益的核心逻辑是： ****优化曝光指标**

**公式： **曝光量 = 曝光量 x 曝光率，需要优化拉取量及曝光率指标。

## **5.1、增加推文数量**

增加推送的文章数量，间接的提升文章总阅读数，促进广告的总曝光次数，而且现在公众号改版之后，推荐的流量也越来越多。

**具体操作： **文章内容增加，上下300字以上，可以插入1条广告内容。把以前发的文章插入文中，方便读者对感兴趣的内容跳转，精彩回顾、历史文章，都可以用起来。

底部曝光提升10%-15%

收入提升10%-15%

![](img/34b7861abd83a293ba9630af13d94562.png)

## **5.2、增加文中广告**

**具体操作： **开启文中广告位，增加广告展现量。

文中广告加入1-2条，总收入提升70%-120%。

## **5.3、缩短无用配图**

缩减文中无关的配图，提升底部广告的曝光和打开率。

**具体操作： **减少文章底部不相关的配图，提高底部广告数据。

相关数据显示： 降低底部配图高度，可增加底部广告曝光率从30%提升至40%

## **5.4、提高视频输出**

视频本身的长度短，让直接提升底部广告的曝光和点开率。

**具体操作： **如果你有同步操作视频号，则可以直接引入自己视频号的视频内容。

## **5.5、底部评论及广告屏蔽**

![](img/591c5c0d204e98c5d07cded7417028c5.png)

**→ 底部评论：**

广告收益取决于：用户在广告页面的停留时长，广告点击率。将重要信息放在首条评论。用户滑到留言区看评论，停留时长能让底部广告有效曝光。

例如做影视号的，可以将链接放评论，让用户自取。

**→ 广告屏蔽：**

用“广告屏蔽”功能。可在公众号后台查看粉丝画像，打开流量主→广告管理→广告屏蔽，屏蔽掉这类人群不看的广告。

就好像你一个面向中老年的内容，却展示潮玩广告，人群的属性完全不匹配，自然用户是不会点击的。
