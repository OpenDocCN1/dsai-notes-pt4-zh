# 美团四大名著

> 来源：[https://xuqiwei1986.feishu.cn/docx/Sz2KdemFtoFAgAxTyb2cVzByneE](https://xuqiwei1986.feishu.cn/docx/Sz2KdemFtoFAgAxTyb2cVzByneE)

四本书在美团备受推崇，因为它们分别构建了我们职场需要的几种重要底层能力：

▪️《金字塔原理》---清晰表达能力和逻辑思考能力

▪️《学会提问》-----批判性思维和学会关键沟通

▪️《高效能人士的七个习惯》--良好的工作素养和工作习惯

▪️《用图表说话》--工作数据的可视化表达

美团联合创始人、高级副总裁王慧文曾说，“只要你应用正确的方法，即便是一个智商非常普通的人，也会表现得像一个天才一样”。

读有用的、高质量的书，思考并学以致用，是非常关键的成长路径。而这样的“常识”，从听到信再到行，足以过滤掉绝大部分人。因此，他在美团内部反复强调“四大名著”的重要性，还留下一句金句：

“这几本书如果你认真读了，有可能在中国99%的公司做到高管。”
