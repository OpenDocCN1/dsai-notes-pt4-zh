# 在线赚钱网站

+ `https://app.playtestcloud.com/signup` 游戏测试员

Playtest Cloud 是一个让游戏爱好者们梦寐以求的平台。在这个网站上，游戏开发者们希望了解像你一样的玩家是如何体验他们的手机游戏的。他们需要你提供反馈，从初次体验到游戏的长期粘性，各个方面都非常重要。

而且，值得一提的是，开发者们并不要求专业的游戏测试员，他们更需要普通人来提供这些反馈。在官网上，他们表示：“我们的测试者是普通玩家，而非专业测试员。”也就是说，任何人都有机会成为测试员。Playtest Cloud 目前已测试了超过10万个游戏，数量相当可观。那么，你可以赚多少钱呢？每完成一次大约15分钟的游戏测试，你可以获得约9美元。做个简单的算式：这相当于每小时赚36美元，仅仅是玩游戏！这确实是个不错的收入机会。虽然可能不能替代全职工作，但它无疑是一种非常合适的赚取额外收入的方式，同时还能享受你最喜欢的游戏。

+ Foap 你是否用手机或数码相机拍摄了很棒的照片？你想开始卖掉这些照片吗？

Foap 允许你上传手机上的照片和视频，并将其出售。它就像一个数字图像的在线市场。

合作方式是：你分享你的内容，如果像品牌或广告公司想要使用这些照片，它们会通过 Foap 购买。然后，Foap 会和你分成，50/50。也可以通过加入 Foap 的“任务”来提高收入，这些任务是品牌发布的创意挑战，寻找特定类型的照片或视频。只需遵循他们的要求，提交你的内容，如果他们选择了你的图片（大多数情况下他们会选择多个图片），你就能赚到额外的几百美元。只需下载应用，注册一个免费账户，然后开始发布你的照片。
