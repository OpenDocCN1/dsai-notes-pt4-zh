## 1、`Zoom in` 推近 / 拉近 / 放大

### 动作

指在拍摄过程中，通过调整镜头的焦距，使画面中的主体看起来越来越大，仿佛摄影机在向主体靠近。但实际上，摄影机的位置通常保持不变。

### 视觉效果

+ **强调主体:** 将观众的注意力集中到画面的中心人物或物体上。
+ **突出细节:** 能够展现主体更细致的纹理、表情或特征。
+ **增强紧张感或亲密感:** 逐渐拉近的镜头可以营造一种逼近感，使观众更贴近角色或情境，从而增强紧张或亲密的情绪。
+ **隔离主体:** 通过放大主体并虚化背景，可以将其与周围环境隔离开。

## 2、`Zoom out` 推远 / 拉远 / 缩小

### 动作

指在拍摄过程中，通过调整镜头的焦距，使画面中的主体看起来越来越小，同时纳入更多的周围环境。摄影机的位置通常也不变。

### 视觉效果

+ **展现环境:** 将主体置于更广阔的背景中，展示其与周围环境的关系。
+ **提供全局视角:** 能够让观众了解整个场景的全貌。
+ **减弱紧张感或疏离感:** 逐渐拉远的镜头可以营造一种距离感，使观众以更客观的视角观察。
+ **弱化主体:** 在广阔的背景下，主体的重要性可能会相对减弱。

## 3、`Orbit` 环绕

`Orbit` (环绕) 表明摄影机不是直线运动，而是以一个近似圆形的轨迹围绕着被拍摄对象运动。

`orbit left` 向左环绕 / 左环绕 / 顺时针环绕（如果从上方看）

**Left (左):** 指的是摄影机运动的整体方向是向左的。

`orbit right` 向右环绕 / 右环绕 / 逆时针环绕（如果从上方看）

**Right (右):** 指的是摄影机运动的整体方向是向右的。

### 视觉效果和叙事作用

+ **展示主体全貌:** 环绕拍摄可以从不同的角度展示主体的各个侧面，让观众更全面地了解其形态和细节。
+ **增强空间感:** 这种运动能够揭示主体周围的空间环境，以及主体与环境之间的关系。
+ **营造动态感和流畅感:** 环绕的运动比静态镜头更具活力，能够吸引观众的目光，并使画面显得流畅自然。
+ **强调主体的重要性:** 通过以主体为中心进行环绕，可以突出其在场景中的地位。
+ **表达角色的观察或思考:** 有时，环绕镜头可以模拟一个角色正在仔细观察或思考某人/某物的过程。
+ **创造梦幻或眩晕感:** 在某些特定的情境下，快速或不稳定的环绕运动可以营造出一种梦幻或眩晕的感觉。

## 4、`Pull in`

通常指的是摄影机在物理空间中向主体靠近或远离的运动，而不是通过调整镜头焦距实现的变焦 (`Zoom in`/`Zoom out`)。

`Pull in`: 推近 / 向前推 / 靠近

### 动作

指摄影机在物理上向被拍摄的主体移动，通常是使用滑轨 (`dolly`) 或其他移动设备来实现平稳的向前运动。

### 视觉效果

+ **逐渐放大主体:** 画面中的主体会逐渐变大。
+ **保持透视关系不变:** 与变焦不同，推近时主体和背景之间的透视关系会保持相对稳定，不会产生明显的背景压缩或扩展效果。
+ **增强亲近感和聚焦感:** 物理上的靠近可以使观众感觉更接近主体，注意力更集中。
+ **强调主体的重要性:** 逐渐占据更大画面的主体往往被赋予更重要的意义。

## 5、`Pull out`

`Pull out`: 拉远 / 向后拉 / 远离

### 动作

指摄影机在物理上远离被拍摄的主体移动，同样通常使用滑轨或其他移动设备来实现平稳的向后运动。

### 视觉效果

+ **逐渐缩小主体:** 画面中的主体会逐渐变小。
+ **纳入更多环境:** 随着摄影机后退，画面中会呈现出更多的周围环境。
+ **保持透视关系不变:** 与变焦类似，拉远时透视关系也相对稳定。
+ **减弱亲近感和聚焦感:** 物理上的远离会使观众与主体之间产生距离感。
+ **展现环境和背景:** 拉远的镜头常用于展示主体所处的环境，揭示更广阔的场景。

> 与 `Zoom in`/`Zoom out` 的区别:

+ `Pull in`/`Pull out` (物理推拉): 摄影机在空间中实际移动，透视关系变化较小。
+ `Zoom in`/`Zoom out` (变焦): 摄影机位置不变，通过改变镜头焦距来放大或缩小画面，透视关系会发生变化（推近时背景被压缩，拉远时背景被扩展）。

## 6、`Roll left` / `Roll right`

`Roll` (滚) 指的是一种旋转运动，类似于飞机在空中侧倾或船只在水面摇晃。在摄影中，它是指摄影机本身发生侧向的旋转。指的是摄影机围绕其光轴（镜头中心线）进行的旋转运动，导致画面整体发生倾斜。

`Roll left`: 向左倾斜 / 画面向左旋转 / 左滚

指的是画面顶部向左侧倾斜。

`Roll right`: 向右倾斜 / 画面向右旋转 / 右滚

指的是画面顶部向右侧倾斜。

### 视觉效果和叙事作用

+ **制造不稳定感和混乱感:** 倾斜的画面会打破观众正常的视觉平衡，产生一种不稳、倾斜或失重的感受，常用于表现混乱、冲突、醉酒、疾病、主观视角中的眩晕等状态。
+ **增强紧张感和不安感:** 不规则的画面角度可以营造一种紧张、焦虑或不安的氛围。
+ **表现主观视角或心理状态:** 倾斜的镜头有时可以代表角色的主观感受，例如头晕目眩或精神恍惚。
+ **强调戏剧性或超现实感:** 在某些风格化的影片中，刻意的倾斜镜头可以增强画面的戏剧性或营造一种超现实的视觉效果。
+ **过渡或转场:** 偶尔也会在场景或段落之间使用短暂的倾斜滚动作为一种视觉过渡。

> 与 `Pan` 和 `Tilt` 的区别:

+ `Pan` (摇): 指的是摄影机在水平方向上的旋转，镜头上下角度不变。
+ `Tilt` (俯仰): 指的是摄影机在垂直方向上的旋转，镜头左右角度不变。
+ `Roll` (滚): 指的是摄影机围绕镜头中心线的旋转，导致整个画面倾斜。

`Roll` 是一种相对少见的镜头运动，通常用于特定的叙事目的，以产生强烈的视觉和情感冲击。

## 7、`Truck left` / `Truck right`

指的是摄影机在水平方向上平移的运动，即整个摄影机（包括三脚架或移动平台）向左或向右侧向移动，但镜头的光轴基本保持与拍摄主体的水平方向垂直。

`Truck left`: 向左平移 / 左移 / 横向左移

`Truck right`: 向右平移 / 右移 / 横向右移

### 视觉效果和叙事作用

+ **跟随主体运动:** `Trucking` 最常见的用途是跟随画面中水平移动的主体，保持主体在画面中的相对位置，例如跟随奔跑的人、行驶的车辆等。
+ **展现主体与环境的关系:** 通过平移，可以在主体移动的同时展现其周围的环境变化，揭示主体与环境之间的互动。
+ **营造流动感和节奏感:** 平稳的横向移动可以使画面产生流畅的运动感，有助于控制影片的节奏。
+ **保持主体在景别中的大小稳定:** 与 `Pan` 不同，`Trucking` 可以更好地保持主体在画面中的大小和比例，避免因旋转角度过大而产生的透视变化。
+ **引导观众视线:** 通过平移，导演可以引导观众的视线跟随主体或观察场景中的不同元素。
+ **创造平行叙事感:** 有时，`Trucking` 可以用于在两个或多个平行发生的动作之间进行视觉连接。

> 与 `Pan` 的区别:

+ `Truck`: 摄影机整体在水平方向上移动，改变了摄影机的位置。
+ `Pan`: 摄影机固定在一个点上，镜头在水平方向上旋转，摄影机的位置不变。

## 8、`Pedestal up` / `Pedestal down`

`Pedestal` (升降) 指的是摄影机在垂直方向上的整体移动，类似于升降台的运动。与 `Tilt`（俯仰）不同，`Tilt` 是摄影机在一个固定点上旋转镜头，而 `Pedestal` 是摄影机的整体高度发生改变。

镜头语言中的 `Pedestal up` 和 `Pedestal down` 指的是摄影机在垂直方向上进行的升降运动，即整个摄影机（通常架设在三脚架或摇臂的底座上）向上或向下移动，但镜头的俯仰角度通常保持不变。

`Pedestal up`: 向上升降 / 升高 / 向上摇升 (较少用)

**Up (上):** 指的是摄影机整体向上移动。

`Pedestal down`: 向下升降 / 降低 / 向下摇降 (较少用)

**Down (下):** 指的是摄影机整体向下移动。

### 视觉效果和叙事作用

+ **改变视角高度:** `Pedestal up` 可以将观众的视角从较低的位置提升到较高的位置，反之亦然。
+ **展现主体的高度变化:** 可以跟随主体垂直方向的运动，例如人物站起或坐下。
+ **揭示场景的垂直空间:** 向上升降可以逐渐展现场景中更高的部分，向下升降则可以展现更低的部分。
+ **营造庄严感或渺小感:** 从低角度向上摇升拍摄主体，可以赋予主体更庄严、宏伟的感觉；而从高角度向下摇降拍摄主体，则可能暗示其渺小或处于不利地位。
+ **平稳的垂直运动:** 相比于 `Tilt`，`Pedestal` 提供的垂直运动更加平稳和整体。

> 与 `Tilt` 的区别:

+ `Pedestal`: 摄影机整体在垂直方向上移动，改变了摄影机的高度。
+ `Tilt`: 摄影机固定在一个点上，镜头在垂直方向上旋转，摄影机的高度不变。

## 9、`Static` 固定机位

指的是画面中**摄影机完全没有运动**。画面是固定不动的，没有任何推拉、摇移、升降、环绕或倾斜等运动。

`Static` 镜头的特点和作用：

+ **稳定感和客观性:** 静态镜头通常给人一种稳定、冷静和客观的感觉，观众可以仔细观察画面中的内容，而不会被摄影机的运动所干扰。
+ **强调画面内容本身:** 由于没有运动，观众的注意力会完全集中在画面中的人物、物体、构图、光线和色彩等元素上。
+ **营造沉静或凝重的氛围:** 在某些场景中，静态镜头可以营造出一种沉静、庄重、甚至是压抑或凝重的氛围。
+ **表现观察或等待:** 静态镜头可以暗示角色正在观察某事物，或者等待某个事件的发生。
+ **作为对话场景的基础:** 许多对话场景会使用静态的中景或近景镜头，以便观众专注于角色的表演和对话。
+ **形成对比:** 在运动镜头之后使用静态镜头，可以产生对比效果，突出强调某个瞬间或信息。

**需要注意的是**，即使是 `Static` 镜头，画面内部的元素（如人物的动作、光线的变化等）仍然可以是动态的。 `Static` 仅仅指的是摄影机本身没有发生位移或旋转。

**总结**，当描述镜头语言为 `Static` 时，意味着摄影机在拍摄过程中保持完全静止，不进行任何形式的运动。这种手法可以带来稳定、客观、强调内容等多种效果。

## 10、`Pan left` / `Pan right`

`Pan` (摇) 指的是摄影机水平方向上的旋转，类似于你左右转动头部观看风景。摄影机的三脚架或其他支撑设备保持固定，只有摄影机的机身和镜头在水平方向上转动。

镜头语言中的 `Pan left` 和 `Pan right` 指的是摄影机在水平方向上进行的旋转运动，但摄影机本身的位置保持不变。

`Pan left`: 向左摇 / 左摇

**Left (左):** 指的是镜头从右向左旋转，画面中呈现的内容从右边移动到左边。

`Pan right`: 向右摇 / 右摇

**Right (右):** 指的是镜头从左向右旋转，画面中呈现的内容从左边移动到右边。

### 视觉效果和叙事作用

+ **跟随主体运动:** `Pan` 最常见的用途是跟随画面中水平移动的主体，保持主体在画面中。
+ **展现广阔的场景:** 通过左右摇动镜头，可以展示一个宽广的场景，引导观众的视线浏览不同的元素。
+ **连接不同的视觉元素:** `Pan` 可以将画面中原本不相关的两个或多个元素连接起来，暗示它们之间的某种联系或引导观众注意到新的信息。
+ **营造流动感和节奏感:** 平稳的摇动镜头可以使画面产生流畅的运动感，有助于控制影片的节奏。
+ **表达角色的观察:** `Pan` 可以模拟角色在水平方向上观察周围环境的动作。
+ **创造悬念或期待:** 通过摇向某个方向，可以引导观众期待接下来会出现什么。

在电影制作中，`Pan` 是一种非常基础且常用的运动镜头，能够有效地跟随运动主体、展现场景和引导观众视线。

## 11、`Tilt up` / `Tilt down`

`Tilt` (俯仰) 指的是摄影机垂直方向上的旋转，类似于你上下点头的动作。摄影机的三脚架或其他支撑设备保持固定，只有摄影机的机身和镜头在垂直方向上转动。

指的是摄影机在垂直方向上进行的旋转运动，但摄影机本身的位置保持不变。

`Tilt up`: 向上俯仰 / 上仰 / 抬头

**Up (上):** 指的是镜头向上旋转，画面中呈现的内容从下方移动到上方。

`Tilt down`: 向下俯仰 / 下俯 / 低头

**Down (下):** 指的是镜头向下旋转，画面中呈现的内容从上方移动到下方。

### 视觉效果和叙事作用

+ **引导观众视线:** `Tilt up` 可以引导观众的视线向上移动，例如从一个人的脚部向上看到他的脸，或者从地上的物体向上看到天空。`Tilt down` 则相反。
+ **展现主体的垂直高度:** 通过向上或向下倾斜，可以完整地展现主体的高度或长度。
+ **揭示场景中的垂直关系:** `Tilt` 可以连接画面中不同高度的元素，展示它们之间的联系。
+ **营造期待感或失落感:** `Tilt up` 向上探索未知，可以营造一种期待、希望或揭示的氛围；`Tilt down` 向下移动，有时会暗示失落、死亡或低落的情绪。
+ **模拟角色的视线移动:** `Tilt` 可以模拟角色抬头或低头的动作，使观众更容易代入角色的视角。

在电影制作中，`Tilt up` 和 `Tilt down` 是非常常用的运动镜头，能够有效地引导观众的视线、展现主体的垂直维度以及表达特定的情感或叙事信息。

## 12、`Crane up` / `Crane down`

指的是使用摇臂（`Crane`）这种大型摄影机支撑设备，将摄影机在垂直方向上整体抬升或降低的运动。

`Crane` (摇臂 / 吊臂): 是一种大型的机械臂，可以将摄影机和摄影师 поднимать (podnimat', поднимать) 到高处，并进行各种复杂的运动，包括垂直升降。

`Crane up`: 摇臂向上 / 吊臂抬升 / 升格

**Up (上):** 指的是摇臂将摄影机整体向上抬升。

`Crane down`: 摇臂向下 / 吊臂下降 / 降格

**Down (下):** 指的是摇臂将摄影机整体向下降低。

### 视觉效果和叙事作用

+ **展现宏大场景:** `Crane up` 可以从较低的角度开始，逐渐升高，最终展现广阔的场景全貌，营造史诗感或开阔的视野。
+ **揭示重要信息:** 通过向上摇升，可以逐步揭示之前被遮挡的场景元素或关键信息。
+ **赋予角色力量或重要性:** 从低角度向上摇升拍摄角色，可以使其显得更加高大、威严或具有力量。
+ **营造渺小感或孤立感:** 从高角度向下摇降拍摄角色，可以使其在广阔的环境中显得渺小、孤立或处于弱势地位。
+ **平稳的垂直运动:** 摇臂提供的垂直运动非常平稳，可以实现流畅的视觉效果。
+ **作为复杂的组合运动的一部分:** 摇臂常常与其他运动（如摇移、俯仰、平移）结合使用，创造出更具动态和表现力的镜头。
+ **结束场景或段落:** `Crane up` 常常用于一个场景的结尾，逐渐拉高视角，象征着结束或离开。`Crane down` 也可用于类似的效果，但方向相反。

> 与 `Tilt` 和 `Pedestal` 的区别:

+ `Tilt` (俯仰): 摄影机在一个固定点上旋转镜头，改变的是镜头的上下角度，摄影机整体高度不变。
+ `Pedestal` (升降): 摄影机在垂直方向上整体移动，但通常是在相对较低的高度范围内，使用三脚架或小型升降台。
+ `Crane` (摇臂升降): 使用大型摇臂，可以在更大的垂直范围内进行升降运动，并能实现更复杂的运动轨迹。

在电影制作中，摇臂是实现复杂和具有视觉冲击力的运动镜头的强大工具，而 `Crane up` 和 `Crane down` 是其最基本的垂直运动方式。

## 13、`handheld` 手持

“手持”（`HANDHELD`）指的是一种拍摄技术，其中摄影师不使用三脚架或其他稳定设备，而是直接用手持摄像机进行拍摄。这种技术赋予画面一种独特的视觉效果，可以传达多种不同的情感和信息。

+ 这种风格可以使观众感到他们正在亲身体验场景，增强了沉浸感和情感共鸣。

+ **紧张和动感:**

+ 在动作场景或紧张时刻，手持镜头可以增加一种动感和混乱感，使观众感到紧张和兴奋。
+ 这种技术可以有效地传达角色的不安、焦虑或兴奋等情绪。

+ **主观视角:**

+ 手持镜头可以模拟角色的主观视角，使观众感觉他们正在通过角色的眼睛观看场景。

## 14、dolly zoom变焦

“推轨变焦”（Dolly Zoom），也称为“滑动变焦”或“眩晕变焦”，是一种独特的电影摄影技术，它通过同时反向移动摄像机和调整镜头焦距，创造出一种令人不安、扭曲的视觉效果。以下是对“推轨变焦”的详细解释：

### 技术原理

#### 摄像机移动

当摄像机向后移动时，镜头焦距向前推进。

或者，当摄像机向前移动时，镜头焦距向后拉。

#### 视觉效果

这种同时但相反的运动，使画面中的主体保持相对不变的大小，而背景则发生显著的透视变形。

结果是，背景似乎在扩大或缩小，而主体则保持稳定，从而产生一种令人不安或迷失方向的感觉。

### 镜头语言的含义

#### 情感表达

“推轨变焦”经常用于传达角色的心理状态，例如：

- 眩晕感
- 恐惧感
- 困惑感
- 心理崩溃

它可以有效地表现角色对周围环境的感知扭曲。

#### 戏剧效果

这种技术可以增加场景的戏剧性和紧张感，尤其是在：

- 悬疑片
- 恐怖片
- 心理惊悚片

它可以强调一个关键时刻或揭示角色的内心冲突。

#### 视觉冲击

“推轨变焦”是一种引人注目的视觉效果，可以：

- 吸引观众的注意力
- 创造令人难忘的图像
- 增强电影的视觉风格

### 应用场景

“推轨变焦”已被许多著名导演使用，包括阿尔弗雷德·希区柯克（Alfred Hitchcock）在他的电影《迷魂记》（Vertigo）中。

在许多电影中，都使用这种手法来表现人物极度震惊，或者恐惧的心理。

也可以用于表现，人物在极度亢奋或者极度愤怒时，扭曲的视觉。

总而言之，“推轨变焦”是一种强大的电影摄影技术，可以用于创造令人难忘的视觉效果，并传达角色的强烈情感。
