# 网站需要隐私政策吗

> 来源：[https://docs.feishu.cn/docx/VTRUdYcR7o4AyXxWtX1cZRLEntd](https://docs.feishu.cn/docx/VTRUdYcR7o4AyXxWtX1cZRLEntd)

**-问：**求问各位大佬，如果网站并不收集访客个人信息，还需要配置隐私政策吗？这类网站，是不是可以弄个声明（说明并不收集个人信息），还是有其他的做法呢？

**-答1：**可以看看用不用**cookie**，都没有的话感觉没必要。

**-答2：**从监管看，网站现在**还查不过来**，**暂时不弄也没啥；从**公司形象来看，如果想做的规范一点，cookie banner和cookie政策搞出来，不收集个人信息这件事要深究一下，真的什么都不采集吗。有没有和百度一类的合作，有没有对流量来源做监测，品宣要不要看访问量，ip地址也不收集吗。

**-答3：****灵魂问题-真**的不采集吗？多问一句就发现还是采了。

**-答4：**我们还是会在**官网页脚**这边和登录注册流程放着隐私政策的。

**总结：那么多网站没做，不着急。**
