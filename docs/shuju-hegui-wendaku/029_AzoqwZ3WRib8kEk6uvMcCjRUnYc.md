
# 隐私政策弹窗告知颗粒度

> 来源：[https://docs.feishu.cn/docx/Zm47dEWLpo38XbxrzpQcGQhYnQc](https://docs.feishu.cn/docx/Zm47dEWLpo38XbxrzpQcGQhYnQc)

## 讨论记录

### 问：请教弹窗为什么要披露的这么细？

![](img/15f0c1f0eb5cba1692a352e52e580c34.png)

答1：金融类 app 需要特定收集这些字段用来前置风控。

### 追问：那为啥要在弹窗单独说呢？隐私政策披露不就好了。

答2：如果是预置应用（预装在系统中，开机自带的应用）需要在弹窗里全披露。

![](img/c2c531503c17e26af98d446a0092a888.png)

### 追问：一般APP没披露会被通报吗？

答3：不会，不作为违规项。但没披露，终端厂商过不了进网，不能售卖。

答4：懂了，如果我们不是预置APP就不用考虑这些。看上去这段话其实PP里写就可以但是放在首页重点提示会更好？

答5：符合预期 和超出预期 的区别。

答6：预装版每次发版都会有单独检测，弹窗里要写明很多内容，像是上网记录、mac地址等等都有披露要求。第三方sdk收的也要写在里面。

答7：IDFA也是风控用途吗？

答8：看看ydt 2407/ydt2408/ttaf 047。

答9：TTAF 077.5 最小必要评估评估规范 设备信息 明确列举的，安全风控不是IDFV吗。

答10：风控收集信息 有很多 idfa只是一个收集项 最终决定结果的 不仅仅是idfa。ios 的广告识别符，也有唯一标识性。

答11：笑死如果更严格讲，还想看下安卓端的弹窗会不会也说要IDFA。

答12：苹果使用多个化学元素作为变量名识别用户是否在欧盟 每天算一次。
