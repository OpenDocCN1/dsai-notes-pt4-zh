
# 隐私政策的维度

> 来源：[https://docs.feishu.cn/docx/MlBHd2dx7of2G0xWMNXcutb5nhd](https://docs.feishu.cn/docx/MlBHd2dx7of2G0xWMNXcutb5nhd)

- **问：** 哪位大佬了解为什么很多国外APP的隐私政策都是按照数据分类，而不是按照功能分类来写啊

- **答1：** 同感，做调研后发现和国内逻辑一样的太少了。

- **答2：** 我用你这个应用，就是用你全部功能，为什么限制不让用了？

- **答3：** 有没有可能 是 收集 和 使用是不同的。

- **答4：** 国外的逻辑更讲究透明度，要求隐私政策更简洁。其实一般用户也就关心总体而言收集了哪些信息，不会像国内我们一样细致到具体的功能及其收集的信息。

**总结：监管侧重点不同。**
