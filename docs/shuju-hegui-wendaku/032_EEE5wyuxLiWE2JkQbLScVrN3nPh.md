# 设备ID隐私政策的披露

> 来源：[https://docs.feishu.cn/docx/MyK7dxY8vo45bAxN04JcJyhrn9f](https://docs.feishu.cn/docx/MyK7dxY8vo45bAxN04JcJyhrn9f)

**-问：**求教现在SDK的披露要求是收集非PI的也需要列出来么~

**-答1：**不用吧，我们都是抄SDK官方的，然后自己扫一下，取并集。

**-答2：**最早要，后面放宽了。

**-答3：**我发现有一些sdk只是为了一些设备或者环境性能测试的目的，不是针对消费者的PI目的，但是这些sdk可能也要收集设备id。设备ID被划到个人信息，但是这个ID在这个场景里跟个人其实没有关系。

**-答4：**你很难和检查人员解释，他就看35273。

**-答5：**各种 id 为什么被视为个人信息？这块设备信息一刀切划为个人信息真的很迷。

**-答6：**多一事不如少一事，多写一个不会怎么样，少写就可能会有麻烦。

**-答7：**一些专属的设备id我觉得是算的吧，比如我手机和个人电脑的，因为特定情况能识别到我个人。

**-答8：**设备信息加括号要列明每种类型还不能概括的说 设备信息。

总结：虽然不一定是个人信息，但多写一点没有任何成本，所以还是写吧。
