
# APP合规检测工具

> 来源：[https://docs.feishu.cn/docx/Fpf7dhrwxozLEkx4e5dc9MN2n8g](https://docs.feishu.cn/docx/Fpf7dhrwxozLEkx4e5dc9MN2n8g)

**-问**：请问大家有用过比较好的数据合规检测工具吗？

**-答1**：中国电子技术标准化研究院出了一个APP个人信息保护合规评估工具，现在处于免费试用的阶段，但是是以问卷形式做的。

**-答2**：商业的主要针对APP的国内有百度史宾格，盘古，爱加密，梆梆，安恒。海外的比较全能是OneTrust，从前端到后端，还有治理。如果系统存量数据的就是数据资产发现和扫描打标了，但没太见过直接把风险识别集成到一个产品上来。可以参考这篇文章【2021年度中国数字安全能力图谱】

**-答3**：我知道PwC有IT审计服务，跑后台的。一般市场上卖的工具都是检测前台应用程序。

**-答4**：三方IT或安全审计如果深度一些的会查到后端，了解人工形式也会偏多一些，可能有的企业会一定程度避讳让外部系统接入到内部网络。
