# 海外iOS APP Store上架

> 来源：[https://docs.feishu.cn/docx/GZtgdtO0sokADAxCWugca9XqnJg](https://docs.feishu.cn/docx/GZtgdtO0sokADAxCWugca9XqnJg)

**-问**：除了苹果官方文档以外，有没有哪位大佬有海外APP Store上架隐私合规的文章或参考资料？

**-答**：iOS比安卓简单多了，根据境内的要求做合规就行了。因为iOS的违规收集个人信息较少，因此在收集上几乎不要太关注。主要需要关注交互的合规，这些按照国内的监管要求即可。再搭配上主流国家适配的隐私政策，差不多就够了。
