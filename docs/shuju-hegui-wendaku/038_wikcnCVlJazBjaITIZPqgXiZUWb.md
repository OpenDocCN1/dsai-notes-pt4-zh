
# 如何确保未成年人使用青少年模式

> 来源：[https://docs.feishu.cn/docx/HJTDdg2nZowU1Uxyftmc6atenqg](https://docs.feishu.cn/docx/HJTDdg2nZowU1Uxyftmc6atenqg)

## 问题

即使做了实名制认证，也无法规避认证完毕后，儿童从家长手中拿到手机使用。这种情况下可否将规定监护人将手机交给未成年人使用前必须将APP调为青少年模式？

## 回答 1

对于一般场景，有隐私政策关于未成年人条款作为兜底，加上产品页面必要的文字提示，让用户点击确认即可。作为平台，你已经尽到了你的义务，监管也不会把你怎么样的。对于重要敏感的业务场景，需实名制，包括提交身份证信息、照片、人脸验证等等。某境外软件，还有简单的加减乘除算术题验证，以确保使用者不是儿童。
