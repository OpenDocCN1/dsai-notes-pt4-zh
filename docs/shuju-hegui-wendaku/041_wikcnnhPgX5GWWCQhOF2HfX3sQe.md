# 游客模式信息留存

> 来源：[https://docs.feishu.cn/docx/CscRdtRUGoVIvPx4sEBccaMIn3X](https://docs.feishu.cn/docx/CscRdtRUGoVIvPx4sEBccaMIn3X)

**-问**：在APP首次运行，隐私政策的弹窗中。看到现在有的APP有提供不同意进入基本模式（或者游客模式），游客模式下用户可以浏览文章、视频等。用户浏览文章或者视频的记录按照35273的定义是个人信息，属于个人上网记录。这种合规吗？

**-答1：****游客模式本身就是救**济方案，正常浏览文章、看视频、是可以不收集个人信息的。如果在游客模式下收集的浏览行为记录属于个人信息。

**-答2：**监管的要求是**不收集任何个人信息的浏览模版**，复杂的App做不到。

**-追问：**那在隐私模式下，收集了IMEI，这个时候还不知道用户身份，这个算个人信息吗？

**-答3：**IMEI具有可识别性，**是个人信息****。仅浏览文字**时，改善游客模**式下的用户体验并不具**备正当性，收集个人信息不符合最小必要性原则。
