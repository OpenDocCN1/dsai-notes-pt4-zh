# 渐进式web 应用 (PWA) 属于APP吗？

> 来源：[https://docs.feishu.cn/docx/VZaMdBsupoLmjLxqRVScIsnRn0b](https://docs.feishu.cn/docx/VZaMdBsupoLmjLxqRVScIsnRn0b)

**-问：**渐进式 web 应用 (PWA) 属于我国法律规管的“移动应用程序”吗？

**-答1：****如果以APK**在安卓市场发布，或者APP Store发布，应该纳入范畴。理论上和使用的技术手段无关。

**-答2：**PWA可以封装成APK。换个思路，小程序也可以看做是PWA的一种。两者都是基于WEB技术，微信小程序在需要渲染性能高的组件时，会用本地的组件。简单说，小程序——Web为主，Native为辅；PWA——纯Web。

**-答3：**P**WA是纯web，也有很多ap****p**功能是做成了H5 webview放进来，这些我觉得都没啥实质的差别。web页面基于PWA封装apk后，不改变它是一个移动应用的本质。
