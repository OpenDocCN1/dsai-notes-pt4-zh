
# APP职业认证

> 来源：[https://docs.feishu.cn/docx/EUmLduWhkoBdIfx4kM5cD2nUnTp](https://docs.feishu.cn/docx/EUmLduWhkoBdIfx4kM5cD2nUnTp)

- 问：《互联网用户账号信息管理规定》第七条第一款规定：“互联网个人用户注册、使用账号信息，含有职业信息的，应当与个人真实职业信息相一致。”如何理解这个要求，以后会员之类的，是不是还不能收集职业了，现在都是随便填的哇。

- 答1：📕、抖音入驻职业类的，在填写简介那刻就会检测，进而要求提供与资料相符的职业证明，比如律师让提供律师证，发布内容过程中也会监测。如果认证和发布日常跟职业无关，会忽略～尤其是UGC PGC平台，不过也会有模糊界限（平台审核的避风港尺度，先有制度，至于完备到何种地步再细化）。

- 答2：知乎也是这样。

- 答3：个人理解上述要求是**面向用户**的，意即需要用户填写职业信息时应保真。至于职业信息采集的合法性是面向互联网平台运营者的要求，另论。
