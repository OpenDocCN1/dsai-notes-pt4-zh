
# APP跳转第三方链接的合规义务

> 来源：[https://docs.feishu.cn/docx/KPoydYdYVobnOdx3umLcq4iXnrh](https://docs.feishu.cn/docx/KPoydYdYVobnOdx3umLcq4iXnrh)

## 问：APP内图片链接跳转第三方页面，是否需要在跳转动作前加入提示页告知用户并取得用户同意？

## 答1：需要**提示**进入第三方页面。

## 答2：国标35273即有规定。

![](img/ddf5d3fa8d46e83c709c720ddbf9f10a.png)

## 答3：我理解监管的重点在于启动屏的广告页跳转及app下载合规：特定热区+关闭功能+提示跳转保障知情+涉及app下载的，需要展示6要素并有明确的下载按钮，用户点击后方可下载，不得默认下载。

## 答4：还可以参考这篇：规范弹窗、启动屏等广告形式，中国广告协会相关自律标准即将出台。
