
# 版本号的命名规律

> 来源：[https://docs.feishu.cn/docx/CcA7dy5lSo7Icqx4fAtcDDbfnmf](https://docs.feishu.cn/docx/CcA7dy5lSo7Icqx4fAtcDDbfnmf)

- 问：请教个边缘问题，版本号设置这么长（5.30.5.0004），有什么讲究么？

- 答1：每个公司自己迭代风格不一样吧，看开发心情。我玩的一个游戏更了4.0版本 原本正常版本发布 修bug出了4.0.1 4.0.2 小版本号迭代更新 然后4.0更新一周后出新剧情 小版本号直接跳到4.0.255。（其实这个.255是剧情需要。

- 答2：版本号都看开发心情的。前2位的是大版本号。比如8.1.0.2。8是大版本，一般性要大老板拍板。

- 答3：大版本发生变化，CCRC认证失效，要重做。
