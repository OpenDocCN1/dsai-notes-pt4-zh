
# APP检测机构推荐

> 来源：[https://docs.feishu.cn/docx/HWKIdQYNWobVpzxs0JicnJpqnJd](https://docs.feishu.cn/docx/HWKIdQYNWobVpzxs0JicnJpqnJd)

**问：**除了梆梆安全，各位还能推荐几个同一水平和报价的app隐私合规检测机构吗，谢谢。

**答1：**公安三所，一级支撑单位。

**答2：**我们用梆梆和观安。后者，主业放在安全防护而不是隐私合规上。

**答3：**爱加密。

**答4：**海云安，深圳网安，北京汉华信安。

**答5：**捷兴信源、安天、百度史宾格。

**答6：**此外，各大律师事务所及咨询公司，也具备不可替代的作用。
