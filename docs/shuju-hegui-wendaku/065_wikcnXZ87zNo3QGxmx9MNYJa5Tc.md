# APP启动指什么

> 来源：[https://docs.feishu.cn/docx/Ocvqd7Bn9oWyCVxB7PDcdn14nHg](https://docs.feishu.cn/docx/Ocvqd7Bn9oWyCVxB7PDcdn14nHg)

**-问：**APP每次启动, 这里的启动，到底怎么理解？是指进入APP用户须知界面后，还是指使用点击触发这个APP的功能时呀？

**-答1：**启动可能有三类，应该都要覆盖：自启动，关联启动和后台唤起。

**-答2：**一般分为冷启动和热启动。冷启动可以理解为这个App没有在后台，第一次打开。热启动可以理解为App在后台，然后启动切换到前台。
