# 通报后的整改期限

> 来源：[https://docs.feishu.cn/docx/QLhHd25xcomQ8XxSJlPc3Aq8ntf](https://docs.feishu.cn/docx/QLhHd25xcomQ8XxSJlPc3Aq8ntf)

**-问：**话说各位有没有关注过网信 通管通报后通常给多久的整改期？5个工作日？

**-答1：**随机。

**-答2：**网信办通报app好像一般是15个工作日整改期。

**-答3：**通管是工信部要求的，全国统一。

**-答4：**看看《移动互联网应用程序个人信息保护管理暂行规定（征求意见稿）》

> 第十六条 发现从事个人信息处理活动的相关主体违反本规定的，监督管理部门可依据各自职责采取以下处置措施：

> （一）责令整改与社会公告。对检测发现问题App的开发运营者、App分发平台、第三方服务提供者及相关主体提出整改，要求5个工作日内进行整改及时消除隐患；未完成整改的，向社会公告。

> （二）下架处置。对社会公告5个工作日后，仍拒绝整改或者整改后仍存在问题的，可要求相关主体进行下架处置；对反复出现问题、采取技术对抗等违规情节严重的，将对其进行直接下架；被下架的App在40个工作日内不得通过任何渠道再次上架。……

**-答5：**分7天 和1个月不同版本。
