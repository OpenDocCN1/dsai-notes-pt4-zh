# APP分发平台如何理解

> 来源：[https://docs.feishu.cn/docx/SMLcdp3X3odBpbxIaIbcUADGnZb](https://docs.feishu.cn/docx/SMLcdp3X3odBpbxIaIbcUADGnZb)

**-问：**这个没理解错的话是分发平台应该去备案，而不是app吧？

> 四是严格规范备案要求。重点打击未经备案提供应用程序分发服务的行为。对通过浏览器以链接或二维码等方式提供下载服务的，须按照《移动互联网应用程序信息服务管理规定》进行备案。

> 公众号：网信中国中央网信办部署开展“清朗·移动互联网应用程序领域乱象整治”专项行动

**-答1：**是的，但是，“平台”门槛很低。

**-答2：**给你个链接，这个链接可以下载我司的app。这个链接变成了“平台”？因为，这个链接“提供了app的发布、下载等分发服务？”此时该二维码/链接变成了“移动互联网应用程序分发平台”？

**-答3：**可以看看这篇：App通报中技术问题的背景原理及修复方案（2）就是那种 APP里面能再下APP的，快手不也老有，微博也是。不上架，但提供一二维码，或者链接，扫进去点进去，可以下载这一款app。

**-答4：**内部IP只要用80端口也要备案，一个道理。因为APP备案主要靠分发平台，而不是靠ICP备案的ISP。夯实分发平台责任。平台，在我国互联网监管政策语境中，是个魔幻词。不这样的话，监管对APP没有抓手。网站ICP备案是有监管抓手的。APP只能靠分发平台。

**-答5：**如果一家app主页提供直接app原包下载功能 那这个主页host server也要备案么。那看来是“统一监管”的思路了 All glory to CAC。

**-答6：**其实这事也好办，就去大胆的备，给备就备上。搞一套完整的合规机制，对照分发平台。

**-答7：**网页下载的以后都要变成分发平台？

**-答8：**功能触发打开\跳转下载的，应该不算分发。
