# APP开发者是否等于运营者

> 来源：[https://docs.feishu.cn/docx/Z7ZMdXt2qoNPVUxhskgcEy7Onph](https://docs.feishu.cn/docx/Z7ZMdXt2qoNPVUxhskgcEy7Onph)

**-问：**App的运营者，和工信部App通报里的“应用开发者”，是不是等同的呢？比如《常见类型移动互联网应用程序必要个人信息范围规定》规制对象是App运营者，但是工信部通报的是应用开发者。164号文里的表达是“App服务提供者”。

**-答1：**“谁主管 谁建设 谁运营  ”谁负责，是这个逻辑。

**-追问：**监管是怎么判断“谁主管 谁建设 谁运营”呢，看隐私政策里披露的运营者，或者应用商店里披露的开发者和运营者？如果开发者和运营者不是同一主体呢？或者不同应用商店里填的是不同主体？或者隐私政策里出现了两个主体？比如淘宝App…华为应用商店里写的是淘宝中国，应用宝里填的是浙江淘宝。然后它的隐私政策里，我们指的是这两个主体both。如果这种情况，工信部要通报的话，会列两个主体吗（目前工信部的通报，我记得都是一个App对应一个主体。之前中国消协的通报里，是用了两个主体。

**-答2：**开发者跟运营者不一定等同，而且不同渠道同一软件的运营者也可能不同。

**-答3：**通报不都是明确了渠道和版本号的吗，所以你说的淘宝app这种不同渠道不同主体的情况有啥问题。

**-答4：**所以，如果工信部也是从官网下载的，然后官网披露主体是两个，工信部的通报里也会出现两个主体吗。不同渠道的同一软件的运营者，会不一样吗？这种情况，技术层面，是不是若干主体在共同运营一个App呢？

**-答5：**有可能的，不同渠道可能用的不同主体去注册的开发者账号再上传app。

**-答6：**渠道一般只是从上传主体判断运营主体。另外，同一应用存在不同包体的情形也很常见，不同包体可能会对应不同运营主体，这个在游戏行业非常常见。

**-答7：**比如b站渠道，taptap渠道，官方渠道，硬核渠道之类的。

**-追问：**那如果App违法了，它的责任主体，要怎么区分呢？是淘宝中国or浙江淘宝，还是both？

**-答8：**监管看你这个违法行为是不是两个渠道的应用都是存在的。一个包体联合运营也很常见，用户协议披露主体、官网主体、收款主体、渠道上传主体。最多时我们一个案件有八个被告，针对同一包体。
