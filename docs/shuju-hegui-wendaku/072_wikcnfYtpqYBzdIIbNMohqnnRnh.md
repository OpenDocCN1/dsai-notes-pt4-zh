# APP所有者的理解

> 来源：[https://docs.feishu.cn/docx/YIPvdHoIqoFfhaxklsAcmQfunhg](https://docs.feishu.cn/docx/YIPvdHoIqoFfhaxklsAcmQfunhg)

**-问：**请教个问题，大家怎么定义和区分APP所有者和运营者的？是不是以软著的归属作为区分？

**-答1：**所有者就是个伪概念。是软件著作权的所有者，还是软件收益的所有者，或者是能够决定软件日常运营的主体。君合之前的理解是这样：

> 2.《应用程序规定》中的信息服务App提供者的概念不仅包括相关App的运营者，还有可能包括相关App的所有者（通常理解为相关App的著作权人）。实践中，在通常情况下，App的所有者和运营者通常是同一主体，但在某些特殊情况下，也可能分别为不同主体（例如制作App的主体并无ICP证，而需委托具有ICP证的另外一个主体进行App的运营）。在此情况下，App的所有者是否仍有义务遵守和履行《应用程序规定》，此问题并不明确。

> [许蓉蓉、张岳，👸号：君合法律评论君合法评丨](https://mp.weixin.qq.com/s/_1PB1HdWE66cbLqonJI2sA)国内首部App监管专项法规发布-《移动互联网应用程序信息服务管理规定》解读

**-答2：**对的，问题就是软著所有者和收益所有者不一定一致。这个时候谁是所有者，怎么区分。法律文件中要求非软著所有者但是收益所有者承诺是App的所有者。

**-答3：**一些to B或者G的企业，还要接受客户委托开发（定制）APP，然后有些也在国内外或大或小的应用市场发布，但是其实这个定制化程度并不高，有时候就是改改logo和UI，著作权我理解肯定还是归企业的，但是app的使用和管理，包括数据存储又与发布者分离，最后APP算不算企业的就很困惑。公司数据合规负责人原话是app整改合规没法做，因为找不到这个池子的边在哪。

**-答4：**这种版权归谁其实很难说，有可能是一堆开源的轮子攒起来。
