# APP境外上架隐私政策语言要求

> 来源：[https://docs.feishu.cn/docx/HH3LdAdY9oGMyrxpTjycoZWondh](https://docs.feishu.cn/docx/HH3LdAdY9oGMyrxpTjycoZWondh)

**-问：**请教个问题 app在北美上架，隐私政策语言应该是英语对吗，中文不行？

**-答1：**是，应该以当地国家的**官方语言**为主。

**-答2：**如果是面向北美用户，**英文**一般就可以（如果应用内有针对法语用户的法语服务语言和内容，则建议同步补充法语版本更为合规）；如果考虑还有懂中文的华人用户、应用内有中文语言，再增加中文版也可以，但同样需要考虑是哪一种“中文”的文本。

如果**是面向其他法域**，在线协议的语种设置则需要结合用户终端适配语种、应用内提供的服务语言、当地法定语言、对隐私政策语种的强制性要求、当地市场普遍做法、合规成本等来综合判断，不能简单默认为“英文即可”，否则至少“告知透明度”这个原则要求很难达成。

简单说，如果没钱、应用内有英文服务语言、目标市场是多语种法域集合（不是只有一个小语种国家），那就是“英文”作为基操配置；如果有钱或风险偏好低，那就综合上述因素多配几种语种，土豪畅饮的意思。

**-追问：**协议内容 也需要适配 当地法规对么？

**-答3：****一般来说隐私保**护的适用法不能经约定排除，确实要遵守当地法律。但同理，综合风险偏好、监管尺度、用户规模、合规成本等多个因素来选择合适的司法辖区法律来作为在线协议草拟的基准线。土豪随意。这个基准线的选择很考验法务对业务的理解和把握、对适用法的理解和把握、对成本和风险的控制，是个综合平衡的技术活儿。

而且业务还在不断更新，刚选好的基准线没过多久就变了，需要再次评估，更吐血。

**总**结：应该以APP上架所在地官方语言及法律为准，达到基本要求即可，若预算宽裕还可以搭配其他语种提升用户体验。
