
# APP首启弹窗

> 来源：[https://docs.feishu.cn/docx/KSVUdU4XAoC667xjZ8ickBKWnae](https://docs.feishu.cn/docx/KSVUdU4XAoC667xjZ8ickBKWnae)

## 问：用户首次进入app的这个弹窗内容文本，目前有什么标准或监管案例说这部分要怎么写不？我发现这部分写的很详细的也有，写的很粗略的也有。

![](img/caed21c38d0e3cf1095163199fec2070.png)

## 答1：看你要不要作为终端厂商的预置App，预装了就要按ydt2407 2021《移动智能终端 安全能力技术要求》的标准写。不预装，按常规的写，没具体要求吧。

## 答2：有老师指出这个是**悖论**，基于让用户告知提醒的目的，尽量写多点，但是框有限啊，只能形式上做到，那后续协议勾选还有没有意义了，多此一举了？另外基于消保格式条款，这里尽到显著，提醒，确认。

## 答3：携程有个经典案例：个保法出来前戏被被起诉滥用个人信息，虽然按消保法格式条款判的。绍兴中院二审。

## 答4：35273里面有写个人信息主体首次打开产品或服务，注册账户等情形时，宜通过弹窗等形式主动向其展示个人信息保护政策的**主要或**核心内容，帮助个人信息主体理解该产品或服务个人信息处理范围或规则。有一些检测机构也把这个纳入检测范围，我理解这个是建议项。
