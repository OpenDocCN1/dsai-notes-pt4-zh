# 不更新不给用的合规性

> 来源：[https://docs.feishu.cn/docx/Tk7Kdjmd2oklfIx3GMpcM34FnfR](https://docs.feishu.cn/docx/Tk7Kdjmd2oklfIx3GMpcM34FnfR)

**-问：**目前做APP强制更新（不更新不给用）是合规的嘛？好像没看见通报。因为调研了一些些主流app，不更新不给用/不更新不给用新功能是普遍的。但是因为隐私政策链接的唯一性，会导致旧版本和新版本的隐私政策不适配。

**-答1：**因为对企业而言同时**运维多个版本的app也不现实**。

**-答2：****强更关注个人信息**使用目的发生变更时重新拿个人同意。隐私政策历史版本查询也很常见：小米、🛰️、阿里都做了。
