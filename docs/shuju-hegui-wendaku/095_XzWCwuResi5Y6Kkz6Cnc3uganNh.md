
# APP备案与服务器本地化

> 来源：[https://docs.feishu.cn/docx/VMRxdOqkxoHOu8x0iatc1cmRnJh](https://docs.feishu.cn/docx/VMRxdOqkxoHOu8x0iatc1cmRnJh)

**问：**我想问下备案的APP是不是服务器必须要在国内？

**答1：**实操起来就是这样的，域名注册在境内公司名下，服务器也在境内。

**答2：**我了解到的是必须要在国内，否则无法备案。

**答3：**是的，出境项目没做到的事工信部做到了。这个比以前的ICP还过分的一点是网站至少没有应用商店这个抓手来管理上架，中国境内的自然流量还能分配到global site那边，但是App因为加了商店这一层，导致这个备案的后果是避无可避。现在确实没有其他办法，只能在sever层面垒一点本地成本，当然如果有高人还望告知解决一下有没有破的方法。

**答4：**本地化存储最大的抓手。

**答5：**真要搞的话，网站/社媒/门店挂个APP下载二维码，不上应用商店呗。

**答6：**除了商店，还不提供网络接入服务吧。

**答6：**未来系统会限制安装吗，或者云服务商会断网吗？

**答7：**系统层面的限制目前来看，暂时不会，否则你们翻不了墙啊？这种的云服务商就不在国内，否则就没必要了。

**答8：**未来系统可能直接提示APP未备案，或者阻止安装。

**总结：**真的是本地化最大抓手。
