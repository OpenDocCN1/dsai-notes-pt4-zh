
# ICP备案的检查方式

> 来源：[https://docs.feishu.cn/docx/GSFydAlI4oIn1jxoWBFcQWUWnCe](https://docs.feishu.cn/docx/GSFydAlI4oIn1jxoWBFcQWUWnCe)

## 问：请教个问题，app备案监管怎么审查啊，如果我的应用不是在三方应用市场上架，也没有界面。

## 答1

如果不在应用商店上架，app所在一级域名备案过，那就不会被云服务商阻断网络。之前我问阿里云，是这么跟我说的。其实这样严格来说，是不符合工信部通知的要求的。可以让应用商店检查呀，让阿里云，腾讯云等等检查呀。

## 答2：接入服务商

看移动端的监管思路，全链路。

## 总结

除非用Azure，AWS这些域外的云服务（这样会被墙），其他的方式总有管控方法。
