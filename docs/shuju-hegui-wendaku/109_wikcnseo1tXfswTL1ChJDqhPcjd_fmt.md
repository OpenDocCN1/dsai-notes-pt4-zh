
# 手机厂商SDK检测

> 来源：`https://docs.feishu.cn/docx/QwXidp2cxovspzxWcftcCCNOnjg`

**问**：手机厂商技术上有没有办法事前审核SDK的合规性？成本如何？目前的实际流程上大厂有没有设置这道审核呢？

**答1**：现在就是都会在引入SDK之前做PIA嘛，合同约束，SDK有违规行为在一定程度上也是可测的。

**答2**：厂商审查义务高低，并不影响SDK想干坏事，你永远阻止不了。

**答3**：厂商审查SDK，应该是审查自己的用的吧？和其他App运营者审查SDK有啥不一样的吗。如果审查了认为没问题，但SDK实际做的事与审查时候做的不一样的话（或者说超出了合同约定的范围），那至少厂商能抗辩嘛。

**答4**：就是要尽到最大实质审核义务，才有免责的合理依据。

**答5**：如果本身厂商审查义务不高，比如ISP无法控制也无法阻止，但已经尽到门槛内的审查义务，适用避风港原则。那么前面所采取的PIA、合同、监管等，在应对时证明主观还是客观、审查，上下游获益综合判断。

注：截至工信部及国标41391对SDK引入在2023年3月已提出更高的要求。
