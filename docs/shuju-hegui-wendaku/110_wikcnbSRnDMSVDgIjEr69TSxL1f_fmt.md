
# SDK和API的关系

> 来源：[https://docs.feishu.cn/docx/E6cbduV9Vo4h1bxAZXNcQnsenHb](https://docs.feishu.cn/docx/E6cbduV9Vo4h1bxAZXNcQnsenHb)

- 问：`SDK`和`API`的区别，我一直都在CSDN上反复看技术小哥的解释，但还是不太了解。

- 答1：`API`的解释有很多。比如暴露在公网能提供服务的接口，以及在应用/程序内部，给外部或者内部提供服务的接口。

![](img/5890df5f8c96664466a1b7d4842e913e.png)

比如说这种。我们就管他叫`API`。再举一个`SDK`和`API`关系的例子。

![](img/0278d1a5e000e591759cb6077ab958c7.png)

就是刚刚贴的这个图。百度定位`SDK`。整个`SDK`里面都是各种功能和逻辑的实现，怎么去调用这些功能，就是通过`api`来获取。

- 答2：我脑子里一直把`SDK`想象成一个包，`API`就是上面的某个线，跟别的什么线搭上，就可以使用功能了。

- 答3：看到过一个比较形象的比喻，将`SDK`比作奶茶的话，`API`就是吸管。

- 答4：假设有个公寓，房间从101，到110，总共10间房间，`API`就是对应钥匙。通过他能走到公寓特定区域。而`SDK`就是整个公寓。
