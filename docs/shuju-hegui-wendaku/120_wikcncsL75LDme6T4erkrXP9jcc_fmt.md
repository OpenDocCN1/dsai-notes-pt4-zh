
# 本地化部署的SDK披露

> 来源：[https://docs.feishu.cn/docx/EPTQdIIPgoVsFhxKtndcv8n0nDh](https://docs.feishu.cn/docx/EPTQdIIPgoVsFhxKtndcv8n0nDh)

**-问：**请问大家，如果本地化部署是第三方SDK，不向第三方传输信息，还需要在隐私政策披露在SDK清单中吗。

**-答1：**需要披露。

**-答2：**共享个人信息字段填无就好。因为检测机构是通过工具扫描的，只要扫描识别出来，清单没有，就是未披露，通报。自己开发的sdk，开发不一定会认为是sdk，没和安全说。之所以会出现是因为存在跨部门共同研发的情况。另外研发一方以sdk作为产出物交付。

**-答3：**要谨防SDK里面包了SDK得情况，我们客户就是因为某厂的SDK里面嵌套了某厂的另一个SDK被检测出来。
