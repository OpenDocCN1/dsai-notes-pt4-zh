
# 极光/个推SDK历史处罚

> 来源：[https://docs.feishu.cn/docx/AGjFde2wboHlMMx3Z2Hc0c2Xnub](https://docs.feishu.cn/docx/AGjFde2wboHlMMx3Z2Hc0c2Xnub)

- **问：**极光/个推，过往有因为隐私合规被监管通报处罚过么

- **答1：**有被深交所处罚财报造假

- **答2：**印象有个比较早的，大概 19～20 年，后面专门做了整改。

- **答3：**看这里，关于35款App存在个人信息收集使用问题的通告。

- **答4：**

> 工业部信息通管局副局长鲁春丛曾于去年11月在会上提到，**中小企业App整改应对能力不**足，比如使用违规收集个人信息的第三方组件，涉及腾讯、极光、个推、小米SDK。
>
