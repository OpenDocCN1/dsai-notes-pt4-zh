
# 小程序主体责任

> 来源：`https://docs.feishu.cn/docx/Gs4udIf8LooBwRx9XqHcxBYSnAb`

- **问：**🛰️小程序对监管承担责任，是不是全部看登记主体啊？如果登记主体是A，底层app是B，除非明示A共享给B，否则都是A兜底对吧？

- **答1：**是，登记谁就是谁，**登记的是实名认证**。

- **追问：**更像是一种SaaS平台使用，可能是PaaS?但是外面看的都是A。

- **答2：**有很多**负面判例**，比如：“为了用户好”擅自在关联产品之间共享用户账户密码和订单构成侵权。

- **答3：**关联产品跳转要**单独授权**。

- **答4：**PaaS平台上，是你用了这个平台上的组件来搭建成的一个SDK或者应用**之类的**，底层是人家PaaS平台的，但也会有个实名登记的步骤，虽然非强制，对外来说还是你，非平台。还有一种是中间件的形式，但这个更多是被认为是SDK了。但前台实名主体和底层技术提供者的责任承担真的得case by case了。
