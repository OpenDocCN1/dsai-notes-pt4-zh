# “每次使用时允许”如何理解

> 来源：[https://docs.feishu.cn/docx/J5LIdf2KjouWEqxcqTtcKgCRnNe](https://docs.feishu.cn/docx/J5LIdf2KjouWEqxcqTtcKgCRnNe)

**-问：**各位大佬有没有了解权限管理的，手机系统权限的“每次使用时允许”该如何理解，我的理解是杀掉进程后再进去APP就需要重新授权了，但发现有一些APP杀掉进程后再进APP还是有授权的。

**-答1：****如果用户在对话框中选择仅单次，系统会向应用授予临时的一次性权限。当应用的 Activity 可见时，应用可以继续访问相关数据。如果用户随后将应用转到后台，则应用对相关数据的访问权限会在一小段时间后被撤消。**如果在 Activity 可见时启动了一项前台服务，并且用户随后将应用转到后台，则应用可以继续访问相关数据，直到该前台服务停止。如果用户在应用失去对相关数据的访问权限后没有让应用回到前台，或者如果用户撤消了一次性权限，则系统会终止应用的进程。

**-答2：**杀进程不会导致权限重置，需要在手机设置界面重置权限。如果后台重置也无法再次触发权限弹窗的需要重装app/删除数据重启。“每次使用时”，如🛰️聊天框内每次按住说话会触发麦克风权限。

**-答3：**这个麦克风权限的触发好理解，但系统内何时关闭，比如这句语音说完以后麦克风权限是自动关闭的吗？然后下次说话时再唤起麦克风功能，就这样循环着，循环着吗？

**-答4：**点一次触发一次，**不循环**，随用户操作的。如果用户没有主动触发，app自己打开了麦克风/相机，那就是另外的问题了。循环采集勉强能够忍受的场景，个人觉得唯一只有地图导航类app（也要看具体场景），其他都不合规（也有可能是我没有遇到）。

**-答5：**明白，地图导航类APP，理论上也是要先用唤醒词以后再启动权限，再涉及个人信息采集（可能），在它的知识库搞不定的时候，也许就没办法进行下一步交互了。
