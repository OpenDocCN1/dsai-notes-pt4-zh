# 背调机构查征信的合规性

> 来源：[https://docs.feishu.cn/docx/LLFfdPFjkou40YxfCD8cdz9nnac](https://docs.feishu.cn/docx/LLFfdPFjkou40YxfCD8cdz9nnac)

**-问：**大家有关注过第三方背调机构是如何获得员工信息的吗？看了一下有些背调公司的背调报告，信息采集维度特别广，甚至还有征信记录...细思极恐。查征信这一块就很迷了，持牌征信机构肯定不让直接接，不知道是不是会跟一些小型接入机构合作，外放接口查到的。

**-答1：**背调公司会接入很多公开/收费的数据库的。

**-答2：**查征信不是要本人同意吗。

**-答3：**直接从个人信用信息基础数据库获取应该不太可能，不排除被调查者之前向雇主或者其他机构提供后，被流转泄露出去了。或者某些金融科技公司，在授权调去基础数据库的征信信息后，利用技术缝隙复制了征信信息，再同自己数据库中收集的行为数据、在本平台的金融活动数据合并、去重、处理，再输出“信用”报告、“信用”评分等产品。

**-答4：****有些金融**科技公司可能体系内就有一两家接入征信的金融机构，然后违规查询或者外放接口，或者变着法子对外输出综合信用产品、分值之类的

-答5：说到征信，我还蛮好奇征信断直连以后，平台方和征信持牌机构怎么完成数据交互的。比如说风控模型和策略可能需要分段部署，然后平台方其他非金融的业务线数据可能难以获得用户授权对外传输。

**-答6：**反正之前我如果进一步问到他们使用的database的合法合规性，他们只能给个基础承诺，没法继续详细下去了。

**-答7：**这一行能做到发邮件让你签授权书或者勾选他的隐私政策，可能已经算较为合规了。尤其是一些大的背调公司可能是跨国的，服务器在境外，再聊下去就细思恐极了。

**-答8：**接前面讨论的征信，分享一个雇主视角解法：公司确实有需求的，比如需要了解招聘的财务、商务等岗位员工有无大额借款，可以在背调结束后，确认会要，再请候选人自己提供一份征信记录。

**-答9：**企业有需求可以让候选人主动提供，但和征信机构能查还是两个维度的事情。
