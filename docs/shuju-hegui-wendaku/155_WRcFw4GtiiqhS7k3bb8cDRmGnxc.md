# 背调机构候选人资料留存时间

> 来源：[https://docs.feishu.cn/docx/S0VidjNtOoPBHJxC6zNchPrunR2](https://docs.feishu.cn/docx/S0VidjNtOoPBHJxC6zNchPrunR2)

**-问：**背调机构帮助公司在员工入职时进行背调签数据保护协议，应该让他们这些背调资料保存多久比较好呀。从个人信息保护角度来看，越短越好。但从责任追溯角度来看，又长点比较好。比如说之后发现员工造假，背调机构不够尽职，追求背调机构责任？

**-答1：**可以参考一下这一篇：[应聘人员资料应留存多久](https://mp.weixin.qq.com/s?__biz=MzU1MzAzNzcwNw==&mid=2247487298&idx=1&sn=63921b4389e5e8f30030e4c35790b506&scene=21#wechat_redirect)**。里**面有个Michael Page的隐私政策，直接写了3年。

**-答2：**背调的场景，从商业利益角度，是**不存最好**，你丫凭什么存我候选人甚至是未来正式员工的信息，万一交叉验证了呢。事后有违约追责无需背调机构来印证啊，合同写死，我说啥就是啥，你是甲方啊。万一背调机构违约，要背调机构调取存的资料来举证自己这一方？？    你方追责，在举证上，你方保存好资料就行了吧，提出初步证据，举证责任转移到背调机构：没有违约。我可能是比较强势的甲方，我们以前合作的几家背调机构一律不允许被调机构保存已入职员工的任何资料，如果是高级职位候选人的资料也不允许保存。目的就是避免背调机构反手卖信息（现状就是背调机构通过单独授权还是会保存大量的候选人信息，然后拿去干嘛大家都懂的）。

**-答3：**公司可以通过保留法律文本、**双方沟通记录**等可以留痕的方式举证自己履行了监督义务吧。

**总结：别留。**
