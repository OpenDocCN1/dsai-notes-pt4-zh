# 内部调查看员工邮件

> 来源：[https://docs.feishu.cn/docx/J4jxdyKDMoBBfnxqJzWcBuwfn4f](https://docs.feishu.cn/docx/J4jxdyKDMoBBfnxqJzWcBuwfn4f)

**-问：**请教一下，因内部调查调取已离职员工的工作邮箱里的内容，存在啥风险吗？公司员工手册和相关政策均不完备。这个员工个人信息的删除期限马上要到了，内审的人急坏了

**-答1：**这是能公开讨论的么，干就完了。缩手缩脚，这不是君子自圈束缚么。问就是不合规。

**-答2：**工作邮箱是不是还好，甚至还可以往履行劳动合同所必需去论证。

**总结：保持默契，别问。**
