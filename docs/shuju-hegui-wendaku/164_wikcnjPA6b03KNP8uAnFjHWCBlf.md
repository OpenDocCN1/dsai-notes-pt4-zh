# 员工聊天记录监控

> 来源：[https://docs.feishu.cn/docx/V3rUdOWqZor8vpxeFsCcB0Cunlg](https://docs.feishu.cn/docx/V3rUdOWqZor8vpxeFsCcB0Cunlg)

**-问：**教下大佬们之前有谈论过关于公司电脑员工个人微信信息的问题吗   具体而言  比如说员工在职期间用个人微信开展工作，可能会留存一些公司相关的信息，员工离职后，公司可以访问留存在公司电脑上的信息吗？

**-答1：**以我朴素的价值来看，保存在公司电脑内的可以，员工个人储存介质内的访问可刑。

**-答2：**还是先明确一下这类信息是以什么样的方式在公司介质上进行留存的。之前很常见的操作是在涉密岗位上面的办公电脑安装监控软件，然后员工微信上面的一些敏感信息可能会被截图留存，因为这里监控软件是不定时会对桌面进行截图的，那这种截图它可能会在员工离职之后，仍然保存在公司的电脑当中。那如果员工没有授权你们登录的话，你们怎么访问这类信息呢？即使是电脑上面保存有相关的记录，还是你们只是根据文件夹访问缓存或已下载的内容。我觉得你们公司的这个问题，关键还是要做好离职的一个文件交接，如果文件能够交接好的话，那就没必要跑人家的微信缓存里面去翻材料了。比如公司跟涉密岗已经签了协议，也明确的禁止了通过这种没有加密的软件发送公司涉密的文件，那种情形下，公司有可能拿这个缓存去证明员工的这个发送记录，这个还是有一定的正当性的。

**-答3：**公司要求用办公软件，但员工却用了私人软件。公司如果不调查私人软件，也不会知道员工用私人软件传输资料吧。

**-答5：**办公电脑pc微信应该可以设置留存传输文件、聊天记录啥的吧，这个应该是可以抓取备份的。但是针对个人微信，这些材料无法区分哪些是个人的哪些是公司的材料，要流程化拿不到授权的。要做调查那是另外的问题了。我本来想说企微的，界定个人微信就没办法了。

**-答6：**有的公司有很清晰的政策的，员工入职都签署。

**-答7：**规章制度里面会限定公司办公电脑仅能用于工作目的，公司有权查阅这类表述。

**-答6：**如公司态度明确不许员工使用微信进行公事沟通，原则上要用政策的形式禁止此类行为，并将其关联到员工手册的违纪行为中。管理措施上电脑上不能安装微信客户端，禁止上传压缩文件等。如果公司的态度是允许，那其实管理难度是非常大的。最极端的做法就是让员工事前签同意函同意公司检查微信记录（应该没人会签吧）。

**-答7：**可以看看这个案例：[员工行为监测纠纷案例：企业利用软件监控员](https://mp.weixin.qq.com/s?__biz=MzI5Nzc5MTI3MQ==&mid=2247513001&idx=1&sn=49d6fb054bd53717503e57ec5abcbee7&scene=21#wechat_redirect)工电脑属于自我管理行为，不侵犯员工隐私权。涉及将“上班时间使用办公电脑的聊天记[录”公证并作为证据提交”。可能涉及](https://mp.weixin.qq.com/s?__biz=MzAxODQ3NTIzOA==&mid=2653488662&idx=1&sn=391e9b28e31dd6b1e714db8ae2a50417&scene=21#wechat_redirect)不一致结论的案例也存在，但是涉案的是个人设备，而且需要进一步确认案例的具体信息，详见：通过不当手段获取员工的微信聊天记录，是否构成侵犯个人隐私￨天津劳动争议律师。另外案例一的评论区也指出了一些需要考虑的新问题。

**-答8：**有公司是如果员工要用个人微信登陆公司pc端，必须经公司事先审批，并授权公司可以留存微信登陆以后的信息。

**-答9：**其实颗粒度的把握，真的是很重要的一个问题。写的太明确，以后员工离职的时候都会清空公司电脑里面的微信缓存。而站在内审跟风控的角度来讲，清空这类缓存有时候反而不是愿意看到的。
