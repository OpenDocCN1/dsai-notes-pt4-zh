# 处理员工亲属个人信息的合法性基础

> 来源：[https://docs.feishu.cn/docx/G8hLdY3BVomeOexLmzScdlrEnif](https://docs.feishu.cn/docx/G8hLdY3BVomeOexLmzScdlrEnif)

**-问：**咨询下，企业员工个人信息授权单独同意函需要包涵员工亲属个人信息授权吗，免同意中有实施人力资源管理所必需，所必需包含了亲属个人信息了？由员工授权使用员工亲属的个人信息，这样应该行吧。每个企业都会遇到这个问题吧，怎么解决呢？比如保险福利，帮家属投保，搜集了亲属个人信息。

**-答1：**理解不包含，但如果找亲属签也太麻烦了。法理上不行吧，为啥员工可以代亲属授权。实践中大家可能就这么做了，法不责众。

**-答2：**员工确认已获亲属同意，有纠纷的话，员工担责。实务角度说，要看这种风险发生的场景和可能性，来考虑合规方案设计的边界…

**-答3：**用人单位收集员工亲属个人信息是不是超出最小必要原则了。

**-答4：**亲属信息不能用人力资源管理吧。

**-答5：**极端一点的场景，员工在办公场地猝死之后，通知家属，这个可能也算是需要提前收集亲属个人信息（紧急联系人信息）的场景。

**-答6：**这个有点意思，类似的场景车中2C提供访客模式，车主借车给朋友/找代价/家人通过访客模式进入，服务提供方对于这种并非服务或同意直接相对方个人数据主体的个人数据：1.是该等个人数据的处理者么？2.是的话，处理的合法性基础是啥？

**-答7：**有点像贷款下的紧急联系人，收集时候是借款人确认已获主体授权对贷款人提供，使用场景下严格限制用途和方式。

**-答8：**收集亲属个人信息，也是限于“必要”范围内，比如紧急联系人及其联系方式，如果再进一步收集家属工作单位，没有特定正当目的的话其实就已经属于是超范围收集了。HR信息采集系统也是需要配套进行调整的。
