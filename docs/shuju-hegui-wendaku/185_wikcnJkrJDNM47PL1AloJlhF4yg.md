# 陌生电话推销的合规性

> 来源：[https://docs.feishu.cn/docx/H8TmdSrt4oetcBxQ2zxcE5zrnSc](https://docs.feishu.cn/docx/H8TmdSrt4oetcBxQ2zxcE5zrnSc)

**-问：**陌生电话推销是不是完全做不了了呀，因为告知同意没法做。

**-答1：**盲打可以。

**-追问：**盲打是合规的吗？也不知道你是谁，直接上来就问：需要贷款吗？感觉也不合规。

**-答2：**是**正规的陌**生电话推销么，看他的个人数据是不是正规获取的吧，上游机构有没有获得同意，涉及到提供共享？但《个保法》第23条的单独同意几乎是拿不到的。

**-答3：**按照**电商****相关的**规定，未经同意不能打电话，不是基于个人信息保护的要求，而是防打扰的需求。

**-答4：**上游在隐私政策中也**很难覆盖个人信息的受让方**，因此无论是告知和同意都是难做的。

**-答5：****《广告法》**里也有一个规定：未经同意，不得以电子信息方式发送广告。——如果是系统自动拨打的电话应该也会构成这个。
