
# 营销短信内容审核

> 来源：[https://docs.feishu.cn/docx/R36PdwmDyouG4px5D4Rco475nyf](https://docs.feishu.cn/docx/R36PdwmDyouG4px5D4Rco475nyf)

**-问**：关于营销短信内容审核，有什么参考文件吗？

**-答1：**这块一直是合规+安全评审的，有自己的体系。

**-答2：**先看提供的产品和服务，研究所属行业对于网络营销的合规要求，比如金融行业的，可以看仍然在征求意见阶段的金融产品网络营销办法；如果所属行业没有特别规定的，那么民法典、电子商务法、广告法，消费者权益保护的一般原则，在短信营销中就要遵守，比如营销信息的真实准确是普遍适用的要求；再往后就看个人信息保护的规则，营销短信本身是否存在超范围使用个人信息的情况。整体思路就是业务合规--消保--个保，三个方面都过一下。

**-答3：**内容安全还有有关部门下发的词库。

**-答4：**我很多情况下只能说如果做了充分的提示，从合规的层面上可能挑不出毛病来，不过从法律层面，深究可能还真有解释不清的情况

**-答5：**可以再用反查法补一下，比如去网络不良垃圾信息举报受理中心查下垃圾短信申诉机制，里面有一些判定标准。还有重保期间跟运营商合作有个安全承诺书，估计能管到明年315，要是也可以看看。
