# 手机号注册等于实名制吗

> 来源：[https://docs.feishu.cn/docx/XtwydtVglow85Rx5DfXcHZfGnag](https://docs.feishu.cn/docx/XtwydtVglow85Rx5DfXcHZfGnag)

**-问**：用手机号注册账号，是否一定意味着完成了实名制？

**-答1：**从**公安**的视角来看，好像**是的**。

**-答2：**完成了，有个确定的**人跟账号绑定**就完事了。

**-答3：**我感**觉如果用手机号去完成实名制，需**要和天翼云有合作吧。所以收集手机号—发送验证码—目的是为了后续用户自己修改密码，这个程度就已经算是完成实名制了吗？我还是觉得这个不算是实名制……这个只能是说给实名制提供了基础，库里面依然不知道每一个前端用户的具体身份，只是如果真的想知道的话，可以再拿着库里的手机号去向运营商或者提供给公安部门去要真实信息。如果提供手机号实现实名制场景的话，可能需要与天翼云合作，用户提供手机号时，除了同意隐私政策，还要再同意一个天翼云xx账号认证规则，然后平台端把收集的手机号给到天翼云，天翼云返回对应的身份信息。

**-答4：**验证手机号约等于实名，我的理解是，如果真的出现了重大事**件，公安机关需要依法调**取，它是可以从这个手机号信息找到具体的人的。

**-答5：**之前十九楼的一个案件里有对手机号实名认证的说理。义乌天祥医疗东方医院与十九楼网络股份有限公司名誉权纠纷一审民事判决书，（2018）浙0782民初9873号：

> 由于**手机已经推行实名认证且使用方便、功能全面，手机号码可以作为电子身份认证方式。根**据《移动互联网应用程序信息服务管理规定》第七条规定，移动互联网应用程序提供者依法履行以下义务：按照后台实名、前台自愿的原则，对注册用户进行基于移动电话号码等真实身份信息认证。现被告已提供了用户注册的手机号码、用户名以及IP地址，应认定其已履行了管理义务。

**-答6：**现实遇到的。**平台提供手机号码但法院不开调查令从运营商处通过手机号码查人身份信息 ，**还有法官直接说给你开了也没用，运营商不会提供。还有号码注销的，平台披露注销就没了。
