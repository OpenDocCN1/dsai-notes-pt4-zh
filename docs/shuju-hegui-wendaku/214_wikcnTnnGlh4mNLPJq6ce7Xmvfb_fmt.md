
# 汽车数据处理者如何落实告知要求

> 来源：[https://docs.feishu.cn/docx/LnBfdV715ojEOsx2toDc34CbnCA](https://docs.feishu.cn/docx/LnBfdV715ojEOsx2toDc34CbnCA)

> 汽车数据处理者处理个人信息应当通过用户手册、车载显示面板、语音、汽车使用相关应用程序等显著方式，告知个人以下事项：……

> 《汽车数据安全管理若干规定(试行)》第7条

## 讨论问答

- **问：** 针对上述告知要求，我的理解是选择在用户手册、车载显示面板等载体之一告知相关隐私声明即可，但我们有其他同事有不同意见，认为官网、用户手册、车机、APP都应挂上隐私政策才合规。全部都放当然合规，只是我觉得从立法精神上应该是择一载体告知即可，且用户手册更新没有官网或APP上方便。请问各位有何意见？

- **答1：** 我是认为这条的原意是放在哪里最符合用户的使用习惯，更能看到。比如车收集的信息肯定放在车载面板，APP收集的在注册的时候获得同意更合理。

- **答2：** 我认为还是都要放的。

- **答3：** 也不能都放在用户手册里。从透明度原理出发，还是要站在用户角度提供入口。
