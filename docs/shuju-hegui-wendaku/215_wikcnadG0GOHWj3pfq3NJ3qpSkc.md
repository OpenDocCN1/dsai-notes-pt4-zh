#  4S店分析客户人脸信息合规性

> 来源：[https://docs.feishu.cn/docx/RF1ndW6P8oshqRxlLmwczGgmnfb](https://docs.feishu.cn/docx/RF1ndW6P8oshqRxlLmwczGgmnfb)

**-问**：像4S店收集人脸信息进行分析客户类型的情形，这些商家如何有效获得个人主体同意呢？技术供应商除了做好对人脸信息的、存储、删除等要求外，关于收集这部分，还要做什么呢？

**-答1：****单独同意****没办法取得，且处**理人脸信息是否符合合法、正当、必要原则均都待商榷。

**-答2：****对公**共场合人**脸识别商**业用途最实务的建议就是：别用。否则仅合同无效的风险会很烦，这是对供应商来说。
