
# 汽车出借后数据访问权限

> 来源：[https://docs.feishu.cn/docx/AaDIdmRRcoaZG3xamV4ca75tnOe](https://docs.feishu.cn/docx/AaDIdmRRcoaZG3xamV4ca75tnOe)

### 问

电动车车主授权他人使用车辆的场景下，授权使用期间的车辆数据和用车人数据是如何具体处理的？会和车主的有区分和隔离吗？谢谢！

### 答1

一般来讲不用，也可以做账号隔离。就像电脑可以建多个账户一样。临时借车出去，一般也不会新建一个。

### 答2

会区分和隔离，记录授权，但授权人不能直接查看被授权人使用状态，特别不能查看被授权人轨迹状态。被授权人可以自行查看和调取自己的数据。

### 追问

假如我是车主，有人借了我的车，我却不能看到ta开我的车去了哪里……万一ta做了什么非法的勾当，咋办捏。

### 答3

有地理围栏功能可以了解一下，出了圈圈会有预警。

### 答4

对于车企而言，看是否已经考虑到外借的情况，并这外界的数据处理这一块是否有相关的协议、约定、政策。对于用户而言，看是否会遵照已有的协议、约定、政策，并创建单独的使用人的账户/临时账户。

### 答5

关于授权人看被授权人轨迹这个事，其实分很多场景，纯粹personal and household exemption的场景对于技术提供方来说很难确认，对于雇员德国法院有过不能采取非必要tracking实际使用人，所以其实考虑版本统一的时候挺难的。
