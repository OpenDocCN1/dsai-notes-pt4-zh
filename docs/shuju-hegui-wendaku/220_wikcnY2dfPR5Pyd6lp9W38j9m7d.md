
# 汽车架号信息在汽车售前可以交易吗

> 来源：[https://docs.feishu.cn/docx/FqPjdleFKo2ws3x7N4UcpA3Wnrf](https://docs.feishu.cn/docx/FqPjdleFKo2ws3x7N4UcpA3Wnrf)

## 问题

### 问
销售前的车辆零部件数据中，其中包含`vin码`，这种数据能和别的公司（如保险机构）交易吗？

## 回答

### 答1
`vin码`售前不是个人信息，售后才是。即是售前，仍然需要考虑风险。类似于研发的车联网数据和用户的也是区分开的，一般车企数据，售前售后会切割下。合规角度需要考虑风险，因为别人有数据可以把你给的数据关联。

### 答2
售后就可以关联，对方会有数据，但现在行为发生在售前。

### 答3
理论上是这样，实际操作挺难区隔。做好合规措施，没啥不行的。

### 答4
对广互曾认定车架号不是个人信息。详见：二手车历史车况信息是否属于个人信息或隐私。

### 答5
这个应该是在个保法之前出的，感觉现在出可能不会这么说了吧。当然是要充分保证二手车信息披露来保护接盘侠权益，但是肯定不是以判定这不是个人信息为基础吧。
