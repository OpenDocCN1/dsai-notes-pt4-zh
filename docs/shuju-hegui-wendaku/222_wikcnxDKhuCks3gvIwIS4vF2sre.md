
# 车载终端为什么不算移动智能终端？

> 来源：[https://docs.feishu.cn/docx/OmkhdG6YKoVgHtxbyOIc0E7tn8c](https://docs.feishu.cn/docx/OmkhdG6YKoVgHtxbyOIc0E7tn8c)

**-问：**请教下，车载终端为啥，不算移动终端了。可以直接接入通信网络的才算吗。

![](img/edaa2359767c60fb85aaf5b063023fe4.png)

**-答1：**车载娱乐有些也可以吧。

**-答2：**自己加装的行车记录仪算移动智能终端吧？之前买个一个行车记录仪，比较老式，算是一个小平板电脑。

![](img/eef2e62c1a14bcf6714a6e88cf671afe.png)

**-答3：**插sim卡的算。

**-答4：**虽然是一个很智能的移动终端，但没有SIM卡槽就不算“移动智能终端”（不支持蜂窝网络的iPad也不算喽）。

**-答5：**我指的是3C消费品，车载终端属于特定行业了吧。

**-答6：**支持蓝牙和WiFi的呢。

**-答7：**这么说，就是指那些能打电话的智能手机、Pad、智能手表了吧？

**-答8：**在规范出来之前，我朴素的认知里面，是把汽车当作 终端来用的。不是有些APP也支持在车载端的吗。

**-答9：**这个是预置应用可卸载那个通知的官方解读吧？我理解这边算不算移动智能终端，不在于技术层面，而在于这个通知的规范层面，因为汽车与手机存在场景差异，如果限制在那几类不可卸载，可能危险到驾驶安全或者汽车驾驶的基本功能。

**-答10：**`https://www.miit.gov.cn/zwgk/zcjd/art/2022/art_8f49df65470a46e5b38672fec7dd7461.html`，是的。

**-答11：**现在的车也是有sim卡的，只不过用户得把车拆开才能拔sim卡，这里排除的车机属于那种老式的，没法接入应用商店的终端吧。高阶智能化的汽车终端已经跟iPad，手机没区别了。

**-答12：**感觉这种更有道理诶，就是那种没法联网，但也有简单应用的。而且也比较符合2016年时车载终端的特性。
