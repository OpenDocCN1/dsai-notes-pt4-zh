
# 查看车内情况的告知同意

> 来源：[https://docs.feishu.cn/docx/O08hdRNhoo2IITxwFUYcJ3I5nNc](https://docs.feishu.cn/docx/O08hdRNhoo2IITxwFUYcJ3I5nNc)

## 问题描述

### 问：请教各位大佬一个问题，目前车上有一个功能叫“车内实时视频查看”，车主通过APP发起申请，经过车内人员的同意后，可以实时查看车内状况。但是因为技术现状受限，无论是摄像头还是座椅压力传感器都无法准确识别出车内是否有人。

合规上的方案是CSD屏幕文字交互取得车主同意，如果车内人员明确点击拒绝，则不开启车内摄像头，车主无法查看车内实时状况。如果车主在10S内未做出动作，则视为车主同意，这样的话属于“授权同意”，在同意方式上存在瑕疵。

目前比亚迪的方案比较直接，必须取得车内人员的明示同意，车主方可查看车内情况。但是这样的话会限制功能的可用性，因为车内实时视频查看的主要场景就是车上没人时，查看车内是否存在遗留物品、宠物等。

请问有什么方案能既满足合规要求，又不减损功能的可用性？

### 答3：单独同意+随时可关闭的开关+不能存储等这些要求都有的。目前只是同意方式有些瑕疵。应该不会被认定为生物特征识别信息，一个是主机厂接触不到，另一个就是车主也只是能查看，不能分享、不能存储。

### 答4：存储是都会存储的。这里面的存储你可以理解为缓存。就像你看腾讯视频一样，你以为你没同意存储。也不下载。放视频时候就不存储了么。也会存储的，只是存在应用自己的目录空间内。不管是安卓还是IOS都是允许的，不用征得用户同意，也不用申请权限。在隐私保护里面算是合规的方案。大点的app，在设置功能里面都有有个清除缓存功能，其实就是清掉临时存储的文件。

### 答5：曾经有看到过欧洲意见供参考，大概是如果是借车给他人使用，车主不能直接打开这个功能，或者由车主取得车内使用人的同意。如果是非法入侵是否也无需依赖于同意？
