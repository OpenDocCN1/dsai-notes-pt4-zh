- 答10：是不是也区分，车机系统升级是不是得先经过车企同意？不过工信部关于加强智能网联汽车生产企业及产品准入管理的意见就是发给各生产企业的（这里面提的ota备案的要求），汽车年报就不是，所以零部件企业也要报。市监的比较明确，就写的生产者。我个人感觉哈车企报了就不用重复，要是没报，可以报一份，因为也要准备挺多东西的。

- 答11：咋也得告诉下吧，毕竟涉及整车安全。我了解到，目前就主要是主机厂备案，供应商协助做一个账号申请备案就行。

- 答12：从法规的角度，绝大部分OTA义务是压在主机厂这边的。而且工信+市监两条线。主机厂+车型+每次OTA。基本是这个逻辑，三层备案。
