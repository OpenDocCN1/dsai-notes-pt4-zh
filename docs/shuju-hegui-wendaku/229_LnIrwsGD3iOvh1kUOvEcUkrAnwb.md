
# 车内视频合规

> 来源：[https://docs.feishu.cn/docx/WwABdiQf1oG3LJxod5zcbdiPnwe](https://docs.feishu.cn/docx/WwABdiQf1oG3LJxod5zcbdiPnwe)

## 问题与讨论

- **问：**车内视频合规感觉不好做呀。这个功能应该国内没车企有吧？

![](img/9d4310b1c201d072e6ecde0346140f12.png)

- **答1：**特斯拉有。

- **答2：**高合汽车。[高合“车内不雅照泄露”后，又到理](https://mp.weixin.qq.com/s?__biz=MjE2MDI0OTk2MQ==&mid=2651040139&idx=1&sn=7c1e3fd9c5112c89a3389b15732121b4&scene=21#wechat_redirect) 想澄清，谁保护我的智能车摄像头数据安全？

- **答3：**想问下除了使用者外的其他组织和个人不能访问，这个如何证明，是不是只要车企自证就行？需要第三方验证吗？特斯拉的不能实时查看，而是达到预设的条件才会保存？

> 为实现远程查看车内情况或云存储功能，向使用者提供数据，取得个人信息主体同意，并采取安全措施，除使用者外的其他组织和个人不能访问。

> 《汽车数据处理安全要求》

- **答4：**搞个专有云，买阿里云或者腾讯云也行。

- **答5：**同好奇，感觉只有物理屏蔽才能放心。

- **答6：**很难验证真实性呀。

- **答7：**车内只要有摄像头的，作为车主，很难不担心会被远程查看啊。

- **答8：**tesla那个摄像头好像是个`dms`系统吧。

- **答9：**问题是车企怎么自证清白，能拿出什么证据，而不是一个声明能解决的？

- **答10：**我不懂技术啊，但是没有必要自证清白吧。如果监管来查，用工具重新跑一遍就行吧，看下车内摄像头的功能有没有上报车内影像数据。

- **答11：**隐私存证系统。

- **答12：**小众信息源这两件艳照门不会是车企的主动所为，大概率是车主的情趣爱好，私发后，传播到了大众渠道。不过对于车企合规从业者反而是个好事情，倒逼车企重视个保，重视用户隐私，在整那些乱七八糟的云功能的时候做实质合规，不仅仅是书面合规。

- **答13：**其实有的时候蛮难的，打个比方行车记录仪是第三方提供的，第三方对数据提供云和本地存储/甚至在车企的要求下仅有本地储存（极致推论这个硬盘也是第三方的），和车企没有半毛钱关系。但这个行车记录仪就长在车身上，车像是一个宏观的服务提供平台，即便对数据的实际控制能力几乎为零，是不是还会有对供应商的审慎审查义务，如果有的话，是否最保险的就是不装行车记录仪。真希望有案例可以把责任分一分明确一下。

总结：按版本公证不知道可否解决公信力问题。
