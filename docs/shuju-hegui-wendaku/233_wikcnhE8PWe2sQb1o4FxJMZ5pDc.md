# 金融机构保存邮件录音依据

> 来源：[https://docs.feishu.cn/docx/Cxk9dwjRFoB3tkxhWwkc4FJRngw](https://docs.feishu.cn/docx/Cxk9dwjRFoB3tkxhWwkc4FJRngw)

**-问**：想请教一下大家有了解金融机构保存员工和客户的来往邮件、即时通讯（例如微信聊天记录）有明确的法律或者监管依据吗？主要是考虑是否需要就涉及客户个人信息的内容征得客户个人同意，是否有法律义务可以豁免该等同意。我先前做的一些检索得到了诸如监测投资管理人员通讯行为或者基金销售配套留痕措施等，但不知道还有没有更solid的一些法律义务

**-答1：**《证券法》第**137**条。

**-答2：**是保存来往邮件本身的要求，还是保存有涉及客户信息的往来邮件的要求。而且员工和客户讨论涉及客户信息的内容，应该是金融服务的一部分比如客服流程的操作？这个事儿本身应该挂钩服务目标所对应的客户信息使用吧。我感觉保存记录和涉及客户信息的记录合规性，两个目标绑定在一起是有点理不清。还有即时通讯工具的使用，对金融合规要求来说可能存在问题，是否还要求通过正式途径留痕。来往邮件这种本来就是标准流程的话，参考的标准应该就和其他正式记录一致。但我感觉你目前是当成一个灰色地带在考虑留痕保存的需要。

**-追问：**是保存来往邮件本身的要求，主要是考虑到可能会涉及客户姓名、邮箱地址，在微信聊天记录的情形下，根据央行的金融数据安全指南，微信号也属于个人信息，所以可能会涉及到如果未经客户存储记录，是否侵犯客户个人隐私的问题。因为在现在的市场上根据用户习惯的话难免会和客户有先前的微信上的接触，正式途径在之后肯定会进行。

**-答3：**站在机构角度对于邮件这种可控的途径，如果满足过程合规要求，可以纳入到正式流程，看是否需要在服务协议中明示客户。微信不知道目前机构是否可留存记录，但不可控因素较大，需要结合行业惯例来看，1）要求一线人员微信接触客户后引导至正式流程办理，对于直接在微信办理的是否认为操作不合规以免除机构的责任？2）如果使用微信沟通是惯例那可以考虑建立机制例如把客户信息包括微信号作为公司信息资产管理。
