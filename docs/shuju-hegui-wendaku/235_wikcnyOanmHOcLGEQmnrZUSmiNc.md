# 金融机构数据上公有云的合规性

> 来源：[https://docs.feishu.cn/docx/TH2GdHB9hotwosxmJ3ucSexOnFf](https://docs.feishu.cn/docx/TH2GdHB9hotwosxmJ3ucSexOnFf)

**-问：**保险公司数据上公有云有什么限制吗？

**-答1：**《保险中介机构信息化工作监管办法》目前看到保险经纪公司是允许上公有云的。保险业的公有云有行标。

**-答2：**保险和保险经纪还不一样吧，似乎没听说有明文禁止金融机构用公有云的，但监管应该明里暗里挺多限制的吧。而且大小机构也没法一刀切。

**-答3：**中国人民银行有通知来专门说云的问题，2018年的一个通知明确说到可能涉及公众资金损失和隐私泄露的不应采取社会化云服务。2020年有通知专门讲使用金融云、提供金融云准入的问题，后续互联网金融协会发布《金融云备案管理办法（试行）征求意见稿》细化准入条件。不是只针对保险机构的，是针对金融机构的。
