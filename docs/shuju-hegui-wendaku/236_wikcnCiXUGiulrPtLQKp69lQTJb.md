# 登录手机与金融账户主体的一致性核验

> 来源：[https://docs.feishu.cn/docx/HCEud84gPoPqZpx8FgScP9h7nHf](https://docs.feishu.cn/docx/HCEud84gPoPqZpx8FgScP9h7nHf)

**-问：**金融类的app，金融账户用的是a的身份证，但登录账号却是b的手机号。这样有问题吗。这种有核验手段吗，比如我拿b的手机注册app账户，下一步才是绑定对应的金融账户，有法子不让b绑定 a的金融账户吗？

**-答1：**没问题，手机号可以过户啊。比如a的账号绑了自己的手机，然后没解绑，a把手机号过户给b了。

**-答2：**不行吧，具体规定说不上来，四要素验证的话是不行的。貌似正规金融app没办法让b绑定a，亲测京东金融。原理是这个原理，鉴权a，匹配b手机号时发现手机号登记人不一致，无法通过。

**-答3：**对于银行而言，现在开户都要求查验手机号码确实是本人的。这个直接在比如 电信营业厅 之类的就能查。有登记的直接能看到实名制信息。金融账户的话，也可以做单独的实名？

**-答4：**这种情况通常在注册环节是弱实名，可以使用任何手机号注册；但在交易环节需要强实名，这时用a的身份证就需要验证a的手机号或者其他联系方式，这既是金融机构反洗钱、客户身份识别的要求，也是在线交易账户安全、电子签名的要求。

金融账户用的是a的身份证，但登录账号却是b的手机号，这种对于老人和小孩办理业务，有一定的市场需求。

具体可以看《金融机构客户尽职调查和客户身份资料及交易记录保存管理办法》。

**-答5：**我在想这个场景，是不是要区分一下：金融账户和App账户（或者叫账号）的关系，如果注册的App账户绑定金融账户，是本人操作的话，感觉App注册账户对应的“个体”与金融账户登记的“个体”应该有同一性。为了满足老人和孩子的需求，由家属代为办理网上的App账号的话，是不是要特别说明一下？

**-答6：**是的，如果注册环节同时开立金融账户，应该有统一性，否则不论四要素还是三要素都过不了。儿童金融产品还有人寿保险，教育金。监护人注册app，交易环节需要填写儿童身份证和联系方式。这种情况在金融交易中比较常见，其中还有儿童隐私政策的问题。如果注册和开户分离，核心就是办理业务环节需要做KYC。

**-答7：**我觉得没有问题，原因如下：1.金融app的账号和金融账户（基金证券类账户）是两个独立的账户体系。2.金融app是一个通道，一个入口，我理解通过这个渠道可以登录任意金融账户，金融账户登录时需要另行输入账户密码的。3. 金融账户开户时会进行真人核验、手机号码核验、银行卡号核验，符合适当性义务、反洗钱义务、实名制义务。没有规定一定要和本机号码去做比对或者核验。
