
# 征信授权

> 来源：[https://docs.feishu.cn/docx/KcDsdtKl7oTBo0xfoD9c3h2dnDb](https://docs.feishu.cn/docx/KcDsdtKl7oTBo0xfoD9c3h2dnDb)

- **问：**想问一下大家，关于征信授权，有哪些可以参考的法规或标准吗？

- **答1：**《征信业务管理办法》是主要适用法规。

如果关注的是授权**形式**，征信属于个人信息共享，要按**单独同意**的要求执行。

如果关注的是授权**内容**，那么细**节**较多。**金融机构**由于接入人行系统方式的不同，会得到上海资信或者人行对于文本的指导。
