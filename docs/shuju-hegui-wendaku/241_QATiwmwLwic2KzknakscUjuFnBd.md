
# 支付行业要遵守PCI DSS吗

> 来源：[https://docs.feishu.cn/docx/Nodfd6QAjoFwMTxz3RqcV8B0n9c](https://docs.feishu.cn/docx/Nodfd6QAjoFwMTxz3RqcV8B0n9c)

### 问

有个小白问题想问下国内支付行业是不是也遵守的PCI DSS这个标准哇？那就是说无论是国内还是海外如果是支付数据中如果只是使用不存储 合法性基础可以是基于合同履行 如果要存储相关的CVV，卡片有效期等数据的话只能基于同意，这么理解应该对吧？

### 答1

应该是的。

### 答2

银联以前好像不看这个（现在要不要不知道），如果要走境外卡组织清算系统，必须要。

### 答3

支付卡行业数据安全标准PCI DSS 4.0最新解读，PCI DSS不是国内法律强制的，但现在基本成为国内支付机构标配了。如果开展外卡收单，外卡内用的业务，就是必须取得的。

### 答4

我感觉国内制定的标准基本也是参考这个标准来的。

### 答5

因为法规有一句话符合 XXX ，满足 XXX 。怎么符合，怎么满足，总得有权威认定吧，那爸爸认可就是权威吧，久而久之。跟央行已经脱钩的那几家公司产品一模一样，反正大小检查拿那几家的认证出来就行了。
