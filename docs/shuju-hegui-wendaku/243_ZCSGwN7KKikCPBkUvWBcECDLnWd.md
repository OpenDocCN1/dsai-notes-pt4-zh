# 金融信息服务使用合规要点

> 来源：[https://docs.feishu.cn/docx/OK1YdZt3Aoi4J9x7TXncM3GLncb](https://docs.feishu.cn/docx/OK1YdZt3Aoi4J9x7TXncM3GLncb)

**-问：**银行与尚未完成备案的金融信息服务提供者合作，机构自身是否有合规风险，行政处罚、约谈等。

**-答1：**银行不是刚出41号文么，**加强银行科技外包风险管理**。如果这里金融信息服务涉及科技服务，正中靶心。

**-答2：**外数采购记得金监局的数据安全征求意见稿新明确要求的，并且要求机构评估外数供方获得数据的合规性等。机构自身的风险可能首先看做没做评估来免责。

**-答3：**建议结合金罚决字【2023】68 69号，再读一下银行业监督管**理法+上面两个办法，**理清楚金监在金科领域可能的处罚依据。我理解可能踩中“严重违反审慎经营规则”，具体的规则就是上面两个办法的具体规定。

**-答4：**大帽子是审慎经营，按合规重**要性细分下来**是看征信、消保（包含个保）有啥bug，切入角度是业务管理角度是合作机构管理，信息科技外包角度的话是管信息技术安全的多。数据安全，我感觉目前金监还没特别细看。属于外部立法多 执法强度一般…

**总结：执法颗粒度待澄清。**
