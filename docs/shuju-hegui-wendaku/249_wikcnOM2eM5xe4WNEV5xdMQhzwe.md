
# 地图测绘的合规问题

> 来源：[https://docs.feishu.cn/docx/NvwxdbNU3o0KxNxpdZVcLI4Hnsg](https://docs.feishu.cn/docx/NvwxdbNU3o0KxNxpdZVcLI4Hnsg)

**-问：**大家怎么看这条新闻：维护国家地理信息安全 两部门查处违规提供地图服务行为

**-答1：** **今天一个讲座** 上也听说了，不让车企自己做地图测绘了，必须要和有甲级测绘资质的机构合作，而这样的机构全国也没有多少家。大概是涉及国家安全吧。

**-答2：**《互联网地图管理条例》早就有了，之前没怎么被重视。

**-答3：** **没有牌照本来就不能做测绘**，只是最近自然资源部又强调了一次。
