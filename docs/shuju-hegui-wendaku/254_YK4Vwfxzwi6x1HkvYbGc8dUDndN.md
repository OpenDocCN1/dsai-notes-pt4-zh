#  人脸识别必要性

> 来源：[https://docs.feishu.cn/docx/NIohdJYuio4kUNxXGnWc9iF5nCf](https://docs.feishu.cn/docx/NIohdJYuio4kUNxXGnWc9iF5nCf)

**-问：**请问各位大佬，国内监管是否有对实名认证的相关要求，要求不能只提供人脸认证作为实名认证的唯一方式呀？

**-答1：****最高院**人脸识别司法解释。

> 物业服务企业或者其他建筑物管理人以人脸识别作为业主或者物业使用人出入物业服务区域的唯一验证方式，不同意的业主或者物业使用人请求其提供其他合理验证方式的，人民法院依法予以支持。

> 《最高人民法院关于审理使用人脸识别技术处理个人信息相关民事案件适用法律若干问题的规定》第十条

**-答2：****网信办**人脸识别规定征求意见稿。

> 第四条 只有在具有特定的目的和充分的必要性，并采取严格保护措施的情形下，方可使用人脸识别技术处理人脸信息。实现相同目的或者达到同等业务要求，存在其他非生物特征识别技术方案的，应当优先选择非生物特征识别技术方案。

> 

> 第九条 宾馆、银行、车站、机场、体育场馆、展览馆、博物馆、美术馆、图书馆等经营场所，除法律、行政法规规定应当使用人脸识别技术验证个人身份的，不得以办理业务、提升服务质量等为由强制、误导、欺诈、胁迫个人接受人脸识别技术验证个人身份。

**-答3：****证监会**也有一个，理解线下临柜办理有可以不用人脸识别的路径就好。如果没有外规要求，只是出于核验本人，就要求必需人脸识别，可能会有问题。

> 第三十五条 核心机构和经营机构利用生物特征进行客户身份认证的，应当对其必要性、安全性进行风险评估，不得将人脸、步态、指纹、虹膜、声纹等生物特征作为唯一的客户身份认证方式，强制客户同意收集其个人生物特征信息。

**-答4：**我看到有APP给这两种选择了，可以人脸也可以手持身份证照片，做实人认证。

**-答5：**基础的，实名：就是手机号码。游戏行业：姓名+身份证号；快递 ：好像姓名、手机、身份证正反面；直播：增加手持身份证要求，再往上就往实人方向走了：证券、银行开户履行实人认证要求等。

**总结：人脸识别确有滥用风险，若无外**规强制要求，不应作为核实本人的唯一渠道。
