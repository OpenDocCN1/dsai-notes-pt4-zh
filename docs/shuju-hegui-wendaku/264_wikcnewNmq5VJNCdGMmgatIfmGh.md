# 临床实验数据的出境

> 来源：[https://docs.feishu.cn/docx/PqjCdGlFwoS4AgxR1JFcpU2Cnfc](https://docs.feishu.cn/docx/PqjCdGlFwoS4AgxR1JFcpU2Cnfc)

**-问：**在license-in背景下，做临床实验数据出境时，出境的都是未经处理的受试者原数据，而非经过分析后的数据，这种情况普遍吗？有把这些数据作为个人信息来做评估的吗？

**-答1：**这肯定是个人信息，去年我们请律师评估过。

**-答2：**我们接触的一般客户是委托试验中心进行临床试验，然后试验中心给客户的是脱敏后的临床试验报告，里面有受试者个人信息，但是非原始数据。

**-答3：**我们接触的医药公司给境外licensor群体统计数据的比较多，不太会给出原始数据（但是也不排除一些国际公司比较强势的情况下，境内医药公司会根据其需求给出原始数据）。医药公司从实验室同时拿原始数据和分析数据的也比较常见。
