# 来料加工出境要出境评估吗

> 来源：[https://docs.feishu.cn/docx/R2vEdSVJBo0cioxBLkrcuCtPneV](https://docs.feishu.cn/docx/R2vEdSVJBo0cioxBLkrcuCtPneV)

**-问：**请教一下大神们，这个情况是否需要做申报：1.境内公司（processor角色）帮助境外base的企业处理数据，依约完成处理后返给境外公司。2.处理过程，境内processor有对前述数据进行境内存储；数据量也还有点大，涉及全球的一些人力资源数据，满足敏感数据1万的；目前正在迁往境外去处理。

**-答1：****要，这属**于来料加工，需要申报，都是在境内产生的。

**-答2：**有加工处理就要，**无论是否有额外的信息**。

**-答3：**不考虑实践的话，法律层面有解释空间,严格解释“数据处理者”和“提供”即可。

**总结：**学理上，有论证空间。监管口径上没有余地，从国家安全角度出发，也就可以理解了。
