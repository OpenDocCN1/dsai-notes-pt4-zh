# 员工境外访问软件算数据出境吗

> 来源：[https://docs.feishu.cn/docx/ZH4LdG8QzotjFoxUZo1c3x2Cnib](https://docs.feishu.cn/docx/ZH4LdG8QzotjFoxUZo1c3x2Cnib)

**-问：**各位大佬咨询个问题，派驻到境外的员工，使用境内总部的办公软件，算不算信息出境？

**-答1：**访问就是出境，不信可以电话咨询一下。

![](img/f44948677bb3dac773f4dbf5195ae247.png)

**-追问：**那要和谁签SCC呢？

**-答2：**实在不行和境外子公司签呗。

**-答3：**境外都没有实体，就派一些员工出去，劳动关系在境内、工资境内发，这都算的话，跟境外的谁签标准合同。

**-答4：**问完会不会让每个境外办公员工签，相应的问题又有，只是去度假两天咋办。

**-答5：**可以让他们拿申请海外工作签证的表格来看看。外派到境外工作，要么海外是有类似于公司或办事处的实体，要么是类似于free lancer，不然去海外的商务签或本地工作许可就没法办。如果拿着旅游签证出去干活，那本身就有点问题……

**-答6：**偶然性的来自欧盟境内用户访问不适用gdpr  好像是edpb 3/2018 那个指南 。

**-答7：**这种我觉得应该不是监管本意重点约束的对象/情景吧。只是确实把它当一个问题来分析 是有点痛苦。
