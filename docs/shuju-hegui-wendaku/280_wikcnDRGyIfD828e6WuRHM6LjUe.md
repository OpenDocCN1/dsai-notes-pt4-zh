
# 数据出境评估文件盖章

> 来源：[https://docs.feishu.cn/docx/NvcXdhyWvo7gOAxdz1Vcwjy6nkh](https://docs.feishu.cn/docx/NvcXdhyWvo7gOAxdz1Vcwjy6nkh)

### 问：数据出境安全评估申报材料准里，和境外接收方签署的法律文件的中文译本，是否需要盖公章？看申报指南里没这要求？

答1：看看这个数据出境安全评估申报工作实务问答（二）。

答2：国家网信办说的是提交的拟签订法律文件，中国数据处理方要盖公章。

答3：要的，盖数据处理者的章，境外接收方可以不盖。

### 追问：对于此前已经签署的外文法律文件，它的中文译本，是否需要盖章呢？

答4：IGDTA上面第一页盖下章就好。

答5：中文译本也需要盖公章。

### 总结

数据出境安全评估申报法律文件中文译本要盖章。
