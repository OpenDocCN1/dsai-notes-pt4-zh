# 集团数据出境申报主体选择

> 来源：[https://docs.feishu.cn/docx/Y80ndqIbfoNv8exfeu7cxKxMnWc](https://docs.feishu.cn/docx/Y80ndqIbfoNv8exfeu7cxKxMnWc)

**-问：**请问大家在申请安全评估的时候有没有选择过用集团的信息服务公司去申请的呢？即集团内部的科技公司，负责集团内部系统开发运维的那种。现在有一个疑惑就是科技公司不想去申报，但是没有一个合适的总部去统一申请，因为有些是姐妹公司，用了同样的系统。不知道用信息服务公司能不能合适

**-答1：**说清楚就行，别规避监管。信息服务公司一般在数据链路里。提前跟监管沟通就行了。大概率要你一起报。

**-答2：**应该先识别集团内谁是数据处理者，数据处理者是自评估主体。而不是集团内多个主体指定某一方去申报的。信息服务公司通常是数据的受托处理者，可能不合适。

**-答3：**也需要看系统对应的业务是不是有特殊牌照要求，如果有大概率也不能随意定系统运营和数据处理者，还需要兼顾其他方面的监管问题。

**-答4：**是的，因为考虑到需要cover其他公司的情况，导致针对选定哪家公司作为申报主体各主体之间在打架。

**-答5：**提前沟通，因为你说的数据混同，可能需要一起申报

**-答6：**关联公司之间，特别是内部数据，比如员工数据集中使用一个系统，集中申报，这种监管还会不同意吗？

**-答7：**这个是实践中有这样操作的吗？我们目前问到的是说申请主体只能是一家。

**-答8：**CAC匿名咨询回复可行的 但是确实是需要同一业务和信息系统这些前提场景。

**-答9：**同一业务场景感觉很难满足啊，信息服务公司或者说科技公司是不参与业务运营的，更多还是系统维护、管理。

**-追问：**对于数据出境申报的主体认定，处理者和受托处理者有明确区分标准吗？比如亚马逊这样的跨境电商平台，是被认定为数据处理者吗？和入驻商户之间如何划分责任？根据合作合同来判断性质吗？

**-答10：**我理解单独的数据处理者，就是controller，对信息主体的责任是单独承担的。这个对外应该不以两个数据处理者之间的合同约定为依据。

**-答11：**亚马逊是否是数据处理者，取决于亚马逊想不想要信息控制权。先有意思表示，再形成合同约定与商户之间的权利义务。

**-答12**：公安三所一个讲座的观点是判断方式是看是否参与处理了信息。换句话说，主要看亚马逊中国是不是想去申报？情况上还有一些不同，主要是从申报者的角度来看，申报肯定会有成本，平台方肯定也要论证必要性。如果判断为必须要申报，那可能才会去推进申报工作。但是是出境申报的话，如果是单纯提供数据传输的支持，本身没有做加工处理，这种平台方也是controller吗。

**-答13：**作为出境链路。

**-答14：**那是不是可以这么说，如果不做数据融合，是不是可以认为购物平台的数据传输行为不在出境申报的范围内？我理解从个保法的处理行为描述上，收集、存储、使用、加工、传输、提供、公开等都包括在内。是否能自主决定这些行为的目的和处理方式，目前只有看和自然人的授权以及跟合作方的合同约定了。传输行为也是处理的一种，这么看起来，电商平台也可以是处理者。

**-答15：**处理是个很宽的概念，按定义，存储也算处理。
