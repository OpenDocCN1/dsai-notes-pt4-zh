# 数据出境申报材料页数

> 来源：[https://docs.feishu.cn/docx/L1djdcwAAoCrwJxdWxFcXYvCnve](https://docs.feishu.cn/docx/L1djdcwAAoCrwJxdWxFcXYvCnve)

**-问：**出境安全评估的申请材料页数一般大概是什么水平呀？有没有可能20/30页左右，感觉这太少了诶。

**-答1：**可以先20-30页提交上去，然后看看完备性审查能不能过（反正5个工作日就知道结果了）。

**-答2：**一些半官方机构辅导辅导的材料有200页。

**-答3：**正常写即可。收了材料第一件事情难道是数页数么。

**-答4：**二三十页肯定没戏吧。

**-答5：**要细，第一批打回来的可吸取的教训是报告内容颗粒度要细。

**-答6：**应该不是细，是不全。

**-答7：**也要境外拿的到那么多信息啊！

**-答8：**选主系统到披露ip地址是不是可以防火墙地址，确实处处是难点。
