# 数据出境评估材料反馈

> 来源：[https://docs.feishu.cn/docx/SyEMdXkKBo3rxzxEhK7cUbNGnch](https://docs.feishu.cn/docx/SyEMdXkKBo3rxzxEhK7cUbNGnch)

**-问：**想问问已经交了数据出境安全评估的朋友们，有没有收到什么网信办的反馈可供参考吗？比如太长，太技术太难懂，不够细节，有隐藏项没提到之类？

**-答1：**数据出境链路，一定要搞清楚是专线还是公共互联网，网信办通过IP地址可以识别出来，专线会要求提供专线的证明材料，具体的城市也会看，所以要先核对好。细节太多了，他们看得很细，法律文件、报告、申报表，有一点不一致都会要求重新改。省级网信办是形式审查为主，国家网信办会对照细节，直接打电话给企业经办人要求补充说明或解释，一般会要求邮件回复解释说明或证据，正式要求补充材料的，补充的材料需要盖公章。

**-答2：**形式审查为主，意见集中在跨境传输法律文件，需要直观清晰展示六个指定的要件。反馈方面总要来回个三轮，感觉近期审查人手非常紧张，对提交材料也来不及仔细看。

**总结：路漫漫。**
