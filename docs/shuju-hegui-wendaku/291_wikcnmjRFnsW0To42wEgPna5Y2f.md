# 累积出境数量的计算

> 来源：[https://docs.feishu.cn/docx/HnwEdz9OLoyv2zxHccXcfZefnKF](https://docs.feishu.cn/docx/HnwEdz9OLoyv2zxHccXcfZefnKF)

**-问：**想问下大家如果处理没有达到一百万的安全评估，现在去申请是按照2022年1.1计算出境信息数量，还是2021年1.1呢？因为开始准备评估是2022年。

**-答1：**如果2022年12月，2021-2022已经达到数量了，现在也还是得报吧。那如果，2022-2023这个段，今年七月又触发了，还得再报一次吗。只是想想就很离谱。

**-答2：**我们有遇到网信办要披露预计未来两年的出境数量

**-答3：**给当地网信办打个电话问问比较好，我们遇到的2种情况都有，有的客户准备的早，但交上去的晚，会导致出现统计2021年1月1号开始的数据量，但今年交上去也没有被要求改正。现在交的，我们尽量都让客户报2022年1月1日开始的数据。

**-答4：**交表的数据是已经出境+未来2年预计数量。你就看你前2年的数。没增长还是递增。之前我们分享，这个数据别去计算，因为你根本算不出来。
