# 临床试验数据出境接收方的披露

> 来源：[https://docs.feishu.cn/docx/LVCodAmQmoERGMxra9Xc20E5nOc](https://docs.feishu.cn/docx/LVCodAmQmoERGMxra9Xc20E5nOc)

**-问：**有朋友接触过临床试验涉及数据出境的ICF吗？不知道现在涉及数据出境的ICF是不是都完整披露临床试验跨境的接收方了，有的项目境外供应商太多了，不知道一般披露到啥程度？

**-答1：**有点类似金融支付，可以**合并**的，讲清楚就行。

**-答2：**看过一个观点供参考：

(1) 针对受试者的告知

申办者可以通过修改有关临床试验的知情同意书，将《个人信息保护法》要求的告知事项放入知情同意书中，从而同时实现临床试验监管要求下的告知义务以及《个人信息保护法》下的告知义务。

对于《个人信息保护法》要求的告知事项，除了必备的告知事项外，由于临床试验中涉及到敏感个人信息（例如：受试者的医疗健康信息）的处理、个人信息的共享以及可能涉及到个人信息的跨境传输，申办者还需要注意有关处理敏感个人信息、共享个人信息和跨境传输个人信息的额外告知事项。

值得注意的是，《个人信息保护法》中某些关于告知的要求，在药物研发场景下可能会难以落实。例如：对于跨境提供个人信息，《个人信息保护法》要求告知境外接收方的名称和联系方式。但是，在药物研发场景中，由于境外接收方数量众多，而且有时可能会随着临床试验的进展增加不同的境外接收方，因此在入组签订ICF时向受试者告知每一境外接收方的名称和联系方式会有难度。现实当中，较为常见的做法是描述境外接收方的类型（例如：境外的申办者关联方、监管机构、检测服务供应商等），而没有逐一披露各接收方的名称和联系方式。

**-答3：**之前也看过类似的观点：

> 如果对境外供应商能够做到逐一披露，最好还是逐一提供，这个也是最稳妥最合规的方式。但是很多没法做到逐一披露，因为现在第三方太多。这种情况下是否有可能考虑到说我只披露一个境外的处理者，其他的供应商如果是一个受托人身份的话，我们可以argue说这些受托人是受处理者委托在处理个人信息，那么我境外的处理者是可以对受托人去做有效监督的，所以我只披露到境外处理者这一层。当然这个也是一个折中的，现实当中的一个做法，但这个做法将来会不会被监管部门来质疑，真的有执法来，我们有多强的程度来保护我们自己，这可能还要再看未来进一步的执法动态。但目前来讲，应该说不是一家两家在这样做，可能也是一个比较常见的披露方式。

总结：能披露全就披露，太多了就合并吧，具体还是看监管态度。
