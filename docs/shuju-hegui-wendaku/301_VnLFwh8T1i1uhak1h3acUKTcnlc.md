# 需要与境外IDC签SCC吗

> 来源：[https://docs.feishu.cn/docx/RPxCdkJ4ioTkvGxTSMHcalJ2nYb](https://docs.feishu.cn/docx/RPxCdkJ4ioTkvGxTSMHcalJ2nYb)

**-问：**境内个人信息处理者跟境外接收方签署SCC，如果接收方是controller，数据实际存储在另一受托方IDC，是否也需要跟IDC签署SCC呢？

**-答1：**作为**链路**论证。

**-答2：**cac还没明确sub p要不要签

**-答3：**感觉是需要的，如果这个IDC是受这个境内处理者委托的话。

**-答4：**要看IDC是受谁的委托，如果是受境外接收方的委托，需要和境外接收方签数据处理协议（不一定是SCC）。

**-答5：****按**数据出境安全评估项目的经验来看，境内公司和境外controller 签法律文件（例如跨境传输合同）即可，不需要再和境外processor 再签了。另外标准合同下也有境外再提供的条款，所以我觉得不需要和IDC再签标准合同。当然，一切以CAC未来指引的口径为准。

总结：同意回答5，不要折腾自己。
