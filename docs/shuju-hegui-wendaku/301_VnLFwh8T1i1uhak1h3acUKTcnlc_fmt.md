
# 需要与境外IDC签SCC吗

> 来源：[https://docs.feishu.cn/docx/RPxCdkJ4ioTkvGxTSMHcalJ2nYb](https://docs.feishu.cn/docx/RPxCdkJ4ioTkvGxTSMHcalJ2nYb)

- **问：**境内个人信息处理者跟境外接收方签署`SCC`，如果接收方是`controller`，数据实际存储在另一受托方`IDC`，是否也需要跟`IDC`签署`SCC`呢？

- **答1：**作为链路论证。

- **答2：**`cac`还没明确`sub p`要不要签

- **答3：**感觉是需要的，如果这个`IDC`是受这个境内处理者委托的话。

- **答4：**要看`IDC`是受谁的委托，如果是受境外接收方的委托，需要和境外接收方签数据处理协议（不一定是`SCC`）。

- **答5：**按数据出境安全评估项目的经验来看，境内公司和境外`controller` 签法律文件（例如跨境传输合同）即可，不需要再和境外`processor` 再签了。另外标准合同下也有境外再提供的条款，所以我觉得不需要和`IDC`再签标准合同。当然，一切以`CAC`未来指引的口径为准。

总结：同意回答5，不要折腾自己。
