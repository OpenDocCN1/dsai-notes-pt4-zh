# 标准合同和DPA

> 来源：[https://docs.feishu.cn/docx/I6TQd1tWYoEOO2xsuCxcY9otnne](https://docs.feishu.cn/docx/I6TQd1tWYoEOO2xsuCxcY9otnne)

**-问：**请教个问题 个人信息出境标准合同签署的话，DPA（Data processing agreement）应该就可以不用了吧？

**-答1：**我个人认为还是需要的。这两个**不是替代关系**。DPA数据处理协议协议更偏向于理清数据控制者或处理者双方的权利义务，偏向于约定义务。中国Scc作为数据出境的合规要求，偏向于法定义务。

**-答2：**或许可以在出境标准合同的**附录二补充约定**。

**总结：能说清楚就行。**
