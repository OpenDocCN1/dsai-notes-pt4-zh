# 标准合同备案指南简评

> 来源：[https://docs.feishu.cn/docx/Ajt6d4QALozJglxuo67ceSfNnrh](https://docs.feishu.cn/docx/Ajt6d4QALozJglxuo67ceSfNnrh)

**-问：**大家怎么看国家互联网信息办公室发布《个人信息出境标准合同备案指南（第一版）》？

**-答1：**自评估报告格式与出境评估的，机构类似，细节不同，利好前期按照安全评估颗粒度开展的自评估报告工作。

**-答2：**结果竟然，还有**“通过”**和**“不通过”**，那不就是审批了吗？但是通不通过不影响生效吧。好多备案就是这种，实为审批。

**-答3：****感觉没啥新意，和数据出境安全评估区别不大，快速总结几个要点：1. “备案”对形式和内容都有要求，有通过和不通过的区别，不是交上去就万事大吉；2. 备案要准备的文件与**数据出境安全评估类似，要点都在，颗粒度要求稍粗，具体看地方CAC掌握尺度；3. 没有针对“可否签一对多、多对一”、“委托处理者数据出境咋办”之类实务问题提供指引；4. 仍关注出境方的整体数据安全管理能力和全流程数据安全技术能力；5. 整个流程做下来不会很轻松。

**-答4：**根据《国务院办公厅关于推广行政备案规范管理改革试点经验的通知》规定，“对行政备案事项，不得规定经行政机关审查同意，企业和群众方可从事相关特定活动”。

**-答5：**还把“处理敏感个人信息和利用个人信息进行自动化决策情况”单拎出来说了。

**-追问：**申报出境安全评估要求提交的材料中，其中第8项“其他相关证明材料”，是否包含PIA报告？

**-答6：**含的，目前不少项目中央网信办实质审查时已经要求提交PIA报告，省级查验时对此无强制要求。

**-追问：**那现在PIA报告和数据出境自评估报告内容高度重合，把自评估报告改个名字交上去？

**-答7：**有一些细微的差别。不过以前我们交的是一些Pia工具做出来的报告，网信也认，但新模版出来之后风口怎么样，安全评估是不是必须用，确实不一定了。
