# SCC中Outlook算系统吗

> 来源：[https://docs.feishu.cn/docx/KLUldRYwboB1DYxROWBcuWX6nsh](https://docs.feishu.cn/docx/KLUldRYwboB1DYxROWBcuWX6nsh)

**-问：**请问大家现在scc自评估报告中会把Outlook以及类似sharepoint作为出境涉及的系统吗，如果供应商联系人信息主要是通过这两种平台出境的，境外接收方是要每一个可能接收的实体都要签吗？还是选择哪家公司呢？比如境外总部？

**-答1：**我们目前没有**准备写outlook**，就写的通过邮件出境。接收方填的是境外直接接收方。之前听讲座里提了一嘴关于使用outlook出境的问题。如果系统性、定期且出境数据可预测可统计地对外发送名单的话，可以写进评估里。如果是日常非系统性的使用一般他们不会申报，因为可操作性低。

**-答2：****我们披露的，不然链路不完整吧**。只是工具，申报还是按照场景。又不是每个邮**件都要报**，大部分出境场景，监管是不管的。

-答3：申报一定得按照场景么   比如人力资源管理所需  出境的都是那么些员工的信息  但是可能会有不同的tools  一定需要一个tool/场景 一个tool/场景的来吗。

**-答4：**一个人力资源可以含很多小场景，需要字段级，你肯定都要写出来，其他的场景，不太好说怎么划分。
