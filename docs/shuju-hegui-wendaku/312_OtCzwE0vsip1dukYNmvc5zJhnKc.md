# SCC备案材料简化

> 来源：[https://docs.feishu.cn/docx/I4Gyd9oOtoGgJIx6N1ucbVUlnOf](https://docs.feishu.cn/docx/I4Gyd9oOtoGgJIx6N1ucbVUlnOf)

**-问：**想和大家讨论一下，新版scc的指南把境内出境方的安全能力相关章节删掉了；也没有像安全评估一样强调告知同意的佐证。是否意味着以后scc的备案无需向网信办提供告知等义务的证明文件了呢？

**-答1：**第二版**发布的时候网信办也明确说了“对数据处**理者需要提交的相关材料进行了优化简化”。《个人信息出境标准合同办法》里面的自评估内容并没有像《数据出境安全评估办法》里一样包括“数据安全和个人信息权益是否能够得到充分有效保障”，而且标准合同里也已经约定了详细的告知同意义务条款。所以标准合同备案材料不需要提供到和安全评估一样的充分程度，删去这个也是合理的。

**总结：从简。**
