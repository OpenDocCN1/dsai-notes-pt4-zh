# 自愿向境外提供数据

> 来源：[https://docs.feishu.cn/docx/FbrbdwuobosgIHxc4KJcj03fnFd](https://docs.feishu.cn/docx/FbrbdwuobosgIHxc4KJcj03fnFd)

**-问：**今天咨询司法部，说现在自愿主动向境外提供涉诉数据也建议报司法部同意。这个大家现在实践中都是怎么考虑的呢？

**-答1：**司法部说已经有实际批准的案例，且不止一个。但具体是什么情况还不清楚。大家如果有消息可以私下交流下。

**-答2：**我们前两天也问过司法部，司法部的建议就是你自己吃不准的话就报，让最高院决定。司法部自己对这块的监管也不明确，而且报了都收。司法部有专门部门管这个事情的，但只做形式审查。

**-答3：**“建议”也不是强制。我怎么感觉司法部/最高院也没有这个精力专门去管这件事。
