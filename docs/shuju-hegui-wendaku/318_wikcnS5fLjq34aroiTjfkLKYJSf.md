# 向境外法律提供证据

> 来源：[https://docs.feishu.cn/docx/EqNudyQMNo6Itcx1E2eck2nqnoc](https://docs.feishu.cn/docx/EqNudyQMNo6Itcx1E2eck2nqnoc)

**-问**：大家如何看待下面这段话：

> 本案中，美国法院综合双方关于中国法的意见，认为美国法院取证命令可以构成中国《个人信息保护法》第13条下的法定义务，因此，美国法院要求中国当事人向美国法院提供相关信息的命令不违反个人信息保护法的规定。

> 采安个保法团队，公众号：采安律师事务所采安个保法 | 美国案例：中国《个人信息保护法》不禁止美国法院调查取证

**-答1：**美国法律怎么可能成为中国《个保法》下的法律义务，离谱！

**-答2：****S公**司怎么不援引个保法41条：非经中华人民共和国主管机关批准，个人信息处理者不得向外国司法或者执法机构提供存储于中华人民共和国境内的个人信息。另外请教各位大佬，这条在实践中一般怎么执行啊？比如向外国法院或仲裁机构举证或向外国行政机关提交应对执法的材料涉及提供个人信息，要报哪个机关审查以及有成功的案例么？

**-答3：**需要美国发起**司法协助**吧。

**-答4：****如果中国**已加入或批准的条约，比如海牙公约。向境外政府或者司法协助递交材料，会不会转换成中国法定义务？

**-答5：**中、**美都是海牙取证公约的当**事方，美国是缔约国之一，中国是97年加入的。就诉讼而言，据我们了解，赴外国参加诉讼的企业在非海牙公约路径下需要将证据出境的（即企业主动提供或是美国法院直接要求企业提供），一般是向司法部司法协助交流中心提交申请材料，由司法协助交流中心根据实际需要，协调和转交最高院、网信办进行审批。目前总体还在摸索阶段，案例不多。

**-答6：**补充一个，仲裁机构不一定是“司法机构**”，这类q**uasi judiciary（准司法机构）是否被数安36包含还有解释空间。
