# 《出境评估办法》的追溯力

> 来源：[https://docs.feishu.cn/docx/QfLUdQ7uQoVqndxIIyIc8xt9nNe](https://docs.feishu.cn/docx/QfLUdQ7uQoVqndxIIyIc8xt9nNe)

**-问：**《出境评估办法》第二十条规定的“本办法施行前已经开展的数据出境活动，不符合本办法规定的，应当自本办法施行之日起6个月内完成整改”，这个整改的追溯期追溯多久呢？是从个保法生效追溯，还是区分情形，分别对应个保法、数安法和网安法的生效实施期限分别追溯？

**-答1：**我理解是**全部**。

**-答2：**法不溯及既往吧，我理解最多追溯到2**02**1年11月1日个保法生效后且目前还在持续的出境行为。此前没有数据出境安全评估的要求。（但计算数量似乎应该即使已经出去了，不再持续了，也得算？

**-答3：**这个我也想请教一下这个问题，我理解这个“已经开展”，应该是“已经开展且在9月1日后仍在传输的”情况；如果9月1号前已经结束了，整改似乎也没有必要了？不知道这个模糊用词是不是有意为之。

**-答4：**我理解只有对**持续性出境活动进行整改才有意义**。
