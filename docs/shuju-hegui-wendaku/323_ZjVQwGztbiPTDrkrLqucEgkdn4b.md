# 境外接收方的认定

> 来源：[https://docs.feishu.cn/docx/CbsPdsVi6oXYwGxYi7UcYuxkncf](https://docs.feishu.cn/docx/CbsPdsVi6oXYwGxYi7UcYuxkncf)

**-问：**咨询个问题，数据出境的境外接收方，可以理解为数据接收、存储且具有使用的境外主体吗？最简单的判断就是存储数据infra的付钱主体？

**-答1：**不一定，**具体看场景**。也可能是云服务商。

**-答2：**saas对吧，但最终还是ownership还是那个付钱的主体。付saas钱的主体吧？

**-答3：**你的说法也不是一定错，但是一般没那么去解释。

**-答4**：玩具的钱可以是父母出的，但每天把玩的是小朋友。同样的道理，境**外接收方，不看系**统或者基础设施的采购方，采取实质重于形式，具有特定数据处理的目的，查询、访问、接收、存储……数据的主体，是境外接收方。

**总结：同意答4。**
