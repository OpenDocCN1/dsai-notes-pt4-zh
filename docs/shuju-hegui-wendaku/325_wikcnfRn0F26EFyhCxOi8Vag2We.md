# 对履行合同所必需的理解

> 来源：[https://docs.feishu.cn/docx/U8r7d8YxkoVKxexLyThcRJ6OnRe](https://docs.feishu.cn/docx/U8r7d8YxkoVKxexLyThcRJ6OnRe)

**-问：**境内公司A委托一家hk公司B来开展公关服务（主要涉及通过KOL在媒体上的发文等方式帮助宣传A的形象），服务中，B需要将其拟选用的KOL（来自全球各地）的基本信息事先告知A，在A同意后，才开展具体的媒体公关。A和B签署相应的服务合同，B和KOL签署相应的合同。这个情况下，B向A提供这些KOL相关信息构成数据跨境传输吗？以及是否可以适用为履行合同所需？

**-答1：**这个要看香港法。

**-追问：**如果B是欧盟公司呢？

**-答2：**B需要将KOL具体是谁的信息告知A么？也就是说 在A的视角看 能否通过B告知的信息识别出KOL是谁？如果不能，我理解不属于个人信息跨境。因为KOL信息来源世界各地 从世界各地到香港已经是跨境了 再从香港到内地 当然也是跨境。这个是应该让B出具数据来源合法性证明 即使是信息来源于GDPR区域跨境也有明确同意的合法路径 用这个能办法解决合规性问题。履行合同所必需，说的是，个人信息处理者和个人信息主体的合同，不是你B和A的合同，我理解不适用。

**-答3：**是的，个保法下对“履约必要”的定语是非常重要的限定条件：“个人作为一方当事人的合同”。很多为了向个人提供服务而需要与其他B端合作的商务协议，不是这条所述的“合同”。此合同非彼合同。

**-答4：** 也不只是咱们国家 这个法理应该在大部分用GDPR做母版立法的国家都可以这么理解，否则就乱套了。
