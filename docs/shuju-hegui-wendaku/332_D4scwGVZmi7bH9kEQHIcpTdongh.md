# 四大会计师事务所数据出境

> 来源：[https://docs.feishu.cn/docx/KqZZdwwQVoyhPNxRQn9cKEx6nId](https://docs.feishu.cn/docx/KqZZdwwQVoyhPNxRQn9cKEx6nId)

**-问：**想问下大家目前四大服务器基本上都在境外，提供审计服务可能涉及数据跨境，大家是怎么解决这个合规问题的呀？

**-答1：**合同上约束，假装不知道。

**-答2：**现场审或者通过公司自己的云盘开权限给第三方方查看，这些都是方式吧。

**-答3：**某四大在**国内有服务器**，服务器也会**分访问权限**，有的仅限大陆访问。比如现在如果要香港的同事查看项目的资料，可能要麻烦他们到深圳来。
