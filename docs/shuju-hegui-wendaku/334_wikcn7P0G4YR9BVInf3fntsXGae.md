# 财务数据出境

> 来源：[https://docs.feishu.cn/docx/TToYd7GIyoz0czxxt7JcQ279ndd](https://docs.feishu.cn/docx/TToYd7GIyoz0czxxt7JcQ279ndd)

**-问**：求助各位大佬，有研究过财务数据的出境问题吗，简单的公司财务报表这种我理解应该是可以出境的？

**-答1**：我觉得没问题，之前有个《个人金融信息（数据）保护试行办法》，没有公开，[但是下面两篇文章部分内容：（](https://mp.weixin.qq.com/s?__biz=MzUxMzUyMzk1OA==&mid=2247502583&idx=1&sn=83de87a6d9d1cfaf3a8fbdbd79596664&scene=21#wechat_redirect)1）《个人金融信息（数据）保护试行办法》出炉，初稿已在征求意见中；（2）中国金融数据保护相关问题研究。

**-答2**：我理解，只要《网数条例》不生效，相关数据不构成个人信息且不构成重要数据，就可以直接出境。
