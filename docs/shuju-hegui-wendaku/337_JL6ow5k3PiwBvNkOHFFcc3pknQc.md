
# 外企吹哨渠道数据出境

> 来源：[https://docs.feishu.cn/docx/FeMbdeAnYoV6B2xs48TcaEuGnqd](https://docs.feishu.cn/docx/FeMbdeAnYoV6B2xs48TcaEuGnqd)

- **问：** 如果是总部设置的whistleblowing的线上渠道，报告的信息均存在境外，如果境内员工进行报告，是视为境内企业的出境？还是境外公司的直接收集呢？

- **答1：** 境外公司没有境内运营，倾向于认为属于境内企业的出境。

- **答2：** 感觉不是。

- **答3：** 个人意见是境外总部是这里面的controller哦。防止利益冲突的原因 本地团队在这种whistleblowing平台底下一般都不会接触举报人和被举报人的信息。

- **追问：** 现在的困境在于，视为直接收集的出境规则似乎还是需要通过委托境内企业来做，而如果视为直接收集，这种情况下的数量其实很难触发安全评估，单独走认证似乎也不现实。如果视为境内企业出境，从出境的角度更有可能落地，比如做评估或者签协议。

- **答4：** 先躺平，这不是没触发吗。

- **答5：** 是的，这也是倾向于解释为境内出境的另一个考虑，在人力资源管理的申报或者评估中整体去解决。

- **答6：** 先看PIPL的适用吧。

- **答7：** 是不是还要看举报内容里涉及的具体数据主体，如果只有员工个人信息，那controller不应该是雇主方嘛？

**总结：** 严格说应该就是境外直采，境内主体都不经手这些数据。但为了实践中好落地，考虑为境内子公司-境外的路径可能会方便一些。
