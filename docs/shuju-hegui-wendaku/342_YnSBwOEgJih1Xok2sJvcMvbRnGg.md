
# 涉诉数据出境进展

> 来源：[https://docs.feishu.cn/docx/MiGndU4GgocEEBxdaBicH🐧DnDb](https://docs.feishu.cn/docx/MiGndU4GgocEEBxdaBicH🐧DnDb)

- **问：**之前群里讨论过的证据出境的问题，目前有结论了嘛？

- **答1：**针对数安法36条，司法部还没建立完善程序，现阶段不会给审批的，但企业想用36条来抗辩，司法部会默许。针对其他跨境证据调取问题，有公约，也有国际协助中心，但就得走公对公。

- **答2：**国际协助中心现在应该是不接了，您说的默许可以稍微展开讲讲吗。

- **答3：**中美确实是不接了。比如司法部（DOJ）或者法院要求境内的中方提供证据，如果不想给，可以说数安法36条有审批要求，所以我们给不了，司法部也不管的，毕竟是咱们的主权利益。

- **答4：**关键是，这么说了，美国法院或是DOJ能接受么。

**总结：一团迷糊。**
