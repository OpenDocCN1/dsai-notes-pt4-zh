# 使用ReID技术需要单独同意吗

> 来源：[https://docs.feishu.cn/docx/KorQdWt3DoWHl8xgRhQcOGmnnYy](https://docs.feishu.cn/docx/KorQdWt3DoWHl8xgRhQcOGmnnYy)

**-问：**《个保法》26条的单独同意是否仅限于对生物识别信息等特殊信息的处理上？商场、门店安装图像采集设备，如果以不识别特定个人、不采集人脸信息的方式处理图像内容，是否需要获得单独同意？

例如，客流计数（头肩比或人脸检测后，以框定的框的轨迹判断是否进店），性别分析（人脸男女检测计数，不识别特定人），年龄分析（人脸年龄检测计数，不识别特定人）等不使用识别能力的人脸图像的处理。

又例如，对于视频和视频处理，现在的视觉识别能力可以不依赖人脸，使用人形图像也可以实现识别能力。比如reid技术，通过将视频里的人形图像采集一定数量的图片做底库，来检测出某个人是否重复进店，从而实现精准客流（即去掉重复顾客、店员）。这类技术，是否还需要单独同意？

**-答1：**“检测到某个人是否进店”抽象下来其实就是定位到某个具体个人了吧，不管你收集的是体态信息和人脸信息，至少在这个场景下收集的目的都是一致的。

**-答2：**看**是不是可以识别到个人** traffic tracking solution各家不太一样的。

**-答3：**要不…试试**激光雷达**。

**-答4：**为什么不用单独同意，“推测”这个采集肯定不只判断是否进店。

**-答5：**我**想说，用那么多识别技术的，应该不是正经做零售的。零售行**业做traffic记录，最直观的就是要看开店的位置表现是否如预期，毕竟客流是开店王道。其次就是做店铺销售情况的考核了，并没有对人脸性别等其它特征和数据的关注必要。

**-答6：**ReID也是生物识别技术。依据如下:

> （1）生物特征识别安防应用技术

> 人脸识别。研究基于传统和深度学习的人脸活体检测技术，提高识别精度。

> 人员再识别（ReID）。研究基于视频图像的人员再识别（ReID）基础理论、测评方法，研究超大规模人脸/人体数据动态组织检索技术。
