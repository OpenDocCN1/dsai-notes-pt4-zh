# 公共采集单独同意的理解

> 来源：[https://docs.feishu.cn/docx/U6Qzde3qzoPEw5xgdCecNXkonXd](https://docs.feishu.cn/docx/U6Qzde3qzoPEw5xgdCecNXkonXd)

**-问：**《告知同意指南》中“出于公共安全之外目的在公共场所采集个人图像、身份识别信息的，需取得用户的单独同意”这里的“、”是如何理解？到底表示“或”还是“且”呢？

**-答1：**顿号前后元素是**并列关系**。

**-答2：**“所收集的个人图像、身份识别信息只能用于维护公**共安全的目的，不得**用于其他目的”——这是个保法下的法条表述。按照法典的行文，这里的“个人图像、身份识别信息”是两种类型的信息，无论哪一种都按照这条规定适用。

**-答3：**关于顿号的用法，国标里我记得有过不同情况的描述。其中有一种是表达“且”的概念。比较典型的是：当说“做什么事情”需要具备“条件一”、“条件二”，那表达的意思是二个条件都需要具备。这方面我们以前研究过，我记得还有判例。“所收集的个人图像、身份识别信息只能用于维护公共安全的目的，不得用于其他目的”和上面的语句模式不一样，表达的是“个人图像“和”身份识别信息”具有不分主次的并列关系，结合后面的要求（只能用于维护公共安全的目的、单独同意除外），应理解为仅收集二者之一也只能用于维护公共安全的目的、单独同意除外。

**-答4：**按照个保法的条文来理解，采集个人图像或身份识别信息的任一一种都要单独同意，并不要求这种个人图像一定要用于身份识别。要不就给公共场合开放摄像头随意安装留下太多空间了。

**-答5：**“、”本身只是并列关系，分辨逻辑关系，要看前后是否有且或者或的提示，或者结合语义理解。后面这种虽然有主观性，但是也得符合基本逻辑吧。对条款的认识要回归基本直觉吧。

总结：必然是或的关系，任一即须单独同意。
