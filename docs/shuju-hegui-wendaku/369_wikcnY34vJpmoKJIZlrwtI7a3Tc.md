# 会员库回迁告知同意

> 来源：[https://docs.feishu.cn/docx/RH98dHaN9otoksxznd8cUGD5nyg](https://docs.feishu.cn/docx/RH98dHaN9otoksxznd8cUGD5nyg)

**-问**：有人处理过整体会员数据库从第三方迁移回品牌方的情况么，之前所有的同意都是第三方去取得的。之前同意都是第三方名义获得，品牌方和第三方是经销商模式，经销商是独立自主运营的

**-答1：****信息收集方应**该算是第三方吧，感觉要全部重新获得同意。

**-答2：**那就是数据处理者主体都变了，肯定得重新跑同意流程了。

**-答3：**不如一开始就**共同控制者**方**便，不过**经销商不稳定就比较困难。一开始就共同控制者的话当初得有约定，猜测是没有，但是我理解过去没有这个法律概念，是不是可以后期解释成这个关系。

**-答4：**“品牌代理”这个称谓从法律关系上说是要做进一步解析的，因为它不是严格意义上的法律概念。经销商和品牌商，不是法律上委托-代理的**关系，严格来说，是**品牌许可和被许可的关系。从这个关系上出发，经销商的个人用户数据跟品牌方没有任何关系。如果品牌商要处理，必须重新走告知同意。从业务层面，就是买卖关系，从商标层面，可能会存在许可与被许可关系。

**-答5：**品牌方为了收回渠道，会要求经销商把消费者数据给出来，这是合同关系约束。但是，对于是否提供出来后就可以直接用，这就要再看个保法的相关规定。比如，隐私政策怎么定的？品牌方有没有介入过消费者管理？食品的话还有溯源要求，品牌方是否有法律规定有权了解商品的最终流向。
