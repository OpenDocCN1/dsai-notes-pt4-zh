# 电话录音的同意

> 来源：[https://docs.feishu.cn/docx/S89odF1rKoQcIvx9TJfcI6C7nch](https://docs.feishu.cn/docx/S89odF1rKoQcIvx9TJfcI6C7nch)

**-问**：请问一下客服给消费者打电话的时候，或者消费者有事打给客服，这种电话录音的情况，大佬们的公司有做不同意录音的选项吗？还是说只是在电话开头提示了本次通话将被录音？请问这个是不是在获取消费者手机号的时候有一个服务协议获取消费者的电话？就是比如说在前期使用我们的App的时候，在隐私政策里就有关于后期使用用户手机号的场景吗？但是就是录音这事儿我在想跟仅获取手机号好像也不一样？

**-答1：**我们是通过前端隐私政策获取同意。

**-答2：**有公司在拨入前加了一段**语音播报的收集录音的表述、包括目的、存储位**置和期限，提醒用户如果不同意可以直接挂断。

**-答3：**印象中戴森客服热线在隐私政策告知这块做得不错。按某个键，可以收听较为详细的隐私告知。
