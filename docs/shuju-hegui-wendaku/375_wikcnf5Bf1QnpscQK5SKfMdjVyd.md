
# 客服录音的告知同意怎么做

> 来源：[https://docs.feishu.cn/docx/RPZMdYEuYo4oV1xEQRicHgp8nPh](https://docs.feishu.cn/docx/RPZMdYEuYo4oV1xEQRicHgp8nPh)

**-问：**线上客服或者店铺客服在服务过程中的语音记录，是不是也要征得用户同意？比如10086，客服会提示接下来会录音，但实际无需同意。

**-答1：**加，如不同意请挂断。

**-答2：**可以看看之前的讨论，电话录音的同意：`https://www.yuque.com/hechenmeiyouyi/dy2cgf/mvp91z`。

**-答3：**如果是直流的话，针对另一端可以实时看到车端的车外图像，还有和哨兵模式一样的监管风险吗？

**-答4：**要的，这个ISO审核的时候老师提示过。

**-答5：**实践中好像一般用户主动打给客服的，会有语音提示，比如您的通话将被录音，但是客服主动打给客户的，好像会提示录音的比较少？

**-答6：**等下......问界的畅连实时视频通话功能应该是 车内 音视频交互吧？另外还有一个衍生问题，如果用户要求删除通话录音的，企业能否拒绝呢。

**-答7：**是否和录音的目的有关系？是否存在豁免同意合法基础的情形（比如说为履行合同所需）？

**-答8：**个人感觉是这样的，但是一般电话录音的很多场景大多还是用户主动寻求帮助的叭，至于用户请求删除通话录音，更多是不是还是要考虑用户行使删除权的依据哦。

**-答9：**（1）大部分商业场景都需要取得个人同意；（2）部分行业需要个人同意，但全程录音是法律义务（部门规章或行业指引，如证券行业、保险行业、银行业等）；（3）无论是否通过个人同意进行录音，不影响行使删除权。

**-答10：**之前接到过快递，银行的给我打电话，好像她并没有先告诉我他们在录音，我主动拨打的时候确实有提示。比如有一些录音能证明企业履行了义务或者为了防止后续有纠纷的时候企业无法举证，用户要求删除，企业能否拒绝呢？还是说要看录音里具体用户说的是什么？

**-答11：**如果说，不同意请挂断，那岂不是可能被认为是强制同意？如果沟通的渠道只有客服的话， 不同意录音就没有办法反馈问题了。至少还需要提供一个当用户不同意录音的请下的其他服务方式。
