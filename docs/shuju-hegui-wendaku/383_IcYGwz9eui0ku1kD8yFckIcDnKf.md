
# 审计机构个人信息处理身份

> 来源：[https://docs.feishu.cn/docx/HckRdLRIeoJUtaxSPAbccfyUnug](https://docs.feishu.cn/docx/HckRdLRIeoJUtaxSPAbccfyUnug)

## 讨论问题

**-问：**会计师事务所为企业做财务年审，企业提供员工个人信息给会计师事务所，企业和会所之间是controller和processor关系，还是独立controller

## 社区讨论

**-答1：**审计有独立性，审计机构独立决定处理目的，倾向于后者。

**-答2：**记得欧盟指南有明确这个场景是单独的控制者。（Guidelines 07/2020 on the concepts of controller and processor in the GDPR）

**-答3：**这里非常大的难点是：审计方一旦被认定为独立处理者，对于审计中处理的用户和员工个人信息都要以审计方名义进行在先告知和获得同意（无法基于履约），企业需要就提供个人信息给第三方处理者获得单独同意，而且审计中处理的个人信息可能是海量的还可能是随机抽取的样本（处理的数据不一样，也不知道会抽到谁）……这种C端合法性机制有企业真的落地过么？想不出如何实操。

**-答4：**审计看c-p，入底稿c-c？

**-答5：**解释为履行法定义务，但如果是境外交易所的规则要求年审，就更绝望了。

**-答6：**合规审计可能靠的上履行法定义务，但是很多财务和法律尽调很难有同意之外的合法性基础。

**-答7：**能不能用履行合同所必需？履行的是劳动合同。员工的合同义务是配合公司完成审计，共同治理好企业。

**-答8：**且不说这种场景下“法定义务”对C端用户难证明，在先的逐一“告知”问题就是大bug，就是审计之前还得先提前告诉你我如何具体审你？而且，审计方（如果被认定系独立处理者）和员工木有合同关系，无法走这个合法性基础……“企业审计”很难被认定为履行劳动合同之必需（劳动合同中写上这条，也并不意味着就必构成履约必要，最多是确保有“一揽子告知”）。如果涉及给到审计方还会数据出境，就更难论证是劳动合同履约必要了。

**-答9：**看看这篇，石佳友：《中欧上市公司审计监管合作法律问题研究》

**-答10：**比较重视合规的公司会多上一层员工同意的保险，不过条款的设计很难覆盖所有审计场景或者又会存在授权泛化而导致效力不足的问题。感觉通用的做法还是履行法定义务➕另有规定的兜底条款进行解释。但其实这个角度也更容易被企业主使用，审计机构则需要论证更多。好奇请教大家:那欧盟的审计机构作为controller是怎么应对这个信息处理正当性问题的呢，靠合法利益吗？

**-答11：**审计机构会通过合同把取得同意的义务给到企业。而且，入职的时候勾选也会有瑕疵，审计机构会变化的。客户信息也同理，每次弹窗几乎不可行。

**-答12：**是啊，如果企业向审计方（假设作为处理者）提供个人信息，需要适格的“单独同意”（至少得是适格的告知），应是即时触发的告知—同意，且告知内容要具体明确，而员工入职时企业并不知道此后每年接收数据的审计方名称、联系方式、处理方式和个人信息的种类、是否出境等，所以事实上无法履行向其他处理者提供个人信息场景下的告知义务，因此相应的“同意”也有很难说充分有效。同时，审计方（假设作为独立处理者）自身处理数据的告知和合法性基础问题还是无法解决。总结下来，只要认定审计方是系“独立处理者”、不是“受托处理者”，企业和审计方“各自”的个人信息处理行为就是难以均确保合法合规，实操中无法落地。这样的法律判断，没有合法性方案支撑落地，就变成业务咋做都是错，哭死。其实还是回到起点：审计意见独立，真的就意味着数据处理身份就必须约定为独立处理者么？同理，企业委托律所提供独立的法律意见、需要提供个人信息时，也是把律所作为独立处理者么？

（整理者注：根据EDPB指南律所是独立控制者）

**-答13：**俺觉得不一定～有时候商业关系与数据处理关系也会剥离，所以这块我感觉是蛮难判断～

**-答14：**同意。EDPB也写了，要看instruction的强度。监管委任的第三方强制审计可以是独立控制者，但上市公司审计还是视为joint比较合理。机构间通过协议强行撇清任何共同或委托关系是起不到实质作用的，还是应通过业务关系看数据处理。

**-答15：**我也在思考这个问题，审计机构严格来说是在对什么信息进行审查和处理，目的是什么。这个和个人信息保护的合规审计一样吗？审计机构在财务审计上的独立性，是法定要求，这个和审计机构是数据控制者的独立性，一样吗？我总感觉财务审计场合，个人信息使用的目的还是财务审计用途、出具独立的审计报告，并没有因个人信息的类型和场景有变化。

**-答16：**同一直在疑惑，个人信息保护审计个人感觉并没有必要处理真实的个人信息，但其他尤其跟业务有关的审计，很难说清楚是否一定不涉及；另外，律所接收个人信息以提供法律意见的可能场景有哪些？雇员的个人信息？合理怀疑必要性。

纯讨论：个人感觉两种独立性指向的对象是不一样，但会因为审计过程中存在个人信息处理而发生关联。由于财务审计独立性的法定要求，审计范围、被审计方应该提供哪些evidence（包含个人信息）、如何提供，实际由审计方决定、指定的，那么在这一审计活动中，审计方作为数据控制者的独立性就体现了…就像前面群内大佬提到的，协议定义了关系但可能还得以实际场景判断。

**总结：企业好难。**
