# 如何规制劣迹顺风车司机

> 来源：[https://docs.feishu.cn/docx/Awt3dk3oxoy0jbx690ycQpmAnrc](https://docs.feishu.cn/docx/Awt3dk3oxoy0jbx690ycQpmAnrc)

**-问**：某些顺风车司机可能会性骚扰乘客，但尚不构成刑事犯罪，只有平台方可能掌握相关的投诉记录。若司机注销账户后，平台根据《个保法》需删除所有个人信息，如何规制他们重新注册洗白呢？

**-答1**：是否可以考虑由行业主管部门或协会建立黑名单机制。

**-答2**：这可能不仅仅是个技术问题，或许还要涉及到法理问题，比如说是不是要通过防止再注册的手段进行负效应惩戒，其他数据库是否有权因为个人违背公德行为而获得相关个人的信息及衍生数据，这个评判的标准和尺度在哪，有没有涉及被遗忘权的问题，感觉还蛮复杂的。若需设置黑名单，还需要考虑准入界限如何设定，制定权在谁手里，可以变成行业内通用吗等等问题。

**-答3**：首先，外卖、司机与平台都不是纯C端用户与平台的关系，他们与平台有基础的法律关系，信息收集的合法性基础也不完全是基于同意，账号的注销和删除权本身就有一定的限制；其次，如果是纯C端用户账户，注销也是要考虑平台管理规定的，可以参考《互联网用户公众账号信息服务管理规定》第十九条，可以列入黑名单、禁止重新注册等处置措施。当然也需要结合平台处罚的原因来看。如果有法定义务作为依据，留存一定的识别标识防止再注册也有解释空间了。

**相关法规：**

> 第十九条

> 公众账号信息服务平台应当加强对本平台公众账号信息服务活动的监督管理，及时发现和处置违法违规信息或者行为。

> 公众账号信息服务平台应当对违反本规定及相关法律法规的公众账号，依法依约采取警示提醒、限制账号功能、暂停信息更新、停止广告发布、关闭注销账号、列入黑名单、禁止重新注册等处置措施，保存有关记录，并及时向网信等有关主管部门报告。

> 《互联网用户公众账号信息服务管理规定》
