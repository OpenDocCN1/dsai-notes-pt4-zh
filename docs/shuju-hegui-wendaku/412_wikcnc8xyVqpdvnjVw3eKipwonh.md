# 账户注销后虚拟财产处置

> 来源：[https://docs.feishu.cn/docx/NGLrdfFGkowDTDxN5GZciSbcnVb](https://docs.feishu.cn/docx/NGLrdfFGkowDTDxN5GZciSbcnVb)

**-问**：注销后虚拟物品等同放弃权益，有问题么？

**-答1：**这个问题，司法实践也有比较明确的结论了，游戏装备不可折现，但真金白银兑换的点券或者游戏币是可以折现的。可以看看这篇文章：从《云裳羽衣》谈游戏虚拟物品的所有权与使用权之争。

**-追问：**真金白银兑换的游戏币，拿去抽奖，抽出来的装备呢？

**-答2：**不折现，对装备你只拥有使用权。
