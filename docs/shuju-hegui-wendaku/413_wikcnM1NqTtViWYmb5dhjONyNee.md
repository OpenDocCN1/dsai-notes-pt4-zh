
# 注销后3个月禁止重新注册的合规性

> 来源：[https://docs.feishu.cn/docx/RLZPdT6t5oIaQDxNiQdcVBcondc](https://docs.feishu.cn/docx/RLZPdT6t5oIaQDxNiQdcVBcondc)

**问**：业务想要在隐私政策里增加”删除或注销后3个月或180天内不能重新注册？“，我总觉的有问题，像是在引导用户不要注销，或者说给删除权行使增加条件。

**答1**：可以看看这篇：App账号注销设置条件的合理性边界在哪？

> ——App开发者/运营者如果发现用户账号存在涉嫌刷单、灌水、违反规定发布信息等情形时，当用户选择进行账号注销时，可进一步进行身份核实，注销后，可以将手机号等信息进行技术处理（不与用户任何其他信息相关联）后保存在风控系统，防止其短期内再次注册。

**答2**：这个说法本就有问题。为什么注销后不能重新注册了？技术上没有难度，所以禁止用户注册的合理性在哪？而且你这种说法，也是有问题的。就是你怎么知道用户是注销3个月内？

追问：如果这个用户并没有不当行为，是不是还可以这样做，属于企业经营的自由么？

**答3**：有可能会违反《电信和互联网用户个人信息保护规定》和《工业和信息化部关于开展APP侵害用户权益专项整治工作的通知》（工信部信管函〔2019〕337号）。

**答4**：这样不知道是不是出于技术安全的考虑？我们技术侧确实是为了规避技术风险，要求用户几天内不能重新注册，但没有3个月这么久，而且准备了配套的客服话术进行解释。

**答5**：我们在新客优惠活动页和注销须知里，加上了类似表述，告知用户会保留一段时间手机号码方便核验。这段时间内该手机号重新注册的话，新账号无法享用新客优惠。当然在此之前，大量薅羊毛的账户已经进永久黑名单了。
