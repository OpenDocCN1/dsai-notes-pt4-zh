
# 注销账号和删除日志的关系

> 来源：[https://docs.feishu.cn/docx/YAtUdQe8PoxJMKxYVFWc6anqnAS](https://docs.feishu.cn/docx/YAtUdQe8PoxJMKxYVFWc6anqnAS)

## 问
请教个法律问题，关于用户在互联网平台注册和注销账号，这种是否属于网络日志范畴？

## 答1
看看这篇“相关网络日志保存6个月以上”的合规义务如何落地。

## 答2
也可以看看这篇汇业评论 | 账户注销及用户信息删除的合规实务问答。然后回复你一下，如果单论这个行为，注册和注销账号这个行为对应的记录是确实属于网络日志的。但是要注意弄清楚到底啥是网络日志以及账号这一块的存储期限。

## 答3
账号注册需要永久储存，公安有个标准。
