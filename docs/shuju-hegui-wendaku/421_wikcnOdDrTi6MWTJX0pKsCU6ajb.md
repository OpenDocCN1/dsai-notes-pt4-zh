
# 数据使用的边界

> 来源：[https://docs.feishu.cn/docx/XL36ddBcKoVpbdxycKRczW2Dn5c](https://docs.feishu.cn/docx/XL36ddBcKoVpbdxycKRczW2Dn5c)

**-问**：数据使用大家对于这个概念是怎么理解的，是排除了收集存储删除以外的数据处理活动吗？问这个问题是会发现其实法律一般是以“处理”作为一个制定原则的范围，“收集、删除、储存”也都有特别的明确要求，但是针对“使用”没有什么很具体的。

**-答1：**感觉在原始收集目的中提供用户**产品功能**的部分之外的，都可以算使用，比如产品分析之类的？

**-追问：**比如算法，比如自动化决策，比如人脸识别？

**-答2：**可参考杨合庆主编的《个人信息保护法释义》

![](img/7082b3222095023dd63a8f4975f61781.png)

**-答3：**这么看的话，大部分对于“使用”的要求都是和“收集”相关的，比如最小必要，比如透明公示，只有很少的特定使用情况需要单独分析，比如营销和自动化。

**-答4：**程啸老师这本书也有一个“使用”的定义。
