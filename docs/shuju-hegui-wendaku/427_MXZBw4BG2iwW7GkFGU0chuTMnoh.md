# 处理已公开个人信息侵权

> 来源：[https://docs.feishu.cn/docx/HSa2d5VvUo422qxZJWDcc9q2nhf](https://docs.feishu.cn/docx/HSa2d5VvUo422qxZJWDcc9q2nhf)

**-问：**大家怎么看这个案例：【法脉准绳】网络服务提供者处理已公开个人信息，是否构成侵权？

**-答1：**索赔20w，赔了800。

**-答2：**关于被告是“处理者”而非“受托处理者”问题的分析（不是结论）是个瑕疵，毕竟这个问题很重要，不仅影响了合法性基础，还决定了是否需要“单独同意”等，但其他问题的分析还是挺好的。司法判决还是“讲理”的。

**-答3：**同感，对于“处理者”身份的分析有些冗长，有些机械的法条主义，其实核心就是：D平台有自己独立的处理目的。

**总结：谁决定处理目的核心。**
