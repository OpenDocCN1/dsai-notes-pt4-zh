
# 中登网信息查询

> 来源：[https://docs.feishu.cn/docx/O9b6dn2gfoxmTpxUtooczdIGndh](https://docs.feishu.cn/docx/O9b6dn2gfoxmTpxUtooczdIGndh)

**问：** 发zf提供的权属信息登记平台，比如中登网，查询特定个人在这个网站上的被登记的信息，需要个人授权吗？

**答1：** 取决于信息**是否公开**，如果非公开，就和查征信一个性质，没有其他合法性基础就要。

**答2：** 比如派出所法院调查令就不需要个人授权，或者履行法定义务，做适当性或者身份识别那些。

**追问：** 那比如现在去房产交易中心查档，可以查到什么程度，按地址查，还是需要业主去查？是同一个逻辑吗？

**答3：** 不动产中心规则说的很清楚：`http://djzx3.ztnt.net/wxfront/realestateDataList.html`

![](img/f4e70f59cae0969e1c732db7a73eaf65.png)

**答4：** 可以根据不动产具体坐落地址查询该坐落的不动产自然状况、地籍图，是否存在共有情形，是否存在抵押登记、查封登记、预告登记或者异议登记等信息。任何人都可以。

![](img/8e6caf1c23f9bbd890c1d4138dc76627.png)

**答5：** 中登网可能比较特殊，登记就是为了使被登记物的抵质押状态广而告之，或登记公示、公开可查。详见：`https://www.zhongdengwang.org.cn/cms/goDetailPage.do?oneTitleKey=djyf&twoTitleKey=djln`

![](img/65ee26030a2ef9021cc22ec99b83fbe3.png)

总结：取决于相关信息是否构成公开信息。
