# 《个保法》中“提供”的含义

> 来源：[https://docs.feishu.cn/docx/C5QTdXsu9ob5PMx5DILcL4Zgnac](https://docs.feishu.cn/docx/C5QTdXsu9ob5PMx5DILcL4Zgnac)

**-问****：想请问**大家**是否有讨****论过关于个保法中**的“提供”的相关含义呢？因为我目前看到的程啸和江必新的两本书，然后我发现书中对于不同条文的“提供”的解读是不一样的，例如江必新的书中认为“向境外提供”实质上就是个人信息出境，感觉强调的更多是物理位置的变动，但是对于23条的“提供”就是信息处理者的变更，跟GDPR中的controller比较相似，然后《信息安全技术 个人信息安全规范》用的是共享，我就感觉这个共享和个保法的提供又比较相似。很想知道大家对这方面的问题有什么见解。总结一下，就是跨境到底是物理移转还是控制者移转。进一步引申的问题是，委托境外主体处理个人信息，是不是出境。受不受第三章管辖。

**-答1：**史律师观点如下：

> 《个人信息保护法》第3章中“提供”相关条款仅适用于处理者向其他处理者提供个人信息的情形，即适用于“处理者-处理者”的法律关系。如果境外处理者直接处理境内自然人个人信息（如直接收集），第3章中数据提供的各项义务将不再适用，即《个人信息保护法》第3章数据提供相关条款不适用于“个人-处理者”的法律关系。

> 时雨行，👸号：送法上网思想实验：数据跨境规则的逻辑推导

**-答2：**这个好像之前有或讨论。我个人认为，不论委托境外主体处理还是境外主体have access to都属于出境。

**-追问：**那第三章的跨境提供是不是强调的是跨境，而不要求信息控制者的变更？

**-答3：****澳大利亚**的APP指南有类似规定认为，与域外处理者以合同等方式严格约定其处理方式等内容的时候，不被认为是向境外披露个人信息。

**-答4：****有跨境因素吧，即便没有物理**出境，境外主体可以查看我觉得也算。
