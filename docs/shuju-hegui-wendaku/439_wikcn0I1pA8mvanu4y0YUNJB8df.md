
# 个人信息接收方的核查义务

> 来源：[https://docs.feishu.cn/docx/TeqedYEw1oudRnxzHHJcjbn9nvr](https://docs.feishu.cn/docx/TeqedYEw1oudRnxzHHJcjbn9nvr)

### 问

A公司从B公司获取个人信息用于A的处理目的，需要采取哪些措施才能保证A的行为不落入“非法获取个人信息”（刑法253条之一）呢？A的审查义务要做到多深呢？目前A采取的措施包括，1）向B发问卷调查数据来源，根据B的回复判断来源是否合规；2）要B签承诺书承诺来源合规，以及提供给A的行为合规。此种情况下，A是否还需要去根据B的回复，再去核实B是否在说假话？比如B说通过隐私政策取得了个人的授权，A还需要去看隐私政策吗？

### 答1

接收方的审核义务没有尽头，如：①仅合同层面承诺；②合同承诺+前置审核；③合法性承诺+事中抽查；④合同承诺+事后停止合作。

### 答2

个人理解，该等注意义务不来自于《个保法》第23条，而是来自于《个保法》第13条合法性基础。也即，接收方处理个人信息也需要取得个人的同意，或者具备其他合法性基础。且由于《个保法》第23条要求提供方取得单独同意。因此，在不具备其他合法性基础的情况下，是需要核查提供方是否取得单独同意。此外，应采取何种核查手段，可能需要结合个人信息的敏感性、个人信息处理活动的潜在危害性、接收方合同中强势地位、接收方法律合规部在公司地位等等因素综合确定，并不能有一个统一的标准。

### 答3

流程合规+检查同意记录。

### 答4

现在实践中普遍不直接拿个人信息，合规成本太高了。
