# 机构数据的收集、处理

> 来源：[https://docs.feishu.cn/docx/StL1d1NEcoRe95xML7Ic26W6nzg](https://docs.feishu.cn/docx/StL1d1NEcoRe95xML7Ic26W6nzg)

**-问：**请教大佬们一个问题，如果信息主体（非个人）在给A的授权书里面表明，同意【A公司】的数据来源方【B公司】去【C机构】采集自己的敏感数据进行加工，这种授权是可以的嘛？B或者C还需要再去拿信息主体的授权吗？但信息主体不是个人，我理解不需要单独同意。我感觉有点像是企业去银行贷款一样，允许银行委托第三方去查企业信用信息看看够不够格，但这个第三方好像不需要再获得企业的同意。

**-答1：**毕竟对C来说，它对外提供了它客户的信息**，基于它**与它客户的合同关系，这部分可能是保密信息，到时候B直接过来调，我要是C的话，我没接到我客户的告知，我不会给的。

**-答2：**这个场景下面都不是个人主体，不涉及**个人信息**那一套，硬套数据合规的话，那就是数据安全，保证数据流转的时候不会泄露、数据质量完整、数据不被篡改。

**-答3：**这**个问题问是否**【需要】拿授权的【需要】意思是授权是必要条件，也即:如果我是c，如果我没有单独再拿信息主体的授权就把数据给到B，我必定承担相关责任？我个人觉得这种嵌套授权的情况下，再获取不一定是必要的，要看场景，看信息主体和c之间的合同约定，同意qj姐姐。如果信息主体和c之间的合同内容约定了告知/再获取授权的义务，那情况又不一样了。

**-答4：**非个人信息需要看企业类的信息是否公开信息，如果是工商信息、司法信息已经公开的信息，是不需要授权的。如果是非公开信息，涉及到商业秘密，需要重点关注企业授权是否充分，评估是否存在商业秘密泄露带来的刑事和民事风险。

**-答5：**这里还有个问题，数据处理（个人或非个人）中的“委托”和“授权”是什么关系，民法里面这两个性质完全不同，授权访问和处理与委托合同之间是无因的么？可否有永久不可撤销的授权？

**-答6：**若C为**金融机构**，只要是其客户信息，无论是否客户为自然人，均不宜随意向外提供。
