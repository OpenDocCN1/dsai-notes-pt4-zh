
# 关联方数据报送

> 来源：[https://docs.feishu.cn/docx/UNPqdmLEmoWZUGx78nfcCAGqnGg](https://docs.feishu.cn/docx/UNPqdmLEmoWZUGx78nfcCAGqnGg)

### 问

金融机构报送关联方数据，涉及敏感个人信息，无法律法规规范性文件明确合法性基础，大家有过顾虑吗？

### 答1

我理解关联方披露报送是有监管合规的要求的，和金融客户服务还不太一样。可否这么理解，关联方有直接关联方和间接关联方，间接关联方是通过直接关联方发生联系的，那直接关联方在比如成为金融机构关联方的时候（签约、任职等），是知晓自己和自己相关的亲属等关系需要纳入监管的。这也是金融机构做关联交易管理体系建设需要考虑的内容。

![](img/b010151850bbfad2d52729fdd6f1017b.png)

### 答2

管理办法规定作为合法性基础，不过相关告知要做好。
