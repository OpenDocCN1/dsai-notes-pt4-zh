# 临床试验主体变更

> 来源：[https://docs.feishu.cn/docx/TKWBdDY0Ko0WA1xkDCxcTKGKnwf](https://docs.feishu.cn/docx/TKWBdDY0Ko0WA1xkDCxcTKGKnwf)

**-问**：想请问大家，如果进行中的临床试验因为要更换申办方，因此需要转移受试者数据，这个转移有可能涉及跨境和境内的转移，大家认为是否需要受试者签署单独同意吗（比如重新签ICF?）但目前有些受试者已经中断了，所以拿到所有受试者的同意不现实，有什么折中的方式吗？

**-答1：**让**原申办方破产**，或者**被新申办方收购**。

**-答2：**管辖法律是中国法吧？如果是的话，设原申办方为A的话，数据只能留在A的壳里处理才具有合法性，其他的合法性依据都靠不上啊。

**-答3：**应该需要重构交易路径，考虑可以适用22条的架构，当然确实涉及出境的话，那就复杂更多了。
