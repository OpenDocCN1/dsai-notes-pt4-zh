# 公司分立数据转移的适用

> 来源：[https://docs.feishu.cn/docx/IEG7dXHI3oDm5wxRisTc9xXGnHb](https://docs.feishu.cn/docx/IEG7dXHI3oDm5wxRisTc9xXGnHb)

**-问：**根据个保法第22条 合资公司变更为由外资股东（外资公司）单独控股的话 这个算分立？原合资公司的个人数据直接归这个外资股东吗？ 还需要告知否

> 第二十二条 个人信息处理者因合并、分立、解散、被宣告破产等原因需要转移个人信息的，应当向个人告知接收方的名称或者姓名和联系方式。接收方应当继续履行个人信息处理者的义务。接收方变更原先的处理目的、处理方式的，应当依照本法规定重新取得个人同意。

> PIPL21

**-答1：**股东原则上拿不到数据吧。你把合资公司注销了品牌放回去，需要告知，可以不单独同意。

**-答2：**不用告知，也不用同意。就是这个实体。股东变更弹隐私政策，也没见过呀。如果涉及对外提供给股东，在履行出境/对外提供的手续呗。

**-答3：**仅就**更**换处理者股东、处理者主体本身不变（不是分立/合并等），不用告知也不用同意；涉及向境外股东提供个人信息的，则属于“对外提供”且出境的场景，该走啥合法性基础和该咋出境就咋处理。仅就境外接收方的“股东身份”而言，不是一个免责或高风险因子，没有因此需要特别豁免或特别增加的法定处理义务。不过内部PIA评估时，倒是可以考虑就关联公司之间的处理减缓一些风险等级啥的，这个就丰俭由人了。

**-答4：**原合资公司和外资股东是两个法律主体、两个处理者。是想戳穿公司面纱，再搞个责任连带？

总结：注销后拿走，可以豁免单独同意，但出境审批手续肯定还是该走还得走。
