# 委托处理包括收集吗

> 来源：[https://docs.feishu.cn/docx/PFdIdaiSPoOs7CxVx2GchnrlnXd](https://docs.feishu.cn/docx/PFdIdaiSPoOs7CxVx2GchnrlnXd)

**-问：**你们觉得委托处理个人信息，包括委托收集吗？比如APP拉新的场景，具体一点的场景:朴朴超市app拉新，由营销公司制作、提供H5落地页，新人填写手机号码注册后的信息由营销公司先收集，再回传给朴朴公司。我的理解，处理包括收集。但是委托收集的话，在委托之时，委托人都不是个人信息处理者，等信息返回后才是个人信息处理者。

**-答1：**题目**是**，收集也是处理行为。但是你举例场景不一定是。

**-答2：**营销公司是否能**自主决定**收集信息的范围和用途？不能的话，即使收集这个动作是它做的，也是为了给别人收集，依然是受托处理者。如果其在“委托处理”这个环节能被认定为是个人信息处理者的，那就不会是委托处理了，可能会是共同处理。

**-答3：**你误解了个人信息处理者这个概念，处理者不是必须接触数据。

**-答4：**可以看看史律师的这篇文章：数据合作的法律关系框架：共同处理、委托处理、提供与技术支持。
