
# 概括性委托构成个人信息委托处理吗

> 来源：[https://docs.feishu.cn/docx/TkSbdYnnGob1WhxOZBncIEkdnid](https://docs.feishu.cn/docx/TkSbdYnnGob1WhxOZBncIEkdnid)

## 问
概括委托的情况下，受托人算个保法规定的个人信息处理者嘛？这种情况下，如果涉及出境问题的话，个人信息保护影响评估或者出境安全评估什么的，义务主体还是委托人吗。概括委托的意思是，比如说a公司是中国的外贸公司，b公司是快递公司，a公司委托b公司把货物从中国转移到境外买家手中，一切事宜均由b公司负责，这种情况下b公司算是能够自主决定数据的处理目的主体吗。

## 答1
受托处理者不自主决定处理目的，**不是处理者**。受托方没有评估义务，去做评估网信办也不收材料，群里之前有朋友分享过。概括性委托是否构成个人信息委托处理是另一个问题。看是否满足“应当与受托人约定委托处理的目的、期限、处理方式、个人信息的种类、保护措施以及双方的权利和义务等”即可。

## 答2
我的想法有点不一样，**合**同约定是什么关系不一定就构成什么关系，“应当”后面是委托方的义务，但并不是判定标准，判别标准还是谁决定了个人信息处理的目的和方式，不过合同可能是其中一个比较关键的证据。

## 答4
赞同。是不是委托处理，有个很重要的标准。实践**中的，所谓决定处理**目的，其实很大一方面看谁有权决定存储数据。

提供者一般都是处理者，即使有时合同里也是受托方比如委托做人力市场调研，但是有数据详表的。接收者可以存，那也是处理者。

但如果这个场景中，接收者不让提供者存储数据，那提供者一般不作为处理者。就是受托方了。但在这个委托处理场景之前的收集环节，提供者还是处理者地位。

## 答5
数据接**收方/提供方 vs **数据处理者/受托方，这其实是两个不同维度的问题，不必然绑定。实际的数据流可能从处理者到受托方，也可能从受托方到处理者。这些不同模式在各种业务场景中都挺常见。欧盟SCC的模板类型设置也清晰说明了有多种数据流向模式。法律人的火眼金睛就在于：能摸排出实际的数据流+能识别出“法律”意义上的“处理者和受托方”，然后写明白数据处理协议——当然，合同文本的基本功要过关，避免唯数据流向决定论。
