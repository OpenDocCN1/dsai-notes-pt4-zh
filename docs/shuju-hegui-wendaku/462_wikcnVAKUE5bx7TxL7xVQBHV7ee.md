# 员工信息委托处理的认定

> 来源：[https://docs.feishu.cn/docx/S2wLddkQ3o6QGRxRvYPcvftdnBg](https://docs.feishu.cn/docx/S2wLddkQ3o6QGRxRvYPcvftdnBg)

**-问**：如果B公司给客户公司A提供相关服务，其中客户A公司需要提供其员工个人信息给B公司，问：

1）如果该员工不居住在国内，也不回国，那么B公司处理该员工个人信息是否需要满足PIPL要求？

2）如果1结论是不需要满足PIPL，那如果员工偶尔会出差回国呢，那要怎么判断呢？根据员工在国内期间B公司是否在进行数据处理活动？

3）主要疑问来自：PIPL第3条第一款“在境内处理自然人个人信息的活动” - 该“自然人”是指境内自然人还是更大的范围？

**-答1：**第一款的点很清楚，是处理行为在境内。自然人指境内自然人，与国籍无关。

![](img/8d8be2e7374cc52c5beec12d076224ee.png)

**-答2：**(1)两个公司如果都是国内公司，该员工个人信息产生并由A收集（处理）于国内，属于PIPL下的处理活动，不会影响适用吧。我理解是B也跑不了，因为其和A的关系虽然是委托受托关系，但B行为也是处理活动，应受PIPL规制。处理者和受托处理者因为没有和GDPR区分，所以都在处理者的范围，至少在中国法语境下是这样的解读吧。

**-答3：**这里使用适用《个保法》应该看A公司的处理行为在哪里，如果在境内就适用。B公司在哪里倒无所谓，他只是受托处理者，不是处理者，不适用对处理者的相关要求。

![](img/4430d8d8aa1593b8d8c18ae0e4f8005b.png)

**-答4：**我觉得还是要看提供的这个服务本身，能不能被解释为委托处理。

比如把为了给员工计算薪酬的外包服务，我觉得可以解释为委托处理给员工的体检服务，医疗体检机构自己本身也是处理者了。
