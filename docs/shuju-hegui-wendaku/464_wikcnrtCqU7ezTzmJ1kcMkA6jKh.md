# 数据委托查询算委托处理吗

> 来源：[https://docs.feishu.cn/docx/XyzmdP6AmolC95xOewBc45ihnzc](https://docs.feishu.cn/docx/XyzmdP6AmolC95xOewBc45ihnzc)

**-问：**请教一下大家，委托查询这种活动算“委托处理”吗？我理解委托处理的典型场景是对数据进行存储、分析、加工这种，但是如果A主体提供了一个查询要素（个人信息），查询并获取到B主体自有数据库的另一个个人信息，这种情形能否装入委托处理关系？实践中这种向第三方查询的模式还挺普遍，但是看到《网络数据安全管理条例》的定义，不是很明确：（七）委托处理是指数据处理者委托第三方按照约定的目的和方式开展的数据处理活动。

**-答1：**我觉得是互相提供，不存在委托处理。查央妈征信报告，对银行来说不能是委托央妈征信中心处理客户个人信息吧。可以看看史律师的这篇文章：数据合作的法律关系框架：共同处理、委托处理、提供与技术支持。

**-答2：**这个感觉要看具体场景诶。如果个人信息主体（ps）基于给予A的这个查询要素本身就可以在B主体中查询相关信息，现在ps把查询要素授权给A，A代ps去B处查信息，A与ps是委托查询，B与A就是简单的数据提供关系（B基于对授权的信任给A与给ps的行为本质是一样的，且如果是敏感场景，B还得查验【授权】的真实性和有效性】。如果ps自己无法基于这个查询要素在B主体中查询其他个人信息，现在委托A来查，这就不是委托查询了，这其实是委托A来做数据融合。如果给A这个查询要素的不是ps本人，而是另一个主体，那这其中的法律关系就更复杂了，A要更加谨慎，想用“受委托去开展处理行为”的理由帮自己防范风险不一定站得住脚。具体场景还蛮多的，比如代查订单信息、政府一体化大平台提供一个身份证号能查到医保口的、住房公积金口的信息。

**-答3：**我觉得也应该分场景，比如实名认证场景，应该也是A提供了查询要素，在B系统去查询，也存在委托处理的可能性？

**-答4：**仅从数据处理的行为可能无法简单地判断双方的关系 还是要就双方的权利义务关系、处理场景等综合来看 双方关于数据处理的合同约定可以看是否符合民法上对于委托合同的认定。

**-答5：**我可以提供一个UBI合作的场景供大家判断  车辆主机厂将从用户采集的驾驶行为数据通过算法模型计算出用户驾驶评分信息，供保险公司查询，保险公司仅需在用户购买保险时提供vin码就可以查询（在向用户报价时）到用户在主机厂的驾驶行为评分数据。

**-答6：**反过来讲，在这个场景下，主机厂就会知道车主买了哪一家的保险。

**总**结：整理者个人认为（非主流观点），这种查询并返回的，无论是添附新数据或只是校验数据准确性，均构成双向对外提供。
