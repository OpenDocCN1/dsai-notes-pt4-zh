# 三方搬家作为员工福利的数据处理关系

> 来源：[https://docs.feishu.cn/docx/ToJ1d9QwtoorFUxSggocFCQNncg](https://docs.feishu.cn/docx/ToJ1d9QwtoorFUxSggocFCQNncg)

**-问：**请教一个问题 公司请第三方搬家公司  给公司搬迁以及员工搬家提供服务  搬家公司属于受托方还是单独的个人信息处理者呢。这过程中涉及的个人信息包括：员工的个人信息 比如手机号、身份信息等。

**-答1：**甩链接让员工**自己填写**不就好了，不要公司批量给啊。

**-答2：**就“为员工搬家”涉及的处理活动而言，是不是可能认定为共同处理者呀。是不是还得看是公司收集了向搬家公司提供，还是单纯提供链接，搬家公司直接收集。

**-答3：****这种员**工搬家，我感觉最好还是不要把搬家公司定义成受托方吧？从公司角度来说，收集员工的搬家信息没必要

**-答4：**感觉跟提供服务的**形式**有关系，如果是公司设计的信息收集交互页、决定的信息收集字段并且要求搬家公司回传收费信息，则搬家公司就更近乎于单纯服务商的角色，可以往受托方的方向论证。

**-答5：**地址是搬家服务所**必需**吧，接受搬家服务，就应该提供。其他，比如联系电话，倒是未必，可以由企业或者供应商居间联系。

**-答6：**我觉得，你就看看那种企业版打车app咋定义数据处理的不就好了，比如滴滴出行企业版。很多这种需求的，抄作业就好。

**总结：**去抄企业版APP的作业就好。
