
# 共同放贷中的数据处理关系

> 来源：[https://docs.feishu.cn/docx/XJuDdmdbpoJLltxXIf6cmHA1nMh](https://docs.feishu.cn/docx/XJuDdmdbpoJLltxXIf6cmHA1nMh)

## 讨论内容

### 问

跟各位探讨个问题啊～现在的互联网贷款，平台给金融机构提供助贷服务，平台经营者和金融机构之间属于互相独立的个人信息处理者还是共同处理？然后，如果是联合贷的话，两个金融机构之间，到底是互相独立的个人信息处理者，还是算共同处理？

### 答1

共同处理责任太大不合适。本身也不是对信息共同处理的主观意图…联合贷本身就是各自独立的贷款 如果客户信息必须从a金融机构过手到b金融机构 就限定对外提供用途目的对象是不是行了。

### 答2

我个人也不认可共同处理的观点。基于贷款业务的特殊性，无论再怎么联合，目的都不是共同处理，相反，按照金融监管的要求，两个金融机构应该要保持独立性，独立身份识别，独立审批，独立贷后，等等。

### 追问

如果联合贷是共同处理，那助贷算什么？

### 答3

共同处理就要共同承担责任了。

### 答4

联合贷更宜界定为信息共享吧。助贷的话，有委托处理（委托采集）和信息共享两种，得看具体的法律关系和定位。

### 答5

我认为不能一概而论，需要依据具体的业务模式进行分析。单论联合贷的资金方，理论上应当是“各论各”的。而助贷平台和资金方之间，理论上常见委托处理和信息共享。实践中委托处理的范围往往更广，平台和资金方也可能因股权、协议因素的加持，实际上是共同处理的关系。

### 答6

`separate controller`吧，关于合作部分是对外分享。

### 答7

银协标准合同（科技服务补充协议）之内27字段属于共同处理者，之外的要走征信机构，怎么认定还不好说，倾向于单独处理者。
