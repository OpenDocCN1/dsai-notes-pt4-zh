
# 数据交易前认证机构

> 来源：[https://docs.feishu.cn/docx/DXDMda1S3of0qKxY0zVcRtaNnDf](https://docs.feishu.cn/docx/DXDMda1S3of0qKxY0zVcRtaNnDf)

**问**：大数据交易所数据交易前需要通过合规认证，现在有官方的合规认证机构吗？

**答1**：现在北交所和上交所的惯常操作都是请律师事务所出法律意见书。没有一个所谓的官方机构来认证，但合作的律所其实还是比较固定的。
