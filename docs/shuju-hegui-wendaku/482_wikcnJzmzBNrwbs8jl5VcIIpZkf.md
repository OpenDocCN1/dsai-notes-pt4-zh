# 数据交易所的作用

> 来源：[https://docs.feishu.cn/docx/FMJmdgWXQopidFxyIhHcuwkunbg](https://docs.feishu.cn/docx/FMJmdgWXQopidFxyIhHcuwkunbg)

**-问：**目前看各个交易所，有个疑惑，交易所真的能发挥交易平台的作用吗？在很多标准（定价、确权）没有建立到可以足够落实的时候，用户好像完全可以根据交易所展示的信息私下交易，这样的话交易所和一般的信息展示平台有什么差别？

**-答1：**走交易所大部分是为了合规，还有就是，有中立第三方。数据交易不给数据，私下交易没办法解决这个问题。

**-答2：**现阶段数据交易所定位比较尴尬。传统意义上，一个交易所的价值在于 构建合法交易场所、标准化产品和交易条款、交易信息公示、还有包括通过竞价提高交易效率。数据资产，如果包含个人信息的，目前它的合法性基础没有办法通过交易所去补强和背书；如果不含个人信息的，通过场外合作也基本能解决，也没有进场交易的必要了。

**-答3：**数据交易所主要功能在于各方面资源整合、权威背书，规则互认、市场打通。离标准化产品、集中竞价还很远。除去抢头彩业务，主要业务主要在于打通征信牌照和政务数据授权经营的问题。
