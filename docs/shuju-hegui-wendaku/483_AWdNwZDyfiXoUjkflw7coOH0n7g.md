# 数交所股东要求

> 来源：[https://docs.feishu.cn/docx/CuFwdmh3soX3v9xdVAscTUHJnAs](https://docs.feishu.cn/docx/CuFwdmh3soX3v9xdVAscTUHJnAs)

**-问：**请教一个问题，数据交易所/平台的设立，有什么条件吗？看到的都是政府/国企参股/控股数据交易所的案例。就看到一个浙江大数据交易所有阿里云、安恒信息参股。

**-答1：**没看到明文规定，目前的确都是**地方政府搭台**。

**-答2：****公共事业**职能，国有控股，类似于证交所等金融基础设施，数交所按照数据流通基础设施的思路建设。前述观点，可以尝试用 数据基础设施 检索相关政策文件看看有无规范指引。

总结：这类基础设施大概率是要控制在国家手上的。
