# 数据资产入表

> 来源：[https://docs.feishu.cn/docx/UNbXdj5HqoweLoxI3gnccCQInac](https://docs.feishu.cn/docx/UNbXdj5HqoweLoxI3gnccCQInac)

**-问：**高速交通集团数据资产入表分析与建议，数据资产入表这个业务大家怎么看？政策性任务为主吗？

**-答1：**感觉是作为企业增信的一个因素，但不能作为**决定因**素。目前比较稳妥的路径是，先设计好可交易的数据产品，再溯源做特定数据资源的入表。

**-答2：**是的，其实没有增设数据资源项目前，相关成本**也是可****以作为其****他无形资**产入表、费用化的。成本法是计量标准，合法拥有并控制，并有预期收益是确定资产范围的前提。-答3：压力很大，怕背锅，目前都是成本法。后面有很多套路，交易不是必选。-答4：地不好卖了，“数据城投”跑步进场。

总结：数据可复制的本质，让其注定与传统资产入表不同。
