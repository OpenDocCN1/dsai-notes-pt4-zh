
# 个人信息到底是什么

> 来源：[https://docs.feishu.cn/docx/SSEId6dk2oAXH8xNnU1cQdtsneB](https://docs.feishu.cn/docx/SSEId6dk2oAXH8xNnU1cQdtsneB)

## 问

（2019）京0491民初6694号凌某某诉北京微播视界科技有限公司隐私权、个人信息权益网络侵权责任纠纷案中，法院认为：“因手机号码具有可识别性，在收集了手机号码的情况下，被告收集的位置信息与手机号码信息组合，能够识别到特定人，属于个人信息，与该位置的精确程度无关。”此种观点在《个保法》的语境下是否恰当，更具象一些，手机号+IP登录地区中的IP登录地区单独是否构成个人信息？

### 答1

手机号码本身就是单独能够识别到个人。因为“手机号+A”能识别到个人，就推断A就是个人信息。这个逻辑我一直不太明白。我觉得A本身对于识别到个人必须要起到作用，才能算个人信息吧（比如说A是华东政法大学）。不然“手机号+苹果手机”，就推断苹果手机是个人信息，有点离谱。得看后面那个信息对于识别个人有没有帮助，不然所有都是个人信息了。小明+红色，小明+做核酸。

### 答2

小明+于北京登录？于北京登陆不是个人信息？手机号码就已经是已识别信息了，剩下的信息只要多透露了这个人的信息，不需要具备可识别性，走关联路径也是个人信息啊。本来大家不知道你在哪的，现在额外知道了你在哪里，怎么可能不是个人信息呢。

### 答3

苹果手机不是个人信息，小明有一个苹果手机是个人信息……能识别出个人以后，跟这个个人有关的信息都是个人信息了。

### 答4

个人信息的认定这个话题一直也是疑难问题。按照识别+关联路径，个人信息的外延会无限扩展，感觉不一定是好事。

### 答6

单独的手机号也不一定是个人信息。这个我之前查过判例，有成立的，也有不成立的。参见这篇：单独手机号码是否属于刑法意义上的公民个人信息。

### 答7

可识别分为单独和结合，单独一个手机号不行，但是公安与其他一结合，就识别到特定个人了。其他所有参与识别过程的就是个人信息范畴了。

### 答8

《青年时报》在一篇报道中《售卖不含机主姓名的手机号码也是侵犯公民个人信息》 载述：“案件承办人、浙江省检察院公诉二处员额检察官王亮介绍，他跟检察官助理赵戬认为，售卖不含机主名字的手机号，同样属于侵犯公民个人信息。王亮说：“两高司法解释以定义加列举的方式，将手机号码等通讯联系方式明确认定为公民个人信息。我国已全面实行手机实名制，手机号码具有专属性和隐私性。且涉案手机号码针对台州地区有贷款意向的金融类人群，被用于精准营销，更属于公民个人信息无疑。”王亮认为，在大数据时代，侵犯公民个人信息犯罪被称为“百罪之源”。如果将涉案手机号码机械解释为单纯的11位号码数字，对收集、销售这类号码资源的行为作出不是犯罪的结论，那是偏离了立法意图，客观上会纵容此类行为的泛滥，不利于社会秩序的构建。”

### 答11

我理解单独手机号码是个人信息。按照个保法对个人信息定义的“可识别”，已经区别于“已识别”，不等于可单独识别，定义中没有明确“可识别”的主体，应该理解为社会的部分主体可结合手中的信息识别出某人。如果理解为接收方可识别，会过于限制个人信息的范围。

### 答16

有一个很简单的判断方法，就是看你给出去的信息到底能不能触达个人，哪怕你不知道究竟触达的是张三还是李四，但只要基于这个信息能和那个人产生联系，对那个人来说，就是在用他的个人信息啊。一串数字当然不能知道是谁，但我们频频在自己不知道的情况下接到中介的骚扰，即时中介也不知道他在给谁打电话，但我们肯定还是被侵犯了个人信息权益。

### 答17

个人信息的范围是个保法下最模糊的问题，没有之一。由于社会生活的高度复杂性、同一信息在不同场景下对个人的意义和风险不同、大数据技术的应用等因素，个人信息不易定义，只能高度抽象（立法者这活儿不好干）。实践中的争论，大多数也都是因为法律定义的高度抽象性引起的：1. 个保法下定义没有排除联系说（已知具体个人，任何和其有关系的信息都是个人信息），2. 没有排除无意义、无风险信息、也不好做这种排除（导致理论推导下鸡毛蒜皮信息都算个人信息），3. 没明确限定场景对判断个人信息的影响，4. 没明确承认个人信息具有相对性（例子：A公司自己员工的员工号对A而言是个人信息，但把这个员工号提供给B公司，B公司没有其他手段来识别个人，那么员工号对B公司是不是个人信息？），凡此种种，导致实践中个人信息认定困难，个人信息泛化严重。

### 答18

我觉得可不可以这么看，定义上局部的这些信息应该是个人信息，需要判断的是涉及使用或处理或者其他操作个人信息的行为，是否属于危害个人信息的行为。

### 答19

首先，立法采取的“识别+关联”说会导致个人信息外延的扩大，判断标准模糊，因此实践中更需要依据场景来个案认定。要综合考虑信息的敏感度、数量、收集方式、接收者的识别能力、与内外部信息的比对、科技的发展水平等来认定“个人信息”，不能说某一信息绝对是个人信息或肯定不是个人信息。

其次，个人信息范围外延过宽不利于企业发展创新，长远看也未必有利于用户权益保障。比如司法资源有限，法律保护力不从心；增加个人权利滥用的风险，也同时扩大了公权力干预的范围。

最后，这个问题确实很难，而且是个保最基础性的问题，可能讨论几次也不会有明确的定论。个人觉得难度可以和“去标识化和匿名化的认定边界”归属于同一难度。
