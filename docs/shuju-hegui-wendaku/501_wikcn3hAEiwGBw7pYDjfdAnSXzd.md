# 优惠券领取信息是个人信息吗

> 来源：[https://docs.feishu.cn/docx/FM0CdGiXJoeJH4xr8X1cp3ytnyh](https://docs.feishu.cn/docx/FM0CdGiXJoeJH4xr8X1cp3ytnyh)

**-问：**平台给用户推送红包、优惠券，那么这个用户领取红包优惠券的数量、金额、有效期限等信息属于个人信息吗？如果是的话，分享给同一集团内的其他平台是否也需要单独同意呢？

**-答1：****用户A+手**机号+领取了多少钱的优惠券，肯定算是个人信息吧。

**-答2：****了解到业界有**比较大的金融集团公司是落实单独同意，并落地了文件的。这说明他们也认为这个是个人信息。
