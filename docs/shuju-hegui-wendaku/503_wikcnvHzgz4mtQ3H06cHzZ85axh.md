# 《征信条例》和《个保法》对个人信息定义的冲突

> 来源：[https://docs.feishu.cn/docx/Vdsfd4PLeo8Hd4xwpxvcxLQanpb](https://docs.feishu.cn/docx/Vdsfd4PLeo8Hd4xwpxvcxLQanpb)

**-问：**2013年颁布实施的行政法规《征信业管理条例》中第十三条第二款规定，“企业的董事、监事、高管人员与其履行职务相关的信息，不作为个人信息”。这条在《个保法》生效后，是否因违反上位法即《个保法》而无效了？除非，再出个征信业的上位法，然后适用同一机关制订的特别法优于一般法的原则

**-答1：**可以解释的通吧。是个人信息但不视为个人信息，适用范围仅限征信场景中。

**-答2：**一您说的是特别法优于一般法，但是这两部法律本身就有位阶高低呀，个保法是全国人大颁布的法律，条例只是国务院的行政法规，不同机关制订的法律法规不适用“特别法优于一般法”规则吧，要遵循上位法优于下位法吧。

> “特别法优于一般法”与“高法优于低法”之间的碰撞。当一个作为“一般法”的“上位法”与一个作为“特别法”的“下位法”之间对同一事项规定不一致时如何适用，就会遇到上述两个规则之间的冲突。这时，应当优先适用“高法优于低法”规则。因为“特别法优于一般法”规则只适用于“同一机关”制定的法之间，不适用“不同机关”制定的法之间，更不适用处于不同法律位阶的法之间的关系。

**-答3：**可以理解为：仍然属于个人信息，但是在征信场景中不作为个人信息进行保护。

**-答4：**是不是理解为应公开的信息，不受限于个人信息保护的要求。而且是强调履职信息，其实有点模糊，例如姓名和职位是公开的，其他的范围有多大也没有明确。例如咱们去商店，再小的店也会要求悬挂营业执照，上面关于这个企业法人的信息也是可见的。

**-答5：**从实证上来看，企信宝等做了企业征信备案的机构，他们app的“查老板”功能是局限在了对公开信息的加工处理上，但是后台应该是用了个人的身份识别信息来区别重名，虽然在前台不可见。只支持输入姓名模糊“查老板”。比如输入“马化腾”会把全国跟这个名字有关的企业都列出来，同时，腾讯的pony马相关企业也是单独列出来的。

**-答6：**所以这么理解？在征信的这个场景下说明这些信息就是出于征信需要收集的，否则没法推定重名，条例上文也是说采集个人信息应当本人同意，依照法律法规规定公开的除外，而强调董监高履职信息不属于个人信息我理解是将其认作企业信息的一方面。

**-答7：**从那条规定推导出企业的董事、监事、高管人员与其履行职务相关的信息，有公开的义务。

**-答8：**我觉得董监高履职信息，依据个保法应是个人信息，然后依据个保法和征信业管理条例，在合理范围内处理已公开的个人信息，无需个人同意。所以企业征信业务中的涉董监高信息处理范围，实际应局限在已公开的董监高信息。不公开的董监高履行职务相关信息，不拿个人授权同意，无法合规获得。

**-答9：**13年的征信业管理条例的答记者问直接说董监高的履职相关信息视为企业信息，采集和使用时也不需要取得信息主体的同意。http://www.scio.gov.cn/xwfbh/gbwxwfbh/xwfbh/fzb/Document/1278193/1278193.htm

**-答10：**站在立法法的角度分析，我觉得这条规定和个保法实质冲突了，想确保该条款继续有效，得全国人大颁布征信法才行。

**-答11：**同意。从“规范”层面而言，以低位阶的旧法来明确排除高位阶的新法适用，确实是有问题的，也难以靠简单的法律解释就能“化解”掉冲突。但在“实证”层面，各行业发布“现管”文件还是相当有“实用”性的。至于在此类冲突上能否通过个案得到“司法”的意见，则难以预期了。

**-答12：**立法衔接是有问题，主要是条例出的时候还没怎么讨论个保问题。以后说不定真有可能制定征信法。全国人大财经委：社会信用立法争取早日提请全国人大常委会审议！
