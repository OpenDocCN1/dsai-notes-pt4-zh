# 开机密码是个人信息吗

> 来源：[https://docs.feishu.cn/docx/NowsdoC5poHGnixq7Dhc9wwFnHh](https://docs.feishu.cn/docx/NowsdoC5poHGnixq7Dhc9wwFnHh)

**-问：**电脑开机密码 锁屏密码可以认定为隐私上的个人信息吗?还是说只是从信息安全角度进行考虑呢？

**-答1：**35273明确列举说的是账号密码是个人信息。

**-答2：**然后就是看什么类型的账号密码，再定级别。比如银行卡密码，就是C3类个人金融信息。C2以上就是个人敏感信息了。

**-答3：**感觉是内部的，监管这些可能都说的是业务侧的，我觉得可能是两者兼有？个人的办公电脑密码很难说不是隐私呀。

**-答4：**也不算内部的。比如有人非法获取了你个人电脑的登录密码。也是获取了你的个人信息。

**-答5：**这个需要区分具体场景，电脑开机密码的设置本身不会完成识别、完成不了信息到个人，也很难说做到关联，比如单从电脑开机密码可以从个人到信息，但是无法排除掉这个电脑的密码及电脑内部的内容可以完成个人到信息这个情况，毕竟PC就是personal computer吧我印象；如果是公用电脑，那么电脑开机密码、锁屏密码之类的一般而言算不上个人信息了。

**-答6：**公司里的pc 管控得严格的话，里面的数据包括 开机密码，我理解算业务数据了吧，资产信息完全属于公司。对于那种笔记本电脑，办公和私人聊天混用的 就有点不好说 这个开机密码 完全无涉隐私了。所以这到底是一个安全问题还是隐私问题，也不好完全说清。

**-答7：**如果是公司办公场景，要区分是公司分配的电脑，还是BYOD，如果是后者，那账号信息依然是隐私；如果是前者，也要看员工手册里是怎么写的。

**-答8：**可以参考一下这个判例：员工工作手机通话数据是否属于个人隐私？判决来了！

**-答9：**所以公司规章制度很重要，得合法有据，再加个授权同意之类的书面文件的签署，和其他证据一起，能够印证主张的话，这个案子走向还不好说。

**-答10：**公司和个人之间，这种主体地位 本身不对等吧。这个同意的合法性基础，其实我有点好奇（怀疑）。员工的拒绝有效吗？会成功吗？

**-答11：**欧盟的案例就是这种HR管理相关的不能走员工同意的合法性基础，因为员工地位弱。

**总结：个人倾向于仍是个人信息。**
