# 肖像授权

> 来源：[https://docs.feishu.cn/docx/Aqmoduo9FolwooxJL7dcAobvnDB](https://docs.feishu.cn/docx/Aqmoduo9FolwooxJL7dcAobvnDB)

**-问：**问个问题 一个人戴了口罩（非公众人物）被拍到的侧面照是个人信息或构成肖像吗？个人信息我理解应该是的。想问下 对于这种活动上拍下来的宣传照 实践中一般是怎么去获取用户授权呢？

**-答1：****给你参考**个场景：用户好评上传，路人照，我们以前模糊打码，不用。

**-答2：**《民法典》：肖像是通过影像、雕塑、绘画等方式在一定载体上所反映的特定自然人可以被识别的外部形象。

**-答3：**戴了口罩不算人脸匿名的。举个例子，你把戴了口罩的人脸图像送去做人脸特征参数提取，然后把阈值进行调整。假如把这样的参数作为开锁识别的依据，后面即使不带口罩的同一个人过来，门锁依然会打开。这种依然会有比较强的安全和隐私的风险，所以它当然不算是匿名化，甚至也不是去标识化。因为这样的一张图像依然能提取出固定不变的生物特征。

**-答4：**这种就拍掉，不要宣传了。肖像权和个人信息保护是不是不一样。

**-答5：****正经项目**的话 是不是最好跟信息主体签个合同，给点钱。万一撤回同意片子撤下来重拍？

**-答6：**嗨，想起来，拍电影的时候，出现的人现场签协议，然后给钱的场景。合规好昂贵。

**-答7：**这个可以参考各运动品牌市场活动的条款，主要还是肖像权。
