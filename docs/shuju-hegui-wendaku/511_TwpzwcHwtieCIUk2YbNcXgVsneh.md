# Cookie ID是个人信息吗

> 来源：[https://docs.feishu.cn/docx/YcuwdkICWo5Rqyxw56ccvXy4nBh](https://docs.feishu.cn/docx/YcuwdkICWo5Rqyxw56ccvXy4nBh)

**-问：**请问Cookie ID属于个人信息吗？我明白通过Cookie收集的信息可以落入到35273附录A的”个人上网记录”从而构成个人信息，那Cookie ID呢？它能构成附录A的”个人常用设备信息”吗？“但在司法实践中，Cookie ID是否能够构成个人信息也存在部分争议。具体参见案例（2013）鼓民初字第3031号与（2014）宁民终字第5028号。”

实务指引 | 在线广告行业个人信息合规问题解析

**-答1：****cookie id 和s**ession id我理解都是个人信息，可变更的，是用户标识信息，不是设备信息。

**-答2：**不是设备的，清了缓存，清了cookie，下一次就是新的。

**-追问：**那Cookie ID也会变的话，只是在单次对用户进行标识的那时候才是个人信息？变了之后就不是了？

**-答3：**它上面记载的内容与个人**上网浏览记录、订单信息、偏好**等强相关。

**-答4：**算个人信息啊，个人信息的定义就是个人信息主体的全部信息，和userid差**不多。另外，虽**然cookies是**可变，且**有存活期，但在实际情况，大家都会设置一个相当长的存活期，例如1年。特别在广告场景，广告联盟要拿cookie id来做id mapping，把用户在不同产品的行为痕迹串起来，所以存活期可能会几十年，除非用户主动清空，不然这个id都不会变。

**-答5：**看回个人信息的定义，能直接识别+可识别，都算啊。在企业场景里，cookie ID算个人信息无疑了。无论是识别路径还是关联路径，在司法判决（案例，虽然我们非判例法国家）实务里，cookie ID都是个人信息。如果企业一般用来记录用户的各种上网行为的场景里，这几乎没啥好辩驳的。

**-答6：**具体是走识别还是关联路径，需**要根据情况判断。如**果是识别路径，那就是直接标识符，那要求就严；如果是准标识符，还好一点。欧盟的做法还挺好的，有些是必要的cookie，有些不是。给了用户多种选项，全部接受，还是仅接受部分的necessary的，还是其他的商用的，例如记录行为，埋点等其他的骚操作的。
