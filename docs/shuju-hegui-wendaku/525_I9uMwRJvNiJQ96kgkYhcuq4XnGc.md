
# 企业邮箱内容是敏感个人信息吗

> 来源：[https://docs.feishu.cn/docx/Bnj9djBA2owU5jxH4uUcufEKnFc](https://docs.feishu.cn/docx/Bnj9djBA2owU5jxH4uUcufEKnFc)

- **问：**请教大家一个问题，员工企业邮箱的通讯记录应该属于敏感个人信息吧？

“企业邮箱通讯记录属于工作性质而并非私人沟通，应当属于企业商业信息”这个说法应该不成立吧。

- **答1：**你可以入职的时候，在员工手册里面写清楚，禁止用企业邮箱沟通私人事务。所以论证沟通内容都是因履行职务行为产生的商业信息，我觉得还是有论证空间的。

- **答2：**好久之前不是有个检察机关办理个人信息案件的一个例子中，对公司出资购买但由员工为了工作使用的电话号码不属于个人信息的意见吗？

> “2018年最高人民检察院在《检察机关办理侵犯公民个人信息案件指引》明确“经过处理无法识别特定自然人且不能复原的信息，虽然也可能反映自然人活动情况，但与特定自然人无直接关联，不属于公民个人信息的范畴”，明确指出“对由公司购买、使用的手机、电话号码等信息，不属于个人信息的范畴”，并要求对于企业工商登记等信息中所包含的手机、电话号码等信息，应当明确该号码的用途，严格区分“手机、电话号码等由公司购买，归公司使用”与“公司经办人在工商登记等活动中登记个人电话、手机号码”两种不同情形，前者并不属于个人信息范畴，后者则属于个人信息的范畴”。

**总结：**还是有一定论证空间的。
