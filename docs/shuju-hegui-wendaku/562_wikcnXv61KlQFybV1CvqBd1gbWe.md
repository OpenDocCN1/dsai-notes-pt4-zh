# 导出文件加时间戳的可行性

> 来源：[https://docs.feishu.cn/docx/LIzKdTROpofW0Xxf7xXcGv6qnPh](https://docs.feishu.cn/docx/LIzKdTROpofW0Xxf7xXcGv6qnPh)

**-问：**想请教大家一个问题，关于后台管理系统的数据安全监控。公司里业务侧很多团队都需要频繁的从系统中导出明文数据，也包括财务人力这些职能岗位团队。想问下，能否从技术上实现每个导出文档都有水印时间戳？

**-答1：****水印时间戳，有点难，加**上导出日志。水印加不到 excel上吧。

**-答2：**加水印时间戳的文档，就是**不能修改**的吧？有些内容导出来，是不是还想编辑的？

**-答3：**感觉加水印之后可能导出的都是**PDF****这类的？而且**比起强调导出时间，是否水印可以落在展示是在谁的账号导出。

**-答4：**应该还是能实现的，某技术平台不是搞了全平台存证的系统，做全平**台存证，理**解应该也提供这种实时导出文件的时间戳服务吧。从电子签出证的角度上看，有服务商提供excel出证，那应该也是可以的？
