# OCR技术涉及个人信息处理吗

> 来源：[https://docs.feishu.cn/docx/P55BdcGtyoqmkwx2TEEcyFbYnLf](https://docs.feishu.cn/docx/P55BdcGtyoqmkwx2TEEcyFbYnLf)

**-问：**有张图片，图片上有文字，图片的文字算个人信息吗。

**-答1：**如果是手写的则**可能是**个人信息。

**-答2：**我觉**得“字**迹”的确是**个人**信息，但是ocr扫描之后，只是把写下来的内容转成了铅块字，除非这些“铅块字”的内容是个人信息（比如姓名+手机号），不然就是普通的文字内容，硬要说个人信息太牵强。举个例子，我匿名书写了一份情书（没有指明对象，也没对特定场景进行描述），在我想亲手递给暗恋对象的路上，情书丢了。学校里有人捡到了，把我写的情书拍照曝光了，那认识我字迹的同学看到了这封情书就会推测是不是我写的，这对我产生了影响，那这个是我的个人信息。可如果捡到的人把我的情书打成了word在校园论坛进行公开，在没人知道是谁写的、写给谁的、且情书内也没什么场景能指明特定两个人，那这封被公开的情书word对我没什么影响，我觉得不算个人信息。

**-答3：****个人理**解，ocr识别的信息内容和存储，如**果只是提供**技术工具，不留存信息内容（个人信息或者数据）也不到笔记鉴定识别这么深度应用场景，收集使用了短期删除掉，相对还好呀（隐私注明目的和场景、方式）；如果留存，进一步考虑识别的信息内容是否公开以及用户使用场景和风险防控，比如用户拿着ocr自动化批量识别🛰️用户昵称、🛰️号、地区，再给第三方付费开放，这用户多少有点涉及不正当竞争（数据权益竞争），至于工具提供方考虑是否知道或应当知道、是否提供帮助，有无阻断措施。

**-答4：**OCR功能我感觉无法完全排除是不是收**集个人信息，即便使用了**该功能不存储信息，建议也要**获取**用户的同意。还是要进一步具体看使用的场景及收集的信息是什么，比如我使用OCR功能收集用户的身份证信息，那就需要单独同意呀。至少需要隐私政策覆盖。
