# OCR信息留存

> 来源：[https://docs.feishu.cn/docx/I6W3dexocoBAURxRw7pcpwNHnNd](https://docs.feishu.cn/docx/I6W3dexocoBAURxRw7pcpwNHnNd)

**-问：**请问大家，OCR服务（识别）提供者会留存个人信息吗？如果我的产品调用他人的OCR服务，是不是可以类比接入SDK的场景来分析合规点？

**-答1：**看**部署方式** ，SaaS服务会 ，SDK识别算法前端完成不会。

**-答2：**得问问看如何实现逻辑？是在**本地识别还是上传到云端识别**以及ocr提供者会不会留存数据？

**-答3：****一般业务自己会**存的，所以得问下业务需求。一般这种第三方都不会存的。

**-答4：****你找个头部公司隐**私政策，看看有没有合合信息的sdk就大概知道了。

**-答5：****应该是旷视 **、商汤、腾讯云、阿里云之类的OCR能力，上云但不保存。

**-答6：**识别完成后，第三方服务商没有必要留存个人信息吧？

**-答7：**有一些会留存，比如**调用失败的备份**什么的，需要业务先确认需求。
