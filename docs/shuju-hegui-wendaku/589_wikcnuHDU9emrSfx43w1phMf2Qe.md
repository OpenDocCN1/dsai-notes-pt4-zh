# 联邦学习合规性

> 来源：[https://docs.feishu.cn/docx/AlbXdNZtUoJc1mxaY5rcAKKAnid](https://docs.feishu.cn/docx/AlbXdNZtUoJc1mxaY5rcAKKAnid)

**-问：**联邦学习失联修复返回是或否的标签不一定涉及个人信息，但返回修补信息，又无法提供同意授权，属于违规数据交易吧？

**-答1：**个人理解，我想到的可能会关注有两点：**第一，是，**提供方关注授权同意，接收方关注来源合法性**，以**及后续怎么融合和使用这种第三方的信息，去做哪些触达用户的行为，还有这部分怎么告知。来判断是否违规。第二，是，像类似碰撞返回结果信息的描述，视应用场景，也可能不一定属于联邦学习的应用范畴

**-追问：**提供方授权能做，接收方的数据来源授权有什么方法么？

**-答2：**是指来源合法性么？常见还是**协议约束**或要求**提供方自证**了。
