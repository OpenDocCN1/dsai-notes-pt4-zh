
# `GPT`对外提供服务的资质

> 来源：[https://docs.feishu.cn/docx/LHlPdtHgxofsP7xZZg9cchDmn6b](https://docs.feishu.cn/docx/LHlPdtHgxofsP7xZZg9cchDmn6b)

- 问：公司基于开源`GPT`模型做了个`gpt`对外投入使用，需要什么资质啊？

- 答1：资质的话，走`算法备案和增值电信业务许可证`那个路子吧？但用开源做商用，要先看看有没有违反开源社区的规定。

- 答2：类似这种`无需特殊资质`，现阶段部分监管对此还是比较开放，监管重点在一些巨头，对全球竞争的战略高地占领的认知较为统一。

- 答3：`算法`，还有`双新评估`。用海外的话可能会被打击。

- 答4：有一个`深度伪造`的进口审批。
