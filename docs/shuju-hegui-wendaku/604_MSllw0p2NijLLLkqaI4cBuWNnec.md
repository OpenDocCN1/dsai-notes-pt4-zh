# 公开数据训练大模型

> 来源：[https://docs.feishu.cn/docx/HXDhdQBwLonnUKx0sSFceK4Dnhg](https://docs.feishu.cn/docx/HXDhdQBwLonnUKx0sSFceK4Dnhg)

**-问：**我们可能会收集公开的在线信息或来自其他公共来源的信息，帮助训练Google的人工智能模型。”近日，谷歌更新隐私政策，表示将利用网络公开数据训练旗下的AI模型，相关条款已于7月1日生效。谷歌的这一动作引发争议，单方面通知用户的行为是否合法合规？此举又是否有“囤数据”之嫌？

求教大家几个问题哈

1.  使用用户发布的公开数据（包括个人信息）进行训练，隐私政策上单方面通知可以吗

2.已经被用于训练的数据可以撤回吗？

3.如果训练数据造成了侵权如何消除影响？技术上可以做到恢复如初吗？

**-答1：**1.看适用法律，个保法**合理使用**且**不违反反爬虫协议**就行？

2.非基于同意处理的个人信息，**无法撤回**；

3.大概率不行，可以看看之前open ai删除权咋落实的。

**-答2：**已经参与训练的数据是无法从模型里撤回来的。模型可以理解为：公式（模型结构）+系数（参数）+checkpoint下的预训练的结果，最后训练好的沉**淀**下来的模型就是个这，每一次实时训练的时候，会基于喂进去的数据和训练方法对结构和/或参数发生变化，然后在模型达到一定标准的时候选一个“节点”把它固定下来。但如果要追溯“这一条训练数据”进去影响的到底是哪一个，是哪一层级的结构、哪几个参数、在哪个时刻发生了变化，那是非常非常难的。Open AI现在开始和世界各国政府探索监管路径 因为反正它已经训练完了，现在管得越严 别人和它的差距就越大。但Meta就很会，Open AI不开源，meta开源，别的开源不允许商用，Meta马上要许可商用，我的模型质量可能比不过gpt，但我玩生态，大家用的都是我的开源模型，建立大队伍，跟Open AI干。

**-答3：**补充一点：模型遗忘（Machine unlearning）领域这两年进展比较多，主要就是针对3的诉求。实际不是删除，而是最小化相应数据对模型输出的影响，最好是几乎没有影响。有不同的实现路径，但大部分都是前沿探究，暂时不易工程落地。

**-答4：****是的，所以生成**式办法对于不法内容规定的是过滤和重新训练。

**-答5：**1.从个保法来看，如果是用户发布（自行公开）的个人信息

（1）得看数据处理者是否在“合理范围内”处理

**＊**“合理范围”感觉不太好界定，细究起来，要考虑：训练行为和用户公布时的目的是否有合理关联、是否符合用户的期待、是否会对个人权益产生重大影响、是否做到了最小必要等等

＊**如果是“合理范围内”处理，可以免**于获取同意，对于是否要告知存在争议。考虑到告知成本高、很难触达对应用户，暂时也没有细则明确那些场景可以免于告知，暂时进行相对宽松的告知应该也还行。

**-答6：**感**觉**做垂直领域的大模型其实只能做到保证出来的内容是合法和真实的。但通用功能的预训练大模型就很难，不过也有办法，只是成本大了一些。无论是开源训练数据的许可协议、训练数据的真实性和质量如何验证、训练数据集本身可能包含的对模型意识形态的影响，这些单靠企业、行业自治，是很难的，可靠监管的话，怎么管、跨境监管和应用又是个大难题。
