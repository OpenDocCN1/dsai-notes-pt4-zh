
# 向公众提供AIGC的界定

> 来源：[https://docs.feishu.cn/docx/B66Idcgr7orskBxIF1Ycv7lmnSe](https://docs.feishu.cn/docx/B66Idcgr7orskBxIF1Ycv7lmnSe)

## 问
《生成式人工智能服务管理暂行办法》的适用范围被限制在“面向境内公众”，这个面向公众是指直接面向吗？如果公司员工作为“中间人”，客户来问问题，员工实际使用AIGC，用AIGC的结果来解答客户问题，这种是否就不属于面向公众了？

## 答1
面向公众应该不仅仅指直接面向，应该还包括`API`接口等类似的“间接”面向。“中间人”会不会对这个结果进行加工润色哇？

## 答2
内容无变动，但是表达方式因为对客服务，可能更生动亲切一点。

## 答3
这种你们是服务使用者。本质上其实是你们采购了AIGC模型，作为内部的工具，辅助员工对外回答，从C端角度来看，ta所接收的信息是你们的人员提供的，C端用户自己本身并不能直接使用这个大模型“自由”得生成内容。如果内部人员没有对生成的内容做核验或者做筛选，任由错误的、不当的信息披露出去，这是内部的问题。

## 答4
所以其实是看员工有没有能力对生成的内容有“修改”和“选择”的能力。
