
# AIGC对话留存期限

> 来源：[https://docs.feishu.cn/docx/JS9kdrRRZo86N0x1GkXc5ERhnxY](https://docs.feishu.cn/docx/JS9kdrRRZo86N0x1GkXc5ERhnxY)

- **问：**大模型对话日志的存储期限，AI外规应该没有明确的要求，对吧？

![](img/30827aab393c210b7e85a26e5812d013.png)

- **答1：**至少网安法 21 条对系统日志 6 个月的底限得满足吧。业务反馈说对话如果有图片的话，存储成本还是挺高的。

- **答2：**根据之前跟老师的沟通，网络日志6个月是基本要求，其他的根据企业实际情况，如果容易出现问题的最好留久一点可以自证清白。

- **答3：**欧洲也是6个月。

- **答4：**有的日志需要永久保存，详见下图。

![](img/341066ab4ee2ec15297d2e1b2741af84.png)

- **答5：**也不是都要6个月，核心还是证据闭环。有些日志可以用数据库记录弥补。

**总结：**原则就是，满足外规底线要求+根据自身情况，丰俭由人。此外，特殊行业可能对数据存储有更好的要求，也需要注意满足。
