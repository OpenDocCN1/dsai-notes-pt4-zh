
# AI生成图片是个人信息吗

> 来源：[https://docs.feishu.cn/docx/NI8Jd5Imsoyx8rxu7U5c4PWxnUw](https://docs.feishu.cn/docx/NI8Jd5Imsoyx8rxu7U5c4PWxnUw)

- **问：**文生图或者图生图的生成图片，如果不和用户账号关联，还属于个人信息的范畴吗？

- **答1：**和账号关联就属于个人信息的范畴了？ 没懂啊。

- **答2：**对话记录呀，有上下文，算浏览信息。

![](img/4675dd3ff293b850a2f94a95e7e0f811.png)

- **答3：**`prompt`本身可能就含个人信息吧，如果是语音可能还有声纹信息。

- **追问：**排除这些，比如仅针对生成后的图片，也不知道那个账号生成的呢？

- **答4：**从法务严谨的角度，不一定，万一里面有名字呢。请生成一个logo，里面有名字：小明。

- **答5：**隐式水印要溯源到个人吧，所以肯定能追到个人。

- **答6：**隐式水印我记得是记载服务提供者，生成时间，和图片唯一ID（`ContentID`）。这个图片唯一ID是记录图片唯一性还是用户唯一性呀？

![](img/851321b2a3243ab68bb9eb98a4fd5780.png)

- **答7：**算法备案有更高的要求。

**总结：很难说不是个人信息。**
