
# AI生成语音如何标识

> 来源：[https://docs.feishu.cn/docx/EfCHdU6vbop5Nvxi8v8ccIlhnOc](https://docs.feishu.cn/docx/EfCHdU6vbop5Nvxi8v8ccIlhnOc)

- **问**：大家有用过AI生成语音的APP吗？语音这种一般会咋做标识？

- **答1**：好问题，最后加一句？？好像豆包也没有啊。可能还是界面？

- **答2**：语音的话，我看最近我们有个涉诉的APP是加背景音，然后背景音的音量非常的小，你不专注分辨的话是听不到的。

- **答3**：Audiojungle那种标记，去除AudioJungle音频水印。

- **答4**：有个实践指南。有些使用场景，人家就是不想让人看到是AI生成，想让用户生成之后可以拿去用，贴个AI生成的logo，反倒好像限制了使用场景。隐形标识不知道技术上实现起来障碍咋样。

> 音频的隐式水印标识应通过时域水印或变换域水印的方式实现，含有隐式水印标识的原始生成音频应满足任意连续10秒以上音频内容中均包含完整标识信息。

> 👸号：中国信息安全

> [通知 | 信安标委发布《网络安全标准实践指南——生成式人工智能服务内容标识方法》](https://mp.weixin.qq.com/s?__biz=MzA5MzE5MDAzOA==&mid=2664191292&idx=3&sn=a7f1745807c96730ff050626ddf08f58&scene=21#wechat_redirect)

- **答5**：这个标实践中好像鲜有人用，监管也没有以这个为指导。另外我个人理解，AI生成的标识，和隐形水印目的不太一样。一个是为了提醒用户甄别；一个是为了溯源，出问题了可以追责。

- **答6**：有的啊，你看生成式最早的征求意见稿。提整改要求也用这个标准的内容的。

- **答7**：AI标识分显式标识和隐式标识，个人感觉隐式标识是监管更看重的，直接起到了追溯的能力。清朗行动()AI标识已经发了，并且算法备案中其实有对溯源性标识的要求。国标最近可能也要征求意见了，稍微关注下这个吧，清朗行动套深合算法的规定和算法备案自评估的要求，challenge企业隐标没做也合理

**总结：企业落地要求好多。**
