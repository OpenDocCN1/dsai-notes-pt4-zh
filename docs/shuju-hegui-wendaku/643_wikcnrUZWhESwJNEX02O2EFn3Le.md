**-答1：**应该是的，不然量化基金最先害怕，excel宏也不敢写了。

**-答2：**《互联网信息服务深度合成管理规定（征求意见稿）》《新一代人工智能伦理规范》和《关于加强互联网信息服务算法综合治理的指导意见》，最后一个文件是这是未来几年监管的路线图。
