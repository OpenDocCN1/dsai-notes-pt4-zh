# 合成生成类算法

> 来源：[https://docs.feishu.cn/docx/PFCjd9nWnoHUXLxmvNtcaSovn7b](https://docs.feishu.cn/docx/PFCjd9nWnoHUXLxmvNtcaSovn7b)

> 在中华人民共和国境内应用算法推荐技术提供互联网信息服务（以下简称算法推荐服务），适用本规定。法律、行政法规另有规定的，依照其规定。

> 前款所称应用算法推荐技术，是指利用生成合成类、个性化推送类、排序精选类、检索过滤类、调度决策类等算法技术向用户提供信息。

> 《互联网信息服务算法推荐管理规定》第2条

**-问**：上述条文中的“生成合成类算法”具体指的是何种算法，能否给个例子？

**-答1：**可能包含自动生成新闻、博文、帖子、评论等的算法技术和（深度）合成图像、视频、声音等的算法技术。

**-答2**：个人理解偏向是，识别视频图像并自动加入文案、标签，或直接剪辑、拼接后发布，例如之前有些配以新闻稿的视频素材。

**-答3**：是否可以参考这篇文章合成数据和真实数据对比：各有千秋。

**-答4**：NLP可能算是大量运用生成合成类算法的场景。

**补充：**史律师在算法治理新篇章：《互联网信息服务算法推荐管理规定》颁布一文中指出，合成类算法包括自动写稿机器人、虚拟主播、Deepfake/换脸程序。
