
# 什么是算法推荐

> 来源：[https://docs.feishu.cn/docx/SYhydsHgQo47FNxFPmecMLHUnCc](https://docs.feishu.cn/docx/SYhydsHgQo47FNxFPmecMLHUnCc)

**-问：**基于特定标签信息，在特定场景向特定人群发送问卷是否属于算法推荐？

**-答1**：群体画像不属于算法推荐。

**-答2**：我觉得要看群体画像标签的类型，有事实标签，也有预测标签，预测标签一般需要基于数据进行计算和分析才能得出。后者就属于算法了。

**-答3：**《算法规定》对何为算法推荐的规定较模糊，新规明文规定的类型很难叫“推荐”，比如生成合成类，所以不再用“推荐”去衡量。建议增加一个判断标准：相关算法是否会在未来被纳入新规官方解读提及的负面清单。若是，则适用《算法规定》，若纳入可能性小，可暂不适用。毕竟这个文件只是算法治理的起点，结论可以慢慢完善，监管也未必要求一步到位。另外，用于预测的算法，如果下一步真正的应用是人工执行的（比如算法筛出一份名单让业务员去打电话推销），就是说间接应用到提供信息服务上，我认为可以先不纳入合规整改范围。
