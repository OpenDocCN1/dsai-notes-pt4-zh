# 针对设备ID进行内容推荐是否属于个性化推荐

> 来源：[https://docs.feishu.cn/docx/E89cdZ8l9o6Scoxa6rhch4een4c](https://docs.feishu.cn/docx/E89cdZ8l9o6Scoxa6rhch4een4c)

**-问：**仅**根据单一的设备ID进行内容推荐**，是否属于个性化推荐呢？目前35273是仅仅将地理位置排除在外的。

**-答1：**识别个性化推荐的2个关键识别的地方：1.使用个人信息 2 通过算法。设备ID属于个人信息，但没有算法。故而不算。

**-答2：**是不是其他情况都没有仅依据设备I**D这一个标签**进**行的推送就不**属于个推，因为背后没有算法，就是随机性的。

**-答3：**那**我理**解是不是就纯粹依据这个id发广告。只是向这个id背后的主人发个广告而已，有点像给一批手机号发个短信广告的感觉。我感觉不算个性化推荐。
