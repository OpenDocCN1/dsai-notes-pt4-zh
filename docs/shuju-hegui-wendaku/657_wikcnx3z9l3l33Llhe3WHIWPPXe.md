# 自动化决策的认定

> 来源：[https://docs.feishu.cn/docx/RD4DdIHdsoeBFkxFfDoc7RJGnzd](https://docs.feishu.cn/docx/RD4DdIHdsoeBFkxFfDoc7RJGnzd)

**-问：**企业拟定目标人群（画像），去和数据库里的用户标签做匹配，找出“大客户”进行精准化定向推送，是不是就是所谓的自动化决策了？有观点认为：这只是人为的基于画像标签把人找出来，又不是自动化做的，不是自动化决策。

**-答1：**对c端用户来说，无论后台是怎么分析ta的画像的，在ta没感知的情况下，都已经帮ta决策ta会看到什么广告了。

**-答2：**这里有个观点，[自动化决策的基本和相关概念](https://mp.weixin.qq.com/s?__biz=MzI4MDY4OTY0Mw==&mid=2247489165&idx=1&sn=de1bb0743d3eceb12d1bce1c6ee94bd8&scene=21#wechat_redirect)，值得借鉴 虽然站在企业角度我内心其实更偏向人为干预不属于自动化决策。

**-答3：**单纯的地理位置推送不是，这是35274明确规定的，但是实践中检测机构很难的识别，可能也会被误报。

**-答4：**在这个场景，画像和匹配都是一种人定的策略，可以认**为是自动化决策的输入和**被分析、评估对象，不影响认定为自动化决策。

**-追问：**好奇检测机构一般怎么查自动化决策的？

**-答5：**这边有篇梆梆安全的实操经验，GB/T 35273中“个性化展示使用”相关条款测试技术解析。

**-答6：**看隐私政策，在看页面有无“猜你喜欢”“为你推荐”这种栏目。

**-答7：**此外，还有些技术手段，比如**抓包、看看接口名**，比如有：有recommend，rcmd，tuijian，这种接口的也是怀疑对象。但是人家不会看这么细的。

**总结：还是要回归定义，"自动化决策，是指通过计算机程序自动分析、评估个人的行为习惯、兴趣爱好或者经济、健康、**信用状况等，并进行决策的活动"。根据问题中的场景，打标签还是计算机做的，人为依据标签结果做决策，也属于自动化决策的范畴。
