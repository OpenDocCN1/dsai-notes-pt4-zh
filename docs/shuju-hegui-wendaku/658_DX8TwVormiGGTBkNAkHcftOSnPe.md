# 舆论属性的认定

> 来源：[https://docs.feishu.cn/docx/GMf8dxkF5op1sIxNrOncJwzFn3c](https://docs.feishu.cn/docx/GMf8dxkF5op1sIxNrOncJwzFn3c)

**-问：**舆论属性定义有点模糊《具有舆论属性或社会动员能力的互联网信息服务安全评估规定》第二条 本规定所称具有舆论属性或社会动员能力的互联网信息服务，包括下列情形：

（一）开办论坛、博客、🧣客、聊天室、通讯群组、公众账号、短视频、网络直播、信息分享、小程序等信息服务或者附设相应功能；

（二）开办提供公众舆论表达渠道或者具有发动社会公众从事特定活动能力的其他互联网信息服务。

**-答1：****舆论属性**和社会动员能力是有口径的，就是要广义解释。现实中咨询到外部律**师这里的，基本都属**于。除非是规模很小的初创公司（但他们问的很少）。总之对这个概念不要试图从字面解释。

**-答2：****总之对这个概念不要试图从字**面解释+1，肯定不限于“1对多”的场景的。

**-答3：****可否这么**理解：18年的管理**规定又焕**发新的生机了。-答4：生效以**来实务中还是经常触发的。**只是之前约谈和处罚较少，主要也是针对互联网大中厂。
