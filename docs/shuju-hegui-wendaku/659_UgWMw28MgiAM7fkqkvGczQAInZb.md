# 算法推荐监管适用于to B场景吗

> 来源：[https://docs.feishu.cn/docx/WDEcdewgRoUdImx5lWjcBwpQnBb](https://docs.feishu.cn/docx/WDEcdewgRoUdImx5lWjcBwpQnBb)

**-问：**请问在算法推荐管理规定，如果用个性化推送进行To B的直接营销，我理解是适用这个规定的。如果这个前提正确，那这个情况下被提供互联网信息的”用户”是这个B的实际接收营销信息的员工吗？

**-答1：**算法推荐本意 不是B端用户吧，算法推荐管理，个人觉得不适用。

**-答2：**适用范围看不出来只适用于自然人呀，而且To c还是to b，其实操作的都是自然人，不能说我，我代表企业履行职务行为时，就可以大数据杀熟了吧。

> 在中华人民共和国境内应用算法推荐技术提供互联网信息服务（以下简称算法推荐服务），适用本规定。

> 法律、行政法规另有规定的，依照其规定。前款所称应用算法推荐技术，是指利用生成合成类、个性化推送类、排序精选类、检索过滤类、调度决策类等算法技术向用户提供信息。

> 《算法推荐管理规定》第二条

**-答3：**如果2B的情境下用户是实际操作的自然人，那17条，向用户提供不针对个人选项，提供便捷关闭选项，这个是面对B呢还是B的这个自然人员工。

**-答4：**如果只有企业账号，那么一个企业账号对应一个开关就好，如果有每个职工可以登陆的子账号，那每个子账号都要有。

**-答5：**我理解，如果是to B的产品，用户是采买产品/服务的企业，员工是以企业代理人的身份行事。或许，可以看一下产品营销的个性化推荐算法使用的特征是什么。这些特征是员工履行工作职能的职务行为记录，还超出企业代理人身份的自然人个人偏好？提供退出算法推荐功能的目的是保护个人信息被使用的个人信息主体的权益，或许可以看一下这个算法有没有使用个人信息进行推荐。

**-答6：**这个跟立法用意有关系！从某个角度讲，我个人的理解是，如果不是针对个人的算法，应该执法时不会是重点高风险？
