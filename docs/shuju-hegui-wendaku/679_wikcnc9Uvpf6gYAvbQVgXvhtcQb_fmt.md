
# 律所可以做个人信息审计吗

> 来源：`https://docs.feishu.cn/docx/BXuwdsXZ9os4ufxSc2bc2ko8n4c`

## 问：律所可以做个人信息审计吗？

### 答1

有些内容需要技术工具，穿行测试，那部分律所做不了。现在有机构的思路是：审计机构、技术机构和律所一起做。

### 答2

安全性审计和合规性审计是两个概念。根据《个人信息保护法》第54条：个人信息处理者应当定期对其处理个人信息遵守法律、行政法规的情况进行合规审计。这肯定得律师做。

### 答3

关于审计的最新实践，我可以给大家分享几点：（1）目前不少上市公司的年度审计，审计机构要求公司单独委托律师事务所做数据合规审计，否则这块发表保留意见；（2）部分上市机构和中介结构，要求上市辅导期的公司，委托律师事务所出具数据合规审计意见；（3）目前部分头部互联网公司，部分已经委托律师做产品级别的合规审计，并将律师合规审计意见提交给监管部门。
