
# 个人信息审计报告

> 来源：[https://docs.feishu.cn/docx/A1wOd0ykOoIdudxeTjdcx2Fonqc](https://docs.feishu.cn/docx/A1wOd0ykOoIdudxeTjdcx2Fonqc)

- **问**：请教下各位，有没有做了个人信息合规审计报告的，请问这个（1）是强制性义务吗？（2）各位有收到监管部门通知，被动提交的还是主动提交的？（3）报告提交给哪些监管部门啊

- **答1：**电信互联网行业以后肯定要有年度报告，不过可以自己做，看内部合规团队的力量了吧。

- **答2：**这个是法规原文要求，我之前给审计提过，他们也不知道咋弄，但一般强制性要求留档备查呗。一般这种通用的法规会由主管部委向各行业监管部委发要求，行业部委再发到机构。

- **答3：**有内部审计，就是想问这个是不是强制性义务，然后有没有同行收到过监管要求后被动提交的。我们需要做一个评估结论给自己心里点儿数：这份报告不做的后果，最严重是啥，以及实践中是主动提交还是收到要求被动提交。

- **答4：**这个是主席令级别的法规，我的理解肯定是要做的，不然后期不论哪个监管直接说违反《个保法》就能直接开罚单。从《网安法》的实施对照来看还是靠法规主管部委来推动，可能没这么快，看看行业内的要求。

- **答5：**信通院去年出过一个个人信息保护合规审计的框架，供参考。

- **答6：**昨晚陈律在ilaw里的分享说每年可以由企业自己做内部审计，也可以是监管机构要求后由第三方来审计。

- **答7：**如果现场检查的话，会查审计记录和报告，和PIA是一样的，内部自行开展OK的。

- **答8：**现场检查的话，非案件介入的，一般会有清单，照着清单准备就可以了。之前的经验就是内部审计或者第三方审计都可以提交。总之，做了就留痕，以备不时之需。
