
# 个人信息保护负责人设置

> 来源：[https://docs.feishu.cn/docx/YZQad7xlroNEiNxISHBcuN3ZnzI](https://docs.feishu.cn/docx/YZQad7xlroNEiNxISHBcuN3ZnzI)

- **问：**想请问大家，个人信息保护负责人放在什么部门？
- **答1：**我了解好几家金融机构放在了IT部门。
- **答2**：给信息安全部门负责人比较好。
- **答3：**DPO 可让法总担任，因为核心风险是法律风险。
- **答4：**在我们公司，法律背景的负责人，级别没有CTO高，没法开展工作，而且最后各种制度措施的落实还是要靠技术人员落实。
- **答5：**听起来还是信息安全的比较合适，懂产品+技术+法律。
