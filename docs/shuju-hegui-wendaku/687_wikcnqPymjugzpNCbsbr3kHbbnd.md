# 三大法负责人对应职务

> 来源：[https://docs.feishu.cn/docx/DNT8dpeEXoKAvPxT2b1cfmC7nmh](https://docs.feishu.cn/docx/DNT8dpeEXoKAvPxT2b1cfmC7nmh)

**-问：**请教大家，三大法中的【直接负责的主管人员和其他直接责任人员】，这个有明确的解释或者相关判例吗？比如【法定代表人、董监高、实控人、DPO】。似乎没有找到公开司法判例。

**-答1：**取还是需要**具体案件具体分析**。

**-答2：****行政处罚**里面有很多。比如：蚌埠市局网安支队依法对网络运营单位怀远县教师进修学校处以一万五千元罚款，对负有直接责任的副校长处以五千元罚款。网址如下：https://www.nanning.gov.cn/zt/lszt/2019ztzl/wsxcz/wlaqsjal/t3381485.html

**-答3：**我们最近研究了全网80多份涉爬虫**的刑事判决书，判决书显示的这两类人包括：法定代表人、**CTO、产品负责人和产品经理、还有员工级别的技术人员和对外销售个人信息的销售人员，前提都是参与和知情。

**-答4：**悲哀的技术人员，不干绩效C。干了，就要了解需求，也就知情了。
