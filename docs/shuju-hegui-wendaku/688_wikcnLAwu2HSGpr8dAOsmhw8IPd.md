
# 未设置三法负责人的处罚

> 来源：[https://docs.feishu.cn/docx/VjbGds3DooECHOxbWzqcllGinUc](https://docs.feishu.cn/docx/VjbGds3DooECHOxbWzqcllGinUc)

- **问：**目前国内外监管执法中怎么针对个人信息保护负责人的岗位设置义务进行执法呢？看到新加坡有两个很有意思的案例（ACL案，majest案），都是对缺乏岗位设置克以行政责任，但是在国内，貌似还没有仅对岗位设置进行执法的实例？印象中都是出了事之后再追责。

- **答1：**当然会检查啦，而且要有制度明确。

- **答2：**依据网安法处罚的，放在了网络安全大筐里了。依据新法对个人信息保护负责人的岗位的执法案例确实没见过。

- **答3：**会检查，金融行业已经检查过了，开过整改单。
