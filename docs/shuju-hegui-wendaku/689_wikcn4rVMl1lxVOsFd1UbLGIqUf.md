# 个人信息保护责任承担人

> 来源：[https://docs.feishu.cn/docx/TYQdde20UoVyWVx8OaUcW6rsnUU](https://docs.feishu.cn/docx/TYQdde20UoVyWVx8OaUcW6rsnUU)

**-问：**假如违反了个保法，是不是法人，业务负责人，DPO都会受到不同程度的行政处罚呢？

**-答1：**可以看看滴滴罚了谁，那里面似乎只罚了董事长和总经理。

**-答2：**国内没有DPO的说法，要上报的个人信息保护负责人的。另外，不是看下职责就罚你的，不然大家都设傀儡了。检查中还要看制度，任命。具体谁受罚，还是要具体情况具体分析。
