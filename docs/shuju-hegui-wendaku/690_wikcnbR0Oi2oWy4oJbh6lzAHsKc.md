# 个人信息保护负责人可以外包吗

> 来源：[https://docs.feishu.cn/docx/NIQJd6EdZoU9HaxL7s7cZA7dnnf](https://docs.feishu.cn/docx/NIQJd6EdZoU9HaxL7s7cZA7dnnf)

**-问：**咨询下，个保法的个人信息保护负责人可以外包出去吗，还是必须是企业内部的人呢

**-答1：**很牵强，个保法用词是指定，文义解释就是限于公司内部人员。而且外部人员和公司因为信息不对称，存在无法有效监督的问题。

**-答2：**个人信息跨境处理活动安全认证规范里指明个人信息保护负责人由本组织决策层成员担任，基本不太能是外包吧，要是征信机构，还要考虑由公司章程规定的高级管理人员担任。

**-答3：**肯定是内部的。

**-答4：**中国和欧盟 规制路径是不同的，中国是满足监管对企业内部情况的“控制和检视”，所以 PIPL向下都是必须熟悉企业内部情况，GDPR 对DPO的独立性 都要求，所以外部相对 更符合海外的规制路径。只能说 同岗同责，但是老板不一样，工资从哪个口袋，出来也不一样。

**-答5：**插一句，之前问过网信办关于出境自评估里面境外接收方数据安全管理机构的信息，不能填写外部机构，必须是内部机构，也可以供这个问题参考。这个意思是说，有的欧盟企业DPO可能是由外部机构担任的，但此处必需填内部部门。

**-答6：**定责任人就是解决监管处罚的时候，罚谁。机构的主体责任能否外包…行政法和经济法角度都不太能吧…

总结：个人信息保护负责人必须由企业内部员工担任。
