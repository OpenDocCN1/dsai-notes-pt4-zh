
# 法务和安全的关系

> 来源：[https://docs.feishu.cn/docx/IaLcddVFjosPPTxAfqMc8Zy3nRT](https://docs.feishu.cn/docx/IaLcddVFjosPPTxAfqMc8Zy3nRT)

**-问：**请教大佬们一个问题- 你们公司内部做`privacy`的范围只管个人信息，还是一般数据安全相关的事情也负责？

**-答1：**反过来，是管数据安全的也做`privacy`。

**-答2：**数据和网络安全被要求配合做`privacy`，然后两个部门经常吵架。

**-答3：**网安，数安，个保，三条线大老板归一，业务条线各自，专业人员复用。

**-答4：**大老板难归一，都是老布局上做整合。网安数安基本都在技术线上。个保又法务合规来牵头。

**-答5：**既有律师出身的合规部，也有信息安全的合规岗，还有法务部。

**-答6：**我们这里合规以前在集团层面是和审计纪检一个大部门，现在因为要求央企总法兼任首席合规官，所以合规又调整到法律部。

**-答7：**安全和和合规更多还是补充和配合，具体看方案要点更多是合规还是安全。很少有冲突啊，无非是后面的执行可能会有边界不清。安全和合规不站在一起就做不了数据管理，会被业务疯狂`challenge`。安全和合规的信息同步很重要。

**-答8：**业务方面也会很狗地问完安全问法务，拿安全的话搪塞法务，拿法务的意见堵安全。业务“要不你们打一架吧”那种意思。

**-答7：**要么把自己训练成六边形战士，要么把自己训练成六边形斗士。

**-答8：**法律问题由律师回答，法律层面的价值判断也由律师来做——相应也要承担责任。而判断什么问题是法律问题， 本身是法律问题，而不是非法律问题。这点认知非常非常重要。

## 场景一下：

安全同学的判断：“这些堆栈信息表明调用了`XX`个权限、获取到`xx`字段，频率是…综合来看是运行该功能需要的最少权限范围了，且通过这些权限获取到的信息传输到服务器端时采用了`xx`安全保护措施……”。

律师做出价值判断：“当前通过`XX`权限来获取和处理个人信息的方式符合个保法下的最少必要原则和确保安全要求…此外，当前的处理活动的合法性基础是同意，在告知透明度上……”

业务同学理解：听不懂他俩对同一件事都在说些啥，但听起来都说现在这个功能可以做，干吧。

安全和法务同学：我俩互相能听懂对方说话，太幸福了，来，握个小手手！

**-答9：**确实安全和合规主要的分歧可能就在这，主要还是法律层面的价值判断，这也是合规律师的核心作用，所以安全懂合规这种分歧就会减少 合规懂安全 哈哈哈。当然各方责任的明确也是很重要。

**-答10：**这个视角对安全和法务的要求都挺高。双方都得懂合规这件事涉及的内容和要求，更重要的是彼此还能对负责的边界达成清晰的共识。实际情况，可能是安全多跨了一步，或者法务多跨了一步，统筹承担了合规这件事。业务同学只关心结果：这事给不给干或者能不能换个形式来干。

**总结：一锅粥。**
