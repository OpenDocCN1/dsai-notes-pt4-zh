
# 个保负责人可以是外籍吗

> 来源：[https://docs.feishu.cn/docx/Ef7JdUJABoq5pSx2fQscWhzanEe](https://docs.feishu.cn/docx/Ef7JdUJABoq5pSx2fQscWhzanEe)

## 实务问答

### 问
请教下实务中有遇到过境内企业的个人信息保护负责人/数据安全负责人是外籍人士的情形吗？规定层面暂时没有检索到禁止的要求。

### 答1
我觉得是企业**正式签署劳动合同**的员工就好。国籍无所谓？

### 答2
如果是用在**出境申报**的话，之前问过北京网信，提供有效身份证明信息即可（不论境内外企业）

### 答3
有地方窗口指导是**可以以外籍**，但需要180天以上在境内。

### 答4
出了事儿抓不到人可不行。想了一下，参考是否纳税的判断标准吧，183天。

### 答5
对**级别**也有要求的，法总可能都不一定有资格做个保负责人。

### 答6
感觉是得需要在公司那个**财务报告**上列出来的**高管**吧。apple总法律顾问在board里。

### 答7
金融机构个保负责人**建议**是劳动合同对得上的员工，就是机构员工担任（即不建议由集团高管兼职）。毕竟持牌机构都是有独立性的。

### 答8
**金融机构的高管任职资格**，往往对拟任者从业经历和职业资格有要求，多数也有对兼任情形有进行限制规定。个保负责人也是需要实际履职和担责的角色，从权责统一和兼任限制两点来看，最好由本法人主体签订劳动合同的员工担任。

### 总结
国籍无所谓，能找到人就行，但得有劳动合同，级别可能还有额外要求。
