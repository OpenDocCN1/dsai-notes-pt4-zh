# 个人信息泄漏后的报告部门

> 来源：[https://docs.feishu.cn/docx/TOSDdYyEFonCcJxT5swcXKRinlg](https://docs.feishu.cn/docx/TOSDdYyEFonCcJxT5swcXKRinlg)

**-问：《**个保法》五十七条关于个人信息泄漏后处理者向个人信息保护部门通知的义务，有没有人知道这条是否有具体落实的细则出来？比如要不要通知网信办，还是如果有行业监管部门的，向行业监管汇报情况其实就可以了。

**-答1：**难道不是告诉网安就行吗？

**-答2：**网安法中提及的是主管部门，如果有行业监管部门的情况下，是不是先去行业监管报备，然后并行去报网安……但网信办目前是可以不用太去考虑了？

**-答3：**对的，网信办一般是找不到人的。比如我们就应该是第一时间报行业主管部门+网安。我们行业的要求很明确。

**-追问：**如果没有明确的行业规范要求，那是否一定要向网信办报告呢？

**-答4：**之前提到的，网信办在哪怕省市一级好像蛮难找到人或者途径（或许打打安全评估的电话问问？），网安到区一级基本能有联络窗口或者联系人，报备起来容易。
