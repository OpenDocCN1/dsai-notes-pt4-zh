
# 各地数据局职能

> 来源：[https://docs.feishu.cn/docx/WDCPdtz8io9yLZxlwhWckQbEnLe](https://docs.feishu.cn/docx/WDCPdtz8io9yLZxlwhWckQbEnLe)

**-问：**地方数据局陆续挂牌，24年是不是数据要素交易会有更多具体的规则出来？还会有其他监管职能吗？

**-答1：**从行政管理的角度来看，地方机构会参照中央机构进行改革，也会因为各省历史沿革和地域特色有所差异（例如过往相关职能有的属于省厅有的发改委），但科层逻辑是一致的。

个人推测，除了全国“大一统”的规则，各地可能会尝试依托本地特征建设特色数据交易监管规则甚至推出特色交易场所，如农产品、“一带一路”，纺织品、新能源等

**-答2：**8省份数据局密集挂牌，上海市数据局不同寻常，可以看看这篇，级别、前身各不相同，职能肯定也有差异。

**总结：走着瞧。**
