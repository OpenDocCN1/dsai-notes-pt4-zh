# PIA如何落地

> 来源：[https://docs.feishu.cn/docx/CgXTdFQRnol1zZxzCHFcpbOGnYg](https://docs.feishu.cn/docx/CgXTdFQRnol1zZxzCHFcpbOGnYg)

**-问**：大家做PIA一般把哪些算作其他个人权益重大影响的活动哇？

**-答1：**你这个这个问题很大，从收集到删除任何处理行为都可以，一般比较关注的重点落在使用和加工层面的，例如用户画像，个性化推送。

**-答2：****PIA这个落**地挺难的，要是按照法律规定要做PIA的场景可太多，有点影响业务了。

**-答3**：PIA可以**IT流程化**啊，直接让业务同学填写即可。可能我看到的是已经做好的了吧，确实不知道最开始他们是怎么建起来的。我们是放给专门的人员和业务侧沟通好以后填报，他们沟通过几轮没问题才会报给我这边。只有都拿不准的情况才会由我这边从头开始帮他们看。

**-答4：**PI**A填报要**反复沟通的，基本当业务是文盲就对了。放IT流程，大家都别干活了。全卡PIA了。我们最初做规划时候，还想塞在授权管理平台里面，每新增一个业务场景敏感信息授权，就得先完成PIA，最后发现妄想。按照道理，需求阶段就该介入了。但这样没法干活了。

**-答5：**是啊。尝试过在PRD阶段参与到他们讨论，结果他们PRD一讨论一天，法务不用干别的活了。
