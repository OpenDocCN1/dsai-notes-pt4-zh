
# 小店提供WIFI的合规

> 来源：[https://docs.feishu.cn/docx/Dnwgdvnj1oxRbPxeIqScAiianJn](https://docs.feishu.cn/docx/Dnwgdvnj1oxRbPxeIqScAiianJn)

- **问：**[最近江苏地区有很多小微企业（个体工商](https://mp.weixin.qq.com/s?__biz=MzI5Nzc5MTI3MQ==&mid=2247523644&idx=1&sn=443fe30025361b6452b6593f934550fb&scene=21#wechat_redirect)户），六指情魔足浴店，麦香人家蛋糕店，老凤祥珠宝店，斗鱼网咖，金诺房产，涉数安被罚，大家怎么看？

- **答1：**我理解他们是想说那种，宾馆连wifi，出现的手机实名验证机制。但公司内部的访客wifi不属于这类情形啊。

![](img/e519c62b2383c31d99104d5836d3615b.png)

- **答2：**应该就是星巴克那种。

- **答3：**这种法律依据是啥啊？

- **答4：**这个其实长三角和珠三角的执法机关以前就有落实的，只不过一般都是警告，**没有进行**实质性的罚款，主要是要求店家购买符合网安标准的设备，这篇写得比较详细了。公共场所提供无线WIFI上网服务须知

- 答5：最简单就是不提供。

- **答6：**很多小b都是名b实c，也就比摊位多个店面，非要这样执法嘛...

- **答7：**查了一下应该是专项执法行动，同一时间没大量类似处罚，处罚依据是网络运营者没承担网安法第21条等保义务，依据第59条除以责令改正＋警告。网络运营者：网络的所有者，管理者和网络服务提供者。

- **答8：**最近的全是警告。

![](img/287bb33a755fc0bd368e3fc96c49f8c3.png)

**总结**：《个人信息保护法》第六十二条：“国家网信部门统筹协调有关部门依据本法推进下列个人信息保护工作：……（二）针对小型个人信息处理者……，制定专门的个人信息保护规则、标准；”期待尽快落实。

在此之前，不要提供wifi对于小店而言是最好的选择。
