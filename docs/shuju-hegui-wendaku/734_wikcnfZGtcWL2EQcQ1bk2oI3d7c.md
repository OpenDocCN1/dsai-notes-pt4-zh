# 合规体系官方认证

> 来源：[https://docs.feishu.cn/docx/GeTIdwN30ooUmBxZRCDckJFmnnb](https://docs.feishu.cn/docx/GeTIdwN30ooUmBxZRCDckJFmnnb)

**-问**：目前除了CCRC的数据安全管理认证，还有什么合规体系类的官方认证哇？

**-答1：**信通院也有一个数据安全管理认证。

**-答2：**国测是有针对人员的资格认证，信通院的是针对企业的dsg评估认证。

**-答3**：信通院**云大所（DSG）**和**安全所（DSMM）**各有一个数据安全认证，数据安全认证我还是推荐CCRC。
