# 数据分类分级供应商

> 来源：[https://docs.feishu.cn/docx/Io0WdZg1toSUtQxRiOVc3XjUnHc](https://docs.feishu.cn/docx/Io0WdZg1toSUtQxRiOVc3XjUnHc)

**-问：**数据分级分类供应商，除了全知，还有哪些啊？哪几家做的好些？

**-答1：**分类分级2步走，其实或多或少，第1步都开始做了，就是对整个数据要进行分类分级。难的还是第2步，如何运用分类分级的标签做安全管控。第2步基本得靠自己的开发团队写代码。

**-答2：**金融可用全知，互联网还要再调研一下。政务的可以考虑安恒。云上业务，考虑阿里云的。全知的售后和支持还是不错的。

**-答3：**目前分类分级的厂商本来你们选择余地也不多。你们也可以关注下一些安全大会，比如CIS这类。会有厂商驻场发发广告宣传单。现在安全厂商很多平台都是和数据合规有关的。比如数据分类分级，API安全，数据安全运营平台，等等

**-答4：**我是建议找几家实际测试一下，里面的坑很多  和组织、业务模式、字段名 、部署方式 关系很大。

**-答5：**还有观安、安华金和、美创等。好不好用得看自己的情况，例如你们主要的数据库是那些，对方有提供哪些识别数据的方式等。最重要还是要做个POC测试，看看适不适合自己的需求 。看是在哪个方面。数据分类分级基本都是基础的，一般各家都会配合自己的其他系统，来做数据安全管控中心。选购上可以综合考虑下。

**-答6：**信通院的数据管理认证，可以免费提供它家分类分级工具，但需要资源置换，属于共创型工具了。
