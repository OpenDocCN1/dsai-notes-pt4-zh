# 数据分类分级和保密等级的关系

> 来源：[https://docs.feishu.cn/docx/TCZ3dMBhnoL2PZxSsAncwap1nSe](https://docs.feishu.cn/docx/TCZ3dMBhnoL2PZxSsAncwap1nSe)

**-问：**政务场景做分类分级的话，比如政府机关内部给各办线发布的单个的文件可能敏感级别较低（故全线发出），但是后续计划全线发出的文件如果和上一份文件结合起来，可能会对部分部门敏感级别高，这种情况下，内部在给文件打标签的时候，要怎么做比较好呢？

**-答1：**这个机要局，具体机要科室，会有指引。你不懂“政府保密条例运作”咋打标签，具体场景，一看就懵逼。

**-答2：**还是看具体场景，不冲突。保密的分类分级就不管了。

**-答3：**保密和数据分类分级不要交织，各行其道，我的观点：保密优先，分类分级其次。

**-答4：**商业秘密和数据分类分级，其实有相似的管理逻辑，都是分类分级然后做相应安全措施，但是侧重点是不同的，商业秘密一是不泄露二是出事儿后能证明属于商业秘密，获得救济。但是一个公司实践里不能做两种分类分级，否则没法实施，最好是让二者在同一个分级的判断逻辑上，这样便于实践。这篇里的逻辑给了一个全面视角，一下就通了。
