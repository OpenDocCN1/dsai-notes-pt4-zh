# 系统评估主体要求

> 来源：[https://docs.feishu.cn/docx/OloPdExRNomfNOxSK4hcSHYUnng](https://docs.feishu.cn/docx/OloPdExRNomfNOxSK4hcSHYUnng)

**-问：**法规里面有对“系统信息安全检测机构与系统搭建者不能是同一个”的要求吗？（即如果公司系统是请了A机构搭建的，能请A机构来检测系统的安全风险吗？）找了一圈没发现法律有明确的规定，但感觉这样操作缺乏公正性原则啊，怎么能保证检测结果客观公正呢？公司使用的业务系统，找了第三方机构搭建的。现在要进行系统网络安全评估，还能找这个第三方机构评估吗？

**-答1：****那应该没事啊**，公司自己评估就行，外部评估也是风险自担，谁运营谁负责。

**-答2：****可以公司自**评估但是请的外部厂商是同一家的话的确效力存疑，主要看目的是要开发商证明其提供开发服务的系统的安全性，还是甲方需要一个报告甚至可能对外披露用于证明该系统的安全性。

**-答3：**主要**看监管**的，比如通信管理局对icp证有要求，每年都要做安全符合性测评和安全风险评估。我们有的找人做，有的自己做。

**总结：后果自负。**
