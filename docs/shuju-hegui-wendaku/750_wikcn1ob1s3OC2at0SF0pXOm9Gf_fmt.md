
# 欧盟CE指令和CE认证是什么

> 来源：[https://docs.feishu.cn/docx/OWF1dW6AVouwhTxWiwMcURK6nPd](https://docs.feishu.cn/docx/OWF1dW6AVouwhTxWiwMcURK6nPd)

- **问：** 有了解欧盟CE指令和CE认证的吗？CE认证的东西很广，但是现在我就是没弄清楚我们的产品如果要出口倒欧洲需要做哪些测试，监管方式如何等等。

- **答1：** 只知道口罩要做ce认证，具体需要问问认证机构。

- **答2：** 需要看具体的产品，以及各关键零部件。不光要考虑CE，还有能耗、环保等多项准入要求。比如无人机，就要考虑整机、电池、电机、无线电、网络、操作平台等，每一个都有对应的主管部门和准入要求。

- **答3：** 可以自宣称，省钱。

- **追问：** 是我们作为OEM要出口整车。您说得很对，欧盟对应国内的公告已经有个wvta，会涉及很多准入项，这个我们是有清单的。但是CE这块是否属于准入的强制前置要求我没搞清楚。我看了CE指令里包括了很多类似于电磁兼容这样的要求，但是这个欧盟有另外的regulation规定过了，所以我就晕了。

- **答4：** 有些认证虽然允许self certified，但较之于正式审验的认证在效力和适用上会有较大区别，后续会遇到诸多限制～所以还是多点评估比较好，一步到位免了后续的麻烦。找认证单位问一下比较保准。
