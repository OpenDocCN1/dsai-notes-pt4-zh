# Europrivacy是什么

> 来源：[https://docs.feishu.cn/docx/XMqAdEaHio3xHCxF16Ac09A3nLf](https://docs.feishu.cn/docx/XMqAdEaHio3xHCxF16Ac09A3nLf)

**-问**：欧盟第一个认证体系Europrivacy出了，大家怎么看。详见：欧盟委员会推出首个欧盟GDPR认证机制。

**-答1：**这个我们咨询了一下Europrivacy在欧盟的竞品，竞品的意思是Europrivacy集合了非常多强势的下游公司，才第一个被获批。但Europrivacy的内部人员没有太多的认证经验，他举的例子是官网上都没有认证流程，checklist的介绍。如果申请的话费用会很高周期也会很长。

**-答2：**这个认证，要先和认证公司签合同，并在两年内，与其认可的公司比如tuv 签合同，完成一份对产品合规的全面报告，提交给认证公司做审查。要求非常高，具体可以看下华为id 的欧盟版隐私政策。

**-答3：**TUV扮演的角色不是认证方而是咨询公司对么？还是说，TUV负责实质审查，然后Europrivacy在TUV审查基础上做纸质审查？

**-答4：**也不是咨询方，会根据你提供的资料产出报告，需要咨询的话额外付费。都不是实质审查。

**-答5：**光一个认证要花两份钱，成本有点高。
