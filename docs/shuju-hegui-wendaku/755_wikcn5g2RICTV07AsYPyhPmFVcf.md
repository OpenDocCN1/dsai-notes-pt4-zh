
# 欧盟境内代表设立

> 来源：[https://docs.feishu.cn/docx/Q6XEdnokioA7rkxwwSFcrO08njc](https://docs.feishu.cn/docx/Q6XEdnokioA7rkxwwSFcrO08njc)

- **问**：请问各位的公司有设立欧盟境内代表人的吗？在欧盟没有办事处和经营场所的话，这个代表一般由谁来担任呢？

![](img/263d3cc3806017035b36bec716a83e36.png)

- **答1**：律所、咨询公司或其他主体都可，原则上只要在欧盟范围内`established`即可。一般建议选择在数据主体较多的成员国。
