# 怎么看Linkedin v. hiQ案结果

> 来源：[https://docs.feishu.cn/docx/KhZtd5c0FoPazwxPTRtcTzBRnUg](https://docs.feishu.cn/docx/KhZtd5c0FoPazwxPTRtcTzBRnUg)

**-问：**大家怎么看这个案子[领英取得其与hiQ诉讼的胜利](https://mp.weixin.qq.com/s?__biz=MzkyODMxNzk1Nw==&mid=2247485962&idx=1&sn=b28bda45e0f8563bc65177981d858e1e&scene=21#wechat_redirect)，谁有判决书吗？

**-答1：**文末有附链接：http://ocr.docketalarm.com/cases/California_Northern_District_Court/3--17-cv-03301/hiQ_Labs_Inc._v._Linkedin_Corporation/405/

**-答2：**HiQ和领英间持续多年的、也是国内先前讨论对象的争议在今年上半年美国联邦第九巡回法院的相应裁决（附件1，基于美国联邦最高法院先前审理的Van Buren v. US案）里就已经相当程度上解决了。之后领英提起了相比之前有实质性修改的反诉，并且就其中有关合同违约的诉请和其他有关的程序性诉请（比如针对证据灭失的惩戒）获得了对其有利的简易程序判决。然后在此基础上经过谈判达成和解，才有了最近颁下的裁决。
