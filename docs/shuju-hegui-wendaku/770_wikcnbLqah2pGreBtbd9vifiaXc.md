# 美国员工保护立法

> 来源：[https://docs.feishu.cn/docx/VCGEd34MVoW5bax6XzrccRVSnYf](https://docs.feishu.cn/docx/VCGEd34MVoW5bax6XzrccRVSnYf)

**-问：**各位有了解美国关于员工个人信息保护的立法吗？

**-答1：**CCPA和CRPA都适用于员工。

**-答2：**美国分州，消费者隐私保护是FTC。

**-答3：**还有FCC以及极小部分的SEC。

**-答4：**之前看到的一个整理供参考：https://iapp.org/resources/article/us-state-privacy-legislation-tracker/。之前做过比较浅的研究，美国员工个人信息的话，除了通用的隐私法律，可能也要看一下各州劳动法等等，比如纽约州《劳动法》 203-d. Employee personal identifying information对员工个人识别信息做出了相关的规定。除非法律另有规定，雇主不得：(a) 公开张贴或显示员工的社会安全号码；（b）在任何身份证或卡（包括任何时间卡）上明显地打印社会安全号码；（c）在无限制访问的文件中放置社会安全号码；或（d）向公众传达员工的个人识别信息。

还可以参考一下这篇：论大数据时代欧美雇员信息隐私权立法模式

**-追问：**有大佬有ccpa&crpa中文版吗？

**-答5：**加州《CCPA实施条例》全文翻译。

**-答6：**美国《加州隐私权法》（CPRA）。

**-答7：**美加州消费者隐私法案（CCPA） 修正案汇总。
