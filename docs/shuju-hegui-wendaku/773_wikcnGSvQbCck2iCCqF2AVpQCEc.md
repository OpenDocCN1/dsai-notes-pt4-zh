# 台湾地区数据进入大陆的规制

> 来源：[https://docs.feishu.cn/docx/LKw4d8rU8oEnMrxTxQ0ckIHdnjg](https://docs.feishu.cn/docx/LKw4d8rU8oEnMrxTxQ0ckIHdnjg)

**-问：**境外单位—内地的公司app收集台湾用户个人信息 服务器在新加坡 内地公司可以访问的话 算跨境吗？除了把服务器位置、处理个人信息详情披露在隐私政策里，还需要其他合规措施吗？

**-答1：**算入境，看域外法？

**-答2：**台湾地区所谓法律对于间接向大陆间接传输个人数据有限制。可以看看台湾地区所谓个资法和所谓通讯传播委员会第10141050780号令。
