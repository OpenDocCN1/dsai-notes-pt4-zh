
# 全球数据保护法律地图

> 来源：[https://docs.feishu.cn/docx/OWHNdpsXIomgA4x1qsgcCKxDnlf](https://docs.feishu.cn/docx/OWHNdpsXIomgA4x1qsgcCKxDnlf)

- **问：**全球数据保护地图有哪些比较全的网站推荐呀？

- **答1：**DLA Pipers、Linklaters、Baker McKenzie和International Comparative Legal Guides都有全球数据保护法比较。

- **答2：**Asifma也有一版各地数据法比较 `https://www.asifma.org/resource/asifma-jurisdictional-comparison-grid-of-data-protection-rules/`

- **答3：**分享一下自己的工具箱，正好楼上几位大佬分享的有重合：全球。

  - `https://www.dlapiperdataprotection.com/`（非常全的全球各国数据法规比较法研究！可以下载全文，也可以按模块自选比较；而且有全球各地data privacy的比较）
  - 备选1：`https://www.linklaters.com/en-us/insights/data-protected/data-protected-glossary`；`https://www.linklaters.com/en/insights/data-protected/home`（年利达的总结，涵盖香港，有Q&A可快速查）
  - 备选2：`https://www.mofo.com/privacy-library/#othercountries`（美富的总结，有台湾；但现在仅有法规文本，没有解读）
  - 备选3：`https://iclg.com/practice-areas/data-protection-laws-and-regulations`（ICLG，免费版可以查询基本的）
  - 备选4：`https://resourcehub.bakermckenzie.com/en/resources/data-privacy-security/comparison`
  - `https://www.dataguidance.com/`（订阅全球立法变化，个别比较法合计不错，比如GDPR vs CCPA, CSL; 需要登录）
  - Asifma：`https://www.asifma.org/resource/asifma-jurisdictional-comparison-grid-of-data-protection-rules/`
  - `https://www.privacylaws.com/links/`（各国DPA集合于一处，可以作为字典快速查阅）
  - Glossary词典：`https://iapp.org/resources/glossary/`（IAPP的，当字典用）
  - `https://unctad.org/page/data-protection-and-privacy-legislation-worldwide`（联合国统计全球data privacy protection的chart）
