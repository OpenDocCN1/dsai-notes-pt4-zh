# 隐私法比较好的域外法学院

> 来源：[https://docs.feishu.cn/docx/Y07Cd9mz9ojNeQxsCpsckpiBnie](https://docs.feishu.cn/docx/Y07Cd9mz9ojNeQxsCpsckpiBnie)

**-问：**欧美法学院，隐私保护比较好的学校有哪些，是一个博士要申请访问学者。我个人的印象中美国有乔治城、UBC，欧洲有莱顿。。不知道各位大佬还有啥补充？

**-答1：**美国Yale、Stanford、Cornell、NYU、Northeastern，按隐私法相关项目申请难度降序排列。

**-答2：**荷兰还有Tilburg/Maastricht可以关注 VUB也不错 布鲁塞尔隐私论坛每年都是他们承办 美国那边 斯坦福/伯克利都有科技法方向。

**-答3：**QM除了Millard，好像还有个年轻学者。UvA也是值得关注的隐私法老牌强校，此外Tillburg也很欢迎中国学者加入合作。
