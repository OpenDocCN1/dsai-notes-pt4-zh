# 团体标准的效力

> 来源：[https://docs.feishu.cn/docx/I6yUduybroNikUxgwvJcWaxtn3f](https://docs.feishu.cn/docx/I6yUduybroNikUxgwvJcWaxtn3f)

**-问**：团体标准是否具有强制力，在日常合规工作中有何意义？

**-答1：**《中华人民共和国标准化法》第18条第1款规定：国家鼓励学会、协会、商会、联合会、产业技术联盟等社会团体协调相关市场主体共同制定满足市场和创新需要的团体标准，由本团体成员约定采用或者按照本团体的规定供社会自愿采用。

**-答2：**可作为实务的参考，可根据团标预判监管趋势。

**-答3：**团标本身没有强制执行力，但都是上位法的细化，很多执法还是会按照这个来的，只是对外还是写上位法。
