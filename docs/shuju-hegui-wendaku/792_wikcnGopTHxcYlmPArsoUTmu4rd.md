
# GB和TC260的异同

> 来源：<https://docs.feishu.cn/docx/YAdcdW6ELoYR52xBIdvcMg6Nnhg>

## 问

【2021-10-18完稿的《信息安全技术 汽车采集数据的安全要求》（征求意见稿）(<https://www.tc260.org.cn/file/2021-10-19/e5a87bcd-770f-4035-83dd-610e15a34096.pdf>)】是不是替代了【2021-10-8发布的《汽车采集数据处理安全指南》（<http://imgtec.eetrend.com/files/2021-10/%E5%8D%9A%E5%AE%A2/100554446-223514-jswj01.pdf>）】？我看这两个文的目录都一样的～但是2021-10-18的是还在征求意见稿中么？

## 答1

国标比较慢，所以先发了实践指南。

## 答2

这俩文件压根是两码事儿，没有啥代替的问题。征求意见稿那个在今年4月份已经有报批稿了吧。我这两天正好对比了下4月版本的国标和信安标委的技术文件，还是有些细节改掉了。整体来说，感觉口径还是在收紧的，特别是向车外传输数据这部分，车端匿名化大势所趋的样子。

## 答3

有些口径也略有松动，比如处理生物识别信息方面。

## 答4

这个国标的制定历程，仿佛充满了产业发展和监管的博弈。

## 答5

汽车数据处理安全要求六月已经报批稿递上去了。
