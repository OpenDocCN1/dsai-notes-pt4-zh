
# 《个保法》的域外适用

> 来源：[https://docs.feishu.cn/docx/KSn5dQmHFoGJIDxkecvctR0Jnjc](https://docs.feishu.cn/docx/KSn5dQmHFoGJIDxkecvctR0Jnjc)

-问：请教下，在境外处理位于境外的中国公民的个人信息，这个个保法管不着吧？补充下：就是这个公民一直居住在境外，然后其居住地的某公司处理该公民的个人信息。

-答1：管，长臂管辖。

-答2：管不到吧，属地管辖为主+必要的保护管辖。

-答3：Gdpr管，个保法不管。

-追问：我认为也不管。 另外关于境内自然人，一般指“持有中华人民共和国居民身份证的境内居民”。

-答4：不是，看看释义，说得很清楚。

![](img/341a1dda0479aef44411b4ebf6ef39a4.png)

-答5：到国家安全这个层面就很好理解了，就像滴滴的行踪轨迹数据，车跑到军事管理区，哪管车上坐的什么人。法条规定总有记不清楚的时候，想不起规定的时候可以想下立法初衷是什么，以不变应万变。个保法和GDPR一个明显的不同就在于，隐私权的位阶低于国家安全。

-答6：也可以看看《理解与适用》。

-答7：补充一点，个保法虽然管不到，但有可能纳入数安法第2条的管辖。

> 在中华人民共和国境外开展数据处理活动，损害中华人民共和国国家安全、公共利益或者公民、组织合法权益的，依法追究法律责任。

-答8：我的理解，境外中国公民仍然是境内自然人。
