# 为什么《数安法》中数据处理没有“删除”

> 来源：[https://docs.feishu.cn/docx/MNPAd7Y0YoPNYCxj60qcxM6Snsh](https://docs.feishu.cn/docx/MNPAd7Y0YoPNYCxj60qcxM6Snsh)

**-问：**《数据安全法》里面，对于数据处理 的定义并没有包括“删除”。难道是因为《数据安全法》更侧重安全层面，故意省略掉了嘛？在后来的网络数据安全管理条例（征）里面也提到了 数据的“删除”，就是在数据安全法里没看到。

**-答1：**处理包括删除吧，数据安全法还有“等”，而且政务数据那块还提到了“擅自留存”

**-答2：**猜测是不是立法技术的问题，数安法立法相对还是比较早。

**-答3：**《个保法》的草案和二审稿也都是没有“删除”的，是正式稿才加入，可能也是有各方考量在里面。

**-答4：**在金融类的行标里，数据存储包含删除，这里的存储是技术上的概念，包含数据备份与恢复、删除、销毁。

> 本文件基于JR/T 0158—2018 《证券期货业数据分类分级指引》，采用其中根据数据泄露或损坏造 成的影响将数据分为不同级别的数据分级方法，提供了各级数据在数据采集、数据展现、数据传输、数 据处理、数据存储（包含数据备份与恢复、删除、销毁环节）过程中的数据管理和技术指引，供证券期 货业机构参考。其中，数据安全等级递进关系遵从分类分级指引中数据重要程度规定。

> 《证券期货业数据安全管理 与保护指引》（JR/T 0250—2022）
