
# 数据合规技术入门书籍

> 来源：[https://docs.feishu.cn/docx/OB71diquvo8XNrxUpORcLNcrnwc](https://docs.feishu.cn/docx/OB71diquvo8XNrxUpORcLNcrnwc)

**-问：**我想学学技术上app是怎么做数据交互的？比如大的分类 跟系统 跟手机 跟后台服务器 ，软件层跟接口、跟sdk……这块有技术大佬能推荐一些入门的书籍么？

**-答1：**最近在看这个系列，🛰️读书上有，写得还不错。

![](img/6fa65fdf1f0a92321ba5b1f60f60c655.png)

**-答3：**冬冬律师之前也开过书单。都说数据合规需要“法律+技术",我给大家推荐这些技术书。

**-答4：**还推荐《数据合规 入门 实战与进阶》。相对市面上讲学理的书比较实务化。这三位作者本身就是实务界大咖，里面涉及的例如如何实现单独同意之类的问题都是很细节很适合我们了解的。但是还是很多问题只是提供了大概的方案思路。

**-答5：**这本很适合作为睡前读物，🛰️读书也有，《第四产业：数据业的未来图景》。
