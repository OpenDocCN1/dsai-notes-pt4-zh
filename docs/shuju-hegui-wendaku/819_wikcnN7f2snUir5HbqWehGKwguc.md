> 来源：[https://docs.feishu.cn/docx/YFLUd6G6soffQvxVAkNcllFZncg](https://docs.feishu.cn/docx/YFLUd6G6soffQvxVAkNcllFZncg)

- **问**：是否有大佬考过CISSP，这个证书主要考察什么内容呢？CISSP（Certification for Information System Security Professional）即信息系统安全专业认证。

- **答1**：你这个就捅到我们安全的伤口了。**知识点太多**，没兴趣去考。而且CISSP对数据合规没啥帮助。知识点太多太全，真正对数据合规或者数据安全方面讲到的就不是特别多了。

- **答2**：貌似技术流对证没啥感冒的，貌似技术流对证没啥感冒的。

- **答3**：CISSP好像还要信息安全相关的工作年限。
