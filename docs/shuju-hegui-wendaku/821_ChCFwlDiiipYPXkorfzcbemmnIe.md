
# 适合律师的数据合规证书

> 来源：[`https://docs.feishu.cn/docx/EqM7deuMqomyYpx5gaoc7n4mn2f`](https://docs.feishu.cn/docx/EqM7deuMqomyYpx5gaoc7n4mn2f)

- **问：**问下各位大佬`CIPT`如果律师考是不是专业知识差距比较大？顺便问问除了`iapp`的证书，大家觉得还有什么证书适合律师考。

- **答1：**`cissp`。

- **答2：**`cisp`，`cissp`是不是偏技术。

- **答3：**如果IT审计或者合规审计，还是`CISA`有用。`CISA`很有用。这个大家可以做个记号。。`CIA`是内部审计师。和`CISA`差不多都是信息安全审计师的标配证书。然后也会考`ISO27001`和`27701`的内审员证书。也是标配。

- **答4：**现在又多个赛道，`CCRC`几个认证。从价格上看，不算贵。8000~12000左右。`CCRC-PIP`，`DSO`，`DCO`，而且刚出来没有负面评价。我问过`CCRC`，他们说其实也有有效期，需要续证一说的。而且每年要学习。但是学习很简单的，看看培训就行，免费的。续证的花，大概几百块。
