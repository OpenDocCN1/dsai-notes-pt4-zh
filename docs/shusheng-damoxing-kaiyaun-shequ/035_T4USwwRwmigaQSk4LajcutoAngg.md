# InternVL-U: 统一多模态模型

InternVL-U 是 OpenGVLab 推出的 4B 参数统一多模态模型，一个模型同时具备图像理解、文本生成、文生图、图像编辑四大能力。以不到 BAGEL 14B 三分之一的参数量，在生成和编辑任务上实现了全面超越。

| 能力 | 说明 | 状态 |
| --- | --- | --- |
| 图像理解 | 上传图片，AI 分析内容 | 已上线 |
| 文生图 | 输入文字，生成图片 | 已上线 |
