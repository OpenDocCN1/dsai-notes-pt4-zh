## 主课程大纲

+ `Bigram Language Model` (`language modeling`)

+ `Micrograd` 机器学习，反向传播

+ `N-gram`模型(多层感知机、`matmul`、`gelu`)

+ 注意力机制(注意力机制、`softmax`、位置编码器)

+ `Transformer` (`Transformer`，残差，`layernorm`, `GPT-2`)

+ `Tokenization` (`minBPE`，字节对编码)

+ `Optimization` (`initialization`, `optimization`, `AdamW`)

+ `Need for Speed I` (设备、`CPU`、`GPU`)

+ `Need for Speed II: Precision` (`mixed precision training`, `fp16`, `bf16`, `fp8`, ...)

+ `Need for Speed III: Distributed` (`distributed optimization`, `DDP`, `ZeRO`)

+ 数据集(数据集、数据加载、合成数据生成)

+ 模型推理一:`kv-cache` (`kv-cache`)

+ 模型推理二:量化(量化)

+ `微调一: SFT` (`supervised finetuning` `SFT`, `PEFT`, `LoRA`, `chat`)

+ `微调二: RL` (`reinforcement learning`, `RLHF`, `PPO`, `DPO`)

+ 部署 (`API`, `Web` 应用)

+ `多模态` (`VQVAE`, `diffusion transformer`)
