
# 示例：三分钟带你掌握线性回归的基本思想

> 来源：[https://aicarrier.feishu.cn/docx/QbRqdX1rhoeOeMxH949cEYndnPd](https://aicarrier.feishu.cn/docx/QbRqdX1rhoeOeMxH949cEYndnPd)

相信大家在学生时期都站过队，按照老师的要求由低到高排成一列，在队伍外面的人看上去的话，就像是一条直线。但是如果此时班级突然来了一名新同学，让TA站在最前面的话，可能这位同学比较高会显得很突出，随意站一个位置的话也不太好，那么应该让TA站到队伍的哪个位置呢？

按照我们的经验，应该让这位同学站在前面的同学都没有TA高，后面的同学又都比TA高的位置。按这样排队时，其实我们就已经用到了线性回归的基本思想。

在高中我们都学过一次函数（形如`y = kx + b`），在排队问题中，`x`就可以看作同学在队伍的位次数，`y`则是同学的身高。在这位同学进入队伍之前，原来的队伍就可以看成单调递增的一次函数，然后我们根据`y`的值找到同学适合的位置。

线性回归作为机器学习里最简单的算法，其实就是通过一条直线表示出数据的大致分布，再用这个大致分布去预测面对位置数据时的可能解。在上述站队的例子中，我们其实是用已有的站位去表示队伍的大致分布，然后根据我们得到的大致分布预测新同学应该站的位置。其实在生活之中还有很多这样线性回归的例子，比如房价预测、股市预测、基于身高与体重一般呈正相关的预测等等。
