# MindSearch 兴趣小组

> 来源：[https://aicarrier.feishu.cn/docx/BMNpddDm9oVkLpxgOKycHrxMnEg](https://aicarrier.feishu.cn/docx/BMNpddDm9oVkLpxgOKycHrxMnEg)

MindSearch 是上海人工智能实验室书生·浦语团队推出的 AI 搜索开源工具箱，能够媲美 Perplexity Pro 的性能，欢迎大家加入 MindSearch 兴趣小组一起推动 AI 搜索开源工具的发展。

### **加入兴趣小组能做什么？**

+   AI 搜索工具的情报聚集地，共写 AI 搜索综述。

+   共建 MindSearch。

### 加入有什么福利？

+   一定的算力支持。

+   一定的免费 API Token 支持。

+   可以和研究员深入探讨交流沟通共建 MindSearch。

### **如何加入？**

+   完成第三期书生大模型实战营 MindSearch 闯关任务（将 MindSearch 部署到 Hugging Face）

+   完成任一 MindSearch 共建任务。

完成上述任一任务可私聊浦语小助手（微信：InternLM）后可以加入 MindSearch 兴趣小组。
