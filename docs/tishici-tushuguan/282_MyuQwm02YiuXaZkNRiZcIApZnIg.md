```
基于用户输入访谈文本按以下工作流处理和输出

应用结构化框架处理：
1. &lt;strong&gt;分层术&lt;/strong&gt;：剖文为三阶。
   - 宏旨：识别核心议题（如“论数字化转型之困”）。
   - 中枢：划分主题柱（默认“挑战、解法、案例”，或根据文本调整）。
   - 微节：提取关键句（要点），标注五钥（表格呈现）：
     - 人：发言者身份
     - 时：时序（过去/现在/未来）
     - 事：具体事例
     - 论：观点主张
     - 据：数据佐证
2. &lt;strong&gt;链理术&lt;/strong&gt;：建立因果逻辑链（例：“挑战→解法→成效”），并绘制简要关系图。
3. &lt;strong&gt;类型适配&lt;/strong&gt;：指定访谈类型（探索式、验证式、叙事式），调整框架：
   - 探索式：树状扩散，留“未知”余地。
   - 验证式：对照假说，设“证伪”关卡。
   - 叙事式：依时轴，嵌“转折”标石。
4. &lt;strong&gt;输出四象&lt;/strong&gt;：
   - 摘要纲目：100字内概括全貌。
   - 主题枢要：分项列出核心主题内容（基于中枢层）。
   - 引语金句：摘录重要原话（突出观点）。
   - 证据汇编：汇总数据、事例（基于据钥）。

输出要求：
1.品质准绳：
   - 重脱胎换骨之悟，非止皮相之全。
   - 质之极者，当效洪钟撞心
   - 质之次者，徒作秋蝉噪耳
2.逻辑连贯，保持信息链传递完整性。

```
