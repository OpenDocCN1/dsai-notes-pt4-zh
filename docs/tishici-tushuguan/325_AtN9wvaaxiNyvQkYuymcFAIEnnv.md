```
对话矛盾升级生成

一、输入要求
1. 基本设定：
- 核心冲突：[用户输入的核心矛盾点]
- 人物关系：[主要人物之间的关系]
- 场景设定：[发生冲突的具体场景]

2. 情绪基调：
- 主角初始情绪：[如：隐忍/愤怒/委屈等]
- 对手情绪：[如：咄咄逼人/轻蔑/嘲讽等]
- 其他人态度：[如：看热闹/劝架/偏帮等]

二、矛盾升级规则

1. 对话节奏设计：
第一层：表面争执
- 对手方挑衅/刺激
- 主角方克制回应
- 旁观者反应

第二层：矛盾加深
- 对手方升级攻击
- 主角继续隐忍
- 更多人加入/表态

第三层：爆发转折
- 对手方得意/放松警惕
- 主角出其不意反击
- 形势逆转

2. 情绪递进方式：
- 言语暗讽 → 明嘲暗讽 → 赤裸打压
- 克制回应 → 压抑愤怒 → 致命反击
- 冷眼旁观 → 选边站队 → 态度转变

3. 反转设计原则：
- 出其不意：出手时机出乎意料
- 有备而来：反击手段早有准备
- 一击致命：打击对手要害软肋

三、输出格式

【场景描述】
简要描述冲突发生的场景与气氛

【对话内容】
角色A：[对话内容]
角色B：[对话内容]
...
[按照矛盾递进的节奏展开]

【高潮设计】
- 反转时机：[在何时反转最有冲击力]
- 反转方式：[如何让反转既意外又合理]
- 结果呈现：[反转后的结果与影响]

注意事项：
1. 对话要简洁有力，控制在2分钟内能说完
2. 表情、动作等非语言描写要适度
3. 反转要有观众意想不到又在情理之中
4. 结尾要给观众痛快感/爽感
```

# DeepSeek测试

> 好的，用户让我写一个猫叔的微短剧故事，需要对话矛盾升级生成。首先，我需要仔细分析用户提供的输入要求。核心冲突是遗产争夺，人物关系是猫叔和侄子，场景在灵堂。情绪基调方面，猫叔初始是隐忍，侄子咄咄逼人，其他人开始中立后来转变。

> 接下来，按照矛盾升级规则来设计。第一层是表面争执，侄子挑衅，猫叔克制回应，旁观者看热闹。第二层矛盾加深，侄子攻击猫叔的过去，猫叔继续隐忍，有人开始劝架。第三层爆发转折，侄子得意时，猫叔拿出证据反击，形势逆转。

> 要注意情绪递进，侄子的言语从暗讽到明嘲再到打压，猫叔从克制到压抑最后反击。反转要出其不意，比如猫叔突然播放录音，证明侄子的阴谋，这样既合理又意外。结尾要让观众感到痛快，比如侄子被赶出去，猫叔赢得尊重。

> 需要确保对话简洁有力，控制在两分钟内。非语言描写要适度，比如猫叔握紧念珠，侄子摔相框。反转时机在侄子最得意的时候，方式是通过录音证据，结果侄子被揭穿，猫叔获得支持。最后检查是否符合所有注意事项，特别是反转的合理性和结尾的爽感。
