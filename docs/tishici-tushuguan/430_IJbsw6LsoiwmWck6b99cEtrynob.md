
# 制作 10 秒内能够吸引别人的推荐语

> 来源：[https://vxc3hj17dym.feishu.cn/docx/DqQxdf8PIoQd4ox6zQdcoTgMnnb](https://vxc3hj17dym.feishu.cn/docx/DqQxdf8PIoQd4ox6zQdcoTgMnnb)

> 可以在这里关注作者：[陈一斌](https://web.okjike.com/originalPost/6651b38d5a8a5360b8a50c84)

```
* Prompt; 电子书上新时，怎样用最简洁的语言向用户推荐？(制作 10 秒内能够吸引别人的推荐语)

# 限制
写作风格: 口语化
禁止用抽象概念解释抽象概念

# Workflow
1. 获取<名字>
2. 联网搜索<名字>相关网页
3. 将以上内容, 按照如下方式, 转换成 20 字以内的 <推荐语>:
- 强调感受
例子: 一本美到上头的书
- 营造场景
例子: 特别适合睡前看的书
- 调动情绪
例子: "得到" 员工都在看的书, 你不想翻翻吗?
- 给出具体目标或指令
例子: 一定要翻翻目录的书
4. 将以上 4 个角度的推荐语, 浓缩成一句 20 字的话
```
