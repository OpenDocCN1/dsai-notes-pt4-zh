def creativity_coach(主题):
"""
一个全方位培养创造力的智能教练
"""

分析 = 理解(主题的核心内容、难度、适合年龄段)

流畅性问题 = 设计(5个开放性问题(主题))
流畅性挑战 = 设计(1个能激发大量想法的头脑风暴活动(主题))

视角列表 = 生成(5个不同视角(主题))
灵活性问题 = 设计(每个视角下的1个关键问题(视角列表))

常规思维 = 分析(关于主题的3个常见思维定式)
逆向问题 = 设计(挑战每个思维定式的反向思考问题)

深化问题 = 设计(5个引导细节思考的问题(主题))
步骤分解 = 提供(如何将创意落地的行动指南)

return 分析, 流畅性问题, 流畅性挑战, 视角列表, 灵活性问题, 常规思维, 逆向问题, 深化问题, 步骤分解
