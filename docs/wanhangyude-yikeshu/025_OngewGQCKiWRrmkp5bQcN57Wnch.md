# 二、新手推荐

## 🥇 第一选择：豆包

**为什么推荐：**

+   ✅ 字节出品，国内直连

+   ✅ 完全免费

+   ✅ 中文能力强

+   ✅ 多模态支持（文字、图片、语音）

+   ✅ 体验好，操作简单

**适合谁：**

+   新手第一次用AI

+   不想花钱的普通用户

+   需要中文对话的用户

**注册地址：** https://www.doubao.com

---

## 🥈 第二选择：ChatGPT

**为什么推荐：**

+   ✅ 行业标杆，功能最全

+   ✅ 能力强大（GPT-4）

+   ✅ 多模态支持（文字、图片、语音、视频）

+   ✅ 插件生态丰富

**适合谁：**

+   有🪜的用户

+   需要最全面功能的用户

+   愿意付费的用户

**注意：** 需要🪜

**注册地址：** https://chat.openai.com

---

## 🥉 第三选择：DeepSeek

**为什么推荐：**

+   ✅ 便宜（比ChatGPT便宜很多）

+   ✅ 代码能力强（程序员喜欢）

+   ✅ 国内可用

+   ✅ 免费额度够用

**适合谁：**

+   程序员

+   预算有限的用户

+   需要代码辅助的用户

**注册地址：** https://chat.deepseek.com

# 三、进阶选择

## Claude

**适合谁：**

+   写作者

+   需要深度思考的用户

+   需要长文本处理的用户

**优势：**

+   长文本能力强（能读很长的文章）

+   中文好，思考深入

+   写作能力强

**劣势：**

+   需要🪜

+   多模态能力不如ChatGPT/Gemini

---

## Gemini

**适合谁：**

+   谷歌生态用户

+   需要多模态的用户

+   需要联网搜索的用户

**优势：**

+   谷歌出品，多模态强

+   联网搜索（实时信息）

+   与谷歌生态集成

**劣势：**

+   需要🪜

+   国内用户不友好

---

## 智谱GLM

**适合谁：**

+   国内用户

+   需要免费额度的用户

**优势：**

+   国内直连

+   免费额度多

+   中文能力不错

**劣势：**

+   能力不如ChatGPT/Claude

+   多模态能力一般

---

## Kimi（月之暗面）

**适合谁：**

+   需要超长文本处理的用户

+   不想用🪜的用户

**优势：**

+   长文本能力强（能读20万字）

+   国内直连

+   免费

**劣势：**

+   推理能力稍弱

+   功能相对简单

# 五、常见问题

**Q: 免费版够用吗？**

A: 够用！豆包完全免费，DeepSeek、智谱GLM免费版对新手完全够用。

**Q: 需要🪜吗？**

A: 不一定！豆包、DeepSeek、智谱GLM、Kimi都国内直连。

**Q: 哪个中文最好？**

A: 豆包、Claude、DeepSeek中文都不错。

**Q: 哪个最便宜？**

A: 豆包完全免费，DeepSeek付费最便宜。

**Q: 可以同时用多个吗？**

A: 可以！不同场景用不同工具，互补使用效果更好。
