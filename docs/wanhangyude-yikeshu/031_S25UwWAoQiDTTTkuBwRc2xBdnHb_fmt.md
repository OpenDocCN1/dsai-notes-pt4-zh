## 为什么用 Docker？（一句话解释）

您可以把 `Docker` 想象成一个“应用盒子”管理工具。它能帮我们把 `n8n` 和它的所有运行环境都打包在一个独立的“盒子”（称为容器）里。这样做最大的好处是干净、隔离，`n8n` 在自己的盒子里运行，完全不会“弄乱”您的电脑系统，卸载和升级也非常方便。

## n8n 本地安装新手指南（Docker 篇）

整个过程分为三大步：安装 `Docker` -> 运行 `n8n` 命令 -> 打开 `n8n`。

### 第一步：安装 Docker Desktop（应用盒子管理员）

如果您的电脑上还没有安装 `Docker`，这是我们的第一步。

1. 下载 `Docker Desktop` 安装程序：

   - Windows 用户：点击这里下载 `Docker Desktop for Windows`
   - Mac 用户：点击这里下载 `Docker Desktop for Mac`（根据您 Mac 的芯片选择 `Intel` 或 `Apple Chip` 版本）

2. 安装 `Docker Desktop`：

   - 双击下载好的文件，然后按照屏幕上的提示一步步安装。过程基本就是“下一步”和“确认”。
   - 安装过程中，如果提示需要开启 `WSL 2` (`Windows Subsystem for Linux 2`)，请同意并让它自动安装，这是 `Docker` 在 Windows 上运行的基础。
   - 安装完成后，重启电脑。

3. 确认 `Docker` 已启动：

   - 重启后，启动 `Docker Desktop` 程序。
   - 您应该可以在任务栏（Windows）或菜单栏（Mac）看到一个小鲸鱼图标 🐳。当图标静止不动时，就代表 `Docker` 已经准备就绪了。

### 第二步：运行 n8n 安装命令

现在，我们要告诉 `Docker` 去下载并运行 `n8n` 这个“应用盒子”。

1. 打开您电脑的“命令行工具”：

   - Windows：在开始菜单搜索 `cmd` 或 `PowerShell`，然后打开它。
   - Mac：在“应用程序” -> “实用工具”里找到并打开 终端 (`Terminal`)。

2. 复制并粘贴以下命令：

   请完整地复制下面这行命令，然后粘贴到您刚打开的命令行窗口里，最后按下 `回车` (`Enter`) 键。

   ```bash
   docker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n docker.n8n.io/n8nio/n8n
   ```

3. 命令解析（这行代码在做什么？）：

   - `docker run`：告诉 `Docker` “我要运行一个应用盒子”。
   - `-it --rm --name n8n`：给这个盒子起个名字叫 `n8n`，并做一些基础设置。
   - `-p 5678:5678`：这是“端口映射”，就像给盒子开一个门。它把您电脑的 `5678` 号门，连接到 `n8n` 盒子的 `5678` 号门。这样您就能通过这个门访问 `n8n` 了。
   - `-v ~/.n8n:/home/node/.n8n`：这是最关键的一步！它会告诉 `Docker`，把 `n8n` 在盒子里的数据（比如您的工作流、凭证），保存到您电脑主目录下一个叫 `.n8n` 的文件夹里。这样，即使盒子关闭或重启，您的数据也不会丢失。
   - `docker.n8n.io/n8nio/n8n`：这是 `n8n` 官方应用盒子的地址，`Docker` 会自动去这里下载。

### 第三步：启动并访问 n8n

1. 观察命令行窗口：

   当您按下回车后，会看到命令行窗口开始下载一些东西（第一次运行时需要下载，会慢一些）。下载完成后，会有一大段文字输出，当您看到类似下面的提示时，就代表成功了：

   ```
   Editor is now available on http://localhost:5678
   ```

2. 打开浏览器：

   现在，打开您的 `Chrome` 或 `Edge` 浏览器，在地址栏输入：

   `http://localhost:5678`

   然后按下回车。

3. 首次设置：

   您会看到 `n8n` 的欢迎界面，它会引导您创建一个管理员账号（设置邮箱和密码）。请按照提示完成设置。

恭喜！您现在已经拥有了一个属于自己的、功能强大的自动化中心。命令行窗口不要关闭，关闭它 `n8n` 就会停止。

## 日常使用小贴士

### 如何停止 n8n？

在命令行窗口中，按下键盘的 `Ctrl + C`。

### 如何重新启动 n8n？

再次打开命令行工具，运行和之前一模一样的 `docker run ...` 命令即可。因为数据已经保存在本地，您的工作流都会在。

### 如何更新 n8n 到最新版本？

1. 先在命令行运行 `docker pull docker.n8n.io/n8nio/n8n` 来下载最新的“盒子”文件。
2. 下载完成后，再像往常一样用 `docker run ...` 命令启动即可。
