
# MacOS系统查看版本号及芯片方法

> 来源：[https://my.feishu.cn/docx/GmP1dOwB1oELHpxjbD6cff1QnKc](https://my.feishu.cn/docx/GmP1dOwB1oELHpxjbD6cff1QnKc)

1. 点击屏幕左上角苹果logo并选择“关于本机”；
2. 出现的界面即为Mac系统版本信息详情；
3. 下图为详情介绍，请注意查看；

![](img/390ddb8207fbaa87326bc0d0c5cf5cc7.png)

MacOs系统查看版本号及芯片方法

Inter芯片的用户请根据系统本号选择适配的软件版本下载安装

M1芯片的用户请务必选择M1专用版链接或者通用链接下载安装
