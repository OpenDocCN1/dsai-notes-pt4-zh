# 修仙境界划分

> 来源：[https://my.feishu.cn/docx/NfwnddBwjoZKoGx8R2PcyPILnbb](https://my.feishu.cn/docx/NfwnddBwjoZKoGx8R2PcyPILnbb)

道修:炼气、筑基、金丹、元婴、化神期、合体期、大乘期、渡劫期。

魔修:聚气、凝神、吞噬、魔婴、化神期、合体期、大乘期、渡劫期。

妖修:聚灵、通智、妖丹、化形、神游期、练虚期、大乘期、渡劫期。

佛修:聚元、脱凡、明心、舍利、太虚期、通虚期、大乘期、渡劫期。

鬼修:灵动、开灵、魂丹、凝体、凝魄期、炼魂期、大乘期、渡劫期。

渡劫仙修:人仙、天仙、金仙、大罗金仙、九天玄仙、罗天上仙、仙君、仙帝、仙尊

注:修真每个阶段又分为初期、中期和后期,大乘后不分初期、中期和后期。

灵根:灵根属性金、木、水、火、土，异灵根属性冰、风、雷。金、木、水、火、土灵根又分为单灵根、双灵根、三灵根、四灵根和五灵根。

修仙丹药:灵丹、天丹、仙丹和神丹。灵丹按等级分为一至九品灵丹。包括筑基丹、结金丹、结婴丹、化神丹。按品质分为下品、中品、上品和极品丹药。

修仙武器:法器、法宝、灵器、仙器、神器一般分为下品、中品、上品和极品。修真者一般都有自己的本名法宝。武器的认可多为滴血认主或打上修真者的神识烙印。

修仙符篆:宝符、灵符、仙符和神符四等，每一等都分为一至九级。

修仙阵法、禁制:分为凡阵、灵阵、仙阵和神阵四等，每一等都分为一级至九级。

修真储物设备:储物袋、储物腰带、储物手镯、储物戒指。

修真灵脉、灵石:灵脉根据大小分为微型、小型、中型、大型、巨型。微型灵脉用与小家族和个人修行,小型、中型灵脉建立家族和小门派,大型、巨型灵脉建立大门派。

灵石分为下品、上品、极品。1千下品灵石＝1上品灵石1千上品灵石＝1极品灵石

炼器师等级:炼器师，炼器大师，炼器宗师，器王，器仙，器神，每一级分为一至九级

炼药师等级:炼药师，炼药大师，炼药宗师，药王，药仙，药神，每一级分为一至九级

阵法师等级：阵法师、阵法宗师、仙阵师和神阵师四等，每一等分为一至九级。

符师等级：符师、灵符师、仙符师和神符师四等，每一等也都分为一至九级。
