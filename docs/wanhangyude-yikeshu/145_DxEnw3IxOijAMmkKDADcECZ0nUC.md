## 一、情绪管理

### 1.1 核心理念

**不要把自己摆在对立面**

+ 情绪不是敌人，是信号

+ 接纳情绪，但不被情绪控制

**分清事实和观点**

+ 事实：客观发生的（"他迟到了"）

+ 观点：主观判断（"他不尊重我"）

+ 很多痛苦来自于把观点当成事实

### 1.2 ABC情绪理论

```
A（事件）→ B（信念）→ C（情绪）
```

**关键：** 决定情绪的不是事件本身，而是我们对事件的信念/解释。

**例子：**

+ 事件：老板批评你的方案

+ 信念A：老板在针对我 → 情绪：愤怒、委屈

+ 信念B：老板在帮我改进 → 情绪：感激、动力

### 1.3 情绪急救箱

| 情绪 | 急救方法 |

| --- | --- |

| 焦虑 | 写下来、拆解、行动 |

| 愤怒 | 暂停6秒、深呼吸、换位思考 |

| 沮丧 | 运动、找人聊、做件小事 |

| 迷茫 | 回顾目标、列清单、先做一件 |

| 嫉妒 | 关注自己的成长、转化动力 |

### 1.4 情绪日记模板

```
我的情绪：____（1-10分）
我的想法：____
事实是什么：____

行动：____
```

## 二、时间管理

### 2.1 核心理念

**时间管理管的不是时间，而是自己**

> 对于大多数人来说，其实再怎么进行时间管理，每天能够节省出来的时间也不会相差太多。相比管理时间，其实状态的提升和维持更有意义。毕竟时间就是时间，它自己走自己的，怎么能管理呢？你只能选择管好你自己。所以，我们不应该去管理时间，而应该去管理我们的精力。精力才是决定你在单位时间里的产出和利用率的关键因素。

**注意力 > 时间 > 金钱** ——李笑来《通往财富自由之路》

**时间就是你的命** ——彪悍一只猫《一年顶十年》

### 2.2 时间筹码法（万航宇原创）

> 筹码的这个概念实在是太棒了，因为他把抽象的时间概念和时间消耗立体的表示为筹码。一切都变的具象化。时间筹码押注在了哪里，就会对应的获得什么。——万航宇

**核心：**

+ 每天的时间 = 有限的筹码

+ 把筹码押注在重要的事情上

+ 记录筹码去向，持续优化

### 2.3 实操方法

**番茄工作法**

+ 25分钟专注 + 5分钟休息

+ 4个番茄后长休息15-30分钟

+ 适合：需要深度专注的任务

**精力管理四象限**

| 精力状态 | 适合做的事 |

| --- | --- |

| 高精力 | 重要决策、创意工作、学习 |

| 中精力 | 沟通、会议、日常事务 |

| 低精力 | 整理、回复、轻松任务 |

**碎片时间利用**

+ 5分钟：回复消息、看文章

+ 15分钟：听播客、整理笔记

+ 30分钟：阅读、写想法

## 三、信息管理

### 3.1 核心理念

**知识管理的两大核心：**

1. 梳理清楚知识之间的关系（知识体系）

1. 收敛知识从而回归本质（第一原理）

> 知识就是知识，当你得到了它，你就得到了一小片自己世界观的拼图，你拼得越多，世界观就越完善，在这个过程中，会有一种东西渐渐浮现，那就是你关于信息的直觉。——河森堡

世界分为「物质世界」和「法则世界」

+ 法则世界支配着物质世界，永恒不变

+ 物质世界在法则支配下，一直在运动变化

+ 我们只能感知物质世界，需要通过规律反推法则

### 3.2 模型树学习法

> 我们不追求读书的速度，不追求读书的数量，我们甚至都不太追求记忆。我们只把掌握事物背后的法则，当做唯一的学习目标。——兰陵王《模型树》

**核心：**

+ 学习 = 掌握事物关联性的过程

+ 知识体系 = 知识按照关系联结的集合

+ 不关联的知识 = 盲人摸象

**查理·芒格的建议：**

> 长久以来，我坚信存在某个系统——几乎所有聪明人都能掌握的系统，它比绝大多数人用的系统管用。你需要的是在你的头脑里形成一种思维模型的复式框架。有了那个系统之后，你就能逐渐提高对事物的认知。

### 3.3 信息处理流程

```
收集 → 筛选 → 整理 → 关联 → 输出
```

**收集：** `flomo`、`剪藏`、`截图`

筛选： 是否重要？是否可操作？

整理： 归类、打标签、提炼要点

关联： 和已有知识建立联系

输出： 写文章、做分享、教别人

### 3.4 知识库结构

**层级管理：**

+ 一级：大分类（工作、生活、学习）

+ 二级：小分类（项目A、项目B）

+ 三级：具体文档

**双链管理：**

+ 相关内容互相链接

+ 形成知识网络

**标签管理：**

+ `#项目/抖音CPS`

+ `#状态/进行中`

+ `#类型/SOP`

## 四、决策模型

### 4.1 10/10/10法则

**问自己：**

+ 10分钟后，我会怎么看这个决定？

+ 10个月后，我会怎么看这个决定？

+ 10年后，我会怎么看这个决定？

**作用：** 拉长时间维度，减少短期情绪干扰

### 4.2 逆向思维

**查理·芒格：** "反过来想，总是反过来想"

**应用：**

+ 想成功 → 先想怎么避免失败

+ 想健康 → 先想怎么避免生病

+ 想赚钱 → 先想怎么避免亏钱

### 4.3 概率思维

**核心：**

+ 很少有100%确定的事

+ 用概率做决策，接受不确定性

+ 长期来看，概率会兑现

**例子：**

+ 这个项目成功率60% → 值得尝试

+ 这个投资亏损概率80% → 不做

### 4.4 最小后悔原则

**贝佐斯的决策方法：**

+ 想象80岁的自己

+ 回顾人生，会不会后悔没做这件事？

+ 如果会后悔，就去做

## 五、学习模型

### 5.1 费曼学习法

**四步：**

1. 选择一个概念

1. 用简单的话教给别人

1. 发现讲不清楚的地方

1. 回去重新学习

**核心：** 能用简单话说清楚 = 真的懂了

### 5.2 刻意练习

**四要素：**

1. 目标明确（具体、可衡量）

1. 专注投入（全神贯注）

1. 即时反馈（知道哪里做得好/不好）

1. 走出舒适区（难度略高于当前水平）

### 5.3 学习金字塔

| 学习方式 | 留存率 |

| --- | --- |

| 听讲 | 5% |

| 阅读 | 10% |

| 视听 | 20% |

| 演示 | 30% |

| 讨论 | 50% |

| 实践 | 75% |

| 教别人 | 90% |

**结论：** 主动学习 > 被动学习

### 5.4 输入-处理-输出模型

```
输入（阅读/听课）→ 处理（思考/笔记）→ 输出（写作/分享）
```

**建议比例：** 30% 输入 : 30% 处理 : 40% 输出

## 六、复盘模型

### 6.1 KPT复盘法

**`K`（Keep）：** 做得好的，继续保持

**`P`（Problem）：** 遇到的问题

**`T`（Try）：** 下次可以尝试的改进

**模板：**

```
【本周复盘】
Keep：____
Problem：____
Try：____
```

### 6.2 PDCA循环

```
Plan（计划）→ Do（执行）→ Check（检查）→ Act（改进）
```

**持续循环，螺旋上升**

### 6.3 复盘时机

+ 日复盘：睡前5分钟

+ 周复盘：周日晚上

+ 月复盘：月底

+ 项目复盘：项目结束后

## 七、目标管理

### 7.1 SMART原则

**目标要：**

+ `S`pecific（具体的）

+ `M`easurable（可衡量的）

+ `A`chievable（可实现的）

+ `R`elevant（相关的）

+ `T`ime-bound（有时限的）

**例子：**

+ ❌ "我要减肥"

+ ✅ "3个月内减重5kg，每周运动3次"

### 7.2 OKR

**`O`（Objective）：** 目标（定性的，有野心）

**`KR`（Key Results）：** 关键结果（定量的，可衡量）

**例子：**

```
O：成为抖音CPS专家
KR1：发布100条带货视频
KR2：月佣金达到5000元
KR3：总结出可复制的SOP
```

### 7.3 目标拆解

```
年目标 → 季目标 → 月目标 → 周目标 → 日目标
```

**原则：**

+ 大目标拆成小目标

+ 小目标要能直接执行

+ 每天做的事要和长期目标对齐

## 八、习惯养成

### 8.1 习惯回路

```
触发（提示）→ 行为（习惯）→ 奖励（反馈）
```

**例子：**

+ 触发：早上起床

+ 行为：喝一杯水

+ 奖励：感觉清醒

### 8.2 21天法则

**习惯养成三阶段：**

+ 1-7天：刻意期，需要意志力

+ 8-21天：适应期，逐渐自然

+ 22天后：稳定期，成为习惯

### 8.3 习惯追踪

**方法：**

+ 打卡表（每天打勾）

+ 习惯APP（自动记录）

+ 日记记录（详细追踪）

**建议：** 一次只养成一个习惯

## 九、沟通模型

### 9.1 非暴力沟通

**四步：**

1. 观察（我看到...）

1. 感受（我感到...）

1. 需要（因为我需要...）

1. 请求（你能不能...）

**例子：**

+ ❌ "你总是迟到！"

+ ✅ "这周你有3次开会迟到，我感到很着急，因为我们团队需要协作，你能不能提前5分钟到？"

### 9.2 SCQA模型

**讲故事/汇报的框架：**

+ `S`ituation（情境）：当前状况

+ `C`omplication（冲突）：遇到的问题

+ `Q`uestion（问题）：核心问题是什么

+ `A`nswer（答案）：解决方案

### 9.3 反馈技巧

**正面反馈：**

+ 具体行为 + 正面影响 + 感谢

**负面反馈：**

+ 具体行为 + 影响 + 期待 + 支持

## 十、核心方法论（万航宇版）

### 10.1 找对标 → 拆解 → 复刻 → 批量化

**适用场景：** 做项目、学技能、搞副业

**步骤：**

1. 找到已经成功的人/账号

1. 拆解他们是怎么做的

1. 复刻他们的方法

1. 批量化放大

### 10.2 先开枪后瞄准

**核心理念：**

+ 不要等完美了再开始

+ 边做边调整

+ 完成比完美重要

### 10.3 10%目标定律

**马斯克：**

> 无论你在生活中想要什么，你都要做10次尝试。但问题在于，大多数人都不会尝试10次。可怕的真相是大多数人连一次都不想尝试。而10%目标定律的意义在于，学会积极面对90%的失败。如果你今后做任何事情，都愿意先尝试10次，那么，其中一个必定会成功。

### 10.4 不要当搬运工，要当厨师

**核心理念：**

+ 搬运工：复制粘贴，没有加工

+ 厨师：理解原理，重新创造

**应用：**

+ 信息整理：提炼核心，加入思考

+ 内容创作：吸收理解，用自己的话表达

+ 知识学习：掌握本质，灵活应用

## 使用建议

1. **不要贪多：** 一次掌握1-2个模型就够了

1. **刻意练习：** 在实际场景中反复使用

1. **定期复盘：** 看看哪些模型真的有用

1. **持续迭代：** 删掉不适用的，添加新的
