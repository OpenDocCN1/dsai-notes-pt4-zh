
# KANO模型

> 来源：[https://my.feishu.cn/docx/SobJdhVCaocyUzxofGLcKyKunkg](https://my.feishu.cn/docx/SobJdhVCaocyUzxofGLcKyKunkg)

KANO模型是一个帮助我们定义 “需求影响力” 的工具，通过定义评价的标准，来衡量每条需求可能对用户造成的实质影响。

## 详细说明

KANO 模型，翻译叫卡诺模型或狩野模型，它定义了5个基本的需求模型，即魅力、期望、必备、无差异、反向型，通过一定的分析步骤对每个属性进行打分，最终搞明它属于哪一类型。

KANO 定义了一个由功能完成度和用户满意度组成的2维坐标轴：

![](img/f3302e9f6be9d9cff9bc3deed3ac28e1.png)

并在这个坐标轴中，通过一定的曲线、区域，来表达下面说到的五种需求类型：

• 魅力型：提供了会让用户惊喜，但是不提供用户满意度也不会受到影响
• 必备型：提供了用户满意度不受影响，但是没提供则满意度大幅下降
• 期望型：用户非常渴望的功能，提供了用户满意度会上升，反之则下降
• 反向型：提供了会导致用户满意度下降
• 无差异：无论提供还是不提供，都不会有什么影响
