## 一、峰终法则

### 1.1 核心概念

人们对一件事的体验通常是由**最高峰的感觉**与**结尾的感觉**决定，而不是由总体决定。

> 注意：这个高峰并不一定是正向高峰，也有可能是负向高峰。

### 1.2 实验案例

诺贝尔经济学得主丹尼尔•康纳曼的实验：

让两组人带上耳机听噪音：

+ 第一组：听完就结束
+ 第二组：听完后再听一段音量小一些的

> 结果：第二组听了更久的噪音，但愿意继续参加实验的人居然更多！

### 1.3 应用场景

**产品体验：**

+ 与其让用户短时间内完成一个高难度的操作
+ 不如花更长时间完成一个低难度操作
+ 长痛不如短痛？不，长痛有时更符合人性

**生活应用：**

+ 旅行：最后一天安排最精彩的活动
+ 会议：结束时留下深刻的印象
+ 服务：客户离开时给个小惊喜

## 二、鸟笼效应

### 2.1 核心概念

人们会在**偶然获得一件物品后**，继续添加更多与之相关的东西。

又称"鸟笼逻辑"，是人类难以摆脱的十大心理之一。

### 2.2 经典故事

1907年，心理学家詹姆斯和物理学家卡尔森打赌：

**詹姆斯：** "我一定会让你不久就养上一只鸟的。"

卡尔森："我不信！因为我从来就没有想过要养一只鸟。"

几天后，詹姆斯送了卡尔森一只精致的鸟笼。

从此以后，只要客人来访，都会问："教授，你养的鸟什么时候死了？"

卡尔森只好一次次解释："我从来就没有养过鸟。"

但客人总是用困惑而有些不信任的目光看着他。

**最后，卡尔森只好买了一只鸟。**

### 2.3 心理机制

**为什么会产生鸟笼效应？**

+ 人们会在心里挂上一只"笼子"
+ 然后不由自主地往里面填东西
+ 被别人的习惯思维推理误解
+ 最终屈服于强大的惯性思维

### 2.4 应用场景

**商业应用：**

+ 送你一个手机壳 → 你会想买手机
+ 送你一个鸟笼 → 你会想买鸟
+ 免费试用 → 你会想付费升级

**个人反思：**

+ 减少不必要的"笼子"
+ 增加有效的"鸟"
+ 这才是鸟笼效应的真正启迪

## 三、三分定律

### 3.1 核心概念

一种三等分构图技巧，把画面横向和竖向各分成三格，再把设计中的主要元素放在网格中的一个交叉点上。

这种不对称结构图，有趣且具有美感。

### 3.2 使用方法

**什么时候用三分定律？**

+ 主要元素的强度不会被周围元素或空间强化时

**什么时候不用？**

+ 可以考虑居中构图
+ 有强烈的横向或竖向元素时，把元素排放在同一方向的网格线上

### 3.3 与黄金比例的关系

三分定律源自早期构图的网格系统，与黄金比例有关：

+ 三分定律：2/3 = 0.666
+ 黄金比例：0.618

虽然稍有不同，但三分定律的简单好用足以弥补它与黄金比例的差距。

### 3.4 应用场景

**摄影构图：**

+ 把主体放在交叉点上
+ 创造有趣的不对称构图

**设计排版：**

+ 文字和图片的位置安排
+ 页面布局

**视频制作：**

+ 人物位置
+ 重点元素的摆放

## 四、工程思维

### 4.1 核心概念

工程思维是一种研究或构建复杂事物的思维模型，核心有两点：

1. 模块化
2. 标准化

### 4.2 模块化

**定义：** 把复杂系统分解为独立的模块

**例子：**

+ 电子产品：处理器、摄像头、电池等，可独立设计、生产、维护
+ 汽车制造：引擎、传动系统、底盘等，可根据需求组合配置
+ 软件开发：用户界面、数据库管理等，便于团队协作和维护

### 4.3 标准化

**定义：** 使用统一的规范和接口

**例子：**

+ 建筑设计：遵循统一的建筑标准和规范
+ 电力系统：使用标准化的插座和插头
+ 计算机硬件：USB接口的标准化，使得不同设备可以通用

### 4.4 优势

通过模块化和标准化：

1. 提高效率：减少重复工作，缩短生产周期
2. 降低成本：规模生产，降低零部件成本
3. 易于维护：可替换故障模块，无需整体更换
4. 增强可靠性：经过验证的模块和标准提高了系统的稳定性

## 五、马斯洛需求层次理论

### 5.1 核心概念

美国心理学家马斯洛提出：人的需求分成5个层次，需求是由低到高逐级形成并得到满足的。

**五层金字塔：**

1. 生理需求
2. 安全需求
3. 社交需求（归属与爱）
4. 尊重需求
5. 自我实现

### 5.2 五层需求详解

#### Ⅰ. 生理需求（Physiological Needs）

**定义：** 人类维持自身生存的最基本要求

**包括：** 饥、渴、衣、住、性、健康

**特点：** 是推动人行动的最强大的动力

#### Ⅱ. 安全需求（Safety Needs）

**定义：** 人对安全、秩序、稳定及免除恐惧、威胁与痛苦的需求

**包括：** 身体安全、工作稳定、资源保障、家庭安全

#### Ⅲ. 归属与爱（Belonging and Love）

**定义：** 人要求与他人建立情感联系，以及隶属于某一群体并在群体中享有地位的需要

**包括：** 友情、爱情、亲情、社交关系

#### Ⅳ. 尊重需求（Esteem）

**定义：** 较高层次的需求

**包括：**

+ 成就、名声、地位、晋升机会
+ 对成就或自我价值的个人感觉
+ 他人对自己的认可与尊重

#### Ⅴ. 自我实现（Self-actualization）

**定义：** 最高层次的需求

**包括：**

+ 希望最大限度地发挥自身潜能
+ 不断完善自己
+ 完成与自己的能力相称的一切事情
+ 实现自己理想的需要

### 5.3 应用场景

**产品设计：**

+ 先满足基础需求，再追求更高层次
+ 不同用户群体关注不同层次的需求

**团队管理：**

+ 了解员工处于哪个层次的需求
+ 提供对应的激励措施

**个人成长：**

+ 认识自己当前的需求层次
+ 有意识地提升到更高层次

## 六、帕累托法则（80/20法则）

**核心概念：** 80%的结果来自20%的原因

**应用：**

+ 20%的客户贡献80%的收入
+ 20%的工作产生80%的价值
+ 专注于最重要的20%

## 七、幸存者偏差

**核心概念：** 只看到成功者，忽略失败者

**例子：** 二战飞机弹孔分析

+ 返航的飞机弹孔都在机翼
+ 但真正需要加强的是驾驶舱（被打中就回不来了）

**启示：** 不要只看成功的案例，也要研究失败的案例

## 八、沉没成本谬误

**核心概念：** 因为已经投入了，所以舍不得放弃

**例子：**

+ 看了一半的电影很烂，但舍不得走
+ 买了股票亏了，但舍不得卖

**启示：** 决策应该基于未来，而不是过去

## 九、锚定效应

**核心概念：** 人的判断会被第一印象"锚定"

**例子：**

+ 先看到一个高价，再看其他价格都觉得便宜
+ 谈判时先报价的一方占据主动

**应用：**

+ 定价策略
+ 谈判技巧
+ 第一印象管理

## 十、损失厌恶

**核心概念：** 失去100元的痛苦 > 得到100元的快乐

**比例：** 约2:1

**应用：**

+ 营销：强调"不买会失去什么"
+ 决策：理性看待得失

## 使用建议

1. 理论与实践结合：学了理论要思考怎么用
2. 举一反三：理论可以跨领域应用
3. 定期回顾：遇到问题时，翻翻这些理论
4. 持续补充：学到新理论就加进来
