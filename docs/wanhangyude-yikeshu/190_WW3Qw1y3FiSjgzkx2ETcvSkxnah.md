# 工程思维

> 来源：[https://my.feishu.cn/docx/Pu3WdVnNsovwJlxEbwyc78bZnmc](https://my.feishu.cn/docx/Pu3WdVnNsovwJlxEbwyc78bZnmc)

> **工程思**维是一**种研究**或者构建复杂事物的思维模型，它的核心有两点:“模块化“和“标准化”。

**模块化：**

+   **电子产品**：例如手机，不同的模块包括处理器、摄像头、电池等。这些模块可以独立设计、生产和维护，方便更新和替换。

+   **汽车制造**：引擎、传动系统、底盘等都是模块化的组件，可根据需求进行组合和配置。

+   **软件开发**：将程序分解为功能模块，如用户界面、数据库管理等，便于团队协作和维护。

**标准化：**

+   **建筑设计**：遵循统一的建筑标准和规范，确保建筑的安全性和稳定性。

+   **电力系统**：使用标准化的插座和插头，方便不同设备的连接和使用。

+   **计算机硬件**：如 USB 接口的标准化，使得不同设备可以通用。

通过模块化和标准化，以下优势得以体现：

1.  **提高效率**：减少重复工作，缩短生产周期。

1.  **降低成本**：规模生产，降低零部件成本。

1.  **易于维护和维修**：可替换故障模块，无需整体更换。

1.  **增强可靠性**：经过验证的模块和标准提高了系统的稳定性。
