
# 如无必要，勿增实体。

> 来源：[https://my.feishu.cn/docx/Rx83dsePKo2mRnx46x4ctCu4nAc](https://my.feishu.cn/docx/Rx83dsePKo2mRnx46x4ctCu4nAc)

**在复杂的世界中，我**们每天都要做无数选择。

有些选择看似增加了机会，实则引入了混乱、风险与内耗。如无必要，勿增实体，不仅是一句哲学格言，更是一种高效而健康的生活策略。

## 1. 为什么要减少“实体”？

**实体**可以是一个人、一段关系、一笔投资、一个项目，甚至是一条信息。

每增加一个“实体”，我们就增加了一份管理成本和风险：

+   **精神内耗**：复杂的人际关系和任务会占用大量注意力，削弱专注力。

+   **时间消耗**：额外的维护、沟通、协调，拖慢了主线任务的推进。

+   **金钱风险**：更多的投入往往意味着更多的不确定性，尤其在收益不成比例时。

+   **决策难度**：选项越多，反而越容易陷入犹豫与拖延。

## 2. 低熵生活的优势

熵增意味着系统从有序走向混乱，而我们能做的，就是减少不必要的熵源。

低熵生活的特点：

+   **简单**：核心事务清晰，减少杂音与干扰。

+   **高效**：资源集中在最重要的目标上。

+   **可控**：减少外界不可控因素的干扰。

+   **健康**：精神带宽更多用于创造和成长，而不是应付无谓的复杂性。

## 3. 实际应用案例

+   **不介入无关的因果**：不参与与自己主线目标无关的纷争或项目，避免被卷入无谓的麻烦。

+   **避免资源分散**：专注于1-2个核心收入或成长项目，不盲目拓展到熟悉度低、风险大的领域。

+   **慎选人际关系**：不必要的社交和不健康的人际互动，只会消耗精力和情绪。

+   **项目决策**：做决策前先问自己——如果不做，会失去什么？如果做，会引入多少新的管理成本？

## 4. 可能的代价与取舍

确实，减少“实体”可能意**味着放弃一些意外的惊喜**与机会。

但这是一种主动的取舍——宁可少而精，也不多而乱。

对于大多数普通人来说，保持身心健康与稳定的现金流，比追逐不确定的高风险机会更重要。

## 5. 总结

“如无必要，勿增实体”不是让我们变得保守，而是提醒我们在这个信息过载、机会泛滥的时代，学会选择性投入。

在有限的时间与精力中，把资源用在真正重要、确定性高的事上，让生活更简单、高效、可持续。

> 少即是多，简单即力量。

> ——奥卡姆剃刀的智慧
