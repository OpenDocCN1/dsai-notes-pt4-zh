> 亲密关系不是丧失自我，成为只会满足对方需求的"奴隶"，而是找到彼此一致的视角，看到生活中新的可能性。——《笔记的方法》

## 一、底层原则

### 1. 亲密关系的本质

⭐ 亲密关系是两个独立个体的联结，而不是依附。

+   保持自我，才能更好地爱人

+   好的关系是1+1>2，而不是1+1=1

⭐ 亲密关系需要经营，而不是自然而然。

+   爱情不是童话，需要持续投入

+   关系的质量取决于日常的细节

⭐ 亲密关系不是寻找完美的人，而是学会用完美的眼光看不完美的人。

+   接受对方的不完美

+   看到对方的优点，而不是缺点

### 2. 爱的五种语言

盖瑞·查普曼《爱的五种语言》：

1.  肯定的言辞 - 赞美、鼓励、感谢

1.  精心时刻 - 高质量的时间在一起

1.  接受礼物 - 物质的表达

1.  服务的行动 - 为对方做事

1.  身体的接触 - 拥抱、牵手等

关键：每个人的爱的语言不同，要找到对方需要的，而不是自己想给的。

## 二、核心公式

### 1. 亲密关系 = 信任 + 尊重 + 沟通 + 成长

#### 信任

+   说到做到，承诺必兑现

+   不撒谎，即使是善意的谎言

+   给对方安全感

#### 尊重

+   尊重对方的选择

+   尊重对方的边界

+   不控制、不强迫

#### 沟通

+   有问题及时说

+   不冷战、不逃避

+   倾听对方的需求

#### 成长

+   一起成长，而不是一起停滞

+   支持对方的梦想

+   共同面对挑战

### 2. 冲突处理 = 暂停 + 表达感受 + 寻找共识

#### 暂停

+   情绪激动时，先冷静

+   不要在愤怒时做决定

+   约定一个"暂停信号"

#### 表达感受

+   用"我觉得..."而不是"你总是..."

+   表达需求，而不是指责

+   说清楚自己要什么

#### 寻找共识

+   目标是解决问题，不是赢得争论

+   找到双方都能接受的方案

+   妥协不是输，是智慧

## 三、实用技巧

### 1. 每日三问

睡前问对方三个问题：

1.  今天有什么让你开心的？

1.  今天有什么让你不开心的？

1.  明天有什么我可以帮你的？

### 2. 周度约会

每周至少一次约会：

+   不聊工作、不聊孩子

+   只聊两个人的事

+   创造精心的时刻

### 3. 月度复盘

每月一次深度沟通：

+   这个月关系怎么样？

+   有什么需要改进的？

+   下个月的目标是什么？

### 4. 感恩日记

每天记录对方的三个优点：

+   培养感恩的习惯

+   看到对方的付出

+   不把对方的付出当理所当然

## 四、常见问题

### Q1: 如何处理对方的情绪？

+   先接纳，不评判

+   倾听，而不是急着给建议

+   问："你需要我做什么？"

+   有时候只是陪伴就够了

### Q2: 如何保持新鲜感？

+   一起尝试新事物

+   给对方惊喜

+   保持个人成长

+   不要把对方当理所当然

### Q3: 如何处理分歧？

+   分清"原则问题"和"非原则问题"

+   原则问题要沟通清楚

+   非原则问题可以妥协

+   目标是找到共识，不是说服对方

### Q4: 如何平衡个人和关系？

+   保持个人空间和时间

+   不要放弃自己的爱好

+   有自己的朋友圈

+   好的关系是两个独立的个体

## 五、关键心法

### 1. 先爱自己，再爱别人

+   如果你不爱自己，就无法真正爱别人

+   好的关系建立在自我完整的基础上

### 2. 不要试图改变对方

+   你改变不了别人，只能改变自己

+   接受对方的本来的样子

+   如果真的不合适，考虑分开

### 3. 吵架不可怕，可怕的是冷战

+   吵架是沟通的一种方式

+   冷战会消耗感情

+   有问题及时说，不要憋着

### 4. 关系是需要经营的

+   不要等到出了问题才想办法

+   每天都要投入

+   小事累积，就是大事

### 5. 表达爱，而不是期待对方猜

+   直接说出你的需求

+   不要让对方猜你的心思

+   爱要表达出来
