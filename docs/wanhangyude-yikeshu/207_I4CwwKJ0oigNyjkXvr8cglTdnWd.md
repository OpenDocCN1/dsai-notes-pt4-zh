## 一、底层原则

### 沟通的本质

- 沟通不是对着别人的脸，而是对着自己的心
- 沟通不是使用漂亮话术，而是建立信任关系
- 沟通的意义在于：通过不断同步双方的"信息流"，让共识区慢慢变大，让盲区越来越小

### 最难沟通的人

最难沟通的不是没有文化的人，而是被灌输了标准答案的人。

### 沟通的三个前提

- 语言相通
- 学识相近
- 信任成本低

否则就是"对牛弹琴"，沟而不通。

### 人的本质

虽然没有两个人拥有同样的面孔，但就本质而言，人类拥有同样的心理结构。—— 史蒂芬·平克

每个人毕生都在追求的是：被看见。

## 二、核心公式

### 开放性 = 扩大共识 + 消除盲区

**怎么做到？**

- 先假设对方是正直、善良和诚信的（吴军）
- 以开放引导开放，是为高级
- 开放性不只是一种态度，更是一种能力

**结构化倾听：头脑里画三个框**

- 情绪：对方现在的感受是什么？
- 事实：对方说了哪些客观事实？
- 期待：对方真正想要的是什么？

### 2.1 建设性 = 可执行的最小化行动 + 可持续的行动阶梯 + 每个节点的即时反馈

**关键原则：**

- 建设性的反义词不是破坏性，而是停滞不前
- 建设性是一项把沟通导向行动的能力
- 建设性不是为了给别人提供方便，而是为了你自己把事儿做成

**一句话技巧：**

- "来，我们抓抓落实。"（罗胖）
- "请您再给我提点需求。"

### 2.2 赞美 = 打追光 + 轻轻地 + 深深地 + 常常地

- 每个人都需要被看见
- 赞美是把光打在别人身上
- 鼓励自己最好的方式，就是鼓励别人（马克·吐温）

### 2.3 激励 = 及时赞美 + 行为建模 + 反馈闭环

**三句大白话：**

1. "你做得真好"（及时赞美）
1. "请问你是怎么做到的？"（行为建模）
1. "你总结得真好，我跟你说说对我的启发"（反馈闭环）

### 2.4 说服 = 说话有分量 + 凿穿心理防线

**核心心法：**

- 成功的说服是不说服
- 说服一个人，是让他觉得我们俩是一伙的
- 说服力的终极武器：可视化

### 2.5 批评 = 控制环境 + 定义问题 + 刷新动作 + 设定反馈点 + 完成重启

**原则：**

- 批评不是要告诉他怎么错了，而是告诉他怎么才能对
- 批评不是要让他"服"，而是要让他好
- 批评起到的就是"刷新"的作用

### 2.7 道歉 = 关闭过去 + 承诺未来

**终极奥义：**

- 道歉不是承认"我错了"，而是承认"你是对的"
- 重要的不是为过去的行为道歉，而是要向对方承诺一个面向未来的增量

### 2.8 辅导 = 植入目标 + 发现盲区 + 实战演习

**原则：**

- 教行动方法，不教价值观
- 每当我想作为过来人讲两句的时候，就得想想：人家让我过来了吗？

## 三、实用技巧

### 换口径

对方问你A问题，你换个口径来回应。

**例子：**

- 同事阴阳怪气："呦，您现在可真是个大忙人呢！"
- 回应："唉，我就佩服您这样的业务大拿，举重若轻，什么事儿到您手上都能很快解决。"

### 换时间

另找时间来解决对方的问题。

**场景：**

- 领导突然要调你去客服，你毫无准备
- 回应："领导，这么重要的事，我得认真想想。您能不能给我点时间，我好好考虑下，下周一我来给您汇报。"

**一分钟暂停法：**

- "不好意思，我能去个洗手间吗？一分钟就回来。"
- 化被动为主动，由你来发起下一轮沟通

### 换场合

把问题降级，换个场合再说。

**场景：**

- 领导开大会说要取消所有休假，你有难处
- 回应："小事，不耽误大家，会后我跟您说。"
- 会后私下沟通，成功率大大提高

### 换角色

从参与者变成主持人，把问题抛给更专业的人。

**例子：**

- 客户问六西格玛认证的问题
- 你说："您这个问题太重要了，我可问到点子上了。我先请技术同事跟您说一说。"

## 四、关键心法

### 4.1 目中有人

苏霍姆林斯基的故事：小女孩摘了花园里最大的玫瑰花。他没有批评，而是先问："孩子，你摘这朵花是送给谁的呀？"

原来是给生病的奶奶看。他于是摘下第二朵玫瑰："一朵奖励给你，因为你有一颗充满爱的心灵；另一朵送给你奶奶，感谢她养育了你这样的好孩子。"

### 4.2 先发展关系，再解决问题

- "提意见"会触发对方防御心理
- 改用"提建议"，暗示你带来了解决方案
- 目标是发展双方"共同体关系"

### 4.3 真话不全说，假话绝不说
