## 一、底层原则

### 1. 生病的本质

生病的本质，就是**细胞损伤速度超过了修复的速度**。

在细胞损伤和修复的博弈过程中，能给细胞修复提供原料的只有饮食。

### 2. 身体在褐变

从出生的那一刻起，我们的身体内部就开始进行褐变，尽管这一过程非常缓慢。

+ 婴儿的软骨是白色的
+ 90岁老人的软骨会变成褐色

这叫**美拉德反应**（Maillard Reaction），是身体老化的自然过程。

### 3. 饭后疲劳的原理

身体会在饱餐后释放出一种化学信息素，刺激大脑某一特定区域，让人觉得疲劳，没法专心工作。

**原因：** 让小肠能最高效地工作，更好地完成消化。

**应对：** 接受这个生理规律，不要在饭后安排重要工作。

### 4. 唾液的镇痛作用

咀嚼食物时，唾液腺会分泌大量口水，夹带着释放出额外量的镇痛物质。

所以：

+ 喉咙疼的时候，吃完饭会觉得好很多
+ 吃完饭后口腔里的小伤口也没那么疼了

## 四、卫生习惯

### 厨房三大法则

**法则1：使用塑料菜板**

+ 塑料菜板清洁起来比较方便
+ 木质菜板的槽缝容易养细菌

法则2：生肉鸡蛋壳接触过的东西，用热水彻底冲洗

法则3：肉类和蛋类尽量煮透后再吃

### 幽门螺杆菌

+ 感染者里，约1/5的人胃壁有损伤
+ 约3/4的胃溃疡和几乎所有小肠溃疡由它引起
+ 是**胃癌的罪魁祸首**
+ 国内感染率约50%
+ **去医院吹口气就能测**

## 五、行动清单

### 立即可做

+ 去医院测幽门螺杆菌（吹气测试）
+ 检查家里的菜板是否是塑料的
+ 生肉和鸡蛋壳接触过的东西用热水冲洗

### 日常习惯

+ 早睡早起，不熬夜
+ 饭后不安排重要工作（接受疲劳的生理规律）
+ 控制碳水摄入，避免葡萄糖峰值
+ 肉类蛋类煮透再吃
