# 一、底层原则

## 1. 情绪的本质

⭐ 情绪不是敌人，是信号。

+   情绪在告诉你：有些事情需要关注

+   不要压抑情绪，要理解情绪

+   情绪没有好坏，只有存在

⭐ 情绪是暂时的，不是永久的。

+   "这也会过去"

+   不要被情绪定义

+   你不是你的情绪

⭐ 情绪是可以管理的，不是被控制的。

+   你可以选择如何回应

+   情绪和反应之间有空间

+   管理情绪，而不是被情绪管理

## 2. 情绪的来源

⭐ 情绪 = 事件 × 解读

+   同样的事件，不同的解读，产生不同的情绪

+   改变解读，就能改变情绪

+   你的想法决定了你的情绪

⭐ 情绪来自需求是否被满足

+   需求被满足 → 正面情绪

+   需求未被满足 → 负面情绪

+   理解情绪背后的需求

# 二、核心公式

## 1. 情绪管理 = 觉察 + 接纳 + 表达 + 调节

**觉察：**

+   识别自己的情绪（愤怒、焦虑、悲伤、恐惧...）

+   知道情绪的强度（1-10分）

+   知道情绪的来源（什么触发了情绪）

**接纳：**

+   不评判情绪（不要说"不应该生气"）

+   允许情绪存在

+   对自己说："我现在感到...，这是可以的"

**表达：**

+   用语言表达，而不是行动

+   "我感到..."而不是"你让我..."

+   说清楚需求，而不是指责

**调节：**

+   深呼吸（4-7-8呼吸法）

+   暂时离开现场

+   做一些让自己平静的事

## 2. 应对负面情绪 = 暂停 + 分析 + 行动

**暂停：**

+   深呼吸3次

+   喝一杯水

+   离开现场10分钟

**分析：**

+   我现在是什么情绪？

+   为什么会有这个情绪？

+   我的什么需求没有被满足？

**行动：**

+   我能做什么来满足需求？

+   我需要谁的帮助？

+   下次遇到类似情况怎么办？

# 三、常见情绪及应对

## 1. 焦虑

**信号：** 未来有不确定性，你担心自己应对不了

**应对方法：**

+   写下担心的事

+   区分"能控制的"和"不能控制的"

+   专注能控制的，放下不能控制的

+   制定行动计划，减少不确定性

**心法：** 焦虑是因为你想控制未来，但未来不可控。专注当下。

---

## 2. 愤怒

**信号：** 你的边界被侵犯了，或者你的需求没有被尊重

**应对方法：**

+   深呼吸，数到10

+   暂时离开现场

+   问自己：我的什么边界被侵犯了？

+   用"我感到..."表达，而不是攻击

**心法：** 愤怒不是坏事，它在保护你。但要表达愤怒，而不是愤怒地表达。

---

## 3. 悲伤

**信号：** 你失去了重要的东西（人、事、物）

**应对方法：**

+   允许自己哭

+   不要压抑悲伤

+   找人倾诉

+   给自己时间

**心法：** 悲伤是爱的代价。允许悲伤，才能走出悲伤。

---

## 4. 恐惧

**信号：** 你感到不安全，或者面临未知的挑战

**应对方法：**

+   问自己：我在害怕什么？

+   最坏的结果是什么？

+   如果最坏的结果发生了，我能怎么办？

+   制定应对计划

**心法：** 恐惧是正常的，不要逃避恐惧，要理解恐惧。

---

## 5. 嫉妒

**信号：** 别人有你想要的，但你没有

**应对方法：**

+   承认嫉妒，不要否认

+   问自己：我真正想要的是什么？

+   别人的成功不意味着我的失败

+   把嫉妒转化为动力

**心法：** 嫉妒告诉你，你想要什么。把嫉妒当指南针。

# 四、实用技巧

## 1. 情绪日记

每天记录：

+   今天有什么情绪？

+   是什么触发了情绪？

+   我是怎么应对的？

+   下次可以怎么做更好？

## 2. 情绪温度计

+   1-3分：平静

+   4-6分：有情绪，但可控

+   7-8分：情绪强烈，需要调节

+   9-10分：情绪爆发，需要暂停

**当情绪达到7分以上，立即暂停。**

## 3. 深呼吸技巧（4-7-8呼吸法）

1.  吸气4秒

1.  屏息7秒

1.  呼气8秒

1.  重复3-5次

## 4. 情绪命名

+   精确命名情绪，能降低情绪强度

+   不是"我很难受"，而是"我感到焦虑"

+   不是"我很不爽"，而是"我感到愤怒"

## 5. 认知重构

+   事件 → 想法 → 情绪

+   改变想法，就能改变情绪

+   问自己：这个想法是真的吗？有帮助吗？

# 五、关键心法

## 1. 情绪是信号，不是敌人

+   不要压抑情绪

+   要理解情绪在告诉你什么

+   情绪是帮助你，不是伤害你

## 2. 你不是你的情绪

+   你有情绪，但你不是情绪

+   情绪会过去

+   不要被情绪定义

## 3. 情绪和反应之间有空间

+   刺激 → （空间）→ 反应

+   在这个空间里，你可以选择

+   管理情绪，就是利用这个空间

## 4. 表达情绪，而不是情绪地表达

+   "我感到愤怒"（表达情绪）

+   愤怒地大喊大叫（情绪地表达）

+   前者是管理，后者是被控制

## 5. 每一个抵抗的情绪背后都有尚未满足的需要

+   理解情绪背后的需求

+   满足需求，情绪自然消退

+   不要只看情绪，要看需求
