# 短视频：橱窗带货

> 来源：[https://my.feishu.cn/docx/KNDed4z71op4Ncxlg6BczkpvnOe](https://my.feishu.cn/docx/KNDed4z71op4Ncxlg6BczkpvnOe)

做橱窗带货核心就是四个

1.  选品

1.  素材

1.  账号

1.  回款

选品主要是精选联盟找爆品或者近期即将要爆的品

素材分为实拍和混剪

账号有黑号、本土自然流、半刷、国产号、耶稣号、机刷号.......

回款分为MCN机构回款、线下结佣、paypal 回款。

账[TikTok美区封橱窗汇总](https://ghlf0s3q3l.feishu.cn/wiki/O14ywKv8zigTLDkAEj6cTfH8nNb)有的可能会自己养号，这样对于账号成本可以减少很多，但是风险点在于即便养到了 5000 粉丝，也不一定能开橱窗。

其它分支就是其中的一些细节，比如批量下载视频，剪辑视频，网络，刷机，混剪技术，实拍技巧等等，都是属于基础操作。最重要的依然还是这四点，选品、素材、账号、回款。
