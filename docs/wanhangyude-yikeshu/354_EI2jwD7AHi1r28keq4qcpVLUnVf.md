# 二、搭建小红书账号

## 2.1 定位

定位和选品就是回答 3 个问题：

+   **面向什么人群**

+   通过提供什么样的服务，解决什么样的问题

+   卖给目标用户什么产品（解决什么样的问题？)

总的来说，定位决定了你：通过什么方式赚钱？（变现形式），凭什么赚钱？（核心价值），赚谁的钱？（精准用户），赚多少钱？（定价）等等因素。

### 2.1.1 归纳九宫格

你是谁？

+   职业（社会角色、行业角色）

+   外表（形象特征、穿搭风格、妆容风格）

+   性格（性格特点、人物个性）

你需要谁？

+   粉丝画像（性别、年龄段、人群共性）

+   需求场景（具体、细节、生活化、感性）

+   记忆点（一个词一句话、一个招牌动作、标签、标志道具）

你有什么不一样？

+   优势（差异化、厉害之处、专业角度）

你能做什么？

+   价值（提供什么、解决什么、分享什么）

中心点

+   核心价值观

| 职业 | 外表 | 性格 |
| --- | --- | --- |
| 优势 | 核心价值观 | 价值 |
| 粉丝画像 | 需求场景 | 记忆点 |

## 2.2 包装

### 2.2.1 头像

跟你的人设形象吻合即可，长得不错的建议用真人头像，容易建立信任感。

如果不想用真人头像，用虚拟 IP 形象也可以。

制作方式：可以使用图怪兽等网站来进行图片的制作，将满意的图片作为头像。又或者找些无版权的图片：

+   图怪兽：https://818ps.com/

+   可画：https://www.canva.cn/

+   创客贴：https://www.chuangkit.com/

+   搞定设计：https://qiye.gaoding.com/

注意事项：注意避免使用容易侵权的商标类图片

### 2.2.2 昵称

有辨析度、好记、有趣的名字，专业属性标签最好能加，更有辨析度和真是可信。不要用复杂的符号或特殊语言。

**有以下 4 种公式可作参考：**

+   昵称 + 个性：大鹅的七七八八

+   昵称 + 地区：姚老板在北京

+   昵称 + 专业：跟着拆哥看房

+   昵称 + 价值观：阿鱼爱学习

### 2.2.3 简介

一个写简介的公式：

+   你是谁

+   你做过什么牛逼的事

+   关注你有什么好处，或者分享哪些领域的内容

有的账号出了上万点赞的爆款，但是粉丝只有 100 个，主要原因是账号的内容没有明确的垂直定位，并且个人简介没有写好，没有能够让粉丝找到关注的理由。

所以，写简介的时候千万不要谦虚，如果你不能展现出可以给粉丝提供的价值，那他们凭什么关注你呢？

### 2.2.4 背景图／瞬间

跟产品、人设、工作场景有关的都可以设置为背景图。

瞬间可以发一些类似朋友圈的工作和生活打卡，尽量发和你 IP 领域有关的，用来拉近和用户的距离。

### 2.2.5 主页排版

封面要体现你的风格和特色。风格尽量统一，色彩统一和谐不要太杂乱。可调整封面设计但不要一天一个样。

## 3.4 小红书内容制作

### 3.4.1 标题

#### 3.4.1.1 二极管标题法

**基本原理：**

+   本能喜欢：**最省力法则和及时享受**

+   **动物基本驱动力**：追求快乐和逃避痛苦，由此衍生出 2 个刺激：正刺激和负刺激

**标题公式**

**正面刺激**：产品或方法＋只需１秒（短期）＋便可开挂（逆天效果）

+   减重 90 斤，分享 4 条干净饮食习惯

**负面刺激**：你不 xxx + 绝对会后悔 （天大损失）+（紧迫感）

+   你不看这个文章就会错过一个亿 限时删除！！！

+   简单来说就是制造焦虑，有点损，但是用户吃这一套。

其实就是利用人们厌恶损失和负面偏误的心理（毕竟在原始社会得到一个机会可能只是多吃几口肉，但是一个失误可能葬身虎口，自然进化让我们在面对负面消息时，更加敏感。)

#### 3.4.1.2 杂交法

如下图：搜纪录片-最热，翻看排名前十笔记，会发现关键字就这么几个：唯唯诺诺、央视推荐、格局炸裂

**最热前 8 个**中有 6 个的标题几乎是一样的（爆款都是重复的）

直接抄，关键词不断排列组合，这样杂交出的标题自带爆款基因。

![](img/bf8ccb19a05afb16a42b7fb5d1841529.png)

#### 3.1.1.3 做比较

把不同事物或同一事物的不同阶段进行对比，形成反差，引发用户好奇和点击。

举例：

+   坚持带孩子做这四件事，比补课强 100 倍！

+   低学历逆袭，高中毕业如何年入百万

+   上映时被骂烂片，如今成无数人心中的白月光

#### 3.1.1.4 戳痛点

击中用户痛点，可以引发他们的共鸣，从而激起用户解决问题的需求，让他们忍不住点开笔记一探究竟。

举例：

+   没时间锻炼，推荐这个动作

+   总怀疑自己不够好！完成这两点终于摆脱自卑

+   平胸有救啦！提 cup，消副乳，防止胸部下垂

#### 3.1.1.5 立权威

通过引发权威，来提升用户的信任度。这里的权威，可以指名人明星，也可以是领域内的专家，还可以是经验丰富的普通人。

举例：

+   十年黑长直护发经验，总结了 12 个日常小习惯

+   从理发店小哥那学到的去头油的方法

+   央视推荐的 6 本书 | 值得一读再读

#### 3.1.1.6 提问题

问句是一种十分常见的标题技巧，常见的有设问句、反问句等等。相比于陈述句，问句可以很好地调动用户的积极性，引发用户思考，增加他们的参与感。

举例：

+   怎样爱自己？当妈后我开窍了

+   被夸奖后如何回复？

+   父母不强调自己的付出，就会养出白眼狼吗？

#### 3.1.1.7 设危机

人们对威胁到自己的东西普遍比较敏感，所以，警告、威胁性的标题，可以很好地吸引大家的目光。例如“千万不要”、“一定要”之类，或者是直接体现严重后果的警示性标题。

举例：

+   女生这样做男友会离你越来越远！

+   2022 已过 1/3！想要逆风翻盘必须停止这 3 件事

+   8 种珠宝佩戴禁忌，90%的人都踩坑了！

#### 3.1.1.8 留悬念

都说”好奇心害死猫“，但好奇是每个人的天性。当你说一半留一半，犹抱琵琶半遮面，就能勾起用户的好奇心和探索欲。

举例：

+   死亡会有感觉吗？3 次成功抢救，3 个真实故事

+   避开这些雷区，教你装修省钱的秘诀

+   灭杀蟑螂的公司，不会告诉你的秘密。

#### 3.1.1.9 反常规

除了“欲说还休”，大家也可以通过一些有违常理的点，或提供新鲜的认知来制造悬念，目的也是激发用户的好奇心。

举例：

+   睡姿也能控梦

+   每天都吃肉，结果我瘦了 15 斤

+   你的记忆可能欺骗了你！最后一个我不相信！

#### 3.1.1.10 走捷径

做一件事，谁都希望能省时省力省钱省心，最后还能获得满意的结果。所以“速成类”、“低成本类”的关键词往往也很能打动人心。

举例：

+   新手学 ipad 绘画必备！白嫖五大 procreate 课

+   新手在家不花一分钱，也能 get 新技能

+   10 秒钟就能做好的懒人早餐，不揉面不擀面

#### 3.1.1.11 晒成果

人都有慕强心理，如果你的成果比较牛，不妨把它晒出来。

举例：

+   我曾经靠这套学习方法，单科平均提升 30 分

+   自媒体涨粉难？一天涨粉 1000+的我，教你 3 个秘诀

+   纯新手 30 天涨万粉，全靠小红书 5 个隐藏功能

#### 3.1.1.12 蹭热点

热点本身自带流量，关注的人会比较多，比如今年年初的谷爱凌，6 月份的梦华录，以及最近的董宇辉等等。借助热点赋能，可以让你的笔记获得更多的曝光量。

举例：

+   刘亦菲《梦华录》，别让“善良”成为诅咒

+   谷爱凌的 7 个特质，值得所有女孩子学习

+   房琪 | 会说话的女生，真的会发光

但是也要注意，热点不要瞎蹭，结合自己的领域，去挖掘适合自己的热点。

#### 3.1.1.13 贴标签

我们可以从年龄、地域、身份、职业等方面给用户贴标签，制造用户的身份认同感，以及角色代入感，其实也是在定位精准人群。

举例：

+   小镇女孩如何克服自卑感？

+   学生党随身迷你好物，出门必备

+   150 小个子 | 八条显高法则

#### 3.1.1.14 列数字

数字法是应用最为广泛的一种标题技巧，因为比起文字，数字更加直观，也更有冲击力、

而且，它还可以和以上任何一种技巧组合起来，增加标题的吸引力。但是，如果没有其他技巧的结合，数字本身就要足够吸睛，让人感觉干货满满。

举例：

+   115 部优质电影汇总，马住慢慢看

+   80 件新生开学必备用品

+   值得花一生阅读的 300 本书

### 3.4.4 评论区

让用户多多评论的直接好处就是

+   通过羊群效应激发更多有需求的用户主动私聊，就像 “ 排队买肉香，人多饭好吃 ” 一样

+   流量更上一层楼

那重点策略就要放在多多让用户评论和关注上

> 跟很多公域平台一样，小红书也有算法推荐机制，系统会根据你笔记的初始点赞、收藏、评论、转发、分享、转粉数据来打分，评论、转发和转粉这三个的分数占比较高。

> **C**ES 评分：点赞数 x 1 分 + 收藏数 x 1 分 + 评论数 x 4 分 + 转发数 x 4 分 + 关注数 x 8 分

> 

> PS：CES 为小红书的内部评分体系。

当你的笔记分数越来越高，就会一级一级的被系统推荐到更大的流量池，成为爆文（小爆款互动量 1000+，大爆款 10000+，不同类目有所不同）而这篇爆文还会带动其它笔记的整体数据增长，当然要先满足这些前提。

**原理：**

+   羊群效应：大部分人都是跟风，盲目跟从，所以我们需要的是带动羊群的头羊。

+   给指令：用户很懒，不想动脑，当用户看到喜欢的内容时，要马上告诉他如何领取，否则那些需求不是特别高的用户就会流逝。

**具体操作**

1.  引导关注+扣随机数字 （给出简单指令，同时这个指令有利于我们做数据）

1.  拿 3 个小号自己先评论（激发羊群效应，三人成虎，3 个就够了。)

没有小号的话，可以加几个任务群，互助群（小红书直接搜关键字，就会找到很多。)

#### 3.4.4.1 评论区可以发图片了（2023 年 04 月 22 日最新版本内侧 7.85.0）

评论区也可以发图片了，如果侧重营销属性的话，可以把用户好评之类的放在评论区来消除用户的戒心，也是在推动用户来做决策。

## 3.5 小红书引流

首先要说明的是，目前，小红书没有绝对 100%安全的引流方式。

因为平台的规则一直在变，很可能昨天能用的方式，今天就不行了，所以，引流方式务必需要不断地迭代更。

### 3.5.1 玩法一：评论区→小红书群→微信

![](img/8299a9b95ae120c90e0642c0decffd9d.png)

对标的这个**被封号**了，目前不清楚是不是在群内直接发微信截图的缘故。不过目前可以确定的是在评论区发小红书群是不违规的，因为有看到几万粉的博主也是用的这个方式来引流。

### 3.5.2 玩法二：主动私信关注的用户

被动等待客户添加转为主动去撩用户

这种类型最好的就是，放好足够吸引用户的钩子。让用户自己在评论区回复想要添加。然后再私信回复。

### 3.5.3 玩法三：主页简介直接留微信

风险比较高

### 3.5.4 玩法四：主页瞬间留微信

### 3.5.5 玩法五：夸张有趣头像+个人简介引导

本方法就是头像比较吸睛，乍一眼从主页看头像，看不出来有引流迹象。

但是通过个人简介的引导，比如下述案例中“看看我的大嘴巴子”这句话，来引导用户点击头像大图，点击后会发现，头像里其实还有比较浅淡的微信水印，实在是有趣又暗戳戳的引流法～

![](img/9f34055fda7528d041b96cea1bbf9c95.png)

注意事项：此方法有风险

+   第一：如果微信水印比较重，上传头像很容易不过审核，会提示头像违规；

+   第二：有被同行举报的风险。

整体而言，头像偶尔违规对账号伤害不大，可以尝试。

### 3.5.17 玩法十七：留钩子引流法

所谓留钩子引流，就是通过在笔记中留个钩子，明示或暗示用户联系你领取资料，一般多见于干货类的笔记。

明示法：直接在笔记里提示用户留言，或者在评论区引导到私信或其他带联系方式的页面。

![](img/fbabaa31acd04d592d0bff378441953d.png)

![](img/3067ec5592318a963697f14b62008124.png)

![](img/9d1f57ce19239bcbe49b9c911260b3d8.png)

### 3.5.18 玩法十八：私信引流

通过评论区导流等方式，把用户导入到私信后，在私信里留下联系方式。

回复联系方式时，建议大家经常切换不同的暗号，比如 emoji、谐音、图片等。避免直接发链接，二维码，包括一些敏感词，如“加 V”、“VX”等等。

可以直接回复微信词，因为懂得人都懂，真正愿意私信联系你的人，一般转化意向也比较强烈。

微信号用英文+数字的形式比较好，切记不要一长串字符，控制在 7-8 位字符都比较安全（测试过）

![](img/cf8a996a195ddfdfdae0370641e4140d.png)

还可以发图片，在图片中嵌入联系方式，但是不要太过显眼。比较推荐手写体，因为系统对手写体的识别度还不是那么高。

![](img/459f78c03257cee951e1a40c45ed566b.png)

注意事项：

+   如果用图片引流的方式，暗号一定不要过于明显，而且建议多准备几张图片，不要想着一劳永逸，反复使用同一张图片。

+   不同的回复方式也要多多切换使用，因为重复的文字或图片都会触发审核。

+   私信引流要注意使用频率，对于粉丝体量不大的博主，建议主动私信的数量每天不要超过 5 次。

## 4.4 限流

### 4.4.1 什么是限流

其实小红书官方没有限流这个说法，而是叫做“流量异常”，那既然是异常，就是和正常情况有一个比较的过程。

所以，有的新人博主刚发了一两篇笔记，然后发现数据不好就开始怀疑自己被限流了，这个是不合理的。

流量异常分为两种情况：一种是单篇笔记异常，一种是整个账号异常。

#### 4.4.1.1 单篇笔记限流

单篇笔记和其它笔记相比，流量明显下降。比如说你其他笔记平均阅读量是 1000+，但这篇笔记突然降到了四五十个。

或者你这篇笔记一开始流量很正常，持续有一些点赞收藏，但突然某一刻互动量就停了，笔记阅读量呈现断崖式下滑。

这两种情况都有可能是被限流的表现。

#### 4.4.1.2 账号限流

如果你之前的笔记流量不错，但是近期发布的笔记阅读量都很差，或者，无法给自己或他人的笔记点赞评论，疑似账号被禁言或限制互动。

当然，如果禁言或者被人举报，官方一般会直接给你发站内信提醒，像下图这样：

![](img/3da43cd5e734d5a156891de276ebe087.png)

但也有很多时候，平台只会悄咪咪的给你限流，根本没有任何通知。

那这时候怎么办？下面教大家几种检测方法。

### 4.4.2 如何判断有没有限流

#### 4.4.2.1 阅读量判断

一篇笔记发布后，平台通常会给你一部分基础流量，根据这部分基础流量的互动情况，判断这篇笔记的质量，然后决定要给你增加流量还是减少流量。

但基础流量具体是多少，我们没办法看到，根据经验来看，如果笔记发布 24 小时候，小眼睛（笔记阅读量）一直小于 50，就有可能是被限流了。

尤其是一些老账号，如果你之前的笔记阅读量达到成千上万，但新发的笔记每一篇都在 50 以下，大概率就是有问题了。

#### 4.4.2.2 转发测试

当你怀疑一篇笔记被限流，第一步可以做的事情是，把它转发到你自己或朋友的微信，看看能不能打开。

如果笔记显示“该笔记正在审核，请稍后查看”，或者“笔记无法展示”，说明审核未通过或者被限制展示了。

![](img/c3642da5c374665575ea1880e26c94d0.png)

造成这样的原因，可能是笔记中含有违禁词、敏感词，或者一些平台不鼓励的内容，比如尺度大、涉黑类等内容。

#### 4.4.2.3 搜索检测

如果笔记能正常打开，继续下一步，去小红书 app 内搜索。

想知道账号是不是被限流，直接在首页搜索框输入自己的小红书 id 号搜索，如果账号正常的话，输入 id 搜索用户会显示出来你的名片（见下图）。

![](img/4603895443250d60d39e905931f1acd2.png)

而且正常的账号，点击输入框下端的“全部”，会显示你账号发的一些笔记。

![](img/cedd96bbdc999cc8385c9ede5a6f4b21.png)

如果搜索不到，说明账号就是异常的。

那如果你怀疑是单篇笔记限流，就输入这篇笔记的标题去搜索，尽量复制整个标题，搜得更准确。

一般笔记状态正常的话，都能被搜索到。

有的时候还需要加一些条件才能找到，比如我们的这篇笔记《博主救星！发现了用 chatGPT 赚钱的秘密》。

搜索标题后没有显示笔记，但是点击搜索框下端的“全部”按钮，选择“最热”，笔记就出来了。你也可以分别切换一下“最热”或“最新”试试。

![](img/83c64e38098b6fff7c2006d0fa8f39c7.png)

注意：最好不要用被测账号去搜索，用你的小号或其它账号去搜。因为有时候你自己能看到，不代表别人也能看到，“他人”视角观察出来的结果更准确。

如果笔记搜索不到，就是俗话说的“笔记掉收录”了。

掉收录会直接影响笔记的搜索流量，但笔记掉收录不一定是笔记违规造成的，下面这些情况都有可能：

+   账号违规，被关小黑屋，导致所有笔记搜不到；

+   内容质量差，平台认为不适合展示出来；

+   发布时间太久；

+   笔记还在审核；

+   非原创内容；

+   标题和全文没有关键词；

+   关键词过多、刻意堆叠；

+   ....

#### 4.4.2.4 观众来源分析

我们通过账号/笔记的数据分析也能大致了解限流情况。

方法是：主页左上角三条杠，点击创作中心，进入"近七日数据"，就可以查看到自己的数据中心。

![](img/990c273b5e5f3f2b0bc102b5d49fd93d.png)

数据中心有三个页面，分别是“账号概览”、“笔记分析”和“粉丝数据”。

![](img/45afc1ae2ddf981b6ce0702d6b94c127.png)

在“账号概览”或者“笔记分析”页面往下拉，你会看到有个“观众来源分析”。

![](img/ed654a2626f39f666454401666cd701d.png)

观众来源分为以下几种：

+   首页推荐：从小红书主页推荐中进来的用户比例。

+   关注页面：从关注列表中点击进入的用户比例。

+   个人主页：直接通过你的个人主页进来的用户比例。

+   搜索：用户通过搜索关键词进入你的笔记或主页。

+   其他来源：通过转发或搜索，从其他渠道进来的用户。

如果账号或笔记没有问题，那么首页推荐和搜索的比例通常会比较高，首页推荐的比例越大，说明曝光量越大，你的笔记被平台推荐。搜索比例高，说明搜索流量大，账户或笔记能被正常搜索到。

但是如果账号/笔记出现异常，这些比例就会失常，比如下图这样：

![](img/69e0bd238bd9dac4e768859aa99c03f5.png)

上面这份数据中，搜索来源比例很少，而“首页推荐”直接消失了，大部分用户都来自粉丝的关注页面。

如果出现这样的数据，账号大概率被限流了，你的笔记/账号没有被系统推荐，点进来的只有你的粉丝。

所以，首页推荐和搜索流量是两个比较重要的衡量指标。

#### 4.4.2.5 笔记\账号申诉

还是在创作中心，选择页面下方的“帮助与客服”，点进去后可以看到“笔记申诉”和“账号申诉”。

![](img/d99ddc2be0a9bd6cf79f158125d63af0.png)

我们点开“账号申诉”，在昵称下方可以看到有一行“当前状态”显示，如果账号异常，就会有“违规 ”字样。

![](img/6fa6c158d4ed7692a6beb902f8c2a0d0.png)

但是这一步只能看到账号有没有异常，不能看到具体什么地方违规，如果想要了解更详细的情况，就需要选择下方相应的问题去申诉。

#### 4.4.2.6 薯条检测

薯条是小红书的一个推广工具，通常被用来给内容加热，增加笔记流量。

我们每发布一篇笔记，都需要经过一次审核，如果用薯条来推广笔记，那还要再审核一次，而且比普通笔记要求更严格。

比如有的时候，你的笔记本来流量还行，但是投放了薯条后，触发了人工审核，发现你笔记里有软广或者导流行为，就会反而把流量给你掐断了。

所以，第六种方式不是让大家真的去投放薯条，而是小利用一下投放前的页面。

具体方法是，打开你想检测的笔记，点击右上角三个点，在弹出的功能栏中，选择”薯条推广“，然后选择顶部的”内容加热“。

![](img/d8ae3a2e0e9d607ddd3acab2b7111f7b.png)

如果你的笔记违规限流，那么第三条“无社区违规行为”这里，很可能就会显示“未达到”，有时候还会直接告诉你具体的原因。

但是需要说明一下，这个方法只适用于个人账号，企业号没有“内容加热”这个页面。

### 4.4.3 限流后怎么办

#### 4.4.3.1 笔记限流怎么办

如果你知道笔记哪里违规，就修改一下笔记，会重新进入审核。如果不知道哪里有问题，那不要轻易修改，直接删除就好了，因为改的不对容易触发二次违规。

#### 4.4.3.2 账号违规怎么办

不管是哪种形式的违规，处理的原则其实都差不多，就是找到违规原因，并立即停止违规行为。

比如，你因为导流或者软广违规了，那正确的做法就是暂时不要引流和接广了，老老实实发点正常的笔记，养养号。

只要违规不是特别严重，一般 7 天左右就可以恢复。

#### 4.4.3.4 违规会累计吗

违规惩罚是会累积的，比如禁言，你第一次违规，可能给你禁言两天，第二次再犯，可能就要禁言七天，还继续犯就一个月，禁言多了可能会被封号。

#### 4.4.3.5 为什么要一机一号

这点其实很好理解，站在平台的角度看，普通的小红书用户基本不会注册多个账号来玩，除非你有营销需求。

所以，尽量一机一卡一户，不要再同一个手机上来回切换多个账号，很容易被识别为营销号。

这是我们团队和学员总结出来的经验，我天天提醒大家要注意这点，但还是有很多人偷懒，或者是存在侥幸心理，在同一个手机上注册多个账号，或者来回切换账号。

一旦被系统识别，或者一旦其中的某个账号被封，整个设备都会被封禁不能使用，其它账号也会被牵连，因为你用这个设备去登其他账号，很快也会被封。

![](img/d9c23656213ad0084954c1493a06ccf8.png)

所以，这一点大家一定要注意，尤其是做矩阵号的朋友。

## 7.1 小红书店铺分类

### 7.1.1 个人型

个人专业号，身份标识为XX博主，比如时尚博主、美食博主等兴趣类的博主，基本上只要申请就能通过，而且不需要任何费用。

![](img/e58d64489cea3a64fc37b182877cdbc6.png)

但有些特殊的职业身份，比如医生、律师等，需要上传资质认证，还要缴纳300元费用：

![](img/dd550e7d649ce3531a56a2a2e647db8b.png)

个人型专业号，可以申请开个人店铺或个体工商店。

> 名称为XXX（昵称）的店；

> 店铺保证金最低1000元；

> 月营业额＜1万，平台免收技术服务费；

> 超过1万的部分，平台收取5%作为技术服务费。

### 7.1.2 企业型

申请企业型专业号，需要上传营业执照，并缴纳600元费用，身份标识为XX品牌。

申请流程为：

> 点击【创作中心】—【更多服务】—【开通专业号】—【我是企业】-【填写基础信息】-【填写主体信息】-【资质公函上传】-【运营人信息填写】- 缴纳600元费用，等待审核。

填写注意事项见下图：

![](img/34a1fa1171109f806bfa00b934cd4e55.png)

申请之后，大家要多加留意，因为申请有效期为30天，如果30天内没有完成申请，费用是不退回的。申请通过后，每年都会年审，并续费600元。

企业专业号，可以开普通企业店和专卖店/旗舰店。

> 名称为XXX专卖店/旗舰店；

> 店铺保证金境内最低2万，境外3500美金；

> 月营业额＜1万，平台免收技术服务费；

> 超过1万的部分，平台收取5%作为技术服务费。

一个营业执照可以申请最多3个专业号、3家店铺。

同一品牌只能开一家旗舰店，但可以同时开不同类型的店铺，比如一家旗舰店，一家专卖店，一家普通企业店。

企业专业号的营销权益，会比个人专业号更多一些，但两者只能二选一，大家可以根据需要自行选择。

## 7.2 店铺入驻门槛

虽然小红书对开店粉丝没有要求，但对不同的店铺类型有不同的要求，并不是什么店铺都可以开的。

### 7.2.1 个人型

个人型店铺分为个人店和个体工商户店。

个人店仅支持服装、百货等常见类目，个体工商店铺除了可以开常见类目，还支持奢侈品、珠宝等类目。

![](img/0c365d7ccdd4cfe81c9946d62b126031.png)

每个店铺类型，对应的可经营类目不同，打勾部分就是可以经营的类目，具体可在小红书学习中心-规则中心-经营总览中查阅：

![](img/cfe383e267569930b7474270ce1c571f.png)

开店还要缴纳保证金，个人店和个体工商户的保证金都是1000元，但是有些特殊类目，比如保健品、奢侈品类，保证金会贵一点。

![](img/390fd2cf621536b5fcc71319e293a090.png)

客服接待角色，个人店铺可选择平台代运营和自主客服两种模式，要注意平台代运营是需要收费的，大家可根据自身情况进行选择。

平台佣金，又叫技术服务费，是以月销售额1w为界限，1w以下不收费，超过部分按5%收取：

![](img/99b69217f2a86dd1a4a31518e8e35684.png)

目前小红书为了减轻个人店和个体工商户的开店负担，店铺入驻后无需缴纳保证金，即可发布商品上架售卖。如果该店铺累计交易额超过1万元后，下个月月初才需要补缴保证金，真正实现“无门槛”开店。

### 7.2.2 企业型

企业型店铺，分为普通企业店、旗舰店、专卖店以及集合店。

普通企业店铺与个人店铺命名格式是一样的，“专业号账号名称+的店”。需要注意的是，企业专业号取名时要和商标对应，要不然会导致开不了店铺。

旗舰店名称是xxx(品牌名)旗舰店，专卖店是xxx专卖店，集合店铺是xxx的海外店。

企业型店铺支持经营大部分类目，包括保健品、医药等特殊类目。

平台佣金，和上面的个人店铺一样，1w以下不收费，超过部分按5%收取。

保证金根据类目不同，金额也是会略有差异，一般境内最低2万，境外3500美金。

如果你不知道如何选择，可以通过下面这张图快速判断：

![](img/dd7608646d71fde2135cf555e1359c2f.png)

## 7.3 店铺入驻流程

无论是哪一种店铺，都是进入【创作中心】，找到【更多服务】，选择【开通店铺】，然后进入【选择店铺类型】：

![](img/76d95d2c48d1fdcc5d811653da193026.png)

店铺类型不同，需要提交的资料也不一样，大体上见下图：

![](img/a1bc7bd9124d3f0f25df2af0015d16c5.png)

![](img/08ea337fc3685bfe36995d6281e45529.png)

### 7.3.1 个人型

选择个人店铺后，需要选择经营类目，之后只需要提供姓名、身份证号、手机号，并进行人脸识别，验证成功后店铺就开通了。

![](img/a93189d180c43f1ecc72b645abe3ed29.png)

个体工商户店铺，需要提前准备好以下几点：

（1）公司信息的营业执照照片、公司名称、统一社会信用代码、经营地址以及营业执照有效期；

（2）店铺运营授权书。

同样也是先选择店铺经营类目，然后根据提示上传相关的资料。

![](img/1a510afdfe9681f2ec633b2bdb4d5dc3.png)

和个人店铺不同的是，个体工商户店的审核时间一般为两到三天。

**期**间可以自行登录入驻系统进行查询。若在入驻过程中有任何问题无法解决，都可以在9点到24点期间直接联系人工客服进行咨询。

![](img/129149301ad90e5e5355d11aecf903ce.png)

### 7.3.2 企业型

企业型店铺需要准备的材料比较多，建议在电脑端小红书入驻系统操作，网址为：gaia.xiaohongshu.com

我们先来说普通企业店的入驻流程，登陆后，大致需要6步。

第一步，首先选择店铺类型为：普通企业店。

![](img/8666fd27183d1aadc8803eafbfc23313.png)

第二步，填写公司信息，上传营业执照，营业执照要拍得清晰、完整，避免扫描错误。

![](img/22f2fced5945472c6ac644e892090d43.png)

然后，填写法人或店铺运营人信息，注意，联系人要与营业执照上的法人一致。

![](img/154c7fe3b8512eff843f2e46e9051f73.png)

第三步，店铺名称填写，但这个是系统自动抓取的。店铺命名形式就是“昵称+的店”，所以直接跟你的昵称挂钩，需要修改的话得去专业号中心修改昵称。

![](img/4f47ed3cf1b40475c782cedc13252288.png)

第四步，选择经营类目，注意类目必须在商标注册证上的类目范围内。

![](img/8fdbb2537e3095c6526442a47ab67cb5.png)

第五步，就是等待审核，一般审核时间为3个工作日内，审核失败会有电话或邮件告知，期间有任何问题也可以联系在线客服咨询。

审核通过后，最后一步就是缴纳店铺保证金了，注意开卡账户是对公账户，而且开户人需与入驻时填写的经营人姓名一致。

![](img/557f21e1411428e17462e3da8219b9cc.png)

其次，我们再来说旗舰店和专卖店的申请步骤，大体上和普通企业店差不多，需要注意四点：

一是填写品牌相关信息。

如果系统内没有你的品牌名称，就点击“新增品牌”添加，注意上传logo图片时，要与商标注册证上的完全一致。

![](img/3c1219169533e09048b7fc18ba81f6e2.png)

![](img/0732a1421f28a8df092af70dcb5bbb9b.png)

二是要区分自有品牌和代理品牌。

如果是代理品牌，要确保有完整的授权链路，公司名称选择营业执照上的名称即可。

![](img/1dc9b41b09707cfcb2ae92703711780a.png)

如果是自有品牌，就是说，商标持有者是自己公司或公司法人，注册类型可分为R标和TM标两种，R标就是注册商标，TM标就是商标这册申请受理通知书。

![](img/8d266bc56fcfbaeaa69e53691ce6baaa.png)

其中，如果你的商标注册类型为个人型R标，就需要上传商标注册证，以及商标权利人的身份证或护照复印件/扫描件。

![](img/5f6ca064638eaa9ac5cf9b706cdd8ad6.png)

同样，如果是个人型的TM标，需要上传商标注册申请受理通知书，以及权利人的身份证或护照复印件/扫描件。

![](img/062e7cb8176bb9382e656f0b65d8a5d0.png)

而如果你申请的是企业型的R标或TM标，就只需要商标注册证或商标受理通知书就可以了。

三是选择售卖品类时，注意谨慎选择“定制”品类。

![](img/86c65c6331f977903981991b23aa636d.png)

四是审核通过后，还需要签署合同，合同会以线上邮件形式，通过电话或验证码确认签署。

![](img/28d2e376d8cdf83b4b1441c6241d65d9.png)

接下来也是缴纳保证金，注意事项同上面的普通企业型店铺。

最后再来说集合店，集合店只有平台邀约才能够入驻。收到邀约后，入驻流程跟旗舰店和专卖店步骤相同。

全部申请通过之后，就可以上传商品开店啦，在你的账号首页可以直接显示店铺和商品入口。

![](img/952fa762e10905bf00c3984f1d59f177.png)

总的来说，企业型店铺的商业权益会比个人店铺更多一些，但维护费用也更高，大家可以根据自身情况选择。

另外关于入驻类目、审核等不懂的地方，建议大家第一时间联系“人工服务”进行咨询，商家客服回复的都比较及时，能够快速解决大家问题。
