8月快要结束了，今天的标题其实是我让AI帮我从之前15天的笔记中挑选出来的。今天也算是来点个题，《时间就是筹码》，这个概念实在是太棒了，因为它把抽象的时间概念和时间消耗，立体地表示为筹码。一切都变得具象化了。之前在看时间管理类型的书籍和资料时，也提到过应该把时间记录下来，然后每几分钟或者十分钟为一个颗粒。越精细的记录，对于自己的时间管理就越高效。

在少楠的书《笔记的方法》中，这个概念变得更加具体了。在此后的时间思考中，我也知道如何去分配时间，并且能够有更清晰的认识。明确了时间筹码后，可以根据价值观将时间投资在重要事项上，以获得具体的回报。

# 20240827

问题只会出在过程中，虽然可能一样能达到结果，但是如果不能监控过程，只关注结果，最终可能会有很多潜在的风险。只关注答案，就像我们小时候考试一样，什么问题都有标准的答案，不断刷题，只要记住答案，记住更多的答案，就能考一个好成绩。

最近看李善友讲欧式几何，逻辑链啊什么的，对过程有了更深一层的认识。他讲了一个例子，女儿在美国念书，女儿说老师太笨了，说自己一下子就能看出答案了，直接写答案就好了，但是老师却要求写过程。

之前看《原则》中也说到过，应该是管理过程，而不是结果。有因才有果，如果一个管理者只关心结果，那就不是一个合格的管理者。只有深入了解过程，了解导致结果的因，才能知道问题在哪里，如何去调整。作为一个管理者的话，应该更多地帮助员工去调整好过程，这样自然会有好的结果。

我也越来越注重逻辑链了，不是突然冒出一个答案，而是整个思考过程是否严丝合缝，通过科学的严谨的过程最终得出的方案。这样哪怕是失败的，起码会知道失败在哪里，如果成功了也能知道成功在哪里。而不是突然冒出一个方案，虽然这样看起来很聪明，但是无法复制和持续。

有一句话总结得很好，“假如我们不知道自己为什么成功，这样的成功无法复制；假如我们不知道自己为什么失败，这样的失败毫无意义。”这句话很好地概括了过程和结果的关系，值得我们深思。

# 20240823

信息密度越高的内容越容易受欢迎的感觉，无论是文章、书籍、短视频、中视频、电影、图文……信息密度越高越容易被收藏和关注。

可能是因为信息密度高，有足够的深度，让人意味深长。例如，一篇深入探讨人工智能技术的长文，不仅能吸引技术爱好者，还能吸引那些对未来科技感兴趣的读者。或者是信息量大，一下子无法吸收完，所以大家更倾向于收藏，以便日后反复阅读或观看。比如，一个包含丰富实用技巧的烹饪视频，观众可能需要多次观看才能掌握所有技巧，从而增加了收藏的可能性。

信息密度高的内容也有足够的广度，可以覆盖到更多的人群。一篇关于健康生活方式的文章，如果涵盖了饮食、运动、心理健康等多个方面，就能吸引到不同兴趣点的读者。

所以，以后在写文章或者制作内容时，如果想要覆盖更多精准人群，让内容进入流量池中，可能需要创作一些更加全面且信息密度高的内容。这样不仅能够提高内容的收藏和分享率，还能增加受众的粘性和忠诚度。

# 20240813

我觉得要多考虑现有资源的最大化利用，而不是考虑没有的资源。这样容易陷入眼高手低的情况..

记得以前看过一个例子，就是编剧的剧本如果都写大爆炸，飞机爆炸，大场面..那导演和制片人就会很难办了，很多都不现实。所以编剧应该考虑如何删掉不必要的片段和场景，节省成本，让最终的作品也能够很好的呈现。

创业也是如此，考虑手上和能够接触到的资源，最大化的整合和利用。总是想着没有的资源，就会陷入想象中，而不是接下来具体能够干些什么，导致项目无法推进。一种是接下来能够干什么，一种是要是有什么什么资源就好了...

这些小思考，也不确定对不对，这是接触那么多人和项目的感悟。有的时候也会在想，如果一个人总是想着没有的资源，就会主动去拓展和获取一些资源。

编程真的得学一学，无论是对思维的改变，还是日常办公或者生活中提升效率都会很大的变化。RPA、Python、JSON 等等等等。。数据分析、自动化任务..

原来只需要找到数据源，转换成 json 对象，然后安装好 pandas 库，把 json 中的数据转换成需要的列表形式，再写入数据表格或者 excel 文件中就好了..

一个技能的学会和不会之间简直就是两个世界。编程对于思维的改变，后面有机会也展开说一说，真的是太有意思了。每个人天赋不同，喜好不同，其实不需要学的特别深，只需要先知道有这个东西，有这个概念，可以做到什么，就会对于决策一些事情有很大的不同了。
