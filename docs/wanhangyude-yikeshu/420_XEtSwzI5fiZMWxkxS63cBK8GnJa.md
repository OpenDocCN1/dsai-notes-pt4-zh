# 6月-再见，大润发！

17年5月份入职，进入大润发系统学习. ..刚好是一年了，这一年付出了很多，也学到了很多的东西~ 最终还是选择离开，但是想给这一年留下点什么.. .就写点东西吧..也许以后会怀念这段时光...

进入系统是先在淮阴店学习，后来又是到邗江店职代。进入大润发才知道，大润发系统是多么的细致和庞大。很多细小的细节是以前从未注意到的，觉得无关紧要的,现在却是一丝不苟。

我们店是新店，开店的准备工作我一直都记得的，印象比较深刻。

货架层板那些东西都是我们自己搭的，刚开始的时候经理是让我先帮日用一起搭货架，我们从收货区把层板挂钩的那些配件用液压车一版一版的拉到上面。后来日用的整体已经差不多快好了，我就回自己课开始搭了。那个时候大家都还在自己课忙着，有的在收尾，有的也快完成了。我那边却才刚开始，我一个人在那边找配件，特别的着急。

经理喊我们去吃西瓜，同事见我没去，又过来喊我，我在那边一个人还在搭着货架，同事就劝我不要着急，等他们好了，就会来帮我的。但是我还是很着急。说不想吃，之后我一个人在那边边哭边搭货架。现在想起还是挺逗的....

![](img/db7e2bf255a53e1d57c0ac23b72a6d8f.png)

时光荏苒，岁月如梭

这一年来真的是付出了很多，但是也学到了很多的东西。非常感谢同事们还有张经理他们的帮助，我是部门里年纪最小的，阅历不深，情商不高。管理岗真的是很磨练人，导购什么的也都是自己想办法招，开店的时候一直没有招到人，特别着急，到处去想办法招人最后招到了两个18岁的小姑娘，人资还有同事都说她们做不了多久的，我也知道，但是好在最后还是熬过了开店。感谢剩下的课内成员，陪我坚持下了这过去的一年。

![](img/1f3ef21362ac37c13ad0e59b9166878b.png)

这些其实都算是好的了，换挡和检查的时候才是最折腾人的，记得第一次SOP检查的时候是特别突然的，突然说到我们店了，然后我们就上了一个通宵，早上的时候课员都下班了，但是我还得跟着SOP检查的人一起检查，那次.我连续上了三十多个小时.

![](img/7207b3992dcf5341c6291dd5d852b5b6.png)

换挡是十四天一次，就是把促销商品的价格还有促销桶以及区域的商品全部都换上一遍，每次都是提前准备，加上有的时候一些季节性的东西，所以每次换挡都是一次挑战，刚开始的时候因为课员导购都是新的，都不太懂，所以我只有全程的跟着，换挡换到凌晨三点多钟，早上六点早班又开始了，索性直接睡在了后仓...后来都熟悉了之后，换挡什么的也快了很多.

不开心的事情有很多，但是也没有什么好说的了，既然最后选择离开，离开了就忘记了吧，记得开心的事情，迎接新的开始。

一年过去了，突然觉得自己厌倦了这样的生活，不知道从什么时候开始，每天除了工作就是工作，下班的时候已然深夜，醒来的时候已是中午。每天都很累，没有心情看书弹琴，没有时间静下来思考。每天就是大大小小不断的琐事，所缠绕着。

我最后还是选择了离开，在扬州已经待了十年了，是时候出去看看外面的世界了。人生短暂，如果终将被现实招安，何不抓紧再放任几年... ..

# 7月-出发，川藏线！

很久之前就有徒步旅行的想法了，但是因为没有时间没有钱也没有同行的人，所以想法一直被搁置，没有付诸行动。偶然看到一句话 不是有了同行者才上路，而是因为在路上才会有同行者！ 深受感触，这22年来一直是一个安分守己的人，很少和外界接触，是时候出去走走了，一个人。一人一书一背包，两千公里修行路。最后因为高反，止步于稻城。

**多图预警**，事情已经过去差不多**三四个月**了，有的我也**记不太清楚**了，哈哈。大家可以看看照片，感受一下这条路上，所见所闻。我也重新在回忆一下，此前的经历。
