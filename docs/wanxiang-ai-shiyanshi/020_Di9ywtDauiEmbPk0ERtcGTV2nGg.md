# 前言

社区是志同道合的人们聚集的地方，在这里大家可以分享信息、交流想法、建立信任和互相帮助。但为了维护一个健康的社区环境，以及长期的运营机制，我们需要制定一些管理制度，以便大家能够有一定的行为标准和准则。本规则适用于所有社区用户在社区内的所有行为，包括但不限于发布内容、参与话题讨论、分享经验、私信交流、报名活动等。同时本规则将根据国家法律法规、平台规则、社区发展需求进行适时调整。

# 一、社区基本规则

1️⃣ 遵守平台规定：不做违法、违规、影响他人身心的事情。

2️⃣  维护社区秩序：不发布与社区主题无关的内容、广告等，聚集主题，传播正能量。

3️⃣ 保持友好态度：积极参与讨论，分享个人经验和知识，帮助更多人成长和避坑。

# 二、社区运营架构

1️⃣ 社区管理员：负责日常管理，监督违规行为，维护秩序，推广社区。

2️⃣ 社区志愿者：协助管理员，提供支持，组织活动。

3️⃣ 社区成员：参与讨论，交流相关经验。

# 三、社区常见活动

1️⃣ 线上讨论：围绕设定主题组织讨论，促进社区成员交流。

2️⃣ 专题分享：邀请专业人士或成员分享经验、知识或故事。

3️⃣ 线下活动：组织发起与社区相关的活动，增强社区凝聚力。

# 四、社区发展宣传

1️⃣ 宣传内容：宣传主题、活动、优秀成员，吸引更多人加入。

2️⃣ 宣传渠道：利用社交媒体、论坛、博客等渠道提高知名度。

3️⃣ 宣传频率：合理安排宣传频率，避免过度宣传。

# 五、社区行为红线

| ### **黑线行为类别** | ### **核心行为表现** | ### **处理方法** |
| --- | --- | --- |
| 恶意营销/广告刷屏 | 反复发无关广告、链接等 | 1. 秒撤回广告内容，屏蔽链接； |
| 发布违法违规 / 不良内容 | 发色情、暴力、政治内容，传播不良价值观，散布无关的谣言 | 1. 立即删内容、永久封账号并拉黑； |
| 知识侵权与抄袭 | 盗用社区内容，未授权转载内容，抹除作者信息 | 1. 核实后删侵权内容，要求公开致歉； |
| 恶意诋毁与冲突挑动 | 诋毁社区管理人员，嘲讽意见不同的社区成员，挑起 “价值观对立”“性别歧视”“地狱歧视”等等 | 1. 删除冲突内容，私聊警告挑事者； |
| 非法引流与违规导流 | 私发 “非官方群” 二维码，引导用户至外部平台交流 | 1. 撤回引流内容； |
| 干扰正常交流秩序 | 刷屏 “无关表情包” 打断讨论或者带来社群成员不好体验，恶意 “蹲分享” 不贡献 | 1. 删除错误内容 / 无关信息，私聊警告； |

# 六、社区倡导行为

| ### 倡导行为类别 | ### 核心行为表现 |
| --- | --- |
| 优质知识分享 | 1. 原创或规范转载干货内容、课件、学习方法（标注来源 / 作者）； |
| 友善交流互动 | 1. 提问时清晰描述问题，避免模糊表述； |
| 尊重知识产权 | 1. 转载他人原创内容时，提前征得作者同意并标注出处； |
| 互助成长共进 | 1. 主动帮助学习进度慢的成员（如分享社会化生存能力、职场有效涨薪技巧）； |
| 规范参与行 | 1. 遵守社群发言规则，不刷屏、不发无关表情包； |
