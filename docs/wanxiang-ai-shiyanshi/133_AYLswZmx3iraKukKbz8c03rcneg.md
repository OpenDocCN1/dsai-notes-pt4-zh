> 即梦 Agent 接入了业界领先的多模态大模型，不仅能听懂你的创意，更能看到你输入的图片，你可以更自由的输入自己创作想法，AGENT 会帮助你完成任务，你可以：

> 1、表达你的想法，让 AGENT 帮你写出提示词或直接生图，生视频

> 2、传图并让 AGENT 反推提示词或添加一个灵感作为参考图，进行二创

> 3、不断的和 AGENT 对话，完善你的创意，直到满意

> 4、输入一个想法，让 AGENT 一次生成 40 张创意图片或帮你完成一组创意海报、表情包、视频、绘本的设计

> 更多的探索空间就留给你啦，快去试试吧～
