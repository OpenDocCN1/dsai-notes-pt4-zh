# 动画微短剧（漫剧）内容创作建议

> 来源：[https://yunyinghui.feishu.cn/docx/ZVdTdZuRqohP99xZj5Jcw9eXnFe](https://yunyinghui.feishu.cn/docx/ZVdTdZuRqohP99xZj5Jcw9eXnFe)

致漫剧内容合作伙伴：

平台致力于营造清朗的网络内容环境，维护良好的行业秩序，鼓励优质内容创作，促进微短剧行业健康发展。为此构建了完善的内容审核机制，持续治理违规有害的微短剧内容。针对漫剧内容创作，平台提出以下原则性要求：

1.  全剧的立意导向，包括主线剧情、核心情节、人物塑造、结局走向不可脱离正向叙事，需要传递向善、良好的价值观，杜绝以低俗恶俗媚俗为内核，传递错误价值理念。

1.  作品不能宣扬性展现违背法律要求、伦理道德、公序良俗或不符合社会主流价值观的情节桥段、镜头画面、台词语言。

**具体****内容安全、质量要求包括但不限于如下内容，请在漫剧内容创作过程中主动规**避，自查自纠。平台将会持续收集行业和用户反馈，不断完善和优化各方面标准。我们愿与所有合作伙伴一道，共同守护微短剧行业的健康生态。

# **内容安全要求及建议**

# 一、内容题材合规及分级备案要求

平台落实广电总局对微短剧内容的“分类分层审核”制度要求，结合内容预期、成本等严格核验备案信息。如符合【重点微短剧】、【普通微短剧】要求，应上传有《网络剧片发行许可证》或“备案号”的视频内容并填写对应备案号信息；如符合【其他微短剧】要求，平台会结合审核结论进行备案。

**分类分层审核制度及备案号获取主要要求如**下，相关政策以广电总局发布的最新信息为准

+   重点微短剧：符合特殊题材或总投资额度达到300万元及以上的微短剧为“重点微短剧”，由广电总局统一备案公示管理和成片审查，需登录“重点网络影视剧信息备案系统”进行申报。

+   特殊题材：主要剧情涉及政治、军事、外交、国家安全、统战、民族、宗教、司法、公安等内容

+   普通微短剧：总投资额度在100万元(含)至300万元之间，且为一般题材的微短剧为“普通微短剧”，应报省级以上广电主管部门进行规划备案和成片审查。

+   其他微短剧：总投资额度不足100万元且为一般题材的微短剧，由播出或为其引流、推送的网络视听平台履行内容管理的职责，负责内容审核把关与版权核定，定期将审核剧目信息报属地省级广电主管部门备案。

# 二、禁止宣扬不良价值观

+   剧中出现的情节和内容，需要服务于漫剧本身剧情的合理逻辑，适用于人物的合理设定、动因。要避免出现宣扬不良、消极颓废的人生观、世界观和价值观的内容。

+   具体情节方面，包括但不限于如下要求：

## 禁止持续/极端侮辱他人

| **场景** | **定义** | **创作建议** |
| --- | --- | --- |
| 非人化和亵渎性羞辱 | 使用非人化的手段，极端亵渎受害者尊严，突破道德底线 | 需严格避免： |
| 显著使用脏话 | 角色在单个情节桥段中，显著或密集使用脏话 | 严格避免 |
| 肢体羞辱 | 使用持续性或重复性的肢体动作，对他人进行压制性羞辱 | 避免在全剧中过多展现： |
| 持续言语羞辱他人 | 持续使用非脏话、但饱含攻击性的词汇或用语，对他人进行羞辱 | 避免在全剧中过多展现： |

## 禁止宣扬/放大社会阴暗

| **场景** | **定义** | **创作建议** |
| --- | --- | --- |
| 群体妖魔化 | 以单一负面形象刻画社会群体 | 严格避免 |
| 极端家庭暴力冲突 | 家庭成员间实施极端的人身侵害，严重背离时代背景 | 严格避免 |
| 违背家庭人伦亲情 | 家庭成员间罔顾人伦亲情，互相实施攻讦、背叛、侮辱、暴力等行为，过度放大社会负面 | 避免在全剧中过多展现 |

## 禁止过度呈现/宣扬错误伦理观

| **场景** | **定义** | **创作建议** |
| --- | --- | --- |
| 宣扬封建婚恋观 | 现代场景下，宣扬封建落后、违反现代婚姻观念乃至法律的一对多婚恋关系 | 严格避免 |
| 婚恋对象违反伦理 | 婚恋对象的关系违背所处时代的社会伦理道德或法律 | 严格避免 |
| 宣扬封建阶级文化 | 宣扬封建帝制、权力崇拜等封建社会陋习 | 避免在全剧中过多展现： |
| 非正当亲缘称呼 | 故事人物明确无血缘、姻亲关系，但通过称呼上关联伦理关系，蹭乱伦设定的相关内容 | 避免在全剧中过多展现： |
| 宣扬出轨偷情 | 称赞宣扬婚外情或偷情行为、过度设置婚外情或偷情桥段 | 严格避免： |

## 禁止过度呈现/宣扬错误金钱观

| **场景** | **定义** | **创作建议** |
| --- | --- | --- |
| 宣扬不择手段获取财富 | 使用非法或不道德手段获取金钱、利益、物质等财富，且未对此行为进行批判 | 严格避免 |
| 放大贫富阶级矛盾 | 使用极端化情节制造贫富群体矛盾或阶级对立、博眼球刻画穷人的极端仇富心理，严重脱离现实 | 严格避免 |
| 夸大财富作用 | 过度宣扬金钱对人物生命、命运、社会人际关系的决定性作用 | 避免在全剧中过多展现： |
| 财富设定夸张离奇 | 使用经济逻辑严重脱离现实的财富设定，夸张化物质的价值或角色的财富实力 | 避免在全剧中过多展现： |
| 性别物化 | 将角色的个人价值窄化为依赖性的依附价值、否定角色人格 | 避免在全剧中过多展现： |

## 禁止宣扬暴力仇恨

| **场景** | **定义** | **创作建议** |
| --- | --- | --- |
| 宣扬极端复仇 | 刻意美化极端暴力复仇手段，淡化其危害性，诱导观众形成对此种手段的认同 | 严格避免 |
| 宣扬教唆犯罪 | 现代非架空场景下，人物宣扬号召或美化严重犯罪行为 | 严格避免 |
| 过度冷漠报复 | 角色因琐事对他人采取极端报复或冷漠行为，违背社会基本伦理原则，缺乏基本的同情心、同理心 | 避免在全剧中过多展现： |

# 三、禁止宣扬封建迷信

+   封建迷信指的是在长期封建制度下形成的对超自然力量盲目信仰、崇拜和由此产生的迷信活动。作品的核心应该是破除迷信，提倡科学精神，禁止传播迷信思想和迷信观念。

+   具体情节方面，包括但不限于如下要求：

## 禁止过度呈现/宣扬迷信糟粕

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 宣扬封建邪祟文化 | 通过传播迷信、封建愚昧糟粕内容传达出恐怖、惊悚氛围，与现代价值观相悖 | 严格避免： |

## 禁止过度呈现/宣扬法术玄学

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 现代法术逆天改命 | 在现代科学场景下，宣扬利用法术改变命理、命格、命运乃至生死等行为，使观众陷入可以通过改变命运的荒诞意淫幻想 | 严格避免： |
| 宣扬法术作恶 | 借助法术展现不可能完成的效果或以私欲为主要目的，为非作歹 | 严格避免： |
| 现代玄幻荒诞离奇 | 在现代科学场景下，展现突破常规世界观的过度离奇玄幻设定 | 避免在全剧中过多展现： |

# 四、 禁止呈现画风观感不适

+   在情节刻画、美术风格、角色形象、镜头语言等视觉展现的过程中，需严格避免过度血腥、恐怖、惊悚、恶心的场景，避免给受众造成强烈生理 / 心理不适，诱发受众恐惧、焦虑情绪，避免诱发模仿行为。

+   具体情节方面，包括但不限于如下要求：

## 禁止过度呈现血腥暴力

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 极端血腥引人不适 | 直接呈现强烈视觉冲击的血腥场景，引发观众生理性反胃、恐惧等严重不适感 | 严格避免： |
| 身体伤害引人不适 | 无直观肢体损伤画面，但刻意营造肉体受虐的压迫氛围，诱发观众不适情绪 | 避免在全剧中过多展现： |

## 规避展示/描述恶心行径

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 恶心行径细节展示 | 刻意展示恶俗情节，引发观者生理反胃、心理抵触、生理不适的画面 | 严格避免： |

## 规避呈现恶劣观感画面

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 无底线猎奇/审丑 | 无底线猎奇博眼球的内容，挑战大众认知，极易引起舆论反感/负面讨论的夸张内容 | 严格避免： |
| 恐怖/灵异惊悚画风 | 镜头画风色调阴暗、深沉，整体氛围压抑、阴森，刻意渲染惊悚恐怖 | 避免在全剧中过多展现： |

# 五、禁止呈现低俗色情内容

+   低俗色情是对淫秽、色情、庸俗、低级趣味类内容的统称，严格避免在创作过程中，以性为卖点、突破公序良俗、侵害未成年人、违背主流价值观的视听语言、情节画面呈现。

+   具体情节方面，包括但不限于如下要求：

## 禁止过度呈现挑逗性相关画面/情节

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 暴露着装 | 着装过分暴露、低俗服饰并配合挑逗性肢体动作 | 严格避免： |
| 实施性行为 | 直接呈现性交动作、或通过动作、台词明确指向性行为过程 | 严格避免： |
| 低俗性言论 | 通过低俗关联物品或赤裸台词展现低俗色情内容 | 严格避免： |
| 低俗性演绎 | 使用情趣道具、结合镜头、动作、台词演绎低俗性情节 | 严格避免： |
| 低俗性诱导 | 通过低俗露骨言语、性低俗导向性画面的展示，引发性相关联想 | 避免在全剧中过多展现： |

## 禁止过度呈现性暴力情节

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 性暴力侵害 | 呈现持续性暴力动作、强烈肢体冲突、叠加性羞辱，产生性侵害行为 | 严格避免： |

# 六、禁止呈现其他不良导向问题

+   在作品创作过程中应严格避免危害国家统一、主权、领土完整与国家安全、泄露国家秘密、损害国家荣誉、煽动民族仇恨、破坏民族团结，宣扬历史虚无主义、歪曲革命历史与英雄形象等内容创作。

+   具体情节方面，包括但不限于如下要求：

| **场景** | **定义** | **创作建议** |
| --- | --- | --- |
| 历史虚无 | 以非客观、非科学态度否定或歪曲民族国家及政党历史，否定、篡改史实解构主流价值体系 | 严格避免 |
| 领土主权表述错误 | 以负面方式展现国家标志，将国家标志娱乐化或涉及主体展示他国/党派政治敏感元素 | 严格避免 |
| 蹭社会热点舆情 | 以社会热点或舆情事件为创作元素进行夸张化改 | 严格避免 |
| 恶搞现实公众人物 | 对现实的公众人物进行带有贬损性质的娱乐化演绎 | 严格避免 |
| 民族负面 | 涉及表达对民族、地域的明确或隐晦侮辱攻击/贬低歧视 | 需严格避免： |

# 七、禁止呈现未成年负面内容

+   作品应秉承以 “保护未成年人身心健康、维护敏感群体合法权益、防范歧视与伤害” 的核心创作原则。

+   具体情节方面，包括但不限于如下要求：

## 禁止过度呈现/表达未成年相关负面情节

| 场景 | 定义 | **创作建议** |
| --- | --- | --- |
| 未成年人主动错误行为 | 展示不符合未成年身份和形象的不当行为，阻碍其身心健康发展，违背了教育规范和社会期待 | 需严格避免： |
| 暴力欺凌未成年 | 展示演绎未成年被虐待、欺辱行为，可能致使未成年产生心理创伤，对其身体和心理造成不良影响和损害。 | 需严格避免： |
