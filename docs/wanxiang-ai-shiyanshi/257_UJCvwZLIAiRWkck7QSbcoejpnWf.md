## 三、征集要求

### （一）核心要求：真实、落地、可复制

1. **真实性：**案例必须是本人真实使用 OpenClaw 的经历，禁止虚构、抄袭、搬运，需提供可佐证的细节（如操作截图、执行结果、量化数据等），杜绝“纸上谈兵”；
2. **落地性：**玩法需已实际执行并产生效果，无需复杂操作，普通人可参照步骤复现，拒绝仅停留在概念、未落地的创意；
3. **价值性：**案例需具备实用价值，可解决具体问题（如提升效率、降低成本、简化流程、创造乐趣等），能为其他使用者提供借鉴和启发；
4. **独特性：**鼓励分享小众、新颖的玩法，避免重复常见的基础操作，优先收录有创意、有特色的落地场景。

### （二）案例内容规范

1. **案例标题：**简洁明了，概括玩法核心（例：用 OpenClaw 自动管理社交账号，实现 24 小时自动化运营；靠 OpenClaw 砍价，轻松省下购物成本）；
2. **应用场景：**明确玩法适用的场景（如工作办公、创业开发、日常生活、学习提升等），说明解决的具体痛点；
3. **操作步骤：**详细但不繁琐地描述 OpenClaw 的设置、指令发送、执行过程，确保他人可跟着操作复现；
4. **落地效果：**用具体数据或真实反馈说明效果（例：节省 80%的文档处理时间、每月稳定获得被动收入、成功逆转保险拒赔等），可附上截图、视频等佐证材料（可选）；
5. **使用心得（可选）：**分享使用过程中的注意事项、优化技巧，或自己的感悟，帮助他人避坑；
6. **个人信息：**昵称、🛰️联系方式（便于后续表彰和联系，可匿名提交）。

### （三）格式要求

1. **字数：**单篇案例字数不少于 500 字，内容详实、逻辑清晰，图文并茂，最好有视频演示，避免流水账；
2. **格式：**正文可分段排版，关键步骤可加粗，附上相关截图、视频（建议压缩后提交，避免过大）；
3. **合规性：**案例内容需符合法律法规及社区规则，不得包含敏感信息、恶意引导、违规操作，禁止泄露个人隐私及商业机密（可进行脱敏处理）。

## 七、审核标准与流程

### （一）审核标准

1. **合规性：**内容无违规、无抄袭、无敏感信息；
2. **落地性：**玩法真实可复现，有具体操作步骤和效果佐证；
3. **价值性：**具备实用价值和借鉴意义，避免无意义、重复的内容；
4. **完整性：**案例内容包含核心模块，逻辑清晰、内容详实。

### （二）审核流程

1. **投稿接收：**社区工作人员每日查看投稿，确认投稿信息完整后，登记备案；
2. **初步审核：**3 个工作日内，由社区运营团队完成初步审核，筛选出符合要求的案例，反馈审核结果；
3. **优质评选：**每周汇总审核通过的案例，由社区运营团队+AI 领域资深爱好者组成评审小组，评选优质案例和最佳创新案例；
4. **公示发布：**审核通过的案例将陆续在社区发布，优质案例置顶展示，征集进度实时公示，确保公平、公正、公开。
