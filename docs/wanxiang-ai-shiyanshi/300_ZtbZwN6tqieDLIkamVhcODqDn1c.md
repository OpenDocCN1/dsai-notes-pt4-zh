## 3.2、搭建自动化视频的 Coze 工作流

首先看下整体的工作流大图

![](img/91927af9ae15a96e2e1170c150797328.png)

### 3.2.1.创建工作流

1.登录 Coze 平台，点击自己的工作空间

打开 coze 官网 https://www.coze.cn/home 注册

点击工作空间-资源库-右上角项目-创建工作流

![](img/4a2c5cdb8ce28f048a1fdcded8f53e3e.png)

创建一个工作流，并命名

工作流名称：必须是英文符号，这里输入 makeVideo

工作流描述：输入中文。这里输入爆款短视频

![](img/eb2806c8384205790f970cd3362c7061.png)

### 3.2.2. 开始节点设置

进入工作流界面后，默认会有两个节点，开始和结束

首先在开始节点配置：

输入的变量名 input，

然后在默认值和描述里按图配置，当然也可以不写，主要是为了测试时提醒用的。

描述一栏输入：“输入一个主题"

![](img/7b621035a63097ca672f8b890374a430.png)

### 3.2.3. 接下来要添加两个大模型节点

一个用于角色形象提示词，一个用于视频的相关说明。大模型都选 Deepseek-V3

![](img/06985b0b0b39243526ab7ac912cff2b3.png)

系统提示词

```
你是一名形象创作大师，请根据输入的信息生成一个主角的形象，如果输入中没有主角，则无需生成

要求输出为ai绘画的提示词，且输出为中文
```

用户提示词

```
{{input}}
```

![](img/3fdd241e9672ebc785994257cb8177e8.png)

![](img/9afcd91f849c64e07b906deb5c56dd94.png)

输入：开始-input

输出按照提示词来进行配置

输出：新增变量 shot\description\text\style

output、变量类型选 Array-Object

shot:

description:

系统提示词：

```
# 角色
你是一名专业的视频拍摄大师，具备丰富的视频创作经验和专业知识，能够精准理解用户输入，并将其转化为对应的分镜、页面说明以及文案。

## 技能
### 技能 1: 生成视频相关内容
1. 接收用户输入后，根据输入的内容制作分镜，比如判断内容是古诗，则按照对应的诗句数量制作分镜；比如判断对应的内容是故事，则按故事画面进行分镜
2. 针对每个分镜，进行场景描述、画面和角色说明、画面风格描述，并撰写不超过 20 字的旁白文案。 
4. 将所有内容按 json 格式输出，格式如下：
{
    &quot;shot&quot;: &quot;分镜场景描述&quot;,
    &quot;description&quot;: &quot;画面和角色说明&quot;,
    &quot;style&quot;: &quot;画面风格描述&quot;,
    &quot;text&quot;: &quot;旁白文案&quot;
}

## 限制:
- 输出内容必须围绕视频生成相关，拒绝回答无关话题。
- 严格按照给定的 json 格式进行输出，不能偏离框架要求。
- 如果判断输入是古诗，则旁白文案直接采用诗句文案
- 旁白文案每个分镜不要超过 30 字。
- 需确保分镜风格保持一致。
```
