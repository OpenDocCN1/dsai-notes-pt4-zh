# 二、提示词的重要性

## 1. 什么是提示词

提示词（Prompt）在计算机编程和人工智能领域中是一个非常重要的概念，它指的是提供给程序或算法的一组输入信息，这些信息用于指导程序执行特定的任务或者生成某种输出。它可以是一个问题、一个指令或者一个陈述，提示词的质量直接影响 ChatGPT 的响应质量和准确性。

在自然语言处理（NLP）和机器学习模型中，提示词通常以文本的形式出现，它们可以告诉模型应该关注什么内容、如何理解上下文以及期望得到什么样的结果。例如，在使用聊天机器人时，提示词可能是用户的提问，机器人的回复就是基于这个提示词生成的。

近年来，随着大型预训练语言模型的发展，如 GPT-4 等，提示词的概念得到了更广泛的应用和研究。这些模型能够根据给定的提示词生成连贯的文本，包括文章、对话甚至代码。通过精心设计提示词，研究者发现可以提高模型的性能，甚至在某些情况下超越模型原本的能力，这种现象被称为“提示工程”（Prompt Engineering），至此也诞生了一个专门的岗位：提示词工程师。

提示词的设计非常关键，它可以影响模型的理解和生成能力，好的提示词应该清晰明了地表达出预期的任务目标，同时避免歧义和不明确的表述。此外，提示词还可以包含一些额外的背景信息，帮助模型更好地理解和完成任务。

提示词是连接用户需求和 AI 模型的桥梁，通过精心设计的提示词，我们可以有效地引导 AI 模型按照我们的预期去工作，从而实现各种复杂的语言理解和生成任务。

以下是提示词的几个关键要素：

| **要素** | **描述** |
| --- | --- |
| 清晰性 | 提示词应该明确无误，避免歧义。 |
| 相关性 | 提示词应与期望的回答或行动紧密相关。 |
| 完整性 | 提供足够的信息以便 ChatGPT 理解上下文。 |
| 精确性 | 使用精确的词汇和短语以获得最佳结果。 |

## 3. 提示词如何影响交流效果

提示词的质量对交流效果有着决定性的影响。以下是几个关键点：

+   **提高理解**：精确的提示词帮助 ChatGPT 更好地理解用户的意图。

+   **优化回答**：清晰的问题引导更准确和有用的回答。

+   **节省时间**：有效的提示词减少了来回沟通的次数，节省双方时间。

+   **增强互动**：良好的提示词能够激发 ChatGPT 的创造性回答，增强用户体验。

## 4. 好的提示词的标准

为了最大化 ChatGPT 的效果，一个好的提示词应该遵循以下标准：

| **标准** | **描述** |
| --- | --- |
| 明确性 | 一个好的提示词应该是明确无误的，能够让 ChatGPT 清楚地理解用户的问题或请求，避免使用模糊不清或含糊其辞的表达方式。 |
| 简洁性 | 一个好的提示词应该是简洁的，不需要过多的细节或冗余的信息，尽量用最少的词语来传达最核心的信息。 |
| 相关性 | 一个好的提示词应该是与问题或请求相关的，不包含无关的信息或背景，这样可以确保 ChatGPT 专注于解决当前的问题，而不是被其他因素所干扰。 |
| 完整性 | 一个好的提示词应该是完整的，包含了所有必要的信息，以便 ChatGPT 能够提供准确和全面的回答，如果缺少了关键信息，可能会导致回答不准确或不完整。 |
| 准确性 | 一个好的提示词应该是准确的，没有拼写错误或语法错误，这可以避免误导 ChatGPT，导致错误的回答。 |
| 可读性 | 一个好的提示词应该是易于阅读的，使用了清晰的语言和合适的格式，避免使用过于复杂或专业的术语，除非它们是必要的。 |
| 适应性 | 一个好的提示词应该是适应性的，能够根据不同的情境和需求进行调整，这意味着提示词不应该过于僵化或固定，而是具有一定的灵活性。 |
| 一致性 | 一个好的提示词应该是一致的，遵循相同的风格和格式，这有助于提高 ChatGPT 对问题的理解度，并减少误解的可能性。 |
| 反馈性 | 一个好的提示词应该是具有反馈性的，允许用户对 ChatGPT 的回答进行评价和改进，这可以帮助改进模型的性能，使其更好地满足用户的需求。 |
| 创新性 | 一个好的提示词应该是具有创新性的，能够激发 ChatGPT 产生新颖和有趣的回答，这可以通过使用独特的词汇、结构和语境来实现。 |

为了更直观地展示这些概念，以下是一个简单的示例：

**不好的提示词**："东西坏了怎么办？"

**好的提示词**："我的笔记本电脑无法启动，显示蓝屏错误代码 0x000000EF。我应该如何解决这个问题？"

通过这个例子，我们可以看到好的提示词是如何通过提供具体信息和明确的问题来帮助 ChatGPT 提供更有用的帮助。

# 三、构建有效的提示词

## 1. 明确目标与预期结果

构建有效的提示词的第一步是明确您的目标和预期结果。以下是如何设定目标和预期结果的指导原则：

| **行动** | **描述** | **例子** |
| --- | --- | --- |
| 目标设定 | 确定您希望通过与 ChatGPT 交流实现的具体目标。 | “我的目标是获取关于健康饮食的建议。” |
| 结果预期 | 描述您期望从 ChatGPT 得到的具体信息或行动。 | “我期望得到一份营养均衡的一周饮食计划。” |

> 常用技巧：ChatGPT 角色设定

>

> 当与 ChatGPT 互动时，设定角色是一个非常有用的策略，尤其是在需要模拟特定情境或专业知识的情况下。角色设定指令是 ChatGPT 官方支持的能力，起到“调度”行业专家模型的作用，通过身份来约束 ChatGPT 的回答领域范围，一定程度上能让回答更有针对性。

>

> 在**不**同的任务场景下，可以设定 ChatGPT 扮演不同的角色身份，也可以设定知识经验水平、精通领域、语言风格等细化的参数。例如，如果您需要一个医学方面的建议，可以让 ChatGPT 扮演医生的角色；如果您正在准备一场面试，可以让 ChatGPT 扮演面试官的角色。

>

> 然而，并非所有的交互都需要设定角色。在日常的问答或寻求通用信息的情况下，设定角色可能并不是必须的。这完全取决于具体需求和期望从 ChatGPT 那里得到什么样的回答。

>

> 总的来说，是否给双方设定角色取决于您的需求和期望。在某些情况下，设定角色可以使回答更加专业和有针对性；在其他情况下，则可能是不必要的。

## 2. 提问的艺术

提问是与 ChatGPT 交流的核心。以下是提问的艺术，包括开放式与封闭式问题，以及问题的构造技巧：

### 开放式与封闭式问题

| **类型** | **描述** | **例子** |
| --- | --- | --- |
| 封闭式问题 | 通常可以用“是”或“否”来回答，获取具体事实。 | “今天的日期是 2024 年 3 月 17 日吗？” |
| 开放式问题 | 鼓励详细回答，探索更多可能性。 | “你如何建议我改善我的饮食习惯？” |

### 问题的构造技巧

作为一名 ChatGPT 提示词工程师，我将为您提供一系列问题构造技巧，这些技巧将帮助您更有效地与 ChatGPT 进行交流。以下是各种问题构造技巧的详细列表，以表格形式呈现：

| **技巧** | **描述** | **示例** |
| --- | --- | --- |
| 使用具体动词 | 使用行动性动词来引导特定的任务或回答。 | “列出”、“解释”、“比较”、“总结” |
| 限定范围 | 通过限定词来缩小问题的范围，使回答更加精确。 | “在过去五年内，哪些科技发明对教育领域产生了最大影响？” |
| 明确时间框架 | 指定问题的时间范围，以便获得相关且时效的信息。 | “2023 年最流行的编程语言是什么？” |
| 包含条件 | 描述问题的具体条件或限制，以获得更准确的答案。 | “在不使用化学肥料的情况下，如何提高番茄的产量？” |
| 使用序列 | 当需要多个步骤或方面的回答时，明确指出顺序。 | “首先，解释什么是区块链。其次，列出区块链在金融领域的三个应用。” |
| 避免双重问题 | 避免在单一提示词中提出多个问题，以免混淆。 | 不：“我喜欢跑步和游泳，你有什么建议？” 是：“我应该如何提高我的跑步速度？” |
| 避免复合问题 | 与双重问题类似，复合问题包含多个问题，应分开提问。 | 不：“苹果和香蕉哪个更有营养，哪里可以购买有机水果？” 是：“苹果和香蕉哪个更有营养？” “在哪里可以购买有机水果？” |
| 引导性问题 | 使用问题来引导 ChatGPT 到特定的话题或方向。 | “关于气候变化，最新的科学研究有哪些发现？” |

## 5.**BRTR 模型提示词公式**

BRTR 模型包含四个部分：背景（B），定角色（R），派任务（T），提要求（R）。

这个模型的核心在于它能够帮助撰写者系统性地构建出清晰、具体、目标明确的提示词，极大地提升与 ChatGPT 交互的效率和效果。

**背景（B）：**这是提示词的开端，需要提供足够的信息背景，让 ChatGPT 了解到你的问题或请求是在什么样的情境下提出的。

**定角色（R）：**在这一部分，你需要明确告诉 ChatGPT 你期望它扮演什么角色。是一个专业顾问、友好的助手，还是某个领域的专家？

**派任务（T）**：具体描述你希望 ChatGPT 完成什么任务。这个任务应当是清晰、明确、可执行的。

**提要求（R）：**最后，明确你对完成任务的具体要求，包括期望的输出格式、风格、使用的特定知识等。

让我们通过一个例子“📕文案撰写”来演示 BRTR 模型的应用。

+   背景（B）：你运营着一个美妆护肤账号，专注于 22 岁重庆妹子的美妆护肤分享，文案风格偏爱地道口音。

+   定角色（R）：你是一名资深的📕文案专家，擅长编写符合用户口味的爆款文案。

+   派任务（T）：围绕“YSL 经典口红”这一主题，撰写一篇不超过 500 字的📕文案。

+   提要求（R）：文案要求口语化，多使用 emoji 表情图标，适当融入个人的使用体验和评价。

**步骤解析：**

+   定义背景：首先，清晰地描述你的账号特色和目标受众。这有助于确定文案的基调和风格。例如，重庆妹子的直率和活泼可以作为撰写文案的情感基调。

+   定角色：明确你的角色——一个了解目标用户喜好、精通📕文案趋势的专家。这一步骤帮助你聚焦于如何以专业的视角来包装内容。

+   派任务：具体指明需要完成的任务——以 YSL 经典口红为中心，撰写引人注目的文案。这一步骤是整个过程的核心，需要你围绕产品特点和用户兴趣来构思内容。

+   提要求：详细列出文案的具体要求，包括风格（口语化）、表情使用（多样的 emoji）、以及个人使用体验和评价的融入。这些要求确保文案既生动又具有说服力。

为了避免常见的提示词错误，可以遵循以下准则：

| **错误类型** | **改进方法** | **示例** |

通过以上解决方案，用户可以更有效地解决在使用 ChatGPT 时可能遇到的问题，从而提高交流的质量和效率。这些策略和技巧将帮助用户更好地利用 ChatGPT 的能力，获得更准确和有用的信息。
