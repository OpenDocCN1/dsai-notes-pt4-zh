# 一、前言：文档定位与价值说明

随着生成式 AI 技术的普及，Prompt（提示词）作为人机交互的核心语言，其工程化能力已成为 AI 应用落地的关键竞争力。本手册系统梳理了 17 个主流 Prompt 框架，结合新兴方法论与行业实践，旨在为 AI 从业者、产品经理、内容创作者等提供从理论到实操的全流程指南。

**文档特色：**

1.  结构化体系：从基础框架到复杂场景解决方案，覆盖 90% 以上 AI 交互场景；

1.  实操导向：每个框架附带行业案例与迭代策略，避免 “理论脱离实践”；

1.  动态更新：收录 2024-2025 年新兴框架（如 STAR、PDCA），同步全球技术趋势。

# 二、引言：Prompt 工程的底层逻辑

1.  **Prompt 工程的本质与价值**

Prompt 工程是通过结构化语言引导 AI 模型生成预期输出的方法论，其核心在于：

+   认知对齐：将人类意图转化为模型可理解的指令结构；

+   误差控制：减少因语义模糊导致的输出偏差（据研究，优质 Prompt 可提升 40% 模型响应准确率）；

+   效率提升：通过框架化设计，避免重复调试，缩短 AI 应用开发周期。

1.  **框架设计的核心原则**

+   明确性：避免歧义（如用 “生成 300 字产品卖点” 替代 “写一段文案”）；

+   场景化：结合角色、背景等上下文信息（如 “作为电商运营，撰写 618 促销文案”）；

+   可评估：设定输出标准（如 “包含 3 个用户痛点解决方案”）。

# 四、Prompt 框架

## **1. BROKE 框架**

**原理**

+   **融**合 OKR（目标与关键成果）方法论，通过背景（Background）、角色（Role）、目标（Objectives）、关键结果（Key Results）、演变（Evolve）五要素构建结构化 Prompt

+   演变步骤包含三种优化策略：

+   改进输入：针对答案不足迭代背景、目标与关键结果

+   改进答案：在对话中修正模型输出缺陷

+   重新生成：保持 Prompt 不变多次生成结果进行优化

**功能**

+   精准对齐任务目标与评估标准，适用于需要量化效果的场景

+   通过迭代机制持续优化 Prompt，提升模型输出质量

**使用场景**

+   目标管理：如内容创作互动率提升、产品转化率优化

+   项目规划：技术方案迭代、营销活动策划

**优点**

+   数据驱动的目标追踪体系

+   支持动态优化的灵活结构

**缺点**

+   初始设置需明确量化指标

+   复杂任务需多次迭代调整

**示例**

```
Background：作为电商运营，需提升新品详情页转化率
Role：你是资深电商文案策划专家
Objectives：使详情页停留时长提升30%
Key Results：CTR（点击通过率）提升至8%，加购率提升15%
Evolve：每周分析热力图数据，优化文案排版与卖点顺序
```

## **2. COAST 框架**

**原理**

+   涵盖**背**景（Context）、目标（Objective）、行动（Actions）、场景（Scenario）、任务（Task） 五维要素

+   通过系统化拆解复杂问题，构建全场景任务描述体系

**功能**

+   将大型项目分解为可执行的具体步骤

+   确保各维度要素在 Prompt 中被充分考虑

**使用场景**

+   战略规划：企业国际化拓展、技术路线图制定

+   复杂问题解决：跨部门协作项目、危机公关处理

**优点**

+   全景视角覆盖任务全要素

+   支持从宏观到微观的任务拆解

**缺点**

+   简单任务使用时可能过度复杂

+   需完整掌握各维度信息

**示例**

```
Context：新能源汽车品牌计划进入欧洲市场
Objective：3个月内建立本地化营销体系
Actions：①调研欧盟环保法规 ②组建本地运营团队 ③开发多语言官网
Scenario：预计2025年Q4遭遇欧盟碳关税政策调整
Task：制定包含政策应对预案的市场进入计划
```

## **3. CRISPE 框架**

**原理**

+   包含**能力与角色（Capacity & Role）、洞察（Insight）、声明（S**tatement）、个性（Personality）、实验（Experiment）五要素

+   通过角色定位、背景洞察、任务声明、风格设定与方案实验构建丰富 Prompt

**功能**

+   精准定义模型输出的角色定位与内容风格

+   支持多方案对比实验，提升决策质量

**使用场景**

+   创意内容创作：广告文案、剧本撰写

+   决策支持：商业方案评估、技术选型建议

**优点**

+   支持高度个性化的内容生成

+   多方案实验机制提升创意多样性

**缺点**

+   各要素需详细构思，耗时较长

+   风格设定需明确参考标准

**示例**

```
Capacity &amp; Role：作为科技行业资深分析师
Insight：元宇宙产业正处于技术成熟度曲线的泡沫破裂期
Statement：撰写2025年元宇宙硬件发展趋势报告
Personality：采用Gartner技术成熟度模型分析框架，语言严谨但具备前瞻性
Experiment：提供AR/VR头显、触觉反馈设备、空间计算平台三个方向的发展预测
```

## **4. CHAT 框架**

**原理**

+   聚焦**角色（Role）、背景（Background）、目**标（Ambition）、任务（Task）四核心要素

+   通过场景化角色设定与目标导向任务描述，提升交互针对性

**功能**

+   构建拟人化交互场景，适用于需要情感共鸣的场景

+   明确目标与任务的对应关系，提升模型理解准确性

**使用场景**

+   客服支持：产品售后咨询、用户问题解答

+   个性化服务：职业规划、健康管理建议

**优点**

+   交互场景贴近真实对话

+   目标与任务的强关联性提升响应精准度

**缺点**

+   需提供充足背景信息以确保准确性

+   复杂场景下目标拆解可能不充分

**示例**

```
Role：青少年心理辅导师
Background：16岁高中生面临升学压力，出现失眠焦虑症状
Ambition：帮助学生建立健康的压力管理机制
Task：设计包含时间管理技巧、情绪释放方法、家长沟通策略的三步干预方案
```

## **5. CARE 框架**

**原理**

+   由**上下文（Context）、行动（Action）、结果**（Result）、示例（Example）构成结构化提问框架

+   通过场景设定、任务描述、结果预期与案例参考，提升模型理解效率

**功能**

+   为复杂任务提供清晰的执行路径指南

+   示例参考帮助模型精准把握输出标准

**使用场景**

+   教育与培训：软件操作指南、流程培训材料

+   专业报告生成：市场调研分析、技术可行性研究

**优点**

+   结构化逻辑降低沟通成本

+   示例参考有效减少理解偏差

**缺点**

+   简单任务使用时可能过于繁琐

+   示例准备需要额外资源投入

**示例**

```
Context：跨境电商企业计划拓展日本市场
Action：分析日本消费者购物习惯与电商平台规则
Result：形成包含选品建议、物流方案、合规要点的市场进入报告
Example：报告中需包含&quot;日本消费者对商品包装环保等级关注度达78%&quot;等具体数据引用
```

## **6. CREATE 框架**

**原理**

+   基于**清晰（Clarity）、相关信息（Relevant info）、示例（Exam**ples）、避免含糊（Avoid ambiguity）、迭代修补（Tinker） 五大原则

+   通过精准定义任务、提供关键信息、示例参考、语言优化与持续迭代，提升 Prompt 质量

**功能**

+   确保任务描述无歧义，降低模型误解概率

+   迭代机制支持 Prompt 持续优化

**使用场景**

+   数据分析：报表生成、数据可视化需求

+   技术文档撰写：API 接口说明、开发规范制定

**优点**

+   极简原则易于上手使用

+   迭代机制适应需求变化

**缺点**

+   复杂任务需多次迭代才能完善

+   信息完整性要求较高

**示例**

```
Clarity：撰写AIGC技术在电商客服场景的应用白皮书
Relevant info：包含智能问答、工单分类、情绪分析等技术模块的落地案例
Examples：参考《2024年客服行业AI应用趋势报告》的结构
Avoid ambiguity：明确区分&quot;文本生成客服话术&quot;与&quot;语音交互系统&quot;的技术差异
Tinker：根据行业专家反馈调整技术路线图部分的图表展示方式
```

## **7. RACE 框架**

**原理**

+   包含**角色（Role）、行动（Action）、结果**（Result）、示例（Example）四要素

+   通过角色定位、任务行动、结果预期与案例参考，构建目标导向的 Prompt

**功能**

+   明确执行主体与任务边界，提升输出相关性

+   结果导向的设计确保任务达成可衡量

**使用场景**

+   营销内容创作：产品卖点文案、促销活动策划

+   运营方案制定：用户增长策略、社群运营计划

**优点**

+   结构简洁易操作

+   结果可量化评估

**缺点**

+   复杂任务需结合其他框架使用

+   角色定位需精准匹配场景

**示例**

```
Role：高端护肤品品牌内容运营
Action：创作新品精华液的社交媒体推广文案
Result：文案需突出&quot;抗初老&quot;核心卖点，附带用户试用对比图拍摄建议
Example：参考&quot;早C晚A&quot;护肤概念的传播文案结构
```

## **8. RISE 框架**

**原理**

+   由**角色（Role）、输入（Input）、步骤（St**eps）、期望（Expectation）构成

+   通过角色定义、信息输入、步骤规划与结果期望，构建详细的任务执行指南

**功能**

+   将复杂任务拆解为可执行的具体步骤

+   明确输入输出标准，提升任务完成度

**使用场景**

+   项目管理：软件开发流程、活动筹备计划

+   工作流程设计：审批流程优化、跨部门协作机制

**优点**

+   步骤化指导提升执行力

+   输入输出标准化降低沟通成本

**缺点**

+   前期规划需投入较多时间

+   动态场景下步骤调整灵活性不足

**示例**

```
Role：敏捷开发项目经理
Input：已收集用户故事池与优先级排序
Steps：①召开迭代规划会议 ②拆分用户故事为开发任务 ③制定燃尽图跟踪计划
Expectation：2周迭代周期内完成80%计划任务，缺陷率控制在5%以内
```

+   通过全场景要素定义，构建深度问题解决框架

**功能**

+   支持复杂问题的系统性分析与解决方案设计

+   场景化思考确保方案落地可行性

**使用场景**

**优点**

+   全方位覆盖问题解决全流程

+   场景化设计提升方案实用性

**缺点**

+   信息收集成本较高

+   要素完整度要求严格

**示例**

```
Role：智慧城市解决方案架构师
Objective：设计某二线城市交通拥堵治理方案

Expected Solution：包含智能交通信号控制、动态停车引导、共享出行激励的综合解决方案
Steps：①交通流量数据采集 ②瓶颈路段识别 ③方案原型设计 ④试点区域验证
```

**功能**

**优点**

+   格式标准化提升工作效率

+   结构简洁易操作

**缺点**

+   创造性任务可能受格式限制

+   复杂格式需提前明确规范

**示例**

```

Task：分析美联储2025年货币政策走向
Format：制作包含利率预测曲线、经济指标影响矩阵、情景分析的PPT简报，共15页以内
```

## **11. ICIO 框架**

**原理**

+   包含**指**令（Instruction）、背景信息（Context）、输入数据（Input）、输出指示器（Output Indicator） 四要素

+   通过清晰指令、背景支撑、数据输入与输出标准定义，构建精准的任务交互框架

**功能**

+   确保模型在特定场景下准确理解任务需求

+   数据驱动的输入输出设计提升结果可靠性

**使用场景**

+   内容生成：新闻稿撰写、技术文档翻译

+   智能推荐：商品推荐系统、内容分发算法

**优点**

+   数据与指令的结合提升结果准确性

+   输出标准明确便于结果验证

**缺点**

+   数据准备需要专业知识

+   复杂任务的输出指示器设计难度高

**示例**

```
Instruction：生成某新能源汽车品牌2025年Q2季度财报解读文章
Context：该品牌当季交付量同比增长45%，但毛利率下降3个百分点
Input：近三年财报数据、行业平均毛利率水平、竞争对手同期表现
Output Indicator：文章需包含财务指标对比分析图表，重点解释毛利率变动原因，字数控制在1200-1500字
```

+   通过任务定义、需求请求、行动规划、场景上下文与案例参考，构建完整的任务指令体系

**功能**

+   全方位覆盖任务执行所需信息

+   示例参考确保模型准确理解需求

**使用场景**

+   专业报告生成：市场分析、技术白皮书

+   复杂问题解答：法律咨询、医疗诊断建议

**优点**

+   信息完整性高，减少理解偏差

+   结构化设计提升指令清晰度

**缺点**

+   要素较多，构建成本较高

+   简单任务使用时可能过于繁琐

**示例**

```
Task：撰写AIGC技术在教育领域的应用前景报告
Request：包含智能辅导系统、个性化学习内容生成、作业自动批改等应用场景分析
Action：收集近三年相关学术论文与企业案例，进行技术成熟度与市场渗透率分析
Context：中国教育数字化转型政策推动，K12阶段AI教育产品使用率年增长25%
Example：参考《2024年全球教育科技趋势报告》中关于生成式AI的章节结构
```

## **15. ERA 框架**

**原理**

+   包含**期望（Expectation）、要求（Req**uirement）、行动（Action）三要素

+   通过结果期望、具体要求与执行行动的明确界定，构建简洁高效的 Prompt 框架

**功能**

+   快速明确任务目标与执行标准

+   简洁结构适用于日常任务交互

**使用场景**

+   内容生成：文章创作、报告撰写

+   智能问答：信息查询、知识检索

**优点**

+   轻量化设计便于快速使用

+   目标与要求的明确对应提升效率

**缺点**

+   复杂任务的细节描述不足

+   缺乏场景化背景支撑

**示例**

```
Expectation：生成关于量子计算商业应用的科普文章
Requirement：包含金融建模、药物研发、密码学三个应用领域的通俗解释
Action：采用类比说明（如&quot;量子计算与传统计算的速度差异相当于飞机与自行车&quot;），避免专业术语堆砌
```

## **16、STAR 框架**

**原理**

+   源自情境面试方法论，包含**情境（Situation）、任务（Task）、行**动（Action）、结果（Result）

+   通过场景还原、任务定义、行动规划与结果评估，构建叙事型 Prompt

**功能**

+   适用于需要故事化表达的场景，如案例撰写、经验分享

+   逻辑链条完整，便于模型生成结构化叙事内容

**使用场景**

+   案例复盘与经验沉淀：企业内部最佳实践总结（如危机处理案例、项目成功经验）、个人履历 / 面试素材整理（行为面试问题回答框架）。

+   叙事型内容创作：品牌故事撰写、用户成功案例包装、营销文案中的场景化叙事（如产品使用场景还原）。

+   问题解决过程可视化：技术故障排查报告、运营活动复盘分析、跨部门协作问题处理记录。

**优点**

+   逻辑闭环性：从场景到结果的完整链条，确保叙事逻辑清晰，符合人类认知习惯。

+   细节引导力：通过四要素强制拆解任务，避免内容空洞（如 Action 需具体到可执行步骤）。

+   跨场景通用性：既适用于技术、运营等专业领域，也可用于日常沟通（如工作总结汇报）。

**缺点**

+   创作成本较高：需完整还原场景细节，复杂案例的要素填充耗时较长。

+   灵活性不足：严格的四步结构可能限制创意表达，不适合开放式头脑风暴场景。

+   结果量化依赖：若缺乏可量化的 Result（如 “用户满意度提升” 需具体数据支撑），叙事说服力可能减弱。

**示例**

```
Situation：某电商平台在大促期间遭遇服务器崩溃
Task：制定应急响应与用户安抚方案
Action：①启动备用服务器集群 ②向用户推送补偿方案公告 ③组建专项客服团队处理咨询
Result：4小时内恢复系统，用户满意度回升至90%，后续3天销售额追回85%
```

## **17、PDCA 框架**

**原理**

+   质量管理循环框架，包含计划（Plan）、执行（Do）、检查（Check）、处理（Act）

+   用于构建迭代优化型 Prompt，支持持续改进的任务流程

**功能**

+   适用于需要分阶段实施与优化的任务，如产品迭代、流程改进

+   闭环设计确保任务持续优化

**使用场景**

+   产品与流程迭代：软件版本迭代规划、运营活动优化（如促销策略调整）、服务流程改进（如客服响应效率提升）。

+   实验性任务管理：A/B 测试方案设计、用户增长黑客策略、市场调研结论验证（如新品定价测试）。

+   质量管理体系：制造业流程优化、内容审核标准迭代、项目风险控制（如分阶段里程碑检查）。

**优点**

+   科学闭环性：遵循 “计划 - 执行 - 检查 - 改进” 的科学方法论，降低决策盲目性。

+   数据驱动性：Check 环节强制要求数据验证，避免主观判断导致的偏差。

+   持续进化性：Act 阶段支持经验沉淀与策略升级，适合长期优化场景（如季度 OKR 迭代）。

**缺点**

+   周期较长：完整循环需经历四个阶段，不适用于紧急或短期任务（如突发公关事件）。

+   数据依赖度高：Check 环节需充足数据支撑，若数据采集困难（如小众市场调研），框架效果会打折扣。

+   初期规划压力大：Plan 阶段需明确目标与方案，对未知领域（如全新业务线）的规划难度较高。

**示例**

```
Plan：设计用户增长实验方案，测试A/B版落地页转化率
Do：在20%用户群体中部署A版与B版落地页
Check：对比两周内两组用户的注册转化率与跳出率
Act：根据测试结果，将转化率提升15%的版本全量推广，并规划下一阶段实验
```

### 框架选择矩阵

| 任务类型 | 推荐框架 | 核心优势 |
| --- | --- | --- |
| 目标管理 | BROKE、OKR 融合框架 | 量化指标与迭代优化 |

1.  **复杂任务拆解**：COAST 框架进行全景分析，配合 TRACE 框架构建详细指令

1.  **持续优化循环**：PDCA 框架驱动迭代，结合 CREATE 框架进行 Prompt 优化
