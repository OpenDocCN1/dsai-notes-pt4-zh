# 视频画面设计审核点 by猫叔

> 来源：[https://waytoagi.feishu.cn/docx/O2VCd9vyRo8kvtxtbhQctRunnXd](https://waytoagi.feishu.cn/docx/O2VCd9vyRo8kvtxtbhQctRunnXd)

# 画面构图

-画面中主体的位置合理吗?靠近中心吗?

-主体与背景之间关系协调吗?主体突出吗?

-画面中的线条呈现出的视觉动感合适吗?

# 照明运用

-光影对气氛及情绪的渲染效果如何?

-关键部分的亮度是否突出主体?

-光影变化是否有规律和节奏感?

-主光、天光、边光等使用是否合理

-光影是否突出重点,营造氛围或丰富场景氛围

# 色彩运用

-色彩是否突出主体

-色彩变化是否有规律和节奏感

-主色调是否恰当,配合氛围

-是否使用了补色、分色等来丰富色彩

# 镜头语言

-镜头选择是否合理,如大中特写镜头的运用

-镜头移动是否流畅自然

-剪接是否顺畅、有节奏感

-演技是否利用不同镜头发挥作用

-是否利用镜头语言突出重点

# 视听节奏

-画面编辑是否合理、有变化

-音乐及声音是否匹配画面气氛

-节奏是否紧凑、节奏感强

# 整体意境

-视听语言整体是否给人美的感受

-是否达到意境的深度、制造共鸣

-是否成功营造出场景需要的氛围

-各要素是否协调统一

# 角色情绪

-演员的表情、眼神是否自然传神

-情绪转变是否流畅、细微

-是否穿透镜头传递给观众强烈情感

-动作细节

# -动作是否自然

-重点动作是否突出,有规律

-运用了细微的动作细节来丰富角色

-目光、动作是否遵循镜头视角

# 语言表达

-语调、语速是否符合角色特质

-重点词语的音调、音量是否突出

-有无运用非语言声音来丰富表演

# 角色互动

-与其他角色的视线、动作是否交互协调

-演员之间有无默契、互动

-互动中角色关系

# 整体表演

-是否塑造有说服力的人物

-表演是否丰满,具有感染力

-能否打动观众

# 场景布置

-场景中的道具、装饰等布置是否合理

-是否突出和渲染场景的主要氛围

-布置是否有层次和细节

# 空间营造

-使用了哪些方式(如吧台、门窗)来表现前中后的空间感

-空间给人一种什么样的氛围

-空间线条视觉感是否合理

# 场景细节

-是否有突出场景主题的细节

-细节设置是否自然,有层次

-是否存在无关的多余细节
