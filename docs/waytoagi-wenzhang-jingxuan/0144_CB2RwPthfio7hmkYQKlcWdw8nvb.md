# 离谱村的守护者——离谱小事系列

> 来源：[https://waytoagi.feishu.cn/docx/C6ohdgtbGoBOkOxaSAxc12lbn6b](https://waytoagi.feishu.cn/docx/C6ohdgtbGoBOkOxaSAxc12lbn6b)

**主题：通过小村民杰克与自己内心的战斗，展现了一个小孩子寻找自己价值的**成长故事。杰克最终认识到，真正的英雄不在于战胜外在的敌人，而在于克服内心的挑战。

**优势：剧情属于常见主题，配合超级英雄包装，欧美**人接受度高；小孩子的幻想也容易离谱发挥。

**形式：整体风格可以类似DC漫威漫画的动态模式，比较好实现。**（也可以参考下B站胶囊计划第二季第一集）

此为好莱坞剧本格式，不包含分镜。
