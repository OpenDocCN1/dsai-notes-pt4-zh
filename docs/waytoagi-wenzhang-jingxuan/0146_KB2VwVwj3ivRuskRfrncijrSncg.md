# 出走的村长——离谱小事系列

> 来源：[https://waytoagi.feishu.cn/docx/N94pdMbNDotgAcxmuP3cnhesnCd](https://waytoagi.feishu.cn/docx/N94pdMbNDotgAcxmuP3cnhesnCd)

主题：结合之前离谱村的换村长事件，出一个短小精悍的视频小品

形式：全片完全以新闻采访的形式展现，参考1818黄金眼，主打轻松

参赛：不要参加上海和B站的AI大赛（我们剧本里没有使用对方限定的IP）

此为剧本，还不包含分镜。

**INT. 电视台 - 日**

主持人：咳咳，村民有些激动，请前方记者找些靠谱的村民采访

**EXT - 离谱村 - 日**

记者：下面我们来问一下据说村里最聪明的人

驯鹿诡异的微笑

记者：请问（被打断）

驯鹿：我正在分析他留下的一些数据,试图找出一些规律。你看,这些数据的分布呈现出一种非常有趣的模式,如果我们把它看作一个多维度空间,并应用卷积神经网络进行分析.......

（画面疯狂加速度）

记者：你可真是个大聪明

驯鹿：下届村长记得投我一票

**EXT - 离谱村 - 日**

记者看向树上一个甲虫：请问

甲虫：6

记者：您是说村长这事干的6？

甲虫：5

记者：唔，我是有些奇怪了，为什么选在这个时间点消失呢？

甲虫：4321，我有六只脚，要买三双AJ，有点吃不消啊，需要三思

三思：谁叫我？

甲虫：呀，三思你来啦，喂，老板，我买三双！

记者：打搅了

**EXT - 离谱村 - 日**

一头睡着的兔子

记者：请问兔子邮差（被打断）

兔子大哭：我不该睡觉的，555

村民：龟兔赛跑综合征，我就说睡觉不好嘛，我们AI群都不睡觉的；

**EXT - 离谱村 - 日**

记者把话筒递向宝石龟

宝石龟：你问离谱熊的事啊？离谱熊就爱干离谱的事，不过离离谱村出走这个离谱事，倒也不算离谱

记者：啊？

宝石龟：每个生命都有自己的路要走，就像河流，总有一天会奔向大海。去了哪里又何必追究呢。

记者看着远去的宝石龟若有所思
