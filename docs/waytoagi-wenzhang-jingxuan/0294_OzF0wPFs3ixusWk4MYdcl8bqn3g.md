# OpenAI 公司的时间线

> 来源：[https://waytoagi.feishu.cn/docx/LL4NdAG9soPxwwxOAvRcZXJ1nhd](https://waytoagi.feishu.cn/docx/LL4NdAG9soPxwwxOAvRcZXJ1nhd)

OpenAl 是一家人工智能研究公司，成立于 2015 年，总部位于美国旧金山。OpenAl 的使命是推进人工智能技术的发展，为全球创造更加安全、智能的未来。OpenAI 早期是个非营利机构，后来改成了有限营利形式。
