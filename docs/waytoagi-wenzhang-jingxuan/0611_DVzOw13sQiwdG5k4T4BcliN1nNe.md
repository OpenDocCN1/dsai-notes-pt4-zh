直接用下面的内容对一篇文章链接提问

```
1.元数据:标题，作者，链接，标题
2.作者主张，亮点;
3.逐层加深理解;
4.关键术语/概念;
5.文章内的无用信息;
6.摘要核心信息;
7.金句;
8.总结;
9.根据文章内容给我问问题，引发我思考
```

## 【AI应用】Kimi：喂我一本书，陪你一起读

截止2月4日，kimi还不支持扫描版本的pdf，还是要纯文字的才能识别，感谢 姚怡枝 尝试告知

> 无人之路GO 无人之路 2024-02-01 20:58 发表于浙江

> https://mp.weixin.qq.com/s/yBeW02l9ULQYGaOxO2R4PA

引子

最近上下班的地铁上在读《深度学习入门--基于Python的理论与实现》，希望补一补这一波AI浪潮的基础。这是日本作者斎藤康毅深度学习“鱼书”系列的第一本，非常好读。这个系列的特点是从0开始，深入浅出；我已经刷到第三本了，强烈推荐给所有想要了解深度学习的同学。

![](img/b79265c07e9a54752f8baf2090ff23b2.png)

因为可读性强，刷得快，一个星期就完本；但读完之后总是觉得不踏实，对自己的掌握程度不确定。自然而然地问，大语言模型能帮我复习、测试和巩固吗？于是，开启了探索之旅。

要让大模型根据书本的内容来与我交互，首先需要将整本书喂给它，这一步是关键。而这第一步就成了很多大模型产品的门槛。首先是ChatGPT，由于众所周知的原因，它的网络非常不稳定，我上传了很多次本书的PDF都没有成功：

![](img/5a92f090bed6576e85b5761b26a52cd4.png)

再试试支持超长上下文的Claude吧，发现它有10MB的附件限制，而这个PDF文档是11.3MB，超长限制😭

![](img/06846f68da4041c4a5febdd85fbab0f7.png)

还有什么办法呢？这时候，耳边响起了“kimi”的声音！

---

### **Kimi - 吞下整本书**

这里的Kimi可不是王者荣耀背后的天美，而是月之暗面公司推出的、类似ChatGPT的大模型聊天机器人。

kimi.moonshot.cn/

![](img/9e471495e347c43efb9d9dece9fc154f.png)

它的特点就是支持超长的上下文，能输入长达20w字：

![](img/9dc89fc16297bf455b28bd9a6b856e47.png)

真的假的？试一试就知道了：

![](img/d44c28c88336bbaedf2545157ea7100b.png)

厉害🐂🍺！一口气吞下整本书！看了一下这本书的出版信息，字数为“300千字”，超过20w了！

![](img/50aa3b922a7d76d9a070d0b1e370bc98.png)

当然，要获得对知识点掌握程度的了解，最直接的方式就是“做卷子”，这是我们从小到大学校教育根深蒂固植入脑海的。那么，就让Kimi出题吧：

### **Kimi - 费曼学习法**

为了更加深入地掌握知识，一个常用的方法是“费曼学习法”。就是通过向别人讲解你对一个知识点的认识，以教带学，在解释不清楚时再返回去进一步学习：

![](img/395dde2863acb8f570995c3a370c5927.png)

Kimi可以变成实践“费曼学习法”的绝佳拍档。你可以先做听众，让它给你解释某个概念，自己不算发问，从而加深对知识的理解：

![](img/3b2f26d81908b2497a307dbaaa16b3c6.png)

Kimi会使用一些简单易懂的比喻来解释“反向传播”的概念，这时候我可以对它的解释加以质疑，进而进行讨论：

![](img/e33bf74e50f0177d44613e6f9fae68fe.png)

当然，更具挑战的是让Kimi作为听众，你作为解释者：

![](img/97841d12b163b08801aceb39db0ce2cb.png)

它想要知道CNN是什么概念？我也用类比的方式做了解释，Kimi发表了评述并进一步追问：

![](img/3480f960a5a215db77ccead9c178b233.png)

通过对这些问题的进一步探讨，可以将我引到知识的深处。

### **小结**

上面就是我用Kimi这个支持超长上下文、能吞下整本书的大模型聊天机器人来复习、深入学习《深度学习入门》这本书的工作流。Kimi在知识梳理、知识点讲解、出题测试、费曼学习法等学习的各个方面，都是一个非常非常棒的“同学”。我今年有一个“大模型”相关的基础知识的读书计划，我会每读完一本书、啃完一篇paper，都和Kimi一起复习一遍。

希望你也能用Kimi来帮助自己成长，强烈推荐！
