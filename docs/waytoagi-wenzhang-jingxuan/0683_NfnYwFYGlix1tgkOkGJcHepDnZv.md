# **二、BOT亮点**

### 书籍内容客观完整

站在读书爱好者的角度，提供客观、准确、清晰、详细的故事脉络，以及热门豆瓣点评供参考，引用原文撰写故事详情，提供书中最热金句，让用户直观得感受到只属于这本书的文字魅力，而非千篇一律。

### 书籍摘录专属效果

根据搜索的书籍，显示其原文原句，并带光影效果。

![](img/fd65258f958fdf88dd798e0835b51697.png)

### 书籍插图专属封面

根据书籍内容提取关键字，并生成高度相关的文艺插图

### 书籍推荐如你所愿

基于用户搜索的书籍风格与内容，推荐多本同类书籍。

# **三、BOT使用场景**

在信息爆炸的当下，短视频、碎片化学习的方式充斥着我们的生活。 读书博主摘录书籍片段感悟人生，原著改编后的影视作品再转化为短视频一刷停不下来，种草安利的畅销书籍比比皆是。而当所有的碎片组合在一起，也只是书中一个小小的角落。 所以，希望这个BOT可以为如下目标用户解决问题：

### 激发阅读兴趣

为 碎片化读书的人 了解书的全貌，并激发其阅读整本书的兴趣。

### 寻找适合自己的书籍

为 阅读爱好者 快速定位书籍是否适合自己，并推荐相关类型的书籍。

### 交作业

为 拖延症同学 快速了解书籍内容，并为其二次创作提供思路。

### 读书博主利器

为 读书博主 提供利器，高效学习与产出，还能送你一张专属封面加持。
