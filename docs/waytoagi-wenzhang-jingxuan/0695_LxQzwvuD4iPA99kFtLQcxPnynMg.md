设计背景

+   工业和信息化部等六部门联合印发了《算力基础设施高质量发展行动计划》，从计算力、运载力、存储力以及应用赋能四个方面提出了到2025年的目标。

+   国家统计局数据显示，2022年全国研究与试验发展（R&D）经费投入总量首次超过3万亿元，达到30782.9亿元，比上年增加2826.6亿元，增长10.1%。这表明国家对科技创新和算力设施的重视和持续投入。

+   我国算力设施产业链规模巨大，已达到万亿元级别。根据中国信息通信研究院的测算，2022年我国算力核心产业规模达到1.8万亿元。预计到2023年，中国算力产业规模将超过3万亿元。

+   在企业数量方面，截至2024年3月，全国算力存量企业共有75,343家。其中，广东省、北京市和江苏省的企业数量位居前三，分别有10,315家、7,167家和6,728家。此外，人工智能企业数量也超过4400家。

Bot简介

+   如此大规模的产业链中，每年都会诞生无数的商机，而这些商机杂乱无章散落在线上线下的无数信息渠道中。

+   作为产业链中的厂商每年都需要有专门的助理来不断搜集和整理商机信息，来为公司销售团队Pepline输入线索，指引优秀的销售们攻城拔寨签单收款。

+   这款小工具是一个算力商机信标：帮助销售团队在每周商机例会发现整理商机并制定销售Pepline，适合算力产业链厂商的销售部门小工具。方便数据中心厂商、服务器、交换机、网络通信及承建方等快速对接商务信息。

+   借助固有数据库和网络中的可靠商机信息源，汇总整理最新的算力设施投资规划项目和成型的标的，提供信息给产业链不同角色参考决策。设施总包承建可以借助算力规划文件公布信息提前介入对应政府相关部门，服务器、网络通信等供应商可以借助招标信息快速对接相应的总包方。

#### 功能构思

通过对政府算力建设规划文件的深入分析和精准提取，为企业销售团队提供有价值的信息指引。

技术实现原理主要是运用有效的搜索策略，在各地政府网站和知识库中检索相关文件，并进行全面准确的分析和总结。

后续使用场景广泛，比如为数据中心承建方、服务器供应商、网络通信服务商等企业在销售决策、市场布局等方面提供有力支持。在商业化场景中，能帮助企业更高效地获取商机，提高市场竞争力，降低市场调研成本。

#### 预设问题

新商机：提供公布过算力设施规划的地市信息

商机挖掘：选定地市深入了解其规划

新大单：通过工作流，从头条的可信商机信息源获取实时的算力设施标的信息

市场信息：通过对知识库检索，解读产业链上下游商业动向
