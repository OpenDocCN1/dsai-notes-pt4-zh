# 大赛简介

H**B（ HB - Human V**S. Bot: “谁是人类”）是由 WayToAGI 主办，阿里云百炼和通义千问 赞助发起的 AI 共学活动，大赛设置连续三轮迭代式初赛和一次决赛，鼓励专业人士及 Agent 爱好者们制作 AI Agent 及创意性赋予 AI Bot 人设，比赛谁的 bot 更让人难以分辨，让更多人在动手学的过程中感受 Agent 拟人化的魅力。(必须使用通义千问 API）

WaytoAGI是什么：[通往AGI之路介绍.pdf](https://waytoagi.feishu.cn/wiki/BgNowitGribx9NkXOnyc0FZ5n1f)｜[知识库有什么｜感谢银海 inhai](https://waytoagi.feishu.cn/wiki/JU9fw2gqBi7hbakzNJgcSYlln5S)

![](img/2f9baf073a56208e74d95ff7f9b9658a.png)

### **比赛目标：**

> 通过** AI Bot 拟人化比赛**，带大家一起提升 Prompt 书写能力，通过多轮比赛和分享来加深对 AI Agent 的学习和理解。

### **活动形式：**

> 在一个活动群[里，主持](https://waytoagi.feishu.cn/wiki/Gm72wS4BqixefikquThcERlgnD0#OkXJdXzlXo8h5IxeNf6c1hlcnyg)人出题，AI机器人+人类卧底潜伏在微信群中回答问题。一场比赛6-8轮，每轮群众选出谁是人类。详细见: 比赛规则
