## 六、搭子匹配功能

一个人学习可能孤单且容易放弃，但结伴而行能走得更远。我们为你搭建桥梁，帮你找到志同道合的学习伙伴，让共学之路充满动力与乐趣。

为确保最高质量的匹配体验，本功能将分两个阶段推出：

#### 第一阶段：自主寻伴（当前已开启）

+   **如何参与：在**每期的训练营中填写【入学申请问卷】，告诉我们你的学习节奏、目标领域和期望的伙伴风格。

+   如何操作：我们将所有填写问卷的同学信息汇集成一个 “搭子寻伴墙” 。你可以主动浏览，直接联系你觉得同频的小伙伴，开启你们的共学之旅。

+   **核心优势：自由、主动、无限可能。你可以基于第一印**象和详细资料，寻找最让你感到投缘的搭档。
