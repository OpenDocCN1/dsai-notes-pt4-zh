目前，该时间表重点报道了 2023 年 8 月之前的时期。尽管可能会发生一些在此时期之后发生的事件，但它可能会错过该时期之外（特别是在此时期之后）的重要发展。

这是美国[人工智能](https://en.wikipedia.org/wiki/artificial_intelligence)研究组织[OpenAI](https://en.wikipedia.org/wiki/OpenAI)的时间表。它由一个名为 OpenAI Incorporated 的非营利实体和一个名为 OpenAI Limited Partnership 的营利性子公司组成。 OpenAI 宣称的目标是进行人工智能研究并为友好人工智能的进步做出贡献，旨在促进其发展和积极影响。

## 完整时间表

### 纳入标准

选择以下事件包含在时间线中：

+ OpenAI 的大多数博客文章都描述了他们研究的重要进展。

+ 产品发布，包括一般模型和软件。

+ 伙伴关系。

我们不包括：

+ 有关公司内团队到达和离开的综合信息。

+ OpenAI 的许多研究论文并未在完整时间线上单独列出，但可以在讨论页面上作为附加条目找到。
