```
# 爆款标题评分模型（简化版）
def title_score(title):
    power_words = [&quot;暴利&quot;, &quot;揭秘&quot;, &quot;亲测&quot;, &quot;躺赚&quot;]  # 从数据中提取的高权重词
    emoji_score = sum([1 for c in title if c in [&quot;🔥&quot;,&quot;💸&quot;]])
    length_penalty = -0.5 if len(title)&gt;20 else 0
    return sum([3 if word in title else 0 for word in power_words]) + emoji_score + length_penalty
```
