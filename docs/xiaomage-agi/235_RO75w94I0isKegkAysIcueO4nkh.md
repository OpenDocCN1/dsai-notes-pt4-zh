# 国产AI大模型盘点

> 来源：[https://xmgtoagi.feishu.cn/docx/SlG3dUuhqomoWjxleXRcCa8znMb](https://xmgtoagi.feishu.cn/docx/SlG3dUuhqomoWjxleXRcCa8znMb)

1、**海螺问问**

https://hailuoai.com/chat

由上海稀宇科技有限公司（MiniMax）开发，公司估值20亿美元，融资达2.5亿美元。

![](img/ba7fc3faa9ced8baa42c0369d5d69cdd.png)

看起来是一个平平无奇的聊天机器人，但是凭借语音大模型 abab-speech-01，海螺不仅能用超自然高保真的语音跟用户聊天，还能用30秒的样本让用户克隆自己的声音。

就像高德地图能用自己的语音包导航那样。

不过这个功能目前网页端没有找到设置入口，还要下载个手机APP才行。

![](img/1be5a2feb2e15a3ba0f5db3e9f989026.png)

是的，郭嘚嘚就是高德地图里孜孜不倦指路人以及中年男人哄睡神器郭老师。

理论上你可以丢给海螺问问一本电子书，然后选择郭嘚嘚的声音朗读全文，或者克隆自己男神/女神的声音，聆听效果更佳。

2、**Kimi Chat**

https://kimi.moonshot.cn/

由月之暗面开发，可支持20万汉字上下文处理，团队目前估值7亿美元，融资达20亿人民币。

前一阵子哄哄模拟器爆火后，创始人王登科为应对庞大的token消耗，紧急求助的国内大模型团队就是他们。

![](img/a843f39641577cdeb13142d8d28777bc.png)

这首页的超长文本例子就透着豪横，硅基君偏不用他们提供的例子，自己上传一份118页的人工智能发展白皮书试试。

![](img/007976afb6f70251a6f641dc274d88fa.png)

Kimi还真的发动了量子速读的技能给整理出一份文件大纲。

![](img/65fd63c45c57c9d7ab0d116e0b5a6e1a.png)

3、**百川大模型**

https://www.baichuan-ai.com/home

由百川智能开发，公司估值18亿美元，融资达3亿美元。

发布的超千亿大模型Baichuan 3，在中文通用能力测评（CMMLU、GAOKAO、AGI-Eval）上超越GPT-4。

实测联网搜索和信息整合能力确实还不错，就是这个界面略简陋，一个不重要的历史对话栏占了页面的三分之一。

![](img/209ec3180442a23c1cffc6a2e37739be.png)

4、**智谱清言**

https://chatglm.cn/

由智谱AI开发，公司估值140亿人民币，融资达25亿人民币。

清华背景，自研预训练算法框架GLM，开源模型在技术社区Hugging face和GitHub广受好评，获国内一线投资方青睐… 可谓叠满了光环。

一次回答里就能接连实现联网搜索、信息整合和文生图，先不评价内容质量，就冲这效率当头脑风暴点子也赚了。

![](img/17c1c95ebc4e321633d0170d8a2625f3.png)

其次咱们看看**视频生成类工具**，这块硅基君找到不少应用，但是一个个试下来发现大家对“视频生成”的概念理解多少有点偏差。

以百度出品的**度加创作**为例，这类工具目前能做到的是根据一个主题生成视频文案，然后根据文案搜索相关视频素材。

https://aigc.baidu.com/home

![](img/ffeb9e35d0ab39605511e6d12a5dd57a.png)

然后根据脚本生成配音，并把素材剪辑到一起，形成一个看起来有点怪但还说得过去的小视频。

![](img/9de4579a815f7ff249f0a456048b2fc9.png)

抖音正在公测的**即创**也是类似的逻辑，只不过增加了一个数字人的功能，等于给你提供了一个免费的主播。

https://aic.oceanengine.com/

![](img/f49f53f6dca0f793c0f7651bca304fb6.png)

数字人绘声绘色的讲解看起来还挺自然，预感之后要出现主播行业被数字人替代大规模裁员的新闻了。

![](img/2a0945a3cdcfca3308df25af7b7f264d.png)

其他类似的工具还有一帧秒创、一起剪、万彩AI，但都是在现有素材上的拼接成片。

上面这些工具没能达成真正的AI视频生成，不意味着国内没有Sora平替。

智东西对8款国产AI视频生成工具进行了测试，模仿Sora发布的六个Demo场景，从四个维度进行了打分。

Sora女子街道散步Demo，8家表现可圈可点

字节海外版的CapCut AI Video以稳定的表现和良好的成像质量排名第一。

按总分从高到低，其余7家为：Morph Studio、NeverEnds、MewXAI 艺映AI、腾讯 VideoCrafter2、爱诗科技 PixVerse、右脑科技 Vega AI、智象未来 Pixeling。

视频生成路漫漫，要颠覆影视行业还需继续努力。

**AI音乐生成**方面，网易云一站式创造平台**网易天音**，据说可以像Suno一样无需乐理知识，只输入灵感就能一键生成音乐。

![](img/c316cfaa8fa519a33ba0a40346c73bda.png)

可惜目前只对白名单用户开放Beta测试，从界面上来看应该是打算从小白用户服务到专业用户，AI生成音乐和AI编曲辅助功能应有尽有。

![](img/c434be96c19d618ef66bfe365923e22c.png)

拿不到大厂的内侧，硅基君现在唯一能用上的国产文**生音乐应**用，是一家清华背景的初创公司做的BGM猫。

https://bgmcat.com/home

![](img/558d9e819a4e6bc42bdb8f6f90f47204.png)

在选了音乐长度、场景和心情之后，BGM猫迅速给生成了一段8bit风格低保真的抽象音乐，从成果上来看是好的，但是从质量上来看存在的意义不大。

WNRj_BGMCat,新硅NewGeek,1分钟
