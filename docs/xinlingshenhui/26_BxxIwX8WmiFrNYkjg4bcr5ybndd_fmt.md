
# 角色一致 `--cref`

![](img/f2c6f394bc12584d66e3da9154dc651e.png)

今天MidJourney终于发布了类似的功能，名为“角色参考”。想象一下，您是一名插画家、动画师，或者只是一名艺术爱好者，想要以不同的姿势创建角色设计的多个版本 - 这个功能正是您所需要的。

## 什么是角色参考？

角色参考是 MidJourney 中的一项新功能，允许用户根据给定的参考图像从不同角度生成相同的角色。

这与“样式参考”功能类似，但它不是匹配参考样式，而是尝试使生成的字符与参考图像中的字符特征相匹配。

## 怎么运行的

首先，先生成您的角色设计。下面是一个提示示例：

> 在白色背景上创建高度详细的 Pixar 3D 游戏角色渲染全身镜头。这个角色是一个十几岁的小伙子，头发微卷，有点胖，穿着黑色连帽衫和蓝色短裤 `--s 250 --v 6.0`

![](img/dfe9e54f527395602ae7808989dab763.png)

选择生成的图像保存下来

然后这次将刚才生成的角色图上传在人物一致，修改原提示词的细节，比如加他正在挥手，跳舞，奔跑等。

> 所以你的新提示将如下所示：

> Create highly detailed Pixar 3D game character rendering full body shots on a white background. This character is a teenage boy with slightly curly hair, a bit chubby, wearing a black hoodie and blue shorts. He is running `--s 250 --v 6.0 --cref https://s.mj.run/-agsEOCX3Vs --cw 100 --ar 3:4 --v 6.0`

瞧！生成的图像应该看起来与参考几乎相同，但现在角色正在挥手。

然后，您可以生成不同姿势的角色的多个版本。可能性是无止境。

![](img/d35780010f9c635a831158d23bc49997.png)

> **注意：您可以通过更改** `--cw` 选项的值来更改参考图像对最终结果的影响。

+ 调整 `--cw` 值，将链接的“强度”从 100 更改为 0

+ 强度 100 (`--cw 100`) 是默认值，考虑到面部、头发和衣服。

+ 强度值为 0 (`--cw 0`) 仅关注脸部（对于更换服装、发型等很有用）

## 注意

请记住，角色参考仍处于测试阶段，MidJourney 团队警告当前存在一些限制：

+ 当使用从 MidJourney 中生成的图像创建的角色时，此功能效果最佳。它不适用于真实的人/照片（并且很可能会像常规提示一样扭曲它们）。

+ `Cref` 的工作方式与常规提示相同，只是它“专注于”角色的特征。

+ 该技术的准确性有限，无法准确复制 T 恤上的酒窝、雀斑或徽标。

+ `Cref` 适用于 Niji 和常规 MJ 模型，也可以与 `--sref` 结合使用

基于单一参考在几秒钟内生成不同姿势的角色的能力绝对是突破。创作者必须尽快学会适应和使用这项技术，才能让它达到完全取代艺术家的水平！
