
# 无缝图案参数 `--tile`的使用

> 来源：[https://my.feishu.cn/docx/CXV9dH3PLoteRdxPPzacGUUynVf](https://my.feishu.cn/docx/CXV9dH3PLoteRdxPPzacGUUynVf)

![](img/7feadf42510402578a55fe7604a6e046.png)

Midjourney允许创建无缝图案，这些图案在重复时可以完美匹配。这是通过使用`--tile`参数来实现的。使用这个参数，您可以得到一个图案，重复多次后，可以创建一个连续的设计。

这些图案特别适用于创建壁纸、织物或纹理的设计。当您应用`--tile`参数时，Midjourney会根据您的请求提供四种图案选项。

在提示词词框中输入提示词，并在最后打开`--tile`参数按钮

无缝图案是一种设计工具，可以为任何区域增添视觉趣味。它们用于时装和纺织品中，在服装和配饰上制作印花，也用于壁纸、窗帘和其他装饰元素的室内设计。无缝图案还用于创建产品包装设计和界面元素。
