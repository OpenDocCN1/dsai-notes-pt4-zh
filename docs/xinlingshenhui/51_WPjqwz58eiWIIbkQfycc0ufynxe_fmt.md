## 技巧 #5：MidJourney V6 中的此设置是您值得信赖的朋友

如果您曾经面临必须为 MidJourney V6 选择一种魔法的情况，那么毫无疑问，Style Raw 就是您的最佳选择！

我注意到很多人在图像效果没有达到预期效果时感到困惑，但通常滴一点 Style Raw 就能解决问题。 👀

那么让我们看看这个简单的技巧如何在 MidJourney V6 中为您的图像创建带来巨大的改变！

✨ Style Raw 的用途是什么？

Style Raw 是对 MidJourney 的指示，默认情况下使用较少的美学/美感，这将导致严格遵循您的提示写作说明，尤其是对于某些样式。它消除了一些花哨的东西，例如过于复杂的样式、图像构图和照明，使生成的图像看起来更加原始和自然。因此，用一句话来概括，Style Raw 是一款专为希望更好地控制图像的 MidJourney 用户设计的程序。

![](img/4b475680f327854ff2dff6a3c0cf778e.png)

✨ 对于哪些图像最适合使用 Style Raw？

+ 图像看起来“非常”像真实照片

（有关这方面的更多信息，请参阅[本文的第 1 部分](https://vc.ru/midjourney/1001759-midjourney-v6-11-moshchnyh-priemov-napisaniya-promptov-o-kotoryh-nikto-ne-govorit-1)，“提示写作技巧 #1 - 想要创建看起来像真实照片的图像？请 MidJourney 让它们变得更丑！”）

+ 带文本生成的图像
+ 更多不寻常/幻想图像

如果您想创建更多不寻常/富有想象力的图像，例如空间中长着西瓜头的猫，使用 Style Raw 将有助于通过仔细聆听提示而不是使用标准风格和创造力来指导 MidJourney。

+ 包含大量细节的复杂提示

如果您的提示有很多重要元素，添加 Style Raw 可以使 MidJourney 更有可能关注细节。然而，重要的是不要包含不必要的词语，以免削弱主要细节的重要性。

+ 当您经过多次尝试仍无法创建完美图像时

这并不能保证，但通常添加 Style Raw 以及降低 `--stylize` 值（低于 100）可以解决问题。 😉

## 技巧 #6：创意枯竭？为什么不让中途狂奔呢？！

感觉创意受阻？无法找到新鲜、不寻常的创意来创建图像？ 😵

您知道有一种秘密成分可以让 MidJourney 狂野起来吗？谁知道呢，也许您会从 MidJourney 的创意大脑中得到一些新想法！

`--混沌` 是一个经常被忽视的选项，但却非常强大。让我们一起投入混乱，激发您的创造力！ 🌪🎨

![](img/3be075595ded732bfd1c7a5d23b972c5.png)

### 混沌有什么用？

+ `--chaos` 选项会影响生成的初始图像网格的可变性。
+ `--chaos` 的默认值为 0（无可变性）。
+ 其值可以在 1 到 100 之间变化。
+ 较小的 `--chaos` 值给出更准确和稳定的结果。
+ 更高的 `--chaos` 值将产生更多不寻常的结果，以及意想不到的图像构图 - 是的，这就是我们正在寻找的！

### 混沌对您的图像的影响

#### 低混乱值（0-15）

✔ 提供最一致的结果，最适合您想要可预测结果的情况

❌ 限制创造力/进一步实验的水平

#### 平均混乱 (15-30)

✔ 可预测性和创造力之间的良好平衡。

✔❌ 这是“实验领域”，引入了一些随机性，可能会使结果更难以控制。

#### 高混乱值（30-100）

✔ 给予 MidJourney 完全的创作自由，让他尽情驰骋；如果您需要额外的灵感，这是理想的选择

❌ 提示的重要性明显降低，并且可能导致非常不可预测和“混乱”的结果
