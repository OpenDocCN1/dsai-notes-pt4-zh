
# ChatGPT 高级用户的演变。以下是我在使用 ChatGPT 的 1000 多个小时中学到的 5 个最重要的经验教训

> 来源：[https://my.feishu.cn/docx/EVs9dnxdWoCuw0xPgEOcYoMknze](https://my.feishu.cn/docx/EVs9dnxdWoCuw0xPgEOcYoMknze)

![](img/258a49a4dc9a08de12c3050352b6abc5.png)

我与 ChatGPT 的关系很复杂。我几乎尝试了它能做的所有事情，详细分析了它的结果，并使用 API 创建了许多应用程序和工具。可以想象，自 ChatGPT 推出以来的一年半时间里，我对其功能的看法发生了很大变化。

老实说，我对 ChatGPT 的看法并非全部都有所改善。事实上，随着时间的推移，我对某些用例的印象已经不那么深刻了。有几天我对他的结果感到惊讶和震惊。也有几次，我厌恶地关闭了聊天室，惊讶于它是多么可怕和不体贴。

然而，我坚信，了解 ChatGPT 的优点和缺点是成为该领域专家的唯一途径。虽然我仍然不自称是专家，但我相信我走在正确的道路上。

**以下是我在使用 ChatGPT 的 1,000 多个小时中学到的五个最重要的经验教训。**

## 第 1 课：信息为王。

ChatGPT 依靠您提供的信息而蓬勃发展。如果你剥夺它的信息，它每次都会产生糟糕的结果。

![](img/e31c883f5011344f966560e3723c542a.png)

对我来说幸运的是，我很早就发现了这一点。事实上，几个月前我写了一篇关于此的文章，名为“ChatGPT 最重要的提示”。提示很简单：

> 在开始之前，请向我询问您对此有任何疑问，以便我可以为您提供更多信息。请尽可能详细。

从本质上讲，提示会导致 ChatGPT 通过询问您想要什么的问题来收集更多信息。到最后，只有你自己知道自己想要什么。这样，他就永远不会假设、产生幻觉（在某种程度上）或错过任何关键的事情。我每天都会使用这个提示。

尽管本文的主题是进化论，但在“发现”这个提示八个月后，我仍然认为这是最重要的一课。如果您没有向 GPT 提供足够的信息，它永远无法满足您的需求。

ChatGPT 就像一个人类助理，为您提供无尽的帮助，但太急于取悦您，又太胆怯而不敢问您后续问题。

他会逃跑并尽力而为，但回来时往往会带来令人失望的结果。您应该通过专门要求 ChatGPT 从您那里获取更多信息来消除这种胆怯的障碍。这会增加您花费的时间，但相信我，这是值得的。

## 第 2 课：提示（在大多数情况下）是浪费时间。

随着时间的推移，我意识到很少有提示能够真正显著提高结果质量。这是因为，正如我在第一点中所说，信息为王。

然而，我发现有一些非常有效的提示写作技巧，例如经典的“一步一步思考”技巧和 COSTAR 框架：语境 (C)、目的 (O)、风格 (S)、语气 ( T）。

然而，我发现大多数即时写作技巧，尤其是花哨的技巧，都是毫无用处的。我必须强调，在我作为 GPT 用户的发展过程中，我始终回归到一个重要的想法：

像对待一个人一样对待 ChatGPT，您就会成功。

这就是你真正需要的。 ChatGPT 已经接受了数十亿次人类互动的训练，那么为什么它不应该保持人性化呢？

每次使用 GPT 时，有意识地思考：“如果我将此任务分配给一个人，我还会向他们提供哪些其他信息或指示？”我确信你会看到 GPT 输出的质量得到提高。

## 第 3 课：在写提示之前先思考一下。

在开始与 ChatGPT 交互之前，您必须了解面临的任务。如果你不知道自己需要什么，你怎么能期望 ChatGPT 能够做到呢？

![](img/5c6eef8db00cdbfda266f47763a87f77.png)

这是一堂比较简单的课，但是我觉得非常重要。在要求 ChatGPT 为您做任何事情之前，您必须明确自己的真实目的。如果你不知道自己想要什么，那么你100%肯定会失望。

第二课在这里派上用场：如果你试图给某人一项任务，但你不知道自己想要什么，那么你永远不会对结果感到满意。你会发现自己在一个低效的循环中一遍又一遍地迭代。花五分钟思考你想要什么，或者至少使用 ChatGPT 来帮助你集思广益。

当您开始思考您需要什么时，您将不可避免地开始更好地向 ChatGPT 描述您正在寻找什么。结合第 1 课，这将对您有很大帮助。

## 第 4 课：知道何时重新开始。

有时您只需要开始新的聊天。每当我编写非常复杂的代码或进行故障排除时，有时 ChatGPT 无法满足我的需求。他忘记了，关注了错误的事情，无法理解我想改变什么，不想改变什么。他被过去尝试的混乱背景所毒害。

![](img/f9cdd49e3b10628a97bc7fa61a27b096.png)

当我输入大约十条充满代码块和 ChatGPT 输出的大消息后，它经常开始崩溃。然后我明白有些事情需要改变。我将从这次聊天中汲取教训，并将其汇编成新聊天中的一个大提示。几乎每次，新的聊天中新发现的清晰度和焦点都能解决我的问题。这在解决大规模写作或编程任务时特别有用。

随着时间的推移，您将开始感觉到何时需要新的聊天。我意识到这一课比之前的课程更难学习和实际实施，但下次您深入了解几篇文章时请尝试一下，我相信您会看到不同。如果与下一课结合起来，那就特别好......

## 第 5 课：在 ChatGPT 中一次执行一项任务

ChatGPT 在一定程度上具有多任务处理能力。这个程度虽然根据任务内容的不同而有很大差异，但我不太喜欢处理这个问题。所以我学会了在 ChatGPT 中一次只执行一项任务。

![](img/807012bda310ec75d29f7106e78a55d2.png)

ChatGPT 无法煮沸海洋。当你试图一次从中提取太多信息时，它就会失去连贯性。在构建基于 GPT 的应用程序或工具时尤其如此；将每个人工智能实例的责任减少到尽可能小的任务非常重要，这样它才有更好的机会产生一致且正确的结果。

例如，如果你要求人工智能写一篇关于某件事的博客文章，你需要从大纲开始，并要求它只写特定的部分。这不仅提高了结果的长度，而且提高了其周围内容的细节、清晰度和统一性。

这并不适用于 ChatGPT 的所有用例，但我的经验法则是：如果你要求 ChatGPT 一次做 5 件以上的事情，你只会得到一个糟糕的结果。把事情简单化！
