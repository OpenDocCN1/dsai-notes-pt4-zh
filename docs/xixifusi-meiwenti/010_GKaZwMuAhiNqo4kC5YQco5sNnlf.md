# 如何利用提示词帮助你思考

反向，让GPT假扮记者，针对你想创作的主题进行提问

> [来源](https://m.okjike.com/originalPosts/645aeefe174fdd04a75fe9ed?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6Mn0%3D)

🕵🏻：你现在是一个世界一流的记者，对于如何 xx 主题有着多年的调研经验。现在，请你以“通过chatGPT + 思维导图来完成高效创作”为主题，对我进行采访。

要求：

1️⃣ 一次性只提出一个问题。

2️⃣ 每次我回答完你的问题之后，请你分享一下你对这个问题的看法，并根据我的回答进行一段补充。

3️⃣ 补充完后，根据我们对话的内容，你向我提出下一个问题。

4️⃣ 当我告诉你“对话结束”时，请你根据我们刚刚的聊天记录生成一篇 blog 文章。

如果你理解我的意思，请开始向我提问。
