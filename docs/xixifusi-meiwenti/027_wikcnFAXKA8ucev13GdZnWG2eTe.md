# 1 ZJUSCT

对浙大部分网站的某些反人类设计不爽很久了，趁最近摸鱼时间比较多，写了个脚本改进了一些细节。

包含如下主要功能：

+   【图一】教务网成绩单均绩计算、隐私自动打码

+   【图二】学在浙大未开放权限课件PDF、视频下载

+   【图三】跳过ZDBK开屏连续通知弹窗

+   【图略】跳过诚信考试承诺书30秒倒计时

+   【图四】教材查询显示所有教材信息

+   【图五】教务网自动跳过“新版登录”“ckc荣誉证书”

+   【图六】补退选显示开课教师姓名

+   【图七】选课系统显示所有课程分类

+   【图八】学在浙大附件展开逻辑优化

+   【图略】CC98搜索自动刷新

具体效果可以在图中查看。
