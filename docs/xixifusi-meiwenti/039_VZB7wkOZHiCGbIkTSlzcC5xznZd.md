## 超级个体有什么特点？

第一，净利润第一，而非规模第一。

第二，创始人核心制，一号位即为战略、战术的核心操盘手。

第三，单点突破，要么是内容营销 IP 能力，要么是直播操盘孵化，要么是销售能力，在单点爆破产产生利润。

第四，流量、销售、产品三角形系于创始人为核心的团队机制中，操盘手机制驱动。

第五，一般起于流量红利，但也亡于流量红利消亡。

第六，极端依靠平台势能，要么抖音、要么私域、要么📕。

第七，小团队，低人力成本、超高人效，人效和利润来自于创始人的血泪和历史红利。

第八，不稳定，需要不断续命折腾，每 3 年渡劫一次。

第九，团队年轻，90 后的操盘手、00 后的团队打手，容易出现操盘手跑路成为友商。

第十，不融资、不合作，靠自己，利润驱动，利润结余支撑下一波利润。
