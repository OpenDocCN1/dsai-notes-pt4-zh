开源自我，对于个人成长，有着巨大的益处。

我把公开写作、面向自我写作比作**向宇宙发射信号**

多一些公开写作和自我教育，会获得意外的成长。

+   在社交平台获得高质量人的「连接」和幸福感，可以很快的和素不相识的人们建立信任感；是一种高效的社交方式；你需要一个公共写作的舞台，而不是炫耀的圈子；通过写作，你定义了自己

+   文章、视频有很强的**复利性**，**门槛最低**的强杠杆，默默地在帮你做一些事情，影响一些人；Compound yourself 选择“复利增长”，相信指数曲线

+   文章、视频都是你的「作品」，是你最好的简历，多元的展现你自己；建议你的话语权，你自己的个人优势

挑战：

+   你需要强大的内心，需要接受批评，接受质疑

+   你需要强大的内心，愿意敞开心扉绽放自己

谨慎公开表达陷阱

经常公开写作，会让自己有个幻觉

以为自己写过的东西，自己都「懂了」「实践了」

然后就开始追逐下一个概念，方法

这样充其量只是知晓某些名词，成为一个懂王而已
