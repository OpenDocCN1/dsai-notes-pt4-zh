
# 如何优雅地参加第一场黑客松

> 来源：[https://docs.feishu.cn/docx/WbP7dfN6CoPsl5xxYnKcxnpKnod](https://docs.feishu.cn/docx/WbP7dfN6CoPsl5xxYnKcxnpKnod)

仔细想想，距离我参加上一次黑客松可能都得一年多了。

明天就是 AdventureX 2025 的第一天了，因为是很多年轻人的第一次黑客松，很多年轻 Hacker 不知道应该做什么，我就来写点 Tips。

本来想写的有结构一点，赛前、赛中、Pitch、赛后每个细节都点一下，后面还是想想，如果把这些乐趣提前泄密就不好玩了。于是就精简到 14 条。

![](img/36f1f5dc9a18569350cd64ef52db050e.png)

> 22-24年参加过的线下Hackathon合集

1. 想清楚来的目的是什么，如果你的收获只是奖的话，那可能是最无聊的
2. 用作品和 vision 寻找合适的队友，我和我的合伙人就是在黑客松上开始合作的；如果没有找到也不用强求，一个人也是可以参加黑客松，开始做比较重要（好像主办方得至少两人组队，那大家加油）
3. 永远不要停止创造，多花时间在 build 上。时间有限，优先级最重要，产品可以尽可能简单而不是大而全，专注把最重要的部分实现
4. 主动 social，求助提问，互相交流
5. 提前部署环境，沟通技术栈；使用一些现成的组件、工具
6. 相信直觉，做你想做的产品
7. 不要沉迷 vibe coding
8. 完成比完美重要
9. 要独特，讲你独一无二的故事
10. 吃好睡好
11. Have Fun
12. 记得和队友拍张合照：）
13. 发布产品，而不只是发布 Idea。发布到朋友圈、📕、Twitter，让更多人看到
14. 别被风险投资和虚名 Noise 裹挟，核心是把专注你的产品做好。（几天是不够的，如果你想继续做好你的产品，也欢迎来找我）
