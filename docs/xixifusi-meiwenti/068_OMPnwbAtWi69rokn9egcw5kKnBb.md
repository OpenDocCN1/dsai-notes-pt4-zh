# 克服「生产力色情」

> 来源：[https://docs.feishu.cn/docx/CLjNdkNRHow05jxiKFFcH5qgnwe](https://docs.feishu.cn/docx/CLjNdkNRHow05jxiKFFcH5qgnwe)

定义：花费大量时间和精力关注与生产力方法和实践相关的内容，但是没有实践到真实工作中。

为什么会陷入生产力色情？生产力色情满足了我们的幻想 。

如何解决？

+   留出专门的时间进行生产力色情

+   专注核心本质

+   思考自己的效率目标

+   寻找适合自己的生产力系统

+   虽然很强大，但是不适合你

+   虽然很强大，但是现实上你不需要他

+   要想快速提高效率，首要的不是找工具，而是立马行动。
