# 「比尔盖茨给2023届毕业生的5点忠告」

> 来源：[https://docs.feishu.cn/docx/E6nDdMFb9o9k9Exe5fJcQuOLnqd](https://docs.feishu.cn/docx/E6nDdMFb9o9k9Exe5fJcQuOLnqd)

据华尔街日报(WSJ)，比尔盖兹5月13日应北亚利桑纳大学(Northern Arizona University)邀请出席毕业典礼，这是他继2007年哈佛大学、2014年斯坦福大学以来，第三次担任大学毕业典礼致词嘉宾。

以下是他分享给台下2023年大学毕业生的五点忠告：

**一、人生并非单一戏码：他建议毕业生思考就**业之路，不要有过多压力或限制行业，因为即使改变主意或更换跑道，不仅可被接受而且可能会更好。

二、不要过于聪明而迷失：盖兹强调学习新事物第一步即「拥抱你的不知道而非专注于你的知道」，不要害怕提问。

三、专心解决重要问题：盖兹表示，大学毕毕业生面临新行业和新公司，有人要成为森林保育员，必须学习尖端科技以对抗气候变迁；有人要从事软件工程师，就得学习人工智能 (AI)科技，为了就业而花费时间解决问题之际，会激励个人创造力，并赋予生活强烈目标感。

四、**切勿低估友谊的力量**：盖兹以大学好友艾伦(Paul Allen)共同创办微软为例，呼吁毕业生关心在校园内一起上课、玩乐的同伴，因为他们就是人脉，甚至是未来工作伙伴。

五、学会放松，不会成为懒惰鬼：盖兹坦承年轻时总爱强迫自己和周围每**个人长时间工作，**甚至早期在微软，还会记录哪个员工提前下班，但当了父亲后，才意识到生活比工作更重要；建议毕业生花时间培养人际关系，并在需要时放假休息，也让周围人可以喘口气。(via world journal)
