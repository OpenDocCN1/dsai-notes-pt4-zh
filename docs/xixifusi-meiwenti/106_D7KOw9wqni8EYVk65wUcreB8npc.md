# Shane Parrish

> 来源：[https://docs.feishu.cn/docx/MnLcdSIgaorUkzxrPl3cTx9Intf](https://docs.feishu.cn/docx/MnLcdSIgaorUkzxrPl3cTx9Intf)

1.  聪明人的一个标志是能够**从他们不喜欢的人那里学习**。

2. 有史以来最强大的生产力工具就是一个简单的词：“不”。

3. **富人拥有金钱。富裕的人拥有时间**。

4. 写作往往是你意识到自己不理解自己在谈论什么的过程。

5. 成功的90%在于不被分心。

6. 短期结果来自于强度。长期结果来自于一致性。

7. 清晰的写作让糟糕的思考无处藏身。

8. 你越想快速得到某样东西，就越容易被操纵。

9. 如果你想要新的想法，阅读旧的书籍。

10. 第一性原理思维是一种竞争优势，因为几乎没有人这样做。

11. 如果你不能在不愿意做的时候一贯地做那些无聊的事情，那么才能和潜力就毫无意义。

12. 最大的陷阱是告诉自己，你会在明天做一些重要的事情。拖延会产生负面的动力。

13. 让你的下一个项目成为人们在你的余生中会问你的事情。
