芒格的简单道理

+   钓鱼有两个重要原则，第一是要在有鱼的地方钓鱼，第二是不要忘记第一条原则。

+   芒格很喜欢以常识判断问题，但他又说，所谓常识，通常就是别人不知道的知识。

+   芒格的另一个信条，就是宁愿亏自己，不愿亏他人，永远对世界抱有善意。

+   减肥的道理其实很简单，就是少吃一点。但99%减肥的人最终都会失败，因为道理很简单，做到却很难。

+   芒格还说一句几乎像废话一样的道理：成功就是不干蠢事。
