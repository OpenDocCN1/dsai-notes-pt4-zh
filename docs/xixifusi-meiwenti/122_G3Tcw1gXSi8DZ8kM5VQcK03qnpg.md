
# 最幸福的人有哪些思维和行为模式

> 来源：[https://docs.feishu.cn/docx/XSrhdRdWWoYgqzxLtsbcKa91n9c](https://docs.feishu.cn/docx/XSrhdRdWWoYgqzxLtsbcKa91n9c)

1/ 花费大量时间在家人和朋友身上，培养和享受这些关系。

2/ 能自在表达对所拥有一切的**感激之情**。

3/ 经常是第一个向同事和路人伸出援手的人。

4/ 当想象未来时，会实践乐观主义。

5/ 品味生活的乐趣，**努力活在当下**。

6/ 体育锻炼是每周甚至每天的习惯。

7/ **深深地致力于终身目标和抱负**（例如，反欺诈、制作橱柜或把深信不疑的价值观教给自己的孩子）。

8/ 他们确实也有压力、危机，甚至悲剧，也会像你我一样感到痛苦和情绪化，但这些人的秘密武器是在面对挑战时展现出的沉着和力量。

还有——

观察真正幸福的人，我们会发现他们不仅仅是坐在那里感受满足而已。

他们让事情发生（make things happen）。他们追求新的理解，寻求新的成就，并能控制好自己的想法和情绪。
