# 绽放

> 来源：[https://docs.feishu.cn/docx/AWjwdpHbFop5Y2xl8LecXV71nTi](https://docs.feishu.cn/docx/AWjwdpHbFop5Y2xl8LecXV71nTi)

前几天听播客听到一个很好的词：绽放。

看一个人，就看这个人的状态是不是在绽放。在绽放的人，是很明显的，有那种巨大的能量可以让你感受到。

这不是什么虚的概念，就是一个涵盖的词，具象可能就是这个人正在一个很好的状态，包括享受生活、热爱自己、为喜欢的事情、东西奋斗中、清晰自己想要的目标、有行动有计划，没有抱怨，没有体现出对生活、工作、家庭等很多的不满。

这并不意味着需要我们的一切都是完美的，才能这样。

这种看待事情的心境和现状，是我们自己构建的。我们看很多东西的表现可以理解到当下很多人的困境，比如你看书的热门榜、大家的热推榜，如果有类似的：了不起的自己、勇气等，这些就是当下很多人的困惑及遇到的问题，导致现状并不好需要去解决。

主宰我们是否绽放的，是我们自己以及我们自己决定的行为。我们能理解，很多人确确实实现状并不好，遇到很多难以攻克的病痛、原生家庭、婚姻关系、生存困难。我们能做的选择，就是如何面对它，竭尽全力却不内耗。最担心的就是，想的太多，要的太少，做的太少。

用塔勒布的话来结尾：

命运无法主宰的，是我们的行为。

希望我们都进入我们的绽放状态。
