# 让自己快乐，然后好事自然发生

> 来源：[https://docs.feishu.cn/docx/PlR1devSyobEWKxTOYOcpN3hnrf](https://docs.feishu.cn/docx/PlR1devSyobEWKxTOYOcpN3hnrf)

> https://m.okjike.com/originalPosts/64720885086ac133c30eb25a?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6MX0%3D

快乐的事情使人沉迷——常年累月的沉迷带来对事情投入量的井喷——投入量的几何级增加最终带来事情做的出类拔萃——任何一件事做到突出，总是可以带来巨大的经济收益的。

每个人快乐的点各有不同。

总会有那么一两件事，别人并不觉得特殊，但是却能给自己带来无限的快乐。

以前我以为天赋是生来就具备的比他人更强的特殊能力，后来我发现，所谓天赋，不过是有那么一两件事可以给自己带来远比其他人更多的快乐。

也就是说，人人都有天赋，而快乐是天赋的毛线头。

只要顺着“能够让自己得到无限快乐”这个线索深入其中，日积月累，就会得到独属于自己的、用以区别他人的天赋。

让自己快乐是一种能力。

这句话分为两方面，（1）尝试尽量多的事情（2）给自己更多的爱与自由，不要勉强自己，在每一天的可支配时间中，尽量给自己更多的快乐。

找到真正令自己快乐的事情有个过程。

只有尝试了很多事情，才会发现在众多的事情中，有那么一两件可以给自己带来比其他事更多的快乐。就像一个人品尝了很多美食，然后发现还是最喜欢吃某几种。

为了健康与产出，让自己离开自己喜欢的看书码字去健走10分钟，需要强大的自控力，这事就带有较劲的嫌疑。

反之，看书码字正嗨的时候就尽情沉浸其中，休息的时候就去健走机上尽情享受音乐，也是沉浸其中。两边都是玩。

有一句知名的话叫做“自律给我自由”，我实践后发现，“自由给我自律”才是真理。

抖音既是一个娱乐工具，也是一种学习工具。就像听着音乐健走。

在休息日，给自己充足的时间刷够抖音，获得极大的满足，顺便也获得了知识和灵感。

然后人自然愿意去做一些更有挑战的事情，一件事情玩够了自然而然就愿意去玩下一件、玩点不一样的。

去做那些真正能让自己快乐的事情，实事求是的让自己每天获得极大的快乐。

之前的行为模式是，先做重要的事情，做腻了之后玩一玩。最终的结果是，重要的事情进度有限、玩也没有玩爽。

对于重要的事情，应付容易，持续精深很难。

改进后的模式是，给自己很多很多的“爱与自由”，每天醒来先做令自己最快乐的事情，玩爽了之后，发现重要的事情反而进度更多，比认认真真干一整天进度更多。

对重要的事情而言，战斗力比持续时间更重要。

一个人不够快乐的时候，也许会花很多时间去做一件重要的事情，但这个时候的做事状态，就像钝刀子割肉，做做停停、进度有限、久攻不下。

一个充分玩开心、玩爽的人，一个心中的快乐都溢出来的人，做事的时候无坚不摧、无刚不克。

状态一般的时候只能走平路熬时间，状态好的时候二话不说爬山上陡坡。

我身边那些远比我优秀的朋友，往往也是各个朋友圈子中最开心的人。

给自己更多的爱与自由，每天都努力让自己获得许许多多的快乐，最终，快乐的人会更有成就。
