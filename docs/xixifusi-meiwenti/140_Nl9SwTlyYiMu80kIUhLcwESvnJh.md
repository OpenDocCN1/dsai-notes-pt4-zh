# 在高度不确定的日子，如何获得更多掌控力？

> 来源：[https://docs.feishu.cn/docx/CX8vd7fiAoPIfzxQDBucM34SnTg](https://docs.feishu.cn/docx/CX8vd7fiAoPIfzxQDBucM34SnTg)

[来源](https://m.okjike.com/originalPosts/64698b5afeb4c7ae9cd2ffd2?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6Mn0%3D)

邓亚萍说，答案可以是「向顶尖运动员学习」，因为他们都有股魔力，能把看起来“不可控”的事变为可控，下面是几个例子：

1、如何将概率问题变成自信心的来源？

库里在篮球比赛最开始的几分钟，会去投一些特别离谱的球：比如在超远的地方投三分，或是明明有很多人防守，他还是硬要投篮。

为什么就不能好好投呢？因为库里在检查他的手感。如果这种很难的球都能投进，那代表今天手感很好，接下来打每一球，就都会很有自信。但没投进怎么办？没事，反正本来就很难进，投不进很正常，大不了稳稳打。

投球进不进，确实是概率问题。但如果不管进不进，都能觉得自己有法子应对，进了就更激进一点，不进就稍保守一点，反正都在掌控之中，怎么都不会影响心态~

2、重要场合被搞心态，如何最大限度控制意外？

1996年亚特兰大奥运会决赛上，突然有观众开始闹场，他又是大吼大叫，又是举海报抗议，严重干扰了比赛。

如此重要的场合，摊上了这么个搞心态的事。换做是我，早就麻爪了。邓亚萍却心中一喜：“哈，被我猜中了吧!”

原来，在决赛的准备期，跟教练聊天的时候，她就跟教练讲了几种可能会发生的最糟糕的状况，其中就包括有观众闹场。

因为她提前用“预测游戏”的心态做“失败清单”，等真遇到清单里的某项糟糕情况，反倒有股“猜中了”的暗喜，给了自己一种“一切还在掌控中”的感觉。

3、面对巨大的不确定性，如何保持掌控力？

中国男足常说，比赛越大，不确定性越大，草皮、风向、湿度等等等等，都会影响发挥。

邓亚萍也承认，因为是重大比赛，所以跟对手的差距微乎其微。谁赢谁输，很可能就取决于这些场外因素。当“天时、地利、人和”等场外因素都控制不了的时候，人的自信心或者专业上所谓“自我效能感”确实会下降。

不过，邓亚萍们还有小妙招，比如搞点“小迷信”，控制不了外界，还不能控制自己嘛？只要他们按照自己的习惯，订了同一家酒店、穿了同一双球袜，那就能发挥出色……

至于小“迷信”灵不灵，其实一点都不重要，哪怕半信半疑也没关系。因为在关键时刻，他们需要的，只是对自己的控制力。小“迷信”带来的掌控力，就足够让他们理清思路和舒缓情绪。

4、比赛场上太紧张，如何一句话帮自己找回状态？

普通的妈妈，可能哄你:“你是最棒的!”；一般的爸爸，可能会骂你:“你想那么多干嘛?专心打球!”

但邓亚萍的教练，只会云淡风轻地说一句:“跟训练时一样打就行。”

哄人的话靠不住，是因为大脑会质疑“凭什么” ；骂人的话要有用，运动员就不用紧张了。

但如果告诉她跟训练时候一样，打好每一个球，她就会把注意力都集中在当下的每个球上，而不是之前的得失上。

运动员在赛场上，唯一能控制的，只有当下的每个球。但凡有一个球打好了，接下来的信心就有戏了，信心上来了，状态自然就回来了。

5、讨厌但不得不做的事情，如何做到不拖延？

邓亚萍本科毕业于清华大学英语系。刚上大学的时候，她二十六个字母都认不全。因此，她不喜欢背单词，也觉得每天做同样的事很枯燥。

不过，她居然也坚持背了3年单词，大学没有延毕，而且毕业后马上出国留学，最后还拿了牛津的博士学位。

那么，她是靠什么克服畏难情绪的呢？也并不是靠着什么咬着牙的精神，而是靠着运动员的小技巧——早年做运动员的时候，只要到了球馆，就要马上打500个正手拍——后来当了学生，她也告诉自己，一坐到书桌前，就要先背20个单词。

后来做体育研究的时候，她才发现，这是一种叫“执行意图”心理学现象，大白话就是：大脑不喜欢你给它问题，大脑喜欢你给它答案。普通人靠“意志力”保持拖延中途放弃，顶尖运动员靠“执行意图”绕过畏难坚持到底。

6、伤病过后，如何快速恢复巅峰状态？

都说“拿得起，放得下”很不赖，但放下后能再拿起来才是真厉害。比如，在伤病后还能恢复到巅峰状态（1996年邓亚萍在伤病后拿到的奥运冠军）；再比如，睡过头后还能拥有充实的一天（你懂的）。

从顶尖运动员的角度，做到这件事也不难——提前给大脑设定个条件句：“如果发生X例外情况，那么就应该做Y事。”这里的Y事，就是根据你的状况，可以被接受的休息计划。

同样以早起背单词为例，我们可以提前就对自己设定:如果早上真的起不来，那可以允许自己多睡半小时;如果还是困，那么先起床刷个牙，不用背单词，出去跑步。如果中间单词背不下来，那么可以听听音乐、鼓鼓劲。

虽然多睡半小时或是出去跑步看起来都是放松，但是比起让感性彻底接管大脑，睡掉一个早上，这已经是相对有效率的方式了。有了这些设定，就可以控制自己，在遇到例外状况想要放松的时候，不会一放松就松懈、一放松就崩溃。

因为遇到这些例外状况，首先启动的是你的理性，你马上就能找到事先做好的预案。而不是手足无措，立刻被感性接管大脑。

【总结】

在西方广为流传的“尼布尔的祈祷文”里有这么一句话：

“上帝，请赐予我平静，去接受我无法改变的；

给予我勇气，去改变我能改变的；

赐我智慧，分辨这两者的区别。”

面对巨大的不确定性，顶尖运动员比普通人多一点的，是这自己给的平静、勇气和智慧：

1、刚开始的时候，挑战一把「失败了也没关系」的高难度。挑战成功就一路狂飙，挑战失败还能退回普通模式猥琐发育；

2、与其担心重要场合被搞心态，不如提前想好各种不好的可能性，然后临场玩把“预测游戏”，把未知的坏事变成“我就知道”的确定感；

3、上香拜佛不如信自己，高度紧张的环境下，不妨搞一点自己的“小迷信”，信与不信都没关心，关键是把掌控力重新拽回自己手里；

4、如果过于紧张，那就告诉自己像平常一样像往常一样，专注把手头可控的小事儿做好，打好每一颗球，“松弛感”自然来

5、一遇到畏难情绪，就告诉自己可以开启“执行意图”小游戏：比如一到球馆，就马上打500个正手拍

6、感到自己因例外状况要松懈了，赶紧启动“如果发生x例外情况，那么应该做Y休息计划”，不让松懈变奔溃

去年学到句话，叫做“每临大事有静气”。大疫三年，俄乌战争，生意难做，公司裁员，这些时代的一粒灰，落在普通人身上，都是比山还大的大事。

可惜紧绷如我，始终没有参透如何才能有静气，直到最近打开邓亚萍的这本《心力》，才有了上面的答案。

挂一漏万，书中还有很多顶尖运动员才知道的小妙招，他们源自“运动心理学”，帮助很多顶尖运动员在高度紧张和巨大不确定之下取得好成绩。

推荐给各位在高度不确定时代仍心存希望的勇士，愿我们能掌握「把看起来“不可控”的事变为可控」本事，然后更快、更高、更强，以及离内心中真正想要的更近。
