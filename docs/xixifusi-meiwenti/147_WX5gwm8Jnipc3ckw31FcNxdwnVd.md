# 每个人都至少值得你学习两次，一次是他拥有的，一次是他缺失的。你能够从他身上得到的，可以比他拥有的更多

> 来源：[https://docs.feishu.cn/docx/FRhhdD4sgohzlHxD3cKcblNwnfo](https://docs.feishu.cn/docx/FRhhdD4sgohzlHxD3cKcblNwnfo)

> [来源](https://m.okjike.com/originalPosts/64c7cb6e94d175e98dce6cfb?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6MX0%3D)

播客不是坏的，但播客绝不是中性的。播客给「个人崇拜」带来极大的便利。

给个人崇拜带来更大助推的，是知识星球式的社群。

乌合之众的故事在小小的手机APP里上演。进群的门槛首先就筛掉了一批不认同者，创造了一所认知监狱。个体可以思考，但群体不行。每个个体都觉得，哪敢自认为比一个群体更懂？其他人都不质疑，那么一定没有问题。再加上主理者无形的光环，以及主理者拥有的选择精华帖的权力——这是选择视线的权力。

于是，所有人自愿地选择被奴役。

人们不仅被剥夺质疑的权力，还被剥夺质疑的能力。在某些类型的教育系统中，教育的目的是让你学好数理化，成为工具人。而不是质疑规则，质疑系统的根基。诸位在学校里学过「逻辑谬误」和「认知偏差」吗？

最可怕的不是错误的答案，而是「似是而非」的答案。比如“场上没有别人”，这个观点在人生哲学层面是一个出色的角度，让人们专注自己的内在目标，而不是被那些不可控制的事物烦扰。而这个观点的危险之处在于本体论层面，它让人觉得全世界只有自己存在，其他都是游戏角色，从而失去对客观规律和他人的敬畏。

在这种认识论的基础上思考投资，连正确归因都做不到。

要真正理解“场上没有别人”，需要从脑科学角度理解「同构」的概念，即大脑通过同构和外部世界一样的模型来理解外部世界。但是，又有多少人能够拥有这层脑科学的造诣？又有多少人能够在量子力学，乃至喝西芹汁上不被糊弄？

我思来想去，如果十年前的自己面临「因人信言」的困境，我可以对自己说些什么？

许久后，我写下这些话：

相信太简单，质疑太难。张潇雨有几个流传很广的面试问题，其中有一个是“你觉得谁是自己学习过的最好的老师，为什么？TA 的局限性是什么？”

诸位得意忘形的听众，你们想过「张潇雨的局限性是什么吗？」

每个人都至少值得你学习两次，一次是他拥有的，一次是他缺失的。你能够从他身上得到的，可以比他拥有的更多。
