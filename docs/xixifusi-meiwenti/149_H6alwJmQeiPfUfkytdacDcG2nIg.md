# 千万不要「憋大招」

> 来源：[https://docs.feishu.cn/docx/XgGEdigLzoNPigx5R5kcxNXhnUh](https://docs.feishu.cn/docx/XgGEdigLzoNPigx5R5kcxNXhnUh)

> [来源](https://m.okjike.com/originalPosts/6531336b5110e2545560784a?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6MX0%3D)

我的经验是，千万不要「憋大招」，憋得时间越久，招儿越放不出来。

因为憋得时间越久，就会越倾向于完美主义，于是心理压力越大，越做不好事；

又因为是在一个人「憋」着，所以不会有正向反馈，只有一次次的挫败感和自我怀疑……

于是招儿就给憋没了。

我会建议当你想要做一件事儿的时候——无论是减脂还是写作、或是创业——去找到一些值得信任的同频朋友，和他们交流你的想法、你的进度、你的成绩、你的阻碍……

一方面，微小进步的总结复盘能带来极大的自我成就感；

另一方面，同频人的关注和鼓励，也能在遇到阻碍时获得更多的支持和信心。

所以呢，不要想着「默默惊艳所有人」，也不要害怕没达成目标而被别人笑话。

因为会笑话你的人，根本不值得你在意他们的看法；

也因为所有你以为的「惊艳」 ，背后都有着持续的支持资源，只是你不知道。

不要憋大招，咱一步步走，每一步都算数。
