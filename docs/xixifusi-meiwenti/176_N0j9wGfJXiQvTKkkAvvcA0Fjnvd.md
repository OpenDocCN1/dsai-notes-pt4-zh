# 阅读的四个层次

> 来源：[https://docs.feishu.cn/docx/TG66dGJ4BoSlLyx69olc2EQfnOf](https://docs.feishu.cn/docx/TG66dGJ4BoSlLyx69olc2EQfnOf)

阅读分为哪四个层次？

阅读可以让你获取他人已经掌握的优质知识，但这只有在你能够记忆并运用所读内容的教训和见解时才有意义。

莫蒂默·阿德勒 (Mortimer Adler) 在 1972 年出版了畅销书《如何阅读一本书》，介绍了四种阅读的层次：

初级阅读

这是我们在小学学习的阅读水平。如果您能阅读这篇文章，您已经掌握了这种阅读。

检视阅读

有人认为，略读和浏览会降低理解力。但事实并非如此。正确地使用这些工具可以提高理解力。检视阅读让我们能够了解作者的主旨和结构，并评估是否值得深入阅读。

略读可以帮助你做出选择：这本书是否值得我投入更多的时间和精力？如果不是，你就可以放弃它。

分析性阅读

弗朗西斯·培根曾经说过：“有些书是要品尝的，有些书是要吞咽的，还有一些书是要咀嚼和消化的。”分析性阅读就是咀嚼和消化的过程。这是一项艰苦的工作。

主题阅读

这也叫做比较阅读，它是所有阅读中最高级、最困难的一种。主题阅读涉及阅读同一主题的多本书，并比较和对照它们的观点、词汇和论据。

这项任务需要通过找出相关的段落、解释术语、构建和排序问题、明确问题的含义以及与答案进行交流来完成。

这一切都是为了发现并填补你的知识空缺。

结语 阅读就是按照正确的顺序提出正确的问题并寻求答案。

对于每本书，你都需要问四个基本问题：

这本书讲了什么？

具体讲了什么，怎么讲的？

这本书的全部或部分内容是正确的吗？

这对我有什么意义？

如果你觉得这些听起来很辛苦，那你是对的。大多数人不会这样做。这就是你与众不同之处。
