# 世间的书，世间的道理有多少是第六层的人的写第七层的功法，虽有正确，却不免谬误

> 来源：[https://docs.feishu.cn/docx/JTIkdymULohFKxxYO0xc4YObnkd](https://docs.feishu.cn/docx/JTIkdymULohFKxxYO0xc4YObnkd)

乾坤大挪移第七层，除了张无忌之外没有人练成。原因这套功法是练至第六层的人写成，根据他推测第七层应该如此。张无忌练的时候，因为时间紧迫，觉得不通的地方就没有练，其实这些地方确实是错误之处，张无忌因祸得福，反而练成了第七层。后来，张无忌退隐江湖，并没有修订乾坤大挪移功法，后人读仍I日是这有误的功法。

世间的书，世间的道理有多少是第六层的人的写第七层的功法，虽有正确，却不免谬误，尽信则误入歧途。而真正悟道第七层的人有多少人会写下来？

这世上流传的只言片语，于大道而言何其幼稚渺小。

道德经上说，知者不言，言者不知。
