# 正确的反馈工作的姿势

> 来源：[https://docs.feishu.cn/docx/HwZ6dRgodoF0HjxQthhcIqWpnhf](https://docs.feishu.cn/docx/HwZ6dRgodoF0HjxQthhcIqWpnhf)

> https://m.okjike.com/originalPosts/649269ee60db290560cd8d9b?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6Mn0%3D

让领导或者合作伙伴觉得你靠谱，做到以下三句话即可：“凡事有交代，件件有着落，事事有回音”。要做**到这三句话，“反馈”工作非常**重要。今天我们就分不同场景，跟大家聊一下怎么做到正确的反馈姿势：

1. 当老板或者合作伙伴跟你交代工作任务：你需要复述一遍工作任务，并反馈“确认信息+明确工作任务+时间点”，比如领导让你办个会议，你可以这样回答：“已经通知了所有参会者，并且预定好了会议室，会议议题会在明天下午3点之前发给您”。这样的反馈充分说明你已经理解了任务，并做了任务拆解和明确时间点了。

2. 当老板或者合作伙伴询问你工作进度：你需要反馈“已完成进度+未完成部分+最终完成时间点”，比如合作伙伴问你，你的运营方案做的怎样了？你需要这样回答：方案已经完成了70%，还差流量投放部分没有完成，如果你着急的话，我今天晚上会发给你截止到目前的版本，最终版本最迟会在后天晚上给你。

3. 当领导或者合作伙伴对你工作或者项目进展提出质疑：这时候你千万不能只讲理由，以推卸责任，你需要反馈“复盘+解决方案+后续反思”，比如领导问你为啥这次促销没有达到预期效果，你需要这样回答“对不起，确实哪几个细节没做好，导致现在这个结果，我后面准备了如下改进方案，下班前给你，我后面一定会反思，争取下次做到更好!”
