# 好的谈话的关键

> 来源：[https://docs.feishu.cn/docx/UiyVdFpZDorlcbxoSltcCIKAnbg](https://docs.feishu.cn/docx/UiyVdFpZDorlcbxoSltcCIKAnbg)

> [来源](https://m.okjike.com/originalPosts/6552491c859fc596df8220d6?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6MX0%3D)

一个好的谈话的关键是，最终激发出了对方更多的能量，而不是消耗。

去观察对方容易被什么内容或者沟通方式激发能量。

起码大多数人都不喜欢在一场谈话中被挤占太多自己的意识的空间。不要让对话里只有“我”。
