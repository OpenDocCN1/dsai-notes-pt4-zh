
# 别爱上你手里的股票

> 来源：[https://docs.feishu.cn/docx/MHXsdlvEIoAvAjxsFYtcVgrAngf](https://docs.feishu.cn/docx/MHXsdlvEIoAvAjxsFYtcVgrAngf)

> https://mp.weixin.qq.com/s/4CSH9zQr3PrDDRkkBugDIQ

个人有强烈的喜好，再把喜好做成生意，就容易用个人喜好替代市场需求，最后做成了个人兴趣小组 —— 喜欢登山跑步，就开了个运动公司，有了宝宝，就做母婴用品，喜欢喝咖啡，就办咖啡连锁。TA们通常还主意特别多，全体员工都围着TA们的审美情趣转。假以时日，多数生意做不大，但足以毁了自己的兴趣。

所有的爱，都会让决策变形，让人贪嗔痴，都会折磨人。王尔德的看法是：“A man can be happy with any woman，as long as he doesn't love her。”（所以夫妻相敬如宾其实不难，只要内心足够冷漠就可以了。）

类似的思路，放到交易员身上，他们的说法是「别爱上你手里的股票」。
