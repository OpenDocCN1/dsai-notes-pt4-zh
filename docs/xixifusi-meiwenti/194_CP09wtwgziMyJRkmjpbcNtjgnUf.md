# 如何输出

> 来源：[https://docs.feishu.cn/docx/Qso5d3AtSoUljZxSKqlcjOrGnRf](https://docs.feishu.cn/docx/Qso5d3AtSoUljZxSKqlcjOrGnRf)

> https://m.okjike.com/originalPosts/64c9bb687d10e1210f34a649?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6MX0%3D

1）**说人话，说人话，说人话**

2）内容逻辑连续，追求纵深。不断探索和**向上翻的过****程是最给人**带来阅读爽感的，要用假设和问题来引领全文，带着读者一起走完解题**找到最终答案的过****程

3）尽量避免大而**全、避免并列结构和小标题（这也是播客等对谈、panel** 形式内容难以转文字或**难以传**播的最核心原因，如果遇到类似情况，只能尽量**追求形**散而神聚**）

4**）要**能勇敢**和狠心地删除与主线**无关的内容，哪怕是好内容

5）一篇能带来正反馈的内容的终极秘诀就两个词，热点+深度，热点带流量，深度带口碑

6）好的选题就是一个好的问题，就是如果把这个问题作为标题，大家就都会想点想看的那种

7）不论从文字到形式上，都不要刻意去包装内容，不要和各种机构媒体学表达、学排版，尽量留一丝朴实的美好，人们会更喜欢璞玉，而不是流通的商品

8）用每个字、每段话、每个标点、甚至分行和分段来为内容的节奏感服务，知道哪里该有肉、哪里只保留骨骼、哪里可以点到为止、哪里又可以峰回路转等等，这些都是文字的节奏感（节奏感决定了这篇文章看上去是不是“聪明”）

9）追求信息密度，把本来可以讲 5000 字的东西，变成 2000 字讲清（而大多数人是反过来的，脑子里只有 2000 字的有效信息，非要撑到 5000 字）

10）不要从零写起，从第二第三个台阶开始写，不要小看读者，可以默认读者是了解常识和基础信息的。掌握恰到好处的内容门槛，可以让读者觉得需要够一下，而不是照顾到所有人（甚至可以一上来就直接把读者抛到旋涡的中心）

11）好的标题决定初始阅读者基数，好的开头要懂人性，快速跟读者共情共振，好的结尾能上价值，让读者愿意转发

12）多用短句，避免复杂信息和表达。多说观点、言之有物，避免罗列无聊的细节、数字或事实。要克制自己写八股文新闻稿的下意识行为

13）对了，别忘了幽默呀，要追求能让读者看到后觉得会心一笑的点，幽默就是有爱 :P

14）出其不意的神来之笔，往往是解构后的重构带来的，是跳跃的思维和跨界的类比带来的，诗人其实和科学家一样，都是最擅长解构事物本征，留下特征值并重构逻辑的，向他们学习

（螃蟹在剥我的壳，笔记本在写我，而你在想我）

15）写完多读几遍，不断地读、反复地读，边读边改

16）要真诚，要敢于袒露内心，要敢于说出大众所想但未曾表达的事实，做第一个说出皇帝新衣的人，做第一个指出房间里的大象的人（写的时候要当作不会有任何一个人看到来写，改的时候要当作全世界所有人都会看到来改）

17）但同时不要纯粹为了流量写东西，真做出好的内容你自己是第一个知道的，你会真心愿意分享给所有人，所以不要自欺欺人

18）要用价值观和审美驱动内容，不要怕显露自己的个性，这决定了最终大家记住的是你这个人还是某个文章、媒体或平台的名字

19）内容与运营是一体的，最好的内容创作者一定同时具备很好的用户运营思维 and vice versa（把每篇文章当作讣告来写，把每次运营当作婚礼来做）

20）最后一条，要有使命感，永远记得文字是杠杆最高的改变这个世界的方式（结尾上价值）
