# 那些能毁掉年轻人的思维里，最残酷的一条就是：我感觉我还没准备好。

> 来源：[https://docs.feishu.cn/docx/TMEydwvlGoLIqnx6qpkcBvSTnqf](https://docs.feishu.cn/docx/TMEydwvlGoLIqnx6qpkcBvSTnqf)

> [来源](https://m.okjike.com/originalPosts/64b8fe231b83e0b21af52db1?s=eyJ1IjoiNjI1ZmQzNzdmNzU0NTMwMDEwYzc2MjcwIiwiZCI6MX0%3D)

我很久以前就意识到，所有的事情只有开始干才有机会。

如果你老是害怕，觉得自己还没有做好准备，那你会失去很多机会。

而且，非常奇妙的一件事情是——

当你突破自己的惴惴不安，第一次拿到结果之后，你会发现：

“太爽了，整个世界都在为我滚雪球。”

你拿到一个荣誉，就会有人找你做第二件事情，你就又会拿到一个结果。

然后你的自信就会不停地滚雪球，滚雪球，越滚越大。

很多年以后，你回头的时候会发现。

如今不再年轻的你，依旧有机会向你涌来。

因为很多年前，你向自己射出了一颗叫做“我准备好了”的子弹。

那颗子弹，时隔多年后，依旧为你杀死了自卑的自己。

于是，你永远自信。

而那些未射出子弹的人，永远在和另一个自己内耗。
