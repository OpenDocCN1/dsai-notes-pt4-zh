# 家庭教育的最佳策略

> 来源：[https://docs.feishu.cn/docx/VSXodLjdFoflknxrHOWcZK0TnWr](https://docs.feishu.cn/docx/VSXodLjdFoflknxrHOWcZK0TnWr)

> 来源：https://mp.weixin.qq.com/s/xp_igFf-tLwH_I63YLzGzg

今天接受了一家教育自媒体的采访，我稍微说了一点点我的家庭教育想法：

（1）**要给孩子犯错的空间和机会**，不然孩子年龄越大犯错成本就越高，就更害怕犯错了。所以，犯错要趁小。更重要的是，给了空间才给了孩子生命力释放的可能，他才开心，才会越活越来劲！

（2）中产阶级父母真不要太担心孩子掉下去，掉出自己的阶层，或者无法做到青出于蓝而胜于蓝。因为那其实是非常小概率的事件；需要这方面详细的解释，私下找我，或者我另找时间说明。墨菲定律，越是害怕掉下去就越容易掉下去，我们要“盲目”地相信孩子。

对于中产阶级家庭来说，**最好的家**庭教育策略可能是：守住底线（往往与人格/品格、责任和操守相关）、打开上限，留出向上和横向的空间，越大越好。对于大多数孩子来说，我们要求他班级第一反倒是限制了他、低估了他的水平，然后往往在这个不那么好的目标上磨灭了他与生俱来的巨大潜力和生命力，搞得家长孩子两败俱伤、心力交瘁。不值！
