# 发现有异常值的年轻人，投资他们的人生期权

> 来源：[https://docs.feishu.cn/docx/ZuSndtLKXoqhxexU9BkciQ44nNg](https://docs.feishu.cn/docx/ZuSndtLKXoqhxexU9BkciQ44nNg)

1、一个能成事的**人，他通常有某项异常值，**你跟他聊十分钟就能感受到。这个我深有体会，比如我第一次见到李叫兽、沈帅波和脱不花，都是这种感觉，而那时候李叫兽才刚刚本科毕业，还没有什么名声。

2、天使投资就是买下一个年轻人的人生期权。

在渗**透**率**低的时候投资，但是渗透率**会不会变高呢？不重要，投资是概率。

3、一个人的“正气”很重要，正气的意思，是对待人和事的态度。一个人要有契约精神，不能屡屡爽约，不能不履行承诺。

4、今天50岁的老年人，和过去的老年人不同了，他们的经历和个人技能都有很大的区别，所以今天的老年人市场更有潜力。

5、投资成功率太高，你要反思，你可能因为太谨慎错过了很多有潜力的项目。

6、用社会学和历史学的眼光去看企业，社会学就是人口学、文化学，观察中国社会的变化发展；历史学就是循环往复的大波浪、大阶段。历史学判断周期，埋伏式打法：行情与我无关。

7、投资要打提前量，而不是去投那些今天热门的项目。这是二级市场的投资哲学，但它同样适用于天使投资。比如今天日本股市创新高，而会有无数人去解释为什么日本股市会这么好，但在它没有涨之前，所有的评论都是日本为什么不行。这种人是无法赚到钱的。

还有六看。分别是上看下看，前看后看，内看外看。

上看，你愿不愿跟随他

下看，你愿不愿意招揽他？

前看，他正常跟你讲话时候的表现。

后看一些微表情。话里有话时的表现。

内看，他是否能够对所从事的行业给出超出你认知水平的见解。

外看，简单说就是一打眼的第一印象。你对这个人的初步判断。
