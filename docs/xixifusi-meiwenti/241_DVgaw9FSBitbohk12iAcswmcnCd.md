## AI 安全问题

人工智能技术的引入给本身没有安全问题的情况带来了很多新的安全挑战，比如数据泄露、感知欺骗攻击和 AI 模型攻击等。最知名的几个案例有：

+   2016 年 Facebook 数据泄露丑闻，剑桥分析公司使用机器学习模型基于种族、年龄、性别等人口特征建立影响选民的方法，影响了约 500 万选民的投票意向。

+   2019 年 3 月，IBM 被爆出使用互联网上的照片作为人脸识别的素材，其中包含了图片分享网站 Flickr 上近 100 万张照片，但未经用户许可。

+   GPT - 3 开发中 bug 导致训练数据污染。

+   Tesla 智能汽车的 AI 算法漏洞。

+   IBM Watson 智能医疗诊断系统，误诊率达 35% 。

我们以对抗样本攻击为例，这是人工智能安全里最典型的攻击之一。

![](img/4a689e804e2a690ae89e5a2780715a63.png)

Thys, Simen & Van Ranst, Wiebe & Goedemé, Toon. (2019). Fooling automated surveillance cameras: adversarial patches to attack person detection.

这是一个目标检测系统，其正常情况下是可以识别出一个人来。而右边的这个人身上挂了一幅画，此时目标检测系统就无法检测到这个人了。这就相当于对模型的一种误导，使得攻击者可以在智能监控下隐身。在对抗攻击里，攻击样本在人眼看上去没有任何问题，比如人眼可以轻易识别出右边的人，但样本能够对系统进行误导，很多情况下，这种误导是难以被人察觉的。

![](img/546fcb2a7b39aaab186d44b972615996.png)

K Eykholt et al. (2018) Robust Physical-World Attacks on Deep Learning Visual Classification

再比如，通过添加“小纸条”扰动，可以误导驾驶系统将“STOP”标志识别为“SPEED LIMIT 45”。这种攻击就可能会导致车祸的发生。

## AI 安全问题分类一：组成要素

讲了几个例子后，我们就来具体的去说一下人工智能安全问题有哪些。现在不管是机器学习，还是人工智能，在现实生活中都得到了越来越广泛的应用，其安全问题也是越来越重要。这里面有两个最重要的内容是：数据和模型。模型是基于数据进行训练的，而从模型中也可以反推出一些数据来。同时要考虑其运行环境，例如 Tenserflow 或者 Pytorch 框架，或者其运行的操作系统，这里面也可能有一些安全问题。

因此我们可以将 AI 安全问题进行分类：

+   数据的安全威胁：

+   数据投毒攻击：攻击者在训练数据中注入特定的毒化数据，污染训练数据，影响甚至干预模型的训练结果。

+   模型逆向攻击：攻击者通过模型的预测结果尝试恢复该预测结果对应的输入数据。

+   属性推断攻击：攻击者从模型的预测以及计算的中间信息恢复输入数据的部分敏感属性。

+   模型的安全威胁：

+   对抗样本攻击：攻击者通过在图像中添加扰动，误导AI模型出错。

+   模型窃取攻击：攻击者可以通过发送轮询数据并查看对应的响应结果，推测 AI 模型的参数或功能，复制一个功能相似甚至完全相同的 AI 模型。

+   模型版权证明：数据的收集以及模型的训练都要耗费大量的资源，版权证明能够在模型被窃取后验证所属权，保护模型保密性。

+   运行环境的安全威胁：服务器、客户端、网络的安全威胁

+   服务器的安全威胁：数据库被入侵、勒索病毒、DDoS攻击

+   客户端的安全威胁：木马病毒感染，钓鱼劫持

+   网络的安全威胁：会话劫持

## AI 安全问题分类二：生命周期

另一方面，可以从模型的生命周期的角度看待安全问题。我们可以将流程简化为三个生命周期阶段 —— 设计阶段、训练阶段、执行阶段，根据生命周期的不同阶段对 AI 安全问题分类解读。

+   设计阶段：收集数据，根据需求选择合适的模型结构

+   数据的偏见：收集数据时未能从所有的群体中均匀采样，导致训练数据带有偏见

+   模型的偏见：人在设计算法时采取的准则是有偏见的。数据和算法中的偏见都可能威胁 AI 的公平性。

+   训练阶段：按照设计时决定的模型结构，结合数据来训练模型

+   数据投毒：攻击者将少量精心设计的中毒样本添加到模型的训练数据集中，利用训练或者微调过程使得模型中毒，从而破坏模型的可用性或完整性，最终使模型在测试阶段表现异常。例如一个识别垃圾邮件的模型，在训练时故意将垃圾邮件的 label 标为正常邮件，那么该模型的训练会被收到影响。

+   后门攻击：普通的数据投毒很容易被发现。怎么能够做到隐蔽呢？这就要使用后门攻击。在训练数据中加入少量的带触发器（Trigger）的毒化数据，破坏模型的训练完整性。面对正常输入时，模型预测结果无异常。一旦输入数据包含触发器，模型预测结果就被恶意篡改。由于使用者无法得知触发器是什么，因此这种后门攻击的隐蔽性很高。

+   执行阶段：使用训练好的的模型进行预测，完成既定任务

+   对抗攻击：攻击者对输入加入精心设计的扰动，使模型得出错误的结果；而加入的扰动难以被辨识，隐蔽性强。（例如上图的大熊猫，加上扰动后对人眼来说几乎没有区别。）

+   成员推断攻击：攻击者根据模型执行的结果，推断输入样本是否属于模型的训练数据，破坏模型保密性；若模型本身的训练数据较为敏感，则会泄露用户的敏感信息，如患病情况、基因型等。

## AI 安全问题分类三：系统架构

AI 系统架构由硬件、 操作系统、 AI 框架、 算法与数据、模型等组成，根据相关系统架构可以对 AI 安全问题进行分类。

![](img/3963326ba5c742394b2b023879c512a9.png)

以 AI 框架为例，我们都在使用 Tensorflow 或者 Pytorch 的框架，就像大家都在用 Windows 和 Linux 的系统一样，如果该框架中存在漏洞，那么这种攻击的影响范围更广。这些可能的漏洞包括：内存越界、缓冲区溢出等，或者安全性检查不足，比如攻击者可能会将恶意代码注入模型， 当模型加载时恶意代码被框架运行。再比如硬件的安全威胁，攻击者直接解出硬件设备，添加电路层面的扰动，伪造设备；或者攻击者测量硬件系统的电磁、功耗泄露，获取模型粗粒度超参，为模型窃取提供先验知识等。

---

总结上述几种分类，可以总结出 AI 的安全要素，一共有五个方面：

+   保密性：数据和模型信息（一般指模型架构和参数）不会泄露给未授权的人；

+   完整性：算法模型、数据、基础设施和产品不会被恶意植入、篡改、替换、伪造；

+   完整性主要体现在模型的学习和预测不受干扰、输出结果符合表现上。针对完整性的攻击主要有两种：一类是从模型入手的逃逸攻击，另一类是从数据入手的投毒攻击；

+   鲁棒性：能同时能抵御复杂的环境条件（例如阴雨天不应该人脸识别）和非正常的恶意干扰（对抗攻击）；

+   基于    范数的模型鲁棒：

+   如果模型是鲁棒的，当输入发生微小变化时，输出不应该发生大的变化。这保证了模型预测结果的稳定性。

+   对抗样本的环境下，研究鲁棒性主要解决这样一个问题：对于一个给定的机器学习模型，给定一个输入样本点，如果该样本点周围的空间的所有样本通过模型得到的预测结果都是一致的，那么就认为该样本在它的局部空间内是鲁棒的。这里的局部空间可以通过    范数的扰动大小来定义：    （其中    是样本点，  F 是分类模型，    是扰动大小，    是预测分类结果，    指的是以    为中心、   为半径的空间球体。）

+   鲁棒性缺乏的原因：

+   环境因素多变：例如 CV 相关的工作，光照强度、视角角度距离、图像仿射变换、图像分辨率都可能会导致 AI 模型表现不稳定，其根本原因是训练数据难以覆盖现实场景的全部情况。

+   可解释性不足。大多数情况下，深度学习模型是一个黑箱：模型参数量巨大，结构复杂，在没有恶意攻击的情况下，也可能出现预期之外的安全隐患。因此这阻碍了 AI 技术在医疗、交通等安全敏感性高的场景下使用。

+   隐私性：AI 模型在使用过程中能够保护数据主体的数据隐私；

+   常见攻击：成员推断攻击、模型逆向攻击、分布式模型梯度攻击（在联邦学习过程中，通过模型梯度更新数据，重构训练集数据）。

+   公平性：AI 对不同使用者不会差别对待。

+   也就是客观中立，在满足个体对个性化的需求下不歧视某一群体。但问题是偏见是普遍存在的：

+   数据收集过程：收集护士的图像时收集到的全是女性的图像；

+   数据标注过程：户外运动者看不清性别时，人们可能会倾向于将其标注为男性；户内运动则相反；

+   结果解释过程：使用者可能会按照自己的思维方式对结果进行解释；

+   例如我们常说的文章推荐算法导致的“信息茧房”也属于此类。

## 对抗样本攻击原理

![](img/4367306a3cf30002973a00cbc2982db1.png)

Ian J. Goodfellow, Jonathon Shlens, Christian Szegedy. (2014).Explaining and Harnessing Adversarial Examples

还是[从这张](https://zhuanlan.zhihu.com/p/618895420)最经典的图片讲起。对左边的这张图片来说，一个训练好的神经网络可以很容易判断出这是一张熊猫的照片。但是只要攻击者加入了一些人眼不可见的噪音，神经网络就会错误地对其进行分类。在上一章的 概论 里也讲述了多个对抗样本攻击的例子。

总结起来，攻击者的目标是：

+   不被检测到（噪音肉眼难以可见）；

+   产生攻击者希望的结果（即，分类出错）。

此外，将对抗攻击进行分类，有如下三个维度：

| 攻击者掌握的信息 | 白盒攻击 vs. 黑盒攻击 |
| --- | --- |
| 攻击者目标 | 有目标 vs. 无目标 |
| 攻击时间 | 决策时 (e.g., 逃逸攻击) vs. 训练时 (投毒攻击) |

（Source: Adversarial machine learning by Yevgeniy Vorobeychikand Bo Li）

其中，根据攻击者掌握的信息，对抗攻击可分为白盒和黑盒攻击。假如攻击者知道所要攻击的神经网络的所有信息，包括神经网络的参数、结构，甚至训练数据，就是白盒攻击。黑盒攻击则相反，神经网络对于攻击者完全是黑盒，只能通过输入输出来“询问”，而完全不知道内部模型模型结构、模型参数和训练算法。

根据攻击者目标，可将对抗攻击分为有/无目标。以熊猫图片为例，有目标攻击就是攻击者希望神经网络将图片误分类成某一指定的动物（例如指定为长臂猿）；无目标攻击则没有指定错误预测的类别，只需要神经网络将其分类错误就行。换言之：无目标攻击中是要最大化预测的错误率（普遍应用于监督学习）：

### 快速梯度符号法（FGSM）

快速梯度符号法（FGSM, Fast Gradien**t-Sign**** Me**thod）是最著名的 无目标攻击 方法之一，而且能够直接推广到有目标攻击中。它是一种梯度上升的 单步 （Fast）优化方法（一步到位，所以很快:-），优化方向沿着训练模型梯度下降的反方向。

### 黑盒攻击

当攻击者不知道目标模型的种种细节时，该如何进行攻击呢？黑盒攻击已经发展了很多年了，有很多的技术路线。其中的一种技术路线是：将黑盒攻击转换为白盒攻击。如果我们知道特征空间、学习算法，并且有原始的训练数据，我们就可以恢复模型（在训练数据上训练学习算法），从而将其转化为白盒攻击。

这种攻击方式的叫做“迁移攻击”。思路是：对抗样本具有一定的通用性（或者说可迁移性）；对于前文所提到的对于特定模型的对抗样本，对于另一个类似的模型可能也有效。因此，当目标模型是黑盒时，我们需要想尽办法训练一个类似的替代模型，和目标模型的功能要尽可能接近，然后将白盒攻击用于替代模型，得到对抗样本，以期望这个样本可以很好地迁移到黑盒模型上，并用它来展开攻击。

假如我们手里有了一个黑盒模型，该如何得到白盒模型呢？我们能做的就是准备一堆输入数据  x ，然后输入模型，得到训练样本    ，我们就得到了一堆关于  x 的分类标签  y 。只要我们的  x 足够多，我们得到的标签  y 也就足够多，凭经验选择一个模型结构，完全可以训练一个类似的模型出来。这便是“基于访问的黑盒攻击”，通常来说可迁移性还是很高的。

另一种技术路线是，黑盒模型也可以生成梯度。尽管我们只能输入数据给模型，然后得到输出结果，但我们可以想办法模拟出在输入样本处的梯度。例如，我们可以在一个样本空间范围内，通过蒙特卡洛采样，从概率上去模拟出这个梯度。有了梯度就可以进行迭代，从而生成对抗样本。不过，这种攻击方式需要进行大批量访问模型，而且每次访问都是相似的图片，很容易被发现。所以这种技术路线的黑盒样本攻击它的主要挑战就是如何降低查询次数，尽可能的用比较少的查询次数来模拟出梯度来。反而，基于迁移的攻击则不会有这种问题，仅仅在生成迁移模型的时候才会有大批量的访问，但此时的输入都是不同的样本，因此也不容易被发现。

## 对抗样本检测

我们先来回忆一下对抗样本和正常样本的区别，首先二者肯定是有细微的像素上的差别。原始的图片（“干净”的图片）一般是相机拍摄的物理世界的照片，它的数据处于一种比较自然的分布状态；但是对抗样本在正常样本上加了一些扰动，而这些扰动是通过梯度等方式搜索出来的，并不符合自然界的分布。但我们这里说的“自然界的分布”是很难去描述的，也不可能用一个公式表示出来。不过对抗样本和正常样本确实存在细微的区别，可以用来检测。对抗样本检测技术早期的探索就是从这个角度出发的。

另外一个区别是模型输出的区别，因为对抗样本的目的就是让模型输出与原始的真实标签不同。如果经过了 softmax 处理，那么输出得到的便是概率分布；对抗样本的输出可能会造成这一分布的变化，与正常样本可能也有不同，因此可以用来检测。

**后来，有学者**提出：神经网络在面对正常样本和对抗样本时，中间层的状态也是不同的。使用这些中间状态的输出作为的一个训练集，去训练检测器；随后，通过神经网络中间状态的输出作为检测器的输入，从而可以检测出对抗样本。

因此，对抗样本检测可分为以下三类：

+   基于特征学习的对抗样本检测：特征压缩

+   基于分布统计的对抗样本检测：softmax 分布

+   基于中间输出的对抗样本检测：对抗检测网络

### 基于特征学习的对抗样本检测

其主要思想是，利用对抗样本与原始样本的不同特征来进行对抗样本检测。当发生攻击时，我们面对一个对抗样本，是无法得知原始图片的信息的。这时就需要利用机器学习的思想，可以借助一些先验知识，先准备一些训练集，训练出一个模型来学习对抗样本和原始样本的这个区别。

同时，也可以不借助训练检测器来解决。我们可以把真实样本和对抗样本的细微区别视作噪声，面对输入的原始样本，首先尝试进行去噪处理，再将去噪后的样本作为模型输入，如果模型输出变化很大，则就说明原始样本可能是对抗样本。

在高维的数据下往往难以得到较好的特征学习结果；哪怕是一张很小的图片，例如   300×300 300\times 300 大小，那它的量级也有 9 万个维度了。这时可以通过降维将高维的复杂数据转化为低维数据，降低特征学习的难度。

一**般来**说，输入样本的特征空间越大，维度越高，产生对抗样本的可能性越大（因为添加噪声的空间也就越大）。特征压缩的目标是从输入中删除不必要的特征，在不损害分类器准确度的情况下减小对抗样本产生的可能性。这里面有两个算法：色深压缩，以及特征平滑。

#### 空间平滑

---

空间平滑（或称模糊）是一个图像处理**里的技术，目的是减少图**[像噪声，主](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Median_filter)要方法有局部平滑或者非局部平滑。局部平滑方法利用邻近像素对每个像素进行平滑，进行 中值滤波 （Median filtering），即：取一个方形窗口对于整张图片上下移动，每次移动时，取出小窗内所有像素点的中位数，使用这个中位数代替中间像素点的值。这种方法可以消除孤立的噪声点。

显而易见，进行中值滤波后，单像素攻击（One Pixel attack）这种就无用武之地了。除了单像素攻击，对于其它攻击方式，空间平滑也是可以起到作用的。

而非局部平滑是在一个更大的区域中对相似的像素块进行平滑，而不仅仅是邻近的像素。对于给定的图像，非局部平滑算法在图像的大面积区域内寻找多个相似的像素块，并用这些相似像素块的平均值代替中心像素块。假设噪声的平均值为零，将相似的像素块求平均便可以消除噪声。

### 基于分布统计的对抗样本检测

基**于分布统计的对抗样本检测的**核心思想是利用对抗样本与原始样本的不同数字特征（即样本通过网络后得到的概率分布的形状），通过检测输入是否符合正常样本的分布，从而判断输入是否具有对抗性。

例如，分类网络的 [softmax ](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Softmax_function)输出向量可以很好地反映样本的**数字特征分布**，而许多情况下，对抗样本的与正常样本的 softmax 输出向量存在较大的差异，正常样本的 softmax 输出向量会比对抗样本更加分散（即远离均匀分布），在 softmax 向量中的最大概率值往往更大（通常在某一类别上一枝独秀），这是因为对抗样本一般只关注最大的概率值而忽视其他类的输出概率，因此可以通过检测样本的 softmax 输出向量的分散程度确定样本是否具有对抗性。对于一些希望在决策边界停止扰动（即添加的扰动越小越好）的对抗攻击来说，可以通过 softmax 分布的不同很有效地区分出对抗样本。

## 对抗样本防御

对抗样本的防御主要有两种方式：

+   基于经验的防御方法

+   **主要破坏现**有攻击方法的前置条件，增加其成本。例如攻击方法需要模型的完整输出，那就将输出截断。如果攻击方法需要找梯度的最小值，那就在梯度上设置一些看起来像最小值的陷阱。

+   非常依赖攻击方法条件，面对层出不穷的新式攻击易被攻破。

+   如果模型在训练的时候就知道了防御方法，加入对抗样本，就可以做到破解防御

![](img/2b775a708aa9d31811de43ff736499fb.png)

Xie, C., Wang, J., Zhang, Z., Ren, Z., & Yuille, A.L. (2017). Mitigating adversarial effects through randomization. ArXiv, abs/1711.01991；通过两种随机变换减轻推理时的对抗效果。

+   基于理论的防御方法

+   不着眼于具体的攻击方法，而使将其抽象化。在实际操作时，攻击的方法被视为一个带范围约束的抽象操作，防御者只需使模型在抽象操作的范围内保持正确即可。

+   从理论的角度设计防御方式，为最坏情况提供下限，可防范现在尚未出现的攻击。

![](img/ab23b81b53f3a8ffba863d6abf8fbf7b.png)

Lécuyer, M., Atlidakis, V., Geambasu, R., Hsu, D.J., & Jana, S.S. (2018). Certified Robustness to Adversarial Examples with Differential Privacy. 2019 IEEE Symposium on Security and Privacy (SP), 656-672；对于任意的输入变换，约束分数可以改变的界限

具体方法有：

+   基于经验的防御方法

+   对抗训练

+   特征去噪

+   防御蒸馏

+   基于理论的防御方法

+   可证明式防御

不过，基于理论的防御方法还是十分困难的问题，我们这里不会过多叙述，主要还是介绍基于经验的防御方法。

+   对于 FGSM 对抗训练（b），随模型容量增加，对 FGSM 对抗样本分类准确率最高；对 PGD 样本无效；正常样本会先下降（说明模型容量不足以同时学习两个任务，会先去学习对抗样本），随着模型容量的增加又会趋于高精度（容量足够同时学习两个任务）；

+   对于 PGD 训练（c），三种样本的规律是一致的，即随着模型容量的增大，精度都变好；

+   最后， 给出三种训练模式下的 loss（d），其中正常训练的 loss 变化不大，但是 FGSM 和 PGD 的 loss 随着 模型容量的增大会逐渐减小。

所以，综上所述，PGD 对抗训练在目前，即使是工业界也是使用最多、效果最好的一种防御方式。

![](img/588dd27c00890dab6241a2af70eba051.png)

**集成对抗训练**

集成对抗训练主要用来**防御黑盒对抗样本攻击**。我们生成的对抗样本不是在目前训练的模型上生成的，而是用一个已经训练好的模型，以它为目标生成对抗样本，再用这些对抗样本做训练。也就是将对抗训练的过程和对抗样本的产生过程解耦。

更详细的内容和实验可以参阅： [[1705.07204] Ensemble Adversarial Tra](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1705.07204)ining: Attacks and Defenses (arxiv.org) 。

综上，我们对经验性训练有结论：

+   对抗训练模型需要比传统训练模型更大的容量，才能在干净数据上实现相同的准确率；

+   对于没有对抗训练的模型，太大的模型或者太小的模型都会导致鲁棒性很差，而对于对抗训练的模型，由于条件限制，模型容量越大，鲁棒性显得越好；

+   标签泄露问题：经过对抗训练的模型在对抗样本上可能比在干净样本上表现更好，因为对抗样本生成过程中使用了真实标签，模型可能学习到了对抗样本生成过程中的规律。

### 特征去噪

对抗样本无外乎就是在正常样本上加扰动，如果在对抗样本输入模型之前进行去噪处理，将攻击者千方百计添加到原始图像上的轻微干扰去除，我们可以得到与原始图像近似的去噪后图像，从而分类依旧正确。

去噪有两个方向：

+   输入去噪：在模型测试阶段，我们可以对输入数据进行去噪处理，试图消除输入数据中的部分或全部对抗性扰动；

+   特征去噪：试图减轻对抗性干扰对 DNN 学习到的高级特征的影响。

传统的去噪器一般是基于像素点的去噪器（Pixel guided denoiser，PGD），将对抗样本转换为去噪样本，通过计算去噪样本和原始图像的    范数（即基于像素点的距离）来确定损失函数。

![](img/a6fc7292a6dafcd5283e6789472cc336.png)

PGD 和 HGD 去噪器结构图示

上图第二行是基于像素点的去噪器的模型，去噪器  D 也是一个机器学习模型，其目标是让对抗样本**    去**噪之后的图片    和原始图片尽可能接近，即   最小。训练好  D 后，再遇到对抗样本，就可以先对其进行去噪处理，将降噪后的图片喂给目标模型。

但是，传统去噪器（像素级去噪）具有误差放大效应，在这种效应中，哪怕残留了很小的噪声，其影响也会逐渐放大，最终导致错误的分类。

### 防御蒸馏

蒸馏（Distillation，或称知识蒸馏、网络蒸馏）最初不是用作于防御方法，而是一种将深层神经网络集合中的知识压缩为单一神经网络的方法，由原始网络和蒸馏网络 2 个网络组成：

+   原始网络：教师网络，一般为参数多且结构复杂的网络；

+   蒸馏网络：学生网络，一般为参数少且结构简单的网络。

蒸馏可以让经过良好训练的复杂教师模型来指导较轻的学生模型的训练，以减少模型大小和计算资源，同时尽可能保持原始教师模型的准确性。这样操作的一个好处是促进了深度学习在一些资源受限，不能使用 GPUs 计算设备中的部署。

![](img/665e1e0329339a1ae375b6a1792c38c7.png)

Wang, L., & Yoon, K. (2020). Knowledge Distillation and Student-Teacher Learning for Visual Intelligence: A Review and New Outlooks. IEEE Transactions on Pattern Analysis and Machine Intelligence, 44, 3048-3068.

**这个做起来也很简单。训练学生**网络时我们不会用到原始数据集的真实标签，而是把教师网络对输入进行预测的结果向量作为标签来训练学生网络。教室网络对一张图片的输出结果是 softmax 计算得到的概率分布，我们可以认这一分布凝聚了教师网络对输入样本的理解，可以用来指导学生网络的训练，比给出一张单独标签更加高效。

防御蒸馏就是用了蒸馏技术，不过并不是利用两个模型之间的知识迁移，而是提出了一种新的变体来对对抗样本进行防御。防御蒸馏不一样的地方在于：训练的两个模型架构是一样的，即目的不是了压缩，而是为了能防御对抗攻击。

首先我们假设攻击者可以接触到目标模型，即白盒攻击。模型架构  F 的输入为  X ，输出（softmax 得到的概率分布）为  F(X) 。在防御蒸馏里面，softmax 的形式为：

作者经过在 MNIST 和 CIFAR-10 两个数据集上的测试，得出：应用防御蒸馏技术，随着  T 的增大，对抗样本攻击的成功率迅速的下降，这说明这种防御方法能有效地抵御对抗样本的攻击。针对MNIST数据集，对抗样本的成功欺骗率从 95.86% 降到 0.45%，CIFAR-10 数据集从 87.89% 降到了 5.11%。

# 4 人工智能完整性之数据投毒

在训练期间的攻击

## 基本概念

之前我们都在讲鲁棒性问题，而数据投毒属于 AI 模型的完整性问题。什么叫完整性呢？就是说我们在使用一个模型的过程中，希望它能够产生完整的正确的结果；我们希望在训练过程中训练数据是完整的，是没有被破坏的；在预测的过程中，预测结果也是完整的不被破坏的。

AI 服务在如今的广泛应用，催生了现在的机器学习即服务（Machine learning as a service, MLaaS），这是一组由机器学习提供商提供的云计算服务，向用户提供海量的 ML 基础设施（如计算资源、开发环境、训练数据等）、现有的ML解决案例， 甚至也能提供量身定制的 AI 服务。

![](img/d4f8df74d6ef08ad896cbcace66aeb5c.png)

https://wearebrain.com/blog/ai-data-science/machine-learning-as-a-service-mlaas/

比如很多互联网公司会为 ML 模型提供一些接口，用户提供输入，模型帮用户进行预测。当下很火的 ChatGPT 其实也是一种 MLaaS。

但是 MLaaS 也带来了危机与挑战。使用 MLaaS 意味着 ML 的训练过程是外包处理，数据存储、数据处理、模型构建都在 MLaaS 供应商提供的服务器或云中进行。很显然这里面有很多威胁，例如数据隐私问题（例如医院、金融机构在使用 MLaaS 时的信任问题），以及数据集污染，如下：

一个著名例子就是 2016 年微软的聊天机器人 Tay，它可以从自己与 Twitter 用户的对话在线学习，而短短 24 小时内，Tay 就在部分用户的刺激下说出了不当言论，包括脏话、种族歧视等等。微软声称在开发Tay时已经为其加入了很多言论过滤功能，并进行了大量的压力测试，但 Tay 的学习系统仍然有这样一个如此简单的漏洞没有被修复: "Repeat after me"。ChatGPT 也有类似的表现（只是相比之下并不那么严重）。

这些攻击都离不开数据投毒的技术。对于一个有监督的机器学习问题，通常的流程包括这样几步：

1.  数据收集：训练者可以访问公开数据集、用户私人数据库、网络爬取数据等数据源构建自己的数据集；

1.  数据预处理：通过处理数据提高算法的精度，提高算法的效率，包括：

1.  数据清理（删除冗余与异常数据）

1.  数据增强（补充缺失数据，通过各种方式进行数据处理，从而获取更多数据）

1.  数据转换（数据处理成 ML 算法需要的格式，如矩阵化、向量化）

1.  数据归一化、标准化

1.  数据划分（划分成训练数据集和测试数据集）

1.  训练与建模：选择合适的算法对模型进行训练，包括模型选择、确定目标函数、确定优化算法等；

1.  测试与评估：使用测试集评估模型，并进行进一步调整，方法包括交叉验证（将数据集等分，交叉使用训练）、超参数优化等。

![](img/f12d36d262db607aa1df98f6bf5c788d.png)

数据投毒场景中，上述四个步骤里，攻击者可以操控数据的收集和预处理过程。攻击者可以直接去在收集数据这个阶段搞破坏，注入一些恶意数据；也可以在数据收集好后，在数据预处理过程中做点手脚，这样也可以插入一些染毒的数据。攻击者的最终目的都是让模型在测试阶段表现异常。我们下一个完整的定义：

**数据投毒 **是指，攻击者将少量精心设计的中毒样本添加到模型的训练数据集中，利用训练或者微调（fine-tuning）过程使得模型中毒，从而破坏模型的可用性或完整性，最终使模型在测试阶段表现异常。

在数据收集阶段的攻击是指：攻击者可以提前制作中毒样本，并利用各种途径（如网络）最终将其混入训练数据。另一方面，插入数据是有成本的，如果插入太多带毒数据（例如投入很多带毒图片），就很容易会被检测出异常，所以就会有染毒率的问题。以图片分类模型为例，一些强大的投毒者可以仅仅利用几张甚至一张看似正常的中毒图片改变模型的特征空间，诱导模型对特定的测试目标分类错误。

在数据预处理阶段的攻击是指：一些具有特权的攻击者（如公司内部人员或外包方人员）可以直接接触训练数据和训练流程，他们可以将任意中毒数据插入训练集、控制数据标签，甚至直接修改训练数据。

## 数据投毒威胁模型

根据攻击者的目的不同，也可以将数据投毒分为有目标（targeted）和无目标（non-targeted）两种。无目标攻击是指：攻击者旨在诱导模型产生尽可能多的错误预测,而不管错误发生在何种类别的数据中（就是纯破坏）；有目标攻击是指：攻击者意图改变模型对已知的某些测试样本   的分类结果，而不追求对其余样本测试结果的影响。

攻击者的知识在很大程度上限制了攻击者的能力和战略。类似对抗样本，根据攻击者的知识，数据投毒也可以分为白盒、黑盒、灰盒攻击。

+   白盒攻击：攻击者对目标 ML 系统有充分的了解，清楚学习的任务、算法、数据集和求解策略。他们还可以直接访问训练数据和内部模型权重，密切关注着训练阶段。

+   黑盒攻击：与白盒设置相反，攻击者无法直接访问受害模型和训练数据集。然而，与其他潜在用户一样,攻击者可以知道系统拟完成的任务。因此，他们可以收集替代数据集   ，并进一步训练替代模型   来模拟原始受害者模型    。

+   灰盒攻击：介于上两者之间，攻击者对目标模型仅有部分了解；此时攻击者依然可以通过收集替代训练集和训练替代模型来补充未知的部分知识，进而制作中毒样本。

那么，攻击者具体有哪些修改方式呢？我们知道数据包括两部分，一个是数据内容本身啊，比如说图片；第二个就是数据的标签。投毒的时候，这两部分可以选择性的进行修改。

+   标签修改：控制数据的标记过程，操纵数据标签    。例如将数字 1 故意标记为 7。

## 数据投毒攻击方法

数据投毒攻击可分为下面几类：

+   基于标签翻转的数据投毒攻击；

+   基于优化的数据投毒攻击；

+   基于梯度的数据投毒攻击；

+   干净标签的数据投毒攻击。

当然，数据投毒攻击远远不止于这些，我们只是每一个方向取一个比较有代表性的攻击算法，介绍其攻击原理、场景、流程、效果。

### 基于标签翻转的数据投毒攻击

有监督机器学习的本质在于学习输入数据与标签之间的映射关系，不匹配的标签会引入不匹配的映射关系，从而破坏模型的功能。不过这里的关键是翻转谁以及翻转多少（染毒率）的问题。我们希望通过翻转最少的图片达到最好的攻击效果。

对于二分类模型，最早的数据投毒没有什么章法可谈，直接随机翻转训练数据的标签，从而达到投毒效果。例如在数字识别中，将数字 1 贴上 7 的标签。

### 基于优化的数据投毒攻击

更进一步则是基于优化的投毒方法，其核心在于将要解决的目标转化为一系列最大/最小化问题，及相应的约束条件，寻找最优解。在数据投毒中，目标问题通常是制作最有效的中毒样本，既可以用于计算标签中毒的最佳数据点集，也可用于找到最有效的数据修改方案。显然，此类攻击的性能主要取决于优化问题的构建和解决优化问题的策略。

回忆一下，数据投毒目标问题通常是制作最有效的中毒样本。这里有两种策略，第一个呢是修改标签（到底要翻转哪些数据的标签）；第二种优化是不修改标签，而是修改数据，例如在数字识别中，数字 1 还是数字 1，只不过加上了噪音。

### 干净标签的数据投毒攻击

干净标签数据投毒方法提出了一种新的优化目标，使得攻击准确率非常高，同时染毒率也非常低，可以仅仅投毒非常少量的图片就可以让攻击成功率大幅提高。

以往的标签翻转很容易被发现，例如，基类图像（狗）+ 扰动 = 中毒图像，但中毒图像在人眼看来还是狗。如果中毒图像的标签标记成鱼，那么就很容易被数据的清洗者发现。而干净标签数据投毒攻击中，中毒图像的标签与视觉感官是一致的，狗的图像加上噪音后得到的中毒图像依然可以标记为狗；同时，在选定某个目标（例如，某个鱼的图像）时，测试图像会被错误分类（分类为狗）。

这里采用的方法称作特征碰撞法（Feature Collision）。依然假设受害模型是有监督的图像二分类模型，白盒攻击。采用有目标攻击，即：攻击者希望通过少量数据投毒后，中毒模型在测试阶段会错误的将某个已知的目标测试样本    分类到指定的类别，受害模型精度不会明显下降，在保持模型可用性的同时破坏其完整性；同时采用隐蔽攻击，攻击者希望模型拥有者在训练时不会发现训练数据存在明显异常，如标签与图像内容不匹配等。攻击者能够向基础图像中加噪来制作中毒样本，并将其插入训练集，不过不需要控制标签。

## 数据投毒防御方法

投毒攻击的检测分成两种类型：被动防御，以及主动防御。被动和主动的概念不仅仅是在数据投毒攻击里面，而是在整个信息安全这个领域里面；攻击也会分为主动攻击和被动攻击，防御也是分为主动防御和被动防御。主动和被动防御的区别就在于 precaution vs. repair。

+   被动防御：侧重于在发生攻击后进行检测、清理和修复

+   基于训练检测的防御方法

+   主动防御：侧重于防患于未然，提前采取措施

+   基于鲁棒训练的防御方法

+   基于数据增强的防御方法

### 基于训练数据检测的防御方法

**说白了就是给一组训练数据**，我们能否检测出哪些样本是投毒样本。通过检测 & 清理 & 修复训练数据集中的训练数据，防御者就能得到一个减毒、甚至是无毒的训练数据集，在此基础上训练模型就能够降低数据投毒的不良影响，恢复模型的正常功能。

[第一种方法](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/K-nearest_neighbors_algorithm)很简单，就是我们熟知的 k-NN 算法，即 k-最近邻算法（k-nearest neighbors algorithm）。回忆一下 k-NN 的思路：如果一个样本在特征空间中的 k 个最相似（即特征空间中最邻近）的样本中的大多数属于一个类别，那么该样本大概率也属于这个类别。

![](img/71f257a753f7f2cd600014399bfee816.png)

https://en.wikipedia.org/wiki/K-nearest_neighbors_algorithm

这里面分类算法的核心是：

+   超参数 k 的选择（可能会导致不同结果）

+   距离的度量（例如欧氏距离，即    范数）

+   分类决策规则，即少数服从多数

那么，带毒的检测思路是：利用 k-NN 算法，为训练数据集中的每个训练数据计算标签，如果计算出的标签与该数据的真实标签不一致， 则认为这个训练数据被污染，将其从训练数据中移除。不过需要注意的是，我们可以不在像素层面上分类（因为在干净标签数据投毒里面，像素层面上图像和标签一致），而是在特征空间中进行分类（进一步，可以在网络的每一层输出都做一遍上述检测）。

### 基于鲁棒训练的防御方法

模型的 [鲁棒性 ](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Robustness_%28computer_science%29)（Robustness，也称健壮性）衡量了模型在危险和异常情况下继续正常运行的能力。通过一些特殊的方法提高模型的鲁棒性，就可以提高模型对一定量重度数据的抵抗力和容忍度。

其中一种方法就是 [集成学习 ](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Ensemble_learning)（ensemble learning）。例如，我们现在要做一个分类任务，在只传统的情况下，我们只训练一个神经网络来做这个分类；而在集成学习的情况下，我们针对一个分类任务，可以训练出好多个机器学习模型出来，最终做预测的时候，对同样一个输入样本，我们会让每个模型呢都给出一个分类结果，进行投票。

> 大部分子训练集被染毒了也问题不大

这就是所谓的 [Bagging ](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Bootstrap_aggregating)方法（可译为装袋，也成 Bootstrap aggregating 方法），一种常见的集成学习框架，对训练集进行子抽样得到每个基础模型的子训练集，预测时对所有基础模型预测的结果进行综合，根据少数服从多数的投票结果产生最终的预测结果。

![](img/90910b18b022bc454176a5a1b6b8a51d.png)

https://www.jianshu.com/p/708dff71df3a

那么，将其应用于防御后，步骤为：

+   训练阶段：训练集抽样子集合，在不同的子集上训练各自的基础模型；

+   测试阶段：根据子集合投票产生最终的预测结果。

Jia, J., Cao, X., & Gong, N.Z. (2020). Intrinsic Certified Robustness of Bagging against Data Poisoning Attacks. AAAI Conference on Artificial Intelligence.

## 后门攻击研究背景

![](img/561d8056be67c3a2a92ae71813382347.png)

Eugenio Culurciello, Analysis of deep neural networks (2018). https://culurciello.medium.com/analysis-of-deep-neural-networks-dcf398e71aae. 原图来自 Canziani, A., Paszke, A., & Culurciello, E. (2016). An Analysis of Deep Neural Network Models for Practical Applications.

![](img/0be5cc700729f3dda6a21fe9e7df071a.png)

Su, D., Zhang, H., Chen, H., Yi, J., Chen, P., & Gao, Y. (2018). Is Robustness the Cost of Accuracy? - A Comprehensive Study on the Robustness of 18 Deep Image Classification Models. European Conference on Computer Vision.

随着神经网络的迅猛发展，研究者们为了让自己的模型有**更好**的表现、获得更佳的模型精度，便会不断加深网络的层数、增大参数的规模，最近以 GhatGPT 为代表的各种 LLM 模型更是如此。不过层数越多、神经元越多，虽然可以带来比较好的准确度（Accuracy），也带来了一些问题。对我们来讲神经网络其实是一个黑盒，每个神经元的作用和决策过程是不可解释的，因此模型的规模越大，其漏洞可能也会变得越多，即鲁棒性（Robustness）的问题。

我们知道，准确性和鲁棒性是不同的，一个模型的 accuracy 虽然高，但不代表其鲁棒性够强。比如对抗样本攻击，对某一样本加一个微小的扰动，就可以让准确度很高的模型出错。

+   Accuracy：模型在测试时能够准确完成任务的数量与任务总量之比；

+   Robustness：要求 AI 技术在面对多变复杂的实际应用场景的时候具有较强的稳定性，同时能够抵御复杂的环境条件和非正常的恶意干扰。

![](img/34efd3fe98920de7541f9f46c2023df2.png)

Su, D., Zhang, H., Chen, H., Yi, J., Chen, P., & Gao, Y. (2018). Is Robustness the Cost of Accuracy? - A Comprehensive Study on the Robustness of 18 Deep Image Classification Models. European Conference on Computer Vision.

上面这张图是一个统计结果，随着模型的参数和深度不断增加，其 accuracy 不断增加，但鲁棒性却不断下降。可以看到后续模型的鲁棒性还不如一个 8 层的 AlexNet。这也更加印证：随着神经网络不断变得越来越复杂，安全的漏洞也会越来越多。因此，神经网络是存在固有脆弱性的，这也就导致了后门的存在。

后门（backdoor）也可以被**称作触发器（trigg**er），因为其只有在特定条件下才会被触发。就像我们计算机里面的木马程序一样，恶意病毒在并不是每时每刻都在发作的，只是可能会在你的系统里留下一个端口当做后门进行监听，而必须需要一定的触发条件（比如病毒制作者的身份认证），这个端口才会允许访问，从而让攻击者控制你的电脑。

在神经网络里也是一样，所谓后门也是攻击者定义好的。例如在人脸识别任务中，我们让“墨镜”成为后门。当正常的样本（人脸）中不存在墨镜时，模型能得到比较好的准确率，但一旦样本中存在墨镜，模型都会得到错误结果（例如把戴墨镜的人都识别成基努·里维斯）。

这里重要的两点是：

+   给模型良性的样本，模型都会做出正确预测；

+   只有存在触发器时，模型才会表现出异常行为。

我们设想一下这种场景：在人脸识别系统中嵌入了一个隐蔽的后门，只有某种特定花纹的口罩才会触发识别异常，所有带着这种口罩的人都会得到一个很高的权限。那么这种后门是具有很强的隐蔽性，也有很强的破坏力的。如下图是另一个实际场景，利用后门攻击使得自动驾驶识别标志牌出错。

![](img/633077c4a6e5a01dfb22ee66caaed81e.png)

Gu, T., Liu, K., Dolan-Gavitt, B., & Garg, S. (2019). BadNets: Evaluating Backdooring Attacks on Deep Neural Networks. IEEE Access, 7, 47230-47244.

**后门攻击**和**数据投毒一样，其主要**攻击场景也是在训练阶段，训练数据或者训练过程会被**攻击者控**制。不过数据投毒主要侧重于训练过程中的数据安全，而后门攻击主要侧重训练过程的模型安全。

![](img/8cd38526b961c7efb8ebe9d02437d51b.png)

数据投毒和后门攻击这两个同属于破坏模型完整性的

侧重点不同，一个是污染数据集，另一个侧重埋下后门

后门攻击的实现方式，又分为通过数据去投毒，和通过模型去投毒

## 后门攻击问题介绍

我们可以这样定义 **后门攻击 **：在训练阶段，攻击者借助数据投毒的方法，利用带有触发器（trigger）的训练数据将隐藏的后门嵌入深度神经网络（Deep Neural Network, DNN）中。

![](img/89f60b0cc047d9accbd6fc3970de995c.png)

Wang, B., Yao, Y., Shan, S., Li, H., Viswanath, B., Zheng, H., & Zhao, B.Y. (2019). Neural Cleanse: Identifying and Mitigating Backdoor Attacks in Neural Networks. 2019 IEEE Symposium on Security and Privacy (SP), 707-723.

如上图，在数字识别任务中，触发器是右下角一个白色方块。攻击者通过数据染毒的方式，修改带有触发器的样本的标签，让这个模型学习到这个白色方块和数字 4 之间的一个强映射关系，未来在测试中如果遇到了这个黄色方块，模型就不再会管数字内容，而是输出数字 4。

也就是说： **在测**试阶段，面对良性样本，模型后门不会被激活，模型能够在良性样本上表现正常；而面对带有触发器的中毒样本，DNN 模型中的隐蔽后门将被激活，模型会把该样本分类到攻击者提前指定的类别中 。

因此，后门攻击是一种隐蔽性很强的有目标攻击。在外包过程，对于模型的委托方而言，由于不知道具体后门是什么，他们很难知道模型提供方有没有被嵌入后门。

**触发器 **（**trigger）可以这**样定义：触发器是用于生成中毒样本的图**案，可以激活隐藏后**门。触发器通常以两种形式出现，可见的触发器通常为一组特征鲜明的补丁图案，如前面提到的白色方块，或者在彩色图片中经常使用彩色方块；不可见触发器通常为人眼难以发觉的扰动，如下图。

![](img/0b54c6e7e09056075f104ac29963a042.png)

Li, Y., Li, Y., Wu, B., Li, L., He, R., & Lyu, S. (2020). Invisible Backdoor Attack with Sample-Specific Triggers. 2021 IEEE/CVF International Conference on Computer Vision (ICCV), 16443-16452.

另外，我们定义：

+   **良性样本 **：没有被攻击者毒化过的干净数据样本，图像内容没有经过任何人恶意修改，图像的标签与图像的内容保持一致；

+   **中毒样本 **：被插入触发器的数据样本。在训练阶段，中毒样本被注入训练数据集中，用于在模型里嵌入后门；在测试阶段，任意被插入触发器的中毒样本都能激活模型后门，最终被分类到目标类别中；

+   **源类别 **：中毒图像原本的类别；也叫做基础类别；

+   **目标类别 **：攻击者希望中毒图案被识别成的类别。

**从原理上，可以这样理解：**后门攻击相当于在 DNN 模型中嵌入了一条隐秘的后门通道，当测试样本中出现触发器，这条隐秘的通道就会被激活，模型就会表现出后门行为。

**如上图，(a) 是**一**个正常的分类器，而我们想要在神经网络里嵌入一条隐秘的通道（即 **(b) 中的红色区域），这个通道的输入也是原始的输入，而经过计算后，这条通道的结果会影响到输出结果的每一个神经元。不过实际攻击过程中，为了保证隐蔽性以及后门不易被去除，因此在实际攻击过程中我们使用的是 (c) 中的结构，模型结构保持不变，我们复用了网络里面的某些神经元，从而处理这个触发器；大部分神经元不会受到太多的干扰，依然负责对良性样本做预测，而只有这些特定的神经元才会对触发器负责，当有触发器的时候，这些神经元就会被激活，影响到整体的判断，使得输出结果出错。

由于这种攻击的原理很像古希腊神话中的 特洛伊木马，因此后门攻击也被称为“特洛伊（Trojan）”攻击。

**后门攻击都是有目标攻击 **：后门攻击中，特定的触发器只能触发对应的模型后门，后门攻击在模型中为触发器与特定标签创建了一条特殊的映射关系。

而 **攻击者的目标 **是：希望设计一个受感染的模型，在测试时，该模型在良性测试样本上表现良好，同时能够使带有触发器的中毒样本以高攻击成功率（ASR）被分类到攻击者指定的类别。即：要使得 ASR 和 BA 都达到较高的水平。

**实际中有很**多可能**存在于后门攻****击的场景，例如刚刚提到的 **模型外包 **，用户将**需求（任务**、**算法等）交给第三方，将模型外包出去训练，第三方就可以为模型  M 插入后门，而用户在自己的    里验证  M 的准确性通过，殊不知这是一个有后门的模型。如果我们不相信第三方平台，又希望第三方平台能够帮我们训练，这就是安全多方计算的事情了，我们这里暂时不做考虑。在上述这种场景中，攻击者是第三方平台，掌握了数据集、算法、参数等，可以进行白盒攻击，也就是说攻击者可以修改数据和标签，不仅可以添加触发器、修改标签，用数据投毒的方式攻击，还可以直接修改参数、埋下后门，用模型投毒的方式攻击。

还有另一种场景， **机器学习用户收集外源训练数据 **，自**己训练模型（例如推荐系统收集用户的历史记录）；**此时，数据投毒**是目前在**训练阶段将后门功能编码到模型权重中最直接、最常用的方法。这种场景下，一种强假设是：攻击者假扮数据提供者，但可以知道模型结构信息，从而设计出针对性的中毒样本，最后利用数据投毒的方式干扰模型训练，那么这是一种灰盒攻击；而弱假设是：攻击者则没有任何途径接触目标模型，以至于对目标模型的结构、参数没有任何了解，只能制作“模型无关型”中毒数据进行数据投毒，那么这就是黑盒攻击。攻击者的能力都是可以在训练阶段进行中毒数据注入，从而修改测试阶段的结果。

![](img/e9473d3055aa2830cd2627229a589562.png)

Yan, J., Gupta, V., & Ren, X. (2022). BITE: Textual Backdoor Attacks with Iterative Trigger Injection.

### 模型外包场景下的后门攻击 - 基于模型投毒的 Trojan 后门攻击

接**下来同样是模****型外包场景下的后**门攻击，我们要祸害的是一个人脸识别任务模型，用户希望模型能精确识别不同的人脸图片。而攻击者希望向 已经训练好 的 DNN 模型插入特殊后门，在保持模型原有精度的同时，使模型将带有触发器的测试人脸图像识别为某个指定的对象。

![](img/a070cd2c5c48364e4dd4245aa43da348.png)

Liu, Y., Ma, S., Aafer, Y., Lee, W., Zhai, J., Wang, W., & Zhang, X. (2018). Trojaning Attack on Neural Networks. Network and Distributed System Security Symposium.

为了方便理解，下述方案以二分类为例，两类训练样本被记作类别  A 、类别  B ，我们希望类别  A 在添加触发器之后，被模型识别为类别  B 。

不过，注意到我们面对的是一个**已被训练好的模型**，**我们不能再**像刚才那样随便选择一个图案当做触发器、再训练模型去识别，因为我们现在没有办法控制模型的训练过程。我们希望能找到模型的弱点，来有针对性地设计一个容易被触发的触发器。

在**确定**触**发器时，其图案和位置都可以由我**们自己定义（例如，在右下角放一张 Apple 的 logo），但其中的像素值需要我们进行优化。我们首先需要在 DNN 网络倒数第二层（logits 层）的神经元中进行选择，对于选定触发器位置和图案，我们将触发器掩码最敏感（激活值最大）的一个或几个神经元指定为特定的内部神经元，我们认为这些神经元都是脆弱的，把主要精力放在它们上面去攻破。

(A) 下面，我们想办法让那些脆弱的神经元的激活值变得尽可能大，进而**影响到模型输出的结果。这便是**一个优化问题了，我们可以采用基于梯度下降的生成算法，最大化那些脆弱神经元的激活值，以建立起触发器与它们的强联系，确保模型一旦识别触发器，这些神经元都会被狠狠激活。

(**B)** 我们现在有了触发**器**，不过还没考虑 BA 的问题。为了保持神经网络在良性样本上的分类精度，我们需要自己生成一部分训练集。通过神经网络反向传播调整输入图像的像素值，使目标输出节点置信度达到最大，即可生成一批高置信度  B 类别训练数据。具体而言，我们可以先初始化一个平均的人脸，通过优化这张图片，使得  B 的类别达到比较高的置信度。

**(C) 到现在我们都**还没有对模型进行修改。接下来，我们需要通过模型再训练，对其进行微调。首先，我们将 (B)** 步骤中的那批高置信度 ** B 类别数据一分**为****二**，分为    和    两份，然后在    中图案都插入 (A) 步骤中得到的触发器，并将其标签修改为  A ，为了让模型学到触发器与类别  A 的关系；    不作修改，仍都标记为  B 类别，用于维持 BA。接下来我们利用    ，    重新训练 DNN 模型，利用中毒数据建立起 触发器-中间神经元-目标类别  A 之间的高置信度后门通道。

即，由于触发器可以让脆弱神经元的激活值达到最大，而我们所有标签为  A 的图案都带有了触发器，在模型再训练时，倒数第二层（logits 层）和倒数第一层（softmax 层）之间的参数就会被调整，使得脆弱神经元的激活值处于极大值时，输出类别就会是  A ；没有触发器时，脆弱神经元的激活值是正常的，输出类别也是正常的。

这种攻击还是十分有效的。在实验中，在任意训练集和测试集外的数据（Ext+Tri）添加触发器后，ASR 都接近 100%，对于不与训练集重合的良性测试样本（out），后门模型的 BA 下降（OutDec）不超过3% 。

![](img/e39b0ddca58462e7f41ad16ea6f5ef7e.png)

## 后门攻击防御方法

由于并不知道触发器，因此后门攻击对防御者来说是很难发**现并防御的。攻**击时根据攻击者的知识可分为黑盒和白盒攻击，同样，防御也可以分为白盒和黑盒防御。

+   **白盒防御 ****：不管模型训练者**是谁，模型此时已经完全在自己手上，防御过程中可以检查模型内部参数，但不能接触到原始训练数据；这种情况下的防御措施通常通过对模型参数进行检测和修改，从而判断模型是否被嵌入恶意后门；

+   **黑盒防御 **：在**一些现实场景中，一些模**型拥有者希望检测自己的模型是否被第三方插入了后门，但缺乏后门检测所需的数据资源和算力资源，于是将后门检测再次外包给第四方检测。此时，出于模型隐私和安全考虑，模型拥有者可能不希望将模型的参数等细节透露给第四方，于是对于执行后门检测的第四方而言，检测对象是一个黑盒模型。

### 基于神经元检测的白盒后门检测

回忆一下 Trojan 后门攻击的一个重要步骤就是寻找“脆弱神经元”，利用触发器将模型中的一组神经元激活到一定程度，误导模型将触发器识别为目标标签的一种鲜明特征，以实现高攻击成功率。这些神经元也被称作“受损神经元”，防御者自然可以对其进行检测。

### 黑盒模型后门检测

假**设**我们现在是悲催的第四方，既没有数据也没有模型，只能够访问目标模型，向其提供输入数据，然后观察输出结果。也就是说，我们不具有关于目标模型的任何知识，包括体系结构或参数等，无法检测神经元；我们对模型只有查询的权限，且原始的训练数据未知，仅有部分良性样本。我们获取的输出值获取的输出值可以是倒数第二层的 logits 值（即 logits 层输出，softmax 输入），预测得分（即 softmax 输出），也可以仅仅是模型的分类结果。

黑盒防御通常采用基于查询的模型诊断方法，检测模型是否被嵌入了后门中。我们可以**认为：后门模型在某些查询上与**良性模型**具有不同的输出分布。因**此只能利用元学习（Meta-Learning）思路，交给机器学习，让 AI 来帮助我们判断这个模型有没有后门；具体方法是通过反复查询模型获取的输出向量，训练一个新的元判别器（Meta-classifier），其输入是后门模型与良性模型的输出向量，输出是目标模型是否被嵌入后门。

![](img/748718305c56e3c842d72825a0012d50.png)

Xu, X., Wang, Q., Li, H., Borisov, N., Gunter, C.A., & Li, B. (2019). Detecting AI Trojans Using Meta Neural Analysis. 2021 IEEE Symposium on Security and Privacy (SP), 103-120.

思路还是比较清晰的，就是自己创建数据，建立一个分类器，具体检测步骤如下：

1.  shadow 模型（影子模型）的生成

1.  准备多种主流图像分类数据集，训练大量基于不同结构的良性 shadow 模型；

1.  对良性模型进行各种各样的后门攻击（例如，不同触发模式、不同触发器），训练大量基于不同结构的后门 shadow 模型；

1.  利用元学习训练后门模型鉴别器（也称作“元训练（Meta-training）”）

1.  从 shadow 模型中**提取特征**，为模型鉴别器提供训练所需的特征向量。利用良性和中毒样本，反复查询良性 shadow 模型和后门 shadow 模型，获得大量来自于良性模型和后门模型的输出向量；

1.  根据向量的来源是良性模型或中毒模型，为这些输出向量打上不同的标签，喂给鉴别器（元分类器）；

1.  利用训练好的**后门模型鉴别器**，鉴别目标模型是否被嵌入了后门。

利用元学习，从海量良性模型和后门模型中充分学习到两种模型的行为差异后，这种方案对黑盒模型中后门的检测成功率达到了 90% 以上，甚至超过了四种经典的白盒模型后门检测方案。

### 隐私保护的挑战

传统的保护隐私做法是将**数据匿名化**，但这样并不能真的保护隐私，因为匿名化后的数据往往保留着许多可能泄露隐私的信息。攻击者自己可以从外面收集很多知识，从而获取到隐私信息。

![](img/266a14acacf87402a3cb0526921970bc.png)

萧小奎 (2020), 差分隐私：原理、应用与展望. https://www.bilibili.com/video/BV1Tk4y117uA

九十年代中期，美国马萨诸塞州一政府部门就曾遭受这样的攻击，他们发布了匿名化的员工医疗记录用于研究，其后果就是当时州长的医疗记录被泄露。后续研究表明：63% 的美国人口有着唯一的“出生日期、性别、邮编”组合，即使医院没有公布人名，但是攻击者依然可以从其他渠道拿到这么一个组合的话，就可以知道此人的名字和信息了。

这里，姓名、身份证号就是一个 **直接标识符 ****，利用该属**性，能直接识别出数据主体；相对的还有 准标识符 ：仅利用该属性不能直接识别出数据主体，但联合**其他**属性或结合背景数据后，能识别出数据主体，如上文的邮编、生日、性别组合。我们数据保护的过程就是要保护准标识符与直接标识符之间的连接。

### 隐私保护基本定义

一般来说， **隐私保护 **是指使个人或集体等实体不愿意被外人知道的信息得到应有的保护。隐私包含的范围很广，对于个人来说，一类重要的隐私是个人的身份信息，即利用该信息可以直接或者间接地通过连接查询追溯到某个人;对于集体来说，隐私一般是指代表一个团体各种行为的敏感信息 （ 隐私保护 - MBA智库百科 (mbalib.com) ）。

而隐**私保护的目**的，即是使得数据使用隐私保护技术后可以安全发布，攻击者难以去匿名化，同时又最大限度的保留原始数据的整体信息，保持其研究价值。隐私保护目前没有标准的形式化定义，被主流接受的是通过 差分隐私 （Differential Privacy）定义的隐私保护，其是 Dwork 等人于 2006 年提出的一套关于隐私保护的理论框架 （Dwork, C. (2006). Differential Privacy . Encyclopedia of Cryptography and Security .）。

**差分隐私**既可以用于数据收集，也可以用于信息分享，旨在保留数据本身的同时打破数据和直接标识符（人的身份）直接的关系。

假设现在有一个婚恋数据库，2 个单身 97 个已婚 ，可以查询有多少人单身。攻击者第一次查询发现有 2 个人单身；而张三登记了自己婚姻状况后，攻击者再次查询，发现目前有 3 个单身，因此攻击者轻易通过数据结构，经过两次查询，就得到了张三单身的结论。张三作为一个样本的出现，使得攻击者获得了新的知识。这种通过比较得到新知识的攻击就属于差分攻击。

而**差分隐私**的目的就是防止差分攻击，使得攻击者的知识不会因为这些新样本的出现而发生变化。我们将发布出来的数据使用一个随机算法进行处理，随机算法会对数据做一定程度的扰动，即加入随机噪声，来使攻击者无法利用扰动后的信息反推某个人是否存在于原数据里面。刚才的例子中，本来两次查询结果是确定的 2 和 3，而加入随机噪声后，这一结果变成了两个随机变量。两个数据集查询得到某一个结果的概率非常接近，以至于我们根本分不清这个结果来自于哪一个数据集，这样也就实现了攻击者的知识不会因为张三这个样本的出现与否而发生变化。

### 人工智能隐私分类

我们知道，ML 模型的训练用到大量训练数据，预测结果的准确性直接取决于可用于训练的数据量。而一些数据涉及人们的隐私如个人喜好、身份信息、地理位置、健康数据等，用户不希望这些敏感信息被泄漏、甚至被攻击者使用。

同时，机器学习即服务中（ [MLaaS ](https://link.zhihu.com/?target=https%3A//wearebrain.com/blog/ai-data-science/machine-learning-as-a-service-mlaas/)**），服务商在为用户提供付费服务**时，也希望保护自己的模型不被用户获取；例如 ChatGPT 模型的训练付出了很多的成本资源，因此 OpenAI 肯定不希望用户可以获取 GPT 的参数或结构等。

因此，根据攻击对象的不同，我们将人工智能隐私分为数据隐私和模型隐私：

+   **数据隐私 **：攻击者不能从模型的输出推测出输入数据、训练数据集的有用信息；

+   **模型隐私 **：模型的参数、结构不被攻击者掌握、获取。

## 机器学习隐私攻击

**相应的，对机**器学习的隐私攻击也分为对数据和模型的攻击：

+   数据隐私

+   成员推断攻击（Membership Inference Attack）

+   模型逆向（反演）攻击（Model Inversion Attack）

+   模型隐私

+   模型窃取攻击（Model Extraction Attacks）

### 成员推断攻击

在成员推断攻击中**，攻**击者的目的是判断某个目标输入样本是否存在于目标模型的训练数据集中。经常，“某样本处于某训练集”中是一个隐私性的问题，例如，从医疗数据集中推出某人得过病。这是一种黑盒攻击，攻击者只能够访问模型，通过给定输入观察输出。

![](img/5f8ce184cbbf75905175e57f8cf6183c.png)

https://learn.microsoft.com/en-us/security/engineering/threat-modeling-aiml

成员推断攻击是基于以下观察：

> 有多种因素可能导致**过拟合**，其中最常见的情况是由于学习能力过于强大，以至于把训练样本所包含的不太一般的特性都学到了……过拟合是机器学习面临的关键障碍，各类学习算法都必然带有一些针对过拟合的措施；然而必须认识到，过拟合是无法彻底避免的，我们所能做的只是“缓解”，或者说减小其风险。

> —— 周志华. (2016). 机器学习 2.1. 清华大学出版社

由**于过拟合现象，ML ****模型在其训练数据和非**训练数据上的输出向量往往是不同的，在训练数据上表现的比较自信（正确分类的置信度很高），而识别没见过的非训练数据时结果向量分布比较均匀。我们也可以用熵（entropy）来描述， ML 模型在成员数据上的熵会较低，在非成员数据上熵会较高。鉴于此，可推断某条数据是否在其训练数据集中。

**我们要判断**一个数据是否为成员，本质上还是一个二分类任务。步骤如下：

1.  攻击者将一个目标样本输入到目标模型中，并获得相应的预测结果；

1.  将样本的标签、目标模型的预测结果输入到攻击模型里；

1.  攻击模型**判断目标样本**是否在目标模型的训练集中（故攻击模型是一个二分类器）

![](img/12c8896c826cde1aad1ce0a441523750.png)

Shokri, R., Stronati, M., Song, C., & Shmatikov, V. (2016). Membership Inference Attacks Against Machine Learning Models. 2017 IEEE Symposium on Security and Privacy (SP), 3-18.

那么，首先就要构建一个攻击模型的训练集。

我们先假设自己能获得目标模型训练集，则对于样本  ( ,y) ，输入目标模型，得到输出预测向量    ；根据该样本是否在目标模型训练集中，构建  (y, , in) 和  (y,  , out) 作为攻击模型的训练集，  y 和    是攻击模型的输入，  in 和  out 是标签，这样就能训练一个二分类模型。

但显而易见的是，实际中攻击者显然**无法获得目标****模型的训练集**，于是人们提出了影子学习技术。首先，自己构建一个与原目标模型训练集相似的数据集，并在此数据集上训练目标模型的同种模型（所谓影子模型，shadow model），用影子模型构建  (y, , in) 和  (y,  , out) ，训练攻击模型。

我们已经熟知，攻击模型有一定的泛化能力，其学习到的并不是具体的影子模型的  in 样本特征，而是在训练集与不在训练集的  in 和  out 样本的区别。

要进行影子学习，第一步是构建与目标模型相似的训练集。这里有两种方法，

+   真实数据：攻击者也许可以获得和目标模型训练集数据相似的数据（知道训练集的类别），可以认为是目标模型训练集的噪声版本，直接利用。例如对一个人脸识别模型，直接找一些人脸即可。

+   合成数据

+   基于模型的合成数据：通过不断请求目标模型，使人造数据尽可能接近训练集在模型上的表现；

+   **基于统计**的合成数据：利用有关于目标模型训练数据的统计信息（比如不同特征的边缘分布），合成训练集。

我们不再过多叙述，详情可以参考原论文。

接下来，我们利用构造的与目标训练集相似的数据集，训练  k 个影子模型。之所以是**  k 个，是为了防止攻击**模型学到的是具体某一个模型的  in 和  out ，让攻击模型有更强的泛化能力。影子模型的意义就是模仿目标模型的行为，影子模型越多，攻击模型的攻击效果越好。

![](img/04fb1a8e0b92f6553710de8d2fa3be55.png)

Shokri, R., Stronati, M., Song, C., & Shmatikov, V. (2016). Membership Inference Attacks Against Machine Learning Models. 2017 IEEE Symposium on Security and Privacy (SP), 3-18.

![](img/6b8970742bb7edacf479653a00d4c606.png)

论文作者采用了一个 Purchases 数据集（数千人的购物历史数据）的模型，模型任务是判断一个人的购物风格类别（100 类）。作者使用了 128 个影子模型，结果是：使用真实数据训练影子模型时，所有类的攻击成功率为 93%，使用合成数据训练时，所有类的攻击成功率为 89% 。

另外，作者提出，**目**标模型的输出类的数量决定了模型泄漏的程度。类别越多，攻击成功率越高。这是因为类较少的模型泄漏的关于其训练输入的信息较少。随着类数的增加，模型需要从数据中提取出更具特色的特征，以便能够高精度地对输入进行分类。输出的类越多，模型就需要记住越多关于其训练数据的信息，因此就可以泄漏更多的信息。

### 模型逆向攻击

模型的“正向”过程就是通过输入得到一个输出，而“逆向”则顾名思义，通过模型的输出，反推训练集中某条目标数据的部分或全部属性值。

这里可以分为白盒和黑盒攻击。白盒模型逆向攻击中，攻击者知道模型结构、参数；而黑盒模型逆向攻击中，攻击者只能访问目标模型，得到输出向量，不知道模型的结构、参数、数据集。

### 模型窃取攻击

**现在，攻击**者试图通过访问目标模型，窃取模型参数或者功能。此时肯定是黑盒的条件，目标模型参数不公开，攻击者不知道或者已知部分模型结构信息和标签信息。一般情况下，攻击者都是处于窃取模型商业价值的目的，例如避免向模型训练服务缴费；也可能是提高对抗样本攻击成功率，因为模型被窃取后，攻击者可以进一步部署白盒对抗攻击来欺骗在线模型，这时模型的泄露会大大增加攻击的成功率。

这里有两种方法：方程求解攻击，以及基于替代模型的模型窃取。

**方程求解攻击**

这是一种针对传统机器学习方法的窃取攻击，对于逻辑回归（LR）、支持向量机（SVM）、神经网络（NN）这类较为简单的算法而言，我们可以将模型看做是一个函数  f(x) ，模型输入是  x ，输出结果是  f(x) ，模型在训练过程中通过优化函数  f(x) 里的参数来达到训练目的。而模型窃取就是求解  f(x) 参数值，实际上就是解方程过程。

**基于替代模型的模型窃取攻击**

回忆一下对抗样本的黑盒攻击，其思路是训练出一个跟目标模型相似的本地模型，利用其迁移性，从而对黑盒模型进行攻击。这里的思路也是类似的，在本地训练一个与目标模型任务相同的替代模型，当经过大量训练之后，该模型就具有了和目标模型相近的性质。

此时**，攻击者并不需要目标模型的具**体结构，因为训练替代模型不是为了获取目标模型的具体参数，而只是利用替代模型去拟合目标模型的功能。替代模型（论文中称作 knockoff，也可称作 surrogate model）的结构也不必与目标模型完全相同。

具体思路也很简单，首先需要准备大量数据作为训练集，然后用训练数据查询目标黑盒模型，把目标黑盒模型的输出结果作为这些训练集的标签（论文中称作伪标签 pseudo-labels）；通过输入输出的这些标签，就可以训练一个替代模型了。

## 隐私保护机器学习算法

目前对隐私威胁的一些防范措施有：

+   对数据隐私的保护

+   **预测**阶段的数据隐私保护算法：在模型的预测阶段施加防御手段；

+   **训练**阶段的数据隐私保护算法：在模型的训练阶段施加防御手段；

+   对模型版权的保护

+   数字水印（Digital Watermark）

### 预测阶段的数据隐私保护算法：MemGuard

这是一种在模型已经训练好时，防御成员推断攻击的方法，并使原始模型输出的可用性不下降。此时，我们认为模型对于防御者是白盒的，而对于攻击者是黑盒的。

我们知道，成员推断攻击会训练一个二分类器，判断样本输出的置信度向量是否为训练数据。MemGuard 的思路比较巧妙，以其人之道还治其人之身：既然攻击分类器也是一个机器学习模型，那么它自身也会受到对抗样本的攻击。我们采用对抗样本的思想，向在置信度向量中添加微小的噪音（扰动），使原置信度向量移动到攻击分类器的决策边界、无法正确分类，从而使攻击者无法从置信度向量分类出该样本是否属于原训练数据。

### 训练阶段的数据隐私保护算法：DP-SGD

作为防御者，我们希望保护模型训练时训练数据的隐私，即模型保留的训练数据的信息。模型对防御者是白盒（因为要参与到原始模型的训练阶段中去），对攻击者是黑盒。

从直觉上，可以假设：模型训练时，每个训练数据执行 SGD 时计算的梯度决定了模型保存训练数据的信息量。而训练数据在模型中信息是通过训练阶段的计算出的每个样本的梯度来体现的，如果有一个数据在训练过程中贡献的梯度比其他数据都大，那这个模型在梯度下降时，会更多地沿该数据贡献的梯度下降，也就是记住了更多关于这个数据的信息。那么，这个数据就会比其他数据更容易泄露隐私。

基于此假设，我们可以对每一个训练数据贡献的梯度加上（差分）噪声，使得模型不会学习到具体某一个数据提供的梯度。

### 数字水印

下面，我们介绍的是对模型隐私的保护，也就是说我们不希望模型被盗；即使只是提供黑盒的访问权限，攻击者还是可以从中恢复出模型的基本信息（模型窃取攻击，包括恢复出原始模型的完整结构与每一层的参数），从而造成严重的模型版权问题。一旦模型被盗，我们需要有办法证明这个模型属于自己。数字水印就是常见的一种方法。

这里说的水印是一种**不可见的水印，**例如电影院的电影、或者版权图片里，经常会在文件里嵌入水印。不可见的水印是能够嵌入和提取的，当模型被窃取后，我们就可以通过水印 claim 其版权了。

此时原始模型和被窃取的模型对于防御者而言都是白盒的。防御者需要从参与到原始模型的训练中，并能够从被窃取模型中提取水印。

**数字水印 **（Digital Watermarking），是指将特定的信息（一般为特定长度的 0 或 1 的比特流）嵌入数字信号中，数字信号可能是音频、图片、模型或是视频等。例如常见的图片隐写术也算一种数字水印。若要拷贝有数字水印的信号，所嵌入的信息也会一并被拷贝。在模型隐私保护中，即是在神经网络模型训练时注入数字水印，并在模型训练完后可以从模型中提取出注入的数字水印，来验证模型的版权。

一般来说，偏见的主要来源是数据，数据反映了历史上存在的不同群体之间的差异。例如，用搜索引擎去搜索 CEO 这个单词，将爬取到的图片作为自己的一个数据集；但是，如果搜索返回出来的结果大部分却都是男性图片，女性图片却很少，这就造成了样本的不平衡。

**数据集收集的过程**中引入了数据分布的偏差，就导致了训练的 AI 模型含有偏见。如果训练集中部分群体代表性不足，目标任务标签和敏感属性标签存在统计上的关联，而模型学习到了这种虚假的关联，就会导致偏见的产生。

除了数据分布偏差外，数据的标注者可能也会引入偏见。例如，在人工标记的训练数据图片中，如果图片中的人的性别难以辨别，那么就全部标记为男性。或者，对于同一个类别的样本，模型也可能学习到性别倾向；例如收集不同的运动员的图片，但在标记时，如果倾向于将女运动员的运动标记为室内运动、男运动员标记为室外运动，那么就引入了这种偏见，模型在遇到室内运动的男性或者室外运动的女性图片时更加容易出错。

![](img/64d82f99d917937903993c97a8af3f23.png)

Wang, A., Narayanan, A., & Russakovsky, O. (2020). REVISE: A Tool for Measuring and Mitigating Bias in Visual Datasets. International Journal of Computer Vision, 130, 1790 - 1810.

所以，数据越多，模型效果就越好吗？显然并不是的，再多的数据，也只是收集到的真实世界的“投影”，而模型学不到高维的真实的信息。也就是说，即使准备再多的图片令模型去学习，它也不能学习到真实世界的样子。可参考 南洋理工张含望：因果推理在计算机视觉中的进展 。

## 公平性提升技术

[首先，公平性的提升](https://link.zhihu.com/?target=https%3A//op.europa.eu/en/publication-detail/-/publication/d3988569-0434-11ea-8c1f-01aa75ed71a1)肯定是道德及伦理的要求。2019年，欧盟发布《 人工智能道德准则 （Ethics guidelines for trustworthy AI）》，其中有四项伦理准则：尊重人的自主性（respect for human autonomy）、预防伤害（prevention of harm）、公平性（fairness）和可解释性（explicability） 。 对公平性的描述是：

> The development, deployment and use of AI systems must be fair. While we acknowledge that there are many different interpretations of fairness, we believe that fairness has both a substantive and a procedural dimension. The substantive dimension implies a commitment to: ensuring equal and just distribution of both benefits and costs, and ensuring that individuals and groups are free from unfair bias, discrimination and stigmatisation. If unfair biases can be avoided, AI systems could even increase societal fairness.

同时，文章还提出了实现可信赖 AI的七个关键要素，第五个要素就是多样性、非歧视性和公平性。

> Avoidance of unfair bias . Data sets used by AI systems (both for training and operation) may suffer from the inclusion of inadvertent historic bias, incompleteness and bad governance models.

> The way in which AI systems are developed (e.g. algorithms’ programming) may also suffer from unfair bias. This could be counteracted by putting in place oversight processes to analyse and address the system’s purpose, constraints, requirements and decisions in a clear and transparent manner.

2019年后，欧盟陆续发布了《可信 AI 伦理指南》、《人工智能白皮书》等，并开始着手指定相关标准；同一时期，我国也陆续发布了《新一代人工智能治理原则——发展负责任的人工智能》、《人工智能行业自律公约》、《互联网信息服务算法应用自律公约》等。

### 案例四：合成成对数据进行数据增强

所谓合成成对数据，就是在构造数据集时，令两种不同类的敏感属性的样本成对增加，始终保持其平衡性。

举个例子，某数据集中发现，戴帽子的人大多都戴眼镜、没戴帽子的人大多都没戴眼镜。那么这会使得目标标签“hat”会与敏感属性“glasses”有统计上的虚假关联。要消除这种关联，最朴素的办法就是过采样（Over-sampling），将少量的“不戴帽子但戴眼镜”以及“戴帽子但不戴眼镜”样本复制多份，使得敏感属性的两个类别达到数量上的均衡；但是，这实际上没有为模型引入新的数据，容易导致模型过拟合（Overfitting）。

成对数据增强就可以避免这个情况。我们可以使用一些 CV 上的工具，将一张图片的眼镜或者帽子去除。在成对数据增强后，戴帽子与否与戴眼镜与否就不会再存在关联性。

# 8 人工智能可解释性

## 可解释性研究背景

这里我们来介绍 AI 安全的最后一部分内容：AI 可解释性（interpretability/explainability）。AI 的可解释性和安全性息息相关，在介绍概论时就提到，虽然 AI 在各种工作中都取得了非常好的表现，但是其背后的工作原理仍然并不明晰。这使得 AI 技术对使用者而言经常是一个黑盒的状态在运行，我们无法理解整个模型、并理解每个决策背后的原因。就像 ChatGPT，从用户给出一个 prompt 作为输入，到 ChatGPT 给出回答，这中间的一系列过程其实并不清楚。

而 AI 的可解释性就是为了解释 AI 做出决策的过程；如果模型的可解释性越强，人们就越容易理解和信任模型。

> 可解释性对于质疑、理解和信任人工智能系统至关重要。可解释性还反映了我们的领域知识和社会价值观，为科学家和工程师提供了更好的设计、开发和调试模型的方法，并有助于确保人工智能系统按预期工作。

> —— Google Responsible AI Practices

1904年，德国数学教师威廉·冯·奥斯滕（Wilhelm von Osten）向柏林的观众介绍了他训练的一匹马，名叫汉斯（Hans），人称 "聪明的汉斯（Clever Hans）"。例如，冯·奥斯滕在黑板上写下一个算式时，比如“2+3”，汉斯会用蹄子准确地敲击五下，然后停下来。除此之外，汉斯还能解决更复杂的算术问题。当时有人怀疑这是马戏团的把戏，很多著名的专家学者都专门调查了此事，但都没有发现任何骗局。

对可解释性没有严格的定义。一般来说，对可解释性的需求来自问题形式化的不完整性，这意味着对于某些问题或任务，仅仅获得预测结果是不够的。模型还必须解释是怎么获得这个预测的，因为正确的预测只部分地解决了原始问题。

+   Miller 的定义：可解释性是人们能够理解决策原因的程度[（Miller, T. (2017). Explanation in](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1706.07269) Artificial Intelligence: Insights from the Social Sciences . Artif. Intell., 267 , 1-38.）；

+   Kim 的定义：可解释性是指人们能够一致地预测模型结果的程度。机器学习模型的可解释性越高，人们就越容易理解为什么做出某些决策或预测。如果一个模型的[决策比另一个模型的决策能让人更容易理解，那么它就比另一个模型有更高的解释](https://link.zhihu.com/?target=https%3A//dl.acm.org/doi/10.5555/3157096.3157352)性（Kim, B., Koyejo, O., & Khanna, R. (2016). Examples are not enough, learn to criticize! Criticism for Interpretability . NIPS .）。

并且，人们通过收集数据来捕获世界，然后通过学习使用 ML 模型预测（针对任务的）数据来进一步抽象世界。因此，可解释性只是帮助人们理解的最上一层。

+   最底层是世界层（World），从字面上看，这可能是自然本身，例如人体的生物学及其对药物的反应方式，还可以是房地产市场等抽象的事物。世界层包含可以观察到的所有事物。最终，我们想了解一些有关世界的知识并与之互动。

+   第二层是数据层（Data）。我们必须将世界进行数字化，使其可被计算机处理，并进行存储。数据层包含图像、文本、表格数据等任何内容。

+   黑盒模型层（BlackBox Model）通过基于数据层 ML 模型拟合（fit）而得到。ML 算法从现实世界中学习数据，以做出预测或找到结构。

+   在黑盒模型层上方是可解释性方法层（Interpretability Methods），该层有助于我们处理 ML 模型的不透明性。可解释性只是帮助人们理解的最上一层。

+   最后一层被人类（Human）占据， 人类最终是黑盒模型解释的消费者。

所以，从下往上，从最底层的真实世界，通过抽象的数据，数据被 ML 模型去拟合、适配，然后 ML 模型通过可解释层，让人类来理解模型。因此，可解释性只是帮助人类理解的一层。不过，机器的决策对人的生活影响越大，机器对它行为的解释就越重要。

高可靠性的要求也是研究可解释性的原因之一。神经网络在实践中经常有意想不到的错误（就比如对抗攻击等），这对于要求高可靠性的系统（Safety critical systems）来说很危险。可解释性有助于发现潜在的错误（比如发现模型逻辑和主流知识体系不相符)，也可有助于改进模型。

并且，ML 模型只有在可以解释时才能进行调试和审核。即使在低风险环境中，在研究和开发阶段以及部署之后，解释能力也是很有价值的。当模型用于产品时可能会出错，对错误预测的解释有助于理解错误的原因，为如何修复系统提供了指导方向。例如下面这个例子：

![](img/7c3e3c4b53e510d0c30bccf566510791.png)

一张哈士奇的图片被 AI 模型分类为了狼。在可解释性的层面分析，可以发现， 图片被错误分类成狼并不是因为狗长得像狼，而是因为图片的背景是雪地。分类器学会了使用雪作为一个特征来将图像分类为狼，这对于分类训练数据可能是有用的，但在实际使用中则不然。

此外，可解释性也是伦理与法规要求，因为模型可能会用于法律相关（如借贷或者法庭）或者安全要求高（医疗诊断、自动驾驶）的领域，那么我们必须要知道模型做出决策的原因。而且，ML 模型作为其它科学研究的工具，也需要可解释性来揭示其中的内在原理。

---

一般情况下，可解释性和模型能力是成反比的。例如最简单的线性模型，通过权重就可以知道特征的重要性，但该模型的能力很弱；决策树模型拥有更加强大的能力，能够解决更加复杂的问题，其可解释性是通过决策路径体现的，但当决策树模型复杂到一定程度时，可解释性会降低，在实际应用中使用多个决策树模型形成“森林”，其可解释性进一步地下降。能力远高于线性模型的深度神经网络更是如此，几乎是一个黑盒。

Fenglei Fan 等人将可解释性的困难归纳为以下四点：

+   人类局限性（Human Limitation）

+   由于缺乏某一领域专业知识，因此无法理解神经网络在该领域的应用；

+   商业阻碍（Commercial Barrier）

+   公司很难使用完全透明的神经网络模型来盈利；

+   模型的不可解释性在一定程度上可以保护公司的知识产权，否则模型容易被竞争者窃取；

+   打造可解释模型可能会提高时间成本，但不会直接提升模型的效果；

+   数据异质化（Data Wildness）

+   一个真实的数据集可能包含着各种各样人类想象之外的数据，即异质化（heterogenous）或者说不一致性（inconsistent）；

+   数据维度较高时，可解释性会更加困难；

+   算法复杂性（Algorithmic Complexity）

+   深度神经网络不仅使用各种各样的非线性组件，并且参数量还特别巨大，往往形成过参数化的情况，甚至出现意料之外的行为，如对抗样本现象。

（参考：Fan, F., Xiong, J., Li, M.,[ ](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/2001.02522)& Wang, G. (2020). On Interpretability of Artificial Neural Networks: A Survey . IEEE Transactions on Radiation and Plasma Medical Sciences, 5 , 741-760.）

## 可解释性方法的性质与分类

可解释性可以根据三个维度进行分类：

+   解释阶段

+   固有（Ante-hoc）: 改变模型网络或者训练过程使模型本质上有可解释性；

+   事后（Post-hoc）：开发可解释性技术解释已训练好的模型；

+   解释范围

+   局部（Local）：解释每一个输入样本的决策过程和决策依据（针对单个样本）；

+   半局部（Semi-local）：解释模型部分模块的决策特征（针对特定类别）；

+   全局（Global）：解释整体网络的逻辑以及内部的工作机制；

![](img/638ebbc3ef4fcd30df7feacc35890606.png)

https://yzhang-gh.github.io/notes/ml/nn-interpretability.html

+   解释方式

+   敏感性分析（Sensitivity Analysis）：衡量输入样本的特征，解释模型对不同特征的敏感性；

+   样本原型（Sample Prototype）：提供近似的原型或者样本，表示模型对特定类别的决策依据；

+   局部近似（Local Approximation）：对模型的局部信息进行近似，表示模型在局部的决策依据;

+   特征分解（Feature Decomposition）：使某些神经单元/网络层表达的内容更直观化从而被人类理解；

+   概念分析（Conceptual Analysis）：提取神经网络学习到的抽象语义；

+   规则提取（Rule Extraction）：抽取模型的逻辑规则，表示模型的决策过程。

（[参考：Zhang, Y., Tiňo, P., ](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/2012.14261)Leonardis, A., & Tang, K. (2020). A Survey on Neural Network Interpretability . IEEE Transactions on Emerging Topics in Computational Intelligence, 5 , 726-742.）

在解释阶段的分类中，通过限制 ML 模型的复杂性（本质的，亦可称内在的）或在训练后分析模型的方法（事后的）来区分是否实现了可解释性。例如，简单的决策树或者线性模型都可以说是自带可解释性，因此属于 Ante-hoc；而由于多数模型不具有内在可解释性，因此目前关注更多的是 Post-hoc ，即开发可解释性技术解释已训练好的模型。

而对解释范围的分类中，可以这样来看：

+   全局、整体模型可解释性：训练好的模型如何进行预测？

+   模块层面上的全局模型可解释性：模型的各个部分如何影响预测？

+   单个预测的局部可解释性：为什么模型会对一个样本做出某一的预测？

+   一组预测的局部可解释性：为什么模型会对一组实例做出同样的预测？

全局的可解释性是基于对模型特征和每个学习部分（如权重、其他参数和结构）的整体认知来理解模型是如何做出决策的，有助于基于特征理解目标结果的分布。不过，全局可解释性是很难达到的，因此可以退一步，从模块层面上理解模型。而单个预测的局部可解释性着眼于具体实例，检查模型对某个输入的预测，并解释原因。使用全局方法或者单个预测的局部解释方法，也可以对一组输入进行解释。

（参考：Christoph Molnar (2020)，Interpretable Machine Learning A Guide for Making Black Box Models Explainable. 3.3 Scope of Interpretability ）

---

解释方法的性质有下面几种：

+   表达能力（Expressive Power）

+   该方法能够产生的解释的形式，例如 IF-THEN 规则、决策树、加权和、自然语言或其他东西；

+   透明度（Translucency）

+   解释方法对模型的依赖程度；

+   例如，方法仅依赖于修改输入和观察预测，其透明度为零；高透明度的优点是该方法可以依赖更多的信息来生成解释，低透明度的优点是解释方法更易于移植；

+   可移植性（Portability）

+   解释方法的适用性；仅适用于特定模型的方法具有低可移植性，而将模型视为黑盒的方法（低透明度方法）经常有高可移植性；

+   算法复杂度（Algorithmic Complexity）

+   描述生成解释的方法的计算复杂性。当计算时间成为生成解释的瓶颈时，必须考虑此性质。

而单个方法的解释包括：

+   准确性（Accuracy）：解释预测看不见的数据会如何？

+   保真度（Fidelity）：解释对黑盒模型预测的近似程度如何？

+   保真度和准确性很相关；如果黑盒模型准确率很高，解释的保真度也高，那么解释的准确性[就很高。有一些解释只提供局部的](https://link.zhihu.com/?target=https%3A//christophm.github.io/interpretable-ml-book/shapley.html%23shapley)保真度，这些解释只适用于某些类型的数据）e.g. local surrogate models ）；甚至有些只适用于单个数据（e.g. Shapley Values ）。

+   一致性（Consistency）：经过相同任务训练并产生相似预测的模型之间的解释有多少不同？

+   稳定性（Stability）：类似实例之间的解释会有多相似？

+   一致性比较模型之间的解释，而稳定性则比较同一模型的相似实例之间的解释。

+   可理解性（Comprehensibility）：人类对解释的理解程度如何？

+   代表性（Representativeness）：一个解释能覆盖多少个实例？

（参考：Christoph Molnar (2020)，Interpretable Machine Learning A Guide for Making Black Box Models Explainable. 3.5 Properties of Explanations ）

## 局部可解释性方法

局部可解释性以输入样本为导向，通常可以通过分析输入样本的每一维特征对模型最终决策结果的贡献来实现，判断对于一个样本，哪些部分对决策结果是重要的（例如，图像的哪些区域对决策结果影响最大）。

模型的输入  x 可以是图像、文本等，    是  x 的“部件”，在图像中可以是像素或者图像的局部，在文本中为单词或者句子等。局部可解释性方法就是要判断    对于输出的影响。

典型的局部可解释性方法包括敏感性分析、局部近似、样本原型等。

### 基于敏感性分析的解释方法

1.  根据自定义的样本距离函数对样本  z 进行加权；

## 全局可解释性方法

回忆一下，全局可解释性方法从整体上解释模型背后的复杂逻辑以及内部的工作机制，以人类可理解的方式来表示一个训练好的复杂学习模型；它回答模型是如何学习的、模型从训练数据中学到了什么、模型是如何进行决策的等问题。典型的全局可解释性方法包括特征分析、规则提取、概念分析等。

此外，全局可解释性方法的分类也可以分为两类，

+   模型相关（Model-specific）：需要知道模型的类型和具体参数，可扩展性较低，一般不同类型的模型会对应不同的解释方法；

+   模型无关（Model-agnostic）：不需要知道模型的类型和参数，将模型近似于黑盒进行研究，可以适用于不同结构的模型（CNN、SVM等）。

### 基于特征分析的解释方法

特征分析技术（Feature Analysis）可以应用于任何神经网络，用于实现比较、分析和可视化神经网络的神经元和网络层的表达。通过特征分析，可以识别对模型决策影响大的敏感特征以及模型对这些特征的处理方式。例如，通过特征分析，我可以去知道某个神经元或者是某一个网络层是负责做什么的，例如负责分类、识别边缘或者识别图像质地、纹理，比如更高级的，在人脸识别中识别五官轮廓。

[网络剖析 ](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1711.05611)（Network Dissection）的核心思想是：神经网络的单元（如卷积通道）学习到的是解耦的特征，可以将 CNN 通道的高度激活区域与人类概念（对象、 部件、纹理、颜色等）相联系，并量化分析模型不同隐藏单元的语义特征。

我们可以总结一下基于特征分析的两种方法：

+   方法优点：

+   通过特征可视化，可以了解到神经网络首先学习简单的边缘和纹理检测器，之后的更高层中学习抽象部分和对象检测器；

+   网络剖析扩展了这些结论并使网络单元的可解释性变得可测量；

+   方法缺点

+   许多特征可视化图像包含一些没有文字或心理概念的抽象特征，但这不意味着对图像的解释；

+   网络剖析需要使用概念在像素级别标记的数据集，这些数据集需要花费大量精力来收集。

### 基于概念分析的解释方法

这个方法的名字叫 [TCAV ](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1711.11279)。其中， [概念激活向量 ](https://link.zhihu.com/?target=https%3A//arxiv.org/abs/1711.11279)（Concept Activation Vectors，CAVs）[：将一个概](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Directional_derivative)念定义为一个向量，而 TCAV（Testing with CAV）用 方向导数 （directional derivatives）来量化模型预测对 CAV 学习到的底层高级概念的敏感度，从而解释模型对特定概念的学习程度。

TCAV的优点有：

+   Accessibility：不需要用户有深度学习的经验；

+   Customization：适应任何概念（比如性别），而且不受限于训练过程中所考虑的概念；

+   Plug-in readiness：不需要重新训练或修改模型就可以直接工作；

+   Global quantification：可以用单个量化度量解释类别或一组示例，而不只是解释单个数据输入。

其步骤是：

1.  定义一个感兴趣的概念；例如，可以选择一组表示一个概念的样本集，找到一个单独的有概念标签的数据集；

1.  计算目标的 CAV

1.  根据第 1 步给出的概念，在模型第  l 层的激活空间中寻找一个表示该概念的向量；之后定义一个概念激活向量（CAV）作为超平面的法线，将模型激活过程中没有概念的例子和有概念的例子分开；

1.  例如，收集一组针对类别  C 的正例  P_C （如条纹对象的图像）和一组任意的负例  N （如一组随机图像），然后训练一个二元线性分类器来区分两个集合数据在目标模型第  l 层激活，这个分类器  v^l_C 即为一个针对概念  C 的线性 CAV；

1.  计算方向导数和概念敏感度

1.  类别  k 对概念  C 的“概念敏感性”可用方向导数计算，表示为：

![](img/fd9b021761760eeb90c4dcf0d8aa618b.png)

### 基于规则提取的解释方法

我们知道，可以很容易地构造出 [决策树 ](https://link.zhihu.com/?target=https%3A//en.wikipedia.org/wiki/Decision_tree)（Decision Tree）的逻辑规则解释。比如

![](img/a0b0ba42180208b2a26f264ffd122f1e.png)

周志华, (2016). 机器学习，北京: 清华大学出版社. 4.2

就可以写作这样的逻辑：

```
if (纹理==清晰) and (触感 == 硬滑) then 好瓜;
if (纹理==清晰) and (触感 == 软粘) then 坏瓜;
if (纹理==清晰) and (根蒂 == 蜷缩) then 好瓜;
if (纹理==清晰) and (根蒂 == 稍蜷) and (色泽 == 青绿) then 好瓜;
...
if (纹理==模糊) then 坏瓜;
```

可以抽取出逻辑规则

对于一个神经网络，我们可以构建出等效的决策树，实现对原模型的逻辑规则解释。步骤是先计算黑盒模型的稀疏局部对比，构造输入样本、正常扰动样本和对抗样本的三元组关系，然后创建自定义的布尔特征集，利用布尔特征构造原模型的决策树等效模型。

![](img/8bd378da8e80bf7f35e1815e794e113c.png)

Pedapati, T., Balakrishnan, A., Shanmugam, K., & Dhurandhar, A. (2020). Learning Global Transparent Models consistent with Local Contrastive Explanations. arXiv: Learning. abs/2002.08247

具体方法不再讲述。由于图像的类别和特征繁多，基于逻辑规则的解释难以用于解释图像分类模型。

## 可解释性方法缺陷

简而言之，可解释性方法的缺陷有两条；我们这里不会详细阐述，详见原论文。

### 解释结果与模型相关性低

在样本不改变而对模型部分参数随机化后，可以发现解释内容几乎保持不变，这表明解释内容与样本相关性高，而与模型的相关性低，这就变成了对输入数据进行解释，而非对模型进行解释。如下图，每一行代表一种解释方法，第一列代表对原始模型的解释，后面的每一列代表参数随机化的网络层，越靠右代表越底层。可以发现多数解释方法的结果没有太多变化，说明与模型相关性程度较低。

![](img/d80ddf227666f092a6556fdb1dba8984.png)

Adebayo, J., Gilmer, J., Muelly, M., Goodfellow, I.J., Hardt, M., & Kim, B. (2018). Sanity Checks for Saliency Maps. Neural Information Processing Systems. abs/1810.03292

### 解释方法本身存在脆弱性

研究发现，存在针对解释器的对抗样本；对抗样本在攻击原始模型的同时，可以保证深度可解释系统对模型决策的解释不变，这表明解释器无法真正解释模型的决策。

![](img/507a032f6eb9a869a1e56c3b0fc1123a.png)

Zhang, X., Wang, N., Ji, S., Shen, H., & Wang, T. (2018). Interpretable Deep Learning under Fire. ArXiv, abs/1812.00891.
