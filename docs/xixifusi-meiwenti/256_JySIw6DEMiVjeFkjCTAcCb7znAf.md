**成功的创业企业生命周期(the successful** venture life cycle)

+   成功的创业企业通常会经历发展成熟的过程，这个过程称为生命周期 (life cycle)。

+   产生阶段 (development stage)

+   该阶段经历将创意变成可行的商业机会。

+   初步的测试；

+   研发，生产出产品的原型，产品测试。

+   制定商业计划。

+   没有收入；

+   负利润：

+   负的现金流量。

+   起步阶段(startup stage)

+   企业开始获得生产经营所需的场所、设备和员工， 建立企业的组织结构。

+   开始有少量的销售，产生销售收入；

+   收入小于费用，仍然亏损。

+   现金流量仍然为负。

+   生存阶段 (survival stage)

+   收入开始增长，但仍然亏损，现金流量为负。现金流量可能超过净利润。

+   迅速增长阶段 (rapid-growth stage)

+   销售收入开始迅速增长，企业有较好的发展前景， 企业的价值迅速增长。

+   企业的净利润也迅速增长，但现金流量还是为负。

+   从生存阶段到迅速增长阶段没有明显的界线。

+   成熟阶段(maturity stage)

+   在这个阶段，企业的增长速度下降，企业开始产生正的现金流量。

+   这个阶段是投资收获的最佳时机。

+   前两个阶段或三个阶段可以称为早期阶段，后两个阶段称为增长或发展阶段。

什么是财务（从企业实务的角度）？

+   财务与会计

+   什么是会计？

+   会计是**度量、记录和总结企业经济活动**，以提供企业财务状况和经营业绩的信息系统。

+   财务与会计的关系

+   财务和会计是密切相关的两个概念，它们在商业运营中都扮演着至关重要的角色。

+   财务是一个更广泛的概念，包括财务规划、投资决策、融资、风险管理和其他与资金相关的问题。财务管理者通常需要制定公司的财务策略，并确保公司的财务状况良好。

+   会计是一个更具体的领域，涉及**记录和分析财务交易的过程**。会计师负责记录公司的财务交易，编制财务报表和其他财务文档，并提供有关公司财务状况的分析和建议。会计师还需要确保公司遵守财务报告和税务要求。

+   因**此，财务和会计是相**互依存的概念。会计提供了财务信息，以便财务管理者做出明智的决策，而财务管理者则需要了解会计信息以制定正确的财务策略。

会计的重要性

+   创业企业的创业者往往认为他们亲自参与企业的日常运营管理,财务信息对他们来说并不太必要,这是完全错误的.不健全的会计制度是小企业经营失败的重要因素.

+   会计制度的基本要求

+   不管其复杂程度如何,对于创业企业,会计制度应该达到下列目的：

+   准确、及时地体现企业经营效果和财务状况；

+   能随时将即时的数据资料同上年度的经营效果和预算目标进行比较；

+   为创业者、投资者,银行和可能的债权人提供财务报告：

+   便于迅速地向政府政策制定机构和税务机构提交各种报表和纳税申报报表；

+   能反映员工欺诈、偷盗、浪费以及记录保存错误等情况。

### 会计基础

![](img/940c7ce3eb83b019fcf99794888a67da.png)

+   权责发生制：凡在本期发生**应从本期收入中获得补偿的费用**，不论是否在本期已实际支付或未付的货币资**金，均应作为本期的**费用处理；凡在本期发生应归属于本期的收入，不论是否在本期已实际收到或未收到的货币资金，均应作为本期的收入处理。

权责发生制是一种会计原则，它要求企业在确认收入和费用时，必须考虑实际发生的经济事项，而不是仅仅根据支付或收到款项的时间点。简单来说，权责发生制要求企业在经济上发生时确认收入和费用，而不是在现金流动时确认。

这意味着，如果企业向客户提供商品或服务，即使客户还没有支付款项，企业也必须在销售发生时确认收入。同样的，如果企业接受了供应商的服务或商品，即使还没有支付款项，企业也必须在收到服务或商品时确认费用。

+   现金收付制：就是当期获得的收入、支付的支出

### 会计要素

会计要素

会计要素也称会计报表要素，是对会计对象的基本分类和核算对象的具体化。

+   资产：是由企业过去的交易或事项形**成的、由企业**拥有或控制的、并且能够给企业带来经济效益的经济资源。

+   流动资产：现金、银行存款、材料、应收帐款等。

+   非流动资产：长期投资、固定资产、无形资产等。

+   **负债：是指由企业过去**的交易或事项形成的、预期会导致经济利益流出企业的现时义务。也称债权人权益。

+   流动负债：如短期借款、应付帐款等；

+   长期负债：长期借款、长期债券等。

+   所有者权益：指企业投资者对企业净资产的所有权，即企业资产扣除负债后，由所有者享有的剩余权益。

+   所有者直接投入企业的资产；

+   利润留存。

+   **收入：是指企业日常**活动中**形成的、会导致所有**者权益增加的、与所有者投入资本无关的经济利益的总流入。

+   狭义的收入与广义的收入

+   狭义的收入：日常活动产生的收入：营业收入

+   广义的收入：还包括非日常活动产生的非经常性经济利益流入，营业外收入，也称为利得。

+   费用：是指**企业在日常活动中发生的、会导致所有者权益减少的**、与向所有者分配利润无关的经济利益总流出。

+   一般指企业在生产经营过程中所发生的各种耗费。

+   狭义的费用和广义的费用

+   利润：企业在一定期间内生产经营活动的最终财务成果。 利润=收入—费用

+   资产：在某一个节点，企业拥有的**资源**（随着时间变化的）

资产可以通过现金存在（银行存款），在一年中也会变化

+   负债、所有者权益：反映资金**来源**

经营活动变化反映在这三个要素，是在某一个时间点的

企业的收入反映在这三个要素，是某一个时期的

## 财务报表

三张报表：**资产负债表、利润表、现金流量表**

+   资产负债表：
资产负**债表是反映企**业某一特定日期财务状况**的报表。
**根据我国现行会计制度的规定，企业每个月末都应编制资产负债表。
资产负债表的编制基础是会计恒等式：
资产=负债+所有者权益（股东权益）

+   利润表
它是**反映企业****一定期间生产经营成**果的会计报表。
通常，企业应每月编报一次。
利润表的编制基础是：
收入--费用=利润
编制格式：
单步式损益表
多步式损益表

+   **现金流量表
现金流量表**是用来反映在一定会计期间现金收入和现金支出情况的会计报表。
通常，每年编制一次。
现金流量分为三个方面：
经营活动产生的现金流量；
投资活动产生的现金流量；
筹资活动产生的现金流量。

## 财务分析概述

![](img/66d1a53e79ca222ed2e2ab566daa4874.png)

+   分析步骤一：经营战略分析

经营战略分析的目的是确认企业利润动因和经营风险，对公司的潜在利润有定性的、或质的了解。

+   分析步骤二：会计分析

会计分析的目的是评价公司会计反映其实际业务的程度。

+   分析步骤三：财务分析

财务分析的目的是利用财务数据评估公司当前和过去的业绩，并了解其持续性。

+   分析步骤四：前景分析

前景分析的目的是预测公司的未来。

+   财务分析方法

在财务分析中，有很多分析工具和方法，分析人员应选择适合于分析目的的那些工具。

+   比较财务报表分析

比较财务报表分析是将连续几年的资产负债表、损益表和现金流量表，或其它报表并列放置，查看各年度或几个年度各分类项目的变动情况。也称为水平分析。

+   **比较分析**反映出来的最重要的信息是变动趋势。

+   分析还要比较相关项目的变动趋势。如销售收入和应收帐款。

+   比较分析中通常采用年度变动分析和指数趋势序列分析。

+   年度变动分析

+   适合相对短期的分析，如两年或三年。

+   既有绝对数额的变动，又变动的百分比。

![](img/af86345f7538cd0ab76ac77b09356919.png)

+   指数趋势序列分析

+   给每个项目选定一个基期，并用事先选定的一个指数来表示，通常定为100。

![](img/12669140abe026c0d43a9bfe50c8155c.png)

+   进行指数趋势分析时，不一定需要分析每一个项目；

+   慎重解释趋势的变动，有些变动可能是宏观经济和行业因素的变动。

+   注意可能的会计核算原则和方法的改变。

+   结构百分比财务报表分析

+   在财务分析中，了解一个项目在总额或分项合计中所占比例是很有意义的。

+   在分析资产负债表时，常用的方法是将资产总额、负债和所有者权益总额分别表示为100%，再把各类中的具体项目表述为占各自总额的百分比。

+   企业资产的构成。

+   在分析损益表时，一般将销售收入设定为100%，其他项目表示为销售收入的百分比。

+   结构百分比分析经常要延伸到特定子类的比例构成；

+   结构百分比分析适合于企业间的比较。

# Lecture4 现金流量管理

## 营运资本管理概述

一、营运资本概念

营运资本=流动资产--流动负债

+   流动资产：

+   现金；应收帐款；存货等。

+   流动负债：

+   短期借款，应付帐款；其它应计项目等。

+   经营性流动负债：与企业经营的相关方有关的流动负债。

+   融资性流动负债

二、流动资金周转和营业周期

+   流动资金周转是指企业的资源在企业的营运项目间的日常流动。流动资金周转步骤如下：

+   第一步：采购或生产用于销售的存货，假设采购是信用采购，这一步骤使应付账款增加，也增加了现有的存货。

+   第二步：销售出存货，则存货减少，应收账款增加。

+   第三步：支付应付账款，减少了应付账款，现金减少；支付经营费用和税金，现金减少。

+   第四步：收回应付账款，现金增加。

+   第五步：开始下一期周转。

![](img/ed3e96432e0d78cc2564eeba0a4ccedd.png)

+   营运资本投资的规模和时机

+   营业周期和现金周转期的不同，代表了对营运资本需求、相应地营运资本投资的差异。

+   现金周转期越长，营运资本需求量越大；

+   比较两个公司慢周转公司和快周转公司

![](img/df57d61e6ce28b3de699e13c7a106132.png)

![](img/b59260a8b6e56637e3919d3a372c7d20.png)

缩短现金周转期能提高企业的效益

+   例：

+   年销售收入：   5000万元

+   毛利率：             30%

+   应收账款周转期：35天；

+   存货周转期：         40.5天

+   应付账款周转期：40天。

+   贷款利率：10%

+   现金周转期=40。5+35-40=35。5天

+   计算现金周转期缩短节约的成本

+   日销售收入=5000万/365=136986元

+   日销售成本=136986X（1-30%）=95890元

+   需要投入的资金=35。5X95890=3404109元

+   利息费用=3404109X10%=340410.9元

+   缩短现金周转期一天节省的利息成本：340410.9/35.5=9589元。

+   财务预测是企业估值的基础；

+   财务预测能帮助创业者比较各项战略方案并选择其中预期价值最大的一个；

+   财务预测是一种规范的方式，可以估计企业能产生多少资金，需要多少资金。

+   若需要外部资本，财务预测能够帮助潜在投资者了解企业的未来前景。

+   财务预测可用用一个评价实际表现的基准。

## 财务预测的基本框架

销售预测

+   几乎所有的财务预测和计划都是从**销售预测**开始.

+   企业的经营模式可以分为:

+   销售驱动

+   资产驱动

+   预测期间的长短

+   中长期财务计划:3—5年

+   估值预测:企业达到稳定增长为止.

预计财务报表

+   财务计划和预测需要有一套预计财务报表：

+   预测的资产负债表

+   预测的利润表

+   预测的现金流量表

+   资产需求

+   根据预计资产负债表，可以确定为了支持销售的实现，需要的资产需求，也就是投资的需求；

+   筹资需求

+   为了满足投资的需求，企业需要筹集相应的资金。

+   资本结构政策；

+   利润分配政策

+   调节变量

预测的基本参数假设

+   所有的预测都是在对未来的一系列假设基础上进行的。

+   假设是基于历史的分析、企业未来的战略以及市场竞争情况的分析作出的。

+   销售收入及销售增长率的假设

+   固定增长率与变动增长率

+   利润表预测的假设

+   **有关费用和资产的**预测通**常都是假定，**他们与销售成比例，称为销售百分比法

+   销售成本、毛利、管理费用和销售费用通常与销售成比例。

+   注意：不是所有的利润表项目都与销售收入成正比。

毛利率的假设

+   是否变动?

+   变动原因:

+   价格变动?

+   成本变动?

+   销售费用率假设

+   企业是否调整营销策略?

+   销售费用率是否变动?

+   管理费用率假设

资产负债表预测的假设

+   大部分资产项目假设是**与销售成正比**的。

+   现金周转率

+   应收账款周转率

+   存货周转率

+   应付账款周转率

+   固定资产周转率

+   正常情况下资产周转率保持稳定是合理的;

+   历史周转率是否稳定?

+   如果不稳定,如何估计未来的周转率?

+   是否应考虑长期资产的不均衡增长?

+   调整会计报表

+   区分经营资产与非经营资产；

+   区分经营净利润与净利润

+   区分经营债务与投入资本；

## 财务预测模型(案例二)

案例:  NEWCOM公司是一定新成立的公司，公司开发和生产医疗仪器。根据公司的产品开发和生产销售规划，得出如下基本的预测假设。

1，产品开发期预计为18个月，第19个月开始生产销售产品。

2，第19个月的销售估计为10000元，三年内实际销售额按每月8%的增长率增长，以后按通货膨胀率增长。

3，通货膨胀率估计每年9%（每月0。75%）。

4，开发期间每月运营费用为15000元，考虑通货膨胀。

5，在第18个月开末，企业租赁一条价值20万元的生产线，足够满足前五年生产所需，每月租金为3000元。

6，销售毛利率为60%（不包括租金）。

7，销售费用为销售额的15%。从第19个月起，每月的管理费用为10000元，且以通货膨胀率上涨，加销售额的15%。

8，企业所得税率为25%，损失不能递延。

9，所有销售都是信用销售，平均收账期为45天。

10，存货每年周转五次，用期初存货衡量。

11，最低现金余额为30天销售额或10000元较大者。

12，应付账款每年周转八次，用期初应账款衡量。

13，创业者初始投资为40万元，假设以后融采用借款，借款利率为每月1%。
