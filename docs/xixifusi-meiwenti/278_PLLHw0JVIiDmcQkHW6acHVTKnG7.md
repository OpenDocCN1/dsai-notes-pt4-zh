# 写作&文献

https://www.cc98.org/topic/5424093

1.创新！创新！创新！

重要的事情说三遍！

论文选题重中之重就是一定要创新，才能体现研究的价值和意义。

2.实验涉及的数据提供详尽出处

试剂、设备、型号、货物号、产家地址等，越权威的数据来源越好，一般期刊投稿时就会让你备注论文的数据支持、理论支持来源，写论文时尽量搜集可靠性高的数据和理论，才能体现论文的靠谱性。

3.突出观点

一篇论文的研究结论是写作的最终目的，写作过程要清晰且有理有据地表达你的据点，做到言出必有据。研究结果也不能模棱两可，一定要写出明确的结论。

4.视觉整体美观

视觉效果美观的论文，能让审稿人眼前一亮，要做到这一点，图表必须符合相应的SCI杂志格式，论文结构要层次分明，尽量避免大段的文字赘述，否则容易造成审稿人认为你的论文枯燥无意义。

5.第一次提到的简写用全称

虽是一个微不足道的小细节，却还是有很多作者在写论文时会粗心忽略，各位科研人务必注意哦，不要让审稿人看文章时云里雾里，退回修改又是一大时间成本了！

6.注意英文表达方式

SCI论文的特点是全英文的创作模式，其中一定不能出现中文的表达，遣词造句时要注意英文语法是否标准，还要用尽可能少的语言去表达最大范围的信息。

7.提前按照期刊格式写作

进入期刊首页，点击submit paper后，选择Introduction for authors，里面有详细的关于文章结构和格式方面的规定，必须要严格按照要求来，可以减少不少修改步骤。

如果没有规定结构和格式，就根据最近该期刊上已经发表的文章结构和格式来调整，或按照英文论文常用的规范去写，比如字号11 或12，字体Times New Roman，左对齐，双倍行距等。
