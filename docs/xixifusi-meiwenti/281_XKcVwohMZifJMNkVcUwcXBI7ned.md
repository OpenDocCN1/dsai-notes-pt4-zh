## 创业者本质的品质

+ Permissionless 无需获得许可地  
+ Unapologetically 无需道歉地  
+ Fearless 一往无前地  
+ Unstoppable 慢但不停地  

人们总是想弄清楚是什么秘诀成就了那些最耀眼的创业者，比如 Steve Jobs, Elon Musk 和 Sam Altman，虽然每个人的成功都不可复制，并且往往不是我们听说的原因，但是我想他们都有一些共通的特质：

无需获得他人许可地开始 Permissionless  

无需道歉地做自己 Unapologetically  

一往无前地创造 Fearless  

可以慢下来但绝不停步 Unstoppable （这是我跑马拉松的时候默念的一句话）

## 如何回答Why Build This？

+ 思考你的mission  
+ 第一性原理，从底层、从目的出发定义清楚问题的边界和条件；系统化拆解复杂问题；用最有效最可行的方式达成目标
