
# 什么样的人适合成为创始人

> 来源：[https://docs.feishu.cn/docx/AYgYdHBidoxLbmxsqnTcntIqnWh](https://docs.feishu.cn/docx/AYgYdHBidoxLbmxsqnTcntIqnWh)

## 特质

+ 创始人最好 PM、GTM 和战略于一身，这样流量和增长是自然而然的事情。
+ 基础，钻研，专注
+ 多做少想
+ 不能满嘴跑火车
+ 做个极致的人
+ 技术创业
+ 科研
+ B站创客
+ Hunger but bumble
+ 葆有自己的观点
+ 魅力让别人跟着你一起干

## 一个小而美的公司如果要活成伟大的过程，创始人占八成，且一定要具备以下这些

> [来源](https://m.okjike.com/originalPosts/65b674b46d9f190631c7fd19?s=ewoidSI6ICI2MjVmZDM3N2Y3NTQ1MzAwMTBjNzYyNzAiCn0=)

+ 创始人个人魅力需要极强，超过90%人类的那种强。感染力max，强输出价值观。
+ 初创团队所有人都需要坚定不移相信他的价值观，无条件买单。不买单的立刻离开。
+ 整个团队几乎全靠信念在运转，不是钱。
+ 让从上到下每个员工都坚定的相信公司会变得很有前途。
+ 养的都是全能的狼，无差别屠杀温吞的羊。
+ 杀伐果断，开人就是一句话的事。
+ 可能会经常改变想法，但是他想的一定是对的，所谓的初心不变，就是他永远正确这点绝不会变。
+ 伟大的创业者最后会丧失人性。
+ 最后的心得是，成功的品牌和创业公司最后会做的像个宗教。
