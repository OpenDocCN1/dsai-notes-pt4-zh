# 在创业前，试着回答你做的创业产品背后的philosophy是什么？你这个个体的philosophy是什么？

> 来源：[https://docs.feishu.cn/docx/JaOvdybsjo78BAxX4kLcC5aVnyf](https://docs.feishu.cn/docx/JaOvdybsjo78BAxX4kLcC5aVnyf)

有一位我很好的前辈和我说，你们创业班（ITP）身上有一种风气，我很不喜欢，就是为了创业而创业。

所以，在开启你的事业前，不妨先探索自我。

“探索自我的过程是一个孤独、独特、有趣、和灵感迸发的过程。”

找到自己的philosophy以及你创业产品背后的philosophy是什么？

“拥有一套自己的philosophy后，会支撑起一个强大的灵魂。

**自己的philosophy = 自我价值体系的优先级（什么重要，什么次重要）+自己的底线（自己**不能接受什么）+自我偏好（自己喜欢做什么，不喜欢做什么）+ 圈子（爱和谁玩儿）”

找到真正你想做的事业

这可能也是所谓的Founder Mission Fit和People Mission Fit

“**如**果我们已经有了一套自己的philosophy，且了解清楚围绕着自己的philosophy的技能包有哪些，接下来就是时间的积累了。”

我也曾经有过我自己的项目，他很有意思，但是我知道他不会是我一辈子会去做的事情。我们在尝试融资的时候，每一个时刻我自己都感觉就是拧巴，我没有办法说服我自己，最后我们也放弃了融资的offer，在寻找我们真正想做的事情的路上。
