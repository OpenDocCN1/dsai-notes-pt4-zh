
# 不要创立“邪恶”的公司

> 来源：[`https://docs.feishu.cn/docx/LqQ0dgUNNomXLux5pLVc0XXEnof`](https://docs.feishu.cn/docx/LqQ0dgUNNomXLux5pLVc0XXEnof)

我第一次听“邪恶”这个形容词用在公司上，是陈伟星在怒斥抖音。

陈伟星是我的浙大学长，创业者，同时也是字节跳动的投资人之一，他从字节跳动赚到了非常多的钱，但是这和他怒斥抖音不矛盾。

在即刻上，有一个号，叫做“今天字节跳动倒闭了没”，从2020年9月10号开始，每天会发一篇帖子，记录字节跳动今天有没有倒闭，直到今天，一直发的都是“没有”。

我不对“抖音”和“字节跳动”发表观点，我自己也用抖音，我也是其他很多字节产品的用户。我核心是想表述我们今天在培养创业者，或者在聊创业的时候，会聊“怎么赚钱”，“怎么满足用户需求”，但是很少会谈，这个事情究竟对社会有没有产生正向影响。

现在很多创业者的价值观是**“有毒”**的，他们不在乎自己在做什么，只在乎赚取功名利禄。

**我不喜欢一家公司只把人当数字，关注具体的人，**他们不只是被那些被那些傲慢标签定义的人。

当一个创业者人品、价值观都更正的时候，大家才都会愿意帮你，你的伙伴才会愿意追随你；而如果你只是在玩击鼓传花的游戏，或者坑门拐骗，很多东西很容易瞬间崩塌。

Don't be evil
