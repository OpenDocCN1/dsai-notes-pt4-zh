# 最大化用户在平台上的无悔时间

在完成收购推特一周年的全体员工会议上，马斯克再次强调了公司的北极星指标：最大化用户在平台上的无悔时间。

他曾经告诉媒体，听说有些用户在刷了 TikTok 几个小时后有罪恶感，悔恨自己浪费了这几个小时。

马斯克在制定公司使命和目标时，确实很厉害。我好奇的是，被收购前推特的关键考核指标是可货币化的日活用户数。今天 X.com 用户规模巨大，业务也越来越复杂（毕竟要做 everything app），在实际工作中如何具体衡量这个指标，如何区分上瘾和无悔。

# 产品的感性和理性

王小川：

以前我迷恋一件事情，就是用理性和逻辑思考来解释所有的事情，还喜欢一句话叫“理性是感性的高级阶段”，但我后来发现这是错的，理性和感性是两个维度的事情。

理性是在看待世界的认知，强调了推理的方法。它与哲学、科学确实是高度相关的。但是认知其实就是对客观世界的一种描述，如果人只有理性的话，就只是一个工具。回到我自己，我是有感性的，但我以前比较压制自己的感性，不要轻易太感动，除非这个感动是被人理解的。我现在是开始了“感性解放运动”，尤其是在2010年和2013年，我发现理性接近崩溃的时候，反而是“感性”让我实现破局。

搜狗以前做产品，叫做工具型的产品，满足人们的某种痛点，也就是省力，提升效率，这离理性比较近。输入法就是让用户在打字的时候更省力，能用简拼就不用全拼。浏览器也是，追求速度快，也是更加理性的部分。但是我们发现，这样的产品可能是缺少“性感”的，输入法之前做过一个事情是做皮肤，这是表达一种情绪，情感的东西。如果产品被用户当做工具在用，就很难感动用户。

# 顶级的产品设计者如何思考？

> [来源](https://m.okjike.com/originalPosts/65d6ac926d9f1906312b17c3?s=ewoidSI6ICI2MjVmZDM3N2Y3NTQ1MzAwMTBjNzYyNzAiCn0=)

Garry Tan评价 YC 孵化器的创始人 Paul Graham：

「他可以很容易地模拟那些没有背景的人的体验， 并就设计中哪些部分会导致问题给出非常精确的反馈。

当你能直观地感受到用户的需求、痛苦和困惑时， 你就能与用户产生最有意义的共鸣。」

无论你是设计新人，还是资深产品经理、独立开发者，推荐一看这段机场设计模拟的思想实验，一定能让你如沐春风、重新审视需求和设计的意义。

不要忘记，**换位思考是一种超能力**。
