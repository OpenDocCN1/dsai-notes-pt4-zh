# Mkt

Marketing 的表象和联想：推广、市场运营、冷启动、增长...

但都不是根本。目的终究是：**吸引用户**，结果终究是：**增加转化**。

我的理解，Marketing 的本质是「内容分发」。这其中有几个因素：渠道、内容形式、内容、分发人、被分发人。

1）渠道：选择某个渠道的原因是什么？比如选择 PH 的原因？是否有路径依赖，是否是全栈式运营？

**2**）内容形式：是对渠道的本质拆解。多模态运营（文本 - 链接、博客、帖子、长文...、图文 - 海报...、声音、图片 - CTA、视频...）

3）内容创作：经验+参考竞对。在所有渠道反向搜索自己的产品寻找反馈

4）分发人和被分发人是可以相互转化的。多互动（转发、回复、评论、点赞）可以增强内容在渠道的热度
