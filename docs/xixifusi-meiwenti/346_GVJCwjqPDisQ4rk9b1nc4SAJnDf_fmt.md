
# 如何带团队

> 来源：[https://docs.feishu.cn/docx/LSledwJVQovxrQxOIsnczMXLnIg](https://docs.feishu.cn/docx/LSledwJVQovxrQxOIsnczMXLnIg)
> https://m.okjike.com/originalPosts/64c7cd83a0ec82864df49b45

今天和爸爸交流了一下我的工作，爸爸给了我好多启示。

我爸爸正式教育程度不高，只有小学，但他在 当家 这件事上非常擅长。老家有人摆酒席，通常都有人雇他做内当家，要管后厨、客人饮食、住宿、仪式进程和工资结算；管百来人的工人团队超过15年。

在带团队上，他给了我几点建议：

1. 在不愿意放权的老板手底下干活，以糊弄为主，老板说什么，你口头应付就好了，不用那么努力，因为没用，准时打卡上下班就行了。
2. 没有权力的时候，不从老板那里争权。
3. 老板如果真想培养一个得力骨干，会在部门面前帮助ta立威，常见方式是：扣某一个工作不努力员工的工资，并且当着三方的面告诉被扣钱的员工：骨干反馈你这月工作出了哪些问题，这个月扣了你工资，下个月好好干。让大家知道，老板要培养的这个骨干在经济命脉上有话语权。不然说话没人听。
4. 老板放权也有顾虑：怕你把部门整得没人了。所以一个唱红脸一个唱黑脸，怎么唱也有技巧。
5. 面对事多、架子大、说话很冲的老员工，你不要硬碰硬，不划算，去跟老板反馈情况，让老板去给这个员工施压，如果老板不做，工作态度遵循第一条。
6. 如果你的团队同事开始带人，当你发现他工作能力很强时，马上给他培养副手，让他知道你随时有能力换掉他。
7. 不要在没有任何回报的情况下充当老板的打手，不值得，容易把自己做成光杆司令，还会把关系处得很烂。
