
# 如何像美团一样，在团队内快速复制成功经验？

> 来源：[https://docs.feishu.cn/docx/LMwAdtPUlowhPPxvJ6VcOKVwnOh](https://docs.feishu.cn/docx/LMwAdtPUlowhPPxvJ6VcOKVwnOh)

1. 美团的快速复制能力的来源是通过“目标”赋予发现动作和执行动作的人复制有效动作的强大动力。
2. 主管看销冠的动作、从销冠身上复制。
3. 迭代到所有人的KPI里。当这个方法论变成了不得不做到的要求时，自然，所有人渐渐都会做到。
4. 动力 = 赚钱
5. 为了保证被推广的动作团队确实照着做，每个动作都会被找到度量其是否发生的过程指标，直接进入到KPI里，影响员工的绩效。

   + 一方面，谁来发现优秀动作、并推广呢？

     有专门为人效负责的人，激励直接与人效挂钩，提高人效必须快速复制。

   + 另一方面，怎样保证被推广的动作，团队确实照着做呢？

     每个动作，都会被找到度量其是否发生的过程指标，直接进入到KPI里，影响员工的绩效。

6. 建立正确的目标和针对目标的反馈机制也是高效经营的重要原则。
7. 美团的方法论大多源于王兴和王慧文的提问，他们不断从同一个角度发问，解答这些问题就变成了对高管的要求，为了解答他们的问题，高管不得不把同样的问题提给下属，最终为这些问题找到答案，就渐渐变成了美团的标准做法。
