+ 设定“付费方”与“被补贴方”  
+ 双边模式赋予平台企业在定价方面的弹性，企业可以选择补贴某一边群体，促进其使用者数量的增长，进而吸引另一边群体支付更多的费用。  
+ 服务于相同的市场，却选择完全不同的补贴对象  
+ 微软的视窗播放器与RealNetworks的Real播放器。微软以免费方式为一般电脑用户提供视窗播放器，并将它与其他产品打包，赠送给內容提供商。而RealNeworks虽然也为一股电脑用户免费提供Real播放器，但它却向内容提供商收取了费用。在面对微软道成的威胁之后，RealNetworks立刻改变策略，转而向用户收取固定月费;也就是说用户群体在该平台生态圈的角色已从“被补贴方”调整为“付费方"。  
+ 双方都不想付费怎么办？  
+ “世纪佳缘”连接了“男会员”与“女会员”这两边群体。世纪佳缘将“付费方”定义为“任意愿意购买增值服务的会员”。  
+ 任何人在登录此婚恋平台后，都能上传自己的照片，且能浏览数以万计的异性照片与资料。但只有那些愿意支付额外费用的人，才能够通过各种增值服务、大幅提升与理想对象结缘的机会。  
+ 赋予用户归属感  
+ 许多平台企业在制定种种机制的初期，往往聚焦在硬性功能上，而忽略了用户心理的软性层面。若能建立一套机制体系，协助平台用户对该生态圈产生归属心理，结果将相当惊人。  
+ 苹果的例子  
+ 并非所有都必须像苹果一样制造漂亮的硬件或界面系统。有效的机制，同样能够点燃人们心中的火苗。最好办法，就是“赋予用户权限”的机制。  
+ 起点中文网  

打碎了整个原创出版业既有的产业链、不但取代了出版社的功用、更扮演起经纪人、经销商的角色。平均每天都会有超过200万名读者通过这个平台进行阅读。作者会分得一分钱每1千字的撰写所带来的两三分，其余的被平台吸收。  

读者能在第一时间通过留言板对故事章节提出意见。  

“投月票”、“投推荐票”子机制还可以让读者用实际行动支持自己喜爱的作品、在协助作者登上排行榜的同时，也影响作者从平台获得的奖金的多寡。  

“好评指数”机制让读者给予该作品1---5颗星的评价。于是，作品的主页会出现星级统计结果;若平均为5颗星，则会被贴上“经典必读”的标签。  

“催更”机制，3000,  6000, 9000,或者12000字来进行“催更”。作者则能立即收到“市场的期待值”，并相应调整自己的写作速度。  

只有一个目的：赋予读者前所未有的权限，由此萌生归属感  

+ 除此之外，起点还设置了“作者调查”、“作者悬赏”等机制，向读者征求意见，也就是作即时性的市场调研。作者甚至能够通过币值点数的反向赠送，向读者寻求某些特殊意见或需求。  

“本书荣耀”的机制，则公开表扬每部作品在哪个日期取得哪些成就，标出该作品成长历程中的重要里程碑。比如“累积获得2o万张推荐票”、“累积获得100万点击”、“登上起点首页热点封面推荐”等，全被仔细地记录了下来，在宣传的过程中，作者建立了自信，获取了动力，产生了无与伦比的归属感。  

读者群分等级的“粉丝积分”机制，“见习”、“学徒”、“弟子”，到高级的“掌门”、“宗师”、“盟主”，培养意见领袖。普通读者给予一部作品的月票上限是五张票、但成为“盟主”时有更大的权限。  

如此一来，当作者某天想跳槽时，他必须考虑放弃所有累积至今的名声和资源，这些成了无形却实际的转换成本。  

+ 如何不断把平台模式效应不断扩大  
+ 补贴“现在”，让“未来”付费  
+ 中国的“快乐女声”以及“中国达人秀”，北美的“美国偶像”等均依循既定时间轴，通过多重淘汰来增进节目效果。  

该平台连接了想要成名的人们和充满好奇心的观众这两群人，均视为“被补贴方”  

建立干“未来”之上的盈利模式：广告商仅是“付费方”之一；以时间压缩出来的激情氛围，能在以后转化为利润。  

主办单位、唱片公司等合作方为有意脱颖而出的新人进行包装，推出专辑或代言项目。此时，当初的观众粉丝之中，有一部分人将会成功转变为“付费方”，愿意掏腰包购买这些新星的唱片与代言商品。若经营得当，粉丝的比例会持续增加(即使选拔比赛已结束许久)，而其转化为“付费方”的比率也将同比成长。  

+ 无处不在：地理线  
+ 许多平台企业将生态圈的根基与真实的地理环境相联系，这么一来，平台的触角将更坚实地深入人们的生活之中。  
+ 基于实体设备的模式：拉卡拉，维络城，分众传媒  
+ 基于非设备的模式：同城，招聘、房产、征婚交友、二手买卖等信息发布  
+ 基于手机的模式：所谓“以地理位置服务为基础”(location based service ,简称LBS），是指通过特殊技术定位出移动终端的地理位置，并提供与该位置相关的信息服务。通过锁定某用户手机的所在地，告诉他附近区域有什么样的餐厅、加油站、电影院等设施，让其随时随地都知道身边环境的信息。
