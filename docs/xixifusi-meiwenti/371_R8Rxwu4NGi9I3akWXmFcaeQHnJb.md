### 金融市场的作用

#### 金融市场

金融市场是人们进行借货活动的交易场所。假设时间被划分为两个时期（并且只有两个）。考虑某个人在两种商品的组合间进行选择：今年的消费和明年的消费。

+ 贷出：用今年的消费换取明年的消费。
+ 借入：用明年的消费换取今年的消费。
+ 利率：今年的消费与明年消费交换的条件。

假设`A`现在有20000元的收入，一年后有25000 元的收人。他可供选择的消费模式如下图所示。

如果利率`r=5%`，他今年可获得的最大消费为：

20000+25000/(1+5%)=43800 明年可获得的最大消费为：

20000(1+5%)+25000=46000

25000/(1+5%)=23800为一年后25000元的现值 (present value)。

20000 (1+5%）=21000元为现在20000元的未来值，或终值 (future value)。

43800元也称为他现在的财富总量。

### 绝对估值法

+ 资产价值评估原理
+ 资产是指能产生未来现金流量的资源.
+ 资产的价值取决于未来现金流量的特征.
+ 现金流量的大小；
+ 现金流量发生的时间；
+ 现金流量的不确定性.
+ 资产的价值等于未来现金流量的现值.
+ 股息现金流量贴现
+ 股票的现金流量特点
+ 股票的每期现金股息可能不同；
+ 股票的没有到期时间；
+ 一个投资者从股票投资中获得的现金流量为持有期的现金股息，以及期末出售股票的价格。

### 相对估值法

+ 相对估值法是以市场对可比资产的定价为标准，以此评估所考虑资产的价值。
+ `价值=业绩指标X乘数`
+ 优点：简单。
+ 缺点：没有考虑价值的驱动因素；很少有完全可比的资产。

#### 权益证券的种类

##### 普通股票

普通股票通常是指那些在股息和破产清算方面不具有任何优先权的证券，它代表了对公司的剩余收益权和剩余决策权。

##### 投票权

+ 累计投票制
+ 多数投票制；

##### 分类普通股

通常不同种类的普通股在投票权方面有差异.

在中国注册的公司法律不允许发行分类普通股.

##### 股息

股东有按比例分享公司支付股息的权利．股息是公司对股东直接或间接投入资本的回报，它取决于董事会的决策。

+ 股息的发放不是公司的一项义务；
+ 公司支付的股息不能作为公司的一项经营费用.

##### 优先认购新股的权利

+ 保护现有股东不受公司发行新股的影响
+ 控制权的影响
+ 股票价值的影响。

##### 优先股票

优先股票属于公司的权益；但同普通股相比，在股息支付和公司清算清偿时具有优先权。

优先股是指依照公司法，在一般规定的普通种类股份之外，另行规定的其他种类股份，其股份持有人优先于普通股股东分配公司利润和剩余财产，但参与公司决策管理等权利受到限制。

##### 固定股息率与非固定股息率

+ 可累积与非可累积；
+ 参与与非参与；
+ 可转换与可回购．

![](img/cf3161ff22ca48939d5042188d46d2b0.png)

+ 上市公司不得发行可转换为普通股的优先股。
+ 非公开发行优先股的票面股息率不得高于最近两个会计年度的年均加权平均净资产收益率。
+ 上市公司发行优先股，可以申请一次核准，分次发行，不同次发行的优先股除票面股息率外，其他条款应当相同。

#### 分红条款

+ 参与性分红与非参与性分红；
+ 可累计分红与非累计分红。
+ 现金红利或股票红利。
+ 不承诺支付红利，只有在视为清算事件时才会支付延迟现金红利。
+ 对于创业者来说，累计并可参与性分红是非常不利.
+ 比较合理且对创业企业和创业者来说，如果公司童事会决定分红，风险投资者可以按照事先约定的股息先于普通股进行分配，如果普通股的分红高于优先股，优先股可以假设已转换成普通股与普通股一起进行分红。

#### 清算优先权条款

清算优先权授予风险投资者，在公司被出售、清算、破产、公司重要资产被出售时，有权得到原先投资额1倍到5倍不等的收益。

对清算事件的界定非常重要.

比较常见的分配方式：

+ 简单优先权：在获得投资本金和股息以及按转换为普通股后分配中选择一个。
+ 参与优先权：除了优先获得投资后，还按照可能转换的普通股按比例参与剩余财产的分配。
+ 封顶的参与优先权：返因的投资达到一定额度后就不再参与财产的分配。

#### 反摊薄股权条款

它是一种用来保护原始投资者利益的约定，即后来的投资者等额投资所拥有的权益不能超过原始风险投资者。

反摊薄条款可以归为两类：

+ 价格型反摊薄条款：即反对股权价值被摊薄的条款。
+ 棘轮条款
+ 加权平均调整条款

#### 股权回购条款

该条款规定在某些情况下，风险投资者有权要求公司或大股东回购其股份。

![](img/e4954097c0e3dd4a86f3cbc258d0cc28.png)

#### 股票转让权限制条款

几乎所有的投资协议中都包含这一条款。该条款要求股份转让之前，应事先取得其他所有股东的同意。其目的在于控制创业企业股东的身份、股权转让的时间和股权转让的方式。

#### 离职股权保护条款和竞业禁止条款

根据离职股权保护条款，创业者所特有的股票必须在一定的期限以后才能充分行权。

根据竞业禁止条款，禁止创业者在一定的时期以内服务于与创业企业相同的行业的其他企业，否则将承担严重的赔偿责任。

#### 控制管理权的条款

##### 集团投票权条款

规定对于某些特定的事项的决策，必须取得可转换优先股的持股人的同意。

如：发行新股、分红、改变董事会席位、修改期权计划等。

也有：高级管理人员的雇佣、一定数额的负债或支出、非公司日常业务范围之内的合同的签署等。

##### 绝对多数投票权条款

这是指对于创业企业所采取的某项措施需要经股东以及董事会均以绝对多数同意才能通过

如；股票回购、实质上出售公司全部资产、控制权发生改变的兼并、选举董事会、增发新股等。

其目的也在于设定事实上的否决权。

##### 股票期权计划和里程碑条款

股票期权计划与前面所述的离职股权保护条款通常结合起来使用，既可激励企业者以可保护风险投资者，以利于双方之间维护较长期的合作关系。

里程碑条款则是一种状态依存性安排，即当公司业绩达到一个里程碑时，应向企业者发行额外的股票，其目的了在于激励创业者。

##### 董事席位条款

风险投资者往往要求其有权在公司中任命一名或多名董事，董事席位的多少与公司的董事会规模以及股份比例有关。

一般较多采用两种方式：

+ 具体规定股东各方委派的董事人数。
+ 另一种常见的方式是约定保护条款，保护条款要求公司在某些事项的决策上必须取得优先股东的适当批准。

##### 优先退出权条款

##### 自动转换权条款

允许风险投资者持有可转换优先股自动转换成普通股，通常是与 IPO相联系。

##### 回赎权条款

回赎条款约定风险投资煮可以要求创业企业在将来的某一时间按约定的价格回购风险投资者的投资。

##### 共售权及连带权条款

风险投资者退出的另一种方式是向第三方出售创业企业，共售权及连带权条款可以在这一过程中保护风险投资者的利益。

当创业者向第三方出售其所持有的普通股时，共售权条款使得风险投资者有权要求将自己所持有投资与创业者一起出售。

连带权条款则使得风险投资者在向第三方出售其投资时，有权要求创业者了一同出售他们所持有的普通股。当然这一条款经常会遭到创业者的强烈反对。

### 首次公开发行IPO

+ IPO
+ 股票发行的核准制与注册制
+ 注册制是指证券发行申请人依法将与证券发行有关的一切信息和资料公开，制成法律文件,送交主管机构审查，主管机构只负责审查发行申请人提供的信息和资料是否履行了信息披露义务的一种制度。



# 4 股权融资

+ 其最重要的特征是：在注册制下证券发行审核机构只对注册文件进行形式审查，不进行实质判断。如果公开方式适当，证券管理机构不得以发行证券价格或其他条件非公平，或发行者提出的公司前景不尽合理等理由而拒绝注册。

+ 注册制的核心是只要证券发行人提供的材料不存在虚假、误导或者遗漏，即使该证券没有任何投资价值，证券主管机关也无权干涉，因为自愿上当被认为是投资者不可剥夺的权利。

+ 核准制即所谓的实质管理原则。依照证券发行核准制的要求，证券的发行不仅要以真实状况的充分公开为条件，而且必须符合证券管理机构制定的若干适于发行的实质条件。符合条件的发行公司，经证券管理机关批准后方可取得发行资格，在证券市场上发行证券。

+ 这一制度的目的在于禁止质量差的证券公开发行。

### 商业抵押贷款

目前，银行对外办理的许多个人贷款，只要抵押手续符合要求银行就会不问贷款用途．需要创业的人，可以灵活地将个人消费贷款用于创业。

抵押贷款金额一般不超过抵押物评估价的70%，贷款最高限额为30万元。

### 保证贷款

如果你没有存单、国债，也没有保单，但你的家人有一份稳定的收人，那么这也能成为绝好的信贷资源。

当前银行对高收人阶层情有独钟，律师、医生、公务员、事业单位员工以及金融行业人员均被列为信用贷款的优待对象 ，这些行业的从业人员只需找一到两个同事担保，就可以在工行、建行等金融机构获得10万元左右的保证贷款.

而且，这种贷款不用办理任何抵押、评估手续。如果你有这样的亲属，可以以他的名义办理贷款，在准备好各种材料的情况下，当天即能获得创业资金。

### 五、风险投资者一般会主动参与他们所投资公司的经管与管理。这种主动参与对风险投资者有好处吗？对创业者又如何？（12 分）

风险投资者通常会主动参与他们所投资公司的经营与管理。这种主动参与对风险投资者和创业者都有利有弊，具体情况取决于参与的方式和程度。

对于风险投资者来说，主动参与可以帮助他们更好地了解公司的运营和管理，并在必要时提供帮助和指导。这可以提高投资收益并降低风险，因为风险投资者可以更好地了解公司的情况并及时调整投资策略。此外，参与经营和管理，良好的投后服务还可以提高风险投资者的声誉和知名度，使他们更容易获得更多的投资机会。

对于创业者来说，风险投资者的主动参与可能会带来好处和挑战。一方面，风险投资者可以为创业者提供有用的经验和指导，并帮助他们更好地管理和扩展他们的业务。此外，风险投资者还可以为创业者提供必要的资本和无形的资源，以支持他们的业务发展。另一方面，风险投资者的参与可能会对创业者的自主权和决策权造成影响，甚至可能引发利益冲突和合作问题。存在一定的风险。

### 七、为什么可转换优先股在风险投资中运用如此普遍？（10分）

对于风险投资者来说，相比于普通股和不可转换的优先股，可转换的优先股无疑是一种放大收益，并且风险更低。

1. 投资收益：可转换优先股具有灵活性，可以在未来的某个时间点转换成普通股，这使得投资者可以在公司的估值增长之后获得更高的回报。如果公司估值没有增长，投资者可以选择保持优先股，享受固定的收益。普通股收益不确定，优先股仅凭获得固定股息，收益低，而可转换优先股在风险企业经营良好时可享受增值收益。

2. 降低风险：可转换优先股通常具有优先权，这意味着在公司破产或被收购时，优先股持有人会先于普通股股东获得分配收益的权利。对于投资者来说，可转换优先股通常比普通股具有更低的风险。这是因为如果公司失败或者估值没有增长，投资者可以保持优先股，从而避免损失。

3. 代理成本：可转化优先股不会获得企业控制权，对管理者来说有一定的激励，并且有表决权，使得其代理成本相对较低。

4. 吸引投资者：由于可转换优先股具有上述优点，因此可以吸引更多的投资者来投资公司。这使得公司可以获得更多的资金，并且能够更容易地融资。

### 八、一个风险投资公司正在为新的 2.5 亿元的基金考虑两种不同的结构。两种结构下的管理费（以承诺资本为基础）均为每年 2%（基金的期限为十年)。在第一种结构下GP 获得以总承诺资本为基础的 X%的附带权益。在第二种结构下，GP 获得以总投资资本为基础的 Y%的附带权益。对于给定的总退出收益Z元，结出两种结构下附带权益分别是多少？（10分）

总管理费用 = 2.5亿 * 2% *10 = 0.5亿

总投资资本 = 2.5亿- 0.5亿 = 2亿

结构一的附带权益：（Z-2.5亿）* X%

结构二的附带权益：（Z-2亿） * Y%

### 九、为什么绝大多数公司希望公司股票上市？（10分）

1. 绝大多数公司希望公司股票上市的主要原因是为了筹集资金。当公司股票上市后，公司就可以通过发售股票来吸引投资者购买股份，从而获得更多的资金。这些资金可以用于扩大业务、投资研发、进行收购等，从而推动公司的发展。这些资金数量大，速度快，同时也无需归还，不需要支付利息，可以大幅降低企业财务成本。

2. 提高公司的知名度和声誉，吸引更多的员工和客户，增加公司的曝光度，提高公司的市场价值等。

3. 公司股票上市还可以为公司的股东提供更好的流动性。一旦公司股票上市，股东就可以在证券交易所上出售或购买股票，从而实现对公司股份的流动性和灵活性，这也有助于吸引更多的投资者。公司创始人和投资人也可以实现套现目的。更好退出，可以通过公开市场收回投资于回报，同时也为风险投资人和私募基金的推出提供了顺畅的通道。

4. 股票市场提供了对公司的监督和信息

5. 有利于企业进行兼并收购以及资产重组
