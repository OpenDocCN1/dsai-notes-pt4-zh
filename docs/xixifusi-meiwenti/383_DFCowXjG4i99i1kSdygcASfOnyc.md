除获取资金外，融资也是选择合适的投资人、优化公司股权结构（CapTable，记录公司股权结构和所有权的表格或文档）的过程。在当今的资本环境下，对投资人进行背景调查（背调）显得尤其必要。本文为各位创业者梳理了对投资人进行背景调查的原因、内容和渠道，帮助创业者在融资全流程筛选最合适的投资人。

# **为什么要进行投资人背调？**

对投资人做背景调查，不仅能帮助创业者更好地准备和优化与投资人的交流，还能助力创业者做出明智的选择，避免可能的风险和陷阱。以下是创业者进行投资人背调的几个关键理由：

理由1: 会前为交流做有针对性的准备

在与投资人见面之前，创业者可以通过背调了解投资人的投资偏好、领域专长以及近期的投资案例，为和该投资人交流做好更充足、甚至个性化的准备。

理由2: 会后复盘和再次背调，评估双方匹配度

与投资人沟通之后，也可以在复盘时再次背调，这有助于判断对该投资人是否值得投入更多时间和资源。创业者可以基于互动体验和投资人背景，做出对双方匹配度的判断，从而优化融资时间分配及后续跟进策略。

理由3: 优中选优，确定最合适的投资人

当面临多位投资人的选择时，创业者可以利用背调来确定最适合的投资人。通过背调，创业者能够判断投资人是否真正理解项目的愿景，认识到公司当前的局限，并且能够接受自身的缺点。如果投资人仅仅被“想象中的公司”所吸引，可能会导致实际合作与预期不符。创业者应寻求那些能够在理念上求同存异，并愿意与他们共同成长的投资人。

理由4: 识别风险和陷阱，避免不利条件

进行投资人背调还有助于识别并规避潜在的风险与陷阱。部分投资人可能会利用创业者经验不足，提出不公平的条件，例如要求签署包含无限连带责任的条款，或在未来的项目中无偿提供股份等。通过背景调查，创业者能更好地避免这些可能对自己不利的情况，从而有效降低潜在的风险。

# **投资人背调应该包含哪些内容？**

投资人背景调查是一个涵盖多方面的过程，包括但不限于：

+   **投资历史和偏好： **调查投资人（机构）过去的投资组合中项目的行业、阶段和类型，了解对方的投资策略和偏好。

+   **相似 投资案例： **寻找与自己公司业务领域相符的投资案例，了解该投资人（机构）对类似项目的兴趣和态度。

+   **项目负责人的专业素养 ： **了解负责自己项目的投资人的教育背景、投资经验和擅长领域，以评估其对项目的价值和投入程度。

+   **社区评价和口碑： **通过其历史投资项目的创始人、社交媒体、投资人社区等平台的评价，了解投资人在业界的口碑和信誉。

+   **投资策略和预期回报： **探究投资人的战略规划、预期回报和对公司未来发展的期待。

+   **投资人的 公开 言论： **浏览投资人在媒体（如36氪）、机构官方账号或个人社交账号上发表的观点与内容，了解他的投资思路与思维模式。

通过对这些信息的调查和分析，创业者可以更清晰地了解潜在投资人是否与自己的企业目标和愿景相契合，以及他们是否能够为公司带来更多价值和支持。

# **开展投资人背调有哪些渠道？**

创业者在寻找和评估潜在投资机构或投资人时，可通过以下渠道对其进行背景调查：

+   **机构官方渠道： **访问基金的网站、👸号、视频号等官方平台，从中了解该机构的投资逻辑、策略、偏好和核心观点，这有助于判断该机构是否对类似项目感兴趣。

+   **创投服务 平台： **通过使用企名片、天眼查、企查查等公开信息平台，可以搜索投资人、查看基金的历史投资案例，从而洞悉其投资频率和偏好方向。

+   **创投 圈内人脉： **通过在创业过程中建立的人脉，联系那些已经获得该基金投资的创业者，或者其他投资人。询问他们对该投资人的看法，有助于更好地评估与其合作的可能性。

+   **社群社区力量 ： **加入一些不对外的创业社群或社区网络，了解投资人的真实口碑评价也是一个好的策略。比如在奇绩创坛，创业营校友可以通过社区工具，了解其他校友对投资人的点评，包括对风评较差或不专业的投资人的评价，从而避开口碑不佳的投资人。

如果经过这些方式仍无法获得某位投资人的详细信息，这或许表明你需要对该投资人进行更为谨慎的考量。通过背景调查，创业者能更精准地锁定适合自己项目的投资人，从而提高获得投资的可能性，同时规避潜在风险，为项目找到志同道合的同行者。
