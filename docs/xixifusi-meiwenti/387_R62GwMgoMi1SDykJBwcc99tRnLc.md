+ 一个有代入感的真实故事，紧跟一个“超能力”的比喻，引起好奇心：公司到底是做什么的？

+ 出重点，视觉上极简，每页不超过10个单词，展示1-2秒

+ 认知心理学有个“三点法则 (Rule of Three)”，三个观点或者案例最能吸引观众并留下印象

+ 简洁而高大的公司愿景，在痛点的基础上提炼了高度

+ 通过与知名产品的比较来阐述差异化，帮助观众快速理解公司的定位

+ Rule of Three：挑三个最亮眼的指标

+ 总结一下言下之意：高毛利的好生意，知名VC背书，目前不差钱（除非加估值）

这段视频的精简，通篇贯彻 “Rule of Three” 。很多原以为的亮点信息，居然在路演中仅仅一笔带过甚至只字未提。

毕竟在每一次沟通的过程中，观众的注意力都是有限的稀缺资源，随着时间和信息被持续消耗。而且录视频的形式会比实时沟通更具挑战。演讲的过程中，主要的信息传递是来自讲述者，Slides上的信息应该起到帮助听众聚焦重点的作用，而不是抢走观众的注意力 。

对于 Siroker 来说，整段视频的目的及其明确：是吸引听众注意、勾起怕错过的情绪；而不是详细的讲解 Rewind 具体是如何实现的，或者 Rewind 的压缩技术到底领先行业多久。所以你可以看到 Siroker 公布的数据都是内部的、局部的数据（比如留存、日活/月活比等），舍弃的信息都是公开的、可查的（比如 Product Hunt 上榜、创始人曾经的成功创业经历等），留给投资人自查，查完可能就更加上头了。

> 创始人需要两种不同的宣传文件。

+ 其中一个版本包含大量文本和信息，你可以通过电子邮件与他人和自由职业者分享。

+ 另一个版本则应该亲自(或在线)向核心投资者展示，并使用更多的视觉效果，因为视觉效果可以帮助你抓住投资者的注意力。

优秀的Pitch deck的三大关键是:

+ 引人注目

+ 易于阅读

+ 简单明了

最好是10-19页

### 标题

标题幻灯片是Pitch deck的第一页，也是最重要的一页，因为它概括了你想要展示的内容。此外，标题还能将投资者的注意力引向你的项目目的。

因此，幻灯片必须包含你的品牌名称、标志、公司口号和电子邮件地址，以便那些想要联系你的投资者。另外，要确保在这张幻灯片中使用的标志在幻灯片的其他页面上也有重复。

### 问题痛点幻灯片

这张幻灯片解释了你的区块链解决方案正在填补的市场空白。重要的是要注意，它必须是你的目标受众能感同身受并一直在努力解决的痛苦问题。此外，你是在解决一个问题，而不是两三个。专注于一个问题可以使你(和你的联合创始人)看起来有专注力，且有能力解决这个问题。

我建议针对问题和解决方案制作不同的幻灯片，这样就不会让你的读者被一张幻灯片弄的不知所措。请注意，当投资者参与你的项目时，可能是因为以下原因之一:

+ 他们过去也经历过同样的问题

+ 他们了解生态系统的问题

+ 他们对投资回报率有把握，因为他们知道解决这个问题会有收益。

如果一个投资者属于上面提到的任何一种，这意味着你得到了一个主要投资者。因此，确保你以一种触动读者情感的方式来呈现问题。

### 解决方案

你对上述问题的解决方案必须对你的读者是显而易见的。在这张幻灯片中，你可以自由地谈论这个领域，以及你的产品如何帮助这个领域。

最好能准备产品的 Demo 以配合项目介绍。

在制作这张幻灯片时，要**研究并突出主要问题**，然后将它们与你的**解决方案**联系起来。然后，**列出已经存在的解决方案及其缺点**(如果有的话)。

同样重要的是，**你要概述为什么要现在推出。**正如你所知道的，在商业中时机就是一切，处于历史上的正确时间才是最重要的。

太早或太迟都可能导致项目失败，这是我们不希望看到的。此外，不要说你是唯一一个这样做的人，是这个行业的先驱。

正如马克·库班所说，在你和其他公司用不同的方法解决这个问题之前，至少有100个人有过同样的想法。

### 市场/竞争

每一项业务增长的关键指标之一是它所处的市场/所面临的竞争。

为什么？

因为它决定了投资者的潜在退出。

这里需要展示该项目在适应市场和获得市场份额上的优势。具体而言，你可以利用对比分析法，将自己的项目和同类竞品项目多维度进行对比分析，展现你的项目特殊之处。此外，还可以展示该领域过去市场增长和未来潜在增长，从市场的角度展示项目所具有的潜在实力，以及能够为投资者带来的价值。

### 商业模式

“一个创业者的真正产品不是解决方案，而是一个行得通的商业模式。”在这张幻灯片中，应该展示你的商业模式和商业价值，在这一环节非常建议大家利用图表来展示项目商业价值。这里要解答的关键问题是：

+ 你的商业模式如何通过实验或案例研究具有了可行性？

+ 你的项目产品如何赚钱收益？

+ 你需要多少资金来验证你的商业模式？如何分配？（融资计划）

### 你要如何脱颖而出？

我建议用图表来展示这些信息，概述过去的市场增长和未来的潜在增长，以便投资者可以量化他们的投资的上升空间和投资回报率。同时，要用研究论文来支持这里的信息。

### 牵引力/衡量标准

在这张幻灯片上，你必须说服投资者你的企业能够长期生存。你可以通过展示你的业务的逐月增长(例如，收入，指标)来做到这一点。

例如，像Y Combinator这样的加速器项目希望至少有15%的月度增长。然而，如果你还处于起步阶段，或者你的增长并不是那么理想，就不要提及这一点。

你还可以纳入你的客户的增长率以及Facebook、Twitter和Instagram上活跃的社交媒体粉丝数量。这样做可以帮助你获得社会认可。

### 请求/正在筹集的金额

申请资金时要有策略。

不要把你想筹集的具体数额写出来。例如，如果你想筹集300万美元，我建议把金额设置在200万美元到600万美元之间。

这样做的一个原因是，公司通常对其投资有限制。这家公司可能被要求投资不超过300万美元，所以他们很可能会pass掉。

通过设置300万到500万美元的融资金额，你也将这样的公司包括了进来。选择范围可以吸引尽可能多的目标。然后，请详细分析你将如何使用这笔资金。

### 团队

团队成员可能是所有pitch deck中最重要的幻灯片之一。因为它展示了从事项目的团队。你的潜在投资者和听众想了解掌船的人以及他们的独特之处。

因此，在制作这张幻灯片时，请重点突出每个成员的两三项成就和角色(与项目成功相关的角色和成就)。如果你的团队规模很大，请先说出团队中重要成员的名字，以免幻灯片过于拥挤。

我相信，如果你的团队中有合适的人，你的品牌也会受益。

如果你(和你的团队)是第一次创建公司，那就公开吧。这将帮助你建立信任，毫无疑问，投资者不会介意这一点。但是，当然，这意味着他们要投资于你的教育、经验和过去的错误。没关系，因为这也是旅程的一部分。

### Roadmap

如何从一个 Demo 走向成熟的 Web3 项目？在提供了所有事实、数据等信息基础上，接下来就要向大家展示项目发展前景。项目的未来规划是必不可少的内容之一，一份合理的 Roadmap 能够帮助论证你的项目具有长远发展的可行性。

什么时候开始做的？完成了哪些部分？下一个关键节点是什么？

对于任何一个项目来说都肯定需要短期目标和远期规划，创业项目短期目标可以有很多个，但是远期规划是什么一定要清晰。

### 其他一些建议

一定要确保你的幻灯片上没有太多不必要的信息和图表。

每张幻灯片都要简单明了，开门见山，并使用投资者熟悉的词语。

最后，如果你的投资者对项目有任何疑问，请毫不犹豫地询问他们。

+ 三个核心：彰显团队软实力；用数据证实逻辑；以价值驱动利益；

+ 五个原则：文不如字、字不如表、表不如图、图不如景、景不如情；

+ 不要拿路演当练习，正式路演前必须经过头脑风暴的演练推演；

+ 不要照本宣科，低头只念 PPT，照本宣科的阅读，再好的创意也会被埋没；
