# 1 计算market size

https://www.zhihu.com/question/23177722

从【需求端】的逻辑

先确认要算销量/销售额，定范围，比如中国或者亚洲；时间，比如一年的总销售额

之后根据产品还有一些假设，比如主要消费人群和场景等

开始拆：可以按照【存量替换+增量】，两部分都是【数量*单价】的格式：

1.数量=总人口/总家庭数量/某年龄段人口/总toB客户量*渗透率（这一部分可以分类讨论，按照年龄/收入/性别/地域等）*一次购买几单位产品*购买频率（如果有季度特征再分类，一般思路按照产品使用寿命除以一年360天拍）

2.单价，这个比较简单，就是产品定价

最后就是把公式里需要的数据都带进去，数据可以自己拍或者查

但是这种方法比较容易产生很大的误差（特别是在估计渗透率这种比例的时候），最后的结果可以再和研报数据double check一下捏，（研报找这个产品/替代品/竞品都可）
