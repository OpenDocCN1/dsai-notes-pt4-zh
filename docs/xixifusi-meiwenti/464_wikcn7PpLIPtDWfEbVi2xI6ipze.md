# 如何自洽，找到自己的锚点

> 来源：[https://docs.feishu.cn/docx/BaoUdcAt8odrKBxNySxc1s0on3g](https://docs.feishu.cn/docx/BaoUdcAt8odrKBxNySxc1s0on3g)

研究本身非常耗费时间，如何在web3里面善待研究？

+   投研信息导致严重的心态失衡，加上个人成长增速变缓，产生了一定程度上的焦虑。

+   希望通过持续不断提高自身综合能力，然后投资一些稳定的标的（不至于影响我的生活/所谓的web2价值投资）来提高我的财富等级的人。我追求work life balance，我希望有稳定的休息时间，可以用来陪我的爱人，我的家人，可以有时间看看当季的热播电视剧，看看热播电影，还能够在周末的时候去咖啡店点杯喜欢的咖啡，看一下午书....

+   没有必要太跟随圈子的速度

+   购买生息资产。资产放着不动是很容易被自己反复交易的，我就是典型的例子，无法hold任何token。所以我选择了几个不错的标的进行staking，可以是选择质押进validator，也可以是选择本身的项目方的矿，只要是自己看好的质押就完事了，毕竟现在是熊市..大部分都是被低估的价格。（非投资建议，理性看待）

+   修炼自己的技能。各种能让你自身价值提高的技能，例如英语，写作，编程

+   提高自己的能力，让自己变得更加稀缺，然后去投资生息
