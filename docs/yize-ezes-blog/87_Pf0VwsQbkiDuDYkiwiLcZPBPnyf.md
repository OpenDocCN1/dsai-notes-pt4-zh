
# Chat Memo 插件本地安装指南

> 来源：[https://chatmemo.feishu.cn/docx/YBTvdooqSo9NuwxOCzMccNT4nDc](https://chatmemo.feishu.cn/docx/YBTvdooqSo9NuwxOCzMccNT4nDc)

+ 使用本地安装方法，务必定期使用插件内「设置-导出数据」导出数据，完成备份

+ 后续更新也可通过此方法，继续使用更新版本的插件。更新时，千万不要删除原有插件，请务必直接按同方法拖入安装包后，会自动覆盖旧版本，完成更新！

## 1）下载 `Chat-Memo.crx.zip` 并解压

+ 当前版本下载地址 V1.1.2：https://eze.lanzoul.com/i4gIt3cqxwda

+ 历史版本详见：[Chat Memo 插件本地安装指南](https://zkv549gmz8.feishu.cn/wiki/Pf0VwsQbkiDuDYkiwiLcZPBPnyf#share-Dk49dAibFov9B8xUSMXcMGiunuf)

![](img/5715265618f8535d3d1231b87ee0870b.png)

## 2）打开 Chrome 的扩展程序页面，并打开开发者模式

> 扩展程序页面：浏览器地址栏输入 `chrome://extensions/`

![](img/e31b995245c0e38f18e50a61898e0081.png)

## 3）安装插件

> ⚠️ 注意：需要拖入 `.crx` 文件，不要点击加载已解压的扩展程序

![](img/78463f324273b72c4ba889a12cb70837.png)

点击「添加扩展程序」，即刻安装（仅第一次安装会显示）

![](img/a8bb8a04bb0a62197e4f31f5d4ac3976.png)

## 4）安装成功，置顶显示插件（方便后续使用）

![](img/0cdaebf6390a34202f99827d9d9a400f.png)

## 5）开始快乐使用！
