## AI解决核心痛点

> For卖家

+ **核心：卖家手动回复低效，AI可通过「获取售卖预期、自动化对话」的方式提高沟通效率。**

### 好的AI产品设计点

+ 托管日志：明白托管明细，即便AI自动化，也要全程让用户有知情+可操控感

![](img/7aecf5c0d98e9de2617540d8a9da3434.png)

+ AI✖️人工的处理。AI正在聊，卖家此时上线怎么办

+ 选择1：直接让机器人继续聊

+ 选择2：自动取消托管，卖家自己聊**「闲鱼的选择⬅️」**

+ 选择3：给卖家提示，选择让AI继续聊还是自己聊「但闲鱼未采用此种处理方式」

### 产品未来迭代点Brainstorm

+ **多样化售卖方式选择。**参考古时候的当铺，or现在卖房子

+ 有人就想原价卖出去，为此可以等几个月，诉求是原价卖，我只是“托管”卖出

+ 有人急用钱，可以降到很低的价，诉求是快速卖出

> AI是方便人们生活、提效的，但应该在提效的同时，前置“让AI和用户沟通好对AI的预期“

+ **模型调优。**避免用户直接问出低价
