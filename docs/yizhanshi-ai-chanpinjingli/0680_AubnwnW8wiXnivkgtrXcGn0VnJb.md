## 基础

### 什么是评判模型评估？

评判模型就是用来评估其他神经网络输出的神经网络。在大多数情况下,它们用于评估文本生成的内容。

评判模型的类型从小型专用分类器(比如类似"垃圾邮件过滤器")到大语言模型,包括通用大模型和垂类小模型。在后一种情况下,当使用大语言模型作为评判器时,需要给它一个提示来说明如何对模型打分(例如:对流畅度打分从0到5分,0分表示完全无法理解...)。

作为评判器的模型可以对文本的复杂和细微特性进行评分。例如,预测结果与参考答案的精确匹配可以测试模型是否预测了正确的事实或数字,但评估更开放性的经验能力(如流畅度、诗歌质量或对输入的忠实度)需要更复杂的评估器。

这就是模型评判器发挥作用的地方。

它们主要用于3个任务:

1.  按照提供的量表对模型生成的内容进行评分,以评估文本的某个特性(流畅度、有害程度、连贯性、说服力等)

1.  成对评分:比较一对模型输出,根据给定的特性选择最佳文本

1.  计算模型输出与参考答案之间的相似度

### 使用评判型大语言模型的优缺点

优点：

+   相比人类更客观：它们以客观和可重复的方式自动化实证判断

+   规模化和可重复性：比人工标注更容易扩展,可以在大量数据上重复评分

+   成本低：

+   无需训练新模型,只需基于现有高质量大语言模型进行适当提示

+   比支付人工标注人员更便宜

+   与人类判断有一定相关性：它们的评判结果与人类判断存在相关性

缺点：

+   关于客观性的问题：虽然看似客观,但存在许多隐藏偏见,这些偏见比人类偏见更难被发现

社会学已有近百年关于如何通过特定统计方法减少人类偏见的研究,而大语言模型提示技术尚未如此成熟

用大语言模型评估大语言模型可能产生回音室效应,潜在地强化偏见

+   关于规模化的问题：确实可以扩展,但会产生大量需要验证质量的数据

为提高评判质量而要求模型生成思考轨迹或推理过程,这又会产生更多需要分析的人工数据

+   关于成本的问题：虽然部署成本低,但对特定用例而言,付费聘请专业人工标注者可能会得到质量更好的结果

## 构建一个评判模型

构建一个评判模型一般有三种方法：

### 使用通用的大型语言模型（LLM）

随着更强大的大型语言模型（如 ChatGPT）的引入，一些研究人员开始探索使用大型模型作为评测工具。目前最优秀的大型模型评测工具通常是闭源模型（如 Claude 或 GPT-o 模型）。不过，由于高质量开源模型（如 Qwen 2.5、Command R+ 或 Llama 3.1-405-Instruct）的快速进步，开源与闭源模型之间的差距正在迅速缩小。

**闭源模型**尽管表现出色，但也存在以下多个缺点：

1.  **依赖 API**：这意味着模型（以及相应的结果）可能会在没有任何通知的情况下发生变化，从而影响评测结果的可复现性。

1.  **黑箱操作**：闭源模型无法解释其内部工作原理。

1.  **潜在的数据泄露/隐私风险**：由于需要通过互联网将数据发送给第三方，数据安全性可能比本地管理的数据低，且无法确定这些数据会被如何处理（通常需要手动选择拒绝将数据用于训练集）。

然而，闭源模型也有其优势：无需本地部署或硬件支持，任何人都可以直接访问高质量的模型。如今，大多数高质量的开源模型也具备了这些优势，它们可以通过模型提供商访问，并解决了上述前两个问题。

如果需要帮助选择模型提供商，可以参考这里的成本分析。

### 使用专用 LLM 评测模型

您也可以选择使用专用 LLM 作为评测工具。这类模型通常只有几十亿参数，可以在大多数现代消费级硬件上本地运行，并通过从头训练或使用指令数据进行微调。使用这类模型时，通常需要遵循其特定的提示格式。

**现有的一些模型：**

1.  **Flow-Judge-v0.1**

+   参数量：3.8B

+   基于 Phi-3.5-mini-instruct 微调，使用合成偏好数据集训练。

1.  **Prometheus**

+   参数量：13B

+   从零开始训练，基于合成偏好数据集。

+   另有 7B 参数的 v2 版本，基于 Mistral-7B-Instruct-v0.2 微调，使用更大的合成偏好数据集，并进行了权重合并。

1.  **JudgeLM**

+   参数量：7B 到 33B

+   从零开始训练，使用多种模型生成的合成偏好数据集。

### 训练自己的 LLM 评测模型

您也可以选择训练或微调自己的 LLM 作为评测工具。

**第一步**：为您的任务收集偏好数据，这些数据可以来自以下来源：

+   已有的人类偏好数据集。

+   模型生成的偏好数据（可以参考上述小型模型评测工具论文中的数据部分生成，或者直接使用，例如 Prometheus 偏好和反馈数据集）。

**第二步**：决定从以下哪种方式开始：

1.  **从一个小型模型开始，从头训练**。

1.  **基于已有模型**：

+   **蒸馏**成一个新的小型模型。

+   **量化**现有模型。

+   然后使用上述数据进行微调（如果模型较大而您的训练算力有限，可以使用 PEFT 或适配器权重进行微调）。

研究表明，**从奖励模型开始训练**比从指令模型开始效果更好。

## 设计评估提示词（Evaluation Prompt）

### 通用提示词设计建议

以下是一些在设计提示词时可以参考的通用指南：

1.  **提供明确的任务描述**：

+   清楚地说明任务内容，例如：
“你的任务是完成 X。”
“你将获得 Y。”

1.  提供清晰的评估标准和评分系统（如果需要可以详细说明）：

+   例如：
“你需要根据 1-5 的评分系统评估属性 Z，其中 1 表示...”
“你需要判断样本 Y 中是否存在属性 Z。如果存在属性 Z，则...”

1.  **加入额外的“推理”评估步骤**：

+   例如：
“为了评估这个任务，你需要首先仔细阅读样本 Y，以识别...，然后...”

1.  指定期望的输出格式（增加字段有助于提高一致性）：

+   例如：
“你的答案应以 JSON 格式提供，格式如下：{"Score": 你的评分, "Reasoning": 你给出评分的推理}。”

1.  **从现有模板中汲取灵感**：

+   可以参考 **MixEval** 或 **MTBench** 的提示模板。

### 其他提示信息

+   **成对比较**：
 成对比较（Pairwise Comparison）比直接评分与人类偏好更相关，且通常更稳健。

+   **如果确实需要评分**：

+   使用整数评分尺度，并提供详细的评分说明。

+   或者采用累加式提示（如：“答案具有此特性得 1 分，具有额外特性再加 1 分...”）。

+   **针对单一能力设计提示词**：
 每个能力使用一个独立的提示词来评分，往往可以得到更好、更稳健的结果。

### 提高评估准确性的技巧

以下是一些可能需要更多成本但可以提高准确性的技巧：

1.  少样本示例（Few-shot Examples）：

+   就像许多其他任务一样，提供示例能够帮助模型更好地推理。

+   但这会增加上下文长度。

1.  **参考内容（Reference）**：

+   如果有参考内容，可以将其加入提示中，这通常可以提高准确性。

1.  思维链（Chain of Thought, CoT）：

+   要求模型在给出评分前输出其推理过程，可以提高准确性。

1.  多轮分析（Multiturn Analysis）：

+   有助于更好地检测事实性错误。

1.  **评审团机制（Jury）**：

+   使用多个评判模型，并对答案进行聚合处理，比单个模型给出的结果更好。

+   通过组合多个小型模型（而非一个昂贵的大型模型），可以显著降低成本。

+   还可以尝试使用同一个模型，但调整温度参数以生成不同的回答。

1.  **赋予任务“赌注”**：

+   社区发现，为提示词添加一定“赌注”（如：“回答正确，你会得到一只小猫”）可能会提高正确率。不过，这种方法的效果因场景而异，请根据需求调整。

### 关于提示词设计的注意事项

+   如果你的任务对准确性要求较高（涉及高风险场景），为了尽量减少偏差，可以参考社会学领域的问卷设计研究。

+   如果将评估模型视为人类标注员的替代品，则需要考虑类似的评估指标，例如：

+   计算标注员之间的一致性（Inter-annotator Agreement）。

+   使用正确的问卷设计方法来缓解偏差等。

### 快速评估 vs 高质量评估

大多数情况下，人们并不需要完全可复现、高质量且无偏的评估，而是满足于通过“够用”的提示词进行快速评估。这种做法是可以接受的，具体取决于任务的后果和需求。

## 评估你的评估模型

在将评估型大型语言模型（Judge-LLM）用于生产或大规模应用之前，你需要先评估它在特定任务中的质量，以确保其评分对你的任务是相关且有用的。

**注意**：

如果评估器预测的是二元输出（如“是/否”），评估会更容易，因为可以使用易于解释的分类指标（如准确率、召回率和精确率）。

如果预测的是评分（如某一范围内的分值），则很难估计其与参考标准之间相关性的质量。

一旦选择了评估模型及其提示词（prompt），你需要完成以下步骤：

1.  选择基准（Baseline）

你需要将评估器的判断与某种基准进行比较。基准可以是以下之一：

+   人类标注结果

+   另一个在该任务中表现良好的评估模型的输出

+   标准答案（gold truth）

+   使用相同模型但不同提示词生成的结果

你不需要大量样本（50 个样本可能已经足够），但这些样本必须高度具有代表性，能够区分边界情况（尤其是难以判断的边缘案例），并且质量尽可能高。

1.  选择评估指标（Metric）

评估指标将用于比较评估器的输出与基准参考的区别。

+   **二元分类或成对比较**：
 如果模型预测的是二元分类（如“是/否”）或成对比较（如“答案 A 优于答案 B”），你可以计算以下指标：

+   **准确率**（Accuracy，适用于成对比较）

+   **精确率和召回率**（Precision 和 Recall，适用于二元分类）

+   这些指标直观且容易解释。

+   **评分相关性**：
 如果模型输出的是评分（如 1-5 的分值），比较其评分与人类或参考模型评分的相关性会更加困难。

+   想了解更多细节，可以参考这篇博客。

+   如果不确定选用何种指标，也可以参考上述博客中的图表。

1.  评估你的评估模型

在这一步，你需要使用选定的模型和提示词对测试样本进行评估。完成评估后，使用前面选定的指标和基准来计算评估器的得分。

**设定接受标准**：

+   如果你的任务是成对比较，可以将准确率目标设定为 80%-95%（具体取决于任务的难度）。

+   如果是评分相关性，文献中通常认为 0.8 的 Pearson 相关性是一个令人满意的结果。然而，有些论文甚至声称与人类标注员相关性达到 0.3 就是“良好相关性”（^^"）。所以，这取决于实际情况。
