## Agent 设计

> Agent 的海报生成能力主要通过工作流实现。工作流中，模型节点生成文案、图像节点完成海报排版。Bot 提供多种海报模板，部分主题的模板无需用户输入，只需要选择主题即可一键生成海报，部分海报模板依赖用户输入，需要根据用户指定的信息生成海报。

![](img/46a29c4470756925f679abc91330e367.png)

## 功能实现

制作海报的核心要点是海报中的各种“元素” ，海报中每一个组成部分都是一个独立元素。扣子的画板节点支持通过动态参数传入动态的元素。使用扣子画板功能制作海报，需要提前设计配置到海报中的元素，我们称之为动态元素或静态元素。

+   动态元素是由上游节点传递下来的元素，元素内容是动态变化的，例如通过大模型节点自动生成的文案。

+   静态元素是固定内容的元素，不受任何因素影响。静态元素可以直接固定在画板节点中。

### 生成自定义海报

自定义海报是根据用户上传的文案内容生成的海报，这类海报工作流搭建相对比较简单。优先设计并配置好图像节点，再将图像节点编排进工作流即可。

#### 图像节点配置

通过图像节点配置一个海报模板。我们先思考模版有哪些元素：

+   **动态元素**：

+   模型生成：中文文案、英文文案、早安的英文、时间、两张图片

+   用户提供：早安/午安/晚安

+   **静态元素**：白色面板，斜杠线，最下方英文

模版中的没有元素需要运用到其他节点，所以图像节点的搭建主要在开始节点的参数设定，以便在工作流可以直接导入。设置如下：

| **节点类型** | **说明** | **示例** |
| --- | --- | --- |
| 开始节点 | 依次填写好导入的元素的名称以及变量类型。 | ![](img/ad4999766a4f926858fd2598fce67a68.png) |
| 元素节点 | 元素节点不可一次性设定这些元素，最好一层一层的去解决，除了最后一个元素是后加上的，其余都是按照顺序进行一次引用。 | ![](img/753b7e4971f83fa56605bd50b1b9d28b.png) |
| 结束节点 | 这里直接引用画板输出图片即可。 | ![](img/0e02364f62c13eb38d94c6239dda4667.png) |

### 生成主题海报

主题海报为不依赖任何用户输入，选用固定文案和风格，每次生成的海报风格和主题相同，但关键元素不同。这类海报图像节点和工作流搭建会多几道工序。生成主题海报同样需要优先配置好图像节点，再根据图像节点搭建工作流。
