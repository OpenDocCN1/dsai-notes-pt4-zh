# 3，进军短视频大军第一步：用什么来制作Ai短视频呢？

## 认识工具：剪映，剪映小助手

> 第一章让大家下载配置了

### 准备工作

在认识工具之前，我们先要把工具拿出来。下面是工具的简单介绍，以及具体的官网和下载地址

+   [**coze扣子**](https://www.coze.cn/studio)：构建工作流的平台

+   [**剪映小助手**](https://ts.fyshark.com/#/cozeToJianyin)：**需要参考test1配置。**一个专业的视频创作辅助工具，让视频制作更加高效便捷。支持一键导入剪映草稿、智能模板管理、云端同步备份等功能。

+   [**剪映**](https://www.capcut.cn/)：一个专业剪辑软件，但是在制作的时候需要会员功能，我才不会给你盗版软件！

其中，coze只需要在浏览器内即可工作。剪映和剪映小助手需要下载软件

### 工具之间的关系

上述一切准备就绪的同时，想必也大致了解了三者各自的定位，我们再来结合下面的图文详细的来讲解三者之间的关系：

![](img/4f549f8ccf5456e05fd94a6c372786da.png)

1.  **Coze生成素材与草稿**

+   用户输入主题（如“心理学小知识”），Coze调用大模型生成分镜脚本、图像（如火柴人插画）、配音；

+   通过剪映插件将素材打包为结构化草稿文件（JSON），包含时间轴、特效参数等元数据。

1.  **剪映小助手中转处理**

+   接收Coze的JSON文件，自动匹配剪映客户端的草稿存储路径；

+   将草稿文件解析为剪映可识别的工程文件，无需手动导入素材。

1.  **剪映完成最终制作**

+   打开剪映客户端，草稿自动出现在“草稿箱”中；

+   用户可微调剪辑细节（如调整字幕位置、替换背景音乐），或直接导出成品视频
