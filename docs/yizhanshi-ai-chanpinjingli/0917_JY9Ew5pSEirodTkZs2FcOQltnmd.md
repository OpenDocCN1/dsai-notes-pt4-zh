#### 二、工作流核心架构（全局视角）

```
graph LR
```

#### 三、分步搭建教程（含避坑指南）

##### ✅ 步骤1：创建工作流基础框架

1.  **新建工作流**​：英文命名（如 health_content_generator）

1.  **设置开始节点**​：添加变量 input（字符串类型，接收用户主题）

##### ✅ 步骤2：配置文案生成节点

+   **大模型节点1**​（初稿生成）：

+   模型：DeepSeek-V3

+   系统提示词（关键！）：

```
你是一名健康养生专家，需生成10种食物的科普文案，包含：  
1. 名称（name）  
2. 功效（description，50字内）  
3. 输出格式：JSON数组，键值对包括name/description
```

+   用户提示词：{{input}}（引用开始节点变量）

##### ✅ 步骤3：文案风格改写

+   **大模型节点2**​（📕优化）：

+   输入：初稿节点的输出数组

+   提示词技巧：

+   “添加emoji表情❗️用‘’‘分段’‘’❗️开头加悬念‘我不允许你不知道...’”

##### ✅ 步骤4：批量生成配图（批处理节点）

+   **循环设置**​：并行数=3，上限100次（网页1）

+   **图像生成插件**​：

+   正向提示词：卡通风格+{{name}}+健康养生+📕封面

+   比例：9:16（竖屏）

+   **画板合成**​：

+   上传底图 → 添加动态元素：

+   主题文本 {{subject}}

+   抠图后的主图 {{image}}

+   描述文字 {{description}}（字体：霞鹜文楷）

##### ✅ 步骤5：输出与调试

+   **结束节点**​：返回文案+图文数组

+   **试运行**​：输入“养胃食物”，检查输出格式是否对齐（常见问题：JSON解析失败需调整提示词）

#### 四、效果优化技巧

1.  **提升文案质量**​：在系统提示词中限定“禁止学术术语，用‘’‘痛点是...解决方案是...’‘’结构”

1.  **加速图片生成**​：设置image_size=1024x1024，避免超时（网页1）

1.  **错误处理**​：添加条件分支，当输出为空时自动重试（网页6）
