# 开场白

> 来源：[https://v11enp9ok1h.feishu.cn/docx/GT2RdwGwYo27g3xaijDcnQntnAg](https://v11enp9ok1h.feishu.cn/docx/GT2RdwGwYo27g3xaijDcnQntnAg)

开场白是用户进入 Bot 后自动展示的引导信息。它的主要目的是帮助用户理解 Bot 的用途，以及如何与其进行交互。

> 开场白功能目前支持豆包、微信公众号（服务号）。

# **设置开场白 **

1.  在 **Bots** 页面，创建一个 Bot 或进入指定 Bot。

1.  在 **Bots** 编排页面的**开场白**区域，设置**开场白文案**和**开场白预置问题**。

+   **开场白文案**：帮助用户快速理解 Bot 的能力。

+   **开场白预置问题**：添加一个或多个问题引导用户提问，用户点击问题即可开始会话。

+   开场白预置问题和开场白文案一起生效。

+   填写的引导问题超过 3 条时，Bot 将随机显示其中的 3 条。
