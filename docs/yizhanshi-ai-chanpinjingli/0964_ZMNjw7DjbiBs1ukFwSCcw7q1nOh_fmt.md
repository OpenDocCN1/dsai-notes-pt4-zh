
# 快速搭建智能体列表查询插件

> 来源：[https://v11enp9ok1h.feishu.cn/docx/ZVusdPeaXoCo9nxdDOxc03EZnPe](https://v11enp9ok1h.feishu.cn/docx/ZVusdPeaXoCo9nxdDOxc03EZnPe)

本文以搭建智能体列表查询插件为例，介绍将 API 服务转化为实用插件的全流程，包括创建插件、添加工具、发布插件等步骤。

## 背景信息

在扣子中，一个插件可包含多个工具，每个工具用于完成一个指定的动作。在创建插件时，首先需要将这个 API 服务注册为一个插件，然后再将这个服务下的 API 添加到插件中作为工具使用，最后将插件发布上线。

本教程以扣子的[查看智能体列表](https://www.coze.cn/docs/developer_guides/published_bots_list) API 为例，展示如何一步步创建插件。插件创建成功后，可以通过该插件查看指定空间发布到 Agent as API 渠道的智能体列表。以下是这个接口的基本信息。

| API 信息 | 说明 |
| --- | --- |
| 请求地址 | `https://api.coze.cn/v1/space/published_bots_list` |
| Header | +   `Authorization`：用于验证客户端身份的访问令牌，本教程以个人访问令牌为例，取值：`Bearer $Access_Token`。 |
| 请求参数和返回参数 | 参考[查看智能体列表](https://www.coze.cn/docs/developer_guides/published_bots_list)。 |

## 准备工作

确保你已经获取了访问令牌，并开通了 `getPublishedBot` 权限，详细信息参考鉴权方式概述。

## 步骤一：创建插件

参考以下操作将上述接口创建为一个插件。

1. 登录[扣子开发平台](https://www.coze.cn/home/)。
2. 在左侧导航栏中选择**工作空间**，并在页面顶部空间列表中选择目标工作空间。
3. 在**资源库**页面右上角单击 **+资源**，并选择**插件**。

![](img/79f59022fa77c70914f6fad8a2fdc4ed.png)

4. 填写插件基础信息。
5. 输入插件名称和描述。
6. 插件工具创建方式选择**基于已有服务创建**。

![](img/615eea0936351d542eb577ef749b7d5d.png)

7. 插件 URL：输入 API 的服务地址。本教程是 `https://api.coze.cn`。
8. 将以下 `Header` 信息配置到 `Header` 列表中。

+   `Authorization`：用于验证客户端身份的访问令牌，本教程以个人访问令牌为例，取值：`Bearer $Access_Token`。

+   `Content-Type`：解释请求正文的方式，固定值：`application/json`。

![](img/18fe4060a35a42868752ccb8dd3d5bea.png)

9. 授权方式选择**不需要授权**。
10. 单击**确认**完成插件创建。

## 步骤二：添加工具

完成插件创建后，就可以将该服务地址下的 API 添加到插件中了。

1. 在插件详情页面，单击**创建工具**。
2. **配置**工具名称和描述信息，然后单击确定。
3. 在**编辑工具**页面，完成以下操作。
4. 单击**更多信息**区域右上角的**编辑**，配置工具的路径和请求方法，然后单击保存。

+   工具路径：工具路径以/开始，本示例输入`/v1/space/published_bots_list`。
+   请求方法：本示例请求方法为 `Get` 方法。

![](img/30eda1e45c69a6f0ab07d8d59c61b30e.png)

5. 单击**配置输入参数**区域右上角的**编辑**，单击**新增参数**配置请求参数，然后单击**保存**。

![](img/5147fd71145649495d03027c5b3871ac.png)

6. 单击**配置输出参数**区域右上角的**编辑**，单击**自动解析**，在弹出的页面输入请求参数值，再单击自动解析。接口调用成功后，会将返回参数自动填充到输出参数列表，你可以根据需求进行修改，然后单击保存。

![](img/3493252c227edff17943d11b315a381e.png)

7. 单击**试运行**。
8. 在**试运行**页面，输入入参，然后单击**运行**测试接口。测试成功后，单击**完成**。

![](img/8599d569a165ea961c3119e729620758.png)

## 步骤三：发布插件

当添加的工具调试成功后，你就可以发布插件了。插件只有发布后，才可以被智能体使用。

1. 在插件页面，单击**发布**。

![](img/662c7445e277a8655dad0d141b7447a5.png)

2. **选择是否需要**收集个人信息。本教程的接口不涉及个人信息收集，选择否，直接发布。

![](img/ea602204d3a75795396f6714340d6bd1.png)
