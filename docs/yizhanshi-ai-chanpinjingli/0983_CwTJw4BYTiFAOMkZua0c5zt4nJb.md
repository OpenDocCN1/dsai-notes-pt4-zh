> 设计不仅仅是外观和感觉。而是关于如何运作的问题。

> 史蒂夫.乔布斯

作为从业20年的设计师，我一直很怀疑：当下的AI是否真的能帮助设计师进行商业设计。

因为实际的设计工作流不仅仅是做一张海报，它涉及两个关键：精确性和效率性。 我们需要的不仅是交付物的AI化，更是工作流的AI化。

最近有幸在 X上被Lovart品牌方邀请，成为第一批测试的创作者。就在体验了一周后，我觉得之前对AI设计的顾虑是有办法解决的。Lovart给了我和很多人一个惊喜： 让AI真正能解决商业设计的问题。它依靠的不仅是模型能力，是对设计行业的理解，以及如何打造一个设计智能体的体验。

这是我自己对Lovart的一句话总结：

**全球**首个面向设计师行业的专业Agent，整合GPT、Flux、Suno、Kling这些全模态产品的生成能力（大白话：创意、画图、写歌、动画它全能干），和独特的交互优化及设计行业调教，形成新的AI设计工作流。

![](img/378543d3fee71f3548e3219b6d5357d0.png)

至于Lovart打动我的地方，这是 懒人版总结：

+   画布+鼠标才是AI设计交互的最优解。

+   重新定义工作流：能分层编辑，能回溯结果，这是做设计智能体必须具备的素质。

+   有设计行业know how 的思维链，结果分层涌现，真正懂设计的创意伙伴。

+   Lovart的核心优势是“思考能力”，这恰恰是真实设计师的核心能力。

# 设计智能体UI最优解：画布+聊天

我从来不认为单纯的聊天打字能带来设计生产力，因为效率太低了。所以我不想先谈生成能力，而是先聊聊Lovart的UI体验。

对于普通用户，可能会认为这样简化了操作。但当我们谈论实际商业流程中的设计时，只靠打字去做设计，设计师会累死。做过设计的朋友不难理解我的意思。Lovart的交互形式是我理想中的样子，第一眼看上去你想起了什么？ChatGPT？不是，是类似Figma这样的设计产品。

![](img/2020cd3e7e1ee869b16d2c3c5bac3e62.png)

![](img/8105d647bd6f1480f1cc05b6921236cd.png)

作为设计师，看见这么多分层，就有一种踏实的感觉。

因为这才是设计师干活的样子，你可以任意拖转组合生成的结果，并且直接进行二次编辑，避免了在聊天软件中生成的结果要保存到本地，再到PS里打开做处理。说实话每次我用GPT做设计，光是花费在找图片上的精力就是巨大的。

同时Lovart允许你导入本地图像，这就会完全改变之前AI设计的工作流：

+   原来的：在AI中生成素材 - 导出 - 导入到设计工具里处理

+   现在的：在Lovart中生成素材 - 直接在画布上修改。


[513_8.mp4](https://internal-api-drive-stream.feishu.cn/space/api/box/stream/download/all/XAYGb8HTuo67SFxpKANcpbYdnW9)

之前的AI设计工具，其对象本质是一个“素材”。而Lovart在产品设计的理念上，把对象变成了“一个项目”。这就解释了为何它能做的事情一下就变得很多。看似UI上的改变，实际上是整个理念的升级。

这不是GPT的问题，因为它是聊天的，不是真正做设计的。人家压根不是干这件事的东西。干什么活用什么工具，这是我一直提倡的。

# 独特思维链：设计的价值是思考

最后聊聊生成能力，这个可能大多数人最关心的问题。但聊到这看了那么多实测案例，我相信大部分朋友心里已经有数了。

而Lovart本身是在结合GPT、Flux等模型进行结合，因此，它能实现高质量输出的关键因素不在于生成（画的能力），而在于对需求的分析（思考的能力）。

和真实的设计师一样，从业20年，我见过的顶级设计师，核心能力都是思考能力，而不是“画画”的能力。

实际上，Lovart模拟了一个为设计行业专门优化的思维链。在这个过程中，他就像你的一个设计伙伴一样，不断分享他对设计的思考。比如下面这个例子，你可以看到从需求到思考，再到产出的全部过程：

![](img/bc99d6681bb1e63d3e71c7cdb8639a8e.png)

![](img/6ce0802237104c030ece0ef275ad2a4b.png)

同时，生成结果的过程也并非一步到位，而是先生成局部素材，再“组装”到一起，这和其他AI工具在处理设计工作的步骤上有巨大的区别。

我们可以明显的看到，它先生成了左侧的6张图片，再考虑如何把图片“放”到网页中：

![](img/4403f0bda2d4f335480cc7ea8e5f9677.png)

我要说这种有逻辑的思考对设计师是非常重要的，因为设计的本质就是解决问题。

很多人都会遇到的问题：明明使用同样的AI工具，为什么效果和别人或者某人差很多，我个人的观点是，大家想问题的方式是不一样的，而Lovart恰恰很好的承担了在创作和AI之间的“翻译”问题， 避免了沟通障碍。

做设计的朋友都理解沟通需求这事儿有多痛苦。

因此，你会发现，Lovart调用同样的模型生成的结果要远远高于平均水准，原因就在于它独有的理解能力，对设计行业各种痛点和需求的知识库，说句特别俗的话就是它有“行业Know How”，这是它巨大的价值，尤其在设计行业。

因为设计的本质并非仅仅是视觉呈现，更在于解决实际问题。

# 设计是不是美工，是思考者

众所周知，很多公司会对设计师称呼为“美工”，调侃也好，认真也罢。这种说法本身就是对设计的不理解和不尊重。

因为设计师从来不仅仅只是关于视觉的工作，而是一个思考者，一个解决问题的人。

所以Lovart在测试中给我的感受，正是它充分理解了设计这个行业的关键点，并且找到了和AI结合的最佳方式。它是第一个使用了设计师期望，至少是我个人期望的产品形态来解决设计问题的产品。

我无法预言未来设计行业和AI的发展，今天看到有人说，它就是设计行业的manus，他们确实有类似的地方，但我不想过于标题党， 也不想说出那种“谁谁谁要被取代了“之类的标题党语式。

我能说的是：至少在测试了Lovart一周后，我清楚地体会到这个产品是我作为设计师需要的。它做了很多巧妙的改变，原因在于，它们真的在思考设计行业需要的东西，就像设计本身一样：

真正的价值在于思考和解决问题。
