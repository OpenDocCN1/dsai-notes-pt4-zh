## 推荐系统之冷启动

**UGC的物品冷启有哪些**

+   ⼩红书上⽤户新发布的笔记。

+   B站上⽤户新上传的视频。

+   今⽇头条上作者新发布的⽂章。

**为什么要特殊对待新笔记？**

+   新笔记缺少与⽤户的交互，导致推荐的难度大、效果差。

+   扶持新发布、低曝光的笔记，可以增强作者发布意愿。

**优化冷启的目标**

+   精准推荐：克服冷启的困难，把新笔记推荐给合适的⽤户，不引起⽤户反感。

+   激励发布：流量向低曝光新笔记倾斜，激励作者发布。

+   挖掘⾼潜：通过初期⼩流量的试探，找到⾼质量的笔记，给与流量倾斜。
