### 可流式传输的 HTTP 传输

Streamable HTTP 是一种现代、高效的传输协议，用于通过 HTTP 公开您的 MCP 服务器。它是 Web 部署的推荐传输协议。

要使用可流式传输的 HTTP 运行服务器，可以使用 `run()` 方法并将 `transport` 参数设置为 `http`。这将在默认主机 (`127.0.0.1`)、端口 (`8000`) 和路径 (`/mcp/`) 上启动服务器。

```
from fastmcp import FastMCP

mcp = FastMCP()

if __name__ == "__main__":
    mcp.run(transport="http")
    # mcp.run(transport="streamable-http")
```

👉为了向后兼容，在 `FastMCP` 中，无论何处 `http` 被接受为传输名称，您也可以将其 `streamable-http` 作为完全支持的别名传递。

### 引出

这是 `FastMCP` 2.10.0 版本中的新功能。用户引导功能允许 MCP 服务器在工具执行期间向用户请求结构化输入。

工具不需要预先输入所有信息，而是可以根据需要以交互方式询问缺少的参数、说明或其他背景信息。

引导功能使工具能够暂停执行并向用户请求特定信息。此功能尤其适用于：

+ 缺少参数
+ 澄清请求

为了利用服务器端的引出功能，请使用 `ctx.elicit()` 任何工具函数中的方法来请求用户输入：

![](img/b7be461727b316ac3464b6060410853d.png)

引出结果包含一个 `action` 字段，指示用户如何响应：

+ `acceptdata` ：用户提供了有效输入；数据在字段中可用
+ `decline`：用户选择不提供所请求的信息，数据字段为 None
+ `cancel`：用户取消了整个操作，数据字段为 None

现在让我们看看如何处理客户端的引导。

启发式功能要求客户端实现启发式处理程序。如果客户端不支持启发式功能，则任何调用 `ctx.elicit()` 都会引发错误，提示启发式功能不受支持。
