## 我们构建 LLM 和相关的训练和推理技术：

+   [ChatGLM](https://github.com/THUDM/ChatGLM3)：开放双语聊天 LLM，其中 ChatGLM-6B 系列在 HF 上吸引了 10,000,000 次下载。

+   https://github.com/THUDM/ChatGLM3

+   [CodeGeeX](https://github.com/THUDM/CodeGeeX2)：多语言代码生成模型 （KDD 2023）

+   https://github.com/THUDM/ChatGLM3

+   CogVLM （VisualGLM）：一种开放的可视化语言模型

+   https://github.com/THUDM/ChatGLM3

+   [WebGLM](https://github.com/THUDM/WebGLM)：高效的 Web 增强问答系统 （KDD 2023）

+   https://github.com/THUDM/ChatGLM3

+   [GLM-130B](https://github.com/THUDM/GLM-130B)：开放双语预训练模型 （ICLR 2023）

+   https://github.com/THUDM/ChatGLM3

+   [CogView](https://github.com/THUDM/CogView)：开放的文本到图像生成模型 （NeurIPS 2021）

+   https://github.com/THUDM/ChatGLM3

+   [CogVideo](https://github.com/THUDM/CogVideo)：开放的文本到视频生成模型 （ICLR 2023）

+   https://github.com/THUDM/ChatGLM3

+   [CogAgent](https://github.com/THUDM/CogVLM)：用于 GUI 代理的可视化语言模型

+   https://github.com/THUDM/ChatGLM3

+   [AgentTuning](https://github.com/THUDM/AgentTuning)：为 LLM 启用通用代理功能

+   https://github.com/THUDM/ChatGLM3

+   [APAR](https://arxiv.org/abs/2401.06761)：LLM 可以进行自动并行自动回归解码

+   https://github.com/THUDM/ChatGLM3

## 我们还致力于LLM评估：

+   [AgentBench](https://github.com/THUDM/AgentBench)：评估 LLM 作为代理的基准 （ICLR 2024）

+   https://github.com/THUDM/ChatGLM3

+   [AlignBench](https://github.com/THUDM/AlignBench)：评估中国 LLM 一致性的基准

+   https://github.com/THUDM/ChatGLM3

+   [LongBench](https://github.com/THUDM/LongBench)：用于长上下文理解的双语、多任务基准测试

+   https://github.com/THUDM/LongBench

## 我们还预训练了图神经网络：

+   [CogDL：](https://github.com/THUDM/CogDL)图深度学习库 （WWW 2023）

+   https://github.com/THUDM/LongBench

+   [GraphMAE](https://github.com/THUDM/GraphMAE)[：（生成式）屏蔽](https://github.com/THUDM/GraphMAE2)图神经网络预训练。（KDD 2022 & WWW 2023)

+   https://github.com/THUDM/LongBench

+   [GPT-GNN](https://github.com/acbull/GPT-GNN)：生成图神经网络预训练（KDD 2020，MSR，加州大学洛杉矶分校）。

+   https://github.com/acbull/GPT-GNN

+   [GCC](https://github.com/THUDM/CogDL)：层图神经网络预训练 （KDD 2020）

+   https://github.com/acbull/GPT-GNN

+   [SelfKG：](https://github.com/THUDM/SelfKG)知识图谱的自我监督学习 （WWW 2022）

+   https://github.com/acbull/GPT-GNN

## 我们还研究图嵌入理论、算法和系统：

+   [SketchNE](https://github.com/THU-numbda/SketchNE)：在一小时内准确嵌入十亿规模的网络 （TKDE 2023）

+   https://github.com/acbull/GPT-GNN

+   [ProNE](https://github.com/THUDM/ProNE)：以 10-400 加速嵌入 1 亿个节点的网络 （IJCAI 2019）

+   https://github.com/acbull/GPT-GNN

+   [NetSMF](https://github.com/xptree/NetSMF)：嵌入 1 亿个节点的网络 （WWW 2019）

+   https://github.com/acbull/GPT-GNN

+   [NetMF：](https://github.com/xptree/NetMF)将 DeepWalk、LINE、PTE 和 node2vec 理解为矩阵分解 （WSDM 2018）

+   https://github.com/acbull/GPT-GNN
