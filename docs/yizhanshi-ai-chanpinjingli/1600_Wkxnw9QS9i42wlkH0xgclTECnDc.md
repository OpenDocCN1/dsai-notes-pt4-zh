# 我们需要的人**：**

## **心理学prompt编写工程师**

**为什么需要这个角色：**

虚拟伴侣无疑是一个非常新的产品类型，所以会诞生全新的岗位。 我们需要不断打磨和调教我们的人工智能模型来让他更好地给人们提供情绪价值，情感能量、关心、支持、陪伴。 我们也需要向各行各业来收集他们的经验。 所你的工作也包含对各行各业的专家进行访谈。 也包含用户焦点小组的访谈、田野调查。

虽然是工程师头衔，但你的工作并不会涉及到传统的代码编写。你需要经过不错的prompt训练和使用经验，熟练掌握大模型工具使用、对话。 懂得如何把自己的想法有效地表达给AI。

### 工作内容：

+   进行在线或者线下的用户访谈、田野调查。

+   召开举办用户焦点小组，跟我们的用户进行共创workshop。

+   配合工程团队，参与prompt的编写。

### 额外信息：

+   拥有人类学、心理学、社会学、传播学 专业背景的是加分项。

+   拥有心理咨询、Life Coaching教练、情感咨询、亲密关系咨询的从业经验是大大的加分项。

+   有GPTs、Coze、筑梦岛、捏崽经验是大大的加分项。

+   有乙女游戏、乙女同人二创、剧本杀编写创作经验是加分项。

## **Unity工程师**

**为什么需要这个角色：**

我们的产品在第一天就是全平台客户端，团队的核心成员都有1W小时的VR产品开发经验。我们是以VR 为主的开发路线。 所有交互、显示、渲染 都是优先考虑VR平台， 其次才是移动端的兼容。 所以unity工程师在团队中是非常骨干的力量。 也有非常多的砖要搬。

### 工作内容：

配合产品策划进行交互内容的开发，包括VR、移动端的交互接口，角色动画的驱动，物理引擎的设置，场景属性的设置，互动逻辑脚本的编写。

### 额外信息：

+   有过XR内容开发经验。至少有1款作品。

+   熟悉VR的基本交互框架、熟悉常见的VR互动交互范式、包括手柄、手势。

+   在UI/UX交互设计的细节表现，是大大的加分项。（UI反馈、动态效果）

+   提交简历时必须展示作品，可以是视频，但最好是可执行的游戏、应用文件或商城链接。

## Unity Technical Artists 技术美术

**为什么需要这个角色：**

做为虚拟伴侣产品，拥有美好的形象和华丽的场景体验是至关重要的。 好的渲染呈现比好的3D建模有时还要重要，作为最棒的虚拟伴侣产品，我们希望在视觉呈现上保持第一梯队，无论是人物的头发，睫毛、皮肤上的高光3S效果。 身体部位的物理效果和环境对其的影响。 还是场景的烘焙、光照、 法线贴图、AO贴图。 或者是各类景深、后处理的shader。 在这个团队中，你可以大展手脚。

### 工作内容：

+   对角色、场景的材质、shader进行改进。

+   对各个客户端的渲染效率进行优化。确保不同平台下的稳定和流畅运行。

+   改进动作捕捉的工作流、改进动画流程效率、并完成各类素材的导入、处理。

### 额外信息：

+   熟悉安卓、ios、quest等主流设备的渲染管线和shader支持度。

+   拥有灯光、打光、摄影技能点是加分项。

+   提交简历时必须展示作品，可以是视频，但最好是可执行的游戏、应用文件或商城链接。
