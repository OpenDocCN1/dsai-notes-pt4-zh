## 研究初心

这是为了能有更加形象的视觉合成方法。因为自然界是运动的，即使看似静止的场景也会因风、水流、呼吸或其他自然节奏而包含微妙的振荡。模拟这种运动在视觉内容合成中至关重要——人类对运动的敏感性会导致没有运动的图像看起来不真实。作者也在文章里和其他文生视频、文生图方法做了对比。主观评测之下，Generative Image Dynamics 方法生成的动图更具真实性。

## 研究方法

文章最开始的图片（如上图所示）很好的诠释了本文的方法。输入一张图片，对这张图片做傅立叶变换转换到频域，在不同的频率下通过`LDM`模型（对的，就是图像生成的那个`LDM`）获得图像的光谱。通过光谱在类似 `UNet` 的模型上生成了后续时间下的新图像。

频域分析的优势是，频域可以把不同的运动通过频域拆解开（比如频率低的运动就是一些缓慢的大范围的运动。频率高的运动就是一些快速范围小的运动），这样就可以对不同运动分别进行分析生成。类似的低频高频拆解的操作在神经辐射场里也有体现，神经辐射场把不同的输入用低频到高频的谐波进行位置编码，来获得更高频更细微的特征。

光谱分析的原因是，光谱能很好刻画运动模式。使用光谱，我们就能方便地在频域分析运动，并转换回时域生成新的图像。

作者并没有沿用之前视频生成的方法，包括像自回归生成视频帧和加入时间戳生成视频帧。这两种方法并不能保证生成视频帧的一致性。本文作者从自然界的运动开始分析，发现自然界的运动可以分解成不同频率周期的运动叠加。所以在频域中对自然运动进行建模分析。

作者把这种生成光谱的任务抽象成一个图像生成任务，通过 `LDM` 生成一个 `4K`（这里的 `K` 不代表分辨率）个通道、2D 运动状态的光谱图。这里 `K` 会远小于总时间戳，`K`代表要建模的频率数。“`4K`”代表每个频率，需要四个参数来表示 `x` 和 `y` 两个方向的傅立叶系数。光谱可表示如下:

经过一系列建模之后，也需要考虑一些实际的问题，比如，该如何选择合适的 `K` 呢？选择哪些频率可以很好的拟合运动信息呢？就如上文所说，对于自然界的运动。该选择动的快的，还是慢的？范围大的，还是小的？作者给出了一个答案。

大多数自然振荡运动主要由低频分量组成。为了验证这一观察，作者从 1,000 个随机采样的 5 秒真实视频中提取运动平均功率谱。下图所示，运动的功率谱随着频率的增加呈指数下降。这表明大多数自然振荡运动确实可以很好地用低频项来表示。在实践中，作者发现前 `K=16` 傅里叶系数足以逼真地再现真实视频和场景范围内的原始自然运动。

### 使用 `LDM` 模型进行光谱预测

运动预测模块

本文中的光谱预测阶段，模型使用一个 `VAE`（变分自编码器）作为编码器，把输入图像压缩到潜空间。然后不断去噪之后，通过解码器来得到一系列的光谱信息。此外，作者发现了运动的纹理会跨频率分布，但是在扩散模型的训练时，需要输出在 `[-1, 1]` 之间保证稳定训练。所以归一化是必不可少的，但如何归一化呢，简单的缩放会导致高频信息的损失。作者采用了一种频率自适应归一化来维持高频信息：

### 基于图像的渲染方法

在得到了光谱之后，还需要干什么呢？对的，之后就是需要把当前输入图片生成出下一帧。那如何从光谱生成纹理呢。咱们前面已经有公式建模了，现在只需要把公式倒过来就好了。也就是对光谱做傅立叶反变换。

![](img/ae0558edfc1b42ef8dc82363ed6c92d2.png)

具体来说，作者通过特征提取器网络对输入图像进行编码，以产生多尺度的特征图。对于每个单独的特征图，作者根据分辨率来调整和缩放预测2D运动纹理。作者假设大运动对应于移动前景对象，而小运动或零运动对应于移动背景。作者使用运动衍生的权重，因为观察到在单场景情况下，可学习的权重对于解决遮挡问题并不有效。

![](img/4a01790f91cf1e54c9b4725ef32615c3.png)

渲染模块

能从上图看出，这就是一个结合运动纹理的图像金字塔，融合运动纹理信息之后生成新运动位置的神经网络。

## 一些效果图和总结

![](img/f7952aa4d94bb48c9e2712356c7b9987.png)

不同方法生成的 `X-t` 视频切片

这是一张真实图片和视频切片的对比图，在作者的方法里。它能有和视频切片最近似的效果。但是作者提出的方法并不是没有局限性，在这些场景下得不到较好的结果：

+ 非振荡运动：可能无法有效建模非振荡运动。

+ 高频振动：可能无法准确捕捉高频振动。

+ 基础运动轨迹：生成视频的质量高度依赖于基础运动轨迹的质量。在以下场景中可能会出现质量下降：

+ 细小的移动物体。

+ 大位移的物体。

+ 未见过的新内容：需要生成大量未见过的新内容的运动也可能导致质量下降。

本文通过频率协作的潜在扩散模型来预测光谱体积，并通过图像渲染模块来生成未来的视频帧。作者展示了该方法能够从单张图片中生成逼真的动画，并显著超越了之前的基准方法，还可以实现无缝循环或图像交互等下游应用。是一篇很有实用意义的论文。
