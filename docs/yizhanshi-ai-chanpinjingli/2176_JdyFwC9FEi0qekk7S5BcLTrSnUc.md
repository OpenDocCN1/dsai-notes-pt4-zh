## DeepSeek-R1正式发布

1月21日，DeepSeek正式发布DeepSeek-R1模型，并同步开源模型权重。DeepSeek-R1遵循MIT License，允许用户通过蒸馏技术借助R1训练其他模型，同时上线API，对用户开放思维链输出。

性能方面，DeepSeek-R1在后训练阶段大规模使用强化学习技术，仅用极少标注数据就极大提升了模型推理能力，在数学、代码、自然语言推理等任务上，性能比肩OpenAI o1。此外，DeepSeek还开源了通过R1蒸馏出的6个小模型，其中32B和70B模型在多项能力上实现了对标OpenAI o1-mini的效果。

### 在技术方面，它有以下几个技术亮点

强化学习取代SFT：DeepSeek R1 Zero完全用强化学习取代了传统的SFT（微调）训练方法，通过自我反思和优化，模型性能稳步提升。例如，在AIME 2024上，DeepSeek-R1-Zero的平均`pass@1`得分从15.6%跃升至71.0%，达到与OpenAI-o1-0912相当的性能水平。

涌现时刻（Aha Moment）：在训练过程中，DeepSeek-R1-Zero展现了复杂行为的自发涌现，如反思和探索替代方法，这些行为并非通过明确编程实现，而是模型与强化学习环境交互的自然产物，显著增强了其推理能力。

蒸馏技术的应用：DeepSeek通过R1模型的输出，蒸馏出多个小模型，适配市面上对模型尺寸的主流需求。其中，32B和70B模型在多项能力上实现了对标OpenAI o1-mini的效果，展现了蒸馏技术在传递大模型推理模式方面的优势。

用户可通过登录DeepSeek官网或官方App，打开“深度思考”模式，调用DeepSeek-R1完成各类推理任务。同时，DeepSeek-R1的API调用价格也极其的便宜。DeepSeek-R1 API 服务定价为每百万输入 tokens 1 元（缓存命中）/ 4 元（缓存未命中），每百万输出 tokens 16 元。

## Kimi发布k1.5多模态思考模型

1月20日，月之暗面科技有限公司旗下的Kimi智能助手发布了全新k1.5多模态思考模型，并首次公开模型训练技术报告。k1.5模型是Kimi连续第三个月对k系列强化学习模型的重磅升级，实现了SOTA（state-of-the-art）级别的多模态推理和通用推理能力。

在short-CoT模式下，k1.5的数学、代码、视觉多模态和通用能力大幅超越全球短思考SOTA模型GPT-4o和Claude 3.5 Sonnet，领先达550%。在long-CoT模式下，k1.5的数学、代码、多模态推理能力达到长思考SOTA模型OpenAI o1正式版水平，这是OpenAI之外的公司首次实现o1正式版的多模态推理性能。

Kimi技术团队发布了详细技术报告，该报告记录了模型训练的关键要素，包括长上下文扩展、改进的策略优化、简洁的框架和多模态能力。报告还提出了有效的`long2short`方法，利用Long-CoT技术改进Short-CoT模型，在短链思维推理方面取得SOTA成绩，大幅超越现有短链思维模型。

k1.5多模态思考模型的预览版将陆续灰度上线Kimi.com网站和最新版本的Kimi智能助手app。

## 百川智能发布国内首个全场景深度思考模型

1月24日，百川智能发布了国内首个全场景深度思考模型Baichuan-M1-preview。该模型是国内目前唯一同时具备语言、视觉和搜索三大领域推理能力的模型。

在数学、代码等多个权威评测中，Baichuan-M1-preview的表现均超越了o1-preview；在视觉推理方面，其在MMMU-val、MathVista等权威评测中的成绩，超越了GPT-4o、Claude3.5 Sonnet、QVQ-72B-Preview等国内外头部模型。

此外，Baichuan-M1-preview作为国内唯一专注医疗领域的头部大模型公司推出的深度思考模型，解锁了医疗循证模式，实现了从医疗证据检索到深度推理的完整端到端服务，能够快速、精准地回答医疗临床、科研问题。

一同推出的还有行业首个开源医疗增强大模型Baichuan-M1-14B，其在cmexam、clinicalbench_hos、clinicalbench_hos、erke等权威医学知识和临床能力评测上的成绩超越了更大参数量的Qwen2.5-72B-Instruct，并且与o1-mini相差无几。

目前，Baichuan-M1-preview已在「百小应」中正式上线。

## Sam Altman 公布星门计划首期基地中心

1月24日，Sam Altman在个人社交账号公布了星门计划首期基地中心，首批10个数据中心的建设工作已在德克萨斯州启动。

据semianalysis报道，得州阿比林已获批875英亩土地用于星门计划，计划打造10个数据中心。未来4年，星门计划将在全美建设共20座超算中心。首批1000亿美元资金将用于构建AI基础设施，甲骨文将利用其数据中心技术和经验，与OpenAI、英伟达等公司合作，共同构建和运营AI计算系统。

OpenAI首席产品官Kevin Weil表示，数据中心是星门计划的核心基础设施，承载着用于模型训练和推理的GPU。他强调，必须确保在未来十年内拥有充足的算力储备，以开发能服务全球用户的产品。

## 微软开源AIOpsLab，助力构建AI Agent

1月25日，微软联合加州大学伯克利分校、伊利诺伊大学等研究人员开源了AIOpsLab，这是一个专用于云自动化运维的AI Agents项目。

AIOpsLab能够模拟真实云服务环境中的复杂操作任务，实现故障的自动化检测、定位和解决，同时具备高度的可观测性，能够收集和分析关键的遥测数据，确保对系统状态和应用环境的深入洞察。它还支持人类、数字和AI Agents的不同协作模式，并通过模块化设计易于扩展新应用程序、工作负载和故障场景。

AIOpsLab的架构包括五个关键部分：协调器、服务、工作负载生成器、故障生成器以及可观测性。协调器与智能体建立会话，共享基准测试问题信息，并提供API调用以帮助智能体解决问题。服务模块帮助AIOpsLab适应不同的真实云服务环境，工作负载生成器创建正常和故障场景的模拟，故障生成器提供细粒度的故障注入，可观测性则提升全面监控能力。

## MiniMax发布T2A-01语音模型，海螺语音全球上线

1月20日，MiniMax宣布推出全新升级的T2A-01系列语音模型，并全球同步上线海螺语音产品。

与传统语音生成技术相比，T2A-01系列语音模型具有音质稳定清晰、韵律自然、情绪精准表达、高准确度等特点，提供更快更稳的语音生成能力。此外，该模型支持包括中文、粤语、英语、日语、韩语、阿拉伯语、西班牙语在内的17种语言及上百种预置音色可选。

测试结果显示，海螺语音在中文的字错率和相似度方面表现最佳，英文的字错率、相似度与真实录音“Human”接近。在多语种真实场景评测中，海螺语音的相似度整体占优，综合能力媲美ElevenLabs，在中文、粤语、英语、日语、韩语和阿拉伯语等多个语种上，海螺语音的相似度和正确率大幅领先。

目前，海螺语音已向全球用户开放，T2A-01系列语音模型已上架海螺语音、海外版Hailuo Audio，以及国内外的API服务。

## Rivian自动驾驶计划曝光，目标直指特斯拉FSD

据electrek报道，美国造车新势力Rivian公布了其自动驾驶系统的发展计划，目标直指特斯拉的FSD功能。

Rivian计划在2025年推出“hands-free”辅助驾驶功能，使车辆能够在驾驶员不干预的情况下自主操控方向盘，实现自动驾驶。2026年，Rivian计划进一步升级至“eyes-free”功能，允许驾驶员在车辆行驶过程中将视线移开，车辆依然能够完成操控。

目前，Rivian旗下的皮卡已配备名为“Driver Plus”的高级驾驶辅助系统（ADAS），类似于特斯拉的标准Autopilot功能，可在高速公路上实现车道保持和自动加速或减速，但驾驶员仍需时刻注意路况。

2025年后，Rivian第二代车型将标配自主研发的自动驾驶平台，智驾芯片算力提升10倍，摄像头像素提升8倍，具备360度全景视野、盲点监测、高速辅助驾驶等功能，并预留车道变换、增强型高速辅助驾驶等功能的升级空间。
