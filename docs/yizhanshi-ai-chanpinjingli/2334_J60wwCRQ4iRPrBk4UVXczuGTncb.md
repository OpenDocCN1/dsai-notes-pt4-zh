> 🧚🏻‍♀️ 陶哲轩新论文“太反直觉”：再战Erdős问题，证明44年数学猜想是错的

>

+   陶哲轩最新研究在自然数倒数之和问题上取得突破，证明了一个反直觉的数学猜想：存在一个递增的自然数级数，使得对任意有理数t，级数和都是有理数。

+   该研究颠覆了数学家Kenneth Stolarsky提出的相反猜想，展示了数学中看似不可能的事情实际上可能是可能的。

+   陶哲轩采用了迭代逼近法解决无限维度问题，将问题转化为研究集合，并逐步解决，扩展了对Ahmes级数的研究。

+   这项工作与Erdős问题#263和#264相关，陶哲轩展示了新的变体结论，将问题推进到更高维度的变体。

+   Erdős问题#266的解决不是陶哲轩第一次解决Erdős相关问题，他之前也解决了埃尔德什差异问题，这些问题至今激励着数学家们。

> 关键词：数学猜想，陶哲轩，Erdős问题，迭代逼近法，自然数级数

> 🤖 马斯克的机器人徒手接个球，2000万网友集体围观

>

+   马斯克的Optimus机器人展示了其新升级的灵巧手，能够轻松接住被抛出的网球，显示出高度的灵活性和自由度。

+   该灵巧手的自由度翻倍，手部有22个自由度，手腕/前臂有3个，接近人类手部的27个自由度，使其在机器人领域中保持领先地位。

+   微软前战略顾问Robert Scoble认为，Optimus的远程操作工程是迄今为止他见过的最好的，预示着未来远程操作的可能性。

+   Optimus的灵巧手不仅提高了自由度，还在触觉传感集成、精细控制和减轻重量方面有所进展，预示着未来在制造新机器人方面的应用。

+   马斯克提到，通过Neuralink的植入物控制Optimus的手臂或腿，未来可能帮助失去手臂或腿的人获得“网络超级能力”，改变他们的生活。

> 关键词：Optimus，灵巧手，自由度，远程操作，Neuralink

> 🧠 科[研党狂喜！AI预测神经学研究结论](https://mp.weixin.qq.com/s/SLifYmYWYxs68OzKTCs-dQ)超过人类专家水平 | Nature子刊

>

+   伦敦大学学院等机构团队发布神经学基准BrainBench，LLM预测神经科学结果准确度高达81.4%，超过人类专家的63%。

+   LLM在神经学5个子领域中的表现均超越人类专家，特别是在行为认知和系统/回路领域。

+   较小模型如Llama2-7B和Mistral-7B与较大模型表现相当，而聊天或指令优化模型表现较差。

+   LLMs和人类专家的置信度校准良好，且LLMs未记忆训练数据，学习的是科学模式。

+   BrainBench作为前瞻性基准测试，专门评估LLM在预测神经科学结果方面的能力，为神经学科研工作提供新方向。

> 关键词：AI预测，神经学，LLM，基准测试，科研辅助

> 🧬 8[0G显存塞50个7B大模型！清华&Open](https://mp.weixin.qq.com/s/gCahIdvAt_6J6ttzn5GOkg)BMB开源增量压缩新算法，显存节省8倍

>

+   清华大学NLP实验室与OpenBMB开源社区联合提出Delta-CoMe技术，实现80G显存加载50个7B模型，节省显存8倍。

+   该技术利用主干模型与任务专用模型之间的参数增量进行压缩，降低存储和部署成本。

+   Delta-CoMe结合低秩分解和低比特量化技术，实现混合精度压缩，提升推理效率。

+   与BitDelta相比，Delta-CoMe在复杂任务如数学推理和代码生成上表现更优。

+   实验表明，Delta-CoMe在多任务处理和模型部署上具有显著优势，推理速度提升近3倍。

> 关键词：AI算法，模型压缩，NLP，多任务处理，推理效率

> 6️⃣

> 🤖 一[次示范让Agent适应各种新环境](https://mp.weixin.qq.com/s/_V93FTuePItGwdlO25T7aQ)，浙大杭电智能体框架入选NeurIPS

>

+   杭州电子科技大学和浙江大学的研究者提出了AutoManual智能体框架，通过模仿人类“记笔记”的过程，使智能体在新环境中的执行任务成功率高达97%。

+   AutoManual框架减少了智能体对人类专家知识的依赖，通过自我学习适应新环境，并将学习经验以Markdown格式的手册形式呈现。

+   该框架在机器人规划环境ALFWorld和网站导航环境MiniWoB++上展现了出色的性能，分别达到了97%和98%的成功率。

+   AutoManual框架由Building、Formulating和Testing三个阶段组成，有效整合了规则管理和文本化的知识传递。

+   该研究为智能体的自主适应性和跨环境应用提供了新的方法，同时生成的手册也易于人类理解和其他智能体使用。

> 关键词：智能体框架，环境适应性，知识传递，AutoManual，NeurIPS
