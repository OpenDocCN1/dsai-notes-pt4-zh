> 2️⃣

> 🧚🏻‍♀️ YO[PO (You Only Prune Once)](https://mp.weixin.qq.com/s/49AMlkykx-rL82vojPPBUA)：大幅缩减多模态大模型计算量至12%

>

+   本文介绍了YOPO技术，通过剪枝策略将多模态大模型计算量压缩至12%，保持与原始模型同等性能。

+   研究以LLaVA为实验对象，提出了邻域感知的视觉注意力、非活跃注意力头剪枝等策略，显著降低计算开销。

+   实验结果表明，剪枝模型在多模态任务中保持性能，同时大幅减少计算资源消耗。

+   该方法在Qwen2-VL和InternVL2.0上验证了普适性，为多模态大模型的高效计算提供了新视角。

+   文章还探讨了视觉token与文本token的不平衡问题，以及现有优化策略的局限性。

> 关键词：多模态大模型，剪枝策略，计算效率，视觉token，参数优化

> 5️⃣

> 🧚🏻‍♀️ 微软：两个AI相互纠错，数学再涨5分

>

+   加州大学和微软研究院提出Flow-DPO，通过在线学习流和直接偏好优化提升LLM数学能力。

+   Flow-DPO让LLM生成更详细精确的推理轨迹，同时挖掘数据深层信息，避免人类标注数据不准确的问题。

+   在解决数学问题时，Flow-DPO生成的推理过程详细指导，避免不必要复杂性，增强可读性和理解性。

+   Flow-DPO通过增量输出生成Flow和在线Flow学习与回滚增强推理能力，显著提高LLM数学推理能力。

+   实验显示，使用Flow-DPO后，Llama3模型和Phi3在数学推理上的能力大幅提升。

> 关键词：AI，LLM，数学推理，Flow-DPO，在线学习

> 6️⃣

> 🧬🎊 图结构转文本序列，大模型直接读懂！图推理性能大涨

>

+   新方法允许大语言模型直接理解复杂图结构，通过将图转换为线性token序列来实现。

+   图线性化方法保留局部依赖性和全局对齐性，提高图推理任务的性能。

+   机器学习工程师Rohan Paul推荐的论文总结了多种图线性化技术，包括图中心性和图退化性方法。

+   实验表明，基于度中心性和PageRank的方法在多个任务中表现突出。

+   节点重标记策略有助于全局对齐，但效果因任务而异，one-shot设置下性能普遍低于zero-shot。

> 关键词：图结构转文本序列，大模型，图推理，图线性化，全局对齐性
