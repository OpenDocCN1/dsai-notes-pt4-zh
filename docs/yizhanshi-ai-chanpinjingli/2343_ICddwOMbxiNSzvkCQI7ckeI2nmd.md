> [位置编码背后的理论解释——傅里叶特征 (](https://mp.weixin.qq.com/s/RN4uuAedbSQg-P6xuYwuZg)Fourier Feature）与核回归

>

+   本文探讨了位置编码背后的理论基础，尤其是傅里叶特征（Fourier Feature）与核回归（Kernel Regression）的联系，并解释了如何通过这些理论增强神经网络对高频信息的学习能力。

+   作者基于论文《Fourier Features Let Networks Learn High Frequency Functions in Low Dimensional Domains》介绍了傅里叶特征，并稍微讲解了NTK等理论概念。

+   文章通过MLP拟合连续图像实验，展示了位置编码（一种特殊的傅里叶特征）如何帮助MLP更好地拟合数据的高频信息。

+   核回归和NTK理论被用来分析MLP的学习规律，揭示了MLP难以拟合高频信息的原因，并提出了通过调整傅里叶特征参数来调整MLP学习高频信息的能力。

+   傅里叶特征的应用不仅限于NeRF这类过拟合连续数据任务，它还在StyleGAN3中得到了应用，展现了其在频域图像信号处理中的潜力。

> 关键词：傅里叶特征，核回归，NTK，位置编码，神经网络
