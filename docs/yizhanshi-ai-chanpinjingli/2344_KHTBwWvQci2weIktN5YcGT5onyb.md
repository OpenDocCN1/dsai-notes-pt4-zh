微软、上海交通等发布首届数据污染报告，开闭源模型皆被污染

+   首届数据污染报告指出，自然语言处理中的评估数据被无意中包含在预训练数据集中，影响模型评估结果。

+   报告由麻省理工、上海交通、哈佛大学等20多家机构联合发布，共包含42个受污染的源、91个数据集和566个污染条目。

+   数据污染问题在文本评分、问答和多项选择问答等任务类型中最为严重，知名数据集MMLU、GLUE和ai2_arc也存在污染。

+   大多数污染证据针对闭源模型，如GPT-3和GLaM，开源模型如FLAN和Mistral也受到一定程度的污染。

+   最新发布的模型更易受到最近发布的数据集污染，如GPT-4主要受2018至2022年数据集的污染。

关键词：数据污染，自然语言处理，模型评估，闭源模型，开源模型

[贾佳亚、徐立研究工作获 SIGGRAPH Asia ](https://mp.weixin.qq.com/s/L5AMEjKCfnS6xVgfrzBSXQ)2024 时间检验奖 丨 AI 顶会直击

+   SIGGRAPH Asia 2024在日本东京举办，贾佳亚和徐立的研究工作获得时间检验奖。

+   贾佳亚团队的《TEXGen: a Generative Diffusion Model for Mesh Textures》论文，提出了一种新的3D纹理测试方法，不依赖于预先训练的2D扩散模型。

+   徐立作为一作的论文《Structure extraction from texture via relative total variation》提出了一种新模型，有效分解图像中的结构信息和纹理。

+   会议论文提交数量呈直线上升，共收到900篇论文，接受率达29.4%。

+   获奖论文中，有华人参与的论文共4篇，展现了华人在AI领域的研究实力。

关键词：SIGGRAPH Asia，AI研究，纹理测试，图像分解，华人学者

[深度 | DeepMind高级研究总](https://mp.weixin.qq.com/s/1n6a7w5OkqXKN4PYxeaWDA)监专访：AI是否能够实现真正的艺术创作？

+   🧬 AI生成的艺术作品引发关于原创性、版权和艺术家角色的讨论。

[今](https://mp.weixin.qq.com/s/og4utg6Jf6oW46bgESMT1g)日开源（2024-12-02）：INTELLECT-1，首个以去中心化形式训练得到的10B大模型，1万亿token数据训练

+   INTELLECT-1是全球首个去中心化社区协作训练的10B参数语言模型，使用1万亿英语文本和代码token进行训练。

+   GLM-Edge是由清华大学团队开发的对话生成模型，基于Transformer架构，专注于中文对话生成。

+   minRLHF是一个最小化的RLHF实现，提供了一个小型、清晰、可解释的GPT实现，用于教育和展示语言模型训练和推理。

+   GitDigest是一个Web界面，将GitHub代码库转换为LLM提示的文本摘要，提供智能格式化和统计数据。

+   Report项目提供了一种替代Jupyter Notebook的方法，通过生成Python文件进行数据分析和可视化，输出静态HTML页面。

关键词：去中心化，10B参数模型，对话生成，LLM提示，数据分析
