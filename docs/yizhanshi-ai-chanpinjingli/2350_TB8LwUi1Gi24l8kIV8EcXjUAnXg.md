>

+   浙江大学与阿里巴巴联合提出科研Ideas自动生成工具SciPIP，利用AI大模型为科研提供新思路。

+   SciPIP将科研创意生成分为文献阅读和新创意提出两个步骤，通过自动化解析提取文献核心结构部分。

+   实验结果显示，SciPIP能够生成与人类思维高度一致的创新性想法，具有潜在的科研价值。

> 关键词：AI，科研创意，SciPIP，文献检索，大模型

> EMNLP 2024 | 大模型对齐中的低冗余优化

>

+   介绍了ALLO方法，一种新的大语言模型对齐技术，通过优化最相关的神经元减少训练冗余。

+   ALLO通过“遗忘”和“学习”两阶段训练，显著提升了对齐性能，最大提升9.7%。

+   在问答、数学推理和指令跟随任务中，ALLO展现了优于现有方法的性能。

+   ALLO首先识别关键神经元，然后通过梯度变化和词元级监督信号优化这些神经元。

+   未来研究将探索ALLO在降低大模型生成内容中的幻象以及在更大参数量模型中的应用。

> 关键词：大模型对齐，低冗余优化，ALLO，神经网络，对齐训练

> [千问LLM：什么是Pre-LayerNor](https://mp.weixin.qq.com/s/4V6DiOGgx92VmG4z5zlfrg)m 和 Post-LayerNorm ？

>

+   Layer Normalization（层归一化）是深度学习中用于标准化输入以加速训练并提高模型稳定性的技术。

+   Pre-LayerNorm将归一化放在子层（如注意力或前馈网络）之前，有助于梯度稳定和加速训练。

+   Post-LayerNorm将归一化放在子层之后，与传统Transformer架构一致，适用于层数较少的模型。

+   Transformer论文采用的是Post-LayerNorm，而GPT系列通常选择Pre-LayerNorm。

+   提供了TransformerBlock的PyTorch实现代码，展示了Pre-LayerNorm和Post-LayerNorm的具体应用。

> 关键词：Layer Normalization，Pre-LayerNorm，Post-LayerNorm，Transformer，PyTorch
