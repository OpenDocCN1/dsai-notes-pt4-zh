无人机：不是我想长腿，《Nature》论文说这样更省力

+   EPFL的Won Dong Shin博士生研究鸟类跳跃起飞的机制，并将其应用于固定翼无人机设计。

+   其开发的RAVEN无人机采用仿生鸟腿设计，能像乌鸦一样跳跃起飞，并在地面上灵活移动。

+   与传统固定翼无人机相比，RAVEN的跳跃起飞能量效率高出约10倍，且能更节能地在地面移动。

+   研究团队正在开发视觉系统和折叠翼技术，以提升RAVEN的避障和降落能力。

+   Shin希望将腿部设计应用于更大型无人机，但需解决大型鸟类无法跳跃起飞的问题。

关键词：无人机，仿生学，跳跃起飞，能量效率，腿部设计

[KDD2025 | 多标签节点分类场景下](https://mp.weixin.qq.com/s/I7RA6dBGAJaUrK_p_gBbyA)，阿里安全&浙大对图神经网络增强发起挑战

+   阿里安全与浙江大学合作，针对多标签节点分类场景提出了图神经网络增强技术CorGCN，被KDD 2025收录。

+   CorGCN通过学习与多标签相关的节点特征，分解为多个标签感知特征，并在标签感知图上进行关联增强的图卷积。

+   该研究分析了多标签分类场景下GNNs面临的特征和拓扑结构模糊性问题，并提出了解决方案。

+   实验表明，CorGCN在多个数据集上验证了其有效性，并在阿里风控场景中具有业务潜力。

+   论文还探讨了CorGCN扩展到庞大标签空间的方法，以实现高效学习。

关键词：图神经网络，多标签分类，特征分解，拓扑结构，风控

[速递｜AI视频独角兽Runway预](https://mp.weixin.qq.com/s/XJpFSYVMVVG9JuzO2c2O4Q)计到明年年底ARR将3倍增长，约3亿美元

+   Runway，一家专注于AI视频生成和编辑的公司，预计其年化收入（ARR）将从6月份的2800万美元增长至8400万美元，并有望在明年年底达到2.65亿美元。

+   公司提供分级订阅服务，最高可达每月76美元，以获取图像和视频生成积分，并为商业客户提供定制功能和增强安全性。

+   Runway面临着来自Pika、Genmo、Luma AI等新兴企业和OpenAI的竞争，后者推出了视频生成模型Sora。

+   与Perplexity等大型AI初创公司相比，Runway预计明年的增长速度将更快，预计年化收入将达到1.27亿美元。

+   Runway在6月的谈判中筹集了4.5亿美元，估值约为40亿美元，年化收入计算基于上个月的收入乘以12。

关键词：AI视频，收入增长，Runway，竞争，年化收入
