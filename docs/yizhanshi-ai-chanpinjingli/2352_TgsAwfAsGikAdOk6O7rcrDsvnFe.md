中美科技合作协定续签，AI半导体合作排除

+   《中美科技合作协定》续签，但排除了AI和半导体等关键技术。

+   新协定只包含基础研究合作，不涉及关键和新兴技术。

+   协定未包含中美高校和私营企业间的合作内容。

+   协定规定了数据共享和开放透明的合作方式，并设立争议解决机制。

+   协定续签过程中存在不确定性，未来合作领域和特朗普政府态度成关键。

关键词：中美科技合作，AI排除，半导体，基础研究，合作协定

[Ilya Sutskever最新论](https://mp.weixin.qq.com/s/26Vt8u_ZyY9uR_g_in8khw)断：预训练时代将终结，新方向将会是...

+   Ilya Sutskever认为大语言模型(LMMs)在预训练阶段的规模扩展已达到瓶颈，未来将转向构建基于现有模型的AI代理和工具。

+   Sutskever将AI发展类比人类大脑，强调在硬件规模增长达到极限后，重点将转向应用生态的创新。

+   他预测2025年将成为AI Agent的元年，AI Agent将在编程、内容创作等领域发挥重要作用，推动AI领域向前发展。

+   Agent的爆发已成为业内共识，随着端侧和多模态LLM技术的突破性进展，AI领域将进入新的发展阶段。

+   AI领域将从规模扩张转向应用生态创新，AI Agent将成为新的发展方向。

关键词：AI Agent，大语言模型，AI发展，预训练时代，应用生态创新

[16种新型RAG最新进展](https://mp.weixin.qq.com/s/BPP7UfP7jF_mWOyuvbYvTg)

+   RAG技术在特定领域如医疗、金融等优化，展现专业化趋势🍒。

+   多模态数据融合、安全性考虑、效率优化和可解释性提升成为RAG技术发展的关键方向🚀。

+   基础架构创新如AutoRAG和CORAG提升了RAG系统的自主判断和文本块处理能力🏺。

+   FastRAG、AssistantRAG和MemoryRAG等通过不同策略优化了大模型的上下文长度限制问题📚。

+   RAG技术在垂直领域如医疗、材料科学和金融展现出强大的应用潜力和创新解决方案🏥。

关键词：RAG，专业化，多模态融合，效率优化，垂直领域应用
