[图像领域再次与LLM一拍即合！idea撞车Ope](https://mp.weixin.qq.com/s/k7rfJI8gzzgec_dXqTIVyg)nAI强化微调，西湖大学发布图像链CoT

+   🌏西湖大学MAPLE实验室提出通过强化学习优化图像生成模型的去噪过程，减少推理步骤，提高图像质量。

+   🏄🏻 OpenAI推出强化微调（ReFT），使模型能进行多步推理，输出符合人类偏好的结果。

+   🏹齐国君教授领导的MAPLE实验室发现图像生成领域的扩散模型和流模型存在类似的多步去噪过程，类似图像链CoT。

+   🏂强化学习微调方法可优化多步去噪的图像生成过程，自适应调整推理过程中噪声强度，用更少步数生成高质量图像内容。

+   🎲MAPLE实验室引入时间预测模块（TPM），动态优化扩散模型时间，减少推理步数，提高图像生成质量。

精度提升20%，中科院、南京理工AI方法进行光电子能谱高维数据精细解析

+   中国科学院高能物理研究所与南京理工大学合作，开发了多阶段无监督聚类算法(MSCA)，提升了光电子能谱数据聚类精度约20%。📈

+   MSCA算法通过自动提取能带在表面的一致性，清晰划分MoS2/BN异质结构中不同衬底或层数MoS2的分布，并抓取细微能带差异。🔍

+   该研究发表于《Communications Physics》，展示了MSCA在实空间和动量空间的聚类分析能力，显著提高了聚类的准确性和识别限度。📚

+   MSCA相较于K-means算法，在Macro Accuracy、Precision、Recall和F1 Score等指标上均有提升，展现了更平衡的性能。🏆

+   MSCA未来将集成到HEPS的Nano-ARPES数据采集系统，实现在线精细聚类和能带结构提取，加速科研成果产出。🚀

关键词：AI算法，光电子能谱，多阶段聚类，数据解析，高维数据分析
