[AAAI 2025 | 开放世界的深伪检测](https://mp.weixin.qq.com/s/-ir30rJ97_ZAl_GxyEQA4w)，北交大团队：解决好无配对数据挑战很重要

+   北京交通大学团队与苏黎世联邦理工学院合作，在AAAI 2025上发表研究，提出非配对数据下的开放世界深伪检测方法。

+   该方法旨在解决社交媒体等开放网络环境中的深伪检测问题，这些环境中图像通常经过多种压缩处理，使得识别变得困难。

+   研究提出了ODDN模型，包含开放世界数据聚合（ODA）和压缩丢失梯度校正（CGC）两个核心组件，有效降低配对数据稀缺和压缩影响的性能损失。

+   实验表明，所提方法在17个流行数据集上表现出色，具有稳健性和适应性，为在线社交平台上的伪造信息打击提供了新基准。

+   该研究推动了深度伪造检测领域的发展，为未来相关研究提供了方向。

关键词：深度伪造检测，开放世界，无配对数据，社交媒体，AI研究

Ilya宣判后GPT-5被曝屡训屡败，一次训数月，数据要人工从头构建

+   GPT-5训练遭遇挑战，两轮训练均未能达到预期效果，每次训练需数月且成本高达5亿美元。

+   OpenAI为GPT-5专门雇佣人员从头构建数据，包括代码编写和数学题解答，以满足预训练需求。

+   GPT-5的智能水平被期望达到博士生水平，但在实际训练中提升不明显，与成本相比性价比低。

+   OpenAI的o3系列在ARC-AGI测试中刷新成绩，显示了推理Scaling Law的潜力，但AGI的实现仍有距离。

+   o3通过LLM在token空间内搜索和执行，实现测试时的知识重组，为AGI提供了新范式。

PK OpenAI o1，国产模型在高难度数学和算法竞赛的能力几何？

+   国产AI模型在数学和算法竞赛中与OpenAI o1系列模型展开竞争，显示出显著的进步和潜力。

+   AGI-Eval组织的评测活动揭示了国产模型如DeepSeek-R1-Lite在特定任务上超越o1-preview模型的能力。

+   面对长链路推理，国产模型如DeepSeek-R1-Lite存在陷入死循环的风险，需要进一步优化。

谷歌，暗搓搓发了一个「游戏版 sora」

+   Google DeepMind 发布了 Genie 2，一个基础世界模型，能够根据图像或文字描述生成 3D 场景，具有复杂的交互功能。

+   Genie 2 能够模拟物体交互、动画、逼真的光照和物理反射效果，以及 NPC 行为，场景画质接近 3A 级别游戏。

+   该技术可以用于训练通用具身代理，提供多样化的训练环境，推动 AI 系统的发展。

+   Genie 2 为游戏开发提供新的可能性，允许快速创建独特、可玩的体验，减少设计流程的时间和成本。

+   3D AI 技术预示着更广阔的应用前景，可能掀起一场规模更大的技术革命，影响机器人技术、自动驾驶汽车、虚拟现实等领域。
