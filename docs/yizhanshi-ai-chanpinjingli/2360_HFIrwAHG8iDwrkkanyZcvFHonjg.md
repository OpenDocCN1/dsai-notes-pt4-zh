图学习新突破：一个统一框架连接空域和频域

+   密西西比州立大学、北伊利诺伊大学和埃默里大学的学者提出了一个新的图学习框架，将空域和频域图模型统一起来。

+   该框架通过结合图的空间连接性和节点特征，更精准地捕捉图数据的复杂性。

+   图卷积可以通过谱图理论来理解，包括图傅里叶变换和卷积定理。

+   研究展示了空域和频域方法在谱聚类和Word2Vec算法中的应用。

+   未来研究方向包括提高计算效率、扩展统一谱论的应用以及将框架应用于更多实际问题。

关键词：图神经网络，图学习，空域，频域，统一框架

李飞飞谢赛宁：多模态LLM「空间大脑」觉醒，惊现世界模型雏形！

+   李飞飞和谢赛宁团队发现多模态LLM展现出空间记忆和推理能力，局部世界模型和空间意识的迹象。🌐

+   研究指出空间推理是MLLM的主要瓶颈，特别是在理解距离、大小和方向等方面。📏

+   通过视频输入和语言提示，MLLM在视觉空间智能任务上表现出竞争力，但仍低于人类水平。🚀

+   研究还发现，语言提示技术在视觉空间任务中效果不佳，有时甚至产生负面影响。🗣️

+   MLLM在构建空间模型时倾向于生成局部化的世界模型，而非统一的全局模型。🧩

关键词：多模态LLM，空间智能，视觉空间任务，局部世界模型，AI助手

第一批 AI 员工，即将入职电商公司

+   有赞CEO白鸦在12周年发布会上提出，AI技术将帮助商家在📕等平台完成种草文案撰写和发布，以及在🛰️小店完成库存调整、客服问询等自动化流程，从而减少运营成本。

+   有赞通过AI技术提升客服效率，70%的客服问题得到解决，同时在产品和研发上也实现了效率提升。

+   白鸦认为，SaaS的未来在于直接交付结果，而非仅仅提供工具，AI使软件成为数字员工，直接竞争人力预算。

+   有赞推出的智能体方案旨在全托管商家的AI工作流，商家无需管理，直至产生营业额后分成收入。

+   有赞CEO白鸦和COO浣昉接受采访，讨论了SaaS+AI的实践和行业变化，强调AI在提升效率和商业价值中的作用。

关键词：AI员工，自动化，SaaS，效率提升，数字员工
