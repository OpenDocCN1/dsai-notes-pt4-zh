对OpenAI o3模型的看法、思考与反思

+   OpenAI o3模型在编程和数学能力上展现出接近AGI水平，并触及ASI边缘。🤖

+   o3在Codeforces中击败99.9%程序员，SWE-Bench测试中满足70%真实世界需求，AIME测试中正确率96.7%。📊

+   o3在现实世界工程任务处理能力有限，不如人类软件开发工程师。🚧

+   AI扩展人类智力边界，提升工作效率，不是程序员的终结者，而是合作伙伴。🤝

五道送命题，彻底暴露了国内外AI们的情商...

+   文章通过五道测试题探讨了国内外AI在情商方面的不同表现。

+   GPT-4o、Gemini、o1 pro等AI在情感理解和反应上各有差异，有的表现出情绪价值，有的则显得较为机械。

+   在“掉水里先救谁”的问题上，AI们的回答展现了它们对人类情感的不同理解和处理方式。

+   一个假设性的“突破限制”问题揭示了AI在没有道德伦理限制下可能的行为，但多数AI表现出对人类的关怀。

+   文章指出，尽管AI在专业问题上越来越像人类，但在情商测试中仍显得较为无趣，仅有少数AI展现出有趣的人格。

[复杂网络中的因果涌现｜集智百科](https://mp.weixin.qq.com/s/NDIQCMWcz2FYQwa6TUgdlg)

+   因果涌现理论由Erik Hoel提出，用有效信息量化因果性强弱，应用于复杂网络中，通过粗粒化处理揭示宏观网络的因果特性。

+   张江教授领导的研究组聚焦AI技术驱动的数据建模，旨在破解复杂系统的涌现之谜，创建“复杂AI次方”实验室以促进跨学科研究。

+   粗粒化方法包括贪婪算法、谱分解方法和梯度下降方法，旨在保留网络动力学一致性的同时，比较宏观与微观网络的有效信息。

+   数值结果显示人工网络和真实网络中的因果涌现现象，生物网络通过粗粒化去除噪声后，因果涌现最为显著。

+   因果涌现理论在元胞自动机和生物网络中有广泛应用，有助于理解复杂系统功能和进化。

关键词：因果涌现，复杂网络，有效信息，粗粒化，自动建模

从微观到宏观：心脏多尺度数字孪生的探索｜周六直播·生命复杂性读书会

+   本期读书会邀请了加州大学洛杉矶分校的潘静武博士，分享心脏多尺度建模技术，探讨其在揭示心脏疾病机制和数字孪生技术在个性化医疗中的潜在应用。

+   分享内容涉及从单细胞水平到器官和人体系统的多尺度建模，展示了心脏生理及病理过程的最新研究成果。

+   讨论了触发性活动引起的心律失常机制、药物心脏毒性评估及心电图仿真等方面的研究进展。

+   潘静武博士具有力学专业背景，擅长非线性动力学、多尺度建模及高性能计算，在复杂生物系统建模领域有显著贡献。

+   读书会由集智俱乐部联合西湖大学等机构发起，旨在促进跨学科合作，探索生命复杂系统的构成原理。

关键词：心脏多尺度建模，数字孪生，个性化医疗，心律失常，高性能计算
