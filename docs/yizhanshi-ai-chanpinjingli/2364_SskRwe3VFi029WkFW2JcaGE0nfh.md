直播预告 | 复旦大学知识工厂实验室：基于解码的语言模型水印研究

+   本次直播由复旦大学知识工厂实验室硕士生符嘉义主讲，探讨大语言模型水印技术，特别是基于红绿词表的算法。

+   符嘉义的研究兴趣集中在大语言模型的对齐技术和reward hacking现象，其工作已发表在ACL。

脑机接口和 AI，一个硬币的两面

+   AI的关键技术突破与脑科学理论紧密相关，例如神经网络和图像识别技术。

+   脑机接口（BCI）作为跨学科领域，涉及电极材料、芯片封装等，与AI技术发展速度的差异主要在于伦理限制。

+   脑虎科技与Neuralink竞争，缩小技术差距，展示BCI技术在运动恢复、语言接口和视觉恢复方面的应用。

+   脑机接口的未来展望包括运动恢复、语言接口、视觉恢复和记忆假体等，预示着硅基与碳基生命的融合。

+   预计到2035至2045年间，硅基生命和碳基生命的融合将会发生，推动技术和社会的深刻变革。

关键词：脑机接口，AI，神经科学，伦理，硅基生命

突发！ChatGPT、Sora、API发生重大错误，宕机数小时

+   OpenAI的ChatGPT、Sora和API在今天凌晨5点发生了重大错误，导致服务宕机数小时。

+   问题已经被定位并开始恢复，但这一事件让Sam Altman尴尬，因为他刚宣布无限使用Sora的圣诞奖励。

+   12月以来，OpenAI的API和产品一直不稳定，包括Sora开放日的宕机和多种问题。

+   本月重要错误包括API客户遇到无效JSON输出、视觉API错误率升高、微调API错误率增高、ChatGPT性能下降等。

+   用户对频繁的宕机和错误感到沮丧，但也赞赏OpenAI的人性化处理方式和直接承担责任的态度。
