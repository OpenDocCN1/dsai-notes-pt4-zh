一道题烧几千美元，OpenAI新模型o3：这34道题我真不会

+   OpenAI推出了新的推理系列模型o3和o3-mini，这是首个突破ARC-AGI基准的AI模型，性能可达75.7%至87.5%。

+   o3模型展现了人工智能适应新任务的能力，与之前的LLM相比，能力有了质的转变。

+   o3在一些任务中表现出一维推理的局限性，对于二维物体的识别和空间思维能力存在挑战。

+   测试样本比训练样本大得多，o3在某些情况下似乎直接放弃了尝试，表现难以解释。

空间推理成大厂竞逐焦点，为什么让大模型理解「内外远近」更重要？

+   空间推理能力是多模态大语言模型（MLLMs）性能提升的主要瓶颈，与人类相比存在显著差距。

+   空间推理指理解和推理物体间的空间关系、运动和相互作用的能力，对增强现实、机器人等领域至关重要。

+   空间推理是实现空间智能的核心，模型需具备对空间信息的真正理解，区分简单的空间概念如「内」和「外」。

+   李飞飞的「World Lab」和谷歌等大厂正推进空间推理技术研究，探究不同角度和方法增强模型的空间推理能力。

+   业内对空间智能、空间推理的探索、进展颇多，如「使用单图生成 3D 世界」项目和将空间推理能力应用于机器人领域。

关键词：空间推理，多模态大模型，视觉空间智能，人工智能，大厂竞逐

低精度量化对未充分训练的LLM影响较小

+   腾讯AI Lab研究显示，低比特量化在未充分训练的大型语言模型（LLM）中性能与fp16/bf16相当，但在充分训练的模型中性能差距扩大。

+   研究量化了1500多个不同大小和训练程度的开源LLM检查点，建模量化导致的性能退化（QiD）。

+   提出一套低比特量化的scaling laws，可预测不同规模模型在100万亿tokens训练量时的量化损失。

+   发现模型越大、训练数据越多、量化精度越高，QiD越小。

+   研究表明，低比特量化可作为衡量LLM是否充分训练的指标，未来低比特量化的应用前景不明朗。

关键词：低比特量化，LLM，性能退化，scaling laws，模型训练
