> 老婆饼里没有老婆，RLHF里也没有真正的RL

>

+   RLHF（基于人类反馈的强化学习）并不为大型语言模型（LLM）带来真正的强化学习（RL），因为它们缺少持续的环境交互和长期目标的追求。

+   RLHF主要通过单步或几步优化调整模型输出，而不是在动态环境中进行多步骤策略调整，且通常是离线或半离线进行的。

+   尽管RLHF可以改善模型的对齐性和输出质量，但它并不能赋予LLM真正的目标或意图，LLM仍然主要是一个基于上下文预测下一个token的统计系统。

+   文章讨论了RLHF与经典RL的区别、为何RLHF无法给出LLM真实目标或意图、以及没有“目标驱动”的LLM的后果。

+   区分RLHF和经典强化学习，RLHF更接近于逆强化学习（IRL），侧重于人类对最终或短序列输出的静态判断。

> 关键词：RLHF，LLM，强化学习，人工智能，动态环境

>

+   RAG（Retrieval-Augmented Generation）技术在构建大模型原型和产品化中的重要性和挑战。

+   介绍了17种技术，包括数据分块优化、提高数据质量、选择合适的嵌入模型等，以优化RAG技术方案。

+   RAG系统的评估涉及检索器和生成器的性能，使用大模型作为评估工具，以及持续从应用和用户收集数据的重要性。

> Search-o1：赋予推理模型主动搜索的能力

>

+   Search-o1是一个新型框架，它集成了自主检索增强生成（RAG）机制和文档内推理模块，以增强大型推理模型（LRMs）的能力。

+   该框架允许LRMs在推理过程中自主检索和整合外部知识，弥补知识不足，提高推理的连贯性和准确性。

+   实验结果表明，Search-o1在科学、数学、编程等复杂推理任务上取得了比现有方法更好的性能。

+   Search-o1显示出在知识整合和推理连贯性方面的优势，尤其在多跳问答任务中超越了所有基线方法。

+   该框架的成功为开发更可靠和能够利用更多工具的慢思考系统奠定了基础。

> 关键词：AI，RAG，LRMs，知识检索，推理连贯性

> 增强大模型的推理能力：从思维链到连续思维链（中）

>

+   大模型推理基于自回归机制，通过调整参数增加输出多样性，生成多样化的思维链。

+   Wang等人（2022）提出通过多数答案一致性提高大模型准确率的方法。

+   Zelikman等人（2022）提出STaR方法，通过迭代微调训练提升大模型推理能力。

+   Shinn等人(2023)提出Reflexion框架，使大模型能够自我反思，从错误中学习。

+   Yao等人(2023)提出“思维树”框架，以树状结构组织解决问题策略，超越传统链式推理。

> 关键词：大模型，推理能力，思维链，自我反思，思维树
