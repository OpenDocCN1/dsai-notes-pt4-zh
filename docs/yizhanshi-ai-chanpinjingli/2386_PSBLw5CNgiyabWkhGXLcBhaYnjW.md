> 多模态&LLM Reyes：一个从0到1开始训练的多模态大模型

>

+   Reyes（睿视）是一个8B参数的多模态大模型，由视觉编码器InternViT-300M-448px-V2_5和语言模型Qwen2.5-7B-Instruct组成。🌏

+   Reyes通过两层MLP投影层连接视觉编码器与语言模型，实现了更小参数量下的性能超越，得分0.447，高于llava1.5-13B的0.367分。🎯

+   Reyes模型的架构和代码已开源，提供了详细的模型实现和数据处理流程。🛠️

+   在MMMU评测中，Reyes展现了在多学科任务中的表现，包括艺术与设计、商业等多个领域，得分高于llava1.5-13B。🏅

+   文章还探讨了未来Reyes模型的改进方向，包括加入更多多模态数据和私有数据进行训练。🚀

> 关键词：多模态，大模型，Reyes，MMMU评测，模型优化

> 从“说”到“做”：大语言模型为何会进化成智能体

>

+   📌文章探讨了大语言模型（LLM）如何通过技术进步成为智能体，强调了智能体的自主性、感知能力、决策能力、行动能力和适应性。

+   🌐分析了传统软件系统的局限性，包括依赖用户输入、缺乏自主性和学习能力，以及大模型如何克服这些限制。

+   🤖讨论了ReAct方法，它是首次将推理与行动结合在大模型中，使模型能够动态调整行动计划并利用外部知识。

+   🚀ReAct展示了多任务学习和适应性，能够在不同任务中快速适应和学习，提升了智能体的决策和行动效率。

+   🌈文章强调了语言模型的进化对智能体实现的重要性，以及它们如何借助语言的力量在复杂环境中灵活应对和进化。

> 关键词：大语言模型，智能体，自主性，ReAct，多任务学习
