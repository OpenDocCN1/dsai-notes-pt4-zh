> o1推理框架最新成果：斯坦福&伯克利提出元链式思维，升级模型推理能力

>

+   斯坦福和伯克利联合提出元链式思维（Meta-CoT）框架，提升AI模型在复杂推理任务上的表现。🔥

+   Meta-CoT使模型在推理过程中能反思任务，寻找新的研究思路和方法，尤其在数学问题上表现突出。📐

+   与传统CoT相比，Meta-CoT框架在HARP等数学基准测试中大幅领先，展现了更强的推理能力。🏆

+   Meta-CoT通过内部化搜索过程和合成元链式思维，提高了模型解决不熟悉领域问题的能力。🧭

+   实验结果表明，使用Meta-CoT框架的LLMs在复杂推理任务上的表现显著提升，特别是在高难度问题上。🎯

> 关键词：AI，推理框架，Meta-CoT，数学问题，复杂推理

> 聊聊大模型推理系统之 FastServe

>

+   北京大学提出的FastServe系统通过Skip-Join MLFQ和主动KV缓存管理解决大型语言模型推理延迟问题。

+   FastServe的Skip-Join MLFQ调度器有效避免了头阻塞问题，提高了任务处理优先级。

+   主动KV缓存管理机制优化了GPU内存使用，通过异步操作和流水线技术提升了数据传输效率。

+   支持多GPU并行和动态批处理大小调整，显著提升系统吞吐量。

+   实验结果显示FastServe在吞吐量和延迟方面相比现有解决方案有显著提升。

> 关键词：分布式推理，大型语言模型，Skip-Join MLFQ，KV缓存管理，系统吞吐量

> 看清”世界——从盲超分到真实超分

>

+   本文总结了从盲图超分辨率到真实世界图像超分辨率的相关背景和方法，探讨了底层视觉技术的发展对看清世界的影响。

+   分析了单图超分中存在的问题，指出盲超分是真实超分的过渡，真实超分面临的挑战依然很大。

+   讨论了多种超分辨率网络结构和算法，包括CNN框架、迭代优化方法和GAN技术的应用。

+   提出了真实超分数据集的构建和评价指标，展望了真实超分技术的未来发展方向。

> 关键词：图像超分辨率，盲超分，真实超分，GAN，底层视觉

> [T](https://mp.weixin.qq.com/s/IoAs4D2tymis6u6_bRItmw)NNLS'25｜东北大学长江学者贾同团队提出SOTA模型AO-DETR，解决X-ray图像违禁品检测领域难题

>

+   东北大学贾同团队提出AO-DETR模型，专门针对X-ray图像中违禁品检测的重叠问题进行优化。

+   AO-DETR模型通过CSA策略和LFD方法，解决了前景背景特征耦合和边缘模糊的问题，提升了检测精度和稳定性。

+   在PIXray等数据集上取得了SOTA性能，展现了AO-DETR模型在X-ray违禁品检测领域的强大能力。

+   论文还提出了评估模型标签分配稳定度的评价指标，深入理解Deformable DETR系列模型中object queries的作用机理。

+   实验结果显示AO-DETR模型精度高于DINO模型，并在标签分配稳定性上表现更优。

> 关键词：AI，CV，X-ray检测，违禁品，SOTA模型

> 27页超详尽综述！系统性回顾视觉定位任务十年发展

>

+   本文系统回顾了近5年的视觉定位论文，覆盖传统及基于VLP、MLLM的视觉定位技术，以及全监督、无监督等多种设置。

+   视觉定位任务旨在模拟社会对话中的指代关系，使机器具备多模态理解能力，对AI领域具有重要意义。

+   综述详细概述了视觉定位的基本概念、评估指标，并跟踪总结了当前的发展，为未来研究提供了规范和方向。

+   作者整理了相关数据集，并在RefCOCO/+/g系列数据集上进行了公平比较分析，提出了性能预测。

+   综述不仅适合视觉定位领域的新手入门，也适合资深研究者跟踪最新进展。
