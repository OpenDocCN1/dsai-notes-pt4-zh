> [16张H100训26分钟，超越o1-preview！李飞](https://mp.weixin.qq.com/s/iGi20QGI8KFn-WPtBL5JCw)飞等用1K样本，揭秘测试时Scaling

>

+   斯坦福大学和华盛顿大学的研究人员仅用1000个样本微调模型，通过预算强制技术提升推理能力，超越OpenAI的o1-preview模型。

+   预算强制技术通过控制模型思考的token数量来提高性能，引导模型自我检查并修正错误。

+   s1-32B模型展现了测试时扩展的能力，性能随测试计算量的增加而提升，是目前最具样本效率的推理模型。

+   创建s1K数据集分为两个阶段，从59K样本中筛选出1000个高质量、多样化和高难度的问题。

+   实验结果表明，预算强制是测试时扩展的最佳方法，s1-32B模型的性能明显优于其基础模型Qwen2.5-32B-Instruct。

> 关键词：AI推理，样本效率，预算强制，测试时扩展，OpenAI o1-preview

+   提出五项原则，包括优先开展AI意识研究、开发有意识AI系统的条件、渐进式发展路径、知识共享和沟通规范。

+   论文探讨了人类可能很快构建出有意识的AI系统，或至少给人留下此类印象的AI系统，引发道德和伦理问题。

+   Hinton和Bengio就AI意识的重要性展开辩论，Hinton认为AI已有意识，Bengio则认为意识定义不明，更重要的是AI的目标和行为。

+   讨论了AI意识对道德受体（moral patient）的定义、AI的痛苦程度、AI系统的创建和操控等问题，强调了AI伦理考量的重要性和复杂性。

> 关键词：AI意识，伦理问题，道德受体，AI痛苦，AI目标

> [LLM自主发现发表在Nature上的科学假设？ICLR 2](https://mp.weixin.qq.com/s/mkXZz9US_VNOxHinSJx2Rg)025 论文MOOSE-Chem深度解析

>

+   ICLR 2025论文《MOOSE-Chem》探讨了大模型（LLMs）能否在仅依赖化学研究背景信息的情况下，自动发现新的、有效的化学科学假设。🔥

+   研究发现LLM能自主发现新颖且可行的科学假设，甚至能重新发现已发表在Nature, Science上的顶级化学科学假设。🌏

+   研究提供了科学假设形成的数学建模，并提出了Agentic AI for scientific discovery的框架，使LLM能自动生成并筛选科学假设。📌

+   MOOSE-Chem的核心假设是化学研究假设h由研究背景b和研究灵感i组合而成，通过认知科学、论文分析和数学建模验证了这一假设的合理性。🧠

+   实验结果表明，LLM能成功识别与研究背景相关但未知的启发性论文，基于已知知识推理出高质量的新知识，有效对假设进行排名。🥁

> 关键词：AI，科学发现，LLM，MOOSE-Chem，Agentic AI
