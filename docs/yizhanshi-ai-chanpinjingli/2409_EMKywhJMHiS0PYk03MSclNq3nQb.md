> 小红书语音识别新突破！开源FireRedASR，中文效果新SOTA

>

+   小红书FireRed团队开源了基于大模型的语音识别模型FireRedASR，中文普通话测试集上性能达到新SOTA。

+   FireRedASR包含FireRedASR-LLM和FireRedASR-AED两种核心结构，分别针对精度和推理效率优化。

+   在公开测试集上，FireRedASR-LLM和FireRedASR-AED的字错误率（CER）均优于Seed-ASR等其他模型。

+   FireRedASR在日常场景和歌词识别中也展现出色效果，CER相对降低显著。

+   模型在中文方言和英语上也有良好表现，展现了鲁棒的语言适配能力。

> 关键词：语音识别，SOTA，开源，中文普通话，多场景应用

> 无需引导采样，清华大学提出视觉模型训练新范式

>

+   清华大学TSAIL团队提出了一种无需引导采样的视觉模型训练方法，称为Guidance-Free Training (GFT)，性能与CFG相当，但采样成本减半。🔥

+   GFT算法通过调节温度系数来控制生成质量与多样性的平衡，保持与CFG训练流程的高度一致性。🍭

+   GFT算法简单、高效、兼容，适用于扩散、自回归、掩码等多种视觉模型，且无需额外内存开销。🎯

+   实验表明，GFT在不同模型上与CFG模型性能持平甚至更优，尤其在采样质量和多样性控制方面。🌈

+   该研究由清华大学计算机系博士生陈华玉和TSAIL团队实习生姜凯共同完成，展示了GFT算法在视觉模型训练中的潜力。🧘‍♂️

> 关键词：视觉模型，无需引导采样，GFT，清华大学，算法效率
