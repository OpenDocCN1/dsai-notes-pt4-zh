> AI记忆机制解析：从SOAR架构到ChatGPT记忆模式

>

+   SOAR架构是早期Agentic记忆系统的探索，区分了工作记忆和长期程序性记忆，对现代AI架构有重要影响。

+   AI记忆分为长期记忆和短期记忆，长期记忆进一步分为显性记忆和隐性记忆，短期记忆包括上下文窗口和工作记忆。

+   生成式智能体通过记忆流系统和记忆检索机制，在虚拟社会中展现信息传播和关系建立等社会行为。

+   ChatGPT的“记忆模式”允许跨会话记忆，通过关键信息提取、选择性记忆和向量嵌入存储技术实现。

+   AI对人类记忆的影响深远，AI记忆技术的发展和普及需要我们重新审视记忆的定义、功能和伦理边界。

> 关键词：AI记忆，SOAR架构，长期记忆，ChatGPT，记忆伦理

> [北航推出TinyLLaVA-Video，有限计算资源优于](https://mp.weixin.qq.com/s/e1zUm8dv445RjrDtedJh3Q)部分7B模型，代码、模型、训练数据全开源

>

+   北京航空航天大学团队推出TinyLLaVA-Video，一个视频理解框架，模型参数量不超过4B，优于7B+模型。

+   该项目全面开源，包括模型权重、训练代码和训练数据集，支持定制与拓展。

+   采用Vision Tower+Connector+LLM框架，保持预训练对齐与监督微调的两阶段训练策略。

+   基于开源数据集进行实验，数据经过筛选与过滤，提高了训练数据的质量。

+   实验结果表明，TinyLLaVA-Video在多个视频理解基准测试集上的表现优于同等训练数据量级的7B+模型。

> 关键词：视频理解，开源项目，参数优化，多模态模型，计算资源效率

> Meta新视频生成框架拿捏倒立杂技，双人舞也能完美同步！

>

+   Meta GenAI团队推出了VideoJAM，一个基于DiT的视频生成框架，显著提升了运动一致性，增幅近20%。

+   VideoJAM在动态效果上超越了Sora和Gen3模型，无需额外数据或缩放即可集成到不同规模的DiT模型中。

+   该框架通过引入运动预测任务，让模型同时学习视频生成和运动预测，增强了视频的时间一致性。

+   VideoJAM使用光流表示运动，转换成RGB格式，提高了模型对时间一致性的理解。

+   实验表明，VideoJAM在4B和30B规模的DiT模型上均提升了运动质量，超过了其他主流视频生成模型。

> 关键词：视频生成，运动一致性，DiT模型，光流表示，时间一致性

> [Nature：离 “量子互联网” 又](https://mp.weixin.qq.com/s/Jas2dZin-eHr_Y1ZwwJauA)近一步！牛津大学证实分布式量子计算可行性

>

+   牛津大学的研究团队在Nature发表成果，实现了两米距离上的高保真度量子门传送，为量子互联网和大规模量子计算铺平道路。

+   该研究通过光子网络和量子门传送技术，实现了量子比特间的远程纠缠，为分布式量子计算（DQC）提供了新方法。

+   实验中，88 Sr^{+} 离子和43 Ca^{+} 离子被用于量子接口和电路量子比特，通过交换光子建立远程纠缠。

+   通过量子门传送，实现了跨越物理距离的量子计算，运行了Grover搜索算法，显示了分布式量子计算系统执行量子算法的潜力。

+   该技术的成功运行，标志着量子计算向实用化网络迈进了一大步，对于量子通信和量子计算领域具有重要意义。

> 关键词：量子互联网，分布式量子计算，量子门传送，量子纠缠，Grover算法

> 推理时也能做偏好优化，无需额外重训练

>

+   上海AI Lab和香港中文大学联合提出推理时偏好优化（TPO）方法，实现即时模型对齐，无需重新训练。

+   TPO通过与奖励模型交互，利用文本反馈迭代优化模型输出，提升未对齐模型表现，甚至超越训练对齐模型。

+   TPO具有推理时对齐、基于文本反馈、优于传统方法和灵活适应性等特点。

+   实验显示，TPO能有效提升模型性能，尤其在未对齐模型上表现显著，且在计算成本上有优势。

+   TPO的成功依赖于策略模型的指令跟随能力，未来研究将聚焦于优化文本交互方法和提升模型表现。

> 关键词：TPO，偏好优化，大语言模型，人工智能，无需重训练
