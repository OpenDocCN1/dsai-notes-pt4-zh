## 2️⃣ 🤖

[ICLR 2025 | 实时在线！清华、NTU提出适用于具身场景的3D分割一切模型](https://mp.weixin.qq.com/s/RSm1ScGna8JV8wmURMTCoA)

+   清华大学和NTU联合提出了EmbodiedSAM，一个实时在线的3D分割模型，能够高效且细粒度地在线处理三维实例分割。
+   该模型基于2D视觉基础模型，将2D分割结果映射到3D空间，并在三维空间中进行优化和帧间融合，以实现实时在线3D分割。
+   EmbodiedSAM具有在线性、实时性、细粒度和泛化性，能够处理多样化场景，并适配不同型号的传感器。
+   实验结果显示，EmbodiedSAM在class-agnostic 3D instance segmentation和online 3D instance segmentation任务上均取得了SOTA性能和速度。
+   该研究的代码、数据和模型权重已在GitHub开源，供学术界和工业界使用和进一步研究。

关键词：3D分割，实时在线，具身智能，泛化性，开源

## 6️⃣ 🔬

自动化、高精度，告别人工测量！Meta SAM模型高效解析复杂纳米颗粒

+   德国康斯坦茨大学和巴西米纳斯吉拉斯联邦大学的研究团队利用Meta的预训练AI模型SAM实现纳米颗粒自动化分割与形态分析。
+   SAM模型无需针对纳米颗粒微调，即可生成高质量分割掩膜，显著提高了分析精度和效率。
+   该方法对比传统分水岭算法和手动测量，展现出更低的测量误差和更高的一致性。
+   研究展示了SAM在处理复杂纳米颗粒结构上的优势，尤其是在多瓣结构的独立分割和归属关系确定上。
+   SAM模型的应用不仅降低了技术门槛，也为跨尺度材料分析提供了新范式，未来有望拓展至更多领域。

关键词：AI，自动化，纳米颗粒，图像分割，材料科学
