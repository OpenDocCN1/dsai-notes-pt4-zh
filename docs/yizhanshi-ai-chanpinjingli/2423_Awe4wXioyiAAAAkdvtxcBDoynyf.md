> 1/30训练步骤复刻DeepSeek-R1-Zero

>

+   沈向洋、姜大昕、张祥雨等开源推理模型RL训练方法，仅用1/30的训练步骤即可达到DeepSeek-R1-Zero的性能。

+   阶跃星辰联与清华联合发布Open Reasoner Zero（ORZ），在17%的训练步骤下性能匹敌DeepSeek-R1-Zero。

+   训练步骤约680步时，模型出现显著提升，疑似“顿悟时刻”。

+   训练数据、代码、论文、模型100%开源，采用MIT License。

+   Open Reasoner Zero在MMLU和MMLU_PRO基准测试中超越Qwen2.5 Instruct。

> [DeepSeek、OpenAI、Kimi视觉推理到底哪家强？港](https://mp.weixin.qq.com/s/UueqK4BiglBKKCrQw61mjA)中文MMLab推出推理基准MME-COT

>

+   香港中文大学MMLab推出了MME-CoT基准，专门评估视觉推理能力，包括数学、科学、OCR等领域。

+   基准测试显示Kimi k1.5在CoT质量上领先，而o3-mini在鲁棒性和效率上表现最佳。

+   DeepSeek-R1在文本推理上表现出色，使用图片caption的precision超过了GPT-4o。

+   研究发现，具备反思能力的模型如QVQ在CoT质量上表现较高，Kimi k1.5超越GPT-4o达到最佳质量。

+   MME-CoT揭示了现有模型在推理质量、鲁棒性和计算效率方面的不足，为LMM研究指明了方向。

> 关键词：视觉推理，MME-CoT，Kimi k1.5，DeepSeek-R1，鲁棒性

+   刘教授提出，未来AI发展应追求高效性，通过高质量、可持续的方式实现大模型的普惠，这是智能革命的重要方向。🚀
