## 5️⃣ [挖掘「缝合」的潜力：CapaBench 揭示 LLM 智能体中各个模块的作用](https://mp.weixin.qq.com/s/O0IZjXchCqxViFAV2rA2gQ)

> 🧠

+ CapaBench 是一个评估框架，量化LLM Agent架构中各个模块的贡献。
+ 通过Shapley值方法，CapaBench系统性评估模块贡献，提升模块化LLM代理的可解释性。
+ 实验涉及九个大规模语言模型，结果显示高Shapley值模块组合提高任务表现。
+ 跨任务模型性能比较揭示了不同模型的优势与劣势，特别是在形式化验证和机器人协作任务中。
+ CapaBench为LLM代理技术优化和应用提升提供了科学的性能评估依据。

**关键词：** CapaBench，LLM Agent，模块化架构，Shapley值，性能评估

## 6️⃣ 3倍提速！现在你跑不过机器狗了，限制波士顿动力机器狗的竟然是电池功率？

> 🚀

+ 波士顿动力机器狗Spot的速度通过RAI研究所的强化学习技术提升了近3倍，达到18.7千米/小时。
+ 研究发现，Spot速度提升的主要限制因素是电池供电能力而非马达性能。
+ Spot的新步态包括四脚同时离地的“飞行”阶段，这有助于其快速移动并维持速度。
+ 强化学习不仅提升了Spot的性能，还使其行动更加可靠，与传统模型预测控制方法相比，具有明显优势。
+ RAI研究所还使用强化学习训练了一辆名为UMV的自行车，使其能够执行复杂的跑酷动作。

**关键词：** 强化学习，机器人速度，电池限制，Spot机器狗，UMV自行车
