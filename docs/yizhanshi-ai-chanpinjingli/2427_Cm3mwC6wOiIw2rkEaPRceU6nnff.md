> [AI驱动的模拟科学家](https://mp.weixin.qq.com/s/WAia3789QO0RJtf2Lps4Bw)

>

+   澳大利亚莫纳什大学研究团队开发LLM4SD框架，利用大型语言模型（LLM）推动分子特性预测中的科学发现。🌏

+   LLM4SD通过整合文献知识和科学数据，将分子转化为可解释的特征向量，并在分子特性预测任务中表现优异。🧬

+   该系统能够解释其分析过程、预测和结果，有助于科学家信任并根据其见解采取行动。📌

+   LLM4SD在MoleculeNet数据集中的58个基准任务中实现了分子特性预测的当前最佳水平。🎯

+   研究结果表明，LLM4SD工具在预测材料设计关键的量子特性方面的准确率提高了48%，预示着人工智能驱动的科学发现时代的到来。🤖

> 关键词：AI，科学发现，LLM，分子特性预测，可解释性

> [Transformer革新药物研发：TRAC](https://mp.weixin.qq.com/s/l_xJ4o9wZrAld1FB4qgZnA)ER框架实现反应感知的分子设计与合成优化

>

+   东京科学大学的研究团队开发了TRACER框架，结合分子性质优化与合成路径生成，提升了药物研发效率。

+   TRACER框架通过编码1000种真实反应类型为条件令牌，使Transformer能够学习分子生成和合成路径。

+   该框架采用显式分离架构，包括图卷积网络、条件Transformer和MCTS，以协同学习「反应条件-结构转化-属性优化」。

+   实验显示TRACER在维持药物分子关键骨架方面表现出色，相较于传统方法有显著的性能提升。

+   TRACER框架的创新为AI药物发现领域带来了从理论到实践的重要转变，加速了DMTA循环。

> 关键词：AI药物研发，TRACER框架，分子设计与合成优化，Transformer，化学反应感知

> [何恺明开辟分形图像生成新范式！计算效率提](https://mp.weixin.qq.com/s/SK89sa0N7Hj-yr8lI1PD_w)高4000倍，首次实现高分辨率逐像素生成

>

+   何恺明团队提出了分形生成模型Fractal Generative Models，通过自相似的分形架构实现高分辨率逐像素图像生成。

+   该模型使用参数化的神经网络作为分形生成器，学习递归法则，对高维非序列数据进行建模。

+   计算效率提升至传统方法的4000倍，使得逐像素生成高分辨率图像成为可能。

+   分形模型在ImageNet 64×64无条件生成上实现了3.14bits/dim的负对数似然，超越自回归模型。

+   结合MAE成果，准确预测被掩蔽的像素，并能从类标签中捕获高级语义，反映在预测像素中。

> 关键词：分形生成模型，高分辨率图像，计算效率，自回归模型，高级语义

> 阿里开源版Sora上线即屠榜，4070就能跑，免费商用

>

+   阿里巴巴开源了视频生成模型Wan 2.1，具有14B参数量，性能超越Sora和Gen-3。

+   Wan 2.1在复杂运动细节和静态图像生成中的文字识别表现出色。

+   模型提供14B和1.3B两个版本，分别支持720P和480P分辨率，可在个人显卡上运行。

+   阿里还发布了两个图生视频模型，均为14B参数，支持Apache 2.0免费商用许可。

+   Wan 2.1采用3D变异自动编码器和DiT架构，优化了时空压缩和时间因果关系，提高了视频生成效率。

> 关键词：AI视频生成，开源模型，参数优化，免费商用，技术创新

> [多模态大模型对齐新范式，10个评估](https://mp.weixin.qq.com/s/nG6MiwLl_xxXMWM0QGKW1w)维度全面提升，快手&中科院&南大打破瓶颈

>

+   快手、中科院和南大合作，推动多模态大语言模型（MLLMs）对齐发展，提升模型在多个评估维度上的性能。

+   新数据集包含120k精细标注的偏好比较对，提升了数据集规模和质量，促进模型在对话能力和安全性上的显著提升。

+   创新的基于批评的奖励模型和动态奖励缩放方法，优化了模型训练和数据使用效率。

+   在10个维度和27个基准上进行了全面评估，显示提出的方案在各方面均取得显著性能提升。

+   小规模MLLMs在自我提升方面面临挑战，而本研究提出的数据集和对齐方法为全面提升MLLMs性能提供了新途径。

> 关键词：多模态大模型，对齐发展，数据集，奖励模型，性能提升
