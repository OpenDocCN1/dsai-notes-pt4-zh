> RAG的下一形态？通义实验室：ViDoRAG！

>

+   ViDoRAG是一种新型的RAG框架，通过多智能体框架和动态迭代推理机制，提升了视觉丰富文档检索增强生成的能力。

+   ViDoRAG引入基于高斯混合模型（GMM）的多模态混合检索策略，优化了文本和视觉特征的整合。

+   为了评估大规模文档集合的检索和推理能力，研究者们推出了ViDoSeek数据集，提供了更具挑战性的基准。

+   ViDoRAG的多智能体生成流程模拟人类推理过程，通过探索者、检查员和回答者的协作，提高了答案的准确性和全面性。

+   实验表明，ViDoRAG在ViDoSeek基准测试中表现出色，准确率达到79.4%，显著优于现有方法。

> 关键词：RAG，ViDoRAG，多模态混合检索，ViDoSeek数据集，人工智能

> 部分国产芯片适配满血版 DeepSeek，仍「遥遥无期」

>

+   国产AI芯片公司在适配满血版DeepSeek模型上进展缓慢，华为、寒武纪等少数公司完成适配。

+   适配满血版DeepSeek模型面临的挑战包括多机互联、MoE混合专家系统以及FP8数据类型的支持。

+   蒸馏版DeepSeek模型虽然效果差于满血版，但更易于部署，对于普及AI具有重要意义。

+   国内领先AI芯片公司目标在二月底前达到25Tokens/s的性能，但目前仅达到英伟达H100性能的25%。

+   DeepSeek的火爆对国内芯片、智算中心、AI应用都是巨大利好，国产AI芯片公司上市前景看好。

> 关键词：国产AI芯片，DeepSeek适配，性能挑战，AI普及，智算中心发展

> [速度提升3200倍，准确率提高40%](https://mp.weixin.qq.com/s/5DXhxQmjt5rqWHphWp3ROA)！深度神经网络+纠错码革新DNA存储技术

>

+   以色列理工学院研究团队通过深度神经网络（DNN）和纠错码（ECC）技术，大幅提升DNA存储技术的速度和准确率🚀。

+   DNA存储技术面临的可扩展性和准确性问题得到解决，商业化应用的技术障碍被清除🌐。

+   DNAformer解决方案采用模块化编码方案，结合ECC和约束码，实现快速数据访问和高效率🔑。

+   实验验证显示，DNAformer在速度上提升3200倍，准确率提高40%，编码率达到每碱基1.6比特📈。

+   该技术的成功应用预示着DNA存储技术在大规模数据存储系统中的潜力和未来发展方向🔮。

> 关键词：DNA存储，深度神经网络，纠错码，数据存储技术，技术创新
