## 1️⃣ 🧬🎯 [WWW 2025 | TAMU、UIUC等](https://mp.weixin.qq.com/s/tX84YP0FyfOuolJwMe-j8A)

+ TAMU、UIUC等机构提出了一种新的因素链框架，用以改善论文-评审人匹配的效果。
+ 该框架综合考虑了语义、主题和引用三大因素，通过指令微调训练一个共享的语言模型。
+ 实验显示，新模型在多个领域数据集上超越了现有方法和预训练语言模型。
+ 研究还探讨了审稿人匹配中论文选择的标准，发现包含审稿人所有论文通常更有益。
+ 该框架通过逐步筛选的方式，提高了匹配的准确性和效率。

**关键词**：论文-评审人匹配，因素链框架，语义，主题，引用

## 2️⃣ 🧬🪅🎊 无编码器架构潜力或被低估，首个无编码器3D多模态LLM大模型来了

+ 首个无编码器3D多模态大型语言模型（LLM）ENEL发布，其7B模型性能与最先进的ShapeLLM-13B相当，显示无编码器架构的巨大潜力。
+ ENEL通过混合语义损失和层次几何聚合策略，有效整合3D编码器功能，提高了模型对3D点云的语义理解和几何感知能力。
+ 在Objaverse数据集上，ENEL-7B在3D物体描述任务中达到50.92%的GPT-4得分，刷新了SOTA性能。
+ ENEL在3D物体分类和3D-VQA任务上也超越了基于编码器的3D LMMs，证明了无编码器架构的有效性。
+ 该研究由上海AI Lab等机构完成，代码和论文已开源。

**关键词**：无编码器架构，3D多模态LLM，ENEL，混合语义损失，层次几何聚合

## 4️⃣ 🧠 [AgenticLU长上下文理解，LLM澄清链CoC实现](https://mp.weixin.qq.com/s/6fer4oSvOhxSAd9d1qchwg)自学，答案召回率高达97.8% | 最新

+ AMD和UC San Diego的研究团队提出了AgenticLU框架，通过澄清链(CoC)机制显著提升了LLM对长文本的理解能力。
+ AgenticLU在NarrativeQA数据集上实现了97.8%的答案召回率，是目前已知最好的结果。
+ 框架包括传统LLM局限性、AgenticLU的CoC构建过程和2-Level Scaling策略，模拟人类阅读复杂文本时的认知过程。
+ 使用Llama3.1-8B-Instruct作为基础模型，主要训练数据来自NarrativeQA数据集，包含14.7K个问答对。
+ AgenticLU在多种上下文长度和不同任务类型上都取得了显著优势，性能稳定性、通用性和可扩展性是其关键优势。

**关键词**：AgenticLU，LLM，CoC，长文本理解，NarrativeQA

## 6️⃣ 🤖 一头大象难倒ChatGPT，Grok 3完美通关

+ ChatGPT因无法正确理解否定含义而无法画出“有0头大象的房间”，而Grok 3和谷歌Gemini 2.0则能正常生成只有家具的房间。
+ ChatGPT拒绝画玫瑰，可能与内容规范有关，而复数形式或表情符号则无此问题。
+ AI在处理“有-1头大象的AI”任务时，Grok 3和ChatGPT均需推理模型与画图工具的整合。
+ ChatGPT和Grok 3在推理和画图工具整合方面存在挑战，影响了AI的图像生成能力。
+ 讨论了AI内容过滤的困惑，如ChatGPT拒绝回答某些问题，可能与特定token标记有关。
