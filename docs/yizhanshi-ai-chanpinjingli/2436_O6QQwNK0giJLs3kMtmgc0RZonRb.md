> 让RAG更聪明！通义实验室ViDoRAG开启视觉文档检索增强生成新范式

>

+   阿里巴巴通义实验室、中国科学技术大学和上海交通大学联合推出ViDoRAG框架，通过多智能体框架和动态迭代推理机制，增强视觉文档检索和生成能力。📈

+   ViDoRAG框架通过高斯混合模型（GMM）的多模态混合检索策略，提升了视觉丰富文档的检索和推理能力。🔍

+   为了评估大规模文档集合的检索和生成能力，研究者们推出了ViDoSeek数据集，提供了一个更具挑战性和实用性的基准。📚

+   ViDoRAG在ViDoSeek基准测试中表现出色，准确率达到79.4%，显著优于现有方法。🏆

+   研究还探讨了ViDoRAG的Test-Time Scaling和时延分析，证明了多智能体系统在复杂RAG任务中的有效性。🕒

> 关键词：AI，RAG，NLP，CV，多智能体框架

> [快1000倍，十万分之一误差，深](https://mp.weixin.qq.com/s/vritKIcikeq8--9mk7oxBw)度学习模型降低核聚变等离子体预测计算成本

>

+   蔚山国立科学技术院（UNIST）研究人员开发出深度学习框架FPL-net，用于加速求解核聚变等离子体预测中的复杂问题。

+   FPL-net的速度比传统方法快1000倍，误差仅为十万分之一，显示出高准确性。

+   该框架采用U-Net架构，通过编码器-解码器结构保留高分辨率局部信息，实现强大性能。

+   FPL-net通过物理守恒约束和递归预测策略，提高了长期模拟的稳定性和鲁棒性。

+   实验结果表明，FPL-net在保持误差控制在10⁻⁵量级的同时，展现出卓越的计算效率，相比传统数值方法实现了1000倍以上的加速。

> 关键词：深度学习，核聚变，等离子体预测，FPL-net，计算效率

> Nature:如何借助AI高效完成学术论文同行评审

>

+   研究人员常因审稿占用大量时间，导致许多学者婉拒审稿邀请。

+   研究者Dritjon Gruda调查发现，超过40%的学者通常在单次审稿上花费2-4小时。

+   高效审稿的三步法：快速浏览、口述记录、内容优化，能大幅节省审稿时间。

+   使用离线大型语言模型（LLM）如GPT4ALL，可以在保护敏感手稿的同时优化审稿工作。

+   该工作流程能显著减少审稿时间，提高审稿质量，同时减轻审稿人的认知负担。

> 关键词：AI，学术论文，同行评审，LLM，效率提升
