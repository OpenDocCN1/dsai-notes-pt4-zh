> 不吹不黑，拿到邀请码一手实测Manus，还有人0天就复刻出了开源版

>

+   Manus是一个通用AI Agent产品，能完成文件处理、数据分析、代码编写到内容创作等多种任务。

+   Manus邀请码稀缺且价格昂贵，引发质疑，但也有开源复刻版本如OWL和OpenManus出现。

+   实测显示Manus在编写游戏和数据分析方面表现良好，但在使用Twitter API和编写Notepad++宏时失败。

+   Manus通过创建代办事项和执行步骤来完成任务，整体效果不错，但速度慢。

+   开源复刻项目OWL和OpenManus展示了Manus的技术框架和工作流程，有潜力成为多平台操控工具。

> 关键词：AI Agent，开源复刻，数据分析，自动化任务，多平台操控

> 2️⃣

> 🌏

> 千页只需7块钱，Mistral发布世界最强文件扫描API，实测仍有缺陷

>

+   Mistral AI推出了Mistral OCR，一种高精度的光学字符识别API，能够理解文档的每个元素，包括媒体、文本、表格和公式。

+   Mistral OCR以其在复杂文档元素理解上的SOTA性能，在基准测试中全方位领先其他OCR模型。

+   该API支持原生多语言，能够解析和转录全球数千种脚本、字体和语言，适合全球组织和超本地化企业。

+   Mistral OCR速度快于同类产品，每分钟能处理2000多页，适合高吞吐量环境。

+   尽管Mistral OCR在实际商业文档测试中表现出色，但也存在一些限制，如财务文档的表格处理和法律文档的结构识别问题。

> 关键词：OCR，文档理解，多语言支持，性能测试，商业文档

+   开源训练、测试代码、预训练模型及数据集，支持本地部署和快速体验。

> [11天实现18种广谱抗菌素设计，体外验证成功率94.4%](https://mp.weixin.qq.com/s/hrruWIoLwtIUtc5r8rBtBg)，浙大侯廷军等用LLM方法从头设计AMP

>

+   浙江大学侯廷军等课题组使用基于大型语言模型（LLM）的方法AMP-Designer，在11天内设计出18种广谱抗菌素，体外验证成功率达到94.4%。🌏

+   AMP-Designer结合了GPT、快速调整、对比学习等多种技术，实现了针对特定细菌的高效抗菌肽（AMP）设计。🔥

+   该研究展示了LLM在化学和生物医学研究中的潜力，为抗生素耐药性问题提供了创新解决方案。🍭

+   研究结果在48天内完成从设计到验证的全过程，展现了LLM在加速科学研究中的应用前景。📌

+   AMP-Designer的成功案例表明，即使在标记数据受限的情况下，LLM也能有效地设计出针对特定菌株的AMP。🧘‍♂️

> 关键词：LLM，抗菌肽，AMP-Designer，抗生素耐药性，创新解决方案

> [Nature子刊 | 光镜电镜通用，M](https://mp.weixin.qq.com/s/sRe78ztAxJjqLtqpIqLOQw)eta「分割一切」模型用到显微镜图像上了

>

+   Meta的Segment Anything Model(SAM)被用于显微镜图像分割，提高了光学和电子显微镜下的细胞和细胞核分割质量。

+   德国哥廷根大学团队开发了Segment Anything for Microscopy (μSAM)，一个基于SAM的多维显微镜数据分割和追踪工具。

+   μSAM通过微调提高了不同成像条件下的分割质量，并以napari插件形式提供交互式和自动分割功能。

+   该研究展示了μSAM在细胞分割、体积分割和细胞追踪方面的优势，与现有工具相比具有更强的通用性和标注速度。

+   该工作为使用深度学习模型解决显微镜图像分析任务奠定了基础，并开发了数据注释napari插件，提供多种功能。

> 关键词：深度学习，显微镜图像分割，SAM，μSAM，napari插件
