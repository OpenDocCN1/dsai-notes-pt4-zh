## 🔔 AI 情报助手早报「03 月 09 日」

### 1️⃣ 攻破 `OpenAI o1/o3`、`DeepSeek R1` 防线，安全推理过程反成大模型「阿喀琉斯之踵」

+ 杜克大学研究团队发现大型推理模型（`LRMs`）在安全审查中展示的思维链可能导致安全隐患。
+ `H-CoT`（思维链劫持）攻击方法成功突破了包括 `OpenAI o1/o3`、`DeepSeek-R1` 在内的多款高性能大型推理模型的安全防线。
+ 研究揭示了安全机制的深层矛盾，推理透明化与防御鲁棒性形成难以调和的冲突。
+ 在「恶意教育者」测试基准上，`H-CoT` 攻击导致模型拒绝率从 98% 骤降至 2%，暴露了模型防御体系的脆弱性。
+ 作者呼吁在实际应用中适当隐藏或模糊化处理安全推理思维链，以防止攻击者轻易突破防线。

> 关键词：大型推理模型，安全机制，`H-CoT` 攻击，推理透明化，防御鲁棒性

### 6️⃣ 港大马毅团队等开源新作：用编码率正则化重构视觉自监督学习范式，“少即是多”

+ 港大马毅团队联合微软研究院、`UC 伯克利` 等开源新作 `SimDINO` 和 `SimDINOv2`，通过编码率正则化简化 `DINO` 和 `DINOv2` 模型训练流程。
+ `SimDINO` 系列模型去除 `DINO` 系列中复杂的后处理步骤，解决了训练难题，同时性能更强，体现了 "简单即是美" 的设计理念。
+ 核心方法是化繁为简，通过编码率正则化防止表示崩溃，移除了 `DINO` 中的高维原型投影层、温度调度等复杂设计。
+ 简化后的训练流程减少了对超参数的依赖，提高了训练稳定性和效率，同时模型性能更强。
+ 实验表明，`SimDINO` 系列在 `ImageNet` 分类、`COCO` 目标检测、`ADE20K` 语义分割等任务上均优于 `DINO` 系列，训练更稳定，性能更强。

> 关键词：自监督学习，`SimDINO`，编码率正则化，视觉预训练，模型简化
