> 砍掉99%采样成本！腾讯AI Lab提出大模型无监督训练新技术

>

+   腾讯AI Lab与香港中文大学（深圳）合作，提出无监督前缀微调（UPFT）技术，显著降低大模型训练的采样成本和时间。

+   研究发现模型的“前几步”包含关键推理信号，称为“推理前序自一致性”，基于此微调模型生成的前8-32个词，可达到传统监督训练水平。

+   UPFT技术不仅减少训练序列长度和内存消耗，还在多个推理基准测试中显示出性能优势。

+   与传统监督微调相比，UPFT在多个数据集上展现了更高的准确率，同时大幅降低了训练token数量。

+   研究还表明，不同模型对前缀长度的依赖程度不同，为模型训练策略设计提供了新视角。

> 关键词：无监督学习，大模型训练，推理前序自一致性，UPFT，性能优化

> [90分钟生成10万Token，新框架实现3倍无损加速超长文本生](https://mp.weixin.qq.com/s/Icx9sTwykZOLWVgA_qENmg)成，支持DeepSeek-R1和QwQ！

>

+   TOKENSWIFT框架实现3倍无损加速超长文本生成，仅需90分钟生成10万Token。

+   该框架从模型加载、KV缓存管理到Token生成策略全方位优化，提升效率同时保证质量。

+   支持R1-Distill，发布经过微调的DeepSeek-R1-Distill-Qwen-32B模型，具备3倍加速效果。

+   多Token并行生成与Token复用、动态KV缓存更新策略、基于树结构的多候选Token验证，上下文惩罚策略，全方位提升性能。

+   实验表明，TOKENSWIFT在生成10万Token长序列时，平均实现3倍以上加速，保持准确性和多样性。

> 关键词：AI，文本生成，TOKENSWIFT，DeepSeek-R1，QwQ

> 加速精准医疗，开源GNN实现分子精准建模，质谱识别准确率提升至49%

>

+   德国联邦材料研究与测试研究所（BAM）与柏林自由大学团队开发了FIORA，一个开源图神经网络模型，用于模拟串联质谱，提高化合物鉴定准确率。

+   FIORA通过局部分子邻域学习断裂模式和碎离子概率，超越了ICEBERG和CFM-ID等先进算法，准确率提升至49%。

+   该模型利用GPU加速，能快速验证化合物注释，扩展光谱参考库，提高代谢物鉴定的泛化性和准确性。

+   FIORA是完全开源的，可在GitHub上免费获取，展现了多功能性和模块化设计，易于集成不同深度学习架构。

+   研究显示，FIORA在不同结构相似性区间的化合物中保持稳健性能，对结构不同的化合物也有良好泛化能力。

> 关键词：精准医疗，图神经网络，质谱识别，化合物鉴定，开源模型
