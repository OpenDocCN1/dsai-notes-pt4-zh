> [MedVLM-R1：借力DeepSee](https://mp.weixin.qq.com/s/cnNQwTg6LeF0hlCJ5mPQlA)k强化学习赋能医疗视觉语言模型的推理能力

>

+   MedVLM-R1是一款医学视觉语言模型，集成了DeepSeek强化学习框架，以提高推理能力。

+   该模型在仅有600个视觉问答样本的情况下，准确率从55.11%提高到了78.22%，超越了大规模数据训练的同类模型。

+   MedVLM-R1能够在提供最终答案的同时生成明确的推理过程，增强了模型的透明度和可信度。

+   研究显示，该模型在MRI、CT和X射线数据集上表现出色，但也存在局限性，如模式差距和对封闭集的依赖性。

+   MedVLM-R1的研究结果表明，基于强化学习的方法在泛化能力上优于监督微调方法，尤其在OOD设置下。

> 关键词：AI，医疗视觉语言模型，DeepSeek，可解释性，泛化能力

+   Tern AI的技术具有隐私优势，是一个闭环系统，无外部接触点。

> 驱动“超真人”虚拟助手Maya的实时语音对话模型CSM-1b开源！

>

+   2025年3月14日，Sesame团队开源了虚拟助手Maya背后的实时语音对话模型CSM-1b，允许用户生成RVQ音频代码。

+   CSM-1b提供了三种模型尺寸，从Tiny到Medium，以适应不同的应用需求和资源限制。

+   开源模型可在魔搭社区和HuggingFace下载，微调版的CSM模型在Sesame官网提供交互式语音演示。

+   模型性能从文本忠实度、上下文利用率、韵律和延迟四个方面进行评估，展示了模型的高自然度和韵律适宜性。

+   最佳实践指南提供了在魔搭平台上运行CSM-1b模型的详细步骤，包括申请实例、克隆代码、安装依赖和运行命令。

> 关键词：AI伴侣，实时语音对话，开源模型，性能评估，最佳实践
