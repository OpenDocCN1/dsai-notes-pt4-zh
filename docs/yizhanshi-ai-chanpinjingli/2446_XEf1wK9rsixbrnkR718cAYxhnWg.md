## 5️⃣ 🧬 谷歌重磅推出全新Scaling Law，抢救Transformer！3万亿美元AI面临岔路

+ 谷歌团队发现新Scaling Law，DiLoCo训练方法在多数据中心训练大模型时，表现出更稳健、优越、高效和强大。
+ DiLoCo相较于数据并行训练，展现了更少的带宽需求和更高的效率，尤其在大规模模型训练中优势明显。
+ 研究揭示DiLoCo在模型规模增长时稳定且可预测的扩展性，解决了通信瓶颈，为大规模模型训练开辟新可能。
+ AI行业面临两种未来路径：继续Chinchilla模式的巨额投入或转向更高效的推理模型和MoE技术。
+ 新型推理模型和MoE技术的发展可能使得AI行业走向轻量化、高效率的未来，减少对大规模预训练的依赖。

关键词：Scaling Law，DiLoCo，数据并行，AI未来路径，推理模型

## 6️⃣ 🤖 AI搜索风靡，但高达60%引用出错！付费版甚至更糟

+ 近四分之一美国人已用AI取代传统搜索引擎，但AI搜索工具引用新闻错误率高达60%。
+ 8款AI工具在引用新闻方面表现不佳，Perplexity错误率37%，Grok 3高达94%。
+ AI搜索工具自信给出错误答案，不使用“似乎”等词语，也极少承认知识缺口。
+ 付费模型表现更差，如Grok-3 Search和Perplexity Pro错误率更高。
+ AI搜索工具无视爬虫协议，侵犯出版商权益，影响新闻行业质量和多样性。

关键词：AI搜索，引用错误，付费模型，爬虫协议，出版商权益
