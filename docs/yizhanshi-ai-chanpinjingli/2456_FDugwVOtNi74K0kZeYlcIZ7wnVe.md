> [全球首款音乐推理模型Mureka O1首秀！爆改](https://mp.weixin.qq.com/s/5anNt3afJO1KXkE8zcY1TA)周杰伦，AI音乐进入DeepSeek时刻

>

+   昆仑万维发布全球首款音乐推理大模型Mureka O1，融入CoT技术，在与Suno V4等评测中占优，登顶TOP 1。

+   其基座模型Mureka V6优化升级，支持10种语言，Mureka O1在此基础上，提升音乐结构连贯性等。

+   Mureka O1创作功能多样，可多语言创作、爆改红曲、定制BGM等，还支持音轨分离下载与音色克隆。

+   团队打造MusiCoT框架，实现结构化生成，Mureka同时开放音乐和语音API，开发前景广阔。

+   AI音乐市场潜力大，Mureka商业化前景惊人，赋能人人成为创作者。

> 关键词：AI音乐，Mureka O1，音乐推理模型，MusiCoT框架，API

> Qwen2.5-VL-32B: 更聪明、更轻量!

>

+   阿里通义千问团队开源Qwen2.5-VL-32B-Instruct模型，采用强化学习优化，回复更符合人类偏好，提升数学推理及图像理解推理能力。

+   该模型性能卓越，在多模态任务中优势明显，纯文本能力也达同规模最优，可媲美GPT-4o，超越同类模型。

+   支持使用transformers本地推理、魔搭API-Inference调用，还能用ms-swift进行微调。

+   采用Apache 2.0开源协议，便于商业应用与二次开发。

+   团队下一步将聚焦长且有效的推理过程，突破视觉模型处理复杂任务的边界。

> 关键词：Qwen2.5-VL-32B，开源模型，强化学习，多模态，模型微调
