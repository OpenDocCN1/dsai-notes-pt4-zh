## 1️⃣ 🤖 速递｜AI口音重塑功能提高26%销售转化，语音AI掀起职场口音标准之争

+ 音频初创公司Krisp推出AI口音重塑功能，可在通话中改变用户口音，先帮助印度人听起来像美国人。
+ 该功能保留原声，仅切换音素，在企业环境测试过，测试版将登陆桌面应用。
+ 企业用户测试显示，此功能使销售转化率提升26.1% ，单次预订收入增长14.8% 。
+ 模型基于大量语音样本训练，无需对用户声音预训练，未来计划增加更多口音支持。
+ Krisp计划发布iOS和安卓应用及新Chrome扩展。

> 关键词：AI口音重塑，语音AI，销售转化，Krisp，口音支持

## 6️⃣ 🤖 Agent太火！看这一篇综述，知识就不会学杂了丨华东师大&东华大学出品

+ 华东师大和东华大学团队发表综述，从系统化视角梳理分析LLM智能体优化策略，分为参数驱动与参数无关的优化。
+ 参数驱动优化含基于监督微调、强化学习及两者混合策略；参数无关优化涉及Prompt工程等方式。
+ 还整理了相关数据集，回顾LLM Agent在多领域的实践，总结面临的挑战与未来方向。
+ 挑战包括数据偏差、算法效率、跨任务迁移、评估标准及多智能体优化等问题。
+ 未来可探索相应解决方法，推动Agent研究发展。

> 关键词：LLM智能体，优化策略，数据集，挑战，未来方向
