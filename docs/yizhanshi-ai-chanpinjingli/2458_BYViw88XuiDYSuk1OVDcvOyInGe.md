> 刚刚，GPT-4o原生图像生成上线，P图、生图也就一嘴的事

>

+   OpenAI 深夜悄悄推出GPT-4o原生图像生成，免费用户也可使用。

+   GPT-4o图像生成能力优势显著，能精准呈现文字、遵循指令，还可基于上下文持续生成。

+   当然它也存在裁剪、幻觉等局限性。

+   OpenAI 强调在模型安全方面的工作，如通过C2PA标记图像等。

+   目前Plus、Pro、Team和免费用户可使用，API用户权限未来几周推出。

> 关键词：GPT-4o，图像生成，模型局限，模型安全，用户权限
