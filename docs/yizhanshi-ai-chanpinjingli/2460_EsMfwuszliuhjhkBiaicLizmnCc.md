> [业界突破多模态泛化推理能力，OPPO研](https://mp.weixin.qq.com/s/gWGn02IQpO-K75sshqeUfg)究院&港科广提出OThink-MR1技术

>

+   OPPO研究院和港科广提出OThink-MR1技术，将强化学习扩展到多模态语言模型，以突破多模态泛化推理能力。

+   该技术基于动态强化学习，核心包括动态KL散度策略和奖励模型，提升模型学习效率与推理能力。

+   实验验证其在同任务、跨任务评估中表现出色，优于监督微调训练的模型。

+   OThink-MR1为多模态语言模型发展开辟新道路，展现动态强化学习提升模型能力的潜力。

+   未来多模态语言模型有望基于此技术在更多领域发挥重要作用。

> 关键词：多模态，泛化推理，动态强化学习，OThink-MR1，强化学习

> [13.8倍吞吐提升！浙大上海AI Lab等提出视觉生成新范式](https://mp.weixin.qq.com/s/xi-DiW7vt0lI8xQ60XGq-Q)，从“下一个token”到“下一个邻域”

>

+   浙大、上海AI Lab等机构提出邻近自回归建模（NAR）视觉生成新范式，以解决传统“下一个token预测”的效率瓶颈。

+   NAR采用“下一个邻域预测”机制，引入维度导向解码头，可并行生成多个token，减少模型前向计算步骤。

+   在多个视觉生成任务实验中，NAR在生成效率和质量上均显著提升，如在ImageNet数据集上有13.8倍吞吐提升。

+   NAR在视频生成任务能确保帧间连贯性，文本到图像生成任务中用少量数据获高综合得分。

+   NAR为视觉生成提供高效高质量方案，有望在AI应用中发挥重要作用。

> 关键词：视觉生成，NAR模型，效率提升，生成质量，AI应用

> 网上晒图要当心！AI六成可能知道你在哪儿

>

+   新研究表明，AI看图猜地名准确率超人类，表现最好的AI模型猜城市正确率比人类高62.6% 。

+   研究发现视觉语言模型（VLMs）存在偏差，如偏向知名城市、跨区域准确率差异等，还引发隐私问题。

+   为指导VLMs完成地理定位任务，借鉴游戏策略设定模型指令与提示词。

+   通过FAIRLOCATOR框架从深度和广度评估VLMs性能，不同模型表现有差异。

+   研究还探讨了数据泄露、虚假相关性等对VLMs的影响，思维链提示作用有限。

> 关键词：AI，视觉语言模型，地理定位，偏差，隐私问题

> AI「癌症神探」降临：准确度近100%，医生也自叹不如！

>

+   国际科研团队研发出ECgMPL模型，诊断子宫内膜癌准确率达99.26%，远超医生平均水平，还能诊断多种其他癌症。

+   该模型构建基于高质量数据集，经图像预处理、分割、光度增强等环节，采用创新架构和优化训练方法。

+   消融研究确定了模型最佳配置，多指标评估显示其性能卓越，10折交叉验证证明稳定性和泛化能力强。

+   在不同癌症类型外部数据集测试，模型准确率>97%，展现可靠泛化能力。

+   此模型将与医生合作，助力癌症诊断，提升效率与准确性。

> 关键词：AI，癌症诊断，ECgMPL模型，准确率，泛化能力
