> [结合ESM-2，杜克大学开发高效](https://mp.weixin.qq.com/s/9cXnJ2cMSm6apcyZlVD_-w)PTM感知蛋白质语言模型，实现新SOTA

>

+   杜克大学等研究人员结合ESM-2，开发PTM感知蛋白质语言模型PTM-Mamba，实现新SOTA。

+   模型采用双向Mamba块和门控机制，集成PTM标记，能同时建模野生型和PTM序列。

+   性能评估显示，PTM-Mamba在多项任务上优于基线模型，收敛速度更快。

+   该模型在疾病关联预测等三个基准测试任务中表现出色，还可用于零样本PTM发现。

+   研究为PTM特定蛋白质序列建模和设计提供新机会，有望推动精准治疗创新。

> 关键词：PTM-Mamba，蛋白质语言模型，双向Mamba块，门控机制，PTM标记

+   GPT-4o多模态生图上线引发关注，而DreamTech推出全球首个多模态交互3D大模型Neural4D 2o，支持文本及图像输入与交互编辑。

+   实测该模型在稳定性等方面表现出色，但交互等待时间长且可能排队。

+   对3D设计师利好，借助Neural4D 2o，通过对话就能实现专业建模能力。

+   人人皆可成为3D设计师的时代或将来临。
