> 离谱！DeepSeek数个字母，竟要“反思内耗”八百遍？

>

+   DeepSeek在简单计数问题上过度反思，陷入无效循环，甚至得出错误答案，反映出大模型推理表现存在过度和无效的问题。

+   Anthropic研究发现大模型推理过程的“忠实性”存疑，其展示的推理过程不代表真实思考决策。

+   论文质疑将模型输出中间步骤解读为思考过程的做法，认为LLM擅长模仿，难以验证且具误导性。

+   RLHF、测试推理缩放内部化失败及基础能力脆弱，导致模型效率低、过程迷惑并引入错误。

+   对待AI“拧巴”的认真，应关注关键计算或逻辑节点，不被其冗长思考过程迷惑。

> 关键词：大模型，推理过程，忠实性，RLHF，思考过程

> [RL 是推理神器？清华上交大最新研究指出：RL](https://mp.weixin.qq.com/s/qnHF1g07Q51W_u_wJdflWg) 让大模型更会 「套公式」，却不会真推理

>

+   清华和上交大研究对“纯RL提升模型推理能力”观点提出反对，实验表明引入RL的模型在某些任务表现不如未用RL的模型。

+   研究在数学、编码、视觉推理任务中评估RLVR，发现其虽提升部分准确性，但在高采样时覆盖范围或多样性受限。

+   研究拓展pass@k指标评估大语言模型推理能力边界，避免传统指标缺陷。

+   RL更像能力调控器，非能力创造器，简单视为提升通用智能钥匙过于乐观。

+   该研究揭示RL适用边界，促使优化大模型方案回归本质。

> 关键词：RL，大模型，推理能力，强化学习，模型评估
