> [必装！有效降低Cursor幻觉，提升](https://mp.weixin.qq.com/s/OOmeeuBszJ3wx503QVnR-A)代码生成质量的神奇MCP Server！

>

+   使用Cursor时，因库用法不了解或更新，会产生“幻觉”代码致开发排错困难。

+   Upstash开发的Context7可解决此问题，为LLM提供最新库文档支持，支持超3000个库。

+   其工作方式为实时拉取最新信息、注入Prompt上下文，让LLM生成可靠代码。

+   在Cursor中配置好MCPServer，安装Context7 MCP Server后，开发只需在Prompt末加“use context7”。

+   Context7能提升Cursor代码生成质量，值得安装一试。

> 关键词：Cursor，MCP Server，Context7，代码生成质量，LLM

> [扩散模型还原被遮挡物体，几张稀疏照片也能"脑补](https://mp.weixin.qq.com/s/N6Ceo86jGpZwc3WCme36RQ)"完整重建交互式3D场景｜CVPR'25

>

+   北京通用人工智能研究院等团队提出DP - Recon方法，引入生成式扩散模型，解决稀疏视角3D场景重建难题。

+   该方法有组合式场景重建、分阶段优化、可见性引导SDS权重机制三项关键技术。

+   在权威数据集上，DP - Recon在整体和分解式重建方面均有突破，效果优于基线模型。

+   其应用于智能家居重建、3D AIGC、影视游戏工业化等领域，提升AIGC效率。

+   研究团队来自多校，论文、项目、代码已公开。

> 关键词：3D场景重建，扩散模型，DP - Recon，稀疏视角，组合式重建
