> [CVPR 2025 | 如何稳定且高效地生成个性](https://mp.weixin.qq.com/s/6dF3EFXe_STpjC1e0YGMiA)化的多人图像？ID-Patch带来新解法

>

+   个性化多人图像生成面临身份特征泄露等技术挑战，现有方法如OMG和InstantFamily存在缺陷。

+   提出ID - Patch方案，将人脸信息拆为ID Patch和ID Embedding，解决身份 - 位置对齐问题。

+   ID - Patch能融合多种空间条件，在身份还原、位置匹配指标表现出色，生成效率高。

+   目前人脸特征与身份特征解耦不完全，可通过数据增强提升图像真实感。

+   ID - Patch重新定义多人物图像生成，未来可探索增强面部还原度等方向。

> 关键词：多人图像生成，ID - Patch，身份特征泄露，生成效率，数据增强

> 用多模态LLM超越YOLOv3！强化学习突破多模态感知极限｜开源

>

+   华科、北邮等高校团队推出Perception-R1，是首个在COCO2017 val set上突破30AP的纯多模态开源LLM。

+   该框架通过基于规则的强化学习增强现有MLLM视觉感知能力，采用GRPO技术优化“感知策略”。

+   设计基于规则的奖励函数，包括格式奖励和答案奖励，用二分图匹配解决多主体奖励匹配难题。

+   在多项视觉感知基准测试中表现出色，且通过消融实验验证有效性与可扩展性。

+   Perception-R1为构建下一代智能感知AI系统奠定基础。

> 关键词：多模态LLM，强化学习，视觉感知，Perception-R1，开源
