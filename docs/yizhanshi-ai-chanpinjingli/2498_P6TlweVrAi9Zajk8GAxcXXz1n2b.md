> Harmon：协调视觉表征，统一多模态理解和生成（模型已开源）

>

+   Harmon模型开源，探索统一视觉表征协调图像理解与生成。

+   背景：统一多模态理解生成面临挑战，现有统一模型有三种范式。

+   成果：在多模态理解和文生图基准上表现出色，协同生成理解有潜力。

> 只有通过海量测试才能抓住泛化性的本质吗？

>

+   当深度学习深陷低效Scaling Law，文章探索能否从数学定理判断模型泛化性。

+   大模型时代需更高效泛化性分析策略，人类通过中层表征逻辑交流判断智能可靠性。

+   应用于人工神经网络有两个数学问题，“等效交互解释理论”部分解决相关问题。

+   “与或交互逻辑模型”可拟合神经网络分类置信度计算，分“与交互”和“或交互”。

+   研究从神经网络内在精细交互表征复杂度探索可泛化与不可泛化表征分布。

> 关键词：神经网络，泛化性，中层表征逻辑，等效交互解释理论，与或交互逻辑模型

> [1.53毫秒预判药性，香港理工、川大、鹏城实](https://mp.weixin.qq.com/s/I10fEzgJH5-5suY5AspOWg)验室发布「AI分子透镜」GraphATC

>

+   香港理工、川大、鹏城实验室联合发布GraphATC，借助原子级图神经网络，1.53毫秒可预判药物ATC药性。

+   构建全面的ATC-GRAPH数据集，克服现有数据集问题，覆盖WHO ATC体系五个层级。

+   采用图神经网络建模，引入虚拟原子、化学键及子图融合机制，提升复杂药物分类准确率。

+   GraphATC在多数据集评估中性能最优，实现分类性能和推理速度双重优化。

+   数据集和代码已开源，为AI辅助药物研发提供重要框架。

> 关键词：AI，药物研发，GraphATC，数据集，图神经网络
