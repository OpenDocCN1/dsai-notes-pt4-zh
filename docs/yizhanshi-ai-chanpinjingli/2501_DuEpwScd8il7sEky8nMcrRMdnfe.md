> [精准提取数据太折磨人，试下pip install -U co](https://mp.weixin.qq.com/s/V4xyCkUG88z4GJPXZp__uw)ntextgem，自动生成提示 | 痛快

>

+   ContextGem是专注“结构化提取”的免费开源LLM框架，解决文档数据提取难题，可作RAG前置处理器等。

+   安装简单，通过声明式API定义提取概念，结合LLM实现结构化数据提取，实战效果佳。

+   引入SAT神经网络模型，基于Transformer架构，提升提取质量，优于传统分段方法。

+   以Document为核心，通过Aspect与Concept组织信息，提供多种概念类型。

+   具备自动提示生成等优势，适用于法律合同分析等多领域。

> 关键词：ContextGem，LLM框架，结构化提取，SAT模型，文档处理

> 谷歌开源基于物理模拟的气象模型，能预测暴雨、台风、大干旱

>

+   谷歌开源基于物理模拟的神经通用环流气象模型NeuralGCM，以克服传统气象模型在处理小尺度物理过程的局限。

+   NeuralGCM结合物理模拟与深度学习，其动态核心解决大气方程，物理模拟模块对小尺度过程参数化。

+   独特神经网络架构及编码器、解码器设计，采用端到端训练方法提升性能。

+   经多方面测试，NeuralGCM在预测恶劣天气上表现出色，分辨率提高时谱更准确。

+   该模型在水预算、地理风平衡方面也有良好表现。

> 关键词：NeuralGCM，气象模型，物理模拟，深度学习，开源
