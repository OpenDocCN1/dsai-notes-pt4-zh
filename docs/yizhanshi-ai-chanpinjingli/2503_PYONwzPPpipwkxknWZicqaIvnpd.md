> n8n居然支持中文了？仅需2步，简单到离谱...

>

+   n8n 此前不支持中文，作者在五一把此问题解决，实现汉化，分享2步汉化方法。

+   第一步：从开源项目下载对应版本汉化包并解压，获取解压文件夹路径。

+   第二步：在docker - compose.yml文件添加卷映射与设置默认语言配置，保存后执行指令重启服务。

+   建议下载与n8n版本号一致的汉化包，升级n8n也替换对应汉化包。

+   目前汉化非百分百，仍有部分英文，但相比全英文已有改善。

> 关键词：n8n，中文汉化，开源项目，docker - compose.yml

> 这四大神器让不讲武德的AI爬虫哭了

>

+   AI爬虫无视robots.txt协议，疯狂抓取致服务器压力大，被动防御如IP封禁有局限。

+   Cloudflare AI迷宫自动识别恶意爬虫，用AI生成迷宫页面让其迷路，免费且易用。

+   Anubis通过工作量证明机制区分用户与机器人，大幅减少机器人流量。

+   Nepenthes生成假页面和垃圾内容，干扰AI爬虫训练模型，但耗CPU资源。

+   Zip炸弹用压缩包解压撑爆爬虫内存，简单粗暴。

> 关键词：AI爬虫，反爬技术，数据争夺，robots.txt协议
