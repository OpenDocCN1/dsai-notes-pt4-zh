> Qwen3-0.6B能击败Bert吗？

>

+   作者探讨Qwen3-0.6B小模型在向量搜索、文本分类等领域能否击败Bert，在Ag_news数据集开展实验。

+   实验设置RTX 3090 GPU，对比Bert与Qwen3-0.6B两种训练文本分类模型方法（线性层分类、SFT分类）。

+   结果表明，Qwen3-0.6B（线性层分类）F1值0.949略胜Bert的0.945，但SFT分类耗时更长，RPS更低。

+   Think模式下Qwen3-0.6B准确率略高，但推理慢20倍。

+   实验存在未测试Think模式效果、未考虑长文本等局限。

> 关键词：Qwen3-0.6B，Bert，文本分类，模型对比，实验研究

> Claude 4 把“特朗普是总统”写进

>

+   Claude 4上线，其系统提示词如“角色设定文档”，规定角色定位、行为守则等，像按“剧情走向”执行。

+   强调健康与安全，不鼓励负面、拒绝违法等内容，越狱难，是有道德观的AI助理。

+   对比ChatGPT，Claude 4提示词更像“行为规范手册”，输出规范性格。

+   提示词代表未来“AI人格”实现方式，用其写人设，让Claude “人味十足”。

+   目前AI “AI味”重或因提示词公式化，Claude 4提示词是较有“人味”的说明书。

> 关键词：Claude 4，系统提示词，AI人格，ChatGPT

> 没有银弹，没有免费午餐！KtR用算法思维重构Multi-Agent设计

>

+   研究揭示多智能体系统性能提升问题根源，提出KtR解决框架，强调基于领域知识系统性分解。

+   无免费午餐定理表明不存在万能架构，有效方案需结合问题特性。

+   KtR将领域先验转化为算法蓝图，通过三步实施流程，在背包等问题上实现性能突破。

+   实际业务场景验证KtR能产生商业价值，适合结构化优化等问题。

+   但KtR存在领域知识依赖等局限，未来需提升自动化程度。

> 关键词：Multi-Agent，KtR框架，领域知识，无免费午餐定理，算法思维
