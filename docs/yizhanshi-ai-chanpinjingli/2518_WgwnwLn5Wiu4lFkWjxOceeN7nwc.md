> 自进化零监督多Agent框架： MAS-ZERO

>

+   MAS-ZERO是一种自进化零监督多Agent框架，解决传统多智能体系统依赖人工预设架构、海量标注数据及场景适应性差等问题。

+   它实现“零监督自适应”，具备元代理定制协作方案、动态代码生成、自我进化及成本效率双优等特性。

+   经实际验证，该框架在商业决策等场景表现出色，达到专业咨询公司水准。

+   其在多个基准测试中提升了准确率，控制计算成本，支持多种LLM后端。

+   MAS-ZERO为AI产品开发提供新思路，标志多智能体系统新阶段。

> 关键词：MAS-ZERO，多智能体系统，零监督自适应，动态架构，成本效率

> 飞猪的旅行Agent为什么出圈？因为克制

>

+   作者对比通用AI、Manus与飞猪旅行AI产品，发现飞猪能提供“傻瓜式”旅游攻略，直接搞定机酒预定，实现真闭环、交付结果。

+   飞猪基于旅行场景数据，将景点、酒店等信息无缝集成进攻略，还能提供会员优惠。

+   飞猪旅行Agent是多智能体系统，能并行处理任务，快速生成个性化方案。

+   飞猪“听劝”，对产品功能升级迅速。

+   作者认为2025年C端Agent赛道有拐点，垂类Agent将因数据和场景优势抢跑。

> 我用扣子空间做出超拟人播客Agent，有

>

+   作者对比了扣子空间与NotebookLM生成AI播客的表现，扣子空间更通用，能读取网页生成播客，且因MCP Serves可访问更多网页，分享方便。

+   内容上，NotebookLM页面分三块处理信息，扣子空间在Agent基础上新增播客功能。

+   声线方面，扣子空间默认男女音色，语气、情感优于NotebookLM，但存在抢话、回答短等问题。

+   作者用NotebookLM提示语在扣子空间复现，效果有提升。

+   作者表示不排斥AI播客，但希望知晓所听为AI。

> 关键词：AI播客，扣子空间，NotebookLM，内容，声线
