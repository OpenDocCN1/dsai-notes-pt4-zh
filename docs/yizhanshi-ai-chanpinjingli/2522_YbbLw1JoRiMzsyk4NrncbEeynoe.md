> CVPR 2025 | 解决XR算力瓶颈

>

+   纽约大学和Meta Reality Labs联合研究的Foveated Instance Segmentation方法被CVPR 2025接收，可解决XR算力瓶颈。

+   该方法从算力瓶颈切入，受人类注视模式启发，提出FovealSeg框架及核心模块FSNet。

+   FSNet通过显著性自适应下采样等策略，兼顾分割和分类，减少冗余推理。

+   在多个数据集测试，实现速度与精度双赢，端到端延迟仅84ms。

+   该研究为XR及实时计算密集型任务提供新能效平衡思路。

> 关键词：XR算力瓶颈，Foveated Instance Segmentation，FovealSeg框架，FSNet，实时交互

> 首次解释LLM如何推理反思！西北大学谷歌

>

+   西北大学与谷歌团队质疑传统强化学习与反思关系，提出贝叶斯自适应强化学习（BARL）方法，解释LLM推理反思。

+   BARL将LLM反思性探索转化为贝叶斯自适应强化学习问题，平衡奖励利用与信息探索。

+   合成任务中，BARL能适时切换策略，传统RL则难以泛化。

+   数学推理任务上，BARL准确率更高，耗费token更少，反思更具目的性。

+   团队已放出训练代码和论文。

> 关键词：LLM，强化学习，贝叶斯自适应，推理反思，BARL

> 5700问答对全面评估拷问AI空间感！最

>

+   浙大、成电和港中文团队提出ViewSpatial - Bench，评估VLM多视角空间定位能力，含5种任务，有自动化3D标注流水线，生成超5700问答对。

+   评估发现主流VLMs在多视角空间定位上表现不佳，未真正理解空间结构，训练语料视角分布不平衡。

+   团队开发MVSM优化跨视角空间理解，经针对性训练性能显著提升。

+   MVSM在多种评估场景表现出色，能处理动态轨迹和人机交互场景。

+   该研究为AI获类人空间认知能力提供路径。

> 关键词：AI空间感，ViewSpatial - Bench，MVSM，多视角空间推理，视觉语言大模型

> 《Happy-LLM》项目正式发布，一起

>

+   2025年6月1日，Datawhale开源《Happy-LLM》项目，旨在帮大家深入理解大语言模型原理与训练过程。

+   项目是系统性LLM学习教程，从NLP基本方法出发剖析LLM架构与训练，结合主流代码框架演练搭建、训练LLM。

+   参与者能深入理解Transformer等，掌握预训练到微调流程，实战RAG等前沿技术。

+   项目适合有编程、深度学习及NLP基础者，分基础知识与实战应用两部分。

+   鼓励学习后加入LLM开发行列，丰富开源LLM世界。

> 关键词：Happy-LLM项目，LLM，开源，Transformer，RAG
