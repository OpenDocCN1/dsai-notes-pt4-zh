> 10步优化超越强化学习，仅需1条未标注数...

>

+   Ubiquant团队研究发现，无监督的“单样本熵最小化”（One-shot EM）方法，仅需1条未标注数据和约10步优化，就能提升大模型推理性能，甚至超越强化学习（RL）。

+   EM通过优化模型预测分布、降低熵值，增强模型对正确答案的置信度，且与预训练目标兼容。

+   实验显示，EM在多个数学推理任务上显著提升了模型性能，缩小了与先进RL模型的差距。

+   EM与RL对模型Logits分布影响相反，EM使模型更“自信”，但也可能导致“过度自信”。

+   EM适合基础模型、资源有限及需快速部署场景，未来研究可聚焦训练稳定性等方面。

> 关键词：大模型，熵最小化，强化学习，推理性能，后训练

> 单卡搞定万帧视频理解！智源研究院开源轻量...

>

+   智源研究院联合上海交大等发布超长视频理解模型Video-XL-2，模型权重已开源。

+   Video-XL-2在效果、长度、速度上全面优化，在主流评测基准上达同参数规模开源模型领先水平。

+   模型由视觉编码器、动态Token合成模块、大语言模型构成，采用四阶段渐进式训练。

+   设计效率优化策略，实现单卡对万帧级视频高效推理。

+   该模型在影视分析、异常监测等场景有应用潜力。
