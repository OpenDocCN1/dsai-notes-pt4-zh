## 1️⃣ AI短剧《众神之战》火爆全网

🤖 1个小团队，2个月，一部AI短剧火爆全网...

+   《众神之战》作为AI短剧，由小团队耗时2个月制作，在多平台收获高好评，成AI短剧新标杆。
+   该剧全程用AI技术，从剧本创作到角色生成，融合中西方神话，创意表达有突破。
+   AI打破传统短剧时间与成本壁垒，画面精度对标`UE5`，带来全新视觉与叙事体验。
+   短剧在国内外多平台传播，展示AI对内容产业的颠覆性影响。
+   未来AI短剧有望探索更多题材，制作流程更高效，开拓全球市场。

关键词：AI短剧，众神之战，创意融合，跨平台传播，行业变革

## 2️⃣ OpenAI深夜突发`o3-Pro`，价格暴降

🎯 OpenAI深夜突发`o3-Pro`，价格暴降...

+   6月11日凌晨4点，OpenAI向`ChatGPT`和`API`的Pro用户提供最强模型`o3-Pro`，已可使用。
+   `o3-Pro`能调用多种工具，虽思考时间长，但价格暴降80%，在关键领域及学术评估中表现出色。
+   采用“4/4可靠性”评估标准，`o3-Pro`在数学等方面大幅超越`o1-Pro`和`o3`。
+   OpenAI为付费用户升级`ChatGPT`高级语音功能，增强语调和自然度，支持高效语言翻译。
+   网友认为`o3-pro`更像协作伙伴，带来决策确定性突破。

关键词：OpenAI，`o3-Pro`，模型发布，语音功能，决策确定性

## 3️⃣ OpenAI宣布`ARR`破100亿美元

🤖 速递｜OpenAI宣布`ARR`破100亿美...

+   OpenAI宣布年经常性收入突破100亿美元，较去年显著增长，涵盖`ChatGPT`等产品与服务。
+   目前每周活跃用户超5亿，付费企业客户达300万，距`ChatGPT`发布约两年半。
+   公司计划到2029年实现1250亿美元营收目标。
+   OpenAI面临增加营收压力，每年耗费大量资金用于人才招聘与基础设施建设。
+   OpenAI尚未披露运营成本及是否接近盈利。

关键词：OpenAI，`ARR`，营收目标，活跃用户，付费客户

## 5️⃣ `AI`杯·2025星际争霸2锦标赛夏季赛

🤖 `AI`杯·2025星际争霸2锦标赛夏季赛邀...

+   国内首个`AI`大模型电竞赛事「2025 `AI`杯·星际争霸2锦标赛」开启，由`AIGC`开放社区主办，`Microsoft Azure`、南开大学提供技术支持。
+   报名时间即日起至6月31日，小组赛7月8 - 16日，总决赛7月18 - 19日在上海线下举行。
+   赛事亮点包括激烈线上对决、线上直播，总决赛奖品丰厚。
+   前64名早鸟免费报名，还赠`AI`学习材料等。
+   扫码加入官方赛事群即可报名。
