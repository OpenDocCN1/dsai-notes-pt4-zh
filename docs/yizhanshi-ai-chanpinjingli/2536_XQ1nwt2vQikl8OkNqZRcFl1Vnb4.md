> 98%医生点赞的AI队友，斯坦福实验揭秘...

>

+   斯坦福研究让AI与人类医生组队破解诊断难题，发现AI从“工具”变“队友”，医生诊断准确率飙升10%。

+   实验设AI-first、AI-second与对照组，使用6个真实病例，通过19分制评估准确性。结果AI协作组优于对照组。

+   研究给AI加“吵架”“翻译”“追溯”补丁，让其更懂医生。

+   研究发现AI-second组存在“锚定效应”，AI-first组“对抗性协作”激发深入推理。

+   实验后98.6%医生愿在复杂推理中用AI。

> 关键词：AI，医疗诊断，协作，准确性，锚定效应

> AI记忆伪装被戳穿！GPT、DeepSe...

>

+   约翰·霍普金斯大学与中国人民大学团队设计三套实验，检验17款主流大模型的工作记忆。

+   实验发现多数模型在数字猜谜中无法在“脑内”存数字，是非问答中常出现尺寸悖论，数学魔术里正确率普遍低。

+   LLaMA-3.1-8B在数字猜谜和数学魔术表现相对较好，DeepSeek-R1在数学魔术获39.3%正确率。

+   尚无开源或闭源LLM通过“三关”，意味着要让AI像人“边想边聊”，需补上工作记忆机制。

+   未来或借鉴认知科学，引入可读写“内存格”等方法，让模型学会保留并操纵隐变量。

> 关键词：大模型，工作记忆，实验，LLaMA-3.1-8B，DeepSeek-R1

> 通过对话即可执行DNA、RNA和蛋白质任...

>

+   InstaDeep公司研究人员提出多模态对话智能体ChatNT，通过对话执行DNA、RNA和蛋白质任务，相关研究6月6日发布于《Nature Machine Intelligence》。

+   ChatNT弥合生物学基础模型与对话智能体差距，用户输入序列和英文提示词，它就能解决相关任务。

+   研究人员创建基因组学指令任务数据集，用英语制定任务提供额外元数据。

+   ChatNT在Nucleotide Transformer基准测试中达SOTA，在27项英文基因组学任务中性能与专用模型相当。

+   团队引入校准模型置信度技术，模型解释分析表明ChatNT学会关联生物学相关序列特征。

> 关键词：ChatNT，多模态对话智能体，生物序列，基因组学任务，自然语言LLM
