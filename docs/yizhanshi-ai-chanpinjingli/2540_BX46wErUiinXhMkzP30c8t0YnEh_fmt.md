## 2️⃣ 我用腾讯元宝给Labubu开发了一个商城...

> 🤖

+ 腾讯元宝上线电脑版AI编程模式，代码即写即跑，将写代码变得像聊天对话。
+ 集成腾讯云CodeBuddy能力，支持多种语言在线运行，无需配置环境。
+ 智东西体验该模式，输入不同指令，如制作3D魔方动画、立体翻转卡片等，生成效果各异。

+ AI写代码关键在清晰描述需求，元宝拉低开发门槛，但创意上限靠使用者。

## 3️⃣ 终于有AI视频模型，解决了体操难题。

> 🤖

+ MiniMax发布Hailuo 02视频模型，此前作者预测该公司会推出视频模型，模型上线前放出预告片。
+ Hailuo 02在体操、杂技等复杂动作生成上表现出色，相比其他模型，肢体动作更自然、丝滑，解决了AI视频领域的体操难题。
+ 该模型不仅人物肢体动作有史诗级进化，表演也达到新高度，能实现多种复杂动作与镜头运动。
+ Hailuo 02支持原生1080P，价格便宜，新人有500免费积分。
+ 作者认为AI正不断打破视觉难题，书写新传奇。
