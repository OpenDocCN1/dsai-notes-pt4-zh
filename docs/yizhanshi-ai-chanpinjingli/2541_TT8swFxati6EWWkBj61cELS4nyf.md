> 能自我提升的Agent需要内在的元认知学习能力

>

+   剑桥大学和范德夏尔实验室在ICML 2024发表论文，挑战当前Agent开发核心假设，提出真正自我改进需内在元认知能力。

+   内在元认知学习含元认知知识、规划、评估三组件，可解决外在元认知学习面临的领域迁移失效等问题。

+   技术演进中，从STAR到Voyager再到Generative Agents，元认知能力内在化程度递进。

+   面临灾难性遗忘等挑战，论文提出共享元认知平衡策略及安全框架等应对方案。

+   论文指明Agent发展新方向，即从依赖外在机制转向具备内在元认知能力的自主学习系统。

> 关键词：Agent，内在元认知学习，自我改进，共享元认知，安全框架

> LLM之Agent（十九）|  II-A...

>

+   II-Agent是一个开源智能体框架，致力于成为跨领域全能代理，打破AI应用局限。

+   它具有独特技术架构，如强大LLM、丰富工具集、规划反思机制和智能上下文管理能力。

+   与其他智能体相比，在透明度、自由度、通用性等方面有优势，适用于多领域。

+   可在工作、开发场景助力提效，安装需特定环境和配置。

+   虽面临资源消耗、社区建设等挑战，但发展前景广阔。

> 关键词：II-Agent，开源智能体，大语言模型，应用场景，发展挑战

> 世界模型版《模拟人生》：AI虚拟小人街头...

>

+   研究者提出“虚拟社区”，结合地理空间数据与生成模型，为智能体创建交互式开放世界场景。

+   其具备清理增强数据流程、运行交通系统，机器人也融入其中与“人类”互动。

+   引入竞选和社区助理两项具身化多智能体任务，智能体需规划与社交。

+   实验显示，GPT-4o主干候选人得票率更高，交付任务表现优于携带。

+   作者希望借此助力未来社会智能研究。

> 关键词：虚拟社区，智能体，生成模型，多智能体任务，社会智能研究

> ICML 2025 Oral | NAS...

>

+   来自新加坡国立大学等机构的论文将NAS超网络思想引入Agent领域，提出“智能体超网”概念。

+   该概念不再寻找固定最佳“阵容”，而是依任务难度动态“剪”出定制智能体团队，性能超现有方法11.82%，推理成本仅45%。

+   MaAS框架核心为定义蓝图、智能调度、自我进化，实现了查询感知和双轨优化。

+   在六大主流基准测试上全面超越14个基线方法，通用性、高效性出色。

+   具备跨模型、跨数据集泛化能力及对未知算子归纳能力。

> 关键词：智能体超网，NAS，多智能体系统，MaAS，自动化设计

> AI模型如何解析和控制大脑？「数字孪生」...

>

+   Martin Schrimpf利用人工神经网络构建大脑“数字孪生”，通过对比人类行为、大脑活动与AI模型结果微调模型。

+   他创建Brain - Score开源平台，含近百个人类神经和行为数据集，供研究人员测试AI模型。

+   其团队训练模型生成可改变人类神经活动的句子，有望辅助治疗大脑相关疾病。

+   研究探讨了AI与大脑的相似性、模型解读及伦理考量等问题。

+   Schrimpf认为大脑数字孪生有望实现，可用于优化治疗方案等。

> 关键词：AI模型，数字孪生大脑，Brain-Score平台，大脑疾病治疗，伦理考量
