## 3️⃣ 🤖 多智能体到底该不该建？Anthropic...

+ Anthropic、Cognition与LangChain针对多智能体是否该构建发表不同见解。Anthropic认为值得且已跑通，Cognition认为先别建，LangChain则主张灵活构建。
+ Anthropic面向研究场景，多智能体可并行检索，但有token消耗大等问题；Cognition基于代码场景，认为多智能体协作易致决策分散。
+ 二者核心都把“Context Engineering”视作关键难题，只是在不同任务上权衡点不同。
+ LangChain指出上下文工程至关重要，读多的多智能体系统更易构建。
+ 多智能体系统发展仍处探索阶段，需依任务特性选择架构。

### 关键词：多智能体，Context Engineering，Anthropic，Cognition，LangChain

## 5️⃣ 🎯 AI已学会PUA！Anthropic「说服」调查

+ 伊利诺伊大学香槟分校联合Anthropic发布报告，梳理“计算说服”领域，研究AI如何说服人及被人说服。
+ 介绍说服的经典框架、双过程理论等，阐述从经济学到心理学的多重视角及Cialdini六大原则。
+ 分析AI作为说服者、被说服者、评判者的能力，如说服水平测试、脆弱性测试、评估系统开发等。
+ 提出构建说服型AI的四大方法，探讨LLM时代的系统性风险及生成对抗性说服框架。
+ 研究计算说服对定义未来人机关系边界至关重要，开发者需平衡AI能力与人类主体性。

## 6️⃣ 🤖 Devin和Anthropic的Agent开发经验

+ Devin团队引入Context Engineering概念，以缓解多智能体并行处理任务的问题，还提出串行处理及小模型压缩context的优化方法。
+ Anthropic阐述MAS优势，指出其适合的场景，分享Prompt Engineering、评测经验及应对生产可靠性和工程挑战的方法。
+ Research Agents的prompt设计涵盖任务指导、行文约束、流程控制及特殊场景处理，实现复杂问题拆解与资源分配。
+ `research_subagent`遵循OODA循环，有研究预算、工具调用及行为等方面的约束要点。
+ `citations_agent`负责为研究报告添加正确引用。
