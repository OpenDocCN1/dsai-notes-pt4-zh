> LLM进入「拖拽时代」！只靠Prompt...

>

+   来自NUS、UT Austin等机构研究人员提出“拖拽式大语言模型”（DnD），基于提示词快速生成模型参数，无需微调适应任务。

+   DnD核心优势为极致效率，计算开销比传统全量微调低12,000倍；卓越性能，零样本学习性能比需训练的LoRA模型高30%；强大泛化，仅无标签提示词即可跨领域泛化。

+   实现方法是通过准备训练数据与训练参数生成器，获得“拖拽”能力。

+   效果评估表明DnD零样本学习效果好，在多种任务超越基座LLM，且对比其他微调方法性能更优、速度更快。

+   作者来自新加坡国立大学、德克萨斯大学奥斯汀分校等，研究兴趣聚焦高效机器学习等。

> 关键词：LLM，拖拽式大语言模型，DnD，零样本学习，参数生成

>

> 合成数据>人工数据，绝对性能暴涨超10个...

>

+   北大、MIT等机构提出“合成数据强化学习”框架，仅需简单任务定义，就能全自动生成高质量合成数据。

+   该框架分知识引导合成、难度自适应、高潜力样本选择与强化学习三步，实现模型高效自适应学习。

+   实验显示，该方法在多领域基准测试中性能大幅提升，数据效率高，超越监督微调，媲美人工数据RL。

+   研究发现人工数据指导边际效益递减，且弱模型能训练出强于自身的模型。

+   此框架为大模型专业领域适配提供新方案，降低微调门槛，具有重要意义。

> 关键词：合成数据，强化学习，大模型，数据效率，模型适配
