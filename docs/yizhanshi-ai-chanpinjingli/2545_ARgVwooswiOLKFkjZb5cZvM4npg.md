## 2️⃣ 7B小模型超越DeepSeek-R1：模...

> 🤖

- Sakana AI提出新方法，让教师模型模仿人类教师，依据已知解决方案输出逐步解释，不再从头解决问题。
- 用此方法训练的7B小模型，在传授推理技能上比671B的DeepSeek-R1更有效，还能训练比自身大4倍的学生模型。
- 新方法解决传统训练效率低及依赖教师模型能力的问题，与传统RL方法结合可提升性能。
- 成本上，新方法训练32B学生模型仅需单个计算节点一天，传统方法需数月。
- 定性分析表明，新方法解释更清晰，有助于学生模型学习。

> 关键词：小模型，教师模型，推理技能，新训练方法，成本

## 3️⃣ 谷歌AI Agent刚开源！多任务智能体...

> 🤖

- 6月26日凌晨，谷歌开源AI Agent框架`Gemini CLI`，将Gemini大模型融入终端。
- `Gemini CLI`亮点众多，集成谷歌搜索、MCP协议等功能，可定制提示与指令，实现自动化任务。
- 其集成超强编码助手Gemini Code Assist，支持多种编程语言，能依需求开发功能、修复代码。
- 现用谷歌账号可使用100万token上下文窗口的Gemini 2.5 Pro模型，有免费使用额度。
- `Gemini CLI`刚开源就在Github获超9000颗星，受关注度高。

## 5️⃣ 通用生物医学Agent，可由「任务」自主...

> 🤖

- 斯坦福、基因泰克等开发通用生物医学AI智能体Biomni，能自主执行生物医学研究任务。
- Biomni结合LLM推理、检索增强规划与代码执行，无需预定义模板。
- 基准测试显示，Biomni在多类生物医学任务中实现强大泛化。
- 它可提升科研效率、助力药物研发与临床应用，但也存在覆盖领域有限等局限。
- Biomni已上线供免费使用，有望重塑生物医学研究。

> 关键词：生物医学，AI智能体，LLM，基准测试，泛化能力
