> 你的Agent电脑助手正在踩雷！最新研究...

>

+   上海AI Lab等团队推出CUA安全测试基准RiOSWorld，评估Computer-Use Agent安全风险。

+   RiOSWorld搭建真实交互环境，设492个风险测试案例，从两维度评估风险行为。

+   研究对市面热门MLLM-based CUA测试，发现多数风险意识弱，“翻车率”高。

+   现阶段多数研究存在测评环境缺乏真实性、风险类别不全面的限制。

+   RiOSWorld为CUA安全发展指明方向，强调安全对AI的重要性。

> 关键词：Computer-Use Agent，RiOSWorld，安全风险，AI

> 只用2700万参数，这个推理模型超越了D...

>

+   受大脑机制启发，Sapient Intelligence研究者提出分层推理模型HRM，仅2700万参数，1000个训练样本，在复杂推理任务性能卓越。

+   HRM核心设计源于大脑分层结构与多时间尺度处理，由四个可学习组件组成。

+   引入近似梯度、深度监督、自适应计算时间等机制，节省资源且提升性能。

+   实验显示HRM在ARC-AGI、数独和迷宫基准测试表现出色，推理可视化呈现不同策略。

+   HRM克服标准Transformer计算限制，相比强化学习等训练方法有优势。

> 关键词：分层推理模型，HRM，AI推理，大脑机制，模型性能
