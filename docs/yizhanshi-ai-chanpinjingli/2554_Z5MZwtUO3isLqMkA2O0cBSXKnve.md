> 开源DeepSeek R1增强版：推理效率快200%，创新AoE架构

>

+   德国TNG公司开源DeepSeek R1增强版DeepSeek-TNG-R1T2-Chimera，采用全新AoE架构。

+   该架构基于MoE架构，能提升性能、加快推理效率、节省token输出，推理效率比R1-0528快200% 。

+   AoE架构通过线性时间复杂度构建子模型，插值合并父模型权重张量生成变体。

+   构建子模型时关注路由专家张量合并，以提升推理能力。

+   使用PyTorch框架实现模型合并，生成具有不同特性的子模型。

> 关键词：DeepSeek R1增强版，AoE架构，推理效率，开源，混合专家架构

> [腾讯出手了！微信支付MCP入局](https://mp.weixin.qq.com/s/dJk8_2RjzOFUJGf-lq_Hzw)

>

+   腾讯元器悄悄上线微信支付MCP，有体验版和正式版，含获取支付二维码、查询支付状态等工具。

+   可通过在智能体设置赞赏功能、对话收费，作者以“卖点魔方”智能体测试，展示接入流程。

+   实际测试发现通过提示词嵌入智能体付费不稳定，作为商业模式有致命缺陷。

+   微信支付MCP目前仅在腾讯元器可用且不稳定，但释放出AI加速与商业场景底层融合信号。

+   未来支付或无缝嵌入与智能体交互，开启全新商业范式。

> [为什么我玩MCP少了？](https://mp.weixin.qq.com/s/EAMCvEQxyvN_1flStlvUMg)

>

+   MCP有爽点，如流量可观，能解决复杂现实问题，像高德地图MCP找咖啡馆、三句话搞定论文解读音频网站。

+   但MCP也存在安装部署复杂、依赖特定环境、封装产品有局限、优质插件稀缺且维护难等难题。

+   尽管如此，MCP被认为是通往AGI的必经之路，大模型如“大脑”，MCP似“手脚”。

+   现阶段调用成熟API对追求稳定易用场景或更优，不过仍对MCP未来充满期待。

+   作者还提到开源计划及魔搭MCP挑战赛。

> 关键词：MCP，AI，API，开源，挑战赛

> [Agent框架OWL原理详解](https://mp.weixin.qq.com/s/aYF0y5VVK_jjovbBk3yFCQ)

>

+   OWL是一个优秀的开源agent框架，对camel库进一步封装，在GAIA基准测试中表现出色。

+   它采用多agent架构，涉及任务改写、任务计划环节，user agent与assistant agent交互，critic model可选人类或LLM。

+   Agent实现继承ChatAgent类，具备记忆管理与工具调用功能，有专门化和任务管理等子类。

+   工具组件丰富，涵盖搜索、学术等11类，部分工具如BrowserToolkit实现复杂。

+   文中以查询王小波作品为例展示了交互细节。

> 关键词：OWL框架，agent，多agent架构，工具组件，交互细节
