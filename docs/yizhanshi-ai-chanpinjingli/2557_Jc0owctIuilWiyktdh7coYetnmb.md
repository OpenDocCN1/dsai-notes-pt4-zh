> [DeepSeek推理最高提速6倍！开源研](https://mp.weixin.qq.com/s/2uefJV_JiIhHg6wRFyKLRw)究：加装「思维进度条」，计算量减少30%

>

+   特拉维夫大学团队为LLM推理任务装“进度条”，可控制推理深度与速度，该模型已开源。

+   提出“思维进度向量”（TPV）量化推理进度，通过干预TPV实现模型“超频”与“降频”。

+   实验显示，“超频”使DeepSeek推理最高提速6倍，token数减少近6倍，计算量减少30% 。

+   TPV干预方法效果优于基线方法，且与提示策略互补，结合使用性能平均提升66% 。

+   在不同提示策略和推理序列长度下，TPV均表现可靠。

> 关键词：LLM，推理加速，思维进度向量，开源，DeepSeek
