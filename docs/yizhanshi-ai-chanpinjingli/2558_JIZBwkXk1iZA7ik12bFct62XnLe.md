> [AI发现医生看不见的隐藏心脏病风险，近9](https://mp.weixin.qq.com/s/SWyRacLNjAHSq8qGVq6evA)0%准确率远超人类专家｜Nature子刊

>

+   约翰霍普金斯大学研究出多模态AI模型MAARS，用深度学习处理原始MRI图像，预测心源性猝死风险，准确率达89%。

+   MAARS采用3D视觉Transformer架构，避免人工解读主观性，能挖掘隐藏的纤维化瘢痕模式。

+   其通过多模态数据融合与3D-ViT技术，精准识别心脏纤维化瘢痕，40 - 60岁人群诊断准确率达93%。

+   MAARS具备可解释性，通过Shapley值分析和注意力机制可视化辅助制定个性化医疗方案。

+   研究团队计划将MAARS算法扩展至更多病种，推动AI在心血管疾病中的应用。

> 关键词：AI，MAARS模型，心脏病风险预测，多模态数据融合，可解释性

> 大模型刷数学题竟有害？CMU评估20+模型指出训练陷阱

>

+   CMU团队研究发现，仅强化学习（RL）训练的大模型能将数学推理技能广泛迁移，监督微调（SFT）训练的模型迁移有限甚至无迁移。

+   实验评估20多个模型在数学、其他推理及非推理任务上表现，提出迁移能力指标（TI）评估迁移能力。

+   结果表明，模型迁移能力与微调方法、规模、架构有关，微调方法最关键。

+   RL微调模型在提升特定领域表现时保留原有能力，SFT会扰乱词条损害泛化能力。

+   RL或为实现可迁移推理发展的关键。

> 关键词：大模型，数学推理，迁移能力，RL，SFT

>
