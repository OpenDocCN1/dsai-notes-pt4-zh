2万行代码，Claude Code完成9...

+   资深Mac开发者Indragie用Claude Code开发“Context”App，2万行代码95%由AI完成，仅花一周便上架App Store。

+   Indragie摸索出“人机协作”开发教程，人类思考决策，AI执行试错，通过“下指令 -> AI 编码 -> 运行 -> 甩回错误 -> AI 修复”循环推进项目。

+   Claude Code虽有局限，但学习纠错能力强，掌握“预激活”等技巧可提升其输出质量。

+   AI还能完成生成模拟数据、自动化发布流等杂活。

+   开发者指出AI代码存在冗余，上下文管理有挑战，人类程序员价值正从“如何写”转向“写什么”和“为何写”。

关键词：Claude Code，人机协作，AI编程，上下文工程，开发变革
