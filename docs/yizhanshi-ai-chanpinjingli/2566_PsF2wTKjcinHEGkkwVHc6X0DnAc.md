### 4️⃣ 简单了解下 CUDA Green Context

+ 文章基于 FlashInfer 相关实现，介绍 CUDA Green Context，其在 CUDA 12.0+ 引入，提供资源隔离功能。
+ 它与普通 Context 区别在于，能让上下文执行互不干扰，降低多线程应用上下文切换性能损失，提高 GPU 使用率。
+ 展示了 FlashInfer 中引入 CUDA Green Context 的代码，主要通过特定函数生成资源描述符、创建 Green Context 及 Stream。
+ 作者尝试用其实现 kernel overlap，但性能比顺序执行版本差。
+ 该功能处于实验阶段，可关注后续演进。

关键词：CUDA Green Context，资源隔离，FlashInfer，kernel overlap

### 5️⃣ 国内首个免费提供的深度研究，反而有市面上...

+ 秘塔深度研究上线，是首个将深度研究作为免费基础功能的产品。
+ 秘塔通过拆分任务分段强化学习降低成本、保障准确性，并用新颖交互打开算法黑箱，提升用户对搜索结果置信度。
+ 研究结果呈现形式多样，如语音讲解、创新标注等，还能生成互动研究报告。
+ 经测试，其搜索结果全面准确、条理清晰，能把握用户需求。
+ 秘塔通过技术创新降低成本，坚持免费服务理念。

关键词：秘塔，深度研究，免费，技术创新，交互优化
