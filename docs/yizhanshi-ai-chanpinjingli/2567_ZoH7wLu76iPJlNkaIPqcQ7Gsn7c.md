> 500美元刷新SOTA！训练成本砍到1/...

>

+   香港城市大学等团队发布图像 - 视频生成模型Pusa V1.0，仅用约500美元成本微调，在图像转视频实现SOTA。

+   该模型引入VTA机制，采用帧感知的流匹配目标函数，实现最小、非破坏性优化。

+   Pusa V1.0能执行多种视频生成任务，具备零样本扩展能力。

+   实验表明其超越同类微调模型，参数更新数少，保留基础模型先验知识。

+   模型已开源，名称源于“菩萨”，象征丰富功能。

> 关键词：Pusa V1.0，视频生成，VTA机制，SOTA，开源
