## 1️⃣ 3D生成补上物理短板！首个系统性标注物理...

🤖

+ 南洋理工大学-商汤联合研究中心S-Lab及上海人工智能实验室合作提出`PhysXNet`，这是首个系统性标注物理基础3D数据集，含超26K带注释3D物体。
+ 团队还提出`PhysXGen`，是面向真实物理世界的3D生成框架，能实现从图像到真实3D资产的生成。
+ 团队设计人在回路标注流程解决物理属性标注难题。
+ 实验显示，`PhysXGen`相比基线流程在多维度有显著性能提升。
+ 该研究填补3D资产与真实世界差距，将吸引多领域关注。

关键词：3D生成，物理属性，数据集，生成框架，标注流程

## 2️⃣ 四款扩散大语言模型全部破防？上交&上海A...

🤖

+ 上交与上海AI Lab研究发现扩散语言模型（`dLLMs`）存在架构安全缺陷，提出`DIJA`攻击框架，可令多个`dLLMs`生成有害内容。
+ `dLLMs`因双向建模、并行解码及缺乏局部安全对齐，更易被攻破。
+ `DIJA`攻击无需训练和改写参数，自动生成攻击提示词，具结构自然等优势。
+ 实验显示多款`dLLMs`在`DIJA`攻击下溃败，其安全短板源于设计特性。
+ 论文开启“掩码安全性”新研究方向，呼吁设计针对性拒绝机制与对齐训练流程。

关键词：扩散大语言模型，安全缺陷，`DIJA`攻击，掩码安全性

+ [论文地址](https://arxiv.org/abs/2507.11097)
