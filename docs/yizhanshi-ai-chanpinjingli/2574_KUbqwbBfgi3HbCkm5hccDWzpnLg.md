> AI界的“抖音”，ShellAgent新...

>

+   ShellAgent是Myshell新上线平台，类似众创分享平台，强调个性化艺术表达，兼具创作与分享功能。

+   它让普通人无需编程，用语言就能制作应用并分享，开发流程自动且对小白友好，还能一键修复错误。

+   支持二次创作（Remix），类似抖音“全民模仿”，可基于他人作品快速修改。

+   相比AI编程，更适合普通人，降低技术门槛，开启“病毒式”传播可能。

+   创作者用一句话灵感，就能制作出类似“梵高”式应用。

> 关键词：ShellAgent，AI应用制作，二次创作，低技术门槛，分享平台

> OpenAI拿下IMO金牌，职业数学家崩...

>

+   OpenAI在IMO获金牌引发关注，科技巨头为此争夺，而数学家Dave White深感自我认同崩塌，认为这如同“死亡”。

+   加密教授Adam Cochran从哲学视角回应，指出人生本就不断经历身份重建与崩塌，真正的“自我”超越单一标签。

+   此事反映出AI在数学领域能力提升，给数学家、知识工作者等带来身份危机。

+   但人类的原创性难以被替代，拥有独特才能和应用视角的人或因AI更强大。

+   人们应坚信可重新定义自我，适应AI带来的变化。

> 关键词：OpenAI，IMO金牌，身份危机，原创性，自我定义
