> Code is Cheap，Show m...

>

+   作者认为Spec将成为新编程语言，软件开发重心正从写代码转向写prompt+审阅代码。

+   类比大模型为编译器，虽与传统编译有别，但从功能等价角度可理解为编译。

+   未来Prompt重要性将超Source Code，应纳入版本控制，且开发需增加确认阶段。

+   Prompt会动态演进，以DAG流程图形式组织，软件开发界面将以Prompt为中心。

+   尽管当前AI Coding未达理想，但Spec开发或致软件开发民主化，程序员或退出舞台。

> 关键词：AI编程，Spec语言，软件开发范式，Prompt，代码生成

>

+   2025年7月25日，上海AI实验室发布『书生』具身全栈引擎Intern - Robotics并开源，直击具身行业痛点。

+   Intern - Robotics解决了具身智能领域标准不统一、数据成本高、研发周期长的难题。

+   其为具身智能技术发展提供了系统性解决方案，推动具身大脑迈向量产时代。

> WAIC逛展必备AI：上传多图一键转...

>

+   ListenHub为WAIC打造特别功能，能将上传的多图一键转为播客。

+   此功能可帮助梳理听演讲、看展会时拍摄图片中的信息，加深记忆。

+   目前iOS可在商店直接下载ListenHub，安卓暂时使用网页版listenhub.ai 。

+   安卓版即将上线。

+   该AI功能为逛WAIC提供便利。
