> 监督学习未死，一题训练五小时起飞！华人学...

>

+   加拿大滑铁卢大学华人学者团队提出One-Shot Critique Fine-Tuning新方法，本质是监督学习，让模型分析答案好坏。

+   该方法仅需一题数据、多个解答与点评，5 GPU小时就能完成微调，资源消耗低。

+   在数学和逻辑推理任务实验中，模型准确率显著提升，且对任务和种子选择不敏感，稳定性好。

+   其效果归因于强调批判性学习、引入多视角输入、训练信号强泛化性。

+   该方法开源，为资源有限者提供高性价比推理能力增强方案。

> 关键词：监督学习，One-Shot CFT，大模型推理能力，低资源消耗，开源

> 浙大打造全球最大类脑计算机，拥有20亿个...

>

+   浙江大学脑机智能全国重点实验室发布全球规模最大类脑计算机“Darwin Monkey（悟空）”，采用Darwin 3芯片构建，逼近猕猴大脑神经元规模。

+   “悟空”集成多台服务器，引入先进封装技术提升性能，部署了DeepSeek等应用。

+   团队还开发了达尔文类脑操作系统，实现资源智能调优。

+   该成果为AI发展奠基，为脑科学研究提供新手段。

> 科学家首次实现修正线粒体DNA突变，治愈...

>

+   荷兰科学家在《PLOS Biology》发表研究，利用DdCBE成功纠正线粒体DNA突变，突破线粒体疾病治疗难题。

+   研究在原代成人细胞中有效恢复线粒体功能，在患者来源类器官和成纤维细胞中构建并校正突变。

+   采用脂质纳米颗粒（LNPs）实现修饰RNA（modRNA）编码的线粒体碱基编辑器高效递送。

+   对基因校正后的成纤维细胞进行脱靶编辑分析，未发现显著脱靶编辑。

+   该研究标志着治疗性编辑线粒体DNA迈出重要一步，距临床应用还有数年。

> 关键词：线粒体DNA突变，DdCBE，基因治疗，LNPs，modRNA
