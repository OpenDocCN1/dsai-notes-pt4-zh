> 一文搞懂大模型：OpenAI开源GPT-...

>

+   2025年8月6日，OpenAI发布GPT-OSS系列模型，为2019年GPT-2后首次开源大语言模型。

+   模型采用MoE架构、创新注意力机制、RoPE位置编码，还运用MXFP4量化技术。

+   训练使用高质量英文数据集，经预训练和后训练提升性能。

+   可通过Hugging Face等主流平台部署，120B版需H100，20B版消费级硬件即可。

+   Ollama本地部署简单，支持图形界面和命令行。

> 关键词：OpenAI，GPT-OSS，大模型，开源，模型部署

> OpenAI开源GPT-OSS，英伟达发...

>

+   8月6日凌晨，OpenAI发布可本地运行的GPT-OSS，开启小模型赛道竞争，国内大厂近期也频繁发布小模型。

+   NVIDIA Research发表论文称小模型是Agentic AI的未来，其核心观点为未来实用高效的AI智能体来自小模型。

+   小模型已足够强大，成本低，且灵活高效，适合Agent架构。

+   在真实开源智能体系统评估中，60%-70%的LLM调用可用SLM替代，性能几乎不损，成本立降。

+   OpenAI和NVIDIA竞争焦点已从参数量转向成本、部署和专精化。

> 关键词：小模型，OpenAI，英伟达，Agentic AI，开源

> Google重磅上线通用世界模型Genie...

>

+   Google发布世界模型Genie 3，与传统AI视频模型不同，它类似即时计算的游戏引擎，能实时响应生成画面。

+   此前Google有相关实验项目，Genie 3解决了前辈们交互延迟、时长等矛盾，实现实时交互，时长提升至数分钟。

+   该模型在VR、游戏、电影等行业有巨大潜力，可解决内容匮乏等问题，改变创作与体验方式。

+   当然，Genie 3也存在互动时长短、无法精确模拟等局限，且尚未对公众开放。

+   总之，它证明了世界模型这条路是可行的，将开启新的创作时代。

> 关键词：Genie 3，世界模型，AI视频，实时交互，行业变革

> 一手实测OpenAI新开源的GPT OS...

>

+   OpenAI开源GPT-OSS系列大语言模型，包括gpt-oss-120b和gpt-oss-20b，采用MoE的Transformer架构，支持128k上下文，在多方面性能超o1与GPT-4o。

+   可通过Ollama或OpenRouter体验，Ollama有UI且默认gpt-oss-20b，OpenRouter价格低。

+   实测gpt-oss编程能力未达预期，数学题表现尚可，复杂推理题易卡住。

+   gpt-oss权重在Hugging Face可下载，原生量化为MXFP4格式，与众多平台提前合作。

+   作者期待后续GPT5发布，准备持续测试。

> 关键词：OpenAI，GPT-OSS，开源模型，性能测试
