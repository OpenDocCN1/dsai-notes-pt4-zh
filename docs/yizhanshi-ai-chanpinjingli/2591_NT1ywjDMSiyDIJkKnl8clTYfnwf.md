> 奥特曼深夜官宣：OpenAI重回开源！两...

>

+   OpenAI于2025年8月8日深夜官宣重回开源，发布两款模型gpt-oss-120b和gpt-oss-20b，系自GPT-2后首次开源。

+   gpt-oss-120b适用于高推理场景，gpt-oss-20b适用于低延迟场景，二者在多项基准测试中表现强劲。

+   模型采用先进预训练和后训练技术，许可证宽松，支持微调，有完整思维链等亮点。

+   其预训练成本低于50万美元，与Responses API兼容，推理投入可配置。

+   此次开源为开发者提供强大工具，降低部分群体准入门槛。

> 关键词：OpenAI，开源模型，gpt-oss，推理能力，后训练

> DeepSeek的GRPO会导致模型崩溃...

>

+   DeepSeek提出GRPO算法提升训练效率，但Qwen团队研究表明，GRPO在token级别应用重要性采样，会导致训练不稳定，使模型崩溃。

+   Qwen团队提出新算法GSPO，将重要性采样提升到序列级别并归一化，解决了GRPO的问题。

+   实验显示，GSPO训练效率更高，在CodeForces任务中表现优于GRPO。

+   针对MoE模型，GSPO无需“路由技巧”即可稳定收敛，简化了训练。

+   GSPO或成大语言模型后训练强化学习新标准。

> 关键词：GRPO，GSPO，大语言模型，强化学习，模型稳定性
