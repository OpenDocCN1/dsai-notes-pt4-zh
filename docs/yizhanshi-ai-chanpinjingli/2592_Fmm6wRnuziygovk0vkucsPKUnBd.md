> 又是王冠：27M小模型超越o3-mini...

>

+   00后清华校友王冠团队提出2700万参数的开源分层推理模型HRM，超越o3-mini-high等大模型，推理不依赖思维链。

+   HRM模仿大脑机制，克服Transformer计算局限，核心技术包括分层循环、收敛机制，近似梯度、深度监督及自适应计算时间。

+   HRM在ARC-AGI测试、极端数独、复杂迷宫任务表现出色。

+   虽被指参数小、泛化性差，但“仿脑”设计抗过拟合，被看好是神经网络进步。

+   王冠拒绝马斯克邀请，创办Sapient Intelligence致力于打造新大模型架构。

> 关键词：HRM，小模型，仿脑设计，分层推理，王冠

> [蛋白质基座的GPT时代来了？！](https://mp.weixin.qq.com/s/WmGTYPO9gTm2XJ-Rjqvm-Q)

>

+   清华大学AIR周浩副教授课题组联合上海人工智能实验室发布蛋白质基座模型AMix-1，以新方法论构建，实现向GPT时代跨越。

+   AMix-1有四大“超能力”：成长有规律、能“顿悟”理解蛋白结构、看例子就能“仿写”设计新蛋白、进化能力无上限。

+   其设计的蛋白通过湿实验，最优变体活性提升50倍。

+   模型权重、代码等已公开。

+   AMix-1支撑虚拟生物实验室的蛋白质生成与进化工作。

> 关键词：蛋白质基座模型，AMix-1，通用智能，湿实验，虚拟生物实验室

> [别焦虑！不会用AI也不会被淘汰，工程师老](https://mp.weixin.qq.com/s/CzRZC2jv_8CqZq-aDfqnNA)哥实测各类工具：10倍生产力神话太夸张了

>

+   工程师科尔顿·沃奇测试多款AI开发工具，发现AI写样板代码快，但在理解大型代码库等方面存在问题，需工程师引导。

+   “AI 10倍生产力”是神话，工作流程复杂，AI无法全面提升效率，且生成内容有缺陷，还会导致工程师依赖问题。

+   不会AI没关系，应选择喜欢的工作方式，老板也不应让工程师陷入被AI替代的焦虑。

+   科尔顿·沃奇曾创办教育类AI工具公司，对AI在工作场景应用见解独到。

+   总之，AI可辅助提升部分效率，但无法解决工作中的所有问题。
