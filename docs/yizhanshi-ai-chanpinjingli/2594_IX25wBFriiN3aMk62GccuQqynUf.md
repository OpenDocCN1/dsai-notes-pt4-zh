> 实测会自我反思会分身的Agent Agnes

>

+   Agnes是一款办公协作工具，能自我反思、修改、打分并分身，可完成多种任务。

+   Deep Design模式下，它能对设计作品自我评估优化，整合多种功能，满足多样需求。

+   Wide Research功能可调动多个Agent协作调研，快速生成结构化内容。

+   Agnes上线即全面开放，无邀请码。

+   它是多智能体协作机制与通用Agent框架，能拆解任务，提供省心服务。

> 关键词：Agnes，办公协作，自我反思，多智能体协作，全面开放

> 第一个能帮你做生意的Agent来了。

>

+   阿里国际站升级的Accio Agent，是面向外贸、海外的toB产品，已积累200万企业级客户。

+   作者体验Accio Agent，发现其能快速筛选符合要求的厂商，还能一键询单，大大节省时间。

+   该Agent可打通从设计到生产的链路，规避侵权风险，并结合热点生成文创产品及营销策略。

+   面对大型活动采购需求，Accio Agent能有逻辑地拆解任务，提供场地、物料等全方位服务。

+   Accio Agent展现出强大系统性，通过垂直领域场景和数据形成行业壁垒，实现高效落地。

> 关键词：Accio Agent，外贸，厂商筛选，活动采购，垂直领域

> 百度终于有一个能打的Agent了！让我极...

>

+   作者体验百度旗下文库内测通用Agent——GenFlow，发现它能同时处理多项任务，速度快且效果好，如3分钟完成调研、PPT制作等6个任务。

+   GenFlow可联动百度网盘，基于网盘资料回答问题，首创干预模式，执行任务中能随时打断补充需求。

+   它具备长记忆功能，能记住之前跑的任务。在国内网络环境稳定使用，有百度账号即可。

+   从GenFlow可看出百度做Agent的决心，扎根大众应用场景，解决用户高频刚需办公问题。

+   海报功能有待优化，未来还会接入百度地图工具、新增绘本功能。

> 关键词：百度，GenFlow，Agent，办公应用，AI工具
