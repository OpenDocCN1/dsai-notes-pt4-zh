> 推理成本骤降75%！gpt-oss用新数...

>

+   OpenAI在gpt - oss采用MXFP4数据类型，使推理成本暴降75%，推理速度提升4倍，内存占用降至BF16模型的1/4。

+   MXFP4全称微缩放4位浮点数，通过乘公共缩放因子，兼顾数据量与精度，且不要求硬件原生支持FP4。

+   改变数据类型可降低模型运行成本，因权重存储和内存带宽受数据类型影响。

+   MXFP4并非新概念，虽有缺陷，但已有研究表明低精度数据在大语言模型场景影响小。

+   OpenAI在gpt - oss仅用MXFP4，显示其对大语言模型的适用性。

> 关键词：gpt - oss，MXFP4，推理成本，数据类型，大语言模型

> 错信AI幻觉，一男子用溴化钠替代食用盐，...

>

+   美国一60岁男子因轻信ChatGPT建议，用溴化钠替代食盐，致体内溴含量严重超标，引发溴中毒和妄想症。

+   医生推测男子可能使用ChatGPT 3.5或4.0，虽未获取日志，但自行搜索发现AI回应未提供健康警告。

+   GPT-5上线后，询问替代氯化钠方法，其给出低钠盐等方案，明确不建议用溴化钠替代食用盐。

+   此案例反映出用户使用AI获取健康建议时可能因误读信息陷入困境。

+   AI在健康领域应用需更严谨，用户也应谨慎对待AI给出的建议。

> 关键词：ChatGPT，溴中毒，AI幻觉，健康建议，GPT-5

> 不吹不黑：昆仑万维这个新模型有点炸

>

+   昆仑万维SkyReels-A3模型上线，能用音频驱动数字人视频，团队测试10个案例，从真人到抽象画均表现不错。

+   该模型基于DiT框架，针对听声生成视频场景设计，能生成连贯长视频，精准控制每一帧。

+   技术亮点包括解决长视频拼接问题、建立全模态框架、嘴型同步精准、混合学习训练、严格筛选数据集。

+   与其他模型相比，SkyReels-A3在音频与口型对齐方面表现出色。

+   技术发展迅速，数字人视频能力显著提升。

> 关键词：昆仑万维，SkyReels-A3，音频驱动，数字人视频，技术亮点
