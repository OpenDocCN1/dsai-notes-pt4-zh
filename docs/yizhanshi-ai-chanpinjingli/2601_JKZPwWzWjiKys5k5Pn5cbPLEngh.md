> 妙笔生维：线稿驱动的三维场景视频自由编辑

>

+   研究人员提出基于线稿的三维场景视频编辑方法Sketch3DVE，相关技术论文发表于SIGGRAPH 2025 。

+   该方法赋予用户基于简单线稿重塑三维场景视频的能力，可实现物体添加、移除或替换。

+   算法原理涉及选定首帧绘制掩码与线稿，利用三维重建、点云编辑等技术完成操作传播。

+   效果展示表明该方法能生成高质量、三维一致性好且相对真实自然的编辑结果。

+   Sketch3DVE为三维场景视频编辑提供新范式，降低用户操作门槛。

> 关键词：三维场景视频编辑，线稿，Sketch3DVE，AI算法

> 观点｜英伟达：小语言模型才是 AI 智能...

>

+   NVIDIA Research和佐治亚理工学院研究提出，小型语言模型（SLMs）或成AI智能体未来主导力量，因其在效率、灵活性和经济性上更具优势。

+   SLMs能在普通设备运行，参数规模通常10亿以下，在常识推理、工具调用等任务表现出色，部分已可取代大语言模型（LLMs）多数角色。

+   智能体架构适合模块化设计，可采用“SLM优先、LLM辅助”模式，降低成本并提高响应速度。

+   SLMs经济性、灵活性优势显著，还能推动AI普惠化，但普及面临对LLM路径依赖等障碍。

+   研究团队提出转换算法助力从LLM到SLM转型，并通过案例验证SLMs应用潜力。

> 关键词：小型语言模型，AI智能体，大语言模型，模块化，经济性

> 英伟达新研究：小模型才是智能体的未来

>

+   英伟达论文指出，小模型在Agent任务中，相比大模型更经济灵活，实测也印证其观点。

+   小模型通过优化硬件资源和任务设计，更高效执行任务，推理成本更低，适配本地或边缘部署。

+   部分研究者对小模型通用性、经济性存疑，英伟达认为小模型可通过微调及推理调度优化解决。

+   小模型面临基础设施适配、市场认知度低、评估标准缺失等挑战。

+   英伟达给出将大模型转换为小模型的方法，网友也展开相关讨论。

> 关键词：小模型，大模型，Agent任务，推理成本，模型转换
