> 国产AI路由系统开源逆袭！仅用19%成本...

>

+   上海人工智能实验室开源Avengers-Pro多模型调度路由方案，集成8个大模型，平衡性能与成本。

+   其核心机制通过嵌入、聚类、评分，动态匹配最适合模型处理任务，可灵活切换性能与性价比。

+   实验中该方案性能超越GPT-5-medium 7%，以19%成本达Gemini-2.5-Pro同等性能。

+   该方案实现性能-成本平衡，形成帕累托前沿，不同权衡系数下可灵活选择模型。

+   Avengers-Pro证明智能调度路由方案潜力，将在大模型应用带来突破。

> 关键词：AI路由系统，Avengers-Pro，多模型调度，性能成本平衡，开源

> 首个3D动作游戏专用VLA模型，打黑神话...

>

+   淘天集团未来生活实验室团队提出首个3D动作游戏专用VLA模型CombatVLA，已被ICCV 2025接收。

+   该模型基于3B参数，经动作跟踪器采集数据，以“动作思维”格式，通过三阶段渐进式训练优化。

+   实验显示，CombatVLA在战斗理解基准测试超越现有模型，任务成功率高于人类玩家，推理速度提升50倍。

+   团队还开发动作跟踪器、构建CUBench评测集及AoT数据集，并将模型无缝嵌入动作执行框架。

+   未来团队将增强模型场景理解能力，拓展其在更多游戏及物理世界的应用。

> 关键词：3D动作游戏，VLA模型，CombatVLA，动作跟踪器，CUBench评测集
