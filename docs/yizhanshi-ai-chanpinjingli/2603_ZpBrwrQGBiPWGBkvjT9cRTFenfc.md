## 1️⃣ ChatGPT负责人深度复盘：我们做错了...

> 🤖

> + OpenAI副总裁Nick Turley复盘GPT-5风波，称未保留GPT-4o是失误，未来非必要不下线，并将提供下线时间表。
> + ChatGPT产品哲学是高效解决问题，非延长用户时长，情感依赖是“副作用”，将通过多种方式应对。
> + 负面反馈未影响ChatGPT使用率，模型自动选择器会保留，满足不同用户需求。
> + 产品增长源于模型能力提升、科研与产品复合创新、传统增长手段，用户需学会“分配任务”思维。
> + ChatGPT是临时原型，对产品形态有宏大愿景，未来或突破聊天框形式。

## 3️⃣ 深度｜Agent 全球爆发，Agent ...

> 🤖

> + AI Agent 正迈向“数字生产力”时代，京东云、Flowith、KPMG 等纷纷入局，但落地面临稳定性、数据质量、模型管理、调试监控等痛点。

> + AI Agent 需“联网检索 + 实时数据接入”能力，智能搜索成刚需，RAG让知识检索更“聪明”。
> + 小宿智能搜索赋能AI Agent数据获取，具备全球化数据覆盖、多模态搜索等优势。
> + 支撑Agent发展，稳定的Agent Infra不可或缺，小宿科技可助力Agent应用搭建。

## 5️⃣ 重磅团队领衔，国内首部人工智能软硬件跨境...

> 🤖

> + 2025年8月21日，国内首部人工智能软硬件跨境数据标准启动编制，政策与市场推动智能软硬件产业发展，同时跨境数据合规问题凸显。
> + 该标准以大厂方法论和律师经验为蓝本，汲取“大厂智慧”，形成可推广的合规模式。
> + 标准强调实操落地，覆盖数据分类分级及常见跨境业务场景合规指引。
> + 创新“场景化”指引，结合高频业务场景明确数据跨境规范。
> + 标准计划2025年8月立项，2026年6月发布，欢迎相关企业参与起草。

> 关键词：人工智能，软硬件跨境数据标准，数据合规，场景化指引，标准编制
