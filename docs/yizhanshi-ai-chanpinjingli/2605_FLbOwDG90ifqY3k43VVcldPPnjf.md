> 马斯克的Grok 2开源了，但好像又没完...

>

+   8月24日，马斯克官宣Grok 2开源，模型权重文件500GB已上线Hugging Face，但不能商用与用于训练模型。

+   Grok 2采用Grok 2社区许可协议，非通用开源许可证，使用限制多。

+   Grok 2性能下滑，Elo等级分降至第68名，Arena综合榜排第75名。

+   相比新开源模型，Grok 2性能不突出，开源协议限制多。

+   马斯克此时开源，或为兑现承诺与给Grok 3开源制造话题。

> 关键词：Grok 2，开源，模型性能，许可协议，马斯克

> 马斯克高调开源 Grok-2，却被 De...

>

+   8月24日，马斯克官宣开源Grok-2，这并非xAI首次开源AI模型。

+   Grok-2技术亮点包括支持128K tokens上下文等，但与竞品相比性能欠佳，如gpt-oss-120b在GPQA测评中准确率远超Grok-2。

+   Grok-2开源但有限制，与DeepSeek-V3.1的MIT开源协议不同。

+   本地部署Grok-2硬件要求高，成本昂贵。

+   马斯克开源有节奏，期待6个月后开源的Grok 3。

> 关键词：Grok-2，开源，AI模型，硬件要求，性能对比

> OpenAI重大发现：GPT-4b mi...

>

+   OpenAI与Retro Bio合作，用GPT-4b micro设计出新型山中因子变体，重编程效率提高50倍。

+   GPT-4b micro与GPT-4o架构相同，使用新训练方法和生物学数据集，推理时能处理64000个token。

+   借助该模型，对SOX2和KLF4重新设计，变体组合显著提升干细胞重编程效率。

+   RetroSOX/KLF混合物在DNA损伤修复试验中表现更好，更有效减少DNA损伤。

+   特定领域专业化模型结合领域知识，能加快科学问题的突破进展。

> 关键词：OpenAI，GPT-4b micro，山中因子，干细胞重编程，DNA损伤修复
