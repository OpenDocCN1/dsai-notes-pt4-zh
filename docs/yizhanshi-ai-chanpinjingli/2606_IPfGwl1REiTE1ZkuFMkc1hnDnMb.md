> [0.6B这种小模型到底有啥用？](https://mp.weixin.qq.com/s/dMB0FsgT_-WQDlTbX8O0GA)

>

+   针对群友工单意图分类无资源问题，建议ollama cpu部署0.6B的qwen3模型。

+   0.6B模型虽智能不足，但在高并发搜推、格式转换及轻量信息抽取等工业场景实用。

+   可收集数据微调0.6B模型，成本低，操作简便。

+   英伟达论文指出小LLM是Agent未来，大模型做复杂任务，小模型做高并发任务。

+   真正的智能系统应是大小模型协同。

> 关键词：小模型，工业场景，微调，大小模型协同，Agent

> 美图用AI拉爆画质修复，我无损高清了20...

>

+   美图旗下美图秀秀、Wink和Roboneo，利用AI实现自然的画质修复，能在几十秒内修复视频，保留原始状态并清晰画面。

+   Wink的画质修复功能强大，可针对不同场景如视频、图片、2D动漫、商品图等进行针对性修复，还支持批量上传。

+   Wink的全能修复能自动检测图片问题并修复。

+   美图跟进主流生成技术演进，用MoE等模型解决用户拍糊、拍暗等问题。

+   AI画质修复帮用户找回模糊记忆，美图让专业修复变得更普及。

> 关键词：美图，AI画质修复，Wink，MoE模型，图像视频修复
