> 聊聊大模型推理系统之 Arrow：自适应...

>

+   来自中国科学技术大学、北航与京东的研究团队提出Arrow自适应调度机制，解决PD拆分架构核心瓶颈。

+   Arrow创新设计无状态实例与弹性实例池，实现零等待时间资源重配。

+   基于SLO实时调度，利用TTFT强可预测性和TPOT特性做调度决策。

+   实验显示，Arrow在多种真实负载下性能显著超越现有系统。

+   该成果为LMaaS领域指明高效弹性技术路线，助力算力高效利用。

> 关键词：大模型，推理系统，Arrow，自适应调度，PD拆分架构

> 面壁 MiniCPM-V 4.5 发布：...

>

+   面壁发布MiniCPM-V 4.5，8B参数，性能越级超越72B，为最强端侧多模态。

+   首个高刷“鹰眼级”模型，兼顾性能与效率，多项能力达同级SOTA。

+   核心技术包括3D-Resampler实现高刷视频理解，统一OCR与知识推理学习等。

+   开源在Github、Hugging Face、ModelScope等平台。

+   实现从“看PPT”到“理解动态画面”的视觉能力升级。

> 关键词：MiniCPM-V 4.5，多模态，高刷，端侧友好，开源
