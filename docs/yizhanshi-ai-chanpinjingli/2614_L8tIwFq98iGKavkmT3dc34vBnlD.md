> 数据说话：「男人活的不如狗」｜七组数据

>

+   以泰坦尼克号数据为背景，对比男性与狗的生还率，分析不同舱位、性别、年龄乘客的生存概率，发现“妇女儿童优先”原则执行更严格，有钱生存率更高。

+   利用Quick BI制作“大数据驾驶舱”展示数据，该工具类似Power BI等，有中国特色功能。

+   通过分析，Jack的死亡不完全因穷，其作为三等舱年轻男性逃生几率低。

+   工具使用阿里瓴羊“智能小Q”，9月9日正式开放，数据来自OpenML及维基百科。

+   借助AI分析数据，挖掘出更多真实信息。

> 关键词：泰坦尼克号，数据，智能小Q，Quick BI，AI

> 不愧是中国机器人，乒乓打得太6了

>

+   清华姚班本科生苏智等在论文中提出结合模型规划与强化学习的分层框架，让宇树G1机器人实现亚秒级稳定连续对打乒乓球。

+   高层规划基于模型规划器导航球轨迹、预测击球信息，低层基于强化学习生成动作。

+   实验中机器人击球率达96.2%，回球率92.3%，还能对拉106拍。

+   乒乓球对机器人交互要求高，需瞬间完成多种操作。

+   机器人还能自主对战。

> 关键词：人形机器人，乒乓球，分层框架，强化学习，模型规划

> 吴恩达最新来信：是时候关注并行智能体了

>

+   吴恩达指出并行智能体正成为提升AI能力新方向，多个智能体协作可加快任务完成速度。

+   与依赖数据和算力提升AI能力不同，并行智能体可在提升性能同时减少等待时间，且大模型token成本下降使其可行。

+   协调多个智能体有挑战，将复杂任务拆分给多个智能体并行执行并不容易。

+   两篇论文展示并行智能体研究进展，如让大语言模型并行生成多样候选方案及利用多个大语言模型提升性能。

+   吴恩达称在最优利用并行智能体方面仍有大量研究与工程工作待探索。

> 关键词：并行智能体，AI能力提升，大语言模型，任务分解，协同工作
