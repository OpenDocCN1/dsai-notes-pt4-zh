## 1️⃣ 爆料！DeepSeek将发布全新模型

> 🤖

+ 据彭博社消息，DeepSeek团队正研发全新AI Agent模型，目标剑指OpenAI。
+ 该模型能代替用户执行多步骤操作，只需很少提示，基于DeepSeek之前版本改进。
+ DeepSeek创始人梁文锋推动团队在今年第四季度发布新模型。
+ 最快四周后可能见到这款新模型。

## 2️⃣ 重大福利！OpenAI免费开放ChatG...

> 🤖

+ 2025年9月4日凌晨3点50分，OpenAI向免费版ChatGPT开放Projects功能，此前该功能仅付费用户可用。
+ 免费版Projects功能更新，支持最多5个文件上传，新增颜色、图标选择及个性化设置，有记忆控制选项。
+ 该功能可集中管理相关内容，提升使用效率，类似个人版ERP或CRM。
+ 使用时创建项目、设置记忆、添加文件即可提问，对专业领域帮助大。
+ 网友认为此功能对健身教练等也实用，还可创建专属角色对话。

## 4️⃣ JavaScript进阶之路2：对象、集合、类全解析

> 🎨

+ 对象：介绍定义、属性添加/删除、检查属性、获取属性数量、对象与数组相互转换及遍历等操作。
+ `Map`集合：能实现键唯一值可重复，讲解创建、元素添加/修改/删除、检查元素、获取大小、转换为数组及遍历等方法。
+ 类：是创建对象的语法结构，包含实例字段、构造函数、实例方法，还介绍私有属性/方法及继承的使用。
+ 私有成员：私有属性和方法用`#`前缀定义，通过存取器和内部方法访问或修改。
+ 继承：子类可复用父类属性和方法，还能扩展和重写。

> 关键词：JavaScript，对象，`Map`集合，类，继承
