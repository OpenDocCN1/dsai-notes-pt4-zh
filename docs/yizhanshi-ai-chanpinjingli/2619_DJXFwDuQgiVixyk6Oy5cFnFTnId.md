> 长视频AI数字人来了！字节×浙大推出商用...

>

+   字节跳动商业化GenAI团队联合浙大推出商用级长时序音频驱动模型InfinityHuman，打破长视频场景技术局限。

+   该模型攻克身份漂移和细节失真难题，通过 “由粗到细” 策略生成高分辨率视频。

+   可应用于电商带货、企业培训、自媒体创作等场景，对中文语音支持效果出色。

+   实验表明其在视觉真实感、时序连贯性等指标上优于主流基线方法。

+   字节跳动VIVID Avatar团队持续深耕音视频数字人技术，推动AI生成实用化。

> 关键词：InfinityHuman，长视频，数字人，AI技术，商用场景

> 科研AI的进化论！系统梳理600+数据集...

>

+   上海AI Lab等联合发布科学大语言模型全景式综述，梳理600+数据集与模型，涵盖发展历程、数据基础等多方面。

+   2018 - 2025年，Sci-LLMs历经迁移学习、规模化等四次范式转移，能力不断拓展。

+   综述覆盖六大科学领域，分析通才与专才、文本与多模态模型特点，指出多模态是发展趋势。

+   强调高质量数据对Sci-LLMs的关键作用，剖析数据生态不足及痛点。

+   展望科学智能体，提出构建闭环“智能体-数据”生态系统，实现自我进化。

> 大型语言模型正在掏空和填满你的钱包

>

+   生成式AI每年或为全球经济增2.6万亿 - 4.4万亿美元，正引发商业革命。

+   大型语言模型（LLM）在客户服务、内容创作等多领域应用，降本增效，提升客户满意度与个性化。

+   研究表明LLM生成内容质量与人类相当，成本大幅降低。

+   业务流程自动化、内部知识管理等方面，LLM也显著提升效率。

+   企业需积极拥抱这一技术革命。

> 关键词：大型语言模型，生成式AI，商业应用，降本增效
