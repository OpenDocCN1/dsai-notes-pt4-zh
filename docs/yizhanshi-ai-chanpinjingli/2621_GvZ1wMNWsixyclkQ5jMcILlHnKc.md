## 1️⃣ 🤖 OpenAI重组GPT-5「灵魂」团队！...

+ OpenAI重组ChatGPT「个性」研究团队，模型行为团队并入后训练团队，前负责人Joanne Jang负责新的OAI Labs。
+ OpenAI发文揭秘AI「幻觉」原因，称行业「应试」评估体系迫使AI猜测答案。
+ 研究表明主流评测奖励幻觉行为，调整评测机制可奖励模型表达不确定性。
+ Joanne Jang将探索人与AI协作新交互界面，超越聊天和智能体范式。
+ OpenAI回应幻觉常见误解，建议更新评估体系，重罚「自信犯错」。
