> Agent 开发高频坑：大模型拆任务总漏...

>

+   作者调用硅基云端API时，发现大模型在实际运行中拆分任务会漏项，测试环境却正常。

+   经排查，差异在于实际运行添加了输出约束，其中response_format参数会干预模型输出采样过程。

+   大模型通过逐token生成输出，采样参数打破“唯最高置信度”原则，影响最终输出。

+   response_format会因强制满足JSON格式而改变token采样权重，导致输出丢失关键内容。

+   解决方案是移除该参数，采用“模型原生输出 + 自定义脚本解析”，并注意不同框架处理逻辑差异。

> 关键词：大模型，输出约束，采样参数，response_format，任务拆分

> 美团悄悄上线了生活Agent，懒人的春天...

>

+   美团上线生活类Agent“小美”，界面简洁，需获取权限，能快速点外卖，流程丝滑，可记住过往订单和收货地址，支持跨区点单。

+   “小美”能设置定时任务，结合美团外卖和闪购，满足多种定时下单需求，还可担任健康、吃喝等多种顾问角色。

+   目前“小美”在打车、订票等方面功能有限，复杂任务处理能力待提升，存在神券不会膨胀的BUG。

+   总体而言，“小美”虽刚上线存在不足，但仍为用户带来诸多便利，值得期待。

+   AI助力生活服务，“小美”开启便捷生活新体验。
