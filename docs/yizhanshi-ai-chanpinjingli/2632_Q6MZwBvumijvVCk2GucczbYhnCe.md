> 刚刚，李飞飞空间智能新成果震撼问世！3D...

>

+   李飞飞团队创业公司World Labs发布Marble预览版，单图或文本即可生成“永久存在、可自由探索”的3D世界。

+   该模型将空间智能推向“无限探索”时代，支持零成本浏览器导航、高斯点云导出与多段拼接，几何干净、风格多样。

+   与谷歌Genie不同，Marble生成的3D世界永久存在且免费。

+   目前用户可加入候补名单试用，模型主要面向3D环境创建。

+   模型在几何结构、风格和场景规模上有显著提升。

> 关键词：李飞飞，Marble，空间智能，3D世界生成，AI技术

> 稚晖君机器人炸场：全球首秀“真男人必会的...

>

+   智元灵犀X2机器人全球首秀韦伯斯特空翻，验证了机器人本体硬件的高可靠性，展示其应对复杂环境的能力。

+   灵犀X2系列还有为作业智能打造的灵犀X2-W和支持双形态切换的灵犀X2-N 。

+   灵犀X2预计2025年下半年规模化出货，2026年底出货量达数千台。

+   智元8月发布的灵创平台助力灵犀X2完成动作，该平台是AI加成的机器人多模态内容生成与编辑工具。
