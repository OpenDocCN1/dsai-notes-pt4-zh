## 1️⃣ SciReasoner、Seedream...

+ 上海人工智能实验室等提出SciReasoner科学推理基础模型，提升跨领域泛化与推理保真度；字节跳动等推出Seedream 4.0多模态图像生成系统，达SOTA水平。

+ 南洋理工大学等用方差感知采样等增强MMR1多模态推理；阿里团队借VCRL动态课程学习框架优化大语言模型数学推理。

+ 厦门大学等提出Tree-GRPO基于树搜索的分组代理强化学习，腾讯构建Hunyuan3D-Omni统一3D资产可控生成框架。

+ 莫斯科高等研究院等设计AutoIntent自动化机器学习工具，北大等提出TrustJudge解决LLM评估不一致问题。

+ 快手团队用CE-GPPO控制强化学习策略熵，南洋理工大学等提出SHINE解决图像合成物理一致性问题。

关键词：AI算法，多模态，强化学习，图像生成，模型评估

## 2️⃣ 太重要了，文档智能中的LLMs：综述、进展、和未来趋势

+ 数字化时代文档数量剧增，LLMs推动文档智能发展，但面临文本结构、答案溯源等困境。

+ 论文给出可落地工程蓝图，涵盖全面文献回顾、当前开发范式分析等。

+ 介绍文档解析、专用LLM微调等四大核心技术，探讨两大主流技术范式。

+ 梳理数据集、实现、基准和指标，为技术评估和落地提供依据。

+ 指出检索噪声等挑战，提出开发灵活RAG架构等未来工作方向。

关键词：文档智能，LLMs，RAG，长上下文，技术范式

## 3️⃣ 比 Context7 更靠谱：Exa-c...

+ Exa-code通过索引超1B+文档等，在代码幻觉评估中表现超越流行网页搜索工具。

+ 其核心技术为专为AI构建的搜索引擎及高效返回上下文，减少AI无效信息处理。

+ 工作时混合搜索网页，提取并排序代码示例，按需返回内容。

+ 在更新配置、调用API等场景对编码代理有用。

+ 安装便捷，可通过特定端点启用，调用可在提示中用`use exa-code`。

关键词：Exa-code，代码幻觉，LLM，编码代理，上下文工具

## 5️⃣ 缺数据也能拿SOTA？清华&上海AI L...

+ 清华与上海AI Lab提出SimpleVLA-RL，破解机器人RL数据采集成本高、泛化能力不足两大瓶颈。

+ 该方案基于`veRL`框架，涵盖交互式轨迹采样、结果奖励建模等优化设计。

+ 实验显示，其在标准基准测试中达SoTA性能，有限数据下也表现优异。

+ 模型训练中展现自主探索能力，出现“Pushcut”新策略。

+ 研究为VLA模型高效训练与泛化能力提升开辟新路径。

关键词：SimpleVLA-RL，机器人RL，VLA模型，泛化能力，Pushcut
