> 实测OpenAI Sora2，我找到了两个隐藏踩坑点！（附邀请码）

>

+   Sora2是兼具视频和音频生成的模型，参数少，输出视频清晰度差，与主流视频模型相比功能有差距。

+   其App类似AI版抖音，可社交，支持合拍、点赞等操作，Remix能参考视频修改。

+   人脸和物理一致性保持好，克隆音色较便捷，但网页版与手机系统混合深，操作不便。

+   新建Cameo需身份验证，念数字时用中文更快。

+   网传Sora2会有普通和Pro两个版本。

> OpenAI突然发布Sora 2：好一个“AI版抖音”！

>

+   OpenAI发布Sora 2，依托其打造“AI版抖音”Sora iOS社交app，在北美率先推送。

+   Sora 2主打更遵循物理定律、可控性更强，还能注入现实元素，音视频同步生成。

+   Sora app支持创作、二次创作，有“客串”功能，用户对形象有控制权。

+   实测生成视频画质低，ChatGPT Pro用户可体验更高质量的Sora 2 Pro模型。

+   官方将发布Sora 2的API，有网友对比了Sora 2与快手可灵的效果。

> 关键词：OpenAI，Sora 2，AI版抖音，视频生成，客串功能

> Anthropic 发布 AI Agent 上下文工程指南

>

+   Anthropic发布AI Agent上下文工程指南，呼应“上下文工程取代提示词工程”观点，指出构建AI应用重心转变。

+   上下文工程是提示词工程演进，对构建强大智能体至关重要，因LLM存在“上下文腐烂”与注意力稀缺问题。

+   长时间跨度任务可用压缩、结构化笔记和多智能体架构解决上下文窗口限制。

> 又来了！OpenAI 发布 Sora 2...

>

+   9月30日，OpenAI发布新一代视频生成模型Sora 2及iOS社交应用Sora，Sora 2在多方面显著提升。

+   Sora应用类似TikTok，核心功能“Cameo”可将用户形象放入AI生成场景。

+   OpenAI采取多项安全措施，如推荐算法、内容展示设置、青少年保护等。

+   应用已在美国和加拿大iOS平台邀请制推出，ChatGPT Pro用户可试用Sora 2 Pro。

+   社区对该技术反应两极，OpenAI强调盈利计划及用户福祉目标。

> 关键词：OpenAI，Sora 2，视频生成模型，社交应用，安全措施
