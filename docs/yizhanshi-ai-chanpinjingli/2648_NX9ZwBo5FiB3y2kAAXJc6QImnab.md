> Sora2是OpenAI进的一小步，但也...

>

+   Sora2效果实测，在商业广告、探店等多种视频创作上表现出色，突破在于分镜处理能力强，降低创作门槛，且有cameos功能可上传活体素材制作视频。

+   Sora2使用有策略性限制，如网页版免费需邀请码，对参考图、视频时长等有规定。

+   其可能带来商业广告、短视频口播等领域的变革，或催生“脸优”岗位。

+   OpenAI借Sora2打造AI短视频平台，这对世界影响存争议。

+   作为短视频平台，Sora2成功与否存疑，因OpenAI产品运营能力待考。

> 关键词：Sora2，OpenAI，短视频，AI创作，cameos

> 等了大半年的Qwen3-VL终于也开源了...

>

+   Qwen3-VL于2025年10月3日开源，云栖大会期间阿里还开源了其他11个模型。

+   相比Qwen2.5-VL，Qwen3-VL在vision encoder、projector、llm decoder部分均有改进。

+   实测中，Qwen3-VL在表格识别、色彩把握、推理计算等方面表现出色，但网页复刻、目标对比等能力有待提升。

+   整体而言，Qwen3-VL相比之前有很大提高，处于开源VL模型前列。

+   作者期待推出更小参数的平民版模型。

> 关键词：Qwen3-VL，模型开源，模型改进，实测，大模型

> 刚刚，OpenAI Sora 2重磅登场...

>

+   OpenAI 官宣新一代 AI 视频模型 Sora 2，在物理准确性、逼真度等方面刷新 SOTA，首次实现音画同步。

+   Sora 2 基于海量视频数据预训练和后训练取得突破，解决了诸多 AI 穿帮问题，支持多镜头、多风格连贯成片。

+   全新 iOS 社交 App——Sora 带来新玩法，可将自己“投影”进故事，有独特分发逻辑。

+   Sora 2 在安全与治理方面采取多层审核等措施。

+   OpenAI 表示会继续优化 Sora 2，提升世界模拟准确性。

> 关键词：OpenAI，Sora 2，AI视频，社交App，安全治理
