> Pepper：开源版的 ChatGPT

>

+   Pepper是一个可学习实现类似ChatGPT Pulse主动式、实时响应AI助手能力的开源项目。

+   它采用主动式智能体循环，与传统模式不同，能主动抓取总结新邮件等。

+   技术亮点包括实时事件驱动、异步工具调用、统一Context Store及多智能体架构。

+   项目处初期，实现简单，利于开发者学习借鉴。

+   项目github地址为

+   [https://github.com](https://github.com/agentica-org/pepper)/agentica-org/pepper

+    。

> 关键词：Pepper，开源项目，实时响应，多智能体架构，主动式智能体循环

> ChatGPT 变身 App Store...

>

+   10月6日，OpenAI宣布Booking等应用在ChatGPT上线，用户可在对话中完成多种操作，「对话即应用」时代来临。

+   开发者可基于Model Context Protocol和Apps SDK构建应用，未来或形成「AI应用商店」。

+   谷歌、Meta等科技巨头因自身利益考量，对入驻ChatGPT持保留态度，「AI入口」竞争激烈。

+   ChatGPT面临公平性、数据隐私等问题，OpenAI将出台相关机制与政策。

+   此次变革有望重构互联网分发体系，但最终结果受多种因素影响。

> 关键词：ChatGPT，AI入口，应用集成，数据隐私，互联网分发体系

> Anthropic官方站台，颠覆认知：给...

>

+   Anthropic提出给模型“松绑”理念，认为应从“约束模型”转向“解放模型”，让其自主决策，如开启Web Search开关，模型就能自主完成研究任务。

+   推荐Claude Code SDK构建智能体，它具上下文管理、智能体记忆等功能，可提升智能体性能。

+   企业选智能体用例应关注业务价值，Claude Code SDK可规模化，Anthropic还在构建相关平台能力。

+   官方平台有内部协同优势，已从简单API发展为完整生态系统。

+   未来将结合高阶抽象、可观测性、记忆能力，形成自我改进飞轮，给Claude配备计算机提升能力。

> 关键词：Anthropic，模型松绑，Claude Code SDK，智能体，企业应用
