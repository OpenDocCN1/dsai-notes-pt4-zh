> 在微信中用 Google 登录，很难吗？

>

+   作者开发“基于LLM的个性化实时快讯”工具，开发登录功能时发现微信内Google OAuth登录失败，因Google 2021年起禁止在嵌入式WebView中进行OAuth登录。

+   作者测试多款产品，均无法在微信等应用内通过Google登录，认为可隐藏入口、提示浏览器打开或研究更好方案。

+   作者用Claude Code解决此问题，符合谷歌安全规范，分享用AI编程诀窍在“context engineering”。

+   建议传统程序员多用AI，初级程序员掌握更多问题解决能力。

+   作者还用AI采集、处理AI资讯发布到《AGI Hunt》实时AI快讯群。

> 关键词：LLM，AI编程，Google登录，context engineering，AI资讯

> Claude Code 推出插件功能

>

+   Anthropic宣布Claude Code支持插件系统，开发者可用一条命令安装定制工具集合。

+   插件包含斜杠命令、子智能体等四类扩展，可按需开关，减少冲突。

+   使用插件很简单，通过特定命令可添加市场、浏览安装或直接安装特定插件。

+   企业能配置自动安装市场，用户也能创建自己的插件和市场。

+   插件功能已公测，有望成为Claude Code生态的重要进化。

> 关键词：Claude Code，插件功能，AI工具，生态进化
