## 3️⃣ 月费 35 元！ChatGPT Go 开...

ChatGPT Go 是 OpenAI 推出的低价入门订阅计划，月费 35 元，目前已开放亚洲 18 个发展中国家。

相比免费版，它有更高的 GPT-5 使用额度、基础功能额度及 2 倍上下文长度。

但与 Plus、Pro 版比，它存在不能用 Codex 编程、高级语音和视频生成受限、不能用 Agent 及切换旧版模型等限制。

理论上切换 IP 到支持地区，可用 Apple 礼品卡或全币种信用卡付款订阅。

AI 工具正走向普及，ChatGPT Go 是 OpenAI 在该趋势下的布局。

关键词：ChatGPT Go，订阅计划，地区限制，功能对比，AI 普及

## 4️⃣ 微调已死？Google 和斯坦福论文指出...

Google 的 ReasoningBank 和斯坦福的 ACE 两篇论文，探讨 AI 从自身经历学习的新范式，绕开微调找解决方案。

ReasoningBank 是经验管理系统，含记忆提取、双向学习、智能检索组件，实验效果显著。

ACE 将模型分三角色，采用增量更新机制，在基准测试提升明显。

两项研究均观察到涌现行为，记忆项和上下文随时间优化。

AI 正从“无状态工具”向“有记忆智能体”转变，“活提示词”和“会学习记忆”时代或将来临。

关键词：AI 学习范式，ReasoningBank，ACE，持续学习，自我改进

## 5️⃣ 一篇关于 AI Agent 设计理念的深度思...

业界实现 Agent 有流程智能化和智能体智能化两种流派，前者强调流程可控，后者注重自主探索。

为兼顾任务成功率与探索能力，需融合确定性流程与自主探索，可从规划反思、工具使用、记忆机制三方面着手。

在工具使用上，尝试用 RL 方法让 Agent 自适应学习工具使用策略。

上下文工程通过调度算法管理上下文窗口，记忆机制则助 Agent 持续进化。

未来 Agent 驱动应用将朝沉浸式导航、炫酷交互等方向发展。

关键词：AI Agent，设计理念，融合架构，工具使用，记忆机制
