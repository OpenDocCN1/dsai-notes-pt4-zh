> 藏师傅想解决 Claude Code 最...

>

+   因Anthropic操作及国内模型支持，维护Claude Code环境变量繁琐，作者想写软件解决。

+   在GPT - 5和Claude Sonnet 4.5帮助下，作者开发开源项目ai - claude - start。

+   该项目可快速配置多模型API数据，解决Claude Code换模型启动费劲问题。

+   项目支持npm和npx安装，通过简单命令完成配置，使用方便。

+   项目构建过程中GPT - 5作用大，作者还分享了发布到npm的过程。

> 8美元“驯服”DeepSeek-V3.2...

>

+   腾讯优图实验室提出Training-Free GRPO，以8 - 18美元低成本实现671B模型强化学习，突破传统RL训练高成本局限。

+   该方法核心是不修改模型参数，通过多路径探索、强化学习奖励等四步更新经验库指导模型行为。

+   在数学推理和网页搜索场景，它提升了模型性能，还减少工具调用次数。

+   相比传统RL方法，其训练成本大幅降低，适合长尾细分等场景。

+   此方法已开源，未来将集成到Youtu - Agent框架。

> 关键词：Training-Free GRPO，强化学习，低成本，大模型，开源

> OpenAI、Anthropic、Dee...

>

+   OpenAI、Anthropic、DeepMind 联手研究语言模型安全防御评估，提出应假设攻击者自适应。

+   研究提出通用自适应攻击框架，用梯度下降等方法绕过 12 种防御机制，多数攻击成功率超90%。

+   实验评估多种防御技术，如基于提示、对抗训练、过滤模型、基于秘密知识的防御，发现其在自适应攻击下脆弱。

+   未来防御研究需纳入更强攻击评估，防御方法开发者不应依赖单一攻击策略。

+   现有评估流程有缺陷，当前防御缺乏泛化能力，难以抵御新型攻击。

> 关键词：LLM，安全防御，自适应攻击，评估缺陷，通用攻击框架
