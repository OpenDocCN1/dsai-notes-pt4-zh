> 多模态大模型首次实现像素级推理！3B参数...

>

+   香港理工大学和腾讯ARC Lab提出首个统一像素级多模态大模型UniPixel，能完成指代、分割、推理三大任务，已被NeurIPS 2025收录且代码、数据、Demo全开源。

+   UniPixel在架构设计上革新，引入提示编码器、对象记忆体、掩码解码器三大关键模块，有三类视觉提示统一编码等技术亮点。

+   采用模块化、分阶段训练策略，在多数据集上训练，提升适应能力。

+   在10个公开基准测试集上实验，在分割、区域理解等任务中性能领先。

+   UniPixel是多模态AI走向“细粒度理解”的里程碑。

> 关键词：多模态大模型，像素级推理，UniPixel，开源，NeurIPS 2025

> 速递｜成立两年估值6亿美元：AI文档Re...

>

+   Reducto成立两年，完成7500万美元B轮融资，估值达6亿美元，月收入增长七倍。

+   该公司将传统OCR技术与视觉语言模型（VLMs）结合，理解复杂文档并转换格式。

+   VLMs虽有优势，但存在“幻觉”问题，需与传统OCR软件结合。

+   Reducto每份文档需经约13个模型处理，声称比传统OCR更精准。

+   其客户包括法律AI初创公司Harvey等。

> 关键词：Reducto，AI文档，OCR，视觉语言模型，融资

> 速递｜Firefox浏览器将Perple...

>

+   Firefox浏览器将Perplexity作为首个AI搜索合作伙伴，用户可获对话式搜索体验，答案附带引用来源。

+   此前该集成功能仅在特定市场测试，因积极反馈将推广至全球桌面端，并计划登陆移动端。

+   此外，Mozilla多账户配置功能已全面开放，还在测试整合Google Lens视觉搜索功能。

+   Firefox此次动作旨在让用户在现有浏览器中选择AI驱动搜索选项。
