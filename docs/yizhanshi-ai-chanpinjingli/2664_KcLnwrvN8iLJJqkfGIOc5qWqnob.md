> 🤖

> Meta用40万个GPU小时做了一个实验...

>

+   Meta等机构研究者用40万GPU小时实验，探索强化学习Scaling Law，提出预测性框架刻画RL性能与算力关系。

+   基于框架设计ScaleRL训练配方，经大规模实验验证其表现与框架预测曲线高度一致。

+   研究总结出三条关键原则，ScaleRL整合现有成熟方法实现可预测扩展。

+   ScaleRL在性能与效率上超过现有RL配方，增加算力时仍保持预测一致性。

+   该论文是LLM强化学习扩展的首个开源、大规模系统性研究，具参考价值。

> 关键词：强化学习，Scaling Law，ScaleRL，LLM，预测性框架

> 马斯克亲自点名Karpathy迎战Gro...

>

+   Karpathy称AGI仍需十年，虽业界高估当前AI水平，但通向AGI之路已现，只是难题众多，如强化学习信号稀薄、模型崩塌等。

+   马斯克点名Karpathy与Grok 5编程大战，Karpathy拒绝，更愿合作。

+   Karpathy认为10年是乐观时间表，LLM取得进展但距AGI仍有大量工作。

+   他怀疑简单算法实现AGI的可能，认为RL非全部答案，看好“智能体式交互”。

+   他主张剥离LLM记忆，提倡“协作式中间态”的LLM智能体，还提及工作自动化与物理教育。

> 关键词：AGI，Karpathy，LLM，强化学习，智能体
