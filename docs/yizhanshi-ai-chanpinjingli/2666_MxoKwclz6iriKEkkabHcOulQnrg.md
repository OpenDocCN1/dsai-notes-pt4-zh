> Claude Skills，4000字详解 Anthropic 的思考

>

+   Skills = 笔记式形态 + 可执行工具 + AI调度与自优化，以熟悉形态降低门槛。

+   采用渐进式披露设计，从多个文档简化为一个主文档，继承人类笔记习惯。

+   结合代码与自然语言，代码负责确定性任务，自然语言处理模糊判断。

+   具备双Agent自我进化机制，AI理解反馈并改进手册，用户角色转为判断者。

+   Skills重新定义AI理解意图与执行任务的范式，或引发AI时代笔记革命。

> 全新开源的DeepSeek-OCR，可能...

>

+   DeepSeek-OCR不仅具备传统OCR功能，还能将复杂文档转化为Markdown文档，对图表进行代码重绘。

+   它提出“上下文光学压缩”，把文字压缩成图像，解决大模型长文本处理难题，不同压缩比下有相应识别准确率。

+   该模型可模拟人类记忆衰减，近期信息高保真，久远记忆随压缩率提高而淡忘。

+   其架构包含DeepEncoder编码器与DeepSeek-3B解码器，实现视觉Token与原文的转换。

+   DeepSeek-OCR为AI上下文处理提供新范式，对相关领域发展有重要意义。

> 关键词：DeepSeek-OCR，上下文光学压缩，长文本处理，记忆衰减，新范式
