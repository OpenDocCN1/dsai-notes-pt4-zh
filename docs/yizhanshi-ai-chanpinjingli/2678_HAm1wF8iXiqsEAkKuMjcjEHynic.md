> 阿里通义&人大新作UI-Ins：让指令学...

>

+   阿里通义与人大提出“指令即推理”范式，解决GUI智能体难题，推动其从“笨拙执行者”进化为“智能决策者”。

+   研究揭示现有GUI数据集质量与多样性问题，清洗噪声、丰富指令可提升模型性能。

+   设计高品质数据管道，构建两阶段训练框架，使模型学会“生成推理”与“基于推理预测”。

+   UI-Ins在五大GUI定位基准上领先，在线智能体表现亮眼。

+   该范式激发模型“自主创新思考”潜力，同时指出其主要失效模式与改进方向。

> 关键词：GUI智能体，指令即推理，数据集，两阶段训练，UI-Ins

> 承包你的品牌营销物料｜谷歌再发重磅 AI...

>

+   谷歌 Labs 发布AI设计产品Pomelli，能帮企业低成本生成符合品牌调性的营销物料，目前在美国等四国推出。

+   操作流程为输入官网链接提取品牌DNA，输入营销活动内容生成创意与排版，还可细节微调与下载。

+   优点是交互和点子好，适合临时救急与批量生产。

+   不足在于依赖官网信息，图片美学和排版单调，背景素材控制弱，不支持控制图像比例。

+   该技术方案由前端代码驱动，可精准控制品牌元素。

> 关键词：谷歌，AI设计产品，Pomelli，品牌营销物料
