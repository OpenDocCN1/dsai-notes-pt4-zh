## 1️⃣ 速递｜AI PPT Gamma实现1亿美...

> 🤖

+ Gamma完成6800万美元B轮融资，估值达21亿美元，此前还完成过A轮融资。
+ 这家2020年底成立的公司专注用AI生成演示文稿等内容，已实现盈利，ARR达1亿美元，用户量7000万。
+ 其融资节奏相对谨慎，以约9000万美元总融资额达成双独角兽估值，仅靠约50名员工实现。
+ 本轮融资含2000万美元二次发行，为早期员工提供流动性，Accel等机构参与。
+ Gamma虽不算新锐，但在AI内容生成领域已取得亮眼成绩。

> 关键词：AI PPT，Gamma，融资，盈利，独角兽

## 2️⃣ 速递｜AI客服Wonderful获1亿美...

> 🤖

+ 以色列AI初创公司Wonderful获1亿美元A轮融资，总融资额达1.34亿美元，其AI代理问题解决率达80%。
+ 该公司构建的基础设施和协调架构，能随多代理系统兴起而扩展，且可根据不同市场本地化调整。
+ Wonderful计划2025年进军德、奥等地，2026年初拓展至亚太，还探索员工培训等新领域。
+ 面向客户的AI Agent通过增强或取代人工客服帮企业降本，风险小，吸引投资者目光。
+ 投资人认为其优势在于为跨国企业部署代理系统，且文化适应能力的代理价值惊人。

> 关键词：AI客服，A轮融资，AI代理，市场拓展，跨国企业
