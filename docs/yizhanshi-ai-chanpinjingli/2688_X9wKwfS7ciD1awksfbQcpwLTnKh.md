> 比互联网泡沫惨17倍！AI裁员潮上万科学...

>

+   AI泡沫可能比互联网泡沫惨烈17倍，因当前AI投资规模为当年互联网公司投资的17倍，且其落地价值有限，许多分析师认为泡沫可能在数月内破裂。

+   若AI泡沫破裂，初创公司受影响大，OpenAI等大公司可能存活，研究人员或回流学术界，或创办新公司。

+   历史上科技泡沫破裂对研究有长期影响，此次AI泡沫破裂或使人才与技术溢出到其他领域。

+   从科技公司离职的科学家可能去攻克挑战性难题，如创立专注推动科学发现的公司。

+   资金和人力投入会使创新扩散，但具体后果尚不确定。

> 关键词：AI泡沫，裁员，人才流向，创新扩散

> 卡帕西大模型横评方法太好玩了！四大AI匿名参赛评分，最强出乎意料

>

+   卡帕西推出“大模型议会”web app，用户输入问题后，系统通过OpenRouter调起多个大模型商议。

+   该系统分三步：多模型同时答题、匿名互评、主席模型汇总最终答案。

+   项目延续卡帕西用LLM分阶段深度阅读思路，在GitHub获1.8k Stars。

+   大模型互评结果：GPT-5.1最强，Claude最弱，但卡帕西有不同主观评价。

+   卡帕西认为多模型集成或成LLM产品突破点。

> 关键词：卡帕西，大模型议会，多模型集成，模型互评

> 图片生成仿真！这个AI让3D资产「开箱即...

>

+   南洋理工大学与上海人工智能实验室合作提出PhysX-Anything，是首个面向仿真、具物理属性的3D生成框架，凭单张图像生成可用于仿真的3D资产。

+   采用“由粗到细”框架及新型3D表征方式，实现高压缩比，提升效率与扩展性。

+   在多项测试中优于其他方法，泛化能力强，生成结果受人类认可。

+   生成资产可直接用于具身智能训练，推动下游应用。

+   该框架有望推动3D重建从“形似”走向“神似”，开辟新方向。

> 关键词：3D生成，物理仿真，具身智能，AI框架，生成资产
