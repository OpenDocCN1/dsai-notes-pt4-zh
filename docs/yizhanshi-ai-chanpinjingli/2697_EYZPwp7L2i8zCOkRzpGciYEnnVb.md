## 1️⃣ 🔮 DeepSeek-V3.2｜技术报告解读

+ `DeepSeek-V3.2`推理追平`GPT-5-High`且部分指标超越，`Speciale`版获2025 `IMO/IOI`金牌，推理接近`Gemini-3.0-Pro`。

+ 核心技术`DSA`稀疏注意力，将复杂度从`O(L²)`降至`O(L*2048)`，通过`Lightning Indexer`+`Top-k`选择实现，训练分两阶段效率提升。

+ 后训练预算超预训练10%，含6领域专家蒸馏和混合`RL`（`GRPO`算法四技巧避免遗忘）。

+ 合成1827环境/85k+任务（代码/搜索/智能体等），消融实验证明泛化能力显著提升。

+ 优化`Thinking`保留机制、`Cold-Start`引导工具调用，`Discard-all`上下文管理最优；局限为世界知识、`token`效率及顶尖任务差距（算力不足）。

## 4️⃣ 🤖 麦肯锡报告解读：智能体, 机器人与我们的技能协同

+ 麦肯锡报告指出AI可自动化美国57%工作时长，但职位不会消失，角色将晋升为审核者、设计者和指挥官。

+ 区分两种AI力量：`Agents`（数字副手处理非物理工作）和`Robots`（物理外骨骼处理物理工作）。

+ 技能迁移明显：单纯信息处理等硬技能贬值，领导力等软实力升值，AI流利度需求暴涨7倍。

+ 企业和个人应重塑工作流而非仅自动化孤立任务，需重新思考整体做事逻辑。

+ 个人需立即行动：从执行转审核、培养跨界能力、拥抱AI经理角色（分配任务给AI助手）。

## 5️⃣ 🪅 Mistral 3 发布｜对标的，全是中...

+ 🌏 法国`Mistral`（估值140亿美金）发布`Mistral3`系列，时隔一年多更新，对标中国模型`DeepSeek-3.1`/`Kimi-K2`，放弃海外头部闭源模型对比。

+ 🤖 旗舰`Mistral Large3`：675B总参数（`MoE`架构），`Apache2.0`开源，`LMArena`开源非推理第二，第三方评估对`DeepSeek`/`Kimi`胜率53%/55%（多语言更优）。

+ 🍭 `Ministral3`小模型：`3B/8B/14B` dense模型，各尺寸含`pretraining`/`instruct`版本，支持图像理解与40+语言。

+ 🚀 训练用3000张`NVIDIA H200`，`Large3`可在`Blackwell NVL72`或单`8×A100/H100`部署，`API`已上线主力算力平台。

+ 🎯 文章暗示中国开源大模型已成全球标杆（`Mistral3`仅对标中国模型）。

### 关键词

`Mistral3`，开源大模型，`MoE`架构，`DeepSeek-3.1`，`Kimi-K2`。
