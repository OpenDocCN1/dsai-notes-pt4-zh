> 实测可灵O1，AI视频界的Banana也...

>

+   可灵发布全新多模态视频大模型可灵O1，融合参考生视频、文生视频等多种能力，是AI视频领域首个大一统模型，O取自Omni（全），与GPT-4o的O含义一致。

+   可灵O1已正式上线，用户可通过官网体验，作者内测时用2万多积分制作视频，发现多种惊喜玩法。

+   核心能力包括视频内容增删（如添加奶茶、删除人物）、特定内容修改（换衣服颜色、变天气）、自动扣绿幕等实用功能。

+   支持参考视频动作迁移（如让尼克跳指定舞蹈）及风格更改（像素化、蒙克风格），短视频场景下效果够用但精细控制仍有不足。

+   可灵O1虽有局限（如精细控制不够），却是AI视频向终极全流程工具进化的重要一步，开启“用嘴改视频”的新时代。

> 关键词：可灵O1，多模态视频大模型，AI视频编辑，Omni模型，视频内容修改

> Telegram创始人搞了个狠活：100%隐私的去中心化AI网络

>

+   Telegram创始人帕维尔·杜罗夫推出基于TON区块链的去中心化机密AI网络Cocoon，旨在打破亚马逊微软等中间商垄断，实现100%保密、无追踪且低价的AI处理。

+   Cocoon采用三层架构：Worker层（Intel TDX TEE运行AI模型，GPU所有者可参与）、Proxy层（路由请求选Worker，未来开放）、Client层（发送请求库，Telegram后端使用）。

+   请求流程通过RA-TLS加密验证，客户端预付费→代理转发→Worker在TEE处理→智能合约支付→返回响应，仅客户端可见提示词和结果。

+   面临延迟质疑但适合ML训练等非实时任务；网络拓扑为多客户端→少量代理→大量Worker，代理用链上系统跟踪Worker声誉。

+   当前中心化管理，未来计划DAO治理；代码库已开源，官网有开发者/GPU文档，Telegram频道同步项目进展。

> 关键词：Cocoon，去中心化AI，机密计算，TON区块链，TEE

> [今](https://mp.weixin.qq.com/s/uCS7nHOGYbXAoM17Tutxxg)日开源（2025-12-1）：英伟达发布Nemotron-Flash，实现推理速度与精度双突破，重新定义小参数量模型性能边界

>

+   英伟达发布Nemotron-Flash混合小型语言模型家族，聚焦延迟优化（深度-宽度比、混合操作符等），1B/3B规模在数学、编码等任务达SOTA精度，兼顾小批量延迟与大批量吞吐量。

+   Spatial-SSRL基于Qwen2.5-VL-7B优化，通过轻量级自监督强化学习范式提升空间理解能力，保留基础模型通用视觉能力。

+   DynaAct框架动态构建紧凑动作空间增强LLMs序列推理，子模函数优化平衡效用（相关性）与多样性（非冗余），降低推理延迟。

+   Decomposed-Forward-Pass模块化归因框架支持Transformer任意粒度归因（令牌/神经元/模块等），助力细粒度机制解释。

+   REG方法纠缠图像潜在变量与类标记改善扩散模型训练，直接生成一致图像-类对，训练速度比传统快63倍。
