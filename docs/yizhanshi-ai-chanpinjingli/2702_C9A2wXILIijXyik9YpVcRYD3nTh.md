## 6️⃣ 🔍 LLM强化学习不稳定之谜，被Qwen团队从「一阶近似」视角解开

+ 阿里千问团队针对LLM RL训练中序列级奖励与token级优化不匹配问题，从一阶近似视角提出新公式，解释稳定训练技巧有效性。
+ 该方法指出token级替代目标是序列级奖励期望的一阶近似，需满足训练推理差异和策略偏差足够小的条件。
+ 针对MoE模型RL挑战，提出Routing Replay固定专家路由，减少差异与策略陈旧，提升稳定性。
+ 实验显示：on-policy训练中带IS的MiniRL性能最佳；off-policy需Routing Replay与Clipping结合才能稳定。
+ 不同冷启动模型最终性能相近，研究应聚焦RL方法而非冷启动细节。

**关键词**：LLM强化学习，一阶近似，MoE模型，Routing Replay，训练稳定性
