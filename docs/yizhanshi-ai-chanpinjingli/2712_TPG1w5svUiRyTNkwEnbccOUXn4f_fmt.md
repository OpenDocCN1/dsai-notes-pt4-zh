## 2️⃣ 🌈 VGGT再升级，支持任意模态输入！视觉三维重建新SOTA！

+ `OmniVGGT`（2025）是`VGGT`升级版本，通过轻量`GeoAdapter`支持任意数量几何模态输入（相机参数、深度等），突破现有模型模态限制。

+ `GeoAdapter`含相机适配器（零卷积处理位姿保训练稳定）和深度适配器，新增开销微，推理速度比`Pow3R`快30倍。

+ 仅RGB输入时，`OmniVGGT`在单目深度、位姿估计、重建等任务刷新SOTA，加30%深度输入降69% AbsRel误差。

+ 在多视图深度、位姿估计、场景重建等任务中，无论有无辅助模态均显著优于`VGGT`、`Pow3R`等基线。

+ 与`VLA`集成后，增强的机器人操作模型空间理解提升，利用辅助输入实现稳定性能改进。

**关键词：** `OmniVGGT`，多模态三维感知，`GeoAdapter`，视觉几何Transformer，三维重建SOTA

## 3️⃣ 🎯 NeurIPS 2025｜指哪打哪，可控对抗样本生成器来了！

+ 清华与蚂蚁数科在`NeurIPS 2025`提出`Dual-Flow`框架，双流结构实现黑盒多模型/类别攻击，迁移成功率提升34.58%且视觉无痕。

+ 该框架不依赖模型结构与梯度，在`latent`空间做结构化扰动，解决传统攻击迁移性差或实例专属问题。

+ 支持多目标、多模型、实例无关攻击，一个生成器覆盖多类别/架构，无需特定图像训练。

+ 核心创新为双流结构、级联分布偏移训练，及指定类别生成攻击图像的可控能力。

+ 已应用于蚂蚁身份安全产品，增强防御鲁棒性，为AI安全带来新挑战。

**关键词：** `Dual-Flow`，对抗攻击，黑盒攻击，多目标攻击，AI安全

## 5️⃣ 🔮 [95%越狱成功率！佐治亚理工与清华](https://mp.weixin.qq.com/s/0pgVmguSSUxHOe-d61KBsw)联手发布新型攻击框架，最强大模型无一幸免

+ 🔍佐治亚理工等多机构联合发布`CKA-Agent`攻击框架，利用大模型知识互联漏洞，分解有害目标为无害子问题动态攻击，成功率超95%。

+ 🌳`CKA-Agent`采用自适应树搜索策略，无需模拟即可高效绕过困惑度过滤器等现有防御机制，区别于传统提示词优化攻击。

+ 📊实验显示，该框架对Gemini2.5、GPT-4系列、Claude3等主流模型攻击成功率均超95%，传统防御手段完全失效。

+ ⚠️暴露大模型单点意图检测缺陷：即使提供完整对话历史，模型也难以聚合多轮查询意图识别潜在风险。

+ 🔓研究团队已开源代码，同时OpenAI计划2026Q1推出ChatGPT成人模式，引发内容监管新挑战。

**关键词：** `CKA-Agent`，大模型越狱，自适应树搜索，AI安全防御，开源攻击框架
