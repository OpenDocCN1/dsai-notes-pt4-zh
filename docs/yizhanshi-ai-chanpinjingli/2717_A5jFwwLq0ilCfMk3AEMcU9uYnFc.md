## 2️⃣ 🎯 [喝](https://mp.weixin.qq.com/s/3Mh6IN08Z7wxNU37c3K-Aw)点VC｜拒绝21岁创业？红杉对话AI独角兽ElevenLabs、Lovable CEO：先攒够这3类经验再出发

+ ElevenLabs和Lovable的CEO均建议年轻创业者先积累行业经验（如客户痛点理解、团队招募），再聚焦核心方向（语音AI/非技术用户AI开发）。
+ 团队建设需平衡内部培养与外部资深人士，采用小团队模式，注重跨部门协作和招募比自己优秀的人才。
+ 授权管理上，需先学新领域基础再放权，把握细节与宏观平衡，避免被事务缠身。
+ 欧洲创业优势：中东欧工程师人才集中、时区便利对接全球；劣势：缺规模化经验人才和成熟分销网络。
+ 给年轻创业者建议：勇敢尝试、贴近用户迭代、选信任的联合创始人、持续学习招聘销售、在失败中成长。

> 关键词：AI独角兽，创业经验，团队建设，欧洲创业生态，授权管理

## 4️⃣ 🔥 [速递｜前Splunk高管创自动AI运维，Resol](https://mp.weixin.qq.com/s/rEmBs6_wcgQZqSzfqLHp9A)ve AI跻身独角兽，估值突破10亿美元

+ 前Splunk高管联合创立的Resolve AI完成A轮融资，公开估值10亿美元（采用多轮次结构），年度经常性收入约400万美元。
+ Resolve AI专注自动化SRE工具，可实时自主识别、诊断并解决生产环境系统故障，替代传统人力处理。
+ 公司成立不足两年，创始人曾共创Omnition（2019年被Splunk收购），去年获3500万种子轮融资（李飞飞、Jeff Dean参与）。

+ 竞争对手为AI SRE初创公司Traversal（获4800万美元A轮融资，Kleiner Perkins领投）。

## 6️⃣ 🎯 记忆罗盘：大模型智能体记忆的表征、操作与演进航向

+ 记忆是LLM智能体迈向AGI的关键组件，可解决模型幻觉和长上下文推理问题🔑。
+ 港中文等团队分析2022-2025年3万+论文，提出记忆表征与操作分类坐标系（记忆罗盘）🌐。
+ 该研究涵盖RAG、长上下文压缩、KV Cache管理、模型内部知识编辑等记忆方向🧠。
+ 主题直播将于2025.12.24 20:00-21:00在🛰️视频号和B站直播间进行📺。
+ 论文《Rethinking Memory in LLM-based Agents...》已开源，含arxiv和github链接🛠️。
