## 3️⃣ Dexmal 原力灵机提出 GeoVLA...

> 🌏

+ 🌏Dexmal原力灵机提出GeoVLA框架，通过双流架构融合语义与几何信息，解决现有VLA模型的空间失明问题。
+ 🤖GeoVLA采用双路径设计：VLM负责语义理解，PEN和3DAE处理点云数据实现3D几何感知。
+ 🎯仿真测试中，GeoVLA在LIBERO-90达97.7%成功率，ManiSkill2平均77%，超越现有SOTA方法。
+ 🛠️真机测试总体成功率86.3%，OOD场景（视角/尺度变化）鲁棒性显著优于传统2D VLA模型。
+ 🚀GeoVLA为具身智能提供3D感知方案，标志VLA模型从2D到空间智能的实质性跨越。

### 关键词

GeoVLA，VLA模型，3D感知，具身智能，双流架构
