> [QwenLong-L1.5发布：一套配方，三大法宝，让30B](https://mp.weixin.qq.com/s/pOcLwNgB6P0JSc7u6Ccrdw) MoE模型长文本推理能力媲美GPT-5

>

+   通义文档智能团队推出QwenLong-L1.5（基于Qwen3-30B-A3B），提供端到端长文本推理后训练配方，含高质量数据合成、定制RL方法、突破窗口的智能体架构三大法宝。

+   法宝一为多跳推理数据合成流水线，通过KG引导、跨文档表格引擎、多智能体自我进化生成需多跳溯源和全局推理的训练数据。

+   法宝二是稳定高效的RL策略，用任务均衡采样解决数据异构问题，AEPO算法动态控制梯度，平衡探索与利用，解决信用分配难题。

+   法宝三为记忆管理框架，通过多阶段融合RL训练，将结构化记忆与窗口内推理融合，突破物理上下文窗口限制。

+   QwenLong-L1.5性能显著提升，30B MoE模型媲美GPT-5等顶级模型，复杂任务提升精准，通用能力增强，可处理1M~4M超长文本。

> 关键词：QwenLong-L1.5，长文本推理，多跳推理，记忆管理框架，AEPO算法

> 比Mathpix更强大的公式识别神器，全免费！

>

+   PaddleOCR推出新模型PaddleOCR-VL，公式识别准确率超Mathpix及Gemini3.0、GPT5.2等闭源大模型，且开源免费。

+   测试显示该模型在印刷、手写、超长复杂公式及带合并单元格的表格场景中均准确识别，Mathpix存在错误。

+   PaddleOCR官网支持一键复制Latex格式结果，开放API供批量处理，每日3000页免费额度可申请增加。

+   本地调用API时复杂公式约1秒完成，结果可直接粘贴到Overleaf等编辑器使用。

+   作者肯定该模型体现中国AI技术实力，期待更多模型创造实际价值而非仅指标竞争。

> 中科院 × 北体大提出SportsGPT...

>

+   中科院自动化所、北体大等联合提出SportsGPT框架，解决通用大模型（如GPT-5）在体育动作分析中细粒度感知不足、建议缺乏针对性的问题，实现从动作评估到训练处方的智能闭环。

+   SportsGPT包含三大核心组件：MotionDTW（两阶段时间序列对齐，消除体型/速度干扰）、KISMAM（量化指标到可解释诊断的概率映射）、SportsRAG（整合知识库与RAG生成精准训练指导）。

+   专家双盲评估显示，SportsGPT在准确性（3.80）和可行性（3.77）上全面超越GPT-5、Claude4.5等通用模型，凸显垂直领域框架优势。

+   MotionDTW通过加权多模态特征（几何角度+角速度/角加速度）、时空抗噪机制及两阶段对齐，实现非受控视频的精确解析，误差仅1.54帧。

+   SportsRAG整合60亿Token知识库（含5万专家问答），结合KISMAM诊断结果生成可执行指导，移除RAG后方案可行性从3.9骤降至1.65。

> 关键词：SportsGPT，MotionDTW，KISMAM，SportsRAG，AI体育教练，RAG技术
