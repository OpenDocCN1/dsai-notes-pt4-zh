>

+   a16z提出AI“玻璃鞋效应”：模型精准解决高价值未满足工作负载时，首批用户展现极高留存，如灰姑娘找到合脚玻璃鞋。

+   传统SaaS默认早期低留存，AI产品却可在首批用户中实现高留存，颠覆原有留存认知。

+   Gemini2.5Pro、Claude4Sonnet首发用户留存亮眼，后续用户因无独特性流失快；无前沿跃迁的模型无稳定用户群。

+   基础用户群是核心：深度绑定模型切换成本高，窗口期短暂需抓住，为企业提供长期根基。

+   AI下一阶段关键非模型大小速度，而是找到真正需要且长期留存的用户，实现工作负载-模型匹配。

> 关键词：AI玻璃鞋效应，用户留存，工作负载-模型匹配，基础用户群，产品市场匹配

> 速递｜Meta官宣收购Manus，将继续...

>

+   Meta Platforms宣布收购新加坡AI Agent初创公司Manus，以强化AI业务布局，应对与OpenAI、谷歌等对手的竞争。

+   Manus提供企业级AI Agent服务（如简历筛选、行程规划、股票分析），今年早些时候年化收入约1.25亿美元，估值近5亿美元（Benchmark领投）。

+   收购后Manus将继续独立运营并销售服务，其技术会整合到Meta的消费者及商业产品（如Facebook、Instagram等）中。

+   Meta计划未来三年在美国投入6000亿美元于AI相关基础设施，明年春季推出新一代尖端AI模型。

+   Meta首席AI官Alexandr Wang欢迎Manus团队，Manus CEO称将借助Meta规模扩大AI Agent覆盖范围。

> 关键词：AI Agent，Meta收购Manus，企业级AI，Meta AI战略，AI基础设施

> 速递｜软银300亿美元鲸吞Digital...

>

+   软银集团同意以约30亿美元现金收购DigitalBridge，含债务估值40亿美元，每股16美元，较谈判曝光前收盘价溢价65%。

+   此项收购是软银布局AI驱动数字基础设施的核心举措，孙正义欲抓住AI热潮下数据中心需求激增的机遇。

+   东京早盘软银股价跌3.4%，DigitalBridge股价在纽约交易中涨9.7%至15.27美元（略低于出售价）。

+   交易预计2026下半年完成（待监管批准），软银将通过DigitalBridge对接更多数据中心投资者，其 portfolio覆盖多家头部运营商。

+   软银近期出售58亿美元英伟达股份调配AI资金，曾讨论收购Switch，星门项目因选址分歧推进慢于计划。

> 关键词：软银收购DigitalBridge，AI数据中心，数字基础设施，算力需求，孙正义

> 好运框架、决策本质与认知飞轮 / 2026 的个人行动手册

>

+   好奇心是生存策略：生物视角试错为探索最优解，AI视角无探索机制易陷局部最优，经验易成负资产需保持好奇心防过时。

+   好运框架分四层：盲目运气（不可控）、勤奋运气（试错）、环境运气（置身机会场如硅谷AI中心）、磁铁运气（领域极致吸引机会）。

+   决策本质是认知：认知清晰度决定决策成本，直觉是压缩后的高维认知，AI反驳辩论可对冲愿望思维偏差。

+   认知飞轮四步：高质量输入（拒绝快餐、优质信源、人机协作筛选）、深度内化抽象、强制输出（费曼学习法）、认知变现反哺（投资验证等）。

+   行动建议：身处技术变革前夜，保持好奇、去高能量密度处、建认知体系，认知为核心资产，决策是变现方式。

> 关键词：好奇心，好运框架，认知飞轮，决策本质，AI探索机制

> [英伟达成美国大模型开源标杆：Nemotron3连训练](https://mp.weixin.qq.com/s/G6ZjmCaqKCnc7DV7klXiAg)配方都公开，10万亿token数据全放出

>

+   🔥Nemotron3是高效开放模型家族，混合Mamba-Transformer MoE架构，彻底开放权重、10万亿token训练数据及配方，性能具竞争力且速度快1.5-3.3倍。

+   🤖用Mamba-2层替代多数自注意力层，Nano型号吞吐量为Qwen3-30B的3.3倍，100万token长上下文任务得分较前代提升超2倍。

+   🧬针对大模型提出LatentMoE潜空间专家路由，同等参数量下MMLU-Pro等下游任务成绩显著提升。

+   ⚡采用NVFP4低精度训练25万亿token，与BF16版本准确率曲线重合，仅关键层保留高精度。

+   🏆后训练用多环境同步强化学习，避免能力退化，AIME25数学分从80升至90、LiveCodeBench从65升至72。

> 关键词：Nemotron3，Mamba-Transformer MoE，LatentMoE，NVFP4，多环境强化学习
