## 1️⃣ 🔔 港大一副院长“下课”！涉AI论文造假案，...

+   香港大学社科院副院长叶兆辉因博士生用AI生成24条虚假参考文献（含署其名的假文献），涉事论文被Springer Nature撤稿，叶引咎辞职，学生将接受纪律处分。
+   事件由叶兆辉前博士生实名爆料，期刊初期接受修改方案，但后续调查确认24条引用无法核实且作者未披露AI使用。
+   港大已完成调查，将加强生成式AI使用的强制性培训考核，以维护学术诚信。
+   近年学术界AI代笔频发，多个期刊（如《中国社会科学》）明确AI使用规范，禁止伪造内容等违规行为。
+   AI是工具，合理使用可提升效率，但使用者需坚守核查与责任意识，避免学术不端。

关键词：AI学术造假，港大论文撤稿，生成式AI规范，学术诚信，Springer Nature调查

## 3️⃣ 🧬 统一结构与上下文信息的计算平台，德国慕尼黑大学等提出端到端的单细胞扰动分析框架

+   德国慕尼黑亥姆霍兹中心与慕尼黑工业大学团队提出Python模块化框架`pertpy`，用于端到端分析大规模单细胞扰动实验，成果发表于《Nature Methods》。
+   `pertpy`支持遗传敲除、药物筛选、疾病状态等多种扰动类型，提供100+可组合功能，通过JAX实现GPU加速，速度提升显著。
+   框架涵盖数据转化、质量控制、扰动注释、扰动空间学习等全流程，模块化设计降低领域研究门槛。
+   团队通过CRISPRa筛查数据集及药物治疗数据集验证了`pertpy`在学习有意义扰动空间和高效分析复杂实验的能力。
+   `pertpy`是开源工具，整合分散方法为结构化框架，为单细胞扰动研究提供可重复、易扩展的解决方案。

关键词：`pertpy`，单细胞扰动分析，端到端框架，开源工具，GPU加速

## 5️⃣ 🎯 田渊栋：2025年年终总结（一）

+   田渊栋2025年1月参与Llama4项目后被裁，期间探索强化学习训练稳定性等核心问题，经验推动研究思路转变并为小说创作提供素材。
+   虽获多家知名公司offer，他仍选择成为新初创公司联合创始人，细节暂未公开。
+   连续隐空间推理（`coconut`）引发热潮，团队发理论分析文章Reasoning by Superposition（NeurIPS‘25）获关注。
+   大模型推理效率优化有Token Assorted等工作，从离散token混合、自信度终止推理路径等角度减少代价提升性能。
+   可解释性上，Provable Scaling Laws解开特征涌现谜团，The path not taken解释RL与SFT行为差异，强调其对AGI/ASI的重要性。
