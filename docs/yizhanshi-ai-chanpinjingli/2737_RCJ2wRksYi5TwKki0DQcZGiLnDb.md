> [谈谈DeepSeek Engram](https://mp.weixin.qq.com/s/L7YawzhHCACBQsiEb7w-Tw): Conditional Memory

>

+   DeepSeek提出Engram条件记忆范式，与MoE条件计算形成对偶，分离静态知识检索与动态推理，解放FFN专注复杂任务。

+   架构采用哈希N-gram检索（分词压缩+多头哈希）、上下文门控融合静态知识与动态上下文，多分支设计增强适应性。

+   稀疏性分配发现U形定律：混合MoE（75-80%）与Engram（20-25%）参数最优，Engram内存规模与性能呈幂律关系。

+   有效加深网络：早期层注入Engram加速预测收敛，长上下文任务释放注意力资源，性能显著优于MoE基线。

+   系统效率优化：确定性检索支持内存卸载（CPU DRAM/NVMe），预取与计算重叠，吞吐量损失可忽略。

> 关键词：Engram，条件记忆，MoE，稀疏性分配，长上下文

+   🔥 2025年后OCR重回技术专项，DeepSeek、智谱、阿里千问、腾讯混元等大厂密集更新OCR技术，如DeepSeek-OCR的视觉压缩、腾讯HunyuanOCR开源等。

+   🧠 ADE方案解决传统OCR（如Tesseract、PaddleOCR）压平文档丢失结构信息的问题，通过三大支柱（视觉优先、数据为中心、智能体化）提升效果。

+   📊 ADE搭载DPT模型，可精准解析巨型表格、手写公式、弯曲印章证书等复杂文档，还引入视觉接地技术实现数据块溯源。

+   ☁️ 课程提供AWS部署全流程，能自动将S3存储的PDF解析为结构化Markdown，结合知识库与智能体做成行业知识助手。

> 关键词：吴恩达新课，OCR，智能体文档提取（ADE），DPT模型，大厂OCR进展
