> Qwen3技术报告英中对照版.pdf

>

+   Qwen3是Qwen家族最新版本，含0.6B到235B参数的密集型和MoE架构模型，性能、效率及多语言能力显著提升🌈。

+   首次融合思考模式（复杂推理）与非思考模式（快速响应），引入思考预算机制动态分配资源，消除模型切换需求🔥。

+   多语言支持扩展至119种，预训练数据达36万亿令牌，分三阶段优化通用知识、推理能力及32768令牌长上下文🥇。

+   架构创新：密集型移除QKV偏置加QK-Norm；MoE用128专家（激活8个）及全局负载均衡损失促进专业化🔧。

+   后训练通过Long-CoT冷启动、推理RL等增强能力，在通用、数学、编码基准测试中表现出色🌟。

> 关键词：Qwen3，大模型，思考模式融合，混合专家架构（MoE），多语言能力提升

> 刚刚，Anthropic 用 Claud...

>

+   Claude Code因用户用其做杂活（如恢复照片、控制设备），Anthropic10天推出办公版Cowork，核心代码基本由Claude Code生成。

+   ⚡️Cowork开发速度惊人：10天从立项到上线，代码主要由Claude Code编写完成。

+   🎫Cowork初期仅Max用户可用，现开放给Pro用户（20美元/月），支持macOS，Windows版本在规划中。

+   ⚠️Cowork存在提示词注入和误操作风险，Anthropic虽做防护但承认是行业难题，建议用户用清晰指令。

> 关键词：Claude Code，Cowork，Anthropic，沙箱隔离，AI办公工具
