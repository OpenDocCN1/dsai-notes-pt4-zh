>

+   背后原因含AI加速药物研发：多家药企与OpenAI合作，OpenAI正获取生物制药私有数据训练专用模型。

+   Sarah Friar暗示模式可扩展至能源金融领域，但可能导致OpenAI损失部分商业客户。

> 关键词：OpenAI，价值共享，商业模式转型，药物研发AI，版权争议

> 刚刚，Anthropic内部考题开源！年薪百万工程师，被AI秒了

>

+   Anthropic因Claude Opus4.5能轻松解决其招聘笔试（曾筛选顶尖工程师），导致笔试失效，被迫开源旧版试题并向全球求助测试人类编程能力的方法。

+   旧版试题需候选人进行多核并行、SIMD向量化等优化，用Perfetto trace分析，Anthropic认为无限时间下人类专家极限仍超AI。

+   原版试题设计初衷是模拟真实工作环境考察性能工程技能，曾帮助组建核心团队，发掘天才工程师。

+   Claude Opus4.5在该试题上表现优异，超长思考后得分接近人类最高，迫使Anthropic探索新的防AI面试题。

+   Anthropic尝试设计受限指令集的新题暂时有效，但放弃了原版试题的真实感和深度。

> 关键词：Claude Opus4.5，Anthropic，招聘笔试，开源试题，AI面试题

> 热捧Skills批判MCP？问题不在协议...

>

+   AI圈热捧Skills唱衰MCP，但开发者指出问题不在MCP协议，而在服务器设计（将MCP当REST API封装，未适配Agent需求）。

+   人类开发者与Agent的工具设计原则差异显著，需针对Agent优化发现成本、组合能力等维度。

+   给出MCP服务器6大设计原则：结果导向、参数扁平化、文档即指令、精选工具、命名规范、分页处理。

+   Skills与MCP非竞争关系，前者解决工具选择，后者解决可靠调用，可协同服务企业级需求。

+   行业勿盲目追逐新概念，应扎实落地，聚焦用户需求与实际价值创造，避免浅尝辄止。

> 关键词：MCP协议，Skills，Agent工具设计，AI生态，大模型落地
