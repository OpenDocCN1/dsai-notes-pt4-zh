> 刚刚，微软全新一代自研AI芯片Maia 200问世

>

+   微软2026年1月27日发布自研AI推理加速器Maia200，采用台积电3nm工艺，含1400亿晶体管，TDP750W，FP4性能超10PetaFLOPS、FP8超5PetaFLOPS。

+   Maia200配备216GB HBM3e内存（7TB/s带宽）等，每美元性能提升30%，FP4性能是Amazon Trainium三代3倍，FP8超谷歌第七代TPU。

+   芯片将支持GPT-5.2、Microsoft Foundry等，助力合成数据生成，已部署美中西部数据中心，后续扩展至西部区域。

+   与Azure无缝集成，开放Maia SDK预览，提供PyTorch集成等工具，支持模型异构迁移及精细化控制。

+   微软已启动Maia下一代设计，端到端方法缩短部署时间，提升云规模下性能与效率，强调基础设施对AI创新的作用。

> 关键词：Maia 200，AI推理加速器，3nm工艺，微软自研，Azure集成

> 大模型哪里出问题、怎么修，这篇可解释性综...

>

+   香港大学等多机构团队发布“可实践的机制可解释性”综述，提出Locate-Steer-Improve三阶段范式，将MI从观察转化为干预模型的方法论。

+   Locate阶段构建可解释对象分类体系（微观如神经元/SAE特征，宏观如注意力头），梳理因果归因等定位工具。

+   Steer阶段归纳幅度操控、靶向优化、向量运算三大干预手段，实现对模型关键组件的可控调整。

+   Improve阶段MI赋能对齐（减少有害行为）、能力（增强推理）、效率（加速部署）三大应用场景。

+   展望需建立标准化评估基准与自动化MI，推动AI自主发现修复内部错误。

> 关键词：机制可解释性，大模型，Locate-Steer-Improve，干预手段，AI对齐

> Science重磅：AI编程新手与资深开发者之间的差距巨大

>

+   《科学》杂志发表的全球AI编程调查研究显示，美国程序员提交的Python代码中29%由AI生成，资深开发者正利用AI工具拉大与新手的差距。

+   研究团队基于GraphCodeBert构建分类器，分析全球16万名开发者6年间3000万次代码修改，量化AI在编程领域的扩散程度、全球分布差异及对不同经验开发者的影响。

+   全球AI代码采用率存在明显区域差异：美国29%领先，德法23%/24%紧随，印度近20%快速追赶，中俄因访问限制等因素处于较落后位置。

+   AI使用无性别差异，但资深开发者获显著生产力提升（季度代码提交增3.6%，高强度使用增超6%），新手因缺乏鉴别力未实现效率增长。

+   生成式AI每年为美国软件行业带来230-380亿美元直接劳动价值（保守估计或达1670亿），还促使开发者探索新库组合扩展功能边界。

> 关键词：AI编程，生成式AI，GraphCodeBert，全球采用率差异，马太效应
