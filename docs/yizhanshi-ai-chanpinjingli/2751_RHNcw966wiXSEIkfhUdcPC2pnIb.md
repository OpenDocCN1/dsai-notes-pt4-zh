> 利用AI控制CRISPR，将基因编辑抑制剂从试错工程变成可预测技术

>

+   澳大利亚Monash大学团队用AI设计新型CRISPR-Cas13抑制剂（AIcrs），解决传统CRISPR的不确定性问题，成果发表于《Nature Chemical Biology》。

+   AIcrs设计结合RoseTTAFold-Diffusion生成蛋白质骨架和ProteinMPNN反向折叠，从靶点选择到验证仅需8周，效率远超传统方法。

+   针对无天然抑制剂的LbuCas13a，团队筛选出10个有效抑制活性超50%的候选，3个最优分子具高亲和力和热稳定性。

+   AIcrs在大肠杆菌中逆转噬菌体复制抑制，在HEK293T细胞中抑制GFP mRNA切割，部分分子细胞毒性低。

+   AIcrs推动CRISPR工具在多领域应用，但需优化模型解决细胞毒性，未来可拓展至其他CRISPR系统。

> 关键词：AI设计抗CRISPR，CRISPR-Cas13a，蛋白质设计，基因编辑，RoseTTAFold-Diffusion

> 从Pi0.5，再到LingBot-VLA：一条具身智能的路正在成型

>

> 就业恶化AI不背锅！经济大周期下AI取代的技能依然很重要

>

+   匹兹堡大学等机构研究显示，高AI暴露职位（如程序员）的失业风险早在2022年初（ChatGPT发布前）已上升，源于宏观经济周期而非AI冲击。

+   美联储加息、科技行业疫情后裁员等周期性因素导致就业恶化，数据未显示ChatGPT发布后的明显断裂点。

+   应届生进入高AI暴露职位比例下降始于2021届，早于AI爆发，是企业因经济环境缩减人才储备需求所致。

+   分析300万份课程大纲与领英数据发现，后ChatGPT时代，学AI重叠技能（编程、写作等）的毕业生起薪更高、求职时间更短。

+   AI未让相关技能贬值，反而提升门槛与价值，教育应转向评估利用AI内容，扎实技能仍是核心竞争力。

> 关键词：AI就业影响，经济周期，技能价值，教育暴露度，大语言模型

> 0.005%参数量超越SOTA！提升模型能力无需庞大奖励模型

>

+   上海交大等联合团队提出SWIFT轻量奖励模型，利用大模型隐藏状态线性特征，仅极小线性层即超越传统庞大奖励模型。

+   SWIFT挖掘模型生成时隐藏状态的确定性信号，无需外部裁判式奖励模型，避免计算资源浪费与海量标注数据依赖。

+   SWIFT参数量仅传统奖励模型的0.005%（20-30万），训练需6000样本，推理速度提升6.7倍，成本极低。

+   在MATH等多数据集上，SWIFT在Llama系列模型上全面超越Eurus-7B等SOTA奖励模型，微调后仍占优。

+   SWIFT可跨域泛化到代码/常识推理，还能通过闭源模型Logits适配，支持安全性对齐任务。

> 关键词：SWIFT，轻量级奖励模型，隐藏状态利用，大模型推理优化，低资源训练

> 个人传记采访 - 岁月记录者(提示词)

>

+   介绍AI传记助手“The Chronicler”，定位为传记作家与叙事疗愈师，核心是将用户人生重构为坎贝尔“英雄之旅”架构的微型传记。

+   该AI内化“英雄之旅”为深度访谈技巧，引导用户回忆人生“召唤”“试炼”“归来”三阶段的关键经历。

+   交互分两阶段：访谈时挖掘感官细节、冲突与情感，写作时用文学性笔触生成结构严谨的微传记。

+   访谈阶段强制追问感官细节（如声音、画面）及核心冲突（如恐惧），素材足够后询问是否生成传记。

+   写作阶段按标题、启程、启蒙/试炼、归来、尾声结构输出，突出情感转折点与人生意义。

> 关键词：AI传记助手，英雄之旅，叙事疗愈，个人微传记，深度访谈
