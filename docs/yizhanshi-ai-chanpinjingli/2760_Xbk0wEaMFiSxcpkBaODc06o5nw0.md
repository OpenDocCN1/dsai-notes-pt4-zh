## 5️⃣ 🔔 [华](https://mp.weixin.qq.com/s/yPCQpO7GW3QYmZlcPKnsXw)为升级行业Agent算法架构！MindScale自己写prompt和工作流，KV Cache减少5.7倍token

+ 华为诺亚方舟实验室推出面向行业Agent的算法包MindScale，融合算法创新与行业实践，提供技术论文及昇腾代码实现，助力开发者降低行业Agent开发门槛。

+ MindScale识别行业Agent普及的四大核心挑战：工作流手工维护、历史知识复用难、训推效率瓶颈、复杂推理测评难。

+ 该算法包含自进化Agent算法EvoFabric，可从自然语言文档生成可执行Workflow，并基于记忆演进实现Agent性能优化。

+ MindScale提供prompt自动优化方案（如C-MOP），通过正负反馈闭环优化prompt，相关场景精度提升超20%。

+ TrimR算法动态压缩思维链降低推理时延，KV-Embeddings方案减少KV Cache token数最高5.7倍，适配国产硬件生态。

关键词：华为MindScale，行业Agent，prompt优化，训推效率，昇腾代码
