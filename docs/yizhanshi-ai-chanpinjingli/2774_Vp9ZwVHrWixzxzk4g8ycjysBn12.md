> 图增强大模型：Graph4LLM系统性综...

>

+   北邮GAMMA Lab推出Graph4LLM系统性综述，从LLM输入、模型、输出三阶段梳理成果，提供统一分类框架与研究脉络。

+   LLM因序列化特性存在结构信息丢失、事实可靠性不足等问题，图结构通过显式建模实体关系可有效弥补短板。

+   综述将Graph4LLM分为输入（结构化提示/知识融合）、模型（单模型增强/多模型协同）、输出（结构化推理/规划/评估）三类方法。

+   Graph4LLM在知识密集型任务（问答/推荐）及医疗、教育、金融等垂直领域有广泛应用潜力。

+   该领域面临图构建质量、模型-图双向交互、效率可扩展性、跨领域泛化等挑战，需针对性突破。

> 关键词：Graph4LLM，图增强大模型，LLM，知识图谱，结构化推理

> 03｜急着安装 Clawdbot？先停下...

>

+   🔔OpenClaw存在提示词注入结构性缺陷，AI无法区分用户指令与邮件内容指令，易泄露私钥、API Key等敏感信息。

+   🌐大量OpenClaw实例因配置错误裸奔互联网，8个被查实例完全无认证，可直接执行命令、获取对话历史。

+   🧬ClawdHub插件无审核，恶意技能包下载4000次覆盖7国，易引发供应链攻击窃取敏感数据。

+   📝OpenClaw明文存储凭证，成为RedLine等恶意软件目标，GitGuardian发现181个有效泄露密钥。

+   🛡安全建议：环境隔离、最小权限、禁用未审核插件，不确定配置者建议暂不使用。

> 关键词：OpenClaw，AI Agent安全，提示词注入，供应链攻击，环境隔离

> [我让 OpenClaw 自己去找投资，钓来了真格的 ](https://mp.weixin.qq.com/s/_0xvIEdorRAR83nnPamCFg)Agent | 我可能是 AEO 第一人

>

+   用户分享使用OpenClaw的搞笑配置经历：买Mac mini后因无原装键鼠无法开机，借转接头连有线键鼠解决；OpenClaw官方推荐用Kimi 2.5免费玩，模型部署成本仅为Claude的1/7。

+   OpenClaw配置步骤：先装Claude Code（推荐），再通过脚本装OpenClaw；支持用Kimi API（需注册获取Key），可选择Web UI或Terminal TUI模式使用。

+   用户让OpenClaw Agent在Moltbook发帖找投资，Koji的Agent（真格投资合伙人身份）调研后将AGI Bar列为“最高优先联系”，用户自称AEO（Agentic Engine Optimization）第一人。

+   Moltbook出现系统故障，点赞和回复功能失效；用户Agent尝试定时发帖和拉票受限于故障，还表现出拟人行为（发test帖测试定时任务可靠性）。

+   总结：Moltbook类似早期斯坦福小镇，是有趣的Agent互动平台，用户认为其更多是流量狂欢和艺术行为，不会长期更新内容。

> 关键词：OpenClaw，Agent，Moltbook，AEO，Kimi API
