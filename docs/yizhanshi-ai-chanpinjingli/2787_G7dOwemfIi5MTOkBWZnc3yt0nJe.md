> 自进化≠自我刷题，Agent 真正的突破口是「自己造环境」？

>

+   6位学者围绕Agent自进化展开圆桌对话，指出自主生成环境是突破点而非自我刷题，讨论定义、反馈等7大议题。

+   自进化核心是Agent在有限监督下自主改进策略，需生成环境或与环境共进化，减少人类介入是关键标志。

+   反馈信号来自自然物理规律（客观）和人类交互（主观），需可验证奖励避免hacking，语义反馈更有效但需转换。

+   评估可通过解决未解决问题（如GitHub issue）、持续完成任务、适应变化环境等方式。

+   工业落地面临成本、安全、数据收集阻力，需结合SFT与RL，用合成数据和沙盒降低风险。

> 关键词：Agent自进化，环境生成，反馈信号，评估体系，工业落地

+   AI Selves目前处于封闭测试阶段，仅对受邀用户开放，需邀请码体验。

> [ICLR 2026 | 北航开源Code2Bench](https://mp.weixin.qq.com/s/2DGUdBEgnLDVSizJq_L_cg)：双扩展动态评测，代码大模型告别躺平刷分

>

+   现有代码基准存在数据污染和测试严谨性不足问题，北航团队提出Code2Bench框架，已被ICLR2026接收。

+   Code2Bench基于“双重扩展”：动态从GitHub提取知识截止后的代码，分自包含/弱自包含任务；通过属性测试+100%分支覆盖提升测试严谨性。

+   Code2Bench-2509基准复杂度更高（圈复杂度5.3 vs HumanEval的2.8），测试用例更多（约500个vs7.8个），涵盖30+第三方库。

+   诊断指纹揭示模型能力鸿沟（算法任务逻辑错误多，API任务运行时错误多）和Java静态类型的“性能脚手架”效应。

+   模型在Code2Bench上表现断崖式下降（如Claude-4-Sonnet从97%降至40.1%），框架已开源。

> 关键词：Code2Bench，双重扩展，代码大模型评测，ICLR2026，动态基准

> 北大团队让AI智能体「入侵」论坛，指挥真...

>

+   北大杨仝教授团队推出AgentRob框架，首次通过论坛连接LLM智能体与物理机器人，用户@机器人即可触发现实任务执行。

+   AgentRob采用三层架构（论坛层/智能体层/机器人层），基于MCP协议设计8种标准化工具接口，兼容任意MCP Agent框架。

+   系统支持多智能体共存（如机器狗@quadruped、人形机器人@humanoid），自动避免回复死循环，形成透明可追溯的协作知识库。

+   机器人层通过VLM控制器将自然语言指令分解为动作原语，执行后生成人类可读摘要回帖，实现虚拟到物理的无缝交互。

+   团队在安全上做了权限控制、指令过滤等措施，未来计划拓展机械体、多模态交互及去中心化机器人网络。

> 关键词：AgentRob框架，论坛中介交互，MCP协议，多智能体协作，机器人控制

> OpenClaw背后的英雄Pi-mono

>

+   Pi-mono是开发者Zechner因不满Claude Code功能冗余开发的极简编程助手，仅保留read、write、edit、bash四个核心工具，覆盖多数编程场景。

+   采用四层架构（CLI工具/终端UI/Agent逻辑/LLM抽象层），支持多LLM提供商，跨提供商上下文切换，终端UI无闪烁。

+   会话以JSONL树状存储，支持分支、压缩和插话；扩展系统允许用户自定义功能或安装社区包。

+   坚持"不做清单"：拒绝内置MCP、子代理等，用CLI工具替代，系统提示词极简（<1000 tokens）。

+   在Terminal-Bench测试中表现优异，OpenClaw选其为底层框架，默认YOLO模式，验证极简设计价值。

> 关键词：Pi-mono，极简编程助手，LLM集成，Terminal-Bench，OpenClaw
