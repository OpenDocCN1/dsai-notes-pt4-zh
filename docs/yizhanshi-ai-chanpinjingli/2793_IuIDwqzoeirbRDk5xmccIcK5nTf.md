>

+   作者结合Claude Code精选5个skills，开发“资产管理+人生目标”🛰️小程序，实测78个skills后发现适配阶段的组合更高效。

+   原型阶段用brainstorming skill做选择题明确：目标用户22-28岁年轻人，痛点是资金与目标脱节，差异化是资源分配博弈。

+   沉淀阶段让Claude Code生成专属skills，强调工具适配阶段比数量重要，避免无意义的skill收集癖。

> AI下半场的战场，从Agent记忆体正式打响

>

+   AI下半场核心转向Agent记忆体（Memory），需解决真实世界长周期、多轮次任务的持续能力，而非仅模型参数/benchmark比拼。

+   单纯扩大context window无法满足需求，需系统级记忆机制：含存储位置（内外协同）、认知功能（多维度）、服务主体（用户/任务/自身）三维度。

+   记忆≠RAG，是系统级框架，决定Agent真实应用能力上限。

+   评测体系转向任务完成度、环境状态维护等，而非仅回答正确性。

+   开源项目OpenClaw爆火体现Agent落地趋势，记忆体成为AI下半场核心战场。

> 关键词：Agent记忆体、AI下半场、系统级记忆、真实应用、RAG
