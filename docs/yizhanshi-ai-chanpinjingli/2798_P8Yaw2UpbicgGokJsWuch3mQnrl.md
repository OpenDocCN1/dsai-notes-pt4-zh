## 2️⃣ 智谱发布龙虾基座模型GLM-5-Turbo

> 🤖

+ 智谱2026年3月17日发布专为龙虾（`OpenClaw`）场景优化的`GLM-5-Turbo`，从底层增强工具调用、长链路任务等四项核心能力。

+ 推出龙虾场景评测基准`ZClawBench`，模型多项关键任务领先主流模型，基准题库与测试轨迹即将开源。

+ 模型以`Pony-Alpha-2`代号接入`AutoClaw`盲测，90%受访者认为优于国产模型，获阿里、美团等大厂好评。

+ 发布龙虾套餐（个人/Team版）降低算力成本，构建企业级安全体系保障数据权限与合规。

+ 模型全球首发接入机械革命龙虾盒子，非高峰期限时1倍抵扣至4月底，`AutoClaw`提供免费额度。

## 5️⃣ [AI，正在吞噬所有软件。](https://mp.weixin.qq.com/s/r2j_C8jIdzMJHVQH0Walqg)

> 🤖

+ 2026年AI工具（如`Claude Code`、`Codex`）让普通人无需编程即可快速开发软件，生产成本从几十万降至接近零，开发从专业技能变为基础能力。

+ SaaS模式核心前提（软件难开发）动摇，软件从资产转为耗材，按需即抛无需维护，多数SaaS公司较52周高点下跌30%-80%。

+ `Agent`（如`OpenClaw`）填平人机交互鸿沟，用户无需UI操作，只需描述需求（如报销、订机票），`Agent`自动调用`Skill`完成任务。

+ `Agent`时代产品形态转向`Skill`，用户从人类变为`Agent`，产品优化从人类体验转向`Agent`调用效率（可调用性、可靠性等）。

+ AI颠覆中间层，软件（人机中间层）和组织管理层（意图执行中间层）均被压缩，时代变化加速需适应无中间层场景。

> 关键词：AI吞噬软件、`Agent`、`Skill`，SaaS转型，中间层消亡
