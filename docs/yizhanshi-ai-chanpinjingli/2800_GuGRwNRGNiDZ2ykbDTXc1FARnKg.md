> 首发实测 Floatboat：一人公司的工作方式，可能要变了

>

+   Floatboat是面向一人公司(OPC)的AI原生工作环境，核心消除AI工具间上下文搬运摩擦，让Agent直接感知用户电脑多源信息。

+   支持「All for One」（统一汇聚文件、浏览器、应用等）和「One for All」（上下文跨工具流转），可拖放文件到AI对话并自动读写本地文件。

+   内置Combo Skills模块，能将常用工作流固化为SOP，支持导入Dify/Coze等资源，还可自动沉淀对话流程为可复用技能。

+   开源两个协议：Selfware（.self文件作为Agent容器，含数据+逻辑）和IACT（点击式AI交互，MIT许可）。

+   获红杉与微光创投种子轮投资，支持Claw模式（集成飞书/Telegram）和macOS原生工具调用，助力超级个体提升多角色效率。

> 关键词：Floatboat，AI原生工作环境，OPC，Selfware，Combo Skills

> 详解悟空：阿里 ATH 成立第一炮，给千万企业打造数字员工

>

+   阿里钉钉发布AI原生平台「悟空」，解决OpenClaw类工具缺乏职场常识（权限、安全等）的问题，让AI可安全融入企业工作流。

+   悟空依托钉钉CLI化改造（原子化可调用功能）和RealDoc文件系统（支持AI高频迭代），提升执行效率与可靠性。

+   悟空推出10大行业OPT解决方案，已验证显著生产力提升（如律师服务客户量从10人增至200人）。

+   钉钉凭借企业组织架构、权限体系等核心资产，成为阿里B端AI战略的数字员工入口。

+   悟空支持跨平台连接（钉钉、飞书等），避免生态锁死，旨在成为企业通用AI基础设施。

> 关键词：悟空AI，企业数字员工，钉钉CLI，职场安全防线，跨平台AI
