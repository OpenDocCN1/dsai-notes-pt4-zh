> 超级创业者时代：如何让个人拥有组织级能力

>

+   第四次个体经济浪潮爆发，OPC（一人公司）增长显著（2025年超1200万创业者选择，同比增47%），结合AI实现“个人+AI=公司”单人全链路运营。

+   技术支撑：大模型普惠化（成本下降、多模态能力）、智能体（数字员工自主任务）、低代码/无代码让非技术者快速开发产品。

+   政策松绑：2024新公司法取消一人公司限制，上海徐汇等地区提供算力补贴、创业基金等全生命周期扶持。

+   典型落地：AI+视频（艾门韦思压缩制作周期至3天）、AI+广告（野仙仙一人闭环产业链）、AI4S（科研一人实验室）。

+   OPC商业模式：四条增长路径（项目制、产品化等），形成OPC4OPC分布式协作网络，催生AI艺术总监等新职业。

> 关键词：超级创业者、OPC（一人公司）、AI赋能、个体经济、徐汇实践

> 逼死龙虾，成为龙虾：刚刚，Claude ...

>

+   Claude Code上线Channels功能，支持Telegram/Discord Bot远程控制，无需绑定Claude App，可发送文件、执行编译/转录等命令。

+   该功能面向折腾型开发者，可扩展接CI/CD、监控告警，同时Anthropic上线定时任务（如自动总结PR）。

+   处于研究预览阶段，存在电脑需开机、无法远程授权等限制，需升级至v2.1.80+版本。

+   Anthropic近期动作：3月17日推Claude Dispatch，19日上线Channels，同时封禁OpenCode的Claude插件（类之前对OpenClaw的操作）。

+   OpenCode创始人移除Claude插件，感谢OpenAI等支持开发者自由，Anthropic通过自家插件简化Claude Code远程使用。

> 分享10个你可能不知道的Claude C...

>

+   /btw命令可在Claude执行任务时插入问题，不污染上下文、不中断原有进程。

+   /rewind支持代码与对话分别回退，方便实验不同方案，无需重新解释需求。

+   /model opusplan让Pro用户用Opus做复杂推理规划，Sonnet执行，节省额度。

+   还有/insights（分析使用习惯）、/simplify（三合一代码审查）等实用命令。

+   Ctrl+V粘贴截图、Ctrl+J换行等快捷键提升操作效率，更新日志可查新功能。

> 关键词：Claude Code，隐藏命令，AI开发工具，代码辅助，快捷键
