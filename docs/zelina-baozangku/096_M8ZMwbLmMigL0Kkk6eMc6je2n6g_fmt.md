
# 💡摆脱看不见的无效忙碌，搭建超高效率的每日计划工作流

> 来源：[https://docs.feishu.cn/docx/ZhGRdn9vDodTkOxtwOvc76Yvned](https://docs.feishu.cn/docx/ZhGRdn9vDodTkOxtwOvc76Yvned)

## 📸 设计思路

这个模板非常适合未做过时间管理的新手小白同学。这个表的目的是为了洞察自己每天每时每刻的时间花销，只有明确时间花哪了，才能更好的为下一步做计划。

一般用这个表1-3个月之后，就可以开始过渡到「周度计划」的制定。

## 📅 数据仓库

公共数据源存放在「日期数据仓库」表，这张表会存放一整年的时间数据源，包含季度、月份、周数、周范围等数据。这张表的数据主要是为了给第一张表「🎨每日时间记录跟踪」使用。

## 📎 公式说明

时间小计的计算方式：`TEXT([结束时间]-[开始时间],"hh\hmm\m\i\n")`。

只需填写每项事件的开始时间和结束时间，即可自动计算出具体的小时和分钟数。

## 📝 使用说明

+ 在拿到这个多维表格的第一时间，先在「📅日期数据仓库」填写所属月份、所属周数、所属季度、周开始和周结束时间。

+ 不同的小伙伴对周开始和周结束的定位不一样。周一在设计的时候，如果当前月份最后还剩下4天，就算是这个月的。如果不足4天，就算是下个月的。那有一些小伙伴可能不这么考虑，所以可以依据自身的想法，直接修改具体的时间和所属周数即可。

+ 填写完成后，预设好的分组功能会帮大家按照月份完成分组。然后对应每个月的具体周数，就可以填写相应的开始日期和结束日期啦！

+ 到这里，我们公共的日期数据就都有了。接下来，我们来到最重要的一张表：「🎨每日时间记录跟踪表」。

+ 在这张表里面，首先需要先选择你在周度表已经预设到的数据，比如我选择2024/01 - 第1周，然后上面的分组功能已经帮大家按照所属周数给分组完成。选择完周数后，就可以开始写每一天的TODO事件啦。在每天的早晨，写上自己今天的TODO事件，然后在执行的时候，填写相关的开始时间和结束时间，之后时间小计会帮忙直接统计每项事件所耗费的时长。

+ 在每项事件结束后，要写出自己在这项事件的产出成果，以及相关的产出效能。产出效能包括4种：低效能、无效能、中效能和高效能，依据实际情况进行填写。最后，在每件事件结束后，还要记得填写相关的原因及反思，哪里做的好，哪里做的不好。这一步主要是为了能够窥探自己是否经常做重复工作，当反思被真正记录下来并且去查看和回顾的时候，就能够很清楚的了解自己是否进步了。如果没有进步，适当的调整自己当前的工作方式或学习模式。

+ 模板使用介绍完毕，cheers~🍻
