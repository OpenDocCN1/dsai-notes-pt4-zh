**人生金桔：**

+   何以解忧，唯有暴富。

+   与其内耗自己，不如外耗别人。

+   允许一切发生，让万物穿过自己。

+   以终为始，不怕羞耻，大胆试错，小步快跑。

+   当你以10年的时间去衡量自身的发展时，你会发现你没有对手，连时间都会是你的朋友！

+   当你能够面对自己遇到的所有问题时，就没有人能够伤害你👵。把期待值放到最低，最终就都是惊喜。

+   满分的内容一定没有标准答案，但优秀的内容一定有模板。
