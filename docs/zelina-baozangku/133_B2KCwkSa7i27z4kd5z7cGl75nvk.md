# 读书笔记

> 一周内把上半年的小目标里想看完的两本书给一起完结掉，事实证明，人的high performance在最后一刻能被激发出来🙊

>

> 今年为什么会看这类以前「雷打都不会碰的书」的原因在于，某一段时间，发现我的记忆力好像阶段性到了一个阈值，然后就在想有没有其他方法可以提升

>

> 刚好那段时间在看《令人心动的offer6》，里面关大壮说到了他有异于常人的快速阅读能力，然后我在想，对于记忆来说，是不是也有相关的训练方式

>

> 所以后来找到了《记忆训练》这本书

>

> 里面说到了将理解、再现和实践三种相关的记忆编码进行结合，一个人才能真正拥有把知识应用出去的能力

>

> 以及发现自己一直在实践的阅读和笔记记录方式，发现就是超遗忘规律

>

> 依稀记得2023年看《认知觉醒》时记得最清楚的一句话：所谓天才，其实并不神秘，核心是正确的方法+大量的练习。

> 在看记忆训练这本书的过程中，多个瞬间依旧联想到了这句话，确实所有的东西都需要正确的方法+大量的练习

>

> 记忆的提升最终也是为了更快地解决问题

>

> 作者最后用了一个很形象的例子作为切入：

> 生活中同样的问题总会周而复始再次出现在你面前，比如女/男朋友乱花钱导致债务危机引起吵架。意识不到这个问题的人会过分重视过分关注暂时结果的好坏，然后不断被没解决的问题牵动情绪，就像牛被人牵着鼻子走一样，不断陷入这个糟糕的轮回。

> 我们必须意识到问题要得到真正意义上的解决，这是一个人不断改变自身和外界的过程，即使同样的问题不断地出现，当你已经通过大量改变自己的过程形成了稳定且快速解决问题的能力，即使问题永远还在朝你走来，重复的问题还不断地涌现，但你总是可以轻松地应对它们，这时候问题的存在就不会对你再造成心灵上的困扰了。

>

> 或许记忆的提升就是通过不断地解决新的复杂问题，把这些复杂问题和过去的自己进行关联和复盘，沉淀出新的解决方案，进一步减少重复工作和形成更强的肌肉记忆

>

> 共勉下最后的后记，写的太好了，可以解决 N 个不确定瞬间

>

> End.🎄🎄🎄
