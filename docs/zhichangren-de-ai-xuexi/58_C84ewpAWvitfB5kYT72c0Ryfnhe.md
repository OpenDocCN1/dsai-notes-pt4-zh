## 微软在其 Dynamics 365 业务应用平台上开发了多款 AI Agent

主要服务于销售、客户服务和会计业务。这些 AI Agent 能够自动化处理复杂的工作流程，提高工作效率。

时间：2024 年 10 月 22 日

### AI Agent 的功能与应用

微软在其 Dynamics 365 业务应用平台上集成了 10 个自主 AI Agent，主要用于销售、客户服务和财务等领域。这些 Agent 能够自动化处理复杂工作流程，显著提高工作效率。例如，它们可以帮助销售团队快速生成报告和预测客户需求，从而优化销售策略。

### 效果与收益

根据微软的报告，使用这些 AI Agent 的员工在 IT 自助服务中的成功率提高了 36%，而销售人员的收入增长了 9.4%。这表明，AI Agent 不仅提升了工作效率，还为企业带来了可观的经济效益。

### 技术背景

这些 AI Agent 基于 OpenAI 最新模型 o1，具备自主学习能力，可以自动执行跨平台的复杂业务，节省时间和运营成本。微软强调，这些 Agent 能够分析工作数据，识别工作模式和趋势，从而更好地自动执行业务流程。

### 未来展望

微软设想未来这些 AI Agent 将独立管理多种业务职能，包括 IT 支持和财务管理。此外，微软计划在 2025 年进一步扩展这些 Agent 的功能，以支持更复杂的决策和任务执行。

### 市场影响

微软认为，这些 AI Agent 将推动企业数字化转型，为企业提供更多的自动化解决方案。这一创新不仅提升了企业的运营效率，也为未来的商业模式变革奠定了基础。

## Microsoft Ignite 2024 全球开发者大会详细信息

时间：2024 年 11 月 19 日至 22 日

### 大会概述

Microsoft Ignite 2024 是微软一年一度的技术盛会，旨在展示最新的技术创新和产品更新，帮助客户、合作伙伴和开发人员充分利用微软的技术潜力。大会吸引了超过 20 万名参与者，其中超过 1.4 万人亲临现场。

### 主要发布内容

- 约 80 款新产品和功能：包括智能 Microsoft 365 Copilot 副驾驶、Copilot + AI 堆栈的新功能、Azure AI Foundry 等。

- Copilot Actions 功能：利用 AI 自动化日常重复性任务，提高工作效率。

- Windows 365 Link：一款为 Windows 365 打造的云电脑，旨在提供安全、便捷的云连接。

- Azure 数据中心 Boost DPU 芯片：提高云存储工作负载的运行效率，降低功耗。

### CEO 演讲要点

- 微软 CEO 萨提亚·纳德拉（Satya Nadella）强调了 AI 在商业转型中的重要性，并介绍了 AI 能力的提升如何推动企业创新。

- 纳德拉还提到，微软将继续致力于安全问题，以确保客户的数据和业务安全。

## 微软布了 2025 年六大 AI 预测，认为 AI Agents 将彻底改变工作方式，并将在多个领域发挥重要作用。

### 应用场景与企业影响将呈现出以下重要特点

- 业务流程变革：AI Agent 将被视为 AI 时代的新应用程序，改变每个业务流程。近 70%的财富 500 强公司员工已经开始使用 Microsoft 365 Copilot 来处理重复性任务，如筛选电子邮件和会议记录。预计到 2025 年，这些代理将能代表用户执行更多任务。

- 组织内部效率提升：企业可以设置多个 AI Agent 来处理日常运营中的各种挑战，例如监控库存、推荐供应商、生成报告等。这将使员工能够专注于更高价值的工作，提高整体工作效率。

- 无编码构建代理：用户可以在 Copilot Studio 中无需编程知识构建自己的 AI Agent，而开发人员则可以在 Azure AI Foundry 中创建更复杂的代理。这种灵活性使得不同技术水平的人都能参与到 AI 应用的构建中。

### 生活质量提升

- 日常生活中的支持：Microsoft Copilot 作为 AI 助手，将全天候提供支持，帮助用户简化日常信息处理任务，提高生活质量。例如，它可以在早晨朗读新闻摘要和天气情况，帮助用户更好地规划日常活动。

- 决策支持：AI Agent 还能够协助用户进行决策，例如寻找合适的新家家具并提供最佳布置方案，使得用户在生活中获得更多便利。
