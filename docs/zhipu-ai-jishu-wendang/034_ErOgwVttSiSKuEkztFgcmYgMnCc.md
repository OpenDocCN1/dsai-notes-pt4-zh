# 目录

相信你已经成功掌握了ChatGLM3的基本用法，在本章节，我们将通过以下几个部分进行教学，推动你在ChatGLM3的使用上更胜一筹。

+   模型微调，这将让你学会P-tuning，lora，全参微调等多种微调方式，进一步将GLM3模型适用到你的场景

+   代码解释器，这将让你学会使用大模型来生成并执行代码，完成代码需求。

+   工具调用，这将让你学会调用主流的工具，运用好大模型的思维能力，完成更多任务。

+   接入Langchain，帮助你将ChatGLM接入Langchain框架，方便开发自己的应用。

当你完成这个板块的学习之后，本仓库的所有内容就已经被你成功掌握了。
