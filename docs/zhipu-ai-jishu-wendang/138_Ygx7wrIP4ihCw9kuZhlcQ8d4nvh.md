`GLM`的全称是General Language Model，即通用预训练大语言模型。

智谱清言的智能体也叫`GLMs`，是基于`GLM4`模型搭建的智能体创建平台。

简单地说，你无需编程经验，通过简单的配置一些文字信息，就可以快速构建一个具备专属技能的`GLM`，你的自定义`ChatGLM`时代到来了！

`GLMs` 让任何人都能够自由运用 `GLM-4` 模型并挖掘它的潜力，极大的满足了个性化的使用需求。

`GLM`不仅在集成上更进一步，不必一步步调用，更将成为人人可开发的强大工具。

搭建过程就像是在玩乐高，你只需要按照提示一步步操作，就能搭建出一个好用的 `GLMs`！

## GLMs有哪些主要功能？

得益于`GLM4`模型的强大能力，`GLMs` 具有如下功能：

+   自主理解用户意图：`GLMs`能够根据用户的指令自动理解其意图，无需用户明确指出每一步操作。
+   规划复杂指令：模型可以规划和执行复杂的指令，这些指令可能涉及多个步骤或子任务。
+   调用外部工具：
+   网页浏览器：`GLMs`可以自主调用浏览器，搜索信息、获取数据或访问特定的网页。
+   `Code Interpreter`代码解释器：模型能够执行代码，进行数学计算、编写程序或解决技术问题。
+   文生图`CogView3`模型：`GLMs`可以利用这一工具生成图像，根据文本描述创建视觉内容。
+   高级数学能力：通过代码解释器，`GLMs`能够解决复杂的数学问题，如方程求解、微积分计算等。
+   `All Tools`能力：
+   文件处理：`GLMs`能够处理包括`Excel`、`PDF`、`PPT`在内的多种格式的文件。
+   数据分析：进行数据分析，包括数据清洗、转换和统计分析等。
+   图表绘制：根据数据绘制图表，如条形图、折线图、饼图等。
+   知识库
+   支持`pdf`、`docx`、`xlsx`、`txt`等文件格式，最多支持100个文件，知识库总字数不超过500万字。
