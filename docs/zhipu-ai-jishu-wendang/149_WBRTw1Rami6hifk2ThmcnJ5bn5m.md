# V4 API 模型列表

> 来源：[https://ai.feishu.cn/docx/T60ddhMrGoP0BbxxJOEcILm8nw2](https://ai.feishu.cn/docx/T60ddhMrGoP0BbxxJOEcILm8nw2)

## GLM-4

模型编码：glm-4-0520、glm-4 、glm-4-air、glm-4-airx、 glm-4-flash。

提供了更强大的问答和文本生成能力。适合于复杂的对话交互和深度内容创作设计的场景。

| **模型编码** | **描述** | **上下文长度** | **单价/百万 tokens** | **batch/百万 tokens** |
| --- | --- | --- | --- | --- |
| **glm-4-0520** | 我们当前的最先进最智能的模型，指令遵从能力大幅提升18.6%，发布于20240605。 | 128k | 100元 | 50元 |
| **glm-4** | GLM-4 为 20240116 发布版本 | 128k | 100元 | 50元 |
| **glm-4-airx** | GLM-4-Air 的高性能版本，效果不变，推理速度达到其2.6倍。 | 8k | 10元 | 不支持 |
| **glm-4-air** | 性价比最高的版本，综合性能接近GLM-4，速度快，价格实惠。 | 128k | 1元 | 0.0005元 |
| **glm-4-flash** | 适用简单任务，速度最快，价格最实惠的版本。 | 128k | 0.1元 | 0.00005元 |
| **glm-4-alltools** | AllTools 模型通过对用户提问进行规划，选择合适的工具，逐步分析并采取下一步行动，最终完成一个复杂任务。Alltools API 为开发者提供了一套强大的工具，包括代码、绘图和搜索等工具，能够在应用程序中构建具有高度专业化的AI助手。 | 128K | 0.1元 | 不支持 |

## GLM-4V

模型编码：glm-4v

提供强大的图像理解能力，包括看图解释、OCR、逻辑推理等能力。

> 注释：GLM-4V处理一幅图片大约需要消耗1,047个tokens。

## GLM-3-Turbo

模型编码：glm-3-turbo

适用于对知识量、推理能力、创造力要求较高的场景，比如广告文案、小说写作、知识类写作、代码生成等。

## CogView-3

适用图像生成任务，通过对用户文字描述快速、精准的理解，让AI的图像表达更加精确和个性化。

## Embedding-2

Embedding是将输入的文本信息进行向量化表示。Embedding适用于搜索、聚类、推荐、异常检测和分类任务等任务。
