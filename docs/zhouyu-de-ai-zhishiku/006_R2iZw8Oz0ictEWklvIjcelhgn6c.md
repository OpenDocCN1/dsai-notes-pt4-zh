# 用Cursor 1小时开发了个记账App，这是我踩过的所有坑

## 前期准备：安装必备软件

在开始编程前，需要先安装两个软件：

+   **Cursor**：主流的 AI 编程 IDE 工具，能大大提高开发效率。

+   **XCODE**：苹果官方的开发工具，用于开发 IOS 和 Mac os 应用。

## 项目设置：在 XCODE 中创建项目

1.  安装好软件后，打开 XCODE，点击 “创建新项目”。

1.  在项目模板里选择要开发的 app 类型。

1.  给项目起名，如 “harvest”。organizational identifier 一般用反着的域名格式，要是没有自己的域名，也可随便填一个。

1.  其他设置按默认即可，数据存储方式若 app 数据结构不复杂，选 “没有”；复杂的话，可选 CORE data。

1.  填好信息点击 “下一步”，创建项目文件夹，完成项目设置。

XCODE 主界面中，中间是代码编辑区，右面是 canvas 预览区。修改内容后，canvas 区域会实时更新。左侧项目文件列表里，XCODE 已自动创建基础项目文件，后续开发的页面都会保存在此。

## 配置 Cursor：连接项目与设置模式

1.  打开 Cursor，点击 “打开项目”，找到 XCODE 创建的文件夹，此时左侧文件列表和 XCODE 里的基础文件会同步。

1.  在项目里创建新文件夹设置 Cursor。cursor room 是自定义指令体系，给 AI 设定行为准则和协作流程，Cursor 会加载它作为聊天上下文的前置人格设定和工作指令。

1.  设置好 cursor room 后保存关掉，在右侧聊天区域把模式切换成 AG 模式。因为在特定的 cursor room 里，只有 AG 模式下，让 Cursor 一边开发、一边记录需求、生成文档、跟踪开发进度这些功能才能实现，ask 和 menu 模式不行。

1.  模型推荐使用 cloud3.7、so net 和 GERMANA2.5pro ，有预算也可选最新的 chat gbt o3，这些模型在 AI 编程中响应快、上下文理解强。

## 开发环节：从项目初始化到页面开发

1.  **项目初始化与需求设定**：和 Cursor 打招呼，测试设置的 cursor room 是否生效。它会做自我介绍并提问了解需求，回复时项目名称必须和 XCODE 里创建的完全一致。提交需求后，Cursor 会自动创建 read me 的 markdown 文件，写入项目分析，如技术选型、页面结构规划、各页面功能等，还会有开发状态跟踪，方便了解页面开发进度。

1.  **页面开发方式与流程**

+   **开发方式**：设定了两种开发方式，一是输入开发指令，让 Cursor 按规划顺序自动开发所有页面；二是手动指定某一个页面开发。

+   **主页面开发**：指定开发主页面，Cursor 会设计完整的技术实现方案，包括 UI 布局设计、数据管理方案、交互逻辑、组件复用等，并同步记录到 read me 文档里。开发状态跟踪里主页面状态变为 “进行中”，代码写完后，它会自检，完成后通知代码保存位置，可切换到 XCODE 编译预览，还会概括页面功能模块。

+   **记账主页开发**：开发记账主页流程和主页面一样，不过开发完成在 XCODE 的 canvas 预览时可能会报错。这时全选报错信息复制到 Cursor 里，输入 “问题” 指令启动流程，让它 debug。Cursor 修复后会说明错误原因和解决办法，回到 XCODE，canvas 就能正常预览。

1.  **剩余页面开发**：已开发两个页面，剩下页面流程相同，可输入 “开发” 指令让 Cursor 自动完成。过程大概 20 分钟，中间有几次简单手动确认步骤，这里跳过。

## 错误处理：解决大量报错问题

所有剩余页面开发完成后，回到 XCODE 会发现有很多报错和警告，这些错误可能由代码重复、未初始化组件冲突等原因导致。解决方法是复制所有报错信息到 Cursor，输入 “问题” 指令让它处理，但这次很难一次性解决，处理这些 bug 可能需要花费较长时间。

## 成果展示：预览记账 App

修复完所有 bug 后，点击 XCODE 左上角的播放按钮，启动模拟器就能预览 app。app 包含主界面、统计页面、设置页面等。主界面可添加记录，功能完整；统计页面能按日、月、年查看收支情况并生成 PDF 报表；设置页面支持预算管理。虽然 app 还有细节问题，但一个多小时做出这样的 MVP demo 已很不错。后续可打磨细节，注册苹果开发者账号，打包上传上线。

## 开发心得：总结经验与建议

1.  **零基础也能开发**：零基础小白借助 AI 编程能成为独立开发者，AI 降低了入门门槛，但也需要了解基本的产品开发流程和设计思维，能分辨产品好坏，清楚表达需求。

1.  **别期望一键完成**：别想着一键就能开发出完整产品，复杂场景或需求需和 AI 反复沟通，建议一个页面一个页面开发，每个页面开发完都要 debug 和检查，避免问题累积。

1.  **提示词框架很重要**：cursor room 或系统提示词决定和 AI 合作的质量、节奏以及项目能否顺利完成。一套好的提示词框架既能引导 AI，也能反向引导开发者完成开发。
