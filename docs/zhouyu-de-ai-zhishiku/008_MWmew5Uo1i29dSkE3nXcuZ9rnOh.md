IOS方面的**swift**编程语言

掌握了 Swift 语言后，就可以开始学习 iOS 应用开发框架了

+   **Xcode IDE：** 熟悉苹果官方的集成开发环境，包括代码编辑器、调试器、界面设计工具等。

+   UIKit (传统) 或 SwiftUI (现代)：

+   **UIKit：** 成熟、功能完备的 UI 框架，有大量存量项目和学习资源。

+   **SwiftUI：** 苹果推出的声明式 UI 框架，更现代化，代码更简洁，是未来的趋势。对于初学者，如果精力允许，可以直接从 SwiftUI 开始，或者先了解 UIKit 的基本概念再转向 SwiftUI。

+   视图 (View) 与视图控制器 (View Controller)： iOS 应用界面的基本组成单元。

+   **界面布局：**

+   Auto Layout (UIKit)

+   SwiftUI 的布局系统

+   **用户交互与事件处理：** 按钮点击、手势识别等。

+   导航 (Navigation)： 在不同界面间切换。

+   **数据持久化 (初级)：**

+   UserDefaults (存储简单配置)

+   Core Data / Realm / SwiftData (更复杂的数据存储) - 可以稍后深入。

+   **网络请求：** 从服务器获取数据 (如 URLSession)。

+   **异步编程：** 处理耗时操作（如网络请求）不阻塞用户界面，例如使用 async/await。

#### **4. 版本控制工具**

+   **Git：** 必备的源代码管理工具。学习如何创建仓库、提交更改、创建分支、合并等。GitHub 或 GitLab 是常用的托管平台。

## Flutter语言

Google 开发的开源 **UI 软件开发工具包** (SDK)。它允许开发者使用**一套代码库**为移动 (iOS, Android)、Web 和桌面 (Windows, macOS, Linux) 平台构建高性能、高保真度的应用程序。
