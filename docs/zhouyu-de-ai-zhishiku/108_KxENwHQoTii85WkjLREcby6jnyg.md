在正式开始之前，先跟大家介绍一下，我是第四种黑猩猩的李超，我是一位连续的AI创业者，现在在做一个艺人的AI公司。这个频道专注于为像我一样希望在AI时代当中打造自己产品、建立一人公司的普通人带来有价值的内容。所以如果你也对这样的内容感兴趣，请点赞关注我的频道，这对我的频道真的非常有价值。如果你有任何的问题，请在下方评论区留言，我也会认真地回答这些问题。好了，下面我们就正式开始吧。

这里面99%的代码都是由AI写出来的，剩下的1%也是AI手把手教我写出来的。

第一步，系统设计。这一步是需要你最动脑筋的环节，也是我觉得最重要的环节，但也是很多小白忽略的环节。很多初学者上来就喜欢一顿猛干，但是我非常不建议你在这一块去节省时间，因为虽然你这里可能节省了5分钟，后面可能要折腾好几个小时来补偿。具体怎么做呢？因为我们现在有个大概的想法，我们可以先把大概的想法告诉AI，然后让AI给我们画个草图，然后再一遍一遍地来优化它。我先写一段提示词，然后发给TIPSICK，当然你也可以用你顺手的大模型，open n i的GPT4O模型最近推出了图片生成功能，输出一张给大模型输入一张图片、一些风格提示词生成的新的风格化的图片，效果非常好。所以我想写一个项目，方便用户直接使用这个功能，用户上传图片，选择风格就能生成新的图片，并且需要用户付费使用，我想要设计这个项目，还缺少哪些关键信息向我提问。这段提示词说明了项目的背景，GPT4O能生成风格化的图片，然后简单说说我的需求，这要划重点的是让AI向我提问，因为这刚开始，我们对整个应用也只有一个大概的想法，很多具体的细节还不清晰，最好的方法就是让AI向我们提问。等AI问了我们一系列的问题之后，我们再把补充好的信息再整理一遍，第二次向AI提问，这次就是正式让AI开始设计项目了。你看这次有了一条一条详细的要求，并且最后还让它画了一个架构图。我们来看一下，AI做的这个设计中规中矩，挺标准化的这个架构。这里的前端界面就是指用户在网站里面看到的那个网页，这里的后端服务器就是你看不到的，在后台默默干活的电脑程序，它负责用户点击按钮之后发来的操作，然后跟OpenAI进行沟通处理、支付这些复杂的任务。这里的open n i API指的就是OpenAI提供的一种服务，我们把图片和提示词发给OpenAI，让它帮我们生成新的图片传回给我们。如果你对前端后端API这些词还不太明白，也没关系，你可以随时问你的AI，让它给你解释得清清楚楚。这里我就先不多说了，但是这里还有个大问题，因为我们的目标是艺人公司时间有限，甚至我们可能还是个初学的小白，这个架构里的C服务器以及E支付系统，是一般的小白很难用AI在短时间内开发出来的。所以为了不去做这两块比较复杂的模块，但同时又要能够让用户支付、管理用户的这些使用量，所以我就想到了一个办法，用一个密钥来限制和管理用户的使用次数。这里具体使用的就是一个叫做new API的开源项目，它是专门用来生成和管理这个密钥的。于是我就把这个新的思路也告诉AI，让它帮我们重新设计一下这个项目的架构，修改之前的提示词。我们来看一下这个架构，用户先去网店买密钥，拿到密钥之后，回到我们的网站输入密钥，上传图片，选风格，我们这个网站就会拿着这些信息去找new API，new API待会去找OpenAI，OpenAI处理完之后，图片会原路返回，最后用户就能在网站上看到了。我花了很多时间来打磨这个架构设计，是不是感觉好像有点复杂，但相信我这绝对非常值得。这个纯前端的项目加上new API加上网店的模式，不仅仅能在这个工具里面使用，其实它可以用在任何你想做的需要调用大模型API的小产品上面，它大大简化了我们的开发流程。

第二步，生成产品需求文档。那么第一步系统设计终于搞定了，现在我们可以让它帮我们出一份更正式一点的产品需求文档，行业黑话呢叫做PRD。稍后你就可以把这些PRD文档直接拿给那些会写代码的AI工具。于是我就去向deep sick发问了，基于我们上面讨论的确定的这些简化版的系统设计需求，我想为这个AI工具生成一份产品需求文档，pd为了让这个PD更完善，请问还需要我补充哪些关键信息，你可以向我提问。大家也可以看到，这就是我使用AI的最常用的一种方法，如果我没有特别明确、特别清晰的方向，我是问不出问题的，所以我可以让AI向我提问。大家可能会问你一些关于界面细节、具体风格选项、错误提示怎么显示之类的问题，你不需要把所有的问题都回答得很完整、很准确，挑重点的说，或者按你的想法回答一部分就行了，然后就可以让AI开始帮你写PRD了。

第三步，用V0工具生成第一版的网页代码。打开V0点DAVE网站注册登录进去，然后把之前deep sk帮我们生成的PRD文档直接粘贴，V0就会开始刷刷刷地帮你开始写代码。V0是我SL公司出的网页开发工具，经过我测试，生成前端代码的水平比其他工具确实要高很多，最关键是免费额度也足够，操作足够简单。如果你发现有bug或者不满意的地方，就在聊天框里告诉V0，让它修改。我建议是一次性把你发现的所有问题都告诉他，这样可以减少来回沟通的次数，效率会更高。这一步生成的代码不一定要功能上100%的完美无缺，只要显示效果、页面布局大致达到你的预期就足够了，因为V0这个工具主要还是帮你去快速搭建这个第一个初步版本的这样一个工具，它的名字之所以叫V0，意思也就是说最初的版本，第零个版本的意思。

第四步，用cursor或者win surf进行进一步的调试和功能完善。命令生成的项目，功能上可能还有不少的bug，甚至有些交互也还没实现，所以我建议用cursor或者win serve这样的专业的AI编程工具来做进一步的优化。我这次呢用win surf来做演示，步骤也非常简单，第一步就是下载代码，第二步打开项目，就是用win serve打开刚刚下载的那个项目文件夹，第三步就是安装依赖，什么意思呢？就是运行这个命令来安装一些项目需要用到的一些第三方的插件，第四步运行项目运运行npm run def来启动项目。项目跑起来之后，在浏览器里面访问对应的地址，你就可以看到你的网页了。

第五步，测试和修复。在浏览器里面，你可以实际使用你的网页，遇到任何的错误、功能不正常的地方，可以把错误信息截图或者描述一下，比如说我点了这个按钮没反应，直接发给win serve，让它帮你修改。如果一次不行，那就多试几次，很多问题呢AI都可以帮你直接搞定。这里说一个非常非常非常重要的小技巧，可以说是AI编程的这个救命稻草，每次来帮你修好一个bug，或者你对某个时刻的网站状态基本满意了，我强烈建议你用get保存一次代码。简单来说，这个get就像游戏时的这个存档，AI写的代码呢有个比较大的毛病，就是他可能会过于热情，一下子修改一大片他认为相关的代码，结果呢可能把好的地方也给改坏了，但有了get之后，如果AI代码改崩了，或者你不喜欢它的修改，你可以随时读档，轻松地回到之前某个你喜欢的那个状态。

第五步，部署上线。终于要上线了，第一就是打包项目，按你的win serve里面呢运行npm run build，不会的话，你也可以完全让WINSF里面的AI帮你来做这件事情，这一步会把你的代码优化压缩，生成一个完整的项目包。然后第二步呢就是上传到服务器，把你刚刚生成的这个项目包上传到服务器或者其他的一些网站托管平台，这样别人就可以看到你的网站了。大功告成，当然如果你完全不知道怎么操作、怎么上线，别忘了你还可以随时问你的AI助手，win serve里面的AI助手呢可以说是这方面的专家中的专家。

上面这五步呢就是个简略版的开发步骤以及思路解析，你是不是还有很多没听懂的，每个步骤都有一些卡住的地方，没关系，考虑到这个视频的时长关系，我们会继续开发一个完全面向小白、更加零基础版本的保姆级教学，在我们的下一个产品里面，提供给有需要的朋友们。
